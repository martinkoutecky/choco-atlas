The continuous mirror question, as graded

Given a finite directed compatibility graph \(A\) on types \(T\), rational masses \(\mu_t\), a fixed cycle limit \(\ell\), and \(k\) hospitals each holding \(\mu_t/k\) of type \(t\), choose nonnegative mass \(x_C\) on each compatible cycle \(C\) of hospital-labelled types \((i,t)\). Respect every supply constraint \(\sum_C a_{(i,t),C}x_C\le \mu_t/k\), and maximize \(\sum_C |C|x_C\) subject to each hospital’s matched mass being at least its internal optimum \(V(\mu)/k\), where \(V(b)\) is the maximum cycle-packing value at type supplies \(b\).

Result

For every fixed \(\ell\ge 2\), an exactly optimal, individually rational packing can be computed in polynomial time. Its welfare is \(V(\mu)\), so the requested additive loss is zero.

This holds for all instances in the stated divisible mass model. The essential premises are that every hospital has the same type proportions and that cycles entirely within one hospital are allowed.

1. The type packing linear program

Let \(\mathcal P\) be the set of permitted cyclic type sequences of lengths from \(2\) through \(\ell\). Repeated types are allowed, exactly as in the question. If cyclic rotations represent the same pattern, retain one representative.

For \(p\in\mathcal P\), write \(r_p=|p|\) and let \(g_{t,p}\) count occurrences of type \(t\). Thus \(\sum_{t\in T}g_{t,p}=r_p\).

By the definition of divisible packing, for any nonnegative supply vector \(b\),

\(\displaystyle V(b)=\max\left\{\sum_{p\in\mathcal P}r_p y_p:\ y_p\ge 0,\quad \sum_{p\in\mathcal P}g_{t,p}y_p\le b_t\ \text{for every }t\in T\right\}.\)

This is an exact formulation of \(V(b)\): each variable assigns mass to one permitted pattern, and its occurrences consume the corresponding type supplies.

The feasible set is nonempty because the zero vector is feasible. It is bounded: for every pattern \(p\), choose a type \(t\) occurring in it. Nonnegativity and that type’s supply constraint imply

\(\displaystyle 0\le y_p\le \frac{b_t}{g_{t,p}}.\)

The feasible set is also closed, so an optimum exists. If \(\mathcal P\) is empty, the empty packing has value zero.

Let \(y^*\) be an optimal solution for supplies \(\mu\). Then

\(\displaystyle \sum_{p\in\mathcal P}r_p y_p^*=V(\mu).\)

2. Constructing the hospital packing

For each hospital \(i\in\{1,\ldots,k\}\) and pattern \(p=(t_1,\ldots,t_{r_p})\), define

\(\displaystyle C_i(p)=((i,t_1),\ldots,(i,t_{r_p})).\)

This is a permitted hospital-labelled pattern: all its compatibility arcs are those of \(p\), and compatibility applies within hospitals. Repeated labels are permitted by the stated model.

Assign

\(\displaystyle x_{C_i(p)}=\frac{y_p^*}{k},\)

and assign zero to every other hospital-labelled pattern.

For each hospital \(i\) and type \(t\), the mass consumed is

\(\displaystyle \sum_C a_{(i,t),C}x_C=\frac1k\sum_{p\in\mathcal P}g_{t,p}y_p^*\le\frac{\mu_t}{k}.\)

Thus the packing is feasible. Each hospital’s matched mass is

\(\displaystyle u_i(x)=\frac1k\sum_{p\in\mathcal P}r_p y_p^*=\frac{V(\mu)}k.\)

Consequently, every individual rationality constraint holds with equality. Summing over hospitals gives

\(\displaystyle W(x)=\sum_{i=1}^k u_i(x)=V(\mu).\)

3. The construction attains the global benchmark

For completeness, no feasible hospital-labelled packing can exceed \(V(\mu)\).

Given any such packing \(x\), erase the hospital labels from each pattern \(C\), and denote the resulting type pattern by \(p(C)\). Aggregate its masses as

\(\displaystyle \bar y_p=\sum_{C:\,p(C)=p}x_C.\)

Erasing labels preserves length and type multiplicities. Therefore, for each type \(t\),

\(\displaystyle \sum_{p\in\mathcal P}g_{t,p}\bar y_p=\sum_{i=1}^k\sum_C a_{(i,t),C}x_C\le\sum_{i=1}^k\frac{\mu_t}{k}=\mu_t.\)

Hence \(\bar y\) is a feasible type packing. Its objective value is

\(\displaystyle \sum_{p\in\mathcal P}r_p\bar y_p=\sum_C |C|x_C=W(x).\)

The definition of \(V(\mu)\) now implies \(W(x)\le V(\mu)\). Section 2 attains this bound while satisfying individual rationality.

4. Polynomial time and encoding length

There are at most

\(\displaystyle N=|\mathcal P|\le\sum_{r=2}^{\ell}\tau^r\)

type patterns. Enumerate all these tuples and check their consecutive compatibility arcs, including the closing arc. For fixed \(\ell\), this takes polynomial time in \(\tau=m\).

The linear program has \(N\) variables and \(\tau\) supply constraints, together with nonnegativity constraints. Its matrix and objective coefficients are integers between zero and \(\ell\); its right-hand sides are the input binary rationals. Its total encoding length is therefore polynomial in \(\tau\) and \(L\), with the polynomial depending on fixed \(\ell\).

The standard rational linear programming theorem states that an explicitly encoded rational linear program with a nonempty feasible set and a finite optimum admits an exact rational optimal solution computable in time polynomial in its encoding length. Such a solution has polynomial encoding length. These are the polynomial-time and rational-size results covered in the [MIT notes on LP algorithms](https://courses.csail.mit.edu/6.854/21/Notes/n14-LP_algorithms.html) and [LP encoding length](https://courses.csail.mit.edu/6.854/21/Notes/n11-lp.html). The preceding sections verify the required hypotheses here.

Finally, output at most \(kN\) hospital-labelled patterns. Dividing each rational mass by \(k\) increases its encoding length by at most \(O(\log k)\). The complete algorithm and output therefore have size polynomial in \(m,\tau,k,L\).

The algorithm is deterministic and does not use \(\delta\). Since \(V(\mu)\ge0\) and \(\ln(k/\delta)>0\), its equality \(W(x)=V(\mu)\) implies the requested additive guarantee for every permitted \(\delta\).

5. Relation to discrete ownership

The [Blum et al. model](https://cs.au.dk/~iannis/publ/C83-soda17.pdf) assigns individual vertices randomly to hospitals and uses discrete matchings. The construction above instead uses the exact proportional supplies and divisible pattern masses specified here: each hospital can implement a scaled copy of the same optimal type packing. Thus the cited discrete implementation difficulty does not obstruct this mass formulation.
