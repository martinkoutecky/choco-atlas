Theorem 2 — class: algorithmic

The continuous mirror question, as graded

Given a finite spatial template with role set \(T\), conflict graph \(H=(T,E)\), and common role bids, repeat the template across zones \(u\in[0,1]\), with zones more than \(d\) apart. Each role has mass \(\mu_t=1/|T|\), and an allocation \(a(u)\in\{0,1\}^{T}\) must satisfy \(a_t(u)+a_s(u)\leq1\) for each \((t,s)\in E\) almost everywhere. Find a measurable allocation whose served mass is at least the Theorem 2 factor \(\min\{\kappa/\bar d(H),\,\kappa' \log(\log \Delta(H))/\Delta(H)\}\) times the maximum feasible served mass, where \(\bar d(H)\) and \(\Delta(H)\) are the average and maximum degrees.

A society is given by its support: the list of the \(\tau\) types with positive mass, each mass a binary rational; \(\tau\) denotes support size, not the number of possible types.
Here the types are roles \(T\), with \(m=\tau=|T|\), masses \(\mu_t=1/m\), and a finite simple undirected conflict graph \(H=(T,E)\). Each role has a positive rational bid \(b_t\), identical across its copies.
The population is \(T\times[0,1]\), with measure \(\mu_t\,du\), where \(du\) is Lebesgue measure. The coordinate \(u\) labels independent zones: conflicts occur only between roles in the same zone, as specified by \(H\).
An allocation is a measurable map \(a:[0,1]\to\{0,1\}^{T}\) satisfying \(a_t(u)+a_s(u)\leq1\) for every \((t,s)\in E\), almost everywhere.

Computational allocations are represented by finitely many intervals with binary rational endpoints and a binary allocation vector on each interval. Let \(L\) be the total input bit length; running times are measured in \(m,\tau,L\).
Write \(\bar d(H)=2|E|/m\) and \(\Delta(H)=\max_{t\in T}\deg_H(t)\). Fix positive constants \(\kappa\) and \(\kappa'\), with \(\kappa'\) depending only on \(\kappa\), and use natural logarithms.

Conclusion and interpretation of the constants

The intended approximation guarantee is computable in polynomial time. The independent-zone continuum problem is exactly equivalent, including approximation ratios, to unweighted maximum independent set on the role graph.

I interpret the constants as in the cited approximation theorem: for every fixed \(\kappa>0\), there is a suitable constant \(\kappa'(\kappa)>0\). This is an existential choice of the second constant, rather than a guarantee for every arbitrarily prescribed positive pair. That is the interpretation underlying [STAMP, Theorem 2](https://www.cs.sjtu.edu.cn/~fwu/res/Paper/ZWC13GLOBECOM.pdf).

Below I prove a slightly stronger statement under this interpretation: a suitable second constant makes the guarantee valid for every \(\Delta(H)\geq3\), with the required finite representation.

1. Exact reduction to maximum independent set

Write \(\alpha(H)\) for the maximum cardinality of an independent set in \(H\).

For any feasible measurable allocation, define \(\ I(u)=\{t\in T:a_t(u)=1\}\). Because \(H\) has finitely many edges, the union of the exceptional null sets in its feasibility constraints is null. Outside that union, \(I(u)\) is independent. Consequently,

\(\displaystyle S(a)=\frac1m\int_0^1|I(u)|\,du\leq\frac{\alpha(H)}m.\)

Conversely, any independent set \(I\subseteq T\) gives the constant feasible allocation \(a_t(u)=\mathbf1_{\{t\in I\}}\), whose served mass is \(|I|/m\). Taking a maximum independent set proves

\(\displaystyle \mathrm{OPT}=\frac{\alpha(H)}m.\)

In particular, the supremum is attained. Bids play no role in this equality because they neither weight the objective nor alter feasibility.

The equivalence also preserves computational approximation guarantees. Suppose a represented allocation uses positive-length intervals of lengths \(\lambda_j\), with allocation sets \(I_j\). Feasibility almost everywhere forces every \(I_j\) to be independent: an edge violation on a positive-length interval would violate feasibility on positive measure. Since

\(\displaystyle mS(a)=\sum_j\lambda_j|I_j|\leq\max_j|I_j|,\)

selecting a largest \(I_j\) produces an independent set at least as good as the allocation’s average. This extraction takes polynomial time in the representation length.

Thus mixing allocations across zones provides no improvement in either the optimum or the achievable approximation ratio.

2. A constructive graph-theoretic ingredient

We use the following established result: there is an absolute constant \(c>0\) such that, for each fixed integer \(\ell\geq3\), a deterministic polynomial-time algorithm on a \(K_\ell\)-free graph with \(n\) vertices and sufficiently large average degree \(d\) constructs an independent set of size at least

\(\displaystyle c\,\frac nd\log\!\left(\frac{\log d}{\ell}\right).\)

This is the constructive clique-free independence bound developed in [Halldórsson and Radhakrishnan, Section 3](https://www.cs.helsinki.fi/njc/njc1_papers/number4/paper5.pdf).

We need a uniform consequence. For each fixed \(\ell\), there is \(c_\ell>0\) and a deterministic polynomial-time algorithm that, given a \(K_\ell\)-free graph \(F\) and an integer \(D\geq3\) satisfying \(\Delta(F)\leq D\), returns an independent set of size at least

\(\displaystyle c_\ell |V(F)|\,\frac{\log\log D}{D}.\)

Here are the details handling small degrees and the use of an upper bound \(D\). Choose a fixed integer \(D_\ell\) large enough that the quoted theorem applies above \(D_\ell\) and \(D_\ell\geq\exp(\ell^2)\). Put

\(\displaystyle c_\ell=\min\left\{\frac c2,\frac1{D_\ell+1}\right\}.\)

If the average degree \(d\leq D_\ell\), a greedy independent set has size at least \(|V(F)|/(d+1)\), hence at least \(|V(F)|/(D_\ell+1)\). This suffices because \(0<\log\log D/D<1\).

If \(d>D_\ell\), define \(g(x)=\log((\log x)/\ell)/x\). Its derivative is

\(\displaystyle g'(x)=\frac{1/\log x-\log\log x+\log\ell}{x^2}.\)

For \(x\geq\exp(\ell^2)\), this derivative is negative and \(\log\log x-\log\ell\geq\frac12\log\log x\). Since \(d\leq D\),

\(\displaystyle g(d)\geq g(D)\geq\frac{\log\log D}{2D}.\)

The quoted constructive theorem therefore gives the claimed bound. Empty graphs are handled by returning the empty set.

3. A polynomial algorithm with the requested factor

Fix \(\kappa>0\), and choose a fixed integer \(\ell\geq\max\{3,4\kappa\}\). Define

\(\displaystyle \kappa'_0(\kappa)=\min\left\{\frac{c_\ell}{2},\frac12\right\}.\)

The following algorithm works for every \(0<\kappa'\leq\kappa'_0(\kappa)\).

First, compute a minimum-degree greedy independent set \(G\) in \(H\). It satisfies

\(\displaystyle |G|\geq\sum_{v\in T}\frac1{\deg_H(v)+1}\geq\frac m{\bar d(H)+1}.\)

For completeness, the first inequality follows inductively: selecting a minimum-degree vertex of degree \(\delta\) removes \(\delta+1\) vertices, whose reciprocal-degree terms sum to at most \(1\); degrees of surviving vertices decrease, so their terms can only increase. The second inequality is Cauchy–Schwarz.

Next, repeatedly remove an \(\ell\)-clique until none remains. Let \(F\) be the remaining induced graph, with \(n\) vertices. Run the algorithm from Section 2 on \(F\), using \(D=\Delta(H)\), obtaining an independent set \(J\). Return the larger of \(G\) and \(J\).

Set \(\alpha=\alpha(H)\), \(d=\bar d(H)\), and \(\Delta=\Delta(H)\). The removed cliques are disjoint. An independent set meets each in at most one vertex, so

\(\displaystyle \alpha\leq\frac{m-n}{\ell}+\alpha(F)\leq\frac m\ell+n.\)

There are three cases.

If \(d<1\), greedy gives \(|G|>m/2\geq\alpha/2\). Since \(\kappa'\leq1/2\) and \(\log\log\Delta/\Delta<1\), this exceeds \(r(H)\alpha\).

If \(d\geq1\) and \(n\geq\alpha/2\), the clique-free algorithm gives

\(\displaystyle |J|\geq c_\ell n\frac{\log\log\Delta}{\Delta}\geq\kappa'\alpha\frac{\log\log\Delta}{\Delta}\geq r(H)\alpha.\)

If \(d\geq1\) and \(n<\alpha/2\), the preceding upper bound implies \(\alpha<2m/\ell\). Therefore,

\(\displaystyle \frac{|G|}{\alpha}>\frac{\ell}{2(d+1)}\geq\frac{\ell}{4d}\geq\frac{\kappa}{d}\geq r(H).\)

Every case establishes the required approximation.

Clique removal is polynomial because \(\ell\) is fixed: enumerate all \(\ell\)-vertex subsets at each of at most \(m\) removal steps. The other algorithms are also polynomial for fixed \(\ell\). Their polynomial exponents may depend on \(\kappa\), which is a fixed constant.

4. Required allocation representation

For the returned independent set \(I\), output one interval with endpoints \(0\) and \(1\), carrying the vector \(\mathbf1_I\). Both endpoints are binary rationals, and the representation uses \(O(m)\) bits.

By Section 1,

\(\displaystyle S(a)=\frac{|I|}{m}\geq r(H)\frac{\alpha(H)}m=r(H)\mathrm{OPT}.\)

The running time is polynomial in \(m,\tau,L\), with \(\tau=m\). This proves the intended approximation guarantee directly for the continuum model; a separate continuum approximation theorem is unnecessary.
