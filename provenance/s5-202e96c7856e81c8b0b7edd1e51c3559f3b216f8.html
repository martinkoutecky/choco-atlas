The continuous mirror question, as graded

Given a finite type set \(\Theta\), rational masses \(\mu_t\) with \(\sum_t\mu_t=1\), and ranked smart ballots \(B_t=(D_t^1>\cdots>D_t^{k_t}>b_t)\), where each \(D_t^h=(S_t^h,\varphi_t^h)\) references types in \(\Theta\) and uses a contingent complete-DNF Boolean function, decide whether there is a type ordering and consistent certificate \(\ell\) such that \(\sum_{t\in\Theta}\mu_t\ell_t\le M\), with every type receiving its selected integral direct vote and inducing a direct-vote distribution over the population.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a nonempty list \(\Theta\) of \(\tau\) types with positive binary-rational masses \(\mu_t\), summing to \(1\); \(\tau\) is the support size, not the number of possible types. There is one binary issue, with vote domain \(\{0,1\}\) and no abstention.
Each type submits a strict ranked ballot \(B_t=(D_t^1>\cdots>D_t^{k_t}>b_t)\), where \(k_t\geq0\), \(b_t\in\{0,1\}\), and \(D_t^h=(S_t^h,\varphi_t^h)\) with \(\varnothing\neq S_t^h\subseteq\Theta\setminus\{t\}\). The variables of \(\varphi_t^h\) belong to \(S_t^h\); the formula is contingent and explicitly represented in complete DNF, meaning the list of all its prime implicants.
Ballots are valid: whenever two delegation levels have intersecting delegate sets, their Boolean functions are inequivalent, comparing them on the union of their variable sets.
A certificate chooses one integral level \(\ell_t\in\{1,\ldots,k_t+1\}\) per type. It is consistent if some permutation of the types assigns their votes sequentially: level \(k_t+1\) assigns \(b_t\); a delegation level assigns \(x_t\in\{0,1\}\) only when every completion of its still-unassigned delegate variables gives the same value \(x_t\), given previously assigned votes.
Every type's entire mass receives its assigned vote; the resulting distribution is \(p_j=\sum_{t:x_t=j}\mu_t\) for \(j\in\{0,1\}\). The input also includes a nonnegative binary-rational bound \(M\). The decision problem asks whether a consistent certificate satisfies \(\sum_t\mu_t\ell_t\leq M\).
State running times in \(m=1\), \(\tau\), the maximum ballot length \(K=\max_t(k_t+1)\), and the total input bit length \(L\), including all explicit formulas, masses, and the bound.

Is this mass-weighted consistent-certificate decision problem solvable in polynomial time, or is it NP-hard?

For finite agents with an unweighted sum of selected levels, the decision problem is NP-complete, even with only positive literals; restricting delegations to copying one other agent makes minimum-sum unravelling polynomial-time computable. [Source](https://arxiv.org/pdf/2111.13145)
No result settling exactly the mass-weighted problem defined here was located in the literature search.

Modeling choices made when packaging the task

  • Specified one binary issue without abstention, following the Boolean delegation language.
  • Required positive masses on a nonempty support, retaining the stated normalization to total mass one.
  • Carried over ballot validity: no self-delegation and no equivalent delegation functions at levels whose delegate sets intersect.
  • Required nonempty delegate sets, since a Boolean function on an empty set cannot be contingent.
  • Defined complete DNF as an explicit list of all prime implicants, rather than a list of full satisfying assignments.
  • Fixed certificate indexing: delegation levels are one-based and the backup vote has level k_t+1.
  • Defined consistency using necessary values over every completion of unresolved delegate votes, rather than requiring all delegates to precede the type.
  • Specified a nonnegative binary-rational bound, allowing the normalized weighted objective to be compared exactly.
  • Retained one integral level and one integral vote for each entire type mass, and defined the induced vote distribution.
  • Defined m as the number of issues, fixed to one, and L as the total explicit input bit length.

Result

The problem is NP-complete, under the stipulated input guarantees. NP-hardness already holds with \(m=1\), \(K=2\), and every delegation formula a single conjunction of positive literals.

The proof below handles dyadic masses explicitly, so it applies even if “binary-rational” means a rational with a finite binary expansion. The conjunction construction parallels the finite-agent reduction in [Lemma 2 of the cited paper](https://arxiv.org/pdf/2111.13145), but we give a self-contained reduction from Vertex Cover.

1. Polynomial-time verification

A witness consists of the selected levels \((\ell_t)_{t\in\Theta}\) and a permutation of the types. We verify the claimed sequential assignment in that order.

First, we establish how to evaluate a complete DNF under a partial assignment \(\alpha\). A cube is a consistent conjunction of literals.

Lemma. For a Boolean function \(\varphi\) represented by all its prime implicants:

  • Every completion of \(\alpha\) satisfies \(\varphi\) if and only if some listed cube has all its literals assigned true.
  • Every completion of \(\alpha\) falsifies \(\varphi\) if and only if every listed cube contains an assigned false literal.

Proof. For the first assertion, a satisfied cube immediately implies that every completion satisfies \(\varphi\).

Conversely, suppose every completion satisfies \(\varphi\). Let \(C_\alpha\) be the conjunction of the literals specified by \(\alpha\), restricted to the variables of \(\varphi\). Then \(C_\alpha\) is an implicant. Successively delete literals while the remaining conjunction is still an implicant. Since the conjunction is finite, this process terminates at a prime implicant whose literals are a subset of those in \(C_\alpha\). Completeness guarantees that this prime implicant is listed, and all its literals are assigned true.

For the second assertion, if every cube has an assigned false literal, every completion falsifies every cube and hence falsifies \(\varphi\). Conversely, if a cube has no assigned false literal, assign its remaining variables to satisfy its remaining literals. This is possible because the cube is consistent. The resulting partial assignment extends to a completion satisfying that cube, and therefore satisfying \(\varphi\). \(\square\)

Both conditions can be checked by scanning the explicit formula.

The verifier checks the level ranges and the permutation, then processes each type:

  • At its backup level, assign its backup vote.
  • At a delegation level, apply the lemma to the previously assigned delegate votes. Reject if neither value is forced; otherwise assign the forced value.

Finally, it computes \(\sum_t\mu_t\ell_t\) exactly and compares it with \(M\). Acceptance is equivalent to the witness satisfying the definition of consistency and the budget constraint.

For an explicit conservative bit-complexity bound, put \(B=L+\tau\lceil\log_2(\tau+1)\rceil+\tau\lceil\log_2(K+1)\rceil\). The witness has \(O(B)\) bits. Formula processing and exact rational arithmetic can be performed in \(O(B^3)\) bit operations using elementary arithmetic. In particular, a common denominator formed by multiplying the input denominators has bit length bounded by their total input length; multiplying numerators by selected levels and summing them preserves a polynomial bit-length bound.

Thus verification is polynomial in \(\tau\), \(K\), and \(L\), with \(m=1\), and the problem belongs to NP.

2. Reduction from Vertex Cover

Vertex Cover asks whether a finite simple undirected graph \(G=(V,E)\) has a set \(C\subseteq V\) of size at most \(k\) meeting every edge. This is an NP-complete problem.

We may restrict to graphs with at least one edge and no isolated vertices: deleting isolated vertices preserves the answer, and edgeless instances are trivial. Write \(n=|V|\).

Let \(Q\) be the smallest power of two strictly greater than \(n\). Then \(n<Q\leq 2n\).

Construct a society with one type for each vertex and one additional type \(d\):

\( \Theta=V\cup\{d\},\qquad \tau=n+1. \)

For each vertex \(v\), let \(N_G(v)\) denote its neighborhood and set

\( B_v=\bigl((N_G(v),\varphi_v)>1\bigr),\qquad \varphi_v=\bigwedge_{u\in N_G(v)}x_u. \)

Here the final \(1\) is the backup vote; it occupies level \(2\). Give \(d\) the direct-only ballot \(B_d=(0)\), which occupies level \(1\).

Assign masses and bound

\( \mu_v=\frac1Q\quad(v\in V),\qquad \mu_d=\frac{Q-n}{Q},\qquad M=1+\frac{k}{Q}. \)

All masses are positive dyadic rationals, and

\( \sum_{t\in\Theta}\mu_t=\frac nQ+\frac{Q-n}{Q}=1. \)

Input requirements

Every vertex has a nonempty neighborhood, and simplicity excludes self-delegation.

Each \(\varphi_v\) is contingent: setting all its variables to \(1\) satisfies it, whereas setting any one to \(0\) falsifies it. Its complete DNF consists of exactly the displayed conjunction. Indeed, every implicant must force every neighbor variable to \(1\); consequently the conjunction of all those positive literals is its unique prime implicant.

Each vertex ballot has only one delegation level, so the validity condition comparing pairs of delegation levels is vacuous. The ballot of \(d\) is also valid. Hence the construction meets every stipulated requirement, with \(m=1\) and \(K=2\).

3. Consistency is equivalent to covering the edges

For a selected certificate, define

\( C=\{v\in V:\ell_v=2\}. \)

Thus \(C\) is exactly the set of vertex types selecting their backup votes.

Lemma. This certificate is consistent if and only if \(C\) is a vertex cover of \(G\).

Proof.

First suppose the certificate is consistent, and fix a witnessing permutation.

We prove inductively that every assigned vertex vote is \(1\). A vertex selecting its backup receives \(1\). For a vertex selecting its conjunction, all previously assigned neighbor votes are \(1\), by induction. The completion assigning all still-unassigned neighbors \(1\) makes its conjunction true. Therefore its conjunction cannot force \(0\), and any legally assigned value must be \(1\). The vote of \(d\) is irrelevant because \(d\) occurs in no vertex delegation.

Moreover, such a conjunction can be assigned only after all its neighbors have been assigned. If a neighbor is still unassigned, one completion assigns every unassigned neighbor \(1\), yielding value \(1\); another assigns that neighbor \(0\), yielding value \(0\). The value is then not forced.

Now take any edge \(\{u,v\}\). If neither endpoint belongs to \(C\), both endpoints select their conjunctions. Whichever endpoint occurs first in the witnessing permutation has the other as an unassigned neighbor, contradicting the preceding paragraph. Thus \(C\) meets every edge.

Conversely, suppose \(C\) is a vertex cover. Assign the types in \(C\) first, using their backup votes \(1\), and assign \(d\) its direct vote \(0\). Then assign the remaining vertex types in any order. Every neighbor of a vertex outside \(C\) belongs to \(C\), because no edge has both endpoints outside a vertex cover. All its delegate votes are therefore already assigned \(1\), so its conjunction forces \(1\). This order witnesses consistency. \(\square\)

4. The weighted budget preserves the cover size

Every type contributes its mass times level \(1\), except that each vertex in \(C\) contributes one additional mass unit \(1/Q\). Consequently,

\( \sum_{t\in\Theta}\mu_t\ell_t=1+\frac{|C|}{Q}. \)

Since \(Q>0\), the budget condition is equivalent to

\( 1+\frac{|C|}{Q}\leq 1+\frac{k}{Q}\quad\Longleftrightarrow\quad |C|\leq k. \)

Together with the consistency lemma, this proves that the constructed society has a consistent certificate within its bound if and only if \(G\) has a vertex cover of size at most \(k\).

The equivalence uses integral level choices and the assignment of each type’s entire mass, exactly as required.

5. Size and complexity conclusion

The construction has \(\tau=n+1\), \(m=1\), and \(K=2\). Its formulas contain \(2|E|\) literal occurrences in total. Type references, masses, and the bound require \(O(\log(n+2))\) bits per relevant entry, giving total input length

\( L=O\bigl((n+|E|)\log(n+2)\bigr). \)

The reduction is therefore polynomial-time.

NP-hardness holds already for this restricted family, and Section 1 establishes polynomial-time verification for the full stipulated problem. Hence the mass-weighted consistent-certificate decision problem is NP-complete. A polynomial-time algorithm in \(\tau\), \(K\), and \(L\) would imply \(\mathrm{P}=\mathrm{NP}\).
