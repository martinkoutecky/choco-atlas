The continuous mirror question, as graded

Given projects \(O\) with costs \(w_o\), a budget \(W\), and a finite-support distribution \(\mu\) over approval-set types \(A_t\subseteq O\), where the positive masses are binary rationals summing to \(1\), find a feasible funded set \(S\subseteq O\) maximizing \(\sum_t\mu_t|S\cap A_t|\), subject to \(\sum_{o\in S}w_o\le W\).

Packaged proof task (what the prover saw — nothing else)

Let \(O\) be a set of \(m\ge1\) indivisible projects, with positive binary-rational costs \(w_o\) and a nonnegative binary-rational budget \(W\).
A society is given by its support: the list of the \(\tau\) distinct approval types \(A_t\subseteq O\) with positive binary-rational masses \(\mu_t\), where \(\sum_{t=1}^{\tau}\mu_t=1\). Here \(\tau\) is the support size, not the number of possible approval sets.
Approval sets may be empty and need not satisfy the budget constraint. Type \(t\)'s utility for a funded set \(S\) is \(|S\cap A_t|\).
Find any set \(S\subseteq O\) maximizing \(\sum_{t=1}^{\tau}\mu_t|S\cap A_t|\), subject to \(\sum_{o\in S}w_o\le W\); any maximizing set is acceptable.
Let \(L\) be the total binary input length. State running times in \(m\), \(\tau\), and \(L\).

Is this exact welfare-maximization problem solvable in polynomial time in \(m,\tau,L\), or is it NP-hard?

For explicitly listed, equally weighted voters, exact utilitarian approval maximization with arbitrary project costs has a polynomial-time algorithm using \(O(m^2n)\) arithmetic operations, where \(n\) is the number of voters. [Source](https://arxiv.org/pdf/2210.02496)
No result settling the binary-rational support-mass version was located in the literature search.

Result

The exact optimization problem is \(\mathrm{NP}\)-hard, even when \(\tau=m+1\), every nonempty approval type is a singleton, all costs and the budget are integers, and all masses are dyadic rationals. Its threshold decision version is \(\mathrm{NP}\)-complete. Consequently, a polynomial-time exact algorithm in \(m,\tau,L\) exists only if \(\mathrm{P}=\mathrm{NP}\).

Reduction from SUBSET SUM

We use the standard \(\mathrm{NP}\)-complete problem SUBSET SUM: given binary-encoded positive integers \(a_1,\ldots,a_k\) and a nonnegative integer \(B\), decide whether some index set \(I\subseteq\{1,\ldots,k\}\) satisfies \(\sum_{i\in I}a_i=B\).

Set \(C=\sum_{i=1}^k a_i\), and let \(D=2^q\) be the smallest power of two strictly greater than \(C\). Construct the following welfare instance:

  • There are \(m=k\) projects \(o_1,\ldots,o_k\), with \(w_{o_i}=a_i\) and budget \(W=B\).
  • For each \(i\), include the approval type \(A_i=\{o_i\}\), with mass \(\mu_i=a_i/D\).
  • Include one additional type \(A_{k+1}=\varnothing\), with mass \(\mu_{k+1}=(D-C)/D\).

These are exactly \(\tau=k+1\) distinct approval types. Every mass is positive because \(a_i>0\) and \(D>C\), and their sum is
\(\sum_{i=1}^{k+1}\mu_i=C/D+(D-C)/D=1\).
All masses are dyadic rationals, so the construction is valid even under that narrower interpretation of “binary-rational.”

For any funded set \(S\), its welfare is
\[ \]
\(F(S)=\sum_{t=1}^{k+1}\mu_t|S\cap A_t|=\frac{1}{D}\sum_{i:o_i\in S}a_i.\)

Thus welfare is exactly total funded cost divided by \(D\). Every feasible set satisfies \(F(S)\le B/D\).

We now prove the equivalence:

  • If the SUBSET SUM instance has a solution \(I\), then \(S=\{o_i:i\in I\}\) is feasible and has welfare \(B/D\). Since this is an upper bound for every feasible set, the optimum equals \(B/D\).
  • If the welfare optimum equals \(B/D\), then every maximizing set \(S^\star\) satisfies \(\sum_{i:o_i\in S^\star}a_i=D F(S^\star)=B\). Its project indices therefore solve SUBSET SUM.

An exact optimizer returning any maximizing set consequently decides SUBSET SUM: run it and check whether the returned set’s total cost equals \(B\). No particular tie-breaking rule is needed.

Encoding size

Let \(N\) be the SUBSET SUM input length. The integer \(C\), and hence the exponent \(q\), has magnitude bounded by \(O(N)\) bits and \(O(N)\), respectively. Each mass requires \(O(N)\) bits. Listing all approval sets as incidence vectors requires \(O(k^2)\) bits.

The resulting input therefore has length \(L=O(N^2)\), with \(m=k\) and \(\tau=k+1\). Computing and writing it takes polynomial time in \(N\). The reduction is a polynomial-time reduction, rather than an expansion into exponentially many voters.

Decision complexity and running times

Define the threshold decision problem by additionally supplying a binary-rational threshold \(K\) and asking whether a feasible set \(S\) has \(F(S)\ge K\).

A certificate is the \(m\)-bit incidence vector of \(S\). Compute its cost and the intersection counts \(|S\cap A_t|\), then compare its welfare with \(K\) using exact rational arithmetic. Products of the input denominators have bit length at most their total encoding length; the required sums likewise have polynomial bit length. Thus verification takes polynomial time. A conservative bound using schoolbook integer arithmetic is \(O((m\tau+m+\tau)L_{\mathrm{dec}}^2)\) bit operations, where \(L_{\mathrm{dec}}\) includes the threshold encoding.

The reduction above, with \(K=B/D\), proves that this decision problem is \(\mathrm{NP}\)-complete.

For completeness, an exact optimization algorithm can enumerate all \(2^m\) funded sets. After scaling costs and masses to integer common denominators, its running time is bounded by \(O((m\tau+m+\tau+m2^m)L^2)\) bit operations. The hardness result rules out a polynomial bound in \(m,\tau,L\), unless \(\mathrm{P}=\mathrm{NP}\).

Why the explicitly listed voter algorithm does not extend

For \(n\) equally weighted, explicitly listed voters, let \(c_o\) denote the integer number approving project \(o\). Maximizing normalized welfare is equivalent to maximizing \(\sum_{o\in S}c_o\). Since \(c_o\le n\), every attainable total score lies between \(0\) and \(mn\). Dynamic programming over these integer scores gives \(O(m^2n)\) arithmetic operations, as in [Proposition 34 of the cited paper](https://arxiv.org/pdf/2210.02496).

Our constructed society can be represented by \(D\) equally weighted voters: \(a_i\) approve only project \(o_i\), and \(D-C\) approve nothing. But \(D\) can be exponential in its binary encoding length. The explicitly listed voter algorithm therefore gives no polynomial bound for the compressed support-mass input.
