The continuous mirror question, as graded

Given a finite type support \(T\), rational masses \(\mu_t>0\) summing to \(1\), per-member endowments \(e_t>0\), per-member demands \(d_{t,j}\ge 0\) for rounds \(j\in[r]\), and per-capita supplies \(q_j\ge 0\), choose a common per-member allocation \(x_{t,j}\) for each type, with \(0\le x_{t,j}\le d_{t,j}\) and \(\sum_{t\in T}\mu_t x_{t,j}\le q_j\). If \(D\) is a common denominator of the masses, maximize lexicographically the nondecreasing vector containing \(D\mu_t\) copies of \(\sum_j x_{t,j}/e_t\) for each type \(t\). Can an exact optimum be computed in time polynomial in \(\tau=|T|\), \(r\), and the binary input length \(L\), without expanding the \(D\)-member population?

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a list \(\mathcal T\) of \(\tau\ge1\) types with positive binary-rational masses \(\mu_t\) summing to \(1\). Here \(\tau\) is the support size, not the number of possible types.
There are \(m=k\ge1\) rounds. Each type has a per-person endowment \(e_t>0\) and per-person demands \(d_{tb}\ge0\); each round has per-capita supply \(q_b\ge0\). All these data are binary rationals, with total input bit length \(L\); endowments need not sum to any prescribed value.
An allocation assigns the same divisible amount \(x_{tb}\) to every person of type \(t\), subject to \(0\le x_{tb}\le d_{tb}\) and \(\sum_{t\in\mathcal T}\mu_t x_{tb}\le q_b\) for every round \(b\). Its normalized per-person utility is \(r_t=\bigl(\sum_{b=1}^{m}x_{tb}\bigr)/e_t\).
Define \(F_x(z)=\sum_{t:r_t\le z}\mu_t\) and the nondecreasing quantile profile \(Q_x(p)=\inf\{z:F_x(z)>p\}\) for \(0\le p<1\). Compare two profiles on the common partition into half-open intervals determined by their cumulative masses: at the first interval where their constant values differ, the larger value is preferred. Equal profiles are tied.
The computational problem is to return an exact rational feasible allocation whose profile is maximal in this order among all feasible real allocations.

Is this problem solvable in polynomial time in \(m\), \(\tau\), and \(L\), or is it NP-hard?

For a finite list of agents with positive endowments and nonnegative fractional demands and supplies, a frugal allocation maximizing the sorted vector of endowment-normalized utilities can be computed in polynomial time.
That finite-agent result does not explicitly address a society encoded by rational masses and the mass-weighted quantile objective above.

Modeling choices made when packaging the task

  • Set m=k to identify the number of rounds with the requested resource-count parameter, and take k to be a positive integer.
  • Made the quantile ordering precise using right-continuous profiles on [0,1) and comparison on their common finite partition; equal profiles require no allocation tie-breaking.
  • Specified exact rational output while optimizing over feasible real allocations, reflecting divisible resources and binary-rational input.
  • Interpreted x_tb as a uniform per-person allocation within each type, as required by the stated type-indexed allocation.
  • Explicitly left positive endowments unnormalized, consistent with the discrete definition.

Exact polynomial-time solvability

The problem is solvable in polynomial time in \(m\), \(\tau\), and \(L\). A sequence of at most \(O(\tau^2)\) rational linear programs computes an exact optimal allocation. Rational masses need not be expanded into individual agents.

The proof has two substantive parts: progressive max–min optimization is valid for the mass-weighted quantile order, and all intermediate optimization levels have polynomial encoding length.

1. The feasible polytope

Introduce utility variables \(r_t\), and let \(P\) consist of all pairs \((x,r)\) satisfying
\[ 0\le x_{tb}\le d_{tb},\qquad \sum_{t\in\mathcal T}\mu_t x_{tb}\le q_b,\qquad e_t r_t=\sum_{b=1}^{m}x_{tb}. \]

Here and below, these displayed relations are understood as
\(0\le x_{tb}\le d_{tb}\),
\(\sum_{t\in\mathcal T}\mu_t x_{tb}\le q_b\), and
\(e_t r_t=\sum_{b=1}^{m}x_{tb}\).

The set \(P\) is a rational polytope with \(N=m\tau+\tau\) variables and a description of polynomial length. It is nonempty because the zero allocation is feasible. It is compact: the allocation variables are bounded, and, since \(e_t>0\), each utility satisfies
\(0\le r_t\le (\sum_b d_{tb})/e_t\).

We will work directly with this polytope.

2. A cancellation lemma for weighted profiles

For a utility vector \(r\), its utility distribution is the finite measure
\(\nu_r=\sum_{t\in\mathcal T}\mu_t\delta_{r_t}\),
where \(\delta_a\) denotes unit mass at \(a\).

It is useful to define the same quantile comparison for finite positive measures of any common total mass \(M>0\), using \(0\le p<M\).

Lemma 1. Let \(\nu\) and \(\eta\) be distinct finitely supported positive measures with the same total mass. Let \(a\) be the smallest point at which their atomic masses differ. Then the measure with less mass at \(a\) has the preferred quantile profile.

Consequently, adding the same finitely supported positive measure to both distributions preserves their strict profile comparison.

Proof. The two measures agree at every point below \(a\). Let their common total mass below \(a\) be \(c\), and suppose
\(\nu(\{a\})>\eta(\{a\})\).

Their quantiles agree for
\(0\le p<c+\eta(\{a\})\).
At
\(p_0=c+\eta(\{a\})\),
the quantile of \(\nu\) is still \(a\), whereas the quantile of \(\eta\) is strictly greater than \(a\). Indeed,
\(p_0<c+\nu(\{a\})\le M\),
and \(\eta\) has positive mass above \(a\), because
\(M-c-\eta(\{a\})>M-c-\nu(\{a\})\ge0\).
Thus this is the first interval of disagreement, and \(\eta\) is preferred.

Adding a common measure leaves both the first point of atomic disagreement and the sign of that disagreement unchanged. This proves cancellation. \(\square\)

In particular, when some types have identical utilities in two allocations, their common distribution can be removed before comparing the remaining types.

3. Progressive max–min optimization

We define a sequence of nonempty compact polytopes \(P_j\), sets \(S_j\) of remaining types, and levels \(h_j\).

Initially, let \(P_0=P\) and \(S_0=\mathcal T\). At stage \(j\), assuming \(S_{j-1}\ne\varnothing\), perform the following operations.

  • Solve the linear program

\(\max\lambda\), subject to
\((x,r)\in P_{j-1}\), \(\lambda\ge0\), and
\(r_t\ge\lambda\) for every \(t\in S_{j-1}\).
Denote its optimum by \(h_j\).

  • Define

\(P_j=\{(x,r)\in P_{j-1}:r_t\ge h_j\text{ for every }t\in S_{j-1}\}\).

  • For each \(t\in S_{j-1}\), solve

\(a_{jt}=\max\{r_t:(x,r)\in P_j\}\).
Define the bottleneck set
\(B_j=\{t\in S_{j-1}:a_{jt}=h_j\}\),
and let \(S_j=S_{j-1}\setminus B_j\).

The first program has an attained optimum: its feasible set is nonempty and compact, since \(\lambda\) is bounded above by the bounded utility variables. Therefore \(P_j\) is nonempty. Every auxiliary maximum is also attained.

Lemma 2: Every stage fixes at least one type

Claim. \(B_j\ne\varnothing\). Moreover, every point of \(P_j\) satisfies \(r_t=h_j\) for every \(t\in B_j\).

Proof. The equality assertion follows from the definition: throughout \(P_j\), such a utility is at least \(h_j\), and its maximum is exactly \(h_j\).

Suppose \(B_j\) were empty. For every \(t\in S_{j-1}\), choose a point \(z^{(t)}\in P_j\) whose \(t\)-utility exceeds \(h_j\). Average these finitely many points.

The average belongs to \(P_j\) by convexity. For each remaining type, every summand has utility at least \(h_j\), and its corresponding chosen summand has utility strictly greater than \(h_j\). Hence every remaining utility in the average exceeds \(h_j\).

Because there are finitely many remaining types, their minimum also exceeds \(h_j\), contradicting the definition of \(h_j\). \(\square\)

Thus the procedure terminates after some \(s\le\tau\) stages. The sets \(B_1,\ldots,B_s\) partition \(\mathcal T\), and every point of \(P_s\) has the same utility vector \(r^*\), characterized by \(r_t^*=h_j\) for \(t\in B_j\).

The levels strictly increase whenever another stage follows. To see this, average points of \(P_j\) that separately improve each type in \(S_j\). This produces a point whose utilities for all types in \(S_j\) exceed \(h_j\), so \(h_{j+1}>h_j\).

4. Correctness for the mass-weighted objective

Theorem 3. Every allocation represented by a point of \(P_s\) has a maximal quantile profile among all feasible real allocations.

Proof. Fix a point \((x^*,r^*)\in P_s\), and consider any feasible point \((y,u)\in P\).

If \((y,u)\in P_s\), then \(u=r^*\), so the profiles are identical.

Otherwise, let \(j\) be the first stage for which \((y,u)\notin P_j\). Then \((y,u)\in P_{j-1}\). Every previously fixed type has the same utility in both allocations: for \(i<j\) and \(t\in B_i\), we have \(u_t=r_t^*=h_i\).

Remove these common contributions from the two utility distributions. The remaining types are precisely \(S_{j-1}\), with the same positive total mass in both distributions.

Failure to belong to \(P_j\) means
\(\min_{t\in S_{j-1}}u_t<h_j\).
In contrast,
\(\min_{t\in S_{j-1}}r_t^*=h_j\):
all these utilities are at least \(h_j\), and the nonempty set \(B_j\) attains \(h_j\).

The remaining distribution of \(u\) therefore has a strictly smaller minimum utility than that of \(r^*\). Its profile is worse on the first interval. By Lemma 1, restoring the common distribution of previously fixed types preserves this strict comparison.

Thus every point outside \(P_s\) has a strictly worse profile, and every point inside \(P_s\) has the same profile. \(\square\)

This proof uses the given masses exactly. Positivity ensures that any remaining type contributes positive mass to its utility level.

5. Polynomial encoding lengths

A polynomial number of LP calls alone does not establish polynomial running time: the intermediate levels must also have polynomial bit length. We now prove that bound without assuming it in the preceding correctness argument.

Choose a permutation \(\pi\) of the types such that
\(r_{\pi(1)}^*\le\cdots\le r_{\pi(\tau)}^*\).
Consider the auxiliary polytope
\(P_\pi=\{(x,r)\in P:r_{\pi(1)}\le\cdots\le r_{\pi(\tau)}\}\).

Its description consists of the original constraints and \(\tau-1\) ordering inequalities. In particular, its coefficients do not involve any computed level \(h_j\).

Lemma 4: The optimal utilities occur at a vertex of \(P_\pi\)

Proof. Within \(P_\pi\), the vector
\((r_{\pi(1)}^*,\ldots,r_{\pi(\tau)}^*)\)
is lexicographically maximal.

Indeed, suppose another point had a lexicographically larger ordered vector, and let \(\ell\) be the first differing coordinate. The contributions of types \(\pi(1),\ldots,\pi(\ell-1)\) are identical. After removing them, the minimum remaining utility is the coordinate indexed by \(\ell\) in each vector, because both vectors obey the same ordering. The other point would therefore have the preferred weighted profile by Lemma 1, contradicting Theorem 3.

Now successively maximize the linear functions
\(r_{\pi(1)},\ldots,r_{\pi(\tau)}\)
over \(P_\pi\), restricting after each maximization to its optimal face. Lexicographic maximality shows that the successive optimal values are exactly the corresponding coordinates of \(r^*\).

The final set is a nonempty face of \(P_\pi\), so it contains a vertex of \(P_\pi\). That vertex has utility vector \(r^*\). \(\square\)

The permutation is used only to prove the encoding bound; the algorithm does not enumerate permutations.

Clear denominators separately in each constraint of \(P_\pi\). All resulting integer coefficients and right-hand sides have bit length bounded by some
\(H=\operatorname{poly}(m,\tau,L)\).
This follows because each row contains polynomially many input rationals, and multiplying their denominators adds their encoding lengths.

A vertex is determined by \(N\) linearly independent active constraints. Cramer’s rule expresses each coordinate as a ratio of determinants of integer \(N\times N\) matrices. If every entry has absolute value at most \(2^H\), Hadamard’s inequality gives the bound
\(|\det A|\le N^{N/2}2^{NH}\),
also for the numerator matrices.

Thus every vertex coordinate has numerator and denominator bit lengths
\(O(NH+N\log N)\),
which is polynomial in \(m,\tau,L\). Lemma 4 therefore gives this bound for every coordinate of \(r^*\).

Finally, every computed level \(h_j\) equals \(r_t^*\) for some \(t\in B_j\). Hence all intermediate levels have polynomial bit length.

6. Running time and exact output

We use the standard rational linear-programming theorem: feasibility and optimization for explicitly given rational linear constraints can be solved in time polynomial in their binary encoding length, returning an exact rational feasible point or optimum when appropriate. This includes lower-dimensional feasible sets. See [MIT’s linear-programming algorithm notes](https://courses.csail.mit.edu/6.854/21/Notes/n14-LP_algorithms.html).

The hypotheses hold here:

  • Every optimization program is nonempty and has an attained finite optimum.
  • There are at most \(\tau\) stages.
  • The number of auxiliary programs is at most

\(\tau+(\tau-1)+\cdots+1=\tau(\tau+1)/2\).

  • Each program has at most \(N+1\) variables and polynomially many constraints.
  • Its coefficients consist of input data and previously computed levels, all of polynomial bit length by Section 5.

After the final stage, one additional rational feasibility computation on \(P_s\) returns an exact rational allocation \(x^*\). Theorem 3 proves its profile maximal even against feasible allocations with arbitrary real coordinates.

Thus the requested problem is polynomial-time solvable. The argument works directly on the support of size \(\tau\), without expanding masses into a potentially enormous finite population, and requires no normalization of the endowments.
