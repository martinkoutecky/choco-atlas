The continuous mirror question, as graded

Given \(n\) alternatives and a finite-support distribution \(\mu\) over strict rankings, is there a linear order \(O\) such that every ranking \(t\) with \(\mu_t>0\) is single-peaked with respect to \(O\)? If so, output such an axis.

Packaged proof task (what the prover saw — nothing else)

Let \(X\) contain \(m\geq 3\) alternatives. Types are strict rankings of all alternatives in \(X\); single-peakedness has its standard meaning with respect to a linear axis on \(X\).
A society is given by its support: the list of the \(\tau\) types with positive mass, each mass a binary rational, with \(\sum_t\mu_t=1\). Here \(\tau\) is the support size, not the number of possible rankings. Let \(L\) be the total binary input length; state running times in \(m,\tau,L\).
Determine whether there is a linear order \(O\) on \(X\) such that every supported ranking is single-peaked with respect to \(O\), and output such an axis when one exists.

Is this problem solvable in polynomial time in \(m,\tau,L\), including constructing a compatible axis, or is its decision version \(\mathrm{NP}\)-hard?

For a discrete profile of \(v\) voters and \(m\) alternatives, consistency can be decided and a compatible axis constructed in \(O(mv)\) time: Escoffier, Lang, and Öztürk, [Single-peaked consistency and its complexity](https://doi.org/10.3233/978-1-58603-891-5-366).

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Result

The problem is polynomial-time solvable, including construction of a compatible axis. The recognition algorithm takes \(O(m\tau)\) time after extracting the rankings; allowing for reading the entire binary input gives \(O(L+m\tau)\) time under the usual word-RAM convention.

1. Reduction to a discrete profile

Write the supported strict rankings as \(r_1,\ldots,r_\tau\), with masses \(\mu_1,\ldots,\mu_\tau>0\). For a ranking \(r\), let \(\mathcal A(r)\) denote the set of linear axes with respect to which \(r\) is single-peaked.

The society’s set of compatible axes is exactly
\[ \mathcal A_{\mathrm{society}}=\bigcap_{t=1}^{\tau}\mathcal A(r_t). \]
Indeed, an axis belongs to this intersection if and only if every supported ranking is single-peaked on it, which is precisely the requirement in the question.

Construct a discrete profile \(P=(r_1,\ldots,r_\tau)\) containing one voter for each supported type. Its compatible axes satisfy
\[ \mathcal A(P)=\bigcap_{t=1}^{\tau}\mathcal A(r_t)=\mathcal A_{\mathrm{society}}. \]
Thus the reduction preserves all compatible axes, as well as the decision answer. The numerical masses do not enter this equality.

2. Algorithm and correctness

Use the stated theorem of Escoffier, Lang, and Öztürk: for an explicitly listed profile of \(v\) strict rankings of \(m\) alternatives, an algorithm decides single-peaked consistency and constructs a compatible axis when one exists in \(O(mv)\) time. Both correctness and construction are established in their [paper, Section 3, Propositions 1–2](https://www.lamsade.dauphine.fr/~lang/papers/elo-ecai08.pdf).

Apply it as follows:

  • Extract the \(\tau\) supported rankings and form \(P\).
  • Run the discrete-profile algorithm with \(v=\tau\).
  • If it rejects, report that no compatible axis exists. Otherwise, output its axis.

The theorem’s hypotheses hold: \(P\) is explicitly listed, every ranking is strict and complete, and every voter ranks the same set \(X\).

If the algorithm outputs an axis, the equality \(\mathcal A(P)=\mathcal A_{\mathrm{society}}\) proves that it satisfies the original requirement. If it rejects, that equality proves that no axis satisfies the original requirement. This establishes correctness in both directions.

3. Running time and binary masses

Reading the input costs \(O(L)\), and recognition and construction cost \(O(m\tau)\). Consequently, the total word-RAM running time is \(O(L+m\tau)\).

This also yields polynomial bit complexity: the recognition algorithm uses indices, counters, and rank positions of polynomially bounded size, so its word operations admit polynomial-cost bit simulation. The masses are promised valid and can be skipped; no rational arithmetic or expansion into voters is needed.

In particular, clearing denominators and replicating rankings according to their masses would be unnecessary and could produce exponentially many voters.

The decision problem therefore belongs to \(\mathrm P\). It could be \(\mathrm{NP}\)-hard under polynomial-time many-one reductions only if \(\mathrm P=\mathrm{NP}\).
