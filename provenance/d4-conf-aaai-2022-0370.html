The continuous mirror question, as graded

Given an explicit finite support \(\{(\Delta_t,g_t)\}_{t=1}^{\tau}\) of claimant-case types with rational masses \(\mu_t\ge 0\) summing to \(1\), compute \(M=\sum_{t=1}^{\tau}\mu_t\,\mathbf{1}[\mathrm{PCA}_{\mathrm{sst}}(\Delta_t,g_t)]\), the population share whose queried literal is possibly credulously accepted under semi-stable semantics; equivalently, for rational \(q\in[0,1]\), decide whether \(M\ge q\). Each \(\Delta_t\) is an explicitly represented incomplete argumentation framework, and completions remain internal possibilities within each type.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: the list of \(\tau\) claimant-case types \((\Delta_t,g_t)\) with positive binary rational masses \(\mu_t\), where \(\sum_t\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types.
Each explicitly represented incomplete argumentation framework is \(\Delta_t=\langle A_t,B_t,R_t,T_t\rangle\): disjoint certain and uncertain argument sets \(A_t,B_t\), and disjoint certain and uncertain attack sets \(R_t,T_t\subseteq(A_t\cup B_t)^2\). The query \(g_t\) is an argument in \(A_t\cup B_t\) or its negation.
A completion is \(\Lambda=\langle A',R'\rangle\) with \(A_t\subseteq A'\subseteq A_t\cup B_t\) and \(R_t\cap(A'\times A')\subseteq R'\subseteq(R_t\cup T_t)\cap(A'\times A')\).
Use standard Dung semi-stable semantics. For an extension \(E\) of a completion, its fulfillment is \(F_t(E,\Lambda)=E\cup\{\neg a:\exists b\in E,\ (b,a)\in R'\}\cup\{\neg a:a\in B_t\setminus A'\}\).
Define \(\mathrm{PCA}_{\mathrm{sst}}(\Delta_t,g_t)\) to hold precisely when some completion \(\Lambda\) has a semi-stable extension \(E\) with \(g_t\in F_t(E,\Lambda)\). Completions are internal possibilities, with no probabilities assigned to them.
Given also a binary rational \(q\in[0,1]\), decide whether \(M=\sum_{t=1}^{\tau}\mu_t\mathbf{1}[\mathrm{PCA}_{\mathrm{sst}}(\Delta_t,g_t)]\ge q\). Let \(m=\max_t|A_t\cup B_t|\) and \(L\) be the total input bit length; state running times in \(m,\tau,L\).

Is this population-share threshold problem solvable in polynomial time in \(m,\tau,L\), or is it NP-hard?

For a single incomplete argumentation framework and queried literal, possible credulous acceptance under semi-stable semantics is \(\Sigma_2^p\)-complete ([Alfano et al.](https://www.researchgate.net/publication/357016535_Incomplete_Argumentation_Frameworks_Properties_and_Complexity_Technical_Report)). No result specifically treating the stated distribution over claimant-case types was located.

Result

The population-share threshold problem is \(\Sigma_2^p\)-complete under polynomial-time many-one reductions, and therefore NP-hard. Consequently, a polynomial-time algorithm in \(m,\tau,L\) would imply \(\mathrm P=\mathrm{NP}\).

The hardness already holds for \(\tau=1\). The upper bound below addresses arbitrary explicitly listed supports and binary rational masses.

1. Semi-stable extension verification

Fix a completion \(\Lambda=\langle V,H\rangle\). For \(E\subseteq V\), define its attacked set and range by
\(E_H^+=\{a\in V:\exists b\in E,\ (b,a)\in H\}\) and
\(\rho_\Lambda(E)=E\cup E_H^+\).

A set \(E\) is conflict-free if no attack has both endpoints in \(E\). It defends \(a\in V\) if every attacker of \(a\) is attacked by some member of \(E\). It is complete if it is conflict-free, defends every member of \(E\), and contains every argument it defends.

These conditions can be checked in \(O((m+1)^3)\) time by directly examining arguments and attacks.

Under standard Dung semi-stable semantics, \(E\) is semi-stable precisely when it is complete and no complete extension \(D\) satisfies
\(\rho_\Lambda(E)\subsetneq\rho_\Lambda(D)\).
The maximality is by set inclusion, not by cardinality.

Thus, after checking completeness of \(E\), failure of semi-stability has a polynomial-size certificate: a complete extension \(D\) with strictly larger range.

The additional conditions in the task are also polynomial-time checkable:

  • Whether \(\Lambda\) satisfies the stipulated completion constraints.
  • Whether a positive query \(a\) belongs to \(E\).
  • Whether a negative query \(\neg a\) is fulfilled because \(a\in E_H^+\) or \(a\in B_t\setminus V\).

This verification uses exactly the task’s fulfillment definition, including negations of omitted uncertain arguments.

2. Exact rational arithmetic is polynomial-time

Write \(\mu_t=a_t/b_t\) and \(q=c/d\), with positive denominators. Define the common denominator
\(K=d\prod_{t=1}^{\tau}b_t\),
and the integer weights
\(w_t=a_t(K/b_t)\) and \(h=c(K/d)\).

Then, for every subset \(S\subseteq\{1,\ldots,\tau\}\),
\(\sum_{t\in S}\mu_t\ge q\) holds exactly when
\(\sum_{t\in S}w_t\ge h\).

The bit length of \(K\) is \(O(L)\), because the denominator encodings are part of the total input. Moreover, the hypotheses \(\sum_t\mu_t=1\) and \(q\in[0,1]\) imply
\(\sum_t w_t=K\) and \(0\le h\le K\).
All these integers therefore have \(O(L)\) bits.

Using ordinary integer multiplication and division, the weights can be computed in \(O(L^3)\) bit operations. Subsequent subset-weight comparisons are polynomial-time. No numerical approximation is required.

3. Membership in \(\Sigma_2^p\)

Let
\(Y=\{t:\mathrm{PCA}_{\mathrm{sst}}(\Delta_t,g_t)\}\).
Because every mass is positive,
\(\sum_{t\in Y}\mu_t\ge q\)
is equivalent to the existence of a subset \(S\subseteq Y\) satisfying
\(\sum_{t\in S}\mu_t\ge q\).

Indeed, the forward implication uses \(S=Y\); the reverse implication follows from positivity of the masses.

An existential certificate consists of:

  • A subset \(S\) whose total mass reaches \(q\).
  • For every \(t\in S\), a completion \(\Lambda_t\) and a set \(E_t\) claimed to be a semi-stable extension fulfilling \(g_t\).

The deterministic checks verify the weight threshold, each completion, completeness of each \(E_t\), and fulfillment of each query.

The remaining condition is universal: for every selected index \(t\) and every \(D\subseteq V_t\), either \(D\) is not complete in \(\Lambda_t\), or
\(\rho_{\Lambda_t}(E_t)\not\subsetneq\rho_{\Lambda_t}(D)\).

This is a polynomial-time predicate over the existential certificate and a universally quantified pair consisting of an index and an argument subset. The existential certificate has length
\(O(\tau(m^2+m+1))\),
and the universal pair needs
\(O(m+\log(\tau+1))\)
bits. Both lengths are polynomial in \(L\), since the frameworks and support are explicitly represented.

Using the existential-universal characterization of \(\Sigma_2^p\), this proves membership. For completeness, the certificate equivalence is exact:

  • If the certificate passes every universal check, all selected types satisfy possible credulous acceptance. Their mass reaches \(q\), so \(M\ge q\).
  • If \(M\ge q\), select \(S=Y\) and choose one witnessing completion and extension for each selected type. Every universal check then passes.

For \(q=0\), the empty subset supplies a certificate, as expected.

4. Hardness

The supplied single-framework result states that possible credulous acceptance under semi-stable semantics is \(\Sigma_2^p\)-complete. This is also stated in Theorem 6 of [Alfano et al.’s technical report](https://www.researchgate.net/publication/357016535_Incomplete_Argumentation_Frameworks_Properties_and_Complexity_Technical_Report).

Given an instance \((\Delta,g)\) of that problem, construct the society
\(\tau=1\), \((\Delta_1,g_1)=(\Delta,g)\), \(\mu_1=1\), and \(q=1/2\).

This is a valid support with a positive binary rational mass summing to one. Its population share is
\(M=\mathbf 1[\mathrm{PCA}_{\mathrm{sst}}(\Delta,g)]\).
Therefore,
\(M\ge 1/2\) if and only if
\(\mathrm{PCA}_{\mathrm{sst}}(\Delta,g)\).

The reduction copies the framework and adds only constant-size data. It is polynomial-time and establishes \(\Sigma_2^p\)-hardness.

Hardness also persists with two distinct support types and equal masses. Add a fresh certain argument \(z\) whose only attack is \((z,z)\), and query \(z\). Its only conflict-free set is empty; that set is complete and semi-stable, so the query is never fulfilled. Giving this type and the original type mass \(1/2\), with \(q=1/2\), again makes the threshold equivalent to the original acceptance question.

Together with Section 3, this proves \(\Sigma_2^p\)-completeness.

5. An explicit deterministic running time

A direct exact algorithm also gives a useful parameter bound.

For type \(t\), put \(n_t=|A_t\cup B_t|\), \(b_t=|B_t|\), and \(u_t=|T_t|\). There are at most
\(2^{b_t+u_t}\)
completions: choose the uncertain arguments, then choose the uncertain attacks whose endpoints are present. Since \(b_t\le m\) and \(u_t\le m^2\), this is at most \(2^{m+m^2}\).

For each completion:

  • Enumerate all argument subsets and retain the complete extensions.
  • Record which ranges occur.
  • Identify the inclusion-maximal occurring ranges.
  • Check whether any complete extension with such a range fulfills the query.

Step 3 can be implemented without comparing every pair of extensions. Index subsets by bit masks and let \(H(U)\) indicate whether \(U\) occurs as a complete-extension range. Compute
\(C(S)=\sum_{U\supseteq S}H(U)\)
using the subset dynamic program that starts with \(C=H\) and, for each argument \(i\), performs
\(C(S)\leftarrow C(S)+C(S\cup\{i\})\)
for every \(S\) omitting \(i\).

After processing the arguments, the recurrence sums exactly over all supersets. An occurring range \(S\) is maximal precisely when \(C(S)=1\): its own occurrence contributes one, and any strict superset would contribute another. The counters have at most \(m+1\) bits.

Consequently, each completion takes
\(O(2^m(m+1)^3)\)
bit operations. Computing all acceptance indicators and then comparing their exact weighted sum with \(q\) takes
\(O\!\left(\tau\,2^{m^2+2m}(m+1)^3+L^3\right)\)
bit operations.

Thus, fixed \(m\) yields polynomial time in \(\tau,L\); unrestricted \(m\) gives the \(\Sigma_2^p\)-complete problem proved above. Throughout, completions are existential possibilities, with no probabilities assigned to them.
