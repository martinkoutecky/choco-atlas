The continuous mirror question, as graded

Given schools \(C\), a finite set of complete student types \(T\), rational masses \(\mu_t\) summing to \(1\), per-capita capacities \(q_c\), and an added-capacity budget \(b\), choose \(a_c\geq 0\) and assignment masses \(x_{tc}\geq 0\) (including \(x_{t,\emptyset}\)) minimizing \(\sum_{t,c} r_{tc}x_{tc}\), subject to \(\sum_c x_{tc}=\mu_t\), \(\sum_t x_{tc}\leq q_c+a_c\), and \(\sum_c a_c\leq b\). For each type \(t\) and school \(c\), require \(\min\{L_{tc},A_{tc}\}=0\), where \(L_{tc}=\sum_{d:\,c\succ_t d}x_{td}\) and \(A_{tc}=q_c+a_c-\sum_u x_{uc}+\sum_{u:\,t\succ_c u}x_{uc}\). Determine the optimal capacity vector and stable assignment, and investigate algorithms parameterized by \(m\), \(|T|\), and the input bit length.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a list \(T\) of \(\tau\) types with positive binary-rational masses \(\mu_t\), summing to \(1\). Here \(\tau\) is the support size, not the number of possible types. Let \(C\) contain \(m\geq1\) schools.
Each type has a strict preference order \(\succ_t\) over \(C\cup\{\emptyset\}\); only schools above \(\emptyset\) are acceptable. Each school has an input strict priority order \(\succ_c\) over types; students within a type have equal priority, with no further tie-breaking.
Inputs include nonnegative binary-rational per-capita capacities \(q_c\), budget \(b\), and a binary-rational threshold \(K\). For acceptable schools, \(r_{tc}\) is their position in the type's preference list; \(r_{t\emptyset}\in\mathbb{Q}\) is an input penalty, possibly negative. Let \(L\) be the total input bit length.
Choose real masses \(x_{td}\geq0\) and expansions \(a_c\geq0\), with \(x_{tc}=0\) for unacceptable schools, \(\sum_{d\in C\cup\{\emptyset\}}x_{td}=\mu_t\), \(\sum_{t\in T}x_{tc}\leq q_c+a_c\), and \(\sum_{c\in C}a_c\leq b\). The outside option has unrestricted capacity and receives no expansion.
For every acceptable pair \((t,c)\), define \(L_{tc}=\sum_{d\in C\cup\{\emptyset\}:c\succ_t d}x_{td}\) and \(A_{tc}=q_c+a_c-\sum_{u\in T}x_{uc}+\sum_{u\in T:t\succ_c u}x_{uc}\). An assignment is stable precisely when \(\min\{L_{tc},A_{tc}\}=0\) for every such pair.
The decision problem asks whether a feasible stable assignment and expansion have \(\sum_{t\in T}\sum_{d\in C\cup\{\emptyset\}}r_{td}x_{td}\leq K\).

Is this continuous capacity-expansion decision problem in P, with running time polynomial in \(m,\tau,L\), or is it NP-hard?

Result

The problem is \(\mathrm{NP}\)-complete. Hardness holds even when every type accepts at most one school, all schools have the same strict priority order, all initial capacities are zero, and all outside penalties are positive.

The proof below treats masses and expansions as real variables throughout.

Reduction from SUBSET SUM

Use the standard \(\mathrm{NP}\)-complete positive-integer SUBSET SUM problem: given binary-encoded positive integers \(w_1,\ldots,w_n\) and an integer \(B\), determine whether some subset sums to \(B\). This is the classical integer subset-selection problem established in [Karp’s paper](https://www.cs.umd.edu/~gasarch/BLOGPAPERS/Karp.pdf).

Write \(S=\sum_{i=1}^n w_i\). We may restrict to \(n\geq1\) and \(1\leq B\leq S\): excluded cases are immediately decidable and can be mapped to fixed yes or no instances satisfying these conditions.

Choose a power of two \(D>2S\) with \(D\leq4S\), and put \(h_i=w_i/D\).

Create schools \(c_1,\ldots,c_n\), two types \(H_i,R_i\) for each index, and one additional type \(o\):

| Type | Mass | Only acceptable school | Outside penalty |
|---|---|---|---|
| \(H_i\) | \(h_i\) | \(c_i\) | \(2\) |
| \(R_i\) | \(h_i\) | \(c_i\) | \(4\) |
| \(o\) | \(1-2S/D\) | None | \(1\) |

For \(H_i\) and \(R_i\), place \(c_i\) first, the outside option second, and all other schools below the outside option in any strict order. Thus their acceptable-school rank is \(1\). Type \(o\) ranks the outside option first.

Give every school the same strict priority order:

\(H_1\succ\cdots\succ H_n\succ R_1\succ\cdots\succ R_n\succ o.\)

Set every initial capacity to zero and set

\(b=\dfrac{2B}{D}.\)

The objective value when everyone is outside is

\(F_0=\sum_i(2h_i+4h_i)+(1-2S/D)=1+\dfrac{4S}{D}.\)

Choose the threshold

\(K=F_0-2b=1+\dfrac{4(S-B)}{D}.\)

All masses are positive and sum to one. Every numerical input is dyadic rational. The construction has \(m=n\), \(\tau=2n+1\), and polynomial encoding length: \(D\) has \(O(\log S)\) bits, and the preference and priority lists have polynomial size.

Stability forces a sharp objective bound

Consider any feasible stable assignment in the constructed instance. Define

\(s_i=x_{H_i c_i},\qquad z_i=x_{R_i c_i},\qquad a_i=a_{c_i}.\)

No other type accepts \(c_i\), so feasibility gives

\(0\leq s_i,z_i\leq h_i,\qquad s_i+z_i\leq a_i.\)

For the acceptable pair \((H_i,c_i)\), the quantities in the question are exactly

\(L_{H_i c_i}=h_i-s_i,\qquad A_{H_i c_i}=a_i-s_i.\)

Indeed, the only potentially assigned lower-priority type at this school is \(R_i\); its mass cancels from the definition of \(A_{H_i c_i}\).

If \(z_i>0\), capacity feasibility implies

\(A_{H_i c_i}=a_i-s_i\geq z_i>0.\)

Stability therefore forces \(L_{H_i c_i}=0\), hence \(s_i=h_i\). Consequently, every stable assignment satisfies

\(z_i\leq s_i.\)

The objective value is

\(F=F_0-\sum_i(s_i+3z_i),\)

because assigning one unit of \(H_i\) saves one unit of cost, while assigning one unit of \(R_i\) saves three.

Using \(z_i\leq s_i\), capacity feasibility, and the budget constraint gives

\(\sum_i(s_i+3z_i)\leq2\sum_i(s_i+z_i)\leq2\sum_i a_i\leq2b.\)

Thus every feasible stable assignment satisfies \(F\geq F_0-2b=K\).

Moreover, if \(F\leq K\), equality must hold throughout this chain. In particular,

\(0=2\sum_i(s_i+z_i)-\sum_i(s_i+3z_i)=\sum_i(s_i-z_i).\)

Each summand is nonnegative, so \(s_i=z_i\) for every index. If this common value is positive, the stability implication proved above forces it to equal \(h_i\). Therefore,

\((s_i,z_i)\in\{(0,0),(h_i,h_i)\}\)

for every index. This conclusion follows from stability and the tight threshold, without any integrality assumption.

Equivalence of the two decision instances

A continuous yes instance yields a subset sum. Suppose a feasible stable assignment has \(F\leq K\), and let

\(I=\{i:s_i=z_i=h_i\}.\)

Equality in the preceding chain also gives \(\sum_i(s_i+z_i)=b\). Hence

\(\sum_{i\in I}w_i=D\sum_i s_i=\dfrac{D}{2}\sum_i(s_i+z_i)=\dfrac{Db}{2}=B.\)

Thus \(I\) solves SUBSET SUM.

A subset sum yields a continuous yes instance. Conversely, suppose \(\sum_{i\in I}w_i=B\). For every selected index, assign both types entirely to their school and set \(a_i=2h_i\). For every unselected index, leave both types entirely outside and set \(a_i=0\). Leave type \(o\) outside.

Capacity feasibility holds, and total expansion is

\(\sum_i a_i=2\sum_{i\in I}h_i=\dfrac{2B}{D}=b.\)

For a selected school, both acceptable pairs have \(L_{tc}=0\). For an unselected school, capacity and assignments are zero, so both acceptable pairs have \(A_{tc}=0\). Type \(o\) has no acceptable pairs. The assignment is therefore stable.

Its objective value is

\(F=F_0-4\sum_{i\in I}h_i=F_0-\dfrac{4B}{D}=K.\)

This proves the reduction and establishes \(\mathrm{NP}\)-hardness.

Membership in \(\mathrm{NP}\)

For any feasible assignment in the general problem, \(L_{tc}\geq0\), since it is a sum of nonnegative masses. Also,

\(A_{tc}=\left(q_c+a_c-\sum_u x_{uc}\right)+\sum_{u:t\succ_c u}x_{uc}\geq0,\)

by capacity feasibility. Consequently, stability is equivalent to the disjunction

\(L_{tc}=0\quad\text{or}\quad A_{tc}=0\)

for every acceptable pair.

A certificate chooses one of these two equalities for each acceptable pair, using at most \(m\tau\) bits. A verifier adds the chosen equalities to all feasibility constraints and the objective threshold. The resulting system is linear, has polynomially many variables and constraints, and has rational coefficients of polynomial encoding length.

The standard polynomial-time theorem for rational linear-programming feasibility therefore supplies a polynomial-time verifier. An original stable solution determines an accepted branch choice; conversely, every feasible chosen branch satisfies all stability disjunctions.

Thus the problem belongs to \(\mathrm{NP}\), completing the proof of \(\mathrm{NP}\)-completeness. A running time polynomial in \(m,\tau,L\) would imply \(\mathrm{P}=\mathrm{NP}\).
