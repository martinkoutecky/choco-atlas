The continuous mirror question, as graded

Given a finite type set \(\mathcal T=D\mathbin{\dot\cup}S\), positive rational masses \(\mu_t\) summing to \(1\), and for each \(t\in D\) eligible target types \(N(t)\) with positive integer rank costs \(c(t,u)\), assume every delegating type can reach a casting type. Each member of type \(t\) delegates to every member of each target type \(u\in N(t)\) at cost \(c(t,u)\). Compute the exact aggregate assignment \(x_{t,s}=\mu_t R_{t,s}\), where \(R_{t,s}\) is the limiting probability of absorption in casting type \(s\) for the type-level chain with transition probabilities \(P^\varepsilon_{t,u}=\mu_u\varepsilon^{c(t,u)}/\sum_{w\in N(t)}\mu_w\varepsilon^{c(t,w)}\) as \(\varepsilon\to0\). Equivalently, compute the type-level aggregate outcome obtained by averaging assignments uniformly over minimum-cost maximum-cardinality branchings in any integral finite expansion of the masses.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a list of \(\tau\) types \(\mathcal T=D\mathbin{\dot\cup}S\), each with positive binary rational mass \(\mu_t\), where \(\sum_{t\in\mathcal T}\mu_t=1\); \(\tau\) is the support size, not the number of possible types.
Casting types \(S\neq\varnothing\) have no delegation edges. Each delegating type \(t\in D\) has an explicitly listed nonempty target set \(N(t)\subseteq\mathcal T\), and every delegating type reaches a casting type. Each eligible edge has a binary-encoded cost \(c(t,u)\in\mathbb Z_{>0}\); equal costs are allowed. Targets may include the source type.
Let \(m=\sum_{t\in D}|N(t)|\) and let \(L\) be the total input bit length. For \(0<\varepsilon\leq1\), define \(P^\varepsilon_{t,u}=\mu_u\varepsilon^{c(t,u)}/\sum_{w\in N(t)}\mu_w\varepsilon^{c(t,w)}\) on eligible edges, zero on other edges from delegating types, and \(P^\varepsilon_{s,s}=1\) for casting types.
Let \(h^\varepsilon_{t,s}\) be the probability of eventual absorption at \(s\) starting at \(t\). The required output is the exact rational matrix \(x_{t,s}=\mu_t\lim_{\varepsilon\to0^+}h^\varepsilon_{t,s}\), indexed by \(D\times S\).

Can this matrix be computed exactly in time polynomial in \(m,\tau,L\), or is its computation \(\mathrm{NP}\)-hard?

For finite explicitly listed voters, uniform averaging over minimum-cost maximum-cardinality branchings is computable in polynomial time. [Utke and Schmidt-Kraepelin](https://arxiv.org/html/2307.01174v2) also describe an algorithmic extension for limiting absorption probabilities with positive-coefficient rational transition functions, encompassing the transition family above; consequently, this target cannot presently be presented as an established open question.

Modeling choices made when packaging the task

  • Defined m as the number of eligible type-level edges because this problem has no candidate parameter; defined L as total input bit length and encoded costs in binary.
  • Specified casting types as absorbing states and unspecified delegating transitions as zero.
  • Specified the output indices as D times S, matching the discrete fractional assignment; casting types retain their own masses.
  • Allowed equal costs, as the discrete definition permits arbitrary positive integer edge costs rather than requiring strict rankings.
  • Allowed within-type delegation, retaining the graded question's unrestricted target sets, and used its explicit type-level chain as the definition without requiring a finite expansion.

Result

The matrix is exactly computable in time polynomial in \(m,\tau,L\), including when costs are encoded in binary.

The extension in [Utke and Schmidt-Kraepelin, Section 6](https://arxiv.org/html/2307.01174v2#S6) covers positive-coefficient rational transition functions of the stated form. Below is a self-contained proof using state elimination, with an explicit bit-complexity argument.

1. Remove normalization and self-loops

If \(D=\varnothing\), the required matrix is empty. Henceforth assume \(D\neq\varnothing\).

Write each mass as \(\mu_u=p_u/d_u\), and define

\(B=\prod_{u\in\mathcal T}d_u,\qquad a_u=B\mu_u.\)

Every \(a_u\) is a positive integer satisfying \(a_u\leq B\), and \(\log B=O(L)\). For distinct types \(i,j\), define

\(w_{ij}(\varepsilon)=a_j\varepsilon^{c(i,j)}\)

when \(i\in D\) and \(j\in N(i)\), and define \(w_{ij}=0\) otherwise. Self-loops are omitted.

Fix \(s\in S\). The first-step equations for absorption probabilities, multiplied by the original row normalizers and then by \(B\), give

\(\displaystyle \left(\sum_{j\neq i}w_{ij}\right)h^\varepsilon_{i,s} =\sum_{j\neq i}w_{ij}h^\varepsilon_{j,s},\qquad i\in D,\)

with boundary values \(h^\varepsilon_{r,s}=\mathbf 1_{\{r=s\}}\) for \(r\in S\). The self-loop term cancels from both sides.

For completeness, absorption occurs almost surely for every fixed \(\varepsilon>0\). Choose a simple path from each delegating type to \(S\). Each path has positive transition probability and length at most \(\tau-1\). The minimum of these finitely many path probabilities is positive. Consequently, survival probabilities decay geometrically over blocks of \(\tau\) steps.

Thus it suffices to solve the harmonic equations above and take their limits.

2. Elimination with nonnegative arithmetic

Suppose the current remaining vertex set is \(V\), containing every casting type. Write

\(\displaystyle q_i=\sum_{j\in V\setminus\{i\}}w_{ij}\)

for each remaining delegating type \(i\).

To eliminate a delegating type \(k\), set \(V'=V\setminus\{k\}\) and, for distinct \(i,j\in V'\) with \(i\in D\), replace the rates by

\(\displaystyle w'_{ij}=w_{ij}+\frac{w_{ik}w_{kj}}{q_k}.\)

All quantities here are rational functions of \(\varepsilon\). A missing rate means zero.

The denominator is always positive

Initially every delegating type reaches \(S\). This remains true after elimination: take a simple path from a remaining vertex to \(S\). If it passes through \(k\), replace the segment \(i\to k\to j\) by \(i\to j\). The update creates a positive rate on that replacement edge.

Inductively, every remaining delegating vertex has a positive outgoing rate. Therefore \(q_k(\varepsilon)>0\) for every \(\varepsilon>0\).

Elimination preserves the harmonic equations

The equation at \(k\) gives

\(\displaystyle h_k=\frac{1}{q_k}\sum_{j\in V\setminus\{k\}}w_{kj}h_j.\)

Substitution into the equation at another delegating vertex \(i\) yields

\(\displaystyle \left(q_i-\frac{w_{ik}w_{ki}}{q_k}\right)h_i =\sum_{j\in V'\setminus\{i\}} \left(w_{ij}+\frac{w_{ik}w_{kj}}{q_k}\right)h_j.\)

The new diagonal coefficient is exactly the sum of the new outgoing rates, because

\(\displaystyle \sum_{j\in V'\setminus\{i\}}w'_{ij} =q_i-w_{ik}+\frac{w_{ik}}{q_k}(q_k-w_{ki}) =q_i-\frac{w_{ik}w_{ki}}{q_k}. \)

Hence the reduced equations retain the same form. Importantly, the algorithm computes this diagonal coefficient by summing the new rates; it never performs the subtraction appearing in the verification.

Now fix a starting type \(t\in D\), and eliminate every vertex of \(D\setminus\{t\}\). Only \(t\) and the casting types remain. If \(W_{t,s}\) denotes the final rate from \(t\) to \(s\), then the remaining harmonic equation gives the exact identity

\(\displaystyle h^\varepsilon_{t,s} =\frac{W_{t,s}(\varepsilon)} {\sum_{r\in S}W_{t,r}(\varepsilon)}. \)

3. Compute only leading terms

For a nonzero function encountered during elimination, store a pair \((v,b)\), meaning

\(\displaystyle f(\varepsilon)=b\varepsilon^v(1+o(1)),\qquad b\in\mathbb Q_{>0},\quad v\in\mathbb Z.\)

Store zero separately.

Initially an eligible non-self rate has pair \((c(i,j),a_j)\). Every subsequent operation is addition, multiplication, or division by a positive quantity. Thus leading pairs can be updated exactly:

  • Multiplication sends \((v,b),(z,d)\) to \((v+z,bd)\).
  • Division sends them to \((v-z,b/d)\).
  • Addition keeps the pair with smaller exponent; if the exponents agree, it produces \((v,b+d)\).

These rules follow directly from the displayed asymptotic expansions. Positive leading coefficients cannot cancel, so no higher-order terms are needed.

After eliminating all delegating vertices except \(t\), let the nonzero final rates have pairs \((v_{t,s},b_{t,s})\). Define

\(\displaystyle v_*=\min_{s:W_{t,s}\neq0}v_{t,s}, \qquad b_*=\sum_{s:v_{t,s}=v_*}b_{t,s}. \)

The minimum exists because \(t\) still reaches \(S\). The required limit is

\(\displaystyle \lim_{\varepsilon\to0^+}h^\varepsilon_{t,s} = \begin{cases} b_{t,s}/b_*,&W_{t,s}\neq0\text{ and }v_{t,s}=v_*,\\ 0,&\text{otherwise}. \end{cases} \)

Multiplication by \(\mu_t\) gives \(x_{t,s}\).

This proves correctness and existence of every required limit. It remains to bound the sizes of the exact numbers manipulated.

4. Polynomial bit complexity

Let \(C=\max_{(i,j)}c(i,j)\). Although \(C\) may be exponentially large, its binary length is at most \(L\).

Define the original \(\tau\times\tau\) polynomial Laplacian \(A(\varepsilon)\) by

\(\displaystyle A_{ii}=\sum_{j\neq i}w_{ij},\qquad A_{ij}=-w_{ij}\quad(i\neq j), \)

with zero rows for casting types.

Every entry is an integer polynomial of degree at most \(C\). Its coefficient norm, defined as the sum of the absolute values of its coefficients, is at most \(\tau B\).

For any square submatrix \(M\) of order \(d\leq\tau\), the determinant expansion therefore gives

\(\displaystyle \deg\det M\leq dC, \qquad \|\det M\|_1\leq d!(\tau B)^d. \)

Indeed, coefficient norms are submultiplicative under polynomial multiplication and subadditive under addition; the determinant has \(d!\) signed product terms.

Set

\(\displaystyle H=\tau!(\tau B)^\tau.\)

Every coefficient of every such determinant has absolute value at most \(H\), and

\(\displaystyle \log H=O\!\left(\tau(L+\log\tau)\right).\)

These determinant bounds are used only in the analysis; the algorithm does not expand any polynomial.

Intermediate rates are ratios of minors

Let \(K\subseteq D\) be the already eliminated vertices, and let \(V=\mathcal T\setminus K\). Gaussian elimination gives the current Laplacian as the Schur complement

\(\displaystyle A^{(K)}=A_{VV}-A_{VK}A_{KK}^{-1}A_{KV}. \)

This follows from the elimination calculation in Section 2: its current diagonal entries are \(q_i\), and its off-diagonal entries are \(-w^{(K)}_{ij}\).

The matrix \(A_{KK}\) is invertible for every \(\varepsilon>0\). In the elimination order used for \(K\), its determinant is the product of the positive pivots established in Section 2.

For \(i,j\in V\), the bordered determinant identity gives

\(\displaystyle A^{(K)}_{ij} = \frac{ \det\begin{pmatrix} A_{KK}&A_{Kj}\\ A_{iK}&A_{ij} \end{pmatrix} }{ \det A_{KK} }. \)

The identity follows by subtracting \(A_{iK}A_{KK}^{-1}\) times the upper block rows from the last row. For \(K=\varnothing\), use denominator \(1\).

Thus every nonzero current rate and every pivot is, up to the sign of an off-diagonal entry, a ratio of integer polynomial determinants of order at most \(\tau\).

If the numerator and denominator have least nonzero exponents \(\alpha,\beta\) and corresponding coefficients \(p,q\), the stored leading pair has exponent \(\alpha-\beta\) and positive coefficient \(|p/q|\). Consequently:

  • Every stored exponent has absolute value at most \(\tau C\), requiring \(O(\log\tau+\log C)\) bits.
  • In reduced form, every stored rate coefficient and every complete pivot coefficient has numerator and denominator at most \(H\), requiring \(O(\log H)\) bits.

Partial sums used to form a pivot also have polynomial bit length. They contain at most \(\tau\) coefficients, each with numerator and denominator at most \(H\). Using the product of their denominators gives numerator and denominator lengths \(O(\tau\log H+\log\tau)\).

Each rate update uses only a constant number of products, divisions, and additions of these bounded numbers. Its temporary values therefore also have polynomial bit length. Reducing rational coefficients after each operation preserves these bounds for subsequent steps.

Number of operations and output size

For one starting type \(t\), there are at most \(\tau\) eliminations, each updating at most \(\tau^2\) rates. Repeating this procedure for every \(t\in D\) uses \(O(\tau^4)\) leading-pair operations.

Every operation uses integers of polynomial bit length, so the total bit running time is polynomial in \(m,\tau,L\).

Finally, each output entry is a ratio of two bounded leading coefficients, multiplied by the input rational \(\mu_t\). Its bit length is polynomial as well. There are at most \(\tau^2\) entries.

Conclusion

The elimination algorithm computes the exact requested matrix in polynomial time. It handles tied costs, self-targets, and binary-encoded costs without enumerating voters or expanding high-degree polynomials.
