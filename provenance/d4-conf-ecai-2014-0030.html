The continuous mirror question, as graded

Given a candidate set \(C\), a finite set \(T\) of ranking types, registered masses \(\mu_t\ge 0\) with \(\sum_{t\in T}\mu_t=1\), available unregistered masses \(\nu_t\ge 0\), a target \(p\in C\), and a rational budget \(\kappa\ge 0\), decide whether there are additions \(x_t\in[0,\nu_t]\) with \(\sum_{t\in T}x_t\le\kappa\) such that \(p\) wins under \(1\text{-Approval THEN }1\text{-Approval}\). In the first round, the finalists are the candidates maximizing \(\sum_{t:\,t\text{ ranks }c\text{ first}}(\mu_t+x_t)\). In the runoff among those finalists, each mass unit supports its highest-ranked finalist; \(p\) must receive at least as much runoff mass as every other finalist. What is the complexity in \(m=|C|\), \(\tau=|T|\), and the input bit length?

Packaged proof task (what the prover saw — nothing else)

Let \(C\) be a nonempty candidate set, \(m=|C|\), and \(p\in C\). Types are strict total rankings of \(C\).
Each society is given by its support: types with positive mass, each mass a binary rational. Let \(T\) be the union of the registered and available supports, with missing masses set to zero; \(\tau=|T|\) counts listed types, not all possible rankings.
The input gives registered masses \(\mu_t\geq0\) with \(\sum_{t\in T}\mu_t=1\), available masses \(\nu_t\geq0\), and a binary rational budget \(\kappa\geq0\). Let \(L\) be the total input bit length.
An addition chooses divisible masses \(x_t\in\mathbb R\) with \(0\leq x_t\leq\nu_t\) and \(\sum_t x_t\leq\kappa\); the resulting masses are \(w_t=\mu_t+x_t\).
Under \(1\text{-Approval THEN }1\text{-Approval}\), the finalist set \(F\) consists of all candidates maximizing \(\sum_{t:\,c\text{ is first in }t}w_t\). All resulting mass participates in the runoff, with unchanged rankings restricted to \(F\).
An addition succeeds precisely when \(p\in F\) and \(p\) receives strictly more runoff mass than every member of \(F\setminus\{p\}\); a sole finalist wins automatically.

Is deciding whether a successful addition exists solvable in polynomial time in \(m,\tau,L\), or is it NP-hard?

For indivisible, unweighted voters, constructive control by adding or deleting votes under this rule is NP-hard, with a unique final winner required ([Guo–Shrestha, 2014](https://www.researchgate.net/publication/265476940_Controlling_Two-Stage_Voting_Rules)).
No result settling this exact divisible-mass problem was identified in the literature search.

Result

The decision problem is \(\mathrm{NP}\text{-complete}\). Hardness holds even when every input mass and the budget are dyadic rationals.

The reduction below handles arbitrary real additions: partial additions cannot bypass the combinatorial requirement.

1. Reduction from Set Cover

We use the standard \(\mathrm{NP}\)-complete Set Cover problem: given a nonempty universe \(U=\{e_1,\ldots,e_r\}\), sets \(S_1,\ldots,S_n\subseteq U\), and an integer \(0\leq k\leq n\), decide whether at most \(k\) of the sets cover \(U\). We may assume \(n\geq1\), since instances with no sets are trivial. See [Karp, *Reducibility among Combinatorial Problems*](https://link.springer.com/chapter/10.1007/978-1-4684-2001-2_9).

Numerical parameters

Let \(Q\) be the smallest power of two satisfying \(Q\geq12r+4\), and define
\[ b=\frac Q2-2r-1. \]

Consequently,
\[ b\geq4r+1, \qquad 2b+4r+2=Q. \]

We initially describe unnormalized mass units. Every registered and available mass, and the budget, will then be divided by \(Q\).

Candidates and rankings

The candidates are \(p\), a fixed rival \(q\), one candidate \(c_j\) for each set \(S_j\), and a collection \(D\) of dummy candidates.

For each element \(e_i\), let \(A_i\) be the list of candidates \(c_j\) such that \(e_i\in S_j\), ordered by increasing \(j\).

Every ranking prefix below is completed by appending all unlisted candidates in a fixed order. Thus every listed type is a strict total ranking.

The registered types are:

| Number of types | Ranking prefix | Mass per type |
|---:|---|---:|
| \(1\) | \(p\succ q\) | \(2\) |
| \(1\) | \(q\succ p\) | \(2\) |
| \(b\) | \(d\succ p\succ q\) | \(1\) |
| \(b-2\) | \(d\succ q\succ p\) | \(1\) |
| Four for each \(e_i\in U\) | \(d\succ A_i\succ q\succ p\) | \(1\) |

Each occurrence of \(d\) denotes a different dummy candidate. Hence
\[ |D|=b+(b-2)+4r=Q-4. \]

The total registered mass is
\[ 2+2+b+(b-2)+4r=Q. \]

For each \(j\), the available support contains one type with ranking prefix
\[ c_j\succ q\succ p \]
and available mass \(2\). There are no other available types. The unnormalized budget is \(2k\).

Divide all masses and the budget by \(Q\). The resulting registered mass sums to \(1\), exactly as required. Since \(Q\) is a power of two, all numerical inputs are dyadic rationals.

Polynomial size

Because \(Q<2(12r+4)\), the number of dummy candidates is \(O(r)\). In fact,
\[ m=n+Q-2, \qquad \tau=n+Q-2. \]

The equality for \(\tau\) holds because every listed type has a different first-ranked candidate. Each ranking has length \(m\), and the numerical parameters have polynomial encoding length. Thus this is a polynomial-time construction from an explicitly represented Set Cover instance.

2. Analysis of arbitrary divisible additions

Let \(x_j\) be the actual added mass of the available type headed by \(c_j\), and put \(a_j=Qx_j\). Feasibility is equivalent to
\[ 0\leq a_j\leq2, \qquad \sum_{j=1}^{n}a_j\leq2k. \]

All scores below are multiplied by \(Q\); this preserves both equality and strict comparison.

Exact finalist set

The first-round scores are:

  • \(p\) and \(q\): \(2\) each;
  • every dummy: \(1\);
  • \(c_j\): \(a_j\).

Therefore, for every feasible addition, the finalist set is exactly
\[ F=\{p,q\}\cup\{c_j:j\in J\}, \qquad J=\{j:a_j=2\}. \]

In particular, no dummy can reach the runoff, and a partially added set candidate cannot reach it.

The budget gives
\[ 2|J|\leq\sum_{j=1}^{n}a_j\leq2k, \]
so \(|J|\leq k\).

Runoff scores

Let
\[ u=\left|U\setminus\bigcup_{j\in J}S_j\right|, \qquad A=\sum_{j\notin J}a_j. \]

Thus \(u\) counts uncovered elements and \(A\geq0\) is the total mass of partial additions.

The runoff score of \(p\) is exactly
\[ R_p=2+b. \]

Indeed, \(p\) receives its own initial mass \(2\) and the \(b\) dummy-headed types with \(p\) second. Every other type places either \(q\) or a selected set candidate above \(p\).

The runoff score of \(q\) is exactly
\[ R_q=2+(b-2)+4u+A=b+4u+A. \]

To verify every term:

  • Its own registered type contributes \(2\).
  • The \(b-2\) dummy-headed types with \(q\) second contribute \(b-2\).
  • For a covered element, the four associated types transfer to the first selected candidate in \(A_i\). For an uncovered element, all four transfer to \(q\).
  • If \(j\notin J\), candidate \(c_j\) is absent from the runoff, so its entire added mass \(a_j\) transfers to \(q\). If \(j\in J\), that mass stays with \(c_j\).

Every selected candidate \(c_j\) receives its own added mass \(2\) and possibly some element-associated mass. The total element-associated mass is \(4r\), so
\[ R_{c_j}\leq2+4r<2+b=R_p. \]

Thus \(p\) always strictly beats every selected set candidate. Its comparison with \(q\) is decisive:
\[ R_p>R_q \quad\Longleftrightarrow\quad 4u+A<2. \]

Because \(u\) is a nonnegative integer and \(A\geq0\), success necessarily implies \(u=0\).

3. Correctness of the reduction

A successful addition yields a cover

Suppose an arbitrary feasible real addition succeeds.

The runoff calculation implies \(u=0\), so the sets indexed by \(J\) cover \(U\). The budget calculation gives \(|J|\leq k\). Hence the Set Cover instance is a yes-instance.

This argument permits every fractional value \(a_j\in[0,2]\); it makes no integrality assumption about additions.

A cover yields a successful addition

Conversely, suppose \(J\subseteq\{1,\ldots,n\}\) indexes a cover with \(|J|\leq k\). Choose
\[ a_j= \begin{cases} 2,&j\in J,\\ 0,&j\notin J. \end{cases} \]

This addition respects all capacities and uses mass \(2|J|\leq2k\). Since the selected sets cover \(U\), we have \(u=0\); since there are no partial additions, \(A=0\).

Therefore,
\[ R_p=b+2>b=R_q. \]

The previously proved bound also gives \(R_p>R_{c_j}\) for every selected set candidate. Consequently, \(p\) is the unique runoff winner.

The reduction proves \(\mathrm{NP}\)-hardness.

4. Membership in NP

Although additions may be real, membership in \(\mathrm{NP}\) follows by guessing the finalist set and solving a rational linear program.

Fix a guessed set \(F\subseteq C\) containing \(p\). For each type \(t\), let \(h_F(t)\) be its highest-ranked candidate in \(F\). Define the linear score functions
\[ s_c(x)=\sum_{t:\,c\text{ is first in }t}(\mu_t+x_t), \]
and, for \(c\in F\),
\[ r_c^F(x)=\sum_{t:\,h_F(t)=c}(\mu_t+x_t). \]

Introduce a variable \(\delta\), and maximize \(\delta\) subject to:

  • \(0\leq x_t\leq\nu_t\) for every \(t\), and \(\sum_t x_t\leq\kappa\);
  • \(0\leq\delta\leq1\);
  • \(s_c(x)=s_p(x)\) for every \(c\in F\);
  • \(s_c(x)\leq s_p(x)-\delta\) for every \(c\notin F\);
  • \(r_c^F(x)\leq r_p^F(x)-\delta\) for every \(c\in F\setminus\{p\}\).

This program has polynomially many variables and constraints and rational coefficients of polynomial encoding length. Its feasible region is closed and bounded.

It has a feasible solution with \(\delta>0\) if and only if an addition succeeds with exactly the finalist set \(F\):

  • Positive \(\delta\) enforces exactly the required first-round ties, excludes every outside candidate, and gives \(p\) every required strict runoff victory.
  • Conversely, a successful addition with finalist set \(F\) has finitely many strictly positive first-round exclusion gaps and runoff winning gaps. Choose \(\delta\) to be the minimum of these gaps and \(1\). If there are no such gaps, choose \(\delta=1\).

Rational linear programming can be solved, and its optimum compared exactly with zero, in polynomial time; this is the standard polynomial-time linear programming theorem of [Khachiyan](https://www.mathnet.ru/eng/dan42319). Thus an \(\mathrm{NP}\) verifier can guess \(F\) using \(m\) bits and accept precisely when this program has positive optimum.

Combining membership with the reduction, the target problem is \(\mathrm{NP}\text{-complete}\). A polynomial-time algorithm in \(m,\tau,L\) would therefore imply \(\mathrm{P}=\mathrm{NP}\).
