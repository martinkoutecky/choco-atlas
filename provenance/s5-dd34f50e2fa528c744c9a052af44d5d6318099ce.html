The continuous mirror question, as graded

Given a finite set of temporal report types \(T\), positive rational masses \(\mu_t\) summing to \(1\), and a temporal delegation network whose approved targets are types, choose a time-stamped outgoing delegation for each delegating type. Require the selected edges to form a tree toward a sink spanning all non-abstaining types, with every path respecting its type’s trust horizons; decide whether the mass-weighted first-edge satisfaction \(\sum_{t \in T_D}\mu_t w(e_t)\) can reach a given rational threshold \(q\).

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a nonempty list \(T\) of \(\tau\) temporal report types, each with positive binary-rational mass \(\mu_t\), where \(\sum_{t\in T}\mu_t=1\). Here \(\tau\) is the support size, not the number of possible reports.
There are \(H\ge1\) discrete deliberation rounds. In each round \(r\), a type \(t\) either commits to casting a ballot permanently or reports approved targets \(S_t^r\subseteq T\setminus\{t\}\), a weak ranking with positive integer satisfaction scores, and an integer trust horizon \(0\le\delta_t^r\le r-1\); an empty approval set means abstention in that round.
Let \(C\) contain types that commit to casting, \(A=\{t\in T\setminus C:S_t^H=\varnothing\}\), and \(D=T\setminus(C\cup A)\). Discard all delegation reports of casting types.
The network has a sink \(\bot\). Each remaining approval gives an edge \(e=(t,u,r)\) with its reported satisfaction \(w(e)\); a casting type committing in round \(b_t\) has zero-weight edges \((t,\bot,r)\) for every \(b_t\le r\le H\). There are no other sink edges.
Choose exactly one time-stamped outgoing edge \(e_t\) for each \(t\in D\), and one casting edge for each \(t\in C\). These choices apply to the entire mass of each type and all mass arriving there.
The chosen edges must form a directed tree on \((T\setminus A)\cup\{\bot\}\) toward \(\bot\). For every consecutive pair \((t,u,r),(u,v,s)\), including casting edges, require \(r\ge s\ge r-\delta_t^r\).
Given a binary-rational threshold \(q\), decide whether a feasible tree satisfies \(\sum_{t\in D}\mu_t w(e_t)\ge q\). Reports and time-stamped edges are explicit; let \(m\) be the number of available edges and \(L\) the total input bit length. State running times in \(m,\tau,L,H\).

Is this mass-weighted temporal delegation decision problem solvable in polynomial time in \(m,\tau,L,H\), or is it \(\mathrm{NP}\)-hard?

For finite individual voters, maximizing first-edge satisfaction subject to these temporal and tree constraints is \(\mathrm{NP}\)-hard, even with retrospective trust \(\delta_t^r=r-1\) and Borda scoring. [Source](https://arxiv.org/pdf/2307.12898)
No result settling the exact mass-weighted type problem was located in the literature search.

Modeling choices made when packaging the task

  • Specified discrete rounds H and used L for total input bit length; reports and time-stamped edges are explicitly encoded, with m counting available edges.
  • Defined casting, abstaining, and delegating types from their reports: casting is permanent, and non-casting types with empty final-round approvals abstain.
  • Specified positive integer satisfaction scores, weak rankings, nonnegative integer trust horizons bounded by the report round minus one, and exclusion of self-approval.
  • Added casting edges available from commitment onward, discarded casting types' earlier delegation reports, and included casting-edge timestamps in the trust constraints.
  • Made each selected edge and timestamp common to the entire type mass and all incoming mass, preserving the graded question's single-action tree requirement.
  • Required the tree to exclude all abstaining types and to span every casting and delegating type, including casting types that receive no delegations.

Result

The decision problem is \(\mathrm{NP}\)-complete, already with \(\smash{H=2}\), retrospective trust, a single casting type, and equal masses for all delegating types.

The proof below directly constructs an explicit support of distinct temporal report types. It therefore establishes hardness for the stated support model.

Membership in \(\mathrm{NP}\)

A certificate specifies one available outgoing edge for every type in \(D\cup C\). Its length is \(O(\tau\log(m+1))\).

A verifier checks:

  • Each specified edge is available and has its endpoint in \((T\setminus A)\cup\{\bot\}\).
  • Every type in \(D\cup C\) has exactly one selected outgoing edge, and every such type reaches \(\bot\). These conditions imply that the selected graph is a directed tree toward \(\bot\).
  • For each selected edge \((t,u,r)\) with \(u\ne\bot\), the selected outgoing edge \((u,v,s)\) satisfies \(r\ge s\ge r-\delta_t^r\).
  • The exact rational sum \(\sum_{t\in D}\mu_t w(e_t)\) is at least \(q\).

The graph checks take linear time in the selected graph once the edges are indexed. Exact rational arithmetic has polynomial bit complexity: a common denominator obtained from the input denominators has bit length \(O(L)\), and the necessary numerators also have bit length \(O(L)\). Using ordinary integer arithmetic, a conservative verifier bound is \(O((m+\tau)L^2)\) bit operations. Thus the problem belongs to \(\mathrm{NP}\).

Reduction from Vertex Cover

We use the standard \(\mathrm{NP}\)-complete decision problem Vertex Cover: given a simple undirected graph \(G=(V,E)\) and an integer \(k\), decide whether a set \(U\subseteq V\) of size at most \(k\) meets every edge.

Write \(V=\{1,\ldots,n\}\) and \(p=|E|\). We may restrict to \(n\ge2\), \(p\ge1\), and \(0\le k\le n\). Excluded cases are immediately decidable and can be replaced by fixed instances satisfying these restrictions: a single edge with threshold \(1\) is a yes-instance, and a single edge with threshold \(0\) is a no-instance.

Types, masses, and threshold

Introduce:

  • A vertex type \(x_i\) for each \(i\in V\).
  • An edge type \(y_e\) for each \(e\in E\).
  • One casting type \(c\).

Consequently, \(\tau=n+p+1\). Set

\[ b=\lceil\log_2\tau\rceil,\qquad a=2^{-b}. \]

Assign mass \(a\) to every vertex and edge type, and assign \(c\) mass \(1-(n+p)a\). These masses are positive dyadic rationals summing to \(1\): since \(\tau a\le1\), the casting mass is at least \(a>0\).

Define

\[ W=n+2,\qquad B=\sum_{i=1}^{n}(i+1)=\frac{n(n+3)}2, \qquad q=a(B+Wp-k). \]

Reports

There are two rounds. Type \(c\) commits to casting in round \(1\), giving casting edges \((c,\bot,1)\) and \((c,\bot,2)\), both of weight zero.

The other reports are:

| Type | Round \(1\) | Round \(2\) |
|---|---|---|
| \(x_i\) | Approves only \(c\), with score \(i\) | Approves only \(c\), with score \(i+1\) |
| \(y_{\{i,j\}}\) | Approves \(x_i,x_j\), tied with score \(W\) | Approves only \(c\), with score \(1\) |

Every noncasting type uses retrospective trust: \(\delta_t^1=0\) and \(\delta_t^2=1\).

All scores are positive integers and define valid weak rankings. Every noncasting type has a nonempty final approval set, so \(C=\{c\}\), \(A=\varnothing\), and \(D=T\setminus\{c\}\).

The temporal report types are distinct. Different vertex types have different scores; different edge types have different unordered pairs of approved endpoints because the graph is simple. Vertex and edge types differ in their round-one approval-set sizes, and the casting type commits to casting.

Correctness of the Reduction

For a selected assignment, let

\[ U=\{i:x_i\text{ selects its round-one edge}\}, \]

and let \(z\) be the number of edge types selecting their round-two edge.

Temporal constraint

If \(y_{\{i,j\}}\) selects its round-one edge to \(x_i\), then its timestamp is \(1\) and its trust horizon is \(0\). The consecutive-edge condition forces the timestamp \(s\) selected by \(x_i\) to satisfy \(1\ge s\ge1\). Hence \(i\in U\).

Therefore, every edge type selecting a round-one edge must delegate to an endpoint belonging to \(U\).

Conversely, choose the casting edge \((c,\bot,1)\). Every vertex type may then select either of its edges: timestamps \(1\) and \(2\) both permit a following timestamp of \(1\). Every edge type may select its round-two edge to \(c\), or its round-one edge to an endpoint in \(U\).

All these compatible choices form a tree. Every vertex type points to \(c\); every edge type points to a vertex type or to \(c\); and \(c\) points to \(\bot\). Thus every type reaches \(\bot\), and there is exactly one outgoing edge per type.

Exact objective identity

For vertex type \(x_i\), the score is \(i+1\) minus \(1\) precisely when \(i\in U\). The vertex types therefore contribute an unweighted score of \(B-|U|\).

The edge types contribute \(W(p-z)+z=Wp-(W-1)z\).

Since every delegating type has mass \(a\), the exact objective is

\[ a\bigl(B+Wp-|U|-(W-1)z\bigr). \]

It reaches the threshold \(q\) exactly when

\[ |U|+(W-1)z\le k. \]

A vertex cover gives a feasible tree

Suppose \(U\) is a vertex cover with \(|U|\le k\). Select:

  • The round-one edge for \(x_i\) when \(i\in U\), and its round-two edge otherwise.
  • For each edge type, its round-one edge to an endpoint in \(U\).
  • The casting edge \((c,\bot,1)\).

The preceding temporal analysis proves feasibility. Here \(z=0\), so the objective is \(a(B+Wp-|U|)\ge q\).

A feasible tree reaching the threshold gives a vertex cover

Suppose a feasible tree reaches \(q\). Its objective identity gives \(|U|+(W-1)z\le k\).

But \(W-1=n+1>k\). Since \(|U|\) and \(z\) are nonnegative integers, necessarily \(z=0\) and \(|U|\le k\).

Thus every edge type selects a round-one edge. The temporal constraint forces its selected endpoint to belong to \(U\). Hence \(U\) meets every edge of \(G\), so it is a vertex cover of size at most \(k\).

This proves both directions of the reduction.

Size and Running Times

The constructed instance has

\[ H=2,\qquad \tau=n+p+1,\qquad m=2n+3p+2. \]

Here vertex types contribute \(2n\) edges, edge types contribute \(3p\), and the casting type contributes two sink edges. Scores, masses, and the threshold have \(O(\log(n+p))\)-bit encodings. With indexed vertices, the total output length is \(L=O((n+p)\log(n+p))\), and the construction takes \(O((n+p)\log^2(n+p))\) bit operations.

For general instances, verification takes \(O((m+\tau)L^2)\) bit operations. Enumerating all outgoing-edge choices gives a deterministic upper bound of \(O((m+1)^\tau(m+\tau)L^2)\). Dependence on \(H\) is already represented in the explicit edges and input length.

The polynomial reduction proves \(\mathrm{NP}\)-hardness even for \(H=2\); membership proves \(\mathrm{NP}\)-completeness. Therefore a polynomial-time algorithm in \(m,\tau,L,H\) would imply \(\mathrm{P}=\mathrm{NP}\).
