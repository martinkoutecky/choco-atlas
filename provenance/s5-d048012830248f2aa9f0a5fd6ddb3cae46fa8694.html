The continuous mirror question, as graded

Given a finite candidate set with candidate attributes, group quotas, committee size \(k\), voter populations with designated committees \(W_P\) and representation quotas, and a finite support \(T\) of complete ranking-and-population-membership types with positive rational masses \(\lambda_t\) summing to one, find a size-\(k\) committee maximizing \(\sum_{c\in W}\sum_{t\in T}\lambda_t\alpha_{\operatorname{pos}_t(c)}\), subject to the paper's diversity and representation constraints and fixed tie-breaking.

Packaged proof task (what the prover saw — nothing else)

Given a candidate set \(C\) with \(m\ge2\) candidates and an integer \(1\le k\le m\), there is one candidate attribute partitioning \(C\) into at least two nonempty groups \(\mathcal G\).
A society is given by its support: the list \(T\) of \(\tau\) types with positive binary-rational masses \(\lambda_t\), with \(\sum_{t\in T}\lambda_t=1\). Here \(\tau=|T|\) is the support size, not the number of possible types.
Each type specifies a strict complete candidate ranking and membership in exactly one population for each of \(\pi\ge1\) voter attributes. Each attribute partitions \(T\) into at least two populations of positive mass; let \(\mathcal P\) contain all these populations. Attributes with identical partitions and identical corresponding quotas are identified.
Each population \(P\) has a supplied designated committee \(W_P\subseteq C\) of size \(k\). These committees are input data, without a requirement that they arise from the scoring rule used below.
Diversity quotas are integers \(1\le\ell_G^D\le\min(k,|G|)\); representation quotas are integers \(1\le\ell_P^R\le k\). A committee \(W\subseteq C\) is feasible precisely when \(|W|=k\), \(|W\cap G|\ge\ell_G^D\) for every \(G\in\mathcal G\), and \(|W\cap W_P|\ge\ell_P^R\) for every \(P\in\mathcal P\).
Given a binary-rational positional scoring vector \(\alpha_1\ge\cdots\ge\alpha_m\ge0\), find a feasible committee maximizing \(\sum_{c\in W}\sum_{t\in T}\lambda_t\alpha_{\operatorname{pos}_t(c)}\), or report infeasibility. Resolve equal scores lexicographically using a supplied candidate priority order.
Let \(L\) be the total binary input length. State running times in \(m,\tau,L,k,\pi,|\mathcal G|,|\mathcal P|\).

Is this exact committee optimization problem solvable in polynomial time, or is it NP-hard?

Discrete winner determination with one candidate attribute and any positive number of voter attributes is NP-hard for monotone, separable positional scoring rules. [Relia (2022)](https://arxiv.org/pdf/2211.13217)
No verified complexity result for exactly this rational-mass formulation was located.

1. Result

The exact committee optimization problem is \(\mathrm{NP}\text{-hard}\). In fact, feasibility alone is \(\mathrm{NP}\text{-complete}\), even when:

  • \(\pi=1\);
  • \(|\mathcal G|=2\), with both diversity quotas equal to \(1\);
  • every representation quota equals \(2\);
  • all supported types have the same candidate ranking;
  • all masses are positive dyadic rationals.

Hardness also holds for every fixed positive number of voter attributes, and with a nonconstant scoring vector such as Borda.

The boundary cases are easy: \(k=1\) is infeasible because there are at least two candidate groups with positive quotas; \(k=m\) returns \(C\). The hardness concerns variable \(k\).

[Relia’s Theorem 1](https://arxiv.org/pdf/2211.13217) establishes hardness in the discrete setting. The following reduction proves the result directly for the formulation in the question.

2. Reduction from Vertex Cover

We use the classical \(\mathrm{NP}\)-complete Vertex Cover problem: given a finite simple graph \(H=(V,E)\) and an integer \(b\), determine whether some \(S\subseteq V\), with \(|S|\le b\), intersects every edge. See [Karp (1972)](https://link.springer.com/chapter/10.1007/978-1-4684-2001-2_9).

We may restrict to instances with \(N=|V|\), \(q=|E|\), \(2\le b\le N\), and \(q\ge2\). Indeed, excluded instances are decidable in polynomial time: budgets at most \(1\) can be checked by enumerating the empty set and singletons, budgets exceeding \(N\) are sufficient, and graphs with at most one edge are immediate. Such instances can be mapped to fixed restricted yes- or no-instances: respectively, two or three disjoint edges with budget \(2\). Thus the restricted problem remains \(\mathrm{NP}\)-complete.

Construction. Set \(k=b+1\). Introduce:

  • one candidate for each vertex in \(V\);
  • an additional candidate \(a\);
  • for each edge \(e\), a private set \(D_e\) of \(b-2\) candidates.

The sets \(D_e\) are pairwise disjoint and disjoint from \(V\cup\{a\}\). Write \(D=\bigcup_{e\in E}D_e\). Then

\(C=V\cup D\cup\{a\},\qquad m=N+q(b-2)+1.\)

Use one candidate attribute, with groups \(\{a\}\) and \(V\cup D\), and give both groups diversity quota \(1\). Consequently, every feasible committee contains \(a\).

Enumerate the edges as \(e_1,\ldots,e_q\). Introduce exactly \(q\) supported types \(t_1,\ldots,t_q\), all with the same strict complete ranking. There is one voter attribute, whose populations are the singletons \(P_i=\{t_i\}\). The types are distinct because their population memberships differ.

Let \(h=\lceil\log_2 q\rceil\), and assign masses

\(\lambda_{t_i}=2^{-h}\quad(1\le i<q),\qquad \lambda_{t_q}=1-(q-1)2^{-h}.\)

These masses are positive dyadic rationals, sum to \(1\), and each have binary encoding length \(O(\log q)\). In particular, every population has positive mass.

For \(e_i=\{u,v\}\), supply

\(W_{P_i}=\{a,u,v\}\cup D_{e_i},\qquad \ell_{P_i}^{R}=2.\)

Each designated committee has exactly \(3+(b-2)=b+1=k\) candidates. All quota bounds in the question are satisfied.

Initially choose \(\alpha_j=1\) for every position \(j\). Every candidate then has score \(1\), so every committee of size \(k\) has score \(k\). Supply any candidate priority order.

The construction has parameters

\(\tau=q,\qquad \pi=1,\qquad |\mathcal G|=2,\qquad |\mathcal P|=q.\)

Because \(b\le N\), its candidate lists, rankings, masses, and designated committees all have total length polynomial in the graph input length.

Forward implication. Suppose \(S\subseteq V\) is a vertex cover with \(|S|\le b\). Since \(b\le N\), extend it to a set \(S'\subseteq V\) with \(|S'|=b\). Put \(W=\{a\}\cup S'\).

This committee has size \(k\) and meets both diversity quotas. For every edge \(e_i=\{u,v\}\), at least one endpoint belongs to \(S'\). Hence \(W\cap W_{P_i}\) contains \(a\) and an endpoint, and has size at least \(2\). Thus \(W\) is feasible.

Reverse implication. Suppose \(W\) is feasible. Its diversity constraints force \(a\in W\), leaving exactly \(b\) selected candidates in \(V\cup D\).

Construct \(S\subseteq V\) by retaining all selected vertex candidates and, for each selected candidate in \(D_e\), adding one arbitrarily chosen endpoint of \(e\). Repeated additions count only once. Therefore

\(|S|\le |W\cap V|+|W\cap D|=b.\)

Fix an edge \(e_i=\{u,v\}\). Since \(a\in W\) and \(|W\cap W_{P_i}|\ge2\), the committee contains at least one member of \(\{u,v\}\cup D_{e_i}\). If it contains an endpoint, that endpoint belongs to \(S\). Otherwise, a selected private candidate in \(D_{e_i}\) causes an endpoint of \(e_i\) to be added to \(S\). Thus \(S\) intersects every edge and is a vertex cover.

We have proved the equivalence

\(H\text{ has a vertex cover of size at most }b \quad\Longleftrightarrow\quad \text{the constructed instance has a feasible committee}.\)

An exact optimizer must distinguish these cases by returning a committee or reporting infeasibility. It is therefore \(\mathrm{NP}\text{-hard}\).

The constant scoring vector is unnecessary for this conclusion. Replacing it by the Borda vector \(\alpha_j=m-j\) preserves the equivalence, because feasibility is unchanged. Thus hardness also holds with a nonconstant positional scoring rule.

3. Every fixed positive number of voter attributes

Fix any integer \(r\ge2\). Starting from the construction above, add supported types \(s_2,\ldots,s_r\), all with the same ranking as the existing types. Place them in \(P_1\) for the original voter attribute.

For each \(j\in\{2,\ldots,r\}\), introduce an additional attribute with populations \(\{s_j\}\) and \(T\setminus\{s_j\}\). For both populations, supply any committee \(R\) of size \(k\) containing \(a\), and set the representation quota to \(1\).

These additional constraints hold whenever \(a\) is selected, so they do not change feasibility. The new partitions are pairwise distinct. They also differ from the original partition: their singleton population is a marker type, whereas no marker singleton is a population of the original attribute. Hence attribute identification removes none of them.

All types remain distinct through their membership patterns. Reassign positive dyadic masses using the preceding formula with support size \(q+r-1\). This gives

\(\pi=r,\qquad \tau=q+r-1,\qquad |\mathcal P|=q+2(r-1).\)

For every fixed \(r\), the construction remains polynomial. Thus hardness holds for every fixed \(\pi\ge1\).

4. Exact arithmetic and decision complexity

Write \(p=|\mathcal P|\), \(g=|\mathcal G|\), and

\(s_c=\sum_{t\in T}\lambda_t\alpha_{\operatorname{pos}_t(c)}.\)

Exact scores can be computed without expanding the masses into individual voters. Write the input rationals as \(\lambda_t=a_t/d_t\) and \(\alpha_j=b_j/e_j\), with positive denominators, and use the common denominator

\(D=\left(\prod_{t\in T}d_t\right)\left(\prod_{j=1}^{m}e_j\right).\)

Then

\(D s_c=\sum_{t\in T}a_t b_{\operatorname{pos}_t(c)} \frac{D}{d_t e_{\operatorname{pos}_t(c)}}\)

is an integer. The total denominator encoding length is bounded by \(L\), so \(D\), the scaled scores, and committee score sums have \(O(L)\) bits. Using schoolbook integer arithmetic, a sufficient bound for preprocessing is

\(H_0=O(L^3+\tau mL^2).\)

This bound also accommodates preprocessing the explicitly supplied memberships and committee incidences.

Given a committee, all constraints are checkable in polynomial time. Feasibility therefore belongs to \(\mathrm{NP}\); together with the reduction, it is \(\mathrm{NP}\text{-complete}\). The decision version asking for a feasible committee with score at least a supplied rational threshold is likewise \(\mathrm{NP}\text{-complete}\): membership follows from exact arithmetic, and hardness follows by taking threshold \(k\) in the constant-score construction.

5. Exact running-time bounds

An exhaustive algorithm evaluates every committee of size \(k\). With candidate membership markers, it checks all representation constraints in \(O(pk)\) operations and diversity constraints in \(O(k+g)\) operations. A conservative bit running-time bound, including exact comparisons and tie-breaking, is

\(O\!\left( L^3+\tau mL^2+ \binom{m}{k}\bigl(k(p+1)+g+p\bigr)L^2 \right).\)

There is also a useful dynamic program exploiting the single candidate partition. Define

\(Q=\prod_{P\in\mathcal P}(\ell_P^R+1)\le(k+1)^p.\)

Process the candidate groups consecutively, and candidates within each group consecutively. A state records:

  • the total selected cardinality \(j\in\{0,\ldots,k\}\);
  • the current group’s selected count, capped at its diversity quota;
  • for each population \(P\), the intersection count with \(W_P\), capped at \(\ell_P^R\).

At each candidate, consider selecting or skipping it. At a group boundary, discard states failing that group’s diversity quota and remove the current-group coordinate. At the end, require total cardinality \(k\) and every population coordinate to equal its quota.

For each state retain the best partial committee. To implement tie-breaking exactly, let \(c_1,\ldots,c_m\) be the supplied priority order and assign secondary value

\(b(W)=\sum_{c_i\in W}2^{m-i}.\)

Among equal-cardinality committees, maximizing this value implements preference for the earlier sorted priority list: the earliest differing candidate’s bit exceeds the sum of all later bits. Compare partial committees by the ordered pair consisting of scaled score and secondary value.

This retention rule is valid because partial committees in the same state have identical available future choices and identical capped-count transitions. Adding the same future subset preserves their score and secondary-value comparison. Capping loses no relevant information because every constraint is a lower bound.

The bit running time is bounded by

\(O\!\left( H_0+ (k+1)(p+1)QL^2 \sum_{G\in\mathcal G}|G|(\ell_G^D+1) \right),\)

and hence by

\(O\!\left(H_0+m(k+1)^2(p+1)(k+1)^pL^2\right).\)

Thus the problem is polynomial-time solvable for fixed \(p\), and exhaustive enumeration is polynomial for fixed \(k\). Since each voter attribute has at most \(\tau\) populations, \(p\le\pi\tau\); the dynamic program is also polynomial when both \(\pi\) and \(\tau\) are fixed. Fixing \(\pi\) alone does not suffice, as the reduction proves.
