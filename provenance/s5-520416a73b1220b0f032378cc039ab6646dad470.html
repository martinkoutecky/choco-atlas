Result

The divisible-mass problem is in \(\mathrm{P}\). An exact algorithm runs in \(O((\tau+1)L^2)\) bit operations for the fixed \(m=5\), axis, and scoring vector in the question. Whenever manipulation is possible, there is a rational successful distribution supported on at most five permitted strict reports.

The proof below gives an explicit feasibility algorithm and its bit complexity.

1. Tied reports can be replaced by mixtures of strict reports

Let \(R\subseteq Q\) be the permitted strict orders.

Every tied group in a permitted weak order contains at most two candidates: it cannot contain the unique peak, and it contains at most one candidate from either side of that peak. Otherwise, two candidates on the same side would be tied, contradicting strict decrease along that side.

For \(q\in Q\), let \(\mathcal R(q)\) be its strict refinements, obtained by independently ordering each tied pair. Every refinement is permitted: the peak remains uniquely first, and the strict preferences between candidates on either side remain unchanged.

Choose a refinement uniformly from \(\mathcal R(q)\). A singleton retains its position. Each candidate in a tied pair occupying positions \(j,j+1\) receives each of \(\alpha_j,\alpha_{j+1}\) with probability \(1/2\). Consequently, for every candidate \(c\),

\(\displaystyle s_q(c)=\frac{1}{|\mathcal R(q)|}\sum_{r\in\mathcal R(q)}s_r(c).\)

Thus mass assigned to any weak report can be divided among its strict refinements without changing any candidate’s score. Conversely, every strict report is permitted. Coalition feasibility over \(Q\) therefore equals coalition feasibility over \(R\).

To count \(R\), write the axis as \(c_1\prec\cdots\prec c_m\). A strict order with peak \(c_i\) consists of that peak followed by an interleaving of the two fixed sequences

\(c_{i-1},c_{i-2},\ldots,c_1\quad\text{and}\quad c_{i+1},c_{i+2},\ldots,c_m.\)

There are \(\binom{m-1}{i-1}\) such interleavings. Hence

\(\displaystyle |R|=\sum_{i=1}^{m}\binom{m-1}{i-1}=2^{m-1}=16.\)

This count concerns possible coalition reports; it does not identify their number with the input support size \(\tau\).

2. An equivalent rational linear program

Compute the nonmanipulator scores and deficits

\(\displaystyle N_c=\sum_{t=1}^{\tau}\nu_t s_t(c),\qquad d_c=N_c-N_p\quad(c\ne p).\)

For each strict report \(r\in R\), define

\(A_{c,r}=s_r(p)-s_r(c).\)

The entries of \(A\) are integers between \(-4\) and \(4\). By the preceding section, the desired manipulation exists exactly when the following system has a solution:

\(\displaystyle y_r\ge 0\quad(r\in R),\qquad \sum_{r\in R}y_r=\rho,\qquad \sum_{r\in R}A_{c,r}y_r\ge d_c\quad(c\ne p).\)

Indeed, the last inequality rearranges to

\(\displaystyle N_p+\sum_r y_rs_r(p)\ge N_c+\sum_r y_rs_r(c).\)

These are exactly the winner conditions, including ties for the maximum score.

The system has sixteen variables, four winner inequalities, and one mass equality. Its coefficients and right-hand sides are rational.

3. A successful distribution needs at most five reports

If \(\rho=0\), the only coalition distribution is zero. The answer is yes exactly when \(N_p\ge N_c\) for every opponent \(c\). Henceforth assume \(\rho>0\).

Let \(P\) be the feasible set of the preceding system. It is closed and contained in the compact simplex \(\{y\ge0:\sum_r y_r=\rho\}\). If nonempty, it has an extreme point. For completeness, successively minimizing each coordinate over the remaining nonempty compact set produces a singleton face, whose point is extreme.

Fix an extreme point \(y\). Let \(J=\{r:y_r>0\}\), let \(k=|J|\), and let \(H\) be the opponents whose winner inequalities are equalities at \(y\).

On the coordinates in \(J\), the mass row and the rows indexed by \(H\) must have rank \(k\). Otherwise, there is a nonzero vector \(u\), supported on \(J\), satisfying

\(\displaystyle \sum_{r\in J}u_r=0,\qquad \sum_{r\in J}A_{c,r}u_r=0\quad(c\in H).\)

For sufficiently small \(\varepsilon>0\), both \(y+\varepsilon u\) and \(y-\varepsilon u\) remain feasible. To see this, choose \(\varepsilon\) small enough to preserve all positive coordinates and all strictly positive slacks of inactive inequalities. The mass equality and active inequalities remain unchanged. This contradicts extremality.

There are at most five available rows: the mass row and four opponent rows. Therefore \(k\le5\). Since the mass row is nonzero, it can be extended to a basis using \(k-1\) active opponent rows.

4. Explicit exact algorithm

Enumerate every report subset \(J\subseteq R\) with \(1\le k=|J|\le5\), and every opponent subset \(H'\subseteq C\setminus\{p\}\) with \(|H'|=k-1\).

For each pair, form the square system

\(\displaystyle \sum_{r\in J}y_r=\rho,\qquad \sum_{r\in J}A_{c,r}y_r=d_c\quad(c\in H').\)

Skip singular systems. Otherwise, solve exactly, set all coordinates outside \(J\) to zero, and check nonnegativity and all four winner inequalities. Accept if any check succeeds; reject otherwise.

Every accepted vector satisfies the required system. Conversely, if the system is feasible, Section 3 supplies an extreme point whose support and a basis of active rows occur in this enumeration. The corresponding nonsingular system recovers that point. Thus the algorithm is complete.

The number of candidate systems is

\(\displaystyle \sum_{k=1}^{5}\binom{16}{k}\binom{4}{k-1}=15504.\)

Each system has order at most five.

5. Bit complexity

Write the input masses as \(\nu_t=u_t/v_t\) and \(\rho=u_\rho/v_\rho\), with positive integer denominators. A common denominator for all nonmanipulator scores, deficits, and \(\rho\) is

\(\displaystyle D=2v_\rho\prod_{t=1}^{\tau}v_t.\)

The factor \(2\) accounts for the average scores of tied pairs. Its bit length is \(O(L)\), since the total bit length of the input denominators is at most \(L\). Moreover, \(0\le N_c\le4\), so the numerators of \(N_c\) and \(d_c\) over denominator \(D\) also have \(O(L)\) bits.

Computing the scores requires \(O(m\tau)\) exact arithmetic operations. The enumeration and checks require \(O(15504m^3)\) operations, including report preprocessing, with \(m=5\).

All nonsingular system matrices are fixed integer matrices of order at most five, with entries bounded in absolute value by \(4\). By the adjugate formula, every computed solution has denominator dividing \(D|\det M|\), and numerator of \(O(L)\) bits. Since these determinants and cofactors are constants, exact computation and verification use only \(O(L)\)-bit integers.

Using elementary quadratic-time integer arithmetic gives the explicit bound

\(\displaystyle O\bigl((m\tau+15504m^3)L^2\bigr)\qquad(m=5).\)

Therefore the running time is \(O((\tau+1)L^2)\), and hence polynomial in the total input length. The same argument proves that a successful rational witness uses at most five reports and has \(O(L)\) total bit length.

6. Why indivisible-voter hardness does not transfer

The cited paper’s Theorem 11 establishes the stated hardness for positive integer voter weights on this axis. Its reduction requires assigning whole voters to report classes whose total weights encode a partition. [Fitzsimmons and Hemaspaandra, Theorem 11](https://arxiv.org/html/1604.08191v2).

Here, any amount of coalition mass may be assigned to any report. Those discrete assignment constraints disappear, leaving precisely the rational linear feasibility problem proved above. Thus the divisible-mass problem is polynomial-time solvable; it could also be \(\mathrm{NP}\)-hard under standard polynomial-time reductions only if \(\mathrm{P}=\mathrm{NP}\).
