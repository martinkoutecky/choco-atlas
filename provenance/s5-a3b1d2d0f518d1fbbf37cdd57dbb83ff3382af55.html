Theorem 3.3 — class: algorithmic

The continuous mirror question, as graded

Given rational type masses μ_t summing to \(1\), entitlements \(w_t>0\), additive values \(v_{tj}\), and rational per-capita supplies \(q_j\) for \(M\) item categories, find a finite-support assignment λ_{t,b}≥0 to integral bundles \(b∈\mathbb{Z}_{\ge 0}^M\), with ∑_b λ_{t,b}=μ_t and ∑_{t,b}λ_{t,b}b_j=q_j\). Require that for every two positive-mass recipient classes \((t,b)\) and \((s,d)\), if \(d\ne 0\), some category \(k\) with \(d_k>0\) satisfies \(v_t(b)/w_t\ge v_t(d-e_k)/w_s\). Can such an assignment always be computed in time polynomial in \(M\), the number τ of types, and the binary input length \(L\)?

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a list of the \(\tau\geq1\) types with positive masses \(\mu_t\in\mathbb{Q}_{>0}\), encoded in binary, with \(\sum_t\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types.
There are \(m=M\geq1\) item categories. Each type has entitlement \(w_t\in\mathbb{Q}_{>0}\) and additive nonnegative rational values \(v_{tj}\); supplies are \(q_j\in\mathbb{Q}_{\geq0}\). All input numbers are binary encoded, with total bit length \(L\); entitlements need not sum to one.
A bundle is \(b\in\mathbb{Z}_{\geq0}^{m}\), with \(v_t(b)=\sum_{j=1}^{m}v_{tj}b_j\). Copies within a category have identical values.
A complete assignment consists of finitely many nonzero rational masses \(\lambda_{t,b}\geq0\), with bundles and masses binary encoded, satisfying \(\sum_b\lambda_{t,b}=\mu_t\) and \(\sum_{t,b}\lambda_{t,b}b_j=q_j\) for every category \(j\).
It is strongly weighted envy-free up to one item (WEF1) if, for every ordered pair of classes \((t,b),(s,d)\) with \(\lambda_{t,b}>0\), \(\lambda_{s,d}>0\), and \(d\neq0\), some \(k\) with \(d_k>0\) satisfies \(v_t(b)/w_t\geq v_t(d-e_k)/w_s\), where \(e_k\) is the \(k\)-th unit vector. This includes comparisons between different bundles assigned to the same type; equality is allowed.

Can a complete WEF1 assignment always be computed in time polynomial in \(m,\tau,L\), or is finding such an assignment NP-hard?

For finitely many agents and explicitly listed indivisible goods, nonnegative additive valuations and arbitrary positive entitlements admit a complete WEF1 allocation computable in polynomial time. [Verified discrete result](https://www.ifaamas.org/Proceedings/aamas2020/pdfs/p231.pdf)
No result settling the exact mass-based problem defined above was located in the literature search.

Modeling choices made when packaging the task

  • Restricted values and supplies to nonnegative rationals, matching the discrete goods domain and making the binary input model explicit; zero values and zero supplies remain allowed.
  • Specified rational positive entitlements for the binary input model, without imposing an entitlement normalization.
  • Specified rational assignment masses and binary encoding of bundle coordinates and masses so that exact computation has a defined representation.
  • Treated copies within each category as identical for every type, as dictated by the category-indexed additive values.
  • Set the category count m equal to M and required positive support and category counts; retained the stated normalization of total society mass to one.
  • Made explicit that fairness compares all positive-mass recipient classes, including different bundles of the same type, and permits equality.

Result

A complete strongly WEF1 assignment can always be computed in time polynomial in \(\,m,\tau,L\,\). The algorithm below outputs at most \(\tau+m\) positive-mass classes.

The key is to simulate a finite weighted picking procedure in compressed form. Although clearing denominators may create exponentially many agents and goods, each category depletion introduces at most one new bundle class.

1. A weighted picking lemma

Consider finitely many agents with positive weights and nonnegative additive valuations. Initially, every agent has picked zero goods. Repeatedly:

  • Choose an agent minimizing her number of previous picks divided by her weight, using a fixed order to break ties.
  • Give her a most-valued remaining good, again using fixed tie-breaking.

This is the picking rule in [Algorithm 1 of the cited paper](https://www.ifaamas.org/Proceedings/aamas2020/pdfs/p231.pdf). We give a self-contained fairness proof.

Lemma. The resulting complete allocation is strongly WEF1. In fact, removing the envied agent’s first pick suffices.

Proof. Fix distinct agents \(a,s\), with weights \(w_a,w_s\). Suppose \(s\) receives goods \(g_1,\ldots,g_\ell\), in chronological order. If \(\ell\leq1\), removing her sole good, when present, leaves value zero, so the required inequality follows from nonnegativity.

Otherwise, put \(\gamma=w_a/w_s\). Immediately before \(s\)’s \((r+1)\)-st pick, she has made \(r\) picks. If \(K_r\) is the number of picks already made by \(a\), the selection rule gives

\(\displaystyle \frac{r}{w_s}\leq\frac{K_r}{w_a},\qquad\text{hence}\qquad K_r\geq r\gamma.\)

Give each good picked by \(a\) one unit of bookkeeping capacity. For \(r=1,\ldots,\ell-1\), assign \(\gamma\) units of this capacity to \(g_{r+1}\), using only goods picked by \(a\) before \(g_{r+1}\).

This assignment is possible inductively: before step \(r\), exactly \((r-1)\gamma\) capacity has been used, all from goods among those first \(K_r\) picks. Therefore at least

\(\displaystyle K_r-(r-1)\gamma\geq\gamma\)

capacity remains available.

Every good \(h\) whose capacity is assigned to \(g_{r+1}\) was picked while \(g_{r+1}\) remained available. Greedy choice therefore implies \(v_a(h)\geq v_a(g_{r+1})\). Summing the capacity-weighted inequalities, and using nonnegativity for unused capacity, yields

\(\displaystyle v_a(A_a)\geq\gamma\sum_{r=1}^{\ell-1}v_a(g_{r+1}).\)

Dividing by \(w_a\) gives

\(\displaystyle \frac{v_a(A_a)}{w_a}\geq\frac{v_a(A_s\setminus\{g_1\})}{w_s}.\)

Comparisons of an agent with herself follow directly from nonnegativity. This proves the lemma.

2. Clearing denominators without expanding the instance

Let \(N\) be the product of the positive denominators appearing in the masses \(\mu_t\) and supplies \(q_j\). Define integers

\(\displaystyle A_t=N\mu_t,\qquad G_j=Nq_j,\qquad G=\sum_{j=1}^{m}G_j.\)

Then every \(A_t\) is positive and \(\sum_tA_t=N\).

Conceptually, construct \(A_t\) identical agents of type \(t\), each retaining entitlement \(w_t\), and \(G_j\) individual goods of category \(j\). We will simulate the preceding picking procedure without constructing these agents or goods explicitly.

If \(G=0\), assign the empty bundle to all mass of every type and stop. Henceforth assume \(G>0\).

Write \(w_t=a_t/b_t\), with positive integers \(a_t,b_t\), and set

\(\displaystyle H=\prod_{t=1}^{\tau}a_t,\qquad h_t=\frac{Hb_t}{a_t}=\frac{H}{w_t}.\)

Each \(h_t\) is a positive integer.

Label type \(t\)’s conceptual agents by integers \(i\) satisfying \(0\leq i<A_t\). Break agent ties by type index and then label. Break ties between equally valued categories by category index.

An agent of type \(t\) who has already picked \(k\) goods has normalized pick count \(k/w_t=kh_t/H\). Thus the entire picking order is the order of tickets

\(\displaystyle (kh_t,t,i),\qquad k\in\mathbb Z_{\geq0},\quad 0\leq i<A_t,\)

sorted lexicographically.

Indeed, tickets for any one agent have strictly increasing first coordinates. Consequently, the earliest unprocessed ticket is that agent’s next pick, and minimizing its first coordinate is precisely minimizing the normalized pick count.

For fixed \(t,k\), all \(A_t\) tickets at timestamp \(kh_t\) form one consecutive block, ordered by agent label.

3. State of the compressed simulation

At a prefix of the ticket order, maintain, for every type \(t\):

  • \(n_t\): the number of fully processed blocks of that type;
  • \(p_t\): the number of processed labels in its next block, where \(0\leq p_t<A_t\).

Therefore agents with \(i<p_t\) have made \(n_t+1\) picks; the others have made \(n_t\) picks. Initially both counters are zero.

Also maintain remaining integer supplies \(r_j\), initially \(G_j\).

For each type, store its agents as consecutive half-open intervals of labels. An interval carries the common bundle of all its agents. Initially, type \(t\) has the single interval \([0,A_t)\), carrying the empty bundle.

The simulation operates in epochs, each ending when one category is exhausted. At the beginning of an epoch, choose for each type its favorite available category:

\(\displaystyle f_t\in\operatorname*{arg\,max}_{j:r_j>0}v_{tj},\)

using the fixed category tie-breaking.

Until a category is exhausted, available categories do not change. Hence every pick by type \(t\) during that part of the epoch chooses \(f_t\).

4. Finding and processing the next depletion

4.1 Exact demand through a timestamp

For an integer \(z\geq0\), define

\(\displaystyle K_t(z)=\max\left\{0,\left\lfloor\frac{z}{h_t}\right\rfloor+1-n_t\right\}.\)

The number of unprocessed type-\(t\) tickets with timestamp at most \(z\) is

\(\displaystyle X_t(z)=A_tK_t(z)-p_t\mathbf 1_{\{K_t(z)>0\}}.\)

The subtraction accounts for the already processed prefix of the current block, if that block is included.

Under the fixed choices \(f_t\), the additional demand for category \(j\) through timestamp \(z\) is consequently

\(\displaystyle F_j(z)=\sum_{t:f_t=j}X_t(z).\)

Set \(F_j(-1)=0\). Each \(F_j\) is nondecreasing.

Find the smallest nonnegative integer \(z\) for which

\(\displaystyle F_j(z)\geq r_j\quad\text{for some currently available category }j.\)

This search has a polynomial-bit upper bound. Set

\(\displaystyle B=(G+1)\max_t h_t.\)

Let \(P\) be the number of goods already allocated. The counters give

\(\displaystyle P=\sum_t(A_tn_t+p_t)\leq G,\qquad n_t\leq G.\)

Since \(\lfloor B/h_t\rfloor+1\geq G+2\), every current partial block is included in \(F_j(B)\), and

\(\displaystyle \sum_{j:r_j>0}F_j(B) =\sum_tA_t\left(\left\lfloor\frac{B}{h_t}\right\rfloor+1\right)-P \geq N(G+2)-P >G-P =\sum_{j:r_j>0}r_j.\)

Thus the search predicate holds at \(B\). Binary search on the integer interval from zero to \(B\) finds the smallest qualifying timestamp exactly.

4.2 Skipping all earlier tickets

By minimality of \(z\),

\(\displaystyle F_j(z-1)<r_j\)

for every available category. Therefore all remaining tickets with timestamp strictly less than \(z\) can be processed without exhausting a category.

For each type, put

\(\displaystyle n'_t=\max\left\{n_t,\left\lceil\frac{z}{h_t}\right\rceil\right\},\qquad \Delta_t=n'_t-n_t.\)

If \(\Delta_t=0\), make no change for that type.

If \(\Delta_t>0\), give additional copies of category \(f_t\) as follows:

  • \(\Delta_t-1\) copies to each agent with \(i<p_t\);
  • \(\Delta_t\) copies to each agent with \(i\geq p_t\).

The first group already received its pick in the current partially processed block, which explains the difference of one.

Subtract \(A_t\Delta_t-p_t\) from the supply of \(f_t\), and replace the counters by \(n_t=n'_t,\ p_t=0\).

These updates exactly process all previously unprocessed tickets before timestamp \(z\). They leave every available category with positive supply.

4.3 Processing tickets at the depletion timestamp

Now process the blocks at timestamp \(z\), in increasing type order. A type has such a pending block exactly when \(n_th_t=z\).

For that type, let

\(\displaystyle \ell_t=\min\{A_t-p_t,\ r_{f_t}\}.\)

Give one copy of category \(f_t\) to every agent whose label satisfies

\(\displaystyle p_t\leq i<p_t+\ell_t.\)

Increase \(p_t\) by \(\ell_t\) and decrease \(r_{f_t}\) by \(\ell_t\). If the block finishes, increase \(n_t\) by one and reset \(p_t=0\).

As soon as \(r_{f_t}=0\), end the epoch and recompute favorite available categories.

A depletion must occur during this step: otherwise all outstanding tickets through timestamp \(z\) would be processed with positive supplies remaining, contradicting the defining inequality \(F_j(z)\geq r_j\).

There are at most \(\tau\) blocks at any timestamp, because \(h_t>0\). Thus this step explicitly processes at most \(\tau\) blocks per epoch.

4.4 Correctness of the simulation

Inductively, the stored state is an exact prefix of the conceptual ticket order.

During the skipped part, total demand for every category is strictly smaller than its remaining supply. No category disappears, so the fixed favorites \(f_t\) agree with every conceptual greedy choice.

At timestamp \(z\), the algorithm follows the specified order of types and labels and stops precisely when a category disappears. The next epoch recomputes favorites before processing any further ticket.

Thus the compressed algorithm produces exactly the same bundles as the individual weighted picking procedure. Every epoch exhausts one available category, so there are at most \(m\) epochs. At termination all \(G\) goods have been allocated.

5. Output size and polynomial running time

5.1 At most one new interval boundary per depletion

We maintain the additional invariant that every positive \(p_t\) is an existing boundary in type \(t\)’s interval partition.

A skipped update assigns constant additional bundles on the two ranges separated by \(p_t\), so it introduces no new boundary.

When processing a block at timestamp \(z\), the updated range begins at the existing boundary \(p_t\). Its endpoint is either:

  • \(A_t\), when the block finishes; or
  • an internal label where the chosen category is exhausted.

Only the second case can create a new boundary, and that case ends the epoch immediately.

Consequently, each category depletion creates at most one new interval. Starting from \(\tau\) intervals and having at most \(m\) depletions, the final interval count is at most \(\tau+m\).

5.2 Converting intervals to rational classes

For a final interval \(I\) of type \(t\), carrying bundle \(b\), assign mass

\(\displaystyle \lambda_{t,b}=\frac{|I|}{N}.\)

Combine intervals carrying the same bundle of the same type. Every resulting mass is positive and rational. The identities

\(\displaystyle \sum_b\lambda_{t,b}=\frac{A_t}{N}=\mu_t,\qquad \sum_{t,b}\lambda_{t,b}b_j=\frac{G_j}{N}=q_j\)

establish completeness.

Every positive-mass class contains at least one conceptual agent. The weighted picking lemma therefore supplies the required WEF1 comparison between any two distinct classes, including classes of the same type. A class compared with itself satisfies the condition by nonnegativity.

5.3 Bit complexity

The products defining \(N\) and \(H\) have \(O(L)\) bits: the sums of the bit lengths of their factors are bounded by the input length.

Likewise,

\(\displaystyle \log(G+1),\quad \log(\max_t h_t+1),\quad \log(B+1) =O(L+\log(m+1)).\)

Counters and bundle coordinates are at most \(G\); label endpoints are at most \(N\). Demand calculations also involve only integers of polynomial bit length.

Each epoch uses:

  • polynomially many rational comparisons to determine favorites;
  • \(O(\log(B+1))\) binary-search evaluations, each using \(O(\tau+m)\) integer arithmetic operations;
  • interval updates on at most \(\tau+m\) stored intervals;
  • explicit processing of at most \(\tau\) blocks at the selected timestamp.

There are at most \(m\) epochs, and all stored bundles have \(m\) binary-encoded coordinates. Thus both running time and output length are polynomial in \(m,\tau,L\).

Conclusion

The exact mass-based problem is polynomial-time solvable. Clearing denominators is used only conceptually: binary search and interval updates simulate the exponentially large finite instance without enumerating its agents or goods. The output is a complete strongly WEF1 assignment with at most \(\tau+m\) positive-mass classes.
