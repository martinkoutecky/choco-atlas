The continuous mirror question, as graded

Given a finite type set \(T\), rational masses \(\mu_t\) summing to \(1\), a rational piecewise-affine coalition-value function \(v(q)\) for \(0\le q\le\mu\), and a finite library of policy-rule templates with bounded coefficients, decide whether coefficients \(z\) and payoff rates \(p_t\) exist such that \(\iota(q)=\sum_j z_j\psi_j(q)\), \(\iota(\mu)=0\), \(p\cdot\mu=v(\mu)\), and \(p\cdot q\ge v(q)+\iota(q)\) for every coalition-mass vector \(q\).

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a nonempty list \(T\) of \(\tau\) types with positive binary-rational masses \(\mu_t\), summing to \(1\). Here \(\tau\) is the support size, not the number of possible types. Coalitions are all real vectors in \(Q=\prod_{t\in T}[0,\mu_t]\).
The input includes a rational piecewise-affine value function \(v:Q\to\mathbb R_{\geq0}\), promised to satisfy \(v(0)=0\), \(v(\mu)>0\), and \(v(q+r)\geq v(q)+v(r)\) whenever \(q,r,q+r\in Q\).
A library of \(m\) rational piecewise-affine templates \(\psi_j:Q\to\mathbb R\), each satisfying \(\psi_j(0)=0\), and finite rational bounds \(a_j\leq b_j\) are also given. Each function is encoded by an explicit finite partition of \(Q\) into cells specified by rational strict or weak linear inequalities, with a rational affine formula on each cell; continuity is not required.
Coefficients \(z_j\in[a_j,b_j]\) are real and define monetary incentives \(\iota(q)=\sum_{j=1}^{m}z_j\psi_j(q)\); positive incentives are subsidies and negative incentives are taxes. Payoff rates \(p\in\mathbb R^\tau\) are constant within each type.
Feasibility means \(\iota(\mu)=0\), \(p\cdot\mu=v(\mu)\), and \(p\cdot q\geq v(q)+\iota(q)\) for every \(q\in Q\). Let \(L\) be the total binary input length, including all cells, formulas, masses, and coefficient bounds.

Is this feasibility problem solvable in polynomial time in \(m,\tau,L\), or is it \(\mathrm{NP}\)-hard?

For finite normalized superadditive industrial-symbiosis games, unrestricted incentive-rule selection guarantees implementability while leaving the grand-coalition value unchanged ([discrete result](https://arxiv.org/pdf/2006.01784)).
No result settling this exact bounded-library, coalition-mass feasibility problem was located.

Modeling choices made when packaging the task

  • Restored the discrete domain assumptions: nonnegative coalition values, superadditivity under addition of disjoint coalition masses, and strictly positive grand-coalition value; these are input promises.
  • Interpreted normalization in an atomless society as zero value at the zero mass vector. A positive mass of one type can contain many agents, so no zero-value condition is imposed on coordinate axes.
  • Specified the previously undefined template domain and encoding as rational piecewise-affine functions given by explicit polyhedral partitions, allowing discontinuities and fixing boundary membership through strict or weak inequalities.
  • Required templates to vanish at zero so incentives preserve the empty-coalition normalization.
  • Interpreted bounded coefficients as real variables in input-specified finite rational intervals, allowing subsidies, taxes, and zero coefficients.
  • Kept payoff rates real and unrestricted in sign, as in transferable-utility core allocations; retained the graded question's requirement that rates be constant within each type.
  • Used m for the library size and L for the total encoded input length because this problem has no candidate or alternative count.

Exact classification

On the promised inputs, feasibility is \(\mathrm{coNP}\)-complete under polynomial-time many-one reductions. Equivalently, infeasibility is \(\mathrm{NP}\)-complete.

This holds even when the value function is additive, the masses are equal dyadic rationals, and every coefficient interval has positive width.

Consequently, the problem has a polynomial-time algorithm exactly if \(\mathrm{P}=\mathrm{NP}\). It is \(\mathrm{NP}\)-hard under polynomial-time Turing reductions. Under many-one reductions, calling feasibility itself \(\mathrm{NP}\)-hard would be equivalent to \(\mathrm{NP}=\mathrm{coNP}\). Thus the proposed dichotomy needs a qualification about the reduction notion.

1. A reduction preserving all promises

We construct, from a Boolean formula \(\Phi\) in conjunctive normal form with at most three literals per clause, an instance satisfying

\(\text{the constructed instance is feasible}\quad\Longleftrightarrow\quad\Phi\text{ is unsatisfiable}.\)

We use the standard \(\mathrm{NP}\)-completeness of three-literal satisfiability; its complement is therefore \(\mathrm{coNP}\)-complete. [Karp’s original paper](https://www2.seas.gwu.edu/~simhaweb/champalg/tsp/papers/KarpOriginal.pdf).

Let \(\Phi\) have variables \(x_1,\ldots,x_n\) and clauses \(C_1,\ldots,C_k\), where \(n,k\geq1\). Restricting to these nonempty instances does not affect hardness.

1.1 Society and value function

Let \(N\) be the smallest power of two satisfying \(N\geq\max\{n,2\}\). Set

\(T=\{1,\ldots,N\},\qquad \tau=N,\qquad \mu_i=\frac1N,\qquad Q=\prod_{i=1}^{N}[0,\mu_i].\)

These masses are positive dyadic rationals and sum to \(1\). Define the single affine function

\(v(q)=\sum_{i=1}^{N}q_i.\)

It is nonnegative on \(Q\), satisfies \(v(0)=0\) and \(v(\mu)=1\), and, whenever \(q,r,q+r\in Q\), satisfies

\(v(q+r)=v(q)+v(r).\)

Thus the superadditivity promise holds with equality.

Define the box

\(G=\prod_{i=1}^{N}\left[\frac{\mu_i}{4},\frac{3\mu_i}{4}\right].\)

For every \(q\in Q\), interpret the original Boolean variables by

\(x_i(q)=1\quad\Longleftrightarrow\quad q_i\geq\frac{\mu_i}{2},\qquad 1\leq i\leq n.\)

Let \(s_j(q)\in\{0,1\}\) indicate whether \(C_j\) is true under this assignment. Also define

\(g(q)=\mathbf 1_{\{q=\mu\}},\qquad h(q)=\mathbf 1_G(q).\)

The sets \(G\) and \(\{\mu\}\) are disjoint.

1.2 Templates and bounds

For convenience, index the \(m=k+1\) templates by \(0,1,\ldots,k\). Define

\(\psi_0(q)=-k\,g(q)-\left(k-\frac12\right)h(q),\)

and, for \(1\leq j\leq k\),

\(\psi_j(q)=g(q)+h(q)s_j(q).\)

Give their coefficients the bounds

\(z_0\in[0,1],\qquad z_j\in[1,2]\quad(1\leq j\leq k).\)

Every interval has positive width. Since \(0\notin G\) and \(0\neq\mu\), every template satisfies \(\psi_j(0)=0\).

1.3 These are polynomial-size explicit partitions

The indicator notation above describes functions that admit the required explicit cell encodings. It does not conceal an exponential partition.

First partition \(Q\) into \(G\), the singleton \(\{\mu\}\), and polynomially many cells covering their complement.

To do this, list the \(2N\) weak inequalities defining \(G\). The cells \(E_\ell\) where the first violated inequality is inequality \(\ell\) partition \(Q\setminus G\). Each \(E_\ell\) uses preceding weak inequalities and one strict inequality.

Also define, for \(1\leq i\leq N\),

\(D_i=\{q\in Q:q_h=\mu_h\text{ for }h<i,\ q_i<\mu_i\}.\)

Because every coordinate of \(q\in Q\) is at most its mass, the cells \(D_i\) partition \(Q\setminus\{\mu\}\). Consequently, the intersections \(E_\ell\cap D_i\) partition \(Q\setminus(G\cup\{\mu\})\), using at most \(2N^2\) cells. Equalities are expressible by pairs of weak inequalities.

Inside \(G\), each clause template needs at most four cells: one for the first true literal at each of its at most three positions, and one where all its literals are false. Literal truth and falsity each correspond to one strict or weak threshold inequality. The template is constant on each such cell.

Thus every template has polynomially many cells and inequalities. Empty cells can be discarded using the polynomial-time strict-feasibility test in Section 2.3. All formulas are rational constants, and all numerical data have polynomial binary length. Since \(N\) is polynomially bounded in the formula size, the entire construction is polynomial-time.

1.4 Grand-coalition neutrality forces all coefficients

At the grand coalition,

\(\psi_0(\mu)=-k,\qquad \psi_j(\mu)=1\quad(1\leq j\leq k).\)

Therefore neutrality requires

\(\sum_{j=1}^{k}z_j-kz_0=0.\)

Equivalently,

\(\sum_{j=1}^{k}(z_j-1)+k(1-z_0)=0.\)

Every term is nonnegative under the prescribed bounds. Hence every feasible solution must satisfy

\(z_0=z_1=\cdots=z_k=1.\)

Although all coefficient intervals have positive width, neutrality forces a unique coefficient vector.

1.5 Coalition inequalities force all payoff rates

For each type \(i\), let \(q^{(i)}=\mu_i e_i\), where \(e_i\) is the \(i\)-th coordinate vector.

Because \(N\geq2\), this coalition has a zero coordinate, so it lies outside \(G\), and it is not \(\mu\). Every template therefore vanishes at \(q^{(i)}\). Its coalition inequality gives

\(p_i\mu_i\geq v(q^{(i)})=\mu_i.\)

Since \(\mu_i>0\), we obtain \(p_i\geq1\). Efficiency requires

\(\sum_{i=1}^{N}p_i\mu_i=v(\mu)=1=\sum_{i=1}^{N}\mu_i.\)

The positive-weighted sum of the nonnegative quantities \(p_i-1\) is zero. Thus

\(p_i=1\qquad(1\leq i\leq N).\)

In particular, every feasible solution satisfies \(p\cdot q=v(q)\) for every coalition.

1.6 Exact equivalence with unsatisfiability

With the forced coefficient vector, the incentive on \(G\) is

\(\iota(q)=\sum_{j=1}^{k}s_j(q)-\left(k-\frac12\right).\)

At \(\mu\), it is zero. Outside \(G\cup\{\mu\}\), it is also zero.

Suppose first that \(\Phi\) is unsatisfiable. Every assignment falsifies at least one clause, so

\(\sum_{j=1}^{k}s_j(q)\leq k-1\qquad(q\in G).\)

Hence \(\iota(q)\leq-\frac12\) on \(G\) and \(\iota(q)=0\) elsewhere. Choosing all coefficients and payoff rates equal to \(1\) satisfies the bounds, neutrality, efficiency, and every coalition inequality:

\(p\cdot q=v(q)\geq v(q)+\iota(q).\)

The instance is feasible.

Conversely, suppose that \(\Phi\) has a satisfying assignment. Represent it by choosing

\(q_i=\frac{3\mu_i}{4}\text{ when }x_i=1,\qquad q_i=\frac{\mu_i}{4}\text{ when }x_i=0,\)

and choosing \(\mu_i/4\) for the unused coordinates. This gives a point \(q\in G\) satisfying every clause. Consequently,

\(\iota(q)=k-\left(k-\frac12\right)=\frac12.\)

Every putative feasible solution has the coefficient vector and payoff rates forced above, so its coalition inequality at this point would require

\(v(q)=p\cdot q\geq v(q)+\frac12,\)

which is impossible.

This proves the equivalence and establishes \(\mathrm{coNP}\)-hardness of feasibility, as well as \(\mathrm{NP}\)-hardness of infeasibility.

2. Feasibility belongs to \(\mathrm{coNP}\)

We now prove that every infeasible promised instance has a polynomial-size certificate checkable in polynomial time. The argument handles strict cells and discontinuous functions explicitly.

2.1 Joint cells and their closures

Choose one input cell for \(v\) and one input cell for each template. Their intersection with \(Q\) is a joint cell \(C\). There are finitely many such choices, though potentially exponentially many.

For a nonempty joint cell, write its constraints as

\(C=\{q\in Q:Aq\leq b,\ Dq<e\}.\)

Let its weak relaxation be

\(P_C=\{q\in Q:Aq\leq b,\ Dq\leq e\}.\)

We claim that \(P_C=\overline C\). The inclusion \(\overline C\subseteq P_C\) follows because the relaxed inequalities and \(Q\) are closed.

For the reverse inclusion, choose \(c\in C\). For any \(x\in P_C\) and \(0<t\leq1\), set \(q_t=(1-t)x+tc\). Convexity preserves all weak inequalities and membership in \(Q\). Moreover,

\(Dq_t=(1-t)Dx+tDc<e.\)

Thus \(q_t\in C\), and \(q_t\) tends to \(x\) as \(t\) tends to zero. This proves the claim.

Let \(\widehat v_C\) and \(\widehat\psi_{j,C}\) denote the affine formulas selected by the joint cell, viewed as affine functions on the entire ambient space. For fixed \(p,z\), define

\(F_C(q;p,z)=p\cdot q-\widehat v_C(q)-\sum_{j=1}^{m}z_j\widehat\psi_{j,C}(q).\)

This is affine and continuous in \(q\). Therefore,

\(F_C(q;p,z)\geq0\text{ for every }q\in C \quad\Longleftrightarrow\quad F_C(q;p,z)\geq0\text{ for every }q\in P_C.\)

This uses the selected affine formulas at closure points. They need not equal the actual function values assigned by other cells at those points. Their inequalities remain necessary because they are limits of inequalities within \(C\).

2.2 An equivalent finite linear system

The set \(P_C\) is a nonempty bounded rational polyhedron, hence a polytope and the convex hull of its finitely many vertices. Since \(F_C\) is affine in \(q\), its nonnegativity on \(P_C\) is equivalent to

\(p\cdot u\geq\widehat v_C(u)+\sum_{j=1}^{m}z_j\widehat\psi_{j,C}(u)\)

for every vertex \(u\) of \(P_C\).

For fixed \(u\), this is a linear inequality in \((p,z)\). Taking these inequalities over all nonempty joint cells, together with coefficient bounds and the two required equalities, produces a finite rational linear system exactly equivalent to feasibility. The original partitions cover \(Q\), so no coalition is omitted.

Each vertex has polynomial binary length. Indeed, at a vertex the tight constraint normals span the \(\tau\)-dimensional ambient space: otherwise a sufficiently small perturbation in a common null direction would express the point as the midpoint of two distinct feasible points. Select \(\tau\) independent tight constraints. After clearing denominators, their integer coefficients have polynomial binary length, and Cramer’s rule expresses every vertex coordinate as a ratio of determinants. The determinant bounds give polynomial binary length in \(\tau,L\).

Evaluating the selected affine formulas at such a vertex also takes polynomial time and produces rational coefficients of polynomial length.

2.3 A polynomial certificate of infeasibility

Put \(d=\tau+m\), the number of real decision variables.

We use the finite form of Helly’s theorem: if a finite family of convex subsets of \(\mathbb R^d\) has empty intersection, some subfamily of at most \(d+1\) already has empty intersection. Our finite linear system consists of halfspaces in \(\mathbb R^d\), with equalities represented by two halfspaces, so the theorem applies. [A primary research source stating this finite form](https://epubs.siam.org/doi/10.1137/060656309).

Thus, if the system is infeasible, at most \(d+1\) of its inequalities suffice to witness infeasibility.

A certificate lists these inequalities. For a vertex-derived inequality, it supplies:

  • The input cell index for each function.
  • The rational point \(u\) used in that inequality.

The verifier reconstructs \(C\), checks that \(C\) is nonempty and \(u\in P_C\), and evaluates the selected affine formulas at \(u\). It need not verify that \(u\) is a vertex: every point of \(P_C\) yields a necessary inequality. The existence of a short certificate follows from the polynomial-size vertices established above.

To check nonemptiness of a cell with strict inequalities, solve the rational linear program that maximizes \(\eta\) subject to

\(q\in Q,\qquad Aq\leq b,\qquad Dq+\eta\mathbf1\leq e,\qquad 0\leq\eta\leq1.\)

The cell is nonempty exactly when this program is feasible with optimum strictly positive. A point satisfying finitely many strict inequalities has a positive minimum slack, and a positive \(\eta\) ensures every strict inequality. When there are no strict inequalities, a nonempty cell permits \(\eta=1\).

Finally, the verifier checks that the listed linear inequalities are jointly infeasible. Rational linear programming, including feasibility and exact optimization, is polynomial-time in the binary encoding length. [Khachiyan’s polynomial algorithms](https://www.mathnet.ru/eng/zvmmf5239).

There are at most \(d+1\) listed inequalities, each with polynomial-size data. All checks therefore take polynomial time.

For soundness, every accepted listed inequality is necessary for original feasibility; an infeasible collection of such inequalities rules out a feasible solution. For completeness, Helly’s theorem supplies such a collection whenever the equivalent finite system is infeasible.

Hence infeasibility belongs to \(\mathrm{NP}\), and feasibility belongs to \(\mathrm{coNP}\).

3. Consequences for the question

Combining the reduction and certificate argument proves the claimed \(\mathrm{coNP}\)-completeness.

A polynomial-time feasibility algorithm would decide three-literal satisfiability by constructing the instance and reversing its answer. Therefore it would imply \(\mathrm{P}=\mathrm{NP}\). Conversely, if \(\mathrm{P}=\mathrm{NP}\), then \(\mathrm{coNP}=\mathrm{P}\), so the membership result gives a polynomial-time feasibility algorithm.

The same construction is a one-query polynomial-time Turing reduction from satisfiability to feasibility. Thus feasibility is \(\mathrm{NP}\)-hard under Turing reductions.

For many-one reductions, the distinction is essential. If feasibility were \(\mathrm{NP}\)-hard under such reductions, its membership in \(\mathrm{coNP}\) would imply \(\mathrm{NP}\subseteq\mathrm{coNP}\), and taking complements would give equality. Conversely, if \(\mathrm{NP}=\mathrm{coNP}\), its \(\mathrm{coNP}\)-completeness makes it \(\mathrm{NP}\)-hard.

The precise classification is therefore complete: feasibility is \(\mathrm{coNP}\)-complete; infeasibility is \(\mathrm{NP}\)-complete.
