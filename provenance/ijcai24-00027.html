The continuous mirror question, as graded

Given \( \tau \) exchangeable types, rational population proportions \( \mu\in\mathbb{Q}_+^\tau \) with \( \sum_t\mu_t=1 \), and a finite catalogue of anonymous coalition templates \( (q^k,w_k) \) with \( q^k\in\mathbb{Z}_+^\tau \), find \( \lambda_k\ge0 \) maximizing \( \sum_k w_k\lambda_k \) subject to \( \sum_k q^k_t\lambda_k=\mu_t \) for every type \(t\).

The input also explicitly lists \(m\ge1\) anonymous coalition templates \((q^k,w_k)\), with \(q^k\in\mathbb Z_{\ge0}^{\tau}\setminus\{0\}\) and \(w_k\in\mathbb Q\); all integers and rationals are binary encoded. Let \(L\) be the total input bit length.

Result

The exact optimization problem is solvable in time polynomial in \(m,\tau,L\). This holds for arbitrary support size and binary encoded template coefficients. The algorithm returns an exact rational maximizer whenever the instance is feasible.

1. Exact linear programming formulation

Define \(Q\in\mathbb Z_{\ge 0}^{\tau\times m}\) by \(Q_{tk}=q_t^k\), and let \(w=(w_1,\ldots,w_m)\) and \(\mu=(\mu_1,\ldots,\mu_\tau)\).

The given problem is precisely the rational linear program

\(\max\{w^{\mathsf T}\lambda:Q\lambda=\mu,\ \lambda\in\mathbb R_{\ge 0}^{m}\}\).

Indeed, its variables are exactly the listed template intensities, its equalities are exactly the required mass balances, and its objective is exactly the stated welfare. Divisibility means that no integrality constraints are imposed.

There are \(m\) variables and \(\tau\) equality constraints. If an inequality representation is needed, replace the equalities by \(Q\lambda\le\mu\) and \(-Q\lambda\le-\mu\), and add \(-I_m\lambda\le 0\). This representation has \(2\tau+m\) inequalities and encoding length polynomial in \(m,\tau,L\). Every coefficient is already supplied by the input or belongs to \(\{-1,0,1\}\).

2. Feasibility guarantees an attained finite optimum

Let \(P=\{\lambda\in\mathbb R_{\ge 0}^{m}:Q\lambda=\mu\}\).

For each template, define its total consumption coefficient \(s_k=\sum_{t=1}^{\tau}q_t^k\). Since \(q^k\) is a nonzero vector of nonnegative integers, \(s_k\ge 1\).

Summing all mass balance equalities gives, for every \(\lambda\in P\),

\(\sum_{k=1}^{m}s_k\lambda_k=\sum_{t=1}^{\tau}\mu_t=1\).

Nonnegativity therefore implies \(\sum_{k=1}^{m}\lambda_k\le 1\), and hence \(0\le\lambda_k\le 1\) for every coordinate.

Thus \(P\) is bounded. It is also closed, because it is defined by linear equalities and non-strict inequalities. If \(P\) is nonempty, it is compact, and the continuous function \(w^{\mathsf T}\lambda\) attains a finite maximum on \(P\). This reasoning allows negative welfare coefficients and does not require independent mass balance equations.

3. An exact maximizer has polynomial encoding length

We prove this explicitly to address the requirement to return an exact vector.

Assume \(P\) is nonempty. Choose a maximizer \(\lambda^*\) having the fewest positive coordinates, and define \(S=\{k:\lambda_k^*>0\}\).

Claim. The columns of \(Q\) indexed by \(S\) are linearly independent.

Suppose otherwise. There is a nonzero vector \(d\in\mathbb R^m\), supported on \(S\), with \(Qd=0\). For sufficiently small \(\varepsilon>0\), both \(\lambda^*+\varepsilon d\) and \(\lambda^*-\varepsilon d\) remain nonnegative and satisfy the mass balances. Optimality of \(\lambda^*\) consequently forces \(w^{\mathsf T}d=0\): either nonzero sign would make one of these two perturbations improve welfare.

Moreover, summing the coordinates of \(Qd=0\) gives \(\sum_k s_kd_k=0\). Since all \(s_k>0\), the nonzero vector \(d\) must have both positive and negative coordinates. Define

\(\alpha=\min_{k:d_k>0}\lambda_k^*/d_k>0\).

Then \(\lambda'=\lambda^*-\alpha d\) is nonnegative and satisfies \(Q\lambda'=\mu\). Its welfare equals that of \(\lambda^*\), because \(w^{\mathsf T}d=0\). At least one positive coordinate becomes zero, and no coordinate outside \(S\) changes. This contradicts the choice of \(\lambda^*\), proving the claim.

Write \(r=|S|\). Independence implies \(1\le r\le\tau\), and we can select \(r\) rows so that the resulting square matrix \(B\) of these columns is nonsingular. Let \(b\) be the corresponding subvector of \(\mu\). Then \(B\lambda_S^*=b\).

Write each input mass as \(\mu_t=a_t/d_t\), with positive integer denominator \(d_t\), and set \(D=\prod_{t=1}^{\tau}d_t\). The binary length of \(D\) is \(O(L)\). The vector \(v=Db\) is integral and satisfies \(0<v_i\le D\).

For each column index \(j\), let \(B_j\) be \(B\) with that column replaced by \(v\). Cramer's rule yields

\(\lambda_{S,j}^*=\det(B_j)/(D\det(B))\).

Set \(H=\max(1,D,\max_{t,k}q_t^k)\). Its binary length is \(O(L)\). By the determinant expansion, \(|\det(B)|\le r!H^r\) and \(|\det(B_j)|\le r!H^r\). Consequently, the numerator and denominator of each displayed rational have bit length \(O((r+1)L+r\log(r+1))\).

Thus some exact maximizer is rational, uses at most \(\tau\) templates, and has total encoding length polynomial in \(m,\tau,L\).

4. Polynomial-time algorithm and relation to SMART

We use the standard exact rational linear programming theorem: for an explicitly given linear program with binary encoded rational coefficients, a deterministic algorithm runs in time polynomial in its dimensions and encoding length, detects infeasibility or unboundedness, and otherwise returns an exact rational optimal solution. This is a bit complexity guarantee, and it permits redundant constraints and feasible sets of lower dimension. See [the polynomial-time theorem in these University of Washington notes](https://courses.cs.washington.edu/courses/cse521/22au/521-lecture-16.pdf) and [Trevisan's discussion of exact rational solution recovery](https://lucatrevisan.github.io/cs261/lecture05.pdf).

Apply that theorem to the formulation in Section 1. Its dimensions and encoding length are polynomial in \(m,\tau,L\); Section 2 excludes unboundedness whenever it is feasible. The algorithm therefore either reports infeasibility or returns the requested exact maximizer in polynomial time.

SMART concerns partitions of a finite agent set into disjoint coalitions, as defined in [the cited paper](https://www.ijcai.org/proceedings/2024/0027.pdf). The present model instead explicitly permits real intensities for an explicitly listed catalogue. Its polynomial-time classification follows directly from exact rational linear programming and requires no transfer of SMART's operation bound.
