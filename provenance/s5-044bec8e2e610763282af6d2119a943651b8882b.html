The continuous mirror question, as graded

Given rational type masses \(\mu_\theta\), per-capita category quotas \(q_c\), eligibility and priority orders over types, and a target type \(\theta^\star\), decide whether there is a valid mass allocation \(x_{\theta c}\) with \(\sum_c x_{\theta^\star c}>0\). The allocation must respect type masses, quotas, eligibility, and priorities: if \(x_{\theta c}>0\), every type \(\theta'\succ_c\theta\) must be fully allocated. It must also be Pareto efficient among priority-respecting allocations, meaning no such allocation can increase one type’s served mass without decreasing another’s.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support \(\Theta\): the list of \(\tau\) types with positive binary rational masses \(\mu_\theta\), normalized by \(\sum_\theta\mu_\theta=1\). Here \(\tau\) is the support size, not the number of possible types.
There are \(m\geq1\) categories \(C\), each with a nonnegative binary rational per-capita quota \(q_c\), an explicitly listed eligible set \(E_c\subseteq\Theta\), and a total preorder \(\succeq_c\) on \(E_c\). Ties are allowed; \(\succ_c\) denotes strict priority. The target \(\theta^\star\) belongs to \(\Theta\).
An allocation has real entries \(x_{\theta c}\geq0\), served masses \(s_\theta(x)=\sum_c x_{\theta c}\leq\mu_\theta\), category totals \(\sum_\theta x_{\theta c}\leq q_c\), and \(x_{\theta c}=0\) whenever \(\theta\notin E_c\). Individuals demand at most one unit and are indifferent between categories.
Priority respect means \(x_{\theta c}>0\Longrightarrow s_{\theta'}(x)=\mu_{\theta'}\) for every \(\theta'\succ_c\theta\); tied types impose no such requirement on each other.
An allocation is valid if it also admits no allocation \(y\) satisfying these same mass, quota, eligibility, and priority constraints with \(s_\theta(y)\geq s_\theta(x)\) for all types and strict inequality for at least one type.

Is deciding whether a valid allocation with \(s_{\theta^\star}(x)>0\) exists solvable in polynomial time in \(m,\tau,L\), or is it NP-hard, where \(L\) is the total input bit length?

For finite unit-demand agents with integer category quotas, deciding whether a designated agent receives positive allocation in some valid allocation is NP-hard, even allowing fractional allocations; finding an unrestricted valid allocation is polynomial-time solvable. [Source](https://maeichho.github.io/publication/ec23/ec23.pdf)

Result

The problem is \(\mathrm{NP}\)-hard, even when every supported type has the same mass \(\mu_\theta=1/\tau\). A direct normalization transfers the finite-agent hardness result to the stated model.

Here, rational numbers are encoded by binary numerators and denominators.

Source problem and reduction

The source problem has an explicitly listed set \(A\) of \(n\geq1\) unit-demand agents, integer category quotas \(Q_c\), eligible sets \(E_c\subseteq A\), total preorders \(\succeq_c\), and a designated agent \(a^\star\). Allocations may be fractional. Its priority constraint requires every strictly higher-priority agent to receive a full unit whenever a lower-priority agent receives positive allocation. Validity means Pareto efficiency among allocations satisfying these constraints.

Deciding whether some valid allocation gives \(a^\star\) positive allocation is \(\mathrm{NP}\)-hard. This is Proposition 4 of the supplied paper; its Definition 3 explicitly defines inclusion through positive allocation, and Section 2 uses the same priority and Pareto constraints as the task. [Banerjee, Eichhorn, and Kempe](https://maeichho.github.io/publication/ec23/ec23.pdf)

From such an instance, construct the society as follows:

  • Let \(\Theta=\{\theta_a:a\in A\}\), so \(\tau=n\).
  • Set \(\mu_{\theta_a}=1/n\) for every \(a\in A\).
  • Retain the categories, and set \(q_c=Q_c/n\).
  • Replace each eligible agent \(a\) by \(\theta_a\), preserving every priority comparison and tie.
  • Set \(\theta^\star=\theta_{a^\star}\).

Every mass is positive, and \(\sum_{\theta\in\Theta}\mu_\theta=n(1/n)=1\).

Exact correspondence of allocations

Write \(z_{ac}\) for a source allocation and \(x_{\theta_a c}\) for a society allocation. Define the inverse transformations

\(x_{\theta_a c}=z_{ac}/n,\qquad z_{ac}=n x_{\theta_a c}.\)

We verify that these transformations preserve all required properties.

Mass and quota constraints. Nonnegativity is preserved because \(n>0\). For each agent and category,

\(\sum_c z_{ac}\leq1\ \Longleftrightarrow\ \sum_c x_{\theta_a c}\leq1/n=\mu_{\theta_a},\)

\(\sum_a z_{ac}\leq Q_c\ \Longleftrightarrow\ \sum_a x_{\theta_a c}\leq Q_c/n=q_c.\)

Eligibility. The eligible pairs are unchanged under relabeling, and \(z_{ac}=0\) if and only if \(x_{\theta_a c}=0\).

Priority respect. Suppose \(a'\succ_c a\). Then

\(z_{ac}>0\ \Longleftrightarrow\ x_{\theta_a c}>0,\)

and

\(\sum_d z_{a'd}=1\ \Longleftrightarrow\ \sum_d x_{\theta_{a'}d}=1/n=\mu_{\theta_{a'}}.\)

Consequently, each source priority implication is equivalent to the corresponding society priority implication. Ties impose no implication in either model.

Thus scaling gives a bijection between the two sets of constraint-satisfying allocations, including all real fractional allocations.

Pareto efficiency. For any two corresponding source allocations \(z,w\) and society allocations \(x,y\),

\(s_{\theta_a}(y)-s_{\theta_a}(x)=\frac1n\left(\sum_c w_{ac}-\sum_c z_{ac}\right).\)

Since \(1/n>0\), the difference is nonnegative, or strictly positive, exactly when its source counterpart is. The feasible-allocation bijection therefore preserves Pareto domination in both directions. In particular, \(z\) is valid if and only if \(x\) is valid.

Finally,

\(s_{\theta^\star}(x)=\frac1n\sum_c z_{a^\star c}>0\ \Longleftrightarrow\ \sum_c z_{a^\star c}>0.\)

The source instance and constructed society consequently have the same answer.

Encoding size and conclusion

The construction retains the explicitly listed agents as supported types; it does not enumerate any ambient universe of possible types. Hence \(\tau=n\), and the number of categories is unchanged.

Each mass \(1/n\) requires \(O(\log n)\) bits. Each quota \(Q_c/n\) requires \(O(\log(Q_c+1)+\log n)\) bits before optional fraction reduction. Eligibility lists and priority tiers are copied. The output length and construction time are therefore polynomial in the source input length.

This is a polynomial-time many-one reduction from the stated \(\mathrm{NP}\)-hard problem. It completely settles the requested hardness alternative: a polynomial-time algorithm in \(m,\tau,L\) would imply \(\mathrm{P}=\mathrm{NP}\).
