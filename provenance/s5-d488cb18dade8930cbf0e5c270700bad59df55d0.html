The continuous mirror question, as graded

Given \(m\), ordered support locations \(z_1<\cdots<z_\tau\), positive rational masses \(\mu_i\) summing to \(1\), and the paper's entrance-fee oracle \(e\), find an optimal facility profile \(\ell\in\mathbb{R}^m\) for either \(\sum_{i=1}^{\tau}\mu_i\min_{j\le m}(|z_i-\ell_j|+e(\ell_j))\) or \(\max_{i\le\tau}\min_{j\le m}(|z_i-\ell_j|+e(\ell_j))\), using the paper's input and oracle conventions.

Packaged proof task (what the prover saw — nothing else)

A society is supplied by its support: ordered locations \(z_1<\cdots<z_\tau\) and positive masses \(\mu_i\) summing to \(1\), all binary rationals. Here \(\tau\) is the support size, not the number of possible types; \(L\) is the total binary input length, including the positive integer \(m\).
An entrance fee \(e:\mathbb R\to\mathbb R_{\ge0}\cup\{+\infty\}\), finite somewhere, is supplied by an exact oracle. It evaluates \(e(x)\) and, given binary integers \(a>0,b\) and a nonempty closed interval \(I\) (possibly unbounded), returns the minimum value of \(a e(x)+bx\) and a minimizer whenever the minimum is finite; otherwise it reports the appropriate infinite infimum. Promise that every finite such infimum is attained.
Use the oracle-relative exact-real arithmetic model: arithmetic, comparisons and oracle calls have unit cost, while reading or constructing binary integer arguments costs their bit length. State running times in \(m,\tau,L\).
A facility profile is \(\ell\in\mathbb R^m\); coincident and unused facilities are allowed. Travel cost per unit distance is \(1\), and each type incurs \(c_i(\ell)=\min_{1\le j\le m}(|z_i-\ell_j|+e(\ell_j))\). Equal-cost facilities are selected by smallest entrance fee, then rightmost location.
The two optimization problems ask for an exact optimal profile minimizing respectively \(\sum_{i=1}^{\tau}\mu_i c_i(\ell)\) and \(\max_{1\le i\le\tau}c_i(\ell)\).

For each objective, is this support-encoded mass optimization problem solvable in polynomial time in \(m,\tau,L\) under the stated oracle model, or is it NP-hard?

For an explicit list of \(n\) agents, both objectives have a stated \(O(n^3m)\) algorithm with constant-cost entrance-fee oracle access ([Ma et al.](https://arxiv.org/html/2204.11282v2)). No result settling exactly the support-encoded rational-mass version was located.

Modeling choices made when packaging the task

  • Support locations were not given an encoding; they are binary rationals, and L includes locations, masses and m.
  • The source does not specify a bit-complexity model for real oracle answers; exact-real arithmetic and oracle calls have unit cost, with binary integer argument lengths charged explicitly.
  • The oracle's minimization output was unspecified; it returns both the minimum value and an attaining location.
  • Arbitrary entrance fees need not admit optimal locations; finite interval infima are promised attained, and the fee is finite somewhere.
  • Interval endpoint conventions were unspecified; oracle queries use nonempty closed intervals, including unbounded intervals, with infinite infima reported explicitly.
  • No distinctness or utilization requirement is imposed on facilities; coincident and unused facilities are allowed, and m is positive.
  • Travel cost is normalized to 1, and facility-selection ties use smallest entrance fee followed by rightmost location.

Result

Both objectives are polynomial-time solvable under the stated oracle model, and an exact optimal profile exists.

Let \(K=\min\{m,\tau\}\). Conservative running-time bounds, including construction of binary oracle arguments and output of all \(m\) facility locations, are:

  • Weighted sum: \(O(L^3+\tau^3L+K\tau^2+m)\).
  • Maximum cost: \(O(L+(K+1)\tau^2+m)\).

The proof below establishes the support-encoded result directly. The explicit-agent algorithm in [Ma et al., Section 3.2](https://arxiv.org/html/2204.11282v2) provides the motivation, but no expansion of rational masses into individual agents is needed.

1. Selected facilities serve contiguous support blocks

Write \(f_x(z)=|z-x|+e(x)\) for the cost of using a facility at \(x\).

Consider any profile containing at least one facility with finite entrance fee. Every support point then has finite cost, so facilities with infinite entrance fees are never selected. Collapse coincident facility locations, since their costs and tie-breaking attributes coincide.

For two remaining locations \(u<v\), define

\(d(z)=f_u(z)-f_v(z)=|z-u|-|z-v|+e(u)-e(v)\).

The distance difference equals \(u-v\) for \(z\le u\), equals \(2z-u-v\) for \(u\le z\le v\), and equals \(v-u\) for \(z\ge v\). Consequently, \(d\) is nondecreasing.

Suppose, towards a contradiction, that support points \(z_i<z_j\) select locations \(v\) and \(u\), respectively. Selection of a minimum-cost facility gives

\(d(z_i)\ge 0,\qquad d(z_j)\le 0.\)

Monotonicity implies

\(0\le d(z_i)\le d(z_j)\le 0,\)

so both differences vanish. Thus \(u\) and \(v\) are tied in cost at both support points and belong to the minimum-cost set at both points.

The prescribed tie-breaking rule gives a fixed preference between these two locations: smaller entrance fee first, then larger location. Selecting \(v\) at the first point requires this rule to prefer \(v\) over \(u\), whereas selecting \(u\) at the second requires the reverse. This is impossible.

Therefore selected locations are nondecreasing along the ordered support. In particular, the support points selecting any one location form a contiguous block. After unused facilities are discarded, there are at most \(K\) nonempty blocks.

This argument depends only on locations and costs, not on masses.

2. Exact weighted-sum optimization for one block

For \(1\le p\le q\le\tau\), define the one-facility block optimum

\(V_\Sigma(p,q)=\min_{x\in\mathbb R}\sum_{i=p}^{q}\mu_i\bigl(|z_i-x|+e(x)\bigr).\)

We will prove that this minimum exists and compute a minimizer.

Clearing denominators

Write each input mass as \(\mu_i=p_i/q_i\), with positive binary integers \(p_i,q_i\). Set

\(D=\prod_{i=1}^{\tau}q_i,\qquad w_i=p_i(D/q_i).\)

Then \(w_i\) is a positive integer, \(\mu_i=w_i/D\), and the normalization of the masses gives

\(\sum_{i=1}^{\tau}w_i=D.\)

The binary length of \(D\) is \(O(L)\), because the total binary length of the denominators is at most \(L\). Every \(w_i\), every sum of these weights, and every signed difference of such sums consequently has \(O(L)\) bits.

The numerical value of \(D\) may be large; its binary length is what matters.

Piecewise affine formulas

Precompute the prefix quantities

\(P_r=\sum_{i=1}^{r}w_i,\qquad R_r=\sum_{i=1}^{r}w_i z_i,\qquad P_0=R_0=0.\)

Fix a block \([p,q]\), and let \(A=P_q-P_{p-1}>0\). Cover the real line by the following closed intervals:

  • \(I_{p-1}=(-\infty,z_p]\).
  • \(I_r=[z_r,z_{r+1}]\) for \(p\le r<q\).
  • \(I_q=[z_q,\infty)\).

For each corresponding index \(r\), put

\(U_r=P_r-P_{p-1},\qquad B_r=2U_r-A,\qquad C_r=(R_q-R_r)-(R_r-R_{p-1}).\)

On \(I_r\), support points indexed at most \(r\) lie to the left of \(x\), and those indexed above \(r\) lie to its right. Hence

\(\sum_{i=p}^{q}w_i|z_i-x|=B_rx+C_r.\)

This identity also holds at interval endpoints, where the relevant distance is zero. Therefore the block objective on \(I_r\) is

\(\sum_{i=p}^{q}\mu_i\bigl(|z_i-x|+e(x)\bigr)=\dfrac{Ae(x)+B_rx+C_r}{D}.\)

Call the oracle with the binary integer arguments \(a=A>0\), \(b=B_r\), and interval \(I_r\). Both integer arguments have \(O(L)\) bits, since \(|B_r|\le A\le D\).

Attainment and reconstruction

The nonnegativity of all individual costs implies, on \(I_r\),

\(Ae(x)+B_rx\ge -C_r.\)

Thus none of these oracle calls can have infimum \(-\infty\). A call either has infimum \(+\infty\), or has a finite minimum with a supplied minimizer by the oracle promise.

Because \(e\) is finite somewhere and the intervals cover the real line, at least one call has finite infimum. Taking the smallest finite value after adding \(C_r\) and dividing by \(D\) therefore computes \(V_\Sigma(p,q)\), together with an attaining location.

There are \(q-p+2\) calls for this block. Over all blocks, their number is \(O(\tau^3)\). Prefix quantities make the formula construction use a constant number of exact-real operations per call, plus \(O(L)\) work for the binary integer arguments.

3. Exact maximum-cost optimization for one block

Define

\(V_{\max}(p,q)=\min_{x\in\mathbb R}\max_{p\le i\le q}\bigl(|z_i-x|+e(x)\bigr).\)

Only the extreme support locations of the block matter. Indeed, for \(z_p\le z_i\le z_q\),

\(|z_i-x|\le\max\{|z_p-x|,|z_q-x|\},\)

and the endpoints themselves belong to the block.

Set

\(t=\dfrac{z_p+z_q}{2},\qquad h=\dfrac{z_q-z_p}{2}.\)

The elementary endpoint-distance identity gives

\(\max_{p\le i\le q}\bigl(|z_i-x|+e(x)\bigr)=e(x)+h+|x-t|.\)

For completeness, \(\max\{|z_p-x|,|z_q-x|\}=\max\{x-z_p,z_q-x\}\): the other two signed distances are dominated because \(z_p\le z_q\). Substituting \(z_p=t-h\) and \(z_q=t+h\) yields \(h+|x-t|\).

Make exactly two oracle calls:

\(v_-=\inf_{x\in(-\infty,t]}\bigl(e(x)-x\bigr),\qquad v_+=\inf_{x\in[t,\infty)}\bigl(e(x)+x\bigr).\)

These use integer arguments \((a,b)=(1,-1)\) and \((1,1)\). Then

\(V_{\max}(p,q)=h+\min\{t+v_-,-t+v_+\}.\)

On the left interval, \(e(x)-x\ge -t\); on the right interval, \(e(x)+x\ge t\). Neither infimum is \(-\infty\). At least one is finite because \(e\) is finite somewhere. The oracle promise supplies an attaining minimizer for each finite branch, and the smaller branch supplies an exact block minimizer.

Thus all maximum-cost block optima and minimizers require \(O(\tau^2)\) operations and oracle calls. The positive masses do not affect this objective.

4. Dynamic programs over contiguous partitions

A partition into \(k\) nonempty contiguous blocks is specified by

\(0=t_0<t_1<\cdots<t_k=\tau.\)

Assign it the values

\(\sum_{r=1}^{k}V_\Sigma(t_{r-1}+1,t_r)\)

and

\(\max_{1\le r\le k}V_{\max}(t_{r-1}+1,t_r)\)

for the two objectives, respectively.

Let \(S(k,j)\) and \(T(k,j)\) be the minimum respective partition values for the first \(j\) support points using exactly \(k\) nonempty blocks. Initialize

\(S(0,0)=T(0,0)=0,\)

and set states with \(k>j\), or with exactly one of \(k,j\) equal to zero, to \(+\infty\). For \(1\le k\le j\), use

\(S(k,j)=\min_{k-1\le r<j}\bigl(S(k-1,r)+V_\Sigma(r+1,j)\bigr),\)

\(T(k,j)=\min_{k-1\le r<j}\max\bigl\{T(k-1,r),V_{\max}(r+1,j)\bigr\}.\)

Every partition has a unique last block \([r+1,j]\), preceded by a partition of \([1,r]\) into \(k-1\) blocks. Conversely, every such predecessor partition and last block form a valid partition. This proves both recurrences. The base value zero also works for the maximum recurrence because every block cost is nonnegative.

Take

\(P_\Sigma=\min_{1\le k\le K}S(k,\tau),\qquad P_{\max}=\min_{1\le k\le K}T(k,\tau).\)

Store a minimizing predecessor for every state. Backtracking recovers a minimizing partition; its block minimizers were already stored during oracle preprocessing.

The dynamic programs require \(O(K\tau^2)\) operations.

5. Proof that the partition solutions are globally optimal

It remains to justify that independent block minimizers produce optimal profiles, even if some support points subsequently prefer another block’s facility.

Every profile has objective at least the partition optimum

Consider any profile with finite objective. By Section 1, its selected locations induce a partition into \(k\le K\) nonempty contiguous blocks.

For each block, the cost at its selected facility is at least the optimum defining \(V_\Sigma\) or \(V_{\max}\). Summing these inequalities, or taking their maximum, shows that the profile’s objective is at least the value of this partition, and therefore at least \(P_\Sigma\) or \(P_{\max}\).

Profiles with infinite objective also satisfy this lower bound.

A minimizing partition gives a profile attaining the bound

Choose a minimizing partition for either objective, and place one facility at its stored minimizer for each block.

For a support point \(i\) in block \([p,q]\), its actual cost is the minimum over all these facilities. Therefore it is at most its cost at the facility assigned to \([p,q]\).

For the weighted-sum objective, multiplying by positive masses and summing gives actual objective at most \(P_\Sigma\). For the maximum objective, taking the maximum gives actual objective at most \(P_{\max}\).

The preceding lower bound applies to these constructed profiles, so equality holds. In particular, both global optima are attained.

If the construction uses fewer than \(m\) facilities, duplicate any constructed location until the profile has exactly \(m\) entries. Duplication preserves every support point’s minimum cost.

6. Running times and conclusion

For the weighted-sum algorithm, ordinary binary integer arithmetic constructs \(D\) and the \(w_i\) within \(O(L^3)\) time: all relevant integers have \(O(L)\) bits, and at most \(O(\tau)\) multiplications and exact divisions suffice. Prefix construction fits within this bound. The \(O(\tau^3)\) block oracle calls each require \(O(L)\) work for their integer arguments. Dynamic programming and explicit profile output add \(O(K\tau^2+m)\).

Thus the weighted-sum running time is

\(O(L^3+\tau^3L+K\tau^2+m).\)

For maximum cost, reading the input costs \(O(L)\), each block uses two constant-size oracle arguments, and the remaining costs are dynamic programming and profile output. Its running time is

\(O(L+(K+1)\tau^2+m).\)

These bounds are polynomial in \(m,\tau,L\). The denominator-clearing step establishes why rational masses do not cause an exponential population expansion, while the oracle’s attainment promise establishes exact reconstruction rather than merely computation of infima.
