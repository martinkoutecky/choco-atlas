The continuous mirror question, as graded

Given \(m\) candidates, a target \(c\), and a rational distribution \(\mu\) over \(\tau\) complete rankings with \(\sum_t\mu_t=1\), find the least integer \(r\) for which there are masses \(x_{t,u}\geq 0\) satisfying \(\sum_u x_{t,u}=\mu_t\), \(x_{t,u}=0\) whenever the Kendall swap distance \(d_{\mathrm{swap}}(t,u)>r\), and \(\sum_{t,u:\,c\succ_u d}x_{t,u}>1/2\) for every opponent \(d\neq c\). Return \(r\) and a witnessing reassignment.

Packaged proof task (what the prover saw — nothing else)

Let \(C\) be a set of \(m\geq 1\) candidates, let \(c\in C\), and let \(\mathcal R(C)\) denote all strict complete rankings of \(C\).
A society is given by its support: a list \(T\subseteq\mathcal R(C)\) of \(\tau\) types with positive binary rational masses \(\mu_t\), where \(\sum_{t\in T}\mu_t=1\). The parameter \(\tau\) is the support size, not the number \(m!\) of possible rankings; \(L\) is the total input bit length.
Use Kendall swap distance \(d_{\mathrm{swap}}\). A reassignment may split each type's mass among arbitrary rankings, including rankings outside \(T\).
For a nonnegative integer radius \(r\), feasibility means there exist real masses \(x_{t,u}\geq0\) satisfying \(\sum_{u\in\mathcal R(C)}x_{t,u}=\mu_t\), with \(x_{t,u}=0\) whenever \(d_{\mathrm{swap}}(t,u)>r\), and \(\sum_{t\in T}\sum_{u:\,c\succ_u d}x_{t,u}>1/2\) for every \(d\in C\setminus\{c\}\). Pairwise ties do not suffice.
The computational problem is to find the least feasible integer \(r\) and a witnessing reassignment, represented by its positive entries as binary rationals.

Can this minimum radius and a witnessing reassignment be computed in time polynomial in \(m,\tau,L\), or is deciding feasibility for an input radius \(r\) NP-hard, with its binary encoding included in \(L\)?

For an explicitly listed finite electorate, the minimum maximum number of adjacent swaps per voter needed to make a designated candidate a strict Condorcet winner is polynomial-time computable. [Source](https://www.ifaamas.org/Proceedings/aamas2011/papers/C6_R74.pdf)
The literature search located no result explicitly treating the normalized, splittable-mass problem defined above.

  • Made explicit that destination rankings range over all strict complete rankings, including those absent from the input support.
  • Specified that a witness is represented by its positive reassignment entries as binary rationals, while feasibility retains the stated real-mass domain.

Result

The minimum radius and a witnessing reassignment are computable in time polynomial in \(m,\tau,L\). In fact, an optimal witness assigns each type’s entire mass to a single ranking.

The decisive property is that moving \(c\) upward by as many as \(r\) positions simultaneously achieves every pairwise victory involving \(c\) that is individually achievable within \(r\) swaps.

1. A lower bound for reversing a pair

For a ranking \(t\), let \(p_t(a)\in\{1,\ldots,m\}\) denote the position of candidate \(a\), with position \(1\) highest.

Lemma. Suppose \(d\succ_t c\), and put \(g=p_t(c)-p_t(d)\). Every ranking \(u\) satisfying \(c\succ_u d\) has \(d_{\mathrm{swap}}(t,u)\geq g\).

Proof. There are exactly \(g-1\) candidates strictly between \(d\) and \(c\) in \(t\). For each such candidate \(z\), the original ranking satisfies \(d\succ_t z\succ_t c\).

If \(u\) preserved both comparisons \(d\succ_u z\) and \(z\succ_u c\), transitivity would give \(d\succ_u c\), contradicting \(c\succ_u d\). Thus, for every intermediate \(z\), at least one of the unordered pairs \(\{d,z\}\) and \(\{z,c\}\) reverses its order. The pair \(\{d,c\}\) also reverses.

These give at least \(g\) distinct reversed pairs. An adjacent swap changes the relative order of exactly one unordered pair, so every swap sequence from \(t\) to \(u\) contains at least \(g\) swaps. This proves the lemma.

The bound is attained by moving \(c\) upward exactly \(g\) positions.

2. One ranking simultaneously maximizes all pairwise support

For a nonnegative integer \(r\), define \(s_r(t)\) by moving \(c\) upward in \(t\) by \(k_t(r)=\min\{r,p_t(c)-1\}\) positions, preserving the relative order of all other candidates.

This uses exactly \(k_t(r)\) adjacent swaps, so \(d_{\mathrm{swap}}(t,s_r(t))=k_t(r)\leq r\).

For every opponent \(d\neq c\), define \(a_{t,d}=\max\{0,p_t(c)-p_t(d)\}\). Directly from the construction,

\(c\succ_{s_r(t)}d\quad\Longleftrightarrow\quad a_{t,d}\leq r.\)

Indeed, candidates originally below \(c\) remain below it. A candidate originally above \(c\) is passed precisely when its position gap from \(c\) is at most \(r\).

Moreover, every \(u\) with \(d_{\mathrm{swap}}(t,u)\leq r\) satisfies

\(c\succ_u d\quad\Longrightarrow\quad c\succ_{s_r(t)}d.\)

For an opponent originally below \(c\), this follows because \(s_r(t)\) still ranks \(c\) above it. For an opponent originally above \(c\), the lemma gives \(a_{t,d}\leq d_{\mathrm{swap}}(t,u)\leq r\), so \(s_r(t)\) also ranks \(c\) above it.

Thus \(s_r(t)\) simultaneously attains every pairwise victory that any allowed destination ranking could attain.

3. Exact feasibility criterion

Define the attainable support against \(d\) by

\(A_d(r)=\sum_{t\in T:\,a_{t,d}\leq r}\mu_t.\)

Proposition. Radius \(r\) is feasible if and only if \(A_d(r)>1/2\) for every \(d\neq c\).

Necessity. Let \(x\) be any allowed reassignment, including one with real masses and arbitrary splitting. If \(a_{t,d}>r\), the lemma shows that no allowed destination of type \(t\) ranks \(c\) above \(d\). Every other type contributes at most its entire mass. Consequently,

\(\sum_{t\in T}\sum_{u:\,c\succ_u d}x_{t,u}\leq\sum_{t:\,a_{t,d}\leq r}\mu_t=A_d(r).\)

A strict pairwise majority therefore requires \(A_d(r)>1/2\).

Sufficiency. Assign each type’s entire mass to \(s_r(t)\): set \(x_{t,s_r(t)}=\mu_t\), and set every other entry to zero.

The row sums are correct, and every positive entry satisfies the radius constraint. By the characterization in Section 2, the resulting support against each \(d\) is exactly \(A_d(r)\). Hence all the required strict inequalities hold.

This proves the criterion and shows that splitting mass cannot improve feasibility.

4. Computing the minimum and witness

If \(m=1\), the pairwise conditions are vacuous. Return radius \(0\) and \(x_{t,t}=\mu_t\).

Assume \(m\geq2\). Every \(a_{t,d}\) lies in \(\{0,\ldots,m-1\}\), and \(A_d(m-1)=1\). Define

\(r_d=\min\{j\in\{0,\ldots,m-1\}:A_d(j)>1/2\}.\)

Each \(A_d\) is nondecreasing. The feasibility criterion therefore gives the exact optimum

\(r_{\min}=\max_{d\in C\setminus\{c\}}r_d.\)

An algorithm computes all positions and gaps, finds these thresholds, and returns the \(\tau\) positive entries \(x_{t,s_{r_{\min}}(t)}=\mu_t\).

The criterion proves minimality: any smaller radius fails the strict-majority requirement for at least one opponent. The construction proves feasibility at the returned radius.

5. Exact arithmetic and polynomial bit complexity

Write each input mass as \(\mu_t=\alpha_t/\beta_t\), where \(\alpha_t,\beta_t\) are positive binary integers. Let

\(D=\prod_{t\in T}\beta_t,\qquad w_t=\alpha_t(D/\beta_t).\)

The bit length of \(D\) is at most \(1+\sum_t\log_2\beta_t\), hence \(O(L)\). Each \(w_t\) is a positive integer, and normalization gives \(\sum_t w_t=D\), so these weights also have \(O(L)\) bits.

For each opponent \(d\), form the buckets

\(H_d(j)=\sum_{t:\,a_{t,d}=j}w_t,\qquad j\in\{0,\ldots,m-1\}.\)

Then \(r_d\) is the first index \(j\) for which

\(2\sum_{i=0}^{j}H_d(i)>D.\)

This exact integer comparison enforces strict majority: equality is rejected.

Computing positions and filling buckets takes \(O(m\tau)\) elementary operations; scanning the buckets takes \(O(m^2)\) operations. All arithmetic uses integers of polynomial bit length. Computing \(D\) and the weights likewise takes polynomial time.

For a supplied binary radius \(r\), one may replace it by \(\min\{r,m-1\}\), since radius \(m-1\) is always feasible. Thus a large binary radius causes no enumeration proportional to its numeric value.

The witness has exactly \(\tau\) positive entries. Its masses are copied from the input, and its destination rankings are explicitly constructed in polynomial time. Its total encoding length is polynomial.

6. Relation to the cited result

[Proposition 4.8 of the cited paper](https://www.ifaamas.org/Proceedings/aamas2011/papers/C6_R74.pdf) gives the finite-electorate algorithm that repeatedly moves \(c\) upward in every vote. The proof above establishes directly why the same operation solves the normalized, splittable-mass problem, with exact rational arithmetic and a polynomial-size witness.
