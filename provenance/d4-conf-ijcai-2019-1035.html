The continuous mirror question, as graded

Given a finite set of types \(T\), positive rational masses \(\mu_t\) summing to \(1\), and an explicitly represented rational polynomial \(F\) on a neighborhood of \([0,\mu]\), with \(\partial_t F(\mu/2)\ne 0\) for every \(t\), return the total preorder \(t\succeq u\) iff \(\operatorname{sgn}(\partial_t F(\mu/2))\ge \operatorname{sgn}(\partial_u F(\mu/2))\). This asks for the limiting ordinal Banzhaf ranking when each finite-population context includes each other member independently with probability \(1/2\), and coalition power is given by \(F\) of its type-mass vector.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a nonempty list \(T\) of \(\tau\) types with positive binary-rational masses \(\mu_t\), where \(\sum_{t\in T}\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types.
The input also contains a rational polynomial \(F\) in the \(m=\tau\) type-mass coordinates, represented by an explicit list of monomials with binary-rational coefficients and unary nonnegative integer exponents. Let \(L\) be the total input bit length and \(d\) the total degree.
Coalition mass vectors lie in \([0,\mu]=\prod_{t\in T}[0,\mu_t]\); higher values of \(F\) mean greater coalition power, and equal values mean indifference. Values and coefficients may have either sign; no monotonicity or normalization of \(F\) is imposed.
Assume \(\partial_tF(\mu/2)\ne0\) for every \(t\in T\). Return the total preorder defined by \(t\succeq u\iff\operatorname{sgn}(\partial_tF(\mu/2))\ge\operatorname{sgn}(\partial_uF(\mu/2))\); equal signs give tied types.

Is computing this preorder solvable in polynomial time, or is it NP-hard? State running times in \(m,\tau,L,d\).

For finite societies with a strict total order of coalitions, ranking individuals by the sum of their ordinal marginal contributions agrees with weighted majority comparisons: each comparison's weight counts the coalitions obtained by adding neither or both compared individuals that lie strictly between the two single-addition coalitions. This is an equivalence result, with no complexity classification ([Khani–Moretti–Öztürk](https://www.ijcai.org/proceedings/2019/0054.pdf)).
No result settling exactly the continuous computation above was located in the literature search.

Result

Computing the requested preorder is polynomial-time solvable, even when \(m=\tau\) is part of the input. The algorithm evaluates the derivative signs exactly, so cancellation and arbitrarily small nonzero derivative values cause no difficulty.

A conservative running-time bound, using schoolbook integer arithmetic, is

\(O\!\left(L^4+(m+d)L^3(d+1)^2+\tau^2\right)\)

bit operations. The \(\tau^2\) term applies if the output is the full comparison matrix; an ordered list of tied classes avoids that term. Since \(m=\tau\le L\) and unary exponents imply \(d\le L\), this gives an \(O(L^6)\) bound.

1. Integer representation of the input

Write the polynomial as

\(F(x)=\sum_{j=1}^{s}c_j\prod_{t=1}^{m}x_t^{\alpha_{jt}},\)

where \(s\le L\), every \(\alpha_{jt}\) is a nonnegative integer, and \(k_j:=\sum_t\alpha_{jt}\le d\).

All rational denominators below are chosen positive. Write \(c_j=u_j/v_j\), and set

\(C:=\prod_{j=1}^{s}v_j,\qquad A_j:=u_j(C/v_j).\)

Then \(C\) is positive and \(A_j\) is an integer, with \(c_j=A_j/C\). If the input contains repeated exponent vectors, combine their integer coefficients \(A_j\), and discard zero coefficients. This preserves the common denominator \(C\). Henceforth the displayed list is the resulting polynomial, whose degree is \(d\). The nonzero-derivative promise implies \(d\ge1\).

For the evaluation point \(q:=\mu/2\), write \(q_t=a_t/b_t\), and define

\(B:=\prod_{t=1}^{m}b_t,\qquad p_t:=a_t(B/b_t).\)

Thus \(q_t=p_t/B\). Positive masses give \(p_t>0\), and \(\sum_t\mu_t=1\) implies \(q_t\le1/2\), so \(p_t\le B/2\).

The total binary lengths of the input numerators and denominators are bounded by \(L\). Forming the midpoint denominators adds only \(O(m)\) bits. Consequently, \(B,C,p_t\), and \(A_j\) all have \(O(L)\) bits. Combining coefficients preserves this bound: each combined coefficient is a sum of at most \(L\) integers of \(O(L)\) bits.

2. Exact integer sums determine every derivative sign

For each monomial, compute the positive integer

\(P_j:=B^{d-k_j}\prod_{u=1}^{m}p_u^{\alpha_{ju}}.\)

For each coordinate, compute the signed integer

\(R_t:=\sum_{j=1}^{s}\alpha_{jt}A_jP_j.\)

We claim that

\(\displaystyle \partial_tF(q)=\frac{R_t}{C\,p_t\,B^{d-1}}.\)

To verify this, consider a monomial with \(\alpha_{jt}>0\). Its contribution to the expression on the right is

\(\displaystyle \frac{\alpha_{jt}A_jB^{d-k_j}\prod_u p_u^{\alpha_{ju}}} {C\,p_t\,B^{d-1}} = \frac{A_j}{C}\,\alpha_{jt} \left(\frac{p_t}{B}\right)^{\alpha_{jt}-1} \prod_{u\ne t}\left(\frac{p_u}{B}\right)^{\alpha_{ju}}, \)

which is exactly its contribution to \(\partial_tF(q)\). When \(\alpha_{jt}=0\), both contributions are zero. Summing proves the identity.

Because \(C,p_t,B\) are positive,

\(\operatorname{sgn}(\partial_tF(\mu/2))=\operatorname{sgn}(R_t).\)

Thus the algorithm only needs exact integer sign tests.

3. Bit lengths and running time

The preceding construction must be checked in the bit model; counting arithmetic operations alone would not suffice.

Since \(p_t\le B\) and the total number of factors in \(P_j\), counted with multiplicity, is \(d\),

\(0<P_j\le B^d.\)

Hence every \(P_j\) has \(O(Ld)\) bits. Also,

\(\displaystyle |R_t|\le s\,d\,\max_j|A_j|\,B^d.\)

Therefore every \(R_t\), and every partial sum used to compute it, has

\(O\!\left(L(d+1)+\log s+\log(d+1)\right)=O(L(d+1))\)

bits. Products can likewise be formed without exceeding this bound, by multiplying the factors of each \(P_j\) successively.

Denominator clearing and combining duplicate monomials take \(O(L^4)\) bit operations under a conservative implementation. Thereafter:

  • Computing each \(P_j\) takes \(O(m+d)\) elementary operations: scan its exponents and perform at most \(d\) multiplications.
  • Computing its contributions to all \(R_t\) takes \(O(m)\) elementary operations.

The total is \(O(s(m+d))\) arithmetic operations on integers of \(O(L(d+1))\) bits. Schoolbook multiplication takes quadratic time in that bit length; addition and comparison take no longer. Thus evaluation costs

\(O\!\left(s(m+d)L^2(d+1)^2\right) \subseteq O\!\left((m+d)L^3(d+1)^2\right).\)

This proves the stated polynomial bit bound. In particular, neither negative coefficients nor cancellation require numerical approximation.

4. Constructing the preorder

Define

\(T_+:=\{t:R_t>0\},\qquad T_-:=\{t:R_t<0\}.\)

The promise ensures these sets partition \(T\). Return the nonempty classes in the order \(T_+,T_-\), with all types within each class tied. This is correct because positive derivative signs exceed negative derivative signs, while equal signs give indifference.

The [Khani–Moretti–Öztürk paper](https://www.ijcai.org/proceedings/2019/0054.pdf) concerns ordinal comparisons of finite coalitions. Its weighted-comparison representation is not needed here: the explicitly prescribed continuous preorder follows directly from polynomial-time exact evaluation.
