Each \(g_k(x)\) is computable in time polynomial in \(k\), and \(g_k(k)\) is polynomially bounded in \(k\).
Write \(\Delta_k(i)=g_k(i)-g_k(i-1)\) and \(s_k=\min\{i\in\{2,\ldots,k\}:\Delta_k(i)\ne\Delta_k(i-1)\}\), taking \(s_k=\infty\) when the set is empty.

Result

Interpreting the question as asking whether there exists a qualifying committee, the problem is \(\mathrm{NP}\)-complete for every fixed family satisfying the assumptions. Checking a supplied committee is polynomial-time solvable.

1. Applicable unit-weight hardness theorem

[Theorem 11 of Faliszewski, Skowron, Slinko, and Talmon](https://link.springer.com/article/10.1007/s00355-018-1126-4#Sec4) establishes \(\mathrm{NP}\)-hardness of the following problem: given an explicitly listed electorate and a nonnegative integer threshold \(Q\), determine whether some size-\(k\) committee has total score at least \(Q\).

Its hypotheses match those here:

  • The counting functions are independent of \(m\), polynomial-time computable in \(k\), and have polynomially bounded maximum value \(g_k(k)\).
  • For every sufficiently large \(k\), the counting function is convex, meaning precisely that its increments \(\Delta_k(i)\) are nondecreasing.
  • Its “singularity” is precisely \(s_k\), and the required condition is \(k-s_k\ge k/c\).

The family remains fixed throughout the reduction.

The restriction \(2k\le m\) can also be enforced without losing hardness. Given a source instance with \(k\le m<2k\), append \(2k-m\) dummy candidates at the bottom of every ranking. All top-\(k\) sets remain unchanged, and independence from \(m\) keeps the counting function unchanged. Every original committee retains its score. Conversely, replace every dummy in a padded committee by a distinct unused original candidate. There are enough such candidates because the original candidate set has size at least \(k\). No intersection with a top-\(k\) set decreases, so monotonicity of \(g_k\) ensures that the score does not decrease. Thus padding preserves the answer and increases the candidate count by at most a factor of two.

2. Polynomial reduction to normalized rational masses

Take a unit-weight instance with \(n\ge1\) voters, candidate set \(C\), committee size \(k\), and integer threshold \(Q\). Empty electorates are trivial and can be excluded from the hard source problem.

Group voters by their entire strict ranking. Let \(T\) be the distinct rankings, and let \(n_t\) be the multiplicity of ranking \(t\). Construct the rational-mass instance using

\(\mu_t=n_t/n\qquad\text{and}\qquad q=Q/n.\)

Every listed mass is positive, and

\(\sum_{t\in T}\mu_t=\frac{\sum_{t\in T}n_t}{n}=1.\)

For every size-\(k\) committee \(W\), grouping equal rankings gives the exact identity

\(\sum_{t\in T}\mu_t g_k(|W\cap A_t|)=\frac1n\sum_{j=1}^{n}g_k(|W\cap A_j|).\)

Because \(n>0\), this implies

\(\sum_{t\in T}\mu_t g_k(|W\cap A_t|)\ge q \quad\Longleftrightarrow\quad \sum_{j=1}^{n}g_k(|W\cap A_j|)\ge Q.\)

In particular, equality is preserved exactly. Hence the source and target instances have the same answer.

Encoding size and reduction time. Index candidates by integers from \(1\) to \(m\), and write \(b_Q\) for the binary length of \(Q\). We have \(\tau\le n\), and each mass uses \(O(\log(n+1))\) bits. The output length satisfies

\(L=O\!\left(\tau m\log(m+1)+\tau\log(n+1)+b_Q+\log(m+1)+\log(k+1)\right).\)

If the source length is \(N\), sorting rankings and counting multiplicities takes polynomial time; a conservative bound, including rational encoding, is

\(O\!\left(N+nm\log(n+1)\log(m+1)+(n+1)(N+1)^2\right).\)

Fractions can be reduced by the Euclidean algorithm if the encoding requires lowest terms. Since voters are explicitly listed, both the running time and output length are polynomial in \(N\).

This is therefore a polynomial-time many-one reduction, proving \(\mathrm{NP}\)-hardness of the normalized rational-mass problem.

3. Exact verification and running times

Let \(p_g(k)\) be a fixed polynomial bounding the time to evaluate \(g_k(x)\). A certificate lists the \(k\) distinct members of \(W\).

Write the input fractions as \(\mu_t=a_t/b_t\) and \(q=u/v\), with positive denominators. Compute

\(x_t=|W\cap A_t|,\qquad D=\prod_{t\in T}b_t,\qquad H=\sum_{t\in T}a_t g_k(x_t)(D/b_t).\)

Each division is exact. The certificate qualifies precisely when

\(vH\ge uD.\)

Thus verification uses integer arithmetic and accepts equality.

To bound its cost, put \(G=g_k(k)\). The binary length of \(D\) is \(O(L)\), because the denominator encodings are part of the input. Moreover, positivity and normalization imply

\(0\le H=D\sum_{t\in T}\mu_t g_k(x_t)\le DG.\)

Every partial sum defining \(H\) satisfies the same bound. Since \(G\) is polynomially bounded in \(k\), all arithmetic operands have \(O(L+\log(k+1))\) bits, including those used in the final comparison.

Using schoolbook integer arithmetic and direct candidate comparisons, a conservative verification bound is

\(R(m,\tau,k,L)=O\!\left(L+\tau k^2\log(m+1)+\tau p_g(k)+\tau(L+\log(k+1))^2\right).\)

The explicitly listed rankings ensure that \(m\), and hence \(k\), is polynomially bounded by \(L\). The certificate length is \(O(k\log(m+1))\). Consequently, verification is polynomial in the input length, establishing membership in \(\mathrm{NP}\).

For completeness, enumerating all committees gives a deterministic decision algorithm with running time

\(O\!\left(\binom{m}{k}R(m,\tau,k,L)\right).\)

Combining membership with the reduction proves \(\mathrm{NP}\)-completeness for every fixed family under the stated assumptions.
