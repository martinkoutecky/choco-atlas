The continuous mirror question, as graded

Given finite worker types \(i\) with rational masses \(\mu_i\) and finite firm types \(j\) with rational masses \(\nu_j\), capacity 2, and two-sided valuation matrices (restricted to \(\{0,1,2\}\) and type-degree at most 3), choose masses \(y_{j,b}\) of firm type \(j\) receiving each integral worker-type bundle \(b\) with \(|b| \le 2\), satisfying \(\sum_b y_{j,b} = \nu_j\) and \(\sum_{j,b} b_i y_{j,b} = \mu_i\), to maximize the normalized sum of worker and firm log utilities, excluding zero-utility assignments.

Definitions. An instance has finite worker types \(A\), firm types \(B\), rational type masses \(M_W\mu_a\) and \(M_F u_b\), valuations \(v^W_{ab},v^F_{ba}\in\{0,1,2\}\), and capacity \(2\) per firm. Each type positively values at most three counterpart types.
For each \(b\), let \(\mathcal S\) be the multisets of worker types of cardinality at most \(2\). Choose \(y_{b,S}\ge0\), set \(x_{ab}=\sum_{S\in\mathcal S}n_a(S)y_{b,S}\), and require \(\sum_Sy_{b,S}=M_F\nu_b\) and \(\sum_{b,S}n_a(S)y_{b,S}=M_W\mu_a\).
The objective is to maximize \(L=\sum_{a,b}x_{ab}\log v^W_{ab}+\sum_{b,S}y_{b,S}\log\!\left(\sum_an_a(S)v^F_{ba}\right)\), with zero-valued terms infeasible whenever assigned positive mass.

Classification

Theorem

Under the standard binary Turing model for the rational masses, the stated continuous maximum-Nash-welfare problem is polynomial-time solvable.

More precisely, one can return either:

  • a proof that no feasible positive-utility assignment exists; or
  • an exact rational optimal configuration vector \(y^*\), together with the exact symbolic optimum \(L^*=P^*\log 2+Q^*\log 3\), where \(P^*,Q^*\in\mathbb Q\).

The sparsity assumption that every type positively values at most three counterpart types is not needed for this result.

1. Removing zero-utility configurations

Write \(r_a=M_W\mu_a\) and \(f_b=M_F\nu_b\). For each firm type \(b\), call a multiset \(S\) admissible if:

  • \(v^W_{ab}>0\) for every worker type occurring in \(S\); and
  • \(U_{b,S}:=\sum_a n_a(S)v^F_{ba}>0\).

Any nonadmissible configuration must have \(y_{b,S}=0\). Thus it may be deleted. This is exactly the zero-value convention in the question. If the intended convention additionally forbids assigning a worker with \(v^F_{ba}=0\) inside an otherwise positive firm bundle, deleting those configurations as well does not affect the argument.

For an admissible configuration, substitute

\[ x_{ab}=\sum_S n_a(S)y_{b,S}. \]

Interchanging the finite sums gives

\[ L=\sum_{b,S}c_{b,S}y_{b,S}, \]

where

\[ c_{b,S} = \sum_a n_a(S)\log v^W_{ab} + \log U_{b,S}. \]

Consequently, the apparently logarithmic optimization problem is a linear optimization problem over the configuration variables.

2. The configuration formulation has polynomial size

The number of worker-type multisets of cardinality at most \(2\) is

\[ 1+|A|+\frac{|A|(|A|+1)}2. \]

Hence the number of variables is \(O(|B||A|^2)\), which is polynomial in the explicit input length.

After deleting inadmissible configurations, the feasible region is

\[ \mathcal P= \left\{ y\geq 0: \sum_S y_{b,S}=f_b\ \text{for every }b,\quad \sum_{b,S}n_a(S)y_{b,S}=r_a\ \text{for every }a \right\}. \]

Its constraint matrix has entries only in \(\{0,1,2\}\). It is bounded because

\[ 0\leq y_{b,S}\leq f_b \]

for every variable. Feasibility is therefore decidable by an ordinary rational linear program in polynomial time.

3. Only two fixed logarithms occur

For every admissible configuration, each positive worker valuation is \(1\) or \(2\), while

\[ U_{b,S}\in\{1,2,3,4\}. \]

Define

\[ p_{b,S} = \sum_a n_a(S)\mathbf 1[v^W_{ab}=2] +\mathbf 1[U_{b,S}=2] +2\mathbf 1[U_{b,S}=4] \]

and

\[ q_{b,S}=\mathbf 1[U_{b,S}=3]. \]

Then \(p_{b,S}\in\{0,1,2,3,4\}\), \(q_{b,S}\in\{0,1\}\), and

\[ c_{b,S}=p_{b,S}\log 2+q_{b,S}\log 3. \]

Put

\[ P(y)=\sum_{b,S}p_{b,S}y_{b,S}, \qquad Q(y)=\sum_{b,S}q_{b,S}y_{b,S}, \qquad \rho=\frac{\log 3}{\log 2}. \]

Since \(\log 2>0\), maximizing \(L\) is equivalent to maximizing

\[ P(y)+\rho Q(y). \]

The number \(\rho\) is irrational: if \(\rho=m/n\in\mathbb Q\), then \(2^m=3^n\) after clearing signs and denominators, contradicting unique prime factorization.

4. Polynomial bit bounds for all vertices

Let \(N\) denote the binary input length. Every vertex of \(\mathcal P\) has polynomial encoding length.

Indeed, if a vertex has \(s\) positive components, their columns in the equality-constraint matrix must be linearly independent. Otherwise, a nonzero kernel direction supported on those positive components would permit sufficiently small perturbations in both directions, contradicting extremality. Thus \(s\leq |A|+|B|\).

Choose \(s\) independent rows and let \(G\) be the resulting nonsingular \(s\times s\) submatrix. Its entries lie in \(\{0,1,2\}\). The positive vertex coordinates solve \(Gz=d\), where \(d\) is a subvector of the rational mass vector. Cramer's rule and Hadamard's inequality give

\[ |\det G|\leq (2\sqrt{s})^s. \]

After clearing the denominators of \(d\), the same bound applied to the replaced-column determinants shows that every numerator and denominator in \(z\) has bit length polynomial in \(N\).

It follows that there is an explicitly computable polynomial \(K(N)\) such that, for every pair of vertices \(y,z\), both \(P(y)-P(z)\) and \(Q(y)-Q(z)\) are rationals whose numerators and denominators have at most \(K(N)\) bits.

5. Exact treatment of the irrational objective

A numerical approximation to \(\rho\) is not by itself sufficient: one must prove that the chosen precision preserves the ordering of all vertices.

We use the following fixed-base consequence of an effective lower bound for linear forms in logarithms.

Two-logarithm separation lemma. There is an effectively computable constant \(C_0>0\), depending only on \(2\) and \(3\), such that for all integers \(u,v\), not both zero, with \(H=\max\{3,|u|,|v|\}\),

\[ |u\log 2+v\log 3|>H^{-C_0}. \]

This is a direct specialization of the explicit bounds for homogeneous rational linear forms in logarithms of algebraic numbers; the relevant hypotheses hold because \(2\) and \(3\) are algebraic and multiplicatively independent. See [Matveev’s explicit lower-bound theorem](https://www.mathnet.ru/eng/im190).

Now consider two vertices \(y,z\), and set

\[ \Delta_P=P(y)-P(z), \qquad \Delta_Q=Q(y)-Q(z). \]

If \((\Delta_P,\Delta_Q)\neq(0,0)\), clear their denominators to obtain integers \(u,v\), of \(O(K(N))\) bits, and a positive integer \(D\), also of \(O(K(N))\) bits, such that

\[ \Delta_P+\rho\Delta_Q = \frac{u\log 2+v\log 3}{D\log 2}. \]

The numerator is nonzero by multiplicative independence. The separation lemma therefore yields a computable constant \(C_1\) such that

\[ |\Delta_P+\rho\Delta_Q|>2^{-C_1K(N)}. \]

Thus distinct vertex objective values have an inverse-exponential gap whose exponent is polynomial in the input length.

Furthermore,

\[ 0\leq Q(y)\leq \sum_b f_b \]

for every feasible \(y\). Let \(R\) be an easily computed binary bound satisfying

\[ |Q(y)-Q(z)|\leq R \]

for all feasible \(y,z\). The bit length of \(R\) is polynomial in \(N\).

Choose a rational number \(\widehat\rho\) satisfying

\[ |\widehat\rho-\rho| < \frac{2^{-C_1K(N)}}{2R}. \]

Such an approximation has polynomially many bits and is computable in polynomial time. For example, rational upper and lower bounds for \(\log 2\) and \(\log 3\) can be computed using the geometrically convergent series

\[ \log z = 2\sum_{j\geq 0} \frac{1}{2j+1} \left(\frac{z-1}{z+1}\right)^{2j+1}. \]

For any pair of vertices with different true objective values,

\[ \left| (\Delta_P+\widehat\rho\Delta_Q) - (\Delta_P+\rho\Delta_Q) \right| < \frac12|\Delta_P+\rho\Delta_Q|. \]

Therefore \(P+\widehat\rho Q\) and \(P+\rho Q\) order every pair of vertices in exactly the same way. If two vertices tie under the true objective, irrationality of \(\rho\) implies \(\Delta_P=\Delta_Q=0\), so they also tie under the approximating objective.

6. Polynomial-time algorithm

The complete algorithm is:

  • Enumerate all multisets \(S\) of worker types of cardinality at most \(2\).
  • Delete inadmissible configurations.
  • Test feasibility of \(\mathcal P\) by rational linear programming.
  • Compute the polynomial vertex bit bound \(K(N)\).
  • Compute \(\widehat\rho\) to the precision established above.
  • Solve the rational linear program

\[ \max_{y\in\mathcal P} \sum_{b,S} \bigl(p_{b,S}+\widehat\rho q_{b,S}\bigr)y_{b,S}. \]

  • Return an optimal basic feasible solution \(y^*\), reconstruct \(x^*\), and report the exact symbolic value

\[ L^*=P(y^*)\log 2+Q(y^*)\log 3. \]

All coefficients in Step \(6\) have polynomial encoding length. Exact rational linear programming therefore runs in polynomial time.

Because every nonempty bounded polytope has an optimal vertex for a linear objective, and because the rational approximate objective has exactly the same vertex ordering as the true objective, the returned solution is exactly optimal for the original logarithmic objective.

7. Why the discrete hardness does not transfer

The discrete problem requires each individual firm to select one integral bundle. In the mass formulation, \(y_{b,S}\) may split a firm type continuously among several configurations. This is precisely a configuration-LP relaxation of the individual allocation requirement, and its constraint matrix need not force integral vertices.

Consequently, even replacing every individual by a separate type does not reproduce the discrete problem: the corresponding unit mass may still be divided fractionally. The discrete NP-completeness result therefore does not contradict the polynomial-time algorithm above.

Conclusion

The stated continuous mass-formulated maximum-Nash-welfare problem is exactly polynomial-time solvable. The decisive features are the fixed capacity \(2\), which makes the configuration set polynomial, and the fact that every objective coefficient is a fixed rational linear combination of \(\log 2\) and \(\log 3\). Effective separation for these two logarithms completes the exact bit-complexity argument.
