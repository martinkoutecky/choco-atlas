The continuous mirror question, as graded

Given candidates \(C\), a committee size \(k\), and \(\tau\) approval types \(A_t\subseteq C\) with positive binary-rational masses \(\mu_t\) summing to \(1\), suppose the types have an order in which each candidate is approved by consecutive types. For a fixed Thiele sequence \(w\), can an optimal size-\(k\) committee maximizing \(S_\mu(W)=\sum_t\mu_t\sum_{i=1}^{|A_t\cap W|}w_i\) be computed in time \(f(\rho_C+\rho_V)\operatorname{poly}(m,\tau,L)\), where \(\rho_C=\max_c|\{t:c\in A_t\}|\), \(\rho_V=\max_t|A_t|\), and \(L\) is the total mass bit length?

Packaged proof task (what the prover saw — nothing else)

Fix a Thiele sequence \(w\) with \(1=w_1\geq w_2\geq\cdots\geq0\), whose first \(m\) entries are binary rationals computable in polynomial time in \(m\).
A society is given by its support: \(\tau\) distinct approval sets \(A_t\subseteq C\), each with positive binary-rational mass \(\mu_t\), where \(\sum_t\mu_t=1\). Here \(\tau\) is the support size, not the number of possible approval sets; \(L\) is the total mass bit length.
Let \(m=|C|\geq1\), \(1\leq k\leq m\), and require every candidate to have a supporter; empty approval sets are allowed. The support admits a linear order in which each candidate's supporting types are consecutive.
Define \(\rho_C=\max_{c\in C}|\{t:c\in A_t\}|\) and \(\rho_V=\max_t|A_t|\). Output any committee \(W\subseteq C\) of size \(k\) maximizing \(S_\mu(W)=\sum_{t=1}^{\tau}\mu_t\sum_{i=1}^{|A_t\cap W|}w_i\), with an empty inner sum equal to zero.

Is this optimization problem solvable in \(\operatorname{poly}(m,\tau,L,k)\) time, or is it \(\mathrm{NP}\)-hard? If it is \(\mathrm{NP}\)-hard, is it nevertheless solvable in \(f(\rho_C+\rho_V)\operatorname{poly}(m,\tau,L,k)\) time?

For discrete voter-interval elections, generalized Thiele winner determination is FPT in the sum of maximum candidate support and maximum ballot size, and XP in maximum candidate support; unrestricted nonconstant Thiele rules are NP-hard and W[1]-hard in committee size. [Lassota–Sornat](https://arxiv.org/html/2607.28575v1)
Later polynomial-time results explicitly cover voter-interval elections with arbitrary binary-rational, voter-specific non-increasing scoring sequences, including this mass objective. Thus the stated target is already settled in \(\mathrm{P}\), rather than open. [Manurangsi–Sornat](https://arxiv.org/html/2604.05953v1)

Conclusion

The problem is solvable in \(\operatorname{poly}(m,\tau,L,k)\) time for every fixed sequence \(w\) satisfying the stated assumptions. Consequently, it is also fixed-parameter tractable in \(\rho_C+\rho_V\), with a constant parameter factor.

The proof is a polynomial-size reduction to generalized Thiele winner determination on voter-interval profiles.

The theorem used

Manurangsi–Sornat, Theorem 10. Given a voter-interval approval profile and voter-specific, nonnegative, non-increasing scoring sequences with entries in \([0,1]\), encoded as binary rationals, an optimal committee of the prescribed size can be computed in polynomial time in the input encoding length. Individual sequences need not have first entry equal to \(1\). Their formulation supplies the first \(m\) entries of each sequence. See [Section 2 and Theorem 10](https://arxiv.org/html/2604.05953v1).

We apply this theorem directly, checking the objective, structural assumptions, and encoding size below.

Reduction and correctness

Let \(T=\{t:A_t\neq\varnothing\}\). Construct one voter \(v_t\) for every \(t\in T\), with approval ballot \(A_t\). Keep the candidate set \(C\) and required committee size \(k\).

For each constructed voter, supply the scoring entries
\[ a_i^{\,t}=\mu_t w_i,\qquad 1\leq i\leq m. \]
If an infinite sequence is desired, extend these entries by zeros after position \(m\).

Scoring hypotheses. Positivity of the masses and their normalization imply \(0<\mu_t\leq1\). Therefore
\[ 1\geq a_1^{\,t}\geq a_2^{\,t}\geq\cdots\geq a_m^{\,t}\geq0. \]
Thus every constructed sequence meets the theorem’s hypotheses. In particular, its first entry is \(\mu_t\), which the generalized formulation permits.

Voter-interval hypothesis. Take the promised order of the original types and restrict it to \(T\). For any candidate, its supporters remain consecutive: if two retained types support it, every retained type between them also lay between them in the original order and hence supports it. Moreover, deleting empty types removes no supporter. Thus every candidate still has a supporter, and the constructed profile is voter-interval.

Objective preservation. For every committee \(W\subseteq C\),
\[ \sum_{t\in T}\sum_{i=1}^{|A_t\cap W|}a_i^{\,t} =\sum_{t\in T}\mu_t\sum_{i=1}^{|A_t\cap W|}w_i =S_\mu(W). \]
The final equality holds because each omitted empty approval set contributes zero. The feasible committees also remain exactly the size-\(k\) subsets of \(C\). Consequently, an optimal committee returned for the constructed instance is optimal for the original society.

Encoding size and running time

Let \(B_w(m)\) be the total bit length of the first \(m\) entries of \(w\). The assumed polynomial-time computation of those entries implies that \(B_w(m)\) is polynomially bounded in \(m\).

Write \(\mu_t=p_t/q_t\) and \(w_i=r_i/s_i\), using their binary-rational representations. We can encode
\[ a_i^{\,t}=\frac{p_t r_i}{q_t s_i}. \]
The numerator and denominator lengths are bounded by the sums of the corresponding input lengths, up to a constant. Reduction to lowest terms can only decrease these lengths.

Summing over all constructed entries, their total encoding length is therefore
\[ O\!\left(mL+\tau B_w(m)+\tau m\right). \]
The approval profile has at most \(\tau\) voters and can be represented by an incidence matrix with \(\tau m\) entries. All rational products are computable in polynomial time.

Hence the constructed input has size polynomial in \(m,\tau,L,k\). Applying Theorem 10 proves the required polynomial running time. This construction uses one voter per retained support type; the masses enter only through the scoring coefficients.

Parameterized consequence

The same algorithm has running time \(f(\rho_C+\rho_V)\operatorname{poly}(m,\tau,L,k)\) with \(f(p)=1\). Thus the parameterized question is settled affirmatively without needing a hardness assumption.
