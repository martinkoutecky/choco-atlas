The continuous mirror question, as graded

Let \(\mathcal A_{d,n}\) be the finite set of normalized vectors \(a\in\mathbb Q_{\ge0}^d\), with \(\sum_j a_j=1\) and coordinate bit length at most \(n\). An unknown rational distribution \(\mu\) has support size at most \(\tau\), with masses of bit length at most \(L\). An oracle queried at rational prices \(p\in\mathbb Q_{\ge0}^d\) and budget \(B\in\mathbb Q_{\ge0}\) returns \(D_\mu(p,B)=\sum_a\mu_a b_a(p,B)\), where \(b_a\) is the paper's tie-broken optimal bundle for type \(a\). Can an adaptive algorithm using time and queries polynomial in \(d,\tau,n,L\) and the query bit length output at most \(\tau\) rational type-mass pairs that induce the same \(D_\mu(p,B)\) for every rational \(p,B\)?

Packaged proof task (what the prover saw — nothing else)

Let \(m=d\geq1\) be the number of divisible goods, with bundles in \([0,1]^d\). Define \(\mathcal A_{d,n}=\{a\in\mathbb Q_{\geq0}^d:\sum_j a_j=1\}\), restricted to coordinates whose reduced numerators and denominators each have binary length at most \(n\).
For \(a\in\mathcal A_{d,n}\), define \(b_a(p,B)\) by maximizing \(a\cdot x\) over \(x\in[0,1]^d\) with \(p\cdot x\leq B\), then minimizing expenditure among maximizers, then choosing the lexicographically smallest remaining bundle in the fixed coordinate order.
A society is represented by its support: its \(\tau\) distinct positive-mass types and their binary rational masses. Here this representation is hidden; \(\tau\) is the support size, not the number of possible types. Masses sum to \(1\), and each reduced mass numerator and denominator has binary length at most \(L\).
The learner knows \(d,\tau,n,L\) and has only an exact oracle returning \(D_\mu(p,B)=\sum_a\mu_a b_a(p,B)\) for adaptively chosen \(p\in\mathbb Q_{\geq0}^d\) and \(B\in\mathbb Q_{\geq0}\). Oracle answers use binary rational encodings.
The reconstruction problem asks for a distribution \(\widehat\mu\) on at most \(\tau\) types in \(\mathcal A_{d,n}\), with positive rational masses summing to \(1\), such that \(D_{\widehat\mu}(p,B)=D_\mu(p,B)\) for every rational nonnegative \((p,B)\).

Does this exact reconstruction problem admit a deterministic adaptive algorithm with time, query count, and query bit lengths polynomial in \(m=d,\tau,n,L\), or is it NP-hard in this oracle model? Account for binary query and answer processing in the running time.

For a single normalized rational linear-utility buyer, exact learning uses \(O(nd)\) revealed-preference queries ([Balcan et al.](https://arxiv.org/pdf/1407.7937v1)).
Polynomial-time aggregate-demand learning is known for linear Fisher markets with fixed buyer budgets and bundles in \(\mathbb R_{\geq0}^d\); that model differs from the capped bundles and query-selected common budget here ([Bei et al.](https://www.microsoft.com/en-us/research/wp-content/uploads/2016/06/aaai16_learnmarket.pdf)).

Modeling choices made when packaging the task

  • Specified the bundle domain as the unit cube, retaining the per-good caps in the discrete definition.
  • Resolved unspecified residual ties by choosing the lexicographically smallest bundle after utility maximization and expenditure minimization, including at zero prices or zero budget.
  • Interpreted coordinate and mass precision as separate binary-length bounds on reduced numerators and denominators.
  • Used tau for the actual positive support size and supplied it to the learner, reconciling the support-size convention with the graded question's support bound.
  • Made the support representation hidden and accessible only through the exact aggregate-demand oracle; normalized masses to sum to one.
  • Required output types to belong to the original type class; output masses are rational without imposing the original mass precision bound.
  • Specified deterministic learning and required polynomial query lengths, preventing arbitrarily long queries from being hidden in an auxiliary complexity parameter.

Result

The reconstruction problem admits a deterministic adaptive algorithm with running time polynomial in \(d,\tau,n,L\). It uses \(O(d^2\tau n)\) oracle queries, each of binary length \(O(dn)\). The canonical binary encoding of every answer used by the algorithm has length \(O(d(\tau L+n))\).

In fact, the algorithm recovers the original normalized types and their masses exactly, which is stronger than demand-equivalent reconstruction.

For \(d=1\), the only normalized type is \((1)\), so the answer is immediate. Henceforth assume \(d\geq2\).

1. Small-budget queries reveal cumulative masses

We first establish precisely what an individual buyer purchases in the queries we will use.

Lemma 1. Suppose every price satisfies \(p_i\geq1\), and the common budget is \(B=1/2\). Let \(h\) be the largest coordinate index maximizing \(a_i/p_i\). Then

\(b_a(p,1/2)=\frac{1}{2p_h}e_h.\)

Proof. Every feasible bundle satisfies \(x_i\leq1/(2p_i)\leq1/2\), so the upper bounds \(x_i\leq1\) impose no additional restriction.

Write \(c=\max_i a_i/p_i\). Normalization implies \(c>0\). For every feasible bundle,

\(a\cdot x=\sum_i\frac{a_i}{p_i}p_ix_i\leq c\sum_i p_ix_i\leq c/2.\)

Purchasing \(1/(2p_h)\) units of good \(h\) attains this bound. Equality requires spending the entire budget exclusively on goods maximizing \(a_i/p_i\). Thus all utility maximizers have the same expenditure.

Among these maximizers, the lexicographically smallest bundle places all expenditure on the largest maximizing index: each earlier coordinate can be set to zero, and lexicographic minimization requires doing so. This proves the formula. \(\square\)

This small-budget observation also underlies the single-buyer algorithm of [Balcan et al.](https://arxiv.org/pdf/1407.7937v1). We will use it to obtain cumulative-mass queries for a sparse distribution.

2. A finite grid separates every possible utility ratio

Set

\(Q=2^{2n},\qquad K=4n+3,\qquad M=2^{K+n-1}.\)

If \(a_j>0\), define \(r_k=a_k/a_j\) for \(k\neq j\). Each such ratio satisfies

\(0\leq r_k<2^n,\)

and its reduced denominator is less than \(Q\). Indeed, each positive coordinate is greater than \(2^{-n}\), and each coordinate is at most \(1\). Moreover, writing the coordinates as reduced fractions, the denominator of their ratio before reduction is a product of two positive integers less than \(2^n\).

For integers \(z\in\{0,\ldots,M\}\), define

\(t_z=\frac{2z+1}{2^K}.\)

These thresholds have three useful properties.

  • No ratio equals a threshold. The reduced denominator of \(t_z\) is exactly \(2^K>Q\).
  • The largest threshold exceeds every ratio. We have \(t_M=2^n+2^{-K}\).
  • Each grid cell contains at most one possible ratio. Distinct reduced rationals with denominators less than \(Q\) differ by more than \(Q^{-2}\), whereas consecutive thresholds differ by

\(2^{1-K}<Q^{-2}\).

Define the label of a ratio by

\(\ell(r)=\min\{z\in\{0,\ldots,M\}:r<t_z\}.\)

Consequently, the label uniquely determines every possible ratio.

Fix a reference good \(j\), and index the other goods in their original coordinate order. For a label vector \(z=(z_k)_{k\neq j}\), make the query

\(p_j=2^K,\qquad p_k=2z_k+1\ \text{for }k\neq j,\qquad B=1/2.\)

All prices are positive integers. For a type with \(a_j>0\),

\(\frac{a_k}{p_k}<\frac{a_j}{p_j}\quad\Longleftrightarrow\quad\frac{a_k}{a_j}<t_{z_k}.\)

Equality is impossible by the threshold construction. Hence good \(j\) is the unique maximizer exactly when all these inequalities hold. A type with \(a_j=0\) never purchases good \(j\), since some coordinate has positive utility.

Lemma 1 therefore gives

\(F_j(z):=2^{K+1}D_\mu(p,1/2)=\sum_{a:a_j>0}\mu_a\,\mathbf 1\{\ell(a_k/a_j)\leq z_k\text{ for every }k\neq j\}.\)

Thus one demand query implements one lower-orthant cumulative-mass query for the label vectors of types with \(a_j>0\).

For a fixed reference \(j\), distinct normalized types yield distinct ratio vectors: the ratios determine the type through

\(a_j=\frac{1}{1+\sum_{k\neq j}r_k},\qquad a_k=r_ka_j.\)

Since labels uniquely determine ratios, distinct types also yield distinct label vectors. Therefore \(F_j\) represents a positive measure with at most \(\tau\) distinct atoms, whose masses are precisely the corresponding original masses.

3. Sparse positive measures can be recovered from cumulative queries

We now prove the reconstruction procedure needed for each reference good.

Lemma 2. Let \(\nu\) be a positive measure supported on at most \(s\) points of \(\{0,\ldots,M\}^k\). Given exact queries

\(F(z)=\nu(\{y:y_i\leq z_i\text{ for all }i\}),\)

one can recover every atom and its mass deterministically using at most

\(1+s\bigl(k\lceil\log_2(M+1)\rceil+1\bigr)\)

queries.

Proof. First query the total mass \(T=F(M,\ldots,M)\).

Suppose some atoms \((y^{(u)},w_u)\) have already been recovered correctly. Their contributions can be subtracted to evaluate

\(R(z)=F(z)-\sum_u w_u\,\mathbf 1\{y^{(u)}\leq z\}.\)

Here vector inequalities mean coordinatewise inequalities. By the induction hypothesis, \(R\) is exactly the cumulative function of the remaining positive measure.

If the recovered masses sum to \(T\), reconstruction is finished. Otherwise, locate the lexicographically smallest remaining support point \(v\), coordinate by coordinate.

Choose \(v_1\) as the smallest integer \(t\) such that

\(R(t,M,\ldots,M)>0.\)

This predicate is monotone in \(t\), so binary search suffices. Having chosen \(v_1,\ldots,v_{h-1}\), choose \(v_h\) as the smallest integer \(t\) such that

\(R(v_1,\ldots,v_{h-1},t,M,\ldots,M)>0.\)

To justify this search, induct on \(h\). After the preceding choices, every remaining support point satisfying the preceding upper bounds must have prefix exactly \((v_1,\ldots,v_{h-1})\): a smaller coordinate at the first differing position would contradict an earlier minimum. Thus the new search selects the minimum next coordinate among points with that exact prefix. Its predicate is positive at \(t=M\).

At the end, \(v\) is a remaining support point. Moreover, it is the only remaining support point dominated coordinatewise by \(v\). Indeed, any different such point would have a smaller coordinate at its first differing position, contradicting the corresponding search minimum. Therefore its exact mass is

\(w=R(v)>0.\)

Record \((v,w)\) and repeat. Each iteration removes one original atom, so there are at most \(s\) iterations. The stated query bound follows. \(\square\)

Positivity is essential here: a positive cumulative value certifies the existence of a remaining atom. The procedure uses only cumulative queries and subtraction of already recovered atoms.

4. Recovering exact ratios and the society

Apply Lemma 2 to each \(F_j\), with \(k=d-1\) and \(s\leq\tau\). It remains to decode each recovered label.

If \(\ell(r)=0\), then \(r=0\): any positive rational with denominator less than \(Q\) is greater than \(1/Q>t_0\).

For a positive label \(z\), the ratio satisfies

\(t_{z-1}<r<t_z.\)

Let the midpoint of this interval be

\(c_z=\frac{2z}{2^K}.\)

Writing \(r=u/v\) in lowest terms, we have \(v<Q\) and

\(\left|r-c_z\right|<2^{-K}=\frac{1}{8Q^2}<\frac{1}{2v^2}.\)

We use Legendre’s continued-fraction theorem: if a reduced rational \(u/v\), with \(v>0\), satisfies \(\left|\xi-u/v\right|<1/(2v^2)\), then it is a convergent of the continued fraction of \(\xi\). This statement applies to rational \(\xi\) as well; see the [formal theorem in Mathlib](https://leanprover-community.github.io/mathlib_docs/number_theory/diophantine_approximation.html#real.exists_rat_eq_convergent).

All its hypotheses have just been checked for \(\xi=c_z\). Compute the finite continued fraction of \(c_z\) by the Euclidean algorithm, and select the convergent with denominator less than \(Q\) lying in \((t_{z-1},t_z)\). Such a convergent exists by the theorem and is unique by the rational-separation bound. Since \(c_z\) has \(O(n)\)-bit numerator and denominator, this decoding takes polynomial time in \(n\).

Decode all ratios of each recovered atom, then normalize using

\(a_j=\frac{1}{1+\sum_{k\neq j}r_k},\qquad a_k=r_ka_j.\)

The injectivity proved in Section 2 guarantees that this recovers exactly one original type, with its original mass.

Finally, take the union of the recovered type lists over all reference goods. When a type occurs in several lists, retain one copy with its mass; do not add these duplicate masses. Each list recovers the same original mass for that type.

Every normalized type has at least one positive coordinate, so every original type appears in at least one list. Consequently, this union is exactly the original support with exactly the original masses. It contains \(\tau\) types, belongs to \(\mathcal A_{d,n}\), and has positive masses summing to \(1\). In particular,

\(D_{\widehat\mu}(p,B)=D_\mu(p,B)\)

for every rational nonnegative query, including queries with zero prices or binding caps.

5. Binary running time

Because \(\log_2 M=5n+2\), the total number of demand queries is at most

\(d\left[1+\tau\left((d-1)(5n+3)+1\right)\right]=O(d^2\tau n).\)

Every queried price has \(O(n)\) bits, and the budget is always \(1/2\). Thus each complete query has length \(O(dn)\).

To bound answer lengths, let \(H\) be the product of the reduced denominators of the original masses. Then

\(\log_2 H\leq\tau L.\)

By Lemma 1, for every query used here and every coordinate \(i\),

\(D_{\mu,i}(p,1/2)=\frac{1}{2p_i}\sum_{a:h(a,p)=i}\mu_a.\)

The subset sum has denominator dividing \(H\). Therefore the reduced denominator of this demand coordinate divides \(2p_iH\), and its numerator has no greater binary length, since the coordinate lies in \([0,1]\). Each coordinate answer consequently has \(O(\tau L+n)\) bits; the complete answer has \(O(d(\tau L+n))\) bits.

Cumulative values and residual values are sums of subsets of original masses, so their reduced denominators also divide \(H\). Reducing fractions after arithmetic therefore keeps their bit lengths polynomial. Evaluating a residual requires comparing at most \(\tau\) recovered label vectors and subtracting their masses. Continued-fraction decoding uses polynomial time, and normalization involves only \(d\) rationals with \(O(n)\)-bit components, hence polynomial-size intermediate arithmetic.

These bounds include reading and processing every coordinate of every oracle answer. They use the usual canonical binary rational encoding; arbitrary redundant padding would make a bit-time guarantee ill-posed independently of reconstruction.

The algorithm is therefore deterministic and polynomial in \(m=d,\tau,n,L\) in the stated exact-oracle model.
