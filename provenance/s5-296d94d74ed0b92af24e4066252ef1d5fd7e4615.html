The continuous mirror question, as graded

Given a finite support \(T\) of \(\tau\) interchangeable types, rational masses \(\mu_t>0\) summing to \(1\), a symmetric rational similarity kernel \(c:T\times T\to[0,1]\) with \(c(t,t)=1\), and an integer \(k\), decide whether there is a set \(R\subseteq T\) with \(|R|=k\) such that \(\sum_{t\in T}\mu_t\max_{r\in R}c(r,t)\geq\omega\). Each type’s mass is assigned to its most-similar representative, split evenly among ties.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a nonempty list \(T\) of \(\tau\) interchangeable types with positive binary-rational masses \(\mu_t\), where \(\sum_{t\in T}\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types.
The input also contains the explicitly listed symmetric rational kernel \(c:T\times T\to[0,1]\), with \(c(t,t)=1\), an integer \(1\leq k\leq\tau\), and a binary-rational threshold \(\omega\in[0,1]\). No metric or preference-realizability restriction is imposed on the kernel.
Representatives form a set \(R\subseteq T\) with \(|R|=k\). Each type assigns its entire mass to representatives maximizing \(c(r,t)\), divided equally among ties. Define \(F(R)=\sum_{t\in T}\mu_t\max_{r\in R}c(r,t)\).
Let \(L\) be the total binary input length. State running times in \(\tau,k,L\); this kernel formulation has no alternative-count parameter \(m\).

Is deciding whether some representative set \(R\) satisfies \(F(R)\geq\omega\) solvable in polynomial time, or is it NP-hard?

For a finite population with unit agent weights, selecting exactly \(k\) representatives whose sum of maximum similarities reaches an input threshold is NP-hard, even for symmetric rational similarities with diagonal entries equal to \(1\).
No separate complexity result for the rational-mass formulation was verified.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Result

The decision problem is \(\mathrm{NP}\)-complete, even when every mass equals \(1/\tau\), \(\tau\) is a power of two, every kernel entry belongs to \(\{0,1\}\), and \(\omega=1\). Thus the hardness holds even if “binary-rational” is interpreted as requiring dyadic rational masses.

Here \(k\) is part of the input. A polynomial-time algorithm for all instances exists if and only if \(\mathrm{P}=\mathrm{NP}\).

Membership in \(\mathrm{NP}\) and running times

A certificate is a set \(R\subseteq T\) of exactly \(k\) distinct types. For each \(t\in T\), compute
\[ v_t=\max_{r\in R}c(r,t), \]
and then compare \(\sum_{t\in T}\mu_t v_t\) with \(\omega\).

This requires \(O(\tau k)\) rational comparisons. The final comparison can also be performed exactly with polynomially bounded integers. To see this explicitly, write
\[ \mu_t=\frac{a_t}{b_t},\qquad v_t=\frac{p_t}{q_t},\qquad \omega=\frac{a_\omega}{b_\omega}. \]
Each \(v_t\) is an entry of the input kernel. Let \(D\) be the product of all denominator occurrences in the input masses, kernel, and threshold. Its binary length is \(O(L)\), and both \(b_tq_t\) and \(b_\omega\) divide \(D\). Consequently, the required comparison is the integer comparison
\[ \sum_{t\in T}a_tp_t\frac{D}{b_tq_t} \ \geq\ a_\omega\frac{D}{b_\omega}. \]
All integers involved have \(O(L)\) bits: each summand is nonnegative, and their sum is \(DF(R)\leq D\).

Using schoolbook integer arithmetic, verification takes \(O(\tau kL^2)\) bit operations. Therefore the problem belongs to \(\mathrm{NP}\).

Enumerating all representative sets gives an exact algorithm with running time
\[ O\!\left(\binom{\tau}{k}\tau kL^2\right). \]
In particular, the problem is polynomial-time solvable for each fixed \(k\). The hardness below concerns unrestricted input \(k\).

A reduction from Boolean \(3\)-satisfiability

We use the standard theorem that Boolean \(3\)-satisfiability is \(\mathrm{NP}\)-complete. The reduction below handles clauses containing at most three literals, so it also applies to the usual restriction to three literals per clause.

Let a formula have variables \(x_1,\ldots,x_n\) and clauses \(C_1,\ldots,C_m\), with \(n\geq1\). Construct a simple undirected graph \(G\) as follows:

  • For each variable \(x_i\), introduce three vertices \(v_i^+,v_i^-,u_i\), and join all three pairs to form a triangle.
  • For each clause \(C_j\), introduce a vertex \(w_j\).
  • Join \(w_j\) to \(v_i^+\) whenever \(x_i\) occurs in \(C_j\), and to \(v_i^-\) whenever \(\neg x_i\) occurs in \(C_j\).
  • Add no other edges.

A set \(S\) dominates a graph if every vertex either belongs to \(S\) or has a neighbor in \(S\).

We prove the equivalence
\[ \text{the formula is satisfiable} \quad\Longleftrightarrow\quad G\text{ has a dominating set of size exactly }n. \]

Forward direction. Given a satisfying assignment, select \(v_i^+\) if \(x_i\) is true and \(v_i^-\) if \(x_i\) is false. These \(n\) vertices dominate every variable triangle. Each clause contains a true literal, so its clause vertex has a selected neighbor. Thus the selected set dominates \(G\).

Reverse direction. Suppose \(S\) dominates \(G\) and \(|S|=n\). The only neighbors of \(u_i\) are \(v_i^+\) and \(v_i^-\). Hence \(S\) must contain at least one vertex from each variable triangle. These \(n\) triangles are disjoint, so \(S\) contains exactly one vertex from each and contains no clause vertex.

Assign \(x_i\) to true when \(v_i^+\in S\), to false when \(v_i^-\in S\), and arbitrarily when \(u_i\in S\). Every clause vertex must have a selected neighbor, and all its neighbors are literal vertices. A selected neighboring literal is true under this assignment. Therefore every clause is satisfied, proving the equivalence.

Conversion to a rational-mass society

The graph \(G\) has \(N=3n+m\) vertices. Let
\[ P=2^{\lceil\log_2 N\rceil}, \qquad s=P-N, \]
and form \(H\) by adding \(s\) isolated vertices to \(G\).

Define the society by
\[ T=V(H),\qquad \tau=P,\qquad \mu_t=\frac1P\quad(t\in T),\qquad k=n+s,\qquad \omega=1. \]
All masses are positive dyadic rationals and sum to \(1\). Also,
\[ 1\leq k=n+s\leq N+s=\tau. \]

Define the kernel by
\[ c(u,v)= \begin{cases} 1,&u=v\text{ or }\{u,v\}\in E(H),\\ 0,&\text{otherwise}. \end{cases} \]
This kernel is explicitly representable, symmetric, rational, takes values in \([0,1]\), and has diagonal entries equal to \(1\).

For every nonempty representative set \(R\),
\[ \max_{r\in R}c(r,t)= \begin{cases} 1,&t\text{ is dominated by }R,\\ 0,&t\text{ is not dominated by }R. \end{cases} \]
It follows that
\[ F(R)= \frac{\bigl|\{t\in V(H):t\text{ is dominated by }R\}\bigr|}{P}. \]
Consequently, \(F(R)\geq1\) holds exactly when \(R\) dominates \(H\).

Every dominating set of \(H\) must contain all \(s\) isolated vertices. Therefore a dominating set of size exactly \(n+s\) in \(H\) exists if and only if a dominating set of size exactly \(n\) in \(G\) exists. Combined with the preceding proof, this gives
\[ \text{the formula is satisfiable} \quad\Longleftrightarrow\quad \exists R\subseteq T,\ |R|=k,\ F(R)\geq\omega. \]

Finally, \(P<2N\). The construction therefore has polynomial support size, an explicitly listed kernel of polynomial size, and masses with \(O(\log\tau)\)-bit encodings. It is a polynomial-time many-one reduction.

Conclusion

The rational-mass formulation is \(\mathrm{NP}\)-hard, and its polynomial-time certificate verification makes it \(\mathrm{NP}\)-complete. This proof establishes the result directly and covers dyadic masses without relying on an unverified transfer from the finite-population formulation.
