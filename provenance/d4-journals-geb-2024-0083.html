The continuous mirror question, as graded

Given finite worker types \(W\) and position types \(F\), rational type masses and capacities, shared strict rankings over mutually acceptable types, and type-level assignment constraints, compute a finite union of rational polyhedra describing all stable mass assignments. Each assignment is a matrix \(x\ge 0\) with row and column sums bounded by the corresponding masses and capacities; forbidden pairs require \(x_{ij}=0\), while an in-constraint requires the whole specified type mass to be assigned within its permitted set. For each acceptable pair \((i,j)\), stability requires that either \(a_i-\sum_k x_{ik}+\sum_{k:\,j\succ_i k}x_{ik}=0\) or \(b_j-\sum_h x_{hj}+\sum_{h:\,i\succ_j h}x_{hj}=0\). Can this description be computed in time polynomial in the input encoding size plus polynomial work per output polyhedron?

Packaged proof task (what the prover saw — nothing else)

Let \(W\) and \(F\) be nonempty finite sets of worker and position types, with \(m=|F|\). A society is given by its support: the list of its \(\tau=|W|+|F|\) types with positive binary-rational masses, where position masses are capacities; \(\tau\) counts listed types, not all possible types. Write worker masses as \(a_i\), position capacities as \(b_j\), and total input bit length as \(L\); totals need not equal each other or be normalized.
Each type has a strict ranking of a nonempty list of acceptable opposite-side types, shared by all its members; acceptability is mutual and preferred to remaining unmatched.
A mass assignment is \(x\in\mathbb R_{\geq0}^{W\times F}\), with \(\sum_jx_{ij}\leq a_i\), \(\sum_ix_{ij}\leq b_j\), and \(x_{ij}=0\) on unacceptable pairs. Worker- and position-side out-constraints also require their specified pairs to have zero mass.
A worker-side in-constraint with permitted set \(S_i\subseteq F\) requires \(\sum_{j\in S_i}x_{ij}=a_i\); a position-side in-constraint with permitted set \(T_j\subseteq W\) requires \(\sum_{i\in T_j}x_{ij}=b_j\). Both kinds of constraint may coexist.
Stability requires, for every acceptable pair \((i,j)\), \(a_i-\sum_kx_{ik}+\sum_{k:\,j\succ_i k}x_{ik}=0\) or \(b_j-\sum_hx_{hj}+\sum_{h:\,i\succ_j h}x_{hj}=0\), including acceptable pairs forbidden by constraints; \(\succ\) denotes strict preference.
The description sought is a finite list of distinct nonempty rational polyhedra in the assignment variables, given by binary-rational linear inequalities, whose union is exactly the constrained stable assignments; the empty list describes infeasibility. Each output polyhedron must have encoding length polynomial in \(m,\tau,L\); let \(s\) be the number output.

Is constrained stable-mass feasibility in \(\mathrm P\) or \(\mathrm{NP}\)-hard? Can the complete polyhedral description be computed in total time \((s+1)\operatorname{poly}(m,\tau,L)\)?

For discrete forced and forbidden pairs, feasibility and enumeration take \(O(N^3(1+s_d))\) total time with \(O(N^3)\) delay, where \(N\) is the larger number of workers and individual positions and \(s_d\) counts solutions ([Gutin–Neary–Yeo](https://arxiv.org/html/2204.03989v4)).
A single unconstrained bipartite stable allocation with divisible quantities can be computed in strongly polynomial time ([Dean–Munshi](https://people.computing.clemson.edu/~bcdean/stable_alloc.pdf)); this result does not establish constrained polyhedral enumeration.

Modeling choices made when packaging the task

  • Masses and capacities are strictly positive binary rationals, expressed in common units without normalization or equal-total requirements, preserving potentially unbalanced markets.
  • Each type has a nonempty acceptable list; acceptability is mutual, rankings are strict within each type, and acceptable assignments are preferred to remaining unmatched.
  • Position-side in-constraints require the entire capacity to be filled from the permitted worker set, paralleling worker-side full-mass requirements.
  • Assignments may have arbitrary nonnegative real entries; constraints forbid assignments without removing acceptable pairs from stability checks.
  • Polyhedra are represented by explicit rational linear inequalities in the assignment variables, with polynomial encoding length; outputs are distinct and nonempty, and infeasibility is represented by the empty list.
  • The enumeration time means a total bound polynomial in the input parameters times one plus the number of output polyhedra, rather than a polynomial-delay requirement.

Result

Constrained stable-mass feasibility is in \(\mathrm P\). A complete polyhedral description can be computed in total time \((s+1)\operatorname{poly}(m,\tau,L)\).

The enumeration below outputs closures of feasible rotation cells, including their faces. These are distinct, nonempty polyhedra; some may be contained in others. The question does not require an irredundant or minimum-size description.

1. Reduction to bipartite stable allocation

Let \(E\subseteq W\times F\) be the acceptable pairs, and write \(e=|E|\). Retain every edge of \(E\), including pairs forbidden by the assignment constraints.

For each acceptable pair, introduce the redundant edge capacity

\[ u_{ij}=\min(a_i,b_j). \]

These capacities do not change assignment feasibility. They also do not change stability: if \(x_{ij}=u_{ij}\), then at least one endpoint assigns its entire mass to the other endpoint, so that endpoint’s dissatisfaction expression is zero. If \(x_{ij}<u_{ij}\), the pair blocks precisely when both dissatisfaction expressions are positive.

For completeness, unequal totals and unmatched mass can be handled explicitly. Put \(A=\sum_i a_i\) and \(B=\sum_j b_j\). Add a dummy worker of mass \(B\) and a dummy position of capacity \(A\). Each original type ranks its dummy partner last; each dummy ranks the other dummy last. Give every added edge the capacity equal to the minimum of its endpoint quotas.

An original assignment has a unique extension satisfying all augmented row and column equalities:

\[ x_{i0}=a_i-\sum_jx_{ij},\qquad x_{0j}=b_j-\sum_ix_{ij},\qquad x_{00}=\sum_{i,j}x_{ij}. \]

No dummy edge can block: on each such edge, at least one endpoint ranks the other last and has no worse assignment. Thus extension and restriction give inverse bijections between original stable assignments and augmented stable allocations.

The augmented instance has \(\tau+2\) vertices and \(e+\tau+1\) edges.

2. The rotation representation used

We use the following published structural result, beyond the computation of a single allocation.

For a bipartite stable-allocation instance, one can compute a base allocation \(x^0\), a poset of \(k=O(e+\tau)\) rotations, positive multiplicities \(r_v\), and rotation directions \(\rho^v\), with entries in \(\{-1,0,1\}\). Stable allocations are represented bijectively by

\[ \Phi(y)=x^0+\sum_{v=1}^k y_v\rho^v, \]

where

\[ 0\leq y_v\leq r_v,\qquad p\prec q,\ y_q>0\ \Longrightarrow\ y_p=r_p. \]

The representation is computable in polynomial time. These are the rotation construction and correspondence in Section 4, particularly Lemmas 10–12, of [Dean–Munshi](https://people.computing.clemson.edu/~bcdean/stable_alloc.pdf).

Restrict \(x^0\) and the directions to the original assignment coordinates. The representation remains bijective, because the dummy extension is unique.

Let \(\mathcal C\) denote the displayed domain of rotation vectors. A vector in \(\mathcal C\) will be called *closed*. The hypotheses of the cited result hold: the instance is bipartite, preferences are strict, and all quotas and edge capacities are rational.

The construction also has polynomial bit complexity here. After scaling by a common denominator of polynomial bit length, its arithmetic uses integer additions, subtractions, comparisons, and minima. Its polynomial number of operations therefore produces data of polynomial bit length.

3. All assignment constraints form one nonnegative penalty

Let \(E_{\mathrm{out}}\) be the union of the worker-side and position-side forbidden acceptable pairs. Let \(I\) and \(J\) index the worker-side and position-side in-constraints.

Define the affine function

\[ H(x)= \sum_{(i,j)\in E_{\mathrm{out}}}x_{ij} +\sum_{i\in I}\left(a_i-\sum_{j\in S_i}x_{ij}\right) +\sum_{j\in J}\left(b_j-\sum_{i\in T_j}x_{ij}\right). \]

Every summand is nonnegative on every feasible assignment. For example,

\[ \sum_{j\in S_i}x_{ij}\leq\sum_jx_{ij}\leq a_i. \]

Consequently, an assignment satisfies all specified constraints if and only if \(H(x)=0\). Constraints on unacceptable pairs hold automatically.

In rotation coordinates, write

\[ \ell(y)=H(\Phi(y))=\gamma+\sum_{v=1}^k c_vy_v. \]

All these coefficients are computable exactly in polynomial time, and

\[ \ell(y)\geq0\qquad\text{for every }y\in\mathcal C. \]

Thus the target set is precisely \(\Phi(\{y\in\mathcal C:\ell(y)=0\})\).

4. Polynomial-time feasibility

First observe a property of partially applied rotations.

Lemma 1. If \(y\in\mathcal C\) and \(0<y_v<r_v\), every predecessor of \(v\) is fully applied and every successor is unused. With all other coordinates fixed, \(y_v\) can vary throughout \([0,r_v]\) while preserving closedness.

Proof. Positive \(y_v\) forces every predecessor to its upper bound. A positive successor would force \(y_v=r_v\), which is excluded. These conditions remain sufficient throughout the indicated interval. \(\square\)

Because \(\ell\) is affine, Lemma 1 lets us replace any partial coordinate by an endpoint without increasing \(\ell\). Repeating this produces a closed vector with every coordinate in \(\{0,r_v\}\). Hence the minimum of \(\ell\) over \(\mathcal C\) is attained at such a vector.

These endpoint vectors correspond exactly to ideals of the rotation poset. Here an ideal \(K\) means that \(q\in K\) and \(p\prec q\) imply \(p\in K\). Its objective value is

\[ \gamma+\sum_{v\in K}c_vr_v. \]

Minimum-weight ideal selection is a polynomial-time minimum-cut problem. Explicitly, for weights \(w_v=c_vr_v\), use:

  • an arc from the source to \(v\) of capacity \(-w_v\) when \(w_v<0\);
  • an arc from \(v\) to the sink of capacity \(w_v\) when \(w_v>0\);
  • an arc from \(q\) to \(p\), for each precedence \(p\prec q\), of capacity \(M>\sum_v|w_v|\).

A minimum cut crosses no precedence arc: a cut respecting precedence exists with capacity at most \(\sum_v|w_v|\). The vertices on its source side therefore form an ideal. For an ideal \(K\), the cut capacity is

\[ \sum_{w_v<0}|w_v|+\sum_{v\in K}w_v, \]

so minimizing the cut minimizes the ideal weight.

The minimum of \(H\) is nonnegative. It is zero exactly when the constraints are feasible. All capacities have polynomial bit length, proving feasibility is in \(\mathrm P\).

5. Feasible cells

Give each rotation one of three statuses:

  • \(0\): unused, so \(y_v=0\);
  • \(1\): fully applied, so \(y_v=r_v\);
  • \(*\): partially applied, so \(0<y_v<r_v\).

A complete status pattern determines an open coordinate cell. Suppose that cell contains a closed vector. Its closure is the box obtained by replacing each partial interval with \([0,r_v]\).

This entire box lies in \(\mathcal C\). Indeed, every predecessor of a \(*\) coordinate has status \(1\), every successor has status \(0\), and every predecessor of a status-\(1\) coordinate also has status \(1\).

The nonnegative penalty has a useful consequence.

Lemma 2. If such an open cell contains a vector with \(\ell(y)=0\), then \(\ell\) vanishes throughout its closure.

Proof. At that vector, each free coordinate can be varied slightly in either direction while staying in the box. Since \(\ell\) is nonnegative on the box and equals zero at the vector, its coefficient on each free coordinate must be zero. Its value therefore remains zero throughout the box. \(\square\)

Thus every feasible complete pattern yields a nonempty polyhedron of constrained stable assignments. Every constrained stable assignment belongs to the box associated with its own status pattern.

It remains to enumerate exactly these patterns without spending time on branches with no feasible completion.

6. A polynomial-time oracle for status prefixes

Fix an order of the rotations. A prefix prescribes statuses on some initial segment. Let \(Z,O,P\) be its sets of unused, fully applied, and partially applied rotations.

Closedness forces the following additional endpoint statuses:

\[ O'=O\cup\operatorname{Pred}(O\cup P),\qquad Z'=Z\cup\operatorname{Succ}(Z\cup P), \]

where predecessors and successors are strict and transitive.

Reject the prefix if \(O',Z',P\) are not pairwise disjoint. This also detects comparable rotations in \(P\).

There is another necessary rejection rule: if \(c_v\neq0\) for some \(v\in P\), reject.

To justify it, suppose a feasible completion existed. By Lemma 1, varying \(y_v\) slightly in either direction would preserve closedness. Nonnegativity of \(\ell\), together with its zero value at the completion, would force \(c_v=0\).

Assume these checks pass. Set

\[ y_v=r_v\quad(v\in O'),\qquad y_v=0\quad(v\in Z'),\qquad y_v=r_v/2\quad(v\in P). \]

Let \(U\) contain the remaining rotations. Every rotation of \(U\) is incomparable with every rotation of \(P\).

The prefix has a feasible completion if and only if it has one in which all coordinates of \(U\) are endpoints.

For the nontrivial direction, take any feasible completion. The coefficients on its partial coordinates are zero, by the same variation argument. Set the prescribed partial coordinates to their midpoints. Then round every other partial coordinate to an endpoint. Lemma 1 preserves closedness at each step, and the zero coefficients preserve \(\ell=0\).

Endpoint completions correspond exactly to ideals \(K\) of the induced poset on \(U\): fully apply \(K\), and leave \(U\setminus K\) unused. Indeed, \(O'\) is downward closed, \(Z'\) is upward closed, and every predecessor of a prescribed partial rotation is already in \(O'\).

Their penalty values are

\[ \gamma+\sum_{v\in O'}c_vr_v+\sum_{v\in K}c_vr_v. \]

The prescribed partial coordinates contribute zero. A minimum-weight ideal computation therefore decides whether this expression can equal zero.

This gives an exact polynomial-time prefix oracle.

7. Polynomial-size inequalities in assignment variables

Consider a feasible complete pattern. Let \(P\) be its free rotations and \(O\) its fully applied rotations. Its image is

\[ \mathcal Q= \left\{ h+\sum_{v\in P}t_v\rho^v: 0\leq t_v\leq r_v \right\}, \qquad h=x^0+\sum_{v\in O}r_v\rho^v. \]

We must describe this polyhedron without retaining auxiliary rotation variables.

Let \(V\) be the matrix whose columns are \(\rho^v\), for \(v\in P\), in the original assignment coordinates. It has full column rank. Otherwise, a nonzero kernel vector would give two distinct parameter vectors sufficiently close to the box’s midpoint with the same assignment image, contradicting the bijectivity of \(\Phi\).

Choose \(|P|\) coordinate rows \(R\) such that \(V_R\) is nonsingular. Define the affine expression

\[ t(x)=V_R^{-1}(x_R-h_R). \]

Then \(\mathcal Q\) is described exactly, in assignment variables, by

\[ x-h=Vt(x),\qquad 0\leq t_v(x)\leq r_v\quad(v\in P). \]

Each equality can be written as two inequalities. If \(P\) is empty, the description is simply \(x=h\).

There are polynomially many coefficients. Gaussian elimination computes them in polynomial time, and rational matrix inversion gives polynomial bit length. In particular, \(V_R\) has entries in \(\{-1,0,1\}\), so determinant bounds give polynomial bit length for its inverse. Thus every output polyhedron has the required polynomial encoding length.

8. Enumeration, distinctness, and total time

Run a depth-first ternary search over rotation statuses. Apply the prefix oracle at every node, and prune rejected nodes. At every surviving complete pattern, output its polyhedron.

Correctness. Lemma 2 shows that every output lies entirely in the constrained stable set. Conversely, each constrained stable assignment has a unique rotation vector and hence a status pattern. That vector witnesses acceptance of every prefix along its path, so its polyhedron is output.

Distinctness. Different surviving complete patterns define different coordinate boxes: a coordinate fixed at an endpoint differs from a free coordinate, and the two endpoints differ from each other. All boxes lie in \(\mathcal C\). Since \(\Phi\) is injective there, their image polyhedra are distinct.

Running time. Let \(s\) be the number output. Every accepted node has an accepted complete descendant, by the oracle’s correctness. The depth is \(k\), so accepted nodes lie on the union of \(s\) paths of length \(k\), giving at most \((k+1)s\) accepted nodes. Each has at most three children to test.

If \(s=0\), the root is rejected. Otherwise, the number of oracle calls is \(O(1+ks)\). Each call and each output construction takes polynomial time in \(m,\tau,L\), and \(k=O(e+\tau)\). The total time is therefore

\[ (s+1)\operatorname{poly}(m,\tau,L). \]

This uses the listed types directly; no expansion into individual workers or positions is required.
