The anchor (named result in the paper)

Theorem 4.2 — class: hardness

The continuous mirror question, as graded

Given a finite type set \(T\) with rational masses \(\mu_t\ge 0\) summing to \(1\), a laminar family \(\mathcal E\subseteq 2^T\) of coalition templates, strict rankings \(\succ_t\) over each type's incident templates, and rational weights \(w_e\), choose coalition masses \(x_e\ge 0\) satisfying \(\sum_{e\ni t}x_e\le \mu_t\). Define \(q_{t,e}(x)=\mu_t-\sum_{f\ni t:\,f\succeq_t e}x_f\); stability requires every template \(e\) to have some \(t\in e\) with \(q_{t,e}(x)=0\). Find a stable allocation maximizing \(\sum_{e\in\mathcal E}w_ex_e\); for the one-positive-weight case, decide whether a distinguished singleton template can receive its type's full mass.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a list \(T\) of \(\tau\) types with positive binary-rational masses \(\mu_t\), where \(\sum_{t\in T}\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types.
There are \(m\) explicitly listed, labeled coalition templates \(e\in\mathcal E\), with nonempty incidence sets \(S_e\subseteq T\); distinct templates may have identical incidence sets. These sets are laminar: any two are disjoint or one contains the other. Each type strictly ranks all its incident labeled templates; \(f\succeq_t e\) means \(f=e\) or \(f\succ_t e\).
An allocation \(x\in\mathbb R_{\ge0}^{m}\) is feasible if \(\sum_{e:t\in S_e}x_e\le\mu_t\) for every \(t\). It is stable if every template \(e\), including those receiving positive mass, has some \(t\in S_e\) satisfying \(\mu_t-\sum_{f:t\in S_f,\ f\succeq_t e}x_f=0\).
Given signed binary-rational weights \(w_e\), maximize \(\sum_e w_ex_e\) over stable allocations. The associated decision problem supplies a binary-rational threshold \(B\) and asks whether this objective can reach \(B\). In the singleton restriction, a distinguished template \(e_\star\) has \(S_{e_\star}=\{t_\star\}\), weight \(1\), and all other weights \(0\); ask whether a stable allocation satisfies \(x_{e_\star}=\mu_{t_\star}\).
Is exact maximum-weight stable allocation solvable in polynomial time, or is its threshold decision problem \(\mathsf{NP}\)-hard? Independently, is the singleton full-mass decision problem in \(\mathsf P\) or \(\mathsf{NP}\)-hard? State running times in \(m\), \(\tau\), and the total input bit length \(L\).
For discrete matchings, the weight-threshold problem is \(\mathsf{NP}\)-complete even with only one weight-\(1\) singleton and all other weights \(0\), allowing parallel templates; finding an arbitrary stable laminar matching with integer vertex capacities is polynomial-time solvable. Result

Both the weight-threshold decision problem and the singleton full-mass decision problem are \(\mathsf{NP}\)-complete. This holds even with equal dyadic masses and only one nonzero weight, assigned to a singleton template. Consequently, exact maximum-weight stable allocation is \(\mathsf{NP}\)-hard.

The key fact is that fixing stability witnesses defines a face of the feasibility polytope. Laminarity makes this polytope integral when capacities are integral, so continuous solutions cannot evade the discrete hardness result.

1. Stability defines a union of faces

Let \(A\in\{0,1\}^{\tau\times m}\) be the incidence matrix, where \(A_{te}=1\) exactly when \(t\in S_e\). Write

\(P(\mu)=\{x\in\mathbb R_{\geq 0}^{m}:Ax\leq\mu\}\).

This is a nonempty compact polytope: it contains the zero vector, and nonemptiness of each \(S_e\) implies \(x_e\leq\min_{t\in S_e}\mu_t\).

For an incident pair \(t\in S_e\), define the linear form

\(h_{e,t}(x)=\sum_{f:t\in S_f,\ f\succeq_t e}x_f\).

Every point of \(P(\mu)\) satisfies \(h_{e,t}(x)\leq\mu_t\). Indeed,

\(\mu_t-h_{e,t}(x)=\left(\mu_t-\sum_{f:t\in S_f}x_f\right)+\sum_{f:t\in S_f,\ e\succ_t f}x_f\),

and both terms on the right are nonnegative. Thus equality holds exactly when type \(t\) is saturated and every incident template ranked below \(e\) receives zero mass.

A witness map chooses \(\sigma(e)\in S_e\) for every template. Define

\(F_\sigma=\{x\in P(\mu):h_{e,\sigma(e)}(x)=\mu_{\sigma(e)}\text{ for every }e\}\).

Each nonempty \(F_\sigma\) is a face of \(P(\mu)\). To verify this directly, suppose \(x=\lambda y+(1-\lambda)z\in F_\sigma\), where \(y,z\in P(\mu)\) and \(0<\lambda<1\). Each relevant linear form is bounded above by its required value. Its equality at \(x\) therefore forces equality at both \(y\) and \(z\). Hence \(y,z\in F_\sigma\).

The stable set is exactly \(\bigcup_\sigma F_\sigma\): a stable allocation supplies one witness per template, and any allocation in \(F_\sigma\) has all the required witnesses.

Consequently, for every stable allocation \(x\) and every linear objective \(w^\mathsf Tx\), there is a stable vertex \(v\) of \(P(\mu)\) with \(w^\mathsf Tv\geq w^\mathsf Tx\).

For proof, choose \(F_\sigma\) containing \(x\), and maximize the objective on that compact polytope. A maximizing vertex exists. Every vertex of \(F_\sigma\) is a vertex of \(P(\mu)\): otherwise a nontrivial convex decomposition in \(P(\mu)\) would, by the face property, also be a decomposition in \(F_\sigma\). Every point of \(F_\sigma\), including this vertex, is stable.

This argument explicitly includes templates receiving positive mass.

2. Laminarity gives integral vertices at unit capacities

We prove that \(A\) is totally unimodular, including when templates have identical incidence sets.

First order the types so that every distinct incidence set is an interval. Such an ordering exists: adjoin \(T\) and all singleton sets to the distinct incidence sets, organize this laminar family into its inclusion tree, and list singleton leaves recursively, keeping each child subtree contiguous. Every set then consists of consecutive leaves. Parallel templates simply produce identical columns.

Consider any square submatrix \(C\) of \(A\), retaining the induced row order. Each column still has consecutive ones. Apply the determinant-preserving row transformation that keeps the first row and replaces row \(i\) by original row \(i\) minus original row \(i-1\). The resulting matrix \(D\) has, in each column, at most one entry \(1\) and at most one entry \(-1\).

Every square matrix with this latter property has determinant in \(\{0,1,-1\}\). This follows by induction on its order:

  • A zero column gives determinant zero.
  • A column with one nonzero entry permits cofactor expansion, reducing to a smaller matrix with the same property.
  • If every column has two nonzero entries, they have opposite signs. All column sums are zero, so the matrix is singular.

Therefore \(\det C=\det D\in\{0,1,-1\}\), proving total unimodularity.

Appending rows of \(-I_m\) preserves total unimodularity: expand any minor involving such a row along its sole possible nonzero entry. Hence the constraint matrix of

\(Q=\{y\in\mathbb R_{\geq0}^{m}:Ay\leq\mathbf1\}\)

is totally unimodular.

At any vertex of \(Q\), choose \(m\) independent active constraints. Their coefficient matrix has determinant \(1\) or \(-1\), and their right-hand side is integral. Cramer’s rule therefore makes the vertex integral. Since every column of \(A\) is nonzero, feasibility also gives \(y_e\leq1\). Thus every vertex belongs to \(\{0,1\}^{m}\) and represents a discrete matching.

For such a vector, continuous stability at unit capacities is exactly discrete matching stability:

  • If \(e\) is selected, each type in \(S_e\) is saturated by \(e\) alone, so \(e\) satisfies the continuous condition using itself.
  • If \(e\) is unselected, its prefix sum equals \(1\) at a type exactly when that type is covered by a selected template strictly preferred to \(e\). This is precisely the discrete condition preventing \(e\) from blocking.

Combining this equivalence with Section 1 proves:

Every linear objective on stable allocations in \(Q\) has a maximizing allocation that is the incidence vector of a discrete stable matching.

In particular, fractional allocations cannot improve the optimal value at unit capacities.

3. Reduction proving hardness of both questions

Use the following discrete result supplied in the question: deciding whether a laminar instance with labeled parallel templates has a stable matching containing a distinguished singleton template is \(\mathsf{NP}\)-complete. The singleton restriction is explicit in the construction proving [Biró–Csáji–Schlotter, Theorem 4.3, Appendix D.1](https://arxiv.org/html/2502.08827v2#A4.SS1).

Take such an instance with \(n\) vertices and \(m_0\) templates. Let \(N\) be the smallest power of two satisfying \(N\geq n\). Add \(N-n\) dummy types, each with its own unique singleton template. These templates have weight zero and are disjoint from every original template. Laminarity is preserved.

Set \(q=1/N\) and give every type mass \(q\). The resulting support has size \(\tau=N\), and its masses are positive dyadic rationals summing to one. Preserve all original rankings. Each dummy type has only its singleton template.

Give the distinguished original singleton \(e_\star\) weight \(1\), every other template weight \(0\), and set \(B=q\).

Scaling by \(x=qy\) transforms feasibility into \(Ay\leq\mathbf1\), and transforms each stability equality into

\(\sum_{f:t\in S_f,\ f\succeq_t e}y_f=1\).

Thus scaling preserves stability.

If the original discrete instance has a stable matching containing \(e_\star\), append all dummy singleton templates and scale its incidence vector by \(q\). This yields a stable allocation with \(x_{e_\star}=q=\mu_{t_\star}\).

Conversely, suppose the constructed instance has a stable allocation with \(x_{e_\star}=q\). Its scaled allocation \(y=x/q\) is stable in \(Q\) and satisfies \(y_{e_\star}=1\). By Section 1, maximizing the coordinate \(y_{e_\star}\) on its witness face yields a stable vertex \(v\) with \(v_{e_\star}\geq1\). Feasibility gives \(v_{e_\star}\leq1\), so equality holds. Section 2 makes \(v\) a discrete stable matching containing \(e_\star\). Removing the disjoint dummy templates leaves a stable matching in the original instance.

Finally, feasibility gives \(x_{e_\star}\leq q\). Because the objective is exactly \(x_{e_\star}\), reaching threshold \(B=q\) is equivalent to the singleton full-mass requirement. Hence this one reduction proves hardness of both decision problems.

The construction has \(\tau=N<2n\) and \(m=m_0+N-n<m_0+n\). Each mass requires \(O(\log n)\) bits, and the complete construction takes polynomial time in the original input length.

4. Membership in \(\mathsf{NP}\)

For arbitrary input masses and signed weights, a yes-instance of the threshold problem has a stable vertex meeting the threshold, by Section 1.

Such a vertex has a polynomial-size certificate: specify \(m\) independent active constraints among the \(\tau\) capacity constraints and \(m\) nonnegativity constraints. A verifier solves the corresponding rational linear system and checks feasibility, stability, and the objective threshold using exact arithmetic. Rational linear-system solving and all these checks take \(\operatorname{poly}(m,\tau,L)\) bit operations.

For the singleton problem, start with a stable allocation satisfying \(x_{e_\star}=\mu_{t_\star}\). Maximizing \(x_{e_\star}\) on its witness face produces a stable vertex retaining equality, because feasibility bounds that coordinate above by \(\mu_{t_\star}\). The same certificate and verification procedure apply.

Therefore both decision problems belong to \(\mathsf{NP}\), completing their \(\mathsf{NP}\)-completeness proofs.

5. Exact algorithms and running times

Stable allocations exist under the stated hypotheses. Scarf’s lemma says that a nonnegative matrix with nonzero columns, positive capacities, and strict row preferences admits a feasible point that saturates some incident row for every column using only weakly preferred columns. Here these hypotheses follow respectively from incidence, nonempty templates, positive masses, and the given rankings; Section 1 identifies its conclusion with the required stability condition. See [Lemma 2.1 in Biró–Csáji–Schlotter](https://arxiv.org/html/2502.08827v2#S2.SS1).

The stable set is a finite union of compact faces, so every linear objective attains its maximum. Section 1 shows that some maximizing allocation is a vertex of \(P(\mu)\).

An exact algorithm therefore enumerates all choices of \(m\) constraints from the \(m+\tau\) feasibility constraints. For each choice, it solves the active equations, discards singular or infeasible candidates, checks stability, and compares objective values. Every vertex is encountered.

Its bit running time is

\(\binom{m+\tau}{m}\operatorname{poly}(m,\tau,L)\leq2^{m+\tau}\operatorname{poly}(m,\tau,L)\).

This algorithm returns an exact maximizing allocation and value, and also decides the singleton problem. It is polynomial for fixed \(m\) or fixed \(\tau\). An alternative enumerates the witness maps and solves one rational linear program per map, giving running time

\(\left(\prod_{e\in\mathcal E}|S_e|\right)\operatorname{poly}(m,\tau,L)\leq\tau^m\operatorname{poly}(m,\tau,L)\).

For unrestricted \(m\), \(\tau\), and \(L\), a polynomial-time exact maximization algorithm—or a polynomial-time algorithm for either decision problem—would imply \(\mathsf P=\mathsf{NP}\).
