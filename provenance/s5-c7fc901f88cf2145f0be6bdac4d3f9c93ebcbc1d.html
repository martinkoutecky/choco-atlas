2. A vertex bound and an explicit normalization

Write the input polytopes as \(P_1,\ldots,P_k\), with \(V(x)=c_i\cdot x+d_i\) on \(P_i\). Let \(\mathcal V\) denote all listed vertices, counting repetitions.

Define the rational number

\(M=\max_{v\in\mathcal V,\ v\ne0}\frac{|V(v)|}{|v|}.\)

This maximum is well-defined: every nonzero vertex has positive mass because its coordinates are nonnegative, and some listed vertex is nonzero because the polytopes cover the nontrivial box.

Claim. For every \(x\in[0,\mu]\),

\(|V(x)|\le M|x|.\)

Proof. Choose a polytope \(P_i\) containing \(x\). By the vertex representation of a polytope, there are its vertices \(v_1,\ldots,v_r\) and coefficients \(\lambda_j\ge0\), with \(\sum_j\lambda_j=1\), such that \(x=\sum_j\lambda_jv_j\). Affineness gives

\(V(x)=\sum_j\lambda_jV(v_j).\)

For nonzero vertices, \(|V(v_j)|\le M|v_j|\) by definition. The same inequality holds at the zero vertex because \(V(0)=0\). Consequently,

\(|V(x)|\le\sum_j\lambda_j|V(v_j)|\le M\sum_j\lambda_j|v_j|=M|x|.\)

The last equality uses nonnegative coordinates, on which mass is linear. This proves the claim.

Now set

\(\delta=\beta-\alpha,\qquad c=\frac{\alpha+\beta}{2},\qquad \sigma=\frac{\delta}{2(M+1)},\qquad a_t=c\quad(t\in T).\)

These parameters are rational, and \(\sigma>0\). For every coalition,

\(W(x)=c|x|+\sigma V(x),\)

so

\(|W(x)-c|x||\le \frac{\delta M}{2(M+1)}|x|\le\frac{\delta}{2}|x|.\)

Since \(c-\delta/2=\alpha\) and \(c+\delta/2=\beta\), this proves

\(\alpha|x|\le W(x)\le\beta|x|\)

throughout the box. Replacing \(\sigma\) by \(-\sigma\), while keeping the same \(a_t\), also gives an admissible normalization.

Thus existence is completely established, including the nonzero-scale requirement.

3. A sharper construction using superadditivity

The promises allow an alternative construction that attains both bounds at suitable coalitions.

Computing the marginal slopes

Fix a supported type \(t\). For each cell, define

\(I_{i,t}=\{h\in[0,\mu_t]:he_t\in P_i\}.\)

Each nonempty \(I_{i,t}\) is a closed interval, possibly a single point, and these finitely many intervals cover \([0,\mu_t]\).

At least one contains \([0,r_t]\) for some \(r_t>0\). Otherwise, intervals containing zero would be singletons, and every other nonempty interval would have a positive left endpoint. Their finitely many positive left endpoints would leave sufficiently small positive \(h\) uncovered, a contradiction.

For such a cell, \(d_i=V(0)=0\). Hence

\(V(he_t)=c_{i,t}h\quad(0\le h\le r_t),\qquad b_t=c_{i,t}.\)

In particular, the limit defining \(b_t\) exists and is rational.

These coefficients can be found directly from the vertex lists. A suitable cell contains the zero vertex and a nonzero vertex on the \(t\)-axis:

  • Any cell containing zero has zero as a vertex, because all its vertices have nonnegative coordinates.
  • If a cell contains a positive point on that axis, express the point as a convex combination of its vertices. Nonnegativity forces every vertex with positive coefficient to lie on the same axis, and at least one is nonzero.

Conversely, a cell listing zero and \(se_t\), with \(s>0\), contains their segment. Its coefficient \(c_{i,t}\) therefore equals \(b_t\). Any two such choices give the same coefficient because their segments overlap near zero and the formulas agree there.

Nonnegativity of the residual

Define

\(D(x)=V(x)-\sum_t b_tx_t.\)

Claim. \(D(x)\ge0\) everywhere.

Proof. If \(x_t>0\), choose a positive integer \(n\) sufficiently large that \(x_t/n\le r_t\). Repeated superadditivity gives

\(V(x_te_t)\ge nV((x_t/n)e_t)=b_tx_t.\)

Every partial sum used here lies in the box because it is bounded coordinatewise by \(x_te_t\). The same inequality holds when \(x_t=0\), using \(V(0)=0\).

Next add the axis coalitions one at a time. Their partial sums are bounded coordinatewise by \(x\), so superadditivity applies again and gives

\(V(x)\ge\sum_tV(x_te_t)\ge\sum_tb_tx_t.\)

This proves the claim.

The exact residual bound

Compute

\(H=\max_{v\in\mathcal V,\ v\ne0}\frac{D(v)}{|v|}.\)

The same convex-combination calculation used in Section 2 gives

\(0\le D(x)\le H|x|\quad(x\in[0,\mu]).\)

Essentiality states \(D(\mu)>0\). Since \(|\mu|=1\), the preceding bound implies \(H\ge D(\mu)>0\).

Therefore the following rational parameters are well-defined:

\(\sigma_+=\frac{\delta}{H},\qquad a_t^+=\alpha-\sigma_+b_t.\)

They give

\(W_+(x)=\alpha|x|+\frac{\delta}{H}D(x),\)

and consequently \(\alpha|x|\le W_+(x)\le\beta|x|\).

For a negative scale, use

\(\sigma_-=-\frac{\delta}{H},\qquad a_t^-=\beta+\frac{\delta}{H}b_t.\)

Then

\(W_-(x)=\beta|x|-\frac{\delta}{H}D(x),\)

which satisfies the same bounds.

For the positive construction, the lower bound is attained on sufficiently short axis segments, and the upper bound is attained at a nonzero listed vertex maximizing \(H\). For the negative construction, these roles are reversed.
