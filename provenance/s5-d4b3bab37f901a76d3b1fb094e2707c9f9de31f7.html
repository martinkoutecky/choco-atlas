Theorem 3.6 — class: hardness

The continuous mirror question, as graded

For fixed \(p\in(0,1]\), given finite valuation types \(T\) with rational masses \(\mu_t\), finite item types \(G\) with rational per-capita supplies \(q_g\), \(\sum_t\mu_t=1\), and additive values \(v_t(g)\), choose masses \(x_{t,B}\ge0\) for integral bundles \(B\subseteq G\) satisfying \(\sum_{B\subseteq G}x_{t,B}=\mu_t\) and \(\sum_{t,B:g\in B}x_{t,B}=q_g\). Require that whenever \(x_{t,B}>0\) and \(x_{u,C}>0\), \(v_t(B)\ge v_t(C\setminus\{g\})\) for every \(g\in C\) with \(v_t(g)>0\), and maximize \(W_p(x)=\left(\sum_{t,B}x_{t,B}v_t(B)^p\right)^{1/p}\).

Packaged proof task (what the prover saw — nothing else)

Fix a rational \(p\in(0,1]\) and an integer \(c\leq3\).
A society is given by its support: the list \(T\) of \(\tau\geq1\) valuation types with positive binary-rational masses \(\mu_t\), summing to \(1\); \(\tau\) is the support size, not the number of possible types.
There are \(m\geq1\) item types \(G\), with binary-rational supplies \(0<q_g\leq1\) and nonnegative binary-rational additive values \(v_t(g)\); each item type is positively valued by some supported type.
To retain the few-surplus condition, a positive integer population scale \(n\) is supplied in binary, with \(n+c\geq1\) and \(\sum_gq_g=1+c/n\). Masses need not be multiples of \(1/n\). Let \(L\) be the total binary input length.
Each person receives an integral bundle \(B\subseteq G\), possibly empty, containing at most one item of each type. An allocation consists of real masses \(x_{t,B}\geq0\) satisfying \(\sum_{B\subseteq G}x_{t,B}=\mu_t\) and \(\sum_{t,B:g\in B}x_{t,B}=q_g\).
Require EFX across all occupied bundles: whenever \(x_{t,B}>0\) and \(x_{u,C}>0\), require \(v_t(B)\geq v_t(C\setminus\{g\})\) for every \(g\in C\) with \(v_t(g)>0\), including comparisons within the same valuation type.
Maximize \(W_p(x)=\bigl(\sum_{t,B}x_{t,B}v_t(B)^p\bigr)^{1/p}\); infeasible instances are permitted.

For each fixed \(p\) and \(c\) above, is exact EFX-constrained welfare maximization, including recognizing infeasibility, solvable in time polynomial in \(m,\tau,L\), or is it NP-hard?

Discrete EFX-constrained welfare maximization is NP-hard for every fixed \(p\in(0,1]\) and integer \(c\leq3\) when the number of goods equals the number of agents plus \(c\). [Source](https://arxiv.org/html/2601.12849v1)
No result settling this precise mass allocation problem was located in the literature search.

Modeling choices made when packaging the task

  • Restricted the unspecified numerical domain of valuations to nonnegative binary rationals and retained the requirement that every item type is positively valued by some supported type.
  • Chose fixed rational p to give exact optimization an effective numerical specification.
  • Restored the omitted few-surplus condition using a binary-encoded population scale n and total per-capita supply 1+c/n; this scale imposes no integrality restriction on masses.
  • Took listed item types to have positive supplies at most one, consistent with bundles containing at most one item of each type.
  • Allowed empty bundles and infeasible instances; the discrete existence guarantee does not automatically apply to arbitrary type supplies.

Result

Exact EFX-constrained welfare maximization is \(\mathrm{NP}\)-hard for every fixed rational \(p\in(0,1]\) and every fixed integer \(c\leq3\).

The hardness holds even when \(\tau=3\), every constructed instance is EFX-feasible, and all masses, supplies, and valuations are dyadic rationals. Thus recognizing infeasibility is not needed for the hardness.

The construction adapts the partition-and-special-items idea in [Appendix A.6 of the cited paper](https://arxiv.org/html/2601.12849v1), with a separate argument accounting for arbitrary mass splitting.

1. A partition problem with a convenient target

Write \(p=a/b\), where \(a,b\) are fixed positive integers and \(a\leq b\).

We reduce from binary-encoded PARTITION: given positive integers \(d_1,\ldots,d_\ell\), decide whether some subset sums to half their total \(A=\sum_i d_i\).

Choose \(H=2^{br}>2A\), with \(r\) the smallest positive integer satisfying this inequality. Form the list
\(w_1,\ldots,w_k\), where \(k=\ell+2\), consisting of

\[ \]
\(2d_1,\ldots,2d_\ell,H-A,H-A.\)

Its total is \(2H\). A subset summing to \(H\) must contain exactly one of the last two numbers: without them its sum is at most \(2A<H\), while both together sum to \(2H-2A>H\). Its remaining numbers therefore sum to \(A\), which is equivalent to a subset of the original numbers summing to \(A/2\).

Consequently, deciding whether some subset of the \(w_j\) sums to \(H\) is \(\mathrm{NP}\)-hard. This transformation has polynomial encoding length. Moreover, \(H^p=2^{ar}\) is an integer.

Choose a fixed constant \(D=2^{bs}\), with \(s\) a positive integer large enough that

\(D^p(1-2^{-p})>1.\)

Such a choice exists because \(p>0\). Both \(D^p\) and \((DH)^p\) are integers.

2. Construction of the mass-allocation instance

Let \(C=|c|+2\), and choose \(n\) to be the smallest power of two strictly greater than \(k+4C+|c|+4\).

There are three supported valuation types, denoted \(P,J,F\), with masses

\(\alpha=1/n,\qquad \beta=C/n,\qquad \gamma=1-\alpha-\beta.\)

There are \(k+3\) item types: \(g_1,\ldots,g_k,x,y,z\). Their valuations are:

| Type | \(g_j\) | \(x\) | \(y\) | \(z\) |
|---|---:|---:|---:|---:|
| \(P\) | \(w_j\) | \(H\) | \(H\) | \(0\) |
| \(J\) | \(0\) | \(DH/2\) | \(DH/2\) | \(0\) |
| \(F\) | \(0\) | \(0\) | \(0\) | \(1\) |

Define supplies by

\(q_{g_j}=\alpha/2,\qquad q_x=q_y=\beta,\qquad q_z=Q,\)

where

\(h=k\alpha/2+2\beta,\qquad Q=1+c/n-h.\)

These supplies satisfy the required identity

\(\sum_{g\in G}q_g=1+c/n.\)

For later use, observe that

\(Q-h=1+(c-k-4C)/n>0,\)

and

\(\gamma-Q=(k/2+C-1-c)/n=(k/2+|c|+1-c)/n>0.\)

Thus \(0<h<Q<\gamma<1\). All masses are positive, every supply belongs to \((0,1]\), and \(n+c\geq1\). Every item is positively valued by a supported type.

Because \(n\) is a power of two and all displayed valuations are integers, the numerical inputs are dyadic rationals. Their total encoding length is polynomial in the PARTITION input length.

3. Every constructed instance is EFX-feasible

Give types \(P\) and \(J\) only the empty bundle.

For type \(F\), assign:

  • mass \(q_g\) to \(\{z,g\}\), for each \(g\neq z\);
  • mass \(Q-h\) to \(\{z\}\);
  • mass \(\gamma-Q\) to the empty bundle.

The masses of type \(F\) sum to
\(h+(Q-h)+(\gamma-Q)=\gamma\).
Each item \(g\neq z\) has its required supply, and the total mass receiving \(z\) is \(h+(Q-h)=Q\).

Every occupied bundle contains at most one item positively valued by any given type. Removing that item leaves value zero to that type. Since every own-bundle value is nonnegative, all EFX comparisons hold, including comparisons within a type.

Hence the construction is EFX-feasible independently of the partition answer.

4. An unconditional welfare upper bound

Use the equivalent objective

\(\Phi_p(x)=W_p(x)^p=\sum_{t,B}x_{t,B}v_t(B)^p.\)

Since \(p>0\), maximizing \(\Phi_p\) and maximizing \(W_p\) are equivalent.

First maximize \(\Phi_p\) without EFX. This unrestricted allocation polytope is nonempty and compact: it has finitely many bundle variables, closed constraints, and \(0\leq x_{t,B}\leq\mu_t\). Thus a maximizer exists.

Ownership in every unrestricted maximizer

We claim that every unrestricted maximizer assigns each \(g_j\) exclusively to \(P\), assigns \(x,y\) exclusively to \(J\), and assigns \(z\) exclusively to \(F\).

Here is the mass-transfer argument. Suppose an item \(g\) is received by some type other than its designated type \(s\). Its supply satisfies \(q_g\leq\mu_s\). Writing \(r\) for the mass of type \(s\) currently holding \(g\), positive outside ownership gives \(r<q_g\), so

\(\mu_s-r\geq q_g-r>0.\)

There is therefore an occupied bundle \(A\) of type \(s\) not containing \(g\), and an occupied outside bundle \(B\) containing \(g\). For sufficiently small positive mass \(\delta\), replace \(\delta\) of \(A\) by \(A\cup\{g\}\), and \(\delta\) of \(B\) by \(B\setminus\{g\}\). This preserves every type mass and item supply.

For a partition item \(g_j\), or for \(z\), the outside recipient values the transferred item at zero, while its designated recipient values it positively. The transfer strictly increases \(\Phi_p\).

For \(x\) or \(y\), the increase to type \(J\), per unit of transferred mass, is at least

\((DH)^p-(DH/2)^p.\)

Indeed, a type-\(J\) bundle missing that item has value at most \(DH/2\), and concavity makes the increment from adding a fixed value nonincreasing in the initial value.

The outside recipient values the item at either \(H\) or zero. Its loss in powered utility is at most \(H^p\), by subadditivity:

\((u+v)^p\leq u^p+v^p\qquad(u,v\geq0).\)

For completeness, this inequality follows by dividing by \((u+v)^p\) and using \(t^p\geq t\) on \([0,1]\); the zero-total case is immediate.

Consequently, the net increase per unit mass is at least

\(H^p\bigl(D^p(1-2^{-p})-1\bigr)>0.\)

Every violation of the asserted ownership therefore contradicts unrestricted optimality.

Computing the bound

Under this ownership structure, every type-\(J\) person receives \(\{x,y\}\): each special item has supply equal to the entire mass \(\beta\) of that type. Its contribution is \(\beta(DH)^p\).

Type \(F\) receives only \(z\) or the empty bundle, contributing \(Q\).

Type \(P\) receives only partition items. Its total utility, integrated over its mass, is

\(\sum_B x_{P,B}v_P(B)=\sum_j(\alpha/2)w_j=\alpha H.\)

Jensen’s inequality, applied with probabilities \(x_{P,B}/\alpha\), gives

\(\sum_B x_{P,B}v_P(B)^p\leq\alpha H^p.\)

Define the threshold

\(R=\alpha H^p+\beta(DH)^p+Q.\)

Every unrestricted maximizer has value at most \(R\). Therefore every allocation, with or without EFX, satisfies \(\Phi_p(x)\leq R\).

The threshold \(R\) is a polynomial-length dyadic rational, because \(H^p\) and \((DH)^p\) are integers.

5. Attaining the bound is equivalent to partition

A partition yields an EFX allocation attaining the bound

Suppose \(S\subseteq\{1,\ldots,k\}\) satisfies \(\sum_{j\in S}w_j=H\). Its complement also sums to \(H\).

Assign:

  • type \(P\): mass \(\alpha/2\) to each of the two complementary partition bundles;
  • type \(J\): mass \(\beta\) to \(\{x,y\}\);
  • type \(F\): mass \(Q\) to \(\{z\}\), and mass \(\gamma-Q\) to the empty bundle.

These masses satisfy every supply constraint.

Each type-\(P\) bundle has value \(H\). Against another partition bundle, removing any positively valued item leaves value at most \(H\). Against \(\{x,y\}\), removing either item leaves exactly \(H\). Type \(P\) values \(z\) at zero.

Type \(J\) values only \(x,y\), which it receives together; all other types’ occupied bundles have value zero to it. Type \(F\) values only the singleton \(z\), whose removal leaves zero. These observations also verify every comparison within a type.

The allocation is EFX and satisfies \(\Phi_p(x)=R\).

An EFX allocation attaining the bound yields a partition

Conversely, suppose an EFX allocation satisfies \(\Phi_p(x)\geq R\). The upper bound forces equality.

This allocation is consequently an unrestricted maximizer, so it has the ownership structure proved above. In particular, \(\{x,y\}\) is occupied by type \(J\).

For every occupied type-\(P\) bundle \(B\), EFX toward that bundle, after removing \(x\), requires

\(v_P(B)\geq v_P(\{y\})=H.\)

But type \(P\)’s integrated utility is exactly \(\alpha H\). Thus

\(\sum_B x_{P,B}\bigl(v_P(B)-H\bigr)=0.\)

Every summand is nonnegative, so every occupied type-\(P\) bundle has value exactly \(H\).

Since \(\alpha>0\), at least one such bundle exists. Ownership ensures it consists solely of partition items, giving a subset of the \(w_j\) summing to \(H\). By Section 1, the original PARTITION instance is a yes-instance.

This argument applies equally at \(p=1\); it does not require strict concavity.

6. Complexity conclusion

We have established the equivalence

\(\text{PARTITION is yes}\quad\Longleftrightarrow\quad\exists\text{ EFX allocation }x\text{ with }W_p(x)^p\geq R.\)

The reduction is polynomial, uses exactly three supported types, and always produces an EFX-feasible instance. Hence the welfare-threshold problem, and therefore exact EFX-constrained welfare maximization, is \(\mathrm{NP}\)-hard for every fixed \(p,c\) in the question.

If the objective is expressed directly as \(W_p\), its threshold is \(R^{b/a}\), an explicitly represented algebraic number of fixed degree.
