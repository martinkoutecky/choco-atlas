The continuous mirror question, as graded

Given a realizable weighted tournament \(W\) induced by a finite-support society of \(\tau\) voter types with binary-rational masses \(\mu_t\), compute a candidate \(j\) using only \(W\) such that, for every compatible mass society and every consistent metric \(d\) with positive optimal cost, \(\mathrm{SC}_{\mu}(j,d)/\min_{c\in C}\mathrm{SC}_{\mu}(c,d)\le 1+2\sqrt{2}\).

Packaged proof task (what the prover saw — nothing else)

Let \(C\) be a labelled set of \(m\ge 2\) candidates. A society is given by its support: a list \(T\) of \(\tau\ge 1\) types, each reporting a strict ranking \(\succ_t\) and having positive binary-rational mass \(\mu_t\), with \(\sum_{t\in T}\mu_t=1\). Here \(\tau\) is the support size, not the number of possible rankings.
Its weighted tournament is \(W=(w_{ab})\), where \(w_{ab}=\sum_{t:a\succ_t b}\mu_t\) for distinct candidates and \(w_{aa}=1/2\). The input is a binary-rational \(W\), promised realizable by such a society; the rule observes only \(W\).
A compatible society is any finite-support rational-mass society inducing exactly \(W\), with no bound on its support size. A consistent nonnegative pseudometric \(d\) on the disjoint union \(T\sqcup C\) satisfies \(a\succ_t b\Rightarrow d(t,a)\le d(t,b)\); distance ties may therefore follow the reported strict ranking.
Define \(\mathrm{SC}_{\mu}(c,d)=\sum_{t\in T}\mu_t d(t,c)\). A deterministic rule must return the same labelled candidate for identical \(W\), independently of the compatible society or metric.
Let \(L\) be the total binary encoding length of the support description and \(W\). State running times in \(m,\tau,L\), while preserving the restriction that the winner depends only on \(W\).

Can a polynomial-time deterministic rule using only \(W\) select \(j\in C\) such that \(\mathrm{SC}_{\mu}(j,d)/\min_{c\in C}\mathrm{SC}_{\mu}(c,d)\le 1+2\sqrt{2}\) for every compatible society and every consistent pseudometric with positive optimal cost, or is computing a winner with this approximation guarantee NP-hard?

For finite equal-weight electorates, a polynomial-time deterministic weighted-tournament rule achieves distortion at most \(1+2\sqrt{2}\), uniformly over \(m\ge2\). [Source](https://arxiv.org/html/2608.15247v1).

Result

The required winner can be computed in polynomial time using only \(W\). An exact implementation of the cited rule takes \(O(m^{4}L^{2})\) bit operations. Its guarantee extends to every compatible finite-support rational-mass society, without expanding the electorate during computation.

The proof has two distinct parts: an exact implementation on binary-rational tournaments, and a transfer of the equal-weight guarantee to rational masses.

1. The rule and the theorem used

Fix a total order on candidate labels, independently of the society, and set \(\lambda=\sqrt{2}\).

For distinct candidates \(j,k\), define a directed graph \(G(j,k)\) on \(C\) by

\[ a\to b \quad\Longleftrightarrow\quad w_{bj}\le\sqrt{2}\,w_{ak}. \]

Say that \(j\) passes if, for every \(i\ne j\), some \(k\ne j\) satisfies both:

  • \(k=i\) or \(w_{ij}\le\sqrt{2}\,w_{ki}\);
  • \(k\) is reachable from \(j\) in \(G(j,k)\).

Return the first passing candidate in the fixed label order.

This is the Path-Unblanketed Set rule. The cited paper’s Theorems 1 and 2 establish that a passing candidate exists and that this rule has distortion at most \(1+2\sqrt{2}\) for finite equal-weight electorates. Its Section 2 explicitly permits pseudometrics and weak distance inequalities for consistency, matching the conventions here. [Chan, Lin and Wang, Sections 2–3.1](https://arxiv.org/html/2608.15247v1#S3.SS1).

We use this equal-weight result as the known theorem supplied in the question.

2. Exact polynomial-time computation

Every numerical test in the rule has the form \(x\le\sqrt{2}\,y\), where \(x,y\) are nonnegative rationals.

Write \(x=p/q\) and \(y=r/s\), with \(p,r\ge0\) and \(q,s>0\). Then

\[ x\le\sqrt{2}\,y \quad\Longleftrightarrow\quad ps\le\sqrt{2}\,rq \quad\Longleftrightarrow\quad (ps)^2\le2(rq)^2. \]

The last equivalence holds because both sides before squaring are nonnegative. Thus all tests, including boundary cases involving zero, reduce to exact integer arithmetic.

Let \(B\) be the encoding length of \(W\), including its labels; \(B\le L\). Each input integer has at most \(B\) bits, and the products and squares above have \(O(B)\) bits. Schoolbook multiplication therefore evaluates each comparison in \(O(B^2)\) bit operations.

Implement the rule as follows:

  • For each ordered pair \(j\ne k\), construct \(G(j,k)\) and record whether \(k\) is reachable from \(j\).
  • For each \(j\), inspect every \(i\ne j\) and enumerate possible \(k\ne j\), checking admissibility and the recorded reachability.
  • Return the first passing \(j\).

There are \(O(m^2)\) graphs, each requiring \(O(m^2)\) comparisons. Graph construction therefore costs \(O(m^4B^2)\). Reachability in each graph takes \(O(m^2)\) graph operations. The final inspection uses \(O(m^3)\) further comparisons. Even charging bit costs for vertex indices, these terms are bounded by \(O(m^4B^2)\).

Consequently the running time is

\[ O(m^4B^2)\subseteq O(m^4L^2). \]

The algorithm reads only \(W\) and candidate labels. It has no additional dependence on \(\tau\), uses no realization of \(W\), and never constructs replicated voters.

3. Transfer to every compatible rational-mass society

Fix an arbitrary compatible society with finite support \(S\), positive rational masses \(\nu_s\), and a consistent nonnegative pseudometric \(d\) on \(S\sqcup C\). Assume its optimal social cost is positive.

Choose a positive integer \(Q\) divisible by all denominators of the \(\nu_s\), and put \(n_s=Q\nu_s\). Each \(n_s\) is a positive integer, and

\[ \sum_{s\in S}n_s=Q\sum_{s\in S}\nu_s=Q. \]

Construct, solely for the proof, the equal-weight voter set

\[ V=\{(s,r):s\in S,\ 1\le r\le n_s\}. \]

Every copy of \(s\) reports \(s\)’s strict ranking. Define \(\pi:V\sqcup C\to S\sqcup C\) by \(\pi(s,r)=s\) and \(\pi(c)=c\), and define

\[ d'(x,y)=d(\pi(x),\pi(y)). \]

This is a nonnegative pseudometric. Symmetry and the zero diagonal follow directly from those of \(d\). For any \(x,y,z\),

\[ d'(x,z) =d(\pi(x),\pi(z)) \le d(\pi(x),\pi(y))+d(\pi(y),\pi(z)) =d'(x,y)+d'(y,z). \]

Consistency also transfers: if a copy of \(s\) ranks \(a\) above \(b\), then

\[ d'((s,r),a)=d(s,a)\le d(s,b)=d'((s,r),b). \]

Distinct copies may have distance zero, which is permitted by the pseudometric hypothesis.

For distinct candidates \(a,b\), the replicated electorate induces

\[ w'_{ab} =\frac{1}{Q}\sum_{s:\,a\succ_s b}n_s =\sum_{s:\,a\succ_s b}\nu_s =w_{ab}. \]

Its diagonal convention also agrees with \(W\). Hence the replicated electorate has exactly the same labelled tournament, and the rule returns the same candidate \(j=f(W)\).

For every candidate \(c\), its unnormalized equal-weight social cost is

\[ \mathrm{SC}_{V}(c,d') =\sum_{s\in S}n_s d(s,c) =Q\,\mathrm{SC}_{\nu}(c,d). \]

In particular, \(\min_c\mathrm{SC}_{V}(c,d')=Q\min_c\mathrm{SC}_{\nu}(c,d)>0\). All hypotheses of the cited equal-weight theorem now hold: the electorate is finite, rankings are strict, \(d'\) is a consistent pseudometric, and optimal cost is positive. Applying that theorem gives

\[ \frac{\mathrm{SC}_{\nu}(j,d)} {\min_c\mathrm{SC}_{\nu}(c,d)} = \frac{\mathrm{SC}_{V}(j,d')} {\min_c\mathrm{SC}_{V}(c,d')} \le1+2\sqrt{2}. \]

The compatible society and metric were arbitrary. Therefore this single candidate \(f(W)\) satisfies the required guarantee for every compatible society and consistent pseudometric with positive optimal cost.

4. Conclusion

The rational-mass model is polynomial-time solvable. Replication establishes the guarantee, while exact rational comparisons establish polynomial running time in the succinct input length. No bound on compatible support size is needed.
