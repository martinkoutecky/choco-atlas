Theorem B.3 — class: hardness

The continuous mirror question, as graded

Given \(m\) alternatives and a finite support of complete acceptability types \(t\), each with utility vector \(u_t\), threshold \(\theta_t\), and rational mass \(\mu_t\) summing to one, decide whether there is a lottery \(x\in\Delta(S)\) such that \(\sum_{t:\langle u_t,x\rangle\ge\theta_t}\mu_t\ge\rho\), for a given rational quota \(\rho\); equivalently, compute the maximum accepted mass. Is this problem NP-hard, including when utilities are binary and the masses come from the paper’s clique construction?

Packaged proof task (what the prover saw — nothing else)

Let \(S\) contain \(m\ge2\) alternatives. A society is given by its support: the list of \(\tau\ge1\) distinct types with positive mass, each mass a binary rational; \(\tau\) is the support size, not the number of possible types. Masses satisfy \(\sum_t\mu_t=1\).
Each type explicitly specifies binary-rational utilities \(u_t\in[0,1]^m\) and a binary-rational threshold \(\theta_t\in(0,1]\). It accepts a lottery \(x\in\Delta(S)\) exactly when \(\langle u_t,x\rangle\ge\theta_t\), including equality; its entire mass then accepts.
Given a binary-rational quota \(\rho\in[0,1]\), accepted-mass decision asks whether some lottery satisfies \(\sum_{t:\langle u_t,x\rangle\ge\theta_t}\mu_t\ge\rho\). Let \(L\) be the total input bit length; state running times in \(m,\tau,L\) and any additional parameters.
Also consider this binary graph family: take a simple undirected graph \(G=(V,E)\), \(|V|=m\), \(M=|E|\), and an integer \(2\le\kappa\le m\); set \(R=m+M+1\) and \(D=Rm+m+M\).
For each vertex \(v\), include a type with utility zero at \(v\) and one elsewhere, threshold \(1-1/\kappa\), and mass \(R/D\), and a type with utility one at \(v\) and zero elsewhere, threshold \(1/\kappa\), and mass \(1/D\). For each edge \(\{v,w\}\), include a type with utility one precisely at its endpoints, threshold \(2/\kappa\), and mass \(1/D\). Merge identical utility–threshold pairs by adding their masses.

Is accepted-mass decision in \(\mathrm{P}\) or NP-hard, both for unrestricted rational types and for the binary graph family defined above?

For a finite list of explicitly specified agents, deciding whether a lottery is accepted by at least a given number of agents is NP-hard even with binary utilities. [Choo, Goldberg and Teh](https://arxiv.org/abs/2604.17505).
With explicit constraints, unanimous acceptance is feasible in polynomial time by linear programming; this also applies to support-encoded societies at quota \(\rho=1\).

Modeling choices made when packaging the task

  • Specified utilities and thresholds as explicitly supplied binary rationals, with utilities in [0,1] and thresholds in (0,1], following the discrete domains and making input bit complexity well-defined.
  • Specified the quota domain as [0,1], since total society mass is one.
  • Made the graph-derived mass restriction explicit by normalizing agent multiplicities by the total number of constructed agents.
  • Merged identical utility–threshold pairs by adding masses, so the representation lists distinct support types even when construction categories coincide.
  • Restricted the graph-family clique parameter to 2 through m, excluding parameters larger than the number of vertices.

The finite-agent hardness result is [Theorem B.3 of Choo, Goldberg and Teh](https://arxiv.org/html/2604.17505v1#ThmtheoremB.3). The proof below treats the support encoding directly and establishes an exact formula for the graph family’s optimum.

2. Membership in \(\mathrm{NP}\)

For a lottery \(x\), define its accepted mass by

\(A(x):=\sum_{t:\langle u_t,x\rangle\ge\theta_t}\mu_t.\)

A certificate is a subset \(I\subseteq\{1,\ldots,\tau\}\). The verifier checks that \(\sum_{t\in I}\mu_t\ge\rho\), then tests feasibility of the rational linear program

\(x_j\ge0\quad(j=1,\ldots,m),\qquad \sum_{j=1}^{m}x_j=1,\qquad \langle u_t,x\rangle\ge\theta_t\quad(t\in I).\)

This program has \(m\) variables, at most \(m+\tau\) inequalities, one equality, and encoding length polynomial in \(L\). Exact rational linear-programming feasibility and the mass comparison therefore take \(\operatorname{poly}(m,\tau,L)\) time.

If the verifier accepts, a feasible lottery accepts every type in \(I\), so its accepted mass is at least \(\rho\). Conversely, a witnessing lottery supplies its accepted set as a valid certificate. The certificate uses \(\tau\) bits. Hence the unrestricted problem, and consequently its graph restriction, belong to \(\mathrm{NP}\).

3. Exact optimum for the binary graph family

For \(T\subseteq V\), let \(e_G(T)\) be the number of edges with both endpoints in \(T\), and define

\(e_\kappa(G):=\max_{T\subseteq V,\ |T|=\kappa}e_G(T).\)

We prove the following exact characterization:

\(\displaystyle \max_{x\in\Delta(V)}A(x)=\frac{Rm+\kappa+e_\kappa(G)}{D}.\)

Moreover, a maximizing lottery can always be chosen uniform on \(\kappa\) vertices.

Merging preserves the objective

Before merging, identical utility–threshold pairs have identical acceptance indicators for every lottery. Their combined contribution is therefore their summed mass times that common indicator. Thus merging changes neither \(A(x)\) nor its maximum.

We may consequently calculate using the original vertex and edge contributions, even when some pairs coincide.

Acceptance conditions and the weight gap

Because \(\sum_vx_v=1\), the three acceptance conditions are:

  • The vertex type of mass \(R/D\) accepts exactly when \(1-x_v\ge1-1/\kappa\), equivalently \(x_v\le1/\kappa\).
  • The vertex type of mass \(1/D\) accepts exactly when \(x_v\ge1/\kappa\).
  • The edge type for \(\{v,w\}\) accepts exactly when \(x_v+x_w\ge2/\kappa\).

Write \(F(x):=D A(x)\). If some coordinate exceeds \(1/\kappa\), at least one contribution of weight \(R\) is lost. Even granting acceptance to every remaining contribution gives

\(F(x)\le R(m-1)+m+M=Rm-1,\)

where the equality uses \(R=m+M+1\).

On the other hand, the lottery uniform on any \(\kappa\)-element vertex set satisfies every upper bound \(x_v\le1/\kappa\), and therefore has \(F(x)\ge Rm\). Thus lotteries violating an upper bound cannot maximize accepted mass.

Upper bound when every coordinate is capped

Suppose \(x_v\le1/\kappa\) for all \(v\). Define

\(T_x:=\{v\in V:x_v=1/\kappa\}.\)

The probability-sum constraint implies \(|T_x|\le\kappa\). The lower-bound vertex types accept exactly at the vertices of \(T_x\).

For an edge \(\{v,w\}\), both endpoint coordinates are at most \(1/\kappa\). Hence

\(x_v+x_w\ge2/\kappa\quad\Longleftrightarrow\quad x_v=x_w=1/\kappa.\)

It follows that

\(F(x)=Rm+|T_x|+e_G(T_x).\)

Since \(\kappa\le m\), extend \(T_x\) to a set \(T\subseteq V\) of size \(\kappa\). Every edge induced by \(T_x\) remains induced by \(T\), so

\(|T_x|+e_G(T_x)\le\kappa+e_G(T)\le\kappa+e_\kappa(G).\)

Consequently \(F(x)\le Rm+\kappa+e_\kappa(G)\). Lotteries violating a cap satisfy the strictly smaller bound established above, so this upper bound holds globally.

Attainment

Choose \(T\) of size \(\kappa\) with \(e_G(T)=e_\kappa(G)\), and set \(x_v=1/\kappa\) for \(v\in T\), and \(x_v=0\) otherwise.

Every upper-bound vertex type accepts. Exactly \(\kappa\) lower-bound vertex types accept. An edge type accepts exactly when both endpoints belong to \(T\). Therefore

\(F(x)=Rm+\kappa+e_\kappa(G),\)

proving the claimed optimum and its attainment. Acceptance at equality is essential to this calculation.

4. Polynomial-time reduction from \(\mathrm{CLIQUE}\)

Use the standard \(\mathrm{NP}\)-complete \(\mathrm{CLIQUE}\) problem with \(2\le\kappa\le m\).

First suppose \(M\ge\binom{\kappa}{2}\). Construct the prescribed society and choose

\(\displaystyle \rho:=\frac{Rm+\kappa+\binom{\kappa}{2}}{D}.\)

This is a valid quota: its numerator is positive, and

\(Rm+\kappa+\binom{\kappa}{2}\le Rm+m+M=D.\)

By the exact optimum formula, this society is a yes-instance precisely when

\(e_\kappa(G)\ge\binom{\kappa}{2}.\)

A simple graph on \(\kappa\) vertices has at most \(\binom{\kappa}{2}\) edges, with equality exactly when every vertex pair is adjacent. Thus the displayed condition holds precisely when \(G\) contains a clique of size \(\kappa\).

If instead \(M<\binom{\kappa}{2}\), the clique instance is necessarily negative. Map it to the fixed graph-family instance consisting of an edgeless graph on three vertices, \(\kappa=2\), and quota \(\rho=1\). Unanimity would require all three lower-bound vertex types to accept, forcing \(x_v\ge1/2\) for three coordinates, contrary to their sum being \(1\). This is a valid no-instance.

This separate branch ensures that every output quota lies in \([0,1]\).

Validity and size of the construction

All utilities are binary. Since \(2\le\kappa\), each threshold \(1-1/\kappa\), \(1/\kappa\), and \(2/\kappa\) belongs to \((0,1]\). Every mass is positive, and the masses sum to

\(\displaystyle \frac{Rm+m+M}{D}=1.\)

There are at most \(2m+M\) distinct types after merging. Because \(G\) is simple, \(M=O(m^2)\), \(R=O(m^2)\), and \(D=O(m^3)\). Thus the rational entries need \(O(\log m)\) bits each, and the explicitly listed output has length

\(L_{\mathrm{out}}=O\bigl((2m+M)(m+\log m)\bigr).\)

Construction and merging take \(\operatorname{poly}(m,M)\) time. Hence this is a polynomial-time many-one reduction.

The graph family is therefore \(\mathrm{NP}\)-hard. Together with Section 2, it is \(\mathrm{NP}\)-complete. Since these are also valid unrestricted instances, the unrestricted problem is \(\mathrm{NP}\)-complete as well.

5. Algorithmic bounds and tractable cases

\(\displaystyle \binom{\tau+m}{m-1}\operatorname{poly}(m,\tau,L).\)

\(x_j=0\quad(j=1,\ldots,m),\qquad \langle u_t,x\rangle=\theta_t\quad(t=1,\ldots,\tau).\)

For each choice, adjoin \(\sum_jx_j=1\). If the resulting system has a unique solution, compute it exactly, check membership in the simplex, and evaluate its accepted mass.

To prove sufficiency, let a witnessing lottery accept the set \(I\). The polyhedron

\(P_I:=\{x\in\Delta(S):\langle u_t,x\rangle\ge\theta_t\text{ for all }t\in I\}\)

is nonempty and bounded, so it has a vertex \(y\). At a vertex, the active constraints together with the probability-sum equality have rank \(m\). Indeed, otherwise there would be a nonzero direction preserving all active equalities; sufficiently small displacements in both directions would preserve every inactive inequality by its positive slack, contradicting extremality.

Thus \(m-1\) active inequalities can be selected whose equalities, together with the probability-sum equality, determine \(y\) uniquely. The enumeration includes them. Since \(y\) accepts every type in \(I\), its accepted mass is at least that of the original witness.

This proves polynomial-time solvability for every fixed \(m\), with bound \((\tau+m)^{m-1}\operatorname{poly}(m,\tau,L)\).

\(\displaystyle \binom{m}{\kappa}\operatorname{poly}(m,\tau,L).\)

Endpoint quotas

At \(\rho=0\), every instance is positive because the simplex is nonempty.

At \(\rho=1\), positivity of every listed mass implies that every type must accept. One rational linear program decides feasibility in \(\operatorname{poly}(m,\tau,L)\) time.
