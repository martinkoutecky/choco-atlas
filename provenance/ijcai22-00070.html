The continuous mirror question, as graded

Given projects \(P\) with integer costs \(c(p)\), budget \(b\), approval types \(A_t\subseteq P\), and a rational distribution \(\mu\) with \(\mu_t\ge0\) and \(\sum_t\mu_t=1\), decide whether there exists \(S\subseteq P\) such that \(\sum_{p\in S}c(p)\le b\) and \(\min_{t:\mu_t>0}\sum_{p\in S\cap A_t}c(p)\ge s\).

Definitions

An instance consists of a finite project set \(P\), integer costs \(c(p)\), an integer budget \(b\), approval types \(A_t\subseteq P\), rational masses \(\mu_t\geq0\) with \(\sum_t\mu_t=1\), and an integer threshold \(s\). Decide whether some \(S\subseteq P\) has \(c(S)\leq b\) and \(c(S\cap A_t)\geq s\) for every \(t\) with \(\mu_t>0\).

Target

Is this decision problem solvable in polynomial time, or is it NP-hard?

Claim

The decision problem is \(\mathrm{NP}\)-complete, and in particular \(\mathrm{NP}\)-hard. The rational masses do not change feasibility once zero-mass types are deleted.

Reduction from finite-voter maxmin participatory budgeting

Consider an instance of the ordinary finite-voter maxmin participatory-budgeting decision problem. It consists of:

  • a finite project set \(P\);
  • integer project costs \(c(p)\);
  • a budget \(b\);
  • voters \(1,\ldots,n\), where voter \(i\) approves \(A_i\subseteq P\);
  • a threshold \(s\).

The question is whether there exists \(S\subseteq P\) such that \(c(S)\leq b\) and

\[ c(S\cap A_i)\geq s \]

for every voter \(i\).

Construct an instance of the problem in the question as follows. Retain \(P,c,b,s\). For every voter \(i\), introduce a type \(t_i\) with

\[ A_{t_i}=A_i \qquad\text{and}\qquad \mu_{t_i}=\frac1n. \]

Every type has positive mass, and the masses satisfy

\[ \sum_{i=1}^n\mu_{t_i} = \sum_{i=1}^n\frac1n = 1. \]

The construction is polynomial-time: each rational number \(1/n\) has binary encoding length \(O(\log n)\).

If approval types are required to be distinct, group together voters with the same approval set. For each distinct approval set \(A\), let \(m_A\) be the number of voters approving exactly \(A\), and introduce one type of mass \(m_A/n\). This alternative construction is also polynomial-time and has exactly the same constraints.

Correctness of the reduction

Let \(S\subseteq P\). The budget condition in the constructed instance is unchanged:

\[ c(S)\leq b. \]

Moreover, every constructed type has positive mass. Consequently, its constraint is imposed, and for each voter \(i\) it is exactly

\[ c(S\cap A_{t_i}) = c(S\cap A_i) \geq s. \]

Thus \(S\) is feasible for the ordinary finite-voter instance if and only if \(S\) is feasible for the constructed type-and-mass instance.

Therefore the reduction preserves yes-instances and no-instances. Since the ordinary finite-voter maxmin participatory-budgeting decision problem is strongly \(\mathrm{NP}\)-hard by the stated known result, the problem in the question is \(\mathrm{NP}\)-hard.

Membership in \(\mathrm{NP}\)

A certificate is a subset \(S\subseteq P\), represented by its incidence vector.

Given \(S\), one can compute \(c(S)\) and, for every positive-mass type \(t\), compute \(c(S\cap A_t)\). Integer addition and comparison take polynomial time in the binary encoding length of the instance. One can therefore verify in polynomial time that

\[ c(S)\leq b \qquad\text{and}\qquad c(S\cap A_t)\geq s \]

for every \(t\) with \(\mu_t>0\). Hence the problem belongs to \(\mathrm{NP}\).

Conclusion

The decision problem is \(\mathrm{NP}\)-complete. In particular, it is not polynomial-time solvable unless \(\mathrm{P}=\mathrm{NP}\). The masses affect only whether a type is present: after deleting zero-mass types, their numerical values play no role in feasibility.

Summary

The reduction correctly transfers the stated strong \( \mathrm{NP} \)-hardness result, and the membership argument establishes \( \mathrm{NP} \)-completeness. The only gap is the unstated requirement \(n\geq 1\), needed to define the masses \(1/n\).

Step-by-step audit

  • Source problem. The prover accurately restates the ordinary finite-voter decision problem supplied in the nearest known results.
  • Construction. Retaining \(P,c,b,s\) and assigning each voter a type with the same approval set and mass \(1/n\) is polynomial in the source encoding. The calculation that these masses sum to \(1\) is correct, provided \(n\geq 1\).
  • Repeated approval sets. The optional grouping construction is correct: replacing voters sharing an approval set by one type of mass \(m_A/n\) preserves exactly one copy of the same feasibility constraint. Constraint multiplicity has no effect.
  • Correctness equivalence. For every candidate subset \(S\), the budget constraint is unchanged and every constructed type has positive mass. Thus each target constraint is identical to its corresponding voter constraint. The claimed if-and-only-if preservation is valid.
  • Hardness conclusion. Given the stated known strong \( \mathrm{NP} \)-hardness of the source problem, the polynomial-time equivalence-preserving construction establishes \( \mathrm{NP} \)-hardness of the target problem.
  • Membership in \( \mathrm{NP} \). An incidence vector for \(S\) has polynomial length. All required sums, rational positivity tests, and integer comparisons can be performed in polynomial time in the explicit binary input encoding. This establishes membership in \( \mathrm{NP} \).
  • Final classification. Combining membership with hardness justifies \( \mathrm{NP} \)-completeness and the conditional statement about polynomial-time solvability.

Required clarification

The source-instance description does not explicitly state \(n\geq 1\). Without it, \(1/n\) is undefined when \(n=0\). The write-up should state that the cited hardness result applies to instances with a nonempty electorate, or separately specify the reduction on the zero-voter edge case. This is a minor domain clarification and does not affect the substantive hardness argument.
