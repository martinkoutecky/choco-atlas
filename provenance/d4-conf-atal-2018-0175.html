The continuous mirror question, as graded

Given \(m\) candidates, committee size \(k\), a support of \(\tau\) complete rankings with rational masses \(\mu_t\ge 0\) summing to \(1\), and a rational threshold \(\theta\), is there a size-\(k\) committee \(S\) and assignment masses \(y_{t,c}\ge 0\) such that \(\sum_{c\in S}y_{t,c}=\mu_t\), \(\sum_t y_{t,c}=1/k\) for every \(c\in S\), and \(\sum_t\sum_{c\in S}y_{t,c}(m-\operatorname{pos}_t(c))\ge\theta\)?

Packaged proof task (what the prover saw — nothing else)

Let \(C\) be a set of \(m\ge 1\) candidates and let \(1\le k\le m\) be an input integer. A society is given by its support: a list of \(\tau\) distinct strict complete rankings of \(C\), each with positive mass \(\mu_t\) encoded as a binary rational, with \(\sum_{t=1}^{\tau}\mu_t=1\). Here \(\tau\) is the support size, not the number of possible rankings. The threshold \(\theta\in\mathbb{Q}\) is also encoded in binary; let \(L\) be the total input bit length.
A committee is a subset \(S\subseteq C\) with \(|S|=k\). Its assignment consists of divisible real masses \(y_{t,c}\ge 0\), indexed by supported types and committee members, satisfying \(\sum_{c\in S}y_{t,c}=\mu_t\) for every type and \(\sum_{t=1}^{\tau}y_{t,c}=1/k\) for every committee member.
Write \(\operatorname{pos}_t(c)\) for the position of \(c\) in ranking \(t\), starting at \(1\). An assignment meets the threshold when \(\sum_{t=1}^{\tau}\sum_{c\in S}y_{t,c}(m-\operatorname{pos}_t(c))\ge\theta\); any committee meeting it is admissible, with no tie-breaking requirement.

Is deciding whether such a committee and assignment exist in \(\mathrm{P}\), or is it \(\mathrm{NP}\)-hard? State running times in \(m,\tau,k,L\).

For finite societies with indivisible voters, Borda satisfaction, and exactly equal nonempty districts, threshold feasibility is NP-complete; it is FPT separately in the number of voters and candidates. [Faliszewski–Talmon](https://ifaamas.org/Proceedings/aamas2018/pdfs/p14.pdf)
Fractional representative assignments have previously been studied, but no complexity classification for the precise support-encoded problem above was located. [Potthoff–Brams](https://journals.sagepub.com/doi/10.1177/0951692898010002001)

Modeling choices made when packaging the task

  • Specified the committee-size domain as integers satisfying one through the number of candidates, as in the discrete definition.
  • Interpreted complete rankings as strict linear orders and positions as starting at one.
  • Removed zero-mass entries and merged duplicate rankings to implement the required positive-mass support encoding.
  • Specified binary encoding for the rational threshold and defined L as the total input bit length.
  • Allowed divisible real assignment masses and accepted every threshold-feasible committee without tie-breaking.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Classification

The problem is \(\mathrm{NP}\)-complete. Divisibility does not remove the hardness: after suitable scaling, every fixed committee has an integral optimal assignment, so the finite-voter hardness transfers to the support encoding.

An exact deterministic algorithm runs in
\(\binom{m}{k}(m+\tau+k+L)^{O(1)}\)
bit operations. In particular, the problem is fixed-parameter tractable in \(m\), and polynomial-time solvable for every fixed \(k\).

1. Integrality for a fixed committee

We first prove the property needed to transfer hardness.

Lemma. Let \(a_1,\ldots,a_\tau\) and \(b_1,\ldots,b_k\) be nonnegative integers with equal total. Suppose the set of nonnegative real matrices satisfying
\(\sum_{j=1}^{k}x_{t,j}=a_t\) and
\(\sum_{t=1}^{\tau}x_{t,j}=b_j\)
is nonempty. For arbitrary real coefficients \(w_{t,j}\), the objective
\(\sum_{t,j}w_{t,j}x_{t,j}\)
has an integral maximizer.

Proof. The feasible set is closed and bounded: every entry lies between zero and the common total. Thus the objective attains its maximum. Among its maximizers, choose \(x\) with the fewest nonintegral entries.

Construct a bipartite graph with row vertices and column vertices, placing an edge exactly where \(x_{t,j}\) is nonintegral. No vertex has degree one. Indeed, if precisely one entry in a row or column were nonintegral, subtracting the other, integral entries from its integral prescribed sum would make that entry integral.

If this graph has any edges, every nonisolated vertex has degree at least two, so it contains a cycle. Being bipartite, that cycle has even length. Define a matrix \(h\) by putting alternating values \(+1\) and \(-1\) on the cycle and zero elsewhere. Each row and column sum of \(h\) is zero.

All cycle entries of \(x\) are positive. Consequently, for sufficiently small positive \(\varepsilon\), both \(x+\varepsilon h\) and \(x-\varepsilon h\) are feasible. Optimality of \(x\) then forces
\(\sum_{t,j}w_{t,j}h_{t,j}=0\):
otherwise one perturbation would improve the objective.

Now choose
\(\delta=\min\bigl(\{\lceil x_{t,j}\rceil-x_{t,j}:h_{t,j}=1\}\cup\{x_{t,j}-\lfloor x_{t,j}\rfloor:h_{t,j}=-1\}\bigr)\).
Every quantity in this minimum is positive. The matrix \(x+\delta h\) remains nonnegative and preserves all margins. Each changed entry remains between its original floor and ceiling, and at least one becomes integral. No originally integral entry changes.

The objective is unchanged because its coefficient along \(h\) is zero. This contradicts the choice of \(x\). Hence \(x\) is integral. \(\square\)

2. Polynomial reduction from finite societies

We use the finite-society hardness result supplied in the question: threshold feasibility for strict Borda rankings and exactly equal nonempty districts is \(\mathrm{NP}\)-complete. This is the case \(X=1\) of Observation 3.1 in [Faliszewski–Talmon](https://ifaamas.org/Proceedings/aamas2018/pdfs/p14.pdf).

Let a source instance have \(n\) explicitly listed voters, \(m\) candidates, committee size \(k\), and total satisfaction threshold \(B\).

Exactly equal nonempty districts require \(k\mid n\). Instances violating this condition are necessarily NO-instances and can be mapped to the fixed target NO-instance \(m=k=\tau=1\), \(\mu_1=1\), \(\theta=1\). Thus we may assume \(k\mid n\).

Group identical rankings. Let the resulting distinct rankings have multiplicities \(r_1,\ldots,r_\tau\), where each \(r_t\) is positive and \(\sum_t r_t=n\). Construct the target instance using the same candidates, rankings, and committee size, with
\(\mu_t=r_t/n\) and \(\theta=B/n\).

The masses are positive binary rationals summing to one. There are at most \(n\) supported rankings, and each mass has encoding length \(O(\log(n+1))\). Grouping rankings and forming these fractions take polynomial time in the source input length. The construction therefore has polynomial output length.

We prove equivalence.

Source YES implies target YES. Suppose a source assignment uses committee \(S\). Let \(x_{t,c}\) count voters of type \(t\) assigned to \(c\). Then
\(\sum_{c\in S}x_{t,c}=r_t\) and
\(\sum_t x_{t,c}=n/k\).
Setting \(y_{t,c}=x_{t,c}/n\) satisfies all target assignment constraints. Its satisfaction equals the source satisfaction divided by \(n\), so it meets \(\theta=B/n\).

Target YES implies source YES. Suppose a target assignment \(y\) with committee \(S\) meets the threshold. Set \(x_{t,c}=ny_{t,c}\). Its margins are
\(\sum_{c\in S}x_{t,c}=r_t\) and
\(\sum_t x_{t,c}=n/k\),
which are integers. Its objective satisfies
\(\sum_{t,c\in S}x_{t,c}(m-\operatorname{pos}_t(c))\ge B\).

Apply the lemma to this fixed committee, with coefficients \(m-\operatorname{pos}_t(c)\). An integral maximizer \(x^*\) exists and has objective at least that of \(x\), hence at least \(B\).

For every type \(t\), partition its \(r_t\) individual voters into groups of sizes \(x^*_{t,c}\), assigning the corresponding group to \(c\). This is possible because those entries are nonnegative integers summing to \(r_t\). Each committee member receives exactly \(n/k\) voters. Since all voters of a type share their ranking, this assignment has exactly the objective of \(x^*\).

Thus the source instance is YES. The reduction proves \(\mathrm{NP}\)-hardness.

3. Membership in \(\mathrm{NP}\)

Real assignments do not prevent polynomial-size certificates.

Write \(\mu_t=p_t/q_t\), with positive integer denominators \(q_t\), and define
\(D=k\prod_{t=1}^{\tau}q_t\).
Its binary encoding length is \(O(L+\log(k+1))\). Both \(D\mu_t\) and \(D/k\) are integers.

For any fixed committee, scaling assignments by \(D\) gives the margins
\(\sum_{c\in S}x_{t,c}=D\mu_t\) and
\(\sum_t x_{t,c}=D/k\).
This transportation set is nonempty: the assignment \(y_{t,c}=\mu_t/k\) is feasible.

If a committee admits a threshold-meeting assignment, the lemma gives an integral maximizer \(x^*\) for these scaled margins. Its normalized assignment \(x^*/D\) also meets the threshold.

A certificate therefore consists of the committee and the \(\tau k\) integers \(x^*_{t,c}\). Every entry lies between zero and \(D\), so the certificate length is
\(O(k\log(m+1)+\tau k(L+\log(k+1)))\).

The verifier checks nonnegativity, the row and column sums, and
\(\sum_{t,c\in S}x^*_{t,c}(m-\operatorname{pos}_t(c))\ge D\theta\).
All checks use exact integer arithmetic and rational cross-multiplication on polynomially many bits. Verification takes \((m+\tau+k+L)^{O(1)}\) bit operations.

Consequently, the problem belongs to \(\mathrm{NP}\), completing the proof of \(\mathrm{NP}\)-completeness.

4. Running times

For a fixed committee \(S\), threshold feasibility is a rational linear program with \(\tau k\) variables, \(\tau+k\) margin equations, nonnegativity constraints, and one satisfaction inequality. All coefficients have polynomial encoding length in \(m,\tau,k,L\). Polynomial-time rational linear programming therefore decides it in
\((m+\tau+k+L)^{O(1)}\)
bit operations.

Enumerating all committees gives the exact deterministic bound
\(\binom{m}{k}(m+\tau+k+L)^{O(1)}\).
Since \(\binom{m}{k}\le 2^m\) and \(\binom{m}{k}\le m^k\), this also yields bounds
\(2^m(m+\tau+k+L)^{O(1)}\) and
\(m^k(m+\tau+k+L)^{O(1)}\).

The first proves fixed-parameter tractability in \(m\); the second proves polynomial-time solvability for fixed \(k\). Neither bound involves expanding binary rational masses into individual voters. The general problem has no polynomial-time algorithm unless \(\mathrm{P}=\mathrm{NP}\).
