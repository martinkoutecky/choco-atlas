The continuous mirror question, as graded

Given \(m\) candidates, a rational distribution \(\mu\) over \(\tau\) complete ranking types, and a target \(d\), choose nonnegative masses \(x_\pi\) on complete manipulator rankings \(\pi\) with \(d\) first to minimize \(\sum_\pi x_\pi\), subject to \(\mathrm{sc}_\mu(c)+\sum_\pi x_\pi s(\pi,c)\leq \mathrm{sc}_\mu(d)+\sum_\pi x_\pi s(\pi,d)\) for every \(c\ne d\).

Packaged proof task (what the prover saw — nothing else)

Let \(C=\{1,\ldots,m\}\), with \(m\geq2\), and let \(d\in C\). Rankings are strict and complete; use Borda scores \(s(\rho,c)\).
A society is given by its support: the list of the \(\tau\) ranking types with positive mass, each mass a binary rational. Here \(\tau\) is the support size, not the number of possible rankings. Assume \(\sum_\rho\mu(\rho)=1\), and define \(\mathrm{sc}_\mu(c)=\sum_\rho\mu(\rho)s(\rho,c)\).
Let \(\Pi_d\) contain all complete rankings placing \(d\) first. Additional manipulator masses \(x_\pi\in\mathbb R_{\geq0}\) are unrestricted in total; ties favor \(d\).
Minimize \(t=\sum_{\pi\in\Pi_d}x_\pi\), subject to \(\mathrm{sc}_\mu(c)+\sum_{\pi\in\Pi_d}x_\pi s(\pi,c)\leq\mathrm{sc}_\mu(d)+(m-1)t\) for every \(c\ne d\).
For the decision version, a binary rational budget \(b\geq0\) is supplied and the question is whether the minimum is at most \(b\). State running times in \(m,\tau,L\), where \(L\) is the total input bit length.

Is this decision problem in \(\mathrm P\), or is it \(\mathrm{NP}\)-hard?

Known discrete results: any integer matrix containing equally many copies of every Borda score can be rearranged into ranking rows while preserving column sums; unweighted Borda manipulation is also [NP-complete with two manipulators](https://gkatsi.github.io/papers/dknwaaai11.pdf).
Known continuous result: [Xia, Conitzer and Procaccia](https://www.cs.cmu.edu/~conitzer/schedulingEC10.pdf) give an exact polynomial-time algorithm for minimum divisible manipulator weight under positional scoring rules. Their weighted non-manipulator and convex-combination ballot definitions include exactly the problem above, so this target is already settled.

  • Normalized the non-manipulator distribution to total mass one; additional manipulator mass is measured in the same units and is not renormalized.
  • Made explicit that rankings are strict and complete and that ties favor the distinguished candidate.
  • Allowed arbitrary nonnegative real manipulator masses, including zero total mass, with no imposed upper bound.
  • Introduced a nonnegative binary rational budget for the decision formulation of the minimum-mass problem.

Result

The decision problem is in \(\mathrm{P}\). In fact, the exact minimum manipulator mass can be computed in time polynomial in \(m,\tau,L\).

This agrees with Theorem 3.4 of [Xia, Conitzer and Procaccia, *A Scheduling Approach to Coalitional Manipulation*](https://www.cs.cmu.edu/~conitzer/schedulingEC10.pdf), which solves minimum divisible manipulator weight exactly in polynomial time. Below is an independent proof using a polynomial-size linear program.

1. A polynomial-size formulation

Put \(n=m-1\), and let \(R=C\setminus\{d\}\) be the set of rivals. For each \(c\in R\), compute the initial score gap

\(\displaystyle \Delta_c=\mathrm{sc}_\mu(c)-\mathrm{sc}_\mu(d).\)

Every manipulator ranking gives \(d\) score \(n\) and assigns the scores \(0,\ldots,n-1\) bijectively to the rivals.

Introduce a variable \(y_{c,j}\) for each \(c\in R\) and \(j\in\{0,\ldots,n-1\}\). Its intended meaning is the total manipulator mass assigning score \(j\) to rival \(c\).

Consider the following linear program:

\(\displaystyle \text{minimize }t,\)

subject to

\(\displaystyle t\geq0,\qquad y_{c,j}\geq0\quad(c\in R,\ 0\leq j<n),\)

\(\displaystyle \sum_{j=0}^{n-1}y_{c,j}=t\quad(c\in R),\)

\(\displaystyle \sum_{c\in R}y_{c,j}=t\quad(0\leq j<n),\)

\(\displaystyle \sum_{j=0}^{n-1}j\,y_{c,j}\leq nt-\Delta_c\quad(c\in R).\)

The row equations say that every rival receives some score on all manipulator mass. The column equations say that every score is assigned once on all manipulator mass. The last inequalities are precisely the conditions that \(d\) weakly beats each rival.

For the decision problem, add the constraint \(t\leq b\) and test feasibility. The program has \(n^2+1\) variables and \(O(n^2)\) constraints, counting nonnegativity constraints.

We next prove that these marginal constraints characterize valid mixtures of complete rankings exactly.

2. Equivalence with the original problem

From rankings to a feasible matrix

Suppose the original problem has feasible masses \(x_\pi\), with total mass \(t=\sum_{\pi\in\Pi_d}x_\pi\). Define

\(\displaystyle y_{c,j}=\sum_{\substack{\pi\in\Pi_d\\s(\pi,c)=j}}x_\pi.\)

Each ranking assigns exactly one score to each rival and exactly one rival to each score. Consequently, every row sum and every column sum of \(Y=(y_{c,j})\) equals \(t\).

Moreover,

\(\displaystyle \sum_{j=0}^{n-1}j\,y_{c,j}=\sum_{\pi\in\Pi_d}x_\pi s(\pi,c).\)

Thus the original winning inequalities imply all constraints of the matrix program, with the same objective value.

From a feasible matrix to rankings

We prove the required decomposition directly.

Lemma. If an \(n\times n\) nonnegative real matrix \(Y\) has every row sum and every column sum equal to \(t\), then

\(\displaystyle Y=\sum_{\ell=1}^{q}a_\ell P_\ell,\qquad a_\ell>0,\qquad \sum_{\ell=1}^{q}a_\ell=t,\)

where each \(P_\ell\) is a permutation matrix and \(q\leq n^2\). For \(t=0\), the sum is empty.

Proof. If \(t=0\), nonnegativity forces \(Y=0\).

Otherwise, start with residual matrix \(Z=Y\), whose common row and column sum is \(r=t>0\). Form a bipartite graph with rows on one side, columns on the other, and an edge wherever \(Z\) has a positive entry.

For any set \(S\) of rows, let \(N(S)\) be its neighboring columns. All mass in those rows lies in \(N(S)\), so

\(\displaystyle |S|r=\sum_{i\in S}\sum_{j\in N(S)}Z_{i,j}\leq\sum_i\sum_{j\in N(S)}Z_{i,j}=|N(S)|r.\)

Since \(r>0\), this gives \(|S|\leq|N(S)|\). Hall’s marriage theorem therefore provides a perfect matching, represented by a permutation matrix \(P\), using only positive entries.

Let

\(\displaystyle a=\min\{Z_{i,j}:P_{i,j}=1\}>0.\)

Replace \(Z\) by \(Z-aP\). The result remains nonnegative, and every row and column sum becomes \(r-a\). At least one positive entry becomes zero, and no zero entry becomes positive.

Repeat whenever the common sum is positive. Each iteration removes at least one positive entry, so there are at most \(n^2\) iterations. The process must end with common sum zero: otherwise the same matching argument would permit another iteration. The final residual is zero. Summing the subtracted matrices gives the stated decomposition, and comparing row sums gives \(\sum_\ell a_\ell=t\). This proves the lemma.

Apply the lemma to any feasible \(Y\). Each permutation matrix assigns the scores \(0,\ldots,n-1\) bijectively to the rivals. These assignments determine a unique complete ranking with \(d\) first. Give that ranking mass \(a_\ell\), combining masses if a ranking occurs more than once.

The resulting manipulator masses total \(t\), and rival \(c\) receives exactly \(\sum_jj\,y_{c,j}\) additional points. The last constraints of the linear program therefore ensure that \(d\) wins under the stipulated tie-breaking rule.

Hence the matrix program and the original problem have exactly the same feasible total masses and the same optimum.

3. Attainment and bit complexity

The minimum exists

Because the original society has total mass one and Borda scores lie between \(0\) and \(n\), every gap satisfies \(\Delta_c\leq n\).

Choose any ranking with \(d\) first and give it mass \(n\). Each unit of this mass improves \(d\)’s score relative to every rival by at least one. Thus mass \(n\) is feasible.

Restricting the matrix program to \(0\leq t\leq n\) therefore preserves its infimum. Its feasible set is closed and bounded, since the row equations and nonnegativity imply \(0\leq y_{c,j}\leq n\). It is also nonempty. A continuous linear objective attains its minimum on this compact set.

Running time

Let \(K=L+\lceil\log_2m\rceil+1\).

Computing all initial scores requires \(O(\tau m)\) exact rational arithmetic operations. To bound their bit sizes, write each input mass as \(p_\rho/q_\rho\) and use the common denominator \(Q=\prod_\rho q_\rho\). The binary length of \(Q\) is \(O(L)\), because the denominator encodings are part of the total input.

Every score has denominator dividing \(Q\) and lies in \([0,n]\). Thus each score and each gap has a representation using \(O(K)\) bits. Using elementary integer arithmetic, preprocessing takes \(O(\tau mK^2)\) bit operations.

The decision linear program has:

  • \((m-1)^2+1\) variables;
  • \(O(m^2)\) constraints and nonzero coefficients;
  • coefficients and right-hand sides of \(O(K)\) bits each;
  • total sparse binary encoding length \(O(m^2K)\).

The polynomial-time theorem for rational linear programming gives exact feasibility testing in time polynomial in this encoding length. Therefore, for some fixed constant \(k\), the overall running time is bounded by

\(\displaystyle O\!\left(\tau mK^2+(m^2K)^k\right),\)

which is polynomial in \(m,\tau,L\). Rational linear optimization also computes the exact minimum in polynomial time. This uses only the listed support; it never enumerates all complete rankings.

4. Relation to the cited continuous result

To map the instance to Xia, Conitzer and Procaccia’s formulation, treat each support ranking as one non-manipulator ballot of weight \(\mu(\rho)\). For positive total manipulator mass \(t\), the coefficients \(x_\pi/t\) form a convex-combination ballot of a single divisible manipulator of weight \(t\). Conversely, such a ballot gives masses \(x_\pi=t\alpha_\pi\).

Their weighted non-manipulator scores and co-winner condition therefore coincide with this problem. Their Definition 2.4 and Theorem 3.4 apply. Restricting ballots to place \(d\) first causes no loss for Borda: moving \(d\) to first increases its score and weakly decreases every rival’s score. [Source](https://www.cs.cmu.edu/~conitzer/schedulingEC10.pdf)

The discrete hardness result concerns indivisible ballots. Here arbitrary real masses are allowed, and the proved matrix decomposition preserves that continuous freedom.
