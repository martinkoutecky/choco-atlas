The continuous mirror question, as graded

Given a finite outcome set \(Z\), a finite set \(T\) of complete preference types, rational masses \(\mu_t>0\) summing to \(1\), and a quota \(q>1/2\), does a non-empty-valued CSWP exist? A coalition is a mass vector \(x\) with \(0\le x_t\le\mu_t\) and \(\sum_t x_t\ge q\); it weakly or strictly prefers an outcome comparison when every type with \(x_t>0\) has that comparison. Any such coalition can move from any outcome to any other, and paths and the CSWP conditions are as in the paper.

Packaged proof task (what the prover saw — nothing else)

Let \(Z\) be a nonempty finite outcome set, with \(m=|Z|\). A society is given by its support: the list \(T\) of \(\tau\) types with positive mass, each mass \(\mu_t\) a binary rational, with \(\sum_{t\in T}\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types. Each type has an explicitly given complete, transitive weak preference relation \(\preceq_t\), allowing indifference; \(a\preceq_t b\) means that \(b\) is weakly preferred to \(a\), and \(\prec_t\) denotes its strict part.
The input also contains a binary rational quota \(q\in(1/2,1]\). A winning coalition is any real vector \(x\) with \(0\le x_t\le\mu_t\) and \(\sum_t x_t\ge q\). Every winning coalition can move from any outcome to any outcome, including itself; other coalitions cannot move. Write \(a\preceq_x b\), respectively \(a\prec_x b\), when every type with \(x_t>0\) weakly, respectively strictly, prefers \(b\) to \(a\).
A path is any finite sequence \(\alpha=(a_1,x^1,a_2,\ldots,x^{k-1},a_k)\) whose coalitions are winning, including singleton paths; repetitions are allowed, and every such path is feasible. Let \(\Pi_a\) be all paths starting at \(a\), and let \(r(\alpha)\) be the terminal outcome. Path comparisons use only terminal outcomes.
A predictor assigns a set \(\sigma(a)\subseteq\Pi_a\) to each outcome. A path \(\alpha\) is blocked relative to \(\sigma\) if there exist an outcome \(b\) occurring anywhere on \(\alpha\), a winning coalition \(x\), and an outcome \(c\), such that \(x\) can move from \(b\) to \(c\), \(\sigma(c)\ne\varnothing\), \(r(\alpha)\preceq_x r(\beta)\) for every \(\beta\in\sigma(c)\), and \(r(\alpha)\prec_x r(\beta)\) for at least one such \(\beta\).
A conservative stable weak predictor (CSWP) satisfies, for every \(a\) and \(\alpha\in\Pi_a\), that \(\alpha\in\sigma(a)\) if and only if \(\alpha\) is not blocked relative to \(\sigma\). It is nonempty-valued when \(\sigma(a)\ne\varnothing\) for every \(a\).
Is deciding whether a nonempty-valued CSWP exists solvable in polynomial time, or is it NP-hard? State running times in \(m\), \(\tau\), and the total input bit length \(L\), including the encoding of \(q\).
For finite discrete proper voting games with all paths feasible, existence is guaranteed when every winning coalition strictly and unanimously orders every pair of distinct outcomes; finite majority games with indifferences can fail to admit a nonempty-valued CSWP. These are existence results, not complexity classifications. [Verified discrete results](https://www.york.ac.uk/media/economics/documents/discussionpapers/2009/0933.pdf)
No result settling the exact distributional decision problem was located in the literature search.

Modeling choices made when packaging the task

  • Interpreted complete preference types as complete, transitive weak orders, allowing indifference as in the finite nonexistence example.
  • Made the quota a binary rational and restricted it to (1/2,1], preserving the nonempty family of winning coalitions required for voting games.
  • Allowed real coalition coordinates, so positive type masses are divisible.
  • Used all finite paths, including singletons, repeated outcomes, and self-moves, without a domination feasibility restriction, matching the anchor's setting.
  • Required a nonempty outcome set and defined L as the total input bit length.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Result. The decision problem is \(\mathrm{NP}\)-complete. This holds even when all masses and the quota are dyadic rationals and every preference relation has at most five indifference classes.

The proof below gives a finite certificate, a polynomial verification algorithm, and a reduction from \(\mathrm{3SAT}\).

1. Finite characterization. Assign each type an integer rank function \(r_t:Z\to\{0,\ldots,m-1\}\) representing its weak order, with higher ranks preferred. Thus \(a\preceq_t b\) exactly when \(r_t(a)\le r_t(b)\).

For a nonempty set \(U\subseteq Z\), define

\[ w_U(z,u)= \sum_{\substack{t\in T:\\ r_t(z)\le r_t(v)\ \text{for every }v\in U,\\ r_t(z)<r_t(u)}}\mu_t, \qquad u\in U. \]

Write \(B_U(z)\) for the condition that \(w_U(z,u)\ge q\) for some \(u\in U\).

Proposition. A nonempty-valued CSWP exists if and only if some nonempty \(U\subseteq Z\) satisfies

\[ z\in U\quad\Longleftrightarrow\quad \neg B_U(z) \qquad\text{for every }z\in Z. \tag{1} \]

For such a set, the corresponding predictor is

\[ \sigma_U(a)=\{\alpha\in\Pi_a:r(\alpha)\in U\}. \tag{2} \]

Proof. For an arbitrary predictor, whether a path is blocked depends only on its terminal outcome. Indeed, the outcome \(b\) occurring on the path imposes no restriction: every winning coalition can move from every \(b\) to every \(c\).

Consequently, if \(\sigma\) is a CSWP, there is a common set \(U\) of unblocked terminal outcomes such that (2) holds for every \(a\). Every outcome is reachable from every starting outcome using the winning vector \(x_t=\mu_t\). Hence nonempty-valuedness is equivalent to \(U\ne\varnothing\), and the terminal outcomes represented in every \(\sigma(a)\) are exactly \(U\).

A path ending at \(z\) is blocked relative to \(\sigma_U\) precisely when there are \(u\in U\) and a winning coalition whose supported types weakly prefer every member of \(U\) to \(z\), and strictly prefer \(u\) to \(z\). Such a coalition exists precisely when the total mass of these eligible types is at least \(q\): necessity follows from \(x_t\le\mu_t\), and sufficiency follows by taking the full mass of every eligible type. This is exactly \(B_U(z)\). The CSWP equivalence therefore becomes (1). Conversely, (1) makes the predictor (2) a nonempty-valued CSWP. \(\square\)

2. Two forcing observations. Define strict majority dominance by

\[ a\longrightarrow b \quad\Longleftrightarrow\quad \sum_{t:a\prec_t b}\mu_t\ge q. \]

Lemma. Every set \(U\) satisfying (1) is upward closed under this relation: if \(a\in U\) and \(a\longrightarrow b\), then \(b\in U\).

Proof. Suppose \(b\notin U\). By (1), there is a set of types of mass at least \(q\) that weakly prefers every member of \(U\), including \(a\), to \(b\). This set is disjoint from the types strictly preferring \(b\) to \(a\). The latter also have mass at least \(q\). Their combined mass would therefore be at least \(2q>1\), a contradiction. \(\square\)

Two consequences will be used.

  • If no outcome strictly majority dominates \(z\), then \(z\in U\). Otherwise \(B_U(z)\) would provide such an outcome.
  • Suppose a winning coalition weakly prefers every outcome in \(Z\) to \(z\), and strictly prefers some outcome \(u\) to \(z\). Then \(z\notin U\). If \(z\in U\), upward closure would force \(u\in U\); that same coalition would then establish \(B_U(z)\), contradicting (1).

3. Reduction from \(\mathrm{3SAT}\). Take a Boolean formula with variables \(x_1,\ldots,x_n\) and \(s\) nonempty clauses, each containing at most three literals. We may restrict to \(n\ge1\).

Index literals by \(\lambda=(i,b)\), where \(b=1\) denotes \(x_i\) and \(b=0\) denotes its negation. Construct the following outcomes:

  • one outcome \(c\);
  • two outcomes \(p_\lambda,r_\lambda\) for each literal \(\lambda\);
  • one outcome \(a_C\) for every original clause and every additional clause \(\{(i,0),(i,1)\}\);
  • two outcomes \(d_i,v_i\) for each variable.

The additional clauses will require at least one truth value to be selected. The outcomes \(d_i\) will prevent both values from being selected.

Let \(\mathcal C\) be the indexed collection of the \(s+n\) original and additional clauses. Define

\[ O=\{p_\lambda,r_\lambda:\lambda=(i,b)\}, \]

\[ D=\{a_C:C\in\mathcal C\}\cup\{d_i:1\le i\le n\}, \qquad V=\{v_i:1\le i\le n\}, \qquad H=D\cup V. \]

Thus \(Z=\{c\}\cup O\cup H\), and

\[ m=1+7n+s. \]

Choose positive dyadic rationals \(\varepsilon,\eta\) satisfying

\[ \varepsilon\le\frac{1}{32(n+s+1)}, \qquad \eta\le\frac{\varepsilon}{4n+1}, \]

and having encoding length \(O(\log(n+s+1))\). For example, take reciprocal powers of two by rounding the two denominators upward to powers of two. Set

\[ q=\frac12+2\varepsilon. \]

The following table defines the preference types by integer ranks. For each row, first assign the default rank, next assign the indicated rank to every member of \(H\), and finally apply the exceptional assignments. Higher ranks are preferred.

| Type | Mass | Default rank | Rank on \(H\) | Exceptional ranks |
|---|---:|---:|---:|---|
| Baseline | \(\frac12\) | \(1\) | unchanged | \(r(c)=2\); \(r(z)=0\) for \(z\in D\) |
| First pair type, for each \(\lambda\) | \(\varepsilon\) | \(2\) | \(3\) | \(r(p_\lambda)=0,\ r(r_\lambda)=1\) |
| Second pair type, for each \(\lambda\) | \(\varepsilon\) | \(2\) | \(3\) | \(r(p_\lambda)=1,\ r(r_\lambda)=0\) |
| Clause type, for each \(C\in\mathcal C\) | \(2\varepsilon\) | \(0\) | \(2\) | \(r(a_C)=0\); \(r(p_\lambda)=1\) for \(\lambda\in C\) |
| Type \(A_i\), for each \(i\) | \(2\varepsilon-\eta\) | \(2\) | \(3\) | \(r(d_i)=0,\ r(v_i)=1\) |
| Type \(E_i\), for each \(i\) | \(\eta\) | \(0\) | \(2\) | \(r(d_i)=0,\ r(v_i)=1\) |
| Type \(B_i^b\), for each \(i,b\) | \(\eta\) | \(3\) | \(4\) | \(r(v_i)=0,\ r(d_i)=2,\ r(p_{(i,b)})=1\) |
| Indifferent filler | specified below | \(0\) | unchanged | none |

These rank functions define complete, transitive weak preferences with at most five indifference classes.

Call all types other than the baseline and filler the private types. Their total mass is

\[ P=(8n+2s)\varepsilon+2n\eta. \]

Indeed, the pair types contribute \(4n\varepsilon\), the clause types contribute \(2(s+n)\varepsilon\), and the four private types for each variable contribute \(2\varepsilon+2\eta\).

Our parameter choices give

\[ 2n\eta<\varepsilon, \qquad P<(8n+2s+1)\varepsilon<\frac14. \]

Give the filler type mass \(\frac12-P\). Every mass is positive and dyadic, and the masses sum to one. Also \(q\in(1/2,1]\). The number of supported types is at most

\[ \tau=9n+s+2. \]

4. Verification of the reduction. We prove that the formula is satisfiable exactly when the constructed instance has a set satisfying (1).

Step 1: \(c\) is included, and all members of \(D\) are excluded. The baseline ranks \(c\) highest, and the filler is indifferent. Therefore the types strictly preferring any outcome to \(c\) have total mass at most \(P<1/4<q\). No outcome strictly majority dominates \(c\), so \(c\in U\).

For a clause outcome \(a_C\), combine the baseline with its clause type. Their total mass is

\[ \frac12+2\varepsilon=q. \]

Both rank every outcome weakly above \(a_C\), and both strictly prefer \(p_\lambda\) to \(a_C\) for any \(\lambda\in C\). Since \(C\) is nonempty, the second forcing observation implies \(a_C\notin U\).

For \(d_i\), combine the baseline, \(A_i\), and \(E_i\). Their total mass is

\[ \frac12+(2\varepsilon-\eta)+\eta=q. \]

All these types rank every outcome weakly above \(d_i\), and strictly prefer \(v_i\) to \(d_i\). The same forcing observation gives \(d_i\notin U\).

Thus \(U\cap D=\varnothing\).

Step 2: all members of \(V\) are excluded. Fix \(i\). Combine the baseline, \(A_i\), and \(B_i^0\), again obtaining total mass \(q\).

Once \(D\) is excluded, every possible member of \(U\) belongs to \(\{c\}\cup O\cup V\). Each of these three types ranks every such outcome weakly above \(v_i\), and strictly prefers \(c\) to \(v_i\). Because \(c\in U\), this establishes \(B_U(v_i)\). Therefore \(v_i\notin U\).

We have proved that every solution must satisfy

\[ \{c\}\subseteq U\subseteq\{c\}\cup O. \tag{3} \]

The remaining calculations apply to any set satisfying (3).

Step 3: each literal pair is selected together or excluded together. Fix a pair \(p_\lambda,r_\lambda\), and let \(z\) be one of its members, with the other member denoted \(z'\).

Only \(c\) can strictly majority dominate \(z\). The baseline ties \(z\) with every other optional outcome and every auxiliary outcome, and places every member of \(D\) below \(z\). Thus strict preference for any witness other than \(c\) has mass at most \(P<q\).

For the witness \(c\), the baseline always contributes \(\frac12\). The two private pair types contribute:

  • \(2\varepsilon\) if \(z'\notin U\);
  • \(\varepsilon\) if \(z'\in U\), because exactly one of them ranks \(z'\) below \(z\).

Among all other types, only the \(B_i^b\) types can strictly prefer \(c\) to an optional outcome. Their combined mass is \(2n\eta<\varepsilon\). Inspection of the table verifies that the clause types, \(A_i\), \(E_i\), and other pair types never strictly prefer \(c\) to \(z\).

Consequently,

\[ B_U(z)\quad\Longleftrightarrow\quad z'\notin U. \tag{4} \]

Applying (1) to both members gives

\[ p_\lambda\in U \quad\Longleftrightarrow\quad r_\lambda\in U. \tag{5} \]

Conversely, either selecting both members or excluding both satisfies (1) for these two outcomes.

Step 4: a clause outcome is blocked exactly when a represented literal is selected. Fix \(C\in\mathcal C\). The baseline contributes \(\frac12\) toward any witness in \(U\).

Every private type other than the clause’s own type ranks \(a_C\) at least as high as every member of \(\{c\}\cup O\). Hence none can contribute to a strict comparison from \(a_C\) to a witness in \(U\).

The clause’s own type weakly prefers every member of \(U\) to \(a_C\). It strictly prefers precisely the optional outcomes \(p_\lambda\) with \(\lambda\in C\). Its mass is \(2\varepsilon\). Therefore

\[ B_U(a_C) \quad\Longleftrightarrow\quad p_\lambda\in U\text{ for some }\lambda\in C. \tag{6} \]

Since \(a_C\notin U\), condition (1) requires every original and additional clause to have a selected representative.

Step 5: \(d_i\) is blocked exactly when the two truth-value representatives are not both selected. Fix \(i\). Again, the baseline contributes \(\frac12\) for every witness in \(U\).

Type \(A_i\) contributes its full mass \(2\varepsilon-\eta\): it strictly prefers every member of \(U\) to \(d_i\). Type \(E_i\) contributes nothing, because it ties \(d_i\), \(c\), and all optional outcomes.

Type \(B_i^b\) contributes \(\eta\) exactly when \(p_{(i,b)}\notin U\). If that representative is selected, it lies strictly below \(d_i\), making this type ineligible for every blocking witness. If it is absent, every member of \(U\) lies strictly above \(d_i\) for this type.

All other private types rank \(d_i\) at least as high as every member of \(U\), so contribute nothing. Thus, for every witness \(u\in U\),

\[ w_U(d_i,u)= \frac12+2\varepsilon-\eta +\eta\,\mathbf 1[p_{(i,0)}\notin U] +\eta\,\mathbf 1[p_{(i,1)}\notin U]. \]

Comparing with \(q=\frac12+2\varepsilon\) yields

\[ B_U(d_i) \quad\Longleftrightarrow\quad p_{(i,0)}\notin U \text{ or } p_{(i,1)}\notin U. \tag{7} \]

Because \(d_i\notin U\), condition (1) forbids selecting both truth-value representatives.

Soundness. Suppose a set \(U\) satisfies (1). By the additional clause for variable \(i\) and (6), at least one of \(p_{(i,0)},p_{(i,1)}\) is selected. By (7), at most one is selected. Assign \(x_i=b\) according to this unique selected representative. Equation (6) for every original clause proves that this assignment satisfies the formula.

Completeness. Suppose the formula has a satisfying assignment. Form \(U\) from \(c\) and both members \(p_\lambda,r_\lambda\) of every literal pair made true by the assignment.

The calculations above verify (1) for every outcome:

  • \(c\) is unblocked.
  • Selected optional outcomes are unblocked, and excluded optional outcomes are blocked, by (4).
  • Every clause outcome is blocked, by satisfaction of the original clauses and selection of one value for each variable.
  • Every \(d_i\) is blocked, by (7).
  • Every \(v_i\) is blocked by the coalition used in Step 2.

Thus \(U\) satisfies (1), and Proposition 1 supplies a nonempty-valued CSWP. This completes the reduction.

5. Encoding and running times. All constructed ranks lie in \(\{0,1,2,3,4\}\). The parameters, masses, and quota have \(O(\log(n+s+1))\)-bit encodings. The construction has \(m=1+7n+s\) outcomes and \(\tau\le9n+s+2\) supported types. Expanding the rank descriptions into explicit preference relations takes at most \(O((n+s+1)^3\log(n+s+1))\) bit operations and produces a polynomial-size instance. Hence the reduction is a polynomial many-one reduction.

For the general problem, a certificate is simply the \(m\)-bit indicator vector of a nonempty set \(U\). To verify it, compute

\[ \ell_t=\min_{v\in U}r_t(v). \]

Then evaluate every relevant \(w_U(z,u)\) using the tests \(r_t(z)\le\ell_t\) and \(r_t(z)<r_t(u)\). This requires \(O(\tau m^2)\) comparisons and additions.

For exact rational arithmetic, let \(D_0\) be the product of the denominators of all masses and of \(q\). Its bit length is \(O(L)\). Converting all masses and the quota to integer numerators over \(D_0\) costs \(O(\tau L^2)\) bit operations using elementary arithmetic. All subsequent sums use \(O(L)\)-bit integers. Including preference preprocessing, a conservative verification bound is

\[ O(\tau L^2+\tau m^2L). \]

This proves membership in \(\mathrm{NP}\), with the quota’s encoding fully included.

Enumerating all nonempty subsets, while reusing the integer preprocessing, gives an exact decision algorithm taking

\[ O(\tau L^2+2^m\tau m^2L) \]

bit operations. The reduction proves \(\mathrm{NP}\)-hardness, so a polynomial-time algorithm for the general problem would imply \(\mathrm{P}=\mathrm{NP}\).

Step-by-step verification

1. Finite characterization

The proposition correctly handles the quantifiers in the blocking definition.

For a fixed predictor, blocking depends only on the terminal outcome: the required occurrence of an outcome \(b\) on the path imposes no further restriction, since every path contains an outcome and every winning coalition can move from that outcome to any \(c\).

Consequently, the CSWP equivalence forces membership to depend only on the terminal outcome, with the same accepted terminal set \(U\) at every starting outcome. Every terminal outcome is reachable from every starting outcome using the full-mass coalition, whose mass is \(1\ge q\). Thus nonempty-valuedness is equivalent to \(U\ne\varnothing\).

For \(\sigma_U\), the blocking condition requires:

  • every supported type in the coalition to weakly prefer every outcome in \(U\) to \(z\);
  • one common outcome \(u\in U\) that every supported type strictly prefers to \(z\).

The definition of \(w_U(z,u)\) expresses precisely these requirements. In particular, it correctly preserves the requirement of a common strict witness; it does not replace that requirement by separate witnesses for different types.

The eligible types support a winning coalition exactly when their total mass is at least \(q\). The necessity follows from the coordinate bounds, and choosing their full masses proves sufficiency. Therefore equation (1) is the correct fixed-point condition, in both directions.

Singleton paths, repeated outcomes, real-valued coalition coordinates, and the endpoint \(q=1\) introduce no omitted exception.

2. Forcing observations

The upward-closure lemma is valid. If \(a\in U\) and \(b\notin U\), blocking \(b\) requires eligible types weakly preferring \(a\) to \(b\). Those types are disjoint from the types strictly preferring \(b\) to \(a\). If both sets have mass at least \(q\), their combined mass is at least \(2q>1\), which is impossible.

Both consequences follow correctly:

  • Blocking an excluded outcome supplies a strict-majority dominating witness, so an outcome without such a dominator must belong to \(U\).
  • In the second observation, the specified coalition establishes \(z\longrightarrow u\). Assuming \(z\in U\), upward closure puts \(u\in U\), after which the same coalition establishes \(B_U(z)\), contradicting equation (1).

The use of \(q>1/2\) is explicit and essential.

3. Construction and parameter checks

The outcome and type counts are correct:

  • The optional outcomes number \(4n\).
  • The clause outcomes number \(s+n\).
  • The remaining variable outcomes number \(2n\).

Hence \(m=1+7n+s\). The displayed type families contain \(9n+s+2\) rows.

The private mass calculation is also correct: pair types contribute \(4n\varepsilon\), clause types contribute \(2(s+n)\varepsilon\), and variable types contribute \(2n\varepsilon+2n\eta\). Their sum is \(P=(8n+2s)\varepsilon+2n\eta\).

The parameter inequalities imply \(2n\eta<\varepsilon\) and \(P<(8n+2s+1)\varepsilon<1/4\). Thus the filler mass is positive. Each other mass is positive, including \(2\varepsilon-\eta\), and all masses sum to one.

The quota satisfies \(q\in(1/2,1]\). Reciprocal powers of two meeting the stated bounds have encoding length \(O(\log(n+s+1))\); the resulting masses and quota remain dyadic with the same asymptotic encoding bound.

The rank table defines complete, transitive weak orders. Since its ranks lie in \(\{0,1,2,3,4\}\), each order has at most five indifference classes.

4. Forced inclusion and exclusion: Steps 1–2

The argument forcing \(c\in U\) is correct. The baseline never strictly prefers another outcome to \(c\), and the filler is indifferent. Therefore any strict dominator receives mass at most \(P<q\).

For \(a_C\), the baseline and its own clause type have combined mass exactly \(q\). Both weakly prefer every outcome to \(a_C\), and both strictly prefer any represented \(p_\lambda\) to it. Nonemptiness of \(C\) supplies the required witness.

For \(d_i\), the baseline, \(A_i\), and \(E_i\) likewise have combined mass exactly \(q\). Their ranks satisfy both requirements of the second forcing observation, with witness \(v_i\).

Step 2’s coalition has mass exactly \(q\). After excluding \(D\), each of its three types weakly prefers every possible member of \(U\) to \(v_i\), and strictly prefers \(c\) to \(v_i\). Since \(c\in U\), this proves \(B_U(v_i)\).

Therefore equation (3) follows without circularity.

5. Optional pairs: Step 3

Apart from the minor wording issue recorded below, the dominance and eligibility calculations are correct.

The baseline strictly prefers only \(c\) to an optional outcome. Any other strict witness receives mass at most \(P<q\).

For witness \(c\), the baseline is eligible and contributes \(1/2\). Both pair types contribute when the partner is absent from \(U\). When the partner is present, exactly one pair type is ineligible because it ranks that partner below the tested outcome. Their contributions are therefore exactly \(2\varepsilon\) and \(\varepsilon\), respectively.

Among the remaining private types, only the \(B_i^b\) types can strictly prefer \(c\) to the tested optional outcome. Their total mass is at most \(2n\eta<\varepsilon\). Consequently:

  • An absent partner gives mass at least \(1/2+2\varepsilon=q\).
  • A present partner gives mass strictly below \(1/2+2\varepsilon=q\).

Equation (4) follows, and equation (1) then gives the paired membership equivalence (5). Both selected and both excluded are correctly identified as the two permitted patterns.

6. Clause and exclusivity tests: Steps 4–5

For a clause outcome \(a_C\), the baseline contributes \(1/2\) for every witness in \(U\). Every private type except its own clause type ranks \(a_C\) at least as high as every possible member of \(U\), so none contributes to a strict comparison.

Its own clause type is always weakly eligible and strictly prefers precisely the \(p_\lambda\) with \(\lambda\in C\) among possible witnesses in \(U\). Its mass is \(2\varepsilon\). Equation (6) is therefore exact, including equality at the quota.

For \(d_i\):

  • The baseline contributes \(1/2\).
  • \(A_i\) contributes \(2\varepsilon-\eta\) for every witness.
  • \(E_i\) contributes nothing.
  • \(B_i^b\) contributes \(\eta\) exactly when \(p_{(i,b)}\notin U\).
  • Every remaining private type contributes nothing.

The displayed formula for \(w_U(d_i,u)\) is correct for every \(u\in U\). It reaches the quota exactly when at least one truth-value representative is absent. Thus equation (7) is correct.

7. Soundness and completeness

Soundness uses the additional variable clauses to require at least one selected truth value, and equation (7) to require at most one. The resulting assignment satisfies each original clause by equation (6).

Completeness checks every outcome category. The proposed \(U\) is nonempty because it contains \(c\). The optional pairs satisfy equation (1) by equation (4), the clause outcomes by satisfaction, the \(d_i\) by selecting exactly one truth value, and the \(v_i\) by the Step 2 coalition. The assertion that \(c\) is unblocked follows from the already established absence of any strict-majority dominator.

The reduction therefore proves the required equivalence. The source restriction to nonempty clauses of size at most three and \(n\ge1\) is compatible with standard \(\mathrm{3SAT}\) NP-hardness.

8. Encoding and running times

The reduction has polynomial size. Expanding the ranks into explicit weak-preference relations fits the stated bound \(O((n+s+1)^3\log(n+s+1))\).

For membership in \(\mathrm{NP}\), the \(m\)-bit nonempty-set certificate is sufficient by the finite characterization. Computing the minima and evaluating all relevant masses uses \(O(\tau m^2)\) comparisons and additions.

The common denominator \(D_0\) has bit length \(O(L)\), since \(L\) includes the encodings of all mass denominators and the quota denominator. The stated preprocessing bound \(O(\tau L^2)\) is conservative under elementary arithmetic. Subsequent sums and threshold comparisons use \(O(L)\)-bit integers.

Thus the verification bound \(O(\tau L^2+\tau m^2L)\) and exhaustive decision bound \(O(\tau L^2+2^m\tau m^2L)\) are justified. Preference preprocessing fits within these conservative bounds.

Together with the reduction, this establishes \(\mathrm{NP}\)-completeness.
