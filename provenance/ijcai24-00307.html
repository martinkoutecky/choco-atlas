The continuous mirror question, as graded

Given rational interval starts \(a_t\), rational masses \(\mu_t\ge 0\) with \(\sum_t\mu_t=1\), and type intervals \(I_t=[a_t,a_t+1]\), compute an exact minimizer \(x^\star\) for either \(S_\mu(x)=\sum_t\mu_t\min\{|x-a_t|,1\}\) or \(M_\mu(x)=\max_{\mu_t>0}\min\{|x-a_t|,1\}\), where the covering interval is \([x,x+1]\).

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a list of \(\tau\ge 1\) distinct types with starts \(a_t\in\mathbb Q\), intervals \(I_t=[a_t,a_t+1]\), and positive binary-rational masses \(\mu_t\) satisfying \(\sum_{t=1}^{\tau}\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types.
There is one covering interval, so \(m=1\), placed as \([x,x+1]\) with \(x\in\mathbb R\). Type \(t\)'s cost is its uncovered length, \(c_t(x)=\min\{|x-a_t|,1\}\).
The input specifies either the social objective \(S_\mu(x)=\sum_{t=1}^{\tau}\mu_t c_t(x)\) or the maximum objective \(M_\mu(x)=\max_{1\le t\le\tau}c_t(x)\). Compute an exact rational minimizer; any minimizer is acceptable. No incentive constraint is imposed.
Let \(L\) be the total binary input length. State running times in \(m\), \(\tau\), and \(L\).

For each objective separately, is computing an exact minimizer solvable in polynomial time in \(m,\tau,L\), or is it NP-hard?

For a finite unweighted society with starts supplied in sorted order, both minimizing positions are claimed computable in linear time by [Deligkas, Filos-Ratsikas, and Voudouris](https://doi.org/10.1007/s10458-024-09673-6).

Classification

For the stipulated case \(m=1\), both objectives are solvable in polynomial time, with an exact rational minimizer as output.

The following bounds use ordinary binary arithmetic; “arithmetic operations” counts exact rational or integer operations.

| Objective | Arithmetic operations, arbitrary input order | Bit operations |
|---|---:|---:|
| Social objective | \(O(\tau\log(\tau+1))\) | \(O(\tau\log(\tau+1)L^2)\) |
| Maximum objective | \(O(\tau)\) | \(O(\tau L^2)\) |

If the starts are already sorted, the social algorithm uses \(O(\tau)\) arithmetic operations and \(O(\tau L^2)\) bit operations. These are bounds for \(m=1\); no assertion about variable \(m\) is needed.

The cited paper’s Theorem 2.3 states the linear-time result for its finite unweighted setting. The proof below directly handles the rationally weighted support representation. [Deligkas, Filos-Ratsikas, and Voudouris, *Truthful interval covering*](https://doi.org/10.1007/s10458-024-09673-6).

1. Social objective: finitely many candidates

For each type \(t\), the cost has the following description:

  • It equals \(1\) when \(x\le a_t-1\).
  • It equals \(a_t-x\) when \(a_t-1\le x\le a_t\).
  • It equals \(x-a_t\) when \(a_t\le x\le a_t+1\).
  • It equals \(1\) when \(x\ge a_t+1\).

Thus \(c_t\) is continuous and affine between its three breakpoints \(a_t-1,a_t,a_t+1\). Consequently, \(S_\mu\) is continuous and affine between consecutive distinct points of

\(B=\{a_t-1,a_t,a_t+1:1\le t\le\tau\}\).

Claim. Some global minimizer belongs to \(B\).

Proof. On a closed interval between consecutive breakpoints, an affine function attains its minimum at an endpoint: choose the left endpoint if its slope is nonnegative, and the right endpoint otherwise. Outside the extreme breakpoints, every type has cost \(1\), so \(S_\mu=1\).

For any type \(u\), positivity and normalization of the masses give

\(S_\mu(a_u)=\sum_{t\ne u}\mu_t c_t(a_u)\le\sum_{t\ne u}\mu_t=1-\mu_u<1.\)

Therefore the exterior constant regions cannot contain a global minimum. Taking the minimum over the finitely many breakpoint values gives a global minimizer. This proves the claim.

Already, evaluating all at most \(3\tau\) candidates directly gives a polynomial-time algorithm. The following sweep improves its arithmetic running time.

2. Social objective: exact sweep

Write the rational input as \(a_t=p_t/q_t\) and \(\mu_t=r_t/s_t\), with integer numerators and positive integer denominators. Define

\(P=\prod_{t=1}^{\tau}q_t,\qquad Q=\prod_{t=1}^{\tau}s_t,\qquad A_t=p_t(P/q_t),\qquad W_t=r_t(Q/s_t).\)

These quantities are integers, with \(P,Q,W_t>0\). Normalization implies \(\sum_tW_t=Q\).

Under the coordinate change \(X=Px\), define

\(F(X)=\sum_{t=1}^{\tau}W_t\min\{|X-A_t|,P\}.\)

Then, for every real \(X\),

\(S_\mu(X/P)=F(X)/(PQ).\)

Hence minimizing \(F\) is equivalent to minimizing \(S_\mu\). The breakpoints of \(F\) are the integers \(A_t-P,A_t,A_t+P\).

The slope changes contributed by type \(t\) are:

| Coordinate | Change in slope |
|---|---:|
| \(A_t-P\) | \(-W_t\) |
| \(A_t\) | \(2W_t\) |
| \(A_t+P\) | \(-W_t\) |

These follow directly from the successive slopes \(0,-W_t,W_t,0\) of that type’s summand.

Sort the event coordinates, aggregate changes at coincident coordinates, and denote the resulting distinct coordinates by \(b_1<\cdots<b_k\), where \(k\le3\tau\). Let \(\Delta_j\) be the total slope change at \(b_j\).

At the first breakpoint, \(b_1\le A_t-P\) for every type, so

\(F(b_1)=P\sum_tW_t=PQ.\)

Initialize \(V_1=PQ\) and \(D_0=0\). At each event, update the slope by

\(D_j=D_{j-1}+\Delta_j.\)

For \(j<k\), compute the next value using

\(V_{j+1}=V_j+D_j(b_{j+1}-b_j).\)

Correctness. There is no breakpoint strictly between \(b_j\) and \(b_{j+1}\). Thus \(F\) is affine there with slope \(D_j\). Continuity therefore gives the displayed recurrence, and induction proves \(V_j=F(b_j)\) for every \(j\).

Choose any \(b_j\) with smallest \(V_j\) and return \(x=b_j/P\). Section 1 proves that this is a global minimizer. It is an exact rational number.

Constructing and sorting the events uses \(O(\tau\log(\tau+1))\) arithmetic operations; the sweep uses \(O(\tau)\). If the starts are sorted, each of the lists \((A_t-P)_t\), \((A_t)_t\), and \((A_t+P)_t\) is sorted. Merging these three lists, aggregating coincident events, and sweeping takes \(O(\tau)\) arithmetic operations.

3. Social objective: bit complexity

All arithmetic above has polynomially bounded operand length.

Indeed, the binary lengths of \(P\) and \(Q\) are bounded by constants times the sums of the input denominator lengths, hence are \(O(L)\). Each \(A_t\), \(W_t\), and breakpoint also has \(O(L)\) bits.

For every coordinate, \(0\le F(X)\le PQ\). Every slope is a sum of contributions belonging to \(\{-W_t,0,W_t\}\), so its absolute value is at most \(Q\). Breakpoint differences and the products used in the recurrence have \(O(L)\) bits as well. Thus no intermediate integer requires more than \(O(L)\) bits.

Using elementary integer multiplication and division, each required arithmetic operation costs at most \(O(L^2)\) bit operations. This proves the stated bounds:

  • Arbitrary input order: \(O(\tau\log(\tau+1)L^2)\).
  • Sorted starts: \(O(\tau L^2)\).

The returned numerator and denominator have \(O(L)\) bits. In particular, the algorithm never expands a rational mass into repeated agents.

4. Maximum objective: midpoint algorithm

Let

\(a_-=\min_t a_t,\qquad a_+=\max_t a_t,\qquad d=a_+-a_-.\)

The masses do not affect the specified maximum objective.

For every real \(x\), define \(R(x)=\max_t|x-a_t|\). Since the truncation function \(u\mapsto\min\{u,1\}\) is nondecreasing and the maximum is over a finite nonempty set,

\(M_\mu(x)=\min\{R(x),1\}.\)

Every start lies between \(a_-\) and \(a_+\). The greatest distance from \(x\) to a point in that interval occurs at an endpoint; both endpoints are present in the support. Therefore

\(R(x)=\max\{|x-a_-|,|x-a_+|\}.\)

The triangle inequality gives

\(d\le|x-a_-|+|x-a_+|\le2R(x),\)

and hence

\(M_\mu(x)\ge\min\{d/2,1\}.\)

At the rational midpoint \(x^\star=(a_-+a_+)/2\), both endpoint distances equal \(d/2\). Consequently,

\(M_\mu(x^\star)=\min\{d/2,1\},\)

which matches the lower bound and proves optimality.

This also covers \(\tau=1\), when \(x^\star=a_-=a_+\). If \(d\ge2\), the optimum is \(1\), and every real position is optimal; the midpoint remains an acceptable rational output.

Scanning the support finds the two extreme starts using \(O(\tau)\) rational comparisons. Each comparison and the midpoint calculation involve \(O(L)\)-bit integers and cost at most \(O(L^2)\) bit operations. The total is \(O(\tau L^2)\), and the midpoint has \(O(L)\) output bits.
