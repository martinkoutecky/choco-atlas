The continuous mirror question, as graded

Given \(C\), \(\tau\), \(k\), \(y\), a finite support \(T\subseteq(C\cup\{\varnothing\})^\tau\), rational masses \(\mu_\sigma\ge0\) summing to \(1\), and rational \(X\), decide whether there are integral committees \(D_1,\ldots,D_\tau\subseteq C\) with \(|D_t|\le k\), \(\sum_{\sigma\in T}\mu_\sigma\mathbf{1}[\sigma_t\in D_t]\ge X\) for every \(t\), and \(\sum_{t=1}^{\tau}\mathbf{1}[\sigma_t\in D_t]\ge y\) for every \(\sigma\in T\) with \(\mu_\sigma>0\).

Packaged proof task (what the prover saw — nothing else)

Definitions

Let \(q\in(1/2,1)\) be fixed. An instance consists of \(\tau\) levels and an explicitly listed finite set \(\Theta\) of types, each with a positive rational mass \(\mu_\theta\), where \(\sum_{\theta\in\Theta}\mu_\theta=1\), and a trajectory \(u_\theta\in(\{d,c_\top,c_\bot\}\cup\{\varnothing\})^\tau\). Does there exist \(D_1,\ldots,D_\tau\subseteq\{d,c_\top,c_\bot\}\), with \(\lvert D_t\rvert\le2\), such that for every \(t\), \(\sum_{\theta:u_{\theta,t}\in D_t}\mu_\theta\ge q\), and every \(\theta\in\Theta\) is satisfied in at least one level, i.e. \(\lvert\{t:u_{\theta,t}\in D_t\}\rvert\ge1\)?

Target

Is this finite-support rational-mass committee-sequence problem solvable in polynomial time, or is it NP-hard?

Nearest known results

For finite societies with individual agents, the corresponding egalitarian committee-sequence problem is NP-hard even when the per-level score threshold is \(0\), committee size is \(1\), every agent needs satisfaction in only one level, and there are two candidates.

Complexity Classification

Theorem

For every fixed \(q\in(1/2,1)\), the finite-support rational-mass committee-sequence problem is NP-hard.

If \(q\) is rational, the problem is NP-complete. Consequently, it is not polynomial-time solvable unless \(\mathrm{P}=\mathrm{NP}\).

Reduction from \(3\)-SAT

Let \(\varphi\) be a \(3\)-CNF formula with variables \(x_1,\ldots,x_n\) and non-tautological clauses \(C_1,\ldots,C_m\).

Tautological clauses can be deleted, repeated literals can be removed, and duplicate clauses can be merged in polynomial time without changing satisfiability. Thus we may assume that no clause contains both \(x_i\) and \(\neg x_i\), and that distinct clauses have distinct literal sets. We also assume \(m\geq1\); the empty formula can be mapped separately to any fixed feasible instance.

Because \(q<1\), choose and fix a rational number \(\alpha\) satisfying

\(\displaystyle q<\alpha<1.\)

This number depends only on the fixed parameter \(q\), not on \(\varphi\). Put \(\beta=1-\alpha\). Since \(q>1/2\),

\(\displaystyle \beta=1-\alpha<1-q<q.\)

Construct an instance with \(\tau=n\) levels.

Types and masses

Introduce an anchor type \(\theta_0\) of mass

\(\displaystyle \mu_{\theta_0}=\alpha\)

and trajectory

\(\displaystyle u_{\theta_0,i}=d\)

for every \(i\in\{1,\ldots,n\}\).

For every clause \(C_j\), introduce a clause type \(\theta_j\) of mass

\(\displaystyle \mu_{\theta_j}=\frac{\beta}{m}.\)

Its trajectory is defined, for every variable \(x_i\), by

\(\displaystyle u_{\theta_j,i}= \begin{cases} c_\top,&\text{if }x_i\in C_j,\\ c_\bot,&\text{if }\neg x_i\in C_j,\\ \varnothing,&\text{otherwise.} \end{cases} \)

This is well-defined because no clause contains both \(x_i\) and \(\neg x_i\).

All masses are positive rationals, and

\(\displaystyle \mu_{\theta_0}+\sum_{j=1}^{m}\mu_{\theta_j} =\alpha+m\frac{\beta}{m} =\alpha+\beta =1. \)

The construction has \(m+1\) types, \(n\) levels, and polynomial encoding length. In particular, because \(\alpha\) is fixed, the bit length of \(\beta/m\) is \(O(\log m)\).

Correctness of the Reduction

Forward implication

Assume that \(\varphi\) has a satisfying assignment \(a\).

For each level \(i\), choose

\(\displaystyle D_i= \begin{cases} \{d,c_\top\},&\text{if }a(x_i)=\mathrm{true},\\ \{d,c_\bot\},&\text{if }a(x_i)=\mathrm{false}. \end{cases} \)

Each \(D_i\) has cardinality \(2\). Moreover, the anchor type belongs to the selected committee at every level, so

\(\displaystyle \sum_{\theta:u_{\theta,i}\in D_i}\mu_\theta \geq\mu_{\theta_0} =\alpha >q. \)

Thus every level satisfies the mass threshold.

The anchor type is satisfied at every level. Consider a clause type \(\theta_j\). Since \(a\) satisfies \(C_j\), that clause contains a true literal.

If the true literal is \(x_i\), then \(u_{\theta_j,i}=c_\top\in D_i\). If the true literal is \(\neg x_i\), then \(u_{\theta_j,i}=c_\bot\in D_i\). Hence \(\theta_j\) is satisfied at some level.

Therefore the constructed committee-sequence instance is feasible.

Reverse implication

Assume that \(D_1,\ldots,D_n\) is a feasible committee sequence.

We first prove that \(d\in D_i\) for every level \(i\). Suppose instead that \(d\notin D_i\). The anchor type is then excluded. The total mass of all remaining types is exactly \(\beta\), and therefore

\(\displaystyle \sum_{\theta:u_{\theta,i}\in D_i}\mu_\theta \leq\beta <q, \)

contradicting the level-\(i\) mass constraint. Thus \(d\in D_i\).

Because \(|D_i|\leq2\), at most one of \(c_\top\) and \(c_\bot\) can also belong to \(D_i\). Define an assignment \(a\) by

  • \(a(x_i)=\mathrm{true}\) if \(c_\top\in D_i\);
  • \(a(x_i)=\mathrm{false}\) if \(c_\bot\in D_i\);
  • choose either truth value arbitrarily if \(D_i=\{d\}\).

Now consider any clause \(C_j\). Its type \(\theta_j\) must be satisfied at some level \(i\). Clause-type trajectories never contain \(d\), and \(\varnothing\) is not selectable. Hence either:

  • \(u_{\theta_j,i}=c_\top\in D_i\), in which case \(x_i\in C_j\) and \(a(x_i)=\mathrm{true}\); or
  • \(u_{\theta_j,i}=c_\bot\in D_i\), in which case \(\neg x_i\in C_j\) and \(a(x_i)=\mathrm{false}\).

In either case \(C_j\) has a true literal. Since this holds for every clause, \(a\) satisfies \(\varphi\).

We have therefore proved

\(\displaystyle \varphi\text{ is satisfiable} \quad\Longleftrightarrow\quad \text{the constructed committee-sequence instance is feasible}. \)

This establishes NP-hardness.

Membership in NP for Rational \(q\)

Suppose the fixed threshold \(q\) is rational. A certificate consists of \(D_1,\ldots,D_\tau\). Since there are only three candidates, the certificate has size \(O(\tau)\).

For every level, one can sum the explicitly given rational masses of the selected types and compare the result with \(q\) using polynomial-time rational arithmetic. For every type, one can inspect its \(\tau\) trajectory entries and verify that at least one lies in the corresponding \(D_t\). The verification time is polynomial in the input encoding length.

Thus the problem belongs to NP when \(q\) is rational, and the preceding reduction proves NP-completeness.

For an arbitrary fixed real \(q\), membership in NP requires an effective representation or comparison model for \(q\). The NP-hardness proof itself does not require such an assumption: the rational constant \(\alpha\in(q,1)\) can be fixed and hard-coded for that particular \(q\).

Verification Report

Overall assessment

The prover fully resolves the target. The reduction is polynomial, preserves feasibility in both directions, respects the mass and trajectory requirements, and proves NP-hardness for every fixed \(q\in(1/2,1)\). The NP-membership argument is valid when \(q\) is rational.

Step-by-step audit

  • Choice of constants.

For fixed \(q<1\), a rational \(\alpha\) with \(q<\alpha<1\) exists. Defining \(\beta=1-\alpha\) gives
\[ \beta<1-q<q, \]
using \(q>1/2\). Both inequalities are correct.

  • Validity of the constructed instance.

The anchor has positive rational mass \(\alpha\), and each clause type has positive rational mass \(\beta/m\). Their total mass is exactly
\[ \alpha+m(\beta/m)=1. \]
Every trajectory entry belongs to the permitted alphabet. Non-tautological clauses ensure that no trajectory entry is assigned both \(c_\top\) and \(c_\bot\).

  • Polynomial encoding length.

The construction contains \(n\) levels and \(m+1\) explicitly listed types, with \(O(mn)\) trajectory entries. Since \(\alpha\) and \(\beta\) are constants depending only on the fixed \(q\), the encoding length of \(\beta/m\) is \(O(\log m)\). Thus the reduction is polynomial-time.

  • Forward implication.

Given a satisfying assignment, the proposed committee at each level contains \(d\) and the candidate corresponding to the assigned truth value. Its size is exactly \(2\). The anchor alone contributes mass \(\alpha>q\), so every level meets the threshold. Each clause contains a true literal, and the corresponding clause type is consequently satisfied at that literal’s variable level. This direction is correct.

  • Forced inclusion of \(d\).

If \(d\notin D_i\), the anchor contributes no mass. All remaining types have total mass \(\beta<q\), so the threshold cannot be met. Therefore every feasible committee contains \(d\). This is the key forcing argument and is valid.

  • Extraction of an assignment.

Since \(d\in D_i\) and \(\lvert D_i\rvert\leq2\), the committee cannot contain both \(c_\top\) and \(c_\bot\). The assignment definition is therefore consistent. If \(D_i=\{d\}\), choosing either truth value cannot invalidate any satisfaction witness because no clause type ever has trajectory value \(d\).

  • Reverse implication.

Every clause type must be satisfied somewhere. Since its trajectory entries are only \(c_\top\), \(c_\bot\), or \(\varnothing\), and \(\varnothing\notin D_i\), its satisfaction witness corresponds to a selected literal candidate. By the extracted assignment, that literal is true. Hence every clause is satisfied. This direction is complete.

  • NP membership for rational \(q\).

A committee sequence is a certificate of polynomial size. Exact sums and comparisons of explicitly encoded rationals can be performed in polynomial time, and all type-satisfaction conditions can be checked in \(O(\lvert\Theta\rvert\tau)\) trajectory inspections. Thus membership in NP is correctly established for fixed rational \(q\).

  • Arbitrary fixed real \(q\).

The prover appropriately limits the NP-completeness statement to rational \(q\). For NP-hardness, the fixed rational \(\alpha\in(q,1)\) may be hard-coded into the reduction, so no effective representation of \(q\) is needed by the reduction itself.

Conclusion

No mathematical or logical gap was found. The output proves NP-hardness for every fixed \(q\in(1/2,1)\) and NP-completeness when the fixed threshold \(q\) is rational.
