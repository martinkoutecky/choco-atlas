The continuous mirror question, as graded

Given finite complete agent types \(T\) with rational masses \(\mu_t\), bundles \(D\), utilities \(u_t(d)\), per-capita resource bound \(b\), resource use \(a(d)\), and nonnegative welfare weights \(\lambda_t\), find an incentive-compatible direct mechanism \(y(d\mid r)\) maximizing \(\sum_{t\in T}\mu_t\lambda_t\sum_{d\in D}y(d\mid t)u_t(d)\), subject to \(\sum_d y(d\mid r)=1\), \(y(d\mid r)\ge 0\), \(\sum_t\mu_t\sum_d y(d\mid t)a(d)\le b\), and truthful reporting being optimal for each type.

1. An equivalent linear program

For each \(t\in T\) and \(d\in D\), introduce a real variable \(x_{td}\), interpreted as \(y(d\mid t)\). Consider the following linear program:

\( \displaystyle \max_x\ \sum_{t\in T}\sum_{d\in D} \mu_t\lambda_t u_t(d)x_{td} \)

subject to

\( \displaystyle x_{td}\ge 0 \qquad(t\in T,\ d\in D), \)

\( \displaystyle \sum_{d\in D}x_{td}=1 \qquad(t\in T), \)

\( \displaystyle \sum_{t\in T}\sum_{d\in D}\mu_t a(d)x_{td}\le b, \)

and

\( \displaystyle \sum_{d\in D}u_t(d)x_{td} - \sum_{d\in D}u_t(d)x_{rd} \ge 0 \qquad(t,r\in T,\ t\ne r). \)

All coefficients are fixed rational input data or products of such data.

Equivalence proof. Given a feasible incentive-compatible mechanism, set \(x_{td}=y(d\mid t)\). Its lottery conditions imply the first two families of constraints, its resource feasibility implies the third constraint, and its incentive compatibility implies the last family.

Conversely, any feasible LP solution defines lotteries by \(y(d\mid t)=x_{td}\). The constraints establish exactly the required resource feasibility and incentive compatibility. The omitted incentive inequalities with \(t=r\) are identities.

Finally, the LP objective equals the mechanism’s stated objective. Thus the correspondence preserves feasibility and objective values in both directions. In particular, solving this LP solves the requested optimization problem.

Consequently, its numbers of variables and constraints are polynomial in \(m,\tau\).

The resource coefficients are \(\mu_t a(d)\), and the objective coefficients are \(\mu_t\lambda_t u_t(d)\). Multiplying a fixed number of binary-encoded rationals adds their numerator and denominator bit lengths, up to constant overhead. Since each input rational has encoding length at most \(L\), every resulting coefficient has bit length \(O(L)\). Incentive coefficients are input utilities, their negatives, or zero.

Even a dense encoding of the constraint matrix therefore has length polynomial in \(m,\tau,L\). It can be constructed in polynomial time using exact rational arithmetic. 3. Exact optimization and attainment

We use the standard polynomial-time theorem for rational linear programming: an explicitly encoded rational LP can be solved in time polynomial in its total binary encoding length, with infeasibility or unboundedness detected and an exact rational optimizer returned whenever a finite optimum is attained.

Its hypotheses hold here. Every coefficient is rational, and Section 2 establishes polynomial encoding length. Moreover, nonnegativity and normalization imply \(0\le x_{td}\le 1\). The feasible set is therefore bounded. It is also closed, being defined by finitely many linear equalities and non-strict inequalities. If nonempty, it is compact, so its continuous linear objective attains a finite maximum.

For completeness, exact output does not require exponentially many bits. A nonempty bounded polyhedron has an optimal vertex. At a vertex, the active constraint normals span the full variable space: otherwise a nonzero direction orthogonal to them would permit sufficiently small feasible movements in both directions, contradicting extremality. Thus \(n\) independent active constraints determine the vertex.

Clear denominators in these constraints. The resulting integer coefficients and right-hand sides have bit length bounded by some \(B\) polynomial in the LP encoding length. Cramer’s rule expresses every coordinate as a ratio of determinants. If all integer entries have absolute value at most \(2^B\), the determinant expansion bounds each determinant’s absolute value by \(n!2^{nB}\). Its bit length is therefore \(O(nB+n\log n)\), which is polynomial. Hence an optimal rational mechanism has polynomial output length.

Applying the rational LP theorem now yields the claimed exact polynomial-time algorithm.

4. Feasibility and the cited mechanism-design result

Feasibility itself admits a simple characterization:

\( \displaystyle \text{a feasible incentive-compatible mechanism exists} \quad\Longleftrightarrow\quad \min_{d\in D}a(d)\le b. \)

Indeed, every lottery has expected resource use at least \(\min_{d\in D}a(d)\); averaging over masses summing to one preserves this lower bound. Conversely, if a minimum-resource bundle satisfies the bound, assigning it deterministically to every report is feasible. Every report then gives a given type the same utility, so all incentive inequalities hold with equality.

This characterization settles only feasibility; the LP above optimizes over all feasible truthful mechanisms.

The probability-variable formulation follows the approach in [Conitzer and Sandholm (2002), Section 4](https://www.cs.cmu.edu/~sandholm/www/complexity_of_mechanism_design.uai02.pdf). The resource constraint is handled directly by adding its single linear row. The supplied incentive-efficiency characterization is not needed for this algorithm or its correctness proof.
