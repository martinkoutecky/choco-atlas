The continuous mirror question, as graded

Given a finite bipartite type graph \(H=(T_L\cup T_R,F)\), rational masses \(\mu_t\ge0\) with \(\sum_t\mu_t=1\), and rational per-agent allocations \(q_t\), decide whether \(q\) is in the continuous core: \(\sum_t\mu_tq_t=V(\mu)\) and \(\sum_tz_tq_t\ge V(z)\) for every \(0\le z\le\mu\), where \(V(z)\) is the maximum \(\sum_{(t,u)\in F}x_{tu}\) subject to \(\sum_u x_{tu}\le3z_t\), \(\sum_t x_{tu}\le3z_u\), and \(x_{tu}\ge0\); if not, output a violating \(z\) and feasible \(x\).

Packaged proof task (what the prover saw — nothing else)

Let \(H=(T_L\cup T_R,F)\) be a finite simple bipartite graph, with \(m=|F|\). A society is given by its support: the list of its \(\tau\) types with positive mass, each mass \(\mu_t\) a binary rational, with \(\sum_t\mu_t=1\); \(\tau\) is the support size, not the number of possible types. The graph has exactly these types as vertices. Input also includes per-agent allocations \(q_t\in\mathbb{Q}\); let \(L\) be the total binary input length.
For every real coalition-mass vector \(0\le z\le\mu\), define \(V(z)=\max\{\sum_{(t,u)\in F}x_{tu}:x\in\mathbb{R}_{\ge0}^{F},\ \sum_{u:(t,u)\in F}x_{tu}\le3z_t\ (t\in T_L),\ \sum_{t:(t,u)\in F}x_{tu}\le3z_u\ (u\in T_R)\}\). Each unit of matched mass has value \(1\); there are no additional edge-capacity constraints.
Continuous core membership means \(\sum_t\mu_tq_t=V(\mu)\) and \(\sum_tz_tq_t\ge V(z)\) for every \(0\le z\le\mu\). The separation problem decides membership and, upon rejection, reports failure of efficiency or returns rational \(z\) and feasible rational \(x\) with \(\sum_{(t,u)\in F}x_{tu}>\sum_tz_tq_t\).

Is this continuous core-membership and separation problem polynomial-time solvable in \(m,\tau,L\), or NP-hard?

For finite agents on a simple bipartite graph, coalition value is the maximum cardinality of a \(3\)-matching in the induced graph: discrete core membership is co-NP-complete, and detecting a blocking coalition is NP-complete ([source](https://arxiv.org/pdf/1508.06420)).
No result settling precisely the support-mass problem defined above was identified in the literature search.

Modeling choices made when packaging the task

  • Removed zero-mass types and used the induced graph on the positive-mass support.
  • Allowed signed rational allocations, consistent with the discrete cooperative-game allocation domain.
  • Allowed real coalition masses and matching flows; requested rational witnesses for strict coalition violations.
  • If efficiency fails, permitted reporting that failure instead of requiring a blocking coalition, which need not exist.
  • Preserved the explicitly specified continuous value function without an additional edge-capacity bound; the discrete restriction of at most one match per individual pair does not supply a bound on aggregate type-to-type mass.
  • Defined m as the number of type-graph edges and L as total binary input length.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

1. Result

The continuous core-membership and separation problem is polynomial-time solvable in \(m,\tau,L\).

More precisely, an allocation \(q\) belongs to the continuous core if and only if all three conditions hold:

  • \(\sum_t\mu_tq_t=V(\mu)\).
  • \(q_t\ge 0\) for every type \(t\).
  • \(q_t+q_u\ge 3\) for every edge \((t,u)\in F\).

Every failure of a coalition inequality has a rational blocking certificate supported on at most two types.

2. Necessity of the local conditions

Assume that \(\sum_tz_tq_t\ge V(z)\) for every real vector \(0\le z\le\mu\). Every listed type has \(\mu_t>0\), by the support convention.

If \(q_t<0\), choose \(z_t=\mu_t\), with all other coordinates zero, and choose \(x=0\). This matching vector is feasible, and its value satisfies \(\sum_{e\in F}x_e=0>\mu_tq_t=\sum_vz_vq_v\). Thus nonnegative allocations are necessary. This construction also provides the required rational certificate.

Now suppose an edge \((t,u)\) satisfies \(q_t+q_u<3\). Let \(a=\min\{\mu_t,\mu_u\}>0\). Choose \(z_t=z_u=a\), with all other coordinates zero, and choose \(x_{tu}=3a\), with all other edge coordinates zero.

The vector \(z\) lies in the prescribed box. At each of \(t,u\), the matching uses exactly \(3a=3z_t=3z_u\); every other vertex has zero incident matching mass. Hence \(x\) is feasible. Moreover, \(\sum_{e\in F}x_e=3a>a(q_t+q_u)=\sum_vz_vq_v\).

Therefore every edge must satisfy \(q_t+q_u\ge3\). Again, the construction is a rational blocking certificate.

3. Sufficiency for every real coalition

Assume \(q_t\ge0\) for every type and \(q_t+q_u\ge3\) for every edge.

Fix any real \(z\) satisfying \(0\le z\le\mu\), and any feasible matching vector \(x\). Define the incident matching mass by \(d_t(x)=\sum_{e\in F:\,t\in e}x_e\). Feasibility gives \(d_t(x)\le3z_t\).

Since \(q_t\ge0\), multiplying these inequalities by \(q_t/3\) and summing yields
\(\sum_tz_tq_t\ge\frac13\sum_tq_td_t(x)\).

Each edge has precisely its two endpoints, so
\(\frac13\sum_tq_td_t(x)=\frac13\sum_{(t,u)\in F}(q_t+q_u)x_{tu}\ge\sum_{(t,u)\in F}x_{tu}\),
where the last inequality uses \(q_t+q_u\ge3\) and \(x_{tu}\ge0\).

Consequently, \(\sum_tz_tq_t\ge\sum_{(t,u)\in F}x_{tu}\) for every feasible \(x\). Taking the maximum gives \(\sum_tz_tq_t\ge V(z)\).

The maximum exists: the feasible set is nonempty because it contains zero, is closed, and is bounded because each edge variable satisfies \(x_{tu}\le3\min\{z_t,z_u\}\).

This proves the coalition inequalities for all real \(z\) in the box, including irrational vectors. Together with efficiency, it proves the stated characterization.

4. Exact efficiency computation

Construct a directed network with source \(s\), sink \(r\), and the types as its other vertices. Its arcs and capacities are:

  • \(s\to t\), of capacity \(3\mu_t\), for \(t\in T_L\).
  • \(t\to u\), of capacity \(3\), for \((t,u)\in F\).
  • \(u\to r\), of capacity \(3\mu_u\), for \(u\in T_R\).

The capacity \(3\) on a middle arc imposes no additional restriction: any feasible matching already satisfies \(x_{tu}\le3\mu_t\le3\).

A feasible matching \(x\) defines a feasible flow by assigning \(x_{tu}\) to each middle arc and assigning the corresponding incident sums to the source and sink arcs. Its flow value is \(\sum_{(t,u)\in F}x_{tu}\).

Conversely, flow conservation implies that the values on the middle arcs satisfy precisely the matching constraints for \(\mu\). The flow value equals their sum. Thus the maximum flow value is exactly \(V(\mu)\).

For an exact bit-complexity bound, write each input mass as \(\mu_t=a_t/b_t\), with positive integer denominator, and let \(D=\prod_tb_t\). The binary length of \(D\) is at most the sum of the denominator lengths, hence is bounded by \(L\). Multiplying every network capacity by \(D\) produces integer capacities with binary length bounded by \(O(L)\).

The Edmonds–Karp theorem states that maximum flow on a finite directed network with nonnegative capacities can be computed using \(O(NA^2)\) arithmetic operations, where \(N\) and \(A\) are the numbers of vertices and arcs. Here \(N=\tau+2\) and \(A=m+\tau\). On the scaled network, all capacities, residual capacities, and flow values remain integers of \(O(L)\) bits, since the total source capacity is at most \(3D\). Thus this computation has polynomial bit complexity. Dividing its value by \(D\) gives \(V(\mu)\) exactly.

The rational number \(\sum_t\mu_tq_t\) can likewise be computed and compared with \(V(\mu)\) in polynomial bit complexity.

5. Membership and separation algorithm

Perform the following steps:

  • Compute \(V(\mu)\) exactly. If \(\sum_t\mu_tq_t\ne V(\mu)\), reject and report failure of efficiency.
  • Scan the types. If some \(q_t<0\), return the singleton certificate from Section 2.
  • Scan the edges. If some \(q_t+q_u<3\), return the two-type certificate from Section 2.
  • Otherwise, accept.

Sections 2 and 3 prove correctness. Each returned certificate uses an input mass or the minimum of two input masses, multiplied only by \(3\), so its binary encoding length is polynomial in the input length. The scans and their exact rational comparisons also take polynomial time.

The discrete hardness result concerns a different feasible set: its matching selects a subset of edges, so each edge is used at most once. This is explicit in the cited paper’s model, and its Theorem 13 establishes the stated discrete hardness. [Biró et al., *The Stable Fixtures Problem with Payments*](https://arxiv.org/pdf/1508.06420). In the present model, a single edge can carry \(3a\) units for a coalition containing mass \(a\) at each endpoint. That permitted construction forces the local edge inequality and makes the characterization above possible.
