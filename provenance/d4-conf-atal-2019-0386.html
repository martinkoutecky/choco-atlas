Theorem 3 — class: hardness

The continuous mirror question, as graded

Given a finite state set \(S\), initial state \(s_0\), state labels, finite types \(T\) with rational masses \(\mu_t>0\), action sets \(A_t\), an LTL goal \(\gamma_t\) for each type, an LTL query \(\varphi\), and a rational piecewise-polyhedral transition map \(\delta(s,x)\), where \(x_{t,a}\geq 0\) and \(\sum_{a\in A_t}x_{t,a}=\mu_t\), decide whether there exists a finite-state population strategy whose induced run satisfies \(\varphi\) and is in the population core. The core excludes any deviation by a nonzero submass vector \(\nu\in[0,\mu]\) for which every type with \(\nu_t>0\) loses on the baseline run and every response by the residual population of mass \(\mu-\nu\) makes each deviating type’s goal true.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a nonempty list \(T\) of \(\tau\) types, each with positive binary-rational mass \(\mu_t\). Here \(\tau=|T|\) is the support size, not the number of possible types; total mass need not equal \(1\).
The input also contains a nonempty finite state set \(S\), initial state \(s_0\), labels \(\lambda:S\to 2^{AP}\), nonempty finite action sets \(A_t\) available at every state, and LTL formulae \(\gamma_t\) and \(\varphi\) over \(AP\).
For any nonnegative mass vector \(r\), define \(D(r)=\{x\in\mathbb R_{\geq0}^{\sum_t|A_t|}:\sum_{a\in A_t}x_{t,a}=r_t\text{ for every }t\}\). The deterministic transition map \(\delta:S\times D(\mu)\to S\) is explicitly encoded, for each state, by finitely many disjoint cells covering \(D(\mu)\), each specified by rational linear strict or weak inequalities and assigned one successor state; boundary assignments are included.
A strategy for population mass \(r\) is a deterministic finite-state transducer observing only the public state history and outputting an allocation in \(D(r)\). Its finitely many output vectors may have real coordinates, and its memory size is unrestricted. Allocations are divisible masses, not randomised actions.
A baseline strategy \(\sigma\) for mass \(\mu\) induces a unique run \(\rho_\sigma\) from \(s_0\). A type wins exactly when its LTL goal holds on that run, and strictly prefers winning to losing.
A beneficial deviation consists of a fixed vector \(\nu\in\prod_{t\in T}[0,\mu_t]\), with \(\sum_t\nu_t>0\), and a strategy \(\eta\) for mass \(\nu\), such that every type with \(\nu_t>0\) loses on \(\rho_\sigma\), while every strategy \(\theta\) for residual mass \(\mu-\nu\) yields a run satisfying all those types’ goals. These runs restart at \(s_0\), with simultaneous allocations \(y\) and \(z\) and successor \(\delta(s,y+z)\); both sides use the strategy model just defined. The population core consists of baseline strategies admitting no beneficial deviation.
Is deciding whether there exists a population-core strategy \(\sigma\) with \(\rho_\sigma\models\varphi\) solvable in polynomial time, or is it \(\mathrm{NP}\)-hard? State running times in \(m=|S|\), \(\tau\), \(k=\sum_t|A_t|\), and the total binary input length \(L\), including transition guards and LTL formulae.
The discrete existential core-verification problem is \(\mathrm{PSPACE}\)-complete for one player and \(2\mathrm{EXPTIME}\)-complete for multiple players ([source](https://arxiv.org/html/2301.06157)). No complexity result for this exact population model was located in the literature search.

Result

The decision problem is \(2\mathrm{EXPTIME}\)-complete, and hence \(\mathrm{NP}\)-hard.

The hardness holds already with \(\tau=2\), \(k=4\), unit masses, and transition guards consisting only of single-coordinate comparisons with \(\frac12\). Thus divisible allocations and small support do not yield a polynomial-time algorithm.

The proof below applies to the stated finite-state, public-history strategy model.

Full masses suffice for beneficial deviations

For a nonempty subset \(C\subseteq T\), define \(\mu^C_t=\mu_t\) when \(t\in C\), and \(\mu^C_t=0\) otherwise. Write \(\Gamma_C=\bigwedge_{t\in C}\gamma_t\).

Call \(C\) enforceable if some strategy for mass \(\mu^C\) ensures \(\Gamma_C\) against every strategy for mass \(\mu-\mu^C\), starting at \(s_0\).

Lemma. A baseline with losing-type set \(B\subseteq T\) admits a beneficial deviation if and only if some nonempty \(C\subseteq B\) is enforceable.

Proof. An enforceable \(C\subseteq B\) immediately gives a beneficial deviation with mass vector \(\mu^C\).

Conversely, suppose \((\nu,\eta)\) is a beneficial deviation. Put \(C=\{t:\nu_t>0\}\), so \(C\subseteq B\). Define \(e=\mu^C-\nu\), which is coordinatewise nonnegative.

Choose any fixed allocation \(w\in D(e)\). Such an allocation exists because every action set is nonempty. Define the enlarged coalition strategy by adding \(w\) to every output of \(\eta\).

For any residual strategy \(\theta'\) of mass \(\mu-\mu^C\), adding \(w\) to its outputs gives a strategy \(\theta\) of mass \(\mu-\nu\). At every public history, the combined allocations agree:

\(\displaystyle (\eta+w)+\theta'=\eta+(\theta'+w).\)

Consequently, the resulting runs agree. Since \(\eta\) ensures \(\Gamma_C\) against every \(\theta\), its enlargement ensures \(\Gamma_C\) against every \(\theta'\). Adding a fixed vector preserves finite memory and finitely many output vectors. Therefore \(C\) is enforceable. ∎

In particular, whether a baseline belongs to the core depends only on its losing-type set.

Hardness with two types and four actions

We reduce from the complement of LTL realizability.

The standard realizability problem asks whether a finite-state Mealy machine can ensure an LTL specification \(\psi\) when, in each round, the environment chooses the input valuation first and the machine then chooses the output valuation. This problem is \(2\mathrm{EXPTIME}\)-complete. Since this is a deterministic complexity class, its complement is also \(2\mathrm{EXPTIME}\)-complete. See [Pnueli and Rosner, *On the synthesis of a reactive module*](https://doi.org/10.1145/75277.75293).

Let the input and output propositions, together, be \(p_1,\ldots,p_q\), ordered with all input propositions first. Unused dummy propositions can ensure that both parts are nonempty.

Encoding a round by public states

Create two types, called system and environment. Each has mass \(1\) and actions \(\{0,1\}\). Thus \(\tau=2\) and \(k=4\).

The states are:

  • the initial state \(s_0\);
  • a round marker \(M\);
  • a bad absorbing state \(B\);
  • states \(V_{j,0},V_{j,1}\) for each \(j\in\{1,\ldots,q\}\).

Thus \(m=2q+3\).

Introduce fresh propositions \(c,b\). Label \(M\) by \(\{c\}\), label \(B\) by \(\{b\}\), label \(V_{j,1}\) by \(\{p_j\}\), and give all other states the empty label.

At \(s_0\), the system type chooses between \(B\) and \(M\). At \(M\), the first bit is selected. At \(V_{j,\ell}\), for \(j<q\), the next bit is selected. Input bits are controlled by the environment type; output bits by the system type. Both \(V_{q,0}\) and \(V_{q,1}\) return deterministically to \(M\).

Every binary choice controlled by type \(t\) uses the two cells

\(\displaystyle x_{t,1}<\frac12,\qquad x_{t,1}\geq\frac12.\)

They select bit \(0\) and bit \(1\), respectively. At \(s_0\), these select \(B\) and \(M\), respectively.

These cells are disjoint and cover the allocation domain, including the boundary. Forced transitions use a single cell covering the entire domain. Every guard has constant size, apart from state identifiers.

A play entering \(M\) therefore consists of successive blocks, each comprising \(M\), followed by one state for each of the \(q\) bits. The environment selects all current input bits before the system selects the current output bits. Each selected bit becomes publicly visible.

Translating the LTL specification

Put \(h=q+1\). Define a translation \(H\) recursively, using the Boolean operators, next, and until as a syntax basis:

  • \(H(p_j)=\mathsf X^j p_j\).
  • \(H(\neg\alpha)=\neg H(\alpha)\).
  • \(H(\alpha\wedge\beta)=H(\alpha)\wedge H(\beta)\).
  • \(H(\mathsf X\alpha)=\mathsf X^h H(\alpha)\).
  • \(H(\alpha\mathsf U\beta)=(\neg c\vee H(\alpha))\mathsf U(c\wedge H(\beta))\).

Here \(\mathsf X^j\) means \(j\) explicitly written next operators.

For every play in the round gadget, let \(w\) be its word of combined input/output valuations, one valuation per block. At the marker of block \(i\),

\(\displaystyle \rho,ih\models H(\alpha)\quad\Longleftrightarrow\quad w,i\models\alpha,\)

where positions are counted from the first \(M\).

This follows by structural induction. For an atom, its bit is exactly \(j\) positions after the marker. Next jumps exactly one block. For until, the right operand can hold only at a marker; before that marker, the left operand is required precisely at the preceding markers, because \(\neg c\) holds at every intermediate bit state.

The translation has size \(O(q|\psi|)\).

Goals and the requested baseline outcome

Set

\(\displaystyle \gamma_{\mathrm{sys}}=\mathsf X(c\wedge H(\psi)),\qquad \gamma_{\mathrm{env}}=\top,\qquad \varphi=\mathsf X b.\)

Every baseline satisfying \(\varphi\) enters \(B\) immediately. Its losing-type set is exactly \(\{\mathrm{sys}\}\). Such a baseline exists: the system mass can be allocated entirely to action \(0\) initially.

By the lemma, this baseline is in the core exactly when the full system type cannot enforce \(\gamma_{\mathrm{sys}}\).

The full system type can enforce \(\gamma_{\mathrm{sys}}\) exactly when \(\psi\) is realizable:

  • A realizing Mealy machine first chooses \(M\), records the publicly selected input bits, and selects its output bits accordingly. Pure allocations implement either bit.
  • Conversely, any finite-state system strategy entering \(M\) induces a finite-state Mealy machine: simulate its successive public-state updates while collecting the input bits and generating the output bits. The translation proves equality of the relevant objectives.

The restriction to finite-state residual strategies causes no gap. If a fixed finite-state system strategy has a violating input word, its product with a deterministic parity automaton for the objective is a finite graph with a rejecting infinite path. Such a graph has a rejecting ultimately periodic path: retain the recurrent odd extremal priority and repeat a suitable closed walk. Its input sequence can be generated by a finite-state environment strategy.

Therefore,

\(\displaystyle \text{a core baseline satisfying }\varphi\text{ exists} \quad\Longleftrightarrow\quad \psi\text{ is unrealizable}. \)

The reduction has \(\tau=2\), \(k=4\), \(m=2q+3\), and output binary length \(O(q|\psi|+q\log(q+2))\), hence polynomial length. This proves \(2\mathrm{EXPTIME}\)-hardness.

A finite abstraction for coalition enforcement

We next prove the matching upper bound for arbitrary valid inputs.

Fix a nonempty \(C\subseteq T\). For a state \(s\) and nonempty \(R\subseteq S\), define

\(\displaystyle F_C(s,R)\quad\Longleftrightarrow\quad \exists y\in D(\mu^C)\ \forall z\in D(\mu-\mu^C): \delta(s,y+z)\in R. \)

This is a sentence of linear real arithmetic. Membership in \(R\) is expressed by the disjunction of precisely those transition cells assigned a successor in \(R\). Strict and weak inequalities are retained exactly. The sentence has at most \(2k\) scalar variables and binary length \(O(L+k)\).

These sentences are decidable in doubly exponential time in their binary length. This follows from quantifier elimination for linear real arithmetic; the Ferrante–Rackoff procedure is described and verified in [Nipkow, *Reflecting Quantifier Elimination for Linear Arithmetic*](https://www21.in.tum.de/~nipkow/pubs/mod2007.pdf).

Construct a finite turn-based arena as follows:

  • At \(s\), the coalition chooses any nonempty \(R\) satisfying \(F_C(s,R)\).
  • The opponent chooses any \(s'\in R\).
  • Play continues from \(s'\).

There is always a legal coalition choice, because \(F_C(s,S)\) holds. This arena has at most \(m2^m\) vertices and \(O(m^2 2^m)\) edges.

Lemma. The coalition can ensure \(\Gamma_C\) in this finite arena exactly when \(C\) is enforceable in the population model.

Proof. First suppose it wins in the finite arena with finite memory. For every selected pair \((s,R)\), fix a witness allocation \(y_{s,R}\) for \(F_C(s,R)\). Output that allocation in the population model. Every possible residual allocation leads to a successor in \(R\), so every resulting public run is a permitted abstract run. The strategy uses finite memory and finitely many real output vectors.

For the converse, fix an enforceable finite-state population strategy \(\eta\). At each of its memory states and public states, its output is a fixed vector \(y\). Define its exact response set

\(\displaystyle R_s(y)=\{\delta(s,y+z):z\in D(\mu-\mu^C)\}. \)

This is nonempty and satisfies \(F_C(s,R_s(y))\). Choosing these sets defines a finite-state strategy in the abstract arena.

Suppose this abstract strategy were losing. Fixing its finite memory and taking the product with a deterministic parity automaton for \(\Gamma_C\) gives a finite graph containing a rejecting ultimately periodic path.

For each transition of that path to \(s'\in R_s(y)\), select an allocation \(z\) witnessing \(\delta(s,y+z)=s'\). A residual transducer can follow this finite prefix and repeating closed walk, outputting those witness allocations.

It needs only finite memory. It observes public states and can track the fixed strategy \(\eta\)'s memory from those states; thus it can determine \(y\) without observing allocations. The resulting population run violates \(\Gamma_C\), contradicting enforceability. ∎

For an LTL formula of length \(O(L)\), standard constructions provide a deterministic parity automaton with

\(\displaystyle D=2^{2^{O(L)}}\text{ states},\qquad d=2^{O(L)}\text{ priorities}.\)

The priority bound follows by translating first to an exponentially sized nondeterministic Büchi automaton and then applying [Piterman’s determinization](https://arxiv.org/abs/0705.2205).

Consequently, coalition enforcement reduces to a finite parity game with at most \(m2^mD\) vertices. Finite parity games admit positional winning strategies and can be solved in time \(N^{O(d)}\), where \(N\) is their number of vertices. Hence enforceability can be computed for all nonempty support subsets.

Testing baseline outcomes

Construct a directed graph on \(S\) by including \(s\to s'\) exactly when

\(\displaystyle \exists x\in D(\mu):\delta(s,x)=s'.\)

This can be computed in polynomial time in \(m,k,L\), by testing the feasibility of each transition cell.

Strict inequalities are handled exactly: replace every strict inequality in a cell by its weak version with a common positive slack, constrain that slack to be at most \(1\), and maximize it. The original cell is feasible exactly when the optimum slack is positive.

For each candidate winner set \(W\subseteq T\), define

\(\displaystyle \Psi_W= \varphi\wedge \bigwedge_{t\in W}\gamma_t\wedge \bigwedge_{t\notin W}\neg\gamma_t. \)

This formula has length \(O(L)\). Test whether the baseline graph has a path from \(s_0\) satisfying \(\Psi_W\). An exponentially sized nondeterministic Büchi automaton and a product-graph emptiness test give time

\(\displaystyle \operatorname{poly}(m,k,L)\,2^{O(L)}.\)

This test exactly captures the finite-state baseline requirement. Every baseline generates a graph path. Conversely, a successful Büchi emptiness test yields an ultimately periodic public-state path. Fixing an allocation witnessing each edge of its finite prefix and repeating closed walk produces a finite-state baseline.

Accept exactly when some \(W\) passes this path test and no nonempty enforceable \(C\subseteq T\setminus W\) exists. The full-mass lemma proves correctness.

The subset condition for all winner sets can be precomputed in \(O(\tau2^\tau)\) time by propagating enforceability flags to supersets of losing-type sets.

Running time and conclusion

Let \(A=2^{2^{p(L+k)}}\) bound one linear-real-arithmetic decision, for a fixed polynomial \(p\). Choose fixed constants so that \(D=2^{2^{O(L)}}\), \(d=2^{O(L)}\), and put \(N=m2^mD\).

A deterministic running-time bound is

\(\displaystyle 2^\tau\left[ m2^m A + N^{O(d)} + \operatorname{poly}(m,k,L)\,2^{O(L)} \right]. \)

The terms account for the enforcement queries, parity games, and baseline path tests, respectively. The subset propagation cost is absorbed by this bound.

Because the input is explicit, \(m,\tau,k\leq L\), so the bound is \(2^{2^{\operatorname{poly}(L)}}\). Together with the reduction, this establishes \(2\mathrm{EXPTIME}\)-completeness for the exact population model.
