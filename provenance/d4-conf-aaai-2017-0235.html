Packaged proof task (what the prover saw — nothing else)

Given a candidate set \(\mathcal{C}\), \(k\leq |\mathcal{C}|\), approval types \(\mathcal{T}\subseteq2^{\mathcal{C}}\), and rational masses \(\mu_A\geq0\) with \(\sum_{A\in\mathcal{T}}\mu_A=1\), a committee \(W\subseteq\mathcal{C}\) of size \(k\) has fractional perfect representation if there are \(x_{A,w}\geq0\) such that \(x_{A,w}=0\) when \(w\notin A\), \(\sum_{w\in W}x_{A,w}=\mu_A\) for every \(A\), and \(\sum_{A\in\mathcal{T}}x_{A,w}=1/k\) for every \(w\in W\).

Target. Is deciding whether such a committee exists polynomial-time solvable, or NP-hard?

For finite voter profiles with \(k\mid n\), deciding whether a perfectly representative committee exists is NP-complete. For finite voter profiles without the divisibility condition, deciding whether a fractional-perfectly-representative committee exists is NP-complete.

Prover output (gpt-6-astra / medium, Bolzano prover prompt)

The decision problem is NP-complete, under the usual explicit encoding of approval types and binary encoding of rational masses. Here \(1\leq k\leq|\mathcal C|\), as required for \(1/k\) to be defined.

The key point is that, on finite profiles where \(k\) divides the number of voters, fractional perfect representation is equivalent to ordinary perfect representation.

  • Equivalence on divisible finite profiles.

Consider a finite profile with \(n\) voters and \(k\mid n\). For each approval set \(A\) occurring in the profile, let \(n_A\) be the number of voters with that approval set. Set \(\mu_A=n_A/n\) and \(q=n/k\).

Fix a committee \(W\) of size \(k\). If the voters can be assigned to approved members of \(W\), with exactly \(q\) voters assigned to each member, let \(y_{A,w}\) count the type-\(A\) voters assigned to \(w\). Then \(x_{A,w}=y_{A,w}/n\) satisfies all fractional-perfect-representation constraints.

Conversely, suppose such fractional variables \(x_{A,w}\) exist. Construct a directed network with source \(s\), one vertex for each approval type \(A\), one vertex for each \(w\in W\), and sink \(t\). Its arcs and capacities are:

  • \(s\to A\), with capacity \(n_A\);
  • \(A\to w\), with capacity \(n\), whenever \(w\in A\cap W\);
  • \(w\to t\), with capacity \(q\).

The values \(f(s,A)=n_A\), \(f(A,w)=nx_{A,w}\), and \(f(w,t)=q\) define a feasible flow of value \(n\). Indeed, conservation at each type and committee vertex follows from the two prescribed marginal sums. Also, \(nx_{A,w}\leq n\), since \(x_{A,w}\leq\mu_A\leq1\).

All capacities are nonnegative integers. The integral maximum-flow theorem therefore guarantees an integral maximum flow. Its value is \(n\): the displayed fractional flow attains this value, and the total capacity leaving \(s\) is \(n\). Consequently, every source arc and every sink arc is saturated, since their respective total capacities are both \(n\).

Write \(y_{A,w}\) for the integral flow on \(A\to w\). For each \(A\), these nonnegative integers sum to \(n_A\), so the \(n_A\) individual voters of that type can be partitioned into groups of sizes \(y_{A,w}\) and assigned accordingly. Every assignment respects approval, and every committee member receives exactly \(q\) voters. Thus \(W\) is ordinarily perfectly representative.

  • Polynomial-time reduction and hardness.

Use the NP-complete problem stated in the question: existence of an ordinarily perfectly representative committee for an explicitly listed finite profile satisfying \(k\mid n\).

Preserve \(\mathcal C\) and \(k\), group voters by identical approval sets, and output the occurring types with masses \(\mu_A=n_A/n\). There are at most \(n\) types, and each mass has a binary encoding of length \(O(\log n)\). Grouping and constructing this instance take polynomial time.

The equivalence proved above holds for every committee \(W\). Hence the original profile admits a perfectly representative committee if and only if the resulting rational-mass instance admits a fractionally perfectly representative committee. This proves NP-hardness.

  • Membership in NP.

A certificate is simply a committee \(W\) of size \(k\). Its feasibility can be checked in polynomial time using a flow network with capacities \(\mu_A\) on \(s\to A\), capacity \(1\) on each allowed \(A\to w\), and capacity \(1/k\) on \(w\to t\).

A flow of value \(1\) exists exactly when the required variables exist. In particular, value \(1\) forces all source and sink arcs to be saturated because each family has total capacity \(1\).

To justify polynomial time with binary rational inputs, write each mass as \(\mu_A=a_A/b_A\), where \(b_A>0\), and let \(D=\prod_{A\in\mathcal T}b_A\). Multiplying every capacity by \(kD\) gives integer capacities. The bit length of \(D\) is at most the sum of the denominator bit lengths, up to a constant, so the scaled network has polynomial encoding length. A polynomial-time integer-capacity maximum-flow algorithm can therefore check whether its maximum flow has value \(kD\).

Thus the problem belongs to NP and, together with the reduction, is NP-complete.
