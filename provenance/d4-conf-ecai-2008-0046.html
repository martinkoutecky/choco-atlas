Result

The problem is \(\mathrm{NP}\)-complete. Hardness holds even when \(\tau=1\), \(\mu_1=1\), \(\theta=\tfrac12\), and the preference relation is a total preorder with three indifference classes. Consequently, a polynomial-time algorithm in \(m,\tau,L\) would imply \(\mathrm{P}=\mathrm{NP}\).

The proof below establishes this directly for the specified encoding and attack definition.

1. Stable-extension verification

For an attack relation \(R\), a set \(E\subseteq A\) is stable precisely when:

  • It is conflict-free: no \(x,y\in E\) satisfy \((x,y)\in R\).
  • It attacks every excluded argument: for every \(y\in A\setminus E\), some \(x\in E\) satisfies \((x,y)\in R\).

With indexed Boolean tables for \(C_t\) and \(\succeq_t\), the attack relation is computed using
\((x,y)\in R_t\) if and only if \((x,y)\in C_t\) and \(\neg(y\succeq_t x\ \land\ \neg(x\succeq_t y))\).

Thus constructing \(R_t\), checking stability of a proposed \(E\), and checking \(a\in E\) require \(O(m^2)\) Boolean operations per type.

2. Membership in \(\mathrm{NP}\)

Define the set of accepting types by
\(B=\{t:\exists E\text{ stable in }(A,R_t),\ a\in E\}\).

A certificate consists of a subset \(S\subseteq\{1,\ldots,\tau\}\) and, for each \(t\in S\), an \(m\)-bit description of a stable extension \(E_t\) containing \(a\). The verifier checks these extensions and the inequality
\(\sum_{t\in S}\mu_t\geq\theta\).

Soundness. Every verified type belongs to \(B\), so \(S\subseteq B\). Since all masses are positive,
\(\sum_{t\in B}\mu_t\geq\sum_{t\in S}\mu_t\geq\theta\).
Therefore an accepted certificate implies a yes-instance.

Completeness. For a yes-instance, choose \(S=B\) and one witnessing extension for each accepting type. This certificate passes every check.

The certificate uses at most \(\tau(m+1)\) bits. Since the support and argument set are explicit, this is polynomial in the input length.

Exact rational arithmetic also takes polynomial time. Write each selected mass as \(p_t/q_t\), with \(q_t>0\). An unreduced common denominator divides \(\prod_{t\in S}q_t\), whose bit length is \(O(L)\). Every partial sum lies in \([0,1]\), so its numerator also has \(O(L)\) bits. Schoolbook arithmetic therefore gives the conservative verification bound
\(O\!\left(L+\tau m^2+(\tau+1)L^2\right)\),
using constant-time indexed Boolean access and charging for integer arithmetic at bit cost.

The cases \(\theta\leq0\) and \(\theta>1\) are immediately yes and no, respectively. Hence the problem belongs to \(\mathrm{NP}\).

3. A direct hardness reduction

Reduce from \(\mathrm{3SAT}\). Let
\(\varphi=\bigwedge_{j=1}^{q}D_j\)
have variables \(x_1,\ldots,x_n\). Introduce distinct arguments
\(A=\{x_i^+,x_i^-:1\leq i\leq n\}\cup\{c_j:1\leq j\leq q\}\cup\{a\}\).

Here \(x_i^+\) represents \(x_i\), and \(x_i^-\) represents \(\neg x_i\). Write \(\ell(\lambda)\) for the argument representing a literal \(\lambda\).

Conflict and preference relations

Define \(C\) by including both orientations of exactly these unordered pairs:

  • \(\{x_i^+,x_i^-\}\), for each variable;
  • \(\{\ell(\lambda),c_j\}\), whenever literal \(\lambda\) occurs in \(D_j\);
  • \(\{c_j,a\}\), for each clause.

All pairs contain distinct arguments, so \(C\) is symmetric and irreflexive.

Give literal arguments rank \(2\), clause arguments rank \(1\), and \(a\) rank \(0\). Define
\(u\succeq v\) if and only if \(r(u)\geq r(v)\).

This relation is reflexive and transitive because the numerical order is reflexive and transitive. It is total, with indifference exactly within each rank. Its strict part satisfies
\(u\succ v\) if and only if \(r(u)>r(v)\).

Under the task’s attack definition, the attacks are therefore exactly:

  • \(x_i^+\to x_i^-\) and \(x_i^-\to x_i^+\);
  • \(\ell(\lambda)\to c_j\) whenever \(\lambda\) occurs in \(D_j\);
  • \(c_j\to a\).

In particular, clauses do not attack literals, and \(a\) does not attack clauses.

Satisfiability implies acceptance

Suppose \(v\) satisfies \(\varphi\). Let \(M_v\) contain exactly the literal argument made true by \(v\) for each variable, and put \(E=M_v\cup\{a\}\).

This set is conflict-free: it contains no complementary literal pair and no clause argument.

Every omitted literal argument is attacked by its selected complement. Every clause argument \(c_j\) is attacked by a selected literal because \(v\) satisfies \(D_j\). These are all arguments outside \(E\). Thus \(E\) is stable and contains \(a\).

Acceptance implies satisfiability

Conversely, suppose \(E\) is stable and contains \(a\).

Since every \(c_j\) attacks \(a\), conflict-freeness excludes all clause arguments from \(E\). Complementary literals attack each other, so \(E\) contains at most one of \(x_i^+,x_i^-\).

It also contains at least one. If both were omitted, stability would require an argument of \(E\) attacking \(x_i^+\). Its only attacker is \(x_i^-\), which was also omitted. This is impossible.

Hence \(E\) selects exactly one literal per variable, defining an assignment \(v\). Each omitted \(c_j\) must be attacked by \(E\). Its attackers are precisely the literal arguments occurring in \(D_j\), so \(D_j\) has a selected, true literal. Therefore \(v\) satisfies every clause.

We have proved
\(\varphi\text{ is satisfiable}\ \Longleftrightarrow\ \exists E\text{ stable with }a\in E\).

Encoding as a society

Use this PBAT as the sole supported type, with \(\mu_1=1\) and \(\theta=\tfrac12\). The queried mass is either \(0\) or \(1\), so the threshold inequality holds exactly when \(\varphi\) is satisfiable.

Here \(m=2n+q+1\). Both relations can be explicitly encoded with \(O(m^2\log(m+2))\) bits and constructed in polynomial time. The singleton support satisfies the distinctness requirement, and its positive mass sums to \(1\). This proves \(\mathrm{NP}\)-hardness under polynomial-time many-one reductions.

4. Running time and the extension-finding distinction

A deterministic exhaustive algorithm enumerates all subsets containing \(a\) separately for each supported type, checks stability, and then sums the accepting masses. Its running time is
\(O\!\left(L+\tau\,2^m m^2+(\tau+1)L^2\right)\)
under the same computational conventions. It processes only the \(\tau\) explicitly listed types.

Finding an arbitrary stable extension does not resolve the queried acceptance condition. In this reduction, every assignment \(v\) yields a stable extension: select its true literal arguments, include exactly the clause arguments for clauses it leaves unsatisfied, and include \(a\) exactly when no clause is unsatisfied. Conflict-freeness follows from these choices; omitted literals are attacked by their complements, omitted clauses by true literals, and an omitted \(a\) by an included unsatisfied clause. This extension contains \(a\) precisely when \(v\) satisfies \(\varphi\).

This explains why the classification is compatible with the distinction between extension finding and credulous acceptance emphasized in the [cited paper, Section 5](https://helios2.mi.parisdescartes.fr/~moraitis/webpapers/Moraitis-ECAI08.pdf).
