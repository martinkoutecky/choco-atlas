The continuous mirror question, as graded

Given \(\tau\) types with rational masses \(\mu_h\) summing to \(1\), per-household demands \(d_h\), piecewise-constant utilities \(v_{hj}\) for full connection over each of \(p\) intervals, and per-capita supply \(s\), choose connection shares \(\lambda_{hj}\in[0,1]\) to maximize \(r\), subject to \(\sum_h \mu_h d_h\lambda_{hj}\le s\) for each interval \(j\) and \(\sum_j v_{hj}\lambda_{hj}\ge r\) for each type \(h\). Return individual on/off schedules realizing these shares.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: the list of the \(\tau\) types with positive binary-rational masses \(\mu_h\), with \(\sum_h\mu_h=1\); \(\tau\) is the support size, not the number of possible types. Type \(h\) consists of households indexed by \(x\in[0,1)\), with mass measure \(\mu_h\,dx\).
Time is \([0,1]\), partitioned into \(p\ge1\) positive-length intervals \(I_j\) with rational endpoints; set \(m:=p\). Each type has constant rational demand \(d_h>0\) and rational utility \(v_{hj}\ge0\) for full connection throughout \(I_j\), with constant utility density within that interval. Utilities are additive, without normalization. Supply is a constant rational \(s>0\), with \(s<\sum_h\mu_hd_h\); there are no transmission constraints.
Choose \(\lambda_{hj}\in[0,1]\) and maximize \(r\ge0\), subject to \(\sum_h\mu_hd_h\lambda_{hj}\le s\) for every \(j\) and \(\sum_jv_{hj}\lambda_{hj}\ge r\) for every \(h\).
Also return deterministic on/off schedules \(a_h(x,t)\in\{0,1\}\), described by finite Boolean combinations of rational linear inequalities in \((x,t)\), such that \(\int_{I_j}a_h(x,t)\,dt=\lambda_{hj}|I_j|\) for almost every \(x\), and \(\sum_h\mu_hd_h\int_0^1a_h(x,t)\,dx\le s\) at every \(t\). Connection supplies the household's full demand; disconnection supplies nothing. There is no prescribed bound on the number of switches.

Is this exact optimization problem, including realization by individual schedules, polynomial-time solvable in \(m,\tau,L\), or is it NP-hard, where \(L\) is the total binary input length?

For finite households, [Baghel–Levit–Segal-Halevi](https://arxiv.org/html/2205.14531v1) report PPA-hardness and instances requiring \(n-1\) cuts; the cited consensus-halving hardness concerns bounded-cut solutions.
[Hartman–Baghel–Segal-Halevi](https://arxiv.org/html/2506.02193v1#S3) prove NP-hardness of deciding whether every finite household can be connected for at least \(1/2\) of the time, even with uniform utilities and no transmission constraints.

Result

The exact optimization problem, including deterministic individual schedules, is polynomial-time solvable in \(m,\tau,L\).

The key fact is that every rational feasible fractional allocation admits a realization using only two rational linear bands per type and time interval. Thus realization introduces neither an integrality gap nor an exponential output requirement.

1. Exact fractional optimization

Write the interval endpoints as \(0=b_0<b_1<\cdots<b_m=1\), and let \(\ell_j=b_j-b_{j-1}>0\). Endpoint membership in the given intervals does not affect their integrals.

Set \(w_h=\mu_hd_h\). The fractional problem is the rational linear program

\(\displaystyle \max r\)

subject to

\(\displaystyle \sum_{h=1}^{\tau}w_h\lambda_{hj}\le s\qquad(j=1,\ldots,m),\)

\(\displaystyle \sum_{j=1}^{m}v_{hj}\lambda_{hj}\ge r\qquad(h=1,\ldots,\tau),\)

and \(0\le\lambda_{hj}\le1\), \(r\ge0\).

It has \(m\tau+1\) variables and \(m+\tau+2m\tau+1\) inequalities. Its encoding length is polynomial in \(m,\tau,L\): forming each coefficient \(w_h\) requires only multiplication of two input rationals.

The feasible set is nonempty because \(\lambda_{hj}=r=0\) is feasible. It is bounded because the allocation variables belong to \([0,1]\), and, for every type \(h\),

\(\displaystyle 0\le r\le\sum_{j=1}^{m}v_{hj}\lambda_{hj}\le\sum_{j=1}^{m}v_{hj}.\)

It is also closed, so the maximum is attained.

We use the standard exact rational linear-programming theorem: a linear program with binary-encoded rational coefficients can be solved in time polynomial in its encoding length, returning an exact rational optimum and an optimal rational solution whenever its optimum is finite and attained. All these hypotheses have just been verified.

Consequently, we can compute rational values \(\lambda^*_{hj}\) and \(r^*\) exactly in polynomial time. Their binary encoding lengths are polynomial as well. The remaining issue is to realize them by schedules of polynomial description length.

2. A cyclic realization lemma

For \(\alpha\in[0,1]\), define the periodic indicator \(g_\alpha:\mathbb R\to\{0,1\}\) by

\(\displaystyle g_\alpha(z)=1\quad\Longleftrightarrow\quad z\in\bigcup_{k\in\mathbb Z}[k,k+\alpha).\)

For every real \(c\),

\(\displaystyle \int_c^{c+1}g_\alpha(z)\,dz=\alpha.\)

Here is an explicit verification. Write \(c=N+\theta\), where \(N\in\mathbb Z\) and \(0\le\theta<1\). Periodicity and a change of variable give

\(\displaystyle \int_c^{c+1}g_\alpha(z)\,dz =\int_\theta^1g_\alpha(z)\,dz+\int_1^{1+\theta}g_\alpha(z)\,dz =\int_\theta^1g_\alpha(z)\,dz+\int_0^\theta g_\alpha(z)\,dz =\int_0^1g_\alpha(z)\,dz =\alpha.\)

This also covers \(\alpha=0\) and \(\alpha=1\).

Now consider the schedule \(g_\alpha(x+u)\) on household coordinates \(x\in[0,1)\) and normalized times \(u\in[0,1]\). The identity implies both

\(\displaystyle \int_0^1g_\alpha(x+u)\,du=\alpha\qquad\text{for every }x\in[0,1),\)

and

\(\displaystyle \int_0^1g_\alpha(x+u)\,dx=\alpha\qquad\text{for every }u\in[0,1].\)

Thus every household receives the same connection duration, while the connected fraction of the population is constant over time.

3. Explicit Boolean descriptions

The following construction works for any rational feasible allocation \(\lambda\), so apply it in particular to \(\lambda^*\).

For type \(h\), declare \(a_h(x,t)=1\) precisely when at least one of the following \(2m\) clauses holds, indexed by \(j\in\{1,\ldots,m\}\) and \(k\in\{0,1\}\):

\(\displaystyle b_{j-1}<t<b_j \quad\text{and}\quad k\ell_j\le \ell_jx+t-b_{j-1}<(k+\lambda_{hj})\ell_j.\)

Otherwise declare \(a_h(x,t)=0\).

This is an explicit finite disjunction of conjunctions of rational linear inequalities in \((x,t)\). The indices merely specify the clauses to output; they introduce no additional variables.

At every partition endpoint \(b_j\), all households are disconnected. Within the interior of interval \(j\), put

\(\displaystyle u=\frac{t-b_{j-1}}{\ell_j}\in(0,1).\)

The band inequalities become \(k\le x+u<k+\lambda_{hj}\). Since \(0<x+u<2\), only \(k=0,1\) can contribute to the definition of \(g_{\lambda_{hj}}\). Therefore

\(\displaystyle a_h(x,t)=g_{\lambda_{hj}}\!\left(x+\frac{t-b_{j-1}}{\ell_j}\right)\)

throughout that interval’s interior.

4. Verification of the schedules

Individual durations and utilities

For every \(h,j\) and every \(x\in[0,1)\), changing variables from \(t\) to \(u\) and using the lemma gives

\(\displaystyle \int_{I_j}a_h(x,t)\,dt =\ell_j\int_0^1g_{\lambda_{hj}}(x+u)\,du =\ell_j\lambda_{hj}.\)

Disconnecting at finitely many endpoints does not change this integral. The required duration identity therefore holds for every household coordinate, which is stronger than the requested almost-everywhere condition.

The utility density of type \(h\) on interval \(j\) is \(v_{hj}/\ell_j\). Hence every household of that type receives total utility

\(\displaystyle \sum_{j=1}^{m}\frac{v_{hj}}{\ell_j}\int_{I_j}a_h(x,t)\,dt =\sum_{j=1}^{m}v_{hj}\lambda_{hj}\ge r.\)

Supply at every time

If \(t\) is in the interior of interval \(j\), the other identity in the lemma gives

\(\displaystyle \int_0^1a_h(x,t)\,dx=\lambda_{hj}.\)

Accordingly, instantaneous demand is

\(\displaystyle \sum_{h=1}^{\tau}\mu_hd_h\int_0^1a_h(x,t)\,dx =\sum_{h=1}^{\tau}w_h\lambda_{hj}\le s.\)

At a partition endpoint it is zero. Supply feasibility thus holds at every time, including endpoints.

The schedules take values only in \(\{0,1\}\), so each connected household receives its full demand.

5. Optimality and polynomial output size

For completeness, the fractional capacity inequalities are also necessary for any realization satisfying the requested duration identities. The schedule descriptions are measurable. By Fubini’s theorem, the duration identities and pointwise supply feasibility imply

\(\displaystyle \ell_j\sum_{h=1}^{\tau}w_h\lambda_{hj} =\int_{I_j}\sum_{h=1}^{\tau}w_h\int_0^1a_h(x,t)\,dx\,dt \le s\ell_j.\)

Dividing by \(\ell_j>0\) gives the fractional capacity constraint. Individual utilities are exactly the corresponding utility sums, as calculated above.

Therefore the linear program describes precisely the realizable allocations under the task’s requirements. In particular, realizing its optimizer attains \(r^*\), and no feasible answer can attain a larger value.

The complete schedule output contains \(2m\tau\) clauses, each with a constant number of linear inequalities. Their coefficients use only the input endpoints, their differences \(\ell_j\), and products involving \(\lambda^*_{hj}\). All these rationals have polynomial binary encoding length. Generating the entire output consequently takes polynomial time and produces polynomially many bits.

6. Why the finite-household hardness does not transfer

The finite-household reduction in [Hartman–Baghel–Segal-Halevi, Theorem 3.1](https://arxiv.org/html/2506.02193v1#S3) relies on instantaneous configurations being subsets of indivisible households. At the critical threshold, feasible configurations must encode an exact partition of their demands.

Here, each type is a nonatomic population. The construction connects exactly a fraction \(\lambda_{hj}\) of that population at each interior time while rotating which households are connected. Instantaneous feasibility therefore requires only the weighted fractional capacity inequality.

Likewise, the consensus-halving results discussed by [Baghel–Levit–Segal-Halevi, Section 4.4](https://arxiv.org/html/2205.14531v1#S4.SS4) involve bounds on time cuts. This task permits household-dependent switching times described by linear bands in \((x,t)\), with no prescribed cut bound.

The complete algorithm is thus: solve the rational linear program exactly, then output the band formulas above.
