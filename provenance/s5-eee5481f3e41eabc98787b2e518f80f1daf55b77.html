Result

No such finite protocol exists. Equal masses and an integral target number of types allow every feasible mass-splitting allocation to be rounded to an allocation of whole types. This gives a reduction from the stated indivisible-player impossibility theorem.

The reduction preserves termination on every input and does not require a uniform query bound. It also works if supported types must have pairwise distinct preference functions.

1. Feasibility and rounding at a fixed cut

Write \(\tau=2k\), where \(k\ge2\). At a cut \(y\), partition the supported types into:

  • \(A\): types preferring only left;
  • \(B\): types preferring both pieces;
  • \(C\): types preferring only right.

Let \(a=|A|\), \(b=|B|\), and \(c=|C|\), so \(a+b+c=2k\).

In a feasible allocation, each type in \(A\) must have \(z_t=1/\tau\): otherwise positive mass would receive its unpreferred right piece. Similarly, each type in \(C\) must have \(z_t=0\). Types in \(B\) may receive any left mass between \(0\) and \(1/\tau\). Consequently,

\(\displaystyle \frac{a}{\tau}\le\sum_t z_t=\frac12\le\frac{a+b}{\tau}.\)

Multiplying by \(\tau=2k\) gives

\(\displaystyle a\le k\le a+b.\)

Conversely, these inequalities suffice: assign all types in \(A\) and any \(k-a\) types in \(B\) wholly to left, and all remaining types wholly to right. Both groups then contain exactly \(k\) types, and every type prefers its assigned piece.

Thus we have proved:

Rounding lemma. At any fixed cut, a feasible mass-splitting allocation exists if and only if an allocation of whole types into two groups of \(k\) types exists. Given a feasible cut, the whole-type allocation can be constructed using \(\tau\) Evaluate queries.

The construction does not inspect or perform arithmetic on the protocol’s reported fractions \(z_t\).

2. Allocations nevertheless always exist

This distinguishes the computational obstruction from nonexistence of an allocation.

For each type \(t\), its strict-left region is open: it is the complement in \([0,1]\) of the closed set where right is preferred. Its strict-right region is open for the same reason.

Define

\(\displaystyle U_L=\{x:\text{more than }k\text{ types prefer only left at }x\},\)

\(\displaystyle U_R=\{x:\text{more than }k\text{ types prefer only right at }x\}.\)

These sets are open. For example, \(U_L\) is the finite union, over all subsets of \(k+1\) types, of the intersections of their strict-left regions.

They are disjoint: membership in both would require more than \(2k=\tau\) types, since a type cannot strictly prefer both pieces. Hunger gives \(0\in U_R\) and \(1\in U_L\).

If every cut were infeasible, the rounding lemma would imply that every cut belongs to \(U_L\cup U_R\). This would separate the connected interval \([0,1]\) into two disjoint, nonempty open sets, a contradiction.

Hence a feasible allocation always exists.

3. Ensuring that all supported types are distinct

If types are simply labelled oracle objects, the rounding lemma already gives the required reduction. To cover the stricter interpretation that different supported types must have different preference functions, we give an explicit transformation.

Start with an arbitrary indivisible-player instance with \(\tau=2k\) players and prescribed group sizes \(k,k\). Denote their preferences by \(P_t\).

Set \(a_0=1/3\), \(b_0=2/3\), and

\(\displaystyle \alpha_t=\frac{3t-2}{12\tau},\qquad \beta_t=\frac{3t-1}{12\tau}\quad(1\le t\le\tau).\)

The intervals \([\alpha_t,\beta_t]\) are pairwise disjoint and lie strictly between \(0\) and \(1/4\).

Define transformed preferences \(\widehat P_t\) as follows:

  • For \(x<a_0\), type \(t\) prefers only left on \((\alpha_t,\beta_t)\), both pieces at \(\alpha_t,\beta_t\), and only right elsewhere.
  • For \(a_0\le x\le b_0\), set \(\widehat P_t(x)=P_t(3x-1)\).
  • For \(x>b_0\), type \(t\) prefers only left.

Assign each transformed type mass \(1/\tau\).

Admissibility. The original preferences at \(0\) and \(1\) are respectively right-only and left-only, so the definitions agree at the junctions \(a_0,b_0\). Each transformed preferred-piece set is a finite union of closed intervals and affine images of original closed preferred-piece sets; hence it is closed. The preferences are nonempty everywhere and satisfy hunger.

Distinctness. At any point inside \((\alpha_t,\beta_t)\), type \(t\) prefers only left, whereas every other type prefers only right. Thus all \(\tau\) transformed preference functions are distinct, and the support contains exactly \(\tau\) types.

Location of feasible cuts. At any \(x<a_0\), at most one type can receive positive left mass. The maximum permissible left mass is therefore at most \(1/\tau<1/2\). At \(a_0\), all types prefer only right. At every \(x\ge b_0\), all types prefer only left, forcing total left mass \(1\). Consequently, every feasible transformed cut lies in \((a_0,b_0)\).

A feasible transformed cut \(y\) therefore maps to an original cut \(u=3y-1\), with exactly the same preference sets. The rounding lemma then produces the required indivisible-player assignment at \(u\).

4. Exact simulation of the three query types

Let \(D_t\) be the original indifference set. The transformed indifference set is exactly

\(\displaystyle \widehat D_t=\{\alpha_t,\beta_t\}\cup\left\{\frac{1+u}{3}:u\in D_t\right\}.\)

This gives finite, exact oracle simulations.

Evaluate. Outside \([a_0,b_0]\), answer from the fixed excursion construction. Inside that interval, make one original Evaluate query at \(3x-1\).

Next-indifference-point. Consider the decoration points \(\alpha_t,\beta_t\) that are at least \(x\). If \(x\le b_0\), also make an original Next query at \(\max\{0,3x-1\}\), and transform its answer by \(u\mapsto(1+u)/3\). Return the least available candidate, or absence if there is none. If \(x>b_0\), no original indifference point can contribute.

Previous-indifference-point. Consider the decoration points that are at most \(x\). If \(x\ge a_0\), also make an original Previous query at \(\min\{1,3x-1\}\), and transform its answer. Return the greatest available candidate, or absence. If \(x<a_0\), no original indifference point can contribute.

Each transformed query requires at most one original query and finitely many exact arithmetic operations and comparisons. These simulations work for arbitrary real query coordinates.

5. Contradiction and resource accounting

Suppose a mass-splitting protocol satisfying the task’s termination requirement existed.

Given any indivisible-player instance with \(\tau=2k\) players:

  • Construct the transformed support and oracle wrappers above.
  • Run the purported mass-splitting protocol.
  • Map its feasible cut back to the original interval.
  • Make \(\tau\) original Evaluate queries and apply the rounding lemma.

The transformed instance is admissible and has exactly \(\tau\) distinct supported types. Therefore the assumed protocol terminates on it. Every simulated step is finite, and the final rounding procedure is finite. The resulting indivisible-player protocol thus terminates on every admissible original input, without assuming any uniform bound.

The supplied impossibility theorem applies: there are \(m=2\) pieces, both prescribed groups have size \(k\ge2\), preferences are hungry and closed, and the protocol uses only the three permitted query types. It rules out precisely such a finite protocol. [Segal-Halevi and Suksompong, Theorem 3](https://arxiv.org/pdf/2301.09061).

For resource accounting, if the hypothetical protocol used \(Q(2,\tau,L)\) queries on a transformed support of bit length \(L\), the reduction would use at most \(Q(2,\tau,L)+\tau\) original queries. The auxiliary rational coordinates have \(O(\log\tau)\) bits each, so their total description has \(O(\tau\log\tau)\) bits. These are conditional bounds for the reduction; the contradiction rules out even a protocol whose query count is finite on each input but has no uniform bound in \(m,\tau,L\).
