The continuous mirror question, as graded

Given a finite set \(T\subseteq V_3\) of complete canonical cardinal valuation types, compute or approximate \(\rho_{J^\star}(T)=\inf_{\mu\in\Delta(T)}\frac{\sum_{t\in T}\mu_t\sum_{c\in C}p^{J^\star}_c(\mu)u_t(c)}{\max_{c\in C}\sum_{t\in T}\mu_tu_t(c)}\), where \(J^\star=c_1U^1+c_2U^2\) and \(p^{J^\star}_c(\mu)=c_1\sum_{t:c\in\operatorname{Top}_1(t)}\mu_t+\frac{c_2}{2}\sum_{t:c\in\operatorname{Top}_2(t)}\mu_t\); return a certified worst-case mass vector and ratio bound.

Result

The certified additive approximation is polynomial-time solvable for the stated case \(m=3\). The algorithm returns a rational society supported on at most \(\min\{s,12\}\) catalogue types, together with a rational lower bound satisfying the requested inequalities.

The proof has two ingredients: an exact reduction to twelve types, and an exact threshold algorithm for quadratic optimization in constant dimension.

1. Basic bounds and attainment

For a type \(t\), define its election-probability vector by

\(v_t(c)=c_1\mathbf 1_{\{c\in\operatorname{Top}_1(t)\}}+\frac{c_2}{2}\mathbf 1_{\{c\in\operatorname{Top}_2(t)\}}.\)

Since \(c_1+c_2=1\), every \(v_t\) is a probability vector. Consequently, so is \(p(\mu)=\sum_t\mu_tv_t\).

Write \(W(\mu)=\max_c w_c(\mu)\) and \(N(\mu)=\sum_c p_c(\mu)w_c(\mu)\). Normalization of each valuation gives

\(\sum_c w_c(\mu)=\sum_t\mu_t\sum_c u_t(c)\geq 1,\)

and therefore \(W(\mu)\geq 1/3\). Moreover, \(0\leq N(\mu)\leq W(\mu)\), because \(p(\mu)\) is a probability vector. Thus

\(0\leq R(\mu)\leq 1.\)

The denominator is bounded away from zero, so \(R\) is continuous on the compact simplex \(\Delta(T)\). In particular, the defining infimum is attained:

\(\rho(T)=\min_{\mu\in\Delta(T)}R(\mu).\)

2. Exact reduction to at most twelve catalogue types

There are six strict rankings of three candidates. Fix one such ranking, written \(a\succ b\succ d\). Every type having this ranking has utilities

\(u_t(a)=1,\qquad u_t(b)=x_t,\qquad u_t(d)=0,\qquad 0<x_t<1.\)

Its election-probability vector depends only on the ranking:

\(v_t(a)=c_1+c_2/2,\qquad v_t(b)=c_2/2,\qquad v_t(d)=0.\)

For each nonempty ranking class, retain types attaining its smallest and largest middle utilities. If these coincide, retain just one type. Let \(T'\subseteq T\) be the retained catalogue. Then \(|T'|\leq\min\{s,12\}\).

To prove that this reduction is exact, consider a ranking class whose extrema are \(x_-\lt x_+\). For any type in that class, set

\(\lambda_t=\frac{x_+-x_t}{x_+-x_-}.\)

Then \(0\leq\lambda_t\leq1\), and

\(u_t=\lambda_tu_-+(1-\lambda_t)u_+,\qquad v_t=\lambda_tv_-+(1-\lambda_t)v_+.\)

The first identity follows coordinatewise from the utilities above. The second follows because all three probability vectors are identical.

Replacing mass \(\mu_t\) by masses \(\mu_t\lambda_t\) and \(\mu_t(1-\lambda_t)\) on the two retained types therefore preserves both \(w(\mu)\) and \(p(\mu)\). Applying this replacement to every omitted type preserves \(R(\mu)\). A singleton ranking class requires no replacement.

Conversely, every society on \(T'\) is admissible on \(T\). Hence

\(\rho(T')=\rho(T).\)

All retained types are actual members of the input catalogue, with their original strict valuations.

3. Exact quadratic minimization on a constant-dimensional simplex

We need the following elementary algorithmic lemma.

Lemma. Fix a positive integer \(n\). Given rational coefficients of a quadratic polynomial

\(f(x)=x^{\mathsf T}Hx+h^{\mathsf T}x+\gamma,\qquad H=H^{\mathsf T},\)

one can compute its exact minimum on

\(\Delta_n=\{x\in\mathbb R^n:x_i\geq0,\ \sum_i x_i=1\}\)

and a rational minimizer in time polynomial in the coefficient bit length. No definiteness assumption on \(H\) is required.

Proof. Enumerate every nonempty subset \(S\subseteq\{1,\ldots,n\}\). On the corresponding face, set coordinates outside \(S\) to zero and write the remaining coordinates as \(y\).

Choose \(j\in S\). Consider the rational linear system

\(\sum_{\ell\in S}y_\ell=1,\)

\(2\sum_{\ell\in S}(H_{i\ell}-H_{j\ell})y_\ell+h_i-h_j=0\qquad(i\in S\setminus\{j\}),\)

together with \(y_\ell\geq0\). Its equations say precisely that all gradient coordinates indexed by \(S\) are equal.

If this system is feasible, obtain one rational feasible point and evaluate \(f\) there. Return the smallest value among all points obtained.

We first justify the feasible-point computation. The solution set is a bounded rational polyhedron, being contained in a simplex. Every nonempty bounded polyhedron has a vertex: successively minimizing its coordinates produces nested nonempty compact faces, ending in a singleton.

At a vertex, the equality rows together with the active inequalities span the whole coordinate space. Otherwise, a nonzero direction annihilating all these rows would permit sufficiently small perturbations in both directions, contradicting extremality. Here the active inequalities are coordinate equations \(y_\ell=0\). Thus enumerating subsets of coordinates to set to zero, solving the resulting full-rank systems, and checking all equations and inequalities finds a rational feasible point whenever one exists.

Next, all solutions of the stationarity equations on a given face have the same objective value. Indeed, let \(y,z\) be two such solutions and put \(d=z-y\). Their coordinate sums agree, so \(\mathbf 1^{\mathsf T}d=0\). Their gradients are constant across \(S\), giving

\(d^{\mathsf T}\nabla f(y)=0,\qquad d^{\mathsf T}(\nabla f(z)-\nabla f(y))=0.\)

Since the gradient difference is \(2H_{SS}d\), we obtain \(d^{\mathsf T}H_{SS}d=0\). The quadratic expansion therefore gives

\(f(z)-f(y)=d^{\mathsf T}\nabla f(y)+d^{\mathsf T}H_{SS}d=0.\)

Finally, let \(x^\star\) be a global minimizer and let \(S\) be its positive support. It lies in the relative interior of that simplex face. For each \(i,j\in S\), sufficiently small perturbations along \(e_i-e_j\) are feasible in both directions. Differentiating at the minimum shows that the corresponding gradient coordinates agree. Thus \(x^\star\) satisfies the stationarity system for \(S\).

The rational point selected for this system has the same objective value as \(x^\star\). Every other selected point is feasible, so the smallest selected value is exactly the global minimum.

For fixed \(n\), both subset enumerations have constant size. All systems have constant dimension. Exact Gaussian elimination and rational comparisons have polynomial bit complexity; determinant formulas also show that the produced rational points have polynomial bit length. This proves the lemma. \(\square\)

4. An exact threshold test for \(\rho(T)\)

Index the reduced catalogue by \(1,\ldots,n\), where \(n\leq12\), and let \(x\in\Delta_n\) denote its masses.

Define rational matrices \(U,V\), with three rows and \(n\) columns, by

\(U_{ci}=u_i(c),\qquad V_{ci}=v_i(c).\)

Then

\(w(x)=Ux,\qquad p(x)=Vx,\qquad N(x)=x^{\mathsf T}Hx,\)

where

\(H=\frac12(V^{\mathsf T}U+U^{\mathsf T}V).\)

For a rational threshold \(r\in[0,1]\), define three quadratic polynomials

\(q_{c,r}(x)=N(x)-r\,w_c(x).\)

Because \(r\geq0\),

\(N(x)-r\max_cw_c(x)=\min_c q_{c,r}(x).\)

Since \(W(x)>0\), it follows that

\(\rho(T)\leq r\quad\Longleftrightarrow\quad \min_{c\in C}\min_{x\in\Delta_n}q_{c,r}(x)\leq0.\)

Apply the lemma to each of these three rational quadratic polynomials. This decides the threshold question exactly in polynomial time.

Moreover, whenever the answer is affirmative, the algorithm supplies a rational \(x\) and a candidate \(c\) satisfying \(q_{c,r}(x)\leq0\). Consequently,

\(N(x)\leq r\,w_c(x)\leq r\,W(x),\)

so \(R(x)\leq r\). The threshold test therefore returns a rational society witnessing its affirmative answer.

5. Bisection and the requested certificate

Initialize rational endpoints \(\ell=0\) and \(u=1\). Choose any pure society as the current witness \(\widehat\mu\). The bounds established above give

\(\ell\leq\rho(T)\leq R(\widehat\mu)\leq u.\)

At each iteration, test \(r=(\ell+u)/2\).

  • If \(\rho(T)\leq r\), set \(u=r\) and replace \(\widehat\mu\) by the rational witness returned by the threshold test.
  • Otherwise, set \(\ell=r\).

Both updates preserve

\(\ell\leq\rho(T)\leq R(\widehat\mu)\leq u.\)

After \(K=\lceil\log_2(1/\varepsilon)\rceil\) iterations, the interval length satisfies \(u-\ell=2^{-K}\leq\varepsilon\). Output \(b=\ell\) and the stored society. Then

\(b\leq\rho(T)\leq R(\widehat\mu)\leq u\leq b+\varepsilon,\)

exactly as required.

Grouping the catalogue and finding its extrema takes polynomial time in \(s\) and \(L\). Each threshold computation has dimension at most twelve and coefficient bit length polynomial in \(L+K\). There are \(K\) threshold computations. The total running time and output bit length are therefore polynomial in \(s,L,\log(1/\varepsilon)\), with output support size \(\tau\leq\min\{s,12\}\).

This settles the stated fixed-\(m=3\) problem. The supplied discrete-society welfare guarantee is established separately by Theorem 7 of [Filos-Ratsikas and Miltersen](https://arisfilosratsikas.com/papers/range_voting.pdf).
