The continuous mirror question, as graded

Given a fixed model set \(C\), target \(p\), and task types \(T\) with strict rankings \(\pi_t\), rational masses \(\mu_t\) summing to \(1\), per-unit training costs \(\gamma_t\), and budget \(\beta\), is there a choice of trained mass \(x_t\in[0,\mu_t]\) with \(\sum_t\gamma_t x_t\le\beta\) such that \(p\) is a Borda winner? For each type, training its chosen mass replaces \(\pi_t\) by \(\pi_t^p\), the ranking with \(p\) moved to the top while preserving the other models’ order; the resulting score is \(S_c(x)=\sum_t((\mu_t-x_t)b_{\pi_t}(c)+x_t b_{\pi_t^p}(c))\), and the condition is \(S_p(x)\ge S_c(x)\) for every \(c\in C\).

Packaged proof task (what the prover saw — nothing else)

Let \(C\) be an input set of \(m\ge 1\) models and \(p\in C\) the target; \(C\) stays unchanged during training, but \(m\) is not a fixed constant.
A society is given by its support: a list \(T\) of \(\tau\ge 1\) types, each with a strict ranking \(\pi_t\) of \(C\) and positive binary-rational mass \(\mu_t\), with \(\sum_{t\in T}\mu_t=1\). Here \(\tau\) is the support size, not the number of possible rankings; types may differ in cost despite sharing a ranking.
Each type has a positive binary-rational per-unit training cost \(\gamma_t\); the budget \(\beta\) is a nonnegative binary rational. Let \(L\) be the total input bit length.
Training any real mass \(x_t\in[0,\mu_t]\) replaces that mass's ranking by \(\pi_t^p\), obtained by moving \(p\) to the top and preserving all other models' relative order. The remaining mass keeps \(\pi_t\).
Write \(b_\pi(c)\) for standard Borda points and define \(S_c(x)=\sum_{t\in T}((\mu_t-x_t)b_{\pi_t}(c)+x_t b_{\pi_t^p}(c))\). Feasibility requires \(\sum_{t\in T}\gamma_t x_t\le\beta\) and \(S_p(x)\ge S_c(x)\) for every \(c\in C\); ties for the highest aggregate score count as winning.

Is deciding whether such a feasible training allocation exists in \(\mathrm{P}\), with running time polynomial in \(m,\tau,L\), or is it \(\mathrm{NP}\)-hard?

The discrete problem of selecting whole tasks at fixed positive training costs to make the target a Borda winner is \(\mathrm{NP}\)-hard, equivalently all-or-nothing Borda shift bribery. This discrete result does not establish the complexity of the divisible-mass problem.

Modeling choices made when packaging the task

  • Interpreted the fixed model set as an input set that remains unchanged by training, rather than a constant-size set across instances.
  • Required positive binary-rational per-unit costs, following the discrete definition's strictly positive task costs.
  • Allowed a nonnegative binary-rational budget to accommodate normalized masses and per-unit costs, including the zero-training case.
  • Specified real-valued trained masses because the question concerns divisible mass.
  • Allowed types with identical rankings but different costs, since discrete tasks can share rankings while having different training costs.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Result

The divisible-mass problem is in \(\mathrm{P}\). It is exactly the feasibility problem for a rational linear program with \(\tau\) variables, \(2\tau+m\) inequalities, and encoding length polynomial in \(m,\tau,L\).

1. Effect of training on score differences

Use standard Borda scores \(m-1,m-2,\ldots,0\). Let \(r_t\in\{1,\ldots,m\}\) be the position of \(p\) in \(\pi_t\). For each \(c\ne p\), define

\(a_{tc}=1\) if \(c\) occurs above \(p\) in \(\pi_t\), and \(a_{tc}=0\) otherwise.

Moving \(p\) to the top increases its Borda score by \(r_t-1\). Every model originally above \(p\) moves down one position and loses one point; every model originally below \(p\) retains its position. Consequently,

\(b_{\pi_t^p}(p)-b_{\pi_t}(p)=r_t-1,\qquad b_{\pi_t^p}(c)-b_{\pi_t}(c)=-a_{tc}.\)

Define the initial score deficit against \(c\) by

\(D_c=S_c(0)-S_p(0)=\sum_{t\in T}\mu_t\bigl(b_{\pi_t}(c)-b_{\pi_t}(p)\bigr).\)

By the definition of aggregate scores, training mass \(x_t\) changes the difference between \(p\)'s score and \(c\)'s score by \((r_t-1+a_{tc})x_t\). Thus

\(S_p(x)-S_c(x)=-D_c+\sum_{t\in T}(r_t-1+a_{tc})x_t.\)

This identity holds for every allowed real allocation \(x\), including allocations that train only part of a type.

2. An equivalent linear program

Consider the following system in the real variables \((x_t)_{t\in T}\):

\(0\le x_t\le\mu_t\qquad(t\in T),\)

\(\sum_{t\in T}\gamma_t x_t\le\beta,\)

\(\sum_{t\in T}(r_t-1+a_{tc})x_t\ge D_c\qquad(c\in C\setminus\{p\}).\)

The first constraints impose the available-mass bounds, and the second imposes the budget. By the score-difference identity, each remaining constraint is equivalent to \(S_p(x)\ge S_c(x)\). Weak inequalities correctly allow ties.

Therefore this system is feasible if and only if the requested training allocation exists. It has \(\tau\) variables and \(2\tau+1+(m-1)=2\tau+m\) inequalities. All its coefficients are rational.

For \(m=1\), there are no competitor constraints, and \(x_t=0\) is feasible. The same formulation handles every \(m\ge2\).

3. Polynomial encoding length

It remains to verify that constructing the linear program does not produce coefficients of excessive bit length.

The coefficients \(r_t-1+a_{tc}\) are integers between \(0\) and \(m\), so each requires \(O(\log(m+1))\) bits. The masses, costs, and budget are already supplied as binary rationals.

For the newly computed right-hand sides, write \(\mu_t=u_t/q_t\), with positive integers \(u_t,q_t\), and set \(Q=\prod_{t\in T}q_t\). Then

\(D_c=\dfrac{N_c}{Q},\qquad N_c=\sum_{t\in T}u_t(Q/q_t)\bigl(b_{\pi_t}(c)-b_{\pi_t}(p)\bigr).\)

The bit length of \(Q\) is at most the sum of the denominator bit lengths, hence \(O(L)\). Moreover, every Borda-score difference has absolute value at most \(m-1\). Since the masses are positive and sum to one,

\(|N_c|\le(m-1)\sum_{t\in T}u_t(Q/q_t)=(m-1)Q.\)

Thus each \(D_c\) has a rational representation using \(O(L+\log(m+1))\) bits. These representations can be computed by polynomially many integer arithmetic operations on integers of polynomial bit length.

The ranks and indicators can also be obtained by scanning the supplied rankings. Hence the entire linear program can be constructed in time polynomial in \(m,\tau,L\), and its total binary encoding length is polynomial in those parameters.

4. Applying polynomial-time linear programming

The standard polynomial-time theorem for rational linear programming states that feasibility of a finitely specified rational linear system over the reals can be decided deterministically in time polynomial in its binary encoding length. This is an exact feasibility result; it does not require a positive margin in any inequality.

Its hypotheses hold here: the system has finitely many variables and constraints, all coefficients are rational, and its encoding length is polynomial in \(m,\tau,L\). Applying this theorem therefore decides the training problem within the required polynomial running time.

The discrete hardness result does not transfer: requiring each \(x_t\) to belong to \(\{0,\mu_t\}\) would introduce discrete restrictions, whereas the present problem permits the full interval \([0,\mu_t]\).
