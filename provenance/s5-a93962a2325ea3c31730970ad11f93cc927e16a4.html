Theorem 7 — class: hardness

The continuous mirror question, as graded

Given finite types \(T\), item categories \(J\), rational masses \(\mu_t\), rational per-capita supplies \(b_j\), and valuations \(p_{tj}\in\{0,1,+\infty\}\), where each category \(j\) is valued \(+\infty\) by at most one type, assign each mass to integral bundles \(z\in\mathbb Z_{\ge0}^{J}\) subject to \(\sum_z x_{t,z}=\mu_t\) and \(\sum_{t,z}x_{t,z}z_j\le b_j\), maximizing the minimum utility \(q\); determine its exact or approximation complexity in \(m\), \(|T|\), and the input bit length \(L\), including whether the factor-\(2\) barrier persists.

Packaged proof task (what the prover saw — nothing else)

Let \(T\) be a nonempty support of \(\tau\) types, listed with positive binary rational masses \(\mu_t\) summing to \(1\); \(\tau\) counts supported types, not all possible types. Let \(J\) contain \(m\ge1\) item categories with nonnegative binary rational per-capita supplies \(b_j\). Valuations satisfy \(p_{tj}\in\{0,1,+\infty\}\), and each category has infinite value for at most one type. Let \(L\) be the total input bit length.
A bundle is \(z\in\mathbb Z_{\ge0}^{J}\), allowing multiple units of a category. Its utility is \(u_t(z)=+\infty\) if it contains any unit valued infinitely by \(t\), and otherwise \(u_t(z)=\sum_{j:p_{tj}=1}z_j\).
An allocation consists of finitely supported nonnegative real masses \(x_{t,z}\), with \(\sum_z x_{t,z}=\mu_t\) and \(\sum_{t,z}x_{t,z}z_j\le b_j\). Unused supply is allowed. Its value is \(q(x)=\min\{u_t(z):x_{t,z}>0\}\); maximize this value, denoting the optimum by \(\mathrm{OPT}\in\mathbb Z_{\ge0}\cup\{+\infty\}\).
A factor \(\rho\ge1\) approximation returns a feasible allocation of value at least \(\mathrm{OPT}/\rho\), with \((+\infty)/\rho=+\infty\).

Does this problem admit a factor \(\rho\) approximation for some fixed \(1\le\rho<2\) in time polynomial in \(m,\tau,L\), or is achieving every fixed factor \(1\le\rho<2\) NP-hard?

For finitely many players and individual items under the same valuation restriction, approximation within any factor below \(2\) is NP-hard, even when each item has positive value for at most two players ([Bateni–Charikar–Guruswami](https://www.cs.princeton.edu/techreports/2009/848.pdf)).
No result settling this precise mass allocation approximation question was identified in the literature search.

Modeling choices made when packaging the task

  • Normalized total society mass to 1, matching a distribution over types and per-capita supplies.
  • Specified nonempty type and category sets, positive supported masses, and nonnegative supplies; zero supplies remain allowed.
  • Defined utility additively, with infinity triggered only by a positive number of infinitely valued units.
  • Interpreted the minimum utility over all bundles assigned positive mass, rather than over type-average utilities.
  • Specified finitely supported nonnegative real allocation masses, allowing arbitrary splitting of each type.
  • Retained unrestricted integer category multiplicities from the graded question: categories represent repeatable units, rather than individually named items.
  • Allowed zero and infinite optimum values and specified the approximation convention for infinity.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Exact polynomial-time optimization

The problem admits a polynomial-time exact algorithm, hence a factor \(\rho=1\) approximation. The essential point is that masses may be split, and a bundle may contain multiple units of one category. Together, these make every fixed utility threshold testable by a polynomial-size linear program.

1. Normalizing allocations at a fixed threshold

For each type \(t\), define
\[ \]
\(I_t=\{j\in J:p_{tj}=+\infty\}\) and \(F_t=\{j\in J:p_{tj}=1\}\).

Let \(e_j\in\mathbb Z_{\ge0}^{J}\) denote the bundle containing one unit of category \(j\). Fix an integer \(k\ge1\).

Lemma. If an allocation of value at least \(k\) exists, then one exists using only bundles \(e_j\) with \(j\in I_t\), and bundles \(k e_j\) with \(j\in F_t\), for each type \(t\).

Proof. Consider a supported pair \((t,z)\), of mass \(a=x_{t,z}>0\).

If \(u_t(z)=+\infty\), choose \(j\in I_t\) with \(z_j\ge1\). Replace this mass by mass \(a\) receiving \(e_j\). Its utility remains infinite, and its consumption decreases coordinatewise.

Otherwise, let \(S=\sum_{j\in F_t}z_j=u_t(z)\). Because the allocation has value at least \(k\), we have \(S\ge k>0\). For each \(j\in F_t\), replace the original mass by mass \(a z_j/S\) receiving \(k e_j\).

The replacement masses sum to \(a\), and every replacement bundle has utility \(k\). Its aggregate consumption of category \(j\in F_t\) is

\(\displaystyle \frac{a z_j}{S}\,k\le a z_j.\)

Consumption of every other category is zero. Thus consumption again decreases coordinatewise.

Applying these replacements to all supported pairs preserves every type’s mass and feasibility. The resulting support is finite because the original support and \(J\) are finite. This proves the lemma. \(\square\)

The replacement uses both permissions in the task: splitting masses and assigning repeated units of a category.

2. A polynomial-size exact feasibility test

For fixed \(k\ge1\), introduce a nonnegative variable \(y_{tj}\) for every pair with \(j\in I_t\cup F_t\). Interpret it as the mass receiving \(e_j\) when \(j\in I_t\), or \(k e_j\) when \(j\in F_t\).

Consider the following linear feasibility problem:

  • \(y_{tj}\ge0\) for every indexed pair.
  • \(\displaystyle \sum_{j\in I_t\cup F_t}y_{tj}=\mu_t\) for every \(t\in T\).
  • \(\displaystyle \sum_{t:j\in I_t}y_{tj}+k\sum_{t:j\in F_t}y_{tj}\le b_j\) for every \(j\in J\).

Proposition. This linear program is feasible if and only if an allocation of value at least \(k\) exists.

Proof. A feasible linear-program solution directly specifies an allocation using the indicated bundles. The type equations give the required masses, the category inequalities give feasibility, and every allocated bundle has utility either \(k\) or \(+\infty\).

Conversely, the normalization lemma transforms any allocation of value at least \(k\) into one of this form. Aggregating the masses assigned to each indicated bundle yields a feasible solution \(y\). \(\square\)

There are at most \(m\tau\) variables, \(\tau\) type equations, and \(m\) supply inequalities. All coefficients are rational, and their encoding length is polynomial in \(m,\tau,L,\log(k+1)\).

We use the standard rational linear-programming theorem: feasibility can be decided, and an exact rational feasible point can be produced when one exists, in time polynomial in the system’s binary encoding length. This is the classical polynomial-time solvability result for linear programming; see [Khachiyan, “Polynomial algorithms in linear programming”](https://www.mathnet.ru/eng/zvmmf5239). Here its hypotheses hold: the system is finite and explicitly represented with rational coefficients. Moreover, every variable satisfies \(0\le y_{tj}\le\mu_t\), so its feasible region is bounded.

Consequently, the threshold test also constructs a feasible allocation with at most \(m\tau\) supported type–bundle pairs and polynomial-length rational masses.

3. Detecting infinite optimum

Define \(A_t=\sum_{j\in I_t}b_j\).

Proposition. An allocation of value \(+\infty\) exists if and only if \(A_t\ge\mu_t\) for every \(t\in T\).

Proof. For necessity, every allocated bundle of type \(t\) must contain at least one unit from \(I_t\). Hence

\(\displaystyle \mu_t=\sum_z x_{t,z}\le\sum_z x_{t,z}\sum_{j\in I_t}z_j\le\sum_{j\in I_t}b_j=A_t.\)

For sufficiency, suppose all these inequalities hold. For each type \(t\), choose nonnegative rational masses \(h_{tj}\le b_j\), indexed by \(j\in I_t\), summing to \(\mu_t\). These can be obtained greedily by traversing \(I_t\) and assigning as much remaining mass as each category’s supply permits.

Assign mass \(h_{tj}\) of type \(t\) to bundle \(e_j\). The sets \(I_t\) are pairwise disjoint, because each category has infinite value for at most one type. Therefore these choices do not compete for supply. Every supported bundle has infinite utility. \(\square\)

This test and construction use polynomial-time rational arithmetic.

4. Bounding the finite search range

Suppose the infinite-optimum test fails. Choose \(t_0\) with \(A_{t_0}<\mu_{t_0}\), and define

\(\displaystyle \delta=\mu_{t_0}-A_{t_0}>0,\qquad B=\sum_{j\in J}b_j,\qquad U=\left\lfloor\frac{B}{\delta}\right\rfloor.\)

Proposition. Every achievable positive integer threshold \(k\) satisfies \(k\le U\).

Proof. In any feasible allocation, let \(H\) be the mass of type \(t_0\) receiving infinite utility. Each such bundle contains at least one unit from \(I_{t_0}\), so the same consumption argument as above gives \(H\le A_{t_0}\).

Thus the mass of type \(t_0\) receiving finite utility is at least

\(\mu_{t_0}-H\ge\mu_{t_0}-A_{t_0}=\delta.\)

If the allocation has value at least \(k\), every bundle assigned to this finite-utility mass contains at least \(k\) units: its utility counts only units valued \(1\). Therefore total consumption satisfies

\(\displaystyle B\ge\sum_{t,z}x_{t,z}\sum_{j\in J}z_j\ge k(\mu_{t_0}-H)\ge k\delta.\)

It follows that \(k\le\lfloor B/\delta\rfloor=U\). \(\square\)

Although \(U\) may be numerically large, its binary encoding length is polynomial. To verify this explicitly, let \(D\) be the product of the denominators of all input masses and supplies. Its binary length is at most the sum of their denominator lengths, hence \(O(L)\). Since \(\delta\) is a positive rational whose denominator divides \(D\), we have \(\delta\ge1/D\). Also, every supply has magnitude at most \(2^L\), so

\(\displaystyle U\le BD\le m\,2^{O(L)}.\)

Consequently, \(\log(U+1)=O(L+\log(m+1))\).

5. The exact algorithm and its correctness

The algorithm is as follows.

  • Compute all \(A_t\). If \(A_t\ge\mu_t\) for every type, return the infinite-value allocation constructed above.
  • Otherwise compute \(\delta,B,U\) as in Section 4.
  • Treat threshold \(0\) as feasible, witnessed by assigning every type the empty bundle. Binary-search the integer interval from \(0\) to \(U\), using the linear program from Section 2 for positive thresholds.
  • Let \(K\) be the largest feasible threshold. If \(K=0\), return the empty-bundle allocation. Otherwise solve its linear program and return the corresponding allocation.

Threshold feasibility is monotone: an allocation of value at least \(k\) also has value at least every smaller nonnegative integer. Binary search is therefore valid.

When the infinite test fails, Section 4 bounds all positive achievable values by \(U\). Every allocation’s finite value is an integer, because every finite bundle utility is an integer. Thus the largest feasible threshold \(K\) is exactly \(\mathrm{OPT}\). The returned allocation attains it.

Binary search makes \(O(\log(U+1))\) threshold calls. Each call has polynomial encoding length and polynomial running time. Every returned bundle has one nonzero coordinate, equal to either \(1\) or \(K\), so the allocation itself has polynomial encoding length.

The algorithm therefore computes and attains \(\mathrm{OPT}\) in time polynomial in \(m,\tau,L\).

6. Relation to finite-player hardness

The finite-player hardness premise concerns allocations of indivisible individual items. The normalization lemma here splits a type’s mass between several bundles and may give each recipient multiple units of the same category. Those operations are permitted by the present model and need not correspond to a valid finite-player allocation.

Thus the cited hardness does not contradict the exact algorithm proved above.
