The continuous mirror question, as graded

Given capacity types \(r\) with weights \(w_r\), rational proportions \(\mu_r\), population scale \(N\), and repeatable tasks \(j\) with thresholds \(q_j\) and rewards \(v_j\), partition the atomless mass \(N\mu_r\) into disjoint measurable teams, each assigned a task and having total capacity at least its threshold. Can an algorithm return teams with reward at least \(\frac12\mathrm{OPT}_\infty\) in time polynomial in the input bit length?

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: \(\tau\ge1\) capacity types with positive binary rational masses \(N\mu_r\), where \(\mu_r>0\), \(\sum_r\mu_r=1\), and \(N\in\mathbb Z_{>0}\) is binary encoded; \(\tau\) is the support size, not the number of possible types.
Type \(r\) has capacity per unit mass \(w_r\in\mathbb Z_{>0}\). Represent its atomless population by a disjoint interval of length \(N\mu_r\) with Lebesgue measure.
There are \(m\ge1\) repeatable task types with binary encoded thresholds and rewards \(q_j,v_j\in\mathbb Z_{>0}\); require \(q_j\le N\sum_r\mu_rw_r\) and \(q_j\le q_k\Rightarrow v_j\le v_k\).
A solution partitions the population into finitely many disjoint measurable teams, each assigned one task, and an optional idle remainder. A team containing type masses \(a_r\) can perform task \(j\) iff \(\sum_rw_ra_r\ge q_j\), earning \(v_j\) once; the remainder earns zero.
Let \(\mathrm{OPT}_\infty\) be the supremum of total reward over such solutions, allowing arbitrary real team masses. Solutions returned by an algorithm use rational masses and may be represented by repeated team templates: a task index, a type-mass vector, and a positive binary integer multiplicity, with total type usage at most \(N\mu_r\).
Can an algorithm return a solution of reward at least \(\frac12\mathrm{OPT}_\infty\) in time polynomial in \(m\), \(\tau\), and the total input bit length \(L\), including the encoding of \(N\)?
For finite indivisible populations, a polynomial-time \(\frac12\)-approximation is known ([Gal, Nguyen, Tran and Zick](https://comsoc-community.org/assets/proceedings/comsoc-2021/GalEtAl.pdf)).
No result settling this precise atomless formulation was located in the literature search.

Modeling choices made when packaging the task

  • Retained the discrete domains: positive integer capacities, thresholds and rewards, at least one type and task, monotone rewards in thresholds, and feasibility of every task for the whole population.
  • Normalized the proportions to sum to one and took the population scale N to be a positive binary encoded integer, corresponding to the discrete population size.
  • Made the atomless model concrete using disjoint Lebesgue intervals; capacities scale linearly with type mass, and each team earns one task reward rather than a reward proportional to its mass.
  • Allowed an idle remainder to account for participants completing no task; it can be attached to a successful team without decreasing reward.
  • Defined the benchmark over finite measurable team collections with arbitrary real masses, using a supremum.
  • Allowed rational team templates with binary integer multiplicities so that returning teams does not require explicitly listing exponentially many identical teams.

Result

Yes. A polynomial-time algorithm achieves a \(\frac12\)-approximation using a single rational team template with a binary encoded multiplicity.

Write \(M_r=N\mu_r\) for the available mass of type \(r\), and let \(C=\sum_{r=1}^{\tau}w_rM_r\) be the total capacity. By the hypotheses, \(C>0\) and every task satisfies \(q_j\le C\).

1. Atomless feasibility reduces to total capacity

We first prove that nonnegative integer task counts \(z_1,\ldots,z_m\) are realizable if and only if \(\sum_{j=1}^{m}z_jq_j\le C\).

Necessity. For any solution, let \(a_{T,r}\) be the mass of type \(r\) in team \(T\), and let \(j(T)\) be its task. Feasibility and disjointness imply
\(\sum_Tq_{j(T)}\le\sum_T\sum_rw_ra_{T,r}\le\sum_rw_rM_r=C\).
Grouping teams by their assigned task proves the required inequality.

Sufficiency. For every task \(j\), define the rational mass vector \(b^{(j)}\) by \(b^{(j)}_r=q_jM_r/C\). Each copy of this vector has capacity
\(\sum_rw_rb^{(j)}_r=(q_j/C)\sum_rw_rM_r=q_j\),
so it performs task \(j\).

Moreover, the prescribed copies use type \(r\) mass
\(\sum_jz_jb^{(j)}_r=(M_r/C)\sum_jz_jq_j\le M_r\).
Within each type interval, place consecutive disjoint subintervals of these prescribed lengths. A team is the union of its corresponding subintervals across types. These teams are measurable and disjoint; the unused portions form the idle remainder.

Consequently, \(\mathrm{OPT}_\infty\) equals the maximum of \(\sum_jz_jv_j\) over integer vectors satisfying \(z_j\ge0\) and \(\sum_jz_jq_j\le C\). This maximum exists: every coordinate satisfies \(z_j\le\lfloor C/q_j\rfloor\), so there are finitely many feasible vectors. In particular, allowing arbitrary real team masses creates no additional reward beyond these integer task counts.

2. Algorithm and feasibility

Choose a task \(j^\star\) maximizing the reward density \(v_j/q_j\), breaking ties arbitrarily. Define \(q^\star=q_{j^\star}\), \(v^\star=v_{j^\star}\), and \(k=\lfloor C/q^\star\rfloor\).

Return the single template consisting of task \(j^\star\), mass vector \(a_r=q^\star M_r/C\), and multiplicity \(k\).

Since \(q^\star\le C\), the multiplicity is positive. Each copy has capacity exactly \(q^\star\), and its total type usage satisfies \(ka_r=(kq^\star/C)M_r\le M_r\). Thus the template represents a feasible measurable partition, by the interval construction above.

3. Approximation guarantee

Let \(d=v^\star/q^\star=\max_jv_j/q_j\).

For every feasible solution, including one with arbitrary real team masses, its reward satisfies
\(\sum_Tv_{j(T)}\le d\sum_Tq_{j(T)}\le dC\).
Taking the supremum gives \(\mathrm{OPT}_\infty\le dC\).

Set \(x=C/q^\star\). Then \(x\ge1\), and \(k=\lfloor x\rfloor\ge1\). Since \(x<k+1\le2k\), we have \(k\ge x/2\). Therefore the returned reward satisfies
\(kv^\star\ge(x/2)v^\star=\frac12Cd\ge\frac12\mathrm{OPT}_\infty\).

This proves the requested guarantee. The reward-monotonicity hypothesis is not needed for this argument.

4. Polynomial time and output length

All calculations use exact integer and rational arithmetic.

The maximum-density task can be found using integer cross-products: \(v_j/q_j\ge v_\ell/q_\ell\) exactly when \(v_jq_\ell\ge v_\ell q_j\).

The rational numbers \(M_r\), \(C\), and \(a_r=q^\star M_r/C\) have bit lengths polynomial in the input length \(L\). Indeed, a common denominator for the sum defining \(C\) can be obtained by multiplying the input denominators; its bit length is at most the sum of their bit lengths. Multiplication, addition, division, and exact comparisons therefore require polynomial time.

Finally, \(\sum_r\mu_r=1\) gives \(C\le N\max_rw_r\). Because \(q^\star\ge1\), we have \(k\le C\le N\max_rw_r\), so the binary encoding of \(k\) also has polynomial length.

The algorithm outputs only one task index, \(\tau\) rational masses, and one binary integer multiplicity. It never enumerates the individual teams. Its running time and output length are polynomial in \(m\), \(\tau\), and \(L\), including the encoding of \(N\).
