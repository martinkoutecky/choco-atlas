The continuous mirror question, as graded

Given candidates \(C\), tree order \(k\), and a support of ballot types \(t\) with rational masses \(\mu_t\), compute the restricted Markov tree’s maximum-likelihood transition table. For each context \(S\) and eligible next candidate \(c\), use the total mass \(W_{S,c}\) of ballots contributing the transition \(S\to c\) and the context mass \(W_S=\sum_c W_{S,c}\), returning \(\hat\theta_{S,c}=W_{S,c}/W_S\) when \(W_S>0\), with the model’s fixed default distribution otherwise.

Packaged proof task (what the prover saw — nothing else)

Given a candidate set \(C\) with \(m=|C|\geq 1\) and an integer order \(1\leq k\leq m\), a society is given by its support: the list of \(\tau\) ballot types with positive binary rational masses \(\mu_t\), summing to \(1\). Here \(\tau\) is the support size, not the number of possible types; \(L\) is the total input bit length.
A ballot type records disjoint ordered blocks of distinct candidates certified to occupy consecutive positions in an incomplete ranking; at most one block is marked as beginning at the first position. Unspecified positions and comparisons remain unknown. Complete rankings and strict top orders are included.
Contexts \(S\) are ordered sequences of distinct candidates with \(0\leq |S|\leq k\) and \(|S|<m\); eligible successors are \(c\in C\setminus S\). From a marked initial block, extract each prefix transition whose context has length less than \(k\), including the empty-context transition. From every block, extract every consecutive window of length \(k+1\), using its first \(k\) candidates as context and its last as successor; pool these observations across positions.
Let \(a_t(S,c)\) count these occurrences in type \(t\), \(W_{S,c}=\sum_t\mu_t a_t(S,c)\), and \(W_S=\sum_{c\in C\setminus S}W_{S,c}\). Compute the exact table \(\hat\theta_{S,c}=W_{S,c}/W_S\) when \(W_S>0\), and \(\hat\theta_{S,c}=1/(m-|S|)\) otherwise. Maximum likelihood refers to the extracted categorical training observations, with no smoothing. Represent the table by its observed-context rows and an implicit uniform default for all other contexts.
Is this exact transition-table computation solvable in polynomial time in \(m,\tau,L,k\), or is it NP-hard?
Known discrete results give a finite-sample parameter-error bound for rankings drawn from the same model and claim estimation time linear in the total length of supplied training subsequences, using an implicit-default representation. [Doucette and Cohen (2017)](https://www.ifaamas.org/Proceedings/aamas2017/pdfs/p893.pdf).
No published result addressing exactly this rational-mass formulation was located.

Modeling choices made when packaging the task

  • Normalized the positive rational masses to sum to one, since the society is a distribution over types.
  • Specified contiguous-ballot input as disjoint certified consecutive blocks with an optional marked initial block, so missing candidates do not create unsupported adjacency observations.
  • Included initial-prefix transitions for contexts shorter than the order, and pooled every certified window of length one greater than the order across ballot positions.
  • Counted transition occurrences rather than merely whether a ballot contains a transition.
  • Used the uniform distribution over candidates outside the context as the fixed default.
  • Used observed-context rows with implicit defaults, following the source's representation rather than requiring enumeration of every possible context.
  • Interpreted maximum likelihood as categorical estimation on extracted observations without pseudocounts, consistent with the graded formula and the source's training procedure.
  • Allowed a nonempty candidate set and orders from one through the candidate count; excluded contexts containing every candidate because they have no successor.

Claim and scope. The exact transition table is computable in deterministic polynomial time in \(m,\tau,L,k\), with the stipulated representation by observed rows and an implicit uniform default. This holds for variable \(k\), including \(k=m\).

The proof uses precisely the extracted categorical observations specified in the question.

1. Bounding the number of observations.

Let \(B_t\) be the total number of candidate occurrences listed in the blocks of ballot type \(t\), and let \(N_t\) be its number of extracted transition occurrences. Because the blocks are disjoint and contain distinct candidates, \(B_t\leq m\).

An unmarked block of length \(r\) contributes \(\max\{r-k,0\}\) windows of length \(k+1\), hence at most \(r\) observations.

A marked initial block of length \(r\) contributes:

  • \(\min\{k,r\}\) prefix transitions, whose context lengths run from \(0\) through \(\min\{k,r\}-1\);
  • \(\max\{r-k,0\}\) windows with context length \(k\).

Their sum is exactly \(r\). Thus, writing \(N\) for the total number of extracted occurrences and \(R\) for the number of distinct observed contexts, we obtain

\(R\leq N=\sum_{t=1}^{\tau}N_t\leq\sum_{t=1}^{\tau}B_t\leq\tau m.\)

Every extracted transition is eligible: its context and successor are distinct candidates in the same block. Prefix contexts have length less than \(k\) and less than \(m\). A window can exist only if \(k+1\leq m\), so its context also has length less than \(m\).

Consequently, explicitly listing all eligible successor probabilities in the observed rows requires at most \(Rm\leq\tau m^2\) entries. The algorithm need not enumerate unobserved contexts.

2. Clearing denominators without expanding the society.

Write each supplied mass as \(\mu_t=p_t/q_t\), where \(p_t,q_t\) are positive integers represented in binary. Define

\(D=\prod_{t=1}^{\tau}q_t,\qquad x_t=p_t(D/q_t).\)

Each \(x_t\) is a positive integer. The normalization of the input masses gives

\(\sum_{t=1}^{\tau}x_t=D\sum_{t=1}^{\tau}\mu_t=D.\)

For each extracted occurrence of \((S,c)\) in type \(t\), add \(x_t\) to an integer accumulator \(A_{S,c}\). After processing all occurrences, define \(A_S=\sum_{c\in C\setminus S}A_{S,c}\). Then

\(A_{S,c}=\sum_t x_ta_t(S,c)=DW_{S,c},\qquad A_S=DW_S.\)

Therefore, whenever \(A_S>0\),

\(\hat\theta_{S,c}=A_{S,c}/A_S=W_{S,c}/W_S.\)

Because all masses are positive, \(A_S>0\) holds exactly for contexts that occur in the extracted data. Store those rows, assigning zero to eligible successors with no occurrence. For every other context, store the single default rule \(\hat\theta_{S,c}=1/(m-|S|)\).

The integers \(x_t\) serve only as arithmetic weights; the algorithm never creates \(x_t\) copies of a ballot.

3. Exact arithmetic and bit complexity.

The sum of the binary lengths of the supplied denominators is at most \(L\). Consequently,

\(\log_2D=\sum_t\log_2q_t\leq L.\)

Furthermore, the sum of all integer observation weights satisfies

\(\sum_{S,c}A_{S,c}=\sum_t x_tN_t\leq m\sum_t x_t=mD.\)

All accumulators, including every \(A_S\), therefore have \(O(L+\log(m+1))\) bits. Reducing \(A_{S,c}/A_S\) by their greatest common divisor cannot increase this bound.

For a deterministic implementation, first label candidates by integers from \(1\) through \(m\). Generate the \(N\) occurrence records, retaining their ballot-type indices, and sort them lexicographically by the ordered context and successor. Each key contains at most \(k+1\) candidate indices, so has \(O((k+1)\log(m+1))\) bits. Sorting and grouping these records takes polynomial time.

Computing \(D\) and the \(x_t\), accumulating grouped weights, computing row totals, and reducing output fractions requires \(O(\tau+N+Rm)\) calls to integer arithmetic and greatest-common-divisor routines. Their operands have polynomial bit length, and these routines admit polynomial-time algorithms.

Including context keys, the output has size at most

\(O\!\left(R(k+1)\log(m+1)+Rm\bigl(L+\log(m+1)\bigr)\right).\)

Since \(R\leq\tau m\), this size and the entire running time are polynomial in the requested parameters.

4. Verification of the maximum-likelihood interpretation.

For completeness, consider one observed context \(S\), and put \(p_c=W_{S,c}/W_S\). Let \(I=\{c:W_{S,c}>0\}\). Its contribution to the weighted categorical log-likelihood is

\(\ell_S(\theta)=\sum_{c\in I}W_{S,c}\log\theta_{S,c},\)

subject to nonnegative probabilities summing to one over \(C\setminus S\).

If any \(\theta_{S,c}=0\) for \(c\in I\), its log-likelihood is negative infinity and cannot maximize the objective. Otherwise, using \(\log u\leq u-1\) for \(u>0\),

\(\ell_S(\theta)-\ell_S(p)=W_S\sum_{c\in I}p_c\log(\theta_{S,c}/p_c)\leq W_S\left(\sum_{c\in I}\theta_{S,c}-1\right)\leq0.\)

Equality requires \(\theta_{S,c}=p_c\) for every \(c\in I\); these probabilities already sum to one, forcing zero on the remaining successors. Thus the computed observed row is the unique maximizer.

For an unobserved context, all weights vanish and the likelihood is independent of that row. The prescribed uniform default is therefore a valid maximizing choice. Since the extracted categorical objective separates over contexts, these rowwise choices maximize the full objective.

5. Relation to the cited work and boundary cases.

[Doucette and Cohen (2017), Section 3.2](https://www.ifaamas.org/Proceedings/aamas2017/pdfs/p893.pdf) discusses a finite-sample parameter-error bound and estimation using lazily constructed maps with uniform defaults. The proof above independently establishes the additional exact rational-arithmetic and output-size bounds needed for this formulation; it requires no assumption that the input society was sampled from a model.

If no observations are extracted, the output consists entirely of the uniform-default rule. For \(k=m\), there are no windows of length \(k+1\), and the prefix argument still applies. For \(m=1\), the only context is empty and its sole probability is one. Thus the proof covers every allowed input.
