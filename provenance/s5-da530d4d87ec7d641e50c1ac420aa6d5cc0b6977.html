The continuous mirror question, as graded

Given finite \(S\), finite priority-cohort types \(\Theta\), rational masses \(\mu_\theta\), rational per-capita capacities \(q_s\) with \(\sum_s q_s=1\), a finite rational distribution \(\nu\) over common strict rankings \(\Pi\), and strict inter-cohort relations \(\succ_s\), choose a type order \(\sigma:[0,1]\to\Theta\) with \(\lambda(\sigma^{-1}(\theta))=\mu_\theta\), encoded by rational block lengths and at most \(K\) blocks. Run serial dictatorship along \(\sigma\), let \(a_{\sigma,\Pi}(u)\) be the assigned object at position \(u\), and minimize \(J(\sigma)=\mathbb{E}_{\Pi\sim\nu}\left[\int_0^1\int_u^1 \mathbf{1}[a_{\sigma,\Pi}(u)\succ_\Pi a_{\sigma,\Pi}(v)]\mathbf{1}[\sigma(v)\succ_{a_{\sigma,\Pi}(u)}\sigma(u)]\,dv\,du\right]\), or decide whether \(J(\sigma)\le B\); ties within a cohort do not create justified envy.

Packaged proof task (what the prover saw — nothing else)

Let \(S\) be a nonempty set of \(m\) objects. A society is given by its support: the list \(\Theta\) of the \(\tau\) priority-cohort types with positive mass, each mass \(\mu_\theta\) a binary rational, with \(\sum_\theta\mu_\theta=1\). Here \(\tau\) is the support size, not the number of possible types.
Each object has a positive binary-rational capacity \(q_s\), with \(\sum_s q_s=1\), and a strict total priority order \(\succ_s\) over cohorts; agents within a cohort are tied. All objects are acceptable.
An explicitly listed distribution \(\nu\) has \(r\) common strict rankings of \(S\), with positive binary-rational probabilities summing to one. One ranking \(\Pi\) is drawn and shared by the whole society.
Given a positive integer \(K\) encoded in unary and a binary-rational threshold \(B\in\mathbb{Q}\), choose \(\sigma:[0,1]\to\Theta\), constant on at most \(K\) consecutive blocks of positive rational lengths, with \(\lambda(\sigma^{-1}(\theta))=\mu_\theta\), where \(\lambda\) is Lebesgue measure. Cohorts may recur, and the same order must be used for every realized \(\Pi\).
Continuous serial dictatorship processes mass in increasing position, assigning the best available object under \(\Pi\) until its capacity is exhausted, then continuing with the next object. Let \(a_{\sigma,\Pi}(u)\) be the resulting assignment; boundary values are immaterial.
Define \(J(\sigma)=\mathbb{E}_{\Pi\sim\nu}\left[\int_0^1\int_u^1\mathbf{1}[a_{\sigma,\Pi}(u)\succ_\Pi a_{\sigma,\Pi}(v)]\mathbf{1}[\sigma(v)\succ_{a_{\sigma,\Pi}(u)}\sigma(u)]\,dv\,du\right]\). Within-cohort ties create no justified envy.

Is deciding whether an admissible \(\sigma\) satisfies \(J(\sigma)\le B\) in \(\mathrm{P}\), or is it \(\mathrm{NP}\)-hard? State running times in \(m,\tau,r,K,L\), where \(L\) is the total input bit length.

For finitely many agents, equally many unit-capacity objects, strict priorities, and a uniformly drawn common ranking, expected justified-envy minimizers are exactly Kemeny rankings ([Hamdan, 2026](https://arxiv.org/html/2603.05660v2)).
Computing a Kemeny ranking is \(\mathrm{NP}\)-hard even for four input rankings ([Dwork et al., 2001](https://www.wisdom.weizmann.ac.il/~naor/PAPERS/rank_www10.html)); this concerns discrete rank aggregation. No result settling the exact continuous problem above was located.

Modeling choices made when packaging the task

  • Normalized society mass to one, matching the position interval and total capacity.
  • Required positive capacities and universal acceptability, following the discrete capacity and preference domains.
  • Interpreted strict inter-cohort relations as complete, transitive strict total orders, with indifference within cohorts.
  • Made the ranking distribution explicit, with positive binary-rational probabilities summing to one; its support size is r.
  • Specified consecutive positive rational blocks, allowing cohorts to recur, and fixed the order before the common ranking is realized.
  • Encoded the block limit K in unary because its encoding was unspecified; allowed arbitrary rational thresholds B.
  • Defined continuous serial dictatorship by exhausting capacities in preference order and disregarding measure-zero boundary choices.

Result and interpretation

The decision problem is \(\mathrm{NP}\)-complete, even when
\(m=\tau=r=K\), all cohort masses and object capacities are equal, and the explicitly listed distribution is uniform over cyclic object rankings.

I interpret the question as asking whether there exists an admissible \(\sigma\) satisfying \(J(\sigma)\le B\). Evaluating a supplied rational block schedule is polynomial-time solvable.

1. A polynomial-time evaluation formula

Write a schedule with \(b\le K\) blocks as labels \(\theta_1,\ldots,\theta_b\) and endpoints
\(0=x_0<x_1<\cdots<x_b=1\).

Fix a realized common ranking \(\Pi=(s_1,\ldots,s_m)\). Define
\(c_0=0\) and \(c_t=\sum_{h=1}^{t}q_{s_h}\).

Since all agents share \(\Pi\), serial dictatorship assigns object \(s_t\) precisely on the interval \((c_{t-1},c_t)\), independently of cohort labels. Define the overlap length

\(\ell_{it}=\lambda\bigl((x_{i-1},x_i)\cap(c_{t-1},c_t)\bigr)\).

The realized objective is exactly

\(J_\Pi(\sigma)=\sum_{i<j}\sum_{t<t'}\ell_{it}\ell_{jt'}\,\mathbf 1[\theta_j\succ_{s_t}\theta_i]\).

Indeed, points in block \(i\) precede points in block \(j\) when \(i<j\), and \(s_t\succ_\Pi s_{t'}\) exactly when \(t<t'\). Each contributing rectangle has area \(\ell_{it}\ell_{jt'}\). Pairs within one cohort contribute zero because of the priority tie.

For faster evaluation, merge the cohort endpoints with the assignment endpoints. There are at most \(m+b-1\) resulting positive-length intervals. Both the cohort label and assigned object are constant on each, so summing contributions over interval pairs takes \(O((m+b)^2)\) rational arithmetic operations.

After constructing priority-position lookup tables, evaluation and admissibility checking therefore take

\(O\bigl(m\tau+rm+K+\tau+r(m+K)^2\bigr)\)

rational arithmetic operations. If the supplied schedule has total bit length \(C\), the bit running time is \(\operatorname{poly}(m,\tau,r,K,L+C)\).

2. Hardness reduction

Source problem and padding

Use the following decision problem: given four strict rankings \(R_1,\ldots,R_4\) of \(n\) candidates and an integer \(T\), does some permutation \(\rho\) have total Kendall disagreement at most \(T\)? This problem is \(\mathrm{NP}\)-complete. [Dwork et al., Appendix B, Theorem 11](https://www.wisdom.weizmann.ac.il/~naor/PAPERS/rank_www10.html).

Choose \(N\) to be the smallest power of two satisfying \(N\ge\max\{4,n\}\). Add \(N-n\) dummy candidates at the bottom of every ranking, in the same fixed order. Call the extended rankings \(R'_1,\ldots,R'_4\).

For a permutation \(\rho\) of the extended candidates, define

\(D(\rho)=\sum_{h=1}^{4}\sum_{i<j}\mathbf 1[\rho(j)\succ_{R'_h}\rho(i)]\).

Padding preserves the decision answer:

  • Any permutation of the original candidates extends by placing the dummies last in their common order. This adds zero disagreements.
  • Restricting any extended permutation to the original candidates deletes only nonnegative disagreement contributions.

Consequently, the original instance is a yes-instance exactly when some extended permutation satisfies \(D(\rho)\le T\).

Construction of the continuous instance

Create one cohort for each extended candidate and \(N\) objects
\(s_0,\ldots,s_{N-1}\). Set

\(m=\tau=r=K=N,\qquad \mu_\theta=q_s=1/N\).

Partition the objects into four groups of size \(N/4\). Give every object in group \(h\) the cohort priority order \(R'_h\).

For each \(\ell\in\{0,\ldots,N-1\}\), explicitly list the cyclic common ranking

\(\Pi_\ell=(s_\ell,s_{\ell+1},\ldots,s_{\ell+N-1})\),

where indices are taken modulo \(N\). Assign probability \(1/N\) to each ranking. Finally set

\(B=T/(4N^2)\).

These are valid inputs. In particular, all masses, capacities, and probabilities are positive and sum to one. Since \(N\) is a power of two, these numbers and the threshold are dyadic rationals.

The block constraint forces a permutation

Every cohort has positive mass, so every cohort must label at least one positive-length block. There are \(N\) cohorts and at most \(K=N\) blocks.

Thus every admissible schedule has exactly \(N\) blocks, with each cohort appearing exactly once. Cohort recurrence is impossible in this construction. The mass constraint forces each block to have length \(1/N\).

Hence admissible schedules correspond precisely to permutations \(\rho\) of the cohorts. Block \(i\) is \(((i-1)/N,i/N)\) and has label \(\rho(i)\).

Exact objective identity

Fix \(\Pi_\ell\). Equal capacities make assignment intervals coincide with the cohort blocks. Block \(i\) receives

\(s_{(\ell+i-1)\bmod N}\).

For every \(i<j\), the object assigned to block \(i\) is strictly preferred under \(\Pi_\ell\) to the object assigned to block \(j\). The corresponding block rectangle has area \(1/N^2\). Therefore

\(J_{\Pi_\ell}(\sigma)=\frac{1}{N^2}\sum_{i<j}\mathbf 1[\rho(j)\succ_{s_{(\ell+i-1)\bmod N}}\rho(i)]\).

For each fixed \(i\), as \(\ell\) ranges over the \(N\) cyclic rankings, the object assigned to block \(i\) ranges over every object exactly once. Averaging gives

\(J(\sigma)=\frac{1}{N^3}\sum_{i<j}\sum_{s\in S}\mathbf 1[\rho(j)\succ_s\rho(i)]\).

Each \(R'_h\) is the priority order of exactly \(N/4\) objects. Thus

\(\displaystyle J(\sigma)=\frac{D(\rho)}{4N^2}\).

It follows that

\(\exists\,\sigma:\ J(\sigma)\le B\quad\Longleftrightarrow\quad\exists\,\rho:\ D(\rho)\le T\).

Combined with the padding equivalence, this proves a polynomial-time many-one reduction.

The constructed input has bit length
\(O(N^2\log N+\operatorname{bits}(T))\), and can be written in that time. Since \(N=O(n+1)\), the reduction is polynomial. This proves \(\mathrm{NP}\)-hardness using an explicitly listed distribution of only \(N\) common rankings.

3. Polynomial-size rational certificates

Membership in \(\mathrm{NP}\) requires a bound on witness length: merely requiring rational block lengths does not supply such a bound. The following argument provides it.

A finite collection of quadratic problems

Temporarily allow exactly \(K\) slots with nonnegative lengths. Zero-length slots can be deleted afterward, leaving an admissible schedule with at most \(K\) positive-length blocks. Conversely, any admissible schedule can be padded with zero-length slots.

Fix labels \(\theta_1,\ldots,\theta_K\). Using internal endpoints \(x_1,\ldots,x_{K-1}\), the mass constraints are

\(\sum_{i:\theta_i=\theta}(x_i-x_{i-1})=\mu_\theta\quad\text{for every }\theta\),

with \(x_0=0\), \(x_K=1\), and \(x_i-x_{i-1}\ge0\).

Collect all distinct internal assignment boundaries from all \(r\) rankings. Their number \(H\) satisfies \(H\le r(m-1)\). These boundaries partition \([0,1]\) into \(H+1\) closed intervals, with adjacent intervals sharing an endpoint.

Choose one such interval for each internal block endpoint. This adds rational linear bounds and defines a compact rational polytope \(P\).

To see that the objective is quadratic on \(P\), for ranking \(\Pi\) define

\(h_t(x)=\min\{\max\{x-c_{t-1},0\},q_{s_t}\}\).

Then \(\ell_{it}=h_t(x_i)-h_t(x_{i-1})\). On each chosen interval, every \(h_t\) is affine; its formulas agree at shared boundaries. The formula from Section 1 consequently makes \(J\) a rational quadratic polynomial on \(P\).

The polytope and quadratic polynomial have descriptions of bit length polynomial in \(m,\tau,r,K,L\).

Lemma: rational quadratic minima have small witnesses

Lemma. A rational quadratic polynomial on a nonempty compact rational polytope has a rational minimizer whose bit length is polynomial in the description length.

Proof. Write the polynomial as
\(f(x)=\tfrac12x^\mathsf THx+c^\mathsf Tx+d\), with \(H\) symmetric.

Let \(x^*\) be a minimizer, which exists by compactness. Combine the original equality constraints and all inequalities tight at \(x^*\) into \(Ex=e\). Let the columns of a rational matrix \(Z\) form a basis of \(\ker E\).

For every direction in \(\ker E\), sufficiently small moves in either direction from \(x^*\) remain feasible: tight constraints remain equalities, and the other inequalities have positive slack. First-order optimality therefore gives

\(Z^\mathsf T(Hx^*+c)=0\).

Consider the rational affine space

\(W=\{x:Ex=e,\ Z^\mathsf T(Hx+c)=0\}\).

It contains \(x^*\). The polynomial \(f\) is constant on \(W\). Indeed, for \(y,z\in W\), let \(v=y-z\). Then \(v\in\ker E\), so stationarity at \(z\) gives \(v^\mathsf T(Hz+c)=0\). Subtracting the stationarity equations gives \(Z^\mathsf THv=0\), hence \(v^\mathsf THv=0\). Therefore

\(f(y)-f(z)=v^\mathsf T(Hz+c)+\tfrac12v^\mathsf THv=0\).

The intersection \(P\cap W\) is a nonempty compact rational polytope. It has a rational vertex \(y\), and \(f(y)=f(x^*)\). Rational nullspace computation and Cramer’s rule bound the description of \(W\) and the coordinates of this vertex by a polynomial in the original description length. Thus \(y\) is the required minimizer. \(\square\)

Application to the decision problem

There are finitely many label sequences and endpoint cells. By the lemma, every nonempty cell has a polynomial-size rational minimizer. Therefore, if any admissible schedule satisfies \(J\le B\), some polynomial-size rational schedule does.

Deleting its zero-length slots preserves masses and the objective. Its remaining lengths are positive rational numbers. Section 1 gives a polynomial-time verifier.

Because \(K\) is unary, all description and certificate bounds above are polynomial in the input length. Hence the problem belongs to \(\mathrm{NP}\), completing the proof of \(\mathrm{NP}\)-completeness.

4. Explicit running-time bounds

Besides polynomial-time verification, the proof yields an exact deterministic algorithm.

First reject if \(K<\tau\), since every positive-mass cohort requires a block. Otherwise enumerate:

  • The \(\tau^K\) slot-label sequences.
  • At most \((H+1)^{K-1}\) endpoint-cell choices.
  • Subsets of the cell polytope’s inequalities to be treated as tight.

There are \(K\) nonnegative-length inequalities and \(2(K-1)\) endpoint bounds, so fewer than \(2^{3K}\) subsets.

For each subset, form \(E\), compute \(Z\), and construct \(W\) as in the lemma. Test whether \(P\cap W\) is nonempty using rational linear programming. If it is, obtain a rational feasible point and evaluate its objective.

This procedure is exact: every candidate is feasible, and the subset consisting of all inequalities tight at a cell minimizer produces a space \(W\) on which the minimum value is constant. Obtaining and checking each candidate takes polynomial bit time.

A valid general running-time bound is therefore

\(\displaystyle \tau^K\bigl(r(m-1)+1\bigr)^{K-1}2^{3K}\operatorname{poly}(m,\tau,r,K,L)\).

In particular, the problem is polynomial-time solvable for every fixed \(K\). The hardness reduction uses \(K=m=\tau=r=N\) growing with the source instance.
