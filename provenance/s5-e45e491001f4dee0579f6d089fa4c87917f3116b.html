The continuous mirror question, as graded

Given a finite type set \(T\), rational masses \(\mu_t>0\) summing to \(1\), resistances \(\alpha_t\in(0,1]\), baseline opinions \(s_t\in[0,1]\), a rational row-stochastic type-mixing matrix \(P\), and a target mass \(\beta\in[0,1]\), choose \(x_t\in[0,\mu_t]\) with \(\sum_t x_t=\beta\). Set \(\bar{s}_t(x)=s_t+(x_t/\mu_t)(1-s_t)\), \(R=\operatorname{diag}(\alpha)\), and \(M=(I-(I-R)P)^{-1}R\). Find an \(x\) maximizing the mean equilibrium opinion \(\mu^\top M\bar{s}(x)\).

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a nonempty list \(T\) of \(\tau\) types with positive binary-rational masses \(\mu_t\), where \(\sum_{t\in T}\mu_t=1\); \(\tau\) counts supported types, not possible types.
Each type has binary-rational resistance \(\alpha_t\in(0,1]\) and baseline internal opinion \(s_t\in[0,1]\). The input also contains a nonnegative rational row-stochastic matrix \(P\), whose entry \(P_{tu}\) is the influence weight of type \(u\) on type \(t\), and a binary-rational budget \(\beta\in[0,1]\). All resistances and mixing weights remain fixed.
An intervention chooses real masses \(0\le x_t\le\mu_t\) with \(\sum_t x_t=\beta\), changing the internal opinion of that much type mass to \(1\). Its type-average internal opinions are \(\bar s_t(x)=s_t+(x_t/\mu_t)(1-s_t)\).
Set \(R=\operatorname{diag}(\alpha)\) and \(M=(I-(I-R)P)^{-1}R\). The objective is to find any feasible \(x\) maximizing the mean equilibrium opinion \(\mu^\top M\bar s(x)\); ties are allowed.
Let \(m=|\{(t,u):P_{tu}>0\}|\) and let \(L\) be the total binary input length. State running times in \(m,\tau,L\).

Is this exact continuous opinion-maximization problem solvable in polynomial time in \(m,\tau,L\), or is it NP-hard?

For discrete agents, selecting a prescribed number and changing their internal opinions to \(1\) admits a cubic-arithmetic exact algorithm; an asynchronous exact-selection guarantee additionally depends on a positive boundary-score gap and the minimum resistance. Those results concern finite node selection and do not classify the divisible-mass problem defined here.

Conclusion and input interpretation

The problem is exactly solvable in polynomial time in \(m,\tau,L\). An optimal intervention can be chosen rational, with at most one type receiving a strictly partial intervention.

I use the finite-input interpretation that the baseline opinions \(s_t\) are also binary-encoded rationals. The proof below is independent of the [linked discrete-agent results](https://arxiv.org/html/2510.17226v1).

1. The equilibrium matrix exists

Write \(A=I-(I-R)P\), and let \(\alpha_{\min}=\min_{t\in T}\alpha_t>0\). Since \(P\) is nonnegative and row-stochastic, the nonnegative matrix \(B=(I-R)P\) satisfies

\(\displaystyle \|B\|_\infty=\max_{t\in T}(1-\alpha_t)=1-\alpha_{\min}<1.\)

Consequently, the matrix series \(\sum_{j=0}^{\infty}B^j\) converges and is the inverse of \(I-B=A\). Thus \(A\) is invertible and \(A^{-1}\) is nonnegative.

Moreover, writing \(\mathbf 1\) for the all-ones vector, row-stochasticity gives \(A\mathbf 1=R\mathbf 1\). Hence \(M=A^{-1}R\) is nonnegative and satisfies \(M\mathbf 1=\mathbf 1\).

These conclusions use only the stated hypotheses, including strict positivity of every resistance.

2. The objective has fixed marginal gains

Define \(q=M^\top\mu\). Since every supported mass \(\mu_t\) is positive, define the gain per unit intervention mass by

\(\displaystyle g_t=\frac{q_t(1-s_t)}{\mu_t}.\)

Expanding the prescribed type-average opinions yields

\(\displaystyle \mu^\top M\bar s(x)=\mu^\top Ms+\sum_{t\in T}g_t x_t.\)

The first term is independent of \(x\). Therefore the optimization problem is exactly

\(\displaystyle \max\left\{\sum_{t\in T}g_t x_t:\ 0\le x_t\le\mu_t,\ \sum_{t\in T}x_t=\beta\right\}.\)

The gains are fixed because neither \(P\) nor \(R\) changes under an intervention.

They can be computed using one linear-system solve. Specifically, solve

\(\displaystyle A^\top y=\mu.\)

Then \(q=Ry\), so

\(\displaystyle g_t=\frac{\alpha_t y_t(1-s_t)}{\mu_t}.\)

All quantities in this computation are rational.

3. A greedy intervention is globally optimal

Order the supported types as \(t_1,\ldots,t_\tau\) so that

\(\displaystyle g_{t_1}\ge g_{t_2}\ge\cdots\ge g_{t_\tau},\)

breaking ties arbitrarily.

If \(\beta=0\), return \(x=0\). Otherwise, let \(k\) be the smallest index for which

\(\displaystyle \sum_{i=1}^{k}\mu_{t_i}\ge\beta.\)

Such an index exists because the supported masses sum to \(1\). Set \(x^*_{t_i}=\mu_{t_i}\) for \(i<k\), set

\(\displaystyle x^*_{t_k}=\beta-\sum_{i=1}^{k-1}\mu_{t_i},\)

and set \(x^*_{t_i}=0\) for \(i>k\).

Minimality of \(k\) implies \(0<x^*_{t_k}\le\mu_{t_k}\). Thus \(x^*\) is feasible and has at most one strictly partial coordinate.

To prove optimality, let \(z\) be any feasible intervention, allowing real coordinates. The equality of their total masses gives

\(\displaystyle \sum_{i=1}^{\tau}g_{t_i}(x^*_{t_i}-z_{t_i})=\sum_{i=1}^{\tau}(g_{t_i}-g_{t_k})(x^*_{t_i}-z_{t_i}).\)

Every summand on the right is nonnegative:

  • For \(i<k\), both factors are nonnegative, since \(g_{t_i}\ge g_{t_k}\) and \(x^*_{t_i}-z_{t_i}=\mu_{t_i}-z_{t_i}\ge0\).
  • For \(i=k\), the first factor is zero.
  • For \(i>k\), both factors are nonpositive, since \(g_{t_i}\le g_{t_k}\) and \(x^*_{t_i}-z_{t_i}=-z_{t_i}\le0\).

Therefore \(\sum_t g_t x^*_t\ge\sum_t g_t z_t\). This proves global optimality over the entire real feasible set, including all tie cases.

4. Exact computation has polynomial bit complexity

A cubic arithmetic bound alone would not establish polynomial time for binary input. We therefore bound the sizes of the exact intermediate numbers.

Clearing denominators

Let \(D\) be the product of the input denominators occurring in the resistances, nonzero entries of \(P\), and masses. Its binary length is \(O(L)\). Each denominator of an entry of \(A\) divides \(D\): such an entry involves at most a product of one resistance denominator and one mixing-weight denominator.

Thus

\(\displaystyle C=DA^\top,\qquad b=D\mu\)

have integer entries, and \(A^\top y=\mu\) is equivalent to \(Cy=b\). Every entry of \(C\) and \(b\) has absolute value at most \(D\), because \(|A_{tu}|\le1\) and \(0<\mu_t\le1\).

For every square minor of order \(h\) of the augmented matrix \([C\mid b]\), the determinant expansion gives the bound

\(\displaystyle |\det|\le h!D^h.\)

Consequently, all these determinants have bit length

\(\displaystyle O\bigl(\tau(L+\log(\tau+1))\bigr).\)

Elimination and intermediate fractions

Gaussian elimination on \(C\) needs no row exchanges. To see this, take any nonempty subset \(S\subseteq T\). Its principal submatrix satisfies

\(\displaystyle A_{SS}=I_S-(I-R)_{SS}P_{SS}.\)

The nonnegative matrix \((I-R)_{SS}P_{SS}\) has row sums at most \(1-\alpha_{\min}<1\), so \(A_{SS}\) is invertible by the same convergent-series argument used above. Every leading principal submatrix of \(C\) is therefore invertible, ensuring nonzero elimination pivots.

Let \(\Delta_h\) denote the leading principal determinant of order \(h\) of \(C\), with \(\Delta_0=1\). After eliminating the first \(h\) variables, each remaining coefficient, including an augmented-column coefficient, is a ratio of a minor of order \(h+1\) to \(\Delta_h\). Indeed, for the leading block \(E\), the relevant Schur-complement entry obeys

\(\displaystyle \det\begin{pmatrix}E&v\\ w^\top&a\end{pmatrix}=\det(E)(a-w^\top E^{-1}v).\)

This identity follows by subtracting \(w^\top E^{-1}\) times the first block of rows from the last row. The preceding determinant bounds therefore bound every reduced fraction during elimination.

Back substitution also retains polynomial bit lengths. By Cramer’s rule, every solution coordinate has the form \(y_j=E_j/\Delta_\tau\), where \(E_j\) is a determinant covered by the same bound. In triangular row \(i\), every coefficient and the right-hand side can be represented with denominator \(\Delta_{i-1}\). Thus every partial sum in back substitution has common denominator \(\Delta_{i-1}\Delta_\tau\), and its numerator is a sum of at most \(\tau+1\) products of bounded determinants. Its bit length has the same asymptotic bound.

The gain calculations and exact comparisons add only input-sized factors. Finally, the boundary mass \(\beta-\sum_{i<k}\mu_{t_i}\) has polynomial bit length, since its denominator divides the product of the corresponding input denominators.

Running time

Set

\(\displaystyle H=\tau\bigl(L+\lceil\log_2(\tau+1)\rceil\bigr)+2.\)

The algorithm uses

\(\displaystyle O\bigl(m+\tau^3+\tau\log(\tau+1)\bigr)\)

exact rational arithmetic operations: construct the system, solve it, compute and sort the gains, and allocate the budget.

All operands have \(O(H)\) bits. Using schoolbook integer arithmetic and fraction reduction by the Euclidean algorithm, \(O(H^3)\) bit operations per rational operation is a conservative bound. Including input reading, this gives

\(\displaystyle O\!\left(L+\bigl(m+\tau^3+\tau\log(\tau+1)\bigr)H^3\right)\)

bit operations, which is polynomial in \(m,\tau,L\).

Exact sorting handles equal gains directly. Arbitrarily small positive resistances are also covered: their encoding lengths enter \(L\), and the algorithm does not use iterative convergence.

5. Classification

The exact continuous problem is polynomial-time solvable, with a rational optimizer explicitly constructed above. Its decision version is consequently in \(\mathrm P\); NP-hardness under polynomial-time reductions would imply \(\mathrm P=\mathrm{NP}\).
