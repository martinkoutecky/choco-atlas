Theorem 9.2 — class: hardness

The continuous mirror question, as graded

Given a finite type set \(T\), rational masses \(\mu_t\) summing to \(1\), self-qualification bits \(\sigma_t\), cross-agent qualifications \(\Phi(t,u)\) for an agent of type \(t\) judging a different agent of type \(u\) including \(u=t\), a target type set \(P\), and rational budget \(B\), choose \(x_t\in[0,\mu_t]\) with \(x_t=0\) for \(t\in P\) and \(\sum_t x_t\le B\). Let \(S(x)=\{t:\mu_t-x_t>0\}\), evaluate the iterative-consensus closure using \(\sigma_s=1\) and \(\Phi(r,s)=1\) for every present type \(r\) in \(Q_0\), and in iteration \(i\) requiring \(Q_{i-1}\ne\varnothing\), \(\sigma_s=1\), and \(\Phi(r,s)=1\) for every \(r\in Q_{i-1}\). Decide whether every surviving agent of every target type in \(P\) belongs to some \(Q_i\).

Packaged proof task (what the prover saw — nothing else)

A society is given by its support \(T\): the list of its \(\tau\) types with positive binary-rational masses \(\mu_t\), summing to \(1\); \(\tau\) counts supported types, not possible types. Each type represents an atomless population.
The input includes \(\sigma_t\in\{0,1\}\), recording self-qualification, and \(\Phi:T\times T\to\{0,1\}\), recording qualification of a different individual, including another individual of the same type; \(1\) means qualified. These bits are independent.
Given a nonempty protected target set \(P\subseteq T\) and binary-rational budget \(B>0\), a deletion chooses real masses \(0\le x_t\le\mu_t\), with \(x_t=0\) for \(t\in P\) and \(\sum_{t\in T}x_t\le B\). Remaining masses are not renormalized; write \(S(x)=\{t\in T:\mu_t-x_t>0\}\).
For this surviving support, define \(Q_0=\{s\in S(x):\sigma_s=1\text{ and }\Phi(r,s)=1\text{ for every }r\in S(x)\}\).
For \(i\ge1\), put \(K_{i-1}=\bigcup_{j=0}^{i-1}Q_j\) and \(Q_i=\{s\in S(x)\setminus K_{i-1}:Q_{i-1}\ne\varnothing,\ \sigma_s=1,\ \Phi(r,s)=1\text{ for every }r\in Q_{i-1}\}\).
Stop at the first empty round; the qualified types are \(F(x)=\bigcup_{i\ge0}Q_i\), with every surviving individual of such a type qualified. Assume \(P\not\subseteq F(0)\).
The decision problem asks whether an admissible deletion satisfies \(P\subseteq F(x)\). Let \(L\) be the total input bit length; running times use \(\tau,L\), with no separate candidate parameter \(m\) in this model.

Is this continuous constructive deletion problem in \(\mathrm{P}\), with running time polynomial in \(\tau\) and \(L\), or is it NP-hard?

For finite individual societies, constructive deletion under iterative consensus is NP-complete and \(\mathrm{W}[2]\)-hard in the number \(\ell\) of permitted deletions. [Source](https://arxiv.org/pdf/2209.15396#page=55)
No result settling exactly this continuous formulation was located in the literature search.

Modeling choices made when packaging the task

  • Restored the requirement that each round contain only types not qualified in earlier rounds, and specified termination at the first empty round.
  • Required a nonempty protected target set and positive rational budget, carrying over the discrete instance conditions.
  • Required at least one target type to be initially unqualified, carrying over the discrete restriction to instances whose constructive objective is initially unmet.
  • Interpreted each positive type mass as an atomless population, so same-type cross-individual qualifications apply even when only a small positive mass survives; self-qualification remains a separate bit.
  • Kept deletion masses real and measured their cost against the original normalized total mass without renormalizing survivors.
  • Defined L as total input bit length; this group-identification model has no separate candidate parameter m.

Theorem. The continuous constructive deletion problem is \(\mathrm{NP}\)-complete, even when all masses and the budget are dyadic rationals and \(\sigma_t=\Phi(t,t)\) for every type. Consequently, an algorithm polynomial in \(\tau\) and \(L\) would imply \(\mathrm{P}=\mathrm{NP}\).

Lemma 1: Whole-type deletions suffice.

For any admissible deletion \(x\), define
\[ D=\{t\in T:x_t=\mu_t\}. \]
Then \(S(x)=T\setminus D\). Define another deletion by \(x'_t=\mu_t\) for \(t\in D\), and \(x'_t=0\) otherwise.

Because \(x'_t\le x_t\) for every \(t\), this deletion respects the budget. It also respects protection: no protected type belongs to \(D\), since its original deletion mass is zero and its population mass is positive.

Moreover, \(S(x')=S(x)\). Every qualification round depends only on the surviving support and the given bits, so \(F(x')=F(x)\).

Thus the original question is equivalent to asking whether there exists \(D\subseteq T\setminus P\) such that
\[ \sum_{t\in D}\mu_t\le B \qquad\text{and}\qquad P\subseteq F(T\setminus D), \]
where \(F(S)\) denotes the rule evaluated on support \(S\). In particular, allowing arbitrary real deletion masses introduces no additional successful supports.

Membership in \(\mathrm{NP}\).

A certificate is the set \(D\), encoded by \(\tau\) bits. Check protection and the budget, then simulate the qualification rounds on \(T\setminus D\).

The nonempty rounds are disjoint, so there are at most \(\tau\) of them. Checking each round directly takes at most \(O(\tau^2)\) bit inspections, giving an \(O(\tau^3)\) bound for the simulation. Exact summation and comparison of the input rational masses require polynomial time in \(L\). Therefore certificate verification is polynomial in \(\tau\) and \(L\).

The finite hardness theorem being used.

The cited source proves that constructive deletion for the finite iterative-consensus rule is \(\mathrm{NP}\)-complete: given individuals \(N\), an opinion matrix, protected targets \(A\), and a deletion limit \(\ell\), one asks whether deleting at most \(\ell\) individuals outside \(A\) qualifies every target. Its rule uses unanimity initially and thereafter self-qualification and unanimity of the preceding nonempty round. See [Junker, Theorem 11, printed page 52; rule definition on printed pages 14–15](https://arxiv.org/pdf/2209.15396#page=55).

Write its opinions as \(a_{uv}\in\{0,1\}\), with \(1\) meaning qualified. For a surviving finite society \(U\), let \(R_i(U)\) be its rounds. In particular,
\[ R_0(U)=\{v\in U:a_{uv}=1\text{ for every }u\in U\}. \]
Subsequent rounds require \(a_{vv}=1\), unanimity of \(R_{i-1}(U)\), exclusion of previously qualified individuals, and a nonempty preceding round.

The following reduction checks explicitly that this finite theorem applies despite the continuous model’s separate self-qualification bits and normalization requirement.

Lemma 2: A normalized dyadic embedding preserves every round.

Consider a finite instance with \(n=|N|\), nonempty protected set \(A\), positive deletion limit \(\ell\), and at least one initially unqualified target. Replace \(\ell\) by \(\min\{\ell,n\}\); this does not change feasibility.

Choose \(q\) to be the smallest power of two strictly greater than \(n+\ell\). Construct
\[ T=\{t_v:v\in N\}\cup\{d\}, \qquad P=\{t_v:v\in A\}. \]
Assign masses and budget
\[ \mu_{t_v}=\frac1q,\qquad \mu_d=\frac{q-n}{q},\qquad B=\frac{\ell}{q}. \]
All masses are positive dyadic rationals, and their sum is exactly one.

For the original types, set
\[ \sigma_{t_v}=a_{vv}, \qquad \Phi(t_u,t_v)=a_{uv}. \]
For the additional type \(d\), set
\[ \sigma_d=0,\qquad \Phi(d,d)=0,\qquad \Phi(d,t_v)=1,\qquad \Phi(t_v,d)=0. \]
These choices are permitted because the input bits are independent.

The inequality \(q>n+\ell\) gives
\[ \mu_d=\frac{q-n}{q}>\frac{\ell}{q}=B. \]
Consequently, every admissible deletion leaves \(d\) in the support. Its self-qualification bit is zero, so it never belongs to a qualification round.

We claim that for every \(U\subseteq N\), the rounds on support
\[ S_U=\{t_v:v\in U\}\cup\{d\} \]
satisfy
\[ Q_i(S_U)=\{t_v:v\in R_i(U)\}. \]

For the initial round, an original type \(t_v\) qualifies precisely when
\[ a_{vv}=1 \quad\text{and}\quad a_{uv}=1\text{ for every }u\in U. \]
The opinion of \(d\) adds no restriction. Since \(v\in U\), unanimity over \(U\) already includes \(a_{vv}=1\). Hence this condition is exactly \(v\in R_0(U)\).

Suppose the rounds agree through index \(i-1\). Their previously qualified sets then correspond, and their preceding rounds are simultaneously empty or nonempty. For each remaining original type, the self-qualification test is \(a_{vv}=1\), and the unanimity test examines exactly the corresponding individuals in \(R_{i-1}(U)\). Thus the next rounds agree as well. The type \(d\) remains excluded by \(\sigma_d=0\).

Induction proves the claim, including agreement of termination and final qualified sets.

Correctness and size of the reduction.

If a finite deletion \(D\subseteq N\setminus A\) succeeds and \(|D|\le\ell\), delete exactly the types \(\{t_v:v\in D\}\). The total deleted mass is \(|D|/q\le B\), and Lemma 2 proves that every protected type qualifies.

Conversely, suppose a continuous deletion succeeds. By Lemma 1, replace it with whole-type deletions. The type \(d\) cannot be deleted, and protected types cannot be deleted. Thus the deleted types correspond to some \(D\subseteq N\setminus A\). The budget gives
\[ \frac{|D|}{q}\le\frac{\ell}{q}, \]
so \(|D|\le\ell\). Lemma 2 proves that deleting those individuals succeeds in the finite instance.

The output has \(\tau=n+1\) supported types. Since \(\ell\le n\), the choice of \(q\) ensures \(q\le4n\). Each constructed mass and the budget therefore has an \(O(\log n)\)-bit encoding, and the qualification matrix has \((n+1)^2\) entries. The reduction has polynomial size and construction time.

Finally, with no deletion, Lemma 2 preserves the initially unqualified target. Thus the output satisfies the required promise \(P\not\subseteq F(0)\).

Handling finite instances without an initially unqualified target.

To obtain a reduction from the entire finite problem, first simulate its rule without deletion. If all targets already qualify—including when the target set is empty—the finite instance is a yes-instance. Map it to the following fixed promised yes-instance:

Take types \(p,b\), each of mass \(1/2\), protect \(p\), and set
\[ \sigma_p=1,\qquad \sigma_b=0,\qquad \Phi(p,p)=1, \]
with every other matrix entry zero. Set \(B=1/2\).

Initially the first round is empty: \(b\) disqualifies \(p\), and \(b\) is not self-qualified. Deleting \(b\) makes \(p\) qualify in the initial round. This is therefore a yes-instance satisfying every input condition, including the promise.

All other finite instances meet the hypotheses of Lemma 2. The preprocessing is polynomial, so the reduction establishes \(\mathrm{NP}\)-hardness for the exact promised formulation. Together with membership in \(\mathrm{NP}\), this completes the proof.
