The continuous mirror question, as graded

Given types \(T\) with rational capacities \(\mu_t \ge 0\), \(\sum_{t\in T}\mu_t=1\), nonnegative rational attribute vectors \(q_t\in\mathbb{Q}_{\ge 0}^d\), and rational \(A,b\), choose masses \(x_t\) with \(0\le x_t\le\mu_t\) satisfying \(A\sum_{t\in T}x_tq_t\ge b\), while minimizing \(\sum_{t\in T}x_t\); report infeasibility if no such choice exists.

Conclusion

Exact minimum-mass winning-coalition optimization is polynomial-time solvable, with running time \(\operatorname{poly}(m,\tau,d,L)\) in the binary bit model. The algorithm returns an exact rational optimum coalition or reports infeasibility. No fixed-dimension assumption is needed.

1. Exact linear-programming formulation

Index the listed types by \(\{1,\ldots,\tau\}\). Define the nonnegative rational matrix \(C\in\mathbb{Q}_{\ge0}^{m\times\tau}\) by

\(\displaystyle C_{it}=\sum_{j=1}^{d}A_{ij}q_{tj}.\)

For every selection vector \(x\in\mathbb{R}^{\tau}\), distributivity gives

\(\displaystyle \left(A\sum_{t=1}^{\tau}x_tq_t\right)_i=\sum_{t=1}^{\tau}C_{it}x_t.\)

Consequently, the required optimization problem is exactly the linear program

\(\displaystyle \min_{x\in\mathbb{R}^{\tau}}\ \sum_{t=1}^{\tau}x_t \quad\text{subject to}\quad Cx\ge b,\qquad 0\le x_t\le\mu_t\quad(t=1,\ldots,\tau).\)

It has \(\tau\) variables and \(m+2\tau\) scalar inequalities. Its feasible vectors are precisely the winning divisible coalitions, and its objective is precisely their mass.

2. Feasibility and attainment

Let \(\mu=(\mu_1,\ldots,\mu_\tau)\). Because every entry of \(C\) is nonnegative, every permitted vector \(x\) satisfies

\(\displaystyle Cx\le C\mu.\)

Thus a winning coalition exists if and only if \(C\mu\ge b\): necessity follows from \(b\le Cx\le C\mu\), and sufficiency follows by selecting \(x=\mu\).

If feasible, the feasible region is a closed subset of the bounded box \(\prod_{t=1}^{\tau}[0,\mu_t]\), hence compact. The continuous objective therefore attains its minimum. Every feasible objective value lies in \([0,1]\), since \(\sum_t\mu_t=1\).

The permitted degeneracies cause no difficulty. If \(b=0\), the empty coalition is feasible and has the minimum possible mass, namely zero. Zero attributes and zero constraint coefficients are handled directly by the same formulation.

3. Polynomial encoding size

We must check that forming \(C\) does not produce coefficients of exponential encoding length.

Write each input rational as a numerator divided by a positive denominator, both encoded in binary. Let \(D\) be the product of all input denominators. Since their total encoding length is at most \(L\), the binary length of \(D\) is \(O(L)\).

Writing \(A_{ij}=a_{ij}/s_{ij}\) and \(q_{tj}=u_{tj}/v_{tj}\), we have

\(\displaystyle DC_{it}=\sum_{j=1}^{d}a_{ij}u_{tj}\frac{D}{s_{ij}v_{tj}}.\)

Each quotient is an integer: \(s_{ij}\) and \(v_{tj}\) occur as separate factors in \(D\). Each summand has \(O(L)\) bits, and summing \(d\) nonnegative summands adds at most \(O(\log(d+1))\) bits. Hence every \(C_{it}\) has an exact rational representation of length

\(\displaystyle O\!\left(L+\log(d+1)\right).\)

Set \(B=L+\log(d+1)\). Computing \(D\) and these sums takes \(O(m\tau d B^2)\) bit operations using conventional integer arithmetic. This bound also covers the construction of \(D\), because the number of input rationals is \(O(m\tau d)\).

The resulting LP, including its bound inequalities and objective, has total dense encoding length

\(\displaystyle \ell=O\!\left((m+2\tau)(\tau+1)B\right).\)

In particular, its encoding length is polynomial in the original input parameters.

4. Exact optimization and running time

Use the standard polynomial-time theorem for rational linear programming: given a rational LP, one can determine feasibility and boundedness and, when a finite optimum exists, return an exact rational optimal solution in time polynomial in the numbers of variables and inequalities and the total binary encoding length. This is the rational LP consequence of the ellipsoid method; see [Theorem 17.1 and the optimization discussion in these University of Washington notes](https://courses.cs.washington.edu/courses/cse521/22au/521-lecture-16.pdf).

Here its hypotheses hold: all coefficients are rational, the LP is explicitly represented with polynomial encoding length, and feasibility implies a finite attained optimum by Section 2.

Exact output also has polynomial size. A linear objective on a nonempty bounded polyhedron has an optimal vertex. At a vertex, \(\tau\) linearly independent active inequalities determine its coordinates. Multiplying the constraints by \(D\) gives integer coefficients of \(O(B)\) bits. Cramer’s rule and the determinant bound

\(\displaystyle |\det H|\le \tau!\left(\max_{i,j}|H_{ij}|\right)^\tau\)

therefore bound each vertex coordinate’s numerator and denominator length by \(O(\tau(B+\log(\tau+1)))\).

For a fixed polynomial \(P\) supplied by the rational LP algorithm, the total running time is bounded by

\(\displaystyle O\!\left(m\tau d B^2+\ell\right)+P(m+2\tau,\tau,\ell) =\operatorname{poly}(m,\tau,d,L).\)

This establishes polynomial bit complexity, including exact rational output.

5. Relation to inclusion-minimality

The finite-agent inclusion-minimality result is not needed for this conclusion. Here divisibility makes the feasible set a rational polyhedron, and total mass is a linear objective. The polynomial-time algorithm therefore solves the stated minimum-mass problem directly.
