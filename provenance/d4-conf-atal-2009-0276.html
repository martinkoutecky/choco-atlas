The continuous mirror question, as graded

Given supported types \(T\) with rational masses \(\mu_t\), nonnegative rational per-unit committee weights \(a_{tj}\), rational quotas \(q_j\), and a tested type \(t^\star\), decide whether there are coalition masses \(y_t\in[0,\mu_t]\) and some \(\delta>0\), with \(y_{t^\star}+\delta\le\mu_{t^\star}\), such that \(\sum_t a_{tj}y_t<q_j\) for at least one committee \(j\), while \(\sum_t a_{tj}(y_t+\delta\mathbf{1}[t=t^\star])\ge q_j\) for every committee.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a nonempty list \(T\) of \(\tau\) types with positive binary-rational masses \(\mu_t\), normalized by \(\sum_{t\in T}\mu_t=1\). Here \(\tau=|T|\) is the support size, not the number of possible types.
There are \(m\ge1\) committees. The input specifies binary-rational per-unit weights \(a_{tj}\ge0\), quotas \(q_j\in\mathbb Q\), and a tested type \(t^\star\in T\). Let \(L\) be the total input bit length; state running times in \(m,\tau,L\).
A coalition is a real mass vector \(y\) with \(0\le y_t\le\mu_t\). It wins precisely when \(\sum_{t\in T}a_{tj}y_t\ge q_j\) for every committee \(j\); equality counts as winning.
The continuous NONDUMMY problem asks whether there exist such a coalition \(y\) and a real \(\delta>0\) with \(y_{t^\star}+\delta\le\mu_{t^\star}\), such that \(\sum_{t\in T}a_{tj}y_t<q_j\) for at least one \(j\), while \(\sum_{t\in T}a_{tj}y_t+\delta a_{t^\star j}\ge q_j\) for every \(j\). The coalition may already contain mass of the tested type.

Is continuous NONDUMMY solvable in time polynomial in \(m,\tau,L\), or is it \(\mathrm{NP}\)-hard?

For finite players and conjunctions of committee games, DUMMY is \(\mathrm{coNP}\)-hard even with weights in \(\{0,1\}\), and belongs to \(\mathrm{coNP}\); consequently NONDUMMY is \(\mathrm{NP}\)-complete. [Source](https://www.cs.ox.ac.uk/people/michael.wooldridge/pubs/aamas2009d.pdf)
No result settling this exact continuous problem was identified in the literature search.

Modeling choices made when packaging the task

  • Normalized the positive masses to sum to 1, interpreting the society as a distribution over supported types.
  • Specified that coalition masses and the added positive mass are real, while all numerical input data are binary rationals.
  • Required a nonempty support, at least one committee, and a tested type belonging to the support.
  • Retained arbitrary rational quotas, including nonpositive or unattainable quotas, because the discrete definition permits arbitrary real thresholds.

Result

Continuous NONDUMMY is solvable in time polynomial in \(m,\tau,L\). An algorithm uses at most \(m\) rational linear programs.

Write \(s=t^\star\), and define the committee scores
\(S_j(y)=\sum_{t\in T}a_{tj}y_t\).

1. A canonical form for witnesses

Lemma. A NONDUMMY witness exists if and only if one exists with \(y_s=0\) and \(\delta=\mu_s\).

Proof. Suppose \((y,\delta)\) is a witness, and choose a committee \(k\) with \(S_k(y)<q_k\). Define \(x_t=y_t\) for \(t\ne s\), and \(x_s=0\).

Since every weight is nonnegative,
\(S_k(x)=S_k(y)-a_{sk}y_s\le S_k(y)<q_k\).
Thus \(x\) loses.

After adding the full tested mass, every committee \(j\) has score
\(S_j(x)+\mu_s a_{sj}=S_j(y)+(\mu_s-y_s)a_{sj}\).
The witness condition gives \(\mu_s-y_s\ge\delta\). Consequently,
\(S_j(x)+\mu_s a_{sj}\ge S_j(y)+\delta a_{sj}\ge q_j\).

Also, \(x\) respects all mass bounds, and \(\mu_s>0\). Therefore \((x,\mu_s)\) is a witness of the asserted form. The converse follows directly from the definition. \(\square\)

2. Linear programming characterization

Define the polytope of winning coalitions containing the full tested mass:
\(F=\{z\in\mathbb R^T:0\le z_t\le\mu_t\text{ for every }t,\ z_s=\mu_s,\ S_j(z)\ge q_j\text{ for every }j\}\).

Its feasibility is easy to check. By nonnegativity, \(S_j(z)\le S_j(\mu)\) whenever \(0\le z\le\mu\). Hence:

  • If \(S_j(\mu)<q_j\) for some committee, no coalition wins, so NONDUMMY is false.
  • Otherwise, \(\mu\in F\), so \(F\) is nonempty.

Assume henceforth that \(F\) is nonempty. For each committee \(k\), solve the linear program
\(v_k=\min_{z\in F}\sum_{t\ne s}a_{tk}z_t\).

The minimum is attained: \(F\) is closed and bounded, and the objective is continuous.

Proposition. NONDUMMY holds exactly when \(v_k<q_k\) for at least one committee \(k\).

Proof, forward direction. By the lemma, take a witness \((x,\mu_s)\) with \(x_s=0\). Set \(z_t=x_t\) for \(t\ne s\) and \(z_s=\mu_s\). The post-addition coalition wins, so \(z\in F\). Since \(x\) loses, some committee \(k\) satisfies
\(\sum_{t\ne s}a_{tk}z_t=S_k(x)<q_k\).
Therefore \(v_k<q_k\).

Proof, reverse direction. Suppose \(v_k<q_k\), and let \(z\in F\) attain this minimum. Set \(x_t=z_t\) for \(t\ne s\) and \(x_s=0\). Then
\(S_k(x)=v_k<q_k\), so \(x\) loses. Adding \(\delta=\mu_s>0\) produces exactly \(z\), which wins. All mass bounds hold. Thus \((x,\mu_s)\) is a NONDUMMY witness. \(\square\)

The strict comparison matters: \(v_k=q_k\) does not establish a witness, because equality counts as winning.

3. Algorithm and bit complexity

The algorithm is:

  • Compute all grand-coalition scores \(S_j(\mu)\) exactly. Return NO if any is below its quota.
  • Solve the preceding linear program for every committee \(k\).
  • Return YES if some exact optimum satisfies \(v_k<q_k\); otherwise return NO.

The standard rational linear programming theorem provides a deterministic algorithm that detects infeasibility and, for a feasible program with finite optimum, computes an exact rational optimum in time polynomial in its dimensions and binary encoding length. Rational optimal solutions have polynomial encoding length, permitting exact comparison with a rational quota. See [Goemans’s linear programming notes, Sections 11–13](https://ocw.mit.edu/courses/6-854j-advanced-algorithms-fall-2008/908fe54d659623efadda2d033b895caf_notes_lp.pdf).

Here every program has:

  • \(\tau\) real variables;
  • \(m+2\tau\) inequalities and one equality;
  • rational coefficients copied from the input, together with zeros and ones.

In a dense matrix encoding, its bit length is \(O(L+\tau^2)\). The feasible region is nonempty after step 1 and bounded by the mass constraints, so every optimum is finite. The theorem applies even when this region has lower dimension.

Thus the total running time is \(m\cdot\operatorname{poly}(m,\tau,L)\) bit operations, including construction and exact comparisons. No enumeration of possible types is required: the variables correspond precisely to the \(\tau\) supported types.

The [finite-player hardness result](https://www.cs.ox.ac.uk/people/michael.wooldridge/pubs/aamas2009d.pdf) concerns indivisible coalition choices. Here coalition coordinates vary over real intervals, and the characterization above uses linear optimization over those intervals.
