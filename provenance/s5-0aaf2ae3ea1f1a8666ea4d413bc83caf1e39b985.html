The continuous mirror question, as graded

Given a finite type set \(T\), rational masses \(\mu_i>0\) summing to \(1\), a symmetric nonnegative rational contact kernel \(W\), and an integer \(k\), let \(q_i^r\in[0,1]\) be the share of type \(i\) holding opinion \(1\) at round \(r\). Define \(D_i=\sum_j W_{ij}\mu_j\), and update \(q_i^{r+1}\) to \(1\) when \(\sum_j W_{ij}\mu_jq_j^r>D_i/2\), to \(0\) when it is less, and to \(q_i^r\) on a tie. Decide whether there exists an initial state \(q^0\in[0,1]^{|T|}\) whose first two-periodic time, \(\min\{r:q^{r+2}=q^r\}\), is at least \(k\).

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a nonempty list \(T=\{1,\ldots,\tau\}\) of types with positive binary rational masses \(\mu_i\), where \(\sum_i\mu_i=1\); \(\tau\) is the support size, not the number of possible types. There are \(m=2\) opinions.
The input also contains an explicitly listed symmetric matrix \(W\in\mathbb{Q}_{\geq0}^{\tau\times\tau}\) and a binary integer \(k\geq0\). Diagonal entries represent contact within a type and may be positive; zero rows are allowed. Let \(L\) be the total input bit length; state running times in \(m,\tau,L\), and \(k\).
An initial state is any real vector \(q^0\in[0,1]^\tau\), with \(q_i^r\) the share of type \(i\) holding opinion \(1\). For every integer round \(r\geq0\), update all types simultaneously. Set \(D_i=\sum_jW_{ij}\mu_j\) and \(S_i^r=\sum_jW_{ij}\mu_jq_j^r\).
Set \(q_i^{r+1}=1\) if \(S_i^r>D_i/2\), \(q_i^{r+1}=0\) if \(S_i^r<D_i/2\), and \(q_i^{r+1}=q_i^r\) on a tie.
Define \(t(q^0)=\min\{r\in\mathbb{Z}_{\geq0}:q^{r+2}=q^r\}\), using exact vector equality and \(\min\varnothing=+\infty\). The decision problem asks whether some \(q^0\in[0,1]^\tau\) satisfies \(t(q^0)\geq k\).

Is this continuous voting-time decision problem in \(\mathrm{P}\), or is it \(\mathrm{NP}\)-hard?

For finite simple graphs with binary initial opinions, synchronous majority updates, and retention of the current opinion on ties, the corresponding decision problem is \(\mathrm{NP}\)-complete ([Kaaser, Mallmann-Trenn, and Natale](https://drops.dagstuhl.de/storage/00lipics/lipics-vol058-mfcs2016/LIPIcs.MFCS.2016.55/LIPIcs.MFCS.2016.55.pdf)). No result settling the exact continuous problem above was identified in the searches.

Modeling choices made when packaging the task

  • Specified binary encoding for the threshold and restricted it to nonnegative integers, since convergence time starts at round zero.
  • Defined total input bit length L and fixed m=2 as the number of opinions.
  • Specified min of the empty set as positive infinity, making the decision problem defined without assuming continuous trajectories reach a two-periodic state.
  • Made explicit that initial shares may be arbitrary real numbers, as indicated by the graded question's domain.
  • Retained unrestricted nonnegative diagonal entries as contact within a type and allowed zero rows, consistent with the graded kernel domain; the simple-graph restriction does not forbid contact between distinct agents of the same type.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

The problem is $\mathrm{NP}$-hard. This holds even with uniform masses and a symmetric nonnegative integer matrix whose diagonal entries strictly dominate their rows. In this restricted class, every binary initial state is fixed; the hardness comes from fractional initial states.

The proof below gives a polynomial-time many-one reduction from Independent Set and proves soundness for every real initial state.

1. Centered coordinates and the construction

Put $x_i^r=2q_i^r-1$. For uniform masses $\mu_i=1/\tau$ and $W=B$, the update becomes
$$ x_i^{r+1}= \begin{cases} 1,&(Bx^r)_i>0,\\ -1,&(Bx^r)_i<0,\\ x_i^r,&(Bx^r)_i=0. \end{cases} $$
Indeed,
$$ S_i^r-\frac{D_i}{2} =\frac{1}{2\tau}(Bx^r)_i. $$
This change of coordinates preserves exact vector equality and voting time.

For a nonempty finite simple graph $H$, let $p(H)$ denote the maximum number of edges in an induced path of $H$. A single vertex is an induced path with zero edges.

We first construct a matrix $B(H)$ for which the maximum continuous voting time, denoted $V(H)$, satisfies
$$ p(H)+1\leq V(H)\leq p(H)+2. $$
We will then construct graphs whose induced-path lengths have a gap large enough to absorb this one-round uncertainty.

Enumerate the edges of $H$ as $e_0,\ldots,e_{s-1}$ and give edge $e_a$ weight $4^a$. Write
$$ S=\sum_{a=0}^{s-1}4^a,\qquad d=4S+1. $$
Define $B=B(H)$ by
$$ B_{ii}=d,\qquad B_{ij}= \begin{cases} 4^a,&\{i,j\}=e_a,\\ 0,&\{i,j\}\notin E(H), \end{cases} \quad i\neq j. $$
This matrix is symmetric, nonnegative, and integral. Moreover,
$$ d>\sum_{j\neq i}B_{ij} $$
for every vertex $i$.

2. Endpoint freezing and noncancellation

We establish two properties of this matrix.

First, a coordinate at an endpoint never changes. If $x_i=1$, then
$$ (Bx)_i =d+\sum_{j\neq i}B_{ij}x_j \geq d-\sum_{j\neq i}B_{ij}>0. $$
If $x_i=-1$, the analogous inequality gives $(Bx)_i<0$.

Consequently, each coordinate retains its initial fractional value until it first reaches an endpoint, after which it is constant. Every update that changes the state therefore consumes at least one previously fractional coordinate. An update that changes nothing produces a fixed point. Thus every trajectory becomes fixed within $\tau$ rounds.

Also, in this system equality two rounds apart implies equality one round apart: a coordinate can change at most once, so it cannot return to its previous value. Hence the voting time equals the first round at which the state is fixed.

Second, let
$$ F=\{i:|x_i^1|<1\}. $$
For every $i\in F$, the first update was a tie, so $x_i^1=x_i^0=:c_i$ and
$$ dc_i+\sum_{j\neq i}B_{ij}x_j^0=0. $$
It follows that
$$ |c_i| \leq\frac{\sum_{j\neq i}B_{ij}}{d} \leq\frac{S}{4S+1} <\frac14. $$

When such a coordinate $j$ later reaches an endpoint $\eta_j\in\{-1,1\}$, its change
$$ \Delta_j=\eta_j-c_j $$
satisfies
$$ \frac34<|\Delta_j|<\frac54. $$

Fix a vertex $i$ and a nonempty set $C\subseteq F$ of its neighbors that reach endpoints in the same round. Their contributions to the change in the field at $i$ cannot cancel:
$$ \sum_{j\in C}B_{ij}\Delta_j\neq0. $$
To prove this, choose $j_*$ with the largest incident weight $w_*=B_{ij_*}$. The weights are distinct powers of four, so
$$ \sum_{j\in C\setminus\{j_*\}}B_{ij}<\frac{w_*}{3}. $$
The triangle inequality gives
$$ \begin{aligned} \left|\sum_{j\in C}B_{ij}\Delta_j\right| &\geq w_*|\Delta_{j_*}| -\sum_{j\in C\setminus\{j_*\}}B_{ij}|\Delta_j|\\ &>\frac34w_*-\frac54\frac{w_*}{3}\\ &=\frac13w_*>0. \end{aligned} $$
This argument allows arbitrary signs and real values of the changes.

3. An upper bound valid for every real initial state

We prove
$$ V(H)\leq p(H)+2. $$

Fix any initial state $x^0\in[-1,1]^\tau$, and use the set $F$ from the preceding section. Coordinates outside $F$ are endpoints by round one and remain fixed thereafter.

Let
$$ A=\{i\in F:(Bx^1)_i\neq0\}. $$
These are exactly the coordinates in $F$ that reach endpoints at round two.

If $A=\varnothing$, then $x^2=x^1$, so the voting time is at most one. Assume henceforth that $A\neq\varnothing$.

For each $r\geq2$, let $C_r$ be the set of coordinates in $F$ that first reach endpoints at round $r$. Thus $C_2=A$.

Suppose $i\in F$ remains fractional at round $r$. Its field at round $r-1$ was zero, since otherwise it would already have reached an endpoint. The only changes from round $r-1$ to round $r$ occur in $C_r$, so
$$ (Bx^r)_i =\sum_{j\in C_r}B_{ij}(\eta_j-c_j). $$
The noncancellation property proves that this field is nonzero exactly when $i$ has a neighbor in $C_r$. Therefore
$$ C_{r+1} = \left\{ i\in F\setminus\bigcup_{u=2}^{r}C_u: N_H(i)\cap C_r\neq\varnothing \right\}. $$

These are precisely the successive distance layers from $A$ in the induced graph $H[F]$:
$$ C_{2+a} = \{i\in F:\operatorname{dist}_{H[F]}(i,A)=a\}. $$
Here only vertices in components meeting $A$ have finite distance. Vertices in the other components retain their fractional values forever.

Let $a_*$ be the largest finite distance from $A$ in $H[F]$. The state is fixed by round $2+a_*$. A shortest path realizing this distance is an induced path: any edge between nonconsecutive path vertices would shorten it. Since $H[F]$ is induced in $H$, that path is also induced in $H$. Hence
$$ a_*\leq p(H), $$
and therefore
$$ t(x^0)\leq2+a_*\leq p(H)+2. $$

The proof covers every real initial state, including all possible initial ties.

4. A lower bound from any induced path

We prove
$$ V(H)\geq p(H)+1. $$

Let
$$ v_0,v_1,\ldots,v_\ell $$
be an induced path in $H$. Write $P=\{v_0,\ldots,v_\ell\}$ and $O=V(H)\setminus P$.

Set every coordinate in $O$ initially to $1$. We choose the coordinates $c=(c_i)_{i\in P}$ by solving
$$ B_{PP}c = \frac14\,e_{v_0}-b, \qquad b_i=\sum_{j\in O}B_{ij}. $$
Here $e_{v_0}$ has entry one at $v_0$ and zero elsewhere.

This system is nonsingular. Indeed, if $B_{PP}u=0$ and $|u_i|=\|u\|_\infty$, then
$$ d\|u\|_\infty \leq S\|u\|_\infty. $$
Since $d>S$, this implies $u=0$.

The solution is fractional. Taking a coordinate of maximum absolute value in the defining system gives
$$ d\|c\|_\infty \leq S\|c\|_\infty+S+\frac14, $$
and therefore
$$ \|c\|_\infty \leq\frac{S+\frac14}{d-S} =\frac{S+\frac14}{3S+1} <\frac13. $$

For this initial state,
$$ (Bx^0)_{v_0}=\frac14, \qquad (Bx^0)_{v_j}=0\quad(1\leq j\leq\ell). $$
Thus only $v_0$ changes at round one, adopting endpoint $1$. All coordinates outside $P$ remain at their frozen endpoint.

Inductively, exactly $v_j$ changes at round $j+1$, also adopting endpoint $1$. To verify this, suppose $v_0,\ldots,v_{j-1}$ have already changed. The change at $v_{j-1}$ makes the field at $v_j$ positive by the amount
$$ B_{v_jv_{j-1}}(1-c_{v_{j-1}})>0. $$
No later path vertex is adjacent to an already changed path vertex, because the path is induced. Its field therefore remains zero. Previously changed coordinates remain frozen.

There is consequently one change in each of rounds
$$ 1,2,\ldots,\ell+1, $$
after which every coordinate is $1$. The voting time is exactly $\ell+1$.

Taking a longest induced path proves the claimed lower bound. Together with the preceding section,
$$ \boxed{p(H)+1\leq V(H)\leq p(H)+2.} $$

5. Creating a sufficient gap from Independent Set

We now give an elementary graph construction that turns an independent-set gap of one into a much larger induced-path gap.

Let $G$ be a finite simple graph on $n\geq1$ vertices, and let $\alpha(G)$ be its maximum independent-set size. Put
$$ \lambda=n+2. $$
Construct $H$ as follows:

  • Retain the original vertices and edges of $G$.
  • For each unordered nonadjacent pair of original vertices, add a path of exactly $\lambda$ edges connecting them. Its internal vertices are new and are used only for this path.
  • At each original vertex, attach two pendant paths of exactly $\lambda$ edges. All their other vertices are new and distinct.

We claim
$$ (\alpha(G)+1)\lambda \leq p(H) \leq(\alpha(G)+1)\lambda+n-1. $$

For the lower bound, let $u_1,\ldots,u_a$ be an independent set, where $a=\alpha(G)$.

If $a\geq2$, join these vertices in that order using the added connecting paths, and extend the two ends by a pendant path at $u_1$ and at $u_a$. This is an induced path: the selected original vertices have no edges between them, and every selected internal vertex has only its two path neighbors. Its length is
$$ (a-1)\lambda+2\lambda=(a+1)\lambda. $$
If $a=1$, the two pendant paths at a single original vertex give an induced path of length $2\lambda$, as required.

For the upper bound, consider any induced path $Q$ in $H$.

If it contains no original vertex, it lies inside one added path and has length at most $\lambda$, which satisfies the claimed bound.

Otherwise, list its original vertices in their order along $Q$. Between consecutive original vertices, $Q$ either uses one original edge of $G$ or traverses an entire added connecting path of length $\lambda$. This follows because every new internal vertex has degree two.

Partition the listed original vertices into maximal blocks connected by original edges. Let $b$ be the number of blocks and $a$ the total number of original vertices on $Q$.

Original vertices in different blocks cannot be adjacent in $G$: such an edge would join nonconsecutive vertices of $Q$ and would be a chord. Choosing one original vertex from each block therefore gives an independent set, so
$$ b\leq\alpha(G). $$

There are exactly $b-1$ complete connecting paths between blocks and $a-b$ original edges within blocks. The portions before the first original vertex and after the last each have length at most $\lambda$. Consequently,
$$ \begin{aligned} |E(Q)| &\leq2\lambda+(b-1)\lambda+(a-b)\\ &=(b+1)\lambda+a-b\\ &\leq(\alpha(G)+1)\lambda+n-1, \end{aligned} $$
where the last inequality uses $a\leq n$ and $b\geq1$. This proves both bounds.

6. The reduction and its encoding size

Independent Set asks, for a finite simple graph $G$ and an integer $h$, whether $\alpha(G)\geq h$. It is $\mathrm{NP}$-complete: graph complementation transfers CLIQUE to Independent Set, and CLIQUE is $\mathrm{NP}$-complete by [Karp’s theorem](https://doi.org/10.1007/978-1-4684-2001-2_9). We may restrict to $n\geq1$ and $1\leq h\leq n$, since the other cases are immediately decidable.

Given such an instance $(G,h)$, construct $H$ as in Section 5, and then $B(H)$ as in Section 1. The voting instance has
$$ \tau=|V(H)|,\qquad \mu_i=\frac1\tau,\qquad W=B(H),\qquad k=(h+1)\lambda+1. $$
All masses are positive rationals and sum to one. The matrix is explicitly listed, symmetric, nonnegative, and integral, with permitted positive diagonal entries.

If $\alpha(G)\geq h$, then
$$ p(H)\geq(h+1)\lambda. $$
Section 4 supplies an initial state with
$$ t(q^0)\geq p(H)+1\geq(h+1)\lambda+1=k. $$
Thus the voting instance is yes.

If $\alpha(G)\leq h-1$, then Section 5 gives
$$ p(H)\leq h\lambda+n-1. $$
For every real initial state, Section 3 gives
$$ t(q^0)\leq p(H)+2\leq h\lambda+n+1. $$
Since $\lambda=n+2$,
$$ k-\bigl(h\lambda+n+1\bigr) =\lambda-n=2. $$
Every real initial state therefore has voting time strictly less than $k$. The voting instance is no.

This proves the exact equivalence
$$ \alpha(G)\geq h \quad\Longleftrightarrow\quad \exists q^0\in[0,1]^\tau:\ t(q^0)\geq k. $$

It remains to check polynomial encoding size. If $z$ is the number of nonadjacent unordered pairs in $G$, then
$$ |V(H)|=n+2n\lambda+z(\lambda-1)=O(n^3), $$
and
$$ |E(H)|=|E(G)|+2n\lambda+z\lambda=O(n^3). $$
Writing $s=|E(H)|$, every weight $4^a$, and also the diagonal value $4S+1$, has $O(s)$ bits. There are $\tau+s$ nonzero matrix entries up to a constant factor, while all $\tau^2$ entries are explicitly listed. Thus
$$ L=O\!\left(\tau^2+(\tau+s)s+\tau\log\tau+\log(k+1)\right) =O(n^6). $$
Also $k=O(n^2)$ and $m=2$. The entire reduction runs in polynomial time in the source input length.

Hence the continuous voting-time decision problem is $\mathrm{NP}$-hard under polynomial-time many-one reductions.

7. Verification time on the hard subclass

The restricted class used above is also in $\mathrm{NP}$, so it is $\mathrm{NP}$-complete. Here are the certificate and running-time details.

Consider uniform masses and any symmetric nonnegative integer matrix satisfying
$$ W_{ii}>\sum_{j\neq i}W_{ij}. $$
The endpoint-freezing argument proves $t(q^0)\leq\tau$ for every real initial state.

We show that every real trajectory has a rational representative of polynomial encoding length through these $\tau$ rounds. Write the initial centered coordinates as variables $y_1,\ldots,y_\tau$. Along a fixed trajectory, every current coordinate is either its initial variable or an endpoint. Each field is therefore an affine form in $y$.

Record the signs of all fields used in rounds $0,\ldots,\tau-1$, together with the signs of the endpoint forms $y_i-1$ and $y_i+1$. These signs determine the update branches and whether an initial coordinate is already an endpoint.

Introduce a variable $\varepsilon$ and impose:

  • $-1\leq y_i\leq1$ and $0\leq\varepsilon\leq1$;
  • each recorded zero form equals zero;
  • each recorded positive form is at least $\varepsilon$;
  • each recorded negative form is at most $-\varepsilon$.

There are $O(\tau^2)$ constraints. The original real point admits some $\varepsilon>0$, by taking the minimum absolute value of the finitely many recorded nonzero forms, capped at one.

This is a nonempty bounded rational polytope. A linear functional on such a polytope attains its maximum at a vertex, so maximizing $\varepsilon$ gives a vertex with positive $\varepsilon$. At a vertex, $\tau+1$ independent active equations determine all variables: otherwise a small perturbation in a common null direction would contradict extremality.

The coefficients have $O(L+\log\tau)$ bits. By Cramer’s rule, each coordinate of the vertex has
$$ O\!\left(\tau(L+\log\tau)\right) $$
bits. Thus the total rational certificate length is polynomial in $\tau,L$. It preserves the recorded branches and endpoint status, and hence the voting time.

For $k=0$, the answer is yes. For $k>\tau$, this restricted problem answers no. Otherwise, an exact verifier simulates the polynomial-size rational certificate and checks that no fixed state occurs before round $k$. Its running time is
$$ (\min\{k,\tau\}+1)\operatorname{poly}(m,\tau,L), \qquad m=2, $$
using $O((\min\{k,\tau\}+1)m\tau^2)$ exact rational arithmetic operations. Operand lengths remain polynomial because coordinates are always initial certificate values or endpoints.

The classification established for the full input model is $\mathrm{NP}$-hardness; the additional $\mathrm{NP}$-completeness statement concerns this diagonal-dominant subclass.
