The continuous mirror question, as graded

Given a unary Tight Bin Packing instance \(S=\{s_1,\dots,s_m\}\) with \(\sum_i s_i=kB\) and \(s_i\le B\), let \(W\) be the distinct source-item values together with \(B\), and set \(q_w=(|\{i:s_i=w\}|+2\mathbb{1}[w=B])/(k+1)\). Consider two recipient types of masses \(\mu_0=1/(k+1)\) and \(\mu_1=k/(k+1)\), with cost factors \(0\) and \(1\), common utility \(u(b)=\sum_{w\in W}wb_w\), and per-capita supply \(q_w\) of each good type. Does there exist a mass assignment \(\lambda_t(b)\ge0\) over integral bundles \(b\in\mathbb{Z}_{\ge0}^{W}\) such that \(\sum_b\lambda_t(b)=\mu_t\), \(\sum_{t,b}\lambda_t(b)b_w=q_w\), every pair of bundles in its positive-mass support satisfies \(u(b)\ge u(b'-e_w)\) whenever \(b'_w>0\), and \(\sum_{t,b}\alpha_t\lambda_t(b)u(b)\le kB/(k+1)\)?

Packaged proof task (what the prover saw — nothing else)

Given a multiset \(S=(s_1,\ldots,s_m)\) and positive integers \(k,B\), all encoded in unary, assume \(1\le s_i\le B\) and \(\sum_i s_i=kB\).
Set \(W=\{s_i:1\le i\le m\}\cup\{B\}\), \(N_w=|\{i:s_i=w\}|+2\mathbf{1}_{\{w=B\}}\), and per-capita supplies \(q_w=N_w/(k+1)\).
A society is given by its support: the list of its \(\tau\) types with positive mass, each mass a binary rational; \(\tau\) counts supported recipient types, not possible types or good types. Here \(\tau=2\), with \((\mu_0,\alpha_0)=(1/(k+1),0)\) and \((\mu_1,\alpha_1)=(k/(k+1),1)\); total society mass is \(1\).
An integral bundle is \(b\in\mathbb{Z}_{\ge0}^{W}\), including the empty bundle; its common utility is \(u(b)=\sum_{w\in W}wb_w\), and its type-dependent cost is \(\alpha_tu(b)\). Let \(e_w\) denote the unit vector for good type \(w\).
An assignment consists of nonnegative real masses \(\lambda_t(b)\) satisfying \(\sum_b\lambda_t(b)=\mu_t\) and \(\sum_{t,b}\lambda_t(b)b_w=q_w\) for every \(w\in W\).
Write \(H=\{b:\lambda_0(b)+\lambda_1(b)>0\}\). Require \(u(b)\ge u(b'-e_w)\) for every ordered pair \(b,b'\in H\) and every \(w\) with \(b'_w>0\), and require \(\sum_{t,b}\alpha_t\lambda_t(b)u(b)\le kB/(k+1)\).
Let \(L\) be the total input bit length, including unary source data and binary rational society and supply data; state running times in \(m,\tau,L,k,B\).

Is deciding the existence of such an assignment solvable in polynomial time in the input length \(L\), or is it \(\mathrm{NP}\)-hard?

The corresponding discrete decision problem, with one zero-cost agent, \(k\) unit-cost agents, the source items plus two items of value \(B\), and budget \(kB\), is \(\mathrm{NP}\)-hard even with unary numbers. [Source](https://arxiv.org/html/2601.11372v1).

Result

The mass-assignment problem is polynomial-time solvable in \(L\).

The proof has two parts: the budget forces the utilities of both recipient types exactly, and the remaining fractional assignment problem has a polynomial-size flow formulation.

1. The budget forces the supported bundles

Write \(c_w=|\{i:s_i=w\}|\), so \(N_w=c_w+2\mathbf{1}_{\{w=B\}}\).

For any feasible assignment, its total assigned utility is

\(\displaystyle T=\sum_{t,b}\lambda_t(b)u(b)=\sum_{w\in W}wq_w=\frac{(k+2)B}{k+1}.\)

The interchange of sums is valid because every summand is nonnegative. Let

\(\displaystyle F=\sum_b\lambda_0(b)u(b),\qquad C=\sum_b\lambda_1(b)u(b).\)

Then \(F+C=T\), and the budget gives

\(\displaystyle C\le\frac{kB}{k+1},\qquad F\ge\frac{2B}{k+1}=2B\mu_0.\)

First, every supported bundle has utility at least \(B\). There exists a type-\(0\) supported bundle \(b^*\) with \(u(b^*)\ge 2B\). Otherwise, integer utilities would imply \(u(b)\le 2B-1\) throughout the type-\(0\) support, contradicting \(F\ge 2B\mu_0\).

Choose any \(w\) occurring in \(b^*\). Since \(w\le B\), fairness implies, for every \(b\in H\),

\(\displaystyle u(b)\ge u(b^*-e_w)=u(b^*)-w\ge B.\)

Consequently,

\(\displaystyle C\ge B\mu_1=\frac{kB}{k+1}.\)

The budget therefore holds with equality. Moreover,

\(\displaystyle \sum_b\lambda_1(b)\bigl(u(b)-B\bigr)=0.\)

Every summand is nonnegative, so every type-\(1\) supported bundle has utility exactly \(B\).

Because \(\mu_1>0\), choose such a bundle \(\widehat b\). Fairness between \(\widehat b\) and any supported bundle \(b\) gives, for every \(w\) occurring in \(b\),

\(\displaystyle u(b)-w\le u(\widehat b)=B.\)

Thus \(u(b)\le 2B\). Since \(F=T-C=2B\mu_0\), every type-\(0\) supported bundle must have utility exactly \(2B\). For such a bundle, the preceding inequality implies \(w\ge B\) for every occurring good. All good values are at most \(B\), so the bundle consists of exactly two goods of value \(B\).

We have proved the necessary structure:

  • Type \(0\) receives only \(2e_B\), with mass \(1/(k+1)\).
  • Type \(1\) receives only bundles of utility \(B\), with total mass \(k/(k+1)\).

In particular, every feasible assignment exhausts the budget exactly.

2. An equivalent fractional configuration problem

Define the finite set

\(\displaystyle \mathcal C_B=\{b\in\mathbb Z_{\ge0}^{W}:u(b)=B\}.\)

It is finite because \(w\ge1\) implies \(b_w\le B\).

The original problem is equivalent to finding nonnegative real numbers \(x_b\), indexed by \(b\in\mathcal C_B\), satisfying

\(\displaystyle \sum_{b\in\mathcal C_B}x_b=k,\qquad \sum_{b\in\mathcal C_B}x_b b_w=c_w\quad(w\in W).\)

For necessity, set \(x_b=(k+1)\lambda_1(b)\). The type-\(0\) assignment established above consumes exactly \(2/(k+1)\) units of good \(B\), leaving supplies \(c_w/(k+1)\) for type \(1\). This gives the displayed equations.

Conversely, given such \(x_b\), set

\(\displaystyle \lambda_0(2e_B)=\frac1{k+1},\qquad \lambda_1(b)=\frac{x_b}{k+1},\)

and set all other masses to zero. The configuration equations give exactly the required type masses and supplies. The cost is \(Bk/(k+1)\).

Fairness also holds: every supported bundle has utility at least \(B\); removing any good from a utility-\(B\) bundle leaves utility below \(B\), while removing either good from \(2e_B\) leaves utility \(B\).

Thus the equivalence is exact. It remains to avoid explicitly listing the potentially numerous configurations.

3. A polynomial-size linear program

Construct a directed graph with vertices \(\{0,\ldots,B\}\). For each \(w\in W\) and each integer \(v\) with \(0\le v\le B-w\), include an edge

\(\displaystyle (v,w):v\longrightarrow v+w,\)

labelled by \(w\). Every edge increases the vertex value, so the graph is acyclic.

A path from \(0\) to \(B\) represents an integral bundle of utility \(B\): its coordinate \(b_w\) counts edges labelled \(w\). Conversely, ordering the goods of any \(b\in\mathcal C_B\) produces such a path. Every partial sum lies between \(0\) and \(B\), so all required edges exist.

Introduce a nonnegative real variable \(f_{v,w}\) for each edge. Impose flow balance at every vertex \(z\):

\(\displaystyle \sum_{\substack{w\in W\\z+w\le B}}f_{z,w} - \sum_{\substack{w\in W\\w\le z}}f_{z-w,w} = \begin{cases} k,&z=0,\\ -k,&z=B,\\ 0,&0<z<B. \end{cases} \)

Also impose the good-count constraints

\(\displaystyle \sum_{v=0}^{B-w}f_{v,w}=c_w\qquad(w\in W).\)

These are linear equalities and nonnegativity constraints with integer coefficients.

Proof of equivalence

Given feasible configuration masses \(x_b\), choose one path for each configuration and send flow \(x_b\) along it. Flow balance follows because every path starts at \(0\) and ends at \(B\). The good-count equations follow because the path for \(b\) uses exactly \(b_w\) edges labelled \(w\).

For the reverse direction, any feasible nonnegative flow decomposes into nonnegative weighted paths from \(0\) to \(B\). Here is a direct justification. While positive flow leaves \(0\), follow positive-flow edges. Conservation prevents the walk from stopping at an intermediate vertex, and acyclicity forces it to reach \(B\). Subtract the minimum edge flow along this path and record that amount as its weight. Each iteration eliminates at least one positive-flow edge.

After these finitely many iterations, no positive flow can remain: a remaining positive-flow subgraph would have a vertex with positive outgoing flow and no positive incoming flow, contradicting conservation and the absence of remaining source flow.

For each recorded path, form its bundle and aggregate the weights of paths representing the same bundle. The resulting numbers \(x_b\) have total mass \(k\), and

\(\displaystyle \sum_bx_b b_w=\sum_{v=0}^{B-w}f_{v,w}=c_w.\)

They therefore solve the configuration problem.

4. Running time and bit complexity

Let \(d=|W|\). Then \(d\le\min\{m+1,B\}\). The graph has \(B+1\) vertices and

\(\displaystyle |E|=\sum_{w\in W}(B-w+1)\le dB\)

edges. The linear program consequently has at most \(dB\) variables and \(B+1+d\) equality constraints, together with nonnegativity.

All matrix coefficients belong to \(\{-1,0,1\}\). The right-hand sides are \(k\) and the counts \(c_w\). Since

\(\displaystyle kB=\sum_i s_i\le mB,\)

we have \(k\le m\), and every right-hand side has bit length \(O(\log(m+1))\). Each variable occurs in two flow-balance equations and one good-count equation.

The standard polynomial-time theorem for rational linear-programming feasibility applies: all coefficients are rational, the formulation is finite and explicit, and its encoding length is polynomial in the stated parameters. Thus, including reading the input, a valid bit-operation running-time bound is

\(\displaystyle \bigl(L+\tau+dB\log(m+k+B+2)\bigr)^{O(1)},\qquad \tau=2.\)

Using \(d\le m+1\), this is also

\(\displaystyle \bigl(L+\tau+(m+1)B\log(m+k+B+2)\bigr)^{O(1)}.\)

Because the source data, \(k\), and \(B\) are unary, this bound is polynomial in \(L\). A rational feasible flow also yields a finite rational assignment by the path decomposition above.

5. Relation to the discrete hardness result

The cited unary hardness result concerns discrete agents and indivisible source items. [Deltl, Theorem 10 and Appendix A.7](https://arxiv.org/html/2601.11372v1#A7)

In the configuration formulation, discrete allocation requires integer configuration multiplicities. The specified mass-assignment problem permits arbitrary nonnegative real multiplicities, which the flow linear program represents exactly. The polynomial-time conclusion therefore applies to the mass model in the question, with \(\tau=2\) supported recipient types.
