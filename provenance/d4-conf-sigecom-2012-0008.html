The continuous mirror question, as graded

Given a finite complete type set \(\mathcal T\), rational population mass \(\mu\), per-capita resource supplies \(\rho\), the score-ordered greedy mass allocation \(q^\mu\), and a specified symmetric tagged-agent residual and tie-breaking kernel \(G^{\mathrm{tag}}_\mu(t,\widehat t)\), compute \(w\) and slacks \(\xi_{t,S}\ge 0\) minimizing \(\frac12\lVert w\rVert_2^2+C\sum_{t,S}q^\mu_{t,S}\xi_{t,S}\), subject to \(f_w(\mu,t,S)-f_w(\mu,t,S')\ge \mathcal L(S,S')-\xi_{t,S}\) for every positive-mass \((t,S)\) and every alternative bundle \(S'\), with \(w_1>0\), and output \(p_w(\mu,S)=-w_{-1}^{\mathsf T}\psi(\mu,S)/w_1\) together with the induced tagged-agent population regret certificate.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Exact population training is \(\mathrm{NP}\)-hard

The specified problem is \(\mathrm{NP}\)-hard, even when \(\tau=|\mathcal T|=b=d=1\), all masses and supplies equal \(1\), and the feature takes values only in \(\{0,1,2\}\). The reduction satisfies the promise that the unrestricted optimizer has \(w_1>0\).

The population certificate \(R\leq B\) is valid. An exact algorithm obtained by enumerating bundles runs in \(2^{O(m)}\operatorname{poly}(m,\tau,L,|\mathcal T|,b,d)\) bit operations. A polynomial-time algorithm for the general problem would imply \(\mathrm P=\mathrm{NP}\).

1. Proof of the population regret certificate

Fix any feasible weights and slacks with \(w_1>0\). Define the true type’s utility by

\(u_t(S)=v_t(S)-p_w(\mu,S)=f_w(\mu,t,S)/w_1.\)

This identity uses the specified signed prices directly.

For every positive-mass training pair \((t,S)\) and every bundle \(S'\), feasibility implies

\(w_1\bigl(u_t(S')-u_t(S)\bigr)\leq \xi_{t,S}-\mathbf 1_{S\ne S'}\leq \xi_{t,S}.\)

Fix a supported type \(t\) and an admissible report \(\widehat t\). Average this inequality over \(S'\) using \(G^{\mathrm{tag}}_\mu(t,\widehat t;S')\), and then over \(S\) using \(q^\mu_{t,S}/\mu_t\). Both are probability distributions. We obtain

\(\displaystyle \sum_{S'}G^{\mathrm{tag}}_\mu(t,\widehat t;S')u_t(S') -\sum_S\frac{q^\mu_{t,S}}{\mu_t}u_t(S) \leq \frac{1}{\mu_t w_1}\sum_Sq^\mu_{t,S}\xi_{t,S}. \)

By the promised truthful-tag identity, the second term is precisely truthful expected utility. The right-hand side does not depend on \(\widehat t\), so the inequality remains valid after maximizing over admissible reports. Multiplying by \(\mu_t\) and summing over supported types proves

\(\displaystyle R\leq \frac{1}{w_1}\sum_{t,S}q^\mu_{t,S}\xi_{t,S}=B.\)

Also \(R\geq0\), because truthful reporting is admissible. This proof requires neither deterministic tagged allocations nor restrictions on the signs of prices.

2. A reduction from Boolean satisfiability

Let \(\varphi\) be a Boolean formula on \(n\geq1\) variables. We construct a training instance in polynomial time.

2.1. Items, types, allocation, and tagged distributions

Set \(m=n+1\). Let item \(n+1\) be a marker, and write \(A=[m]\).

There is one admissible type \(t\), with mass \(\mu_t=1\). Its only desired bundle is \(A\), valued at \(1\). Thus

\(v_t(A)=1,\qquad v_t(S)=0\quad\text{for every }S\ne A.\)

Give every item supply \(1\). The greedy procedure has only one desired type–bundle pair to process, so it allocates all mass to \(A\). Supply the sparse table

\(q^\mu_{t,A}=1\)

and the tagged distribution

\(G^{\mathrm{tag}}_\mu(t,t;A)=1.\)

These tables satisfy every allocation and truthful-tag requirement. Set \(C=2\).

2.2. The feature circuit

Use one feature coordinate. For a bundle \(S\), let \(x_j=\mathbf1_{j\in S}\), for \(j\in[n]\). Define the circuit by the following ordered cases:

  • If \(S=A\), output \(\psi(\mu,S)=1\).
  • Otherwise, if \(n+1\notin S\) and \(\varphi(x_1,\ldots,x_n)\) is true, output \(\psi(\mu,S)=2\).
  • Otherwise, output \(\psi(\mu,S)=0\).

The circuit ignores \(\mu\), is independent of the tag’s report, and has polynomial size. Every output is a constant-size binary rational.

Two properties will be used:

  • The proper bundle \(\{n+1\}\) always has feature \(0\).
  • A proper bundle with feature \(2\) exists exactly when \(\varphi\) is satisfiable.

The second property holds because every Boolean assignment is represented by a bundle contained in \([n]\), which necessarily omits the marker.

2.3. The resulting optimization problem

Write \(a=w_1\), \(z=w_{-1}\), and \(\xi=\xi_{t,A}\). There is one training example, of mass \(1\), so the objective is

\(\displaystyle F(a,z,\xi)=\frac12(a^2+z^2)+2\xi.\)

For every proper bundle \(S'\), its valuation is zero and its loss against \(A\) is one. Consequently its constraint is

\(a+z\bigl(1-\psi(\mu,S')\bigr)\geq1-\xi.\)

The constraint for \(S'=A\) merely repeats \(\xi\geq0\).

3. Exact optimizers in the two cases

3.1. Unsatisfiable formulas

If \(\varphi\) is unsatisfiable, every proper bundle has feature \(0\). The complete feasible system is therefore

\(a+z\geq1-\xi,\qquad \xi\geq0.\)

For \(0\leq\xi\leq1\), Cauchy–Schwarz gives

\(\displaystyle a^2+z^2\geq\frac{(a+z)^2}{2}\geq\frac{(1-\xi)^2}{2}.\)

Hence

\(\displaystyle F(a,z,\xi)\geq\frac{(1-\xi)^2}{4}+2\xi =\frac14+\frac32\xi+\frac14\xi^2. \)

This expression has its unique minimum on that interval at \(\xi=0\). For \(\xi\geq1\), the objective is at least \(2\), so no such point is optimal.

At \(\xi=0\), equality in the lower bound requires \(a=z=1/2\), and these weights are feasible. Thus the unique optimizer is

\(\displaystyle (a,z,\xi)=\left(\frac12,\frac12,0\right),\qquad F^*=\frac14.\)

In particular, \(w_1=1/2>0\).

3.2. Satisfiable formulas

If \(\varphi\) is satisfiable, a proper bundle with feature \(2\) exists. A proper bundle with feature \(0\) also exists, namely \(\{n+1\}\). Thus the complete feasible system is

\(a+z\geq1-\xi,\qquad a-z\geq1-\xi,\qquad \xi\geq0.\)

For \(0\leq\xi\leq1\), the first two inequalities imply

\(a\geq1-\xi+|z|\geq0.\)

Therefore \(a^2+z^2\geq(1-\xi)^2\), with equality only when \(a=1-\xi\) and \(z=0\). It follows that

\(\displaystyle F(a,z,\xi)\geq\frac12(1-\xi)^2+2\xi =\frac12+\xi+\frac12\xi^2. \)

This expression has its unique minimum on the interval at \(\xi=0\). Again, \(\xi\geq1\) gives objective at least \(2\). The unique optimizer is consequently

\((a,z,\xi)=(1,0,0),\qquad F^*=\frac12.\)

Here \(w_1=1>0\).

3.3. Consequence for computational complexity

The construction has polynomial input length and satisfies

\(\displaystyle \varphi\text{ is satisfiable} \quad\Longleftrightarrow\quad w_1^*>\frac34. \)

Both cases satisfy the positivity promise. An exact optimizer therefore decides Boolean satisfiability in polynomial additional time. This establishes \(\mathrm{NP}\)-hardness of the requested output problem.

The learned prices also distinguish the cases: \(p_w(\mu,A)=-1\) in the unsatisfiable case and \(p_w(\mu,A)=0\) in the satisfiable case.

In this reduction, \(B=R=0\), since the slack is zero and the report domain is a singleton. Thus hardness persists even when evaluating the regret certificate itself is trivial.

4. Existence, uniqueness, and exact representation

Let

\(N=\bigl|\{(t,S):q^\mu_{t,S}>0\}\bigr|.\)

The greedy procedure allocates each supported type only its listed desired bundles and possibly \(\emptyset\), so

\(N\leq\tau(b+1).\)

4.1. The optimizer exists and is unique

The point \(w=0\), with every slack equal to \(1\), is feasible and has objective \(C\), because the training masses sum to \(1\).

On the feasible objective sublevel set with objective at most \(C\),

\(\|w\|_2^2\leq2C,\qquad 0\leq\xi_{t,S}\leq1/q^\mu_{t,S}.\)

This set is nonempty, closed, and bounded in a finite-dimensional space. It is therefore compact, and the continuous objective attains its minimum.

Any two optimizers with different weights would have a feasible midpoint with strictly smaller objective, by strict convexity of the squared norm and linearity of the slack penalty. Thus the optimal weights are unique.

For fixed weights, every slack has a positive objective coefficient and must equal its smallest feasible value:

\(\displaystyle \xi_{t,S} = \max\left\{0,\max_{S'\subseteq[m]} \left[\mathbf1_{S\ne S'}+f_w(\mu,t,S')-f_w(\mu,t,S)\right]\right\}. \)

Hence the slacks, and therefore the entire optimizer, are unique.

The positivity promise means this unrestricted optimizer is also the requested optimizer satisfying \(w_1>0\).

4.2. The optimizer has polynomial-length rational coordinates

For completeness, the exponentially many constraints do not force an exponentially long numerical output.

Write the expanded program as minimizing

\(F(x)=\frac12x^{\mathsf T}Qx+c^{\mathsf T}x\)

subject to \(Ax\geq h\), where \(x=(w,\xi)\) has dimension \(k=d+1+N\), and \(Q=\operatorname{diag}(I_{d+1},0_N)\). Every coefficient has bit length \(O(L)\).

At the unique optimizer \(x^*\), choose a maximal linearly independent collection \(E\) of active constraint rows, with right-hand side \(h_E\). It has at most \(k\) rows.

For every \(u\in\ker E\), sufficiently small movements \(x^*\pm\varepsilon u\) are feasible: all active rows remain equalities, and the finitely many inactive inequalities retain their positive gaps. Optimality therefore implies

\((Qx^*+c)^{\mathsf T}u=0.\)

Thus some vector \(\lambda\) satisfies

\(Qx^*+c=E^{\mathsf T}\lambda,\qquad Ex^*=h_E.\)

The coefficient matrix of this linear system is nonsingular. Indeed, a homogeneous solution \((u,v)\) satisfies \(Qu=E^{\mathsf T}v\) and \(Eu=0\). Multiplication by \(u^{\mathsf T}\) gives \(u^{\mathsf T}Qu=0\), hence \(Qu=0\). Independence of the rows of \(E\) then gives \(v=0\). If \(u\ne0\), small feasible movements along \(u\) would leave the objective unchanged, contradicting uniqueness. Therefore \(u=0\).

This nonsingular rational system has dimension at most \(2k\). Clearing denominators and applying determinant bounds shows that its solution has bit length \(\operatorname{poly}(k,L)\). Consequently the optimizer, its price coefficients, and \(B\) all have polynomial-length rational representations in the original parameters.

5. Running times and relation to the cited result

5.1. Exact training by bundle enumeration

Enumerating all bundles produces a rational convex quadratic program with

\(k=d+1+N\)

variables and at most

\(M=N2^m+N\)

inequalities, including nonnegativity of the slacks.

Evaluating a valuation requires at most \(b\) bundle-containment checks. Evaluating the supplied feature circuit takes polynomial time in \(L\). Thus constructing the expanded program takes \(2^m\operatorname{poly}(m,\tau,b,d,L)\) time, and its encoding length is \(2^m\operatorname{poly}(m,\tau,b,d,L)\).

The standard polynomial-time theorem for rational convex quadratic programming applies: the objective has a rational positive-semidefinite quadratic matrix, the constraints are rational and linear, and a finite attained optimum exists as proved above. It yields an exact solution in time polynomial in the expanded encoding length. See [Kozlov, Tarasov, and Khachiyan, *The polynomial solvability of convex quadratic programming*](https://www.mathnet.ru/eng/zvmmf5189).

The resulting bound, including all supplied input, is

\(\displaystyle 2^{O(m)}\operatorname{poly}(m,\tau,L,|\mathcal T|,b,d).\)

In particular, training is polynomial-time solvable for fixed \(m\).

5.2. Computations after training

Once the weights are known:

  • A succinct price representation consists of the supplied feature circuit and the rational coefficients \(-w_{-1}/w_1\).
  • Evaluating that price at any supplied bundle takes polynomial time.
  • Computing \(B\) requires a weighted sum over the \(N\) training pairs.
  • Computing \(R\) requires evaluating utilities only on the explicitly listed tagged-distribution supports and maximizing over the explicitly listed reports.

These computations take \(\operatorname{poly}(m,\tau,L,|\mathcal T|,b,d)\) time. The total input length \(L\) includes every tagged-distribution entry, including those for reports outside the population support.

The cited paper’s Theorem 4.1 gives the finite-agent slack bound conditional on \(w_1>0\); its subsequent discussion discards learned hypotheses with nonpositive \(w_1\). Its tractable training result imposes additional feature and weight structure. These statements are consistent with the hardness above for arbitrary supplied feature circuits.
