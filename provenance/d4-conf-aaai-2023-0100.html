The continuous mirror question, as graded

Given finite agent types \(T\) with rational masses \(\mu_t\) summing to \(1\), resource types \(U\) with per-capita supplies \(\sigma_u\), a compatibility relation, and each type’s permitted rounds \(K_t\) and request \(\rho_t\), choose nonnegative masses \(\lambda_{t,p}\) on full schedules \(p\). Each schedule assigns a compatible resource type in \(\rho_t\) distinct rounds of \(K_t\); require \(\sum_p \lambda_{t,p} \leq \mu_t\) for each \(t\) and \(\sum_{t,p:\,p(r)=u}\lambda_{t,p} \leq \sigma_u\) for each \(u,r\). Maximize \(\sum_{t,p}\lambda_{t,p}\), the mass receiving all requested rounds.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a list \(T\) of \(\tau\) agent types with positive binary-rational masses \(\mu_t\) summing to \(1\); \(\tau\) is the support size, not the number of possible types.
There are \(m\geq1\) resource types \(U\), with nonnegative binary-rational per-capita supplies \(\sigma_u\), available separately in each of \(k\geq1\) explicitly represented rounds. Supplies need not sum to \(1\).
The input specifies a round-independent compatibility relation \(C\subseteq T\times U\), and, for each \(t\), an explicit set \(K_t\subseteq\{1,\ldots,k\}\) and an integer request \(1\leq\rho_t\leq|K_t|\).
Let \(P_t\) consist of all schedules \(p:D_p\to U\) with \(D_p\subseteq K_t\), \(|D_p|=\rho_t\), and \((t,p(r))\in C\) for every \(r\in D_p\). Resource types may repeat across rounds; schedules are implicit, not listed in the input.
An allocation assigns real masses \(\lambda_{t,p}\geq0\), subject to \(\sum_{p\in P_t}\lambda_{t,p}\leq\mu_t\) and \(\sum_{t\in T}\sum_{p\in P_t:\,r\in D_p,\,p(r)=u}\lambda_{t,p}\leq\sigma_u\) for every \(u,r\).
The objective is to maximize the fully satisfied mass \(\sum_{t\in T}\sum_{p\in P_t}\lambda_{t,p}\); unallocated mass receives no service. Let \(L\) be the total binary input length.

Is this continuous optimization problem solvable in time polynomial in \(m,\tau,k,L\), or is it \(\mathrm{NP}\)-hard?

For discrete agents and individual resources, maximizing the number of fully satisfied agents is \(\mathrm{NP}\)-hard even for \(k=3\); deciding whether everyone can be satisfied is polynomial-time solvable. [Source](https://ojs.aaai.org/index.php/AAAI/article/download/26380/26152)
No result settling the exact continuous model above was located in the literature search.

Modeling choices made when packaging the task

  • Specified supplies as nonnegative binary rationals, without normalization; each supply is available anew in every round.
  • Specified positive integer requests bounded by the number of permitted rounds, matching the intended satisfaction benefit with zero benefit for no service.
  • Made compatibility round-independent and allowed the same resource type in multiple rounds, consistent with independent per-round matchings.
  • Specified rounds and permitted-round sets explicitly, while full schedules remain implicit; L denotes total binary input length.
  • Specified allocation masses as nonnegative reals and assigned no service to unallocated mass, as in the graded full-schedule formulation.

Polynomial-time solvability

The exact continuous problem is solvable in time polynomial in \(m,\tau,k,L\). It admits a polynomial-size linear program. The key is that its marginal variables can always be decomposed into fully satisfying schedules; this is proved constructively below.

1. A compact linear program

For each type \(t\), let \(A_t=\{u\in U:(t,u)\in C\}\).

Introduce a variable \(x_t\) for the satisfied mass of type \(t\), and variables \(y_{t,r,u}\) for \(r\in K_t\), \(u\in A_t\), representing the mass of that type using resource \(u\) in round \(r\).

Consider the following linear program:

\(\displaystyle \begin{aligned} \text{maximize}\quad &\sum_{t\in T}x_t\\ \text{subject to}\quad &0\leq x_t\leq\mu_t &&(t\in T),\\ &y_{t,r,u}\geq0 &&(t\in T,\ r\in K_t,\ u\in A_t),\\ &\sum_{u\in A_t}y_{t,r,u}\leq x_t &&(t\in T,\ r\in K_t),\\ &\sum_{r\in K_t}\sum_{u\in A_t}y_{t,r,u}=\rho_t x_t &&(t\in T),\\ &\sum_{\substack{t\in T:\\r\in K_t,\ u\in A_t}}y_{t,r,u}\leq\sigma_u &&(u\in U,\ r\in\{1,\ldots,k\}). \end{aligned} \)

Empty sums are zero. In particular, if \(A_t=\varnothing\), the equality and \(\rho_t\geq1\) force \(x_t=0\).

The per-round constraint is essential: a satisfied mass \(x_t\) can receive at most \(x_t\) units of service in any one round.

2. Every schedule allocation yields a feasible LP solution

Given a feasible allocation \(\lambda\), define

\(\displaystyle x_t=\sum_{p\in P_t}\lambda_{t,p}, \qquad y_{t,r,u}= \sum_{\substack{p\in P_t:\\r\in D_p,\ p(r)=u}}\lambda_{t,p}. \)

The mass and resource constraints follow directly from the allocation constraints.

For any fixed type and round, each schedule uses at most one resource. Consequently,

\(\displaystyle \sum_{u\in A_t}y_{t,r,u} =\sum_{\substack{p\in P_t:\\r\in D_p}}\lambda_{t,p} \leq x_t. \)

Every schedule uses exactly \(\rho_t\) rounds, so

\(\displaystyle \sum_{r\in K_t}\sum_{u\in A_t}y_{t,r,u} =\sum_{p\in P_t}|D_p|\lambda_{t,p} =\rho_t x_t. \)

Thus the resulting LP solution is feasible and has the same objective value.

3. Constructive decomposition lemma

Lemma. Fix a type \(t\). Suppose nonnegative numbers \(x\) and \(y_{r,u}\), indexed by \(r\in K_t\), \(u\in A_t\), satisfy

\(\displaystyle v_r:=\sum_{u\in A_t}y_{r,u}\leq x, \qquad \sum_{r\in K_t}v_r=\rho_t x. \)

Then there are nonnegative schedule masses \(\lambda_p\) satisfying

\(\displaystyle \sum_{p\in P_t}\lambda_p=x, \qquad \sum_{\substack{p\in P_t:\\r\in D_p,\ p(r)=u}}\lambda_p=y_{r,u}. \)

Moreover, a decomposition can be found in polynomial time when the given numbers are rational.

Proof. If \(x=0\), nonnegativity and the total-service equality imply that all \(y_{r,u}=0\). The empty allocation suffices.

Suppose \(x>0\). We repeatedly extract a schedule from the current residual values.

Call a round tight if \(v_r=x\), and positive if \(v_r>0\). There are at most \(\rho_t\) tight rounds: if their number is \(h\), then

\(\displaystyle h x\leq\sum_r v_r=\rho_t x.\)

There are at least \(\rho_t\) positive rounds: if their number is \(s\), then

\(\displaystyle \rho_t x=\sum_r v_r\leq s x.\)

Therefore we can choose a set \(D\subseteq K_t\) of exactly \(\rho_t\) positive rounds containing every tight round. For each \(r\in D\), choose \(u_r\in A_t\) with \(y_{r,u_r}>0\). These choices define a valid schedule \(p\), with domain \(D\) and \(p(r)=u_r\).

Set

\(\displaystyle \delta= \min\left( \{x\} \cup\{y_{r,u_r}:r\in D\} \cup\{x-v_r:r\in K_t\setminus D\} \right). \)

Every quantity in this minimum is positive: selected entries are positive, and every unselected round is not tight. Thus \(\delta>0\).

Assign mass \(\delta\) to \(p\), and update the residual by

\(\displaystyle x'=x-\delta,\qquad y'_{r,u}= \begin{cases} y_{r,u}-\delta,&r\in D,\ u=u_r,\\ y_{r,u},&\text{otherwise}. \end{cases} \)

These residual values satisfy the same hypotheses:

  • Nonnegativity follows from \(\delta\leq y_{r,u_r}\) and \(\delta\leq x\).
  • For \(r\in D\), the residual round total is \(v'_r=v_r-\delta\leq x-\delta=x'\).
  • For \(r\notin D\), it is \(v'_r=v_r\leq x-\delta=x'\), by the definition of \(\delta\).
  • Exactly \(\rho_t\) entries were reduced by \(\delta\), so

\(\displaystyle \sum_r v'_r=\rho_t x-\rho_t\delta=\rho_t x'. \)

It remains to prove finite termination. If \(x'>0\), the minimum defining \(\delta\) guarantees that either a previously positive entry becomes zero, or a previously non-tight, unselected round becomes tight.

Zero entries never become positive. A tight round stays tight at every subsequent nonterminal step: it must be selected, so its round total and \(x\) decrease by the same amount. Hence these events can occur only finitely many times.

More precisely, writing \(d=|K_t||A_t|\) and \(n=|K_t|\), there are at most \(d+n\) nonterminal steps and one terminal step. The algorithm must therefore reach \(x=0\), at which point all residual entries are zero.

Summing the extracted schedule masses and their coordinate contributions proves the required identities. Repeated occurrences of the same schedule may be combined.

For rational inputs, choose a common denominator \(Q\) equal to the product of their denominators. Every residual value and every extracted \(\delta\) remains an integer multiple of \(1/Q\), because the algorithm uses only sums, differences, comparisons, and minima. The bit length of \(Q\) is bounded by the total initial denominator bit length. All residual values remain bounded by their initial values, so their numerators also have polynomial bit length. Together with the polynomial step bound, this proves polynomial-time constructibility. \(\square\)

4. Exact equivalence

Take any feasible solution of the compact LP. Apply the lemma independently to each type, using \(x=x_t\) and \(y_{r,u}=y_{t,r,u}\).

The resulting schedules belong to \(P_t\): they select exactly \(\rho_t\) distinct rounds from \(K_t\), and use only compatible resources. Repeating a resource across different rounds is allowed by the stated model.

For each type, the decomposition allocates exactly \(x_t\leq\mu_t\). It also preserves every marginal \(y_{t,r,u}\). Therefore the aggregate use of each resource in each round is unchanged and remains at most \(\sigma_u\).

The resulting schedule allocation is feasible and has objective value \(\sum_t x_t\). Combined with Section 2, this proves equality of the two optimal values, with an effective conversion in both directions.

In particular, the compact LP does not merely provide an upper bound: its optimum is attainable in the original continuous model.

5. Polynomial bit complexity

The LP has

\(\displaystyle N=\tau+\sum_{t\in T}|K_t||A_t| \leq\tau+\tau km \)

variables. Including nonnegativity constraints, its number of constraints is \(O(N+\tau k+mk+\tau)\).

Its coefficients are rational. Apart from the supplied masses and supplies, their magnitudes are at most \(k\), since \(1\leq\rho_t\leq k\). Thus its entire binary encoding length is polynomial in \(m,\tau,k,L\).

The feasible region is nonempty because the zero solution is feasible. It is bounded: \(x_t\leq\mu_t\), and every \(y_{t,r,u}\leq x_t\). Consequently, the optimum is finite and attained.

The standard rational linear-programming theorem gives an exact optimal rational solution in time polynomial in the LP’s binary encoding length, with polynomial output bit length; see [Trevisan’s account of polynomial-time linear programming](https://lucatrevisan.wordpress.com/2011/01/24/cs261-lecture-5-linear-programming/). All its hypotheses hold here.

Finally, the decomposition lemma converts that solution into an explicit allocation with only polynomially many positive schedule masses, also in polynomial time.

This settles the requested continuous model. The discrete hardness result is consistent with this conclusion: indivisible agents cannot be split into the fractional schedule masses used by the decomposition.
