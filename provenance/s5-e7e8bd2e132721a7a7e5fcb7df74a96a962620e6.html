The continuous mirror question, as graded

Given a finite set of roommate types \(T\), rational masses \(\mu_t>0\) summing to \(1\), and a strict ranking \(\succ_t\) of partner types for each \(t\), represent pairings by masses \(x_{tu}=x_{ut}\ge 0\) with \(\sum_{u\ne t}x_{tu}+2x_{tt}=\mu_t\). For distinct types \(t,u\), let \(b_t(u)\) be the mass of type \(t\) assigned partners it ranks below \(u\); require \(b_t(u)=0\) or \(b_u(t)=0\), and require \(b_t(t)=0\) to rule out same-type blocking. Determine the entire stable-pairing set in a finite-union-of-rational-polyhedra representation when it is nonempty; otherwise return a feasible pairing that is Pareto efficient under type-level first-order stochastic dominance.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a nonempty list \(T\) of \(\tau\) types with positive binary-rational masses \(\mu_t\), where \(\sum_{t\in T}\mu_t=1\). The support size \(\tau\) counts listed types, not possible preference types; here the number of partner types is \(m=\tau\). Let \(L\) be the total input bit length.
Each type \(t\) has a strict complete ranking \(\succ_t\) of \(T\), including \(t\); every partner type is acceptable. Same-type partners are distinct individuals, and nobody remains single.
A feasible pairing has real masses \(x_{tu}=x_{ut}\geq0\) satisfying \(\sum_{u\neq t}x_{tu}+2x_{tt}=\mu_t\). Define assigned-person masses \(a_t(u)=x_{tu}\) for \(u\neq t\), and \(a_t(t)=2x_{tt}\).
Put \(b_t(u)=\sum_{v:\,u\succ_t v}a_t(v)\). A pairing is stable exactly when \(b_t(u)=0\) or \(b_u(t)=0\) for every distinct \(t,u\), and \(b_t(t)=0\) for every \(t\).
The partner distribution of type \(t\) is \(q_t(u)=a_t(u)/\mu_t\). A feasible pairing is Pareto efficient if no feasible pairing weakly improves every \(q_t\) under first-order stochastic dominance and strictly improves at least one.
The computational problem is to output the entire stable-pairing set, when nonempty, as an explicit finite list of polyhedra in the \(x\)-coordinates defined by binary-rational linear inequalities; otherwise output a rational Pareto-efficient feasible pairing. No minimality or irredundancy of the list is required.

Is this representation-and-fallback problem solvable in time polynomial in \(m,\tau,L\), including the time to write the output, or is it NP-hard?

For finite societies with an even positive number of agents and strict complete preferences, Evci establishes full implementation of the stable-matching set when it exists and a Pareto-efficient outcome otherwise, without a polynomial-time bound. [Source](https://www.econstor.eu/bitstream/10419/159813/1/wp0975.pdf)
Chen, Roy and Sorge give polynomial-time algorithms for finding ordinally stable fractional roommate matchings and, with strict preferences, maximizing the number of fully matched agents in their unit-capacity, loopless model; these results do not address the unequal-mass, same-type, entire-set output problem above. [Source](https://arxiv.org/pdf/2011.12259)

Modeling choices made when packaging the task

  • Rankings are strict complete orders over all supported partner types, including the agent's own type; all partner types are acceptable.
  • Diagonal pairing mass represents pairs of distinct individuals of the same type, not individuals paired with themselves; it contributes twice its value to assigned-person mass.
  • Type-level stochastic dominance compares normalized partner distributions, and Pareto efficiency is relative to all feasible pairings.
  • The number of partner types is m = tau, and L is the total binary input length.
  • The requested union is an explicit list of rational inequality descriptions in the original pairing coordinates, without minimality or irredundancy requirements; polynomial running time includes writing this list.
  • Pairings range over real masses, while the fallback output must have rational coordinates.

Conclusion

The requested algorithm cannot run in polynomial time including output. There are instances with a nonempty stable set for which every exact list requires \(2^{\Omega(\tau)}\) polyhedra, regardless of redundancy or the inequalities used.

Moreover, optimizing a linear objective over these stable sets is NP-hard. The output-size obstruction is unconditional; it does not depend on whether \(\mathrm{P}=\mathrm{NP}\).

1. A graph-based construction

Let \(G=(V,E)\) be a simple graph with \(V=\{1,\ldots,n\}\), where \(n\geq 1\). For each vertex \(i\), introduce four types \(u_i,w_i,z_i,y_i\).

Choose
\(H=2^{\lceil\log_2(4n)\rceil}\)
and give every introduced type mass \(h=1/H\). If \(4n<H\), add a type \(d\) of mass \((H-4n)/H\). Thus every mass is positive and dyadic, and the total mass is one.

The rankings are specified by the following prefixes. After the displayed prefix, append every remaining type in an arbitrary strict order.

| Type | Ranking prefix |
|---|---|
| \(u_i\) | \(w_i\succ_{u_i}[u_j:\{i,j\}\in E]\succ_{u_i}y_i\succ_{u_i}u_i\) |
| \(w_i\) | \(z_i\succ_{w_i}u_i\succ_{w_i}w_i\) |
| \(z_i\) | \(y_i\succ_{z_i}w_i\succ_{z_i}z_i\) |
| \(y_i\) | \(u_i\succ_{y_i}z_i\succ_{y_i}y_i\) |

The bracketed neighbors are strictly ordered arbitrarily. If present, \(d\) ranks itself first.

These are strict complete rankings, with every partner type acceptable. The construction has \(\tau=4n\) or \(\tau=4n+1\), and input length \(L=O(n^2\log(n+1))\).

The four-type construction is adapted from Figure 3 in [Chen, Roy and Sorge](https://arxiv.org/pdf/2011.12259). The argument below verifies its behavior directly for the model in the question.

2. Exact characterization of the stable set

Proposition. The stable pairings of the constructed society are in affine bijection with

\(K(G)=\{\alpha\in[0,1]^n:\alpha_i=0\text{ or }\alpha_j=0\text{ for every }\{i,j\}\in E\}\).

For the pairing corresponding to \(\alpha\), its nonzero coordinates within gadget \(i\) are

\(x_{u_iw_i}=x_{z_iy_i}=h(1-\alpha_i)\),

\(x_{w_iz_i}=x_{y_iu_i}=h\alpha_i\).

All other coordinates involving gadget types vanish. If \(d\) is present, \(x_{dd}=\mu_d/2\).

Proof: every stable pairing has this form

First, the condition \(b_t(t)=0\) excludes every assignment to a partner ranked below \(t\) itself: each such assigned-person mass is a nonnegative summand of \(b_t(t)\).

Consequently, a gadget type can receive only its displayed partners or itself. The additional type \(d\), if present, can receive only itself.

Fix gadget \(i\), and write

\(p_i=x_{u_iw_i}/h,\quad q_i=x_{w_iz_i}/h,\quad r_i=x_{z_iy_i}/h,\quad s_i=x_{y_iu_i}/h\).

For each gadget type \(t\), let \(\delta_t=2x_{tt}/h\). Let

\(e_i=\sum_{j:\{i,j\}\in E}x_{u_iu_j}/h\).

The feasibility equations are

\(p_i+s_i+e_i+\delta_{u_i}=1\),

\(p_i+q_i+\delta_{w_i}=1\),

\(q_i+r_i+\delta_{z_i}=1\),

\(r_i+s_i+\delta_{y_i}=1\).

We next prove that the last three self-assignment quantities vanish.

  • If \(\delta_{w_i}>0\), then \(p_i<1\). Because \(w_i\) is \(u_i\)'s first choice, \(b_{u_i}(w_i)=h(1-p_i)>0\). Also \(b_{w_i}(u_i)=h\delta_{w_i}>0\). This contradicts stability of the pair \(u_i,w_i\).
  • If \(\delta_{z_i}>0\), then \(q_i<1\). Hence \(b_{w_i}(z_i)=h(1-q_i)>0\) and \(b_{z_i}(w_i)=h\delta_{z_i}>0\), again contradicting stability.
  • If \(\delta_{y_i}>0\), then \(r_i<1\). Hence \(b_{z_i}(y_i)=h(1-r_i)>0\) and \(b_{y_i}(z_i)=h\delta_{y_i}>0\), contradicting stability.

Thus

\(p_i+q_i=q_i+r_i=r_i+s_i=1\).

It follows that \(r_i=p_i\), \(s_i=q_i=1-p_i\), and therefore \(p_i+s_i=1\). The feasibility equation for \(u_i\) now gives

\(e_i+\delta_{u_i}=0\).

Both terms are nonnegative, so both vanish. In particular, there are no assignments between different gadgets and no self-assignments within any gadget.

Set \(\alpha_i=s_i\). We have obtained exactly the claimed coordinates, with \(0\leq\alpha_i\leq1\).

For an edge \(\{i,j\}\in E\), the only assigned partner of \(u_i\) ranked below \(u_j\) is \(y_i\). Therefore

\(b_{u_i}(u_j)=h\alpha_i,\qquad b_{u_j}(u_i)=h\alpha_j\).

Stability consequently requires \(\alpha_i=0\) or \(\alpha_j=0\).

Proof: every point of \(K(G)\) gives a stable pairing

Take \(\alpha\in K(G)\) and assign the coordinates stated in the proposition. Each gadget type receives total assigned-person mass \(h\), so feasibility holds.

For the four internal pairs, respectively, the following quantities vanish:

\(b_{w_i}(u_i)=0,\quad b_{z_i}(w_i)=0,\quad b_{y_i}(z_i)=0,\quad b_{u_i}(y_i)=0\).

Thus none of those pairs blocks. For each graph edge, the two relevant quantities are \(h\alpha_i\) and \(h\alpha_j\); at least one vanishes by the definition of \(K(G)\).

Every other distinct partner is ranked below self by the relevant gadget type. All its assigned partners are ranked above self, so its worse-assigned mass relative to that partner is zero. The same-type stability conditions also hold. The additional type \(d\), if present, receives only its first choice.

This proves stability and the proposition. In particular, the stable set is always nonempty: choose \(\alpha=0\).

3. Every exact list can require exponentially many polyhedra

Take \(G\) to consist of \(k\) disjoint edges. Thus \(n=2k\) and \(\tau=8k\) or \(\tau=8k+1\).

For each edge, choose exactly one endpoint. Set \(\alpha_i=1\) at the chosen endpoints and \(\alpha_i=0\) elsewhere. There are \(2^k\) choices, and all belong to \(K(G)\). Let their corresponding stable pairings be \(X^\sigma\).

Consider two different choices \(\sigma\) and \(\rho\). They select opposite endpoints \(i,j\) of at least one edge. Their midpoint has

\(\alpha_i=\alpha_j=1/2\),

so it does not belong to \(K(G)\). Since the correspondence in the proposition is affine, the midpoint \((X^\sigma+X^\rho)/2\) is unstable.

Now suppose an exact output list satisfies

\(\mathcal S=\bigcup_{\ell=1}^{R}P_\ell\),

where \(\mathcal S\) is the entire stable set and each \(P_\ell\) is a polyhedron. Exactness implies \(P_\ell\subseteq\mathcal S\) for every \(\ell\). A polyhedron is convex, so it cannot contain two distinct pairings \(X^\sigma,X^\rho\): it would also contain their unstable midpoint.

Every one of the \(2^k\) pairings must nevertheless occur in the union. Hence

\(R\geq2^k\geq2^{(\tau-1)/8}\).

The input length is \(O(k^2\log(k+1))\). Therefore writing these entries already takes more than any polynomial in \(m,\tau,L\), with \(m=\tau\).

This argument permits arbitrary inequalities, overlapping polyhedra, and redundant entries. None can circumvent convexity.

4. The precise NP-hard optimization consequence

For the constructed society, consider the linear objective

\(\Phi(x)=h^{-1}\sum_{i=1}^{n}x_{u_iy_i}\).

Under the characterization above, \(\Phi(x)=\sum_i\alpha_i\). The support

\(I(\alpha)=\{i:\alpha_i>0\}\)

is an independent set of \(G\). Because every \(\alpha_i\leq1\),

\(\sum_i\alpha_i\leq|I(\alpha)|\leq\operatorname{ind}(G)\),

where \(\operatorname{ind}(G)\) is the maximum independent-set cardinality.

Conversely, the indicator vector of any maximum independent set belongs to \(K(G)\) and attains objective value \(\operatorname{ind}(G)\). Thus

\(\max_{x\in\mathcal S}\Phi(x)=\operatorname{ind}(G)\).

The construction is polynomial in the graph input, so deciding whether this maximum is at least a given integer is NP-hard.

Given an explicit polyhedral list, this maximum can be computed by solving one rational linear program per nonempty entry and taking the largest optimum. Every entry is bounded because it is contained in the feasible-pairing set. This postprocessing is polynomial in the input length plus the returned representation length.

Accordingly, a hypothetical polynomial-time representation algorithm would solve Independent Set in polynomial time. For the variable-output problem, the unconditional output lower bound in Section 3 is the stronger and more direct conclusion; the statement here separately identifies its NP-hard optimization content.

5. The Pareto-efficient fallback is obtainable by linear programming

Let \(r_t(u)\in\{1,\ldots,\tau\}\) be the rank of \(u\) for type \(t\), with rank one best. Maximize over feasible pairings the linear objective

\(W(x)=\sum_{t\in T}\sum_{u\in T}(\tau-r_t(u))a_t(u)\).

The feasible set is a nonempty bounded rational polytope: assigning \(x_{tt}=\mu_t/2\) and every off-diagonal coordinate zero is feasible. Standard rational linear programming therefore returns a rational maximizer in polynomial time.

To verify Pareto efficiency, define the top-\(j\) assigned mass

\(C_t(j)=\sum_{u:r_t(u)\leq j}a_t(u)\).

Counting how many top-rank cutoffs contain each partner gives the identity

\(\sum_u(\tau-r_t(u))a_t(u)=\sum_{j=1}^{\tau-1}C_t(j)\).

First-order stochastic dominance weakly increases every \(C_t(j)\), since \(\mu_t>0\) is fixed. Strict improvement of at least one distribution increases at least one proper-cutoff cumulative mass. It therefore strictly increases \(W\), contradicting maximality.

Thus every maximizer is Pareto efficient. The fallback does not remove the output obstruction, which occurs on instances having stable pairings.

2. Necessary form of every stable pairing

The first exclusion is valid: because all assigned-person masses are nonnegative, \(b_t(t)=0\) forces every mass assigned below self to vanish. This accounts for the factor of two on diagonal pairing coordinates through \(a_t(t)=2x_{tt}\).

Consequently, the four feasibility equations list every assignment still permitted within a gadget, including neighboring \(u\)-types and self-assignment.

Each contradiction eliminating self-assignment is correct:

  • If \(\delta_{w_i}>0\), feasibility gives \(p_i<1\). Since \(w_i\) is \(u_i\)’s first choice, \(b_{u_i}(w_i)=h(1-p_i)>0\). Among permitted assignments for \(w_i\), only self lies below \(u_i\), giving \(b_{w_i}(u_i)=h\delta_{w_i}>0\).
  • If \(\delta_{z_i}>0\), the analogous quantities for \(w_i,z_i\) are \(h(1-q_i)>0\) and \(h\delta_{z_i}>0\).
  • If \(\delta_{y_i}>0\), the corresponding quantities for \(z_i,y_i\) are \(h(1-r_i)>0\) and \(h\delta_{y_i}>0\).

Each contradicts exactly the distinct-type stability condition in the task.

The subsequent algebra is correct:
\[ p_i+q_i=q_i+r_i=r_i+s_i=1 \]
implies \(r_i=p_i\) and \(s_i=q_i=1-p_i\). Thus the remaining feasibility equation gives \(e_i+\delta_{u_i}=0\). Nonnegativity forces both quantities to vanish and, individually, every inter-gadget assignment in the sum defining \(e_i\) to vanish.

Setting \(\alpha_i=s_i\) yields the stated coordinates and \(0\leq\alpha_i\leq1\). For a graph edge, \(w_i\) is above the neighboring \(u_j\), while \(y_i\) is below it; all other assignment masses vanish. Hence
\[ b_{u_i}(u_j)=h\alpha_i. \]
The corresponding equality at the other endpoint proves the necessary condition defining \(K(G)\).

The same-type conditions also hold. Thus the sufficiency argument covers every required pair.

The correspondence is affine and injective, since each parameter can be recovered as \(\alpha_i=x_{y_iu_i}/h\). Together with necessity, this proves the claimed affine bijection. The choice \(\alpha=0\) proves nonemptiness.

4. Exponential lower bound for every exact list

For \(k\) disjoint edges, the \(2^k\) selected endpoint vectors all belong to \(K(G)\).

Two distinct selections differ on at least one edge. Their midpoint has both endpoint parameters equal to \(1/2\), violating that edge’s defining condition. The affine correspondence therefore makes the midpoint of the associated pairings unstable.

The convexity argument is valid for arbitrary polyhedra in the required coordinates:

  • Exact equality of the union with the stable set forces every listed polyhedron to be contained in that set.
  • A polyhedron containing two selected pairings would contain their unstable midpoint.
  • Therefore each polyhedron covers at most one selected pairing.
  • Covering all selected pairings requires at least \(2^k\) entries.

The numerical bound is correct:
\[ R\geq2^k\geq2^{(\tau-1)/8}. \]

The input length is polynomial in \(k\), while this entry count is exponential in \(k\). An explicit list requires writing each entry, so the lower bound excludes polynomial time in \(m,\tau,L\), including output time. Overlap, redundancy, and alternative inequalities do not affect the argument.

5. NP-hard optimization consequence

The objective satisfies
\[ \Phi(x)=\sum_i\alpha_i. \]
The positive support of every \(\alpha\in K(G)\) is an independent set, and \(\alpha_i\leq1\). Therefore its objective value is at most the maximum independent-set cardinality. Conversely, the indicator vector of a maximum independent set belongs to \(K(G)\) and attains that cardinality.

The postprocessing claim also holds. Each nonempty listed polyhedron is bounded because exactness places it inside the bounded feasible-pairing set. Rational linear programming can optimize over each entry, with total time polynomial in the input and returned representation length.

The prover correctly limits this consequence: postprocessing an exponentially long list need not take polynomial time in the original input. No formal polynomial-time reduction to the representation problem itself is supplied or needed for the unconditional output obstruction.

6. Pareto-efficient fallback

The feasible set is a nonempty bounded rational polytope. The proposed all-self pairing establishes nonemptiness, and feasibility bounds every coordinate. Its dimension, constraints, and objective coefficients have polynomial encoding length. Thus the stated application of polynomial-time rational linear programming has its hypotheses satisfied.

The cumulative-mass identity is correct: a partner of rank \(r\) contributes to exactly \(\tau-r\) proper top-rank cutoffs.

Since each \(\mu_t>0\) is fixed, stochastic dominance of partner distributions is equivalent to the corresponding inequalities for assigned-person cumulative masses. Strict dominance requires a strict inequality at a proper cutoff; total mass cannot change. Hence any Pareto improvement strictly increases \(W\), contradicting maximality.

The edge case \(\tau=1\) is also valid: feasibility determines the unique pairing, which is Pareto efficient.
