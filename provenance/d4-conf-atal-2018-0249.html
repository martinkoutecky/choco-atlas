The continuous mirror question, as graded

Given candidates \(C\), a target candidate \(p\), four complete ranking types \(t_1,\ldots,t_4\), and rational masses \(\mu_1,\ldots,\mu_4\) summing to \(1\), does some consensus order \(\pi\) minimizing \(\sum_i \mu_i d_{\mathrm{KT}}(\pi,t_i)\) rank \(p\) first?

Packaged proof task (what the prover saw — nothing else)

Given a finite candidate set \(C\), let \(m=|C|\) and \(p\in C\). A society is given by its support: \(\tau=4\) distinct strict total orders \(t_1,\ldots,t_4\) on \(C\), each with a positive binary rational mass \(\mu_i\), where \(\sum_{i=1}^4\mu_i=1\). Here \(\tau\) is the support size, not the number \(m!\) of possible types; let \(L\) be the total input bit length.
A consensus is a strict total order \(\pi\) minimizing \(\sum_{i=1}^4\mu_i d_{\mathrm{KT}}(\pi,t_i)\), using Kendall tau distance. Accept precisely when some minimizing order ranks \(p\) first; no tie-breaking selects among minimizing orders.

Is this decision problem in \(\mathrm{P}\), with running time polynomial in \(m,\tau,L\), or is it \(\mathrm{NP}\)-hard?

For four votes with positive binary integer weights or multiplicities, Kemeny winner determination is \(\Theta_2^p\)-complete; with four unweighted voters it is also \(\Theta_2^p\)-complete. [Source](https://mathcs.holycross.edu/~zfitzsim/papers/Fitzsimmons-Hemaspaandra2019_Article_High-multiplicityElectionProbl.pdf).

Modeling choices made when packaging the task

  • Required positive masses and four distinct ranking types, following the support convention and the high-multiplicity definition.
  • Required strict total orders for both input rankings and consensus orders.
  • Used existential winner status across all minimizing orders, with no tie-breaking.
  • Defined L as the total binary input length.

Result

The problem is \(\Theta_2^p\)-complete, hence \(\mathrm{NP}\)-hard. Hardness holds even when all four masses equal \(\frac14\) and the four support orders are distinct. Consequently, a running time polynomial in \(m,\tau,L\) would imply \(\mathrm{P}=\mathrm{NP}\).

1. Known hardness theorem

We use the following supplied result: determining whether a candidate ranks first in some Kemeny-optimal order for an election with four unweighted voters is \(\Theta_2^p\)-complete. This is Theorem 19 of [Fitzsimmons–Hemaspaandra, *High-multiplicity election problems*](https://mathcs.holycross.edu/~zfitzsim/papers/Fitzsimmons-Hemaspaandra2019_Article_High-multiplicityElectionProbl.pdf).

The four voters’ orders might repeat. Thus, applying this theorem to the present problem requires ensuring four distinct support orders.

2. Reduction to four distinct orders

Let a source instance have candidate set \(C\), distinguished candidate \(p\), and four orders \(v_1,\ldots,v_4\), possibly repeated. Its objective is

\(F(\sigma)=\sum_{i=1}^4 d_{\mathrm{KT}}(\sigma,v_i)\).

Introduce three fresh candidates \(D=\{a,b,c\}\), disjoint from \(C\). Choose four distinct orders on \(D\):

\(s_1=(a,b,c),\quad s_2=(a,c,b),\quad s_3=(b,a,c),\quad s_4=(b,c,a)\).

For each \(i\), construct \(t_i\) by listing \(C\) in order \(v_i\), followed by \(D\) in order \(s_i\). Set \(\mu_i=\frac14\).

These are four distinct strict total orders: their restrictions to \(D\) are distinct. Their masses are positive binary rationals summing to \(1\). The construction adds only three candidates and has polynomial output length.

3. Exact preservation of optimality and winners

Kendall tau distance counts unordered candidate pairs whose relative orders disagree.

For an order \(\pi\) on \(C\cup D\), let \(\pi_C\) and \(\pi_D\) denote its restrictions to \(C\) and \(D\). Define

\(G(\rho)=\frac14\sum_{i=1}^4 d_{\mathrm{KT}}(\rho,s_i)\),

and let \(I(\pi)\) be the number of pairs \((x,d)\in C\times D\) for which \(\pi\) ranks \(d\) above \(x\).

Every \(t_i\) ranks every original candidate above every fresh candidate. Partitioning candidate pairs into pairs within \(C\), within \(D\), and between the two sets therefore gives the exact identity

\(F'(\pi):=\frac14\sum_{i=1}^4 d_{\mathrm{KT}}(\pi,t_i)=\frac14F(\pi_C)+G(\pi_D)+I(\pi)\).

Let

\(K=\min_{\sigma\text{ on }C}F(\sigma),\qquad H=\min_{\rho\text{ on }D}G(\rho)\).

Both minima exist because the sets of orders are finite. Since \(I(\pi)\geq 0\), every order satisfies

\(F'(\pi)\geq \frac14K+H\).

Equality is attainable: concatenate an order attaining \(K\) with an order attaining \(H\). This concatenation has \(I(\pi)=0\). Consequently,

\(\min_{\pi\text{ on }C\cup D}F'(\pi)=\frac14K+H\).

Moreover, if \(\pi\) minimizes \(F'\), then

\(0=\frac14\bigl(F(\pi_C)-K\bigr)+\bigl(G(\pi_D)-H\bigr)+I(\pi)\).

All three summands are nonnegative, so each equals zero. In particular, \(\pi_C\) minimizes the original objective.

We now obtain both directions of winner preservation:

  • If some original minimizing order ranks \(p\) first, concatenate it with a minimizing order on \(D\). The resulting order minimizes \(F'\) and ranks \(p\) first.
  • If some minimizing order for the constructed instance ranks \(p\) first, its restriction to \(C\) is an original minimizing order and still ranks \(p\) first.

Thus the reduction preserves acceptance exactly, including the existential treatment of tied optimal orders. The known theorem proves \(\Theta_2^p\)-hardness.

4. Membership in \(\Theta_2^p\)

This upper bound also accommodates arbitrary binary rational masses.

Write \(\mu_i=a_i/b_i\), with positive binary integers \(a_i,b_i\). Set

\(Q=\prod_{i=1}^4b_i,\qquad w_i=a_i\prod_{j\neq i}b_j\).

Then \(Q\mu_i=w_i\), so multiplying the objective by \(Q>0\) preserves every minimizing order. These integers have bit length polynomial in \(L\).

Let \(N=\binom m2\). Every order’s integer objective belongs to the explicitly enumerable set

\(S=\left\{\sum_{i=1}^4w_i k_i:\ (k_1,k_2,k_3,k_4)\in\{0,\ldots,N\}^4\right\}\).

This set has at most \((N+1)^4\) elements, each of polynomial bit length.

For every \(s\in S\), ask in one parallel round two \(\mathrm{NP}\) queries: whether an order has objective at most \(s\), and whether such an order exists with \(p\) first. A certificate is the order itself; its score and first candidate can be checked in polynomial time.

The smallest accepted threshold in each family is its corresponding optimum, because both optima belong to \(S\). Acceptance is exactly equality of these two optima. Hence the problem lies in \(\mathrm{P}^{\mathrm{NP}}_{\parallel}=\Theta_2^p\).

Together with the reduction, this proves \(\Theta_2^p\)-completeness.
