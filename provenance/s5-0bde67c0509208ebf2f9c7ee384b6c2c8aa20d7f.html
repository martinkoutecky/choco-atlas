Theorem 5.1 — class: other

The continuous mirror question, as graded

Given candidates \(C\), delegate count \(D\), a finite support \(T\) of plurality ballot types with binary-rational masses \(\mu_t\) summing to \(1\), a viable set \(\mathcal V\), and a claimed integer allocation \(a\) summing to \(D\), let \(Q=\sum_{t:\,\mathrm{first}(t)\in\mathcal V}\mu_t>0\) and \(p_c=\sum_{t:\,\mathrm{first}(t)=c}\mu_t/Q\). With a fixed tie rule, decide whether Hamilton largest-remainder allocation from \((p_c)_{c\in\mathcal V}\) and \(D\) yields \(a\).

Packaged proof task (what the prover saw — nothing else)

Let \(C\) be a candidate set with \(m=|C|\geq 1\). A society is given by its support: a list \(T\) of \(\tau\) plurality ballot types with positive binary-rational masses \(\mu_t\), summing to \(1\); \(\tau\) is the support size, not the number of possible types. Each type selects one candidate or abstains, denoted by \(\mathrm{first}(t)\in C\cup\{\bot\}\).
The input also gives a nonempty eligible set \(\mathcal V\subseteq C\), a positive integer delegate count \(D\), and a claimed allocation \(a\in\mathbb Z_{\geq 0}^{\mathcal V}\) with \(\sum_{c\in\mathcal V}a_c=D\). Integers are binary encoded; candidates outside \(\mathcal V\) receive zero delegates. Eligibility is supplied, rather than tested.
Define qualified mass \(Q=\sum_{t:\mathrm{first}(t)\in\mathcal V}\mu_t>0\) and qualified shares \(p_c=Q^{-1}\sum_{t:\mathrm{first}(t)=c}\mu_t\) for \(c\in\mathcal V\). Use Hamilton largest-remainder apportionment with a fixed total priority order on candidate identifiers to resolve equal remainders; ties are allowed.
Let \(L\) be the total input bit length. State running times in \(m,\tau,L\), and \(\log(D+1)\).

Is deciding whether Hamilton apportionment of \(D\) delegates from \((p_c)_{c\in\mathcal V}\) equals \(a\) in \(\mathrm P\), or is it \(\mathrm{NP}\)-hard?

For finite ballots, an incorrect allocation violates at least one strict pairwise assertion \(p_u>p_v+(a_u-a_v-1)/D\), for distinct \(u,v\in\mathcal V\); this is a sufficient certificate of correctness, not an equivalence covering ties. [Source](https://arxiv.org/pdf/2102.08510). No complexity classification for the support-encoded mass problem is established by that result.

Modeling choices made when packaging the task

  • Plurality ballots may select no candidate; represented abstentions by a symbol excluded from qualified mass.
  • Specified a positive binary-encoded delegate count and a nonnegative integer claimed allocation indexed by eligible candidates, with zero delegates outside that set.
  • Made the fixed tie rule a total priority order on candidate identifiers and retained equal-remainder instances.
  • Treated the viable set as supplied eligibility for the allocation stage, without adding a viability threshold or testing eligibility.
  • Defined L as total input bit length and required running-time dependence on the binary length of D.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

The decision problem is in \(\mathrm P\). Exact integer arithmetic computes Hamilton’s allocation in time polynomial in the input length, even when the binary-encoded delegate count is large.

1. Converting masses to integer weights

Let \(k=|\mathcal V|\), and write each supplied mass as \(\mu_t=n_t/d_t\), where \(n_t,d_t\) are positive binary-encoded integers. This also covers dyadic rational masses.

Define \(H=\prod_{t\in T}d_t\) and \(w_t=n_t(H/d_t)\). Each \(w_t\) is an integer, and \(\mu_t=w_t/H\). For every eligible candidate, compute
\[ W_c=\sum_{t:\mathrm{first}(t)=c}w_t, \qquad W=\sum_{c\in\mathcal V}W_c. \]
Here and below, equivalently in inline notation, \(W_c=\sum_{t:\mathrm{first}(t)=c}w_t\) and \(W=\sum_{c\in\mathcal V}W_c\).

The hypothesis \(Q>0\) gives \(W>0\). Moreover, \(Q=W/H\), so the qualified shares are exactly \(p_c=W_c/W\). Thus neither abstentions nor support types selecting ineligible candidates contribute to the allocation weights.

The common denominator has polynomial bit length: \(\log_2 H=\sum_t\log_2 d_t\leq L\). Since the masses sum to one, \(\sum_t w_t=H\). Consequently, \(0\leq W_c\leq W\leq H\), and all these weights have \(\mathcal O(L)\) bits.

2. Computing Hamilton’s allocation exactly

For each \(c\in\mathcal V\), use integer division to obtain the unique quotient and remainder satisfying \(DW_c=b_cW+s_c\), with \(0\leq s_c<W\). Dividing by \(W\) shows that \(Dp_c=b_c+s_c/W\). Therefore \(b_c=\lfloor Dp_c\rfloor\), and the fractional remainder of candidate \(c\) is exactly \(s_c/W\).

Set \(R=D-\sum_{c\in\mathcal V}b_c\). Summing the quotient-remainder identities and using \(\sum_cW_c=W\) gives \(RW=\sum_cs_c\). Hence \(R\) is an integer satisfying \(0\leq R<k\), because \(0\leq\sum_cs_c<kW\).

Sort eligible candidates by decreasing \(s_c\), breaking equal values according to the specified priority order. Let \(S\) contain the first \(R\) candidates in this order, with \(S=\varnothing\) when \(R=0\). Define \(h_c=b_c+1\) for \(c\in S\), and \(h_c=b_c\) otherwise.

This is precisely Hamilton apportionment: the initial allocation consists of the quota floors, and the remaining delegates go to the candidates with the largest fractional remainders. Comparing the integers \(s_c\) compares those remainders exactly because their common denominator \(W\) is positive. Equal remainders are resolved by the prescribed priority.

The algorithm accepts exactly when \(a_c=h_c\) for every \(c\in\mathcal V\). This proves correctness in both directions, including ties, zero-share eligible candidates, and the case \(k=1\).

3. Bit complexity

Let \(\ell=\lceil\log_2(D+1)\rceil\) and \(B=L+\ell+2\). Every integer used above has \(\mathcal O(B)\) bits: in particular, \(DW_c\leq DH\), and \(b_c\leq D\).

Using ordinary quadratic-time integer multiplication and division:

  • Constructing \(H\), converting the \(\tau\) support masses, and accumulating weights takes \(\mathcal O((m+\tau)B^2)\) bit operations.
  • Computing the \(k\) quotient-remainder pairs and comparing the allocation takes \(\mathcal O(mB^2)\) bit operations.
  • Sorting takes \(\mathcal O(m\log(m+1)B)\) bit operations, using candidate priority ranks to resolve ties.

Thus, under the usual explicit encoding of candidate identifiers and their fixed priority, a valid overall bound is \(\mathcal O((m+\tau)B^2+m\log(m+1)B)\).

For explicit input lists, \(m,\tau=\mathcal O(L)\), and the binary encoding of \(D\) gives \(\ell=\mathcal O(L)\). The bound is therefore \(\mathcal O(L^3)\). There is no iteration over the delegates or over unlisted ballot types.

4. Relation to the strict pairwise assertions

The cited paper’s sufficient correctness assertions are not needed for this algorithm. Its pairwise audit result appears in Equation 1 and Theorem 1 of [*Auditing Hamiltonian Elections*](https://arxiv.org/pdf/2102.08510).

Indeed, take two eligible candidates with \(p_u=p_v=1/2\), \(D=1\), and priority favoring \(u\). Hamilton correctly gives \(a_u=1\), \(a_v=0\), but the strict assertion for \((u,v)\) becomes \(1/2>1/2\), which is false. Direct computation handles this boundary exactly.

Accordingly, the problem is polynomial-time solvable. An \(\mathrm{NP}\)-hardness result under polynomial-time many-one reductions would imply \(\mathrm P=\mathrm{NP}\).
