The continuous mirror question, as graded

Given \(\tau\) worker types with rational masses \(\mu_r>0\) summing to \(1\), \(j\ge2\) ordered levels, and a monotone rational polynomial production function \(F(x)\) of fixed degree, where \(x_{r,i}\ge0\) and \(\sum_i x_{r,i}=\mu_r\), let \(x^0_{r,i}=\mu_r/j\). For each type, set \(d_r=\partial_{r,1}F(x^0)-\partial_{r,j}F(x^0)\). Compute the exact rational shares \(\beta_r=\mu_r d_r/\sum_s\mu_s d_s\), given that the denominator is positive.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a list of \(\tau\ge1\) worker types with positive binary-rational masses \(\mu_r\) summing to \(1\); \(\tau\) is the support size, not the number of possible types. There are \(m=j\ge2\) levels, ordered from most important \(1\) to least important \(j\).
Feasible allocations satisfy \(x_{r,i}\ge0\) and \(\sum_{i=1}^j x_{r,i}=\mu_r\). The production function \(F\) is a polynomial in these coordinates, supplied as an explicit list of monomials with binary-rational coefficients and nonnegative integer exponents; its total degree is at most a fixed constant \(D\). Coefficients and output values may have either sign.
Monotonicity means that transferring any feasible amount of one type's mass from level \(i\) to level \(h<i\) never decreases \(F\). This is an input promise. Let \(L\) be the total input bit length.
Set \(x^0_{r,i}=\mu_r/j\), \(d_r=\partial_{r,1}F(x^0)-\partial_{r,j}F(x^0)\), and \(Z=\sum_{s=1}^{\tau}\mu_s d_s\), where \(\partial_{r,i}\) denotes the ambient coordinate partial derivative. Promise \(Z>0\). The computational problem is to return the exact rational shares \(\beta_r=\mu_r d_r/Z\).

Is computing these shares solvable in time polynomial in \(m,\tau,L\) for each fixed \(D\), or is it NP-hard?

For finite workers, the generalized Banzhaf score equals \(j^{-1}\sum_A[V(A_p^1)-V(A_p^j)]\), where the sum ranges over all level assignments and \(A_p^i\) moves worker \(p\) to level \(i\); normalized scores give revenue shares. This is an identity, without a complexity classification ([Pongou, Tchantcho and Tedjeugang, 2012](https://www.scirp.net/journal/paperinformation?paperid=24226)).
No result settling the exact continuous problem above was located in the literature search.

Modeling choices made when packaging the task

  • The polynomial representation was unspecified; chose an explicit monomial list with binary-rational coefficients and nonnegative integer exponents, with total degree bounded by a fixed constant.
  • Interpreted monotonicity as nondecreasing production under feasible transfers toward more important levels, matching the discrete hierarchy, and treated it as a promise.
  • Allowed signed coefficients and signed production values because the discrete production function is real-valued without a nonnegativity restriction.
  • Interpreted the partial derivatives as ambient coordinate derivatives of the supplied polynomial.
  • Set m=j and defined L as total input bit length to make the running-time parameters explicit.

Conclusion

The shares are computable exactly in polynomial time in \(m,\tau,L\) for every fixed \(D\). The explicit monomial representation permits direct evaluation, and all necessary integers have polynomial bit length.

Exact evaluation and correctness

Write the supplied polynomial as
\(F(x)=\sum_{k=1}^{N}c_k\prod_{r=1}^{\tau}\prod_{i=1}^{j}x_{r,i}^{a_{k,r,i}}\),
where \(a_{k,r,i}\) are nonnegative integers and
\(\sum_{r,i}a_{k,r,i}\le D\).

Set \(q_r=\mu_r/j>0\), and evaluate each monomial at the specified allocation:
\(v_k=c_k\prod_{r,i}q_r^{a_{k,r,i}}\).

Because every \(q_r\) is positive, differentiating a monomial gives
\(\partial_{r,i}\bigl(c_k\prod_{s,h}x_{s,h}^{a_{k,s,h}}\bigr)(x^0)=a_{k,r,i}v_k/q_r\).
This identity also holds when the exponent or coefficient is zero.

Define
\(g_r=\sum_{k=1}^{N}(a_{k,r,1}-a_{k,r,j})v_k\).
Then
\(d_r=g_r/q_r=(j/\mu_r)g_r\), so
\(\mu_r d_r=jg_r\).
Consequently,
\(Z=j\sum_{s=1}^{\tau}g_s\), and the desired answer is exactly
\(\beta_r=g_r/\sum_{s=1}^{\tau}g_s\).

Thus the algorithm evaluates each monomial once, accumulates its contributions to the \(g_r\), and normalizes their sum. The promise \(Z>0\) guarantees that the denominator is positive.

Each monomial has at most \(D\) coordinates with positive exponents. Hence, after reading the input, evaluating all monomials and accumulating their contributions requires \(O(ND+\tau)\) rational arithmetic operations. It remains to bound their bit complexity.

Polynomial bit complexity

Write the input rationals as
\(c_k=A_k/B_k\) and \(\mu_r=u_r/v_r\), with integer numerators and positive integer denominators in binary. Define the positive integers
\(Q=j\bigl(\prod_{k=1}^{N}B_k\bigr)\bigl(\prod_{r=1}^{\tau}v_r\bigr)\)
and \(T=Q^{D+1}\).

The denominator of each coefficient divides \(Q\). The denominator of each \(q_r=u_r/(jv_r)\) also divides \(Q\). Therefore, a monomial of degree \(d\le D\) has denominator dividing \(Q^{d+1}\), which divides \(T\). In particular,
\(h_k=Tv_k\) is an integer.

These integers can be constructed directly. Let
\(C_k=A_k(Q/B_k)\) and \(U_r=u_r(Q/(jv_r))\).
If \(d_k=\sum_{r,i}a_{k,r,i}\), then
\(h_k=C_kQ^{D-d_k}\prod_{r,i}U_r^{a_{k,r,i}}\).
Every division in this construction is exact.

Now accumulate integers
\(H_r=\sum_{k=1}^{N}(a_{k,r,1}-a_{k,r,j})h_k\)
and \(H=\sum_{r=1}^{\tau}H_r\).
Since \(H_r=Tg_r\), the output is simply
\(\beta_r=H_r/H\).
Also, \(Z=jH/T>0\), so \(H>0\).

To bound the integer sizes, the total encoded length of the input denominators gives
\(\log_2 Q=O(L+\log j)\), and hence
\(\log_2 T=O((D+1)(L+\log j))\).

Every coordinate \(q_r\) lies in \((0,1]\), and each input coefficient satisfies \(|c_k|\le 2^L\). Therefore
\(|v_k|\le 2^L\) and \(|h_k|\le 2^LT\).
Moreover, for each monomial,
\(\sum_r|a_{k,r,1}-a_{k,r,j}|\le\sum_r(a_{k,r,1}+a_{k,r,j})\le D\).
It follows that both \(|H_r|\) and \(|H|\) are at most \(ND2^LT\).

Thus all accumulated integers, and all intermediate integers in their construction, have bit length
\(O\bigl(L+(D+1)(L+\log j)+\log(1+ND)\bigr)\).
For fixed \(D\), this is polynomial in the stated parameters. Standard integer arithmetic and greatest-common-divisor computation therefore produce the exact, reduced output fractions in polynomial time. Since the monomials are explicitly listed, \(N\) is bounded by the input length.

Role of the promises

Monotonicity also verifies that the outputs are nonnegative. Let \(e_{r,i}\) denote the unit vector for coordinate \((r,i)\). For \(0<t\le q_r\), the allocation
\(x^0+t(e_{r,1}-e_{r,j})\) is feasible. Monotonicity implies
\(\bigl(F(x^0+t(e_{r,1}-e_{r,j}))-F(x^0)\bigr)/t\ge0\).
Taking the right-hand limit gives \(d_r\ge0\), because \(F\) is differentiable. Hence \(\beta_r\ge0\), and their definition gives \(\sum_r\beta_r=1\).

The algorithm does not need to verify monotonicity: it operates on the promised inputs. Negative coefficients and cancellation do not obstruct exact computation. The finite-worker assignment identity is not needed for this argument.
