The continuous mirror question, as graded

Given a network \(G=(V,E)\), rational per-capita edge capacities \(\kappa_e\), and a finite set of types \(T\) with rational masses \(\mu_t\) summing to \(1\), where each type \(t\) has a terminal pair \((s_t,z_t)\), demand \(d_t\), and value \(w_t\), compute a welfare-maximizing mass assignment to simple routes. Choose \(x_{t,P}\ge 0\) to maximize \(\sum_{t\in T}\sum_{P} w_t x_{t,P}\), subject to \(\sum_P x_{t,P}\le\mu_t\) for each \(t\) and \(\sum_{t,P:e\in P}d_t x_{t,P}\le\kappa_e\) for each edge \(e\). Each unit of mass takes one whole route; the mass of a type may be divided among routes.

Packaged proof task (what the prover saw — nothing else)

Let \(G=(V,E)\) be a finite undirected network, with \(n=|V|\), \(m=|E|\ge 1\), and binary-rational per-capita capacities \(\kappa_e\). Use bandwidth units with \(0<d_t\le 1\), and assume \(C:=\min_{e\in E}\kappa_e>1\).
A society is given by its support: the list of its \(\tau\) types with positive binary-rational masses \(\mu_t\), summing to \(1\). Here \(\tau\) is the support size, not the number of possible types. Each type has distinct terminals \(s_t,z_t\in V\), binary-rational demand \(d_t\), and binary-rational value \(w_t\ge 0\).
Let \(\mathcal P_t\) contain all simple routes between these terminals. An assignment chooses \(x_{t,P}\ge 0\), subject to \(\sum_{P\in\mathcal P_t}x_{t,P}\le\mu_t\) and \(\sum_t\sum_{P\in\mathcal P_t:e\in P}d_tx_{t,P}\le\kappa_e\). Each unit of served mass uses one whole route; a type's mass may be divided among routes or left unserved.
Its welfare is \(W(x)=\sum_t\sum_{P\in\mathcal P_t}w_tx_{t,P}\); let \(\mathrm{OPT}\) be the maximum feasible welfare. Write running times in \(n,m,\tau,L\), where \(L\) is the total binary input length.

Does this continuous routing problem admit a polynomial-time algorithm achieving \(W(x)\ge\alpha(C,m)\mathrm{OPT}\), where \(\alpha(C,m)=\left(\frac{\mathrm e C}{C-1}m^{1/(C-1)}\right)^{-1}\), or is attaining this guarantee NP-hard?

Discrete unsplittable unicast routing admits a polynomial-time, deferred-acceptance-implementable approximation with this welfare fraction, using \(C\) as its minimum normalized edge capacity. [Kim](https://arxiv.org/html/1507.01353v3)
A fractional path-packing formulation is also established for discrete routing; that source does not state a complexity theorem for the society input specified here. [Kim](https://arxiv.org/html/1507.01353v3)

  • Carry over the normalized demand bound and strict minimum-capacity condition, applying them directly to the given per-capita capacities: positive demands at most one and minimum capacity greater than one. No finite population size is introduced.
  • Exclude zero demands and coincident terminals, for which the discrete algorithm's scoring denominator vanishes.
  • Values are nonnegative binary rationals; capacities and demands are binary rationals.
  • Require at least one edge so the minimum capacity and approximation ratio are defined; terminal pairs without a route are allowed and their mass remains unserved.

Result

The problem is polynomial-time exactly solvable, so it admits the requested approximation guarantee.

Under the stated normalization, capacities never bind. To address the substantive continuous-routing question as well, I also give a polynomial-size linear programming formulation that remains exact when capacities do bind.

1. The stated capacities are redundant

For any assignment satisfying the type-mass constraints and any edge \(e\), nonnegativity gives

\(\displaystyle \sum_t\sum_{P\in\mathcal P_t:e\in P}d_tx_{t,P}\le \sum_t d_t\sum_{P\in\mathcal P_t}x_{t,P}\le \sum_t d_t\mu_t\le \sum_t\mu_t=1.\)

Because \(\kappa_e\ge C>1\), every edge-capacity constraint is therefore automatically satisfied.

Let \(T_{\mathrm{conn}}\) denote the types whose terminals lie in the same connected component of \(G\). If \(t\notin T_{\mathrm{conn}}\), then \(\mathcal P_t\) is empty and that type cannot be served. For every assignment, the mass constraints and \(w_t\ge0\) imply

\(\displaystyle W(x)\le \sum_{t\in T_{\mathrm{conn}}}w_t\mu_t.\)

This bound is achievable: for each \(t\in T_{\mathrm{conn}}\), choose any simple route \(P_t\) between its terminals and set \(x_{t,P_t}=\mu_t\), with all other variables zero. The preceding load bound proves feasibility. Consequently,

\(\displaystyle \mathrm{OPT}=\sum_{t\in T_{\mathrm{conn}}}w_t\mu_t.\)

2. Algorithm and running time

Compute a spanning forest and connected-component labels. For each supported type:

  • If its terminals have different component labels, leave it unserved.
  • Otherwise, assign its entire mass to the unique route between its terminals in the spanning forest.

Computing the forest takes \(O(n+m)\) graph operations. Extracting each route takes \(O(n)\), so all routes take \(O(\tau n)\). The output contains at most \(\tau\) routes, each with at most \(n-1\) edges, and uses the input masses unchanged.

Thus the algorithm uses \(O(n+m+\tau n)\) graph operations and has bit running time polynomial in \(n,m,\tau,L\). Exact evaluation of the rational welfare also takes polynomial time. The dependence is on the listed support size \(\tau\).

Finally,

\(\displaystyle \alpha(C,m)=\frac{C-1}{\mathrm e C}\,m^{-1/(C-1)}\in(0,1),\)

because \(C>1\) and \(m\ge1\). The optimal assignment therefore satisfies \(W(x)=\mathrm{OPT}\ge\alpha(C,m)\mathrm{OPT}\), without computing the generally irrational approximation factor.

3. Stronger result: exact optimization with binding capacities

Even if the assumption \(C>1\) is removed and arbitrary positive rational capacities are allowed, the continuous problem remains polynomial-time exactly solvable. Here is a compact formulation and a proof of its equivalence to the path formulation.

Replace each undirected edge \(e=\{u,v\}\) by two directed arcs \((u,v)\) and \((v,u)\); let \(A\) be this arc set. For each type \(t\), introduce served mass \(y_t\) and nonnegative bandwidth flows \(f_{t,a}\). Maximize

\(\displaystyle \sum_t w_ty_t\)

subject to the following constraints:

\(\displaystyle 0\le y_t\le\mu_t,\)

\(\displaystyle \sum_{a\in\delta^+(v)}f_{t,a}-\sum_{a\in\delta^-(v)}f_{t,a} =\begin{cases} d_ty_t,&v=s_t,\\ -d_ty_t,&v=z_t,\\ 0,&\text{otherwise}, \end{cases}\)

and, for every \(e=\{u,v\}\),

\(\displaystyle \sum_t\bigl(f_{t,(u,v)}+f_{t,(v,u)}\bigr)\le\kappa_e.\)

The last constraint counts both directions against the same undirected capacity.

Equivalence: paths give flows

Given a feasible path assignment, set \(y_t=\sum_Px_{t,P}\). Orient each route from \(s_t\) to \(z_t\) and add bandwidth \(d_tx_{t,P}\) to its arcs.

Each route contributes the required source and sink balances and zero balance at intermediate vertices. Since a simple route traverses an undirected edge at most once, its contribution to that edge’s capacity is exactly the contribution in the original formulation. The resulting flow solution is feasible and has the same welfare.

Equivalence: flows give paths

Fix a feasible flow solution and a type \(t\). Write \(q=d_ty_t\). While \(q>0\), there is a directed \(s_t\)-to-\(z_t\) route using positive-flow arcs.

To prove this, let \(R\) be the vertices reachable from \(s_t\) using positive-flow arcs. If \(z_t\notin R\), no positive flow leaves \(R\). Summing flow balances over \(R\) would then give

\(\displaystyle q=f_t(R,V\setminus R)-f_t(V\setminus R,R)\le0,\)

contradicting \(q>0\).

Choose a simple directed route \(P\) in this positive-flow graph and put

\(\displaystyle \delta=\min\bigl(\{q\}\cup\{f_{t,a}:a\in P\}\bigr)>0.\)

Record path mass \(\delta/d_t\), subtract \(\delta\) from every arc of \(P\), and replace \(q\) by \(q-\delta\). This preserves nonnegativity and the flow-balance equations for the residual flow.

Each iteration either finishes the process or makes at least one positive-flow arc zero. Subtraction never creates a positive-flow arc. Hence there are at most \(2m+1\) iterations. The recorded bandwidth amounts sum to \(d_ty_t\), so the recorded masses sum to \(y_t\). Discard the residual flow, whose balances are all zero.

The resulting routes are simple undirected routes. Their edge loads are no greater than those of the original flow solution, because the procedure only subtracts flow and discards the remainder. They therefore form a feasible path assignment with exactly the same welfare.

Polynomial bit complexity

The linear program has \(\tau(2m+1)\) variables and \(O(\tau n+m+\tau)\) constraints, with rational coefficients of encoding length polynomial in \(n,m,\tau,L\).

It is feasible because the zero solution is feasible. Its feasible region is bounded: \(y_t\le\mu_t\), and every arc-flow variable is bounded by its underlying edge capacity. Thus an optimum exists. The polynomial-time theorem for rational linear programming yields an exact rational optimum in time polynomial in \(n,m,\tau,L\).

The constructive decomposition above produces at most \(\tau(2m+1)\) routes. It uses polynomially many graph operations and rational arithmetic operations; the rational numbers involved have polynomial encoding length. This gives an explicit optimal path assignment in polynomial time.

4. Relation to the discrete result

[Kim’s Section 4](https://arxiv.org/html/1507.01353v3#S4) requires each selected firm’s demand to be routed as an unsplittable flow. The society formulation permits each type’s served mass to be divided among routes, which is precisely what makes the compact flow formulation exact.

Accordingly, the requested guarantee is attainable in polynomial time. Under the stated hypotheses, the spanning-forest algorithm already achieves the optimum.
