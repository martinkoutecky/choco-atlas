The continuous mirror question, as graded

Input a finite set of types \(T\), object categories \(J\), rational type masses \(\mu_t\) with \(\sum_{t\in T}\mu_t=1\), per-capita category capacities \(b_j\), and, for each type \(t\), an eligibility set and a partial order over eligible categories. On an atomless population partitioned into type groups of masses \(\mu_t\), decide whether there exist at most fixed \(k>1\) feasible matchings \(F=(f_1,\ldots,f_k)\) such that, for every feasible competing matching \(g\), the mass of people who strictly prefer some \(f_i(\omega)\) to \(g(\omega)\) is at least the mass who strictly prefer \(g(\omega)\) to every \(f_i(\omega)\). Each matching assigns at most one category to each person and assigns category \(j\) to mass at most \(b_j\); incomparability contributes to neither strict-preference mass.

Packaged proof task (what the prover saw — nothing else)

Fix an integer \(k>1\). A society is given by its support: a list \(T\) of \(\tau\) types with positive binary-rational masses \(\mu_t\), summing to \(1\); \(\tau\) is the support size, not the number of possible types.
The input also gives \(m=|J|\) object categories, binary-rational capacities \(b_j\geq0\), and, for each type \(t\), an eligibility set \(E_t\subseteq J\) and an explicitly listed strict partial order \(\succ_t\) on \(E_t\). Let \(L\) be the total input bit length.
Use Lebesgue measure \(\lambda\) on \(\Omega=[0,1]\), partitioned into type intervals \(\Omega_t\) of lengths \(\mu_t\). Write \(\bot\) for being unmatched and extend preferences by \(j\succ_t\bot\) for every \(j\in E_t\).
A feasible matching is a measurable map \(f:\Omega\to J\cup\{\bot\}\) with \(f(\omega)\in E_t\cup\{\bot\}\) almost everywhere on \(\Omega_t\), and \(\lambda(f^{-1}(j))\leq b_j\) for every category. Assignments may vary within a type.
A nonempty family \(F=(f_1,\ldots,f_r)\), where \(1\leq r\leq k\), is weakly Condorcet-winning if every feasible matching \(g\) satisfies
\(\lambda\{\omega:\exists i\leq r,\ f_i(\omega)\succ_{t(\omega)}g(\omega)\}\geq\lambda\{\omega:\forall i\leq r,\ g(\omega)\succ_{t(\omega)}f_i(\omega)\}\).
Identical or incomparable outcomes yield no strict preference; all matchings are compared on the same population.

For each fixed \(k>1\), is deciding whether such a family exists in \(\mathrm{P}\), or is it NP-hard? State running times in \(m,\tau,L\), with dependence on \(k\) explicit.

For finite agents and unit-capacity objects with partial-order preferences, existence of a weakly Condorcet-winning set of at most \(k\) matchings is NP-complete for every fixed \(k>1\). [Source](https://arxiv.org/html/2602.16289v1#S6.SS1).
No result settling this exact atomless decision problem was located in the literature search.

Modeling choices made when packaging the task

  • The unmatched outcome was unspecified; every eligible category is strictly preferred to being unmatched, as in the discrete definition.
  • Capacities had no stated domain; they are nonnegative binary rationals. Empty eligibility sets and zero capacities are allowed, consistent with unrestricted matching instances.
  • The atomless space and measurability were unspecified; use Lebesgue measure on the unit interval with type intervals and measurable assignments, allowing different assignments within each type.
  • The lower bound on family size was unspecified; require a nonempty family of at most k matchings.
  • Preference encoding and input bit length were unspecified; list each strict partial order explicitly and let L denote the total input bit length.

Result

For every fixed \(k>1\), the atomless decision problem is \(\mathrm{NP}\)-complete, hence \(\mathrm{NP}\)-hard.

The proof below allows assignments to vary arbitrarily within each type. The related finite-agent hardness theorem is established in [Kavitha–Matuschke–Schmidt-Kraepelin](https://arxiv.org/html/2602.16289v1#S6.SS1); the reduction here establishes hardness for the atomless model.

Define
\( N_k=\sum_{t\in T}\sum_{h=0}^{\min(k,|E_t|)}\binom{|E_t|}{h} \leq \tau(m+1)^k. \)
An exact algorithm uses \(3^m\) rational linear programs, each with \(N_k\) variables and \(m+\tau+1\) constraints. Its bit running time is
\( 3^m\operatorname{poly}\!\bigl(k\tau(m+1)^{k+1}+L\bigr), \)
where the polynomial has an exponent independent of \(k\). Verification of a certificate takes
\( \operatorname{poly}\!\bigl(k\tau(m+1)^{k+1}+L\bigr). \)

1. An exact finite formulation

For each type \(t\), let
\( \mathcal S_t=\{S\subseteq E_t:|S|\leq k\}. \)
The set \(S\) records the distinct non-unmatched outcomes that a person receives across the family.

For \(S\neq\varnothing\) and \(a\in E_t\cup\{\bot\}\), define the adversary’s vote advantage by
\( c_t(S,a)= \mathbf 1\{a\succ_t s\text{ for every }s\in S\} - \mathbf 1\{\exists s\in S:s\succ_t a\}. \)
For the empty set, define
\( c_t(\varnothing,a)=\mathbf 1\{a\neq\bot\}. \)
These definitions agree with the task’s comparison rule: an empty set represents receiving \(\bot\) in every matching. In particular,
\( c_t(S,\bot)= \begin{cases} -1,&S\neq\varnothing,\\ 0,&S=\varnothing. \end{cases} \)
Every coefficient belongs to \(\{-1,0,1\}\).

Introduce variables \(x_{t,S}\), representing the mass of type \(t\) receiving outcome set \(S\). Their feasibility conditions are
\[ \displaystyle x_{t,S}\geq0,\qquad \sum_{S\in\mathcal S_t}x_{t,S}=\mu_t,\qquad \sum_t\sum_{S\ni j}x_{t,S}\leq k b_j. \tag{1} \]

Lemma 1: Conditions (1) exactly describe realizable outcome-set distributions

Proof. Given a family of at most \(k\) feasible matchings, partition each type according to its distinct non-unmatched outcomes. For each category, its presence in a person’s outcome set is bounded by the number of family members assigning that category to the person. Integrating gives the capacity inequality in (1).

Conversely, suppose (1) holds. Partition each type interval into cells of masses \(x_{t,S}\). On a cell for \(S\), form a vector of length \(k\) containing every member of \(S\) once and \(\bot\) in the remaining positions. Split that cell into \(k\) equal pieces and use the \(k\) cyclic shifts of the vector as the assignments in the \(k\) matchings.

Thus every matching assigns category \(j\) to mass
\( \displaystyle \frac1k\sum_t\sum_{S\ni j}x_{t,S}\leq b_j. \)
Every person in the cell has precisely the non-unmatched outcome set \(S\). Repeated outcomes and additional occurrences of \(\bot\) do not affect either strict-preference event in the task. This proves the claim. \(\square\)

For a fixed distribution \(x\), an adversary is described by nonnegative variables \(y_{t,S,a}\) satisfying
\( \displaystyle \sum_{a\in E_t\cup\{\bot\}}y_{t,S,a}=x_{t,S}, \qquad \sum_{t,S}y_{t,S,j}\leq b_j. \)
Its maximum advantage is the optimum of
\[ \displaystyle \max_y\sum_{t,S,a}c_t(S,a)y_{t,S,a}. \tag{2} \]

This is an exact representation of measurable opponents. Any opponent induces such variables. Conversely, every feasible vector \(y\) can be realized by subdividing the measurable cells into the prescribed masses, using the nonatomicity of Lebesgue measure.

Therefore the family is weakly Condorcet-winning exactly when the optimum of (2) is at most zero.

2. Integer price certificates and membership in \(\mathrm{NP}\)

Associate a nonnegative dual price \(p_j\) with each category capacity, and put \(p_\bot=0\). The dual of (2) is
\[ \displaystyle \min_{p,q} \left( \sum_j b_jp_j+\sum_{t,S}x_{t,S}q_{t,S} \right), \tag{3} \]
subject to
\( \displaystyle p_j\geq0,\qquad q_{t,S}+p_a\geq c_t(S,a) \quad (a\in E_t\cup\{\bot\}). \)

The primal is feasible, because everyone may be unmatched, and bounded, because its coefficients lie in \(\{-1,0,1\}\). Hence finite-dimensional LP strong duality applies.

Lemma 2: The dual has an optimum with \(p_j\in\{0,1,2\}\)

Proof. The constraint for \(\bot\) implies \(q_{t,S}\geq-1\). Any feasible solution can be modified as follows without increasing its objective:

  • Replace every \(q_{t,S}>1\) by \(1\). Feasibility is preserved because \(c_t(S,a)\leq1\) and all prices are nonnegative.
  • Replace every \(p_j>2\) by \(2\). Feasibility is preserved because \(q_{t,S}\geq-1\), so \(q_{t,S}+2\geq1\geq c_t(S,j)\).

It therefore suffices to optimize over the compact polytope given by the original constraints and
\( -1\leq q_{t,S}\leq1,\qquad 0\leq p_j\leq2. \)

After changing the sign of every \(q\)-variable, each constraint involving two variables is a difference constraint. Its coefficient matrix is the transpose of a directed incidence matrix, augmented by unit rows for the bounds. This matrix is totally unimodular. All right-hand sides are integers, so every vertex is integral.

The linear objective attains an optimum at a vertex. At that vertex, \(p_j\in\{0,1,2\}\). \(\square\)

For any such price vector, define
\[ \displaystyle q_{t,S}(p)= \max_{a\in E_t\cup\{\bot\}} \bigl(c_t(S,a)-p_a\bigr). \tag{4} \]
These values belong to \(\{-1,0,1\}\).

Combining the two lemmas with strong duality gives the exact criterion:

A winning family exists if and only if some \(p\in\{0,1,2\}^J\) admits an \(x\) satisfying (1) and
\[ > \displaystyle > \sum_j b_jp_j+\sum_{t,S}x_{t,S}q_{t,S}(p)\leq0. > \tag{5} > \]

For a fixed \(p\), this is a rational LP. Enumerating all \(3^m\) prices gives the stated algorithm. Computing all coefficients in (4) takes \(O(k(m+1)N_k)\) operations after preparing preference lookup tables.

For fixed \(k\), a price vector is a polynomial-length certificate, and feasibility of its LP is decidable in polynomial time. Thus the problem belongs to \(\mathrm{NP}\). Rational LP feasibility also guarantees that every yes-instance has a winning family describable by finitely many rational interval pieces.

3. Reduction from Vertex Cover

Fix \(k>1\). We reduce from Vertex Cover on a simple graph \(G=(V,\mathcal E)\), with
\( n=|V|,\qquad e=|\mathcal E|\geq1, \)
and budget \(1\leq h\leq n\). Vertex Cover remains \(\mathrm{NP}\)-complete under these restrictions.

Choose a positive dyadic rational \(\delta\) such that
\( \varepsilon=(k-1)\delta,\qquad h\varepsilon<1. \)
Set
\( M=2ek,\qquad R=kh\delta,\qquad H=2k(k+1)M+M+k+2. \)
Observe that
\( R<\frac{k}{k-1}\leq2 \)
and consequently
\[ H>2k(k+1)M+M+R. \tag{6} \]

Choose a power of two \(D>M+R+H\). We describe unnormalized masses and capacities, subsequently divided by \(D\).

Categories and capacities

There are:

  • Global categories \(\alpha,\beta\), each with unnormalized capacity \(e\).
  • A category \(\ell_v\) for each vertex \(v\), with unnormalized capacity \(\varepsilon\).
  • For each edge \(a\) and copy \(c\in\{0,1\}\), private categories \(d_{a,c,i}\) and \(\ell_{a,c,i}\), for \(1\leq i\leq k-1\).
  • Three further categories \(z,\nu,u_*\).

Let
\( Y=\{\alpha,\beta\}\cup\{d_{a,c,i}\}. \)
The private categories \(d_{a,c,i}\) have unnormalized capacity \(1\). Hence
\[ \displaystyle \sum_{y\in Y}\widehat b_y =2e+2e(k-1)=M. \tag{7} \]

The remaining unnormalized capacities are
\( \widehat b_\nu=kM,\qquad \widehat b_{u_*}=h\delta. \)
The actual capacities of these categories, the vertex categories, and \(Y\) are their unnormalized capacities divided by \(D\).

Every private category \(\ell_{a,c,i}\), and \(z\), instead has actual capacity \(2\), equivalently unnormalized capacity \(2D\).

Types and preferences

For each edge \(a=\{v,w\}\), create two types \(t_{a,0},t_{a,1}\), each of unnormalized mass \(k\).

Each copy is eligible for
\( \{\alpha,\beta,\ell_v,\ell_w\} \cup \{d_{a,c,i},\ell_{a,c,i}:1\leq i\leq k-1\}. \)
Its private comparisons are
\( d_{a,c,i}\succ\ell_{a,c,i}. \)
In copy \(0\), also impose
\( \alpha\succ\ell_v,\qquad \beta\succ\ell_w; \)
in copy \(1\), impose
\( \alpha\succ\ell_w,\qquad \beta\succ\ell_v. \)
There are no other comparisons between eligible categories.

The total unnormalized mass of these edge types is \(M\).

Create a background type of unnormalized mass \(H\), eligible for \(Y\cup\{z,\nu\}\), with precisely the comparisons
\( y\succ z\qquad(y\in Y). \)
Thus \(\nu\) is incomparable with every other eligible category.

Create a subsidy type of unnormalized mass \(R\), eligible only for \(u_*\).

Finally, create a filler type of unnormalized mass \(D-M-R-H>0\), with empty eligibility set.

Divide all type masses by \(D\). They are positive dyadic rationals summing to \(1\). All the specified preferences are strict partial orders: their nontrivial relations have height two.

The construction has
\( m=n+4e(k-1)+5,\qquad \tau=2e+3. \)
Its encoding length is
\( O\!\left((n+ke)\log\bigl((n+ke+2)(k+1)(h+1)\bigr)\right). \)
In particular, it is polynomial-time for every fixed \(k\).

4. A vertex cover produces a winning family

Suppose \(C\subseteq V\) is a vertex cover with \(|C|\leq h\).

Use prices
\( p_y=1\quad(y\in Y),\qquad p_{\ell_v}=\mathbf 1\{v\in C\},\qquad p_{u_*}=1, \)
and set all other prices to zero.

For each edge, choose an endpoint whose *other* endpoint belongs to \(C\). Such a choice exists because \(C\) covers the edge.

For each of its two types, assign the outcome set consisting of:

  • All its \(k-1\) private categories \(d_{a,c,i}\).
  • The one global category, \(\alpha\) or \(\beta\), that dominates the chosen endpoint’s category in that copy.

The swapped preferences ensure that one copy uses \(\alpha\) and the other uses \(\beta\).

Every zero-price eligible category is dominated by a member of this outcome set: the private lower categories are dominated by their private \(d\)-categories, and any zero-price endpoint category is the chosen endpoint’s category. Also, the outcome set contains maximal categories, so no eligible outcome strictly dominates the entire set. Thus (4) gives
\( q_{t_{a,c},S}(p)=-1. \)

Assign the background type the singleton outcome set \(\{z\}\), the subsidy type \(\{u_*\}\), and the filler type the empty set. Their \(q\)-values are, respectively,
\( 0,\qquad -1,\qquad 0. \)

These distributions satisfy the augmented capacities (1):

  • Each private \(d\)-category receives unnormalized mass \(k\), exactly \(k\) times its capacity.
  • Each of \(\alpha,\beta\) receives mass \(ek\), exactly \(k\) times its capacity.
  • Category \(u_*\) receives mass \(R=kh\delta\), exactly \(k\) times its capacity.
  • Category \(z\), of actual capacity \(2\), can accommodate the background assignment.

Multiplying the left side of (5) by \(D\), its value is
\( \displaystyle M+\varepsilon|C|+h\delta-M-R =\varepsilon(|C|-h)\leq0. \)
The exact criterion therefore gives a winning family.

5. A winning family produces a vertex cover

Conversely, suppose a winning family exists. Take the distribution \(x\) and integer prices \(p\) supplied by (5), with \(q\) defined by (4).

Write
\( \widehat x_{t,S}=Dx_{t,S} \)
and multiply (5) by \(D\). Denote the resulting expression by
\[ \displaystyle \widehat C= \sum_j\widehat b_jp_j+ \sum_{t,S}\widehat x_{t,S}q_{t,S}(p)\leq0. \tag{8} \]

5.1. The abundant lower categories have price zero

Every \(q\)-value is at least \(-1\), and the normalized population mass is \(1\). A positive integer price on any category of actual capacity \(2\) would therefore make the normalized expression in (5) at least \(2-1>0\).

Consequently,
\[ p_z=0,\qquad p_{\ell_{a,c,i}}=0. \tag{9} \]

5.2. Every category in \(Y\) has positive price

Suppose some \(y\in Y\) had price zero.

Consider background cells whose outcome sets contain neither a member of \(Y\) nor \(\nu\). Such a set is empty or \(\{z\}\). In either case \(c(S,y)=1\), so its \(q\)-value is \(1\).

Let \(A\) be the unnormalized background mass whose outcome sets meet \(Y\cup\{\nu\}\). By (1) and (7),
\( \displaystyle A\leq k\left(\sum_{y\in Y}\widehat b_y+\widehat b_\nu\right) =k(k+1)M. \)
On this exceptional mass, \(q\geq-1\). The background’s contribution is therefore at least
\( H-2k(k+1)M. \)

The edge and subsidy types together contribute at least \(-M-R\). The filler contributes zero, and all price costs are nonnegative. Hence
\( \widehat C \geq H-2k(k+1)M-M-R>0 \)
by (6), contradicting (8).

Thus
\( p_y\geq1\quad(y\in Y), \)
and their total price cost is at least \(M\).

5.3. The background cannot provide a net subsidy

We claim that
\[ \displaystyle \widehat b_\nu p_\nu+ \sum_{S}\widehat x_{\mathrm{background},S} q_{\mathrm{background},S}(p)\geq0. \tag{10} \]

If \(p_\nu=0\), the background has \(q\geq0\), because \(\nu\) is incomparable with every eligible non-unmatched outcome.

If \(p_\nu\geq1\), a background cell with \(q=-1\) must have \(c(S,z)=-1\), by (9). Therefore its outcome set contains some category in \(Y\). Its total negative mass is at most \(kM\), by (1) and (7). The price cost of \(\nu\) is at least \(\widehat b_\nu=kM\), proving (10).

5.4. The subsidy type supplies at most \(h\varepsilon\)

If \(p_{u_*}=0\), the subsidy type has \(q\geq0\). If \(p_{u_*}\geq1\), its combined price cost and vote contribution are at least
\( h\delta-R=-(k-1)h\delta=-h\varepsilon. \)
Thus, in every case,
\[ \displaystyle \widehat b_{u_*}p_{u_*} +\sum_S\widehat x_{\mathrm{subsidy},S}q_{\mathrm{subsidy},S}(p) \geq-h\varepsilon. \tag{11} \]

5.5. Positive vertex prices select at most \(h\) vertices

The edge types contribute at least \(-M\), while the price cost of \(Y\) is at least \(M\). Combining this cancellation with (9)–(11), the zero filler contribution, and the vertex price costs gives
\( \displaystyle \widehat C\geq \varepsilon\sum_{v\in V}p_{\ell_v}-h\varepsilon. \)
Since \(\widehat C\leq0\) and \(\varepsilon>0\),
\[ \sum_{v\in V}p_{\ell_v}\leq h. \tag{12} \]

Define
\( C=\{v\in V:p_{\ell_v}\geq1\}. \)
Integer prices and (12) imply \(|C|\leq h\).

5.6. These vertices cover every edge

Suppose an edge \(a=\{v,w\}\) were uncovered. Then
\( p_{\ell_v}=p_{\ell_w}=0. \)

For either associated edge type, an outcome set with \(q=-1\) must dominate every zero-price private lower category. Its only possible dominator is the corresponding \(d_{a,c,i}\), so the set must contain all \(k-1\) private \(d\)-categories.

It must also dominate both \(\ell_v\) and \(\ell_w\). Their only dominators in that type are \(\alpha\) and \(\beta\), respectively, with the roles swapped in the other copy. Hence the outcome set must contain both global categories.

It would therefore contain at least
\( (k-1)+2=k+1 \)
distinct categories, contrary to its allowed size. Thus neither edge type has any cell with \(q=-1\). Because the \(q\)-values are integers, both types contribute nonnegative amounts.

Their combined unnormalized mass is \(2k\). Consequently, the total contribution of all edge types is now at least \(-M+2k\). Repeating the preceding bound yields
\( \displaystyle \widehat C \geq \varepsilon\sum_vp_{\ell_v}+2k-h\varepsilon \geq2k-h\varepsilon>0, \)
contradicting (8).

Every edge is therefore covered by \(C\), and \(|C|\leq h\).

6. Complexity conclusion

The reduction proves equivalence between a vertex cover of size at most \(h\) and an atomless winning family of size at most \(k\). Its soundness applies to arbitrary within-type splitting.

Together with the integer-price certificate characterization, this proves \(\mathrm{NP}\)-completeness for every fixed \(k>1\). The explicit dependence on support size and category count is the \(3^m\)-LP algorithm stated above; a polynomial-time algorithm for the general problem would imply \(\mathrm{P}=\mathrm{NP}\).
