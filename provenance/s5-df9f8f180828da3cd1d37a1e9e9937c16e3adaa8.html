The continuous mirror question, as graded

Given a finite catalogue \(G\), a cardinality bound \(k\), and two additive valuation types \(v_1,v_2:G\to\mathbb{Z}_{\ge 0}\), each with mass \(1/2\), choose \(S\subseteq G\) with \(|S|\le k\) to maximize \(\sqrt{v_1(S)v_2(S)}\), on instances where some feasible set gives both types positive utility. What is the computational complexity of this problem?

Conclusion

The exact optimization problem is \(\mathrm{NP}\)-hard, already for support size \(\tau=2\), distinct valuation types, and masses \(1/2\). Consequently, an algorithm polynomial in \(m,\tau,k,L\) would imply \(\mathrm{P}=\mathrm{NP}\).

This agrees with Theorem 20 of Garg, Kulkarni, and Murhekar, which establishes hardness for two agents consuming the same selected public goods. Equal masses give precisely their objective \(\sqrt{v_1(S)v_2(S)}\). [Source, Theorem 20](https://drops.dagstuhl.de/storage/00lipics/lipics-vol213-fsttcs2021/LIPIcs.FSTTCS.2021.22.pdf).

Here is a direct reduction checking all the additional promises.

A reduction from PARTITION

Use the standard NP-complete problem PARTITION: given positive integers \(a_1,\ldots,a_n\), determine whether some subset sums to \(A/2\), where \(A=\sum_{i=1}^n a_i\). We restrict to \(n\ge 2\); excluded instances are trivially decidable.

Construct \(m=2n\) goods. Assign weights \(w_i=a_i\) to the first \(n\) goods and weight zero to the remaining \(n\) goods. Set \(k=n\) and \(B=2nA+1\). Define the two additive valuations by

\[ v_1(g_i)=B+2nw_i-A,\qquad v_2(g_i)=B-2nw_i+A. \]

Both masses are \(1/2\).

The instance satisfies every promise. Since \(0\le w_i\le A\),

\[ v_1(g_i)\ge B-A>0,\qquad v_2(g_i)\ge B-2nA+A=A+1>0. \]

Thus every nonempty feasible set gives both types positive utility. The types are distinct: on every zero-weight good their values are \(B-A\) and \(B+A\), and \(A>0\). Also \(2\le k=n\le m=2n\).

Each valuation has \(O(\log n+\log A)\) bits. Hence the construction, including the threshold below, has polynomial bit length and is computable in polynomial time.

Correctness of the reduction

Because the square root is strictly increasing on nonnegative numbers, maximizing the requested objective is equivalent to maximizing the integer product \(v_1(S)v_2(S)\).

For any feasible set \(S\), write \(r=|S|\) and \(x=\sum_{g_i\in S}w_i\). Additivity gives

\[ v_1(S)=rB+2nx-rA,\qquad v_2(S)=rB-2nx+rA. \]

Consequently,

\[ v_1(S)v_2(S)=r^2B^2-(2nx-rA)^2\le r^2B^2. \]

Take the integer threshold \(T=n^2B^2\). If \(r<n\), then \(r^2B^2<T\), so \(S\) cannot reach the threshold. If \(r=n\), then

\[ v_1(S)v_2(S)=n^2B^2-n^2(2x-A)^2. \]

Thus a feasible set reaches \(T\) if and only if it contains exactly \(n\) goods and its weights sum to \(A/2\).

If the PARTITION instance has a solution using \(q\) original integers, select their corresponding goods and add \(n-q\) zero-weight goods. This produces such a feasible set.

Conversely, any feasible set reaching \(T\) identifies, through its positive-weight goods, a subset of the original integers summing to \(A/2\).

Therefore the PARTITION instance is a yes-instance exactly when the maximum product is at least \(T\). An exact optimizer returning any maximizing set decides PARTITION by evaluating that set’s product.

The product-threshold decision problem is also in \(\mathrm{NP}\): a selected set is a polynomial-size certificate, and its cardinality, utilities, and product can be checked using polynomial-time binary arithmetic. Thus that decision problem is NP-complete.

Exact running times and pseudo-polynomial solvability

All bounds below count bit operations.

Enumeration. Nonnegative valuations imply that adding goods cannot decrease the objective. Every feasible set can be extended to size \(k\), so some optimum has exactly \(k\) goods. Enumerating all such sets gives an exact algorithm with running time

\[ O\!\left(\left(m\tau+\binom{m}{k}\tau k\right)L^2\right), \qquad \tau=2. \]

In particular, this is polynomial for every fixed \(k\). If \(k=m\), simply select all goods. The hardness concerns variable \(k\).

A pseudo-polynomial dynamic program. Let \(U_i=\sum_{g\in G}v_i(g)\). Swap the two types if necessary so that \(U=U_1=\min\{U_1,U_2\}\). Order the goods as \(g_1,\ldots,g_m\), and write \(a_j=v_1(g_j)\), \(b_j=v_2(g_j)\).

Define \(D_j(r,x)\) as the largest second-type utility achievable by selecting exactly \(r\) goods among the first \(j\), with first-type utility exactly \(x\). Unreachable states have value \(-\infty\). Initialize \(D_0(0,0)=0\), with all other states unreachable.

For \(0\le r\le k\) and \(0\le x\le U\), the recurrence is

\[ D_j(r,x)= \max\left\{ D_{j-1}(r,x),\; D_{j-1}(r-1,x-a_j)+b_j \right\}, \]

where the second term is omitted when its predecessor is invalid or unreachable.

Every eligible subset either excludes \(g_j\), yielding the first term, or includes it, yielding the second term after its removal. This proves the recurrence and its interpretation by induction.

For fixed \(r,x\), the product \(x\,v_2(S)\) is nondecreasing in \(v_2(S)\), since \(x\ge0\). Therefore retaining only the largest second utility loses no optimum. Maximize \(xD_m(r,x)\) over reachable states with \(r\le k\), and recover a maximizing set using stored predecessor choices.

There are \(O(mk(U+1))\) states. Utilities and products have \(O(L)\) bits, so a conservative running-time bound, including reconstruction, is

\[ O\!\left(\left(m\tau+mk(U+1)\right)L^2\right), \qquad \tau=2. \]

Storing all layers and predecessors uses \(O(mk(U+1)L)\) bits. This bound is pseudo-polynomial because \(U\) can be exponential in \(L\). Indeed, the elementary bound \(U\le m2^L\) gives a worst-case bound of \(O(m^2k2^LL^2)\), rather than a polynomial in the input length.

Thus constant support size permits pseudo-polynomial exact computation but does not remove the proved NP-hardness.
