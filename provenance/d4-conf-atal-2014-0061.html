The continuous mirror question, as graded

Given candidates \(C \cup \{p\}\), a common order \(L\), fixed \(r \ge 3\), and \(\tau\) ranking types that are 2-peaked with respect to \(L\), each with rational mass \(\mu_t \ge 0\) and \(\sum_t \mu_t = 1\), plus a rational deletion budget \(\rho\), does there exist deleted mass \(x_t \in [0,\mu_t]\) with \(\sum_t x_t \le \rho\) such that \(p\) is the unique \(r\)-approval winner among the remaining mass; that is, \(\sum_t (\mu_t-x_t)a_{t,p} > \sum_t (\mu_t-x_t)a_{t,c}\) for every \(c \in C\), where \(a_{t,c}\) indicates whether type \(t\) ranks \(c\) in its top \(r\)?

Packaged proof task (what the prover saw — nothing else)

Let \(A=C\cup\{p\}\), with \(p\notin C\), \(m=|A|\ge r\), and fixed integer \(r\ge3\). The input includes a common linear order \(\ell\) of \(A\).
A strict ranking is 2-peaked with respect to \(\ell\) if \(\ell\) can be partitioned into at most two nonempty contiguous blocks, on each of which the restricted ranking is single-peaked; the partition may depend on the ranking.
A society is given by its support: a list of \(\tau\) distinct such ranking types, each with positive binary rational mass \(\mu_t\), where \(\sum_{t=1}^{\tau}\mu_t=1\). Here \(\tau\) is the support size, not the number of possible rankings.
The deletion budget is a binary rational \(\rho\in[0,1]\). Write \(a_{t,c}\) for the indicator that type \(t\) ranks candidate \(c\) among its top \(r\) positions.
A feasible deletion chooses real masses \(x_t\in[0,\mu_t]\) with \(\sum_{t=1}^{\tau}x_t\le\rho\). Candidate scores are \(s_x(c)=\sum_{t=1}^{\tau}(\mu_t-x_t)a_{t,c}\); ties do not make \(p\) a unique winner.
The decision problem asks whether a feasible deletion satisfies \(s_x(p)>s_x(c)\) for every \(c\in C\).

For each fixed \(r\ge3\), is this continuous deletion problem in \(\mathrm{P}\), with running time polynomial in \(m,\tau,L\), or is it \(\mathrm{NP}\)-hard, where \(L\) is the total input bit length?

Discrete deletion of at most a prescribed number of whole votes is \(\mathrm{NP}\)-complete for every fixed \(r\ge3\), even for 2-peaked rankings with the common order supplied ([Yang–Guo](https://arxiv.org/pdf/1304.4471)).
No result settling this exact continuous deletion problem was identified in the literature search.

Modeling choices made when packaging the task

  • Defined 2-peaked rankings using at most two nonempty contiguous single-peaked blocks, following the full version; partitions may differ across types.
  • Restricted the normalized deletion budget to [0,1], matching the discrete budget bound between zero and the number of votes.
  • Required m at least r so that the top r positions exist; retained the all-approved boundary case m=r.
  • Omitted zero-mass types from the input support and required distinct strict ranking types.
  • Allowed real-valued partial deletions and retained unnormalized remaining scores and strict unique-winner comparisons.
  • Renamed the common order to ell so that L denotes total input bit length.

Result

The problem is in \(\mathrm{P}\) for every fixed \(r\ge3\). In fact, the same algorithm works for arbitrary explicitly listed rankings and for variable \(r\). The crucial feature is that deletion masses may be fractional.

1. A linear program for the winning margin

Define the retained mass of type \(t\) by \(y_t=\mu_t-x_t\). The deletion constraints become
\[ 0\le y_t\le\mu_t \quad\text{and}\quad \sum_{t=1}^{\tau}y_t\ge1-\rho, \]
because \(\sum_t\mu_t=1\). Conversely, every such retained-mass vector gives a feasible deletion through \(x_t=\mu_t-y_t\).

For each opponent \(c\in C\), define \(b_{t,c}=a_{t,p}-a_{t,c}\in\{-1,0,1\}\). The score difference is
\[ s_x(p)-s_x(c)=\sum_{t=1}^{\tau}b_{t,c}y_t. \]

Consider the following rational linear program, with variables \(y_1,\ldots,y_\tau,\delta\):
\[ \begin{aligned} \text{maximize}\quad &\delta\\ \text{subject to}\quad &0\le y_t\le\mu_t &&(1\le t\le\tau),\\ &\sum_{t=1}^{\tau}y_t\ge1-\rho,\\ &\sum_{t=1}^{\tau}b_{t,c}y_t\ge\delta &&(c\in C),\\ &-1\le\delta\le1. \end{aligned} \]

The margin bounds are legitimate: every feasible retained-mass vector satisfies \(\sum_t y_t\le1\), so every candidate score lies in \([0,1]\) and every score difference lies in \([-1,1]\).

This program is nonempty: take \(y_t=\mu_t\) and \(\delta=-1\). Its feasible set is closed and bounded, hence compact, so an optimal value \(\delta^\star\) exists.

2. Equivalence with strict victory

Claim. A successful deletion exists if and only if \(\delta^\star>0\).

Proof. Suppose a feasible deletion makes \(p\) the unique winner. For its retained-mass vector \(y\), every quantity \(\sum_t b_{t,c}y_t\) is positive. Since \(C\) is finite and nonempty, their minimum
\[ \eta=\min_{c\in C}\sum_{t=1}^{\tau}b_{t,c}y_t \]
is positive. It is at most \(1\), so \((y,\eta)\) is feasible for the linear program. Thus \(\delta^\star\ge\eta>0\).

Conversely, if \(\delta^\star>0\), let \((y^\star,\delta^\star)\) be an optimum and set \(x_t=\mu_t-y_t^\star\). The retained-mass constraints ensure that \(x\) is a feasible deletion. For every opponent,
\[ s_x(p)-s_x(c)=\sum_t b_{t,c}y_t^\star\ge\delta^\star>0. \]
Hence \(p\) is the unique winner. This proves the claim.

3. Polynomial bit complexity and exact positivity

The standard polynomial-time theorem for rational linear programming states that feasibility and optimization are solvable in time polynomial in the dimensions and binary encoding length of the rational data. See [Adler–Beling, introduction](https://adler.ieor.berkeley.edu/ilans_pubs/lp_algebraic_stoc_1992.pdf).

Here there are \(\tau+1\) variables and \(2\tau+m+2\) inequalities. All constraint-matrix entries belong to \(\{-1,0,1\}\); the right-hand sides are input masses, \(1-\rho\), and small integers. The indicators can be constructed by scanning the supplied rankings. Consequently, the program has encoding length polynomial in \(m,\tau,L\), and it can be constructed in polynomial time.

For completeness, strict positivity also has an explicit rational separation bound. Put \(n=\tau+1\), and let \(D\) be the product of the denominators appearing in the input masses and budget. Its binary length is at most \(L+1\), and every right-hand side of the program becomes integral after multiplication by \(D\).

A linear objective on a nonempty bounded polytope attains its optimum at a vertex. At such a vertex, the active constraint normals span the full variable space: otherwise a sufficiently small perturbation in a direction orthogonal to all active normals would give two distinct feasible points whose midpoint is the vertex. Thus one can select \(n\) independent active constraints, giving
\[ Mz=v/D, \]
where \(M\) is a nonsingular integer matrix with entries in \(\{-1,0,1\}\), and \(v\) is integral.

By Cramer’s rule, the margin coordinate has the form
\[ \delta^\star=\frac{k}{D\det M} \]
for an integer \(k\). The determinant expansion gives \(|\det M|\le n!\). Therefore,
\[ \delta^\star>0 \quad\Longrightarrow\quad \delta^\star\ge\frac{1}{Dn!}. \]

The number \(1/(Dn!)\) has polynomial binary encoding length. Thus one may alternatively decide the problem by a single rational LP feasibility test, adding the constraint \(\delta\ge1/(Dn!)\). The proved separation bound makes this test exactly equivalent to strict victory, including rejection when the best margin is zero.

4. Scope of the conclusion

The proof uses neither the common order nor the two-peaked restriction. It applies to every explicitly supplied finite support.

The stated hardness of whole-vote deletion concerns an integrality requirement. The present problem allows every real mass in the specified intervals, so its feasible set is a rational polytope and the linear-programming argument settles the continuous version.
