The continuous mirror question, as graded

Given rational type masses \(\mu_t\) and exactly two approved rational population shares \(A_t=\{a_t,b_t\}\subset(0,1]\) for each type, decide whether the population can be partitioned into coalitions so every unit of mass is assigned to a coalition whose share its type approves. Equivalently, for each distinct approved share \(a\), do there exist nonnegative allocations \(x_{t,a}\) and an integer coalition count \(q_a\ge 0\) satisfying \(\sum_{a\in A_t}x_{t,a}=\mu_t\) for every type \(t\), and \(\sum_{t:a\in A_t}x_{t,a}=a q_a\) for every share \(a\)?

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a list of \(\tau\ge 1\) types with positive binary rational masses \(\mu_t\), normalized by \(\sum_t\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types.
Each type approves exactly two distinct binary rational coalition shares \(A_t=\{a_t,b_t\}\), with \(0<a_t<b_t\le 1\). Put \(S=\bigcup_t A_t\), \(m=|S|\), and let \(L\) be the total input bit length.
The population is atomless: each type's mass may be split arbitrarily among coalitions. A feasible partition consists of finitely many positive-mass coalitions covering the entire population, with every assigned portion approving its coalition's total mass.
Equivalently, feasibility means that there exist \(x_{t,a}\in\mathbb R_{\ge 0}\) for \(a\in A_t\) and \(q_a\in\mathbb Z_{\ge 0}\) for \(a\in S\), satisfying \(\sum_{a\in A_t}x_{t,a}=\mu_t\) for every type and \(\sum_{t:a\in A_t}x_{t,a}=a q_a\) for every approved share. Coalition counts have no additional bound.

Is this feasibility problem solvable in time polynomial in \(m,\tau,L\), or is it NP-hard?

For a finite list of agents, deciding whether all agents can be partitioned into coalitions of approved cardinalities is NP-complete even when each agent approves exactly two distinct sizes. [Source](https://arxiv.org/pdf/2311.02067v2).
No result settling this exact atomless model with integer coalition counts was located in the literature search.

Modeling choices made when packaging the task

  • Normalized total population mass to one, so approved population shares are coalition masses.
  • Made the mass interpretation explicitly atomless, allowing arbitrary splitting within each type.
  • Specified a finite partition covering all mass, with positive-mass coalitions and unrestricted nonnegative integer coalition counts.
  • Defined m as the number of distinct approved shares and L as the total binary input bit length; required approved shares to use binary rational encoding.
  • Made the two approved shares explicitly distinct and ordered them for notation.

Result

The feasibility problem is \(\mathrm{NP}\)-complete, even when all masses and approved shares are dyadic rationals and every type approves one common share.

The proof directly addresses the atomless model; it does not rely on transferring the [finite-agent hardness theorem](https://arxiv.org/pdf/2311.02067v2).

1. Reduction from SUBSET SUM

We use the standard \(\mathrm{NP}\)-complete problem SUBSET SUM: given positive binary-encoded integers \(w_1,\ldots,w_n\) and a target \(B\), decide whether some subset sums to \(B\). We may restrict to \(1\le B\le W\), where \(W=\sum_{i=1}^n w_i\), because targets outside this range are trivial.

Let \(\mathcal W\) be the set of distinct input weights, and let \(k_w\) be the multiplicity of \(w\in\mathcal W\). Thus

\(\displaystyle \sum_{w\in\mathcal W}k_w w=W.\)

Choose the smallest power of two \(D\) satisfying \(D>2W+2\), and define

\(\displaystyle p=D-W-1,\qquad c=\frac{D-B}{D}.\)

In particular, \(p>W+1>B\) and \(1/2<c<1\).

Construct the following society:

  • For every \(w\in\mathcal W\), create a type with mass \(\mu_w=k_w w/D\) and approval set \(\{w/D,c\}\).
  • Create one padding type with mass \(\mu_p=(p+1)/D\) and approval set \(\{p/D,c\}\).

Repeated input weights are aggregated, so this is a list of distinct supported types.

Validity and encoding size

All masses are positive, and their sum is

\(\displaystyle \sum_{w\in\mathcal W}\mu_w+\mu_p =\frac{W+p+1}{D}=1.\)

Every type approves exactly two distinct shares in the required order. For an original weight,

\(\displaystyle 0<\frac{w}{D}\le\frac{W}{D}<\frac{D-B}{D}=c,\)

because \(D>2W+2\) and \(B\le W\). For the padding type,

\(\displaystyle c-\frac pD=\frac{W+1-B}{D}>0.\)

The padding share differs from every original share because \(p>W\).

All masses and shares are dyadic rationals. Moreover,

\(\displaystyle D\le 4W+4,\)

so their binary encodings have polynomial length in the source input. The construction has

\(\displaystyle \tau=|\mathcal W|+1,\qquad m=|\mathcal W|+2.\)

It is therefore a polynomial-time construction.

2. Proof of equivalence

Write \(q_w\) for the number of coalitions of share \(w/D\), \(q_p\) for the number of padding-share coalitions, and \(q_c\) for the number of common-share coalitions.

Feasibility implies a subset summing to the target

Suppose the constructed society is feasible.

Only type \(w\) approves share \(w/D\). Consequently,

\(\displaystyle \frac{w}{D}q_w=x_{w,w/D}\le\mu_w=\frac{k_w w}{D},\)

which gives \(0\le q_w\le k_w\).

Likewise, only the padding type approves \(p/D\), so

\(\displaystyle \frac pDq_p\le\frac{p+1}{D}.\)

Since \(p>1\), this implies \(q_p\in\{0,1\}\).

Summing the feasibility equations over all types and shares gives

\(\displaystyle \sum_{w\in\mathcal W}\frac wDq_w+\frac pDq_p+cq_c=1.\)

Because \(c>1/2\), we have \(q_c\le1\). On the other hand, the total mass of all coalitions using the other shares is at most

\(\displaystyle \sum_{w\in\mathcal W}\frac wDk_w+\frac pD =\frac{W+p}{D}=\frac{D-1}{D}<1.\)

Thus \(q_c\) cannot be zero, and hence \(q_c=1\).

Substituting this into the total-mass equation and multiplying by \(D\) yields

\(\displaystyle \sum_{w\in\mathcal W}wq_w+pq_p=B.\)

Since \(p>B\) and all terms are nonnegative, \(q_p=0\). Therefore

\(\displaystyle \sum_{w\in\mathcal W}wq_w=B,\qquad 0\le q_w\le k_w.\)

Selecting \(q_w\) of the original indices with weight \(w\), for each distinct weight, produces a subset summing to \(B\).

A subset summing to the target implies feasibility

Conversely, suppose a subset of the input indices sums to \(B\). Let \(r_w\) be its number of indices with weight \(w\). Then

\(\displaystyle 0\le r_w\le k_w,\qquad \sum_{w\in\mathcal W}wr_w=B.\)

Set

\(\displaystyle q_w=r_w,\qquad q_p=0,\qquad q_c=1.\)

For each original type, assign

\(\displaystyle x_{w,w/D}=\frac{wr_w}{D},\qquad x_{w,c}=\frac{w(k_w-r_w)}{D}.\)

Assign the entire padding type to the common share:

\(\displaystyle x_{p,p/D}=0,\qquad x_{p,c}=\frac{p+1}{D}.\)

These assignments are nonnegative and exhaust every type’s mass. Each original share receives exactly its share times its coalition count. The total assigned to the common share is

\(\displaystyle \sum_{w\in\mathcal W}x_{w,c}+x_{p,c} =\frac{W-B+p+1}{D} =\frac{D-B}{D}=c.\)

Thus all feasibility equations hold.

There is also a concrete finite partition: for every \(w\), split the assigned mass \(wr_w/D\) into \(r_w\) coalitions of mass \(w/D\), and put all remaining mass into one coalition of mass \(c\). Atomlessness permits these splits, and every assigned portion approves its coalition’s mass.

This proves the reduction and establishes \(\mathrm{NP}\)-hardness.

3. Membership in \(\mathrm{NP}\)

Consider any instance of the stated problem, with total bit length \(L\).

For every feasible solution and every share \(a\), nonnegativity and total population mass one imply

\(\displaystyle 0\le aq_a\le1,\qquad q_a\le\left\lfloor\frac1a\right\rfloor.\)

If \(a=u/v\) is represented by positive binary integers, then \(q_a\le v\). Consequently each count has \(O(L)\) bits, and the entire vector of counts is a polynomial-size certificate.

Given a proposed count vector, first check that the counts are nonnegative integers within these bounds and that

\(\displaystyle \sum_{a\in S}aq_a=1.\)

The remaining question is whether the required masses can be assigned to approved shares. Construct a directed flow network with:

  • An edge from the source to each type \(t\), of capacity \(\mu_t\).
  • An edge from type \(t\) to each share \(a\in A_t\), of capacity \(\mu_t\).
  • An edge from each share \(a\) to the sink, of capacity \(aq_a\).

A feasible assignment gives a flow of value one. Conversely, a flow of value one saturates every source-to-type edge because their capacities sum to one. It also saturates every share-to-sink edge because their capacities sum to one. Its type-to-share flows therefore satisfy exactly the required feasibility equations.

This maximum-flow check is polynomial-time with binary rational capacities. Explicitly, multiply all capacities by the product of the denominators appearing in the input. That product has polynomial bit length and makes every capacity integral. A capacity-independent polynomial-time maximum-flow algorithm, such as Edmonds–Karp, then uses polynomially many operations on integers of polynomial bit length.

Thus the certificate is verifiable in time polynomial in \(m,\tau,L\), proving membership in \(\mathrm{NP}\).

4. Conclusion

The exact atomless feasibility problem with integer coalition counts is \(\mathrm{NP}\)-complete. Hence an algorithm polynomial in \(m,\tau,L\) would imply \(\mathrm{P}=\mathrm{NP}\).

The hardness already holds for dyadic input data with a common approved share, so neither arbitrary rational denominators nor indivisible agents are needed.
