The continuous mirror question, as graded

Given a finite contestant set \(N\) and a finite support \(T\) of complete juror types with positive rational masses \(\mu_t\) summing to one, determine whether there is a threshold \(q_0\) and a constructible mechanism scheme such that, for every \(q\ge q_0\) with \(q\mu_t\in\mathbb{Z}\) for all \(t\), the mechanism Nash implements the true ranking in the jury containing \(q\mu_t\) jurors of each type, for every admissible state.

Packaged proof task (what the prover saw — nothing else)

Let \(N\) contain \(m\ge 3\) contestants, and let \(\Pi\) be their strict rankings. A society is given by its support: the list of \(\tau\) types with positive binary-rational masses \(\mu_t\), where \(\sum_t\mu_t=1\); \(\tau\) is the support size, not the number of possible types. Let \(L\) be the total input bit length.
Each type specifies a designer-known set \(I_t\subsetneq\binom{N}{2}\) of indifferent pairs, encoded explicitly. For every positive integer \(q\) satisfying \(q\mu_t\in\mathbb Z\), the replica jury has \(q\mu_t\) individually identified jurors of type \(t\).
An admissible state consists of a true ranking \(\rho\in\Pi\) and, for each juror \(j\), a preference function \(R_j\) assigning a complete, transitive weak order on \(\Pi\) to every true ranking. Whenever two outcomes differ only by swapping an adjacent pair in \(I_t\), a type-\(t\) juror strictly prefers the outcome ordering that pair as in the true ranking. There are no further preference restrictions; jurors of the same type may have different admissible preference functions.
The state is common knowledge among jurors; the designer knows their types but cannot observe the state. A mechanism is deterministic, has finite message spaces, and outputs a ranking. It Nash implements truth if, in every admissible state, pure Nash equilibria exist and their outcome set is exactly \(\{\rho\}\).
A constructible scheme is one algorithm that, given the society and an eligible \(q\), produces a finite description of such a mechanism, including a terminating outcome algorithm; it cannot depend on the state. Neither anonymity nor a polynomial bound on mechanism construction is imposed.
Is deciding whether there exist an integer \(q_0\ge 3\) and a constructible scheme implementing truth for every eligible \(q\ge q_0\) solvable in polynomial time in \(m,\tau,L\), or is this decision problem NP-hard?
For finite juries with at least three jurors, known indifferent-pair sets covering every contestant pair suffice for Nash implementation; pair coverage is also necessary on this admissible-state domain. [Verified finite-jury results](https://dialnet.unirioja.es/descarga/articulo/2133084.pdf).
No separate complexity classification for this support-encoded, eventual-replica decision problem was located.

  • Interpreted a complete juror type as its fully specified indifferent-pair set, rather than a fixed preference function, preserving the anchor's quantification over all admissible preference functions.
  • Required at least three contestants and proper indifferent-pair sets, carrying over the non-impartial-juror domain; empty indifferent-pair sets remain allowed.
  • Made each replica juror's type known to the designer and fixed across states; preference functions may vary independently even among jurors of the same type.
  • Used strict contestant rankings, complete transitive weak juror preferences, and strict preference for truth-respecting adjacent swaps; imposed no restrictions on unlisted pairs.
  • Defined replication factors as positive integers and required an integer threshold of at least three, ensuring the finite-jury size condition.
  • Interpreted constructibility as a uniform effective construction of finite deterministic mechanisms, without anonymity or polynomial construction-time requirements.
  • Specified pure Nash implementation with equilibrium existence and no incorrect equilibrium outcomes.

Result

The decision problem is solvable in deterministic polynomial time. Its exact criterion is

\( \displaystyle \bigcup_{t=1}^{\tau} I_t=\binom{N}{2}. \)

If this criterion holds, one may take \(q_0=3\). The proof below also establishes the required uniform constructibility.

1. Every eligible replica has the same pair coverage

Write each mass in reduced form as \(\mu_t=a_t/b_t\), and let \(D=\operatorname{lcm}(b_1,\ldots,b_\tau)\). Every positive multiple of \(D\) is eligible, so eligible replica sizes are unbounded.

Fix an eligible \(q\). Since \(\mu_t>0\), the integer \(q\mu_t\) is at least one. Thus every supported type appears in the replica. Moreover, its total number of jurors is

\( \displaystyle \sum_{t=1}^{\tau}q\mu_t=q. \)

Let \(J_q\) denote its individually identified jurors, and assign \(I_j=I_t\) to each juror of type \(t\). Consequently,

\( \displaystyle \bigcup_{j\in J_q}I_j=\bigcup_{t=1}^{\tau}I_t. \)

In particular, replication changes multiplicities but never changes pair coverage.

2. An uncovered pair makes implementation impossible

We prove necessity directly, including the existence of the preference functions used in the impossibility argument.

Suppose \(\{a,b\}\notin\bigcup_t I_t\). Choose a ranking \(\rho\) in which \(a,b\) are adjacent, and let \(\rho'\) result from swapping them. These rankings differ in the relative order of exactly the pair \(\{a,b\}\).

For each juror \(j\), each possible true ranking \(\sigma\), and each outcome \(x\in\Pi\), define

\( \displaystyle u_j^\sigma(x)=-\left|\left\{e\in I_j:\text{the relative order of }e\text{ in }x\text{ differs from its order in }\sigma\right\}\right|. \)

Define \(R_j(\sigma)\) by weakly preferring outcomes with higher utility. This is a complete, transitive weak order.

To check admissibility, consider outcomes differing only by an adjacent swap of a pair \(e\in I_j\). Such a swap changes the relative order of \(e\) and no other contestant pair. Therefore the outcome ordering \(e\) as in \(\sigma\) has utility exactly one greater than the other outcome. The required strict preference holds. Since this construction applies to every \(\sigma\), it defines an admissible preference function.

Because \(\rho,\rho'\) disagree only on the uncovered pair, they agree on every pair in \(I_j\). Hence, for every juror and every outcome,

\( \displaystyle u_j^\rho(x)=u_j^{\rho'}(x), \qquad R_j(\rho)=R_j(\rho'). \)

Now fix any eligible replica and any proposed mechanism. At the two admissible states consisting of these same preference functions and truths \(\rho,\rho'\), respectively, every juror has identical preferences over outcomes. The induced games therefore have identical pure Nash equilibrium sets.

Implementation at truth \(\rho\) requires an equilibrium whose outcome is \(\rho\). That same message profile is an equilibrium at truth \(\rho'\), where its outcome remains \(\rho\ne\rho'\). This contradicts implementation.

Thus an uncovered pair prevents implementation for every eligible replica. Since eligible sizes are unbounded, no threshold \(q_0\) can avoid this obstruction.

3. Coverage gives finite implementation

We use the finite-jury sufficiency theorem supplied in the question:

Finite-jury theorem. For at least three jurors with designer-known proper indifferent-pair sets, coverage of every contestant pair suffices for deterministic Nash implementation of truth on the stated admissible preference domain.

The cited paper’s Theorem 1 establishes sufficiency; its appendix uses a finite message space consisting of a ranking and a permutation for each juror. Thus the result provides finite-message implementation. [Amorós, *Eliciting Socially Optimal Rankings from Unfair Jurors*, Theorem 1 and appendix](https://dialnet.unirioja.es/descarga/articulo/2133084.pdf).

Suppose now that \(\bigcup_t I_t=\binom{N}{2}\), and fix any eligible \(q\ge3\). All hypotheses hold:

  • There are exactly \(q\ge3\) jurors.
  • Their indifferent-pair sets cover every contestant pair, by Section 1.
  • Each set is proper, by the input assumptions.
  • The designer knows each juror’s type and therefore their indifferent-pair set.
  • Jurors have the admissible preference functions specified in the question, without any requirement that jurors of the same type share preferences.

The theorem therefore gives a finite implementing mechanism for this replica. It remains to justify that these separate existence statements yield one constructible scheme.

4. A uniform construction algorithm

For any fixed replica, whether a proposed finite mechanism implements truth is decidable by exhaustive finite verification.

Indeed, \(\Pi\) is finite. Every complete, transitive weak order on \(\Pi\) can be represented by an ordered partition of \(\Pi\) into indifference classes. Enumerating all ordered partitions therefore enumerates all such weak orders.

For each juror \(j\), enumerate every function assigning one of these weak orders to each \(\sigma\in\Pi\). Retain precisely the functions satisfying the required adjacent-swap comparisons for every \(\sigma\). This filtering is a finite computation: it checks finitely many truths, pairs, and outcomes.

Taking all combinations of retained functions across the individually identified jurors, together with all truths, enumerates every admissible state. In particular, the enumeration permits different preference functions for jurors of the same type.

For a candidate mechanism specified by finite message sets and an outcome table, enumerate its message profiles. At each admissible state, a profile \(z\) is a pure Nash equilibrium exactly when

\( \displaystyle g(z)\;R_j(\sigma)\;g(z'_j,z_{-j}) \)

for every juror \(j\) and every message \(z'_j\) available to that juror. All these comparisons are finite and decidable. Check that at least one equilibrium exists and that every equilibrium has outcome \(\sigma\).

Now define one construction algorithm as follows.

  • Given the society and eligible \(q\ge3\), construct its identified juror list and known sets \(I_j\).
  • For successive integers \(B=1,2,\ldots\), enumerate every vector of message-space sizes with each size between one and \(B\).
  • For each vector, enumerate every outcome table with entries in \(\Pi\), and perform the verification above.
  • Upon finding an implementing table, output its message-space descriptions, the table, and an outcome algorithm that returns the corresponding table entry.

Each stage contains finitely many candidates and terminates. Every finite mechanism occurs eventually, up to relabeling its messages. Under coverage, Section 3 guarantees that an implementing finite mechanism exists, so the search terminates.

The returned outcome algorithm also terminates, since it performs a finite table lookup. The construction uses only the society and \(q\); enumerating all possible states does not require observing the actual state.

This is one uniform constructible scheme. Its running time need not be polynomial, which the question explicitly permits. If an output is required for eligible sizes below three, the algorithm can return any fixed finite mechanism there; the implementation guarantee concerns sizes at least \(q_0=3\).

5. Polynomial-time decision procedure

Combining the preceding sections gives the equivalence

\( \displaystyle \text{eventual constructible implementation exists} \quad\Longleftrightarrow\quad \bigcup_{t=1}^{\tau}I_t=\binom{N}{2}. \)

To decide the right-hand side, initialize a Boolean table indexed by unordered contestant pairs, mark every explicitly listed pair in every \(I_t\), and accept exactly when all entries are marked.

Writing \(S=\sum_t|I_t|\), this requires \(O(m^2+S)\) elementary table operations. Pair indices use polynomially many bits, and reading the input takes polynomial time in \(L\). Hence the decision procedure runs in polynomial time in \(m,\tau,L\). It never expands a replica or searches for a mechanism.
