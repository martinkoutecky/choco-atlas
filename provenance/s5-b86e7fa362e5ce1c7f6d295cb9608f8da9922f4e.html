The continuous mirror question, as graded

Given a common set of \(n\) entities, a distribution with positive rational masses \(\mu_t\) over supported binary clusterings \(t\), where \(\sum_t \mu_t=1\), and a rational threshold \(K\), decide whether there is a binary clustering \(s^\star\) such that \(\sum_t \mu_t\,\mathrm{hd}(s^\star,t)(n-\mathrm{hd}(s^\star,t))\le K\).

Packaged proof task (what the prover saw — nothing else)

Let \(m=n\ge1\) be the number of labeled entities. A binary clustering is represented by a string in \(\{0,1\}^m\); either label class may be empty, and complementary strings represent the same partition.
A society is given by its support: a list of \(\tau\) distinct supported binary strings \(t\), each with positive binary-rational mass \(\mu_t\), where \(\sum_t\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types.
Given this society and a threshold \(K\in\mathbb Q\), decide whether some \(s^\star\in\{0,1\}^m\) satisfies \(\sum_t\mu_t\,\mathrm{hd}(s^\star,t)(m-\mathrm{hd}(s^\star,t))\le K\), where \(\mathrm{hd}\) is Hamming distance.
Let \(L\) be the total binary input length; state running times in \(m,\tau,L\).

Is this rational-mass binary clustering aggregation problem solvable in polynomial time, or is it NP-hard?

Discrete Mirkin Distance Minimization is NP-hard under polynomial-time many-one reductions; under ETH it admits no \(2^{o(m)}|I|^{O(1)}\)-time algorithm. [Chen, Hermelin, and Sorge](https://arxiv.org/abs/1807.08949v2).
The supplied results do not separately establish a complexity classification for the rational-mass formulation.

Modeling choices made when packaging the task

  • Binary clusterings and supported types are encoded as binary strings, following the discrete domain; empty label classes are allowed.
  • Complementary strings may both occur as distinct supported string types, although they represent the same partition.
  • The entity count is denoted by m=n to state running times in the requested variables; L is the total binary input length.

Classification

The problem is \(\mathrm{NP}\)-complete under polynomial-time many-one reductions, even when every mass is a dyadic rational. Under ETH, it has no algorithm running in \(2^{o(m)}L^{O(1)}\) time.

Here \(m=n\) denotes the string length, while \(\tau\) denotes the number of distinct supported strings. No equality between these parameters is assumed. For \(m=1\), every objective value is zero, so that case is trivially decidable.

1. The discrete source problem

Write
\[ f_m(s,t)=\mathrm{hd}(s,t)\bigl(m-\mathrm{hd}(s,t)\bigr). \]

The discrete problem takes an explicit collection \(t_1,\ldots,t_N\in\{0,1\}^m\) and an integer \(k\), and asks whether some \(s\in\{0,1\}^m\) satisfies
\[ F(s):=\sum_{j=1}^{N}f_m(s,t_j)\le k. \]

This is exactly the string formulation in Section 2 of [Chen, Hermelin, and Sorge](https://arxiv.org/pdf/1807.08949): their Mirkin distance equals \(f_m\), and their solution domain is all binary strings. Their supplied hardness and ETH results therefore apply to this source problem.

For completeness, the distance identity follows directly from pair disagreements. Let \(A\) be the coordinates where \(s\) and \(t\) differ, and put \(d=|A|\). A pair of coordinates has different same-class relationships in the two partitions precisely when exactly one coordinate belongs to \(A\). There are \(d(m-d)\) such unordered pairs.

Complementation causes no difficulty: \(\mathrm{hd}(\overline{s},t)=m-\mathrm{hd}(s,t)\), so
\[ f_m(\overline{s},t)=f_m(s,t). \]
Thus allowing complementary representations agrees with the partition interpretation.

2. Reduction to distinct support with normalized masses

Consider a nonempty source collection. Let \(u_1,\ldots,u_\tau\) be its distinct strings, and let \(c_i\) be the multiplicity of \(u_i\). Then
\[ c_i\ge1,\qquad \sum_{i=1}^{\tau}c_i=N,\qquad F(s)=\sum_{i=1}^{\tau}c_i f_m(s,u_i). \]

If “binary-rational” means a rational encoded by binary numerator and denominator, simply set
\[ \mu_i=\frac{c_i}{N},\qquad K=\frac{k}{N}. \]
These masses are positive and sum to one, and the new objective is exactly \(F(s)/N\). Consequently, this transformation preserves the answer.

We next prove hardness even under the stricter requirement that all masses have power-of-two denominators.

Dyadic masses

Choose a power of two \(P\) satisfying
\[ 8N\tau m^2\le P<16N\tau m^2. \]
For each support string, define
\[ a_i=\left\lfloor\frac{Pc_i}{N}\right\rfloor,\qquad r=P-\sum_{i=1}^{\tau}a_i. \]

The fractional parts of \(Pc_i/N\) sum to the integer \(r\), hence \(0\le r<\tau\). Increase \(a_i\) by one for any \(r\) distinct indices, obtaining integers \(q_i\). Set
\[ \mu_i=\frac{q_i}{P},\qquad K=\frac{2k+1}{2N}. \]

This produces a valid society:

  • Since \(P\ge N\) and \(c_i\ge1\), every \(q_i\ge1\).
  • By construction, \(\sum_iq_i=P\).
  • Every mass is dyadic.
  • The support strings remain distinct.

Moreover,
\[ \left|\mu_i-\frac{c_i}{N}\right|\le\frac1P. \]
Because \(0\le f_m(s,u_i)\le m^2/4\), the new objective
\[ G(s)=\sum_{i=1}^{\tau}\mu_i f_m(s,u_i) \]
satisfies, for every \(s\),
\[ \left|G(s)-\frac{F(s)}N\right| \le\frac{\tau m^2}{4P} \le\frac1{32N}. \]

Now \(F(s)\) is integer-valued. If the source instance is a yes-instance, some \(s\) has \(F(s)\le k\), giving
\[ G(s)\le\frac{k}{N}+\frac1{32N} <\frac{k+1/2}{N}=K. \]

If the source instance is a no-instance, every \(s\) has \(F(s)\ge k+1\), giving
\[ G(s)\ge\frac{k+1}{N}-\frac1{32N} >\frac{k+1/2}{N}=K. \]

Thus this is an answer-preserving many-one reduction. The threshold need not be dyadic, since the task expressly permits any rational \(K\).

Encoding size and hypothesis checks

The reduction leaves \(m\) unchanged and has \(\tau\le N\). Also,
\[ \log P=O\bigl(\log N+\log\tau+\log(m+1)\bigr). \]
The output length is therefore
\[ L=O\bigl(\tau m+\tau\log(N\tau(m+1))+\log(|k|+2)\bigr), \]
which is polynomial in the explicit source input length. Grouping strings, computing multiplicities, and performing the indicated integer arithmetic all take polynomial time.

An empty source collection is trivial and can be mapped to a fixed yes-instance or no-instance according to its threshold. Hence its exclusion above does not restrict the reduction.

This establishes \(\mathrm{NP}\)-hardness with distinct support, positive normalized masses, and even dyadic masses.

3. Membership in \(\mathrm{NP}\) and exact running times

A certificate is a string \(s\in\{0,1\}^m\).

To verify it exactly, write the masses as \(\mu_i=a_i/b_i\) and the threshold as \(K=c/d\), with positive denominators. Let
\[ D=d\prod_{i=1}^{\tau}b_i. \]
The required inequality is equivalent to the integer comparison
\[ \sum_{i=1}^{\tau}a_i\frac{D}{b_i}f_m(s,u_i) \le c\frac{D}{d}. \]

Since the total input length is \(L\), these integers have \(O(L+\log m)=O(L)\) bits. Computing the Hamming distances takes \(O(m\tau)\) time. Using elementary integer arithmetic, denominator clearing and evaluation take \(O(\tau L^2)\) bit operations. Thus verification takes
\[ O(m\tau+\tau L^2) \]
bit operations, proving membership in \(\mathrm{NP}\).

An exact algorithm enumerates strings whose first bit is zero. Complement invariance ensures that these representatives cover every partition. Its running time is
\[ O\bigl(2^{m-1}(m\tau+\tau L^2)\bigr). \]

4. ETH consequence

The reduction preserves string length exactly and increases input length only polynomially. Therefore, an algorithm for the rational-mass problem with running time \(2^{o(m)}L^{O(1)}\) would solve the discrete source problem in \(2^{o(m)}|I|^{O(1)}\) time, contradicting the supplied ETH lower bound.

The classification is consequently complete: the rational-mass formulation is \(\mathrm{NP}\)-complete, and a polynomial-time algorithm would imply \(\mathrm{P}=\mathrm{NP}\).
