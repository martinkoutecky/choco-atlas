The continuous mirror question, as graded

Given a candidate set \(C\) and an explicit support of \(\tau\) nonempty approval types \(A\subseteq C\), each with positive binary-rational mass \(\mu_A\) and \(\sum_A\mu_A=1\), find a nonempty committee \(W\subseteq C\) maximizing \(\mathrm{MSat}_{\mu}(W)=\sum_A\mu_A\frac{|W\cap A|}{\min(|A|,|W|)}\).

Packaged proof task (what the prover saw — nothing else)

Let \(C\) be a candidate set with \(m=|C|\geq 1\). A society is given by its support: a list of \(\tau\) distinct nonempty approval types \(A\subseteq C\), each with positive binary-rational mass \(\mu_A\), with \(\sum_A\mu_A=1\). Here \(\tau\) is the support size, not the number of possible approval types; let \(L\) be the total input bit length.
Find a nonempty committee \(W\subseteq C\), of unrestricted cardinality, maximizing \(\mathrm{MSat}_{\mu}(W)=\sum_A\mu_A\frac{|W\cap A|}{\min(|A|,|W|)}\). Any maximizing committee is acceptable.

Is this exact optimization problem solvable in time polynomial in \(m,\tau,L\), or is it NP-hard?

For finite societies given as explicit lists of agents with nonempty approval ballots, maximizing the corresponding unweighted MSat score over committees of unrestricted nonzero size is polynomial-time computable. The supplied discrete result does not establish a complexity bound for the binary-rational support formulation.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Result

The exact optimization problem is polynomial-time solvable in \(m,\tau,L\). Fixing the committee size makes the objective additive over candidates, and all necessary comparisons can be performed using integers of polynomial bit length.

1. Optimize separately for each committee size

For each approval type \(A\), write \(a_A=|A|\). Fix \(k\in\{1,\ldots,m\}\), and define the candidate weight

\(s_c(k)=\displaystyle\sum_{A:\,c\in A}\frac{\mu_A}{\min(a_A,k)}.\)

For any committee \(W\) with \(|W|=k\), interchanging two finite sums gives

\(\displaystyle \mathrm{MSat}_{\mu}(W) =\sum_A\frac{\mu_A}{\min(a_A,k)}\sum_{c\in W}\mathbf{1}_{c\in A} =\sum_{c\in W}s_c(k).\)

Order the candidates as \(c_1,\ldots,c_m\) so that \(s_{c_1}(k)\geq\cdots\geq s_{c_m}(k)\), breaking ties arbitrarily. Set \(W_k=\{c_1,\ldots,c_k\}\).

To verify optimality, any other committee of size \(k\) has the form \(\{c_{j_1},\ldots,c_{j_k}\}\), where \(j_1<\cdots<j_k\). Since \(j_i\geq i\), the ordering implies \(s_{c_{j_i}}(k)\leq s_{c_i}(k)\) for every \(i\). Consequently,

\(\displaystyle \mathrm{MSat}_{\mu}(W)=\sum_{i=1}^k s_{c_{j_i}}(k)\leq\sum_{i=1}^k s_{c_i}(k)=\mathrm{MSat}_{\mu}(W_k).\)

Thus choosing the \(k\) largest candidate weights solves the problem for size \(k\).

2. Exact arithmetic has polynomial bit complexity

Write each input mass as \(\mu_A=p_A/q_A\), with positive binary-encoded integers \(p_A,q_A\). Explicit finite binary fractions can also be converted to this representation in polynomial time.

Define

\(Q=\displaystyle\prod_A q_A,\qquad D=m!,\qquad H=QD.\)

Every integer \(d\in\{1,\ldots,m\}\) divides \(D\). Also,

\(n_A=p_A(Q/q_A)\)

is a positive integer, and the normalization of the masses gives

\(\displaystyle\sum_A n_A=Q\sum_A\mu_A=Q.\)

For each \(c\) and \(k\), compute the integer weight

\(v_c(k)=\displaystyle\sum_{A:\,c\in A}n_A\frac{D}{\min(a_A,k)}.\)

Every division here is exact, and \(v_c(k)=H s_c(k)\). Hence integer comparisons of these weights give precisely the required ordering of candidates.

Moreover,

\(0\leq v_c(k)\leq D\displaystyle\sum_A n_A=H.\)

Because the total bit length of the input denominators is at most \(L\), we have \(\log_2 Q\leq L\). Since \(m!\leq m^m\), all these weights have at most

\(B=O\!\left(L+m\log_2(m+1)\right)\)

bits. Computing the products and exact quotients above also uses integers of this bit length.

For a size-\(k\) committee, its scaled score is

\(V_k=\displaystyle\sum_{c\in W_k}v_c(k)=H\,\mathrm{MSat}_{\mu}(W_k).\)

Each approval type contributes a satisfaction between zero and one, because \(|W_k\cap A|\leq\min(a_A,k)\). Thus \(0\leq V_k\leq H\), so comparing committee scores also requires only \(B\)-bit integers.

3. Algorithm and global optimality

For every \(k\in\{1,\ldots,m\}\):

  • Compute \(v_c(k)\) for all candidates.
  • Choose the \(k\) candidates with largest weights, obtaining \(W_k\).
  • Compute \(V_k=\sum_{c\in W_k}v_c(k)\).

Return \(W_{k^\ast}\), where \(k^\ast\) maximizes \(V_k\).

For any nonempty committee \(W\), let \(k=|W|\). The fixed-size optimality proved above gives

\(\mathrm{MSat}_{\mu}(W)\leq\mathrm{MSat}_{\mu}(W_k)\leq\mathrm{MSat}_{\mu}(W_{k^\ast}).\)

Therefore the returned committee is a global maximizer.

Across all sizes, computing weights requires \(O(m^2\tau)\) integer operations; sorting requires \(O(m^2\log(m+1))\) comparisons. Ordinary integer arithmetic on \(B\)-bit operands takes polynomial time. For example, a conservative overall bound is

\(O\!\left(m^2(\tau+\log(m+1))\bigl(L+m\log(m+1)\bigr)^2\right)\)

bit operations. The algorithm never expands rational masses into individual agents.
