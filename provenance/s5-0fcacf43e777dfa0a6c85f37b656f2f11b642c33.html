The continuous mirror question, as graded

Given finite states \(S\), outcomes \(A\), complete firm classes \(\Theta\), rational shares \(\lambda_\theta\), rational evidence laws \(p_\theta(s)\), and a target rule \(f:S\to A\), determine whether an anonymous mechanism exists for an atomless population of type \((\theta,E)\), with mass \(\mu_s(\theta,E)=\lambda_\theta p_\theta(s)(E)\), that implements \(f(s)\) in every continuum Bayesian Nash equilibrium for every bounded preference profile and gives zero transfers almost everywhere in equilibrium. The mechanism may condition outcomes and per-capita transfers on individual reports and the aggregate report distribution; a mass-deception witness for classes and states should be returned when the corresponding NPD condition fails.

Packaged proof task (what the prover saw — nothing else)

Let \(S,A,\Theta\) be finite nonempty sets, with publicly observable firm classes \(|\Theta|\geq2\), and let \(f:S\to A\). Evidence articles form an explicitly listed universe of size \(m\); each class has positive binary-rational share \(\lambda_\theta\), with \(\sum_\theta\lambda_\theta=1\), and an explicitly supported rational probability law \(p_\theta(s)\) on evidence collections.
At state \(s\), an atomless society has exact masses \(\mu_s(\theta,E)=\lambda_\theta p_\theta(s)(E)\). The state is common knowledge among agents and unknown to the designer; each agent privately observes her evidence. Evidence is payoff irrelevant, and an agent may costlessly submit any \(F\subseteq E\), including all her evidence, but cannot fabricate articles or change class.
A society is given by its support: the list of the \(\tau\) types with positive mass, each with its mass as a binary rational. Here \(\tau\) is the maximum support size across states, not the number of possible types; \(L\) is the total input bit length.
An anonymous mechanism has a finite message alphabet, with evidence-feasible messages available monotonically under evidence inclusion, and common functions \(g(r,D)\in A\) and \(t(r,D)\in\mathbb R\) of a class-tagged individual report \(r\) and the aggregate report distribution \(D\); transfers are uniformly bounded. No individual identity enters these functions.
Preferences may be any measurable profile \(u_i(a,s)+t\), independent of evidence, satisfying \(\sup_{a,a',s}|u_i(a,s)-u_i(a',s)|<1\). A continuum mixed Bayesian Nash equilibrium is a measurable feasible strategy profile inducing \(D\), with almost every agent best responding while holding \(D\) fixed.
Implementation requires equilibrium existence at every state for every such preference profile, and, in every equilibrium, outcome \(f(s)\) and transfer zero almost everywhere.
For an ordered pair \((s,s')\), call \(s'\) nonrefutable at \(s\) if every \((\theta,E)\) with \(p_\theta(s)(E)>0\) has some \(E'\supseteq E\) with \(p_\theta(s')(E')>0\). A perfect mass deception consists of nonnegative flows \(x_\theta(E,F)\), supported on \(F\subseteq E\), with row sums \(\lambda_\theta p_\theta(s)(E)\) and column sums \(\lambda_\theta p_\theta(s')(F)\).
Mass NPD requires \(f(s)=f(s')\) whenever \(s'\) is nonrefutable at \(s\) and a perfect mass deception exists. The computational problem also requests an ordered pair and rational deception flows whenever mass NPD fails; no equivalence with continuum implementability is assumed.

Result

The specified anonymous atomless implementability problem is in \(\mathrm P\). More precisely, an implementing mechanism exists if and only if mass NPD holds. A violating ordered pair and rational deception flows can also be found in polynomial time.

The sufficiency proof uses discontinuous dependence on the aggregate distribution, which the stated model permits. Equilibrium existence is proved separately at every state and for every admissible preference profile. The argument establishes the atomless characterization directly; it does not apply the cited [finite-agent characterization](https://arxiv.org/html/2209.10741v4).

Write \(\mathcal E_\theta(s)=\{E:p_\theta(s)(E)>0\}\) and \(\mu_s(\theta,E)=\lambda_\theta p_\theta(s)(E)\). Extend \(\mu_s(\theta,E)\) by zero to unsupported collections.

1. Necessity of mass NPD

Suppose an anonymous mechanism implements \(f\). Fix states \(s,v\) such that \(v\) is nonrefutable at \(s\), and suppose a perfect mass deception \(x_\theta(E,F)\) exists from \(s\) to \(v\). We prove \(f(s)=f(v)\).

Use the admissible preference profile \(u_i(a,w)=0\) for every agent, outcome, and state. By the required existence property, there is an equilibrium at \(v\). Let its aggregate distribution be \(D^*\).

For each positive-mass type \((\theta,F)\) at \(v\), let \(q_{\theta,F}(r)\) be the average equilibrium mixed-report distribution among agents of that type. Because messages are finite and feasibility depends only on class and evidence, this average is a feasible probability distribution. Moreover,

\[ D^*(r)=\sum_{\theta,F}\mu_v(\theta,F)q_{\theta,F}(r). \]

Here and below, displayed equations use the same mathematical content as their inline counterparts.

Implementation at \(v\) gives zero transfers almost everywhere. Since outcome utilities are zero, every equilibrium agent obtains payoff zero. Thus, for every positive-mass type at \(v\),

\[ t(r,D^*)\leq 0 \quad\text{for every }r\in M_\theta(F), \]

where \(M_\theta(F)\) denotes its feasible messages. Otherwise every agent of that type would have a profitable deviation.

Also, whenever \(D^*(r)>0\), anonymity and implementation imply

\[ t(r,D^*)=0, \qquad g(r,D^*)=f(v). \]

Indeed, these functions have the same values for all agents using that report at the fixed aggregate.

Construct a strategy at \(s\) by assigning every positive-mass type \((\theta,E)\) the report distribution

\[ \widehat q_{\theta,E}(r) = \frac{1}{\mu_s(\theta,E)} \sum_F x_\theta(E,F)q_{\theta,F}(r). \]

The row-sum condition makes this a probability distribution. It is feasible: positive \(x_\theta(E,F)\) requires \(F\subseteq E\), so monotonicity gives \(M_\theta(F)\subseteq M_\theta(E)\).

The column-sum condition gives exactly the original aggregate:

\[ \sum_{\theta,E}\mu_s(\theta,E)\widehat q_{\theta,E}(r) = \sum_{\theta,F}\mu_v(\theta,F)q_{\theta,F}(r) = D^*(r). \]

Every copied report consequently gives transfer zero. To check all deviations, take any positive-mass source type \((\theta,E)\). Nonrefutability supplies \(E'\in\mathcal E_\theta(v)\) with \(E\subseteq E'\). Hence every message feasible for this source type is feasible for that target type, and therefore has transfer at most zero at \(D^*\).

Thus the constructed, type-dependent measurable strategy profile is an equilibrium at \(s\). It produces outcome \(f(v)\) and zero transfers almost everywhere. Implementation at \(s\) requires its outcome to be \(f(s)\), proving \(f(s)=f(v)\).

This establishes necessity.

2. A finite anonymous mechanism

Assume mass NPD holds. Let \(U\) be the evidence universe and choose any \(a_0\in A\).

A report is \(r=(\theta,\kappa,b,F)\), where \(\kappa\in S\) is a state claim, \(b\in\{0,1\}\) is an auxiliary bit, and \(F\subseteq U\) is submitted evidence. An agent of class \(\theta\) with evidence \(E\) can send exactly those reports with her own class tag and \(F\subseteq E\).

The alphabet has size \(2|\Theta||S|2^m\). It is finite, permits every evidence subset, and satisfies evidence monotonicity.

Designated aggregates

For every \(v\in S\), define the designated distribution \(D^v\) by

\[ D^v(\theta,\kappa,b,F) = \begin{cases} \mu_v(\theta,F),&\kappa=v,\ b=0,\\ 0,&\text{otherwise}. \end{cases} \]

These distributions are distinct because their state-claim coordinates differ. Let \(\mathcal C=\{D^v:v\in S\}\).

For submitted evidence \(F\), define

\[ \rho_v(\theta,F) = \begin{cases} 1,&\text{no }E'\in\mathcal E_\theta(v)\text{ contains }F,\\ 0,&\text{otherwise}. \end{cases} \]

Thus \(\rho_v(\theta,F)=1\) means the submission refutes \(v\).

Outcome and transfers at designated aggregates

If \(D=D^v\), set, for every individual report \(r=(\theta,\kappa,b,F)\),

\[ g(r,D)=f(v), \qquad t(r,D)=\rho_v(\theta,F). \]

In particular, the individual’s report does not change her outcome when the aggregate is held fixed.

Outcome and transfers elsewhere

If \(D\notin\mathcal C\), set \(g(r,D)=a_0\) for every report.

Let \(z(D)\) be the total mass of reports having auxiliary bit zero. Choose \(b^*(D)=0\) when \(z(D)<1\), and \(b^*(D)=1\) when \(z(D)=1\). Set

\[ t(r,D)=\mathbf 1\{b=b^*(D)\}. \]

Transfers are uniformly bounded between zero and one. The rules depend only on the class-tagged individual report and the aggregate. Their aggregate dependence is Borel measurable: the exceptional aggregates form a finite set, and the remaining test uses a linear aggregate statistic.

3. Verification of implementation

Fix a true state \(s\) and any admissible measurable preference profile.

Equilibrium existence

Have every agent report \((\theta,s,0,E)\), submitting all her evidence. Exact type masses make the resulting aggregate \(D^s\).

At this aggregate, every individual deviation yields outcome \(f(s)\). Moreover, an agent with positive-mass evidence \(E\) can submit only \(F\subseteq E\), and \(E\in\mathcal E_\theta(s)\) witnesses \(\rho_s(\theta,F)=0\). Thus every feasible report gives transfer zero.

Every agent is therefore best responding. This is a measurable pure equilibrium for the given preference profile.

No equilibrium outside the designated aggregates

Suppose an equilibrium had aggregate \(D\notin\mathcal C\).

At fixed \(D\), every report yields the same outcome \(a_0\). Changing only the auxiliary bit is always feasible. Consequently, every best response must use bit \(b^*(D)\), since that bit gives transfer one and the other gives zero.

If \(z(D)<1\), this forces almost every agent to use bit zero, giving \(z(D)=1\), a contradiction. If \(z(D)=1\), it forces almost every agent to use bit one, giving \(z(D)=0\), again a contradiction.

This argument also rules out mixed equilibria outside \(\mathcal C\).

Every equilibrium at a designated aggregate is correct

Suppose an equilibrium at \(s\) has aggregate \(D^v\).

First, it induces a perfect mass deception. Let \(x_\theta(E,F)\) be the mass of true type \((\theta,E)\) submitting evidence \(F\). Feasibility gives support only on \(F\subseteq E\). Its row sums are \(\mu_s(\theta,E)\), while the aggregate \(D^v\) gives column sums \(\mu_v(\theta,F)\).

Second, \(v\) must be nonrefutable at \(s\). Otherwise some positive-mass source type \((\theta,E)\) has \(\rho_v(\theta,E)=1\). Every report appearing with positive mass in \(D^v\) has evidence in \(\mathcal E_\theta(v)\), and therefore transfer zero. Almost every agent of the refuting type could instead submit all of \(E\), obtaining transfer one while retaining outcome \(f(v)\). That is a profitable deviation, contradicting equilibrium.

Mass NPD now gives \(f(s)=f(v)\). Every report used in this equilibrium has outcome \(f(v)\) and transfer zero.

Thus the mechanism implements \(f\), proving sufficiency and the characterization.

The auxiliary-bit rule is the point at which unrestricted aggregate dependence matters: it excludes undesignated equilibrium aggregates while preserving the explicitly constructed equilibrium at every state.

4. Polynomial-time decision and witnesses

For each ordered pair \((s,v)\) with \(f(s)\neq f(v)\), perform the following tests.

Nonrefutability

For each listed source type \((\theta,E)\), check whether a listed target type \((\theta,E')\) satisfies \(E\subseteq E'\).

There are at most \(\tau^2\) source–target comparisons. With evidence represented by indicator vectors, this takes \(O((m+1)\tau^2)\) elementary bit operations, apart from class-label comparisons.

Perfect mass deception

Build a directed network with a source \(o\), a sink \(d\), one left vertex for each listed type at \(s\), and one right vertex for each listed type at \(v\).

Add:

  • An arc from \(o\) to \((\theta,E)\) of capacity \(\mu_s(\theta,E)\).
  • An arc from left \((\theta,E)\) to right \((\theta,F)\), of capacity one, precisely when \(F\subseteq E\).
  • An arc from right \((\theta,F)\) to \(d\) of capacity \(\mu_v(\theta,F)\).

The graph has at most \(2\tau+2\) vertices and \(\tau^2+2\tau\) arcs.

A perfect mass deception exists if and only if the maximum flow has value one. For the forward implication, place the deception flows on the middle arcs. Their prescribed row and column sums supply a feasible unit flow.

Conversely, both the total capacity leaving \(o\) and the total capacity entering \(d\) equal one. A unit flow therefore saturates every such arc. Conservation at the intermediate vertices makes its middle-arc flows satisfy exactly the required row and column sums.

If both tests succeed, return \((s,v)\) and these middle-arc flows. This is a mass-NPD failure witness and, by necessity, a certificate of nonimplementability. If no pair succeeds, mass NPD holds and the mechanism above establishes implementability.

5. Running time and output size

Use exact arithmetic. A common denominator \(Q\) for all masses can be chosen with \(O(L)\) bits:

  • If masses are supplied directly, take the product of their denominators.
  • If supplied as \(\lambda_\theta p_\theta(s)(E)\), take the product of all input share and probability denominators.

Scale all capacities by \(Q\). They become nonnegative integers bounded by \(Q\), and the desired flow value becomes \(Q\).

The Edmonds–Karp algorithm takes \(O(VE^2)\) arithmetic operations on such a network; see [Trevisan’s maximum-flow notes](https://theory.stanford.edu/~trevisan/books/cs261.pdf). Here this is \(O(\tau^5)\). Residual capacities and flow values have \(O(L)\) bits, so additions, subtractions, and comparisons cost \(O(L)\) bit operations.

Including exact preprocessing, a conservative total bit-operation bound is

\[ O\!\left( L^3+ |S|^2\bigl((m+1)\tau^2+L\tau^5\bigr) \right). \]

Class and outcome labels can be indexed during preprocessing; their comparisons fit within this bound. Since every class has positive share, \(|\Theta|\leq\tau\). There is no additional multiplicative dependence on \(|\Theta|\) or \(|A|\); their explicit encodings are included in \(L\).

A returned deception has at most \(\tau^2\) nonzero entries. Each entry is an integer divided by \(Q\), so its encoding uses \(O(L)\) bits. Using references to the listed types, the entire flow certificate has size \(O(\tau^2L)\).

The decision algorithm does not enumerate the exponentially many evidence subsets in the implementing mechanism’s alphabet. Therefore the requested decision and witness problem is polynomial-time solvable; it could also be \(\mathrm{NP}\)-hard only if \(\mathrm P=\mathrm{NP}\).
