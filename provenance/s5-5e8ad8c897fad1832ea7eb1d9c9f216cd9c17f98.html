The continuous mirror question, as graded

Given a finite set \(S\) of sending communities, receiving types \(R\) with rational masses \(\mu_r>0\) summing to \(1\), a rational matrix \(P\) of receiving-type influence weights, an access matrix \(C\), and a target distribution \(q_r\) over the distinct sending-source states for each \(r\in R\), determine whether there is a matrix \(X\) of external influence weights such that \(q_r(s)=\sum_{r'\in R}P_{r',r}q_{r'}(s)+X_{s,r}\) for every \(s\in S,r\in R\), with \(X_{s,r}=0\) when \(C_{s,r}=0\), \(X_{s,r}>0\) when \(C_{s,r}=1\), and \(\sum_{r'\in R}P_{r',r}+\sum_{s\in S}X_{s,r}=1\) for every \(r\); if feasible, construct \(X\).

Packaged proof task (what the prover saw — nothing else)

Let \(S\) be a nonempty set of sending communities, each representing a distinct source state, and put \(m=|S|\).
A society is given by its support: a nonempty list \(R\) of \(\tau\) receiving types with positive binary rational masses \(\mu_r\) summing to \(1\); \(\tau=|R|\) is the support size, not the number of possible types.
The input includes a fixed nonnegative rational matrix \(P\in\mathbb{Q}^{\tau\times\tau}\) with column sums at most \(1\) and spectral radius \(\rho(P)<1\), and a binary access matrix \(C\in\{0,1\}^{m\times\tau}\). Assume \(1-\sum_{r'\in R}P_{r',r}>0\) exactly when column \(r\) of \(C\) is nonzero.
Here \(P_{r',r}\) is the total influence of type \(r'\) on type \(r\), already aggregated over its mass; \(C_{s,r}=1\) means that type \(r\) has access to community \(s\). Each type has a specified rational probability distribution \(q_r\) on \(S\), allowing zero probabilities.
Feasibility means existence of external influence weights \(X\in\mathbb{R}_{\geq0}^{m\times\tau}\) satisfying, for every \(s\in S,r\in R\), \(q_r(s)=\sum_{r'\in R}P_{r',r}q_{r'}(s)+X_{s,r}\), with \(X_{s,r}=0\) if \(C_{s,r}=0\) and \(X_{s,r}>0\) if \(C_{s,r}=1\), and satisfying \(\sum_{r'\in R}P_{r',r}+\sum_{s\in S}X_{s,r}=1\) for every \(r\).

Is this feasibility problem in \(\mathrm{P}\), with a rational feasible \(X\) constructible in polynomial time, or is it \(\mathrm{NP}\)-hard? State running times in \(m\), \(\tau\), and the total input bit length \(L\).

For finite receiving agents, attainable beliefs are characterized by the external influence residual being zero on inaccessible communities and strictly positive on accessible communities; feasible sending-agent weights are also characterized. Result. The feasibility problem is in \(\mathrm{P}\). Whenever feasible, its external influence matrix is unique and rational. It can be constructed using \(\mathrm{O}(m\tau^2)\) exact rational arithmetic operations, or \(\mathrm{O}(L+m\tau^2L^2)\) bit operations with elementary integer arithmetic.

1. Exact feasibility criterion

Define \(Q\in\mathbb{Q}^{m\times\tau}\) by \(Q_{s,r}=q_r(s)\), and define the residual matrix

\(V=Q-QP,\qquad V_{s,r}=q_r(s)-\sum_{r'\in R}P_{r',r}q_{r'}(s).\)

We prove that feasibility is equivalent to the following entrywise conditions:

\(C_{s,r}=0\ \Longrightarrow\ V_{s,r}=0,\qquad C_{s,r}=1\ \Longrightarrow\ V_{s,r}>0.\)

For necessity, rearranging each prescribed belief equation gives \(X_{s,r}=V_{s,r}\). Thus every feasible matrix must equal \(V\), and its required zero and positive entries imply the stated conditions. This also proves uniqueness.

For sufficiency, suppose the conditions hold and set \(X=V\). Every entry is nonnegative, the access requirements hold, and the belief equations hold by definition. It remains to verify normalization. Since each \(q_r\) is a probability distribution, for every receiving type \(r\),

\(\displaystyle \sum_{s\in S}V_{s,r} =\sum_{s\in S}q_r(s) -\sum_{r'\in R}P_{r',r}\sum_{s\in S}q_{r'}(s) =1-\sum_{r'\in R}P_{r',r}. \)

Consequently,

\(\displaystyle \sum_{r'\in R}P_{r',r}+\sum_{s\in S}X_{s,r}=1.\)

All feasibility requirements therefore hold. Because \(P\) and \(Q\) are rational, so is \(X=V\).

This proof includes columns of \(C\) that are entirely zero: every residual entry in such a column must vanish, and the displayed identity then gives the required normalization.

2. Algorithm and bit complexity

The algorithm computes \(V\), checks its entries against \(C\), and returns \(X=V\) if every check passes. Computing the matrix product directly requires \(\mathrm{O}(m\tau^2)\) rational arithmetic operations; checking the entries requires \(\mathrm{O}(m\tau)\) comparisons.

To establish a bit bound, assume the usual explicit binary encoding of rational numerators and positive denominators. Let \(D\) be the product of all denominators appearing in \(P\) and \(Q\). Their total encoded length is at most \(L\), so \(D\) has \(\mathrm{O}(L)\) bits. Set

\(A_{s,r}=Dq_r(s),\qquad B_{r',r}=DP_{r',r}.\)

These are integers. The input hypotheses imply \(0\leq q_r(s)\leq1\) and \(0\leq P_{r',r}\leq1\), hence \(0\leq A_{s,r},B_{r',r}\leq D\). Compute the integer numerators

\(\displaystyle N_{s,r}=DA_{s,r}-\sum_{r'\in R}B_{r',r}A_{s,r'}.\)

Then \(V_{s,r}=N_{s,r}/D^2\). Because \(D^2>0\), the required tests are exactly whether \(N_{s,r}=0\) or \(N_{s,r}>0\); strict positivity involves no numerical tolerance.

All intermediate integers have \(\mathrm{O}(L)\) bits. Indeed, the nonnegative partial sums satisfy

\(\displaystyle \sum_{r'\in R}B_{r',r}A_{s,r'} \leq D\sum_{r'\in R}B_{r',r} =D^2\sum_{r'\in R}P_{r',r} \leq D^2. \)

There are \(\tau^2+m\tau\) input rational entries in \(P\) and \(Q\). Constructing \(D,A,B\) uses that order of integer multiplications and exact divisions. Computing all numerators uses \(\mathrm{O}(m\tau^2)\) integer operations. Since \(m,\tau\geq1\), the former count is also \(\mathrm{O}(m\tau^2)\). Elementary multiplication and long division on \(\mathrm{O}(L)\)-bit integers each cost \(\mathrm{O}(L^2)\) bit operations. Including input reading gives the claimed bound

\(\mathrm{O}(L+m\tau^2L^2).\)

A feasible output can be represented by the fractions \(N_{s,r}/D^2\), with total output length \(\mathrm{O}(m\tau L)\). These fractions need not be reduced to represent exact rational numbers. Thus construction as well as decision takes polynomial time.

3. Role of the society representation

The masses \(\mu_r\) introduce no additional calculation: by hypothesis, \(P_{r',r}\) already contains the influence aggregated over mass. The algorithm operates directly on the \(\tau\) listed support types, without expanding them into receiving agents.

The proof does not require the spectral-radius hypothesis; it applies, in particular, to every promised input satisfying it. Fixing both \(P\) and the prescribed beliefs makes the residual—and therefore \(X\)—fully determined.

The residual criterion agrees with the finite-agent characterization in Theorem 1 of [Salami, Ying, and Sayed](https://infoscience.epfl.ch/record/287312/files/09432750.pdf). The proof and complexity bounds above follow directly from the stated society equations.
