The continuous mirror question, as graded

Given a candidate set \(C\), committee size \(k\), and a distribution \(\mu\) over approval types \(t\subseteq C\), listed with their positive rational masses, compute the \(k\)-candidate committee produced by MMS. For each nonempty \(D\subseteq C\), calculate \(v_\mu(D)\) by maximizing \(s\) subject to \(\sum_{t:c\in t} y_{t,c}\ge s\) for every \(c\in D\), \(\sum_{c\in t\cap D} y_{t,c}=\mu_t\) for every type with \(t\cap D\ne\varnothing\), and \(y_{t,c}\ge0\); then iteratively add the unelected candidate maximizing \(v_\mu(W\cup\{c\})\), using the paper’s fixed priority for ties.

Packaged proof task (what the prover saw — nothing else)

Let \(C\) be a candidate set with \(m=|C|\ge1\), and let \(1\le k\le m\). Fix a total priority order on \(C\) for breaking ties.
A society is given by its support: a list \(T\) of \(\tau\) distinct approval types \(t\subseteq C\) with positive binary rational masses \(\mu_t\), where \(\sum_{t\in T}\mu_t=1\). Here \(\tau\) is the support size, not the number of possible approval types. Empty approval types and candidates with no approvers are allowed. Let \(L\) be the total input bit length, including the priority order.
For every nonempty \(D\subseteq C\), define \(v_\mu(D)\) as the maximum of \(s\in\mathbb R\) over variables \(y_{t,c}\ge0\) indexed only by \(t\in T\) and \(c\in t\cap D\), subject to \(\sum_{t\in T:c\in t}y_{t,c}\ge s\) for each \(c\in D\), and \(\sum_{c\in t\cap D}y_{t,c}=\mu_t\) for each \(t\in T\) with \(t\cap D\ne\varnothing\).
The maximin support method (MMS) starts with \(W=\varnothing\) and repeatedly adds the highest-priority candidate among those maximizing \(v_\mu(W\cup\{c\})\) over \(c\in C\setminus W\), until \(|W|=k\). Support may be redistributed freely at each evaluation.

Is exact computation of this MMS committee possible in time polynomial in \(m,\tau,k,L\), or is it NP-hard?

For finite electorates with explicitly listed unit-weight voters, MMS is computable in polynomial time. [Discrete algorithmic result](https://arxiv.org/abs/1609.05370v2).

Modeling choices made when packaging the task

  • Normalized the masses to sum to one, following the continuous question's use of a distribution.
  • Carried over the discrete domain restriction that the candidate set is nonempty and the committee size lies between one and the number of candidates.
  • Made the fixed tie-breaking priority a total order supplied with the input and included its encoding in the total input bit length.
  • Specified that allocation variables exist only for approved candidates in the evaluated set; types approving none of that set allocate no mass.
  • Retained empty approval types and candidates with no approvers, which the discrete MMS definition permits.
  • Specified that support allocations can be recomputed freely at every evaluation, as required by MMS.

Result

Exact computation of the specified MMS committee is possible in time polynomial in \(m,\tau,k,L\). Binary rational masses can be handled directly, without expanding the society into individual voters.

The proof extends the linear-programming argument in Theorem 2 of the [cited paper](https://arxiv.org/pdf/1609.05370v2), with explicit attention to input size and exact comparisons.

1. Each score is the optimum of a polynomial-size rational linear program

Fix a nonempty \(D\subseteq C\), and define

\(T_D=\{t\in T:t\cap D\ne\varnothing\}\),
\(E_D=\{(t,c):t\in T_D,\ c\in t\cap D\}\).

Use the variables \(y_{t,c}\) for \((t,c)\in E_D\), together with \(s\), and solve:

\( \displaystyle \text{maximize }s \)

subject to

\( \displaystyle \sum_{t\in T_D:c\in t}y_{t,c}\ge s \qquad(c\in D), \)

\( \displaystyle \sum_{c\in t\cap D}y_{t,c}=\mu_t \qquad(t\in T_D), \)

\( \displaystyle y_{t,c}\ge0 \qquad((t,c)\in E_D), \qquad 0\le s\le1. \)

We first verify that adding the bounds on \(s\) preserves the optimum in the question.

For every \(t\in T_D\), choose one candidate in \(t\cap D\) and assign its entire mass \(\mu_t\) to that candidate. This gives a feasible allocation with \(s=0\). Consequently, negative values of \(s\) cannot improve the optimum.

For any feasible solution of the original program, summing the candidate constraints and then using the type equalities gives

\( \displaystyle |D|s\le\sum_{c\in D}\sum_{t\in T_D:c\in t}y_{t,c} =\sum_{t\in T_D}\mu_t\le1. \)

Thus every original feasible solution satisfies \(s\le1/|D|\le1\). The added bounds therefore preserve \(v_\mu(D)\).

Furthermore, each allocation variable satisfies \(0\le y_{t,c}\le\mu_t\le1\). The resulting feasible region is nonempty, closed, and bounded, so the maximum is attained.

The program has

\( \displaystyle |E_D|+1\le\tau|D|+1 \)

variables, and at most \(|D|+\tau\) candidate and type constraints, in addition to nonnegativity and the two bounds on \(s\). Its matrix coefficients belong to \(\{-1,0,1\}\); its right-hand sides are input masses, zero, or one. Its complete binary encoding length is therefore polynomial in \(\tau,|D|,L\).

2. The scores can be computed and compared exactly

We use the standard polynomial-time theorem for rational linear programming:

Given a linear program with binary-encoded rational coefficients, feasibility and boundedness can be decided in polynomial time in its encoding length; when a finite optimum is attained, an exact rational optimum can be computed in polynomial time.

The preceding section verifies all the required hypotheses. Hence \(v_\mu(D)\) can be computed exactly in polynomial time.

For completeness, the scores also have polynomial binary length. Write each input mass as \(\mu_t=a_t/b_t\), with positive integer denominator, and let

\( \displaystyle Q=\prod_{t\in T}b_t. \)

The binary length of \(Q\) is \(O(L)\). Let \(n=|E_D|+1\). Because the feasible region is a nonempty compact polytope, some vertex attains the optimum. At that vertex, select \(n\) linearly independent active constraints. They form a system

\( \displaystyle Ax=b, \)

where \(A\) is an integer matrix with entries in \(\{-1,0,1\}\), and \(Qb\) is integral with entries of absolute value at most \(Q\).

Cramer’s rule expresses the optimal \(s\) as

\( \displaystyle s=\frac{\det A_s(Qb)}{Q\det A}, \)

where \(A_s(Qb)\) replaces the column for \(s\) by \(Qb\). Hadamard’s inequality gives

\( \displaystyle |\det A|\le n^{n/2},\qquad |\det A_s(Qb)|\le Qn^{n/2}. \)

Thus its numerator and denominator have \(O(L+n\log(n+1))\) bits.

Two computed scores \(p_1/q_1\) and \(p_2/q_2\), with positive denominators, can consequently be compared exactly by comparing the integers \(p_1q_2\) and \(p_2q_1\). This detects equality as well as strict inequalities in polynomial time.

3. Computing the committee

Start with \(W=\varnothing\). At each round, compute the exact score \(v_\mu(W\cup\{c\})\) for every \(c\in C\setminus W\). Select the highest-priority candidate among those with maximum score, and add it to \(W\).

Every evaluated set has size at most \(k\), so each program has at most \(\tau k+1\) variables. The total number of score evaluations is

\( \displaystyle \sum_{j=0}^{k-1}(m-j)=km-\frac{k(k-1)}2\le km. \)

Each evaluation and each comparison takes polynomial time in \(m,\tau,k,L\). The entire procedure therefore takes polynomial time in these parameters.

By induction on the rounds, the procedure produces precisely the committee in the question: it starts from the same empty set, computes the defining scores exactly, and applies the same priority order at every tie.

Empty approval types contribute no variables or constraints. If a candidate in \(D\) has no approvers, its candidate constraint is \(0\ge s\), forcing the optimum to be zero. These permitted cases are therefore covered by the proof.
