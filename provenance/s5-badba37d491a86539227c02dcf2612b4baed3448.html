The continuous mirror question, as graded

Given projects \(P\), costs \(c\), budget \(b\), a satisfaction function, and a finite-support distribution \(\mu\) over approval types \(A\subseteq P\), decide whether a feasible allocation \(\pi\) has no blocker: a mass vector \(0\le z_A\le\mu_A\) with \(\sum_A z_A\ge c(Q)/b\) for some \(Q\subseteq P\), such that every type with \(z_A>0\) strictly prefers \(Q\) to \(\pi\).

A society is given by its support: the list of the \(\tau\ge1\) approval types \(A\subseteq P\) with positive mass, each mass \(\mu_A\) a binary rational, with \(\sum_A\mu_A=1\). Here \(\tau\) is the support size, not the number of possible approval sets.
A common satisfaction function \(\operatorname{sat}:2^P\to\mathbb Q_{\ge0}\) is supplied as a Boolean circuit taking a subset's incidence vector and returning a binary numerator and positive denominator. It is promised inclusion-monotone, with \(\operatorname{sat}(S)=0\) exactly when \(S=\varnothing\); additivity is not required. Type \(A\) strictly prefers \(Q\) to \(\pi\) exactly when \(\operatorname{sat}(A\cap Q)>\operatorname{sat}(A\cap\pi)\).
A blocker consists of \(Q\subseteq P\) and real masses \(0\le z_A\le\mu_A\), with \(\sum_A z_A>0\) and \(\sum_A z_A\ge c(Q)/b\), such that every type with \(z_A>0\) strictly prefers \(Q\) to \(\pi\). The allocation belongs to the core exactly when no blocker exists. Let \(L\) be the total input bit length, including the circuit; state running times in \(m,\tau,L\).

Is deciding whether the given allocation belongs to the core in \(\mathsf P\), or is its complementary blocker-existence problem \(\mathsf{NP}\)-hard?

Discrete approval-based PB can have an empty core, including under cost satisfaction \(\operatorname{sat}(S)=c(S)\); this is an existence result, not a complexity classification. [Maly](https://arxiv.org/html/2311.06132v1)

Result

Under the stated promises, blocker existence is \(\mathsf{NP}\)-complete, and core membership is \(\mathsf{coNP}\)-complete. Hardness holds already with \(\tau=1\), unit project costs, and a satisfaction function taking only the values \(\{0,1,2\}\).

Consequently, core membership is not in \(\mathsf P\) unless \(\mathsf P=\mathsf{NP}\).

1. Eliminating the real coalition masses

For a proposed project set \(Q\), define its improving types and their total mass by
\[ I(Q)=\{A:\operatorname{sat}(A\cap Q)>\operatorname{sat}(A\cap\pi)\}, \qquad M(Q)=\sum_{A\in I(Q)}\mu_A. \]

Lemma. A blocker exists exactly when some nonempty \(Q\subseteq P\) satisfies \(c(Q)\le bM(Q)\).

Proof. Suppose \((Q,(z_A)_A)\) is a blocker. Every type outside \(I(Q)\) must have \(z_A=0\). Thus
\[ \frac{c(Q)}b\le\sum_A z_A\le\sum_{A\in I(Q)}\mu_A=M(Q). \]
Moreover, \(Q\) cannot be empty: satisfaction from the empty set is zero, so no type strictly prefers it.

Conversely, suppose \(Q\ne\varnothing\) and \(c(Q)\le bM(Q)\). Because every project has positive cost, \(M(Q)>0\). Set \(z_A=\mu_A\) for \(A\in I(Q)\), and \(z_A=0\) otherwise. These masses satisfy every blocking condition. This proves the lemma.

In particular, a certificate needs only the incidence vector of \(Q\); no real-valued masses need to be supplied.

2. Verification and running times

Given \(Q\), evaluate the satisfaction circuit on \(A\cap Q\) and \(A\cap\pi\) for each of the \(\tau\) support types. Each evaluation takes \(O(L)\) Boolean operations. Compare the rational outputs exactly by cross-multiplication, sum the improving masses, and check \(c(Q)\le bM(Q)\).

Circuit outputs have at most \(O(L)\) bits. Exact sums of input costs and masses also have \(O(L)\)-bit representations: even for general numerator–denominator encodings, a common denominator can be formed by multiplying the input denominators, whose total bit length is at most \(L\). Schoolbook integer arithmetic therefore gives the conservative verification bound
\[ O\bigl((m+\tau)L^2\bigr). \]
Hence blocker existence belongs to \(\mathsf{NP}\) on the promised inputs.

Enumerating all project subsets gives a deterministic decision algorithm with running time
\[ O\bigl(2^m(m+\tau)L^2\bigr). \]

3. A reduction from satisfiability

We use the standard \(\mathsf{NP}\)-completeness of satisfiability for formulas in conjunctive normal form with three literals per clause; see these [CMU lecture notes](https://www.cs.cmu.edu/~fp/courses/flac/lectures/lecture33.html).

Let the input formula be \(\varphi=C_1\land\cdots\land C_r\), with variables \(x_1,\ldots,x_n\). We may assume \(n\ge1\), since adding an unused variable preserves satisfiability.

Projects, budget, and society

Create two literal projects \(p_i^+\) and \(p_i^-\) for every variable, together with a dummy project \(d\):
\[ P=\{p_i^+,p_i^-:1\le i\le n\}\cup\{d\}. \]

Every project costs \(1\). Set \(b=n\) and \(\pi=\{d\}\). These choices satisfy \(0<c(p)\le b\) and \(c(\pi)\le b\).

There is exactly one approval type, \(A=P\), with mass \(\mu_A=1\). Thus \(m=2n+1\) and \(\tau=1\).

For each clause \(C_j\), let \(T_j\) contain the projects corresponding to its literals: \(x_i\) corresponds to \(p_i^+\), and \(\neg x_i\) corresponds to \(p_i^-\).

Satisfaction circuit and its promises

For \(S\subseteq P\), define the Boolean predicate \(F(S)\) by requiring both:

  • \(S\cap\{p_i^+,p_i^-\}\ne\varnothing\) for every variable \(i\);
  • \(S\cap T_j\ne\varnothing\) for every clause \(j\).

Define
\[ \operatorname{sat}(S)=\mathbf 1_{\{S\ne\varnothing\}}+\mathbf 1_{\{F(S)\}}. \]

Both indicators are inclusion-monotone, so their sum is inclusion-monotone. Since \(n\ge1\), \(F(\varnothing)\) is false. Therefore \(\operatorname{sat}(\varnothing)=0\), whereas every nonempty set has satisfaction at least \(1\). All satisfaction promises are satisfied.

The circuit computes nonemptiness by an OR over project inputs. It computes \(F\) using one OR for each variable pair, one OR for each clause, and an AND of those results. The literal projects are separate inputs, so these tests contain no negated input occurrences. The sum is output as a two-bit numerator with denominator \(1\).

There are \(O(n+r)\) gates. With explicit binary wire indices, the resulting input has length \(L=O((n+r)\log(n+r+2))\), and can be constructed in polynomial time.

Because the dummy project covers no variable, \(\operatorname{sat}(\pi)=1\).

4. Correctness of the reduction

If \(\varphi\) is satisfiable, a blocker exists. Choose \(p_i^+\) when \(x_i\) is true and \(p_i^-\) when \(x_i\) is false. The resulting set \(Q\) contains exactly \(n\) projects, covers every variable, and meets every clause. Hence \(F(Q)\) holds and \(\operatorname{sat}(Q)=2>1\).

The unique type strictly prefers \(Q\). Taking its full mass \(z_A=1\) pays for \(Q\), since \(c(Q)/b=n/n=1\). Thus \(Q\) blocks.

If a blocker exists, \(\varphi\) is satisfiable. The unique type must strictly prefer its project set \(Q\), so \(\operatorname{sat}(Q)>1\), which implies \(F(Q)\).

Its coalition mass is at most \(1\), hence blocking affordability implies \(|Q|=c(Q)\le n\). But \(F(Q)\) requires at least one project from each of the \(n\) disjoint variable pairs. Consequently, \(Q\) contains exactly one project from each pair and excludes \(d\).

Assign \(x_i\) to be true exactly when \(p_i^+\in Q\). Since \(Q\) meets every \(T_j\), every clause contains a true literal. Thus this assignment satisfies \(\varphi\).

The construction is therefore a polynomial-time many-one reduction from satisfiability to blocker existence. Together with the verifier, it proves the claimed completeness results.
