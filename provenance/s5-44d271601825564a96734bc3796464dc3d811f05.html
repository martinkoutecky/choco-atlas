The continuous mirror question, as graded

Given τ agent types with rational masses μ, deterministic grand-coalition value g, and K i.i.d. uncertainty samples represented by rational piecewise-affine functions U_k on a listed common triangulation of Q(μ) = {q : 0 ≤ q_t ≤ μ_t}, with U_k(μ) = g and a promise that C_K is nonempty, compute C_K = {a ≥ 0 : μ^⊤a = g, q^⊤a ≥ max_{k ≤ K} U_k(q) for every q ∈ Q(μ)} and a minimum-cardinality I ⊆ {1,…,K} such that C_I = C_K; then instantiate the PAC instability certificate using |I|.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a list of \(\tau\geq1\) types with positive binary-rational masses \(\mu_t\), normalized by \(\sum_t\mu_t=1\); \(\tau\) counts listed types, not possible types.
Let \(Q(\mu)=\{q\in\mathbb R^\tau:0\leq q_t\leq\mu_t\}\). A coalition has mass vector \(q\); an allocation \(a\in\mathbb R^\tau_{\geq0}\) pays each unit of type \(t\) the amount \(a_t\).
Input consists of binary-rational \(g\geq0\), integers \(K\geq1\), a listed rational triangulation of \(Q(\mu)\) with \(m\) simplices, and functions \(U_1,\ldots,U_K:Q(\mu)\to\mathbb R\), specified by rational affine coefficients on each simplex that agree on shared faces. Values may be negative; \(U_k(0)=0\) and \(U_k(\mu)=g\).
For \(J\subseteq\{1,\ldots,K\}\), define \(C_J=\{a\geq0:\mu^\top a=g,\ q^\top a\geq U_k(q)\text{ for every }q\in Q(\mu),\ k\in J\}\); write \(C_K=C_{\{1,\ldots,K\}}\) and promise \(C_K\neq\varnothing\). Thus \(C_\varnothing=\{a\geq0:\mu^\top a=g\}\).
The computational problem is to obtain a finite rational halfspace description of \(C_K\) and a minimum-cardinality \(I\) with \(C_I=C_K\). Ties and repeated samples are allowed; any minimizing subset of indices is admissible. Let \(L\) be the total binary input length.
For the PAC interpretation, the functions are independent samples from an unknown distribution \(\mathbb P\) on such functions, and every \(K\)-tuple from its support has nonempty core. Define \(V(C)=\mathbb P\{U:\exists a\in C,\exists q\in Q(\mu),\ q^\top a<U(q)\}\).
Given binary-rational \(\beta\in(0,1)\), instantiate the certificate \(\mathbb P^K\{V(C_K)\leq\varepsilon(|I|)\}\geq1-\beta\), using \(\varepsilon(K)=1\) and \(\varepsilon(s)=1-(\beta/[K\binom Ks])^{1/(K-s)}\) for \(0\leq s<K\); the bound may be represented symbolically.

Is computing this core, a minimum compression subset, and its PAC certificate polynomial-time in \(m,\tau,K,L\), or is deciding whether some \(I\) satisfies \(C_I=C_K\) and \(|I|\leq r\) NP-hard, for input \(r\in\{0,\ldots,K\}\)?

For finite-agent games, a distribution-free collective instability certificate depending on minimum compression cardinality is established under nonemptiness for every multi-sample; this is a probabilistic guarantee, not a computational complexity classification. [Pantazis et al.](https://kostasmargellos.github.io/assets/downloads/publications/journals/PFFM_LCSS_2022.pdf)
Related work establishes collective feasibility certificates for uncertain polytopic feasible sets, but does not settle minimum sample-subset computation in the mass model stated here. No result settling that exact computational problem was located. [Pantazis, Fele and Margellos](https://ifatwww.et.uni-magdeburg.de/ifac2020/media/pdfs/0475.pdf)

Result

The minimum-compression decision problem is \(\mathrm{NP}\)-hard, even with exactly \(\tau=3\) types, fixed masses \(\mu=(1/4,1/4,1/2)\), \(g=1\), and nonnegative sample functions. A proposed compression subset can be verified in polynomial time on the promised valid inputs.

The core itself has a polynomial-time computable rational halfspace description. Once the compression cardinality is known, the requested PAC certificate also has a polynomial-size symbolic representation. Thus the difficulty lies in finding a minimum compression subset.

The degenerate case \(g=0\) is immediate: the promise implies \(C_K=C_\varnothing=\{0\}\), so the minimum subset is empty. The reduction below uses \(g=1\).

1. Finite core description and polynomial verification

Let \(\mathcal V\) be the set of vertices of the listed triangulation. Its cardinality satisfies \(|\mathcal V|\leq m(\tau+1)\).

Fix a sample \(k\), an allocation \(a\), and a simplex with vertices \(v_0,\ldots,v_\tau\). Every point in that simplex has a representation \(q=\sum_{i=0}^{\tau}\lambda_i v_i\), where \(\lambda_i\geq0\) and \(\sum_i\lambda_i=1\). Since \(U_k\) is affine there,

\[ q^\top a-U_k(q) =\sum_{i=0}^{\tau}\lambda_i\bigl(v_i^\top a-U_k(v_i)\bigr). \]

Consequently, the coalition inequalities hold throughout the simplex if and only if they hold at its vertices. Agreement on shared faces makes each \(U_k(v)\) unambiguous.

Define \(h_v=\max_{1\leq k\leq K}U_k(v)\). Then

\[ C_K = \left\{ a\in\mathbb R^\tau: a_t\geq0,\ \mu^\top a=g,\ v^\top a\geq h_v\ \text{for every }v\in\mathcal V \right\}. \]

Encoding the efficiency equality as two inequalities gives a rational halfspace description with at most \(\tau+2+|\mathcal V|\) halfspaces. Evaluating the rational affine functions at the listed vertices, comparing their values, and writing these inequalities require polynomial time and polynomial output length in \(m,\tau,K,L\).

Now consider a proposed subset \(I\). The same construction gives a finite description of \(C_I\). Because \(C_K\subseteq C_I\), equality holds exactly when

\[ \min_{a\in C_I}v^\top a\geq h_v \qquad\text{for every }v\in\mathcal V. \]

These minima exist: the promise makes \(C_I\) nonempty, and efficiency and positive masses imply \(0\leq a_t\leq g/\mu_t\). Each test is therefore a bounded rational linear program of polynomial encoding length. Rational linear programming is polynomial-time solvable; the bit-complexity statement is recorded, for example, in [Adler and Beling](https://adler.ieor.berkeley.edu/ilans_pubs/lp_algebraic_stoc_1992.pdf).

Thus \(|I|\leq r\) and \(C_I=C_K\) are polynomial-time verifiable.

2. A polynomial reduction from Set Cover

We reduce from Set Cover: given a nonempty universe \(E=\{1,\ldots,n\}\), sets \(S_1,\ldots,S_K\) with \(\bigcup_kS_k=E\), and \(r\in\{0,\ldots,K\}\), decide whether at most \(r\) sets cover \(E\). This is the classical \(\mathrm{NP}\)-complete Set Cover problem. [Karp](https://www.cs.umd.edu/~gasarch/BLOGPAPERS/Karp.pdf)

2.1 Fixed society and target inequalities

Set

\[ \tau=3,\qquad \mu=(1/4,1/4,1/2),\qquad g=1. \]

Write \(x_t=\mu_ta_t\). This invertible change of variables identifies the baseline allocation set with

\[ \Delta=\{x\in\mathbb R^3_{\geq0}:x_1+x_2+x_3=1\}. \]

For each universe element \(j\), define

\[ \theta_j=\frac{j}{n+1}, \qquad b_j=\frac14+\frac{\theta_j}{4}-\frac{\theta_j^2}{16}, \qquad q_j=(\theta_j/4,1/4,0). \]

The coalition inequality at \(q_j\), with right-hand side \(b_j\), becomes

\[ \theta_jx_1+x_2\geq b_j. \]

We will construct sample \(k\) so that its only substantive inequalities are precisely those indexed by \(S_k\).

2.2 An explicit triangulation with \(m=n+6\)

First triangulate the unit cube. For every permutation \(\pi\) of \(\{1,2,3\}\), take

\[ T_\pi= \operatorname{conv} \{0,e_{\pi_1},e_{\pi_1}+e_{\pi_2},(1,1,1)\}. \]

These six tetrahedra form a triangulation: \(T_\pi\) is exactly the region where \(1\geq z_{\pi_1}\geq z_{\pi_2}\geq z_{\pi_3}\geq0\).

The cube edge from \((0,1,0)\) to \((1,1,0)\) belongs to just one tetrahedron,

\[ T_*=\operatorname{conv}\{0,(0,1,0),(1,1,0),(1,1,1)\}. \]

Set \(\theta_0=0\), \(\theta_{n+1}=1\), and \(w_j=(\theta_j,1,0)\). Replace \(T_*\) by

\[ R_j= \operatorname{conv}\{0,(1,1,1),w_j,w_{j+1}\}, \qquad 0\leq j\leq n. \]

This is a conforming subdivision. Indeed, \(T_*\) is the convex hull of its two opposite edges \([0,(1,1,1)]\) and \([w_0,w_{n+1}]\); subdividing the latter edge gives the displayed tetrahedra, with disjoint interiors and triangular shared faces. The two faces of \(T_*\) incident to the subdivided edge lie on the cube boundary. Its other two faces remain unsubdivided, so neighboring tetrahedra still meet along complete faces.

Finally apply the invertible diagonal map \(D=\operatorname{diag}(1/4,1/4,1/2)\). The resulting rational triangulation covers \(Q(\mu)\), contains every \(q_j=Dw_j\), and has

\[ m=5+(n+1)=n+6. \]

Its vertices are the eight box corners and \(q_1,\ldots,q_n\).

2.3 Constructing the sample functions

For sample \(k\), prescribe nodal values as follows:

  • \(U_k(\mu)=1\);
  • \(U_k(v)=0\) at every other box corner;
  • \(U_k(q_j)=b_j\) when \(j\in S_k\), and \(U_k(q_j)=0\) otherwise.

On each tetrahedron, take the unique affine interpolant of its four nodal values. Shared-face agreement follows because the two interpolants agree at every vertex of the shared face.

These functions satisfy all required conditions, including \(U_k(0)=0\) and \(U_k(\mu)=g\). They are even nonnegative everywhere, because their nodal values are nonnegative.

The affine coefficients are computable by rational linear algebra in fixed dimension. All coordinates and nodal values have \(O(\log(n+1))\) bits, so the complete listed instance has polynomial size and is constructed in polynomial time.

For \(J\subseteq\{1,\ldots,K\}\), put \(A_J=\bigcup_{k\in J}S_k\). The vertex characterization from Section 1 now gives

\[ C_J \longleftrightarrow P_{A_J} := \left\{ x\in\Delta: \theta_jx_1+x_2\geq b_j \ \text{for every }j\in A_J \right\}. \]

Every other nodal inequality is automatic from nonnegativity or efficiency.

2.4 Verifying nonemptiness

The allocation \(a^*=(1,1,1)\), corresponding to \(x^*=\mu\), satisfies every target inequality, since

\[ \theta_jx^*_1+x^*_2-b_j = \frac{\theta_j^2}{16}>0. \]

It also satisfies all remaining vertex inequalities. Therefore every constructed sample admits the same allocation.

In particular, the reduction satisfies the promised nonemptiness condition. More strongly, every multisample of any length drawn from these constructed functions has nonempty core.

2.5 Every universe element is indispensable

For each \(i\in E\), define

\[ \delta=\frac{1}{32(n+1)^2} \]

and the allocation coordinates

\[ \widehat x^{\,i} = \left( \frac14-\frac{\theta_i}{8}, \frac14+\frac{\theta_i^2}{16}-\delta, \frac12+\frac{\theta_i}{8}-\frac{\theta_i^2}{16}+\delta \right). \]

These coordinates sum to one and are strictly positive. In particular, the first exceeds \(1/8\), the second is positive because \(\delta\leq1/128\), and the third exceeds \(1/2\). Hence \(\widehat x^{\,i}\in\Delta\).

For any \(j\),

\[ \theta_j\widehat x^{\,i}_1+\widehat x^{\,i}_2-b_j = \frac{(\theta_j-\theta_i)^2}{16}-\delta. \]

For \(j=i\), this equals \(-\delta<0\). For \(j\neq i\), the spacing \(|\theta_j-\theta_i|\geq1/(n+1)\) gives

\[ \frac{(\theta_j-\theta_i)^2}{16}-\delta \geq \frac{1}{16(n+1)^2}-\delta = \delta>0. \]

Thus \(\widehat x^{\,i}\) violates precisely inequality \(i\) and satisfies every other target inequality.

2.6 Equivalence with Set Cover

Because \(\bigcup_kS_k=E\), the full core corresponds to \(P_E\).

If \(A_I=E\), then \(C_I=C_K\). Conversely, if \(A_I\neq E\), choose \(i\in E\setminus A_I\). The witness \(\widehat x^{\,i}\) belongs to \(P_{A_I}\) but not \(P_E\), so \(C_I\neq C_K\).

Therefore

\[ C_I=C_K \quad\Longleftrightarrow\quad \bigcup_{k\in I}S_k=E. \]

The minimum compression cardinality equals the minimum Set Cover cardinality exactly. This proves the claimed \(\mathrm{NP}\)-hardness, with fixed \(\tau=3\) and a triangulation of linear size.

3. Direct proof of the PAC certificate

Let \(B=C_\varnothing\), and for a function \(U\) define its feasible allocation set

\[ F(U)= \{a\in B:q^\top a\geq U(q)\text{ for every }q\in Q(\mu)\}. \]

Then \(C_J=\bigcap_{j\in J}F(U_j)\), with the empty intersection interpreted as \(B\), and

\[ V(C)=\mathbb P\{U:C\not\subseteq F(U)\}. \]

The following proof uses only independence and this intersection structure. Rational finite descriptions give a countable function class, so the events are measurable under the usual discrete interpretation.

Write \(s_K=\min\{|I|:C_I=C_K\}\). Fix \(s<K\) and a fixed index subset \(J\) of size \(s\). Conditional on the samples indexed by \(J\), the set \(C_J\) is fixed.

If \(C_J=C_K\), every remaining sample must contain all of \(C_J\) in its feasible set. Independence therefore gives

\[ \mathbb P^K\{C_J=C_K,\ V(C_J)>\varepsilon(s)\} \leq (1-\varepsilon(s))^{K-s}. \]

For the specified choice

\[ \varepsilon(s) = 1- \left(\frac{\beta}{K\binom Ks}\right)^{1/(K-s)}, \]

the right-hand side equals \(\beta/[K\binom Ks]\).

If \(V(C_K)>\varepsilon(s_K)\) and \(s_K<K\), some minimum compression subset \(J\) realizes one of these events with \(s=s_K\). When \(s_K=K\), failure is impossible because \(\varepsilon(K)=1\). Taking a union bound over all subset sizes and index subsets yields

\[ \mathbb P^K\{V(C_K)>\varepsilon(s_K)\} \leq \sum_{s=0}^{K-1} \binom Ks \frac{\beta}{K\binom Ks} = \beta. \]

Hence the requested certificate holds:

\[ \mathbb P^K\{V(C_K)\leq\varepsilon(|I|)\}\geq1-\beta \]

for any minimum compression subset \(I\). Uniqueness is unnecessary, so ties and repeated samples cause no difficulty.

Given \(|I|\), symbolic instantiation is polynomial-time: \(\binom K{|I|}\) has at most \(K+1\) binary digits, and the rational-root expression can be retained exactly.

4. Computational consequences

The complete classification is:

  • Core description: polynomial-time computable.
  • Verification of a proposed compression subset: polynomial-time on promised valid inputs.
  • Minimum compression: \(\mathrm{NP}\)-hard, already for \(\tau=3\).
  • PAC certificate given the compression cardinality: polynomial-time symbolically computable.

Thus the combined requested computation cannot be polynomial-time unless \(\mathrm P=\mathrm{NP}\).

For comparison, when \(\tau=2\), every single-sample core is a nonempty closed interval on the efficiency line. Their intersection is determined by a largest lower endpoint and a smallest upper endpoint, each supplied by one sample. Consequently, a compression subset of size at most two always exists; testing all subsets of size at most two finds a minimum in polynomial time. For \(\tau=1\), the promised core equals the singleton baseline, and the empty subset suffices.
