The anchor (named result in the paper)

Theorem 3 — class: hardness

The continuous mirror question, as graded

Given finite types \(T\), rational masses \(\mu_t>0\) summing to \(1\), and symmetric binary compatibilities \(a_{ts}=a_{st}\), choose \(y_S\geq 0\) for every multiset \(S\) of three types, with \(\sum_S m_t(S)y_S=\mu_t\) for each \(t\). Define \(u_t(S)=\sum_s (m_s(S)-\mathbf{1}[s=t])a_{ts}\) and \(D_t(S;y)=\sum_{R\ni t}m_t(R)y_R\mathbf{1}[u_t(S)>u_t(R)]\). Require that no \(S\) has \(D_t(S;y)>0\) for every distinct type \(t\) in \(S\). Find a stable \(y\) maximizing \(W(y)=\sum_S y_S\sum_t m_t(S)u_t(S)\), or report that no stable \(y\) exists.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a nonempty list \(T\) of \(\tau\) types with positive binary rational masses \(\mu_t\) summing to \(1\); \(\tau\) counts supported types, not possible types. Input also includes \(a\in\{0,1\}^{T\times T}\) with \(a_{ts}=a_{st}\); \(a_{tt}\) values a distinct partner of the same type, not oneself.
Let \(\mathcal S\) contain all unordered multisets of three types, allowing repetitions, and let \(m_t(S)\) denote multiplicity. An allocation consists of real \(y_S\geq0\) satisfying \(\sum_{S\in\mathcal S}m_t(S)y_S=\mu_t\) for every \(t\); all mass is assigned to triples.
For \(t\) occurring in \(S\), define \(u_t(S)=\sum_{s\in T}(m_s(S)-\mathbf1[s=t])a_{ts}\) and \(D_t(S;y)=\sum_{R\in\mathcal S:m_t(R)>0}m_t(R)y_R\mathbf1[u_t(S)>u_t(R)]\), where \(\mathbf1\) is the indicator.
An allocation is stable if no \(S\in\mathcal S\) satisfies \(D_t(S;y)>0\) for every distinct type occurring in \(S\). Thus blocking uses strictly improving positive submasses, including repeated types; utility ties do not block.
The computational problem is to find a stable allocation maximizing \(W(y)=\sum_{S\in\mathcal S}y_S\sum_{t:m_t(S)>0}m_t(S)u_t(S)\), or report that no stable allocation exists. Let \(L\) be the total input bit length; the room size is fixed at \(3\), and there is no separate candidate parameter \(m\).

Is this exact continuous welfare optimization problem solvable in polynomial time in \(\tau\) and \(L\), or is it \(\mathrm{NP}\)-hard?

For finite agents with symmetric binary valuations, maximizing welfare among stable matchings into triples is \(\mathrm{NP}\)-hard; a stable matching always exists and can be found in \(O(n^3)\) time, where \(n\) is the number of agents. [Source](https://eprints.gla.ac.uk/245422/2/245422.pdf)
No result settling this exact continuous optimization problem was identified in the literature search.

Modeling choices made when packaging the task

  • Diagonal compatibilities are binary input values describing valuations between distinct agents of the same type; self-valuation is excluded by the utility formula.
  • The allocation variables range over nonnegative reals, while the input masses remain binary rationals.
  • Full assignment is retained from the graded question, corresponding to the discrete option of matching every agent; no unmatched mass is introduced.
  • Repeated types represent distinct members of a nonatomic population, and blocking requires positive improving mass for each distinct participating type.
  • There is no candidate parameter m in this model; running times are expressed in support size tau and total input bit length L.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

1. Result

The exact continuous optimization problem is polynomial-time solvable in \(\tau\) and \(L\).

In fact, every welfare-maximizing feasible allocation is stable. Thus one can discard the stability constraints and solve a single linear program. The proof depends essentially on allowing fractional allocations and repeated-type triples.

2. Edge counts and a local construction

For a triple multiset \(R=\{r_1,r_2,r_3\}\), define its valued-edge count by
\(e(R)=a_{r_1r_2}+a_{r_1r_3}+a_{r_2r_3}\).
The three positions represent distinct individuals, even when their types coincide. Symmetry gives
\(\sum_{t:m_t(R)>0}m_t(R)u_t(R)=2e(R)\).
Consequently, \(W(y)=2F(y)\), where
\(F(y)=\sum_R e(R)y_R\).

We first construct an auxiliary nonnegative triple vector \(z(P)\) for any pair multiset \(P=\{p,q\}\). It consumes exactly the type masses specified by \(P\), namely one unit of each endpoint if they differ and two units of their common type otherwise.

If \(p\ne q\), set
\(z(P)_{\{p,p,q\}}=z(P)_{\{p,q,q\}}=\frac13\),
with all other coordinates zero. Indeed, each endpoint’s consumed mass is \(\frac23+\frac13=1\). Its valued-edge total is
\(g(P):=\sum_R e(R)z(P)_R=\frac{4a_{pq}+a_{pp}+a_{qq}}3\).

If \(p=q\), set
\(z(P)_{\{p,p,p\}}=\frac23\).
This consumes two units of type \(p\), and \(g(P)=2a_{pp}\).

Writing \(b(P)=a_{pq}\), both cases give
\(g(P)\ge b(P)\).
Moreover, if \(b(P)=1\), then
\(g(P)-b(P)\ge\frac13\).

Thus two retained partners can be reassigned without losing their valued edge, and with a strict gain when that edge is valued.

3. Welfare maximizers contain no one-edge triples

Let \(y\) maximize welfare over all feasible allocations. Suppose \(y_R>0\) for a triple \(R\) with \(e(R)=1\).

Choose the endpoints of its unique valued edge as a pair multiset \(P\), and denote the remaining type by \(r\). For any \(0<\delta\le y_R\), remove \(\delta\) units of \(R\), add the triple vector \(\delta z(P)\), and add \(\frac{\delta}{3}\) units of \(\{r,r,r\}\).

This preserves every type’s mass: \(\delta z(P)\) consumes precisely the two endpoint masses, and the pure triple consumes precisely the remaining mass. All coordinates remain nonnegative.

Since \(b(P)=1\), the change in \(F\) is
\(\delta\bigl(g(P)+a_{rr}-1\bigr)\ge\frac{\delta}{3}>0\).
This contradicts welfare optimality.

Therefore
\(y_R>0\ \Longrightarrow\ e(R)\ne1\).

4. Every welfare maximizer is stable

Fix a welfare-maximizing feasible allocation \(y\). Suppose, for contradiction, that a triple multiset \(S=\{t_1,t_2,t_3\}\) blocks it.

For every distinct type \(t\) in \(S\), the condition \(D_t(S;y)>0\) implies that some triple \(R\) satisfies
\(y_R>0\), \(m_t(R)>0\), and \(u_t(R)<u_t(S)\).
This follows directly because the defining sum for \(D_t\) has finitely many nonnegative terms.

For each position \(i\), choose such a source triple \(R_i\) for type \(t_i\), and distinguish one occurrence of \(t_i\) in \(R_i\). Sources may coincide, including when \(S\) repeats a type. Let
\(k_i=u_{t_i}(R_i)\),
and let \(P_i\) be the pair remaining after deleting the distinguished occurrence. Put \(b_i=b(P_i)\). Counting edges incident to the distinguished position gives
\(e(R_i)=k_i+b_i\).

Choose \(\delta>0\) sufficiently small that all three source copies can be removed simultaneously. Explicitly, if a triple \(R\) occurs \(c_R\) times among the sources, take
\(\delta\le\min_{R:c_R>0} y_R/c_R\).

Now remove \(\delta\) units of each source copy, add \(\delta\) units of \(S\), and add \(\delta z(P_i)\) for each \(i\). This produces a nonnegative allocation \(y'\).

It is feasible because the removed distinguished occurrences have exactly the multiset of types \(S\), while each \(z(P_i)\) restores the corresponding remaining pair. Its change in valued-edge total is
\(F(y')-F(y)=\delta\left(e(S)-\sum_{i=1}^3k_i+\sum_{i=1}^3\bigl(g(P_i)-b_i\bigr)\right)\).

We show that this quantity is strictly positive.

The three positions of \(S\), with edges given by their binary valuations, form a simple graph on three positions. A blocking triple cannot have an isolated position: that position would have utility zero, which cannot strictly exceed its nonnegative current utility. Hence only the following two cases are possible.

  • Two valued edges. The utilities in \(S\) are \(2,1,1\). Strict improvement and integrality of utilities imply that the corresponding source utilities are at most \(1,0,0\). Thus \(\sum_i k_i\le1\), and

\(F(y')-F(y)\ge\delta(2-1)>0\).

  • Three valued edges. Every utility in \(S\) is two, so each \(k_i\le1\). If \(\sum_i k_i<3\), then

\(F(y')-F(y)\ge\delta\left(3-\sum_i k_i\right)>0\).
Otherwise all \(k_i=1\). Since \(y_{R_i}>0\), Section 3 excludes \(e(R_i)=1\). The identity \(e(R_i)=1+b_i\), together with \(b_i\in\{0,1\}\), therefore forces every \(b_i=1\). Consequently,
\(F(y')-F(y)\ge\delta\sum_{i=1}^3\frac13=\delta>0\).

Both cases contradict welfare optimality. Thus \(y\) is stable.

This argument includes all repeated-type cases: it operates on distinguished positions, allows coinciding source triples, and preserves type multiplicities exactly.

5. Exact polynomial-time algorithm

Enumerate the \(\binom{\tau+2}{3}\) triple multisets and solve the rational linear program with objective
\(\max_y\sum_{S\in\mathcal S}2e(S)y_S\),
subject to
\(\sum_{S\in\mathcal S}m_t(S)y_S=\mu_t\) for every \(t\in T\), and \(y_S\ge0\) for every \(S\).

The required hypotheses for rational linear programming are satisfied:

  • The feasible set is nonempty: assign \(y_{\{t,t,t\}}=\mu_t/3\) for each type.
  • Summing the mass equations yields \(3\sum_S y_S=1\), so the feasible set is bounded and closed. Therefore an optimum exists.
  • There are \(O(\tau^3)\) variables and \(\tau\) equality constraints. Matrix entries belong to \(\{0,1,2,3\}\), objective coefficients to \(\{0,2,4,6\}\), and the right-hand sides are the input rational masses. The LP’s binary encoding length is polynomial in \(\tau\) and \(L\).

The standard polynomial-time theorem for rational linear programming therefore provides an exact rational optimum in polynomial time. By Section 4, every returned optimum is stable. Since it maximizes welfare over all feasible allocations, it also maximizes welfare among stable allocations. A stable allocation always exists, so the “no stable allocation” outcome is never needed.

The [finite-agent hardness result](https://eprints.gla.ac.uk/245422/2/245422.pdf) does not transfer to this model. Here the fractional replacement of a pair by repeated-type triples is feasible and is precisely what makes the improvement argument work.
