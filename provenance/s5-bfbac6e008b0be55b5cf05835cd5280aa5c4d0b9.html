Theorem 5.1 — class: algorithmic

The continuous mirror question, as graded

Given a finite type set \(T\), rational population distribution \(\mu\), finite category set \(Q\), additive values \(u_\theta(q)\), per-capita supplies \(\lambda_q\), an exact integer scaling sequence \(N_k\) with \(N_k\mu_\theta,N_k\lambda_q\in\mathbb Z\), and a target \(r_\theta\) obtained from the paper’s share \(s\) along that sequence, compute the supremal \(\alpha\) for the limit of the original one-good online process on \(N_k\lambda_q\) indivisible copies, against every adversarial arrival order, such that every positive-mass type-\(\theta\) state \(b\in\mathbb Z_{\ge0}^{Q}\) ends with \(u_\theta\cdot b\ge\alpha r_\theta\). Represent the limiting policy by mass transitions \(\eta_{\theta,b}\to\eta_{\theta,b+e_q}\), while every underlying agent receives an integral bundle.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: the list \(T\) of its \(\tau\) positive-mass types, with binary-rational masses \(\mu_\theta>0\) summing to \(1\); \(\tau\) is the support size, not the number of possible types.
Let \(Q\) be a nonempty category set, \(m=|Q|\). Inputs also include binary-rational additive values \(u_\theta(q)\ge0\), supplies \(\lambda_q\ge0\), and targets \(r_\theta\ge0\); let \(L\) be the total input bit length.
A share \(s(V,n)\ge0\) depends only on an agent's value multiset \(V\) and the number \(n\) of agents; it is feasible if every finite additive-goods instance admits a complete allocation giving every agent at least her share.
Let \(D\) be the least common denominator of the masses and supplies and \(N_k=kD\). The targets are supplied explicitly, with the promise that some feasible share satisfies \(r_\theta=\lim_{k\to\infty}s(V_{\theta,k},N_k)\), where \(V_{\theta,k}\) contains \(N_k\lambda_q\) copies of \(u_\theta(q)\) for every \(q\).
At scale \(k\), there are \(N_k\mu_\theta\) agents of type \(\theta\) and \(N_k\lambda_q\) indivisible goods of category \(q\). A deterministic policy knows these data, observes each arriving category, and immediately assigns that whole good irrevocably to one agent; every good must be assigned.
An adaptive adversary chooses each next category after observing previous assignments, subject to the prescribed total category counts; the policy cannot observe future arrivals.
Write \(\eta^{(k)}_{\theta,b}\) for the number of type-\(\theta\) agents holding bundle \(b\in\mathbb Z_{\ge0}^{Q}\), divided by \(N_k\). Initially \(\eta^{(k)}_{\theta,0}=\mu_\theta\); assigning a category-\(q\) good moves mass \(1/N_k\) from \((\theta,b)\) to \((\theta,b+e_q)\), where \(e_q\) is the category unit vector.
A family of such policies guarantees \(\alpha\in[0,1]\) in the limit if, for every sequence of adversarial executions, every coordinatewise subsequential limit \(\eta\) of the terminal mass profiles satisfies \(\eta_{\theta,b}>0\Rightarrow\sum_{q\in Q}u_\theta(q)b_q\ge\alpha r_\theta\). Limiting policies are represented by limits of these mass transitions, retaining integral bundles for individual agents.
Let \(\alpha^*\) be the supremum of the factors guaranteed by policy families. Is computing \(\alpha^*\) polynomial-time solvable or NP-hard, with hardness understood for deciding \(\alpha^*\ge a\) for a binary-rational \(a\in[0,1]\)? State running times in \(m,\tau,L\), including the encoding of \(a\).
For finite societies, every feasible share can be guaranteed online with exact per-agent value-multiset predictions; the construction is polynomial-time when an offline share-achieving allocation is polynomial-time computable, with simulation overhead \(O(M^2n)\) for \(M\) goods and \(n\) agents. This guarantees the specified share, without computing the optimal factor; no result for the limiting optimization problem is supplied here.

Conclusion

On every input satisfying the promise, \(\alpha^*=1\). Consequently, computing \(\alpha^*\), and deciding whether \(\alpha^*\ge a\) for the stipulated \(a\in[0,1]\), are polynomial-time solvable.

This holds for arbitrary support size, positive targets, and adaptive arrival orders. The decisive assumptions are the feasible-share promise, the supplied finite online guarantee, and the restriction \(\alpha\in[0,1]\).

1. Apply the finite guarantee at each scale

Fix a feasible share \(s\) witnessing the promise, and write
\[ s_{\theta,k}=s(V_{\theta,k},N_k). \]

By hypothesis, \(s_{\theta,k}\to r_\theta\) for every \(\theta\in T\).

At scale \(k\), the prescribed population and category counts are integers because \(N_k=kD\). Each type-\(\theta\) agent has exactly the value multiset \(V_{\theta,k}\), independently of the arrival order. Thus the data provide the exact per-agent value-multiset predictions required by the supplied finite online theorem.

That theorem supplies a deterministic online policy \(P_k\) under which every type-\(\theta\) agent receives utility at least \(s_{\theta,k}\). Select such a policy for every \(k\).

The guarantee also covers adaptive adversaries: every completed adaptive execution produces an arrival word with the prescribed counts, and the deterministic policy succeeds for every such word.

2. Prove the limiting guarantee

Consider any sequence of adversarial executions of these policies, and any coordinatewise convergent subsequence of their terminal profiles, with limit \(\eta\).

Fix a type \(\theta\) and an integral bundle \(b\). Define its utility by
\[ v_\theta(b)=\sum_{q\in Q}u_\theta(q)b_q. \]

Suppose \(v_\theta(b)<r_\theta\). Set \(\varepsilon=(r_\theta-v_\theta(b))/2>0\). Convergence of the promised shares implies that, for all sufficiently large \(k\),
\[ s_{\theta,k}>r_\theta-\varepsilon>v_\theta(b). \]

Every type-\(\theta\) agent receives utility at least \(s_{\theta,k}\), so no such agent can finish with bundle \(b\). Therefore \(\eta^{(k)}_{\theta,b}=0\) for every sufficiently large \(k\), uniformly over all adversarial executions. Coordinatewise convergence gives \(\eta_{\theta,b}=0\).

Taking the contrapositive establishes
\[ \eta_{\theta,b}>0 \quad\Longrightarrow\quad \sum_{q\in Q}u_\theta(q)b_q\ge r_\theta. \]

This is precisely the required guarantee for \(\alpha=1\).

3. The limit retains the population mass

The preceding conclusion does not depend on population mass escaping to unbounded bundles.

Indeed, let \(C=\sum_{q\in Q}\lambda_q\) and \(|b|_1=\sum_{q\in Q}b_q\). Every complete terminal allocation satisfies
\[ \sum_{\theta,b}|b|_1\eta^{(k)}_{\theta,b}=C. \]

Hence, for every nonnegative integer \(R\),
\[ \sum_{\theta,\;|b|_1>R}\eta^{(k)}_{\theta,b} \le \frac{C}{R+1}. \]

There are finitely many bundles with \(|b|_1\le R\). Passing to a coordinatewise limit therefore yields, for each type,
\[ \mu_\theta-\frac{C}{R+1} \le \sum_{|b|_1\le R}\eta_{\theta,b} \le \mu_\theta. \]

Letting \(R\to\infty\) proves \(\sum_b\eta_{\theta,b}=\mu_\theta\). Coordinatewise convergent subsequences exist by diagonal extraction, since the coordinates form a countable family and each lies in \([0,1]\).

4. Optimality and running time

Section 2 proves \(\alpha^*\ge1\). The definition restricts all admissible factors to \([0,1]\), so \(\alpha^*\le1\). Thus \(\alpha^*=1\).

An algorithm computing the optimal value simply returns the binary-rational number \(1\). The decision algorithm returns YES for every promised input and allowed threshold \(a\).

Let \(\ell_a\) denote the encoding length of \(a\). If \(L\) excludes that encoding, reading the input takes \(O(L+\ell_a)\) time; if \(L\) already includes it, the time is \(O(L)\). After reading, the answer takes \(O(1)\) time. These bounds are polynomial in \(m,\tau,L,\ell_a\), without expanding the replicated societies.

This classification concerns computing the optimal factor. It does not assert a polynomial-time construction of the guaranteeing policies from the compressed input: the supplied construction has additional offline-computation requirements.
