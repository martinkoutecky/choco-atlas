Theorem 5.1 — class: algorithmic

The continuous mirror question, as graded

Given a finite type set \(T\), rational population distribution \(\mu\), finite category set \(Q\), additive values \(u_\theta(q)\), per-capita supplies \(\lambda_q\), an exact integer scaling sequence \(N_k\) with \(N_k\mu_\theta,N_k\lambda_q\in\mathbb Z\), and a target \(r_\theta\) obtained from the paper’s share \(s\) along that sequence, compute the supremal \(\alpha\) for the limit of the original one-good online process on \(N_k\lambda_q\) indivisible copies, against every adversarial arrival order, such that every positive-mass type-\(\theta\) state \(b\in\mathbb Z_{\ge0}^{Q}\) ends with \(u_\theta\cdot b\ge\alpha r_\theta\). Represent the limiting policy by mass transitions \(\eta_{\theta,b}\to\eta_{\theta,b+e_q}\), while every underlying agent receives an integral bundle.

For each \(N_k\), form \(N_k\mu_\theta\) agents of type \(\theta\) and \(N_k\lambda_q\) indivisible goods of category \(q\); an arriving \(q\)-good must irrevocably be assigned to one agent, and the adversary chooses its order.
For a feasible single-shot share \(s\), let \(V_{\theta,k}\) contain \(N_k\lambda_q\) copies of \(u_\theta(q)\) for every \(q\), and let \(r_\theta=\lim_k s(V_{\theta,k},N_k)\), assumed specified by the instance. In the limit, type-\(\theta\) mass in integral bundle state \(b\in\mathbb Z_{\ge0}^{Q}\) is \(\eta_{\theta,b}\), initially \(\eta_{\theta,0}=\mu_\theta\); assigning a \(q\)-good induces transitions \(\eta_{\theta,b}\to\eta_{\theta,b+e_q}\).

Target. Is computing the supremal \(\alpha\) for which an online limiting mass-transition policy guarantees \(u_\theta\cdot b\ge\alpha r_\theta\) for every final positive-mass state \((\theta,b)\), against every adversarial arrival order, polynomial-time solvable or NP-hard?

Result

Computing the supremal \(\alpha\) is \(\mathrm{NP}\text{-hard}\) under binary encoding. This holds with one agent type, strictly positive integer utilities, and one fixed, polynomial-time computable feasible share.

The proof gives a gap between yes- and no-instances, so it applies to the supremum without assuming that an optimal policy exists.

1. A fixed feasible share

For a multiset \(V\) of nonnegative values and a positive integer \(m\), define \(s(V,m)\) as the \(m\)-th largest value, or zero if there are fewer than \(m\) goods.

This share is feasible, even for heterogeneous additive valuations. When there are at least \(m\) goods, let the agents successively choose their favorite remaining good. Before any agent chooses, at most \(m-1\) goods have disappeared, so at least one of that agent’s \(m\) highest-valued goods remains. Every agent therefore receives its share. Allocate leftovers arbitrarily. When there are fewer goods, every share is zero.

We use this same share throughout the reduction.

2. Reduction and encoding

We reduce from PARTITION: given positive integers \(a_1,\ldots,a_n\) with total \(2A\), decide whether some subset sums to \(A\). This problem is \(\mathrm{NP}\text{-complete}\); see Theorem 8.6.4 in [*Introduction to Combinatorial Optimization*](https://personal.utdallas.edu/~dxd056000/cs6363/LectureNotes.pdf). Restricting to even totals preserves hardness: multiplying every input integer by two enforces this restriction and preserves the answer.

Assume \(n\ge 2\). Define

\(D=n+1,\qquad L=2nA+1,\qquad d_i=LD^{i-1},\qquad S=\sum_{i=1}^{n}d_i.\)

Next define

\(R=d_n+2A,\qquad K=nR+S+A+1,\qquad H=nK+S+A.\)

There is one agent type, with mass \(\mu=1\). For each index \(i\), introduce two categories \(q_i^0,q_i^1\), with supplies and utilities

\(\lambda_{q_i^0}=\lambda_{q_i^1}=\frac12,\qquad u(q_i^0)=K+d_i,\qquad u(q_i^1)=K+d_i+a_i.\)

Take \(N_k=2k\), so every population and supply count is integral.

There are \(2n\) categories. All constructed integers have bit length \(O(n\log n+\log A)\), so the construction takes polynomial time.

The total utility supplied per unit population is exactly

\(\sum_q\lambda_q u(q)=\frac12\sum_{i=1}^{n}(2K+2d_i+a_i)=nK+S+A=H.\)

The specified benchmark

For each even \(N_k\), the multiset \(V_k\) contains \(N_k/2\) copies of each category value. Consequently, its \(N_k\)-th largest value is the second-largest category value. Let this positive integer be \(r\). Then

\(s(V_k,N_k)=r\)

for every \(k\), so the required limiting benchmark is exactly \(r\). It is computable by sorting the category values.

Thus the construction satisfies the promise concerning the feasible share and its specified limit.

3. Exact-value bundles encode partitions

Lemma. There exists an integral bundle \(b\) with \(u\cdot b=H\) if and only if the PARTITION instance is a yes-instance.

Proof. Write \(x_i^0,x_i^1\) for the multiplicities of the two categories in \(b\), and let

\(m=\sum_{i=1}^{n}(x_i^0+x_i^1)\)

be its number of goods. Every good has value at least \(K\). Since \(S+A<K\),

\(mK\le H=nK+S+A<(n+1)K,\)

which implies \(m\le n\).

Every good has value at most \(K+R\). If \(m\le n-1\), then

\(u\cdot b\le(n-1)(K+R)<nK\le H,\)

where the strict inequality follows from \(K>nR\). Therefore an exact-value bundle must have \(m=n\).

Subtracting \(nK\) from \(u\cdot b=H\) gives

\(\sum_{i=1}^{n}(x_i^0+x_i^1)d_i+\sum_{i=1}^{n}x_i^1a_i=S+A.\)

Set \(t=\sum_i x_i^1a_i\). Because there are exactly \(n\) goods and each \(a_i\le2A\),

\(0\le t\le2nA<L.\)

All \(d_i\) and \(S\) are divisible by \(L\). Reduction modulo \(L\) therefore gives \(t\equiv A\pmod L\). Both \(t\) and \(A\) lie between zero and \(L-1\), so \(t=A\).

After subtracting this equality and dividing by \(L\), we obtain

\(\sum_{i=1}^{n}(x_i^0+x_i^1)D^{i-1}=\sum_{i=1}^{n}D^{i-1}.\)

Each coefficient \(x_i^0+x_i^1\) lies between zero and \(n=D-1\). These are valid base-\(D\) digits, so uniqueness of positional representation implies

\(x_i^0+x_i^1=1\qquad\text{for every }i.\)

Hence \(I=\{i:x_i^1=1\}\) is a subset satisfying \(\sum_{i\in I}a_i=A\).

Conversely, given such a subset \(I\), choose \(q_i^1\) when \(i\in I\), and \(q_i^0\) otherwise. The resulting bundle has utility

\(nK+S+\sum_{i\in I}a_i=H.\)

This proves the lemma.

4. A partition yields an online policy for every order

Suppose \(I\) is a partition witness. Define two bundles:

  • \(b^+\) contains \(q_i^1\) for \(i\in I\) and \(q_i^0\) otherwise.
  • \(b^-\) contains the other category for each index.

Both bundles have utility \(H\), since both \(I\) and its complement sum to \(A\). Every category occurs exactly once across these two bundles.

Divide the population into two groups of mass \(1/2\), reserving \(b^+\) for the first group and \(b^-\) for the second. On arrival of a category-\(q\) good, assign it within its designated group to an agent who has not yet received category \(q\).

This is always possible. At finite scale, the group contains \(N_k/2\) agents and exactly \(N_k/2\) goods of that category will arrive. Before the last such good arrives, an eligible agent remains. Eligibility for category \(q\) is unaffected by assignments of other categories.

The same rule directly defines a limiting mass-transition policy: after category-\(q\) mass \(z\) has arrived, exactly mass \(z\) in its designated group has received that category, leaving mass \(1/2-z\) eligible. Each assignment uses a transition \(b\to b+e_q\).

Thus, against every arrival order, the final distribution places mass \(1/2\) on each reserved bundle. The policy guarantees utility \(H\), establishing

\(\alpha^\star\ge H/r,\)

where \(\alpha^\star\) denotes the requested supremum.

5. Resource bounds and the no-instance gap

For any terminal mass distribution \(\eta_b\) in the constructed instance,

\(\sum_b\eta_b=1,\qquad \sum_b\eta_b(u\cdot b)\le H.\)

The first identity expresses conservation of agent mass; the second follows from the available goods.

These statements also hold if terminal distributions are defined through scaling limits. There are exactly \(nN_k\) goods, so the fraction of agents holding more than \(M\) goods is at most \(n/(M+1)\). Thus agent mass cannot escape to unbounded bundle states. For every finite set of states, its limiting utility contribution is at most \(H\); taking increasing finite sets gives the stated utility inequality.

In particular, any guaranteed factor satisfies \(\alpha r\le H\), and therefore

\(\alpha^\star\le H/r.\)

Combined with the preceding construction, every yes-instance satisfies

\(\alpha^\star=H/r.\)

Now suppose the PARTITION instance is a no-instance. The lemma says that no integral bundle has utility exactly \(H\).

If a policy guaranteed any factor

\(\alpha>(H-1)/r,\)

then every positive-mass terminal state would have utility strictly greater than \(H-1\). Utilities are integers, so every such state would have utility at least \(H\). Since utility \(H\) is impossible, every such state would actually have utility at least \(H+1\). Consequently,

\(\sum_b\eta_b(u\cdot b)\ge(H+1)\sum_b\eta_b=H+1,\)

contradicting the resource bound.

Every no-instance therefore satisfies

\(\alpha^\star\le(H-1)/r<H/r.\)

This strict gap handles the possibility that the supremum is unattained.

6. Complexity conclusion

The polynomial-time construction establishes:

  • A yes-instance of PARTITION has \(\alpha^\star=H/r\).
  • A no-instance has \(\alpha^\star\le(H-1)/r\).

Therefore deciding whether \(\alpha^\star\ge H/r\), and hence computing \(\alpha^\star\) exactly, is \(\mathrm{NP}\text{-hard}\).

The proof uses the unrestricted supremum requested in the question; it imposes no additional cap \(\alpha\le1\). It establishes ordinary binary-encoding hardness, without claiming strong hardness or hardness for every possible fixed feasible share.
