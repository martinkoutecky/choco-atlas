The continuous mirror question, as graded

Given two agent types \(r\in\{L,S\}\) with masses \(\mu_r\), finite house types \(h\in H\) with per-capita supplies \(\rho_h\), weights \(w_r>0\), and utilities \(v_r(h)\), decide whether there exist \(x_{rh}\ge0\) and \(p_{rh}\ge0\) satisfying \(\sum_h x_{rh}=\mu_r\), \(\sum_r x_{rh}\le\rho_h\), and, whenever \(x_{rh}>0\) and \(x_{sg}>0\), \(\frac{v_r(h)+p_{rh}}{w_r}\ge\frac{v_r(g)+p_{sg}}{w_s}\); if so, output \(x\) and \(p\).

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: the list of the \(\tau\) types with positive mass, each mass a binary rational; \(\tau\) is the support size, not the number of possible types. Here the support is \(\{L,S\}\), so \(\tau=2\), with \(\mu_L,\mu_S>0\) and \(\mu_L+\mu_S=1\).
There are \(m=|H|\ge1\) house types with binary rational per-capita supplies \(\rho_h\ge0\), satisfying \(\sum_h\rho_h\ge1\). Each agent type has binary rational weight \(w_r>0\) and utilities \(v_r(h)\ge0\); utilities have no further normalization. Let \(L\) be the total input bit length.
An allocation uses real masses \(x_{rh}\ge0\), where \(\sum_hx_{rh}=\mu_r\) and \(\sum_rx_{rh}\le\rho_h\). Every individual receives one house; mass may be divided among house types and unused supply is permitted.
A subsidy \(p_{rh}\ge0\) is a real payment per individual receiving house type \(h\) in agent type \(r\), with no budget bound. The outcome is weighted envy-free if, for all \(r,s\in\{L,S\}\) and \(h,g\in H\) with \(x_{rh}>0\) and \(x_{sg}>0\), \(\frac{v_r(h)+p_{rh}}{w_r}\ge\frac{v_r(g)+p_{sg}}{w_s}\). These weak comparisons include individuals of the same type.
Is deciding whether such an allocation and subsidies exist solvable in time polynomial in \(m,\tau,L\), with a feasible \(x,p\) computable when they exist, or is the decision problem NP-hard?
For discrete agents of two types sharing weights and utilities within each type, existence of a weighted envy-freeable house allocation is decidable and an allocation computable in polynomial time ([Dai et al.](https://arxiv.org/html/2408.12523v1)); such allocations need not exist. No result settling the exact continuous problem above was located in the literature search.

Modeling choices made when packaging the task

  • Normalized total agent mass to one, making house supplies per capita, and required both supported agent types to have positive mass.
  • Carried over nonnegative utilities and positive weights; encoded utilities, weights, and supplies as binary rationals and imposed no additional utility normalization or ordering of weights.
  • Translated the discrete requirement that houses suffice for all agents into total per-capita supply at least one; allowed zero supplies and unused houses.
  • Interpreted each allocation entry as a mass of individuals each receiving one house, and each subsidy entry as a payment per individual in that allocation cell, with no subsidy budget.
  • Specified real nonnegative allocation and subsidy variables and weak envy comparisons, including comparisons within an agent type.

Result

The stated continuous problem is polynomial-time solvable, and feasible rational allocations and subsidies can be computed in polynomial time. More precisely, the algorithm below uses \(O(m^2)\) rational arithmetic operations, all on numbers of polynomial bit length.

The proof works directly with population masses. It gives the same tractability conclusion as the discrete two-type result of [Dai et al.](https://arxiv.org/html/2408.12523v1).

1. Eliminating the subsidy variables

Define the utility difference of each house type by
\[ d_h:=v_L(h)-v_S(h). \]
For an allocation \(x\), let \(H_r(x):=\{h:x_{rh}>0\}\). Both occupied supports are nonempty because \(\mu_L,\mu_S>0\).

Lemma 1. An allocation \(x\) admits nonnegative subsidies making it weighted envy-free if and only if
\[ \max_{g\in H_S(x)}\frac{d_g}{w_S} \;\le\; \min_{h\in H_L(x)}\frac{d_h}{w_L}. \]

Proof. Suppose suitable subsidies exist. The comparisons between individuals of the same type, in both directions, imply
\[ \frac{v_r(h)+p_{rh}}{w_r} = \frac{v_r(g)+p_{rg}}{w_r} \qquad(h,g\in H_r(x)). \]
Denote this common value by \(u_r\), and put \(t:=u_L-u_S\).

For an occupied house type \(g\in H_S(x)\), the comparison of a type-\(L\) individual with its type-\(S\) recipient gives
\[ u_L \ge \frac{v_L(g)+p_{Sg}}{w_S} = u_S+\frac{d_g}{w_S}. \]
Thus \(t\ge d_g/w_S\). Similarly, for \(h\in H_L(x)\),
\[ u_S \ge \frac{v_S(h)+p_{Lh}}{w_L} = u_L-\frac{d_h}{w_L}, \]
so \(t\le d_h/w_L\). These inequalities prove necessity.

Conversely, suppose a real number \(t\) satisfies
\[ \frac{d_g}{w_S}\le t\le\frac{d_h}{w_L} \qquad (g\in H_S(x),\ h\in H_L(x)). \]
Choose
\[ T:= \max\left\{ 0,\; \max_{h\in H}\frac{v_S(h)}{w_S},\; \max_{h\in H}\left(\frac{v_L(h)}{w_L}-t\right) \right\}, \]
and define, for every house type,
\[ p_{Sh}:=w_ST-v_S(h), \qquad p_{Lh}:=w_L(T+t)-v_L(h). \]
The definition of \(T\) makes all these subsidies nonnegative. Every type-\(S\) recipient has normalized subsidized utility \(T\), and every type-\(L\) recipient has normalized subsidized utility \(T+t\). Hence all same-type comparisons hold with equality.

For an occupied type-\(S\) house \(g\),
\[ \frac{v_L(g)+p_{Sg}}{w_S} = T+\frac{d_g}{w_S} \le T+t. \]
For an occupied type-\(L\) house \(h\),
\[ \frac{v_S(h)+p_{Lh}}{w_L} = T+t-\frac{d_h}{w_L} \le T. \]
Thus both directions of cross-type comparison hold. This proves sufficiency. \(\square\)

2. Allocation feasibility for a fixed threshold

For a real threshold \(t\), define the eligible house sets
\[ A(t):=\left\{h:\frac{d_h}{w_L}\ge t\right\}, \qquad B(t):=\left\{h:\frac{d_h}{w_S}\le t\right\}. \]
By Lemma 1, an allocation supported on \(A(t)\) for type \(L\) and on \(B(t)\) for type \(S\) admits suitable subsidies.

For any house set \(C\subseteq H\), write \(\rho(C):=\sum_{h\in C}\rho_h\).

Lemma 2. An allocation with these support restrictions exists if and only if
\[ \rho(A(t))\ge\mu_L,\qquad \rho(B(t))\ge\mu_S,\qquad \rho(A(t)\cup B(t))\ge1. \]

Proof. Necessity follows by summing the supply constraints over the house sets available to each type and to their union.

For sufficiency, abbreviate \(A:=A(t)\), \(B:=B(t)\), and partition the eligible houses into
\[ E_L:=A\setminus B,\qquad E_S:=B\setminus A,\qquad C:=A\cap B. \]
Put \(a:=\rho(E_L)\), \(b:=\rho(E_S)\), and \(c:=\rho(C)\). The assumed inequalities become
\[ a+c\ge\mu_L,\qquad b+c\ge\mu_S,\qquad a+b+c\ge1. \]

Allocate \(\min\{\mu_L,a\}\) mass of \(E_L\) to type \(L\), and \(\min\{\mu_S,b\}\) mass of \(E_S\) to type \(S\). Their remaining demands are
\[ \ell:=\max\{0,\mu_L-a\}, \qquad s:=\max\{0,\mu_S-b\}. \]
We claim that \(\ell+s\le c\).

If both residual demands are positive, then
\[ \ell+s=\mu_L+\mu_S-a-b=1-a-b\le c. \]
If only \(\ell\) is positive, the first assumed inequality gives \(\ell\le c\); if only \(s\) is positive, the second gives \(s\le c\). If both vanish, the claim follows from \(c\ge0\).

Consequently, allocate \(\ell\) mass of the common houses to type \(L\), then allocate \(s\) mass of their remaining supply to type \(S\).

Each allocation step is constructive: traverse the relevant house set and take the minimum of the remaining demand and the remaining supply at each house. Whenever the total available supply is at least the requested mass, this procedure fills the demand. Therefore both types receive their required masses, and every supply constraint holds. \(\square\)

3. Only finitely many thresholds need testing

Lemma 3. If a weighted envy-free outcome exists, one exists using a threshold from the list
\[ \mathcal T:=\left\{\frac{d_g}{w_S}:g\in H\right\}. \]

Proof. Take any feasible weighted envy-free outcome. By Lemma 1, its occupied supports satisfy
\[ \max_{g\in H_S(x)}\frac{d_g}{w_S} \le \min_{h\in H_L(x)}\frac{d_h}{w_L}. \]
Set
\[ t_*:=\max_{g\in H_S(x)}\frac{d_g}{w_S}. \]
The maximum is attained because \(H_S(x)\) is finite and nonempty, so \(t_*\in\mathcal T\). Every occupied type-\(S\) house belongs to \(B(t_*)\), and every occupied type-\(L\) house belongs to \(A(t_*)\). Thus the original allocation satisfies the support restrictions for this candidate. \(\square\)

This argument includes equality cases. No approximation or search over open intervals is needed.

4. Algorithm and correctness

The algorithm is as follows.

  • Compute \(d_h=v_L(h)-v_S(h)\) for every house type.
  • For each of the at most \(m\) candidates \(t=d_g/w_S\), form \(A(t)\) and \(B(t)\).
  • Test the three inequalities from Lemma 2.
  • If a candidate passes, construct \(x\) by the greedy procedure in Lemma 2, and construct \(p\) using the formula in Lemma 1. Return this outcome.
  • If every candidate fails, report that no feasible weighted envy-free outcome exists.

An accepted candidate yields a supply-feasible allocation by Lemma 2 and nonnegative envy-eliminating subsidies by Lemma 1. Conversely, if any feasible outcome exists, Lemma 3 provides a tested candidate whose support restrictions admit an allocation; that candidate passes Lemma 2. Therefore the algorithm is correct.

5. Bit complexity and possible nonexistence

Each candidate requires \(O(m)\) rational comparisons and additions. Across all candidates this gives \(O(m^2)\) rational arithmetic operations. Constructing the allocation and subsidies for an accepted candidate requires another \(O(m)\) operations.

All these operations can be performed exactly with polynomial bit complexity. Differences, quotients, and products of input rationals have polynomial bit length. A sum of supply rationals also has polynomial bit length: their denominator product has bit length at most the sum of their encoded denominator lengths. The greedy construction uses only minima and successive subtractions of such quantities. Finally, the subsidy formula uses maxima, multiplication, and subtraction. Hence the algorithm and its rational output have size polynomial in \(m,\tau,L\), with \(\tau=2\).

Existence is not automatic. For example, take a single house type with
\[ \rho_h=1,\qquad \mu_L=\mu_S=\frac12,\qquad w_L=2,\quad w_S=1,\qquad v_L(h)=1,\quad v_S(h)=0. \]
Both types must occupy that house type. Lemma 1 would require
\[ \frac{d_h}{w_S}=1 \le \frac{d_h}{w_L}=\frac12, \]
which is impossible. Thus the algorithm decides a nontrivial feasibility question.
