The continuous mirror question, as graded

Given finite districts \(D\), schools \(C\), demographic types \(R\), complete repeated student types \(\Theta\), rational masses \(\mu_\theta\), per-capita capacities \(Q_c\), school-level ceilings \(U_c^r\), and a fully specified mass-valued analogue of the paper's rationed and weakly acceptant admissions rules, decide whether every bulk-SPDA outcome satisfies \(\left|y_d^r/\kappa_d-y_{d'}^r/\kappa_{d'}\right|\leq\alpha\) for every \(r\) and \(d\neq d'\). Here \(x_{\theta,c}\geq0\) is assigned mass, \(\sum_c x_{\theta,c}=\mu_\theta\), \(y_c^r=\sum_{\theta:r(\theta)=r}x_{\theta,c}\), and \(\kappa_d=\sum_{\theta:h(\theta)=d}\mu_\theta\); equivalently, compute \(\underline p_d^r\) and \(\overline q_d^r\) by min/max flow over legitimate mass assignments and test \(\overline q_d^r/\kappa_d-\underline p_{d'}^r/\kappa_{d'}\leq\alpha\) for all \(r,d\neq d'\).

Packaged proof task (what the prover saw — nothing else)

Let \(D,C,R,\Theta\) be finite sets of districts, schools, demographic types, and complete student types. Each school \(c\) has district \(g(c)\); each type \(\theta\) has home district \(h(\theta)\), demographic type \(r(\theta)\), and rational mass \(\mu_\theta\). Capacities \(Q_c\), school-level ceilings \(U_c^r\), and \(\alpha\in[0,1]\) are rational; \(\kappa_d=\sum_{\theta:h(\theta)=d}\mu_\theta>0\).
A legitimate mass assignment has \(x_{\theta,c}\geq0\), \(\sum_c x_{\theta,c}=\mu_\theta\), \(\sum_\theta x_{\theta,c}\leq Q_c\), \(\sum_{\theta:r(\theta)=r}x_{\theta,c}\leq U_c^r\), and \(\sum_{c:g(c)=d,\theta}x_{\theta,c}=\kappa_d\). Write \(y_d^r=\sum_{c:g(c)=d,\theta:r(\theta)=r}x_{\theta,c}\). Assume legitimate assignments exist. Under the stipulated mass model, the bulk-SPDA outcomes relevant to this decision problem are exactly the legitimate assignments.

Is deciding whether every such outcome satisfies \(\left|y_d^r/\kappa_d-y_{d'}^r/\kappa_{d'}\right|\leq\alpha\) for all \(r\in R\) and distinct \(d,d'\in D\) in P or NP-hard?

Discrete: with rationed, weakly acceptant admissions, school-level type ceilings, and accommodation of unmatched students, the analogous diversity condition is characterized by implied floors and ceilings computable by minimum-cost flow in polynomial time. Continuum deferred acceptance has been studied for convergence from finite markets; that result does not address this district-diversity decision problem.

Prover output (gpt-6-astra / medium, Bolzano prover prompt)

The decision problem is in \(\mathrm{P}\). The stipulated equivalence between relevant bulk-SPDA outcomes and legitimate assignments makes this a universal question over a rational polytope; polynomially many linear programs settle it exactly.

Let \(P\) be the set of legitimate assignments, with one variable \(x_{\theta,c}\) for each \((\theta,c)\in\Theta\times C\), and with precisely the constraints in the question. By assumption, \(P\) is nonempty. Every feasible assignment satisfies \(0\leq x_{\theta,c}\leq\mu_\theta\), because its entries are nonnegative and \(\sum_{c\in C}x_{\theta,c}=\mu_\theta\). Thus \(P\) is bounded. It is also closed, since all its constraints are linear equalities or non-strict inequalities. Consequently, every linear objective attains its maximum on \(P\).

Fix a demographic type \(r\in R\) and an ordered pair of distinct districts \((d,d')\). Define the linear objective

\(L_{r,d,d'}(x)=\kappa_{d'}\sum_{c:g(c)=d}\sum_{\theta:r(\theta)=r}x_{\theta,c}-\kappa_d\sum_{c:g(c)=d'}\sum_{\theta:r(\theta)=r}x_{\theta,c}\),

and compute its maximum \(M_{r,d,d'}=\max_{x\in P}L_{r,d,d'}(x)\) by rational linear programming.

Because \(\kappa_d\) and \(\kappa_{d'}\) are strictly positive, every \(x\in P\) satisfies the equivalence

\(\displaystyle \frac{y_d^r}{\kappa_d}-\frac{y_{d'}^r}{\kappa_{d'}}\leq\alpha\quad\Longleftrightarrow\quad L_{r,d,d'}(x)\leq\alpha\kappa_d\kappa_{d'}.\)

It follows that this directed inequality holds for every legitimate assignment if and only if \(M_{r,d,d'}\leq\alpha\kappa_d\kappa_{d'}\). Indeed, the forward implication follows by taking the maximum. For the reverse implication, every feasible objective value is at most that maximum.

The algorithm therefore returns yes exactly when \(M_{r,d,d'}\leq\alpha\kappa_d\kappa_{d'}\) for every \(r\in R\) and every ordered pair of distinct districts. This is precisely the requested condition: checking both \((d,d')\) and \((d',d)\) checks both signs of the difference, which is equivalent to bounding its absolute value. If any comparison fails, an assignment attaining that maximum is a legitimate assignment violating the requested bound. Under the stipulated mass model, it is also a relevant outcome. If there are no such demographic types or district pairs, the condition holds vacuously.

To verify polynomial running time, use the usual explicit binary encoding of the finite sets, maps, and rational data. Each linear program has \(|\Theta||C|\) variables and at most \(|\Theta||C|+|\Theta|+|C|+|C||R|+|D|\) constraints, including nonnegativity. These quantities are polynomial in the input length. Each \(\kappa_d\) is a sum of input rationals, so its binary encoding length is polynomial in the input length. The objective coefficients and comparison threshold \(\alpha\kappa_d\kappa_{d'}\) likewise have polynomial encoding length.

The polynomial-time theorem for rational linear programming states that a rational linear program can be solved, including computation of its exact optimum when feasible and bounded, in time polynomial in its binary encoding length. Its hypotheses hold here: every program has rational data, is feasible by assumption, and is bounded as proved above. Hence the comparisons can be made exactly; equality with the threshold is accepted, and no numerical tolerance or strict-feasibility assumption is needed.

There are \(|R||D|(|D|-1)\) linear programs. Thus the entire algorithm runs in polynomial time. The discrete minimum-cost-flow characterization and continuum convergence results are unnecessary for this conclusion.
