Packaged proof task (what the prover saw — nothing else)

Given projects \(P\) with \(m=|P|\), positive integer costs \(c(q)\), a positive integer budget \(B\), and a target \(p\in P\) with \(c(p)\le B\), fix a strict total order for breaking ties. Costs and budget are encoded in binary.
A society is given by its support: the list of the \(\tau\) approval types \(A\subseteq P\) with positive mass, each mass \(\mu_A\) a binary rational, with \(\sum_A\mu_A=1\). Empty approval types are allowed. Here \(\tau\) is the support size, not the number of possible types; let \(L\) be the total input bit length.
Set \(s_\mu(q)=\sum_{A\ni q}\mu_A\). GreedyAV scans projects in nonincreasing order of \(s_\mu(q)\); GreedyCost scans in nonincreasing order of \(s_\mu(q)/c(q)\), resolving ties by the fixed order. Starting with remaining budget \(B\), each rule funds a scanned project exactly when its cost fits, subtracts that cost, and otherwise skips it and continues. Zero-score projects are also scanned.
For each rule \(R\), assume \(p\) is initially unfunded. A feasible deletion set is \(X\subseteq P\setminus\{p\}\) such that \(p\) is funded after deletion; approvals become \(A\setminus X\), with masses, costs, budget, and the restricted tie order unchanged. Minimize \(|X|\).

For each \(R\in\{\mathrm{GreedyAV},\mathrm{GreedyCost}\}\) and fixed \(0<\epsilon<1\), does this minimization problem admit a polynomial-time \(m^{1-\epsilon}\)-approximation, or is approximation within this factor NP-hard? State running times in \(m,\tau,L\), with dependence on \(\epsilon\) explicit.

With finitely many voters, both minimization problems are NP-hard to approximate within \(m^{1-\epsilon}\), even with three voters; they admit a polynomial-time \(m/a\)-approximation for every fixed positive integer \(a\). [Source](https://arxiv.org/pdf/2607.25723)
No result specifically treating the distribution-over-types formulation was identified in the literature search.

Result

For each \(R\in\{\mathrm{GreedyAV},\mathrm{GreedyCost}\}\) and every fixed \(0<\epsilon<1\), the distribution-over-types problem is NP-hard to approximate within \(m^{1-\epsilon}\). Consequently, such a polynomial-time approximation does not exist unless \(\mathrm{P}=\mathrm{NP}\).

The hardness already holds with \(\tau\le 3\). Both rules also admit the stated polynomial-time \(m/a\)-approximation for every fixed positive integer \(a\), with the usual convention that an approximation factor is at least \(1\).

1. Deletion preserves surviving scores

Fix a deletion set \(X\subseteq P\setminus\{p\}\). For every surviving project \(q\in P\setminus X\),

\(s_{\mu}^{X}(q)=\sum_A\mu_A\,\mathbf{1}[q\in A\setminus X]=\sum_A\mu_A\,\mathbf{1}[q\in A]=s_\mu(q).\)

The middle equality holds because \(q\notin X\). Thus deletion changes neither the score nor the score-to-cost ratio of a surviving project.

It follows that, for either rule, the scan order after deletion is exactly the restriction of its original scan order to \(P\setminus X\). The specified tie order is restricted in the same way. If distinct approval types become identical after deletion, merging their masses leaves these equalities unchanged.

Therefore, we can compute the scan order once and evaluate any proposed deletion set by scanning that order while omitting deleted projects.

2. An approximation-preserving transfer

Consider a finite-voter instance with \(n>0\) voters. For every distinct approval ballot \(A\), let \(n_A\) be its multiplicity. Construct a distributional instance by keeping the projects, costs, budget, target, and tie order, and assigning

\(\mu_A=n_A/n.\)

These masses are positive rationals summing to \(1\). Their numerators and denominators have \(O(\log n)\) bits.

For every deletion set \(X\subseteq P\setminus\{p\}\) and surviving project \(q\),

\(s_\mu^X(q)=\frac{1}{n}\left|\{v:q\in A(v)\setminus X\}\right|.\)

Hence the distributional scores are the finite-voter approval counts multiplied by the common positive factor \(1/n\). For GreedyCost, the score-to-cost ratios are multiplied by the same factor. Consequently, both strict comparisons and ties are preserved.

For completeness, identical scan orders imply identical funding outcomes: both executions begin with remaining budget \(B\); at each surviving project they have the same remaining budget and face the same cost, so they make the same funding decision and retain the same remaining budget. Induction over the scan order proves equality of the funded sets.

Thus, for either rule and every \(X\),

\(X\text{ is feasible in the finite-voter instance}\quad\Longleftrightarrow\quad X\text{ is feasible in the distributional instance}.\)

The transformation preserves every solution’s cardinality, the optimum, and \(m\). It is therefore approximation-preserving.

3. Hardness and hypothesis checks

We use the finite-voter hardness result supplied in the task: for each rule and every fixed \(0<\epsilon<1\), constructive project-deletion minimization is NP-hard to approximate within \(m^{1-\epsilon}\), even with three voters. This is [Theorem 5 of Schierreich and Sornat](https://arxiv.org/pdf/2607.25723).

Apply the transformation from Section 2 to those three-voter instances. Its hypotheses and required properties are as follows:

  • There are at most three distinct approval ballots, so \(\tau\le 3\).
  • Every mass is one of \(1/3\), \(2/3\), or \(1\), with constant encoding length.
  • Projects, positive integer costs, budget, target, and tie order are unchanged.
  • Every deletion set produces the same funding outcome; in particular, the target’s initial losing status and all feasible solutions are preserved.
  • Zero-score projects retain their positions and are scanned in both formulations.
  • The project count \(m\), and therefore the requested approximation factor, is unchanged.

The conversion takes polynomial time; with three voters, grouping the approval ballots takes \(O(m)\) operations on their incidence vectors, in addition to copying the input. Its running time and encoding overhead have no dependence on \(\epsilon\).

If a distributional algorithm ran in time polynomial in \(m,\tau,L\) and achieved factor \(m^{1-\epsilon}\), composing it with this conversion would give the forbidden finite-voter approximation. This proves the claimed hardness.

Here, rational encoding means that numerators and denominators are written in binary. Even if masses were restricted to dyadic rationals, hardness would still follow: assign each of the three voters mass \(1/4\) and add empty-ballot mass \(1/4\), merging duplicates. All scores then scale by \(1/4\), and \(\tau\le 4\).

4. Exact arithmetic and evaluation time

We give conservative bit-operation bounds using schoolbook integer arithmetic.

Write each input mass as \(\mu_A=u_A/v_A\), and define

\(D=\prod_A v_A,\qquad w_A=u_A(D/v_A),\qquad S(q)=\sum_{A\ni q}w_A.\)

Then \(s_\mu(q)=S(q)/D\). Because the denominator encodings have total length at most \(L\), the integer \(D\) has \(O(L)\) bits. Also,

\(\sum_Aw_A=D,\qquad 0\le S(q)\le D,\)

so all integer scores have \(O(L)\) bits.

GreedyAV compares \(S(q)\) directly. GreedyCost compares two projects \(q,r\) by comparing the integers

\(S(q)c(r)\quad\text{and}\quad S(r)c(q).\)

These products have \(O(L)\) bits. Thus no voter expansion or numerical approximation is needed.

For either rule, a common preprocessing bound is

\(T_{\mathrm{pre}}=O\!\left((m\tau+m\log m)L^2\right).\)

This includes constructing the integer weights, computing scores, and sorting with exact comparisons. Afterwards, testing a deletion set costs \(O(mL)\) bit operations: scan the precomputed order, compare costs with the remaining budget, and subtract funded costs.

5. Polynomial-time approximation for fixed \(a\)

Let \(\mathrm{OPT}\) denote the minimum feasible deletion cardinality. By the initial-losing promise and \(c(p)\le B\),

\(1\le\mathrm{OPT}\le m-1.\)

The upper bound follows by deleting every project except \(p\).

For a positive integer \(a\), use this algorithm:

  • Enumerate deletion sets in increasing cardinality, up to size \(\min\{a-1,m-1\}\).
  • Return the first feasible set.
  • If none is feasible, return \(P\setminus\{p\}\).

If \(\mathrm{OPT}<a\), the algorithm returns an optimum solution. Otherwise, its output has cardinality \(m-1\), giving

\(\frac{|X|}{\mathrm{OPT}}\le\frac{m-1}{a}<\frac{m}{a}.\)

Thus the approximation factor is at most \(\max\{1,m/a\}\). For \(m\ge a\), this is the requested \(m/a\) guarantee. For \(m<a\), enumeration is exhaustive and the algorithm is exact; a literal factor below \(1\) would be impossible because \(\mathrm{OPT}>0\).

Set

\(N_a=\sum_{j=0}^{\min\{a-1,m-1\}}\binom{m-1}{j}.\)

The running time is

\(O\!\left((m\tau+m\log m)L^2+N_a\,mL\right).\)

Since \(N_a\le a\,m^{a-1}\), a simpler bound is

\(O\!\left((m\tau+m\log m)L^2+a\,m^aL\right).\)

This is polynomial for every fixed \(a\).

6. Explicit dependence on \(\epsilon\)

The hardness applies separately to every fixed \(0<\epsilon<1\); the transfer introduces no additional dependence on \(\epsilon\).

For comparison, choosing the enumeration threshold

\(a=\lceil m^\epsilon\rceil\)

does achieve the requested factor: either the solution is optimal, or

\(\frac{|X|}{\mathrm{OPT}}\le\frac{m-1}{\lceil m^\epsilon\rceil}\le m^{1-\epsilon}.\)

Its running time is bounded by

\(O\!\left((m\tau+m\log m)L^2+\lceil m^\epsilon\rceil\,m^{\lceil m^\epsilon\rceil}L\right).\)

For fixed positive \(\epsilon\), this bound is not polynomial in \(m\). It therefore does not contradict the hardness result.
