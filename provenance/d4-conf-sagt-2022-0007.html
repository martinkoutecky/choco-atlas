Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Result. The continuous men-side coalitional manipulation problem is in \(\mathrm{P}\). An exact algorithm uses at most \(m\) Gale–Shapley runs and one rational linear program with \(m^2+1\) variables. The proof covers arbitrary real report masses and the specified lexicographic tie-breaking.

1. Reducing matching success to score comparisons.

Fix all preferences except those of \(\hat m\). For each strict complete ranking \(R\) of \(W\), let \(f(R)\) be the woman matched to \(\hat m\) by men-proposing Gale–Shapley. Define the set of attainable partners
\[ \]
\(A=\{f(R):R\in\mathcal R(W)\}.\)

We use the standard proposer-strategyproofness theorem: for any strict complete rankings \(R,T\), with all other preferences fixed, \(f(R)\) is weakly preferred to \(f(T)\) according to \(R\). This is the dominant-strategy property of the men-optimal matching procedure. Its hypotheses hold here: matching is one-to-one, preferences are strict and complete, and the designated agent belongs to the proposing side. See [Roth, Theorem 5](https://kylewoodward.com/blog-data/pdfs/references/roth-mathematics-of-operations-research-1982A.pdf).

Lemma 1. For every ranking \(R\), \(f(R)\) is the highest-ranked member of \(A\) according to \(R\).

*Proof.* Let \(a\) be the highest-ranked member of \(A\) according to \(R\). By the definition of \(A\), some ranking \(T\) satisfies \(f(T)=a\). Strategyproofness, treating \(R\) as \(\hat m\)'s true preference, implies that \(f(R)\) is weakly preferred to \(a\) according to \(R\). But \(f(R)\in A\), and \(a\) is the unique highest-ranked member of \(A\). Therefore \(f(R)=a\). \(\square\)

Consequently,
\[ \]
\(f(R)=w^\star\quad\Longleftrightarrow\quad w^\star\in A\ \text{and}\ w^\star\text{ precedes every member of }A\setminus\{w^\star\}\text{ in }R.\)

The set \(A\) can be computed without enumerating rankings. For each \(c\in W\), choose a ranking \(R_c\) placing \(c\) first, with the remaining women in any fixed order. Lemma 1 gives
\[ \]
\(c\in A\quad\Longleftrightarrow\quad f(R_c)=c.\)

Thus \(m\) Gale–Shapley runs compute \(A\). Each run takes \(O(m^2)\) operations using precomputed preference positions, so this stage takes \(O(m^3)\) operations.

If \(w^\star\notin A\), the answer is immediately no.

2. An exact polynomial-size description of continuous reports.

Define the honest scores
\[ \]
\(h_c=\sum_{\pi\text{ in the honest support}}\mu_\pi\bigl(m-\operatorname{pos}_\pi(c)\bigr).\)

These require \(O(\tau m)\) rational arithmetic operations.

For a report distribution, define its position masses by
\[ \]
\(y_{cj}=\sum_{\pi:\operatorname{pos}_\pi(c)=j}x_\pi,\qquad c\in W,\quad 1\leq j\leq m.\)

They satisfy
\[ \]
\(y_{cj}\geq0,\qquad \sum_{j=1}^m y_{cj}=\rho\quad(c\in W),\qquad \sum_{c\in W}y_{cj}=\rho\quad(1\leq j\leq m).\)

Its total score for \(c\) is
\[ \]
\(S_c(y)=h_c+\sum_{j=1}^m(m-j)y_{cj}.\)

Lemma 2. Every nonnegative matrix satisfying these row and column sums comes from a report distribution of total mass \(\rho\). Such a distribution can use at most \(m^2\) rankings.

*Proof.* We give the decomposition argument explicitly. Start with the residual matrix \(Z=y\), whose row and column sums all equal \(r=\rho>0\). Construct a bipartite graph between women and positions, joining \(c\) to \(j\) exactly when \(Z_{cj}>0\).

For any set \(U\) of women, let \(N(U)\) be its neighboring positions. All mass in rows \(U\) lies in columns \(N(U)\), so
\[ \]
\(|U|r=\sum_{c\in U}\sum_{j\in N(U)}Z_{cj}\leq\sum_{j\in N(U)}\sum_{c\in W}Z_{cj}=|N(U)|r.\)

Since \(r>0\), Hall’s condition holds. Therefore there is a perfect matching, represented by a permutation matrix \(P\), all of whose selected entries are positive. Set
\[ \]
\(\alpha=\min\{Z_{cj}:P_{cj}=1\}>0.\)

Subtract \(\alpha P\). The residual remains nonnegative, all row and column sums become \(r-\alpha\), and at least one positive entry becomes zero. No zero entry becomes positive.

Repeat whenever the common residual sum is positive. There are at most \(m^2\) positive entries initially, so the procedure terminates within \(m^2\) steps. A nonnegative residual with zero row sums is the zero matrix. Hence
\[ \]
\(y=\sum_{\ell=1}^{t}\alpha_\ell P^\ell,\qquad t\leq m^2,\qquad \sum_{\ell=1}^{t}\alpha_\ell=\rho.\)

Each \(P^\ell\) specifies one strict complete ranking. Assign that ranking mass \(\alpha_\ell\), combining masses if necessary. This gives exactly the required position masses and total report mass. \(\square\)

Thus the matrix formulation describes attainable scores exactly; it is not merely a relaxation.

3. Handling tie-breaking by one linear program.

Assume \(w^\star\in A\). Partition its attainable competitors into
\[ \]
\(B_{\mathrm{weak}}=\{b\in A\setminus\{w^\star\}:w^\star\text{ has priority over }b\},\)
\[ \]
\(B_{\mathrm{strict}}=\{b\in A\setminus\{w^\star\}:b\text{ has priority over }w^\star\}.\)

The score-induced ranking places \(w^\star\) above all these competitors exactly when
\[ \]
\(S_{w^\star}(y)-S_b(y)\geq0\quad(b\in B_{\mathrm{weak}}),\)
\[ \]
\(S_{w^\star}(y)-S_b(y)>0\quad(b\in B_{\mathrm{strict}}).\)

Introduce one variable \(\varepsilon\). Solve the rational linear program that maximizes \(\varepsilon\), subject to
\[ \]
\(y_{cj}\geq0,\qquad \sum_j y_{cj}=\rho,\qquad \sum_c y_{cj}=\rho,\)
\[ \]
\(0\leq\varepsilon\leq1,\)
\[ \]
\(S_{w^\star}(y)-S_b(y)\geq0\quad(b\in B_{\mathrm{weak}}),\)
\[ \]
\(S_{w^\star}(y)-S_b(y)\geq\varepsilon\quad(b\in B_{\mathrm{strict}}).\)

Reject if this program is infeasible. Otherwise, accept exactly when its optimum is strictly positive, using exact rational comparison.

Lemma 3. This acceptance rule is equivalent to the existence of a successful report distribution.

*Proof.* Suppose a successful distribution exists, and form its matrix \(y\). Lemma 1 implies that its induced ranking places \(w^\star\) above every other member of \(A\). Hence all the required weak and strict score inequalities hold.

If \(B_{\mathrm{strict}}\) is nonempty, choose
\[ \]
\(\varepsilon=\min\bigl(\{1\}\cup\{S_{w^\star}(y)-S_b(y):b\in B_{\mathrm{strict}}\}\bigr)>0.\)

If \(B_{\mathrm{strict}}\) is empty, choose \(\varepsilon=1\). Either choice gives a feasible solution with positive objective.

Conversely, suppose the program has a feasible solution with \(\varepsilon>0\). Its inequalities and the priority rule place \(w^\star\) above every other member of \(A\). Lemma 2 supplies a report distribution realizing \(y\). Lemma 1 then implies that Gale–Shapley matches \(\hat m\) to \(w^\star\).

Finally, every feasible entry satisfies \(0\leq y_{cj}\leq\rho\), and \(0\leq\varepsilon\leq1\). The feasible set is closed and bounded, so a feasible program attains its optimum. Therefore checking whether that optimum is positive is exact. \(\square\)

4. Running time and witness size.

The algorithm consists of:

  • Computing honest scores in \(O(\tau m)\) rational arithmetic operations.
  • Computing \(A\) in \(O(m^3)\) matching operations.
  • Solving one rational linear program with \(m^2+1\) variables, \(2m\) row and column equalities, and \(O(m^2)\) inequalities.

The honest scores have binary encoding length \(O(L+\log m)\): a common denominator can be chosen as the product of the input mass denominators, whose total bit length is bounded by the input length, and each score lies between zero and \(m-1\). The linear program’s coefficients therefore have bit length \(O(L+\log m)\). Its sparse encoding has total length
\[ \]
\(B=O\bigl(m^2(L+\log m)\bigr).\)

Let \(T_{\mathrm{LP}}(n,q,B)\) denote the bit running time of a polynomial-time exact rational linear-programming algorithm, with \(n\) variables, \(q\) constraints, and encoding length \(B\). A conservative total bound is
\[ \]
\(O\bigl((\tau m+m^3)(L+\log m)^2\bigr)+T_{\mathrm{LP}}\bigl(m^2+1,O(m^2),O(m^2(L+\log m))\bigr).\)

This is polynomial in \(m,\tau,L\). In particular, no enumeration of the \(m!\) rankings occurs.

On a yes instance, a rational optimal solution of polynomial encoding length exists by the standard rational-polytope vertex bounds. The decomposition in Lemma 2 then produces a successful rational report distribution supported on at most \(m^2\) rankings. Thus arbitrary real masses do not require irrational witnesses.

For \(m=1\), the answer is always yes. For \(\rho=1\), the honest scores vanish and the same algorithm applies with empty honest support.

The exact continuous problem is therefore polynomial-time solvable.
