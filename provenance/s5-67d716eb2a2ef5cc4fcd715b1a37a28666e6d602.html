The continuous mirror question, as graded

Given a candidate set \(C\) and a finite-support distribution \(\mu\) over complete rankings, with positive support \(S=\{t:\mu_t>0\}\), decide whether there is a finite set of rankings \(U\supseteq S\) and a tree on \(U\) such that the profile containing one copy of each ranking in \(U\) is single-crossing on that tree. If so, return \(U\) and a tree witness.

Packaged proof task (what the prover saw — nothing else)

Let \(C\) be a candidate set with \(m\geq 1\); types are strict complete rankings of \(C\), whose set is \(\mathcal L(C)\).
A society is given by its support: a list \(S\) of \(\tau\) distinct types with positive binary rational masses \(\mu_t\), with \(\sum_{t\in S}\mu_t=1\). Here \(\tau=|S|\) is the support size, not the number of possible rankings; \(L\) is the total input bit length. State running times in \(m,\tau,L\).
For a finite set \(U\subseteq\mathcal L(C)\), a tree \(T\) with vertex set \(U\) is single-crossing if, for every distinct \(x,y\in C\), at most one edge has endpoints ranking \(x,y\) oppositely.
Decide whether there exist \(U\supseteq S\) and such a tree \(T\); on a yes-instance return both. Added rankings need no assigned masses, and no bound or minimality requirement is imposed on \(U\).

Is this recognition problem in \(\mathsf P\), with witnesses computable in polynomial time in \(m,\tau,L\), or is its decision version \(\mathsf{NP}\)-hard?

For finite profiles, recognition of containment in a single-crossing tree profile is polynomial-time, with an extension and tree computable in polynomial time; deleting duplicate rankings preserves recognition. [Verified source](https://arxiv.org/html/1611.04175v4)
The stated distribution problem imposes exactly this containment condition on its explicitly listed support; consequently its complexity is already covered by that result.

Conclusion

The problem is in \(\mathsf P\), and both an extension \(U\) and a single-crossing tree \(T\) can be computed in polynomial time in \(m,\tau,L\). The rational masses do not affect recognition.

Below is a constructive reduction with an explicit, conservative running-time bound.

1. The finite-profile result and its applicability

For a finite profile \(P\) of strict complete rankings, let \(M(P)\) consist of the pairwise majority relations of all triples of rankings from \(P\), allowing repetition.

We use the following constructive consequence of Theorem 1 and its proof in [Dey, *Recognizing and Eliciting Weakly Single Crossing Profiles on Trees*](https://arxiv.org/html/1611.04175v4#S4):

If \(P\) is contained in a single-crossing tree profile, every such triple majority relation is a strict complete ranking, and \(M(P)\) itself is single-crossing on a tree.

This result applies with one voter for each listed support type, so the finite profile has exactly \(\tau\) voters and \(m\) candidates. The source’s single-crossing condition is the same condition used here: each candidate pair changes orientation across at most one tree edge.

Moreover, \(S\subseteq M(S)\), since the majority of the triple \((t,t,t)\) is \(t\). Thus this theorem produces an extension of the actual support without expanding the rational masses into voter multiplicities.

2. A polynomial bound on every witness

Put \(B=\binom m2+1\). Any witness with distinct rankings satisfies \(|U|\leq B\).

Indeed, for each tree edge \(e=\{u,v\}\), define \(D_e\) to be the set of unordered candidate pairs ranked differently by \(u\) and \(v\). Since the rankings are distinct, \(D_e\neq\varnothing\). Single-crossing implies that the sets \(D_e\) are pairwise disjoint. Consequently,

\(\displaystyle |U|-1=|E(T)|\leq\sum_{e\in E(T)}|D_e|\leq\binom m2.\)

In particular, \(\tau>B\) is an immediate no-instance. Although the problem imposes no extension-size bound, its definition guarantees a polynomial bound.

3. Testing a fixed set of rankings by a minimum spanning tree

Let \(V\) be a nonempty finite set of distinct rankings. Form the complete graph on \(V\), with edge weight

\(\displaystyle d(u,v)=\bigl|\{\{x,y\}\subseteq C:u,v\text{ rank }x,y\text{ oppositely}\}\bigr|.\)

Let \(q(V)\) be the number of unordered candidate pairs whose orientation varies across \(V\).

Claim. The set \(V\) is single-crossing on some tree if and only if a minimum spanning tree has total weight \(q(V)\).

Proof. For any spanning tree \(H\), let \(c_H(x,y)\) count its edges whose endpoints rank \(x,y\) oppositely. Counting the contributions to edge weights gives

\(\displaystyle \sum_{e\in E(H)}d(e)=\sum_{\{x,y\}\subseteq C}c_H(x,y).\)

If the orientation of \(x,y\) varies across \(V\), choose vertices with opposite orientations. Their connecting path contains an orientation-changing edge, so \(c_H(x,y)\geq1\). If the orientation is constant, then \(c_H(x,y)=0\).

Therefore every spanning tree has weight at least \(q(V)\). Equality holds precisely when every varying pair changes across exactly one edge, which is precisely the required single-crossing condition. A single-crossing tree attains that lower bound, and any minimum spanning tree attaining it is a valid witness. This proves the claim.

4. Recognition and witness construction

Use the following algorithm.

  • If \(\tau>B\), return no.
  • Enumerate all \(\tau^3\) ordered triples from \(S\), allowing repetition. Compute each triple’s pairwise majority relation.
  • If any such relation is not transitive, return no. Otherwise convert it into its strict complete ranking and insert that ranking into a set \(V\).
  • If \(|V|>B\), return no.
  • Compute the weighted complete graph on \(V\), its minimum spanning tree \(T\), and \(q(V)\).
  • Return no if the tree’s weight differs from \(q(V)\). Otherwise return \(U=V\) and \(T\).

For three strict rankings, each candidate pair has a unique majority orientation. Hence the majority relation is a tournament; explicitly checking transitivity suffices to decide whether it is a strict complete ranking.

Soundness. Every original type belongs to \(V\), because triples with three identical entries are enumerated. If the algorithm returns yes, the minimum spanning tree criterion proves that \(T\) is single-crossing on \(U=V\). Thus the returned objects satisfy the task.

Completeness. Suppose a requested witness exists. Then the finite profile consisting of \(S\) is contained in a single-crossing tree profile. The cited theorem therefore guarantees that every enumerated majority relation is a ranking and that \(M(S)\) is single-crossing on a tree. Every partially constructed \(V\) is a subset of \(M(S)\), whose size is at most \(B\) by Section 2. Thus neither early rejection occurs. Finally, \(V=M(S)\), so the minimum spanning tree criterion accepts.

Both directions are proved.

5. Running time and output size

First store each ranking’s inverse position array. Each triple’s majority relation and transitivity test take \(O(m^3)\) elementary operations. A simple implementation removes duplicates by comparing each resulting ranking against all currently stored rankings. Since at most \(B\) rankings are stored before rejection, this also costs \(O(m^3)\) per triple.

Writing \(N=|V|\leq B\), constructing all graph weights takes \(O(N^2m^2)\) operations, and a dense minimum spanning tree algorithm takes \(O(N^2)\). Thus, with indexed candidates, the combinatorial work is

\(\displaystyle O(\tau^3m^3+N^2m^2)=O(\tau^3m^3+m^6).\)

Including input parsing, candidate relabeling, and bit costs, a conservative bound is

\(\displaystyle O\!\left(L^2+(\tau^3m^3+m^6)\log(L+m+\tau+2)\right).\)

The masses need only be read as part of the promised valid input; no arithmetic involving them is required. The witness contains at most \(\binom m2+1\) rankings and one fewer tree edges, so its encoding size is polynomial as well.

For \(m=1\), the valid support consists of the unique ranking, and the one-vertex tree supplies the witness. The construction also handles this case.
