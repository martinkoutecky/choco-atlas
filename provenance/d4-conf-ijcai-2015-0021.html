The continuous mirror question, as graded

Given candidates \(A\), an integer \(k\), distinct ranking types \(T\) with positive binary-rational masses \(\mu_t\) summing to \(1\), a tree \(H\) on \(T\) such that for every candidate pair each preference side is connected in \(H\), and a common polynomial-time-computable rational positional dissatisfaction function \(\rho\), find a committee \(S\subseteq A\) with \(|S|\le k\) and allocations \(x_{t,c}\ge 0\), zero for \(c\notin S\), with \(\sum_{c\in S}x_{t,c}=\mu_t\), minimizing \(\sum_{t\in T}\sum_{c\in S}x_{t,c}\rho(\operatorname{pos}_t(c))\).

Packaged proof task (what the prover saw — nothing else)

Let \(A\) contain \(m\ge1\) candidates and let \(1\le k\le m\) be an input integer. A society is given by its support: a list \(T\) of \(\tau\ge1\) distinct strict rankings, each with positive binary-rational mass \(\mu_t\), with \(\sum_{t\in T}\mu_t=1\). Here \(\tau\) is the support size, not the number of possible rankings.
A tree \(H\) on \(T\) is supplied. For every distinct \(a,b\in A\), both \(\{t:a\succ_t b\}\) and \(\{t:b\succ_t a\}\) induce connected subtrees when nonempty.
The common positional dissatisfaction function is polynomial-time computable and rational-valued, with \(0=\rho(1)\le\rho(2)\le\cdots\le\rho(m)\); \(\operatorname{pos}_t(c)\) counts positions from the top, starting at \(1\). Its values may be supplied as a binary-rational table.
Find \(S\subseteq A\), \(1\le|S|\le k\), and divisible allocations \(x_{t,c}\in\mathbb R_{\ge0}\), with \(x_{t,c}=0\) for \(c\notin S\) and \(\sum_{c\in S}x_{t,c}=\mu_t\), minimizing \(\sum_{t\in T}\sum_{c\in S}x_{t,c}\rho(\operatorname{pos}_t(c))\). There are no representative capacities; any optimum is acceptable when costs tie.
Let \(L\) be the total binary input length, including dissatisfaction values. State running times in \(m,\tau,k,L\).

Is this continuous utilitarian Chamberlin–Courant optimization problem solvable in time polynomial in \(m,\tau,k,L\), or is it NP-hard?

For discrete voters single-crossing on a tree, polynomial-time winner determination was asserted for both utilitarian and egalitarian dissatisfaction by [Clearwater, Puppe and Slinko (2015)](https://www.ijcai.org/Proceedings/15/Papers/012.pdf).
[Constantinescu and Elkind (2021)](https://cdn.aaai.org/ojs/16667/16667-13-20161-1-2-20210518.pdf) identify an error in that running-time argument and establish an \(O(nmk)\) algorithm for the discrete utilitarian problem with preference-consistent rational costs, counting arithmetic operations at unit cost. Neither cited result explicitly formulates the divisible-mass problem above.

Result

The problem is polynomial-time solvable. With dissatisfaction values supplied as a binary-rational table, a valid bound is \(O(\tau m k L^2)\) bit operations. The underlying winner-determination algorithm uses \(O(\tau m k)\) arithmetic operations.

1. Divisibility does not improve the optimum

Write \(d_t(c)=\rho(\operatorname{pos}_t(c))\). Fix any nonempty committee \(S\subseteq A\), and let \(b_S(t)\) be the most preferred member of \(S\) in ranking \(t\). Monotonicity of \(\rho\) implies \(d_t(b_S(t))\le d_t(c)\) for every \(c\in S\).

Consequently, every feasible allocation to \(S\) satisfies

\[ \sum_{c\in S}x_{t,c}d_t(c) \ge d_t(b_S(t))\sum_{c\in S}x_{t,c} =\mu_t d_t(b_S(t)). \]

Equality is attained by assigning all mass \(\mu_t\) to \(b_S(t)\). Thus the optimum for committee \(S\) is exactly

\[ F(S)=\sum_{t\in T}\mu_t\rho(\operatorname{pos}_t(b_S(t))). \]

In particular, an optimum exists: there are finitely many eligible committees, and each committee admits the allocation just described. Cost ties cause no difficulty because choosing the most preferred representative always attains minimum cost.

2. Exact reduction to the corrected discrete algorithm

We use the following established result.

Constantinescu–Elkind theorem. Given \(n\) voters, \(m\) candidates, a supplied tree on which their strict preferences are single-crossing, and rational costs \(q(v,c)\) satisfying \(a\succ_v b\Rightarrow q(v,a)\le q(v,b)\), one can find an assignment \(w\) minimizing \(\sum_v q(v,w(v))\), subject to \(|w(V)|\le k\), in \(O(nmk)\) arithmetic operations. This is Theorem 6, with the cost and assignment definitions from Section 2, of [Constantinescu and Elkind (2021)](https://cdn.aaai.org/ojs/16667/16667-13-20161-1-2-20210518.pdf).

Construct an instance with one voter for each support ranking, and set

\[ q(t,c)=\mu_t\rho(\operatorname{pos}_t(c)). \]

All hypotheses hold:

  • There are \(n=\tau\) voters with the given strict rankings.
  • The supplied tree \(H\) satisfies the theorem’s single-crossing condition. Indeed, a connected vertex set in a tree contains the unique path between any two of its vertices. Hence two vertices preferring \(a\) to \(b\) cannot have a vertex preferring \(b\) to \(a\) between them.
  • Costs are rational and nonnegative.
  • If \(a\succ_t b\), then monotonicity of \(\rho\), followed by multiplication by \(\mu_t>0\), gives \(q(t,a)\le q(t,b)\).
  • The theorem bounds the number of distinct representatives and imposes no representative capacities.

To verify exact equivalence, let \(U\) be the continuous optimum and \(D_{\mathrm{opt}}\) the discrete optimum.

For any eligible committee \(S\), the assignment \(w(t)=b_S(t)\) uses at most \(k\) candidates and has discrete cost \(F(S)\). Therefore \(D_{\mathrm{opt}}\le U\).

Conversely, any eligible discrete assignment \(w\) gives a feasible continuous solution by taking \(S=w(T)\), assigning \(x_{t,w(t)}=\mu_t\), and setting all other allocations to zero. Its continuous cost equals \(\sum_t q(t,w(t))\). Therefore \(U\le D_{\mathrm{opt}}\).

Thus \(U=D_{\mathrm{opt}}\). The theorem computes the required solution using \(O(\tau m k)\) arithmetic operations, without expanding rational masses into repeated voters.

3. Polynomial bit complexity

We now justify that these arithmetic operations have polynomial bit cost.

Write the input rationals as \(\mu_t=p_t/u_t\) and \(\rho(j)=r_j/v_j\), with positive integer denominators. Define

\[ B=\left(\prod_{t\in T}u_t\right)\left(\prod_{j=1}^{m}v_j\right). \]

The binary length of \(B\) is \(O(L)\), since the sum of the binary lengths of its factors is at most \(L\). For every \(t,c\), the scaled cost

\[ Q(t,c)=Bq(t,c) =p_t r_{\operatorname{pos}_t(c)} \frac{B}{u_t v_{\operatorname{pos}_t(c)}} \]

is a nonnegative integer. Multiplication by the common positive factor \(B\) preserves every comparison of objective values and preserves preference consistency.

Using schoolbook integer arithmetic, constructing \(B\) and all scaled costs takes \(O(\tau m L^2)\) bit operations. Inverse ranking tables supply all positions in \(O(\tau m)\) elementary operations.

The cited dynamic program initializes entries with individual costs and computes further entries by additions and minima, merging disjoint vertex sets. Consequently, every finite entry is the cost of assigning one representative to each vertex of some subset \(U\subseteq T\). This follows inductively from its initialization and merging recurrences in [Section 4.1](https://cdn.aaai.org/ojs/16667/16667-13-20161-1-2-20210518.pdf).

Such an entry satisfies

\[ 0\le \sum_{t\in U}Q(t,w(t)) =B\sum_{t\in U}\mu_t\rho(\operatorname{pos}_t(w(t))) \le B\rho(m), \]

because all costs are nonnegative, \(\rho(\operatorname{pos}_t(w(t)))\le\rho(m)\), and \(\sum_{t\in U}\mu_t\le1\).

The integer bound \(B\rho(m)\) has \(O(L)\) bits. Therefore every finite table value has \(O(L)\) bits; infeasibility can be represented by a separate infinity flag. Additions and comparisons each take \(O(L)\) bit operations.

Including preprocessing and assignment reconstruction, the resulting bound is

\[ O(\tau m L^2+\tau m k L) \subseteq O(\tau m k L^2). \]

Recording a minimizing transition at each table entry permits reconstruction of an optimal assignment. Set \(S=w(T)\) and \(x_{t,w(t)}=\mu_t\); this explicitly returns an optimal committee and allocation.

If dissatisfaction values are evaluated by an algorithm instead of supplied as a table, add the time needed to evaluate \(\rho(1),\ldots,\rho(m)\). Under the stated polynomial-time computability assumption, this remains polynomial.
