The continuous mirror question, as graded

Let \(S_\mu(x,y)\) be the maximum minimum edge margin over directed paths from \(x\) to \(y\), with value \(0\) if no path exists. Prover output (gpt-6-astra / medium, Bolzano prover prompt)

The decision problem is polynomial-time solvable, including the bit complexity of the rational masses. The following proof works directly with the stated input formulation.

Write \(n=|C|\), \(m=|T|\), and let \(L\) be the total binary input length. Let \(a\) be the designated candidate.

Exact integer representation. Write each input mass as \(\mu_t=p_t/q_t\), where \(p_t\geq 0\) and \(q_t\geq 1\) are integers. Define

\(D=\prod_{t\in T}q_t,\qquad r_t=p_t(D/q_t).\)

These are integers, and the normalization assumption gives \(\sum_{t\in T}r_t=D\). For distinct candidates \(x,y\), compute

\(W(x,y)=\sum_{t\in T}r_t\bigl(\mathbf{1}[x\succ_t y]-\mathbf{1}[y\succ_t x]\bigr).\)

Consequently, \(W(x,y)=D\Delta_\mu(x,y)\) and \(|W(x,y)|\leq D\). Thus the positive-margin graph has exactly the edges with \(W(x,y)>0\), and scaling all edge weights by \(D\) preserves every comparison relevant to the definition.

Although the numerical value of \(D\) may be large, its binary length is polynomially bounded: \(\log_2 D=\sum_{t\in T}\log_2 q_t\leq L\). Each \(r_t\), each \(W(x,y)\), and every partial sum used to compute a margin therefore has \(O(L)\) bits. All these integers can be computed in polynomial time without expanding the masses into individual voters.

Threshold characterization. For any positive integer \(h\), define a directed graph \(G_h\) on \(C\) by including \(x\to y\) exactly when \(W(x,y)\geq h\). For distinct \(u,v\),

\(v\text{ is reachable from }u\text{ in }G_h \quad\Longleftrightarrow\quad S_\mu(u,v)\geq h/D.\)

To prove the forward implication, a path in \(G_h\) has every margin at least \(h/D\), so its minimum edge weight is at least \(h/D\).

Conversely, the maximum defining \(S_\mu(u,v)\), when a path exists, is attained. Indeed, any repeated-vertex walk can have its cycles deleted without decreasing its minimum edge weight, and there are only finitely many simple paths. Therefore, if \(S_\mu(u,v)\geq h/D\), an attaining path has every integer edge weight at least \(h\), so it is a path in \(G_h\). When no path exists, \(S_\mu(u,v)=0<h/D\), as required.

Decision algorithm and correctness. For every \(b\neq a\) with \(W(b,a)>0\), set \(h=W(b,a)\) and test whether \(b\) is reachable from \(a\) in \(G_h\).

  • If any such test fails, return that \(a\notin SC_\infty(\mu)\).
  • If every such test succeeds, return that \(a\in SC_\infty(\mu)\).

For a tested candidate \(b\), the threshold characterization gives

\(b\text{ is not reachable from }a\text{ in }G_{W(b,a)} \quad\Longleftrightarrow\quad S_\mu(a,b)<W(b,a)/D=\Delta_\mu(b,a).\)

Because the test is performed exactly when \(\Delta_\mu(b,a)>0\), a failed test is precisely a witness excluding \(a\) under the given definition. Candidates with nonpositive incoming margin cannot be witnesses. The algorithm is therefore correct. In particular, equality of the strongest-path strength and incoming margin correctly prevents exclusion.

Running time. Precompute each candidate’s position in each ranking. Computing all integer margins then requires \(O(mn^2)\) arithmetic operations. There are at most \(n-1\) reachability tests; constructing each threshold graph and searching it takes \(O(n^2)\) comparisons and graph operations. Thus the total is \(O(mn^2+n^3)\) such operations, plus polynomial-time denominator preprocessing.

Every integer operand has \(O(L)\) bits, and \(n,m\) are bounded by the explicitly listed input length. Standard exact integer arithmetic therefore makes the entire algorithm polynomial in \(L\), settling the target question.
