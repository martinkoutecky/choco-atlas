The continuous mirror question, as graded

Given a finite road network, a finite set of commuter types θ with rational masses μ_θ summing to one, feasible route–arrival-time options \(A_θ\), rational per-capita link–time capacities κ_e, and valuations \(v_{θ a}\), compute a welfare-maximizing allocation \(x_{θ a}\) of type mass to options, subject to \(∑_{a∈A_θ}x_{θ a}=μ_θ\), \(∑_{θ,a}A_{ea}x_{θ a}≤κ_e\), and \(x_{θ a}≥0\), maximizing \(∑_{θ,a}v_{θ a}x_{θ a}\).

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: the list of \(\tau\) commuter types with positive binary-rational masses \(\mu_\theta\), summing to \(1\); \(\tau\) is the support size, not the number of possible types.
The input includes a finite directed road network of size \(m\), positive integer link travel times, and a finite, explicitly listed set of time slots. Each type has a fixed, distinct origin and destination and a nonempty, explicitly listed set \(A_\theta\) of route–arrival-time options.
An option specifies a nonempty simple route and its destination arrival slot. Travel follows the route without waiting: a link is entered at the arrival time minus the remaining route travel time, including that link. All resulting entry slots must be listed.
Let \(E\) be the link–time pairs and \(A_{ea}\in\{0,1\}\) indicate whether option \(a\) uses the permit for pair \(e\). Each link has a positive binary-rational per-capita capacity, identical across its time slots; write the resulting capacities as \(\kappa_e\).
Net valuations are explicitly supplied binary rationals satisfying \(1\le v_{\theta a}\le V\), for a supplied rational \(V\ge1\); they already include travel and schedule costs. Permit payments are transfers and do not enter welfare.
Assume feasibility. Allocate divisible mass \(x_{\theta a}\ge0\), requiring \(\sum_{a\in A_\theta}x_{\theta a}=\mu_\theta\) for every type and \(\sum_\theta\sum_{a\in A_\theta}A_{ea}x_{\theta a}\le\kappa_e\) for every \(e\in E\), to maximize \(\sum_\theta\sum_{a\in A_\theta}v_{\theta a}x_{\theta a}\).
Let \(n=\sum_\theta|A_\theta|\), \(k=|E|\), and \(L\) be the total binary input length; state running times in \(m,\tau,n,k,L\).

Is computing an exact welfare-maximizing allocation for this continuous problem in \(\mathrm{P}\), or is it \(\mathrm{NP}\)-hard?

For indivisible commuters, a day-to-day auction has a large-population welfare guarantee: the achieved-to-optimal welfare ratio tends to \(1\) with fixed route–time options, uniformly bounded positive valuations, and proportionally scaled capacities. This is an asymptotic guarantee, not a polynomial-time bound ([Wada–Akamatsu](https://www.jstage.jst.go.jp/article/jscejipm/67/3/67_3_376/_pdf)).

1. Constructing the explicit linear program

Index variables by the explicitly listed pairs \((\theta,a)\), where \(a\in A_\theta\). There are exactly \(n\) variables. Define the type-incidence matrix \(B\in\{0,1\}^{\tau\times n}\) by
\(B_{\theta,(\theta',a)}=1\) if \(\theta=\theta'\), and \(0\) otherwise. Define \(c_{(\theta,a)}=v_{\theta a}\).

The permit-incidence matrix \(A\in\{0,1\}^{k\times n}\) can be constructed from the routes and arrival slots. Specifically, if option \(a\) has route \((\ell_1,\ldots,\ell_r)\), arrival slot \(t_a\), and link travel times \(d_{\ell_j}\), then its entry slot on \(\ell_i\) is
\(t_a-\sum_{j=i}^{r}d_{\ell_j}\).
Set the corresponding entry of \(A\) to \(1\); set all other entries in that column to \(0\). This is exactly the stipulated no-waiting travel rule.

Each simple route has at most \(m\) links. Its suffix travel times require at most \(O(L+\log(m+1))\) bits, so these computations and comparisons against the explicitly listed slots take polynomial bit time. In particular, large numerical travel times do not require enumerating intervening times.

The optimization problem is therefore precisely the rational linear program
\(\max\{c^{\mathsf T}x:Bx=\mu,\ Ax\le\kappa,\ x\ge0\}\).

Every feasible vector of this linear program is an admissible allocation, and conversely. Its objective is exactly welfare because permit payments are excluded by hypothesis.

Replacing each type equality by two inequalities gives
\(q=k+2\tau+n\)
inequalities, including nonnegativity. Every constraint-matrix entry belongs to \(\{-1,0,1\}\).

Let \(H\) denote the binary encoding length of this explicit linear program. A conservative dense-encoding bound is
\(H=O\!\left(nq+(k+1)L\right)\).
Here the term \(kL\) permits copying a link’s capacity into every corresponding link–time constraint. Thus construction has polynomial cost in \(m,\tau,n,k,L\). No unlisted types or route options are introduced.

2. Existence and polynomial encoding of an exact optimum

Let \(P\) be the feasible set. It is nonempty by the feasibility assumption. For every variable, nonnegativity and its type’s mass equality imply
\(0\le x_{\theta a}\le\mu_\theta\le1\).
Consequently, \(P\) is closed and bounded, hence compact. The continuous linear objective attains its maximum. Moreover,
\(1\le c^{\mathsf T}x\le V\)
for every feasible allocation, because total allocated mass is \(1\).

The extreme-point theorem for linear programming states that a linear objective on a nonempty bounded polyhedron has an optimal vertex. Its hypotheses therefore hold here.

For completeness, an optimal vertex has polynomially many output bits. Let \(x^*\) be such a vertex. There are \(n\) linearly independent active constraint rows at \(x^*\). Indeed, if the active rows did not span \(\mathbb R^n\), a nonzero direction orthogonal to them would preserve every active constraint; sufficiently small moves in both directions would also preserve all finitely many inactive inequalities. That would express \(x^*\) as the midpoint of distinct feasible points, contradicting that it is a vertex.

Select these rows and write
\(Rx^*=b'\),
where \(R\) is an invertible integer matrix with entries in \(\{-1,0,1\}\). Each component of \(b'\) is a signed mass, a capacity, or zero.

Let \(D\) be the product of the denominators of the \(n\) selected right-hand sides. Each denominator has at most \(L\) bits, so
\(D\le2^{nL}\).
The vector \(Db'\) is integral. Cramer’s rule therefore represents each coordinate of \(x^*\) with denominator dividing \(D|\det R|\). Hadamard’s inequality gives
\(|\det R|\le n^{n/2}\),
because every row has Euclidean norm at most \(\sqrt n\).

Thus each reduced denominator has
\(O(nL+n\log(n+1))\)
bits. Since \(0\le x_i^*\le1\), its reduced numerator has no more bits than its denominator, up to a constant. The entire exact allocation consequently has polynomial encoding length.

This establishes that exact rational output is compatible with polynomial time; the output need not be merely an approximation.

3. Polynomial-time exact solution

Use the standard rational linear-programming theorem: given an explicitly encoded rational linear program, a deterministic algorithm can detect infeasibility or unboundedness, or return an exact rational optimum, in time polynomial in its dimensions and binary encoding length. This is the bit-complexity guarantee of rational linear programming; see [Adler–Beling](https://adler.ieor.berkeley.edu/ilans_pubs/lp_algebraic_stoc_1992.pdf) and [Trevisan’s discussion of exact rational recovery](https://lucatrevisan.wordpress.com/2011/01/24/cs261-lecture-5-linear-programming/).

All hypotheses have been checked: the program is explicit, its coefficients are rational, its encoding length is polynomially bounded, and it is feasible with an attained finite optimum. Applying the theorem costs
\(\operatorname{poly}(n,q,H)\)
bit operations. Including construction, the total running time is
\(\operatorname{poly}(m,\tau,n,k,L)\).

The returned vector is an exact welfare-maximizing allocation by the equivalence established in Section 1. The relevant number of types is the listed support size \(\tau\).

Hence the continuous problem is in \(\mathrm{P}\). An \(\mathrm{NP}\)-hardness classification under polynomial-time reductions would therefore imply \(\mathrm{P}=\mathrm{NP}\).

4. Relation to the auction guarantee

The [Wada–Akamatsu large-population guarantee](https://www.jstage.jst.go.jp/article/jscejipm/67/3/67_3_376/_pdf) concerns asymptotic welfare for an auction with indivisible commuters. Such a welfare limit does not establish a polynomial bound on computation or auction iterations. The classification proved here follows independently from the explicit rational linear program for divisible mass.
