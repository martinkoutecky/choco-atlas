The continuous mirror question, as graded

Given \(m\le7\) alternatives and a rational distribution \(\mu\) over complete rankings with \(|\operatorname{supp}(\mu)|\le3\), can one find locations in \(\mathbb{R}^2\) for the alternatives and each positive-mass type that realize every ranking in the support by Euclidean distance?

Packaged proof task (what the prover saw — nothing else)

Let \(A\) contain \(1\le m\le7\) alternatives. A society is given by its support: \(\tau\) distinct strict complete rankings \(\succ_i\), each with positive binary rational mass \(\mu_i\), where \(\sum_i\mu_i=1\) and \(1\le\tau\le3\). Here \(\tau\) is the support size, not the number of possible rankings; \(L\) is the total input bit length.
An embedding assigns \(x_a,y_i\in\mathbb R^2\) to every alternative and supported type, satisfying \(a\succ_i b\iff\lVert x_a-y_i\rVert_2<\lVert x_b-y_i\rVert_2\) for every distinct \(a,b\). Find an embedding, represented by rational coordinates, or report infeasibility.

Is this embedding problem solvable in time polynomial in \(m,\tau,L\), or is it NP-hard?

Bulteau and Chen establish, by exhaustive computational verification, that every discrete profile with at most three voters and seven alternatives admits such an embedding. [Source](https://arxiv.org/pdf/2205.14687v1)
The stated mass problem has exactly the same embedding constraints as the discrete profile consisting of its supported rankings; consequently, its feasibility is already covered by that result.

Modeling choices made when packaging the task

  • Normalized the rational distribution to total mass one and required nonempty support and at least one alternative.
  • Interpreted complete rankings as strict linear orders and required strict distance comparisons, following the discrete definition.
  • Specified rational coordinates as the finite output representation; strict inequalities ensure that any real embedding admits a rational embedding.

Conclusion

The stated embedding problem is solvable in polynomial time, including the requirement to output rational coordinates.

The feasibility question is already settled by the premise. The remaining issue is to give an algorithm whose rational output and running time are justified. The proof below uses the fixed bounds \(m\leq 7\) and \(\tau\leq 3\); its constants need not be practically small.

1. Feasibility and the role of masses

Replace the society by the discrete profile having one voter for each supported ranking. This profile has \(m\leq 7\) alternatives and \(\tau\leq 3\) voters. Its embedding constraints are exactly those of the society: no constraint involves a mass \(\mu_i\).

Theorem 3 of [Bulteau and Chen](https://arxiv.org/html/2205.14687v1#S4) states that every profile with at most three voters and seven alternatives admits a two-dimensional Euclidean embedding. Its hypotheses therefore apply. Using this given result, every valid input is feasible.

2. Every feasible profile has a rational embedding

For \(m=1\), placing all points at the origin satisfies the vacuous constraints. Assume henceforth that \(m\geq 2\).

Fix a real embedding. Multiplying every coordinate by the same positive number preserves every distance comparison, so we may scale the embedding until all coordinates belong to \([-1/2,1/2]\).

For each supported type \(i\) and pair with \(a\succ_i b\), define the squared-distance gap

\(\displaystyle F_{iab}=\lVert x_b-y_i\rVert_2^2-\lVert x_a-y_i\rVert_2^2.\)

Every such gap is positive. There are finitely many gaps and at least one, so

\(\displaystyle \delta=\min_{i,\;a\succ_i b}F_{iab}>0.\)

Let \(n\) be a positive integer. Round every coordinate to a nearest multiple of \(1/n\), with coordinate error at most \(1/(2n)\). Every rounded coordinate belongs to the grid

\(\displaystyle G_n=\{k/n:k\in\mathbb Z,\ -n\leq k\leq n\}.\)

We verify that sufficiently fine rounding preserves every gap. An original coordinate difference between an alternative and a voter has absolute value at most \(1\). Its rounding error has absolute value at most \(1/n\). Thus, writing that difference as \(u\) and its error as \(e\),

\(\displaystyle |(u+e)^2-u^2|\leq 2|u||e|+e^2\leq 2/n+1/n^2.\)

Summing over two coordinates, a squared distance changes by at most \(4/n+2/n^2\). Consequently, each gap changes by at most

\(\displaystyle 8/n+4/n^2\leq 12/n.\)

Choose \(n>12/\delta\). Every rounded gap is then strictly positive. These comparisons realize the entire ranking: if \(a\not\succ_i b\), strict completeness gives \(b\succ_i a\), and the corresponding positive gap enforces the opposite distance comparison.

Therefore every feasible profile admits a rational embedding on some grid \(G_n\).

3. An exact algorithm

First rename the alternatives as \(1,\ldots,m\), retaining the correspondence to their input labels.

For \(n=1,2,\ldots\):

  • Enumerate every assignment of the \(2(m+\tau)\) coordinates from \(G_n\).
  • Check every required strict squared-distance comparison using exact arithmetic.
  • Output the first assignment passing all checks.

The checks require only integer arithmetic. If \(x_a=(p_{a1}/n,p_{a2}/n)\) and \(y_i=(q_{i1}/n,q_{i2}/n)\), compare the integers

\(\displaystyle (p_{a1}-q_{i1})^2+(p_{a2}-q_{i2})^2\)

for the alternatives in the ranking. Their common denominator \(n^2\) cancels.

Section 2 proves that this deterministic algorithm terminates on every valid input. By Section 1, no valid input requires an infeasibility report.

4. Polynomial running time

After renaming alternatives, only finitely many ranking profiles satisfy the fixed bounds. Indeed, their number is at most

\(\displaystyle \sum_{m=1}^{7}\sum_{\tau=1}^{3}(m!)^\tau.\)

Let \(\mathcal P\) be the finite set of valid canonical profiles. For each \(P\in\mathcal P\), let \(N(P)\) be the first grid index admitting an embedding. The preceding proof establishes that every \(N(P)\) is finite. Hence

\(\displaystyle N_*=\max_{P\in\mathcal P}N(P)<\infty.\)

Crucially, \(N_*\) is independent of the masses, their bit lengths, and alternative labels.

There are at most \(20\) coordinates and \(63\) comparisons. At grid index \(n\), the algorithm examines at most \((2n+1)^{20}\) assignments, with each verification taking time polynomial in \(\log(n+1)\). Thus its entire search has a fixed finite running-time bound depending only on \(N_*\).

Reading the input, renaming alternatives, and restoring labels take polynomial time in \(L\). Output coordinates have bounded bit length because \(n\leq N_*\). The total running time is therefore polynomial in \(L\), and hence polynomial in \(m,\tau,L\) on the stated domain.

This is a uniform algorithm: it does not need a supplied embedding table or prior knowledge of \(N_*\). That constant is used only to prove its running-time bound.
