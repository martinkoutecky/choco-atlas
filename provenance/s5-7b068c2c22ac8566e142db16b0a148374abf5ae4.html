The continuous mirror question, as graded

Given alternatives \(A=U\cup K\), fixed positive reference weights \(r_k\) for \(k\in K\), and a finite support \(\mathcal T\) of assessor types with rational masses \(\mu_t\), suppose each type reports positive rational ratios \(c^t_{ij}\) on the same comparison set \(E\). If every connected component of the graph on \(U\) has a reported comparison to \(K\), compute the log-priority vector \(z_U\), with \(z_k=\log r_k\), minimizing \(\sum_{t\in\mathcal T}\mu_t\sum_{(i,j)\in E:\{i,j\}\cap U\ne\varnothing}(\log c^t_{ij}-(z_i-z_j))^2\), and return the priorities \(w_i=e^{z_i}\) or their ranking.

A society is given by its support: the list of its \(\tau\) assessor types with positive binary rational masses \(\mu_t\), summing to \(1\). Here \(\tau\) is the support size, not the number of possible types; \(L\) is the total input bit length.
All types report positive rational ratios \(c^t_{ij}\) on the same set \(E\) of compared pairs, each stored in one orientation; the reverse ratio is \(c^t_{ji}=1/c^t_{ij}\). Ratios estimate \(w_i/w_j\). Missing comparisons contribute no error; comparisons within \(K\) are fixed by the reference weights and omitted.
In the undirected comparison graph induced on \(U\), every connected component, including each isolated vertex, must have a comparison to \(K\).
Using natural logarithms, compute a minimizer \(z_U\in\mathbb R^U\), with \(z_k=\log r_k\), of \(\sum_{t\in\mathcal T}\mu_t\sum_{(i,j)\in E:\{i,j\}\cap U\ne\varnothing}(\log c^t_{ij}-(z_i-z_j))^2\), and the priorities \(w_i=e^{z_i}\).
Exact outputs are represented symbolically: each \(z_i\) is a rational linear combination of logarithms of input ratios and reference weights, and \(w_i\) is its exponential.

1. Incidence matrices and fixed reference values

Let \(n=|U|\), \(p=|K|\), and \(q=|E|\), after omitting comparisons within \(K\). Index each comparison by its stored orientation \(e=(i,j)\).

Define matrices \(B\in\mathbb Z^{q\times n}\) and \(D\in\mathbb Z^{q\times p}\) by
\(B_{eu}=\mathbf 1_{\{i=u\}}-\mathbf 1_{\{j=u\}}\) and
\(D_{ek}=\mathbf 1_{\{i=k\}}-\mathbf 1_{\{j=k\}}\).
Thus the full oriented incidence matrix is partitioned into its unknown and reference columns.

Write \(x=z_U\), \(\rho_k=\log r_k\), and \(y_e^t=\log c_{ij}^t\). For every comparison,
\((Bx+D\rho)_e=z_i-z_j\).
Consequently, the objective is
\(F(x)=\sum_{t=1}^{\tau}\mu_t\|y^t-Bx-D\rho\|_2^2\).

All logarithms exist because the input ratios and reference weights are positive. Each comparison appears exactly once, in its stored orientation.

2. Exact aggregation of assessor types

Define the mass-weighted logarithmic report
\(\bar y=\sum_{t=1}^{\tau}\mu_t y^t\).

For every real number \(a\) and every comparison \(e\), expansion of the square gives
\(\sum_t\mu_t(y_e^t-a)^2=(\bar y_e-a)^2+\sum_t\mu_t(y_e^t-\bar y_e)^2\).

Indeed, write \(y_e^t-a=(y_e^t-\bar y_e)+(\bar y_e-a)\). The cross term vanishes because
\(\sum_t\mu_t(y_e^t-\bar y_e)=0\), and the coefficient of \((\bar y_e-a)^2\) is \(\sum_t\mu_t=1\).

Applying this identity to every comparison yields
\(F(x)=\|\bar y-Bx-D\rho\|_2^2+C\),
where
\(C=\sum_{e,t}\mu_t(y_e^t-\bar y_e)^2\)
is independent of \(x\).

Thus the original problem has exactly the same minimizers as this single least-squares problem. This is an identity over the real numbers; the algorithm need not evaluate any logarithms.

3. The anchoring hypothesis gives positive definiteness

Set \(M=B^{\mathsf T}B\). For every \(v\in\mathbb R^U\),
\(v^{\mathsf T}Mv=\|Bv\|_2^2\).

An edge between unknown alternatives \(u,u'\) contributes \((v_u-v_{u'})^2\). An edge between an unknown alternative \(u\) and a reference alternative contributes \(v_u^2\), regardless of its stored orientation. Hence
\(v^{\mathsf T}Mv=\sum_{\{u,u'\}\in E,\ u,u'\in U}(v_u-v_{u'})^2+\sum_{\{u,k\}\in E,\ u\in U,\ k\in K}v_u^2\).

Suppose this quantity is zero. Every summand is nonnegative, so every summand is zero. The unknown–unknown edges therefore force \(v\) to be constant on each connected component of the graph induced on \(U\).

By hypothesis, each such component has an edge to \(K\). That edge forces the component’s constant to be zero. This also covers isolated unknown vertices, each of which must have a reference comparison. Therefore \(v=0\).

It follows that \(M\) is positive definite and invertible.

Differentiating the quadratic objective gives
\(\nabla F(x)=2B^{\mathsf T}(Bx+D\rho-\bar y)\).
Its unique stationary point is consequently
\(x^*=M^{-1}B^{\mathsf T}(\bar y-D\rho)\).

This point is the unique global minimizer: for any \(h\in\mathbb R^U\), expansion and the normal equations give
\(F(x^*+h)-F(x^*)=h^{\mathsf T}Mh\),
which is strictly positive whenever \(h\ne0\).

4. Explicit symbolic output

Compute the rational matrices
\(S=M^{-1}B^{\mathsf T}\) and \(T=-SD\).

For each \(u\in U\), output
\(z_u^*=\sum_{e=1}^{q}\sum_{t=1}^{\tau}S_{ue}\mu_t\log c_e^t+\sum_{k\in K}T_{uk}\log r_k\),
followed by
\(w_u=\exp(z_u^*)\).

Every coefficient is rational: \(M,B,D\) have integer entries, \(M\) is nonsingular, and all masses are rational. Thus these expressions have exactly the required form.

For each \(k\in K\), output \(z_k=\log r_k\) and \(w_k=r_k\). These prescribed reference weights are preserved without subsequent normalization.

Possible algebraic relations among the logarithms cause no difficulty. The requested representation is a rational linear combination of input logarithms; it does not require a canonical representation or testing logarithmic independence.

5. Polynomial bit complexity

It remains to justify polynomial running time in the binary input model.

Because \(E\) contains at most one stored orientation of each compared pair, \(q\leq m(m-1)/2\). The matrix \(M\) has integer entries of absolute value at most \(m\): its diagonal entries are unknown-vertex degrees, and its off-diagonal entries are either zero or minus one.

First consider coefficient sizes. Hadamard’s determinant inequality bounds every determinant of an \(s\times s\) submatrix of \(M\) by \((\sqrt{s}\,m)^s\). Consequently, \(\det M\) and all cofactors have bit length \(O(n\log(nm))\). Since
\(M^{-1}=\operatorname{adj}(M)/\det M\),
the inverse has rational entries of polynomial bit length.

For completeness, the inverse can also be *computed* in polynomial bit time by the following explicit rational-arithmetic procedure. Write
\(\chi_M(\lambda)=\lambda^n+a_1\lambda^{n-1}+\cdots+a_n\),
and set \(a_0=1\). Newton’s identities give, for \(1\leq j\leq n\),
\(a_j=-\frac1j\sum_{\ell=1}^{j}a_{j-\ell}\operatorname{tr}(M^\ell)\).

Compute the powers \(M,\ldots,M^n\) by repeated matrix multiplication, then compute these coefficients in increasing order of \(j\). This uses \(O(n^4)\) arithmetic operations with ordinary matrix multiplication.

The numbers involved have polynomial bit length:

  • Each entry of \(M^\ell\) has absolute value at most \(n^{\ell-1}m^\ell\), so its bit length is \(O(n\log(nm))\) for \(\ell\leq n\).
  • The coefficient \(a_j\), up to sign, is the sum of the \(j\times j\) principal minors of \(M\). Therefore \(|a_j|\leq\binom nj(\sqrt j\,m)^j\), again giving polynomial bit length.
  • Products and partial sums in Newton’s identities retain polynomial bit length, since each sum has at most \(n\) terms. The divisions yield integers because the identities compute the characteristic-polynomial coefficients of an integer matrix.

The Cayley–Hamilton theorem applies to the square matrix \(M\) over \(\mathbb Q\), giving
\(M^n+a_1M^{n-1}+\cdots+a_{n-1}M+a_nI=0\).
Here \(a_n=(-1)^n\det M\ne0\), by the positive definiteness already proved. Thus
\(M^{-1}=-\frac1{a_n}(M^{n-1}+a_1M^{n-2}+\cdots+a_{n-1}I)\).
This computes the inverse using polynomially many operations on numbers of polynomial bit length.

Matrix multiplication then computes \(S\) and \(T\) in polynomial bit time. Their entries can all use the common denominator \(\det M\). Their numerators are sums of polynomially many signed cofactors, so they also have polynomial bit length.

Finally, multiplying \(S_{ue}\) by an input mass \(\mu_t\) adds at most \(O(L)\) bits to its rational representation. Across all unknown alternatives, the displayed output contains at most \(n(\tau q+p)\) coefficient–logarithm terms. Both the number of terms and the size of every coefficient are polynomial in \(m,\tau,L\). Input logarithms may be referenced by their input positions.

Therefore the complete symbolic output can be computed and written in polynomial time. No expansion of rational masses into individual assessors is required.
