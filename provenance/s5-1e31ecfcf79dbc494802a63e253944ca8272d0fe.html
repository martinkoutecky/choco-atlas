Exact classification

Every admissible instance converges after one update. Define \(q=(1-\rho)h\). Then

\(a^\infty=(1,1)\) and \(A^\infty=1\) if \(\rho\geq(1-\rho)h\);

\(a^\infty=(0,0)\) and \(A^\infty=0\) if \(\rho<(1-\rho)h\).

Equivalently, the all-active outcome occurs exactly when \(\rho\geq h/(1+h)\), including equality. Exact computation is polynomial-time solvable.

Proof of convergence

Since \(\rho,h\in(0,1)\), we have \(0<q<1\).

At time \(1\), both types receive the same threshold:
\(\theta_r(1)=\theta_o(1)=\rho\cdot0+(1-\rho)h=q\).

Both also receive the same activity input:
\(p_r(1)=p_o(1)=\rho\cdot1+(1-\rho)\cdot0=\rho\).

Consequently, defining \(b=\mathbf{1}\{\rho\geq q\}\), the synchronous update gives \(a_r(1)=a_o(1)=b\).

We now prove that this state persists. Suppose, for some \(t\geq1\), both thresholds equal \(q\) and both activities equal \(b\). The next thresholds equal \(\rho q+(1-\rho)q=q\), while the next activity inputs equal \(\rho b+(1-\rho)b=b\).

If \(b=0\), then \(b<q\), so both next activities are zero. If \(b=1\), then \(b\geq q\), so both next activities are one. Thus both activities remain \(b\). Induction proves that, for every \(t\geq1\), the thresholds equal \(q\) and the activity profile equals \((b,b)\).

Therefore the limits exist, \(a^\infty=(b,b)\), and \(A^\infty=\rho b+(1-\rho)b=b\).

Exact algorithm and bit complexity

Write the input rationals as \(\rho=R/S\) and \(h=H/K\), with positive integers satisfying \(0<R<S\) and \(0<H<K\). Reduced fractions are unnecessary.

Because the denominators are positive, the activation condition is exactly

\(\rho\geq(1-\rho)h\quad\Longleftrightarrow\quad RK\geq(S-R)H\).

The algorithm computes these two integer products and compares them. It outputs \((1,1)\) and total mass \(1\) when the comparison holds, and \((0,0)\) and total mass \(0\) otherwise.

All intermediate integers have bit length \(O(L)\). Using elementary integer arithmetic, the subtraction, two multiplications, and comparison take \(O(L^2)\) bit operations. Since \(\tau=2\) is fixed, this is polynomial in the stipulated input measures.

This proof applies directly to the specified mass recurrence. In particular, the initial profile \((1,0)\) cannot persist: the two activities become equal at the first update. No finite-graph classification theorem or assumption about \(\beta\) is needed.
