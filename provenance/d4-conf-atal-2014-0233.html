The continuous mirror question, as graded

Given a finite type set \(T\), rational type shares \(\mu_t>0\) summing to \(1\), qualities \(w_t>0\), and reliabilities \(r_t\in(0,1)\), form for each scale \(M\) a random population with independent counts \(N_t\sim\operatorname{Poisson}(M\mu_t)\). Conditional on those counts, use the paper’s reliability-extension Max-Game and its ordinary finite Shapley values \(\phi_i\). For each type \(t\), compute the high-multiplicity limit \(\lim_{M\to\infty}\mathbb{E}[\sum_{i:\,\mathrm{type}(i)=t}\phi_i]\), and determine whether these limits admit an exact polynomial-time algorithm in \(|T|\) and the input bit length.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a nonempty list \(T\) of \(\tau\) types with positive binary rational masses \(\mu_t\), where \(\sum_{t\in T}\mu_t=1\); \(\tau\) counts listed types, not possible types. Each type has binary rational quality \(w_t>0\) and reliability \(r_t\in(0,1)\). Let \(m\) be the number of distinct qualities and \(L\) the total input bit length.
For each real scale \(M>0\), draw independent counts \(N_t\sim\operatorname{Poisson}(M\mu_t)\), creating a finite set \(N\) of distinct agents with type map \(\theta:N\to T\).
Conditional on these counts, each agent \(i\) survives independently with probability \(r_{\theta(i)}\). The coalition value is \(v^r(S)=\mathbb{E}[\max(\{w_{\theta(i)}:i\in S\text{ survives}\}\cup\{0\})]\).
Let \(\phi_i\) be the ordinary finite Shapley value of \((N,v^r)\), and define \(A_t(M)=\mathbb{E}_{(N_s)_{s\in T}}[\sum_{i:\theta(i)=t}\phi_i]\). Empty populations and absent types contribute zero; equal qualities are allowed.

Do all limits \(a_t=\lim_{M\to\infty}A_t(M)\) exist, and is computing the entire vector \((a_t)_{t\in T}\) exactly solvable in polynomial time in \(m,\tau,L\), or is this computation NP-hard?

For finite explicitly listed agents, Shapley values in reliability extensions of Max-Games are computable in polynomial time ([Bachrach, Savani and Shah, 2014](https://www.cs.toronto.edu/~nisarg/papers/MaxGames.pdf)).
No result settling this precise Poisson population limit was located in the literature search.

Modeling choices made when packaging the task

  • Qualities and reliabilities lacked an encoding specification; both are binary rationals, and L includes all masses, qualities and reliabilities.
  • The reliability extension is specified as the expected maximum of independently surviving agents, with empty survivor sets valued at zero.
  • Poisson sampling can produce empty populations or absent types; their aggregate payoffs are zero.
  • Equal qualities are permitted, consistently with the finite model; the maximum requires no tie-breaking.
  • The model had no m parameter; m denotes the number of distinct quality levels.
  • The scale ranges over positive reals, with shares, qualities and reliabilities fixed as it tends to infinity.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Result

All limits exist, and the entire vector is exactly computable in polynomial time in \(m,\tau,L\).

Write the distinct qualities as \(0=q_0<q_1<\cdots<q_m\). Define

\(\displaystyle \Delta_k=q_k-q_{k-1},\qquad T_k=\{s\in T:w_s\ge q_k\},\qquad x_t=\mu_t r_t,\qquad c_k=\sum_{s\in T_k}x_s.\)

For each type \(t\), let \(j(t)\) satisfy \(w_t=q_{j(t)}\). Every \(c_k\) is positive, because \(T_k\) is nonempty and every \(x_s\) is positive.

We will prove the exact formulas

\(\displaystyle A_t(M)=x_t\sum_{k=1}^{j(t)}\frac{\Delta_k}{c_k}\bigl(1-e^{-Mc_k}\bigr),\qquad a_t=x_t\sum_{k=1}^{j(t)}\frac{\Delta_k}{c_k}.\)

In particular, every \(a_t\) is rational.

1. Shapley values for a fixed population

Fix a finite population \(N\). Independently sample its agents’ survival indicators, and let \(B\subseteq N\) be the resulting survivor set. Define the deterministic game

\(\displaystyle g_B(S)=\max\bigl(\{w_{\theta(i)}:i\in S\cap B\}\cup\{0\}\bigr).\)

By the definition of the reliability extension, \(v^r(S)=\mathbb E_B[g_B(S)]\). The Shapley value is a finite linear combination of coalition values, so

\(\displaystyle \phi_i(v^r)=\mathbb E_B[\phi_i(g_B)].\)

For each quality threshold, put \(B_k=\{i\in B:w_{\theta(i)}\ge q_k\}\). The identity

\(\displaystyle g_B(S)=\sum_{k=1}^{m}\Delta_k\,\mathbf 1\{S\cap B_k\ne\varnothing\}\)

holds for every coalition: if its highest surviving quality is \(q_j\), precisely the first \(j\) indicators equal one, and their contributions telescope to \(q_j\). If there is no survivor, all indicators vanish.

Consider the threshold game \(h_k(S)=\mathbf 1\{S\cap B_k\ne\varnothing\}\). In a uniformly random permutation of all agents, an agent has marginal contribution one exactly when it belongs to \(B_k\) and appears before every other member of \(B_k\). Each member of a nonempty \(B_k\) has probability \(1/|B_k|\) of appearing first among its members. Therefore,

\(\displaystyle \phi_i(h_k)= \begin{cases} 1/|B_k|,&i\in B_k,\\ 0,&i\notin B_k. \end{cases}\)

When \(B_k\) is empty, the game is identically zero.

Let \(K_t\) denote the number of surviving type-\(t\) agents, and set \(K^{(k)}=\sum_{s\in T_k}K_s=|B_k|\). By Shapley linearity, the aggregate allocation to type \(t\) in \(g_B\) is

\(\displaystyle \sum_{i:\theta(i)=t}\phi_i(g_B) =\sum_{k=1}^{j(t)}\Delta_k \begin{cases} K_t/K^{(k)},&K^{(k)}>0,\\ 0,&K^{(k)}=0. \end{cases}\)

This also covers absent types and empty populations.

All these allocations are nonnegative. Their sum over types equals \(g_B(N)\), by telescoping marginal contributions along each permutation, and hence is at most \(q_m\). Thus all expectations used below are finite.

2. Averaging over the Poisson population

We now average over both population counts and survival indicators.

Conditional on \(N_t\), the count \(K_t\) is binomial with parameters \(N_t,r_t\). For \(0\le z\le1\), its probability generating function is

\(\displaystyle \mathbb E[z^{K_t}] =\mathbb E[(1-r_t+r_tz)^{N_t}] =\exp\bigl(M\mu_t r_t(z-1)\bigr). \)

The last equality follows by summing the Poisson probability series. Consequently, \(K_t\) is Poisson with mean \(Mx_t\). These surviving counts are independent across types, because the original counts and the survival experiments are independent across types.

It follows by multiplying generating functions that \(K^{(k)}\) is Poisson with mean \(Mc_k\).

Conditional on \(K^{(k)}=n\), the vector of eligible surviving counts has the multinomial distribution with probabilities \((x_s/c_k)_{s\in T_k}\). Indeed, for nonnegative integers \(h_s\) summing to \(n\), division of the joint Poisson probability by the probability of their sum gives

\(\displaystyle \Pr\bigl(K_s=h_s\text{ for all }s\in T_k\mid K^{(k)}=n\bigr) =\frac{n!}{\prod_{s\in T_k}h_s!} \prod_{s\in T_k}\left(\frac{x_s}{c_k}\right)^{h_s}. \)

Thus, for \(t\in T_k\) and \(n\ge1\),

\(\displaystyle \mathbb E\!\left[\frac{K_t}{K^{(k)}}\,\middle|\,K^{(k)}=n\right] =\frac{1}{n}\mathbb E[K_t\mid K^{(k)}=n] =\frac{x_t}{c_k}. \)

Taking the ratio to be zero when \(K^{(k)}=0\), we obtain

\(\displaystyle \mathbb E\!\left[\mathbf 1\{K^{(k)}>0\}\frac{K_t}{K^{(k)}}\right] =\frac{x_t}{c_k}\Pr(K^{(k)}>0) =\frac{x_t}{c_k}(1-e^{-Mc_k}). \)

Applying the fixed-population identity and then the law of total expectation proves

\(\displaystyle A_t(M)=x_t\sum_{k=1}^{j(t)} \frac{\Delta_k}{c_k}(1-e^{-Mc_k}). \)

3. Existence and value of every limit

There are finitely many summands, and every \(c_k\) is strictly positive. Hence each exponential tends to zero as \(M\) tends to infinity, proving

\(\displaystyle a_t=\lim_{M\to\infty}A_t(M) =x_t\sum_{k=1}^{j(t)}\frac{\Delta_k}{c_k}. \)

The formula also gives a quantitative convergence bound. Since \(c_k\ge c_m>0\),

\(\displaystyle 0\le a_t-A_t(M) =x_t\sum_{k=1}^{j(t)}\frac{\Delta_k}{c_k}e^{-Mc_k} \le a_t e^{-Mc_m}. \)

As a consistency check, the limits allocate exactly the maximum listed quality:

\(\displaystyle \sum_{t\in T}a_t =\sum_{k=1}^{m}\frac{\Delta_k}{c_k} \sum_{t\in T_k}x_t =\sum_{k=1}^{m}\Delta_k =q_m. \)

4. Exact polynomial-time computation

The formula requires sorting qualities, computing the tail sums \(c_k\), and computing the prefix sums \(\sum_{k=1}^{j}\Delta_k/c_k\). To establish polynomial bit complexity, we must also bound the sizes of these rational numbers.

Let \(D\) be the product of all denominators appearing in the input masses, reliabilities, and qualities. Since their binary encodings are included in the input, \(D\le 2^L\). Define integers

\(\displaystyle X_t=Dx_t,\qquad Q_k=Dq_k,\qquad d_k=Q_k-Q_{k-1},\qquad S_k=\sum_{t\in T_k}X_t.\)

These are integers: the denominator of \(\mu_t r_t\) divides the product of the two corresponding input denominators, which divides \(D\).

Furthermore, \(1\le S_k\le D\), because \(c_k>0\) and

\(\displaystyle c_k\le\sum_{t\in T}\mu_t r_t<\sum_{t\in T}\mu_t=1.\)

Now \(\Delta_k/c_k=d_k/S_k\). Compute integer pairs recursively by

\(\displaystyle P_0=1,\quad B_0=0,\qquad P_j=P_{j-1}S_j,\quad B_j=B_{j-1}S_j+d_jP_{j-1}. \)

Induction gives

\(\displaystyle \frac{B_j}{P_j}=\sum_{k=1}^{j}\frac{d_k}{S_k},\)

so the output for type \(t\) is the rational number

\(\displaystyle a_t=\frac{X_tB_{j(t)}}{DP_{j(t)}}.\)

These integers have polynomially bounded bit lengths. Indeed, \(P_j\le D^j\). Also, \(c_k\ge1/D\), so

\(\displaystyle \frac{B_j}{P_j} =\sum_{k=1}^{j}\frac{\Delta_k}{c_k} \le D\sum_{k=1}^{j}\Delta_k =Dq_j \le Dq_m. \)

Every input quality is at most \(2^L\). Consequently, \(B_j\le D^{j+1}2^L\). All intermediate integers and output numerators and denominators therefore have \(O((m+3)L)\) bits.

Sorting rational qualities uses polynomially many binary arithmetic operations. Grouping types by quality, forming tail sums, evaluating the recurrence, and producing all \(\tau\) fractions also use polynomially many operations on integers of the bounded sizes above. Fractions may be reduced using the polynomial-time Euclidean algorithm.

Thus the entire vector is exactly computable in polynomial time in \(m,\tau,L\), including its binary output representation.
