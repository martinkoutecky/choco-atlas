Result

The promised problem is solvable in polynomial time, with every limiting belief output as an exact rational number.

The proof uses the finite-agent limiting-belief characterization supplied in the question. The additional computational step is exact rational linear algebra on matrices of dimension at most \(\tau\).

1. Reduction to a finite network on the support

Construct a finite network with one vertex for each supported type \(t\). Give this vertex the type’s prior, likelihood table, signal process, and influence weights \(a_{ut}\).

Its update equations are exactly those of the society:
\(\psi_{t,i}(\theta)=b_{t,i-1}(\theta)\ell_t(z_{t,i}\mid\theta)/\sum_{\eta\in\Theta}b_{t,i-1}(\eta)\ell_t(z_{t,i}\mid\eta)\), followed by
\(b_{t,i}(\theta)=\sum_u a_{ut}\psi_{u,i}(\theta)\).

Thus, using the same signal realizations, the two systems have identical beliefs at every time. This follows by induction from their identical initial beliefs and update equations. There is no expansion of a mass into individual agents: the finite network has precisely \(\tau\) vertices.

The masses require no further multiplication because, by hypothesis, \(a_{ut}\) already incorporates the mass of type \(u\).

The finite-agent characterization states that, when senders learn and receiver observations cannot distinguish sender true states from their own truth, the limiting receiver vector is
\(\bigl[T_{SR}(I-T_{RR})^{-1}\bigr]^{\mathsf T}\) times the limiting sender vector. This is Theorem 2, with the influence matrix defined in equation (21), of [Salami, Ying, and Sayed](https://arxiv.org/pdf/1609.03703).

Here the required stochasticity, sender structure, sender learning, and likelihood equalities are given premises. Two details concerning the receiving network deserve explicit verification.

Arbitrary receiver connections

Every receiver is reachable from some sender along positive influence edges. To prove this, let \(U\subseteq R\) consist of receivers not reachable from senders. If \(r\in U\) and \(a_{ur}>0\), then \(u\in U\): otherwise an existing sender-to-\(u\) path extends to \(r\). Consequently, if \(U\) were nonempty, the restriction of \(T_{RR}\) to \(U\) would be column-stochastic.

After ordering \(U\) first, \(T_{RR}\) would have block form
\(\begin{bmatrix}C&F\\0&G\end{bmatrix}\), where \(C\) is column-stochastic. Hence \(1\) would be an eigenvalue of \(T_{RR}\), contradicting \(\rho(T_{RR})<1\).

Furthermore, the strongly connected components of the receiver graph can be ordered to make their component matrix block triangular. Each diagonal block has spectral radius less than \(1\), because its eigenvalues are eigenvalues of \(T_{RR}\). Thus unrestricted receiver connections fit the transient receiving part of the characterization.

Different receiver true states

If a common true-state label within each receiving component is needed, choose any sender true state \(\theta_*\) and relabel every receiver’s true state as \(\theta_*\). For each receiver \(r\), the stipulated equality gives
\(\ell_r(\cdot\mid\theta_*)=\ell_r(\cdot\mid\vartheta_r)\).

This relabeling preserves the actual signal laws and every update equation. It therefore preserves the entire belief process. All receiving components can consequently be treated as having the common true-state label \(\theta_*\).

These observations allow the supplied finite-agent characterization to be applied directly to the support network.

2. Exact formula for all limiting beliefs

Write \(k=|S|\), \(n=|R|\), and define
\(B=T_{RR}^{\mathsf T}\) and \(D=T_{SR}^{\mathsf T}\).

Define the \(k\times m\) matrix \(E\) by
\(E_{s\theta}=\mathbf 1_{\{\vartheta_s=\theta\}}\).
Because each sender learns its block’s true state, \(E\) is exactly the matrix of limiting sender beliefs.

The limiting receiver matrix \(Q=(q_r(\theta))\) is therefore

\(\displaystyle Q=(I_n-B)^{-1}DE.\)

The inverse exists: \(\rho(B)=\rho(T_{RR})<1\), so \(1\) is not an eigenvalue of \(B\).

In particular,

\(\displaystyle q_r(\theta)=\sum_{\substack{s\in S\\\vartheta_s=\theta}}\bigl[(I_n-T_{RR}^{\mathsf T})^{-1}T_{SR}^{\mathsf T}\bigr]_{rs}.\)

This formula automatically adds contributions from sender blocks with the same true state. For a state that is no sender’s truth, the corresponding column of \(E\), and hence of \(Q\), is zero.

Influence through receivers is retained

Since \(\rho(B)<1\), the convergent matrix geometric series gives

\(\displaystyle (I_n-B)^{-1}D=\sum_{j=0}^{\infty}B^jD.\)

The entry \((B^jD)_{rs}\) sums the products of influence weights along paths from sender \(s\) to receiver \(r\) containing exactly \(j\) receiver-to-receiver edges. Thus the inverse includes paths through other receivers and arbitrarily many traversals of receiver cycles.

The formula produces probability distributions

Every entry of \(Q\) is nonnegative by the geometric-series representation.

Column-stochasticity of \(A\) implies
\(D\mathbf 1_k+B\mathbf 1_n=\mathbf 1_n\).
Also, \(E\mathbf 1_m=\mathbf 1_k\). Therefore,

\(\displaystyle Q\mathbf 1_m=(I_n-B)^{-1}D\mathbf 1_k=(I_n-B)^{-1}(I_n-B)\mathbf 1_n=\mathbf 1_n.\)

Hence every row of \(Q\) sums to \(1\).

3. Polynomial-time exact computation

The algorithm constructs \(E\) and solves the rational linear system

\(\displaystyle (I_n-B)Q=DE.\)

A bit-length argument is necessary: a polynomial number of arithmetic operations alone would not establish polynomial-time exact computation.

Let \(d\) be the product of the positive denominators of all entries of \(A\), as encoded in the input. Its binary length is \(O(L)\). Set
\(C=d(I_n-B)\) and \(F=dDE\).
Both matrices are integral, and the system becomes \(CQ=F\).

Because all influence weights lie in \([0,1]\), every entry of \(C\) has absolute value at most \(d\). Each entry of \(DE\) sums a subset of the weights in a receiver column of \(A\), so every entry of \(F\) also has absolute value at most \(d\).

For a column \(f\) of \(F\), Cramer’s rule expresses each solution coordinate as
\(\det(C[j\leftarrow f])/\det(C)\), where \(C[j\leftarrow f]\) replaces column \(j\) of \(C\) by \(f\). The denominator is nonzero because \(C\) is nonsingular.

Hadamard’s determinant inequality gives

\(\displaystyle |\det(C)|\leq(\sqrt n\,d)^n,\qquad |\det(C[j\leftarrow f])|\leq(\sqrt n\,d)^n.\)

Thus every output numerator and denominator has binary length
\(O(n(\log d+\log n))=O(\tau(L+\log\tau))\).
Reducing the fraction cannot increase these lengths.

For an explicit polynomial algorithm, compute \(\det(C)\) and the \(nm\) replacement determinants using pivoted fraction-free Gaussian elimination. This uses a polynomial number of integer operations. Its intermediate entries are controlled by minors of the integer matrices; applying the same determinant bound to those minors gives polynomial intermediate bit lengths. Integer arithmetic and fraction reduction consequently take polynomial time as well.

There are \(nm\leq\tau m\) output entries, each of polynomial length. Constructing the matrices and reading the remaining input also take polynomial time. Therefore the total running time is polynomial in \(m,\tau,z_{\max},L\).

Conclusion

Under the stated promises and the supplied finite-agent characterization, exact limiting-belief computation belongs to \(\mathrm{FP}\). The algorithm solves rational linear systems on the support and fully retains receiver-mediated influence.
