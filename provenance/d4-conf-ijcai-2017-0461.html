The continuous mirror question, as graded

Given a finite type set \(T\), rational mass vector \(\mu\in\Delta(T)\), and relation matrix \(R:T\times T\to\{F,E,\bot\}\), decide whether there exists a finite-support mass decomposition \(\mathcal P=\{(\lambda_r,x^r)\}_r\) with \(\sum_r\lambda_r x^r=\mu\) and no nonzero profile \(z\) that can be assembled from agents weakly preferring \(z\) to their assigned profiles, with a positive-mass set strictly preferring it, under enemies aversion.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a nonempty list \(T\) of \(\tau\) types with positive binary-rational masses \(\mu_t\), summing to \(1\). Here \(\tau\) is the support size, not the number of possible types; \(L\) is the total input bit length. There is no separate candidate parameter \(m\).
The input also contains a directed relation matrix \(R:T\times T\to\{F,E,\bot\}\), denoting friends, enemies, and neutrals. Diagonal entries describe relations between distinct agents of the same type; an individual has zero mass.
A coalition profile is an absolute mass vector \(x\) with \(0\le x\le\mu\) and \(x\ne0\). Define \(e_t(x)=\sum_{s:R(t,s)=E}x_s\) and \(f_t(x)=\sum_{s:R(t,s)=F}x_s\). Type \(t\) ranks profiles by lexicographically maximizing \((-e_t(x),f_t(x))\); equality in both coordinates means indifference.
A finite fractional mass decomposition is \(\mathcal P=\{(\lambda_r,x^r)\}_{r=1}^{k}\), with real \(\lambda_r>0\), coalition profiles \(x^r\), and \(\sum_r\lambda_rx^r=\mu\). The mass of type \(t\) assigned profile \(x^r\) is \(\lambda_rx_t^r\); neither the profiles nor the weights are separately normalized.
A weak block consists of real recruitment amounts \(0\le y_{tr}\le\lambda_rx_t^r\), forming \(z_t=\sum_r y_{tr}\) with \(z\ne0\), such that \(y_{tr}>0\) implies \(z\succeq_t x^r\), and \(\sum_{(t,r):z\succ_t x^r}y_{tr}>0\). A decomposition is strictly core stable if it admits no weak block.

Is deciding whether such a strictly core-stable finite mass decomposition exists in \(\mathrm P\), with running time polynomial in \(\tau\) and \(L\), or is it \(\mathrm{NP}\)-hard?

For finite agents with directed friend, enemy, and neutral relations under enemies aversion, strict-core existence is \(\Sigma_2^{\mathrm P}\)-complete, and verification of a given partition is \(\mathrm{coNP}\)-complete. [Ota et al.](https://www.ijcai.org/proceedings/2017/0051.pdf)
No result settling this exact continuous mass-decomposition problem was located.

Modeling choices made when packaging the task

  • The profile domain was unspecified: profiles are nonzero absolute coalition mass vectors bounded componentwise by the society, preserving comparisons by friend and enemy quantities rather than proportions.
  • The decomposition weights were unspecified: they are positive real fractional multiplicities, with only the stated mass-conservation equation imposed; assigned mass is the weight times the profile.
  • Existential profiles and recruitment amounts may be real, and the decomposition has arbitrary finite support without an imposed size bound.
  • The assembly condition is expressed through recruitment amounts from each type and assigned profile, with strict improvement required on positive recruited mass.
  • Enemies aversion is lexicographic minimization of enemy mass followed by maximization of friend mass, with exact ties and neutral mass ignored.
  • Relations remain directed; diagonal labels apply to distinct agents sharing a type, while an individual's own zero mass contributes nothing.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Result

Deciding whether a strictly core-stable finite mass decomposition exists is \(\mathrm{NP}\)-hard.

This holds even when all masses are dyadic rationals, all diagonal entries are neutral, the enemy relation is symmetric, and only two types have any friends.

1. Enemy-free profiles are necessary

Call a profile \(x\) enemy-free if \(x_t>0\) implies \(e_t(x)=0\).

Lemma. Every profile of a strictly core-stable decomposition is enemy-free. Moreover, any weak block against a decomposition whose profiles are enemy-free must itself be enemy-free.

Proof. Suppose \(x_t^r>0\) and \(e_t(x^r)>0\). Set \(a=\lambda_rx_t^r\). Mass conservation gives \(0<a\le\mu_t\). Choose

\(\varepsilon=\frac12\min\{a,e_t(x^r)\}>0.\)

Recruit only an amount \(\varepsilon\) of type \(t\) from profile \(r\). The resulting profile \(z\) has \(z_t=\varepsilon\) and all other coordinates zero. It is feasible, and

\(e_t(z)\le\varepsilon<e_t(x^r).\)

Thus all recruited mass strictly improves, contradicting stability.

For the second assertion, let \(z\) be a weak block against enemy-free profiles. If \(z_t>0\), some \(y_{tr}>0\). Since the incumbent enemy coordinate is zero, \(z\succeq_t x^r\) requires \(e_t(z)=0\). Hence \(z\) is enemy-free. \(\square\)

Consequently, the support of an enemy-free profile cannot contain two types connected by an enemy entry.

2. Reduction from Independent Set

We reduce from Independent Set: given a simple undirected graph \(G=(V,\mathcal E)\), with \(n=|V|\), and an integer \(1\le k\le n\), decide whether its maximum independent-set size \(\alpha(G)\) satisfies \(\alpha(G)\ge k\). This problem is \(\mathrm{NP}\)-complete: graph complementation transforms it into the clique threshold problem, whose \(\mathrm{NP}\)-completeness is stated in [Ota et al., Section 4](https://www.ijcai.org/proceedings/2017/0051.pdf).

Introduce a set \(B\) of \(k\) additional types and two distinguished types \(p,q\). Thus

\(T=V\mathbin{\dot\cup}B\mathbin{\dot\cup}\{p,q\}.\)

Choose the least integer \(h\) such that \(2^h>n+k\), and put

\(\delta=2^{-h},\qquad \mu_s=\delta\ \text{for }s\in V\cup B,\qquad \mu_p=\mu_q=\frac{1-(n+k)\delta}{2}.\)

These masses are positive dyadic rationals and sum to \(1\).

Specify the relation matrix as follows:

  • \(p\) and \(q\) are mutual enemies.
  • For every \(\{u,v\}\in\mathcal E\), types \(u,v\in V\) are mutual enemies.
  • Every type in \(V\) is a mutual enemy of every type in \(B\).
  • Type \(p\) considers every type in \(V\cup B\) a friend.
  • Type \(q\) considers every type in \(B\) a friend.
  • Every remaining entry, including every diagonal entry, is neutral.

The types in \(V\cup B\) have no friends. Thus they are indifferent between all enemy-free profiles: their preference coordinates are always \((0,0)\).

For \(C\subseteq T\), write \(\mu[C]\) for the profile whose coordinate is \(\mu_t\) when \(t\in C\), and zero otherwise. Recruiting the entire mass of every type in \(C\) is always capacity-feasible: use \(y_{tr}=\lambda_rx_t^r\) for \(t\in C\), and zero otherwise.

We prove that the constructed society admits a strictly core-stable decomposition if and only if \(\alpha(G)\ge k\).

3. Stability forces the entire pool into profiles containing \(q\)

Suppose

\(\mathcal P=\{(\lambda_r,x^r)\}_{r=1}^{\ell}\)

is strictly core stable. By the lemma, every profile is enemy-free.

First, every profile containing type \(q\) must give it friend mass exactly \(k\delta\):

\(x_q^r>0\quad\Longrightarrow\quad f_q(x^r)=k\delta.\)

Indeed, \(q\)'s only friends are the types in \(B\), so every feasible profile gives \(q\) friend mass at most \(k\delta\).

Consider recruiting all mass of \(q\) and all mass of \(B\), producing \(z=\mu[\{q\}\cup B]\). This profile is enemy-free. Every recruited type in \(B\) is indifferent, while every recruited portion of \(q\) weakly prefers it. If any occupied profile of \(q\) supplied less than \(k\delta\) friend mass, a positive amount of \(q\) would strictly improve. That would be a weak block.

Because each coordinate \(x_b^r\) is at most \(\delta\), equality \(f_q(x^r)=k\delta\) forces

\(x_b^r=\delta\qquad\text{for every }b\in B\text{ whenever }x_q^r>0.\)

Now set

\(J=\{r:x_q^r>0\},\qquad W=\sum_{r\in J}\lambda_r.\)

Mass conservation for \(q\) gives

\(\mu_q=\sum_{r\in J}\lambda_rx_q^r\le\mu_qW,\)

so \(W\ge1\).

For any \(b\in B\), mass conservation gives

\(\delta=\sum_r\lambda_rx_b^r\ge\sum_{r\in J}\lambda_r\delta=\delta W,\)

so \(W\le1\). Here \(B\) is nonempty because \(k\ge1\). Therefore \(W=1\), and for every \(b\in B\),

\(\sum_{r\notin J}\lambda_rx_b^r=0.\)

All summands are nonnegative and every weight is positive. Consequently,

\(r\notin J\quad\Longrightarrow\quad x_b^r=0\text{ for every }b\in B.\)

Thus every profile containing any mass of \(B\) also contains \(q\). This conclusion applies to arbitrary real weights and arbitrary fractional profiles.

4. A stable decomposition implies a sufficiently large independent set

Since \(p,q\) are enemies, no enemy-free profile containing \(p\) can contain \(q\). By the preceding section, such a profile also contains no type in \(B\).

Its positive coordinates in \(V\) form an independent set of \(G\). Each such coordinate is at most \(\delta\). Hence

\(x_p^r>0\quad\Longrightarrow\quad f_p(x^r)\le\delta\alpha(G).\)

Suppose \(\alpha(G)<k\). Recruit all mass of \(p\) and all mass of \(B\), producing

\(z=\mu[\{p\}\cup B].\)

This profile is enemy-free and gives \(p\) friend mass \(k\delta\). Every recruited portion of \(p\) strictly prefers it, since its incumbent friend mass is at most \(\delta\alpha(G)<k\delta\). Every recruited portion of \(B\) is indifferent.

The strictly improving recruited mass is \(\mu_p>0\), so this is a weak block—a contradiction. Therefore existence of a strictly core-stable decomposition implies \(\alpha(G)\ge k\).

5. A sufficiently large independent set gives a stable decomposition

Conversely, suppose \(\alpha(G)\ge k\), and let \(I\subseteq V\) be a maximum independent set.

Use the following profiles, each with weight \(1\):

  • \(\mu[\{p\}\cup I]\);
  • \(\mu[\{q\}\cup B]\);
  • \(\mu[\{v\}]\) for every \(v\in V\setminus I\).

Their supports partition \(T\), so their sum is \(\mu\). They form a valid finite mass decomposition. Every profile is enemy-free.

The incumbent preference coordinates are:

  • \((0,\delta\alpha(G))\) for type \(p\);
  • \((0,k\delta)\) for type \(q\);
  • \((0,0)\) for every type in \(V\cup B\).

Suppose a weak block produces \(z\). The recruitment bounds imply \(0\le z\le\mu\), and the lemma implies that \(z\) is enemy-free.

Every recruited type in \(V\cup B\) remains indifferent because it has no friends.

For type \(q\), every feasible profile satisfies

\(f_q(z)=\sum_{b\in B}z_b\le k\delta.\)

Thus \(q\) cannot strictly improve.

If \(p\) participates, examine the source types present in \(z\). The support cannot contain both a type in \(V\) and a type in \(B\), because every such pair consists of mutual enemies.

If it contains types from \(V\), those types form an independent set of \(G\), giving

\(f_p(z)\le\delta\alpha(G).\)

If it contains types from \(B\), it gives

\(f_p(z)\le k\delta\le\delta\alpha(G).\)

If neither set contributes, its friend mass is zero. Therefore \(p\) cannot strictly improve either.

All recruited types have zero incumbent enemy mass, so none can strictly improve by reducing enemies. No recruited mass strictly improves in either coordinate, contradicting the definition of a weak block. The decomposition is therefore strictly core stable.

6. Complexity conclusion

The construction has

\(\tau=n+k+2\le2n+2.\)

Every mass has an encoding of \(O(\log n)\) bits, and the relation matrix has \(O(n^2)\) entries. The reduction is computable in polynomial time and establishes

\(\alpha(G)\ge k \quad\Longleftrightarrow\quad \text{a strictly core-stable finite mass decomposition exists}.\)

Hence the requested decision problem is \(\mathrm{NP}\)-hard. A running time polynomial in \(\tau\) and \(L\) would imply \(\mathrm P=\mathrm{NP}\).
