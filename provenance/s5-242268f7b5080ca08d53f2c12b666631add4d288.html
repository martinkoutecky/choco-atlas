Result

The problem is polynomial-time solvable in \(m,\tau,L\). The projection has the explicit formula
\[ y_{ij}=\frac{B_i-B_j}{m}\qquad(i<j), \]
where \(B_i\) is candidate \(i\)’s mass-weighted Borda score. Both the projection and every Borda tie can be computed using exact integer arithmetic.

1. Weighted Borda scores and pairwise row sums

Use the Borda convention that a candidate receives one point for each candidate ranked below it. Let \(b_t(i)\in\{0,\ldots,m-1\}\) denote this score in ranking type \(t\), and define
\[ B_i=\sum_{t=1}^{\tau}\mu_t b_t(i). \]

Extend the given pairwise vector antisymmetrically by setting \(d_{ji}=-d_{ij}\) for \(i<j\). Because every ranking is strict and the masses sum to one, this extension satisfies
\[ d_{ij}=\sum_{t:\,i\succ_t j}\mu_t-\frac12 \]
for every distinct \(i,j\).

Define \(r_i=\sum_{j\ne i}d_{ij}\). Interchanging the finite sums gives
\[ r_i =\sum_{t=1}^{\tau}\mu_t\sum_{j\ne i}\mathbf 1_{\{i\succ_t j\}} -\frac{m-1}{2} =B_i-\frac{m-1}{2}. \]

Antisymmetry also gives \(\sum_i r_i=0\), since each unordered pair contributes two opposite terms.

2. Exact formula for the orthogonal projection

Set \(p_i=r_i/m\), so that \(\sum_i p_i=0\), and define \(y_{ij}=p_i-p_j\) for \(i<j\). By construction, \(y\in\mathcal S\).

For an arbitrary \(q\in\mathbb R^m\), the corresponding vector in \(\mathcal S\) has coordinates \(q_i-q_j\). Regrouping each edge’s contributions at its two endpoints yields
\[ \begin{aligned} \sum_{i<j}\bigl(d_{ij}-(p_i-p_j)\bigr)(q_i-q_j) &=\sum_i q_i\sum_{j\ne i}\bigl(d_{ij}-(p_i-p_j)\bigr)\\ &=\sum_i q_i\left(r_i-mp_i+\sum_jp_j\right)\\ &=0. \end{aligned} \]
The last equality follows from \(mp_i=r_i\) and \(\sum_jp_j=0\).

Thus \(d-y\) is orthogonal to \(\mathcal S\). For any \(z\in\mathcal S\), orthogonality gives
\[ \|d-z\|^2=\|d-y\|^2+\|y-z\|^2. \]
Consequently, \(y\) is the unique orthogonal projection. Substituting the expression for \(r_i\) proves
\[ y_{ij}=\frac{r_i-r_j}{m}=\frac{B_i-B_j}{m}. \]

In particular, \(p_i>p_j\) exactly when \(B_i>B_j\), and \(p_i=p_j\) exactly when \(B_i=B_j\). Sorting the Borda scores in decreasing order therefore gives the projection-induced ranking with all ties retained.

3. Exact algorithm and bit complexity

Write each input mass as \(\mu_t=a_t/b_t\), with positive integers \(a_t,b_t\) encoded in binary. The argument covers general binary-encoded rationals and hence also dyadic rationals.

Choose the common denominator
\[ D=\prod_{t=1}^{\tau}b_t, \qquad w_t=a_t(D/b_t). \]
Every \(w_t\) is an integer. Moreover, positivity and normalization imply \(\sum_t w_t=D\).

Compute the integer score numerators
\[ N_i=\sum_{t=1}^{\tau}w_t b_t(i). \]
Then \(B_i=N_i/D\). The algorithm outputs each coordinate as the exact rational
\[ y_{ij}=\frac{N_i-N_j}{mD}, \]
and sorts the integers \(N_i\) in decreasing order, grouping equal values into ties.

To bound the arithmetic sizes, the total encoding length of the denominators is at most \(L\), so
\[ \log_2 D=\sum_t\log_2 b_t\le L. \]
Also, \(0<w_t\le D\) and
\[ 0\le N_i\le(m-1)D. \]
Therefore all score accumulators, coordinate numerators, and coordinate denominators have \(O(L+\log m)\) bits. The positive partial sums used to compute each \(N_i\) satisfy the same bound.

Reading the rankings and accumulating the scores requires \(O(m\tau)\) arithmetic operations. Producing the coordinates requires \(O(m^2)\) further operations, and sorting requires \(O(m\log m)\) exact integer comparisons. Computing \(D\) and the weights requires \(O(\tau)\) integer multiplications and exact divisions. All these operations take polynomial time in the stated bit lengths. If reduced fractions are desired, computing a greatest common divisor for each output coordinate also takes polynomial time.

The total output length is \(O(m^2(L+\log m))\) bits, plus the ranking representation. Thus the algorithm runs in time polynomial in \(m,\tau,L\) and returns precisely the requested exact output.
