The continuous mirror question, as graded

Given a population divided into τ response types with rational masses μ, a current yes-mass profile x, and explicit rational piecewise-affine response maps for each type and current opinion, compute the exact closure of all next yes-mass profiles attainable with positive probability as the cohort sizes grow. Output the transition relation as a finite symbolic representation.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: the list of \(\tau\geq1\) response types with positive masses \(\mu_t\), each a binary rational, with \(\sum_t\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types; there are \(m=2\) opinions, no and yes.
Let \(D=\prod_{t=1}^{\tau}[0,\mu_t]\). The input includes a rational current yes-mass profile \(x\in D\) and maps \(p_{t,b}:D\to[0,1]\), where \(b\in\{0,1\}\) is the agent's current opinion and the value is its probability of saying yes next.
Each map is explicitly specified by a finite partition into cells defined by rational strict or weak linear inequalities, with a rational affine formula on each cell. The maps are promised coordinatewise nondecreasing, with \(p_{t,0}(z)\leq p_{t,1}(z)\), \(p_{t,0}(0)=0\), and \(p_{t,1}(\mu)=1\).
For every positive integer \(N\) making all \(N\mu_t\) and \(Nx_t\) integral, form a population with \(N\mu_t\) agents of type \(t\), exactly \(Nx_t\) currently saying yes. Conditional on this state, agents update independently using \(p_{t,b}(x)\); let \(Y_N\) be the vector of next yes counts divided by \(N\).
Define \(R_x=\overline{\{y\in D:\exists N_k\to\infty,\ y_k\to y,\ \Pr(Y_{N_k}=y_k)>0\}}\), using admissible population sizes and Euclidean closure. The computational problem is to represent \(R_x\), the transition relation from the supplied \(x\), as a finite union of closed rational polytopes specified by linear inequalities.

Can this exact transition-set computation be performed in polynomial time in \(m,\tau,K,L\), or is it NP-hard, where \(K\) is the total number of response-map cells and \(L\) is the total binary input length?

For finite societies with independent updates and monotone aggregation functions satisfying unanimity boundaries, minimal coalitions permitting yes or no determine every positive-probability transition ([source](https://www.dbc.wroc.pl/Content/40006/PDF/orad_26_2016_2_069_085.pdf)); this is a characterization, without a complexity classification.
No result settling the specified mass-limit computation was identified in the literature search.

Modeling choices made when packaging the task

  • Normalized total population mass to one and interpreted each profile coordinate as absolute yes mass within its type.
  • Made the current profile rational, and defined cohort growth by exact integer replications of both type masses and current yes masses.
  • Used conditional independence of individual updates, as in the discrete transition-probability definition.
  • Carried over monotonicity and unanimity boundaries, including monotonicity in the agent's own current opinion.
  • Specified piecewise-affine inputs by rational polyhedral partitions with explicit boundary assignments; continuity is not imposed because aggregation functions need not be continuous.
  • Interpreted positive-probability attainability through limits of finite-population support points, without requiring probabilities to stay bounded away from zero.
  • Interpreted the requested transition relation as the outgoing set from the supplied current profile, and fixed its symbolic representation to a finite union of closed rational polytopes.
  • Set the opinion count to two and introduced the response-map cell count as an additional input parameter.

Result

The specified computation is polynomial-time solvable. For the supplied fixed profile \(x\), the set \(R_x\) is a single closed rational box, representable by \(2\tau\) linear inequalities.

The proof uses the stated definition: outcomes need positive probability, with no lower bound on that probability as the population grows.

1. Define the endpoints

For each type \(t\), let
\(a_{t,0}=\mu_t-x_t\), \(a_{t,1}=x_t\), and \(q_{t,b}=p_{t,b}(x)\).

Thus \(Na_{t,b}\) is the number of type-\(t\) agents currently holding opinion \(b\), and each such agent independently says yes next with probability \(q_{t,b}\).

Write \(\mathbf{1}_{E}\) for the indicator of a condition \(E\). Define
\(\ell_t=\sum_{b\in\{0,1\}}a_{t,b}\mathbf{1}_{\{q_{t,b}=1\}}\)
and
\(u_t=\sum_{b\in\{0,1\}}a_{t,b}\mathbf{1}_{\{q_{t,b}>0\}}\).

Here \(\ell_t\) is the mass forced to say yes, whereas \(u_t\) is the mass that can say yes. Since \(a_{t,b}\) is nonnegative and \(q_{t,b}\in[0,1]\), we have
\(0\leq\ell_t\leq u_t\leq\mu_t\).

We will prove
\(R_x=B_x\), where \(B_x=\prod_{t=1}^{\tau}[\ell_t,u_t]\).

2. Exact support at each admissible population size

Fix an admissible positive integer \(N\). Within type \(t\), the agents split into three groups:

  • Agents with \(q_{t,b}=1\) always say yes.
  • Agents with \(q_{t,b}=0\) always say no.
  • Agents with \(0<q_{t,b}<1\) can say either opinion with positive probability.

The first group contains exactly \(N\ell_t\) agents. The third group contains exactly
\(r_t=N(u_t-\ell_t)\) agents. These quantities are integers because they are sums of subgroup counts \(Na_{t,b}\).

For every integer \(j\) with \(0\leq j\leq r_t\), choose exactly \(j\) agents from the third group to say yes and all its remaining agents to say no. Every prescribed outcome for these agents has strictly positive probability. Independence makes the probability of their joint prescribed outcome a finite product of positive factors, hence positive.

Consequently, every next yes count
\(N\ell_t+j\), for \(j\in\{0,\ldots,r_t\}\), has positive probability. No other count is possible: the first group must say yes, the second must say no, and the third contributes between zero and \(r_t\) yes responses.

Independence across all agents also allows these choices to be made simultaneously for every type. Therefore, writing \(S_N=\{y\in D:\Pr(Y_N=y)>0\}\), we obtain the exact identity

\(S_N=\left\{\left(\ell_t+\frac{j_t}{N}\right)_{t=1}^{\tau}:j_t\in\mathbb Z,\ 0\leq j_t\leq N(u_t-\ell_t)\text{ for every }t\right\}.\)

In particular, \(S_N\subseteq B_x\).

3. The limiting transition set is the entire box

Because \(B_x\) is closed and contains every \(S_N\), every limit occurring in the definition of \(R_x\) belongs to \(B_x\). Taking the additional closure preserves this inclusion. Thus \(R_x\subseteq B_x\).

For the reverse inclusion, fix any \(y\in B_x\). Choose a positive integer \(Q\) divisible by the denominators of every \(\mu_t\) and \(x_t\). Such an integer exists because these numbers are rational. Every \(N_k=kQ\) is admissible, and \(N_k\) tends to infinity.

For each coordinate, set
\(j_{k,t}=\lfloor N_k(y_t-\ell_t)\rfloor\)
and
\(y_{k,t}=\ell_t+j_{k,t}/N_k\).

Since \(0\leq y_t-\ell_t\leq u_t-\ell_t\), and \(N_k(u_t-\ell_t)\) is an integer, we have
\(0\leq j_{k,t}\leq N_k(u_t-\ell_t)\).
The support identity from Section 2 therefore gives
\(\Pr(Y_{N_k}=y_k)>0\).

Moreover,
\(0\leq y_t-y_{k,t}<1/N_k\)
for every \(t\). Hence
\(\|y-y_k\|_2\leq\sqrt{\tau}/N_k\), which tends to zero.

Thus \(y\) is itself a limit of positive-probability outcomes along admissible population sizes. This proves \(B_x\subseteq R_x\), and establishes \(R_x=B_x\). The outer closure in the definition is consequently redundant.

4. Polynomial-time construction

The algorithm performs the following operations.

  • Evaluate each \(p_{t,b}(x)\) exactly. Scan its explicitly listed cells and test their defining rational inequalities at \(x\). The promised partition identifies the cell containing \(x\). Evaluate that cell’s rational affine formula.
  • Classify each evaluated probability. Determine whether it equals zero, equals one, or lies strictly between them, using exact rational comparisons.
  • Compute the endpoints. Apply the formulas for \(\ell_t\) and \(u_t\).
  • Output the polytope. Return the \(2\tau\) inequalities \(\ell_t\leq y_t\) and \(y_t\leq u_t\), for \(t\in\{1,\ldots,\tau\}\).

Strict cell inequalities cause no difficulty: membership is tested at the supplied rational point using exact comparisons. No cell-feasibility problem needs to be solved.

There are only polynomially many encoded inequalities and coefficients in the total input length \(L\). Each substitution or affine evaluation involves polynomially many rational arithmetic operations. Bringing its terms to a common denominator produces integers of polynomial bit length, so these operations and comparisons take polynomial time.

The endpoint formulas sum at most two rational subgroup masses each, giving polynomial bit length for every output coefficient. The output therefore has polynomial size, including when some intervals degenerate to singletons.

This proves polynomial running time in \(\tau,K,L\), and hence in the listed parameters with \(m=2\).

5. Role of the assumptions

The proof requires independence, probabilities in \([0,1]\), and polynomial-time exact evaluation at the fixed profile. The monotonicity and unanimity promises are compatible with the result but are not needed to compute this particular transition set.

The independent-update product formula also appears in the supplied [paper, Section 2](https://www.dbc.wroc.pl/Content/40006/PDF/orad_26_2016_2_069_085.pdf). The argument above derives the mass-limit set directly, without enumerating minimal coalitions.

Probabilities that shrink with population size still contribute to \(R_x\). For example, take \(\tau=1\), \(\mu_1=1\), \(x_1=1/2\), and \(p_{1,0}(z)=p_{1,1}(z)=z\). These maps satisfy all the promises. For every admissible \(N\), the all-no and all-yes outcomes each have probability \(2^{-N}>0\), and the proved formula gives \(R_x=[0,1]\).
