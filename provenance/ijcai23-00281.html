The continuous mirror question, as graded

Given \(n\) rounds, a finite type catalogue \(T\), rational cohort masses \(\mu_i(t)\) with \(\sum_{t\in T}\mu_i(t)=1\), rational utilities \(a_t,b_t>0\), and \(1\le a_t\le\alpha\), compute a deterministic type-level acceptance scheme \(E=(E_1,\ldots,E_n)\) maximizing \(\operatorname{Del}_{\mu}(E)\), or satisfying \(\operatorname{Del}_{\mu}(E)\ge c\frac{\log\log\alpha}{\log\alpha}\operatorname{OS}(\mu)\), when one candidate type is sampled from cohort \(i\) per round and the agent follows the induced optimal stopping response.

Packaged proof task (what the prover saw — nothing else)

Given \(n\ge1\) rounds, a society is given by its support: a list \(T\) of \(\tau\) types having positive mass in at least one cohort, with binary-rational masses \(\mu_i(t)\ge0\) satisfying \(\sum_{t\in T}\mu_i(t)=1\). Here \(\tau\) counts supported types, not possible types.
Each type has binary-rational utilities \(a_t,b_t>0\), with \(1\le a_t\le\alpha\) for a known rational \(\alpha\ge1\). Let \(L\) be the total input bit length; measure running times in \(m=n\), \(\tau\), and \(L\).
The principal commits to deterministic acceptance sets \(E_i\subseteq T\). Independently in each round, a type is sampled from \(\mu_i\); the agent observes it and irrevocably proposes it or discards it before seeing later draws.
A proposal reveals the type and ends the process: acceptance yields utilities \((a_t,b_t)\), rejection yields zero. Exhausting the rounds without a proposal also yields zero. Both parties know all input data.
The agent maximizes expected utility, breaking ties to maximize the principal’s expected utility. Let \(\operatorname{Del}_{\mu}(E)\) be the resulting principal utility and \(\operatorname{OS}(\mu)\) her optimal expected utility from observing the draws herself and stopping online.
Define \(r(\alpha)=\log\log(\max\{4,\alpha\})/\log(\max\{4,\alpha\})\).

Can a deterministic scheme satisfying \(\operatorname{Del}_{\mu}(E)\ge c\,r(\alpha)\operatorname{OS}(\mu)\), for a universal constant \(c>0\), be computed in polynomial time, or is this approximation guarantee impossible?

Known results: finite-support online delegation admits a deterministic polynomial-time scheme with this asymptotic guarantee. The cohort-mass formulation above is already covered by that model, so this target is settled. [Source](https://arxiv.org/html/2203.01084v1)

Modeling choices made when packaging the task

  • Specified independent draws across rounds, as required by the underlying model.
  • Specified full information, observable proposed types, termination after any proposal, and zero utility after rejection or no proposal.
  • Specified agent-optimal stopping with ties resolved in favor of the principal.
  • Defined the benchmark as the principal’s optimal undelegated online stopping utility.
  • Interpreted support as the union of positive cohort supports, permitting zero mass in individual cohorts.
  • Extended the asymptotic approximation expression to small discrepancy by replacing alpha inside the logarithms with max{4, alpha}.
  • Used m=n for the round-count parameter because this problem has no separate candidate-count parameter.

Conclusion

The requested deterministic scheme is computable in time polynomial in \(m\), \(\tau\), and \(L\). This follows from the known finite-support online-delegation theorem, with an exact reduction and polynomial-bit implementation as detailed below.

1. Known theorem used

We use the bounded-agent-utility result of Braun, Hahn, Hoefer, and Schecker: for independent, explicitly represented finite-support round distributions, conscious proposals, positive agent utilities with bounded discrepancy, and principal-favorable tie-breaking, their algorithm constructs a deterministic acceptance scheme with an \(\Omega(\log\log\alpha/\log\alpha)\) guarantee against optimal online search. This is [Theorem 3 and Algorithm 1 of *Delegated Online Search*](https://arxiv.org/html/2203.01084v1#S3.SS1).

We use its uniform formulation: if agent utilities lie in \([1,A]\), where \(A\ge4\), there is a universal constant \(c_0>0\) such that the computed scheme achieves at least
\(\displaystyle c_0\frac{\log\log A}{\log A}\)
times the principal’s optimal online utility. An upper bound \(A\) suffices; its endpoints need not be attained. The bounded range is covered by the construction’s constant number of dyadic classes.

This theorem is the external result used below; we do not claim a new proof of it.

2. Exact reduction of the cohort formulation

For each round \(i\), define
\(\displaystyle T_i=\{t\in T:\mu_i(t)>0\}\).
Create a round-specific option \(\omega_{i,t}\) for every \(t\in T_i\), with probability \(\mu_i(t)\), agent utility \(a_t\), and principal utility \(b_t\).

The number of represented options is
\(\displaystyle N=\sum_{i=1}^{m}|T_i|\le m\tau\).
Thus the reduction enumerates only supported types in their respective rounds.

Every hypothesis of the theorem holds:

  • Each round distribution has finite support and total probability one.
  • Draws across rounds are independent.
  • Agent utilities are positive and belong to \([1,A]\), for \(A=\max\{4,\alpha\}\).
  • Proposals reveal the type, so the principal can implement acceptance decisions for each represented option.
  • A proposal ends the process, with zero utilities upon rejection.
  • The prescribed tie-breaking favors the principal.

Let \(F_i\) be the acceptance set returned for round \(i\) in the reduced instance. Output
\(\displaystyle E_i=\{t\in T_i:\omega_{i,t}\in F_i\}\).

To verify preservation, couple the two instances using the same type draw in every round. Proposing \(t\) in the original instance and proposing \(\omega_{i,t}\) in the reduced instance give identical acceptance decisions and utilities. Discarding also leads to identical future distributions. Consequently, every agent strategy has a corresponding strategy with the same expected utility pair. Maximizing agent utility and then principal utility therefore gives identical delegated principal utilities.

The same coupling preserves every stopping strategy available to the principal when she observes the draws herself. Hence the online benchmarks are also identical.

Applying the theorem now gives
\(\displaystyle \operatorname{Del}_{\mu}(E)\ge c_0\frac{\log\log A}{\log A}\operatorname{OS}(\mu)=c_0r(\alpha)\operatorname{OS}(\mu)\).

3. Polynomial time under binary encoding

The cited construction sorts options, accumulates probability masses and probability-weighted principal utilities, forms dyadic agent-utility classes, and selects acceptance bins. It uses polynomially many operations in \(N\) and \(K=\lceil\log_2 A\rceil\). See [Algorithms 1–2](https://arxiv.org/html/2203.01084v1#S3.SS1).

These operations admit exact polynomial-bit implementations:

  • The expanded input is polynomial in size. There are at most \(m\tau\) records, each copying input rationals and adding round and type indices.
  • There are polynomially many dyadic boundaries. If the numerator encoding of \(\alpha\) has at most \(L\) bits, then \(K=O(L+1)\). Powers \(2^k\) used in comparisons consequently have polynomial bit length. No numerical evaluation of logarithms is needed.
  • Rational arithmetic has polynomial bit length. The accumulated quantities are sums of input probabilities and products of an input probability with an input utility, together with multiplication by dyadic boundaries. A common denominator obtained by multiplying all denominators in the expanded input has polynomial bit length and accommodates these sums and products. Their numerators also have polynomial bit length, since each sum has at most \(N\) terms of polynomial-bit magnitude.

Thus exact sorting, additions, multiplications, and comparisons all take polynomial bit time. The output itself has at most \(m\tau\) acceptance indicators.

Therefore the full construction runs in \(\operatorname{poly}(m,\tau,L)\) time and proves the requested affirmative answer.

Under the stated coupling, corresponding histories contain the same type draws and past decisions. At each history:

  • Corresponding proposals receive the same acceptance decision and utilities.

Thus corresponding strategies have identical expected utility pairs. The correspondence works in both directions on all histories with positive probability.

Consequently, both the agent’s maximum expected utility and the principal’s maximum utility among agent-optimal strategies are preserved. This checks the tie-breaking requirement, rather than merely preservation of the agent’s payoff.

\[ \operatorname{Del}_{\mu}(E) \ge c_0\frac{\log\log A}{\log A}\operatorname{OS}(\mu) = c_0r(\alpha)\operatorname{OS}(\mu). \]
