The continuous mirror question, as graded

Given a finite set of complete player types \(T\), rational masses \(\mu_t \ge 0\) summing to \(1\), and a sparse rational polynomial \(v(x)=\sum_{a\in A}q_a\prod_{t\in T}x_t^{a_t}\) with \(v(0)=0\), compute the exact limiting aggregate Shapley payoff for each type as finite societies with proportions \(\mu\) are replicated. Is the vector \(\Phi_t=\mu_t\int_0^1\partial_t v(\lambda\mu)\,d\lambda\) computable in time polynomial in the sparse input size, \(|T|\), the degree bound, and the rational bit lengths?

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a list \(T\) of \(\tau\geq1\) types with positive binary-rational masses \(\mu_t\), summing to \(1\). Here \(\tau\) is the support size, not the number of possible types; players of the same type are interchangeable.
The worth function is supplied as a sparse polynomial \(v(x)=\sum_{a\in A}q_a\prod_{t\in T}x_t^{a_t}\), with signed rational coefficients \(q_a\), nonnegative integer exponents \(a_t\), and \(v(0)=0\); no monotonicity or nonnegativity of worths is required. Its domain is \(\prod_{t\in T}[0,\mu_t]\).
Write \(m=|A|\). Exponents are binary encoded, a total-degree bound \(d\geq\max_{a\in A}\sum_t a_t\) is supplied in unary, and \(L\) is the total binary encoding length of the masses, coefficients, and exponent vectors.
For every positive integer \(n\) making all \(n\mu_t\) integral, form a TU-game with \(n\mu_t\) players of type \(t\), each representing mass \(1/n\), and coalition worth \(w_n(S)=v((|S\cap N_t|/n)_{t\in T})\). The limiting aggregate Shapley payoff of type \(t\) is represented by \(\Phi_t=\mu_t\int_0^1\partial_t v(\lambda\mu)\,d\lambda\).

Is computing the exact rational vector \((\Phi_t)_{t\in T}\) possible in time polynomial in \(m,\tau,d,L\), or is this computation NP-hard?

For arbitrary finite TU-games with independently specified coalition worths, exact Shapley computation requires \(\Omega(2^{n-1})\) worth accesses even for one player; this is a query lower bound, not an NP-hardness classification. [Besner](https://mpra.ub.uni-muenchen.de/112329/)
The continuous Aumann–Shapley diagonal formula and its interpretation as a limit of discrete cost shares under increasing divisibility are known; these do not classify the sparse rational input problem above. [Sprumont](https://cireqmontreal.com/wp-content/uploads/cahiers/11-2004-cah.pdf)

Modeling choices made when packaging the task

  • Removed zero-mass types so the supplied type list is exactly the positive-mass support; types mean interchangeable player classes.
  • Specified nonnegative integer exponents and signed rational coefficients, retaining the unrestricted worth domain of TU-games.
  • Specified the worth function's relevant domain as the box of feasible type masses.
  • Defined replication using equal player masses of 1/n, exact type proportions, and coalition worths evaluated at coalition masses; type payoffs are sums of individual Shapley payoffs without further normalization.
  • Used m for the number of supplied monomials and L for the total binary encoding length of masses, coefficients, and exponents.
  • Supplied the degree bound in unary so the requested polynomial dependence on its numerical value defines a polynomial-input-time question.

Result

The exact rational vector is computable in deterministic time polynomial in \(m,\tau,d,L\).

We take the supplied diagonal formula for \(\Phi_t\) as a premise. Its interpretation through increasing divisibility is discussed by [Sprumont](https://cireqmontreal.com/wp-content/uploads/cahiers/11-2004-cah.pdf); the proof below establishes the complexity for the specified sparse rational representation.

1. Exact contribution of each monomial

For each exponent vector \(a\), define its total degree and its value at the mass vector by
\(k_a=\sum_{s\in T}a_s\) and \(M_a=\prod_{s\in T}\mu_s^{a_s}\).

A term with \(k_a=0\) is constant and contributes zero to every derivative. Consider a term with \(k_a>0\).

If \(a_t=0\), its contribution to \(\Phi_t\) is zero. If \(a_t>0\), differentiation and substitution give
\(\mu_t\partial_t\bigl(q_a\prod_{s\in T}x_s^{a_s}\bigr)\big|_{x=\lambda\mu} =q_a a_t M_a\lambda^{k_a-1}\).
This identity holds throughout the integration interval: when \(k_a=1\), the last factor is the constant polynomial \(1\).

Because the sum is finite, differentiation and integration may be performed term by term. Since
\(\int_0^1\lambda^{k_a-1}\,d\lambda=1/k_a\), we obtain the exact formula
\(\boxed{\displaystyle \Phi_t=\sum_{\substack{a\in A\\k_a>0}}q_a\frac{a_t}{k_a}\prod_{s\in T}\mu_s^{a_s}}\).

Thus each nonconstant monomial contributes its value at \(\mu\), distributed across types in the proportions \(a_t/k_a\). Signed coefficients cause no difficulty.

If \(d=0\), every term is constant, so all coordinates are zero. Henceforth assume \(d\geq1\).

2. A common denominator of polynomial bit length

Write the input rationals as
\(\mu_s=u_s/b_s\) and \(q_a=p_a/r_a\), where \(u_s,b_s,r_a\) are positive integers and \(p_a\) is an integer. These fractions need not be reduced.

Define
\(B=\prod_{s\in T}b_s\),
\(R=\prod_{a\in A}r_a\), and
\(D=R B^d d!\).
Empty products are interpreted as \(1\).

For a nonconstant monomial, put
\(P_a=\prod_{s\in T}u_s^{a_s}\) and
\(Q_a=\prod_{s\in T}b_s^{a_s}\).
Its contribution to coordinate \(t\) is
\(p_a a_t P_a/(r_a k_a Q_a)\).

We claim that \(r_a k_a Q_a\) divides \(D\). Indeed:

  • \(r_a\) divides \(R\).
  • Since \(1\leq k_a\leq d\), \(k_a\) divides \(d!\).
  • Since every \(a_s\leq d\),

\(B^d/Q_a=\prod_{s\in T}b_s^{d-a_s}\) is an integer.

Multiplying these three integer quotients proves the claim.

Consequently,
\(\Phi_t=N_t/D\), where the integer numerator is
\(\displaystyle N_t=\sum_{\substack{a\in A\\k_a>0}}p_a a_t P_a\frac{D}{r_a k_a Q_a}\).

Let \(\ell(z)\) denote the binary bit length of an integer \(z\), with \(\ell(0)=1\). Because the total input encoding length is \(L\),
\(\log_2 B\leq L\) and \(\log_2 R\leq L\).
Also, \(d!\leq d^d\). Therefore
\(\ell(D)=O\bigl(1+(d+1)L+d\log_2(d+1)\bigr)\).

The numerators are also small enough to output in polynomial time. Positivity and normalization of the masses imply \(0<\mu_s\leq1\), hence \(0<M_a\leq1\). Moreover, \(0\leq a_t/k_a\leq1\), and the coefficient encoding gives \(|q_a|\leq2^L\). Thus each summand in \(N_t\) has absolute value at most \(D2^L\). Every partial sum has absolute value at most \(mD2^L\), so
\(\ell(N_t)=O\bigl(\ell(D)+L+\log_2(m+1)\bigr)\).

This bounds both the final output and the intermediate accumulators, even when coefficients have different signs.

3. Polynomial-time algorithm

The following algorithm uses exact integer arithmetic.

  • Compute \(B,R,D\), and initialize an integer accumulator \(N_t=0\) for each type.
  • For each monomial, compute \(k_a\). Skip it if \(k_a=0\).
  • Compute \(P_a,Q_a\) by binary exponentiation and compute the exact integer quotient \(D/(r_a k_a Q_a)\).
  • Add \(p_a a_t P_a D/(r_a k_a Q_a)\) to each \(N_t\).
  • Output \(N_t/D\), reducing each fraction by the greatest common divisor if reduced output is required.

Every exponent is at most \(d\), so each exponentiation requires \(O(\log_2(d+1))\) integer multiplications. Furthermore,
\(\log_2 P_a\leq dL\) and \(\log_2 Q_a\leq dL\).
Together with the bounds above, this shows that every integer occurring in the algorithm has polynomial bit length.

The number of arithmetic operations is
\(O\bigl(m\tau\log_2(d+1)+m+\tau+d\bigr)\):
the factorial can be computed with \(d\) multiplications, and each monomial requires polynomially many exponentiations and coordinate updates. Integer addition, multiplication, division, and greatest-common-divisor computation all admit polynomial-time bit algorithms. Therefore the entire computation has polynomial bit complexity in \(m,\tau,d,L\).

The unary encoding of \(d\) is essential to this argument: it makes polynomial dependence on the numerical degree a polynomial dependence on the supplied input length.

4. Complexity conclusion

The specified function problem belongs to \(\mathrm{FP}\). No construction or enumeration of the finite games is needed.

The query lower bound for independently specified coalition worths concerns a different input representation. Here the sparse polynomial lets us evaluate all monomial contributions directly. An \(\mathrm{NP}\)-hardness result under standard polynomial-time reductions would therefore imply \(\mathrm{P}=\mathrm{NP}\).
