The continuous mirror question, as graded

Given a finite transaction set \(X\) and a finite-support rational distribution over pairs of true and reported strict orders, with at most mass \(\varepsilon\) on pairs that disagree, compute an ordering \(\pi\) using the reported-order marginal. Require that for every \(\gamma \in (1/2,1]\), if true-order mass at least \(\gamma\) ranks \(x\) before \(y\) but \(\pi\) reverses them, then \(\pi\) contains a reverse path from \(y\) to \(x\) whose every step has true-order mass at least \(\gamma-2\varepsilon\).

Packaged proof task (what the prover saw — nothing else)

Let \(X\) be a finite transaction set of size \(m\geq 1\). A society is given by its support: the list of the \(\tau\) types with positive mass, each mass a binary rational; \(\tau\) is the support size, not the number of possible types. Here a type is a pair \((T,R)\) of complete strict orders on \(X\), respectively true and reported. Masses sum to \(1\).
Let \(\varepsilon\in[0,1]\) be rational, with \(\Pr[T\neq R]\leq\varepsilon\), and let \(L\) be the total binary input length. Write \(p(x,y)=\Pr[x\prec_T y]\).
Compute a deterministic strict order \(\pi\) of all of \(X\) using only the reported-order marginal: the output must be identical for all societies with that marginal, independently of their true orders and of \(\varepsilon\).
For every admissible society and every real \(\gamma\in(1/2,1]\), require that if \(p(x,y)\geq\gamma\) and \(y\prec_\pi x\), there exist \(k\geq 1\) and distinct transactions \(y=z_0\prec_\pi z_1\prec_\pi\cdots\prec_\pi z_k=x\) with \(p(z_i,z_{i+1})\geq\gamma-2\varepsilon\) for every \(0\leq i<k\).

Can such an ordering rule be computed in time polynomial in \(m,\tau,L\), or is this continuous ordering problem NP-hard?

For \(n\) equally weighted replicas with complete votes and \(f\) faulty replicas, [Ranked Pairs achieves this guarantee](https://arxiv.org/html/2304.02730v4#S4) simultaneously for every \(\gamma\in(1/2,1]\), with error parameter \(f/n\), in polynomial time without knowing \(f\).
No result settling the exact rational-support mass formulation was located in the literature search.

Modeling choices made when packaging the task

  • Made the distribution normalization explicit: positive rational support masses sum to one.
  • Specified complete strict true and reported orders on the entire transaction set, and required a complete output order.
  • Specified a rational error bound in [0,1], retaining the anchor's allowance of any faulty fraction.
  • Interpreted using the reported marginal as requiring a deterministic output depending only on that marginal, independently of true orders and the error bound, as in the discrete algorithm.
  • Made the reverse path requirement explicit: every step must advance in the output order, as required by the discrete fairness definition.
  • Defined L as total binary input length and allowed any nonempty finite transaction set.

Proven result

The problem is polynomial-time solvable. Exact rational weights can be used directly in Ranked Pairs, without expanding the society into equally weighted replicas. The resulting order depends only on the reported-order marginal and satisfies the requirement simultaneously for every allowed \(\gamma\) and \(\varepsilon\).

1. Construction using only reported orders

For distinct \(u,v\in X\), define the reported pairwise probability
\( q(u,v)=\Pr[u\prec_R v]. \)
This is determined by the reported-order marginal.

Fix a canonical order on the transaction identifiers, independent of the society. Use it to break all ties deterministically.

Apply the descending-weight locking procedure described in [Section 4 of the supplied paper](https://arxiv.org/html/2304.02730v4#S4):

  • List all \(m(m-1)\) directed edges \((u,v)\), with weight \(q(u,v)\).
  • Sort them by nonincreasing weight, breaking equal-weight ties canonically.
  • Start with the empty directed graph \(H\) on \(X\). Process each edge in this sequence, adding it precisely when its addition would not create a directed cycle.
  • Output a topological order \(\pi\) of the final graph, choosing the canonically first available vertex whenever necessary.

Processing all directed edges, including weights at most \(1/2\), will ensure the proof applies even when \(\gamma-\varepsilon\leq 1/2\).

The graph remains acyclic by construction, so a topological order exists and includes every transaction. All decisions depend only on \(q\) and the fixed transaction identifiers. Consequently, societies with the same reported-order marginal produce identical output, regardless of their true orders, support decompositions, or values of \(\varepsilon\).

For \(m=1\), the construction outputs the unique order and the guarantee is vacuous.

2. The reverse-path property

We prove a property of the construction that holds for every distinct pair \(x,y\):

If \(y\prec_\pi x\), then there is a directed path in the final graph \(H\) from \(y\) to \(x\), every edge of which has weight at least \(q(x,y)\).

To prove this, consider the moment when \((x,y)\) was processed. It cannot have been accepted: an accepted edge remains in the final graph, and every topological order would then put \(x\) before \(y\), contradicting \(y\prec_\pi x\).

Thus \((x,y)\) was rejected. Let \(H_{\mathrm{old}}\) be the graph immediately before that rejection. It was acyclic, whereas adding \((x,y)\) would create a directed cycle. Any such cycle must contain the new edge, since \(H_{\mathrm{old}}\) itself has no cycle. Removing the new edge from this cycle gives a directed path
\( y=z_0\longrightarrow z_1\longrightarrow\cdots\longrightarrow z_k=x \)
in \(H_{\mathrm{old}}\), with \(k\geq 1\).

Every edge of this path was processed before \((x,y)\). The processing sequence is nonincreasing in weight, so
\( q(z_i,z_{i+1})\geq q(x,y) \)
for every \(0\leq i<k\).

Accepted edges are never removed, so the path persists in the final graph. Its vertices are distinct because the graph is acyclic. Finally, every path edge is respected by the topological order, giving
\( y=z_0\prec_\pi z_1\prec_\pi\cdots\prec_\pi z_k=x. \)
This proves the property, including the required monotonicity in the output order.

3. Transfer from reported probabilities to true probabilities

Let \(\delta=\Pr[T\neq R]\), so that \(\delta\leq\varepsilon\). For any distinct \(u,v\), the indicators of \(u\prec_T v\) and \(u\prec_R v\) agree whenever \(T=R\). Therefore
\( \begin{aligned} |p(u,v)-q(u,v)| &=\left|\mathbb{E}\!\left[\mathbf{1}_{\{u\prec_T v\}}-\mathbf{1}_{\{u\prec_R v\}}\right]\right|\\ &\leq\mathbb{E}\!\left[\left|\mathbf{1}_{\{u\prec_T v\}}-\mathbf{1}_{\{u\prec_R v\}}\right|\right]\\ &\leq\Pr[T\neq R]\\ &\leq\varepsilon. \end{aligned} \)

Now fix any real \(\gamma\in(1/2,1]\) and distinct \(x,y\) satisfying \(p(x,y)\geq\gamma\) and \(y\prec_\pi x\).

The reverse-path property supplies distinct transactions
\( y=z_0\prec_\pi z_1\prec_\pi\cdots\prec_\pi z_k=x \)
such that, for every \(0\leq i<k\),
\( \begin{aligned} p(z_i,z_{i+1}) &\geq q(z_i,z_{i+1})-\varepsilon\\ &\geq q(x,y)-\varepsilon\\ &\geq p(x,y)-2\varepsilon\\ &\geq\gamma-2\varepsilon. \end{aligned} \)

This is exactly the requested guarantee. The construction never uses \(\gamma\) or \(\varepsilon\), and the argument holds for every allowed choice of them. Thus the guarantee is simultaneous over the entire specified continuum of thresholds.

4. Polynomial bit complexity

Write the support masses as \(a_s/b_s\), for \(1\leq s\leq\tau\), with positive integers \(a_s,b_s\) encoded in binary. Set
\( D=\prod_{s=1}^{\tau}b_s, \qquad c_s=a_s(D/b_s). \)

The bit length of \(D\) is at most \(1+\sum_s\log_2 b_s\), hence is \(O(L)\). The normalization of the masses gives
\( \sum_{s=1}^{\tau}c_s=D. \)

For each directed pair, compute
\( A(u,v)=\sum_{\{s:\,u\prec_{R_s}v\}}c_s. \)
Then \(q(u,v)=A(u,v)/D\), and \(0\leq A(u,v)\leq D\). Every weight numerator therefore has \(O(L)\) bits. Although the numerical value of \(D\) can be exponentially large, its binary representation has polynomial length.

Using rank positions in each reported order, all numerators can be computed with \(O(\tau m^2)\) integer additions. Sorting requires \(O(m^2\log(m+1))\) comparisons of these numerators; their denominator is common.

For each candidate edge \((u,v)\), a graph search tests whether the current graph contains a path from \(v\) to \(u\). Such a path exists exactly when adding \((u,v)\) would create a cycle. Each search takes \(O(m^2)\) graph operations, so processing all edges takes \(O(m^4)\) graph operations. Topological sorting is polynomial as well.

All integer arithmetic uses polynomially many bits, and standard exact arithmetic therefore gives total running time polynomial in \(m,\tau,L\). Neither replica expansion nor enumeration of threshold values is required.
