Here \(\tau\) is the support size, not the number of possible types; \(L\) is the total input bit length.
There are \(m\) divisible items of unit supply. Each atomless agent has a fixed unit budget of artificial currency; monetary transfers are forbidden and resources may be discarded.
A deterministic anonymous direct rule assigns a nonnegative rational bundle density \(A_\mu(r)\) to every report \(r\in\mathbb{Q}_{>0}^m\), including reports outside the support. Write \(x_t=A_\mu(v_t)\); feasibility requires \(\sum_t\mu_t x_{tj}\leq1\) for every item \(j\), for every reported society.
An individual's report leaves the aggregate distribution unchanged. Require dominant-strategy truthfulness: \(v\cdot A_\mu(v)\geq v\cdot A_\mu(r)\) for all positive rational true types \(v\), reports \(r\), and aggregate reported societies \(\mu\).
Let \(x^*(\mu)\) maximize \(\sum_t\mu_t\log(v_t\cdot x_t)\) subject to the same feasibility constraints. Its type utilities are unique. Let \(p^*(\mu)\) be the associated competitive-equilibrium prices with unit budget per agent, equivalently aggregate budget \(\mu_t\) for type \(t\).
The achieved PF ratio is \(\rho_A(\mu)=\min_t\{v_t\cdot A_\mu(v_t)/(v_t\cdot x_t^*(\mu))\}\). Computing the rule means producing a finite description that evaluates any rational report; construction and evaluation times are measured in \(m,\tau,L\) and the report's bit length.

Can a polynomial-time feasible, dominant-strategy truthful direct rule guarantee \(\rho_A(\mu)\geq\min_j\{p_j^*(\mu)/\lceil p_j^*(\mu)\rceil\}\) for every such atomless society, or is this approximation guarantee impossible?

For finitely many unit-budget agents with additive valuations, Strong Demand Matching is truthful, runs in polynomial time, and guarantees \(\min_j\{p_j^*/\lceil p_j^*\rceil\}\). [Cole–Gkatzelis–Goel](https://arxiv.org/pdf/1212.1522)

Proven result

Yes. Under the stated atomless deviation model, a polynomial-time feasible, dominant-strategy truthful rule can achieve the stronger guarantee \(\rho_A(\mu)=1\).

The normalization \(\sum_t\mu_t=1\) makes the requested bound relatively weak: equilibrium prices sum to \(1\), so it equals \(\min_j p_j^*(\mu)\). Nevertheless, the construction below implements the PF utilities exactly, including a truthful extension to every report outside the support.

1. Compute an aggregate Fisher equilibrium

Fix any reported society \(\mu\). Construct a finite linear Fisher market with:

  • one buyer for each support type \(t\);
  • buyer \(t\)'s budget equal to \(\mu_t\);
  • utility coefficients \(v_{tj}\);
  • one unit of each item.

We use the following established computational result: a linear Fisher market with positive rational budgets and rational utility coefficients admits exact equilibrium computation in polynomial time, with rational prices and allocations. Orlin gives an exact strongly polynomial algorithm for the integer-input formulation. [Orlin, *Improved Algorithms for Computing Fisher’s Market Clearing Prices*](https://drops.dagstuhl.de/storage/16dagstuhl-seminar-proceedings/dsp-vol10171/DagSemProc.10171.2/DagSemProc.10171.2.pdf).

Its hypotheses apply here. To reduce rational inputs to integers, multiply all budgets by a common denominator \(D\), and multiply each valuation row by its own common denominator. Row scaling preserves preferences. Budget scaling multiplies equilibrium prices by \(D\) and preserves physical allocations; divide the computed prices by \(D\) afterward. These denominator products have polynomial bit length in \(L\), and there are only \(\tau\) buyers.

Let \(p\) be the resulting prices and \(y_t\) the aggregate physical bundle allocated to buyer \(t\). Every price is positive: if \(p_j=0\), any buyer could obtain unbounded utility from item \(j\), because all valuation coefficients are positive, contradicting utility maximization.

Define \(\beta_t=\max_j v_{tj}/p_j\). The equilibrium conditions give

\(\displaystyle \sum_t y_{tj}=1,\qquad p\cdot y_t=\mu_t,\qquad y_{tj}>0\ \Longrightarrow\ v_{tj}/p_j=\beta_t.\)

Consequently,

\(\displaystyle \sum_jp_j=\sum_t p\cdot y_t=\sum_t\mu_t=1.\)

Set the per-agent densities to \(\displaystyle x_t=y_t/\mu_t\). Then

\(\displaystyle p\cdot x_t=1,\qquad v_t\cdot x_t=\beta_t,\qquad \sum_t\mu_t x_{tj}=1.\)

Fix all algorithmic tie-breaking deterministically, and sort support types canonically before computation. Thus the construction depends only on the reported society.

2. Define the rule on every rational report

Let the common set of available bundles be

\(\displaystyle B_p=\{z\in\mathbb{R}_{\geq0}^m:p\cdot z\leq1\}.\)

For each positive rational report \(r\), define \(A_\mu(r)\) as follows.

  • If \(r=v_t\) for a support type, return \(x_t\).
  • Otherwise, let \(j(r)\) be the smallest index maximizing \(r_j/p_j\), and return \(\displaystyle e_{j(r)}/p_{j(r)}\), where \(e_j\) is the \(j\)-th coordinate vector.

All returned bundles are nonnegative and rational. The prices specify a set of permissible bundles; the rule makes no monetary transfers.

For any report \(r\), write \(\beta(r)=\max_j r_j/p_j\). Every \(z\in B_p\) satisfies

\(\displaystyle r\cdot z=\sum_j\frac{r_j}{p_j}p_jz_j\leq\beta(r)\,p\cdot z\leq\beta(r).\)

For an outside-support report, the specified pure bundle attains this bound. For a support report \(v_t\), the equilibrium identities give \(v_t\cdot x_t=\beta_t=\beta(v_t)\).

Thus, for every report \(r\), \(A_\mu(r)\) maximizes \(r\cdot z\) over \(B_p\).

3. Feasibility and dominant-strategy truthfulness

Feasibility follows directly:

\(\displaystyle \sum_t\mu_t A_\mu(v_t)_j=\sum_t\mu_t x_{tj}=\sum_t y_{tj}=1.\)

This argument applies separately to every reported society in the specified domain.

For truthfulness, fix any aggregate society \(\mu\), any positive rational true type \(v\), and any positive rational report \(r\). By construction, \(A_\mu(r)\in B_p\), while \(A_\mu(v)\) maximizes \(v\cdot z\) over \(B_p\). Therefore

\(\displaystyle v\cdot A_\mu(v)\geq v\cdot A_\mu(r).\)

This includes true types and reports outside the support. The essential premise is that an individual's deviation leaves \(\mu\), and therefore the prices and available bundles, unchanged.

4. The supported allocation is exactly PF

We prove optimality directly.

Let \(z=(z_t)_t\) be any feasible collection of densities. If some \(v_t\cdot z_t=0\), its logarithmic objective is negative infinity, so it cannot improve on \(x\). Otherwise, the preceding budget inequality gives

\(\displaystyle \frac{v_t\cdot z_t}{\beta_t}\leq p\cdot z_t.\)

Using \(\log a\leq a-1\) for positive \(a\), and \(v_t\cdot x_t=\beta_t\), we obtain

\(\displaystyle \sum_t\mu_t\log(v_t\cdot z_t)-\sum_t\mu_t\log(v_t\cdot x_t) \leq \sum_t\mu_t\frac{v_t\cdot z_t}{\beta_t}-1. \)

The right-hand side is at most

\(\displaystyle \sum_t\mu_t p\cdot z_t-1 = \sum_jp_j\sum_t\mu_tz_{tj}-1 \leq \sum_jp_j-1 =0, \)

where the inequality uses feasibility and positive prices.

Hence \(x\) maximizes the stated PF objective. By the stipulated uniqueness of PF type utilities,

\(\displaystyle v_t\cdot A_\mu(v_t)=v_t\cdot x_t^*(\mu)\quad\text{for every }t.\)

It follows that \(\rho_A(\mu)=1\). Since each positive price satisfies \(\displaystyle p_j^*(\mu)/\lceil p_j^*(\mu)\rceil\leq1\), the requested guarantee follows.

5. Finite description and polynomial complexity

The rule's description stores the support types, the computed prices, the densities \(x_t\), and the report-evaluation instructions above.

Exact Fisher equilibrium computation takes polynomial time in \(m,\tau,L\). Its rational outputs have polynomial encoding length, and division by the positive rational masses preserves that bound.

Evaluation uses exact rational equality checks against the support. For an outside-support report, it compares the \(m\) ratios \(r_j/p_j\) and outputs one reciprocal price. Both construction and evaluation therefore have the required polynomial complexity.

The finite-agent obstruction does not carry over: a finite agent can change equilibrium prices by changing their report. Here each individual's report leaves the aggregate fixed, and the rule explicitly makes truthful reporting select a utility-maximizing bundle from the resulting fixed set.
