The continuous mirror question, as graded

Given a finite type set \(T\), rational masses \(\mu_t\) summing to \(1\), and a rational piecewise-linear coalition-value function \(\phi\) on \([0,\mu]\), compute a finite list of nonzero vectors \(x^1,\ldots,x^k\) with \(\sum_j x^j=\mu\) whose total value \(\sum_j\phi(x^j)\) is within \(\varepsilon\) of the supremum over such lists. Determine the complexity in \(|T|\), the number of linear pieces, input bit length, and \(\log(1/\varepsilon)\), including whether dynamic programming over type-mass splits admits useful pruning.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a nonempty list \(T\) of \(\tau\) types with positive binary-rational masses \(\mu_t\), where \(\sum_{t\in T}\mu_t=1\). Here \(m=\tau=|T|\); support size means listed positive-mass types, not the number of possible types.
Let \(B=\prod_{t\in T}[0,\mu_t]\). The input specifies a continuous piecewise-affine function \(\phi:B\to\mathbb R\) by \(r\) rational polytopes covering \(B\), each given by linear inequalities and a rational affine formula; formulas agree on overlaps. Require \(\phi(0)=0\), but allow either sign elsewhere.
A coalition structure is any finite list of nonzero real vectors \(x^1,\ldots,x^k\in B\) with \(\sum_{j=1}^k x^j=\mu\). Repeated vectors are allowed, and there is no bound on \(k\). Its value is \(\sum_{j=1}^k\phi(x^j)\); let \(S\) be the supremum over all such lists.
Given binary-rational \(0<\varepsilon<1\), the computational problem is to output an explicit list of rational coalition vectors with value at least \(S-\varepsilon\). Let \(L\) be the total input bit length; running time includes writing the list.

Does this problem admit an algorithm polynomial in \(m,\tau,r,L,\log(1/\varepsilon)\), or is obtaining this additive guarantee NP-hard?

For finite agents with arbitrary real coalition values, every nonempty bipartition of a coalition of size \(c\le n/2\) passes IDP's size-based split filter; this is a property of that filter, not a lower bound for all algorithms. [Verified discrete result](https://ifaamas.org/AAMAS/aamas2014/proceedings/aamas/p293.pdf).
Optimal continuous resource allocation is polynomial-time computable for linear bottleneck overlapping-coalition games, a differently represented restricted model. [Verified continuous result](https://arxiv.org/pdf/1407.0420). The search located no result settling the general problem defined above.

Modeling choices made when packaging the task

  • Interpreted rational piecewise-linear input as continuous piecewise-affine data on an explicitly listed rational polyhedral cover, with formulas agreeing on overlaps.
  • Set the empty-coalition value to zero. The discrete definition does not constrain it because partitions exclude empty coalitions; this is the natural normalization for the mass model.
  • Retained arbitrary signed values, as in the discrete characteristic-function definition, rather than imposing nonnegativity.
  • Used precisely the positive-mass support as T, so m and tau both equal its size.
  • Interpreted epsilon as an absolute additive tolerance with 0 < epsilon < 1.
  • Allowed real vectors in the supremum but required binary-rational vectors in the explicit computational output; repeated coalitions and unrestricted finite list length remain allowed.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Proven conclusion. Obtaining the additive guarantee is \(\mathrm{NP}\)-hard, even for \(m=\tau=1\) and fixed \(\varepsilon=1/4\). The reduction below has polynomial-length rational optimal solutions.

Moreover, the explicit-list requirement creates a separate, unconditional obstruction: some instances with \(m=\tau=1\) and \(r=2\) require exponentially many output coalitions.

1. Encoding Exact Cover by integer sums. We reduce from Exact Cover, a classical \(\mathrm{NP}\)-complete problem established in [Karp’s original paper](https://link.springer.com/chapter/10.1007/978-1-4684-2001-2_9).

Let the universe be \(U=\{1,\ldots,n\}\), with \(n\ge 1\), and let the listed subsets be \(C_1,\ldots,C_p\). Empty sets and duplicates can be deleted without changing whether an exact cover exists.

Define the positive integers

\[ D=n+1,\qquad E=\sum_{i=1}^{n}D^{i-1},\qquad H=nE+1,\qquad W=nH+E. \]

For each listed set, define

\[ e_j=\sum_{i\in C_j}D^{i-1}, \qquad w_j=H+e_j. \]

Let \(A=\{H,w_1,\ldots,w_p\}\). The number \(H\) serves as a padding weight. Every member of \(A\) lies between \(H\) and \(H+E\), and therefore belongs to \(\{1,\ldots,W\}\).

We claim that \(W\) is a sum of members of \(A\), with repetitions allowed, if and only if the Exact Cover instance is a yes-instance.

If an exact cover uses \(k\) sets, then \(k\le n\), because those sets are nonempty and disjoint. Their corresponding weights, together with \(n-k\) copies of \(H\), sum to \(nH+E=W\).

Conversely, suppose a multiset of \(\ell\) weights from \(A\) sums to \(W\). Since every weight is at least \(H\), and \(E<H\),

\[ \ell H\le W=nH+E<(n+1)H, \]

so \(\ell\le n\). If \(\ell\le n-1\), its sum is at most

\[ (n-1)(H+E)<nH<W, \]

where the strict inequality follows from \((n-1)E<H\). Thus \(\ell=n\).

Subtracting the \(n\) copies of \(H\), the selected set encodings must sum to \(E\). Let \(c_i\) count how many selected sets contain element \(i\), counting repetitions. Then

\[ \sum_{i=1}^{n}c_iD^{i-1} = \sum_{i=1}^{n}D^{i-1}. \]

Here \(0\le c_i\le n<D\), so neither side has carries in base \(D\). Uniqueness of base-\(D\) representation gives \(c_i=1\) for every \(i\). Hence the selected sets form an exact cover. In particular, no nonempty set is selected twice.

All constructed integers have \(O(n\log(n+1))\) bits, so this encoding is polynomial in the Exact Cover input length.

2. Constructing the permitted piecewise-affine function. Use one listed type of mass \(\mu_1=1\), so \(B=[0,1]\). Define

\[ d(u)=\min_{a\in A\cup\{0\}}|u-a|, \qquad \phi(x)=x-d(Wx). \]

This function is continuous and satisfies \(\phi(0)=0\). Its negative values are permitted by the task.

To verify the required explicit representation, sort the distinct weights as \(0=a_0<a_1<\cdots<a_s\le W\). For each \(i\in\{0,\ldots,s-1\}\), supply the following two interval polytopes and affine formulas:

  • On \([a_i/W,(a_i+a_{i+1})/(2W)]\), use \(\phi(x)=(1-W)x+a_i\).
  • On \([(a_i+a_{i+1})/(2W),a_{i+1}/W]\), use \(\phi(x)=(1+W)x-a_{i+1}\).

Finally, on \([a_s/W,1]\), use \(\phi(x)=(1-W)x+a_s\). A degenerate final interval may be omitted.

These intervals cover \(B\), and their formulas agree at every shared endpoint. There are at most \(2p+3\) pieces. Every coefficient and endpoint has polynomial bit length. Thus this is a polynomial-time construction in exactly the representation specified in the question.

3. An exact characterization of the coalition optimum. Define the additive semigroup

\[ \mathcal M= \left\{ \sum_{j=1}^{k}a_j: k\ge 0,\ a_j\in A \right\}, \qquad \Delta=\min_{z\in\mathcal M}|W-z|. \]

The minimum exists: its possible values are nonnegative integers, and \(0\in\mathcal M\).

We prove that \(S=1-\Delta\).

First, consider any admissible finite coalition structure \(x^1,\ldots,x^k\). For each coalition, choose a nearest weight \(b_j\in A\cup\{0\}\) to \(Wx^j\). Then \(\sum_jb_j\in\mathcal M\). Using feasibility and the triangle inequality,

\[ \begin{aligned} \sum_{j=1}^{k}\phi(x^j) &=1-\sum_{j=1}^{k}|Wx^j-b_j|\\ &\le 1-\left|W-\sum_{j=1}^{k}b_j\right|\\ &\le 1-\Delta. \end{aligned} \]

This argument applies to every finite list, regardless of its length or repeated vectors.

For the reverse inequality, choose \(z_*\in\mathcal M\) attaining \(\Delta\). Since \(H\in\mathcal M\) and \(0<H<W\),

\[ \Delta\le W-H<W. \]

Consequently, \(0<z_*<2W\). Choose a representation \(z_*=\sum_{j=1}^{k}a_j\), with \(a_j\in A\), and set \(x^j=a_j/z_*\). These are positive rational coalition vectors in \(B\), and they sum to \(1\). Moreover,

\[ \begin{aligned} \sum_{j=1}^{k}d(Wx^j) &\le \sum_{j=1}^{k}\left|\frac{Wa_j}{z_*}-a_j\right|\\ &=\left|\frac{W}{z_*}-1\right|\sum_{j=1}^{k}a_j\\ &=|W-z_*|=\Delta. \end{aligned} \]

Their value is therefore at least \(1-\Delta\). Combined with the upper bound, this proves \(S=1-\Delta\), with the maximum attained by rational coalitions.

This also proves that the reduction has short optimal outputs. Each \(a_j\ge H\), so

\[ kH\le z_*<2W, \qquad k<\frac{2W}{H}=2n+\frac{2E}{H}<2n+2. \]

Thus \(k\le 2n+1\). Every numerator and denominator in \(x^j=a_j/z_*\) has \(O(\log W)\) bits.

4. The constant-gap hardness reduction. Section 1 gives the following dichotomy:

  • If an exact cover exists, then \(W\in\mathcal M\), hence \(\Delta=0\) and \(S=1\).
  • If no exact cover exists, then \(W\notin\mathcal M\). Since all members of \(\mathcal M\) are integers, \(\Delta\ge 1\), hence \(S\le 0\).

Now run a hypothetical polynomial-time algorithm for the requested problem with \(\varepsilon=1/4\). On a yes-instance, its output must have value at least \(3/4\). On a no-instance, every feasible output has value at most \(0\).

Evaluating the explicit rational output is polynomial in its bit length, using the listed interval formulas. Therefore, testing whether its value is positive decides Exact Cover in polynomial time. This establishes \(\mathrm{NP}\)-hardness, even with one support type and fixed additive error. Every reduction instance has a polynomial-length exact rational optimum, as proved above.

5. The unconditional output-length obstruction. For an integer \(N\ge 1\), again use one type of mass \(1\), and define

\[ \delta=2^{-N}, \qquad \phi(x)=\min\{x/\delta,1\}. \]

This has two rational affine pieces and input length \(O(N)\). For every coalition structure,

\[ \sum_j\phi(x^j)\le\sum_jx^j/\delta=2^N. \]

Splitting the mass into \(2^N\) coalitions of size \(\delta\) attains this bound, so \(S=2^N\).

Each coalition contributes at most \(1\). Therefore, a list attaining value at least \(S-1/4\) must have

\[ k\ge 2^N-\frac14. \]

Since \(k\) is an integer, \(k\ge 2^N\). Writing this explicit list requires exponential time. Consequently, the polynomial running-time bound asked for in the question is impossible unconditionally under the stated output format.
