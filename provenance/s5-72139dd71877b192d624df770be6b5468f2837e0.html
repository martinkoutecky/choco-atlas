The continuous mirror question, as graded

Given a finite customer set \(D\), a finite support \(T\) of facility types, rational masses \(\mu_t>0\) with \(\sum_{t\in T}\mu_t=1\), and rational utilities \(u_{td}\), define \(V(S)=\sum_{d\in D}\max_{t\in S}u_{td}\), with \(V(\varnothing)=0\). Generate a random ordering of \(T\) by repeatedly choosing a remaining type \(t\) with probability equal to its mass divided by the remaining mass. For each \(t\), compute \(\Phi_t=\mathbb{E}[V(P_t\cup\{t\})-V(P_t)]\), where \(P_t\) is the set of preceding types, and output the exact vector \((\Phi_t)_{t\in T}\). Determine the exact computation’s bit complexity; equivalently, compute \(\Phi_t=\sum_{d\in D}\int_0^{u_{td}}\frac{\mu_t}{\sum_{s:u_{sd}\ge q}\mu_s}\,dq\).

Packaged proof task (what the prover saw — nothing else)

Let \(F\) be a nonempty set of \(m\) facilities, which are the players. A society is given by its support: a list \(T\) of \(\tau\) resident utility-profile types with positive binary rational masses \(\mu_t\), where \(\sum_{t\in T}\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types.
Each type specifies binary rational utilities \(u_{it}\geq0\) for every \(i\in F\); equal utilities are allowed. Let \(L\) be the total input bit length.
For every coalition \(S\subseteq F\), define \(v_\mu(S)=\sum_{t\in T}\mu_t\max(\{u_{it}:i\in S\}\cup\{0\})\). Facilities are uncapacitated, and residents contribute utility but are not players.
The requested payoffs are the standard Shapley values and the probabilistic Banzhaf values, with Banzhaf coefficients \(2^{-(m-1)}\) and no subsequent normalization of the payoff vector.

Can all facilities’ exact Shapley and Banzhaf payoffs be computed in time polynomial in \(m,\tau,L\), or is this computation task NP-hard?

For finite customer lists with unit customer weights, Han et al. give a polynomial-time algorithm computing both payoff vectors in facility location games ([source](https://arxiv.org/html/2006.14583v6)).
That result does not explicitly classify the bit complexity of the rational-mass input defined here.

  • Required at least one facility, matching the nonempty player-set convention.
  • Fixed Banzhaf to the probabilistic value with coefficients 2^{-(m-1)}, as defined in the supplied background, without efficiency normalization.
  • Allowed utility ties and used the characteristic function to determine payoffs; no ordering-based tie-breaking is imposed.
  • Renamed the facility set to F and reserved L for total input bit length.

Result

Both exact payoff vectors can be computed in deterministic time polynomial in \(m,\tau,L\). This includes arbitrary ties and binary rational masses and utilities.

Han et al.’s Theorem V-H.1 and Appendix I give formulas and a sorting algorithm for the finite-customer model. The proof below independently establishes the formulas needed here and their rational bit complexity. [Han et al.](https://arxiv.org/html/2006.14583v6#S5.SS8)

1. Decomposing each type into threshold games

For each type \(t\), define
\(w_t(S)=\max(\{u_{it}:i\in S\}\cup\{0\})\).
Thus \(v_\mu=\sum_{t\in T}\mu_t w_t\).

List the distinct positive utilities of type \(t\) in increasing order:
\(0=a_{t,0}<a_{t,1}<\cdots<a_{t,r_t}\), where \(r_t\leq m\).
For each level, put

\(\displaystyle \Delta_{t,\ell}=a_{t,\ell}-a_{t,\ell-1},\qquad A_{t,\ell}=\{i\in F:u_{it}\geq a_{t,\ell}\},\qquad n_{t,\ell}=|A_{t,\ell}|.\)

Every \(A_{t,\ell}\) is nonempty. For any nonempty \(A\subseteq F\), define the threshold coverage game
\(h_A(S)=\mathbf 1\{S\cap A\neq\varnothing\}\).

We have the exact identity

\(\displaystyle w_t(S)=\sum_{\ell=1}^{r_t}\Delta_{t,\ell}h_{A_{t,\ell}}(S).\)

Indeed, if the maximum utility in \(S\) is \(a_{t,k}\), precisely the thresholds with \(\ell\leq k\) are covered, and their increments sum to \(a_{t,k}\). If the maximum is zero, every indicator is zero. When all utilities are zero, the sum is empty and the identity still holds.

Consequently,

\(\displaystyle v_\mu=\sum_{t\in T}\sum_{\ell=1}^{r_t}\mu_t\Delta_{t,\ell}h_{A_{t,\ell}}.\)

2. Exact payoffs of a threshold game

For a game \(v\), the requested values are

\(\displaystyle \phi_i(v)=\sum_{S\subseteq F\setminus\{i\}}\frac{|S|!(m-|S|-1)!}{m!}\bigl(v(S\cup\{i\})-v(S)\bigr),\)

\(\displaystyle \beta_i(v)=2^{-(m-1)}\sum_{S\subseteq F\setminus\{i\}}\bigl(v(S\cup\{i\})-v(S)\bigr).\)

Both are linear in \(v\), directly from these finite sums.

Fix a nonempty \(A\subseteq F\), and write \(n=|A|\). If \(i\notin A\), adding \(i\) never changes \(h_A\), so both payoffs are zero.

Suppose \(i\in A\).

Shapley value. The Shapley formula equals the expected marginal contribution when facilities are ordered uniformly at random. To verify this equivalence, for a fixed predecessor set \(S\), exactly \(|S|!(m-|S|-1)!\) of the \(m!\) orders have precisely \(S\) before \(i\).

In \(h_A\), the marginal contribution is one exactly when \(i\) is first among the members of \(A\). By symmetry of the uniform order, each of the \(n\) members has probability \(1/n\) of being first. Hence
\(\phi_i(h_A)=1/n\).

Probabilistic Banzhaf value. A coalition \(S\subseteq F\setminus\{i\}\) gives marginal contribution one exactly when it excludes all \(n-1\) members of \(A\setminus\{i\}\). Its membership choices among the \(m-n\) facilities outside \(A\) are unrestricted. Therefore precisely \(2^{m-n}\) coalitions contribute, giving

\(\displaystyle \beta_i(h_A)=\frac{2^{m-n}}{2^{m-1}}=2^{-(n-1)}.\)

This uses exactly the requested Banzhaf coefficients, with no subsequent normalization.

3. Formulas and algorithm for all facilities

Applying linearity to the threshold decomposition gives

\(\displaystyle \boxed{\phi_i(v_\mu)=\sum_{t\in T}\mu_t\sum_{\ell:\,a_{t,\ell}\leq u_{it}}\frac{\Delta_{t,\ell}}{n_{t,\ell}}},\)

\(\displaystyle \boxed{\beta_i(v_\mu)=\sum_{t\in T}\mu_t\sum_{\ell:\,a_{t,\ell}\leq u_{it}}\frac{\Delta_{t,\ell}}{2^{n_{t,\ell}-1}}}.\)

Equal utilities cause no ambiguity: all facilities at the same level cover exactly the same thresholds for that type.

For each type, compute all its contributions as follows:

  • Sort the facilities by utility and group equal utilities.
  • Obtain the distinct positive levels, their increments, and the counts \(n_{t,\ell}\). Each count is the number of facilities in the current or a higher group.
  • Form prefix sums of the two sequences \(\mu_t\Delta_{t,\ell}/n_{t,\ell}\) and \(\mu_t\Delta_{t,\ell}/2^{n_{t,\ell}-1}\).
  • For every facility at level \(a_{t,k}\), add the two prefix sums through \(k\) to its running payoffs. Facilities with zero utility receive zero from this type.

Sorting costs \(O(m\log(m+1))\) comparisons per type; the subsequent scan and assignments cost \(O(m)\) arithmetic operations per type. It remains to show that these operations have polynomial bit cost.

4. Exact arithmetic and bit complexity

Interpret each binary rational as an explicitly encoded integer numerator and positive integer denominator.

Let \(D\) be the product of all input denominators, including those of both masses and utilities. The sum of their binary lengths is at most \(L\), so \(D\) has \(O(L)\) bits. Every input denominator divides \(D\). Therefore

\(\displaystyle M_t=D\mu_t,\qquad U_{it}=Du_{it},\qquad B_{t,\ell}=Da_{t,\ell}\)

are integers, computable by exact integer division and multiplication. Each has \(O(L)\) bits: every input utility is at most \(2^L\), and \(D\leq 2^L\). Sorting may therefore use the integers \(U_{it}\).

Use the common output denominators

\(\displaystyle Q_{\mathrm{Sh}}=D^2m!,\qquad Q_{\mathrm{Ba}}=D^2\,2^{m-1}.\)

For each type and threshold, its Shapley contribution is represented over \(Q_{\mathrm{Sh}}\) by the integer numerator

\(\displaystyle M_t(B_{t,\ell}-B_{t,\ell-1})\frac{m!}{n_{t,\ell}}.\)

The division is exact because \(1\leq n_{t,\ell}\leq m\), so \(n_{t,\ell}\) divides \(m!\).

Its Banzhaf contribution is represented over \(Q_{\mathrm{Ba}}\) by the integer numerator

\(\displaystyle M_t(B_{t,\ell}-B_{t,\ell-1})\,2^{m-n_{t,\ell}}.\)

Dividing these numerators by their respective denominators gives exactly the summands in Section 3. Thus every prefix sum and final accumulation can use integer addition with fixed denominators.

To bound the accumulator sizes, put \(U_{\max}=\max_{i,t}u_{it}\). For every coalition and facility,

\(\displaystyle 0\leq v_\mu(S\cup\{i\})-v_\mu(S)\leq\sum_t\mu_tu_{it}\leq U_{\max}.\)

The Shapley coefficients sum to one by their permutation interpretation, and the Banzhaf coefficients sum to one because there are \(2^{m-1}\) coalitions. Hence both payoffs lie between zero and \(U_{\max}\).

All threshold contributions are nonnegative. Therefore every prefix or running accumulator is bounded by \(Q_{\mathrm{Sh}}U_{\max}\) or \(Q_{\mathrm{Ba}}U_{\max}\), respectively. Since

\(\displaystyle \log_2(m!)\leq m\log_2(m+1),\qquad U_{\max}\leq 2^L,\)

all intermediate integers have
\(O(L+m\log(m+1))\) bits. The products used to construct individual contribution numerators satisfy the same bound.

Constructing \(D\), converting the inputs, computing \(m!\) and the powers of two, sorting, and accumulating require polynomially many operations on integers of polynomial bit length. Standard integer arithmetic therefore gives polynomial total bit complexity. Each output rational also has polynomial encoding length; reducing it by a greatest common divisor is optional and takes polynomial time.

5. Conclusion

The formulas and algorithm are valid for every input in the question, including \(m=1\), zero utilities, and arbitrary ties. They compute both complete payoff vectors exactly in polynomial time in \(m,\tau,L\).

Rational masses are handled by multiplication within each type’s contribution. No expansion into a potentially enormous unit-weight resident list is needed.
