The continuous mirror question, as graded

Given rational type masses \(\mu\) over \(\tau\) symmetric compatibility types, \(K\) coalition labels, horizon \(H\), accuracy \(\varepsilon\), confidence \(\delta\), and a finite-rate semi-bandit or bandit oracle, choose per-type room distributions \(q^r\) from shared feedback to minimize normalized population Nash regret, and output \(\hat{q}\) with population Nash gap at most \(\varepsilon\); determine regret and sample complexity as functions of \(\tau\), \(K\), \(H\), \(\varepsilon\), \(\delta\), and the encoding length of \(\mu\).

Packaged proof task (what the prover saw — nothing else)

A nonatomic society is given by its support: the list of \(\tau\geq1\) types with positive binary-rational masses \(\mu_r\), summing to \(1\); \(\tau\) is the support size, not the number of possible types. Let \(L\) be the input bit length.
There are \(K\geq1\) room labels, so the action count is \(m=K\), and \(H\geq1\) rounds; accuracy and confidence parameters satisfy \(\varepsilon,\delta\in(0,1)\). Unknown fixed distributions \(D_{rs}=D_{sr}\) on \([-1,1]\) have means \(a_{rs}=a_{sr}\); \(a_{rr}\) describes interactions between distinct individuals of type \(r\), not self-interaction.
An allocation consists of rational distributions \(q^r\in\Delta(\{1,\ldots,K\})\), with room masses \(x_{r\ell}=\mu_rq^r_\ell\) and individual payoff \(u_{r\ell}(q)=\sum_s a_{rs}x_{s\ell}\). Empty rooms are allowed. An infinitesimal individual may switch to any room label without changing these masses; an entire type is not a unilateral deviator.
Define the normalized population Nash gap \(G(q)=\max_r\bigl[\max_\ell u_{r\ell}(q)-\sum_\ell q^r_\ell u_{r\ell}(q)\bigr]\) and Nash regret \(R_H=\sum_{t=1}^H G(q_t)\).
The finite-rate oracle operates once per round: independently sample \(\ell_r\sim q^r\) for each type, and draw fresh independent samples \(X_{rs}=X_{sr}\sim D_{rs}\) for unordered type pairs, including diagonal pairs. Samples are binary rationals of at most \(B\) bits, where \(B\) is known.
Semi-bandit feedback reveals \(X_{rs}\) for each \(r,s\) with \(x_{s\ell_r}>0\); bandit feedback reveals only \(Y_r=\sum_s x_{s\ell_r}X_{rs}\) for each \(r\). All feedback and sampled labels are shared; subsequent allocations may depend on this history. One oracle call is one round, irrespective of the number of revealed components.
Is producing \(\widehat q\) with \(G(\widehat q)\leq\varepsilon\) with probability at least \(1-\delta\) polynomial-time solvable in this oracle model, or is it NP-hard? State computational dependence on \(m=K,\tau,L,B,\varepsilon^{-1},\log(1/\delta)\).
For each feedback model, what are the minimax high-probability regret over \(H\) rounds and the oracle-call complexity of obtaining such an output, as functions of the same parameters?
Discrete: for \(n\) agents, established high-probability upper bounds are \(O(\sqrt{n^3H\log(n^2H/\delta)})\) under semi-bandit feedback and \(O((n^{3/2}+1)\sqrt{n^3H\log(n^2H/\delta)})\) under bandit feedback ([finite-agent result](https://ojs.aaai.org/index.php/AAAI/article/download/33498/35653)).

Result

The problem is polynomial-time solvable exactly, without oracle calls. Under both feedback models, the minimax high-probability Nash regret is identically \(0\).

This holds throughout the stated parameter range: splitting every type equally among all labels produces a universal equilibrium.

Proof of the universal equilibrium

For every type \(r\) and label \(\ell\), set
\(q^{*,r}_\ell=1/K\).
These are rational distributions, including when \(K=1\). The resulting masses are
\(x^*_{s\ell}=\mu_s/K\).

Fix any admissible mean matrix \(A=(a_{rs})\). For every type \(r\) and every label \(\ell\),

\(u_{r\ell}(q^*)=\sum_{s=1}^{\tau}a_{rs}\mu_s/K=:c_r.\)

Thus all room labels give type \(r\) the same payoff. Consequently,

\(\max_\ell u_{r\ell}(q^*)-\sum_{\ell=1}^{K}q^{*,r}_\ell u_{r\ell}(q^*)=c_r-\sum_{\ell=1}^{K}c_r/K=0.\)

Taking the maximum over types proves \(G(q^*)=0\).

This calculation uses the stipulated nonatomic deviation rule: an individual’s switch does not change any room mass. It includes diagonal interactions exactly as defined. Indeed, symmetry of the mean matrix is unnecessary for this construction.

Computational and oracle-call complexity

The algorithm outputs \(\widehat q=q^*\). Its guarantee is deterministic:

\(\Pr\!\left(G(\widehat q)\leq\varepsilon\right)=1.\)

Under an explicit encoding listing all \(\tau K\) probabilities, each entry \(1/K\) requires \(O(\log(K+1))\) bits. Reading the input and writing the allocation therefore takes

\(O\!\left(L+\tau K\log(K+1)\right)\)

bit operations using ordinary binary fraction encoding. This is polynomial in \(m=K,\tau,L\). There is no additional dependence on \(B,\varepsilon^{-1}\), or \(\log(1/\delta)\).

The required oracle-call complexity is exactly \(0\), for both semi-bandit and bandit feedback.

Exact minimax regret

Use \(q_t=q^*\) in every round. For every admissible collection of distributions and every realization of the oracle feedback,

\(R_H=\sum_{t=1}^{H}G(q_t)=0.\)

For the matching lower bound, consider any allocation \(q\). For each type, \(\sum_\ell q^r_\ell u_{r\ell}(q)\) is a convex combination of its room payoffs, so it cannot exceed their maximum. Hence \(G(q)\geq0\), and therefore every algorithm has \(R_H\geq0\) on every trajectory.

These upper and lower bounds establish the exact minimax value:

| Feedback model | Minimax regret with probability at least \(1-\delta\) | Calls needed to produce \(\widehat q\) |
|---|---:|---:|
| Semi-bandit | \(0\) | \(0\) |
| Bandit | \(0\) | \(0\) |

If the online protocol requires one oracle invocation in each of its \(H\) rounds, that execution makes \(H\) calls. The allocation ignores their results, and producing the requested output requires none.

Why the discrete comparison does not obstruct this result

The [cited finite-agent paper](https://ojs.aaai.org/index.php/AAAI/article/download/33498/35653) studies partitions of individual agents. Here, type mass can be split equally, while unilateral individuals have zero mass. Also, the sampled labels determine feedback; the stated gap is evaluated at the population masses. These premises make the universal equilibrium above available for the entire specified model.
