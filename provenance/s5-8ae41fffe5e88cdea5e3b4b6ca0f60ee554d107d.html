The continuous mirror question, as graded

Given ℓ≥3, m, a finite supported type set T, binary affinities q:T×T→{0,1}, and rational masses μ, decide whether real assignments x_{t,v}≥0 exist for the vertices v of the ℓ×m grid, with ∑_v x_{t,v}=μ_t and ∑_t x_{t,v}=1/(ℓm), such that whenever x_{t,v}>0, U_t(v;x)≥U_t(z;x) for every grid vertex z, where U_t(v;x)=∑_{u∈N(v)}∑_{s∈T} ℓm x_{s,u}q(t,s).

Packaged proof task (what the prover saw — nothing else)

Given integers \(\ell\geq3\) and \(m\geq1\), use the undirected rectangular grid \(V=\{1,\ldots,\ell\}\times\{1,\ldots,m\}\), with orthogonal adjacency and neighbor sets \(N(v)\).
A society is given by its support: a nonempty list \(T\) of \(\tau\) types with positive binary rational masses \(\mu_t\), satisfying \(\sum_{t\in T}\mu_t=1\). Here \(\tau=|T|\) is the support size, not the number of possible types.
The input includes the full affinity matrix \(q:T\times T\to\{0,1\}\); symmetry is not required, and \(q(t,t)\) specifies affinity toward other individuals of the same type.
An assignment consists of real masses \(x_{t,v}\geq0\) with \(\sum_{v\in V}x_{t,v}=\mu_t\) for every type and \(\sum_{t\in T}x_{t,v}=1/(\ell m)\) for every vertex.
Define \(U_t(v;x)=\sum_{u\in N(v)}\sum_{s\in T}\ell m\,x_{s,u}q(t,s)\). An assignment is envy-free if \(x_{t,v}>0\) implies \(U_t(v;x)\geq U_t(z;x)\) for every \(z\in V\); equal utilities are allowed. Comparisons describe infinitesimal exchanges, so the aggregate assignment remains fixed.
Use an explicit grid encoding, and let \(L\) be the total input bit length; state running times in \(\ell,m,\tau,L\).

Is deciding whether such an envy-free assignment exists in \(\mathrm{P}\), or is it \(\mathrm{NP}\)-hard?

For indivisible agents, utility is the sum of affinities toward neighboring agents, and envy means a strict utility gain after exchanging seats with another agent. Existence of an envy-free bijection is \(\mathrm{NP}\)-complete for every fixed \(\ell\geq3\), even with binary affinities. [Source](https://www.jstage.jst.go.jp/article/ipsjjip/33/0/33_755/_pdf)
No result settling this exact continuous formulation was located in the literature search.

Modeling choices made when packaging the task

  • Normalized the positive support masses to sum to one, as required by the specified total seat capacity.
  • Allowed every positive integer width m; the discrete problem imposes no general restriction to widths used in its reduction.
  • Interpreted diagonal affinities as preferences toward other individuals of the same type, with arbitrary binary values; excluding self-preference does not exclude preferences between distinct individuals sharing a type.
  • Interpreted the stated fixed-assignment utility comparisons as infinitesimal exchanges in a nonatomic society.
  • Used an explicit grid encoding to make polynomial time refer to the represented seat graph rather than a succinctly encoded exponentially large grid; L denotes total input bit length.

Result

The decision problem is \(\mathrm{NP}\)-complete. NP-hardness holds already on the fixed grid \(\ell=3\), \(m=1\), with symmetric binary affinities, zero diagonal entries, and exactly one liked type per type.

The reduction uses an unbounded support size \(\tau\), as permitted by the question. All masses are positive rational numbers whose numerators and denominators are encoded in binary.

1. Normalization

Write \(n=\ell m\), and define
\[ y_{t,v}=n x_{t,v}, \qquad a_t=n\mu_t. \]

The feasibility constraints become
\[ \sum_v y_{t,v}=a_t, \qquad \sum_t y_{t,v}=1, \qquad y_{t,v}\geq0. \]

Utilities are
\[ U_t(v;y)=\sum_{u\in N(v)}\sum_s y_{s,u}q(t,s). \]

Thus normalization preserves both feasibility and envy-freeness.

2. Paired types on the three-vertex path

Consider the grid \(3\times1\), whose vertices form a path \(v_1,v_2,v_3\). Partition the types into pairs. Each type likes only its partner: for a pair \(p,r\),
\[ q(p,r)=q(r,p)=1, \]
and every other affinity is zero.

For each type \(t\), put
\[ c_t=y_{t,v_2}, \qquad b_t=y_{t,v_1}+y_{t,v_3}=a_t-c_t, \qquad D_t=a_t-2c_t=b_t-c_t. \]

If \(s\) is the partner of \(t\), then
\[ U_t(v_1;y)=U_t(v_3;y)=c_s, \qquad U_t(v_2;y)=b_s. \]

Consequently, envy-freeness for type \(t\) is exactly
\[ c_t>0\ \Longrightarrow\ D_s\geq0, \qquad b_t>0\ \Longrightarrow\ D_s\leq0. \tag{1} \]

Lemma

For a pair \(p,r\) with positive normalized masses \(a_p,a_r\), conditions (1) hold if and only if
\[ (D_p,D_r)\in \bigl\{(0,0),\ (a_p,-a_r),\ (-a_p,a_r)\bigr\}. \tag{2} \]

Proof. Since \(0\leq c_t\leq a_t\), we have
\[ -a_t\leq D_t\leq a_t. \]

If \(-a_t<D_t<a_t\), both \(c_t\) and \(b_t\) are positive, so (1) forces its partner’s \(D\)-value to be zero.

Suppose \(D_p\neq0\). If \(D_r\) were strictly between its bounds, applying the preceding observation to \(r\) would give \(D_p=0\), a contradiction. Thus \(D_r\) is at a bound and is nonzero. The same argument then puts \(D_p\) at a bound.

If \(D_p=a_p\), then \(b_p=a_p>0\), so (1) gives \(D_r\leq0\), hence \(D_r=-a_r\). If \(D_p=-a_p\), then \(c_p=a_p>0\), so \(D_r=a_r\).

Finally, if \(D_p=0\), it lies strictly between its bounds because \(a_p>0\); therefore \(D_r=0\). Each of the three possibilities in (2) directly satisfies (1). This proves the lemma.

Consequence for the seat capacities

The normalized masses sum to \(3\). The middle-seat capacity is equivalent to
\[ \sum_t D_t = \sum_t a_t-2\sum_t c_t = 3-2 = 1. \tag{3} \]

By the lemma, each pair contributes one of
\[ 0,\qquad a_p-a_r,\qquad -(a_p-a_r) \]
to this sum.

Conversely, suppose a choice of the three modes for every pair gives total contribution \(1\). Define
\[ c_t=\frac{a_t-D_t}{2}, \qquad y_{t,v_2}=c_t, \qquad y_{t,v_1}=y_{t,v_3}=\frac{a_t-c_t}{2}. \tag{4} \]

These quantities are nonnegative and have the required type totals. Moreover,
\[ \sum_t c_t=\frac{3-1}{2}=1, \qquad \sum_t y_{t,v_1}=\sum_t y_{t,v_3}=\frac{3-1}{2}=1. \]

The lemma guarantees envy-freeness. Therefore, for paired affinities, existence is exactly the problem of choosing those signed pair contributions to sum to \(1\).

3. Encoding SUBSET SUM by signed choices

Start with an instance of the standard NP-complete problem SUBSET SUM: positive integers \(b_1,\ldots,b_k\) and a positive integer target \(B\). The question is whether some subset sums to \(B\).

Define
\[ A=\sum_{i=1}^k b_i, \qquad K=A+B+1, \qquad g_i=K5^{i-1}, \qquad C=\sum_{i=1}^k g_i. \]

Introduce \(2k\) positive integer weights
\[ w_{i,0}=g_i, \qquad w_{i,1}=g_i+b_i, \]
and target
\[ W=C+B. \]

We claim that the original instance is positive if and only if there are choices
\[ e_{i,j}\in\{-1,0,1\} \]
such that
\[ \sum_{i=1}^k\sum_{j=0}^1 e_{i,j}w_{i,j}=W. \tag{5} \]

Forward direction. For a subset indicator \(z_i\in\{0,1\}\) satisfying \(\sum_i z_i b_i=B\), choose
\[ e_{i,1}=z_i, \qquad e_{i,0}=1-z_i. \]
Then (5) follows immediately.

Reverse direction. Rearranging (5) gives
\[ K\sum_{i=1}^k (e_{i,0}+e_{i,1}-1)5^{i-1} + \left(\sum_{i=1}^k e_{i,1}b_i-B\right) =0. \tag{6} \]

The absolute value of the parenthesized term is at most \(A+B<K\). Since the first term is an integer multiple of \(K\), equation (6) forces
\[ \sum_i e_{i,1}b_i=B, \qquad \sum_i d_i5^{i-1}=0, \]
where \(d_i=e_{i,0}+e_{i,1}-1\in\{-3,-2,-1,0,1\}\).

All \(d_i\) must be zero. Indeed, if \(h\) is the largest index with \(d_h\neq0\), then
\[ |d_h|5^{h-1}\geq5^{h-1}, \]
whereas
\[ \left|\sum_{i<h}d_i5^{i-1}\right| \leq 3\sum_{i<h}5^{i-1} = \frac{3(5^{h-1}-1)}4 < 5^{h-1}, \]
contradicting cancellation.

Thus \(e_{i,0}+e_{i,1}=1\). With both coefficients in \(\{-1,0,1\}\), the only possibilities are \((1,0)\) and \((0,1)\). Hence the indices with \(e_{i,1}=1\) form a subset summing to \(B\), proving the claim.

4. Constructing the society

Let
\[ S=\sum_{i,j}w_{i,j}=2C+A, \qquad \Delta=3W-S=C+3B-A. \]

We have \(\Delta>0\), because \(C\geq K>A\).

For each of the \(2k\) weights \(w_{i,j}\), introduce a pair of types \(t_{i,j}^{+},t_{i,j}^{-}\). Give them normalized masses
\[ a_{i,j}^{+}=\frac{w_{i,j}}W+\frac{\Delta}{4kW}, \qquad a_{i,j}^{-}=\frac{\Delta}{4kW}. \tag{7} \]

Both masses are positive, and
\[ a_{i,j}^{+}-a_{i,j}^{-}=\frac{w_{i,j}}W. \]

There are \(2k\) pairs, so the total normalized mass is
\[ \sum_{i,j}(a_{i,j}^{+}+a_{i,j}^{-}) = \frac SW+\frac{\Delta}{W} = 3. \]

Set \(\mu_t=a_t/3\). Explicitly,
\[ \mu_{i,j}^{+} = \frac{4k w_{i,j}+\Delta}{12kW}, \qquad \mu_{i,j}^{-} = \frac{\Delta}{12kW}. \]

These are valid positive rational masses summing to \(1\). Use the paired affinity matrix from Section 2 and the explicit three-vertex grid.

By the paired-type lemma and the capacity equivalence,
\[ \begin{aligned} \text{an envy-free assignment exists} &\Longleftrightarrow \exists e_{i,j}\in\{-1,0,1\}: \sum_{i,j}e_{i,j}\frac{w_{i,j}}W=1\\ &\Longleftrightarrow \exists e_{i,j}\in\{-1,0,1\}: \sum_{i,j}e_{i,j}w_{i,j}=W\\ &\Longleftrightarrow \text{the SUBSET SUM instance is positive}. \end{aligned} \]

This proves NP-hardness.

Encoding size

If the SUBSET SUM input has bit length \(H\), each \(g_i\), \(w_{i,j}\), \(W\), and mass numerator or denominator has \(O(H+k)\) bits.

The output has
\[ \ell=3,\qquad m=1,\qquad \tau=4k, \]
and includes the full \(\tau\times\tau\) affinity matrix. Its total bit length is
\[ L=O\!\left(k^2+k(H+k)\right)=O(H^2). \]

All numbers and the explicit grid can be constructed in polynomial time.

5. Membership in NP and running times

Let \(n=\ell m\) and \(d=\tau n\).

Guess sets \(S_t\subseteq V\) of permitted occupied vertices. Consider the rational linear system
\[ y_{t,v}\geq0, \qquad \sum_v y_{t,v}=a_t, \qquad \sum_t y_{t,v}=1, \]
together with
\[ y_{t,v}=0\quad(v\notin S_t), \]
and
\[ U_t(v;y)\geq U_t(z;y) \quad (t\in T,\ v\in S_t,\ z\in V). \tag{8} \]

An envy-free assignment makes this system feasible by choosing its actual supports. Conversely, every feasible solution is envy-free: any positive coordinate belongs to \(S_t\), where (8) applies. Requiring strict positivity on guessed supports is unnecessary.

This system has \(d\) variables and \(O(\tau n^2+\tau+n)\) constraints. Its feasible set is bounded, since \(0\leq y_{t,v}\leq1\).

To verify polynomial certificate size explicitly, let \(D\) be the product of the denominators of the input masses. Its bit length is \(O(L)\). At a vertex of any nonempty support polytope, \(d\) linearly independent tight constraints determine the coordinates. Their coefficient matrix has entries in \(\{-1,0,1\}\), and their right-hand sides, multiplied by \(D\), are integers of absolute value at most \(Dn\).

Cramer’s rule and the determinant bound \(d!\) therefore give rational coordinates with bit length
\[ O\!\left(L+\log n+d\log(d+1)\right). \]
Thus every yes-instance has a polynomial-size rational assignment certificate.

Given that certificate, feasibility and envy-freeness can be checked using \(O(\tau^2 n)\) rational arithmetic operations: compute all utilities, then compare occupied-seat utilities with each type’s maximum. The bit complexity is polynomial in \(n,\tau,L\). With explicit grid encoding, this is polynomial in the total input length.

Consequently, the problem belongs to \(\mathrm{NP}\). Together with the reduction, it is \(\mathrm{NP}\)-complete.

For completeness, enumerating all permitted-support sets and solving the corresponding rational linear programs gives a deterministic algorithm with running time
\[ 2^{\tau\ell m}\operatorname{poly}(\ell m,\tau,L). \]
