The continuous mirror question, as graded

Given candidates \(C\), committee size \(k\), complete-ranking types \(T\), rational masses \(\mu_t\) summing to \(1\), and a polynomial-time computable weakly separable scoring family \(\alpha_k^m\), find every \(k\)-element committee maximizing \(\sum_{t\in T}\mu_t\sum_{c\in W}\alpha_k^m(\operatorname{pos}_t(c))\).

Packaged proof task (what the prover saw — nothing else)

Definitions. Let \(C\) be a candidate set with \(m=|C|\), \(k\le m\), and let \(T\) be an explicitly listed set of strict complete rankings of \(C\). Each \(t\in T\) has a nonnegative rational mass \(\mu_t\), with \(\sum_{t\in T}\mu_t=1\).

A weakly separable scoring family provides a polynomial-time computable nonincreasing function \(\alpha_k^m:[m]\to\mathbb N\) for every \(m,k\). For each \(k\)-committee \(W\subseteq C\), let \(F(W)=\sum_{t\in T}\mu_t\sum_{c\in W}\alpha_k^m(\operatorname{pos}_t(c))\). A winning committee maximizes \(F\). Winner determination asks whether a queried \(k\)-committee is winning, with ties denoting all maximizers.

Target. Is this continuous weakly separable committee-winner problem solvable in polynomial time, or is it NP-hard?

Nearest known results. For an explicitly listed finite sequence of voters, winner determination for every polynomial-time computable weakly separable committee scoring rule is polynomial-time computable.

Prover output (gpt-6-astra / medium, Bolzano prover prompt)

Result. The problem is solvable in polynomial time for every scoring family satisfying the stated hypotheses. Rational masses can be handled directly with exact arithmetic.

Reduction to individual candidate scores.

For each candidate \(c\in C\), define
\[ s(c)=\sum_{t\in T}\mu_t\,\alpha_k^m(\operatorname{pos}_t(c)). \]
Interchanging two finite sums gives, for every committee \(W\) of size \(k\),
\[ F(W) =\sum_{t\in T}\sum_{c\in W}\mu_t\,\alpha_k^m(\operatorname{pos}_t(c)) =\sum_{c\in W}s(c). \]
Thus the objective is additive across candidates: a candidate’s contribution does not depend on which other candidates are selected.

Choose an ordering \(c_1,\ldots,c_m\) such that
\[ s(c_1)\ge s(c_2)\ge\cdots\ge s(c_m), \]
breaking ties arbitrarily, and let \(U=\{c_1,\ldots,c_k\}\).

We prove that \(U\) is winning. For any other committee \(W\) of size \(k\), the sets \(A=U\setminus W\) and \(B=W\setminus U\) have equal cardinality. Every candidate in \(A\) has score at least that of every candidate in \(B\), by the chosen ordering. Consequently, pairing their elements by any bijection gives
\[ F(U)-F(W)=\sum_{a\in A}s(a)-\sum_{b\in B}s(b)\ge 0. \]
This also covers \(A=B=\varnothing\), with empty sums interpreted as zero. Hence the queried committee \(W\) is winning exactly when
\[ \sum_{c\in W}s(c)=\sum_{i=1}^{k}s(c_i). \]
Equality accepts every maximizer, as required. For \(k=0\) or \(k=m\), there is only one committee of the required size, and it is winning.

Exact arithmetic and polynomial running time.

Write each explicitly encoded rational mass as \(\mu_t=a_t/b_t\), where \(a_t\) is a nonnegative integer and \(b_t\) is a positive integer. Set
\[ D=\prod_{t\in T}b_t,\qquad S(c)=\sum_{t\in T}a_t\frac{D}{b_t}\, \alpha_k^m(\operatorname{pos}_t(c)). \]
Every \(S(c)\) is an integer, and \(S(c)=D\,s(c)\). Since \(D>0\), sorting and testing equality using \(S\) instead of \(s\) preserves all comparisons.

Let \(L\) be the total input length. The binary length of \(D\) is at most the sum of the binary lengths of the denominators, hence is \(O(L)\). Each scoring value has polynomially bounded binary length because the scoring function is polynomial-time computable. There are only polynomially many explicitly listed candidate-ranking pairs. Therefore each summand defining \(S(c)\), each score \(S(c)\), and each committee-score sum has polynomially bounded binary length: multiplication adds operand bit lengths, while summing \(n\) nonnegative integers adds at most \(\lceil\log_2 n\rceil\) bits beyond the largest summand’s length.

Compute positions from the listed rankings, evaluate the scoring function, and compute all integer scores using standard exact integer arithmetic. All these operations take polynomial time. Sorting the scores and comparing the queried committee’s sum with the sum of the largest \(k\) scores also take polynomial time.

Thus the continuous formulation with explicitly listed rational masses admits a polynomial-time winner-determination algorithm.

Adversarial review (gpt-6-astra / low, Bolzano verifier prompt)

The prover resolves the target correctly: winner determination is polynomial-time solvable under the stated explicit rational encoding. No major or minor issues were found.

  • Candidate-score decomposition is valid. Both sums are finite, so interchanging them is justified. The identity \(F(W)=\sum_{c\in W}s(c)\) holds for every committee. Weak separability ensures that each candidate’s score is independent of the other committee members.
  • Optimality of the highest-scoring candidates is proved. For any two committees \(U,W\) of size \(k\), the difference sets \(A=U\setminus W\) and \(B=W\setminus U\) have equal cardinality. The sorted ordering ensures \(s(a)\ge s(b)\) for every \(a\in A\) and \(b\in B\). Pairing these sets therefore establishes \(F(U)\ge F(W)\). The empty-difference case is explicitly covered.
  • The decision criterion handles ties correctly. Since \(U\) attains the maximum objective value, a queried committee is winning exactly when its score equals \(F(U)\). Arbitrarily breaking ties when constructing \(U\) does not exclude other maximizers from acceptance.
  • Boundary cases are covered. For \(k=0\) and \(k=m\), the committee of the required size is unique and hence winning. These observations also cover an empty candidate set if that is admitted by the definitions.
  • The integer scaling is exact. Each denominator is positive, so \(D>0\), and each quotient \(D/b_t\) is an integer. Consequently, \(S(c)=D\,s(c)\) exactly. Scaling by this common positive factor preserves ordering and equality. Zero masses cause no difficulty, and fractions need not be reduced.
  • The bit-complexity bounds are sufficient. The product of denominators has binary length at most the sum of their binary lengths, which is bounded by the input length. Polynomial-time computability of the scoring function bounds the binary length of its outputs. Explicitly listed rankings supply only polynomially many candidate-ranking pairs. Products, candidate-score sums, and committee-score sums therefore have polynomially bounded binary lengths. The stated bound on bit growth when summing nonnegative integers is correct for nonempty sums; empty sums are zero.
  • The complete algorithm runs in polynomial time. Computing positions, evaluating scores, forming the common denominator, performing exact divisions and integer arithmetic, sorting, and comparing committee totals all require polynomially many operations on integers of polynomially bounded length. No expansion into a potentially enormous unweighted voter sequence is required.
