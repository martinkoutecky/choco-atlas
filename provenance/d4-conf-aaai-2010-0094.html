The continuous mirror question, as graded

Given \(m\) candidates, a committee size \(k\), and a finite support \(\mathcal S\) of approval sets with positive rational masses \(\mu_S\) summing to \(1\), return a committee \(K\) with \(|K|=k\) such that \(D_\mu(K) \le 2\operatorname{OPT}_\mu\), where \(D_\mu(K)=\max_{S\in\mathcal S} d_H(K,S)\) and \(\operatorname{OPT}_\mu=\min_{|K'|=k}D_\mu(K')\).

Packaged proof task (what the prover saw — nothing else)

Let \(A\) be a set of \(m\geq1\) candidates and let \(k\in\{1,\ldots,m\}\). Approval types are arbitrary subsets of \(A\), including the empty set.
A society is given by its support: a nonempty list \(\mathcal S\) of \(\tau\) distinct approval types with positive binary rational masses \(\mu_S\) satisfying \(\sum_{S\in\mathcal S}\mu_S=1\). Here \(\tau\) is the support size, not the number of possible approval types; \(L\) is the total input bit length.
For an integral committee \(K\subseteq A\) with \(|K|=k\), define \(D_\mu(K)=\max_{S\in\mathcal S}d_H(K,S)\) and \(\operatorname{OPT}_\mu=\min_{K'\subseteq A:\,|K'|=k}D_\mu(K')\), using Hamming distance. Any committee satisfying the guarantee is acceptable.

Does a deterministic algorithm running in time polynomial in \(m,\tau,k,L\) always return a committee \(K\) with \(|K|=k\) and \(D_\mu(K)\leq2\operatorname{OPT}_\mu\)?

Caragiannis, Kalaitzis, and Markakis established a deterministic polynomial-time \(2\)-approximation for discrete minimax approval voting ([primary source](https://ojs.aaai.org/index.php/AAAI/article/download/7615/7476)).
The stated support objective is exactly that discrete objective on the listed types, so its \(2\)-approximation question is already settled affirmatively; this is not an open target.

Conclusion

Yes. The support formulation admits a deterministic polynomial-time \(2\)-approximation. The rational masses do not enter the objective, so no expansion according to their denominators is needed.

Known theorem and its hypotheses

Caragiannis, Kalaitzis, and Markakis prove that discrete minimax approval voting admits a deterministic polynomial-time algorithm returning a size-\(k\) committee whose maximum Hamming distance is at most twice optimum. Approval sets may be empty. Their algorithm solves a linear-programming relaxation and selects the \(k\) candidates with largest fractional coordinates. See [Theorem 3 of the primary source](https://ojs.aaai.org/index.php/AAAI/article/download/7615/7476).

The paper assumes that the number of voters exceeds \(k\). We ensure this without changing the objective by duplicating an existing approval type.

Reduction and proof of the guarantee

Write the nonempty support as \(\mathcal S=(S_1,\ldots,S_\tau)\). Construct a discrete profile \(P\) containing one voter with approval set \(S_i\) for each \(i\). If \(\tau\leq k\), append \(k+1-\tau\) additional voters, all approving \(S_1\). Thus the profile has
\[ n=\max\{\tau,k+1\}>k \]
voters. Every approval set is a subset of the same candidate set \(A\), and the committee size satisfies \(1\leq k\leq m\), as required.

For every size-\(k\) committee \(K\), duplication leaves the maximum unchanged:
\[ \max_{1\leq i\leq n}d_H(K,P_i) =\max_{S\in\mathcal S}d_H(K,S) =D_\mu(K). \]
Indeed, every support type appears in \(P\), and every appended approval set already appears among the support types. Taking minima over the identical family of feasible committees gives
\[ \operatorname{OPT}(P)=\operatorname{OPT}_\mu. \]

Apply the cited deterministic algorithm to \(P\). Its output \(K\) therefore satisfies
\[ |K|=k,\qquad D_\mu(K) =\max_i d_H(K,P_i) \leq 2\operatorname{OPT}(P) =2\operatorname{OPT}_\mu. \]
This is an absolute inequality, so it also covers \(\operatorname{OPT}_\mu=0\).

Running time

The constructed profile contains at most \(\tau+k+1\) ballots, each representable by \(m\) bits. Its encoding length is consequently polynomial in \(m,\tau,k\). Reading the original input takes time polynomial in \(L\); constructing the profile and applying the cited polynomial-time algorithm takes time polynomial in \(m,\tau,k,L\).

Thus the required algorithm exists for every valid input, independently of the sizes of the mass denominators.
