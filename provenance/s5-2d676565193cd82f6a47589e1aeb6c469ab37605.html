The continuous mirror question, as graded

Given a finite set of complete agent types \(\mathcal{T}\), a rational population mass vector \(\mu\in\mathbb{Q}_{\ge 0}^{\mathcal{T}}\) with \(\sum_{t\in\mathcal{T}}\mu_t=1\), and an explicit finite catalogue \(\mathcal{Q}\subseteq\mathbb{Z}_{\ge 0}^{\mathcal{T}}\setminus\{0\}\) of feasible integral team compositions with rational values \(w_q\), compute an optimal \(y\in\mathbb{R}_{\ge 0}^{\mathcal{Q}}\) maximizing \(\sum_{q\in\mathcal{Q}}w_qy_q\), subject to \(\sum_{q\in\mathcal{Q}}q_ty_q=\mu_t\) for each \(t\in\mathcal{T}\). Here \(y_q\) is the number of recipe-\(q\) teams per unit of population.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a list \(\mathcal T\) of \(\tau\ge 1\) complete types with positive binary rational masses \(\mu_t\), summing to \(1\). Here \(\tau\) is the support size, not the number of possible types; members of a type are interchangeable for team values.
An explicit catalogue \(\mathcal Q\subseteq\mathbb Z_{\ge0}^{\mathcal T}\setminus\{0\}\) contains \(m=|\mathcal Q|\) permitted team recipes, with binary rational values \(w_q\ge0\); it contains every singleton recipe \(e_t\). Recipe coordinates are binary encoded. Values depend only on the recipe, and teams have no externalities.
A mass allocation is \(y\in\mathbb R_{\ge0}^{\mathcal Q}\), where \(y_q\) is the number of recipe-\(q\) teams per unit population. It must satisfy \(\sum_{q\in\mathcal Q}q_ty_q=\mu_t\) for every \(t\in\mathcal T\), and its value is \(\sum_{q\in\mathcal Q}w_qy_q\). Compute an allocation of maximum value. Let \(L\) be the total input bit length; state running times in \(m,\tau,L\).

Is this continuous optimization problem solvable in polynomial time in \(m,\tau,L\), or is it NP-hard? If NP-hard, is it FPT parameterized by \(\tau\)?

For finite populations with a complete table of coalition values by type composition, optimal coalition structure generation has an \(O(n^{2\tau})\) algorithm, polynomial in the number \(n\) of agents for fixed \(\tau\) ([Ueda et al.](https://www.ijcai.org/Proceedings/11/Papers/074.pdf)).
Discrete coalition structure generation with an SCG representation is NP-hard, a different input representation ([Ohta et al.](https://link.springer.com/article/10.1007/s10458-018-9386-z)). No result addressing exactly the mass-and-catalogue formulation was located.

Modeling choices made when packaging the task

  • Removed zero-mass types so that the type list is exactly the positive-mass support.
  • Restricted recipe values to nonnegative binary rationals, following the discrete model's nonnegative coalition values.
  • Required every singleton recipe, preserving the discrete model's availability of singleton coalitions and exhaustive population assignment.
  • Defined m as the catalogue size and L as total input bit length, including binary recipe coordinates.
  • Retained the graded question's explicit catalogue of permitted recipes rather than requiring the anchor's complete table of all compositions.

Conclusion. The stated mass-and-catalogue problem is solvable exactly in polynomial time in \(m,\tau,L\). Consequently, it is also FPT parameterized by \(\tau\). This holds for arbitrary support size and binary-encoded recipe coordinates.

1. Exact linear programming formulation. Enumerate the catalogue as \(\mathcal Q=\{q^1,\ldots,q^m\}\). Define \(A\in\mathbb Z_{\geq0}^{\tau\times m}\) by \(A_{tj}=q^j_t\), and let \(w_j=w_{q^j}\). The required optimization problem is precisely

\[ \max\{w^\top y:Ay=\mu,\ y\geq0\}. \]

Indeed, its variables are exactly the permitted team masses, its equations are exactly the type-mass balances, and its objective is the specified allocation value. There are \(m\) variables and \(\tau\) equality constraints. Every coefficient is explicitly supplied in the input.

2. Feasibility and existence of an optimum. Because every singleton recipe \(e_t\) belongs to the catalogue, assigning \(y_{e_t}=\mu_t\) and assigning zero to every other recipe gives a feasible allocation.

For each recipe, put \(s_q=\sum_{t\in\mathcal T}q_t\). The assumptions that \(q\) is nonzero and has nonnegative integer coordinates imply \(s_q\geq1\). Summing all balance equations therefore gives

\[ 1=\sum_{t\in\mathcal T}\mu_t =\sum_{q\in\mathcal Q}s_qy_q \geq\sum_{q\in\mathcal Q}y_q. \]

Thus every feasible coordinate lies in \([0,1]\). The feasible set is closed, bounded, and nonempty, hence compact. Its linear objective is continuous, so a finite maximum is attained.

3. Exact computation and bit complexity. We use the standard rational linear programming theorem: an explicitly encoded linear program with rational coefficients can be solved in polynomially many bit operations, producing an exact rational optimal solution whenever its optimum exists and is finite. This is an exact theorem, rather than merely an approximation guarantee; see the discussion of exact polynomial-time algorithms in [Gleixner and Steffy, Section 1.3](https://optimization-online.org/wp-content/uploads/2019/12/7507.pdf).

All hypotheses hold here: the coefficients are rational, the entire program is explicit, and feasibility and finite attainment were proved above. Replacing each equality by two inequalities produces \(m+2\tau\) inequalities, including nonnegativity. A dense encoding has length \(O(L+m\tau)\). Consequently, constructing and solving the program takes

\[ (L+m\tau)^{O(1)}=(m+\tau+L)^{O(1)} \]

bit operations. Since the input explicitly lists its types and recipes, \(m+\tau=O(L)\), so this is also \(L^{O(1)}\). The polynomial exponent is independent of \(\tau\).

For completeness, an optimal allocation has a polynomial-length rational encoding even though allocations were allowed to be real. We prove a stronger structural statement: some optimum uses at most \(\tau\) recipes.

Choose an optimum \(y^*\) having the smallest number of positive coordinates, and write \(S=\{j:y^*_j>0\}\). Suppose the columns indexed by \(S\) were linearly dependent. Then there would be a nonzero vector \(z\), supported on \(S\), satisfying \(Az=0\). For sufficiently small \(\varepsilon>0\), both \(y^*+\varepsilon z\) and \(y^*-\varepsilon z\) would remain nonnegative and satisfy the balance equations. Optimality in both directions forces \(w^\top z=0\).

Change the sign of \(z\), if necessary, so that it has a positive coordinate, and set

\[ \alpha=\min_{j:z_j>0}\frac{y^*_j}{z_j}. \]

Then \(y^*-\alpha z\) is feasible and has the same objective value. It has no positive coordinates outside \(S\), and at least one formerly positive coordinate becomes zero. This contradicts the choice of \(y^*\). Hence its positive-support columns are independent, and \(|S|\leq\tau\).

The singleton columns give \(A\) rank \(\tau\), so these independent columns extend to a nonsingular \(\tau\times\tau\) matrix \(B\) of catalogue columns. The corresponding coordinates \(x\), with zeros on the added columns, satisfy \(Bx=\mu\).

Write \(\mu_t=a_t/b_t\), with positive integer denominators, and set \(D=\prod_t b_t\). Then \(D\mu\) is integral, and Cramer’s rule gives

\[ x_i=\frac{\det(B_i)}{D\det(B)}, \]

where \(B_i\) replaces column \(i\) of \(B\) by \(D\mu\).

Let \(H\geq1\) bound the bit length of every recipe coordinate. The determinant expansion, together with \(0<\mu_t\leq1\), yields

\[ |\det(B)|\leq\tau!\,2^{\tau H}, \qquad |\det(B_i)|\leq\tau!\,D\,2^{(\tau-1)H}. \]

Since \(\log_2 D=O(L)\) and \(H\leq L\), each numerator and denominator needs only \(O(L+\tau H+\tau\log(\tau+1))\) bits. Thus exact output size poses no obstruction.

4. Parameterization and the discrete results. An FPT running time has the form \(f(\tau)L^c\), with constant \(c\) independent of \(\tau\). The polynomial algorithm above already satisfies this with \(f(\tau)=1\).

The finite-population results concern additional discreteness. For a population of size \(N\), if \(z_q\) denotes its integer number of recipe-\(q\) teams, the normalized allocation satisfies \(y_q=z_q/N\); hence it obeys the additional restriction \(Ny_q\in\mathbb Z_{\geq0}\). That restriction is absent here. Likewise, Ohta et al.’s SCG formulation explicitly uses binary coalition-selection variables; its hardness theorem concerns that discrete formulation. See [Ohta et al., Theorem 7 and Definition 15](https://link.springer.com/article/10.1007/s10458-018-9386-z).

In particular, comparing the computed optimum against any rational threshold is polynomial-time solvable. NP-hardness of this formulation under standard polynomial-time reductions would therefore imply \(\mathrm P=\mathrm{NP}\).
