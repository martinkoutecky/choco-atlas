The anchor (named result in the paper)

Theorem 6.3 — class: algorithmic

The continuous mirror question, as graded

Given finitely many types \(t\in\mathcal T\), masses \(\mu_t\), rate parameters \(a_t\) with \(q_t=\mu_ta_t\) and \(\sum_t q_t=1\), and value laws \(F_t\), find a succinct allocation kernel \(P_t(k)\) for nonzero count vectors \(k\in\mathbb N^{|\mathcal T|}\). Require \(P_t(k)\ge 0\), \(P_t(k)=0\) when \(k_t=0\), and \(\sum_{t:k_t>0}P_t(k)=1\). For each type with \(q_t>0\), if the other bidders’ counts are independent \(K_s\sim\operatorname{Poisson}(q_s)\), require \(\mathbb E[P_t(K+e_t)/(K_t+1)]=1-e^{-1}\); when exactly two bidders of different types are present, require each type to receive probability at most \(1/2\), with same-type bidders split uniformly. Can an oracle returning \(P(k)\) to additive error \(\varepsilon\) be computed in time polynomial in \(|\mathcal T|\), input bit length \(L\), and \(1/\varepsilon\)?

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: the list of the \(\tau\) types with positive mass, each mass a binary rational; \(\tau\) is the support size, not the number of possible types. Normalize \(\sum_t\mu_t=1\). There is \(m=1\) indivisible item.
Each type has a nonnegative binary-rational rate \(a_t\); write \(q_t=\mu_ta_t\) and require \(\sum_tq_t=1\). Value laws may be any bounded nonnegative laws and do not enter the allocation constraints or computational input. Let \(L\) be the bit length of the society and rates.
An allocation kernel assigns probabilities \(P_t(k)\) to every \(k\in\mathbb Z_{\geq0}^{\tau}\setminus\{0\}\), with \(P_t(k)\geq0\), \(P_t(k)=0\) if \(k_t=0\), and \(\sum_tP_t(k)=1\). Conditional on selecting type \(t\), choose uniformly among its \(k_t\) bidders.
For every \(t\) with \(q_t>0\), require exactly \(\mathbb E[P_t(K+e_t)/(K_t+1)]=1-e^{-1}\), where all \(K_s\sim\operatorname{Poisson}(q_s)\) are independent and \(e_t\) is the unit vector of type \(t\).
For distinct types \(s,t\), require \(P_s(e_s+e_t)\leq1/2\) and \(P_t(e_s+e_t)\leq1/2\). No allocation occurs at the zero count vector.
A succinct kernel is a finite description with an evaluation procedure returning rational approximations to its coordinates for any binary-encoded query \(k\) and rational accuracy \(0<\varepsilon<1\); all queries refer to the same exact kernel. Let \(B\) be the query bit length, including the accuracy.

Is constructing such a kernel polynomial-time solvable, with construction time and description size polynomial in \(m,\tau,L\), and evaluation time polynomial in \(m,\tau,L,B,1/\varepsilon\) for coordinatewise additive error \(\varepsilon\), or is this construction problem NP-hard?

For finite agents with positive shares \(\alpha_i\) summing to one, randomized allocation computation achieves interim error \(O(\sqrt{\log n/K})\), preserves doubleton bounds \(p_j^{\{i,j\}}\leq(1+\alpha_i)/2\), and runs in time polynomial in \(K,n,1/\min_i\alpha_i\); this yields approximate equilibrium and robustness guarantees. [Lin et al.](https://arxiv.org/html/2505.11431v2)
No result settling this exact Poisson-kernel construction problem was located in the literature search.

Modeling choices made when packaging the task

  • Normalized the positive rational society masses to sum to one.
  • Specified nonnegative binary-rational rates; these are Poisson intensity rates and need not be bounded by one.
  • Specified nonnegative integer counts, binary query encoding, rational accuracy, and dependence on query bit length.
  • Defined succinctness through a finite description and evaluation procedure for one exact kernel; evaluation error does not relax the interim equalities.
  • Applied uniform splitting among bidders of the same type at every count vector and specified no allocation when there are no bidders.
  • Retained arbitrary bounded nonnegative value laws as ancillary data requiring no computational access, since the stated kernel constraints do not involve them.
  • Set the item parameter to one and interpreted the requested polynomial-time construction deterministically.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Result

The construction is polynomial-time solvable. Uniform allocation among all present bidders satisfies every stated constraint for arbitrary support size and admissible rates; this is not restricted to a degenerate case.

Construction and pointwise constraints

For a nonzero count vector \(k\), define its total count by \(n(k)=\sum_{s=1}^{\tau}k_s\), and set

\( \displaystyle P_t(k)=\frac{k_t}{n(k)}. \)

At the zero vector, allocate nothing.

Since \(n(k)>0\) on the kernel’s domain, every coordinate is nonnegative, \(P_t(k)=0\) whenever \(k_t=0\), and

\( \displaystyle \sum_{t=1}^{\tau}P_t(k)=\frac{\sum_{t=1}^{\tau}k_t}{n(k)}=1. \)

Conditional on selecting a type with \(k_t>0\), uniform selection among its bidders gives each such bidder probability \(P_t(k)/k_t=1/n(k)\). Thus this kernel implements uniform allocation among all present bidders.

For distinct types \(s,t\), the vector \(e_s+e_t\) has total count two, so

\( \displaystyle P_s(e_s+e_t)=P_t(e_s+e_t)=\frac12. \)

Both doubleton bounds therefore hold with equality.

Exact interim equalities

Let \(N=\sum_{s=1}^{\tau}K_s\). Independence and the Poisson probability generating function give, for \(0\leq z\leq1\),

\( \displaystyle \mathbb E[z^N]=\prod_{s=1}^{\tau}\exp(q_s(z-1))=\exp\!\left((z-1)\sum_{s=1}^{\tau}q_s\right)=\exp(z-1). \)

This is the probability generating function of a Poisson random variable with mean one. Hence \(N\sim\operatorname{Poisson}(1)\). The calculation also accommodates zero rates, since a Poisson variable with mean zero is identically zero.

For every type \(t\), the vector \(K+e_t\) is nonzero and has total count \(N+1\). Consequently, pointwise,

\( \displaystyle \frac{P_t(K+e_t)}{K_t+1}=\frac{(K_t+1)/(N+1)}{K_t+1}=\frac1{N+1}. \)

Taking expectations and using the Poisson mass function,

\( \displaystyle \mathbb E\!\left[\frac{P_t(K+e_t)}{K_t+1}\right]=e^{-1}\sum_{r=0}^{\infty}\frac{1}{(r+1)r!}=e^{-1}\sum_{j=1}^{\infty}\frac1{j!}=e^{-1}(e-1)=1-e^{-1}. \)

The series converges by the exponential series. This proves the required exact equality for every type with \(q_t>0\), and indeed for every type.

Succinctness and computational complexity

The description consists of the support indexing, the integer \(\tau\), and the fixed procedure: sum the counts and return \(k_t/n(k)\). Its construction time and description size are polynomial in \(\tau,L\), and hence in \(m,\tau,L\) with \(m=1\).

For a binary-encoded query of bit length \(B\), the total count has bit length at most the maximum coordinate bit length plus \(\lceil\log_2\tau\rceil+1\). Binary addition therefore computes it in time polynomial in \(\tau,B\). Return \(k_t/n(k)\) as an exact rational; if reduced fractions are required, the Euclidean algorithm also runs in polynomial time.

The returned rational has additive error zero for every requested accuracy \(0<\varepsilon<1\). Evaluation is thus polynomial in \(m,\tau,L,B,1/\varepsilon\), with no dependence on the smallest positive mass or rate. All queries evaluate the same explicitly defined kernel.

Although the required expectation is irrational, no irrational number needs to be encoded: the kernel’s coordinates are rational, and the exact expectation follows from the calculation above.

Step-by-step verification

  • Pointwise allocation constraints. Nonnegativity follows from \(k_t\geq0\), absence of type \(t\) implies \(P_t(k)=0\), and summing the coordinates gives exactly one. Conditional uniform selection within the selected type gives each present bidder probability \(1/n(k)\). The division by \(k_t\) is used only when \(k_t>0\).
  • Doubleton constraints. For distinct \(s,t\), the vector \(e_s+e_t\) has total count two, with both relevant coordinates equal to one. Consequently, both required probabilities equal \(1/2\). When \(\tau=1\), these constraints are vacuous.
  • Distribution of the total count. The probability generating function computation is correct. Its hypotheses hold: the number of types is finite, the \(K_s\) are independent Poisson variables with nonnegative parameters, and \(\sum_s q_s=1\). Their generating functions therefore multiply to \(\exp(z-1)\), identifying \(N\) as \(\operatorname{Poisson}(1)\). Zero parameters cause no exception.
  • Pointwise interim identity. For every realization of \(K\), the vector \(K+e_t\) has total count \(N+1\), and its type-\(t\) count is \(K_t+1>0\). Hence

\[ \frac{P_t(K+e_t)}{K_t+1}=\frac{1}{N+1}. \]
This identity holds for every type, including types with zero rate.

  • Exact expectation. Using the Poisson mass function gives

\[ \mathbb E\!\left[\frac{1}{N+1}\right] =e^{-1}\sum_{r=0}^{\infty}\frac{1}{(r+1)r!} =e^{-1}\sum_{j=1}^{\infty}\frac{1}{j!} =1-e^{-1}. \]
The factorial identity, index shift, convergence, and final evaluation are all correct. No approximation enters the required equalities.

  • Construction and description size. A fixed evaluation procedure together with the support indexing and \(\tau\) provides a finite description of polynomial size. Producing it takes polynomial time in \(\tau,L\). The kernel does not need to encode the rates or value laws, because its correctness holds for every admissible rate vector.
  • Evaluation complexity and consistency. The stated bound on the total count’s bit length is valid. Binary addition and rational output take polynomial time in \(\tau,B\); optional fraction reduction also takes polynomial time. Returning the exact rational meets every requested additive accuracy with zero error. This stronger bound implies the requested polynomial bound in \(m,\tau,L,B,1/\varepsilon\). Every query uses the same fixed formula.
  • Irrational expectation. There is no representation conflict: rational kernel coordinates can have an irrational expectation under the specified Poisson law. The expectation is proved analytically and need not be stored in the description.

The finite-agent approximation result is not used, and no inference from it is needed. No additional clarification or repair is required.
