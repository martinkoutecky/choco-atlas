The continuous mirror question, as graded

Given rational type masses \(\mu_t\), a symmetric rational interaction matrix \(W\), and a per-capita imputation \(x_t\), where \(v(q)=\frac12\sum_{t,u}W_{tu}q_tq_u\) and \(\sum_t\mu_tx_t=v(\mu)\), decide whether the imputation belongs to the type-mass bargaining set. An objection by type \(a\) against type \(b\) chooses \(q\in[0,\mu]\) with \(q_a>0\) and \(q_b<\mu_b\), and per-capita rates \(y_t>x_t\) for included mass, summing to \(v(q)\). A counterobjection chooses \(r\) with \(r_b>0\) and \(r_a<\mu_a\), specifies feasible overlap masses \(h_t\), and allocates exactly \(v(r)\) while meeting the original objection’s lower bounds on overlap and the imputation’s lower bounds outside it. The decision is whether every such objection has a feasible counterobjection; complexity is measured in \(\tau\) and the binary input length \(L\).

Packaged proof task (what the prover saw — nothing else)

A society is atomless and given by its support: \(\tau\) types with positive binary rational masses \(\mu_t\), normalized by \(\sum_t\mu_t=1\); \(\tau\) is the support size, not the number of possible types. Input also includes a symmetric matrix \(W\in\mathbb Q^{\tau\times\tau}\) with unrestricted signs and diagonal, and rational per-capita payoffs \(x_t\geq0\). Let \(L\) be the total binary input length; running times are measured in \(\tau,L\), with no separate candidate parameter \(m\).
For every real coalition mass vector \(q\in\prod_t[0,\mu_t]\), define \(v(q)=\frac12\sum_{t,u}W_{tu}q_tq_u\). The input imputation satisfies \(\sum_t\mu_tx_t=v(\mu)\); individual agents have zero singleton worth.
For distinct types \(a,b\), an objection consists of real masses \(q\) with \(q_a>0\), \(q_b<\mu_b\), and real rates \(y_t\) satisfying \(y_t>x_t\) whenever \(q_t>0\) and \(\sum_tq_ty_t=v(q)\).
A counterobjection consists of real masses \(r\in\prod_t[0,\mu_t]\) with \(r_b>0\), \(r_a<\mu_a\), and overlap masses satisfying \(\max\{0,q_t+r_t-\mu_t\}\leq h_t\leq\min\{q_t,r_t\}\) for every type.
It assigns real rates \(z_t^{\mathrm{in}}\) on overlap and \(z_t^{\mathrm{out}}\) outside the objection, satisfying \(z_t^{\mathrm{in}}\geq y_t\) when \(h_t>0\), \(z_t^{\mathrm{out}}\geq x_t\) when \(r_t-h_t>0\), and \(\sum_t[h_tz_t^{\mathrm{in}}+(r_t-h_t)z_t^{\mathrm{out}}]=v(r)\). Rates on zero-mass pieces are irrelevant.
The type-mass bargaining set consists of imputations for which every objection has a counterobjection.

Is membership in this type-mass bargaining set solvable in polynomial time in \(\tau,L\), or is it NP-hard?

For finite graph games with signed edge weights, bargaining-set membership is \(\Pi_2^P\)-hard and, together with the matching upper bound, \(\Pi_2^P\)-complete. [Verified full version](https://arxiv.org/pdf/0810.3136).
No result settling membership for the exact type-mass model defined here was located in the literature search.

Modeling choices made when packaging the task

  • Normalized the positive masses to sum to one, interpreting the society as a distribution over types.
  • Restored individual rationality: the rational input payoffs are nonnegative because an individual in the atomless quadratic model has zero singleton worth.
  • Required the objecting and challenged types to be distinct, as the discrete definition requires distinct players.
  • Allowed arbitrary signed rational matrix entries and retained unrestricted diagonal entries; within-type interactions need not vanish in a mass model.
  • Allowed coalition masses, overlap masses, and proposed payoff rates to be real, rather than restricting witnesses to rational values.
  • Specified overlap feasibility by the intersection bounds within each type's total mass.
  • Allowed separate counterobjection rates on overlap and outside it, carrying over the discrete definition's separate lower bounds and exact budget equality.
  • Defined L as the total binary input length; this problem has no separate candidate parameter m.

Result

Membership in the stated type-mass bargaining set is \(\mathrm{NP}\)-hard under polynomial-time many-one reductions. This holds even when all masses are equal dyadic rationals, all payoffs are strictly positive, and every diagonal entry of \(W\) is positive.

The proof below accounts for arbitrary real objection rates and arbitrary real countercoalition masses.

1. Eliminating counterobjection rates

Fix an objection \((q,y)\) by type \(a\) against type \(b\). Define \(d_t=y_t-x_t>0\) when \(q_t>0\), and set \(d_t=0\) otherwise. For any prospective countercoalition \(r\), define

\[ F_{q,y}(r)=v(r)-\sum_t x_t r_t-\sum_t d_t\max\{0,q_t+r_t-\mu_t\}. \]

Here and below, the displayed formulas use the same mathematical notation as the inline formulas.

Counterobjection criterion. An admissible mass vector \(r\), meaning \(r_b>0\) and \(r_a<\mu_a\), supports a counterobjection if and only if \(F_{q,y}(r)\geq0\).

Indeed, for any allowed overlap \(h\), the minimum required payment is

\[ \sum_t\bigl[h_ty_t+(r_t-h_t)x_t\bigr] =\sum_t x_tr_t+\sum_t d_th_t. \]

Because every relevant \(d_t\) is positive, this payment is minimized by choosing \(h_t=\max\{0,q_t+r_t-\mu_t\}\). Thus \(F_{q,y}(r)\geq0\) is necessary. It is sufficient because the minimum rates can be assigned first, and any remaining surplus can be added to a positive-mass piece. Such a piece exists because \(r_b>0\).

We will use two consequences.

Positive surplus anywhere suffices. If \(F_{q,y}(r^0)>0\) at any point of the mass box, the objection has a counterobjection. To see this, choose \(s\) in the box with \(s_a=0\) and \(s_b=\mu_b\), and put \(r^\varepsilon=(1-\varepsilon)r^0+\varepsilon s\). For every \(0<\varepsilon<1\), this vector satisfies the countercoalition restrictions. Continuity gives \(F_{q,y}(r^\varepsilon)>0\) for sufficiently small \(\varepsilon\).

Every fractional objection has a counterobjection. The objection budget gives \(v(q)-\sum_t x_tq_t=\sum_t d_tq_t\). Consequently,

\[ F_{q,y}(q) =\sum_t d_t\bigl[q_t-\max\{0,2q_t-\mu_t\}\bigr] =\sum_t d_t\min\{q_t,\mu_t-q_t\}. \]

If \(0<q_t<\mu_t\) for any type, its summand is strictly positive, and all other summands are nonnegative. The preceding consequence therefore applies.

Thus every objection without a counterobjection must use either zero or the entire mass of each type.

2. Constructing the reduction

We reduce from Independent Set: given a simple undirected graph \(G\) with \(n\geq1\) vertices and an integer \(1\leq k\leq n\), decide whether \(G\) has an independent set of size at least \(k\). This is the standard \(\mathrm{NP}\)-complete problem, equivalently Clique on the complement graph; see [Karp’s theorem](https://doi.org/10.1007/978-1-4684-2001-2_9).

To make the masses dyadic, first add isolated vertices until \(n+2\) is a power of two, increasing \(k\) by the number added. This preserves the answer because each added vertex increases the independence number by one. It increases the graph size by only a constant factor. Rename the resulting parameters \(n,k\).

Introduce one type for each graph vertex, together with two additional types \(\alpha,\beta\). Set

\[ N=n+2,\qquad \mu_t=\frac1N,\qquad M=n+1,\qquad A=k+M|E(G)|+1. \]

Define a symmetric integer matrix \(H\) by the following entries; unspecified off-diagonal entries are zero:

  • \(H_{tt}=2(A+1)\) for every type.
  • \(H_{\alpha\beta}=-M\).
  • \(H_{\beta i}=1\) for every graph-vertex type \(i\).
  • \(H_{ij}=-M\) for every graph edge \(\{i,j\}\).

Set \(W=N^2H\), and choose per-capita payoffs

\[ x_\alpha=N,\qquad x_\beta=N(A+1+k),\qquad x_i=N(A+1). \]

All payoffs are strictly positive.

For normalized masses \(u_t=Nq_t\), the worth is

\[ v(q)=(A+1)\sum_tu_t^2-Mu_\alpha u_\beta +u_\beta\sum_i u_i-M\sum_{\{i,j\}\in E(G)}u_i u_j. \]

The proposed imputation is efficient. At the grand coalition,

\[ v(\mu)=N(A+1)-M+n-M|E(G)|. \]

On the other hand,

\[ \sum_t\mu_tx_t=N(A+1)-A+k. \]

These are equal because \(A-k=M|E(G)|+1\) and \(M=n+1\).

For a coalition consisting of entire types, let \(U\) denote its graph-vertex types and let \(e(U)\) be the number of graph edges induced by \(U\). Its excess over the imputation is

\[ A\mathbf1_{\{\alpha\in S\}}-k\mathbf1_{\{\beta\in S\}} +\mathbf1_{\{\beta\in S\}}|U|-Me(U) -M\mathbf1_{\{\alpha,\beta\in S\}}. \]

3. Reducing all objections to one

By Section 1, every fractional objection already has a counterobjection. Consider an objection consisting of entire types, with support \(S\). Its target type is outside \(S\).

Targets other than \(\beta\)

If the target is a graph-vertex type \(i\), use all agents of that type as the countercoalition. Its worth and imputation payment are both \(A+1\).

If the target is \(\alpha\), use all agents of type \(\alpha\). Its worth is \(A+1\), whereas its imputation payment is \(1\).

In either case, this countercoalition has zero overlap with the objection, includes the target, and excludes the objecting type. Its surplus is nonnegative, so the counterobjection criterion applies.

Target \(\beta\)

Now \(\beta\notin S\), so the objection’s excess is

\[ A\mathbf1_{\{\alpha\in S\}}-Me(U). \]

An objection requires strictly positive excess. Hence \(\alpha\in S\).

Suppose \(U\neq\varnothing\). Define the positive total payment increments \(\delta_t=\mu_t(y_t-x_t)\) for \(t\in S\). The objection budget implies

\[ \delta_\alpha+\sum_{i\in U}\delta_i=A-Me(U). \]

Because \(U\neq\varnothing\) and each \(\delta_i>0\), we have \(\delta_\alpha<A\). At the mass vector consisting only of all agents of type \(\alpha\),

\[ F_{q,y}(\mu_\alpha e_\alpha) =(A+1)-(1+\delta_\alpha)=A-\delta_\alpha>0. \]

Positive surplus anywhere suffices, so this objection also has a counterobjection, regardless of which type in \(S\) objects.

The sole remaining possibility is therefore the objection by \(\alpha\) against \(\beta\) consisting of all agents of type \(\alpha\). Its budget uniquely determines

\[ q_\alpha=\frac1N,\qquad q_t=0\ (t\neq\alpha),\qquad y_\alpha=N(A+1). \]

It is a valid objection because \(y_\alpha>x_\alpha=N\).

4. When the remaining objection has a counterobjection

Fix that objection. Write \(s_t=Nr_t\), so \(s\in[0,1]^N\). All countercoalition agents of type \(\alpha\) necessarily overlap the objection, and every other type has zero overlap.

Its surplus after minimum required payments is therefore

\[ F(s)=(A+1)\sum_t(s_t^2-s_t)-ks_\beta +s_\beta\sum_i s_i -M\sum_{\{i,j\}\in E(G)}s_i s_j -Ms_\alpha s_\beta. \]

The countercoalition restrictions are \(s_\beta>0\) and \(s_\alpha<1\).

An independent set gives a counterobjection

If \(U\) is independent and \(|U|\geq k\), take \(s_\alpha=0\), \(s_\beta=1\), and include exactly the vertex types in \(U\), each with full mass. Then

\[ F(s)=|U|-k\geq0. \]

This vector satisfies both countercoalition restrictions, so it supports a counterobjection.

Without an independent set, no real countercoalition works

Suppose the independence number of \(G\) is smaller than \(k\).

First evaluate \(F\) at every Boolean vector \(\eta\in\{0,1\}^N\), and put \(U=\{i:\eta_i=1\}\).

If \(\eta_\beta=0\), then \(F(\eta)=-Me(U)\leq0\).

If \(\eta_\beta=1\), then

\[ F(\eta)=|U|-k-Me(U)-M\eta_\alpha. \]

When \(U\) is independent, \(|U|\leq k-1\), so this expression is at most \(-1\). When \(U\) is not independent, \(e(U)\geq1\), and

\[ |U|-k-Me(U)\leq n-k-(n+1)=-k-1<-1. \]

Thus every Boolean vector satisfies \(F(\eta)\leq-\eta_\beta\).

Now fix an arbitrary real vector \(s\in[0,1]^N\). Let the coordinates of a random Boolean vector \(\eta\) be independent, with \(\Pr(\eta_t=1)=s_t\). Independence gives \(\mathbb E[\eta_t\eta_u]=s_ts_u\) for distinct types. Also, \(\eta_t^2=\eta_t\). Substitution into the formula for \(F\) yields

\[ F(s)=\mathbb E[F(\eta)]-(A+1)\sum_t s_t(1-s_t). \]

The Boolean bound therefore implies

\[ F(s)\leq-s_\beta-(A+1)\sum_t s_t(1-s_t)\leq-s_\beta. \]

Every admissible countercoalition has \(s_\beta>0\), so its surplus is strictly negative. By the counterobjection criterion, none can work.

This rules out all real countercoalitions.

5. Correctness and input size

If \(G\) has an independent set of size at least \(k\), Section 4 supplies a counterobjection to the sole remaining objection; Section 3 handles all others. Hence the constructed imputation belongs to the bargaining set.

If \(G\) has no such independent set, the objection consisting of all agents of type \(\alpha\), directed against \(\beta\), has no counterobjection. Hence the imputation does not belong to the bargaining set.

We have proved

\[ G\text{ has an independent set of size at least }k \quad\Longleftrightarrow\quad x\text{ belongs to the constructed bargaining set}. \]

The support size is \(\tau=N=O(n)\). Since \(A=O(n^3)\), every integer coefficient has \(O(\log n)\) bits, and the dense output has length \(O(n^2\log n)\). The construction takes polynomial time and uses no additional candidate parameter.

Thus membership is \(\mathrm{NP}\)-hard. A polynomial-time algorithm in \(\tau,L\) would imply \(\mathrm{P}=\mathrm{NP}\).
