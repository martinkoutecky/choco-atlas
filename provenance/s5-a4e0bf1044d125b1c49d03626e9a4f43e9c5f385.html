Result

The decision problem is \(\mathrm{NP}\)-complete when \(m\) is part of the input.

Hardness holds even when \(\tau\leq 3m-4\), every mass is a dyadic rational, and only one sincere ranking type is eligible to manipulate for the only challenger who can possibly succeed. The reduction works for every fixed elimination priority order.

For general inputs, an exact algorithm runs in \(m!\,\operatorname{poly}(m,\tau,L)\) time. Thus the problem is polynomial-time solvable for each fixed \(m\).

1. Source problem and normalization

We reduce from Vertex Cover on simple graphs of maximum degree at most \(3\): given \(G_0=(V_0,E_0)\) and an integer \(k_0\), decide whether some set of at most \(k_0\) vertices meets every edge. This problem is \(\mathrm{NP}\)-complete. [Garey–Johnson–Stockmeyer, Theorem 2.6](https://www.math.ucdavis.edu/~deloera/MISC/LA-BIBLIO/trunk/JohnsonDavid2.pdf).

We may assume \(0\leq k_0\leq |V_0|\). Write \(M_0=|E_0|\). If \(M_0>3k_0\), the instance is necessarily negative, since each vertex meets at most \(3\) edges. Map such an instance to the immune two-candidate society consisting entirely of the ranking \(w\succ d\).

Otherwise, add \(p\) disjoint copies of \(K_{3,3}\), where

\(p=\max\left\{1,\left\lceil(2k_0+4-M_0)/3\right\rceil\right\}\),

and increase the cover bound by \(3p\). Denote the resulting graph by \(G=(V,E)\), its edge count by \(M\), and its bound by \(k\). Then

\(k=k_0+3p,\qquad M=M_0+9p,\qquad k\geq3,\qquad 2k+4\leq M\leq3k.\)

Each copy of \(K_{3,3}\) has minimum vertex-cover size \(3\): one bipartition class is a cover, and three disjoint edges give the matching lower bound. Consequently, the original and normalized instances have the same answer. The normalization has polynomial size and preserves maximum degree at most \(3\).

2. The support-encoded election

Choose a dyadic rational \(a\) satisfying

\(\displaystyle \frac1{k+3}<a<\frac1{k+2}.\)

Such an \(a\) can be constructed with \(O(\log k)\) bits: choose a power-of-two denominator larger than \(2(k+2)(k+3)\), and take the first grid point strictly above \(1/(k+3)\).

Set

\(\displaystyle h=\frac a4,\qquad b=1-a-Mh.\)

The normalized bounds imply

\(\displaystyle a+Mh=a(1+M/4)>\frac{k+4}{2(k+3)}>\frac12,\)

and

\(\displaystyle a+Mh<\frac{1+3k/4}{k+2}<1.\)

Thus \(0<b<1/2\). Moreover,

\(\displaystyle \frac ba=\frac1a-1-\frac M4>k+1-\frac M4\geq1+\frac k4>1,\)

so \(b>a\).

The candidates are

\(C=\{w,d\}\cup V.\)

Fix any order for completing the tails of the following rankings. The sincere support consists of:

| Ranking prefix | Mass |
|---|---:|
| \(w\succ d\succ V\) | \(a\) |
| \(d\succ w\succ V\) | \(b\) |
| \(u\succ v\succ w\succ d\succ(V\setminus\{u,v\})\), for each \(\{u,v\}\in E\) | \(h/2\) |
| \(v\succ u\succ w\succ d\succ(V\setminus\{u,v\})\), for each \(\{u,v\}\in E\) | \(h/2\) |

Every ranking is strict and complete. All masses are positive dyadic rationals and sum to \(a+b+Mh=1\).

Writing \(n=|V|\), we have

\(m=n+2,\qquad \tau=2M+2\leq3n+2=3m-4.\)

Each mass has \(O(\log k)\) bits, and \(k\leq n\). Hence the output bit length is \(L=O(m\tau\log m)=O(m^2\log m)\), and the reduction is polynomial-time.

The sincere winner is \(w\)

While \(w\) remains, a vertex candidate \(v\) can receive sincere support only from ballots corresponding to incident edges. Its tally is therefore at most

\(\deg(v)h\leq3h=3a/4<a.\)

Candidate \(w\) always has at least its first-place mass \(a\), and \(d\) has mass \(b>a\). Thus every vertex candidate is eliminated before either \(w\) or \(d\).

Once all vertices are eliminated, \(w\) has mass \(a+Mh=1-b>1/2\), whereas \(d\) has mass \(b<1/2\). Therefore \(\operatorname{IRV}(\mu)=w\), independently of the priority order.

No vertex candidate can successfully manipulate

Fix \(v\in V\). Exactly the incident-edge ballots rank \(v\) above \(w\), so their total eligible mass is

\(p_v=\deg(v)h\leq3a/4<a.\)

Consider any permitted manipulation targeting \(v\), and any round in which both \(v\) and \(w\) remain. Every ineligible ballot remains unchanged and ranks \(w\) above \(v\). Consequently, the tally of \(v\) is at most the entire eligible mass \(p_v\), even with arbitrary reports.

The mass \(a\) initially ranking \(w\) first is ineligible and unchanged. Hence the tally of \(w\) is at least \(a>p_v\). Candidate \(w\) cannot be eliminated while \(v\) remains.

Thus \(v\) cannot win. The only possible successful challenger is \(d\), whose eligible sincere mass consists precisely of the single type \(d\succ w\succ V\), of mass \(b\).

3. A vertex cover gives explicit successful transfers

Suppose \(T\subseteq V\) is a vertex cover, with \(t=|T|\leq k\). Put \(U=V\setminus T\). Since \(T\) covers every edge, \(U\) is independent.

Let \(f_v\), for \(v\in T\), be the contribution of the edge ballots to \(v\) when the remaining set is \(\{w,d\}\cup T\). Every edge then supports an endpoint in \(T\), so

\(\displaystyle \sum_{v\in T}f_v=Mh,\qquad 0\leq f_v\leq\deg(v)h\leq3a/4.\)

Because \(t\leq k\) and \(a<1/(k+2)\), the quantity \(1-(t+2)a\) is positive. Define

\(\displaystyle \varepsilon=\frac{1-(t+2)a}{2(t+1)}>0,\qquad y_v=a+\varepsilon-f_v\quad(v\in T),\)

and let

\(\displaystyle y_d=b-\sum_{v\in T}y_v.\)

Each \(y_v\) is positive. Using \(\sum f_v=Mh\), we obtain

\(\displaystyle y_d-(a+\varepsilon)=1-(t+2)a-(t+1)\varepsilon=\frac{1-(t+2)a}{2}>0.\)

Transfer mass \(y_v\) from the sincere type \(d\succ w\succ V\) to the report

\(v\succ d\succ w\succ(V\setminus\{v\})\)

for each \(v\in T\), and leave the remaining mass \(y_d\) reporting sincerely. These are permitted transfers and use less than the available mass \(b\).

First, all candidates in \(U\) are eliminated

Initially, each vertex has edge-ballot first-place mass \(\deg(v)h/2\).

For \(u\in U\), every neighbor lies in \(T\). Thus, while candidates in \(T\) remain, eliminating other members of \(U\) sends no votes to \(u\). Its tally stays at

\(\deg(u)h/2\leq3a/8.\)

For \(v\in T\), its initial manipulated tally is at least

\(\displaystyle y_v+\deg(v)h/2 \geq a+\varepsilon-\deg(v)h/2 \geq5a/8+\varepsilon.\)

These tallies cannot decrease while only members of \(U\) are eliminated. Candidate \(w\) retains tally \(a\): every edge still has an endpoint in \(T\) ahead of \(w\). Candidate \(d\) has tally \(y_d>a+\varepsilon\).

Hence every member of \(U\) is eliminated before any member of \(\{w,d\}\cup T\).

Next, \(w\) is eliminated

At remaining set \(\{w,d\}\cup T\), the tallies are:

  • \(w\): \(a\);
  • each \(v\in T\): \(f_v+y_v=a+\varepsilon\);
  • \(d\): \(y_d>a+\varepsilon\).

Thus \(w\) is the unique minimum and is eliminated.

Finally, \(d\) wins

The first-place mass \(a\) of \(w\) transfers immediately to \(d\), giving \(d\) tally at least \(y_d+a>2a+\varepsilon\).

While \(d\) remains, a vertex \(v\in T\) receives coalition mass only from its own report, since every other coalition report places \(d\) above \(v\). It receives fixed mass only from its incident-edge ballots, since all other fixed ballots place \(d\) above \(v\) after \(w\) disappears. Therefore its tally is at most

\(\displaystyle y_v+\deg(v)h\leq a+\varepsilon+3a/4=7a/4+\varepsilon<2a+\varepsilon.\)

Candidate \(d\) consequently has strictly more support than every remaining vertex at every subsequent round. It wins.

4. A successful manipulation forces a vertex cover

Suppose a successful manipulation exists. By Section 2, it must target \(d\), so every fixed ballot in the construction remains unchanged.

Consider the round in which \(w\) is eliminated. Its remaining set has the form

\(S=\{w,d\}\cup T,\qquad T\subseteq V.\)

Write \(t=|T|\), and let \(u\) be the number of edges with neither endpoint in \(T\).

The fixed contribution to \(w\) is exactly \(a+hu\): the first-place mass \(a\) remains with \(w\), and an edge contributes its entire mass \(h\) to \(w\) precisely when both endpoints have disappeared. Manipulator reports can only add further support to \(w\).

Since \(w\) is eliminated, every candidate in \(S\) has tally at least that of \(w\). Total mass is \(1\), giving the necessary inequality

\[\displaystyle (t+2)(a+hu)\leq1. \tag{1}\]

We show that this inequality implies the existence of a vertex cover of size at most \(k\).

First, \(t\geq k+1\) is impossible, because

\((t+2)(a+hu)\geq(k+3)a>1.\)

Thus \(t\leq k\).

The cases \(t=0\) and \(t=1\) are also impossible:

  • If \(t=0\), then \(u=M\), and \(2(a+hM)=2(1-b)>1\).
  • If \(t=1\), then \(u\geq M-3\), so

\(\displaystyle 3(a+hu)\geq\frac{3a(M+1)}4 \geq\frac{3a(2k+5)}4 >\frac{3(2k+5)}{4(k+3)}>1.\)

Now suppose \(2\leq t\leq k\), and assume for contradiction that no vertex cover of size at most \(k\) exists.

Adding one endpoint of each uncovered edge to \(T\) produces a vertex cover of size at most \(t+u\). Therefore

\(u\geq k+1-t.\)

Since \(h=a/4\), it follows that

\(\displaystyle (t+2)(a+hu)\geq\frac a4(t+2)(k+5-t).\)

The identity

\((t+2)(k+5-t)=4(k+3)+(t-2)(k+1-t)\)

shows that the right-hand side is at least \(a(k+3)>1\). This contradicts (1).

Thus a successful manipulation implies that \(G\) has a vertex cover of size at most \(k\). Together with Section 3 and the normalization, this proves \(\mathrm{NP}\)-hardness.

5. Membership in \(\mathrm{NP}\) and running times

The real-valued transfers and unrestricted report space require an upper-bound argument; enumerating all rankings would not give a polynomial-size certificate.

Fix a challenger \(d\neq w\). Let \(E_d\) be the sincere support types ranking \(d\) above \(w\), let

\(\displaystyle B=\sum_{r\in E_d}\mu_r,\)

and retain as fixed mass all other sincere types.

The attainable profiles are exactly the fixed profile plus an arbitrary nonnegative report distribution of total mass \(B\). Indeed, unchanged eligible mass can be included in that distribution. Conversely, when \(B>0\), any such distribution \(\nu\) is realized by

\(\displaystyle x_{r,s}=\mu_r\nu_s/B\quad(r\in E_d),\)

with zero transfers from ineligible types. When \(B=0\), only the sincere profile is attainable.

A polynomial-size linear program for a fixed order

Guess an elimination order \(e_1,\ldots,e_m\), with \(e_m=d\). At round \(i\), the remaining candidates are \(e_i,\ldots,e_m\).

Let \(g_{i,j}\) denote the fixed tally of \(e_j\) at that round. Introduce variables \(q_{i,j}\), for \(1\leq i\leq j\leq m\), representing coalition support. Impose

\(\displaystyle q_{i,j}\geq0,\qquad \sum_{j=i}^m q_{i,j}=B,\)

and, for every \(j>i\),

\(q_{i+1,j}\geq q_{i,j}.\)

These constraints express that coalition support persists on surviving candidates, and only the eliminated candidate’s support is redistributed.

They are also sufficient for realization by fixed complete rankings. Define the transfer from \(e_i\) to \(e_j\) by

\(q_{i+1,j}-q_{i,j}\quad(j>i).\)

The row-sum equations imply that these transfers sum to \(q_{i,i}\). Together with initial allocations \(q_{1,j}\), they form a conserved flow on an acyclic graph whose candidate indices increase along edges. Decompose this flow into paths ending at \(e_m=d\). For each path, report its candidates in path order, followed by all other candidates below \(d\). The resulting report distribution realizes every specified tally \(q_{i,j}\).

For each \(j>i\), impose

\(g_{i,i}+q_{i,i}\leq g_{i,j}+q_{i,j}\)

if the priority order eliminates \(e_i\) before \(e_j\) on a tie, and impose the corresponding strict inequality otherwise. These comparisons are exactly the conditions for the guessed elimination order.

To handle strict inequalities, introduce \(0\leq\delta\leq1\), replace each strict comparison by a gap of at least \(\delta\), and maximize \(\delta\). The order is realizable exactly when the resulting linear program is feasible and has optimum strictly positive. If there are no strict comparisons, \(\delta\) is unconstrained apart from its bounds, so the same criterion still works.

The program has \(O(m^2)\) variables and constraints. All fixed tallies are sums of input rationals and have polynomial bit length: a common denominator obtained by multiplying the input denominators has bit length \(O(L)\). The program can therefore be constructed and solved exactly in \(\operatorname{poly}(m,\tau,L)\) time, using polynomial-time rational linear programming. [Khachiyan, *Polynomial algorithms in linear programming*](https://www.mathnet.ru/php/archive.phtml?jrnid=zvmmf&option_lang=eng&paperid=5239&wshow=paper).

An elimination order is a certificate of \(O(m\log m)\) bits, and the preceding procedure verifies it in polynomial time. Hence the decision problem belongs to \(\mathrm{NP}\).

Finally, the sincere winner can be computed using \(O(\tau m^2)\) rational arithmetic operations, with polynomial bit cost. Enumerating all candidate elimination orders and applying the verifier gives running time

\(m!\,\operatorname{poly}(m,\tau,L).\)

Combined with the reduction, this establishes the claimed \(\mathrm{NP}\)-completeness.
