The continuous mirror question, as graded

Given child types \(\Theta\) with rational masses \(\mu_\theta\), home types \(K\) with capacities \(\nu_k\), feasible edges, and complete preference and evaluation rankings, compute a feasible assignment flow \(x_{\theta k}\), allowing unmatched mass, for which no feasible flow \(y\) admits, for each \(\theta\), a coupling \(z^\theta\) with old-destination marginal \(x_{\theta\cdot}\) and new-destination marginal \(y_{\theta\cdot}\) such that every positive \(z^\theta_{kk'}\) has \(I_\theta(k')\subseteq I_\theta(k)\), while positive mass is sent to some \(k'\in I_\theta(k)\). Here \(I_\theta(k)=\{k' : k'\succ_\theta k\text{ and }k'>_\theta k\}\), and \(I_\theta(\varnothing)=\{k:k\succ_\theta\varnothing,\ k>_\theta\varnothing\}\).

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: the list \(\Theta\) of its \(\tau\) child types with positive mass, each mass \(\mu_\theta\) a binary rational, with \(\sum_\theta\mu_\theta=1\). Here \(\tau\) is the support size, not the number of possible types. There are \(m=|K|\) home types with positive binary-rational capacities \(\nu_k\), measured in the same units as child mass, and feasible edges \(E\subseteq\Theta\times K\). Each child type has two strict total rankings \(\succ_\theta\) and \(>_\theta\) over \(D=K\cup\{\varnothing\}\).
A feasible flow has \(x_{\theta d}\geq0\), \(\sum_{d\in D}x_{\theta d}=\mu_\theta\), and \(\sum_\theta x_{\theta k}\leq\nu_k\). Require \(x_{\theta k}=0\) unless \((\theta,k)\in E\), \(k\succ_\theta\varnothing\), and \(k>_\theta\varnothing\); unmatched mass \(x_{\theta\varnothing}\) is allowed without capacity restriction.
For every \(d\in D\), define \(I_\theta(d)=\{k\in K:k\succ_\theta d\text{ and }k>_\theta d\}\), using all home types, irrespective of edge feasibility.
Call \(x\) improvable if there exist a feasible flow \(y\) and nonnegative couplings \(z^\theta\) satisfying \(\sum_{d'}z^\theta_{dd'}=x_{\theta d}\), \(\sum_d z^\theta_{dd'}=y_{\theta d'}\), and \(z^\theta_{dd'}>0\Rightarrow I_\theta(d')\subseteq I_\theta(d)\), with \(\sum_{\theta,d,d':\,d'\in I_\theta(d)}z^\theta_{dd'}>0\). Competitor flows and couplings may have real entries. A flow is unimprovable if it is not improvable.

Is computing a rational unimprovable flow solvable in polynomial time in \(m\), \(\tau\), and the total input bit length \(L\), or is this search problem NP-hard?

For discrete one-to-one assignments, Adaptive Serial Dictatorship with Indifferences produces an unimprovable matching; its stated guarantee does not give a polynomial running-time bound. [Source](https://arxiv.org/html/2411.12860v5).

Result

Computing a rational unimprovable flow is polynomial-time solvable. Minimize the mass-weighted number of unanimous improvers. Every permitted coupling weakly decreases this objective, and every coupling witnessing improvability strictly decreases it.

The argument applies to the continuous problem as stated, including competitors and couplings with real entries.

1. A linear potential

For every child type \(\theta\) and destination \(d\in D\), define

\[ c_{\theta d}=|I_\theta(d)|. \]

These costs use all home types when computing \(I_\theta(d)\), including homes whose edges are infeasible. Define the potential of a feasible flow by

\[ \Phi(x)=\sum_{\theta\in\Theta}\sum_{d\in D}c_{\theta d}x_{\theta d}. \]

Lemma. If a feasible flow \(x\) is improvable, witnessed by a feasible flow \(y\) and couplings \(z^\theta\), then \(\Phi(y)<\Phi(x)\).

Proof. Whenever \(z^\theta_{dd'}>0\), the coupling condition gives \(I_\theta(d')\subseteq I_\theta(d)\). Consequently,

\[ c_{\theta d}-c_{\theta d'}\geq 0. \]

If this move also satisfies \(d'\in I_\theta(d)\), then \(d'\) is a home type. Strictness of the rankings implies \(d'\notin I_\theta(d')\): a destination cannot rank strictly above itself. Thus \(d'\) belongs to \(I_\theta(d)\setminus I_\theta(d')\), and

\[ c_{\theta d}-c_{\theta d'}\geq 1. \]

Using both marginal identities of the couplings gives

\[ \begin{aligned} \Phi(x)-\Phi(y) &=\sum_{\theta,d,d'}z^\theta_{dd'} \bigl(c_{\theta d}-c_{\theta d'}\bigr)\\ &\geq \sum_{\theta,d,d':\,d'\in I_\theta(d)}z^\theta_{dd'}\\ &>0. \end{aligned} \]

The final inequality is exactly the strict-improvement requirement. All sums are finite, so the calculation applies without any rationality assumption on \(y\) or \(z^\theta\). This proves the lemma.

Corollary. Every global minimizer of \(\Phi\) over feasible flows is unimprovable.

Indeed, an improvement would yield a feasible flow with strictly smaller objective, contradicting optimality.

2. Computing a minimizer by minimum-cost flow

Let the admissible edge set be

\[ A=\{(\theta,k)\in E: k\succ_\theta\varnothing \text{ and } k>_\theta\varnothing\}. \]

Construct a directed network with source \(s\), sink \(t\), one node for each child type, and one node for each home type. Its arcs are:

| Arc | Capacity | Cost per unit |
|---|---:|---:|
| \(s\to\theta\) | \(\mu_\theta\) | \(0\) |
| \(\theta\to k\), for \((\theta,k)\in A\) | \(\mu_\theta\) | \(c_{\theta k}\) |
| \(\theta\to t\) | \(\mu_\theta\) | \(c_{\theta\varnothing}\) |
| \(k\to t\) | \(\nu_k\) | \(0\) |

Require an \(s\)-\(t\) flow of value \(1\).

The source arcs have total capacity \(\sum_\theta\mu_\theta=1\). Therefore every flow of value \(1\) saturates every source arc. Conservation at child node \(\theta\) then gives

\[ \sum_{k:\,(\theta,k)\in A}f_{\theta k}+f_{\theta t} =\mu_\theta. \]

Set \(x_{\theta k}=f_{\theta k}\) on admissible edges, set \(x_{\theta k}=0\) on all other home edges, and set \(x_{\theta\varnothing}=f_{\theta t}\). Conservation and capacity at home node \(k\) give \(\sum_\theta x_{\theta k}\leq\nu_k\). Thus the resulting assignment is feasible.

Conversely, every feasible assignment defines a network flow of value \(1\) through these identities, with \(f_{s\theta}=\mu_\theta\) and \(f_{kt}=\sum_\theta x_{\theta k}\). This correspondence holds for real flows as well as rational ones.

The network cost is exactly

\[ \sum_{(\theta,k)\in A}c_{\theta k}f_{\theta k} +\sum_\theta c_{\theta\varnothing}f_{\theta t} =\Phi(x). \]

Hence an exact minimum-cost flow produces a global minimizer of \(\Phi\). The network is feasible: send all child mass through the unmatched arcs.

3. Bit complexity and rational output

The costs satisfy \(0\leq c_{\theta d}\leq m\). They can be computed by recording positions in the two rankings and testing every pair \((d,k)\), using \(O(\tau(m+1)m)\) comparisons. Testing admissibility also takes polynomial time.

The network has \(\tau+m+2\) nodes and \(|A|+2\tau+m\) arcs.

To handle rational capacities exactly, let \(Q\) be the product of the denominators of all masses and capacities in their input representations. Its binary length is at most one plus the sum of the input denominator lengths, hence \(O(L)\). Computing \(Q\) takes polynomial time.

Multiply every capacity by \(Q\), and require flow value \(Q\). All capacities and supplies are now integers with \(O(L)\) bits; costs remain integers between \(0\) and \(m\). Scaling establishes a bijection between real feasible flows in the two networks, multiplying every objective value by \(Q\).

Use the standard minimum-cost-flow theorem: a feasible network with integer capacities, costs, and supplies has an integral optimum over its real feasible flows, and an exact optimum can be computed in polynomial time in the network size and binary input length. Polynomial-time algorithms for capacitated minimum-cost flow are established, for example, by [Orlin’s minimum-cost-flow algorithm](https://pubsonline.informs.org/doi/10.1287/opre.41.2.338). Here the network is finite, all capacities are finite integers, supplies are integral, and feasibility was established above.

Divide the computed integral flow by \(Q\). This yields an exact rational minimizer of \(\Phi\). Every assignment numerator is at most \(Q\), because each child’s outgoing flow is at most \(Q\mu_\theta\leq Q\). Therefore each output entry has \(O(L)\) bits, and the entire output has polynomial length.

By the lemma, this rational flow is unimprovable against every allowed real competitor and coupling. This completes the polynomial-time construction.
