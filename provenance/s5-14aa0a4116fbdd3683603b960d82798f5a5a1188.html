The continuous mirror question, as graded

Given \(k\) buckets and a finite ordered set of key intervals, each carrying a rational mass of red or blue records distributed uniformly within that interval, maintain cuts and bucket labels after rational-mass insertions, deletions, or relocations. After each update, use at most \(2(k-1)\) cuts and ensure, with probability at least \(1-\eta\), that every bucket \(j\) receives color-\(i\) mass \(b_{ij}\) satisfying \((1-\epsilon)M_i/k \le b_{ij} \le (1+\epsilon)M_i/k\), where \(M_i\) is the current total mass of color \(i\). What update and output time can be achieved as a function of \(k\), the number \(\tau\) of cohorts, the rational input bit length \(L\), \(\epsilon\), and \(\eta\)?

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: \(\tau\) positive-mass types, each with a binary rational mass; \(\tau\) counts listed types, not possible types. Here a type is a color and a nondegenerate rational interval in \([0,1]\); interval interiors are disjoint, and its mass is uniform on that interval. There are \(m=2\) colors, \(k\ge2\) buckets, and rational parameters \(\epsilon,\eta\in(0,1)\). Masses need not sum to one; both color totals remain positive.
An update inserts or deletes positive rational mass of one color, or relocates such mass by deletion and equal-mass insertion of that color. It is specified by \(r\) cohort edits, including any interval refinements, preserving the representation and nonnegative masses; zero-mass cohorts are omitted. There is no divisibility restriction on mass.
After each update, output at most \(2(k-1)\) rational cuts and a bucket label for every resulting interval. Every interval is assigned wholly to one bucket, which may receive several intervals; all mass is assigned. Writing \(M_i\) for total color-\(i\) mass and \(b_{ij}\) for that mass assigned to bucket \(j\), require simultaneously \((1-\epsilon)M_i/k\le b_{ij}\le(1+\epsilon)M_i/k\) with probability at least \(1-\eta\) per output, conditional on the preceding history.
Target. What preprocessing, update, and explicit-output bit-time bounds are achievable for this approximate splitting problem as functions of \(m=2,k,\tau,L,r,\epsilon,\eta\), where \(L\) is the total binary encoding length of the current support, update, and parameters?
Nearest known results. Discrete two-color necklaces admit this relative-error guarantee with \(2(k-1)\) cuts and failure probability \(1/N\): maintenance costs \(O(\log N)\) per bead update and output costs \(O(k^3 2^{2k}\epsilon^{-2}(\log N)^2)\), yielding \(O(k^2 2^{2k}\epsilon^{-2}(\log N)^2+\log N)\) per bead when output follows batches of \(k\) updates, where \(N\) is the bead count ([Advani et al.](https://drops.dagstuhl.de/storage/00lipics/lipics-vol365-icdt2026/LIPIcs.ICDT.2026.19/LIPIcs.ICDT.2026.19.pdf)).
For continuous measures, a verified static approximation algorithm permits a logarithmic factor more cuts; it does not supply dynamic bounds with the cut budget above ([Alon–Graur](https://web.math.princeton.edu/~nalon/PDFS/effneck3.pdf)).

Modeling choices made when packaging the task

  • Specified disjoint interval interiors, rational endpoints in [0,1], positive interval lengths, and uniform monochromatic densities to make the ordered-cohort representation precise.
  • Used unnormalized masses, required both color totals to remain positive, and set k≥2 and epsilon, eta in (0,1).
  • Allowed arbitrary positive rational update masses without divisibility constraints, since the discrete restriction preserves integral equal shares and has no corresponding restriction for divisible mass.
  • Specified updates by r cohort edits, counting interval refinements, to account for input size when an update affects multiple intervals.
  • Required complete allocation, permitted multiple intervals per bucket, and allowed rational cuts within cohorts.
  • Interpreted failure probability per output conditional on prior history, rather than as a guarantee for an unbounded sequence of outputs.
  • Separated maintenance from explicit output and included preprocessing in bit complexity; used m=2 for the color count and N for the discrete bead count.

Achievable bounds

The problem admits a deterministic approximation algorithm with the required cut budget. In particular, no dependence on \(\eta\) is necessary.

Using ordinary quadratic-time integer arithmetic, achievable bit-time bounds are:

| Operation | Bit-time bound |
|---|---:|
| Preprocessing the support | \(O(\tau\log(\tau+1)L^2)\) |
| Processing an update with \(r\) cohort edits | \(O(r\log(\tau+r+1)L^2)\) |
| Computing and explicitly writing one output | \(O(k^2\epsilon^{-1}\log(\tau+1)L^2)\) |

Consequently, an update followed immediately by an output costs
\(O((r\log(\tau+r+1)+k^2\epsilon^{-1}\log(\tau+1))L^2)\).

Each output contains at most \(2(k-1)\) rational cuts, has encoding length \(O(kL)\), and satisfies both colors’ fairness constraints deterministically. These are achievable upper bounds; no optimality claim is made.

For an update, the support size in the output bound is the size after the update. The maintenance bound uses \(\tau+r\) to bound intermediate support sizes. When using one encoding-length parameter across an update, take \(L\) to cover the support before and after the update together with its edit description and parameters.

The construction combines deterministic mass quantiles with the circular removal method for two-color necklaces, as in [Alon–Graur, Proposition 2](https://web.math.princeton.edu/~nalon/PDFS/effneck3.pdf). The proof and implementation bounds below are self-contained.

1. A deterministic finite approximation

Let \(\mu_i\) be the color-\(i\) measure, let \(M_i=\mu_i([0,1])>0\), and define its normalized cumulative distribution function by
\(F_i(x)=\mu_i([0,x])/M_i\).

The measures have no atoms, so each \(F_i\) is continuous. Set
\(n=k\lceil 2k/\epsilon\rceil\).
Thus \(k\) divides \(n\), and \(n\ge 2k^2/\epsilon\).

For each color \(i\) and each \(s\in\{1,\ldots,n\}\), construct the quantile
\(x_{i,s}=\min\{x\in[0,1]:F_i(x)\ge (s-\tfrac12)/n\}\).

Continuity gives
\(F_i(x_{i,s})=(s-\tfrac12)/n\).

These coordinates are rational: within a support interval, cumulative mass is affine with rational coefficients. At a cumulative-mass plateau, the minimum selects the rational endpoint preceding that plateau.

Quantiles of one color are distinct. Quantiles of different colors are also distinct: a selected quantile lies in the interior or at the right endpoint of an interval of its color, with positive density immediately to its left. Coincidence would therefore contradict the disjointness of interval interiors.

Define the empirical probability measure
\(\nu_i=n^{-1}\sum_{s=1}^n\delta_{x_{i,s}}\),
with cumulative distribution function \(G_i\). By the definition of the minimum quantile,
\(x_{i,s}\le x\) if and only if \((s-\tfrac12)/n\le F_i(x)\).
Counting these equally spaced thresholds proves
\(\lvert G_i(x)-F_i(x)\rvert\le 1/(2n)\)
for every \(x\in[0,1]\).

It follows, by subtracting cumulative masses at the two endpoints, that every interval \(J\) whose endpoints avoid the sample points satisfies
\(\lvert \nu_i(J)-\mu_i(J)/M_i\rvert\le 1/n\).

This bound also holds for intervals touching \(0\) or \(1\), since their cumulative discrepancies are zero at the corresponding exterior boundary.

2. Exactly splitting the quantile necklace

Sort the \(2n\) quantile points by position, retaining their colors. Write \(p=n/k\). We now prove that this finite necklace can be divided so that each bucket receives exactly \(p\) samples of each color, with at most \(2(k-1)\) changes of label in the original linear order.

Suppose the remaining samples form a circular sequence containing \(hp\) samples of each color, where \(h\ge 2\). Consider all circular windows of length \(2p\).

Each red sample occurs in exactly \(2p\) such windows. Therefore, the average red count of a window is
\((2p)(hp)/(2hp)=p\).

As the window advances one position, its red count changes by at most one. Since these counts are integers and their average is \(p\), some window has exactly \(p\) red samples. Its other \(p\) samples are blue.

Assign this window to a fresh bucket and remove it. The remaining circular sequence has \((h-1)p\) samples of each color. Repeat until one bucket remains, and assign all remaining samples to it.

Cut-count proof

Initially, mark every sample as unassigned. After each removal, count adjacent pairs in the original linear order whose marks differ, treating “unassigned” as one mark.

Previously assigned marks never change. A pair of originally adjacent unassigned samples is also adjacent in the remaining circular sequence. Membership in a circular window changes at most twice around that sequence. Consequently, assigning the window introduces at most two new differing adjacent pairs.

After \(k-1\) removals, there are at most \(2(k-1)\) such pairs. Renaming the remaining unassigned mark to the final bucket introduces no additional pair. This proves the cut budget.

Linear-time implementation

The finite algorithm can be implemented in \(O(n)\) operations on integers of \(O(\log n)\) bits.

Maintain:

  • a circular doubly linked list of the remaining samples;
  • the red count of the length-\(2p\) window starting at each remaining sample;
  • a doubly linked list of starts whose window count equals \(p\).

Initialize all window counts with one rolling scan. A qualifying start always exists by the preceding argument.

Removing a chosen window deletes \(2p\) starts. Among surviving starts, only the \(2p-1\) predecessors of the deleted window can have changed window contents. Recompute their counts by one rolling scan, updating their membership in the qualifying-start list in constant time per start.

Each removal therefore takes \(O(p)\) operations. Initialization and all removals together take
\(O(n+kp)=O(n)\).

3. Transferring the allocation to the society

Let the sorted quantile points be \(y_1<\cdots<y_{2n}\). Partition \([0,1]\) into cells by placing a boundary at
\((y_t+y_{t+1})/2\)
between each consecutive pair.

Each cell contains exactly its corresponding sample. Give the entire cell that sample’s bucket label. Merge adjacent cells with equal labels.

The preceding cut-count proof shows that the resulting partition uses at most \(2(k-1)\) cuts. All cuts are rational, and the cells cover the whole domain, including gaps in the support.

For bucket \(j\), let \(A_j\) be its assigned set. It is a union of at most \(2k-1\) resulting intervals. Because bucket \(j\) receives exactly \(p\) samples of each color,
\(\nu_i(A_j)=p/n=1/k\).

Applying the interval discrepancy bound separately to those intervals gives
\(\lvert \mu_i(A_j)/M_i-1/k\rvert\le (2k-1)/n\le \epsilon/k\).

Multiplication by \(M_i>0\) proves
\((1-\epsilon)M_i/k\le \mu_i(A_j)\le(1+\epsilon)M_i/k\)
for every color and bucket.

The construction is deterministic. Its conditional success probability after every history is therefore one.

4. Dynamic data structure and bit complexity

Store the support intervals in a balanced search tree ordered by their left endpoints. At every node, store the exact subtree mass of each color.

Sorting and constructing this tree takes
\(O(\tau\log(\tau+1)L^2)\)
bit time.

Each specified cohort edit changes a constant number of records and updates the aggregates along \(O(\log(\tau+r+1))\) tree nodes. Since refinements are included in \(r\), an entire update costs
\(O(r\log(\tau+r+1)L^2)\).

To retrieve a color quantile, descend using that color’s subtree masses. If the selected cohort has interval endpoints \(a,b\), mass \(v\), and preceding color mass \(S\), then the quantile at normalized level \(u\) is
\(a+(b-a)(uM_i-S)/v\).
A query uses \(O(\log(\tau+1))\) rational operations.

All relevant rational operands have \(O(L)\) bits:

  • A sum of current cohort masses has a denominator dividing the product of their denominators, whose bit length is bounded by their total input length.
  • Its numerator also has \(O(L)\) bits.
  • The quantile levels have denominators \(2n\), and \(\log n=O(L)\), because \(k\) and \(\epsilon\) are binary encoded.
  • The coordinate formula and midpoint construction use only a constant number of operations on these rationals.

With reduced fractions and quadratic-time integer arithmetic, each such rational operation costs \(O(L^2)\).

Generate the two increasing quantile lists and merge them. Quantile retrieval takes
\(O(n\log(\tau+1)L^2)\)
bit time; merging, finite splitting, and extracting label transitions take \(O(nL^2)\). Since \(n=O(k^2/\epsilon)\), the total explicit-output bound is
\(O(k^2\epsilon^{-1}\log(\tau+1)L^2)\).

There are \(O(k)\) output coordinates and labels, each using \(O(L)\) bits, so serialization uses \(O(kL)\) bits and is included in that bound. The method never expands rational mass into a potentially enormous number of unit beads.
