The continuous mirror question, as graded

Given candidates \(C\), ballot types \(R\in\mathcal T\subseteq\Gamma(C)\), a prefix \(\ell\), and independent random nonnegative rational weights \(X_R\) with explicitly listed finite distributions on a common grid and \(\sum_R X_R>0\), set \(\mu_R=X_R/\sum_S X_S\). After eliminating \(\ell\) and transferring each type’s mass to its highest-ranked remaining candidate, compute exactly the probability that a specified remaining candidate \(A_i\) has strictly less first-choice mass than every other remaining candidate.

Packaged proof task (what the prover saw — nothing else)

Let \(C\) contain \(m\geq2\) candidates. A ballot type in \(\Gamma(C)\) is a strict ordered list of distinct candidates, possibly empty or incomplete.
A society is given by its support: the list of the \(\tau\) types with positive mass, each mass a binary rational; \(\tau\) is the support size, not the number of possible types.
The random input lists distinct types \(\mathcal T\subseteq\Gamma(C)\) and independent weights \(X_R\). Each distribution explicitly lists its positive-probability outcomes and binary rational probabilities summing to \(1\); outcomes are nonnegative binary rationals in \(\{hb:h\in\mathbb Z_{\geq0}\}\), for a supplied binary rational \(b>0\). Unlisted outcomes have probability zero, and each listed type has positive probability of positive weight.
Promise \(\sum_R X_R>0\) almost surely. Each realization gives masses \(\mu_R=X_R/\sum_S X_S\), summing to \(1\), with zero-mass types omitted. For complexity bounds, \(\tau=|\mathcal T|\) is the maximum realized support size.
The input also gives an ordered list \(\ell\) of distinct candidates and a candidate \(A_i\in D=C\setminus\ell\), with \(|D|\geq2\). Delete the candidates in \(\ell\) from every ballot; each type contributes its mass to its first surviving listed candidate, or contributes nothing if exhausted. Let \(M_A\) denote the resulting first-choice mass of \(A\in D\).
The required probability is \(p=\Pr[M_{A_i}<M_A\text{ for every }A\in D\setminus\{A_i\}]\), without conditioning on whether \(\ell\) actually occurs as an IRV elimination prefix. Ties do not satisfy the event; exhausted mass is not redistributed.
Let \(L\) be the total binary input length and \(s\) the total number of listed distribution outcomes; state running times in \(m,\tau,L,|\ell|,s\).

Can \(p\) be computed exactly in polynomial time in this input encoding, or is its exact computation NP-hard under polynomial-time Turing reductions?

For independent discrete vote totals after fixed deletions, an exact sum-of-products identity for the strict-minimum probability is known; this identity supplies no classification for sparse binary input. [Kapoor and Staecker](https://arxiv.org/pdf/2405.09009v1).
No complexity classification for exactly this normalized random-mass problem was located.

Modeling choices made when packaging the task

  • Ballot types are strict partial rankings, including the empty ranking; ballots with no surviving listed candidate exhaust.
  • The prefix specifies unconditional candidate deletions, rather than conditioning the weight distributions on an actual elimination history.
  • The positive-total condition is an almost-sure promise, preserving the given independent distributions without conditioning.
  • Zero-mass types are omitted in each realization; for input complexity, tau is the maximum realized support size, equal to the number of listed potentially positive types.
  • The common grid has a positive binary rational spacing, with sparse explicitly listed outcomes and binary rational probabilities; omitted outcomes have probability zero.
  • At least two candidates remain, matching the nonfinal round in which the strict-minimum event is used.
  • Grid outcomes are exact weights, and equality fails the requested strict event; no bucket-tie resolution is applied.
  • For the exact rational-valued computation problem, NP-hardness is interpreted under polynomial-time Turing reductions.

Result

Exact computation of \(p\) is \(\mathrm{NP}\)-hard under polynomial-time Turing reductions. This holds even when \(b=1\), exactly two candidates survive the fixed deletions, every random distribution has two equiprobable outcomes, and no ballot becomes exhausted.

Consequently, a polynomial-time exact algorithm for the stated encoding would imply \(\mathrm{P}=\mathrm{NP}\).

1. Normalization cancels from the comparisons

For each listed type \(R\), let \(a_\ell(R)\) be its first candidate remaining after deleting \(\ell\), or let \(a_\ell(R)=\bot\) if it becomes exhausted. Define the unnormalized totals

\(Y_A=\sum_{R:\,a_\ell(R)=A}X_R,\qquad Z=\sum_{R\in\mathcal T}X_R.\)

By the promise, \(Z>0\) almost surely. The specified treatment of exhausted ballots gives \(M_A=Y_A/Z\). Therefore, in every realization of positive probability,

\(M_{A_i}<M_A\quad\Longleftrightarrow\quad Y_{A_i}<Y_A.\)

It follows that

\(p=\Pr[Y_{A_i}<Y_A\text{ for every }A\in D\setminus\{A_i\}].\)

Furthermore, the variables \((Y_A)_{A\in D}\) are mutually independent: each is a function of a disjoint subfamily of the independent input variables \((X_R)_{R\in\mathcal T}\). Exhausted types belong to none of these subfamilies.

This argument uses only the fixed deletion list. It introduces no conditioning on an elimination history.

2. A two-query reduction from SUBSET SUM

We use the standard \(\mathrm{NP}\)-complete problem SUBSET SUM: given positive binary integers \(a_1,\ldots,a_n\) and a positive binary target \(T\), decide whether some subset \(I\subseteq\{1,\ldots,n\}\) satisfies \(\sum_{j\in I}a_j=T\). This is the equality version of the problem called KNAPSACK in [Karp’s original paper](https://www.cs.umd.edu/~gasarch/BLOGPAPERS/Karp.pdf).

For each integer \(q\geq0\), construct a probability instance \(\mathcal I(q)\) as follows.

Take

\(C=\{A,B,E_1,\ldots,E_n\},\qquad \ell=(E_1,\ldots,E_n),\qquad A_i=A.\)

Thus \(D=\{A,B\}\). Set \(b=1\), and list the following types and distributions:

| Type | Weight distribution |
|---|---|
| \((A)\) | Deterministically \(q+1\) |
| \((B)\) | Deterministically \(1\) |
| \((B,E_j)\), for each \(j\in\{1,\ldots,n\}\) | \(0\) and \(a_j\), each with probability \(1/2\) |

All weights are independent.

Verification of the input requirements

The listed types are distinct, including when some integers \(a_j\) coincide. Each ballot is a strict list of distinct candidates. Every listed type has positive probability of positive weight because \(q+1>0\), \(1>0\), and \(a_j>0\).

All outcomes are nonnegative integer multiples of \(b=1\), and each distribution’s listed probabilities sum to \(1\). Moreover,

\(Z=q+2+\sum_{j=1}^nX_{(B,E_j)}\geq2,\)

so the almost-sure positivity promise holds.

Deleting \(\ell\) changes every type \((B,E_j)\) into \((B)\). No listed type becomes exhausted.

Evaluation of the constructed probability

Let \(\xi_1,\ldots,\xi_n\) be independent Bernoulli variables with parameter \(1/2\), and put

\(S=\sum_{j=1}^na_j\xi_j.\)

After deletion, the unnormalized totals are

\(Y_A=q+1,\qquad Y_B=1+S.\)

By Section 1, the oracle’s answer on \(\mathcal I(q)\) is therefore

\(p_q=\Pr[q+1<1+S]=\Pr[S>q].\)

Query the exact-probability oracle on \(\mathcal I(T-1)\) and \(\mathcal I(T)\). Both are valid because \(T\geq1\). Since \(S\) is integer-valued,

\(p_{T-1}-p_T=\Pr[S>T-1]-\Pr[S>T]=\Pr[S=T].\)

Every subset is selected with probability \(2^{-n}\), so

\(2^n(p_{T-1}-p_T)=\bigl|\{I\subseteq\{1,\ldots,n\}:\sum_{j\in I}a_j=T\}\bigr|.\)

In particular, the SUBSET SUM instance is a yes-instance exactly when \(p_{T-1}>p_T\). Strict comparisons are essential here: the difference isolates precisely the probability of equality at the target.

Size and running time of the reduction

Each oracle instance has

\(m=n+2,\qquad \tau=n+2,\qquad |\ell|=n,\qquad s=2n+2.\)

Its maximum realized support is indeed \(\tau\), because all \(n\) random item types are simultaneously positive with probability \(2^{-n}>0\).

If the SUBSET SUM input has binary length \(K\), each constructed instance has length

\(L=O(K+n\log(n+2)).\)

Both instances can be constructed in polynomial time in \(K\). Their answers have denominators dividing \(2^n\), so reading and comparing the exact answers also takes polynomial time.

Thus SUBSET SUM reduces to exact computation of \(p\) using two oracle calls. This proves the asserted \(\mathrm{NP}\)-hardness.

3. Exact output has polynomial binary length

The hardness does not arise from an inherently long answer.

Write the probability of outcome \(o\) of type \(R\) as \(u_{R,o}/v_{R,o}\), with positive integer denominator. Define

\(Q_R=\prod_o v_{R,o},\qquad Q=\prod_{R\in\mathcal T}Q_R.\)

Every joint outcome probability has denominator dividing \(Q\), because independence makes it a product containing one listed probability per type. Summing over the joint outcomes satisfying the event therefore gives

\(p=N/Q\)

for some integer \(N\) satisfying \(0\leq N\leq Q\).

The sum of the binary lengths of all listed denominators is bounded by \(L\). Hence \(\log_2Q=O(L)\), and both numerator and denominator of the reduced answer have \(O(L)\) bits.

4. Exact algorithms and their running times

These bounds also explain why the known probability identity does not yield a polynomial-time algorithm for sparse binary input.

For each type let \(s_R\) be its number of listed outcomes. Enumerating all joint outcomes requires

\(N_{\mathrm{joint}}=\prod_{R\in\mathcal T}s_R\leq(s/\tau)^\tau\)

iterations. After computing \(a_\ell(R)\) for every type, each iteration computes the candidate totals, tests the strict inequalities, and accumulates its exact probability.

Using ordinary integer and rational arithmetic, a conservative bit-operation bound is

\(O\!\left(\left[m+|\ell|+\tau m+s+(m+\tau)(s/\tau)^\tau\right](L+1)^3\right).\)

The factor \((L+1)^3\) suffices for the required arithmetic, including reduction of rational numbers. Section 3 supplies a common denominator of \(O(L)\) bits.

There is also a pseudopolynomial algorithm. Define the integer-valued variables \(H_R=X_R/b\), and let

\(H=\sum_{R\in\mathcal T}\max\{x/b:x\text{ is a listed outcome of }X_R\}.\)

The lattice promise guarantees that every term in this definition is an integer. Put \(V_A=Y_A/b\), and define

\(f_A(k)=\Pr[V_A=k],\qquad F_A(k)=\Pr[V_A\leq k].\)

All candidate totals lie in \(\{0,\ldots,H\}\). Mutual independence from Section 1 gives

\(p=\sum_{k=0}^{H}f_{A_i}(k)\prod_{A\in D\setminus\{A_i\}}\bigl(1-F_A(k)\bigr).\)

Indeed, for each fixed \(k\), the product is the probability that every other total exceeds \(k\), independently of \(V_{A_i}=k\); summing over the mutually exclusive values of \(V_{A_i}\) gives the event probability. This is the strict-minimum identity appearing in [Kapoor and Staecker, Section 5.2, Lemma 7](https://arxiv.org/pdf/2405.09009v1).

Compute each \(f_A\) by successively convolving the distributions assigned to candidate \(A\). Convolving a current array with a type having \(s_R\) outcomes takes \(O(s_R(H+1))\) arithmetic operations. Cumulative probabilities and the final sum take \(O(m(H+1))\) more. A conservative bit-operation bound is consequently

\(O\!\left(\left[m+|\ell|+\tau m+(s+m)(H+1)\right](L+1)^3\right).\)

All intermediate probabilities have polynomial binary length by the same denominator argument as in Section 3, applied to the relevant subfamilies of types.

This running time is polynomial when \(H\) is polynomially bounded. In the specified binary encoding, however, \(H\) can be exponentially large in \(L\). The identity and this algorithm are therefore compatible with the hardness proof.

5. Conclusion

The target classification is resolved: exact computation of \(p\) is \(\mathrm{NP}\)-hard under polynomial-time Turing reductions, already for two surviving candidates and distributions with at most two outcomes. No assertion that \(\mathrm{P}\ne\mathrm{NP}\) is needed for this classification.
