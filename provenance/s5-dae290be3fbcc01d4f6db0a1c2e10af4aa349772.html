The continuous mirror question, as graded

Given options \(O\) with integer serving sizes \(s_o\), a positive rational population scale \(P\), and a binary-encoded distribution \(\mu\) over acceptability types \(A\subseteq O\), choose integer order quantities \(q_o\ge 0\) minimizing \(\sum_o s_o q_o\u0005\). A menu is valid when there are nonnegative assignment masses \(x_{A,o}\), allowed only for \(o\in A\), such that \(\sum_{o\in A}x_{A,o}=P\mu_A\u0005\) for each supported type and \(\sum_{A:o\in A}x_{A,o}\le s_o q_o\u0005\) for each option; the decision version asks whether a valid menu of size at most \(B\) exists.

Packaged proof task (what the prover saw — nothing else)

Let \(O\) be a set of \(m\ge 1\) options with binary-encoded integer serving sizes \(s_o\ge 3\).
A society is given by its support: a list of \(\tau\) distinct nonempty acceptability types \(A\subseteq O\), each with positive binary-rational mass \(\mu_A\), where \(\sum_A\mu_A=1\). Every option belongs to some supported type. Here \(\tau\) is the support size, not the number of possible types.
The input also includes a positive binary-rational population scale \(P\) and a binary-rational budget \(B\ge P\). Type \(A\) requires \(P\mu_A\) units of acceptable food.
A menu consists of quantities \(q_o\in\mathbb Z_{\ge 0}\), with size \(\sum_{o\in O}s_oq_o\). It is valid if there exist real assignment masses \(x_{A,o}\ge 0\), zero whenever \(o\notin A\), satisfying \(\sum_{o\in A}x_{A,o}=P\mu_A\) for every supported type and \(\sum_{A:o\in A}x_{A,o}\le s_oq_o\) for every option. Unused food is allowed.
Let \(L\) be the total binary input length; state running times in \(m,\tau,L\), including the encodings of \(P,B\), and the serving sizes.

Is deciding whether a valid menu of size at most \(B\) exists solvable in polynomial time in \(m,\tau,L\), or is it NP-hard?

For explicitly listed unit-demand agents, this decision problem is NP-complete, even when every serving size equals \(3\) and the budget equals the number of agents.

Modeling choices made when packaging the task

  • Normalized the distribution to total mass one, with P specifying total food demand.
  • Required supported acceptability sets to be nonempty, consistent with the intended discrete model's guarantee that valid menus exist.
  • Discarded options accepted by no supported type, as in the discrete model.
  • Restricted serving sizes to integers at least three and required B to be at least P, carrying over the anchor's conditions.
  • Allowed binary-rational budgets because total population demand is rational.
  • Specified real, divisible assignment masses while retaining integer order quantities.

Result

The decision problem is \(\mathrm{NP}\)-complete, even when every serving size is \(3\) and \(B=P\) is an integer.

The explicitly listed unit-demand hardness stated in the question transfers to the support representation by grouping agents with identical acceptability sets. The key point is that allowing real assignment masses does not change feasibility when the aggregated demands and option capacities are integers.

1. Flow characterization and membership in \(\mathrm{NP}\)

Fix a menu \(q=(q_o)_{o\in O}\). Construct a directed network with source \(u\), sink \(v\), one vertex for every supported type, and one vertex for every option. Its edges and capacities are:

  • \(u\to A\), with capacity \(P\mu_A\);
  • \(A\to o\), for \(o\in A\), with capacity \(P\);
  • \(o\to v\), with capacity \(s_oq_o\).

The menu is valid if and only if this network admits a flow of value \(P\).

Indeed, a valid assignment gives such a flow by sending \(P\mu_A\) into each type vertex, \(x_{A,o}\) along each type-to-option edge, and \(\sum_{A:o\in A}x_{A,o}\) from each option to the sink. The capacity \(P\) on a type-to-option edge is sufficient because \(x_{A,o}\le P\mu_A\le P\).

Conversely, the source edges have total capacity \(\sum_A P\mu_A=P\). A flow of value \(P\) therefore saturates every source edge. Flow conservation at type and option vertices gives precisely the required assignment equalities and capacity inequalities.

A menu of size at most \(B\) satisfies \(0\le q_o\le\lfloor B/3\rfloor\) for every option. Since \(B\) is binary encoded, each quantity has \(O(L)\) bits, so the menu is a certificate of length \(O(mL)\).

To verify feasibility using exact arithmetic, write \(P=a/b\) and \(\mu_A=c_A/d_A\), with positive integer denominators, and define \(D=b\prod_A d_A\). Multiplying every network capacity by \(D\) makes all capacities integers. The binary length of \(D\) is at most the sum of the denominator lengths, hence \(O(L)\). For a certificate satisfying the budget, all scaled capacities also have \(O(L)\) bits: in particular, \(Ds_oq_o\le DB\) and \(DP\le DB\).

Let \(r=\sum_A|A|\), \(V=m+\tau+2\), and \(E=r+m+\tau\). An exact Edmonds–Karp computation uses \(O(VE^2)\) arithmetic operations. With elementary binary arithmetic, the complete verification, including checking the budget and constructing scaled capacities, takes

\[ \]
\(O\!\left((m+\tau+2)(m\tau+m+\tau)^2L^2\right)\)

bit operations. This bound includes the encodings of \(P\), \(B\), the masses, and the serving sizes. Thus the problem belongs to \(\mathrm{NP}\).

2. Polynomial reduction from explicitly listed agents

Use the \(\mathrm{NP}\)-complete unit-demand problem supplied in the question, restricted to serving sizes \(3\) and budget equal to the number \(n\) of agents.

An agent with an empty acceptability set makes the source instance infeasible; such an instance can be mapped to the fixed no-instance consisting of one option with serving size \(3\), one type of mass \(1\), and \(P=B=1\). Options accepted by no agent can be deleted, because any food allocated to them is unused. The case \(n=0\), if permitted, is immediately feasible and can be mapped to the analogous fixed yes-instance with \(P=B=3\).

We may therefore consider \(n\ge1\), nonempty agent acceptability sets, and options each accepted by some agent.

For every distinct acceptability set \(A\), let \(k_A\) be the number of agents having that set. Construct the support instance by setting

\(s_o=3,\qquad P=B=n,\qquad \mu_A=k_A/n.\)

Every mass is positive, the masses sum to \(1\), and every option belongs to some supported type. Moreover, \(\tau\le n\). Grouping identical acceptability lists takes polynomial time in the explicitly listed input length, and each mass requires \(O(\log(n+1))\) bits.

Forward direction

Suppose the source instance has a feasible menu and assignment of agents to options. For each type \(A\) and option \(o\), let \(x_{A,o}\) count the agents of type \(A\) assigned to \(o\). Then

\(\sum_{o\in A}x_{A,o}=k_A=P\mu_A\)

and

\(\sum_{A:o\in A}x_{A,o}\le3q_o.\)

The same menu is therefore valid in the support instance, with the same size and budget.

Reverse direction

Suppose the support instance has a valid menu of size at most \(n\). Apply the flow characterization above. Its capacities are now all integers:

  • source-to-type capacities are \(P\mu_A=k_A\);
  • type-to-option capacities are \(n\);
  • option-to-sink capacities are \(3q_o\).

There exists a flow of value \(n\). By the integral maximum-flow theorem, there also exists an integer-valued flow of value \(n\). Its hypotheses hold because every capacity is a nonnegative integer. Equivalently, an augmenting-path algorithm starts from zero and preserves integer flow values at every augmentation.

Consequently, there are integers \(y_{A,o}\ge0\), supported only on acceptable pairs, satisfying

\(\sum_{o\in A}y_{A,o}=k_A,\qquad \sum_{A:o\in A}y_{A,o}\le3q_o.\)

For each type \(A\), assign exactly \(y_{A,o}\) of its \(k_A\) explicitly listed agents to option \(o\). The first equality ensures that every agent is assigned once, and the second inequality respects every option’s capacity. Thus the original unit-demand instance is feasible.

The reduction therefore preserves both yes-instances and no-instances.

3. Conclusion

The reduction proves \(\mathrm{NP}\)-hardness, and the polynomial certificate verification proves membership in \(\mathrm{NP}\). Hence the support-encoded problem is \(\mathrm{NP}\)-complete. In particular, it is polynomial-time solvable in \(m,\tau,L\) if and only if \(\mathrm{P}=\mathrm{NP}\).
