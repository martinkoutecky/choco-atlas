The continuous mirror question, as graded

Given a finite role set \(R\), positive rational masses \(\mu_r\) summing to \(1\), rational influence shares \(q_{rs}\geq 0\) with \(\sum_{s\in R}q_{rs}=1\), a threshold \(T\in[1/2,1)\), and rational initial opinion shares \(x_r^0\in[0,1]\), iterate \(a_r^t=\sum_{s\in R}q_{rs}x_s^t\), setting \(x_r^{t+1}=1\) if \(a_r^t>T\), \(x_r^{t+1}=0\) if \(1-a_r^t>T\), and otherwise \(x_r^{t+1}=x_r^t\). Decide whether the process reaches unanimity on opinion \(1\) when \(\sum_{r\in R}\mu_rx_r^0>T\), or on opinion \(0\) when \(\sum_{r\in R}\mu_r(1-x_r^0)>T\); if neither inequality holds, the condition is vacuous.

The input also contains binary rationals \(T\in[1/2,1)\), \(x_r^0\in[0,1]\), and \(q_{rs}\geq0\) with \(\sum_{s\in R}q_{rs}=1\). For every integer \(t\geq0\), update all roles synchronously: set \(a_r^t=\sum_{s\in R}q_{rs}x_s^t\), and set \(x_r^{t+1}=1\) if \(a_r^t>T\), \(x_r^{t+1}=0\) if \(1-a_r^t>T\), and \(x_r^{t+1}=x_r^t\) otherwise.
Accept exactly when \(\sum_r\mu_rx_r^0>T\) implies that some finite time has \(x_r^t=1\) for every role, and \(\sum_r\mu_r(1-x_r^0)>T\) implies that some finite time has \(x_r^t=0\) for every role. If neither inequality holds, accept. The initial profile is supplied, not universally quantified.

Result

The decision problem is \(\mathrm{PSPACE}\)-complete, and therefore \(\mathrm{NP}\)-hard. Hardness already holds for binary initial shares, uniform masses, and influence rows that are uniform over their nonzero entries.

For the stipulated \(m=2\), there is an exact deterministic algorithm using \(O(2^\tau\tau^2L^2)\) bit operations and \(O(\tau^2L)\) bits of space. Thus the problem admits a polynomial-time algorithm if and only if \(\mathrm{P}=\mathrm{PSPACE}\).

Here, binary rational encoding means that numerators and denominators are written in binary.

1. The source theorem

We use the network complexity result supplied in the question. Its formulation agrees with Definition 1 and Proposition 1 of [Zhuang et al., *Lifting Majority to Unanimity in Opinion Diffusion*](https://research-repository.griffith.edu.au/server/api/core/bitstreams/357bdeb9-c2d4-447b-b70f-701850f199ce/content):

Given a finite directed network, nonempty influencer sets, a threshold \(T_0\in[1/2,1)\), and a supplied binary initial profile, deciding whether each initial opinion whose population proportion exceeds \(T_0\) eventually becomes unanimous is \(\mathrm{PSPACE}\)-complete. Updates are synchronous, influence is uniform over each influencer set, comparisons are strict, and ties preserve the previous opinion.

The supplied initial profile is part of this source instance; the theorem does not require universal quantification over initial profiles.

2. A polynomial reduction preserving the entire trajectory

Let a source instance have vertex set \(V=\{1,\ldots,n\}\), initial opinions \(b_r^0\in\{0,1\}\), and nonempty influencer sets \(I(r)\subseteq V\). Write \(d_r=|I(r)|\).

Construct an instance of the present problem by setting

\(R=V,\qquad \tau=n,\qquad m=2,\qquad T=T_0,\)

and, for every \(r,s\in V\),

\(\mu_r=\frac1n,\qquad x_r^0=b_r^0,\qquad q_{rs}=\begin{cases}\frac1{d_r}&s\in I(r),\\0&s\notin I(r).\end{cases}\)

These data satisfy every required hypothesis:

  • Each mass is positive, and \(\sum_r\mu_r=1\).
  • Each initial share belongs to \([0,1]\).
  • Each influence weight is nonnegative, and \(\sum_s q_{rs}=d_r/d_r=1\).
  • Self-influence is allowed, so any source self-loop is represented directly.
  • All constructed numbers have binary rational encodings of polynomial length.

For example, the dense influence matrix has encoding length \(O(n^2\log(n+1))\). Together with the copied threshold, the entire construction has polynomial size and can be performed in polynomial time.

We now prove that the trajectories coincide. Let \(b^t\) denote the source profile. At time zero, \(x_r^0=b_r^0\). Suppose \(x_s^t=b_s^t\) for every \(s\). Then

\(a_r^t=\sum_s q_{rs}x_s^t=\frac{|\{s\in I(r):b_s^t=1\}|}{d_r}.\)

Consequently, \(a_r^t>T_0\) holds exactly when the source proportion of opinion \(1\) among \(r\)'s influencers exceeds its threshold. Likewise, \(1-a_r^t>T_0\) holds exactly when the corresponding proportion of opinion \(0\) exceeds the threshold. Both systems preserve the previous opinion when neither strict inequality holds. Therefore \(x_r^{t+1}=b_r^{t+1}\), completing the induction.

The initial majority tests also coincide, because

\(\sum_r\mu_rx_r^0=\frac{|\{r:b_r^0=1\}|}{n},\qquad \sum_r\mu_r(1-x_r^0)=\frac{|\{r:b_r^0=0\}|}{n}.\)

Finally, unanimity at any particular time is identical in the two trajectories. Thus the constructed instance is accepted if and only if the source instance is accepted.

This proves \(\mathrm{PSPACE}\)-hardness, and hence \(\mathrm{NP}\)-hardness.

3. A finite bound on rational-share trajectories

We next prove membership in \(\mathrm{PSPACE}\), including instances with fractional initial shares.

Lemma. Along any trajectory, \(x_r^t\in\{x_r^0,0,1\}\) for every role and time. Once a coordinate becomes binary, it remains binary.

Proof. An update either preserves the coordinate or replaces it by \(0\) or \(1\). Applying this observation inductively proves both assertions.

Define the set of fractional coordinates at time \(t\) by

\(F_t=\{r:0<x_r^t<1\}.\)

The lemma gives \(F_{t+1}\subseteq F_t\). Moreover, every coordinate in \(F_t\) still equals its initial value.

Consider a consecutive interval of times on which \(F_t\) is constant, and put \(k=\tau-|F_t|\). Only its \(k\) binary coordinates can vary, so at most \(2^k\) distinct profiles occur during that interval.

Whenever the fractional set changes, it strictly shrinks, so \(k\) strictly increases. In particular, there is at most one such interval for each \(k\in\{0,\ldots,\tau\}\). Therefore the whole trajectory contains at most

\(B=\sum_{k=0}^{\tau}2^k=2^{\tau+1}-1\)

distinct profiles.

The update is deterministic. If two profiles coincide, their subsequent trajectories coincide as well. It follows that every profile that is ever reached first appears among times \(0,\ldots,B-1\): a first occurrence at any later time would require more than \(B\) distinct preceding profiles.

Thus checking these \(B\) times suffices to decide whether a prescribed unanimous profile is ever reached.

4. Exact algorithm and bit complexity

First compute the initial opinion-\(1\) mass

\(M_0=\sum_r\mu_rx_r^0.\)

At most one of \(M_0>T\) and \(1-M_0>T\) can hold. Indeed, if both held, adding them would give \(1>2T\), contradicting \(T\geq1/2\).

If neither holds, accept immediately. Otherwise, let \(b\in\{0,1\}\) be the uniquely qualifying opinion. Simulate synchronously and inspect the profiles at times \(0,\ldots,B-1\). Accept upon finding \(x_r^t=b\) for every role; reject if all \(B\) checks fail. Section 3 proves this algorithm correct.

To justify exact arithmetic bounds, let \(D\) be the product of the denominators of all input rationals. Its binary length is \(O(L)\). Define the integers

\(Q_{rs}=Dq_{rs},\qquad X_r^0=Dx_r^0,\qquad U_r=D\mu_r,\qquad C=DT.\)

At every time, store \(X_r^t=Dx_r^t\), which belongs to \(\{X_r^0,0,D\}\). For each role, compute

\(A_r^t=\sum_s Q_{rs}X_s^t.\)

The two update tests are exactly

\(A_r^t>CD,\qquad D^2-A_r^t>CD.\)

The initial majority tests similarly compare \(\sum_rU_rX_r^0\) and its complement in \(D^2\) against \(CD\). All comparisons therefore use integers, without rounding.

Because each influence row sums to one and all shares lie in \([0,1]\), every partial sum defining \(A_r^t\) is between \(0\) and \(D^2\). All arithmetic operands consequently have \(O(L)\) bits. With schoolbook arithmetic, one synchronous update takes \(O(\tau^2L^2)\) bit operations.

There are fewer than \(2^{\tau+1}\) inspected profiles. Including preprocessing, the running time is therefore \(O(2^\tau\tau^2L^2)\) for \(m=2\). Storing the scaled influence matrix, initial and current profiles, arithmetic workspace, and an \(O(\tau)\)-bit counter requires \(O(\tau^2L)\) bits.

This establishes membership in \(\mathrm{PSPACE}\). Combined with Section 2, it proves the claimed \(\mathrm{PSPACE}\)-completeness.
