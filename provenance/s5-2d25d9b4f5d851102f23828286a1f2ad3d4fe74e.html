The continuous mirror question, as graded

Given a finite project set \(P\), common partition \(\mathcal Z\), rational costs and budget \(L\), and finite voter-type support \(H\) with rational masses \(\mu_h>0\) summing to \(1\), where each type specifies an approval set and nondecreasing concave interaction tables, compute the IES outcome \(W\) and payment sequence using initial purse \(\mu_h L\) and type payment \(\min\{b_h,\mu_h q\,u_h(p\mid B)\}\). Does this mass-based rule satisfy EJRI-1 for every measurable coalition of mass at least \(\operatorname{cost}(T)/L\) that meets the paper’s marginal cohesiveness condition, with a positive-mass member witnessing the guarantee?

Packaged proof task (what the prover saw — nothing else)

Let \(P\) contain \(m\) indivisible projects, with a common partition \(\mathcal Z\), strictly positive rational costs \(c(p)\), and strictly positive rational budget \(\ell\); write \(c(T)=\sum_{p\in T}c(p)\).
A society is given by its support: a list \(H\) of \(\tau\) types with positive binary rational masses \(\mu_h\) summing to \(1\). Here \(\tau=|H|\) is the support size, not the number of possible types; let \(L\) be the total input bit length and state running times in \(m,\tau,L\).
Each type specifies an approval set \(A_h\subseteq P\) and explicit nonnegative rational, nondecreasing concave tables \(f_{hZ}:\{0,\ldots,|Z|\}\to\mathbb Q_{\ge0}\), with \(f_{hZ}(0)=0\). Define \(u_h(B)=\sum_{Z\in\mathcal Z}f_{hZ}(|A_h\cap B\cap Z|)\) and \(u_h(p\mid B)=u_h(B\cup\{p\})-u_h(B)\).
Mass IES starts with \(B=\varnothing\) and aggregate type purses \(b_h=\mu_h\ell\). For each \(p\notin B\), let \(q_p\) be the least \(q\ge0\) satisfying \(\sum_h\min\{b_h,\mu_hq\,u_h(p\mid B)\}\ge c(p)\), or \(\infty\) if none exists. Select a project of minimum finite \(q_p\), breaking ties by a fixed input order, charge each type \(\min\{b_h,\mu_hq_pu_h(p\mid B)\}\), subtract these payments, and add the project to \(B\). Stop when all remaining values are infinite and return \(W=B\) and the ordered project and type-payment sequence.
Treat each type's mass as nonatomic. A measurable coalition is described by real masses \(0\le s_h\le\mu_h\), with \(s=\sum_hs_h>0\) and \(H_S=\{h:s_h>0\}\). For \(T\subseteq P\) and \(\alpha:2^P\to\mathbb R_{\ge0}\) with \(\alpha(\varnothing)=0\), it is cohesive if \(s\ge c(T)/\ell\) and \(\alpha(B\cup\{p\})-\alpha(B)=\min_{h\in H_S}u_h(p\mid B)\) for every \(p\in T\) and \(B\subseteq P\setminus\{p\}\).
An outcome satisfies EJRI-1 if every such cohesive coalition has a type \(h\in H_S\) with \(u_h(W)\ge\alpha(T)\), or with \(u_h(W\cup\{p\})>\alpha(T)\) for some \(p\in T\); this witnesses the guarantee on positive coalition mass.

Is exact computation of the mass IES outcome and payment sequence in \(\mathrm P\), or is it \(\mathrm{NP}\)-hard? Does mass IES always satisfy EJRI-1 as defined above, or is there a counterexample?

For finite equal-weight voters with a common partition and concave interaction functions, IES is polynomial-time computable and is claimed to satisfy EJRI-1. [Source](https://arxiv.org/html/2106.05360v2). No result for exactly the nonatomic mass formulation above was located in the literature search.

Modeling choices made when packaging the task

  • Renamed the budget to ell and reserved L for total input bit length.
  • Specified strictly positive costs and budget, nonnegative rational utility tables including zero, and f(0)=0.
  • Specified fixed input-order tie-breaking, nonnegative affordability prices, purse updates, termination, and the exact payment-sequence output.
  • Interpreted measurable coalitions through arbitrary real submasses of nonatomic type populations; a witness must have positive mass within the coalition.
  • Corrected the printed marginal expression alpha(B union {p}) minus alpha(p) to alpha(B union {p}) minus alpha(B), consistently with the intended marginal interpretation.
  • Normalized alpha(empty set)=0; otherwise unrestricted additive shifts make the stated proportionality claim false.
  • Included both the weak utility guarantee without an additional project and the strict guarantee with one additional project, as used in the anchor's proof.

1. Conclusions. Exact computation of the outcome and payment sequence is polynomial-time solvable—more precisely, the function problem belongs to \(\mathrm{FP}\). However, mass IES does not always satisfy \(\mathrm{EJRI}\text{-}1\).

The counterexample below has eight equal-mass types, dyadic costs and masses, and identical concave tables. Every coalition type remains strictly below the required threshold even after adding any one project from the cohesive set.

2. Exact polynomial-time computation. Fix a state with selected set \(B\) and remaining purses \(b_h\). For an unselected project \(p\), put
\[ d_h=u_h(p\mid B),\qquad a_h=\mu_h d_h. \]
Here and below, these displayed expressions mean \(d_h=u_h(p\mid B)\) and \(a_h=\mu_h d_h\).

If \(p\) belongs to block \(Z\), maintain the count \(k_{hZ}=|A_h\cap B\cap Z|\). Then \(d_h=0\) when \(p\notin A_h\); otherwise,
\(d_h=f_{hZ}(k_{hZ}+1)-f_{hZ}(k_{hZ})\).
Thus each marginal requires only a table lookup and subtraction.

Define \(I=\{h:a_h>0\}\) and \(F(q)=\sum_{h\in I}\min\{b_h,a_hq\}\). This is a continuous, nondecreasing, piecewise-linear function whose maximum is \(\sum_{h\in I}b_h\). Consequently:

  • If \(\sum_{h\in I}b_h<c(p)\), then \(q_p=\infty\).
  • Otherwise, the least root of \(F(q)=c(p)\) is finite and is exactly \(q_p\).

For each \(h\in I\), the breakpoint is \(r_h=b_h/a_h\). Sort these breakpoints, grouping equal values, and scan the successive linear segments while maintaining their intercept and slope. The first segment reaching \(c(p)\) determines the root by one linear equation. This takes \(O(\tau\log(\tau+1))\) exact arithmetic operations.

Continuity ensures that the payments at the least root sum to exactly \(c(p)\). There are at most \(m\) selections and one final affordability check, giving \(O(m^2\tau\log(\tau+1))\) arithmetic operations overall. Comparing finite prices and applying the input tie order determines the complete ordered payment sequence.

Bit-length bound. An arithmetic-operation bound alone is insufficient because the input uses binary rationals. We therefore bound every intermediate number.

Let \(D\) be the product of the positive denominators of all input rationals, including costs, masses, the budget and table entries. Then \(\log_2D=O(L)\). Every marginal has denominator dividing \(D\), so every coefficient can be written as \(a_h=A_h/D^2\), where \(A_h\) is a nonnegative integer with \(O(L)\) bits. Write \(c(p)=C/D\).

Maintain all current purses with a common denominator: \(b_h=n_h/E\). Initially one may take \(E=D^2\), since \(b_h=\mu_h\ell\).

For a finite least root \(q_p\), define
\(S=\{h\in I:r_h<q_p\}\) and \(U=\{h\in I:r_h\ge q_p\}\).
The set \(U\) is nonempty: otherwise all positive coefficients would already be saturated strictly before \(q_p\), contradicting its minimality. Put \(K=\sum_{h\in S}n_h\) and \(J=\sum_{h\in U}A_h\), so \(J>0\). The equation determining the root is
\(K/E+q_pJ/D^2=C/D\), hence
\(q_p=D(CE-DK)/(EJ)\).

For \(h\in U\), its payment is
\(A_h(CE-DK)/(DEJ)\).
For \(h\in S\), its payment is \(n_h/E\); types outside \(I\) pay zero. Therefore every updated purse can be represented with common denominator \(E'=DEJ\).

Because \(J\) is a sum of at most \(\tau\) integers of \(O(L)\) bits, its bit length is \(O(L+\log(\tau+1))\). After at most \(m\) updates, both \(\log E\) and the bit lengths of purse numerators are
\(O((m+1)(L+\log(\tau+1)))\): purse numerators satisfy \(0\le n_h\le E\ell\). The formulas above give the same bound for prices, breakpoints and payments.

Using elementary integer arithmetic, a conservative bit-time bound is therefore
\(O((L+m^2\tau\log(\tau+1))(m+1)^2(L+\log(\tau+1))^2)\).
This is polynomial in \(m,\tau,L\), and bounds the output length as well. The case \(m=0\) is immediate.

3. A counterexample. Let \(H=\{0,\ldots,7\}\), with indices interpreted modulo \(8\). Give every type mass \(\mu_h=1/8\), and take budget \(\ell=8\). Each initial aggregate purse is therefore \(b_h=1\).

There are eight target projects \(p_i\), each costing \(1\). For every pair \(h,i\) satisfying \(i\notin\{h,h+1\}\), introduce a private project \(x_{hi}\) costing \(3/32\). Define the common partition by
\(Z_i=\{p_i\}\cup\{x_{hi}:i\notin\{h,h+1\}\}\).

Each block has one target and six private projects. Thus \(m=56\) and \(\tau=8\).

Type \(h\) approves all target projects and its own six private projects:
\(A_h=\{p_i:i\in H\}\cup\{x_{hi}:i\notin\{h,h+1\}\}\).
For every type and block, use the explicit table
\(f_{hZ_i}(k)=\min\{k,1\}\) for \(k\in\{0,\ldots,7\}\).
Its successive increments are \(1,0,\ldots,0\), so it is nonnegative, nondecreasing and concave.

The exact IES run. We prove that all \(48\) private projects are selected before any target.

Suppose only private projects have been selected so far. A remaining private project \(x_{hi}\) has marginal utility \(1\) for its owner \(h\) and zero for every other type. Indeed, no target has been selected, and \(x_{hi}\) is the only private project in \(Z_i\) approved by \(h\).

Each type pays for at most six private projects. Its purse throughout this phase is therefore at least
\(1-6(3/32)=7/16>3/32\).
Consequently every remaining private project has price
\(q_{x_{hi}}=(3/32)/(1/8)=3/4\),
and charges exactly \(3/32\) to its owner and zero to everyone else.

For any target \(p_i\), every marginal utility is either zero or one. At any price \(q\), its total possible payment is at most
\(\sum_h\mu_hq\,u_h(p_i\mid B)\le q\sum_h\mu_h=q\).
Since its cost is \(1\), every finite target price is at least \(1\). Thus a remaining private project always precedes every target. This proves the induction.

After all private projects have been selected, every purse equals \(7/16\). For target \(p_i\), precisely types \(i\) and \(i-1\) still have marginal utility \(1\): these are exactly the types without an approved private project in \(Z_i\). The other six types have marginal utility zero.

The maximum payment available for \(p_i\) is therefore
\(2(7/16)=7/8<1=c(p_i)\).
All targets are unaffordable, so IES stops with
\(W=\{x_{hi}:i\notin\{h,h+1\}\}\).

This argument works for every input tie order. The payment sequence selects the private projects in their input order, charging each owner \(3/32\).

4. Cohesiveness and failure of the guarantee. Take the entire society as the coalition: \(s_h=\mu_h=1/8\), so \(s=1\) and \(H_S=H\). Set \(T=\{p_0,\ldots,p_7\}\), and define on every subset \(B\subseteq P\)
\(\alpha(B)=\sum_{i\in H}\min\{|B\cap Z_i|,1\}\).
This is nonnegative and satisfies \(\alpha(\varnothing)=0\).

We verify the required marginal identity for arbitrary \(p_i\in T\) and \(B\subseteq P\setminus\{p_i\}\).

  • If \(B\cap Z_i=\varnothing\), every type gains utility \(1\) from adding \(p_i\). The increment of \(\alpha\) is also \(1\).
  • If \(B\cap Z_i\ne\varnothing\), this intersection contains a private project \(x_{hi}\). Its owner already receives utility \(1\) from this block, so that owner’s marginal for \(p_i\) is zero. All marginals are nonnegative, making their minimum zero. The increment of \(\alpha\) is likewise zero.

Thus
\(\alpha(B\cup\{p_i\})-\alpha(B)=\min_{h\in H_S}u_h(p_i\mid B)\)
for every required project and subset.

Moreover, \(c(T)/\ell=8/8=1=s\). The coalition is therefore cohesive, and \(\alpha(T)=8\).

Each type approves selected private projects in exactly six distinct blocks, so \(u_h(W)=6\). Adding any target either leaves its utility unchanged or represents one additional block. Hence, for every \(h\in H_S\) and \(p_i\in T\),
\(u_h(W\cup\{p_i\})\le7<8=\alpha(T)\).

Every coalition type fails both witnessing conditions. Mass IES therefore violates \(\mathrm{EJRI}\text{-}1\), even if its strict improvement condition were weakened to a non-strict one.

5. Relation to the finite-voter claim. The counterexample also has an eight-voter equal-weight interpretation. With one voter per type, each initial purse remains \(1\), and dividing every mass-IES price by \(8\) gives the finite-voter price with identical payments and selections. Thus the obstruction already occurs in the finite analogue of the exact definitions posed here. The guarantee asserted in Proposition 1 of the [cited paper](https://arxiv.org/html/2106.05360v2) cannot establish this formulation.

Because costs are strictly positive and \(F(0)=0\), a finite least affordable price satisfies \(F(q_p)=c(p)\). Consequently the payments cover the project cost exactly and keep every purse nonnegative.
