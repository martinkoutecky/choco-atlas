The continuous mirror question, as graded

Given finite agent-type and item-type sets \(T\) and \(G\), rational agent masses \(\mu_t\) and item supplies \(q_g\) summing to \(1\), strict rankings of item types, and either rational values \(v_t(g)\) or metric costs \(c_t(g)\), form each admissible \(N\)-agent instance with \(N\mu_t\) agents of type \(t\) and \(Nq_g\) items of type \(g\). Run the paper's uniform-random-order RSD on each finite instance. Establish and compute the limiting expected assignment masses \(x_{tg}=\lim_{N\to\infty}N^{-1}\mathbb{E}[\#\text{ type-}t\text{ agents assigned to type }g]\) and the corresponding per-capita expected welfare \(\sum_{t,g}x_{tg}v_t(g)\), or cost \(\sum_{t,g}x_{tg}c_t(g)\).

Packaged proof task (what the prover saw — nothing else)

Let \(T\) be the agent-type support and \(G\) the item-type support, with \(\tau=|T|\) and \(m=|G|\). A society is given by its support: the list of its \(\tau\) positive-mass types, each mass a binary rational; \(\tau\) is the support size, not the number of possible types. Supplies are also positive binary rationals, with \(\sum_t\mu_t=\sum_g q_g=1\); let \(L\) be the total input bit length.
Each type has a strict ranking of all item types and either nonnegative rational values \(v_t(g)\), ranked in nonincreasing order, or nonnegative rational costs \(c_t(g)\), ranked in nondecreasing order. In the cost setting, the input is promised to admit points \(a_t,b_g\) in a common metric space with \(c_t(g)=d(a_t,b_g)\); points may coincide. The supplied ranking resolves equal values or costs.
For every positive integer \(N\) making all \(N\mu_t\) and \(Nq_g\) integral, create those numbers of agents and item copies. RSD uses a uniformly random permutation of all agents; each agent takes one copy of its highest-ranked type still available. Copies within a type are interchangeable.
Define \(A^{(N)}_{tg}\) as the number of type-\(t\) agents receiving type-\(g\) items, and \(x_{tg}=\lim_{N\to\infty}\mathbb E[A^{(N)}_{tg}]/N\), along admissible integers. The associated per-capita welfare and cost are \(W=\sum_{t,g}x_{tg}v_t(g)\) and \(C=\sum_{t,g}x_{tg}c_t(g)\).

Do these limits exist for every input, and is exact computation of \(x\) and the applicable aggregate \(W\) or \(C\) possible in time polynomial in \(m,\tau,L\), or is the computation NP-hard?

Exact finite-instance RSD expected welfare and metric cost are \(\#\mathrm P\)-hard. [Caragiannis–Homrighausen](https://arxiv.org/abs/2405.14316)
Che–Kojima establish convergence of replica RSD assignments to continuum probabilistic serial, including proportionally growing unequal supplies; this covers the limit specified here, so it cannot honestly be presented as an unresolved limit problem. [Primary source](https://www.columbia.edu/~yc2271/files/papers/psrp28.pdf)

Modeling choices made when packaging the task

  • Use only positive-mass agent types and positive-supply item types; zero entries are omitted from the supports.
  • Require nonnegative rational values or costs and rankings consistent with them; the supplied strict rankings break cardinal ties.
  • Interpret metric costs as a rational cross-distance matrix promised to have a common metric realization, allowing agents and items to occupy coincident points.
  • Treat copies of an item type as interchangeable; any ordering among copies leaves assignment masses unchanged.
  • Take the limit through all positive integers for which every agent count and item count is integral.
  • Interpret computation as exact computation, matching the hardness anchor, and measure complexity using total binary input length together with the two support sizes.

Result

All the limits exist. The limiting allocation \(x\), and hence the applicable aggregate \(W\) or \(C\), can be computed exactly in time polynomial in \(m,\tau,L\).

The limit is the mass-weighted probabilistic serial allocation. This agrees with the convergence result of [Che–Kojima](https://www.columbia.edu/~yc2271/files/papers/psrp33-EMA.pdf). Below is a self-contained proof for the specified inputs, followed by an exact algorithm and its bit-complexity analysis.

1. The continuum allocation

Let \(s\) denote time, starting at zero. Each type \(t\) consumes its highest-ranked available item type at rate \(\mu_t\). Write \(z_{tg}(s)\) for its cumulative consumption and
\[ r_g(s)=q_g-\sum_t z_{tg}(s) \]
for the remaining supply.

This process has a precise finite-stage construction. At the beginning of a stage, let
\[ S=\{g:r_g>0\}, \qquad h_t(S)=\text{the highest-ranked item in }S, \]
and define
\[ a_g=\sum_{t:h_t(S)=g}\mu_t. \]
The duration of the stage is
\[ \Delta=\min_{g\in S:a_g>0}\frac{r_g}{a_g}. \]
During the stage, update
\[ z_{t,h_t(S)}\leftarrow z_{t,h_t(S)}+\mu_t\Delta, \qquad r_g\leftarrow r_g-a_g\Delta. \]
Remove every item whose remaining supply becomes zero, including all simultaneous exhaustions.

Whenever \(S\) is nonempty, every type chooses an item in \(S\), so \(\sum_g a_g=1\). Thus the minimum exists and is positive. Each stage exhausts at least one item, so there are at most \(m\) stages.

At elapsed time \(s\), total remaining supply is \(1-s\). Moreover,
\[ \Delta \leq \sum_{g:a_g>0}a_g\frac{r_g}{a_g} = \sum_{g:a_g>0}r_g \leq 1-s. \]
Consequently the construction never passes time one. Upon termination all supply is exhausted, so termination occurs exactly at time one. Define
\[ x^*_{tg}=z_{tg}(1). \]
Then
\[ \sum_g x^*_{tg}=\mu_t, \qquad \sum_t x^*_{tg}=q_g. \]

2. Convergence of finite RSD to this allocation

Fix an admissible \(N\). After the first \(k\) agents in the random permutation have acted, let \(B_t^{(N)}(k)\) be the number of those agents of type \(t\).

Define \(F_t^{(N)}(s)\) by linearly interpolating \(B_t^{(N)}(k)/N\) at times \(s=k/N\). Likewise, let \(Y_{tg}^{(N)}(s)\) interpolate the normalized cumulative assignments. In particular,
\[ Y_{tg}^{(N)}(1)=\frac{A_{tg}^{(N)}}N. \]
Every coordinate of these processes is nondecreasing and \(1\)-Lipschitz, and
\[ \sum_gY_{tg}^{(N)}(s)=F_t^{(N)}(s), \qquad \sum_{t,g}Y_{tg}^{(N)}(s)=s. \]

Uniform convergence of type arrivals

For a fixed prefix length \(k\), the variable \(B_t^{(N)}(k)\) is hypergeometric. Hence
\[ \mathbb E[B_t^{(N)}(k)]=k\mu_t, \qquad \operatorname{Var}(B_t^{(N)}(k))\leq N. \]
Chebyshev’s inequality therefore gives convergence in probability of normalized counts to their means at each fixed time; interpolation contributes at most \(1/N\).

To obtain uniform convergence, fix a finite grid of mesh at most \(\delta\). A union bound gives convergence simultaneously at its grid points. Between grid points, both \(F_t^{(N)}\) and \(s\mapsto\mu_ts\) are \(1\)-Lipschitz, so the error increases by at most \(2\delta\). First letting \(N\) tend to infinity and then letting \(\delta\) tend to zero proves
\[ \max_t\sup_{0\leq s\leq1} \left|F_t^{(N)}(s)-\mu_ts\right| \xrightarrow{\mathbb P}0. \]

Identification of every possible assignment limit

Consider any deterministic sequence of permutation realizations along which the preceding arrival error tends to zero. The assignment paths are uniformly bounded and uniformly Lipschitz. By the Arzelà–Ascoli theorem, every subsequence has a further subsequence converging uniformly to a path \(y\).

Its coordinates are nondecreasing and Lipschitz, and
\[ \sum_g y_{tg}(s)=\mu_ts, \qquad r_g(s):=q_g-\sum_t y_{tg}(s)\geq0, \qquad \sum_g r_g(s)=1-s. \]

We now determine its derivatives, which exist almost everywhere.

If \(r_g(s)=0\), monotonicity and feasibility imply that every coordinate \(y_{tg}\) remains constant thereafter. Thus exhausted items receive no further allocation, apart from irrelevant individual exhaustion times.

Next suppose \(t\) ranks \(g\) above \(h\). On any closed interval contained in the open set where \(r_g>0\), uniform convergence ensures that item \(g\) remains available throughout the corresponding finite processes, for all sufficiently large \(N\). RSD therefore makes no assignments of \(h\) to type \(t\) on that interval. Consequently \(y_{th}\) is locally constant wherever a better-ranked item has positive remaining supply.

For \(s<1\), at least one item has positive remaining supply because their total remaining supply is \(1-s\). Let \(h_t(s)\) be type \(t\)’s highest-ranked such item. The preceding observations eliminate every other item from its allocation derivative. Differentiating the row identity therefore yields, almost everywhere,
\[ y'_{tg}(s)= \begin{cases} \mu_t,&g=h_t(s),\\ 0,&g\neq h_t(s). \end{cases} \]

These equations uniquely determine the path. Indeed, between consecutive exhaustion times the available set is fixed, so all rates are fixed. The next exhaustion occurs after exactly the minimum residual-supply-to-rate ratio from Section 1. Removing all items exhausted at that time and repeating determines the entire path in at most \(m\) stages. Thus \(y=z\).

It follows that whenever type-arrival errors tend to zero, the assignment paths converge uniformly to \(z\): otherwise a subsequence staying a positive distance away would have a uniformly convergent further subsequence, whose limit was just proved to equal \(z\).

Combining this deterministic implication with arrival convergence gives
\[ Y_{tg}^{(N)}(1)\xrightarrow{\mathbb P}x^*_{tg}. \]
For completeness, failure of this implication in probability would allow us to select realizations with arbitrarily small arrival error but assignment error bounded away from zero, contradicting the preceding compactness argument.

Finally, these normalized assignment variables lie in \([0,1]\). For every \(\varepsilon>0\),
\[ \mathbb E\left|Y_{tg}^{(N)}(1)-x^*_{tg}\right| \leq \varepsilon+ \Pr\left(\left|Y_{tg}^{(N)}(1)-x^*_{tg}\right|>\varepsilon\right). \]
Therefore
\[ \lim_{\substack{N\to\infty\\N\text{ admissible}}} \frac{\mathbb E[A_{tg}^{(N)}]}N =x^*_{tg}. \]
This proves existence and identifies the requested limits.

3. Exact computation and polynomial bit complexity

The stage construction already gives an exact rational algorithm. The remaining issue is whether its intermediate numbers have polynomial bit length.

Let \(D\) be the product of the input denominators of the masses, and \(E\) the product of the input denominators of the supplies. Write
\[ \mu_t=\frac{M_t}{D}, \qquad q_g=\frac{Q_g}{E}. \]
Then
\[ \sum_t M_t=D, \qquad \sum_g Q_g=E, \qquad \log_2D+\log_2E=O(L). \]
The products themselves may be large, but their binary encodings have polynomial length.

Maintain a common denominator \(H\) for every residual supply, allocation entry, and elapsed time:
\[ r_g=\frac{R_g}{H}, \qquad z_{tg}=\frac{Z_{tg}}H, \qquad s=\frac UH. \]
Initially take \(H=ED\), \(R_g=DQ_g\), and all allocation and time numerators zero.

At a stage, put
\[ K_g=\sum_{t:h_t(S)=g}M_t, \qquad a_g=\frac{K_g}{D}. \]
Choose an item \(e\) minimizing \(R_g/K_g\) among those with \(K_g>0\). Then
\[ \Delta=\frac{DR_e}{HK_e}. \]
Using the new denominator \(H'=HK_e\), the exact updates are
\[ R'_g=K_eR_g-K_gR_e, \]
\[ Z'_{tg}= \begin{cases} K_eZ_{tg}+M_tR_e,&g=h_t(S),\\ K_eZ_{tg},&g\neq h_t(S), \end{cases} \]
and
\[ U'=K_eU+DR_e. \]
All comparisons use integer cross multiplication. No rounding is required.

Since \(1\leq K_e\leq D\), after at most \(m\) stages,
\[ H\leq ED^{m+1}. \]
Every represented residual, allocation, and elapsed time belongs to \([0,1]\), so its nonnegative numerator is at most \(H\). Thus all stored integers have
\[ O\bigl(1+\log E+(m+1)\log D\bigr) = O\bigl(1+(m+1)L\bigr) \]
bits. Products used in comparisons and updates also have polynomial bit length.

A straightforward implementation scans the listed rankings and updates the allocation matrix at each stage, using \(O(\tau m^2)\) arithmetic operations overall. Standard exact integer arithmetic therefore gives polynomial bit complexity in \(m,\tau,L\).

The algorithm uses only the \(\tau\) listed positive-mass types. It neither enumerates unlisted rankings nor constructs any replicated finite society.

4. Welfare, cost, and the metric promise

Having computed \(x=x^*\), calculate the applicable aggregate by exact rational arithmetic:
\[ W=\sum_{t,g}x_{tg}v_t(g), \qquad C=\sum_{t,g}x_{tg}c_t(g). \]
There are \(\tau m\) terms. A common denominator can be obtained by multiplying the final allocation denominator by the input denominators of the applicable cardinal data. Its bit length is polynomial, because those input denominators have total bit length at most \(L\). Numerators likewise have polynomial length. Hence the aggregate is exactly computable in polynomial time.

The cost algorithm needs only the supplied costs and rankings. It therefore applies to every input satisfying the metric promise without reconstructing the metric space. Equal values or costs cause no ambiguity because the supplied strict rankings determine every choice.

The cited finite-instance hardness concerns exact expectations before replication and passage to the limit. It does not prevent the limiting quantities proved here from having polynomial-time exact algorithms. See [Caragiannis–Homrighausen](https://arxiv.org/abs/2405.14316).
