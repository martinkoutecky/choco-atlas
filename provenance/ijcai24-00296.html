Packaged proof task (what the prover saw — nothing else)

Given a finite project set \(P\), explicitly listed nonzero rational masses \(\mu_A\ge 0\) for approval types \(A\subseteq P\), with \(\sum_A\mu_A=1\), unit project costs, budget \(B=1\), and tie-breaking order \(\prec\), AV funds the first project in nonincreasing approval score \(s(q)=\sum_{A i q}\mu_A\), breaking ties by \(\prec\).

For a currently losing project \(p\), a change chooses \(z_A\in[0,\mu_A]\) for each \(A\supsetneq\{p\}\), replaces mass \(z_A\) of type \(A\) by type \(\{p\}\), and has cost \(\sum_A z_A\).

Target. Given rational \(r\), is deciding whether a change of cost at most \(r\) makes AV fund \(p\) NP-hard or solvable in polynomial time?

Nearest known results. For finite electorates, deciding whether changing at most \(\ell\) voters who approve \(p\) to approve only \(p\) makes \(p\) win is NP-complete, even with \(B=1\) and unit-cost projects. No result for the exact rational-mass version above was verified.

Prover output (gpt-5.6-sol / xhigh, Bolzano prover prompt)

Polynomial-Time Solvability

Theorem

The decision problem is solvable in polynomial time by rational linear programming.

Throughout, write \(q\prec p\) when \(q\) has tie-breaking priority over \(p\). Thus, if \(q\prec p\) and \(q\) ties \(p\), then \(q\) is funded instead of \(p\).

1. Effect of a change on approval scores

Let

\[ \mathcal T_p=\{A\subseteq P:\mu_A>0\text{ and }\{p\}\subsetneq A\}. \]

For \(A\in\mathcal T_p\), moving mass \(z_A\) from \(A\) to \(\{p\}\) does not change the score of \(p\): the moved mass approves \(p\) both before and after the change. Hence

\[ s_z(p)=s(p). \]

For every \(q\ne p\), define its score reduction by

\[ D_q(z)=\sum_{\substack{A\in\mathcal T_p\\q\in A}}z_A. \]

The resulting score of \(q\) is therefore

\[ s_z(q)=s(q)-D_q(z). \]

All these expressions are linear in the variables \(z_A\).

2. Exact winning conditions

Partition the other projects into

\[ E=\{q\in P\setminus\{p\}:q\prec p\} \]

and

\[ L=P\setminus(E\cup\{p\}). \]

For \(q\in E\), a tie is insufficient for \(p\), so \(p\) must satisfy

\[ s_z(q)<s(p). \]

Equivalently,

\[ D_q(z)>s(q)-s(p). \]

For \(q\in L\), \(p\) wins a tie, so the required condition is

\[ s_z(q)\le s(p), \]

equivalently,

\[ D_q(z)\ge s(q)-s(p). \]

Thus a change makes \(p\) win exactly when it satisfies these inequalities together with

\[ 0\le z_A\le\mu_A \]

for every \(A\in\mathcal T_p\), and

\[ \sum_{A\in\mathcal T_p}z_A\le r. \]

Negative right-hand sides cause no difficulty because every \(D_q(z)\) is nonnegative.

3. Handling the strict inequalities

Suppose first that \(E\ne\varnothing\). Introduce a common slack variable \(\delta\) and solve the rational linear program maximizing \(\delta\) subject to:

  • \(0\le z_A\le\mu_A\) for every \(A\in\mathcal T_p\);
  • \(\sum_{A\in\mathcal T_p}z_A\le r\);
  • \(D_q(z)\ge s(q)-s(p)+\delta\) for every \(q\in E\);
  • \(D_q(z)\ge s(q)-s(p)\) for every \(q\in L\);
  • \(0\le\delta\le 2\).

The upper bound \(2\) is harmless: scores and score reductions lie in \([0,1]\), so every possible strict slack is at most \(2\).

Let the optimum be \(\delta^\star\), with an infeasible program interpreted as rejection.

Lemma

There exists a change of cost at most \(r\) making \(p\) win if and only if the linear program is feasible and \(\delta^\star>0\).

Proof

Assume first that \(z\) makes \(p\) win. For every \(q\in E\),

\[ D_q(z)-\bigl(s(q)-s(p)\bigr)>0. \]

Because \(E\) is finite, the minimum

\[ \delta_0=\min_{q\in E}\left(D_q(z)-s(q)+s(p)\right) \]

is strictly positive. Therefore \((z,\delta_0)\) is feasible for the linear program. Consequently \(\delta^\star\ge\delta_0>0\).

Conversely, suppose the program has a feasible solution with \(\delta>0\). For every \(q\in E\),

\[ D_q(z)\ge s(q)-s(p)+\delta>s(q)-s(p), \]

so \(s_z(q)<s(p)\). For every \(q\in L\), the non-strict constraints give \(s_z(q)\le s(p)\). Hence no project has higher priority than \(p\) among projects attaining the maximum score, and AV funds \(p\). The cost and mass bounds are also satisfied. This proves the equivalence. \(\square\)

If \(E=\varnothing\), no strict inequality is needed. It suffices to test feasibility of the same system without \(\delta\) and without the constraints indexed by \(E\).

4. Running time

Let \(t\) be the number of explicitly listed positive-mass types and let \(m=|P|\). The linear program has at most \(t+1\) variables and \(O(t+m)\) constraints.

Its coefficients consist of:

  • incidence coefficients in \(\{0,1\}\);
  • the input rationals \(\mu_A\) and \(r\);
  • scores \(s(q)\), each obtained by adding explicitly listed rational masses.

The binary encoding length of every computed score is polynomial in the total input length. Therefore the constructed linear program has polynomial encoding length.

Rational linear-program feasibility and optimization, including exact comparison of the rational optimum with \(0\), are solvable in time polynomial in the number of variables, number of constraints, and coefficient encoding length. All hypotheses of that result are satisfied here.

5. Conclusion

The rational-mass problem belongs to \(\mathrm P\). The finite-electorate NP-hardness does not transfer because changing an individual voter is an indivisible decision, whereas the present variables \(z_A\) allow arbitrary fractional portions of every type mass. This removes the relevant integrality constraint and leaves a linear program.
