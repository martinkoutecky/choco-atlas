The continuous mirror question, as graded

Given indivisible goods \(G\), two groups, a distribution \(\mu\) over exactly two complete additive-utility types in group \(1\) and one type in group \(2\), and rational positive masses, define \(M_\theta=\max_{G=B_1\dot\cup B_2}\min\{u_\theta(B_1),u_\theta(B_2)\}\). Compute or approximate the maximum \(\lambda(\mu)=\max_{G_1\dot\cup G_2=G}\min_{\mu_{i,\theta}>0}u_\theta(G_i)/M_\theta\), in particular deciding whether \(\lambda(\mu)\ge 2/3\).

Packaged proof task (what the prover saw — nothing else)

Let \(G\) consist of \(m\) indivisible goods. There are two groups: group \(1\) has exactly two additive utility types and group \(2\) exactly one. Each type specifies a nonnegative binary-rational value for every good; assume its two-bundle maximin share is positive.
A society is given by its support: the list of the \(\tau\) group–type pairs with positive mass, each mass a binary rational, with masses summing to \(1\). Here \(\tau=3\) is the support size, not the number of possible types. Let \(L\) be the total input bit length.
An allocation is a complete partition \(G=G_1\dot\cup G_2\); every member of group \(i\) evaluates the entire bundle \(G_i\). Goods and group bundles cannot be divided among types.
For each supported type \(\theta\), define \(M_\theta=\max_{G=B_1\dot\cup B_2}\min\{u_\theta(B_1),u_\theta(B_2)\}\), and define \(\lambda(\mu)=\max_{G=G_1\dot\cup G_2}\min_{(i,\theta)\in\operatorname{supp}(\mu)}u_\theta(G_i)/M_\theta\).

What is the sharp universal maximin-share approximation factor \(\alpha\) such that every such society admits an allocation with \(u_\theta(G_i)\ge\alpha M_\theta\) for every supported \((i,\theta)\), and can that factor be guaranteed by an algorithm polynomial in \(m,\tau,L\)?

For discrete groups of sizes \((2,1)\), a polynomial-time algorithm guarantees \(2/3\), while some instances admit no factor exceeding \(3/4\). [Source](https://arxiv.org/pdf/1706.09869)
These bounds also apply to the stated mass model: its objective depends only on the three supported group–type pairs. In particular, deciding whether \(\lambda(\mu)\ge2/3\) is already settled affirmatively.

Modeling choices made when packaging the task

  • Specified nonnegative binary-rational per-good utilities, following the additive nonnegative utility domain and making computational input finite.
  • Normalized the distribution over group–type pairs to total mass one; support entries include group membership.
  • Required positive maximin shares so that the graded question's ratios are defined; zero-share requirements would otherwise be vacuous.
  • Specified that each group receives one shared indivisible bundle, with no splitting or randomization across its types.

Result

The sharp universal factor is \(\alpha=2/3\), and it can be guaranteed in time polynomial in \(m,\tau,L\).

The following four-good instance improves the stated upper bound from \(3/4\) to \(2/3\).

A sharp counterexample

Let \(G=\{g_1,g_2,g_3,g_4\}\), with valuations

| Supported type | \(g_1\) | \(g_2\) | \(g_3\) | \(g_4\) | Mass |
|---|---:|---:|---:|---:|---:|
| Group \(1\), type \(a\) | \(3\) | \(1\) | \(1\) | \(1\) | \(1/4\) |
| Group \(1\), type \(b\) | \(1\) | \(3\) | \(1\) | \(1\) | \(1/4\) |
| Group \(2\), type \(c\) | \(2\) | \(2\) | \(1\) | \(1\) | \(1/2\) |

All values and masses are nonnegative binary rationals, all three masses are positive, and they sum to \(1\).

Maximin shares. Each type values the whole set at \(6\), so its two-bundle maximin share is at most \(3\). The following partitions give both bundles value \(3\) to the indicated type:

  • Type \(a\): \(\{g_1\}\) and \(\{g_2,g_3,g_4\}\).
  • Type \(b\): \(\{g_2\}\) and \(\{g_1,g_3,g_4\}\).
  • Type \(c\): \(\{g_1,g_3\}\) and \(\{g_2,g_4\}\).

Consequently, \(M_a=M_b=M_c=3\).

Impossibility above \(2/3\). Write \(S=G_1\), so \(G_2=G\setminus S\). We prove that some supported type receives utility at most \(2\).

If \(u_a(S)\le 2\) or \(u_b(S)\le 2\), this already holds. Otherwise, both utilities exceed \(2\). There are three exhaustive cases:

  • If \(g_1,g_2\in S\), then \(G_2\subseteq\{g_3,g_4\}\), giving \(u_c(G_2)\le 2\).
  • If \(g_1\notin S\), every good in \(S\) is worth \(1\) to \(a\). Thus \(u_a(S)>2\) forces \(S=\{g_2,g_3,g_4\}\), giving \(u_c(G_2)=u_c(\{g_1\})=2\).
  • If \(g_1\in S\) and \(g_2\notin S\), every good in \(S\) is worth \(1\) to \(b\). Thus \(u_b(S)>2\) forces \(S=\{g_1,g_3,g_4\}\), again giving \(u_c(G_2)=2\).

Since every maximin share equals \(3\), no allocation achieves a factor exceeding \(2/3\). Conversely, \(G_1=\{g_1,g_2\}\), \(G_2=\{g_3,g_4\}\) gives utilities \((4,4,2)\), so this instance has \(\lambda(\mu)=2/3\).

Universal guarantee and polynomial running time

The given discrete theorem guarantees a \(2/3\)-MMS allocation for nonnegative additive valuations with group sizes \((2,1)\). Its maximin shares use two bundles, exactly as here. Representing each supported pair by one agent therefore preserves every constraint and the objective; positive masses impose no additional conditions. [Suksompong, Theorem 1](https://arxiv.org/pdf/1706.09869).

The cited algorithm normalizes utilities by their totals, handles goods worth at least \(1/3\), and then uses greedy round robin. It requires no exact maximin-share computation. A scanning implementation uses \(O(\tau m^2)\) comparisons and rational arithmetic operations. Totals and normalized values have bit length polynomial in \(L\), so these operations take polynomial bit time.

Thus the universal guarantee and the counterexample match: \(\alpha=2/3\), with a polynomial-time algorithm attaining it.
