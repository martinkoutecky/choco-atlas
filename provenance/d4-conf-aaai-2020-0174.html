Theorem 2 — class: algorithmic

The continuous mirror question, as graded

Given a finite item set \(X\), a slate size \(k\), type utilities \(u_t\), response models \(R(r\mid q,t)\), and rational type masses \(\mu_t\) summing to \(1\), apply one common slate \(q=(x_1,\ldots,x_k)\) to the cohort and recommend to each member according to that member's response. For each response \(r\), let \(p_r=\sum_t\mu_tR(r\mid q,t)\) and \(V_\mu(q)=\sum_r\max_{y\in X}\sum_t\mu_tR(r\mid q,t)u_t(y)\). If each \(x_i\) is replaced by \(y_i^*\in\arg\max_{y\in X}\sum_t\mu_tR(x_i\mid q,t)u_t(y)\), does the resulting slate \(q'\) satisfy \(V_\mu(q')\ge V_\mu(q)\) for noiseless responses and the Theorem 2 lower bound \(V_\mu(q')\ge V_\mu(q)-\Delta_\mu\) for logistic responses, with its stated noise bound evaluated under \(\mu\)?

Conclusion

The noiseless guarantee always holds. The stated logistic guarantee is false under the permitted negative utilities, even with two supported types, distinct replacement items, and strictly positive \(\Delta_\mu\).

A single supported type with negative maximum utility \(M\) already gives \(V_\mu(q')=V_\mu(q)=M\) and \(\Delta_\mu=(k-1)M<0\). Below is a stronger counterexample, together with a general proof of the noiseless guarantee.

1. Proof of the noiseless guarantee

For each supported type \(t\), let \(c(t)\) be its selected slot in \(q\), and let \(c'(t)\) be its selected slot in \(q'\). Both selections use the specified smallest-slot tie rule.

By the definition of the replacement items,

\(V_\mu(q)=\sum_{i=1}^{k}\sum_t\mu_tR_i(q,t)u_t(y_i^*)=\sum_t\mu_tu_t(y_{c(t)}^*)\).

For each response slot \(j\) of \(q'\), the item \(y_j^*\) is an admissible candidate in the maximization defining \(V_\mu(q')\). Consequently,

\(V_\mu(q')\geq\sum_{j=1}^{k}\sum_t\mu_tR_j(q',t)u_t(y_j^*)=\sum_t\mu_tu_t(y_{c'(t)}^*)\).

Noiseless response on \(q'\) selects a utility-maximizing slot. Therefore, for every \(t\),

\(u_t(y_{c'(t)}^*)=\max_{1\leq j\leq k}u_t(y_j^*)\geq u_t(y_{c(t)}^*)\).

Multiplying by the positive masses and summing proves

\(\boxed{V_\mu(q')\geq V_\mu(q)}\).

This proof permits negative utilities, repeated replacement items, and zero-probability response slots. A zero-probability slot contributes zero to the sums, whatever item the stipulated tie rule assigns to it.

2. An exact logistic counterexample

Admissible input

Take \(m=4\), \(\tau=2\), \(d=2\), \(k=2\), and \(\theta=1\). Order the items as \(A,B,C,D\), with

\(A=(-3/4,-11/4),\quad B=(-11/4,-3/4),\quad C=(1/4,-3/4),\quad D=(-3/4,1/4)\).

Let \(a_1=(1,0)\), \(a_2=(0,1)\), and \(\mu_1=\mu_2=1/2\). Thus:

| Item | \(u_1\) | \(u_2\) |
|---|---:|---:|
| \(A\) | \(-3/4\) | \(-11/4\) |
| \(B\) | \(-11/4\) | \(-3/4\) |
| \(C\) | \(1/4\) | \(-3/4\) |
| \(D\) | \(-3/4\) | \(1/4\) |

Every input coordinate, coefficient, mass, and temperature is rational. The initial slate is \(q=(A,B)\), whose items are distinct.

Define

\(r=\dfrac{e^2}{1+e^2},\qquad s=\dfrac{e}{1+e}\).

We will use

\(r>3/4,\qquad 1/2<s<3/4\).

These inequalities follow from \(2<e<3\): the lower bound follows from the exponential series, while

\(e=2+\sum_{n=2}^{\infty}\dfrac1{n!}<2+\sum_{n=2}^{\infty}\dfrac1{2^{n-1}}=3\),

because \(n!\geq2^{n-1}\), with strict inequality for \(n\geq3\). In particular, \(e^2>4>3\).

Posterior-optimal replacements

The utility differences between \(A\) and \(B\) are \(2\) for type \(1\) and \(-2\) for type \(2\). Hence

\(R_1(q,1)=r,\qquad R_1(q,2)=1-r,\qquad p_1=p_2=1/2\).

The posterior type masses after response \(1\) are therefore \((r,1-r)\).

More generally, under posterior masses \((z,1-z)\), the expected utilities are:

| Item | Posterior expected utility |
|---|---:|
| \(A\) | \(2z-11/4\) |
| \(B\) | \(-3/4-2z\) |
| \(C\) | \(z-3/4\) |
| \(D\) | \(1/4-z\) |

For \(1/2<z<1\), item \(C\) is the unique maximizer: its advantages over \(A,B,D\), respectively, are

\(2-z>0,\qquad 3z>0,\qquad 2z-1>0\).

Applying this with \(z=r\) gives \(y_1^*=C\). Response \(2\) swaps the posterior type masses; swapping the two types also swaps \(A\) with \(B\) and \(C\) with \(D\). Thus \(y_2^*=D\), uniquely.

Consequently,

\(q'=(C,D),\qquad V_\mu(q)=\dfrac12(r-3/4)+\dfrac12(r-3/4)=r-3/4>0\).

In particular, the replacement items are distinct.

Value after replacement

The utility differences between \(C\) and \(D\) are \(1\) and \(-1\). Thus

\(R_1(q',1)=s,\qquad R_1(q',2)=1-s\),

and both response probabilities are again \(1/2\).

The posterior masses after response \(1\) are \((s,1-s)\). Since \(s>1/2\), the same comparison table proves that \(C\) remains the unique posterior-optimal recommendation. By symmetry, \(D\) is optimal after response \(2\). Therefore

\(V_\mu(q')=s-3/4<0\).

Calculation of the stated penalty

For response \(1\) of the original slate, the posterior masses are \((r,1-r)\), so

\(\sum_t\mu_{t\mid1}(1-R_1(q,t))=r(1-r)+(1-r)r=2r(1-r)\).

Its posterior-optimal expected utility is \(r-3/4\). Response \(2\) has the same two factors by symmetry. Hence

\(\Delta_\mu=4r(1-r)(r-3/4)>0\).

Nevertheless,

\(V_\mu(q)-\Delta_\mu=(r-3/4)\bigl(1-4r(1-r)\bigr)=(r-3/4)(2r-1)^2>0\).

Combining this with \(V_\mu(q')<0\) yields the strict violation

\(\boxed{V_\mu(q')<V_\mu(q)-\Delta_\mu}\).

All comparisons are exact; no numerical approximation or precision parameter is needed.

3. Why utility translation matters

The issue is structural. Add the same rational constant \(c\) to every utility. This is representable within the linear model by appending a constant coordinate \(1\) to each item and a coefficient \(c\) to each type vector.

Logistic response probabilities and posterior distributions remain unchanged. Replacement items also remain unchanged, because each candidate score for slot \(i\) increases by the same quantity \(cp_i\). For every slate,

\(V_{\mu,c}(q)=V_\mu(q)+c\).

Write \(\alpha_i=\sum_t\mu_{t\mid i}(1-R_i(q,t))\). The stated penalty transforms as

\(\Delta_{\mu,c}=\Delta_\mu+c\sum_{i=1}^{k}\alpha_i\).

Each \(\alpha_i>0\), since every logistic slot probability lies strictly between \(0\) and \(1\). Thus utility translation leaves the value difference unchanged but changes the proposed penalty. Sufficiently negative rational translations necessarily invalidate such a universal bound.

The displayed logistic assertion does appear in [Theorem 2 of the supplied full version](https://arxiv.org/html/1911.09153#S3.SS4), but the counterexample above disproves it under the hypotheses given here. The noiseless conclusion agrees with [the original Bayesian treatment, Lemma 1](https://papers.nips.cc/paper_files/paper/2010/file/550a141f12de6341fba65b0ad0433500-Paper.pdf). The failure concerns the logistic penalty, rather than the interpretation of the prior masses.
