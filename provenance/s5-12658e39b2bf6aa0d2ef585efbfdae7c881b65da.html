The continuous mirror question, as graded

Given a finite type set \(T\), population masses \(\mu\in\Delta(T)\), item classes \(J=[r]\), rational per-capita supplies \(\beta\in\mathbb{Q}_{\ge0}^r\), and additive values \(v_t(j)\in\{0,1,2\}\), define \(\lambda_t(\beta)\) as the largest \(\lambda\) for which a unit-mass distribution \(y\) over integral bundles \(q\in\mathbb{Z}_{\ge0}^r\) satisfies \(\sum_q y_q=1\), \(\sum_q q_jy_q\le\beta_j\), and \(y_q>0\Rightarrow\sum_jq_jv_t(j)\ge\lambda\). Decide whether, and compute, a mass allocation \(x_{t,q}\ge0\) with \(\sum_qx_{t,q}=\mu_t\), \(\sum_{t,q}q_jx_{t,q}\le\beta_j\), and \(x_{t,q}>0\Rightarrow\sum_jq_jv_t(j)\ge\lambda_t(\beta)\) for every populated type.

Result

Every valid instance is feasible, and an allocation can be computed in polynomial time. Here polynomial time uses binary-encoded rational supplies and masses. For arbitrary real masses, the same construction establishes existence and expresses every output mass as a rational multiple of the corresponding input mass.

The key is the normalization \(\sum_{t\in T}\mu_t=1\): distributions constructed separately for each type can be combined without exceeding supply.

1. Exact single-type threshold

Fix a type, and define

\(A=\{j:v(j)=1\},\qquad B=\{j:v(j)=2\},\qquad a=\sum_{j\in A}\beta_j,\qquad b=\sum_{j\in B}\beta_j.\)

We prove that

\(\boxed{\lambda(\beta)=\min\{\lfloor a+2b\rfloor,\;2\lfloor a+b\rfloor\}.}\)

Classes valued at zero need never be used.

Necessary conditions

For an integral bundle, let \(\displaystyle U=\sum_{j\in A}q_j\) and \(\displaystyle W=\sum_{j\in B}q_j\). Its value is \(U+2W\).

If every supported bundle has value at least an integer \(k\geq0\), then

\(U+2W\geq k,\qquad U+W\geq\lceil k/2\rceil.\)

The second inequality follows because \(2(U+W)\geq U+2W\) and \(U+W\) is integral. Taking expectations and applying the supply constraints gives

\(a+2b\geq k,\qquad a+b\geq\lceil k/2\rceil.\)

These conditions are equivalent to

\(k\leq\min\{\lfloor a+2b\rfloor,\;2\lfloor a+b\rfloor\}.\)

Indeed, \(\lceil k/2\rceil\leq a+b\) is equivalent to \(\lceil k/2\rceil\leq\lfloor a+b\rfloor\), hence to \(k\leq2\lfloor a+b\rfloor\).

Utilities are integers, so feasibility of any real threshold implies feasibility of its ceiling. Consequently, this also bounds the original real-valued optimization.

Sufficiency: an explicit distribution on aggregate bundles

Suppose that an integer \(k\geq0\) satisfies

\(a+2b\geq k,\qquad a+b\geq\lceil k/2\rceil.\)

We construct a distribution on at most two integral pairs \((U,W)\), each of value at least \(k\), with

\(\mathbb E[U]\leq a,\qquad\mathbb E[W]\leq b.\)

Case 1: \(k=0\). Use \((0,0)\) deterministically.

Case 2: \(k>0\) and \(a\geq k\). Use \((k,0)\) deterministically.

For the remaining cases, assume \(a<k\).

Case 3: \(k=2h>0\) is even. Use

  • \((k,0)\) with probability \(a/k\);
  • \((0,h)\) with probability \(1-a/k\).

Both bundles have value \(k\), and

\(\mathbb E[U]=a,\qquad\mathbb E[W]=(k-a)/2\leq b.\)

The last inequality is precisely a consequence of \(a+2b\geq k\).

Case 4: \(k=2h+1\) is odd and \(1\leq a<k\). This case implies \(k\geq3\). Set

\(p=\dfrac{a-1}{k-1}.\)

Use \((k,0)\) with probability \(p\), and \((1,h)\) with probability \(1-p\). Both have value \(k\). Moreover,

\(\mathbb E[U]=pk+(1-p)=1+p(k-1)=a,\)

\(\mathbb E[W]=(1-p)h=\dfrac{k-a}{2}\leq b.\)

Case 5: \(k=2h+1\) is odd and \(0\leq a<1\). Use

  • \((1,h)\) with probability \(a\);
  • \((0,h+1)\) with probability \(1-a\).

Their values are respectively \(k\) and \(k+1\), and

\(\mathbb E[U]=a,\qquad\mathbb E[W]=ah+(1-a)(h+1)=h+1-a\leq b.\)

Here the final inequality follows from \(a+b\geq\lceil k/2\rceil=h+1\). This case also covers \(k=1\).

These cases exhaust all possibilities.

Lifting aggregate bundles to item classes

We must enforce each individual supply constraint, rather than just the two aggregate constraints.

Discard aggregate outcomes of probability zero. For each remaining outcome \((u,w)\):

  • If \(u>0\), choose \(j\in A\) with probability \(\beta_j/a\), and place all \(u\) value-one items in class \(j\).
  • If \(w>0\), independently choose \(\ell\in B\) with probability \(\beta_\ell/b\), and place all \(w\) value-two items in class \(\ell\).
  • Set all other coordinates to zero.

These choices are well-defined. For example, a positive-probability outcome with \(u>0\) implies \(\mathbb E[U]>0\), hence \(a>0\). The same argument applies to \(w\) and \(b\).

Every resulting bundle is integral and has value \(u+2w\geq k\). For each \(j\in A\) with \(a>0\),

\(\displaystyle \mathbb E[q_j]=\frac{\beta_j}{a}\mathbb E[U]\leq\beta_j.\)

If \(a=0\), no value-one items are used. Likewise, for each \(j\in B\) with \(b>0\),

\(\displaystyle \mathbb E[q_j]=\frac{\beta_j}{b}\mathbb E[W]\leq\beta_j.\)

All zero-valued classes have expected consumption zero. Thus the lifted distribution satisfies every supply constraint.

Applying this construction to

\(k=\min\{\lfloor a+2b\rfloor,\;2\lfloor a+b\rfloor\}\)

attains the necessary upper bound, proving the threshold formula.

2. Combining the types

For each type \(t\), perform the preceding construction using its valuation and the same supply vector \(\beta\). Let the resulting distribution be \(y^{(t)}\). We have

\(\displaystyle \sum_q y^{(t)}_q=1,\qquad \sum_q q_jy^{(t)}_q\leq\beta_j,\)

and every bundle in its support has value at least \(\lambda_t(\beta)\) for type \(t\).

Define

\(\displaystyle x_{t,q}=\mu_t y^{(t)}_q.\)

Then the mass constraint for each type holds:

\(\displaystyle \sum_qx_{t,q}=\mu_t\sum_qy^{(t)}_q=\mu_t.\)

For each item class \(j\), total consumption satisfies

\(\displaystyle \sum_{t,q}q_jx_{t,q} =\sum_t\mu_t\sum_q q_jy^{(t)}_q \leq\sum_t\mu_t\beta_j =\beta_j.\)

Finally, \(x_{t,q}>0\) implies \(y^{(t)}_q>0\), so that bundle meets type \(t\)'s threshold. This proves all required allocation properties.

In particular, the feasibility decision always returns yes on inputs satisfying the stated premises.

3. Polynomial-time construction and output size

For each type, the algorithm computes the two rational sums \(a_t,b_t\), evaluates the threshold formula, and constructs at most two aggregate outcomes.

Each aggregate outcome expands to at most \((r+1)^2\) bundles: at most one class is selected from each positive-value group, with no selection needed when its count is zero. Therefore the entire allocation has at most

\(\displaystyle 2|T|(r+1)^2\)

listed type–bundle pairs before merging duplicates. Each bundle uses at most two classes.

For \(k>0\), every bundle coordinate in the construction is at most \(k\). Furthermore,

\(\displaystyle k\leq a_t+2b_t\leq2\sum_j\beta_j,\)

so bundle coordinates have polynomial binary encoding length, even when supplies are numerically large. The construction uses rational sums, products, divisions, and floors on numbers of polynomial encoding length. All probabilities, and all output masses when the input masses are rational, therefore have polynomial encoding length and are computable in polynomial time.

For arbitrary real input masses, the probabilities remain rational and the allocation is represented symbolically by \(\mu_t\) times those probabilities; a bit-complexity claim for unrestricted real inputs would require specifying their encoding.

The supplied finite-agent maximin-share theorem is not needed: the normalized mass formulation admits the direct construction above.
