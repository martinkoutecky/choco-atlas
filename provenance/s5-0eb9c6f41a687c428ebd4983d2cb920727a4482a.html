Theorem 18 — class: algorithmic

The continuous mirror question, as graded

Given finitely many types \(T\) with rational masses \(\mu_t>0\), \(\sum_{t\in T}\mu_t=1\), status-quo efforts \(a_t\in[0,1]\), and explicitly encoded rational concave piecewise-linear utilities \(u_t(e,Q)\) that strictly increase in \(Q\), let \(Q^0=\sum_t\mu_ta_t\). Does there exist a nonempty mass selection \(\lambda_t\in[0,\mu_t]\) and efforts \(b_t\in[0,1]\) such that \(Q'=\sum_t\lambda_tb_t\) and \(u_t(b_t,Q')>u_t(a_t,Q^0)\) for every \(t\) with \(\lambda_t>0\)? Decide whether such a deviation exists, equivalently whether the status quo is outside the core.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a nonempty list \(T\) of \(\tau\) types with positive binary-rational masses \(\mu_t\), where \(\sum_t\mu_t=1\); \(\tau\) counts listed types, not possible types.
Each type has a binary-rational status-quo effort \(a_t\in[0,1]\) and a jointly concave utility \(u_t:[0,1]^2\to[0,1]\), strictly increasing in \(Q\) for each fixed effort \(e\).
Utilities are explicitly encoded as \(u_t(e,Q)=\min_{1\le j\le k_t}(\alpha_{tj}e+\beta_{tj}Q+\gamma_{tj})\), with signed binary-rational coefficients; let \(m=\sum_t k_t\) and let \(L\) be the total input bit length.
Set \(Q^0=\sum_t\mu_ta_t\). A deviation chooses real masses \(0\le\lambda_t\le\mu_t\) with \(\sum_t\lambda_t>0\), and real efforts \(b_t\in[0,1]\), common to selected members of each type.
Unselected mass contributes zero; the resulting public good is \(Q'=\sum_t\lambda_tb_t\). Every selected type must satisfy \(u_t(b_t,Q')>u_t(a_t,Q^0)\). The status quo is in the core exactly when no such deviation exists.

Is deciding whether a deviation exists in \(\mathrm{P}\), with running time polynomial in \(m,\tau,L\), or is it \(\mathrm{NP}\)-hard?

For \(n\) individual agents with concave utilities and strict positive externalities, core membership has a real-RAM algorithm using \(O(n)\) convex optimization problems and \(O(n)\) additional computation. [Bodwin (2017)](https://drops.dagstuhl.de/opus/volltexte/2017/7491/pdf/LIPIcs-ICALP-2017-45.pdf)
No result settling this exact continuous mass-selection problem was located in the literature search.

Modeling choices made when packaging the task

  • Required status-quo efforts to be binary rationals, completing the finite input encoding.
  • Specified the utility domain as the full effort–public-good square and retained the source model's utility normalization to [0,1].
  • Made the piecewise-linear encoding explicit as a list of rational affine pieces whose minimum defines the utility; m counts all listed pieces.
  • Interpreted nonempty selection as strictly positive total selected mass, with real selection masses and real deviation efforts.
  • Made explicit that selected members of each type share their type's deviation effort and that unselected mass contributes zero.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Result. Deciding whether a deviation exists is in $\mathrm{P}$, with bit running time polynomial in $m,\tau,L$. A direct algorithm uses at most $2\tau+1$ rational linear programs. The proof below handles strict improvement and all boundary cases exactly.

1. Baseline utilities and eligibility thresholds

Write
$$ v_t=u_t(a_t,Q^0), \qquad Q^0=\sum_{t\in T}\mu_ta_t. $$
These are rational numbers computable exactly from the input.

For each type $t$, define its *weak eligibility threshold*
$$ r_t=\min\left\{q\in[0,1]: \text{there exists }e\in[0,1]\text{ with }u_t(e,q)\ge v_t \right\}. $$
The minimum exists: the feasible set is closed, bounded, and nonempty, since it contains $(a_t,Q^0)$. In particular, $r_t\le Q^0$.

The threshold is the optimum of the following rational linear program in two variables:
$$ \begin{aligned} \text{minimize}\quad &q\\ \text{subject to}\quad &0\le e\le1,\qquad 0\le q\le1,\\ &\alpha_{tj}e+\beta_{tj}q+\gamma_{tj}\ge v_t &&\text{for }1\le j\le k_t. \end{aligned} $$
The affine inequalities are equivalent to $u_t(e,q)\ge v_t$ because the utility is their minimum.

The essential threshold property is:
$$ \boxed{ \text{For }q\in(0,1],\quad \exists e\in[0,1]\text{ with }u_t(e,q)>v_t \quad\Longleftrightarrow\quad q>r_t. } $$

To prove the forward implication, suppose $u_t(e,q)>v_t$ with $q>0$. The utility is continuous, being the minimum of finitely many affine functions. Therefore there is some $q'\in[0,q)$ sufficiently close to $q$ such that $u_t(e,q')>v_t$. Consequently,
$$ r_t\le q'<q. $$

For the reverse implication, let $e_t^*$ attain weak eligibility at $r_t$, so that $u_t(e_t^*,r_t)\ge v_t$. If $q>r_t$, strict increase in the public good gives
$$ u_t(e_t^*,q)>u_t(e_t^*,r_t)\ge v_t. $$
This proves the property, including the exclusion of a type at its positive threshold.

For $q>0$, define
$$ A(q)=\{t\in T:r_t<q\}. $$
Thus $A(q)$ is exactly the set of types that could strictly improve at public-good level $q$.

2. Eliminating the mass variables

We next prove an equivalence that removes the bilinear products $\lambda_tb_t$.

Lemma. For any fixed $q\in(0,1]$, a deviation producing public good $q$ exists if and only if there are efforts $b_t\in[0,1]$ for every $t\in A(q)$ such that
$$ u_t(b_t,q)>v_t \quad\text{for every }t\in A(q), \qquad \sum_{t\in A(q)}\mu_tb_t\ge q. $$

*Proof.* First suppose a deviation exists, and let
$$ C=\{t\in T:\lambda_t>0\}. $$
Every selected type strictly improves at $q$, so the threshold property implies $C\subseteq A(q)$.

Retain the deviation effort for each $t\in C$. For each $t\in A(q)\setminus C$, choose any strictly improving effort, which exists by eligibility. All these efforts are nonnegative, and $\lambda_t\le\mu_t$. Hence
$$ \sum_{t\in A(q)}\mu_tb_t \ge \sum_{t\in C}\mu_tb_t \ge \sum_{t\in C}\lambda_tb_t =q. $$

Conversely, suppose the displayed conditions hold and put
$$ S=\sum_{t\in A(q)}\mu_tb_t. $$
Since $S\ge q>0$, the number $\rho=q/S$ satisfies $0<\rho\le1$. Choose
$$ \lambda_t= \begin{cases} \rho\mu_t,&t\in A(q),\\ 0,&t\notin A(q). \end{cases} $$
These masses satisfy $0\le\lambda_t\le\mu_t$, and
$$ \sum_{t\in T}\lambda_tb_t=\rho S=q. $$
Because $S>0$, the set $A(q)$ is nonempty, and its total selected mass is positive. Every selected type strictly improves at the resulting public-good level $q$. Thus this is a deviation. $\square$

The lemma permits the capacity inequality to hold with equality; no unattained supremum is used.

3. Partitioning the public-good levels

Sort the distinct values in
$$ \{0,1\}\cup\{r_t:t\in T\} $$
as
$$ 0=c_0<c_1<\cdots<c_h=1. $$
There are at most $\tau+2$ distinct values, so $h\le\tau+1$.

The intervals
$$ (c_i,c_{i+1}], \qquad 0\le i<h, $$
partition $(0,1]$. On each interval, the eligible set is constant and equals
$$ A_i=\{t\in T:r_t\le c_i\}. $$

Indeed, if $r_t\le c_i$ and $q>c_i$, then $r_t<q$. Otherwise, because no threshold lies strictly between consecutive $c_i$ and $c_{i+1}$, we have $r_t\ge c_{i+1}\ge q$, making the type ineligible. This also explains why the intervals include their upper endpoints and exclude their lower endpoints.

4. An exact linear program for each interval

For each $i$ with $A_i\ne\varnothing$, solve the following LP, with variables $q,\delta$, and $b_t$ for $t\in A_i$:
$$ \begin{aligned} \text{maximize}\quad &\delta\\ \text{subject to}\quad &0\le\delta\le1,\\ &c_i+\delta\le q\le c_{i+1},\\ &0\le b_t\le1 &&\text{for }t\in A_i,\\ &\alpha_{tj}b_t+\beta_{tj}q+\gamma_{tj}\ge v_t+\delta &&\text{for }t\in A_i,\ 1\le j\le k_t,\\ &\sum_{t\in A_i}\mu_tb_t\ge q. \end{aligned} $$
Declare the interval successful precisely when the LP is feasible and its optimum is strictly positive. Intervals with $A_i=\varnothing$ cannot produce a positive public good and are skipped.

We claim:
$$ \boxed{ \text{A deviation with }q\in(c_i,c_{i+1}] \text{ exists} \quad\Longleftrightarrow\quad \text{the interval LP has positive optimum}. } $$

If the LP has a feasible solution with $\delta>0$, then $q>c_i$, and every affine piece of each selected utility is at least $v_t+\delta$. Thus
$$ u_t(b_t,q)\ge v_t+\delta>v_t. $$
Together with the capacity inequality, the lemma constructs a deviation.

Conversely, suppose such a deviation exists. The lemma provides strictly improving efforts for every $t\in A_i$ satisfying the capacity inequality. Since $A_i$ is finite and nonempty,
$$ \eta=\min_{t\in A_i}\bigl(u_t(b_t,q)-v_t\bigr)>0. $$
Choose
$$ \delta=\frac12\min\{1,q-c_i,\eta\}>0. $$
Then $c_i+\delta\le q$. Moreover, every affine piece is at least its minimum, so
$$ \alpha_{tj}b_t+\beta_{tj}q+\gamma_{tj} \ge u_t(b_t,q) \ge v_t+\eta \ge v_t+\delta. $$
All LP constraints hold, establishing positive optimum.

5. Deviations producing zero public good

It remains to handle $q=0$. Since every $\lambda_tb_t$ is nonnegative,
$$ \sum_t\lambda_tb_t=0 $$
forces $b_t=0$ for every selected type. Consequently, a zero-public-good deviation exists exactly when
$$ u_t(0,0)>v_t $$
for at least one type $t$.

Necessity follows from strict improvement for any selected type. For sufficiency, select the full mass of that one type at effort zero. This condition is checked by exact rational comparisons.

6. Correctness and bit complexity

The algorithm computes $Q^0,v_t,r_t$, checks the zero-public-good condition, and then tests the interval LPs. It returns “deviation exists” if and only if one of these tests succeeds.

The preceding equivalences prove correctness: every deviation has public-good level in $[0,1]$, because
$$ 0\le\sum_t\lambda_tb_t\le\sum_t\mu_t=1. $$
Level zero is handled separately, and every positive level belongs to exactly one tested interval.

For running time:

  • There are $\tau$ threshold LPs, each with two variables and $k_t+4$ inequalities.
  • There are at most $\tau+1$ interval LPs, each with at most $\tau+2$ variables and $O(m+\tau)$ inequalities.
  • All baseline values have bit length polynomial in $L$, by exact rational arithmetic.
  • Each threshold also has polynomial bit length: its bounded rational feasible polytope has an optimal vertex, whose coordinates satisfy a nonsingular two-variable rational linear system.
  • Therefore every interval LP has encoding length polynomial in $m,\tau,L$.

We use the standard polynomial-time solvability theorem for rational linear programming: feasibility and exact optimization can be performed in time polynomial in the encoded instance size. Its bit-complexity formulation and rational solution bounds are covered in [Goemans’s linear-programming notes](https://ocw.mit.edu/courses/6-854j-advanced-algorithms-fall-2008/908fe54d659623efadda2d033b895caf_notes_lp.pdf). All our feasible LPs are bounded, so the theorem applies directly, including exact comparison of the optimum with zero.

Thus the complete decision procedure runs in time polynomial in $m,\tau,L$. It can also construct a deviation using the mass-scaling formula in Section 2.
