Theorem 4 — class: other

The continuous mirror question, as graded

Given \(m\) candidates and a finite support of \(\tau\) strict-ranking types with positive rational masses \(\mu_t\) summing to \(1\), and with no pairwise majority ties, does the induced majority tournament contain a directed cycle?

Packaged proof task (what the prover saw — nothing else)

Given a candidate set \(C\) with \(m\geq 1\), a society is specified by its support: \(\tau\) distinct strict total rankings \(\succ_t\) of \(C\), each with a positive binary rational mass \(\mu_t\), where \(\sum_{t=1}^{\tau}\mu_t=1\). Here \(\tau\) is the support size, not the number of possible rankings.
For distinct candidates \(x,y\), put \(w(x,y)=\sum_{t:x\succ_t y}\mu_t\). Assume \(w(x,y)\neq \tfrac12\) for every pair. The majority tournament has an edge \(x\to y\) exactly when \(w(x,y)>\tfrac12\).
The decision problem asks whether this tournament contains a directed cycle. Let \(L\) be the total binary input length; state running times in \(m,\tau,L\).

Is this decision problem in \(\mathrm{P}\), or is it \(\mathrm{NP}\)-hard?

For finite electorates of odd size with strict rankings, Elsholtz and List (2005) establish a necessary and sufficient condition for a majority cycle in terms of the six ranking counts on some triple of candidates. This is a structural characterization, with no complexity classification stated.

Modeling choices made when packaging the task

  • The unspecified domain of the candidate count is taken to be positive integers; instances with fewer than three candidates remain allowed.
  • L is defined as the total binary input length, including the rankings and rational masses.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Classification

The problem is in \(\mathrm{P}\). We can compute the majority tournament using exact integer arithmetic and then test it for a directed cycle. A conservative running-time bound is \(O(m^{2}\tau L^{2})\) bit operations.

Thus, under polynomial-time many-one reductions, this problem could be \(\mathrm{NP}\)-hard only if \(\mathrm{P}=\mathrm{NP}\).

1. Compute every majority edge exactly

Write each input mass as \(\mu_t=p_t/q_t\), where \(p_t,q_t\) are positive integers encoded in binary. This also covers dyadic rational encodings by taking \(q_t\) to be the corresponding power of two.

Define
\[ D=\prod_{t=1}^{\tau}q_t, \qquad a_t=p_t\frac{D}{q_t}. \]
Then \(a_t\) is a positive integer, \(\mu_t=a_t/D\), and the hypothesis that the masses sum to one gives
\[ \sum_{t=1}^{\tau}a_t=D. \]

For distinct candidates \(x,y\), compute
\[ B(x,y)=\sum_{t:x\succ_t y}a_t. \]
Consequently,
\[ w(x,y)=\frac{B(x,y)}{D}, \qquad x\to y \quad\Longleftrightarrow\quad 2B(x,y)>D. \]
These comparisons are exact. The no-ties hypothesis ensures that precisely one direction is selected for each unordered pair.

To evaluate ranking comparisons efficiently, first record the position of each candidate in each input ranking. Then \(x\succ_t y\) holds exactly when the recorded position of \(x\) is smaller than that of \(y\).

2. Test the resulting graph for a cycle

Apply the following procedure to the computed tournament:

  • Compute every vertex’s indegree.
  • Repeatedly remove a vertex of current indegree zero, updating the indegrees of its remaining out-neighbors.
  • Answer “no cycle” if all vertices are removed; otherwise answer “cycle.”

Here is a complete correctness argument.

If the graph contains a directed cycle, none of its vertices can be the first cycle vertex removed: its predecessor on the cycle would still be present and would supply an incoming edge. Therefore the procedure cannot remove all vertices.

Conversely, suppose the procedure stops with a nonempty set of vertices. Every remaining vertex has an incoming edge from another remaining vertex. Start with any remaining vertex \(v_0\), and repeatedly choose \(v_{i+1}\) such that \(v_{i+1}\to v_i\). Since the remaining vertex set is finite, some vertex repeats. Taking the segment up to the first repetition gives distinct vertices forming a directed cycle, with the edges followed in reverse index order.

Thus the procedure answers “cycle” exactly when the majority tournament contains a directed cycle. For \(m=1\), it removes the sole vertex and correctly answers “no cycle.”

3. Binary running time

The use of rational masses does not require arithmetic of exponential bit length. Indeed,
\[ \log_2 D=\sum_{t=1}^{\tau}\log_2 q_t=O(L). \]
Furthermore, \(a_t\leq D\), and every partial sum used to compute \(B(x,y)\) is at most \(D\). All relevant integers therefore have \(O(L)\) bits.

Using schoolbook integer arithmetic:

  • Computing \(D\) and all \(a_t\) costs \(O(\tau L^2)\) bit operations.
  • There are \(\binom{m}{2}\) pairs, each requiring at most \(\tau\) ranking comparisons and additions of \(O(L)\)-bit integers.
  • The cycle test requires \(O(m^2)\) ordinary graph operations when the tournament is stored as an adjacency matrix.

Allowing conservatively for ranking preprocessing, indexing, and graph bookkeeping, the complete algorithm runs in
\[ O(m^2\tau L^2) \]
bit operations. This is polynomial in the input length because both \(m\) and \(\tau\) are bounded by the explicit input size. In particular, the algorithm processes only the \(\tau\) supplied rankings; it never enumerates the \(m!\) possible rankings.

4. Relation to triple characterizations

The structural result mentioned in the question is compatible with this algorithm, but it is not needed for the complexity classification. The relevant elementary fact is that a tournament contains a directed cycle if and only if it contains a directed triangle.

To prove the nontrivial direction, choose a directed cycle of minimum length, written \(v_1\to v_2\to\cdots\to v_k\to v_1\). If \(k>3\), inspect the edge between \(v_1\) and \(v_3\). If \(v_3\to v_1\), then \(v_1,v_2,v_3\) form a directed triangle. If \(v_1\to v_3\), then \(v_1\to v_3\to v_4\to\cdots\to v_k\to v_1\) is a shorter directed cycle. Either possibility contradicts the assumed minimum length \(k>3\).

Consequently, checking every triple after computing the majority edges also gives a polynomial-time algorithm. The graph procedure above avoids enumerating those triples.

Step-by-step verification

1. Exact construction of majority edges

The construction is valid for positive rational masses given explicitly by binary numerators and denominators.

Because every \(q_t\) divides \(D=\prod_{t=1}^{\tau}q_t\), each \(a_t=p_t(D/q_t)\) is a positive integer and satisfies \(\mu_t=a_t/D\). The input normalization therefore gives \(\sum_t a_t=D\).

For every distinct pair \(x,y\), the definition of \(B(x,y)\) consequently gives
\[ w(x,y)=B(x,y)/D. \]
Since \(D>0\), the comparison \(2B(x,y)>D\) is exactly equivalent to \(w(x,y)>\tfrac12\).

Strict total rankings imply \(B(x,y)+B(y,x)=D\). Together with the no-ties hypothesis, this ensures that exactly one directed edge is selected for each unordered pair. Thus the algorithm constructs precisely the required majority tournament.

Recording candidate positions correctly implements ranking comparisons. This preprocessing uses only the supplied \(\tau\) rankings.

2. Correctness of cycle detection

The removal procedure correctly maintains indegrees in the remaining induced graph.

The forward implication is sound: if a directed cycle exists, its first removed vertex would still have its cycle predecessor present, contradicting its current indegree being zero. Hence a graph containing a directed cycle cannot have all its vertices removed.

For the converse, stopping with vertices remaining means that each remaining vertex has an incoming edge from another remaining vertex. The predecessor sequence described by the prover is therefore well-defined, and finiteness guarantees a repetition.

There is one minor wording issue in identifying the cycle:

  • Where: “Taking the segment up to the first repetition gives distinct vertices forming a directed cycle.”
  • Severity: Minor.
  • Issue: The sequence can have an initial portion before the repeated vertex first appears. The entire segment starting at \(v_0\) need not form a cycle.
  • Minimum clarification: Specify that the cycle uses the segment between the two occurrences of the first repeated vertex, with edges traversed in reverse index order.

This is a routine clarification of the existing argument. It does not undermine correctness of the algorithm.

The case \(m=1\) is explicitly handled correctly. For \(m=2\), the single tournament edge likewise permits both vertices to be removed, giving the correct answer.

3. Bit complexity

The integer-size bounds are correct. Since the denominators are explicitly encoded in the input,
\[ \log_2 D=\sum_t\log_2 q_t=O(L). \]
Including the additional bit needed to represent an integer does not change this bound.

Positivity and \(\sum_t a_t=D\) imply \(a_t\leq D\). Every partial sum for \(B(x,y)\) is also at most \(D\). The doubled comparison value \(2B(x,y)\) requires at most one additional bit. Thus all arithmetic uses \(O(L)\)-bit integers.

Schoolbook multiplication and integer division support the claimed \(O(\tau L^2)\) bound for constructing \(D\) and the \(a_t\).

There are \(\binom{m}{2}\) unordered pairs, each requiring at most \(\tau\) position comparisons and additions. The adjacency-matrix cycle procedure uses \(O(m^2)\) graph operations: each vertex is removed at most once, and its outgoing edges can be scanned once upon removal.

The stated overall bound \(O(m^2\tau L^2)\) is conservative enough to cover preprocessing, arithmetic, and graph bookkeeping. Explicitly listing the rankings bounds both \(m\) and \(\tau\) by the input length, so this is polynomial in \(L\).

4. Tournament triangles and the cited structural result

The minimum-cycle argument is correct. A tournament has no loops or directed cycles of length two, so its minimum directed cycle has length at least three. For a minimum cycle of length greater than three, either orientation of the edge between \(v_1\) and \(v_3\) produces the stated shorter cycle, contradicting minimality.

The converse—that a directed triangle is a directed cycle—is immediate. Thus the optional triple-enumeration observation is valid.

The prover does not apply the Elsholtz–List characterization or rely on extending it to rational masses. No unverified hypothesis of that result enters the proof.

5. Complexity conclusion

The polynomial-time algorithm establishes membership in \(\mathrm{P}\). The statement that NP-hardness under polynomial-time many-one reductions would imply \(\mathrm{P}=\mathrm{NP}\) is also correct. The prover appropriately avoids asserting unconditional non-hardness.
