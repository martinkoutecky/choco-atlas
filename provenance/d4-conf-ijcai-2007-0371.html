The continuous mirror question, as graded

Given candidates \(C\), a finite support \(\mathcal T\) of incomplete total-order types with positive rational masses \(\mu_P\) summing to \(1\), a target \(c^\star\), and a fixed elimination tie priority, is there an allocation \(x_{P,\pi}\ge 0\) over consistent complete rankings \(\pi\in\mathcal L(P)\), satisfying \(\sum_{\pi\in\mathcal L(P)}x_{P,\pi}=\mu_P\) for every \(P\), such that STV on the resulting ranking masses elects \(c^\star\), using a strict-majority quota of \(1/2\)?

Packaged proof task (what the prover saw — nothing else)

Let \(C\) be a nonempty candidate set of unbounded size \(m\), with target \(c^\star\in C\) and a given strict elimination priority. Each incomplete ranking type \(P\) specifies a strict partial order of known comparisons; unknown comparisons may be completed, but preference ties and declared incomparability are excluded. Let \(\mathcal L(P)\) be its consistent complete strict rankings.
A society is given by its support: the list \(\mathcal T\) of the \(\tau\) types with positive mass, each mass \(\mu_P\) a binary rational, with \(\sum_{P\in\mathcal T}\mu_P=1\). Here \(\tau\) is the support size, not the number of possible types; \(L\) is the total input bit length. State running times in \(m,\tau,L\).
An allocation consists of real masses \(x_{P,\pi}\geq0\) for \(\pi\in\mathcal L(P)\), satisfying \(\sum_{\pi\in\mathcal L(P)}x_{P,\pi}=\mu_P\). The allocation is fixed throughout the election.
Use single-winner STV on these masses: each ranking contributes its mass to its highest remaining candidate. Elect a candidate whose tally is strictly greater than \(1/2\); otherwise eliminate one candidate of minimum tally, choosing the earliest in the elimination priority among tied minima, and repeat. Transfers preserve each ranking's entire mass.

Is deciding whether some such allocation elects \(c^\star\) solvable in polynomial time in \(m,\tau,L\), or is it NP-hard?

For discrete unweighted voters and unboundedly many candidates, STV possible-winner decision is NP-complete, even with only one unknown vote; the result does not depend on tie-breaking ([Pini–Rossi–Venable–Walsh](https://cgi.cse.unsw.edu.au/~tw/prvwaij11.pdf)).
No result settling this exact divisible-mass completion problem was identified in the literature search.

Modeling choices made when packaging the task

  • Interpreted incomplete total-order types as extendible strict partial orders of known comparisons, with neither preference ties nor declared incomparability.
  • Specified that allocation variables are nonnegative real masses and that the allocation remains fixed throughout the election.
  • Specified transfer to each ranking's highest remaining candidate, preserving its entire mass, following the extended version's repeated-election definition.
  • Resolved the quota wording as election at a tally strictly greater than one half, as stipulated in the continuous question and consistent with the intended discrete majority threshold.
  • Made the elimination priority a given strict order and specified that its earliest tied candidate is eliminated.
  • Specified a nonempty candidate set and defined the bit-length parameter as total input length.

Result

The problem is \(\mathrm{NP}\)-complete. This holds even when every incomplete type has exactly two consistent rankings, differing only in the order of its first two candidates.

The hardness proof below allows arbitrary real allocations. Its Boolean choices are encoded by which candidates are eliminated, so fractional splitting does not invalidate the reduction.

1. Reduction from \(\mathrm{3SAT}\)

Let a \(\mathrm{3SAT}\) instance have variables \(z_1,\ldots,z_n\) and clauses \(D_1,\ldots,D_q\), with \(n,q\geq1\). Each clause has three literal occurrences; repetitions are allowed.

We construct an election with target \(p=c^\star\), rival \(r\), variable candidates \(a_i,b_i\), and clause candidates \(h_j,g_j\). Thus

\[ m=2n+2q+2. \]

We first specify unnormalized rational weights. Dividing every weight by their total \(W\) gives the required masses. During the proof, tallies refer to unnormalized weights, so the majority threshold is \(W/2\).

Set

\[ \delta=\frac{1}{100(n+q+1)},\qquad A=\frac34. \]

Let \(d_i^+\) and \(d_i^-\) count the positive and negative occurrences of \(z_i\). In particular,

\[ d_i^+,d_i^-\leq3q,\qquad q\delta<\frac1{100},\qquad \delta\leq\frac1{300}. \]

In every ranking below, append all unlisted candidates in an arbitrary fixed strict order after \(p\). Consequently, these tails cannot affect transfers while \(p\) remains.

1.1. Variable types

For each variable \(z_i\), introduce:

| Weight | Ranking or partial ranking |
|---|---|
| \(A-d_i^+\delta\) | \(a_i>b_i>p>\cdots\) |
| \(A-d_i^-\delta\) | \(b_i>a_i>p>\cdots\) |
| \(\delta\), for each positive occurrence in \(D_j\) | \(a_i>h_j>p>\cdots\) |
| \(\delta\), for each negative occurrence in \(D_j\) | \(b_i>h_j>p>\cdots\) |
| \(\delta\) | Both \(a_i,b_i\) precede \(p\); only their mutual comparison is unknown; the tail is fixed |

The last type has exactly two linear extensions:

\[ a_i>b_i>p>\cdots,\qquad b_i>a_i>p>\cdots. \]

All weights are positive, since

\[ A-d_i^\pm\delta>\frac34-\frac3{100}>0. \]

1.2. Clause and finalist types

For each clause \(D_j\), introduce:

| Weight | Ranking |
|---|---|
| \(1-\delta/2\) | \(h_j>g_j>p>\cdots\) |
| \(1-\delta\) | \(g_j>h_j>p>\cdots\) |
| \(\delta\) | \(g_j>p>\cdots\) |

Finally introduce:

| Weight | Ranking |
|---|---|
| \(1+4\delta\) | \(p>\cdots\) |
| \(1+(q+7/2)\delta\) | \(r>p>\cdots\) |

Choose any strict elimination priority. The proof works for every such choice.

Identical types can be merged by adding their weights. The support size satisfies

\[ \tau\leq3n+6q+2. \]

The total weight is

\[ W=\frac{3n}{2}+2q+2+ \left(n+\frac q2+\frac{15}{2}\right)\delta. \]

In particular, \(W\geq11/2\). All normalized masses have bit length \(O(\log(n+q+1))\), and all rankings and partial orders have polynomial-size descriptions. This is therefore a polynomial-time construction.

2. Every allocation determines a Boolean assignment

Fix an arbitrary allocation, including allocations using nonrational real masses.

For variable \(i\), let \(y_i\in[0,\delta]\) be the mass assigned to the completion beginning \(a_i>b_i\). Initially,

\[ t(a_i)=A+y_i,\qquad t(b_i)=A+\delta-y_i. \]

Both lie in \([A,A+\delta]\).

When the first member of this pair is eliminated:

  • its literal-occurrence packets transfer to their clause candidates;
  • its remaining fixed mass transfers to the other member;
  • all incomplete mass is then held by the surviving member.

If the eliminated member has \(d\) literal occurrences, the survivor consequently has tally

\[ 2A+\delta-d\delta. \]

Hence its tally lies strictly between \(147/100\) and \(8/5\).

Meanwhile, every clause candidate has tally at least \(1-\delta/2\), and \(p,r\) each have tally greater than \(1\). Since

\[ A+\delta<1-\delta/2, \]

as long as an untouched variable pair exists, the minimum-tally candidate belongs to an untouched pair. A surviving member cannot be eliminated during this phase.

Thus exactly one member of every variable pair is eliminated before any other candidate. Define

\[ z_i=\mathrm{true}\quad\text{if }a_i\text{ is eliminated first}, \]

and define \(z_i=\mathrm{false}\) if \(b_i\) is eliminated first.

Equal splits cause no difficulty: the given priority determines the first elimination and therefore the assignment.

Conversely, every Boolean assignment is realizable. To eliminate \(a_i\) first, assign all incomplete mass to the completion beginning \(b_i>a_i\); to eliminate \(b_i\) first, use the opposite completion. These choices make the desired elimination strict.

At the end of this phase, let \(k_j\) be the number of true literal occurrences in clause \(D_j\). Exactly those occurrences have sent their packets to \(h_j\). Therefore,

\[ t(h_j)=1-\delta/2+k_j\delta,\qquad t(g_j)=1. \]

In particular, \(k_j\geq1\) precisely when the induced assignment satisfies \(D_j\).

3. The clause phase counts satisfied clauses

Consider a clause pair before either member has been eliminated.

If \(D_j\) is unsatisfied, then \(k_j=0\), and

\[ t(h_j)=1-\delta/2<1=t(g_j). \]

Thus \(h_j\) is eliminated first. Its entire mass transfers to \(g_j\), giving

\[ t(g_j)=2-\delta/2. \]

No mass transfers to \(p\).

If \(D_j\) is satisfied, then \(k_j\geq1\), and

\[ t(h_j)=1+(k_j-1/2)\delta>1=t(g_j). \]

Thus \(g_j\) is eliminated first. Its mass \(1-\delta\) transfers to \(h_j\), while its mass \(\delta\) transfers directly to \(p\). The surviving \(h_j\) has tally

\[ t(h_j)=2+(k_j-3/2)\delta. \]

Since \(1\leq k_j\leq3\), every processed clause survivor has tally between \(2-\delta/2\) and \(2+3\delta/2\).

These pairwise conclusions describe the actual global elimination order. Indeed:

  • every unprocessed pair contains a candidate with tally at most \(1\);
  • variable survivors have tally greater than \(147/100\);
  • processed clause survivors have tally at least \(2-\delta/2\);
  • after \(s\) satisfied clauses have been processed, the target has tally

\[ t(p)=1+(4+s)\delta>1; \]

  • the rival has tally

\[ t(r)=1+(q+7/2)\delta>1. \]

Both finalist tallies remain below \(11/10\). Therefore, while an unprocessed clause pair exists, the next eliminated candidate belongs to such a pair. Within that pair, the strict comparison above determines which member is eliminated.

After exactly one member of every clause pair has been eliminated, if the assignment satisfies \(s\) clauses, then

\[ t(p)=1+(4+s)\delta,\qquad t(r)=1+(q+7/2)\delta. \]

No premature majority

Until this point, every candidate’s tally is at most \(2+3\delta/2<21/10\). Since

\[ W/2\geq11/4, \]

no candidate has achieved a strict majority. Thus the election has indeed performed all the eliminations just described.

4. The target wins exactly for satisfying assignments

4.1. An unsatisfied clause forces the target’s elimination

If \(s\leq q-1\), then

\[ t(r)-t(p)=(q-s-1/2)\delta\geq\delta/2>0. \]

Every remaining variable candidate has tally greater than \(147/100\), and every remaining clause candidate has tally at least \(2-\delta/2\). Both finalists have tally below \(11/10\).

Consequently, \(p\) is the unique minimum-tally candidate and is eliminated next. It cannot win.

4.2. If all clauses are satisfied, the target wins

If \(s=q\), then

\[ t(p)-t(r)=\delta/2>0. \]

The rival is now the unique minimum-tally candidate. Its entire mass transfers to \(p\), giving the target tally

\[ H=2+(2q+15/2)\delta. \]

We check that subsequent transfers cannot endanger \(p\).

All remaining clause candidates are \(h_j\), since every \(g_j\) has been eliminated. While \(h_j\) remains, the only masses it can hold are:

  • its original mass \(1-\delta/2\);
  • the mass \(1-\delta\) transferred from \(g_j\);
  • at most three literal-occurrence packets, of total mass at most \(3\delta\).

Thus, throughout the remainder of the election,

\[ t(h_j)\leq2+3\delta/2<H. \]

Each variable survivor has tally at most \(3/2+\delta<H\). It receives no further transfers from other candidates: every relevant ranking places \(p\) before unrelated variable candidates.

The target’s tally is nondecreasing. Therefore, it remains strictly above every other remaining candidate. It cannot be eliminated. Nor can another candidate obtain a strict majority: that candidate and the still-higher target would together exceed the total weight.

The process therefore elects \(p\), either at an earlier majority or when it is the sole remaining candidate.

Combining both directions,

\[ \text{some allocation elects }p \quad\Longleftrightarrow\quad \text{the formula is satisfiable}. \]

This proves \(\mathrm{NP}\)-hardness, with arbitrary real splitting and the stated majority and priority rules.

5. Membership in \(\mathrm{NP}\)

The remaining issue is that an allocation may use real masses and exponentially many rankings. We show that every yes-instance has a polynomial-size rational certificate.

5.1. Eliminating until one candidate remains gives the same winner

Temporarily continue eliminating minimum-tally candidates even after a strict majority appears.

If candidate \(w\) has tally greater than \(1/2\), every other candidate has smaller tally. Moreover, \(w\)’s tally cannot decrease. Thus \(w\) survives every subsequent elimination and is the sole final survivor.

Hence the original rule elects \(c^\star\) exactly when this continued elimination process leaves \(c^\star\) last.

5.2. A bounded rational polytope for a fixed elimination order

Suppose a real allocation leaves \(c^\star\) last, with elimination order \(e_1,\ldots,e_{m-1}\). For each round \(r\), let \(S_r\) be its remaining candidate set and let \(t_{r,a}(x)\) denote candidate \(a\)’s tally. These are linear functions of the allocation variables, with coefficients in \(\{0,1\}\).

Introduce a slack variable \(\varepsilon\), constrained by \(0\leq\varepsilon\leq1\). Impose the type-mass equations and nonnegativity constraints. For every opponent \(a\in S_r\setminus\{e_r\}\), impose:

\[ t_{r,a}(x)-t_{r,e_r}(x)\geq\varepsilon \]

if \(a\) precedes \(e_r\) in elimination priority, and otherwise impose

\[ t_{r,a}(x)-t_{r,e_r}(x)\geq0. \]

These are exactly the required minimum-tally comparisons, with strictness wherever a tie would eliminate \(a\) instead.

The given allocation satisfies every required strict inequality. Since there are finitely many such inequalities, a positive common slack exists. If none requires strictness, take \(\varepsilon=1\).

Maximize \(\varepsilon\). The feasible set is a bounded rational polytope: each allocation coordinate is between zero and its type mass, and \(\varepsilon\in[0,1]\). Therefore an optimal vertex exists, with positive objective value.

5.3. Polynomial support and bit length

There are \(\tau\) type equations, \(\binom m2\) tally comparisons, and the upper bound on \(\varepsilon\). Set

\[ K=\tau+\binom m2+1. \]

At a vertex, at most \(K\) coordinates can be positive. To justify this, if more were positive, the active equations and inequalities restricted to those coordinates would have a nonzero null direction. A sufficiently small perturbation in either direction would preserve positivity and all inactive inequalities, contradicting extremality.

Thus the optimal vertex uses at most \(K\) positive allocation masses.

After restricting to its positive coordinates, choose an independent square system of active constraints. Its coefficients belong to \(\{-1,0,1\}\). The right-hand sides are input masses or zero or one. A common denominator has bit length \(O(L)\). Cramer’s rule and the determinant bound give each coordinate bit length

\[ O\!\left(L+K\log(K+1)\right). \]

Hence a certificate consists of at most \(K\) consistent complete rankings, their type identifiers, and rational masses of polynomial bit length.

A verifier checks consistency with each partial order, checks the type-mass sums, and simulates STV using exact rational arithmetic. Its running time is \(\operatorname{poly}(m,\tau,L)\).

Therefore the problem belongs to \(\mathrm{NP}\).

6. Running-time consequence

The problem is \(\mathrm{NP}\)-complete, so a polynomial-time algorithm in \(m,\tau,L\) would imply \(\mathrm{P}=\mathrm{NP}\).

For completeness, an exact deterministic upper bound is

\[ 2^{O(m\log(m+1))}\operatorname{poly}(\tau,L). \]

Enumerate the at most \(m!\) rankings for each supported type and the \((m-1)!\) elimination orders ending in \(c^\star\). For each order, solve the rational linear program above and test whether its maximum slack is positive. Each program has at most \(\tau m!+1\) variables and polynomial explicit encoding length in \(\tau m!,m,L\); polynomial-time rational linear programming therefore gives the stated bound.
