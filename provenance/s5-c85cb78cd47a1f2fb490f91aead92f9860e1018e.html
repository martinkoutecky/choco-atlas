The continuous mirror question, as graded

Given a room size \(s\), a finite support \(T\) of complete types \(t\) (color and weak order over fractions \(j/s\)), and rational masses \(\mu_t\) summing to \(1\), decide whether there is a feasible assignment \(x_{t,j}\ge 0\) with \(\sum_j x_{t,j}=\mu_t\), \(\sum_{t\in T_R}x_{t,j}=(j/s)q_j\), and \(\sum_{t\in T_B}x_{t,j}=((s-j)/s)q_j\) for some \(q_j\ge0\). For an incumbent \(x\), a challenger is any \(z_{t,j,\ell}\ge0\) with \(\sum_\ell z_{t,j,\ell}=x_{t,j}\) and, for some \(q'_\ell\ge0\), \(\sum_{t\in T_R,j}z_{t,j,\ell}=(\ell/s)q'_\ell\) and \(\sum_{t\in T_B,j}z_{t,j,\ell}=((s-\ell)/s)q'_\ell\). Is there a feasible \(x\) for which every feasible challenger has \(\sum_{t,j,\ell}\delta_t(j,\ell)z_{t,j,\ell}\le0\), where \(\delta_t(j,\ell)\) is \(1\) if type \(t\) strictly prefers \(\ell/s\) to \(j/s\), \(-1\) if it strictly prefers \(j/s\), and \(0\) if indifferent?

Packaged proof task (what the prover saw — nothing else)

Let \(s\ge1\) be an input integer, \(J=\{0,\ldots,s\}\), and \(m=s+1\). A type consists of a color, red or blue, and an explicitly listed complete weak order over \(D=\{j/s:j\in J\}\); fractions always mean the red share, for both colors.
A society is given by its support \(T=T_R\sqcup T_B\): the list of its \(\tau\) positive-mass types, each with a binary rational mass \(\mu_t>0\), with \(\sum_t\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types. Let \(L\) be the total input bit length; state running times in \(m,\tau,L,s\).
All allocation variables are nonnegative real numbers, and all composition indices range over \(J\). An incumbent allocation \(x\) is feasible if there are \(q_j\ge0\) satisfying \(\sum_jx_{t,j}=\mu_t\), \(\sum_{t\in T_R}x_{t,j}=(j/s)q_j\), and \(\sum_{t\in T_B}x_{t,j}=((s-j)/s)q_j\). Here \(q_j\) is total population mass assigned to composition \(j/s\), with no integrality requirement.
A feasible challenger to \(x\) is a tensor \(z\) with \(\sum_\ell z_{t,j,\ell}=x_{t,j}\) and some \(q'_\ell\ge0\) satisfying \(\sum_{t\in T_R,j}z_{t,j,\ell}=(\ell/s)q'_\ell\) and \(\sum_{t\in T_B,j}z_{t,j,\ell}=((s-\ell)/s)q'_\ell\).
Define \(\delta_t(j,\ell)=1\) when \(\ell/s\succ_t j/s\), \(\delta_t(j,\ell)=-1\) when \(j/s\succ_t\ell/s\), and \(\delta_t(j,\ell)=0\) for indifference. Call \(x\) popular if every feasible challenger satisfies \(\sum_{t,j,\ell}\delta_t(j,\ell)z_{t,j,\ell}\le0\).

Is deciding whether a feasible popular allocation exists solvable in polynomial time in \(m,\tau,L,s\), or is it \(\mathrm{NP}\)-hard?

For finite societies partitioned into rooms of size \(s\), popular-outcome existence is \(\mathrm{coNP}\)-hard even with trichotomous preferences; for \(s=2\), a popular outcome always exists and is computable in polynomial time. [Source](https://arxiv.org/abs/2210.07911)
No result settling this exact continuous problem was located in the literature search.

  • Made weak orders explicitly listed, defined m as the number of available fractions, and defined L as total input bit length.

Partial resolution: polynomial time with bounded support in one color

I do not settle the unrestricted polynomial-time versus $\mathrm{NP}$-hardness question. I prove a further tractable case that allows the support size in the other color to grow arbitrarily.

Let
$$ k=\min\{|T_R|,|T_B|\}. $$
If $k=0$, the unique feasible allocation is popular. If $k\geq 1$, existence can be decided, and a popular allocation constructed when one exists, in time
$$ m^{2k}(Ck^2m^2)^{k+1} \operatorname{poly}(m,\tau,L,\log(s+1)), $$
where $C$ is an absolute constant. Consequently, the problem is polynomial-time solvable for every fixed $k$.

In particular, when one color has exactly one positive-mass type, an improved implementation uses $O(m^4)$ allocation linear programs, each of polynomial size.

The proof establishes a normalization of the dual certificate: after choosing the occupied preference tiers of the blue types, only one real parameter per blue type is needed.

1. Removing impossible endpoint assignments

For red and blue types, respectively, define the physically possible index sets
$$ A_R=\{1,\ldots,s\}, \qquad A_B=\{0,\ldots,s-1\}. $$
Write $A_t$ for the set appropriate to type $t$.

The original composition equations force every red cell at index $0$ and every blue cell at index $s$ to be zero. Indeed, the red mass at composition $0$ is zero, and the blue mass at composition $1$ is zero. These restrictions also hold for challenger destinations.

For an interior index $j\in\{1,\ldots,s-1\}$, define
$$ a_{t,j}= \begin{cases} s-j,&t\in T_R,\\ -j,&t\in T_B. \end{cases} $$
If $R_j$ and $B_j$ denote the red and blue masses assigned to index $j$, the composition equations are equivalent to
$$ (s-j)R_j-jB_j=0. $$
The forward implication follows directly from the prescribed shares. Conversely, this equality gives
$$ sR_j=j(R_j+B_j), $$
so setting $q_j=R_j+B_j$ recovers both share equations. At the endpoints, the forced-zero restrictions already give the required compositions.

Thus the feasible allocation polytope is exactly
$$ P= \left\{ x\geq 0: \sum_{j\in A_t}x_{t,j}=\mu_t\ \text{for every }t,\quad \sum_t a_{t,j}x_{t,j}=0\ \text{for }1\leq j\leq s-1 \right\}. $$
It is nonempty: assign every red type to index $s$ and every blue type to index $0$. It is compact because every cell lies between zero and its type’s mass.

If one color is absent, every interior composition must be empty. Hence the allocation just described is the unique feasible allocation, and every feasible challenger has the same assignments. It is popular.

Henceforth assume both colors are present.

2. A support certificate for popularity

Introduce unrestricted real variables $\beta_j$ for the interior indices. Define red and blue potentials by
$$ p^R_j=(s-j)\beta_j\quad(1\leq j\leq s-1), \qquad p^R_s=0, $$
and
$$ p^B_j=-j\beta_j\quad(1\leq j\leq s-1), \qquad p^B_0=0. $$
Write $p_t$ for the potential appropriate to type $t$.

Lemma 1. A feasible allocation $x$ is popular if and only if there are such potentials satisfying
$$ p_t(\ell)-p_t(j)\geq\delta_t(j,\ell) \quad \text{whenever }x_{t,j}>0,\quad \ell\in A_t. $$

Proof. After removing impossible destinations, the maximum challenger margin is the linear program
$$ \begin{aligned} F(x)=\max_{z\geq0}\quad& \sum_t\sum_{j,\ell\in A_t}\delta_t(j,\ell)z_{t,j,\ell}\\ \text{subject to}\quad& \sum_{\ell\in A_t}z_{t,j,\ell}=x_{t,j},\\ & \sum_t\sum_{j\in A_t}a_{t,\ell}z_{t,j,\ell}=0 \quad(1\leq\ell\leq s-1). \end{aligned} $$
The diagonal challenger is feasible and has margin zero. Every feasible challenger has total mass one, so the feasible set is compact and the objective is bounded. Therefore $F(x)$ is attained, and popularity is equivalent to $F(x)=0$.

The dual is
$$ \begin{aligned} \min_{\alpha,\beta}\quad& \sum_t\sum_{j\in A_t}x_{t,j}\alpha_{t,j}\\ \text{subject to}\quad& \alpha_{t,j}+p_t(\ell)\geq\delta_t(j,\ell) \quad(j,\ell\in A_t). \end{aligned} $$
All dual variables are unrestricted. The dual is feasible with $\alpha_{t,j}=1$ and $\beta_j=0$. Since the primal is feasible and bounded, linear-programming strong duality gives an attained dual optimum.

Suppose $x$ is popular and choose a dual optimum of value zero. The diagonal inequalities give
$$ \alpha_{t,j}+p_t(j)\geq0. $$
Incumbent feasibility implies
$$ \sum_t\sum_{j\in A_t}x_{t,j}p_t(j) = \sum_{j=1}^{s-1}\beta_j\sum_ta_{t,j}x_{t,j} =0. $$
Consequently,
$$ \sum_t\sum_{j\in A_t} x_{t,j}\bigl(\alpha_{t,j}+p_t(j)\bigr)=0. $$
Every summand is nonnegative. For each positive cell,
$$ \alpha_{t,j}=-p_t(j). $$
Substitution into the dual inequalities proves the stated certificate.

Conversely, suppose the certificate holds. A zero source cell forces all corresponding challenger entries to vanish. For every feasible challenger,
$$ \begin{aligned} \sum_t\sum_{j,\ell\in A_t}\delta_t(j,\ell)z_{t,j,\ell} &\leq \sum_t\sum_{j,\ell\in A_t} \bigl(p_t(\ell)-p_t(j)\bigr)z_{t,j,\ell}\\ &=0. \end{aligned} $$
The last equality follows from challenger balance for the destination term and incumbent balance for the source term. Thus $x$ is popular. $\square$

This also gives a direct proof of membership in $\mathrm{NP}$. Guess a subset $S$ of the at most $\tau s$ possible cells, and solve:

  • The feasibility system defining $P$, with cells outside $S$ fixed to zero.
  • The certificate inequalities of Lemma 1 for every cell in $S$.

Both are rational linear programs of polynomial encoding size. If both are feasible, the first program returns a popular allocation. Conversely, the positive support of any popular allocation makes both programs feasible.

3. Potentials on a type’s occupied tiers

Here a *tier* means an indifference class of the weak order restricted to $A_t$.

Lemma 2. In a popular allocation:

  • all occupied indices in the same tier of a type have equal potentials;
  • the potential on an occupied higher tier exceeds that on an occupied lower tier by exactly one;
  • each type occupies at most two tiers.

Proof. Let $j$ and $\ell$ be positive cells of the same type. Both directions of Lemma 1 apply.

If they are indifferent, the two inequalities give
$$ p_t(\ell)-p_t(j)\geq0, \qquad p_t(j)-p_t(\ell)\geq0, $$
so the potentials are equal.

If $j$ is strictly preferred to $\ell$, the inequalities give
$$ p_t(j)-p_t(\ell)\geq1, \qquad p_t(j)-p_t(\ell)\leq1. $$
Their difference is exactly one.

If three strictly ordered tiers were occupied, their potentials would satisfy
$$ p_{\mathrm{high}}-p_{\mathrm{middle}}=1, \qquad p_{\mathrm{middle}}-p_{\mathrm{low}}=1, $$
and also
$$ p_{\mathrm{high}}-p_{\mathrm{low}}=1. $$
The first two equalities make the last difference equal to two, a contradiction. $\square$

This lemma is the discrete part of the parameter reduction.

4. A normalization using only blue-type parameters

Assume for now that there are $k$ blue types.

For each blue type $t$, choose a nonempty set $\mathcal C_t$ consisting of either one or two tiers of its restricted order on $A_B$. Define
$$ u_t(C)= \begin{cases} 0,&\mathcal C_t\text{ consists of one tier},\\ 1,&C\text{ is the higher of two chosen tiers},\\ 0,&C\text{ is the lower of two chosen tiers}. \end{cases} $$

For a tier $C$ and index $\ell$, let $\delta_t(C,\ell)$ denote $\delta_t(j,\ell)$ for any $j\in C$. This is well-defined because all members of an indifference class have the same comparisons.

Define
$$ h_t(\ell)= \max_{C\in\mathcal C_t} \bigl(u_t(C)+\delta_t(C,\ell)\bigr), \qquad \ell\in A_B. $$
These are integers in $\{-1,0,1,2\}$. Moreover, if $j$ belongs to a chosen tier $C$, then
$$ h_t(j)=u_t(C). $$
For one chosen tier this is immediate. For two tiers, at the higher tier the two terms are $1+0$ and $0+1$, while at the lower tier they are $1-1$ and $0+0$.

Introduce one real parameter $v_t$ per blue type and put
$$ B_j(v)=\max_{t\in T_B}\bigl(v_t+h_t(j)\bigr), \qquad j\in A_B. $$
Require
$$ B_0(v)\leq0, $$
equivalently,
$$ v_t+h_t(0)\leq0\quad\text{for every blue type }t. $$

Define the canonical potentials
$$ \widehat p^B_0=0, \qquad \widehat p^B_j=B_j(v)\quad(1\leq j\leq s-1), $$
and
$$ \widehat p^R_s=0, \qquad \widehat p^R_j=-\frac{s-j}{j}B_j(v) \quad(1\leq j\leq s-1). $$
They come from the common interior dual variables
$$ \widehat\beta_j=-\frac{B_j(v)}{j}. $$

Eligible cells

For a red type $t$, declare $(t,j)$ eligible exactly when
$$ \widehat p^R_\ell-\widehat p^R_j \geq\delta_t(j,\ell) \quad\text{for every }\ell\in A_R. $$

For a blue type $t$, declare $(t,j)$ eligible exactly when $j$ belongs to a chosen tier $C\in\mathcal C_t$ and
$$ \widehat p^B_j=v_t+u_t(C). $$

Let $E(v)$ be the resulting set of eligible cells.

Proposition 3. A popular allocation exists if and only if there are tier choices $\mathcal C_t$, parameters $v$ satisfying $B_0(v)\leq0$, and an allocation in $P$ supported on $E(v)$.

Proof: sufficiency. Let $x\in P$ be supported on $E(v)$.

Every positive red cell satisfies Lemma 1 by its eligibility definition.

For a positive blue cell $(t,j)$ in chosen tier $C$, eligibility gives
$$ \widehat p^B_j=v_t+u_t(C). $$
For an interior destination $\ell$,
$$ \widehat p^B_\ell =B_\ell(v) \geq v_t+h_t(\ell) \geq v_t+u_t(C)+\delta_t(j,\ell). $$
For destination $0$, the domain condition gives
$$ \widehat p^B_0=0 \geq B_0(v) \geq v_t+h_t(0) \geq v_t+u_t(C)+\delta_t(j,0). $$
Thus every positive blue cell also satisfies Lemma 1. Therefore $x$ is popular.

Proof: necessity. Let $x$ be popular, and choose potentials from Lemma 1.

For each blue type, choose exactly its occupied tiers. There is at least one because its mass is positive, and there are at most two by Lemma 2. That lemma supplies a number $v_t$ such that every positive blue cell in tier $C$ has potential
$$ p^B_j=v_t+u_t(C). $$

For every blue type $t$, each of its chosen tiers contains a positive source cell. Applying the certificate from that source to every destination $\ell$ yields
$$ p^B_\ell\geq v_t+h_t(\ell). $$
Taking the maximum over blue types gives
$$ p^B_\ell\geq B_\ell(v). $$
At index $0$, this proves the required domain condition because $p^B_0=0$.

If $x_{t,j}>0$ is a blue interior cell in chosen tier $C$, then
$$ B_j(v)\geq v_t+h_t(j) =v_t+u_t(C) =p^B_j. $$
Together with the reverse inequality already proved, this gives
$$ B_j(v)=p^B_j. $$
Hence the canonical blue potential agrees with the original potential at every positive blue cell. The same agreement holds at endpoint $0$.

Every occupied interior composition contains positive mass of both colors: its balance equation has strictly positive coefficients on both color totals. Therefore, at every positive red interior cell, some blue cell at the same index is positive. At that index,
$$ \widehat p^R_j =-\frac{s-j}{j}B_j(v) =-\frac{s-j}{j}p^B_j =p^R_j. $$
The red source potential also stays unchanged at endpoint $s$.

At every red interior destination $\ell$, the inequality $B_\ell(v)\leq p^B_\ell$ implies
$$ \widehat p^R_\ell =-\frac{s-\ell}{\ell}B_\ell(v) \geq -\frac{s-\ell}{\ell}p^B_\ell =p^R_\ell. $$
Thus every positive red source keeps its potential, while every red destination’s potential weakly increases. All its original certificate inequalities remain valid.

The original allocation is consequently supported on $E(v)$. $\square$

The essential point is that every occupied interior composition contains blue mass. Minimizing blue destination potentials to the envelope $B_j(v)$ therefore preserves all occupied source potentials and helps the red inequalities.

5. Searching the parameters exactly

For fixed tier choices, Proposition 3 leaves a search over $\mathbb R^k$. A finite arrangement of rational affine hyperplanes makes both the domain condition and the eligible support constant on every face.

Write
$$ w_j=\frac{s-j}{j} \quad(1\leq j\leq s-1). $$
Use the following hyperplanes, discarding equations that define the whole space or the empty set:

  • Endpoint domain boundaries:

$$ v_t+h_t(0)=0. $$

  • Comparisons determining the maximum at each interior composition:

$$ v_a+h_a(j)=v_b+h_b(j). $$

  • All possible interior red comparison boundaries:

$$ w_j\bigl(v_a+h_a(j)\bigr) - w_\ell\bigl(v_b+h_b(\ell)\bigr) =d, $$
for interior $j,\ell$, blue types $a,b$, and $d\in\{-1,0,1\}$.

  • Red comparisons involving endpoint $s$:

$$ -w_j\bigl(v_a+h_a(j)\bigr)=d, $$
for interior $j$, blue type $a$, and $d\in\{-1,0,1\}$.

There are at most
$$ N\leq k+\binom{k}{2}(s-1) +3k^2(s-1)^2+3k(s-1) \leq 8k^2m^2 $$
hyperplanes.

To verify the constancy claim, fix a face, meaning a nonempty set specified by the signs of all these affine functions.

  • The first family fixes the truth of every domain inequality.
  • The second family fixes the maximizing blue types at every interior index. Choosing, for example, the first maximizing type makes $B_j(v)$ one fixed affine function throughout the face.
  • With those choices, every red eligibility inequality has a boundary in the third or fourth family.
  • For a blue interior source in a chosen tier, $h_t(j)=u_t(C)$. Its eligibility equality says that its affine function attains the maximum, which is fixed by the second family.
  • Blue eligibility at endpoint $0$ is fixed by the first family.

Therefore both $E(v)$ and domain admissibility are constant on the whole face.

For each admissible face, take one rational representative and solve the allocation linear program defining $P$ with all cells outside $E(v)$ fixed to zero. Proposition 3 proves soundness and completeness of this procedure.

Enumerating all faces, including boundaries

Boundary faces must be retained because blue eligibility can require exact equalities.

Let $F(N,k)$ be the maximum number of nonempty faces of an arrangement of $N$ affine hyperplanes in $\mathbb R^k$. Then
$$ F(N,k)\leq \sum_{i=0}^k2^i\binom Ni \leq(k+1)(2N)^k \quad(N\geq1). $$

Here is a justification of the bound. When a new hyperplane cuts an old relatively open face, it replaces that face by its positive part, zero part, and negative part, increasing the count by two. Distinct cut faces give distinct faces in the arrangement restricted to the new hyperplane. That restricted arrangement has dimension $k-1$ and at most $N-1$ hyperplanes. Thus
$$ F(N,k)\leq F(N-1,k)+2F(N-1,k-1). $$
The initial values $F(0,k)=F(N,0)=1$ and Pascal’s identity give the displayed binomial bound.

An exact enumeration algorithm adds the hyperplanes one at a time. For each existing sign vector, test its three extensions by the new hyperplane. Feasibility of a sign vector is a rational linear-programming problem: introduce $0\leq\varepsilon\leq1$, replace every strict positive constraint by
$$ f(v)\geq\varepsilon, $$
every strict negative constraint by
$$ f(v)\leq-\varepsilon, $$
and preserve zero constraints as equalities. Maximize $\varepsilon$ and accept precisely when the optimum is positive.

This test is exact. A point satisfying finitely many strict inequalities has a positive minimum slack, so it permits some positive $\varepsilon$. Conversely, positive $\varepsilon$ enforces every requested strict sign. The objective is bounded, and the coefficients are rational, so exact rational linear programming supplies a rational representative when the face is nonempty.

6. Running time and the one-type case

Each restricted blue order has at most $s$ tiers. The number of choices of one or two tiers for one type is at most
$$ s+\binom s2\leq m^2. $$
There are therefore at most $m^{2k}$ joint tier choices.

For each choice, face enumeration uses at most
$$ 3N\,F(N,k) $$
linear-programming tests, followed by at most $F(N,k)$ allocation tests.

The arrangement programs have $k+1$ variables and $O(N)$ constraints. Their coefficients have encoding length $O(\log(s+1))$: the $h_t(j)$ are bounded integers and the only noninteger coefficients are ratios $(s-j)/j$.

The allocation programs have at most $\tau s$ variables and $\tau+s-1$ equality constraints, in addition to nonnegativity and forced-zero bounds. Their coefficients and masses have polynomial encoding size in the specified input parameters. Representatives and eligibility calculations also have polynomial bit complexity.

Combining these bounds gives
$$ m^{2k}(Ck^2m^2)^{k+1} \operatorname{poly}(m,\tau,L,\log(s+1)) $$
for an absolute constant $C$.

If the red support is smaller, exchange the colors and replace every composition index $j$ by $s-j$. Transform each preference order by this same index reversal. This bijectively preserves feasible allocations, feasible challenger tensors, and their vote margins. Thus the algorithm may use
$$ k=\min\{|T_R|,|T_B|\}. $$

Improved implementation when $k=1$

With one blue type, each $B_j(v)=v+h(j)$ is affine in a single scalar. For fixed tier choices, every eligibility or domain boundary is a point on the real line.

There are $O(m^2)$ such points. Sort them and inspect:

  • every boundary point;
  • every open interval between consecutive boundary points;
  • the two unbounded intervals.

One rational representative per interval suffices because eligibility is constant there. Hence each tier choice requires $O(m^2)$ allocation tests. There are $O(m^2)$ tier choices, giving $O(m^4)$ allocation linear programs altogether.

Computing all eligible supports uses $O(\tau m^6)$ rational arithmetic operations, with polynomial bit complexity. Each allocation linear program has polynomial size. This is a polynomial-time algorithm in $m,\tau,L,s$ even when the other color has arbitrarily many types.

7. What remains open

The normalization substantially reduces the search when one color has small support. It does not remove the dependence exponential in
$$ k=\min\{|T_R|,|T_B|\}. $$

For unrestricted support sizes, the simultaneous tier choices and the higher-dimensional parameter search remain unresolved. The argument supplies neither a polynomial-time algorithm for that case nor an $\mathrm{NP}$-hardness reduction.
