The continuous mirror question, as graded

Given \(\tau\) interchangeable route types, unary-encoded positive edge lengths \(w\in\mathbb{Z}_{>0}^{\tau}\), rational per-worker order supplies \(\rho\in\mathbb{Q}_{\ge0}^{\tau}\), and a polynomially bounded threshold \(q\), decide whether there is a finite-support mass distribution \(\lambda\) over integral bundles \(B\in\mathbb{Z}_{\ge0}^{\tau}\) satisfying \(\sum_B\lambda_B=1\), \(\sum_B\lambda_BB_r=\rho_r\) for every \(r\), and \(\lambda_B>0\Rightarrow w\cdot B\le q\); equivalently compute \(\theta_\infty(\rho,w)=\min_{\lambda}\max_{\lambda_B>0}w\cdot B\).

Packaged proof task (what the prover saw — nothing else)

An order society is given by its support: a list of \(\tau\) route types with positive masses \(\rho_r\), each encoded as a binary rational. Here \(\tau\) is the support size, not the number of possible types; zero-supply routes are omitted.
Workers are identical and have total mass \(1\). Order masses are supplies per unit worker mass and need not sum to \(1\).
Each route has a unary-encoded length \(w_r\in\mathbb Z_{>0}\). Routes are independent branches from a common hub, so an integral bundle \(B\in\mathbb Z_{\ge0}^{\tau}\) has cost \(\sum_{r=1}^{\tau}w_rB_r\); empty bundles are allowed, and every allocation is non-wasteful.
The input threshold \(q\in\mathbb Z_{>0}\) is bounded by a fixed polynomial in the encoding length of \((w,\rho)\). A feasible allocation is a finite-support distribution with real masses \(\lambda_B\ge0\) satisfying \(\sum_B\lambda_B=1\), \(\sum_B\lambda_BB_r=\rho_r\) for every route, and \(\lambda_B>0\Rightarrow\sum_rw_rB_r\le q\).
Let \(L\) be the total input bit length. State running times in \(\tau,L,q\); there is no finite order-count parameter \(m\) in this mass model.

Is deciding whether a feasible allocation exists solvable in polynomial time, or is it NP-hard, under these encoding restrictions?

Discrete benchmark: deciding whether identical workers can receive all orders on a weighted star with maximum bundle cost at most a given threshold is NP-hard even with unary edge lengths; computing a minimax and non-wasteful allocation is consequently NP-hard.
For an unweighted star rooted at its center, a discrete minimax and non-wasteful allocation can be found in linear time.

Modeling choices made when packaging the task

  • Omit zero-supply routes so that the listed route types are exactly the positive-mass support; this does not change feasibility.
  • Interpret the society masses as order supplies per unit worker mass, with homogeneous worker mass normalized to one; order supplies need not sum to one.
  • Take the threshold to be a positive integer bounded by a fixed polynomial in the encoding length of the remaining input.
  • Allow nonnegative real allocation masses and empty integral bundles.
  • Use support size, input bit length, and threshold for running times because the mass formulation has no finite order count m.

Result

The decision problem is polynomial-time solvable under the stated encoding restrictions. An exact algorithm runs in \((\tau q+L)^{O(1)}\) bit operations for nonempty support. Empty support is feasible by assigning every worker the empty bundle.

The proof constructs a polynomial-size linear program whose feasible solutions correspond exactly to the required allocations.

1. Bundles as paths

Construct a directed multigraph with vertices \(\{0,1,\ldots,q\}\cup\{t\}\), source \(0\), and sink \(t\).

For each route \(r\) and integer \(s\) satisfying \(0\le s\le q-w_r\), introduce a route arc \(a_{s,r}\) from \(s\) to \(s+w_r\), labeled \(r\). Also introduce a termination arc from each \(s\in\{0,\ldots,q\}\) to \(t\). Distinct route labels remain distinct arcs even when their endpoints coincide.

Because every \(w_r\) is positive, the graph is acyclic, with \(t\) placed last in its topological order.

For a source-to-sink path \(P\), define \(B_r(P)\) as the number of its route arcs labeled \(r\). If its termination arc leaves vertex \(s\), then telescoping the increases in state gives

\(\displaystyle \sum_{r=1}^{\tau}w_rB_r(P)=s\le q.\)

Thus every path encodes an admissible integral bundle.

Conversely, let \(B\in\mathbb Z_{\ge0}^{\tau}\) satisfy \(\sum_r w_rB_r\le q\). List its route occurrences in any order and follow the corresponding route arcs from state \(0\). Every partial sum is at most the total cost, so every required arc exists. Finish with the termination arc. This yields a path encoding \(B\). The direct termination arc from \(0\) encodes the empty bundle.

2. The exact linear program

Write \(A\) for the arc set, and let \(\delta^+(v)\) and \(\delta^-(v)\) denote the outgoing and incoming arcs at \(v\). Introduce a nonnegative real variable \(x_a\) for each arc \(a\).

Impose unit-flow constraints:

\(\displaystyle \sum_{a\in\delta^+(0)}x_a-\sum_{a\in\delta^-(0)}x_a=1,\)

\(\displaystyle \sum_{a\in\delta^+(v)}x_a-\sum_{a\in\delta^-(v)}x_a=0\qquad(v=1,\ldots,q),\)

\(\displaystyle \sum_{a\in\delta^-(t)}x_a-\sum_{a\in\delta^+(t)}x_a=1.\)

For each route, impose the supply equality:

\(\displaystyle \sum_{s=0}^{q-w_r}x_{a_{s,r}}=\rho_r\qquad(r=1,\ldots,\tau),\)

where the sum is empty when \(w_r>q\). In that case its positive supply makes the linear program infeasible, as required.

A feasible allocation gives a feasible flow

For each bundle \(B\) in the allocation’s finite support, choose a path \(P_B\) encoding it. Set

\(\displaystyle x_a=\sum_B\lambda_B\,\mathbf 1_{\{a\in P_B\}}.\)

Each path carries one unit from source to sink. Since \(\sum_B\lambda_B=1\), their weighted sum satisfies the unit-flow constraints.

For each route \(r\),

\(\displaystyle \sum_s x_{a_{s,r}}=\sum_B\lambda_B B_r=\rho_r.\)

Hence the linear program is feasible.

A feasible flow gives a feasible allocation

We prove the needed flow decomposition explicitly.

If the residual flow leaving the source is positive, follow a positive-flow arc from the source. At each intermediate vertex reached, conservation guarantees a positive-flow outgoing arc. Acyclicity ensures that this process reaches \(t\).

Let \(\alpha>0\) be the minimum residual flow on this path. Subtract \(\alpha\) along the path and record the path with mass \(\alpha\). Residual flows remain nonnegative, conservation remains valid, and at least one positive-flow arc disappears.

Consequently, at most \(|A|\) such subtractions are possible. There can be no nonzero residual flow once source outflow is zero: otherwise, the earliest vertex in topological order having a positive outgoing arc would have zero incoming flow, contradicting conservation. Therefore the entire flow is decomposed as

\(\displaystyle x_a=\sum_{i=1}^{k}\alpha_i\,\mathbf 1_{\{a\in P_i\}},\qquad k\le |A|,\qquad \sum_{i=1}^{k}\alpha_i=1.\)

Assign mass \(\alpha_i\) to bundle \(B(P_i)\), combining masses when paths encode the same bundle. This is a finite-support distribution, every bundle has cost at most \(q\), and its route supplies satisfy

\(\displaystyle \sum_{i=1}^{k}\alpha_i B_r(P_i)=\sum_s x_{a_{s,r}}=\rho_r.\)

Thus it is precisely a feasible allocation.

3. Encoding and running time

The number of arcs, hence variables, is

\(\displaystyle |A|=(q+1)+\sum_{r=1}^{\tau}\max\{0,q-w_r+1\}\le(\tau+1)(q+1).\)

There are \(q+2+\tau\) equalities, together with nonnegativity constraints. Every matrix coefficient belongs to \(\{-1,0,1\}\); the right-hand sides are the input rationals \(\rho_r\), together with zero and one.

For nonempty support, even a dense encoding therefore has length

\(\displaystyle O\bigl(\tau q(\tau+q)+L\bigr).\)

We use the standard theorem that feasibility of a rational linear program can be decided exactly in time polynomial in its binary encoding length. Equalities can be replaced by pairs of inequalities, and all coefficients and right-hand sides here are rational, so its hypotheses hold. See [Trevisan’s linear-programming notes, Sections 2.4–2.5](https://lucatrevisan.github.io/cs261/lecture05.pdf).

The resulting bit running time is \((\tau q+L)^{O(1)}\). Since the promise bounds \(q\) by a fixed polynomial in the encoding length of \((w,\rho)\), and that length is at most \(L\), this is polynomial in \(L\). No finite order-count parameter is used.

4. Relation to the discrete benchmark

The discrete hardness benchmark does not contradict this algorithm. With \(n\) discrete workers, bundle multiplicities must be integers; after normalization, an allocation must admit masses whose products with \(n\) are integers. The present model allows arbitrary real bundle masses, and the flow formulation captures that permission exactly.

Individual bundles remain integral throughout the proof. The polynomial-time result comes from representing their possible distributions by a small continuous linear program.
