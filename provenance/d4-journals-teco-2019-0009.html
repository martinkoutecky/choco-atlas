The continuous mirror question, as graded

Given per-dollar subprojects \(D\), budget \(B\), feasible ground-truth sets \(g\subseteq D\) with \(|g|=B\), and report types \(r\subseteq D\) with \(|r|\le B\) occurring with rational masses \(\nu_r\), where \(P(r\mid g)\propto\exp(|g\cap r|)\), compute \(g^\star\in\arg\max_{|g|=B}\sum_r\nu_r\log P(r\mid g)\), using the paper's consistency and tie-breaking rules.

Packaged proof task (what the prover saw — nothing else)

Definitions

Let \(D\) be partitioned into ordered project chains \(D^p_1,\ldots,D^p_{c_p}\). A set is consistent if \(D^p_t\) in it implies \(D^p_{t'}\) is in it for every \(t'<t\). Ground truths are consistent \(g\subseteq D\) with \(|g|=B\).
The input lists report types \(r\subseteq D\), \(|r|\leq B\), with rational masses \(\nu_r\geq0\) summing to \(1\). For \(\mathcal R=\{q\subseteq D:|q|\leq B\}\), let \(P(r\mid g)=\exp(|g\cap r|)/\sum_{q\in\mathcal R}\exp(|g\cap q|)\).
Fix a strict order \(\prec\) on \(D\) with \(D^p_t\prec D^p_{t+1}\); among objective maximizers, select the set containing the \(\prec\)-earliest differing subproject.

Target

Is computing \(g^\star\in\arg\max_{g}\sum_r\nu_r\log P(r\mid g)\), subject to the preceding feasibility and tie-breaking rules, solvable in polynomial time, or is it NP-hard?

Nearest known results

For an explicit finite profile under this noise model, the discrete Knapsack rule is a maximum-likelihood estimator: it maximizes the total overlap \(\sum_i |g\cap r_i|\). The corresponding discrete rule is computable in polynomial time by per-subproject scores and the prescribed tie-breaking order.

Prover output (gpt-6-astra / medium, Bolzano prover prompt)

Computing the prescribed ground truth is polynomial-time solvable, including exact tie-breaking for rational report masses.

Assume the project chains and report types are explicitly listed. Write \(n=|D|\). We consider \(0\leq B\leq n\); otherwise no feasible ground truth exists.

First, the likelihood normalizer is independent of the particular ground truth. For any \(g\subseteq D\) with \(|g|=B\), a report \(q\) with \(|g\cap q|=k\) and \(|q\setminus g|=\ell\) can be chosen in exactly \(\binom{B}{k}\binom{n-B}{\ell}\) ways. Consequently its normalizer is

\(Z_{n,B}=\displaystyle\sum_{k=0}^{B}\binom{B}{k}e^k\sum_{\ell=0}^{\min(B-k,n-B)}\binom{n-B}{\ell}.\)

This uses the stated report space: reports may be any subsets of size at most \(B\), without a consistency restriction. Thus, because \(\sum_r\nu_r=1\),

\(\displaystyle\sum_r\nu_r\log P(r\mid g)=\sum_r\nu_r|g\cap r|-\log Z_{n,B}=\sum_{d\in g}s_d-\log Z_{n,B},\)

where \(s_d=\sum_{r:\,d\in r}\nu_r\). Maximizing the likelihood therefore amounts exactly to maximizing \(\sum_{d\in g}s_d\). No numerical evaluation of exponentials or logarithms is needed.

Next, both rational scores and tie-breaking can be handled with integers of polynomial bit length. Express each listed mass as \(\nu_r=u_r/v_r\), with integers \(u_r\geq0\) and \(v_r>0\), and put

\(L=\prod_r v_r,\qquad a_d=\sum_{r:\,d\in r}u_r(L/v_r)=Ls_d.\)

The integer \(L\) has bit length at most a constant plus the sum of the denominator bit lengths in the input. Moreover, \(0\leq a_d\leq L\), since \(0\leq s_d\leq1\). Scaling by \(L>0\) preserves all objective comparisons and ties.

List the elements in the prescribed order as \(d_1\prec\cdots\prec d_n\). Define integer weights

\(w_{d_j}=2^n a_{d_j}+2^{n-j}.\)

For a subset \(S\), write \(A(S)=\sum_{d\in S}a_d\) and \(T(S)=\sum_{d_j\in S}2^{n-j}\). Its new weight is \(2^nA(S)+T(S)\), with \(0\leq T(S)\leq2^n-1\).

If \(A(S)>A(S')\), integrality gives \(A(S)-A(S')\geq1\), and hence

\(\displaystyle\sum_{d\in S}w_d-\sum_{d\in S'}w_d\geq2^n-(2^n-1)>0.\)

Thus the new objective preserves every strict comparison under the original objective. If \(A(S)=A(S')\), let \(d_j\) be the earliest differing element. Its contribution \(2^{n-j}\) exceeds the sum of all later contributions, because

\(\displaystyle\sum_{h=j+1}^{n}2^{n-h}=2^{n-j}-1.\)

Therefore the new objective prefers precisely the set containing \(d_j\). It implements the required tie-breaking exactly, and distinct subsets have distinct new objective values whenever their original scores tie.

Finally, optimize these weights by dynamic programming over the chains. Let there be \(m\) nonempty chains, and define their prefix weights by

\(W_p(k)=\sum_{t=1}^{k}w_{D^p_t}\quad\text{for }0\leq k\leq c_p,\qquad W_p(0)=0.\)

By consistency, a feasible set intersects each chain in a prefix. Conversely, every union of chain prefixes is consistent. Thus feasible sets correspond exactly to choices \(k_p\in\{0,\ldots,c_p\}\) satisfying \(\sum_{p=1}^{m}k_p=B\).

Let \(F(p,b)\) be the greatest weight of prefixes from the first \(p\) chains containing exactly \(b\) elements. Initialize \(F(0,0)=0\) and \(F(0,b)=-\infty\) for \(b>0\). The recurrence is

\(\displaystyle F(p,b)=\max_{0\leq k\leq\min(c_p,b)}\bigl(F(p-1,b-k)+W_p(k)\bigr).\)

To verify it, any choice counted by \(F(p,b)\) selects some prefix length \(k\) from chain \(p\); its other prefixes contain exactly \(b-k\) elements and have weight at most \(F(p-1,b-k)\). Conversely, every finite candidate in the recurrence is attained by adjoining that prefix to a maximizing choice for \(F(p-1,b-k)\). Induction on \(p\) proves the recurrence computes the optimum. Storing maximizing choices and tracing back from \(F(m,B)\) recovers the required set.

There is a feasible choice for every integer \(B\) between \(0\) and \(n\): successively take as many elements as possible from each chain until a total of \(B\) is reached. For \(n=0\), the only feasible case is \(B=0\), whose answer is the empty set.

The recurrence examines at most \((B+1)\sum_p(c_p+1)=(B+1)(n+m)\) candidates. Since \(m\leq n\) and \(B\leq n\), this is polynomial in the explicit input size, rather than merely pseudopolynomial. All weights and finite table entries have bit length \(O(n+\log L+\log(n+1))\), so their exact arithmetic also takes polynomial time.

Hence the algorithm returns exactly the likelihood-maximizing consistent set of size \(B\), with the specified tie-breaking, in polynomial time.
