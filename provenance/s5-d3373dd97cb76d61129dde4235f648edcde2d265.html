The continuous mirror question, as graded

Given a finite type set \(T\), a rational population distribution \(\mu\), symmetric valuation matrices \(v,v'\) with entries in \(\{-1,0,1\}\) differing on one unordered pair of distinct types, a starting NS partition \(\mathcal P^0=(q^1,\ldots,q^r;\sigma^0)\) under \(v\), and a rational threshold \(\kappa\), does there exist a finite rational post-update NS partition \(\mathcal P'=(p^1,\ldots,p^s;\sigma')\) under \(v'\) with distance at most \(\kappa\)? Each coalition vector is in \(\mathbb Q_{\ge0}^{|T|}\), and the vectors and singleton pool sum to \(\mu\). With \(U_t(q)=\sum_{u\in T}v'_{tu}q_u\), every type \(t\) present in an occupied coalition \(q\) must satisfy \(U_t(q)\ge0\) and \(U_t(q)\ge U_t(r)\) for every occupied coalition \(r\); if \(\sigma'_t>0\), then \(U_t(q)\le0\) for every occupied \(q\). Define distance by \(d_\mu=1-\sum_t\min(\sigma^0_t,\sigma'_t)-\max_{M}\sum_{(i,j)\in M}\sum_{t\in T}\min(q^i_t,p^j_t)\), where \(M\) ranges over partial one-to-one matchings of old and new occupied coalitions.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a list \(T\) of \(\tau\ge2\) types with positive binary rational masses \(\mu_t\), where \(\sum_{t\in T}\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types; the matrix dimension is \(m=\tau\).
The input contains symmetric matrices \(v,v'\in\{-1,0,1\}^{T\times T}\) differing on exactly one unordered pair of distinct types. Diagonal entries describe valuations between distinct individuals of the same type and remain unchanged.
A partition \(\mathcal P=(c^1,\ldots,c^h;\sigma)\) consists of finitely many nonzero vectors \(c^i\in\mathbb Q_{\ge0}^{T}\) and a singleton pool \(\sigma\in\mathbb Q_{\ge0}^{T}\), with \(\sum_i c^i+\sigma=\mu\); types may split among coalitions and the pool. The pool represents individuals alone, each with utility zero, and is not an occupied coalition; \(h=0\) is allowed.
For \(w\in\{v,v'\}\), set \(U_t^w(c)=\sum_{u\in T}w_{tu}c_u\). Nash stability (NS) means that whenever \(c_t^i>0\), both \(U_t^w(c^i)\ge0\) and \(U_t^w(c^i)\ge U_t^w(c^j)\) hold for every occupied coalition \(c^j\); whenever \(\sigma_t>0\), every occupied coalition satisfies \(U_t^w(c^j)\le0\). Individuals are nonatomic, and utility ties permit staying.
The input also contains an explicitly listed starting partition \(\mathcal P^0=(q^1,\ldots,q^r;\sigma^0)\) promised NS under \(v\), and a binary rational threshold \(\kappa\ge0\).
For \(\mathcal P'=(p^1,\ldots,p^s;\sigma')\), define \(d_\mu(\mathcal P^0,\mathcal P')=1-\sum_{t\in T}\min(\sigma_t^0,\sigma'_t)-\max_M\sum_{(i,j)\in M}\sum_{t\in T}\min(q_t^i,p_t^j)\), where \(M\) ranges over partial one-to-one matchings between the two lists of occupied coalitions.

Is deciding whether there exists a finite rational partition \(\mathcal P'\), NS under \(v'\), with \(d_\mu(\mathcal P^0,\mathcal P')\le\kappa\), in \(\mathrm P\) or NP-hard? State running times in \(m,\tau,r,L\), where \(L\) is the total input bit length; the output coalition count \(s\) has no prescribed bound.

For finite agents, this decision problem with symmetric valuations in \(\{-1,0,1\}\), an NS starting partition, and one pair updated is NP-complete ([Frank, Novaković, and Romen](https://arxiv.org/html/2602.21041v1)).
No published result settling the exact mass-partition problem defined above was located in the literature search.

Result

The decision problem is \(\mathrm{NP}\)-hard, even when all masses and the threshold are dyadic rationals.

The reduction below handles arbitrary splitting of types and arbitrarily many output coalitions. It does not rely on transferring the finite-agent hardness result.

1. Source problem and construction

We reduce from Exact Cover by 3-Sets. An instance consists of a universe \(E\), with \(|E|=n=3k\) and \(k\ge1\), and a listed family \(\mathcal S=(S_1,\ldots,S_\ell)\) of three-element subsets of \(E\). The question is whether exactly \(k\) of these sets partition \(E\).

This problem is \(\mathrm{NP}\)-complete: three-dimensional matching reduces to it by taking the disjoint union of the three coordinate sets as the universe and interpreting each allowed triple as a three-element subset. See [Karp, *Reducibility among Combinatorial Problems*](https://link.springer.com/chapter/10.1007/978-1-4684-2001-2_9).

Masses

There is one type for each element \(e\in E\), one type \(t_j\) for each set \(S_j\), and five additional types \(a,b,y,z,o\). Thus

\(m=\tau=n+\ell+5.\)

Choose

\(d=\left\lceil\log_2(10(k+1))\right\rceil,\qquad \delta=2^{-d},\)

\(h=\left\lceil\log_2(2(n+\ell+4))\right\rceil,\qquad \eta=2^{-h}.\)

Set

\(W=n+2+(\ell+2)\delta,\qquad \theta=\eta^{-1}-W.\)

Because \(W\le n+\ell+4\) and \(\eta^{-1}\ge2(n+\ell+4)\), we have \(\theta>0\).

The actual masses are

\(\mu_e=\mu_y=\mu_z=\eta,\)

\(\mu_a=\mu_b=\mu_{t_j}=\eta\delta,\)

\(\mu_o=\eta\theta=1-\eta W.\)

They are positive dyadic rationals and sum to one.

For the proof, we use unnormalized coordinates, obtained by dividing every mass vector by \(\eta\). Element types and \(y,z\) then have mass \(1\); \(a,b,t_j\) have mass \(\delta\); and \(o\) has mass \(\theta\). This scaling preserves every NS inequality.

Valuations

Every diagonal entry is \(1\), except

\(v_{bb}=-1,\qquad v_{oo}=0.\)

The nonzero off-diagonal entries of \(v\), specified symmetrically, are:

  • \(v_{ab}=v_{ay}=v_{az}=v_{yz}=1\).
  • \(v_{ae}=v_{ye}=1\) for every \(e\in E\).
  • \(v_{be}=v_{b t_j}=-1\) for every \(e\in E\) and every \(j\).
  • \(v_{e t_j}=-1\) precisely when \(e\in S_j\).

Every other off-diagonal entry is zero. In particular, the entire row and column of \(o\) are zero.

The update changes only

\(v_{ab}=1\quad\text{to}\quad v'_{ab}=-1.\)

All diagonals remain unchanged.

Starting partition and threshold

In unnormalized coordinates, the starting occupied coalitions are:

  • A main coalition containing masses \(y=z=1\) and \(a=b=\delta\).
  • For each \(e\in E\), a coalition containing only its entire mass \(1\).

The singleton pool contains all set types, each of mass \(\delta\), and all mass \(\theta\) of \(o\). Hence

\(r=n+1.\)

The threshold is

\(\kappa=\eta(k+1)\delta.\)

2. The starting partition satisfies the promise

The following table gives each occupied type’s utility in its coalition and its largest utility in another occupied coalition, using unnormalized coordinates.

| Type | Current utility | Largest utility elsewhere |
|---|---:|---:|
| \(a\) | \(2+2\delta\) | \(1\) |
| \(y\) | \(2+\delta\) | \(1\) |
| \(z\) | \(2+\delta\) | \(0\) |
| \(b\) | \(0\) | \(-1\) |
| Each \(e\in E\) | \(1\) | \(1\) |

For example, an element type evaluates the main coalition as

\(U_e^v(\text{main})=1+\delta-\delta=1,\)

which equals its utility in its own coalition.

A pooled set type evaluates the main coalition as \(-\delta\), and an element coalition as either \(-1\) or \(0\). Type \(o\) evaluates every coalition as zero.

Thus every occupied type attains a nonnegative maximum utility, and every pooled type evaluates all occupied coalitions nonpositively. The starting partition is NS under \(v\).

3. An exact cover gives a nearby stable partition

Suppose \(\mathcal C\subseteq\mathcal S\) is an exact cover.

Move all mass of \(b\) into the pool, and move the entire mass of every set type corresponding to \(\mathcal C\) into the main coalition. Leave everything else in its initial location.

Under \(v'\):

  • Types \(a,y,z\) each have main-coalition utility \(2+\delta\), exceeding their utilities elsewhere.
  • Every element type has utility \(1\) in its own coalition. Because exactly one selected set contains it, its main-coalition utility is

\(1+\delta-\delta=1\).

  • Each selected set type has utility \(\delta\) in the main coalition and nonpositive utility elsewhere.
  • Each unselected, pooled set type evaluates the main coalition as zero and every element coalition nonpositively.
  • Pooled type \(b\) evaluates the main coalition as \(-(k+1)\delta\) and each element coalition as \(-1\).
  • Type \(o\) remains indifferent.

Therefore this partition is NS under \(v'\).

Match each original occupied coalition to its corresponding new coalition. This matching retains all original occupied mass except \(b\), while the pool retains all original pooled mass except the \(k\) selected set types. Consequently,

\(d_\mu(\mathcal P^0,\mathcal P')\le \eta(\delta+k\delta)=\kappa.\)

The constructed partition is finite and rational.

4. Every nearby stable partition gives an exact cover

Now suppose an arbitrary finite rational partition \(\mathcal P'\) is NS under \(v'\) and satisfies the threshold. No restriction is imposed on its coalition count.

Use unnormalized coordinates and write

\(D=\eta^{-1}d_\mu(\mathcal P^0,\mathcal P').\)

Then

\(D\le(k+1)\delta\le\frac1{10}.\)

Choose a matching attaining the maximum in the distance definition.

4.1. Every original occupied coalition is matched

The distance is the sum of unretained initial mass: the pool’s unretained mass plus, for each original occupied coalition, its mass minus its matched overlap.

Every original occupied coalition has unnormalized mass at least \(1\). Leaving any one unmatched would therefore give \(D\ge1\), contradicting the threshold.

Denote the output coalition matched to the original main coalition by \(c^0\), and the output coalition matched to the original element coalition of \(e\) by \(c^e\). These coalitions are pairwise distinct.

Each type was initially located entirely in one coalition or entirely in the pool. Its mass in that original location bounds its retained overlap. Thus the distance has the exact expression

\(\displaystyle D=(1-c_y^0)+(1-c_z^0)+(\delta-c_a^0)+(\delta-c_b^0) +\sum_{e\in E}(1-c_e^e) +\sum_{j=1}^{\ell}(\delta-\sigma'_{t_j}) +(\theta-\sigma'_o). \)

Every summand is nonnegative.

4.2. Type \(b\) must be entirely pooled

Under \(v'\), every entry in row \(b\) is nonpositive, and \(v'_{bb}=-1\). If an occupied coalition contained positive \(b\)-mass, its \(b\)-utility would be strictly negative. This contradicts NS.

Therefore all \(b\)-mass is pooled, so \(c_b^0=0\). Define

\(R=D-\delta.\)

The preceding distance identity gives

\(\displaystyle R=(1-c_y^0)+(1-c_z^0)+(\delta-c_a^0) +\sum_{e\in E}(1-c_e^e) +\sum_j(\delta-\sigma'_{t_j}) +(\theta-\sigma'_o), \)

and

\(0\le R\le k\delta<\frac1{10}.\)

In particular,

\(c_y^0,c_z^0,c_e^e\ge1-R,\)

and the total occupied mass of all set types is at most \(R\).

4.3. All mass of \(a,y,z\) lies in \(c^0\)

Because \(b\) is absent from occupied coalitions, for every occupied coalition \(c\),

\(\displaystyle U_a^{v'}(c)=U_y^{v'}(c)=c_a+c_y+c_z+\sum_{e\in E}c_e,\)

and

\(U_z^{v'}(c)=c_a+c_y+c_z.\)

Their utilities in \(c^0\) are therefore at least \(2-2R\).

Consider any occupied coalition \(c\ne c^0\). It can equal \(c^e\) for at most one element \(e\). Its mass of that element is at most \(1\). All other element mass in \(c\), together with its \(a,y,z\)-mass, contributes to the nonnegative losses making up \(R\). Hence

\(U_a^{v'}(c)=U_y^{v'}(c)\le1+R,\qquad U_z^{v'}(c)\le R.\)

Since \(R<1/10\),

\(2-2R>1+R>0.\)

Thus \(a,y,z\) strictly prefer \(c^0\) to every other occupied coalition and to the pool. NS forces their entire masses into \(c^0\):

\(c_a^0=\delta,\qquad c_y^0=c_z^0=1.\)

4.4. Each element can occupy only \(c^e\) and \(c^0\)

At \(c^e\), type \(e\) has its positive diagonal contribution and possibly negative contributions from incident set types. Consequently,

\(U_e^{v'}(c^e)\ge c_e^e-R\ge1-2R.\)

For any occupied coalition \(c\notin\{c^0,c^e\}\), its \(e\)-mass is at most the mass missing from \(c^e\), hence at most \(R\). Types \(a,y\) are absent there, and all remaining nonzero contributions to \(e\)-utility are negative. Thus

\(U_e^{v'}(c)\le R.\)

Because \(1-2R>R\) and \(1-2R>0\), NS excludes both these other coalitions and the pool for type \(e\).

Write

\(x_e=c_e^0.\)

Then \(c_e^e=1-x_e\), and all its remaining mass is in \(c^e\).

4.5. No incident set type can occupy \(c^e\)

If \(e\in S_j\), then

\(U_{t_j}^{v'}(c^e)\le c_{t_j}^e-c_e^e\le\delta-(1-R)<0.\)

Here \(\delta\le1/20\) and \(R<1/10\). NS therefore implies \(c_{t_j}^e=0\).

It follows that the element’s utility in its retained coalition is exactly

\(U_e^{v'}(c^e)=1-x_e.\)

Define

\(x_j=c_{t_j}^0,\qquad C_e=\sum_{j:e\in S_j}x_j.\)

Its main-coalition utility is

\(U_e^{v'}(c^0)=1+\delta+x_e-C_e.\)

Since \(c_e^e\ge1-R>0\), NS requires

\(1-x_e\ge1+\delta+x_e-C_e.\)

Therefore, for every element,

\(C_e\ge\delta+2x_e.\)

If \(x_e>0\), stability in both occupied coalitions additionally makes this inequality an equality, although that equality is not needed below.

4.6. The budget eliminates every fractional selection

Let

\(D_j=\delta-\sigma'_{t_j},\qquad D_o=\theta-\sigma'_o.\)

These are the masses of the corresponding initially pooled types placed into occupied coalitions. In particular, \(0\le x_j\le D_j\).

After the preceding conclusions, the distance identity becomes

\(\displaystyle D=\delta+\sum_e x_e+\sum_j D_j+D_o.\)

Hence

\(\displaystyle \sum_e x_e+\sum_j x_j\le k\delta.\)

Every set contains exactly three elements, so summing the element inequalities gives

\(\displaystyle 3\sum_j x_j=\sum_e C_e \ge3k\delta+2\sum_e x_e. \)

Combining these bounds yields

\(\displaystyle 3k\delta+2\sum_e x_e \le3\sum_j x_j \le3k\delta-3\sum_e x_e. \)

All \(x_e\) are nonnegative. Therefore

\(\displaystyle \sum_e x_e=0,\qquad \sum_j x_j=k\delta.\)

The distance bound and \(D_j\ge x_j\) now force

\(D_j=x_j\ \text{for every }j,\qquad D_o=0.\)

In particular, all occupied mass of any set type lies in \(c^0\).

There is no element mass in \(c^0\), and no occupied \(b\)-mass. Thus if \(x_j>0\),

\(U_{t_j}^{v'}(c^0)=x_j>0.\)

Such a type cannot have positive mass in the pool: the pool condition would require this utility to be nonpositive. Therefore \(\sigma'_{t_j}=0\), giving

\(x_j=D_j=\delta.\)

Every \(x_j\) is consequently either \(0\) or \(\delta\). Since their sum is \(k\delta\), exactly \(k\) set types are selected.

Finally, \(C_e\ge\delta\) for every element, while

\(\displaystyle \sum_e C_e=3\sum_jx_j=3k\delta=n\delta.\)

Hence \(C_e=\delta\) for every element. Since selected sets contribute exactly \(\delta\), each element belongs to exactly one selected set. These \(k\) sets form an exact cover.

5. Complexity and unrestricted output size

The construction satisfies

\(m=\tau=3k+\ell+5,\qquad r=3k+1\le\tau.\)

Every input rational has \(O(\log\tau)\) bits. Under explicit matrix and coalition-vector encodings, its total length is

\(L=O(m^2+\tau r+\tau\log\tau).\)

A conservative bound for constructing the instance is

\(O((m^2+\tau r+\tau)\log^2\tau)\)

bit operations, which is polynomial in \(L\).

The reverse implication examined every finite output partition, including partitions with additional unmatched coalitions. It proved that every threshold-feasible stable output has all occupied mass in \(c^0\) and the \(c^e\), so such an output actually has \(s=r\). Thus allowing an unbounded output coalition count does not invalidate the reduction.

This establishes \(\mathrm{NP}\)-hardness of the exact problem asked. General membership in \(\mathrm{NP}\) is not required for this conclusion and is not asserted here.
