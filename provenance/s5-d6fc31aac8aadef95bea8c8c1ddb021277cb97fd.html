The anchor (named result in the paper)

Proposition A.1 — class: hardness

The continuous mirror question, as graded

Given recipient types \(r\) with incumbent bundles \(B_r\) and rational masses \(\mu_r\), and indivisible good types \(s\) with rational supplies \(\lambda_s\), where \(\sum_r\mu_r=\sum_s\lambda_s=1\), a common additive valuation accessible by comparison queries, and a highest-valued incumbent bundle \(B_{\max}\): determine whether there are masses \(x_{rs}\ge 0\) with row sums \(\mu_r\), column sums \(\lambda_s\), and \(x_{rs}=0\) unless the query certifies \(u(B_r\cup\{g_s\})\ge u(B_{\max})\). If so, output such an assignment; otherwise, certify infeasibility in the graph of query-certified pairs.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: the list of \(\tau\) recipient types with positive masses \(\mu_r\), each a binary rational; \(\tau\) is the support size, not the number of possible types.
There are \(k\ge 1\) fresh good types, represented by distinct goods \(g_s\), with positive binary rational supplies \(\lambda_s\); \(\sum_r\mu_r=\sum_s\lambda_s=1\). Each recipient has an explicitly listed incumbent bundle \(B_r\), containing no fresh good. Let \(m\) count all distinct good labels and \(L\) be the total binary input length.
All recipients share a normalized additive valuation \(u\) with nonnegative real singleton values, accessible only through comparisons. A query \(\operatorname{Comp}(X,Y)\) returns true when \(u(X)<u(Y)\), false when \(u(X)>u(Y)\), and either answer at equality. A supplied incumbent bundle \(B_{\max}\) is promised to maximize incumbent value.
For every pair \((r,s)\), make one query \(\operatorname{Comp}(B_r\cup\{g_s\},B_{\max})\). Its recorded false answer defines an allowed edge; all other pairs are forbidden. Subsequent answers do not change this graph.
Decide whether there is a nonnegative rational matrix \(x\) with \(\sum_s x_{rs}=\mu_r\), \(\sum_r x_{rs}=\lambda_s\), and \(x_{rs}=0\) on forbidden pairs. If feasible, output such a matrix; otherwise, certify infeasibility in the recorded graph. Mass may split among good types, but each represented recipient receives one whole fresh good.

Is this mass assignment problem solvable in polynomial time, counting comparison queries at unit cost, or is it NP-hard? State running time and query complexity in \(m,\tau,k,L\).

For discrete witness extension, a bijection assigns one fresh good to each incumbent bundle and must satisfy \(u(B_i\cup\{g_{\sigma(i)}\})\ge u(B_j)\) for every \(i,j\). Deterministic comparison algorithms require \(\Omega(n\log n)\) queries; the same bound holds for randomized algorithms with constant success probability, even with identical additive valuations. This is a query lower bound, not an NP-hardness result; no continuous complexity result is established by that bound.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Result

The problem is polynomial-time solvable, with exactly \(\tau k\) comparison queries. After these queries, feasibility and an exact rational assignment can be computed without further access to the valuation.

Set \(n=\tau+k\). One explicit deterministic bit-operation bound is
\[ O\!\left(\tau k(m+L)+nL^2+(n+2)(\tau k+n)^2L\right). \]
The algorithm also produces a verifiable infeasibility certificate when no assignment exists.

1. Fix the recorded graph

Let \(R=\{1,\ldots,\tau\}\) index recipient types and \(S=\{1,\ldots,k\}\) index fresh good types. Define
\[ E_{\mathrm{allow}} =\{(r,s):\operatorname{Comp}(B_r\cup\{g_s\},B_{\max}) \text{ recorded false}\}. \]
Make precisely the prescribed \(\tau k\) queries and retain these answers.

For every allowed pair, the comparison contract implies
\[ u(B_r\cup\{g_s\})\ge u(B_{\max}). \]
Indeed, a strictly smaller value would require a true answer. The promise concerning \(B_{\max}\) therefore gives
\[ u(B_r\cup\{g_s\})\ge u(B_j) \quad\text{for every incumbent type }j. \]

An equality answered true remains forbidden. All subsequent arguments concern this fixed recorded graph, as required.

2. Scale the rational masses exactly

Write the input masses and supplies as
\[ \mu_r=\frac{a_r}{b_r}, \qquad \lambda_s=\frac{c_s}{d_s}, \]
with positive integer numerators and denominators. Reduction to lowest terms is unnecessary.

Choose
\[ D=\left(\prod_r b_r\right)\left(\prod_s d_s\right), \qquad M_r=D\mu_r, \qquad \Lambda_s=D\lambda_s. \]
These are positive integers, and
\[ \sum_r M_r=\sum_s\Lambda_s=D. \]

Although \(D\) may be numerically large, its binary encoding has \(O(L)\) bits: its logarithm is the sum of the logarithms of the input denominators. Every \(M_r\) and \(\Lambda_s\) is at most \(D\), so these integers also have \(O(L)\) bits.

3. Construct a flow network

Introduce a source \(a\), a sink \(b\), one vertex for each recipient type, and one vertex for each fresh good type. Add the following directed arcs:

  • \(a\to r\), of capacity \(M_r\), for every recipient type \(r\);
  • \(r\to s\), of capacity \(D\), for every allowed pair \((r,s)\);
  • \(s\to b\), of capacity \(\Lambda_s\), for every fresh good type \(s\).

There are \(V=n+2\) vertices and \(E=|E_{\mathrm{allow}}|+n\) arcs, with \(E\le \tau k+n\).

Claim. The requested matrix exists if and only if this network admits a flow of value \(D\).

Proof. Given a feasible matrix \(x\), assign flows \(M_r\) to \(a\to r\), \(Dx_{rs}\) to each allowed \(r\to s\), and \(\Lambda_s\) to \(s\to b\). The matrix equations give flow conservation. Furthermore, \(0\le x_{rs}\le 1\), so every middle-arc capacity is respected. The flow value is \(D\).

Conversely, suppose a flow \(f\) has value \(D\). The source arcs have total capacity \(D\), so all are saturated. Likewise, all sink arcs are saturated. Define
\[ x_{rs}= \begin{cases} f(r,s)/D,&(r,s)\in E_{\mathrm{allow}},\\ 0,&(r,s)\notin E_{\mathrm{allow}}. \end{cases} \]
Flow conservation gives
\[ \sum_s x_{rs}=M_r/D=\mu_r, \qquad \sum_r x_{rs}=\Lambda_s/D=\lambda_s. \]
Thus \(x\) is feasible. The algorithm below produces integer flows, ensuring that its output matrix is rational. \(\square\)

4. Compute the flow in polynomial time

Start with the zero flow. For each original arc \(v\to w\) of capacity \(c\) and current flow \(f\), its residual arcs have forward capacity \(c-f\) and backward capacity \(f\); omit residual arcs of zero capacity.

Repeatedly use breadth-first search to find a shortest residual path from \(a\) to \(b\). If one exists, augment by the minimum residual capacity on that path. Stop upon reaching value \(D\), or when no such path exists.

All capacities and flows remain integers: they start integral, and each augmentation amount is an integer. Each augmentation preserves capacity constraints and flow conservation.

For completeness, the number of augmentations is polynomial independently of the numerical value of \(D\).

Let \(d(v)\) be the shortest residual distance from \(a\) immediately before an augmentation, with unreachable vertices assigned infinite distance. Every retained residual arc \(v\to w\) satisfies \(d(w)\le d(v)+1\). A newly activated residual arc is the reverse of an arc on the selected shortest path. For such a new arc \(v\to w\), the old distances satisfy \(d(w)=d(v)-1\). Consequently, along any residual path after augmentation, old distances are at most the corresponding path-prefix lengths. Thus residual distances never decrease.

Every augmentation saturates at least one directed residual arc. Suppose an orientation \(v\to w\) is saturated, so \(d(w)=d(v)+1\). Before that orientation can be saturated again, an intervening augmentation must traverse its reverse \(w\to v\). At that intervening step, with distances denoted by \(d'\),
\[ d'(v)=d'(w)+1\ge d(w)+1=d(v)+2. \]
By distance monotonicity, the distance of \(v\) at the next saturation has increased by at least two. Finite distances are at most \(V-1\), so each directed residual orientation is saturated only \(O(V)\) times. There are at most \(2E\) orientations, giving \(O(VE)\) augmentations.

Each breadth-first search and augmentation takes \(O(V+E)=O(E)\) arithmetic operations, since \(E\ge V-2\). The total is therefore \(O(VE^2)\) arithmetic operations.

5. Produce an infeasibility certificate

Suppose the algorithm stops with flow value \(F<D\) and no residual path from \(a\) to \(b\).

Let \(Q\) be the vertices reachable from \(a\) in the final residual graph. Define \(A=Q\cap R\) and \(C=Q\cap S\). The source belongs to \(Q\), and the sink does not.

Every original arc leaving \(Q\) is saturated; otherwise its positive forward residual capacity would make its endpoint reachable. Every original arc entering \(Q\) has zero flow; otherwise its positive backward residual capacity would make its starting vertex reachable. Summing flow conservation over \(Q\) therefore shows that \(F\) equals the capacity of the cut leaving \(Q\).

For a recipient subset \(A\), define its allowed neighborhood by
\[ N(A)=\{s:\text{some }r\in A\text{ has }(r,s)\in E_{\mathrm{allow}}\}. \]
We have \(N(A)\subseteq C\). To prove this, suppose an allowed arc \(r\to s\) had \(r\in A\) and \(s\notin C\). Since it leaves \(Q\), it would carry its full capacity \(D\). But every middle-arc flow is at most the total flow \(F<D\), a contradiction.

Hence no middle arc leaves \(Q\), and its cut capacity is
\[ F=\sum_{r\notin A}M_r+\sum_{s\in C}\Lambda_s =D-\sum_{r\in A}M_r+\sum_{s\in C}\Lambda_s. \]
Because \(F<D\),
\[ \sum_{r\in A}M_r>\sum_{s\in C}\Lambda_s \ge\sum_{s\in N(A)}\Lambda_s. \]
Dividing by \(D\) gives the certificate
\[ \sum_{r\in A}\mu_r>\sum_{s\in N(A)}\lambda_s. \]

This inequality directly proves infeasibility. Any proposed feasible matrix would have to satisfy
\[ \sum_{r\in A}\mu_r =\sum_{s\in N(A)}\sum_{r\in A}x_{rs} \le\sum_{s\in N(A)}\sum_r x_{rs} =\sum_{s\in N(A)}\lambda_s, \]
contradicting the certificate.

Thus the algorithm either returns the requested matrix or returns a recipient subset whose mass exceeds the supply of all its allowed neighbors. Verification uses only the input rationals and recorded graph.

6. Bit complexity and interpretation

Using \(m\)-bit incidence vectors for bundles, graph construction takes \(O(L^2+\tau k m)\) bit operations, including a conservative allowance for indexing the input good labels. It uses exactly \(\tau k\) unit-cost comparison queries.

Elementary integer arithmetic computes \(D\), \(M_r\), and \(\Lambda_s\) in \(O(nL^2)\) bit operations. Throughout the flow algorithm, capacities, flows, and residual capacities have \(O(L)\) bits. Its additions, subtractions, and comparisons therefore give an \(O(VE^2L)\) bit-operation bound.

Output each entry as an integer numerator over \(D\), without requiring fraction reduction. A dense matrix needs \(O(\tau kL)\) output bits. Combining these bounds yields
\[ O\!\left(\tau k(m+L)+nL^2+(n+2)(\tau k+n)^2L\right). \]
This is polynomial in the stated input parameters.

The matrix splits recipient mass: for each type \(r\), a subpopulation of mass \(x_{rs}\) receives one whole good of type \(s\). It does not give an individual recipient a fractional fresh good.

Finally, the stated discrete-witness lower bound concerns comparison queries. It is compatible with polynomial-time solvability and does not imply NP-hardness of this mass-assignment problem. The complete algorithm and proof above establish the continuous complexity result independently.
