Proposition 7.6 — class: algorithmic

The continuous mirror question, as graded

Given a finite type set \(T\), binary-rational masses \(\mu_i\) summing to one, and a link matrix \(A\) where \(A_{ij}=1\) means every member of type \(i\) links to every member of type \(j\), compute the exact weak order of the types. Let \(D\) be the least common denominator of the masses and define \(d_j=D\sum_i\mu_iA_{ij}\). Rank types by the scores \(q_j=0\) when \(j\) has no predecessor type, and otherwise \(q_j=(d_j+\max_{i:A_{ij}=1}q_i)/(D+1)\), including ties.

Packaged proof task (what the prover saw — nothing else)

A society is given by its support \(T=\{1,\ldots,\tau\}\): the list of types with positive binary-rational masses \(\mu_i\), where \(\sum_i\mu_i=1\). Here \(\tau\) is the support size, not the number of possible types. The agents and alternatives are the same society.
The input also contains \(A\in\{0,1\}^{\tau\times\tau}\), where \(A_{ij}=1\) means every member of type \(i\) links to every member of type \(j\); diagonal entries and directed cycles are allowed. Let \(m=\sum_{i,j}A_{ij}\) and let \(L\) be the total input bit length.
Write each mass in lowest terms and let \(D\) be the least common multiple of its denominators. Define \(P(j)=\{i:A_{ij}=1\}\) and \(d_j=D\sum_i\mu_iA_{ij}\).
The scores are the unique vector \(q\in[0,1]^\tau\) satisfying \(q_j=0\) if \(P(j)=\varnothing\), and otherwise \(q_j=(d_j+\max_{i\in P(j)}q_i)/(D+1)\). The required output is the exact weak order \(j\preceq k\iff q_j\le q_k\), preserving all ties.

Is computing this exact weak order solvable in polynomial time in \(m,\tau,L\), or is it NP-hard?

For explicitly listed finite agents, identity-rank recursive in-degree ranking has a claimed \(O(|V|\,|E|)\)-time algorithm. [Altman and Tennenholtz (2008)](https://auld.aaai.org/Papers/JAIR/Vol31/JAIR-3114.pdf).
No result settling the exact rational-mass problem above was identified in the literature search.

Modeling choices made when packaging the task

  • Restricted the listed types to positive masses, as required by the support convention.
  • Made the cyclic score equations simultaneous fixed-point equations and specified their unique solution in the closed unit cube.
  • Allowed diagonal links and directed cycles, consistent with the unrestricted directed-graph domain.
  • Specified reduced denominators when defining D.
  • Defined m as the number of nonzero type links and L as the total input bit length; complexity is measured in the binary input rather than the numerical value of D.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

1. Result

Computing the exact weak order is polynomial-time solvable in the binary input model, including preservation of every tie.

The proof below works directly with the support representation. It does not require expanding the society into explicitly listed agents or invoking the finite-agent algorithm in [Altman and Tennenholtz (2008)](https://auld.aaai.org/Papers/JAIR/Vol31/JAIR-3114.pdf).

2. Integer normalization and approximation

Write each mass in lowest terms as \(\mu_i=a_i/b_i\), and set \(B=D+1\). The integers \(w_i=a_i(D/b_i)\) satisfy \(w_i>0\) and \(\sum_i w_i=D\). Consequently,
\(d_j=\sum_{i\in P(j)}w_i\) is an integer satisfying \(0\le d_j\le D\).

Define \(F:[0,1]^\tau\to[0,1]^\tau\) by

\[ F(x)_j= \begin{cases} 0,&P(j)=\varnothing,\\ (d_j+\max_{i\in P(j)}x_i)/B,&P(j)\ne\varnothing. \end{cases} \]

Here and below, displayed equations are understood as the corresponding inline mathematics: \(F(x)_j=0\) for empty predecessor sets, and \(F(x)_j=(d_j+\max_{i\in P(j)}x_i)/B\) otherwise.

The map takes the cube into itself because \(d_j\le D=B-1\). For any nonempty predecessor set,

\(\left|\max_{i\in P(j)}x_i-\max_{i\in P(j)}y_i\right|\le\|x-y\|_\infty\).

Thus \(\|F(x)-F(y)\|_\infty\le B^{-1}\|x-y\|_\infty\). Since \(B\ge2\), the contraction mapping theorem applies to the complete metric space \([0,1]^\tau\), giving the unique fixed point \(q\).

Starting with \(x^{(0)}=0\), compute \(x^{(t+1)}=F(x^{(t)})\). Monotonicity of \(F\), together with \(0\le q\), gives \(x^{(t)}\le q\) coordinatewise. The contraction estimate gives

\(0\le q_j-x_j^{(t)}\le B^{-t}\qquad\text{for every }j.\)

Approximation alone does not certify ties. The next bound supplies that certification.

3. A denominator bound for the exact scores

For every \(j\) with nonempty \(P(j)\), choose a predecessor \(p(j)\) attaining \(\max_{i\in P(j)}q_i\). This choice is used only in the proof. Then

\(Bq_j=d_j+q_{p(j)}.\)

Follow the chosen predecessors from any starting vertex \(j\). Since there are only \(\tau\) vertices, the walk either reaches a vertex with no predecessors or enters a cycle.

If it reaches such a vertex after \(h\) steps, write the visited vertices as \(v_0=j,\ldots,v_h\). Since \(q_{v_h}=0\), repeated substitution yields

\(q_j=\sum_{r=0}^{h-1}d_{v_r}B^{-(r+1)}.\)

Its reduced denominator therefore divides \(B^h\), and \(h\le\tau-1\).

Otherwise, let the tail length be \(h\) and the cycle length be \(\ell\). The vertices \(v_0,\ldots,v_{h+\ell-1}\) are distinct, so \(h+\ell\le\tau\). Substitution around the cycle gives

\(q_{v_h}=\sum_{r=0}^{\ell-1}d_{v_{h+r}}B^{-(r+1)}+B^{-\ell}q_{v_h}.\)

Hence

\(q_{v_h}=C/(B^\ell-1),\qquad C=\sum_{r=0}^{\ell-1}d_{v_{h+r}}B^{\ell-1-r}\in\mathbb Z.\)

Substituting along the tail shows that the reduced denominator of \(q_j\) divides \(B^h(B^\ell-1)\), which is less than or equal to \(B^\tau\). This argument includes self-loops.

Therefore every score can be written in lowest terms as \(q_j=u_j/v_j\), with \(1\le v_j\le B^\tau\). If two scores differ, their cross-multiplied numerator is a nonzero integer, giving the separation bound

\(|q_j-q_k|\ge 1/(v_jv_k)\ge B^{-2\tau}.\)

4. Recovering all comparisons, including ties

Take \(N=2\tau+2\) and \(\varepsilon=B^{-N}\). The approximation bound gives errors \(e_j=q_j-x_j^{(N)}\) satisfying \(0\le e_j\le\varepsilon\).

We claim that

\(q_j\le q_k\quad\Longleftrightarrow\quad x_j^{(N)}-x_k^{(N)}\le\varepsilon.\)

If \(q_j\le q_k\), then

\(x_j^{(N)}-x_k^{(N)}=q_j-q_k-e_j+e_k\le\varepsilon.\)

If \(q_j>q_k\), the separation bound instead gives

\(x_j^{(N)}-x_k^{(N)}\ge B^{-2\tau}-\varepsilon=(B^2-1)\varepsilon\ge3\varepsilon>\varepsilon.\)

This proves the claim in both directions.

To implement it using integers, put \(z_j^{(t)}=B^t x_j^{(t)}\). Starting from \(z_j^{(0)}=0\), the recurrence is

\(z_j^{(t+1)}=d_jB^t+\max_{i\in P(j)}z_i^{(t)}\)

when \(P(j)\ne\varnothing\), and \(z_j^{(t+1)}=0\) otherwise. Every \(z_j^{(t)}\) is an integer.

The exact output rule is consequently

\(j\preceq k\quad\Longleftrightarrow\quad z_j^{(N)}-z_k^{(N)}\le1.\)

In particular,

\(q_j=q_k\quad\Longleftrightarrow\quad |z_j^{(N)}-z_k^{(N)}|\le1.\)

Thus ties are certified exactly.

5. Polynomial bit complexity

The algorithm is:

  • Reduce the input fractions and compute \(D\), \(B\), and the integers \(d_j\).
  • Perform \(N=2\tau+2\) iterations of the integer recurrence.
  • Output every comparison using the rule above.

Since \(D\le\prod_i b_i\), its binary length is at most a constant plus the sum of the input denominator lengths, hence \(O(L+1)\). Computing it by successive greatest-common-divisor and least-common-multiple operations takes polynomial time.

Moreover, \(0\le x_j^{(t)}\le1\), so \(0\le z_j^{(t)}\le B^t\). Every integer used during the iterations therefore has \(O(\tau(L+1))\) bits.

Each iteration requires \(O(m+\tau)\) integer operations: scan the edges to compute predecessor maxima, then update the coordinates. There are \(O(\tau)\) iterations and at most \(O(\tau^2)\) output comparisons. All arithmetic is on integers of polynomial bit length.

Therefore the entire computation takes polynomial time in \(m,\tau,L\), even when the numerical value of \(D\) is exponentially large.
