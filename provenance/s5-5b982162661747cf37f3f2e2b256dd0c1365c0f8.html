Proposition C.3 — class: algorithmic

The continuous mirror question, as graded

Given a population of \(N\) contributors with rational type distribution \(\mu\) over finite support \(T\), where each type \(t\) specifies a QRMed input \(x_t\), uncertainty \(\Delta_t\), and weight \(\omega_t\), approximate within \(\varepsilon\) the minimizer \(q^*\) of \(\frac{q^2}{2\ell}+N\sum_{t\in T}\mu_t\omega_t H_{1/2}(q\mid x_t,\Delta_t)\).

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: a nonempty list \(T\) of \(\tau\) types with positive binary-rational masses \(\mu_t\) satisfying \(\sum_{t\in T}\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types.
Each type specifies \(x_t\in\mathbb Q\cup\{\perp\}\), a nonnegative rational weight \(\omega_t\), and, when \(x_t\ne\perp\), finite rational uncertainties \(\Delta_t=(\Delta_{t,\mathrm{left}},\Delta_{t,\mathrm{right}})\in\mathbb Q_{\ge0}^2\); \(\perp\) denotes a missing score.
For a defined score, let \(H_{1/2}(q\mid x,\Delta)=\sqrt{\Delta_{\mathrm{left}}^2+(q-x)^2}-\Delta_{\mathrm{left}}\) when \(q\le x\), and \(H_{1/2}(q\mid x,\Delta)=\sqrt{\Delta_{\mathrm{right}}^2+(q-x)^2}-\Delta_{\mathrm{right}}\) when \(q\ge x\).
Given a binary-encoded positive integer \(N\), positive rational \(\ell\), and rational \(0<\varepsilon<1\), define \(q^*=\operatorname*{argmin}_{q\in\mathbb R}\left\{\frac{q^2}{2\ell}+N\sum_{t:x_t\ne\perp}\mu_t\omega_tH_{1/2}(q\mid x_t,\Delta_t)\right\}\). Type masses need not make \(N\mu_t\) integral.
The computational problem is to output a rational \(\widehat q\) with \(|\widehat q-q^*|\le\varepsilon\). Let \(L\) be the total binary input length, including \(N,\ell,\varepsilon\); this scalar problem has \(m=1\). State running times in \(m,\tau,L\), with numerical-parameter dependence explicit.

Is this approximation problem solvable in time polynomial in \(\tau\) and \(L\), or is it NP-hard?

For an explicit list of \(N\) contributors, a known algorithm uses \(\mathcal O(\log(1+|q^*|))\) initialization iterations and \(\mathcal O(\log(1/\varepsilon))\) dichotomic iterations, each costing \(\mathcal O(N)\) arithmetic operations.
That operation-count guarantee does not establish the bit complexity of the support-based problem with binary-rational inputs.

Modeling choices made when packaging the task

  • Normalized the positive rational masses to sum to one, retaining N as the population-size multiplier.
  • Specified asymmetric uncertainties as finite nonnegative rational pairs, including zero uncertainties.
  • Allowed missing scores and omitted their terms, following the discrete QRMed definition.
  • Specified arbitrary nonnegative rational weights and a strictly positive rational regularization parameter.
  • Encoded N as a positive integer in binary and imposed no integrality requirement on N times a type mass.
  • Interpreted approximation as additive error in the minimizer, with a rational output and binary-rational accuracy parameter between zero and one.
  • Defined L as total binary input length and set m to one because the computational problem concerns a single scalar score.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Result. The approximation problem is solvable in time polynomial in \(\tau\) and \(L\). For the stated scalar problem, \(m=1\), a conservative bound is \(\mathcal O(\tau L^4)\) bit operations.

The proof below gives an algorithm using exact rational comparisons. In particular, it does not require deciding the sign of a sum of square roots.

1. Convexity, uniqueness, and a bounded search interval.

Discard types with missing scores or zero weights, and write \(T_+\) for the remaining types. Define

\(a_t=N\mu_t\omega_t,\qquad A=\sum_{t\in T_+}a_t,\qquad C(q)=\sum_{t\in T_+}a_tH_{1/2}(q\mid x_t,\Delta_t).\)

The objective is \(F(q)=q^2/(2\ell)+C(q)\). If \(T_+\) is empty, its unique minimizer is \(q^*=0\), so return \(0\). Henceforth assume \(T_+\) is nonempty.

For \(q\ne x_t\), let \(d_t(q)\) denote the uncertainty on the applicable side. The derivative of the corresponding loss is

\(H_t'(q)=\dfrac{q-x_t}{\sqrt{d_t(q)^2+(q-x_t)^2}}.\)

On either open side of \(x_t\), its second derivative is

\(H_t''(q)=\dfrac{d_t(q)^2}{\bigl(d_t(q)^2+(q-x_t)^2\bigr)^{3/2}}\ge 0.\)

This also applies when \(d_t(q)=0\), since \(q\ne x_t\). At \(q=x_t\), the left derivative is \(-1\) if \(\Delta_{t,\mathrm{left}}=0\), and \(0\) otherwise. The right derivative is \(1\) if \(\Delta_{t,\mathrm{right}}=0\), and \(0\) otherwise. Thus the derivative is nondecreasing across the junction as well. Each loss is continuous and convex, so \(C\) is convex.

Since every loss is nonnegative, \(F(q)\ge q^2/(2\ell)\). Consequently, \(F\) is continuous and coercive and has a minimizer. Its quadratic term makes it strongly convex with parameter \(1/\ell\), so that minimizer is unique.

Set \(B=\max_{t\in T_+}|x_t|\). For \(q>B\), both \(q/\ell\) and every loss derivative are positive. For \(q<-B\), they are negative. Hence \(|q^*|\le B\).

Every loss subgradient belongs to \([-1,1]\), so every subgradient of \(C\) belongs to \([-A,A]\). Optimality gives \(0\in q^*/\ell+\partial C(q^*)\), and therefore \(|q^*|\le\ell A\).

We have obtained the rational bracket

\(q^*\in[-R,R],\qquad R=\min\{B,\ell A\}.\)

If \(R=0\), return \(0\).

2. A quantitative certificate for approximation.

For a finite convex function on the real line, its subgradient interval is the interval between its left and right derivatives. Indeed, monotonicity of secant slopes shows that exactly these slopes define supporting lines.

Write

\(\partial F(q)=[g_-(q),g_+(q)].\)

We will use the following error certificate:

\(|q-q^*|\le\ell\,\operatorname{dist}(0,\partial F(q)).\)

Here the distance is the minimum absolute value of an element of the interval. To prove the certificate, take \(g\in\partial F(q)\). There are \(v\in\partial C(q)\) and \(v^*\in\partial C(q^*)\) satisfying \(g=q/\ell+v\) and \(0=q^*/\ell+v^*\).

The supporting inequalities for \(C\) give

\(C(q^*)\ge C(q)+v(q^*-q),\qquad C(q)\ge C(q^*)+v^*(q-q^*).\)

Adding them yields \((v-v^*)(q-q^*)\ge0\). Consequently,

\(g(q-q^*)=\dfrac{(q-q^*)^2}{\ell}+(v-v^*)(q-q^*)\ge\dfrac{(q-q^*)^2}{\ell}.\)

For \(q\ne q^*\), this implies \(|q-q^*|\le\ell|g|\). Minimizing over the subgradient interval proves the certificate; the case \(q=q^*\) is immediate.

It also follows that \(g_-(q)>0\) implies \(q>q^*\), and \(g_+(q)<0\) implies \(q<q^*\). Equality with \(q^*\) is excluded in these cases because optimality requires the interval to contain \(0\).

3. Certified rational evaluation of the subgradient.

Choose

\(\eta=\dfrac{\varepsilon}{4\ell},\qquad p=\max\left\{0,\left\lceil\log_2\left(\dfrac{4\ell A}{\varepsilon}\right)\right\rceil\right\}.\)

Then \(A2^{-p}\le\eta\).

For a rational query \(q\ne x_t\), put \(z=q-x_t\) and \(d=d_t(q)\). We approximate the normalized slope \(z/\sqrt{d^2+z^2}\) to absolute error at most \(2^{-p}\).

If \(d=0\), the slope is exactly the sign of \(z\). Otherwise, set \(r=|z|/\sqrt{d^2+z^2}\), which lies in \((0,1)\). For a nonnegative dyadic candidate \(u=j/2^p\),

\(u\le r\quad\Longleftrightarrow\quad j^2(d^2+z^2)\le 2^{2p}z^2.\)

Both sides of the latter comparison are rational. Clearing positive denominators makes it an exact integer comparison. Binary search on the grid with spacing \(2^{-p}\) uses \(p\) such comparisons and produces an approximation to \(r\) with error at most \(2^{-p}\). Restoring the sign gives the required slope approximation. For \(p=0\), returning \(0\) already has error at most \(1\).

At \(q=x_t\), evaluate both one-sided slopes exactly using the cases in Section 1.

Weighting and summing these slope approximations, then adding the exact rational value \(q/\ell\), gives rational endpoints \(\widetilde g_-(q)\) and \(\widetilde g_+(q)\) satisfying

\(\left|\widetilde g_-(q)-g_-(q)\right|\le A2^{-p}\le\eta,\qquad \left|\widetilde g_+(q)-g_+(q)\right|\le\eta.\)

This construction handles zero uncertainties without any positive lower bound on them.

4. The algorithm and its correctness.

Start with \([a,b]=[-R,R]\). Whenever \(b-a>2\varepsilon\), query its rational midpoint \(q=(a+b)/2\) and compute the certified endpoints above.

  • If \(\widetilde g_-(q)>\eta\), then \(g_-(q)>0\). Replace \(b\) by \(q\).
  • Otherwise, if \(\widetilde g_+(q)<-\eta\), then \(g_+(q)<0\). Replace \(a\) by \(q\).
  • Otherwise, return \(q\).

In the first two cases, Section 2 proves that the updated interval still contains \(q^*\).

In the third case,

\(g_-(q)\le\widetilde g_-(q)+\eta\le2\eta,\qquad g_+(q)\ge\widetilde g_+(q)-\eta\ge-2\eta.\)

Since \(g_-(q)\le g_+(q)\), the subgradient interval intersects \([-2\eta,2\eta]\). The certificate therefore gives

\(|q-q^*|\le2\ell\eta=\varepsilon/2.\)

If the loop ends because \(b-a\le2\varepsilon\), return \(\widehat q=(a+b)/2\). The maintained bracket gives \(|\widehat q-q^*|\le\varepsilon\).

Every nonterminal query halves the bracket. Thus the number of queries is at most

\(K=\max\left\{0,\left\lceil\log_2\left(\dfrac{R}{\varepsilon}\right)\right\rceil\right\}.\)

5. Bit complexity and numerical dependence.

Here is an explicit bound, using elementary quadratic-time integer multiplication and division:

\(\mathcal O\!\left(\tau(K+1)(p+1)(L+K+p)^2\right)\)

bit operations, where

\(A=N\sum_{t\in T_+}\mu_t\omega_t,\quad R=\min\left\{\max_{t\in T_+}|x_t|,\ell A\right\},\)

and \(K,p\) are as defined above. This is the running time for \(m=1\).

To justify the bit lengths, use a common denominator \(D\) for all coefficients \(a_t\): the product of the encoded denominators of the relevant masses and weights suffices. Its bit length is \(\mathcal O(L)\), because those denominator encodings are part of the total input. Write \(a_t=n_t/D\). The integers \(n_t\), their sum, and the rational values \(A,R\) have bit length \(\mathcal O(L)\).

After at most \(K\) midpoint updates, every query is a dyadic subdivision of the initial rational interval, so its numerator and denominator have bit length \(\mathcal O(L+K)\). Each slope approximation is a dyadic rational with denominator \(2^p\). Weighted slope sums can therefore be formed with denominator \(D2^p\), rather than accumulating unrelated denominators.

For example, writing \(z=u/v\) and \(d=h/j\), an oracle comparison against a dyadic candidate \(k/2^p\) becomes

\(k^2(h^2v^2+u^2j^2)\le2^{2p}u^2j^2.\)

Its integer operands have bit length \(\mathcal O(L+K+p)\). Thus a query costs \(\mathcal O(\tau(p+1)(L+K+p)^2)\) bit operations. Preprocessing is covered by the displayed total bound. The integers \(K,p\) can themselves be computed by integer bit lengths and exact comparisons with powers of two.

Finally, binary encoding implies \(B\le2^L\), \(\ell\le2^L\), and \(\varepsilon\ge2^{-L}\). Also,

\(A=N\sum_{t\in T_+}\mu_t\omega_t\le N\max_{t\in T_+}\omega_t\le2^{2L},\)

using \(\sum_t\mu_t=1\). Hence \(K=\mathcal O(L)\) and \(p=\mathcal O(L)\), proving the advertised bound \(\mathcal O(\tau L^4)\). The output has bit length \(\mathcal O(L)\).

No expansion into individual contributors is used, and integrality of \(N\mu_t\) is unnecessary. This establishes the polynomial-time alternative.
