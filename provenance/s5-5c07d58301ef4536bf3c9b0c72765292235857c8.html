The continuous mirror question, as graded

Given an ordered candidate set \(C\), committee size \(k\), and a society supported on \(\tau\) approval-interval types \(t\), each with positive binary-rational mass \(\mu_t\) and approval set \(A_t\), find an integral committee \(W\subseteq C\), \(|W|=k\), such that for every \(\ell\in\{1,\ldots,k\}\) and \(c\notin W\), \(\sum_{t:\,c\in A_t,\ |A_t\cap W|<\ell}\mu_t<\ell/k\), and no size-\(k\) committee \(D\) satisfies \(|A_t\cap D|\ge |A_t\cap W|\) for every supported type and a strict inequality for at least one supported type.

Packaged proof task (what the prover saw — nothing else)

Given a totally ordered candidate set \(C\) with \(m\ge 1\) candidates and an integer \(1\le k\le m\), a society is given by its support: the list of \(\tau\ge 1\) distinct approval types with positive binary-rational masses \(\mu_t\), where \(\sum_t\mu_t=1\). Each approval set \(A_t\subseteq C\) is an interval in the supplied order; empty approval sets are allowed. Here \(\tau\) is the support size, not the number of possible types. Let \(L\) be the total binary input length; state running times in \(m,\tau,k,L\).
Find an integral committee \(W\subseteq C\), \(|W|=k\), satisfying both conditions below; any such committee is acceptable.
EJR+: for every \(\ell\in\{1,\ldots,k\}\) and \(c\in C\setminus W\), \(\sum_{t:\,c\in A_t,\ |A_t\cap W|<\ell}\mu_t<\ell/k\).
Pareto optimality: no integral committee \(D\subseteq C\) with \(|D|=k\) satisfies \(|A_t\cap D|\ge |A_t\cap W|\) for every supported type and a strict inequality for at least one supported type.

Is this committee-finding problem solvable in polynomial time in \(m,\tau,k,L\), or is it NP-hard?

For explicitly listed, equally weighted voters with interval approvals, a polynomial-time algorithm finds a committee satisfying EJR+ and Pareto optimality. [Schünke](https://arxiv.org/abs/2605.30490)
For unrestricted discrete approval profiles, finding a committee satisfying JR and Pareto optimality is NP-hard. [Dong](https://arxiv.org/abs/2609.08357)
No result settling the exact rational-mass interval problem above was located.

Modeling choices made when packaging the task

  • Normalize total mass to one, matching the stated threshold ell/k and the discrete threshold ell*n/k.
  • Require a nonempty society and candidate set, and an integer committee size between one and the number of candidates.
  • Allow empty approval sets, as the discrete domain permits approval subsets without a nonemptiness restriction.
  • Define L as the total binary input length and accept any committee satisfying the conditions, without tie-breaking.

Result

The problem is polynomial-time solvable. An exact maximizer of weighted Proportional Approval Voting satisfies both requirements, and interval approvals allow us to compute such a maximizer by an integral linear program.

PAV tractability on the candidate-interval domain is also noted in [Schünke’s paper, Section 1.1](https://arxiv.org/html/2605.30490v1#S1.SS1). Below, the rational-mass extension and its bit complexity are proved directly.

1. Weighted PAV satisfies both requirements

Define the harmonic numbers by \(H_0=0\) and \(H_s=\sum_{j=1}^{s}1/j\). For a committee \(W\), define its weighted PAV score as

\[ F(W)=\sum_{t=1}^{\tau}\mu_t H_{|A_t\cap W|}. \]

In this section, let \(W\) maximize \(F\) over all integral committees of size \(k\). No interval assumption is needed yet.

Pareto optimality

Suppose a size-\(k\) committee \(D\) weakly improves every supported type’s approval count and strictly improves at least one. Since \(H_s\) is strictly increasing and every \(\mu_t\) is positive, this implies \(F(D)>F(W)\), contradicting maximality. Thus \(W\) is Pareto optimal.

EJR+

Write \(s_t=|A_t\cap W|\). Fix an unelected candidate \(c\). Its marginal PAV gain is

\[ \Delta_c=F(W\cup\{c\})-F(W) =\sum_{t:\,c\in A_t}\frac{\mu_t}{s_t+1}. \]

For each \(w\in W\), let the loss from deleting \(w\) after adding \(c\) be

\[ R_w=F(W\cup\{c\})-F((W\setminus\{w\})\cup\{c\}). \]

Optimality of \(W\) implies \(\Delta_c-R_w\le 0\), so \(R_w\ge\Delta_c\).

Summing these losses over \(w\in W\), each type contributes once for each of its \(s_t\) elected approved candidates. Consequently,

\[ \sum_{w\in W}R_w = \sum_{\substack{t:\,c\notin A_t\\s_t>0}}\mu_t + \sum_{t:\,c\in A_t}\frac{\mu_t s_t}{s_t+1} = 1-\sum_{\substack{t:\,c\notin A_t\\s_t=0}}\mu_t-\Delta_c \le 1-\Delta_c. \]

Combining the two inequalities gives \(k\Delta_c\le 1-\Delta_c\), hence

\[ \Delta_c\le\frac{1}{k+1}. \]

For any \(\ell\in\{1,\ldots,k\}\), types with \(s_t<\ell\) satisfy \(s_t+1\le\ell\). Therefore,

\[ \sum_{\substack{t:\,c\in A_t\\s_t<\ell}}\mu_t \le \ell\sum_{\substack{t:\,c\in A_t\\s_t<\ell}}\frac{\mu_t}{s_t+1} \le \ell\Delta_c \le \frac{\ell}{k+1} < \frac{\ell}{k}. \]

This proves exactly the required strict EJR+ inequality, including instances with masses at the stated cutoff.

2. Computing weighted PAV by linear programming

Index candidates in their supplied order. Introduce variables \(x_c\) for candidates and \(y_{t,j}\) for \(t\in\{1,\ldots,\tau\}\), \(j\in\{1,\ldots,k\}\).

Consider the linear program maximizing

\[ \sum_{t=1}^{\tau}\sum_{j=1}^{k}\frac{\mu_t}{j}\,y_{t,j} \]

subject to:

  • \(\sum_{j=1}^{k}y_{t,j}\le\sum_{c\in A_t}x_c\) for every supported type \(t\);
  • \(\sum_{c\in C}x_c=k\);
  • \(0\le x_c\le1\) and \(0\le y_{t,j}\le1\).

We will prove that every vertex of this feasible polytope is integral.

For an integral candidate vector \(x\), let \(W=\{c:x_c=1\}\) and \(s_t=|A_t\cap W|\). The objective coefficients for type \(t\) are positive and decreasing in \(j\). Its optimal auxiliary variables are therefore \(y_{t,j}=1\) for \(j\le s_t\), and zero otherwise. Their objective contribution is precisely \(\mu_tH_{s_t}\).

Thus an integral optimal LP solution yields a weighted PAV maximizing committee.

3. Proof of integrality

A matrix is totally unimodular if every square submatrix has determinant in \(\{0,1,-1\}\).

Interval-matrix lemma

Every zero-one matrix whose ones in each row form an interval of columns is totally unimodular.

To prove this, take any square submatrix \(M\), retaining the inherited column order. Its rows still have consecutive ones. Multiply it on the right by the upper triangular matrix \(T\) having diagonal entries \(1\), entries \(-1\) immediately above the diagonal, and zeros elsewhere.

Since \(\det T=1\), we have \(\det(MT)=\det M\). Each row of \(MT\) has at most one entry \(1\) and at most one entry \(-1\): these mark the beginning of its interval and the position immediately after its end.

Any square matrix with this latter property has determinant in \(\{0,1,-1\}\). Indeed, induct on its dimension. A row with at most one nonzero permits determinant expansion along that row, reducing to a smaller matrix with the same property. If every row has two nonzeros, they are \(1\) and \(-1\), so every row sums to zero and the matrix is singular. This proves the lemma.

Applying the lemma

Let \(B_{t,c}=1\) exactly when \(c\in A_t\). Its rows have consecutive ones; an empty approval set gives a zero row.

Express the cardinality equality using two inequalities. The candidate-variable part of the constraint matrix then consists of the rows of \(-B\), one all-ones row, and one negative all-ones row. Changing row signs produces an interval matrix. By the lemma, and because row sign changes preserve total unimodularity, this matrix is totally unimodular.

Each auxiliary variable \(y_{t,j}\) adds a column with exactly one nonzero entry, equal to \(1\), in its type’s constraint. Appending such columns preserves total unimodularity: a square submatrix containing such a column either has determinant zero or can be expanded along that column.

Finally, the bounds append rows with exactly one entry \(1\) or \(-1\). Determinant expansion gives the same preservation argument. Hence the full inequality matrix is totally unimodular.

All right-hand sides are integers: \(0\), \(1\), \(k\), or \(-k\). At any vertex, a nonsingular square subsystem of active constraints determines the variables. Its determinant is \(1\) or \(-1\), so its inverse has integer entries by the adjugate formula. The vertex is consequently integral.

The polytope is nonempty—choose any \(k\) candidates and set every auxiliary variable to zero—and bounded by the variable bounds. It therefore has an optimal vertex. Such a vertex can be found in polynomial time using exact rational linear programming. If necessary, one obtains a vertex by successively minimizing coordinates within the optimal face.

4. Algorithm and bit complexity

The algorithm is:

  • Construct the LP above.
  • Compute an exact optimal vertex.
  • Return \(W=\{c:x_c=1\}\).

The integrality proof gives \(|W|=k\). Section 1 proves EJR+ and Pareto optimality.

There are \(N=m+\tau k\) variables and at most \(\tau+2+2N\) inequalities. All constraint coefficients belong to \(\{0,1,-1\}\).

For completeness, write each mass as \(\mu_t=a_t/b_t\) and let \(Q=\prod_t b_t\). Multiplying the objective by the positive integer \(Qk!\) produces integer objective coefficients

\[ \left(\frac{Qa_t}{b_t}\right)\left(\frac{k!}{j}\right). \]

These divisions are exact. Because the total mass encoding length is at most \(L\), \(Q\) has \(O(L)\) bits. Since \(0<\mu_t\le1\), each scaled coefficient has \(O(L+k\log(k+1))\) bits.

Construction and exact LP optimization therefore take

\[ \operatorname{poly}\!\left(m+\tau k+L+k\log(k+1)\right) \]

bit operations, which is polynomial in \(m,\tau,k,L\). This bound uses the listed support directly and requires no expansion of rational masses into individual voters.

The objective \(F(W)=\sum_t\mu_t H_{|A_t\cap W|}\) is well-defined for every committee.

2. The EJR+ calculation

Fix \(c\notin W\), and write \(s_t=|A_t\cap W|\). The marginal-gain formula
\[ \Delta_c=\sum_{t:c\in A_t}\frac{\mu_t}{s_t+1} \]
is correct.

For each \(w\in W\), the committee \((W\setminus\{w\})\cup\{c\}\) has size \(k\), so optimality gives \(R_w\ge\Delta_c\). This comparison does not require optimality among committees of size \(k+1\).

The summed deletion losses are also correct:

  • A type not approving \(c\), with \(s_t>0\), contributes \(s_t\) losses of \(\mu_t/s_t\), totaling \(\mu_t\).
  • A type approving \(c\) contributes \(s_t\) losses of \(\mu_t/(s_t+1)\), totaling \(\mu_t s_t/(s_t+1)\).
  • A type with no elected approved candidates contributes zero.

Using \(\sum_t\mu_t=1\), these contributions give exactly the displayed identity and hence
\[ k\Delta_c\le 1-\Delta_c,\qquad \Delta_c\le\frac{1}{k+1}. \]

For \(s_t<\ell\), integrality of \(s_t\) implies \(s_t+1\le\ell\). Consequently, the prover correctly obtains
\[ \sum_{t:c\in A_t,\ s_t<\ell}\mu_t \le\frac{\ell}{k+1}<\frac{\ell}{k}. \]

The final inequality is strictly valid because \(k\ge1\) and \(\ell\ge1\). Thus equality at the prohibited EJR+ threshold is excluded.

When \(k=m\), there are no unelected candidates, so EJR+ is vacuous; the argument remains applicable.

This yields objective contribution \(\mu_t H_{s_t}\). The index range is sufficient because \(s_t\le k\). Empty approval sets force every corresponding auxiliary variable to zero.

Thus an integral optimal LP solution indeed supplies a weighted PAV maximizer.

  • Otherwise, every row has one positive and one negative entry, so all row sums vanish and the matrix is singular.

Therefore, every square submatrix has determinant in \(\{0,1,-1\}\), establishing total unimodularity.
