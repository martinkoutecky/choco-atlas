The continuous mirror question, as graded

Given candidates \(C\), committee size \(k\), and approval types \(A_1,\ldots,A_\tau\) with positive rational masses \(\mu_j\) summing to \(1\), compute a committee \(W\subseteq C\) of size \(k\) such that for every \(\ell\in\{1,\ldots,k\}\) and every cohort vector \(v\) with \(0\le v_j\le\mu_j\), \(\sum_j v_j\ge\ell/k\), and \(\left|\bigcap_{j:v_j>0} A_j\right|\ge\ell\), one has \(\sum_{j:|A_j\cap W|\ge\ell}v_j>0\).

Packaged proof task (what the prover saw — nothing else)

Let \(C\) be a finite candidate set with \(m=|C|\), and let \(k\) be an integer satisfying \(1\le k\le m\).
A society is given by its support: a list of \(\tau\) distinct approval types \(A_j\subseteq C\), each with positive binary-rational mass \(\mu_j\), where \(\sum_{j=1}^{\tau}\mu_j=1\). Empty approval sets are allowed. Here \(\tau\) is the support size, not the number of possible approval sets; let \(L\) be the total input bit length.
A cohort is a real vector \(v\in\mathbb R^{\tau}\) with \(0\le v_j\le\mu_j\). For an integer \(\ell\in\{1,\ldots,k\}\), it is cohesive if \(\sum_jv_j\ge\ell/k\) and \(\left|\bigcap_{j:v_j>0}A_j\right|\ge\ell\).
The computational problem is to output a committee \(W\subseteq C\) with \(|W|=k\) such that every cohesive cohort at every level \(\ell\) satisfies \(\sum_{j:|A_j\cap W|\ge\ell}v_j>0\). Any committee satisfying this condition is an admissible output.

Is this committee-construction problem solvable in time polynomial in \(m,\tau,k,L\), or is it NP-hard?

For explicitly listed discrete voters, LS-PAV is polynomial-time computable and outputs committees satisfying EJR ([Skowron et al.](https://arxiv.org/abs/1704.00293)); two polynomial-time EJR constructions are also established by [Aziz et al.](https://ojs.aaai.org/index.php/AAAI/article/view/11478).
No published complexity result for exactly the rational-support, real-cohort formulation above was identified in the search.

Modeling choices made when packaging the task

  • Restricted the committee size to an integer between one and the number of candidates, as required by the discrete definition.
  • Specified approval types as distinct subsets of the candidate set; empty approval sets remain allowed by the discrete domain.
  • Specified cohort coordinates as real numbers, permitting arbitrary portions of each type's mass.
  • Defined L as the total input bit length and allowed any qualifying committee as output, with no tie-breaking requirement.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Result

The committee-construction problem is solvable in polynomial time in \(m,\tau,k,L\).

A weighted version of thresholded LS-PAV suffices. The discrete algorithm uses swaps whose PAV improvement is at least \(n/k^2\); after normalizing total mass to one, the corresponding threshold is \(1/k^2\). See [Skowron et al., Algorithm 1](https://arxiv.org/pdf/1704.00293). Below is a self-contained proof for the stated rational-support, real-cohort formulation, including bit complexity.

Algorithm

For each integer \(s\) with \(0\le s\le k\), define the harmonic number
\(H_0=0\) and \(H_s=\sum_{r=1}^{s}1/r\).

For a committee \(W\) of size \(k\), define its weighted PAV score by

\(F(W)=\sum_{j=1}^{\tau}\mu_j H_{|A_j\cap W|}.\)

Run the following algorithm:

  • Start with any committee \(W\subseteq C\) of size \(k\).
  • If there exist \(c\in C\setminus W\) and \(w\in W\) such that

\(F((W\setminus\{w\})\cup\{c\})-F(W)\ge 1/k^2\),
perform such a swap.

  • Repeat until no such swap exists, and output \(W\).

All comparisons are exact. In particular, swaps attaining the threshold with equality are performed.

Swap identity

Fix a committee \(W\), write \(s_j=|A_j\cap W|\), and fix \(c\in C\setminus W\). Define

\(d(c)=\sum_{j:c\in A_j}\frac{\mu_j}{s_j+1}\)

and, for each \(w\in W\),

\(\Delta(c,w)=F((W\setminus\{w\})\cup\{c\})-F(W).\)

We claim that

\(\displaystyle \sum_{w\in W}\Delta(c,w) =(k+1)d(c)-\sum_{j:s_j>0\ \text{or}\ c\in A_j}\mu_j. \)

To prove this identity, sum each type’s score changes over all possible removed candidates \(w\).

  • If \(c\in A_j\), removing one of the \(s_j\) approved committee members and adding \(c\) leaves its satisfaction unchanged. Removing any of the other \(k-s_j\) members increases its score by \(\mu_j/(s_j+1)\). Its total contribution is therefore

\(\mu_j(k-s_j)/(s_j+1)=\mu_j((k+1)/(s_j+1)-1)\).

  • If \(c\notin A_j\) and \(s_j>0\), precisely \(s_j\) removals decrease its score, each by \(\mu_j/s_j\). Its total contribution is \(-\mu_j\).
  • If \(c\notin A_j\) and \(s_j=0\), its contribution is zero.

Summing these contributions proves the identity. Since the masses sum to one, it implies

\(\displaystyle \sum_{w\in W}\Delta(c,w)\ge (k+1)d(c)-1. \)

Consequently, if \(d(c)\ge 1/k\), then

\(\displaystyle \sum_{w\in W}\Delta(c,w)\ge \frac1k. \)

There are exactly \(k\) terms in this sum, so some \(w\in W\) satisfies
\(\Delta(c,w)\ge 1/k^2\).

Correctness for every real cohort

Suppose that the algorithm terminates at \(W\), but that \(W\) violates the required condition. Then there exist a level \(\ell\in\{1,\ldots,k\}\) and a cohesive cohort \(v\) such that

\(\displaystyle q:=\sum_jv_j\ge\frac{\ell}{k}, \qquad \left|\bigcap_{j:v_j>0}A_j\right|\ge\ell, \qquad \sum_{j:s_j\ge\ell}v_j=0. \)

The last equality follows because the required sum is nonnegative and fails to be strictly positive. Thus every type with \(v_j>0\) satisfies \(s_j\le\ell-1\).

Let \(S=\bigcap_{j:v_j>0}A_j\). This intersection is over a nonempty set of types because \(q>0\). There must be a candidate \(c\in S\setminus W\): otherwise \(S\subseteq W\), and every active type would approve at least \(|S|\ge\ell\) committee members, contradicting \(s_j\le\ell-1\).

Every active type approves this candidate \(c\). Using \(v_j\le\mu_j\) and \(s_j+1\le\ell\) for active types gives

\(\displaystyle d(c) =\sum_{j:c\in A_j}\frac{\mu_j}{s_j+1} \ge\sum_{j:v_j>0}\frac{v_j}{s_j+1} \ge\frac{q}{\ell} \ge\frac1k. \)

The swap identity therefore yields some \(w\in W\) with
\(\Delta(c,w)\ge 1/k^2\), contradicting termination.

Hence the output satisfies the required condition for every real cohort. No rationality assumption on \(v\) was used.

Polynomial running time and bit complexity

First, the number of swaps is polynomial. Every size-\(k\) committee satisfies

\(\displaystyle 0\le F(W)\le\sum_j\mu_jH_k=H_k\le k. \)

Every performed swap increases the score by at least \(1/k^2\). Thus there are at most \(k^2H_k\le k^3\) swaps.

It remains to show that each iteration uses polynomial-time exact arithmetic. Write each input mass as \(\mu_j=p_j/q_j\), where \(p_j,q_j\) are positive integers encoded in binary. Set

\(\displaystyle D=\prod_{j=1}^{\tau}q_j,\qquad T=k!,\qquad B=DT. \)

Because every integer from \(1\) through \(k\) divides \(T\), each \(TH_s\) is an integer. Therefore every committee score has the common-denominator representation

\(\displaystyle F(W)=\frac{P(W)}{B}, \qquad P(W)=\sum_{j=1}^{\tau} p_j\frac{D}{q_j}\bigl(TH_{|A_j\cap W|}\bigr)\in\mathbb Z. \)

The denominator \(D\) has \(O(L)\) bits, and \(T\) has \(O(k\log(k+1))\) bits. Moreover, \(0\le P(W)\le Bk\), so every score numerator has polynomial bit length as well.

A proposed swap from \(W\) to \(W'\) meets the threshold exactly when

\(\displaystyle k^2\bigl(P(W')-P(W)\bigr)\ge B. \)

This is an integer comparison on numbers of polynomial bit length. Each scan considers at most \(k(m-k)\) swaps; computing each proposed score directly from the \(\tau\) listed types takes polynomial time. Together with the polynomial number of scans, this proves a polynomial bound in \(m,\tau,k,L\).

The argument includes empty approval types, which contribute zero to the score. It also includes the boundary cases \(k=1\) and \(k=m\).

  • The algorithm addresses the required construction problem.

The algorithm starts with a committee of size \(k\) and preserves that size through every swap. It searches over the explicitly listed candidates and evaluates scores using the support masses directly. It does not expand the rational masses into discrete voters.

Its stopping condition is precise: every possible swap has improvement strictly less than \(1/k^2\). Performing swaps whose improvement equals the threshold is essential to the subsequent contradiction.

The introductory attribution is accurate: [Skowron et al., Algorithm 1](https://arxiv.org/pdf/1704.00293) uses an inclusive improvement threshold of \(n/k^2\). Dividing the discrete score by \(n\) gives \(1/k^2\). The correctness proof here is self-contained and does not assume that the published discrete-voter theorem already covers real cohorts.

  • The swap identity is correct.

Fix \(c\notin W\). The three cases exhaust all approval types.

For a type approving \(c\), exactly \(s_j\) removals preserve its approved committee count, and exactly \(k-s_j\) removals increase it by one. Its total contribution is therefore
\[ \frac{\mu_j(k-s_j)}{s_j+1} =\mu_j\left(\frac{k+1}{s_j+1}-1\right). \]

For a type not approving \(c\) with \(s_j>0\), exactly \(s_j\) removals decrease its count by one. Each costs \(\mu_j/s_j\), giving total contribution \(-\mu_j\). A type approving neither \(c\) nor any committee member contributes zero.

These contributions yield exactly the claimed identity. All denominators are positive wherever used; in particular, the expression \(\mu_j/s_j\) is restricted to \(s_j>0\).

  • The improvement bound has the correct constants and inequality directions.

The mass subtracted in the identity belongs to a subset of the support, so it is at most one. Hence
\[ \sum_{w\in W}\Delta(c,w)\ge (k+1)d(c)-1. \]

If \(d(c)\ge 1/k\), the right-hand side is at least \(1/k\). Since the sum has exactly \(k\) terms, at least one term is at least \(1/k^2\). This averaging argument remains valid even if other terms are negative. Equality is handled correctly.

Negating the required condition produces a cohesive cohort whose represented mass is zero, because that mass is nonnegative. Since the support is finite and all summands are nonnegative, each active type must have \(s_j<\ell\), equivalently \(s_j\le\ell-1\).

The cohort has positive mass because \(q\ge\ell/k>0\). Thus its active support is nonempty, and the intersection defining \(S\) has no empty-index ambiguity.

The existence of \(c\in S\setminus W\) follows as written: if \(S\subseteq W\), every active type approves at least \(|S|\ge\ell\) committee members, contradicting the preceding bound.

Every active type approves this \(c\). The successive inequalities bounding \(d(c)\) are justified respectively by nonnegativity and \(v_j\le\mu_j\), by \(s_j+1\le\ell\), and by cohesion:
\[ d(c)\ge \sum_{j:v_j>0}\frac{v_j}{s_j+1} \ge\frac{q}{\ell} \ge\frac1k. \]

The resulting qualifying swap contradicts termination. No step requires the cohort coordinates to be rational. The contradiction applies to an arbitrary alleged violation, so it establishes the required universal condition.

Every score lies between zero and \(H_k\), since the masses sum to one and each satisfaction count is at most \(k\). Every performed swap increases the score by at least \(1/k^2\). Consequently, the number of swaps is at most \(k^2H_k\le k^3\).

This bound is independent of the magnitudes of the mass denominators and applies to any choice among qualifying swaps. There is at most one additional terminating scan.

  • The exact-arithmetic implementation has polynomial bit complexity.

The product denominator \(D\) has bit length bounded by the total input denominator length, hence \(O(L)\). The factorial \(T=k!\) has \(O(k\log(k+1))\) bits and is divisible by every harmonic denominator used.

Therefore the displayed formula for \(P(W)\) is integral and represents \(F(W)\) exactly. The bound \(P(W)\le Bk\) gives polynomial-length numerators. Multiplying a numerator difference by \(k^2\) also preserves polynomial bit length.

Since \(B>0\), the integer threshold comparison is equivalent to the score comparison, including equality. Each scan contains at most \(k(m-k)\) swaps, and direct score computation requires only polynomially many membership checks and arithmetic operations on polynomial-length integers. Combined with the swap bound, this establishes the claimed running time.

For \(k=m\), the initial committee is \(C\); every active type in a cohesive cohort approves its shared intersection of at least \(\ell\) candidates, so the required represented mass is positive.
