For \(j\in C\setminus\{c\}\), define \(X_j(t)=\mathbf{1}\{t\text{ ranks }c\text{ above }j\}\). Input binary rational thresholds \(\alpha_j\in(0,1)\) satisfying \(\sum_{t\in T}\mu_tX_j(t)=\alpha_j\).

Given binary rational \(\varepsilon,\delta\in(0,1)\), the approximation problem asks for \(\widehat p\) satisfying \(\Pr[|\widehat p-p|\leq\varepsilon]\geq1-\delta\). Let \(L\) be the total binary input length; computation uses the randomized Turing model.

Does this additive approximation problem admit a randomized algorithm running in \(\operatorname{poly}(m,\tau,L,\varepsilon^{-1},\log(\delta^{-1}))\) time, or is achieving this approximation NP-hard?

For independent voters drawn from a generic ranking distribution, the probability that \(c\) beats every \(j\) with strictly more than \(\alpha_j n\) supporters converges to \(p\) at these mean thresholds; this is an asymptotic identity, not a complexity classification. Result and interpretation

The additive approximation problem admits a randomized algorithm with the stated polynomial running time. The proof below includes finite-bit sampling and arithmetic; it does not assume exact real-valued Gaussian draws.

I interpret the full-support requirement literally: every ranking occurs in the explicit list, so \(\tau=m!\) when the list has no duplicates. This is the genericity convention used by [Caizergues et al.](https://arxiv.org/html/2505.06028v1). The algorithm actually works for arbitrary listed supports, provided every \(\alpha_j\) lies in \((0,1)\).

1. A factorization with normalized rows

Write \(d=m-1\) and \(k=\tau\). For each opponent \(j\), define

\(\displaystyle \sigma_j=\sqrt{\alpha_j(1-\alpha_j)},\qquad b_{jt}=\frac{\sqrt{\mu_t}\bigl(X_j(t)-\alpha_j\bigr)}{\sigma_j}.\)

These quantities are well-defined because \(0<\alpha_j<1\). Using the promised marginal identities and \(X_j(t)^2=X_j(t)\),

\(\displaystyle \sum_t b_{jt}^2=\frac{\sum_t\mu_t(X_j(t)-\alpha_j)^2}{\alpha_j(1-\alpha_j)}=1.\)

In particular, \(|b_{jt}|\leq1\).

Let \(Z_1,\ldots,Z_k\) be independent standard normal variables, and set

\(\displaystyle H_j=\sum_t b_{jt}Z_t.\)

This is a centered Gaussian vector with covariance

\(\displaystyle \operatorname{Cov}(H_j,H_\ell)=\frac{\Sigma_{j\ell}}{\sigma_j\sigma_\ell}.\)

Consequently, \((\sigma_jH_j)_j\) has the distribution specified for \(G\), and

\(\displaystyle p=\Pr[H_j>0\text{ for all }j].\)

Every \(H_j\) is standard normal. No independence between the coordinates \(H_j\) is asserted or needed.

2. A finite-bit normal sampler

We first prove an elementary sampling lemma.

Lemma. For every rational \(a\in(0,1)\), there is an algorithm producing a rational random variable \(\widehat Z\), using polynomially many operations and random bits in \(a^{-1}\) and the binary length of \(a\), such that:

  • \(|\widehat Z|\leq R\), where \(R=\lceil2/a\rceil\);
  • there is a coupling with a standard normal \(Z\) under which, with probability at least \(1-a\), both \(|Z|\leq R\) and \(|Z-\widehat Z|\leq a\).

The algorithm has a polynomial worst-case running time.

Proof. Let \(f(x)=\exp(-x^2/2)\). Partition \([-R,R]\) into \(K=\lceil32R/a\rceil\) equal intervals of length \(h=2R/K\), so \(h\leq a/16\). Let \(x_i\) be their rational midpoints, and let \(f_h\) equal \(f(x_i)\) throughout interval \(i\).

Since \(\int_{\mathbb R}|f'(x)|\,dx=2\),

\(\displaystyle \int_{-R}^{R}|f(x)-f_h(x)|\,dx\leq h\int_{-R}^{R}|f'(x)|\,dx\leq2h.\)

The first inequality follows by bounding the pointwise difference in each interval by the integral of \(|f'|\) over that interval, then integrating over its length.

Put \(A=\int_{-R}^{R}f(x)\,dx\) and \(B=\int_{-R}^{R}f_h(x)\,dx\). Because \(R\geq1\),

\(\displaystyle A\geq\int_{-1}^{1}f(x)\,dx\geq2e^{-1/2}>1.\)

We use the following normalization bound: if nonnegative functions \(u,v\) have positive integrals \(U,V\), then

\(\displaystyle d_{\mathrm{TV}}(u/U,v/V)\leq\frac{\int|u-v|}{U}.\)

Indeed, the triangle inequality bounds the corresponding \(L^1\) distance by \((\int|u-v|+|U-V|)/U\), which is at most \(2\int|u-v|/U\).

It follows that the normal distribution conditioned on \([-R,R]\) differs in total variation by at most \(a/8\) from the distribution with density \(f_h/B\).

Next compute dyadic numbers \(u_i\in[0,1]\) satisfying

\(\displaystyle |u_i-f(x_i)|\leq\gamma,\qquad \gamma=\frac{a}{32R}.\)

These approximations are computable in polynomial time. Explicitly, for rational \(r=x_i^2/2\), the Taylor polynomial of \(e^{-r}\), truncated before term \(n\), has error at most \(r^n/n!\). Taking \(n\geq6r\) and sufficiently large \(n=O(r+\log(\gamma^{-1}))\) gives

\(\displaystyle \frac{r^n}{n!}\leq\left(\frac{er}{n}\right)^n\leq2^{-n}.\)

Compute to error \(\gamma/2\), round to a dyadic number with rounding error at most \(\gamma/2\), and clip to \([0,1]\). All intermediate rational numbers have polynomial binary length: \(r\leq R^2/2\), and the Taylor degree is polynomial in \(a^{-1}\).

Replacing the interval values \(f(x_i)\) by \(u_i\) changes the unnormalized density by \(L^1\) distance at most \(2R\gamma=a/16\). Also,

\(\displaystyle B\geq A-2h\geq1-a/8\geq7/8.\)

Thus the normalized distributions differ in total variation by at most \(a/14\). The new distribution assigns interval \(i\) probability

\(\displaystyle q_i=\frac{u_i}{\sum_\ell u_\ell},\)

which is rational.

Sample this finite distribution approximately using exactly \(b\) fair bits: choose uniformly a midpoint of the dyadic partition of \([0,1]\) into \(2^b\) intervals, locate it in the cumulative probability intervals, and output the corresponding \(x_i\). Each interval probability changes by at most \(2\cdot2^{-b}\), so the total variation error is at most \(K2^{-b}\). Choose \(b=\lceil\log_2(8K/a)\rceil\), making this error at most \(a/8\). All cumulative comparisons are exact rational comparisons.

Finally, Chebyshev’s inequality gives

\(\displaystyle \Pr[|Z|>R]\leq R^{-2}\leq a^2/4\leq a/4.\)

Couple \(Z\) to its conditioned distribution, then couple the resulting interval index to the sampler’s index. Finite distributions admit a coupling with disagreement probability equal to their total variation distance, by matching the minimum of their two masses at each point. The combined failure probability is at most

\(\displaystyle \frac a4+\frac a8+\frac a{14}+\frac a8=\frac{4a}{7}<a.\)

On success, \(Z\) and the output midpoint lie in the same interval, so their distance is at most \(h/2\leq a\).

There are \(K=O(a^{-2})\) intervals, and all calculations and the fixed number of random bits have polynomial bounds. This proves the lemma. \(\square\)

3. Finite precision changes the orthant probability only slightly

Choose

\(\displaystyle a=\frac{\varepsilon}{32dk},\qquad R=\lceil2/a\rceil,\qquad \rho=\frac aR.\)

Compute rational approximations \(\widetilde b_{jt}\) with

\(\displaystyle |\widetilde b_{jt}-b_{jt}|\leq\rho.\)

This requires no matrix decomposition. The squared magnitude is the exact rational number

\(\displaystyle b_{jt}^2=\frac{\mu_t(X_j(t)-\alpha_j)^2}{\alpha_j(1-\alpha_j)}\in[0,1].\)

Approximate its square root by rational bisection on \([0,1]\), using exact comparisons of squares, and attach the sign of \(X_j(t)-\alpha_j\). The number of bisection steps is \(O(\log(\rho^{-1}))\), with polynomial bit complexity in \(L+\log(\rho^{-1})\).

Generate independent copies \(\widehat Z_t\) of the lemma’s sampler and define

\(\displaystyle \widetilde H_j=\sum_t\widetilde b_{jt}\widehat Z_t,\qquad Y=\mathbf1\{\widetilde H_j>0\text{ for all }j\}.\)

Couple these draws independently to \(Z_t\). With probability at least \(1-ka\), every coupling succeeds. On that event, for each \(j\),

\(\displaystyle |\widetilde H_j-H_j|\leq\sum_t|\widetilde b_{jt}-b_{jt}|\,|\widehat Z_t|+\sum_t|b_{jt}|\,|\widehat Z_t-Z_t|\leq k\rho R+ka=2ka.\)

If the two orthant indicators disagree on this event, some coordinate satisfies \(|H_j|\leq2ka\). Every \(H_j\) is standard normal, whose density is everywhere at most \(1\). Hence

\(\displaystyle \Pr[|H_j|\leq2ka]\leq4ka.\)

A union bound, including coupling failures, now gives

\(\displaystyle |\mathbb EY-p|\leq ka+4dka\leq5dka=\frac{5\varepsilon}{32}<\frac{\varepsilon}{4}.\)

This bound uses only the marginal normal distributions. It has no dependence on the smallest eigenvalue of \(\Sigma\).

4. Averaging and the running-time guarantee

Let \(s\) be the smallest integer satisfying \(2^s\geq2/\delta\), and take

\(\displaystyle N=\left\lceil2\varepsilon^{-2}s\right\rceil.\)

Generate \(N\) independent copies \(Y_1,\ldots,Y_N\) of \(Y\), and output the rational number

\(\displaystyle \widehat p=\frac1N\sum_{r=1}^{N}Y_r.\)

Hoeffding’s inequality applies because the samples are independent and take values in \([0,1]\). It gives

\(\displaystyle \Pr\!\left[|\widehat p-\mathbb EY|>\frac{\varepsilon}{2}\right]\leq2e^{-N\varepsilon^2/2}\leq2e^{-s}\leq\delta.\)

The last inequality follows from \(s\geq\log_2(2/\delta)\geq\ln(2/\delta)\). Together with the proved bias bound, this establishes

\(\displaystyle \Pr[|\widehat p-p|\leq\varepsilon]\geq1-\delta.\)

For completeness, all runtime dependencies have the required form:

  • \(a^{-1}=32dk\varepsilon^{-1}\), so the sampler’s table has polynomial size in \(m,\tau,\varepsilon^{-1}\).
  • Its rational arithmetic and random-bit counts are polynomially bounded, as proved in the lemma.
  • The \(dk\) factor coefficients require polynomial time in \(m,\tau,L,\log(\varepsilon^{-1})\).
  • Each indicator uses \(k\) finite-bit draws and \(dk\) rational multiply-add operations.
  • \(N=O(\varepsilon^{-2}(1+\log(\delta^{-1})))\).

Thus the entire randomized Turing algorithm has worst-case running time

\(\displaystyle \operatorname{poly}(m,\tau,L,\varepsilon^{-1},\log(\delta^{-1})).\)

This settles the requested algorithmic alternative without a real-arithmetic assumption or a conditioning assumption on the covariance.
