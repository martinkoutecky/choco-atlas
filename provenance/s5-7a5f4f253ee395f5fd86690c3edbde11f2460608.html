The continuous mirror question, as graded

Given schools \(M\), supported types \(t=(i,S_t)\) with rational masses \(\mu_t\), common values \(v_k\), and a feasible initial mass assignment \(b_{t,k}\) to accessible schools \(k\in S_t\), set \(c_k=\sum_t b_{t,k}\). Find an assignment \(x_{t,k}\ge 0\) with \(\sum_k x_{t,k}=\mu_t\), \(x_{t,k}=0\) for inaccessible schools, and \(\sum_t x_{t,k}=c_k\), such that no group \(i\) has a feasible exact-capacity witness assignment \(y\) with \(\sum_{t:g(t)=i} y_{t,k}\le\sum_{t:g(t)=j} x_{t,k}\) for every school \(k\) and \(U_i(y)>U_i(x)\), where \(U_i(z)=\sum_{t:g(t)=i}\sum_k v_k z_{t,k}\).

Packaged proof task (what the prover saw — nothing else)

Let \(M=\{1,\ldots,m\}\), with \(m\geq1\), be schools with common values \(v_k\in\mathbb{Q}_{\geq0}\). There are exactly two groups, each of positive mass.
A society is given by its support: a list \(T\) of \(\tau\) types \(t=(g(t),S_t)\), where \(g(t)\in\{1,2\}\), \(\varnothing\neq S_t\subseteq M\), and each positive mass \(\mu_t\) is a binary rational, with \(\sum_t\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types.
The input includes a rational initial assignment \(b_{t,k}\geq0\) satisfying \(\sum_k b_{t,k}=\mu_t\) and \(b_{t,k}=0\) whenever \(k\notin S_t\); set \(c_k=\sum_t b_{t,k}\). Let \(L\) be the total binary input length.
An exact-capacity assignment \(z\) satisfies \(z_{t,k}\geq0\), \(\sum_k z_{t,k}=\mu_t\), \(z_{t,k}=0\) for \(k\notin S_t\), and \(\sum_t z_{t,k}=c_k\). Define \(q_{i,k}(z)=\sum_{t:g(t)=i}z_{t,k}\) and \(U_i(z)=\sum_k v_kq_{i,k}(z)\).
Such an assignment \(x\) is envy-free if, for every distinct \(i,j\in\{1,2\}\), there is no real exact-capacity assignment \(y\) of the entire society satisfying \(q_{i,k}(y)\leq q_{j,k}(x)\) for every school and \(U_i(y)>U_i(x)\).
Is finding a rational envy-free exact-capacity assignment, or determining that none exists, solvable in time polynomial in \(m,\tau,L\), or is this problem NP-hard?
For discrete students in two groups, a \(1\)-relaxed envy-free assignment always exists and is computable in polynomial time; this permits capacity deviations of at most one seat per school. [Shibatani–Yamaguchi](https://arxiv.org/html/2603.19701v1)
No published result settling this exact continuous problem was identified in the literature search.

Result

The problem is solvable in time polynomial in \(m,\tau,L\). In fact, a rational envy-free exact-capacity assignment always exists.

The construction treats unequal and equal group masses separately. In the equal-mass case, divisibility allows us to average an assignment with a feasible assignment that swaps the groups’ school totals.

1. Basic identities

Let \(\mathcal P\) be the set of real exact-capacity assignments, and define the group masses by
\[ \alpha_i=\sum_{t:g(t)=i}\mu_t,\qquad i\in\{1,2\}. \]
Thus \(\alpha_1+\alpha_2=1\), and both masses are positive. The supplied assignment \(b\) belongs to \(\mathcal P\), so \(\mathcal P\) is nonempty.

For every \(z\in\mathcal P\),
\[ \sum_k q_{i,k}(z)=\alpha_i,\qquad q_{1,k}(z)+q_{2,k}(z)=c_k. \]
Consequently, writing \(V=\sum_k v_kc_k\), we have
\[ U_1(z)+U_2(z)=V. \]

We use the standard polynomial-time theorem for rational linear programming: feasibility of a rational linear system can be decided in polynomial time, and a feasible bounded rational linear program can be optimized over its real feasible set, returning a rational optimum of polynomial encoding length. Section 4 verifies the required size and boundedness conditions.

2. Unequal group masses

Assume first that \(\alpha_1<\alpha_2\); the other ordering is symmetric.

Choose a rational assignment \(x\) solving
\[ \max_{z\in\mathcal P} U_1(z). \]

Group 1 does not envy group 2. Any witness \(y\) would belong to \(\mathcal P\) and satisfy \(U_1(y)>U_1(x)\), contradicting optimality.

Group 2 does not envy group 1. Any witness \(y\) would satisfy \(q_{2,k}(y)\leq q_{1,k}(x)\) at every school. Summing these inequalities gives
\[ \alpha_2=\sum_k q_{2,k}(y) \leq\sum_k q_{1,k}(x)=\alpha_1, \]
contrary to \(\alpha_1<\alpha_2\).

Therefore \(x\) is envy-free.

3. Equal group masses

Now assume \(\alpha_1=\alpha_2=\tfrac12\).

A necessary condition for envy

For any \(x,y\in\mathcal P\), suppose
\[ q_{1,k}(y)\leq q_{2,k}(x)\qquad\text{for every }k. \]
Both sides sum to \(\tfrac12\). Thus all the nonnegative differences \(q_{2,k}(x)-q_{1,k}(y)\) sum to zero, forcing equality at every school:
\[ q_{1,k}(y)=q_{2,k}(x). \]
Exact capacities then imply
\[ q_{2,k}(y)=c_k-q_{1,k}(y) =c_k-q_{2,k}(x)=q_{1,k}(x). \]

The same argument applies with the group labels reversed. Hence every possible envy witness must swap both groups’ school totals exactly. This is the continuous counterpart of the perfectly-swapped-allocation observation in Lemma 2 of [Shibatani–Yamaguchi](https://arxiv.org/html/2603.19701v1).

Construction

Test feasibility of the following rational linear system:
\[ y\in\mathcal P,\qquad q_{1,k}(y)=q_{2,k}(b),\quad q_{2,k}(y)=q_{1,k}(b) \qquad\text{for every }k. \]

There are two cases.

Case A: The system is infeasible. Return \(x=b\). If either group envied the other, the necessary condition just proved would supply a feasible solution to this system. Thus \(b\) is envy-free.

Case B: The system is feasible. Obtain a rational solution \(y\), and return the componentwise average
\[ x_{t,k}=\frac{b_{t,k}+y_{t,k}}2. \]
Nonnegativity, accessibility restrictions, type masses, and exact school capacities are all preserved under averaging. Hence \(x\in\mathcal P\). Moreover, for each school,
\[ q_{1,k}(x) =\frac{q_{1,k}(b)+q_{1,k}(y)}2 =\frac{q_{1,k}(b)+q_{2,k}(b)}2 =\frac{c_k}2. \]
Likewise \(q_{2,k}(x)=c_k/2\). In particular, \(U_1(x)=U_2(x)=V/2\).

To verify envy-freeness directly, consider either ordered pair of distinct groups \(i,j\), and any \(w\in\mathcal P\) satisfying \(q_{i,k}(w)\leq q_{j,k}(x)\) for every school. These inequalities become
\[ q_{i,k}(w)\leq \frac{c_k}2. \]
Their two sides have equal total mass \(\tfrac12\), so equality holds at every school. Therefore
\[ U_i(w)=\sum_k v_k\frac{c_k}2=U_i(x). \]
The strict improvement required for envy is impossible.

Thus both cases return a rational envy-free assignment.

4. Encoding length and running time

Use variables \(z_{t,k}\) only for accessible pairs \(k\in S_t\). Their number is
\[ n=\sum_t |S_t|\leq m\tau. \]

The constraints defining \(\mathcal P\) consist of nonnegativity, \(\tau\) type-mass equations, and \(m\) school-capacity equations. The equal-mass feasibility test adds at most \(2m\) equations. The unequal-mass optimization has rational objective coefficients \(v_k\) for types in the smaller group and zero otherwise.

All coefficients and right-hand sides have polynomial encoding length in \(m,\tau,L\): the quantities \(\alpha_i\), \(c_k\), and \(q_{i,k}(b)\) are sums of input rationals, computable exactly with polynomially many bits. Also, every feasible variable satisfies
\[ 0\leq z_{t,k}\leq\mu_t, \]
so \(\mathcal P\) is bounded.

The rational linear-programming theorem therefore applies. Each branch requires one polynomial-time linear-programming computation, followed by polynomial-time rational arithmetic. Averaging two polynomial-length rational assignments also produces an assignment of polynomial encoding length.

Crucially, these computations use the listed types directly; they do not expand binary-encoded masses into individual students.

The algorithm always returns an envy-free assignment, so the “none exists” outcome never occurs under the stated premises.
