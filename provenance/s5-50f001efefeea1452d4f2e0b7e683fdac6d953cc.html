The continuous mirror question, as graded

Given a finite alternative set \(C\), a chair order \(\succ\), a finite support \(T\) of ranking types, and a rational polytope \(P\) of possible mass distributions \(\mu\) over \(T\), construct a finite adaptive policy that queries unranked pairs and returns a ranking \(R\) that is \(W_\mu\)-unimprovable for every \(\mu\in P\). Each query reports the pairwise majority under \(\mu\), with ties resolved by a fixed public rule; \(W_\mu\)-unimprovability is defined using rankings reachable under \(W_\mu\) and alignment with \(\succ\).

Packaged proof task (what the prover saw — nothing else)

Let \(C\) contain \(m\geq 2\) alternatives, let \(\succ\) be a strict total chair order, and let \(T\) list \(\tau\geq 1\) distinct strict ranking types that vote sincerely.
A society is given by its support: the list of the \(\tau\) types with positive mass, each with its mass as a binary rational; \(\tau\) is the support size, not the number of possible rankings. Here the masses are unknown: their feasible values are the rational points of a nonempty rational polytope \(P\subseteq\{\mu\in\mathbb R_{>0}^{\tau}:\sum_{t\in T}\mu_t=1\}\), given by explicit binary rational inequalities.
An unknown \(\mu\in P\cap\mathbb Q^{\tau}\) remains fixed throughout the interaction. For distinct \(x,y\), define \(xW_\mu y\) when \(\sum_{t:x\succ_t y}\mu_t>1/2\); at equality, an input table selects exactly one winner for each unordered pair.
Starting from the empty relation \(Q\), a query may select only a pair incomparable in \(Q\). If its reported winner is \(x\) and loser is \(y\), replace \(Q\) by the transitive closure of \(Q\cup\{(x,y)\}\). Continue until \(Q\) is a total ranking.
A deterministic adaptive policy selects queries using only the input and previous queried pairs and winners. Represent it by a finite executable description, rather than an explicitly expanded decision tree; its terminal ranking \(R_\mu\) may depend on the answers.
A ranking is \(W_\mu\)-reachable if some legal sequence of queries under \(W_\mu\) produces it. Define \(A_\succ(R)=\{(x,y):x\succ y\text{ and }xRy\}\). A reachable ranking \(R\) is \(W_\mu\)-unimprovable if no reachable \(R'\) satisfies \(A_\succ(R)\subsetneq A_\succ(R')\).

Can a policy whose outcome \(R_\mu\) is \(W_\mu\)-unimprovable for every \(\mu\in P\cap\mathbb Q^{\tau}\) be constructed and executed in time polynomial in \(m,\tau,L\), or is this construction problem NP-hard? Here \(L\) is the total binary input length, and each majority query has unit oracle cost.

For finite committees, insertion sort produces an unimprovable ranking for every total asymmetric majority relation, without prior knowledge of that relation; the result also allows fixed resolution of indecisive votes. [Curello and Sinander](https://arxiv.org/abs/2001.11341). No separate complexity result for the polytope-input formulation is supplied.

Modeling choices made when packaging the task

  • Normalized total mass to one and restricted realized masses to binary rationals, consistent with the required society encoding.
  • Required every listed type to have positive mass throughout the nonempty feasible polytope, so the listed support size remains the actual support size.
  • Specified an explicit rational inequality encoding of the polytope and included all input data in L.
  • Specified sincere voting by strict ranking types and encoded fixed tie resolution by a winner table on unordered pairs.
  • Restored immediate transitive closure after each binding query and mandatory continuation until a total ranking is obtained.
  • Interpreted the guarantee pointwise: one policy must work for every feasible society, but its output ranking may depend on query answers.
  • Used a finite executable policy description and counted both construction and execution time, with unit-cost majority queries, to avoid requiring an exponentially expanded decision tree.
  • Restricted to at least two alternatives and a nonempty support to exclude vacuous interaction instances.

Result

The construction problem is polynomial-time solvable in the stated oracle model. A single deterministic insertion-sort policy works for every feasible mass vector and uses at most \(\binom{m}{2}\) majority queries.

1. Each fixed mass vector defines a tournament

Fix \(\mu\in P\cap\mathbb Q^\tau\). For distinct alternatives \(x,y\), put
\[ s_\mu(x,y)=\sum_{t:x\succ_t y}\mu_t. \]
Because every type is a strict ranking and the masses sum to one,
\[ s_\mu(x,y)+s_\mu(y,x)=1. \]
Consequently, away from equality exactly one alternative has majority support. At equality the input table chooses exactly one winner. Including that prescribed resolution in \(W_\mu\), the relation \(W_\mu\) is therefore total and asymmetric on distinct alternatives.

Moreover, \(W_\mu\) remains fixed throughout execution: the types vote sincerely, \(\mu\) is fixed, and the tie table is fixed.

2. The executable policy

Label the alternatives in chair order:
\[ c_1\succ c_2\succ\cdots\succ c_m. \]

Maintain an ordered list \(S\), initially \([c_m]\). For \(k=m-1,m-2,\ldots,1\):

  • Write the current list as \(S=[s_1,\ldots,s_r]\).
  • Query \(\{c_k,s_1\},\{c_k,s_2\},\ldots\), in that order, until \(c_k\) first wins.
  • If its first win is against \(s_j\), insert \(c_k\) immediately before \(s_j\). If it loses every query, append \(c_k\).

Return the final list as a ranking. This is the chair-ordered insertion-sort strategy of Curello and Sinander. Their Theorem 1 establishes that this strategy produces a \(W\)-unimprovable ranking for every total asymmetric relation \(W\), under the same query-and-transitive-closure protocol. [Curello–Sinander, §5](https://arxiv.org/pdf/2001.11341)

3. Every query is legal

We prove an invariant describing the actual relation \(Q\), so legality does not depend on merely treating the list as an ordinary sorting data structure.

At the start of stage \(k\), \(Q\) totally orders the alternatives in \(S\) according to that list, while every remaining alternative is isolated. This holds initially: a singleton has no distinct pairs, and \(Q\) is empty.

During stage \(k\), suppose \(c_k\) has lost against precisely the prefix \(s_1,\ldots,s_{j-1}\). Then \(Q\) consists of the existing chain on \(S\), together with
\[ s_iQc_k\qquad(1\leq i<j), \]
and the other unprocessed alternatives remain isolated.

Indeed, adding \(s_{j-1}Qc_k\) can imply only that predecessors of \(s_{j-1}\) also precede \(c_k\). It creates no relation from \(c_k\) to an element of \(S\). Thus \(c_k\) and \(s_j\) are incomparable, making the next query legal.

If \(c_k\) wins against \(s_j\), transitivity gives
\[ c_kQs_\ell\qquad(j\leq\ell\leq r). \]
Together with the preceding losses, this produces exactly the chain obtained by inserting \(c_k\) before \(s_j\). If every query is lost, the resulting chain places \(c_k\) last. No isolated alternative enters any directed path, so all other unprocessed alternatives remain isolated.

This proves the invariant inductively. After the final stage, \(Q\) is a total ranking, exactly the returned list. Hence the policy terminates legally and its outcome is \(W_\mu\)-reachable.

4. The guarantee holds simultaneously over the polytope

The cited theorem applies because:

  • \(C\) is finite and \(\succ\) is a strict total chair order;
  • \(W_\mu\) is total, asymmetric, and fixed;
  • legal queries and closure updates are exactly those of the theorem;
  • its alignment comparison is precisely inclusion of the sets \(A_\succ(R)\).

Thus, for the arbitrarily fixed \(\mu\), no \(W_\mu\)-reachable ranking \(R'\) satisfies
\[ A_\succ(R_\mu)\subsetneq A_\succ(R'). \]

The policy itself depends only on the chair order and observed answers. It does not depend on the fixed \(\mu\) used in this argument. Therefore the same policy has the required guarantee for every \(\mu\in P\cap\mathbb Q^\tau\). Fixed tie winners are already incorporated into the tournament, so no additional tie assumption is needed.

5. Construction and execution complexity

At stage \(k\), the list contains \(m-k\) alternatives, so that stage makes at most \(m-k\) queries. Hence the total is at most
\[ \sum_{k=1}^{m-1}(m-k)=\binom{m}{2}. \]

The executable description consists of a fixed program and the chair-ordered alternative identifiers; it has polynomial size. An array implementation performs \(O(m^2)\) scans and list-update operations. The invariant above lets the list and current scan position represent \(Q\) implicitly, without recomputing transitive closure.

Including input reading and binary bookkeeping, construction and execution take time polynomial in \(m,\tau,L\), with each oracle query charged unit cost. Neither enumerating feasible majority relations nor solving an optimization problem over \(P\) is necessary.
