The continuous mirror question, as graded

Given a finite template \(A=(O,h,\alpha,t)\) with \(O=\{A,B\}\), odd \(\alpha\), a binary-rational initial distribution \(\mu_0\) over the template's local states, and a universal temporal formula \(\phi\) without epistemic operators, decide whether every path from \(\mu_0\) satisfies \(\phi\). For a distribution \(\mu\), let \(a(\mu)\) be its active mass and \(a_o(\mu)\) the active mass holding opinion \(o\). When \(a(\mu)>0\), set \(q_o=a_o(\mu)/a(\mu)\) and \(p_o(\mu)=\sum_{j=(\alpha+1)/2}^{\alpha}\binom{\alpha}{j}q_o(\mu)^j(1-q_o(\mu))^{\alpha-j}\). A transition chooses masses \(x_{\ell,o}\geq0\) with \(\sum_o x_{\ell,o}=\mu_\ell\), forces latent mass to take the action for its current opinion, and requires \(\sum_{\ell\ \mathrm{active}}x_{\ell,o}=a(\mu)p_o(\mu)\). It produces \(\mu'_{\ell'}=\sum_{\ell,o:t(\ell,o)=\ell'}x_{\ell,o}\); if \(a(\mu)=0\), only latent transitions apply. The proposition \(p(o)\) holds exactly when all mass has opinion \(o\).

Result: the problem is in \(\mathrm P\)

The exact, unrounded model-checking problem is decidable in \(\mathrm P\), with running time \(O(L)\) under the explicit input encoding.

The key invariant is that the set of opinions with positive mass never changes. Consequently, every reachable distribution has the same atomic labels, and ACTL model checking reduces to evaluating the formula on a single state with a self-loop. This covers arbitrary permitted transition tables, every finite odd \(\alpha\), and mixed initial societies.

1. Every distribution has a successor

Let \(r=(\alpha+1)/2\). When \(a(\mu)>0\), write \(q=q_A\), so \(q_B=1-q\). Reindexing the sum defining \(p_B\) gives
\[ p_A+p_B = \sum_{j=r}^{\alpha}\binom{\alpha}{j}q^j(1-q)^{\alpha-j} + \sum_{j=0}^{r-1}\binom{\alpha}{j}q^j(1-q)^{\alpha-j} =1. \]
Here the two ranges partition all indices because \(\alpha\) is odd.

Thus a feasible allocation exists: for active \(\ell\), choose \(x_{\ell,o}=\mu_\ell p_o\); for latent \(\ell\), choose \(x_{\ell,\operatorname{op}(\ell)}=\mu_\ell\) and set the other allocation to zero. The active row sums equal \(\mu_\ell\), and the active column sums equal \(a(\mu)p_o\).

When \(a(\mu)=0\), use the prescribed latent allocations. In both cases, the resulting successor is a distribution: all masses are nonnegative, and total mass remains \(1\) because \(t\) is total.

Therefore the transition relation is serial. Repeatedly using the allocation just constructed produces an infinite path from every distribution.

2. Opinion support is invariant

Define the total and latent masses of opinion \(o\) by
\[ c_o(\mu)=\sum_{\ell:\operatorname{op}(\ell)=o}\mu_\ell, \qquad z_o(\mu)=\sum_{\ell:\operatorname{op}(\ell)=o,\ b(\ell)=1}\mu_\ell. \]
Then \(c_o(\mu)=a_o(\mu)+z_o(\mu)\).

For every permitted transition \(\mu\to\mu'\) with \(a(\mu)>0\), the transition restrictions imply
\[ c_o(\mu')=z_o(\mu)+a(\mu)p_o(\mu). \]
Indeed, latent mass keeps its opinion under its forced action. Active mass allocated to action \(o\) acquires opinion \(o\), and its prescribed total is \(a(\mu)p_o(\mu)\). This identity holds for every feasible allocation, regardless of the successor latent statuses.

Also,
\[ p_o(\mu)>0\quad\Longleftrightarrow\quad a_o(\mu)>0. \]
To verify this, if \(a_o(\mu)=0\), then \(q_o=0\), and every term defining \(p_o\) vanishes because its exponent \(j\) is positive. If \(a_o(\mu)>0\), then \(q_o>0\), and the term with \(j=\alpha\) gives \(p_o(\mu)\geq q_o^\alpha>0\).

Since all masses are nonnegative, it follows that
\[ c_o(\mu')>0 \quad\Longleftrightarrow\quad z_o(\mu)>0\ \text{or}\ a_o(\mu)>0 \quad\Longleftrightarrow\quad c_o(\mu)>0. \]

If \(a(\mu)=0\), all mass is latent and preserves its opinion, so \(c_o(\mu')=c_o(\mu)\). Hence, in every case,
\[ \{o:c_o(\mu')>0\}=\{o:c_o(\mu)>0\}. \]

By induction, this opinion support is constant along every finite transition sequence.

Because total mass is \(1\), the proposition \(p(o)\) holds exactly when opinion support is the singleton \(\{o\}\). Therefore every distribution reachable from \(\mu_0\) has precisely the same atomic labels as \(\mu_0\).

In particular, a mixed initial society never reaches exact unanimity at any finite time.

3. Exact reduction of ACTL to Boolean evaluation

Let \(S_0=\{o:c_o(\mu_0)>0\}\). Define a Boolean evaluator \(E\) on the standard ACTL basis by
\[ E(p(o))=[S_0=\{o\}],\qquad E(\neg p(o))=\neg E(p(o)), \]
\[ E(\psi\land\chi)=E(\psi)\land E(\chi),\qquad E(\psi\lor\chi)=E(\psi)\lor E(\chi), \]
\[ E(\mathrm{AX}\,\psi)=E(\psi), \]
\[ E(\mathrm A[\psi\,\mathrm U\,\chi])=E(\chi),\qquad E(\mathrm A[\psi\,\mathrm R\,\chi])=E(\chi). \]
The brackets in the atomic clause denote the Boolean truth value of the enclosed condition.

Claim. For every subformula \(\theta\) and every reachable distribution \(\mu\), we have \(\mu\models\theta\) exactly when \(E(\theta)\) is true.

Proof. Proceed by structural induction.

The atomic cases follow from opinion-support invariance. The Boolean cases follow directly from the induction hypothesis.

For \(\mathrm{AX}\,\psi\), all successors are reachable and have the same truth value \(E(\psi)\). Since every distribution has a successor and every successor extends to an infinite path, universal next has exactly that truth value.

For \(\mathrm A[\psi\,\mathrm U\,\chi]\), if \(E(\chi)\) is true, then \(\chi\) already holds at the current position, satisfying until with witness index \(0\). If \(E(\chi)\) is false, it remains false at every position of every path, so no until witness exists. Infinite paths exist, so the universal formula is false.

For \(\mathrm A[\psi\,\mathrm R\,\chi]\), if \(E(\chi)\) is true, then \(\chi\) holds forever on every path, satisfying release. If \(E(\chi)\) is false, release fails at the current position: standard release requires its right operand there, including when its left operand already holds. Again, infinite paths exist.

This completes the induction. \(\square\)

Standard abbreviations such as \(\mathrm{AF}\) and \(\mathrm{AG}\) can be handled directly by the same evaluator.

4. Algorithm and running time

The algorithm is:

  • Read the opinions appearing in the positive initial support and determine \(S_0\).
  • Evaluate \(\phi\) bottom-up using the rules above.
  • Return \(E(\phi)\).

Under the stated initialization restriction, \(\tau\leq m=2\): each opinion has only one permitted initial state. Because the support list contains only positive masses, no rational arithmetic is needed to determine \(S_0\).

After parsing, the semantic computation uses \(O(m+\tau+|\phi|)\) elementary Boolean and support operations. Including an input scan, the running time is
\[ O(L+m+\tau+|\phi|)=O(L), \]
where \(L\) is the total binary input length.

Here \(|\mathcal L|=2m(H+1)=4(H+1)\), and the explicit transition table contains \(m|\mathcal L|\) entries. Its encoding contributes to \(L\), but the algorithm need not evaluate transitions or majority polynomials. There is no additional dependence on the numerical values of \(|\mathcal L|\) or \(\alpha\). In particular, binary encoding of \(\alpha\) causes no numerical iteration up to \(\alpha\).

Thus the problem is in \(\mathrm P\). NP-hardness under polynomial-time many-one reductions would consequently imply \(\mathrm P=\mathrm{NP}\).

5. Why rounding changes the situation

The referenced paper’s Definition 3.3 uses a finite weight set and replaces the updated opinion mass by a nearest weight. That is a different transition rule from exact mass evolution. [Kouvaros–Lomuscio, Definition 3.3](https://www.doc.ic.ac.uk/~alessio/papers/16/AAMAS16-KL.pdf)

The proof here depends on preserving arbitrarily small positive masses. It therefore settles the specified unrounded problem directly, without invoking that abstraction. Standard temporal “eventually” requires truth at a finite path position; asymptotic approach to unanimity does not satisfy it.
