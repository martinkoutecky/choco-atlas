The continuous mirror question, as graded

Given \(p\) binary issues, a finite type set \(T\) of complete rankings and uncertainty radii, rational type masses \(\mu_\theta\), an initial report-mass state \(\nu^0_{\theta,a}\), a common order \(O\), and the paper's nonatomic simultaneous-update rule, does every maximal legal positive-mass one-issue LDI execution terminate at a state with no improving mass move, or is there a finite cycle or Zeno execution?

Packaged proof task (what the prover saw — nothing else)

Let \(p\geq1\), \(D=\{0,1\}^p\), and \(m=|D|=2^p\). A society is given by its support: the list of \(\tau\) types with positive binary-rational masses \(\mu_\theta\), summing to \(1\); \(\tau\) is the support size, not the number of possible types. Each type has an explicitly listed strict ranking \(R_\theta\) of \(D\) and fixed radii \(r_\theta^i\in\mathbb Q_{\geq0}\). State any running times in \(m,\tau,L,p\), where \(L\) is the input bit length.
All rankings are \(O\)-legal for one common issue order \(O\): the preference between outcomes differing only on an issue depends only on outcomes of earlier issues.
The initial report masses are binary rationals \(\nu^0_{\theta,a}\geq0\) with \(\sum_a\nu^0_{\theta,a}=\mu_\theta\). Subsequent masses may be real. At state \(\nu\), set \(s_c^i=\sum_{\theta,a:a_i=c}\nu_{\theta,a}\); simultaneous plurality selects each issue’s winner, with ties favoring \(0\).
Type \(\theta\) considers the score tuples \(S_\theta(\nu)=\prod_i\{v^i\in\mathbb R_{\geq0}^2:\|v^i-s^i\|_\infty\leq r_\theta^i\}\) possible. These hypothetical vectors need not sum to \(1\).
For a report \(a\), define \(F(v,a)\) issuewise: a strict score leader wins, and a score tie is resolved in favor of \(a_i\). Thus an individual report has only infinitesimal influence at ties.
Writing \(a^{\oplus i}\) for \(a\) with issue \(i\) flipped, this flip is an LDI move exactly when \(F(v,a^{\oplus i})\succeq_\theta F(v,a)\) for every \(v\in S_\theta(\nu)\), with strict preference for at least one such \(v\).
A round chooses one issue \(i\) and simultaneously transfers masses \(x_{\theta,a}\in[0,\nu_{\theta,a}]\) from reports \(a\) to \(a^{\oplus i}\), with \(\sum_{\theta,a}x_{\theta,a}>0\); every positive transfer must be an LDI move evaluated at the state before the round. There is no minimum moving mass or fairness requirement.
An execution is maximal if it is infinite or ends where no positive-mass legal move exists. A finite cycle returns to the same report-mass state after positive rounds; a Zeno execution has infinitely many rounds with finite total transferred mass.

Does every maximal execution from every admissible initial state terminate after finitely many rounds at a state with no improving mass move, or does an admissible instance admit an infinite legal execution, possibly a finite cycle or a Zeno execution?

For finitely many agents, binary-issue LDI dynamics with common \(O\)-legal rankings terminate from every initial profile ([Kavner et al., 2023](https://www.ijcai.org/proceedings/2023/0310.pdf)).
A nonatomic extension claims convergence with simultaneous updates under a fixed minimum resolution \(\varepsilon>0\), expressly introduced to exclude indefinitely shrinking moves; that result does not address unrestricted positive-mass executions ([full version](https://arxiv.org/pdf/2301.08873)).

Modeling choices made when packaging the task

  • Required all rankings to be O-legal for the supplied common order, restoring the anchor's hypothesis.
  • Normalized total society mass to one, following the nonatomic definition.
  • Selected additive infinity-norm uncertainty with fixed nonnegative rational radii; the graded question did not specify a candidate-wise distance.
  • Used independent nonnegative real hypothetical score coordinates without a fixed-total constraint, extending the score-vector uncertainty definition to masses.
  • Defined individual influence as resolving score ties in favor of the reported candidate, following the nonatomic definition; actual election ties favor zero.
  • Specified one common issue per simultaneous round and evaluated all participating moves at the state before the round.
  • Allowed real transfers of arbitrary positive total mass, without a minimum resolution, to preserve the graded question's unrestricted positive-mass and Zeno scope; this explicitly differs from the published nonatomic model.
  • Defined maximality without fairness, and defined Zeno behavior by finite total transferred mass because no physical timing model was supplied.
  • Included all infinite legal executions in the negative alternative, since finite cycles and Zeno executions need not exhaust nontermination.

Proven conclusion. An admissible instance admits an infinite legal Zeno execution. Moreover, that execution can converge to a state that still has a positive-mass LDI move. Thus the proposed universal finite-termination property is false.

The failure already occurs for \(p=1\). Below I also extend the construction to every \(p\) and prove that common \(O\)-legal rankings nevertheless exclude finite cycles.

1. An admissible instance and its legal moves.

Set \(p=1\), so \(D=\{0,1\}\) and \(m=2\). There is one supported type \(\theta\), with:

  • Mass \(\mu_\theta=1\).
  • Strict ranking \(1\succ_\theta 0\).
  • Radius \(r_\theta^1=\tfrac12\).
  • Initial report masses \(\nu^0_{\theta,0}=1\) and \(\nu^0_{\theta,1}=0\).

These data are binary rationals, and the ranking is \(O\)-legal for the unique issue order.

Write \(q=\nu_{\theta,1}\). The score vector is then \(s^1=(1-q,q)\).

For every \(q\in[0,1]\), the hypothetical tie vector \(v^*=(\tfrac12,\tfrac12)\) belongs to \(S_\theta(\nu)\), because \(\|v^*-s^1\|_\infty=|q-\tfrac12|\leq\tfrac12\).

We now verify that \(0\to1\) is an LDI move at every such state. For any hypothetical vector \(v\):

  • If \(v_0>v_1\), both reports produce outcome \(0\).
  • If \(v_1>v_0\), both reports produce outcome \(1\).
  • If \(v_0=v_1\), then \(F(v,0)=0\) and \(F(v,1)=1\).

Consequently \(F(v,1)\succeq_\theta F(v,0)\) for every \(v\in S_\theta(\nu)\). At \(v^*\), the preference is strict. Hence \(0\to1\) is LDI whenever report \(0\) has positive mass.

2. An infinite execution with a nonterminal limit.

Index states by \(n\geq0\). In round \(n\), transfer \(x_n=2^{-(n+2)}\) from report \(0\) to report \(1\).

After \(n\) rounds, the report masses are
\(\nu^{(n)}_{\theta,1}=\tfrac12(1-2^{-n})\) and
\(\nu^{(n)}_{\theta,0}=\tfrac12(1+2^{-n})\).

These formulas follow from the finite geometric sum
\(\sum_{k=0}^{n-1}2^{-(k+2)}=\tfrac12(1-2^{-n})\).

Every round satisfies all requirements:

  • It updates the single issue.
  • Its transferred mass \(x_n\) is strictly positive.
  • It is feasible: \(x_n\leq\tfrac14<\nu^{(n)}_{\theta,0}\).
  • Its positive transfer is LDI at the state before the round, by the preceding verification.

Therefore the sequence is an infinite legal execution. It is maximal under the task’s definition, which expressly declares every infinite execution maximal.

Its total transferred mass is \(\sum_{n=0}^{\infty}x_n=\tfrac12\), so it is Zeno. All its finite states have binary-rational masses.

The limiting state satisfies \(\nu^{(\infty)}_{\theta,0}=\nu^{(\infty)}_{\theta,1}=\tfrac12\). At that state, \(0\to1\) remains LDI and has positive source mass. For example, transferring mass \(\tfrac14\) is a legal round.

Thus this execution neither terminates nor converges to a state without improving mass moves.

3. The same obstruction for every number of issues.

For any \(p\geq1\), use one type of mass \(1\), and rank outcomes by decreasing value of \(U(a)=\sum_{j=1}^{p}2^{p-j}a_j\). Distinct binary outcomes have distinct values, so this defines an explicitly listable strict ranking. Flipping any issue from \(0\) to \(1\) increases \(U\), independently of all other coordinates. The ranking is therefore \(O\)-legal for \(O=(1,\ldots,p)\).

Set \(r_\theta^1=\tfrac12\) and \(r_\theta^j=0\) for \(j>1\). Initially place all mass on \((0,\ldots,0)\), and perform the same transfers \(x_n\) to \((1,0,\ldots,0)\), updating only issue \(1\).

Throughout the execution, every later issue has score vector \((1,0)\) and radius zero, so its hypothetical outcome is always \(0\). The two outcomes compared by an issue-\(1\) flip therefore differ only on issue \(1\), where \(1\) is preferred. The verification in Sections 1–2 applies verbatim.

Hence the failure persists for every \(p\), with support size \(\tau=1\).

4. A further proven property: finite cycles are impossible.

Despite the Zeno counterexample, no admissible instance with common \(O\)-legal rankings admits a finite cycle.

*Proof.* Relabel issues so that \(O=(1,\ldots,p)\). Suppose a finite cycle exists, and let \(i\) be the earliest issue in this order that is updated anywhere in the cycle. No earlier issue is updated, so its scores remain fixed throughout the cycle.

Fix a type \(\theta\) and a report prefix \(u\in\{0,1\}^{i-1}\). For each \(j<i\), define
\(B_{\theta,j}(u_j)=\{F_j(v^j,u_j):v^j\in S_\theta^j(\nu)\}\).
Here \(S_\theta^j(\nu)\) denotes the issue-\(j\) factor of the uncertainty set. These nonempty sets are fixed throughout the cycle. By the product definition of uncertainty, the attainable earlier outcome prefixes are exactly
\(B_{\theta,u}=\prod_{j<i}B_{\theta,j}(u_j)\).
For \(i=1\), this is the singleton containing the empty prefix.

By \(O\)-legality and strictness, each earlier outcome prefix \(w\) determines a unique preferred issue-\(i\) bit \(g_{\theta,i}(w)\), independently of later outcomes.

Consider any legal flip on issue \(i\), from a report with prefix \(u\) and issue-\(i\) bit \(c\). There must be a hypothetical tie on issue \(i\): without a possible tie, the flip changes no hypothetical outcome and cannot satisfy strict improvement.

For every \(w\in B_{\theta,u}\), product uncertainty lets us combine an earlier score tuple realizing \(w\) with that issue-\(i\) tie and any allowable later score tuple. The two reports then produce outcomes differing only on issue \(i\), from \(c\) to \(1-c\). Weak dominance and strict ranking imply \(g_{\theta,i}(w)=1-c\).

Therefore a legal flip for this fixed pair \((\theta,u)\) is possible only if \(g_{\theta,i}\) is constant on \(B_{\theta,u}\). When it is constant, every such flip throughout the cycle has the same target bit \(b_{\theta,u}\).

Choose a pair \((\theta,u)\) receiving a positive transfer on issue \(i\), and consider
\(Q_{\theta,u}(\nu)=\sum_{a:\,a_{<i}=u,\ a_i=b_{\theta,u}}\nu_{\theta,a}\).

Updates on later issues preserve \(Q_{\theta,u}\). Updates on issue \(i\) can only increase it, and the chosen positive transfer increases it strictly. Earlier issues are never updated. Hence \(Q_{\theta,u}\) cannot return to its initial value, contradicting return to the same report-mass state. This proves the claim.

5. Relation to the cited convergence result.

The construction uses arbitrarily small positive transfers. Appendix C of the [full version](https://arxiv.org/pdf/2301.08873) imposes a fixed minimum resolution specifically to exclude infinite sequences of successively smaller moving subsets. Our execution violates that additional hypothesis, while satisfying every hypothesis in the present task.

The requested termination question is therefore completely resolved by the Zeno construction; a finite cycle is unnecessary and, as proved above, impossible under these assumptions.

The integer-valued expression

takes distinct values on distinct binary outcomes. It therefore defines a strict ranking of all \(m=2^p\) outcomes, which can be supplied as an explicit list.

A flip from \(0\) to \(1\) on issue \(j\) increases this value by \(2^{p-j}>0\), independently of all other coordinates. This establishes the stated legality for the common issue order.

This extension satisfies the input representation requirements and uses support size \(\tau=1\). No running-time claim is made, so no complexity bound requires verification.

4. Exclusion of finite cycles

The additional argument is sound, including simultaneous transfers.

  • Earliest updated issue. A finite cycle contains a positive round, so an earliest updated issue \(i\) exists. Every earlier issue retains its report coordinates and hence its scores throughout the cycle.
  • Fixed attainable prefixes. For fixed \((\theta,u)\), the sets \(B_{\theta,j}(u_j)\) are nonempty because each uncertainty factor contains its actual score vector. They remain fixed because earlier scores and radii remain fixed. Product uncertainty makes their Cartesian product exactly the attainable earlier outcome prefixes. The empty-prefix convention correctly handles \(i=1\).
  • Preferred bit. Strict rankings and legality for the common issue order give a unique preferred issue-\(i\) bit at each earlier outcome prefix, independent of later outcomes. This is precisely the dependence restriction supplied in the task.
  • Necessity of a hypothetical tie. The two reports differ only on issue \(i\). If no hypothetical tie exists on that issue, their hypothetical outcomes agree everywhere, contradicting the strict-improvement requirement.
  • Direction forced by dominance. Product uncertainty permits any attainable earlier prefix to be combined with the tie witness and an allowable later tuple. The compared outcomes are distinct and differ only on issue \(i\). Weak dominance under a strict ranking therefore forces the target bit to be preferred at every attainable earlier prefix.
  • Direction fixed throughout the cycle. Those attainable prefixes do not change. Thus, for any pair \((\theta,u)\) that actually moves on issue \(i\), every legal issue-\(i\) transfer has the same target bit.
  • Monotonic quantity. Later-issue transfers preserve the defining prefix and issue-\(i\) bit of \(Q_{\theta,u}\). Issue-\(i\) transfers for this pair increase \(Q_{\theta,u}\), and none can decrease it. This remains true when transfers occur simultaneously. A positive transfer for the chosen pair gives a strict increase, preventing return to the initial state.

The contradiction proves the claimed exclusion of finite cycles. It does not assert that absence of cycles implies finite termination.
