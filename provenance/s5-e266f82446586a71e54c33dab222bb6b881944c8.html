The continuous mirror question, as graded

Given a connected undirected role graph \(H=(T,E)\) and positive rational masses \(\mu_t\) summing to \(1\), choose seed masses \(x_t\in[0,\mu_t]\) minimizing \(\sum_{t\in T}x_t\). Starting from \(y_t^0=x_t\), all remaining mass of type \(t\) activates once every neighboring type is fully active; require eventual activation of total mass \(1\).

Packaged proof task (what the prover saw — nothing else)

A society is given by its support: the list of \(\tau\) types with positive binary rational masses \(\mu_t\), with \(\sum_{t\in T}\mu_t=1\). Here \(\tau=|T|\) is the support size, not the number of possible types.
The input also contains a finite connected simple undirected role graph \(H=(T,E)\); write \(m=|E|\). Every type may be seeded.
Choose real seed masses \(0\le x_t\le\mu_t\), at cost \(\sum_{t\in T}x_t\). Set \(y_t^0=x_t\). At each synchronous round, set \(y_t^{k+1}=\mu_t\) if \(y_u^k=\mu_u\) for every neighbor \(u\) of \(t\), and otherwise set \(y_t^{k+1}=y_t^k\). The neighbor condition is vacuous for an isolated type.
A seed vector succeeds if some finite round has \(\sum_{t\in T}y_t^k=1\). The optimization problem minimizes its cost; its budget decision version asks whether a successful vector of cost at most a given binary rational \(b\in[0,1]\) exists. Let \(L\) be the total input bit length; state running times in \(m,\tau,L\).

Is this budget decision problem in \(\mathrm{P}\), or is it \(\mathrm{NP}\)-hard?

For discrete agents on a connected undirected unweighted graph, minimizing the number of seeds needed for total activation when every neighbor must already be active is \(\mathrm{NP}\)-hard. [Source](https://upcommons.upc.edu/bitstream/handle/2117/26600/EJOR15_MRS.pdf)
No complexity result for exactly the mass formulation above was identified in the literature search.

Result

The budget decision problem is \(\mathrm{NP}\)-complete, even when all masses are equal dyadic rationals and the role graph is connected.

The key fact is that a seed vector succeeds exactly when its fully seeded types form a vertex cover. Thus allowing arbitrary real seed masses does not reduce the optimum.

1. Exact characterization of successful seeds

For a feasible seed vector \(x\), define its set of fully seeded types by
\[ S(x)=\{t\in T:x_t=\mu_t\}. \]
A vertex cover of \(H\) is a set containing at least one endpoint of every edge.

Lemma. A seed vector \(x\) succeeds if and only if \(S(x)\) is a vertex cover. Whenever it succeeds, every type is full by round one.

Proof. The update rule preserves \(0\le y_t^k\le\mu_t\), and a full type remains full. Since \(\sum_t\mu_t=1\), the equality \(\sum_t y_t^k=1\) holds exactly when every type is full.

Suppose \(S(x)\) is not a vertex cover. There is an edge \(\{u,v\}\) with \(x_u<\mu_u\) and \(x_v<\mu_v\). We prove inductively that \(y_u^k=x_u\) and \(y_v^k=x_v\) for every round \(k\).

This holds at round zero. If it holds at round \(k\), then \(v\) is a neighbor of \(u\) that is not full, so \(u\)'s activation condition fails and \(y_u^{k+1}=y_u^k=x_u\). The same argument gives \(y_v^{k+1}=x_v\). Hence neither endpoint ever becomes full, and \(x\) fails.

Conversely, suppose \(S(x)\) is a vertex cover. For any \(t\notin S(x)\), every neighbor belongs to \(S(x)\): otherwise their connecting edge would be uncovered. All those neighbors are full at round zero, so \(y_t^1=\mu_t\). Types in \(S(x)\) remain full. Therefore every type is full at round one. This also covers isolated types, whose neighbor condition is vacuous. \(\square\)

In particular, when \(\tau=1\), the zero seed vector succeeds in one round and the optimum is zero.

2. The optimum is minimum weighted vertex cover

For \(C\subseteq T\), write \(w(C)=\sum_{t\in C}\mu_t\). Then
\[ \operatorname{OPT}(H,\mu)= \min_{\substack{C\subseteq T\\ C\text{ is a vertex cover}}}w(C). \]

Indeed, any successful vector \(x\) has a vertex cover \(S(x)\), and
\[ \sum_{t\in T}x_t\ge\sum_{t\in S(x)}\mu_t=w(S(x)). \]
Conversely, for any vertex cover \(C\), seed each type in \(C\) with its entire mass and every other type with zero. The lemma proves success, and the cost is \(w(C)\).

Consequently, the budget question is equivalent to asking whether \(H\) has a vertex cover \(C\) with \(w(C)\le b\). An optimal seed vector always exists with \(x_t\in\{0,\mu_t\}\).

3. Membership in \(\mathrm{NP}\) and running times

A certificate is a \(\tau\)-bit indicator vector for a set \(C\subseteq T\). The verifier checks that every edge has an endpoint in \(C\), and then checks the exact rational inequality \(w(C)\le b\).

The graph check takes \(O(m+\tau)\) graph operations. For the arithmetic check, write the input rationals as binary-encoded fractions and take the product \(D\) of their denominators, including the denominator of \(b\). Its bit length is \(O(L)\), because the sum of the input denominator lengths is at most \(L\). Scaling the selected masses and budget by \(D\) reduces the comparison to integer arithmetic on \(O(L)\)-bit integers.

Using schoolbook arithmetic, a conservative verification bound is \(O((m+\tau)L^2)\) bit operations. Thus the problem belongs to \(\mathrm{NP}\), despite its formulation using real seed variables.

Enumerating all subsets gives an exact decision and optimization algorithm in \(O(2^\tau(m+\tau)L^2)\) time.

4. Hardness with connected graphs and dyadic masses

We reduce from the classical \(\mathrm{NP}\)-complete Vertex Cover decision problem: given a finite simple undirected graph \(G=(V,F)\) and an integer \(k\), decide whether it has a vertex cover of size at most \(k\). This is Karp’s “Node Cover” problem. [Karp, *Reducibility among Combinatorial Problems*](https://link.springer.com/chapter/10.1007/978-1-4684-2001-2_9).

We may restrict to \(n=|V|\ge1\) and \(0\le k\le n\), since the excluded cases are immediately decidable.

Let \(N\) be the smallest power of two satisfying \(N\ge n+k+3\), and put \(s=N-n-1\). Construct \(H\) as follows:

  • Retain all vertices and edges of \(G\).
  • Add a new vertex \(z\), adjacent to every original vertex.
  • Add \(s\) new leaves, each adjacent only to \(z\).

Then \(H\) is simple and connected, with \(\tau=N\) and \(m=|F|+N-1\). Give every type mass \(\mu_t=1/N\), and set \(b=(k+1)/N\).

All masses are positive and sum to one. Since \(N\) is a power of two, both the masses and budget have finite binary expansions. Also \(b\in[0,1]\).

We claim that \(G\) has a vertex cover of size at most \(k\) if and only if the constructed society has a successful seed vector of cost at most \(b\).

Forward direction. If \(C\subseteq V\) covers \(G\) and \(|C|\le k\), then \(C\cup\{z\}\) covers \(H\). It covers original edges through \(C\), and every new edge through \(z\). Fully seeding this set succeeds and costs
\[ \frac{|C|+1}{N}\le\frac{k+1}{N}=b. \]

Reverse direction. Suppose a seed vector succeeds with cost at most \(b\). Its fully seeded set \(S\) is a vertex cover of \(H\), and
\[ \frac{|S|}{N}\le\sum_t x_t\le\frac{k+1}{N}, \]
so \(|S|\le k+1\).

If \(z\notin S\), every new leaf must belong to \(S\) to cover its incident edge. But
\[ s=N-n-1\ge k+2, \]
contradicting \(|S|\le k+1\). Hence \(z\in S\).

Now \(S\cap V\) covers every original edge, and \(|S\cap V|\le |S|-1\le k\). Thus \(G\) has the required vertex cover.

Finally, minimality of \(N\) gives \(N<2(n+k+3)\le4n+6\). The construction therefore has polynomial size. Its output length is \(L=O((m+\tau)\log\tau)\), and it can be produced in \(O((m+\tau)\log\tau)\) bit operations under standard explicit graph encodings.

5. Conclusion

The reduction proves \(\mathrm{NP}\)-hardness under every stated restriction, including connectedness, positive normalized masses, and binary rational encoding. Together with the certificate argument, it proves \(\mathrm{NP}\)-completeness. A polynomial-time algorithm exists if and only if \(\mathrm{P}=\mathrm{NP}\).
