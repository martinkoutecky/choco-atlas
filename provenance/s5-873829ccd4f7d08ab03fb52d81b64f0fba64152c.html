The continuous mirror question, as graded

Given a candidate set \(C\) with \(|C|=2^d\), a target \(\alpha^\star\), and a list of rational ranking distributions \(\mu^{(1)},\ldots,\mu^{(s)}\), form each scenario's pairwise-majority tournament, breaking ties by a fixed priority order. Is there one seeding of \(C\) into the leaves of the perfect binary bracket such that \(\alpha^\star\) wins in every scenario? For the hardness anchor, ask whether this remains NP-hard when either the shared feedback arc set size or the number of private arcs is fixed to a constant.

Packaged proof task (what the prover saw — nothing else)

Let \(C\) contain \(m=2^d\) candidates, with \(d\geq 1\), and let \(\alpha^\star\in C\). There are \(s\geq 1\) scenarios, each a probability distribution \(\mu^{(i)}\) over strict total rankings of \(C\).
A society is given by its support: the list of its \(\tau_i\) types with positive mass, each mass a binary rational, summing to \(1\). Types are rankings; support size counts listed rankings, not the \(m!\) possible rankings. Put \(\tau=\sum_i\tau_i\), and let \(L\) be the total input bit length.
In scenario \(i\), form the pairwise-majority tournament \(D_i\); ties favor the earlier candidate in one supplied priority order, common to all scenarios. An arc \(ab\) means that \(a\) beats \(b\).
A seeding is a bijection from \(C\) to the leaves of the perfect binary bracket of depth \(d\). Each match advances its winner according to \(D_i\). Feasibility means that the same seeding makes \(\alpha^\star\) the root winner in every scenario.
Let \(H=(C,\bigcap_i E(D_i))\). Define \(k_F\) as the minimum number of arcs whose reversal makes \(H\) acyclic, and \(k_P\) as the number of unordered candidate pairs whose orientations differ between scenarios.

For each restriction separately—\(k_F\leq c\), with \(k_P\) unrestricted, and \(k_P\leq c\), with \(k_F\) unrestricted—is feasibility polynomial-time solvable for every fixed constant \(c\), or NP-hard for some fixed constant \(c\)? State running times in \(m,\tau,L,s,k_F,k_P\).

For explicitly supplied tournament digraphs, simultaneous tournament fixing is NP-hard even when \(k_F=0\), and separately when \(k_P=0\); it is FPT in \(k_F+k_P\). [Source](https://drops.dagstuhl.de/storage/00lipics/lipics-vol321-ipec2024/LIPIcs.IPEC.2024.7/LIPIcs.IPEC.2024.7.pdf)
No result specifically treating the supported rational-distribution input above was located in the literature search.

Modeling choices made when packaging the task

  • Ranking types are strict total orders, and each scenario's positive rational masses sum to one, interpreting ranking distributions as probability distributions.
  • Support sizes are recorded per scenario; the aggregate support parameter is their sum.
  • Seedings are bijective, so every candidate appears exactly once. The formal function-only definition would otherwise allow repeated copies of the target and trivialize the intended problem; the published version retains this omission.
  • The fixed tie-breaking priority is supplied as one strict total order common to all scenarios.
  • Shared feedback arc set size means the minimum number of shared arcs whose reversal makes the shared digraph acyclic; private arcs count unordered pairs with differing orientations.
  • The constant-parameter restrictions are considered separately, with the other parameter unrestricted; the nontrivial bracket domain has at least two candidates and one scenario.

Result

Both restrictions are NP-complete already at zero:

| Restriction | Complexity |
|---|---|
| \(k_F=0\), with \(k_P\) unrestricted | NP-complete, even with \(s=2\) |
| \(k_P=0\), with \(k_F\) unrestricted | NP-complete, even with \(s=1\) |

Thus, each restriction separately is NP-hard for every fixed nonnegative constant \(c\). The supported-distribution problem is nevertheless FPT in \(k_F+k_P\).

The essential point is that every explicitly supplied tournament can be realized by a polynomial-size supported distribution with dyadic masses, without any majority ties. We prove this representation claim below.

Exact extraction of the tournaments

Write the masses in scenario \(i\) as \(p_{ij}/q_{ij}\), for \(1\leq j\leq\tau_i\), with positive integer denominators. Define

\(Q_i=\prod_{j=1}^{\tau_i}q_{ij}\), and \(w_{ij}=p_{ij}(Q_i/q_{ij})\).

These are positive integers satisfying \(\sum_jw_{ij}=Q_i\). Because the denominators are explicitly encoded in the input, \(Q_i\) has \(O(L)\) bits. The weights and all sums below consequently have \(O(L)\) bits.

For distinct candidates \(a,b\), let \(\varepsilon_{ij}(a,b)\) equal \(1\) if ranking \(j\) places \(a\) before \(b\), and \(-1\) otherwise. The exact majority margin is

\(\mu^{(i)}(a\succ b)-\mu^{(i)}(b\succ a)=Q_i^{-1}\sum_jw_{ij}\varepsilon_{ij}(a,b)\).

Its sign determines the orientation; a zero sum is resolved using the supplied priority order. Inverse position tables for the rankings allow all pairwise comparisons to be computed directly.

Using schoolbook integer arithmetic, a conservative bound for constructing all tournaments is

\(B=O(\tau m^2L^2)\).

This bound includes reading the input and computing the integer weights. Constructing \(H\) and computing \(k_P\) then takes \(O(sm^2)\) additional time.

The feasibility question depends only on these extracted tournaments: the distributions specify deterministic majority outcomes, and the same outcomes are subsequently used throughout each bracket.

A polynomial-size realization lemma

Lemma. Every tournament \(D\) on \(m\geq2\) candidates is the strict pairwise-majority tournament of a distribution with fewer than \(2m(m-1)\) supported rankings. Every mass is dyadic and has \(O(\log m)\) bits. The total encoding length is \(O(m^3\log m)\).

Proof. For each arc \(ab\) of \(D\), enumerate the remaining candidates as \(r_1,\ldots,r_{m-2}\), and introduce the two rankings

\(a\succ b\succ r_1\succ\cdots\succ r_{m-2}\),

\(r_{m-2}\succ\cdots\succ r_1\succ a\succ b\).

Their combined unweighted margin on the pair \(\{a,b\}\) is \(2\), in favor of \(a\). Their combined margin on every other pair is zero:

  • For a pair among the remaining candidates, the two rankings give opposite orders.
  • For a pair involving exactly one of \(a,b\), that candidate precedes the remaining candidate in the first ranking and follows it in the second.

There are \(\binom m2\) arcs, so this construction produces a multiset of

\(N_0=2\binom m2=m(m-1)\)

rankings. For every arc \(ab\), its total margin is exactly \(2\), because only its own two-ranking gadget contributes a nonzero margin.

Let \(N\) be the smallest power of two satisfying \(N\geq N_0\). Then

\(N_0\leq N<2N_0\).

Both \(N\) and \(N_0\) are even. Pad the multiset to size \(N\) by adding \((N-N_0)/2\) pairs, each consisting of an arbitrary ranking and its reverse. Each such pair contributes zero to every margin.

Give each of the \(N\) occurrences mass \(1/N\). Every arc \(ab\) now has probability margin \(2/N>0\). Hence the resulting majority tournament is exactly \(D\), independently of the priority order.

Finally, merge identical rankings. A ranking occurring \(h\) times receives mass \(h/N\), a positive dyadic number with \(O(\log m)\) bits. Merging preserves all probabilities and leaves at most \(N<2m(m-1)\) supported rankings.

Each ranking uses \(O(m\log m)\) bits, so the complete encoding has length \(O(m^3\log m)\). Constructing and sorting the rankings to merge duplicates takes \(O(m^3(\log m)^2)\) bit operations. This proves the lemma. \(\square\)

Applied independently to \(s\) tournaments, the lemma yields a reduction with

\(\tau=O(sm^2)\), and \(L'=O(sm^3\log m)\),

in time \(O(sm^3(\log m)^2)\). It preserves every tournament exactly, and therefore preserves feasibility, \(k_F\), and \(k_P\) exactly.

Hardness for each restriction

We use the known NP-hardness of Tournament Fixing for perfect binary brackets, recorded in Lemma 6 of the [supplied paper](https://drops.dagstuhl.de/storage/00lipics/lipics-vol321-ipec2024/LIPIcs.IPEC.2024.7/LIPIcs.IPEC.2024.7.pdf). Its model uses a power-of-two number of candidates, as required here.

The restriction \(k_P=0\)

Take a Tournament Fixing instance \((D,\alpha^\star)\). Apply the realization lemma and use its distribution as the only scenario.

Since \(s=1\), no pair differs between scenarios, so \(k_P=0\). The extracted tournament is exactly \(D\), and a seeding is feasible precisely when it makes \(\alpha^\star\) win the original instance.

This is a polynomial-time reduction proving NP-hardness with \(k_P=0\) and \(s=1\).

The restriction \(k_F=0\)

Again take a Tournament Fixing instance \((D,\alpha^\star)\). Choose a strict total order placing \(\alpha^\star\) first, and let \(T\) be the transitive tournament oriented from earlier to later candidates.

Construct two scenarios:

  • A distribution realizing \(D\), supplied by the lemma.
  • The single ranking defining \(T\), with mass \(1\).

In the second scenario, \(\alpha^\star\) beats every other candidate. Thus it wins under every seeding: whenever it participates in a match, it advances.

Consequently, a seeding is feasible in both scenarios exactly when it makes \(\alpha^\star\) win in \(D\).

Moreover,

\(H=(C,E(D)\cap E(T))\)

is a subgraph of the acyclic digraph \(T\). A directed cycle in \(H\) would also be a directed cycle in \(T\), which is impossible. Hence \(H\) is acyclic and \(k_F=0\).

This proves NP-hardness with \(k_F=0\) and \(s=2\). In this reduction, \(\tau=O(m^2)\) and \(L'=O(m^3\log m)\).

Verification and algorithmic bounds

NP membership

A certificate specifies the candidate at each leaf, using \(O(m\log m)\) bits. After extracting the tournaments, check that this assignment is bijective and evaluate the bracket in each scenario. Each scenario requires exactly \(m-1\) matches.

A conservative verification bound is

\(O(B+sm^2)\).

For the restrictions at zero, checking \(k_P=0\) requires comparing orientations, and checking \(k_F=0\) requires testing \(H\) for acyclicity; both fit this bound. Thus both zero-parameter restrictions are NP-complete.

For any other fixed \(c\), membership under \(k_F\leq c\) can additionally be certified by supplying at most \(c\) arcs whose reversal makes \(H\) acyclic. The restriction \(k_P\leq c\) is checked directly. Therefore both restricted problems are NP-complete for every fixed nonnegative \(c\).

FPT in the combined parameter

Theorem 5 of the [supplied paper](https://drops.dagstuhl.de/storage/00lipics/lipics-vol321-ipec2024/LIPIcs.IPEC.2024.7/LIPIcs.IPEC.2024.7.pdf) gives an FPT algorithm for explicitly supplied simultaneous tournaments, parameterized by the feedback arc number of their intersection and the number of differing pairs. These are exactly \(k_F\) and \(k_P\) here; its perfect-bracket hypothesis also matches the task.

Duplicate tournaments may be removed without changing feasibility or either parameter. A distinct tournament is determined by its orientations on the \(k_P\) differing pairs, because every other orientation is common. Thus the number of distinct scenarios is at most

\(\min\{s,2^{k_P}\}\).

Sorting their adjacency encodings removes duplicates in \(O(sm^2\log(s+1))\) time. Applying the cited algorithm afterward gives, for a computable function \(f\) and an absolute constant \(a\),

\(O\!\left(\tau m^2L^2+sm^2\log(s+1)\right)+f(k_F+k_P)m^a\).

In particular, bounding both parameters by constants gives polynomial time. Bounding either parameter alone retains NP-hardness, even at zero.
