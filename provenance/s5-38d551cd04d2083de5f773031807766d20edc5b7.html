The continuous mirror question, as graded

Given a finite set of interaction types \(T\), rational masses \(\mu_i>0\) summing to \(1\), a symmetric nonnegative rational kernel \(K_{ij}\), a rational \(\epsilon>0\), and initial and target opinion-mass distributions \(x^0_{i,a}\) and \(y_{i,a}\) over \(a\in\{0,1,2\}\), decide whether the synchronous process ever reaches \(x^t=y\). Define \(D_i=\sum_j K_{ij}\mu_j\) and \(p_{i,a}(x)=\sum_j K_{ij}x_{j,a}\). Each mass cohort of type \(i\) currently holding opinion \(a\) moves to \(b\), with \(c\) the remaining opinion, if \(p_{i,a}(x)\le D_i/2+\epsilon\), \(p_{i,b}(x)>D_i/2+\epsilon\), and \(p_{i,b}(x)>p_{i,c}(x)\); otherwise it stays at \(a\).

The input also contains a symmetric nonnegative rational matrix \(K\), a rational \(\epsilon>0\), and nonnegative rational arrays \(x^0,y\) satisfying \(\sum_a x^0_{i,a}=\sum_a y_{i,a}=\mu_i\) for every \(i\). All rationals are binary encoded; \(L\) is the total input bit length. Diagonal entries of \(K\) are allowed.
For any state \(x\), define \(D_i=\sum_jK_{ij}\mu_j\) and \(p_{i,a}(x)=\sum_jK_{ij}x_{j,a}\).
At each synchronous step, the entire mass currently at \((i,a)\) moves to opinion \(b\ne a\), with \(c\) the third opinion, exactly when \(p_{i,a}(x)\le D_i/2+\epsilon\), \(p_{i,b}(x)>D_i/2+\epsilon\), and \(p_{i,b}(x)>p_{i,c}(x)\); otherwise it stays. All tests use the preceding state, arriving masses add, and interaction types remain fixed.
Exact reachability asks whether \(x^t=y\) for some integer \(t\ge0\).

Result

Using the published discrete hardness theorem stated in the question, the mass problem is \(\mathrm{PSPACE}\)-complete, and therefore \(\mathrm{NP}\)-hard. The reduction preserves every synchronous step exactly.

For \(\mathrm{m}=3\), exact reachability can be decided in time \(O(3^\tau\tau^2L^2)+\operatorname{poly}(L)\) using polynomial space. Consequently, a polynomial-time algorithm would imply \(\mathrm{P}=\mathrm{PSPACE}\).

1. The discrete theorem being used

Theorem 4 of the cited paper states that exact configuration reachability is \(\mathrm{PSPACE}\)-complete on unsigned, unweighted, undirected graphs for the three-opinion rule in the question, with any fixed positive threshold offset. We use the case where that offset is \(1\). This is a use of the published theorem as a known result; its proof is not reproduced here. [Di Ianni, Theorem 4, p. 17](https://art.torvergata.it/retrieve/05a094ba-49ad-4680-a676-5dd15513b2d1/appliedmath-05-00147-v2.pdf).

More precisely, write \(N_{i,a}(s)\) for the number of neighbors of vertex \(i\) having opinion \(a\) in configuration \(s\), and \(d_i\) for its degree. A vertex currently holding \(a\) changes to \(b\), with \(c\) the third opinion, exactly when

\(\displaystyle N_{i,a}(s)\le d_i/2+1,\qquad N_{i,b}(s)>d_i/2+1,\qquad N_{i,b}(s)>N_{i,c}(s).\)

The theorem concerns reaching a specified configuration under synchronous application of these tests.

2. A polynomial-time reduction to the mass problem

Let a discrete instance consist of a graph \(G\) on \(n\ge1\) vertices, an initial configuration \(s^0\), and a target configuration \(s^\star\).

Construct a mass instance with one interaction type per vertex. Thus \(\tau=n\). Set

\(\displaystyle \mu_i=\frac1n,\qquad \epsilon=1,\qquad K_{ij}=\begin{cases}n,&\{i,j\}\in E(G),\\0,&\text{otherwise}.\end{cases}\)

Define the initial and target arrays by

\(\displaystyle x^0_{i,a}=\frac1n\,\mathbf1_{\{s^0_i=a\}},\qquad y_{i,a}=\frac1n\,\mathbf1_{\{s^\star_i=a\}}.\)

These data satisfy every input requirement: the masses are positive and sum to \(1\); the matrix is symmetric and nonnegative; and each row of each array sums to \(\mu_i\). The construction uses zero diagonal entries, which are permitted.

For any discrete configuration \(s\), denote its encoding by \(X(s)_{i,a}=\frac1n\mathbf1_{\{s_i=a\}}\). Direct calculation gives

\(\displaystyle D_i=\sum_jK_{ij}\mu_j=d_i,\qquad p_{i,a}(X(s))=\sum_jK_{ij}X(s)_{j,a}=N_{i,a}(s).\)

Therefore all three mass tests coincide exactly with the discrete tests.

Each encoded row has mass only at its current opinion. That mass either stays there or moves entirely to the opinion selected by the discrete rule. Hence, if \(F\) and \(f\) are respectively the mass and discrete update maps,

\(\displaystyle F(X(s))=X(f(s)).\)

Induction on \(t\) now proves \(x^t=X(s^t)\) for every \(t\ge0\). Since \(X\) is injective,

\(\displaystyle x^t=y\quad\Longleftrightarrow\quad s^t=s^\star.\)

Thus the reduction preserves exact reachability in both directions.

Every constructed rational has \(O(\log(n+1))\) bits, and the dense output has length \(O(n^2\log(n+1))\). The reduction runs in polynomial time. The discrete theorem therefore establishes \(\mathrm{PSPACE}\)-hardness, already for uniform masses, pure initial and target rows, zero diagonal, and fixed \(\epsilon=1\).

3. A finite-state property of the mass dynamics

The continuous-looking state space does not cause unbounded growth of the reachable rational coordinates.

First, row masses remain \(\mu_i\): each update redistributes mass within its interaction type. Consequently, at every reachable state,

\(\displaystyle p_{i,0}(x)+p_{i,1}(x)+p_{i,2}(x)=D_i.\)

All these pressures are nonnegative.

Suppose an opinion \(b\) satisfies \(p_{i,b}(x)>D_i/2+\epsilon\). For either other opinion \(a\),

\(\displaystyle p_{i,a}(x)\le D_i-p_{i,b}(x)<D_i/2-\epsilon<D_i/2+\epsilon.\)

Also \(p_{i,b}(x)>p_{i,a}(x)\). Thus every mass at either opinion other than \(b\) moves to \(b\). Mass already at \(b\) stays, since no other opinion can exceed the threshold.

Conversely, if no opinion exceeds the threshold, no mass moves.

We have proved that each row update is either the identity or replacement by \(\mu_i e_b\), where \(e_b\) is the unit vector for opinion \(b\). Therefore:

  • A mixed row remains equal to its initial row until it first becomes pure.
  • Once a row becomes pure, it remains pure forever.

In particular, every reachable row belongs to the set \(\{x_i^0,\mu_i e_0,\mu_i e_1,\mu_i e_2\}\). This establishes a finite reachable state space without discretizing the rational masses.

4. State count and exact simulation

A slightly sharper count yields the stated running time.

Let \(k(t)\) be the number of pure rows at time \(t\). It is nondecreasing. During any interval on which \(k(t)=k\), the set of pure rows is fixed: pure rows cannot become mixed, and introducing another pure row would increase \(k\).

On that interval, every mixed row equals its initial row, while each of the \(k\) pure rows has one of three opinions. There are therefore at most \(3^k\) distinct states on the interval.

Each value of \(k\) occurs in at most one interval. Hence the total number of distinct states on the trajectory is at most

\(\displaystyle B=\sum_{k=0}^{\tau}3^k=\frac{3^{\tau+1}-1}{2}.\)

It suffices to inspect \(x^0,\ldots,x^{B-1}\). If the target has not appeared, the trajectory must repeat a state by time \(B\); determinism then prevents any subsequently new state.

For exact arithmetic, let \(Q\) be the product of the denominators of all input rationals. Its bit length is \(O(L)\). Write \(K'_{ij}=QK_{ij}\), \(\mu'_j=Q\mu_j\), \(z_{j,a}=Qx_{j,a}\), and \(e'=Q\epsilon\). Every reachable \(z_{j,a}\) is either an initial scaled coordinate, zero, or \(\mu'_j\).

The strict threshold test becomes the integer comparison

\(\displaystyle 2\sum_jK'_{ij}z_{j,a}>\sum_jK'_{ij}\mu'_j+2Qe'.\)

All integers involved have \(O(L)\) bits. The other comparisons and target equality are likewise exact integer comparisons.

Using schoolbook arithmetic, one synchronous step costs \(O(m\tau^2L^2)\) bit operations. For the stipulated \(m=3\), simulation therefore takes \(O(3^\tau\tau^2L^2)+\operatorname{poly}(L)\) time.

For the natural absolute-majority extension to \(m\ge2\) opinions, the same argument gives at most \((m^{\tau+1}-1)/(m-1)\) distinct states and running time

\(\displaystyle O\!\left(\frac{m^{\tau+1}-1}{m-1}\,m\tau^2L^2\right)+\operatorname{poly}(L).\)

A simulation stores only the current row descriptions, the next row descriptions, an \(O(\tau\log m)\)-bit counter, and polynomial-size arithmetic workspace. Thus the stated problem belongs to \(\mathrm{PSPACE}\).

5. Conclusion

The exact trajectory-preserving reduction proves \(\mathrm{PSPACE}\)-hardness, and the finite-state simulation proves membership in \(\mathrm{PSPACE}\). Together they settle the mass problem as \(\mathrm{PSPACE}\)-complete, using the discrete theorem supplied in the question.
