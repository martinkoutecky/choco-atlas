The continuous mirror question, as graded

Given a catalog \(J=[m]\), rational type masses \(\mu_t\) with \(\sum_t\mu_t=1\), rational per-capita item supplies \(b_j\), and explicit monotone submodular valuations \(u_t:2^{R_t}\to\mathbb{Q}_{\ge0}\) with \(|R_t|\le15\), find an allocation maximizing total welfare. Represent it by masses \(x_{t,S}\ge0\) assigned to integral bundles \(S\subseteq R_t\), subject to \(\sum_{S\subseteq R_t}x_{t,S}=\mu_t\) for every type \(t\) and \(\sum_{t,S:\,j\in S}x_{t,S}\le b_j\) for every item \(j\); maximize \(\sum_{t,S}x_{t,S}u_t(S)\).

Packaged proof task (what the prover saw — nothing else)

Given a catalog \(J=[m]\), a society is given by its support: a list of \(\tau\) types with positive binary-rational masses \(\mu_t\), where \(\sum_t\mu_t=1\). Here \(\tau\) is the support size, not the number of possible types.
Each type has a relevant set \(R_t\subseteq J\), with \(|R_t|\le15\), and a monotone submodular valuation \(u_t:2^{R_t}\to\mathbb{Q}_{\ge0}\), given by its complete value table. Items outside \(R_t\) have zero marginal value; no normalization of \(u_t(\varnothing)\) is required.
Each item has a binary-rational per-capita supply \(b_j\ge0\). An allocation consists of real masses \(x_{t,S}\ge0\) for integral bundles \(S\subseteq R_t\), satisfying \(\sum_{S\subseteq R_t}x_{t,S}=\mu_t\) and \(\sum_{t,S:\,j\in S}x_{t,S}\le b_j\).
Its welfare is \(W(x)=\sum_{t,S}x_{t,S}u_t(S)\); let \(\mathrm{OPT}\) be the maximum feasible welfare. Let \(L\) be the total input bit length. State running times in \(m,\tau,L\) and the approximation parameter \(\varepsilon\).

Does this continuous welfare problem admit a PTAS, polynomial in \(m,\tau,L\) for every fixed \(\varepsilon>0\), or is it NP-hard to achieve an approximation ratio better than some constant \(\rho\in(0,1)\)?

For finite players receiving disjoint integral bundles, welfare maximization is APX-hard even with explicit monotone submodular valuations depending on at most \(15\) items per player: some constant \(\rho<1\) bounds polynomial-time approximation unless \(\mathrm{P}=\mathrm{NP}\). [Feige and Vondrák](https://theoryofcomputing.org/articles/v006a011/)

Modeling choices made when packaging the task

  • Explicit valuations mean complete tables containing every subset value.
  • Supplies are nonnegative binary rationals, with no upper bound imposed.
  • Allocation masses are real and may split a type among different integral bundles.
  • Items outside a type's relevant set have zero marginal value.
  • No empty-bundle normalization is imposed because the discrete valuation domain does not require one.

Result

The continuous welfare problem is exactly solvable in polynomial time. Consequently, it admits a PTAS, with running time independent of the approximation parameter \(\varepsilon\).

The decisive feature is that masses may be split among bundles. The complete valuation tables therefore describe a linear program of polynomial size.

1. Explicit linear program

For each type \(t\), write \(r_t=|R_t|\). Introduce one variable \(x_{t,S}\) for every \(S\subseteq R_t\). The total number of variables is

\(N=\sum_{t=1}^{\tau}2^{r_t}\le 2^{15}\tau.\)

Consider the following rational linear program:

  • Maximize \(\displaystyle \sum_{t=1}^{\tau}\sum_{S\subseteq R_t}u_t(S)x_{t,S}\).
  • For every type \(t\), impose \(\displaystyle \sum_{S\subseteq R_t}x_{t,S}=\mu_t\).
  • For every item \(j\in J\), impose \(\displaystyle \sum_{t=1}^{\tau}\sum_{\substack{S\subseteq R_t\\j\in S}}x_{t,S}\le b_j\).
  • Impose \(x_{t,S}\ge0\) for every variable.

Every coefficient is available explicitly: objective coefficients come from the supplied tables, constraint coefficients are zero or one, and right-hand sides are the given masses and supplies.

By the definition of an allocation in the question, the feasible points of this linear program are exactly the admissible allocations. Its objective is exactly their welfare. Thus its optimal value equals \(\mathrm{OPT}\); no relaxation or rounding occurs.

2. Feasibility, boundedness, and exact computation

The linear program is feasible. Indeed, assigning \(x_{t,\varnothing}=\mu_t\) for every type and setting all other variables to zero satisfies every type constraint and consumes no supply.

For every feasible allocation, nonnegativity and the type constraint imply

\(0\le x_{t,S}\le\mu_t.\)

Hence the feasible region is bounded. It is also closed, since it is defined by finitely many linear equalities and inequalities. Therefore it is compact. The linear objective is continuous, so it attains a finite maximum.

We use the standard polynomial-time theorem for rational linear programming: a linear program with explicitly encoded rational coefficients can be solved in time polynomial in its total binary encoding length; when a finite optimum exists, an exact rational optimal solution can be returned.

All hypotheses hold here: the program is finite and explicitly represented, its coefficients are rational, and it is feasible with a finite attained optimum. The fact that the allocation definition permits real masses does not obstruct exact computation: rational linear programming supplies a rational optimizer.

No normalization is needed. In particular, the values \(u_t(\varnothing)\) are included directly in the objective. Monotonicity and submodularity are also unnecessary for this algorithm.

3. Running time and output size

Add one nonnegative slack variable for each supply constraint. The resulting standard-form program has \(m+\tau\) equality constraints and \(N+m\) variables. Its dense binary encoding has length at most

\(B=O\!\left(L+(m+\tau)(N+m)\right).\)

Here the original rational coefficients contribute \(O(L)\) bits, while the additional matrix entries and slack coefficients are zero or one. Using \(N\le2^{15}\tau\), an exact algorithm therefore runs in time

\(\left(L+(m+\tau)(m+2^{15}\tau)\right)^{O(1)}.\)

This is polynomial in \(m,\tau,L\), with a universal exponent. It has no dependence on \(\varepsilon\).

An optimal allocation can additionally be chosen with at most \(m+\tau\) positive bundle masses. To verify this, the standard-form feasible region is compact: the original variables are bounded as above, and each slack lies between zero and its supply. The optimal face therefore has an extreme point. At any extreme point, columns corresponding to positive variables must be linearly independent. Otherwise, a nonzero dependence would allow sufficiently small perturbations in both directions that preserve equality constraints and nonnegativity, contradicting extremality. There are only \(m+\tau\) rows, so at most \(m+\tau\) standard-form variables—and hence at most that many bundle masses—can be positive.

For every \(0<\varepsilon<1\), the exact solution satisfies

\(W(x)=\mathrm{OPT}\ge(1-\varepsilon)\mathrm{OPT}.\)

Thus the same algorithm is a PTAS, and indeed an exact polynomial-time algorithm.

4. Why finite-player hardness does not transfer

The cited [Feige–Vondrák result](https://theoryofcomputing.org/articles/v006a011/) concerns finite players receiving disjoint integral bundles. That requirement differs from the mass-splitting feasibility conditions here.

To make the distinction precise, take a finite instance with \(n\) players and represent each player as a type of mass \(1/n\), with supply \(b_j=1/n\) for each item. Every disjoint finite allocation \((S_1,\ldots,S_n)\) induces a feasible continuous allocation by assigning mass \(1/n\) to bundle \(S_i\) for type \(i\). Its continuous welfare equals the finite welfare divided by \(n\).

The continuous program, however, also permits each type to split its mass among several bundles, subject to aggregate supply constraints. Consequently, this construction only proves

\(\mathrm{OPT}_{\mathrm{continuous}}\ge \mathrm{OPT}_{\mathrm{finite}}/n.\)

It does not turn a continuous optimizer into a disjoint finite allocation. The finite-player hardness theorem therefore does not contradict the exact linear-programming algorithm established above.
