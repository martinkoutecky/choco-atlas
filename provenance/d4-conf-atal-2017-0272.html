The continuous mirror question, as graded

Given a finite variable set \(V\), a goalbase \(G^0\), and an explicitly listed profile \((I,x_I)\) of Boolean interpretations \(I\in\{0,1\}^V\) with positive rational masses \(x_I\) summing to \(1\), decide whether every interpretation with positive mass maximizes \(G^0\)'s utility over all interpretations in \(\{0,1\}^V\).

Packaged proof task (what the prover saw — nothing else)

Let \(V\) be a finite set of \(m\) Boolean variables. A goalbase \(G^0\) is a finite set of pairs \((\varphi,w)\), where \(\varphi\) is an explicitly encoded propositional formula over \(V\) and \(w\) is a signed binary rational. Define \(U(I)=\sum_{(\varphi,w)\in G^0:I\models\varphi}w\).
A society is given by its support: a nonempty list of \(\tau\) distinct interpretations \(I\in\{0,1\}^V\), each with positive binary rational mass \(x_I\), with \(\sum_I x_I=1\). Here \(\tau\) is the support size, not the number of possible interpretations. Let \(L\) be the total input bit length; state running times in \(m,\tau,L\).
The decision problem asks whether \(U(I)\ge U(J)\) for every listed \(I\) and every \(J\in\{0,1\}^V\); tied maximizers are permitted.

Is this decision problem solvable in polynomial time in \(m,\tau,L\), or is it NP-hard?

For finite societies, checking Nash stability is coNP-complete, even with one autonomous agent whose utility is given by a goalbase. Autonomous agents may choose any interpretation over their variables.

Modeling choices made when packaging the task

  • Specified goalbases as explicitly encoded propositional formulas with signed binary rational weights, following the discrete utility definition.
  • Specified that ties among utility maximizers are accepted, following weak best-response inequalities.
  • Defined m as the variable count and L as the total input bit length.

Classification

The problem is coNP-complete under polynomial-time many-one reductions, even when \(\tau=1\) and the goalbase contains a single formula of weight \(1\).

Consequently, it is polynomial-time solvable if and only if \(\mathrm{P}=\mathrm{NP}\). The distinction in the question matters: under many-one reductions, calling this problem NP-hard would be equivalent to asserting \(\mathrm{NP}=\mathrm{coNP}\). Under polynomial-time Turing reductions, it is NP-hard.

1. Exact utility comparisons take polynomial time

Write the goalbase weights as \(w_i=a_i/b_i\), with integers \(a_i\) and positive integers \(b_i\). Define

\[ D=\prod_i b_i, \qquad c_i=a_i(D/b_i). \]

For an empty goalbase, take \(D=1\). Since the total encoding length is \(L\), the integers \(D\), \(c_i\), and every sum of the \(c_i\) have \(O(L)\) bits. In particular,

\[ D\,U(K)=\sum_{i:K\models\varphi_i}c_i \]

is an integer of polynomial bit length. Because \(D>0\), comparing these integers gives exact utility comparisons.

Using elementary integer arithmetic, computing all \(c_i\) takes \(O(L^3)\) bit operations. Evaluating all formulas at one interpretation and summing the corresponding integers takes at most \(O((m+L)^2)\) bit operations; this conservative bound also allows direct lookup of variable values.

The society’s masses do not affect the decision: only its listed interpretations matter.

2. Membership in coNP

Let \(S\) be the nonempty listed support, and define

\[ u_{\min}=\min_{I\in S}U(I). \]

The required condition is equivalent to

\[ U(J)\le u_{\min} \quad\text{for every }J\in\{0,1\}^{V}. \]

Indeed, this condition implies \(U(J)\le U(I)\) for every listed \(I\). Conversely, the original condition applies to an interpretation attaining \(u_{\min}\).

Thus a certificate for a no instance consists of an interpretation \(J\) satisfying

\[ U(J)>u_{\min}. \]

The certificate has \(m\) bits. A verifier computes the listed utilities, their minimum, and \(U(J)\), using exact arithmetic as above. Its running time is

\[ O\!\left(L^3+(\tau+1)(m+L)^2\right). \]

Therefore the complement belongs to NP, and the stated problem belongs to coNP. The strict inequality in the certificate correctly accounts for the permission to have tied maximizers.

3. coNP-hardness with singleton support

We reduce propositional UNSAT, which is coNP-complete under polynomial-time many-one reductions.

Let \(F\) be an arbitrary propositional formula over variables \(X\). Introduce a fresh Boolean variable \(q\), and construct

\[ V=X\cup\{q\}, \qquad G^0=\{(q\land F,1)\}. \]

The society has a single listed interpretation \(I_0\), assigning every variable the value \(0\), with mass \(x_{I_0}=1\). This is a valid society, and the construction has polynomial size.

Since \(I_0(q)=0\),

\[ U(I_0)=0. \]

We check both cases.

  • If \(F\) is unsatisfiable, then \(q\land F\) is false at every interpretation \(J\). Hence \(U(J)=0=U(I_0)\) for every \(J\), so the constructed instance is a yes instance.
  • If \(F\) is satisfiable, choose a satisfying assignment of \(X\) and extend it by setting \(q=1\). The resulting interpretation \(J\) satisfies \(q\land F\), so

\[ U(J)=1>0=U(I_0). \]
Therefore the constructed instance is a no instance.

Consequently,

\[ F\in\mathrm{UNSAT} \quad\Longleftrightarrow\quad \text{the constructed instance satisfies the required condition}. \]

This proves coNP-hardness. Together with membership, it proves coNP-completeness.

4. What this means for the proposed alternatives

Let \(\mathcal D\) denote the decision problem.

Polynomial time. If \(\mathcal D\in\mathrm P\), the reduction above puts UNSAT, and therefore SAT, in \(\mathrm P\). Since SAT is NP-complete, \(\mathrm P=\mathrm{NP}\). Conversely, if \(\mathrm P=\mathrm{NP}\), closure of \(\mathrm P\) under complement gives \(\mathrm{coNP}=\mathrm P\), so \(\mathcal D\in\mathrm P\).

Many-one NP-hardness. If \(\mathcal D\) were NP-hard under polynomial-time many-one reductions, its membership in coNP would imply \(\mathrm{NP}\subseteq\mathrm{coNP}\): coNP is closed under polynomial-time preimages. Taking complements then gives the reverse inclusion. Conversely, if \(\mathrm{NP}=\mathrm{coNP}\), coNP-hardness immediately implies NP-hardness. Hence

\[ \mathcal D\text{ is many-one NP-hard} \quad\Longleftrightarrow\quad \mathrm{NP}=\mathrm{coNP}. \]

Turing NP-hardness. A SAT instance can be decided by constructing the instance above, making one query to \(\mathcal D\), and negating the answer. Thus \(\mathcal D\) is NP-hard under polynomial-time Turing reductions.

An unconditional deterministic upper bound, obtained by enumerating all interpretations, is

\[ O\!\left(L^3+(\tau+2^m)(m+L)^2\right). \]

The hardness already holds for \(\tau=1\); a small explicitly listed support therefore does not remove the difficulty of comparison against all possible interpretations.

Summing any subset of the coefficients adds at most a logarithmic factor in the number of goals to the bit length, which remains \(O(L)\). Signed weights cause no difficulty.
