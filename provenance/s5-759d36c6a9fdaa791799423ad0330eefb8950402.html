The continuous mirror question, as graded

Given buyer types \(B\) and supplier types \(S\), with rational masses \(\mu\), per-agent demands \(d_b\), willingness-to-pay values \(v_b\), capacities \(q_s\), asks \(a_s\), and eligible routes with costs \(w_{bs}\), compute an allocation \(x_{bs}\ge 0\) maximizing \(\sum_{b\in B,s\in S}(v_b-a_s-w_{bs})x_{bs}\), subject to \(\sum_s x_{bs}\le \mu_b d_b\) and \(\sum_b x_{bs}\le \mu_s q_s\), and return supporting equilibrium prices or dual values. The question is whether this mass allocation and its supporting prices can be computed for resource-pooling supply auctions over a society represented by distributions of firm types.

A society is given by its support: the list of the \(\tau\) types with positive mass, each mass a binary rational. Here \(\tau\) is the support size, not the number of possible types; take \(\sum_{t\in B\cup S}\mu_t=1\).

Conclusion

An exact maximizing allocation and optimal supporting dual values can be computed in polynomial time in \(m,n,\tau,|E|,L\).

The relevant formulation is an explicitly represented rational linear program. The binary encoding of masses does not require expanding types into individual agents.

1. The allocation linear program

Define the aggregate buyer demands, supplier capacities, and route surpluses by
\( D_b=\mu_bd_b,\qquad Q_s=\mu_sq_s,\qquad c_{bs}=v_b-a_s-w_{bs}. \)
The assumptions imply that \(D_b,Q_s\) are positive rationals and \(c_{bs}\) are rational, possibly negative.

Write \(k=|E|\). The allocation problem is precisely the linear program

\( \displaystyle \begin{aligned} (P)\qquad \max\quad &\sum_{(b,s)\in E}c_{bs}x_{bs}\\ \text{subject to}\quad &\sum_{s:(b,s)\in E}x_{bs}\le D_b &&(b\in B),\\ &\sum_{b:(b,s)\in E}x_{bs}\le Q_s &&(s\in S),\\ &x_{bs}\ge 0 &&((b,s)\in E). \end{aligned} \)

There are \(k\) variables and \(\tau\) capacity inequalities, besides nonnegativity constraints.

This program is feasible because the zero allocation is feasible. Moreover, every feasible allocation satisfies
\( 0\le x_{bs}\le \min\{D_b,Q_s\}. \)
Thus its feasible set is closed and bounded. Consequently, the continuous linear objective attains a finite maximum.

If \(E\) is empty, the empty allocation and zero supporting values already solve the problem. The argument below also covers this case.

2. The supporting dual values

Associate nonnegative multipliers \(\alpha_b\) and \(\beta_s\) with the buyer and supplier capacity inequalities, respectively. The dual program is

\( \displaystyle \begin{aligned} (D)\qquad \min\quad &\sum_{b\in B}D_b\alpha_b+\sum_{s\in S}Q_s\beta_s\\ \text{subject to}\quad &\alpha_b+\beta_s\ge c_{bs} &&((b,s)\in E),\\ &\alpha_b\ge0 &&(b\in B),\\ &\beta_s\ge0 &&(s\in S). \end{aligned} \)

To verify this formulation, the Lagrangian for nonnegative \(x\) is

\( \displaystyle \sum_bD_b\alpha_b+\sum_sQ_s\beta_s +\sum_{(b,s)\in E}(c_{bs}-\alpha_b-\beta_s)x_{bs}. \)

Its supremum over nonnegative \(x\) is finite exactly when every coefficient in the last sum is nonpositive. These are precisely the displayed dual route constraints.

Set
\( C=\max\bigl(\{0\}\cup\{c_{bs}:(b,s)\in E\}\bigr). \)
The choice \(\alpha_b=C,\ \beta_s=0\) is dual feasible, since every \(c_{bs}\le C\).

We use the strong duality theorem for finite-dimensional linear programming: if a primal linear program is feasible and has a finite optimal value, its dual attains the same optimal value. The preceding section verifies both hypotheses. Hence optimal supporting dual values exist.

For completeness, the dual may also be restricted to a bounded feasible set without changing its optimum. Given any dual feasible pair, replace each coordinate \(y\) by \(\min\{y,C\}\). For each route:

  • If neither endpoint coordinate exceeds \(C\), its constraint is unchanged.
  • If an endpoint coordinate exceeds \(C\), its clipped value is \(C\); the other clipped coordinate is nonnegative, so their sum remains at least \(C\ge c_{bs}\).

Clipping therefore preserves feasibility and cannot increase the objective. Applying it to an optimal dual solution shows that an optimum exists with every coordinate in \([0,C]\).

3. Exact polynomial-time computation

We invoke the standard rational linear programming theorem: an explicitly represented linear program with binary rational coefficients can be solved in deterministic polynomial bit time; when it has an optimum, an exact rational optimal solution can be returned. This is the classical polynomial-time solvability result for rational linear programming, discussed in [Adler and Beling’s paper](https://adler.ieor.berkeley.edu/ilans_pubs/lp_algebraic_stoc_1992.pdf).

Its hypotheses hold here:

  • Explicit representation. The input lists all \(\tau\) supported types and all \(k\) eligible routes. Neither program requires enumerating any other types or routes.
  • Polynomial dimensions. The primal has \(k\) variables and \(\tau\) capacity inequalities. The dual has \(\tau\) variables and \(k\) route inequalities. Adding the dual bounds from the preceding section adds only \(\tau\) inequalities.
  • Polynomial coefficient encoding. Each \(D_b\) or \(Q_s\) is obtained by multiplying two input rationals; each \(c_{bs}\) is obtained by subtracting three input rationals. Multiplication adds the bit lengths of numerators and denominators, while these fixed-size sums can use the product of the input denominators. Hence every derived coefficient has bit length \(O(L)\), and all coefficients can be computed exactly in polynomial time. Computing \(C\) also takes polynomial time by rational comparisons. Even a dense representation of the two programs has polynomial total encoding length in \(\tau,k,L\).
  • Attained finite optima. These were established above for both programs.

The algorithm is therefore to construct the two rational programs and solve each exactly. Strong duality ensures that the returned allocation and supporting values have equal objective values. Their running time, including writing their exact rational outputs, is polynomial in \(\tau,k,L\), and thus in all the parameters requested.

No assumption that masses or capacities are integers is needed.

4. A verifiable optimality certificate

The returned answers admit a direct exact check. For any primal feasible \(x\) and dual feasible \((\alpha,\beta)\), the dual objective minus the primal objective equals

\( \displaystyle \begin{aligned} &\sum_b\alpha_b\left(D_b-\sum_{s:(b,s)\in E}x_{bs}\right)\\ &\quad+\sum_s\beta_s\left(Q_s-\sum_{b:(b,s)\in E}x_{bs}\right)\\ &\quad+\sum_{(b,s)\in E}(\alpha_b+\beta_s-c_{bs})x_{bs}. \end{aligned} \)

Every summand is nonnegative by feasibility. Thus equality of the two objective values certifies that both solutions are optimal. Feasibility and equality can be checked using exact rational arithmetic in polynomial time.

5. Relation to the cited existence result

Chen, Wang, and Lan’s supply-pooling equilibrium result appears as Theorem 3 of the [cited paper](https://pdfs.semanticscholar.org/c107/802ea38e614e7509991feb41e90b464d450a.pdf). The complexity conclusion here follows independently from the specified allocation linear program and its capacity dual. In particular, the task supplies the final effective bids and requests any optimum of these programs.

This completely settles the stated computation as polynomial-time solvable. An NP-hardness classification under the usual polynomial-time reductions would therefore imply \(\mathrm{P}=\mathrm{NP}\).
