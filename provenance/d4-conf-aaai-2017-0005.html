The continuous mirror question, as graded

Given a fixed finite set of complete types \(\Theta\), a rational distribution \(\mu\) over those types, directed compatibility \(f\), rational switching costs \(c\), and fixed cycle cap \(L\), choose transfer masses \(y_{\theta\phi}\) and masses \(x_w\) assigned to compatible cycle templates \(w\) of lengths at most \(L\). Transfers must respect the available mass of each source type, and cycle allocations must respect the resulting mass of each type. Maximize the matched fraction \(\sum_w |w|x_w\) minus per-capita switching cost \(\sum_{\theta\ne\phi}c(\theta,\phi)y_{\theta\phi}\).

Packaged proof task (what the prover saw — nothing else)

Fix a nonempty finite universe \(\Theta\) of complete patient–donor types, with \(m=|\Theta|\), and a constant cycle cap \(K\ge 2\); both \(m\) and \(K\) are constants.
A society is given by its support: the list of the \(\tau\) types with positive mass, each mass a binary rational. Here \(\tau\) is the support size, not the number of possible types. Masses sum to \(1\); unlisted types in \(\Theta\) have mass zero but remain available switching destinations.
Input also includes an explicit directed compatibility table \(f:\Theta\times\Theta\to\{0,1\}\), binary rational switching costs \(c(\theta,\phi)\in\mathbb Q\) for distinct types, and a binary rational threshold \(b\). Costs may have either sign; retaining one's type costs zero.
Choose divisible transfer masses \(y_{\theta\phi}\ge0\) for \(\theta\ne\phi\), with \(\sum_{\phi\ne\theta}y_{\theta\phi}\le\mu_\theta\). Each portion switches at most once, directly from its original type; switched mass may remain unmatched.
The resulting mass is \(q_\theta=\mu_\theta-\sum_{\phi\ne\theta}y_{\theta\phi}+\sum_{\phi\ne\theta}y_{\phi\theta}\).
A cycle template is an ordered tuple \(w=(\theta_1,\ldots,\theta_\ell)\), where \(2\le\ell\le K\), \(f(\theta_i,\theta_{i+1})=1\), and \(\theta_{\ell+1}=\theta_1\). Types may repeat; positions represent distinct participants, so diagonal compatibility permits exchanges between distinct participants of the same type, never singleton cycles.
Write \(a_\theta(w)\) for the number of occurrences of \(\theta\) in \(w\). Choose divisible cycle masses \(x_w\ge0\) satisfying \(\sum_w a_\theta(w)x_w\le q_\theta\) for every type.
Decide whether \(\sum_w |w|x_w-\sum_{\theta\ne\phi}c(\theta,\phi)y_{\theta\phi}\ge b\) is achievable. Let \(L\) be the total input bit length; state running times in \(m,\tau,L,K\).

Is this continuous flip-and-cycle-cover decision problem in \(\mathrm P\), or is it \(\mathrm{NP}\)-hard, with \(m\) and \(K\) fixed?

The discrete flip-and-cycle-cover problem is polynomial-time solvable when the type-universe size and cycle cap are constants ([source](https://www.cs.cmu.edu/~sandholm/www/bitwise.aaai2017_full.pdf)).
No result settling this exact continuous problem was identified in the literature search.

Modeling choices made when packaging the task

  • Preserved the fixed type universe and fixed cycle cap; distinguished universe size m from initial support size tau.
  • Normalized initial mass to one and allowed initially absent types as switching destinations.
  • Used explicit compatibility and cost tables; allowed signed rational costs, following the discrete cost domain of real numbers.
  • Specified direct, single switching from original mass, with all switching charged even when switched mass remains unmatched.
  • Restricted cycle lengths to at least two, allowed repeated types, and counted every occurrence against resulting type mass.
  • Used nonnegative divisible real allocation variables and allowed unused mass.
  • Added a rational objective threshold to define the decision problem; renamed the cycle cap K so L denotes input bit length.

Prover output (gpt-6.1-sol / high, Bolzano prover prompt)

Continuous flip-and-cycle-cover is polynomial-time solvable

Theorem. The stated decision problem belongs to \(\mathrm{P}\) when \(m\) and \(K\) are fixed. In fact, it remains polynomial-time solvable for every fixed \(K\) when \(m\) varies and the compatibility and cost tables are explicit.

1. Enumerating cycle templates

Let \(S=\{\theta\in\Theta:\mu_\theta>0\}\), so \(|S|=\tau\). Set \(\mu_\theta=0\) for every unlisted type.

Let \(\mathcal W\) contain exactly the ordered tuples permitted in the question. Write \(T=|\mathcal W|\), and define

\(\displaystyle H(m,K)=\sum_{\ell=2}^{K}m^\ell.\)

Enumerate every tuple of each length and check its cyclic compatibility conditions. This requires \(O(KH(m,K))\) table lookups, and

\(\displaystyle T\le H(m,K)\le(K-1)m^K.\)

This enumeration includes repeated types and checks diagonal compatibility when successive positions have the same type. It excludes singleton cycles. We do not truncate lengths at \(m\), because types may repeat.

All types in \(\Theta\) participate in this enumeration, including types outside \(S\).

2. An exact linear formulation

If \(\theta\notin S\), the original outgoing-transfer constraint and nonnegativity imply

\(\displaystyle 0\le\sum_{\phi\ne\theta}y_{\theta\phi}\le\mu_\theta=0.\)

Thus every transfer originating outside \(S\) is zero. We may omit those variables while retaining every type as a destination.

Introduce variables \(y_{\theta\phi}\ge0\) for \(\theta\in S\), \(\phi\in\Theta\setminus\{\theta\}\), and \(x_w\ge0\) for \(w\in\mathcal W\). Consider the following rational linear feasibility problem.

For every \(\theta\in S\), impose the original-mass constraint

\(\displaystyle \sum_{\phi\ne\theta}y_{\theta\phi}\le\mu_\theta.\)

For every \(\theta\in\Theta\), impose the cycle-capacity constraint

\(\displaystyle \sum_{w\in\mathcal W}a_\theta(w)x_w +\sum_{\phi\ne\theta}y_{\theta\phi} -\sum_{\substack{\phi\in S\\\phi\ne\theta}}y_{\phi\theta} \le\mu_\theta,\)

where an outgoing sum for \(\theta\notin S\) is defined to be zero.

Finally, impose the threshold constraint

\(\displaystyle -\sum_{w\in\mathcal W}|w|x_w +\sum_{\theta\in S}\sum_{\phi\ne\theta}c(\theta,\phi)y_{\theta\phi} \le-b.\)

Every coefficient is rational. The multiplicities and cycle lengths are integers at most \(K\).

Proof of equivalence

Suppose an admissible switching and cycle plan achieves the threshold. Its transfers from unsupported origins are zero, as proved above. For each type, substituting

\(\displaystyle q_\theta=\mu_\theta-\sum_{\phi\ne\theta}y_{\theta\phi} +\sum_{\substack{\phi\in S\\\phi\ne\theta}}y_{\phi\theta}\)

into \(\sum_w a_\theta(w)x_w\le q_\theta\) and rearranging gives precisely the displayed cycle-capacity inequality. Negating the objective threshold gives the final inequality. Hence the linear system is feasible.

Conversely, suppose the linear system is feasible. Extend its transfers by zero for all unsupported origins. The outgoing constraints allow the original mass of each supported type to be divided into the specified direct transfers and its retained remainder. Because outgoing transfers are bounded by \(\mu_\theta\), rather than by \(q_\theta\), received mass supplies no additional switching capacity.

The resulting masses are nonnegative: each is a nonnegative retained remainder plus incoming mass. Rearranging the cycle-capacity inequalities gives exactly \(\sum_w a_\theta(w)x_w\le q_\theta\). Thus the cycle masses satisfy the model’s capacity requirements. The last inequality gives the required objective value.

Therefore the decision problem is exactly equivalent to this rational linear feasibility problem.

3. Negative costs and exact thresholds

The feasible set before adding the threshold inequality is nonempty: choose all transfers and cycle masses to be zero.

It is also bounded. Summing the outgoing constraints gives

\(\displaystyle \sum_{\theta\in S}\sum_{\phi\ne\theta}y_{\theta\phi}\le1.\)

Transfers preserve total mass, since each transfer appears once positively and once negatively in the sum defining \(q\). Consequently,

\(\displaystyle \sum_{\theta\in\Theta}q_\theta=1.\)

Summing cycle capacities and using \(\sum_\theta a_\theta(w)=|w|\) gives

\(\displaystyle \sum_{w\in\mathcal W}|w|x_w\le1.\)

Since every cycle has length at least two, \(\sum_w x_w\le1/2\). All variables are therefore bounded. The feasible set is closed, so it is compact, and the linear objective attains its maximum. Arbitrary signs of the finite rational costs do not change these conclusions.

For the algorithm, we use the standard rational linear-programming theorem: feasibility of a finite system of non-strict linear inequalities with binary rational coefficients is decidable exactly in time polynomial in its total encoding length. This theorem concerns feasibility over the reals and includes equality at the threshold; no numerical tolerance is required. See [Khachiyan, “A polynomial algorithm in linear programming”](https://www.mathnet.ru/eng/dan42319).

Its hypotheses hold here: the system is finite, all coefficients are explicitly encoded rationals, and all constraints are non-strict linear inequalities.

4. Bit complexity and conclusion

The formulation has

\(\displaystyle d=T+\tau(m-1)\)

nonnegative variables and

\(\displaystyle r=m+\tau+1\)

additional inequalities.

Using a dense encoding with nonnegativity specified as variable bounds, its total encoding length \(B\) satisfies

\(\displaystyle B=O\!\left(L+(r+1)(d+1)\log(K+2)\right).\)

Indeed, the input rational masses occur at most twice, each retained cost occurs once, and the remaining coefficients are zero or integers of magnitude at most \(K\). Thus their rational encodings contribute \(O(L)\), while the dense coefficient layout contributes the second term.

Including input processing, template enumeration, formulation construction, and exact linear feasibility, a running-time bound is

\(\displaystyle O\!\left(L+KH(m,K)+B\right)+\operatorname{poly}(B),\)

where one may substitute

\(\displaystyle B=O\!\left(L+(m+\tau+2)\bigl(H(m,K)+\tau(m-1)+1\bigr)\log(K+2)\right).\)

For fixed \(m\) and \(K\), we have \(\tau\le m\), so \(B=O(L+1)\) and the running time is polynomial in \(L\).

More generally, for fixed \(K\), \(H(m,K)=O(m^K)\), so the bound is polynomial in \(m,\tau,L\). Because the tables are explicit, this also gives polynomial time in the total input length.

Hence the target problem is in \(\mathrm{P}\). Under polynomial-time many-one reductions, an \(\mathrm{NP}\)-hardness result for it would imply \(\mathrm{P}=\mathrm{NP}\).
