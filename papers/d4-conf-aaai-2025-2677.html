The continuous mirror question

Given discrete update periods, a finite type set \(A\), rational type masses \(\mu_a^r\), finite-support contact laws, and a hyperparameter set \(\Theta\) with transmission function \(H\), each period generates a multitype configuration-model network. For a population-fraction budget \(\kappa\), compute feasible seed masses \(z_a^r\) with \(0\le z_a^r\le\mu_a^r\) and \(\sum_a z_a^r\le\kappa\) that maximize the worst-case limiting expected activated fraction \(\min_{\theta\in\Theta}\Phi_{\theta,r}(z^r)\); determine whether an additive-\(\varepsilon\) approximation can be maintained with useful amortized update time in the type and model parameters.

The model it lives in

A society is a distribution \(\mu^r\) over types that include node features and contact roles, with finite-support contact laws specifying the evolving network model. Decisions are seed masses \(z_a^r\), the budget scales with population mass, and the objective is the worst-case limiting expected fraction activated under the IC cascade across \(\theta\in\Theta\).

The objection that survived

The mirror averages over configuration-model network realizations and updates population-level contact laws, whereas the paper optimizes on a given graph through individual node and edge edits; the proponent acknowledges the topology restriction but does not address this additional source of randomness.

fatal: False

What the mirror covers

The mirror covers Theorem 1's approximation guarantee and amortized update problem in the specified exchangeable-network regime. It leaves the paper's guarantees for arbitrary realized graphs, its empirical comparisons, and its unnumbered hardness discussion outside the mirror.

Open questions for a prover

  • For fixed type count, hyperparameter dimension, and finite-support contact laws, can an additive-\(\varepsilon\) solution be computed and maintained efficiently across updates?
  • How does the complexity change when the number of types grows or contact laws undergo fully dynamic changes?

The case FOR (proponent)

My lead is a continuous, typed-population version of the paper’s robust dynamic influence maximization problem. It has a plausible regime: a large regional platform, public-health network, or misinformation response system where many people fall into a small number of exchangeable groups, campaigns reach percentages of groups, and contact patterns change between discrete update periods. For example, \(N\) people might occupy \(\tau\) feature and contact-role types, with \(\tau \ll N\). The update periods stay discrete; the population is what becomes continuous.

The anchor is Theorem 1, proved in this paper (with its proof deferred to the extended version). It guarantees that, with probability at least \(1-\delta_1-\delta_2\), at every time \(t\), the union \(S_t^c=\bigcup_{i=1}^{T}S_t^{(i)}\) of the algorithm’s candidate seed sets satisfies
\[ \min_{\theta\in\Theta}\sigma_{\theta,t}(S_t^c) \ge \left(1-\frac1e-\gamma-3\epsilon_1\right) \max_{S\subseteq V_t:\,|S|\le k}\min_{\theta\in\Theta}\sigma_{\theta,t}(S) -2\epsilon_2. \]
Here \(\gamma\) is the paper’s greedy-update drift term: for incremental updates it is the maximum, and for fully dynamic updates the sum, of the weighted objective loss caused by changes during successive greedy additions. The theorem requires
\[ \ell \ge d\left(\frac{2Bdmn}{\epsilon_2}\right)^d \log\left(\frac{2Bdmn}{\epsilon_2\delta_2}\right), \qquad T\ge \frac{2\log \ell}{\epsilon_2^2}, \]
and gives amortized running time
\[ O\!\left( \frac{n^2\ell^2T c_p c_r}{k^2\epsilon_1^3} \log n\, \log\left(\frac{nTk}{\delta_1}\right) \right). \]
The result combines robustness to a continuous hyperparameter with dynamic-network updates. It is an approximation result, not a hardness result. The paper’s hardness discussion in §3.4 is not stated as a numbered theorem, so I would not use it as an anchor here.

The mirror I would hand to a prover is Typed-Mass Robust Dynamic IC. Its instance has a finite type set \(A\) of size \(\tau\), with rational masses \(\mu_a^r\) summing to one at each discrete update period \(r\). A type specifies the node features and the network role that matter to the model: seed eligibility, if relevant, and a finite-support joint degree law describing its contact pattern with each type. At each period, a directed multitype configuration model generates the contact network from these masses and contact laws. The input also gives a hyperparameter set \(\Theta=[-B,B]^d\) and an IC transmission function \(H(\theta,x_{ab})\) for contacts from type \(a\) to type \(b\). Updates change type masses or contact laws, representing cohort entry and exit or changes in contact patterns.

A decision is a seed-mass vector \(z^r\), where \(0\le z_a^r\le\mu_a^r\) and \(\sum_a z_a^r\le\kappa\), for a campaign budget of fraction \(\kappa\) of the population. For each \(\theta\), let \(\Phi_{\theta,r}(z^r)\) be the limiting expected fraction of the population activated by the IC cascade when \(\lfloor Nz_a^r\rfloor\) members of each type are seeded:
\[ \Phi_{\theta,r}(z^r) = \lim_{N\to\infty} \frac{1}{N}\, \mathbb E[\text{number activated}]. \]
The model class requires these limits to exist. The problem is to compute, at every update period, a feasible \(z^r\) maximizing
\[ \min_{\theta\in\Theta}\Phi_{\theta,r}(z^r). \]
For an approximation version, the output must be within additive \(\varepsilon\) of that optimum at each period. The complexity question is whether that can be done with useful amortized update time in \(\tau\), \(d\), the degree-law support, and input bit length, rather than in the number \(N\) of people.

This is a real population continuization: \(\mu_a^r\) is a fraction of society, and \(z_a^r\) is a fraction of a type being seeded. Network structure is part of the instance because diffusion is relational; it is not being replaced by a type histogram alone. That is also the co-modification the mirror needs to remain faithful to the paper’s question. The types record the contact roles needed to define the stochastic network, while the hyperparameter uncertainty and robust spread objective remain. The paper’s authors could plausibly recognize this as their problem in an exchangeable, high-multiplicity network regime, though not as a mirror of arbitrary named-node graphs.

I expect a Class A result for additive approximation with fixed \(\tau\) and \(d\), and finite-support type contact laws: the limiting cascade is a finite-type process, and the hyperparameter dependence is low-dimensional and Lipschitz. Whether the runtime can be polynomial in \(\tau\) and \(d\), whether efficient guarantees survive fully dynamic changes to the contact laws, and whether hardness returns as the number of types grows are open questions. This is a prediction, not a consequence of Theorem 1.

The weakest point is the network model. In the paper, two nodes with identical features can still have very different neighborhoods, and those differences can control influence spread. Grouping people by features alone would lose information central to the authors’ problem. My mirror handles that by restricting attention to populations with exchangeable contact structure and including contact role in the type and contact law. That makes the regime plausible and the question precise, but narrower than the paper’s arbitrary evolving networks. If preserving arbitrary topology is essential to the authors, this mirror may not pass their recognition test.

The case AGAINST (opponent, writing after the proponent)

Theorem 1 is a genuine computational anchor: it gives an approximation guarantee for robust influence maximization under dynamic graph updates. The strongest case against its mirror is that the paper’s population is not just a collection of people with features. It is a particular graph, and a node’s value as a seed can depend on its exact position in that graph.

The proposed typed configuration model makes same-type nodes exchangeable by replacing the realized graph with a random graph law. That is a substantial change to the problem. The original optimizes for a known network and takes its expectation over the IC cascade; the mirror also averages over network realizations. Communities, hubs, clustering, and pivotal bridges can change influence dramatically while leaving the type masses and degree laws unchanged. If those structural features are added to each node’s type so the input retains the realized topology, the number of types can grow with the population and the high-multiplicity advantage disappears. A configuration-model regime may be sensible on its own, but the authors’ recognition test is uncertain: it asks them to accept a different source of uncertainty and a different representation of network structure.

A graphon-style mirror is the strongest alternative: keep a continuum of network positions, encode connections with a kernel \(W(x,y)\), and choose a seed profile over positions. That better preserves who can reach whom, but it creates a different limit problem. In a dense graph with fixed IC transmission probabilities, a positive-mass seed set can activate essentially every population point connected to it in one round, making many instances collapse to support reachability. Scaling transmission down to avoid that collapse requires a sparse-network limit with richer local structure; a graphon alone no longer captures the relevant network. And an individual node or edge update has zero mass in the limit, even though a single bridge can have a large effect on spread. Making updates macroscopic preserves nontrivial change, but changes the paper’s per-edit maintenance problem into optimization over evolving population-level network laws.

There is also a budget mismatch to resolve. If \(k\) stays fixed as the population grows, the seed mass tends to zero; a type-level mass decision does not identify which particular seed nodes to choose. A nontrivial mass-control version generally takes \(k\) proportional to population size. That is plausible for percentage-based campaigns, but it is a distinct intervention regime from the paper’s choice of a bounded set of named nodes.

These objections make the typed-mass proposal narrower and less faithful than its formulation suggests; they do not defeat it outright. An exchangeable population with a small number of contact roles and a campaign budget stated as a population fraction is a plausible regime, and the resulting worst-case cascade optimization is a real computational question. I cannot honestly argue that no scenario yields a worthwhile mirror. The negative case is weakest precisely at the authors’ recognition gate: they could reasonably regard that regime as robust dynamic influence maximization over a high-multiplicity society.
