Why no mirror

The proposed mass-flow model replaces that with Wardrop best responses and type-level per-unit tariffs; at an unused edge, budget balance does not specify an entrant's charge, so this changes the strategic question rather than preserving it.

The case FOR (proponent)

The strongest honest anchor is Theorem 12(1)–(2), proved in this paper. The supplied text has named polynomial-time results, but no numbered NP-hardness theorem to anchor a continuization whose prize is seeing whether hardness dissolves. Theorem 12 gives a concrete algorithmic result in a network domain where a continuous population is plausible.

Consider a recurring commuter population on a shared network. A type \(t\) is a complete description of a commuter for this problem: an origin–destination pair \((s_t,z_t)\), the edge-delay vector \(d_{t,e}\), and the available path set. There may be millions of commuters but only \(\tau\) distinct types. Type \(t\) has rational mass \(\mu_t>0\), with \(\sum_t\mu_t=1\). This is a credible high-multiplicity regime: commuters with the same route options and delay profile are interchangeable, and the number of types can be far smaller than the number of people.

My lead question is Continuous Mass Enforcement on Series–Parallel Demand Networks. Its instance is an undirected network \(G=(V,E)\), shareable fixed edge costs \(c_e\), the type distribution and delays above, and an initial feasible path flow \(x\), where \(x_{t,P}\ge 0\) is the mass of type \(t\) using path \(P\), and \(\sum_{P\in\mathcal P_t}x_{t,P}=\mu_t\). Require the network to be \( \tau \)-series-parallel in the paper’s sense after replacing players by the supported types: each type’s source–terminal path subgraph has the required series–parallel structure. Write \(q_{t,e}(x)=\sum_{P\ni e}x_{t,P}\) and \(q_e(x)=\sum_t q_{t,e}(x)\). The social cost is
\[ C(x)=\sum_{e:q_e(x)>0}c_e+\sum_{t\in T}\sum_{P\in\mathcal P_t}x_{t,P}\sum_{e\in P}d_{t,e}. \]

The question is: given \(x\), can we compute a feasible flow \(x'\) with \(C(x')\le C(x)\) and a separable cost-sharing protocol that makes \(x'\) a Wardrop equilibrium? Here the protocol assigns each type a nonnegative per-unit charge \(\lambda_{t,e}(\mathbf q_e)\) on edge \(e\), depending only on the vector of type masses \(\mathbf q_e=(q_{t,e})_{t\in T}\) using that edge. It must be budget-balanced whenever the edge is used: \(\sum_t q_{t,e}\lambda_{t,e}(\mathbf q_e)=c_e\). At \(x'\), every path carrying positive mass of type \(t\) must minimize that type’s total delay plus charges among its feasible paths. A solution consists of \(x'\) and a protocol, specified succinctly for all mass profiles; it should run in time polynomial in the graph size, \(\tau\), and the binary input length, not in the implied number of commuters. As in the paper, the protocol may be tailored to the output profile, with a separable rule for other profiles.

The anchor’s content is that if the player-pair graph is \(n\)-series-parallel, then (1) from any strategy profile \(P\), a profile \(P'\) with \(C(P')\le C(P)\) and corresponding cost-share functions can be computed in polynomial time; and (2) for all edge costs \(c\) and delays \(d\), every optimal strategy profile is enforceable. The paper proves these statements here. The continuous problem above asks whether the same two properties hold after identical commuters are represented by rational masses and flows. The correspondence is direct: the paper’s paths become path flows, its player-specific delays become type delays, and its resource-by-resource budget balance becomes balance under integration over mass.

I expect Class A on this structured graph domain. The paper already gets its result from an enforceability LP and a polynomial representation of relevant path alternatives; with only \(\tau\) types, a mass-flow version looks like a plausible setting for the same continuous-optimization machinery. This is a conjecture about the mirror, not a consequence of Theorem 12: the paper’s polynomial runtime is in the number of players, so it does not itself establish runtime polynomial in \(\tau\) and the bit length of masses. The scope here is Theorem 12(1)–(2), not the paper’s full range of matroid and single-source results. Theorem 12(3), the zero-delay Steiner-forest algorithm, is not my anchor: in that setting the relevant connectivity requirements depend on which types have positive mass, so the population masses contribute less to the question.

The main further questions are whether every minimum-cost mass flow is implementable by such tariffs, whether the result survives beyond the \( \tau \)-series-parallel domain, and how a solution maps back to finite elections of commuters with integer counts—especially whether rounding preserves equilibrium or only gives an additive cost approximation.

The weak point is real: an individual in an atomless population cannot change edge masses by deviating, whereas a named player in the paper can change who uses an edge and affect cost sharing. Wardrop equilibrium is the standard continuous routing notion, and mass-based, profile-tailored tariffs make the proposed problem precise, but the equilibrium notion changes a meaningful part of the underlying game. The authors would likely recognize the network, types, mass routing, and separable cost-sharing question; whether they regard Wardrop implementation as the continuous form of their unilateral-enforcement problem is the point the opposing case can press hardest.

The case AGAINST (opponent, writing after the proponent)

Theorem 12(1)–(2) is a genuine algorithmic anchor, and the commuter example is a plausible high-multiplicity regime. I would not argue that the paper lacks a computational result or that repeated origin–destination and delay types are implausible. The problem is that the theorem’s strategic unit is an individual who can change whether they use an edge. Turning those individuals into mass changes what an edge’s fixed cost means at exactly the point the theorem has to reason about: a deviation.

In the finite game, a lone player entering an unused edge must cover its cost \(c_e\); users of an already-used edge can share that cost. In an atomless population, one person has zero mass, so their deviation changes no edge mass. A type-level tariff on an unused edge is then unconstrained by budget balance: there is no mass there to pay \(c_e\). Choosing the entry tariff as zero, finite, or infinite can change which paths are best responses. If instead deviations move a positive mass \(\varepsilon\), that mass must absorb the setup cost, at a per-unit rate on the order of \(c_e/\varepsilon\). This is a singular boundary, not the finite player’s deviation with a smaller numerical weight.

Normalizing the population makes the tension clearer. With \(n\) users and an unscaled fixed edge cost, the average share on an edge used by a positive fraction of the population tends to zero as \(n\) grows, while a lone entrant still faces the full cost. Scaling the edge cost with \(n\) keeps charges nonzero at positive mass, but makes the limiting charge at zero mass infinite. One can define a continuous model with such an entry barrier, or a model in which positive-mass coalitions deviate. Both are coherent choices; neither follows from the paper’s unilateral PNE condition without an additional modelling decision.

The stronger mass-flow version does not remove this issue. The paper’s LP and cost-sharing rule work with individual edge users and their alternative paths. A flow vector records how much of a type uses an edge, but not which members of that type are charged which amounts. Requiring a common per-unit tariff for a type therefore asks whether a flow is implementable under symmetric Wardrop prices. That may be worth studying, but it is a different implementation question from whether a profile is enforceable by the paper’s separable protocol. Expanding types to encode who pays or who is currently on which path restores distinctions the aggregation was meant to remove.

The obvious repair—make each type’s whole mass a single strategic player—also changes the deviation being tested: one commuter’s choice becomes a whole cohort’s choice. It can compress the instance to \(\tau\) players, but it is an atomic cohort game rather than a continuous society of independently acting commuters.

So my negative case is a fidelity objection: preserving individual deviations keeps the relevant granularity; passing to atomless mass replaces them with price-taking or coalition deviations and leaves entry charges at unused edges to be specified. A mass-based tariff problem could still be worthwhile, but I do not see a canonical continuous mirror of Theorem 12(1)–(2) without choosing a different equilibrium model. This is not airtight: if ChoCo treats Wardrop implementation with a specified fixed-cost entry rule as an acceptable mirror, the commuter scenario survives.
