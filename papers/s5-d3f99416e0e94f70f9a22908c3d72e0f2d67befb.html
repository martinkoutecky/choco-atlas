The continuous mirror question

Given agent types \(K=[\tau]\) with rational masses \(\mu_k\), item classes \(J=[t]\) with rational per-capita supplies \(q_j\), and valuation oracles \(\nu_k:2^J\to\{0,-1\}\), find a finite-support rational allocation \(x_{k,\mathbf b}\ge 0\) over integral bundles \(\mathbf b\in\mathbb N^t\). Require \(\sum_{\mathbf b}x_{k,\mathbf b}=\mu_k\), \(\sum_{k,\mathbf b}x_{k,\mathbf b}b_j=q_j\), and EF1 for every pair of positive-mass type-bundle cells, using \(\bar\nu_k(\mathbf b)=\nu_k(\{j:b_j>0\})\); ask whether such an allocation can be found in time and output length polynomial in \(t,\tau,L\), counting valuation-oracle queries.

The model it lives in

The population is mass over complete negative-Boolean valuation types; each individual receives an integral bundle of discrete item-class copies, while supplies scale per capita. The decision variables are the masses \(x_{k,\mathbf b}\); the task is to find a feasible EF1 allocation, with no optimization objective.

The objection that survived

The item-class restriction may erase subset distinctions used by the theorem's minimal-set construction, so the finite algorithm does not itself provide an evident batching method.

fatal: False

What the mirror covers

Covers Theorem 3's negative Boolean EF1 search for agent types and interchangeable item classes; leaves the identical-trilean, SSP, and EFX nonexistence results untouched.

Open questions for a prover

  • Can the search be solved in time polynomial in \(t,\tau,L\) with valuation-oracle access?
  • Does binary encoding of masses and supplies create hardness for this compressed problem?
  • Can the theorem's minimal-set construction be batched over agent types and item-class copies?

The case FOR (proponent)

I would lead with Theorem 3, the paper’s algorithmic result: for any finite fair-division instance with negative Boolean valuations—every agent assigns every item subset value \(0\) or \(-1\), and agents need not have identical valuations—Algorithm NegBooleanEF1 returns an EF1 allocation in polynomial time. The paper proves this result; it is not merely cited. The guarantee is polynomial in the finite instance size, with the proof using only polynomially many valuation queries. The paper offers no NP-hardness result, so this is its strongest computational anchor. ([paper](https://ifaamas.csc.liv.ac.uk/Proceedings/aamas2025/pdfs/p298.pdf), [full version](https://arxiv.org/abs/2411.19881))

A plausible high-multiplicity setting is a large institution assigning recurring task slots to a population with a small number of recurring bundle-attitude profiles. A person’s profile says which bundles are acceptable and which are disfavored; people with the same complete profile form one type. The population may be enormous while the number \(\tau\) of distinct profiles stays modest. Task supply scales with population: the input records task units per person, rather than a huge headcount and total inventory. To keep the paper’s indivisible bundles and one-item EF1 test, each person still receives an integral bundle. Only the population is represented by mass.

Here is the mirror I would ask a prover to solve, Mass-Negative-Boolean EF1 Search. Let \(J=[t]\) be item classes, and let \(K=[\tau]\) be agent types. The input gives rational type masses \(\mu_k\ge 0\) summing to \(1\), rational per-capita supplies \(q_j\ge 0\), and a negative Boolean valuation \(\nu_k:2^J\to\{0,-1\}\) for each type. A bundle is an integer vector \(\mathbf b\in\mathbb N^t\); its value is \(\bar\nu_k(\mathbf b)=\nu_k(\{j:b_j>0\})\). Thus multiple copies of a class are allowed, but utility depends on which classes occur in the bundle. This describes a restricted, explicit regime of the paper’s valuation class.

A solution is a finite-support rational mass allocation \(x_{k,\mathbf b}\ge 0\): \(x_{k,\mathbf b}\) is the fraction of the population of type \(k\) receiving integral bundle \(\mathbf b\). It must satisfy
\[ \sum_{\mathbf b}x_{k,\mathbf b}=\mu_k \quad\text{and}\quad \sum_{k,\mathbf b}x_{k,\mathbf b}b_j=q_j\ \text{for every }j. \]
It must also be EF1 across every pair of bundle types \((k,\mathbf b)\), \((\ell,\mathbf c)\) receiving positive mass. If type \(k\) envies \(\mathbf c\), then either removing one class-\(j\) item from \(\mathbf b\) resolves the envy, or removing one class-\(j\) item from \(\mathbf c\) resolves it:
\[ \bar\nu_k(\mathbf b)<\bar\nu_k(\mathbf c) \implies \exists j:\ \bigl(b_j>0\land \bar\nu_k(\mathbf b-\mathbf e_j)\ge\bar\nu_k(\mathbf c)\bigr) \ \lor\ \bigl(c_j>0\land \bar\nu_k(\mathbf b)\ge\bar\nu_k(\mathbf c-\mathbf e_j)\bigr). \]
The task is to output such an allocation, with running time and output length polynomial in \(t,\tau,L\), where \(L\) is the binary input length of the rational data and valuation queries are counted. A solution can be required to list at most \(t+\tau\) positive type-bundle cells: once a fair support is fixed, reducing its mass/supply equalities to a basic feasible solution keeps a subset of that already EF1 support.

I would expect tractability (Class A), as a research target. Clearing denominators gives a finite instance with \(D\mu_k\) agents of type \(k\) and \(Dq_j\) items of class \(j\); Theorem 3 then guarantees an allocation, which aggregates into a mass solution. That is a useful discrete-to-continuous identity, but \(D\) can be exponential in \(L\), so running the finite algorithm on all \(D\) agents does not answer the compressed search problem. The promising route is to batch repeated types in the theorem’s minimal-set construction. Further questions are whether this batching gives polynomially many queries and output bits, whether binary-encoded multiplicities introduce continuum-specific hardness, and whether similar compression extends to trilean valuations.

The mirror covers Theorem 3’s negative Boolean EF1 search result, not the paper’s identical-trilean or SSP results, nor its EFX nonexistence result. Its weakest point is the item-class cloning assumption: it makes large per-capita supplies fit the paper’s indivisible-item model by requiring copies of a class to be interchangeable. That is a narrower regime than arbitrary item identities. A second limitation is central to the proposed question: Theorem 3 proves polynomial time in the expanded finite population, not polynomial time in the binary encoding of population masses. The continuous search problem remains meaningful precisely because that gap is unresolved.

The case AGAINST (opponent, writing after the proponent)

Theorem 3 is a real computational anchor: the paper gives a polynomial time algorithm for finding an EF1 allocation with nonidentical negative Boolean valuations. That makes a continuous mirror worth considering.

The proposed institution scenario also survives the main high multiplicity test. A large population can have a small number of complete bundle-attitude profiles, with each person receiving an integral bundle and EF1 checked between every pair of bundles that occurs. Fractions describe how many people receive each bundle; they do not make any individual’s fairness condition vacuous. The mass model is a sensible object for that setting.

The strongest objection is that the proposed mirror adds substantial structure to the items. The paper permits arbitrary negative Boolean valuations over subsets of named items. The mirror uses interchangeable copies within each item class and makes value depend only on whether a class occurs in a bundle. That is a restricted regime, and the paper’s minimal-set construction relies on distinctions among subsets that this model may erase. Still, recurring task slots with preferences over combinations of task classes are plausible, and the programme allows a mirror to include such co-modifications. This objection narrows the mirror; it does not defeat it.

The finite theorem also settles existence for the rational mass instances after clearing denominators. Its algorithm may take time polynomial in the expanded population, which can be exponential in the binary input length. Finding a polynomial time algorithm in the compressed encoding is therefore a genuine high multiplicity question, not an answer already supplied by the theorem. The concern is that EF1 still constrains indivisible bundle choices, so there is no obvious LP or continuous optimization structure to exploit. That makes this a weaker fit for ChoCo’s optimization toolbox, rather than an unworthy computational question.

I cannot make a convincing case that no worthwhile mirror exists for this anchor. The honest negative case is limited to saying that the strongest proposed mirror is a narrower, potentially less fruitful research direction than its framing suggests.
