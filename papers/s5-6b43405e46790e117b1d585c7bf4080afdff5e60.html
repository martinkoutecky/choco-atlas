The continuous mirror question

Given a tree \(T=(V,E)\), \(k\) supported resident types, and rational proportions \(\mu_i\ge 0\) with \(\sum_i\mu_i=1\), find a rational allocation \(x_{v,i}\ge 0\) satisfying \(\sum_i x_{v,i}=1\) for every \(v\) and \(\sum_v x_{v,i}=|V|\mu_i\) for every \(i\). Define \(U_i(v;x)=\frac{\sum_{w\in N(v)}x_{w,i}}{\deg(v)}\). Require that for every edge \(uv\) and types \(i\ne j\) with \(x_{u,i}>0\) and \(x_{v,j}>0\), the two residents do not both strictly prefer the other district: it is not the case that \(U_i(v;x)>U_i(u;x)\) and \(U_j(u;x)>U_j(v;x)\). Can such a stable allocation always be found in time polynomial in \(|V|\), the number of supported types, and the input bit length?

The model it lives in

A tree of unit-capacity district sites holds an atomless population split among \(k\) complete resident types, with total mass \(|V|\mu_i\) of type \(i\). Each resident’s utility depends on the type masses in neighboring districts; ask for a stable allocation against infinitesimal swaps between adjacent districts, with no welfare objective.

What the mirror covers

The mirror covers Theorem 2.6’s polynomial-time existence and computation result for local equilibria on trees; it leaves the Price of Anarchy bounds, global swaps, and grid dynamics untouched.

The case FOR (proponent)

The strongest mirror I can defend is the paper’s tree result, Theorem 2.6. It is proved in this paper: for every \(k\ge 2\), every local \(k\)-SSG on a tree has a local swap equilibrium, and one can compute one in polynomial time. Here a local swap exchanges two agents at adjacent vertices; it is profitable when both agents strictly improve their same-type-neighbor fractions. The proof roots the tree and places types from leaves toward the root, so each subtree contains only types no higher than its root’s type. That ordering blocks profitable local swaps.

A plausible high-multiplicity regime is a large, branching residential campus or planned settlement. Let tree vertices represent neighboring districts, each containing many interchangeable homes and residents. Residents share one of \(k\) complete types: all members of a type have the same preferences and parameters. The number of residents can grow far beyond \(k\), while the number of supported types stays small. This keeps the paper’s tree topology, local interaction, utility, and exchange mechanism; the co-modification is that each district has a population density instead of one resident.

Here is the continuous problem I would hand to a prover: Tree Local Infinitesimal Swap Equilibrium. An instance is a tree \(T=(V,E)\), \(k\) types, and rational type proportions \(\mu_i\ge 0\) with \(\sum_i\mu_i=1\). Find an exact rational allocation \(x_{v,i}\ge 0\) such that
\[ \sum_i x_{v,i}=1\quad(v\in V),\qquad \sum_{v\in V}x_{v,i}=|V|\mu_i\quad(i\in[k]). \]
Here \(x_{v,i}\) is the fraction of district \(v\)’s residents of type \(i\). A type-\(i\) resident at \(v\) receives utility
\[ U_i(v;x)=\frac{\sum_{w\in N(v)}x_{w,i}}{\deg(v)}. \]
Call an allocation stable if no edge \(uv\) and types \(i\ne j\) with \(x_{u,i}>0\) and \(x_{v,j}>0\) satisfy both
\[ U_i(v;x)>U_i(u;x) \quad\text{and}\quad U_j(u;x)>U_j(v;x). \]
The swap is infinitesimal: in the large-population limit, one pair’s exchange leaves the population distribution unchanged. There is no welfare objective here; the requested output is a stable allocation. The complexity question is whether one always exists and can be found in time polynomial in \(|V|\), the number of supported types, and the rational input bit length.

I tentatively expect a Class A result, since the tree structure and the paper’s type ordering give a promising basis for an algorithm. The scope is just this local-equilibrium question on trees. It does not cover the paper’s global-swap results, Price of Anarchy bounds, or grid dynamics. The paper’s cited hardness results are useful context, but they do not give me a numbered hardness theorem to anchor this particular mirror.

The main weakness is substantial: infinitesimal swaps change the equilibrium test that Theorem 2.6 solves. In the discrete game, a swap changes the colors at two whole vertices; the proof uses the resulting utility change. In the continuum limit, one pair has negligible effect on district densities, so its destination utility is computed against the unchanged allocation. The theorem therefore motivates this question without establishing its answer. I still think the mirror is plausible because it retains the same agents, local preferences, and bilateral move while making population mass the object of study. Whether the authors accept the infinitesimal stability notion—and whether the tree construction survives it—is the point the paper’s continuous counterpart should put to them.

The case AGAINST (opponent, writing after the proponent)

I cannot honestly defeat the tree anchor. Theorem 2.6 is a named computational result, and the two colors or \(k\) colors are plausible complete agent types: agents of the same color have the same action set and preferences. Large settlements with many residents of each type are a credible high-multiplicity regime. The paper’s cited continuous physical analogue is not a computational treatment, and high-multiplicity work would support this regime rather than collide with it.

The strongest objection is a mismatch in what counts as a swap. In the finite game, exchanging two adjacent occupants changes the neighborhood composition by one whole occupant. The tree proof relies on that indivisible assignment: it places whole vertices in an order that rules out profitable swaps. In an atomless district model, exchanging two individuals changes no aggregate allocation \(x\). Stability then means that no pair of present types prefers the other’s location, a coherent question but a different strategic object. If instead a swap transfers positive mass, post-swap utilities depend on the transfer size; the model must specify that size or a rule for considering all feasible transfers. This weakens the claim that Theorem 2.6’s result or proof has a direct continuous counterpart.

That objection still falls short. The proposed infinitesimal stability notion is well-defined, and one could ask whether stable allocations exist and can be computed on trees. A finite-mass exchange model is another plausible formulation. Treating vertices as districts also changes their interpretation, but it is a natural co-modification for a large residential population. The paper’s PoA results on regular graphs or grids offer further possible mirrors, and I do not see a basis for ruling those out either.

So the negative case is weak: the swap mechanism changes under continuization, but that does not show that the resulting computational questions are unworthy. The tree anchor survives that objection.
