The continuous mirror question

Given a finite alternative set \(X\) and \(\tau\) supported antisymmetric acyclic preference types \(\succsim_t\) with positive rational masses \(p_t\) summing to \(1\), choose for each type a preorder \(R_t\) extending \(\succsim_t\) to minimize \(\sum_t p_t D(\succsim_t,R_t)\); output the minimizing tuple and its value.

The model it lives in

The society is a distribution over complete preference types on \(X\). Each type receives a shared transitive extension, and its mass weights that type’s top-difference repair cost; Theorem 5.1 gives \(R_t=\operatorname{tran}(\succsim_t)\) for every supported type.

What the mirror covers

The mirror covers Theorem 5.1’s best transitive-extension problem, repeated over the supported types; it leaves the axiomatic characterizations, diameter and embedding results, and the paper’s suggested consensus problem aside.

The case FOR (proponent)

The strongest positive mirror is a narrow one: Population-Weighted Transitive-Extension Repair. The paper has no named result classifying a problem as in P or NP-hard. Its best computational anchor is instead an exact optimization result.

The anchor is Theorem 5.1, proved in this paper. For a finite alternative set \(X\), a positive measure \(\nu\), and an antisymmetric acyclic preference relation \(\succsim\), consider all preorders that extend \(\succsim\), meaning they preserve every strict comparison in \(\succsim\). The theorem says that the unique extension minimizing \(D^\nu(\succsim,R)\) is the transitive closure \(\operatorname{tran}(\succsim)\). I use the counting-measure case \(D\).

Here is the continuous problem. An instance has a finite alternative set \(X\) and a distribution \(p\) with rational masses over \(\tau\) antisymmetric acyclic preference types \(\succsim_t\). A type is the complete preference relation used by this repair problem; \(p_t\) is the fraction of the population with that relation. Choose, for every supported type \(t\), a preorder \(R_t\) extending \(\succsim_t\), minimizing

\[ \sum_{t} p_t\,D(\succsim_t,R_t). \]

A solution is the tuple of extensions \(R_t\), together with the resulting minimum population-average distortion. The natural regime is a large choice-experiment or consumer panel where many respondents produce the same relation over a modest set of alternatives: the number of people is much larger than the number \(\tau\) of distinct relation types. Respondents of one type have the same feasible repairs and costs, so assigning a shared repair to that type is the high-multiplicity interpretation.

I expect this mirror to be Class A. Theorem 5.1 gives \(R_t=\operatorname{tran}(\succsim_t)\) for each supported type, uniquely. With explicit relation encodings, these closures and the objective can be computed in time polynomial in \(|X|\), \(\tau\), and the mass bit length; the paper’s Section 3.5 also gives a polynomial-time formula for evaluating the distance. The theorem itself does not state a complexity bound, so the algorithmic conclusion is an inference from its characterization and the paper’s computation formula.

This mirrors only Theorem 5.1’s extension-constrained approximation problem. It does not turn the paper’s axiomatic characterization, diameter formula, or embedding result into population-complexity claims. A natural next question is whether one can choose a *single* preorder minimizing weighted distance to all types—a consensus problem the paper itself suggests studying, but does not solve here.

The weak point is that the population objective separates by type: masses weight the total distortion but do not affect which repair each type receives. So this is a credible high-multiplicity batch version of the authors’ exact problem, not evidence that continuization unlocks a new tractability result. The strongest case for it is its close match to their stated “best transitive extension” question and their motivation of studying preference variability in the aggregate.

The case AGAINST (opponent, writing after the proponent)

Theorem 5.1’s direct population version is weak: given preference types \(\succsim_t\) with masses \(p_t\), minimizing \(\sum_t p_t D(\succsim_t,R_t)\) over separate extensions \(R_t\) lets the theorem choose each \(R_t=\operatorname{tran}(\succsim_t)\). The masses change the total reported cost, but never the repairs. This is a useful batch computation, yet it adds no population-level decision or optimization.

That does not support the stronger claim that no worthwhile mirror exists. A more compelling question is to find one consensus preference \(R\) minimizing
\[ \sum_t p_t D(\succsim_t,R). \]
This is a population-weighted preference aggregation problem. The paper itself points toward consensus as future research, and a large panel with many people sharing each preference type is a plausible high-multiplicity setting. Here the masses affect which consensus is optimal, so the independent-closure shortcut does not apply. The question is computational and uses the population as the continuous object.

That consensus problem extends beyond Theorem 5.1’s stated extension constraint, so a strict reading of “mirror” could reject it as a new direction. But it is close to the paper’s own agenda and directly uses its proposed distance. Calling it already continuous or dismissing it because its complexity might be driven by the number of alternatives would not make a sound case against it.

So the negative case defeats the proponent’s specific, separable mirror: it seems unlikely to yield the kind of computational insight ChoCo seeks. The universal negative remains weak, because the aggregate consensus formulation appears to survive the stronger objections.
