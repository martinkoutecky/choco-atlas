  • Proposition 10 — survived: The exact criterion, combined with the paper’s Dijkstra construction, computes the S-order precedence relation from pairwise type masses.

The continuous mirror question

Given \(m\) alternatives and \(\tau\) supported complete rankings \(t\), each with binary-rational mass \(\mu_t\) summing to one, compute \(Q_\mu=\{(a,b):p_\mu(a,b)>\max\{\frac12,B_\mu[b,a]\}\}\), where \(p_\mu(a,b)=\sum_{t:\,a\succ_t b}\mu_t\) and \(B_\mu[b,a]\) is the maximum, over paths from \(b\) to \(a\) in the directed graph with edges \((x,y)\) satisfying \(p_\mu(x,y)>\frac12\), of the minimum \(p_\mu\)-strength along the path; set \(B_\mu[b,a]=0\) if no such path exists.

The model it lives in

Use complete rankings as types carrying rational mass; form the pairwise strength matrix \(p_\mu\), compute the strongest-path values \(B_\mu\), and return the forced-precedence relation \(Q_\mu\), whose linear extensions are the S-order set.

What the mirror covers

The mirror covers Proposition 10’s construction of \(Q_\mu\), which represents the S-order set as the linear orders respecting \(Q_\mu\). It leaves the paper’s other characterizations, normative properties, and single-winner discussion aside.

The case FOR (proponent)

The strongest positive case is a narrow one: the continuous computation of the paper’s S-order set. It has a natural large-electorate interpretation, and its core computation can be stated directly in terms of type masses.

Take a large election with \(m\) alternatives. A type \(t\) is a complete ranking, and \(\mu_t\) is the fraction of voters with that ranking, with rational masses summing to one. Let \(p_\mu(a,b)=\sum_{t:\,a\succ_t b}\mu_t\), the share ranking \(a\) above \(b\). For the paper’s ratio version of \(\Phi\), \(p_\mu(a,b)+p_\mu(b,a)=1\), so \(\Phi_\mu[a,b]=p_\mu(a,b)\). Many voters can share each type: for example, an election with millions of members, a small candidate slate, and far fewer distinct rankings than voters. The ranking fully describes what the model uses about a voter, so grouping identical rankings preserves the paper’s semantics. Existing high-multiplicity election work also supports treating this as a sensible regime.

My anchor is Proposition 10, proved in this paper. It states, in full, that
\[ (a,b)\in\bigcup_{\alpha\in[1/2,1)}P(S(R_\alpha)) \quad\Longleftrightarrow\quad \Phi[a,b]>\max\left\{\frac12,B[b,a]\right\}, \]
where \(B[b,a]\) is the strength of the strongest path from \(b\) to \(a\): the maximum, over paths in the majority relation \(R_{1/2}\), of the minimum \(\Phi\)-strength on a path edge, with value \(0\) if there is no such path. The paper then says these strengths can be computed using Dijkstra’s algorithm, yielding a computationally efficient way to construct the relation. The proposition is an exact algorithmic characterization; the paper does not state a formal complexity-class theorem or give a running-time bound.

The corresponding problem is Continuous S-Order Computation. An instance consists of \(m\) alternatives and a list of \(\tau\) supported rankings with binary-rational masses \(\mu_t\) summing to one. Compute the exact precedence relation
\[ Q_\mu=\left\{(a,b):p_\mu(a,b)> \max\left\{\frac12,B_\mu[b,a]\right\}\right\}. \]
A solution is this relation, which compactly describes the paper’s S-order set as the linear orders respecting \(Q_\mu\); a solver can also return any one such linear order. There is no optimization objective in this paper: the decision is which pairwise precedences are forced by the construction. Pairwise masses take \(O(\tau m^2)\) additions, and all-pairs strongest-path values can be computed in polynomial time in \(m\). With exact rational arithmetic, this gives a polynomial-time algorithm in \(m,\tau\), and the input bit length \(L\). Clearing the mass denominators recovers a finite high-multiplicity election with the same pairwise shares and the same answer.

I expect this mirror to be tractable. Its scope is Proposition 10’s construction of the S-order relation, and thereby a compact representation of the S-order set. It does not cover the paper’s other results, such as the ranked-pairs and Schulze characterizations, the normative properties, or the single-winner discussion. Further questions include whether the computation stays efficient when the type distribution is given implicitly, and which other supermajority-strength functions admit comparable exact characterizations.

The weak point is substantial: the paper does not present this as a complexity-class result, and its finite-profile construction is already computationally efficient. The continuous version mainly replaces repeated ballots with their rational frequencies; the decisive information then collapses to a pairwise strength matrix. I count Proposition 10 as an algorithmic anchor because it gives the exact computation and the paper explicitly connects it to Dijkstra. If the anchor rule requires a numbered result that literally states “in P,” the paper has no such result. Even under the more permissive reading, this is a faithful but modest high-multiplicity mirror, not a case where population continuity dissolves known hardness.

The case AGAINST (opponent, writing after the proponent)

The strongest negative case is that Proposition 10 is not a complexity result in the paper. It characterizes which precedences enter the S-order relation; the paper then notes that the needed path strengths can be computed with Dijkstra’s algorithm. It gives no complexity classification or formal running-time bound for a computational problem. The paper’s main results are characterizations of collective order rules and their properties.

The best continuous version is still clear: given \(m\) alternatives and \(\tau\) supported rankings with rational masses, compute the full S-order set, represented by its forced-precedence relation. But this just aggregates the masses into pairwise strengths and computes widest paths on an \(m\)-vertex graph. It takes \(O(\tau m^2)\) arithmetic operations to form the strengths, followed by polynomially many graph operations; exact comparisons have polynomial bit complexity. Computing the full set rather than one order does not add a harder task, since the relation compactly describes all its linear extensions. This is a faithful high-multiplicity formulation, but the population types disappear after the initial tally. It offers no separate population-level optimization or strategic problem for ChoCo to analyze.

That objection is narrow. The paper’s finite-voter input is not itself a continuous society, and a low-support election is a sensible high-multiplicity regime. Nor does the existing Dijkstra construction disqualify the mirror: the programme permits tractable outcomes, and its rules say that a known answer does not make a well-posed question unworthy. So I cannot honestly establish the requested universal claim. The case against Proposition 10 works only if ChoCo’s scope excludes direct evaluation of an already characterized aggregation rule; under the programme’s broader computational framing, this is a modest but legitimate mirror.
