The anchor — hardness

Theorem 2.2

Every anchor argued

  • Theorem 2.2 — survived: The opponent’s resource-indivisibility objection is addressed by limiting the mirror to a plausible high-multiplicity regime with repeated package types and supplies that scale with enrollment.

The continuous mirror question

Given student types \(t\) with population shares \(\rho_t\), a target assignment \(a_{tp}\) to projects, and resource types \(r\) with per-package capacity \(q_r\), compatible-project set \(T_r\), and per-capita supply \(\sigma_r\), does there exist an allocation \(z_{rp}\ge 0\) such that \(z_{rp}=0\) for \(p\notin T_r\), \(\sum_{p\in T_r}z_{rp}=\sigma_r\), and \(\sum_r q_r z_{rp}\ge \sum_t a_{tp}\) for every project \(p\)?

The model it lives in

A large student population is represented by masses \(\rho_t\) of preference or eligibility types, with a target assignment mass \(a_{tp}\). Identical resource packages are grouped by capacity and compatibility; their supply \(\sigma_r\) scales per student. Each student and each package remains indivisible in a finite cohort, while their type-level allocations are masses. Feasibility is a rational linear program.

What the mirror covers

The mirror covers Theorem 2.2’s feasibility decision. It does not cover the paper’s nonwastefulness or stability results.

Open questions for a prover

  • For finite cohorts of size \(N\), when can a feasible mass allocation be rounded to whole packages with per-type counts \(N\sigma_r\), and what capacity slack suffices when exact rounding fails?

The case FOR (proponent)

The cleanest anchor is Theorem 2.2, proved in this paper. It states that SPR/FA is NP-complete: given an SPR instance and a matching \(Y\), decide whether there is an allocation of resources to compatible projects that gives every project enough total capacity for its assigned students. The paper proves membership in NP using a resource allocation as a certificate. For hardness, it reduces from strongly NP-hard 4-Partition: given \(4m\) integers \(w_i\) summing to \(m\theta\), with \(\theta/5<w_i<\theta/3\), make \(m\) projects, assign \(\theta\) students to each, and give the projects \(4m\) resources of capacities \(w_i\), each compatible with every project. The matching is feasible exactly when the resources can be partitioned into \(m\) groups of four, each summing to \(\theta\).

My lead mirror is Continuous-Supply SPR/FA. Consider a large university allocation in which students are assigned to projects, and projects obtain seats from compatible teaching or laboratory packages. Student type \(t\) records the student information relevant to this feasibility question, such as their project ranking; \(\rho_t\) is that type’s share of the student population. The instance gives a target assignment \(a_{tp}\), the mass of type \(t\) assigned to project \(p\), with \(\sum_p a_{tp}\leq \rho_t\) and \(a_{tp}=0\) when \(p\) is unacceptable. Each resource type \(r\) consists of identical packages, each with capacity \(q_r\) and compatible-project set \(T_r\). Its supply \(\sigma_r\) is the number of packages per student.

The question is whether the target assignment is feasible with this supply. A solution is a resource allocation \(z_{rp}\geq 0\) satisfying
\[ z_{rp}=0\quad\text{if }p\notin T_r,\qquad \sum_{p\in T_r}z_{rp}=\sigma_r,\qquad \sum_r q_r z_{rp}\geq \sum_t a_{tp}\quad\text{for every }p. \]
Here \(z_{rp}\) is the mass of whole packages of type \(r\) assigned to \(p\): each package still goes to one project. The real-valued aggregate records how a large cohort of identical packages is split across projects, just as the student assignment records how a type’s mass is distributed. The population is the continuous object; resource supply scales per capita with it.

This is a direct mirror of the theorem’s underlying feasibility question. It keeps the matching fixed, retains resource compatibility and endogenous project capacities, and asks whether the assigned population can be supported. It is not a lottery over student outcomes. The resulting feasibility problem is a rational linear program with polynomially many variables and constraints in the numbers of project, student-type, and resource-type categories and the input bit length. I expect Class A: tractable. The continuous model lets the solver allocate aggregate supply across projects, so the discrete partition obstruction need not remain.

The natural regime is a recurring large university intake: many students, but comparatively few preference and eligibility profiles; many capacity packages, but comparatively few package types defined by capacity and project compatibility. Each student still receives at most one project, and each package still goes whole to one project. For this anchor, project priorities do not enter: SPR/FA checks feasibility, not fairness or stability.

The weak point is that Theorem 2.2’s hardness is specifically about packing indivisible resource items. Its reduction uses a collection of differently weighted resources; simply making the student population large would not remove that structure. This mirror is persuasive only in a regime where supplies grow with the student population and many packages share each resource type. If the actual setting has a small inventory of bespoke, one-off resources, the proposed mass allocation would blur precisely the indivisibility that makes the original problem hard. I would not claim that this mirror covers arbitrary SPR/FA instances.

A useful next question is how the continuous answer relates to finite high-multiplicity instances: when can a feasible mass allocation be rounded to whole packages while preserving project feasibility, and what additive capacity slack suffices when exact rounding fails? This case covers Theorem 2.2 only; it makes no claim about the paper’s nonwastefulness or stability results.

The case AGAINST (opponent, writing after the proponent)

Theorem 2.2 is a genuine computational result, so there is no decisive “nothing here to mirror” objection. The strongest case against its mirror is that the theorem’s combinatorial object is the inventory of indivisible resources. Once the matching \(Y\) is fixed, student preferences matter only through which assignments are allowed; feasibility reduces to meeting the project loads \(d_p=|Y(p)|\). The hardness comes from partitioning the resource capacities.

Continuizing student mass alone leaves that resource problem intact. If the resource inventory stays fixed while the student population grows, its capacity per capita vanishes. A nondegenerate limit must scale resource supplies too. The proposed variables \(z_{rp}\) then represent fractional aggregate counts of packages, so the model relies on many packages in each resource type. That is a substantive regime assumption, beyond having repeated student types. With a bespoke inventory, the aggregation erases the very indivisibility that Theorem 2.2 studies.

The stronger version of the mirror is still plausible: a large university cohort with students in a few preference types and teaching packages in a few repeated capacity and compatibility types. For a finite cohort of size \(N\), per-student supply \(\sigma_r\) corresponds to \(N\sigma_r\) whole packages; normalized package counts then have a natural mass limit. This is a coherent high-multiplicity scenario, and the programme explicitly allows per-capita supplies to scale with the population. The paper’s statement that resources are indivisible does not rule it out: individual packages can stay indivisible in finite instances while their aggregate mass has a limit.

So the best negative case is narrower than the requested universal claim: the theorem does not by itself motivate a population-only continuation, and its hard cases need not lie in the repeated-package regime. But that does not defeat the stronger mirror. From the paper and programme brief, I cannot honestly argue that no worthwhile continuous mirror exists in any scenario; the negative case is weak at precisely that point.
