The continuous mirror question

Given bipartite type sets \(U,V\), positive rational masses \(\mu_i\), supported pairs \(E\), rational flow capacities \(\kappa_{ij}\), and type-specific separable, concave, piecewise-affine payoff functions, find a feasible flow \(q\) with \(0\le q_{ij}\le\kappa_{ij}\), per-type budgets \(\sum_j q_{ij}\le\beta_i\mu_i\), and symmetric per-capita allocations \(q_{ij}/\mu_i\) and \(q_{ij}/\mu_j\). Require full stability on this type-level network: no type can improve by reducing its incident flows, and no supported pair of types can both improve by increasing their shared flow while reducing other incident flows, subject to feasibility. Does an exact finite-step or polynomial-time algorithm find such a flow, in terms of the type count, supported pairs, and input bit length?

The model it lives in

A symmetric cohort model of bipartite fractional matching: each type has mass \(\mu_i\), pairwise flows are \(q_{ij}\), each type receives the same per-capita allocation across its members, and full-stability deviations are defined over type-level flows.

The objection that survived

Aggregate flows do not encode unequal allocations within a type, and nonlinear payoffs can make utility at an average allocation differ from average utility; the proposed mirror therefore requires symmetric per-capita allocations and type-level blocks.

fatal: False

What the mirror covers

The mirror covers the bipartite, separable, concave, no-externalities matching setting of Proposition 5.9. It leaves aside the hypergraphic existence result, the full-stability counterexamples, and other existence results in the paper.

Open questions for a prover

  • Does the symmetric type-level stability condition faithfully capture a useful high-multiplicity version of individual full stability?
  • Can a fully stable flow be found in finite or polynomial time in the type count, supported pairs, and input bit length?

The case FOR (proponent)

There is a credible positive mirror in the paper’s bipartite matching results. The regime is a large labor market: many workers and positions, but relatively few complete types. A worker type fixes the cohort’s preferences, payoff functions, and budget; an employer type fixes the corresponding details on the other side. The type masses are rational fractions of the market, and the number of types \(\tau\) may be much smaller than the number of people. That is the population continuization: the input describes masses of interchangeable agents rather than a list of named individuals. Fractional flows are a natural co-modification because the paper’s matching model already lets agents divide their resources across relationships.

My lead anchor is Proposition 5.9, proved in this paper. It says that for a continuous, separable, concave, bipartite network game with no externalities, integral capacities and budgets, and piecewise-affine payoffs whose slope changes occur only at integers, GDA can be run with the rule that each chosen argmax is integral. The resulting network is fully stable and integral, and the algorithm takes at most \(\sum_{C\in E}\alpha_C\) steps. This is a finite-step algorithmic result, though its bound depends on numeric capacities; it is not a polynomial-time classification.

The mirror problem I would hand to a prover is Type-Mass Bipartite Full Stability. An instance consists of finite worker-type and employer-type sets \(U,V\), rational masses \(\mu_i>0\) for each type, a bipartite support \(E\subseteq U\times V\), rational flow capacities \(\kappa_{ij}\), per-capita budgets \(\beta_i\), and type-specific separable, concave, piecewise-affine payoff functions with rational breakpoints. A feasible solution is a flow \(q_{ij}\), the mass of the relationship between types \(i\) and \(j\), satisfying
\[ 0\le q_{ij}\le \kappa_{ij},\qquad \sum_{j:(i,j)\in E}q_{ij}\le\beta_i\mu_i,\qquad \sum_{i:(i,j)\in E}q_{ij}\le\beta_j\mu_j. \]
Type \(i\)’s per-capita allocation on an edge is \(q_{ij}/\mu_i\), and type \(j\)’s is \(q_{ij}/\mu_j\). The question is to return a feasible flow with no profitable full-stability deviation: no type can improve by reducing its incident flows, and no pair of types can strictly improve both payoffs by increasing their common flow while reducing other incident flows, with the resulting allocation still feasible. A deviation changes relationship mass, so fractional quantities represent how much of each cohort participates, rather than fractional people receiving indivisible bundles.

This is a plausible mirror of the paper’s bipartite matching problem: the paper explicitly connects network stability to fractional matching, and its discrete proposition supplies the high-multiplicity comparison. I expect the type-mass problem to be a Class A candidate under these assumptions: it has finitely many allocation variables, rational type data, and concave piecewise-linear payoffs. But Proposition 5.9 does not prove that claim. The paper’s continuous GDA result, Theorem 5.4, proves convergence under its assumptions but allows infinitely many steps; the authors identify finite-time and polynomial-time computation as open questions. So the concrete question is whether this mass-flow version admits a finite, preferably polynomial-time, exact algorithm in the number of types, supported edges, and input bit length.

This mirror covers the bipartite, separable, concave, no-externalities matching result—not the paper’s hypergraphic existence theorem or its full-stability counterexamples. I would not use those as complexity anchors: the counterexamples show nonexistence on particular games, not a hardness classification. Nor would I use the PPAD-completeness mentioned in the discussion as an anchor; it is attributed to prior work, not stated as one of this paper’s numbered results. Proposition 5.9 is the strongest available anchor here because the paper supplies no comparable named NP-hardness or polynomial-time result.

The weakest point is the stability condition under aggregation. Proposition 5.9 reasons about named agents and their incident links; the mirror reasons about masses of types and type-level flows. A referee could ask whether type-level blocking really preserves the paper’s individual deviation semantics, or quietly changes the solution concept. The authors’ matching framing makes the move credible, but the mirror should explicitly fix its block notion and justify why identical members of a type can be represented by mass flows. That is the central formal obligation, alongside proving finite-time computation.

The case AGAINST (opponent, writing after the proponent)

The strongest case against this anchor is that the proposed flow \(q_{ij}\) does not yet preserve the stability notion in Proposition 5.9. That proposition concerns individual agents and individual links: with separable payoffs, an agent’s utility sums contributions from each incident edge, and full stability allows particular agents to reallocate their own incident weights. A type’s average flow does not generally tell us how those links or budgets are distributed among its members.

This matters precisely for the nonlinear payoffs Proposition 5.9 allows. If members of type \(i\) have different weights on links to members of type \(j\), their average \(q_{ij}/\mu_i\) need not determine their average payoff: applying a piecewise-linear payoff to the average can differ from averaging the payoffs. Nor does \(q_{ij}\) show whether some particular pair can make a profitable deviation. The proposed type-level block, which changes mass between types, is therefore not automatically the paper’s block by individual coalition members.

There are two natural repairs, but each changes what is being studied. Requiring every member of a type to receive the same allocation makes \(q\) meaningful, but rules out the asymmetric reallocations permitted by full stability. Tracking the distribution of individual link weights and budgets preserves those deviations, but the state is then a distribution over allocations, not just masses on \(\tau\) fixed types. The proponent would need to show that one of these models is a faithful version of the paper’s problem, rather than assume that aggregation preserves it.

This also limits what Proposition 5.9 contributes computationally. It gives a finite-step algorithm with a bound of \(\sum_{C\in E}\alpha_C\), while Theorem 5.4 allows GDA to take infinitely many steps. The proposition does not establish polynomial-time complexity, and its bound depends on numeric capacities. So the proposed mass-flow question would need both a precise input model and a result connecting its stability notion to the individual-agent one.

That is a real obstacle to this particular mirror, but it does not support the universal claim that no worthwhile mirror exists. In a clone-symmetric matching market, type-level flows and coordinated cohort deviations could be a coherent model the authors would recognize. The paper’s fractional-matching connection makes that scenario especially plausible. I cannot honestly defeat that repaired version from the text: the negative case is weak exactly where the type-mass model is most natural.
