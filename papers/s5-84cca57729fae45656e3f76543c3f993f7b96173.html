The continuous mirror question

Given a finite type set \(T\), rational masses \(\mu_t>0\) summing to \(1\), rational ideal locations \(p_t\) in a rational interval \(I\), and a positive rational piecewise-linear project-cost function \(G(q)\) on \(0\le q\le\mu\), find a finite partition \(q^1,\ldots,q^K\in\mathbb R_{\ge0}^{T}\setminus\{0\}\) with \(\sum_jq^j=\mu\) such that no nonzero mass vector \(r\le\sum_{j:c(q^j)>c(r)}q^j\) exists, where \(c(q)=\frac{G(q)+\min_{p\in I}\sum_tq_t|p-p_t|}{\sum_tq_t}\); if no such partition exists, decide that.

The model it lives in

A society is a distribution \(\mu\) over finitely many resident types, each with ideal location \(p_t\). A jurisdiction is a nonzero mass vector \(q\); its project cost is \(G(q)\), its efficient location cost is \(D(q)=\min_{p\in I}\sum_tq_t|p-p_t|\), and egalitarian per-capita cost is \(c(q)=(G(q)+D(q))/\sum_tq_t\). The task is to find a finite mass partition with no feasible core-blocking mass.

The objection that survived

The paper gives no scaling law connecting finite-coalition costs \(g(S)\) to the proposed mass cost \(G(q)\), and no finite high-multiplicity correspondence is established; this leaves a substantive modeling choice, though the proponent explicitly specifies \(G\) and identifies the bridge as open.

The case FOR (proponent)

The paper has no named computational result: it gives no complexity classification or efficient algorithm for an input-encoded problem. Its closest result is Proposition 1, proved here: in every finite egalitarian game as defined in the paper, there is a partition into jurisdictions such that no coalition can make all its members strictly better off. The proof constructs one by repeatedly selecting a remaining coalition with minimum per-member cost. That is a useful constructive existence proof, but it does not meet your anchor rule. Proposition 2, also proved here, says a Nash-stable partition can fail to exist even with a one-dimensional project space; it is likewise an existence result, not a computational one.

The strongest plausible computational question nearby is Egalitarian Core Partition\(_\infty\). Consider a large metro population with a finite set \(T\) of complete resident types: everyone of type \(t\) has the same ideal project location \(p_t\) and the same relevant costs. The input gives rational masses \(\mu_t\) summing to \(1\). A jurisdiction is a mass vector \(q\in\mathbb R_{\ge0}^{T}\), with project cost \(G(q)\), location cost
\[ D(q)=\min_{p\in I}\sum_{t\in T}q_t\,|p-p_t|, \]
and egalitarian per-capita cost
\[ c(q)=\frac{G(q)+D(q)}{\sum_t q_t}. \]
For a concrete computational version, take a rational one-dimensional interval \(I\), rational locations, and a positive rational piecewise-linear description of \(G\). Let the solution be a finite list of jurisdiction vectors \(q^1,\dots,q^K\) summing to \(\mu\), with their locations and costs. It is core-stable if there is no nonzero mass vector \(r\) that can be drawn entirely from residents whose current jurisdiction costs exceed \(c(r)\). The task is to find such a partition, or report that none exists.

This changes the population itself to a distribution; the project location was already continuous in the paper. The dependence of \(G\) on jurisdiction mass is part of the model, as is the fractional mass of each type assigned to a jurisdiction. A plausible regime is a city or region with many residents across a small number of ideal-location and cost types. The shared-type assumption fits the paper’s model, where location identifies preferences and project costs need not depend on individual identity.

My tentative direction for the specified one-dimensional, piecewise-linear version is Class A, if selecting low-cost coalition mass vectors and extending the greedy construction can be reduced to tractable optimization. But that is a research conjecture, not a consequence of Proposition 1. Its finite proof may rely on removing whole finite coalitions; with divisible masses, a cheapest coalition need not exhaust any type. Establishing existence of a finite stable partition, and bounding the cost of finding one in \(\tau\) and the input bit length, are the central questions. The key further bridge is whether stable partitions of these mass populations correspond to stable partitions in finite high-multiplicity instances.

That is my weakest point, and the reason this is only a modest positive case: the paper’s nearest named result is not computational, and the move from its finite constructive proof to an efficient continuous algorithm is unproved. The paper already studies continuous *outcomes*; the proposed question is relevant only because it makes the *population* continuous.

The case AGAINST (opponent, writing after the proponent)

The strongest case against a mirror is that the paper contains no computational result to continue. Proposition 1 proves that a core stable partition exists, using the common ranking of coalitions; its proof repeatedly chooses a cheapest coalition and removes its members. Proposition 2 gives a six-agent example where Nash stability fails. Neither result studies an encoded input, an algorithm, or complexity. So an “Egalitarian Core Partition\(_\infty\)” problem would be a new algorithmic project built from Proposition 1, not a continuous version of a computational problem the paper posed.

The proposed core problem is nevertheless the best possible mirror, and its population story works: many residents grouped by shared ideal location are a plausible high-multiplicity regime. The sharper objection is that the continuous model needs a cost-scaling choice the paper does not make. It allows \(g(S)\) to depend arbitrarily on a finite coalition’s size and composition; it gives no rule for turning that into a cost function \(G(q)\) on population masses. Fixed project costs, costs proportional to population, and other scaling laws can yield different continuous games. A piecewise-linear \(G\) makes a well-defined new problem, but it is added modeling structure. A finite-population limit could supply the bridge, but only after specifying how project costs scale with population and how core stability behaves under that limit.

This weakens the claim that the proposed problem is *the paper’s* mirror. It does not defeat its value: the programme explicitly allows co-modification when continuization requires it, and establishing that bridge could itself be worthwhile. Nor does the finite termination issue in Proposition 1’s proof settle the matter: it shows that the greedy proof does not directly give a finite algorithm for mass partitions, but adapting or replacing it is precisely part of the proposed research question.

Proposition 2’s Nash result offers a firmer objection to a different mirror. In a nonatomic population, a single agent has zero mass, so moving that agent does not change jurisdiction masses or aggregate costs. An individual-deviation version of Nash stability can therefore become vacuous or ill-defined, especially for deviations to an empty jurisdiction. Replacing an individual deviation with a positive-mass cohort deviation would restore substance, but it would change the stability notion that Proposition 2 studies.

I would not claim the universal negative has been established. The lack of a computational result is a strong reason to describe the core proposal as a new research direction rather than a direct mirror, and the Nash mirror degenerates under nonatomic deviations. But Proposition 1’s mass-core version remains a credible continuous-population question. The honest anti-case is weak against that anchor, which passes the programme’s high-multiplicity test.
