The continuous mirror question

Given a finite type set \(T\), rational masses \(\mu_t>0\) summing to \(1\), and a finite offer menu of products \(j\) and group sizes \(k\le K\), each type has a strict ranking of offers and a nonempty set of individually rational offers. For each group composition \(a\in\mathbb{Z}_{\ge 0}^{T}\) with \(\sum_t a_t=k\), let \(y_{a,j}\ge 0\) be its group rate per capita. Require \(\sum_{a,j}a_t y_{a,j}=\mu_t\) for every type and permit a composition only when each included type accepts offer \((j,k)\). Find a feasible group-rate vector minimizing the maximum, over all types with \(a_t y_{a,j}>0\), of \(d_t(j,k)\), the number of more-preferred individually rational offers for type \(t\).

The model it lives in

Buyers still receive whole units and form finite-size groups; the number of groups of each type composition is fractional per capita. Type masses obey mass conservation, and each type's rank for a product and group size determines its distance to ideal.

The objection that survived

Without cross-type coupling, each type can assemble its top-ranked offer in pure-type groups, making the continuous optimum zero; the proponent does not address this.

fatal: False

What the mirror covers

The mirror covers Proposition 2's minimax guarantee and Proposition 1's Pareto guarantee. It leaves the message bound, empirical runtime and memory results, and behavior-change findings unmirrored.

The case FOR (proponent)

The paper’s strongest numbered anchors are algorithmic guarantees, not complexity classifications. It gives no numbered result asserting that a problem is NP-hard or in P. It does say in §§1 and 4.2 that finding a coalition structure is equivalent to exact set cover and cites Garey and Johnson (1979) for NP-hardness. That is useful background, but it is not a numbered result proved in this paper, so I would not present it as the required hardness anchor.

A credible regime is a large online marketplace where many buyers purchase one unit each from the same product category. A type records everything the paper’s problem uses about a buyer: their strict ranking of product and group-size offers, reservation price, and relevant constraints. The population is described by type masses \(\mu_t\), with many actual buyers per type. Buyers still receive whole products; only the number of groups of each kind becomes fractional in the high-multiplicity limit. This is recognizably the paper’s group-buying problem: buyers form groups, discounts depend on group size, and payoffs are non-transferable. A finite maximum contract size \(K\) makes the regime concrete—for example, a supplier might offer group discounts only up to a capped lot size.

The lead anchor is Proposition 2, proved in this paper. Assuming each buyer’s list of individually rational buying groups has no ties, it says that the protocol’s chosen partition minimizes the worst distance to ideal among all feasible partitions of the agents ready to propose. A buyer’s distance is the number of groups they proposed before the group they end up in. The result concerns the protocol’s actual coalition-formation problem, rather than the encoding used to search for partitions.

The corresponding continuous question is Continuous Minimax-Regret Group Buying. An instance has a finite type set \(T\), rational masses \(\mu_t\) summing to one, products \(j\), and offers indexed by product and group size \(k\le K\). Each type has a strict ranking of those offers, including a personally rational solo-purchase offer. A group configuration \(a\in\mathbb Z_{\ge0}^{T}\) specifies how many buyers of each type are in one group, with \(\sum_t a_t=k\). Let \(y_{a,j}\ge0\) be the number of such groups per capita. Feasibility requires \(\sum_{a,j} a_t y_{a,j}=\mu_t\) for every type \(t\), and every type included in a group must find its offer individually rational. If \(d_t(j,k)\) is the number of more-preferred individually rational offers for type \(t\), the problem is to find a feasible \(y\) minimizing \(\max\{d_t(j,\sum_s a_s): y_{a,j}>0,\ a_t>0\}\). The solution is the rational group-rate vector \(y\) and its optimum worst distance.

I expect this question to be Class A for the stated regime. For any proposed bound on worst distance, feasibility is a configuration LP. It has potentially many columns, one per group composition and product, but the pricing question is simple in this model: for a product and group size, each participating type must find that offer acceptable, and the column’s coefficient for each type is additive. One can price a column by choosing the best eligible types under the LP’s dual prices. That is the kind of separation task that can make an exponential-column LP tractable. The relevant algorithmic parameters would include the number of products, types, offer sizes, and the bit length of the rational masses and prices.

A second, related anchor is Proposition 1, also proved here. It says that, among partitions found in the first round in which any partition exists, one minimizing the sum of buyers’ distances to ideal is Pareto-optimal, again assuming no tied preferences. Its continuous counterpart is Continuous Pareto Group Buying: on the same instances, first minimize the worst distance, then among those solutions minimize aggregate distance, \(\sum_{a,j}y_{a,j}\sum_t a_t d_t(j,\sum_s a_s)\). Return an optimal mass allocation and determine whether it is Pareto-optimal under agentwise comparison: no other feasible allocation can make almost every buyer weakly better off and a positive mass strictly better off. I expect this lexicographic LP question to be Class A too. With strict rankings, a Pareto improvement cannot worsen anyone’s rank; it would either lower the worst rank or preserve it while lowering aggregate rank, contradicting lexicographic optimality.

These are two related questions rather than two claims that the paper proves a continuous algorithm. The paper’s propositions concern finite partitions; the LP and its tractability are the continuous mirrors to investigate. The cited exact-set-cover hardness makes the central research question meaningful: does the combinatorial difficulty of assembling discrete covers disappear when group counts are allowed to vary continuously? Further questions include the integrality gap when converting an optimal mass allocation back to a finite buyer population, how large a population is needed for accurate rounding, and whether pricing stays tractable when group feasibility depends on composition rather than only on product and size.

The mirror covers the paper’s formal guarantees about minimax distance and Pareto efficiency. It does not mirror the empirical results about execution time, memory use, or changes in consumer behaviour, nor does it claim that all non-transferable coalition formation has this structure.

The weakest point is the group-size co-modification. The paper’s discounts depend on absolute group size, so the continuous model needs many finite-sized groups and a fractional rate of such groups—not one giant coalition whose size is a fraction of society. That is plausible for a large buyer base with capped discount contracts, but it narrows the scenario. The authors should recognize the resulting question as theirs because the agents, offers, discount mechanism, and solution criteria remain the same; the relaxation is in how many groups of each composition the population forms.

The case AGAINST (opponent, writing after the proponent)

The clean finite-capacity marketplace in the case for is exactly where both guarantees collapse. For each type \(t\), take its highest-ranked individually rational offer, say product \(j_t\) at group size \(k_t\). In the proposed mass model, make groups consisting only of type \(t\): set \(y_{k_t e_t,j_t}=\mu_t/k_t\), where \(e_t\) is the unit vector for that type. This uses all of type \(t\)’s mass and gives every member their best offer. Repeat independently for each type. The mass constraints hold, and every type gets distance zero.

That defeats the mirror of Proposition 2: the continuous minimum worst distance is automatically zero. It also defeats the proposed mirror of Proposition 1: total distance is zero and the allocation is Pareto-optimal, since no type can improve on its best offer. The configuration LP and pricing problem are beside the point; the optimum is explicit before either is built.

This is not a quirk of choosing a cap \(K\). With positive mass of each type, a large finite population contains many buyers of that type, enough to form groups together. A cap makes the argument especially clear, but even if group size can grow, buyers of one type can form a group among themselves. The paper’s one-unit restriction makes group size and product determine the offer; it gives no seller capacity or other coupling that would force different types to compete for groups. Under its own preference model, identical-type buyers have no reason to compromise with one another.

The finite protocol’s max-distance result does not transfer cleanly through this relaxation. If a finite type count is not divisible by \(k_t\), some buyers may be left over; the mass model can assign a fractional number of groups and erase that remainder. For an average-distance objective the leftover fraction might vanish as the population grows, but Proposition 2 is about the worst-served agent, so even a few leftovers can matter. Keeping those individuals as separate types preserves the finite issue only by making the support grow with the population, losing the useful high-multiplicity regime.

The same structure neutralizes the paper’s exact-set-cover motivation. Its combinatorics come from assigning named agents to overlapping groups. In the high-multiplicity version with a fixed set of complete preference types, pure-type groups sidestep those conflicts. To preserve arbitrary identity-specific restrictions, one would need to encode those identities in the types, so the number of types grows with the population. Adding seller quotas or composition-dependent eligibility could make a continuous group-buying problem nontrivial, but those constraints are absent from this paper and would supply the coupling that its model lacks.

So the negative case is strongest against mirrors of the paper as written: both named guarantees become trivial, while a nontrivial version needs either a different objective or additional market constraints. It is not an airtight claim that no worthwhile continuous group-buying problem exists; a well-motivated capacity-constrained extension might be worth studying. That would be a new model, not a compelling mirror of these results.
