The continuous mirror question

Given a finite support \(U\) of candidate types \(u=(a_u,p_u)\), rational masses \(\mu_u>0\) summing to \(1\), a committee mass \(\kappa\), and normalized lower quotas \(q_i\), choose \(x_u\in[0,\mu_u]\) with \(\sum_u x_u=\kappa\). Let \(z_i=\sum_u a_{u,i}x_u\). Return an allocation satisfying both conditions: there are no types \(u,v\) with \(p_u>p_v\), \(x_u<\mu_u\), and \(x_v>0\) such that \(z_i>q_i\) for every attribute \(i\) held by \(v\) but not \(u\); and there is no feasible exchange of any amount \(0<\epsilon\le\min(\mu_u-x_u,x_v)\) from selected type \(v\) to type \(u\) whose resulting attribute vector strictly dominates \(z\). Extend domination to real-valued counts by requiring each already-met quota to remain met, each unmet quota either to be met or to have its shortfall weakly reduced, with at least one strict improvement.

The model it lives in

A high-multiplicity applicant pool represented by candidate types combining diversity attributes and priority tier, with mass \(\mu_u\) per type. The decision variable \(x_u\) is the selected mass; committee mass and quotas scale with the pool, and individual selections remain integral while type-level averages may be fractional.

What the mirror covers

The mirror covers the two guarantees for Algorithm 1: justified envy-freeness and type optimality. It does not mirror the paper’s unnumbered remarks about global type-distribution optimality or hard-constraint feasibility.

Open questions for a prover

  • Does every such instance admit an allocation satisfying both mass-level axioms?
  • If one exists, can it be found in time polynomial in the attribute count, support size, and input bit length?
  • How closely can these mass guarantees be preserved when rounding to finite cohorts?

The case FOR (proponent)

The strongest mirror I see is a large candidate pool, not a continuous electorate. Think of a scaled admissions or scholarship programme: many candidates share the same relevant attributes and priority tier, and both the number selected and the diversity quotas scale with the pool. Let a candidate type be the full pair \((a,p)\), where \(a\in\{0,1\}^{d}\) records the candidate’s diversity attributes and \(p\) is their priority tier. Candidates of one type are interchangeable under the paper’s rules. A useful regime has \(n\gg s\), where \(n\) is the number of candidates and \(s\) the number of distinct types. This fits the paper’s weak-order model, but only when many candidates genuinely share a priority tier; a strict ranking that gives everyone a distinct position would leave no high-multiplicity gain.

The excerpt does not render proposition counters, so I identify its two proposition environments by order as Proposition 1 and Proposition 2. Both are proved in the paper. Proposition 1 says that Algorithm 1 returns, in time \(O(|C|^2)\), a committee satisfying justified envy-freeness. Proposition 2 says that Algorithm 1 returns a committee satisfying type optimality. The paper has no numbered hardness result to anchor on, so I would not elevate its unnumbered NP-completeness remarks into anchors.

My lead mirror is Continuous Soft-Diversity JEF Search, for Proposition 1. An instance gives a finite support \(U\) of complete candidate types; rational masses \(\mu_u>0\) summing to \(1\); a priority order on the types; a committee mass \(\kappa\); and normalized lower quotas \(q_i\) for each attribute. The decision variable is \(x_u\in[0,\mu_u]\), the mass selected from type \(u\), with \(\sum_u x_u=\kappa\). Write \(z_i=\sum_u a_{u,i}x_u\) for the selected mass of attribute \(i\). The task is to return an allocation with no justified envy: there must not be an excluded type \(u\) and selected type \(v\), with \(u\) higher priority than \(v\), for which there is no attribute \(i\) held by \(v\) but not \(u\) with \(z_i\le q_i\). The decision is group-level mass selection; individuals remain selected or unselected. The paper gives no scalar objective to preserve, so this is an axiom-satisfaction search problem, not a newly invented welfare maximization problem.

The second question is Continuous Local Type-Optimality Search, for Proposition 2, on the same inputs. Here the task is to return \(x\) such that no positive feasible exchange of mass from a selected type \(v\) to an excluded type \(u\) makes the resulting attribute-count vector strictly dominate the current one under the paper’s quota-based definition. Extend that definition from integer counts to real masses: meeting a quota remains meeting it, and for an unmet quota a type must either reach the quota or move no farther from it; at least one type must improve strictly. An exchange of size \(\epsilon\) is feasible when \(0<\epsilon\le\min(x_v,\mu_u-x_u)\). This is the continuous counterpart of the paper’s one-candidate swap test, rather than a global search over arbitrary committees.

I would expect both questions to be Class A targets, though that is a research hypothesis, not a consequence of the paper’s proofs. The paper’s conditions depend on type counts and priority comparisons, so the continuous instances retain a finite type-level description instead of one decision variable per named candidate. A successful result would need to give an algorithm polynomial in the number of attributes, support size, and input bit length. The local-optimality and envy conditions can create disjunctions, so aggregation alone does not establish tractability.

The mirror is plausible because type membership, priority, lower quotas, and candidate swaps are the paper’s actual ingredients. Scaling committee size and quotas is a co-modification required to make mass selection meaningful, not a change of the central question. The mirror covers these two algorithmic guarantees; it does not turn the paper into a voting-electorate result.

The weakest point is the regime. Many committee applications select a small fixed number of people from a much larger pool, or rank every candidate distinctly. In either case the continuous mirror may be a poor account of the original decision. The case is strongest for large cohort selections with repeated candidate profiles, shared priority tiers, and a committee size that remains a meaningful fraction of the pool. A further question for either mirror is whether its exact continuous axioms always admit a solution—and, if they do, whether a solution can be computed efficiently and rounded to discrete committees while preserving the guarantees.

The case AGAINST (opponent, writing after the proponent)

The best negative case is that the paper’s algorithm acts on a finite slate of candidates, not on an electorate. Its input is already a priority order over candidates; voters appear only in the closing suggestion that such an order *could* be derived from voting. So a continuous electorate would be an added model layer, and the paper’s results say nothing about computing over it. The proponent avoids that problem by making the candidate pool itself continuous. That is a coherent high-multiplicity model, but it is a borderline fit for ChoCo’s central object: a society represented by a distribution over voter types.

Proposition 1 is a real algorithmic anchor: Algorithm 1 returns a justified-envy-free committee in \(O(|C|^2)\). Its guarantee, however, compares an excluded candidate directly with a selected candidate. Proposition 2 guarantees type optimality for the same output, using the same one-candidate swap notion. They are not independent computational results; together they describe one finite algorithm and its output. In a mass model, the natural replacement is to select a positive mass from each candidate type and compare excluded and selected mass by priority and attributes. That preserves the substance better than literal atomless envy or infinitesimal swaps would.

The strongest objection to that replacement is granularity. If committee size stays fixed as the candidate pool grows, selected mass vanishes; if committee size and quotas scale with the pool, the model becomes selection from a large cohort of repeated candidate profiles. The latter can be a sensible admissions or scholarship regime, especially with shared priority tiers. It also respects integral selection for each candidate: only the type-level average becomes fractional. So neither degeneration nor loss of identity defeats the best version of the mirror.

The scope objection is also not decisive. A candidate pool is not the voter society specified by ChoCo’s central model, and treating candidates as the population changes what is continuous. But the paper’s core task is committee selection under candidate attributes and priorities, and a mass version of that task is recognizable as diverse committee selection. The author could reasonably regard it as their problem. The shared programme also allows model co-modifications when they are needed to make population mass meaningful.

So I cannot honestly establish the requested universal negative. The paper-native voter-population mirror is weak because the paper does not model voters, and both proposed anchors depend on candidate-level exchanges. But a scaled candidate-cohort mirror can address both propositions with one mass-selection problem. The case against that mirror rests mainly on whether candidate supply counts as the programme’s “population,” not on a fundamental obstruction. If that interpretation passes the programme’s scope gate, at least one anchor survives.
