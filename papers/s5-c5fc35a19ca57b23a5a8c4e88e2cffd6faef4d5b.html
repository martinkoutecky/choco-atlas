The accompanying algorithm is unnumbered, so the paper lacks the required named computational result, even though the proposed replication model is plausible.

What the mirror covers

The proposed replication question concerns the integer nucleolus of directed weighted simple games; it leaves the prenucleolus and generalized-game extensions aside.

Open questions for a prover

  • For which inputs do the type-average nucleoli converge to a single limit rather than multiple subsequential limits?
  • Can the limit set be approximated in Hausdorff distance within \(\varepsilon\), and what is the complexity in \(\tau\) and the input bit length?

The case FOR (proponent)

The strongest mirror I see is a replication limit of the integer nucleolus for large weighted voting games. I would anchor it on Corollary 1, proved in this paper: for a directed simple game \(\Gamma_t\) with a nonempty integer imputation set, its integer nucleolus is exactly the set of images of one payoff vector \(y\) under all symmetries of the game. Here \(y\) is the unique nucleolus element whose payoffs weakly preserve desirability, so \(y_1\ge\cdots\ge y_n\). Section 3’s algorithm computes \(y\), then generates those symmetric images.

This is a computationally used characterization, not a complexity classification. The paper has no numbered result saying the problem is in P or is hard; its algorithm and timing experiments are unnumbered. If “anchor” is restricted to a formal complexity result or an encoding, there is no qualifying anchor here. Corollary 1 is the closest defensible one because the algorithm computes the object it characterizes.

Here is the continuous problem I would put to a prover. Call it Replication Integer Nucleolus Approximation. An instance has \(\tau\) types with rational masses \(\mu_1,\ldots,\mu_\tau>0\) summing to \(1\), integer voting weights \(w_1\ge\cdots\ge w_\tau>0\), a positive rational quota density \(q\), a positive rational resource density \(\rho\), and an accuracy \(\varepsilon>0\). For each sufficiently large integer \(N\) clearing the input denominators, form a game with \(N\mu_k\) players of type \(k\), quota \(Nq\), and a pool of \(N\rho\) indivisible units. A coalition \(S\) is worth \(N\rho\) if its total voting weight reaches \(Nq\), and \(0\) otherwise. Let \(\nu_N\) be that game’s integer nucleolus.

For \(x\in\nu_N\), define its type-average allocation by
\[ z_k(x)=\frac{1}{N\mu_k}\sum_{i:\,\mathrm{type}(i)=k}x_i. \]
Let \(\mathcal Z_\infty\) be the set of all subsequential limits of these vectors as \(N\) grows through the permitted values. The task is to return a finite \(\varepsilon\)-approximation to \(\mathcal Z_\infty\) in Hausdorff distance. Each player still receives an integer number of units in every finite game; the type-level averages and their limits may be fractional.

A plausible regime is a large federation or cooperative body allocating a pool of emergency grants or other discrete benefits. Its membership is in a few voting-weight classes, with many members in each class: \(N\) may be in the millions while \(\tau\) stays small. A type specifies the attributes relevant to the game, here voting weight and the resulting coalition role. The pool scales with membership so the per-member allocation remains meaningful. This is high multiplicity in the paper’s sense, and Corollary 1’s symmetry statement makes type-average allocations a natural aggregate of its finite-game solutions.

I would expect a tractability result for fixed \(\tau\), using type-level optimization and a separation problem over coalition masses subject to a weighted quota. That is a research direction, not a consequence of the paper: it first needs a theorem showing how the finite lexicographic nucleoli behave as \(N\) grows. If \(\tau\) is part of the input, hardness may instead come from the number of types. This mirror covers only the directed simple-game integer-nucleolus characterization; it does not claim a mirror for the paper’s prenucleolus or generalized-game extensions.

The weakest point is the limit itself. Corollary 1 characterizes each finite game, but the paper does not show that the type-average nucleoli converge, or that their limit agrees with any canonical nucleolus defined directly on an atomless population. The replication definition preserves the paper’s finite problem and avoids inventing a measure over infinitely many coalitions, but it makes the convergence and computation of the limit new questions.

The case AGAINST (opponent, writing after the proponent)

The strongest objection is that Corollary 1 is not a computational result in the programme’s sense. It characterizes the solution set through symmetry; it gives no complexity classification. Section 3’s algorithm and Section 4’s performance analysis are central contributions, but the algorithm is an unnumbered exhaustive search with timing experiments, not a theorem about its complexity. So the proponent’s anchor is the closest available, rather than a direct instance of the target the programme set.

The proposed replication problem also lacks a computational guarantee: it asks for an approximation to the set of subsequential limits, while the paper proves neither convergence nor a way to tell when a finite \(N\) is close to that set. As stated, the task may require reasoning about arbitrarily large replications. A more direct question would compute the nucleolus for a high-multiplicity instance and report type averages. That is a better-defined algorithmic task, but it is a new high-multiplicity problem, not a consequence of Corollary 1.

There is a real modelling choice behind any direct continuum version. The finite nucleolus lexicographically orders the excesses of all \(2^n-2\) coalitions. With an atomless population there are uncountably many coalitions, so there is no literal sorted excess vector. Aggregating coalitions by their type masses also discards how many finite coalitions have each composition: with \(n_k\) members of type \(k\), a composition \(a_k\) occurs \(\prod_k {n_k\choose a_k}\) times. A continuum analogue must decide how to preserve that multiplicity, perhaps through the replication limit, or define a different lexicographic objective. This is a serious obstacle to a canonical continuum nucleolus, but the replication construction gives a plausible route rather than ruling one out.

The universal negative case is weak here. A large federation with a few voting-weight classes allocating a pool of emergency grants proportional to membership is a credible high-multiplicity regime. Players within each class are indistinguishable for the game, the pool can scale with the population, and type-average allocations are meaningful even when each player’s award stays integral. There is no identity-based obstruction or degeneration that defeats that scenario. The paper’s own integer algorithm may even give the mirror a useful target: its search over integer partitions grows with the scaled resource and the population.

So I would reject the particular limit-set task as not yet specified well enough to count as a computational problem, and note that the paper supplies no named complexity theorem. But those points do not defeat the better high-multiplicity mirror. Existing high-multiplicity work supports that regime; it cannot serve as an objection to it. I cannot honestly make the case that no worthwhile continuous mirror exists in any scenario.
