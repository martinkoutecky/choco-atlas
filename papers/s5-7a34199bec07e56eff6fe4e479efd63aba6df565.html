The continuous mirror question

Given \(n\) features with \(q\) possible values each, a target outcome \(z\in[q]^n\), and a support-\(\tau\) distribution \(\mu\) over complete strict rankings of \([q]^n\), does there exist an objects scheme—feature subsets whose union covers all features, with overlaps allowed—under which \(z\) is a local optimum for weighted majority? Equivalently, determine whether \(\sum_{t:\,z\succ_t z^{i,a}}\mu_t>\tfrac12\) for every feature \(i\) and every \(a\ne z_i\), where \(z^{i,a}\) changes only feature \(i\); if so, construct a scheme.

The model it lives in

Types are complete strict rankings of outcomes in \([q]^n\), each carrying rational mass \(\mu_t\). The decision variable is a covering collection of feature subsets; feasibility means no outcome preferred to \(z\) by weighted majority can be reached by changing only the features in one object. The objective is feasibility, with no cost minimization.

What the mirror covers

The mirror covers Theorem 3.4’s local-optimum characterization; it leaves the separate global-optimum, reachability, cycle-breaking, and median-voter results unexamined.

Open questions for a prover

  • For the paper’s global-optimum and reachability questions, what is the complexity when the input is a support-\(\tau\) majority distribution and \(n\), \(q\), and \(\tau\) vary?

The case FOR (proponent)

The strongest positive mirror is a tractable one. The paper has no named NP-hardness or other hardness result to carry over. Its best computational anchor is Theorem 3.4, proved in this paper: for a target outcome \(z\), there is an objects scheme under which \(z\) is a local optimum if and only if every social outcome \(w\) preferred to \(z\) differs from \(z\) on more than one feature. The authors also point out that checking the condition requires examining only outcomes at prominent distance one from \(z\), rather than the whole outcome space.

Call the continuous version Local-Optimum Object Design. There are \(n\) features, each with \(q\) possible values, so outcomes are vectors in \([q]^n\). A voter type is a complete strict ranking of those outcomes. The input is a finite support of \(\tau\) such types, with binary-rational masses \(\mu_t\) summing to one, and a target outcome \(z\). Assume weighted majority has no ties. It defines the social relation \(w\succ_\mu z\) when the types ranking \(w\) above \(z\) have total mass greater than \(1/2\).

An objects scheme is a collection of feature subsets whose union covers all features; as in the paper, subsets may overlap. Each subset is one object, so its features can change together. The question is whether there exists a scheme making \(z\) a local optimum under \(\succ_\mu\). A solution is such a scheme, or a certificate that none exists. “Local optimum” has the paper’s meaning: no outcome preferred to \(z\) can be reached as a preferred neighbor by changing only the features in one object.

For this majority mirror, Theorem 3.4 becomes the exact criterion
\[ \forall i\in[n],\ \forall a\ne z_i:\quad \sum_{t:\,z\succ_t z^{i,a}}\mu_t>\frac12, \]
where \(z^{i,a}\) is \(z\) with feature \(i\) changed to \(a\). If any such one-feature deviation defeats \(z\), every covering scheme has an object containing that feature, making the deviation a preferred neighbor. If none defeats \(z\), the scheme of singleton-feature objects makes \(z\) a local optimum. Thus the decision and construction need \(O(\tau n(q-1))\) weighted comparison checks, plus input-reading and rational-arithmetic costs; with explicit rankings, the running time is polynomial in the input length. The solution’s objective is feasibility: find a scheme, not minimize a cost.

The population regime is a large electorate in a consultation over packages assembled from a modest set of policy features. Many participants may share the same complete ranking, while the number \(N\) of participants is much larger than the number \(\tau\) of distinct rankings. Mass records each ranking’s population share. For example, a policy team could care whether a proposed package is stable under how it groups issues for deliberation. This is a plausible high-multiplicity regime for the paper’s problem: the preference type is complete for the comparisons the problem uses, and the authority’s decision variable remains the way features are bundled.

I expect this mirror to be tractable. It is a direct high-multiplicity version of the theorem’s local-stability question, and it preserves the object-construction mechanism the authors study. Its limits matter: the result establishes local stability, not reachability from a specified status quo, convergence under every agenda, or global optimality. It also does not show that multiplicity makes a hard problem easy; the same local check is efficient for a finite list of voters.

A natural next question is how much campaign effort is needed to make \(z\) locally stable. Give transitions between ranking types costs, let variables transfer population mass between types, and require \(z\) to beat every one-feature deviation by a specified rational margin. With a finite set of reachable types, this yields a linear optimization question over mass transfers. Another follow-up is whether a chosen status quo can be routed to \(z\) by some scheme and agenda—the basin-of-attraction question treated for finite societies in Theorem 3.12, and a richer continuous mirror to investigate.

The weakest point in this case is that the paper’s social relation is general, while the continuous mirror derives it from weighted majority over ranking types. That is a natural instance of the paper’s model, but it narrows the aggregation rules covered. The case covers Theorem 3.4’s local-optimum result, not the paper’s broader claims about cycles, global basins, or the median voter.

The case AGAINST (opponent, writing after the proponent)

The best objection is that the proponent’s anchor, Theorem 3.4, is a structural characterization, not a complexity result. Its condition reduces local optimality to checking outcomes that differ from \(z\) in one feature. If those checks pass, the singleton-feature scheme is already a witness; if one fails, no scheme can work. With a weighted population, each check is just a majority calculation over the \(\tau\) types. The proposed mirror is valid, but it adds no substantial design or optimization problem for continuous methods to solve.

That does not make the population model incoherent. A large consultation over policy packages could plausibly have many participants sharing complete preference rankings. Nor is high multiplicity itself an objection. The narrower concern is that the theorem’s computational core is already a short local test. The claimed \(O(\tau n(q-1))\) comparison count also assumes those comparisons can be accessed cheaply; explicit rankings over \(q^n\) outcomes have a much larger representation. Counting the input-reading cost fixes that accounting issue, but does not create a harder computational question.

A stronger mirror would ask whether a target is reachable from a given status quo, or is globally optimal across agendas, using the weighted majority relation. Those questions connect to Theorems 3.12 and 3.8. The paper already gives a finite construction for reachability, however, and the continuous version feeds weighted pairwise comparisons into the same outcome-space procedure. Its remaining computational burden lies in the feature space and the object schemes. Studying that burden could be worthwhile, but it would be a new complexity analysis of the paper’s procedure, rather than a complexity result the paper itself establishes. Campaign costs, object budgets, or robustness margins would be further new questions.

This is a weak negative case. It supports saying that the paper offers little ready-made computational complexity to continuize, and that Theorem 3.4’s mirror may be too immediate to justify much programme time. It does not rule out a worthwhile continuous reachability study under a plausible population model. I cannot honestly defend the universal claim that no scenario yields one.
