The continuous mirror question

Given candidates \(C\), committee size \(k\), and \(\tau\) supported approval sets \(A\subseteq C\) with positive rational masses \(\mu_A\) summing to \(1\), output a committee \(W\subseteq C\) of size \(k\) such that (i) for every \(c\in C\setminus W\), \(\sum_{A:\,c\in A,\,A\cap W=\emptyset}\mu_A<1/k\), and (ii) there is no size-\(k\) committee \(W'\) with \(|A\cap W'|\ge |A\cap W|\) for every supported type \(A\), strictly for at least one type.

The model it lives in

The population is a distribution over approval-set types; the decision is a discrete size-\(k\) committee \(W\). Find any \(W\) satisfying continuous JR and type-level Pareto optimality, with no scalar objective.

The objection that survived

The opponent notes that fixed-\(k\) committee search can be done by enumerating \(m^k\) committees, which limits the relevance of the hardness to fixed-size boards.

fatal: False

What the mirror covers

Covers the all-domain search problem for committees satisfying JR and PO, and the stated PJR-and-PO consequence. It leaves welfare optimization, fractional Pareto optimality, restricted domains, and parameterized cases open.

Open questions for a prover

  • Does the search problem admit an algorithm parameterized by the number \(\tau\) of supported approval types?
  • Does hardness persist under a bound on \(\tau\), or when committee size \(k\) is fixed?

The case FOR (proponent)

My lead is Continuous JR–PO Committee Search. The society is a distribution over approval types: an instance consists of candidates \(C\), committee size \(k\), and \(\tau\) supported approval sets \(A\subseteq C\), each with positive rational mass \(\mu_A\), where \(\sum_A\mu_A=1\). A type is complete for this problem because the axioms use only the voter’s approval set. The task is to find a committee \(W\subseteq C\), \(|W|=k\), satisfying continuous JR and continuous Pareto optimality. There is no scalar objective: any qualifying committee is a solution.

For a type \(A\), let its utility be \(u_A(W)=|A\cap W|\). Continuous PO means there is no other size-\(k\) committee \(W'\) with \(u_A(W')\ge u_A(W)\) for every supported type and strict inequality for at least one. Continuous JR means that, for every unelected candidate \(c\), the total mass of voters who approve \(c\) but approve no member of \(W\) is less than \(1/k\):
\[ \sum_{\substack{A:\ c\in A\\ A\cap W=\emptyset}}\mu_A < \frac{1}{k}. \]
That is exactly the paper’s group condition after replacing “at least \(n/k\) voters” by “at least \(1/k\) of the population.” The committee remains discrete; it is the population that becomes continuous.

A plausible regime is a large membership organization electing \(k\) representatives, where many members cast the same approval ballot. Members with the same ballot are indistinguishable for both axioms. If \(N\) is the number of members and \(\tau\) the number of distinct ballots, it is natural to have \(N\gg\tau\). The continuous input records ballot shares rather than listing every member. Any fixed distribution can be realized by cloning each member type many times, increasing \(N/\tau\) without changing the instance the solver sees.

The anchor is the paper’s main Theorem. The supplied text prints the theorem environment without a numeral, so there is no theorem number to quote accurately. It is proved in this paper by reduction from X3C. Its full claim is: for any ABC voting rule \(f\) that returns a Pareto-optimal and JR committee on every finite approval-based multiwinner instance, computing \(f\) is NP-hard. The paper further states that the result persists when JR is replaced by a strengthening compatible with PO; in particular, it rules out a polynomial-time rule satisfying PJR and PO unless \(P=NP\).

This is a strong mirror because the finite instances embed exactly. Given a profile with \(n\) voters, assign each approval type mass equal to its number of voters divided by \(n\). Then the \(n/k\) JR threshold becomes \(1/k\), and type-level PO agrees with voter-level PO: identical ballots receive identical committee utility. In the paper’s X3C reduction, \(n=18t+12\), \(k=6t+4\), and \(n/k=3\). Its argument that any qualifying committee reveals the X3C answer therefore applies to the corresponding rational-mass instance as well. The reduction puts the combinatorics in the approval and candidate structure; duplicating voters does not remove it. I expect hardness transfers (Class B) for this continuous search problem.

The anchor covers the paper’s all-domain JR-and-PO search hardness, and by the paper’s stated strengthening also the PJR-and-PO consequence. It does not claim anything about optimizing welfare, fractional committees, or restricted domains. Natural follow-up questions are whether the search becomes tractable when parameterized by \(\tau\) or \(k\), and whether hardness persists under a bound on \(\tau\). The paper’s reduction establishes hardness for the general support-input problem; it does not settle those more finely restricted regimes.

The weakest point is that this is a hardness-transfer mirror, not a demonstration that continuity unlocks an algorithm. The supplied result does not establish hardness with a small number of types relative to the problem’s other parameters. Still, the mirror itself is faithful: it asks for the same committee under the same fairness and efficiency requirements, while expressing the electorate in the population proportions a large election naturally has.

The case AGAINST (opponent, writing after the proponent)

I cannot make a convincing case against the main anchor. The paper proves hardness for a computational search problem, and its reduction carries over exactly to the continuous population model.

Given a finite profile, assign each approval type \(A\) mass \(\mu_A=\#\{v:A_v=A\}/n\). Then JR is equivalent to requiring that, for every unelected candidate \(c\), the mass of unrepresented voters who approve \(c\) is less than \(1/k\). PO also carries over: voters with the same approval set have the same utility for every committee, so a strict improvement for one such voter is a strict improvement for a positive-mass type. In the X3C reduction, \(n/k=3\), so the continuous threshold is exactly the reduction’s threshold. Any continuous algorithm that returns a qualifying committee would let us read the answer to X3C from that committee just as in the finite proof.

The stronger mirror is the distribution-input search problem itself: given rational masses on approval types, output any size-\(k\) committee satisfying continuous JR and PO. A polynomial-time algorithm in \(m,\tau,L\) would solve the paper’s reduction in polynomial time. The reduction may use a growing number of types, so it does not settle a fixed-\(\tau\) regime; that is a useful further question, but it does not defeat this mirror. Cloning each type arbitrarily many times leaves the distribution unchanged, making the same instance compatible with a large membership organization.

The strongest practical reservation is narrower: if the organization elects a fixed-size board, enumerating all committees takes \(m^k\) time, polynomial in \(m\) for fixed \(k\). The paper’s hardness concerns growing \(k\), so that particular regime may not benefit from studying the mirror. But this is a limit on one scenario, not a universal objection. Treating the exact transfer as “just the same answer” also cannot carry the negative case under the programme’s stated standard: hardness transfer is an allowed and informative result.
