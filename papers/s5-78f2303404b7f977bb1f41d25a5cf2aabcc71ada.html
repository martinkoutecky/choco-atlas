The continuous mirror question

Given a candidate set \(C\), explicitly listed approval types \(T\subseteq 2^C\), rational masses \(\mu_t\ge0\) with \(\sum_{t\in T}\mu_t=1\), an integer \(\bar{k}\), and \(d\in\mathbb{Q}\), decide whether there exists an integral committee \(W\subseteq C\) with \(|W|=|C|-\bar{k}\) and \(\sum_{t\in T}\mu_t\mathbf{1}[t\cap W\neq\varnothing]\ge d\).

The model it lives in

A recurring approval electorate is represented by types \(t\in T\subseteq 2^C\) carrying rational mass \(\mu_t\); the decision variable is an integral committee \(W\), and the objective is normalized represented mass \(\sum_t\mu_t\mathbf{1}[t\cap W\neq\varnothing]\).

The objection that survived

The hardness constructions use one approval type per graph edge, so they do not establish hardness or a distinctive complexity phenomenon when the support size \(\tau\) is genuinely small relative to the candidate set.

fatal: False

What the mirror covers

The mirrors cover CCAV and PAV winner determination in Theorems 1–3, including \(\bar{k}\)-parameterized hardness and type-parameterized PAV tractability; they leave MAV, treewidth, matching, and the rest of the parameterized landscape untreated.

Open questions for a prover

The case FOR (proponent)

The strongest positive case is a high-multiplicity approval election. Keep the candidate set and committee integral; continuize only the voter population.

Let \(C\) be the \(m\) candidates and let \(T\subseteq 2^C\) be the explicitly listed approval types. A type \(t\in T\) is an approval set, and \(\mu_t\in\mathbb{Q}_{\ge 0}\) is the fraction of the population with that type, with \(\sum_t\mu_t=1\). For a committee \(W\subseteq C\), \(|W|=k\), define

\[ \operatorname{CCAV}_\mu(W) =\sum_{t\in T}\mu_t\,\mathbf 1[t\cap W\neq\varnothing] \]

and

\[ \operatorname{PAV}_\mu(W) =\sum_{t\in T}\mu_t H_{|t\cap W|}, \qquad H_j=\sum_{i=1}^{j}\frac1i,\quad H_0=0. \]

Thus the decision problem is whether there is an integral \(k\)-committee whose normalized score reaches a rational threshold \(d\). No candidate or committee is fractional.

This is plausible for a large recurring electorate: for example, millions of users, clients, or employees may fall into a few hundred approval profiles, each profile representing people who accept exactly the same representatives or service providers. The relevant regime is \(n\gg\tau\), where \(n\) is the expanded electorate and \(\tau=|T|\) is the number of distinct approval types. Rational masses have the exact finite interpretation that, after clearing denominators, \(\mu_t=n_t/n\).

My lead anchor is Theorem 2, proved in this paper. It states that CCAV-MULTIWINNER is W[1]-hard parameterized by \(\bar{k}=m-k\), the number of nonwinning candidates, even when every vote approves exactly two candidates. The problem is: given an approval election, a committee size \(k\), and a threshold \(d\), decide whether some \(k\)-committee represents at least \(d\) voters. The proof reduces from \(\kappa\)-INDEPENDENT SET: vertices become candidates, edges become two-candidate approval votes, and one asks whether a committee omitting \(\kappa\) candidates represents every edge vote.

The corresponding continuous problem is:

\[ \textsc{CCAV-Multiwinner}_{\infty} \]

Given \(C\), a support \(T\) of approval types with rational masses \(\mu\), an integer \(\bar{k}\), and \(d\in\mathbb{Q}\), does there exist \(W\subseteq C\) with \(|W|=m-\bar{k}\) such that

\[ \operatorname{CCAV}_\mu(W)\ge d? \]

In the two-approval restriction, every positive-mass type has size two. This is exactly a weighted partial vertex-cover problem. The theorem’s reduction transfers by assigning mass \(1/|A|\) to each edge type and setting \(d=1\): the committee represents all population precisely when the omitted vertices form an independent set. Hence I expect this mirror to be Class B: hardness transfers. The hardness is driven by candidate interactions, not by the number of named voters. At the same time, the model is genuinely high-multiplicity: each edge type can represent an arbitrarily large recurring cohort.

A second, independent hardness anchor is Theorem 3, also proved in the paper. It states that PAV-MULTIWINNER is W[1]-hard parameterized by \(\bar{k}=m-k\), even when every vote approves exactly two candidates. The reduction is from \(\kappa\)-MINIMUM VERTEX SUBGRAPH on regular graphs. Given a regular graph of degree \(r\), the candidates are vertices, the votes are edge types, the committee omits \(\kappa\) candidates, and the PAV threshold is

\[ d=(m-\kappa)r-\frac{\ell}{2}. \]

The question is whether the omitted set can leave at most \(\ell\) edges inside the selected subgraph.

The continuous counterpart is:

\[ \textsc{PAV-Multiwinner}_{\infty} \]

Given a rational distribution \(\mu\) over approval types, an integer \(\bar{k}\), and \(d\in\mathbb{Q}\), does there exist \(W\subseteq C\), \(|W|=m-\bar{k}\), with

\[ \operatorname{PAV}_\mu(W)\ge d? \]

For the reduction, give every edge type mass \(1/|A|\). If \(W\) contains \(\ell'\) induced edges, then

\[ \operatorname{PAV}_\mu(W) = \frac{(m-\kappa)r-\ell'/2}{|A|}. \]

Thus the continuous threshold is reached exactly when the induced edge count is at most \(\ell\). This is again Class B, but it is useful evidence beyond CCAV: even the nonlinear harmonic PAV objective aggregates naturally over population types while retaining the candidate-side hardness.

The paper also supplies a useful algorithmic anchor. Theorem 1, proved here using the cited IPWSPLT lemma, states that ANNOTATED PAV-MULTIWINNER is FPT with respect to \(n\). Its input includes a forced candidate set \(C'\), a committee size \(k\), and a threshold \(d\); it asks whether there is a \(k\)-committee \(W\) with \(C'\subseteq W\) and PAV score at least \(d\).

The continuous version is:

\[ \textsc{Annotated-PAV}_{\infty} \]

Given \(C\), approval types \(T\) with rational masses \(\mu\), a forced set \(C'\subseteq C\), \(k\), and \(d\), decide whether there is \(W\supseteq C'\), \(|W|=k\), satisfying

\[ \operatorname{PAV}_\mu(W)\ge d. \]

The paper’s proof carries over with \(\tau\) replacing the number of individual voters. Group candidates according to the subset \(U\subseteq T\) of types approving them. There are at most \(2^\tau\) candidate classes. For each type \(t\), use the integer variable \(x_t=|t\cap W|\), and impose

\[ \sum_{t\in T}\mu_t H_{x_t}\ge d. \]

The weighted harmonic function remains piecewise-linear and concave, so the same fixed-variable IPWSPLT machinery gives an FPT algorithm in \(\tau\), with polynomial dependence on the mass encoding length. I therefore expect this mirror to be Class A with respect to the number of approval types, even though the unrestricted problem remains hard in \(\bar{k}\).

The scope is deliberately limited: these mirrors cover the paper’s exact CCAV and PAV winner-determination results, especially Theorems 1–3. They do not claim to continuize the paper’s entire parameterized landscape, MAV, or its treewidth results. Natural follow-up questions include whether CCAV becomes FPT when \(\tau\) is small, whether hardness persists under genuinely compressed supports, and how the continuous model changes under robustness, candidate control, or approximation objectives.

The weakest point is that the continuous problems are close to weighted finite elections. The hardness reductions use one type per graph edge, so they do not show that hardness persists when \(\tau\) is fixed or tiny relative to \(m\). That is a limitation on novelty, not on legitimacy: the model is still the authors’ approval-based committee problem in the natural high-multiplicity regime, and it cleanly separates complexity caused by population size from complexity caused by selecting candidates.

The case AGAINST (opponent, writing after the proponent)

The strongest negative case is not that these mirrors are ill-defined. They are well-defined, and approval elections plainly admit high-multiplicity interpretations. It is that, for this particular paper, continuization adds no population-level object beyond a weighted encoding of the original finite election.

For any finite approval election, let \(n_t\) be the number of voters with approval type \(t\), let \(N=\sum_t n_t\), and put \(\mu_t=n_t/N\). Then, for every committee \(W\),

\[ \frac{\operatorname{CCAV}(V,W)}{N} =\sum_t \mu_t\mathbf 1[t\cap W\neq\varnothing] \]

and

\[ \frac{\operatorname{PAV}(V,W)}{N} =\sum_t \mu_t H_{|t\cap W|}. \]

Conversely, every rational \(\mu\) is obtained from such a finite election by clearing denominators. Thus the proposed continuous problems are exactly weighted finite CCAV and PAV instances. This observation alone is not a valid objection under the programme’s rules: high-multiplicity work is supporting evidence, not a novelty collision. But here it is unusually damaging because all three anchors depend only on these aggregate scores and an integral committee. No intervention transports mass, no feasibility constraint acts on population mass, and no identity-sensitive objective survives the quotient.

Theorem 2 therefore becomes weighted partial vertex cover. With two-approval types, the masses are simply edge weights:

\[ \operatorname{CCAV}_{\mu}(W) =\sum_{e\in E}\mu_e\mathbf 1[e\cap W\neq\varnothing]. \]

The proponent’s reduction gives every edge its own type, so \(\tau=|E|\). That is a weighted graph representation of the original reduction, not a compressed population regime. If one insists on genuinely small \(\tau\), every candidate is described only by the subset of types approving it; candidates with the same description are interchangeable, and there are at most \(2^\tau\) candidate signatures. The graph structure used by the W[1]-hardness reduction has then been quotiented away. Hence the rich-support version merely reproduces the finite problem, while the compressed-support version is a different, heavily symmetrized problem. Neither gives a new continuous population phenomenon.

The same objection applies to Theorem 3. For two-approval types,

\[ \operatorname{PAV}_{\mu}(W) =\sum_{e\in E}\mu_e H_{|e\cap W|}, \]

so the continuous problem is simply weighted PAV on a graph. The normalized regular-graph reduction transfers exactly, but only because the mass vector is an alternative notation for edge multiplicities. Again, allowing one type per edge preserves the original combinatorics rather than exposing a population-level obstruction; forcing few types destroys the incidence structure on which the theorem is built.

Theorem 1 is the strongest possible rescue, but it is also the least genuinely continuous. Its proof already identifies voters only through the subsets of voters approving each candidate. In the proposed model one introduces an integer \(y_S\) for the number of selected candidates with type-incidence signature \(S\), where \(S\subseteq T\), and obtains

\[ x_t=\sum_{S\ni t}y_S, \qquad \sum_S y_S=k, \qquad \sum_t \mu_t H_{x_t}\ge d. \]

After clearing denominators, this is the same bounded-variable integer formulation with rational coefficients. The claimed FPT result in \(\tau\) is plausible, but it is a symmetry quotient and coefficient substitution in the paper’s existing argument, not a new continuous optimization problem. A richer latent continuum of voter attributes would not help: since the rule observes only approval sets, the attributes collapse back to at most \(2^{|C|}\) approval types unless one adds new structure absent from the paper.

Thus the negative case is that every proposed mirror falls into the same dichotomy: with many types it is an exact weighted restatement of the finite election; with few types it removes the incidence structure responsible for the paper’s results. There is no intermediate model in which the population is genuinely continuous while the paper’s computational contribution remains intact.

That is a serious case against investing in this paper as a flagship continuization target. It is not, however, an airtight universal rejection. The high-multiplicity approval model is natural, and Theorem 1 could support a worthwhile study of type-compressed PAV. Under the programme’s stated standards, I would therefore describe the negative verdict as weak: these are arguably modest mirrors, but I cannot honestly claim that no worthwhile continuous mirror exists.
