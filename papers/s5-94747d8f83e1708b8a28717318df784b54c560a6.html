What the mirror covers

The candidate model covers fractional housing allocations in a high-volume market, but none of the paper’s axiomatic impossibility results supplies a computational result for that population setting.

The case FOR (proponent)

The strongest positive lead is a high-volume time-share housing market: many residents have complete preference-and-endowment types, where a type records both a ranking of houses and its per-capita rights vector. The population would be a rational distribution \(\mu\) over those types, and an allocation schedule \(x_{t,h}\) would specify each type’s per-capita share, with feasibility requiring \(\sum_t \mu_t x_{t,h}=\sum_t\mu_t e_t(h)\). That is a plausible population-continuous version of the setting.

But the paper has no named computational result to anchor that mirror. Its main result, Theorem 1, proved here, is an axiomatic impossibility: no fractional housing-market mechanism can be simultaneously weakly SD-strategyproof, SD-efficient, and SD-individually rational, even with strict preferences and single-unit endowments and allocations. Corollaries 1–3 state related impossibilities, attributed to earlier results. None classifies a computational problem as tractable or hard.

The proposed market would preserve the theorem’s axioms, but strategyproofness is a serious modeling gap. In an atomless population, one person’s report has zero mass, so a mechanism defined only by \(\mu\) does not see that deviation; treating a whole type mass as the deviator instead changes individual strategyproofness into bloc or coalition strategyproofness. Theorem 1’s proof relies on deviations by named individuals, so it does not settle either continuous version.

Thus I can offer a credible scenario for a *new axiomatic population question*, but not an anchored ChoCo computational mirror. The paper’s fractional assignments and endowments are already present while its society remains finite; those do not themselves continuize the population.

The case AGAINST (opponent, writing after the proponent)

The proposed time-share housing market is a plausible high-multiplicity model: a type can include both a preference ranking and a per-capita endowment vector. But it gives ChoCo no computational result to mirror. Theorem 1 and Corollaries 1–3 are impossibility statements about the compatibility of axioms; none asks for an algorithm or classifies a computational problem. The paper’s remark that SD-IR and SD-efficiency can be obtained by constrained utility maximization does not supply one: it neither studies computational complexity nor addresses strategyproofness.

The best version of the proposed mirror would ask whether SD-individual rationality, SD-efficiency, and weak SD-strategyproofness can coexist for a society described by type masses. That is a coherent new axiomatic question, but it runs into a basic mismatch with Theorem 1. In a mechanism whose outcome depends only on an atomless population distribution, one person’s report changes no mass, so individual strategyproofness is vacuous. Making a whole positive-mass type the deviator gives a bloc-incentive condition, which is a different axiom. Keeping named individuals influential instead requires information beyond the aggregate type distribution. None of these formulations turns the paper’s impossibility result into the computational question ChoCo studies.

So the negative case is strong on programme fit, not on the plausibility of the market scenario: the paper’s axioms may inspire worthwhile population-level research, but its named results do not anchor a computational continuous mirror. The fractional assignments and endowments do not change that; they make allocations fractional while agents and deviations remain individually specified.
