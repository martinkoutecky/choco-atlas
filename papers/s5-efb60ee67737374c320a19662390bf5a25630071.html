What the mirror covers

The proposed problem concerns computing stable, maximum-surplus allocations; it does not computationally mirror Proposition 1 or Theorems 1–3, which give axiomatic results.

The case FOR (proponent)

The strongest positive opening is at the model level. A large labor or collaboration platform could match millions of people in pairs, with a modest number \(\tau\) of complete worker types. People of type \(a\) would share the same relevant qualifications and the same surplus \(v_{ab}\) from pairing with type \(b\). Let \(\mu_a\) be type \(a\)’s population share. This is a plausible high-multiplicity regime for the paper’s one-sided matching model.

A concrete computational extension would be: given the rational masses \((\mu_a)\) and symmetric pair surpluses \((v_{ab})\), find a stable, maximum-surplus allocation, or report that none exists. The decision variables are pair masses \(x_{ab}\) and per-agent type payoffs \(u_a\). Pair mass \(x_{ab}\) uses that much of each type’s population; \(x_{aa}\) uses \(2x_{aa}\) of type \(a\). Stability requires \(u_a+u_b\ge v_{ab}\) and \(2u_a\ge v_{aa}\); unused mass gets its zero reservation payoff. The matching problem and its payoff constraints form a primal-dual LP with \(O(\tau^2)\) variables and constraints, so this proposed continuous problem is tractable. It is a computational question about the paper’s core and stable outcomes, not about continuity of the solution as values change.

That is a plausible extension, but it has no qualifying named anchor in this paper. Theorem 1, proved here, says that on solvable problems a core subsolution satisfying dummy-agent indifference, continuity, and consistency must equal the core. Theorem 2, also proved here, gives the analogous conclusion using Pareto indifference and consistency. Theorem 3, proved here, says that no solution on all one-sided assignment problems can both agree with the core whenever it is nonempty and satisfy consistency. These are axiomatic characterization and impossibility results; none asserts computational complexity or an algorithm. In particular, “continuity” in Theorem 1 concerns changes in the value function, not a continuous population.

So the honest positive case is limited: the paper’s model motivates a sensible continuous-population core-computation problem, and a type-pair valuation regime makes that mirror concrete. But the computational question would be a new extension of the paper’s model, not the mirror of one of its named computational results. Since there are no qualifying anchors, there is no compliant one-question-per-anchor set to provide.
