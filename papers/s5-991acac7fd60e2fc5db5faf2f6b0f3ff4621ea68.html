The continuous mirror question

Given finitely many agent types \(A\) and item classes \(O\), each type \(a\) has rational mass \(\mu_a>0\), an initial class \(o_a\), and a strict preference list of length at most four; the masses sum to \(1\), and all types may trade with one another. A state records \(y_{a,o}\), the mass of type \(a\) holding class \(o\). A legal step chooses types \(a,b\), classes \(o,p\), and rational mass \(q>0\) currently held in those type-class pairs, with \(p\succ_a o\) and \(o\succ_b p\), and exchanges mass \(q\) between the two classes. Given a target type \(a^\star\), target class \(o^\star\), and rational threshold \(0<\varepsilon\leq\mu_{a^\star}\), is there a finite sequence of legal steps after which \(y_{a^\star,o^\star}\geq\varepsilon\)?

The model it lives in

A complete exchange market represented by finitely many preference-and-initial-item types with rational masses. The state variables are type-level holdings \(y_{a,o}\); each decision exchanges an equal rational mass \(q\) between two types holding mutually preferred classes. There is no cost objective; the question is whether a target type can reach the target class with mass at least \(\varepsilon\).

The objection that survived

The target is now a positive cohort rather than one designated agent receiving a unique object, and mass can split across routes, so Theorem 3’s consistency gadgets may not survive.

The case FOR (proponent)

My lead is a positive-share version of REACHABLE OBJECT, anchored on Theorem 3. It states that REACHABLE OBJECT is NP-complete on complete graphs even when every preference list has length at most four. The paper proves the hardness here, by reduction from a restricted \(3\)-SAT variant; membership in NP follows from Proposition 1. The complete graph is useful for this mirror: all agents can trade with all others, so the model does not depend on inventing a continuum analogue of a sparse social network.

Imagine a large exchange market for standardized, indivisible goods. Each household contributes one item, and many households have the same strict preferences and start with the same kind of item. A platform lets any pair propose a bilateral swap. For example, a type records a household’s preference order over item classes and its initial item class. The \(N\) households may be numerous while the number \(\tau\) of distinct types is comparatively small. Members of a type remain ordinary agents: every unit of mass holds one indivisible item and improves strictly whenever it swaps. Fractional quantities describe how many households undergo a trade, not fractional items received by a household.

Here is the question I would give a prover.

Positive-Share Reachable Object. An instance consists of finite sets of agent types \(A\) and item classes \(O\); for each \(a\in A\), a strict preference order \(\succ_a\) over the classes that type accepts and its initial class \(o_a\); rational masses \(\mu_a>0\) summing to \(1\); a target type \(a^\star\), target class \(o^\star\), and rational threshold \(\varepsilon\) with \(0<\varepsilon\leq\mu_{a^\star}\). All agents may trade with one another. Ask whether there is a finite sequence of mutually beneficial swaps that leaves at least \(\varepsilon\) mass of type \(a^\star\) holding class \(o^\star\).

Precisely, represent the current society by \(y_{a,o}\), the mass of type \(a\) holding class \(o\). Initially \(y_{a,o_a}=\mu_a\) and all other entries are zero. One legal step selects types \(a,b\), currently held classes \(o,p\), and a rational quantity \(q>0\) with \(q\leq y_{a,o},y_{b,p}\), where \(p\succ_a o\) and \(o\succ_b p\). It swaps those \(q\) masses: subtract \(q\) from \((a,o)\) and \((b,p)\), and add it to \((a,p)\) and \((b,o)\). A solution is a finite list of such steps ending with \(y_{a^\star,o^\star}\geq\varepsilon\). The input size and hoped-for complexity are measured in \(|A|,|O|,\tau\), and the binary encoding length of the masses and threshold.

The threshold makes the aggregate target explicit. Setting \(\varepsilon=\mu_{a^\star}\) asks whether the whole target cohort can obtain the desired class; a smaller threshold asks whether a specified positive share can. The model also permits the initial holdings and preference lists to have only the classes that matter, as in the paper’s bounded-list setting.

This is a plausible analogue because it preserves the paper’s central operation and question: can a desired item class reach agents who value it through a finite sequence of strictly improving bilateral swaps? It changes the named recipient into a cohort and the unique object into a class of interchangeable objects. In a market with repeated item categories and repeated household profiles, that is a natural population question. I think the authors could recognize it as a population-level extension of their reachability problem, though the positive-share target is a substantive change rather than a notational one.

I would expect this problem to remain hard, but I would not claim Theorem 3’s reduction already proves that. The reduction’s variable and clause gadgets rely on specifically routed agents and objects. Replicating them as mass types may permit fractional flows that bypass the intended consistency constraints. Whether the hardness survives is itself a useful question: can those constraints be encoded in type-level mass dynamics, or does the continuous model admit a tractable characterization? If hardness survives, the combinatorics would appear to live in the preference and item-class structure, suggesting hardness that transfers or is continuum-specific. If it does not, the relaxation may expose a tractable structure. The paper’s result alone does not settle which outcome to expect.

My weakest point is the aggregate target. Theorem 3 asks whether one designated agent gets one designated object; this mirror asks whether a specified share of a cohort gets an object class. A singleton target agent or a unique target item has zero mass in a nonatomic population, so keeping that exact query would require a tagged-agent or hybrid model. I find the cohort question more convincing as a high-multiplicity market problem, but a referee could reasonably say that it is a related problem rather than the continuous form of the authors’ exact designated-agent query. The mirror covers Theorem 3 only; I would not use the path algorithm or generalized-caterpillar hardness as extra anchors, because their dependence on individual network positions makes a population interpretation less persuasive.

The case AGAINST (opponent, writing after the proponent)

The only anchor is Theorem 3, and it is a real computational result: REACHABLE OBJECT is NP-complete even on complete graphs with preference lists of length at most four. So the negative case cannot dismiss the source result. It has to challenge whether a population version still asks that problem.

The fidelity problem is the reduction’s reliance on unique objects and named agents. Its clause and variable gadgets use private tokens and individually tailored roles to enforce one consistent route for a particular object to a particular recipient. Keep those identities in a continuum, and each named recipient and token has vanishing mass; asking whether that exact recipient gets that exact token is not a positive-mass population question. Keeping them as atoms preserves the query, but makes the model a hybrid with distinguished individuals.

The cohort proposal avoids that degeneracy by turning roles and tokens into types and classes. But then a type’s mass can split across holdings and routes. The variable-consistency mechanism in Theorem 3 no longer directly constrains one variable agent making one choice: different portions of a cohort can take different choices. That is a meaningful change to the computational object, not just a way to write the original instance with weights. A repaired question could maximize the mass of a target cohort that can obtain the target class, rather than choose an arbitrary threshold; it would still be a problem about positive-flow reachability, not the paper’s unique-token reachability.

That is the strongest case against: the proposed mirror is an extension, and Theorem 3’s reduction gives no evidence that its central constraint survives the extension. But this does not defeat the mirror on the programme’s stated terms. Repeated household profiles and interchangeable goods are plausible in a large exchange market, and determining whether cohort splitting makes reachability tractable or remains hard is a legitimate computational question. Calling the case against decisive would rely on a fidelity rule stricter than the programme allows. The honest negative is therefore weak: it can deny a direct mirror of Theorem 3, but not convincingly rule out a worthwhile, author-recognizable population extension.
