The continuous mirror question

Given a finite bipartite tree \(G=(V,E)\) of agent types, a positive rational mass \(\mu_v\) for each type with \(\sum_{v\in V}\mu_v=1\), an integer capacity \(q(v)\), and a weak preference order over neighboring types at each \(v\), compute an assignment maximizing total matched-pair mass subject to capacity and weak stability. Represent assignments by masses of bundles at each type, require matching incidences to balance across every edge, and require that for each type edge at least one endpoint has zero mass of agents willing to match across it.

The model it lives in

A type \(v\) has mass \(\mu_v\), shared capacity \(q(v)\), and a shared weak preference order over its neighbors in the type tree. Decision variables \(y_{v,B}\) assign mass to each multiset bundle \(B\) of at most \(q(v)\) neighboring types; edge incidences must balance, and an edge is stable when at least one endpoint has no positive mass of agents willing to match across it. Maximize the sum of matched-pair masses.

The objection that survived

The type tree replaces the paper's tree of individual possible pairs, so the expanded market can contain complete bipartite blocks and the dynamic program need not apply; this bounds theorem transfer, though the proponent acknowledges it.

fatal: False

The case FOR (proponent)

The strongest anchor is Theorem 4.1, proved in this paper. It says that for the many-to-many stable matching problem on a tree, Algorithm 1 computes the maximum size of a weakly stable matching. The paper’s Section 5 shows that the algorithm can be implemented in \(O(n\log n)\) time and can recover an optimal matching. Here “weakly stable” is the paper’s stated criterion: every unmatched edge must be rejected by at least one endpoint because that endpoint is at capacity and all its current partners are weakly preferred to the other endpoint. This is the paper’s main many-to-many result, extending the earlier one-to-one tree algorithm of Tayu and Ueno. The general NP-hardness mentioned in the introduction is cited to [8], not stated as a numbered result of this paper, so I would not use it as a separate anchor.

My lead mirror would be Maximum-Mass Weakly Stable Matching on a Type Tree. An instance has a finite bipartite tree \(G=(V,E)\) whose vertices are agent types, a positive rational mass \(\mu_v\) for each type with \(\sum_v\mu_v=1\), an integer capacity \(q(v)\) for each type, and a weak preference order \(\succeq_v\) over its neighboring types. Type \(v\) represents an atomless population of mass \(\mu_v\); its members share the same capacity and preferences. A matching assigns almost every agent a set of at most \(q(v)\) distinct partners, with each pair matched only once.

For a precise solution representation, let \(\mathcal B_v\) be the finite collection of multisets of neighboring types of size at most \(q(v)\). A solution gives each bundle \(B\in\mathcal B_v\) a mass \(y_{v,B}\geq 0\), with \(\sum_B y_{v,B}=\mu_v\). For each edge \(vw\), the total number of \(w\)-partners assigned to \(v\)-agents must equal the total number of \(v\)-partners assigned to \(w\)-agents. The objective is to maximize the total mass of matched pairs.

Stability uses the paper’s blocking logic at population scale. A type-\(v\) agent is willing to match with a neighboring type \(w\) if they have a vacant slot or have a current partner they strictly rank below \(w\). The assignment is stable if, for every type edge \(vw\), at least one endpoint has zero mass of agents willing to match across that edge. That rules out any positive mass of blocking pairs. The requested output is the maximum matched mass and an assignment attaining it.

The regime is a large two-sided allocation market with many agents but relatively few role types: for example, a specialized regional placement system in which compatibility links between worker and position categories form a tree. Agents within a role type share capacity and rank adjacent role types alike, perhaps being indifferent among members of the same category. Then \(n\), the population size, can be much larger than \(\tau=|V|\), the number of types. The tree is a substantive restriction, not something every matching market satisfies.

I expect this mirror to be Class A, but that is a conjecture for the continuous problem, not a consequence of Theorem 4.1. The theorem’s rooted-tree dynamic program works with local stability states and capacities; its child choices are made by sorting preference tiers. In the mirror, those choices become rational mass allocations. That gives a concrete route to a dynamic program or optimization formulation whose running time might depend on \(\tau\), the input bit length \(L\), and the capacity encoding, rather than on \(n\). The paper’s algorithm provides a reason to investigate that route, not a proof that it succeeds.

The main further questions are whether this problem has a polynomial-time algorithm in \((\tau,L)\); whether its optimum always has a polynomial-bit rational representation; and which discrete high-multiplicity tree instances correspond to its mass assignments after clearing denominators. The conversion question matters because the paper’s algorithm is about individual agents, while this mirror is about cohorts.

That difference is also my weakest point. The paper’s tree is the graph of individual agents and possible pairs. In the mirror, it is the graph of types. Replacing a tree of individual agents by large cohorts can create cycles in the expanded individual graph, so Theorem 4.1 does not automatically apply. The continuous model also permits positive mass of blocking pairs, whereas a finite matching rules out blocking individual pairs. Still, the mirror preserves the paper’s central question—maximize matching size subject to the same capacity and weak-stability logic—and makes the population itself the continuous object. It is a credible research question for the authors, provided they accept tree structure at the type level as the regime being studied.

The case AGAINST (opponent, writing after the proponent)

Theorem 4.1 is the paper’s computational anchor: it finds a maximum-size weakly stable matching when the graph of possible pairs among the individual agents is a tree. The obstacle is that this tree is part of the input’s interaction structure, not merely a restriction on preferences between categories.

The best population-level proposal is the proponent’s tree of types, with mass on each type and matching allowed between neighboring types. But when a type has many agents, an edge between two types represents a whole block of possible pairs. That block is complete bipartite, and it contains cycles as soon as both types have at least two agents. The paper’s dynamic program relies on actual subtrees separated by individual vertices; a tree of type categories does not give it that structure. This makes the proposed model coherent, but its tree condition describes a different market.

The other route is to keep the paper’s sparse individual tree and assign repeated agents common preference types. Then type masses alone do not say which agents are connected to which: the matching and stability conditions still depend on the particular edge pattern. Keeping enough incidence information to recover that pattern makes the network, as well as the population, part of the continuous object. A graph-limit or network formulation might be possible, but it is no longer the finite-support distribution over voter-like types at the center of this programme.

That is the strongest case against this anchor: there is no evident way to preserve both the paper’s actual tree structure and a population description that aggregates agents into types. Still, the negative case is not decisive. A tree-of-types market is a plausible problem in its own right, and the paper’s authors might recognize it as a worthwhile extension. The concern is that Theorem 4.1 does not itself establish that extension as the continuous mirror of its result; claiming that no matching mirror could be worthwhile would go beyond what this objection supports.
