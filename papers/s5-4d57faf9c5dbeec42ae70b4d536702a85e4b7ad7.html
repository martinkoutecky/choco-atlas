The river-sharing or sequencing scenario is the strongest foothold, but it does not supply that missing anchor. If the society consists of many copies of fixed finite tree components, with each type specifying the component and its worth data, the paper’s solutions can be applied component by component. Studying their population-level averages would be an extension of the allocation model, not a computational result from this paper. If instead the communication tree grows, its topology and the worth of each coalition matter to connectivity, restricted games, and hierarchical outcomes. Compressing agents into a fixed set of types would then require new assumptions about the network and coalition worths. Either route may support research, but neither yields a continuous version of a computational result here.

A continuous version would also need to define the limiting network, coalition worths, and allocation output.
