The continuous mirror question

Given candidate sets \(C_1,\ldots,C_k\), supported approval trajectories \(\theta=(A_1^\theta,\ldots,A_k^\theta)\) with \(A_i^\theta\subseteq C_i\), positive rational masses \(\mu_\theta\) summing to \(1\), and fixed tie orders, start with \(\ell_1(\theta)=0\). At round \(i\), for each \(c\in C_i\), minimize \(\lambda_i(c)=\frac{1+\sum_\theta x_\theta\ell_i(\theta)}{\sum_\theta x_\theta}\) over \(0\leq x_\theta\leq\mu_\theta\), with \(x_\theta=0\) whenever \(c\notin A_i^\theta\) and \(\sum_\theta x_\theta>0\); set \(\lambda_i(c)=\infty\) if no mass approves \(c\). Choose a candidate with minimum \(\lambda_i(c)\), update the selected mass to that load, and leave the other mass loads unchanged. Is the resulting winner sequence and load evolution exactly computable in time polynomial in \(k\), \(m=\max_i|C_i|\), support size \(\tau\), and binary input length \(L\)? A partial selection can occur only at a boundary whose current load equals the resulting load, so it does not split a type into distinct load states.

The model it lives in

A finite-horizon society of approval-trajectory types with masses \(\mu_\theta\), current type loads \(\ell_i(\theta)\), and per-round selected approving masses \(x_\theta\). For each candidate, minimize the post-decision load \(\lambda_i(c)\); select the candidate with the smallest value and simulate the resulting load updates.

The case FOR (proponent)

The strongest positive case is narrow: mirror the computation of Perpetual Phragmén, rather than trying to continuize the paper’s whole axiomatic programme. The paper has no named hardness result to anchor a hardness-dissolution claim. Its computational anchor is Proposition 8, proved here. It says that Perpetual Phragmén (i) satisfies simple proportionality; (ii) has a dry-spell guarantee of \(2n-1\), and that bound is tight; (iii) fails independence of uncontroversial decisions; (iv) is not equivalent to any WAM; and (v) is computable in polynomial time. Clause (v) is my lead.

A plausible high-multiplicity regime is a large membership organization making a finite sequence of recurring choices. Many members may follow the same approval pattern because they share a constituency, role, or stable bloc. A member’s type is their full approval trajectory \(\theta=(A_1^\theta,\ldots,A_k^\theta)\), where \(A_i^\theta\subseteq C_i\) is nonempty. The society is a distribution \(\mu\) over the supported trajectories, with binary-rational masses summing to one. Here \(n\), the number of members, can be very large while \(\tau\), the number of distinct trajectories, stays moderate. For example, millions of members might fall into a few hundred recurring types. The trajectory records identity across rounds; the rule still makes each choice using only the current approvals and past outcomes.

Call the mirror Continuous Perpetual Phragmén Simulation. An instance consists of the candidate sets \(C_1,\ldots,C_k\), the supported approval trajectories and their masses, and fixed tie-breaking orders. The solution is the winner sequence and the resulting load of each supported type after each round. Initially every type has load \(\ell_1(\theta)=0\). In round \(i\), for each candidate \(c\), choose a positive submass \(s_\theta\leq\mu_\theta\) only from types with \(c\in A_i^\theta\), minimizing \(\lambda_i(c)=(1+\sum_\theta s_\theta\ell_i(\theta))/\sum_\theta s_\theta\). Choose a candidate attaining the lowest such value, using the fixed tie rule; set the selected mass’s load to that value and leave other loads unchanged.

This states the underlying voting problem, not an encoding of it. The decision remains a single candidate from \(C_i\); the continuous variable represents which mass of approving members shares the round’s load. A canonical prefix tie rule makes the process deterministic. Since types at the same load are interchangeable, an optimal selected mass can be taken as whole type cohorts: a partial cohort can be optimal only at a boundary where including it does not change the load state.

I expect this problem to be tractable, in Class A. For each candidate, sort its supporting types by current load and scan prefixes, computing the ratio for each prefix; then compare the candidates’ minima. This is the support-size analogue of the sorting procedure used in the paper’s proof. There are at most \(\tau\) type-load entries per round, so the natural target is exact polynomial time in \(k\), the largest candidate-set size \(m\), \(\tau\), and the binary input length \(L\).

There is a particularly direct bridge to the paper’s discrete process. Given \(n\) voters whose trajectory proportions are \(\mu_\theta\), continuous loads can be scaled versions of the discrete loads: set \(L=n\ell\). For a coalition of voters, the continuous ratio is \(n\) times the discrete post-load \((1+\sum_v\ell(v))/|N'|\), so the minimizing coalitions and winners agree. Thus the mirror preserves the rule on finite high-multiplicity instances while representing repeated trajectories by their masses. Proposition 10 also supports this reading: on the apportionment restriction, the paper identifies Perpetual Phragmén with D’Hondt, a setting naturally expressed through party shares.

The scope is Proposition 8’s computation of Perpetual Phragmén. Its proportionality and other axiomatic claims are relevant follow-up questions, but they are not additional complexity anchors here. In particular, the tight \(2n-1\) dry-spell bound does not transfer as stated: \(n\) depends on the chosen finite realization of rational masses, so a denominator-independent continuous version would need its own definition.

The weakest point is the payoff. The discrete problem is already in polynomial time, and the continuous algorithm may be a support-compressed version of an existing procedure rather than a case where continuization dissolves hardness. The paper’s central contribution is axiomatic, so its authors may see this as a useful high-multiplicity formulation rather than the main question of their work. Still, the model is their exact approval-and-load process, with a plausible many-agent regime and a precise complexity question. It generates useful next questions: whether the exact bit complexity is polynomial in \((m,\tau,k,L)\), which proportionality properties survive under mass input, and how to formulate dry-spell guarantees without relying on a finite voter count.

The case AGAINST (opponent, writing after the proponent)

The only anchor that can carry a continuous mirror is Proposition 8(v): Perpetual Phragmén is computable in polynomial time. That is a genuine computational result, so I cannot dismiss the paper as purely axiomatic.

The strongest negative case is about the likely contribution. The paper’s algorithm already identifies the relevant structure: for each candidate, sort approving voters by load and find the subset with the lowest resulting load. With masses, the same calculation scans prefixes of the supported types. A partial selection at the boundary can be omitted without changing the loads, since its load already equals the resulting level. This points to a direct exact algorithm, with work polynomial in \(k\), \(m\), and \(\tau\), rather than a new separation problem or a need for continuous-optimization machinery. The result could be useful as a high-multiplicity algorithm, but it appears to have little algorithmic uncertainty.

That is a case for low research priority, not a sound objection that the mirror is unworthy. The discrete algorithm’s polynomial bound in \(n\) does not settle the high-multiplicity question when \(n\) is implicit in binary-rational masses. A support-based algorithm would answer a distinct question about dependence on \(\tau\) and input bit length. The programme’s stated standard also allows a well-posed mirror to be valuable even if its answer is easy or matches the discrete process.

The proposed trajectory types are credible for a large organization with recurring constituencies: people can share approval patterns across a finite horizon, and the rule can still process each round using only current approvals and past loads. The support may grow with the horizon, which limits the regime’s usefulness, but it does not eliminate scenarios with moderate \(\tau\). Proposition 10’s apportionment result is only a restricted special case, not an existing continuous treatment of general Perpetual Phragmén. It also lends some support to a party-like constituency scenario.

So the best negative case is narrow: this mirror may be a straightforward extension of an existing algorithm, with less room for a broader complexity story than the programme’s central examples. I cannot honestly turn that into the universal claim that no worthwhile continuous mirror exists. On the stated criteria, the Perpetual Phragmén computation remains a plausible mirror, and the negative case against it is weak.
