The continuous mirror question

Given a finite type set \(T\) with rational masses \(\mu_t\) summing to \(1\), a type-determined directed compatibility relation \(A\), a fixed cycle cap \(L\), and a rational target \(q\in[0,1]\), let \(\mathcal C_L\) be the directed cycle patterns of lengths \(2\) through \(L\), allowing repeated type labels when positions use distinct pairs. Is there a nonnegative cycle-mass vector \(x\) satisfying \(\sum_{C\in\mathcal C_L}a_t(C)x_C\le\mu_t\) for every \(t\in T\) and \(\sum_{C\in\mathcal C_L}|C|x_C\ge q\)?

The model it lives in

A continuous population with rational mass \(\mu_t\) at each complete compatibility type \(t\). For each feasible cycle pattern \(C\), choose mass \(x_C\ge0\); type capacities constrain the total mass used, and the objective is to cover at least fraction \(q\) of the population. For fixed \(L\), there are at most \(O(|T|^L)\) cycle patterns, giving a polynomial-size rational LP.

What the mirror covers

The mirror covers the unweighted, no-chain bounded-cycle packing problem underlying Theorem 2. It does not state Theorem 1’s separate targets for \(2\)-cycles and \(3\)-cycles, or cover weighted and chain variants.

Open questions for a prover

  • How does the finite-pool rounding loss depend on the number of types \(|T|\) and the cycle cap \(L\)?
  • Can the mirror remain tractable when the cycle cap \(L\) is part of the input?

The case FOR (proponent)

My lead is Bounded-Cycle Kidney Exchange over a Continuum. The strongest named anchor is Theorem 2, proved in this paper. It says that for the \(p\)-KEP—given a directed graph \(D=(V,A)\), a threshold \(k\), and a fixed cycle cap \(L\ge3\), decide whether there is a packing of vertex-disjoint cycles of lengths \(2\) through \(L\) covering at least \(k\) vertices—there is a randomized algorithm running in \(\mathcal O^*(2^{k+L}(k+L)^2L^3n^L)\) that produces the required packing in a yes-instance with high probability. The proof here reduces the problem to multilinear monomial detection; it uses Lemma 1, which the paper cites from Koutis and Williams [28]. The paper’s introduction also says that KEP is NP-hard for \(L\ge3\), citing earlier work, but that is not a numbered hardness result in this paper, so it is not my anchor.

Consider a large regional or national exchange registry in which many patient-donor pairs share the same complete compatibility profile. A type records everything relevant to cycle eligibility: in particular, its compatibility with every other type. If there are \(N\) pairs and \(\tau\) such types, the regime of interest has \(N\gg\tau\). This is plausible where compatibility is determined by a finite catalogue of clinical profiles and many pairs fall into each profile. Mass \(\mu_t\) is the fraction of pairs of type \(t\), with \(\sum_t\mu_t=1\). Two pairs of the same type are interchangeable for this problem, as high multiplicity requires.

Here is the continuous problem. The input is a finite support \(T\) with rational masses \(\mu_t\), the directed type-compatibility relation \(A\), a fixed cycle cap \(L\), and a rational target \(q\in[0,1]\). Let \(\mathcal C_L\) contain the directed type cycles of lengths \(2\) through \(L\). Repeated type labels are allowed when a cycle uses distinct pairs of that type; \(a_t(C)\) counts how many positions in cycle \(C\) use type \(t\). Choose a nonnegative mass \(x_C\) of each cycle pattern, subject to \(\sum_{C\in\mathcal C_L}a_t(C)x_C\le\mu_t\) for every type \(t\). The question is whether a feasible choice exists with \(\sum_{C\in\mathcal C_L}|C|x_C\ge q\). A solution is the cycle-mass vector \(x\). Each unit of \(x_C\) represents a cohort of pairs completing that whole cycle pattern; it does not mean that an individual receives a fractional kidney.

For fixed \(L\), this mirror should be tractable. There are at most \(O(\tau^L)\) cycle patterns, so the question is a rational linear program of polynomial size in \(\tau\) and the input bit length. I would expect Class A. The mirror preserves the paper’s central objective—maximizing the number of transplants with a cap on exchange-cycle length—while replacing unit-by-unit disjointness with aggregate type capacities. A discrete packing of \(k\) transplants among \(N\) pairs gives a feasible continuous plan covering \(k/N\) of the population. Conversely, with fixed \(\tau\) and \(L\), scaling type counts up and rounding down cycle quantities loses only a bounded number of transplants, so the normalized loss vanishes as the pool grows. The two answers need not coincide for a finite instance.

I think the authors would recognize this as a continuous version of their underlying kidney exchange problem: the same pairs, compatibility relation, cycles, length restriction, and transplant-count objective remain. The mirror covers the unweighted, no-chains, bounded-cycle packing result of Theorem 2, not every weighted or chain variant discussed in the paper. It also raises useful follow-up questions: how tightly can a finite registry approximate the continuous optimum; how does the rounding loss depend on \(\tau\) and \(L\); and can one handle a variable cycle cap without enumerating all cycle patterns?

The weak point is the regime. Exact compatibility profiles may be numerous, and pair-specific crossmatch constraints could make \(\tau\) grow nearly as fast as \(N\). If so, the aggregate LP offers little simplification. This is a limitation of the proposed scenario, not a reason to reject the mirror in a registry with genuinely repeated complete profiles.

The case AGAINST (opponent, writing after the proponent)

The strongest case against the proposed mirror is that it needs a much stronger compatibility assumption than the paper does. In the paper, compatibility is an arbitrary directed graph on patient–donor pairs. To make the proposed \(O(\tau^L)\)-pattern LP exact, compatibility must instead be determined by type: every pair in a type must have the same compatibility relations to every other type. Broad clinical categories may not guarantee that, because crossmatch compatibility is pairwise. If types must preserve each pair’s exact graph neighborhood, the number of types may approach the number of pairs, and the population compression largely disappears.

That is a real limitation of the mirror’s likely reach, but it does not defeat the better version. A large registry with repeated complete profiles and type-determined compatibility gives a coherent high-multiplicity regime. Its cycle variables describe cohorts completing whole exchanges; they do not assign fractional kidneys. The paper’s Theorem 2 is a named computational result, and the program permits a continuous question whose answer is an easy LP. Existing work on kidney exchange even uses identical-neighborhood “vertex types” and studies algorithms parameterized by their number, which supports the regime rather than counting against it. [Maiti and Dey, *Parameterized Algorithms for Kidney Exchange*](https://arxiv.org/abs/2112.10250)

There is a useful caveat: a kidney-exchange model with coarse low/high-sensitization types can make compatibility probabilistic, rather than fixed by type. That suggests another possible continuous mirror involving a compatibility kernel, but it would add stochastic structure beyond this paper’s deterministic graph problem. [Ashlagi et al., *Kidney Exchange in Dynamic Sparse Heterogeneous Pools*](https://web.stanford.edu/~iashlagi/papers/KE-AJM.pdf)

So the negative case is weak. The mirror may apply only to a restricted registry regime, but that restriction is not a fundamental obstruction, and the existing type-based work is evidence in its favor. I cannot honestly defeat the anchor: a continuous population version of bounded-cycle kidney exchange remains a worthwhile question.
