The case FOR (proponent)

My lead is Theorem 4, proved in this paper. It says that TreeCore returns a locally envy-free partial allocation on a rooted tree \(T\) using \(2n^2\) Robertson–Webb queries. It also guarantees that no agent envies a descendant and that the root receives \(1/n\) of the cake. The paper’s earlier continuous protocol for trees is cited prior work; it continuizes the cutting procedure, not the population.

A plausible high-multiplicity regime is a large population organized into repeated cohorts whose roles form a modest rooted tree: for example, residents with a small set of shared valuation profiles in a tree-shaped network of neighboring communities. Let a type specify both an agent’s valuation and its position—and neighboring roles—in that tree. Then agents of a type have the same preferences and the same relevant neighborhood structure. The population can be very large while the number \(\tau\) of types stays small.

The precise question I would give a prover is the Mass-Tree Local Envy-Free Allocation Problem. An instance consists of a rooted type tree \(H=(T,F)\), rational type masses \(\mu_t>0\) summing to \(1\), and one normalized additive valuation \(\nu_t\) per type, accessible through Robertson–Webb queries. Agents of type \(t\) are locally connected to the neighboring types in \(H\). The cake remains a single shared resource. To state a nontrivial limit as individual shares shrink with population size \(N\), represent a type’s allocation by its scaled mean share density \(x_t(z)\): in a finite realization, this is \(N\) times the fraction of type-\(t\) agents receiving cake point \(z\). Require \(x_t(z)\geq 0\) and \(\sum_t\mu_t x_t(z)\leq 1\) almost everywhere. The value of type \(t\)’s mean share is \(\nu_t(x_t)=\int x_t\,d\nu_t\).

The task is to output finite, piecewise-constant densities \(x_t\) satisfying, for every edge \(\{t,u\}\in F\), \(\nu_t(x_t)\geq\nu_t(x_u)\) and \(\nu_u(x_u)\geq\nu_u(x_t)\), and, for every descendant type \(s\) of \(t\), \(\nu_t(x_t)\geq\nu_t(x_s)\). The question is whether this can always be done using \(\operatorname{poly}(\tau,L)\) queries, where \(L\) is the bit length of the masses. The fractional densities describe type-level averages; a finite population realization still gives each individual an integral cake bundle.

I expect this problem to be tractable. Theorem 4 already gives a quadratic-query protocol for the corresponding finite tree. A mass-weighted version could replace repeated queries to identical agents with queries to their type, and use rational masses in place of subtree counts. That adaptation is a plausible route to a polynomial-in-\(\tau\) protocol, though Theorem 4 does not prove it. The root’s \(1/n\) share guarantee is part of the theorem, but I would not carry it into this mirror: the unique root’s vanishing population mass has no direct counterpart in a type tree with positive mass at every node.

This is a narrow case for the mirror: it covers the tree local-envy-freeness result, not Theorem 3’s arbitrary-graph local-proportionality result or global envy-freeness. Its weakest point is that the continuous constraints compare type-average shares, whereas Theorem 4 guarantees envy-freeness between actual neighboring agents. If the authors require that stronger, ex-post guarantee for every realized bundle, this formulation misses their result. The reason I still think the mirror is worth asking is that averaging is inherent when a type represents a positive mass of agents, and it preserves the same local comparisons at the level of the society.

The next questions are whether the average guarantee can be realized with ex-post fairness under a suitable coupling, and whether the type-tree protocol extends to broader type-interaction graphs.

The case AGAINST (opponent, writing after the proponent)

Theorem 4 is a genuine computational result: it gives a locally envy-free protocol using \(2n^2\) Robertson–Webb queries. The strongest case against its mirror is that a type average does not preserve the result’s fairness guarantee. The theorem compares each agent’s bundle with each actual neighbor’s bundle. The proposed densities compare mean bundles. Because valuation is additive, an average comparison can hold even when some neighboring pairs have envy; allocating those averages fractionally does not explain how to realize them as individual bundles while keeping every edge fair.

A stronger mirror could retain individual fairness by using a continuous population with an explicit sparse interaction structure and a coupling of bundles across neighboring agents. But that is no longer captured by a rooted tree of types and their masses. Blowing up a type tree into cohorts changes the graph’s structure; preserving the actual tree’s neighborhoods and descendant relations requires additional structural input. If that input tracks enough of the tree to preserve the protocol’s guarantees, the mirror may lose the hoped-for compression in \(\tau\). The paper’s procedure relies on individual parent–child relations, subtree sizes, and choosing pieces accordingly; replacing those counts with masses is a proposal, not an established adaptation.

So the proponent’s formulation is not yet a mirror of Theorem 4, and the proposed polynomial query bound has no support in the theorem. But I cannot honestly conclude that no worthwhile mirror exists in any scenario. A continuous model that preserves sparse adjacency and ex-post envy remains conceivable; defining its finite input and query complexity would itself be a substantive question. The negative case is strong against this mass-tree formulation, but weak as a universal claim.
