The continuous mirror question

Given a finite type set \(T\), rational masses \(\mu_t\) summing to \(1\), a symmetric utility table \(\sigma:T\times T\to\{-\infty,1\}\), and a coalition cap \(\kappa\in(0,1]\), can one construct a finite rational partition with component masses \(x^j_t\) summing to \(\mu_t\) that is stable against every measurable coalition of mass at most \(\kappa\)? A deviation selects type mass from components, forms links among the selected members, and may retain links to source components, which then join the resulting component in full; it succeeds only if every participating type slice strictly improves its component utility. If no such partition exists, establish that fact.

The model it lives in

An atomless population with type masses \(\mu_t\), where each type has the same symmetric friend/enemy relation \(\sigma(t,s)\) toward every member of type \(s\). A network is represented by component type-mass vectors \(x^j\); type \(t\)'s per-capita utility in component \(j\) is the mass of that component if it contains no enemy mass, and \(-\infty\) otherwise. Stability excludes profitable coordinated deviations by measurable coalitions of mass at most \(\kappa\), with retained source components joining the new component in full.

The objection that survived

A single individual can add a link that joins positive-mass components, while a component-mass state records only positive-mass defections and may therefore miss deviations counted by the finite stability notion.

fatal: False

What the mirror covers

The mirror centers on Theorem 3.6’s construction problem for symmetric friend/enemy utilities; it leaves the welfare results and the generalized-utility results unmirrored.

Open questions for a prover

  • Do mass-\(\kappa\)-stable partitions always exist, and can they always be represented by a finite rational component list?
  • What is the complexity of constructing such a partition; does the conflict-graph independent-set obstruction survive fractional type splitting?

The case FOR (proponent)

The strongest mirror I see is the construction of stable information-sharing networks in the symmetric friend/enemy model. The paper’s population is finite, but a plausible high-multiplicity regime is a very large organization or online community divided into a modest number \(\tau\) of trust cohorts. Each person’s type is their complete relationship profile toward those cohorts: members of type \(t\) have the same utility \(\sigma(t,s)\) toward every member of type \(s\), with \(\sigma\) symmetric and valued in \(\{-\infty,1\}\). Let \(\mu_t\) be the rational fraction of the population in type \(t\). This is a narrow regime: it assumes relationships are genuinely cohort-based, rather than idiosyncratic to named people. But with millions of people and relatively few cohorts, the population-to-type ratio is large, and the type definition captures exactly the relationships the model uses.

Here is the continuous problem I would put to a prover, named Mass-Stable Network Construction. Its input is the finite type set \(T\), rational masses \(\mu_t\) summing to \(1\), the symmetric utility table \(\sigma\), and a rational coalition cap \(\kappa\in(0,1]\). The population is atomless, and agents of each type have total mass \(\mu_t\). A proposed network is a finite partition into sharing components, encoded by rational vectors \(x^j\), where \(x^j_t\) is the mass of type \(t\) in component \(j\) and \(\sum_j x^j_t=\mu_t\). A type’s mass may be split across components.

An agent of type \(t\) in component \(j\) has utility
\[ U_t(x^j)=\int_{C_j}\sigma(t,t(b))\,d\mu(b). \]
Thus the utility is the component’s mass if it contains no positive mass of enemies, and \(-\infty\) otherwise. The network is mass-\(\kappa\)-stable if there is no measurable coalition of mass at most \(\kappa\) whose members all strictly improve by adding links among themselves and dropping any of their old links. More concretely, a deviation chooses type masses \(q_{tj}\le x^j_t\), with \(0<\sum_{t,j}q_{tj}\le\kappa\), and chooses which source components to remain linked to. The selected mass forms one new component; every retained source component joins it in full, while from other source components only the selected mass moves. The deviation succeeds if every participating type slice gets greater utility in the resulting component than in its original one. The question is: given the instance, return a finite rational component list that is mass-\(\kappa\)-stable, or establish that none exists. The case \(\kappa=1\) is the closest mirror of defections by any number of people; for finite populations, a cap of \(k\) people corresponds to a mass cap \(k/n\).

My lead anchor is Theorem 3.6, proved in this paper. In the symmetric \(\{-\infty,1\}\) utility model, when \(k\) is part of the input, constructing a \(k\)-stable network is NP-hard. The proof explains the source of the hardness: if \(k\) is at least the maximum independent-set size of the conflict graph, every \(k\)-stable network must contain a maximum independent set as one of its components. This is a strong match for a continuous question because the computational combinatorics sit in the conflict graph among types. The corresponding continuous problem is still about constructing a stable information-sharing network, with the same gossip components and coordinated link changes; mass replaces headcounts and lets cohorts split.

I expect this mirror to be Class B: hardness transfers, though that is a conjecture about the mirror, not a consequence of Theorem 3.6. The paper’s construction argument calls on maximum independent set; with masses, the natural analogue is maximum-weight independent set over the type conflict graph. Dividing population mass among components might make the problem easier, so a proof would have to show that fractional splitting does not remove the independent-set obstruction. That is the key open step.

A useful second question generated by the same anchor is whether stable mass partitions always exist, as they do in the paper’s finite model, and whether they admit a compact representation. A fractional formulation may look like a configuration optimization problem over conflict-free type sets; its pricing problem would involve maximum-weight independent set. That gives a concrete place to look for continuous-optimization methods and for the boundary between tractability and hardness.

This mirror covers the paper’s stable-network construction results for symmetric friend/enemy utilities. It does not try to continuize the welfare results, general asymmetric utilities, or the outcome space. Its weakest point is the change from a coalition of at most \(k\) individuals to a coalition of at most a fraction \(\kappa\) of the population. That is a genuine model co-modification, and the paper’s discrete hardness reduction does not automatically survive it. I think the authors could recognize the question as theirs because it preserves their central object and strategic move while scaling coalition size and utility to population mass—but that recognition, and the hardness transfer, are precisely what the mirror should test.

The case AGAINST (opponent, writing after the proponent)

The paper has genuine computational anchors: Theorems 3.4 and 3.6 give construction results, and Theorem 3.7 gives a stability-testing result. So the case against cannot rest on a lack of named problems, or on the possibility that hardness survives. The weak point is whether Theorem 3.6’s particular hardness result actually anchors the proposed mass problem.

In that theorem, \(k\) counts indivisible people who coordinate a defection. A cap of \(\kappa\) population mass changes the allowed coalitions and lets each type split. Replicate each type \(r\) times to create high multiplicity: a defection involving \(k\) representatives then has mass \(k/(r\tau)\), which tends to zero as \(r\) grows. Holding \(\kappa\) positive instead permits coalitions of order \(r\tau\), whose behavior need not encode the original reduction. The theorem therefore does not establish that its independent-set obstruction survives the proposed scaling. A fractional type-level independent-set formulation might still be a worthwhile problem, but it needs its own definition and motivation.

The more faithful version would retain defections by individual agents, even when each has zero population mass. That exposes a modeling problem: one link between two such agents can join components of positive mass, and a single enemy can make a component’s utility \(-\infty\). A type-mass vector records neither a zero-mass connector nor whether a zero-mass enemy is present. Defining harm by positive enemy mass and deviations by positive coalition mass resolves the accounting, but it changes the stability notion. Restricting links to entire trust cohorts makes the state finite, but changes who can choose partners: cohort-level action replaces individual negotiation.

This also weakens the proposed existence question. Theorem 3.5 establishes existence using indivisible nodes and clique construction; it does not imply existence or a compact rational representation for mass partitions under either altered notion of deviation. The manuscript’s friend/enemy model makes this especially consequential, since a single relationship can affect everyone reachable in the network.

That is the strongest case against: the proposed mirror has not yet fixed a continuum notion of deviation that preserves the paper’s strategic object, and the hardness theorem does not bridge that gap. The case remains limited. A large institution with genuinely block-structured trust relations could support a sensible mass model, and the authors might recognize it as their problem. I cannot honestly rule out that mirror across all scenarios; the argument against is that this paper has not yet supplied a stable, unambiguous bridge from its computational results to one.
