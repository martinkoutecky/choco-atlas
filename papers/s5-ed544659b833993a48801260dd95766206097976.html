The paper supplies no named computational result to anchor a continuous mirror.

The nearest candidate for a population interpretation is Theorem 4.2: take many bidders from a finite set of valuation types, with rational type masses, and ask whether DSL behavior still guarantees optimal welfare in a combinatorial auction with Sybil bids. But turning that into a faithful continuous problem requires choices the paper does not settle. With fixed indivisible supply, an individual can matter to VCG’s allocation and payments even as type mass becomes continuous; scaling supply to preserve per-capita scarcity changes the auction model and its externality payments. Either way, the proposed question would be a new strategic extension, not a continuous version of a computational result in this paper.

So there is no valid anchor, lead, or per-anchor prover question here under the stated criteria. The paper’s use of DSL with continuous action spaces, and its discussion of auction outcomes, do not make the population continuous.

The case AGAINST (opponent, writing after the proponent)

The proponent is right about one narrow point: the paper contains no theorem classifying a problem as polynomial time or NP-hard. That makes this a less direct mirror than a paper with an explicit complexity result. It does not, though, rule out a worthwhile computational question anchored in Theorem 4.2. That theorem’s central object is an algorithmic mechanism: VCG chooses an allocation by maximizing reported welfare, and its conclusion says what welfare that mechanism achieves when bidders use DSL strategies.

A natural high-multiplicity setting is a large market for recurring ad-slot types. There are many bidders but only \(\tau\) valuation types, and the supply of each slot type scales with population size. Write \(\mu_t\) for the fraction of type \(t\), and \(q_g\) for the per-capita supply of slot type \(g\). An allocation can be represented by the mass \(x_{t,S}\) of type \(t\) receiving bundle \(S\):

\[ \max \sum_{t,S} x_{t,S}v_t(S) \quad\text{subject to}\quad \sum_S x_{t,S}=\mu_t,\qquad \sum_{t,S:g\in S}x_{t,S}\le q_g,\qquad x_{t,S}\ge 0. \]

Each bidder still receives an integral bundle; only the average allocation within a type is fractional. This is the kind of co-modification the programme allows when population continuity requires per-capita supplies.

The VCG externality need not vanish in this limit. If total welfare is \(N F(\mu)\) for a population of size \(N\), removing one type-\(t\) bidder changes the type distribution by \(1/N\). The resulting change in total welfare is scaled by \(N\), so it can converge to a finite marginal externality, described by a one-sided derivative of \(F\). The computational questions are then concrete: compute a welfare-maximizing allocation and its marginal VCG payments from rational type masses, and determine how DSL strategies behave against distributions of rival types and actions. The allocation problem above is an LP; with valuation tables given explicitly, it is polynomial in their input size. Theorem 4.2 supplies the reason this continuous VCG computation matters: it connects the mechanism’s allocation to welfare under DSL behavior. Whether the DSL guarantee persists in the mass model is a question to ask, not an objection based on what its answer might be.

Lemma B.3 is a weaker anchor. Sending the bid grid to zero loses the DSL strategy, as Lemma B.2 indicates; keeping the grid fixed preserves the population mirror but makes the type-by-type bid rule simple. I would not rely on it as a separate complexity result. Its limitations do not dispose of the stronger question arising from Theorem 4.2.

So the positive case has a real qualification: it is a computational question implicit in the paper’s named mechanism result, not a continuous mirror of an existing complexity classification. That is a weaker starting point, but not enough to support the universal claim that no worthwhile mirror exists.
