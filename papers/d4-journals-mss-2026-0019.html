What the mirror covers

The proposed mirrors concern Theorems 1 and 2, but neither supplies a qualifying computational result; no continuous mirror of the paper’s other results is proposed.

The case FOR (proponent)

The paper has named theorems, but no named computational-complexity result of the kind this exercise requires: it gives no hardness, tractability, or parameterized-complexity result for an underlying problem.

The closest candidate is Theorem 2, proved here. With substitutable firm choice functions satisfying the law of aggregate demand, firms’ choices fixed, and workers as the only strategic players, the firm-optimal stable rule implements the stable correspondence in Nash equilibrium: every equilibrium outcome is stable under the true preferences and choices, and every stable matching is the outcome of some equilibrium. Theorem 1, also proved here, says that when workers and firms can both misreport, any stable rule implements the individually rational correspondence: every equilibrium outcome is individually rational under the true market, and every individually rational matching occurs at some equilibrium. These are implementation theorems, not algorithmic or complexity claims.

A continuum version might model worker and firm types as distributions and match mass across types. But if agents are nonatomic, one worker’s deviation changes no mass; if whole types deviate as blocks, the strategic game changes. Either way, a continuum implementation theorem would be a new equilibrium question, not a continuous mirror of a computational result in this paper. So I can’t give a prover-ready continuous problem anchored in a qualifying result.

The case AGAINST (opponent, writing after the proponent)

The strongest case against a worthwhile mirror is that this paper has no computational result to mirror. Theorem 1 says stable rules implement the individually rational correspondence in Nash equilibrium; Theorem 2 says the firm-optimal stable rule implements the stable correspondence under LAD. Neither gives an algorithm, a complexity bound, or a computational problem with a specified input representation. The model even allows arbitrary choice functions over worker subsets, without saying how to encode them as inputs.

The best mirror of Theorem 1 would put workers and firms into repeated types and ask whether the mass individually rational allocations are exactly the equilibrium outcomes. The best mirror of Theorem 2 would do the same for stable mass allocations under LAD. Both are recognizable equilibrium questions, but they extend an implementation theory, not the computational complexity landscape this programme targets.

There is also a deeper mismatch in the strategic object. In an atomless society, one worker’s report changes no aggregate mass. If outcomes are represented only by type-to-type flows, that worker’s deviation typically cannot change their outcome, so the Nash condition loses the individual incentive content of the theorem. If a positive-mass cohort can deviate together, that is a different strategic game: the players are now blocs. If the model instead preserves named assignments so that one person’s report can affect their own match, the aggregate distribution alone no longer specifies the outcome. These choices may support new models, but they do not carry over the paper’s Nash implementation claims unchanged.

This applies to both theorems. Theorem 1’s construction uses each worker’s assigned firm and each firm’s assigned worker set to build a particular equilibrium report profile. Theorem 2 relies on unilateral worker deviations and blocking pairs. Aggregating assignments into flows can preserve a useful allocation question, but it does not preserve those arguments’ individual strategic meaning.

I would not claim that matching markets lack sensible high-multiplicity regimes; large labor markets plainly can have them. The negative case is narrower: for this paper, obtaining a computational question about a continuous population would require adding an algorithmic problem and choosing a new representation and equilibrium notion. That may be worthwhile research, but it is a new computational project built around the paper’s subject, rather than a continuous mirror of one of its results.
