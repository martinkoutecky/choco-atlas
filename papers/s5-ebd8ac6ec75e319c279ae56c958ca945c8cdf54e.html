The proponent raises no continuous-mirror anchors: it says the paper has no computational result to mirror. That is the strongest case against a ChoCo mirror. Theorem 1, Theorem 2, and Theorem 3 characterize the Owen value by axioms. None asks for an algorithm or a complexity bound. A continuous axiomatization might extend the paper’s subject, but it would not answer the computational questions this programme studies.

The strongest rescue would be a large industry with many interchangeable participants in a small number of unions. But a player’s type in a cooperative game must capture how they affect worth across coalitions. The paper allows arbitrary characteristic functions, so that information can be as large as the game itself; having many players does not by itself yield a compact type distribution. A continuum version would also need a worth function for fractional coalitions and a payoff density for infinitesimal participants. One could define those choices—for example, using an Aumann–Shapley-style allocation—but they would set up a new model, rather than give a computational mirror of these theorems.

Computing the Owen value for a chosen compactly encoded class of games could be a worthwhile computational question. Its tractability would depend on that encoding and those restrictions, though, and the paper’s axiomatic characterizations provide no computational result to carry over. So the negative case is strong under ChoCo’s scope, while not ruling out valuable adjacent work on computation in cooperative games.
