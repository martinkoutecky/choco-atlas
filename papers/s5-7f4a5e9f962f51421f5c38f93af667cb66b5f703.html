The continuous mirror question

Given \(m\) criteria, a finite support \(T\) of \(\tau\) types with rational pairwise-judgment matrices \(R^t\), influence weights \(w_t\), positive rational masses \(\mu_t\) summing to \(1\), a finite \(P\subseteq\{1,2,\infty\}\), nonnegative rational weights \(\lambda_p\) not all zero, and a nonempty rational polyhedral feasible set \(F\), find a global minimizer \(X\in F\) of \(\sum_{p\in P}\lambda_pD_p(\mu,X)\). For finite \(p\), let \(D_p(\mu,X)=\left(\sum_{t\in T}\mu_tw_t^p\sum_{j\ne k}|R^t_{jk}-X_{jk}|^p\right)^{1/p}\); let \(D_\infty(\mu,X)=\max_{t\in T,\ j\ne k}w_t|R^t_{jk}-X_{jk}|\).

The model it lives in

The society is a distribution \(\mu\) over complete types \(t=(R^t,w_t)\), where each type carries a pairwise-judgment matrix and its influence weight. The decision variable is the feasible consensus matrix \(X\in F\), minimizing the mass-weighted multi-principle objective \(\sum_{p\in P}\lambda_pD_p(\mu,X)\). This uses a per-capita convention: for a finite profile with \(\mu_t=n_t/n\), recovering the paper's unnormalized objective requires scaling each principle weight by \(n^{1/p}\).

What the mirror covers

The mirror covers Theorem 1's multi-principle consensus computation for \(P\subseteq\{1,2,\infty\}\). It leaves the paper's empirical findings and claims about arbitrary \(p\) outside the stated problem.

Open questions for a prover

  • For which encodings of arbitrary finite \(P\subseteq[1,\infty]\) does the continuous problem retain an efficient algorithm?
  • Which scaling convention for \(\lambda_p\) best preserves multi-principle trade-offs when a finite electorate is replicated?

The case FOR (proponent)

The best mirror is the paper’s multi-principle consensus computation, in a large citizen-participation process. Imagine a city asking many residents to compare a fixed set of policy criteria. A type is a resident’s complete pairwise-judgment matrix together with their social-influence weight \(w\). Mass \(\mu_t\) is the fraction of residents of type \(t\). If the questionnaire uses a fixed response scale and the criteria set is modest, there can be many residents but relatively few distinct types. This fits the paper’s own motivation in citizen participation and its treatment of opinions as pairwise comparisons. The ethical principles \(p\) and their weights \(\lambda_p\) remain features of the collective objective, not attributes that need to be added to each type.

My lead anchor is Theorem 1, proved in this paper. It says that, for a set \(P\) of ethical principles with nonnegative weights \(\lambda_p\), minimizing
\[ \sum_{p\in P}\lambda_p \left[ \sum_{i=1}^n\sum_{j=1}^m\sum_{k\ne j} w_i^p\lvert R^i_{jk}-R^S_{jk}\rvert^p \right]^{1/p} \]
over consensus judgments \(R^S\) satisfying \(F\) is equivalent to a multi-\(\ell_p\)-norm approximation problem. With \(x=\operatorname{vec}(R^S)\), its matrix has \(w_i I_{m^2}\) as the \(i\)-th vertical block, and its right-hand side has \(w_i\operatorname{vec}(R^i)\) as the corresponding block. The theorem is a formulation result rather than a complexity classification; the paper uses the formulation to compute consensus by convex optimization.

The continuous question I would hand to a prover is Finite-Support Multi-Principle Consensus. An instance consists of \(m\) criteria; a support of \(\tau\) types, each with a rational judgment matrix \(R^t\) and rational influence weight \(w_t\); rational masses \(\mu_t>0\) summing to \(1\); a finite \(P\subseteq\{1,2,\infty\}\); nonnegative rational principle weights \(\lambda_p\), not all zero; and a nonempty rational polyhedral feasible set \(F\) of consensus judgments. Find a feasible \(X\in F\) minimizing
\[ \sum_{p\in P}\lambda_p D_p(\mu,X), \]
where, for finite \(p\),
\[ D_p(\mu,X)= \left[ \sum_{t=1}^{\tau}\mu_t w_t^p \sum_{j=1}^m\sum_{k\ne j} \lvert R^t_{jk}-X_{jk}\rvert^p \right]^{1/p}, \]
and
\[ D_\infty(\mu,X)= \max_{t,j\ne k}w_t\lvert R^t_{jk}-X_{jk}\rvert. \]
A solution is any global minimizer \(X\), together with its objective value. The input lists only the \(\tau\) positive-mass types; the number of residents does not appear.

I expect this mirror to be Class A for the stated \(P\). With \(p=1,2,\infty\), each term has an LP or second-order-cone epigraph, so the whole problem is a convex program whose size depends on \(m\) and \(\tau\), not the population size. That matches the paper’s computational route while making the population distribution itself the input. The paper’s continuous-valued consensus outcome is not the continuization here; the mirror is the replacement of the finite list of residents by masses over types.

There is a useful finite-instance dictionary, with a caveat. If a discrete profile has \(n_t\) residents of type \(t\), set \(\mu_t=n_t/n\). Each continuous \(D_p\) is then the paper’s finite \(p\)-distance divided by \(n^{1/p}\). Thus the original finite objective is recovered by setting \(\lambda_p^{\mathrm{cont}}=n^{1/p}\lambda_p^{\mathrm{paper}}\). This factor is immaterial for a single principle but changes trade-offs among principles. Holding the continuous \(\lambda_p\) fixed as the population grows is therefore a deliberate per-capita convention, not an exact preservation of the paper’s multi-principle weights under every replication.

The mirror covers the computational consensus problem anchored by Theorem 1, not the paper’s empirical conclusions about the seven recreationists or the semantic interpretation of every \(p\). Further questions include whether arbitrary rational \(p\) admits comparably efficient algorithms, how to formulate the paper’s reweighting scheme over a type distribution, and which finite-profile and continuous optima correspond under alternative conventions for scaling \(\lambda_p\).

The weakest point is the regime: the paper’s demonstrated group has seven members, and exact agreement on a full cardinal judgment matrix plus influence weight may be a strong assumption for a citywide population. A fixed questionnaire scale and a small criteria set make a moderate-support regime plausible, and the paper already motivates participation by citizens and allows group-level influence weights. Still, that is a convincing scenario for the same mathematical problem, not evidence that the paper’s own seven-person case is a high-multiplicity instance.

The case AGAINST (opponent, writing after the proponent)

The strongest case against is that the paper has no numbered result about computational complexity to continue. Theorem 1 proves a reformulation as multi-\(\ell_p\)-norm approximation; it does not classify an algorithmic problem or establish a complexity boundary. The experiments concern seven recreationists, and the paper’s computational contribution is to use convex optimization for its consensus model. So a mirror would not test whether one of the paper’s complexity results survives when the population becomes continuous.

That leaves a plausible mirror, though. In a large citizen-participation process with a fixed questionnaire, a type can be a complete pairwise-judgment matrix plus its influence weight, and mass can be the fraction of residents with that type. The consensus objective then uses the distribution’s weighted \(p\)-distances. Identity is not needed once the type includes everything the objective uses, and the paper’s own motivation makes this scenario credible. For \(P=\{1,2,\infty\}\), the resulting finite-support problem has the LP or second-order-cone structure the authors already use.

The negative case is about priority, not coherence: the population distribution changes the input representation, while the paper has already put consensus computation in a convex-optimization framework. A follow-up would therefore appear to offer little new computational terrain. But under ChoCo’s stated criteria, an easy or familiar algorithmic answer does not make a well-posed population mirror unworthy. The citizen-participation version survives the strongest objection, so I cannot honestly defend the universal claim that no worthwhile mirror exists. The negative case is weak.
