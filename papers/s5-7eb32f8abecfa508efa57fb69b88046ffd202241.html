The case FOR (proponent)

I would make one focused case around Type-Mass Private Alphabet EF\(_c\). It mirrors the paper’s public-alphabet envy-freeness result, in a regime where many agents share a small number of complete valuation types.

Let \(N\) be the population size and let the \(m\) indivisible goods be valued using the public alphabet \(\mathcal V=\{0=\xi_0<\cdots<\xi_{D-1}\}\). A type \(t\in\mathcal V^m\) is an agent’s full valuation vector. The society is a distribution \(\mu\) with \(\mu_t=a_t/N\), where \(a_t\) is the number of agents of type \(t\); let \(\tau\) be the number of types with positive mass. A plausible regime is a very large population with \(\tau\ll N\): for example, many households with a small number of standardized preference or need profiles. The interesting fairness regime has substantially more goods than agents, so the trivial bound from deleting an entire bundle is not already small.

The allocation variable is a table \(x_{t,B}\), where \(x_{t,B}\) is the fraction of type-\(t\) agents assigned the integral bundle \(B\subseteq[m]\). Require \(x_{t,B}\) to be a multiple of \(1/N\), with
\[ \sum_B x_{t,B}=\mu_t \quad\text{and}\quad \sum_{t,B:\,g\in B}x_{t,B}=\frac1N \quad\text{for every good }g. \]
Thus every good goes to one agent, and every agent receives an integral bundle. Only the *type-level frequencies* are fractional. This table is the anonymous allocation outcome, up to permutations among agents of the same type.

Call the allocation EF\(c\) if, for every type \(t\), every bundle \(B\) assigned positive mass to that type, and every bundle \(B'\) assigned positive mass overall, there is a set \(R\subseteq B'\) with \(|R|\le c\) such that
\[ \sum_{g\in B}t(g)\ \ge\ \sum_{g\in B'\setminus R}t(g). \]
Privacy is pure entry privacy on the population distribution: neighboring inputs move \(1/N\) mass from \(t\) to \(t'\), where the two types differ in one good’s value. The question is to find a randomized mechanism that releases the full allocation table, is \(\varepsilon\)-DP under this adjacency, and achieves the stated EF bound with probability at least \(1-\beta\). There is no welfare objective in the anchor, so I would not invent one. A concrete target is a sparse rational table, computable in time polynomial in \(m,\tau,D,L,1/\varepsilon,\log(1/\beta)\), achieving
\[ c\le \left\lceil\frac mN\right\rceil, \qquad c=O\!\left(1+ \frac{\log m\,(\log D)^{3/2}}{\varepsilon} \log\frac{NmD}{\beta}\right), \]
where \(L\) is the bit length of the type masses. The cap handles regimes where a fixed allocation already gives a small deletion guarantee.

My sole computational anchor is Theorem 16, proved in this paper. It states that for \(n,m,D\ge2\), a public finite alphabet of size \(D\), \(\varepsilon>0\), and \(0<\beta<1\), there is a pure entry-level \(\varepsilon\)-DP mechanism for nonnegative additive valuations that always returns a complete allocation and, with probability at least \(1-\beta\), achieves EF\(c\) with
\[ c\le\left\lceil\frac mn\right\rceil, \qquad c=O\!\left(1+ \frac{\log m\,(\log D)^{3/2}}{\varepsilon} \log\frac{nmD}{\beta}\right). \]
It runs in time polynomial in \(n,m,D\). The theorem is proved here, not cited. It is the strongest anchor because it gives an algorithm for the same fairness and privacy question, and the public alphabet gives a concrete handle for aggregating repeated types. The paper has no named computational-hardness result: Theorem 20 is a lower bound on the deletion guarantee under privacy, not a hardness classification.

I expect this mirror to be Class A, as a research bet rather than a consequence of Theorem 16. The paper’s alphabet method already reduces valuations to threshold counts, and a type-mass representation makes repeated rows explicit. A continuous mechanism might combine those counts with type-level allocation variables and privacy noise, avoiding a separate named-agent computation for every copy of a type. The hard part is finding a tractable way to choose among integral bundle configurations while preserving EF\(c\) and privacy. A useful next question is whether that configuration step admits an efficient pricing or separation routine; another is whether Theorem 20’s privacy–fairness lower bound persists in a type-compressed formulation.

This covers Theorem 16 only. I would not use the discrepancy or consensus-fairness theorems as additional anchors: they would require different mirrors, and this one is already precise. Nor is the paper “already continuous” because goods are indivisible or because the algorithm maintains fractional estimates. The society here is what is represented by a distribution over types.

The weakest point is the anonymous output. The table \(x_{t,B}\) associates bundles with private types, while the paper publishes an allocation to named agents; requiring DP for this type-conditioned table may behave differently and may be more revealing. I think the mirror remains recognizable because type-conditioned bundle frequencies are the natural allocation object when agents of a type are interchangeable, and the fairness test still applies to the integral bundle each person receives. But an author who regards named identities as essential could reject that output model.

The case AGAINST (opponent, writing after the proponent)

Theorem 16 is a real computational anchor: it gives a pure-DP algorithm for a named allocation problem, and repeated valuation rows make a high-multiplicity regime plausible. I would not argue that the paper lacks a result to mirror, or that the underlying fairness question is inherently tied to distinct agent identities.

The proposed type-mass output has a more basic problem. Its row sums reveal the private population histogram exactly:
\[ \sum_B x_{t,B}=\mu_t. \]
If neighboring societies move \(1/N\) mass from type \(t\) to a type \(t'\) differing on one good, the event that the released row sum for \(t\) equals its value in the first society has probability \(1\) there and \(0\) in the neighbor. So no finite-\(\varepsilon\) pure-DP mechanism can release that table. This is a structural conflict between exact type-conditioned allocation counts and the paper’s entry-privacy guarantee, not a difficulty in finding a better algorithm.

A natural repair is to release conditional bundle frequencies for each type, rather than the joint masses \(x_{t,B}\). But that is a policy or allocation kernel, not the realized complete allocation in Theorem 16. To implement it as an exact finite allocation, the mechanism must use the private type counts to realize integral bundle counts; publishing those counts restores the privacy contradiction. Publishing named agents’ assignments avoids exposing the histogram directly, but brings back the individual-level output and privacy problem the type-mass compression was meant to replace. An atomless formulation has a related gap: changing one person changes no population distribution, while defining privacy by changes to positive mass is no longer the paper’s one-entry adjacency.

That leaves room for a different project—perhaps a private allocation kernel with carefully chosen feasibility and fairness semantics—but it would need to establish that those semantics represent the paper’s ex-post allocation guarantee. The proponent has not done that, and the suggested Class A route from “type rows are explicit” to an efficient algorithm is only a research bet.

This is the strongest negative case I can make against their anchor, but it does not establish the universal claim that no worthwhile mirror exists. Theorem 16 remains a strong candidate if one can give a coherent continuous output and privacy definition that avoids this conflict.
