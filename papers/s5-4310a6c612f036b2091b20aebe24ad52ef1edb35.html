The continuous mirror question

Given a finite set of types \(\Theta\), each with an explicit feasible-bundle set \(\Psi_\theta\subseteq\{0,1\}^m\) and strict ranking \(\succ_\theta\), binary-rational masses \(\mu_\theta\) summing to \(1\), per-capita supplies \(\kappa_j\), and error parameters \(\varepsilon_b,\varepsilon_n,\varepsilon_f\), construct prices \(p\), a finite-support budget lottery \(B_\theta\subseteq[1-\varepsilon_b,1]\) for each type, and an allocation of unit mass arriving with type flow \(\mu_\theta du\). After the initial mass \(\varepsilon_s=\varepsilon_n\varepsilon_f/4\), each type’s mass must be split among its most-preferred feasible bundles affordable under its budget draw; each infinitesimal agent receives one integral bundle. If \(d_j\) is expected demand per unit mass, require \(d_j\le\kappa_j\), with equality when \(p_j>0\), and initial use \(s_j\le\varepsilon_s\kappa_j\). The resulting cumulative use \(A_j(u)=s_j+(u-\varepsilon_s)d_j\) must satisfy \((1-\varepsilon_f)u\kappa_j\le A_j(u)\le u\kappa_j\) for each \(u\ge\varepsilon_n\), with the lower bound required when \(p_j>0\). What is the construction’s computational complexity in \(m\), \(|\Theta|\), and the input bit length?

The model it lives in

A continuum of agents with finite type support \(\Theta\), type masses \(\mu_\theta\), and per-capita supplies \(\kappa_j\). The decisions are the initial mass allocation, common prices \(p\), and type-specific budget lotteries and bundle-mass assignments. Type and time cohorts may be split across bundles in aggregate, while every unit of mass receives a whole feasible bundle.

What the mirror covers

The mirror covers Theorem 2’s DACEEI market-clearing guarantee and post-sample EF1 property. It leaves aside the finite-sample learning step, random-arrival concentration bound, and group-strategyproofness guarantee.

Open questions for a prover

  • Can prices and finite-support budget lotteries be constructed in time polynomial in \(m\), \(|\Theta|\), and the binary input length, given explicit bundle rankings?
  • Which parts of the finite-market capacity bound remain necessary when type flow is exact?

The case FOR (proponent)

The strongest honest mirror is a binary-mass construction problem for the market-clearing part of Theorem 2. Theorem 2 is proved in this paper. In full, it says that for any economy, \(\varepsilon_f,\varepsilon_n>0\), and \(0<\varepsilon_b<1/m\), OCAM is group-strategyproof up to one object and envy-free up to one object for a \(1-\varepsilon_s\) fraction of agents, where \(\varepsilon_s=\varepsilon_n\varepsilon_f/4\). Moreover, if arrival order is a uniformly random permutation and
\[ \min_j c_j\ \ge\ \frac{70\bigl(\tau\log(\varepsilon_s n)+\log m+\sqrt n\log n\bigr)} {\varepsilon_s\varepsilon_f^2}, \]
then with probability at least \(1-1/n\), OCAM outputs an \((\varepsilon_b,\varepsilon_n,\varepsilon_f)\)-DACEEI. I would mirror its DACEEI construction and post-sample EF1 guarantee; I would not claim that the group-strategyproofness clause already has a satisfactory atomless analogue.

Here is the continuous problem. Let \(\Theta\) be a finite support of types \(\theta=(\Psi_\theta,\succ_\theta)\), where \(\Psi_\theta\subseteq\{0,1\}^m\) is the type’s feasible bundle set and \(\succ_\theta\) is a strict ranking of those bundles. The instance gives each type a rational mass \(\mu_\theta\), with \(\sum_\theta\mu_\theta=1\), per-capita supplies \(\kappa_j\), and the error parameters. Unit mass arrives over \(u\in[0,1]\), with type flow \(du\,\mu_\theta\). This is the stationary high-multiplicity limit of a fixed population arriving in uniformly random order. Ask for prices \(p\), a budget distribution \(B_\theta\subseteq[1-\varepsilon_b,1]\) for each type, and an assignment of the later mass to bundles. For each budget realization \(b\), the assigned bundle must be \(\theta\)’s most-preferred feasible bundle satisfying \(p\cdot x\le b\). Writing \(d_j\) for the resulting expected per-unit demand for good \(j\), require \(d_j\le\kappa_j\), with equality whenever \(p_j>0\). Also assign the initial \(\varepsilon_s\) mass feasible bundles using at most \(\varepsilon_s\kappa_j\) of each good.

The solution is a mass allocation over integral bundles: a type-and-time cohort may be split among bundles, but each infinitesimal agent receives one whole feasible bundle. The budgets and bundle choices can likewise be represented as a finite-support distribution. If \(s_j\) is the initial mass’s use of good \(j\), then after the initial phase cumulative use is
\[ A_j(u)=s_j+(u-\varepsilon_s)d_j. \]
For every \(u\ge\varepsilon_n\), this gives \(A_j(u)\le u\kappa_j\); for \(p_j>0\), it gives \(A_j(u)\ge(1-\varepsilon_f)u\kappa_j\). The latter follows from \(\varepsilon_s=\varepsilon_n\varepsilon_f/4\). Thus the dynamic clearing guarantee is deterministic in the exact-flow model. With \(\varepsilon_b<1/m\), the post-sample budget and choice rule also gives the support-wise EF1 property. The computational question is whether this solution can be constructed from binary-encoded \(\mu\) and \(\kappa\), with running time stated in \(m,\tau,L\) and with the bundle-ranking representation specified.

A plausible regime is a large annual daycare intake: many families have the same ranking over center-and-day bundles and the same feasibility constraints, while the number of such types is far smaller than the number of families. A randomized intake order is credible where families enter through a placement lottery. The type must include every feature the allocation uses, such as family-specific bundle feasibility. This is a population mirror: fractional quantities describe shares of families receiving whole bundles, not divisible daycare places.

The authors have a good reason to recognize this question. Their ECEEI construction already makes agents of the same type share the same random budget, and the dynamic mechanism uses that type structure to assign later arrivals. Theorem 1, also proved here, supplies the existence foundation: for every \(\varepsilon>0\), an \(\varepsilon\)-ECEEI exists, and the construction gives same-type agents the same random budget. But existence is not a complexity bound. The paper does not establish polynomial bit complexity for finding the prices and budget lotteries, so that is new work for the mirror to ask.

My working expectation is Class A for constructing the mass ECEEI, since the finite type support and aggregate capacity constraints suggest a continuous-optimization formulation. The test is the price-dependent choice condition: a solver must find prices and budget lotteries that support each type’s ranked bundle choices. That pricing problem could dominate the running time, especially with compact preference representations. Further questions include whether an efficient construction exists for binary masses, how much of the finite-market capacity bound disappears in the exact-flow limit, and whether group-strategyproofness can be stated meaningfully for positive-mass coalitions.

The weakest point is that exact stationary type flow removes the sampling fluctuations central to Theorem 2. It therefore mirrors the market-clearing target, but not the paper’s full finite-population mechanism or its random-arrival proof. Group-strategyproofness is particularly delicate: the theorem can rely on one harmed individual, while a single individual has zero mass in the limit. I still think the clearing problem is a credible mirror because the paper’s own solution is built around type-level random budgets and because compressed computation over binary masses is precisely the high-multiplicity question. The paper also uses randomization and integral bundles, but those are parts of its mechanism, not a continuization of the outcome space.

The case AGAINST (opponent, writing after the proponent)

The strongest case against the proposed mirror is that it removes the part of Theorem 2 that makes the result dynamic. In the paper, OCAM sees a finite random prefix and uses it to estimate a population it does not know. Under the proposed stationary flow \(du\,\mu_\theta\), the first \(\varepsilon_s\) mass already has exactly the population’s type proportions. There is no sampling error to control. Once an ECEEI gives later demand \(d_j\leq\kappa_j\), with \(d_j=\kappa_j\) when \(p_j>0\), cumulative use is \(A_j(u)=s_j+(u-\varepsilon_s)d_j\). The prefix guarantees then follow deterministically from the initial capacity bound and the choice of \(\varepsilon_s\). The concentration argument and finite market size condition have disappeared.

The remaining computational question is to find that ECEEI for binary encoded type masses and supplies. That could be a substantial problem, but it is a static equilibrium computation, not a computational account of Theorem 2’s online learning and random arrival guarantee. The paper already proves ECEEI existence in Theorem 1 and shows that agents of the same type can share an allocation and random budget. That result does not settle the running time, but it means the continuous mirror’s existence foundation is already in the paper. Likewise, the post-sample EF1 property follows from the same budget and bundle argument; it adds little dynamic content. The mirror also leaves group strategyproofness aside, though that is permissible for an anchor.

A stronger dynamic proposal could allow the type mix to change over time and ask OCAM to learn it. But a general type-flow path is a new input object, potentially an infinite-dimensional one. Restricting it to a finite set of epochs or a specified stochastic model could make a reasonable research problem, but it would require choices beyond the paper’s fixed population in random order. In an atomless stationary flow, the initial segment reveals the type shares exactly, so it does not restore the paper’s learning problem.

This makes the proponent’s claim of a close mirror too strong, but it does not establish that the mirror is not worth studying. Binary-mass ECEEI computation is a coherent high-multiplicity question, and the paper’s same-type construction gives the authors a clear reason to recognize it. I cannot honestly defeat that anchor as a worthwhile continuous mirror; the negative case is mainly that it is a narrower, static follow-on, not a faithful continuization of Theorem 2’s central dynamic result.
