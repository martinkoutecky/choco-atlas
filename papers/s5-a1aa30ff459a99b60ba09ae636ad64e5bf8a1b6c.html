What the mirror covers

The proposed analogue covers Theorem 1’s final-stance welfare objective; it does not cover the stability results, CCR design, or simulations, and it is not anchored in a computational result.

The case FOR (proponent)

The strongest plausible mirror is Continuous Community-Satisfaction Maximization for a large city or DAO drafting a finite set of policy paragraphs. A type is a participant’s complete final stance vector over those paragraphs, including which ones they did not vote on. Its mass \(\mu_t\) is that type’s share of the community. This is a credible high-multiplicity regime when a consultation has many thousands of participants but far fewer distinct stance patterns.

The closest anchor is Theorem 1, proved in this paper: an aggregation rule maximizes community satisfaction on every instance if and only if it is a relative-majority rule. For each paragraph, the rule includes it when the total normalized approval weight exceeds the disapproval weight, excludes it when the reverse holds, and may break ties either way. That is a useful characterization, but it does not state a computational complexity result. Corollary 1—no rule is both a social-welfare maximizer and stable—does not give one either. So under the requested anchor standard, the paper has no named computational result to anchor a ChoCo complexity claim.

The candidate continuous problem is precise. An instance gives a finite paragraph set \(P\), a support \(\Theta\subseteq\{-1,0,+1\}^{P}\) of complete stance types, and positive rational masses \(\mu_t\) summing to \(1\). Let \(d_t\) be the number of paragraphs on which type \(t\) voted. Find a selected set \(S\subseteq P\) maximizing

\[ \sum_{t\in\Theta}\mu_t\frac{1}{d_t} \sum_{p\in P}\mathbf{1}\!\left[\mathbf{1}[p\in S]\text{ agrees with }t_p\right], \]

where abstentions contribute zero, as in the paper. Theorem 1’s characterization implies an exact algorithm polynomial in \(|P|\), the support size \(\tau\), and the mass bit length \(L\): compute the approval and disapproval weights for each paragraph and select independently. This is a faithful population-continuous version of the paper’s welfare objective, and the authors would likely recognize it as their SWM problem.

The mirror covers Theorem 1’s final-stance welfare maximization. It does not cover the dynamic CCR design results or the simulations. A natural follow-on would model updates as transfers of mass between stance types and ask how much future mass can change a paragraph’s status, or whether any welfare-maximizing rule can stabilize against unrestricted future updates. Those are new questions; the paper’s stability impossibility offers motivation, not a computational classification for them.

The weak point is substantial: this is an easy optimization problem already characterized by the paper, and the paper proves no discrete hardness for continuization to dissolve. The honest positive case is therefore that the high-multiplicity model is sensible and yields a clean exact algorithm—not that this paper establishes the computational complexity landscape ChoCo is meant to chart.

The case AGAINST (opponent, writing after the proponent)

The strongest objection is that this paper has no named computational result to mirror. Theorem 1 characterizes which rules maximize its satisfaction measure; Observation 1 and Corollary 1 give impossibility results about rule properties; Theorem 2 is another rule characterization. None studies the complexity of an input problem or presents an algorithmic result. The simulations compare rule families empirically. The proposed continuous optimization problem is coherent, but it is a computational question we would add to the paper, not one of its computational results.

The proponent’s static mirror is the best case against that objection: a large consultation can plausibly have many participants sharing a finite set of stance patterns, and replacing their counts with rational masses preserves the satisfaction objective. But that makes it a weighted restatement of the axiomatic characterization, not a complexity landscape the paper set out to chart. Its authors might recognize it as an extension of their SWM question; that does not supply the missing computational anchor.

The dynamic follow-on is less faithful. The paper’s stability property quantifies over future *event sequences*. Agents can revise votes, abstain, and act repeatedly; the order and number of events matter to dynamic CCRs. A transfer of mass between final-stance types can ask how much a tally must change to flip a paragraph, but that is a static robustness question, not the paper’s stability question. To preserve the dynamics, one would need to model event timing and agents’ history-dependent behavior. Optimizing those choices could be worthwhile research, but the paper does not specify a computational problem there: its agent behavior is simulated, and its LLM setup does not give a formal input model for such an optimization.

So I would argue this is a poor ChoCo target: its most plausible population mirror is sensible, but it is not a mirror of a computational result in the paper; its dynamic alternatives require formulating new problems. The negative case has a clear limit: I cannot show that the static high-multiplicity formulation is uninteresting to the authors. If ChoCo accepts new computational questions built from axiomatic results, Theorem 1 remains a credible candidate, and a universal claim that no scenario could yield a worthwhile mirror would be too strong.
