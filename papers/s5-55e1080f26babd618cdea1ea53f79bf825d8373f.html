The continuous mirror question

Given a finite set of patient-donor and NDD types, a rational mass \(\mu_t\) for each type, and a compatibility relation between types, what is the maximum patient mass that can be covered by compatible \(2\)-cycles and paths from NDDs of at most fixed length \(\ell\)? For each compatible pattern \(Q\), choose a nonnegative rate \(x_Q\), maximizing \(\sum_Q b_Q x_Q\) subject to \(\sum_Q a_{tQ}x_Q \leq \mu_t\) for every type \(t\), where \(a_{tQ}\) counts pattern \(Q\)'s use of type \(t\) and \(b_Q\) counts its patient-donor pairs.

The model it lives in

Types are complete compatibility profiles, each carrying rational population mass \(\mu_t\). Decision variables \(x_Q\) give the rate of each compatible exchange pattern; type-mass constraints limit pattern use, and the objective maximizes covered patient mass. For fixed \(\ell\), the patterns can be enumerated in \(\tau^{O(\ell)}\) time, yielding a rational linear program.

What the mirror covers

The mirror covers Theorem 3’s maximum-cardinality packing result for \(2\)-cycles and paths from NDDs, including hardness for fixed \(\ell \geq 3\). It leaves the paper’s fairness algorithms, weighted matching results, experiments, and dynamic-pool analysis aside.

Open questions for a prover

  • How closely does the LP optimum approximate realizable packings in finite pools as the number of participants per type grows?
  • What changes when paths have unbounded length, or when type-level inclusion fairness is added?

The case FOR (proponent)

The strongest mirror is the packing problem, not the paper’s use of lotteries by itself. A lottery is continuity over outcomes; the mirror below makes the population continuous.

My anchor is Theorem 3, proved in this paper; its \(\ell\ge3\) hardness proof reduces from 3-dimensional matching. The theorem says that, for \(\ell\le2\), a polynomial-time algorithm finds a maximum-cardinality packing of 2-cycles and paths starting from NDDs. For \(\ell\ge3\), finding such a maximum-cardinality packing is NP-hard. I would build the case around the hardness result, since it asks whether discrete difficulty survives when the population becomes mass.

Consider a large kidney exchange pool with many patient-donor pairs but relatively few repeated biological profiles. A type records the donor and recipient attributes needed to determine compatibility; NDD types record the relevant donor attributes. Types must be complete for the compatibility decisions in the model. The input is a finite set of types, a directed compatibility relation between them, and a rational mass \(\mu_t\) for each type, with total mass one. Here \(\tau\) is the number of positive-mass types, and \(L\) is the input bit length. This regime could arise in a national or multi-program pool whose members share categorical blood, antibody, and other compatibility profiles. The paper’s 200-pair experiments are not themselves high-multiplicity instances; the proposed regime is a plausible setting for the same problem.

Call the mirror Continuous Maximum-Coverage Kidney Exchange\(_\infty(\ell)\). Fix \(\ell\). A pattern \(Q\) is either a compatible 2-cycle or a compatible path starting at an NDD and using at most \(\ell\) arcs. Let \(a_{tQ}\) count how many participants of type \(t\) the pattern uses, and let \(b_Q\) count its patient-donor pairs. Choose a nonnegative rate \(x_Q\) of exchanges of each pattern to maximize

\[ \sum_Q b_Q x_Q \quad\text{subject to}\quad \sum_Q a_{tQ}x_Q\le \mu_t\ \ \forall t,\qquad x_Q\ge0. \]

The solution is the rates \(x_Q\) and the resulting maximum covered patient mass. Each assigned unit of mass takes a complete role in a valid cycle or path; \(x_Q\) partitions a type’s population across exchange patterns. It does not give an individual a fractional transplant. This is the aggregate version of the paper’s maximum-cardinality coverage question.

For every fixed \(\ell\), the type-level patterns can be enumerated in \(\tau^{O(\ell)}\) time. The displayed optimization is therefore a rational linear program of polynomial size in \(\tau\) and \(L\), giving an exact polynomial-time algorithm for fixed \(\ell\). The continuous problem is thus expected to be tractable, even for \(\ell\ge3\), where Theorem 3 proves the discrete problem NP-hard. That is a credible Class A mirror of a hardness result: the packing and coverage question remains recognizable, while the indivisibility of a finite set of named pairs is what the mass model relaxes. The paper’s polynomial result for \(\ell\le2\) is consistent with this account, though it is the hardness boundary that makes the mirror especially informative.

I would expect the authors to recognize this as their problem: it preserves the compatibility graph, allowed exchange structures, and objective of covering as many patient-donor pairs as possible. It also fits the paper’s own distinction between finding a packing (G1) and optimizing a fairness lottery over packings (G2). My claim covers Theorem 3’s packing-complexity result, not the paper’s full fairness theory or its computational findings.

The main follow-up is how this LP relates to finite high-multiplicity pools: when does its optimum approximate an actual packing, and what is the integrality gap as the number of pairs per type grows? Other questions are whether type-level inclusion fairness can be optimized over this feasible region, and whether paths of unbounded length create a hard pricing problem.

The weak point is that kidney exchange compatibility can be highly individualized. If crossmatch or other edge data must be encoded into a type, \(\tau\) may approach the number of pairs, leaving little high-multiplicity advantage. And the LP does relax the discrete packing’s integrality; an author might regard that as too substantial a change. I think the mirror survives that objection because the relaxation is precisely the population-as-mass question, and it asks for the same operational quantity—covered patient mass—using the same admissible exchanges.

The case AGAINST (opponent, writing after the proponent)

The strongest objection is that the proposed LP is exact only for a much more homogeneous compatibility graph than the paper’s model. The paper takes an arbitrary directed graph on patient–donor pairs as input. To represent it exactly with a small set of types, compatibility must be uniform between every pair of type classes: whenever the LP uses a type pattern, the corresponding exchanges must actually be available across enough members of those classes. Coarse biological categories do not guarantee that. If types instead record enough information to preserve each pair’s actual compatibility neighborhood, the number of types can grow toward the number of pairs, undermining the claimed high-multiplicity regime.

A stronger mirror—optimizing type-level leximin inclusion probabilities over the same mass-packing model, perhaps with per-capita NDD supply—does not remove this tension. It would be coherent if compatibility really were determined by type pairs. But it would still either assume a uniformity absent from the paper’s arbitrary-graph input or retain enough instance-specific detail to lose the repeated-type premise. Replacing compatibility edges with probabilities could keep types coarse, but would change the question: cycle and path feasibility depends on joint compatibility, not just expected edge presence.

This is a serious limitation of the proposed scenario, not a decisive defeat. I would not object that the LP is merely fractional, that NDD supply cannot scale, or that an easy continuous answer makes the question uninteresting. If the authors accept a regime with repeated profiles and type-determined compatibility, then the fixed-\(\ell\) LP is a well-posed mirror of Theorem 3’s packing question. The paper does not establish that this regime fits real exchange pools, but it does not rule it out either. So the honest negative case is weak: it makes the mirror conditional on a demanding modeling assumption, but cannot show that no worthwhile continuous mirror exists.
