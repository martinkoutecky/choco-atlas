The continuous mirror question

Given rational masses \(\mu_t\) over a finite set \(T\) of recipient types, item classes \(J\) with rational per-capita supplies \(q_j\), intrinsic values \(p_j\), and type eligibility sets \(E_t\), define bundles \(b\in\mathbb{Z}_{\ge 0}^{J}\) with \(b_j=0\) for \(j\notin E_t\), and utility \(u_t(b)=\sum_{j\in E_t}p_j b_j\). Let \(\mathrm{OPT}_\infty\) be the largest \(z\) for which there is a finite-support allocation \(x_{t,b}\ge 0\) satisfying \(\sum_b x_{t,b}=\mu_t\), \(\sum_{t,b}b_jx_{t,b}\le q_j\), and \(x_{t,b}>0\) only when \(u_t(b)\ge z\). Does a randomized algorithm, running in time polynomial in \(|T|\), \(|J|\), and the input bit length, return such an allocation with guarantee \(z\ge c\,\mathrm{OPT}_\infty\) for some universal constant \(c>0\)?

The model it lives in

A high-multiplicity restricted max-min allocation model: each unit of recipient mass has a complete valuation and eligibility type, supplies scale per capita, and every unit receives an integral bundle. The decision variables \(x_{t,b}\) assign type mass to bundles; the objective maximizes the minimum utility, subject to type-mass and item-supply constraints.

The objection that survived

The paper’s configuration LP has essentially the same mass-over-integral-bundles feasible region, so the mirror’s contribution may be limited to whether that formulation admits a support-sensitive algorithm.

fatal: False

What the mirror covers

The mirror covers the constant-factor Santa Claus approximation in Theorem 4.9; it leaves the paper’s coloring, Ramsey, and MAX-\(k\)-SAT results aside.

Open questions for a prover

  • Can a constant-factor approximation be computed in time polynomial in the number of supported types, item classes, and binary input length, without expanding the population or supplies?
  • How does \(\mathrm{OPT}_\infty\) relate to the limit of finite high-multiplicity Santa Claus instances with the corresponding type proportions and scaled supplies?

The case FOR (proponent)

The strongest honest mirror I see is continuous high-multiplicity Santa Claus. Picture a large resource-allocation programme serving many recipients, where people fall into a modest number of eligibility and valuation profiles, and many items are interchangeable copies of a few item classes. A recipient type is the recipient’s complete profile: which item classes they value, and the value they assign to each. The mass \(\mu_t\) is the fraction of recipients of type \(t\). If there are \(N\) recipients, the supply of each item class scales with \(N\); write \(q_j\) for its supply per recipient. In the regime of interest, \(N\) is large while the number of recipient and item classes stays moderate.

My lead anchor is Theorem 4.9, proved in this paper. It states that there is a constant \(\alpha>0\) and a randomized expected-polynomial-time algorithm for the Santa Claus problem that always assigns items so that every child receives total valuation at least \(\alpha\cdot\mathrm{OPT}\). The paper defines Santa Claus as restricted max-min allocation: items are indivisible, and each child values an item either at its intrinsic value or at zero. The paper does call this discrete problem NP-hard in its prose, citing earlier work, but that claim is not a numbered result here, so it is not my anchor.

Here is the continuous problem I would hand to a prover. Call it Continuous Santa Claus Approximation, or \(\mathrm{SC}_\infty\). An instance gives a finite set \(T\) of recipient types with rational masses \(\mu_t\geq 0\), where \(\sum_t\mu_t=1\); a finite set \(J\) of item classes with rational per-capita supplies \(q_j\); and, for each class \(j\), its intrinsic value \(p_j\) and the types that value it. A bundle is an integer vector \(b\in\mathbb Z_{\geq0}^{J}\), with zero entries for item classes that type cannot use. Let \(u_t(b)\) be its value to type \(t\). The decision variable \(x_{t,b}\geq0\) is the mass of type \(t\) receiving bundle \(b\). The constraints are
\[ \sum_b x_{t,b}=\mu_t\quad\text{for each }t, \qquad \sum_{t,b}b_jx_{t,b}\leq q_j\quad\text{for each }j. \]
Define \(\mathrm{OPT}_\infty\) as the greatest \(z\) for which \(x_{t,b}>0\) only when \(u_t(b)\geq z\). The problem asks for a finite-support allocation \(x\) and a guarantee \(z\geq\alpha\,\mathrm{OPT}_\infty\), for some universal constant \(\alpha>0\), in expected time polynomial in the number of supported recipient types, item classes, and input bit length.

The population is what becomes continuous: each unit of mass still receives an integral bundle. Different parts of one type’s mass may receive different bundles, but the objective guarantees every recipient in the resulting allocation at least \(z\); it does not replace that guarantee with an average-utility target. This preserves the paper’s min-max fairness question. The per-capita supply and type-level mass are the natural co-modifications needed to keep the same allocation problem meaningful as the population grows.

I expect the stated approximation problem to be Class A. For a fixed target \(z\), the model is a configuration LP: its variables represent masses assigned to integral bundles, with item-supply constraints. The configuration space can be large, so a support-sensitive algorithm still needs an effective way to generate or price bundle columns. That is a real algorithmic question, but it is exactly where the paper’s configuration-LP approach and continuous-optimization tools are relevant. I am not claiming exact optimization is easy.

The connection is plausible because the paper already studies the same max-min allocation objective and uses configurations as its central tool. Its configuration LP is strong neighboring prior art: in a large population with repeated types, fractional configuration assignments can represent actual proportions of recipients receiving integral bundles. Establishing precisely when the continuous optimum equals the limit of the corresponding finite configuration LPs would be a useful part of the mirror. That is not a collision with the paper’s model: the paper’s problem has finitely many individually represented children and items, while \(\mathrm{SC}_\infty\) makes recipient mass the object of study.

The weak point is the regime. Ordinary Santa Claus instances can contain one-off items and recipients with distinct eligibility profiles; then the number of types may grow with the population and the high-multiplicity premise buys little. The mirror is strongest for settings with large cohorts and repeated item classes, such as recurring allocations of standardized resources to recipients with a small number of established eligibility profiles. It covers Theorem 4.9’s Santa Claus approximation result; I would not stretch it to the paper’s coloring, Ramsey, or MAX-\(k\)-SAT results. Further questions include whether \(\mathrm{SC}_\infty\)’s optimum is exactly the limit of finite high-multiplicity optima, what pricing guarantees support constant-factor algorithms, and whether the exact continuous optimum is tractable.

The case AGAINST (opponent, writing after the proponent)

The Santa Claus anchor is the proponent’s strongest one. Theorem 4.9 is a named algorithmic result, and a recurring allocation programme with many recipients in a small number of valuation and eligibility profiles is a plausible high-multiplicity setting. Scaling item supplies with the population is also a natural co-modification. I can’t honestly defeat that scenario by arguing that recipients are inherently unique or that the population limit is meaningless.

The strongest objection is that the proposed mirror is already the configuration LP developed in Section 4. Its variables assign mass to configurations, each of which is still an integral bundle; its constraints impose recipient mass and item supplies. For a finite instance, grouping identical children and aggregating their fractional configuration variables gives the proposed \(x_{t,b}\) variables. Conversely, a mass allocation can be represented by giving each child of type \(t\) the same fractional mixture of bundles. Thus the population interpretation does not produce a new feasible region or objective: it redescribes the paper’s LP. The paper says that this LP can be solved approximately in polynomial time, and its constant integrality-gap result together with Theorem 4.9 already gives a constant-factor guarantee relative to the LP optimum.

That objection has a limit. The paper’s stated running time is for an explicitly represented finite instance. It does not establish a running time polynomial in the support size and the bit lengths of binary-encoded masses and per-capita supplies. A compressed, support-sensitive pricing algorithm would therefore be a genuine remaining question. But the anchor’s continuous optimization problem is already answered at the configuration-LP level; the residual is whether that same problem can be solved efficiently under a more succinct encoding.

So my negative case is narrow: this anchor may be a novelty collision because the paper already contains its continuous mass-allocation formulation as its central LP. I cannot rule out the value of the compressed-input question, and under the programme’s criteria that gap may be enough for the mirror to survive. A categorical claim that no scenario is worthwhile would overstate the evidence.
