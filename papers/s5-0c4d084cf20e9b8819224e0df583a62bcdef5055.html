The continuous mirror question

Given projects \(O\) with costs \(w_o\), a budget \(W\), and a finite-support distribution \(\mu\) over approval-set types \(A_t\subseteq O\), where the positive masses are binary rationals summing to \(1\), find a feasible funded set \(S\subseteq O\) maximizing \(\sum_t\mu_t|S\cap A_t|\), subject to \(\sum_{o\in S}w_o\le W\).

The model it lives in

A continuous population of residents partitioned into approval-set types \(A_t\), with mass \(\mu_t\) per type; choose an integral funded set \(S\) to maximize average approval utility under the common project-cost budget.

The objection that survived

The distribution over approval types collapses to the per-project masses \(\sum_{t:o\in A_t}\mu_t\), so type correlations do not affect the winner; this limits the mirror’s structural richness but leaves the weighted knapsack question intact.

fatal: False

What the mirror covers

The mirror covers Proposition 34’s utilitarian winner computation for approval ballots with arbitrary project weights. It leaves the strategyproofness results, CCP characterization, score-matrix results, and closest strategyproof score-function algorithm outside its scope.

Open questions for a prover

  • What are tight exact and parameterized complexity bounds in the number of projects \(m\), support size \(\tau\), and mass encoding length \(L\)?
  • Does the problem admit an FPTAS, and how do the bounds change when all masses share a small common denominator?

The case FOR (proponent)

My strongest mirror is narrow: the paper’s approval-ballot winner-computation problem. In a large participatory-budgeting electorate, a voter’s type is their approval set \(A_t\subseteq O\); mass \(\mu_t\) is the fraction of residents with that ballot. Their utility for a funded set \(S\) is \(|S\cap A_t|\). This is a plausible high-multiplicity regime when a city has many residents but relatively few recurring approval patterns. Project costs remain common across voters, and the funded set remains integral; only the population becomes continuous.

The anchor is Proposition 34, proved in Appendix A.1. It says that for a simple CM with approval ballots, arbitrary project weights, and budget \(W\), a polynomial-time algorithm finds a feasible set \(S\) maximizing total voter utility, \(\sum_{v\in V}u_v(S)\), subject to \(\sum_{o\in S}w(o)\le W\). The paper proves this with dynamic programming over the integer approval totals. I rely on this winner-computation result alone, not on a claim about the paper’s central strategyproofness theorems.

The continuous problem is Continuous Utilitarian Approval Knapsack. An instance consists of projects \(O\), costs \(w_o\), a budget \(W\), and a finite list of approval types \(A_t\) with positive binary-rational masses \(\mu_t\) summing to one. Find a set \(S\subseteq O\) that maximizes
\[ \sum_t \mu_t |S\cap A_t| \quad\text{subject to}\quad \sum_{o\in S} w_o\le W. \]
Equivalently, given a rational threshold \(q\), decide whether any feasible \(S\) achieves average utility at least \(q\). The solution is the funded project set. For a discrete electorate with \(n_t\) voters of each type, setting \(\mu_t=n_t/n\) preserves the winning set: the continuous objective is the discrete total divided by \(n\).

For this binary-rational input model, I expect exact optimization to be NP-hard. Reduce from 0–1 Knapsack: make one project per item, with its item cost; for each item \(j\), create a type that approves only project \(j\), with mass \(p_j/P\), where \(p_j\) is its profit and \(P=\sum_jp_j\). Maximizing average approval utility then maximizes knapsack profit, scaled by \(1/P\). This uses only \(\tau=|O|\) types, and the mass encoding has polynomial bit length. I would classify this as a Class C candidate for the stated \((m,\tau,L)\) input: the explicit-electorate problem in Proposition 34 is in P, while concise rational masses can encode large multiplicities and yield a knapsack instance. The hardness is encoding-sensitive, rather than a claim that continuum analysis itself is the source of difficulty.

This mirror covers only approval-based utilitarian winner computation in Section 4. It does not continuize the paper’s score matrices or strategyproofness characterization. It generates useful follow-up questions: does support size \(\tau\) give an FPT or XP algorithm, is there an FPTAS, and how does the answer change when the masses have a small common denominator?

The weak point is that Proposition 34 is a supporting winner-computation result, not the paper’s main strategyproofness contribution; the authors might regard the rational-mass version as a succinct high-multiplicity input variant. Still, the objective, ballots, feasibility constraint, and selected outcome match their problem directly, and the population interpretation is precisely the regime the mirror is meant to expose.

The case AGAINST (opponent, writing after the proponent)

The strongest case against is about how much of the programme this mirror would exercise. In Proposition 34’s setting, the society can be compressed to the project approval fractions \(p_o=\sum_{t:o\in A_t}\mu_t\). The winner depends on those \(m\) numbers; correlations between approval types do not matter. So this mirror has little type structure for continuous optimization to exploit, and its continuous input mainly exposes the effect of encoding population proportions as binary rationals.

That makes it a narrow candidate for ChoCo’s computational landscape. The paper’s strategyproofness results are harder to carry over: in an atomless society, one person’s report changes no mass, so unilateral strategyproofness becomes vacuous. Treating a positive mass of one type as a strategic actor would instead ask about a coalition deviation.

Those concerns do not defeat Proposition 34’s mirror. Its approval-type society is well-defined, large participatory-budgeting electorates are a plausible high-multiplicity regime, and the rational-mass reduction is valid. The resulting question is one the authors could recognize as their winner-computation problem. I cannot honestly argue that no worthwhile mirror exists in any scenario; under the stated grading rule, this anchor survives. The negative case is weak.
