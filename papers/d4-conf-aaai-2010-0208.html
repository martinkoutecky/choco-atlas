The continuous mirror question

Given a binary-encoded population scale \(N\), rational masses \(\mu_t=k_t/N\) over \(\tau\) piecewise-uniform valuation types \(t\), and rational interval descriptions of each type’s reference set \(U_t\), does there exist a succinct mechanism, evaluable in time polynomial in \(\tau\), the description length \(L\), and \(\log N\), that assigns each of the \(N\) individuals a cake piece? The mechanism must produce a partition with free disposal for every report profile, satisfy proportionality and envy-freeness at truthful profiles, and be dominant-strategy truthful for every individual and every alternative piecewise-uniform report. Its representation must specify assignments by type and within-type rank, so a unilateral report change updates the corresponding type masses by \(1/N\).

The model it lives in

A high-multiplicity cake-cutting mechanism over types \(t\) with masses \(\mu_t=k_t/N\), where each type describes a complete piecewise-uniform valuation over cake intervals. The decision rule assigns ordinary cake pieces to individuals, represented by type and within-type rank, and must guarantee proportionality, envy-freeness, and individual dominant-strategy truthfulness; there is no scalar optimization objective.

What the mirror covers

The mirror covers Theorem 4 for truthful, proportional, envy-free cake cutting with piecewise-uniform valuations. It leaves Theorem 7’s randomized result and the paper’s other observations unaddressed.

Open questions for a prover

  • Can the paper’s subset-selection and maximum-flow steps be compressed to run in time polynomial in \(\tau\), \(L\), and \(\log N\)?
  • Can the compressed assignment preserve dominant-strategy truthfulness when a person changes type and therefore changes their within-type rank?

The case FOR (proponent)

The strongest honest positive case is a high-multiplicity version of the deterministic result, anchored only on Theorem 4. It is proved in this paper: for any finite number of agents with piecewise-uniform valuations, Algorithm 1 is truthful, proportional, envy-free, and polynomial-time. Here a type is the agent’s complete valuation: uniform value on a finite union \(U_t\) of cake intervals and zero elsewhere. The paper’s result concerns the finite-agent mechanism itself, not just an encoding or a fractional relaxation.

A plausible regime is a very large group sharing one heterogeneous food supply, such as a large event or relief program. People may have identical valuations because they value the same marked regions uniformly; assume there are \(N\) people but only \(\tau\) distinct valuation types, with \(N\gg\tau\). This is a property of that regime, not of cake cutting generally. The continuous object is the distribution of people over valuation types, not the cake interval: \(\mu_t=n_t/N\), where \(n_t\) people have type \(t\). A type-level average bundle can be fractional even though each person receives an ordinary cake piece.

I would call the mirror High-Multiplicity Truthful Piecewise-Uniform Cake Cutting. An instance consists of a binary-encoded population scale \(N\), rational masses \(\mu_t\) summing to one with \(N\mu_t\in\mathbb Z\), and the \(\tau\) supported types \(t\), each represented by rational interval endpoints for \(U_t\). Let \(L\) include the bit lengths of these descriptions. The solver must provide a succinct mechanism for this population representation. On every reported profile of piecewise-uniform valuations, including a profile after one person changes their report, it produces a partition \((A_1,\ldots,A_N)\) of the cake, with free disposal allowed. Each person receives an integral set of intervals; the representation may describe assignments by type and within-type rank rather than list all \(N\) pieces. At a truthful profile it must satisfy
\[ V_i(A_i)\ge \frac1N \quad\text{and}\quad V_i(A_i)\ge V_i(A_j)\ \text{for every }j. \]
For every person \(i\), every other report profile, and every alternative piecewise-uniform report \(t_i'\), it must also satisfy
\[ V_i(A_i(F(t_i,t_{-i})))\ge V_i(A_i(F(t_i',t_{-i}))). \]
Thus a deviation transfers one unit of mass, \(1/N\), from one type to another. The question for a prover is whether such mechanisms can be represented and evaluated in time polynomial in \(\tau,L,\log N\), while retaining those exact individual incentive and fairness guarantees. A solution is a mechanism with that representation and a proof of the guarantees, or a hardness result ruling out the proposed running time.

I expect this to be Class A, though the compressed bound is a new question rather than a consequence of Theorem 4’s stated runtime. The paper’s exact-allocation step is tied to maximum flow, which gives a plausible route: combine identical-agent nodes into type nodes with capacities \(n_t\), then recover individual pieces by splitting the resulting flow. The main challenge is retaining the theorem’s individual truthfulness guarantee through that compression, including any tie-breaking needed to assign distinct pieces within a type. The output convention matters too: an explicit list of \(N\) bundles necessarily takes \(\Omega(N)\) space, so the proposed question asks for a succinct representation, not a faster way to print a long list.

The soft spot is the scale parameter \(N\). The type distribution \(\mu\) alone does not specify the original proportionality threshold or how much a single person’s report changes the society. In a literal nonatomic limit, the threshold \(1/N\) vanishes and a person’s deviation has zero mass, so the paper’s individual truthfulness question can collapse. This mirror therefore treats \(\mu\) as the continuous population description within a high-multiplicity family, while retaining finite agents as units of mass \(1/N\). That is a plausible reading of the paper’s problem, but a referee who requires a pure nonatomic cake-cutting model could reasonably reject it. The mirror covers Theorem 4 only; the paper contains no named hardness result, and I am not claiming that theorem 4 already gives the compressed algorithm.

The case AGAINST (opponent, writing after the proponent)

The strongest objection is specific to Theorem 4’s individual incentive guarantee, not to cake already being divisible. The theorem’s mechanism takes a profile of \(n\) people and asks, for each person \(i\), whether changing only \(i\)’s report can improve the piece that \(i\) receives. That is a pointwise question about both a report and its owner.

A distribution \(\mu\) over valuation types does not retain that information. In a nonatomic population, one person’s changed report has zero mass, so it leaves \(\mu\) unchanged. If the mechanism acts only on \(\mu\), the deviation cannot affect its output and truthfulness becomes vacuous. The proportionality guarantee also loses its force as \(1/n\) tends to zero. And with an ex-post partition of a fixed cake, at most countably many people can receive positive-measure pieces; in an atomless population, individual utilities collapse to zero. A mechanism that instead specifies each person’s bundle needs individual assignment information beyond the type distribution.

The proposed finite-\(N\) rescue preserves meaningful deviations by making one person’s report a mass change of \(1/N\). That is a sensible high-multiplicity question, and the programme explicitly treats high multiplicity as supporting evidence, not as a novelty collision. But its central object is then a family of finite-agent mechanisms: the algorithm must track the deviator, place them among the members of a reported type, and assign them one of the distinct cake pieces. A histogram of type masses alone does not specify that assignment. Asking for a succinct representation may be worthwhile, but it asks about compressing the finite theorem’s input, output, and incentive proof—not about the theorem’s behavior in a nonatomic society.

The other apparent repairs change the question too. Allowing a positive mass of agents to misreport tests coalition behavior rather than dominant-strategy truthfulness. Giving each person fractional or lottery-valued cake shares can avoid the ex-post allocation problem, but then the mirror relies on changing the outcome model as well as the population. The randomized result, Theorem 7, has the same individual-assignment obstacle: its guarantees are stated for each finite agent receiving a piece in each realized partition.

So I would reject a pure continuous-population mirror of these results: it either erases the unilateral deviation the paper studies or needs extra individual-level structure that the population distribution does not contain. The negative case is weaker against the proponent’s compressed finite-\(N\) formulation. That may be a worthwhile high-multiplicity project under ChoCo’s bridge, but whether it counts as a continuous mirror depends on whether the programme accepts a nonvanishing individual atom as the operative model.
