The continuous mirror question

Given a finite type set \(T\), rational masses \(\mu_t\ge 0\) summing to \(1\), and a rational utility \(u_q\ge 0\) for each multiset \(q\) of one to three types, choose \(y_q\ge 0\), the mass of teams of profile \(q\) per unit population, subject to \(\sum_q q_t y_q=\mu_t\) for every \(t\in T\). Find an allocation maximizing \(\sum_q |q|u_q y_q\).

The model it lives in

A society is a distribution \(\mu\) over student types that include all features relevant to team utility. Each team has an integral type composition \(q\) of size at most three, receives common utility \(u_q\), and has aggregate mass \(y_q\). Maximize per-capita total utility \(\sum_q |q|u_q y_q\) subject to using all type mass.

The objection that survived

The mirror excludes arbitrary agent-specific coalition structure, including the incidence encoding behind Corollary 4, so it does not establish whether that hardness persists when the number of types is modest.

fatal: False

What the mirror covers

Covers Corollary 4’s welfare-maximization problem for teams of size at most three under type-composition utilities. It leaves the paper’s stability results, price-of-anarchy and price-of-stability bounds, and welfare results for unrestricted team sizes unaddressed.

Open questions for a prover

  • For finite cohorts with integer type counts, what is the worst-case integrality gap between the best partition into teams and the type-mass LP optimum as cohort size grows?
  • For fixed \(\tau\), what convergence rate relates normalized finite-cohort welfare to the continuous optimum?

The case FOR (proponent)

The strongest mirror is the paper’s social-welfare maximization problem in a high-multiplicity regime of common-ranking project teams. This anchors on Corollary 4, proved in the paper using the cited APX-completeness of Maximum Independent Set on cubic graphs: finding a partition that maximizes the sum of agents’ utilities is APX-complete for HGCRP, even when every coalition has at most three members. This is a hardness result with a restriction that fits a plausible large-cohort scenario.

Imagine tens of thousands of students forming project teams of one to three people. A type records everything about a student that affects team utility—for example, their complete skill profile and relevant course background. Students of the same type are interchangeable, and every member of a team receives the same grade, determined by the team’s type composition. The number of students can be very large while the number \(\tau\) of distinct types is modest. This draws on the paper’s own project-group motivation and its bounded-coalition setting.

Here is the continuous problem I would hand to a prover. The input is a finite set \(T\) of \(\tau\) types, rational masses \(\mu_t\ge 0\) with \(\sum_{t\in T}\mu_t=1\), and, for every multiset \(q\) of one to three types, a rational common utility \(u_q\ge 0\). A coalition profile \(q\) specifies an integer number of members of each type; \(|q|\) is its team size. Find a feasible allocation of the population to teams maximizing per-capita total utility.

Let \(y_q\ge 0\) be the mass of teams of profile \(q\), measured per unit of population. The allocation must satisfy
\[ \sum_q q_t y_q=\mu_t \qquad\text{for every }t\in T, \]
and its welfare is
\[ \max \sum_q |q|\,u_q\,y_q. \]
A solution is an optimal vector \(y\), together with a partition realizing it. The coalition profiles still have integral sizes; it is the aggregate number of teams that can be fractional. In an atomless society, type mass can be split among profiles and assembled into teams accordingly.

This is a credible continuous version of the underlying problem: it keeps partitioning into coalitions, the common utility within each coalition, the size limit, and the paper’s utilitarian objective. It makes the high-multiplicity assumption explicit by requiring that agents of the same type have identical consequences under every team composition. For the student-team scenario, that is a meaningful modeling regime: standardized grading can depend on skills and team composition rather than student identities.

The continuous problem is tractable. There are only \(O(\tau^3)\) possible team profiles of size at most three, so the formulation is a rational linear program with polynomially many variables and constraints; it can be solved in time polynomial in \(\tau\) and the input bit length. This is a Class A mirror of the paper’s APX-hard discrete anchor. It does not establish that the corresponding discrete problem is easy: rounding an optimal mass allocation into an actual finite cohort of students raises a separate integrality-gap question.

The mirror covers Corollary 4’s welfare-maximization result only, not the paper’s stability or price-of-anarchy results. It also opens questions about the integrality gap when type counts scale up, rounding guarantees when \(\tau\) is moderate, and whether welfare remains tractable when team sizes are unbounded and the pricing problem ranges over many type compositions.

The weak point is that the mirror imposes type-composition anonymity, while the paper allows utilities to vary across named-agent coalitions. That is a real restriction. I think it remains defensible because it is exactly the structure needed for a large repeated population of interchangeable agents, and it preserves the bounded-team welfare question that Corollary 4 studies.

The case AGAINST (opponent, writing after the proponent)

The strongest case against this anchor is that the paper’s hardness comes from who can be grouped with whom. In Corollary 4’s reduction, each agent represents an edge of a cubic graph, and each high-value coalition represents the edges incident to a vertex. The overlaps among those named agents encode the independent-set problem. If a type records only skills and team utility depends only on type composition, that incidence structure disappears. To preserve it, types would need to encode agents’ graph-specific roles; in the hard instances, that can make the number of types grow with the population and remove the claimed high-multiplicity regime.

That is a real scope concern, but it does not dispose of the proposed mirror. The paper itself offers project groups as an application, and a large cohort with repeated skill profiles and composition-based grading is plausible. In that regime the allocation over team profiles is a valid continuous-population question: the masses represent per-capita frequencies, and fractional profile counts are the natural aggregate model. With team size at most three, there are \(O(\tau^3)\) profiles, so the welfare problem is an explicit linear program. Calling this a standard configuration LP describes why it is easy; it does not make the question ill-posed or out of scope.

A stronger attempt would preserve richer compatibility data by adding it to agents’ types. But if those data encode arbitrary incidence patterns, \(\tau\) may approach the number of agents, so the model loses the compression that motivated continuization. If instead we keep a modest number of types, we get the tractable composition-based problem, but not the hardness structure in Corollary 4.

That is the best negative argument, and it falls short of the required universal claim. The proposed model is a meaningful high-multiplicity regime of the paper’s project-team problem, even though it does not preserve the reduction behind the hardness result. I cannot honestly say that no worthwhile continuous mirror exists here.
