The continuous mirror question

Given a finite support of complete types \(T\), rational masses \(\mu_t>0\) summing to \(1\), and rational values \(v_t(s)\), realize each type as an atomless population \(\Omega_t\) of mass \(\mu_t\). For a measurable coalition \(B\), let a type-\(t\) member's utility be \(U_t(B)=\sum_{s\in T}v_t(s)\lambda(B\cap\Omega_s)\). Decide whether there is a measurable partition \(\Pi^*\) into positive-mass coalitions such that, against every partition \(\Pi'\) inequivalent to it modulo null sets, \(\Phi(\Pi^*,\Pi')=\int_\Omega \operatorname{sgn}(U_{t(x)}(\Pi^*(x))-U_{t(x)}(\Pi'(x)))\,d\lambda(x)>0\).

The model it lives in

An atomless population with rational masses \(\mu_t\) of complete ASHG utility types, where type-\(t\) utility for a coalition is the mass-weighted sum \(\sum_s v_t(s)\lambda(B\cap\Omega_s)\). Outcomes are measurable partitions modulo null sets, and the decision is whether one partition strictly defeats every other in the population majority comparison. Any winning partition must place each type's whole mass in one coalition, since exchanging equal-mass subsets of a split type yields a distinct partition with the same utilities; challengers may still split types. The comparison remains over partitions, rather than becoming an equilibrium concept for nonatomic strategic players.

The objection that survived

If partitions are distinct as exact sets, moving a null-mass point between existing positive-mass coalitions can create a tied distinct challenger; the model should identify partitions modulo null sets.

fatal: False

What the mirror covers

The mirror covers the existence decision in Theorem 1.1 for type-structured ASHGs; it leaves aside verification complexity, weak popularity, and other hedonic-game variants.

Open questions for a prover

  • Can every mass-splitting challenger that defeats a candidate be replaced by a type-level partition challenger?
  • Can the PCW-hardness construction be made robust to all measurable type-splitting deviations?
  • Does a suitable finite encoding capture comparisons against every admissible measurable partition?

The case FOR (proponent)

I would anchor the case on Theorem 1.1, proved in this paper. It says that deciding whether an input ASHG has a strongly popular partition is PCW-complete. In full, the input is an additively separable hedonic game \(\langle N,v\rangle\); the question is whether there is a partition \(\pi^*\) such that, for every other partition \(\pi\), the number of agents who strictly prefer \(\pi^*\) to \(\pi\) exceeds the number who strictly prefer \(\pi\) to \(\pi^*\). PCW is the class of problems polynomial-time reducible to Ckt-Condorcet: given circuits \(C_1,\ldots,C_m\) that map \(n\)-bit strings to \(n\)-bit merits, decide whether some \(x\in\{0,1\}^n\) satisfies \(\sum_i \operatorname{sgn}(C_i(x)-C_i(y))>0\) for every \(y\ne x\). The paper proves containment and PCW-hardness by encoding the circuit comparisons in ASHG gadgets. The class was introduced in [GGKN25]; Theorem 1.1 is the result proved here.

The mirror I find plausible is Mass-AShG Strong Popularity. Its instance is a finite support \(T\) of complete agent types, rational masses \(\mu_t>0\) summing to \(1\), and rational values \(v_t(s)\) for each pair of types. A type specifies everything the game uses: a type-\(t\) agent assigns the same value \(v_t(s)\) to every member of type \(s\). Realize each type as an atomless population \(\Omega_t\) of mass \(\mu_t\). A coalition is a measurable set of positive mass, and a coalition structure is a finite or countable measurable partition of the population into such coalitions. A type-\(t\) member of coalition \(B\) has utility \(U_t(B)=\sum_{s\in T}v_t(s)\lambda(B\cap\Omega_s)\), where \(\lambda\) is population mass. The utilities are the original additive utilities normalized by population size; the normalization preserves preferences.

For two structures \(\Pi,\Pi'\), define their majority margin by \(\Phi(\Pi,\Pi')=\int_\Omega \operatorname{sgn}\!\left(U_{t(x)}(\Pi(x))-U_{t(x)}(\Pi'(x))\right)\,d\lambda(x)\), with ties contributing zero. The question is whether there is a structure \(\Pi^*\) with \(\Phi(\Pi^*,\Pi')>0\) for every distinct admissible \(\Pi'\). A solution is the winning coalition structure.

There is a useful consequence of the atomless population in this model. If a candidate structure puts positive mass of type \(t\) in two coalitions \(A\) and \(B\), exchange equal-mass subsets of type \(t\) between them. Each coalition’s type-mass vector stays the same. All other members retain their utilities, and the exchanged agents’ preference changes cancel in equal masses. The resulting distinct structure ties the candidate, so the candidate cannot be strongly popular. Therefore every winning structure puts each type’s whole mass in one coalition. A solution can be encoded simply as a partition of \(T\), while the challengers in the definition remain all admissible mass partitions. This gives the prover a finite witness without restricting the deviations being tested.

A plausible regime is a large federation whose members form political or organizational blocs. There may be hundreds of thousands of members but only a small number \(\tau\) of complete preference types, such as stable profiles of institutional role and policy alignment. Coalition membership remains integral for every person; the population mass determines how many members of each type are in a coalition and therefore their additive utility. This is a population continuization, with mass-scaled utility as the co-modification. The paper’s question is still recognizable: does one coalition structure beat every alternative in a majority comparison?

I would provisionally expect hardness to transfer (Class B). The anchor’s hard choices are the circuit outputs and comparisons over candidate strings, and the paper represents those choices through gate gadgets and voter agents. That combinatorics lives in the type support and the comparison agenda, so it does not appear to depend only on having many indistinguishable agents. This is a prediction, not a consequence of Theorem 1.1: a transfer proof must show that allowing an alternative to split a type’s mass does not defeat the intended gadget behavior. The key further question is whether every damaging mass split can be replaced by a finite type-level deviation, or whether these splits create a continuum-specific source of hardness. If they cannot be controlled, Class C would be the better classification.

The high-multiplicity bridge has a clean one-way form here. A finite game of replicated types, with \(n_t\) agents of type \(t\), corresponds to masses \(\mu_t=n_t/n\). Every finite partition of those agents gives a measurable mass partition. Thus a continuous winner induces a strongly popular partition in the corresponding finite replicated game. The converse needs separate work: the continuum admits fractional splits of each replicated type, and a finite Condorcet margin need not provide a uniform positive margin against all such deviations.

My weakest point is the mass-scale coalition regime. It represents only positive-mass coalitions and omits a population spread across vanishing-size or singleton coalitions. The strict-majority condition also makes the continuum sensitive to arbitrarily small deviations, so finite hardness does not automatically survive. The mirror still covers the paper’s central existence result directly, and it turns those limitations into concrete questions: can spoilers be finitely compressed, and can the circuit reduction be made robust to mass splitting?

The case AGAINST (opponent, writing after the proponent)

The only anchor is Theorem 1.1, and I cannot honestly defeat it. It is a named computational result, and the proposed mass model preserves its central question: does one coalition structure beat every alternative by a strict majority? With complete agent types and utilities based on coalition mass, the majority margin has a direct population version. Large organizations with repeated role and preference types are a plausible regime.

The strongest objection is a degeneracy in how “distinct partition” is defined. If exact measurable sets count as distinct and singleton coalitions are allowed, take any agent and move them into a singleton coalition. That changes no coalition’s type masses; all other agents’ utilities stay the same, and the moved agent has measure zero. The margin is therefore zero, so no partition can be strongly popular. But quotienting outcomes up to null sets, or requiring every coalition to have positive mass, removes this degeneracy. Those are standard, plausible choices for a continuum model, and the proponent has already made one of them.

After that repair, the question remains well-posed. Fragmenting a type creates a real challenge: the proposed finite description of a candidate does not by itself settle comparisons against all measurable alternatives. But that is a problem for the complexity analysis, not a reason to dismiss the mirror. Existing atomless hedonic work studies coalition stability analytically; it does not answer the computational question of strong popularity, so it is not a novelty collision ([*Gamson’s Law and Hedonic Games*](https://idei.fr/sites/default/files/medias/doc/by/lebreton/gamson.pdf)).

So my negative case is weak. It identifies a modeling choice that must be made explicit, but it does not rule out the repaired mass model or show that the authors would reject it. The anchor survives.
