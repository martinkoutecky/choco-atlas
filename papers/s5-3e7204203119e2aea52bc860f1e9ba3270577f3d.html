The case FOR (proponent)

The paper contains no named computational result of the kind this programme requires. Its closest result is Theorem 2, proved in the paper: for sufficiently large request-grid precision \(K\), the finite \(N\)-player repeated bargaining game converges with probability one to a state where every player accepts all partners and the allocation lies in the interior of the core. Theorem 1, also proved here, characterizes strict Nash equilibrium outcomes as exactly those states. These are results about equilibrium and learning dynamics, not about the complexity of computing a solution or an algorithm for doing so.

There is a plausible direction for a future continuous model: large cohorts of short-lived bargainers sharing the same production technology and preferences, with mass distributed across their current requests and partner choices. But the paper studies a fixed finite set of players, with coalition values defined on subsets of that set. Its convergence proof also uses finite-state dynamics and events involving particular individuals, such as a scapegoat leaving a group. A continuous version would need new assumptions about scaling coalition values and forming groups, plus a new convergence result.

So that direction may be worth studying, but it is not a continuous mirror anchored in a named computational result of this paper.

The case AGAINST (opponent, writing after the proponent)

The strongest case against a mirror is that the paper gives no computational problem to mirror. Theorem 1 characterizes strict Nash equilibrium outcomes as interior-core allocations; Theorem 2 proves almost-sure convergence in a finite-state learning process. Neither asks for an algorithm, states an input and output, or gives a complexity result. A continuous limit of Theorem 2 would be a question about learning dynamics and convergence—the analytic kind of question ChoCo explicitly sets aside.

The best computational reframing of Theorem 1 would ask for a strict-core allocation, or for an equilibrium outcome. The paper assumes convexity and strict superadditivity, which already ensure such allocations exist. With \(v(S)\) listed for every coalition, one can formulate the search as a linear program over those coalition constraints. With a succinct description of \(v\), the hard part becomes separation over coalitions. A continuous version would also need a new representation of coalition value as a function of type masses. Those choices could define worthwhile algorithmic questions, but the computational content would come from the added representation and search task, not from a result in this paper.

Theorem 2 has a tempting cohort interpretation: many identical short-lived bargainers with a shared production technology. But its convergence argument acts on named individuals. A particular player can be left alone, lower her request as a scapegoat, and later join another group; partner lists name particular players, and the formation rule selects among feasible partitions with minimum coalition count. In an atomless population, one person has zero mass, so those steps have no direct mass-level counterpart. Encoding each identity as a separate type preserves the steps but gives no high multiplicity. Replacing individual exits with mass-level faction changes is possible, but it requires a new coalition-formation rule and new dynamics. The resulting convergence question remains an analytic one.

The universal claim is weakest at its edges: one could define homogeneous cohorts, a succinct mass-based production function, and a computational task for finding a core allocation. That could be a useful project in its own right. But it would supply the problem and its computational structure from outside this paper. For ChoCo’s purpose, this is a poor candidate for a continuous computational mirror: the paper’s named results are analytic, and the learning result’s essential transitions depend on individual identities.
