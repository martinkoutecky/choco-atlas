  • Theorem 3.1 — survived: Its continuous analogue asks for the same market-clearing and approximate best-response conditions over rational masses of complete utility types.

The continuous mirror question

Given finite sets of agent types \(\mathcal R\) and good classes \(\mathcal G\), rational masses \(\mu_r>0\) and supplies \(\sigma_j>0\) summing separately to \(1\), and normalized rational utilities \(u_{rj}\in[0,1]\), compute prices \(p_j\ge 0\) and per-capita bundles \(x_{rj}\ge 0\). Require \(\sum_j x_{rj}=1\), \(\sum_r\mu_r x_{rj}=\sigma_j\), \(\sum_j p_jx_{rj}\le 1+\eta\), \(\sum_j u_{rj}x_{rj}\ge V_r(p)-\eta\), and \(\min_j p_j=0\), where \(V_r(p)=\max\{\sum_j u_{rj}z_j:z_j\ge0,\sum_jz_j=1,\sum_jp_jz_j\le1\}\). For type \(r\) with distinct positive utility levels \(0=u_r^{(0)}<\cdots<u_r^{(t_r)}=1\), define \(k_r^*=\max\{k:\sum_{h=k}^{t_r}(u_r^{(h)}-u_r^{(h-1)})/u_r^{(h)}\ge1\}\). Is there an algorithm polynomial in \(\tau=|\mathcal R|\), \(g=|\mathcal G|\), the binary input length \(L\), and \(1/\delta\), returning such an equilibrium with \(\eta\le\max_r(1-1/(t_r-k_r^*+1))^{t_r-k_r^*+1}+\delta\)?

The model it lives in

A continuum HZ market with type masses \(\mu_r\), good supplies \(\sigma_j\), and complete utility vectors \(u_{r\cdot}\). The decision variables are prices \(p_j\) and type-level bundles \(x_{rj}\), equivalently mass allocations \(y_{rj}=\mu_rx_{rj}\). There is no scalar objective: compute a market-clearing allocation at prices where each type approximately optimizes its per-capita bundle.

What the mirror covers

The mirror covers Theorem 3.1's approximate-equilibrium computation; it leaves the exact irrationality result of Theorem 1.2 and Proposition 5.9 outside. Hashimoto's continuum HZ model and finite-market approximation predate this paper, but do not settle the proposed compressed computational bound [Hashimoto (2018)](https://www.sciencedirect.com/science/article/abs/pii/S0022053118304423).

Open questions for a prover

  • Can the utility-stratification construction be paired with a weighted bi-valued equilibrium algorithm whose running time is polynomial in \(\tau\), \(g\), and \(L\), without expanding the masses into named agents and goods?
  • Can the \(1/e\)-style error guarantee be improved in this compressed type-mass model?

The case FOR (proponent)

The strongest anchor is Theorem 3.1 (Main Result), proved in this paper. The paper does not prove a named hardness result of its own, so I would use this algorithmic anchor rather than present hardness cited from earlier work as the paper’s result.

Theorem 3.1 says that for a normalized \(n\times n\) HZ market, with each agent’s distinct positive utility levels \(0=u_i^{(0)}<u_i^{(1)}<\cdots<u_i^{(t_i)}=1\), and with
\[ k_i^*=\max\left\{k\in[t_i]:\sum_{h=k}^{t_i}\frac{u_i^{(h)}-u_i^{(h-1)}}{u_i^{(h)}}\ge 1\right\}, \]
Algorithm 2 runs in time polynomial in \(n\) and \(1/\delta\), for any \(\delta>0\). It returns a pair \((x,p)\) that clears every good exactly, gives every agent exactly one unit of goods, keeps each budget within the stated additive error, and gives each agent utility within that error of her optimal utility at prices \(p\), with the price normalization \(\min_j p_j=0\). The error is at most
\[ \bar\epsilon=\max_i\left(1-\frac{1}{t_i-k_i^*+1}\right)^{t_i-k_i^*+1}+\delta. \]
In particular, choosing \(\delta=1/(2en)\) gives a polynomial-time algorithm with \(\epsilon<1/e\). The equilibrium notion and the full guarantee matter here: this is a constant-error algorithm for the underlying HZ market, not an algorithm merely for its encoding. Its proof uses the exact bi-valued algorithm cited from Vazirani and Yannakakis.

I would mirror it in a large campus housing market. There are \(N\) students and \(N\) room units, but only a small number of student cohorts and room classes. A student’s type is her complete normalized cardinal utility vector over room classes, along with the common HZ budget of one. Students in a cohort have identical utilities and are interchangeable for every part of the model. Rooms belong to the same class only when every student type values them identically. Let \(\mu_r\) be the fraction of students of type \(r\), and \(\sigma_j\) the fraction of rooms in class \(j\). The high-multiplicity regime is \(\tau,g\ll N\), where \(\tau\) is the number of positive-mass student types and \(g\) the number of positive-supply room classes. Individualized preferences belong in different types; this model does not erase them by assumption.

My lead question is Continuous High-Multiplicity Approximate HZ Equilibrium. Its input is finite lists of active agent types \(\mathcal R\) and good classes \(\mathcal G\), rational masses \(\mu_r>0\) and supplies \(\sigma_j>0\) with \(\sum_r\mu_r=\sum_j\sigma_j=1\), and normalized rational utilities \(u_{rj}\in[0,1]\). A solution is a price \(p_j\ge 0\) for each class and a nonnegative mass allocation \(y_{rj}\). Require \(\sum_j y_{rj}=\mu_r\) for every type and \(\sum_r y_{rj}=\sigma_j\) for every class. The per-person bundle for type \(r\) is \(x_{rj}=y_{rj}/\mu_r\). At prices \(p\), define
\[ V_r(p)=\max\left\{\sum_j u_{rj}z_j:\ z_j\ge0,\ \sum_j z_j=1,\ \sum_jp_jz_j\le1\right\}. \]
For error \(\eta\), require \(\sum_jp_jx_{rj}\le1+\eta\), \(\sum_j u_{rj}x_{rj}\ge V_r(p)-\eta\), and \(\min_jp_j=0\) for every type and the price vector, respectively. The task is to compute such prices and an allocation. There is no separate welfare-maximization objective: the goal is a market-clearing allocation supported by prices at which each type is approximately optimizing.

The direct analogue of the theorem’s guarantee uses each type’s utility levels and its corresponding \(k_r^*\), with
\[ \eta\le\max_r\left(1-\frac{1}{t_r-k_r^*+1}\right)^{t_r-k_r^*+1}+\delta. \]
The complexity question is whether this can be achieved in time polynomial in \(\tau\), \(g\), the binary input length \(L\), and \(1/\delta\), without expanding the population into \(N\) named students and rooms.

This is a credible mirror of the paper’s problem. For rational masses, choosing a common denominator gives a finite market with \(N\mu_r\) students of type \(r\) and \(N\sigma_j\) rooms of class \(j\). Conversely, averaging bundles within identical-agent groups and equalizing prices within identical-good groups gives the mass representation. The paper’s Lemmas 4.1 and 4.2 establish those same symmetry-preserving operations, so the aggregation is grounded in the authors’ own equilibrium analysis. HZ’s divisible allocations are not the continuization here; the population is represented directly by type masses, with per-capita supplies scaled to match.

I expect Class A, with an important qualification. The theorem’s utility stratification can be applied to each type rather than each named student, and the resulting bi-valued market has a natural capacitated formulation. The missing step is a polynomial-time weighted bi-valued equilibrium algorithm in the binary encoding of masses and supplies. Theorem 3.1 itself only guarantees polynomial time in the explicit market size \(n\); expanding a rational mass input into \(N\) individuals may take time exponential in \(L\). So the paper supplies a strong algorithmic template, not a proof of the compressed-input bound.

The mirror covers Theorem 3.1’s approximate-equilibrium computation. Its no-waste guarantee in Corollary 4.10 is a plausible further extension, but I would not count it as a separate anchor: it uses the same construction. Theorem 1.2 and Proposition 5.9 establish an irrationality phenomenon for exact equilibria of one finite instance, not a complexity classification; I would leave them outside this mirror. They also counsel against making rational exact equilibrium the task.

The weakest point is the compressed bit complexity. A weighted capacity formulation may expose a real obstacle, and the paper’s tight example shows tightness of its analysis, not a lower bound against other algorithms. That is precisely the useful next question: can the \(1/e\)-style approximation be computed from type masses and capacities in time polynomial in their compressed representation, and can its error be improved?

The case AGAINST (opponent, writing after the proponent)

The strongest case against is that Theorem 3.1 has a real computational anchor, but its guarantee is tied to the explicit market size \(n\), not to population multiplicity. Its algorithm creates \(W\) copies of every agent and good, with \(W=\lceil n/\delta\rceil\), then runs the bi-valued algorithm on the expanded market. The paper therefore establishes polynomial time in \(n\) and \(1/\delta\), not in the number of distinct types and the bit length of their masses. In a generic HZ instance, complete cardinal utility vectors can all be different, so the type count may be \(n\). The campus example needs evidence that exact preference types and room classes stay few as the market grows; “large market” alone does not provide it.

The strongest version of the proposed mirror is still well-posed: give each complete utility type a rational mass, each room class a rational supply, and ask for prices and per-type bundles satisfying the approximate HZ conditions. But the promised gain now depends on a new algorithm polynomial in \(\tau\), \(g\), and the input bit length. The paper does not establish that bound. Its stratification proof handles repeated rows symmetrically, yet the algorithm explicitly expands them; the missing step is a weighted, capacitated version of its bi-valued subroutine. That may be a fairly narrow extension of matching and pricing machinery. If so, the result could amount to running the finite-market algorithm on run-length encoded duplicate rows and columns, with little new complexity structure. If the extension is difficult, that difficulty could make the mirror more interesting; the paper gives no reason to expect either outcome.

Continuum HZ models also predate this paper: Hashimoto formulates an HZ extension for a continuum of agents and studies its approximation by finite-market mechanisms. That work does not settle the computational question, so it is not a novelty collision under ChoCo’s criteria. It does mean that the type-mass equilibrium model itself supplies little novelty; the case for the project rests almost entirely on the compressed-input algorithmic result. ([Hashimoto, 2018](https://www.sciencedirect.com/science/article/abs/pii/S0022053118304423))

I cannot honestly make the requested universal negative case. Repeated student utility profiles and repeated room classes are plausible, and the paper’s symmetrization arguments support the aggregation. The strongest defensible verdict is narrower: the proponent has identified a legitimate mirror, but has not shown that its compressed version is a substantial or nonroutine research problem. That weakens the case for prioritizing it; it does not show that no worthwhile scenario exists.
