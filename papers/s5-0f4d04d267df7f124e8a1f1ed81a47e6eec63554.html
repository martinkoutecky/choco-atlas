The continuous mirror question

Given programs \(P\), applicant types \(T\) with rational masses \(\mu_t\) summing to \(1\), acceptable type-program pairs, type rankings, program priority tiers over types, and per-unit costs \(c(p)\in\{0,1\}\), find a mass assignment \(x_{t,p}\geq 0\) with \(\sum_p x_{t,p}=\mu_t\) for every type. Set capacity \(y_p=\sum_t x_{t,p}\), and minimize \(\sum_p c(p)y_p\), subject to no blocking pair: for every acceptable \((t,p)\), \(\left(\sum_{r:\,p\succ_t r}x_{t,r}\right)\left(\sum_{u:\,t\succ_p u}x_{u,p}\right)=0\).

The model it lives in

A zero-initial-capacity matching problem over a distribution of applicant types. Each type records its complete program preferences and priority category at every program; variables \(x_{t,p}\) assign mass, capacities equal assigned mass, and the objective is total per-capita augmentation cost.

The objection that survived

Theorem 2 does not itself establish hardness for the priority-tier mass model, since its reduction uses strict rankings among individuals; the proponent acknowledges this formal gap, and the sketch makes it plausible but does not close it.

fatal: False

What the mirror covers

The mirror covers Theorem 2’s constant-factor inapproximability for MinSumC under master-list preferences and two costs. It leaves the MinMax algorithm and the other approximation and hardness results unaddressed.

Open questions for a prover

  • Does the paper’s Set Cover reduction give the same constant-factor inapproximability for the priority-tier mass model, including when types split fractionally across programs?

The case FOR (proponent)

A strong mirror is the cost of creating enough program capacity to place a large cohort in a stable matching. A plausible regime is a centralized school or training placement with many applicants but a limited number of preference templates and public priority categories. A type records an applicant’s complete preference list and priority class at every program. If there are \(N\) applicants and \(\tau\) such types, the regime of interest has \(N\gg\tau\); \(\mu_t\) is type \(t\)’s fraction of the cohort. The problem remains recognizably theirs: all applicants must be placed, the matching must be stable, and the planner minimizes the cost of added seats. Capacity and seat cost are expressed per capita.

I would call the mirror Type-Mass MinSumC. Its input is a finite set of programs \(P\), types \(T\), acceptable type-program pairs, rational masses \(\mu_t\) summing to \(1\), and costs \(c_p\in\{0,1\}\). Each type has a strict ranking of its acceptable programs, and each program has a priority order over types. Initial quotas are zero. A solution is a mass assignment \(x_{t,p}\geq 0\), with \(\sum_p x_{t,p}=\mu_t\). Set the augmented capacity of program \(p\) to its assigned mass, \(y_p=\sum_t x_{t,p}\), and minimize \(\sum_p c_p y_p\).

Stability here means that no positive mass of type \(t\), assigned to a program it ranks below \(p\), can claim \(p\) while \(p\) holds positive mass of types it ranks below \(t\). Formally, for every acceptable \((t,p)\), require either
\[ \sum_{r:\,p\succ_t r}x_{t,r}=0 \quad\text{or}\quad \sum_{u:\,t\succ_p u}x_{u,p}=0. \]
Thus a fractional split of a type is allowed, but any positive-mass blocking pair makes the assignment infeasible. For the restricted instances below, require a master order on programs and a master priority order on types, as in the paper’s master-list condition.

My anchor is Theorem 2, proved in this paper by a Set Cover reduction in Section 5.1: *MinSumC cannot be approximated within a constant factor unless \(P=NP\), even when agents’ and programs’ preferences are derived from master lists and the instance has only two distinct costs.* MinSumC is the paper’s zero-initial-quota case: choose quota augmentations and an \(A\)-perfect stable matching to minimize total augmentation cost.

I expect hardness to transfer to this mirror (Class B). The paper’s set-cover gadget appears to survive grouping and fractional assignment. Given a Set Cover instance with \(n\) elements and \(m\) sets, make one element type per element, of mass \(1/[n(m+1)]\), and one dummy type per set, of mass \(1/(m+1)\). Each set has a cost-1 program and a cost-0 dummy program. An element type accepts the set programs for sets containing its element; a dummy type prefers its set program to its dummy program. The set program prioritizes its dummy type over all element types. If any element mass goes to a set program, stability forces that set’s entire dummy mass there too: otherwise the dummy mass left at its preferred dummy program blocks. And because every element type must be assigned, the set programs receiving positive element mass cover all elements. Conversely, a set cover gives a stable assignment by sending each element type to its highest-ranked chosen covering set. Repeating each unit \(K\) times gives \(N=Kn(m+1)\) agents represented by only \(n+m\) types. Fractional splitting does not remove the cover choice: the hard decision is which set programs receive positive mass.

The authors should recognize this as their capacity-planning problem with the population represented by type masses. This case covers MinSumC and its total-cost objective; it does not claim a mirror of the paper’s MinMax result or every approximation result. The main follow-up is whether the reduction yields the same constant-factor inapproximability formally, and whether other type-mass regimes admit exact algorithms or useful approximations.

My weakest point is the type aggregation in the hardness sketch. The paper uses strict individual rankings, while identical members of a continuous type are tied with one another; a referee could ask whether the within-group priority details matter. In this gadget they do not affect the cover argument, which depends on priority between dummy and element types. A formal proof would still need to establish that carefully. The school-placement scenario also applies only where preference and priority profiles are genuinely concentrated into relatively few types; it is not a claim about every admissions market.

The case AGAINST (opponent, writing after the proponent)

The only substantial objection I see to the Theorem 2 mirror is that its claimed type compression does not preserve the paper’s strict program priorities. In the Set Cover reduction, the \(n\) dummy agents for a set are ranked individually, and element agents also occupy distinct positions in the programs’ master order. After duplicating the instance \(K\) times, those copies are therefore not identical in every respect the problem uses. Under the paper’s strict-ranking model, the support size does not collapse to \(n+m\); priority positions distinguish the copies.

There is a good repair: treat applicants with the same preference profile and priority category as one type, with members tied within that category. The proposed mass stability condition then gives a sensible capacity-planning problem. The reduction appears to survive: touching a set program with positive element mass forces its preferred dummy mass there, and every element type must still send mass to a covering set. Fractional splitting does not obviously erase that cover choice. But this repair uses priority tiers, hence a weak-priority version of the paper’s strict HR model. The paper’s theorem does not by itself prove the hardness claim for that version.

That mismatch is a caveat, not a convincing reason to rule out the mirror. Priority categories are plausible in school placement, the population can have high multiplicity, and capacity and cost can sensibly be measured per capita. The paper has named computational results, and I see no basis for claiming that a continuous computational treatment has already answered this question. So I cannot honestly make a strong case that no worthwhile mirror exists: the opponent’s compression argument needs a formal proof in the priority-tier model, but its central question survives that objection.
