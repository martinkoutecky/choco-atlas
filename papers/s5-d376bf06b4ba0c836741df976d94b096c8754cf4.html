What the mirror covers

The proposed mirror addresses Theorem 2's multicore nonemptiness question. It leaves Theorem 3 and Propositions 1–3 without a mirror; none supplies a computational anchor under the stated test.

The case FOR (proponent)

My lead is Continuous Multicore Nonemptiness, mirroring Theorem 2. The theorem is proved in this paper. It says that the multicore is nonempty exactly when every system of balancing multiweights \(\tilde\delta\) satisfies
\[ \sum_{j=1}^{m} V_j(N)\ \ge\ \sum_{j=1}^{m}\sum_{i\in N}\sum_{S\subseteq N} \tilde\delta(S,i,V_j)V_j(S). \]
Here the weights are nonnegative, assign zero weight when \(i\notin S\), exhaust each agent’s resources in every issue,
\[ \sum_i\sum_S\tilde\delta(S,i,V_j)\chi^S=\chi^N, \]
and give each agent the same resource shares across issues:
\[ \sum_S\tilde\delta(S,i,V_j)\chi^S = \sum_S\tilde\delta(S,i,V_{j'})\chi^S \quad\text{for every }i,j,j'. \]
This is a computational anchor by the paper’s LP-formulation route: its proof formulates nonemptiness as a linear program and uses LP duality to obtain the balancing-multiweights test. The authors do not state a complexity class, but with rational values explicitly listed for every coalition, their LP is polynomial in the size of that table. The paper has no named hardness result, so there is no hardness anchor here.

In the mirror, a society has \(\tau\) types with positive masses \(\mu_t\), where \(\sum_t\mu_t=1\). A type is a complete participant role: members have the same outside options, production attributes, and terms on every issue. A coalition is a mass vector \(q\) with \(0\le q_t\le\mu_t\). For each issue \(j\), its value \(v_j(q)\) is given as a continuous, rational, piecewise-affine function over an explicit polyhedral partition of the feasible coalition-mass vectors. Values and transfers are normalized per unit of population.

The question is whether there is an aggregate payoff density \(x_u\) for each type \(u\), and a justifying decomposition \(y^{(t)}_{u,j}\) for each type \(t\), such that
\[ \sum_j y^{(t)}_{u,j}=x_u,\qquad \sum_u\mu_u y^{(t)}_{u,j}=v_j(\mu), \]
and, for every issue \(j\) and coalition mass vector \(q\) with \(q_t>0\),
\[ \sum_u q_u y^{(t)}_{u,j}\ge v_j(q). \]
The first condition preserves the proposed aggregate allocation for every type’s justification; the second preserves issue efficiency; the last says that no coalition containing a member of type \(t\) can do better on that issue by operating alone. The requested solution is a feasible \(x\) and its type-level justifications, or a proof that none exist. This keeps the paper’s question—whether everyone can justify joining the grand coalition—while replacing individual coalition membership with the mass of each role in the coalition.

A plausible regime is a large consortium of repeated small suppliers negotiating across several joint projects. Suppliers fall into a few technology, cost, and contract classes; within each class, participants are interchangeable, while an issue’s coalition value depends on the amounts of each class participating. There are many participants but relatively few types. That is a natural high-multiplicity setting for this problem. The paper’s own firms-and-joint-ventures motivation would need this more specific population story, but the authors should recognize the mirror: it retains multiple issues, coalition values, aggregate transfers, and the agents’ issue-by-issue justifications. Treating coalition sizes as fractional masses is the necessary co-modification when the population becomes continuous.

I expect this mirror to be tractable for the stated input representation. For any proposed justifications, a violated coalition constraint can be found by maximizing \(v_j(q)-\sum_u q_u y^{(t)}_{u,j}\) over coalition masses. On each input polyhedral cell, that is a linear program. These separation problems feed the ellipsoid method for the finite-dimensional feasibility problem. With \(K\) value-function cells in total and binary encoding length \(L\), the expected running time is polynomial in \(\tau\), \(m\), \(K\), and \(L\). This is my algorithmic inference from the mirror’s representation, not a complexity result claimed by the paper.

The scope is Theorem 2’s nonemptiness question. I am not claiming a mirror of the paper’s other set-inclusion or effectiveness results. Further questions include how the continuous balancing-multiweights dual should be represented, when a finite population’s coalition-mass grid gives an exact dictionary to the continuum, and what approximation error results when it does not.

The weakest point is that the original model gives each named agent a potentially different justification, whereas this mirror asks for one justification per type. In an atomless population, an individual has zero mass, so coalition membership must be understood through the limit of coalitions containing positive mass of that type. That is a real modeling choice. It is defensible when values depend only on type composition: participants within a type are interchangeable, and type-level justifications preserve the paper’s coalition-rationality test. The paper’s strongest support is Theorem 2 itself, which is already organized around coalition values and balancing weights rather than a particular story about firms.

The case AGAINST (opponent, writing after the proponent)

The strongest objection is that Theorem 2 is a characterization of nonemptiness, not a result about the complexity of a computational problem. Its proof’s LP is a tool for establishing that characterization. With coalition values listed explicitly, the LP is polynomial in the size of that table; if the values are supplied succinctly, the computational question depends on an encoding the paper does not study. So the proponent has formulated a new algorithmic problem around Theorem 2, rather than mirrored a computational result of the paper.

The proposed tractability also follows largely from its chosen input format: explicit piecewise-affine value functions make coalition separation an LP on each cell, after which the ellipsoid method applies. That is a valid computational question, but its connection to the paper’s finite game still needs a precise scaling dictionary. One could define a natural family \(V_{j,n}(S)=n v_j(q)\) for coalitions with type proportions \(q\), but the paper neither specifies nor analyzes such a family. The claimed algorithm would then be a generic consequence of the new representation, not a complexity finding established by the paper.

This objection does not defeat the best mirror. A large consortium of interchangeable supplier types is a plausible high-multiplicity regime, and type-level justifications preserve the paper’s central nonemptiness question. The piecewise-affine model is also well-posed, and its tractability could be a useful baseline. My negative case is therefore weak: it challenges the anchor’s computational novelty and its link to the paper, but I cannot honestly rule out a worthwhile continuous mirror in that scenario.
