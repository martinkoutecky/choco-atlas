The continuous mirror question

Given finite \(T\), rational masses \(\mu_t\) with \(\sum_t\mu_t=1\), a finite item-slot catalogue \(G\) with rational per-capita capacities \(q_g\), additive values \(v_{tg}\), and welfare densities \(\lambda_t\ge0\) satisfying \(\sum_t\mu_t\lambda_t=1\), choose finite-support \(y_{t,S}\ge0\) with \(\sum_S y_{t,S}=1\) and \(\sum_t\mu_t\sum_{S\ni g}y_{t,S}\le q_g\), and output \(y\) whose log welfare \(\sum_{t,S}\mu_t\lambda_t y_{t,S}\ln(\sum_{g\in S}v_{tg})\) is within \(\ln(1+ε)\) of the optimum.

The model it lives in

A high-multiplicity weighted Nash-welfare allocation model with type masses \(\mu\), integral bundles \(S\), mass variables \(y_{t,S}\), per-capita item capacities \(q_g\), and objective \(\exp(\sum_{t,S}\mu_t\lambda_t y_{t,S}\ln v_t(S))\).

What the mirror covers

The mirror covers weighted additive valuations, the approximation algorithm, the configuration-LP solution, and its pricing oracle; it leaves the submodular discussion and the finite-agent rounding analysis outside the population mirror.

Open questions for a prover

  • Can the configuration-LP and pricing proof be stated directly for rational type masses and per-capita capacities with polynomial bit complexity?
  • When can a finite replicated allocation be rounded from a continuous mass solution with controlled welfare loss?
  • Which discrete \(NP\)- or \(APX\)-hardness results disappear under this high-multiplicity regime?

The case FOR (proponent)

There is a credible positive mirror here, and it is strongest in a high-multiplicity fair-division regime. The paper has no numbered hardness theorem of its own: its NP-hardness and APX-hardness statements are cited from [29] and [24]. I therefore anchor the case in its two proved algorithmic results rather than manufacture a hardness anchor.

My lead anchor is Theorem 1.1, proved in this paper. It states that, for every \(\varepsilon>0\), weighted Nash Social Welfare with additive valuations has a deterministic \((e^{1/e}+\varepsilon)\)-approximation algorithm, with running time polynomial in the input size and \(1/\varepsilon\). Equivalently, the returned allocation has welfare at least \(\mathrm{OPT}/(e^{1/e}+\varepsilon)\).

A natural continuous problem is \(\mathrm{WNSW}^{\mathrm{add}}_\infty\). An instance contains:

  • finitely many agent types \(T\), with rational masses \(\mu_t\ge 0\) satisfying \(\sum_t\mu_t=1\);
  • a finite catalogue \(G\) of indivisible item slots, with rational per-capita supplies \(q_g\);
  • for each type \(t\), additive values \(v_{tg}\ge0\);
  • a welfare-weight density \(\lambda_t\ge0\), normalized by \(\sum_t\mu_t\lambda_t=1\).

A type-\(t\) agent receiving an integral bundle \(S\subseteq G\) has utility \(v_t(S)=\sum_{g\in S}v_{tg}\). A solution is a mass allocation \(y_{t,S}\ge0\), where \(y_{t,S}\) is the fraction of type \(t\) receiving bundle \(S\), satisfying

\[ \sum_{S\subseteq G}y_{t,S}=1 \]

for every \(t\), and

\[ \sum_{t}\sum_{S\ni g}\mu_t y_{t,S}\le q_g \]

for every item slot \(g\). Its welfare is

\[ \mathrm{WNSW}_\infty(y) = \exp\!\left( \sum_{t,S}\mu_t\lambda_t y_{t,S}\ln v_t(S) \right), \]

with the usual convention that a positive-weight type receiving only zero-utility bundles gives value \(0\).

The question is: given \(\varepsilon>0\), output such a mass allocation with

\[ \mathrm{WNSW}_\infty(y) \ge \frac{\mathrm{OPT}_\infty}{e^{1/e}+\varepsilon}. \]

This is a genuine population continuization. Each infinitesimal agent still receives an integral bundle; only the mass of agents receiving each bundle is fractional. The per-capita item supply is the permitted co-modification: without replicating the item supply, only a measure-zero set of agents could receive the finitely many goods.

The high-multiplicity dictionary is exact. For an integer \(N\), take \(N\mu_t\) agents of type \(t\), give each such agent paper-weight \(\lambda_t/N\), and provide \(Nq_g\) copies of each item slot. A rational \(y\) can then be realized by assigning \(N\mu_t y_{t,S}\) agents bundle \(S\). The logarithm of the finite weighted Nash welfare is exactly the displayed continuous objective. Thus this is not a fractional-item relaxation or an unrelated market model; it is the limit of repeated weighted-NSW instances with finitely many valuation and priority profiles.

I expect \(\mathrm{WNSW}^{\mathrm{add}}_\infty\) to be Class A. In fact, the continuum should be easier than the finite problem: the assignment of mass to configurations is already fractional, so the Shmoys–Tardos rounding step responsible for the finite-agent approximation loss is no longer needed. The paper’s configuration-LP machinery becomes an optimization method for the actual continuous allocation problem.

The second anchor is Theorem 2.1, also proved in this paper. It states that, for every \(\varepsilon>0\), the configuration LP has a polynomial-time algorithm that outputs a valid rational solution, represented by its nonzero entries, whose objective is within an additive \(\ln(1+\varepsilon)\) of the LP optimum; the running time is polynomial in the input size and \(1/\varepsilon\).

The corresponding continuous problem, \(\mathrm{Conf\text{-}WNSW}_\infty\), is:

Given the same type, valuation, weight-density, and per-capita-supply data, output a finite-support mass allocation \(y\) satisfying the constraints above and

\[ \sum_{t,S}\mu_t\lambda_t y_{t,S}\ln v_t(S) \ge L_\infty^\star-\ln(1+\varepsilon), \]

where \(L_\infty^\star\) is the maximum continuous log-welfare. The output list itself is the solution: it says what fraction of each population type receives each integral bundle.

This is not merely reusing the paper’s LP as an encoding. In the finite problem, \(y_{i,S}\) is a relaxation variable. In the continuum, \(y_{t,S}\) is literally the distribution of mass across integral bundles. The same mathematical object changes status because the population is nonatomic. Theorem 2.1 therefore gives the continuous problem an especially strong Class A prediction:

\[ \mathrm{WNSW}_\infty(y) \ge \frac{\mathrm{OPT}_\infty}{1+\varepsilon}. \]

The pricing step remains the paper’s underlying knapsack-cover problem: for a type \(t\), item prices \(\alpha_g\), and a target utility, find an integral bundle with sufficient additive value and minimum price. Lemma 3.1 proves that this separation task has an efficient approximate oracle using dynamic programming. That is precisely the computational bridge needed for the exponentially many bundle configurations.

The most plausible regime is large-scale allocation of recurring indivisible benefit slots—housing upgrades, school places, medical packages, energy entitlements, or public-service bundles—to millions of households belonging to a small number of exact valuation and priority types. The number of households is \(N\); the number of types \(\tau\) and item-slot classes is much smaller. The type records everything relevant: additive values and welfare priority. This is a sensible high-multiplicity version of weighted NSW, not a story invented merely to make the LP easy.

The mirror covers the paper’s weighted additive-valuation results, not its submodular discussion. Its weakest point is the item-side scaling: a referee who insists that the finite item set must remain fixed while only the agent population becomes continuous will obtain a degenerate welfare problem. The positive case therefore depends on accepting the programme’s explicit rule that per-capita supplies may scale when that is necessary for a nontrivial population limit. A second limitation is that it does not cover instances with essentially unique agent-specific valuations or weights; those are not high-multiplicity instances in the first place.

The resulting research questions are worthwhile: quantify convergence from finite replicated instances to \(\mathrm{WNSW}_\infty\); characterize when the \(1+\varepsilon\) continuous solution can be rounded with controlled loss; obtain sharper pricing algorithms under compressed item types; and determine which discrete NP/APX-hardness results disappear purely because population multiplicity has been continuized.

The case AGAINST (opponent, writing after the proponent)

I cannot honestly make the requested universal negative case. The strongest objection is that the paper’s finite item set cannot remain fixed while the population becomes nonatomic. With finitely many indivisible items, only a finite amount of mass can receive a positive bundle, so almost everyone receives utility zero and the Nash product collapses. A nondegenerate limit therefore has to scale item supplies as well as agents.

That objection fails under the programme’s explicit rules. Taking \(N\mu_t\) agents of each type and \(Nq_g\) copies of each item gives a legitimate high-multiplicity regime. Every item copy remains indivisible, while the population mass assigned to each integral bundle becomes fractional. For rational \(y_{t,S}\), the continuous allocation is exactly realizable by \(N\mu_t y_{t,S}\) replicated agents. With individual weight \(\lambda_t/N\), the finite weighted Nash welfare has logarithm

\[ \sum_{t,S}\mu_t\lambda_t y_{t,S}\ln v_t(S), \]

so the proposed continuous objective is not an analogy or a divisible-goods relaxation. It is the exact replicated-population limit.

This defeats the main anchor, Theorem 1.1. In a plausible regime of recurring housing, school, medical, or service slots and finitely many household valuation-and-priority types, the theorem induces a genuine continuous-population problem. The Shmoys–Tardos rounding is no longer needed: a mass split across integral bundles is itself an allocation of a nonatomic population. The type can include the welfare density \(\lambda_t\), so weightedness does not require preserving individual identities.

Theorem 2.1 is an even stronger surviving anchor. Its configuration variables become literal mass variables rather than relaxation variables. The paper’s pricing oracle still works type by type, and the configuration LP yields a continuous allocation within additive \(\ln(1+\varepsilon)\), equivalently a \(1+\varepsilon\) multiplicative welfare guarantee. The fact that this continuous problem is already solved by the paper is not a valid objection under the programme’s rules; it is a known positive Class A result and a useful high-multiplicity baseline.

The only defensible negative position would impose an additional restriction: only the population may be continuized, while item supplies must remain finite and named. Under that restriction the mirror degenerates. But that restriction directly conflicts with the programme’s allowance for forced per-capita supply scaling. Nor can one object that the model is “really” fractional allocation: each unit of mass receives an integral bundle, and the finite approximants contain only indivisible items.

If Lemma 3.1 is counted as a third anchor, it also survives: its dynamic-programming pricing procedure depends on a valuation type and item prices, not on agent identity, and therefore aggregates cleanly over finitely many types.

So the negative case is weak. It can reject an overly literal fixed-item limit, but it cannot defeat the better high-multiplicity mirror. The paper supplies at least one worthwhile continuous mirror—indeed, two closely related Class A formulations.
