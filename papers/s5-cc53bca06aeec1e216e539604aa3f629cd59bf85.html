The continuous mirror question

Given worker-type masses \(\mu_a>0\), uniform task arrivals \(s_j=1/m\), shared unknown values \(v_{a,j}\), bounded sub-Gaussian feedback, and horizon \(T\), assign each arriving indivisible task to a worker using past observations and pool feedback by type. For type-level allocation fractions \(x_{a,j}\) with \(\sum_a x_{a,j}=1\), define \(u_a(x)=\mu_a^{-1}\sum_j s_jv_{a,j}x_{a,j}\) and \(\mathrm{OPT}_\mu=\max_x\exp(\sum_a\mu_a\log u_a(x))\). Establish a regret bound for a type-pooled DA-EtC policy against this weighted population benchmark; in particular, determine when balanced masses permit \(\widetilde O(T^{2/3}(\tau m)^{1/3})\) regret.

The model it lives in

A society with \(\tau\) worker types of masses \(\mu_a\), each type sharing its task-value and feedback distributions; decisions allocate incoming tasks to workers and aggregate allocations and utilities by type; the objective is weighted Nash welfare \(\exp(\sum_a\mu_a\log u_a)\) with per-capita type utility.

The objection that survived

The paper measures ex-post NSW across individual workers, and noisy rewards can leave workers of the same type with unequal utilities; therefore the type-average objective does not generally equal the paper’s objective, despite rotating assignments.

fatal: False

What the mirror covers

The mirror covers the online learning guarantees in Theorems 1–3; it does not cover the static equilibrium formulation as a separate computational result or the empirical comparisons.

Open questions for a prover

  • For balanced masses, can pooled type-task estimates yield \(\widetilde O(T^{2/3}(\tau m)^{1/3})\) regret against the weighted population benchmark?
  • How does the regret bound depend on small type masses, especially \(\min_a\mu_a\), while maintaining a meaningful fairness guarantee?

The case FOR (proponent)

The honest positive case is for a continuous population version of the paper’s online learning problem. There is a caveat: the paper has no named NP-hardness, polynomial-time, or parameterized-complexity result. Its numbered results are regret bounds. They can anchor an online-algorithm mirror, but they do not establish a ChoCo-style worst-case complexity classification.

Take a population of \(K\) workers split among \(\tau\) types, with \(K\mu_a\) workers of type \(a\), where \(\mu_a>0\) and \(\sum_a\mu_a=1\). A type is a complete record of the worker’s expected values for the \(m\) task types and, if relevant, their budget or priority and feedback distribution. Workers in a type are identical for everything the allocation problem uses. Let task type \(j\) arrive independently with probability \(s_j\), and let a type-\(a\) worker’s unknown expected value for it be \(v_{a,j}\). After assigning a task to a worker, the planner observes one noisy reward with mean \(v_{a,j}\), as in the paper. The planner assigns each arriving task to an individual, rotating through a type’s members to balance their realized allocations.

For the benchmark, let \(x_{a,j}\) be the fraction of type-\(j\) tasks allocated to type \(a\), with \(\sum_a x_{a,j}=1\). In the \(K\)-normalized per-worker units, type \(a\)’s expected utility is \(u_a(x)=\frac{1}{\mu_a}\sum_j s_jv_{a,j}x_{a,j}\). With equal priority for each individual, the type’s population weight is \(\mu_a\), so the benchmark is \(\widehat{\mathrm{ONSW}}_\mu=\max_x\exp(\sum_a\mu_a\log u_a(x))\).

This normalization gives a direct finite-population bridge: if \(\bar U_a(T)\) is the average cumulative utility of workers in type \(a\), set \(\widehat U_a(T)=K\bar U_a(T)\). Then \(\widehat{\mathrm{NSW}}_\mu(T)=\exp(\sum_a\mu_a\log\widehat U_a(T))\), and the normalized regret is \(\widehat{\mathrm{Regret}}_\mu(T)=T\widehat{\mathrm{ONSW}}_\mu-\widehat{\mathrm{NSW}}_\mu(T)\). It is \(K\) times the paper’s regret in this equal-priority population. Thus the limit is over the *recipient population*, with support \(\tau\) rather than named-worker count \(K\); fractional \(x\) is the aggregate accounting forced by that population limit, not the aim of the continuization.

A convincing regime is a large crowdsourcing workforce with recurring task categories. Many workers share the same task-value profile and priority, while the platform learns those values only from completed tasks. Here \(K\) can be much larger than \(\tau\), and tasks still arrive online and are assigned irrevocably. The paper’s crowdsourcing example gives this mirror a natural home. Its fractional Eisenberg–Gale benchmark alone is not a population-continuous model; the mirror’s substantive step is grouping workers by their complete type and asking how online learning and fair allocation behave as those groups represent a large society.

My lead question is Continuous-Type Explore-then-Commit Fair Allocation. Its instance is \((\mu,s,\{v_{a,j}\},\sigma,T)\), with equal type masses \(\mu_a=1/\tau\), uniform task arrivals \(s_j=1/m\), bounded values \(2l\le v_{a,j}\le h/2\), and sub-Gaussian feedback. A policy must assign each arriving task using past observations, explore type–task pairs, and then commit to a type-level dual-averaging allocation; the solution is a policy and a regret proof against \(\widehat{\mathrm{ONSW}}_\mu\).

Its anchor is Theorem 2, proved in this paper. Under equal individual weights \(B_i=1/n\), uniform item probabilities \(s_j=1/m\), and \(2l\le v_{i,j}\le h/2\), it bounds DA-EtC’s expected regret by \(\widetilde O(T_0+\sqrt{nm/T_0}\,T+n\CDA\sqrt T)\), provided \(T_0\) is large enough to satisfy the theorem’s estimation condition \(\sqrt{8\max(1,\sigma^2)nm\log(nmT)/T_0}\le \min(1,2l)/2\). With \(T_0=T^{2/3}(nm)^{1/3}\), the stated rate is \(\widetilde O(T^{2/3}(nm)^{1/3})\), with the convergence term non-leading in \(T\). The paper proves this result here.

The continuous question is whether pooling observations across identical workers lets a type-level version replace \(n\) by support size \(\tau\): can it prove \(\widetilde O(T_0+\sqrt{\tau m/T_0}\,T+P(\tau,m)\sqrt T)\), and hence \(\widetilde O(T^{2/3}(\tau m)^{1/3})\) for fixed \(\tau,m\), for a polynomial \(P\) independent of \(T\)? The exploration term has a clear interpretation: there are \(\tau m\) shared value parameters rather than \(nm\) named-worker parameters. I expect this to be tractable, though it requires redoing the analysis for pooled estimates and type-level utilities.

Two further questions are worth anchoring. Continuous-Type Minimax Regret asks for the minimax expected normalized regret \(\inf_\pi\sup_v \mathbb E[\widehat{\mathrm{Regret}}_\mu(T)]\) for balanced positive type masses, uniform item arrivals, and binary feedback, as a function of \(\tau,m,T\) and the masses. Its anchor is Theorem 1, proved here using a cited information-theoretic lemma: the paper states that there is a model on which every algorithm has expected regret \(\Omega(\sqrt{mT})\); its construction uses uniform item arrivals, equal agent weights, and binary feedback. The continuous problem is to establish which lower bound survives after values are shared and observations pooled, and to determine the dependence on \(\tau\) and \(\mu\). I expect a genuine bandit lower bound, but would not claim the paper’s rate transfers unchanged.

Continuous-Type Reset-UCB Fair Allocation asks for a type-level RDA-UCB policy: estimate each shared type–task value, hold clipped UCB estimates fixed between count-doubling epochs, and use dual averaging to allocate tasks. The requested solution is a policy and proof of \(\widetilde O(\mathrm{poly}(\tau,m)\sqrt T)\) normalized expected regret for equal type masses and \(l\le v_{a,j}\le h\). Its anchor is Theorem 3, proved here: under \(l\le v_{i,j}\le h\), the paper’s RDA-UCB has expected regret at most \(\widetilde O(\mathrm{poly}(n,m)\sqrt T)\), with the polynomial independent of \(T\). This is also a plausible support-sensitive extension, not a result the paper already proves.

Theorem 2 is my strongest anchor because it gives a concrete exploration–estimation–allocation pipeline, and the type grouping identifies exactly which parameters should be pooled. Theorem 1 supplies a lower-bound question; Theorem 3 supplies a second algorithmic target. Together they cover the paper’s online fair-allocation learning results, not its simulations or all of static fair division.

The weak point is substantive: the paper’s bounds depend on the number of named agents, and its proofs do not show that replacing \(n\) by \(\tau\) is valid. A type-level algorithm must preserve fairness for individual workers while pooling feedback across them; its dual variables and regret scale also need a fresh analysis. That is why I state the continuous bounds as questions rather than transferred theorems. The authors should recognize them as mirrors of their problem because the task stream, unknown values, bandit feedback, irrevocable assignments, and Nash-social-welfare objective all remain in place.

The case AGAINST (opponent, writing after the proponent)

The strongest objection is about ChoCo’s scope. Theorem 1 is an information-theoretic regret lower bound; Theorems 2 and 3 are stochastic regret upper bounds. They measure learning performance as \(T\) grows, not the worst-case computational complexity of a problem or the complexity of exact, approximate, or parameterized algorithms. The proposed mirrors are therefore regret-theory questions, potentially interesting, but they do not supply the kind of computational result this programme is charting.

The mirrors also face a choice. If the objective is the proponent’s normalized NSW of type-average utilities, then the model reduces to a finite weighted fair-division instance: use one representative per type, weight it by \(\mu_a\), and pool that type’s feedback. For equal type masses, the proposed versions of Theorems 1–3 largely amount to applying the paper’s results with \(n=\tau\). That makes them weak ChoCo anchors: the population limit has not exposed a new complexity question. If instead the objective preserves the paper’s ex-post NSW across individual workers, type averages do not generally preserve it. Concavity gives \(\frac{1}{|a|}\sum_{i\in a}\log U_i\leq \log\bar U_a\), with equality only when workers’ cumulative utilities match. Rotating assignments may balance counts, but noisy rewards still leave individual utilities unequal. A model that tracks those differences needs more than the proponent’s type-average state.

This reaches each anchor. For Theorem 2, pooling can replace \(n\) with \(\tau\) in the type-level problem, but that is a regret bound for the quotient model, not a computational-complexity result; preserving individual NSW requires additional state. For Theorem 1, the proof’s worker-specific least-sampled task perturbations cease to be independent alternatives once identical workers share values. Its lower bound can be applied to \(\tau\) representative types, but it remains a statistical lower bound, not computational hardness. For Theorem 3, the reset-UCB policy likewise transfers to the representative-type model under the stated equal-mass setting; the open issue is its regret analysis, not a complexity classification.

That is a case against these anchors *for ChoCo*, not an honest proof that no worthwhile mirror exists in any scenario. Recurring crowdsourcing cohorts with shared value profiles are plausible, and a normalized population-level regret question could be sensible research. The negative case is weakest there: I can argue that this paper does not advance ChoCo’s stated complexity agenda, but I cannot rule out a worthwhile continuous learning problem.
