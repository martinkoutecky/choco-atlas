The continuous mirror question

Given agent types \(a\) with rational masses \(\mu_a\) summing to \(1\), additive utilities \(u_a(j)\), task types \(j\) with rational per-capita supplies \(q_j\), a threshold \(\eta\), and a conflict graph that is the union of three cliques, decide whether there are nonnegative rational variables \(x_{a,B}\) for bundles \(B\) that contain at most one task from each clique and satisfy \(\sum_{B\in\mathcal B_a}x_{a,B}=\mu_a\) for every \(a\), \(\sum_a\sum_{B\in\mathcal B_a}x_{a,B}\mathbf 1[j\in B]\le q_j\) for every \(j\), and \(\sum_{j\in B}u_a(j)\ge\eta\) for every allowed bundle \(B\in\mathcal B_a\). Each unit of population receives an integral bundle.

The model it lives in

A continuous population described by masses \(\mu_a\) of complete utility-profile types, with task supplies \(q_j\) per capita. The decision variables \(x_{a,B}\) split each type's mass among feasible integral bundles; the objective is feasibility subject to utility thresholds and task-capacity constraints.

What the mirror covers

The mirror covers Theorems 4 and 10 through their three-clique and size-three restrictions. It leaves the paper's other parameterized results, including general conflict graphs and unbounded bundle sizes, outside this mirror.

Open questions for a prover

  • How does the feasibility problem's complexity change as the number of conflict cliques grows?
  • How large can the gap be between feasibility in the continuous mirror and feasibility for the original finite roster and inventory?

The case FOR (proponent)

My lead is Theorem 4, proved in this paper. It states that CFFA is NP-complete even when the conflict graph is a cluster graph consisting of three cliques. CFFA asks whether jobs can be assigned in disjoint bundles to agents so that each bundle is conflict-free and gives its agent utility at least \(\eta\). The theorem’s reduction is from Numerical 3-Dimensional Matching: there are three sets of jobs, one clique for each set, and agents with a common utility function. A feasible allocation exists exactly when the jobs can be partitioned into triples, one from each clique, whose values sum to the target.

The continuous mirror, Three-Class CFFA\(_\infty\), keeps the agents’ utility profiles, additive utilities, conflict constraints, and whole bundles. It changes the population and the job inventory to per-capita quantities. A plausible regime is a large volunteer organization running recurring campaigns: many volunteers share a small number of complete utility profiles over standardized tasks, and the supply of task slots grows with the volunteer roster. For the theorem’s hard instances, there is just one volunteer type and \(r\) volunteers; the reduction has \(3r\) task types. In a recurring setting, the task catalog could instead be fixed or moderate in size.

Here is the decision problem. The input gives agent types \(a\) with masses \(\mu_a\in\mathbb{Q}_{\ge 0}\), where \(\sum_a\mu_a=1\); task types \(j\) with per-capita supplies \(q_j\in\mathbb{Q}_{\ge 0}\); utilities \(u_a(j)\); a conflict graph on task types that is the union of three cliques; and a threshold \(\eta\). A bundle is an integral set of task types containing at most one task from each clique. Ask whether the volunteer population can be assigned bundles so that every volunteer receives utility at least \(\eta\), without using more than \(q_j\) of any task type.

More precisely, let \(\mathcal B_a\) contain the bundles that meet the threshold for type \(a\), and let \(x_{a,B}\) be the mass of type-\(a\) volunteers assigned bundle \(B\). A solution is a nonnegative rational assignment satisfying
\[ \sum_{B\in\mathcal B_a}x_{a,B}=\mu_a \quad\text{for each }a,\qquad \sum_a\sum_{B\in\mathcal B_a}x_{a,B}\mathbf 1[j\in B]\le q_j \quad\text{for each }j. \]
Each volunteer still receives a whole bundle. The real-valued variables distribute population mass among bundles; they do not give an individual a fractional task. With three cliques, there are at most \((\tau+1)^3\) bundles, where \(\tau\) is the number of task types. This is an explicit polynomial-size LP, so I expect this mirror to be Class A, tractable. The corresponding maximin-utility problem can be solved by checking the finitely many utility thresholds induced by these bundles.

A second anchor supports the case. Theorem 10, also proved here, says that CFFA is NP-complete even with an edgeless conflict graph and bundle size bounded by \(3\). The reduction is from 3-Partition: for \(3r\) item sizes \(s(x)\) with \(B/4<s(x)<B/2\) and total \(rB\), it creates \(r\) agents, gives item \(x\) utility \(B-s(x)\), and sets the target to \(2B\). A feasible allocation exists exactly when the items partition into triples summing to \(B\).

The continuous mirror, Three-Bundle CFFA\(_\infty\), uses the same mass-assignment model but requires an edgeless conflict graph and integral bundles of size at most \(3\). For each agent type, the number of bundle vectors is \(O(\tau^3)\), including when a task type has multiple compatible copies. Its feasibility question is again an LP, polynomial in the explicit type counts and input bit length. I expect this anchor to be Class A too. Theorem 4 is my stronger anchor because it retains the paper’s conflict structure; Theorem 10 shows that even the no-conflict 3-Partition hardness can dissolve under this population relaxation.

The link to the discrete instances is concrete. An instance with \(N\) volunteers maps to masses \(\mu_a=n_a/N\); a task type with \(k_j\) copies maps to supply \(q_j=k_j/N\). Any discrete allocation gives a continuous solution. Conversely, a rational continuous solution can be realized as a discrete allocation after scaling to a common denominator, generally in a replicated instance. That gap is the point: the continuous LP may accept a fractional mixture of whole bundles even when no integral partition exists for the original roster. The source reductions’ combinatorics are in partitioning jobs among agents, not in a growing number of distinct volunteer preferences.

This case covers Theorems 4 and 10, not the paper’s full parameterized-complexity landscape. It does not assert that general CFFA, with unbounded bundle size and arbitrary conflict graphs, has an explicit polynomial configuration LP; there, generating or pricing bundles could itself be hard. Useful follow-up questions are whether the mirror remains tractable for a fixed number of conflict cliques, where the boundary lies when the number of cliques grows, and how much the continuous optimum can differ from the original finite instance.

The weakest point is the regime assumption: the inventory and task slots must scale with the volunteer population. A one-off set of named tasks cannot support an arbitrarily large population at fixed per-capita supply. The mirror is most convincing for recurring allocation cycles with standardized task profiles and repeatable capacity. That co-scaling is a meaningful modification of the allocation model, but it is also exactly what makes the high-multiplicity population regime coherent.

The case AGAINST (opponent, writing after the proponent)

The strongest objection to both anchors is that, with the paper’s finite job inventory held fixed, neither has a nondegenerate population-continuum version. In Theorem 4 the target is positive, so every volunteer must receive a nonempty bundle; the same is true for Theorem 10. A finite set of indivisible jobs can serve only finitely many people, hence only zero mass in an atomless society. On that literal version, the question collapses.

That objection does not defeat the proposed mirrors, though. They scale job supplies with the volunteer population, which the programme explicitly permits when per-capita supplies must co-scale. The resulting model has a coherent interpretation as recurring allocation cycles. Nor can I dismiss it on type grounds: both hardness reductions use a common utility function, so the continuous population can consist of one valid volunteer type. Mass can be divided among bundles while each volunteer still receives a whole bundle.

For Theorem 4, the three-clique restriction gives at most \(O((\tau+1)^3)\) bundles per volunteer type. For Theorem 10, the size-three restriction likewise gives \(O(\tau^3)\) bundles. With rational masses and capacities, both proposed feasibility questions therefore have explicit polynomial-size LP formulations. The case against cannot rest on their likely tractability: a tractable answer is still a worthwhile mirror under this programme.

The more substantial reservation is that these are joint roster-and-inventory relaxations. A rational LP solution need not realize the original finite instance at its existing roster and job counts; scaling denominators realizes a replicated instance instead. That makes the connection to the paper’s one-shot allocation problem less direct than the proponent suggests. But it is a limitation of the bridge, not a fatal flaw: the programme expressly includes high-multiplicity relaxations and co-scaled per-capita supplies.

So the honest negative case is weak. The fixed-inventory continuum degenerates, and the proposed versions change the supply regime, but that regime has a plausible recurring-campaign interpretation and an exact computational question. I cannot convincingly defeat either anchor, much less rule out every worthwhile mirror.
