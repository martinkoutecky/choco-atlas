The continuous mirror question

Input a finite set of complete ordered additive valuation types \(\Theta\), rational masses \(\mu_\theta\) with \(\sum_{\theta\in\Theta}\mu_\theta=1\), rational per-capita supplies \(q\in\mathbb{Q}_{\ge0}^m\), and \(\varepsilon\in(0,1/2]\). For an integral bundle \(b\in\mathbb{Z}_{\ge0}^m\), define \(\mathrm{MMS}^{\infty}_\theta(q)=\sup\{z:\exists\pi_b\ge0,\ \sum_b\pi_b=1,\ \sum_b\pi_b b=q,\ \pi_b>0\Rightarrow v_\theta(b)\ge z\}\). Compute a finite-support family \(\lambda_{\theta,b}\ge0\) satisfying \(\sum_b\lambda_{\theta,b}=\mu_\theta\) and \(\sum_{\theta,b}\lambda_{\theta,b}b_g=q_g\) for every good \(g\), such that every \(\theta\) with \(\mu_\theta>0\) receives only bundles with \(v_\theta(b)\ge(\frac79-\varepsilon)\mathrm{MMS}^{\infty}_\theta(q)\), in time polynomial in \(|\Theta|\), \(m\), the input encoding length, and \(1/\varepsilon\).

The model it lives in

A high-multiplicity configuration-allocation LP over complete valuation types: \(\lambda_{\theta,b}\) is the mass of type \(\theta\) receiving integral bundle \(b\), the constraints conserve type mass and per-capita item supply, and the objective is to maximize the guaranteed typewise value relative to \(\mathrm{MMS}^{\infty}_\theta(q)\).

The objection that survived

The paper does not prove the discrete-to-continuous dictionary: it leaves open whether \(\mathrm{MMS}^{\infty}_\theta(q)\) admits polynomial-size rounding from finite replicas and whether sequential witness certificates aggregate over split type mass.

fatal: False

What the mirror covers

The mirror covers the ordered additive-goods threshold theorem and FPTAS, namely Theorems 3.1 and 10.4. It leaves the paper's tightness discussion, technical witness lemmas as standalone results, and online, chore, ordinal, and weighted variants outside.

Open questions for a prover

  • Does \(\mathrm{MMS}^{\infty}_\theta(q)\) equal the limit of finite replicated MMS values, with polynomial-size rounding guarantees?
  • Can the paper's threshold search and dynamic witness certificates be aggregated over type masses and per-capita supply?
  • What is the complexity of pricing and optimizing over the integral bundle configurations?

The case FOR (proponent)

The strongest positive case is a high-multiplicity MMS allocation mirror. It continuizes the population, while keeping every individual bundle indivisible.

Let \(G=\{g_1,\ldots,g_m\}\) be good categories. A continuous society has finitely many valuation types \(\Theta\), type mass \(\mu_\theta\) with \(\sum_\theta\mu_\theta=1\), and additive values \(v_\theta(g)\). Assume the ordered regime used by the paper: every type ranks the categories in the same order. Let \(q_g\) be the number of copies of category \(g\) per unit population. Thus a finite society of size \(N\) has \(N\mu_\theta\) agents of type \(\theta\) and \(Nq_g\) indivisible copies of \(g\).

A bundle is still an integral vector \(b\in\mathbb Z_{\ge0}^m\). The continuous allocation variable is only population mass: \(\lambda_{\theta,b}\) is the mass of type-\(\theta\) agents receiving the whole indivisible bundle \(b\). Feasibility is

\[ \sum_b\lambda_{\theta,b}=\mu_\theta \]

for every type \(\theta\), and

\[ \sum_{\theta}\sum_b\lambda_{\theta,b}b_g=q_g \]

for every good category \(g\). No agent receives a fractional item; only a fraction of the population receives each bundle.

The appropriate continuum MMS benchmark for type \(\theta\) is

\[ \MMS^\infty_\theta(q)= \sup\left\{z: \begin{array}{l} \exists\ \pi_b\ge0,\ \sum_b\pi_b=1,\[2pt] \sum_b\pi_b b_g=q_g\ \text{for every }g,\[2pt] \pi_b>0\Rightarrow v_\theta(b)\ge z \end{array} \right\}. \]

This is the value guaranteed by partitioning the per-capita supply into unit-mass bundles. For rational \(\mu\) and \(q\), it is exactly the high-multiplicity limit of the paper’s finite MMS problem: replicate the type and item counts by \(N\), partition the \(Nq_g\) indivisible copies into \(N\) bundles, and let \(N\) grow. Thus this is not outcome-space fractionalization or probabilistic social choice. It is a population measure over integral allocations.

The regime is quite plausible: millions of households, students, or beneficiaries, but perhaps only \(8\)–\(20\) recurring valuation profiles, receiving large repeated supplies of a finite catalogue of indivisible goods. The type includes the complete additive valuation vector, not merely a rank order, so agents grouped together really are interchangeable for the problem. This is exactly the high-multiplicity interpretation the paper’s algorithms already invite.

My lead anchor is Theorem 10.4, proved in this paper. It states that for every ordered additive instance and every \(\varepsilon\in(0,1/2]\), the threshold-search algorithm computes a \((7/9-\varepsilon)\)-MMS allocation in time

\[ \frac{1}{\varepsilon}\cdot\operatorname{poly}(n,m). \]

The corresponding continuous problem is:

“Given \((\Theta,\mu,q,v)\) in the ordered additive regime and \(\varepsilon>0\), output a finite-support family \(\lambda_{\theta,b}\) satisfying the population and supply constraints above and

\[ \lambda_{\theta,b}>0 \quad\Longrightarrow\quad v_\theta(b)\ge \left(\frac79-\varepsilon\right)\MMS^\infty_\theta(q) \]

for every type with positive mass. The desired running time is polynomial in the number of valuation types, good categories, numerical encoding length, and \(1/\varepsilon\), independent of the replicated population size \(N\).”

This is a genuine continuous-population version of the paper’s question. It preserves additive utilities, indivisible bundles, MMS, and the \(7/9\) approximation target. The only change is that repeated agents and repeated item copies are represented by masses and per-capita supplies.

I would expect this problem to be Class A, although the supplied paper does not itself prove the compressed high-multiplicity running time. The allocation is a configuration LP over integral bundles. The paper’s threshold search already avoids exact MMS computation, and its TPS initialization has a natural per-capita form,

\[ \beta=\sum_g q_g\min\{v_\theta(g),\beta\}. \]

The missing work is to aggregate the dynamic witness argument over type mass and to solve the resulting configuration/pricing problems efficiently. That is precisely the kind of continuous optimization question the programme is meant to expose. It is not a trivial restatement: the LP has potentially very many integral bundle configurations, and whether its pricing problem is polynomial, approximation-friendly, or continuum-specifically hard is an interesting computational question.

The supporting anchor is Theorem 3.1, also proved here. It states that for any ordered additive instance, threshold vector \((\alpha_i)\), and agent \(i\), if

\[ \alpha_i\le\MMS_i, \]

then the algorithm allocates to \(i\) a bundle \(B_i\) satisfying

\[ v_i(B_i)\ge\frac79\alpha_i. \]

It further states that if the algorithm returns \((\mathsf{Failure},F)\), then every agent \(i\in F\) satisfies

\[ \alpha_i>\MMS_i. \]

Its continuous mirror is the following threshold-certification problem:

“Given \((\Theta,\mu,q,v)\) and thresholds \(\alpha_\theta\), either output a feasible mass allocation \(\lambda\) such that

\[ \lambda_{\theta,b}>0 \quad\Longrightarrow\quad v_\theta(b)\ge\frac79\alpha_\theta \]

for every positive-mass type, or output a nonempty set \(F\subseteq\Theta\) such that

\[ \alpha_\theta>\MMS^\infty_\theta(q) \]

for every \(\theta\in F\).”

The expected direction is again tractable. In the finite theorem, the witness allocation is private to a fixed feasible agent and tracks only ordered item positions, bundle values, deficits, pebbles, and fluid material. In a high-multiplicity setting, those same objects can plausibly be maintained per valuation type rather than per named agent, with the integer positions replaced by supply quantiles. The failure certificate is especially natural: it says that a type’s target is too high for the per-capita supply, rather than merely that the algorithm got stuck on an unlucky finite assignment.

This anchor also gives a clean bridge between finite and continuous models. For rational inputs, a finite-support continuous allocation can be scaled to an ordinary finite allocation. Conversely, sequences of replicated finite allocations induce mass allocations over integral bundle types. Establishing the exact convergence and the appropriate rounding bounds would be a worthwhile theorem generated by the mirror itself.

The authors should recognise both questions as their problem. The paper’s central objects remain untouched: additive valuations, indivisible goods, MMS partitions, threshold feasibility, ordered residual instances, and the \(7/9\) guarantee. The paper’s Lemma 2.4, cited from earlier work, also makes the common-order restriction defensible rather than an arbitrary simplification: the paper explicitly reduces general instances to ordered ones before applying its analysis.

The scope is deliberately limited. This mirror covers the ordered additive MMS allocation theorem and its FPTAS, not the paper’s online, chore, ordinal, or weighted variants. It also does not pretend that the continuous result is already proved. The paper provides the algorithmic anchors and a strong candidate proof architecture; the continuous work is to aggregate it and determine the pricing complexity.

The weakest point is that MMS is intrinsically an \(n\)-way finite partition benchmark. If the goods are held fixed while the population grows, MMS eventually becomes degenerate, so the per-capita supply \(q\) must scale with the population. A sceptic could say that this changes the problem from indivisible-goods allocation into a configuration-market problem. I think that objection is not fatal: the finite approximants have exactly the paper’s original form, every individual still receives an integral bundle, and only the repeated population and repeated supply are compressed. But the convergence theorem and the efficient high-multiplicity implementation are genuinely necessary; they should be treated as open deliverables, not assumed for free.

The paper contains no named NP-hardness or NP-completeness theorem of its own, so I would not manufacture a hardness anchor from the introductory statement that exact MMS computation is NP-hard. The strongest honest positive case is therefore an algorithmic one: this paper supplies a particularly natural Class A candidate whose continuous version has a precise LP/configuration structure and a meaningful, nontrivial pricing frontier.

The case AGAINST (opponent, writing after the proponent)

The strongest objection is that the proposed mirror is not actually obtained by continuizing the paper’s population while preserving its problem. With the goods fixed, increasing the population makes the MMS benchmark collapse: once there are more agents than valuable item copies, \(\MMS_i\) becomes zero or otherwise trivial. The only repair is to introduce per-capita supplies \(q_g\), replace each good by \(Nq_g\) identical copies, and replace the \(n\)-way partition by a configuration distribution \(\pi_b\). That is a new high-multiplicity configuration problem, not the paper’s finite MMS problem with a continuous population substituted for \(N\).

This defeats the proponent’s claim that Theorem 10.4 already supplies a continuous FPTAS candidate. The theorem’s algorithm depends essentially on an integer active-agent count \(k\), positions \(u_k,u_{2k+1},u_{3k+1}\), and deleting one named bundle at a time. None of these has a canonical mass-level counterpart. The proposed \(\lambda_{\theta,b}\)-LP is not obtained by aggregating the threshold search: it requires a new configuration formulation, a new pricing algorithm, a new continuum MMS theorem, and rounding guarantees polynomial in the encoding length of \(q\). Calling this “expected Class A” is therefore speculation, not an anchor supplied by the paper.

The same objection applies to Theorem 3.1. Its failure set \(F\) consists of individual agents whose thresholds are too high after a particular sequential execution. In the proposed model, removing one bundle changes the residual supply by infinitesimal mass and does not change any continuum state. A type-level failure certificate would have to be newly defined and proved compatible with fractional splitting of a type across integral bundles. The private witness allocation, pebble counts, deficit lists, and adaptive repairs do not aggregate automatically over type mass.

But this is not enough for the requested universal negative. The programme expressly permits per-capita supplies when population continuization forces them, and the repaired model is otherwise quite respectable: types can be complete valuation types, individual bundles remain integral, rational finite instances scale to it, and the configuration problem is not already answered by the paper. Thus the negative case exposes that the proponent has proposed a substantial new problem rather than transferred the paper’s theorems. It does not honestly show that the problem is unworthwhile. Both anchors survive as plausible continuous-population questions, so a universal case against the mirror is weak.
