The continuous mirror question

Given finite driver types \(T\) with rational masses \(\mu_t\), and request classes \(J\) with rational demand densities \(q_j\in[0,1]\), where each type \(t\) has additive rational profits \(p_t(S)=\sum_{j\in S}w_{tj}\) and feasibility indicators \(f_{tj}\), decide separately for \(F\in\{\mathrm{EQ1},\mathrm{EF1}\}\) whether there are nonnegative masses \(x_{t,S}\) over integral bundles \(S\subseteq J\). Require \(\sum_S x_{t,S}=\mu_t\), forbid bundles containing requests infeasible for \(t\), and assign each serviceable class \(j\) exactly mass \(q_j\). For every two positive-mass type-bundle cells \((t,S)\) and \((u,U)\) with \(U\ne\varnothing\), require the paper’s \(F\) condition: for EQ1, some \(j\in U\) satisfies \(p_t(S)\ge p_u(U\setminus\{j\})\); for EF1, some \(j\in U\) satisfies \(p_t(S)\ge p_t(U\setminus\{j\})\).

The model it lives in

A distribution \(x_{t,S}\) over integral feasible bundles for each driver type, with rational population masses and request-class demand densities; the decision objective is whether an allocation satisfies completeness and the chosen pairwise fairness condition.

The objection that survived

The support-based fairness condition can miss a violation confined to a vanishing fraction of a cohort, even though the corresponding finite assignment violates the paper’s all-pairs condition.

fatal: False

What the mirror covers

The mirror covers Theorem 2’s existence problem for feasible complete EQ1 or EF1 assignments; it leaves the paper’s other existence and algorithmic results, and routing optimization, aside.

Open questions for a prover

  • Does allowing request-class mass to split across type-bundle allocations make either continuous existence problem polynomial-time solvable, or does hardness persist?
  • Can continuous solutions be rounded to finite cohorts while preserving feasibility and EQ1 or EF1?

The case FOR (proponent)

The strongest mirror is a high-multiplicity version of the paper’s FEASIBLE COMPLETE EQ1/EF1 decision problem. The anchor is Theorem 2, proved in this paper: with vehicle feasibilities and additive driver profits, deciding whether a feasible, complete EQ1/EF1 assignment exists is weakly NP-hard. The reduction is from Partition and uses three drivers and \(m+4\) requests. In its construction, EQ1 and EF1 coincide. So the hardness is not caused by having a large driver population; it comes from how requests with different profits can be grouped into bundles.

Here is the continuous question I would hand to a prover. Call it Continuous High-Multiplicity Feasible Complete EQ1/EF1. An instance has a finite set \(T\) of driver types, with rational masses \(\mu_t\geq 0\) summing to \(1\), and a finite set \(J\) of request classes. A type specifies a driver’s complete relevant profile: an additive profit \(p_t(S)=\sum_{j\in S}w_{tj}\) for bundles \(S\subseteq J\), and feasibility indicators \(f_{tj}\). Each request class is a recurring slot, with rational demand density \(q_j\in[0,1]\): in a normalized cohort, there is at most one request of class \(j\) per driver. This fits recurring fleet shifts with many drivers but relatively few stable vehicle, contract, and preference types.

A solution is a nonnegative mass \(x_{t,S}\) for each type \(t\) and bundle \(S\subseteq J\). It says what fraction of type \(t\) receives each integral bundle \(S\); it does not give any individual a fractional bundle. Require \(\sum_S x_{t,S}=\mu_t\), and \(x_{t,S}=0\) unless every request in \(S\) is feasible for \(t\). For each class \(j\) that some positive-mass type can serve, require \(\sum_{t,S:\,j\in S}x_{t,S}=q_j\), so all serviceable request mass is assigned. Classes that no type can serve remain unassigned, as in the paper’s completeness definition.

For fairness, compare every pair of type-bundle pairs \((t,S)\), \((u,U)\) with positive mass. If \(U\neq\varnothing\), EQ1 requires some \(j\in U\) such that \(p_t(S)\geq p_u(U\setminus\{j\})\); EF1 requires some \(j\in U\) such that \(p_t(S)\geq p_t(U\setminus\{j\})\). The question is whether such an \(x\) exists, with \(x\) as the witness. This preserves the paper’s one-request removal condition and makes each individual bundle integral while allowing the type-level averages to be fractional.

I think fleet operators planning recurring shifts with many interchangeable drivers could recognize this as their problem: they already assign requests to drivers with different vehicle and profit profiles, and fairness is naturally a condition on the drivers’ actual bundles. Normalizing request supply per cohort is the co-modification that makes this a population mirror. It is a meaningful regime when the number of drivers is much larger than the number of distinct driver types; it is not a claim that every VRP instance has that structure. The mirror covers the paper’s assignment and fairness question in Theorem 2, not routing optimization.

My first expectation is hardness transfers. The source of the reduction’s choices is the request set and its profit weights, not the number of drivers; moreover, the mirror retains indivisible bundles and the one-request fairness test. But Theorem 2 does not prove hardness for this mirror. A continuous mass of same-type drivers can receive different bundles, and that mixing may erase the Partition obstruction. That is especially plausible because the anchor gives only weak NP-hardness. The right initial questions are whether the mirror is still NP-hard, whether it has a pseudo-polynomial or fixed-parameter algorithm, and whether continuous solutions can be rounded to finite cohorts of identical drivers.

That mixing is the weakest point in my case. If it makes the Partition choices disappear, the discrete theorem may yield a tractable continuous problem instead. I still think the proposed question is worth asking: it is a precise population-level version of the paper’s own feasibility-constrained fairness problem, and the three-driver reduction gives a concrete reason to investigate where its hardness goes.

The case AGAINST (opponent, writing after the proponent)

The only anchor is Theorem 2, and it is a genuine computational result: deciding whether a feasible complete EQ1/EF1 assignment exists is weakly NP-hard. So there is no decisive objection that the paper lacks a problem to mirror.

The strongest case against is about the regime. Each request is an indivisible object, and a driver’s type includes their profit and feasibility profile across the whole request set. In a one-off routing problem, location and timing can make those profiles highly specific, so the number of types may grow with the fleet. If the request catalogue stays fixed while the fleet grows, requests per driver vanish and fairness can become trivial. Avoiding that degeneration requires recurring request classes whose supply grows with the driver population. That is a coherent model, but it shifts the setting toward recurring shift allocation.

There is also a fidelity issue: the paper’s fairness conditions quantify over every pair of drivers. A distribution over bundles cannot record a single exceptional driver once that driver has zero mass. The proposed support-based condition therefore permits a violation confined to a vanishing fraction of a large cohort, even though every finite instance containing that driver fails the paper’s condition.

Those points narrow the mirror; they do not defeat its strongest version. The recurring-shift scenario is plausible, and the proposed \(x_{t,S}\) preserves integral bundles while allowing the population to vary continuously. It asks a clear high-multiplicity fairness question. I cannot honestly make the universal negative case: the objections identify limits on when the mirror applies, but do not show that no worthwhile scenario exists.
