The continuous mirror question

Given a finite set of complete types \(T\), rational masses \(\mu_t\), and a differentiable coalition-worth function \(V\) with \(V(0)=0\), a gradient oracle, and bounded partial derivatives, estimate \(A_t=\mu_t\int_0^1 \partial_t V(s\mu)\,ds\) for every type. Can reverse-paired samples \(U_j\) and \(1-U_j\) achieve \(\Pr[\|\widehat A-A\|_\infty\le\epsilon]\ge 1-\delta\) with polynomially many oracle calls, and under what conditions do they reduce variance?

The model it lives in

A nonatomic TU game with finitely many complete agent types and coalition worth determined by the type-mass vector. The allocation to type \(t\) is the aggregate Shapley allocation \(A_t=\mu_t\int_0^1 \partial_t V(s\mu)\,ds\), estimated by paired samples along the path from \(0\) to \(\mu\).

What the mirror covers

The mirror covers Shapley approximation anchored by Theorem 1. It leaves the other Shapley theorems, the Banzhaf and Owen results, the empirical comparisons, and any guarantee that antithetic pairing reduces variance untouched.

Open questions for a prover

  • Which conditions on \(V\) ensure that pairing \(U\) with \(1-U\) reduces the variance of the allocation estimate?
  • Can useful finite-sample guarantees cover discontinuous threshold worth functions, such as weighted voting games, while preserving pivotality?

The case FOR (proponent)

The closest named anchor is Theorem 1, proved in this paper: the estimator from Algorithm 1, which pairs sampled permutations with their reverses, is an unbiased and consistent estimator of each player’s Shapley value. But that is a statistical guarantee, not a result that the underlying problem is in P, hard, or otherwise classified by computational complexity. The paper’s NP-hardness statement for exact Shapley computation appears in the introduction and cites outside work [14–16]; it is not a numbered result of this paper. So there is no anchor that meets your stated complexity-result requirement. I would not present Theorem 1 as if it did.

If statistical approximation guarantees are allowed as anchors, the most plausible mirror is a continuous Shapley allocation problem for a high-multiplicity cooperative game. Consider a utility cooperative with many households, grouped into a small number of complete types such as demand and connection classes. Let \(T\) be the types, \(\mu_t\) the fraction of households of type \(t\), and \(V(x)\) the worth of a coalition with type-mass vector \(x\). For a differentiable \(V\) with \(V(0)=0\), define the aggregate allocation to type \(t\) by

\[ A_t=\mu_t\int_0^1 \partial_t V(s\mu)\,ds. \]

This is the high-multiplicity limit suggested by finite Shapley values: if \(n\) households have type proportions \(\mu\), and a coalition’s worth is \(V\) of its normalized type counts, then a type-\(t\) household’s marginal contribution at position fraction \(s\) approaches \(\partial_t V(s\mu)/n\). Summing over type-\(t\) households gives \(A_t\). The number of households can be very large while \(|T|=\tau\) remains small.

A precise candidate is Continuous Antithetic Shapley Allocation Approximation. Its instance is \((T,\mu,V,\epsilon,\delta)\), with rational \(\mu\), an evaluation oracle for \(\nabla V\), and bounded partial derivatives. The task is to return \(\widehat A\) such that \(\Pr[\|\widehat A-A\|_\infty\le\epsilon]\ge 1-\delta\). For independent uniform samples \(U_j\), the paired estimator

\[ \widehat A_t=\frac{\mu_t}{2M}\sum_{j=1}^{M} \left(\partial_tV(U_j\mu)+\partial_tV((1-U_j)\mu)\right) \]

is unbiased and consistent. With known derivative bounds, standard concentration gives polynomial oracle-sample complexity in \(\tau\), \(1/\epsilon\), and \(\log(1/\delta)\). I would expect this approximation problem to be tractable in that oracle model. The formula is an Aumann–Shapley-type continuous allocation, so any contribution here would be computational or statistical analysis, not novelty of the value formula itself.

The mirror’s weak point is that it restricts the paper’s arbitrary TU games to games whose worth depends smoothly on aggregate type masses. Theorem 1 does not establish a complexity bound or that reverse pairing reduces variance; the paper’s experiments report that antithetic sampling can sometimes perform worse. Thus this is a plausible population-continuous extension of Shapley approximation, but it is not a complexity-anchored case for this paper under the required rule.

The case AGAINST (opponent, writing after the proponent)

The strongest case against treating this as a ChoCo mirror is that the paper supplies no named complexity result. Theorems 1–7 establish unbiasedness and consistency for sampling estimators; they give no finite-sample error or complexity bound, and no theorem guarantees that antithetic pairing reduces variance. The exact Shapley-value NP-hardness is cited as prior work, not proved here. So Theorem 1 is an algorithmic correctness result, but a weak anchor for a programme about complexity and approximation algorithms.

The proponent’s smooth, type-based game is the best version of a continuous Shapley mirror. If finite games are defined by \(v_n(S)=V(k(S)/n)\), with \(V\) differentiable, the type-aggregate Shapley value can converge to \(A_t=\mu_t\int_0^1\partial_tV(s\mu)\,ds\). That is a coherent model. But it adds a sequence of games, a smooth aggregate worth function, and a gradient-oracle input model; none follows from the paper’s arbitrary TU game. The continuous target is an Aumann–Shapley allocation, and its sampling variable is a point on a one-dimensional path. With a gradient oracle, the oracle-call cost also hides the work needed to evaluate the game. This looks more like a new continuous allocation problem than a continuization of the paper’s general estimator result.

A stronger ComSoC example would be a high-multiplicity weighted voting game, since the paper itself discusses voting power. There the natural worth function is a threshold, \(V(x)=\mathbf{1}[\sum_t w_t x_t\ge q]\), which is not covered by the proposed differentiable model: pivotality is concentrated near the threshold, and ordinary derivatives along the path do not capture it. Defining a suitable mass-level power index may be worthwhile, but it requires a further model choice and does not inherit Theorem 1’s guarantee automatically.

That is a good case against this paper as a complexity-anchored ChoCo paper. It does not support the requested universal claim that no worthwhile mirror exists. Smooth, type-symmetric cooperative games give a plausible population-level allocation and approximation question, and a careful extension could be author-recognizable. The honest negative case is therefore limited: the source’s named results are weak complexity anchors, while the broader claim that every continuous mirror fails is not convincing.
