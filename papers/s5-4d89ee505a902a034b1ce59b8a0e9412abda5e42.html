The continuous mirror question

Given ranking types \(T\), binary-rational masses \(\mu_t>0\) with \(\sum_{t\in T}\mu_t=1\), and rational per-capita supplies \(q_j\in[0,1]\) with \(\sum_{j=1}^m q_j=1\), compute exactly the type-level probabilistic-serial allocation \(x_{tj}\). Each type’s mass eats its most-preferred category with positive residual supply at unit speed, so category \(j\) is consumed at rate \(\sum_{t:\,j\text{ is chosen by }t}\mu_t\); determine the running time in \(m\), \(\tau=|T|\), and input bit length \(L\).

The model it lives in

A continuum of students represented by ranking types \(t\) with masses \(\mu_t\), competing for interchangeable seat categories with per-capita supplies \(q_j\). The decision variables are the exact per-student type allocations \(x_{tj}\), produced by mass-weighted PS eating; each student receives one seat in the random-assignment sense.

The objection that survived

Che and Kojima already give an object-exhaustion procedure for continuum PS, including multi-unit-eating PS, so the remaining contribution may be mainly a sharper complexity analysis for binary-encoded masses and supplies.

The case FOR (proponent)

The strongest positive case is the paper’s Theorem 3, proved here: multi-unit-eating PS runs in linear time, is stochastic-dominance envy-free, weakly stochastic-dominance strategyproof, and unanimous, but is not ex post efficient. Its runtime claim is the paper’s clearest computational anchor. The paper gives no named NP-hardness or other complexity-hardness result to anchor a hardness-dissolution question.

A plausible mirror is a large school-assignment market. Let the finitely many types \(T\) be strict rankings over \(m\) school or seat categories, with rational population masses \(\mu_t>0\) summing to \(1\). Let \(q_j\in\mathbb{Q}\cap[0,1]\) be the supply of category \(j\) per person, with \(\sum_j q_j=1\). Thus a finite population of size \(N\) has \(Nq_j\) seats of category \(j\), for compatible \(N\). Each student receives one seat; seats within a category are interchangeable. The regime of interest has \(N\) large and support size \(\tau=|T|\) relatively small. This is the single-unit subcase of the paper’s model, in a setting it explicitly identifies as a natural assignment application.

Call the problem PS\(_\infty\)-Compute. Given \(m\), the rankings in \(T\), the rational masses \(\mu\), and the rational supplies \(q\), compute the exact type-level assignment \(x=(x_{tj})\) produced by probabilistic serial. Start with residual supply \(q_j\) for each category. At each time, every member of type \(t\) eats their most-preferred category with positive residual supply at unit speed; when a category is exhausted, that type moves to its next available category. Category \(j\)'s residual supply falls at rate \(\sum_{t:\,j\text{ is currently chosen by }t}\mu_t\). The solution is the exact matrix \(x\) of per-person type allocations when the process ends, with \(\sum_j x_{tj}=1\) and \(\sum_t\mu_t x_{tj}=q_j\). The population distribution \(\mu\) is the continuous object; the fractional rows record each type’s average allocation, while each student still receives one seat.

I expect this problem to be tractable, in Class A: at most \(m\) categories can be exhausted, and each event updates the types’ choices. That suggests an exact algorithm polynomial in \(m,\tau,L\), where \(L\) is the input bit length. This is a new claim to prove for rational type masses and supplies; Theorem 3’s linear-time result for a finite profile does not itself establish the bit complexity of this compressed input.

The mirror covers the computation clause of Theorem 3 on the \(c=1\) subdomain. The paper’s continuous eating time and fractional assignment are not, by themselves, population continuization; the proposed input is a distribution over preference types. Natural follow-up questions are whether the theorem’s envy-freeness and unanimity claims hold in this rational-mass model, and how to define meaningful strategic deviations by a positive-mass group. In a nonatomic population, a single individual has no effect on aggregate supply, so individual strategyproofness does not transfer directly.

The weakest point is the restriction to interchangeable seat categories and single-unit demand. It is a credible high-multiplicity regime for the paper’s assignment problem, but it does not settle the multi-unit case with distinct objects or the full theorem. The precise algorithmic mirror is promising; its extension and bit-complexity analysis remain to be done.

The case AGAINST (opponent, writing after the proponent)

The strongest negative case is a prior-art collision with the proposed anchor. The paper’s Theorem 3 really does make a computational claim, so “there is no result to mirror” is not available. But the proponent’s concrete mirror is single-unit PS on rational masses of preference types. Che and Kojima already define PS in a continuum economy with finitely many preference types and type masses, and give a recursive object-exhaustion procedure that computes each type’s assignment in finitely many steps—at most one exhaustion round per object. This is an algorithmic construction, not merely an analytic statement about a limit. [Che and Kojima, *Asymptotic Equivalence of Probabilistic Serial and Random Priority Mechanisms*](https://www.columbia.edu/~yc2271/files/publications/psrp-Final.pdf)

Restoring multi-unit demand makes the mirror less identical, but not much more compelling: Che and Kojima also define multi-unit-eating PS, the same rule discussed here, and treat its large-market behavior. The target paper itself cites their work as the source that briefly described MPS. What remains is chiefly a sharper input-encoding analysis—especially a bit-complexity bound for rational masses and supplies—and the correction for cases with fewer than \(c\) available objects. That could make a useful technical result, but it would refine an existing continuum algorithm rather than open a new computational landscape.

This is a credible objection to the proposed mirror’s novelty, not a universal case that no worthwhile mirror exists. If the programme counts a new binary-input complexity theorem as worthwhile even when the continuous rule and its event algorithm are already established, this anchor survives. I can’t honestly rule that out; the negative case is therefore limited.
