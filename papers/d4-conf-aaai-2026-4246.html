The continuous mirror question

Given \(k\ge3\), rational masses \(\mu_{c,d}\ge0\) with \(\sum_d\mu_{c,d}=1/k\) for every color \(c\), and a rational threshold \(q\), let type \((c,d)\) have initial cluster label \(d\). Decide whether there is a finite or countable measurable partition \((F_a)\) of the population such that every \(F_a\) has equal mass from each color and \(J(F)\le q\), where \(J(F)=\frac12\int_{[0,1]^2}\left|\mathbf{1}[d(x)=d(y)]-\mathbf{1}[f(x)=f(y)]\right|\,d\rho(x)\,d\rho(y)\), and \(f(x)\) is the output cluster containing \(x\).

The model it lives in

Use types \(t=(c,d)\), the color and initial cluster, with mass \(\mu_{c,d}\). Allocate \(x_{c,d,a}\ge0\) to output cluster \(a\), with \(\sum_a x_{c,d,a}=\mu_{c,d}\) and \(\sum_d x_{c,d,a}=z_a\) for each color \(c\). The fair-clustering objective is \(J=\frac12\left[\sum_d\mu_d^2+\sum_a(kz_a)^2-2\sum_{d,a}\left(\sum_c x_{c,d,a}\right)^2\right]\), where \(\mu_d=\sum_c\mu_{c,d}\); ask whether a feasible allocation has \(J\le q\).

The case FOR (proponent)

The strongest mirror is the paper’s closest fair clustering with equal group sizes, anchored on Theorem 3, which the authors prove in this paper. For every fixed \(k\ge 3\), Theorem 3 says that \(k\)-CLOSEST EQUIFAIR is NP-hard: given a clustering \(H\) whose \(k\) color groups have equal total size and an integer threshold \(\tau\), decide whether there is a fair clustering \(F\) with \(\operatorname{dist}(H,F)\le\tau\). Here fairness means every output cluster has equal numbers of all \(k\) colors, and \(\operatorname{dist}\) counts the unordered pairs together in one clustering and separated in the other. The paper proves this by reduction from a restricted, strongly NP-complete version of 3-PARTITION; its no-instance argument uses a lemma from Chakraborty et al. (2025a).

A plausible high-multiplicity setting is a large, balanced administrative dataset being post-processed after an existing segmentation. There might be millions of records, three or more equally sized protected cohorts, and dozens or hundreds of initial clusters, with many records in each cohort-by-cluster combination. The type is \((c,d)\): a record’s color \(c\) and its cluster \(d\) in the existing solution. Those attributes fully describe what Theorem 3’s problem uses. Records of the same type are interchangeable for both its fairness constraint and its pairwise distance objective. Thus the population can be much larger than its number \(\tau\) of positive-mass types.

Here is a precise continuous version, EquiFair Closest Mass. An instance is \(k\ge3\), a finite table of rational masses \(\mu_{c,d}\ge0\) summing to \(1\), with \(\sum_d\mu_{c,d}=1/k\) for every color \(c\), and a rational threshold \(q\). Let \(X=[0,1]\) with Lebesgue measure \(\rho\), partitioned into type blocks \(X_{c,d}\) of measure \(\mu_{c,d}\). The initial cluster of each point in \(X_{c,d}\) is \(d\).

A solution is a measurable partition of \(X\) into finitely or countably many positive-mass output clusters \(F_a\), such that each cluster contains equal mass from every color:
\[ \rho(F_a\cap X_1)=\cdots=\rho(F_a\cap X_k). \]
The decision question is whether such a partition exists with
\[ J(F)=\frac12\int_{X\times X} \left|\mathbf{1}[d(x)=d(y)]-\mathbf{1}[f(x)=f(y)]\right| \,d\rho(x)\,d\rho(y)\le q, \]
where \(f(x)\) is the output cluster containing \(x\). This is exactly the paper’s pair-disagreement objective normalized by the square of the population size for finite empirical societies. Every individual still belongs to one output cluster; the continuum permits a type’s mass to be divided across clusters.

Equivalently, a solution can be given by nonnegative allocations \(x_{c,d,a}=\rho(X_{c,d}\cap F_a)\) satisfying \(\sum_a x_{c,d,a}=\mu_{c,d}\) and \(\sum_d x_{c,d,a}=z_a\) for every color \(c\), for some cluster masses per color \(z_a\). Its objective is
\[ J=\frac12\left[ \sum_d\mu_d^2+\sum_a(kz_a)^2 -2\sum_{d,a}\left(\sum_c x_{c,d,a}\right)^2 \right], \qquad \mu_d=\sum_c\mu_{c,d}. \]
Because each type block is nonatomic, these allocations correspond to measurable partitions. This gives a prover a concrete optimization problem in \(k\), the support size \(\tau\), and the mass and threshold bit lengths.

My low-confidence expectation is Class A: tractable, rather than hardness transferring. The reduction’s 3-PARTITION items are encoded as cluster masses; in the continuous problem those masses can be cut and distributed, so the indivisibility that enforces exact packing disappears. The continuous optimum would also be a lower bound on the normalized discrete optimum, with a further question about whether it can be rounded with a useful additive loss. There is no tractability result in this argument: the displayed objective is quadratic and need not yield an LP. If the continuous problem remains hard, that would point to continuum-specific hardness from the objective and allocation structure, rather than an immediate transfer of Theorem 3’s reduction.

This case covers Theorem 3’s equal-proportion closest fair clustering problem only. It does not claim mirrors for the approximation results or for fair correlation and consensus clustering. The weakest point is disciplinary fit: the paper’s units are records being clustered, not voters with preferences, and the pairwise objective leads to a quadratic population problem rather than the LP pattern in ChoCo’s central examples. Still, the mirror preserves the authors’ underlying question—how to change an existing clustering as little as possible while enforcing group fairness—and its type definition follows exactly from what that problem distinguishes.

The case AGAINST (opponent, writing after the proponent)

Theorem 3 is the proponent’s strongest anchor, and its type choice is sound: \((\text{color},\text{input cluster})\) fully captures what the problem uses. Large cohorts of interchangeable records are plausible, and the existing high-multiplicity clustering work supports that regime rather than disqualifying it. I would not argue that the problem depends on individual identity or has no sensible population interpretation.

The sharper concern is that the pairwise objective makes the unconstrained continuum version unstable under cluster refinement. Take \(k\ge3\) monochromatic input clusters, one per color, each of mass \(1/k\). If fair output cluster \(a\) contains mass \(z_a\) of each color, then the proposed normalized cost is
\[ J=\frac{1}{2k}+\frac{k(k-2)}{2}\sum_a z_a^2. \]
Splitting the population into \(r\) equal fair clusters gives \(J=\frac{1}{2k}+\frac{k-2}{2kr}\), which approaches \(1/(2k)\) as \(r\) grows. With finitely or countably many positive-mass clusters, \(\sum_a z_a^2>0\), so the infimum is not attained. If zero-mass singleton clusters are allowed instead, fairness holds vacuously for every cluster and the cost reaches \(1/(2k)\). Either way, the result depends on how the model handles arbitrarily fine output clusters. A cap on the number of clusters or a minimum cluster mass fixes this, but adds a resolution parameter absent from the paper’s closest-clustering problem. The quadratic pairwise objective also offers no immediate LP-based route to the programme’s usual continuous-optimization gains; that makes the payoff uncertain, though it is not by itself a reason to reject the question.

This is a substantive reason to hesitate over the *unconstrained* mirror, but it does not defeat the better fixed-resolution version: a mass-based closest fair clustering with a specified number of output clusters could still be a worthwhile computational question. So the honest negative case is limited. I cannot support the universal claim that no scenario yields a worthwhile continuous mirror, and the anchor likely survives if the authors accept that co-modification.
