The continuous mirror question

Given a fixed finite type set \(T\), rational masses \(\mu_t>0\) summing to \(1\), a type graph \(H\) specifying the symmetric links between type classes, and rational polynomial worth specifications, form each replicated network \(G_q\) with \(q\mu_t\) agents of type \(t\), for integers \(q\) such that \(q\mu_t\in\mathbb{Z}\). Let each component’s worth on the networks reached by isolating agents be \(q\) times its specified polynomial in the component and active type masses. Under a promise that the limits exist, compute to additive error \(\varepsilon\) each type’s limiting per-agent BCE payoff \(p_t=\lim_{q\to\infty}\mathrm{BCE}_i(w_q,G_q)\), and each linked type pair’s first-order withdrawal effect \(d_{t\leftarrow s}=\lim_{q\to\infty}q[\mathrm{BCE}_i(w_q,G_q)-\mathrm{BCE}_i(w_q,G_q^{-j})]\), for agents \(i\) of type \(t\) and \(j\) of type \(s\).

The model it lives in

A society \(\mu\) over fixed types \(T\), a symmetric type graph \(H\), and extensive polynomial worths; the outputs are limiting per-type BCE payoffs and first-order withdrawal effects, with no optimization objective.

What the mirror covers

The mirror covers Theorem 3’s BCE allocation on symmetric fixed-type blow-up networks; it leaves aside the FCE rule, the incompatibility results, the complete-network Shapley identity, and the PFF comparisons.

Open questions for a prover

  • For which worth specifications do the payoff and withdrawal-effect limits exist without a promise?
  • Can these limits be computed to additive error \(\varepsilon\) in time polynomial in the input length and \(1/\varepsilon\), for fixed or variable \(|T|\)?
  • How broadly do the results extend beyond symmetric type-level blow-up networks?

The case FOR (proponent)

The paper contains no named computational result in the ChoCo sense: it proves no problem in P, NP-hard, FPT, or a comparable complexity class, and gives no running-time analysis. The closest anchor is Theorem 3, proved here: for every finite network and network worth function, the BCE rule is the unique allocation rule satisfying component efficiency and balanced contributions. The paper constructs it recursively using spanning-tree offsets, then uses Lemma 4’s cycle-sum identity to establish balanced contributions on the remaining edges. That is a constructive axiomatic result, but calling it a computational-complexity result would overstate what the paper proves.

The strongest plausible regime is a large role-based network economy: many interchangeable participants, but relatively few complete types. For example, a platform might have large cohorts of suppliers and users in a handful of roles, with the same network position and externality-relevant characteristics within each type. The network can be a symmetric, dense type-level structure, and component worth can depend on the masses of active and isolated types. This is a genuine high-multiplicity regime: the number of participants grows while the number of distinct types stays modest.

If Theorem 3 is accepted as a structural anchor for a new computational question, I would propose Continuum BCE Limit. An instance gives a finite type set \(T\), rational masses \(\mu_t\) summing to one, an undirected type graph \(H\), and a succinct rational-polynomial worth specification. For each replication factor \(q\) such that \(q\mu_t\) is integral, form a network \(G_q\) with \(q\mu_t\) interchangeable agents of type \(t\), linking type classes according to \(H\). Specify each component’s worth on every network reached by isolating agents as \(q\) times a function of the active and isolated type masses. This allows network externalities to depend on the whole network state.

For each type \(t\), the requested output is the limiting BCE payoff \(p_t\) to a type-\(t\) agent as \(q\) grows. To retain balanced contributions in the limit, also output, for each linked type pair \(t,s\), the limiting first-order withdrawal effect
\[ d_{t\leftarrow s} =\lim_{q\to\infty}q\bigl(\mathrm{BCE}_i(w_q,G_q) -\mathrm{BCE}_i(w_q,G_q^{-j})\bigr), \]
where \(i\) has type \(t\), \(j\) has type \(s\), and \(G_q^{-j}\) isolates \(j\). The finite models’ balanced-contributions equations imply \(d_{t\leftarrow s}=d_{s\leftarrow t}\). The problem is to compute \(p\) and \(d\) to a requested additive accuracy, under a promise that these limits exist. There is no optimization objective: the output is the allocation and its marginal withdrawal effects, as in the paper’s allocation-rule problem.

I think authors could recognize this as a high-multiplicity version of computing their BCE allocation: it keeps the same network externalities, component efficiency, and individual-withdrawal symmetry, while asking for the allocation in a repeated-type population. The mirror covers Theorem 3 in this structured regime. It does not cover arbitrary networks, the FCE rule, or the paper’s PFF comparisons.

My tentative prediction is Class A for fixed, modest \(|T|\). In the replicated networks, the recursive construction may be compressible by type-count states, and the cycle-sum argument offers a natural way to handle non-tree links. Whether that yields a useful algorithm when \(|T|\) is part of the input is open; the paper supplies no complexity evidence either way. Further questions include whether the limits always exist for regular worth specifications, whether the withdrawal effects equal derivatives of the limiting allocation, and whether the method remains tractable as the number of types grows.

The weak point is substantial: isolating one agent has vanishing mass in an atomless population, so an unscaled continuum version of balanced contributions risks becoming vacuous. The proposed problem preserves its content by taking a replicated-population limit and scaling the withdrawal effect by \(q\). That is a reasoned extension, not a theorem of the paper. And because Theorem 3 is not a complexity result, this is at best a promising follow-up computational problem—not a case that the paper already anchors a discrete-hardness-to-continuum study.

The case AGAINST (opponent, writing after the proponent)

Theorem 3 is the only plausible anchor, and it is not a computational result. It characterizes an allocation rule axiomatically: component efficiency and balanced contributions determine a unique rule. The cycle-sum identity proves that the construction satisfies the axioms on non-tree edges. But the paper gives no encoded input, computational problem, or running-time claim. Its worth function is arbitrary, so the recursive construction is not an algorithmic result with a stated complexity. That is a serious mismatch with a programme about computational questions.

The proposed Continuum BCE Limit is a thoughtful follow-up, but it has to add nearly all the structure that makes it computable: a fixed type graph, replication into homogeneous classes, worths scaled as \(q f(\cdot)\), and promises that the payoff and withdrawal-effect limits exist. Theorem 3 establishes none of these limits or their computability. The resulting question may be interesting, but it is not a continuous version of a computational finding in this paper.

The strongest version would preserve general network structure by making each type encode everything relevant about an agent’s network role. In arbitrary networks, that role can be unique, so the number of types may grow with the population and the high-multiplicity compression disappears. Keeping a fixed number of types instead means restricting attention to symmetric blow-up networks. There, the limit records masses, while the paper’s balanced-contributions condition concerns removing one particular agent and all that agent’s links. That individual has zero mass in the limit. The proposed factor of \(q\) can retain a first-order effect, but it asks for a finite-size asymptotic correction; that correction requires a specified sequence of networks and worth functions, not just a continuous society. Smooth, fixed-type models may make the correction meaningful, but they are a new model class.

Nor does the paper supply a clear computational foothold for that class. For an arbitrary worth function, complexity depends on how it is represented. Restricting it to a succinct polynomial specification fixes that problem by choosing a new input model; it does not reveal a complexity landscape already latent in Theorem 3. The paper’s central work is about which axioms characterize BCE, not how to compute BCE from a compact description.

So the strongest case against is that this paper contributes no computational result for ChoCo to continuize, and its best proposed mirror becomes a separate asymptotic-computation project under substantial new assumptions. The case is weaker against the universal claim: a large symmetric economy with a few roles and smooth, extensive worths is coherent, and studying its limiting allocation could be worthwhile. But the proponent’s prediction of tractability is unsupported here, and the paper itself gives little reason to prioritize that project.
