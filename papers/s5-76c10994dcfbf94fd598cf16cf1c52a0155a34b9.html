The case FOR (proponent)

My strongest case is a high-multiplicity mirror of the paper’s proportional-allocation result.

The anchor is Theorem 4.4, proved in this paper. It states: if \(\mathcal D\) is PDF-bounded and has mean at most \(1/2\), then for \(n\le m\le 2n\), there is a polynomial-time algorithm that outputs a proportional allocation with high probability. The algorithm is the two-stage matching procedure: first give every agent one sufficiently valuable item, then match leftover items to agents whose first item is not yet enough for proportionality.

The continuous problem I would put to a prover is:

\(\textsc{HM-PropAlloc}_{2}\). An instance consists of a finite set \(T\) of agent types, a rational population distribution \(\mu\in\mathbb Q_{\ge0}^{T}\) with \(\sum_t\mu_t=1\), a finite set \(J\) of item classes, rational per-capita supplies \(\rho_j\ge0\) satisfying \(1\le\sum_j\rho_j\le2\), and additive utilities \(u_t(j)\ge0\). Type \(t\) values an integral bundle \(b\in\mathbb Z_{\ge0}^{J}\) at \(u_t(b)=\sum_j b_j u_t(j)\). Let \(U_t=\sum_j\rho_j u_t(j)\), the value of the whole per-capita supply to type \(t\).

The task is to find a mass-allocation \(x_{t,b}\ge0\), over integral bundles \(b\) with \(1\le\sum_jb_j\le2\), such that

\[ \sum_b x_{t,b}=\mu_t \]

for every type \(t\),

\[ \sum_{t,b}b_jx_{t,b}\le\rho_j \]

for every item class \(j\), and

\[ x_{t,b}>0\quad\Longrightarrow\quad u_t(b)\ge U_t. \]

Equivalently, the optimization version maximizes the mass assigned proportionally; the decision question is whether the optimum is \(1\).

This is genuinely a population-continuation. Each unit of mass still receives an integral one- or two-item bundle. Items are not fractionally assigned to individuals. Only the aggregate \(x_{t,b}\) is fractional. For rational data, multiplying by a common denominator turns \(x\) into an ordinary finite allocation of repeated agent types and repeated item copies.

A plausible regime is a large housing or office-allocation market with \(N\) households but only \(\tau\) standardized valuation templates: for example, family-size/location profiles or employer/employee categories. There are \(N\mu_t\) households of type \(t\) and \(N\rho_j\) copies of item class \(j\), with \(N\gg\tau,|J|\). This is exactly the high-multiplicity regime: agents sharing a type have identical utilities and parameters, while the number of agents grows far faster than the number of distinct types.

The authors should recognize this as their problem. The proportionality condition is unchanged after normalization: in a finite market, a type-\(t\) agent must receive at least \(u_t(M)/N=U_t\). The two-stage structure is also not invented merely to make the problem easy; it is the actual structure of the algorithm proving Theorem 4.4 in the paper.

I expect this mirror to be Class A in the stated one-or-two-item regime. The allowed bundles are singletons or pairs, so the continuous problem is a finite configuration LP with \(O(\tau |J|^2)\) variables and polynomially many constraints. It can be solved in polynomial time over rational inputs. The important computational gain is that repeated agents and repeated item supplies are handled as mass flows, while each microscopic allocation remains integral.

This does not claim that the paper’s high-probability statement transfers unchanged. Its i.i.d. continuous utilities almost surely give every finite agent a distinct utility vector, so that particular random model is not itself high-multiplicity. The mirror uses a different but natural scenario for the same proportional-allocation problem. That is legitimate, but it is also the weakest point: a referee might regard the restriction to repeated item classes and one-or-two-item bundles as too specialized. I would therefore not claim to mirror the paper’s EFX theorem, its \(e\)-threshold for envy-free assignments, or the exact random threshold phenomena. The narrower claim is that Theorem 4.4 opens a credible continuous-population version of its core matching problem, with a precise and polynomially solvable mass formulation.

The case AGAINST (opponent, writing after the proponent)

The proponent has chosen the strongest possible rescue, but it does not actually preserve the computational content of Theorem 4.4.

That theorem is not merely “proportional allocation can be found by matching.” Its substantive claim is a high-probability existence result for an \(n\times m\) utility matrix whose entries are independently drawn from a continuous distribution. The threshold \(n\le m\le 2n\), the anti-concentration argument, and the two matching stages all exploit independence across agents and items. A complete agent type in this model is the agent’s entire utility vector over the \(m\) items. Under the paper’s distribution, two such vectors coincide with probability zero. Thus the paper’s own instances have no nontrivial high-multiplicity regime.

The proposed replacement removes exactly that structure. Once agents with the same type have identical utilities for each item class, their threshold graphs and total utilities are perfectly correlated, not Erdős–Rényi and independently concentrated. The proof of Theorem 4.4 no longer applies, and neither does its \(m/n=2\) phenomenon. One could study a new random model over finitely many templates, but that would require a new theorem about a different source of randomness; it would not be a continuization of the paper’s result.

Nor does the proposed LP retain a hidden computational challenge. Because every agent receives at most two items, the possible configurations for type \(t\) are just the \(O(|J|^2)\) singletons and pairs. The formulation is therefore an explicit transportation/configuration LP with polynomially many variables. Clearing denominators gives an ordinary allocation of repeated types and repeated item copies, so the “continuum” contributes no new structure beyond normalized multiplicities. Keeping the items individually named instead of grouping them into classes does not repair this: with one or two items per bundle, there are still only \(O(m^2)\) configurations.

The best attempted rescue is to retain finite agent templates while allowing the item set to grow. That gives a legitimate high-multiplicity allocation problem, but it still replaces the paper’s independent utility draws by a deterministic template matrix. Conversely, retaining independent draws makes the full utility vector part of the type, and the number of types is almost surely the number of agents. A stochastic “type” whose members later receive private utility realizations would no longer be the paper’s ex-post proportionality problem.

So the proponent has exhibited a sensible mass-allocation problem, but not a worthwhile continuous mirror of the paper’s named result: the proposed model discards the theorem’s asymptotic probabilistic phenomenon and leaves behind an elementary explicit LP. This negative case is not airtight, because the programme may reasonably value that LP as a clean Class A baseline for a related fair-division problem. Under the stricter requirement that the mirror preserve the paper’s actual computational contribution, however, Theorem 4.4 does not survive.
