The continuous mirror question

Given finitely many binary agent types \(a\) with rational masses \(\mu_a\), house categories \(h\) with rational per-capita supplies \(\nu_h\), binary utilities \(u(a,h)\), and a rational threshold \(\Gamma\), does there exist an envy-free assignment of mass \(x_{a,h}\) and nonnegative cell subsidies \(p_{a,h}\) with total cost \(\sum_{a,h}x_{a,h}p_{a,h}\leq\Gamma\)? Require \(\sum_h x_{a,h}=\mu_a\), \(\sum_a x_{a,h}\leq\nu_h\), and \(u(a,h)+p_{a,h}\geq u(a,h')+p_{a',h'}\) for every pair of used cells; each person still receives one indivisible house.

The model it lives in

A distributional house-allocation model with finitely many complete binary valuation types, rational type masses, and rational per-capita supplies of house categories. The decision variables are type-to-category mass flows and per-person subsidies for used cells; minimize \(\sum_{a,h}x_{a,h}p_{a,h}\) subject to capacity and envy-freeness constraints.

What the mirror covers

The mirror covers the binary minimum-subsidy hardness in Theorem 3.5 and the bounded-type algorithm in Theorem 4.5; it leaves the two-type general-utility result in Theorem 5.5 unmirrored.

Open questions for a prover

  • Does the Minimum \(k\)-Union reduction remain valid after mass assignments are allowed, in particular through a maximum-cardinality normalization for positive-subsidy optima?
  • Does minimum-subsidy mass allocation remain fixed-parameter tractable in the number of agent types for the full rational input model?

The case FOR (proponent)

The strongest case is that this paper already treats repeated preference profiles as computational structure: its binary results ask whether identical agents can be grouped into types and processed by type-level matching. A continuous mirror keeps each person’s allocation indivisible and changes the population description to masses. That is a reasonable extension of the authors’ problem, not a move to fractional houses or lotteries.

Call the shared model \(\textsc{Mass-MinSubsidy-Binary}\). An instance has finitely many complete agent types \(a\in\mathcal A\), house categories \(h\in\mathcal H\), binary utilities \(u(a,h)\), rational agent masses \(\mu_a\) with \(\sum_a\mu_a=1\), rational house supplies \(\nu_h\) with \(\sum_h\nu_h\geq1\), and a rational subsidy threshold \(\Gamma\). A solution is a mass assignment \(x_{a,h}\geq0\), with \(\sum_h x_{a,h}=\mu_a\) and \(\sum_a x_{a,h}\leq\nu_h\), plus a nonnegative per-person subsidy \(p_{a,h}\) for each cell with \(x_{a,h}>0\). Every person still receives one indivisible house; \(x_{a,h}\) records what fraction of a type’s population receives a category. Require envy-freeness across every pair of used cells: \(u(a,h)+p_{a,h}\geq u(a,h')+p_{a',h'}\) whenever \(x_{a,h},x_{a',h'}>0\). The cost is \(\sum_{a,h}x_{a,h}p_{a,h}\). The decision question is whether a solution of cost at most \(\Gamma\) exists; its optimization version minimizes that cost.

My lead anchor is Theorem 3.5, proved in this paper. It states that deciding whether a binary-utility house-allocation instance has an envy-free outcome with total subsidy at most a given positive integer \(\gamma\) is NP-complete. The paper proves the hardness by reduction from Minimum \(k\)-Union, whose NP-completeness it cites.

The mass version appears to preserve the reduction’s central choice. For a Minimum \(k\)-Union instance with universe \(U\), \(m\) sets, and parameter \(k\), let \(Q=|U|+m+k\). Give each element type mass \(1/Q\), and give one common type mass \((m+k)/Q\). Include a private house category for each element, a category for each set, and \(m\) categories liked only by the common type, each with supply \(1/Q\). Element type \(e\) values its private category and precisely the set categories whose sets contain \(e\); the common type values the \(m\) remaining categories.

In the intended minimum-subsidy pattern, each element type gets its private category, the common type gets the \(m\) categories it values, and its remaining mass \(k/Q\) goes to set categories. If \(y_j\) is the amount sent to set category \(j\), scaled by \(Q\), then \(0\leq y_j\leq1\) and \(\sum_j y_j=k\). Any positive use of a set category forces a subsidy for every element type that values it: those agents would otherwise envy common-type agents receiving that category with a subsidy. The resulting cost is \((k+|\bigcup_{j:y_j>0}S_j|)/Q\). The support must contain at least \(k\) sets, so a support with union size at most \(q\) contains a \(k\)-set subfamily with union size at most \(q\). Conversely, a \(k\)-set solution gives the corresponding mass assignment. This is why the reduction looks robust to fractional flows: splitting mass among more set categories does not turn off the cost of the union.

I expect hardness to transfer for this question. The one proof obligation is to establish for the mass model the same maximum-cardinality normalization that the paper uses for positive-subsidy optima in Lemma 3.4. A mass version of its augmenting-path argument looks plausible, but it is not established by Theorem 3.5 itself. A useful next question is whether hardness persists under restrictions on the number of agent types, or whether the mass problem becomes tractable for fixed support.

The regime is large housing or dormitory allocation with recurring binary eligibility profiles: many residents share the same acceptance pattern over recurring unit categories, and category supplies scale with the cohort. The reduction has \(|U|+1\) agent types, but each construction can be replicated any number of times without increasing that support. Thus the number of people can greatly exceed the number of types. The model’s type is the complete binary valuation vector; its house category is the vector of values across those types. This is particularly plausible here because the paper itself studies agent types and compresses houses by type.

A second, independently useful anchor is Theorem 4.5, also proved in the paper. It states that with \(k\) agent types and binary utilities, a minimum-total-subsidy envy-free allocation can be found in \(O((k\cdot2^{2k})^{1+o(1)})+O(n+m)\) time. Its algorithm uses the type structure and capacitated matching.

The corresponding question, \(k\)-Type Binary Mass-MinSubsidy, is the optimization problem above with \(|\mathcal A|\leq k\): compute a minimum-cost mass assignment and envy-free subsidy schedule. I expect this to be tractable, in fact fixed-parameter tractable in \(k\) and the input bit length. There are at most \(2^k\) distinct house categories, since each category is determined by its binary value vector across the \(k\) agent types. One can enumerate which type-category pairs carry positive mass. For each support, envy-freeness forces all agents of a type to have the same final utility \(U_a\); their subsidies are then \(U_a-u(a,h)\). The flow constraints, envy inequalities on that support, and total subsidy objective are linear in the mass flows and the \(U_a\). Enumerating supports and solving rational LPs gives a finite \(f(k)\operatorname{poly}(L)\) algorithm, where \(L\) is the encoded input length. Further questions include extending this to general utilities with more types and comparing its parameter dependence with Theorem 4.5.

The lead weakness is the reduction’s dependence on support activation: using any positive mass of a set category triggers subsidies for the entire covered element cohort. That follows from envy constraints in this model, but it would disappear if people could receive lotteries over houses instead of one indivisible house. The model should therefore state the individual assignment rule plainly. The case covers the paper’s binary minimum-subsidy hardness and bounded-type algorithm; it does not attempt to mirror the two-type general-utility result in Theorem 5.5.

The case AGAINST (opponent, writing after the proponent)

I can’t make a convincing case that no worthwhile mirror exists. This paper has exactly the feature that makes a negative case difficult: its computational results already single out repeated utility vectors as structure. The binary eligibility setting has a natural high-multiplicity regime in recurring resident cohorts, and an agent’s identity adds nothing once their valuation vector is fixed. Scale house supplies with the cohort and keep each assignment integral at the person level. That is a coherent population-continuous model, with nonzero per-capita subsidy and meaningful envy constraints.

Theorem 3.5 is a real computational anchor. The proponent’s reduction is not fully established merely by sketching the discrete construction in mass form: it needs to prove that a low-cost mass allocation can be normalized so the intended set-selection structure follows. But that is a proof obligation, not a fundamental obstruction. With category capacities and same-type envy constraints, the proposed support-activation effect looks plausible, and fractional flows need not erase the union cost. Even if the reduction fails, asking whether this mass problem is hard remains well posed.

Theorem 4.5 is also a legitimate anchor. For a fixed support of type–house-category assignments, same-type envy forces a common final utility for each type, and the resulting feasibility and subsidy objective can be expressed linearly in the mass flows. Enumerating supports gives a credible route to an algorithm with a parameter dependence on \(k\). That may make the continuous problem easier than the discrete one, but that is a useful result, not a reason to reject the mirror. The same applies to a better version of Theorem 5.5 using two utility types and scaled supplies.

The strongest negative point is therefore modest: the proposed mirrors still need careful formalization, and the reduction’s mass-normalization step and algorithmic input bounds need proofs. I can’t honestly turn those gaps into evidence that the questions are unimportant. The paper has named computational results, a plausible high-multiplicity regime, no apparent dependence on individual identity, and no continuous computational treatment that already answers them. On the programme’s stated criteria, the negative case is weak.
