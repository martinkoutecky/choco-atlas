The case FOR (proponent)

There is no qualifying named computational result in this paper: it has no numbered theorem, lemma, corollary, or proposition asserting a complexity result. Equations (12)–(13) formulate the joint objective, and Tables 5–8 report experimental accuracy results, including improvements over single-task baselines. Those findings support the method’s usefulness, but they are not complexity anchors. So there are no anchors to restate, and I can’t honestly make the anchor-based case requested.

The strongest positive extension I can see is a population version of the paper’s multi-task label aggregation. Imagine a large crowdsourcing platform with many workers repeatedly handling related categorization, preference, or similarity tasks. Workers fall into a modest number \(\tau\) of recurring cohorts with the same task participation and response-ability profile; each cohort has mass \(\mu_t\), the fraction of the worker population it represents. This is plausible for a platform with many annotators and a much smaller set of qualification or response profiles, though the paper’s own datasets, with 94–189 workers, do not establish that regime.

A precise follow-on question would be Continuous Composite-Task Label Aggregation. Its input is a finite set of tasks \(u\), prompts \(j\), and response labels \(y\); a finite type set \(T\) with rational masses \(\mu_t\); and rational observed label masses \(r_{tujy}\), recording how much of type \(t\) supplied label \(y\) on prompt \(j\) in task \(u\). For each task, let \(W_u\) denote its latent answer or task-model variables, and let \(\theta_{tu}\) denote the ability of type \(t\) on that task. Given the paper’s backbone response probabilities \(p_u(y\mid j;W_u,\theta_{tu})\) and a cross-task ability penalty \(G\), ask for a global minimizer of

\[ -\sum_{t,u,j,y} r_{tujy}\log p_u(y\mid j;W_u,\theta_{tu}) +\lambda\sum_t\mu_t\sum_{u<v}G(\theta_{tu},\theta_{tv}). \]

A solution returns the aggregated task outputs \(W_u\) and ability estimates \(\theta_{tu}\), or an explicitly specified approximation to the optimum. This preserves the paper’s central operation—using shared worker ability across tasks—while replacing sums over individual workers with mass-weighted terms. The authors would likely recognize the connection, although using observable or otherwise specified cohorts is an additional modeling assumption.

I would leave this problem’s complexity unclassified on the evidence in the paper. The paper describes gradient-based optimization, but gives no complexity theorem establishing tractability or hardness for the population version. Its objective couples latent outputs and abilities, so a tractability claim would need more than the empirical results or the stated optimization formulation.

The weakest point is that this mirror is a proposed extension, not one anchored in a named result of the paper. In particular, the paper relies on worker identities to connect abilities across tasks; a population model must preserve that linkage through its type definitions or data. If cohorting loses those correspondences, the mirror changes the authors’ underlying problem.

The case AGAINST (opponent, writing after the proponent)

The proponent raises no named result from the paper, so there is no result-level anchor to defeat. That matters here: the paper gives a model, an optimization objective, and empirical accuracy comparisons, but no theorem about the complexity of a computational problem. Its results therefore do not supply the kind of complexity question this programme is meant to continuize.

The proposed population model is a new problem, not a continuous mirror of a result in the paper. As written, its response masses \(r_{tujy}\) are already indexed by worker type, which assumes the type assignments the paper is trying to infer through worker abilities. If those assignments are known, the model becomes groupwise label aggregation with shared parameters. If they are unknown, they must be estimated jointly with the task outputs and abilities, making this a latent-class crowdsourcing problem that the proposed formulation does not specify. The paper’s sparse annotations and cross-task worker overlap make that distinction central: a type definition that preserves each worker’s task history risks retaining nearly all the individual records; a coarser ability cohort needs assumptions about how assignments and responses behave within it.

There is also a fit problem for ChoCo. The paper studies denoising annotations and estimating rankings or embeddings, not a social-choice rule’s complexity, manipulation, control, or robustness. Pairwise preference labels appear in the data, but the main computation is statistical inference about worker reliability and latent answers. Continuizing annotators could be a worthwhile research direction in crowdsourcing, but that does not make it a mirror of the paper’s computational results for this programme.

The negative case is strongest on those grounds, but it cannot honestly establish the universal claim. A platform with many workers in known, recurring cohorts and a shared task design could support a sensible population model. The paper itself does not establish that such a model would yield a worthwhile complexity question; it also does not rule one out.
