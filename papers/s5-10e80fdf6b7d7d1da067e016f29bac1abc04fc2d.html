Theorem 3 also changes individual deviations into positive-mass deviations, while Theorem 8's coalition count has no canonical continuous counterpart.

Open questions for a prover

  • Whether finite repeated-copy economies yield a canonical limit for the paper's individual-manipulability notion without changing the deviation model.

The case FOR (proponent)

The strongest positive case is a high-multiplicity mirror of the paper’s fair assignment-with-compensations problem. There is one important limitation: the paper contains no numbered theorem asserting \(P\), NP-hardness, W[1]-hardness, or a comparable complexity classification. Its only explicit algorithmic claim is prose after Theorem 8, referring to Klijn’s polynomially bounded algorithm. Thus, under a strict complexity-anchor requirement, this paper has no qualifying complexity theorem. The best available positive case rests on its named exact structural results, especially Theorem 3.

The mirror has finitely many agent types \(T\), finitely many object classes \(J\), a population distribution \(\mu\in\Delta(T)\), and an object-supply distribution \(\sigma\in\Delta(J)\). A type \(t\) is a complete valuation vector \(v_t=(v_{tj})_{j\in J}\), together with all other information relevant to manipulation. The population contains mass \(\mu_t\) of type \(t\), while object class \(j\) has mass \(\sigma_j\). Each unit of mass still receives one indivisible object; only the aggregate assignment is continuous.

An allocation is a matrix \(X=(x_{tj})\), where \(x_{tj}\) is the mass of type \(t\) receiving object class \(j\), with

\[ \sum_j x_{tj}=\mu_t \qquad\text{and}\qquad \sum_t x_{tj}=\sigma_j. \]

Let \(p_j\) be the compensation for object class \(j\). Budget balance becomes the forced per-capita version

\[ \sum_j \sigma_jp_j=0. \]

The allocation is fair if every type receiving \(j\) weakly prefers its bundle to every bundle receiving positive mass:

\[ v_{tj}+p_j\ge v_{tj'}+p_{j'} \]

whenever \(x_{tj}>0\) and \(x_{t'j'}>0\). This is not outcome-space continuization: an individual still gets an integral object. It is the aggregate description of many repeated copies of the original assignment problem.

The natural regime is a large housing, office, or school-assignment market: perhaps \(10^5\) households and \(10\)–\(30\) household valuation types, with many copies of finitely many unit classes. Agents of one type have the same complete valuation vector, admissible reports, and budget conditions. When \(n\mu_t\) and \(n\sigma_j\) are integers, the aggregate instance is exactly realized by a finite repeated-copy economy. Thus this is a genuine high-multiplicity relaxation, not merely a story about fractional outcomes.

Because a single atomless agent cannot change an aggregate outcome, individual manipulability must be replaced by vulnerable mass. For a rule \(\Phi\), let

\[ \operatorname{VM}_{\Phi}(\mu) = \sum_{t:\,\text{some positive-mass coalition containing type }t \text{ can profitably misreport}} \mu_t. \]

This is the measure-theoretic analogue of the paper’s set \(P_\varphi(u)\) of agents who can manipulate. A coalition is a submass \(\lambda\le \mu\) that changes its reported types and receives, under the resulting fair and budget-balanced outcome, strictly higher true utility.

My lead anchor is Theorem 3, proved in this paper. It states:

Let \(\varphi\) be any fair and budget-balanced allocation rule. Then \(\varphi\) is agents-counting-minimally manipulable among all fair and budget-balanced allocation rules if and only if \(\varphi\) is a maximally preferred fair allocation rule.

Here “maximally preferred” means that, at every profile, the rule selects a component of maximum cardinality, chooses an agent in that component, and returns the allocations maximizing that agent’s utility among all fair and budget-balanced allocations. The theorem is proved here; its Appendix proof uses Theorem 9.

The corresponding continuous problem is Mass-Maximal Fair Assignment. An instance consists of rational \(T,J,\mu,\sigma,v\), together with a threshold \(q\). The solver must output a fair, budget-balanced aggregate allocation \((X,p)\), an indifference component \(G\), and a certificate that:

  • \(G\) has maximum population mass among all components;
  • \((X,p)\) maximizes the utility of the agents in \(G\) over all fair and budget-balanced allocations;
  • the resulting vulnerable mass is \(1-\mu(G)\).

The decision version asks whether

\[ 1-\mu(G)\le q. \]

The continuous conjecture mirroring Theorem 3 is that every fair and budget-balanced rule \(\Phi\) satisfies

\[ \operatorname{VM}_{\Phi}(\mu) \ge 1-\mu(G_{\max}), \]

with equality attained by a rule selecting a maximum-mass component. A systematic tie-breaking rule over maximum-mass components turns these local choices into a global allocation rule, just as the paper permits arbitrary systematic selections of \(\kappa\).

This is plausibly Class A. The quotient indifference structure has finite support, with at most \(\tau|J|\) type–object cells. Feasibility is a transportation problem, fairness and budget balance are linear conditions, and the preferred allocation can be characterized through assignment-market prices and indifference links. The paper itself says that the corresponding finite-agent computation can be performed using Klijn’s polynomially bounded algorithm; that algorithmic fact is cited from elsewhere, not established as a numbered complexity theorem here. The continuous question is therefore a natural test of whether that finite algorithm survives compression from named agents to type masses.

A second, narrower anchor is Theorem 8, also proved here. For \(k\in N\), if \(k\) belongs to component \(S\), then the agent-\(k\)-preferred rule \(\psi_k\) is manipulable by exactly

\[ |N|-|S| \]

agents and exactly

\[ 2^{|N|-|S|}-1 \]

coalitions. It also follows that \(\psi_k\) is manipulable by fewer than \(50\%\) of all nonempty coalitions at every profile.

Its continuous counterpart is Tagged-Type Manipulability Mass. Given \(T,J,\mu,\sigma,v\) and a distinguished type \(t^\star\), compute a fair and budget-balanced allocation maximizing \(t^\star\)’s utility, find the indifference component \(S_{t^\star}\) containing that type, and return

\[ \operatorname{VM}_{\psi_{t^\star}}(\mu) = 1-\mu(S_{t^\star}). \]

The solver should also determine the coalition structure: no profitable positive-mass coalition may intersect \(S_{t^\star}\), while every positive-mass coalition supported in the complementary population mass should be recognized as manipulable, subject to the chosen aggregate reporting model.

The literal coalition count \(2^{|N|-|S|}-1\) cannot survive atomlessness: there are typically continuum-many measurable subcoalitions, so cardinality is no longer informative. The right continuous question is therefore the mass of the vulnerable population and the measurable support of profitable coalitions. That is a principled modification forced by the population continuum, not a change to divisible individual bundles. This problem also looks Class A for finite \(T\) and \(J\), using the finite indifference graph and the preferred-assignment computation.

The authors should recognize both mirrors as their problem. The primitives are unchanged: indivisible objects, quasi-linear utilities, fairness as envy-freeness, budget balance, allocation correspondences, and strategic misreports. The only substantive change is replacing a large repeated population and repeated object supply by their empirical distributions. The paper’s continuum of fair allocations is not itself a collision: it continuizes the outcome set while leaving the society finite. The proposed mirror continuizes the society, which is exactly the programme’s target.

The weakest point is manipulability. In the atomless model, an individual deviation has zero effect, so the paper’s exact notion of “the number of agents who can manipulate” must become vulnerable population mass or positive-mass coalition manipulability. The maximum cardinality of a component must likewise become its population measure. An opposing reader can reasonably say that this changes the strategic question. My response is that the change is unavoidable and transparent: all core economic structure remains intact, and the replacement is precisely the high-multiplicity analogue of counting agents. If that reinterpretation is rejected, the paper still supplies a credible continuous fair-assignment mirror, but not a fully literal continuization of Theorem 8.

The case AGAINST (opponent, writing after the proponent)

The strongest objection is prior to either mirror: this paper has no named computational result. Theorems 1, 3, and 8 are structural characterizations of allocation rules and manipulation sets, not complexity theorems. They specify no encoded input, decision problem, approximation target, or algorithmic classification. The remark invoking Klijn’s polynomially bounded algorithm is an imported computational aside, not a result of this paper. Thus “Mass-Maximal Fair Assignment” is a new problem invented from the paper’s axioms, not a continuous version of one of its computational problems. Under ChoCo’s strict anchor requirement, that is decisive.

Theorem 3 is the better of the two proposed anchors, but it still does not survive as stated. Its objects are named agents, named objects, unilateral deviations, and allocation rules defined over the entire unrestricted preference domain. The component \(G\) is a set of named agents, and \(\kappa\) selects a named agent. Replacing \(|G|\) by \(\mu(G)\) requires a new measurable component notion, a rule defined on distributions, and a new treatment of deviations.

There is a genuine high-multiplicity assignment story here—large housing or office markets with repeated valuation and unit types—so the objection cannot be that mass is intrinsically unnatural. But the strategic part does not transfer cleanly. With a finite type set, an individual misreport generally creates a new type outside the support. Restricting reports to the existing finite types changes the paper’s preference domain; allowing arbitrary reports produces an infinite type space and a new mechanism-design problem. Declaring that an entire type mass deviates turns an individual manipulation problem into a bloc-deviation problem.

The strongest repair would replicate every agent and object \(n\) times and normalize the finite theorem. That preserves the paper’s semantics, but then the proposed limit is merely a replication dictionary for an axiomatic theorem, not a computational result from the paper. Conversely, the aggregate transportation formulation imposes anonymous object classes and type-level deviations, so it is a sensible new assignment-market model but no longer a faithful mirror of Theorem 3.

Theorem 8 has a more fundamental failure. Its count \(2^{|N|-|S|}-1\) depends on every distinct nonempty subset of named agents being a separate coalition. An atomless society has no canonical counting or uniform measure on measurable coalitions. The proposed

\[ \operatorname{VM}_{\psi_{t^\star}}(\mu)=1-\mu(S_{t^\star}) \]

is not the continuous counterpart of that count. It declares an entire type vulnerable whenever some positive submass of that type belongs to a profitable coalition, even if the manipulable submass can be arbitrarily small. A finite coalition count has been replaced by a new existential type statistic.

One could instead study normalized individual manipulators in finite replicas, or normalize coalition counts through

\[ \frac{1}{n}\log\!\left(1+2^{|N|-|S|}-1\right), \]

which converges to \((1-\mu(S))\log 2\). But these are additional modelling choices. Literal unilateral manipulation vanishes in the atomless limit because one agent does not change \(\mu\); positive-mass manipulation restores nontriviality only by changing the strategic question.

So the negative case is strong against these anchors as mirrors of this particular paper: there is no computational theorem to continuize, and its central manipulation statistics are identity- and coalition-sensitive in ways that atomlessness does not canonically preserve. It is not, however, an honest universal proof that no worthwhile mirror exists. The high-multiplicity assignment setting is genuinely plausible; it could support a new Class A study. The defensible conclusion is therefore that this paper is a poor ChoCo anchor, not that continuous fair assignment is intrinsically uninteresting.
