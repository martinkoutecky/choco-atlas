The continuous mirror question

Input: a finite set of types \(T\), positive rational masses \(\mu_t\) with \(\sum_{t\in T}\mu_t=1\), a fixed initial bundle \(B_t\) and additive binary valuation \(u_t\) for each type, and two indivisible added item types \(r,q\) with positive finite rational supplies \(S_r,S_q\) per unit of population. Let \(x_{t,z}\geq 0\) be the mass of type \(t\) receiving the integral bundle \(z=(z_r,z_q)\in\mathbb{Z}_{\geq 0}^2\), with \(\sum_z x_{t,z}=\mu_t\) and \(\sum_{t,z}x_{t,z}z_j\leq S_j\) for \(j\in\{r,q\}\). Decide whether such an assignment exists in which, for every \(t,t'\) and every \(z,z'\) with \(x_{t,z},x_{t',z'}>0\), \(u_t(B_t)+u_t(r)z_r+u_t(q)z_q\geq u_t(B_{t'})+u_t(r)z'_r+u_t(q)z'_q\).

The model it lives in

Use the paper’s vertex, edge, and distinguished roles as types, each with positive rational mass. Give every member of a vertex type an identical copy of that type’s initial package, preserving the paper’s approval pattern; do the same for the other roles. Scale the two supplies per capita and assign mass to bundles in \(\mathbb{Z}_{\geq 0}^2\). The envy and supply inequalities in the clique reduction continue to force an \(\ell\)-clique.

The case FOR (proponent)

The strongest positive case is the paper’s Theorem 5, proved here. It states that bounded-supply EEAG is NP-complete even with exactly two additional item types, both having positive finite supply; binary additive valuations for all goods; and no separate budget bound. In the hardness construction, the approvers of one additional type are a subset of the approvers of the other, and all numerical quantities are polynomially bounded. This is the paper’s two-type hardness result, not a result it merely cites.

A concrete mirror is Mass-EEAG(2). Its instance has a finite set \(T\) of agent types, each with rational mass \(\mu_t>0\), where \(\sum_{t\in T}\mu_t=1\). A type records an agent’s additive binary valuation and fixed initial bundle \(B_t\); write \(U_{tt'}=u_t(B_{t'})\) for how type \(t\) values type \(t'\)’s initial bundle. There are two added indivisible item types, \(r\) and \(q\), with positive finite supplies \(S_r,S_q\) per unit of population.

The decision question is whether there is an envy-free extension. A solution assigns mass \(x_{t,z}\geq 0\) of type \(t\) to each integral added bundle \(z=(z_r,z_q)\in\mathbb Z_{\geq0}^2\), with
\[ \sum_z x_{t,z}=\mu_t,\qquad \sum_{t,z}x_{t,z}z_j\leq S_j\quad(j\in\{r,q\}). \]
For every two bundles with positive assigned mass, envy-freeness requires
\[ U_{tt}+a_t\cdot z\ \geq\ U_{tt'}+a_t\cdot z', \]
where \(a_t=(u_t(r),u_t(q))\). Thus each person still receives an integral bundle; only the mass of people assigned to each bundle can be fractional. The objective is feasibility, as in EEAG: find an envy-resolving extension under the supply limits, with no added budget constraint. With nonnegative binary values, wasteful items can be removed, and envy-freeness forces people of one type to have the same utility from their added bundle. Finite per-capita supply therefore bounds the useful bundle sizes, so the model has a finite set of bundle patterns for each input.

A fitting regime is a large public benefits or housing programme where existing packages cannot be reassigned, but two kinds of scarce indivisible supplements can be issued. Many recipients share the same valuation and initial-package profile, including how they value other profiles’ packages. The supplies scale with the population. A cohort might represent \(G\) nearly identical recipients; with \(\tau\) profiles the population can be \(N=G\tau\), so \(N\) can greatly exceed the support size. This is population continuity: no recipient receives a fraction of a good.

I expect hardness to transfer, and the paper’s reduction gives a reason beyond analogy. Start from its clique construction, but give every vertex-agent class, edge-agent class, and the distinguished class mass \(1/\tau\), where \(\tau=|V|+|E|+1\). Set the per-capita supplies to \((M+\ell)/\tau\) for \(r\) and \((|E|-M)/\tau\) for \(q\), with \(M=\binom{\ell}{2}\); use the paper’s padding to keep both supplies positive. Each edge-class member must receive at least one approved added good to avoid envying the distinguished class. Let \(\alpha_e\in[0,1]\) be the fraction of edge class \(e\) receiving \(r\). The \(q\)-supply bound forces \(\sum_e\alpha_e\geq M\). If any positive mass of an edge class receives \(r\), both endpoint vertex classes must receive \(r\) throughout: otherwise a vertex agent envies that edge agent’s bundle. If \(W\) is the set of vertices activated this way, the \(r\)-supply bound gives \(\sum_e\alpha_e+|W|\leq M+\ell\), hence \(|W|\leq\ell\). Since only edges within \(W\) can contribute to \(\sum_e\alpha_e\), and each \(\alpha_e\leq1\), reaching \(M\) forces \(W\) to be an \(\ell\)-clique. Fractional splitting of cohorts does not break the counting argument. This establishes NP-hardness for the stated mass problem, so the expected classification is Class B.

The scope is the paper’s exact-two-added-types hardness branch, not all its EEAG results. The next questions are whether this mass model has a sharp one-type/two-type boundary, and how complexity depends on the support size \(\tau\) when the number of added types is fixed.

The soft spot is that the reduction needs \(\tau\) to grow with the graph: its profiles encode vertices and edges. It does not show hardness at a fixed small support size, and graph-indexed eligibility cohorts are a less ordinary scenario than a handful of broad population categories. The claim is narrower: large repeated cohorts can still support the paper’s two-type hardness, even when their allocations may split across integral bundles.

The case AGAINST (opponent, writing after the proponent)

The strongest negative I can make is about the reduction’s fit with a repeated-type population. In Theorem 5, each vertex agent’s initial good is approved only by that agent. If many people are grouped into one vertex type, that private endowment makes them distinguishable: one member values their own bundle at one, but values another member’s at zero. The literal clique construction therefore does not directly lift to a homogeneous cohort.

That objection does not survive the better mirror. Give every member of vertex type \(v\) a copy of the same initial-good type \(p_v\), valued at one by all members of that type. Keep other vertex types’ goods unapproved, and retain the paper’s edge and distinguished-agent valuation pattern. The initial allocation remains envy-free for vertex agents: each values every same-type package at one. The clique argument still works. If any positive mass of an edge type receives \(r\), both endpoint types must receive \(r\) throughout; the \(q\)-supply forces at least \(M=\binom{\ell}{2}\) edge mass onto \(r\); and the \(r\)-supply then leaves room for at most \(\ell\) endpoint types. Those edges can fit only if the endpoints form an \(\ell\)-clique. Splitting cohorts fractionally does not avoid these constraints.

The reduction’s support grows with the graph, so it does not establish hardness at fixed support size. But support size is an explicit parameter of the continuous model, and graph-indexed cohorts with large multiplicities are a coherent regime. That limitation cannot defeat the mirror on the grounds given.

So I cannot honestly defeat the Theorem 5 anchor. Its identity-sensitive endowments are repairable, and the repaired construction still gives a well-posed computational question about a continuous population. The negative case is weak; under the stated gate, this anchor survives.
