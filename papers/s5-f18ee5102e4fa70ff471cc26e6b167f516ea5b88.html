The continuous mirror question

Given rational applicant-type masses \(\mu_t\) summing to \(1\), rational per-capita supplies \(q_s\) of job types \(s\), their interval and processing data, and each type's utilities \(u_t(s)\), define \(M_t\) as the largest \(z\) for which a unit mass of type-\(t\) recipients can be assigned feasible integral bundles with utility at least \(z\), using at most \(q_s\) units of each job type in aggregate. Can one find, in time polynomial in the type supports, input bit length \(L\), and \(1/\epsilon\), finite-support assignment masses \(x_{t,B}\) such that \(\sum_B x_{t,B}=\mu_t\), \(\sum_{t,B} n_s(B)x_{t,B}\le q_s\) for every \(s\), and every positive-mass bundle satisfies \(u_t(B)\ge 0.24(1-\epsilon)M_t\)?

The model it lives in

A society represented by applicant-type masses \(\mu_t\), with repeated interval-job types supplied at rates \(q_s\) per unit population. Assignment variables \(x_{t,B}\) allocate mass of each type to individually feasible integral bundles \(B\), subject to type-mass and job-supply constraints; each recipient's bundle must meet a constant fraction of that type's continuous MMS benchmark \(M_t\).

What the mirror covers

The mirror covers the approximate MMS guarantee of Theorem 2 for high-multiplicity applicant and job types. It leaves the paper's EF1, PO, and IO results and its experiments aside.

Open questions for a prover

  • Can the \(0.24(1-\epsilon)\) guarantee be computed in time polynomial in type supports and binary input length, despite the bundle-pricing problem?
  • How closely does \(M_t\) track finite high-multiplicity MMS under rational scaling of masses and supplies?

The case FOR (proponent)

My lead is Theorem 2, proved in this paper. For any \(0<\epsilon<1\), it proves that, given a \(\beta\)-approximation algorithm for interval-scheduling utilities, an arbitrary FISP instance has a \(\frac{\beta}{\beta+2}(1-\epsilon)\)-MMS schedule that can be found in time polynomial in \(|J|\), \(|A|\), and \(1/\epsilon\). Instantiating the theorem with the cited \(0.64\)-approximation for those utilities gives a \(0.24(1-\epsilon)\)-MMS algorithm. This is an algorithmic anchor; the paper’s numbered results do not give a comparable hardness theorem for its central fair-allocation problem.

A natural high-multiplicity regime is a large hiring or student-work platform: there are many applicants, but relatively few complete preference types, and the same kinds of shifts recur in quantities proportional to the applicant population. A type records an applicant’s full utility vector over shift types. A shift type records its release time, deadline, processing time, and the number \(q_s\) of available copies per unit mass of applicants. Let applicant types have rational masses \(\mu_t\), with \(\sum_t\mu_t=1\). The regime is credible when the number of applicants is much larger than the number of applicant and shift types. Each person still receives a finite, integral set of jobs that can be scheduled without overlap; only the aggregate assignment is fractional. Scaling a workforce of size \(N\) gives approximately \(N\mu_t\) applicants of type \(t\) and \(Nq_s\) copies of shift type \(s\).

I would ask about Continuum-MMS-FISP. For each type \(t\), define its continuous MMS value \(M_t\) as the largest \(z\) for which a unit mass of hypothetical recipients, all evaluated using \(t\)’s utilities, can each receive a feasible integral bundle worth at least \(z\), subject to the per-capita supplies \(q_s\). This is the continuous counterpart of partitioning the jobs into one bundle per agent and evaluating every bundle with that agent’s utility.

The input is the rational type masses, rational per-capita job supplies, interval and processing data for each job type, and the utility of each applicant type for each job type. A solution is a finite-support set of masses \(x_{t,B}\): \(x_{t,B}\) is the mass of type-\(t\) applicants assigned the integral bundle \(B\). It must satisfy \(\sum_B x_{t,B}=\mu_t\), and for every job type \(s\), \(\sum_{t,B} n_s(B)x_{t,B}\le q_s\), where \(n_s(B)\) is the number of copies of \(s\) in \(B\). Every positive-mass bundle must be feasible for one person and worth at least \(0.24(1-\epsilon)M_t\) to its recipients. Thus the fairness promise applies bundle by bundle, not just to average utility. The computational question is whether such an assignment can be found in time polynomial in the type supports, the binary input length \(L\), and \(1/\epsilon\); one can also ask for the best achievable \(\alpha\).

I expect the fixed-factor version to be Class A: the mass assignment has a configuration-LP shape, and the paper’s bag-filling argument and approximation for interval-scheduling utilities offer a plausible route to the same constant guarantee. The pricing problem over feasible bundles may still be difficult, especially with flexible jobs, so the continuum algorithm and its running time in the succinct input size need to be proved; they do not follow automatically from Theorem 2.

The weakest point is the benchmark. The paper’s MMS partitions a finite set of jobs into a finite number of bundles; \(M_t\) instead divides per-capita supplies among a continuum of recipients. That is a new definition, and its relation to finite high-multiplicity MMS instances needs to be established rather than assumed. But the underlying question remains close to the authors’ problem: applicants receive individually feasible job bundles, job supply scales with the population, and the guarantee is per recipient. This mirror covers the paper’s MMS results only; it does not continuize its EF1, PO, or IO results.

The case AGAINST (opponent, writing after the proponent)

The strongest objection is that Theorem 2 does not establish an algorithm for the proposed compressed input. Its running time is polynomial in the *explicit* numbers of jobs and agents, and it assumes an approximation algorithm for interval-scheduling utilities. The bag-filling proof processes individual jobs and agents. Replacing repeated jobs and applicants by binary-encoded supplies and type masses changes the computational question: the MMS benchmarks and the fair assignment now range over feasible bundles and may require solving new pricing problems. Flexible single-machine scheduling is already NP-hard in the paper, so the theorem offers no direct reason to expect an efficient algorithm polynomial in type support and bit length.

That objection blocks the proposed Class A inference, but it does not defeat the mirror. There is a credible regime of recurring shifts and applicants with a small set of complete utility profiles. In that regime, mass assignments of integral, individually feasible bundles preserve the paper’s central fairness idea, while rational supplies and masses make the high-multiplicity connection precise. The new compressed complexity question could be exactly the kind of question the programme is meant to ask. The required type assumptions may narrow the applications, but the programme treats high multiplicity as an instance regime, so narrowness alone is not a decisive objection.

I therefore cannot make a strong case that this anchor has no worthwhile continuous mirror in any scenario. The honest negative case is weaker: Theorem 2 is a motivation for studying the mirror, not evidence that its guarantee or running time carries over. The mirror’s benchmark and algorithms need independent justification. That is a substantial research burden, but it does not make the question unworthy.
