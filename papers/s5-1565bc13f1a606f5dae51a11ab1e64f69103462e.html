What the mirror covers

The case FOR (proponent)

I can make a plausible continuous-population research question from this paper, but it would not have a qualifying anchor under your rule. The numbered results are asymptotic welfare statements, not computational classifications. The closest is Proposition 3, proved here: for uniform utilities in balanced markets, the expected aggregate-efficiency loss \(L_n^A\) under aligned preferences satisfies \(\log n-6\le L_n^A\le2\log n\); under fully idiosyncratic preferences, \(1\le\liminf_{n\to\infty}(\log n)^2L_n^I/(nL_n^A)\le2\). That is a substantive result about the gap between optimal and worst stable welfare, but it says nothing about whether a problem is in P, NP-hard, or otherwise computationally classified. So it cannot honestly serve as the required anchor.

A plausible *follow-on* question is Minimum-Welfare Stable Mass Matching. Let \(F\) and \(W\) be finite sets of firm and worker types, with rational masses \(p_f,q_w\) summing to \(1\) on each side. A type specifies a strict ranking of every opposite-side type and cardinal match utilities \(u_f(w)\), \(v_w(f)\). Find a mass allocation \(x_{fw}\ge0\) that matches all mass, minimizes \(\sum_{f,w}x_{fw}(u_f(w)+v_w(f))\), and is stable. Stability means that for every pair \((f,w)\), at least one of
\[ p_f-\sum_{w'\succeq_f w}x_{fw'}=0 \quad\text{or}\quad q_w-\sum_{f'\succeq_w f}x_{f'w}=0 \]
holds. The solution is the stable mass allocation of minimum welfare; its welfare can be compared with the unrestricted maximum-weight mass matching. This asks about the paper’s stability-versus-utilitarian-efficiency question while making the population itself a distribution over complete agent types.

A credible regime would be a large centralized hiring or residency market with many applicants and positions sharing a relatively small set of standardized profiles. The type masses are population fractions, and \(x_{fw}\) allows the mass of one type to be split across partner types while each individual still receives one partner. The problem would cover the stable-versus-optimal welfare wedge behind Proposition 3, not the paper’s random-market convergence rates. Its complexity in the number of types and the bit length of the masses is a new question; I would not assign it a class on the strength of this paper.

The main weakness is that the paper’s idiosyncratic utility matrices generally make agents’ complete types distinct. Compressing them into a small number of types changes the model that drives several of its results. Thus the paper gives a natural *subject* for a continuous-population computational study, but no named computational result to anchor that study as a mirror of this paper.

The case AGAINST (opponent, writing after the proponent)

Proposition 3 is not a computational result: it bounds expected welfare loss in random markets as \(n\) grows. It gives no algorithmic problem or complexity claim to continuize. The proposed Minimum-Welfare Stable Mass Matching turns the paper’s welfare criterion into a new input-output task: it minimizes welfare over stable allocations in a fixed type distribution. That is a plausible adjacent project, but it replaces the paper’s expected loss over random, realized payoff matrices with an optimization problem on a deterministic mass market.

The type issue makes the proposed link weaker still for the paper’s idiosyncratic cases. An agent’s complete type must include its preferences and utilities across potential partners. With continuous, independently drawn pair utilities, those full types are almost surely distinct, so the support grows with the number of agents and there is no high-multiplicity compression. Grouping agents into a fixed set of profile types instead makes utility depend on type pairs and discards the paper’s pair-specific shocks. Either choice changes the input regime behind Proposition 3.

The strongest alternative is the paper’s sub-modular assortative example in Section 5.2. It has a natural population model: firm and worker abilities range over \([0,1]\), each side has a uniform mass distribution, and match utility is \(\phi(x,y)=(x+y)^\alpha\). But the paper studies welfare under stable and efficient assignments there; it does not pose a computational problem. An algorithmic question over finite type distributions and general utility functions would again be a new research question, not a mirror of a computational result in this paper.

So the negative case is strong under ChoCo’s stated gate: none of the paper’s results supplies a computational anchor. It is weaker as a literal claim that no worthwhile continuous mirror exists in any broader sense. The sub-modular example is a convincing continuous-population analogue of the paper’s welfare question. If “mirror” includes such non-computational reformulations, I cannot honestly rule it out; the case against is that it falls outside this programme’s computational remit.
