What the mirror covers

The proposed extension uses only Theorem 1’s approximate-SPNE existence result; it leaves Theorem 2’s tie-breaking result and Theorem 3’s envy-free implementation result without mirrors.

The case FOR (proponent)

The strongest positive case is an approximate-equilibrium question for large, homogeneous cohorts in strategic fair division. It is a narrow case, and it depends on treating a cohort as a strategic bloc.

The nearest named anchor is Theorem 1, proved in this paper: for any \(n\)-agent GCC protocol \(P\) with a bounded number of steps, any valuation functions \(V_1,\ldots,V_n\), and any \(\varepsilon>0\), the induced game has an \(\varepsilon\)-SPNE. The proof constructs one by discretizing the cake and using backward induction. The theorem does not give a running-time bound, so it is an equilibrium-existence result rather than a result that places a problem in P or another complexity class. Theorem 2 and Theorem 3 likewise concern equilibrium existence or implementation, not computational complexity.

A candidate mirror, if existence results count as anchors here, is Finite-Type Mass GCC \(\varepsilon\)-SPNE. An instance has a finite set \(T\) of preference types, rational masses \(\mu_t>0\) summing to \(1\), and a positive normalized valuation density \(v_t\) for each type. To make the instance finitely represented, densities can be rational piecewise-linear functions. It also has a bounded-depth GCC tree whose moving players are the type cohorts: all mass of type \(t\) shares one strategy and acts as one bloc whenever the tree assigns it a move. Per-capita cake supply scales with the cohort mass, so the cohort’s chosen allocation describes what each member receives. A solution is a strategy for every cohort at every history such that, in every subgame, no cohort can improve its per-capita value by more than \(\varepsilon\) through a unilateral change of strategy. The question is whether every such instance has an \(\varepsilon\)-SPNE, and how to construct one.

The natural scenario is a large allocation process where many households share the same complete valuation profile and a representative for each preference cohort acts for that cohort. The population may be large while \(|T|\) remains small. The expected answer for this *bloc model* is approximate-equilibrium existence, following the discretization idea in Theorem 1. It does not establish polynomial-time computation: the theorem gives no runtime, and that question would need a finite encoding and a separate analysis. Further questions include whether independent agents in a growing population have equilibria converging to this cohort model, and whether any such algorithm can be bounded in \(|T|\), input bit length, and protocol size.

The soft spot is also the central one: cohorts acting as unified players changes the paper’s individual-agent game. If each resident acts independently, role in the protocol affects strategy, and a valuation type alone may not summarize the player. The type masses may then fail to compress the strategic problem. I would present this as a plausible extension for representative cohorts, not as evidence that Theorem 1 already has a continuous-population counterpart. The cake’s divisibility supplies no positive case by itself; the population-mass interpretation is doing all the work.

The case AGAINST (opponent, writing after the proponent)

The strongest objection is that Theorem 1 is not a computational-complexity result. It proves that a finite-agent GCC game has an \(\varepsilon\)-SPNE. Its discretization and backward-induction proof are constructive, but the theorem gives no running-time bound or finite input model: the valuations may be arbitrary continuous functions. So it provides no complexity result for the programme to mirror.

The proposed type-bloc version does not fix that gap. If each type cohort acts as one strategic player, the nearest faithful model is the original theorem with \(n=\tau\). The theorem already guarantees an \(\varepsilon\)-SPNE for that game. With per-capita utilities, multiplying a cohort’s utility by its mass \(\mu_t\) does not change its best responses; if masses instead alter what allocations are feasible, that is an added game model, not a consequence of Theorem 1. A new question about the runtime of finding an equilibrium might be worth studying, but its substance would be the complexity of a finite-player game with continuous actions, not the computational effect of a continuous population.

If cohort members act independently, the strategic structure breaks the other way. GCC assigns moves to particular agents in a finite sequence. In an atomless population, an individual has zero mass, so a unilateral deviation cannot change an aggregate allocation; retaining pivotal individual movers makes the population distribution irrelevant. Giving an entire cohort a shared move restores influence only by adding a coordination or representation institution. A model where a continuum of members submits actions and mass distributions determine outcomes would need new protocol semantics, so it would no longer be a mirror of this theorem.

That leaves the proponent’s mirror either already covered at the level of equilibrium existence, or dependent on a new institution or a new game model. I would reject it as an anchor for this programme. The case is not airtight: a specific representative-based allocation institution could make a finite-type mass game sensible, and its equilibrium-computation complexity could be interesting. But that would need its own motivation and formalization; this paper does not supply the computational result that makes the proposed mirror compelling.
