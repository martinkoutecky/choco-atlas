The continuous mirror question

Given finite \(T\), rational masses μ_t≥0 summing to \(1\), and a symmetric rational affinity matrix \(a_{ts}\), let an atomless population have type-\(t\) mass μ_t. Does there exist a measurable partition ℱ such that no positive-mass measurable set \(X\) has almost every member strictly prefer forming \(X\), with utility \(u_t(X)=\sum_{s\in T}a_{ts}q_s(X)\), to their current coalition in ℱ?

The model it lives in

A finite-type atomless ASHG: input μ and symmetric affinities \(a\); agents of each type may be distributed across coalitions with different type-mass profiles. Seek any measurable partition with no positive-mass blocking coalition. The nonatomic deviation rule changes which coalitions count, so the discrete theorem’s reduction does not transfer verbatim.

The objection that survived

The model permits types to be split across arbitrary coalition-mass profiles, and the case gives no finite support bound or equivalent effective representation for such partitions.

fatal: False

What the mirror covers

The mirror covers only the core-existence result of Theorem 4.3; it leaves the paper’s CSV results, treewidth algorithms and lower bounds, and \(k\)-core results aside.

Open questions for a prover

  • Can core existence be characterized using a finite description or an equivalent measure over coalition-mass profiles?
  • What is the decision complexity in τ=|T| and the input bit length?
  • Do natural restrictions on the affinity matrix yield tractable cases?

The case FOR (proponent)

The strongest anchor is Theorem 4.3: the paper proves that deciding whether a symmetric ASHG has a core-stable partition is \(\Sigma_2^p\)-complete even when the graph has bounded vertex-cover number. Its reduction uses vertex cover \(12\), a constant independent of the instance size. The theorem covers existence of a partition that no coalition can block by making every member strictly better off; it is proved here. [Theorem 4.3 in the paper](https://arxiv.org/abs/2402.10815)

A direct mirror is Continuous ASHG Core Existence. An instance is a finite set \(T\) of types, rational masses \(\mu_t\geq 0\) summing to \(1\), and a symmetric rational affinity matrix \(a_{ts}\). A type completely specifies an agent’s pairwise utility toward every type: two agents of type \(t\) have the same \(a_{ts}\) for every \(s\). Represent the population by an atomless measure space \(\Omega\), with type-\(t\) population \(\Omega_t\) of mass \(\mu_t\). A solution is a measurable partition \(\mathcal P\) of \(\Omega\) into coalitions. If coalition \(S\) contains type-\(s\) mass \(q_s(S)\), a type-\(t\) member of \(S\) gets utility
\[ u_t(S)=\sum_{s\in T}a_{ts}q_s(S). \]
The question is whether some \(\mathcal P\) has no positive-mass measurable set \(X\) whose members almost everywhere strictly prefer forming \(X\) to their current coalitions. There is no welfare objective: the decision is whether such a partition exists.

This has a plausible high-multiplicity setting in large cooperative workforces or member organizations where coalition gains depend on a small number of shared roles or skill classes. Millions of members might fall into a few dozen types, with type meaning the full vector of affinities toward those classes. The mass formulation also has a clear discrete bridge: for \(n\) agents with \(n_t\) agents of each type, set \(\mu_t=n_t/n\). Dividing every finite utility by \(n\) preserves all strict comparisons, and the normalized utility approaches the mass-based expression as the population grows.

I would provisionally expect this mirror to be Class C, hard for continuum-specific reasons, but that is a research hypothesis rather than a consequence of Theorem 4.3. The paper’s reduction encodes an \(\exists\forall\)-Partition instance using item agents with different weights. In the mirror, those agents may split into fractional masses, so the reduction does not transfer directly. The challenge that remains is the search over partitions together with universal quantification over mass deviations. Useful next questions are whether stable partitions have a finite description by coalition-mass profiles, what complexity is possible in \(\tau=|T|\) and the input bit length, and whether special affinity structures yield tractable cases.

This scope is just the core-existence result of Theorem 4.3; I would not use it to claim mirrors for the paper’s verification or \(k\)-core results. The main weakness is that atomless mass-blocking changes the available deviations: a group can split fractionally, and a zero-mass individual cannot block. That is a substantive co-modification of the model. The positive case is that it preserves the paper’s central question—whether a population can be partitioned into coalitions immune to profitable group departure—while making shared types and population mass explicit.

The case AGAINST (opponent, writing after the proponent)

Theorem 4.3 is a real computational anchor: the paper proves \(\Sigma_2^p\)-completeness for core existence, even at vertex-cover number \(12\). The strongest case against its mirror is that this small vertex cover does not signal a high-multiplicity population. In the reduction, the item agents carry the individual values \(a_i\) and \(b_i\); preserving their full interaction descriptions generally requires a separate type for each item. The paper’s own construction encodes an \(\exists\forall\)-Partition instance this way. ([Paper](https://arxiv.org/abs/2402.10815))

That leaves two choices for the proposed mirror. Keep those distinctions and the support size \(\tau\) grows with the number of item agents; atomless splitting then adds fractional copies and deviations the finite instance does not have. Merge agents by role or affinity instead, and the model becomes a dense, weighted block interaction game: agents interact according to type masses, rather than through the sparse, individually wired graph structure studied throughout the paper. That may be a sensible model in its own right, but the reduction and the paper’s structural results give little reason to think it is the high-multiplicity regime of the instances driving this theorem.

There is also a serious representation gap. A measurable partition can split each type across many coalition compositions, giving members of the same type different current utilities. One mass vector per type, or one coalition per type, cannot describe that state. More generally, the partition is a measure over coalition-mass profiles, and blocking depends on how much of each type currently receives utility below the payoff from a proposed profile. A finite support bound or an exact finite formulation would be needed before the proposed question has the input-size complexity landscape ChoCo seeks. Restricting to a finite set of profiles or rounding masses may supply one, but that is an additional modelling choice whose effect on core existence must be established.

This does not defeat every version. A workforce with repeated roles and type-based affinities is plausible, and the resulting core-existence question is mathematically coherent. Nor is the objection that the answer might differ from the finite theorem, or that continuous core analysis already settles the computational question. The honest negative case is narrower: the proponent’s mirror moves from graph-based ASHGs to atomless block games without yet supplying the finite representation that makes it a computational mirror. That weakens the anchor, but it does not establish that no worthwhile mirror exists.
