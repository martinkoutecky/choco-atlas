Why no mirror

But the paper already models homogeneous OD groups through aggregate demands and real-valued flows, then computes stable outcomes over those aggregates. Expressing those demands as rational type masses and scaling capacities and costs per capita re-parameterizes that model; it does not create a distinct population-continuization bridge.

What the mirror covers

The proposed mirror covers Proposition 2’s exact stability-constraint generation for the stable-outcome stage; it does not classify the fixed-charge assignment stage or add complexity guarantees for the paper’s other results.

The case FOR (proponent)

The paper contains no named result classifying a problem as polynomial-time, NP-hard, FPT, or otherwise. My strongest computational anchor is Proposition 2, proved in this paper. It says that, for each optimal path, Algorithm 1 generates stability constraints equivalent to the constraints obtained by comparing every feasible alternative path against every optimal path. The algorithm uses shortest-path calculations and operator subcoalitions drawn from the operators on optimal paths, avoiding explicit enumeration of all feasible paths. This is an exactness result for a computational method, not a complexity bound.

The plausible high-multiplicity setting is a large city platform handling, say, hundreds of thousands of daily trips over a fixed regional network. A user type is an origin–destination pair together with the trip utility attributes the model uses. Users of the same type have the same utility and face the same network costs; route choice remains a decision. The population is a rational distribution \(\alpha\) over \(\tau\) supported OD types, with \(\sum_s \alpha_s=1\). The paper’s 552-OD Sioux Falls example gives a concrete scale for \(\tau\): the number of trips can be enormous compared with the number of distinct OD types. If users with the same OD pair have different relevant utility attributes, those groups become separate types.

My lead mirror is the Continuous OD-Core Certificate problem. An instance gives a directed network \(G=(N,A)\), a finite set of operators owning disjoint link sets, rational type masses \(\alpha_s\), and rational per-capita link disutilities, capacities, and operating costs. The scalable-service regime assumes link capacities and operating costs scale with population mass; the operator’s link-activation choice remains binary. The matching variables are link activations \(y_a\in\{0,1\}\) and flows \(x_a^s\geq 0\), with flow balance for each OD type and shared capacity constraints \(\sum_s x_a^s\leq \bar w_a y_a\). The objective is total travel disutility plus link operating cost.

Given an optimal assignment, its capacity dual values, and a path-flow decomposition, the task is to return an exact finite linear description of the stable-outcome set. Its variables are per-trip user payoffs \(u_s\) and path–operator prices \(p_{rf}\). Feasibility requires that payoffs and prices divide the trip surplus on assigned paths, that payoffs and prices are nonnegative, and that each operator’s flow-weighted revenue covers its per-capita operating costs. Stability requires that no user and alternative route, together with the operators shared with an assigned route, can obtain a better payoff after accounting for travel disutility, capacity scarcity, and the cost of activating unused links. A solution reports whether this set is empty and, when it is not, gives the exact constraints and buyer-optimal and seller-optimal outcomes.

I expect this conditional certificate problem to be Class A, parameterized by the number of operators. For a supplied optimal path-based assignment, the paper’s method makes a shortest-path call for each relevant operator subcoalition; there are at most exponentially many in the number of operators, and each path calculation is polynomial in the network size. With a supplied finite set of optimal path columns, this suggests an \(2^{|F|}\operatorname{poly}(|N|,|A|,\tau,L)\) algorithm, with polynomial dependence also on the number of supplied columns. Whether that bound can be improved when \(|F|\) is part of the input is a further question. This expectation covers the stable-outcome stage of the paper. It does not establish tractability for finding the assignment itself: the paper formulates that stage as a fixed-charge network-design problem with binary link decisions.

The authors would recognize this mirror: OD groups, homogeneous demand, link capacities, path flows, and stable cost allocations are the paper’s own objects. That recognition is also my weakest point. The matching formulation already allows fractional link flows \(x_a^s\geq0\), and the paper treats travelers in homogeneous OD groups. A normalized distribution over OD types may therefore look like a restatement of a model that already aggregates its population continuously. The case for a distinct mirror rests on turning that aggregation into an explicit high-multiplicity problem, with rational population masses and a complexity analysis in \(\tau\), \(L\), and the number of operators. If fractional flow already counts as a continuous population for the programme’s novelty test, this mirror collides with the paper’s model.

Two natural follow-up questions are whether the full stable-outcome set admits a compact separation oracle when the number of operators grows, and whether the discrete integral-trip version has a formal approximation or embedding relationship with this rational-mass version. Proposition 2 gives a strong foothold for the first question; the paper does not answer either one.

The case AGAINST (opponent, writing after the proponent)

The strongest case against this mirror is that the paper already uses the population object the proponent wants to introduce. Its users are homogeneous OD groups with demands \(d_s\); the matching model assigns their flow through real-valued variables \(x_{ij}^s\), and the stable-outcome constraints price those groups and their routes. In a plausible high-volume city setting, the groups are precisely types and their demands are masses. Calling those demands population fractions and scaling capacities and operating costs per capita would make an explicit normalized model, but it would not supply a new population-continuization problem: the paper’s model is already aggregated over types, and its flow assignment already treats each group as divisible mass.

That makes Proposition 2 a poor anchor for a *new* mirror. It proves that Algorithm 1 can generate the stability constraints without enumerating every feasible path. The proposed Continuous OD-Core Certificate asks for that same finite description, given the assignment and related data; the paper already defines the constraints and gives the generation algorithm. A better follow-up—classifying its complexity as the number of operators or network size grows—could be useful. But it would analyze the computational behavior of this paper’s existing aggregate model, not chart a new landscape created by continuizing its population.

The broader version, with rational OD shares and per-capita supplies, has the same problem. It preserves the paper’s type set \(S\), path flows, link activations, and stability questions; the change is the scale and encoding of the demand data. Adding heterogeneous utilities as further type attributes is sensible, but it still refines the same grouped-population model. The paper’s stochastic-utility extension points toward a different question, but that would introduce a distribution over preferences or route choices; it would not rescue a distinct population mirror.

This is a collision argument, not a claim that high multiplicity is implausible or that fractional flows alone make a model continuous. There is an obvious high-volume scenario, and the paper’s aggregation is evidence that it is sensible. The negative case is that the proposed mirror largely restates that scenario and its core computational task. It is not airtight: an explicit rational-mass formulation could expose useful bit-complexity, approximation, or parametric questions. But those seem like extensions of the paper’s existing model, and the case against a worthwhile *new continuous mirror* rests on that distinction.
