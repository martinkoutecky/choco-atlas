The case FOR (proponent)

I don’t see a defensible ChoCo mirror anchored in this paper. It contains no named computational result: no theorem classifies a problem as tractable, hard, fixed-parameter tractable, or otherwise, and it gives no algorithm whose computation could anchor a mirror.

The closest candidate is Theorem 3.4, proved in this paper: for each \(\alpha\in[0,1]\), a value \(f\) on TU games over a fixed finite player set satisfies efficiency, non-singleton covariance, and the \(\alpha\)-dummifying player property if and only if \(f=\varphi_\alpha\), the stated convex combination of the equal division and equal surplus division values. That is an axiomatic characterization, not a complexity result. Corollary 3.8 gives two more such characterizations; Proposition 3.9 proves an implication between axioms. Theorem 2.1 reports characterizations attributed to earlier work. None supplies an eligible computational anchor.

One could try to replace the finite player set with a population distribution and extend the characteristic function to coalition masses. But that would turn the paper’s question into a new axiomatization over a continuous population. It would not mirror a computational problem established by the authors, and continuizing the axioms while the society becomes continuous is outside the programme’s stated scope. The honest answer, therefore, is that this paper offers no named computational result to mirror; there is no per-anchor continuous problem or complexity prediction to give.

The case AGAINST (opponent, writing after the proponent)

Theorem 3.4 is the only plausible anchor, but it characterizes a value; it does not study a computational problem. The value is already given by
\[ \varphi^\alpha_i(N,v)=\alpha v(\{i\})+\frac{v(N)-\alpha\sum_j v(\{j\})}{|N|}. \]
The corollaries give more characterizations, and Proposition 3.9 gives an implication between axioms. None asks how to find an intervention, optimize over outcomes, or classify the complexity of a task.

The most favorable continuous version still does not create such a task. For finitely many player types with masses \(\mu_t\), let \(r(t)\) be the singleton worth for type \(t\) and \(V\) the grand-coalition worth. The natural payoff density is
\[ p_\alpha(t)=\alpha r(t)+V-\alpha\sum_t\mu_t r(t). \]
Given those aggregates, computing it is direct arithmetic. For a nonatomic type space, the corresponding formula replaces the sum with \(\int r(t)\,d\mu(t)\); the remaining computational work is whatever it takes to obtain \(V\) and that integral. If those are hard to compute from some implicit representation, the hardness comes from that representation, which this paper neither specifies nor studies.

A mass-based TU game could support a new axiomatic characterization, but that would continuize the axioms, not formulate the computational questions ChoCo targets. The attached “CASE FOR” in fact makes the same no-mirror argument; its only named candidate, Theorem 3.4, does not survive as a computational anchor.
