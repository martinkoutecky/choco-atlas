What the mirror covers

The proposed extension concerns double implementation in repeated private-value types; it does not mirror a named computational result in the paper.

The case FOR (proponent)

The best positive case is a plausible extension of this paper’s implementation question, but it does not pass the required computational-anchor test. Theorem 1, proved here, says that a rule is doubly implementable if and only if it is weakly securely-strategy-proof: it must be strategy-proof, and every deception profile that is an ex-post equilibrium of the direct game form must leave the rule’s outcome unchanged. Corollary 1, also proved here, says double implementation can be checked using the direct game form. These are substantive characterization results. Neither states a complexity classification, and the paper gives no named result saying a computational problem is in P, hard, FPT, or similar. Its examples compute outcomes for small preference domains, but do not supply such a classification. So there is no qualifying computational anchor in the paper.

If I were to propose an unanchored research lead, it would be *Nonatomic Double Implementation for Repeated Private-Value Types*. Take a finite set \(T\) of complete private-value types and a finite set \(A\) of integral outcomes, such as school assignments. A society is a rational mass vector \(\mu\in\Delta(T)\), with many agents and relatively few repeated types. Per-capita capacities constrain the assignment frequencies. The input also gives a finitely represented rule \(F\) mapping each \(\mu\) to a distribution over integral outcomes for each type; those distributions describe frequencies within a type, not fractional assignments to individuals. The question is whether some game form implements \(F\) for every permitted \(\mu\): truthful reporting is a dominant strategy for each individual, and every ex-post-equilibrium strategy profile yields the prescribed type-level outcome frequencies. A solution would be a mechanism with proofs of both properties, or an impossibility proof.

This is recognizable as an extension of the paper’s private-value double-implementation problem. A large public-service or school-allocation population with recurring preference and eligibility templates gives a plausible high-multiplicity regime. The paper’s tentative-acceptance examples also show that the authors study school choice under incomplete information. The continuum concerns the population; type-level assignment frequencies are a co-modification needed to describe outcomes.

The weak point is substantial: Theorem 1 does not establish this continuum result, and the anchor the task requires is absent. There is also a modeling hazard: if the mechanism’s outcome depends only on aggregate reports, one infinitesimal agent cannot change it, so individual incentive comparisons may collapse. Preserving meaningful incentives requires the mechanism to let an individual’s report affect that individual’s assignment while population masses describe the aggregate. If instead deviations move positive mass, the model changes the paper’s individual equilibrium concepts into coalition deviations. I would leave the candidate’s complexity open and record it as a new research lead, not a supported ChoCo mirror.

The case AGAINST (opponent, writing after the proponent)

Theorem 1 and Corollary 1 are not computational anchors. Theorem 1 characterizes double implementability through weak secure-strategy-proofness; Corollary 1 says the direct game form suffices. Neither poses an algorithmic problem with an input representation or a complexity claim. The paper’s examples check properties on small domains. Continuizing either theorem would continue an axiomatic characterization, which falls outside ChoCo’s computational scope.

The proposed nonatomic allocation question has a plausible population story, but it changes the object being studied. The paper’s rule maps a profile of named agents’ preferences to an outcome, and its equilibrium conditions compare each named agent’s deviations. A type-level allocation distribution can preserve individual incentives only if the mechanism also specifies how an individual report affects that person’s assignment. Then the target is a mechanism over individual reports plus aggregate masses, with a new representation for the rule and its outcomes. If the mechanism uses only aggregate reports and produces a society-wide outcome, an infinitesimal agent cannot change that outcome; the paper’s incentive conditions can collapse. The allocation-kernel version avoids that collapse, but it is a new nonatomic mechanism-design model, not a computational question established by this paper.

School choice is the strongest setting for the proposed extension: large populations can have repeated preferences. But the paper’s school-choice model also uses strict priorities over named students. Preserving those priorities makes students distinguishable; replacing them with priority classes or lotteries changes the model. A type-level allocation rule might still be worth studying, but the paper supplies no computational result to mirror, and turning that rule into a complexity problem would require choices about its encoding and the allowed game forms.

So the negative case is strong on the required ChoCo test: neither named result supports a computational mirror. It is weaker as a universal claim. A carefully specified nonatomic implementation problem could be worthwhile, especially for large allocation systems, but it would be a new research lead rather than a continuization of a computational result in this paper.
