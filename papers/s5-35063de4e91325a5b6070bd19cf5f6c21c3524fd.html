The case FOR (proponent)

There is a credible, though qualified, continuous mirror here. My lead is a continuous version of the paper’s preference-learning problem, anchored in Theorem 3.8.

The population consists of many agents whose types are complete rankings \(v\in L(C)\). A society is a rational mass vector \(\mu=(\mu_v)_{v\in L(C)}\), with \(\sum_v\mu_v=1\). Its exact population frequency matrix is

\[ F_\mu(i,c)=\sum_{v\in L(C)}\mu_v\mathbf 1[\operatorname{pos}_v(c)=i]. \]

This is not a sample from a distribution: it is the deterministic fraction of society placing \(c\) in position \(i\). A natural regime is a large electorate, consumer population, or survey population with millions of agents but relatively few recurring ranking types. A ranking type may represent a demographic, institutional, or behavioural cohort; if there are \(s\) such types and \(N\gg s\) agents, the high-multiplicity interpretation is direct.

The lead problem is:

Continuous Mallows Projection. Given \(C\), a rational-mass society \(\mu\), and a finite rational grid \(\Phi\subseteq[0,1]\), choose a central ranking \(v^\star\in L(C)\) and \(\phi\in\Phi\) minimizing

\[ \operatorname{nPOS}\bigl(F_\mu,F_{v^\star,\phi}\bigr), \]

where \(F_{v^\star,\phi}\) is the frequency matrix of the Mallows model

\[ D_{\mathrm{Mal}}^{v^\star,\phi}(v) =\frac{1}{Z}\phi^{\kappa(v,v^\star)}, \]

and \(\operatorname{nPOS}\) is exactly the normalized positionwise distance used in the paper. The solution is the pair \((\widehat v^\star,\widehat\phi)\) and the achieved distance.

This is a genuine population version of the paper’s Section 5 task: instead of fitting a distribution to a finite list of named votes, fit it to the exact mass profile of a large society. The action is model selection; the objective is population-level frequency-matrix error.

The anchor is Theorem 3.8, proved in this paper. It states that, given \(m\), a central vote \(v^\star\), and a dispersion parameter \(\phi\), there is an algorithm that computes the Mallows frequency matrix using polynomially many arithmetic operations in \(m\). The paper obtains this by dynamically computing the number \(T(m,k,j,i)\) of rankings at swap distance \(k\) in which the candidate at central position \(j\) appears at position \(i\), and then using

\[ f_m(\phi,j,i) =\frac{1}{Z}\sum_{k=0}^{m(m-1)/2}T(m,k,j,i)\phi^k. \]

The theorem is proved here, rather than merely cited.

For the finite-grid version of Continuous Mallows Projection, I would expect Class A. First compute \(F_\mu\) directly from the type masses. For each \(\phi\), Theorem 3.8 computes the canonical Mallows columns. Choosing the central order is then an assignment problem: placing candidate \(c\) at central position \(j\) has cost given by the EMD between \(F_\mu\)’s column for \(c\) and the Mallows column for position \(j\). The minimum over central rankings can therefore be found by bipartite matching rather than by enumerating \(m!\) orders. The positionwise metric’s own column permutation can be incorporated into the same matching. Thus the continuous population does not create a new combinatorial obstruction; it exposes a compact optimization problem.

Further questions would include exact optimization over all real \(\phi\), approximation guarantees when \(\Phi\) is replaced by an \(\varepsilon\)-grid, fitting mixtures of Mallows populations, and fitting a model while requiring a particular candidate to win. Replacing positionwise distance by Kendall-distance fitting would be especially interesting: that may restore hardness through the central-order search.

My supporting anchor is Theorem 3.2, also proved in this paper. It states that, given a rooted ordered tree \(T\), there is an algorithm using polynomially many arithmetic operations in the number of nodes of \(T\) to compute the frequency matrix of the group-separable distribution \(D^T_{\mathrm{GS}}\), the uniform distribution over votes consistent with \(T\). The paper’s dynamic program computes, for every node \(x\) and position \(t\), the probability that \(x\) is preceded by exactly \(t\) leaves after independently reversing internal nodes.

The corresponding problem is:

Continuous Group-Separable Catalogue Fitting. Given a rational-mass society \(\mu\), a candidate set \(C\), and an explicitly listed finite catalogue \(\mathcal T\) of rooted ordered trees on \(C\), choose

\[ T^\star\in\arg\min_{T\in\mathcal T} \operatorname{nPOS}\bigl(F_\mu,F_T\bigr), \]

where \(F_T\) is the exact position-frequency matrix of \(D^T_{\mathrm{GS}}\).

This has a plausible high-multiplicity interpretation: a large organization has recurring preference cohorts generated by a common hierarchy of blocs, departments, or ideological factions. Each internal node represents a block whose local ordering may reverse across cohorts. The tree is a compressed description of many repeated ranking types. The action is to choose the best explanatory hierarchy for the population; the objective is exact matrix distance.

For an explicit catalogue, I again expect Class A. Theorem 3.2 computes \(F_T\) for each tree, and EMD plus the assignment step in \(\operatorname{nPOS}\) is polynomial. If the tree itself must be discovered from an exponentially large implicit family, that becomes a separate structural-complexity question; it should not be confused with the efficient evaluation result established by the paper.

The authors should recognize both mirrors. The paper explicitly interprets a frequency matrix as the expected aggregate behaviour of many sampled voters, and Section 5 explicitly fits parameterized vote distributions to an election by minimizing distance between frequency matrices. The continuous reformulation replaces sampling and named voters by an exact population mass vector and makes the fitted model act on that population directly. It also creates a clean bridge to ChoCo’s later questions about population-level winner determination, robustness, or mass interventions.

The main weakness is substantial: mathematically, the paper already works with distributions over ranking types, and \(F_D\) is exactly an expectation. A strict reader could therefore say that the Mallows and group-separable “mirrors” merely rename the paper’s probabilistic distributions as societies. Moreover, every rational mass profile can be scaled into a finite election, so the change of representation alone does not prove a new complexity separation. The positive case survives only if the distinction between a random vote generator and an exact high-multiplicity society is treated as meaningful, and if the new projection problems are accepted as the computational population questions.

I would therefore present this as a qualified Class-A mirror, strongest for Continuous Mallows Projection. It covers the paper’s frequency-matrix computation and preference-learning core, but not the MDS skeleton map, empirical robustness experiments, or any hardness-based Class-B/Class-C phenomenon. The paper contains no named NP-hardness result, so it cannot by itself support the more ambitious claim that continuization dissolves discrete hardness.

The case AGAINST (opponent, writing after the proponent)

The strongest objection is not that a continuous version would have the same answer. It is that, for both proposed anchors, the paper already has the relevant continuous object.

The paper defines a vote distribution \(D\) over complete ranking types and computes

\[ \#\mathrm{freq}(D)=\sum_{v\in L(C)}D(v)\,\#\mathrm{freq}(v). \]

That is exactly a society mass vector with type space \(T=L(C)\), masses \(\mu_v=D(v)\), and aggregate matrix \(F_\mu\). The distinction between “a random vote generator” and “a deterministic population with those proportions” is semantically meaningful, but it does not survive any computation in the paper: the theorems and the fitting procedure use only this aggregate matrix. Indeed, a rational society \(\mu\) can be expanded into a finite election with the same proportions, giving exactly the same \(F_\mu\).

This defeats the proposed Mallows anchor. Theorem 3.8 computes the model-side matrix \(F_{v^\star,\phi}\). Section 5 already compares that matrix with the frequency matrix of an input election and selects the closest parameters. Replacing the input list of named votes by its exact mass vector therefore does not create a continuous-population problem; it replaces one representation of the paper’s existing input statistic by another. The proposed “Continuous Mallows Projection” is Section 5 applied to an exact histogram.

There is also a more specific degeneracy. Under the paper’s positionwise distance,

\[ \operatorname{rawPOS}(A,B) =\min_{\sigma\in S_m}\sum_i \operatorname{EMD}(a_i,b_{\sigma(i)}), \]

changing the central ranking \(v^\star\) merely permutes the columns of \(F_{v^\star,\phi}\). Since the distance already optimizes over column permutations,

\[ \operatorname{nPOS}(F_\mu,F_{v^\star,\phi}) = \operatorname{nPOS}(F_\mu,F_{v'^\star,\phi}) \]

for every pair of central rankings \(v^\star,v'^\star\). Thus the proposed projection cannot actually learn a central ranking with the paper’s own metric. Making the metric label-sensitive would repair that defect, but would produce an ordinary finite-election fitting problem with a different objective, not a population-continuization of Theorem 3.8. Optimizing over real \(\phi\) instead of a grid would make the parameter continuous, not the society.

The same collision applies to Theorem 3.2. For every tree \(T\), the distribution \(D^T_{\mathrm{GS}}\) is already a probability mass assignment to ranking types. A deterministic high-multiplicity population with masses

\[ \mu_v=D^T_{\mathrm{GS}}(v) \]

has precisely the matrix computed by the theorem. The proposed catalogue problem is simply

\[ \min_{T\in\mathcal T}\operatorname{nPOS}(F_E,F_T) \]

for a finite election \(E\), rewritten with \(F_\mu\) as input. The population size and multiplicity never enter the computation.

Moreover, the dynamic program computes only first-order candidate-position marginals. It does not preserve the hierarchy that supposedly motivates the catalogue interpretation. Distinct trees can yield the same frequency matrix—the paper itself gives balanced group-separable distributions whose matrix is uniform, and flat trees whose matrix is antagonistic. Hence the continuous society cannot identify the explanatory hierarchy; it sees only the same compressed statistic already used by the paper. Using the full ranking distribution, tree likelihoods, or additional cohort attributes could create new questions, but those would no longer be mirrors of Theorem 3.2.

Adding mass transfers, winner constraints, or type-dependent intervention costs could certainly turn these distributions into ChoCo-style problems. But that would be inventing a new intervention problem around the paper’s models, not continuizing one of its computational results. The paper contains no population-level decision problem for which such an operation is the natural limit.

The negative case is therefore strongest under a strict collision test: both anchors are already distribution-over-types computations, and their objectives deliberately discard everything about the population except its frequency matrix. The honest weakness is that a permissive reader could accept “exact type masses instead of sampled votes” as a worthwhile reformulation. If that suffices, the Mallows anchor survives as a modest Class-A question. But accepting it would make almost every probabilistic voting model an automatic continuous-population mirror, erasing the programme’s distinction between an existing distributional treatment and a genuinely new computational theory of societies.
