The continuous mirror question

Given rational distributions \(\mu\) and \(\nu\) over finite supports of Boolean types \(t=(a_t,\alpha_t)\in\{0,1\}^d\times\{0,1\}^d\) and \(s=(a_s,\alpha_s)\in\{0,1\}^d\times\{0,1\}^d\), output a stable coupling \(x\). The coupling must satisfy \(\sum_s x_{t,s}=\mu_t\) and \(\sum_t x_{t,s}=\nu_s\); stability means there are no \(t,s,t',s'\) with \(x_{t,s'}>0\), \(x_{t',s}>0\), \(\alpha_t\cdot a_s>\alpha_t\cdot a_{s'}\), and \(\alpha_s\cdot a_t>\alpha_s\cdot a_{t'}\).

The model it lives in

Each side is a continuum of agents described by rational masses on complete Boolean attribute-and-weight types. The decision variable \(x_{t,s}\) is the mass of type \(t\) matched to type \(s\); each individual receives one partner, while type mass can split across partners. Preferences use the paper's dot-product scores, and blocking requires positive mass on both sides whose assigned partners they strictly prefer to leave.

What the mirror covers

The mirror covers Theorem 7's stable-matching search and Theorem 8's verification result for Boolean attribute preferences. It leaves the d-list, geometric, single-peaked, strategic-behavior, and other attribute-model results aside.

Open questions for a prover

  • How does stable-coupling search complexity depend on support size \(\tau\), dimension \(d\), and input bit length \(L\), especially when \(d\) is small?
  • Which stable couplings can be realized by stable matchings after cloning each type into finitely many individuals?

The case FOR (proponent)

A plausible regime is a large two-sided placement market with standardized profiles: applicants share qualification and priority-weight vectors, while employers share offering and ranking vectors. A type records the complete vector pair \((a,\alpha)\), since both vectors affect preferences. For example, a placement system could have millions of people but only hundreds or thousands of recurring profile types. Replicating every type many times leaves the type distribution unchanged, so this regime can have population size \(N\) far larger than support size \(\tau\).

For the mirror, let the left and right sides each have a distribution over finite supports of Boolean types \(t=(a_t,\alpha_t)\in\{0,1\}^d\times\{0,1\}^d\). Let \(\mu_t\) and \(\nu_s\) be their rational masses, each summing to \(1\). A matching is a coupling \(x_{t,s}\geq 0\) whose row and column sums are \(\mu\) and \(\nu\). It records the fractions matched between each pair of types; each individual still has one partner.

The left type \(t\) values right type \(s\) at \(\alpha_t\cdot a_s\), and the right type \(s\) values left type \(t\) at \(\alpha_s\cdot a_t\). Call the coupling unstable if there are types \(t,s\), plus types \(s',t'\), such that \(x_{t,s'}>0\), \(x_{t',s}>0\), and both \(t\) strictly prefers \(s\) to \(s'\) and \(s\) strictly prefers \(t\) to \(t'\). Those positive flows represent portions of both types willing to match with each other. This gives a type-level version of the paper’s weak stability condition, where both parties must strictly prefer the new partner.

The lead anchor is Theorem 7, proved in this paper: assuming SETH, for every \(\varepsilon>0\), there is a constant \(c\) such that finding a stable matching in the Boolean \(d\)-attribute model with \(d=c\log n\) requires time \(\Omega(n^{2-\varepsilon})\). The proof reduces from Boolean maximum inner product. For vectors \(u\) and \(v\), the constructed man and woman each have their vector as both attributes and weights, so their mutual scores are \(u\cdot v\). The proof shows that every stable matching contains a pair with maximum inner product.

Lead mirror — Boolean Attribute Mass-Stability Search. Given the two rational type distributions and \(d\), output a stable coupling \(x\), if one exists. The output is the mass assigned between every pair of types. I expect this problem to inherit the paper’s fine-grained hardness. The key point is that fractional matching does not erase the reduction: if a maximum-score type pair had zero flow, every partner currently assigned to either endpoint would have a strictly lower score. Positive portions of both endpoint types would then block each other. So every stable coupling must expose a maximum-score pair, which lets its output answer the maximum-inner-product decision problem. The paper’s reduction therefore gives a strong basis for a class-B-style hardness-transfer result for this continuous question. If needed to keep \(\tau=\Theta(n)\), one can append disjoint side-specific binary tags of \(O(\log n)\) bits; they distinguish types without changing cross-side scores. This is my strongest anchor because the hardness argument applies to any stable mass coupling, not just an integral matching.

A second anchor is Theorem 8, also proved here: assuming SETH, for every \(\varepsilon>0\), there is a constant \(c\) such that verifying a stable matching in the Boolean \(d\)-attribute model with \(d=c\log n\) requires time \(\Omega(n^{2-\varepsilon})\). Its proof reduces from Boolean maximum inner product using a threshold \(l\). The construction has \(2n\) participants on each side, dimension \(d+2(l-1)\), and a specified matching; a real man–woman pair blocks exactly when the corresponding inner product is at least \(l\).

Boolean Attribute Mass-Stability Verification. Given the two rational type distributions and a rational coupling \(x\), decide whether \(x\) is stable under the definition above. In the Theorem 8 construction, assign each participant mass \(1/(2n)\) and let \(x\) encode the paper’s specified matching. Its real–real blocking pairs are exactly the threshold witnesses, while the construction rules out other blocking pairs. Thus the verification mirror has its own direct SETH reduction and should also be class-B-style hard. Its additional question is whether this persists for other stability notions or richer, real-valued types.

These mirrors cover the paper’s stable-matching search and verification results for Boolean attribute preferences. They do not cover the d-list, geometric, or single-peaked results, or the strategic-behavior results. Their expected hardness is conditional SETH hardness at the support-size scale, not an unconditional NP-hardness claim. Natural follow-up questions include how complexity changes with \(d\) and \(\tau\), whether small support enables efficient algorithms, and how the mass-stability notion relates to stable matchings in large finite markets formed by cloning each type.

The weakest point is the stability definition for split type mass. The paper matches named individuals, while the mirror records their aggregate assignment and asks whether positive portions of two types can block. That is a natural extension for an atomless population, and it is exactly the definition under which the reductions above work, but the authors or a referee could ask for a canonical relation between it and finite markets with many clones. Exact repetition of complete profile-and-weight types may also need justification in a particular application. Neither concern makes the proposed questions a mere continuization of outcomes: the continuous object is the population, and the coupling is the assignment variable that population forces us to use.

The case AGAINST (opponent, writing after the proponent)

The strongest negative case is about fit, not validity: this paper studies succinct preferences among named participants. In a continuous mirror, a type must include both the attributes and weights that determine preferences. In many matching markets those profiles are individualized, so the support grows with the population. A regime with many people per exact type is possible—for example, standardized applicant and employer profiles—but it needs a concrete application to make the population model compelling.

That concern does not defeat Theorem 7. The best mirror is stable-coupling search over rational type masses, with blocking defined by positive flow to less-preferred partners on both sides. Its reduction survives aggregation: if no maximum-score type pair carries flow, its endpoints can block; any maximum-score pair in the coupling reveals the maximum inner product. The lower bound uses support size \(\tau=\Theta(n)\) and \(d=\Theta(\log \tau)\), so it does not demonstrate an advantage from having many people per type. But that limits the regime covered by the reduction; it does not make the continuous search question ill-posed or unworthy.

Theorem 8 also survives the stronger formulation. Give each constructed participant mass \(1/(2n)\) and represent the specified matching as a coupling. Repeated real types and the repeated dummy types can be aggregated: the threshold witness still creates a positive-mass blocking pair, and the gadget still excludes other blockers. The result transfers conditional hardness to verification at support size \(\Theta(n)\). A verifier for arbitrary couplings would include these instances, so allowing types to split across partners does not evade the reduction.

There is a nearby continuum stable-matching model whose outcome is found by a Deferred Acceptance analogue ([*A Continuum Model of Stable Matching With Finite Capacities*](https://arxiv.org/abs/2205.12881)). That is useful background, but it does not settle the computational landscape for finite rational type supports with succinct attribute preferences. More generally, type-level Deferred Acceptance and direct blocking-pair checks give natural baselines; they do not answer whether the paper’s geometric and fine-grained results transfer.

So the honest negative case is weak. The paper has named computational results, identity need not matter once types capture everything relevant, and the continuum does not degenerate. Both proposed mirrors are coherent and their reductions appear to hold. I can argue that they may be lower priority because their hardest instances use as many types as participants, but I cannot honestly defend the universal claim that no worthwhile continuous mirror exists.
