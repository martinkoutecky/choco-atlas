The continuous mirror question

Given a finite type set \(\mathcal T=D\mathbin{\dot\cup}S\), positive rational masses \(\mu_t\) summing to \(1\), and for each \(t\in D\) eligible target types \(N(t)\) with positive integer rank costs \(c(t,u)\), assume every delegating type can reach a casting type. Each member of type \(t\) delegates to every member of each target type \(u\in N(t)\) at cost \(c(t,u)\). Compute the exact aggregate assignment \(x_{t,s}=\mu_t R_{t,s}\), where \(R_{t,s}\) is the limiting probability of absorption in casting type \(s\) for the type-level chain with transition probabilities \(P^\varepsilon_{t,u}=\mu_u\varepsilon^{c(t,u)}/\sum_{w\in N(t)}\mu_w\varepsilon^{c(t,w)}\) as \(\varepsilon\to0\). Equivalently, compute the type-level aggregate outcome obtained by averaging assignments uniformly over minimum-cost maximum-cardinality branchings in any integral finite expansion of the masses.

The model it lives in

Types are delegating and casting roles with rational masses \(\mu_t\); each delegating role links at a shared rank cost to every member of each eligible target role. In every finite expansion with \(N\mu_t\in\mathbb Z\), the rule minimizes total rank cost among maximum-cardinality branchings and averages the assignments uniformly over all optimal branchings. The continuous output is the aggregate mass matrix \(x_{t,s}\).

What the mirror covers

The mirror covers Theorem 5's computation of Mixed Borda Branching, with Theorem 6's equivalence supporting the formulation; it leaves the axiomatic results and non-fractional impossibility result untouched.

Open questions for a prover

  • Can the exact aggregate assignment be computed in time polynomial in the number of types \(\tau\), the mass bit length \(L\), and the rank-cost bit length?
  • Which of the paper's fractional axioms hold for the type-aggregated assignment?

The case FOR (proponent)

The strongest positive case is a type-compressed continuous version of Mixed Borda Branching for a large organization whose members delegate to role-defined pools. A type is a delegating or casting role, together with the same ranked list of eligible delegate types for everyone in that role. Every member of a listed delegate type is an eligible delegate at the same rank. Thus a delegation type links to whole pools of people, and the rule treats members symmetrically. This is plausible in a large party or association with stable delegate pools: the population can be huge while the number \(\tau\) of distinct delegation types stays small.

The anchor is Theorem 5, proved in this paper: “Algorithm 2 returns Mixed Borda Branching and runs in \(\mathrm{poly}(n)\),” where \(n\) is the number of voters. In full, for each delegating voter \(v\) and casting voter \(s\), the algorithm computes
\[ A_{v,s}=\frac{|B^\ast_{v,s}(G)|}{|B^\ast(G)|}, \]
where \(B^\ast(G)\) is the set of minimum-cost maximum-cardinality branchings, and \(B^\ast_{v,s}(G)\) contains those branchings in which \(v\)'s path ends at \(s\). So the underlying problem is to compute the fractional delegation outcome obtained by averaging uniformly over all minimum-total-rank-cost branchings. This is the paper’s named polynomial-time computational result; the supplied text contains no comparable named hardness result to use as an anchor.

Here is a continuous problem precise enough to give to a prover. Continuous Type-Compressed Mixed Borda Branching takes a finite type set \(\mathcal T=D\dot\cup S\), where \(D\) are delegating types and \(S\) are casting types; positive rational masses \(\mu_t\) summing to \(1\); and, for each \(t\in D\), a set of eligible target types \(N(t)\subseteq\mathcal T\setminus\{t\}\), with a positive integer rank cost \(c(t,u)\) for each \(u\in N(t)\). Require every type in \(D\) to have a path to a type in \(S\). The exclusion \(u=t\) means members of a delegating type do not list their own type as a target; it keeps their delegate lists identical.

For an integer \(N\) making every \(N\mu_t\) integral, expand the instance into \(N\mu_t\) people of each type \(t\), with every person of type \(t\) linked to every person of each target type \(u\in N(t)\) at cost \(c(t,u)\). The continuous solution is the exact aggregate outcome of this expansion. Equivalently, for \(\varepsilon>0\), form the type-level chain
\[ P^\varepsilon_{t,u} = \frac{\mu_u\varepsilon^{c(t,u)}}{\sum_{w\in N(t)}\mu_w\varepsilon^{c(t,w)}} \quad (t\in D,\ u\in N(t)), \]
with types in \(S\) absorbing. Let \(R_{t,s}\) be the limit as \(\varepsilon\to0\) of the probability that a chain starting at \(t\) is absorbed in casting type \(s\). The requested output is the exact mass-assignment matrix \(x_{t,s}=\mu_tR_{t,s}\), with each row summing to \(\mu_t\). A casting type’s total voting mass is then \(\mu_s+\sum_{t\in D}x_{t,s}\). The objective inherited from the paper is minimum total rank cost among maximum-cardinality branchings; the output averages the resulting assignments across all optimum branchings.

This is recognizably their problem: the rule, rank costs, delegation paths, and aggregate assignment are the same, with delegate choices organized into symmetric pools. Theorem 6, also proved here, supports the formulation by showing that Mixed Borda Branching equals the limiting Random Walk Rule. In the complete-pool expansion, the type-level chain above is the exact quotient of that voter-level chain, because each target pool contributes a number of equally ranked edges proportional to its mass.

I expect the compressed problem to be tractable, a Class A mirror. The paper’s Fulkerson and Markov-chain-tree machinery works on the type graph, with rational edge coefficients \(\mu_u\); Section 6 also describes extending the algorithm to parametric chains with rational-function transitions. The research question is whether this yields an exact running time polynomial in \(\tau\), the mass bit length \(L\), and the rank-cost bit length—rather than a bound polynomial in the expanded population \(N\).

The weakest point is the regime: the mirror assumes tied delegation preferences over whole pools, while many real liquid-democracy participants name particular people. The scenario is most convincing where delegates are genuinely chosen from role-based pools and identities within a pool are interchangeable. The mirror covers Theorem 5’s outcome computation only; it does not claim to continuize the paper’s entire axiomatic analysis. Further questions include proving the compressed bit-complexity bound and determining which of the paper’s fractional axioms survive aggregation by type.

The case AGAINST (opponent, writing after the proponent)

Theorem 5 is the only anchor here that asserts a computational result: its algorithm computes Mixed Borda Branching in polynomial time. Theorem 6 supports the same anchor by identifying the rule with a limiting random walk. The axiomatic theorems do not supply additional complexity anchors.

The strongest objection is that a histogram of delegation types does not capture a general delegation graph. The branching algorithm depends on the graph’s actual edges, cycles, and paths to casting voters. Two graphs with the same counts of local delegation profiles can have different branching outcomes. Preserving arbitrary person-to-person links therefore tends to preserve identity-level structure too, undermining compression to a small fixed set of types.

The proposed pool model avoids that problem by making a substantive assumption: everyone in a delegating type accepts every person in each listed target pool at the same rank. That is plausible for delegation to role-based pools, but it does not describe the usual choice of particular trusted delegates. It also changes what the output emphasizes. With positive mass in a casting pool, the pool’s total weight can grow with the population while each individual caster’s share of the electorate vanishes. A model centered on a few named gurus would need to preserve them as distinguished, effectively zero-mass nodes, alongside the continuum.

Those objections narrow the mirror’s reach, but they do not defeat the proposed case. For the pool regime, the quotient is exact: with \(N\mu_u\) people in target type \(u\), the probability of a transition into that type is proportional to \(N\mu_u\varepsilon^{c(t,u)}\). The common factor \(N\) cancels, giving the stated type-level transition probabilities. The aggregate assignment \(x_{t,s}=\mu_tR_{t,s}\) therefore preserves the finite expansion’s type-level outcome. It remains a meaningful question about a continuous population, even though the regime is specialized.

The paper’s extension to rational-function transition probabilities also suggests a direct route to solving that compressed problem. That may limit how much new algorithmic work it needs, but an easy tractable mirror is still within the programme’s aims. I can make a case that this is a narrow, deliberately structured version of liquid democracy; I cannot honestly argue that no worthwhile mirror survives in any scenario. Theorem 5’s pool-based mirror remains standing.
