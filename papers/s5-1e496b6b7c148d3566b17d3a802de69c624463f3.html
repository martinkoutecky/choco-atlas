The continuous mirror question

Given a fixed finite set of complete voter types \(T\), rational masses \(\mu_t\), a fixed type-block order, and a relative-majority threshold sequence with \(k_n/n\to\kappa\), determine all subsequential limits as \(n\to\infty\) of the type-by-ballot masses and acceptance outcome in the unique finite subgame-perfect equilibrium, under specified rounding and tie conventions. Compare these limits when abstention is allowed and when it is not.

The model it lives in

A society is given by type masses \(\mu_t\) over \(T\), where each type includes true preference and payoff parameters. The order is a fixed sequence of type blocks, and the voting rule uses a normalized threshold \(\kappa\). The decision choices are ballots and their resulting masses; the output is the limiting ballot-mass vector and outcome for the finite roll-call equilibria, with and without abstention.

What the mirror covers

The mirror covers Proposition 1’s sequential equilibrium behavior; it leaves the simultaneous-voting equilibria and Harsanyi–Selten equilibrium selection results aside.

Open questions for a prover

  • For which type masses, payoff parameters, block orders, and thresholds do the limits with and without abstention agree on the outcome while differing in ballot masses?

The case FOR (proponent)

The positive case is narrow. The paper has no named complexity result: none of its numbered propositions says a problem is in P, NP-hard, FPT, or the like. So there is no anchor here for the usual question of whether discrete hardness dissolves in the continuum. The closest useful anchor is Proposition 1, which gives a solution characterization for a computational task, but does not establish its running time.

Proposition 1 is proved in this paper. It says the finite sequential voting game has a unique subgame-perfect equilibrium. Working backward, each \(N^{-}\) voter votes No when they are an Abstain–No pivot, Abstains when they are a Yes–Abstain pivot, and otherwise votes Yes. Each \(N^{+}\) voter Abstains when they are an Abstain–No pivot, votes Yes when they are a Yes–Abstain pivot, and otherwise votes No. Pivotality is assessed assuming later voters follow their true preferences. The proposal is rejected, with all \(N^{+}\) voters voting No, if \((N^{+},\varnothing)\notin H\); otherwise it is accepted, with all \(N^{-}\) voters voting Yes. Thus the equilibrium outcome always reflects the true majority.

My lead mirror would be Limit Roll-Call Equilibrium. Its society is a finite set \(T\) of voter types with rational masses \(\mu_t\) summing to \(1\). A type records the voter’s true preference and the complete payoff parameters \((G_t,c_t,d_t)\); an order distribution records where each type appears in the roll call. For a relative \(k\)-majority rule, take an acceptance threshold \(\kappa\) for the limiting Yes-minus-No mass. The decision variable is the mass of each type voting Yes, Abstain, or No. The input also specifies how to round the masses and order distribution into finite roll-call instances. For each such instance, run the paper’s unique finite-game equilibrium. The question is to compute the limit points of the resulting type-by-ballot masses, and the limiting outcome. A solution is that limit set and outcome, including any dependence on the stated tie and rounding conventions.

A plausible regime is a large party convention or cooperative membership vote held by roll call: many members, but relatively few shared preference and outside-pressure profiles. Here \(N\) can be very large while \(\tau=|T|\) stays small. The scenario is close to the paper’s own concern with roll-call voting under party pressure, and the mirror retains its strategic question: which voters conform, dissent, or abstain, and what does the vote decide? For threshold rules with a fixed number of types and block-ordered voters, I would expect the limit problem to be tractable through a compressed backward-induction analysis. That is a conjecture about the mirror, not a complexity result proved by Bolle.

The soft spot is substantial: in a literal nonatomic game, one voter has zero probability of changing the result, so the pivotal incentives driving Proposition 1 disappear. The proposed problem therefore defines the continuous object as a high-multiplicity limit of finite sequential games, rather than claiming that Proposition 1 directly extends to an atomless Nash game. That is still a reasonable population-continuization question, but whether the authors would accept it as their continuous analogue is uncertain. And without a named hardness result, this case supports a study of limiting equilibrium behavior—not a claim that a discrete computational barrier vanishes.

The case AGAINST (opponent, writing after the proponent)

Proposition 1 is the strongest anchor, but it gives no computational complexity result. It characterizes the unique finite-game subgame-perfect equilibrium by backward induction. For standard threshold rules, that characterization is already a direct way to determine the votes; for arbitrary \(H\), the paper gives no input representation from which to assess running time. The paper’s question is how abstention changes equilibrium behavior, not whether an algorithmic barrier disappears.

The best version of the proposed mirror would specify finitely many payoff types, an order distribution over those types, and a threshold \(\kappa\), then ask for the limiting type-by-ballot masses along finite roll-call games. A large parliamentary vote is a plausible high-multiplicity setting, so the population story itself is sound. The trouble is that position in the roll call affects a voter’s pivotality and equilibrium action. Include position in the type, and the number of types grows with the electorate; leave it out, and type masses alone do not capture the suffix of votes that drives backward induction. Encode order separately as a distribution over positions, and the object becomes a path-valued description of the game.

There is also a singular limit at the heart of this proposal. Proposition 1’s incentives rely on an individual being pivotal. In an atomless society, an individual has zero mass and cannot change the outcome. A finite-game sequence can retain individual pivotality at every step, but that makes the proposed question a limit analysis of finite extensive-form games; it does not give the continuum society a canonical sequential equilibrium corresponding to Proposition 1. Making the simultaneous-voting sections continuous avoids the order problem, but then computing a Harsanyi–Selten selected equilibrium becomes a new equilibrium-selection question, with no selection principle supplied by the continuous population model.

So the case against is mainly about fit: a continuous roll-call limit could be mathematically worthwhile, but it would be a singular-limit study in game theory, not a computational-continuization mirror of a named complexity result. This does not establish that no useful continuous question can be built from the paper. The universal negative is weak precisely because the high-multiplicity parliamentary scenario is credible; what is missing is a compelling computational question that survives the move to a population distribution.
