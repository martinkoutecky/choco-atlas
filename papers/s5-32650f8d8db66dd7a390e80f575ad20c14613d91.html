The case FOR (proponent)

The strongest mirror is the problem of computing the majority relation for a population distributed over the rankings in a tiling type domain. The paper’s central result already speaks directly to that aggregation problem.

The continuous problem — Tiling-Domain Majority. An instance consists of a candidate set \([n]\), a permutation \(w\), a commuting class \(C\) of reduced words for \(w\), and a positive rational mass \(\mu_t\) for every ranking \(t\in D=\operatorname{Pre}(C)\), with \(\sum_{t\in D}\mu_t=1\). The masses are given in binary. A type is a complete ranking; \(\mu_t\) is the fraction of the population holding that ranking. The task is to output the strict majority relation on every pair of candidates: \(a\prec b\) exactly when more than half the mass ranks \(a\) above \(b\). The solution is the resulting relation, equivalently its ordered blocks and any simple ties. This is an aggregation problem, so it has no intervention variable or optimization objective.

The regime is a very large electorate made up of cohorts with shared rankings, all drawn from a structured domain that avoids Condorcet cycles. The number \(N\) of people can greatly exceed the number \(\tau=|D|\) of ranking types; the input records the \(\tau\) cohort masses, not \(N\) named voters. This is most convincing where many people share a limited set of complete preference orders. It does require every ranking in \(D\) to have positive mass, as the paper’s theorem does.

My anchor is Theorem 1.7, proved in this paper. For an integer tally \(\rho\) whose support is exactly \(\operatorname{Pre}(C)\), it defines \(\Sigma_\rho(ab)\) as the total tally of rankings that reverse \(a,b\). It proves that this tally strictly decreases up the heap poset \(P_C\). It also proves that the majority relation is the intersection of two linear orders \(<_{u}\) and \(<_{v}\): \(u\) has precisely those inversions \(ab\) with \(\Sigma_\rho(ab)>|\rho|/2\), while \(v\) has precisely those with \(\Sigma_\rho(ab)\ge|\rho|/2\). The paper further shows in Corollary 1.4 that the resulting relation is a prelinear order with only simple ties. The corollary is a consequence of the theorem, not a separate anchor.

For the continuous instance, set
\[ \Sigma_\mu(ab)=\sum_{t\in D:\,ab\in\operatorname{Inv}(t)}\mu_t. \]
The same theorem applies: its tally values are simply scaled by the total mass. Thus the mirror asks for the same majority relation from cohort proportions. With rankings listed explicitly, one can compute all pairwise tallies and the output in time polynomial in \(n\), \(\tau\), and the input bit length. I expect this mirror to be tractable (Class A) in that explicit-support regime. The paper proves the structural formula; it does not itself state this running-time classification.

The mirror covers the paper’s general majority computation for profiles supported exactly on a tiling type domain, including nonuniform weights. It does not cover majority aggregation on arbitrary Condorcet domains, nor does it continuize the outcome space. A natural next question is how much the majority relation can change when a small amount of mass is moved between ranking types; that would be a separate continuous robustness problem, not a result of Theorem 1.7.

The weakest point is that rational masses do not create a radically new aggregation rule here: clearing denominators turns them into integer tallies, and the paper already formulates profiles as tallies. The defensible case is narrower: the population-as-mass formulation is a natural high-multiplicity version of this computational problem, and the paper’s exact structural result transfers directly. The paper offers a named computational characterization, but no named theorem classifying this problem as polynomial-time or hard.

The case AGAINST (opponent, writing after the proponent)

Theorem 1.7 is the only substantive anchor; Corollary 1.4 restates its structural consequence, and the later uniform-tally calculations specialize the same setup. Its proposed mirror has exactly the paper’s population data in normalized form. For any rational mass vector \(\mu\) with support \(D=\operatorname{Pre}(C)\), choose a common denominator \(q\) and set \(\rho(t)=q\mu_t\). Then \(\rho\) is an integer vote tally with the same support, and every pairwise majority comparison is unchanged by the scaling. Conversely, normalizing any tally in the theorem gives such a \(\mu\). This correspondence is polynomial in the binary input length.

That makes the case against stronger than “the answer is already known”: the paper’s own computational object is already a histogram over complete ranking types, and every proposed binary-rational continuous instance is exactly one of those histograms. A large electorate of ranking cohorts is a sensible high-multiplicity regime, but it does not create a distinct mirror here. The theorem already accepts arbitrary positive integer multiplicities on the domain, not just the uniform tally.

A genuinely different question would need to change the task, such as studying intervention or robustness, or admit non-rational masses that have no finite exact binary input. Those are not alternate continuizations of this majority-computation result under the programme’s model. So the negative case rests on a narrow point: the population-as-mass object the proponent proposes is already the paper’s tally object, up to normalization.
