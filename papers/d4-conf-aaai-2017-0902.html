The continuous mirror question

Given an atomless population of mass \(1\), divided into \(\tau\) types with rational masses \(\mu_t>0\), and a finite list of interaction schemas \(h=(t_1,\ldots,t_{r(h)})\) with nonnegative rational weights \(w_h\), let a coalition be represented by type masses \(z_t\in[0,\mu_t]\) and have value \(\nu(z)=\sum_h w_h\prod_{j=1}^{r(h)}z_{t_j}\). Find the largest \(\epsilon\) and nonnegative type payment rates \(p_t\) such that \(\sum_t\mu_t p_t=\nu(\mu)\) and \(\sum_t p_tz_t\ge\nu(z)+\epsilon\sum_tz_t\) for every \(z\) with \(0<\sum_tz_t<1\); the weak least-core value is \(-\epsilon\).

The model it lives in

Types carry mass \(\mu_t\); each interaction schema contributes \(w_h\prod_j z_{t_j}\) to a coalition with type-mass vector \(z\). The decision variables are per-member type payment rates \(p_t\) and the margin \(\epsilon\); maximize \(\epsilon\) subject to budget balance and every proper coalition's weak least-core constraint.

What the mirror covers

Covers Theorem 7's weak least-core computation for block-structured induced-subgraph games; it does not cover arbitrary hypergraph incidence, the airport-game formulas in Theorems 8–11, or the general characterizations in Theorems 2–3.

The case FOR (proponent)

The strongest mirror I see is narrow: the weak least-core computation for the induced subgraph game in Theorem 7, proved in this paper. The theorem says that, given a weighted hypergraph \(G=(V,E,w)\), one can compute a value division in its strong and weak least cores in \(O(|V|^2 f(|V|, O(\sum_{e\in E}|e|))L)\) time, where \(f\) is the max-flow running time on the associated graph and \(L\) is polynomial in \(|V|\) and \(|E|\). The paper proves this using an ellipsoid method and hypergraph minimum-cut separation; the max-flow/min-cut subroutine is cited. The paper gives no comparable named hardness result, so this is the right kind of algorithmic anchor.

A plausible high-multiplicity setting is a large collaboration network: many firms participate in joint projects, and a project creates surplus only when all its required participants join the same alliance. Firms of the same type have the same role and the same interaction rates with every combination of roles. There might be millions of firms but only a few dozen such types. This is a mirror of block-structured induced-subgraph games, not of every arbitrary hypergraph in the theorem.

Here is the direct continuous problem I would hand to a prover: Block-Hypergraph Weak Least Core. Let \(\Omega\) be an atomless population of total mass \(1\), partitioned into \(\tau\) types with rational masses \(\mu_t>0\). Give a finite list of interaction schemas \(h=(t_1,\ldots,t_r)\), each with nonnegative rational weight \(w_h\): an interaction of that schema contributes its weight when all its participants belong to the coalition. For a coalition \(A\), let \(z_t=\mu(A\cap\Omega_t)\). Its normalized value is
\[ \nu(z)=\sum_{h} w_h\prod_{j=1}^{r(h)}z_{t_j}. \]
A division pays each member of type \(t\) at rate \(p_t\). Find the largest \(\epsilon\), and a division attaining it, subject to
\[ p_t\ge 0,\qquad \sum_t\mu_t p_t=\nu(\mu),\qquad \sum_t p_t z_t\ge \nu(z)+\epsilon\sum_t z_t \]
for every coalition with \(0<\sum_t z_t<1\). The continuous weak least-core value in the paper’s sign convention is \(-\epsilon\). Every vector \(z\) in the type-mass box is realizable by a coalition, since each type is atomless.

For this exact mirror, I expect tractability—but with a degenerate answer. Any budget-balanced division has slack tending to zero for coalitions whose mass tends to the whole population. Since the weak margin there tends to \(\epsilon\), no \(\epsilon>0\) can satisfy all the constraints. Thus the optimum is \(0\). A core division is available explicitly: split each interaction’s value equally among its participants, giving
\[ p_t=\sum_h \frac{w_h}{r(h)} \sum_{j:t_j=t}\ \prod_{k\ne j}\mu_{t_k}. \]
For each schema, this allocation to a coalition is at least that schema’s value for the coalition, so the constraints hold at \(\epsilon=0\). Computing these rates is polynomial in the number of schemas, their size, \(\tau\), and the input bit length.

That is a faithful population-continuous version of the paper’s weak least-core question, and the authors should recognize the model. It also shows why the mirror is modest: the nontrivial algorithmic content of Theorem 7 disappears in the atomless limit. A natural follow-up is a macroscopic weak least core, imposing the deviation constraint only when \(\rho\le\sum_t z_t\le1-\rho\) for a fixed rational \(\rho>0\). That avoids both vanishingly small coalitions and coalitions arbitrarily close to the grand coalition. Its separation problem resembles a mass-constrained hypergraph cut; I would expect hardness to transfer from a corresponding finite, balanced-deviation problem, though that is a conjecture, not a result of this paper.

My weakest point is that this useful macroscopic variant changes which coalitions count as deviations, while the exact continuous mirror has a zero margin. I would therefore claim a sound, recognizable mirror for the weak least-core part of Theorem 7—not that its original polynomial-time result survives unchanged, or that this one model covers the paper’s other results.

The case AGAINST (opponent, writing after the proponent)

Theorem 7’s weak least-core anchor runs into a structural problem in an atomless population. Let \(\Omega\) have mass \(1\), let \(p\) be an integrable payoff rate with \(\int_\Omega p\,d\mu=\nu(\Omega)\), and take proper coalitions \(A_j\) whose masses approach \(1\). In any natural finite-density model, including the proposed schema model, both \(\int_{A_j}p\,d\mu\) and \(\nu(A_j)\) approach their grand-coalition values. So the coalition’s slack approaches zero. A positive weak margin would require that slack to stay at least \(\epsilon\mu(A_j)\), which approaches \(\epsilon\); a positive strong margin is impossible for the same reason. If the continuous game has a core allocation, its strong and weak least-core values are therefore both zero.

For the proposed finite interaction schemas, a core allocation is available directly by dividing each interaction’s value among its participants, as the proponent describes. The exact continuous mirror thus has a computable division, but the least-core optimization that motivates Theorem 7 has collapsed. This is not specific to that schema choice: finite-density graphon or hypergraphon models also have coalition values continuous under removing vanishing mass, so the same near-grand-coalition argument applies.

There is also a choice about what structure to preserve. Arbitrary hypergraph incidence can carry the minimum-cut complexity used in the paper, but encoding every player’s full interaction pattern may leave almost no repeated types. With a small number of genuinely interchangeable types, the incidence is instead summarized by interaction rates, and the explicit core allocation bypasses that separation problem. This makes it hard to retain both the theorem’s combinatorial input and a meaningful high-multiplicity population.

The proposed macroscopic variant avoids the collapse by excluding coalitions near the grand coalition. It could be a worthwhile new problem, but it removes deviations that the paper’s least core explicitly constrains. Renormalizing slack by the mass left behind would likewise define a different stability criterion. I can’t rule out that the authors would recognize either as a valuable extension; that is the weak point in a universal negative case. But neither rescues the exact Theorem 7 mirror: its continuous least-core margin is zero, while versions that avoid zero change which deviations count or how stability is measured.
