The continuous mirror question

Given a finite type set \(S\) with rational masses \(\mu_s \ge 0\), \(\sum_{s\in S}\mu_s=1\), integral per-unit resource endowments \(b_{sk}\), and tasks \(i=1,\ldots,m\) with rational demands \(d_{ik}\), positive rewards \(\rho_i\), and a threshold \(Q\), decide whether there are task decisions \(y_i\in\{0,1\}\) and nonnegative aggregate flows \(x_{isk}\) such that \(\sum_{s\in S}x_{isk}=d_{ik}y_i\), \(\sum_{i=1}^m x_{isk}\le\mu_s b_{sk}\), and \(\sum_{i=1}^m\rho_i y_i\ge Q\). Each completed task receives its full required resources; coordination costs are zero.

The model it lives in

A continuum of agents grouped into \(\tau\) resource-profile types, with mass \(\mu_s\) and per-unit endowment \(b_{sk}\). Binary variables \(y_i\) select tasks, while flows \(x_{isk}\) allocate type-level resource mass; the objective is to decide whether total reward reaches \(Q\).

What the mirror covers

The mirror covers Theorem 3's NP-completeness claim in the zero-cost, one-resource restriction. It leaves aside the search-space counts, TOH repair results, and empirical comparisons.

Open questions for a prover

The case FOR (proponent)

The strongest mirror is a high-multiplicity version of the paper’s task allocation problem. Imagine a large fleet of standardized emergency-response units. Each unit has one of a small number of resource profiles—say, battery, cargo, and communications capacity—and many units share each profile. The fleet must complete a fixed set of tasks, each with resource requirements and a reward. A task still completes as a whole; what becomes continuous is the population and the allocation of its resources.

Theorem 3 is the anchor. It states that OCSG in the paper’s resource-constrained, subadditive task-oriented model is NP-complete. The paper proves this by restricting to one resource and zero pairwise communication costs, yielding a threshold task game, whose OCSG hardness it cites from [20] and [27]. In decision form, the question is whether a feasible overlapping coalition structure exists with social welfare at least a given threshold.

Here is the corresponding continuous question, High-Multiplicity OCSG-0. Its input is a finite set of types \(S\), with \(|S|=\tau\); each type \(s\) has mass \(\mu_s\in\mathbb{Q}_{\ge 0}\), where \(\sum_s\mu_s=1\), and integral per-unit resource endowments \(b_{sk}\) for resource \(k\). There are \(m\) tasks, each with per-capita resource demands \(d_{ik}\in\mathbb{Q}_{\ge 0}\) and reward \(\rho_i>0\), plus a welfare threshold \(Q\). Pairwise coordination costs are zero, as in the hard restriction used by Theorem 3.

Ask whether tasks can be completed with total reward at least \(Q\). A solution consists of completion decisions \(y_i\in\{0,1\}\) and aggregate resource flows \(x_{isk}\ge 0\), where \(x_{isk}\) is the amount of type-\(s\) resource \(k\) sent to task \(i\), satisfying
\[ \sum_s x_{isk}=d_{ik}y_i \quad\text{for every task }i\text{ and resource }k, \qquad \sum_i x_{isk}\le \mu_s b_{sk} \quad\text{for every type }s\text{ and resource }k, \]
and \(\sum_i\rho_i y_i\ge Q\). The task’s coalition consists of the mass contributing resources to it. The same type mass can support overlapping tasks, subject to its resource limits. These flows are aggregate quantities: with a large homogeneous cohort, fractional type-level totals can be realized by assigning different integral resource bundles to portions of that cohort. Equivalently, normalize an \(N\)-unit fleet’s supplies and task demands by \(N\); \(\mu_s\) records its type proportions.

This is a credible mirror of Theorem 3 because it keeps the paper’s central decision—choosing which tasks receive feasible coalitions—and its shared-resource constraints. It does not turn task completion into a fractional outcome: \(y_i\) remains binary because the paper awards a task’s reward when that task is accomplished. The mirror changes the population representation, while the task-selection question remains recognizable.

I expect hardness to transfer. In the continuous problem, set \(\tau=r=1\), \(\mu_1=1\), and \(b_{11}=B\). Each task is then an item with weight \(d_i\) and value \(\rho_i\); feasibility is \(\sum_i d_i y_i\le B\). This is the knapsack decision problem. The remaining combinatorics live in choosing tasks as \(m\) grows, even when the population has only one type. So the expected classification is Class B, with NP-hardness persisting in the continuum.

The scenario has \(N\gg\tau\): many interchangeable units, few standard capability profiles, and a finite task list. Resource endowment is a complete type description in the zero-cost restriction. If pairwise communication costs are retained, a type must also describe the unit’s interaction costs with every other type, and those costs need a sensible scaling as population size grows. That extension is a further question, not part of this anchor.

The weakest point is the scope of the match. Zero communication costs make this a narrow, explicitly hard subcase of the paper’s model; the paper’s full objective includes pairwise costs that this mirror leaves out. It therefore covers Theorem 3’s hardness claim, not the TOH repair algorithm or its empirical comparisons. A useful next question is whether a high-multiplicity version with nonzero type-pair coordination costs has a tractable formulation or preserves the same hardness.

The case AGAINST (opponent, writing after the proponent)

Theorem 3 is the only live anchor, and I cannot honestly defeat it. A homogeneous fleet of interchangeable units with one resource type and zero coordination costs is a credible high-multiplicity regime. The proposed flows preserve the paper’s task-selection question: each task is either completed or not, and the units’ aggregate resources must support the selected tasks. Clearing rational denominators gives finite instances with integral resources. Zero coordination costs are a narrow restriction, but they are also the restriction used in the paper’s hardness argument.

The strongest objection is about scaling. The paper’s native model has a fixed list of tasks with fixed resource requirements. If the population grows while those requirements stay fixed, total supply grows with it and each task consumes a vanishing share of the fleet. To avoid that degeneration, the mirror scales task requirements with the population. That describes a growing workload, which is plausible for a large fleet but is an additional regime assumption. And with coordination costs set to zero, the mirror removes the pairwise coalition costs that make the repair heuristic distinctive.

Those points make the mirror narrower than the paper’s overall model; they do not rule it out. The task explicitly allows population-driven co-modifications, and one emphatic mirror suffices. Since the zero-cost task-selection problem remains recognizable as OCSG, the negative case is weak: Theorem 3 survives.
