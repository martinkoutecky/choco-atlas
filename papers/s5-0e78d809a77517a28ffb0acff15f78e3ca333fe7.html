What the mirror covers

The proposed asymptotic criterion targets the existence question in Theorem 3 and the characterization in Theorem 2. It leaves the HCF construction in Theorem 1 and the privacy and randomization results in Propositions 1 and 2 aside.

The case FOR (proponent)

The strongest anchor is Theorem 3, proved in this paper. It says that for an anonymous Boolean function \(G\), \(n\) agents with costs \(c_1,\ldots,c_n\), and a common prior \(q\in(0,1)\), there is a polynomial-time algorithm to decide whether a \(q\)-appropriate sequential mechanism exists. Here “appropriate” means there is an equilibrium in which the mechanism computes \(G\) correctly for every secret vector. The theorem treats \(G\) as succinctly represented by the counts of \(1\)s on which it outputs \(1\). The paper has no named hardness result to anchor, so this is an algorithmic mirror rather than a test of whether discrete hardness disappears.

A credible regime is a large census or telemetry service: many people or devices each hold a private binary datum, each wants the same population statistic, and accessing their datum has a cost determined by a small number of classes—for example, device or service tiers. Let \(T\) be those cost classes. Members of class \(t\) share the same cost \(c_t\), prior \(q\), and benefit \(1\) from learning the correct result. Let \(\mu_t\) be that class’s population fraction. The population is large while the support size \(\tau=|T|\) stays small. Those are complete types for this problem; the private bit is each agent’s realized secret.

I would ask the authors to study Limit Appropriate Elicitation. Its input is a rational distribution \(\mu\) over finitely many cost types, rational costs \(0\le c_t<1\), a common rational prior \(q\in(0,1)\), and an anonymous density rule \(F:[0,1]\to\{0,1\}\) encoded by finitely many rational intervals and endpoints. This covers scalable rules such as majority and consensus. For each population size \(N\) with every \(N\mu_t\) integral, form the finite society with \(N\mu_t\) agents of type \(t\), and set \(G_N(s)=F(\#\{j:s_j=1\}/N)\). The question is: is there an \(N_0\) such that every such \(N\ge N_0\) has a \(q\)-appropriate sequential mechanism for \(G_N\)? A mechanism, as in the paper, chooses the next unapproached agent from the public history or halts with an output; an appropriate equilibrium must compute \(G_N\) correctly for every secret vector. The answer is yes or no. At the population scale, the policy’s state records the mass of each type approached and the reported \(1\)-mass, with individual steps of size \(1/N\).

I expect this problem to be tractable, though Theorem 3 does not establish that. Its existence criterion in Theorem 2 gives a starting point: the finite state graph over counts might have a limit in mass coordinates, where a continuous dynamic program or a simpler pivotality condition decides eventual existence. A key question is whether fixed positive costs make individual pivotality vanish as each cost class grows proportionally with \(N\). If so, the limiting criterion may be quite simple. That would be a substantive conclusion about this strategic problem, even if the answer is less intricate than the finite-population algorithm.

The authors should recognize the mirror: it retains costly acquisition of private bits, the shared value of the answer, sequential public elicitation, anonymous computation, and equilibrium correctness. Only the population scale and the statistic’s representation change. Its scope is deliberately limited to anonymous rules with a meaningful density limit; functions whose behavior depends on one-agent granularity, such as parity, are not covered. It does not try to mirror the paper’s privacy and randomization propositions, which do not supply a comparable complexity anchor.

The weakest point is that this is an asymptotic high-multiplicity question, not a direct game among atomless players. In a literal atomless game, one person’s report has zero effect on the aggregate, and the paper’s pivotality incentive can disappear. The finite-replication definition keeps each game and its equilibrium well-defined, but the limit may become degenerate. That is also the central further question: does eventual appropriateness collapse to a simple condition on the positive-cost mass and \(F\), or does sequential elicitation leave a richer limit? A related question is whether changing the cost or reward scale with \(N\) yields a nondegenerate continuum game that authors would still regard as their problem.

The case AGAINST (opponent, writing after the proponent)

Theorem 3 is a real computational anchor: it gives a polynomial-time existence test, so “the paper has no named computational result” cannot carry the negative case. Nor can I dismiss multiplicity across the board. A large sensor network with many agents in the same cost class is a credible high-multiplicity regime.

The harder problem is that the secret is precisely what the mechanism does not know. In the proposed census model, the mass of each *cost class* is known, but the mass of each secret value is not. If the continuous society instead includes the actual masses of secret-0 and secret-1 agents, it gives the center the aggregate it is meant to compute. If those masses remain hidden, a literal atomless version loses the mechanism’s basic unit: it approaches one named agent at a time, and any one agent has zero influence on the aggregate. With independent secrets, a continuum also makes the aggregate density equal to \(q\) almost surely, so a density rule’s answer is determined by the prior rather than elicitation. Requiring correctness for every profile would still leave the mechanism needing to recover deviations from that density by querying zero-mass agents.

The proponent’s \(N_0\) question avoids this by keeping every game finite. But then its “mass state” is a rescaled count state: agents still move one at a time, and their pivotality still depends on finite steps. The question classifies the tail of a sequence of finite games; it does not give a computational problem over a continuous society. That tail question could be worthwhile in its own right, but its value would not establish a continuous mirror of Theorem 3.

The best repair is to scale incentives with population size so agents remain willing to compute. For a fixed density rule with finitely many thresholds, an individual’s pivotal probability near a threshold is at most \(O(N^{-1/2})\), and away from one it typically decays faster. Keeping computation incentives nontrivial therefore requires the cost-to-benefit ratio to shrink with \(N\). That creates a finite-size asymptotic regime whose leading incentives come from each agent’s residual atomic influence. Treating an entire cost class as one decision-maker would avoid that problem only by changing the game and removing the individual free-riding the paper studies.

So the strongest objection is not that high multiplicity is implausible or that the answer would be simple. It is that the natural continuous object either reveals the hidden aggregate, makes it prior-determined, or removes the individual action on which sequential elicitation depends. The negative case is not airtight: the proponent’s finite-replication question is coherent, and a researcher could choose to study it as asymptotic game theory. I would argue that this is too far from a continuous computational mirror to make it a priority for this programme.
