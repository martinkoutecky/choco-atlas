What the mirror covers

The proposed scoring-correspondence angle touches Corollary 5.5 and the paper’s scoring and veto implementation conditions; it leaves the other implementation characterizations untouched, and none supplies a named computational result.

The case FOR (proponent)

The best positive seed is the paper’s scoring correspondence, but it falls short of the programme’s anchor requirement. The closest result is Corollary 5.5, proved in the paper: if \(n>m\) and the score vector satisfies \(s_{m-1}<\bar{s}_m\) (equivalently, \(H_s\) is unanimous), then \(H_s\) is constitutionally implementable. That is an existence result about implementation, not a result that a computational problem is in P, NP-hard, or otherwise classified. The paper’s main results are characterizations and existence theorems of this kind; I find no named computational-complexity result to anchor a ChoCo mirror on. [The paper’s full text](https://www.researchgate.net/publication/227022275_Constitutional_implementation_of_social_choice_correspondences) describes its results as implementation conditions and applies them to scoring and veto correspondences.

There is a natural population-continuum formulation behind that result. Fix \(m\) alternatives and a scoring vector \(s\); let each type \(t\) be a weak ranking, and let \(\mu_t\) be its population share. The scoring correspondence becomes
\[ H_s(\mu)=\left\{a\in A:\sum_{t\in T}\mu_t\,\operatorname{score}(a,t)\ge \bar{s}_m\right\}. \]
A plausible regime is a large electorate with fixed \(m\) and relatively few distinct ballot types, so \(n\gg\tau\). Corollary 5.5 is encouraging background: its finite-population condition \(n>m\) holds in that regime. But it does not establish an algorithmic result about the continuum.

If I had to nominate a lead research question, it would be: given \(m\) and \(s\), does there exist a measurable game form for a unit-mass population of ranking types whose Nash-equilibrium outcomes equal \(H_s(\mu)\) for every measurable ranking profile, and whose effectivity function agrees with the one induced by \(H_s\) for every measurable coalition? A solution would be such a game form plus a proof of both properties. This is a genuine population-continuum question, and likely the authors would recognize its connection to constitutional implementation. Its expected direction is uncertain; ordinary Nash equilibrium with atomless individuals may create a continuum-specific obstacle because an individual deviation has zero mass.

That uncertainty is also the weakest point—and the decisive scope problem. The proposed question changes the strategic model and asks about existence, not computational complexity. The paper itself starts from a finite set of players and studies which social choice correspondences game forms can constitutionally implement. [Its stated results](https://citeseerx.ist.psu.edu/document?doi=7d45d07c0f15238f04b2d7fec3abcd20279aaece&repid=rep1&type=pdf) do not classify the computational complexity of finding an implementation. So I would present the continuum formulation as a plausible adjacent research question, not as a supported continuous mirror for this programme.

The case AGAINST (opponent, writing after the proponent)

The decisive issue is that Corollary 5.5 is not a computational result. It says that, under \(n>m\), a scoring correspondence satisfying the stated condition is constitutionally implementable. The paper’s main contribution is a set of conditions for implementation, illustrated with scoring and veto correspondences; it does not classify the complexity of an algorithmic problem. The authors define constitutional implementation through Nash equilibrium outcomes and agreement of effectivity functions, not through a computation on an input society. [The paper’s full text](https://www.researchgate.net/publication/227022275_Constitutional_implementation_of_social_choice_correspondences) [Maastricht University’s paper record](https://cris.maastrichtuniversity.nl/en/publications/constitutional-implementation-of-social-choice-correspondences-3/)

The population story itself is credible: a large electorate with a small set of ranking types is a natural high-multiplicity regime. But the proponent’s strongest question—whether a game form for a unit-mass population implements the scoring correspondence for every measurable profile and matches its effectivity function for every measurable coalition—remains a structural existence question. It does not turn the corollary into a computational anchor.

There is also a substantive obstacle in carrying over the implementation concept. In an anonymous atomless model whose outcomes depend on the distribution of actions, a single voter’s deviation changes no mass and hence no outcome. Every strategy profile is then a Nash equilibrium, so this equilibrium notion cannot select the preference-dependent outcomes the correspondence specifies. To repair that, one could use positive-mass coalition deviations and define effectivity by coalition mass or type composition. That is a plausible theoretical extension, but it changes the paper’s core objects: individual Nash deviations and effectivity for each finite coalition become a different equilibrium and a mass-based constitution. It still gives no computational task unless one adds a finite encoding and asks an algorithmic question about it.

One could add such a question—for example, a decision problem about whether a succinctly described correspondence has an implementation under the new mass-based notion. But that would be a new computational problem, not a continuous mirror of a computational result in this paper. The corollary’s implementation claim quantifies over profiles and coalitions globally; it does not take a society \(\mu\) as its instance. If a proposed model instead lets the game form depend on named individuals so that single deviations matter, those identities must be represented in the type space, undercutting the intended moderate-support population model.

So I would not argue that large electorates are implausible, or that the paper has already been treated continuously. The negative case is weaker as a universal claim: someone can formulate an interesting continuum mechanism-design project from this material. But the proposed anchor does not support a ChoCo computational mirror; making one requires adding the computational problem and changing the implementation model.
