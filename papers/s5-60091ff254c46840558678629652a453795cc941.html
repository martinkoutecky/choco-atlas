The continuous mirror question

Given a finite set of roles \(T\), positive rational masses \(\mu_p\) summing to \(1\), and directed trust weights \(a_{pq}\), define \(e_p(x)\) as the minimum incoming weight \(a_{qp}\) over roles with \(x_q<\mu_q\), or \(0\) if there is no such role, and set \(V_\mu(x)=\sum_{(p,q)\in E_T}a_{pq}x_px_q+\sum_{p\in T}x_pe_p(x)\) for \(0\le x\le\mu\). For each integer \(h\) with \(h\mu_p\) integral, form the symmetric clone game \(v_h(S)=V_\mu(x(S))\), where \(x_p(S)\) is the mass of role-\(p\) clones in \(S\). Prove whether \(\Phi_p=\lim_{h\to\infty}h\phi_{p,1}(v_h)\) exists and compute all \(\Phi_p\), with complexity measured in \(|T|\), the input bit length, and requested precision.

The model it lives in

A normalized block-role trust game with role masses \(\mu_p\), role-to-role weights \(a_{pq}\), and coalition state \(x\). Its worth integrates pairwise internal interaction as \(\sum_{(p,q)\in E_T}a_{pq}x_px_q\) and assigns each coalition unit the minimum incoming weight from roles still represented outside. The decision object is the per-mass Shapley value obtained as the symmetric-clone limit.

The objection that survived

The clone model separately normalizes pairwise internal interaction and per-member external exposure, so it is not obtained by uniformly scaling the paper's edge weights; the paper does not establish that authors would accept this relative scaling as part of their trust game.

fatal: False

What the mirror covers

The primary mirror covers Corollary 3.3 by asking for type-level Shapley densities; Theorem 4.2 also has a clone-limit analogue, although its external contribution vanishes in the limit. The core, total-balancedness, and marginal-effect results are left outside this mirror.

Open questions for a prover

  • Determine the running time for exact computation or approximation as a function of \(|T|\), input bit length, and precision.

The case FOR (proponent)

The strongest mirror is for the paper’s value-computation results. It contains no named hardness result, so this case does not claim that a discrete hardness barrier dissolves. Its best anchors are the Shapley formula for the full trust game and the separate Banzhaf formula.

A plausible high-multiplicity regime is a large trust or reputation network organized into a small number of stable roles. A type \(p\) is a complete trust profile: every member has the same directed evaluation \(a_{pq}\) of members of each type \(q\), and the same incoming type-level relations. There may be millions of agents but only \(\tau\) such profiles. The mass \(\mu_p\) is type \(p\)’s fraction of the population. This is a block-homogeneous network model, not a claim that arbitrary individual-to-individual networks have few types.

Here is a continuous trust game for that regime. For a coalition with type-mass vector \(x\), where \(0\le x_p\le\mu_p\), let \(e_p(x)\) be the minimum \(a_{qp}\) over incoming types \(q\) with \(x_q<\mu_q\), or zero if there is no such type. Define its worth by
\(V_\mu(x)=\sum_{(p,q)\in E}a_{pq}x_px_q+\sum_{p\in T}x_p e_p(x).\)\)
The first term is the normalized internal interaction among coalition members; the second gives each unit of coalition mass the minimum evaluation from an incoming type still represented outside it. Thus the model retains the paper’s two defining ingredients, including the outside-neighbor minimum, while making coalition size a mass rather than a headcount.

To define continuous values without relying on a nonexistent uniform random ordering of an atomless population, use a clone limit. For each integer \(h\) such that \(h\mu_p\) is integral for every \(p\), make a finite society with \(h\mu_p\) clones of type \(p\), each of mass \(1/h\). Give a coalition \(S\) worth \(V_\mu(x(S))\), where \(x_p(S)=|S\cap N_p|/h\). Clones of a type are symmetric. The continuous Shapley-density problem asks, from \(T,\mu,E\), and the rational type weights, to prove that the limits exist and compute \(\Phi_p=\lim_{h\to\infty}h\phi^{(h)}_{p,1}\) for every type \(p\). The continuous Banzhaf-density problem asks the same with \(\Beta_p=\lim_{h\to\infty}h\beta^{(h)}_{p,1}\), using the paper’s normalized Banzhaf value. Multiplying by \(h\) reports value per unit population mass.

The lead anchor is Corollary 3.3, proved in this paper. With \(m_i\) the number of incoming neighbors of player \(i\), \(b_i(t)\) their sorted edge weights and \(r_j(i)\) the rank of \(i\) among \(j\)’s incoming neighbors, it gives the full trust-game Shapley value:
\(\displaystyle \phi_i(v)= \sum_{\substack{j\in N\\(i,j),(j,i)\in E}}\frac{a_{ij}+a_{ji}}2 +\sum_{t=1}^{m_i}\frac{b_i(t)-b_i(t-1)}t-\frac{b_i(m_i)}{m_i+1} +\sum_{\substack{j\ne i\\(i,j)\in E}} \left(\sum_{t=r_j(i)+1}^{m_j}\frac{b_j(t)-b_j(t-1)}t-\frac{b_j(m_j)}{m_j+1}\right). \)\)
The paper’s sorted incoming-weight chain is exactly the feature that makes this a promising mirror: in the type model, the corresponding chains are over at most \(\tau\) incoming types. The continuous question is whether the per-mass clone limit of this same fairness index can be computed from the type-level trust structure.

A second, independent anchor is Theorem 4.2, also proved here. It gives the normalized Banzhaf value of the full trust game:
\(\displaystyle \beta_i(v)= \sum_{\substack{j\in N\\(i,j),(j,i)\in E}}\frac{a_{ij}+a_{ji}}2 +\sum_{t=1}^{m_i}\frac{b_i(t)-b_i(t-1)}{2^{t-1}}-\frac{b_i(m_i)}{2^{m_i}} +\sum_{\substack{j\ne i\\(i,j)\in E}} \left(\sum_{t=r_j(i)+1}^{m_j}\frac{b_j(t)-b_j(t-1)}{2^{t-1}}-\frac{b_j(m_j)}{2^{m_j}}\right). \)\)
Its mirror is the continuous Banzhaf-density problem just defined, not a different game or encoding. The theorem’s exponentially indexed weights suggest that this limit may be especially amenable to analysis when many individual neighbors collapse to a few types.

I would expect both questions to be tractable in this regime: the support is small, the internal term is a \(\tau\)-type-pair sum, and the external minimum is controlled by sorted type weights. That is a conjecture about these continuous problems, not a result established by the paper. Useful follow-ups are to prove limit existence, derive exact formulas and convergence rates, and bound the cost of computing the limits in \(\tau\), input bit length, and requested precision. This mirror covers Corollary 3.3 and Theorem 4.2; it does not attempt to continuize the core or total-balancedness results.

The weak point is real: the paper assigns weights to edges between named individuals, whereas this mirror assumes type-to-type trust and normalizes the internal interaction as a population-level quantity. That is a substantial co-modification, and the clone-limit convention for values should be something the authors and a referee accept. The case survives only for the stated block-homogeneous regime. It remains a continuous population of agents with the paper’s internal-interaction and external-minimum structure, and it asks for the same named values by a precise high-multiplicity limit.

The case AGAINST (opponent, writing after the proponent)

The strongest case against is that the proposed mirror changes the network regime substantially. Corollary 3.3 and Theorem 4.2 compute values from a graph whose edges connect particular people. Their external terms depend on the ranks of those particular incoming edges. In the paper’s P2P trust setting, people with the same role need not trust the same individuals, so grouping them into a few types can erase exactly the topology the formulas use. Preserving each person’s full neighborhood profile would generally require as many types as people, leaving no high-multiplicity compression.

The proponent’s block model is the best alternative: every member of type \(p\) assigns the same weight to every member of type \(q\). That is a coherent dense, role-based trust game, and the proposed scaling can be motivated as a mean-field normalization. It is also a narrow change in what an edge means. The question becomes whether values are tractable in a complete block network, rather than in the paper’s general directed trust network. For Corollary 3.3, this narrows the setting precisely where the individual neighbor ranks collapse into a few repeated weight levels. That makes it a plausible asymptotic follow-up, though a weak candidate for charting a broader computational landscape.

Theorem 4.2 has a sharper degeneration in this model. Under the normalized Banzhaf value, a random coalition contains every member of a positive-mass type with probability exponentially small in that type’s size. In the clone limit, the external effects from completing whole types disappear; the surviving external contribution is essentially each type’s minimum incoming weight. A sampling rule that preserved the ranked-neighbor effects would change the Banzhaf question. This supports a negative verdict for the paper’s distinctive layered externality, although the limiting value remains a well-posed computational question.

The negative case is weak against the universal claim. A large role-based reputation network with pooled trust between roles is a plausible high-multiplicity scenario. Its population is continuous, and both value limits can be studied from the same trust-game structure. The paper also does contain named computational results, so the “no result to mirror” ground does not apply. I can argue that the mirror narrows the network model and may offer limited computational reach; I cannot honestly establish that the role-based mirror is not worthwhile.
