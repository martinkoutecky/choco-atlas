What the mirror covers

The apparent mirror covers only Theorem 2’s algorithm-independent query lower bound for homogeneous constituencies; it does not cover heterogeneous type distributions or query bounds depending on support size \(\tau\).

The case FOR (proponent)

A credible positive mirror is \(\textsc{Group-EF-Query}_\infty(\Delta)\). The paper itself gives the key plausibility signal: it says an “agent” may be a group whose utility is measured on average, with fairness required at that averaged level. In the mirror, each of two large constituencies has a distribution \(\mu^\nu\) over complete types \(t\in[0,1]^m\), where a type records one member’s value for every good. The mass \(\mu^\nu_t\) is the fraction of constituency \(\nu\) with that profile; let \(\tau\) be the total number of supported profiles and \(L\) the encoding length of their rational masses and values. Members of each type are identical for every aspect of this allocation problem.

Good \(i\)’s per-capita value to constituency \(\nu\) is \(u_i^\nu=\sum_t\mu^\nu_t t_i\). Goods remain indivisible: an allocation partitions \([m]\) into bundles \((A_a,A_b)\), and each constituency evaluates its bundle using these average values. The instance promises \(\operatorname{OptEnvy}\le-\Delta\). A query selects a good and samples a member from each constituency, returning that member’s value plus independent \(N(0,\sigma^2)\) measurement noise. The algorithm must output a partition with envy at most zero; the resource to minimize is the number of queries. In the hard subcase below, each constituency has just one supported type, so each query is exactly the paper’s Gaussian query to its group-average value. A natural regime is very large constituencies with \(N\gg\tau\); the lower-bound instance has \(\tau=1\) per constituency.

My lead anchor is Theorem 2, proved in this paper (stated in Section 5 and proved in Appendix D). For fixed \(\sigma^2>0\) and \(\Delta\in(1,m/2)\), the authors construct a randomized hard instance with independent \(X_i\sim\mathrm{Bernoulli}(1/2)\). In the first half of the goods, \(X_i=1\) gives values \((1/2+\epsilon,1/2-\epsilon)\) to the two agents and \(X_i=0\) reverses them; in the second half, \(X_i=1\) gives both agents \(1/2+\gamma\), while \(X_i=0\) gives both \(1/2-\gamma\). For suitably chosen \(\epsilon,\gamma\), any possibly adaptive or randomized algorithm using \(q\le c\,m^{2.5}/\Delta^2\), for a sufficiently small constant \(c\), has probability at least \(1/3\) of the joint event that \(\operatorname{OptEnvy}\le-\Delta\) and its output has positive envy. This is a query-complexity lower bound, not an NP-hardness theorem.

The corresponding continuous question is: does \(\textsc{Group-EF-Query}_\infty(\Delta)\) require \(\Omega(m^{2.5}/\Delta^2)\) queries in the worst case, even when arbitrary computation is allowed? Theorem 2 gives the strongest kind of support for that question: every instance in its hard prior can be represented by two large, homogeneous constituencies, each with mass one on a complete valuation type. Thus the lower bound survives in an atomic high-multiplicity subcase; it is driven by uncertainty across goods, not by the number of distinct people. In the programme’s trichotomy this is B-like persistence of hardness, with the qualification that the resource here is oracle queries rather than conventional computational time. The mirror covers this lower-bound result only.

The weakest point is the query model outside that homogeneous subcase. With multiple types, random-member queries produce mixtures of Gaussians, while the paper’s upper-bound analysis uses Gaussianity; Theorem 2 does not establish a matching upper bound for those populations. That suggests useful next questions: how does the minimax query budget depend on \(m,\tau,L,\Delta\) under member sampling, and can the paper’s upper bound extend beyond one-type groups? The paper’s existing group-average motivation makes the mirror recognizable to its authors, but the heterogeneous query model remains a genuine extension rather than a result already proved by this theorem.

The case AGAINST (opponent, writing after the proponent)

The strongest negative case is that the proposed Theorem 2 mirror is already answered by the paper. Its hard instance gives each of the two groups a complete valuation vector; make each group arbitrarily large by cloning that vector across its members. Then each group has one supported type, its average values are exactly the paper’s values, and each query has the same Gaussian distribution. The theorem therefore already proves the proposed \(\Omega(m^{2.5}/\Delta^2)\) lower bound in this high multiplicity subcase. That is more than a lower bound merely surviving continuization: for homogeneous groups, the “continuous question” is the same query problem under a cohort interpretation. The paper even names group averages as a motivation.

The population size adds no operative parameter. Holding the type distributions fixed while increasing group size changes neither the query model nor the required number of queries. In Theorem 2, the uncertainty is about the hidden values of individual goods, not about the composition of a population. With one type per group, the continuum contributes nothing to that uncertainty. So the anchor is a poor new ChoCo question: its answer follows directly from the paper, and its difficulty comes from noisy learning across \(m\) goods, not from a continuous population.

A stronger proposal would allow heterogeneous groups and ask for query complexity as a function of their type distributions. But that changes the oracle: sampling a member produces a mixture of Gaussians, whereas the paper’s main analysis uses Gaussian observations. Under independent member sampling for each query, only each good’s marginal value distribution affects the observations; correlations between coordinates of a member’s full valuation type are not used. The resulting question is naturally about statistical estimation under bounded, possibly non-Gaussian noise. It does not create an optimization over population masses or expose the continuous-optimization machinery that motivates the programme.

This is a limited negative case. The paper’s group-average motivation makes the high multiplicity interpretation convincing, and a heterogeneous-member query model could be worth studying in fair division or bandit learning. But the named anchor is already settled in its homogeneous continuous special case; the broader version is a new statistical model, rather than a continuous computational mirror that this paper’s result opens up.
