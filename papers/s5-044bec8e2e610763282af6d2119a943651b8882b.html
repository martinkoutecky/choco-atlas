The continuous mirror question

Given rational type masses \(\mu_\theta\), per-capita category quotas \(q_c\), eligibility and priority orders over types, and a target type \(\theta^\star\), decide whether there is a valid mass allocation \(x_{\theta c}\) with \(\sum_c x_{\theta^\star c}>0\). The allocation must respect type masses, quotas, eligibility, and priorities: if \(x_{\theta c}>0\), every type \(\theta'\succ_c\theta\) must be fully allocated. It must also be Pareto efficient among priority-respecting allocations, meaning no such allocation can increase one type’s served mass without decreasing another’s.

The model it lives in

A static high-multiplicity allocation model for admissions or rationing: each type is a complete applicant profile, \(\mu_\theta\) is its population mass, and \(q_c\) is a per-capita quota. The decision variable \(x_{\theta c}\) is the mass assigned through category \(c\); each person still receives either a whole unit or none. The question is whether any positive mass of a specified type can be served.

What the mirror covers

Covers static serviceability in Proposition 4 and additive welfare maximization in Corollary 3; leaves the weighted matching characterization, other selection and threshold results, and online arrival guarantees unmirrored.

Open questions for a prover

  • Does Cohort Serviceability remain NP-hard with a fixed number of categories or bounded priority tiers, or is it fixed-parameter tractable in support size \(\tau\)?

The case FOR (proponent)

The strongest mirror is the paper’s static selection problem in a large admissions or rationing cohort. Think of many applicants who share the same eligibility, priority-tier, and utility profiles. A type is that complete profile; \(\mu_\theta\) is the fraction of the population with type \(\theta\). Category quotas become per-capita shares \(q_c\). The decision variable \(x_{\theta c}\) is the mass of type \(\theta\) assigned through category \(c\): \(\sum_c x_{\theta c}\leq\mu_\theta\), and \(\sum_\theta x_{\theta c}\leq q_c\). Each unit of mass still represents an agent receiving one whole unit.

Eligibility requires \(x_{\theta c}=0\) when \(\theta\) is ineligible for \(c\). For priorities, if \(x_{\theta c}>0\) and \(\theta'\succ_c\theta\), then the entire higher-priority cohort must be allocated: \(\sum_d x_{\theta'd}=\mu_{\theta'}\). A valid allocation also has to be Pareto efficient: no other priority-respecting allocation can increase one type’s served mass without decreasing another’s. This is a population model, not just a fractional-outcome model. The quotas scale with the population, while the support consists of the \(\tau\) profiles that actually occur.

This regime is plausible for repeated cohorts of scholarship applicants, school applicants, or people seeking public housing. The paper itself motivates these settings and, in Section 5.1, models many arrivals using a small set of observable types. Types must include everything the allocation uses—including utilities—so agents with different relevant attributes cannot be merged. For this case I would anchor on two results, with Proposition 4 as the lead.

Proposition 4, proved in this paper, says that deciding whether a given agent is *serviceable*—allocated in at least one valid allocation—is NP-hard. Its proof reduces from X3C. The continuous question is Cohort Serviceability: given rational masses \(\mu_\theta\), per-capita quotas \(q_c\), eligibility and priority orders over types, and a target type \(\theta^\star\), is there a valid allocation with \(\sum_c x_{\theta^\star c}>0\)? A yes-instance has a rational allocation vector \(x\) satisfying the constraints and priority conditions above; a no-instance has none. This asks whether a positive mass of a homogeneous cohort can be served, rather than whether a named person can be.

The X3C construction survives this change to mass. For a ground set of \(3n\) elements and \(m\geq n\) triples, let \(\eta=1/(5m-n+1)\). Use mass \(\eta\) for each element type, each set type, and the target type, and mass \(4(m-n)\eta\) for one filler type. There is a category \(\alpha_i\) of quota \(4\eta\) for each triple and a category \(\beta\) of quota \(\eta\). Each \(\alpha_i\) ranks the filler type above set type \(i\), then above the three element types in that set. Category \(\beta\) ranks every element type above the target. These are complete allocation profiles; each can be replicated \(R\) times, giving a population of \(R(5m-n+1)\) agents with only \(O(m+n)\) types.

If any positive target mass is assigned in \(\beta\), priority requires all element mass to be allocated. Since \(\beta\) has only \(\eta\) capacity, almost all of it must be served through the \(\alpha_i\) categories, which in turn requires the filler mass to be fully allocated. Each \(\alpha_i\) that serves any elements must fully allocate its set type. Capacity then allows exactly \(n\) such set types, and their triples must cover all \(3n\) element types: with any element missing from their union, the \(\alpha_i\) categories and the remaining \(\beta\) capacity cannot serve all element mass while leaving positive capacity for the target. Conversely, an exact cover gives a valid allocation of the target mass. Thus the continuous decision is NP-hard. The conclusion is Class B: the combinatorics live in the family of types and categories, and fractional mass does not remove them. This is the lead because it mirrors the paper’s explicit inclusion/serviceability question and has a direct reduction.

My second anchor is Corollary 3, also proved here, as a consequence of Theorem 4. It says that, given utilities \(u_a(c)\in(0,1]\), it is NP-hard to find a valid allocation maximizing \(\sum_{a\in A}\sum_{c\in C}u_a(c)x_{a,c}\). The continuous question is Cohort Welfare Maximization: with a utility \(u_\theta(c)\) shared by every member of type \(\theta\), maximize \(\sum_{\theta,c}u_\theta(c)x_{\theta c}\) over valid mass allocations. A solution is an allocation vector attaining the maximum.

The same construction gives the hardness intuition: give the target type utility \(1\) and other types utility \(\varepsilon\), for example \(1/2\), on eligible categories. The fluid counterpart of Proposition 1—that valid allocations serve the same maximum total mass—means welfare maximization rewards serving the target when the cover exists. The construction makes the target’s positive service equivalent to X3C, so maximizing this type-level welfare is NP-hard as well. This is again Class B, not continuum-specific hardness. Further questions include whether these problems are fixed-parameter tractable in \(\tau\), and how hardness changes when the number of categories or priority tiers is bounded.

The mirror covers the static agent-inclusion and aggregate-welfare results in Sections 4.1 and 4.2. It does not attempt to continuize the online arrival process or time in Section 5; the society itself is the continuous object. Nor does it claim that finding *some* valid allocation is hard: the paper’s weighted-matching characterization concerns that baseline task, while these anchors concern selection among valid allocations.

The weakest point is the population regime required. The mirror assumes many people share priority tiers and other relevant attributes; strict person-by-person rankings or idiosyncratic utilities can make the support size grow with the population and erase the high-multiplicity advantage. This is an assumption about a plausible instance regime, not every allocation setting. It is supported here by the paper’s tiered priorities, its applications, and its own small-type online model—but authors might still distinguish cohort serviceability from their question about one named agent.

The case AGAINST (opponent, writing after the proponent)

The strongest objection is that “serviceability” changes granularity in the mirror. Proposition 4 asks whether one named agent can be included in some valid allocation. An individual has zero mass in an atomless population, so the proposed question—whether a positive mass of a type can be served—is a cohort question. Requiring a fixed fraction of the cohort, or requiring the whole cohort, would be a different problem.

That objection is real, but it does not defeat the best mirror. In the paper’s model, agents with identical eligibility and priority profiles are interchangeable, and priority tiers allow many agents to share a type. Asking whether some of such a cohort can be served is a natural high-multiplicity version of inclusion. The proposed X3C construction also survives aggregation: any positive target mass forces all element mass to be served; the capacity constraints then require exactly \(n\) set types whose triples cover the elements. Its target mass is \(\eta\), so the reduction does not depend on an infinitesimal, vanishing gap.

Corollary 3’s welfare mirror survives for the same reason. Giving the target type utility \(1\) and other types utility \(\varepsilon\) makes welfare depend on how much target mass is served, since valid allocations serve the same total mass. The most I can say against this anchor is that it reuses the serviceability reduction, so it adds little independent evidence for the programme. But the instructions allow one strong mirror, and this is still a distinct, well-posed optimization question with utilities included in the type.

A strict ranking for every applicant could indeed make support grow with population size. That is a limitation of some instance regimes, not a universal obstruction: the paper permits priority tiers, and its applications include settings where applicants share eligibility and priority profiles. I therefore can’t honestly defeat either anchor. The negative case is weak exactly where the burden is hardest: there is a plausible high-multiplicity regime, and the proposed questions survive a careful type-level formulation.
