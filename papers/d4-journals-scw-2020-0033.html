What the mirror covers

The proposed extension concerns Theorem 1’s target-set characterization; Corollary 2 and the other propositions are also axiomatic, and the paper supplies no computational result.

The case FOR (proponent)

The strongest honest case is a high-multiplicity follow-up to Theorem 1, proved in this paper. The theorem says that a choice correspondence over finite populations satisfies efficiency and population-monotonicity exactly when it is a target set correspondence with the same target interval \([a,b]\) for every population. Given the smallest and largest peaks, \(\underline p\) and \(\overline p\), the rule returns \(\{\underline p\}\) if \(b<\underline p\), \(\{\overline p\}\) if \(a>\overline p\), and \([a,b]\cap[\underline p,\overline p]\) otherwise.

The paper contains no named computational result asserting a complexity classification, algorithm, or hardness result. Theorem 1 is an axiomatic characterization, so it cannot serve as an anchor under the stated requirements.

A plausible population regime is a large municipality choosing an “if-needed” list of public-facility locations. Many residents share the same complete single-peaked preference relation; the number of residents \(n\) is much larger than the number \(\tau\) of distinct preference types. A type is that complete preference relation, and its mass is its fraction of residents. The choice is a compact set of locations. This is a credible population continuum: the masses represent cohorts of residents, while the chosen set remains the public good described in the paper.

The precise follow-up question would be: Characterize all maps \(G\) from rational, finite-support mass distributions over single-peaked preference types to compact sets of locations that are efficient and population-monotonic under cohort entry. If the initial population has distribution \(\mu\), an entering cohort has relative mass distribution \(\eta\), and \(\mu'=(\mu+\eta)/(1+\eta(T))\), population-monotonicity requires that all types initially present weakly prefer \(G(\mu')\) to \(G(\mu)\), or that they all weakly prefer \(G(\mu)\) to \(G(\mu')\). The candidate classification is the same target set family, using the smallest and largest peaks in the support. For rational masses, cohorts can be represented by integer counts, so Theorem 1 provides a strong reason to expect that identity in the unrestricted preference domain.

That follow-up has an exact formulation and the authors would likely recognize its population-entry question. Its proposed answer is essentially inherited by representing rational masses as finite populations. Evaluating a supplied target set rule would also be easy from the listed support, in \(O(\tau)\) peak comparisons. That is a straightforward algorithmic consequence, not a computational result of the paper or a substantial complexity question. Restricting the model to a fixed finite type catalogue could also change the characterization, since the theorem is proved on the broader single-peaked domain.

The weakest point is decisive for ChoCo’s scope: the paper studies axioms for outcomes as the finite population changes. Its natural continuous follow-up remains an axiomatic classification, and the induced evaluation task is simple. So Theorem 1 makes a credible case for a continuous-population *extension*, while supplying no valid computational anchor for a ChoCo mirror.

The case AGAINST (opponent, writing after the proponent)

Theorem 1 is the proponent’s strongest anchor, but it is not a computational result. It classifies choice correspondences by two axioms: efficiency and population-monotonicity. It states no algorithm, complexity bound, or hardness result. That is decisive for a ChoCo mirror: the theorem itself supplies no computational question to continuize.

The proposed measure-valued follow-up is nevertheless sensible as an axiomatic extension. For rational, finite-support masses, it is exactly the finite-population model in different notation: scale the masses to integer cohort sizes, apply Theorem 1, and scale back. The target set rule then depends on the extreme peaks in the support. Evaluating a supplied rule takes \(O(\tau)\) peak comparisons. Neither task opens a complexity problem like the ones ChoCo studies. This is not an objection that the theorem’s answer stays the same; it is that the theorem classifies rules rather than posing a computational task.

A genuinely non-atomic population could make a separate question: define solidarity for incumbents almost everywhere, and decide whether the rule should use essential support endpoints rather than the finite support’s extrema. That may merit an axiomatic study, but the paper gives no computational formulation or input representation for it. Adding those would create a new computational problem rather than mirror one of the paper’s results. The paper’s real-line locations and compact outcome sets are continuous outcomes; they do not make its society continuous.

So the case against is strongest at the ChoCo boundary, not at the level of modelling plausibility. A continuous population version of this paper is worth considering as an axiomatic extension, but the proposed anchor does not support a worthwhile computational mirror. This does not rule out an independently invented computational problem in public-facility location; it means that problem would need its own motivation and anchor.
