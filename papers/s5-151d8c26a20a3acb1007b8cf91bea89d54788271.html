The continuous mirror question

Given a finite task set \(I\) and a finite support \(T\) of worker types, where each type \(t\) has a nonempty task bundle \(A_t\subseteq I\) and positive rational mass \(\mu_t\), find a minimum-cardinality set \(S\subseteq I\) such that \(S\cap A_t\ne\varnothing\) for every \(t\in T\).

The model it lives in

The society is a distribution \(\mu\) over supported worker types, each type being the complete task bundle \(A_t\subseteq I\); the supervisor chooses an indivisible inspection set \(S\subseteq I\) minimizing \(|S|\), subject to covering every positive-mass type. For full coverage, masses affect the instance only through which types have positive mass.

What the mirror covers

The mirror covers Theorem 9's full-coverage task-selection result; it leaves the incentive and equilibrium guarantees, hierarchy information bounds, heterogeneous-proficiency results, and quantitative-task results unmirrored.

Open questions for a prover

  • For a target covered mass \(q\in(0,1]\), what is the complexity and approximability of finding a minimum-cardinality \(S\subseteq I\) such that \(\sum_{t:S\cap A_t\ne\varnothing}\mu_t\ge q\)?
  • How do exact, approximation, or parameterized algorithms for full coverage depend on \(|I|\), \(|T|\), and the largest bundle size?

The case FOR (proponent)

The strongest case is a narrow one: the paper’s Theorem 9, proved in the paper, says that the Supervisor Assignment problem is NP-hard. Given a fixed worker–task assignment graph, the problem is to choose the smallest set \(S\) of tasks to inspect so that every worker is assigned at least one task in \(S\). The paper proves this by reducing Vertex Cover: make each graph vertex a task and each graph edge a worker assigned to its two endpoint tasks. A set of inspected tasks covers every worker exactly when it is a vertex cover.

A plausible continuous mirror is Mass-Assignment Supervisor Selection. Let \(I=\{1,\ldots,m\}\) be indivisible tasks. A worker type \(t\) is a nonempty subset \(A_t\subseteq I\): the exact bundle of tasks assigned to each worker of that type. The instance gives a finite support \(T\), with positive rational masses \(\mu_t\) summing to \(1\). Assume the workers share the verification parameters in the paper’s assignment-selection problem. Selecting task \(i\) for inspection verifies all workers whose type includes \(i\).

The question is: find a minimum-cardinality \(S\subseteq I\) such that every positive-mass type is covered:

\[ \min |S| \quad\text{subject to}\quad S\cap A_t\ne\varnothing \quad\text{for every }t\in T. \]

The solution is the selected task set \(S\). This is the paper’s \(p=1\) case: the supervisor must reach every worker. The mirror changes the population representation—repeated workers with the same task bundle become a mass—not the task-selection question.

The regime I have in mind is a large peer-grading or auditing platform that reuses assignment bundles across course sections or cohorts. Many reviewers receive the same bundle of standardized items; the number \(N\) of reviewers is much larger than the number \(\tau=|T|\) of distinct bundles. For instance, in the Vertex Cover reduction, give each edge type \(e=\{u,v\}\) mass \(1/|F|\), with \(A_e=\{u,v\}\). The continuous problem is then exactly Vertex Cover on the original graph. Each edge type could also represent arbitrarily many identical reviewers in a finite cohort, so the hardness persists when \(N\gg\tau\). It is driven by the task-incidence structure, measured by \(m\) and \(\tau\), rather than by the headcount.

I expect hardness to transfer: Mass-Assignment Supervisor Selection is NP-hard even when every type contains exactly two tasks and all type masses are equal. Every discrete instance of the paper’s problem also maps directly to a distribution by grouping workers with identical task bundles and assigning each group its fraction of the workforce. The feasible task sets, and hence the optimum, are unchanged. This covers Theorem 9’s task-selection result; it does not purport to mirror the paper’s incentive guarantees, equilibrium results, or hierarchy-depth claims. Natural follow-up questions include the minimum inspection set needed to cover a target mass \(p<1\), and how approximation or parameterized algorithms depend on \(m\), \(\tau\), and the largest bundle size.

The authors would likely recognize this as their problem: their theorem already studies task selection on a fixed assignment graph, and grouping identical worker neighborhoods preserves its objective and constraints. The weakest point is that, for full coverage, the numerical masses do not affect the answer—only whether a type has positive mass. This is population continuization, but it does not create a new fractional optimization problem or soften the task-selection hardness. The regime also needs genuine bundle reuse; where nearly every worker has a unique assignment, \(\tau\) approaches \(N\) and the compression buys little.

The case AGAINST (opponent, writing after the proponent)

The negative case cannot begin with “there is no computational result”: Theorem 9 is a genuine NP-hardness result about choosing tasks for the supervisor to inspect.

Its proposed mirror is mathematically sound. Let a type \(t\) have task bundle \(A_t\). For full coverage, selecting \(S\) requires \(S\cap A_t\ne\varnothing\) for every type with \(\mu_t>0\). The strongest objection is that the masses then do no work: the task-incidence structure determines the optimization, and changing the workforce size by copying those types leaves the instance unchanged. The continuous society supplies a distribution over constraints; the hard part remains discrete task selection. The scenario also requires many workers to receive exactly the same bundle of named tasks, which is plausible for reused standardized assignments but narrower than crowdsourcing generally.

That makes the mirror a weak case for continuization’s distinctive payoff. It does not defeat the mirror under ChoCo’s criteria, though: full-coverage set selection is exactly the paper’s problem, and hardness transferring from the incidence structure is an accepted outcome.

The best repair makes the masses matter. For a target coverage fraction \(p\), ask for

\[ \min |S| \quad\text{such that}\quad \sum_{t:S\cap A_t\ne\varnothing}\mu_t\ge p. \]

That is a natural population version of the paper’s verification-probability setting and its discussion of covering at least a target number of workers. Reused task bundles across large cohorts provide a plausible regime. Its relation to weighted partial set cover does not make the question inadmissible; a transferred hardness result would still be a result.

So the strongest honest case against is about research priority: full coverage barely uses the continuous masses, and the mass-sensitive version leaves the central task choice discrete. But neither point rules out a worthwhile mirror. The proposed anchor survives, and the negative case is weak.
