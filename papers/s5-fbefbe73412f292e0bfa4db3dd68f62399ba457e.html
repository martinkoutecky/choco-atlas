The continuous mirror question

Given a finite type set \(T\), rational masses \(\mu_t>0\) summing to \(1\), entitlements \(w_t>0\), integer-bundle utility tables \(f_t(r)\), and rational per-capita supply \(q\), compute the maximum \(\lambda\) and an attaining allocation \(x_{t,r}\ge 0\), where \(x_{t,r}\) is the mass of type \(t\) receiving exactly \(r\) indivisible goods. Require \(\sum_r x_{t,r}=\mu_t\) for every \(t\), \(\sum_{t,r} r x_{t,r}=q\), and maximize \(\min_{t,r:x_{t,r}>0} f_t(r)/w_t\).

The model it lives in

A high-multiplicity society of recipients, with each type fully specified by its entitlement and utility curve. Mass is distributed over integer bundle sizes, and the objective maximizes the least utility-to-entitlement ratio. With explicit tables through \(R=\lceil q/\min_t\mu_t\rceil\), the threshold test is \(\sum_t\mu_t b_t(\lambda)\le q\), where \(b_t(\lambda)=\min\{r:f_t(r)/w_t\ge\lambda\}\); remaining supply can be distributed by splitting type mass across adjacent bundle sizes.

The objection that survived

The explicit utility tables can require \(\Theta(q/\min_t\mu_t)\) entries, so the runtime is polynomial in table length but not necessarily in support size and binary encoding length; the proponent flags this compact-encoding issue but does not resolve it.

What the mirror covers

The mirror covers Theorem 1’s weighted maximin allocation question. It leaves the paper’s results on weighted Leximin, WEQX, WMMS, deficit minimization, and scenarios with multiple good types outside its scope.

Open questions for a prover

  • Can compact utility representations yield runtime polynomial in \(\tau\) and the binary input length when \(\min_t\mu_t\) is very small?
  • Which standard encodings of utility curves make threshold evaluation efficient without listing all bundle values through \(R\)?

The case FOR (proponent)

The strongest positive mirror is the paper’s weighted Rawlsian allocation result. It preserves the central question—how to allocate identical indivisible goods so that the least advantaged recipient does as well as possible—while making the recipient population a distribution over complete types.

Anchor: Theorem 1, proved in this paper. For a positive integer \(m\) and a \((1;F,W)\)-scenario with utility functions \(f_i\) surjective onto \([0,f_i(m)]\), the theorem gives an \(O(mn\log n)\)-time algorithm that finds a weighted maximin allocation, for each number \(t\le m\) of goods. Here “weighted maximin” means maximizing \(\min_i f_i(x_i)/w_i\), with \(w_i\) the recipient’s entitlement. The theorem is an algorithmic result, not a hardness result.

I would name the mirror Continuous Weighted Rawlsian Allocation. Its input is a finite support \(T\) of recipient types, with \(\tau=|T|\). Each type \(t\) has rational mass \(\mu_t>0\), where \(\sum_t\mu_t=1\), entitlement \(w_t>0\), and strictly increasing utility function \(f_t(r)\) for receiving \(r\) goods. The instance also gives a rational supply \(q\) of goods per person. A solution is a set of masses \(x_{t,r}\ge 0\): \(x_{t,r}\) is the mass of type \(t\) receiving exactly \(r\) goods. It must satisfy
\[ \sum_r x_{t,r}=\mu_t\quad\text{for every }t, \qquad \sum_{t,r} r x_{t,r}=q. \]
The goods remain indivisible for every individual; only the population mass assigned to each integer bundle is continuous. The objective is to maximize
\[ \min_{(t,r):\,x_{t,r}>0}\frac{f_t(r)}{w_t}. \]
For a finite computational input, the functions can be given by exact value tables up to \(R=\lceil q/\min_t\mu_t\rceil\): an optimal solution exists with no one receiving more than \(R\) goods.

A natural regime is a cloud platform allocating identical compute units to millions of tenant accounts or jobs. Workload template and entitlement determine a recipient’s type; the population may have millions of recipients but only dozens or hundreds of distinct types. Mass records the fraction in each type, and \(q\) is the available compute supply per recipient. This is a plausible high-multiplicity setting, and the mirror keeps the paper’s goods, utility curves, entitlements, and maximin objective.

I expect this explicit-table version to be tractable. For a candidate welfare level \(\lambda\), type \(t\) needs at least
\[ b_t(\lambda)=\min\{r:f_t(r)/w_t\ge\lambda\} \]
goods per person. The level is feasible exactly when \(\sum_t\mu_t b_t(\lambda)\le q\). Scanning the threshold values \(f_t(r)/w_t\) gives the optimum; any remaining supply can be assigned by splitting a type’s mass between adjacent integer bundle sizes. This gives a running time polynomial in the table size, \(\tau\), and the bit length \(L\). Whether common compact representations of utility curves allow a bound polynomial in \(\log R\) is a further question.

There is also a useful bridge to the discrete problem. If the rational masses and supply have a common denominator \(N\), they describe a finite population of \(N\) people and \(Nq\) goods. Both versions have the same maximin value: reaching \(\lambda\) requires giving every person of type \(t\) at least \(b_t(\lambda)\) goods, so feasibility is the same weighted threshold inequality. The continuous solution therefore does not rely on giving anyone a fractional bundle. It is a mass description of recipients receiving whole bundles.

The scope here is deliberately just Theorem 1’s weighted maximin result. I would not use the paper’s unnumbered observation that minimizing total weighted deficit is NP-hard as an anchor: it is not a numbered result, and it concerns general scenarios rather than the identical-goods result chosen here. The supplied paper has no numbered computational hardness result to prefer over this algorithmic anchor. Nor does this mirror claim to cover the paper’s WMMS, Leximin, WEQX, or deficit results.

The weakest point is that this is an algorithmic anchor, so it does not showcase discrete hardness disappearing in the continuum. In fact, the threshold argument predicts the same maximin value on rational finite realizations. That makes the mirror less dramatic as a complexity separation, but it supports the case that the authors would recognize it: the allocation question, the individual goods, and the fairness objective all remain intact.

The case AGAINST (opponent, writing after the proponent)

Theorem 1 is the proponent’s strongest anchor, and I don’t see a sound way to rule it out across all plausible scenarios. The proposed model is coherent: define a type by its full utility curve and entitlement, let \(x_{t,r}\) record the mass of that type receiving \(r\) whole goods, and maximize the least utility-to-entitlement ratio. Repeated cloud workloads with the same service needs and entitlement are a plausible high-multiplicity regime. An objection that the objective ignores how small a positive type mass is would change the Rawlsian question: the least advantaged cohort matters even when it is rare. Replacing the minimum with a population quantile would be a different mirror.

The strongest reservation is about the claimed computational compression. The paper counts goods \(m\) and treats evaluation of arbitrary computable utility functions as free. In the mirror, an explicit table may need entries up to \(R\), which can grow like \(1/\min_t\mu_t\); a mass as small as \(1/N\) can therefore make the table length grow with \(N\), even when its binary encoding is short. The table algorithm is polynomial in its input size, but that alone does not establish an algorithm polynomial in support size and bit length. With succinct utility descriptions, runtime depends on the representation and evaluation model.

That limitation does not defeat the better version of the mirror. For a candidate welfare level \(\lambda\), each type needs \(b_t(\lambda)=\min\{r:f_t(r)/w_t\ge\lambda\}\) goods per person, and feasibility is \(\sum_t\mu_t b_t(\lambda)\le q\). A suitable compact representation could make these thresholds efficient to compute, yielding a meaningful high-multiplicity problem. The resulting algorithm may be simple, but simplicity is not a reason to reject a well-posed continuization under the programme’s stated standards.

So the negative case is weak. The representation caveat limits the proponent’s complexity claim as stated; it does not show that no worthwhile mirror exists. This anchor survives.
