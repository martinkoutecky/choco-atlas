The continuous mirror question

Given a finite set of preference types \(T\) with rational masses \(\mu_t>0\) summing to \(1\), and indivisible public object classes \(J\) with rational per-capita supplies \(q_j\), compute an assignment \(x_{tj}\ge 0\), including the null object \(o^*\), with \(\sum_{j\in J\cup\{o^*\}}x_{tj}=\mu_t\) and \(\sum_{t\in T}x_{tj}\le q_j\), such that no feasible reassignment weakly improves every agent and strictly improves a positive mass.

The model it lives in

A nonatomic, unit-mass public-ownership assignment market: each type \(t\) has mass \(\mu_t\) and a common strict ranking; each recipient gets one indivisible object or \(o^*\); class \(j\) has supply \(q_j\). The variables \(x_{tj}\) represent mass assigned by type and class. Maximizing \(\sum_{t,j}x_{tj}u_t(j)\) for ranking-consistent utilities \(u_t\) yields a Pareto-efficient assignment.

The case FOR (proponent)

The paper has no named result classifying a computational problem as polynomial-time solvable, NP-hard, or otherwise. Its best algorithmic anchor is Proposition 5, proved in this paper. In public-ownership economies, it says that the outcomes of YRMH-IGYT, the refined exclusion core, the exclusion core, the strong core, the rectified core, and the effective core all coincide. The paper further explains that this common set is the set of Pareto-efficient allocations, and that varying the YRMH-IGYT order can find all of them. This is a constructive characterization, but the paper gives no running-time bound.

A continuous mirror I would stand behind is Public-Ownership Type-Mass Efficient Assignment. Its instance is a unit-mass society with a finite support \(T\) of preference types, rational masses \(\mu_t>0\) summing to \(1\), and a finite set \(J\) of indivisible object classes. Each class \(j\) has rational supply \(q_j\) per capita: in an \(N\)-person finite version there are \(Nq_j\) physical copies. Every agent ranks the classes and the null object \(o^*\) strictly, and every object is publicly owned by the whole society. The question is to return an allocation in which every person receives one indivisible object or \(o^*\), no class’s supply is exceeded, and no feasible reassignment makes every agent weakly better off while making a positive mass strictly better off.

The decision variables can be type-level masses \(x_{tj}\), with
\[ \sum_{j\in J\cup\{o^*\}} x_{tj}=\mu_t,\qquad \sum_{t\in T}x_{tj}\le q_j\quad(j\in J). \]
Here \(x_{tj}\) means that this much mass of type \(t\) receives an object of class \(j\); it does not give any individual a fractional object. A feasible matrix can be implemented by assigning whole objects to the corresponding subsets of each type. The problem is tractable: choose ordinal utilities \(u_t(j)\) consistent with each ranking and maximize \(\sum_{t,j}x_{tj}u_t(j)\) subject to those constraints. Any Pareto improvement would strictly increase this objective. The LP has size polynomial in \(\tau\), \(|J|\), and the rational input length, so I expect this mirror to be Class A.

The regime is a large membership cooperative allocating standardized units from a commonly owned stock—for example, a housing cooperative with many members, a finite number of unit classes, and only a moderate number of distinct rankings. The types are complete for this version of the problem: members of a type have the same ranking, and everyone has the same public ownership rights. The population may be very large relative to \(\tau\), while supplies grow with population. This is a continuous population model whose agents still receive integral bundles; the fractions are masses of agents assigned to each class.

This is a deliberately narrow mirror of Proposition 5’s public-ownership case. It preserves the underlying assignment question and uses a case the paper explicitly studies, so I expect the authors to recognize it as their problem’s continuous form. It does not mirror the paper’s central contribution on intricate co-ownership. Nor does this anchor set up the programme’s usual “does discrete hardness dissolve?” question: the paper supplies no hardness result to carry into the continuum. The further questions are whether the paper’s equality of core concepts and Pareto efficiency survives under a precise measure-based definition of blocking, how the continuous allocations relate to finite high-multiplicity instances, and whether a similarly credible type-based model can retain the article’s general co-ownership rights. My weakest point is the same boundary: this is a strong mirror of an explicit special-case result, not of the new general refinement.

The case AGAINST (opponent, writing after the proponent)

The strongest objection is that this paper supplies no numbered complexity result to continuize. Proposition 5 is the closest anchor: it characterizes the public-ownership cores as the Pareto-efficient allocations and says YRMH-IGYT can find them. But it proves neither a complexity bound nor a classification. Theorem 1 and Lemma 3 likewise establish solution properties and constructive existence, not computational complexity. So the proposed task would add a computational question to the paper; it would not continue a computational result the paper established.

The public-ownership choice also removes the paper’s central ownership tension. For every proper coalition \(C\), \(\w(C)=\varnothing\). Exclusion rights therefore do no work, and a self-feasible group can leave with assignments only if those assignments are all \(o^*\). Scaling object supplies with population keeps allocation nontrivial, as the programme permits, but the resulting question concerns type-mass Pareto efficiency rather than the paper’s consistency and co-ownership claims.

That is a case against prioritizing this as a ChoCo mirror, not a decisive refutation. The proposed mass-assignment question is coherent, per-capita supplies are an allowed co-modification, and the paper explicitly includes public ownership. I can’t honestly say this anchor fails under the programme’s broad gate; if Proposition 5’s constructive characterization counts as enough, it survives. The negative case is weak precisely there: a stronger type-based co-ownership model might also be plausible, and this paper gives us no basis to rule out its continuous mirror in every scenario.
