The continuous mirror question

Given a finite support \(T\) of complete compatibility types, rational masses \(\mu_t>0\) with \(\sum_t\mu_t=1\), and compatible exchange patterns \(\kappa\) of length at most fixed \(L=3\), solve the mass cycle-packing LP \(\max\sum_{\kappa}(\sum_t a_{\kappa t})z_\kappa\) subject to \(\sum_{\kappa}a_{\kappa t}z_\kappa\le\mu_t\) and \(z_\kappa\ge0\). For every type \(t\), compute the exact interval \([\underline q_t,\overline q_t]\) of \(q_t(z)=\sum_\kappa a_{\kappa t}z_\kappa/\mu_t\) over the optimal face, and output the partition into types with \(q_t=1\) always, \(q_t=0\) always, or \(0<q_t<1\) for some optimum.

The model it lives in

Types are complete compatibility neighborhoods for patient-donor pairs, with mass \(\mu_t\). Decision variables \(z_\kappa\) assign mass to integral exchange-cycle patterns, subject to type capacities; the objective maximizes transplanted mass. The computational output is the optimal-face range of each type's selected fraction and the induced always/never/mixed partition.

The objection that survived

The full compatibility type may be so individualized in realistic kidney exchange that \(\tau\ll N\) is a specialized template regime rather than a broadly natural application.

fatal: False

What the mirror covers

The mirror covers Proposition 1 for bounded-cycle kidney exchange, including optimal mass packing and the type-level always/never/mixed partition. It leaves the paper's leximin, Nash, RSD, cardinal-preference, near-optimal, axiomatic, and scheduling results untouched.

Open questions for a prover

  • Can the type-level partition and its optimal-face intervals be rounded exactly or approximately to finite repeated-type exchanges?
  • What pricing or hardness boundary appears when \(L\) is variable or compatibility patterns are given implicitly?
  • Can leximin, Nash, or RSD distributions be implemented directly over the typed mass model?

The case FOR (proponent)

My strongest honest case is a narrow but credible one: a continuous, high-multiplicity kidney-exchange mirror of Proposition 1, restricted to bounded exchange cycles. I would not claim that this paper supplies a numbered NP-hardness theorem: its NP-hardness statements for kidney exchange and total tardiness are unnumbered remarks citing earlier work. Proposition 1 is the paper’s only clear named computational anchor.

Proposition 1 (proved in this paper) states: given an ILP \(\xi\in\Xi\), one can partition its agents into \(\mathcal{Y}\), \(\mathcal{N}\), and \(\mathcal{M}\)—agents selected in every optimum, no optimum, or some but not all optima—by solving at most \(n+1\) ILPs that differ from \(\xi\) in at most one constraint. The proof first solves \(\xi\), obtaining \((\bm{x}^*,\bm{y}^*)\). For each agent \(i\), it adds \(x_i=1-x_i^*\). If the modified problem is infeasible or has a strictly smaller optimum, \(i\) belongs to \(\mathcal{Y}\) or \(\mathcal{N}\), according to \(x_i^*\); otherwise \(i\in\mathcal{M}\). The paper also notes that bookkeeping can reduce the number of calls.

My lead problem would be Typed Maximum-\(L\)-Exchange Partitioning\(_\infty\), with fixed \(L=3\), matching the paper’s kidney-exchange experiments.

A type \(t\in T=\{1,\ldots,\tau\}\) is a complete compatibility-relevant description of a patient-donor pair: two pairs of the same type have identical compatibility with every type, the same transplant value, and the same constraints. The society is a rational distribution \(\mu\in\mathbb{Q}_{\geq0}^{\tau}\), \(\sum_t\mu_t=1\), where \(\mu_t\) is the mass of pairs of type \(t\). The intended regime is a large clearinghouse with many repeated clinical types and \(\tau\ll N\), rather than a small exchange containing mostly idiosyncratic pairs.

Let \(\mathcal{K}\) be the finite set of compatible cycle patterns of length at most \(L\). For \(\kappa\in\mathcal{K}\), let \(a_{\kappa t}\) be the number of type-\(t\) pairs used by that pattern. The action is a mass assignment \(z_\kappa\geq0\), where \(z_\kappa\) is the mass of cycles of pattern \(\kappa\). It must satisfy

\[ \sum_{\kappa\in\mathcal{K}}a_{\kappa t}z_\kappa\leq \mu_t \]

for every type \(t\). The objective is to maximize transplanted mass,

\[ \max \sum_{\kappa\in\mathcal{K}}\left(\sum_t a_{\kappa t}\right)z_\kappa. \]

Every unit of mass still receives an integral bundle—a cycle of length at most \(L\). Only the population aggregate is fractional.

For an optimal schedule \(z\), define the selected fraction of type \(t\) by

\[ q_t(z)=\frac{\sum_{\kappa}a_{\kappa t}z_\kappa}{\mu_t}. \]

The continuous analogue of Proposition 1 asks for the partition

\[ \mathcal{Y}_\infty=\{t:q_t(z)=1\text{ for every optimal }z\}, \]

\[ \mathcal{N}_\infty=\{t:q_t(z)=0\text{ for every optimal }z\}, \]

and

\[ \mathcal{M}_\infty=T\setminus(\mathcal{Y}_\infty\cup\mathcal{N}_\infty). \]

Equivalently, the output may include the exact interval \([\underline q_t,\overline q_t]\) of attainable selection fractions over the optimal face for every type. A type is always selected when \(\underline q_t=1\), never selected when \(\overline q_t=0\), and mixed otherwise.

This is a recognizable mirror of the paper’s question. The original kidney-exchange ILP has patient variables \(x_v\), cycle variables \(y_c\), and objective “maximize the number of transplants.” The mirror keeps exactly that object, but replaces repeated named pairs by type mass and repeated cycle patterns. If \(\mu_t=n_t/N\), clearing denominators recovers a finite exchange with \(n_t\) cloned pairs of type \(t\); conversely, normalized finite repeated-type instances produce such mass schedules. A further common cloning factor realizes any rational schedule exactly.

I expect this problem to be Class A for fixed \(L\). There are \(O(\tau^L)\) cycle patterns, so the optimal schedule is a rational linear program. After solving it once, compute \(\underline q_t\) and \(\overline q_t\) by optimizing each \(q_t\) over the optimal face, requiring at most \(1+2\tau\) LPs. Thus the continuous analogue replaces Proposition 1’s \(n+1\) ILP calls by a number of LP calls depending on the number of types, not the population size. If \(L\) is part of the input, the pattern space becomes exponential and a genuine pricing or column-generation boundary appears.

The weakest point is that this is not a literal one-constraint translation of Proposition 1. Its proof relies on flipping an individual binary variable through \(x_i=1-x_i^*\); a type-level selection fraction \(q_t\) is not binary. I therefore use min/max optimization over the optimal face instead. Moreover, the paper’s result concerns named-agent classifications, while this mirror classifies anonymous types. That is a real semantic modification, but it is the unavoidable high-multiplicity version of “sometimes selected”: individual identities disappear, while integral transplantation remains intact.

The scope is deliberately limited. This mirrors Proposition 1 on the kidney-exchange subproblem, not the whole fair-integer-programming framework. It does not yet establish a continuous leximin, Nash, or RSD theorem. Natural follow-up questions are whether those distributions admit type-level implementations, whether finite-population rounding preserves the partition, and whether variable cycle length or richer compatibility structures create Class B or Class C hardness.

The case AGAINST (opponent, writing after the proponent)

The strongest objection comes before the modeling. Proposition 1 is not really a complexity result: it bounds the number of calls to an arbitrary ILP solver by \(n+1\), while each call may itself be NP-hard. The paper gives no end-to-end polynomial, parameterized, approximation, or hardness theorem for this procedure. Its other named results are axiomatic or expressiveness results; the complexity claims about kidney exchange and scheduling are literature summaries, not results proved here. Thus the paper may have no qualifying computational anchor at all.

Even granting Proposition 1 as an anchor, the proposed mirror changes its central object. Proposition 1 classifies named binary variables by asking whether an individual can be flipped while preserving optimality. In the proposed model, individual variables disappear. The quantities

\[ \underline q_t=\min_{z\in Z^\star}q_t(z),\qquad \overline q_t=\max_{z\in Z^\star}q_t(z) \]

are simply coordinate extrema over an optimal LP face. Computing them by \(1+2\tau\) LPs is a standard sensitivity calculation, not the continuous version of the paper’s individual-selection problem. It no longer addresses the paper’s motivating concern: how to control the probability with which a particular agent receives a transplant.

The apparent high-multiplicity regime is also much less natural than the proponent suggests. A kidney-exchange type must encode all compatibility-relevant information. If compatibility is genuinely pair-specific—because of crossmatching, sensitization, donor-specific antibodies, and similar data—then two pairs with the same coarse clinical description are not the same type. Refining types until they are genuinely indistinguishable makes \(\tau\) track the number of distinct compatibility neighborhoods, so the claimed \(\tau\ll N\) regime largely disappears. Coarse types yield an attractive finite-template model, but that is a stylized blow-up of a compatibility hypergraph rather than a faithful high-multiplicity kidney-exchange population.

The proponent’s strengthened formulation does preserve an important feature: each infinitesimal unit receives an integral cycle, while only aggregate mass is fractional. So this is not defeated merely by calling it “fractional.” If one accepts a finite compatibility template with many cloned pairs, the LP is a coherent population model. But that concession exposes the remaining problem: it is a new typed cycle-packing problem whose connection to Proposition 1 is only that both inspect optimal solutions. Allowing variable cycle length or richer compatibility types might create an interesting pricing problem, but its difficulty would arise from cycle packing, not from the paper’s named computational contribution.

A further rescue would retain a lottery over optimal integral schedules and ask for type-level selection probabilities. In an atomless population this adds little: a mass fraction can be assigned deterministically to each cycle pattern. If individual fairness inside a type matters, the type must be refined into distinguishable subtypes, which removes the very anonymity that made the continuum useful. Thus the continuous model either erases the paper’s fairness issue or restores individual multiplicity.

This is not an airtight universal negative. If the programme accepts deliberately constructed compatibility templates as sensible kidney-exchange regimes, the proposed LP is a legitimate high-multiplicity question, and the negative case should not pretend otherwise. My honest conclusion is narrower: the paper supplies no strong computational anchor, and the proponent’s model is a plausible new typed packing problem but a weak mirror of Proposition 1. On the stated standard, that is insufficient for a green verdict.
