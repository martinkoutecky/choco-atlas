The continuous mirror question

Given a candidate set \(C\) and a finite-support distribution \(\mu\) over complete rankings, with positive support \(S=\{t:\mu_t>0\}\), decide whether there is a finite set of rankings \(U\supseteq S\) and a tree on \(U\) such that the profile containing one copy of each ranking in \(U\) is single-crossing on that tree. If so, return \(U\) and a tree witness.

The model it lives in

Each complete ranking is a voter type with rational mass \(\mu_t\); the instance is encoded by its positive support and masses. By duplicate invariance, recognition depends only on the support \(S\); the witness is a completing ranking set \(U\) and its single-crossing tree.

What the mirror covers

The mirror covers Corollary 1’s recognition algorithm and Theorem 1’s support-closure computation. It leaves the elicitation query bounds in Theorems 3–5 and the other consequences for voting rules aside.

The case FOR (proponent)

The strongest case is the paper’s structural recognition problem. It admits a clean high-multiplicity interpretation, though a deliberately modest one: the continuous masses express a large society, while the recognition question depends only on which preference types have positive mass.

Consider a large consultation in which millions of residents rank a fixed set of, say, six policy options. Standardized ballots or shared preference templates could leave only a few hundred distinct rankings. A type is one complete ranking; \(\mu_t\) is the fraction of residents with that ranking. People sharing a ranking are indistinguishable for the paper’s recognition problem. This is a plausible regime with large population size \(n\) and much smaller support size \(\tau\).

My lead anchor is Corollary 1, proved in this paper: *the problem of recognizing whether a profile is weakly single-crossing on trees is in P.* In full, given a profile \(P\), the algorithm decides whether \(P\) is a subprofile of some profile that is single-crossing with respect to a tree; when the answer is yes, the paper’s algorithm also returns a suitable tree. The proof uses Theorem 1, also proved here, together with Theorem 2, which is cited from Clearwater et al. [CPS15].

The corresponding problem, Continuous Weakly-Single-Crossing Recognition, is:

  • Instance: a candidate set \(C\) and a finite-support distribution \(\mu\) over complete rankings of \(C\), with each positive mass given as a binary rational.
  • Question: writing \(S=\{t:\mu_t>0\}\), is there a finite set of rankings \(U\supseteq S\) and a tree on \(U\) such that the profile of rankings in \(U\) is single-crossing on that tree?
  • Solution: a yes/no answer; for yes, \(U\) and its tree give a witness.

This is the paper’s weakly single-crossing question applied to a continuous society. The paper’s Lemma 2 says duplicate preferences can be removed without changing whether a profile is weakly single-crossing on trees. Thus the mirror’s dependence on support, rather than on the values of \(\mu_t\), is faithful to the original problem’s invariance under voter duplication. Its expected classification is tractable: the paper’s recognition algorithm runs in \(\mathrm{poly}(m,\tau)\) after grouping identical rankings, plus the cost of reading the rational masses, so \(\mathrm{poly}(m,\tau,L)\) for mass encoding length \(L\). The result does not need continuous optimization; its tractability comes from the paper’s structural insight and recognition algorithm.

A second, narrower question mirrors Theorem 1, proved here: *for every weakly single-crossing profile on trees, the triad-majority closure is single-crossing on trees; it is therefore the unique minimal single-crossing-tree completion, and can be computed in polynomial time with size at most \(|P|^3\).* In Continuous Tree-Closure Computation, the input is a distribution \(\mu\) promised to have weakly single-crossing support \(S\). The task is to output the unique inclusion-wise minimal set \(U\supseteq S\) whose rankings form a single-crossing profile on a tree. A tree witness can be included with the output. The expected classification is again tractable, in \(\mathrm{poly}(m,\tau,L)\); the paper’s bound becomes \(|U|\le\tau^3\). This is a promised completion problem, rather than a second general recognition problem.

I would not use Theorems 4 and 5 as continuous anchors. Their lower bounds concern exact elicitation through queries to individually indexed voters’ preferences. A distribution over types is a different input interface; mirroring those bounds would require inventing an oracle for recovering arbitrary rational masses. The proposed mirror therefore covers the paper’s weakly single-crossing recognition and closure results, not its elicitation results.

The weakest point is that the continuous masses do no work in either question: the answers depend only on the positive-mass rankings. That makes this a support-based high-multiplicity mirror, not a new mass-sensitive complexity phenomenon. Still, it is the paper’s own domain-recognition problem on a credible large-population regime, and duplicate invariance provides a direct reason the authors should recognize it as their problem. The natural follow-up questions—such as finding a minimum-mass completion or studying stability under mass changes—would be new questions, not results anchored by this paper.

The case AGAINST (opponent, writing after the proponent)

The strongest objection is that both proposed mirrors are support problems, not mass problems. Corollary 1 asks whether the rankings that occur can be extended to a single-crossing tree. Changing every positive mass while holding the support fixed leaves the answer unchanged. Theorem 1 has the same limitation: its closure outputs a set of rankings, with no masses for the added rankings.

There is a real mismatch here. The paper’s “sub-profile” operation adds voters. For normalized distributions, there is no direct mass-preserving version: if probability distributions \(\mu\) and \(\nu\) satisfy \(\mu_t\le\nu_t\) for every type, then both summing to \(1\) forces \(\mu=\nu\). To get a nontrivial analogue, one must ask only whether the support can be enlarged. That makes the recognition mirror a property of which types occur, while the closure mirror produces a hypothetical set of extra types whose population shares are unspecified. A question about the minimum mass to add or remove could use those shares, but it would be a different problem, not a result anchored by this paper.

That objection does not defeat the best version of the mirrors. Support-based recognition is coherent, and the paper’s Lemma 2 explicitly says duplicate preferences do not affect the domain property. A large society with many people sharing a relatively small set of rankings is plausible; the paper’s recognition result then gives a high-multiplicity algorithm in terms of the number of types. Assigning arbitrary masses to the closure’s added types is unnecessary if the task is to compute the paper’s inclusion-minimal support completion.

So the negative case is weak. The mass mismatch limits what these results say about population shares, but it does not show that the support-based questions are outside the programme or that the authors would reject them. Corollary 1 remains a worthwhile mirror, and the objection to Theorem 1 does not dislodge it.
