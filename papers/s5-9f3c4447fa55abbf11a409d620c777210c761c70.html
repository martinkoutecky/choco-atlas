The continuous mirror question

Given \(\tau\) agent types with rational masses \(\mu_t>0\), rational per-capita supplies \(q_j\) of \(m\) item types, rational additive values \(v_{tj}\), and type welfare coefficients \(a_t>0\) satisfying \(\sum_t \mu_t a_t=1\), choose a finite-support distribution of mass \(\lambda_{tB}\ge 0\) over integral bundles \(B\in\mathbb{Z}_{\ge 0}^m\). Require \(\sum_B\lambda_{tB}=\mu_t\) and \(\sum_{t,B}\lambda_{tB}B_j=q_j\). Assuming a positive-welfare feasible allocation exists, can an algorithm running in time polynomial in \(m,\tau\), and the binary input length \(L\) return such a distribution whose weighted NSW, \(\exp(\sum_{t,B}\lambda_{tB}a_t\ln(\sum_j v_{tj}B_j))\), is at least \(e^{-1/e}\) times the optimum?

The model it lives in

A unit-mass population has \(\tau\) complete agent types with masses \(\mu_t\); type \(t\) includes its value vector \(v_{tj}\) and welfare coefficient \(a_t\). Item type \(j\) has per-capita supply \(q_j\). The decision variables are masses \(\lambda_{tB}\) assigned to integral bundles \(B\); the objective is to maximize \(\exp(\sum_{t,B}\lambda_{tB}a_t\ln(\sum_j v_{tj}B_j))\) subject to the type-mass and supply constraints.

What the mirror covers

The mirror covers the weighted NSW approximation result in Theorem 1.1. It leaves aside the unweighted program equivalence and EF1-gap results, and the two scheduling applications.

Open questions for a prover

  • Does a type-aggregated version of the paper’s convex program and rounding analysis achieve the stated approximation against the continuous integral-bundle optimum in time polynomial in \(m,\tau,L\)?
  • Is the \(e^{1/e}\) approximation factor tight for this continuous problem?

The case FOR (proponent)

The strongest mirror is the paper’s main weighted NSW result, Theorem 1.1. Theorem 1.1, proved in this paper, says that its convex program CP\(_{\mathrm{NSW}}\) has integrality gap at most \(e^{1/e}\), and that an efficient rounding algorithm, given a solution \(x\), returns an allocation whose weighted NSW is at least \(e^{-1/e}\) times the value of \(x\). The program maximizes \(\sum_i w_i f_i(x_i)\), subject to assigning each item fractionally in full and giving each agent fractional total at least \(1\). For each agent, \(f_i(x_i)=\sum_{j:v_{ij}>h}x_{ij}\ln(v_{ij}/h)+\ln h\), where \(h\) satisfies \(\sum_j\min\{v_{ij},h\}x_{ij}=h\). The paper also shows how to approximate this program with a polynomial-size LP. The theorem is an algorithmic anchor; the introduction’s discrete NP-hardness claims are citations, not numbered hardness results proved in this paper.

Here is the continuous problem I would hand to a prover: Continuous-Type Weighted NSW. An instance has \(m\) item types, \(\tau\) agent types, rational masses \(\mu_t>0\) summing to \(1\), rational per-capita supplies \(q_j\), and a rational additive value \(v_{tj}\) for each type-item pair. A type records the agent’s complete value vector and welfare weight \(a_t>0\), normalized so \(\sum_t\mu_t a_t=1\). A feasible solution is a finite list of nonnegative masses \(\lambda_{tB}\), where \(B\in\mathbb Z_{\ge0}^m\) is an integral bundle assigned to type \(t\). Require \(\sum_B\lambda_{tB}=\mu_t\) for every \(t\), and \(\sum_{t,B}\lambda_{tB}B_j=q_j\) for every item type \(j\). Its value is \(\exp\!\big(\sum_{t,B}\lambda_{tB}a_t\ln(\sum_j v_{tj}B_j)\big)\). The question is: given this instance, find a feasible allocation measure with value at least \(e^{-1/e}\) times the optimum, in time polynomial in \(m,\tau\), and the binary input length \(L\), with no dependence on the expanded population size. The output is the masses and their integral bundles.

A plausible regime is a large population of households with a small catalogue of complete valuation and welfare-weight profiles, sharing repeated goods: \(N\) agents but only \(\tau\ll N\) types, with \(Nq_j\) copies of item type \(j\). Every individual still receives whole items; only the assignment of bundles across the population is a measure. This is a high-multiplicity version of the paper’s allocation problem, with per-capita supplies scaling along with the population. It preserves the question the authors study—allocating indivisible goods under additive values to maximize weighted Nash welfare—and the authors should recognize it as their problem in a repeated-types regime.

I expect a Class A result for the stated approximation. Theorem 1.1 supplies a concrete target and suggests aggregating its convex program by type, then carrying its rounding argument over to allocation masses. That extension needs proof: Theorem 1.1 does not itself establish the guarantee against this continuous problem’s optimum, so I would present the factor as the proposed result, not as a consequence already proved in the paper. Further questions include whether the continuous optimum can be computed exactly, whether the \(e^{1/e}\) factor remains tight after type aggregation, and how the algorithm depends on \(\tau\).

The weak point is that the type count may be large when value vectors or welfare weights are highly individualized; then this regime offers little compression. Also, the continuous optimum is an allocation over integral bundles, and its relation to the paper’s compact program must be established rather than assumed. Those limitations narrow the regime and the proof obligation, but they do not undermine the mirror for populations with few repeated complete types.

The case AGAINST (opponent, writing after the proponent)

I cannot make a persuasive universal negative against this anchor. Theorem 1.1 is a named algorithmic result: it gives an integrality-gap bound, an efficient rounding algorithm, and a way to solve the convex program approximately with a polynomial-size LP. So the “no computational result to mirror” objection does not apply.

The strongest objection is that the literal population limit degenerates. With a fixed finite set of \(m\) items and a population growing without bound, per-capita supply tends to zero; almost everyone gets an empty bundle, and Nash welfare collapses. To avoid that, the proposed mirror scales supplies with population size and treats goods as repeatable types. That changes the resource regime, and it rules out settings built around unique items. But the programme explicitly allows this kind of co-modification, and repeated goods with a small catalogue of valuation types are plausible. The objection narrows the mirror; it does not defeat it.

Nor does aggregation appear to discard information the objective needs. A type can include an agent’s entire value vector and welfare weight. For type \(t\), the paper’s function \(f_t\) can be applied to a per-agent fractional allocation \(x_t\), with shared supplies constrained by \(\sum_t \mu_t x_{tj}=q_j\). The resulting question—whether the approximation guarantee and rounding extend to allocation masses—is well posed. The proof is not in the paper, but that is a proof obligation, not a reason the mirror lacks value.

Individualized valuations can make the number of types large, but that only weakens the regime’s compression; it does not rule out populations with few repeated types. So the honest negative case is weak: the literal limit fails, while the stronger mirror survives the objection. I cannot justify the claim that no worthwhile continuous mirror exists.
