The continuous mirror question

Given a candidate set \(C\), \(p\in C\), \(k\in\mathbb{N}\), and a finite support \(T\) of complete rankings of \(C\) with positive binary-rational masses \(\mu_t\) summing to \(1\), decide whether there is a set \(X\subseteq C\setminus\{p\}\), \(|X|\le k\), such that \(p\) is a nonunique Schulze winner on \(C\setminus X\). Compute pairwise margins as \(\sum_{t\in T}\mu_t(\mathbf{1}[a\succ_t b]-\mathbf{1}[b\succ_t a])\), using each ranking restricted to the remaining slate.

The model it lives in

The society is a distribution over complete ranking types \(t\in T\), with mass \(\mu_t\); the decision variable is the discrete deletion set \(X\), and feasibility is \(p\)'s Schulze winner condition after recomputing margins on the surviving candidates.

The objection that survived

Clearing the rational masses’ denominators can require exponentially many explicitly listed voters, so the mirror is not necessarily computationally equivalent in input size to the paper’s finite-electorate problem.

fatal: False

What the mirror covers

The mirror covers the constructive candidate-deletion hardness of Theorem 2.2; Theorem 2.1 also has a surviving candidate-addition mirror. It leaves the manipulation, voter-partition, destructive-control, and unresolved path-preserving vertex-cut results unaddressed.

Open questions for a prover

  • Does NP-hardness persist when the support size \(\tau\) is bounded, or does the problem admit an algorithm parameterized by \(\tau\)?
  • Does candidate-deletion control admit an FPT algorithm parameterized by the deletion budget \(k\)?

The case FOR (proponent)

The strongest case is for a high-multiplicity version of the paper’s candidate-control problems. Consider a large membership organization choosing among a modest slate: millions of members, but far fewer distinct complete rankings, perhaps because many members share the same ballot. Let \(C\) be the candidates, \(T\) the rankings that occur, and \(\mu_t\) the fraction of members with ranking \(t\). The support size \(\tau=|T|\) can be much smaller than the population. A ranking is a complete type here: the problem uses no other voter-specific information.

For any remaining slate \(A\), define the pairwise margin by
\[ \mathrm{netadv}_{\mu}(a,b) =\sum_{t\in T}\mu_t\bigl(\mathbf{1}[a\succ_t b]-\mathbf{1}[b\succ_t a]\bigr), \]
using each ranking restricted to \(A\). Schulze path scores and winners are computed from these margins as in the paper. The society—not the candidate set or outcome space—is the continuous object.

Lead anchor: Theorem 2.2, proved here. It says that Schulze voting is resistant to constructive control by deleting candidates: given an election, a distinguished candidate \(p\), and a limit \(k\), it is NP-hard to decide whether deleting at most \(k\) candidates other than \(p\) can make \(p\) a winner. The paper proves this by reduction from 3SAT.

The corresponding problem is Continuous-Population Schulze Candidate-Deletion Control. Its instance is a candidate set \(C\), a distinguished candidate \(p\in C\), an integer \(k\), and an explicitly listed rational distribution \(\mu\) over complete rankings of \(C\). Ask whether there is a set \(C'\subseteq C\setminus\{p\}\), with \(|C'|\le k\), such that \(p\) is a nonunique Schulze winner among \(C\setminus C'\), evaluated using the same population distribution and rankings restricted to that slate. A solution is such a deletion set \(C'\).

This fits a large election in which a chair can remove candidates—for example, after ballot-access review—while members’ rankings are summarized as percentages. The choice of deleted candidates remains discrete, as it does in the paper. The mirror changes the electorate representation to a distribution; it does not replace the paper’s problem with a fractional candidate choice.

A second, independently credible anchor: Theorem 2.1, proved here. It says Schulze voting is resistant to constructive control by adding candidates both with a limit on the number added and with no limit. The theorem’s 3SAT reduction encodes variables and clauses in candidates and arranges their pairwise margins so that a successful addition corresponds to a satisfying assignment.

The corresponding Continuous-Population Schulze Candidate-Addition Control instance has disjoint sets \(C,D\), a distinguished \(p\in C\), and a rational distribution \(\mu\) over complete rankings of \(C\cup D\). Ask whether some \(D'\subseteq D\) makes \(p\) a Schulze winner in \(C\cup D'\). The limited variant adds the constraint \(|D'|\le k\). A solution is the selected subset \(D'\). This suits a large membership election where the possible additions are known in advance and voters can rank them, as in a ballot expansion or candidate-cloning scenario.

Both mirrors preserve the operative question: can the chair change the candidate set so that \(p\) wins under Schulze? The paper’s nonunique-winner convention carries over: ties for the best Schulze score still count as \(p\) winning.

The discrete-to-continuous correspondence here is exact. If a finite electorate has \(n_t\) voters of ranking type \(t\), set \(\mu_t=n_t/n\), where \(n=\sum_t n_t\). Every pairwise margin is then the original margin divided by \(n\). Scaling all edge weights by the same positive factor scales every max-min path score by that factor and leaves every winner comparison unchanged. Thus a candidate action succeeds in the finite election exactly when it succeeds in its distributional mirror. Conversely, rational masses can be represented by integer multiplicities after clearing denominators. The paper’s NP-hardness therefore transfers to both continuous problems.

I expect hardness to transfer (Class B) for each. In the reductions, the main combinatorics live in the candidate agenda: variable and clause candidates encode the 3SAT instance. Replacing voter counts by proportions does not fractionalize that selection. This is useful as a boundary result for the programme even though it does not produce a tractable LP.

The weak point is that these mirrors are close to weighted-voter versions of the original problems, and these anchors do not showcase continuous-optimization machinery. There is also a scenario-specific assumption behind candidate addition: voters’ rankings cover candidates who may not yet be on the ballot. The deletion mirror avoids that complication and is why I would lead with Theorem 2.2. Still, these are genuine continuous-population questions under the programme’s definition: the electorate is supplied as a distribution over complete types, and the outcome and candidate actions remain those of the paper. The broader high-multiplicity elections and control literature supports this as a sensible regime; it is not a reason to treat the mirror as a collision.

This case covers Theorems 2.1 and 2.2 only. Natural follow-up questions are whether hardness persists for restricted support size \(\tau\), and what parameterized algorithms are possible when the deletion or addition budget \(k\) is small.

The case AGAINST (opponent, writing after the proponent)

The strongest negative case is that both proposed mirrors add very little structure beyond a rational pairwise-margin matrix. For candidate deletion (Theorem 2.2), Schulze winners on every remaining slate depend only on the margins between candidates on that slate. For candidate addition (Theorem 2.1), the same is true if voters have rankings over the full potential slate. Once those margins are computed from \(\mu\), the ranking types themselves play no further role. The control choice is still a subset of candidates, and the distribution supplies no apparent opening for the programme’s continuous-optimization tools.

That makes these mirrors look like weighted Schulze control problems with a redundant type-distribution input. It also limits the proponent’s “exact correspondence” claim as a computational one: clearing rational denominators gives an equivalent finite electorate semantically, but can require exponentially many explicitly listed voters. So the paper’s reductions transfer hardness; they do not by themselves settle the complexity of the binary-encoded, high-multiplicity input.

This is a real case for low novelty and limited algorithmic leverage. It does not defeat either anchor. Theorems 2.1 and 2.2 are named computational results. Large membership elections with repeated rankings are plausible high-multiplicity settings; deletion needs no unusual assumption, and addition is coherent when preferences over possible candidates are collected in advance. The margin-matrix compression is itself an observation about how these mirrors should be formulated, not evidence that the population cannot sensibly be continuous. And the encoding change is precisely where a high-multiplicity complexity question can arise.

So I cannot make the requested universal case honestly. The negative argument is weak at its decisive step: it shows that these are unlikely to showcase continuous optimization, but the programme explicitly treats a well-posed mirror with a dull or unchanged complexity answer as worthwhile. Neither anchor has a fundamental modeling obstruction, and either one survives that test.
