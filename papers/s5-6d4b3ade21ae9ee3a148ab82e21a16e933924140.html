The continuous mirror question

Given finite type and item-class sets \(T\) and \(G\), rational masses \(\mu_t\) and per-capita supplies \(q_g\) summing to \(1\), rankings \(\succ_t\), parameters \(h_t\in[0,1)\), requirements \(r_t\in\{1,2\}\), and target \(\kappa\), does there exist \(X\ge0\) with \(\sum_gX_{tg}=\mu_t\) and \(\sum_tX_{tg}=q_g\) such that \(\sum_{t:\operatorname{rank}_t(\operatorname{rep}(p_t,\succ_t,h_t))\le r_t}\mu_t\ge\kappa\), where \(p_t(g)=X_{tg}/\mu_t\) for every \(\mu_t>0\)?

The model it lives in

A high-multiplicity one-sided matching market with finite agent types \(T\) and item classes \(G\), rational type masses \(\mu_t\), and per-capita supplies \(q_g\). The decision variables are aggregate assignment masses \(X_{tg}\); each type faces lottery \(p_t(g)=X_{tg}/\mu_t\), and the objective thresholds the mass whose \(h_t\)-quantile representative has rank at most \(r_t\).

The case FOR (proponent)

The strongest positive case is a high-multiplicity version of the paper’s one-sided matching problem, anchored in Theorem 11, proved in this paper (with the reduction supplied in Appendix A).

Theorem 11 states:

Given a one-sided matching instance \((N,M,\succ,h)\), a rank requirement \(r_i\in\{1,2\}\) for every agent, and an integer \(k\), deciding whether there is a lottery \(x\) over perfect matchings such that at least \(k\) agents receive a representative of rank at most \(r_i\) is NP-hard.

More precisely, agent \(i\) is counted when
\[ \operatorname{rank}_i(\operatorname{rep}(x_i,\succ_i,h_i))\le r_i. \]
The proof reduces Vertex Cover. It creates a type-like agent \(a_v\) for every vertex, requiring its top item, and an agent \(a_e\) for every edge, requiring one of its two endpoint items among its top two. A vertex cover of size \(k\) exists exactly when at least \(|V|+|E|-k\) agents can be satisfied.

My continuous mirror would be called Quantile-Representative Typed Matching\(_\infty\).

An instance consists of:

  • a finite set \(T\) of agent types, with rational masses \(\mu_t\ge0\) summing to \(1\);
  • a finite set \(G\) of item classes, with rational per-capita supplies \(q_g\ge0\) summing to \(1\);
  • for every type \(t\), a strict ranking \(\succ_t\) of the item classes, a quantile parameter \(h_t\in[0,1)\), and a requirement \(r_t\in\{1,2\}\);
  • a rational target mass \(\kappa\).

A solution is an aggregate matching \(X=(X_{tg})\), where \(X_{tg}\) is the mass of type \(t\) assigned item class \(g\), satisfying
\[ \sum_{g\in G}X_{tg}=\mu_t \qquad\text{and}\qquad \sum_{t\in T}X_{tg}=q_g. \]
For \(\mu_t>0\), define the common lottery of type \(t\) by
\[ p_t(g)=\frac{X_{tg}}{\mu_t}. \]
Let \(\rho_t=\operatorname{rep}(p_t,\succ_t,h_t)\). The question is whether there exists \(X\) such that
\[ \sum_{t:\,\operatorname{rank}_t(\rho_t)\le r_t}\mu_t\ge\kappa. \]

This is genuinely a population continuization. The \(X_{tg}\) are aggregate masses, not fractional items received by an individual. Each unit of mass receives one integral item in every realized matching; \(p_t\) is the lottery faced by a member of type \(t\). Rational aggregate solutions can be expanded into finite replicated instances and decomposed into lotteries over integral perfect matchings by the usual bipartite-matching integrality/Birkhoff argument.

The natural regime is a large centralized assignment market: for example, many applicants in recurring cohorts, sharing the same preference ranking, quantile parameter, and eligibility profile, assigned to repeated hospital, school, or employment slots. If there are \(R\) copies of every agent type and \(R\) copies of every item class, then the population has \(R\lvert T\rvert\) agents while its description has only \(\lvert T\rvert\) types and \(\lvert G\rvert\) item classes. This is precisely the high-multiplicity setting. The per-capita supplies \(q_g\) are the necessary matching analogue of the paper’s equal numbers of agents and items.

Theorem 11 transfers directly. Given a Vertex Cover instance \(H=(V,E)\), put \(d=\lvert V\rvert+\lvert E\rvert\). Create one agent type and one item class for every element of \(V\cup E\), each with mass or supply \(1/d\). For each vertex \(v\), use a type \(t_v\) with \(r_{t_v}=1\), \(h_{t_v}=1/(3d)\), and \(v\) as its top item. For each edge \(e=\{u,v\}\), use a type \(t_e\) with \(r_{t_e}=2\), \(h_{t_e}=1-1/d\), and \(u,v\) as its top two items. Set
\[ \kappa=\frac{d-k}{d}. \]

With a vertex cover \(C\) of size \(k\), all vertex types outside \(C\) and all edge types can be satisfied, giving mass \((d-k)/d\). Conversely, if that much type mass is satisfied, at most \(k\) types are unsatisfied. The Appendix A argument extracts from those unsatisfied vertex and edge types a vertex cover of size at most \(k\). Thus the continuous typed problem is NP-hard.

I would classify this as Class B: the hardness transfers, rather than arising specifically from continuity. The combinatorics live in the vertex–edge incidence structure of the type and item classes. Replication makes the society genuinely high-multiplicity, but it does not erase the hard finite core.

The weakest point is that Theorem 11’s own reduction has one distinct type per vertex or edge. Replicating those types makes the population arbitrarily large, but does not establish hardness for fixed \(\lvert T\rvert\), nor does it show that continuum structure itself causes difficulty. Moreover, repeated item classes and per-capita supplies are a co-modification of the paper’s one-to-one matching model. I nevertheless think the mirror is defensible: it preserves the paper’s quantile representatives, rank-threshold objective, and lottery-over-integral-matchings semantics, while replacing named agents and unit-capacity items by repeated cohorts and scaled supplies—the natural high-multiplicity form of matching.

The main follow-up questions are whether the problem becomes fixed-parameter tractable in \(\lvert T\rvert\) or \(\lvert G\rvert\), whether allowing partial credit for a type’s mass yields a linear or configuration program, and what rounding guarantees connect the typed continuum back to finite replicated markets.

The case AGAINST (opponent, writing after the proponent)

The strongest negative argument attacks fidelity, not complexity. The proposed \(X\)-model gives every member of a type the same lottery \(p_t\). But Theorem 11’s original feasible object has one marginal lottery \(x_i\) per named agent. After replicating a type \(R\) times, those \(R\) agents need not receive identical marginals: some copies may satisfy the rank threshold and others may not. Averaging their lotteries can destroy satisfaction because the representative condition is threshold-based and discontinuous. Thus the proponent’s \(X\) is not automatically the high-multiplicity relaxation; it is an additional equal-treatment or anonymity restriction.

The faithful repair would retain, for each type \(t\), a distribution \(\nu_t\) over individual lotteries \(p\), with constraints

\[ \sum_t \mu_t\int p(g)\,d\nu_t(p)=q_g \]

and objective

\[ \sum_t \mu_t\int \mathbf{1}\!\left[ \operatorname{rank}_t(\operatorname{rep}(p,\succ_t,h_t))\le r_t \right]d\nu_t(p)\ge \kappa. \]

That model preserves the mass of individually satisfied agents rather than forcing an entire type to be simultaneously satisfied. It is a more complicated, potentially infinite-dimensional configuration problem, and it is the proper object if type identity is the only information suppressed by continuization.

But this does not defeat the anchor. The equal-treatment version is itself a coherent continuous problem for anonymous typed matching, and the paper’s setting does not require us to preserve every asymmetric lottery over named agents. Its reduction is also sound: with \(d=|V|+|E|\), assigning mass \(1/d\) to every agent and item type, and replicating each type arbitrarily many times, gives a genuine high-multiplicity market. Rational aggregate assignments can be realized by finite replicated matchings. The vertex-cover incidence remains in the type structure, so the resulting mass problem is NP-hard.

Nor can one object that the reduction uses one type per vertex or edge, or that hardness survives replication. The programme explicitly permits Class B mirrors and does not require a fixed number of types. Nor is the use of item classes a scope violation: matching populations with per-capita supplies is precisely the permitted co-modification.

So the honest negative case is limited to saying that the proponent has not yet established the *canonical* high-multiplicity formulation or a two-way equivalence with replicated instances. That is a modelling gap, not a fatal obstruction. Theorem 11 remains a worthwhile continuous mirror, and I cannot honestly support the universal claim that no worthwhile mirror exists.
