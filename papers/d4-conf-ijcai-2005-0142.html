The continuous mirror question

Given \(m\) indivisible goods, a known support \(T\) of \(\tau\) valuation types with rational masses \(\mu_t>0\) summing to \(1\), and an unknown normalized, free-disposal valuation \(v_t\) in an atomic language \(L\) for each type, with value and demand queries available to a representative of each type, recover every \(v_t\) and thus the exact weighted measure \(\nu=\sum_{t\in T}\mu_t\delta_{v_t}\). If \(q_t=\mathrm{size}_L(v_t)\), can this be done with at most \(\sum_t(q_t(m+1)+1)\) demand queries and \(\sum_t q_t\) value queries?

The model it lives in

A distribution over known cohorts whose members share a complete valuation type. The decision objects are the atomic representations of each \(v_t\); the objective is exact recovery of the weighted population valuation measure \(\nu\), using queries to one representative per type.

What the mirror covers

The mirror covers Theorem 1's exact learning guarantee for known valuation types. It leaves the VCG characterization, LeEA, winner determination, and supporting-price computation unaddressed; it also does not establish learning from an anonymous aggregate oracle.

Open questions for a prover

  • Can the valuation measure be recovered when queries expose only anonymous aggregate responses rather than a representative of each known type?

The case FOR (proponent)

The strongest mirror I see is Typewise Atomic Population Learning, anchored on Theorem 1, proved in this paper. It states that an unknown valuation \(v\) in any atomic language \(L\) can be learned using at most \(\mathrm{size}_L(v)(m+1)+1\) demand queries and at most \(\mathrm{size}_L(v)\) value queries. This is a query complexity result, not a claim of ordinary polynomial time independent of the query oracles. The paper has no numbered hardness result to anchor on, so this is its best fit for the requested kind of mirror.

Here is the continuous problem. There are \(m\) indivisible goods and a known finite set of cohort labels \(T\), with \(|T|=\tau\). The society is a distribution \(\mu\) over those cohorts: each \(\mu_t>0\) is a binary rational and \(\sum_{t\in T}\mu_t=1\). Every member of cohort \(t\) has the same unknown, normalized, free-disposal valuation \(v_t:2^G\to\mathbb{R}_{\ge 0}\), represented in a specified atomic language \(L\). The elicitor can issue the paper’s ordinary value and demand queries to a representative of each cohort. The task is to recover the exact weighted population of valuations, \(\nu=\sum_{t\in T}\mu_t\delta_{v_t}\), by outputting a valid atomic representation of each \(v_t\) and its mass. Equivalently, this recovers the population’s mass-weighted valuation function \(\bar v(S)=\sum_t\mu_t v_t(S)\) for every bundle \(S\). Query responses and valuation weights are exact rationals; query complexity is measured in \(m,\tau\), the representation sizes \(q_t=\mathrm{size}_L(v_t)\), and the binary input length.

The expected result is tractability in this query model. Run the paper’s learner once per cohort, in parallel across cohorts. Theorem 1 gives at most \(\sum_t(q_t(m+1)+1)\) demand queries and \(\sum_t q_t\) value queries; parallel execution makes the query rounds depend on the largest cohort representation rather than the number of people. In a discrete election of \(N\) buyers with \(n_t\) copies of each type, the same input has \(\mu_t=n_t/N\). The work scales with the number and complexity of distinct types, not with \(N\). This mirrors the paper’s stated multi-agent use of parallel individual learners, while making the population itself a mass distribution. A plausible regime is a large market of automated procurement agents deployed from a small number of shared preference templates: many agents, but relatively few distinct valuation types.

This is a narrow mirror of Theorem 1’s elicitation problem, not of the paper’s VCG characterization or its allocation results. It does not claim that a continuous population makes the paper’s discrete problem easier; the anchor is already query-efficient. The further questions are whether the valuation types can be learned from an anonymous aggregate demand oracle, and whether learning \(\nu\) suffices to compute efficient allocations or supporting prices when supplies scale with population mass.

The weakest point is that the cohort partition must be observable and the elicitor must be able to query a representative of each cohort. If agents are visible only through an aggregate response, Theorem 1 does not establish that the underlying distribution of valuations can be recovered. Also, the query bound depends on type complexity, not on the masses: the continuous representation organizes the high-multiplicity instance, but does not itself produce the learning gain. The positive case survives because cohortwise elicitation is recognizably the paper’s problem—the authors explicitly describe running individual learners in parallel—and mass-weighted profiles are a sensible high-multiplicity version of that task.

The case AGAINST (opponent, writing after the proponent)

The strongest objection to the proposed mirror is that its population-wide algorithm is already the paper’s learner, run once per cohort. Given known cohorts and access to one representative’s value and demand queries, Theorem 1 yields a bound of \(\sum_t(q_t(m+1)+1)\) demand queries. The masses \(\mu_t\) do not affect the learning; they are attached to the recovered valuations afterward. The result therefore gives no new population-level computation: it batches duplicate individual elicitation.

That is a limited objection, though. The query count can fall from one learner per person to one per distinct valuation type, and shared preference templates among many buyers are a plausible regime. The paper explicitly discusses parallel learners for multiple agents. So the cohortwise problem is well-posed and close to the authors’ stated concerns. Calling it uninteresting simply because the continuous algorithm follows directly from Theorem 1 would not defeat the mirror under the programme’s standards.

A stronger version would make the population anonymous: learn the distribution of valuations through aggregate demand or value responses, without being able to query a representative of each known type. That would make the population itself central, but it changes the oracle model. Theorem 1 provides no guarantee for recovering an unknown support or measure from aggregate responses; that would be a separate learning problem, whose query model and identifiability would need to be established. It might be worthwhile, but it is not a continuous consequence of this theorem.

The paper’s VCG characterization offers a different possible mirror, but it has a more basic continuum problem. If individuals have zero mass, removing one leaves the society unchanged, so the individual VCG externality vanishes and the marginal-economy tests behind universal competitive equilibrium collapse. Treating each positive-mass cohort as a single strategic agent could restore nonzero externalities, but changes the incentive model to one with strategic blocs.

So the honest negative case is weak: it can argue that the cohortwise mirror adds little beyond a direct application, but it cannot show that the question is unworthy. Theorem 1’s mirror survives as a sensible, if modest, continuous-population question; rejecting it would require a higher bar for what counts as worthwhile than the programme’s stated criteria provide.
