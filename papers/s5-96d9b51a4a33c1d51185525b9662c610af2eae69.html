The continuous mirror question

Given a finite core graph \(G[C]\) with thresholds \(\theta_c\), and peripheral types \(i\in[r]\) with rational masses \(\mu_i\), common neighborhoods \(A_i\subseteq C\), thresholds \(\theta_i\), and no edges among peripheral agents, choose core seed bits \(z_c\in\{0,1\}\) and seeded masses \(x_i\in[0,\mu_i]\) minimizing \(\sum_{c\in C}z_c+\sum_i x_i\). Under irreversible threshold diffusion, core vertices count active core neighbors as one each and active peripheral neighbors by mass; unseeded mass of type \(i\) activates once at least \(\theta_i\) vertices in \(A_i\) are active. What is the exact minimum seed cost needed to activate the entire population, and can it be computed with fixed-parameter dependence on \(|C|\) and polynomial dependence on the number of types and input bit length?

The model it lives in

A finite core with individual seed decisions, plus rational masses of peripheral agents grouped by identical core neighborhood and threshold. Seeded mass is a decision variable; the objective is total seeded mass plus the number of seeded core vertices. Enumerating core activation times may reduce feasibility to linear constraints on the seeded masses.

The objection that survived

The lead mirror requires a small core and exact repetition of peripheral neighborhoods and thresholds, limiting it to block-structured networks; the proponent acknowledges this limitation and gives a plausible cohort setting.

fatal: False

What the mirror covers

The lead mirror covers Theorem 5 for a finite core and repeated independent peripheral types; the proposed dyad-cohort extension covers Theorem 6 less directly. These mirrors leave the paper's other TSS results and general networks untouched.

Open questions for a prover

  • For each guessed core activation-time vector, do linear constraints on seeded type masses characterize feasible diffusion exactly?
  • Does this yield an exact algorithm fixed-parameter in the core size and polynomial in the number of types and input bit length?

The case FOR (proponent)

The strongest mirror is a finite-core, continuous-mass version of Target Set Selection. It keeps the paper’s object and mechanics: choose a minimum-cost seed set, then ask whether the same threshold diffusion activates the whole population. What becomes continuous is the mass of repeated peripheral agents, not time, outcomes, or the diffusion rule.

For the lead mirror, take a finite core \(C\) of \(t\) agents, with an arbitrary graph among them. The rest of the population consists of types \(i=1,\ldots,r\). Type \(i\) has rational mass \(\mu_i>0\), is adjacent to the same subset \(A_i\subseteq C\), and has the same threshold \(\theta_i\). There are no edges between peripheral agents. Each core agent \(c\) has a threshold \(\theta_c\); it counts active core neighbors as unit mass and active peripheral neighbors by their mass. A peripheral type’s unseeded mass activates when at least \(\theta_i\) of its core neighbors are active. The instance asks for core seed indicators \(z_c\in\{0,1\}\) and seeded masses \(x_i\in[0,\mu_i]\) that activate the entire population, minimizing \(\sum_{c\in C}z_c+\sum_i x_i\). Dividing by \(t+\sum_i\mu_i\) reports the minimum seed fraction. The masses can equivalently be normalized to a distribution over types.

This is a plausible high-multiplicity regime for a platform or organization with a small set of unusually central accounts and large cohorts that have the same contacts to those accounts. It is not a claim about social networks generally: the required condition is that many peripheral agents really do share the same neighborhood and threshold. There can be arbitrarily many agents but only \(r\) peripheral types; after removing types whose threshold exceeds their degree, there are at most \(\sum_{A\subseteq C}|A|=t2^{t-1}\) nontrivial neighborhood-threshold profiles. The finite core is a set of exceptional atoms in an otherwise mass-based population, which is the mirror’s main modeling compromise.

My lead anchor is Theorem 5, proved in this paper. It states that for a graph \(G\) on \(n\) vertices with threshold function \(\tau\), if \(t\) is the size of a minimum vertex cover, an optimal target set can be computed in time \(2^{O(t\log t)}n^{O(1)}\). The continuous question above mirrors that optimization problem in the regime where the vertex-cover side is a small core and the independent-set side consists of repeated types.

I expect this mirror to be tractable. Enumerate the activation time \(T(c)\in\{0,\ldots,2t\}\) of each core agent; the paper’s two-\(t\)-round bound motivates this range. For a guessed vector of times, each type’s activation time if unseeded is determined by the core schedule. Then the mass of type \(i\) active before a core agent’s guessed time is either \(x_i\) or all of \(\mu_i\). Each core activation requirement is therefore a linear inequality in the \(x_i\), and the objective is linear. Taking the best solution over the \((2t+1)^t\) guesses gives an LP-based route with running time \(2^{O(t\log t)}\operatorname{poly}(r,L)\). This is a proposed mirror algorithm, not a result proved in the paper. It retains the paper’s threshold diffusion and minimum-seed question while making the population mass and seed decision fractional.

A second, more ambitious mirror follows Theorem 6, also proved here. It states that TSS-D1M is solvable in time \(2^{2^{O(t)}}n^{O(1)}\), where \(t\) is the size of a degree-1 modulator. In that problem the input includes a graph, thresholds, a target-set budget, and a modulator \(C\) of size \(t\); outside \(C\), the graph is a disjoint union of isolated vertices and isolated edges. The paper’s algorithm computes an optimum as well. Its proof uses Theorem 11’s bounded-variable integer-programming construction and Proposition 8, which is cited from Kannan.

For the continuous version of this second problem, peripheral mass consists of singleton cohorts and cohorts of identical two-vertex components. A pair type specifies the two endpoints’ neighborhoods in \(C\), their thresholds, and its rational component mass \(\nu_j\). Its seed decision splits that mass among four integral configurations: neither endpoint seeded, the first seeded, the second seeded, or both seeded. If these masses are \(y_j^{00},y_j^{10},y_j^{01},y_j^{11}\), they sum to \(\nu_j\), and the seed cost is \(y_j^{10}+y_j^{01}+2y_j^{11}\). Core activation counts active endpoint mass; endpoint activation still follows the original threshold rule, including the partner edge. A solution is a choice of core seeds and such mass splits that eventually activates every endpoint and every core agent.

I would also expect this mirror to be in Class A. Theorem 11 already groups equivalent singleton and pair components into a number of variables bounded by \(2^{O(t)}\) for each guessed core schedule. In the mass version, those variables represent rational amounts of components in each seed configuration; the paper’s linear constraints suggest an LP in place of the integer program. A likely route is therefore FPT in \(t\), with a bound around \(2^{O(t\log t)}\operatorname{poly}(r,L)\), provided the aggregate constraints are proved exact for fractional component populations. That proof is part of the proposed problem, not something Theorem 6 establishes for the continuous model.

These are separate mirrors of the paper’s two structural results, not a claim that all of TSS has a continuous analogue with the same complexity. They also generate useful follow-up questions: whether the continuous optimum approximates the discrete optimum for large repeated cohorts; whether the D1 component aggregation remains exact under fractional masses; and what changes for the paper’s open D2M case.

The weak point is the regime assumption. Exact repeated neighborhoods and thresholds may be uncommon in an ordinary social network, and the finite-core model leaves a small set of agents indivisible. The case survives because this is not an arbitrary simplification imposed on TSS: the paper’s vertex-cover and degree-1-modulator results already isolate precisely these structures. The proposed scenarios make those structures interpretable as repeated cohorts around a small core. The paper’s numbered anchors I rely on are tractability results; I would not turn its unnumbered hardness discussion into a named hardness anchor without a corresponding result number and a proof that fractional seeding preserves the reduction.

The case AGAINST (opponent, writing after the proponent)

The strongest case against these mirrors is that both theorems get tractability from a very narrow network structure. Theorem 5 works around a small vertex cover: outside it, agents have no ties to one another and are distinguished only by their shared neighbors in the core and their thresholds. Theorem 6 allows peripheral pairs, but still requires all repeated components to share exactly the same profile. Those are restrictive regimes for network diffusion, where connections often distinguish individuals.

That objection does not defeat Theorem 5’s mirror. A stronger version would make the core itself a set of positive-mass types, rather than keeping a few exceptional individuals. Peripheral types could share the same core connections and threshold; core thresholds could be expressed in population shares. This gives a fully mass-based block-network model. Seeding a fraction of a cohort is meaningful, and the core’s activation schedule gives linear constraints on those fractions. Theorem 5 is a named optimization result, and this version asks a genuine computational question about its continuous-population counterpart. Calling the model too special, or saying that fractional seeding changes the problem, is not enough under the programme’s stated standard: the regime is plausible, and that change is the point of the mirror.

Theorem 6 has a narrower and less convincing mirror. Its peripheral units are pairs, so treating them as repeated dyad cohorts is more contrived than treating independent cohorts as types. A model over individual masses would also need to preserve which endpoints are paired. That weakens this anchor as an example of a standard population distribution. But the stronger dyad-cohort model is coherent: each cohort has the same endpoint roles, core connections, thresholds, and internal pair edge; its mass can be split among the four seed configurations. The paper’s integer counts by component class then suggest mass variables and linear activation constraints. This needs an exactness proof, but that is a research question rather than a fundamental failure.

So the honest negative case is about priority: these mirrors cover block-structured diffusion, not general social networks, and the degree-1 version may require a less familiar choice of population unit. It does not establish that no worthwhile mirror exists. Theorem 5 survives the strongest objections, and one surviving anchor is enough under the stated grading rule. I cannot honestly make the requested universal case against this paper.
