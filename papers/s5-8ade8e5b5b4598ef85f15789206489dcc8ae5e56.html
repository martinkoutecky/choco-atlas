The continuous mirror question

Given a finite set of complete workload types \(T\), rational masses \(\mu_t\geq 0\) with \(\sum_{t\in T}\mu_t=1\), normalized demands \(d_{tr}>0\), server classes \(q\), and rational per-capita capacities \(b_{qr}\) for each resource \(r\), find an optimal common global dominant share \(z\) and per-user class allocations \(x_{tq}\geq 0\). Maximize \(z\) subject to \(\sum_q x_{tq}=z\) for every type \(t\), and \(\sum_t \mu_t x_{tq}d_{tr}\leq b_{qr}\) for every class \(q\) and resource \(r\). Each type-\(t\) user receives \(x_{tq}d_{tr}\) of resource \(r\) from class \(q\).

The model it lives in

A nonatomic cloud population distributed over \(\tau\) recurring demand types, with server-class resources supplied per capita. Each user of type \(t\) receives the same per-user allocation \(x_{tq}d_{tr}\); the objective is to maximize the common global dominant share \(z\). The resulting rational LP has \(O(\tau q)\) allocation variables.

What the mirror covers

The mirror covers the max-min DRFH allocation and Proposition 2’s Pareto-optimality guarantee. It leaves the individual truthfulness claim aside, along with the task-level heuristic and its simulation results; other fairness properties could be examined separately.

Open questions for a prover

  • Can the finite-to-continuous equivalence and Pareto-efficiency claim be stated when allocations may vary among users of the same type, using positive-mass Pareto improvements?
  • How does the type-mass formulation change when finite task limits or indivisible tasks are included?

The case FOR (proponent)

There is no numbered result in the paper that classifies a problem as NP-hard, polynomial-time solvable, or otherwise. The strongest computational anchor is Proposition 2 (Pareto optimality), proved in Section 4.2: the paper computes the DRFH allocation by maximizing the minimum global dominant share, subject to each server’s resource constraints, and proves that the resulting allocation is Pareto optimal. In full, for every feasible allocation that lets some user schedule more tasks, at least one other user must schedule fewer. The paper’s LP makes the allocation computationally concrete, though its proposition does not state a running-time bound.

My lead mirror is Continuous DRFH Allocation. The scenario is a large cloud platform with many tenant workloads and a small number \(\tau\) of recurring demand profiles: for example, many tenants running CPU-heavy or memory-heavy workloads. Each type includes the full resource-demand vector and any other feature that affects its allocation; in the paper’s base model, that is just demand. Let \(\mu_t\) be the fraction of users of type \(t\), with \(\sum_t\mu_t=1\). Suppose the platform has server classes \(q\), and \(b_{qr}\) is the amount of resource \(r\) in class \(q\) available per unit of user population. This per-capita supply keeps resource availability stable as the population grows.

Given positive rational normalized demand vectors \(d_t\), the decision variable \(x_{tq}\) is the global dominant share allocated per user of type \(t\) from server class \(q\). The question is to find a feasible allocation maximizing the common per-user share \(z\), namely solve
\(\max z\), subject to \(\sum_q x_{tq}=z\) for every type \(t\), \(\sum_t\mu_t x_{tq}d_{tr}\le b_{qr}\) for every server class \(q\) and resource \(r\), and \(x_{tq}\ge0\). A solution is the optimal rational \(z\) and allocation matrix \(x\); type \(t\) receives resources \(x_{tq}d_{tr}\) per user from class \(q\). This is a linear program with \(O(\tau q)\) allocation variables and \(O(\tau+qm)\) constraints, so it is polynomial-time solvable in the input bit length. That complexity conclusion follows from the displayed LP; it is not a theorem claimed by the authors.

This should be recognizable to the authors as their max-min global-dominant-share allocation with users grouped by complete demand type. With \(N\) users, \(n_t=N\mu_t\), and class capacities scaled as \(N b_{qr}\), dividing the finite-user LP’s resource constraints by \(N\) gives exactly the stated constraints. So the mirror preserves the allocation objective and admits an exact finite-to-continuous dictionary when users share types and tasks remain divisible. Its expected outcome is tractable (Class A) by linear programming, and its continuous allocation retains Proposition 2’s Pareto-efficiency aim.

A plausible regime is a cloud provider serving a very large number of workloads with standardized resource templates, so \(N\gg\tau\); repeated hardware configurations keep the number of server classes manageable too. The paper’s own discussion describes a different regime, with far fewer users than servers, so this is a plausible extension of its model rather than a description of its trace scenario. It also matters that total server capacity scales with the population.

The mirror covers the max-min DRFH allocation and Proposition 2’s Pareto-optimality claim. It does not cover the paper’s truthfulness result: a deviation by one individual has zero effect in a nonatomic population, so a meaningful strategic mirror would need a model that retains individual deviations. Further questions include whether the type compression remains exact with finite task limits or unequal weights, and how indivisible tasks change the LP picture.

The weak point is that this is a modest algorithmic mirror: the finite-user allocation is already computed by an LP, and the continuation largely groups repeated users and scales capacity per capita. The paper has no named hardness result whose dissolution could reveal a new complexity boundary. The positive case rests instead on a faithful, plausible high-multiplicity version of the paper’s central allocation problem, with a clean tractability result.

The case AGAINST (opponent, writing after the proponent)

The strongest objection is that Proposition 2 is not a computational result in the sense ChoCo is meant to mirror. It proves that the max-min DRFH allocation is Pareto optimal; it gives no complexity classification, running-time bound, or algorithmic barrier. The paper already writes down the finite-user allocation LP, so the proposed mirror is a new complexity question attached to a welfare proposition, rather than a continuous version of a complexity result.

That objection does not make the proposed model incoherent. Many tenants sharing a small set of complete demand types is plausible, and scaling server capacity per capita gives the types meaningful masses. The allocation objective still makes sense, and the LP is faithful: \(x_{tq}\) gives each user of type \(t\) the same per-user share from server class \(q\). Pareto optimality is a genuine property to study there. The loss of individual truthfulness does not defeat this anchor, since the proponent expressly excludes it.

The best case against the mirror is that it appears to add little structure beyond exact type compression. For \(N\) finite users with \(n_t\) users of each type, symmetry lets us use a common allocation \(x_{tq}\) within each type. If capacities scale as \(N b_{qr}\), the finite constraints are
\[ \sum_t n_t x_{tq}d_{tr}\le N b_{qr}. \]
Dividing by \(N\) gives the proposed continuous constraints with \(\mu_t=n_t/N\). Conversely, rational masses can be replicated in a finite population. The continuous LP therefore has the same allocation geometry as the paper’s LP after aggregation; it does not expose an exponential-variable formulation, a pricing problem, or a complexity boundary tied to population size.

That makes this a thin candidate for a ChoCo contribution: the paper supplies no hardness result for continuization to dissolve, and the mirror seems to be a routine high-multiplicity compression of an LP already in the paper. But this is a case about contribution and fit, not a fundamental flaw in the mirror. Under the programme’s stated standards, a coherent Class A mirror can still be worthwhile, and a formal finite-to-continuous dictionary is itself a deliverable. I cannot honestly defend the universal claim that no worthwhile mirror exists here. The negative case is weakest precisely where the proponent’s case is strongest: Proposition 2’s welfare claim survives in a plausible continuous population, even though the paper offers no named complexity theorem to anchor it.
