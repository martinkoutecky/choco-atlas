The continuous mirror question

Given a finite type set \(T\), rational masses \(\mu_t\) summing to \(1\), reference vectors \(r(t)\in\mathbb{Q}_{+}^{d}\), and per-agent estate \(e\in\mathbb{Q}_{>0}\), form for each integer \(q\) with \(q\mu_t\in\mathbb{Z}\) the paper's MRA instance with \(q\mu_t\) agents of type \(t\) and total estate \(qe\). If \(a_t^{(q)}(e)\) is the award to each type-\(t\) agent, determine whether \(a_t(e)=\lim_{q\to\infty}a_t^{(q)}(e)\) exists and, if so, compute the limiting allocation path as \(e\) varies, exactly or within \(\varepsilon\), with running time measured in \(d\), \(|T|\), input bit length, and \(\log(1/\varepsilon)\).

The model it lives in

The society is a distribution \(\mu\) over complete project types \(t\), each with reference vector \(r(t)\). Each type receives a per-agent award \(a_t\), with \(\sum_t\mu_t a_t=e\). Define the continuous MRA allocation path as the limit of the paper's finite-agent rule under replication with total estate scaled to \(qe\).

The case FOR (proponent)

There is a plausible population mirror here, but I cannot honestly give it a qualifying computational anchor. The named results are mathematical characterizations and properties: Theorem 2.1 and Theorem 3.2, both proved in the paper, identify random-arrival rules with Shapley values; Proposition 3.3 proves axioms of MRA; and Theorem 3.4 proves its allocation path is piecewise linear between specified estate breakpoints, with additional resources shared equally above the largest breakpoint. Theorem 3.4 is the closest to a computational result, but it gives no running-time classification or analyzed algorithm. The numerical example does not supply one. Under the requested anchor standard, this paper has no named computational result to mirror.

The strongest candidate question would be Replica-Limit MRA. Imagine many local projects receiving a common public fund, with each project assessed against a small set of standardized need indicators. A type \(t\) is the project’s complete reference vector \(r(t)\in\mathbb{Q}_{+}^{d}\). The input is a rational type distribution \(\mu\) over a finite set \(T\), and a rational resource amount \(e\) per project. For each integer replication factor \(q\) such that every \(q\mu_t\) is integral, create \(q\mu_t\) projects of each type, provide total resources \(qe\), and apply the paper’s MRA rule. By anonymity, projects of the same type receive the same award; call it \(a_t^{(q)}\).

The continuous question is: does \(a_t=\lim_{q\to\infty}a_t^{(q)}\) exist for every type, and, given a requested precision \(\varepsilon\), compute awards within \(\varepsilon\) of the limit? The resulting allocation has type density \(a_t\) and satisfies \(\sum_{t\in T}\mu_t a_t=e\). The proposed mirror covers computing the MRA allocation as the population grows. It does not claim to continue the paper’s axiomatic characterizations.

I would tentatively investigate tractability when the number of characteristics \(d\) is fixed: the rule is built from maxima of aggregate reference totals, which suggests a finite-dimensional continuous calculation. The open questions include proving convergence, handling ties between maximizing characteristics, and bounding the running time in \(d,\tau,L,\log(1/\varepsilon)\). These are proposed questions, not consequences of the paper’s theorems.

The weak point is substantial: the paper studies which allocation rule has particular properties, not the complexity of computing it. Replica-Limit MRA is a sensible high-multiplicity extension of that rule, but it is a new computational question without a named computational result in this paper to anchor it.

The case AGAINST (opponent, writing after the proponent)

The strongest case against is at the anchor gate: this paper states no computational result. Theorem 2.1 and Theorem 3.2 identify random-arrival rules with Shapley values; Proposition 3.3 establishes axioms; Theorem 3.4 describes how allocations vary with the estate. None gives an algorithm, a complexity classification, or an analyzed computational problem. The factorial permutation formula is a definition, not a complexity result. So there is no named computational result here for the programme to mirror.

Replica-Limit MRA does not fill that gap as a mirror. It asks for a new result: whether the allocation sequence for \(q\) replicated populations converges, and how to approximate its limit. Theorem 3.2 concerns each finite population; Theorem 3.4 varies the estate while holding the population fixed. Neither establishes a population limit. A direct type-mass version might be a sensible model, but computing its awards would still be a new computational question about the rule, not a continuization of a computational result in this paper.

That distinction is the best available negative case; it does not establish that the new question is unworthy. The proposed project types, each described by a complete reference vector, make mass a meaningful quantity, and scaling the resource with population is a natural co-modification. A stronger direct formulation could ask for the typewise allocation path as the estate varies. I cannot dismiss that on the grounds that the good is already divisible, that the literal finite-agent rule needs adaptation, or that the answer might be easy.

So the case against is strong on scope and weak on the universal claim. No qualifying computational anchor survives, but I cannot honestly conclude that no worthwhile continuous-population question exists for this model. Replica-Limit MRA looks like a plausible adjacent research project; it just is not a computational mirror of a named result in this paper.
