The continuous mirror question

Given a compact rational price polytope \(Y\), a rational market-side ratio \(\rho\), rational type distributions \(\mu^S\) and \(\mu^B\), and each type’s convex piecewise-linear contribution listed by rational affine pieces, compute a rational minimizer \(y^\star \in \arg\min_{y \in Y} \left( \rho \sum_{t \in T_S} \mu^S_t f_t(y) + (1-\rho) \sum_{t \in T_B} \mu^B_t g_t(y) \right)\). When the economy has zero duality gap, return the corresponding Walrasian price.

The model it lives in

A price-space optimization over seller and buyer types carrying population mass, with price vector \(y\) as the decision variable and the mass-weighted aggregate convex objective; the stated piecewise-linear input yields an LP.

The objection that survived

The theorem concerns a decentralized price sequence using private subgradients, while the proposed LP gives an optimizer complete aggregate type data; the theorem also supplies no finite-time guarantee for that computation.

What the mirror covers

The mirror covers computation of the aggregate equilibrium-price target associated with Theorem 4.4. It leaves out the decentralized CDA and RDA dynamics, bubble and crash behavior, and the stochastic-noise results.

The case FOR (proponent)

The strongest honest positive case is a price-computation mirror for a large exchange market with a fixed catalogue of indivisible goods. Imagine millions of buyers and sellers whose reservation values, endowments, and supply schedules fall into a relatively small number of complete types. A type includes everything the model uses to distinguish an agent; \(\mu_t\) is the fraction of the population of that side with type \(t\). This is a plausible high-multiplicity regime: the headcount is large, while the number \(\tau\) of distinct types is modest.

My lead problem is Continuous-Mass Walrasian Price Computation. An instance gives a compact rational price polytope \(Y\), seller and buyer type distributions \(\mu^S,\mu^B\), their rational market-size ratio \(\rho\), and each type’s convex piecewise-linear contribution as an explicit list of rational affine pieces. The objective is \(\mathcal F_\mu(y)=\rho\sum_{t\in T_S}\mu^S_t f_t(y)+(1-\rho)\sum_{t\in T_B}\mu^B_t g_t(y)\). The task is to return a rational minimizer \(y^\star\in\arg\min_{y\in Y}\mathcal F_\mu(y)\). When the economy has zero duality gap, this minimizer is a Walrasian price. The continuous object here is the population distribution; the goods remain indivisible.

The nearest named anchor is Theorem 4.4, proved in this paper. For the cyclic double auction with equal numbers of sellers and buyers, it assumes positive step sizes \(a_k,b_k\) with \(\sum_k a_k=\sum_k b_k=+\infty\) and \(\sum_k a_k^2,\sum_k b_k^2<+\infty\), and a positive \(\lambda\) satisfying \(\sum_k|b_k-\lambda a_k|<+\infty\). If the auction weight is \(\alpha=\lambda/(1+\lambda)\), the generated price sequence converges to a minimizer of the paper’s aggregate convex objective. With zero duality gap, that minimizer is an equilibrium price. This is an algorithmic convergence result, not a polynomial-time or finite-iteration bound; the paper contains no named result classifying a problem as in P or hard.

For the stated piecewise-linear mirror, I expect Class A: introducing an epigraph variable for each type’s piecewise-linear function reduces the price computation to a linear program, whose size depends on the encoded type descriptions and \(\tau\), rather than the number of agents. That tractability argument comes from the mirror’s explicit input representation; Theorem 4.4 motivates the target problem but does not prove this complexity claim. Natural follow-ups are whether tractability survives succinct descriptions of bundle valuations, and whether the decentralized auction has useful finite-time guarantees for type masses.

The main weakness is that the paper’s result is about sequential bilateral price discovery with dispersed private information, while this computation problem gives the aggregate type data to an optimizer. The authors might see that as changing the institutional question. Still, the paper explicitly identifies the optimizer as its benchmark equilibrium-price target, and its large-market settings make a distribution over repeated agent types plausible. The mirror covers that target computation, not the paper’s bubble and crash analysis or its noisy auction dynamics.

The case AGAINST (opponent, writing after the proponent)

The proponent has identified a credible high-multiplicity setting: a large exchange market with many buyers and sellers sharing a small set of complete types. Prices need not track individual identities, and the paper itself studies potentially large markets. The strongest negative case therefore rests on the mismatch between that setting and the paper’s result.

Theorem 4.4 concerns the convergence of a particular decentralized protocol. In each cycle, the \(m\) seller–buyer pairs update prices sequentially using private subgradients; convergence depends on how the two step-size sequences are balanced with \(\alpha\). The theorem gives an asymptotic guarantee, with no iteration bound or finite input model for the functions. The proposed Continuous-Mass Walrasian Price Computation instead gives an optimizer the complete type data and asks it to minimize an aggregate objective. With explicitly listed piecewise-linear functions, that is an LP. It computes the paper’s benchmark price while removing the sequential information exchange that makes Theorem 4.4 a result about this auction.

A closer type-mass version of CDA would need to define how a continuum of agents passes through each cycle. Updating once per type, updating by each type’s mass, and processing every repeated agent in sequence induce different dynamics. For RDA, one can sample types according to their masses, but then the population distribution supplies the stochastic oracle; the resulting asymptotic convergence statement still gives no finite-time complexity classification. Asking for an \(\epsilon\)-price bound would require adding a finite input and oracle model, quantitative regularity assumptions, and a step-size policy. That could be useful work, but it is a new stochastic-optimization question rather than a complexity result established by this paper.

The negative case is weak where the programme’s central gate matters most: multiplicity is plausible here, and a finite-support mass model is mathematically natural. I would reject the proposed LP as a faithful mirror of Theorem 4.4 because it changes the computational task from decentralized price discovery to centralized optimization. I cannot rule out a worthwhile follow-on complexity question for type-mass price computation; the paper’s convergence theorem alone does not make that case.
