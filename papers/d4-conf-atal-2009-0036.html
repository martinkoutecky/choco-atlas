The case FOR (proponent)

The paper has no named result establishing that a problem is in P, NP-hard, FPT, or another complexity class. The strongest positive case is the formulation exception: Proposition 4 gives logical characterizations that the paper then uses in its model-checking application in Section 4.1. Proposition 4 is stated without proof here and is not attributed to another source. In full, it says that for a GPCC \(G\) and valuation \(\theta^*\), \(\theta^*\) is weakly Pareto optimal iff \(G,\theta^*\models\mathrm{WPO}\); very weakly strategy dominant iff \(G,\theta^*\models\mathrm{VWSD}\); a Nash equilibrium iff \(G,\theta^*\models\mathrm{NE}\); a strict Nash equilibrium iff \(G,\theta^*\models\mathrm{SNE}\); and in the weak core iff \(G,\theta^*\models\mathrm{INCR}\). The paper’s Definition 16 calls the \(\mathrm{SNE}\) concept “strong Nash equilibrium,” though Proposition 4 prints “strict Nash equilibrium.”

My lead is the WPO clause. It is the cleanest population mirror: the paper explicitly says this solution concept depends on outcomes and preferences, not essentially on the space of strategies. Section 4.1 also describes computing the action profiles satisfying a chosen solution concept. This makes the WPO characterization a reasonable formulation anchor, though it supplies no complexity bound.

Call the mirror Continuous WPO Model Checking. An instance consists of a finite outcome set \(K\), a finite set of complete agent types \(T\), and rational masses \(\mu_t\ge 0\) summing to \(1\). Each type specifies a preference order \(\succeq_t\) over \(K\) and a finite action set \(A_t\). The action set can be the valuations of the propositions controlled by that type, as in the paper. Let \(q_{ta}\) be the mass of type \(t\) choosing action \(a\), with \(q_{ta}\ge 0\) and \(\sum_{a\in A_t}q_{ta}=\mu_t\). The mechanism maps this aggregate action vector to an outcome in \(K\); give the map as an explicit rational polyhedral partition of the feasible \(q\)-vectors. The input also contains a feasible vector \(q^*\).

The question is whether the outcome at \(q^*\) is weakly Pareto optimal: is there no feasible \(q\) whose outcome is strictly preferred by every type with positive mass to the outcome at \(q^*\)? The solution is a yes/no answer; a no answer can include a dominating \(q\) and its outcome. This is a decision problem, not a welfare-maximization problem, matching the model-checking question in the paper.

The regime is a large population participating in a common mechanism, such as a public consultation or election: many people share the same complete preference ranking and available actions, so \(N\) is large while the number \(\tau=|T|\) of distinct types is modest. A finite profile maps to \(q_{ta}=n_{ta}/N\) and \(\mu_t=n_t/N\). The continuous model relaxes those action counts to masses. The mechanism’s dependence on aggregate action masses is the natural co-modification for this anonymous high-multiplicity setting.

I expect this version to be tractable, in Class A. For each outcome \(k\), the type rankings determine whether \(k\) strictly Pareto-dominates the candidate outcome. For each such \(k\), test whether its polyhedral cell contains a feasible \(q\), using rational linear-programming feasibility. With the cells listed explicitly, this is polynomial in their description size, \(|K|\), \(\tau\), the action-set sizes, and the bit length of the rational data. That is a proposed result for the mirror, not a result established by the paper. It covers the WPO model-checking result only; I would not stretch it to cover the paper’s completeness theorem, effectivity analysis, or equilibrium concepts.

The soft spot is the aggregate mechanism. The paper permits arbitrary outcome functions on individual action profiles; this mirror restricts them to anonymous outcome rules whose regions have polyhedral descriptions. That is a substantive instance regime, not a faithful limit of every GPCC. WPO itself remains the paper’s criterion: there is no simplifying change to the Pareto question. The restriction instead supplies a compact description of the mechanisms that large populations can plausibly use. A further question is whether succinct, non-polyhedral aggregate outcome rules preserve tractability. Extending the mirror to Nash equilibrium is also less straightforward: in a nonatomic population, one person’s action may have no effect on the aggregate outcome, changing the individual-deviation question.

The case AGAINST (opponent, writing after the proponent)

The strongest negative is that this paper has no named computational result to mirror. Theorem 1 is a soundness and completeness result for an axiomatization; Propositions 1–3 characterize effectivity functions; Proposition 4 says that several solution concepts are captured by formulas. Section 4 describes model checking and theorem deduction as applications, but gives no complexity bound or algorithmic result. Under ChoCo’s stated test, that is a serious mismatch: a complexity theorem for a continuous version would be a new result about a newly chosen problem, rather than a mirror of a computational result in this paper.

The WPO proposal is the best bridge, and it is coherent. But it changes what is being computed. In the paper, WPO is a property of a given valuation: find its outcome, then check whether any reachable outcome is strictly preferred by every player. With an explicit outcome table, that is a scan of the listed profiles and outcomes. With the proposed continuous model, the interesting work instead comes from introducing an anonymous aggregate mechanism whose outcome regions are polyhedral. The LP then tests whether a better outcome is reachable under that new mechanism. That is a sensible adjacent problem, but the paper’s WPO characterization supplies no computational structure for it.

The type model makes the gap clearer. WPO’s Pareto condition depends on which preference orders occur, not on their masses: each supported type must strictly prefer the candidate improvement. Masses matter only through the newly introduced aggregate mechanism and the feasible action flows. Listing that mechanism’s polyhedral regions makes the proposed feasibility test polynomial by construction. If one uses a more succinct mechanism description to create algorithmic difficulty, the difficulty comes from that encoding; it is not a population-complexity result of the paper. Replacing the arbitrary outcome function on individual action profiles with an anonymous function of aggregate actions is a substantial modeling choice, even if it is plausible for some applications.

A stronger alternative might continuize Nash-equilibrium model checking. But in an atomless population, one person’s deviation has no effect on aggregate actions, so the equilibrium notion changes to a nonatomic or Wardrop-style one. Treating each type as a strategic player preserves deviation power but collapses population multiplicity; keeping finite agents and tracking the effect of their deviations requires an additional finite-size or approximation parameter. Any of those could motivate a research project, but none is already the computational problem this paper studies.

So the negative case is strongest as a claim about fit: this paper is a logic and game-solvability contribution, not a computational complexity paper, and the proposed WPO LP result is mainly a new anonymous-mechanism problem. It is weaker as a universal claim that no worthwhile question can be built from the paper. The continuous WPO question is well-posed and might be worth pursuing on its own; I cannot honestly rule out every useful continuation.
