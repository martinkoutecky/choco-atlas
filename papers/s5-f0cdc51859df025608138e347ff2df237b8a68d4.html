The continuous mirror question

Given a finite directed network template with private arc types \(T\), public arc types \(U\), rational masses \(\mu_t\) summing to \(1\), and rational public capacities \(b_u\), form each admissible \(k\)-clone game using \(k\mu_t\) private unit arcs of type \(t\) and \(kb_u\) public unit arcs of type \(u\). Let \(a_t^{(k)}\) be the common payoff of type-\(t\) owners in that game’s nucleon. Under the promise that \(a^{(k)}\) converges, compute an approximation to \(a=\lim_k a^{(k)}\) within rational precision \(\delta>0\), in time polynomial in the template size, type counts, input bit length, and \(\log(1/\delta)\).

The model it lives in

A high-multiplicity family of cooperative flow games: type \(t\) is an interchangeable private arc owner with mass \(\mu_t\); public capacity \(b_u\) scales per capita; each finite clone game retains the paper’s coalition max-flow worth and nucleon selection rule.

The objection that survived

The paper’s polynomial-time bound is in the explicit network size, so it gives neither a succinct algorithm for the cloned instances nor a convergence rate for their nucleon payoffs.

What the mirror covers

The mirror concerns Theorem 2’s nucleon computation. It leaves Theorem 1’s approximate-core characterization and the paper’s structural lemmas outside the proposed limit problem.

Open questions for a prover

  • Does the per-type nucleon payoff vector converge for every rational typed network template, and if not, which templates guarantee convergence?
  • Can the limit be approximated in time polynomial in the succinct template size and \(\log(1/\delta)\), with an explicit convergence bound?
  • Does the limit admit a finite-dimensional characterization that captures the finite games’ lexicographic treatment of coalition excesses?

The case FOR (proponent)

The strongest mirror I believe is a limit version of the nucleon computation. It uses the paper’s actual players—owners of private network arcs—and makes many identical owners into a population of types.

Theorem 2 is the anchor. It is proved in this paper, using its polynomial-time nucleon algorithm for the auxiliary game and a cited scaling result. In full, it says: for a flow game \(\Gamma_D=(N,\gamma)\) with public arcs and private players \(N\subseteq E\), the nucleon \(\eta(\Gamma_D)\) can be computed in polynomial time. If \(\sigma_N=1\), then \(\eta(\Gamma_D)=\mathcal C(\Gamma_D)\); otherwise, the nucleon is a singleton. The paper gives no named hardness result, so this is an algorithmic mirror, not a claim that a discrete hardness result dissolves.

Here is the regime. A network has a fixed finite set \(T\) of private arc roles—for example, particular directed links between junctions. Many small operators each own one unit-capacity private arc of a role \(t\), and operators of the same role are indistinguishable in the game. Their population shares are rational masses \(\mu_t>0\), with \(\sum_{t\in T}\mu_t=1\). Public links remain available to every coalition. In a large infrastructure system, private capacity may be spread across many small providers on a few standard routes; shared public capacity can scale with the population. This is a constructed regime, but the repeated parallel arcs it requires are explicitly allowed by the paper’s model.

My lead question is Limit Nucleon for Typed Flow Networks. Its instance is a directed network template with source and sink, private arc roles \(T\), public arc roles \(U\), rational private masses \(\mu_t\), and rational public capacities \(b_u\) per unit population. Assume every source–sink path uses a private arc. For each admissible integer \(k\) such that \(k\mu_t\) and \(kb_u\) are integers, form the paper’s finite flow game by making \(k\mu_t\) private unit arcs of each role \(t\) and \(kb_u\) public unit arcs of each role \(u\). Let \(a_t^{(k)}\) be the payoff to each private arc owner of role \(t\) in that game’s nucleon. For sufficiently large \(k\), Theorem 2 makes the nucleon a singleton; symmetry among parallel copies makes \(a_t^{(k)}\) well-defined.

The problem is: assuming the vectors \(a^{(k)}\) converge along these admissible \(k\), compute their limit \(a\). A solution algorithm takes any rational precision \(\delta>0\) and returns \(\hat a\) with \(\|\hat a-a\|_\infty\leq\delta\). Its target running time is polynomial in the network size, \(|T|\), the input bit length, and \(\log(1/\delta)\). The limiting vector is a per-capita allocation: \(\sum_t\mu_t a_t\) equals the maximum flow per unit population in the template with private capacities \(\mu_t\) and public capacities \(b_u\). This makes the society itself a mass distribution over arc-owner types, while retaining the paper’s coalition-flow question and its nucleon as the selection rule.

I would put this question in Class A as a plausible research target, not as a consequence already proved by Theorem 2. The paper’s iterative LP method and network flow subroutines give a concrete starting point for aggregating repeated arcs and studying the limit. The main follow-up questions are whether the limit exists for every rational template, whether it has a finite-dimensional LP or separation characterization, and whether the convergence rate can be bounded in terms of the network, type support, and input bit length.

The mirror covers Theorem 2’s nucleon computation only. The paper’s approximate-core characterization is useful structural context, but I would not count it as a second anchor here.

The weakest point is that a continuum nucleon does not come for free: with continuum coalitions, the paper’s finite lexicographic excess vector has no immediate literal counterpart. Defining the proposed object as the limit of finite cloned games supplies a precise selection rule, but convergence and efficient computation of that limit are new results to establish. There is also a real modelling co-modification in scaling public capacity per capita. I think the case survives those qualifications because the clones are exactly identical arc owners, and the finite instances are instances of the authors’ stated game.

The case AGAINST (opponent, writing after the proponent)

Theorem 2 is a real computational anchor: it proves polynomial-time computation of the nucleon. And the proposed population regime clears the main modelling objection. Owners of parallel private arcs are interchangeable, so arc role is a sensible type; repeated parallel arcs are allowed by the paper; and scaling public capacity with the population is a legitimate co-modification. I cannot make a credible case that identity or lack of multiplicity rules out this mirror.

The strongest objection is that Theorem 2’s polynomial time is measured in the number of individual arcs. In the proposed limit, that number grows with the cloning factor \(k\), while the input gives only the type masses and capacities. The theorem therefore supplies no algorithm polynomial in the succinct input size, nor any rate at which \(a^{(k)}\) approaches its limit. The proposed approximation task also assumes convergence without providing a way to establish it or a convergence bound. A direct algorithm might overcome these gaps, but it would need new results; the paper’s algorithm does not provide the claimed Class A starting point by itself.

A direct continuum formulation faces a related issue. A coalition could be represented by a mass vector \(z\), with worth given by the maximum flow at those private capacities. But the finite nucleon lexicographically orders the excesses of *all* coalitions. In a continuum there is no immediate analogue of that finite sorted vector. Taking only the worst excess gives an approximate-core question, not the nucleon; weighting excesses by a distribution on coalitions can overlook small coalitions whose constraints matter in the finite games. Defining the object as the limit of cloned games avoids choosing such a distribution, but leaves convergence and efficient approximation to prove.

That is a substantial challenge to the proponent’s claim that the mirror plausibly belongs in Class A. It is not, however, a defeat of the mirror itself. A type-level flow model is plausible, the limit question is precise once convergence is settled, and an efficient algorithm—or a proof that convergence fails—would be a worthwhile computational result. The honest negative case is weak on the universal claim: I can question whether this particular algorithmic bridge exists, but I cannot rule out a worthwhile continuous mirror.
