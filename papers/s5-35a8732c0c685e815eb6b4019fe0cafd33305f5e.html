The continuous mirror question

Given rational type masses, stand-alone payoffs, a rational piecewise-affine coalition-worth function, and a finite rational step allocation, with nonempty core, does a primitive-recursive algorithm output a finite rational step-encoded path to a core allocation? Each block selects positive mass, weakly improves every selected agent and strictly improves a positive-mass subset, and allocates exactly the coalition's worth.

The model it lives in

A unit-mass population has finitely many types, including the characteristics relevant to coalition worth and individual rationality. The input allocation and each later allocation are finite step functions over these types; a block selects encoded submasses from their steps. The worth of a coalition with type-mass vector \(q\) is \(V(q)\), and allocations are individually rational and efficient, with total payoff \(V(\mu)\). A core allocation admits no measurable blocking coalition under the stated weak-and-strict improvement rule.

The objection that survived

The finite-player proof searches over finitely many coalition sequences, while mass coalitions range over continuously many submasses; the proponent does not show that the resulting paths and core endpoints admit finite rational step encodings.

fatal: False

What the mirror covers

The mirror covers the constructive path result in Theorem 3.5, with Lemma 3.4's path-generation method as support. It does not cover Theorem 3.3's noncomputational existence bound, the other structural lemmas, or the paper's broader discussion of bargaining.

Open questions for a prover

  • Does nonempty core imply that every finite step allocation has a finite step-encoded path to some core allocation?
  • Can such a path-construction procedure be primitive recursive in the rational input description?

The case FOR (proponent)

The strongest mirror is core access through mass coalitions. The paper’s international-agreement story involves few countries, so it is a weak high-multiplicity example. A better regime is a large cooperative enterprise whose many members have a small number of productive types: for example, workers with the same skill, technology, and outside option. The population tends to infinity while the number \(\tau\) of distinct initial type-and-entitlement cohorts stays moderate. A type records the characteristics that affect coalition worth and individual rationality; an initial payoff is part of the cohort description. Later blocks may split a cohort, just as a finite game’s players can receive different payoffs.

Here is a concrete continuous model. Normalize the population to mass \(1\), with \(\mu_\theta\) of intrinsic type \(\theta\). A coalition with type-mass vector \(q\), where \(0\le q_\theta\le\mu_\theta\), has transferable worth \(V(q)\). For a computational version, encode \(V\) as a rational piecewise-affine function on a finite rational polyhedral partition, and give each type a rational stand-alone payoff \(r_\theta\). An allocation \(x\) is an integrable payoff function over the population, individually rational almost everywhere and efficient: \(\int x=V(\mu)\). A block selects a positive-mass measurable coalition \(B\), with type-mass vector \(q\), and replaces the current allocation \(x\) by an efficient, individually rational allocation \(y\) such that \(y>x\) almost everywhere on \(B\) and \(\int_B y=V(q)\). A core allocation is one admitting no such block. This keeps the paper’s exact blocking convention: the coalition strictly improves and receives its full worth.

My lead anchor is Theorem 3.3, proved in this paper. It says that for a TU game with nonempty core, there is an integer \(M\) such that from every imputation \(a\), some core imputation \(c\) can be reached by a dominance path of length less than \(M\). The paper presents the bound as depending only on the number of players. A path here consists of imputations, each directly dominated by the next through a blocking coalition. The result uses Lemma 3.1, proved in this paper, and Lemma 3.2, which is cited from Sengupta and Sengupta [10].

The continuous question I would hand to a prover is Uniform Mass Core Access: for the rational finite-type continuum model above, assuming its core is nonempty, does there exist a bound \(f(\tau)\) such that *every* initial imputation can reach some core allocation in fewer than \(f(\tau)\) mass blocks? The bound must be independent of the population’s mass proportions and of the coefficients and breakpoints describing \(V\). A solution is the bound together with a path of mass coalitions and allocations witnessing it; each step has the strict-improvement and exact-worth conditions above. Minimizing the number of blocks is the objective.

This is a credible mirror because it preserves the paper’s central question—how many coalition blocks suffice to reach stability—and changes the population representation to mass over a few types. The authors already focus on deadlines and path length, so they would recognize the problem. It is not continuizing outcomes, probabilities, or time. I expect the unrestricted mirror to encounter a continuum-specific obstruction: even at fixed \(\tau\), a coalition may contain any mass vector \(q\), whereas the paper’s argument can exploit the finite combinatorics of coalitions. A counterexample with unbounded shortest paths at fixed \(\tau\) would be a meaningful Class C boundary. Restrictions on \(V\), such as concavity or a fixed number of affine pieces, may instead yield a Class A result. Further questions include whether accessibility always holds in this model and whether the bound can depend on \(\tau\) plus the description complexity of \(V\).

A second, distinct anchor is Theorem 3.5, also proved here. It says that when a TU game has nonempty core, a primitive-recursive algorithm can construct a finite path from any imputation to a core imputation, with each step a direct block. Its mass analogue is Constructive Mass Core Access: given the rational encoding of \(V\), the type masses and stand-alone payoffs, and an initial rational step allocation, output a finite sequence of mass blocks and step allocations ending at a core allocation. The output must certify exact efficiency, individual rationality, strict improvement on each blocking mass, and the coalition’s exact worth. This asks for an algorithm, not merely an existence proof; the encoding size includes the number of pieces describing \(V\). I expect the general piecewise-affine version to be difficult for continuum-specific reasons, since the algorithm must reason over continuously many candidate coalition masses. A positive result might follow from structure that reduces block search to a tractable finite optimization problem. The paper’s algorithmic result is expressly primitive-recursive, not a polynomial-time claim, so the mirror should test that constructive level before making stronger complexity claims.

These mirrors cover the paper’s core-access results, not its other discussion of bargaining, nor cooperative games as a whole. The weak point is that a typed, mass-dependent worth function is a genuine restriction on arbitrary TU games, and the paper itself does not supply such a type model. Still, the restriction is the high-multiplicity assumption under examination, not a cosmetic change to the blocking problem.

The case AGAINST (opponent, writing after the proponent)

Theorem 3.3 is the real anchor. Theorem 3.5 adds a primitive-recursive construction, but it is not a second, independent complexity result: its proof searches over bounded sequences of coalitions in a finite-player game. The paper gives no running-time or bit-complexity bound. So the case for two computational mirrors is weaker than it first appears; the programme would need to make the step bound itself computationally consequential.

The larger problem is that the proposed mass model has not yet specified a finite computational object. A rational piecewise-affine \(V\) and rational type masses are finite inputs, but an imputation is an integrable function and a block can be any measurable subset. Those data do not encode arbitrary starting allocations or the allocation functions a path must output. Restricting allocations to finitely many payoff classes would make the problem encodable, but partial-mass blocks can split a class and create new payoff classes at each step. The finite proof’s bound depends on classifying coalitions and player histories; \(\tau\), the number of intrinsic types, does not bound that evolving state. One can ask whether it nevertheless suffices, but that is an additional structural conjecture, not a direct transfer of the paper’s finite argument.

There is also a mismatch in the proposed block rule. In the paper, a coalition’s members may all be weakly better off while only some are strictly better off. Requiring \(y>x\) almost everywhere makes every member strictly better off and changes which transitions count. The natural mass translation is weak improvement almost everywhere, with strict improvement on a positive-mass subset. That repairs the rule, but it makes payoff strata and the choice of subsets more central: coalition mass \(q\) alone does not describe a block unless the current allocation is also suitably represented.

A finite-cohort version that only lets whole cohorts block is computable, but it collapses to an ordinary finite game with \(\tau\) players. A version allowing partial cohorts is the more interesting mirror, and large production populations with repeated worker types are a plausible setting for it. I cannot honestly rule out that the authors would recognize that problem as worthwhile. My negative case is therefore limited: the two anchors do not yet establish a well-posed, finitely encoded continuous computational problem, and the proposed model leaves the hardest representation choices unresolved. That is a substantial gap in the case for the mirror, but not a convincing universal case that no worthwhile mirror exists.
