The continuous mirror question

Given candidates \(C\) and a finite support \(T\) of \(\tau\) types, each with ranking \(\succ_t\), known monotone weight vector \(w_t\), and binary-rational mass \(\mu_t\) summing to \(1\), let \(X\) be a measurable population partitioned into sets \(X_t\) of mass \(\mu_t\). For every measurable metric \(d\) on \(X\cup C\) with finite costs and consistent with each type’s ranking, can an algorithm using only \(C,T\), the rankings, weights, and masses output a ranking \(\sigma\) satisfying \(\int_X\sum_{j=1}^m w_{t(x),j}d(x,\sigma_j)\,dx \leq 3\min_{\pi\in S_C}\int_X\sum_{j=1}^m w_{t(x),j}d(x,\pi_j)\,dx\), in time polynomial in \(m,\tau\), and the input bit length \(L\)?

The model it lives in

The society is a distribution over types \(t=(\succ_t,w_t)\), with mass \(\mu_t\); the output is a permutation of \(C\), and its objective is the integral of the paper’s position-weighted metric cost. At position \(j\), Recursive FractionalVeto uses type masses proportional to \(\mu_t w_{t,j}\), grouped by each type’s top remaining candidate. The metric remains hidden and universally quantified, as in the paper.

What the mirror covers

Covers Theorem 8’s known-weights guarantee and its polynomial-time rule. It leaves the generic bound in Theorem 5, Proposition 6, Theorem 11 on Weighted Recursive Copeland, Theorems 12–14 on identical weights, and Theorems 15–16 on normalized weights unmirrored.

Open questions for a prover

  • Can one give a formal high-multiplicity dictionary between the finite-voter and atomless formulations that permits hidden metric distances to vary within each observable type?

The case FOR (proponent)

The strongest positive mirror is the known-weights result, anchored on Theorem 8, proved in this paper. It says: *for every monotone weight profile, Recursive FractionalVeto has distortion at most \(3\), and this bound is optimal among weight-aware social welfare functions.* In full, the rule builds a complete ranking one position at a time, using FractionalVeto on the remaining candidates with voter weights normalized from that position’s column. For every metric consistent with the voters’ rankings, the resulting ranking’s position-weighted social cost is at most three times that of the best ranking for that metric; no weight-aware rule can achieve a smaller worst-case bound.

This is an algorithmic quality result, not a numbered NP-hardness, \(P\), or parameterized-complexity classification. The paper’s §3.2 does state that the direct FractionalVeto implementation runs in polynomial time. So Theorem 8 is a credible approximation-algorithm anchor, with that qualification; the paper offers no named complexity-class result.

A precise population version is Continuous Known-Weight Metric-Distortion Ranking. The input is a candidate set \(C\) and a finite support \(T\) of \(\tau\) types. Each type \(t\) consists of a complete ranking \(\succ_t\) and a known, monotone position-weight vector \(w_t\); its population mass \(\mu_t\) is a binary rational, with \(\sum_t\mu_t=1\). Represent the population by \(X=[0,1]\), partitioned into measurable sets \(X_t\) of measure \(\mu_t\). A metric \(d\) on \(X\cup C\) is admissible when it is consistent with each individual’s type ranking. Given only the type masses, rankings, and weights—not \(d\)—the task is to output a permutation \(\sigma\) of \(C\) such that, for every admissible \(d\),
\[ \int_X\sum_{j=1}^m w_{t(x),j}d(x,\sigma_j)\,dx \;\leq\; 3\min_{\pi\in S_C} \int_X\sum_{j=1}^m w_{t(x),j}d(x,\pi_j)\,dx. \]
The objective and output remain those of the paper; the population is what becomes a distribution. At position \(j\), the type masses supplied to FractionalVeto are proportional to \(\mu_t w_{t,j}\), grouped by each type’s top remaining candidate. With rational input, this gives a polynomial-time algorithm in \(m,\tau,L\), where \(L\) is the total bit length. The expected outcome is tractability with optimal worst-case distortion \(3\); the single-winner special case supplies the matching lower bound. This mirror covers Theorem 8’s known-weights result, not the paper’s other weight regimes.

A plausible regime is a large recommendation platform ranking a fixed shortlist for millions of users. Users can share both an ordinal ranking and a known position-importance profile, while the number of such combinations remains far below the user count. Their masses represent population shares. This is a natural high-multiplicity input, and the output is still a discrete ranking. The mirror does not assume everyone in a type shares a location: it retains the paper’s adversarial uncertainty over metrics within each type.

The weak point is that those hidden metrics can give same-type users different realized distances. If “type” must include every realized cost, grouping only by observed ranking and weights may fail the programme’s strict high-multiplicity test. The case for acceptance is that the paper itself withholds the metric from the rule and evaluates it through worst-case distortion, so the relevant input type is the ranking and disclosed weight profile. A further limitation is that the result transfers almost directly: the paper already uses fractional masses in FractionalVeto. This makes the mirror plausible and precise, but a modest contribution to the programme’s complexity landscape rather than a new hardness-versus-tractability boundary.

The case AGAINST (opponent, writing after the proponent)

Theorem 8 is the proponent’s only anchor, and it is a real algorithmic guarantee: Recursive FractionalVeto produces a ranking with distortion at most \(3\). The strongest mirror would put rational mass on types consisting of a ranking and a known weight vector, then ask for the same guarantee when the unknown consistent metric is defined over a population measure.

That mirror is already captured by the paper’s machinery. Given type masses \(\mu_t\), the objective is the paper’s sum with each type’s contribution weighted by \(\mu_t\). At position \(j\), the relevant voter mass is \(\mu_t w_{t,j}\), exactly the fractional mass used by the rule. Since the programme’s masses are binary rationals, they can also be expanded into a finite electorate of identical copies. Conversely, identical ranking-and-weight rows in a finite electorate can be aggregated into types. The scale of the objective changes, but its distortion ratio does not.

Allowing people of the same observable type to have different hidden metric locations does not create a new algorithmic question. The proof’s matching argument can be lifted to those people by splitting each type’s mass in the proportions of its fractional matching; the inequalities then integrate over the population. The ranking rule still needs only the type masses, rankings, and weights. So even the stronger measure-space formulation inherits the same guarantee and computation.

The authors themselves signal how little separates these formulations: they interpret each position’s weights as voter masses, discuss the exponential cost of explicitly cloning voters, and give a polynomial direct fractional implementation. The continuous version would make that interpretation explicit, but would not add a new complexity boundary, pricing problem, or algorithmic obstacle. The theorem is about a worst-case distortion guarantee, not a complexity classification; its computational content is already the efficient rule that the proposed mirror would reuse.

The negative case is strongest as a novelty objection: this is not merely a continuous answer that happens to be known elsewhere; the paper’s own model and algorithm already operate on the relevant fractional masses. It is not airtight, because the authors might value a formal population-measure statement or a high-multiplicity input dictionary. But that would be a reframing of Theorem 8, rather than a worthwhile new continuous mirror for ChoCo’s complexity landscape.
