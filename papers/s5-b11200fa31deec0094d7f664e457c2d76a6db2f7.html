The case FOR (proponent)

There is no numbered NP-hardness, polynomial-time, FPT, or similar complexity result in this paper. The closest useful anchor is Theorem 2: for the fixed common base period \(L\), with additive setup costs \(K(R)=\sum_{i\in R}K_i\), the paper proves that the cost game \((N,V_{A\Gamma_L})\) is concave:
\[ V_{A\Gamma_L}(A)+V_{A\Gamma_L}(B)\ge V_{A\Gamma_L}(A\cup B)+V_{A\Gamma_L}(A\cap B) \]
for all coalitions \(A,B\subseteq N\). The theorem is proved here; its proof follows the approach of Teo and Shu for unrestricted real replenishment intervals and handles the power-of-two restriction. Concavity implies a nonempty core. This is a structural result that supports a computational question, not a complexity classification.

My lead mirror is a continuous core-allocation problem for a large retailer network. A type \(t\) records a retailer’s complete relevant data: demand \(d_t\), holding costs, and setup cost. The input is a finite support \(T\) with rational masses \(\mu_t\ge 0\), \(\sum_t\mu_t=1\), and a shared warehouse. Many retailers share each type, so the number of retailers \(n\) is much larger than \(\tau=|T|\). Hold the base period \(L\) fixed for every coalition, as the theorem does. To keep the warehouse’s contribution nonzero in a per-capita model, interpret its setup cost as scaling with network size; normalize total costs by \(n\). This is a supply-chain version of the programme’s permitted co-modification for per-capita quantities.

For any coalition mass vector \(x\in[0,\mu]\), let
\[ V_L(x)=\inf_{T_0,T_t\in\Gamma_L} \left[ \frac{\kappa_0}{T_0} +\sum_{t\in T}x_t\left( \frac{\kappa_t}{T_t} +H_tT_t +H_t^w\max\{T_0-T_t,0\} \right) \right], \qquad \Gamma_L=\{2^qL:q\in\mathbb Z\}. \]
Here \(\kappa_0\) is the normalized warehouse setup cost, \(\kappa_t\) is the retailer setup cost for type \(t\), and \(H_t,H_t^w\) are the type’s retailer and warehouse holding-cost coefficients. Each type acts as a synchronized cohort with one replenishment interval. That restriction is natural in the additive model: once \(T_0\) is fixed, identical retailers’ interval choices separate, so copies of the same type can use the same minimizing interval.

The question is: given these data, find a cost density \(a_t\) for each type such that
\[ \sum_t\mu_ta_t=V_L(\mu) \quad\text{and}\quad \sum_tx_ta_t\le V_L(x) \ \text{for every }x\in[0,\mu]. \]
Such a vector is a continuous core allocation: it divides the grand coalition’s average cost, and no coalition of any fractional mass composition pays more than its own optimized cost. The expected direction is tractable for fixed \(\tau\), by extending the paper’s exchange and marginal-cost arguments and exploiting the type-level optimization. Further questions are whether the continuous core always exists, whether a density can be represented and computed efficiently from binary-rational input, and whether finite high-multiplicity cores converge to it.

This covers Theorem 2’s additive-setup result and its common-\(L\) regime. It does not claim a mirror for the paper’s general submodular setup result or for the variant where each coalition chooses its own base period.

The weak point is that Theorem 2 proves submodularity only on the finite coalition lattice. It does not establish the stronger inequalities over every fractional mass vector required by this mirror; those inequalities and the cost-density construction are new questions. Still, the proposed model keeps the paper’s underlying problem—joint replenishment and stable allocation of system-wide cost—while making the retailer population itself the continuous object.

The case AGAINST (opponent, writing after the proponent)

The strongest objection is that this paper offers no computational result for ChoCo to continuize. Theorem 2 proves concavity of a cost game for whole coalitions; nonemptiness of the core follows from that structural property. Theorem 1 and Corollary 1 give core allocations, but the paper makes no complexity claim about computing them. So the proposed task—computing a cost density under constraints for every fractional coalition—is a new algorithmic problem built from the paper’s model, not a continuous version of a computational result the paper establishes.

A large network of retailers with repeated types is a plausible high multiplicity setting. And the proponent’s shared interval for each type is defensible: once the warehouse interval is fixed, identical retailers’ interval choices separate. The more serious issue is preserving the paper’s fixed warehouse setup cost in a per capita limit. With warehouse setup cost \(K_0\) fixed as the number \(n\) of retailers grows, normalized setup cost is \(K_0/(nT_0)\). It vanishes in the limit; the warehouse can choose \(T_0\leq \min_i T_i\), removing the warehouse holding term too. The limiting cost then separates into retailers’ individual costs, and the core density is just their individual optimal costs. The nontrivial formula in the proposed mirror instead requires \(K_0\) to grow proportionally with \(n\). ChoCo permits co-modifications of this kind, but here that changes the economics of the paper’s fixed shared setup fee. It would need to be a setting the authors recognize as their problem.

Even with that scaling, Theorem 2 does not supply the proposed continuous core result. It compares whole subsets of retailers; the density inequalities range over every fractional mass vector. Proving those inequalities and constructing the density would be new work. But the central question would then be whether this particular fractional cost game has a continuous core, not a complexity question already present in the paper. The objective also separates by type once \(T_0\) is chosen, so the proposed formulation offers little evidence of a broader computational landscape to chart.

This is a serious negative case against treating Theorem 2 as a strong ChoCo anchor: the computational target is absent, the natural fixed-cost limit loses the interaction, and preserving the interaction calls for a changed cost regime. It is not, however, a universal veto. A growing network with a setup cost that scales with network size is coherent, and an algorithmic study of its fractional core could be worthwhile. The honest limitation is that this would be a new computational study motivated by the paper, rather than a mirror of one of its computational results.
