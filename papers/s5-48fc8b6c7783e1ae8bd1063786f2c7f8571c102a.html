The continuous mirror question

Given finitely many complete tenant types \(T\) with rational masses \(\mu_t\), each type’s request DAGs with edge utilities, and shared resource classes \(K\) with per-unit-mass capacities \(b_k\), choose masses \(x_{t,q}\ge 0\) over each type’s tuples of paths \(q\). Require \(\sum_q x_{t,q}=\mu_t\) for every \(t\) and \(\sum_{t,q}x_{t,q}a_{t,q,k}\le b_k\) for every \(k\), where \(a_{t,q,k}\) is the additive resource use of tuple \(q\); compute an allocation maximizing \(\sum_{t,q}x_{t,q}U_t(q)\).

The model it lives in

A continuum of repeated NFV tenants represented by complete types, each receiving an integral tuple of paths through its preference DAGs; only the mass assigned to each tuple is fractional. Shared resource capacities scale with population, and additive node resource use makes pricing decompose into longest-path computations.

What the mirror covers

Open questions for a prover

The case FOR (proponent)

The strongest anchor is Proposition 1, proved in this paper. It says that for V-DPAP, deciding whether there is a valid path allocation whose utilitarian value is at least a given bound is NP-complete. The paper proves this by reducing 3-SAT: it builds one DAG per clause, uses paths to represent satisfying assignments to that clause, gives the literal-selection edges weight \(1\), and makes complementary literals conflict across clauses. An allocation reaching the number of clauses exists exactly when the formula is satisfiable.

A continuous mirror I would defend is Continuum V-DPAP-UTIL. Its instance has a finite set of complete request types \(T\), rational masses \(\mu_t\) summing to \(1\), and, for each type \(t\), the DAGs and edge utilities of its requests. A type’s individual options are tuples of paths \(q\in Q_t=\prod_{g\in G_t}\Pi_g\), with utility \(U_t(q)=\sum_{g\in G_t}u_g(q_g)\). The instance also gives conflict-resource classes \(k\), each with a per-capita supply \(b_k\); \(a_{t,q,k}\) is how much of class \(k\) an individual of type \(t\) uses under option \(q\). The question is to find nonnegative masses \(x_{t,q}\) maximizing \(\sum_{t\in T}\sum_{q\in Q_t}x_{t,q}U_t(q)\), subject to \(\sum_{q\in Q_t}x_{t,q}=\mu_t\) for each type and \(\sum_{t,q}x_{t,q}a_{t,q,k}\le b_k\) for each conflict class. A solution assigns each person a whole path tuple; only the fractions of each type receiving different tuples are continuous.

This preserves the paper’s underlying choice: agents select paths through preference DAGs, receive the edge-additive utility, and compete over incompatible items. The co-modification is to scale the supply of exclusive slots or function instances with the population, so resource supply per agent remains meaningful. In the paper, a conflict \(\sigma\) is encoded by \(\sum_{v\in\sigma}\beta_v\le|\sigma|-1\); the mirror treats such conflicts as scarce resource classes with normalized supply. That is a reasonable high-multiplicity model for many network-service tenants in a small number of repeated service-level classes, choosing among the same kinds of function-chain DAGs while providers scale instance capacity with demand. The authors themselves identify NFV as a domain for DPAP.

I expect this mirror to be tractable. Its mass allocation is a linear program with potentially exponentially many path-tuple variables. The pricing problem for a type is to maximize utility minus the prices of the conflict resources it uses. With the paper’s additive edge utilities and node-based conflicts, that separates into longest-path computations in the type’s DAGs. Thus the exponential set of options need not prevent polynomial-time optimization in the explicit DAG and type description. The main follow-up questions would be the discrete-to-continuous approximation guarantee as the number of tenants grows, the effect of capacity ratios on that guarantee, and which capacity structures keep pricing tractable.

The paper’s orbit-slot ownership scenario is a poor high-multiplicity anchor: the authors say the number of users who can afford slots is low. My positive case depends on the repeated-tenant NFV regime instead. Its weakest point is that scaling conflict capacity changes the original all-or-nothing feasibility condition into a cohort-level capacity constraint. That change is defensible under the programme’s stated scope, but an author or referee might still judge it too large a model change. This case covers Proposition 1 only; it does not claim mirrors for the leximin or R-DPAP hardness propositions.

The case AGAINST (opponent, writing after the proponent)

Proposition 1 is a genuine computational anchor, so the strongest objection is about whether its hardness has a useful population regime. The SAT reduction gives each clause its own DAG, with conflicts linking literal occurrences across clauses. Those clause-specific graphs are different types: for a formula with \(m\) clauses, the natural support size grows with \(m\). The reduction shows hardness for heterogeneous path allocation; it does not itself suggest a large population drawn from a small set of complete types.

The proposed resource mirror also changes what a conflict means. In V-DPAP, a single selected profile is invalid if it contains all vertices of a conflict set. In the LP, fractions of a type can choose different options, and a per-capita capacity constrains their aggregate use. Keeping the original scarce items while population grows makes normalized capacity shrink toward zero. Scaling capacity with population avoids that degeneration, but turns hard exclusivity into a capacity-allocation model. That may be a sensible co-modification, but it no longer carries the SAT gadget’s specific conflict structure into the continuum.

That objection does not defeat the best repair, though. The paper itself names NFV as an application and lists capacity-bearing resources as future work. A provider serving many tenants from a few complete service-chain types, while provisioning compute capacity with demand, is a credible high-multiplicity regime. Each tenant can still receive an integral path; only the distribution of identical tenants across paths is fractional. With additive resource use, the resulting LP and longest-path pricing problem are computational questions the authors could recognize. Whether that mirror is valuable is therefore difficult to rule out.

So the negative case is strongest against treating Proposition 1’s SAT reduction as evidence for a natural continuum of that exact problem. It does not support the requested universal claim. The repeated-tenant NFV mirror survives the objections, and I cannot honestly argue that no scenario yields a worthwhile continuous mirror.
