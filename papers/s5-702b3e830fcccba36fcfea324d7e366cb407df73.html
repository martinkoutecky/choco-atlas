The continuous mirror question

Given rational type masses \(\mu_1,\ldots,\mu_k>0\) summing to \(1\), and rational values \(v_1>\cdots>v_k>0\) for one divisible good, let \(M_s=\sum_{i=1}^s\mu_i\), \(v_{k+1}=0\), and \(\Phi_i=\sum_{s=i}^k (v_s-v_{s+1})/M_s\). Find the minimum \(\alpha\) and rates \(x_i\ge 0\) such that \(\sum_i\mu_i x_i=1\) and \(v_i x_i\ge\Phi_i/\alpha\) for each type. Here a type-\(i\) agent receives \(x_i/n\) in a finite replica of size \(n\), and its Shapley value is \(\Phi_i/n\).

The model it lives in

A society is a distribution over \(k\) productivity types, represented by rational masses \(\mu_i\); each type has linear value \(v_i\) for one divisible good. The decision variables are type-level grant rates \(x_i\), with mass-weighted unit-supply feasibility and Shapley-density fairness constraints. The optimum is \(\alpha^*=\sum_i\mu_i\Phi_i/v_i\), attained by \(x_i=\Phi_i/(\alpha^*v_i)\), computable in polynomial time in \(k\) and the input bit length.

What the mirror covers

It mirrors Theorem 4.5’s few-type linear result, including its allocation guarantee and tightness; it leaves the concave and capped-concave bounds, sampling result, and bounded-value-ratio result untouched.

Open questions for a prover

  • For several divisible goods, which valuation and type structures permit polynomial-time computation of the finite-replica Shapley entitlement densities and the optimal mass-SVF allocation?

The case FOR (proponent)

My lead is Mass-SVF-OPT, a high-multiplicity version of the paper’s one-good, linear-valuation problem. The paper’s strongest anchor for it is Theorem 4.5, proved in this paper: with linear valuations and \(k\) distinct agent types, a polynomial-time algorithm computes a \(k\)-SVF allocation, and that factor is asymptotically tight when \(k=o(\ln n)\). The paper has no named NP-hardness result, so this positive algorithmic result is the appropriate anchor.

A plausible regime is a large funding programme with many standardized projects competing for one divisible, normalized budget. A type is a project’s exact value per unit of funding. Projects of the same type have identical valuations, and \(\mu_i\) is the fraction of projects of type \(i\). The population can be very large while the number \(k\) of distinct productivity types stays small. This is a distribution over the population itself; the fact that the budget is divisible is already part of the paper’s model.

Here is the continuous problem. An instance consists of positive rational masses \(\mu_1,\ldots,\mu_k\) summing to \(1\), and rational values \(v_1>\cdots>v_k>0\). Define \(M_s=\sum_{i=1}^s\mu_i\), set \(v_{k+1}=0\), and give type \(i\) the Shapley entitlement density
\(\Phi_i=\sum_{s=i}^k (v_s-v_{s+1})/M_s\).

The question is to find the smallest \(\alpha\) and type allocation rates \(x_i\ge 0\) such that \(\sum_i\mu_i x_i=1\) and \(v_i x_i\ge\Phi_i/\alpha\) for every type. Here \(x_i/n\) is the actual grant to each type-\(i\) project in a finite population of size \(n\); the mass-weighted constraint says those grants use the unit budget.

This entitlement has an exact finite-replica interpretation. If \(n\mu_i\) is an integer, then in the \(n\)-project election each type-\(i\) project’s Shapley value is \(\Phi_i/n\). Thus both the entitlement and the allocation are rescaled per-project quantities, not a new fairness benchmark. The optimum has the explicit solution \(\alpha^*=\sum_i\mu_i\Phi_i/v_i\), with \(x_i=\Phi_i/(\alpha^*v_i)\). Computing it takes polynomial time in \(k\) and the input bit length, without expanding a potentially enormous finite replica.

This is consistent with Theorem 4.5’s \(k\) guarantee, and its lower-bound construction yields continuous instances with \(\alpha^*=\Omega(k)\): take the construction’s type counts as rational masses over a sufficiently large denominator, with geometrically spaced values. So the worst-case ratio remains \(\Theta(k)\) in this mirror. The expected classification is tractable, through type compression and an exact formula. Further questions include extending the benchmark and optimization to several goods, allowing concave valuations, and determining which type structures keep the computation polynomial in the support size and bit length.

I think the authors would recognize this as their problem: it keeps the same Shapley entitlement, no-transfer allocation objective, and linear productivity model, while replacing a list of projects by its type masses. The narrow scope is deliberate: it mirrors Theorem 4.5’s few-type result, not the paper’s general concave-valuation results.

The weakest point is that Shapley values are defined for individual players, and each player’s value vanishes as the population grows. The mirror therefore uses the scaled entitlement density \(n\phi_i\) and scaled grant \(n\) times the per-project grant. That scaling is exact for rational finite replicas in this linear setting, but authors might regard it as a chosen normalization rather than a canonical nonatomic Shapley value.

The case AGAINST (opponent, writing after the proponent)

The strongest attack is that a nonatomic society has no uniform random permutation of its members, so an individual Shapley value becomes zero in the limit. A type-level entitlement density therefore needs a normalization, and the raw continuum model does not supply one by itself.

For this anchor, though, the proposed finite-replica limit supplies a natural normalization. With \(q_i=n\mu_i\), the discrete Shapley value of each type-\(i\) project is exactly \(\Phi_i/n\). Scaling both that entitlement and the project’s grant by \(n\) leaves the SVF ratio unchanged, while feasibility becomes \(\sum_i\mu_i x_i=1\). The extension is pinned down by the finite model, rather than chosen arbitrarily.

That makes the mirror faithful to Theorem 4.5’s problem: identical productivity types, no transfers, and a type-level allocation guarantee. Its exact formula may make this particular mirror easy, and its approximation ratio may retain the same \(\Theta(k)\) behavior. Neither is a reason the question is unworthy under the programme’s criteria. The paper’s finite-agent Shapley computation is not an existing continuous-population treatment, and its treatment of divisible goods does not make the population continuous.

So I cannot make a credible case that this anchor fails, including in its stronger version. The negative case is weak here: the proponent has a coherent, exact population limit, and it appears to be a worthwhile mirror.
