The case FOR (proponent)

The strongest honest case is conditional: the paper has a natural high-multiplicity mirror, but it does not satisfy the programme’s strict computational-anchor rule. None of its numbered results proves NP-hardness, membership in P, FPT, W[1]-hardness, or an approximation algorithm. The statement that Nash-welfare maximization is “not computationally tractable” is background, not a theorem proved here. Thus the following are structural anchors, not computational ones.

The common continuous model is this. Let \(G\) be a finite set of good slots and \(T\) a finite set of complete valuation types. Type \(t\) has mass \(\mu_t\), with \(\sum_t\mu_t=1\), and valuation \(v_t\). Goods have per-capita supplies \(\sigma_g\). A bundle remains integral: each infinitesimal agent receives some \(S\subseteq G\), never a fractional good. The decision variable is

\[ x_{t,S}\ge 0, \]

the mass of type \(t\) receiving bundle \(S\), subject to

\[ \sum_S x_{t,S}=\mu_t,\qquad \sum_{t,S:g\in S}x_{t,S}=\sigma_g. \]

Fractionality occurs only at the population level.

The natural continuum EF1 condition is pairwise: whenever \(x_{t,S}>0\) and \(x_{u,R}>0\), type \(t\) must be able to remove one good from \(R\) so that

\[ v_t(S)\ge v_t(R\setminus\{g\}) \]

for some \(g\in R\). Pareto dominance is defined agentwise through a reassignment coupling \(z_{t,S,R}\): the new bundle \(R\) must satisfy \(v_t(R)\ge v_t(S)\) for every positive mass, with strict inequality for positive mass somewhere. This preserves the paper’s underlying EF1 and PO questions rather than replacing them with average utility or fractional goods.

My lead is Theorem 3.1, proved in this paper. It states that there is a two-agent, eight-good instance with monotone submodular valuations such that, for every \(\alpha>23/24\), no allocation is both EF1 and \(\alpha\)-PO; in particular, no allocation is both EF1 and PO.

The corresponding continuous problem is:

\[ \textsc{HM-Submodular-EF1-}\alpha\textsc{PO}. \]

An instance consists of finitely many submodular valuation types \(T\), rational masses \(\mu_t\), integral good slots \(G\), rational per-capita supplies \(\sigma_g\), and \(\alpha\in(23/24,1]\). The question is whether there exists a mass allocation \(x\) satisfying the supply equations, continuum EF1, and \(\alpha\)-PO. A solution is the complete configuration \(x_{t,S}\); a negative answer means that every such configuration has an \(\alpha\)-Pareto improvement.

This is a credible mirror because it retains exactly the paper’s objects: indivisible bundles, submodular valuations, EF1, and coordinatewise Pareto efficiency. The high-multiplicity scenario is a large population receiving standardized packages of eight indivisible benefit slots, with only a few recurring valuation profiles. For the theorem’s pattern, take two cohorts of mass \(1/2\), one for each valuation, and supply half a copy per capita of each of the eight slots. A finite two-agent instance can then be repeated across a large population.

The continuous question is not a trivial repetition. One may mix several integral EF1 bundle patterns across the population, and EF1 must hold between every pair of bundles appearing with positive mass. The finite theorem therefore does not automatically settle the continuum question. The central question is whether mass-splitting creates an EF1-and-PO allocation that does not exist for one finite pair.

My forecast is a mixed boundary. With a fixed number of good slots and explicitly listed valuation tables, this becomes a finite configuration problem. With the number of goods variable, I would regard it as a plausible Class C problem: the difficult combinatorics concern which integral bundles may coexist in the support while avoiding Pareto improvements, not the number of agents. It is not a hardness-transfer result, because Theorem 3.1 contains no computational hardness claim.

A second, more positive anchor is Theorem 4.4, proved here. It says that if there is a common monotone envelope \(g\), each agent has a downward-closed certificate family \(\mathcal C_i\), and

\[ v_i(S)=\max\{g(T):T\subseteq S,\ T\in\mathcal C_i\} \]

is submodular for every agent, then an allocation exists that is both EF1 and PO; moreover, one can choose it to be leximin-optimal. Corollary 4.5 specializes this to common-weight matroid-rank valuations.

Its continuous mirror is \(\textsc{HM-Common-Envelope-EF1+PO}\). The input is \(T,\mu,\sigma\), a common envelope \(g\), and type-specific certificate families \(\mathcal C_t\). The task is to output a configuration \(x_{t,S}\) that is continuum-EF1 and Pareto optimal. In the matroid specialization,

\[ v_t(S)=\max\{w(I):I\subseteq S,\ I\in\mathcal I_t\}, \]

where all types share the item weights \(w\), but may have different matroids.

This regime is plausible for a large allocation system with many agents but few eligibility profiles: for example, repeated cohorts of workers receiving indivisible training or benefit slots, where types differ in feasible combinations but all slots have a common value scale. Here \(\tau\ll N\), and the type includes the entire matroid or certificate structure, so no individual-specific information has been silently discarded.

I would expect this mirror to be Class A under standard matroid or separation-oracle representations. The paper’s leximin certificate proof suggests a configuration LP for selecting certificate masses, followed by a residual assignment through an envy graph or flow. Matroid pricing can plausibly be handled by greedy optimization. The paper itself proves only existence, however; polynomial-time construction for the continuous version would be a new result.

The natural follow-up questions are whether the Theorem 3.1 obstruction survives repeated types, what the exact continuous \(\alpha\)-threshold is, whether common-envelope leximin allocations admit polynomial-size descriptions, and whether the paper’s Theorem 4.2 obstruction remains meaningful when fPO is already related to population-level randomization.

The weakest point is decisive: these are sensible continuizations of the paper’s allocation problems, but the paper supplies no qualifying computational anchor. Under a strict ChoCo grading rule, I would therefore report: strong substantive mirror, no compliant computational-mirror case.

The case AGAINST (opponent, writing after the proponent)

The negative case is strongest at the programme’s gate: this paper contains no qualifying computational result to continuize. Theorem 3.1 is a constant-size existence counterexample; Theorem 4.4 is an existence theorem. Neither defines an input problem, gives an algorithm, proves hardness, or states an approximation or parameterized result. The remark that Nash-welfare maximization is “not computationally tractable” is background, not a computational theorem established here. Under ChoCo’s stated rule, that is decisive: there is no computational anchor whose continuous analogue could be the paper’s contribution.

The proponent’s best version of Theorem 3.1 is nevertheless a sensible high-multiplicity model: finitely many valuation types, per-capita supplies of integral goods, and mass split among integral bundles. I would not object that such a population is artificial. But the finite obstruction does not survive as an inherited statement. Its proof examines one partition of eight goods between two named agents. In the continuum, mass can be distributed over several partitions. The four EF1 splits in the proof may be mixed, and Pareto improvement must then be defined over the resulting support or through a reassignment coupling. Determining whether those mixtures admit a support-wise EF1 and Pareto-optimal configuration is a new configuration problem, not Theorem 3.1 in continuous form.

One can make that new problem computationally interesting by varying the number of goods, valuation types, and representations of submodular functions. But then the paper supplies neither the problem nor its computational claim; the proposed hardness or algorithm would belong to a newly designed fair-division problem. With the paper’s actual eight goods and two valuation types, repetition creates a regime with no growing combinatorial structure to study.

Theorem 4.4 does not repair this. Its common-envelope and common-weight matroid-rank statements are also purely existential. A continuous version with type masses and scaled supplies is plausible, but an arbitrary envelope \(g\) and certificate families have no specified computational encoding. Even in the matroid specialization, the paper gives no procedure for computing a population-level leximin allocation, no configuration formulation, and no pricing or separation theorem. Saying that matroid greedy algorithms might help is a research proposal, not a result anchored in this paper.

The continuous problem would also need genuinely new choices about how leximin and Pareto dominance operate when one type is split among several integral bundles. Those choices can be made coherently, but whichever coherent choice is made, the resulting algorithmic question is new. It is not a continuous restatement of a computational theorem in the paper.

Thus the proponent has shown that sensible continuous fair-division questions can be attached to this paper. They have not shown that this paper offers a worthwhile ChoCo mirror. The honest limitation of the negative case is that I cannot prove no independently valuable high-multiplicity fair-division project could be built from these ideas. I can say, decisively under the programme’s rules, that such a project would be new computational work rather than a computational continuization of this paper.
