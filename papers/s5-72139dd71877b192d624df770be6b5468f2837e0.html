The anchor — algorithmic

Theorem V-H.1

Every anchor argued

  • Theorem V-H.1 — survived: The opponent accepts it as a computational anchor and challenges the mirror’s novelty, not its computational character.

The continuous mirror question

Given a finite customer set \(D\), a finite support \(T\) of facility types, rational masses \(\mu_t>0\) with \(\sum_{t\in T}\mu_t=1\), and rational utilities \(u_{td}\), define \(V(S)=\sum_{d\in D}\max_{t\in S}u_{td}\), with \(V(\varnothing)=0\). Generate a random ordering of \(T\) by repeatedly choosing a remaining type \(t\) with probability equal to its mass divided by the remaining mass. For each \(t\), compute \(\Phi_t=\mathbb{E}[V(P_t\cup\{t\})-V(P_t)]\), where \(P_t\) is the set of preceding types, and output the exact vector \((\Phi_t)_{t\in T}\). Determine the exact computation’s bit complexity; equivalently, compute \(\Phi_t=\sum_{d\in D}\int_0^{u_{td}}\frac{\mu_t}{\sum_{s:u_{sd}\ge q}\mu_s}\,dq\).

The model it lives in

A unit mass of facilities is distributed over types, each type being a complete utility profile across the finite customer set. The facility-location value remains a maximum over represented types; the output is each type’s aggregate expected Shapley payoff under a size-biased type ordering, with no separate service-supply decision.

The objection that survived

The opponent shows that the proposed allocation equals the aggregate Shapley payoff for every finite multiset with those type proportions, so the mass formulation exposes no new computation; the proponent gives the limiting construction but does not note this exact finite-copy identity.

fatal: False

What the mirror covers

The mirror covers the Shapley computation in Theorem V-H.1 for facility-location games with repeated utility profiles. It leaves the Banzhaf computation, general semivalue robustness results, and ML data-market experiments aside.

Open questions for a prover

  • Prove the exact finite-copy identity and give a bit-complexity bound for computing \((\Phi_t)_{t\in T}\) from rational input.

The case FOR (proponent)

The strongest positive case is narrow: Theorem V-H.1’s computation of Shapley payoffs in the facility-location game. It does not mirror the paper’s main replication-robustness results.

Theorem V-H.1 is proved in this paper, in Appendix J. For a facility-location game with facilities \(L\), customers \(D\), utilities \(u_{id}\), and value \(v(C)=\sum_{d\in D}\max_{i\in C}u_{id}\), it gives closed forms for both Shapley and Banzhaf payoffs. I rely on its Shapley clause:

\[ \phi_i^{\mathrm{Sh}}= \sum_{d\in D}\left[ \frac{u_{id}}{|L|-|L_{id}|} -\sum_{r=1}^{|L_{id}|} \frac{u^d_{e_{i,r}}}{\lambda_d(r)+\lambda_d(r)^2} \right], \qquad \lambda_d(r)=|L|-|L_{id}|+r-1, \]

where \(L_{id}\) is the set of locations with utility at most \(u_{id}\) for customer \(d\), and \(e_{i,r}\) is the \(r\)-th largest location after \(i\) in that customer’s utility ordering. The theorem also gives

\[ \phi_i^{\mathrm{Bz}}= \frac{1}{2^{|L|-1}} \sum_{d\in D}\left[ 2^{|L_{id}|}u_{id} -\sum_{r=1}^{|L_{id}|}2^{|L_{id}|-r}u^d_{e_{i,r}} \right]. \]

Algorithm 1 sorts facility utilities for each customer and uses these formulas to compute the values. Thus this is an algorithmic anchor, even though the theorem does not state a complexity class in its wording. There is a manuscript-level caveat: as printed, \(L_{id}\) includes \(i\), which can make the Shapley formula’s first denominator zero for a top-ranked facility. The intended computation is clear from the theorem and algorithm, but that notation needs checking before treating the displayed formula as verified.

Here is a continuous problem I would hand to a prover: Mass Facility-Location Shapley Allocation. An instance consists of a finite customer set \(D\), rational customer weights \(w_d\geq 0\), a finite support \(T\) of facility types, rational utilities \(u_{td}\geq 0\), and rational masses \(\mu_t>0\) with \(\sum_{t\in T}\mu_t=1\). A type is the complete utility vector \((u_{td})_{d\in D}\); facilities of that type are indistinguishable in this game. Define \(V(S)=\sum_{d\in D}w_d\max_{s\in S}u_{sd}\), with \(V(\varnothing)=0\). Draw an ordering of types by repeatedly selecting a remaining type \(t\) with probability proportional to \(\mu_t\). For each \(t\), output its aggregate allocation

\[ \Phi_t=\mathbb{E}\!\left[V(P_t\cup\{t\})-V(P_t)\right], \]

where \(P_t\) is the set of types preceding \(t\). The solution is the exact vector \((\Phi_t)_{t\in T}\); the original problem is payoff computation, so there is no additional decision variable.

This is a high-multiplicity limit of the paper’s underlying Shapley computation. Take \(N\) facilities, with \(N\mu_t\) copies of each type. In a random Shapley ordering, only the first copy of a type can contribute: later copies have zero marginal value because the type is already represented. As \(N\) grows, the order in which types first appear converges to the mass-weighted ordering above. Equivalently,

\[ \Phi_t=\sum_{d\in D}w_d \int_{0}^{u_{td}} \frac{\mu_t}{\sum_{s:\,u_{sd}\geq q}\mu_s}\,dq. \]

This formula gives an exact polynomial-time algorithm: sort the utility thresholds for each customer, compute suffix masses, and sum the resulting rational intervals. I expect this mirror to be tractable, a Class A result.

The regime is many candidate service facilities with relatively few distinct service profiles: for example, a large network of standardized service units whose utilities to a finite set of customer zones are identical within each profile. The facility population is large while the number \(\tau=|T|\) of distinct utility vectors is modest. The paper already treats facilities as the players in a grand-coalition payoff-allocation game, so the mirror preserves its subject. Aggregating each type’s payoff also matches the paper’s own concern with the *total* payoff received by a replicating player’s identities. This covers Theorem V-H.1’s Shapley computation in the facility-location case; it does not claim to continuize the paper’s results for general semivalues or its empirical ML-market study.

A useful follow-up is what happens to the theorem’s Banzhaf computation under the same limit. With positive mass for every type, the aggregate Banzhaf payoff of a type tends to zero: a copy’s marginal contribution requires no other copy of its type to be in the sampled coalition, an event whose probability vanishes exponentially with multiplicity. That contrast could lead to a question about whether a rescaled continuous Banzhaf allocation has a useful interpretation. Other follow-ups include approximation error for finite \(N\) and how allocations change as the masses \(\mu_t\) change.

The weakest point is that exact repeated utility profiles are a strong regime assumption, and the continuum object returns a type’s aggregate payoff rather than an individual facility’s vanishing per-facility share. I think the limit justifies that choice: the paper itself studies aggregate payoff across replicated identities. The printed notation issue in Theorem V-H.1 is a separate reason to check the claimed formula carefully.

The case AGAINST (opponent, writing after the proponent)

Theorem V-H.1 is a genuine computational anchor: it gives formulas for Shapley and Banzhaf values, and Algorithm 1 computes them. Facilities also admit a credible high-multiplicity regime, especially since the paper explicitly studies replicated identities. I would not reject the mirror on grounds of missing computation, implausible multiplicity, or individual identity.

The strongest objection is that the proposed mass problem does not create a new computational question. For a customer \(d\), a type \(t\) contributes at threshold \(q\) exactly when the first facility in the random Shapley ordering whose utility reaches \(q\) has type \(t\). With \(n_s\) copies of each type \(s\), that probability is \(n_t/\sum_{s:u_{sd}\ge q} n_s\). Thus the proposed formula,

\[ \Phi_t=\sum_{d\in D}w_d\int_0^{u_{td}} \frac{\mu_t}{\sum_{s:u_{sd}\ge q}\mu_s}\,dq, \]

is the exact aggregate Shapley payoff for any finite multiset of facilities with \(\mu_t=n_t/\sum_s n_s\), not merely its limit. The mass-weighted ordering is the order of types’ first appearances in the ordinary finite Shapley permutation. Sorting the \(\tau\) profiles per customer then computes the vector directly. The paper’s existing structure already supplies the computation; grouping repeated profiles compresses its input.

There is also a modeling cost behind that compression. In this game, the characteristic function is a maximum: a type’s first copy can raise value, while every further copy has zero marginal contribution once that type is represented. So mass affects the allocation through the chance that a type appears first; it does not act as an amount of service supplied. A usual marginal-value interpretation for an atomless population has a problem here: the value jumps when a type first appears and is flat as its positive mass grows. To obtain the proposed nonzero type allocation, one must retain the finite-copy arrival ordering. If instead real facilities contribute service in proportion to their mass, the maximum-value game changes, and Theorem V-H.1 no longer anchors that problem.

That leaves a well-defined and potentially useful high-multiplicity reformulation, but its new work is chiefly the dictionary between type masses and grouped Shapley payoffs. The paper’s theorem and algorithm make the associated exact computation unusually direct, with no new optimization or complexity question exposed by the mirror. This is the best case against it on research-priority grounds. It is not airtight: the paper does not state this mass formulation or prove the identity, and a formal high-multiplicity result could still be worthwhile.
