The continuous mirror question

Given a finite type set \(T\), rational masses \(\mu_t\ge 0\) summing to \(1\), and a graph of compatible type pairs with nonnegative rational surpluses \(w_e\), define \(P(q)\) for each coalition mass vector \(0\le q\le\mu\) as the maximum matching surplus. A matching mass \(x_e\) uses one unit of each endpoint type for a cross-type edge and two units of type \(t\) for a loop at \(t\). Find the largest \(\alpha\in[0,1]\) and nonnegative per-agent type payments \(c_t\) such that \(\sum_t\mu_t c_t\le P(\mu)\) and \(\sum_tq_tc_t\ge\alpha P(q)\) for every \(q\le\mu\).

The model it lives in

An atomless population with finitely many complete agent types, each carrying mass \(\mu_t\); matching-mass variables \(x_e\) determine coalition worth, and type-level per-agent payments \(c_t\) maximize the guaranteed coalition coverage factor \(\alpha\).

The objection that survived

The exact-core answer follows directly from the type-level matching LP, and nonatomic assignment work provides a nearby precedent; this limits novelty but does not settle the general-graph population question.

fatal: False

What the mirror covers

The mirror recasts Theorem 14's approximate-core guarantee as an exact-core question. It leaves aside the finite odd-cycle correction, Theorem 17's discrete integrality-gap result, and Theorem 21's assignment-game characterization.

Open questions for a prover

  • For finite markets with type counts approximating \(n\mu_t\), what additive error bounds relate the continuous exact-core allocation to a discrete approximate-core allocation?
  • How does the best coalition-coverage guarantee change when transfers to an agent are restricted to a bounded number of other agents?

The case FOR (proponent)

The strongest mirror is a large matching market or cooperative in which millions of people fall into a few profile types: for example, workers with the same qualifications, location, and availability, where compatibility and surplus depend only on the two types. A type is that complete profile; its mass \(\mu_t\) is the fraction of the population with that profile. The regime is \(n\gg\tau\), with many agents but relatively few types. A coalition is any measurable subpopulation. This keeps the paper’s central question intact: how should transferable profit be divided when coalitions can secede and form their own matches?

The anchor is Theorem 14, proved in the paper. It states that the allocation \(c\) produced by Mechanism 13 is in the \(2/3\)-approximate core of any general graph matching game: its total allocation is at most the worth of the grand coalition, and every coalition receives at least \(2/3\) of the worth it could generate by matching internally. The mechanism starts from an optimal half-integral matching and cover; it scales the cover payments for vertices on a half-integral odd cycle of length \(2k+1\) by \(2k/(2k+1)\), and leaves other payments unchanged. The theorem is a constructive approximation guarantee, though it does not state a formal running-time bound; the construction uses standard efficient matching routines. The paper offers no hardness result to anchor on.

Here is a continuous problem in the same cooperative matching model. Call it Continuous Matching Core Computation. An instance is a finite type set \(T\), rational masses \(\mu_t\ge 0\) summing to \(1\), and a graph of compatible type pairs with nonnegative rational surpluses \(w_e\). Include a loop at \(t\) when two distinct agents of type \(t\) may match. For any coalition described by masses \(0\le q_t\le\mu_t\), define its worth \(P(q)\) as the maximum of \(\sum_e w_e x_e\), subject to each type’s mass being used at most once: a cross-type match of mass \(x_{st}\) uses \(x_{st}\) from each type, and a within-type match of mass \(x_{tt}\) uses \(2x_{tt}\).

The problem is to find the largest \(\alpha\in[0,1]\) and nonnegative per-agent type payments \(c_t\) such that \(\sum_t\mu_t c_t\le P(\mu)\) and, for every coalition \(q\), \(\sum_tq_tc_t\ge\alpha P(q)\). A solution is the pair \((\alpha,c)\), with these guarantees. Individuals still receive whole matches or remain unmatched; fractional values describe how a nonatomic mass of otherwise identical agents is divided among partner types.

I expect this problem to be tractable, with \(\alpha=1\). Solve the dual cover LP: minimize \(\sum_t\mu_tc_t\), subject to \(c_s+c_t\ge w_{st}\) for each cross-type edge, \(2c_t\ge w_{tt}\) for each loop, and \(c_t\ge0\). By LP duality its optimum is \(P(\mu)\). The resulting cover also bounds every smaller coalition’s worth: \(\sum_tq_tc_t\ge P(q)\) for all \(q\le\mu\). With \(\tau\) types, this is an explicit LP with at most \(O(\tau^2)\) edge constraints, so it is polynomial in \(\tau\) and the input bit length.

This is a co-modification of the population, not a switch to continuous outcomes. The paper’s finite matching game can have an integrality gap on odd cycles; with nonatomic type masses, the portions of each type can be paired across the needed type pairs while each individual still has one partner at most. Thus the \(2/3\) guarantee of Theorem 14 becomes an exact core guarantee in this regime. The authors should recognize the mirror: it retains the same matching worth, transferable utility, coalition secession, and profit allocation, while the continuum changes the feasible aggregate matching patterns.

The weak point is the regime restriction. An arbitrary graph with idiosyncratic compatibility or pair-specific surplus may require almost as many types as agents, so this mirror would not cover it efficiently. Its case rests on a plausible class of high-multiplicity instances where agents with the same profile are interchangeable. Further questions include how quickly finite high-multiplicity markets approach the continuous core, what additive error is needed when rounding back to a finite electorate, and how the guarantee changes when transfers are restricted.

The case AGAINST (opponent, writing after the proponent)

The strongest case against this mirror is about its computational value, not whether the model is coherent. A market with many workers per profile and surplus determined by profile pairs is a sensible high-multiplicity regime. The type-level core question is well posed, and the paper’s matching language carries over naturally.

But the continuous answer follows directly from the fractional matching LP the paper already writes down. For coalition masses \(q\), let \(x_{st}\) be the mass matched across types \(s,t\), and \(x_{tt}\) the mass matched within type \(t\). The capacity constraints are

\[ \sum_{s\ne t}x_{st}+2x_{tt}\le q_t. \]

The dual assigns each type a payment \(c_t\), with \(c_s+c_t\ge w_{st}\) for cross-type matches and \(2c_t\ge w_{tt}\) for within-type matches. An optimal dual solution for the whole society has total payment \(P(\mu)\), and its constraints ensure that every coalition receives at least its full matching worth. So \(\alpha=1\), computed by an explicit LP with \(O(\tau^2)\) constraints. There is no pricing problem or new algorithmic obstacle to investigate.

That answer is mathematically meaningful, but the computational result is nearly immediate: atomless type masses make fractional matching physically feasible, removing the odd-cycle integrality obstruction that motivates Theorem 14. The theorem’s distinctive work is precisely the finite-agent correction for that obstruction. Here, the paper’s own primal and dual LPs already supply the solution. The broader LP/core equivalence also has a precedent in the nonatomic assignment literature, though that two-sided model is not the same as the paper’s general-graph model ([The Nonatomic Assignment Model](https://ideas.repec.org/a/spr/joecth/v2y1992i1p103-27.html)).

This does not defeat the mirror on admissibility: the continuous question is sensible, and its exact-core answer could be useful. It does make the negative case narrow. I can argue that this is a routine LP consequence with limited complexity content, but I cannot honestly argue that no worthwhile scenario exists. This anchor likely survives.
