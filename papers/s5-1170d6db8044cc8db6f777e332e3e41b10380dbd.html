The case FOR (proponent)

Under the required anchor rule, this paper has no qualifying computational complexity result. It makes no numbered claim that a problem is in P, NP-hard, FPT, or otherwise classified. The nearest results are both proved here: Theorem 1 says an RDM allocation is PS-DSF exactly when every user has a bottleneck resource on every eligible server; Theorem 3 says PS-DSF satisfies single-resource fairness, bottleneck fairness, envy freeness, and sharing incentive under either RDM or TDM, and additionally satisfies Pareto optimality and strategy-proofness under TDM. These are substantive results, but neither establishes the computational complexity of finding an allocation. I would not present them as qualifying anchors.

The strongest positive mirror is a high-multiplicity version of the paper’s allocation problem. Imagine a large data center serving many jobs drawn from a small catalog of workload templates. A type \(t\) records everything the mechanism uses: its per-task demand vector \(d_t\), eligible-server indicators \(\delta_{t,i}\), and weight \(\phi_t\). The type has population mass \(\mu_t\), with \(\sum_t\mu_t=1\) and \(\tau\ll N\), where \(N\) is the number of users. This is plausible for repeated deployment profiles or workload classes; it does not require all jobs to be identical. Assume the fleet scales with the user population, so its capacities are \(N\bar c_{i,r}\). That per-capita normalization is part of the mirror.

A precise candidate question is Mass-PS-DSF Allocation. Given rational masses \(\mu_t\), type data \((d_t,\delta_t,\phi_t)\), and per-capita server capacities \(\bar c_{i,r}\), find rational per-user allocations \(x_{t,i}\ge 0\). Write \(x_t=\sum_i x_{t,i}\). Require feasibility,
\[ \sum_t \mu_t x_{t,i}d_{t,r}\le \bar c_{i,r}\qquad\text{for every }i,r. \]
For each eligible pair \((t,i)\), define
\[ \bar\gamma_{t,i}=\delta_{t,i}\min_{r:d_{t,r}>0}\frac{\bar c_{i,r}}{d_{t,r}}, \qquad s_{t,i}=\frac{x_t}{\bar\gamma_{t,i}}. \]
The output must also include a bottleneck certificate: for every eligible \((t,i)\), a resource \(r\) with \(d_{t,r}>0\) such that
\[ \sum_u\mu_u x_{u,i}d_{u,r}=\bar c_{i,r}, \]
and every type \(u\) using that resource on server \(i\) satisfies
\[ \frac{s_{u,i}}{\phi_u}\ge \frac{s_{t,i}}{\phi_t}. \]
This is a type-level lift of the bottleneck condition in Theorem 1. Since \(\bar\gamma_{t,i}\) is the monopoly capacity normalized by population size, the normalization preserves the paper’s comparisons between virtual dominant shares. The task is to return any allocation meeting the feasibility and fairness conditions, not to optimize a new scalar welfare objective.

The authors should recognize the model: it keeps their server resources, placement constraints, weights, and PS-DSF rule, while replacing named users with masses of users indistinguishable in all those respects. The paper already allows real-valued task allocations, so the mirror’s continuity is specifically in the population input, not in the outcome. I would tentatively expect this question to be Class A, with complexity measured in \(\tau,K,M,L\): a finite type support and bottleneck certificates make a progressive allocation algorithm or continuous-optimization formulation plausible. That is a conjecture, not a result of this paper.

The scope is the allocation characterization and sharing properties nearest Theorems 1 and 3; it does not turn the simulation comparisons into complexity results. The main weakness is also decisive for the requested anchoring: there is no qualifying computational anchor, and the paper says convergence analysis of its allocation algorithm remains future work. So this is a credible continuous question motivated by named theorems, but the paper does not supply a named complexity result whose fate in the continuum can be studied.

The case AGAINST (opponent, writing after the proponent)

The decisive problem is that this paper has no named computational complexity result to continuize. Theorem 1 characterizes PS-DSF allocations by bottleneck resources; Theorem 3 proves fairness and incentive properties. Neither classifies the complexity of finding an allocation. The paper does give an allocation procedure, but it leaves convergence analysis for future work. So the proposed mass problem would ask for an algorithmic result the paper does not establish, rather than show how a computational result changes under continuization.

The strongest version of the proposed mirror is coherent: workload types can record demands, eligible servers, and weights, while capacities scale with population. The feasibility constraints and bottleneck certificates then lift naturally to per-type variables. That makes a sensible high-multiplicity allocation problem, and I cannot honestly argue that no such scenario exists. But its appeal comes from a new complexity question about computing PS-DSF. For repeated identical users, aggregation replaces sums over users with weighted sums over types; the fairness characterization itself carries over. That may make the problem easier to represent, but it does not continue a complexity claim from this paper, because there is no such claim to compare against.

The fairness properties are also not all preserved as meaningful individual properties in an atomless model. In particular, a single infinitesimal user’s misreport does not change the population distribution, so strategy-proofness becomes vacuous unless the model specifies finite-mass deviations. That would require a further choice of manipulation model; it is not a direct mass version of Theorem 3.

So the negative case is strong for rejecting this paper as an anchored ChoCo complexity study, but weak as a universal claim that no worthwhile continuous mirror exists. The proposed workload-population model is plausible. What it lacks is an anchor in a computational result proved by the paper.
