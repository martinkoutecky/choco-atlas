The case FOR (proponent)

This paper has no named NP-hardness, polynomial-time, or parameterized-complexity result. My best anchor is Theorem 1, “No Learning when Spectral Radius \(\rho>1\)”, proved in this paper’s Appendix E. It says that in a strongly connected social network, under the memoryless belief updates in (10), no agent can learn the truth unless the adjacency matrix has spectral radius \(\rho=1\). The paper notes that, for a strongly connected network, this is the directed-circle case. This is a theorem about learning behavior, not a complexity bound; I would use it to motivate a computational question about deciding learnability.

The regime I find plausible is a large recommendation or polling platform whose users receive cohort-level reports. There may be millions of users but only \(\tau\) relevant cohorts: groups with the same prior, signal likelihoods, and pattern of exposure to other cohorts. Here a type is exactly that bundle of properties, and \(\mu_t\) is type \(t\)’s fraction of users. A platform that aggregates reports by cohort gives a credible setting for treating those masses, rather than named users, as the population description.

My lead mirror is Continuum-BWR Learnability. An instance gives a finite state space \(\Theta\), the true state \(\theta\), a rational distribution \(\mu\) over finitely many types, and for each type \(t\), a common prior \(\nu_t\) and finite signal model \(\ell_t\). It also gives a rational contact intensity \(\kappa_{tu}\): how strongly type \(t\)’s feed draws on type \(u\)’s report. Normalize these intensities into an irreducible row-stochastic matrix
\[ P_{tu}=\frac{\kappa_{tu}\mu_u}{\sum_v\kappa_{tv}\mu_v}. \]
Each user receives fresh independent private signals and updates from the current signal and the immediately previous cohort reports, following the paper’s no-recall principle. Cohort reports are geometric aggregates of their members’ beliefs. Let \(z_{t,k}(\hat\theta)\) be type \(t\)’s mean log-belief ratio for a false state \(\hat\theta\) against \(\theta\). Under a common prior, the type-level dynamics are
\[ z_k(\hat\theta)=Pz_{k-1}(\hat\theta)+d(\hat\theta),\qquad d_t(\hat\theta)=-D_{\mathrm{KL}}\!\left(\ell_t(\cdot\mid\theta)\,\middle\|\,\ell_t(\cdot\mid\hat\theta)\right). \]
The question is: for every false state, do the positive-mass types’ beliefs converge to the truth, meaning \(z_{t,k}(\hat\theta)\to-\infty\)? The solution is a yes/no answer, with the learning rate as a useful output. Because \(P\) is irreducible, its stationary distribution \(\pi\) has positive entries. The log-belief ratios have asymptotic slope
\[ -\sum_t\pi_t D_{\mathrm{KL}}\!\left(\ell_t(\cdot\mid\theta)\,\middle\|\,\ell_t(\cdot\mid\hat\theta)\right). \]
Thus learning holds exactly when each false state is distinguishable by at least one positive-mass type. With finite signal alphabets and rational likelihoods, that condition reduces to checking whether the corresponding likelihood vectors differ. The finite-support problem is therefore a plausible Class A candidate: it can be decided with polynomial-time checks and finite-dimensional linear algebra in \(\tau\) and the input bit length.

The mirror preserves the paper’s finite state space, fresh private signals, belief reports, and memoryless Bayesian inference. The paper also discusses a cited extension in which agents choose one neighbor randomly and learning rates depend on a stationary distribution. That provides useful support for the type-level mixing model, though it is not a numbered anchor here and does not itself establish the complexity result I propose.

The weakest point is that Theorem 1 concerns an adjacency matrix of individual neighbors whose reports are summed; this mirror uses normalized cohort-level aggregates. That change is motivated by the population limit and by platforms that actually show group summaries, but it can remove the repeated-source noise that drives the finite-network theorem. I would present this as a continuous-population question about the same no-recall learning mechanism, not as a literal limit theorem for every sequence of the paper’s graphs. It covers the belief-learning result only; I would not stretch it to the binary-action equilibrium results.

The case AGAINST (opponent, writing after the proponent)

Theorem 1 is not a computational result. It characterizes learning behavior from the spectral radius of a network’s adjacency matrix; it does not state the complexity of deciding learnability or give an algorithmic problem with an input and output. Turning it into “decide whether learning occurs” adds a computational wrapper around an analytic theorem. That is the strongest reason to reject it as an anchor for ChoCo.

The cohort version is a sensible high-multiplicity model: users can share priors, signal structures, and exposure patterns, and a platform could publish cohort-level reports. So I would not object that types are artificial or that the masses are meaningless. But its stochastic matrix \(P\) normalizes contact and aggregates reports. That changes the mechanism behind Theorem 1, which uses an unnormalized sum of individual neighbors’ reports. The paper’s random-neighbor extension makes the cohort model a plausible related question, but it also places the proposed learning-rate analysis closer to an analytical extension than to a computational result of this paper.

A version that preserves the original network mechanism would need types to retain enough information about who observes whom. For arbitrary networks, those exposure patterns can make nearly every agent a distinct type, so the support may grow with the population and the mass description gives no compression. Restricting to networks with repeated exposure patterns avoids that problem, but narrows the question to a special network regime.

That said, I cannot honestly defend the universal claim that no worthwhile mirror exists in any scenario. Block-structured populations with shared exposure patterns could support a meaningful continuous model, and the paper’s cited random-neighbor work gives it a credible connection. My negative case is strongest against this particular anchor: it is a behavioral learning theorem, not a computational-complexity result, and the proposed decision problem does not follow from a complexity question the paper itself asks.
