The case FOR (proponent)

The strongest population setting is a large crowd labeling one binary question, or a fleet of sensors reporting one binary condition. Experts fall into a small number of competence tiers; within a tier they have the same competence and behave independently, as in the paper’s model. A very large expert population is then represented by masses \(\mu_p\) over a small support of competence types \(p\). The number of experts can be huge while the number of types \(\tau\) stays small. Competence is a complete type description for this problem because it is the only expert characteristic the model uses.

The nearest named result is Theorem 1, proved in this paper. It says that if each judge assigns each expert the log-odds of that judge’s perceived competence, and the geometric mean of the judges’ perceived competence odds equals the expert’s true competence odds, then averaging the judges’ scores gives each expert their optimal log-odds weight. The resulting weighted-majority rule is exactly the Bayesian-optimal log-odds rule. This is a natural result to lift to a continuous expert population, but it is not a computational-complexity result under the requested anchor criterion. The paper states no numbered result that establishes a problem is in P, NP-hard, FPT, or similar; its other formal result is an error bound, and its empirical findings are not numbered computational results.

A precise, theorem-inspired population question is Continuous Distributed-Weight Reproduction. An instance gives a rational mass \(\mu_p>0\) for each expert type \(p\) in a finite support \(P\subset(0,1)\), and \(n\) judges with rational competences \(q_j\). Judge \(j\) perceives an expert of type \(p\) as having competence \(\hat p_{jp}=q_jp+(1-q_j)(1-p)\), and assigns that type the score
\[ a_j(p)=\log\frac{\hat p_{jp}}{1-\hat p_{jp}}. \]
The induced type weight is \(W(p)=\frac1n\sum_{j=1}^n a_j(p)\). A realized continuous vote profile is specified by \(x_p\in[0,\mu_p]\), the mass of type \(p\) voting \(1\); the rule selects \(1\) when \(\sum_{p\in P}W(p)(2x_p-\mu_p)>0\). The question is whether these distributed scores exactly reproduce the population’s Bayes-optimal log-odds weights, meaning \(W(p)=\log\frac p{1-p}\) for every supported type. A solution reports the induced type weights and a yes/no certificate. For rational inputs, this check is in P: each equality is equivalent to comparing the rational products
\[ \prod_{j=1}^n\frac{\hat p_{jp}}{1-\hat p_{jp}} \quad\text{and}\quad \left(\frac p{1-p}\right)^n. \]
That is a complexity result for this proposed mirror, derived from the model; it is not claimed by the paper.

This question mirrors only Theorem 1’s exact-weighting claim. It leaves out the single-judge experiments, the constrained reporting variants, and the empirical ensemble results. Further questions include how to approximate the optimal weights when exact reproduction fails, or how to choose a judge population that achieves it.

The weakness is substantial: the paper’s theorem supplies an algebraic condition, and the continuous question above mainly checks that condition type by type. A referee might accept the expert population as a sensible high-multiplicity regime, yet still judge this check too slight to count as the paper’s computational problem. Under the stated anchor requirement, the paper has no qualifying computational anchor, so I would not present this as a full anchored case for continuization.

The case AGAINST (opponent, writing after the proponent)

I would reject the proposed anchor. Theorem 1 gives a sufficient algebraic condition for averaged scores to equal the log-odds weights; it states no computational problem or complexity result. The proposed reproduction check is constructed from that condition, and its predicate does not use the type masses \(\mu_p\) at all. It verifies the theorem’s premise type by type; it does not make the society’s being continuous do any computational work. Checking whether the induced voting rule is optimal, allowing for the fact that weights can be scaled together, would be a better formulation—but still an algebraic verification problem absent from the paper.

The high-multiplicity scenario itself is plausible: a large sensor fleet or crowd could contain many experts in the same competence tiers. The more fundamental difficulty is what happens to the paper’s accuracy objective in the limit. With \(N\mu_p\) independent experts of each type, let \(X_{p,N}\) be the number voting \(1\), and let \(W(p)\) be their weight. Then
\[ \frac{1}{N}\sum_p W(p)(2X_{p,N}-N\mu_p) \;\longrightarrow\; \sum_p \mu_p W(p)(2p-1) \]
almost surely. Under the optimal weights \(W(p)=\log\frac{p}{1-p}\), every informative type contributes positively to this expected margin. The limiting decision is therefore deterministic, and accuracy tends to \(1\) whenever any positive mass has \(p\ne \tfrac12\). The finite-population error probabilities that make optimal weighting interesting have washed out.

One could retain finite-size fluctuations or study an error exponent as \(N\) grows. That may be a worthwhile adjacent project, but it adds a scale-dependent stochastic objective that the paper neither formulates computationally nor analyzes as an algorithmic problem. So the strongest defensible case against is that none of the proposed anchors mirrors a computational result in this paper. I would not claim the material proves that no worthwhile continuous-population question could ever be invented; it supports the narrower, rubric-relevant conclusion that this paper offers no computational anchor for one.
