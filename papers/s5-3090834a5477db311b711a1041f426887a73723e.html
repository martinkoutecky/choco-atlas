The continuous mirror question

Given a rational distribution \(\mu\) over patient-donor pair types \(t=X-Y\in(\{0,1\}^3)^2\), let \(D(\mu)=\sum_{Y\ge X}\mu_{X-Y}\) be the mass of left-lobe-compatible pairs, which receive direct transplants. Let \(E\) be the set of feasible unordered two-way exchange patterns between incompatible pair types, with \(X-Y\) and \(V-W\) exchangeable when \(Y\ge V\) and \(W\ge X\). For each \(e\in E\), choose exchange mass \(x_e\ge0\), subject to \(\sum_{e\in E}a_{t,e}x_e\le\mu_t\) for every type \(t\), where \(a_{t,e}\) counts the type-\(t\) pairs used by pattern \(e\). Compute a feasible \(x\) maximizing \(D(\mu)+2\sum_{e\in E}x_e\), the total mass of pairs receiving transplants.

The model it lives in

A linear program over rational type masses and feasible two-way exchange patterns for the paper’s two-size left-lobe model. There are at most \(64\) pair types; each exchange variable consumes the corresponding type masses, and the objective maximizes directly transplanted mass plus mass matched through exchanges.

The case FOR (proponent)

The strongest anchor I see is Theorem 10 (Ergin et al., 2018), which the chapter cites rather than proves. It says that in the two-size liver exchange model, with only left-lobe transplants and two-way exchanges, the sequential algorithm maximizes the number of exchanges: first clear direct transplants, then clear feasible exchanges in order of waste \(0\), \(1\), and \(2\), using the fixed priority order to choose among exchanges. This is a named algorithmic result, though the chapter does not state a complexity class for it. The chapter’s discussion of NP-completeness for a more general kidney-exchange integer program is unnumbered, so I would not use it as an anchor under your rule.

My lead mirror is Two-Size Left-Lobe Mass Exchange. The agents are patient-donor pairs in a large liver-exchange pool. A type is \(t=X-Y\), where \(X,Y\in\{0,1\}^3\) describe the patient and donor’s blood-antigen and size categories. The input is a distribution \(\mu\) over these types, with rational masses summing to \(1\). A mass unit represents a fraction of the pair population; it receives one transplant if selected, while every actual pair still receives an integral transplant or none.

A pair of type \(X-Y\) is left-lobe compatible for a direct transplant when \(Y\ge X\). By the model’s endowment-bias assumption, such pairs receive direct transplants and do not enter exchanges. An exchange between types \(X-Y\) and \(V-W\) is feasible when \(Y\ge V\) and \(W\ge X\). Let \(E\) be the set of feasible type-pair exchanges, \(x_e\ge0\) the mass assigned to exchange \(e\), and \(a_{t,e}\) the number of type-\(t\) pairs used by it. The problem is to maximize \(D(\mu)+2\sum_{e\in E}x_e\), where \(D(\mu)=\sum_{Y\ge X}\mu_{X-Y}\), subject to \(\sum_{e\in E}a_{t,e}x_e\le\mu_t\) for every type \(t\). A solution is the exchange mass \(x\) attaining that maximum.

This is plausible as a mirror of the authors’ problem: it keeps their pair types, compatibility rule, endowment bias, transplant objective, and two-way logistical limit, while making the population itself a distribution. A plausible regime is a high-volume liver center or coordinated pool that repeatedly sees many pairs from the same ABO and size categories. There are at most \(64\) types in this model, so the number of pairs can be much larger than the number of distinct types. In that fixed-type setting, the mirror is an LP with finitely many exchange patterns, so I expect it to be tractable, polynomial in the input bit length. Theorem 10 anchors the objective and algorithmic setting; the LP’s tractability is a consequence of the continuous formulation, not a complexity claim made by that theorem.

The scope is deliberately narrow: it mirrors Theorem 10’s left-lobe-only, two-size, two-way problem. Further questions are whether fractional mass optima can be rounded with useful guarantees in finite pools, and how the LP behaves when the number of size categories or compatibility types grows, or when right-lobe willingness and multiway exchanges are introduced.

The weakest point is that this is a narrow formal model, while the chapter describes real programs with richer medical details and, at some centers, much larger exchanges. Also, Theorem 10 already gives a maximizing algorithm for the discrete problem, so this mirror does not show discrete hardness dissolving. Its positive case is that it is a precise, recognizable continuous-population version of one of the chapter’s own algorithmic problems.

The case AGAINST (opponent, writing after the proponent)

The strongest objection is limited payoff. In the stated two-size model, there are only eight individual types and at most 64 patient-donor pair types. The best mirror is straightforward: put a rational mass on each pair type, then maximize direct-transplant mass plus the mass used in feasible two-way exchanges, subject to each type’s mass capacity. That is a finite LP of constant dimension. It yields a clean high-multiplicity formulation, but it does not open a substantial complexity landscape: the paper already gives a structural algorithm for the discrete optimum, and the mirrored LP is exceptionally small.

The more serious concern is whether this compression survives a clinically faithful version. In actual liver exchange, compatibility depends on detailed graft and patient measurements and surgical constraints. If those distinctions matter to feasibility, a type must include them; the number of types could then grow with the pool, leaving little aggregation. The paper’s 2025 account of 270 transplants at one center over three years makes a high-volume setting plausible, but does not establish many clinically interchangeable pairs for this particular left-lobe, two-way model.

That case still does not defeat the anchor. Theorem 10 is a named result about an optimization algorithm, which is within the programme’s stated scope. Its two-size model makes pair type a complete description for the feasibility and objective it studies. A large center or coordinated pool with repeated pairs in those categories is a credible instance regime, and adding finer medical distinctions is optional if the authors recognize the stylized question as theirs. The fixed small type space makes the result easy; under the programme’s rules, ease is not a reason to dismiss a well-posed mirror.

So the honest negative case is weak. I can argue that this is a narrow, low-priority mirror whose main result may be a routine mass LP, and that its practical value depends on type aggregation. I cannot show that no plausible regime supports it. Under the stated grading rule, Theorem 10 survives.
