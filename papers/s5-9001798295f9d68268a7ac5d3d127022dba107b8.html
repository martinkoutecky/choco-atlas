The continuous mirror question

Given belief types \(i\in[\tau]\) with rational beliefs \(b_i\) and positive rational masses \(\mu_i\) summing to \(1\), consider profiles assigning one opinion \(z_i\in\mathbb{R}\) to each type. Each agent’s neighbor is an other agent whose opinion is closest to that agent’s belief, with ties between types resolved by a fixed priority. Decide whether a type-symmetric pure Nash equilibrium exists and, if so, compute equilibria minimizing and maximizing per-capita social cost \(\sum_i\mu_i\max\{|z_i-b_i|,|z_i-q_i(z)|\}\), where \(q_i(z)\) is the selected neighbor’s opinion.

The model it lives in

A unit-mass population with finitely many belief types, rational masses, and one common opinion per type. Each individual chooses an opinion and interacts with one other individual whose opinion is closest to their belief; positive mass ensures peers remain at the type’s opinion when one individual deviates. Equilibrium and its per-capita social cost are evaluated at the type level.

The objection that survived

Positive mass per type supplies same-opinion peers, forcing every type-symmetric equilibrium to be truthful and making the extremal-cost computation trivial; this also limits the mirror to type-symmetric profiles.

fatal: False

What the mirror covers

The mirror covers Theorem 10’s equilibrium existence and social-cost extremization questions for \(1\)-COF, restricted to profiles with one opinion per belief type. It does not cover asymmetric equilibria, the price-of-anarchy results, mixed equilibria, or general \(k\).

Open questions for a prover

  • Does the truthful profile give the unique type-symmetric pure equilibrium for every finite support and fixed tie priority?
  • Can the paper’s unrestricted equilibrium computation be mirrored when agents of the same belief type may choose different opinions?

The case FOR (proponent)

The strongest anchor is Theorem 10, proved in this paper: for a \(1\)-COF game, deciding whether a pure Nash equilibrium exists is polynomial-time solvable; when equilibria exist, computing one with minimum social cost or one with maximum social cost is also polynomial-time solvable. The paper proves this by representing equilibria as source-to-sink paths in a directed acyclic graph, with path weights equal to social cost. The authors do not give a hardness classification for these problems, so this algorithmic result is the best anchor.

A natural mirror is Mass-\(1\)-COF Extremal Equilibrium. An instance is a unit-mass population with \(\tau\) belief types. Type \(i\) has rational belief \(b_i\), positive rational mass \(\mu_i\), and \(\sum_i\mu_i=1\). Each member of that type chooses a real-valued opinion. At a type-level pure profile \(z=(z_1,\ldots,z_\tau)\), type \(i\)’s neighbor is one other agent whose opinion is closest to \(b_i\). Equivalently, its opinion \(q_i(z)\) is a closest value in \(\{z_1,\ldots,z_\tau\}\); the positive mass of each type ensures there are other agents at every type’s chosen opinion. Fix a priority over types to resolve ties between distinct closest opinions.

An agent of type \(i\) pays \(\max\{|z_i-b_i|,|z_i-q_i(z)|\}\). A pure equilibrium is a profile where no individual can lower this cost by changing opinion, holding the population distribution fixed. Since a single agent has zero mass, a deviation does not change the neighbor opinion values available to them. Their best response is the midpoint of their belief and their neighbor’s opinion, so equilibrium requires \(z_i=(b_i+q_i(z))/2\) for every type. The requested output is whether such a profile exists and, if so, profiles attaining the minimum and maximum per-capita social cost \(\sum_i\mu_i\max\{|z_i-b_i|,|z_i-q_i(z)|\}\).

This is a high-multiplicity version of the paper’s actual game: the many agents are platform users with recurring ideal points, and each sees the single expressed opinion closest to their private belief. Belief is a complete type because it is the only player-specific input to the paper’s cost and neighbor-selection rules. The population is continuous through its rational type masses; the opinion and compromise rules remain those of \(1\)-COF. Thus the question is still about computing pure equilibria of the authors’ game, rather than about a PDE or an axiomatic description of opinion outcomes.

I expect the maximum-cost equilibrium problem to be tractable in \(\tau\) and the input bit length. Theorem 10’s segment graph suggests a support-compressed version: in an equilibrium, type order constrains which neighboring types can interact, and the graph’s objective can be reweighted by \(\mu_i\). That is a research conjecture, not a consequence of the paper’s polynomial-time algorithm, which is polynomial in the number of individual players. A useful follow-up is whether this compression gives a polynomial-time algorithm with rational masses and the stated tie rule.

The mirror covers Theorem 10’s \(1\)-COF pure-equilibrium existence and social-cost extremization results. It does not claim to cover the paper’s price-of-anarchy bounds, mixed equilibria, or general \(k\).

My weakest point is that positive mass per type changes the equilibrium landscape: the all-truthful profile is always a zero-cost equilibrium, because each type has peers expressing its belief. So existence and the minimum-cost equilibrium become trivial in this mirror; the meaningful computational question is the maximum-cost equilibrium. This also shows why the mirror is a high-multiplicity question rather than a restatement of Theorem 10’s finite-instance problem. The single-neighbor rule remains individual-sized, which is faithful to \(k=1\), but makes this a less typical mass-neighborhood continuum model.

The case AGAINST (opponent, writing after the proponent)

Theorem 10 is the proponent’s strongest anchor: it gives a named polynomial-time result about existence and extremal social cost of pure equilibria. But its natural high-multiplicity mirror collapses. In the proposed model, every belief type has positive mass, so an agent always has peers at that type’s chosen opinion \(z_i\). Let \(q_i\) be the opinion of the nearest neighbor to belief \(b_i\). At equilibrium, \(z_i\) must minimize the maximum distance to \(b_i\) and \(q_i\), so it must be their midpoint. If \(q_i\ne z_i\), then \(|z_i-b_i|=\tfrac12|q_i-b_i|\): the same-type peers at \(z_i\) are strictly closer to \(b_i\) than \(q_i\), a contradiction. Thus \(q_i=z_i\), which forces \(z_i=b_i\).

So the truthful profile is the only pure equilibrium. Existence is automatic, and both the minimum and maximum equilibrium social costs are zero. The proposed output has no nontrivial extremal-equilibrium computation left. This is not just the paper’s algorithm becoming easier as its answer: positive mass per type changes the equilibrium structure because every type supplies its own nearest-neighbor candidate.

One could try a type-heterogeneous action profile, but in a nonatomic population all members of a belief type face the same aggregate neighborhood, and their best response is the same unique midpoint. If nearest opinions fail to exist for a diffuse action distribution, that formulation instead needs a new neighborhood rule. For example, replacing one nearest neighbor with the nearest fraction of the population might avoid the collapse, but it changes the interaction being studied and does not mirror Theorem 10’s \(1\)-COF result.

This is a strong objection to this anchor, though not a proof that no useful continuous question about opinion formation exists. The paper’s broader price-of-anarchy results may suggest other questions, but the proponent did not anchor their case on those, and this particular computational result does not yield a worthwhile high-multiplicity mirror.
