What the mirror covers

The case FOR (proponent)

The strongest positive seed is a large public consultation on a fixed logical agenda: each citizen’s type is a complete, consistent judgment set, and \(\mu_t\) is the fraction of the population with type \(t\). A collective rule maps that distribution to a consistent social judgment. This makes the population itself continuous and connects directly to the paper’s aggregation framework.

The closest anchors are Theorem 24 and Theorem 25, both proved in this paper. Theorem 24 says that, for finite \(N\), if the lattice has complements, \(3=\mathcal P(\{1,2,3\})\) is semi-order-embeddable in it, and the aggregation function satisfies universal domain, Neutrality, Monotonicity, Monotonicity▼, and Decisiveness, then a dictator exists. Theorem 25 says that, for finite \(N\) and a complete, compact lattice with complements, under those same axioms, aggregation functions are necessarily dictatorial if and only if \(3\) is semi-order-embeddable in the lattice.

Those results suggest a real population-continuous follow-up: determine whether a mass-based version of the paper’s axioms still forces dictatorship when citizens are represented by a distribution over judgment types. The finite proof’s key step uses the fact that an ultrafilter on finite \(N\) contains a singleton, so the continuous case could expose exactly what changes when individuals have zero mass.

But neither theorem is a computational result. They establish an axiomatic impossibility and a characterization; the paper gives no named result asserting tractability, hardness, or another complexity classification. So there are no qualifying computational anchors, and I can’t honestly provide a prover-ready continuous problem per anchor or assign one to the programme’s complexity classes. The weakness is decisive for ChoCo: the population model is plausible, but the paper’s question is about axioms, not computation.

The case AGAINST (opponent, writing after the proponent)

The proponent’s strongest scenario is credible: a large public consultation on a fixed agenda, with citizens grouped by complete judgment type. That gives a sensible high-multiplicity population. But it does not give ChoCo a computational problem to mirror. The paper states no result about an algorithm, complexity, or optimization problem. It studies how axioms on an aggregation function and structure in a lattice imply impossibility results. The positive case identifies that gap, then its proposed follow-up—whether mass-based axioms still force dictatorship—is itself an axiomatic question, outside the programme’s remit.

Theorem 24 is the clearest example. Its finite-population step turns an ultrafilter into a singleton, yielding a named dictator. A distribution over judgment types forgets which named citizen supplied which judgment. In an atomless population, changing one person’s judgment does not change the distribution, so individual dictatorship is not a property of the distribution alone. One could instead ask whether a positive-mass cohort is decisive, but that changes the conclusion and requires new axioms. Either formulation may be worth studying; neither is a computational mirror of Theorem 24.

Theorem 25 does not rescue the case. Its characterization hinges on whether the agenda lattice contains a semi-order-embedded copy of \(3\). That condition concerns the agenda’s structure, not how the population is represented. A mass-based version might revisit which coalitions are decisive, but the paper’s theorem supplies no algorithmic task for doing so. One could invent a complexity question about checking lattice embeddings or synthesizing aggregation rules, but that would need a new input representation and a new problem statement; it would not mirror a result in this paper.

So the positive case establishes that a continuous population is plausible, but plausibility is not enough for ChoCo: there is no named computational result here to anchor a prover-ready mirror. The universal claim that no useful continuous question could ever be devised is stronger than the evidence allows. The narrower negative conclusion is firm: neither theorem supports a worthwhile computational continuous mirror as the programme defines one.
