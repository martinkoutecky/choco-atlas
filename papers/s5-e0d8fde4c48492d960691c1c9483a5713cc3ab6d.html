What the mirror covers

The case FOR (proponent)

The paper has no named computational result in the sense required here: it proves no problem NP-hard, polynomial-time, FPT, or otherwise classifies its complexity. The closest named result is Theorem 3(i), proved here. It states that for every finite profile of voters’ linear orders over criteria, Nurmi’s first method \(F^{N1}\) returns exactly the maximal alternatives under the IIS opinion aggregator applied to the profile’s induced state of opinion. That is a representation identity, not a computational result, so it cannot honestly serve as a qualifying complexity anchor.

Still, it points to a credible continuous-population problem. The lead candidate, though unanchored by a qualifying result, is *Continuous Criteria-Ranking Choice*. An instance consists of a finite set \(X\) of alternatives, a finite set \(C\) of criteria, each criterion’s satisfaction set \(\mathrm{Tr}(c)\subseteq X\), and an explicit distribution \(\mu\) over complete rankings of \(C\). The distribution lists its \(\tau\) positive-mass ranking types, with binary-rational masses summing to \(1\). For each criterion \(c\), compute its population Borda score
\[ b_\mu(c)=\sum_{\succsim}\mu_{\succsim}\,|\{d\in C:c\succsim d\}|. \]
Order criteria into score classes \(\Sigma_1\succ\cdots\succ\Sigma_l\), and let \(A_k\) be the intersection of the satisfaction sets of all criteria in the first \(k\) classes. Return \(X\) if \(A_1=\emptyset\); otherwise return \(A_{k-1}\) at the first \(k\ge2\) for which \(A_k=\emptyset\); if no such \(k\) exists, return \(A_l\). The requested solution is this chosen set. The paper’s rule has no separate scalar optimization objective: this is a population-level evaluation of its lexicographic choice rule.

A plausible regime is a large association, electorate, or professional community choosing among voting procedures based on rankings of procedural criteria. There may be millions of respondents but only a moderate number of distinct complete rankings, so \(\tau\ll n\). A type is one complete ranking over \(C\), which captures everything this rule uses from a person. For an empirical population with \(n_t\) people of each type, setting \(\mu_t=n_t/n\) preserves all score comparisons and ties: it simply normalizes the finite Borda scores. This is a direct high-multiplicity extension of the problem Theorem 3(i) represents.

The expected result for this candidate is polynomial-time evaluation in \(|X|\), \(|C|\), \(\tau\), and the mass bit length: sum the weighted scores, sort the criteria, and compute the nested intersections. That is a modest Class A question, not a proposed resolution of discrete hardness. A further question is Continuous IIS Winner Robustness: given \(\mu\), find the smallest total-variation change to the ranking distribution that changes the selected set.

The scope is Nurmi’s first choice rule and its finite-profile representation in Theorem 3(i). It does not turn the paper’s axiomatic characterization into a complexity result. The weakest point is also decisive: the paper supplies no computational anchor, and this continuous version appears easy. The positive case is that the population mirror is sensible and precise; the paper does not support a stronger claim about a complexity landscape.

The case AGAINST (opponent, writing after the proponent)

The strongest objection is that this paper has no named computational result to mirror. Theorem 1 characterizes IIS axiomatically; Theorem 2 relates Borda-based CSCCs to anonymous opinion aggregators; and Theorem 3 gives representation identities for Nurmi’s methods. None classifies the complexity of a computational problem. In particular, Theorem 3(i) says that \(F^{N1}\) and IIS select the same alternatives on finite profiles. The proponent correctly concedes that this is not a complexity result, so it cannot serve as the required anchor.

Their proposed population model is nevertheless coherent. A large association could have many respondents but relatively few distinct rankings of criteria, making a distribution \(\mu\) over complete ranking types a sensible high-multiplicity input. Replacing finite counts by masses gives a natural population version of \(F^{N1}\). But that introduces an evaluation problem the paper does not study; it does not continue a computational question or result from the paper. The fact that the representation identity carries over to masses does not supply the missing complexity anchor.

The stronger alternatives do not fix that gap. A robustness question using total variation would add a perturbation problem absent from the paper. Extending the axiomatic characterization to real-valued opinion states would continuize an axiomatic result, which is outside this programme’s scope. The other named results remain representational or axiomatic as well.

I would not claim that no worthwhile continuous study is possible in any scenario: the large-population setting is plausible. The defensible negative is narrower: none of the paper’s results provides a computational anchor for a continuous mirror. The proposed model may be worthwhile as new work, but it does not establish a surviving mirror of this paper’s computational results.
