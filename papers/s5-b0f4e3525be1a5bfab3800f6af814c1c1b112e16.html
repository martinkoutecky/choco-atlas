The continuous mirror question

Given a finite set \(G\) of good classes, a finite set \(T\) of agent types with additive values \(a_{tg}\in\{1,p\}\) for integral \(p>1\), rational type masses \(\mu_t\ge 0\) summing to \(1\), and rational per-capita supplies \(s_g\ge 0\), compute a feasible mass allocation maximizing Nash social welfare. A configuration \(z\in\mathbb{Z}_{\ge 0}^{G}\) gives each recipient an integral bundle, and \(x_{t,z}\ge 0\) is the mass of type \(t\) receiving that bundle. Require \(\sum_z x_{t,z}=\mu_t\) for each \(t\) and \(\sum_{t,z}z_gx_{t,z}\le s_g\) for each \(g\); maximize \(\exp(\sum_{t,z}x_{t,z}\log(\sum_g a_{tg}z_g))\), with \(\log 0=-\infty\).

The model it lives in

A continuum of agents distributed over valuation types \(t\), with mass \(\mu_t\), receives integral bundles of repeatable good classes. The decision variables \(x_{t,z}\) distribute each type’s mass among bundle configurations \(z\), subject to per-capita supplies \(s_g\); the objective is the geometric mean of recipients’ utilities, equivalently \(\exp(\sum_{t,z}x_{t,z}\log(\sum_g a_{tg}z_g))\).

What the mirror covers

The mirror covers Theorem 10’s exact optimization result for integral \(p\). It leaves Theorem 11’s approximation for nonintegral \(p\), and the paper’s other discussion, outside the proposed question.

Open questions for a prover

  • Determine the exact and approximation complexity in the number of good classes, number of types, and input bit length, including whether the configuration pricing problem can be solved efficiently.
  • Establish whether an optimal mass allocation always has a finite-support representation with a polynomial-size description.

The case FOR (proponent)

My lead is the paper’s Theorem 10, proved here. It states that for a finite set of agents and indivisible goods, when every additive value is either \(1\) or the same integer \(p>1\), there is a polynomial-time algorithm that finds an allocation maximizing Nash social welfare. The proof builds on the binary-valuation algorithm of Barman et al. [8], then supplies the additional argument for integral two-value instances. The paper mentions APX-hardness for general additive valuations in its introduction, but that is background cited to [22], not a numbered result about the problem Theorem 10 solves.

Here is a continuous-population version I would put to a prover. Let \(G\) be a finite catalog of good classes and \(T\) a finite set of agent types. A type is its complete valuation vector \((a_{tg})_{g\in G}\), where each \(a_{tg}\in\{1,p\}\). The input gives rational type masses \(\mu_t\ge 0\) summing to \(1\), and rational per-capita supplies \(s_g\ge 0\) of each good class. For each type \(t\) and integral bundle \(z\in\mathbb Z_{\ge0}^{G}\), let \(x_{t,z}\) be the mass of type-\(t\) agents receiving that bundle. Require
\[ \sum_z x_{t,z}=\mu_t,\qquad \sum_{t,z}z_gx_{t,z}\le s_g\quad(g\in G). \]
Each unit of mass receives an integral bundle; the type-level average bundle and utility may be fractional. The objective is to maximize
\[ \exp\!\left(\sum_{t,z}x_{t,z}\log\!\left(\sum_{g\in G}a_{tg}z_g\right)\right), \]
with \(\log 0=-\infty\). This is the continuum geometric mean of individual utilities. In particular, it uses the average of log utility across agents, not the log of each type’s average utility. A solution is a feasible mass allocation attaining the maximum, representable by its positive-mass type and bundle pairs.

The regime is a large population receiving replicated standardized goods: for example, millions of households receiving repeated categories of essential supplies. Households share a type exactly when they have the same values for every good class. The total supply of class \(g\) scales as \(Ns_g\) for a population of size \(N\), while the number of valuation types \(\tau=|T|\) stays modest compared with \(N\). This co-scales goods supply to keep per-capita resources meaningful, while preserving indivisible bundles for each recipient. A finite instance with \(n_t\) agents of type \(t\) and \(M_g\) goods of class \(g\) corresponds to \(\mu_t=n_t/n\) and \(s_g=M_g/n\); conversely, rational mass plans are the natural candidates for realization by sufficiently large cloned populations.

I expect this mirror to be Class A, though that is a conjecture, not a result of the paper. Its configuration formulation is a linear optimization problem with a column for each type and integral bundle. The central algorithmic question is whether the pricing problem over bundles can be solved efficiently; for dual prices \(\lambda_g\), it asks which integral \(z\) maximizes \(\log(\sum_g a_{tg}z_g)-\sum_g\lambda_gz_g\). That is a concrete place for the continuous-optimization toolbox to enter, and it keeps Theorem 10’s objective intact.

The scope is just the exact integral-\(p\) result of Theorem 10. I would not stretch it to cover the paper’s general two-value approximation result or its discussion of arbitrary additive valuations. The weakest point is that the paper studies a finite set of named goods, whereas this mirror assumes repeated good classes and supply that grows with population. That is a real regime restriction. But it is a plausible high-multiplicity instance regime, and each agent still receives an integral bundle; only the population is continuous.

The case AGAINST (opponent, writing after the proponent)

The strongest objection to Theorem 10’s mirror is that it needs more than a large population: it also needs goods to come in repeatable classes, with supplies scaling alongside the population. The paper allocates a finite set of individually indexed goods. The proposed mirror instead gives each agent an integral bundle from replicated classes and optimizes over fractional masses of those bundles. That is a new configuration problem, not a limit obtained by enlarging the paper’s agent set while holding its goods fixed. For one-off goods, the proposed scaling may have no convincing interpretation.

But that objection narrows the application; it does not defeat the mirror. A large cohort receiving standardized goods is plausible, and the programme explicitly allows per-capita supplies to scale when continuization requires it. The mirror keeps each recipient’s bundle integral and preserves the Nash objective as average log utility. The familiar continuous-goods Nash-welfare formulation does not answer this question, because it makes the goods divisible instead. ([Chaudhury et al., *On Fair Division for Indivisible Items*](https://pure.mpg.de/rest/items/item_2639463_2/component/file_2639462/content))

I can’t honestly defeat the anchor. Theorem 10 is a named computational result, and its high-multiplicity version is a coherent, potentially useful configuration optimization problem. The remaining concern is that its relevance depends on finding a setting with both repeated valuation types and scalable supplies—not that no worthwhile continuous mirror exists.
