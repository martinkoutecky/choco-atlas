The continuous mirror question

Given one activity, a finite type set \(T\), rational masses \(\mu_t>0\) summing to \(1\), an integer population scale \(H\) with \(H\mu_t\in\mathbb{Z}\), and rational preferences \(p_t\) and weights \(w_{tu}\), with \(w_{tt}=0\), choose active masses \(x_t\in[0,\mu_t]\); the rest of each type goes to the void activity. The per-capita welfare is \(F(x)=\sum_t x_t p_t+H\sum_{t,u}x_tx_uw_{tu}\), and the void allocation ensures \(\mathrm{OPT}\ge 0\). Does a polynomial-time algorithm in the input bit length exist for some fixed \(\alpha\ge 1\) that always returns feasible \(x\) with \(F(x)\ge \mathrm{OPT}/\alpha\) whenever \(\mathrm{OPT}>0\)?

The model it lives in

Each type fully specifies an agent’s activity preference and weight toward every other type. A unit of active type mass \(x_t\) receives activity value \(p_t\) and interaction value scaled by the population size, \(H\sum_u x_uw_{tu}\); the objective sums these utilities per capita. In the reduction, \(T\) encodes graph vertices, \(H=n^2\), \(\mu_t=1/n\), and \(p_t=-n(k-2)\). The active fraction \(y_t=nx_t\in[0,1]\) gives a multilinear objective with zero diagonal, so a maximum occurs at a box vertex; positive optimum is equivalent to a clique of size at least \(k\).

What the mirror covers

The mirror covers Theorem 2’s one-activity inapproximability result for arbitrary signed preferences and weights. It leaves the paper’s NOM compatibility results and its approximation mechanisms unmirrored.

Open questions for a prover

  • Which restrictions on the type-interaction graph or on negative weights permit polynomial-time approximation?
  • Does tractability change when the support size \(\tau\) is fixed or otherwise bounded?

The case FOR (proponent)

The strongest anchor is Theorem 2, proved in this paper. It says that when preferences and weights may be arbitrary real values, no polynomial time algorithm can guarantee any bounded approximation to optimal utilitarian welfare, even with just one activity, unless \(\mathrm{P}=\mathrm{NP}\). The proof reduces from MaxClique; the paper cites the NP-hardness of MaxClique from elsewhere.

A direct mirror is Continuous AS-GASP Welfare Maximization. An instance has one activity, a finite set \(T\) of agent types, rational masses \(\mu_t>0\) summing to \(1\), an integer population scale \(H\), and rational values \(p_t\) and \(w_{tu}\). A type completely specifies an agent’s activity preference and their weight toward members of each type. Set \(w_{tt}=0\) for the subcase used below. Choose \(x_t\in[0,\mu_t]\), the mass of type \(t\) assigned to the activity; the remaining mass goes to the void activity. A member of active type \(t\) gets utility \(p_t+H\sum_u x_u w_{tu}\), so per-capita social welfare is
\[ F(x)=\sum_t x_t p_t+H\sum_{t,u}x_t x_u w_{tu}. \]
The question is whether this problem has a polynomial time algorithm with any fixed bounded approximation ratio. A solution is an allocation vector \(x\); an \(\alpha\)-approximate solution has \(F(x)\geq \mathrm{OPT}/\alpha\) when \(\mathrm{OPT}>0\). The void option ensures \(\mathrm{OPT}\geq0\).

This describes a plausible high-multiplicity regime for the paper’s team and group-formation setting: many people fall into repeated role or compatibility classes, and members of each class value members of each other class in the same way. In the finite bridge, \(H\mu_t\) is the number of people of type \(t\). For example, a type can represent a role in a large organization, with a common preference for the project and common affinities toward the other roles. The model still has integral outcomes for individuals; \(x_t\) records how much of a type’s population receives each outcome.

There is a strong reason to expect hardness to transfer. Given a graph on \(n\) vertices, make each vertex a type, give every type mass \(1/n\), and take \(R=n\) copies of each type, so \(H=Rn=n^2\). Set \(p_v=-R(k-2)\), set \(w_{vu}=1\) for edges, and set \(w_{vu}=-n^3\) for nonedges. For an allocation, write \(y_v=nx_v\in[0,1]\). Its welfare is
\[ F(x)=\frac{R}{n}\left[-(k-2)\sum_v y_v+\sum_{v,u}y_vy_u w_{vu}\right]. \]
Because the diagonal weights are zero, this objective is affine in each \(y_v\) when the others are fixed. Its maximum over the box therefore occurs at a vertex \(y\in\{0,1\}^n\): fractional allocations cannot improve the reduction’s optimum. For a selected clique of size \(c\), the bracket is \(c(c-k+1)\), positive exactly when \(c\geq k\); a selected set containing a nonedge has negative value under the chosen penalty. Thus positive optimum is equivalent to a \(k\)-clique. A bounded approximation algorithm would return positive welfare on yes instances and cannot do so on no instances, giving the same MaxClique obstruction. This is a Class B case: the hard combinatorics live in the interaction graph on types, not in the number of copies of each type.

The authors should recognize this as a mirror of their underlying one-activity welfare maximization problem: agents still form a group, their utility still sums activity value and co-participant weights, and the objective is still utilitarian welfare. This anchor does not cover the paper’s NOM results about strategic reporting; it covers only the computational welfare result.

The soft spot is that the reduction uses an arbitrary compatibility graph over types and strong negative weights, and the number of types grows with the graph. It establishes a high-multiplicity regime—here \(n^2\) agents and \(n\) types—but not tractability when the number of types is fixed. That limitation does not erase the mirror: repeated cohorts with type-level interaction values are a recognizable AS-GASP instance regime, and this particular hardness survives fractional mass allocation. A useful next question is whether restrictions on the type-interaction graph or on negative weights yield tractable continuous cases.

The case AGAINST (opponent, writing after the proponent)

I don’t see an honest way to defeat this anchor under ChoCo’s criteria. Theorem 2 is a named computational result about approximating utilitarian welfare. Its continuous mirror preserves the one activity, the void option, type preferences, pairwise weights, and welfare objective. Making each graph vertex a type with \(R\) identical agents is a legitimate high multiplicity regime: every agent of a type has the same preferences and weights toward every type, including zero toward their own type. With \(H=n^2\), the continuous instance represents \(n\) types with \(n\) copies each, and the multilinear objective preserves the clique threshold even when fractional masses are allowed. This is more than a loose analogy to the paper’s problem.

The strongest reservation is about the mirror’s reach. Its reduction has \(\tau=n\), with an arbitrary graph encoded in the type interaction matrix. It therefore does not show what happens when the number of types is small, or that population multiplicity itself is the source of difficulty. The signed, graph-coded interactions may also be a poor fit for some concrete team settings. And this anchor mirrors the welfare optimization result, not the paper’s NOM results.

Those reservations limit what the mirror establishes; they don’t make its question ill-posed. ChoCo explicitly counts Class B hardness and recognizes type-level costs and interactions as valid high multiplicity. Since one surviving anchor is enough, the best case against is weak: this is a credible mirror, even if it may be less revealing than a mirror where continuization changes the computational landscape.
