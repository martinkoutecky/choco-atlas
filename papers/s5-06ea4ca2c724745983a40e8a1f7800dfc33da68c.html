The continuous mirror question

Given a project set \(P\), \(d\) resource costs \(c_k(p)\), budgets \(b_k\), and an explicitly listed support of \(\tau\) approval types \(A_t\subseteq P\) with binary rational masses \(\mu_t\ge0\) summing to \(1\), find a feasible indivisible project set \(S\subseteq P\) maximizing \(\sum_t \mu_t |A_t\cap S|\), subject to \(\sum_{p\in S}c_k(p)\le b_k\) for every resource \(k\). In particular, classify the complexity of its threshold decision version when \(d\) is part of the input.

The model it lives in

A distribution over complete approval-ballot types, with rational mass per type; the decision is an indivisible feasible project set \(S\), and the objective is its mass-weighted approval score \(\sum_t\mu_t|A_t\cap S|\).

The objection that survived

The society compresses to per-project approval shares, and Proposition 5 remains hard with τ=1, so the mirror's hardness comes from project selection and resource feasibility rather than population multiplicity; this limits its population-specific research yield.

fatal: False

What the mirror covers

The mirror covers the Max-Approval computational results in Propositions 3 and 5. It leaves the paper's axiomatic results and its analyses of Greedy-Approval and Sequential Load-Balancing outside this mirror.

Open questions for a prover

The case FOR (proponent)

The strongest mirror is the paper’s Max-Approval problem. It uses the population as the continuous object while keeping the projects indivisible and the resource constraints intact.

Consider a participatory-budgeting instance with project set \(P\), \(d\) resources, project costs \(c_k(p)\), and budgets \(b_k\). A voter type is an approval ballot \(A_t\subseteq P\), with mass \(\mu_t\), where the explicitly listed support has size \(\tau\) and \(\sum_t\mu_t=1\). For a feasible set \(S\), define its approval score by
\[ \operatorname{score}_\mu(S)=\sum_t\mu_t\,|A_t\cap S|. \]
Feasibility still means \(\sum_{p\in S}c_k(p)\le b_k\) for every resource \(k\).

Lead mirror: Continuous Max-Approval with a variable number of resources. Given the project and resource data and the rational-mass society above, find a feasible set \(S\) maximizing \(\operatorname{score}_\mu(S)\). Its decision version asks, for a rational threshold \(q\), whether some feasible \(S\) has \(\operatorname{score}_\mu(S)\ge q\). A solution is the selected project set, not a fractional project allocation.

The anchor is Proposition 5, proved in this paper: MaxAppScore is strongly NP-hard. MaxAppScore asks whether a feasible set reaches a specified approval-score threshold, with the number of resources part of the input. The paper reduces from Independent Set: make each vertex a project and each edge a resource, charge each endpoint one unit of that edge’s resource, and set every resource budget to one. A set of projects is feasible exactly when its vertices form an independent set. With one voter approving every project, its approval score is the set’s size, so reaching threshold \(K\) is equivalent to finding an independent set of size \(K\).

The same reduction works in the continuous mirror with all society mass on the single type \(A=P\). Then \(\operatorname{score}_\mu(S)=|S|\), and feasibility is unchanged. Thus this mirror is strongly NP-hard even with \(\tau=1\). The reduction’s combinatorics lie in the project agenda and resource constraints, not in the number of distinct voter types. I expect hardness transfers; this is a Class B case, not evidence of continuum-specific hardness.

This is a natural high-multiplicity regime for a city-wide PB exercise with a standardized project slate: many residents cast ballots, ballot patterns recur, and the input is naturally summarized as the share approving each subset. For a finite profile of \(n\) voters, setting \(\mu_t\) to each type’s fraction gives \(\operatorname{score}_\mu(S)=s_A(S)/n\), so the maximizing outcome is exactly the paper’s Max-Approval outcome. Conversely, rational masses can be represented by a finite profile after scaling to a common denominator. For this algorithmic problem, an approval set fully describes the voter: the mechanism uses ballots, not voter identities or other individual data.

A second useful anchor is Proposition 3, which says that for any fixed number \(d\ge2\) of resources, computing outcomes under Max-Approval has no polynomial-time algorithm unless \(P=NP\). The paper derives this from the equivalence, in the two-resource case with one voter approving all projects, to Cardinality (2-KP), whose weak NP-hardness it cites from Kellerer et al. [15]. Its continuous counterpart is Continuous Max-Approval restricted to \(d=2\), with all mass on the all-approving type. It asks for a feasible set of maximum cardinality under two resource budgets. This is again Class B hardness transfer; it shows that the hardness need not rely on a resource dimension that grows with the number of projects. Proposition 5 is the lead because its result is stronger and its reduction is given in the paper; Proposition 3 supports the fixed-resource regime.

These mirrors cover the paper’s Max-Approval algorithmic results, not its proportionality and strategyproofness theorems or its other mechanisms. They leave open whether the fixed-\(d\) continuous problem admits useful pseudopolynomial, approximation, or parameterized algorithms, and how those depend on \(m,\tau\), and the mass encoding length \(L\). The main soft spot is also clear: the lead hardness reduction places all mass on one type, so it establishes that this particular problem remains hard in the continuous model, not that continuous population modeling itself creates a new computational challenge. That is still a faithful mirror: the paper’s objective already aggregates approvals, and normalizing the voters’ counts to population shares changes neither what the mechanism optimizes nor which set it selects.

The case AGAINST (opponent, writing after the proponent)

The strongest skeptical case is that Max-Approval’s population input collapses to \(m\) project weights:
\[ w_p=\sum_{t:p\in A_t}\mu_t,\qquad \operatorname{score}_{\mu}(S)=\sum_{p\in S}w_p. \]
So even with many ballot types, the mechanism sees the society only through its per-project approval shares. The continuous mirror is weighted multidimensional knapsack: its type support can be processed away before the hard part begins. The paper’s results therefore give little reason to expect the population continuum to bring the continuous-optimization tools that motivate ChoCo.

That is a concern about the mirror’s research yield, but it does not defeat either anchor. Proposition 5’s reduction works with \(\tau=1\): a continuum of voters can all share the all-approving type, and feasibility still encodes Independent Set. Proposition 3 likewise survives at fixed \(d=2\), with the same single type and the same cardinality-knapsack problem. Neither case degenerates: a one-type population is still a population, and the project slate and resource constraints remain meaningful.

Nor does the natural city-wide scenario rescue the negative case. Repeated approval ballots on a standard project slate make rational population shares a sensible input. For any finite profile, setting \(\mu_t=n_t/n\) preserves the maximizing project set; conversely, rational masses can be scaled to a finite profile. That exact correspondence may make the mirror’s new structure modest, but the programme explicitly treats this dictionary as a deliverable. I see no basis here for claiming the high-multiplicity regime is implausible or already answered by continuous-population work.

So I cannot honestly defeat the proponent’s anchors. The skeptical case is that this is a low-yield mirror: the society compresses to approval weights, while the hardness sits in project selection and resource feasibility. Under the stated criteria, that is not enough to reject a well-posed continuous-population question. The negative case is weak, and both anchors survive.
