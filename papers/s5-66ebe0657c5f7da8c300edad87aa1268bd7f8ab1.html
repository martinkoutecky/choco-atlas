The continuous mirror question

Given a candidate set \(C\) with \(m\geq 2\), τ strict-ranking types with positive rational masses \(\mu_t\) summing to \(1\), a finite-support draw distribution \(D\) with support size \(s\) and maximum value \(d_{\max}\), and \(\varepsilon>0\), compute a lottery \(P\in\Delta(C)\) such that \(\max_{c\in C}\sum_t\mu_t\Pr[c\succ_t P^D]\leq \mathbb{E}[1/(D+1)]+\varepsilon\), using the paper's random-label tie-breaking. The weighted multiplicative-weights algorithm gives this guarantee in \(O(\tau m s\log(d_{\max}+1)\log(m)/\varepsilon^2)\) real-arithmetic operations; determine its complexity in the binary rational input model as well.

The model it lives in

The society is a distribution \(\mu\) over complete ranking types. The decision variable is a lottery \(P\in\Delta(C)\), and each type contributes its mass-weighted probability of preferring a challenger to \(D\) independent draws from \(P\). Minimize the maximum challenger probability, or compute an \(\varepsilon\)-approximate minimizer; the benchmark is \(\mathbb{E}[1/(D+1)]\).

What the mirror covers

Covers Proposition 1's approximate random-size stability computation over τ ranking types. It does not address the paper's distortion bounds or the search for an optimal randomized rule.

Open questions for a prover

  • What is the bit complexity of the algorithm for rational masses, draw probabilities, and tolerance \(\varepsilon\), in terms of their encoding lengths?
  • What quantitative distortion guarantee follows from an \(\varepsilon\)-stable lottery?

The case FOR (proponent)

My strongest honest case is a narrow Class A mirror of the paper’s algorithm for computing random-size stable lotteries. The population is a distribution \(\mu\) over complete ranking types: each type is a strict ranking of the candidates, and \(\mu_t\) is its share of society. This fits, for example, a large election with many repeated ballots and \(\tau\), the number of distinct rankings present, much smaller than the number of voters. For this computation, voters with the same ranking are indistinguishable.

The anchor is Proposition 1 (Appendix B.2), proved in this paper. For a finite electorate of \(n\) voters and a draw distribution \(D\) with finite support of size \(s\) and maximum value \(d_{\max}\), it gives an algorithm that, for every positive integer \(N\), outputs a lottery \(\overline P\) satisfying
\[ \max_{c\in C}\Pr\nolimits_v[c\succ_v\overline P^D] \leq \E\!\left[\frac{1}{D+1}\right] +\sqrt{\frac{\log m}{2N}}. \]
In the real-arithmetic model, its running time is \(O(Nnms\log(d_{\max}+1))\) arithmetic operations and exponential evaluations. Equivalently, additive error \(\varepsilon\) takes \(O(nms\log(d_{\max}+1)\log(m)/\varepsilon^2)\) time.

I would pose the continuous problem as Mass-Profile Random-Size Stability. The input is a candidate set \(C\), a list of \(\tau\) rankings with positive rational masses \(\mu_t\) summing to one, a finite-support draw distribution \(D\), and an error tolerance \(\varepsilon>0\). For a lottery \(P\), define
\[ q_c(P;\mu,D)=\sum_{t\in\supp(\mu)}\mu_t\Pr[c\succ_t P^D], \]
using the paper’s random-label convention for ties. The task is to output \(P\in\Delta(C)\) such that
\[ \max_{c\in C}q_c(P;\mu,D) \leq \E\!\left[\frac{1}{D+1}\right]+\varepsilon. \]
This asks for the same stable-lottery computation as Proposition 1, with voter averages taken over type masses. The expected direction is tractability: the multiplicative-weights update and guarantee extend by replacing the average over \(n\) voters with the weighted sum over \(\tau\) types. The resulting real-arithmetic bound is \(O(\tau ms\log(d_{\max}+1)\log(m)/\varepsilon^2)\). In particular, fixing the paper’s \(D^\star\), supported on \(\{1,2,9,10\}\), makes \(s=4\) and \(d_{\max}=10\).

This mirrors the paper’s computation of a lottery from ordinal preferences; the fact that \(P\) is itself a lottery does not make outcome-space continuity the subject. The continuous object here is the population. The mirror covers Proposition 1 and its stable-lottery ingredient, not the paper’s distortion bounds as computational complexity results, nor the problem of finding an optimal rule among all randomized rules.

The main weakness is that the extension is almost immediate: the paper’s calculations already use voter averages, and its offset discussion explicitly allows distributions over rankings. So this is a convincing continuous-population version of the computational task, but a modest novelty claim. Also, Proposition 1 gives a real-arithmetic bound, not a bit-complexity result for rational masses. Natural follow-up questions are whether the algorithm has polynomial bit complexity in \(m,\tau,L,1/\varepsilon\), and whether an \(\varepsilon\)-stable lottery yields a quantitatively controlled distortion bound.

The case AGAINST (opponent, writing after the proponent)

Proposition 1 is a real computational anchor, and its stronger continuous version survives the obvious objections. A ranking is a complete type for this task: every quantity in the stability condition depends on a voter only through that ranking. Given masses \(\mu_t\), replace the uniform voter average in each update by the weighted sum over the \(\tau\) types. The multiplicative-weights proof then gives the same guarantee in \(O(\tau m s\log(d_{\max}+1)\log(m)/\varepsilon^2)\) real-arithmetic operations. This is a well-posed high-multiplicity computation, not continuity of the lottery outcome.

The strongest negative case is therefore about how much new work the mirror creates. The algorithm’s calculations already depend only on averages over rankings, so the support-weighted version is a direct substitution. The paper also explicitly gives its offset characterization for distributions over rankings. There is no new optimization structure to uncover: the mirror reuses the same multiplicative-weights method and replaces an explicit voter list with its type frequencies. That makes it a weak candidate for a substantial new complexity landscape; the remaining questions, such as polynomial bit complexity for rational masses and quantitative distortion guarantees for approximate stability, are narrower follow-ups.

I cannot honestly make the requested universal case. The paper does not state Proposition 1 for rational mass inputs, so this is not a strict collision with an already stated continuous algorithmic result. And under ChoCo’s standard, a direct high-multiplicity algorithm can itself be worthwhile. The best negative verdict is that this anchor looks mathematically routine, not that its continuous mirror fails. A reader who counts the explicit dependence on \(\tau\) as a useful computational result should retain the mirror.
