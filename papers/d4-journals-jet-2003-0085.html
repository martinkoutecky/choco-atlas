The case FOR (proponent)

I don’t see a defensible anchor for a computational mirror. The paper has no named result about complexity, algorithms, or hardness.

The closest results are Theorem 3.1, which proves that an equilibrium process exists for the paper’s finite-state model using a fixed-point argument; Theorems 4.1 and 4.2, which relate deterministic processes with a unique limit to strong and weak core states; Theorem 4.3, which places absorbing states within the largest consistent set under its stated conditions; and Theorem 5.1, which says every equilibrium process in a common-payoﬀ game reaches the efficient action profile. These are existence and equilibrium-characterization results. “Efficient” in Theorem 5.1 means economically efficient, not computable in polynomial time. None supplies the required complexity anchor.

There is a plausible *follow-on* in the programme’s spirit: take many agents who share a finite set of complete types—action sets, payoffs, discount factors, and coalition move rights—with rational type masses \(\mu\). Represent a state by the distribution of mass across type-action pairs, and a coalition move by reassigning some mass to new actions. One could ask whether a stationary Markov transition kernel exists whose supported moves are profitable and efficient for the moving mass, with strict profitable moves ruling out inaction. A solution would be such a kernel together with value functions satisfying the discounted Bellman equations. A large workforce with a few recurring strategic roles could supply a plausible regime where the number of agents greatly exceeds the number of types.

But that is a research direction, not a mirror anchored in this paper’s computational results. Theorem 3.1 assumes a finite state space, and the authors explicitly leave broader state spaces open. The continuum model would need a new state representation and a precise way to encode or output the kernel; restricting it to a finite representation would add a condition the paper does not study. I therefore cannot honestly assign this question to the programme’s tractable, hardness-transfer, or continuum-specific-hard classes based on the paper. No per-anchor continuous problems can be supplied under the requested standard.

The case AGAINST (opponent, writing after the proponent)

The strongest case against a continuous mirror is that this paper gives ChoCo no computational result to mirror. Theorem 3.1 proves existence by a fixed point argument; Theorems 4.1–4.3 characterize equilibrium outcomes in relation to the core and the largest consistent set; Theorem 5.1 concerns efficiency. None asks for an algorithm, establishes a complexity bound, or proves hardness. The authors’ restriction to finite state spaces is a condition in their existence analysis, not a computational bottleneck they set out to study.

The proposed mass-transfer follow-on could be made meaningful. A large workforce with a few complete strategic types is a plausible high-multiplicity regime, and grouping genuinely interchangeable agents would be appropriate. But the paper’s state is a global state in \(X\), and its transitions depend on which coalition can move from that state. It does not represent society as a distribution of agents. To build the proposed model, one must choose a new aggregate state space, specify which positive-mass coalitions may move and how their moves affect everyone else, and give a finite representation for the transition rule and its value functions. Those are consequential modeling and encoding choices, not details settled by Theorem 3.1. Asking for the complexity of finding an equilibrium after making them would be a new computational game-theory project, not a continuous mirror of a computational question in this paper.

The most promising narrower variant would use many agents with a few action and payoff types, then study equilibrium processes for an aggregate action distribution. That scenario can be sensible, but the named result it might attach to is Theorem 5.1, which says every equilibrium reaches an efficient profile in common-payoff games. It supplies no algorithmic task. Likewise, continuizing the core comparisons in Theorems 4.1 and 4.2 would make a new outcome-characterization question; it would not turn those theorems into complexity results. Existing work on high-multiplicity populations would support the plausibility of such a regime, but it cannot supply the missing computational anchor.

This does not prove that no worthwhile algorithmic theory of large coalition-formation games exists. The negative case is weaker on that universal claim: the paper’s abstract model can be specialized to plausible large populations, and a researcher could formulate a useful computational problem there. The narrower conclusion is stronger: any such project would have to create the computational problem, aggregate model, and encoding from scratch. On the evidence in this paper, there is no anchored continuous mirror for ChoCo to pursue.
