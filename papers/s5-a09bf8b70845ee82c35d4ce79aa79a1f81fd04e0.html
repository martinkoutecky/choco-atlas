The case FOR (proponent)

I can make a real case for a continuous-population analogue, but this paper has no named computational result—no theorem classifies a problem as tractable, hard, or otherwise. The closest anchor is Theorem 1, proved here by construction. It says that with \(I\ge4\) agents and Assumption 1 (information costs are nonnegative and zero for signals independent of the state), every state-contingent decision rule \(d^*:\Theta\to D\) can be implemented with probability one at zero acquisition cost to every agent. The paper’s continuum \(x\in[0,1]\) represents the underlying fundamental state, not the population. So this is a noncomputational bridge from a finite-agent result, not a qualifying ChoCo complexity anchor.

The strongest candidate mirror is Atomless First-Best Committee Implementation. Consider a unit-mass committee with finitely many payoff-and-cost types \(t\), with rational masses \(\mu_t\) summing to one. The instance gives a finite state space \(\Theta\), common prior \(\mu_0\), decision set \(D\), each type’s utility \(u_t(d,\theta)\), and a target rule \(d^*(\theta)\). For example, \(d^*\) could hire a candidate when the full-information aggregate committee surplus is nonnegative. The question is whether one can specify a measurable direct mechanism—information-acquisition recommendations, signal spaces, and a decision rule on the profile of reports—such that truthful compliance is a Bayesian equilibrium, the decision equals \(d^*(\theta)\) almost surely, and almost every member’s acquisition cost is zero. A solution is the mechanism and a proof of those incentive and implementation claims.

The regime is a very large committee or public decision body with a small number \(\tau\) of recurring payoff-and-cost profiles. Types describe members’ exogenous preferences and costs; the mechanism may assign different signal roles to members of the same type, as the paper’s construction already assigns different roles to its indexed agents. Thus population size can grow while the number of types stays fixed. This is a plausible regime for the paper’s committee application, though not for every committee.

There is a concrete reason to expect a constructive yes under the paper’s assumptions. A continuum version could give each member \(a\in[0,1]\) a distinct code \(g(a)\in\{0,1\}^{\mathbb N}\), and use a shared random pad \(U\) independent of \(\theta\). If \(e_\theta\) is a one-hot encoding of the state, recommend signal \(s_a=U\oplus(g(a)\otimes e_\theta)\). Each member’s signal is individually independent of the state, while two distinct members’ signals jointly reveal it. A decision rule can decode the state from almost every pair of reports. A unilateral deviation changes only one member’s coordinate, which has zero mass, so it does not change that rule; since the recommended signal costs zero and deviations cannot have negative cost, compliance is optimal. On this version, I expect an explicit construction—closest to the programme’s tractable class.

The soft spot is also the reason this is not a straightforward continuation of Theorem 1: in an atomless population, a unilateral deviation cannot affect any mass-based outcome. The paper’s finite-agent construction detects a deviator; this mirror can satisfy individual incentive constraints without detecting one. If the authors’ intended problem includes deviations by positive-mass groups, or requires finite-description signals and mechanisms, this construction does not settle it. Those choices need separate questions: does implementation survive coalition deviations? Can it be done with finite signal alphabets or an efficient finite encoding? The mirror covers the first-best committee implementation claim, not a computational result of the paper; no A/B/C complexity verdict follows from its theorem.

The case AGAINST (opponent, writing after the proponent)

The strongest case against a ChoCo mirror is that none of the anchors is a computational result. Theorem 1, along with Corollaries 1 and 2, establishes existence: for \(I\ge4\), the authors construct a mechanism implementing any \(d^*\) at zero information cost. The model allows arbitrary measurable information-acquisition actions and does not specify a finite input encoding, a search or decision problem, or a complexity measure. Its \(x\in[0,1]\) is a latent state variable, not a continuous population.

The atomless committee is the proponent’s strongest repair, and it is a coherent continuous mechanism-design question. A finite set of positive-mass role cohorts could use the paper’s signal code, with the state decoded from their aggregate reports. But atomlessness changes the incentive argument: a unilateral deviation has zero mass and cannot affect a mass-based outcome. The paper’s central construction instead uses reports from named agents to detect a unilateral deviation. Requiring detection through labeled, zero-mass reports would make identity matter to the outcome; requiring resistance to positive-mass deviations would change the solution concept. Neither is the committee mirror as stated.

A high-multiplicity auction could supply another plausible population story, but it would still mirror an existence claim, not a computational one. To create a complexity problem, one would have to add choices such as finite input encodings, bounds on signal or message size, or restrictions on cost functions. Those choices define a new problem; they are not complexity questions the paper formulates.

So I would not claim that no worthwhile continuous *mechanism-design* question can be drawn from this paper. The committee version is plausible. The negative case is strong under ChoCo’s stated scope: there is no named computational result to mirror, and turning the existence theorem into a computational problem requires adding the problem’s defining constraints.
