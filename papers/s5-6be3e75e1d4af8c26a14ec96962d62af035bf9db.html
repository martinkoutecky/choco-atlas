The continuous mirror question

Given a finite set of agent types \(T\) with mass distribution \(\mu\), finite item types \(E\) with per-capita supplies \(q_e\), additive values \(v_t(e)\) satisfying \(\sum_e q_e v_t(e)=1\), and an adversarial online stream of batches of identical copies, irrevocably assign each copy to an individual agent while every bundle remains integral; determine the supremum worst-case \(r\) such that almost every type-\(t\) agent receives \(v_t(B)\ge r\,\MMS^\infty_t\), where \(\MMS^\infty_t\) is the high-multiplicity MMS obtained from distributions of integral bundles \(B\in\mathbb{Z}_{\ge 0}^{E}\) with expectation \(q\).

The model it lives in

A finite-type, atomless high-multiplicity online allocation model: agent types \(t\in T\) carry mass \(\mu_t\), item types \(e\in E\) arrive in batches with per-capita supply \(q_e\), each mass unit receives an integral bundle \(B\), and a configuration measure over \((t,B)\) enforces supplies while the objective is worst-case MMS approximation.

The objection that survived

Theorem 3.1's finite adversarial suffix can starve named agents one at a time, whereas after scaling supplies the same suffix may affect only a null set; proving that a positive-mass batch adversary preserves any obstruction remains open.

fatal: False

What the mirror covers

The mirror covers the general-goods impossibility, the two-agent chores lower bound, and the small-chores algorithmic guarantee. It leaves the other goods and chores regimes, monotone-instance results, normalization appendix, and experiments untreated.

Open questions for a prover

  • For fixed finite \(T\) and \(E\), does an online policy achieve a positive worst-case ratio for continuous goods MMS?
  • Do finite \(K\)-agent instances with \(K\mu_t\) agents and \(Kq_e\) item copies converge to the proposed continuous benchmark and competitive ratio?
  • Can the small-chores guarantee \((1+\alpha)\) be achieved by a finite configuration or flow algorithm while preserving integral individual bundles?

The case FOR (proponent)

There is a genuine continuous mirror here, and the strongest anchor is the paper’s impossibility result for goods.

The common mirror is an atomless high-multiplicity version of the online MMS problem. Let \(T\) be a fixed finite set of agent types, with mass distribution \(\mu\). A type completely specifies an agent’s value or cost for every item type. Let \(E\) be a fixed finite set of item types, with per-capita supply \(q_e\). Items arrive online as batches of identical copies, in an arbitrary order. A batch may be split across many agents, but every individual agent receives an integral bundle: if \(B\) is her bundle, then \(B\in\mathbb{Z}_{\ge 0}^{E}\). No item already assigned may be moved.

For goods, normalize \(\sum_e q_e v_t(e)=1\) for every type \(t\); for chores, normalize \(\sum_e q_e c_t(e)=1\). A continuum MMS benchmark can be defined using a probability distribution \(\lambda\) over integral bundles satisfying \(\mathbb{E}_{B\sim\lambda}[B_e]=q_e\). Thus

\[ \MMS^\infty_t = \sup_{\lambda}\operatorname*{ess\,inf}_{B\sim\lambda} v_t(B) \]

for goods, and

\[ \MMS^\infty_t = \inf_{\lambda}\operatorname*{ess\,sup}_{B\sim\lambda} c_t(B) \]

for chores. An online allocation is successful at ratio \(r\) if almost every agent of type \(t\) ends with value at least \(r\MMS^\infty_t\), or cost at most \(r\MMS^\infty_t\).

This is genuinely a population continuization, not divisible-item fair division. The individual bundles remain integral; only the mass of identical agents receiving each bundle is fractional. For rational \(\mu\) and \(q\), multiplying by a common denominator gives a finite instance with \(K\) agents, \(K\mu_t\) agents of type \(t\), and \(Kq_e\) copies of each item type. The continuous problem is the high-multiplicity limit of those instances.

My lead anchor is Theorem 3.1, proved in this paper. It states that, for online allocation of goods with general additive valuations, no online algorithm has a competitive ratio strictly larger than \(0\), even with \(n=3\) agents. The paper’s model is deterministic, uses arbitrary arrival order, permits an adaptive adversary, and assumes normalized valuations \(v_i(M)=3\).

The corresponding problem is:

Continuous Online Goods-MMS. There are three positive-mass valuation types \(t_1,t_2,t_3\), for example with \(\mu_{t_i}=1/3\), a finite collection of item types with per-capita supplies \(q_e\), and an arbitrary online batch order. Each arriving copy must immediately be assigned to an individual agent, producing an integral bundle for that agent. Determine the largest worst-case ratio \(r\) for which an online policy guarantees

\[ v_t(B)\ge r\MMS^\infty_t \]

for almost every agent of every type.

This is recognizably the authors’ problem: it retains online arrival, irrevocability, heterogeneous additive valuations, normalization, and MMS fairness. The only changed parameter is that “three agents” becomes three repeated valuation types with a large population of clones.

I expect this mirror to be Class A, or at least to invalidate the paper’s zero guarantee. The proof of Theorem 3.1 repeatedly exploits the fact that one particular named agent has received too little and that only one or two future items remain. With a positive mass of indistinguishable agents, that starvation argument no longer transfers directly: a single unfortunate agent has measure zero, while repeated item types can be spread over a cohort. The continuous problem should therefore be attacked through an online flow or configuration formulation. The interesting question is whether the ratio becomes positive, and how it depends on the number of valuation and item types. Further questions include whether a positive ratio exists under arbitrary batches, whether it approaches \(1\) when item batches are sufficiently replicated, and how quickly finite \(K\)-agent instances converge to the mass problem.

A second useful impossibility anchor is Theorem 4.3, also proved here. It states that for two-agent online allocation of chores, no online algorithm can have competitive ratio smaller than \(\frac{15}{11}\). The theorem assumes normalized additive costs \(c_i(M)=2\), arbitrary online arrival order, and deterministic algorithms against adaptive adversaries.

Its mirror is:

Continuous Online Chore-MMS. There are two positive-mass cost types, say \(\mu_{t_1}=\mu_{t_2}=1/2\), normalized per-capita item supply, and an arbitrary stream of item-type batches. Every individual receives an integral bundle irrevocably. Determine the optimal ratio \(r\) such that almost every type-\(t\) agent receives a bundle satisfying

\[ c_t(B)\le r\MMS^\infty_t. \]

I would expect the exact \(\frac{15}{11}\) lower bound not to transfer automatically. Its construction uses seven individually timed items and a last-item dilemma. In the high-multiplicity regime, repeated copies of those item types can be distributed across many agents, potentially removing the bottleneck. My cautious classification is Class C: the finite lower bound is population-specific, but irrevocable assignment and integral bundles may create new continuum-specific online hardness. The problem asks exactly where the discrete obstruction disappears and whether another obstruction replaces it.

As a supporting algorithmic anchor, Theorem 4.7, proved here, states that for small chores—when every item satisfies \(c_i(e)\le\alpha<1\)—the paper’s greedy active-agent algorithm computes a \((1+\alpha)\)-MMS allocation in \(O(mn)\) time. The algorithm assigns each item to an active agent with minimum cost, inactivates an agent once her accumulated cost reaches \(1\), and sends all later items to the sole remaining active agent.

The continuous version is:

Continuous Small-Chore MMS. Given a finite distribution of cost types, per-capita item supplies, arbitrary online batches, and \(c_t(e)\le\alpha<1\) for every type and item type, construct an irrevocable integral-bundle allocation guaranteeing

\[ c_t(B)\le (1+\alpha)\MMS^\infty_t \]

for almost every agent.

This is likely Class A. The active-agent argument has a natural mass version: agents are inactivated when their own bundle reaches cost \(1\), and the greedy cross-type inequality controls the remaining active mass. The main technical task is to express the process as a finite type-level configuration or flow algorithm rather than to change the underlying fairness question.

The mirror covers the paper’s general-goods impossibility, two-type chores lower bound, and small-chores algorithmic result. It does not claim that every monotone-instance or experimental result has a useful continuous counterpart.

The weakest point is the online input model. If one insists that only finitely many individual items arrive while the population becomes infinite, those items have vanishing per-capita mass and the mirror becomes degenerate. The batch/per-capita formulation is therefore essential. It is nevertheless a natural high-multiplicity interpretation: large workforces receive repeated job classes, or large populations receive repeated donation lots. The paper’s own food-bank and manufacturing examples make that regime plausible. The mirror changes the population scale, while preserving indivisible individual bundles, online irrevocability, and MMS as the objective.

The case AGAINST (opponent, writing after the proponent)

The strongest case against these mirrors is that this paper’s difficulty is not population multiplicity. It is atomic online irrevocability: one indivisible item arrives, must be assigned immediately, and a final item can expose an earlier decision. That mechanism has no stable nondegenerate population limit.

Take \(K\) copies of each agent type. If the paper’s finite item stream is left unchanged, each item has per-capita supply \(O(1/K)\). Almost every agent receives nothing, and the MMS benchmark either collapses or any positive guarantee becomes impossible for the trivial reason that only finitely many agents receive items. To avoid that degeneration, every relevant item must also be replicated into a batch of \(\Theta(K)\) copies. But then the model is no longer the paper’s online problem at scale: each “item event” is a bulk arrival that can be distributed across a positive mass of agents. The atomic obstruction has been replaced by a new mass-flow problem.

This defeats Theorem 3.1 as an anchor. Its proof relies on maintaining a small set of named agents whose value is below \( (1/r)\MMS_i \), while fewer than that many items remain. In the proposed continuum, a finite set of badly served clones has measure zero and is irrelevant to an almost-everywhere guarantee. Scaling the future items into positive-mass batches lets the algorithm distribute them across a cohort; retaining only finitely many future items leaves the adversarial suffix invisible in the limit. To recover the theorem, one would have to forbid splitting a batch across clones or make a positive-mass cohort behave as one indivisible agent. That restores the finite-agent obstruction by adding population-level indivisibility; it is no longer a continuization of the paper’s population.

The same issue is sharper for Theorem 4.3. Its \(15/11\) construction forces a particular first item to agent \(1\), a later item to agent \(2\), and finally presents an item that cannot be assigned to both. With repeated types, a first batch can be divided among many clones, and a single final copy affects only a null set. If all seven item types are replicated, the benchmark is also no longer the paper’s two-agent MMS: it is the MMS benchmark for \(K\) agents, whose limit is the configuration-distribution quantity proposed by the other analyst. The \(15/11\) argument therefore does not survive; a new lower-bound construction would be needed. Such a construction might be interesting, but it would be a theorem about bulk online scheduling, not a continuous version of this theorem’s obstruction.

Theorem 4.7 is the strongest supporting anchor, but its alleged mass extension is not immediate. The proof depends on the discrete endpoint “only one active agent remains” and on the last item causing an overshoot of at most \(\alpha\). In an atomless population there is no last active agent: active mass can shrink continuously, and agents of the same static type diverge into many different partial bundles. A type-level state is therefore insufficient; one must track a measure \(\nu_{t,B}\) of agents of type \(t\) currently holding each integral bundle \(B\). The online process becomes a measure-valued configuration problem, not the paper’s \(O(mn)\) greedy algorithm.

If batches are allowed to be split freely, the discrete one-item overshoot can disappear, or its size depends on an arbitrary convention for processing a batch. If integral bundles are rigorously retained, the configuration measure must be tracked, potentially over an unbounded state space. Collapsing that state to fractional loads would make the problem divisible-item allocation, which is outside the programme’s population-only scope. Thus the claimed \((1+\alpha)\) mirror is either a degenerate fluidization or a substantially new dynamic configuration problem.

The common problem is therefore a trilemma. Keeping the original finite item stream makes the population limit trivial; scaling the stream makes the paper’s atomic online dilemmas disappear; preserving those dilemmas requires extra indivisibility that defeats the point of the population continuum. Existing high-multiplicity work is not an objection here—it supports the general regime—but it does not resolve this mismatch between atomic online allocation and an atomless population.

This is a forceful reason to reject the other analyst’s three anchors as direct mirrors. It is not, however, an airtight proof that no worthwhile study exists. A carefully specified batch model with integral individual bundles and configuration-valued online states is mathematically coherent, and small-chores allocation could plausibly yield a genuinely new result. The honest negative conclusion is therefore narrower: none of the paper’s three theorems currently supplies the claimed continuous computational mirror; the most promising surviving idea is a new bulk-online problem whose relevance must be defended independently.
