The continuous mirror question

Given a finite simple type graph \(H=(R,F)\), rational type masses \(\mu_r>0\) summing to \(1\), rational edge-mass supplies \(\lambda_e\), and endpoint values \(w_{r,e}\), choose \(x_{e,r},x_{e,s}\ge 0\) with \(x_{e,r}+x_{e,s}=\lambda_e\) for each \(e=\{r,s\}\), and subsidies \(p_r\ge 0\). Define \(U_r=\sum_{e\ni r}w_{r,e}x_{e,r}/\mu_r\), and let \(v_r(b_s)=w_{r,e}x_{e,s}/\mu_s\) when \(e=\{r,s\}\in F\), and \(0\) otherwise. What is the minimum \(\sum_{r\in R}\mu_r p_r\) subject to \(U_r+p_r\ge v_r(b_s)+p_s\) for every ordered pair \(r,s\)?

The model it lives in

A continuum of agents grouped into local-network roles \(r\in R\), with mass \(\mu_r\), connected by edge-type supplies \(\lambda_e\). Allocate each edge mass between its endpoint roles and minimize total per-capita subsidy subject to envy-freeness between type-average bundles.

The objection that survived

The LP forgets which agents are paired across copies, so its type-average envy constraints do not guarantee ex-post envy-freeness in any realized orientation; the proponent acknowledges this change but does not establish that the authors would accept it.

The case FOR (proponent)

My lead is Continuous Minimum-Subsidy Orientation. The anchor is Theorem 2, proved in this paper: computing an orientation with minimum subsidy is NP-hard even when the graph is simple and valuations are additive, with every incident edge valued in \(\{1,2\}\). The proof reduces from 2P2N-3SAT by showing that deciding whether an envy-free orientation exists is NP-complete. The authors also note that this makes it NP-hard to distinguish zero subsidy from positive subsidy, ruling out a polynomial-time approximation with any bounded guarantee.

A plausible high-multiplicity setting is a large population made up of repeated copies of a local service-sharing network. Each copy has the same agency roles and the same simple pattern of shared assets; each asset must be assigned to one of its two endpoint agencies. The roles are the types: agents with a given role have the same incident role pattern and the same additive values for those assets. If the template has \(\tau\) roles and there are \(K\) copies, the population has \(K\tau\) agents but only \(\tau\) types. Each type has mass \(\mu_r=1/\tau\). This is a constructed instance regime, but it gives “many agents of few types” a concrete interpretation.

Here is the continuous problem for that regime. An instance consists of a finite simple type graph \(H=(R,F)\), with \(|R|=\tau\), type masses \(\mu_r>0\) summing to \(1\), and, for each edge type \(e=\{r,s\}\), a rational edge-mass supply \(\lambda_e\). In the repeated-template case, \(\mu_r=\lambda_e=1/\tau\): each edge type occurs once per copy. Its endpoint values \(w_{r,e},w_{s,e}\) are the normalized values from Theorem 2, in \(\{1/2,1\}\); dividing the paper’s values by two is the paper’s own normalization.

Choose nonnegative masses \(x_{e,r},x_{e,s}\) assigning edge mass to its endpoints, with \(x_{e,r}+x_{e,s}=\lambda_e\). Type \(r\)’s average per-capita bundle contains \(x_{e,r}/\mu_r\) units of edge type \(e\), so its value is \(U_r=\sum_{e\ni r} w_{r,e}x_{e,r}/\mu_r\). Let \(p_r\ge 0\) be its per-capita subsidy. The question is to minimize the total subsidy mass \(\sum_r\mu_r p_r\), subject to type-level envy-freeness: for every ordered pair \(r,s\), \(U_r+p_r\ge v_r(b_s)+p_s\), where \(b_s\) is type \(s\)’s average bundle. If \(r\) and \(s\) share an edge type \(e\), then \(v_r(b_s)=w_{r,e}x_{e,s}/\mu_s\); otherwise it is zero. A solution is the edge-mass split and a subsidy per type satisfying these inequalities.

This is a linear program with \(O(|F|+\tau)\) variables and \(O(\tau^2)\) envy constraints, so the continuous problem is in P. I expect Class A: the mass relaxation appears to remove the combinatorial choice of assigning each repeated edge instance to one endpoint, while preserving the graph-local goods, endpoint restriction, additive valuations and minimum-subsidy objective. The question also invites useful follow-ups: what is the integrality gap when the edge masses are realized across finitely many copies? When does an optimal continuous solution round to an individually envy-free orientation? And can the individual envy constraints be retained in a graphing or other continuum model without losing tractability?

My weakest point is the fairness interpretation. In this mirror, envy is checked between type-average bundles. A fractional edge-mass split can be realized as a proportion of copies assigning the edge to each endpoint, but that does not guarantee that every individual in every copy is envy-free. The paper’s problem is ex-post, individual envy-freeness; this mirror is its type-average high-multiplicity version. I think that is a defensible co-modification when the population is the continuous object, but an author or referee could reject it as changing the solution concept. The mirror covers Theorem 2’s minimum-subsidy computation only; it does not claim a continuous counterpart for the paper’s subsidy-bound results.

The case AGAINST (opponent, writing after the proponent)

Theorem 2 is a genuine computational anchor, so I would not argue that the paper lacks a result to mirror. The strongest objection is that graph orientation makes agents’ identities matter through their exact edge incidences. That is the feature the proposed type averages erase.

Repeating a fixed graph gives repeated roles only after relabeling each copy. In the actual allocation problem, agent \(r\) in copy \(k\) values that copy’s incident edges; the corresponding agent in copy \(\ell\) values different goods. Since feasibility and envy both depend on those incidences, the copy index is part of a complete description of an agent for this problem. Treating all \(r\)-agents as one type is not ordinary high-multiplicity grouping over a shared set of goods.

The proposed LP pools edge allocations across copies and compares an agent’s bundle with a type’s average bundle. But an individual in copy \(k\) does not value the edges in that average bundle that belong to other copies. The masses \(x_{e,r}\) also discard which copies received which shares, even though that correlation determines the individual envy comparisons. Thus the LP may be a coherent model of *type-average* fairness, but its constraints do not express the paper’s individual envy-freeness.

The stronger repair is to retain each copy’s local comparisons and require envy-freeness within each copy. Then the continuum is just a population of independent finite instances: the original orientation problem remains in each fiber, and replication has not supplied a type-based computational mirror. If instead the graph itself grows into an anonymous network, preserving individual envy requires retaining the joint pattern of endpoints, edges, and bundles. That is a different graph-based continuum model; collapsing it to type-average constraints again changes the fairness question.

A group-average subsidy problem for repeated service networks could still be worth studying. That is the negative case’s weakness: I cannot rule out a useful adjacent model. But the proponent has not shown that the polynomial type-average LP is a continuous-population version of Theorem 2 that the paper’s authors would recognize as their problem.
