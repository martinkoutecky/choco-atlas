The continuous mirror question

Given a finite set of room categories \(\mathcal O_t\) for each period, rational per-capita supplies \(q_{t,o}\) with \(\sum_{o\in\mathcal O_t}q_{t,o}=1\), and a rational distribution \(\mu\) over \(\tau\) responsive, directionally separable preference types, find rational masses \(x_{\theta,b}\ge 0\) over integral bundles \(b\in\mathcal B=\prod_t\mathcal O_t\). Require \(\sum_b x_{\theta,b}=\mu_\theta\) and \(\sum_{\theta,b:\,b_t=o}x_{\theta,b}=q_{t,o}\). For every two positive-mass assignments \((\theta,b)\) and \((\theta',d)\), if \(d\succ_\theta b\), require a period \(t\) with \(b\succeq_\theta(\emptyset_t,d_{-t})\), and a reference bundle \(r\in\mathcal B\) and period \(s\) with \(b\succeq_\theta r\) and \((d_s,r_{-s})\succeq_\theta(r_s,d_{-s})\).

The model it lives in

A distribution \(\mu\) over complete room-preference types, per-capita supply \(q_{t,o}\) that scales with the cohort, and assignment masses \(x_{\theta,b}\) over bundles that remain integral for each resident. The task is to find a feasible assignment whose positive-mass bundles satisfy EF1 and swapBE pairwise.

What the mirror covers

Covers Proposition 2's TTC+SD guarantee of EF1 and swapBE under responsive, directionally separable preferences. It leaves Proposition 1 and the welfare results in Propositions 3 and 4 untouched, and establishes no runtime bound in compressed input size.

Open questions for a prover

  • Can such an assignment be computed in time polynomial in \(\tau\), the number of room categories, \(T\), and input bit length \(L\), without expanding a common denominator?
  • Can TTC+SD be implemented directly on type and bundle masses while preserving its EF1 and swapBE guarantee?

The case FOR (proponent)

The paper has no named NP-hardness, polynomial-time, or parameterized-complexity result. Its strongest computational anchor for a continuous mirror is Proposition 2, a constructive guarantee: in a multidimensional allocation problem, if agents have responsive and directionally separable preferences, the TTC+SD mechanism produces an allocation that is both EF1 and swapBE. The paper gives the proof here. It also notes that TTC+SD need not produce swapEF. This is a fairness guarantee for an allocation mechanism, not a running-time classification.

A natural high-multiplicity regime is assigning rooms to a large university cohort over several years. Residents rank a fixed set of room categories in each year; many residents share the same complete preference type, and the number of units in each category grows with cohort size. Thus the population size \(n\) can be much larger than the number of supported types \(\tau\). Each resident still receives whole rooms and an integral bundle. Only the aggregate mass of residents assigned each bundle can be fractional. That is a direct population continuization of the dorm-assignment problem, not a change to fractional outcomes.

Here is the corresponding problem, Continuous TTC Fair Allocation. An instance has a finite set \(\mathcal O_t\) of room categories for each period \(t\), rational per-capita supplies \(q_{t,o}\) with \(\sum_{o\in\mathcal O_t}q_{t,o}=1\), and a distribution \(\mu\) over \(\tau\) preference types. Each type has responsive, directionally separable preferences over period-by-period bundles, as in Proposition 2. Let \(\mathcal B=\prod_t\mathcal O_t\) be the set of integral bundles. The task is to return nonnegative rational masses \(x_{\theta,b}\), where \(x_{\theta,b}\) is the fraction of society of type \(\theta\) receiving bundle \(b\), such that
\[ \sum_{b\in\mathcal B}x_{\theta,b}=\mu_\theta,\qquad \sum_{\theta,b:\,b_t=o}x_{\theta,b}=q_{t,o}. \]
Every person represented by this allocation receives one whole room in each period.

The allocation must also be EF1 and swapBE across its support: for every pair of supported assignments \(x_{\theta,b}>0\), \(x_{\theta',d}>0\), if \(d\succ_\theta b\), there must be a period \(t\) with
\[ b\succeq_\theta(\emptyset_t,d_{-t}), \]
and there must be a reference bundle \(r\in\mathcal B\) and period \(s\) with
\[ b\succeq_\theta r \quad\text{and}\quad (d_s,r_{-s})\succeq_\theta(r_s,d_{-s}). \]
The reference bundle is a hypothetical fairness witness, just as in the paper; it need not be allocated.

The connection to Proposition 2 is concrete. For rational inputs, take a common denominator \(D\), make \(D\mu_\theta\) copies of each type, and \(Dq_{t,o}\) copies of each room category. There are \(D\) residents and \(D\) rooms per period, so the paper’s TTC+SD mechanism applies. Aggregate its allocation and divide counts by \(D\). Since the mechanism’s guarantee holds for every pair of residents, the resulting mass allocation satisfies the support-wise fairness conditions above. This establishes existence for the stated continuous model. It does not establish a polynomial-time algorithm in the binary input length: \(D\) may be exponential in that length.

I expect the search problem to be Class A, with a mass version of TTC+SD processing type and bundle masses directly. The paper’s mechanism gives a strong structural starting point, and only finitely many supported types and bundle configurations need representation. The open algorithmic question is whether that can be done efficiently in the compressed input parameters \(\tau\), number of room categories, \(T\), and bit length \(L\), without expanding the denominator. Further questions include whether the guarantee extends beyond directional separability and how the complexity changes when the number of periods or bundle configurations is unrestricted.

The weakest point is precisely that Proposition 2 proves a finite-population fairness guarantee, not a compressed continuous algorithm or a complexity bound. The denominator construction bridges existence, but may be computationally expensive. Still, the mirror asks the same question the authors study—whether a multidimensional allocation can bound envy by one-period changes—under a natural large-cohort regime.

The case AGAINST (opponent, writing after the proponent)

The strongest case against this anchor is a mismatch of research question. Proposition 2 proves that TTC+SD produces an allocation with EF1 and swapBE under stated preference restrictions. It does not classify the complexity of finding such an allocation, or study an optimization problem. The paper has no numbered complexity result for the proponent’s continuous model to mirror.

The proposed model is coherent: a large cohort can have finitely many complete room-preference types, supplies can scale with the population, and each resident can still receive an integral bundle. Requiring fairness across the support of the assignment faithfully represents comparisons between residents. Fractional assignment *masses* and per-capita supplies are appropriate co-modifications, not objections.

But the proposed task leaves a gap between the paper’s result and the computational question. If it asks whether a fair mass assignment exists, the denominator lift from rational masses to discrete copies transfers Proposition 2’s existence guarantee. If it asks for an algorithm polynomial in the compressed input, that is a question about implementing the mechanism—or finding some fair assignment—without expanding those copies. That could be worthwhile, but it is a new complexity question, not a complexity result from this paper. The proponent’s existence argument establishes no such runtime bound.

That is a real negative point, but it is narrow. I cannot honestly argue that the scenario or continuous model fails: the cohort regime is plausible and the mirror stays focused on population. The case against rests on whether ChoCo counts compressed implementation of a fairness mechanism as a mirror of this paper’s results. If it does, this anchor survives; the universal negative is weak.
