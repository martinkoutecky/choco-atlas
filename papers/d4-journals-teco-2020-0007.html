The continuous mirror question

Given rational masses \(\mu_t\) over a finite set of complete agent types \(T\), repeated item classes \(J\) partitioned into blocks \(J_1,\ldots,J_l\), per-capita supplies \(b_j\), utilities \(v_{tj}\), quota-group map \(g:T\to[k]\), quota masses \(\Lambda_{pq}\), and threshold \(U\), decide whether there exist masses \(x_{tj}\ge 0\) satisfying \(\sum_j x_{tj}\le\mu_t\), \(\sum_t x_{tj}\le b_j\), \(\sum_{t:g(t)=p}\sum_{j\in J_q}x_{tj}\le\Lambda_{pq}\), and \(\sum_{t,j}v_{tj}x_{tj}\ge U\), where each unit of agent mass receives one integral item from its class.

The model it lives in

A finite-type high-multiplicity assignment LP: type \(t\) carries quota group, eligibility, and utility vector \(v_{t\cdot}\), with population mass \(\mu_t\); item class \(j\) has repeated per-capita supply \(b_j\) and belongs to block \(J_q\); decision variable \(x_{tj}\) is assigned mass; the objective is \(\max\sum_{t,j}v_{tj}x_{tj}\) subject to type, supply, and type-block quota constraints.

The case FOR (proponent)

My strongest positive case is a genuine Class A mirror of the paper’s central hardness result.

The lead anchor is Theorem 1, proved in this paper: *the Assignment with Type Constraints (\(\ASTC\)) problem is NP-complete*. Its decision instance consists of agents partitioned into types \(N_1,\ldots,N_k\), items partitioned into blocks \(M_1,\ldots,M_l\), utilities \(u(i,j)\), type-block capacities \(\lambda_{pq}\), and a threshold \(U\). The question is whether there is a matching assigning each agent and item at most once, respecting every type-block capacity, whose total utility is at least \(U\). The paper proves membership in NP and gives a polynomial reduction from Bounded Color Matching.

I would mirror it with the following problem.

Call it Continuous Assignment with Type-Block Quotas, or \(\ASTC_\infty\). There is a finite set \(T\) of complete agent types. A type includes the paper’s quota-relevant group—ethnicity, SES tier, or another protected category—as well as the full utility vector, eligibility information, and any other attribute used by the allocation problem. Let \(g(t)\in [k]\) be the quota group of type \(t\), and let \(\mu_t\ge 0\) be its population mass, with \(\sum_{t\in T}\mu_t=1\).

Items remain indivisible for each individual, but are supplied in repeated classes. Let \(J\) be the set of item classes, partitioned into blocks \(J_1,\ldots,J_l\), and let \(b_j\) be the per-capita mass of available copies of class \(j\). A unit of mass assigned to \(j\) receives one whole item from that class. The quota \(\Lambda_{pq}\) is the permitted mass of agents from quota group \(p\) assigned to block \(q\). Utilities are \(v_{tj}\).

The decision variable is \(x_{tj}\), the mass of type \(t\) assigned to item class \(j\). The continuous problem asks whether there is an \(x\) satisfying \(\sum_{j\in J}x_{tj}\le \mu_t\) for every \(t\), \(\sum_{t\in T}x_{tj}\le b_j\) for every \(j\), and \(\sum_{t:g(t)=p}\sum_{j\in J_q}x_{tj}\le \Lambda_{pq}\) for every \(p,q\), with \(x_{tj}\ge 0\), such that \(\sum_{t,j}v_{tj}x_{tj}\ge U\).

This is not an outcome-space relaxation. An individual student receives one whole school seat, and an individual household receives one whole flat. The fractional quantity \(x_{tj}\) records how an atomless cohort is divided among integral assignments. Any feasible \(x\) can be implemented by partitioning the mass of each type into measurable subpopulations.

The high-multiplicity interpretation is direct. If a finite instance has \(n_t\) agents of complete type \(t\), \(m_j\) copies of item class \(j\), and quota \(\lambda_{pq}\), then at population scale \(S\) set \(\mu_t=n_t/S\), \(b_j=m_j/S\), and \(\Lambda_{pq}=\lambda_{pq}/S\). Conversely, rational masses and supplies can be cleared by a common denominator to produce a finite replicated instance. Thus \(\ASTC_\infty\) is the paper’s assignment problem in the regime where many agents share complete descriptions and population mass—not named individuals—is the operative quantity.

The natural regime is a large school-admission or public-housing intake: perhaps \(10^5\)–\(10^6\) applicants, but only \(10^2\)–\(10^4\) complete profiles induced by a finite menu of preference rankings, eligibility bands, neighbourhoods, budgets, and quota groups. Schools or housing blocks contain many seats or flats of each relevant class. This is stronger than saying that everyone of one ethnicity has identical preferences: different complete preference types may coexist inside the same quota group. The paper’s \(N_p\) is therefore a coarse protected category, while \(T\) supplies the finer high-multiplicity types required by the programme.

The expected classification is Class A. The continuous problem is the explicit linear program with \(|T||J|\) variables and \(|T|+|J|+kl\) families of constraints. It is solvable in polynomial time in the number of types, item classes, quota groups, blocks, and input bit length. The paper’s discrete NP-hardness is caused by selecting whole named agents and whole item copies in a bounded-color matching structure. Once repeated agent mass can be divided among integral assignments, that matching obstruction disappears.

This is also recognisably the authors’ problem. The objective is still utilitarian welfare; the feasible assignments still have one item per individual, one use per item copy, and hard type-block caps. Nothing is replaced by a lottery, a fairness objective, or a different matching notion. The only substantive change is exactly the population continuization, together with the necessary per-capita scaling of supplies and quotas. Indeed, the paper’s own percentage-quota interpretation makes that scaling especially natural.

The mirror also subsumes the paper’s polynomial special cases: when all agents in a quota group share one utility vector, the continuous formulation collapses to the min-cost-flow network used in the paper’s type-uniform theorem. Its exact LP solution is stronger than the paper’s \(1/2\)-approximation guarantee for the discrete problem, but that is the point of the mirror: it asks whether the paper’s NP-hardness survives in a high-multiplicity population. I would not claim to mirror the paper’s price-of-diversity theorems or lottery experiments; those are useful follow-up analyses, not the anchor.

The main follow-up questions are whether one can round \(\ASTC_\infty\) back to a finite population with small additive welfare loss, how the loss depends on the number of complete types and quota groups, whether exact quota-preserving rounding is possible in structured cases, and how much welfare is lost when the continuous optimum is implemented by a lottery or serial dictatorship. A further boundary question is whether hardness returns when some cohorts, seats, or eligibility groups must remain indivisible.

The weakest point is that an opponent can call this “just the LP relaxation” of the paper’s integer program. That criticism would be valid if the proposed setting had only a few idiosyncratic agents and one-off goods. I would concede that the mirror is weak for such instances. Its positive case depends on the explicit large-cohort scenario: repeated complete agent types, repeated item classes, and quotas specified as population proportions. In that regime the fractional-looking variables are aggregate masses of individually integral assignments, so the LP is not merely an artificial relaxation. It is the computational form of the problem the paper is already studying when the applicant population is genuinely high-multiplicity.

The case AGAINST (opponent, writing after the proponent)

The negative case is weak because Theorem 1 is almost tailor-made for a high-multiplicity mirror.

The paper’s \(\ASTC\) objective and constraints are aggregate: welfare is additive, and feasibility depends only on how much mass of each quota type is assigned to each item block. Individual identity matters only through utilities. That is precisely the structure for which a population continuum is meaningful. In a large school intake or housing programme, many applicants can share a complete type—quota category, eligibility, budget, and utility vector—while each seat or flat belongs to a repeated item class. The proposed variables \(x_{tj}\) then record the mass of agents of type \(t\) receiving an integral item from class \(j\).

This is not defeated by saying that the formulation is “just the LP relaxation.” In the stated regime it is the exact aggregate problem. For rational masses and supplies, clearing denominators produces a finite replicated instance; conversely, normalizing a replicated finite instance produces the continuous one. A feasible mass assignment can be implemented by partitioning each atomless type cohort into measurable subcohorts, each of which receives a whole item. The necessary scaling of supplies and quotas is not an illicit continuization of outcomes: it is the natural co-modification forced by a population limit, and the programme explicitly permits it.

Nor does heterogeneity rescue the objection. If all members of a quota group do not share preferences, their complete utility vectors define different types. That may increase \(|T|\), but it does not make the model incoherent. The relevant question is whether a large intake has relatively few repeated complete profiles, which is entirely plausible for school admissions, standardized jobs, or repeated housing units. Conversely, if every applicant has an idiosyncratic valuation for every named flat, then high multiplicity is indeed unhelpful—but that excludes one instance regime; it does not establish that no sensible regime exists.

The strongest criticism is therefore one of ambition, not validity. Once both agent cohorts and item copies are represented by finitely many classes, the mirror is an explicit linear program with \(|T||J|\) variables. It may be less technically distinctive than the programme’s column-generation examples, and its tractability follows from standard aggregate optimization rather than a subtle pricing theorem. But that does not make it a non-mirror. It asks exactly whether the paper’s NP-hard finite assignment problem remains hard when repeated agents and repeated goods make mass, rather than named identities, the operative quantity. The answer being an immediate Class A result is itself a legitimate computational conclusion.

Keeping the paper’s named flats and arbitrary agent–flat utilities would produce a much less convincing continuum: the item supply would not scale, and complete types would generally encode long identity-specific utility vectors. But that only shows that some literal continuizations are poor. It does not defeat the better repeated-school-seat or repeated-housing-unit model proposed by the other analyst.

Thus I cannot honestly defeat the anchor. Theorem 1 supplies a well-posed continuous-population question, with a natural high-multiplicity interpretation and an exact LP answer. The paper’s lottery experiments and price-of-diversity bounds need not have useful mirrors, but the single surviving \(\ASTC\) mirror is enough. The universal claim that no worthwhile continuous mirror exists is not supportable.
