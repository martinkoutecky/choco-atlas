The continuous mirror question

Given a finite type set \(\Theta\), rational masses \(\mu_\theta\), objects \(O\), type-specific integral bundle families \(\mathcal B_\theta\), represented bihierarchical per-capita quotas, and a feasible target \(X\), compute nonnegative masses \(z_{\theta B}\) such that \(\sum_{B\in\mathcal B_\theta}z_{\theta B}=\mu_\theta\), \(X_{\theta a}=\sum_{B\ni a}z_{\theta B}\), and all aggregate quotas are satisfied.

The model it lives in

A type-compressed measurable implementation LP with type masses \(\mu_\theta\), variables \(z_{\theta B}\) assigning mass to integral bundles, linear object and quota constraints, and exact marginal targets \(X\); a global lottery is optional.

The objection that survived

Atomless splitting removes the finite global-lottery correlation that makes Theorem 1's rounding statement distinctive, so the mirror changes implementation from a lottery over finite pure assignments to a measurable mass decomposition.

fatal: False

What the mirror covers

The mirrors cover Theorem 1's implementation result and Theorem 3's generalized probabilistic-serial guarantee; they leave the pseudo-market results, utility-guarantee theorems, and multi-sided and roommate impossibility results unmirrored.

Open questions for a prover

  • Can the mass-decomposition LP be solved in time polynomial in \(\tau\), \(|O|\), \(|\mathcal H|\), and bit length \(L\) under a compact bihierarchy representation?
  • When does a type-level measurable implementation admit a lottery over globally quota-feasible pure assignments, and can its support be bounded polynomially?
  • Does the type-weighted generalized \(PS\) process preserve ordinal efficiency and weak strategy-proofness for all positive-mass types?

The case FOR (proponent)

Strictly, this paper contains no named theorem asserting NP-hardness, membership in \( \mathrm{P} \), W[1]-hardness, FPT, or a comparable complexity classification. It is a mechanism-design paper, not a computational-complexity paper. Thus it cannot supply a genuine ChoCo hardness anchor. The strongest positive case uses its named constructive results as anchors for a new high-multiplicity computational problem.

The natural regime is a large school district or university course market. There are \(n\) agents but only \(\tau\) complete types, with \(\tau\ll n\). A type includes everything relevant to the paper’s model: the ranking or cardinal values of objects, eligibility, group-membership, and all individual constraints. Let \(\mu_\theta\) be the mass of type \(\theta\), with \(\sum_\theta \mu_\theta=1\). Object capacities and group quotas are normalized per capita. Each individual still receives an integral school or course bundle; only the aggregate assignment of a type is fractional because an atomless mass of identical agents can be divided between integral bundles.

My lead anchor is Theorem 1 (Sufficiency), proved in the paper using total-unimodularity results attributed to Hoffman–Kruskal and Edmonds, with a fuller proof in Appendix C. Its complete content is: if a constraint structure is a bihierarchy, meaning that it is the union of two disjoint hierarchies, then for every choice of integer quotas, every expected assignment satisfying those quotas can be implemented as a lottery over feasible pure assignments.

The corresponding continuous problem is:

\(\mathrm{Bihierarchy\text{-}Implementation}_\infty\). An instance consists of a finite type set \(\Theta\), object set \(O\), rational mass vector \(\mu\), type-specific integral bundle constraints, a bihierarchical family of aggregate constraints, and a target type-level expected assignment \(\bar X\). The target is required to satisfy every normalized quota. The question is to output a measurable assignment of each unit of population to an integral bundle, or equivalently a distribution over feasible pure assignments, such that type \(\theta\) receives object \(a\) in total mass \(\mu_\theta \bar X_{\theta a}\). The objective is exact implementation; minimizing the support of the implementing lottery can be added as a secondary objective but is not part of the paper’s theorem.

This is not merely a fractional-outcome problem. The requested solution must partition the mass of each type among integral bundles while respecting capacities and group quotas exactly. For rational \(\mu\), it is the high-multiplicity version of expanding each type into \(n\mu_\theta\) identical agents; the continuous formulation removes irrelevant dependence on the names of those agents. The paper’s Appendix D gives a constructive flow-based decomposition algorithm, so I would expect this problem to be Class A under an explicit bihierarchy representation and a compressed type-level output model. A formal polynomial-time bound in \((\tau,|O|,|\mathcal H|,L)\), rather than in the expanded population size \(n\), would be the ChoCo result to prove.

The authors should recognize this as their problem: it retains their objects, indivisible bundles, quotas, and implementation question, while changing the society from named agents to a distribution over indistinguishable agent types. The school-choice examples with controlled choice provide a particularly credible regime: many applicants share ranking, eligibility, and quota-relevant characteristics, while the number of occupied types is far smaller than the number of applicants.

A second, weaker anchor is Theorem 3, proved in the paper and in Appendix G. It states that, for every preference profile, the generalized probabilistic serial assignment \(PS(\succ)\) is ordinally efficient at that profile, and every realization of its implementing lottery is ex-post Pareto efficient.

Its continuous mirror is \(\mathrm{Generalized\text{-}PS}_\infty\). The instance consists of \((\Theta,\mu)\), a finite object set \(O\) including a null object, per-capita capacities, maximum group quotas forming the paper’s hierarchical constraint structure, and a strict preference order \(\succ_\theta\) for every type. At time \(t\), type \(\theta\) consumes its most-preferred currently available object at aggregate rate \(\mu_\theta\). An object is unavailable to that type whenever some quota containing the relevant type-object pair is tight. At \(t=1\), the resulting masses \(X_{\theta a}\) are returned, together with an integral-bundle implementation.

The continuous question is whether one can compute this population allocation and implementation, and certify:

\[ \sum_{b\succeq_\theta a} \frac{X_{\theta b}}{\mu_\theta} \]

is not weakly below the corresponding quantity for any other feasible allocation for every type and every cutoff \(a\), with strict improvement for no positive-mass type. That is the type-level version of ordinal efficiency. The implementation must also have no feasible realization in which every agent is weakly better off and a positive mass is strictly better off.

I would also expect this problem to be Class A. The eating process has finitely many type-object exhaustion events and can be simulated by an event-driven algorithm. The paper’s Corollary 2 supplies the implementation step in the finite model: for every preference profile, the generalized PS assignment is implementable. In the continuum version, this becomes a type-compressed implementation theorem.

The main plausibility objection is that the paper already uses fractional expected assignments and continuous “eating.” A superficial version of the mirror would therefore be only outcome-space continuity, which is outside ChoCo’s scope. The positive case survives only if the population change is made explicit: \(\mu\) is the input society, capacities and quotas scale with population mass, and the output assigns integral bundles to almost every individual in that society. The expected assignment is then a summary of a continuous population allocation, not the object being continuized.

My weakest point is the absence of a genuine complexity anchor. Nothing in the paper establishes that discrete computational hardness dissolves, transfers, or becomes continuum-specific. The strongest defensible claim is narrower: this paper supplies a very natural high-multiplicity mirror whose underlying implementation and probabilistic-serial questions plausibly fall into Class A, with bihierarchy as the structural reason. It does not yet justify a claim about ChoCo’s central complexity trichotomy. Further questions would include whether the type-compressed algorithm has polynomial bit complexity, whether the paper’s weak strategy-proofness result (Theorem 5) survives the population limit, and whether the three-sided and roommate impossibilities in Theorems 12 and 13 persist under atomless populations.

The case AGAINST (opponent, writing after the proponent)

The strongest negative case is that neither anchor is actually a computational result. Theorem 1 proves an integrality and convex-decomposition property; Theorem 3 proves welfare and incentive properties of a mechanism. Neither states a decision, optimization, approximation, or complexity problem. The proponent’s mirrors therefore introduce the computational content themselves, rather than continuizing a computational question from the paper.

Theorem 1 is the better anchor, but its central phenomenon disappears under the atomless interpretation. For a type \(\theta\), let \(\mathcal B_\theta\) be its feasible integral bundles and introduce masses \(z_{\theta B}\) satisfying

\[ \sum_{B\in\mathcal B_\theta} z_{\theta B}=\mu_\theta, \qquad X_{\theta a}=\sum_{B\ni a}z_{\theta B}. \]

This is already an implementation: assign a measurable subpopulation of type \(\theta\) of mass \(z_{\theta B}\) to bundle \(B\). No lottery over pure assignments is needed. Fractional type-level consumption is not an expected assignment awaiting implementation; it is the aggregate of individually integral assignments.

That is precisely the indivisibility distinction on which Theorem 1 depends. In the finite model, one must round a single assignment of named agents while preserving every quota. In the atomless model, one may split a type into arbitrarily many measurable subpopulations, so convexification is built into the population itself. The theorem’s total-unimodularity argument has therefore been replaced by the definition of a measurable allocation. If one insists on a lottery over globally feasible pure assignments, one is reinstating the finite-world implementation requirement and its correlation structure; that is no longer the natural computational question about a continuous society. Minimizing lottery support would be a potentially new problem, but it is not part of Theorem 1 and would need independent justification.

The school-choice and course-allocation stories make the high-multiplicity regime credible, so “there are no repeated types” is not a viable objection. The problem is more specific: the proposed problem is a sensible compressed allocation exercise, but not a computational mirror of the theorem’s substantive content. Its interesting feature is population compression, while the paper’s theorem concerns integrality of a finite assignment polytope.

Theorem 3 is weaker still. Generalized probabilistic serial already contains a continuous-time process, but that continuity is in the mechanism’s time variable and in probability shares, not in the population. After grouping identical agents into types, the process is simply

\[ \dot X_{\theta a}(t)=\mu_\theta \]

for the currently preferred available object \(a\). The event sequence is the finite algorithm with repeated rows compressed. At the end, \(X_{\theta a}\) is directly the mass of type \(\theta\) assigned to object \(a\); for single-unit demand, there is no residual implementation problem at all.

A stronger mirror could ask for a type-level notion of ordinal efficiency or for a measurable Pareto-improvement certificate. That would be legitimate modelling, but it would be a new welfare-analysis problem, not a computational result asserted by Theorem 3. The theorem already guarantees the property for every reported profile. “Compute the outcome and certify the theorem’s conclusion” supplies no complexity anchor unless one adds a separate search or optimization problem.

Thus the proponent has shown that a high-multiplicity school or course market can be sensibly formulated. They have not shown that this paper contains a worthwhile ChoCo mirror under the programme’s computational remit. The honest limitation of the negative case is that the proposed type-compressed allocation problem is not nonsensical; if ChoCo is willing to treat constructive high-multiplicity algorithms with no original complexity statement as sufficient anchors, this paper should pass. Under the stricter stated standard—computational questions about a continuous society—both anchors fall short.
