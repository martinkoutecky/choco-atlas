The case FOR (proponent)

The nearest result is Theorem 2, proved here: for the game \(v(S)=|\{P\in\mathcal P:N_P^*\subseteq S\}|/|\mathcal P|\) on non-sink agents, its Shapley value equals \(w^*\), where each source-to-sink path gives total weight \(1/|\mathcal P|\), divided equally among that path’s non-sink agents. Section 4.3 gives a dynamic program to compute these weights in polynomial time. But the numbered theorem asserts the identity, not a complexity classification; the polynomial-time claim is in the surrounding text. There is no numbered hardness, \(P\), or parameterized-complexity result to anchor a mirror on.

The closest possible mirror would put many interchangeable firms into supply-chain role types, give each type rational population mass, and ask for type-level Shapley liability shares based on paths through those roles. It has a plausible high-multiplicity story, but it does not preserve the paper’s path-counting game: counting individual paths makes clone multiplicities matter, while counting role-type paths makes them irrelevant. Making cancellation choices into fractional mass flows creates a further problem: an individual atomless firm’s deviation has no effect on the outcome. Avoiding that requires treating a type as a decision-making bloc, which changes the strategic model.

Theorem 1 is the paper’s central result, but it characterizes fixed-weight rules from axioms; it does not classify the complexity of a computational problem. The remaining named propositions are also structural or axiomatic. So I would not hand a continuous problem to a prover as a mirror of a qualifying anchor. The soft spot is fundamental: the paper’s tractability concerns computing graph-based weights, while the continuous programme needs a computational question whose difficulty turns on population multiplicity.

The case AGAINST (opponent, writing after the proponent)

The strongest candidate is Theorem 2 and the path-weight computation around it. Theorem 2 proves an identity: the proposed path-by-path weights equal the Shapley value of a path-counting game. Section 4.3 gives a dynamic program for computing those weights on a finite DAG. Neither result classifies the complexity of a computational problem, and the paper does not pose one with an input encoding, complexity measure, or exact, approximation, or parameterized algorithm question. The computation is a subroutine on the network, not a complexity result about a society given as a distribution over types.

The best version of the proposed mirror would group interchangeable firms into role types, with masses and identical successor options, edge costs, and strategic behavior within each type. One could define a type-level path game and assign each firm a per-capita liability density, such as \(w_t/\mu_t\), so the type’s aggregate liability is finite and an individual’s incentives do not vanish. That is a coherent economic extension. But its central question would be how to define and compute allocation weights in a continuum-population network game. The paper’s Theorem 2 does not establish a computational result that this extends, and the extension would need its own justification as a problem the authors recognize as theirs.

Theorem 1 is no stronger as an anchor: it characterizes liability rules by axioms. Propositions 1–4 are structural implications of those axioms; Theorem 2 is the Shapley identity; and the simulation is illustrative. A continuous axiomatic characterization would continuize the mechanism or the agent space, but it would not supply the missing computational result.

So the negative case is strongest at the programme boundary: the paper offers no qualifying computational result to mirror. It is weaker as a universal claim that no worthwhile continuous model could be built. The repeated-firm, role-type model is plausible and may be worthwhile for network allocation research; the case against it is that it is a new continuum game, not a continuous-population mirror of a computational result in this paper.
