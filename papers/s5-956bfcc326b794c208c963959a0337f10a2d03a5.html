What the mirror covers

The proposed mirror covers no named result; the numbered results concern axiomatic preservation and aggregation-rule characterizations.

The case FOR (proponent)

There is a plausible population model here: in a large public consultation about a fixed debate, many participants might share one of a small number of complete views about which arguments attack which. A type would be an irreflexive attack relation on the fixed argument set, and \(\mu_t\) the fraction of participants with type \(t\). A quota aggregator could include an attack when at least an \(\alpha\) fraction of the population supports it. That makes the society continuous, with \(n\) much larger than the number \(\tau\) of distinct views.

But this paper has no named computational result to anchor a continuous computational problem to. For example, Theorem 1, proved here, says that when \(|\mathrm{Arg}|\ge4\), any unanimous, grounded, neutral, and independent aggregation rule that preserves argument acceptability under grounded, stable, preferred, or complete semantics must be dictatorial. That is an axiomatic impossibility result, not a complexity result. The other numbered results likewise concern preservation properties and aggregation-rule axioms. The conclusion’s claim about the computational intractability of distance-based rules points to other papers; it is not a named result established here.

So the model-level case is plausible, but it cannot supply a compliant anchor-led case: there are zero eligible anchors, and assigning this paper’s results a Class A, B, or C continuous computational mirror would require inventing a new problem rather than mirroring a named computational result.

The case AGAINST (opponent, writing after the proponent)

The proponent names Theorem 1, but also gives the reason it cannot anchor a ChoCo mirror: it characterizes which aggregation rules preserve acceptability under axioms. Replacing supporter counts with masses yields a sensible model—participants can be grouped by their complete attack relations, and attacks accepted above an \(\alpha\)-mass threshold—but the resulting question is still about axiomatic preservation. It does not turn Theorem 1 into a computational result.

The same problem remains for a stronger version of that mirror. With rational type masses, a fixed quota rule can compute the aggregated attack relation by summing the support for each attack. One could then study the cost of shifting mass until a semantic property fails, but the paper specifies no such intervention or cost problem. That would be a new optimization problem inspired by its model, not a high-multiplicity version of a named computational result. The complexity of evaluating the resulting semantics would also be driven chiefly by the number of arguments, not by the population representation.

The proponent’s consultation scenario is credible: many participants can share one of a small number of views about a fixed debate. So the objection is not that multiplicity is implausible or that the type space is unnatural. It is that this paper’s results concern axiomatic preservation, while ChoCo’s target is the computational complexity of problems posed over a continuous society. That is a strong case against a *mirror of this paper*. It does not establish that no worthwhile computational project could be built from its model; it establishes that doing so would require proposing a new problem rather than continuizing a computational result the paper actually proves.
