The continuous mirror question

Given a candidate set \(C\) and an explicit support of \(\tau\) nonempty approval types \(A\subseteq C\), each with positive binary-rational mass \(\mu_A\) and \(\sum_A\mu_A=1\), find a nonempty committee \(W\subseteq C\) maximizing \(\mathrm{MSat}_{\mu}(W)=\sum_A\mu_A\frac{|W\cap A|}{\min(|A|,|W|)}\).

The model it lives in

The society is a distribution \(\mu\) over approval-set types \(A\subseteq C\). The decision variable is a nonempty committee \(W\subseteq C\); maximize \(\mathrm{MSat}_{\mu}(W)=\sum_A\mu_A\frac{|W\cap A|}{\min(|A|,|W|)}\).

What the mirror covers

The mirror covers arbitrary-size MSAV winner determination in Proposition 4. It leaves CSAV in Propositions 1–2 and fixed-size MSAV in Proposition 3 outside its scope.

Open questions for a prover

  • Given a committee \(W\) and distribution \(\mu\), what is the minimum total-variation distance to a distribution under which \(W\) is no longer an MSAV winner?

The case FOR (proponent)

My strongest affirmative case is the arbitrary-size MSAV winner problem. The anchor is Proposition 4, proved in this paper: a maximum-MSAt set of any size can be computed in polynomial time. In full, among all nonempty committees \(W\subseteq C\), it finds one maximizing
\[ \mathrm{MSat}(W)=\sum_{i\in N}\frac{|W\cap A_i|}{\min(|A_i|,|W|)}. \]
The paper’s algorithm considers each size \(k\), finds the best committee of that size, then returns the best across sizes.

Here is the continuous-population question I would hand to a prover: Continuous MSAV Winner Determination. An instance consists of a candidate set \(C\) and an explicit list of \(\tau\) nonempty approval types \(A\subseteq C\), each with a binary-rational mass \(\mu_A>0\), where \(\sum_A\mu_A=1\). Each type is the set of candidates approved by that fraction of society. Find a nonempty committee \(W\subseteq C\) maximizing
\[ \mathrm{MSat}_{\mu}(W)=\sum_A \mu_A\frac{|W\cap A|}{\min(|A|,|W|)}. \]
A solution is any committee attaining the maximum, with ties allowed. Restricting to nonempty approval types keeps the objective defined as printed in the paper.

This is the population-continuous version of their problem: for a finite profile with \(\mu_A\) equal to the fraction of voters submitting ballot \(A\), the continuous score is the paper’s score divided by the number of voters. So the winners are identical. The decision variable remains the committee; only the population becomes a distribution over types.

A plausible regime is a large public consultation over a fixed slate of nominees or proposals. Each resident approves a subset, and many residents may submit the same ballot. There may be millions of residents but far fewer distinct approval sets, so the input can naturally be summarized by \(\tau\) type masses. This is an instance-regime claim, not a claim that all committee elections have high multiplicity.

I expect this mirror to be tractable. For each committee size \(k\), give candidate \(c\) the weighted score
\[ q_c(k)=\sum_{A\ni c}\frac{\mu_A}{\min(|A|,k)}. \]
The score of a size-\(k\) committee is the sum of its candidates’ scores, so select the \(k\) highest-scoring candidates; then compare the resulting committees across \(k=1,\ldots,|C|\). With rational input, this gives an exact algorithm polynomial in \(|C|\), \(\tau\), and the input bit length. I expect the same tractable outcome as Proposition 4, now for a high-multiplicity input representation.

The paper contains no named hardness result to anchor a question about discrete hardness dissolving in the continuum; its numbered computational propositions establish polynomial algorithms. I would therefore keep the scope to Proposition 4 rather than imply that this mirror covers the paper’s other results or produces a complexity reversal. A natural next question is winner robustness: what is the minimum total-variation change to the type distribution that makes the current committee cease to be an MSAV winner?

The weak point is that this may look to the authors like a routine weighted-profile extension: the original algorithm already exploits additivity across candidates, and the continuous version preserves it. That limits the novelty of the computational story. But the mirror is still a faithful population continuization: it uses approval sets as types, their masses as population shares, and the paper’s unchanged committee objective.

The case AGAINST (opponent, writing after the proponent)

The strongest case against Proposition 4 as a programme priority is that its continuous mirror adds almost no new algorithmic structure. For each committee size \(k\), the mass-weighted score of candidate \(c\) is
\[ q_c(k)=\sum_{A\ni c}\frac{\mu_A}{\min(|A|,k)}. \]
The best \(k\)-member committee is just the \(k\) candidates with the largest \(q_c(k)\); checking all \(k\) gives the arbitrary-size winner. The paper’s proof already has exactly this form, with voter counts in place of masses. Replacing counts by binary-rational weights preserves the argument, and any rational distribution can also be scaled to integer ballot counts. So this mirror seems unlikely to reveal a new tractability boundary or call on continuous-optimization machinery.

That is a reason to rank it as a low-yield project, not a reason that no worthwhile mirror exists. The distinction between explicit voters and a support list with rational masses is a real high-multiplicity input regime, and a large consultation over a fixed slate of proposals is a plausible setting for it. The continuous question is well-defined, has a named computational result to mirror, and asks about the population itself. Calling it already done because the paper’s proof aggregates voters would confuse an easy high-multiplicity extension with a prior continuous treatment.

A total-variation question about how much the approval distribution must change before a committee loses, as the proponent suggests, could add a more substantial computational problem. But it is not needed to rescue the main mirror, and it is not a result of this paper.

So the best negative case is that the Proposition 4 mirror is mathematically immediate and may not merit much of ChoCo’s time. It does not support the stronger claim requested here: that no scenario or population model yields a worthwhile mirror. On the programme’s stated standard, this is a valid, if modest, continuous mirror.
