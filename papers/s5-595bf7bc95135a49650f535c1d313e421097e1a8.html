The continuous mirror question

Given categories \(\mathcal K\) and rational masses \(\mu_t>0\) over supported types \(t=(\succ_t,e_t)\), where \(\succ_t\) is a strict ranking of categories and \(e_t\) is the endowed category, compute a mass allocation \(y_{t,k}\) satisfying \(\sum_k y_{t,k}=\mu_t\) and \(\sum_{t:e_t=k}\mu_t=\nu_k=\sum_t y_{t,k}\), with no mass rectification block, or report that none exists. A block selects submass from current type-category assignments and reallocates it using the selected agents’ endowed-category supplies, with weak improvement for all selected mass and strict improvement for positive mass; indifferent participating mass currently assigned category \(k\) is admissible only if the coalition owns all copies of \(k\), that is, \(E_k=\nu_k\).

The model it lives in

Types are category rankings paired with endowed categories, carrying rational masses \(\mu_t\). The decision variables \(y_{t,k}\) assign mass of each type to categories while preserving type mass and category supply. Each unit of mass still receives one indivisible copy; \(y\) records aggregate assignments, and blocking is defined by selected submasses, category reassignments, weak improvement, positive-mass strict improvement, and the rectification condition \(E_k=\nu_k\) for indifferent participants.

The objection that survived

The paper proves finite-agent TTC correctness only; type-mass aggregation and a runtime bound polynomial in \(|\mathcal K|,\tau,L\) remain unproved.

fatal: False

What the mirror covers

The mirror covers the common-indifferences setting with copy categories and the search for a rectified-core allocation; it leaves arbitrary weak preferences, the general GTTC guarantee, the tightness result, and comparisons with other cores aside.

Open questions for a prover

  • Can a weighted TTC procedure produce a rectified-core mass allocation directly from binary-encoded masses in time polynomial in \(|\mathcal K|,\tau,L\)?
  • What is the precise two-way correspondence between these mass allocations and finite high-multiplicity markets?

The case FOR (proponent)

The best positive case is the paper’s common indifferences result. Its authors explicitly model objects as categories with multiple copies, with agents indifferent among copies of a category. That gives a credible high-multiplicity setting without changing the question into one about lotteries or divisible outcomes: each person still receives one indivisible object.

My anchor is Proposition 3, proved in this paper: “When agents have common indifferences, all outcomes of TTC belong to the rectified strong core.” In full, when objects are grouped into categories of copies, and agents are indifferent exactly among copies of the same category, every outcome produced by top trading cycles is a rectified strong core allocation. The paper contains no named complexity-class result such as an NP-hardness or FPT theorem. Proposition 3 is an algorithmic correctness result, not a runtime bound.

A plausible regime is a large housing exchange in which households hold rights to units in a small set of categories—say, by size and accessibility—and many households share both a ranking of categories and an endowed category. The type is that ranking together with the household’s endowed category. With \(N\) households and \(\tau\) supported types, the regime of interest has \(N\gg\tau\). This is especially plausible here because the paper itself identifies multiple copies of object types as a natural source of common indifferences.

The continuous problem I would put to a prover is weighted rectified-core search for copy-indifferent housing markets. Let \(\mathcal K\) be the finite set of object categories. Each supported type \(t\) has a strict ranking \(\succ_t\) over categories and an endowed category \(e_t\), and has rational mass \(\mu_t>0\), with \(\sum_t\mu_t=1\). The supply of category \(k\) is \(\nu_k=\sum_{t:e_t=k}\mu_t\). An allocation is a nonnegative mass matrix \(y_{t,k}\): \(y_{t,k}\) is the mass of type \(t\) receiving a copy of category \(k\), with \(\sum_k y_{t,k}=\mu_t\) and \(\sum_t y_{t,k}=\nu_k\). It is an aggregate description of assignments of whole copies to individuals; it does not give any individual a fractional object.

The question is: given this instance, does a rectified core allocation exist, and if so, return one? A solution is a rational matrix \(y\) satisfying those supply constraints for which there is no rectification block. Precisely, a coalition can choose \(z_{t,k}\le y_{t,k}\) mass from each currently assigned type-category cell. Its endowment of category \(r\) is \(E_r=\sum_{t:e_t=r}\sum_k z_{t,k}\). It can reassign that mass through a matrix \(q_{t,k,\ell}\), preserving each selected cell’s mass and using exactly \(E_\ell\) copies of each category \(\ell\). Every reassignment must be weakly preferred to the current category, and a positive mass must strictly improve. For any positive mass left indifferent, the rectification condition requires the coalition to own all copies in that agent’s indifference class. In this common-indifferences setting, an agent currently receiving category \(k\) is indifferent only among copies of \(k\), so this condition is \(E_k=\nu_k\). The continuum version counts a strict improvement only when it has positive mass.

I expect this search problem to be Class A, plausibly solvable in \(\operatorname{poly}(|\mathcal K|,\tau,L)\) time by an aggregate TTC procedure that moves masses rather than processing households one by one. A finite market with rational proportions can be recovered by scaling up to a common denominator, but that denominator can be exponential in its binary encoding length \(L\). Compressing TTC to work directly with the type masses is therefore a real computational question. Proposition 3 supports the correctness target, but it does not prove an aggregate algorithm or the stated runtime.

The scope is deliberately narrow: it mirrors Proposition 3’s copy-indifference setting, not every result or every preference structure in the paper. Useful follow-on questions are whether weighted TTC always produces the desired allocation, whether the continuous and high-multiplicity discrete formulations agree in both directions, and how the answer changes when indifference classes vary by type.

My weakest point is that Proposition 3 concerns named agents and does not establish that TTC can be compressed to a small-support mass representation. Moreover, the finite result is already an algorithmic one, not a discrete hardness result that continuization might dissolve. The positive case rests on the paper’s unusually direct fit to a population regime with many repeated types and identical object copies; whether that fit yields a genuinely efficient mass algorithm remains the open work.

The case AGAINST (opponent, writing after the proponent)

The strongest case against is that this paper gives no named computational-complexity result to continuize. Theorem 1 establishes existence and welfare properties; Propositions 2 and 3 establish that specified algorithms produce allocations in the rectified strong core. None gives a running time, a complexity classification, or an algorithmic bottleneck such as a pricing problem. Proposition 3 is the closest anchor, but it proves correctness of a finite-market algorithm, not the complexity of a computational problem.

The proposed common-indifferences regime is unusually plausible. Types defined by a ranking of categories and an endowed category give a sensible high-multiplicity market, and the mass matrix is a reasonable aggregate description of assignments of indivisible copies. I would not reject the mirror because of indifferences, fractional type averages, or the absence of individual names.

The difficulty is what the proposed question adds. Since the paper already gives a finite algorithm that produces a rectified-core allocation, the continuous search problem chiefly asks whether that construction can be compressed to operate on rational type masses. In the copy-indifferent case, preferences and supplies are already described by a finite set of type-category quantities. The paper identifies no hard subproblem or structural barrier that would make this compression a substantial complexity question. A weighted TTC or flow-based construction could be useful, but its value as a new algorithmic result is conjectural here; it is not a complexity landscape the paper points toward.

The broader version, using arbitrary weak preferences and asking for a mass-based core allocation, has the same gap. It may be a worthwhile new question, as might core-membership or blocking detection. But those questions are choices made by a follow-on project; the paper does not formulate them as computational problems. Adding a plausible large-market application does not supply that missing connection.

So I can make a strong case against treating Proposition 3 as a ChoCo mirror target: it is an algorithmic correctness result without a computational-complexity question behind it. I cannot honestly make the universal claim that no scenario yields worthwhile work. The common-copy market is a credible high-multiplicity regime, and compressing the algorithm for binary-encoded masses could prove nontrivial. The negative case is strongest if ChoCo requires its mirrors to grow from computational results in the paper; it is weaker if the programme also welcomes new complexity questions prompted by algorithmic existence results.
