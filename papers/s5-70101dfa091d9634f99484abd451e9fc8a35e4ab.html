The case FOR (proponent)

The strongest honest case is a qualified positive one: the paper supports a genuine continuous-population mirror of its approximate APS-allocation problem. My lead anchor is Corollary 5, proved in this paper.

Corollary 5 states that, for indivisible goods and monotone submodular valuations given by value queries, there is a polynomial-time algorithm producing an allocation in which every agent receives at least \(1/3\) of her APS when entitlements are arbitrary. In the equal-entitlement case, it also gives a polynomial-time \(10/27\)-MMS allocation for submodular valuations. I use the arbitrary-entitlement APS clause as the anchor; the equal-entitlement MMS clause is the corresponding special case.

A natural high-multiplicity regime is a large school, housing, or public-benefits allocation system. There are \(N\) people but only \(\tau\ll N\) complete valuation-entitlement profiles: people of the same type have the same monotone submodular valuation \(v_t\) over \(m\) standardized indivisible goods and the same entitlement parameter. Let \(\mu_t\) be the fraction of the population of type \(t\), and let \(q_j\) be the per-capita supply of item kind \(j\). Item copies remain indivisible; only the number of agents receiving each integral bundle becomes a mass.

To make APS meaningful in the limit, write \(\beta_t\) for the entitlement density of type \(t\), with \(\sum_t\mu_t\beta_t=1\). Define the type-level anyprice share by

\[ A_t^\infty = \min_{\substack{\pi_j\ge 0\\ \sum_j q_j\pi_j=1}} \; \max_{\substack{S\subseteq [m]\\ \sum_{j\in S}\pi_j\le \beta_t}} v_t(S). \]

The continuous problem is:

Continuous High-Multiplicity \(1/3\)-APS Allocation. Given rational type masses \(\mu\), rational per-capita supplies \(q\), entitlement densities \(\beta\), and value-query access to the submodular functions \(v_t\), find nonnegative masses \(x_{t,S}\) such that

\[ \sum_{S\subseteq[m]}x_{t,S}=\mu_t \]

for every type \(t\),

\[ \sum_{t}\sum_{S\ni j}x_{t,S}\le q_j \]

for every item kind \(j\), and

\[ x_{t,S}>0 \quad\Longrightarrow\quad v_t(S)\ge \frac13 A_t^\infty. \]

The optimization version maximizes the largest \(\rho\) for which the last inequality can be guaranteed with \(\rho A_t^\infty\).

This is a population continuization, not fractionalization of an individual’s bundle. Every agent receives an integral \(S\); \(x_{t,S}\) records the mass of type-\(t\) agents receiving that bundle. For rational data, choosing \(N\) to clear denominators produces \(N\mu_t\) agents of type \(t\) and \(Nq_j\) indivisible copies of item \(j\). Giving each such agent budget \(\beta_t/N\) and each copy of item \(j\) price \(\pi_j/N\) reproduces the displayed APS expression exactly. Conversely, a finite allocation normalizes to an \(x\)-solution. Thus this is the high-multiplicity version of the paper’s problem, not merely a divisible-goods relaxation.

The authors should recognize this as their problem because the valuation class, the indivisible-bundle model, the no-payment assumption, arbitrary entitlements, and APS benchmark are unchanged. Only redundant named agents have been replaced by masses of identical agents, with item supplies scaled per capita as feasibility requires. The NBA example in the paper is too small to justify this regime, but large-scale allocation of course seats, housing slots, or standardized benefit packages with repeated preference profiles is a much better one.

I would expect this mirror to be Class A, although the paper does not prove the compressed algorithm. Its finite algorithm suggests an aggregate bidding or configuration-LP approach whose running time depends on \(m\), \(\tau\), and the input bit length rather than on \(N\). The main computational question is whether the repeated-agent bidding process can be compressed into a polynomial-size type-level representation, or whether a pricing oracle over integral bundles is required. Any hardness that remains would then come from submodular valuation/pricing structure, not from the number of named agents.

The weakest point is exactly this complexity gap. Corollary 5 is polynomial in the explicit number of agents; it does not automatically imply a \(\operatorname{poly}(m,\tau,L)\) algorithm when enormous multiplicities are binary encoded. A type-aggregated process might still encounter exponentially many bundle states, and APS computation itself is discussed as hard in the paper’s unnumbered appendix. So I would present the mirror as a strong, natural research question with a plausible Class-A route, not as an algorithm already obtained from Corollary 5.

It generates several worthwhile follow-ups: whether the \(1/3\)-APS and \(10/27\)-MMS guarantees admit compressed algorithms; whether a polynomial-size integral-bundle decomposition always exists; how the answer depends on \(\tau\), \(m\), or bounded valuation structure; and whether the paper’s XOS impossibility boundary survives when the bad valuation type has positive population mass.

The case AGAINST (opponent, writing after the proponent)

The strongest negative case is that Corollary 5 does not survive as a faithful population continuization. Its ground set \(M\) consists of distinct indivisible goods, and each valuation is an arbitrary submodular function \(v:2^M\to\mathbb{R}_{\ge 0}\). Replacing each good \(j\) by \(Nq_j\) copies requires extending \(v\) from sets to multisets. The proposed model silently chooses one particular extension: copies of a kind are perfect substitutes, and an agent receives at most one copy of each kind. Other natural extensions—distinct copies, diminishing value for repeated copies, or multi-unit complementarities—produce different MMS and APS values. Thus the displayed \(A_t^\infty\) is not forced by high multiplicity; it defines a new multi-unit fair-division problem.

Keeping the original \(m\) goods avoids that modelling choice but makes the limit degenerate: with \(N\) agents and only \(m\) objects, almost every agent receives the empty bundle, while positive share guarantees disappear. Scaling supplies repairs this, but only by changing the scarce-object side of the problem as well as the population. The resulting question may be sensible, yet it is no longer a continuous version of the paper’s finite-good problem in the strict high-multiplicity sense.

There is also a mismatch in computational content. Corollary 5 is obtained by simulating a sequential bidding game in which named agents exhaust budgets, win particular items, and are removed. The proposed \(x_{t,S}\) formulation discards that temporal and agent-level structure and asks for a configuration-LP decomposition over bundle types. That is a legitimate new aggregate allocation problem, but the paper’s theorem neither supplies its benchmark nor implies its guarantee. In particular, the type-level APS formula is an additional limiting identity that would itself need to be proved; finite APS need not be invariant under cloning goods.

The same objection applies to the \(10/27\)-MMS clause: MMS is defined by partitioning one finite set of goods into exactly \(n\) bundles, so its continuum limit depends essentially on how copies, bundle sizes, and repeated-item valuations are defined. There is no canonical limit supplied by the paper.

This is nevertheless a weak negative case. The programme explicitly permits per-capita supplies when population continuization forces them, and large schools, housing systems, or standardized benefits are credible high-multiplicity settings. Once the multi-unit extension is stated openly, the resulting configuration-LP and pricing questions could be worthwhile in their own right. I therefore cannot honestly defend the universal claim that no valuable continuous mirror exists; the Corollary 5 anchor survives a reasonable repair, even though the proponent’s formulation is not automatic.
