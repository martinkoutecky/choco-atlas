What the mirror covers

The proposed mirror concerns aggregate analogues of Theorems 1 and 4. It leaves Theorem 6 on general coalition formation and the comparisons with matching markets without transfers aside.

Open questions for a prover

  • Which rational polytopes of feasible aggregate flows are exactly exposed optimal faces for some type-pair surplus matrix?
  • Which such faces remain rationalizable when all type-pair surpluses must be nonnegative?

The case FOR (proponent)

The paper has no numbered result establishing a complexity class such as P or NP-hardness. Its closest anchors are structural characterizations of a rationalizability problem: whether a given set of matchings is exactly the set of surplus-maximizing matchings for some assignment game. The results are proved here, but I would not present them as complexity theorems.

The strongest anchor is Theorem 1. It says that for a set \(E\) of matchings, these are equivalent: \(E\) is exactly the core matching set for some integer-valued assignment game; \(E\) is exactly the core matching set for some real-valued assignment game; and \(E\) is consistent. Consistency means that if a matching \(\nu\) gives every agent a partner—or single status—that the agent has in some matching in \(E\), then \(\nu\) itself belongs to \(E\).

A second, distinct anchor is Theorem 4. For a set \(E\), it says that these are equivalent: \(E\) is exactly the core matching set for some nonnegative integer-valued assignment game; the same holds for some nonnegative real-valued game; and \(E\) is monotone consistent. Here monotone consistency adds a case to the consistency condition: a matching also has to be included when, for each agent, either its assignment is witnessed in \(E\), or both that agent and its proposed partner are single in possibly different matchings in \(E\).

The lead mirror is Aggregate Core-Set Rationalizability\(_\infty\). An instance has buyer types \(I\), seller types \(J\), rational masses \(p_i,q_j\), and a nonempty rational polytope \(E\) of observed aggregate matching patterns, given by linear inequalities. Types are complete descriptions of the relevant traits: members of a type have the same preferences, costs, prices, budgets, and other parameters the model uses. A feasible aggregate matching is a flow \(x\) satisfying
\[ x_{ij}\geq 0,\qquad \sum_j x_{ij}\leq p_i,\qquad \sum_i x_{ij}\leq q_j. \]
The unassigned mass represents agents who remain single. Ask whether there is a surplus matrix \(\alpha\in\mathbb{Q}^{I\times J}\) such that
\[ E=\arg\max_{x\text{ feasible}}\sum_{i\in I}\sum_{j\in J}\alpha_{ij}x_{ij}. \]
A solution is such a matrix \(\alpha\). Each person still matches to at most one partner; only the aggregate flow can be fractional because a continuum of same-type people can be split across partner types.

For a nonnegative-surplus version, use the same instance and question, with the additional requirement \(\alpha_{ij}\geq 0\) for every pair of types. These mirror Theorem 4. In both versions, the intended input \(E\) is the full set of predicted aggregate core patterns, so it includes every feasible mixture of optimal flows; it is not just a list of observed outcomes that happen to be optimal.

The regime is a large repeated labor market: for example, many workers grouped by occupation and qualifications, matched to many positions grouped by employer industry and job type. There may be hundreds of thousands of people but only dozens of types on each side. Surplus depends on the two types, not on the names of the individuals. The paper’s own related-literature discussion cites work on aggregate matching frequencies across types, which supports the plausibility of the data object. That is supporting context, not evidence that this paper already uses a continuous population.

I would expect both mirrors to be Class A. In the unrestricted case, core aggregate patterns are exposed faces of the feasible flow polytope; with the stated inequality representations, recognizing a candidate face can be handled with linear programming. The nonnegative version restricts which faces can be exposed by a nonnegative surplus matrix, but remains a linear optimization question. Further questions include how the answer changes as the number of types grows, whether aggregate observations identify any surplus matrix, and when nonnegative surpluses rule out an otherwise rationalizable face. These are predictions for the mirror, not complexity results established by the paper.

The scope is the assignment game results in Theorems 1 and 4. I would not extend this case to the paper’s general coalition-formation result or its discussion of matching without transfers. The mirror keeps the paper’s central question—recovering possible surplus structure from the full set of efficient matchings—and lets population continuity induce fractional type-level flows.

The weakest point is the type-level surplus assumption. The paper allows a distinct surplus for every named pair; the mirror assumes those values are shared by members of the same types. That is sensible in markets where outcomes depend on observable worker and job characteristics, but less so when named individuals have important idiosyncratic complementarities. There is a second limit: since the paper proves no discrete hardness result, this mirror cannot yet claim that population continuity dissolves a known discrete hardness barrier. It is a credible continuous research question anchored in the paper’s main theorems, but not a continuation of a complexity result the authors established.

The case AGAINST (opponent, writing after the proponent)

The strongest case against both anchors is that the paper proves structural characterizations, not computational results. Theorem 1 characterizes which sets of individual matchings can be rationalized by some surplus matrix; Theorem 4 adds nonnegative surpluses. Neither states a complexity bound, gives an algorithm, or specifies a computational input. To turn either theorem into a complexity problem, one must choose how the set of matchings is encoded and whether the task is to rationalize the full optimal set or only observed outcomes. Those choices supply the computational problem; the paper does not.

The proposed aggregate mirror makes that gap especially visible. With type supplies fixed, its input is a polytope \(E\) of aggregate outcomes, and the question is whether \(E\) is the optimal face of a type-level assignment problem. That is a coherent inverse-matching question, but its encoding and complexity come from the chosen representation of \(E\), not from a computational result in Theorem 1. If \(E\) is instead a finite list of observed flows, asking whether some surplus matrix rationalizes those observations changes the object: it is partial-data rationalization, not the theorem’s characterization of the *entire* core set. Theorem 4 has the same gap. Requiring nonnegative type-pair surpluses restricts which faces can be supported, but does not add a computational anchor in the paper.

That is the limit of the negative case. The type-level mirror itself is sensible: repeated workers and positions with shared characteristics give a plausible high-multiplicity regime, and the paper’s discussion of aggregate matching is supporting context. Treating type-level surpluses as a modeling restriction would not defeat it, and neither would the fact that its answer might be tractable. So I cannot honestly rule out a worthwhile continuous project. The case against is that these would be new algorithmic rationalization problems built from Theorems 1 and 4, rather than continuizations of computational results the paper actually establishes.
