The continuous mirror question

Given rational type masses \(\mu_t>0\) summing to \(1\), and a rational piecewise-affine worth function \(W\) on \(Q=\{q:0\le q_t\le\mu_t\}\) with \(W(0)=0\), consider an atomless population partitioned into type classes of masses \(\mu_t\). A measurable coalition \(A\) has worth \(W(q(A))\), where \(q_t(A)\) is its mass of type \(t\). Assume the core is nonempty. Is the core stable: does every imputation \(p\ge0\) almost everywhere with total payoff \(W(\mu)\), but outside the core, admit a core allocation \(x\) and a positive-mass measurable coalition \(A\) such that \(x>p\) almost everywhere on \(A\) and \(\int_A x\le W(q(A))\)?

The model it lives in

An atomless transferable-utility game with finitely many agent types carrying masses \(\mu_t\), coalition worth determined by a rational piecewise-affine function \(W(q)\) of coalition type masses, and integrable payoff functions as allocations. The decision problem is whether every imputation outside the core is dominated by a core allocation through a positive-mass coalition.

The objection that survived

The opponent's best surviving point is that arbitrary within-type payoffs let coalitions select lower-paid members, and the paper proves no reduction from grid-restricted finite games to this atomless model; this limits the high-multiplicity transfer but does not erase the recognizable stable-core question.

What the mirror covers

The mirror covers stable-core existence and external stability, the subject of Corollary 7.2 and Theorem 7.1; it leaves the properties of the maximal-outvoting set and the results on super-stability and vital extendability aside.

Open questions for a prover

  • Does stable-core existence in this model admit a finite certificate or decision procedure with size controlled by the number of types, the number of affine cells, and the input bit length?
  • Is testing stable-core existence tractable for fixed numbers of types, or under useful restrictions on \(W\)?
  • Can arbitrary within-type payoff functions be reduced to type-level data without changing which imputations are blocked?

The case FOR (proponent)

The strongest anchor is Corollary 7.2, proved in this paper from Theorem 7.1. The paper has no named NP-hardness, polynomial-time, or parameterized-complexity result. Its computational contribution is a finite necessary-and-sufficient test for core stability; the authors do not claim that the test is efficient, and their discussion says efficient procedures remain future work.

Corollary 7.2 says that a balanced finite TU game \((N,v)\) has a stable core exactly when the following finite condition holds. Choose \(F\) so that \(VE_{\mathrm{strict}}(v)\subseteq F\subseteq E(v)\) and \(C(v)=\{x\in X(v):x(S)\ge v(S)\ \forall S\in F\}\). For every nonempty collection \(\mathcal S\subseteq F\), and every admissible choice of an associated minimal balanced collection \(B_S\) for each \(S\in\mathcal S\), construct a finite set \(Z\) of vectors and coefficients \(a_z\). Here \(Z\) contains the indicators of \(N\setminus S\) for \(S\in\mathcal S\), the indicators of \(T\in F\setminus\mathcal S\), and vectors \(z^S\) whose \(i\)-th coordinate is the balancing weight of singleton \(\{i\}\) in \(B_S\), when that singleton occurs. Each \(a_z\) is the maximum of the applicable values: \(v(N)-v(S)\) for \(z=\mathbf1_{N\setminus S}\); \(v(T)\) for \(z=\mathbf1_T\), \(T\in F\setminus\mathcal S\); and \(v(N)-\sum_{T\in B_S\setminus\{\{i\}:i\in S\}}\lambda_T^{B_S}v^S(T)\) for \(z=z^S\), where \(v^S\) changes \(v\) only by setting \(v^S(N\setminus S)=v(N)-v(S)\). An associated \(B_S\) contains some singleton \(\{i\}\) with \(i\in S\), and its members are among those singletons, \(N\setminus S\), and coalitions of \(F\) not contained in \(S\); admissibility excludes the cases automatically covered by condition (6.9).

Now take every minimal balanced subset \(Z'\) of \(Z\), with balancing weights \(\delta^{Z'}_z\). Let \(B_0\) be the minimal balanced subsets containing a vector \(\mathbf1_{N\setminus S}\) whose coefficient is exactly \(v(N)-v(S)\). For every choice above, the test requires either some \(Z'\notin B_0\) with \(\sum_{z\in Z'}\delta^{Z'}_z a_z>v(N)\), or some \(Z'\in B_0\) with \(\sum_{z\in Z'}\delta^{Z'}_z a_z\ge v(N)\). The corollary asserts that these tests, over finitely many choices, are equivalent to stable-core existence. This is a real computational foothold, but it is a finite characterization, not a polynomial-time bound.

My lead mirror would be Atomless Finite-Type TU Core-Stability. An instance gives rational type masses \(\mu_t>0\), summing to \(1\), and a nonnegative continuous rational piecewise-affine worth function \(W\) on \(Q=\{q:0\le q_t\le\mu_t\}\). The input specifies \(W\) by a finite rational polyhedral subdivision of \(Q\) and an affine formula on each cell. There is an atomless population \(\Omega\), partitioned into type classes \(\Omega_t\) of mass \(\mu_t\). A coalition is any measurable \(A\subseteq\Omega\); its type-mass vector is \(q_t(A)=\operatorname{mass}(A\cap\Omega_t)\), and its worth is \(W(q(A))\). An allocation is an integrable payoff function \(p:\Omega\to\mathbb R\). An imputation has \(p\ge0\) almost everywhere and \(\int_\Omega p=W(\mu)\); zero is the individual reservation value because a single agent has zero mass. It is in the core if \(\int_A p\ge W(q(A))\) for every measurable coalition \(A\).

The question is: does this game have a stable core? That means every imputation outside the core is dominated by some core allocation: for some measurable \(A\), the core payoff is strictly greater than the imputation almost everywhere on \(A\), while its total payoff to \(A\) is at most \(W(q(A))\). The instance can promise a nonempty core, as Corollary 7.2 does by considering balanced games. A prover’s answer is yes or no, with a no instance witnessing an imputation that no core allocation dominates. The complexity parameters are the number of types \(\tau\), the number of polyhedral cells \(K\), and the rational input bit length \(L\).

A plausible regime is a large cooperative production economy: many workers or firms, but only a modest number of complete operational types, such as credential, productivity, and outside-option classes. The worth of a coalition depends on the masses of types it assembles. With \(n\) discrete participants, type \(t\) has \(n_t\) members and mass \(n_t/n\); the discrete coalitions occupy the grid of attainable mass vectors, while the continuum game admits every vector in \(Q\). That is the high-multiplicity bridge. This is a continuous-population version of the paper’s question about external stability of the TU core; the divisible coalition masses are the co-modification needed to make a population limit meaningful.

I would provisionally expect this problem to be continuum-specifically hard (Class C), though that is a research conjecture, not a consequence of the paper. Corollary 7.2’s finite proof organizes exact coalitions and minimal balanced collections in \(2^N\). Here there are continuously many possible coalition masses, and stability still has nested quantification over allocations and blocking coalitions. A rational piecewise-affine worth function may let optimization reduce some of these quantifiers to finitely many polyhedral cases, but the corollary does not establish that it does so efficiently. I would ask whether an exact finite certificate exists with size bounded in \(\tau,K,L\), whether fixed \(\tau\) is tractable, and which restrictions on \(W\) make separation or core-stability testing efficient.

The scope is just this stable-core characterization and the corresponding decision problem. I would not use the paper’s results about the maximal-outvoting set as separate anchors, or stretch the mirror to cover super-stability.

The soft spot is that the paper’s theorem is built for a finite set of agents and finitely many coalitions. The mirror introduces measurable coalitions and payoff functions, so its main technical challenge is not settled by replacing counts with masses. It is still a credible mirror because the underlying question—whether every imputation outside the core can be blocked by a core allocation—is exactly the authors’ problem. The paper’s finite test makes the continuous question sharper: does nested balancedness have an effective analogue when coalitions range over a polyhedral continuum?

The case AGAINST (opponent, writing after the proponent)

The only anchor the proponent raises is Corollary 7.2, and the best objection is that it is not a complexity result. It gives a finite characterization of stable-core existence, but no running-time bound or efficient algorithm. The paper says the test settles a long-standing question, then leaves efficient procedures for future work. So the proposed mirror—deciding stable-core existence for piecewise-affine atomless TU games—would open a new computational problem. It would not extend a complexity result established here.

The specific model also has a defect: as stated, a null coalition satisfies “strictly better almost everywhere” vacuously, so it can dominate any imputation at zero cost. Requiring a positive-mass coalition fixes that. But the repaired model still has an unresolved aggregation problem. The worth function depends only on type masses, while arbitrary allocations can vary among people of the same type; a coalition can select the lower-paid members. Replacing each type’s payoffs by a type average may therefore change which imputations are blocked. Keeping arbitrary payoff functions preserves the intended question, but makes the central stability test infinite-dimensional. The paper’s finite balancedness criterion does not supply a reduction for it.

The high-multiplicity bridge would need more than normalizing finite worths and taking a limit. One must specify how the finite coalition-value tables \(v_n(S)\) generate \(W(q)\), and show that the stable-core property survives that passage. The paper’s test depends on strict inequalities and exact coalitions; the authors themselves leave open whether core stability is closed under limits. That makes a faithful transfer especially uncertain. A production economy with a chosen polyhedral worth function is a plausible cooperative-game model, but it is an added model class, not a limit construction supplied by this paper.

These points make the proponent’s particular mirror weaker than it first appears, but they do not establish the universal negative the task asks for. A positive-mass, anonymous TU model still poses the authors’ recognizable stable-core question, and its algorithmic complexity could be worth studying. The honest negative case is therefore limited: Corollary 7.2 is a thin anchor for ChoCo’s complexity programme, but I cannot rule out a worthwhile continuous mirror in every scenario.
