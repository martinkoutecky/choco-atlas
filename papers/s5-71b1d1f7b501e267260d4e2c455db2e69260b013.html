The case FOR (proponent)

The strongest honest positive case is a natural high-multiplicity version of the paper’s allocation problem. But there is an important limitation: the paper has no numbered result asserting a computational complexity classification such as tractability or hardness. The closest named result is Proposition 1, the MRS condition, proved in the paper: an allocation \(x\) maximizes \(\sum_i f(\pi_i(x))\) over \(\Delta_m\) exactly when \(mc_j^\uparrow(x)\le mc_k^\downarrow(x)\) for every pair \(j,k\). That characterizes the optimum, but does not give a runtime bound. Section 3.1 does say that CTRs can be computed efficiently by convex optimization, but this claim is unnumbered. The numbered welfare and fairness bounds, including Theorems 7, 9, and 12, are analytical guarantees rather than computational results. So there is no qualifying named anchor; Proposition 1 and the unnumbered computation claim are only the nearest basis for a mirror.

The candidate mirror is High-Multiplicity Continuous Thiele Optimization. There are \(m\) public budget categories and \(\tau\) ideal budget distributions \(q^t\in\Delta_m\), each with positive binary-rational mass \(\mu_t\), where \(\sum_t\mu_t=1\). A type is a resident’s ideal distribution over those categories; agents with the same ideal distribution share a type. Given a fixed Thiele function \(f\), choose a common allocation \(x\in\Delta_m\) maximizing
\[ \Phi_\mu(x)=\sum_{t=1}^{\tau}\mu_t f\!\left(\sum_{j=1}^{m}\min(q^t_j,x_j)\right). \]
For a concrete computational problem, fix \(f(u)=u-u^2/2\), and ask for a rational \(x\) whose objective value is within additive \(\varepsilon\) of the maximum. The input is the supported type distributions and their masses, with \(\varepsilon>0\) given as a binary rational.

A plausible regime is a large city deciding how to divide a public budget among services. Many residents may share one of a relatively small number of standard ideal budget profiles, so the population is large while \(\tau\) is moderate. The action remains the shared public allocation, and each type’s satisfaction is exactly the paper’s overlap utility. The population, rather than the outcome space, is what has been replaced: the paper already has continuous allocations, but its agents are still indexed individually by \([n]\).

This is a close match to the authors’ underlying problem. The objective is their CTR objective with identical agents grouped and weighted by mass. For a finite profile with \(n_t\) people of type \(t\), setting \(\mu_t=n_t/n\) gives the same maximizers as the finite objective, since it differs only by the factor \(1/n\). The general mirror therefore has a direct high-multiplicity interpretation, and it does not depend on an artificial population story.

I would expect this optimization problem to be tractable, in Class A, by convex optimization; for the fixed polynomial \(f\) above, an additive-\(\varepsilon\) solution should be obtainable in time polynomial in \(m,\tau\), the input bit length, and \(\log(1/\varepsilon)\). It also raises natural follow-up questions: whether the result holds for the paper’s full class of efficiently represented \(f\), whether exact optimization has the same guarantee, and how sensitive the chosen allocation is to small changes in type masses.

The weakest point is substantial: the paper does not supply a qualifying numbered computational anchor, and its unnumbered convex-optimization claim already makes the finite-profile problem tractable. The mirror would clarify how runtime can depend on support size rather than population size, but it would not show discrete hardness dissolving in the continuum. The positive case is that the high-multiplicity problem itself is a sensible, faithful extension of the authors’ central optimization question—not that this paper establishes a new complexity result about it.

The case AGAINST (opponent, writing after the proponent)

The strongest defensible case against is that this paper supplies no named computational result to mirror. Proposition 1 is an optimality characterization through marginal contributions; Theorems 7, 9, and 12 give welfare and fairness bounds. None states a complexity classification or an algorithmic guarantee. Section 3.1 says CTRs can be computed by convex optimization, but that claim is unnumbered and does not specify an input encoding or a runtime in \(m,\tau,L\). Theorem 7, Theorem 9, and Theorem 12 could have continuous-population analogues, but those would still be analytical guarantees, outside ChoCo’s computational scope.

The best version of the proposed mirror is plainly coherent: a city has a finite library of ideal budget distributions \(q^t\), residents of each type have mass \(\mu_t\), and the planner maximizes \(\sum_t\mu_t f(\sum_j\min(q^t_j,x_j))\). For rational masses, a common denominator turns this into a finite profile with repeated voters, and the objective differs from the paper’s only by scaling. That is a sensible high-multiplicity regime, so the negative case cannot rest on implausible types or a broken model.

The red case is narrower: this weighted optimization problem is a new computational formulation of the paper’s central rule, rather than a continuous mirror of a named computational result. Fixing \(f\) and specifying an approximation task makes the formulation precise, but it does not supply the missing anchor. Extending the analytical theorems to masses would not fix that gap.

This is a real limitation of the proponent’s case, not a decisive argument that no worthwhile mirror exists. The paper’s central optimization question could still be worth studying with running time measured in support size rather than population size. Given the programme’s explicit interest in high multiplicity, I cannot honestly claim that every plausible mirror fails; the strongest negative verdict is that this paper offers no qualifying computational result to anchor one.
