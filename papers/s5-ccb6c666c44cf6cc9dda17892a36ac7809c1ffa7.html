The case FOR (proponent)

The supplied paper has no qualifying named computational-result anchor. It is a commentary on Bronfman et al.’s redesign, and contains no numbered theorem, lemma, corollary, or proposition asserting a complexity or algorithmic result. The Birkhoff–von Neumann theorem is named, but it is an external mathematical tool cited in the paper, not a computational result proved there. The reported efficiency gains are prose claims, not eligible anchors.

The strongest plausible mirror I can offer is therefore unanchored: *RSD-Dominating Rank Improvement for a Continuum Internship Market*. In a national internship clearinghouse, take a large cohort of \(N\) interns, a fixed set \(H\) of hospitals, and a relatively small support \(T\) of recurring complete preference rankings, so \(N\gg |T|\). A type \(t\in T\) has mass \(\mu_t\), and hospital \(h\) has per-capita capacity \(\kappa_h\), with both distributions summing to \(1\). This is a plausible regime, though the paper gives no evidence that actual rankings have small support.

Include in the instance the RSD baseline probabilities \(\rho_{t,h}\): the probability that an intern of type \(t\) receives hospital \(h\). The question is whether there is a mass allocation \(x_{t,h}\geq 0\) such that
\[ \sum_h x_{t,h}=\mu_t,\qquad \sum_t x_{t,h}=\kappa_h, \]
and, for every type \(t\) and rank prefix \(k\),
\[ \sum_{h\in \mathrm{Top}_t(k)}x_{t,h} \geq \mu_t\sum_{h\in \mathrm{Top}_t(k)}\rho_{t,h}, \]
with a strict inequality for at least one \((t,k)\). A solution is the allocation \(x\): each unit of intern mass still receives one hospital, while type-level averages represent the assignment probabilities. Given the baseline table, this is a linear feasibility question, so I expect this mirror to be tractable. Further questions include how to compute the continuum RSD baseline from \((\mu,\kappa)\), and how well solutions map back to finite cohorts.

This is a credible population mirror because the paper’s central operation is to trade interns’ assignment probabilities while respecting per-intern rank improvements; scaling hospital capacities with the cohort is a natural co-modification. The authors could plausibly recognize it as a continuum version of the problem they discuss. The main weakness is also substantial: the paper does not establish that its preference profiles have \(N\gg |T|\), and the probability-trading structure already exists in finite markets. Most importantly, since there are no eligible anchors, this candidate cannot be presented as mirroring a numbered computational result of this paper.

The case AGAINST (opponent, writing after the proponent)

There is no eligible result here to mirror. This is a commentary on a redesign, not a paper that states a computational problem and proves an algorithm or complexity bound. The Birkhoff–von Neumann theorem is a cited tool; the efficiency gains are reported in prose. That leaves the proponent’s candidate unanchored.

Their strongest candidate is coherent, but once the RSD table \(\rho\) is supplied, it asks whether a fractional assignment can satisfy linear rank-prefix constraints. One can test strict improvement by maximizing the sum of the prefix gains. The resulting LP has \(O(\tau |H|)\) variables and constraints polynomial in the input size. More fundamentally, for rational \(\mu\) and \(\kappa\), scaling by a common denominator gives integer counts of interns and positions; dividing the assignment variables by type mass gives the same per-intern lottery probabilities. The probability-trading layer already has a fractional assignment representation. The proposed mirror therefore adds little computational structure, and says nothing about the cost of generating the RSD baseline that it takes as input.

A more complete version would compute the continuum RSD baseline from \((\mu,\kappa)\) and then find a rank-improving assignment. That is closer to the redesign’s operation, but it is a new computational question: this commentary neither formulates it nor reports an algorithmic result about it. It could be worth studying, so I cannot honestly rule out every worthwhile mirror. The negative case is strongest for the paper as supplied: it has no named computational result to anchor, and the proposed LP looks more like a repackaging of its fractional assignment layer than a substantial continuization problem.
