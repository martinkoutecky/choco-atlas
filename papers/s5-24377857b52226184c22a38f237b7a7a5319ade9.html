The continuous mirror question

Given supported complete utility types \(t\) with masses \(\mu_t\), item classes \(j\in[K]\), integer per-household bundle caps \(b_j\), rational per-capita supplies \(q_j\le b_j\), and additive values \(v_{tj}\) satisfying \(\sum_j b_jv_{tj}=c\) for every type, does there exist a mass assignment \(x_{t,y}\ge0\) over integral bundles \(y\in\prod_j\{0,\ldots,b_j\}\) such that \(\sum_y x_{t,y}=\mu_t\), \(\sum_{t,y}x_{t,y}y_j=q_j\), and every ordered pair of positive-mass outcomes \((t,y),(s,z)\) satisfies the paper’s JF1 test? Writing \(U_t(y)=\sum_jv_{tj}y_j\), whenever \(U_t(y)<U_s(z)\), require either some \(j\) with \(y_j>0\), \(v_{tj}<0\), and \(U_t(y)\ge U_s(z+e_j)\), or some \(j\) with \(z_j>0\), \(v_{sj}>0\), and \(U_t(y)\ge U_s(z-e_j)\), where \(e_j\) is one unit of class \(j\) and the comparison uses the additive utility of the hypothetically changed bundle.

The model it lives in

A distribution over complete household utility types assigns mass to integral bundle configurations. Per-capita item supplies constrain aggregate mass, while pairwise JF1 comparisons retain the paper’s one-item fairness test.

What the mirror covers

Covers Theorem 1’s JF1 existence decision for normalized additive mixed-manna utilities in a population-scaled item-class regime; leaves the paper’s other existence, compatibility, and envy-freeness results aside.

Open questions for a prover

  • Does this mass-splittable JF1 feasibility problem remain NP-hard, or can it be solved efficiently, for example through a configuration LP with tractable pricing?

The case FOR (proponent)

My lead is a continuous version of the paper’s POSSIBLEJF1 problem. Imagine a large food bank serving many households, with standardized item slots supplied in proportion to the population. Households share a relatively small set of complete utility types: a type specifies the same additive value for every item slot, including which items its members like and dislike. Thus the population is a distribution \(\mu\) over types, with \(\tau\) supported types and \(\mu_t\) the fraction of households of type \(t\). The intended regime has many households and \(\tau\) far smaller than their number.

Here is a precise problem for that regime. The input gives finitely many item classes \(j\in[K]\), a per-household capacity \(b_j\) for each class, rational per-capita supplies \(q_j\le b_j\), and rational additive utilities \(v_{tj}\) for each supported type \(t\). Require normalization: \(\sum_j b_jv_{tj}=c\) for the same rational \(c\) for every type. A household’s bundle is still integral, \(y\in\prod_j\{0,\ldots,b_j\}\), with utility \(v_t(y)=\sum_jv_{tj}y_j\). The capacities describe such things as having only a fixed number of slots for each food category; the supplies scale with population, as the programme permits.

The question, Possible-JF1\(_\infty\), is whether there are nonnegative masses \(x_{t,y}\) such that
\[ \sum_y x_{t,y}=\mu_t,\qquad \sum_{t,y}x_{t,y}y_j=q_j\quad\text{for each }j, \]
and every pair of type-bundle outcomes occurring with positive mass satisfies the paper’s JF1 condition. Explicitly, for each supported pair \((t,y),(s,z)\), either \(v_t(y)\ge v_s(z)\), or one item can be moved from the first bundle to the second so that the second household’s utility falls to at most \(v_t(y)\), or a positively valued item can be removed from the second bundle with the same effect. A solution is the mass assignment \(x\): each household receives an integral bundle, while masses of households can be split among bundles. This preserves the indivisibility and the one-item fairness question for individuals while making the society and its supply continuous.

The anchor is Theorem 1, proved in this paper. It states that, for fair division of mixed manna with normalized additive utilities, deciding POSSIBLEJF1—whether there exists a JF1 allocation—is NP-hard. The paper proves this by a polynomial-time reduction from X3C. That is a strong anchor for this mirror: the continuous question asks whether a JF1 allocation exists, not whether some different fairness objective is achievable. The authors should recognize it as their problem in a population-scaled inventory regime, though the scaled supplies and type-level representation are necessary co-modifications.

I would tentatively expect this mirror to be Class C, continuum-specifically hard. The reduction’s X3C structure lives in item and utility-profile choices, which may survive as a combinatorial choice of integral bundle outcomes. But divisible type masses can split assignments that were indivisible in the reduction, so Theorem 1 by itself does not establish hardness transfer. That gap is the real question: can one give a continuous reduction that controls mass splitting, or can the mass formulation be solved through a configuration LP and an efficient pricing procedure? Further useful questions are whether tractability emerges for bounded \(\tau\), and whether continuous feasibility yields an approximate discrete JF1 allocation in a large finite instance.

The weakest point is the bridge from the paper’s finite inventory to population-scaled supplies. Replication is natural for recurring food-bank distributions, and the programme explicitly allows per-capita supply as a co-modification, but this is a restricted fair-division regime with item classes and capacities rather than the paper’s exact finite-item input. If the authors or a referee reject that inventory regime as no longer their question, this anchor does not support the mirror.

The case AGAINST (opponent, writing after the proponent)

The strongest case against this anchor is that Theorem 1 does not establish hardness for the proposed continuous problem. Its reduction gives each named agent a role in an X3C construction. In a mass assignment, members of one type can be split across bundles, and scaling the inventory replaces one-off items with repeated item classes. So the paper’s reduction cannot simply be carried over. The mirror should also state the paper’s JF1 test exactly: when one agent is jealous, a bad from their bundle must be transferred or a good removed from the other bundle, with the specified utility inequality.

That is a limitation on what the theorem tells us, not a reason the continuous question is unworthy. A stronger, repaired version is quite plausible: a recurring food bank has standardized item classes, supplies that scale with the population, and households drawn from a finite set of complete utility types. Each household still receives an integral bundle, and JF1 still concerns individual households. The mass distribution only describes how many households of each type receive each bundle. This fits the programme’s allowance for per-capita supplies and avoids the usual objections about identity, multiplicity, or a vanishing one-item concession.

So I cannot honestly defeat the anchor. Theorem 1 is a named computational result, and the repaired mirror is a coherent population-continuous question. The negative case is weak: the mirror changes the resource regime, and the paper’s hardness proof gives no answer for it. But whether mass splitting makes the problem easier is itself part of the computational question, not a sound objection to asking it.
