The continuous mirror question

Given a feasible configuration set \(\mathcal Y\), bounded features \(\phi\), and a finite support \(\mathcal T\) of user types with rational masses \(\mu_r\), let type \(r\) have utility \(u_r(y)=\langle w_r^*,\phi(y)\rangle\). In each round \(q\), choose one shared configuration \(y_q\) maximizing the current estimate of \(U_\mu(y)=\sum_{r\in\mathcal T}\mu_r u_r(y)\), and receive an \(\alpha\)-informative improvement \(\bar y_{rq}\) from a representative of every type, relative to that type’s own best feasible configuration. For type-block estimates updated from each \((y_q,\bar y_{rq})\), does average regret against the best shared configuration admit a bound such as \(\frac{2R\|\Theta^*\|}{\alpha\sqrt Q}+\frac{1}{\alpha Q}\sum_{q=1}^{Q}\sum_{r\in\mathcal T}\mu_r\xi_{rq}\), where \(\Theta^*=(\sqrt{\mu_r}w_r^*)_{r\in\mathcal T}\), or what bound is attainable under these feedback assumptions?

The model it lives in

A multi-user constructive configuration problem: types \(r\) carry population mass \(\mu_r\), each has a utility model \(w_r\), and the system chooses one feasible configuration to maximize estimated average utility. The algorithm maintains type-specific estimates, receives type-specific improvement feedback, and measures regret against the best shared configuration under \(U_\mu(y)=\sum_r\mu_r\langle w_r^*,\phi(y)\rangle\).

The objection that survived

The paper studies one decision maker, and its stated mass-weighted aggregate update has cross terms that do not justify the proposed bound; a type-block update still needs an alignment argument for the common recommendation.

fatal: False

What the mirror covers

The mirror adapts Theorem 1’s coactive regret guarantee and could similarly extend Theorem 2’s feature-critique guarantee; it does not cover the article’s MILP formulations, empirical comparisons, or other framework discussion.

Open questions for a prover

  • Under typewise \(\alpha\)-informative feedback, what update rule guarantees shrinking regret against the best shared configuration, and how should its bound depend on \(\tau\) and the type models?
  • Can sampled feedback from only some types per round preserve a comparable guarantee?

The case FOR (proponent)

This paper has no numbered theorem classifying a problem as in \(P\), NP-hard, FPT, or similar. Its named computational anchors are Theorem 1 and Theorem 2, which give regret bounds for learning algorithms. I’ll use them as anchors for a continuous-population learning mirror, without treating them as complexity classifications.

The lead is Theorem 1 (Preference Perceptron). The paper attributes it to Shivaswamy and Joachims (2015), rather than proving it there: for an \(\alpha\)-informative user with preference vector \(w^*\) and bounded features \(\|\phi(y)\|\le R\), the Preference Perceptron’s average regret after \(T\) rounds is at most \(2R\|w^*\|/(\alpha\sqrt{T}) + \sum_{q=1}^{T}\xi_q/(\alpha T)\).

A continuous mirror is Population Coactive Configuration Elicitation. Its instance has a shared feasible set of configurations \(\mathcal Y\), represented by constraints over discrete or mixed variables, a bounded feature map \(\phi\), and a finite support \(\mathcal T\) of user types with rational masses \(\mu_r\) summing to one. Type \(r\) has an unknown utility vector \(w_r^*\); its per-person utility is \(u_r(y)=\langle w_r^*,\phi(y)\rangle\). The society’s objective is to choose one common configuration maximizing average utility, \(U_\mu(y)=\sum_{r\in\mathcal T}\mu_r u_r(y)\). At each round, the system proposes a configuration and receives an improved configuration from a representative of each type. Each response is assumed to satisfy the paper’s \(\alpha\)-informativeness condition relative to that type’s own best feasible configuration, with slack \(\xi_{rq}\). The mass-weighted feature differences update the aggregate estimate; the output is a sequence of common recommendations and a final configuration.

The question for a prover is whether this online procedure achieves a population average-regret bound such as \(2R\|W^*\|/(\alpha\sqrt{Q}) + \sum_{q=1}^{Q}\sum_r\mu_r\xi_{rq}/(\alpha Q)\), where \(W^*=\sum_r\mu_r w_r^*\). This is a proposed population extension, not a theorem in the paper. The typewise feedback is what makes the extension plausible: its mass-weighted utility gain is at least the weighted sum of typewise regrets, which in turn dominates the regret against the best single configuration for the whole society.

A plausible regime is a large organization choosing a shared office layout: many employees, but relatively few complete preference profiles over features such as desk arrangement, accessibility, and shared facilities. The type is the full preference and feedback profile relevant to this decision, and \(\mu_r\) is the fraction of employees with that profile. For example, a few tens of thousands of employees might have only dozens of such types. The mass is a population fraction; the layout and its feature space remain combinatorial. This is not a claim that an individual’s preferences become fractional.

I’d expect a shrinking-regret result if the aggregate recommendation step can be optimized efficiently. In ChoCo terms, that is Class A-like only in configuration domains with a tractable inference or pricing oracle. The paper says its general MILP formulations can be NP-hard, so Theorem 1 does not establish polynomial time for arbitrary configuration problems. Further questions include the dependence on support size \(\tau\) and mass bit length, and whether a random sample of types per round can replace feedback from every type while preserving the bound.

A second, narrower anchor is Theorem 2 (Critiquing Preference Perceptron). The paper gives the bound but points to Teso et al. (2017a) for its proof: for an \(\alpha\)-informative user with true weights \(w^*\), bounded true features \(\|\phi^*(y)\|\le R\), and missing-feature discrepancy \(\zeta_q\), average regret is at most \(2R\|w^*\|/(\alpha\sqrt{T}) + \sum_{q=1}^{T}(\xi_q+\zeta_q)/(\alpha T)\).

Its mirror is Population Coactive Critiquing: keep the same population and shared-configuration objective, but allow each type to have its own initially incomplete feature map. When a type’s improvement cannot be explained by its current map, ask that type for a critique and add the identified feature to its type-specific model. The task is to produce common recommendations and feature-acquisition queries whose population regret obeys the corresponding weighted bound, with the slack and missing-feature terms \(\sum_r\mu_r(\xi_{rq}+\zeta_{rq})\). This is also a proposed extension, not a result claimed by the paper. It asks for tractability conditional on aggregate inference; it does not resolve the complexity of the underlying configuration optimization. It also raises the question of how many critiques are needed as a function of \(\tau\) and the types’ feature sets.

The high-multiplicity interpretation is sensible here: the paper is about constructing configurations from preference feedback, and the article itself points to multi-user preference propagation as a direction with prior work. But the soft spot is substantial. The paper’s theorems concern one decision maker, whereas these mirrors introduce a population objective and require type-specific feedback. The shared-configuration objective is a credible group version of their problem, not a result their paper already establishes. These mirrors cover the preference-learning and recommendation guarantees only; they do not mirror the whole article or supply a discrete hardness result whose hardness might dissolve in a continuum.

The case AGAINST (opponent, writing after the proponent)

The strongest negative case is that both anchors study one decision maker’s learning process, rather than a computational problem whose input is a society. The paper has no finite population of agents whose multiplicities could be replaced by masses. A population version therefore needs a new problem definition: either each person gets an individual recommendation, in which case the population mass loses who receives which configuration, or everyone gets one shared configuration, in which case the model needs a social objective absent from the paper.

The proposed mirror of Theorem 1 also needs a technical repair. Updating a single estimate \(W^*=\sum_r\mu_r w_r^*\) with mass-weighted responses does not make its inner product equal the population’s utility gain: the update introduces cross terms between different types’ weights and responses. A sounder version could keep a parameter block for each type, with \(\Theta^*=(\sqrt{\mu_r}w_r^*)_r\) and \(\Phi(y)=(\sqrt{\mu_r}\phi(y))_r\). Typewise improvements then give an update whose inner product with \(\Theta^*\) equals their mass-weighted utility gain. The resulting regret argument appears to be a direct extension of the existing perceptron analysis. Its recommendation step still uses the same configuration optimization oracle, so it opens no new pricing or complexity question for the continuous-population programme. It also requires feedback from every type each round; replacing that with a sample would require a different feedback model and analysis.

Theorem 2 has the same mismatch. Type-specific critiques can be represented in separate feature blocks, and their missing-feature terms can be mass-weighted. That is a plausible population learning extension, but its core remains feature acquisition from representatives and the same inference problem over configurations. If the aim is to preserve the paper’s single-user task, there is no population to continuize. If the aim is a common group recommendation, the new question concerns how to aggregate people’s preferences and critiques. The paper does not supply that objective.

A shared office layout is the strongest scenario for the proponent: many employees could share preference profiles, and the organization could choose one layout. But it makes the change in problem especially clear. The target is now a group decision under an aggregation rule. That may be sensible work, and the paper’s cited multi-user preference-elicitation line supports the plausibility of such a setting. I would not count that prior work against a mirror; it makes the scenario more credible. It still does not turn either theorem into a high-multiplicity version of the single-DM problem studied here.

So the case against is limited. A population regret theorem for group configuration elicitation may be worthwhile on its own, and a shared-workplace example gives it a plausible home. The harder case is that it does not appear to answer ChoCo’s characteristic question: how the computational landscape changes when a society is represented by masses over types. The mirrors either retain one user and have no population axis, or introduce a group objective whose regret guarantee seems to follow from a modest extension of the existing learning analysis.
