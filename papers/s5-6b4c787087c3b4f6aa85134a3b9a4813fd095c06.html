Why no mirror

What the mirror covers

The proposed model draws on Theorem 2's fixed-tax assignment setting, but no computational result is covered; its strategy-proofness, consistency, and anonymity claims remain finite-economy mechanism properties.

The case FOR (proponent)

The strongest plausible setting is a large permanent home-swap market. Let a type specify both a homeowner’s house category and their valuations over a small set of house categories. In a large platform, many homeowners could share each complete type, so the number of people \(n\) could be much larger than the number of types \(\tau\). Treat houses within a category as interchangeable. That preserves the paper’s exchange question while making its high-multiplicity regime concrete.

A corresponding problem would be Rational-Mass Fixed-Tax Core Assignment. Its input is finite sets of agent types \(T\) and house categories \(H\), rational type masses \(\mu_t\) summing to \(1\), each type’s endowment category \(e(t)\), valuations \(v_t(h)\), and a fixed tax \(\alpha\). Category \(h\) has supply \(q_h=\sum_{t:e(t)=h}\mu_t\). The requested solution is a rational matrix \(x_{t,h}\geq 0\) with
\[ \sum_{h\in H}x_{t,h}=\mu_t,\qquad \sum_{t\in T}x_{t,h}=q_h. \]
Each unit of mass gets one whole house category; \(x_{t,h}\) records how much of type \(t\) gets category \(h\). An agent of type \(t\) pays zero for their endowment category and \(\alpha\) otherwise, for utility \(U_t(h)=v_t(h)-\alpha\mathbf{1}[h\ne e(t)]\). Require that no coalition of positive mass can reassign its members among the houses they own so every participant weakly gains and a positive mass strictly gains.

The closest named anchor is Theorem 2, proved in this paper using properties of the HPO algorithms from Saban and Sethuraman. It says that for any \(\alpha\geq0\) and any HPO assignment rule \(f\), the rule that assigns \(f(R(u,\alpha))\), charges zero to agents keeping their endowments, and charges \(\alpha\) to everyone else satisfies individual rationality, strategy-proofness, constrained efficiency, weak consistency, and weak anonymity. On strict induced preferences, the paper’s fixed-tax rule uses the unique core assignment found by top trading cycles. The mass problem above targets that strict-preference assignment component.

I would expect the mass assignment problem to be Class A, as a working conjecture: finite types and categories suggest an algorithm based on cycles or flows. The real test is whether it runs in time polynomial in \(|T|,|H|\), and the rational input bit length \(L\), without expanding the population to the denominator of the masses. Further questions are whether there is an exact finite-replica-to-mass dictionary and how to extend the computation to the paper’s indifference cases and HPO tie-breaking.

The weak point is substantial: the paper does not analyze that computational question. Its named results are axiomatic characterizations and existence theorems. Theorem 2 gives a constructive mechanism, but does not claim that a problem is in P or give a complexity bound; the paper’s TTC algorithm statement is not a numbered theorem. So this is a plausible continuous-population extension of the authors’ allocation problem, but under the stated anchor requirement I cannot honestly present it as a qualifying, complexity-anchored mirror.

The case AGAINST (opponent, writing after the proponent)

The strongest case against starts with the paper’s actual results. Theorems 1–3 characterize rules by axioms or establish their existence; none states a computational complexity result. Theorem 2 is constructive—it uses HPO algorithms—but gives no computational problem, complexity bound, or analysis in parameters such as support size and input bit length. So there is no named complexity result here for ChoCo’s continuous-complexity programme to mirror.

The proposed anchor, Theorem 2, is about a mechanism on finite economies of named agents, each with a distinct endowed object. Its guarantee includes individual strategy-proofness. The proposed mass problem instead asks for a fractional assignment with no blocking coalition. That is a sensible candidate problem, but it does not preserve the theorem’s central strategic question: in an atomless population, one person’s report changes the distribution \(\mu\) by zero, so individual strategy-proofness of a rule defined on \(\mu\) is vacuous. A deviation by positive mass is a coordinated group deviation, which is a different property.

The best repair is to use genuinely interchangeable house categories with supplies that scale with the population. That can make the housing scenario plausible, but it changes the object from a finite one-to-one exchange economy to a mass-allocation economy. The resulting core or assignment problem might be worth studying in its own right. Yet Theorem 2 supplies no computational claim about that problem, and its HPO construction does not furnish a finite-replica-to-continuum result. Establishing such a connection would be new research, not continuizing a computational result in this paper.

This negative case has a real limit: a continuous theory of house exchange could be worthwhile, and the paper provides an axiomatic motivation for studying it. The stronger claim that no scenario could produce a worthwhile mirror is therefore not airtight. The firm objection is narrower: the proposed mass-core question is not a computational mirror of Theorem 2’s stated result, and the paper offers no named computational result to anchor one.
