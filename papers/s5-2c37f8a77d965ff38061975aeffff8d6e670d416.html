The continuous mirror question

Given finite item types \(M\) with conflict graph \(G\), agent types \(T\) with rational mass distribution \(\mu\) and additive valuations \(v_t\), and per-capita supply \(1/r\) of each item type for \(r>\Delta(G)\), find a mass allocation \(x_{t,B}\ge0\) over integral independent bundles \(B\in\mathcal I(G)\) satisfying \(\sum_B x_{t,B}=\mu_t\) and \(\sum_{t,B\ni j}x_{t,B}=1/r\), maximizing the largest \(\alpha\) for which every used bundle satisfies \(v_t(B)\ge\alpha\operatorname{MMS}_t\). Here \(\operatorname{MMS}_t\) is defined by the analogous mass partition problem, and the algorithm should run polynomially in \(m,\tau,L,\log r\).

The model it lives in

A capacitated high-multiplicity fair-allocation model with finitely many agent types, population mass \(\mu\), integral independent-set bundle configurations, per-capita item supply, and an objective of maximizing the guaranteed MMS approximation factor.

The objection that survived

Replicating item copies changes the conflict degree, while allowing type-level capacities changes the literal graph-coloring instance, so the paper's stated approximation guarantee and polynomial running time do not automatically survive.

fatal: False

What the mirror covers

The mirror covers MMS existence and polynomial-time approximation for repeated item types, but leaves EF1, proportionality, MNW, empirical findings, and exact MMS optimization aside.

Open questions for a prover

  • Can the continuous MMS problem be solved in compressed time for the paper's stated approximation factor?
  • Does atomless mass improve the existence guarantee beyond the discrete α bounds?
  • Can finite repeated instances be rounded from a rational mass allocation with additive loss \(O(1/K)\)?

The case FOR (proponent)

The strongest positive case is a high-multiplicity version of the paper’s MMS problem, with Theorem 2 as the lead anchor and Theorem 1 as a supporting existence anchor. Both are proved in the paper; the background remarks that computing MMS and graph coloring are NP-hard are cited literature, not anchors.

The paper’s Theorem 1 says that, for every instance with \(|N|>\Delta(G)\), an \(\alpha\)-approximate MMS allocation exists with \(\alpha>1/3\), specifically \(\alpha=1\) if \(n\le2\), \(\alpha=2/3\) if \(n=3\), \(\alpha=n/(2n-1)\) if \(n\ge4\) and \(\chi(G)=2\), and \(\alpha=\chi(G)/(3\chi(G)-3)\) if \(n\ge4\) and \(\chi(G)\ge3\). The paper’s Theorem 2 says that Algorithm 3 finds such an allocation in polynomial time, with \(\alpha=1/2\) for \(\Delta(G)=1\), \(\alpha=3/7\) for \(\Delta(G)=2\), and \(\alpha=2/(\Delta(G)+2)>1/\Delta(G)\) for \(\Delta(G)>2\). Theorem 2 is proved using normalization, high-valued-item removal, graph colorings, maximum-weight independent-set approximation, and conflict-respecting bag filling. These are genuine computational results, not merely definitions. [The paper](https://link.springer.com/article/10.1007/s10458-021-09537-3)

Here is the mirror I would put before the authors.

Fix a finite set \(M\) of item types and a conflict graph \(G=(M,E)\), with maximum degree \(\Delta\). A bundle is still an integral independent set \(B\subseteq M\); no agent ever receives a fractional item or two conflicting item types. There is a finite set \(T\) of agent types, \(|T|=\tau\), where type \(t\) is a complete additive valuation vector \(v_t\in\mathbb{Q}_{\ge0}^{M}\). The population is a rational mass distribution \(\mu\), with \(\sum_t\mu_t=1\).

The population is large in a concrete repeated-cohort regime. Let \(r>\Delta\) be an integer. Per unit of population mass there are \(1/r\) copies of every item type. Equivalently, after clearing denominators with a replication factor \(K\), there are \(Kr\) agents, \(K\) copies of each item type, and \(Kr\mu_t\) agents of type \(t\). The number of agents and item copies can therefore be enormous, while \(m\), \(\tau\), \(r\), and the valuation description remain moderate. This models, for example, a large organization running many identical cohorts of roles or sessions: people have repeated preference profiles, each role type has repeated openings, and incompatible roles cannot be assigned together to one person.

The action variable is \(x_{t,B}\), the mass of type-\(t\) agents receiving the integral bundle \(B\). Feasibility is

\(x_{t,B}\ge0\), \(\sum_{B\in\mathcal I(G)}x_{t,B}=\mu_t\) for every \(t\), and \(\sum_{t\in T}\sum_{B\ni j}x_{t,B}=1/r\) for every item type \(j\), where \(\mathcal I(G)\) is the family of independent sets of \(G\).

This is genuinely population continuity. The items remain indivisible at the individual level; only the mass of agents assigned each integral bundle is divisible. For rational \(x\), multiplying by a suitable \(Kr\) gives an ordinary finite allocation exactly. Conversely, any type-symmetric allocation in the repeated finite instance gives such an \(x\). Thus this is a high-multiplicity dictionary, not an outcome-space relaxation.

For type \(t\), define its continuum MMS value by

\(\operatorname{MMS}_t=\max\{z:\exists y_B\ge0,\ \sum_B y_B=1,\ \sum_{B\ni j}y_B=1/r\text{ for every }j,\text{ and }y_B>0\Rightarrow v_t(B)\ge z\}\).

This is precisely the limit version of asking a type-\(t\) agent to partition the repeated item supply into \(Kr\) feasible bundles and then receive the least valuable one. A feasible \(x\) is \(\alpha\)-MMS if \(x_{t,B}>0\) implies \(v_t(B)\ge\alpha\operatorname{MMS}_t\) for every positive-mass type \(t\).

My lead problem is therefore:

Continuous Polynomial MMS with Conflicting Item Types. Given \((T,\mu,V,M,G,r)\) with \(r>\Delta(G)\), output a feasible mass allocation \(x\) satisfying \(v_t(B)\ge\alpha\operatorname{MMS}_t\) on every used bundle, where \(\alpha=1/2\) for \(\Delta=1\), \(\alpha=3/7\) for \(\Delta=2\), and \(\alpha=2/(\Delta+2)\) for \(\Delta>2\). The required running time is polynomial in \(m\), \(\tau\), the valuation bit length \(L\), and \(\log r\), rather than in the expanded population size \(Kr\).

I expect this to be Class A, at least for the stated approximation guarantee. The paper’s Algorithm 3 does not fundamentally use agent identities: it uses normalized values, thresholded singleton allocation, graph colorings, and bag filling. In the high-multiplicity regime, those operations should become mass matchings and mass-flow operations over the finite type set. The relevant configuration family remains the independent sets of the fixed type-level graph, and a solution can be represented by a polynomial-size list of bundle patterns and rational masses. The main theorem to prove would be that the paper’s bag-filling invariant survives aggregation: a mass of identical agents can be processed together without losing the guarantee.

The supporting problem mirrors Theorem 1:

Continuous MMS Existence with Conflicting Item Types. On the same input, does there always exist a feasible \(x\) satisfying the paper’s guarantee with \(r\) substituted for \(n\): \(\alpha=1\) for \(r\le2\), \(\alpha=2/3\) for \(r=3\), \(\alpha=r/(2r-1)\) for \(r\ge4\) and \(\chi(G)=2\), and \(\alpha=\chi(G)/(3\chi(G)-3)\) for \(r\ge4\) and \(\chi(G)\ge3\)?

This second question may turn out easier than its discrete counterpart, because atomless mass can be split across several integral bundle patterns. It could therefore expose exactly which losses in Theorem 1 come from individual-agent indivisibility rather than from the conflict graph itself. The natural expectation is again Class A, although the exact guarantee may improve in the continuum.

Further questions follow naturally: whether the exact optimum \(\max_x\min_{t,B:x_{t,B}>0}v_t(B)/\operatorname{MMS}_t\) has a configuration-LP formulation; whether its pricing problem is tractable on bipartite, bounded-treewidth, or other graph classes; whether a finite \(K\)-agent allocation can be rounded from \(x\) with additive loss \(O(1/K)\); and whether arbitrary type-specific valuations create a continuum-specific hardness boundary even though population multiplicity itself has disappeared.

The weakest point is real: Theorem 2 is polynomial in the explicitly listed agents and items, not automatically polynomial in a compressed multiplicity parameter \(\log K\). Literal replication also makes the expanded conflict graph’s degree grow with \(K\). The mirror therefore needs the natural type-level interpretation of conflicts—copies of neighboring item types conflict, while the bundle constraint is still an independent-set constraint on the fixed type graph—and a new aggregation proof. That is a genuine technical gap, not something the paper already establishes. But it is exactly the sort of co-modification forced by making the population continuous, while preserving the paper’s underlying question: allocate integral, conflict-free bundles fairly among agents with additive valuations.

The case AGAINST (opponent, writing after the proponent)

The strongest case against begins with a problem the proposed mirror does not solve: in the paper’s actual model, the item supply is fixed while the population grows. If \(M\) is fixed and we duplicate agents, then once \(n>|M|\), every partition of \(M\) into \(n\) bundles contains an empty bundle. Hence every agent’s MMS is \(0\). In the population limit, almost everyone receives nothing, and both Theorem 1 and Theorem 2 become vacuous. Making items divisible would avoid this, but would abandon the paper’s indivisibility constraint.

The proponent’s repair—replicating every item type—does not preserve the stated theorems. Suppose there are \(K\) copies of every item, \(Kr\) agents, and every copy of \(j\) conflicts with every copy of \(j'\) whenever \(jj'\in E\). Then the expanded graph has maximum degree \(K\Delta(G)\). Theorem 2 consequently gives

\[ \alpha=\frac{2}{K\Delta(G)+2}\longrightarrow 0, \]

not \(2/(\Delta(G)+2)\). Likewise, in the bipartite case Theorem 1 gives

\[ \frac{Kr}{2Kr-1}\longrightarrow \frac12, \]

not the claimed \(r/(2r-1)\). The paper’s algorithm also runs in the expanded number \(Kr\) of agents and does not provide a polynomial algorithm in the compressed input size.

The proposed quotient does not fix this for free. If copies of the same item type are allowed together, then a bundle is a multiset, not an independent set \(B\subseteq M\), so the displayed configuration model is not the replicated paper instance. If copies of the same type are made mutually conflicting to recover \(B\subseteq M\), one has added large cliques and changed both the degree and chromatic number. Either way, the continuous model is a capacitated, type-level fractional-coloring problem with a newly defined MMS—not the high-multiplicity form of the paper’s graph-coloring instance.

This defeats both anchors as stated. Theorem 1’s parameter \(n\) is simultaneously the number of agents, the number of MMS bundles, and the number of colors; there is no principled operation that replaces it by \(r\) while leaving the item graph unchanged. Theorem 2’s guarantee depends explicitly on the expanded maximum degree, so its advertised approximation does not survive the only literal population blow-up.

That is the best negative argument, but it is not an airtight universal rejection. The paper’s own applications—repeated conference sessions, seats, or recurring positions—can plausibly motivate exactly the capacitated type-level model the proponent proposes. In that model, the problem is genuinely computational: the configuration LP has independent-set pricing, and the continuum may expose a useful boundary between fractional feasibility and graph-theoretic hardness.

So the honest conclusion is that the proponent’s particular theorem-to-theorem dictionary is wrong, and the literal paper has no nondegenerate population limit. But the repaired repeated-cohort model remains a worthwhile new continuous fair-allocation problem. I cannot credibly claim that no valuable mirror exists in any scenario.
