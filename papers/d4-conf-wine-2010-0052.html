The continuous mirror question

Given facilities \(F\), supported terminal types \(T\), rational masses \(w_t=N\mu_t\), opening costs \(a_f\), and type-to-facility costs \(d_{tf}\), decide whether there are nonnegative per-unit prices \(\pi_t\) with \(\sum_t w_t\pi_t=c(w)\) and \(\sum_t q_t\pi_t\le c(q)\) for every \(q\) satisfying \(0\le q_t\le w_t\). Here \(c(q)\) is the minimum UFL cost to serve mass \(q\), with each individual assigned to one facility and type-level assignments allowed to be fractional.

The model it lives in

Each type is a complete facility-cost vector \(d_{t\cdot}\), and the population is given by masses \(w_t=N\mu_t\). A service plan chooses open facilities \(y_f\in\{0,1\}\) and aggregate assignments \(x_{tf}\ge0\), with \(\sum_f x_{tf}=w_t\) and \(x_{tf}\le w_ty_f\), minimizing \(\sum_f a_fy_f+\sum_{t,f}d_{tf}x_{tf}\). The core asks for per-unit type prices that cover the grand cost while no subpopulation pays more than its own minimum service cost.

The objection that survived

The continuous question is core existence, while Corollary 5 concerns strategic strong-equilibrium existence; no result shows that continuous core prices can be implemented against all positive-mass strategic deviations.

fatal: False

What the mirror covers

The mirror covers UFL core and strong-equilibrium existence, using the paper’s finite core–equilibrium connection and Corollary 5; it leaves continuous strategic implementation and the paper’s other game classes and approximate-equilibrium results aside.

Open questions for a prover

  • Does continuous core existence remain NP-hard for fixed support \(\tau\), or is there an algorithm with running time \(f(\tau)\operatorname{poly}(m,L)\)?
  • Can every continuous core price allocation be implemented as a measurable strong equilibrium against every positive-mass coalition in a continuous strategic UFL game?

The case FOR (proponent)

The strongest mirror is continuous UFL core existence, grounded in the paper’s strong-equilibrium result for uncapacitated facility location.

The anchor is Corollary 5, proved in this paper using Goemans and Skutella’s result [18] and the paper’s core–equilibrium equivalence: *deciding whether a given UFL strategic game has a strong equilibrium is NP-complete.* The connection matters because the paper also proves that a UFL game has a strong equilibrium exactly when its associated coalitional game has a nonempty core. So a continuous core question follows the same stability question the authors study, rather than borrowing UFL merely as a convenient optimization problem.

For the mirror, let \(F\) be facilities and \(T\) the supported terminal types. A type \(t\) is a complete connection-cost vector \((d_{tf})_{f\in F}\): agents of that type have the same costs to every facility. The population has scale \(N\), type proportions \(\mu_t\), and masses \(w_t=N\mu_t\). This describes, for example, a large population of customers with a modest number of distinct travel-cost profiles to service locations.

Opening facility \(f\) costs \(a_f\). A feasible service plan chooses binary \(y_f\) and assigns mass \(x_{tf}\) so that \(\sum_f x_{tf}=w_t\) and \(x_{tf}\le w_t y_f\). Its cost is \(\sum_f a_f y_f+\sum_{t,f}d_{tf}x_{tf}\). Each person still uses one facility; only the type-level average assignment \(x\) can be fractional.

Here is the continuous question I would hand to a prover: given these rational data, does there exist a stable per-unit cost allocation? A solution is a vector of type prices \(\pi_t\) such that the grand population pays exactly its minimum service cost, and no subpopulation would pay more by arranging service on its own. Formally, for every mass vector \(q\) with \(0\le q_t\le w_t\), let \(c(q)\) be the minimum facility-opening and connection cost for serving that subpopulation. The required conditions are \(\sum_t w_t\pi_t=c(w)\) and \(\sum_t q_t\pi_t\le c(q)\) for every \(q\). Since members of a type are interchangeable, type-uniform prices are the natural certificate; averaging equivalent members’ shares is the continuous counterpart of symmetrizing a finite core allocation.

These infinitely many coalition inequalities have a finite description, though potentially an exponential one. For each facility set \(S\), let \(d_t(S)=\min_{f\in S}d_{tf}\) for types \(S\) can serve. The core conditions are equivalent to requiring \(\sum_t w_t[\pi_t-d_t(S)]_+\le\sum_{f\in S}a_f\) for every such \(S\). This makes the computational question concrete: find feasible prices, or show none exist, while the separation task searches over facility sets.

I expect hardness to transfer for this precise core-existence problem. The hard choices in UFL include which facilities to open and how opening costs trade off against the whole connection-cost matrix; they are not just about having many separately named terminals. There is also a direct high-multiplicity reduction. Starting from a finite UFL instance with \(n\) terminals, make each terminal’s cost vector one type of mass \(n\), and multiply every facility opening cost by \(n\). The resulting population has \(N=n^2\) units and only \(\tau=n\) types. A finite core allocation gives the same per-unit prices in the continuous instance. For any facility set \(S\), the subpopulation that most challenges its core inequality consists of all \(n\) units of each type with \(\pi_t>d_t(S)\); the original finite core inequality for that subset gives the required scaled bound. Conversely, testing continuous coalitions that take all \(n\) units of each type in a chosen subset recovers every finite core inequality. Grand costs scale by \(n\) as well. Thus core existence is preserved, and Corollary 5’s hardness transfers to this continuous core problem. The paper’s finite UFL equivalence then explains why this is a faithful mirror of its equilibrium-existence result.

My weakest point is the bridge from the core to the strategic game. The paper proves that bridge for its finite UFL games; it does not prove that every continuous core allocation can be implemented as a measurable resource-by-resource strong equilibrium against all positive-mass coalitions. That equivalence is a natural follow-up theorem, not something I would assume. The reduction also scales facility opening costs with population size, which is less natural for some service settings than for infrastructure whose cost grows with the market it serves. Those caveats limit the claim to this UFL cost-sharing regime, not the paper’s other games. They do not undermine the continuous core question itself: it has a clear population interpretation, a precise stability certificate, and an exact hardness-preserving high-multiplicity construction.

The case AGAINST (opponent, writing after the proponent)

The strongest objection is that the proposed question changes the target. Corollary 5 is about whether a strategic game has a strong equilibrium; the proposed mirror asks whether a type-price core exists. The paper proves those questions equivalent for its finite UFL games, but that theorem does not by itself establish an equivalence for a nonatomic game. To claim a continuous mirror of Corollary 5, one still needs to define continuous strategic profiles and positive-mass deviations, then show that a core allocation can be implemented as a strong equilibrium.

There is also a real limitation in the particular core model: its fractional coalitions add no new constraints. For a fixed facility set \(S\), write \(d_t(S)\) for the cheapest connection cost for type \(t\). The core inequalities require
\[ \sum_t q_t\pi_t \le \min_S\left(a(S)+\sum_t q_t d_t(S)\right) \]
for every \(0\le q_t\le w_t\). Equivalently, for each \(S\),
\[ \sum_t w_t[\pi_t-d_t(S)]_+ \le a(S). \]
The maximum over coalition masses is attained by taking either all or none of each type. Thus partial-mass coalitions never make the core harder to satisfy. In the proposed reduction, the \(n\) original terminals become \(n\) types, each replicated \(n\) times, and opening costs are scaled by \(n\). The resulting core question is exactly the finite UFL core question after aggregation. It preserves hardness, but it supplies no evidence that continuity creates new computational structure; the support remains \(n\), and the hardness reduction does not reach a bounded-support regime.

That is the best negative case I can make, but it does not defeat the anchor. The paper makes the core–equilibrium connection central, so a continuous core question is recognizably related to its result. The missing continuous core-to-equilibrium theorem is a research task, not a fundamental obstruction. And the programme explicitly allows a worthwhile mirror to have the same answer or to inherit hardness. A population of customers sharing travel-cost profiles is sensible, and scaling infrastructure costs with market size is a defensible model choice. I would tell the third reader that the proponent has overstated the continuous strong-equilibrium link, but I cannot honestly conclude that the UFL core mirror is not worth pursuing.
