The continuous mirror question

Given a finite base candidate set \(C\), spoiler set \(D\), distinguished candidate \(w\in C\), budget \(q\in\mathbb{N}\), and an explicitly supported rational distribution \(\mu\) over complete score types \(r\in\{0,1,2\}^{C\cup D}\), does there exist \(D'\subseteq D\) with \(|D'|\le q\) such that \(w\) is the unique \(2\)-NRV winner on \(C\cup D'\), where each type is restricted to that set, normalized as in the paper, and aggregate scores are weighted by \(\mu\)?

The model it lives in

The society is the mass vector \(\mu\) on complete \(0\)-\(1\)-\(2\) score-vector types; the decision variable is the discrete spoiler subset \(D'\), and the feasibility objective is to make \(w\) a unique winner, optionally minimizing \(|D'|\).

What the mirror covers

It covers the candidate-addition, unlimited-candidate-addition, and destructive candidate-deletion hardness in Theorem 5.4, plus destructive candidate partition and runoff partition in Theorem 5.9. It leaves the voter-control theorems, the constructive candidate-deletion and constructive candidate-partition results, and the generalization and comparison results unmirrored.

Open questions for a prover

  • Does the continuous candidate-addition problem have a sharper classification as a function of support size \(\tau\), candidate count \(m\), and the encoding length of \(\mu\)?
  • Do ties-promote and ties-eliminate, or allowing population mass to be split across voter partitions, change the complexity of the continuous partition variants?

The case FOR (proponent)

The strongest positive case is a Class B mirror of the paper’s candidate-control hardness. Continuizing the population does not dissolve the hardness, because the combinatorics live in the candidate set and in the normalization changes caused by candidate control.

Take \(2\)-NRV. Let \(U\) be the universe of candidates that may appear, and let a voter type be a complete score vector \(r\in\{0,1,2\}^{U}\). A continuous society is a rational distribution \(\mu=(\mu_r)\) over finitely many such types, with \(\sum_r\mu_r=1\). Thus \(\mu_r\) is the fraction of the population giving exactly the score vector \(r\). For a retained candidate set \(A\subseteq U\), define

\[ \operatorname{nrv}_{A}(r,c)= \begin{cases} 2\dfrac{r(c)-\min_{a\in A}r(a)} {\max_{a\in A}r(a)-\min_{a\in A}r(a)},& \max_{a\in A}r(a)>\min_{a\in A}r(a),\[1.2ex] 0,&\text{otherwise}. \end{cases} \]

The second case means that, as in the paper, a type expressing no distinction among the retained candidates is ignored. The aggregate score is

\[ \operatorname{NRV}_{\mu,A}(c) =\sum_r \mu_r\,\operatorname{nrv}_{A}(r,c). \]

The population is continuous; candidates remain discrete, and the score vectors remain integral. This is therefore a population continuization, not an outcome-space relaxation.

My lead anchor is Theorem 5.4. It is proved in this paper, rather than merely cited. The theorem states that \(2\)-NRV is resistant to constructive and destructive control by adding candidates, resistant to constructive and destructive control by adding an unlimited number of candidates, and resistant to destructive control by deleting candidates. The proof reduces from Hitting Set. The construction uses a candidate set containing the Hitting Set universe \(B\) together with distinguished candidates \(c\) and \(w\), and voter blocks whose scores are all in \(\{0,1,2\}\). The selected candidate set encodes a hitting set, while NRV’s renormalization makes \(w\) win exactly when the selected candidates form a hitting set of the required size.

The corresponding continuous problem is:

Continuous \(2\)-NRV Constructive Candidate Addition. An instance consists of a base candidate set \(C\), a spoiler set \(D\) disjoint from \(C\), a distinguished candidate \(w\in C\), an integer \(q\), and a rationally represented distribution \(\mu\) over score types \(r\in\{0,1,2\}^{C\cup D}\). The question is whether there exists \(D'\subseteq D\) with \(|D'|\le q\) such that \(w\) is the unique winner of the \(2\)-NRV election on \(C\cup D'\), using the restrictions of the types to \(C\cup D'\). A solution is the set \(D'\); the optimization version minimizes \(|D'|\).

This is a natural high-multiplicity regime. Imagine a large electorate repeatedly rating a short list of possible candidates using a fixed \(0\)-\(1\)-\(2\) rubric. Voters may be grouped by role, organization, demographic segment, or standardized evaluation profile. There can be millions of voters but only \(\tau\) distinct score vectors, with \(\tau\) perhaps \(O(|C|+|D|)\) or \(O(|B|+|\mathcal S|)\). The paper’s own reduction has precisely this block structure: many voters share each of a relatively small number of score vectors.

The reduction transfers exactly. If a finite election contains \(n_r\) voters of type \(r\), set \(\mu_r=n_r/N\), where \(N=\sum_r n_r\). For every retained candidate set \(A\),

\[ \operatorname{NRV}_{\mu,A}(c) =\frac{1}{N}\operatorname{NRV}_{V,A}(c). \]

Hence all winner and unique-winner comparisons are preserved, including after candidate addition, because the same per-type normalization is performed on the same restricted score vectors. Theorem 5.4 therefore gives NP-hardness of the continuous problem. This is a Class B mirror: the hardness survives because it is driven by candidate selection and set-system structure, not by naming voters individually. The problem is also naturally in NP under explicit rational support, since a proposed spoiler set can be checked with exact rational arithmetic.

This mirror covers the bounded constructive addition case directly. The theorem’s destructive addition, unlimited addition, and destructive deletion statements give immediate sibling questions under the same model. The natural next questions are whether the problems become tractable for fixed \(\tau\), fixed candidate dimension, or bounded score support; whether minimum-spoiler optimization admits approximation guarantees; and whether one can characterize exactly which candidate-control cases remain hard for arbitrary scoring range \(k\).

A second, distinct anchor is Theorem 5.9, also proved in this paper by a reduction from Hitting Set. It states that \(2\)-NRV is resistant to destructive control by partition of candidates and to destructive control by runoff partition of candidates. The reduction constructs an election with candidates \(B\cup\{w\}\). A subset of \(B\) of size at most \(k\) makes \(w\) lose a subelection exactly when it is a hitting set; if the subset is larger or fails to hit some set, the normalization arithmetic makes \(w\) win. Thus a successful candidate partition exists exactly when the Hitting Set instance is positive.

The corresponding continuous problem is:

Continuous \(2\)-NRV Destructive Candidate Partition. An instance consists of a finite candidate set \(C\), a distinguished candidate \(w\in C\), and a rational distribution \(\mu\) over types in \(\{0,1,2\}^{C}\). The chair chooses a partition \((C_1,C_2)\) of \(C\). The candidates surviving the NRV subelection on \(C_1\) are promoted under the ties-promote rule; call that set \(D\). The final election is run on \(D\cup C_2\), using the original population distribution \(\mu\) and renormalizing every type on the final candidate set. The question is whether some partition makes \(w\) not a unique final winner. A solution is the partition \((C_1,C_2)\). The runoff variant instead runs subelections on both \(C_1\) and \(C_2\) and uses the union of their surviving candidates in the final election.

Again, a finite election maps to this problem by setting \(\mu_r=n_r/N\), and every score comparison is preserved after division by \(N\). The reduction in Theorem 5.9 therefore transfers, giving a Class B NP-hardness result for the continuous-population problem. This second mirror is useful because it shows that the programme is not limited to one-shot spoiler selection: the same high-multiplicity society supports sequential candidate filtering and runoff structures.

The regime is plausible here for a large institution or platform with many repeated evaluation profiles, where the chair partitions a finite slate into preliminary panels or constituencies. The population distribution is fixed, while the candidate partition is the intervention variable. The number of population types can be small relative to the number of agents, but the candidate set and its incidence structure remain combinatorial.

The main weakness is that these mirrors are algorithmically conservative. They are weighted-profile or high-multiplicity versions of the paper’s finite problems, and a sceptical reader could say that replacing voter counts by rational masses mostly exposes an existing anonymity rather than creating a new continuous phenomenon. That objection does not defeat the mirror under ChoCo’s standards: high multiplicity is explicitly a target regime, and hardness surviving aggregation is itself a meaningful boundary result. It shows that continuization helps only when population multiplicity is the source of difficulty; here the obstruction sits in the discrete candidate universe.

I would not claim the same automatic transfer for Theorem 5.6 or Theorem 5.7, whose control action partitions voters. In a genuine continuous version, mass of one type could be divided fractionally between subelections, potentially destroying the integral Hitting Set gadget. Those are valuable follow-up questions, possibly yielding Class A or continuum-specific behaviour. The candidate-control results above are the strongest honest case: they provide precise, plausible continuous-population problems anchored by named hardness theorems proved in the paper, with hardness transferring for a principled reason.

The case AGAINST (opponent, writing after the proponent)

The strongest negative case is that both anchors leave the population entirely passive. They replace voter counts by rational weights while the real control object remains a discrete candidate subset or partition. No mass is transferred, optimized, or fractionally assigned, and NRV’s normalization is still performed independently for each voter type. Thus the proposed problems look like weighted versions of the paper’s finite problems, rather than continuous-population problems exposing new optimization structure.

That objection is not enough under ChoCo’s standard, however. The paper’s control problems are anonymous: an agent matters only through their complete score vector. For Theorem 5.4, let a type be \(r\in\{0,1,2\}^{C\cup D}\), including scores for every potential spoiler. Every voter block in the hitting-set construction is then one type with mass equal to its block size divided by the total population. For every retained set \(A\),

\[ \operatorname{NRV}_{\mu,A}(c) = \frac{1}{N}\operatorname{NRV}_{V,A}(c). \]

All winner comparisons, including the context-dependent normalization after candidate addition, are preserved exactly. Repeated standardized rating profiles in a large electorate are a sensible high-multiplicity regime, and candidate-specific scores are part of the complete type rather than an illicit use of individual identity. The candidate-addition mirror therefore survives.

Theorem 5.9 survives for the same reason. A large platform or institution may have a fixed population distribution over recurring evaluation profiles while a chair partitions a finite candidate slate into preliminary contests. The subelections and final election use the same type-wise normalization, so the hitting-set reduction transfers unchanged. The fact that the intervention is on candidates rather than masses is not a scope violation; ChoCo explicitly allows population continuization alongside discrete control actions.

The two anchors are indeed algorithmically conservative and share the same high-multiplicity mechanism. But that is a limitation of their novelty, not a fundamental modelling failure. Class B mirrors and hardness surviving aggregation are explicit programme targets. Nor can one object that the continuous version has the same answer, since that is precisely a result to be established.

Accordingly, I cannot honestly defeat these anchors. There is no credible case that this paper admits no worthwhile continuous mirror in any scenario. The negative case is weak, and the candidate-control mirrors remain valid under the programme’s rules.
