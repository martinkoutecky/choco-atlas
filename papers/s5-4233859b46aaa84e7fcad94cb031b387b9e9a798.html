The continuous mirror question

Given a frame satisfying the paper’s interval-case assumptions, an issue order \(\pi\), and binary-rational masses over complete rational judgment types on its agenda, compute the complete consistent collective judgment set produced by sequential majority: at each issue choose the sign with greater total supporting mass, choose \(P_w\) on a tie, and choose the only sign consistent with prior decisions whenever consistency forces one.

The model it lives in

Types are complete rational modal judgment sets on the \(r\)-issue agenda; the society is a distribution \(\mu\) over those types. The decision at issue \(P_w\) uses its support \(\sum_{J:P_w\in J}\mu_J\); the output variables are the collective issue signs, and there is no scalar objective.

The objection that survived

Scaling rational type masses by a common denominator reproduces the same finite profile and every sequential decision, so the mirror adds no new behavior or algorithmic leverage; the proponent does not explicitly address this exact equivalence.

fatal: False

What the mirror covers

The mirror covers computation of the sequential majority procedure for the interval case \(A=[0,k]\), including its consistency checks. It leaves the dictatorship results, the general-frame impossibility analysis, and the procedure for arbitrary \(A\) outside the proposed mirror.

The case FOR (proponent)

The strongest defensible mirror is narrow: a high-multiplicity version of the paper’s sequential majority procedure for the interval case \(A=[0,k]\).

A type is a complete rational modal judgment set on the paper’s finite agenda of \(r\) propositions \(P_w\). The society is a distribution \(\mu\) over those types, with binary rational masses summing to \(1\). This fits a large consultation in which many respondents give coherent answers to the same modal questions, but only \(\tau\) distinct answer patterns occur. A continuous population is natural when the number of respondents is much larger than \(\tau\).

Call the problem Continuous Modal Sequential Aggregation. Its instance is the paper’s frame and agenda for \(A=[0,k]\), a fixed issue order \(\pi\), and the supported types with their masses. For each issue \(P_w\), its support is \(\sum_{J:P_w\in J}\mu_J\). Process issues in order: choose the sign with greater support, choosing \(P_w\) on a tie, unless consistency with the decisions already made forces the other sign. The solution is the resulting complete, consistent collective judgment set. This is a rule-computation problem, not an optimization problem, so it has no scalar objective.

My lead computational anchor is Lemma 5.3, stated in the paper for \(A=[0,k]\): for every \(w\), \(A+w\subseteq\bigcup_{w_0\in J_+}(A+w_0)\) if and only if \(\cvle[w]+\cvri[w]\le k+1\), where \(\cvle[w]\) is the minimum \(t\in[0,k]\) with \(w-t\in J_+\), and \(\cvri[w]\) is the minimum \(t\in[0,k]\) with \(w+t\in J_+\); either value is \(k+1\) if no such \(t\) exists. The lemma is presented as the paper’s own result, without an external citation; the supplied text does not display its proof. Section 5.4 uses it to report an \(O(rk)\) implementation of the sequential procedure from issuewise acceptance counts.

For the continuous mirror, compute those counts as rational acceptance masses from the \(\tau\) supported types, then run the same procedure. This gives a tractable problem, polynomial in \(r,k,\tau,L\), with exact rational arithmetic; \(r\) is also the agenda size, so the bound is in the explicit number of issues. The paper already represents finite profiles through acceptance counts \(c(w)\), which makes replacing counts by masses a plausible extension of its computational problem rather than a change to the agenda or its consistency requirements.

There is a real limitation to this anchor: Lemma 5.3 is a covering criterion, not a numbered theorem asserting membership in P, and the runtime claim appears in the surrounding algorithm discussion. The paper has no numbered NP-hardness or complexity-class result to anchor a stronger trichotomy claim. Its dictatorship theorems concern axiomatic aggregation, which is outside this continuization programme’s computational scope. So the mirror covers the algorithmic part of the paper, not its Arrow-type impossibility result.

A natural next question is whether one can find a minimum-cost transfer of mass between judgment types that changes the sequential procedure’s output. That would be a new bribery-style problem, not a result established here.

The case AGAINST (opponent, writing after the proponent)

The best case against is that Lemma 5.3 is a covering criterion, not a named complexity result. The paper gives the sequential procedure’s running time in its algorithm discussion, and already represents the finite profile by acceptance counts \(c(w)\). Its computation uses those counts and the frame, without inspecting voter identities or the joint distribution of judgment types.

For a continuous society with type masses \(\mu_J\), define \(q_w=\sum_{J:P_w\in J}\mu_J\). Since the masses are binary rationals, choose a common denominator \(D\) and form a finite profile with \(D\mu_J\) voters of type \(J\). Then \(c(w)=Dq_w\). Every majority comparison, tie, and consistency check produces the same decision in the same issue order. The proposed mirror therefore re-expresses the algorithm the paper already gives: its population-share input adds no new computational structure, and there is no fractional intervention or optimization whose feasible solutions change under continuization. A version that minimizes mass transfers to alter the output could be interesting, but it adds a new objective and cost model that the paper does not study.

That case is limited. A large consultation with recurring modal judgment types is a sensible high-multiplicity regime, and the distribution-based procedure is well-defined. I can argue that this anchor offers little beyond the paper’s existing count-based algorithm; I cannot honestly argue that no worthwhile continuous mirror exists in any scenario.
