What the mirror covers

The candidate covers only Theorem 4's homogeneous equilibrium-load pattern; it leaves the sequential equilibrium computation and social-learning convergence results aside.

The case FOR (proponent)

The strongest positive case is narrow: a continuous version of the paper’s homogeneous, budget-constrained channel-selection equilibrium. The paper has no named theorem classifying a problem as NP-hard, in P, W[1]-hard, or FPT. Its best anchor is therefore a structural equilibrium result, not a complexity classification.

The anchor is Theorem 4, proved in this paper. It says that in the \(M\)-dish, \(N\)-customer game with budget \(L\), if all dishes have the same state and all customers have the same utility function, then every dish has \(n_T\) requesters when \(n_T\le\lfloor NL/M\rfloor\); when \(n_T\ge\lceil NL/M\rceil\), each dish has either \(\lfloor NL/M\rfloor\) or \(\lceil NL/M\rceil\) requesters. Here \(n_T\) is the largest load at which a customer’s expected utility from requesting a dish is positive: it is positive through \(n_T\) and nonpositive beyond it.

A plausible regime is a large wireless access system with many statistically similar terminals choosing among a fixed set of channels. The type is a terminal’s complete decision-relevant description: its channel-quality model, belief about channel states, utility function, and request budget. In the homogeneous case of Theorem 4 there is one type, so \(\tau=1\) while the number of terminals grows. Normalize the population to mass \(1\). A mass of \(x_S\) chooses each feasible bundle \(S\subseteq\{1,\ldots,M\}\), where \(|S|\le L\); each terminal still chooses an integral bundle. The channel load is \(z_j=\sum_{S\ni j}x_S\). This is a continuum of users, not a continuum of channels or states.

Here is the problem I would hand to a prover: Equal-Load Buffet Equilibrium. The input is \(M\), \(L<M\), a common finite state and belief model, and a rational piecewise-linear expected utility \(V(z)\) for requesting a channel at population load \(z\). Assume \(V\) is strictly decreasing and has a rational saturation threshold \(\rho\in(0,1]\), with \(V(z)>0\) for \(z<\rho\) and \(V(z)\le0\) for \(z\ge\rho\). A unit mass of identical users chooses bundles of at most \(L\) channels, and a user choosing \(S\) receives expected utility \(\sum_{j\in S}V(z_j)\). The task is to compute an exact population Nash equilibrium: output a feasible mass assignment \(x_S\) whose supported bundles are best responses to its induced loads. A compact solution can give a sparse list of bundles and their masses rather than enumerate all subsets.

The expected equilibrium loads are
\[ z_j=\min\{\rho,L/M\}\qquad\text{for every }j. \]
Below saturation, a less-loaded channel has higher utility, so unequal loads invite users to switch. If saturation is below the average load allowed by the budget, users stop at that threshold; otherwise the per-user budget fills and equilibrium balances load across channels. I expect this homogeneous problem to be tractable: the load vector is explicit, and it is feasible because it lies in the uniform-matroid polytope \(0\le z_j\le1,\ \sum_j z_j\le L\). A sparse bundle decomposition can represent it. This is a proposed continuous problem, not a complexity result established by the paper.

The connection to Theorem 4 is the normalized limit: if \(n_T/N\) tends to \(\rho\), its two cases converge to the common load \(\min\{\rho,L/M\}\); the floor/ceiling difference disappears. The paper’s uncertainty can remain in the model through the finite belief and state distributions used to define \(V\). The authors should recognize the mirror as their homogeneous congestion game with customer counts replaced by population shares. It covers Theorem 4’s equilibrium-load result, not the paper’s learning convergence or its general recursive equilibrium computation. Mean-field methods may supply tools, but the computational question here is how to represent and compute exact equilibrium masses.

The weak point is that each finite customer affects congestion by one unit, while an infinitesimal user does not affect aggregate load. Theorem 4’s cutoff is defined precisely by whether one additional customer makes utility nonpositive. The mirror therefore needs the stated per-capita utility scaling, with utility reaching its saturation threshold as load becomes a fraction of the population. If channel capacity stays fixed while the population grows, the threshold fraction may vanish and this mirror may cease to be useful. A natural next question is whether the equilibrium computation remains tractable with a small number of terminal types, each with its own utility curve and budget.

The case AGAINST (opponent, writing after the proponent)

Theorem 4 is a real anchor: it proves a structural fact about equilibrium loads. The problem is that the proposed mirror preserves those loads while changing the game that produces them.

In the paper, a customer acts at a particular place in a sequential order and predicts later customers’ choices. Order matters: the simulations show a first-mover advantage, and the authors rotate the order over time to make outcomes fairer. Under ChoCo’s definition of type, position is part of the decision-relevant description. In a fixed time slot, each position is occupied by one customer, so preserving the sequential game gives a number of types that grows with \(N\). Merging them into the proponent’s single type discards the feature that makes the paper’s equilibrium subgame perfect.

The proponent’s equal-load problem is coherent, but it is an anonymous nonatomic congestion game: an individual has no mass and cannot affect the load faced by anyone else. Its equilibrium is therefore a Wardrop-style replacement for the paper’s sequential equilibrium, not a continuization of that equilibrium computation. A stronger attempt could attach a priority coordinate \(s\in[0,1]\) to each user. But each point in that continuum still has zero mass, so its action does not change the continuation loads. Discretizing priority into finite cohorts restores some order, but changes the game to one with cohort moves; refining the cohorts makes the number of strategically distinct positions grow. None of these choices preserves both the finite game’s sequential incentives and a fixed-size type description.

The threshold scaling reinforces the mismatch, though it is not decisive by itself. With fixed channel capacity and a fixed \(n_T\), the normalized threshold \(n_T/N\) tends to zero. A positive limiting \(\rho\) requires scaling the utility or service capacity with population size. The programme explicitly allows such co-modification, and a growing wireless system could make it natural; the result would then be a meaningful anonymous congestion model. It would still leave the order issue.

That is the strongest case against this anchor: the attractive one-type formulation mirrors the theorem’s load-count conclusion, but not the sequential computational problem behind it. The limitation is substantial. A nonatomic equilibrium problem for wireless users is a plausible, worthwhile problem, and the authors might recognize it as theirs. So I cannot honestly defend the universal claim that no worthwhile mirror exists. I can only argue that Theorem 4, as presented, does not establish one without replacing a central feature of the paper’s model.
