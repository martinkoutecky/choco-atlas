The continuous mirror question

Given projects \(P\), per-capita costs \(c(p)>0\), a per-capita budget \(B\), a preselected set \(P_0\), an MES budget \(B_{\mathrm{MES}}\ge c(P_0)\), and rational approval-type masses \(\mu_A\) summing to \(1\), compute the Value-Based Mass-MES output \(Q\supseteq P_0\). Let \(q_p=\sum_{A\ni p}\mu_A\), define the Value-Based threshold using \(q_p\), and assign type \(A\) its payment \(\pi_A=\sum_{p\in A\cap P_0}c(p)/\max\{q_p,q^*\}\). Rebalance to type budgets \(b_A\) maximizing \(\min_{\mu_A>0}(\pi_A+b_A)\), subject to \(\sum_A\mu_A b_A=B_{\mathrm{MES}}-c(P_0)\) and \(b_A\ge0\); then run MES using \(\sum_{A\ni p}\mu_A\min\{b_A,\rho(p)c(p)\}=c(p)\). Does the resulting \(Q\) satisfy mass-EJR+: for every \(p\notin Q\) and every subpopulation \(\nu_A\in[0,\mu_A]\) supported on types approving \(p\), with \(\sigma=\sum_A\nu_A>0\), is there an \(A\) with \(\nu_A>0\) such that \(c(A\cap Q)+c(p)>\alpha_{\mathrm{VB}}B\sigma\), where \(\alpha_{\mathrm{VB}}=\min_{\mu_A>0}(\pi_A+b_A)/B\)?

The case FOR (proponent)

The positive case is a large participatory-budgeting electorate in which many residents submit the same approval ballot: for example, a city with hundreds of thousands of participants but only dozens or hundreds of distinct approval sets. A voter’s type is the complete set \(A\subseteq P\) of projects they approve; because the paper’s satisfaction depends only on approvals and project costs, voters of the same type are interchangeable. The mass \(\mu_A\) is that type’s fraction of the population. The outcome remains a feasible subset of indivisible projects. Only the population becomes continuous.

The closest named anchor is Theorem 2, proved in this paper. It says: if a mixed rule includes \(MES_{\mathrm{Value\text{-}Based}}\) with available budget share \(\alpha\), and that method’s minimum voter budget share is \(\alpha_{\mathrm{VB}}\ge\alpha\), then the mixed rule’s outcome satisfies \(\alpha_{\mathrm{VB}}\)-budget EJR+ up to any project. This is the paper’s main theoretical result and a strong algorithmic fairness guarantee. The paper has no named result classifying a problem’s computational complexity—no P, NP-hardness, FPT, or runtime theorem—so Theorem 2 does not meet a strict complexity-anchor requirement.

Still, it motivates a precise continuous problem. Call it Value-Based Mass-MES. An instance gives a finite project set \(P\), rational costs \(c(p)>0\), total budget \(B\), a rational distribution \(\mu\) over approval types with support size \(\tau\), a preselected set \(P_0\), and an MES budget \(B_{\mathrm{MES}}\ge c(P_0)\). Let \(q_p=\sum_{A\ni p}\mu_A\) be the supporting mass. Apply the paper’s Value-Based preallocation to the preselected projects: compute its threshold using support masses \(q_p\), assign each type its corresponding per-capita payment \(\pi_A\), then rebalance budgets \(b_A\) to maximize \(\min_{A:\mu_A>0}(\pi_A+b_A)\), subject to \(\sum_A\mu_A b_A=B_{\mathrm{MES}}-c(P_0)\) and \(b_A\ge0\). Set \(\alpha_{\mathrm{VB}}=\min_{A:\mu_A>0}(\pi_A+b_A)/B\).

Then run MES on the remaining population mass: for each candidate project \(p\), find the least \(\rho(p)\) satisfying
\[ \sum_{A\ni p}\mu_A\min\{b_A,\rho(p)c(p)\}=c(p). \]
Select an affordable project with minimum \(\rho(p)\), update the budgets of its supporting types, and continue until no project is affordable. A solution is the resulting feasible project set \(Q\supseteq P_0\), together with the budgets and \(\alpha_{\mathrm{VB}}\). The target guarantee is mass-EJR+: for every unselected \(p\) and every subpopulation \(\nu_A\in[0,\mu_A]\) supported on types approving \(p\), if \(\sigma=\sum_A\nu_A>0\), some type with \(\nu_A>0\) must satisfy
\[ c(A\cap Q)+c(p)>\alpha_{\mathrm{VB}}B\sigma. \]
This is the direct mass counterpart of the paper’s “up to any project” condition. The MES choice remains the paper’s minimum-\(\rho\) rule; the fairness condition is its performance guarantee, not a welfare objective being optimized.

This is plausible as the authors’ problem: they already account for preselected projects by adjusting voter budgets, and type-level masses preserve exactly the approval and spending information their rules use. The theorem’s proof appears to extend by replacing voter counts with masses. Rational mass profiles also have a direct finite replication: \(\mu_A=n_A/n\) is precisely a discrete profile with \(n_A\) voters of type \(A\). The expected outcome is tractable by directly simulating the weighted rule, likely in time polynomial in \(|P|,\tau\), and the input bit length; that runtime bound would need to be established for the mass implementation. The mirror covers Theorem 2’s Value-Based guarantee, not the paper’s empirical comparisons or its other preallocation guarantees. Further questions include proving the exact bit-complexity bound and comparing the best achievable mass-EJR+ guarantee with the one obtained by Value-Based MES.

The weak point is that the paper provides no hardness result for continuization to dissolve, and finite approval profiles are already naturally grouped by ballot type. So this is a credible high-multiplicity extension of a named algorithmic guarantee, but it does not yet make the paper a strong case study in a changed complexity landscape.

The case AGAINST (opponent, writing after the proponent)

The strongest objection is that Theorem 2 is not a computational result of the kind this programme is looking for. It proves a proportionality guarantee for a voting rule: the outcome of \(MES_{\mathrm{Value\text{-}Based}}\) satisfies a parameterized EJR+ condition. The other named results likewise concern axioms, impossibilities, or outcome guarantees. The experiments compare welfare and proportionality; they do not classify a computational problem. So there is no complexity result here whose continuous-population mirror would chart the gap the programme targets.

The proponent’s strongest repair is a weighted version of \(MES_{\mathrm{Value\text{-}Based}}\): represent voters by approval types and their masses, then ask whether the rule retains Theorem 2’s guarantee. That is a coherent population continuization, and approval ballots make it a natural high-multiplicity model. But it turns the paper’s fairness theorem into a mass-based fairness theorem; it does not supply the missing computational question. A complexity study of running or verifying the weighted rule could be worthwhile, but it would be an adjacent problem to formulate, not a computational result anchored in this paper. The literal mass equations also need consistent normalization between total project costs and type-level budgets; that looks repairable, so it is not a fundamental objection.

I would not argue that PB lacks a plausible large-population regime, that the projects must become divisible, or that a continuous version would have the same answer. Those objections miss the programme’s scope. The negative case is narrower: this paper offers a credible high-multiplicity model, but no named computational result for that model to mirror. On the programme’s stated criterion, that is a decisive mismatch. The broader claim that no worthwhile mirror could be developed in any scenario is harder to defend: a new computational question about weighted PB rules might still be valuable, but it would extend the paper rather than continuize one of its computational results.
