The continuous mirror question

Given a finite set of types \(T\), non-atomic valuation measures \(V_t\), rational masses \(\mu_t\), and \(\epsilon\in(0,1)\), can one produce a single succinct allocation rule for every compatible population size \(N\), where \(N\mu_t\in\mathbb{Z}\)? For each type \(t\) and clone rank \(j\in\{1,\ldots,N\mu_t\}\), the rule returns a finite union of cake intervals; the bundles must be pairwise disjoint, exactly envy-free for all clones, and satisfy \(V_t(X_{t,j})\geq (1-\epsilon)/N\). Require the rule description and its shared type-level valuation-query cost to be polynomial in \(|T|\), the bit length of \(\mu\), and \(\log(1/\epsilon)\), independent of \(N\).

The model it lives in

A society is a rational distribution \(\mu\) over finitely many valuation types. For each compatible finite population, a succinct rule assigns every clone an integral cake bundle; exact clone-level envy-freeness and the near-proportional guarantee apply in each realization. Fractional type-level average densities may summarize resource use, but do not replace the individual bundles or envy constraints.

The objection that survived

The paper’s mark/eval model may require \(\Theta(N)\) work or output to specify all clone bundles, so an \(N\)-independent type-level query bound needs a precise succinct-rule accounting.

fatal: False

What the mirror covers

The mirror covers Theorem 5’s disconnected-piece guarantee for near-proportional envy-free allocations. It leaves the connected-piece results, including the fixed-agent algorithms, outside its scope.

Open questions for a prover

  • Can shared valuation-oracle information support an \(N\)-independent succinct rule while preserving exact envy-freeness for every compatible \(N\)?
  • What output and evaluation-cost convention makes the succinct allocation rule a faithful computational object in the mark/eval model?

The case FOR (proponent)

The strongest case is a high-multiplicity version of the paper’s disconnected-piece result. Here, a type is a normalized, non-atomic valuation \(V_t\) of the cake; two agents share a type exactly when the paper treats their preferences as identical. The society is a rational distribution \(\mu\) over a finite support \(T\), with \(\tau=|T|\). For each compatible population size \(N\), there are \(N\mu_t\) clones of type \(t\) sharing the same unit cake and allowed to leave some of it unallocated.

Theorem 5 in Section 8, proved in this paper, is the anchor: for every \(n\) and \(\epsilon>0\), with free disposal, an envy-free allocation using disconnected pieces can be found in which every agent receives value at least \((1-\epsilon)/n\). The theorem gives \(O(4^n\ln(1/\epsilon))\) cuts and \(O(n4^n\ln(1/\epsilon))\) mark/eval queries.

The corresponding question I would hand to a prover is Succinct High-Multiplicity Envy-Free Cake Cutting. Given \((T,\mu,(V_t)_{t\in T})\) and \(\epsilon>0\), find a single succinct allocation rule that works for every sufficiently large \(N\) with all \(N\mu_t\) integral. Given \(N\) and a clone’s type and rank within that type, the rule returns that clone’s finite union of cake intervals. For every such \(N\), the resulting allocation must be exactly envy-free among all clones and give each clone \(i\) value at least \((1-\epsilon)/N\). The rule’s description and its type-level value-query count should be polynomial in \(\tau\), the bit length \(L\) of \(\mu\), and \(\log(1/\epsilon)\), rather than growing with \(N\).

The population interpretation is explicit in the type averages. If \(X_i^{(N)}\) is clone \(i\)’s bundle and \(r_t=N\mu_t\), define the scaled average allocation density
\[ x_t^{(N)}(z)=\frac{N}{r_t}\sum_{i:\,t(i)=t}\mathbf{1}_{X_i^{(N)}}(z). \]
Then \(\sum_t\mu_t x_t^{(N)}(z)\leq 1\), and the theorem’s per-agent guarantee becomes a type-level average value of at least \(1-\epsilon\) after scaling by \(N\). These averages can be fractional even though every finite society member receives an ordinary cake piece. The solution must include the exact finite allocation rule: the average densities alone would erase individual envy constraints.

I expect this mirror to be tractable in the high-multiplicity regime: repeated valuation oracles make it plausible that a type-based method can replace work proportional to the number of clones. The paper supplies a useful target and a finite-population baseline, not that algorithm. Further questions include whether the rule can guarantee exact proportionality (\(\epsilon=0\)), whether connected pieces admit a similar support-based bound, and whether a type-average solution can always be implemented with exact envy-freeness for every sufficiently large compatible \(N\).

This case covers Theorem 5 only; it does not claim to mirror the paper’s connected-piece theorems. The weak point is substantive: Theorem 5’s bound depends exponentially on the number of agents, while my proposed question asks for a compressed, support-sensitive rule. Moreover, the original theorem does not group clones by type or prove that fractional type averages preserve the individual envy constraints. The mirror is a credible high-multiplicity research question because it keeps the paper’s exact finite-agent fairness requirement in each realization, but its tractability is a conjecture, not a consequence of the anchor.

The case AGAINST (opponent, writing after the proponent)

Theorem 5 is a real computational anchor: it gives a bounded-query algorithm for envy-free allocations with a near-proportional guarantee. I can’t dismiss it as axiomatic, analytic, or already solved for a continuous population. The strongest objection is that the proposed mirror cannot keep both the paper’s allocation semantics and its promised population-independent query bound.

For clones with valuation \(V_t\), exact envy-freeness forces all their bundles to have equal value under \(V_t\): each clone must weakly prefer its own bundle to every other clone’s, including those of the same type. A type-average density does not record which clone gets which bundle, so it cannot certify that condition. The proposed rank-indexed rule restores the missing information, but each finite realization still has \(N\) bundles to specify. With the paper’s arbitrary valuation oracles, a compact rule cannot simply infer all the required cut locations: mark queries locate cuts, and producing the allocation for all clones entails work that grows with \(N\). If those calls are deferred until a clone requests its bundle, the rule is a lazy description, not a completed allocation with a type-level query bound.

The apparent alternative—keep only fractional type-level allocations—loses the paper’s guarantee. It describes average cake use, not an integral bundle for each agent, and therefore does not preserve individual envy-freeness. In an atomless population, disjoint positive-value bundles for every infinitesimal individual are unavailable; rescaling the guarantee does not supply the missing assignment structure. Adding a rank coordinate brings that structure back, along with the finite allocation work.

One could ask a repaired question: can a succinct rule support exact finite allocations with output-sensitive, \(N\)-dependent cost, or can compact valuation representations make the cut locations generable? Those may be worthwhile questions, but the first leaves population size as a central computational cost, while the second changes the paper’s arbitrary non-atomic valuation model. Neither is the promised compression of Theorem 5 in the paper’s model.

This is not an airtight case against every conceivable mirror. A useful output-sensitive or parametric result could emerge. The negative case is strongest against the specific anchor as a ChoCo continuization: preserving exact envy-freeness appears to preserve the \(N\)-scale allocation problem, while removing that cost by passing to averages changes the problem.
