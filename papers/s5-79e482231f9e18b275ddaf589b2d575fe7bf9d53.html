The continuous mirror question

Given rational type masses \(\mu_t\), per-capita supplies of finitely many object categories, ordinal or benchmark-utility information for each type, and a feasible type-level random assignment \(x\), determine whether \(x\) is undominated; if it is, produce preference-compatible utilities \(v_t\) under which \(x\) maximizes aggregate ex-ante welfare, and otherwise produce a feasible assignment that dominates it.

The model it lives in

A continuum of agents represented by a finite support \(T\) of complete preference-information types, with mass \(\mu_t\) per type. Each type receives categories probabilistically, aggregate category demand is bounded by per-capita supply, and welfare weights each type’s utility by its mass.

What the mirror covers

The mirror covers Theorem 1’s construction of supporting utilities for undominated allocations. It leaves Theorem 2’s finite universal set of utility profiles and Theorem 3’s efficiency-deficit subgradient result aside.

Open questions for a prover

  • Does the type-mass formulation yield a polynomial-time algorithm in the number of represented types, categories, benchmark utilities, and input bit length?
  • How does the continuous assignment model relate to finite assignments with repeated types and integer category supplies?

The case FOR (proponent)

I can make one narrow positive case: a continuous-population version of the paper’s mixed-information efficiency theorem. The caveat is substantial: the paper contains no named computational-complexity result. Its closest anchor is Theorem 1, proved here: if an allocation is undominated, then some preference-compatible profile of von Neumann–Morgenstern utilities makes it ex-ante welfare maximizing. The proof constructs such a profile using primal and dual linear programs. The theorem does not itself assert a complexity classification; the polynomial-time claim below is an inference from its LP method.

In the mirror, a type is a complete description of preference information: either an ordinal ranking over object categories, or a finite set of benchmark utilities whose nonnegative span contains the agent’s utility. A rational mass \(\mu_t\) of the population has each type, with \(\sum_t\mu_t=1\). There are finitely many categories of otherwise distinct objects, each with per-capita supply \(\kappa_j\), where \(\sum_j\kappa_j\ge1\). A type-level allocation \(x_{tj}\) is the fraction of type \(t\) receiving category \(j\): \(\sum_jx_{tj}=1\) and \(\sum_t\mu_tx_{tj}\le\kappa_j\). Think of a sequence of large economies with \(\kappa_jN\) copies of category \(j\), with agents of the same type indifferent among copies. This gives a regime with many agents and relatively few distinct preference-information types.

The resulting question is: given rational type masses and supplies, type information, and a feasible type-level allocation \(x\), determine whether \(x\) is undominated; if it is, produce a preference-compatible utility profile under which \(x\) maximizes aggregate ex-ante welfare; if it is not, produce a feasible dominating allocation. For an ordinal type, domination requires weak improvement in the probability of receiving an object at least as good at every rank cutoff. For a benchmark-utility type, it requires weak improvement under every benchmark utility. In either case, at least one such inequality must be strict for some positive-mass type. A supporting utility is strictly order-compatible for ordinal types, and a nonnegative combination of the supplied benchmarks for cardinal types. It supports \(x\) if \(x\) maximizes \(\sum_t\mu_t\sum_jv_t(j)y_{tj}\) over feasible allocations \(y\).

This is a plausible analogue of Theorem 1 because the population itself is the continuous object; the lotteries over assignments are already in the paper and are not the reason for the mirror. The same duality construction applies to the finite type-level LP. It suggests a polynomial-time algorithm in the number of represented types, object categories, benchmark utilities, and input bit length. The expected classification is tractable. That algorithmic claim is inferred from the LP formulation and proof, not stated as a complexity result in Theorem 1.

The mirror covers Theorem 1’s support-by-utilities result, not Theorems 2 or 3 or the paper’s broader economic claims. It also raises follow-on questions: whether there is a small universal set of supporting utility profiles, as in Theorem 2; how the continuum model relates to finite assignments with repeated types and integer supplies; and whether a worst-case domination measure has a useful convex, piecewise-linear form analogous to Theorem 3.

My weakest point is that this is an inferred computational question attached to an existence theorem, not a mirror of a named hardness or complexity result. The category-supply model also relies on agents sharing rankings and benchmark values across many copies of objects. If the relevant assignment problem depends on idiosyncratic valuations for each individually named object, the type compression is not faithful. Under the stated anchor rule, Theorem 1 is only a near-fit; a strict reading must record that the paper offers no qualifying named computational anchor.

The case AGAINST (opponent, writing after the proponent)

The only anchor is Theorem 1, and it is an existence result: if an allocation is undominated, some preference-compatible utility profile makes it welfare maximizing. Its LP duality proof does not state the complexity of a computational problem. The proposed mirror adds one: given an allocation, decide whether it is undominated and return either a supporting utility profile or a dominating allocation. That is a reasonable problem to ask, but it is an algorithmic extension of the theorem, not a continuous mirror of a computational result in the paper. Under the stated anchor criterion, that is the strongest reason to reject the case.

The proposed population model itself is quite defensible. Agents can share complete preference-information types, object categories can have per-capita supplies, and a type-level allocation can record the fraction receiving each category. Requiring a Pareto improvement to benefit positive mass gives a sensible continuum version of domination. This does not confuse continuous population with fractional outcomes: lotteries are already in the paper, while the new model aggregates agents. Nor does the need to group agents with the same information count against it; that is exactly what a high-multiplicity regime means.

The gap is that the proposed computational question needs to be supplied from outside the paper’s stated result. The finite model already has an LP over individual allocations, and its dual constructs the supporting utilities. Aggregating repeated agents into types changes the representation and could be useful, but it does not uncover a complexity question the paper itself formulates or classify. The case therefore depends on treating an LP-based existence theorem as an invitation to define and study a new decision-and-witness problem.

That is a narrow negative case, not a convincing proof that no worthwhile mirror exists in any scenario. If ChoCo accepts computational problems extracted from existence theorems, this is a plausible candidate. Under the stricter requirement to anchor the mirror on a computational result of the paper, however, Theorem 1 does not qualify.
