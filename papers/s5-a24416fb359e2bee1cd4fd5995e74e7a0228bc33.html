The continuous mirror question

Given finitely many types \(T\) with class labels and compatible item categories, let the society be a rational mass distribution \(\mu\) over \(T\). Items arrive online as a finite sequence of categories with per-capita supplies \(w_o\); at each arrival the policy learns that arrival and its compatible types but not future arrivals, and irrevocably assigns masses \(x_{t,o}\geq 0\), subject to \(\sum_t x_{t,o}\leq w_o\) and \(\sum_o x_{t,o}\leq\mu_t\). Define USW as \(\sum_{t,o}x_{t,o}\), compare it with the offline maximum flow, and define \(V_i^*(Y_j)\) by optimally rematching the item mass assigned to class \(j\) to class \(i\)'s types. For every \(\alpha\in(0,1]\) and \(\varepsilon>0\), does there exist such an instance on which every non-wasteful online policy satisfying \(E[V_i]\geq\alpha E[V_i^*(Y_j)]\) for all class pairs has expected USW at most \((1/(1+\alpha)+\varepsilon)\mathrm{OPT}\)?

The model it lives in

A fluid online matching problem over a society distribution \(\mu\): types encode class and item eligibility; each arrival has a category and per-capita supply; the policy assigns compatible type mass irrevocably. The objectives are maximum matched mass and class envy-freeness measured by optimistic rematching, with randomized guarantees interpreted in expectation.

The objection that survived

The arrival information and supply granularity need specification: aggregating many small arrivals could reveal supply or horizon information earlier than in the paper's item-by-item model.

The case FOR (proponent)

The strongest positive mirror is the paper’s class-level fairness–efficiency trade-off. It has the clearest high-multiplicity witness: the hard instance uses large groups of agents with identical eligibility, so its central argument already operates on class totals.

The anchor is Theorem 5.1, proved in this paper. In the paper’s online matching model, for every \(\varepsilon>0\), there is an instance on which no possibly randomized, non-wasteful online algorithm that guarantees \(\alpha\)-CEF can achieve a USW approximation greater than
\[ \frac{1}{1+\alpha}+\varepsilon. \]
For randomized algorithms, the paper’s fairness guarantees are in expectation. The theorem is an online competitive-ratio lower bound.

Here is the continuous problem I would ask the authors to study: Fluid High-Multiplicity Online Class-Fair Matching. An instance has a finite set of item categories \(Q\) and a finite set of agent types \(T\). Each type \(t\) specifies a class \(i(t)\) and the complete set \(A_t\subseteq Q\) of categories its agents like. The society is a rational distribution \(\mu\) over \(T\), with \(\sum_t\mu_t=1\). A finite sequence of online arrivals reveals category \(q_o\) and supply \(w_o>0\) at each step. The supply is measured per capita: it scales with the population, so an individual item in a population of size \(N\) has normalized supply \(1/N\).

At arrival \(o\), an online policy irrevocably chooses \(x_{t,o}\geq 0\), the mass of type \(t\) assigned to that item. It must obey
\[ x_{t,o}=0\quad\text{if }q_o\notin A_t,\qquad \sum_t x_{t,o}\leq w_o,\qquad \sum_o x_{t,o}\leq\mu_t. \]
The solution is the resulting online allocation. Its USW is \(\sum_{t,o}x_{t,o}\), compared with the maximum feasible matching that knows the full arrival sequence. Non-wastefulness requires assigning all available supply whenever compatible, unsaturated type mass can take it.

For CEF, let \(Y_j\) record the item mass assigned to class \(j\), and let \(y_{j,o}\) be the amount of item \(o\) assigned to that class. Define \(V_i(X)=\sum_{t:i(t)=i,o}x_{t,o}\). Define \(V_i^*(Y_j)\) as the maximum flow that class \(i\)’s types could obtain by rematching the item mass \(y_{j,o}\) to their compatible types, with capacities \(\mu_t\). The allocation is \(\alpha\)-CEF when \(V_i(X)\geq\alpha V_i^*(Y_j)\) for every pair of classes; for randomized policies, use the paper’s expectation convention.

The concrete question is: for every \(\alpha\) and \(\varepsilon>0\), does there exist an instance of this fluid problem on which every non-wasteful online policy satisfying \(\alpha\)-CEF has expected USW at most \(\bigl(1/(1+\alpha)+\varepsilon\bigr)\mathrm{OPT}\)? A proof would give the continuous analogue of Theorem 5.1; a refutation would need a policy that beats this frontier for every instance in the proposed model.

The paper’s witness makes this a particularly credible mirror. It has \(k-1\) classes of \(q\) interchangeable agents each, and a final class of \(q(k-1)\) interchangeable agents. First come \(p(k-1)+q\) universal items; then each of the first \(k-1\) classes gets \(q\) items compatible only with that class. Choose \(p/q\) close to \(\alpha\). After normalizing the population \(N=2q(k-1)\), the first classes each have mass \(1/[2(k-1)]\), the last has mass \(1/2\), and there are only \(k\) types. As \(q\) grows, the support size is small relative to the represented population. A platform allocating many standardized opportunities across large, stable cohorts with shared eligibility profiles is a plausible regime for this model.

I expect the performance barrier to transfer. The proof’s key accounting is about how much mass each class receives in the universal phase and what remains for the dedicated arrivals. Those class-level inequalities make sense with real capacities and fractional flows. The paper’s own online matching setting also studies divisible matching, which makes the fluid version recognizable to its authors.

The scope is deliberately limited to Theorem 5.1’s trade-off, rather than the paper’s other fairness bounds. The main follow-up is whether the frontier is tight: can an online policy achieve \(\alpha\)-CEF and \(1/(1+\alpha)\)-USW in this model, or what is the exact best trade-off?

My weakest point is that normalizing item supplies by population size makes each arrival divisible in the fluid model. That is a co-modification of supply and outcomes, though it follows the high-multiplicity scaling and fits the paper’s divisible matching setting. If the authors require each item to remain indivisible at continuum scale, this particular mirror would need a different formulation.

The case AGAINST (opponent, writing after the proponent)

The strongest case against Theorem 5.1 as a ChoCo mirror is that its central difficulty is online uncertainty: the algorithm must commit before seeing later arrivals. A continuum of agents does not remove that uncertainty. A fluid version must also specify what the policy knows about type masses and future item categories, what the adversary may reveal, and whether fairness is measured for each outcome or in expectation. Those choices can change the model substantially. The proposed version makes reasonable choices, but its frontier would be a new competitive-analysis result, not an automatic consequence of the paper’s theorem.

That is a limited objection, though. Competitive guarantees are algorithmic results, and the paper supplies a named theorem to mirror. More seriously for the negative case, its witness already has a compact high-multiplicity description: within each class, agents have the same eligibility pattern. For fixed \(\alpha\) and \(\varepsilon\), the construction needs only finitely many types—one per class—even as \(q\), the number of agents per small class, grows. With \(N=2q(k-1)\), each small class has mass \(1/[2(k-1)]\), and the large class has mass \(1/2\). The universal and class-specific arrivals can be represented as item categories with supply scaled by \(1/N\). That is precisely the sort of regime in which a population continuum is sensible.

The strongest objection to the *particular* formulation is that it changes the arrival process along with the population: as \(q\) grows, the witness has more arrivals, each with smaller normalized supply. The limiting object needs to preserve online decisions within a stream of fluid arrivals. But this is a manageable modeling choice, and the programme explicitly permits co-modifications forced by population scaling. The finite-\(q\) instances also give a concrete starting point for the mirror.

The existing divisible-matching and asymptotic class-fairness results are relevant neighbors, but they do not answer the continuous-population computational question posed here. I therefore cannot honestly defeat this anchor. The defensible negative case is that its fit is less direct than an offline complexity problem and its continuous theorem would need a carefully specified online information model. The high-multiplicity witness itself is unusually strong evidence that the mirror is worth asking.
