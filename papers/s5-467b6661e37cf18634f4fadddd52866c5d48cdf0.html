The continuous mirror question

Given a finite support of worker types \(t\), rational masses \(\mu_t\), and for each type a task count \(n_t\) and a binary self-predicting signal channel, choose an integer quota \(n_0(t)\in\{0,\ldots,n_t\}\) for each type to maximize \(\sum_t \mu_t\,\delta_t(n_0(t))\), where \(\delta_t(k)\) is that type's EA sensitivity at quota \(k\).

The model it lives in

A continuous population of worker cohorts: type \(t\) specifies the worker's binary signal channel, peer-scoring context, and task count; \(\mu_t\) is its share of the workforce. Each worker receives an integral quota \(n_0(t)\), and the objective is mass-weighted sensitivity.

The objection that survived

The population objective separates by type, so masses do not affect quota choices and the continuum adds no new combinatorial difficulty; the proponent acknowledges this limitation.

fatal: False

What the mirror covers

The mirror covers sensitivity-maximizing EA quotas for binary, self-predicting worker types. It leaves aside the paper's SD-truthfulness results, rounding reductions, non-binary settings, and empirical comparisons.

Open questions for a prover

  • What is the exact bit complexity of evaluating the binomial-quantile quota rule when channel probabilities are binary-encoded rationals and task counts vary?
  • What finite-cohort guarantees follow from the continuous type-mass formulation when the supported worker types are fixed?

The case FOR (proponent)

The strongest positive case is narrow: Proposition C.6, proved in this paper, gives a closed-form solution to an optimization problem. For binary, self-predicting signals and \(n\) tasks, it characterizes the sensitivity-maximizing enforced quota \(\Phi=(n_0,n-n_0)\): \(n_0\) is the largest \(k\in\{0,\ldots,n\}\) for which the \(\operatorname{Bin}(n,\Pr(X_a=0))\) CDF \(F(k)\) is below \((\eta'_{00}-\eta'_{01})/(\eta'_{00}-\eta'_{01}+\eta'_{11}-\eta'_{10})\), where \(\eta'_{ij}=\Pr(X_b=j\mid X_a=i)-\Pr(X_b=j)\). This is the only anchor I would use. It is an optimization result, though the paper does not state a complexity classification such as “in P.”

A plausible population mirror is a large annotation workforce divided into a small number \(\tau\) of cohorts. A type \(t\) completely specifies a worker’s binary signal channel, peer-matching context, task count \(n\), and any other parameters the mechanism uses. The society is a distribution \(\mu\) over those types: \(\mu_t\) is the fraction of workers in cohort \(t\). This is a credible high-multiplicity regime when millions of workers share a modest number of calibrated response channels.

Call the resulting problem Population EA Sensitivity Maximization. Given the type masses and rational signal distributions, choose for each type an enforced quota \(n_0(t)\in\{0,\ldots,n\}\) to maximize the population’s mass-weighted sensitivity, \(\sum_t\mu_t\delta_t(n_0(t))\). A solution is the quota policy \(t\mapsto n_0(t)\). The original result gives a direct solution type by type using its binomial-quantile formula; scanning the \(n+1\) quotas for each supported type gives a polynomial-time procedure in \(n,\tau\), and the input bit length. This mirrors the paper’s sensitivity-optimization question while making the worker population continuous; each worker still receives an integral quota.

The scope is just the optimization of EA enforcement. A large crowdsourcing platform with repeated cohorts is a plausible setting in which the authors could recognize this as their deployment problem. Further questions include optimizing quotas under a shared enforcement budget, handling uncertain learned signal channels, and extending the result beyond binary signals.

The weak point is substantial: Proposition C.6 optimizes one worker’s quota across that worker’s tasks. The continuum over workers only aggregates these per-type optimizations, so it introduces no new combinatorial difficulty. The paper’s main results concern incentive guarantees and sensitivity, not computational complexity. If the required anchor must explicitly assert a complexity class, then this paper has no qualifying named result, and this mirror should be treated as a nearby optimization extension rather than a full ChoCo-style complexity mirror.

The case AGAINST (opponent, writing after the proponent)

The strongest case against rests on Proposition C.6 being a single-agent quota calculation. Given Alice’s binary signal structure and \(n\) tasks, it selects an integer \(n_0\). The paper’s large quantity there is the number of tasks per agent, not the number of agents. In the proposed workforce model, the objective \(\sum_t \mu_t\delta_t(n_0(t))\) separates by type: apply Proposition C.6 to each type, and the masses only weight the resulting sensitivities. They do not affect the quota choices or create a population-level computational problem.

A stronger version could impose a shared enforcement budget. Let \(y_{t,k}\) be the mass of type \(t\) assigned quota \(k\); maximizing total sensitivity subject to type-mass and budget constraints would make population masses matter. But that adds a resource-allocation question the paper does not study. The proposition supplies the sensitivity values for each type and quota; it does not establish results about pooled enforcement resources.

That is a real scope objection, but it is not enough to rule out a worthwhile mirror. A crowdsourcing platform with many workers in a few recurring binary-signal cohorts is a credible high-multiplicity setting. Its quota-policy problem is well-defined, and the pooled-budget extension is a plausible question for the authors. The paper’s result is an optimization result even though it does not classify a problem by complexity.

So the negative case is weak: the proposed mirror may be a modest extension, but I cannot honestly argue that no worthwhile continuous mirror exists. The strongest anchor survives, especially if the programme accepts a named optimization result as a computational result.
