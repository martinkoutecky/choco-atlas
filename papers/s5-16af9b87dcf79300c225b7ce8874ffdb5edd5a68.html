The continuous mirror question

Given a finite type set \(T\), rational masses \(\mu_t\) summing to \(1\), fixed existing-cascade seed memberships, candidate seed capacities by type, rational interaction rates \(\lambda_{tu}\), cascade priorities by type, and a rational budget \(\beta\), choose rational seed masses \(x_t\) with \(0\le x_t\le\mu_t\) and \(\sum_t x_t=\beta\). For each admissible population size \(N\), users of type \(t\) have independent directed edges to users of type \(u\) with probability \(\lambda_{tu}/N\). In the \(N\to\infty\) limit, each still-susceptible type-\(u\) user receives independent Poisson arrivals from type-\(t\), cascade-\(c\) users newly activated in the previous round, with mean \(\lambda_{tu}d^r_{t,c}\), and adopts the highest-priority arriving cascade. If \(q^\infty_{t,\mathrm{new}}(x)\) is the final mass of type \(t\) activated by the new cascade, compute a feasible \(x\) with \(J(x)\le\inf_y J(y)+\varepsilon\), where \(J(x)=1-\sum_{t\in T}q^\infty_{t,\mathrm{new}}(x)\) and \(\varepsilon>0\) is a requested additive error.

The model it lives in

A society is a distribution \(\mu\) over user types carrying mass. Types record candidate eligibility, existing seed memberships, cascade priorities, and block interaction rates. The decision is a seed-mass vector \(x\); the objective is the limiting fraction not reached by the new cascade under the type-level Poisson diffusion recurrence.

What the mirror covers

The mirror covers Theorem 1’s Min-MIM objective in a type-based stochastic block network. It leaves the Max-MIM hardness result, the Reverse Sandwich algorithm and its guarantee, and the experimental results unmirrored.

Open questions for a prover

  • What is the complexity of additive-\(\varepsilon\) optimization as a function of \(|T|\), input bit length, and \(\varepsilon\)?
  • Can the set-cover hardness reduction survive fractional seed masses and the block-network restriction?
  • Under what conditions does the finite-\(N\) optimum converge to the optimum of the stated limiting recurrence?

The case FOR (proponent)

The strongest mirror I see is a continuous version of Min-MIM. Its agents are users of a large platform exposed to several existing campaigns and a new campaign. A type records everything the model uses about a user: their candidate eligibility, which existing cascades seed them, their priority order over cascades when arrivals coincide, and their interaction rates with every other type. The society is a distribution \(\mu\) over these types. This fits a regime with many users but relatively few interaction and behavior profiles—for example, a large platform whose users are grouped by engagement and network role. Within the model, people of a type are exchangeable; that is the high-multiplicity assumption, not a claim that real users are literally identical.

Here is a concrete problem for the prover. The input is a finite type set \(T\), rational masses \(\mu_t\) summing to \(1\), a rational seed-mass budget \(\beta\), fixed existing-cascade seed memberships, a rational nonnegative interaction-rate matrix \(\lambda_{tu}\), and a total cascade priority order for each type. The matrix specifies a stochastic block network: in a finite population of \(N\) users, a type-\(t\) user has an independently active edge to a type-\(u\) user with probability \(\lambda_{tu}/N\). Let \(x_t\in[0,\mu_t]\) be the mass of type \(t\) seeded for the new cascade, with \(\sum_t x_t=\beta\). Existing seeds and new seeds at the same user are resolved by that type’s priority order.

The continuous diffusion is the large-\(N\) limit of this process. If \(d^r_{t,c}\) is the mass of type \(t\) newly activated by cascade \(c\) in round \(r\), then a still-susceptible type-\(u\) user receives independent Poisson counts \(Z^r_{t,c}\) with means \(\lambda_{tu}d^r_{t,c}\). If any cascade arrives, the user adopts the highest-priority arriving cascade. This gives a deterministic recurrence for the newly activated mass and hence the limiting final mass \(q^\infty_{t,\mathrm{new}}(x)\). The problem is to find a feasible \(x\) minimizing

\[ J(x)=1-\sum_{t\in T}q^\infty_{t,\mathrm{new}}(x). \]

A solution is a minimizing seed-mass vector and its objective value; approximation versions can ask for a rational feasible vector within a stated additive or multiplicative error. \(J\) is precisely the population-normalized version of the paper’s expected number of users not activated by the new cascade. The activation rule is a special case the paper itself studies, and the finite seed budget, competitive diffusion, and objective are retained.

My anchor is Theorem 1, proved in the paper. It states that Min-MIM cannot be approximated in polynomial time within the displayed factor \(\Omega(2^{\log^{1-\epsilon} n^{3-\log n}})\), unless \(\mathrm{NP}\subseteq\mathrm{DTIME}(n^{\mathrm{polylog}\,n})\). The paper’s hardness parameter \(n\) here is not the number of social-network vertices. The proof reduces from \(k^\pm\) partial set cover, using the inapproximability cited from Miettinen [46]. So the anchor is a hardness result, not a claim that an algorithm or encoding has already solved the problem.

I expect the continuous problem to be Class B: hardness transfers. The reduction’s combinatorics are expressed through cascade competition and the interaction structure, which can be represented in the type-interaction matrix; they do not inherently require millions of distinct users. But the discrete theorem does not prove this prediction by itself. Its proof chooses exactly \(k\) seed nodes, whereas the mirror chooses fractional masses \(x_t\). The central technical question is whether the reduction can survive that fractional choice, perhaps through rounding or a robust gap construction. If it can, discrete hardness transfers; if fractional choices erase the gap, the continuous problem may be tractable or hard for a new reason.

I think the authors would recognize this as their problem in a plausible large-platform regime: it asks how to seed a new cascade to minimize the share it fails to reach, under the same kind of competing cascade diffusion they study. It covers Theorem 1’s Min-MIM result only; it does not claim to mirror the paper’s whole algorithmic framework.

The weakest point is the network assumption. The paper takes a known graph and permits activation rules that can depend on which neighbors arrive; this mirror uses exchangeable stochastic blocks and type-level cascade priorities. That is a meaningful but narrower setting, and the theorem’s hardness may not survive fractional seeds. The useful next questions are therefore whether the block model is a credible high-multiplicity regime for this application, whether its finite-\(N\) optimum converges to the stated continuous optimum, and whether the set-cover reduction can be embedded without losing its hardness gap.

The case AGAINST (opponent, writing after the proponent)

Theorem 1 is the only strong anchor, and it is a real computational result. The best case against mirroring it is that its hardness lives in a particular fixed graph: the reduction represents set choices and covered elements as distinct vertices connected by an arbitrary incidence pattern. On such instances, an exact “type” must capture a vertex’s seed eligibility, cascade behavior, and interactions with the other types. In the worst case that means essentially one type per vertex. The continuous population then aggregates little.

The proposed block model avoids that problem by imposing exchangeability. A clean version would use a known complete block graph with per-edge activation probability \(\lambda_{tu}/N\), and types that include seed status and cascade priorities. That is a coherent high-multiplicity regime; its mass dynamics and fractional seed allocation are not objections in themselves. But it is a narrower model than the paper’s arbitrary known graph. Keeping only a fixed number of types removes the arbitrary incidence structure used by the hardness reduction. Letting the number of types grow can preserve that structure, but then the proposed aggregation advantage may disappear. Theorem 1 therefore does not establish that its hard instances have a useful low-support mirror.

That weakens the proponent’s Class B case, but it does not defeat the anchor: a continuous mirror could still be worth studying precisely to find out what fractional seed masses and exchangeability do to the problem. Nor does prior “continuous influence maximization” settle it: the cited formulation makes seed-activation strategies continuous on a fixed discrete network, rather than making the population continuous ([AAAI paper](https://ojs.aaai.org/index.php/AAAI/article/view/5332)).

So the strongest honest negative is a relevance concern: the paper’s theorem is about graph-specific seed selection, while the clearest population limit introduces a block structure and a type-level dynamical optimization problem. I cannot make that concern support the universal claim that no worthwhile mirror exists. A fixed-type competitive cascade model is plausible, computationally well-posed, and close enough to the authors’ seed-selection objective that they could recognize it as their problem. The negative case is weak exactly there.
