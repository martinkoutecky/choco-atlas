The continuous mirror question

Fix a finite set \(T\) of complete valuation measures on \([0,1]\) and rational masses \(\mu_t\) summing to \(1\). For each admissible \(N\) with \(N\mu_t\in\mathbb{Z}\), create \(N\mu_t\) clones of each type. In the Robertson–Webb oracle model, what is the minimum worst-case query complexity, as a function of \(N\) and \(\tau=|T|\), for a protocol to partition the cake among the clones so that every clone weakly prefers its own piece to every other piece? In particular, is a polynomial bound in \(N\) and \(\tau\) achievable?

The model it lives in

A society is the distribution \(\mu\) over a finite support \(T\) of complete valuation types. For each admissible population size \(N\), type \(t\) has \(N\mu_t\) identical clones. The decision is a partition \((C_i)_{i=1}^N\) of \([0,1]\) satisfying \(v_{t(i)}(C_i)\ge v_{t(i)}(C_j)\) for all clones \(i,j\); the objective is to minimize Robertson–Webb queries.

What the mirror covers

The mirror covers Theorem 1’s envy-free query-complexity task for populations with fixed type proportions; it leaves the theorem’s particular independent-row probability estimate, the singular-value analysis, and the paper’s existence results unmirrored.

Open questions for a prover

  • Can an envy-free protocol achieve query complexity polynomial in \(N\) and \(\tau\) for fixed type proportions?
  • How does the query complexity depend on the structure of the complete valuation measures, beyond support size \(\tau\)?
  • What probability law on fixed complete valuation types yields a meaningful high-probability analogue of Theorem 1?

The case FOR (proponent)

The strongest mirror I can defend is a high-multiplicity version of the paper’s Robertson–Webb query problem. The continuous society is a distribution \(\mu\) over complete valuation types: a type is an absolutely continuous probability measure on the cake, and agents of the same type have identical valuations. Its mass \(\mu_t\) is the fraction of the population with that valuation. For population size \(N\), take \(N\mu_t\) exact clones of each type, when those counts are integral. The protocol still has to partition the single cake among all \(N\) agents and make the result envy-free; its objective is to minimize the number of cut and evaluation queries. Thus the question is about the high-multiplicity limit with \(\mu\) fixed as \(N\) grows, not about making the cake or the set of possible bundles continuous.

My lead anchor is Theorem 1, proved in this paper. It says that under either \(H_1\)—each player’s values on the \(N\) witness intervals are an independent uniform draw from the standard simplex—or \(H_2(\varepsilon)\)—normalized positive baseline values with independent, bounded, mean-zero perturbations—there is a Robertson–Webb protocol that returns an envy-free division and, for every \(b>4\), satisfies
\[ \mathbb{P}\!\left(C(\mu_1,\ldots,\mu_N)\ge N^{7+b}\right) =O\!\left(N^{-(b-1)/3+1+o(1)}\right). \]
In particular, the probability of using at least \(N^{12}\) queries tends to zero. The paper proves this result using Webb’s algorithm and a small-singular-value estimate; the random-matrix theorem it invokes is cited from Tao and Vu.

Here is the continuous question I would hand to a prover: Type-Distribution Envy-Free Query Complexity. Given \(N\), a finite set \(T\) of valuation types, and rational masses \(\mu_t\) summing to one with \(N\mu_t\in\mathbb{Z}\), form the \(N\)-agent population with exactly \(N\mu_t\) clones of type \(t\). Draw the valuation of each type independently according to \(H_1\) on the \(N\) witness intervals, and give the protocol Robertson–Webb oracle access to the clones, along with their type identities and multiplicities. It must output a partition \((C_i)_{i=1}^N\) satisfying \(v_i(C_i)\ge v_i(C_j)\) for every pair \(i,j\). Characterize the least query growth achievable as \(N\) grows with \(\mu\) fixed; in particular, determine whether a protocol has a polynomial high-probability query bound in \(N\), with explicit dependence on support size \(\tau=|T|\).

I would expect a tractable, type-aware result—perhaps polynomial in \(N\) and \(\tau\)—but I would not predict that Theorem 1’s exponent or tail bound survives. Its proof relies on independent valuation rows, whereas here each type row is repeated and the witness matrix has rank at most \(\tau\). Further questions include whether \(\tau\) is enough to control query complexity, what lower bounds depend on \(N\) even for fixed \(\tau\), and how robust any bound is when nominally identical types differ slightly.

This is a plausible mirror because it keeps the paper’s underlying task, scarce cake, envy-free output, and query model while treating the population as type proportions. The paper’s authors could recognize it as their algorithmic problem in a high-multiplicity regime. But the weakness is substantial: Theorem 1 itself assumes essentially the opposite regime, with independent preferences across agents, and does not establish the proposed type-compressed bound. Also, the formulation is a limit of finite clone populations, not a standalone allocation to a literally atomless set of people. If that distinction fails the authors’ recognition test, this mirror fails with it. I would not stretch the claim to cover the paper’s existence results or to say that its use of divisible cake already continuizes the population.

The case AGAINST (opponent, writing after the proponent)

Theorem 1 is a genuine computational result: it bounds the query complexity of an envy-free protocol. The strongest negative case is that its complexity-bearing setup does not itself define a stable high-multiplicity model. Under \(H_1\), the \(n\) players have independent valuation rows, and the witness partition also changes with \(n\). Repeating a fixed set of valuation types instead gives repeated rows; with support size \(\tau<n\), the witness matrix is singular and Webb’s algorithm is never used. So the proponent’s version needs a new population model and a new stochastic family. That is a substantial gap in the proposed mirror, though by itself it does not rule out a different, worthwhile question.

The natural replacement is a population of clones: each type has many agents with the same valuation, and the protocol still gives a separate piece to every agent. But then envy-freeness has a strong consequence. For any two clones of type \(t\), each must weakly prefer their own piece to the other’s. Since their valuations are identical, this forces \(\mu_t(C_i)=\mu_t(C_j)\). Thus every type must value all \(N\) allocated pieces equally. The clone version is therefore a simultaneous exact-division problem for the supported valuations. That may be worth studying, but its central constraint is exact sharing, not the paper’s analysis of how near-linear dependence among independent valuations drives query cost.

There is an awkward choice of limit. Keep a finite cake and a truly atomless population, and almost every individual receives a set of zero cake measure; for absolutely continuous valuations, envy then becomes vacuous. Replace individual allocations with type-level average bundles, and those averages do not by themselves ensure that each person’s realized piece is envy-free. Add enough replicated cake to give each person a full copy, and scarcity can disappear. These choices make it hard to preserve the paper’s individual envy condition as a nontrivial mass-level object.

This is the best case against the anchor, but it does not establish the universal claim. A finite-clone regime is plausible, and the resulting exact-division query problem is recognizable as a computational question. I would therefore call the negative case weak: the proponent’s specific \(H_1\) formulation is not well-founded as stated, but a continuous mirror of Theorem 1 remains defensible.
