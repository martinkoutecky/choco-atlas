The continuous mirror question

Given a capacitated shared supply network \(G\), a sink player \(r\), and \(\tau\) terminal types with rational masses \(\mu_t>0\), \(\sum_t\mu_t=1\), source locations \(s_t\), and per-agent demands \(d_t\), choose path flows \(x_{tP}\geq 0\) satisfying \(\sum_P x_{tP}\leq \mu_t d_t\) and the network capacities. Type \(t\)'s per-capita payoff is \(u_t=(\sum_P x_{tP})/\mu_t\), and the sink's payoff is total routed mass. Coalitions may include the sink and any submasses \(q_t\leq\mu_t\), routing their demands through the same network; coalitions without the sink have no commodities. Does there exist a polynomial-time algorithm, in the network size, \(\tau\), and input bit length, that computes a core allocation simultaneously maximizing the sink's payoff and \(\min_t u_t\) over feasible allocations?

The model it lives in

A single-sink routing game with a continuum of terminal organizations represented by types \(t\) of masses \(\mu_t\), per-agent demands \(d_t\), and per-capita payoffs \(u_t\), sharing a capacitated transit network and a distinguished sink player. The decision variables are path-flow masses \(x_{tP}\); stability is tested against deviations by the sink and arbitrary submasses of each type.

The objection that survived

In the paper, coalition membership determines which supply vertices and paths are available; the mirror makes transit access shared infrastructure. The proponent acknowledges this shift and gives a plausible setting for it, but does not establish that the authors would treat access as immaterial to their game.

What the mirror covers

The mirror covers Theorem 2's simultaneous throughput and fairness result for single-sink games. It leaves aside the path and spider core algorithms, the approximate-core result, and the empirical-core experiments.

The case FOR (proponent)

The best positive case is for a mass single-sink routing game, anchored on Theorem 2. The paper proves here that for any capacitated supply graph and any single-sink commodity graph, a polynomial-time algorithm returns a core payoff that simultaneously attains maximum social welfare and maximum LP fairness. The theorem is proved in this paper; it is not just a cited result. The paper gives no named hardness result, so this is an algorithmic lead.

In the mirror, an instance has a capacitated supply graph \(G\), a distinguished sink \(r\), and \(\tau\) terminal types. Type \(t\) has positive rational mass \(\mu_t\), with \(\sum_t\mu_t=1\), a common source location, and per-agent demand \(d_t\) to the sink. The mass represents a large cohort of interchangeable terminal organizations. A solution chooses nonnegative routed masses \(x_{tP}\) on paths \(P\) from type \(t\)’s source to \(r\), subject to \(\sum_{P}x_{tP}\le\mu_t d_t\) and the supply capacities \(c_v\) on \(G\). Type \(t\)’s per-capita payoff is \(u_t=(\sum_P x_{tP})/\mu_t\); the sink’s payoff is total routed mass.

Call a route a solution to Mass Single-Sink Core–Fairness if it is in the core against every fractional-cohort deviation and simultaneously maximizes throughput and population fairness, \(\min_t u_t\). A deviation selects masses \(q_t\le\mu_t\). If it includes the sink, its routing is limited by those masses’ demands and the same supply capacities; if it omits the sink, the single-sink commodity graph gives it no routes. A route maximizing total throughput is core: a sink-containing coalition cannot strictly improve the sink’s payoff, since its total routed mass cannot exceed the grand coalition’s maximum. Thus the problem asks for an underlying stable routing allocation, not for an encoding.

The regime is many endpoint organizations—say, local access networks with the same source attachment, peering profile, and per-capita traffic demand—sharing a common transit fabric. The population size \(N\) can be very large while \(\tau\), the number of distinct profiles, remains modest. Capacities scale with population, and aggregate routed mass is fractional; each member of a type receives the type’s average payoff. The flow-vector region for a single sink has the polymatroid structure used in the paper’s proof, so this mirror should be Class A: a polynomial-time flow/optimization algorithm is plausible in the graph size, \(\tau\), and rational input bit length. Further questions include whether the simultaneous optimum persists with several sinks, or with more general commodity graphs.

The case is strongest for Theorem 2 alone. It covers that single-sink result; it does not claim a mirror for the paper’s path and spider algorithms or its empirical-core experiments. Its weakest point is that the sink remains a distinguished strategic atom, and the supply fabric is available to sink-containing coalitions as shared infrastructure. That is a genuine model choice: in the paper, supply-graph nodes are players and coalitions use induced subgraphs. A reader could reject this as too large a change. The defense is that a shared transit operator and many interchangeable endpoint organizations are a recognizable routing regime, and the mirror preserves the paper’s central question—whether a stable coalition outcome can achieve efficient and fair routing—while making the endpoint population itself continuous.

The case AGAINST (opponent, writing after the proponent)

Theorem 2 is the one serious anchor: it proves a polynomial-time algorithm for simultaneously maximizing throughput and fairness in single-sink games. The difficulty for a mirror is that the paper’s population is the supply graph’s vertex set. A vertex’s position in the supply graph and its incident commodities determine which coalitions can route flow, since a coalition uses the induced graph \(G[S]\). A complete type must therefore capture that network role, not just a capacity or demand profile. In a general network, nodes with similar capacities and demands but different neighbors are different types; the number of types can grow with the network.

The proposed terminal-cohort model avoids that problem by making the network fixed infrastructure available to any coalition containing the sink. That is a coherent routing model, but it changes the coalition boundary. In the paper, transit vertices are players whose membership matters. In the proposed model, they are resources a coalition can use without recruiting them. It also makes stability automatic: a coalition without the sink has no commodities to route, while one with the sink cannot strictly improve the sink’s payoff beyond the grand coalition’s maximum throughput.

The strongest repaired version would use many genuinely identical terminal agents with identical source attachments and per-agent demands, and aggregate each type into a representative terminal with demand \(\mu_t d_t\). That is sensible, but it reduces the mirror directly to the paper’s finite single-sink instance with \(\tau\) terminals; the per-capita payoff is just aggregate flow divided by \(\mu_t\). The fairness and throughput computation is then the same finite polymatroid optimization, while the mirror adds no new coalition structure for the theorem to analyze. Making the transit actors part of the continuous population instead requires their full network roles in the types, which is precisely where the small-support premise becomes hard to sustain.

That is the best case against this anchor: the paper’s theorem concerns strategic participation by network vertices, whereas its cleanest continuous-population version treats the network as fixed infrastructure and collapses to a representative finite instance. It is a meaningful adjacent model, but a weak basis for saying this paper has no worthwhile continuous mirror. A large, interchangeable population of terminal organizations sharing a fixed network remains plausible, and the paper does not rule it out.
