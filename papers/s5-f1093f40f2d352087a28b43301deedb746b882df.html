The continuous mirror question

Given finitely many location types \(T\), coordinates \(p_t\in\mathbb{R}^3\), and positive rational masses \(\mu_t\) summing to \(1\), represent the population by an identity space \(\Omega_\mu=\bigsqcup_{t\in T}(\{t\}\times[0,\mu_t))\) with Lebesgue measure. Does there exist a measurable partition of this population into rooms of exactly three individuals such that, for every other rooming distinct modulo null sets, the measure of individuals whose sum of distances to their roommates decreases is strictly greater than the measure whose sum increases?

The model it lives in

Use finitely many location types with rational masses and fixed individual identities within each type. The decision variable is a measurable partition into rooms of three; compare two roomings by the Lebesgue measure of individuals who strictly prefer each one, using the paper's distance-sum preferences.

What the mirror covers

The mirror covers Theorem 1's existence question for strictly popular roomings. It does not mirror the discrete reduction itself or address the paper's conjectures about other room sizes, ordinary popularity, or two-dimensional locations.

Open questions for a prover

  • Does every finite-support atomless instance lack a strictly popular rooming under identity-preserving comparison modulo null sets?

The case FOR (proponent)

The best affirmative case is narrow: Theorem 1 is the paper’s one eligible anchor. Proved here, it says that deciding whether a 3D-Euclidean Stable Roommates instance with room size fixed to \(3\) has a strictly popular partition is co-NP-hard. The reduction constructs a game from a PC-X3C instance so that an exact cover exists iff the game has no strictly popular outcome. If there is no exact cover, the constructed game has a unique popular outcome, which is strictly popular; if there is an exact cover, it has multiple popular outcomes and none is strictly popular.

A direct population version is 3D-Euclidean Strict-Popular Rooming\(_\infty\). Its input is a finite set of location types \(T\), with exactly represented 3D coordinates \(p_t\), and positive rational masses \(\mu_t\) summing to \(1\). Let \(\Omega_\mu=\bigsqcup_{t\in T}(\{t\}\times[0,\mu_t))\), with Lebesgue measure. A solution is a measurable partition \(\Pi\) of this common population into rooms of exactly three individuals. Each individual receives an integral room; only the mass assigned to each type and room profile can be fractional. For an individual \(a\), let \(D_a(\Pi)\) be the sum of their Euclidean distances to their two roommates. Define

\[ M(\Pi,\Pi')= \lambda\{a:D_a(\Pi)<D_a(\Pi')\} - \lambda\{a:D_a(\Pi')<D_a(\Pi)\}. \]

The decision question is whether there exists a rooming \(\Pi\) such that \(M(\Pi,\Pi')>0\) for every distinct rooming \(\Pi'\) of the same population. This preserves the paper’s room size, distance-based preferences, and strict majority comparison between the *same agents* across outcomes.

A plausible regime is a large co-housing intake in which residents come from many repeated origin or workplace clusters, and roommate compatibility depends on how close those locations are. There might be hundreds of thousands of residents but only dozens of location types. The authors should recognize the model: the population changes, while their rooming and popularity questions remain intact.

I would not expect Theorem 1’s co-NP-hardness to transfer. Its construction uses an exact-cover choice among individual gadgets; the PC-X3C instances are regular, so assigning mass \(1/3\) to every set already gives a fractional exact cover. More seriously, the direct atomless version appears to have a zero-margin exchange in every instance: some positive mass of type \(t\) occupies rooms with the same type profile. Split those room instances into two equal portions and exchange their type-\(t\) occupants. All room profiles remain unchanged, and every affected person—and their roommates—has the same distance-based preferences as before. The resulting partition differs on positive mass but has popularity margin \(0\). Thus, under this identity-preserving definition, I expect the high-multiplicity decision problem to be uniformly no, hence formally in P for a degeneracy reason. This is an inference from the model, not a result of the paper.

That exchange is also the mirror’s weakest point. If outcomes identify roomings that differ only by relabeling identical agents, the exchange ceases to be a distinct alternative; then type masses alone do not determine popularity margins between roomings, because those margins depend on how the same agents are paired across outcomes. A coupling-based, type-quotiented definition might be worth investigating, but it would be an extension rather than this direct mirror. So the positive case is that Theorem 1 motivates a precise, author-recognizable population question and a useful boundary for strict popularity. It is a weak candidate for a substantive hardness-dissolution result: the exact finite hardness does not survive this high-multiplicity regime in an interesting way.

The case AGAINST (opponent, writing after the proponent)

Theorem 1 is the paper’s one clear computational anchor, so the negative case cannot rest on a lack of results. The difficulty is that strict popularity is unusually sensitive to having many indistinguishable agents.

In the intended high-multiplicity regime, fix \(\tau\) location types and let the population grow. There are only \(\binom{\tau+2}{3}\) possible room profiles. Once there are more rooms than profiles, every rooming contains two rooms with the same profile. Swap one occupant of a shared type between those rooms. Their location types—and therefore every agent’s distance-based utility—stay the same. The partition changes, but its popularity margin against the original is zero. In an atomless version, the same exchange can be made between equal positive-mass portions of rooms with that profile. So the identity-preserving mirror has a symmetry obstruction built into its strictness condition, rather than the substantive population-level choice that makes a continuous complexity question attractive.

Quotienting away exchanges of identical agents removes that obstruction only by making popularity hard to define. The paper compares the *same agents* across two partitions. A type-profile description records how much mass receives each room profile, but not which members of a type receive which profiles in both outcomes. Without that correspondence, the majority margin is not determined; supplying a coupling or another alignment rule changes the comparison being studied. Keeping a common identity space restores the paper’s comparison, and with it the zero-margin exchanges.

A nonatomic distribution over locations in all of \(\mathbb R^3\) is the strongest escape: it could avoid positive-mass cohorts at a single location. But that moves away from the finite-support high-multiplicity mirror. It requires a representation for an arbitrary spatial measure and retains an identity-sensitive partition into rooms of three, rather than reducing the problem to masses over a moderate set of types. That might support a separate geometric-continuum project, but it is a weaker fit for ChoCo’s population-aggregation programme.

This case is strongest for the paper’s actual anchor and intended finite-type regime. It does not rule out every continuous spatial formulation; it argues that the natural high-multiplicity mirror either loses strict popularity to indistinguishable-agent exchanges or needs a new identity-comparison rule.
