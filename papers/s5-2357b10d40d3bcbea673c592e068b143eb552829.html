The continuous mirror question

Given rational type masses \(\mu_t\) and exactly two approved rational population shares \(A_t=\{a_t,b_t\}\subset(0,1]\) for each type, decide whether the population can be partitioned into coalitions so every unit of mass is assigned to a coalition whose share its type approves. Equivalently, for each distinct approved share \(a\), do there exist nonnegative allocations \(x_{t,a}\) and an integer coalition count \(q_a\ge 0\) satisfying \(\sum_{a\in A_t}x_{t,a}=\mu_t\) for every type \(t\), and \(\sum_{t:a\in A_t}x_{t,a}=a q_a\) for every share \(a\)?

The model it lives in

An atomless society has finitely many types \(t\), each with rational mass \(\mu_t\), and each type approves exactly two rational coalition shares \(A_t=\{a_t,b_t\}\). Let \(x_{t,a}\) be type \(t\)’s mass assigned to coalitions of share \(a\), and let \(q_a\in\mathbb Z_{\ge0}\) count those coalitions. Feasibility requires \(\sum_{a\in A_t}x_{t,a}=\mu_t\) for each type and \(\sum_{t:a\in A_t}x_{t,a}=a q_a\) for each share. The computational question is whether such a partition exists, with complexity measured in the number of supported types and the input bit length.

What the mirror covers

The mirror asks about the share-scaled counterparts of Theorem 22’s exact-two-size hardness and Theorem 3’s interval algorithm. It leaves the deletion, maximization, weighted, single-peaked-cost, and general egalitarian results unaddressed.

Open questions for a prover

  • Does Mass-Wonderful-2 admit a polynomial-time algorithm in the number of types and input bit length, or is it NP-hard because of the integer coalition counts?

The case FOR (proponent)

The strongest mirror I see is for societies divided into a small number of large coalitions. Think of a large association or employer with many members but relatively few preference profiles. A member cares about the size of their division as a share of the whole organization; members with the same approval set are one type. The type mass \(\mu_t\) is that profile’s fraction of the population. This is a narrower regime than an ordinary hiking trip, but it keeps the paper’s central question: can everyone be placed in a coalition whose size they approve?

Here is the common model for my two mirrors. Each type \(t\) has a set \(A_t\subset(0,1]\) of approved coalition mass fractions. A solution partitions the population mass into finitely many coalitions. If coalition \(j\) has mass \(a_j\), every type contributing positive mass to it must approve \(a_j\); all mass of every type must be assigned. The decision is whether such a partition exists, and a solution reports the coalition sizes and the type mass in each coalition. Types may be split across coalitions. The number of coalitions remains an integer.

For the lead, Mass-Wonderful-2 asks this question when each type approves exactly two rational shares, \(A_t=\{a_t,b_t\}\). It mirrors Theorem 22: deciding WONDERFUL-PARTITION is NP-complete even when every agent approves exactly two group sizes. The paper proves this theorem here, by reducing X3C through its ORIENTATION problem; it also notes that Darmann et al. had established hardness when approval sets have size at most two. This is the anchor I consider strongest because it gives the mirror a concrete complexity question: does the exact-two-sizes hardness survive when type mass can be divided?

The question has a compact representation. Let \(x_{t,a}\) be the mass of type \(t\) assigned to coalitions of size \(a\), and \(q_a\) the integer number of such coalitions. Feasibility asks for
\[ \sum_{a\in A_t}x_{t,a}=\mu_t,\qquad \sum_{t:a\in A_t}x_{t,a}=a q_a,\qquad q_a\in\mathbb Z_{\ge0}. \]
This is still a partition question, not a question about an encoding: the equations say that all type mass is assigned and that the mass assigned to size \(a\) fills an integer number of coalitions of that size. Because the population is atomless, the assigned type masses can be split among those coalitions.

I would expect Mass-Wonderful-2 to be continuum-specifically hard, though this is a conjecture, not a result of the paper. Fractional type assignment may break the all-or-nothing choices used by the X3C reduction, so Theorem 22’s hardness does not simply transfer. But the integer coalition counts \(q_a\) leave an arithmetic feasibility problem. The follow-up is whether that integrality still supports NP-hardness, or whether fractional mass turns the problem into a tractable flow or optimization problem. A precise complexity target is polynomial time in the number of supported types and the binary input length of their masses and approved shares.

A second question, Mass-Wonderful-Interval, uses the same model with rational approval intervals \(A_t=[a_t,b_t]\subset(0,1]\). It mirrors Theorem 3: for \(n\) agents with interval approvals over integer group sizes, deciding whether a wonderful partition exists and computing one if it does takes \(O(n^5)\) time. The paper proves this result here using a dynamic program based on an earliest-due-date structure. For the mass version, interval endpoints divide the size range into only \(O(\tau)\) regions with the same eligible types, where \(\tau\) is the support size. A solution can be represented by a coalition count and assigned type mass for each region. I expect Class A, because the interval order and divisible type mass suggest a structured dynamic program or optimization method. The open issue is whether it runs in time polynomial in the binary input length, rather than only in a numerical scale such as the reciprocal of the smallest allowed coalition share.

These are the two results this mirror covers: the exact-two-size hardness and the interval-approval algorithm. The interval result supplies a useful contrast to the lead rather than a claim that Theorem 3 directly solves the new model. Likewise, Theorem 22 motivates the hardness question but does not establish hardness after mass splitting.

The model is recognizable as anonymous hedonic coalition formation: preferences still depend only on coalition size, and “wonderful” still means every participant approves their coalition. Its scale-free version also gives a replication dictionary. A rational mass solution can be scaled to a finite population in which type counts and coalition sizes are integral, with approved sizes scaled by the same factor. Conversely, a partition in such a scaled instance gives a mass solution. So the question is whether the discrete complexity survives when the relevant regime is a large population with a small set of shared types.

My weakest point is the scale choice. Ordinary hiking groups are usually small in absolute numbers; this mirror instead fits divisions whose sizes scale with the institution. A referee could reasonably say that this is not the hiking problem people usually mean. I think the case still holds for the paper’s broader anonymous hedonic model: it studies approval of group size, and relative-size preferences describe a plausible instance regime of that same problem. The mirror makes that regime explicit and asks whether the paper’s complexity boundary changes when the society is represented by type mass.

The case AGAINST (opponent, writing after the proponent)

The paper gives genuine computational results, so there is no decisive “nothing to mirror” objection. The strongest negative case is that its two main results concern finite group cardinalities, and the natural high-multiplicity limit for finite groups dissolves the partition problem.

Keep group sizes as integers while letting the population grow. A type then has a fixed approval set of integer sizes, and the solution can be described by densities of finite group configurations. If \(z_t\) counts type-\(t\) members in a group, let \(y_z\) be the density of groups with configuration \(z\). The population constraints are \(\mu=\sum_z y_z z\). Whenever each type approves at least one size \(s_t\), the configuration \(z=s_t e_t\)—a group made entirely of type \(t\)—can serve that type’s whole mass at density \(\mu_t/s_t\). So the continuum no longer has the packing obstruction that makes WONDERFUL-PARTITION interesting: each type can be handled independently, with fractional group counts.

That degeneration undercuts both anchors in their most faithful local-size version. Theorem 22’s exact-two-size hardness depends on finite agents and integer group counts; splitting type mass across a continuum of groups removes that divisibility barrier. Theorem 3’s interval algorithm likewise has no comparable obstacle left to resolve. This is a permitted kind of failure for a mirror: the central combinatorial object has vanished in the limit.

The proponent avoids that collapse by scaling group sizes with the population. In Mass-Wonderful-2, each coalition occupies a positive share of the organization and the number \(q_a\) of coalitions of each share remains integral. That is a coherent model for a large organization with a few macro-divisions. Its exact-two question is well-posed, and the integer counts leave a real arithmetic problem. The same scale choice underlies Mass-Wonderful-Interval.

The difficulty for the negative case is that these are macroscopic coalitions, not the finite hiking groups in the paper. When approved shares stay bounded away from zero, adding more members does not produce more coalitions; it produces larger versions of the same few blocs. The model’s complexity therefore sits in allocating mass among a small number of population-scale divisions. The proponent’s replication dictionary is exact for instances whose group sizes grow in proportion to population, but it does not establish that this is the high-multiplicity regime of the paper’s original problem. If shares shrink toward zero to recover many ordinary-sized groups, the local-size degeneration returns.

That leaves a real residual case for the proponent: large associations or employers might have a few divisions whose preferred sizes are expressed as fractions of the whole organization. If the authors regard those as natural anonymous hedonic coalitions, the exact-two mirror could be worthwhile. The paper alone does not make that scenario compelling; the hiking motivation points toward bounded-size groups, where the continuous version loses its substance. So the case against is strongest as a scope and naturalness argument, and it remains vulnerable to a convincing macro-division application.
