The continuous mirror question

Given a finite type set \(T\), population masses \(\mu\in\Delta(T)\), item classes \(J=[r]\), rational per-capita supplies \(\beta\in\mathbb{Q}_{\ge0}^r\), and additive values \(v_t(j)\in\{0,1,2\}\), define \(\lambda_t(\beta)\) as the largest \(\lambda\) for which a unit-mass distribution \(y\) over integral bundles \(q\in\mathbb{Z}_{\ge0}^r\) satisfies \(\sum_q y_q=1\), \(\sum_q q_jy_q\le\beta_j\), and \(y_q>0\Rightarrow\sum_jq_jv_t(j)\ge\lambda\). Decide whether, and compute, a mass allocation \(x_{t,q}\ge0\) with \(\sum_qx_{t,q}=\mu_t\), \(\sum_{t,q}q_jx_{t,q}\le\beta_j\), and \(x_{t,q}>0\Rightarrow\sum_jq_jv_t(j)\ge\lambda_t(\beta)\) for every populated type.

The model it lives in

A high-multiplicity fair-division model: types \(t\in T\) carry mass \(\mu_t\), item classes have per-capita supply \(\beta_j\), each agent receives an integral bundle \(q\), and variables \(x_{t,q}\) assign type mass to bundles subject to supply constraints; the objective is to meet every type's exact MMS threshold.

The objection that survived

The opponent's best point is that the proponent has not proved \(\mu_i(N,N\beta)\to\lambda_t(\beta)\), finite-support or rounding bounds, or a polynomial type-level implementation.

fatal: False

What the mirror covers

The mirror covers the general \(\left(\frac{2}{3}-\varepsilon\right)\)-approximation and the exact \(\{0,1,2\}\) case in the high-multiplicity regime. It leaves the \(n=3\) specialization, the probabilistic results, and the paper's other structural lemmas without a stated continuous counterpart.

Open questions for a prover

  • Does \(\lambda_t(\beta)\) equal the limit of \(\mu_i(N,N\beta)\) along integral scalings \(N\), and can optimal bundle distributions have polynomially bounded support?
  • Can the exact \(\{0,1,2\}\) problem be solved in time polynomial in \(\tau\), \(r\), and the bit length of \(\mu\) and \(\beta\), rather than expanded multiplicity?
  • For general additive values, is the configuration formulation tractable, or is its integral-bundle pricing problem hard?

The case FOR (proponent)

I think there is a defensible mirror, provided it is built in the high-multiplicity regime of repeated goods. The population becomes continuous; the goods do not.

Take a finite catalogue \(J=[r]\) of item classes. Item class \(j\) has supply \(\beta_j\) per unit population, and a voter type \(t\in T\) has additive value \(v_t(j)\). A society is \(\mu\in\Delta(T)\). Thus \(x_{t,q}\) denotes the mass of type \(t\) receiving the integral bundle \(q\in\mathbb{Z}_{\ge 0}^r\), where \(q_j\) is the number of copies of item class \(j\). Feasibility means

\[ \sum_q x_{t,q}=\mu_t \]

for every \(t\), and

\[ \sum_{t,q}q_jx_{t,q}\le \beta_j \]

for every item class \(j\). The individual bundles remain indivisible; only the assignment of a continuum of agents to bundles is fractional.

This is exactly the high-multiplicity limit of instances with \(N\mu_t\) agents of type \(t\) and \(N\beta_j\) copies of item \(j\). The type is a complete additive valuation vector, so this is not throwing away individual information within a type.

For each type \(t\), define its continuum maximin share by

\[ \lambda_t(\beta)= \sup\left\{\lambda: \begin{array}{l} \exists y_q\ge 0,\ \sum_q y_q=1,\\ \sum_q q_jy_q\le\beta_j\ \forall j,\\ y_q>0\Rightarrow \sum_jq_jv_t(j)\ge\lambda \end{array} \right\}. \]

This is the high-multiplicity limit of the paper’s \(\mu_i(n,M)\): it is the value that a type could guarantee by partitioning the aggregate stock into unit population mass of integral bundles and receiving the least valuable bundle. It is not automatically proportional, since scarce indivisible item classes can still create packing bottlenecks.

My lead mirror is therefore:

\[ \textbf{Continuous Approximate-MMS:} \]

Given \((T,\mu,J,\beta,v)\) and constant \(\varepsilon>0\), find a feasible mass allocation \(x\) such that, for every type \(t\) with \(\mu_t>0\),

\[ x_{t,q}>0 \quad\Longrightarrow\quad \sum_jq_jv_t(j)\ge \left(\frac23-\varepsilon\right)\lambda_t(\beta). \]

The expected question is whether this can be solved in time polynomial in \(r,\tau\), the encoding length, and—for variable accuracy—the relevant dependence on \(\varepsilon\). I expect this to be Class A: a configuration formulation with exponentially many bundle variables, attacked through high-multiplicity max-min packing, knapsack-style pricing, and an aggregated version of the paper’s matching argument.

The anchor is Theorem 4.1, proved in this paper. It states that for any set \(N\) of agents with additive valuations and any set \(M\) of goods, and for every constant \(\varepsilon>0\), Algorithm 3 runs in polynomial time and returns an allocation \((S_1,\ldots,S_n)\) satisfying

\[ v_i(S_i)\ge \left(\frac23-\varepsilon\right)\mu_i(n,M) \]

for every agent \(i\). The algorithm first obtains approximate maximin values using Woeginger’s PTAS and then uses the recursive matching procedure REC-MMS. Replacing named agents by masses of identical valuation types preserves the benchmark and the indivisibility of each assigned bundle. The continuous problem is not a different fairness notion; it is the same guarantee after passing to the high-multiplicity limit.

A strong supporting anchor is Theorem 5.5, also proved here. It states that if every item value \(v_{ij}\) belongs to \(\{0,1,2\}\), then an exact maximin-share allocation can be found in time

\[ O(nm\log m), \]

so that \(v_i(T_i)\ge\mu_i(n,M)\) for every agent. Its continuous mirror is:

\[ \textbf{Exact Continuous MMS}_{\{0,1,2\}}: \]

Given \(\mu\), \(\beta\), and \(v_t(j)\in\{0,1,2\}\), find a feasible mass allocation \(x\) satisfying

\[ x_{t,q}>0 \quad\Longrightarrow\quad \sum_jq_jv_t(j)\ge\lambda_t(\beta) \]

for every populated type \(t\).

This exact mirror is particularly credible. For rational \(\mu\) and \(\beta\), scale them by \(N\), apply Theorem 5.5 to the resulting finite high-multiplicity instance, and aggregate the resulting allocations by type and bundle. Taking a limit yields an exact continuum allocation. The paper’s bucket, row-reversal, and graph-colouring structure also suggests a compressed weighted version rather than merely an existence argument.

The paper contains an unnumbered statement that deciding whether one agent’s maximin share reaches a threshold is NP-complete, but it does not present that as a numbered hardness theorem. I therefore would not manufacture a hardness anchor. The two numbered anchors above are positive algorithmic results proved in the paper.

The main weakness is genuine: the theorem’s polynomial running time is measured in the explicitly listed agents and goods, whereas the continuous instance encodes potentially enormous multiplicities through rational masses. It is not automatic that Algorithm 3 or Algorithm 6 compresses to polynomial time in \(\tau\), \(r\), and the bit length. That compressed-complexity question must be proved, not assumed. Still, the mirror remains faithful: the population is the continuous object, bundles remain integral, MMS is retained through its high-multiplicity limit, and the paper’s matching and packing machinery gives a plausible route to tractability.

The case AGAINST (opponent, writing after the proponent)

The strongest negative case defeats the *proponent’s evidence*, but not honestly the universal claim.

With the paper’s goods held fixed, the natural high-multiplicity limit degenerates. If \(N\) clones of each type face the same finite set \(M\), then

\[ \mu_t(N,M)\le \frac{v_t(M)}{N}\longrightarrow 0. \]

Thus every constant-factor MMS guarantee eventually becomes vacuous. The proponent avoids this only by scaling the goods as well, replacing \(M\) by \(N\beta\) copies of item classes. That is a coherent repair, but it is a substantive extension: the object is no longer the paper’s finite-goods problem, but an infinite-column configuration problem over integral bundles.

This gap is fatal to the claimed inheritance from Theorem 4.1. Its polynomial running time is polynomial in the explicit numbers \(n\) and \(m\), not in the bit length of rational masses. Clearing denominators can produce \(N\) exponentially large, so running Algorithm 3 on the cloned instance gives no compressed algorithm. Its matching graph has \(N\) agent vertices, its PTAS sees \(N\beta\) goods, and its recursion is not shown to quotient by valuation types. Aggregating the output after an exponential computation is not a polynomial continuous algorithm. The proposed configuration LP may be worthwhile, but it is an unproved new problem, not a consequence of Theorem 4.1.

The same objection is sharper for Theorem 5.5. The theorem guarantees \(v_i(T_i)\ge \mu_i(N,N\beta)\), whereas the proposed mirror requires value at least \(\lambda_t(\beta)\). “Scale and take a limit” does not establish that \(\mu_i(N,N\beta)\) converges to \(\lambda_t(\beta)\), that optimal bundle distributions have finite rational support, or that allocations can be chosen with bounded support so that the limit remains computationally representable. The \(O(nm\log m)\) algorithm also becomes an algorithm on \(N\) cloned agents and \(N\beta\) goods; its bucket reversals and graph colouring do not automatically become a weighted type-level procedure.

A better formulation would classify goods by their complete valuation columns, use per-capita supplies, prove a finite-support theorem, and then establish either a configuration-LP algorithm or a rounding equivalence. That would be a legitimate high-multiplicity research question. It could even be a strong one. But it is precisely why the negative case cannot honestly claim that no worthwhile mirror exists: the paper’s MMS results naturally induce this nondegenerate population-and-supply limit.

So I would reject the proponent’s claim that the two theorems already yield continuous algorithms, but I would not reject the mirror itself. The defensible verdict is “promising extension, with major normalization, convergence, and compressed-complexity obligations,” not “no continuous mirror in any scenario.”
