The continuous mirror question

Given a finite candidate set \(C\), a target \(c\in C\), and a distribution \(\mu\) over \(\tau\) voter types, compute the exact critical endowment \(\omega^*(c;\mu)\) and a type coalition attaining it. Each type specifies a complete ranking and an approval set; let \(D_c\) be the types that disapprove \(c\), and let \(B_R(c)\) be the candidates every type in \(R\subseteq D_c\) strictly ranks above \(c\). With \(\nu(X)=|X|/|C|\), the value is \(\min_{\varnothing\ne R\subseteq D_c}(1-\nu(B_R(c)))/\sum_{t\in R}\mu_t\), or \(\infty\) if \(D_c\) is empty.

The model it lives in

A population is a distribution \(\mu\) over complete voter types, each encoding rankings and approvals on finite \(C\). A coalition consists of mass from disapproving types; it blocks \(c\) when its mass \(q\) and unanimously preferred region \(B(c)\) satisfy \(\nu(B(c))>1-\omega q\). The task is to compute the least blocking ratio and an attaining coalition, with running time measured in \(m=|C|\), support size \(\tau\), and input bit length \(L\).

What the mirror covers

The mirror covers the paper’s computation of the critical endowment for one candidate at a time. It does not cover the full DVC choice set, the other solution concepts, or the axiomatic and empirical results.

Open questions for a prover

  • Can the exact critical endowment and an attaining coalition be computed in time polynomial in \(m,\tau,L\), for rational type masses?

The case FOR (proponent)

The strongest case is a high-multiplicity version of the paper’s critical-endowment computation for the Disapproval Veto Core (DVC). The computational anchor is the restatable theorem tagged measurecomp: it says that for finite \(C\), given a candidate \(c\), its critical endowment \(\omega^*(c)\) can be computed in time \(O((mn)^{1+o(1)})\), where \(m=|C|\). The supplied extract omits that theorem’s displayed numeral, so I can identify it by its source tag but cannot quote a printed number. I find no active numbered hardness result in the supplied paper; this is an algorithmic anchor.

Here is a precise mirror, the Continuous Critical-Endowment Problem for DVC. An instance consists of a finite candidate set \(C\), a target \(c\in C\), and a list of \(\tau\) supported voter types with binary-rational masses \(\mu_t>0\) summing to \(1\). A type \(t\) records its complete weak ranking of \(C\) and its approval set \(A_t\). Let \(\nu(D)=|D|/|C|\) be the paper’s normalized candidate measure. For a nonempty set \(R\) of types that disapprove \(c\), let \(B_R(c)\) be the candidates every type in \(R\) strictly ranks above \(c\). The task is to compute the exact value
\[ \omega^*(c;\mu)= \min_{\varnothing\ne R\subseteq D_c} \frac{1-\nu(B_R(c))}{\sum_{t\in R}\mu_t}, \qquad D_c=\{t:c\notin A_t\}, \]
with value \(\infty\) if no type disapproves \(c\). A solution is this rational value and, when finite, a type set \(R\) attaining it. Equivalently, at budget multiplier \(\omega\), a measurable coalition blocks \(c\) when it consists only of disapprovers and its mass \(q\) satisfies \(\nu(B(c))>1-\omega q\). This keeps the paper’s question intact: a cohesive, disapproving coalition challenges a candidate according to how much of the option space it unanimously ranks above that candidate. It makes only the population divisible.

A plausible regime is a large consultation on a small menu of AI responses or safety policies. Many users may evaluate the same options, while their relevant reports fall into a modest number of ranking-and-approval types. With four options, for example, there are at most \(4!\,2^4=384\) strict-ranking-and-approval types before imposing threshold consistency. The number of people can therefore be enormous while \(\tau\) remains small. Type-level mass is a natural unit here: “\(12\%\) of affected users disapprove and rank these alternatives above the policy” is the same kind of claim as the paper’s coalition-based objection, expressed at population scale. The mirror does not require fractional options or continuous time.

I expect this problem to be Class A. The paper’s critical-endowment computation reduces the explicit-voter problem to a cut computation. In the mirror, identical voter nodes can be aggregated into type nodes with rational capacities; the candidate nodes retain weight \(1/m\). The formula above is a minimum coverage-to-mass ratio, which suggests an exact weighted or parametric min-cut algorithm polynomial in \(m,\tau,L\), where \(L\) is the input bit length. Proving that bound is new work, rather than a result already established by the paper.

There is also a clean bridge to the finite problem. If \(\mu_t=n_t/n\), then for any chosen set of disapproving types, the numerator \(1-\nu(B_R(c))\) is fixed, and the ratio is smallest when the coalition includes all voters of those types. Thus the continuous critical endowment agrees exactly with the finite-election value on such empirical distributions. Continuization would provide a compressed representation and an algorithm parameterized by support size, while preserving this robustness quantity. That is a formal high-multiplicity dictionary, even though it does not make the answer itself different.

The mirror covers the paper’s named critical-endowment computation for one candidate at a time; it does not claim to mirror the whole societal-consent framework. Further questions include whether the exact type-compressed algorithm runs in polynomial time in \(m,\tau,L\), whether the same compression gives equally useful bounds for computing the entire DVC set, and how the model changes when there are continuously many candidate policies.

The weak point is that this is an auxiliary robustness computation and an algorithmic anchor, not a hardness result whose difficulty might dissolve under continuization. The finite problem is already tractable in the paper. Still, the paper explicitly computes and empirically uses \(\omega^*(c)\), and the proposed mirror preserves its coalition, approval, and ranking structure while making a million-person regime mathematically well-defined.

The case AGAINST (opponent, writing after the proponent)

The strongest objection is about contribution scale. The anchor is the paper’s measurecomp theorem: it computes one candidate’s critical endowment in \(O((mn)^{1+o(1)})\) time. In the proposed mirror, the calculation becomes a minimum ratio over disapproving type coalitions,
\[ \omega^*(c;\mu)=\min_{\varnothing\ne R\subseteq D_c} \frac{1-\nu(B_R(c))}{\sum_{t\in R}\mu_t}. \]
That looks like a weighted version of the paper’s existing cut computation. Every rational type distribution can also be expanded into a finite electorate by taking a common denominator. So the mirror appears to preserve the same value while changing how the input is encoded; its algorithm may be a direct weighted min-cut generalization rather than a new structural result.

That makes this a modest anchor: it concerns a robustness statistic, and the proposed gain is a running time in support size and bit length. A fixed menu of four options also bounds the number of ranking-and-approval types, so in that scenario the main advance may be practical compression rather than a new complexity phenomenon.

But this objection does not defeat the mirror under ChoCo’s stated criteria. A large consultation over a small menu is a credible high-multiplicity regime; ranking and approval capture everything this problem uses, and the paper already computes and studies the statistic. A weighted-cut algorithm parameterized by \(\tau\) and \(L\) would be an exact computational result about a continuous population. The fact that rational instances can be expanded into finite electorates is the intended high-multiplicity bridge, not a collision or a defect.

So I cannot make a strong case against this anchor without relying on grounds the programme rules out. The negative case is weak here: the mirror survives, though its likely contribution is narrower than a new hardness boundary or a richer optimization result.
