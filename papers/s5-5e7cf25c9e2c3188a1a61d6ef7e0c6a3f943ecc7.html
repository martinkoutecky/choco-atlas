The continuous mirror question

Given rational agent-type masses \(\mu_v\), rational per-capita supplies \(\sigma_e\) of indivisible item types, and for each item type \(e\) at most two eligible agent types receiving the same utility \(w_e\), choose nonnegative bundle masses \(y_{v,B}\), where \(B\) is an integral subset of item types eligible for \(v\), so that \(\sum_B y_{v,B}=\mu_v\), \(\sum_{v,B:e\in B}y_{v,B}\le\sigma_e\), and every used bundle satisfies \(\sum_{e\in B}w_e\ge\lambda\); maximize \(\lambda\).

The model it lives in

An exact high-multiplicity configuration LP for uniform 2-restricted Max-Min Allocation: agent types \(v\) carry mass \(\mu_v\), item types \(e\) carry supply \(\sigma_e\), \(y_{v,B}\) assigns population mass to integral bundles, and the objective maximizes the minimum bundle utility \(\lambda\).

The objection that survived

The simple type-average formulation changes the fairness objective: positive average utility does not imply that every individual receives a qualifying bundle. The proponent acknowledges this issue but does not itself formulate the exact configuration model needed to repair it.

The case FOR (proponent)

There is a credible positive mirror here, with Theorem 2 as the lead anchor. I would classify the resulting continuous problem as likely Class A: the paper’s factor-\(2\) hardness appears to come from orienting each indivisible item wholly to one endpoint, precisely the kind of population-level integrality that continuization can remove.

Theorem 2, proved in this paper, states:

For every \(\varepsilon>0\), non-uniform 2-restricted Max-Min Allocation has a \((2+\varepsilon)\)-approximation algorithm running in time \(\operatorname{poly}(n,1/\varepsilon)\). Moreover, for every \(\delta>0\), it is NP-hard to obtain a \((2-\delta)\)-approximation for uniform 2-restricted Max-Min Allocation.

The hardness part is my main anchor. The paper also proves the equivalent graph formulation in Theorem 7: uniform graph balancing is NP-hard to approximate within \(2-\delta\), for every \(\delta>0\). Theorem 7 is proved here, not merely cited.

My mirror is Continuous Uniform 2-Restricted Max-Min Allocation.

An instance consists of:

  • a finite set \(V\) of agent types, with rational masses \(\mu_v\ge 0\) satisfying \(\sum_v\mu_v=1\);
  • a finite set \(E\) of item types;
  • for each \(e\in E\), one or two eligible agent types \(u(e),v(e)\), a rational utility \(w_e>0\), and a rational per-capita supply \(\sigma_e\).

Every copy of item type \(e\) gives utility \(w_e\) to either eligible type and zero utility to every other type. Thus the instance remains 2-restricted and uniform. If the population is scaled to \(N\) agents, it contains \(N\mu_v\) agents of type \(v\) and \(N\sigma_e\) copies of item type \(e\). Choosing \(N\) to clear denominators gives an ordinary finite allocation instance. Each copy is still indivisible and each individual still receives an integral bundle; only the aggregate allocation is described by masses.

Let \(z_{e,v}\) be the amount of item mass of type \(e\) assigned to agent type \(v\). The continuous problem is

\[ \max \lambda \]

subject to

\[ z_{e,u(e)}+z_{e,v(e)}=\sigma_e \]

for every two-ended item type \(e\), \(z_{e,v}\ge 0\), and

\[ \sum_{e\ni v} w_e z_{e,v}\ge \lambda\mu_v \]

for every type \(v\) with positive mass. Equivalently, \(\lambda\) is the minimum type-average utility,

\[ \lambda\le \frac{1}{\mu_v}\sum_{e\ni v}w_ez_{e,v}. \]

This is a linear program with \(O(|E|)\) variables and constraints, so I expect the mirror to be tractable.

The scenario is a large allocation system with many repeated beneficiary profiles: for example, a national programme distributing standardized grants or service slots, where each grant type is useful to at most two recurring population categories and has the same value to both. There may be millions of individuals but only \(\tau=|V|\) recurring profiles and a moderate number of item types. The per-capita supply is natural: a larger population brings proportionally more copies of each standardized grant. The type records all relevant information, so agents of one type are genuinely interchangeable.

This is not merely divisible-goods allocation. In every finite realization, goods remain indivisible and bundles remain integral. The fractional \(z_{e,v}\) records that, among many copies of the same item type, some copies go to one recurring population class and the rest to another. The continuous object is the population regime and its aggregate allocation, not a lottery over outcomes.

The expected Class A result would explain the paper’s hardness boundary. The discrete reduction encodes a truth assignment through the requirement that every edge be oriented entirely toward one endpoint. In the mirror, edge mass can be divided among the two endpoint populations. The SAT assignment is no longer forced, and the resulting fairness problem becomes the LP above. Thus this is a genuine example where discrete approximation hardness dissolves because it is driven by indivisible population-scale allocation choices.

The weak point is the objective. The paper maximizes the utility of the least individual agent, whereas the clean continuous formulation maximizes the least type-average utility. That change is defensible—type-level averages are precisely the natural quantities in a mass model—but it needs to be acknowledged. A stricter follow-up would require every positive-mass type to receive only integral bundles meeting \(\lambda\), leading to a configuration formulation rather than the simple LP. I would ask whether that essential-minimum variant remains tractable for uniform 2-restricted instances, and how quickly finite integral allocations converge to the continuous optimum.

The case AGAINST (opponent, writing after the proponent)

The strongest objection is to the proposed LP’s objective. The paper’s Max-Min Allocation problem maximizes the utility of the least individual agent, not the least type-average utility. Those objectives do not converge under population scaling.

Take one agent type of mass \(1\), one eligible item type of utility \(1\), and per-capita supply \(\sigma=\tfrac12\). The proposed LP sets \(z=\tfrac12\) and obtains \(\lambda=\tfrac12\). But every finite realization has \(N\) agents and only \(N/2\) indivisible items, so at least half the agents receive utility \(0\); the discrete max-min value is \(0\) for every \(N\). This is not a rounding issue that vanishes with population size. It is a persistent failure of the type-average objective to represent the paper’s fairness criterion.

The natural repair is to require every individual in every positive-mass type to receive an integral bundle meeting the threshold. For a type \(v\), let

\[ \mathcal B_v(\lambda)= \left\{B\subseteq E(v): \sum_{e\in B}w_e\ge \lambda\right\}. \]

With \(y_{v,B}\) denoting the mass of type \(v\) assigned bundle \(B\), the exact continuous-population formulation is

\[ \sum_{B\in\mathcal B_v(\lambda)}y_{v,B}=\mu_v \]

for every \(v\), together with

\[ \sum_v\sum_{B\ni e}y_{v,B}\le \sigma_e \]

for every item type \(e\). This preserves the original min-over-individuals objective: every unit of population receives an integral bundle, while only the distribution of bundles is continuous.

That repair, however, exposes the weakness of the proposed anchor rather than defeating it. It is a legitimate high-multiplicity problem. It has a natural repeated-agent scenario—standardized grants or service slots allocated to recurring population categories—and it leads to a configuration LP with potentially exponentially many bundles. Its pricing problem is a genuine computational question, not merely a divisible-goods calculation. The paper’s own configuration LP does not eliminate this point: there it is a fractional relaxation of a finite allocation problem; under the continuous-population interpretation, the same variables describe an exact mass allocation. Existing high-multiplicity or configuration-LP work would support, rather than invalidate, the mirror.

Nor can the objection be that fractional \(z_{e,v}\) is “really” continuizing the items. Aggregate item mass must be fractional when a continuum of agents is served, while each individual bundle can remain integral; the programme explicitly permits that co-modification. Likewise, identity is not essential once a type records all relevant eligibility and utility information.

Theorem 7 does not provide a separate escape: its graph-balancing formulation is exactly the same two-ended item model, with vertices as agent types and edges as item types. Theorem 2 and Theorem 7 therefore share the same viable continuous reformulation.

So the negative case can decisively reject the proponent’s simple least-average LP as a faithful mirror of the paper. It cannot honestly reject the repaired configuration-based mirror. Since that repaired model is well posed, has a plausible high-multiplicity interpretation, and raises nontrivial computational questions, I cannot sustain the universal claim that Theorem 2 has no worthwhile continuous mirror.
