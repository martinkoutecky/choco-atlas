The case AGAINST (opponent, writing after the proponent)

I would not select this paper for ChoCo. The decisive issue is that it has no numbered result classifying the complexity of a computational problem. Theorems 7 and 8 characterize an allocation rule axiomatically; Theorems 1–6 are impossibility and implication results about axioms. Section 7.1 is the closest computational hook: it gives an \(O(n)\) cost for computing a smaller-coalition allocation *after* the grand-coalition Shapley value is known. That conditional cost is not a complexity result about computing the paper’s main object.

The strongest possible population mirror would group firms with the same portfolios of interchangeable skill copies, represent their prevalence as mass, and define coalition value over aggregate skill quantities. But the paper’s primitive is \(v:2^T\to\mathbb R\), which may distinguish every subset of skills, and its skills are unique. In the general model, an exact type must retain skill identity, so repeated types do not compress the instance. Restricting \(v\) to depend only on counts of interchangeable copies makes a coherent new model, but removes the identity-specific structure that motivates the paper. Also, anonymity-proofness concerns an agent hiding part of its own skill set; in a nonatomic population, an individual has zero mass. Making the strategic actor a positive-mass cohort could repair that, but it changes the unit of manipulation.

Neither repair produces a computational mirror of a named result. One could study computation for a measure-valued game, but that would require a new input model and new computational question; the paper supplies no complexity claim for it to mirror. The universal claim that no useful adjacent project could ever be formulated is stronger than the evidence supports. The narrower negative case is strong: any plausible continuous extension here is a new continuous-skill or axiomatic project, not a worthwhile mirror of this paper for ChoCo.
