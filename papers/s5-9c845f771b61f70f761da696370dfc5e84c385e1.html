The case FOR (proponent)

The strongest honest positive case is a population-limit extension of Theorem 3, not a mirror of a computational-complexity result. A plausible regime is a large cooperative with many interchangeable members in each role and nested organizational units. A complete type would include a member’s role, coalition memberships, contribution to the game, and bargaining features. The society is a mass vector \(\mu\) over finitely many such types; \(V(x)\) gives the transferable surplus of a coalition with mass vector \(x\). Members bid, propose transfers, and accept or reject; the intended outcome is a per-unit-mass allocation of \(V(\mu)\). Here the number of members can grow while the number of types and hierarchy levels stays fixed.

The paper’s strongest possible anchor is Theorem 3, proved here. It says that for every superadditive finite TU game with a levels structure, the levels bidding mechanism implements the levels structure value in subgame perfect Nash equilibrium: an equilibrium yielding that value exists, and every SPNE subject to the paper’s tie-breaking assumptions yields it. Those assumptions include accepting when indifferent and, for an indifferent proposer, choosing the offer that is accepted. This is a genuine result about the underlying implementation problem, but it asserts no running time or complexity class. Proposition 2 is an intermediate inequality in the proof, not a computational result.

A concrete extension question would be Limit Levels-Bidding Implementation. Its instance is a finite type set \(T\), rational masses \(\mu_t>0\) summing to one, nested partitions of \(T\), and a continuously differentiable, superadditive worth function \(V\) on feasible mass vectors. For each \(q\), make \(q\) identical members of each type, each representing mass \(\mu_t/q\), and give coalition \(S\) worth \(V(x(S))\). Apply the paper’s mechanism and levels structure to that finite game. The question is whether the per-unit-mass equilibrium payoffs converge as \(q\to\infty\), and, if so, to compute the limiting vector
\[ a_t=\lim_{q\to\infty}\frac{q}{\mu_t}\Psi_i^{(q)} \]
for a member \(i\) of type \(t\). A solution would give the vector and establish convergence; Theorem 3 would then make it the limit of all tie-broken SPNE payoffs. With a fixed number of types and a polynomial \(V\), I would expect this limit computation to be tractable, though the paper establishes no such result. Further questions include whether there is a direct atomless mechanism implementing the limit and what changes when the number of types grows.

That is a plausible mirror because it preserves the hierarchy, surplus function, bargaining actions, and intended allocation, while making identical members’ mass explicit. Its weak point is substantial: the original mechanism relies on individual proposers, individual exit, and sequential continuation games. Those features may not survive an atomless limit. More fundamentally, the paper contains no named computational result of the kind the programme asks us to anchor on—no P, NP-hardness, FPT, or related claim. So this is a defensible proposed extension of its implementation theorem, but it cannot honestly be presented as an anchor-based continuization of a computational result in the paper.

The case AGAINST (opponent, writing after the proponent)

The strongest objection is that the paper gives ChoCo no computational result to mirror. Theorem 3 is a substantive implementation theorem: under the paper’s tie-breaking assumptions, an SPNE yielding the levels structure value exists, and every SPNE outcome yields that value. It does not pose a decision, optimization, or search problem, or analyze an algorithm or its running time. Proposition 2 is an inequality used in the proof. Even the most natural computational add-on—computing the value—would need an input model the paper never supplies. With an explicit table of coalition worths, the input already has exponential size; with a succinct representation, complexity would depend on that representation. That could be a worthwhile new problem, but it is not a computational claim of this paper.

The proponent’s replicated-cooperative construction is the best candidate for a continuous extension, and its high-multiplicity regime is plausible: large organizations can have many interchangeable members in nested units. Given masses \(\mu\), a smooth superadditive worth function \(V\), and a hierarchy, one can define finite games with \(q\) copies of each type and ask whether their normalized levels values converge. That may yield a worthwhile limit theorem. But Theorem 3 already identifies each finite game’s equilibrium payoff with its levels value. The proposed question is therefore a limit of a solution concept, not a computational mirror of the implementation result.

There is also a real gap between that sequence of finite mechanisms and a mechanism over an atomless population. In each finite game, an individual can be selected as proposer, reject an offer, or leave. In the limit, each individual has zero mass; selecting one as proposer or removing one changes no aggregate mass. Normalizing payoffs per unit mass may recover an allocation, but it does not supply a continuum game with the paper’s strategic actions. One could add a positive-mass representative or another selection institution, but that would introduce a new mechanism.

A computational version could specify, for example, rational polynomial \(V\), an encoding for its coefficients, and a task of computing the limiting type allocation. Yet the complexity question would then be created by those choices. It might be a useful study of continuous cooperative-game values, but it would not chart the computational landscape of a result in this paper.

So the negative case is strongest under ChoCo’s stated gate: there is no named computational result here to anchor a mirror. It is weaker against the broader claim that a continuous implementation or limit theorem could be worthwhile in cooperative game theory. The replicated-members construction could support such a project; it simply does not make this paper a strong target for the programme’s computational continuization.
