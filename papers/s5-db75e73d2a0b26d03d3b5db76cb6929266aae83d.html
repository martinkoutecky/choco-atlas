The continuous mirror question

Given \(\tau\) nonatomic valuation types \(\nu_t\) on \([0,1]\), rational proportions \(\mu_t\), and population scale \(N\), can a deterministic Robertson–Webb procedure output finite-union bundles \(B_{tj}\) and cohort masses \(\lambda_{tj}>0\) such that \(\sum_j\lambda_{tj}=N\mu_t\), \(\sum_{t,j}\lambda_{tj}\mathbf{1}_{B_{tj}}(x)=1\) almost everywhere, and each type has a common bundle value \(\nu_t(B_{tj})=u_t\geq 1/N\), with values invariant under relabelling? What query complexity is achievable in \(\tau\), mass bit length \(L\), \(\log N\), and output size?

The model it lives in

A population of mass \(N\) distributed over \(\tau\) valuation types, sharing a cake of fixed capacity one. Decision variables assign cohort masses \(\lambda_{tj}\) to integral bundles \(B_{tj}\); assignments obey pointwise cake capacity and give each type a common value of at least \(1/N\).

The objection that survived

With fixed cake capacity, the one-type Lebesgue case needs at least \(N\) positive-value bundle templates, and the proportionality threshold \(1/N\) vanishes as \(N\) grows; the proposed mirror therefore offers no guaranteed support-size compression.

fatal: False

What the mirror covers

The mass-template formulation mirrors Theorem 3's symmetric proportionality guarantee and also makes a continuous SymEF question for Theorem 2 statable. It leaves the Aristotelian result, approximate symmetric envy-freeness, and the paper's elementary-operation analysis without a corresponding type-mass result.

Open questions for a prover

  • What are the upper and lower Robertson–Webb query bounds for the stated mass-template version of symmetric proportional division as functions of \(\tau\), \(L\), \(\log N\), and output size?

The case FOR (proponent)

The strongest positive case is about a large population with a small menu of valuation types. The cake being continuous is not the point: the proposed mirror makes the population continuous. Think of a large jurisdiction or workforce dividing one heterogeneous resource, where \(N\) is large but only \(\tau\) distinct valuation measures occur, with \(\tau \ll N\). A type is a complete valuation \(\nu_t\); its mass is its fraction \(\mu_t\) of the population. This is a plausible high-multiplicity regime, though not every cake-cutting setting has it.

Here is a concrete version. Give each type \(t\) a mass \(N\mu_t\), with rational \(\mu_t>0\) summing to \(1\). Each \(\nu_t\) is a nonatomic probability measure on \([0,1]\), accessible through Robertson–Webb cut and evaluation queries. A solution is a finite list of bundle templates \(B_{tj}\), each a finite union of intervals, and assigned masses \(\lambda_{tj}\geq 0\). They must satisfy \(\sum_j\lambda_{tj}=N\mu_t\) for every type, and
\[ \sum_{t,j}\lambda_{tj}\mathbf 1_{B_{tj}}(x)=1 \quad\text{for almost every }x\in[0,1]. \]
Thus every unit of population mass gets an integral bundle, and each point of the cake is allocated to exactly one unit of mass. The templates compress the assignment; they do not replace each person’s bundle with a fractional bundle.

Lead mirror: Continuous SymProp. For every type \(t\), all assigned bundles must have the same value \(u_t\) under \(\nu_t\), and \(u_t\geq 1/N\). The type-indexed output must depend only on the unordered type-and-mass data: relabelling people in a finite realization cannot change anyone’s value. This is a direct mass version of proportionality and the paper’s order symmetry.

The anchor is Theorem 3, proved in this paper: for \(n\) players with nonatomic probability measures on the cake, there is a deterministic symmetric and proportional algorithm using \(O(n^3)\) Robertson–Webb queries. In full, each player gets value at least \(1/n\), and each player’s value is unchanged by any permutation of the ordered input list. This is a query-complexity result, not an ordinary polynomial-time bound: the paper notes that its SymProp algorithm can use exponentially many elementary operations.

The continuous computational question is whether, given \(N\), the rational masses, and the \(\tau\) valuation oracles, one can construct the template assignment with cost polynomial in \(\tau\), the mass bit length \(L\), and \(\log N\) (plus output size). I would expect Class A to be the target: repeated agents of a type can be represented by mass, and the natural formulation uses bundle configurations. But Theorem 3 does not establish that compression; finding and solving the relevant pricing problem is the research question.

Second mirror: Continuous SymEF. Use the same instance and resource constraint, but require that for every pair of supported bundles \(B\) assigned to type \(t\) and \(D\) assigned to type \(s\),
\[ \nu_t(B)\geq \nu_t(D). \]
This makes every type-\(t\) agent weakly prefer their bundle to every other assigned bundle, including those of their own type. It is the continuous, type-anonymous version of symmetric envy-free division.

Its anchor is Theorem 2, also proved here. It asserts that for arbitrary \(n\) and nonatomic valuations there is a deterministic symmetric and envy-free algorithm returning finite unions of intervals. Symmetry means each player’s own value is invariant under every permutation of the input order; envy-freeness means no player prefers another player’s piece. The proof constructs it using an existing envy-free algorithm, runs that algorithm on all \(n!\) input orders, and selects among the resulting divisions. Thus the theorem gives existence, not a polynomial query bound; the construction uses \(n!\) calls to the underlying algorithm.

For Continuous SymEF, my initial expectation is Class C, with low confidence: exact envy-freeness imposes comparisons across every pair of bundle templates, and the paper’s construction has factorial dependence on the population size. A type-mass formulation might remove that dependence, but it would need a new argument. There is no named discrete hardness result here to support a Class B prediction.

Both mirrors preserve the underlying question: how to assign the same heterogeneous cake to agents with preferences over it. They do not call the paper “already continuous” just because its cake is an interval. They replace the ordered finite list of agents by masses of agents sharing complete valuations. The paper’s symmetry definition makes that replacement especially natural: it explicitly asks whether input order changes an individual’s value.

The weak point is the compression itself. The paper neither groups repeated valuation measures nor represents a large allocation by type-level bundle templates; its algorithms take a list of named players, and the SymProp theorem’s query bound hides potentially exponential arithmetic work. So these are honest high-multiplicity questions for the authors’ problems, not consequences of their theorems. The key further questions are whether finite-template solutions always suffice and whether their exact query complexity can depend on \(\tau\) rather than \(N\).

The case AGAINST (opponent, writing after the proponent)

The strongest case against these mirrors is that the paper allocates a finite cake to named players, while a distribution over types records only who has which valuation. For Theorem 3, the algorithm returns a bundle for each player; symmetry compares a player’s value across permutations of the input list, and proportionality requires value at least \(1/n\). Theorem 2 also returns individual bundles and compares them for envy. Those conditions do not pass unchanged to an atomless population.

With a finite cake and a continuum of agents, the direct limit degenerates. Within any one type, agents’ bundles are disjoint and they share the same finite valuation measure. At most countably many disjoint bundles can have positive value under that measure, so almost every member of the type gets value zero. Proportionality then has a zero limiting benchmark, and envy comparisons among almost all members are vacuous. Scaling the cake with population size does not by itself fix the issue if each type still has a finite valuation measure.

The proposed bundle templates do not yet supply a compressed deterministic allocation. For the one-type Lebesgue case, every agent in a finite \(N\)-person proportional division needs a positive-length bundle. In the proposed constraint, any positive-length template assigned mass \(\lambda_{tj}\) contributes that amount across its bundle, so feasibility forces \(\lambda_{tj}\leq 1\). Since the masses sum to \(N\), at least \(N\) templates are needed. A succinct, on-demand description might reduce the work, but it needs a representation and cost model for arbitrary Robertson–Webb valuation oracles. The stated allowance for output size may itself permit costs growing with \(N\).

One repair is to use type-level allocation densities or lotteries. That can produce a meaningful continuous resource-allocation problem, but it replaces deterministic individual bundles with fractional or randomized allocations and changes what symmetry, proportionality, and envy mean. The programme allows co-modifications forced by population continuization, so this is not a decisive scope objection; it does mean the paper’s theorems do not directly establish the proposed mirrors.

This case is weaker against the finite-type, finite-\(N\) version. A Robertson–Webb question about many agents drawn from a small set of valuation types is sensible, and it might reduce query costs by reusing queries for identical types. Theorem 2’s construction uses \(n!\) permutations, and Theorem 3 gives an \(O(n^3)\) query bound, so there is a concrete algorithmic question to ask there. I can argue that the submitted continuous formulations do not yet preserve the paper’s individual-allocation problem, but I cannot honestly rule out a worthwhile high-multiplicity mirror of either anchor.
