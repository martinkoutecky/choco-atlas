The continuous mirror question

Given a finite item set \(K\), known cohort support \(T\) of size \(\tau\) with rational masses \(\mu_t\) summing to one, per-capita supplies \(s_j\), and unknown free-disposal valuation oracles \(v_t\), assign mass \(x_{t,B}\) of each type to integral bundles \(B\), subject to \(\sum_B x_{t,B}=\mu_t\) and \(\sum_{t,B:\,j\in B}x_{t,B}\le s_j\), to maximize \(\sum_{t,B}x_{t,B}v_t(B)\). Does uniformly sampling from the \(Q=\tau(2^k-1)\) type–bundle value queries, skipping answered or inferable queries, until an optimum is certified use at most \(\frac{q_{\min}}{q_{\min}+1}(Q+1)\) queries in expectation, where \(q_{\min}\) is the fewest queries any valid adaptive policy needs to certify the optimum for the same hidden valuation profile?

The model it lives in

A preference-elicitation problem over a nonatomic cohort market: each type's value oracle is shared by its mass, each unit receives an integral bundle, and the allocation is optimized over feasible mass assignments.

The objection that survived

The bound is generic over a finite query universe and does not depend on fractional masses or continuous allocation; the proponent does not show that continuity changes the query guarantee beyond replacing \(n\) individual oracles with \(\tau\) shared type oracles.

fatal: False

What the mirror covers

The mirror covers Proposition 1's random value-query guarantee. It does not cover the paper's other elicitation policies, theoretical results, or experiments.

Open questions for a prover

  • Does Proposition 1's query-count proof carry over when optimality is defined by the continuous allocation problem?
  • In natural cohort markets, when is \(q_{\min}\) small enough relative to \(Q\) for the bound to imply substantial query savings?

The case FOR (proponent)

The paper has no named result classifying an underlying problem as NP-hard, polynomial-time solvable, or FPT. Its closest computational anchor is Proposition 1, proved in this paper: with \(Q=n(2^k-1)\) possible value queries and \(q_{\min}\) the number used by an optimal elicitation policy on a given instance, the unrestricted random value-query policy has expected query count at most
\[ \frac{q_{\min}}{q_{\min}+1}(Q+1). \]
That is a query-complexity guarantee, not a running-time classification. If only the latter qualifies as an anchor, this paper has no eligible anchor; the positive case below rests on Proposition 1 in the broader query-complexity sense.

A plausible regime is a large procurement market with, say, \(100{,}000\) small firms and a few dozen certified production archetypes. Firms in an archetype share the same valuation over bundles of standardized items because they use the same production process and face the same contracts and resale prices. The market can be represented by type masses \(\mu_t\), with \(n\gg\tau\), where \(\tau\) is the number of archetypes. The auctioneer knows the cohort masses and can query a representative of each cohort, but its value schedule is private until queried.

The lead mirror is Continuous Mass Preference Elicitation. Its instance has a finite item set \(K\), a support \(T\) of \(\tau\) valuation types, rational masses \(\mu_t\) summing to one, per-capita supplies \(s_j\) of each item \(j\), and type-level value oracles \(v_t\) satisfying free disposal. A query \((t,B)\) reveals \(v_t(B)\) for the whole mass of type \(t\). The unknown oracle answers are the private information; type labels and masses are known. A feasible allocation is a vector \(x_{t,B}\ge 0\), where \(x_{t,B}\) is the mass of type \(t\) receiving the integral bundle \(B\), with
\[ \sum_B x_{t,B}=\mu_t,\qquad \sum_{t,B:\,j\in B}x_{t,B}\le s_j. \]
The objective is to certify an allocation maximizing \(\sum_{t,B}x_{t,B}v_t(B)\). The bundle received by each unit of mass remains integral; only the type-level assignment is fractional.

The question to hand a prover is: for this oracle problem, does the policy that samples uniformly from the \(Q=\tau(2^k-1)\) type–bundle value queries, skipping answered or inferable queries, use at most
\[ \frac{q_{\min}}{q_{\min}+1}(Q+1) \]
queries in expectation, where \(q_{\min}\) is the minimum number of queries needed by any valid adaptive policy to certify an optimum for the same hidden valuation profile? The expected answer is that the bound transfers by essentially the same finite-query argument as Proposition 1. This is tractability in query count, not a polynomial-time claim: once values are known, welfare maximization is a finite configuration LP, but the number of bundles grows exponentially in \(k\). Further questions include the complexity of finding or approximating \(q_{\min}\), and whether comparable guarantees hold for order or bound-approximation queries.

This case covers Proposition 1’s random value-query guarantee and the paper’s goal of eliciting just enough information to certify an optimal allocation. It does not claim a mirror for the paper’s other policies or experiments.

The weak point is the oracle model. In ChoCo’s standard explicit input, a type includes its full valuation; if those valuations and their masses are given to the elicitor, there is nothing left to elicit. The mirror therefore needs the paper’s information asymmetry: cohort membership and masses are known, while the common value schedule is accessible only through queries. A referee may accept this as the high-multiplicity version of their elicitation question, but it is an additional oracle formulation, and the result remains a query-count theorem rather than the kind of running-time complexity result the programme most wants.

The case AGAINST (opponent, writing after the proponent)

Proposition 1 is the only plausible anchor, but its guarantee is about oracle-query count, not the running time or parameterized complexity of an explicit computational problem. Its bound depends only on a finite universe of \(Q\) queries and the number \(q_{\min}\) any successful policy needs. It says nothing about the cost of choosing queries, solving the allocation problem, or how either cost changes with population mass.

The strongest mirror is the proponent’s: large cohorts share exactly the same valuation function, masses are known, and one query to a representative reveals the value for the whole cohort. But this adds an oracle model to ChoCo’s explicit society input, where a type is fully described—including its preferences. If those preferences are known, there is nothing to elicit; if they are hidden behind oracles, the mirror is a different input model. And once exact sharing is assumed, the bound simply applies to \(\tau\) type-level oracles instead of \(n\) agent-level oracles. Fractional masses and the allocation LP play no role in Proposition 1; the same query-count statement applies to \(\tau\) unrelated oracles with no continuous population at all. That makes it a weak fit for a programme about the computational consequences of representing society by a distribution.

This does not rule out a sensible continuous oracle-elicitation problem. A market with known, standardized cohorts and private shared value schedules is plausible, and Proposition 1 transfers to it. My negative case is therefore limited: the anchor lacks the population-dependent computational content ChoCo seeks. If ChoCo treats oracle-query complexity as in scope, this mirror survives, and I cannot honestly support the universal claim that no worthwhile continuous mirror exists.
