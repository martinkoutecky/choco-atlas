The continuous mirror question

Given a finite type set \(\Theta\), rational masses \(\mu_t\) with \(\sum_t\mu_t=1\), and ranked smart ballots \(B_t=(D_t^1>\cdots>D_t^{k_t}>b_t)\), where each \(D_t^h=(S_t^h,\varphi_t^h)\) references types in \(\Theta\) and uses a contingent complete-DNF Boolean function, decide whether there is a type ordering and consistent certificate \(\ell\) such that \(\sum_{t\in\Theta}\mu_t\ell_t\le M\), with every type receiving its selected integral direct vote and inducing a direct-vote distribution over the population.

The model it lives in

An explicit cohort-level smart-voting model: types \(t\in\Theta\) carry mass \(\mu_t\), each type selects one preference level \(\ell_t\), Boolean delegations read the integral vote of referenced types, and the objective is the population-weighted rank \(\sum_t\mu_t\ell_t\).

The objection that survived

The strongest remaining objection is that the paper's identity-sensitive individual lifts are not uniquely determined by \(\mu\), so a formal many-copy semantics could disagree with the synchronized cohort semantics used by the mirror.

fatal: False

What the mirror covers

The mirror covers \(\textsc{BoundedMinSum}\) hardness in Theorem 1 and the weighted-liquid \(\minsum\) algorithm in Theorem 2; it leaves the participation axioms, Pareto results, and procedure-comparison results outside.

Open questions for a prover

  • Can the cohort-level semantics be formally obtained as a synchronized \(q\)-copy construction whose normalized optimum converges to the weighted type problem?
  • What is the complexity for fixed \(|\Theta|\), bounded delegation width, or bounded treewidth of the type-dependency graph?
  • If members of one type may use different certificates, what network-kernel or graphon semantics preserves Boolean necessary-winner evaluation?

The case FOR (proponent)

The strongest positive case is a high-multiplicity, cohort-level version of the paper’s optimal unravelling problems. The paper is not itself a continuous-population paper: its agents are named individuals and its delegation functions refer to those individuals. But its central objects—ranked ballots, delegation cycles, certificates, and the optimization of preference levels—survive a natural population quotient.

Consider a large online organization running repeated binary referenda. Its members fall into \(\tau\) recurring roles or cohorts: for example, local chapter delegates, professional groups, or institutional offices. A type \(t\) includes the member’s complete smart ballot, its backup vote, its delegation targets, and its Boolean delegation functions. Thus two members of type \(t\) are indistinguishable in every respect relevant to unravelling. Let \(\mu_t\) be the fraction of the population with type \(t\), with \(\sum_t\mu_t=1\). The high-multiplicity regime is \(N=q\tau\) members, with \(q\gg\tau\) members of each role type.

The natural type-level interpretation is that a delegation to \(S\) refers to the common vote of the corresponding cohorts. A type-level certificate chooses one preference level for each type, and a certificate is consistent if the selected delegations can be evaluated in some ordering of the types, exactly as in the paper’s Definition 5. Its cost is the population-weighted rank

\[ \operatorname{rank}_{\mu}(\ell)=\sum_{t\in\Theta}\mu_t\ell_t. \]

The resulting direct-vote distribution is obtained from the type votes by

\[ \nu_1=\sum_{t:v_t=1}\mu_t,\qquad \nu_0=\sum_{t:v_t=0}\mu_t. \]

A standard voting rule can then be applied to \((\nu_0,\nu_1)\), but the core computational question is the unravelling itself.

My lead anchor is Theorem 1, proved in this paper. It states that \(\minsumbound\) is NP-complete. More explicitly, the input is a valid smart profile whose delegations belong to \(\Blang\), together with an integer \(M\); the question is whether there exists a consistent certificate \(\cert\) with

\[ \operatorname{rank}(\cert)=\sum_{a\in\N}\cert_a\le M. \]

The paper proves membership in NP and NP-hardness by reduction from Feedback Vertex Set. The hardness reduction is particularly useful here because it uses only positive-literal conjunctions in the delegation formulas.

The corresponding continuous question is:

\[ \textsc{Continuous-Bounded-MinSum}. \]

An instance consists of a finite type set \(\Theta\), rational masses \(\mu_t\), and for every type \(t\) a ranked ballot

\[ B_t=(D_t^1>\cdots>D_t^{k_t}>b_t), \]

where each \(D_t^h=(S_t^h,\varphi_t^h)\), \(S_t^h\subseteq\Theta\), and \(\varphi_t^h\) is a contingent complete-DNF Boolean delegation function. Given a rational threshold \(M\), decide whether there is a type-level consistent certificate \(\ell\) satisfying

\[ \sum_{t\in\Theta}\mu_t\ell_t\le M. \]

A solution consists of the certificate, an ordering witnessing consistency, and the resulting type-level direct votes.

This is recognisably the authors’ problem: the delegation language, ranked alternatives, cycles, consistency notion, and objective are unchanged. Only the electorate is represented by masses, and rank is normalized by population size. The continuous problem is likely Class B in the general case. The paper’s FVS reduction transfers almost verbatim: for every graph vertex \(v\), create a type with ballot

\[ B_v=\left(\bigwedge_{u\in O_v}u>1\right), \]

give every type mass \(1/|V|\), and set the threshold to

\[ M=1+\frac{k}{|V|}. \]

Choosing the second preference for a type corresponds to deleting that vertex. The remaining first-level dependencies are consistent exactly when the remaining graph is acyclic. Thus the continuous problem remains NP-hard, with the hardness living in the type-dependency graph rather than in the number of named individuals. The same hard type system can be instantiated by arbitrarily many members of each type, so this is genuinely a high-multiplicity regime.

A useful boundary question follows immediately: for fixed \(\tau\), bounded delegation width, or bounded treewidth of the type-dependency graph, does the problem become FPT or polynomial? That would separate hardness caused by the delegation topology from hardness caused by population multiplicity.

A second, cleaner anchor is Theorem 2, also proved in this paper. It states that an outcome of \(\minsum\) on a profile in \(\Liqlang\) can be found in time

\[ \mathcal{O}(n(d+n)), \]

where \(d\) is the number of delegations. The proof constructs a directed graph with a root representing direct votes and uses Edmonds’ minimum-arborescence algorithm.

Its continuous mirror is:

\[ \textsc{Weighted-Liquid-MinSum}_{\infty}. \]

The input is a finite type set \(\Theta\), rational masses \(\mu_t\), and ranked liquid-democracy ballots in which every delegation has the form \((\{u\},u)\). Construct a directed graph with root \(r\). For every type \(t\), add an edge \(u\to t\) for each delegation of \(t\) to \(u\), and an edge \(r\to t\) for each direct vote. If the relevant preference level is \(h\), assign the edge weight

\[ w(e)=\mu_t h. \]

The problem is to find a rooted arborescence of minimum total weight and return the induced direct-vote distribution. Equivalently, it asks for a consistent certificate minimizing

\[ \sum_{t\in\Theta}\mu_t\ell_t. \]

This is a direct continuous-population version of the paper’s ranked liquid-democracy problem. The result should be Class A: Edmonds’ algorithm applies unchanged to rational mass-weighted edges, giving a polynomial-time algorithm in \(\tau\), the number of type-level delegations, and the input bit length. If each type represents \(q\) identical individuals, multiplying the objective by \(q\tau\) recovers the corresponding finite total rank.

The scope is deliberately limited. These two mirrors cover the paper’s computational core: the general Boolean language and the tractable single-agent-delegation language. I would not stretch the case to the participation axioms or Pareto propositions, since those are primarily axiomatic results and do not add much to the continuous-computation programme.

The weakest point is the type-level treatment of delegation. In the paper, a Boolean formula may refer to named individuals; in the mirror, it refers to exchangeable cohorts with a common type-level vote. If members of one type were allowed to split fractionally among different preference levels, the semantics of a Boolean delegation would need an additional rule for evaluating partially resolved cohort votes. That is a real modelling choice, not a technicality. The proposed mirror therefore needs to be presented as a cohort-level or anonymous-delegation variant, not as the unique atomless extension of the paper.

Nevertheless, it is a credible mirror: the population is the continuous object, mass is the electorate share, the decision variable is the selected delegation level, and the paper’s central combinatorics remain visible. The resulting landscape is also informative: Boolean ranked delegations retain hardness through their type topology, while ranked single-agent delegations collapse to a weighted arborescence problem.

The case AGAINST (opponent, writing after the proponent)

Neither anchor survives as a genuine continuous-population mirror. The obstruction is semantic, not that the resulting problem would be easy or hard.

The paper’s computational object is not an anonymous ballot profile. It is a directed dependency structure on named agents: \(S_a^h\) contains particular agents, and cycles depend on exactly which agents are connected. A distribution \(\mu\) over local ballot types does not determine that structure.

For example, take \(q\) agents of type \(A\) and \(q\) of type \(B\), with first delegation \(A\to B\), \(B\to A\), and backup at level \(2\). There are at least two inequivalent lifts of this apparent type profile. In one, \(A_i\) delegates to \(B_i\) and \(B_i\) to \(A_i\), producing \(q\) separate cycles. Every cycle requires one backup, so the normalized minimum rank is

\[ \frac{3q}{2q}=\frac32. \]

In another, every \(A_i\) delegates to \(B_1\) and every \(B_i\) delegates to \(A_1\). There is then only one cycle; after breaking it, all other agents can use their first preference. The normalized rank is

\[ \frac{2q+1}{2q}=1+\frac{1}{2q}. \]

Both have the same masses \(\mu_A=\mu_B=\frac12\) and the same apparent type-level delegation pattern. The difference lies in the identity-level lift, which the proposed \(\mu\) does not record.

The proponent’s “common cohort vote” resolves this only by changing the model. In the paper, having the same ballot does not imply that agents have the same unravelled vote or use the same certificate. Making a cohort share one state replaces \(q\) agents by one collective super-agent. Conversely, retaining named targets makes those targets part of the complete type, so the number of relevant types grows with the dependency network. Allowing fractional mixtures of certificates would require a new semantics for partially resolved Boolean delegations.

This defeats the proposed mirror of Theorem 1. The FVS reduction is not a high-multiplicity construction: it creates one dependency vertex per graph vertex, and the masses \(1/|V|\) merely normalize the finite rank objective. Replicating every vertex \(q\) times either creates \(q\) separate graph copies, whose identity structure must be retained, or collapses the copies into synchronized cohort nodes, which is a different FVS model. Thus the reduction transfers to a weighted finite dependency network, not to a continuous society determined by population masses.

The same problem defeats Theorem 2. Edmonds’ algorithm certainly solves the proponent’s weighted role graph, with edge cost \(\mu_t h\). But that edge cost assumes that all mass of type \(t\) makes one common delegation choice. In the actual high-multiplicity version, each copy has its own incoming edge and the optimal arborescence depends on how those copies are connected. The weighted type-level arborescence is therefore an algorithm for the newly imposed cohort model, not for the paper’s ranked liquid-democracy problem under population continuization.

One could introduce a delegation kernel, graphon, or measurable network to retain identity-level dependencies, or explicitly study collective cohort delegations. Either direction might support a worthwhile new paper. But the former is a continuous-network problem requiring new consistency and unraveling semantics, while the latter treats cohorts as super-agents and leaves population mass as a weight on a finite graph. Neither is the claimed high-multiplicity mirror of the paper’s named computational results.

The honest weakness in this negative case is that a reader willing to accept collective cohorts as the intended application may regard that new weighted-network problem as sufficiently close. Under the programme’s stricter gate, however, the proposed mirrors do not continuize the population; they quotient away the identity-sensitive structure that makes these results about delegations in the first place.
