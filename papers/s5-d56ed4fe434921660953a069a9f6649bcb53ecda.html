The continuous mirror question

Given \(m\) public projects, a cardinality bound \(k\), a finite type set \(T\) with \(|T|=\tau\), rational masses \(\mu\in\Delta(T)\), and monotone CGS valuations \(v_t:2^{[m]}\to\mathbb R_+\), output a lottery \(D\) over project sets \(S\) with \(|S|\le k\) such that \(W_\mu(D)=\mathbb E_{S\sim D}[\sum_t\mu_t v_t(S)]\) is at least \((1-1/e)\max_{|S|\le k}\sum_t\mu_t v_t(S)\), in time polynomial in the type and project descriptions.

The model it lives in

A high-multiplicity public-project society with valuation types \(t\), masses \(\mu_t\), aggregate valuation \(V_\mu(S)=\sum_t\mu_t v_t(S)\), integral outcome \(S\) with \(|S|\le k\), and a lottery decision variable \(D\) maximizing expected aggregate welfare.

The objection that survived

In an atomless society, an individual's report has zero mass, so the theorem's non-vacuous individual-level truthfulness does not survive; type-block incentives would define a different mechanism.

The case FOR (proponent)

The strongest honest mirror is a continuous-type version of the paper’s flexible combinatorial public-projects problem. I would use Theorem 5.1 as the sole anchor. It is proved in this paper, not cited: “There is a \((1-1/e)\)-approximate, truthful-in-expectation mechanism for combinatorial public projects with CGS valuations in the bounded-lottery-value oracle model, running in expected \(\operatorname{poly}(n,m)\) time.” Here CPP means choosing a set of at most \(k\) out of \(m\) public projects to maximize the sum of the players’ valuations.

The continuous problem would be:

Continuous-Type Flexible CPP. An instance consists of \(m\) projects, a cardinality bound \(k\), a finite set \(T\) of valuation types with \(|T|=\tau\), rational masses \(\mu_t\ge0\) satisfying \(\sum_t\mu_t=1\), and one monotone CGS valuation \(v_t:2^{[m]}\to\mathbb R_+\) for each type. The mass \(\mu_t\) is the fraction of the population having exactly that valuation type. The decision is a lottery \(D\) over integral project sets \(S\subseteq[m]\) with \(|S|\le k\). Its normalized welfare is \(W_\mu(D)=\mathbb E_{S\sim D}[\sum_{t\in T}\mu_t v_t(S)]\). The task is to output \(D\) satisfying \(W_\mu(D)\ge(1-1/e)\operatorname{OPT}_\mu\), where \(\operatorname{OPT}_\mu=\max_{|S|\le k}\sum_t\mu_t v_t(S)\). In the mechanism-strengthened version, the output also includes payments per unit mass and must be truthful in expectation for each type block.

This is a genuine population mirror. Consider a city with millions of residents and a fixed menu of possible public projects—transit lines, parks, schools, clinics—but only a few dozen or few hundred recurring valuation profiles. Members of a type have the same valuation of every project set, and, in the mechanism version, the same payment-relevant parameters. Thus \(N\) is very large while \(\tau\ll N\). The action remains an integral public decision: each realized outcome is an actual set \(S\) of at most \(k\) projects. The continuous object is the population distribution \(\mu\), not the project set, the lottery, or the internal fractional vector used by the algorithm.

The high-multiplicity dictionary is exact. If \(N\mu_t\) is integral and there are \(N\mu_t\) residents of type \(t\), then every project set satisfies \(\sum_i v_i(S)=N\sum_t\mu_t v_t(S)\). Hence the normalized finite problem and the continuous problem have exactly the same optimum and approximation ratios. Conversely, every rational continuous instance is represented by a sufficiently large finite electorate. The gain is that the input is described by \(\tau\) valuation types and their masses rather than by \(N\) repeated bidders.

The reason Theorem 5.1 is a particularly good anchor is that its proof survives the aggregation structurally. The aggregate valuation \(V_\mu(S)=\sum_t\mu_t v_t(S)\) is again CGS, because CGS valuations are closed under nonnegative linear combinations. The paper’s Lemma 5.2, proved here, says that the \(k\)-bounded-lottery rounding scheme is convex for CGS valuations; applied to \(V_\mu\), this gives a concave expected-welfare objective. Lemma 5.3, also proved here, gives the \((1-1/e)\) approximation for submodular valuations. The bounded-lottery oracle for \(V_\mu\) is obtained by querying each type oracle and taking the weighted sum, so the natural running time becomes polynomial in \(\tau\), \(m\), and the encoding length of \(\mu\), rather than in the potentially enormous population size \(N\).

I would therefore expect this mirror to be Class A at the paper’s approximation target: the continuous type problem admits the same \((1-1/e)\) approximation through convex optimization and type aggregation. The exact optimization version is different: even a single coverage valuation can encode Maximum Coverage, so exact hardness should remain. That is a useful boundary rather than a defect: continuization compresses repeated population structure but does not erase combinatorics residing in the project agenda.

This mirror covers Theorem 5.1 and its supporting Lemmas 5.2 and 5.3. I would not stretch it to cover Theorem 4.1: combinatorial auctions require a per-capita supply convention for items, and the continuous analogue would need an additional modelling choice such as \(N\rho_j\) copies of item \(j\). That is plausible, but weaker than the public-projects mirror because public projects already have naturally population-independent supply.

The main weakness is that the paper’s truthfulness statement concerns finitely many individually strategic players, whereas the cleanest continuous formulation aggregates identical residents into type blocks. A type-block truthful mechanism is not automatically an individual-level atomless mechanism with a well-defined payment density. Also, rational masses reproduce finite high-multiplicity elections exactly, so the continuous formulation is not automatically a new complexity phenomenon. The positive case rests instead on a sensible real regime—large populations with few complete valuation types—and on the fact that the paper’s convex-rounding machinery is closed under precisely the weighted aggregation that this regime requires.

The case AGAINST (opponent, writing after the proponent)

The strongest negative case is that the proponent has to choose between two different problems, and neither preserves the paper’s central contribution.

For the welfare-only version, define
\[ V_\mu(S)=\sum_{t\in T}\mu_t v_t(S). \]
Because CGS valuations are closed under nonnegative linear combinations, \(V_\mu\) is itself a CGS valuation. The continuous instance is therefore exactly an ordinary CPP instance with one bidder having valuation \(V_\mu\), or with \(\tau\) weighted bidders having valuations \(\mu_t v_t\). Lemmas 5.2 and 5.3 apply immediately, but they apply because the theorem already handles weighted sums—not because a continuous population creates a new computational object.

This is more than the objection that “continuization does not help.” In CPP, the population has no allocation, identity-sensitive constraint, or type-dependent feasibility condition: everyone receives the same public-project set \(S\). Once utilitarian welfare is written down, the society disappears into the single function \(V_\mu\). The proposed integral is merely a different encoding of that valuation. The city story makes high multiplicity plausible, but it does not make the population computationally operative.

Restoring the paper’s actual mechanism-design content creates a sharper failure. Theorem 5.1 concerns truthfulness for each individual bidder. In an atomless population, one individual has measure zero, so changing that individual’s report does not change \(\mu\), the selected lottery, or the public outcome. Individual truthfulness therefore becomes vacuous; zero payments already suffice. The mechanism-design difficulty that motivates the theorem has disappeared.

The only way to retain a non-vacuous incentive constraint is to make each type block a strategic agent with valuation \(\mu_t v_t\). But then the model is a finite \(\tau\)-player weighted CPP mechanism, not a mechanism for a continuous population. Dividing a block payment by \(\mu_t\) does not turn block-level truthfulness into individual-level truthfulness: a unilateral member cannot control the block’s report. Requiring coordinated block reports or coalition-proofness would be a new mechanism-design problem, not a mirror of Theorem 5.1.

One could add per-type participation constraints, fairness requirements, type-specific project quotas, or transfers that interact with population mass. Those might produce worthwhile continuous public-project models, but they change the problem whose theorem is being mirrored. If those additions are omitted, the mechanism version is either a finite weighted mechanism or a degenerate atomless one; if the mechanism is omitted, the anchor has been reduced to aggregation plus the already-given convex-rounding algorithm.

This negative case is not airtight. The welfare formulation is formally a legitimate high-multiplicity problem, and under a broad programme definition it may count as a Class A mirror. What it does not provide is a nondegenerate continuous mirror of the paper’s named truthful-mechanism result. The honest conclusion is therefore that the proponent has identified a technically valid aggregation exercise, but not yet a worthwhile continuous-population mechanism problem.
