Why no mirror

Theorem 16 has computational content because its proof constructs an equilibrium resource by resource. But in the proposed mass model, an individual deviation no longer changes congestion, so the equilibrium concept shifts from finite-player Nash to Wardrop-style equilibrium. That is a different problem, and the anchored theorem does not transfer.

The case FOR (proponent)

The paper has no named P/NP-hardness or other complexity-classification result. My strongest anchor is Theorem 16, proved in this paper: every allocation game with modular valuation functions and nondecreasing delay functions has a pure Nash equilibrium. Agents may choose any bundle, and delays may be agent-specific; the proof reduces the problem resource by resource, using the single-resource existence result in Lemma 15. The theorem establishes existence, not an algorithm or a complexity bound. The continuous question below turns that existence result into an explicit computation problem.

My lead mirror is Continuous-Type Nash Equilibrium. An instance has a finite resource set \(R\), a finite set of complete agent types \(T\), and rational masses \(\mu_t>0\) summing to \(1\). Type \(t\) has modular values \(v_t(S)=\sum_{r\in S}a_{t,r}\), and experiences a continuous, nondecreasing, rational piecewise-linear delay \(d_{t,r}(q)\) on resource \(r\), where \(q\in[0,1]\) is the fraction of the population using it. Each person still chooses an integral bundle \(S\subseteq R\). A type’s mass may be divided among bundles: write \(x_{t,S}\geq 0\), with \(\sum_S x_{t,S}=\mu_t\), and let \(q_r=\sum_{t,S:r\in S}x_{t,S}\). Given those loads, type \(t\)’s utility for bundle \(S\) is
\[ u_t(S;q)=\sum_{r\in S}\bigl(a_{t,r}-d_{t,r}(q_r)\bigr). \]
The task is to return an equilibrium assignment: whenever \(x_{t,S}>0\), \(S\) maximizes \(u_t(S;q)\) among all bundles. In this nonatomic model, one person’s deviation does not change a resource’s load.

This is a natural high-multiplicity regime: for example, millions of users of shared computing pools, grouped by workload class, where members of a class have the same service values and congestion response. The number of people can be far larger than the number \(\tau=|T|\) of distinct types. The model keeps the paper’s unrestricted resource access, bundle choices, modular values, and congestion-based utility. Replacing the count of users with per-capita load is the population scaling required by the continuum. The fractional quantities \(x_{t,S}\) say what fraction of a type chooses each *integral* bundle; they do not make resources divisible.

I expect this problem to be Class A, tractable. Modularity makes the equilibrium conditions resource-by-resource. For each resource \(r\), at a proposed load \(q\), types with \(a_{t,r}>d_{t,r}(q)\) must use it, types with \(a_{t,r}<d_{t,r}(q)\) must not, and indifferent types may split. Thus an equilibrium load must satisfy
\[ \sum_{t:\,a_{t,r}>d_{t,r}(q)}\mu_t \;\leq q\leq\; \sum_{t:\,a_{t,r}\geq d_{t,r}(q)}\mu_t. \]
With rational piecewise-linear delay curves, a sweep over their breakpoints and value-crossing points can find such a load and the required type-level splits using polynomially many operations in the input size. Solve this for each resource, then couple each type’s per-resource choices into bundles; additive utility means any such coupling remains an equilibrium. The output can be represented compactly by the loads and type-resource masses, with a product coupling specifying an assignment to integral bundles.

The soft spot is that this is a nonatomic equilibrium, while a finite player in the paper affects congestion when deviating. The mirror removes that individual effect, so it is a genuine high-multiplicity limit rather than an identical restatement. It also inherits the strong modularity condition that makes the paper’s proof work, and its algorithm may therefore be a modest continuation rather than a deep new complexity result. The case still holds: modularity is part of the paper’s stated theorem, the population regime is plausible, and the new question asks for an exact equilibrium algorithm for the underlying allocation problem.

This mirror covers Theorem 16 only. It does not claim to continuize the paper’s social-welfare negotiation results in Section 3, whose deal and finite-termination properties would need their own continuous formulation. Natural follow-up questions are whether equilibrium computation survives structured complementarities, how discontinuous congestion curves affect existence, and how the nonatomic equilibria relate to equilibria in large but finite populations.

The case AGAINST (opponent, writing after the proponent)

The strongest objection is that Theorem 16 is an existence theorem, not a complexity result. It says every game in the stated class has a pure Nash equilibrium; it does not pose an input-output problem or analyze the cost of finding one. “Compute a continuous equilibrium” is a natural follow-up, but it is a new task layered onto the theorem, rather than a complexity question the paper itself left open.

The theorem’s assumptions also leave little coupled structure for that task. Modular values and unrestricted bundles make each agent’s resource choices independent. In the proposed mirror, the population limit preserves that factorization: each resource has its own load condition, and those choices can then be combined into bundles. Adding route constraints, budgets, or complementarities might create a richer computational problem, but it would leave the assumptions that make Theorem 16 true. That is the best reason to doubt this anchor’s value for a programme charting computational landscapes.

There is nearby continuous work on computing multiclass Wardrop equilibria with class-dependent costs, including polynomial solvability for fixed-size affine-cost cases such as parallel links ([Meunier and Pradeau](https://arxiv.org/abs/1412.6496)). That does not establish a novelty collision: it is not this paper’s model, and ChoCo’s rules treat an outside answer to a well-posed mirror as insufficient to reject it. Still, it makes the proposed formulation look like a familiar equilibrium-computation question more than a new computational direction opened by this paper.

This is a limited negative case, not a demonstration that no worthwhile mirror exists. The population regime is sensible, and equilibrium computation is a question the authors could recognize as theirs. The weakness is that the paper’s only proposed anchor supplies an existence result whose structure already factors cleanly; the negative case is strongest on research value, and weakest on the claim that the mirror is not a valid question.
