The case FOR (proponent)

There is no eligible anchor in this paper: it contains no numbered Theorem, Lemma, Corollary, or Proposition asserting a complexity result. Its computational findings are empirical comparisons of prediction methods. I should not turn those into complexity anchors. So there is no continuous problem I can honestly present as one-per-anchor.

The strongest positive route is a prospective, unanchored mirror of the paper’s vote-based shortlisting target. Call it Mass-Based Popularity Shortlisting. Let \(P=\{p_1,\ldots,p_q\}\) be the proposed projects and \(k\) the shortlist size. Represent a large electorate by a rational distribution \(\mu\) over \(\tau\) complete voter-response types, where \(\mu_t\) is type \(t\)’s population share. For each type and project, the input gives \(\alpha_{tj}\in[0,1]\), the probability that a voter of type \(t\) would support project \(p_j\). The projected support share is \(v_j=\sum_t\mu_t\alpha_{tj}\). The task is to return a ranking of the projects by \(v_j\), or equivalently a size-\(k\) shortlist maximizing \(\sum_{p_j\in S}v_j\). A solution is that ranking or shortlist. With rational input, this is in P: compute the \(q\) weighted sums and sort them.

A plausible high-multiplicity setting is a recurring urban PB process with tens of thousands of voters but only hundreds of stable response types. The campaigns in the paper have 4,532–95,899 voters, so their scale makes that scenario conceivable; the paper does not measure the number of voter types, however. This model continuizes the electorate, and its output—projects ranked by expected public support—is something the authors could recognize as central to their shortlisting goal. The paper’s normalized vote target in §3.1 also makes the per-capita quantity a natural one.

The weakness is substantial: supplying each type’s approval propensity bypasses the paper’s main predictive step, which infers project support from project features and historical campaign data. The paper provides no complexity result for learning those propensities or producing its forecasts. Thus this is a precise candidate for a population-based popularity-ranking problem, but it is not an anchor-backed mirror of a result proved in the paper.

The case AGAINST (opponent, writing after the proponent)

There is no eligible anchor in the paper: it proves no complexity result for a computational problem. Its results compare prediction methods empirically. The proponent is right to avoid presenting those comparisons as complexity theorems.

The proposed Mass-Based Popularity Shortlisting task is well-defined. Given type masses \(\mu_t\) and support probabilities \(\alpha_{tj}\), it computes \(v_j=\sum_t\mu_t\alpha_{tj}\) and ranks projects by \(v_j\). But those inputs already supply the target quantities the paper tries to predict. The paper’s pipeline estimates support from project features and previous campaigns; it does not receive target-campaign voter types or their project-level propensities. So this task captures the desired output while skipping the paper’s central inference problem.

A closer reconstruction would learn future support from project features and historical campaign data. Its observations are projects across a small number of campaigns; the electorate appears through aggregate vote counts, often normalized by turnout. Continuizing voters does not reduce the number of projects or resolve the paper’s stated challenge of predicting across campaigns that may differ. To make voter types central, one would need a model linking types to responses to new proposals. If that model supplies the response probabilities, the ranking task above returns; if it must be learned, the paper supplies neither the type data nor the behavioral assumptions that define that learning problem. This would be a new preference-modeling study, rather than a continuous mirror of a result in this paper.

The universal negative remains weak: these are large public electorates, and the per-capita support target makes a population model plausible. A recurring campaign with stable, measured voter types could motivate worthwhile research. The paper does not establish that setting, though, and it contains no computational result for such a model to mirror.
