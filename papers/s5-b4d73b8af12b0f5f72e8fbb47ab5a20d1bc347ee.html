The continuous mirror question

Given finite applicant and position type sets \(P,Q\), allowed pairs \(E\subseteq P\times Q\), rational type masses \(\mu_p,\nu_q\) summing to \(1\) on each side, strict rankings of compatible opposite-side types, and a rational threshold \(\kappa\), partition two atomless unit-measure populations into those types. A feasible matching \(M\) is a measurable, measure-preserving partial bijection using only pairs in \(E\); its size \(|M|\) is its matched mass. For each person, compare their partner type (or unmatched status \(\bot\)) in \(M\) and \(N\), assigning vote \(+1,-1,\) or \(0\) for preferring \(M\), preferring \(N\), or being indifferent. Decide whether there is a feasible \(M\) with \(|M|\ge\kappa\) such that \(\Delta(M,N)\ge0\) for every feasible \(N\) with \(|N|\ge\kappa\), where \(\Delta\) is the sum of the two populations’ integrated votes; if so, return \(M\).

The model it lives in

Use atomless unit-measure applicant and position populations partitioned into finitely many types with rational masses. Each person’s type fixes their preferences over opposite-side partner types, with copies of a type tied. Matchings are measurable partial measure-preserving bijections; compare \(M\) and \(N\) on the same people and integrate their votes on both sides. A finite witness can be represented by rational interval pieces matched by translation.

What the mirror covers

The mirror covers Theorem 5’s two-sided popular near-maximum-weight matching hardness, in the unit-weight case; it leaves Theorems 1–3 on popular optimal solutions and Theorem 4’s one-sided near-optimal result aside.

Open questions for a prover

  • Classify the decision and search complexity in the type support and rational input bit length; in particular, determine whether Theorem 5’s hardness survives type ties and divisible cohort mass.

The case FOR (proponent)

The strongest positive case is the paper’s Theorem 5, proved in this paper (as Theorem 29). It says that finding a popular near-maximum-weight matching is NP-hard in the two-sided preference model even when every edge has weight \(1\): given a bipartite graph with strict preferences and a threshold \(k\), it is NP-hard to decide whether there is a matching \(M\) with \(|M|\ge k\) such that \(\Delta(M,N)\ge 0\) for every matching \(N\) with \(|N|\ge k\). The proof reduces from the cited NP-complete problem in Theorem 26, which asks whether a popular matching of a specified size exists.

I would mirror that result with Atomless Popular Near-Threshold Matching, \(\mathrm{APNTM}_\infty\). An instance has finite sets of applicant types \(P\) and position types \(Q\), an allowed-pair relation \(E\subseteq P\times Q\), rational type masses \(\mu_p,\nu_q\) summing to \(1\) on each side, strict rankings of compatible opposite-side types for each type, and a rational threshold \(\kappa\). A type is a complete profile for the market: its members share the same acceptable types and preferences. This could describe a large hiring cycle in which many applicants and positions fall into a modest number of recurring cohorts.

Represent each type by an interval of its stated mass. A matching is a one-to-one, measure-preserving partial map between the applicant and position populations, using only allowed type pairs. For a finite input and output representation, take matchings made of finitely many pairs of equal-length rational intervals, matched by translation. Each individual is either matched to one position or unmatched; types determine preferences, and distinct positions within a type are tied. The interval coordinates identify the same individuals when two matchings are compared; they add no preferences, costs, or other type differences.

Write \(M(a)\) for the type of applicant \(a\)’s partner in \(M\), or \(\bot\) if unmatched, and use the analogous notation for positions. Let \(\operatorname{vote}_z(M,N)\) be \(+1\) if \(z\) prefers its assignment in \(M\), \(-1\) if it prefers its assignment in \(N\), and \(0\) if they are indifferent. Define
\[ \Delta(M,N)= \int_{\Omega_A}\operatorname{vote}_a(M,N)\,d\lambda_A(a) + \int_{\Omega_B}\operatorname{vote}_b(M,N)\,d\lambda_B(b). \]
The size \(|M|\) is its matched mass. The problem is to report whether there is a matching \(M\) with \(|M|\ge\kappa\) such that \(\Delta(M,N)\ge0\) for every feasible matching \(N\) with \(|N|\ge\kappa\), and, if so, return such an \(M\). The proposed complexity measure is the number of types and allowed pairs, plus the bit length of the rational data and the matching output.

This keeps the paper’s question intact: agents on both sides vote on their assigned partners, and the candidate must withstand every sufficiently large competing matching. The population is the continuous object; per-capita position supply and mass-valued matching size are the co-modifications that make it meaningful. This mirror covers Theorem 5 only, not the paper’s popular *optimal*-matching results.

My first conjecture would be hardness transfers (Class B) when the number of types is allowed to grow. The paper’s reduction uses the preference and compatibility structure and an arbitrary size threshold, rather than a large population count by itself. But that is only a conjecture: the reduction has not been shown to survive splitting type mass across assignments. The main questions it raises are whether Theorem 5’s hardness can be lifted when there are many copies per type, and whether a polynomial algorithm is possible when the type support is moderate.

The weakest point is the type aggregation. Theorem 5 assumes strict preferences over individual partners; this mirror ties exact copies within a type and allows their mass to split. The hard instances may also require almost as many distinct types as agents. Either feature could change popularity enough that the discrete reduction no longer applies. So this is a credible continuous version of the authors’ problem, but the paper’s hardness result does not establish its complexity.

The case AGAINST (opponent, writing after the proponent)

Theorem 5 is the strongest possible anchor for a continuous mirror: it is a named complexity result about a computational problem, and neither its hardness nor the paper’s discrete framing is a reason to reject the question.

The best objection is that popularity compares the *same people* across two matchings. A type-to-type flow records how much mass is matched along each pair, but not which members of a type receive which partners in each matching. Two matchings with the same flows can therefore yield different head-to-head votes. A flow-based mirror needs a rule for resolving that: retain a common identity space for the atomless population, or define popularity against the worst feasible alignment of assignments. The first adds an identity-level representation; the second makes popularity depend on an explicit coupling convention. That ambiguity makes it harder to claim there is one canonical continuous version of Theorem 5.

But it does not defeat the better mirror. In a market with repeated applicant and employer cohorts, define measurable assignments over the same atomless populations, compare each person’s assignments in \(M\) and \(N\), and integrate their votes. Scale the threshold to a matched-mass threshold \(\kappa\). This preserves the theorem’s central question, and the identities needed for comparison are part of the population model. Alternatively, a type-level version can state its alignment convention directly. Both are recognizable matching problems; whether the finite hardness survives is a question to investigate, not a reason to avoid asking it.

So the negative case is weak. Identity-sensitive voting is a real modeling cost, but I cannot honestly use it to rule out a worthwhile mirror in every scenario. The hiring-cohort version remains credible, even if the choice of popularity semantics must be made explicit.
