What the mirror covers

The candidate covers computing preferred extensions and checking dilemmas in the integrated framework; it leaves the individual-framework, norm-extension correspondence, priority-extension, and explanation results aside.

The case FOR (proponent)

The strongest honest positive case is narrow, and it does not meet your anchor rule. The paper has no named result asserting a complexity classification or giving a computational formulation that the authors compute with. The nearest formal bridge is Proposition 4.10, proved in the paper’s appendix: every naive extension of the argumentation framework equals the set of arguments generated by some norm extension; conversely, every \(P\)-maximal norm extension generates a naive extension. That is a correspondence between two semantics, not a claim about an algorithm’s running time or the complexity of computing recommendations. I would not present it as a qualifying computational anchor.

As an unanchored candidate, the closest faithful mirror is Continuous Integrated Jiminy Recommendation. An instance would give a finite set \(T\) of stakeholder types, a complete normative profile for each type (its norms and, where relevant, its role and priority information), a shared language and contrariness relation, context \(K\), decision variables \(DV\), and rational masses \(\mu_t\) summing to one. A type is a complete normative system shared by indistinguishable stakeholders; its mass is that fraction of the population. The instance asks for the preferred extensions of the integrated argumentation framework and whether their obligations contain a moral dilemma. If there is no dilemma, the solution also returns the recommendation formed from their obligations. This is a recommendation computation, not an optimization problem; the paper supplies no objective to preserve.

A plausible regime would be a large user or citizen population supplying moral input to a widely deployed autonomous service: perhaps millions of people, but only dozens of recurring normative profiles elicited through the paper’s table-based approach. For a finite electorate with \(n_t\) people of each type, set \(\mu_t=n_t/n\). The high-multiplicity encoding is exact: combine the norms of the types with positive mass and run the integrated-level computation. This stays close to the paper’s treatment of multiple stakeholder systems and keeps the population as the object being represented.

The weakness is also decisive. In the paper’s semantics, a stakeholder’s norms enter by set union; repeating the same normative system does not strengthen its influence. Thus the masses matter only through which types have positive mass. The candidate is a continuous encoding of the input, but the distribution’s proportions do no computational work. I would expect no tractability gain from continuization: any complexity would remain in the number of distinct profiles, their norms, and the extension computation. A genuinely mass-sensitive version would need weighted influence or a mass-transfer intervention, which would change the paper’s model and lacks a named result to anchor it.

So the positive case is that a high-multiplicity input for Jiminy is imaginable and can be specified without changing the core integrated-level question. Its weakest point is that the paper’s own semantics erase multiplicity, and its named results provide no computational-hardness or tractability anchor. I would regard this as a tentative population-scale reformulation, not a strong, paper-anchored continuous mirror.

The case AGAINST (opponent, writing after the proponent)

The proposed Continuous Integrated Jiminy Recommendation has no named computational result to anchor it to. The closest candidates are Proposition 4.10, a correspondence between argumentation extensions and norm extensions, and Proposition 5.13, which gives a simpler way to compute priority extensions. Neither classifies the complexity of computing recommendations. More importantly, neither has a population parameter whose continuous version could change the question.

In a faithful population model, let each type \(t\) specify a complete stakeholder profile: its norms, role, and priority information. The integrated framework is built from the union of the norms of types with positive mass. Consequently, once the support is fixed, changing the masses does not change the framework or its extensions. A type with mass \(0.001\) contributes its norms just as fully as one with mass \(0.9\). If source identity matters for priorities or explanations, it must be included in the type; that makes some institutional stakeholders singletons. Either way, the rational proportions do no work. A large public of users is a plausible setting, but the paper either represents the public through one already-composed stakeholder system or includes distinct user profiles as unweighted inputs. Repeating a profile many times has no additional effect.

A mass-weighted version is the best apparent repair, but it needs a new rule for how population shares affect obligations, attacks, or accepted arguments. That would replace the paper’s set-union treatment of stakeholder input with an aggregation rule. The paper explicitly avoids majority rule; it does not specify a threshold or other way for a user majority to outweigh a regulator’s or manufacturer’s norms. Such a model might be interesting in its own right, but it asks how to aggregate a public’s ethical views, rather than how Jiminy reaches agreement among the stakeholders as modeled here.

A robustness or intervention version—such as finding the smallest share of users who must withdraw or change their norms to alter a recommendation—has the same problem. Under the paper’s semantics, moving mass changes nothing until a type disappears from the support or a new type enters it. Any such problem is therefore about adding or removing stakeholder profiles, with mass as a cost attached to that change. It could be a coherent new stakeholder-control problem, but the paper does not study that intervention or provide a named result about it. For instances where one newly present profile changes the framework, the effect can occur at arbitrarily small positive mass, which makes a literal mass-based robustness measure degenerate.

So the strongest negative case is that a high-multiplicity user population can be imagined, but the paper’s computational model is not sensitive to multiplicity. Its named results concern semantics over argumentation structures, not the size or proportions of a society, and making proportions matter requires changing the aggregation semantics. The limit of this case is that authors might welcome a weighted public-input model as a new extension of Jiminy. I cannot rule that out universally; it would still be a new problem, not a continuous mirror of a computational result in this paper.
