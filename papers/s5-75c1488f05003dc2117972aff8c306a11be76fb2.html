The continuous mirror question

Given \(K\) channels, a finite type set \(T\), rational masses \(\mu_t\) summing to \(1\), bids \(b_t\), demands \(d_t\), and a conflict graph \(H\) on types, choose masses \(y_{t,B}\geq 0\) for each bundle \(B\subseteq\{1,\ldots,K\}\) with \(|B|=d_t\), subject to \(\sum_B y_{t,B}\leq\mu_t\). Define \(z_{t,k}=\sum_{B\ni k}y_{t,B}\), and require \(z_{t,k}z_{u,k}=0\) for each edge \(\{t,u\}\in H\) and channel \(k\). What are the exact, approximation, and parameterized complexities of maximizing \(\sum_{t\in T} b_t\sum_B y_{t,B}\), as functions of \(K\), \(|T|\), and the input bit length?

The model it lives in

A high-multiplicity strict-request spectrum market with types \(t\in T\), mass \(\mu_t\), bid \(b_t\), demand \(d_t\), and complete cross-type conflicts described by \(H\); decision variables allocate each type’s mass among whole-channel bundles or leave it unserved, maximizing total welfare.

The case FOR (proponent)

The strongest mirror is the paper’s SA-SR allocation problem, anchored by Theorem 1. The theorem states that SA-SR is NP-hard and has no \(\delta\)-approximation for some positive constant \(\delta\), unless P=NP. The authors prove it here by reducing the case \(K=d_i=1\) to maximum-weight independent set in the conflict graph.

I would model a large secondary-spectrum market with a finite set \(T\) of bidder types. A type records a bidder’s bid \(b_t\), strict channel demand \(d_t\), and interference role. The society is a rational distribution \(\mu\) over those types, with \(\sum_t\mu_t=1\). Include a conflict graph \(H\) on \(T\): an edge means every user of one type interferes with every user of the other on a shared channel; users within a type do not interfere with each other. This describes a clone-symmetric network: each type is a class of users with the same bid, demand, and network relationships.

Call the resulting problem Continuous Strict-Request Spectrum Allocation. For each type \(t\) and each bundle \(B\subseteq\{1,\ldots,K\}\) of size \(d_t\), choose \(y_{t,B}\geq0\), the mass of type-\(t\) users receiving exactly bundle \(B\). Require \(\sum_B y_{t,B}\leq\mu_t\); remaining mass receives nothing. Let \(z_{t,k}=\sum_{B\ni k}y_{t,B}\). Feasibility requires \(z_{t,k}z_{u,k}=0\) for every conflict edge \(\{t,u\}\) and channel \(k\). Maximize

\[ \sum_{t\in T} b_t\sum_B y_{t,B}. \]

A solution is the allocation vector \(y\) attaining maximum total welfare. Each allocated infinitesimal user still receives exactly the requested number of whole channels; only the fraction of the population served can be fractional.

This is a plausible high-multiplicity regime for managed radio networks with repeated device and service classes: many users share a standardized bid and request, and have the same interference relationships. If there are \(\tau\) types and \(R\) identical users per type, the discrete population has \(n=R\tau\) users. \(R\) can grow arbitrarily while the continuous instance and its support size \(\tau\) remain unchanged.

The hardness survives exactly. Set \(K=d_t=1\) and give every type mass \(1/\tau\) and bid \(1\). The types receiving positive mass must form an independent set of \(H\). Since bids are positive, any chosen type can be served in full, so an optimum corresponds exactly to a maximum independent set. The discrete high-multiplicity counterpart is the graph obtained by replacing each vertex with \(R\) noninterfering twins and putting complete conflicts between twin classes corresponding to adjacent vertices. Its optimum is \(R\) times the original independent-set optimum. Thus the continuous problem is expected to be hardness-transferring (Class B): the combinatorics remain in the type-conflict graph even as the population grows. In this subcase, a continuous approximation would also yield an approximation for maximum independent set.

The authors should recognize this as their allocation question in a homogeneous population regime: the bids, strict requests, channels, and interference feasibility are retained, while identical bidders are represented by mass. The mirror covers Theorem 1’s allocation-hardness result, not the paper’s truthfulness claims or simulations. It invites follow-up questions about parameterized algorithms in \(\tau\), and tractability on restricted conflict graphs.

The weakest point is the network restriction: a type pair is either wholly compatible or wholly conflicting, and same-type users never interfere. That is a structured clone regime, not every radio deployment. It is still an honest mirror of SA-SR on a natural high-multiplicity subclass, and it preserves the theorem’s hard allocation core.

The case AGAINST (opponent, writing after the proponent)

The case against rests on a mismatch between the paper’s radio network and the type graph the proposed mirror needs. Theorem 1 is a genuine computational anchor, and the proponent’s reduction works mathematically: with \(K=d_t=1\), the continuous optimum is a maximum-weight independent set in \(H\), with type \(t\)’s weight \(b_t\mu_t\). Equal masses and bids give \(\alpha(H)/\tau\). I can’t dismiss that as a bad answer just because the hardness transfers.

The concern is what makes that construction a high-multiplicity *radio* market. Every pair of users of adjacent types must interfere, while users of the same type never interfere. Growing a type’s mass therefore means adding arbitrarily many mutually noninterfering “twins” with exactly the same external conflict pattern. That is a specific, restrictive structure for a model whose bidders are distinguished by location and whose interference comes from proximity. In the paper’s bounded geographic region with fixed interference radius, a same-type class of mutually noninterfering users must be spatially separated; packing bounds its size. The clone construction can represent an abstract conflict graph, but the article does not establish that such arbitrarily large clone classes are a convincing regime for its spatial setting.

A more literal spatial continuum has a different problem. With hard distance-based interference, users assigned to one channel must form a pairwise separated set. In a bounded region, such a set has zero area, so an atomless population assigns zero mass to every feasible set; with finitely many channels, total served mass and welfare collapse to zero. A normalized large-area limit at fixed density also makes pairwise conflicts negligible almost everywhere. Preserving nonzero local interference would require an extensive, local-limit model or a change to average or probabilistic interference constraints. Those could be interesting problems, but they do not yield the finite-support mass allocation proposed here.

So the clone-symmetric version survives as a legitimate abstract mirror of Theorem 1. The strongest objection is that the proponent has not shown it is a worthwhile continuization of this paper’s physical network model: in the natural spatial version, hard interference makes the atomless allocation degenerate; in the tractable finite-type version, the required large classes are an artificial network regime. That objection lowers confidence, but it does not defeat the anchor universally. A fully honest negative verdict is weak here.
