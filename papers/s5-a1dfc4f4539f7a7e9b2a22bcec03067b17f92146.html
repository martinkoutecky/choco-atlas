The continuous mirror question

Given finite type sets \(A,B\), rational masses \(\mu_a,\nu_b\) summing to \(1\), and weak rankings of opposite-side types and \(\bot\), find an exact rational flow \(x_{ab},u_a,v_b\ge0\) satisfying \(\sum_b x_{ab}+u_a=\mu_a\) and \(\sum_a x_{ab}+v_b=\nu_b\), with positive \(x_{ab}\) only for mutually acceptable types. For each type pair require \(D_a(b;x)=0\) or \(D_b(a;x)=0\), where \(D_a(b;x)=u_a\mathbf 1[b\succ_a\bot]+\sum_{b':\,b\succ_a b'}x_{ab'}\), and define \(D_b\) symmetrically. Also require Pareto efficiency: among reassignments of the same atomless individuals, none weakly improves everyone and strictly improves a positive measure. Is such a flow computable in time \(\operatorname{poly}(\tau,L)\), where \(\tau=|A|+|B|\) and \(L\) is the input bit length?

The model it lives in

A bipartite atomless matching market with finite preference types and rational type masses. The decision variables are type-pair match masses and unmatched masses; each individual still receives one partner or remains unmatched. Stability forbids positive mass on both sides willing to switch to each other, and Pareto efficiency compares reassignments of the same individuals.

What the mirror covers

The mirror covers Theorem 1’s computation of a Pareto-stable outcome. It does not carry over the theorem’s individual strategyproofness guarantee, and it leaves the college-admissions result and the paper’s technical lemmas unmirrored.

Open questions for a prover

  • Can a Pareto-stable flow be computed in time \(\operatorname{poly}(\tau,L)\), rather than by expanding the masses into a potentially much larger finite market?

The case FOR (proponent)

My lead anchor is Theorem 1, proved in this paper. It says that Algorithm 2 runs in polynomial time and, for every SMIW instance with incomplete weak preferences, returns a matching that is individually rational, weakly stable (has no strongly blocking pair), and Pareto-optimal; truthful reporting is weakly dominant for the men, for any fixed utility assignment chosen independently of the men’s reports. The paper has no named computational-hardness result to use as an anchor, so this is an algorithmic case.

The mirror I would put to a prover is Weak Pareto-Stable Mass Matching, \(\mathrm{WPSM}_{\infty}\). Consider two atomless populations with finite type sets \(A\) and \(B\). A type is a complete preference description: each \(a\in A\) has a weak ranking of \(B\cup\{\bot\}\), and each \(b\in B\) has a weak ranking of \(A\cup\{\bot\}\), where \(\bot\) is being unmatched. The type masses \(\mu_a,\nu_b\) are binary rationals with \(\sum_a\mu_a=\sum_b\nu_b=1\). The decision variable is \(x_{ab}\ge 0\), the mass of \(a\)-agents matched to \(b\)-agents, together with unmatched masses \(u_a,v_b\), satisfying
\[ \sum_b x_{ab}+u_a=\mu_a,\qquad \sum_a x_{ab}+v_b=\nu_b. \]
A positive \(x_{ab}\) is allowed only when both types weakly prefer each other to \(\bot\). Each person still receives one actual partner or is unmatched; only the type-level totals are divisible.

For weak stability, define the mass of type \(a\) willing to leave its current assignment for \(b\) as
\[ D_a(b;x)=u_a\,\mathbf 1[b\succ_a\bot] +\sum_{b':\,b\succ_a b'}x_{ab'}, \]
and define \(D_b(a;x)\) symmetrically. Require \(D_a(b;x)=0\) or \(D_b(a;x)=0\) for every pair \((a,b)\): there must not be positive mass on both sides willing to switch to each other. For Pareto optimality, realize the flow on fixed atomless sets of agents of each type and compare it with reassignments of those same people. The flow is Pareto-optimal if no reassignment makes everyone weakly better off and a positive measure strictly better off. The problem is: given the type masses and rankings, return an exact rational flow with both properties, or determine that none exists. The intended complexity measure is \(\operatorname{poly}(\tau,L)\), where \(\tau=|A|+|B|\) and \(L\) is the input bit length.

A plausible regime is a large centralized graduate-placement market: many candidates and one-to-one positions, but relatively few recurring qualification and job types. Each type carries the full ranking information the market uses, including ties and acceptability. Thus \(N\) can be very large while \(\tau\ll N\). The mass flow is the aggregate of integral person-to-person matches, not a claim that an individual receives a fractional partner. That preserves the paper’s matching question while making the population itself continuous.

I would expect this outcome problem tentatively to be Class A: it has only \(O(\tau^2)\) type-pair variables, and the paper’s algorithm suggests that tie-handling and Pareto refinement may have exploitable structure. This is a conjectural route, not a consequence of Theorem 1: the no-blocking condition above is disjunctive, so a direct LP is not established. Fractional matching work gives a close mathematical neighbor: it studies ordinally stable fractional assignments, including with ties, and provides polynomial-time stable-flow constructions. It also reports NP-completeness for maximizing welfare among ordinally stable matchings with ties, which makes the Pareto-selection step a real concern; that optimization hardness does not itself prove this search problem hard. [Chen, Roy, and Sorge, “Fractional Matchings under Preferences: Stability and Optimality”](https://www.ijcai.org/proceedings/2021/0013.pdf)

The weakest point is also the main scope limit: the paper’s distinctive strategyproofness guarantee does not carry over to this atomless model. One person’s report changes zero mass, so individual truthfulness becomes vacuous. I would mirror Theorem 1’s computed Pareto-stable outcome, not claim a continuous version of its mechanism. A meaningful incentive follow-up would need a different model, such as a positive-mass cohort reporting jointly or a tagged individual in a continuum market. The main further questions are whether every rational-mass instance admits a Pareto-stable flow, whether one can find it in \(\operatorname{poly}(\tau,L)\), and how its Pareto property relates to stable matchings in large replicated finite markets.

The case AGAINST (opponent, writing after the proponent)

The strongest objection is that Theorem 1’s distinctive contribution is strategyproofness for individual men. In an atomless model, one person’s report changes zero mass, so a mechanism based on the reported type distribution cannot respond to that report. Truthfulness becomes automatic. A nontrivial incentive version would need either positive-mass individuals, which abandons the atomless model, or jointly reporting cohorts, which changes who the strategic agents are and what counts as a deviation.

That objection does not defeat the proposed \(\mathrm{WPSM}_{\infty}\) mirror. Theorem 1 also guarantees a Pareto-stable outcome, and the type-flow model can preserve stability and Pareto comparisons when agents of each type are genuinely interchangeable. Its positive-mass blocking condition is a natural continuum counterpart. Replicating rational masses gives a finite instance and hence an existence argument, but that does not settle whether the flow can be found in time polynomial in \(\tau\) and the input bit length. The fractional-matching work cited in the proponent’s case is a neighbor, not evidence that this continuous-population computation is already done.

So the negative case is weak where it matters: I can argue that the theorem’s incentive guarantee does not carry over, but I cannot honestly rule out a worthwhile outcome mirror. The proponent’s anchor survives that objection.
