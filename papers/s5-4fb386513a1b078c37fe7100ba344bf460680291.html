The continuous mirror question

Given a finite type set \(T\), rational masses \(\mu_t\ge 0\) with \(\sum_{t\in T}\mu_t=1\), an explicit finite set \(Q\subseteq\mathbb{N}^{T}\setminus\{0\}\) of feasible team compositions containing every singleton, and rational team values \(w(q)\), choose real team frequencies \(z_q\ge 0\) to maximize \(\sum_{q\in Q}w(q)z_q\), subject to \(\sum_{q\in Q}q_tz_q=\mu_t\) for each \(t\in T\). For fixed maximum team size \(b\), does this continuous coalition-structure problem admit an efficient algorithm?

The model it lives in

Each type captures all decision-relevant agent properties, and each \(q\in Q\) is an integral team composition. The variable \(z_q\) is the real aggregate frequency of such teams in a population of unit mass. With fixed \(b\), there are at most \(O(|T|^b)\) possible compositions, so the stated problem is an explicitly represented linear program.

What the mirror covers

The mirror covers exact coalition-structure optimization for typed agents with explicit, bounded-size feasible compositions. It does not cover DyPE’s pseudotree search, its graph-sensitive complexity comparisons, or its empirical speedups.

Open questions for a prover

  • Can the problem remain tractable when feasible compositions are implicit and require an efficient pricing algorithm?
  • How quickly do discrete optima approach the continuous optimum as population size grows with fixed type proportions?

The case FOR (proponent)

The strongest case I would defend is a Continuous Typed Coalition Structure Generation mirror, anchored in Theorem 1 (Correctness). It says that, for any graph-restricted CSG instance, DyPE calculates an optimal coalition structure. The paper proves this theorem. It establishes exactness, not a complexity class. The paper’s introduction says classical CSG is NP-hard, citing Sandholm et al. (1999), but gives no numbered theorem for that claim; its complexity bounds for DyPE are also unnumbered. So the formal anchor here is the underlying optimization problem, not a claimed P-versus-NP result.

Consider a large pool of agency staff forming joint response teams. There may be many staff members but relatively few complete, decision-relevant types: people with the same role, skills, costs, and compatibility with other roles. A type must capture everything that affects coalition feasibility or value. Let \(T\) be the types, \(\mu_t\) the fraction of the workforce of type \(t\), \(Q\) an explicit finite set of feasible team compositions \(q\in\mathbb{N}^{T}\setminus\{0\}\), and \(w(q)\) the value of a team with composition \(q\). Include singleton teams so every type can be assigned.

The continuous problem is: choose \(z_q\ge 0\), the aggregate number of teams of composition \(q\) per unit of population, to maximize \(\sum_{q\in Q} w(q)z_q\), subject to \(\sum_{q\in Q}q_tz_q=\mu_t\) for every \(t\). A composition still has an integral number of members of each type; \(z_q\) is real because it describes the aggregate frequency of such teams in the continuous population. Feasibility restrictions, including a type-level synergy graph, can be encoded in \(Q\). This is a linear program, solvable in time polynomial in its explicit input size. If team size is bounded by a fixed \(b\), the number of possible compositions is \(O(\tau^b)\), where \(\tau=|T|\).

This preserves the paper’s central question: partition agents into feasible coalitions to maximize the sum of coalition values. It also gives the authors a recognizable high-multiplicity regime, with \(N\gg\tau\). A finite typed workforce maps to \(z_q=(\text{number of teams of composition }q)/N\), so every discrete partition gives a feasible continuous solution. As \(N\) grows with type proportions fixed and \(Q\) finite, the discrete aggregate frequencies can approximate the continuous ones. The expected outcome is Class A for this stated mirror: the continuous problem is an LP, and the discrete partition integrality can cease to be the bottleneck.

The scope is the coalition-structure optimization underlying Theorem 1, including type-homogeneous feasibility restrictions. It does not claim a continuous version of DyPE’s pseudotree search or its empirical speedups. The soft spot is that this is a type-symmetric regime with an explicit coalition-composition set. The paper allows values and synergy relations over named agents; if those depend on individual identities, or if feasible compositions are implicit and difficult to price, this LP may no longer be an efficient mirror. The follow-up questions are whether implicit composition sets admit efficient pricing, how quickly discrete optima approach the continuous optimum, and when the type-level compatibility structure preserves useful graph structure.

The case AGAINST (opponent, writing after the proponent)

The paper-specific anchor is weaker than the proponent suggests. Theorem 1 proves that DyPE returns an optimal coalition structure; it does not state a complexity bound. The complexity comparisons appear in the paper’s analysis, without a numbered complexity theorem. So this mirror is anchored in the underlying CSG problem, not in a named complexity result of the paper.

The proposed Class A case also gets its tractability from a restrictive input choice. With an explicit composition set \(Q\), the model is the standard set partitioning integer program with its integrality constraints relaxed: the discrete model uses integer team counts \(y_q\), while the continuous model lets \(z_q\) be real. If team size is bounded by a fixed \(b\), then \(|Q|=O(\tau^b)\), and a generic LP solver suffices. That establishes a tractable type structured regime. It does not establish tractability for the paper’s broader graph restricted problem, where coalitions and their values may be implicit. Keeping those compositions implicit would require a pricing algorithm, which the proposed mirror leaves open.

That is the strongest case against this particular formulation: its clean polynomial bound depends on specifying the columns and bounding team size, while the paper’s algorithm is about searching over graph constrained coalitions. But it does not defeat the better mirror. A large workforce with repeated roles, type determined compatibility, and bounded team sizes is a plausible CSG regime. Real valued frequencies of integral team compositions give that regime a coherent population interpretation. Allowing implicit compositions turns the pricing problem into a natural computational question for the programme’s continuous optimization toolkit.

Existing type based CSG work reinforces that this is a sensible regime, which counts in favor of the mirror under the programme’s rules. For example, Aziz and de Keijzer give polynomial time algorithms for CSG with known, fixed player types in a monotonic setting; that is supporting precedent, not a collision with the proposed continuous population model. [Their paper](https://arxiv.org/abs/1101.1007)

So the negative case can narrow the claim: the stated LP is a tractable mirror for a restricted input regime, and it does not by itself mirror DyPE’s graph sensitive complexity analysis. I cannot honestly extend that into a case that no worthwhile continuous mirror exists in any scenario. The bounded team size version is already plausible, and the more general pricing version remains a worthwhile question.
