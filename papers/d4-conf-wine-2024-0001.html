The continuous mirror question

For fixed \(k\), given finitely many complete compatibility types \(T\) with rational masses \(\mu_t\), and allowed cycle patterns \(C\) of lengths \(2,\ldots,k\), choose feasible cycle masses \(x_C\ge 0\) satisfying \(\sum_C a_t(C)x_C\le \mu_t\) for every type \(t\), where \(a_t(C)\) counts its positions in \(C\). What is the maximum total participating mass \(\sum_C |C|x_C\)? Repeated appearances of a type in a pattern use distinct agents.

The model it lives in

A typed barter market with per-capita supply \(\mu_t\), complete item and acceptance profiles, and bounded directed cycle patterns. The decision variables are cycle masses \(x_C\); type capacities constrain their use, and the objective maximizes participating mass while each participating unit receives one indivisible item.

What the mirror covers

Covers the high-multiplicity welfare benchmark underlying Theorem 1.2; leaves the truthful mechanism guarantee, non-uniform length-function results, and local-search results unmirrored.

Open questions for a prover

  • Can a nonatomic individual-report incentive model be defined for these cycle flows, and can a truthful mechanism attain a nontrivial welfare approximation?
  • How does the complexity change when \(k\) is part of the input?

The case FOR (proponent)

The strongest honest mirror I see is the high-multiplicity welfare benchmark for \(k\)-barter exchange, rather than the paper’s truthfulness claim.

My anchor is Theorem 1.2, proved in this paper: for every fixed \(k\ge 3\) and constant \(\epsilon>0\), the \(k\)-BE problem admits an efficient truthful mechanism with approximation ratio \(k-1+\epsilon\). Its benchmark is the maximum number of agents participating in compatible, disjoint trading cycles of length at most \(k\). The paper’s introduction also says that computing this optimum is NP-hard for \(k\ge3\), citing Abraham, Blum, and Sandholm; that hardness is stated in prose, not as a numbered result here. Theorem 1.3 is a lower bound on truthful mechanisms’ approximation ratios, not a complexity-class hardness result, so I would not present it as one.

Here is a continuous problem for Theorem 1.2’s welfare benchmark. Call it Type-Continuum \(k\)-Barter Packing. Fix \(k\). An instance has a finite set \(T\) of \(\tau\) complete agent types, rational masses \(\mu_t\ge0\) summing to \(1\), and for each type \(t\), a set \(A_t\subseteq T\) of item types its members are willing to receive. Members of a type have the same item class and the same full compatibility profile. A cycle pattern \(C=(t_1,\ldots,t_\ell)\), for \(2\le\ell\le k\), is allowed when each type accepts the next type’s item, cyclically. A type may occur more than once in a pattern, with distinct agents occupying those positions.

For each allowed pattern, choose \(x_C\ge0\), the mass of copies of that cycle. If \(a_t(C)\) is the number of positions of type \(t\) in \(C\), require
\[ \sum_C a_t(C)x_C\le\mu_t \qquad\text{for every }t\in T. \]
The question is to find feasible cycle masses maximizing
\[ \sum_C |C|x_C. \]
The solution is the cycle mass assigned to each pattern, together with the unused mass of each type. Every participating unit still receives one whole item through a cycle; only the aggregate amount of a type assigned to each pattern is fractional.

A plausible regime is a large home-swap platform batch for one set of dates, with homes grouped into a modest catalogue of location and amenity classes. A type records both its home class and its complete set of acceptable destination classes. Many users can then share one of \(\tau\) profiles, with \(n\) users far larger than \(\tau\). That is a population-composition model: mass means a share of the batch, and the bounded cycle length captures the platform’s concern about long cancellation chains. The scenario is deliberately a typed market; the paper’s own named-agent wish lists need not have this structure in every instance.

For fixed \(k\), this mirror is Class A: there are at most \(\sum_{\ell=2}^{k}\tau^\ell\) cycle patterns, so the stated problem is a linear program of polynomial size in \(\tau\) and the input bit length. It also has a useful high-multiplicity bridge. Given \(n_t\) discrete agents of each type, set \(\mu_t=n_t/n\). Scaling a feasible continuous solution by \(n\) gives a fractional cycle packing; flooring each cycle count gives a feasible integral packing. An optimal basic solution has at most \(\tau\) positive cycle variables, so this rounding loses at most \(k\tau\) participants. Thus the discrete optimum is at most \(n\) times the continuous optimum and at least that value minus \(k\tau\). When \(n\) is large relative to \(\tau\), the aggregate problem gives a tight additive benchmark.

The limitation is also the weakest point of this case: Theorem 1.2 is about truthful mechanisms, while this LP mirrors only the optimization benchmark those mechanisms approximate. In a nonatomic population, one person has zero mass, so a truthful-reporting condition needs a separate account of how that person’s report affects their own assignment. The paper’s finite-agent incentive arguments do not automatically carry over. I think the authors would recognize this as a continuous high-multiplicity version of the combinatorial \(k\)-BE problem, but I would not claim it is already a continuous analogue of their dominant-strategy result. The next questions are whether a meaningful individual incentive model can coexist with these cycle flows, and whether the same LP remains useful when \(k\) is part of the input.

The case AGAINST (opponent, writing after the proponent)

The strongest objection is that the proposed mirror changes what Theorem 1.2 is about. That theorem gives an efficient truthful mechanism with approximation ratio \(k-1+\epsilon\). The proposed LP computes the optimum cycle packing for a typed population. It imposes no truthfulness constraint, so solving it exactly does not reproduce the paper’s result. The rounding argument links the LP benchmark to a discrete packing benchmark; it says nothing about whether the paper’s incentive-compatible mechanisms, or any continuum mechanism, can attain that benchmark. The paper does contain named computational results, so “no result to mirror” is not a sound objection. The sharper point is that the proposed question mirrors the optimization benchmark beneath one of those results, not its strategic contribution.

There is also a real modelling cost in getting to that LP. In the paper, an agent owns a particular item and names particular other agents whose items they will accept. With finitely many types as the population grows, compatibility must instead factor through item and preference classes: everyone of one type accepts items from the same classes. That is plausible for a deliberately typed market, but it is a structural restriction. If types preserve arbitrary named-agent wish lists, their number can grow with the population and the claimed polynomial bound in \(\tau\) may offer little. So the LP is cleanest for a related, more structured barter market.

A closer mirror would define a continuum mechanism, with per-capita assignments or lotteries for individuals of each reported type, and ask whether it can achieve a welfare approximation while remaining truthful. The proposed cycle masses do not specify those assignments or what utility an individual gets by changing their report. An atomless person does not change the aggregate masses by deviating, but their report could still change their own assignment; capturing that incentive requires more than the packing LP. Treating a positive mass as the deviator would define a coalition incentive condition, which is different from the paper’s dominant-strategy condition.

Those are meaningful reasons to resist calling the proposed LP a continuous version of Theorem 1.2. They do not establish that no worthwhile mirror exists, though. A large market with standardized item classes and a modest number of complete compatibility profiles is a plausible high-multiplicity regime, and its bounded-cycle welfare problem is a well-posed population-continuous question. For fixed \(k\), its cycle-packing LP has at most \(\sum_{\ell=2}^{k}\tau^\ell\) variables. That makes the mirror straightforward and perhaps less revealing than the paper’s incentive result, but under the programme’s stated criteria a simple Class A answer can still count.

So the negative case is weak at its universal claim. It can show that the proponent’s LP does not carry over the paper’s truthfulness result, and that its tractability depends on a substantive type restriction. It cannot honestly rule out the typed-market mirror; if a continuous welfare benchmark is sufficient to anchor a mirror, this one likely survives.
