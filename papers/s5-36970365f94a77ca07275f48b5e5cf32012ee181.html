The continuous mirror question

Given a rational distribution μ over applicant types, each recording its applications, first choice, and scores, together with overlapping quota sets p and per-capita quotas q_p, compute the set F of types whose first-choice application is selected by the Hungarian score-tier choice rule for every quota set containing that programme. Certify that, whenever a stable mass allocation exists, all of each type's mass in F is assigned to its first choice in every such allocation.

The model it lives in

Types carry mass μ_t and the application and score information needed by the screening rule; quota sets carry capacities q_p. For each quota set, aggregate mass by score tier and apply the restrictive rule that rejects a tier when including it would exceed the quota. Return the qualifying types and their masses; no global allocation is a decision variable in this screening problem.

The objection that survived

The paper gives no evidence that its 2008 or 2009 instances have τ ≪ N, so the high-multiplicity usefulness of the mirror on those particular datasets is unverified.

The case FOR (proponent)

There is a defensible continuous mirror here, but it is narrow: the paper’s preprocessing results for stable admissions with common quotas. The natural regime is a large national admissions cohort in which many applicants share the same complete preference list, scores at the relevant quota sets, and application options. For example, a system might have \(N\) applicants but only \(\tau \ll N\) distinct such profiles. Each type \(t\) has mass \(\mu_t\), and each programme or overlapping quota has capacity \(q_p\), measured as a fraction of the cohort. This is a plausible regime for the paper’s 80,000-plus applicant setting, though the article does not report how many distinct complete types its data contain.

For a precise mirror, let a type include everything the paper’s model uses: its programme ranking, applications, and scores. For each quota set \(p\), define the Hungarian choice rule on mass by taking the highest-scoring whole score tiers that fit within \(q_p\); if a tied tier would exceed the quota, reject that tier. A stable mass allocation is induced by quota cutoffs: each type goes to its most-preferred programme for which it meets every relevant cutoff, or remains unmatched. Under this policy, an identical type is assigned as a whole. The continuous object is the distribution of applicants and the per-capita quotas; the paper’s equal-treatment rule does not permit splitting a type across outcomes.

My lead anchor is Lemma 3, proved in this paper. It says that if an applicant’s first-choice application is selected by the Hungarian choice function from all applications for every common-quota set containing that programme, then the application belongs to every stable solution. The lemma states the corresponding result for the Chilean choice function too: if the first application is selected by each relevant Chilean choice function, it is in every stable solution.

The continuous question I would hand to a prover is Forced First-Choice Mass (\(\mathrm{FFCM}_H\)). The input is a rational distribution over complete applicant types, the ranked programme and quota sets, and per-capita quotas. Compute the set
\[ F=\{t:\text{the first-choice application of }t\text{ is selected by every relevant } \mathrm{Ch}^H_p\text{ on the full application distribution}\}. \]
The output is the types in \(F\), their masses, and a certificate that, whenever a stable allocation exists, all of each such type’s mass is assigned to its first choice in every stable allocation. This is a faithful mass version of the paper’s forced-acceptance preprocessing. I expect this screening problem to be tractable: aggregate mass by score tier for each quota set and scan the tiers. Its likely running time is polynomial in the support size, number of quota sets, and input bit length. That algorithmic expectation is an inference from the lemma’s test, not a complexity bound proved in the article.

A second useful anchor is Lemma 4, also proved here. It says that for an application \((a_i,c_j)\), if adding it to \(F_j\), the set of first applications to \(c_j\), produces a set from which some relevant Hungarian choice function excludes it, then that application cannot appear in any stable solution. The lemma gives the parallel Chilean-policy statement.

Its continuous counterpart is First-Choice Competition Rejection (\(\mathrm{FCR}_H\)). For each type’s non-first-choice application to programme \(c_j\), take the mass distribution of first applications \(F_j\) and add an infinitesimal probe applicant with that type’s scores. If some relevant quota choice rule excludes the probe as its mass tends to zero, output that type-programme pair as forbidden, with the certificate that no stable allocation can assign mass of that type to that application. This, too, looks tractable by score-tier aggregation. The probe is important: adding the type’s full mass would ask a different question from Lemma 4’s single-applicant test.

These mirrors cover only the paper’s forced-acceptance and forced-rejection preprocessing, not its full stable-matching IPs. They generate a larger, natural question: Mass Stable Admissions with Overlapping Quotas—given the same type distribution and per-capita quotas, decide whether a cutoff-induced stable mass allocation exists and return one if it does. For the unrestricted version I expect hardness to transfer: a discrete instance embeds by giving each applicant a distinct type of mass \(1/n\) and scaling each quota \(u_p\) to \(u_p/n\). The paper’s common-quota NP-hardness claim is cited to Biró et al. (2010), rather than stated as a numbered complexity result in this paper, so I do not use it as an anchor. At moderate \(\tau\), whether the full problem becomes tractable is a further question.

The paper does not contain a numbered theorem classifying its main stable-admissions problem as NP-hard, in P, or otherwise. Lemmas 3 and 4 are the named computational results I can anchor on; the full-problem hardness discussion is prior work cited in the text. Section 6.5 gives practical evidence for the value of these lemmas: the authors report fixing 23,138 applications as accepted and 14,991 as rejected in preprocessing on the 2008 instance, reducing the longest reported runtime from 158,949 seconds to 10,740 seconds.

The soft spot is that the anchored results are preprocessing rules, not a continuous solution to the paper’s full matching problem. Also, the full type must capture complete rankings and scores, so the support could approach the number of applicants; and under the Hungarian policy identical types cannot be divided fractionally. The mirror is most persuasive where many applicants really do share those complete profiles and the quota masses are the meaningful scale.

The case AGAINST (opponent, writing after the proponent)

The strongest case against these anchors starts with what the paper actually proves. Lemmas 3 and 4 establish sufficient conditions for an application to appear in, or be excluded from, every stable solution. Neither gives a complexity classification or an algorithmic bound. The NP-hardness of common quotas is cited from earlier work; this paper’s computational contribution is its IP formulations and experiments on discrete instances.

\(\mathrm{FFCM}_H\) preserves Lemma 3, but its mass version is just a weighted version of the same local check. For each quota set, sum the mass in each score tier, scan the tiers against the quota, and test whether each type’s first choice passes every relevant check. With \(\tau\) types and \(P\) quota sets, this is a direct sorting-and-summing procedure, polynomial in the input size. It never has to find a stable allocation. That may be useful preprocessing, but the continuous formulation adds no substantive computational question: it replaces counts with rational weights, and the result follows almost immediately from the lemma. The paper gives no evidence that its exact applicant profiles have small support; its instances contain tens of thousands of applicants with detailed preferences and scores. If a different admissions regime does have repeated complete profiles, the screening calculation remains just as simple.

\(\mathrm{FCR}_H\)’s infinitesimal probe has a more basic problem. The Hungarian rule is discontinuous at a quota boundary. If a quota is \(1\) and a score tier has mass \(1\), that tier fits; add any positive mass tied at the same score and the whole tier is rejected. A zero-mass probe therefore does not have a canonical admission status at the boundary: evaluating it at zero mass and taking the limit from positive mass give different answers. One can repair the question by adding the candidate type’s whole positive mass and recomputing the score-tier choice. But that is a different test from Lemma 4’s single-applicant test, and it is still a local weighted scan. Asking instead whether the application can occur in any global stable allocation would be more substantial, but then the proposed anchor has become the full stable-admissions problem.

That full problem is the weak point in a universal negative. Mass Stable Admissions with overlapping quotas is a sensible, in-scope question, and the article supplies a natural cutoff-based model for it. I cannot honestly rule out a worthwhile study of that problem in a regime with a genuinely small number of complete types. So these two lemma-based mirrors do not make a strong case for ChoCo’s time, but the paper’s broader matching problem prevents me from claiming that no worthwhile continuous mirror exists in any scenario.
