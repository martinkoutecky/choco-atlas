The continuous mirror question

Given a project set \(M\), budget \(B\), and finite support \(T\) of monotone submodular valuation types, each depending nontrivially on at most a fixed constant \(d\) items, with rational masses \(\mu_t\ge 0\) summing to \(1\), can one compute in polynomial time a \((1-1/e+\epsilon)\)-approximation to \(\max_{S\subseteq M,\ |S|\le B}\sum_{t\in T}\mu_t v_t(S)\), for fixed \(\epsilon>0\)?

The model it lives in

A municipality chooses one indivisible project set \(S\subseteq M\) with \(|S|\le B\). Residents are represented by a finite support \(T\) of complete project-valuation types with rational masses \(\mu_t\); the objective is \(\sum_{t\in T}\mu_t v_t(S)\).

What the mirror covers

Covers the constant-size valuation computational hardness clause of Theorem 1.3. It does not mirror that theorem’s communication complexity clauses or the paper’s welfare maximization and max-min allocation results.

Open questions for a prover

  • How does the approximation complexity depend on the support size \(\tau=|T|\), especially when \(\tau\) is small relative to \(|M|\)?
  • Which parameterized algorithms are possible in \(\tau\), \(B\), and the constant valuation support bound \(d\)?

The case FOR (proponent)

I’d lead with the paper’s Combinatorial Public Projects result. It gives a direct population mirror while leaving the public decision itself intact: a city, for example, chooses at most \(B\) projects from a set \(M\), and residents value the same chosen set.

Call the mirror \(\mathrm{CPP}_{\infty}\). An instance consists of \(M\), \(B\), and a finite support \(T\) of resident types. A type \(t\) is a complete project valuation \(v_t:2^M\to\mathbb{Q}_{\ge 0}\); two residents share a type only if they have the same valuation for every possible project set. The society is given by rational masses \(\mu_t\ge 0\) with \(\sum_t\mu_t=1\). The question is to find a set \(S\subseteq M\), \(|S|\le B\), maximizing
\[ \mathrm{SW}_{\mu}(S)=\sum_{t\in T}\mu_t v_t(S). \]
The solution is an ordinary project set \(S\). Only the population is continuous.

A plausible regime is a large municipality choosing a portfolio of public investments for a population much larger than the number of distinct project-valuation profiles. The profiles might describe, for example, recurring household or neighborhood needs. In a finite electorate of size \(N\), each type has \(N\mu_t\) residents when those counts are integral. Taking \(N\) to be a large multiple of a common denominator makes every positive-mass type numerous while keeping the distribution and the project decision unchanged.

The anchor is Theorem 1.3, proved in this paper. Its full statement is: for submodular CPP, a \((3/4+\epsilon)\)-approximation requires exponential communication; with two players, a \((7/8+\epsilon)\)-approximation requires exponential communication; and for constant-size submodular valuations, a \((1-1/e+\epsilon)\)-approximation would imply \(P=NP\), for every \(\epsilon>0\). I rely on the computational clause. The paper proves it by adapting a Max \(k\)-cover reduction; it notes that the underlying reduction was already used in [6], while the constant-size-valuation observation is the added point.

The continuous question for that anchor is: given \(\mathrm{CPP}_{\infty}\) with each valuation depending nontrivially on at most a fixed constant \(d\) items, can one approximate \(\max_{|S|\le B}\sum_t\mu_t v_t(S)\) within \(1-1/e+\epsilon\) in polynomial time? The expected answer is hardness. Given a discrete CPP instance with \(N\) agents, group agents with identical valuations and set \(\mu_t=n_t/N\), where \(n_t\) is the number of agents of type \(t\). For every project set \(S\),
\[ \sum_{i=1}^{N}v_i(S)=N\sum_t\mu_t v_t(S). \]
So the objectives differ only by a positive scale factor: the optimum and every approximation ratio are preserved. Conversely, rational masses can be realized by a finite electorate after scaling by a common denominator. The theorem’s reduction uses constant-size valuations, so this correspondence preserves the anchor’s restriction.

I expect hardness transfers (Class B). The hard combinatorics lie in choosing projects from the agenda under a cardinality budget. Aggregating residents into masses does not fractionalize that choice: everyone values the same selected set, and the optimization remains over \(S\subseteq M\). This is a particularly plausible mirror of the authors’ underlying CPP problem. My case covers the computational hardness result only; it does not claim to mirror the paper’s communication-complexity statements.

The main follow-up is how the complexity changes with \(\tau=|T|\), \(B\), and \(d\): does comparable hardness persist when the type support is small relative to the project set, and what parameterized algorithms become possible? My weakest point is that Theorem 1.3 does not establish hardness for a fixed, small \(\tau\). Its reduction may use a growing number of distinct valuation types. Replicating the electorate makes \(N\) much larger than \(\tau\), but does not shrink \(\tau\); the theorem therefore supports a high-multiplicity regime with growing support, not a claim of hardness for a fixed handful of archetypes.

The case AGAINST (opponent, writing after the proponent)

The strongest negative point is that the hardness reduction behind Theorem 1.3 may use a support as large as the electorate. In its Max \(k\)-cover construction, each bidder corresponds to a universe element, and that element’s unit-demand valuation records which items cover it. Unless many elements have the same incidence pattern, aggregation leaves \(\tau\) large. Repeating every bidder \(R\) times makes the population \(R\) times larger but does not reduce \(\tau\). So the theorem does not establish hardness in a regime with a small number of resident types. A sharper follow-up would ask what happens when complexity is measured in \(m,\tau,L\), especially for small \(\tau\).

That objection does not defeat the mirror, though. The strongest version takes types to be complete submodular project valuations and asks for a budget-feasible project set maximizing \(\sum_t\mu_t v_t(S)\). This is a sensible population model for a municipality with recurring household or neighborhood profiles. It preserves the paper’s computational problem and its indivisible public decision. Welfare is additive across agents, so mass aggregation is exact; the question does not depend on individual identities or become vacuous in the continuum.

The result is also a real computational anchor: Theorem 1.3 proves the constant-size-valuation hardness clause. Its discrete instances embed as rational-mass instances, and high-multiplicity support is evidence for the model’s plausibility under the programme’s rules. The fact that project choices remain discrete, or that the known reduction does not settle small-\(\tau\) behavior, is not a fundamental objection.

I cannot honestly defeat this anchor. The negative case is weak here: the low-support limitation narrows what the theorem establishes, but leaves a worthwhile continuous CPP question standing.
