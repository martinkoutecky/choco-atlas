The continuous mirror question

Given an item set \(E\), types \(T\) with rational masses \(\mu_t>0\) summing to \(1\), rational nonnegative per-member utilities \(u_{tj}\), and per-capita submodular capacities \(\rho\), choose type-level assignment lotteries \(x_{tj}\ge 0\). Require \(\sum_j x_{tj}\le 1\) and \(z_j=\sum_t\mu_t x_{tj}\in P(\rho)\); define \(U_t(x_t)=\sum_j u_{tj}x_{tj}\), require envy-freeness \(U_t(x_t)\ge U_t(x_s)\) for every \(t,s\), and weighted Nash welfare \(W_\mu(x)=\exp(\sum_t\mu_t\log U_t(x_t))\). Let \(W_\mu^*\) be the maximum over all feasible assignments, without the envy-free constraint. Can an algorithm, polynomial in \(|E|\), \(|T|\), the input bit length, and \(\log(1/eta)\), return an envy-free feasible assignment with \(W_\mu(x)\ge W_\mu^*/(e^{1/e}+\eta)\), using value-oracle access to \(\rho\)?

The model it lives in

A continuum of agents grouped into \(\tau\) complete cardinal-utility types, each receiving a common assignment lottery. Item capacities scale per capita and constrain aggregate type mass; the objective is weighted Nash welfare, with envy checked across types.

What the mirror covers

The mirror covers Theorem 3.4's envy-free approximate Nash-welfare guarantee for cardinal assignment with submodular capacities. It leaves the PS efficiency bounds, chores result, and general Fisher-market algorithm outside its scope.

Open questions for a prover

  • Does the \(e^{1/e}\) approximation and polynomial-time guarantee extend to rational type masses and per-capita submodular capacities?
  • How closely do finite cohorts with counts \(N\mu_t\) and capacities scaled by \(N\) approximate the continuous optimum?

The case FOR (proponent)

The strongest lead is a weighted version of the paper’s envy-free approximate Nash-welfare assignment problem. Theorem 3.4 is proved in this paper; its introduction-level restatement is Theorem 1.3. In full, Theorem 3.4 says that for a submodular capacity function \(\rho\) and a nonnegative utility matrix \(u\), any optimum of the paper’s convex program—maximizing Nash welfare subject to feasibility and envy-freeness—is envy-free, \(e^{1/e}\)-approximate for maximum Nash welfare, and therefore \(e^{1/e}\)-approximately Pareto efficient. It also says that for every \(\varepsilon>0\), an envy-free, \((e^{1/e}-\varepsilon)\)-approximately Pareto-efficient allocation can be computed with a number of arithmetic operations and value-oracle queries polynomial in the encoding length of rational \(u\) and \(\log(1/\varepsilon)\). This is a result proved here, using market-equilibrium and convex-optimization tools. The paper cites hardness results for related exact-fairness problems, but the supplied text gives no numbered hardness theorem that qualifies as an anchor.

Here is the continuous question I would put to a prover: Type-Weighted Envy-Free Nash-Welfare Assignment. An instance has a finite item set \(E\), a support \(T\) of \(\tau\) agent types, rational masses \(\mu_t>0\) with \(\sum_{t\in T}\mu_t=1\), and a rational nonnegative utility vector \(u_t\) for each type. A type is a complete description for this allocation problem: its members have the same utility for every item and the same per-agent assignment constraint. The instance also gives per-capita item capacities through a submodular function \(\rho\); in the ordinary assignment case, \(\rho(S)=\sum_{j\in S}q_j\), where \(q_j\) is the supply of item \(j\) per unit of population.

A solution is a common assignment lottery for each type, represented by marginals \(x_{tj}\geq 0\). Require \(\sum_j x_{tj}\leq 1\) for each type, and require the per-capita aggregate \(z_j=\sum_t\mu_t x_{tj}\) to lie in the polymatroid \(P(\rho)\). Each member of type \(t\) has expected utility \(U_t(x_t)=\sum_j u_{tj}x_{tj}\). Envy-freeness means \(U_t(x_t)\geq U_t(x_s)\) for every pair of types \(t,s\). Define weighted Nash welfare by \(W_\mu(x)=\exp(\sum_t\mu_t\log U_t(x_t))\), and let \(W_\mu^*\) be its maximum over all feasible assignments, whether envy-free or not. The task is: given a tolerance \(\eta>0\), return a feasible, envy-free \(x\) with \(W_\mu(x)\geq W_\mu^*/(e^{1/e}+\eta)\). The marginals describe each person’s lottery; they do not require any individual to receive a fractional bundle in a realized assignment.

The regime is a large recurring placement programme: for example, many graduates assigned to positions from a fixed catalogue, with utilities drawn from a standardized score schedule. A type is the full utility vector, not just a credential category or ranking. The case is strongest when thousands of applicants share a relatively small number of such complete profiles, so \(N\gg\tau\), and position capacities grow with cohort size. The type-weighted welfare is the natural high-multiplicity form: if \(N\mu_t\) people have type \(t\), then the finite-population geometric mean has exponent \(\mu_t\). This makes the society itself continuous. The paper’s fractional allocations and lotteries alone would not do that.

I expect this mirror to be Class A, tractable. Its natural program has \(\tau|E|\) allocation variables and \(O(\tau^2)\) envy constraints, with objective \(\sum_t\mu_t\log U_t(x_t)\) and the same aggregate submodular feasibility condition. Rational masses simply become objective and capacity weights; separation over the polymatroid uses submodular minimization. The proof’s welfare comparison also has a weighted analogue: summing log utility ratios by mass gives the same bound when total mass, and hence total per-capita budget, is one. So the constant-factor argument and the continuous optimization approach appear to survive without expanding each type into \(N\) individual rows. The precise complexity question is whether this can be done in time polynomial in \(m,\tau\), the input bit length, and \(\log(1/\eta)\), with the stated value-oracle access to \(\rho\).

This case covers Theorem 3.4’s cardinal assignment result, including its submodular-capacity form. It does not claim to mirror the paper’s PS efficiency bounds, chores result, or general Fisher-market algorithm. Nor does the paper’s cited convergence of Random Priority and PS with many item copies pre-empt this question: that is an outcome/mechanism limit, not a continuous population model.

The weakest point is the exact-type assumption. Real applicants may share a ranking while differing in cardinal utility, and then they are different types here. The scenario is persuasive only where the full utility schedule is standardized or repeats often enough that \(\tau\) stays small. Also, Theorem 3.4 is not a discrete hardness anchor: this mirror tests whether its algorithmic guarantee extends to a continuous population, not whether population continuization dissolves hardness. The next questions are whether the weighted theorem and its running-time bound hold for value-oracle submodular capacities, and how closely finite high-multiplicity instances with \(N\mu_t\) agents and \(N\)-scaled supplies approximate the continuous optimum.

The case AGAINST (opponent, writing after the proponent)

The strongest objection is that this mirror needs unusually repeated *cardinal* types. A type must capture the utility vector over the whole item catalogue, so sharing a ranking is not enough. In many assignment markets, candidates’ relative valuations differ; then the support size \(\tau\) may grow almost as fast as the population, and the proposed compression buys little. A standardized score schedule and recurring catalogue could make \(\tau\) small, but that describes a narrower regime than ordinary hiring or course allocation.

That objection does not defeat the better version of the mirror. A repeated placement programme with a fixed catalogue and standardized utility schedules is a plausible high-multiplicity setting. For rational type masses and per-capita capacities, take cohort sizes for which the type counts and scaled capacities are integral. Giving each member of a type the same assignment lottery then yields the stated weighted Nash welfare, and type-to-type envy constraints capture individual envy. The allocation variables scale with \(\tau\), not the cohort size. Fractional outcomes in the paper do not pre-empt this: the population, rather than the allocation, is what becomes continuous.

Nor can I use the paper’s other nearby literature to close the case. The Random Priority/Probabilistic Serial convergence result concerns outcomes as item copies grow, not a continuous population. Existing high-multiplicity assignment work would support the regime’s relevance, not create a novelty collision.

So the negative case is weak. Theorem 3.4 is a named computational result, and the type-weighted version is a well-posed population mirror with a credible scenario. The main reservation is that the scenario depends on repeated complete utility profiles; I cannot make that reservation into a convincing argument that no worthwhile continuous mirror exists.
