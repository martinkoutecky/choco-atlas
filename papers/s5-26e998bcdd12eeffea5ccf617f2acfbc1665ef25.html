The continuous mirror question

Given \(n\) and a tree character \(\chi\), construct rational masses \(\mu_A\geq 0\), summing to \(1\), on voter types \(t_A\) with utility \(u_A(x)=\mathbf{1}[|x\cap A|\text{ is even}]\), for nonempty \(A\subseteq[n]\), such that \(\sum_A\mu_Au_A\) has character exactly \(\chi\).

The model it lives in

Use the paper’s voter-basis types \(t_A\), with utilities \(u_A=\mathbf{v}_A\). Assign masses proportional to the coefficients in Theorem 1.3 on \(A\in\chi\setminus\{\emptyset\}\) and on siblinks \(B\in\linkage(\chi)\), adding coefficients when an index occurs in both; normalization scales the constructed vector without changing its character.

What the mirror covers

The mirror covers the constructive realization of tree characters using the voter basis; it leaves general admissibility and realizability from an arbitrary externally supplied type support open.

Open questions for a prover

  • For a fixed supplied support \(R\) of voter-basis types, which target characters can be realized by rational masses on \(R\), and how efficiently can realizability be decided?

The case FOR (proponent)

The strongest positive hook is the paper’s own suggestion that preference vectors from an electorate can be combined to represent aggregate utility. That points to a continuous-population question, but the paper contains no named computational result asserting membership in P, hardness, or another complexity classification. The nearest result is Theorem 1.3, proved here: every tree character—every family \(\chi\) whose Hasse diagram after removing \(\emptyset\) is a tree rooted at \([n]\)—is the exact collection of separable sets of some preference ordering. That is an existence theorem, not a computational anchor of the kind required here.

A precise follow-on question would be Restricted Aggregate Admissibility. There are \(n\) binary proposals and a supplied finite set \(R\) of voter types. Each type \(t\) has a fixed, normalized rational utility function \(u_t:2^{[n]}\to\mathbb{Q}\); fixing utilities matters because the paper’s preferences are ordinal, and ordinal rankings alone do not determine how to aggregate them. An instance also gives a target family \(\chi\). The question is whether there are rational masses \(\mu_t\geq 0\), summing to \(1\), such that the aggregate utility
\[ U_\mu(x)=\sum_{t\in R}\mu_tu_t(x) \]
induces a preference ordering whose character is exactly \(\chi\). A solution is the mass vector \(\mu\). The society could be a large electorate repeatedly considering the same small set of referendum proposals, with many voters sharing one of a modest number of complete preference-and-utility types. The population is continuous; the proposal outcomes remain binary.

Theorem 1.3 is the closest anchor for this question, and its exact content is that every tree character is realizable by one preference ordering. If the supplied type set contains the constructed ordering, placing all mass on that type realizes \(\chi\). The paper’s final discussion makes aggregation a plausible direction for the authors to recognize. But the theorem does not establish feasibility when \(R\) is a given electorate’s type set, and the unrestricted version for tree characters is already answered by putting all mass on the single constructed type. So the more interesting restricted question goes beyond the result.

The soft spot is substantial: this shifts the object from an individual voter’s separability character to the character of an aggregate utility ordering. The paper gestures toward that aggregation, but does not study it or analyze its complexity. I would therefore treat this as a credible research question suggested by the paper, not a strong continuous mirror of one of its computational results. The paper offers no basis for classifying the restricted problem as tractable, transfer-hard, or continuum-specifically hard.

The case AGAINST (opponent, writing after the proponent)

The decisive weakness is that this paper gives no named computational result to mirror. Theorem 1.3 says every tree character is realizable by an individual preference order; Theorem 1.5 supplies a basis and describes its separability properties. The tree theorem even gives an explicit construction, but it makes no complexity claim about a computational problem. There is no decision, optimization, or search problem whose complexity the paper analyzes. That leaves ChoCo without the computational anchor its programme is designed to continuize.

The proposed Restricted Aggregate Admissibility is coherent as a possible new research question. A stronger version would define each type by a complete rational utility function over the \(2^n\) outcomes, then ask whether a distribution over a supplied set of types produces an aggregate utility with a specified character. But that adds cardinal utilities and a population aggregation problem; the paper studies ordinal preferences of one voter. Its suggestion that voter utility vectors could be combined makes this a plausible follow-on, while supplying neither a canonical aggregation model nor a computational result for it. Using majority comparisons instead would require choosing an aggregation rule and handling the possibility that its collective relation is not an ordering.

A large population repeatedly voting on the same proposals is a plausible high-multiplicity setting. So I cannot honestly establish that no worthwhile continuous question could arise from this paper. The negative case is narrower: the proponent’s candidate may be worth studying, but it is a new computational problem suggested by the paper, not a continuous mirror of one of its computational results.
