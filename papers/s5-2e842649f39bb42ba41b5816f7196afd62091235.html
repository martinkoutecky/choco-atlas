The continuous mirror question

Given compatible preference classes \(R\), a finite support of incumbent-marked types \(\alpha=(r,s)\) with rational masses \(\mu_\alpha\), and a feasible baseline matching, decide whether there is a feasible mass matching \(x\) with positive vote margin. For each compatible pair \(\alpha=(r,s),\beta=(q,t)\), let \(x_{\alpha\beta}\geq 0\) be paired mass, and let \(u_\alpha\geq 0\) be unmatched mass, subject to \(\sum_{\beta\ne\alpha}x_{\alpha\beta}+2x_{\alpha\alpha}+u_\alpha=\mu_\alpha\). With \(\delta_{(r,s)}(q)=1\) if \(q\succ_r s\), \(-1\) if \(s\succ_r q\), and \(0\) if \(q=s\), test whether \(\Delta(x,u)=\sum_{\{\alpha,\beta\}}x_{\alpha\beta}(\delta_\alpha(q)+\delta_\beta(r))+\sum_\alpha u_\alpha\delta_\alpha(\bot)>0\) is feasible.

The model it lives in

A society is a distribution \(\mu\) over preference classes marked by incumbent partner class. Challenger matchings are mass flows \(x\) between compatible types, with unmatched mass \(u\); maximizing the linear vote margin \(\Delta\) decides whether the incumbent is popular.

What the mirror covers

Covers Theorem 4’s test of a specified matching’s popularity in a class-based population; it does not cover Theorem 5’s dual-witness structure or Theorem 7’s fractional-popularity characterization.

Open questions for a prover

  • Can the paper’s auxiliary-graph reduction be aggregated by incumbent-marked types to give a combinatorial popularity test polynomial in the support size?

The case FOR (proponent)

My lead is the paper’s Theorem 4, a result proved here. Given a roommates instance and a matching \(M\), the authors build \(G_M^*\) from the preference graph: remove edges that both endpoints rank below their partners; add a blocking node for each endpoint of a blocking edge, except that leaves in the same blocking star share one star node; contract all unmatched vertices into one node \(u\); and delete the blocking edges. The theorem says that \(M\) is popular—no matching makes more agents prefer it than prefer \(M\)—if and only if \(M\) is a maximum-cardinality matching in \(G_M^*\). It follows that popularity testing takes \(O(|E|)\) time, using a cited linear-time test for whether a matching is maximum. The reduction and equivalence are proved in this paper.

A natural high-multiplicity setting is a large roommate-placement program, such as shared housing for recurring cohorts of workers. People fall into a small number of compatibility and preference classes; each class has a strict ranking of the compatible classes. There may be millions of people but only a few dozen such classes. This is a plausible regime when class membership captures everything relevant to whom a person can live with and how they compare potential roommates.

Here is the continuous testing problem I would hand to a prover. Let \(R\) be the finite set of preference classes, with a compatibility graph and a strict ranking \(\succ_r\) over compatible classes for each \(r\in R\). Include \(\bot\), meaning “unmatched,” below every compatible class. Because the question is whether a *given* matching is popular, refine each class to record its incumbent partner class: a type is \(\alpha=(r,s)\), where \(s\in R\cup\{\bot\}\). The instance gives each supported type a rational mass \(\mu_\alpha\), summing to one. The baseline is feasible: for distinct compatible classes \(r,s\), the masses of \((r,s)\) and \((s,r)\) agree; mass of \((r,r)\) is paired within that class; and types \((r,\bot)\) are unmatched.

A challenger is a mass matching. For every compatible unordered pair of types \(\alpha=(r,s)\), \(\beta=(q,t)\), let \(x_{\alpha\beta}\geq 0\) be the mass paired between them; \(x_{\alpha\alpha}\) pairs distinct people of that same type. Let \(u_\alpha\geq 0\) be mass left unmatched. Feasibility requires \(\sum_{\beta\ne\alpha}x_{\alpha\beta}+2x_{\alpha\alpha}+u_\alpha=\mu_\alpha\) for each \(\alpha\). Define \(\delta_{(r,s)}(q)\) to be \(+1\) if \(q\succ_r s\), \(-1\) if \(s\succ_r q\), and \(0\) if they are equal. The challenger’s vote margin is \(\Delta(x,u)=\sum_{\{\alpha,\beta\}}x_{\alpha\beta}\bigl(\delta_\alpha(q)+\delta_\beta(r)\bigr)+\sum_\alpha u_\alpha\delta_\alpha(\bot)\), where \(\alpha=(r,s)\) and \(\beta=(q,t)\). The question is whether any feasible challenger has \(\Delta(x,u)>0\). If so, that mass matching witnesses unpopularity; if not, the incumbent is popular. These variables describe assignments of mass, not lotteries: in an atomless population, each feasible flow can be realized by partitioning the type masses, with each person receiving one partner or remaining unmatched.

I expect this stated problem to be tractable. It is a rational linear program with \(O(p^2)\) pair variables for \(p\) supported, incumbent-marked types, and polynomially many constraints; its running time is polynomial in \(p\) and the input bit length. The expected result is Class A for this mirror. A useful next question is whether the paper’s blocker-node construction can be compressed to type support and yield a faster combinatorial test, or whether LP optimization is the right bound for this mass version. The scope is only testing a specified incumbent’s popularity; it does not mirror the paper’s questions about finding popular matchings or maximizing their size.

I think the authors could recognize this as their problem’s high-multiplicity extension: the comparison is still the same population vote margin over alternative matchings, and the paper itself asks whether its approach extends to popular \(b\)-matchings. The main weakness is real, though: people in one partner class are interchangeable here. A finite clone expansion therefore has ties among named people, whereas the paper assumes strict preferences over individual neighbors. Preserving arbitrary identity-level tie-breaks could require many more types and destroy the regime. So this is a strong mirror for roommate matching with class-level preferences, but not a general continuization of the paper’s strict, identity-sensitive model.

The paper has no numbered hardness result for popularity testing to use as an anchor. Its cited NP-completeness result concerns deciding whether a popular matching exists, a different problem, so I would not use it here.

The case AGAINST (opponent, writing after the proponent)

The strongest case against the Theorem 4 mirror is that the paper’s input is built around strict rankings of named neighbors. To keep those rankings in a repeated housing cohort, people with different identity-based rankings may need different types; support could then grow with the population. The proposed compression instead ranks partner classes, making same-class partners indistinguishable. That changes the preference model as well as replacing counts with masses.

But that objection does not defeat the better mirror. In a recurring placement program where compatibility and preferences really are class-based, marking each type with its incumbent partner class gives enough information to compare the incumbent with any challenger. The challenger’s vote margin is a linear function of feasible mass pairings, and positive margin is an exact computational question over the continuous society. The dependence of types on the incumbent is natural for a test of a specified matching. And although class-based preferences are weaker than the paper’s strict individual rankings, the authors explicitly identify popular matching under weak preferences as an extension of their approach. The gate that the authors would recognize the question as theirs is met.

Nor does the paper’s fractional-popularity result amount to a continuous-population treatment: it allows fractional matching outcomes for a finite set of agents. That is adjacent work, not a collision. The paper’s linear-time algorithm and existing high-multiplicity work also do not answer the continuous mirror; neither is a reason to reject it.

So I cannot honestly defeat this anchor. The strict-identity version may not admit a compact high-multiplicity encoding, but a plausible class-based version survives, and the manuscript itself points toward the relevant preference extension. The negative case is weak here; Theorem 4 supports a worthwhile continuous mirror.
