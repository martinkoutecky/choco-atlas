The continuous mirror question

Given a finite type set \(U\) with support size \(\tau\), facilities \(V\), resources \(N\), type data \(w_u,b_u\), distance \(d\), and fairness parameter \(\gamma\), suppose each period \(t\) reveals a mass profile \(\nu_t\) with \(\sum_{u\in U}\nu_{t,u}=S\), drawn i.i.d. from an unknown law \(G\). A causal policy chooses \(x_{t,u}\in\mathbb{R}_{\ge 0}^{V}\) for each type in the profile, with \(\mathbf{1}^{\top}x_{t,u}\le 1\); it must satisfy \(d(u,u')\ge\gamma(w_u^\top x_{t,u}-w_{u'}^\top x_{t,u'})\) for present types and \(\sum_{t,u}\nu_{t,u}b_u^\top x_{t,u}\le TS\rho\). Is there a policy with expected regret \(O(\sqrt{T})\) against the clairvoyant fair fluid optimum for the realized profiles, and what runtime bound can be achieved in \(\tau, |V|, N\), and the input bit length?

The model it lives in

Model each type as agents identical in \(w_u,b_u\), and fairness-relevant attributes. In each period a nonatomic mass \(\nu_{t,u}\) of type \(u\) arrives; \(x_{t,u}\) is the lottery assigned to each unit of that mass, so aggregate assignment is \(\nu_{t,u}x_{t,u}\). The policy observes the period's profile, maximizes weighted welfare over time, respects within-period Lipschitz fairness, and keeps total mass-weighted resource use within capacity.

What the mirror covers

The mirror covers Theorem (2)'s online regret guarantee and Theorem 1's offline price-of-fairness bound. It does not cover the empirical findings or classify other fair allocation variants.

Open questions for a prover

  • Can dual mirror descent attain \(O(\sqrt{T})\) expected regret for i.i.d. laws on observed mass profiles while enforcing the hard aggregate resource capacity?
  • What explicit runtime and regret dependence on \(\tau, |V|, N\), and input bit length can be proved?

The case FOR (proponent)

There is a credible mirror here, though the paper gives no named NP-hardness or complexity-class result. Its anchors are two theorems proved in the paper: an offline price-of-fairness bound and an online regret guarantee. The online theorem is my lead because it analyzes an algorithm that repeatedly computes fair allocations.

Take a large resettlement intake as the regime: many households, but relatively few modeled profiles. A type \(u\) is a complete description for this allocation model: every household of type \(u\) has the same employment-value vector \(w_u\), resource-use matrix \(b_u\), and fairness-relevant attributes. Mass \(\mu_u\) is the fraction of the intake with that profile. For example, profiles might combine standardized household size, language, and employment characteristics. The facilities and individual assignments remain discrete; the aggregate mass assigned to each facility can be fractional because each person receives a lottery. The paper’s experiment, which treats every surveyed family as a unique type, is not itself this regime.

Lead anchor: Theorem (2). As printed, this theorem is proved in the paper. It says that for Algorithm \(\ref{alg:inbatch_lazy}\), if \(\eta\le \sigma_2/(S\overline b)\) and \(\mu_0\le\mu^{max}\), then expected regret is at most
\[ \frac{2\eta S^2(\overline b^2+\overline\rho^2)}{\sigma_1}T +\frac{1}{\eta}V_h(0,\mu_0) +\frac{\overline w}{\eta\underline\rho} \left\|\nabla h(\mu^{max})-\nabla h(\mu_0)\right\|_\infty +\frac{S\overline w\overline b}{\underline\rho}. \]
Choosing \(\eta\in O(1/\sqrt T)\) gives expected regret \(O(\sqrt T)\), with the paper assuming constant batch size.

The continuous analogue, Online Fair Mass Allocation, is this. An instance has a finite type set \(U\), facilities \(V\), resources \(N\), type data \(w_u,b_u\), a distance metric \(d\), fairness parameter \(\gamma\), horizon \(T\), and per-capita resource capacity \(\rho\). In period \(t\), an observed mass profile \(\nu_t\) over \(U\) arrives, with fixed total mass \(S\). The decision is a lottery \(x_{t,u}\in\mathbb R_{\ge0}^{V}\) for each type present, with \(\mathbf 1^\top x_{t,u}\le1\). Within that period it must satisfy
\[ d(u,u')\ge\gamma\bigl(w_u^\top x_{t,u}-w_{u'}^\top x_{t,u'}\bigr) \]
for every pair of present types. The mass assigned to facility \(v\) is \(\nu_{t,u}(x_{t,u})_v\); total resource use over the horizon must not exceed \(TS\rho\). The objective is total expected welfare, \(\sum_{t,u}\nu_{t,u}w_u^\top x_{t,u}\).

The question for a prover is: when the profiles \(\nu_t\) are drawn i.i.d. from an arrival law, does there exist a causal policy that observes each profile before deciding, respects fairness and the hard aggregate capacity, and has expected regret \(O(\sqrt T)\) against the clairvoyant fair fluid optimum? A policy is a solution; the regret benchmark and resource condition are part of the problem.

I expect this mirror to be Class A. Each period’s fair allocation is a linear program with \(O(\tau |V|)\) variables and \(O(\tau^2)\) pairwise fairness constraints, where \(\tau\) is the profile support size. The paper’s dual mirror descent gives a natural algorithmic starting point. The paper does not state a bit-complexity theorem for its implementation, so a continuous result should include the update and LP runtime as well as regret. Questions it raises include whether the bound holds for changing or adversarial profile laws, and how regret and runtime depend on \(\tau\).

Supporting anchor: Theorem 1. This theorem, also proved in the paper, says that for any \(\gamma\ge1/2\), the offline fair allocation value is at least an \(\Omega(1/\gamma)\) fraction of the offline unfair fluid value. The paper notes that the hidden constant depends on \(1/\underline d\) and \(1/\overline b\).

Its mass version, Offline Fair Mass Welfare, takes a distribution \(\mu\) over \(U\), the same type data and metric, and per-capita resource limits \(\rho\). Choose \(x_u\) for each type, maximize \(\sum_u\mu_u w_u^\top x_u\), subject to \(\mathbf 1^\top x_u\le1\), \(\sum_u\mu_u b_u^\top x_u\le\rho\), and the pairwise fairness constraints above for types in the support. Let \(W_\gamma(\mu)\) be this optimum and \(W_0(\mu)\) the optimum with fairness omitted. The question is whether \(W_\gamma(\mu)\ge\Omega(1/\gamma)W_0(\mu)\) under the paper’s distance and bounded-resource assumptions. It should inherit the paper’s bound: replacing repeated identical agents by their masses preserves the LP’s welfare, resource use, and fairness constraints. This is an approximation guarantee, not a hardness result; the mass LP itself is tractable in the explicit support size.

The authors should recognize both mirrors: the paper already defines finite types and says identical types can receive the same allocation, so the mass formulation replaces sums over named agents by sums weighted by type mass. This is a high-multiplicity version of their allocation problem, not a claim that fractional lotteries already make their society continuous.

The weakest point is the online mirror’s arrival model. The paper samples individual types within each finite batch. With a true continuum of independently sampled agents and a fixed type law, each batch’s mass profile converges to that law, so the sampling uncertainty driving online learning may disappear. To retain a substantive online question, I have allowed each large intake to have an observed, random type-mass profile—for example, changing weekly mixes of origin and skill groups. That is close to their batch model, but it is a modeling extension, not a consequence of taking the population limit. The offline mirror does not depend on that extension.

The case AGAINST (opponent, writing after the proponent)

The clearest objection is that both anchors already run on the type composition of a batch. In the offline LP, agents of the same type have the same \(w_u\) and \(b_u\), and \(d(u,u)=0\) forces them to receive equal expected welfare. Averaging their allocation lotteries therefore lets us represent them by one \(x_u\) without changing welfare, resource use, or fairness. If \(n_u\) agents have type \(u\), dividing by batch size \(S\) gives the mass formulation with \(\mu_u=n_u/S\) and per-capita capacity \(\rho\). Theorem 1’s ratio is independent of these counts, so it already covers every rational mass profile; continuity extends the value bound to real masses. This is a population aggregation argument, not an appeal to fractional outcomes alone. The paper’s Section 4 makes the same type-level reduction explicitly.

Theorem (2) has the same issue. A batch’s empirical type distribution \(\nu_t(u)=n_{t,u}/S\) contains all the information its allocation LP uses: welfare and resource consumption are weighted sums over types, and fairness depends on the types present. The algorithm already chooses allocations indexed by type. Replacing finite sums in its dual update with mass-weighted sums leaves the same bounded-gradient mirror-descent argument. With a fixed type law and a nonatomic population, each batch has that law’s composition, so the sampling uncertainty vanishes. If instead each intake has a random aggregate mix, that preserves online uncertainty, but the mass-profile process is a direct generalization of the paper’s random batch input, and the displayed regret proof appears to extend to it. The paper does not establish running-time bounds, either; for explicit finite support, the per-batch fair allocation problem is already a polynomial-size LP.

So these mirrors look like reformulations or direct extensions of the paper’s existing model, rather than new complexity questions for the programme. This is strongest against the two anchors raised. It does not justify the universal claim that no worthwhile mirror exists: genuinely evolving aggregate profiles could motivate a distinct online model, and the paper does not rule that out. The negative case is therefore weak against the user’s “in any scenario” burden.
