The case AGAINST (opponent, writing after the proponent)

The paper’s decisive weakness is that it states no complexity result for a computational problem. Its only named computational object is GENSINGLEPEAK, a procedure for sampling one ranking with \(m-1\) coin tosses. There is no population optimization, decision problem, or complexity landscape in the paper to carry over.

The strongest continuous recasting is to treat single-peaked rankings as voter types and Impartial Culture as the uniform mass distribution over the \(2^{m-1}\) types, then ask to sample a type according to that mass. But population size and multiplicities do no work in this task: the output is one ballot. For this particular uniform distribution, the paper’s recursive sampler already gives the answer. For an explicitly listed arbitrary mass distribution, sampling is just weighted sampling from the support; using a succinct encoding instead would make the question depend on that encoding, not on continuous population.

Generating a society’s aggregate mass profile would change the task. Under uniform Impartial Culture, that profile is simply the specified uniform distribution; sampling a finite electorate to obtain fluctuating counts returns to the paper’s discrete setting. So the paper can describe a sensible distribution of voter types, but it offers no computational result whose continuous-population mirror would make the population itself computationally consequential.
