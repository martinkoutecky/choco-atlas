The continuous mirror question

Given ordered types \(T=\{t_1<\cdots<t_\tau\}\) with positive rational masses \(\mu_i\) summing to \(1\), and a finite sample size \(k\), choose counts \(z_i\in\mathbb{Z}_{\ge 0}\) with \(\sum_i z_i=k\). Each positive-mass type contains enough interchangeable individuals to supply any finite \(z_i\). Let \(F_i=\sum_{j\le i}\mu_j\) and \(G_i(z)=\frac{1}{k}\sum_{j\le i}z_j\). For a specified objective, find a minimizing \(z\) and its value for \(D_{\mathrm{KS}}(z)=\max_i|F_i-G_i(z)|\), \(D_1(z)=\sum_i\mu_i|F_i-G_i(z)|\), or \(D_{\mathrm{CvM}}(z)=\sum_i\mu_i(F_i-G_i(z))^2\).

The model it lives in

A rational mass distribution \(\mu\) over ordered, interchangeable types; choose integer sample counts \(z_i\) summing to \(k\), minimizing the KS, population-weighted \(L_1\), or population-weighted squared-CDF discrepancy.

The case FOR (proponent)

There is no numbered result here asserting NP-hardness, membership in P, or another complexity classification. The strongest anchor is an exact optimization theorem: Theorem 1, “Characterization of the optimal mechanism,” proved in this paper. It says that when \(n=(2m+1)k\), the Quantile mechanism is optimal under all three measures—KS, \(L_1\), and CvM—and that every sample not equivalent to its output has a strictly larger value under each measure. Its output selects the \((m+1)\)-st highest-ranked item, then the item \((2m+1)\) places later, and so on. This is a named result about the underlying sample-optimization problem, but it is not a complexity theorem.

My lead mirror is Continuous Representative \(k\)-Sample. An instance is a society with ordered types \(T=\{t_1<\cdots<t_\tau\}\), rational masses \(\mu_i>0\) summing to \(1\), and a requested sample size \(k\). Each positive-mass type contains enough interchangeable individuals to select any finite number of distinct people from it. Choose counts \(z_i\in\mathbb Z_{\ge0}\), with \(\sum_i z_i=k\), and return a sample whose type distribution is \(\nu_z=(1/k)\sum_i z_i\delta_{t_i}\), minimizing one of the three distances between \(\mu\) and \(\nu_z\). Writing \(F_\mu(t_i)=\sum_{j\le i}\mu_j\) and \(F_{\nu_z}(t_i)=\sum_{j\le i}z_j/k\), the objectives are
\[ D_{\mathrm{KS}}=\max_i|F_\mu(t_i)-F_{\nu_z}(t_i)|,\quad D_1=\sum_i\mu_i|F_\mu(t_i)-F_{\nu_z}(t_i)|,\quad D_{\mathrm{CvM}}=\sum_i\mu_i(F_\mu(t_i)-F_{\nu_z}(t_i))^2. \]
A solution is any minimizing count vector \(z\), together with its distance.

A plausible regime is a large MDL docket: many claims fall into relatively few legally relevant, interchangeable profiles, ordered by a common claim-strength ranking, while the bellwether sample remains small. The parties can prefer opposite ends of that ranking, as in the paper. The type must include everything the model uses about a claim, including its position in the shared ranking; otherwise grouping claims would change the problem. Here the population is the continuous object, while the selected sample remains \(k\) actual individuals.

I expect this mirror to be Class A. At each ordered type, keep the number \(q\) of selected people so far. The \(L_1\) and CvM objectives have additive stage costs \(\mu_i\phi(F_\mu(t_i)-q/k)\); KS uses the maximum stage discrepancy instead. A dynamic program over \((i,q)\), with transitions from earlier counts \(q'\le q\), finds an optimum in \(O(\tau k^2)\) arithmetic operations, with rational input handled exactly. Thus the finite-support mass model creates a concrete computational question, but this formulation appears tractable. It also generates follow-up questions: how do eligibility constraints or type-specific selection quotas change the dynamic program, and can the optimal sample still be implemented in equilibrium by a continuous cut-and-choose mechanism?

The mirror covers Theorem 1’s representativeness objective, not the whole paper’s strategic mechanism analysis. The main weakness is that the paper’s contribution includes equilibrium implementation, while this question computes the best sample directly; moreover, its finite theorem already has a simple quantile solution in its stated regime. Authors should recognize the sample objective as theirs, but may regard this computational version as an easier subproblem rather than a mirror of the mechanism-design contribution.

The case AGAINST (opponent, writing after the proponent)

The paper gives no named computational result to mirror. Theorem 1 characterizes which sample minimizes three representativeness measures and proves that the Quantile mechanism implements it. The paper formulates no computational problem or complexity question; its only runtime claim is that implementation requires sorting, in \(O(n\log n)\). That matters because the proposed Continuous Representative \(k\)-Sample is a new optimization problem attached to the theorem, not a continuous version of a computational problem the authors studied.

The proposed problem is coherent, but it drops the paper’s strategic core. The planner in the paper does not know the ranking; the players do, and the mechanism must induce a representative sample through their equilibrium play. Giving an algorithm the ordered type masses lets it compute the best sample directly. A more faithful mirror would use a continuous cut-and-choose game over measurable portions of society. But then the computational question needs a finite description of allowed partitions and messages. With finite ordered support, the actions reduce to allocating type mass around quantile thresholds. With unrestricted measurable partitions, the strategic game has no finite input encoding of the kind needed for a complexity question.

There is also little population-specific structure to compute in the atomless case. Because the paper’s measures depend only on ordinal ranks, transforming ranks by the population CDF sends any atomless society to the uniform distribution on \([0,1]\). The instance-specific distribution disappears; only the finite sample size remains. This does not make the discrepancy itself vanish, so it is not a decisive degeneracy argument. Retaining atomic types preserves input variation, but the resulting problem is weighted one-dimensional sample approximation rather than a computational question about the paper’s mechanism or its equilibrium.

That is the strongest case against the anchor, and it is not airtight. The paper’s objective is exactly representative sampling, so the authors could well recognize optimization over a distribution as their problem. A large docket with many interchangeable cases also gives a plausible high-multiplicity regime. The proponent’s mirror therefore survives as a legitimate extension; the negative case is that it sits at the edge of ChoCo’s computational focus, not that it is incoherent or impossible.
