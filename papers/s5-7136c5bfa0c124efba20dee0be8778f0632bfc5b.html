The continuous mirror question

Given a bipartite graph of supported types with rational masses \(\mu_i\) summing to \(1\) on each side, quotas \(q_i\), and rational pair-capacity densities \(\beta_{ij}\), find a stable density vector \(y\), where \(0\le y_{ij}\le\beta_{ij}\) and the total assignment mass between types \(i,j\) is \(\mu_i\mu_j y_{ij}\). Type \(i\)'s assignment uses \(\sum_j\mu_j y_{ij}\le q_i\); its diversifying choice rule cuts offered densities at a common threshold, weighted by counterpart masses, to fill \(q_i\) when possible. A filled type’s head consists of incident pairs attaining its maximum density, while an underfilled type has an empty head; a pair blocks when it is below capacity and outside both endpoint heads. Can the unique stable density vector be computed exactly in time polynomial in the number of supported types \(\tau\), type pairs \(a\), and binary input length \(L\)?

The model it lives in

A bipartite population of buyer and supplier types with rational masses, per-person quotas, and pair-capacity densities. The decision variables are type-pair assignment densities \(y_{ij}\); each type evaluates its offers using counterpart masses in the diversifying quota rule, and type-pair assignment mass is \(\mu_i\mu_j y_{ij}\).

The objection that survived

The \(1/N\) scaling of individual-pair capacities selects a dense market with normalized type-pair capacity; the proposed procurement scenario does not independently establish how common that scaling is.

fatal: False

What the mirror covers

The mirror covers the bipartite algorithmic result in Proposition 4.4, with Theorem 3.1 supporting uniqueness; it leaves the general-graph and hypergraph results aside.

Open questions for a prover

  • Can a direct type-level algorithm compute the unique stable density in time polynomial in \(\tau\), \(a\), and \(L\)?
  • Can the algorithm achieve a strongly polynomial bound independent of the common denominator \(N\), rather than expanding the \(N\)-clone market?

The case FOR (proponent)

The strongest mirror is a weighted, high-multiplicity version of the paper’s bipartite market. Its sole computational anchor is Proposition 4.4, proved here: the modified algorithm terminates after \(O(|E|^2)\) iterations, each taking \(O(|E|)\) time, and finds a stable assignment. Thus the finite-agent problem has a strongly polynomial algorithm. The paper gives no named hardness result to anchor a hardness-dissolution question.

The mirror’s regime is a large two-sided procurement market, where many buyers and suppliers share complete profiles: role, compatible partner types, per-person quota, pair capacity, and the paper’s diversifying choice rule. For example, millions of buyers and suppliers might fall into a few dozen such types. The society is represented by rational masses \(\mu_v\), normalized to sum to \(1\) on each side. This continues the population, not merely the assignment amounts: the paper already allows real capacities and assignments, but still has finitely many agent vertices.

Here is the problem I would hand to a prover: Weighted Diversifying Cohort Stability. Its input is a bipartite graph of supported types, with \(\tau\) type vertices and \(a\) allowed type pairs; positive rational masses \(\mu_v\); per-person quotas \(q_v\); and rational pair-capacity densities \(\beta_{ij}\). The decision variable is a density \(y_{ij}\in[0,\beta_{ij}]\) for each allowed type pair. The total assignment mass between cohorts \(i\) and \(j\) is \(\mu_i\mu_j y_{ij}\).

The type weights matter. An individual of type \(i\) sees mass \(\mu_j\) of type \(j\), so a vector of offered densities \(z_{ij}\) uses quota \(\sum_j\mu_j z_{ij}\). If that exceeds \(q_i\), the diversifying choice rule cuts each density to \(\min(r_i,z_{ij})\), where \(r_i\) is chosen so that
\[ \sum_j\mu_j\min(r_i,z_{ij})=q_i. \]
At a type on the other side, the weights are the masses of its counterpart types. A solution is a density vector whose per-person quota use is at most \(q_v\) at every type, and with no blocking type pair: an edge cannot be below its capacity and below the maximum-density “head” at both endpoints. An underfilled type has an empty head, as in the paper. There is no welfare objective; the task is to find the stable assignment.

This is an exact type-level quotient of a finite clone market under a natural scaling. If rational masses have common denominator \(N\), make \(N\mu_v\) agents of each type and give each individual-pair edge capacity \(\beta_{ij}/N\). A symmetric assignment \(x\) on the clone graph corresponds to \(y_{ij}=Nx_{ij}\). The weighted quota rule follows because each agent has \(N\mu_j\) counterpart agents of type \(j\). Theorem 3.1, proved here, says every finite bipartite diversifying market with real capacities and quotas has exactly one stable assignment. Its uniqueness makes the clone solution invariant under permutations of agents within each type, supporting this quotient and its well-defined stable output.

I expect the weighted problem to be Class A: the clone interactions are identical within each type pair, and the weighted threshold rule retains the paper’s simple diversification structure. The concrete computational question is whether the stable density can be found exactly in time polynomial in \(\tau\), \(a\), and binary input length \(L\), ideally with a strongly polynomial arithmetic bound independent of the common denominator \(N\). That would be a meaningful continuation of Proposition 4.4: the paper’s algorithm runs in time polynomial in the *expanded graph*, whose size can be enormous relative to the type description.

The mirror covers only Proposition 4.4’s bipartite stable-assignment problem. Theorem 3.1 supports its uniqueness; the general-graph corollary and the hypergraph note are outside this case. A further question is whether the weighted algorithm extends to non-bipartite type graphs, and what exact bit-complexity bound it has.

My weakest point is also the main research obligation: Proposition 4.4 does not itself give a \((\tau,a,L)\)-polynomial algorithm. Applying it to the clone graph may take time polynomial in \(N\), which can be exponential in \(L\). The weighted cohort choice rule is a necessary part of preserving the individual-level diversification semantics, and compressing the algorithm across those weights needs proof. That gap is why this is a genuine computational mirror rather than a claim that the paper already solved the continuous-population problem.

The case AGAINST (opponent, writing after the proponent)

The only computational anchor is Proposition 4.4: the paper gives a strongly polynomial algorithm for finding the stable assignment on a finite bipartite graph. Theorem 3.1 supplies uniqueness, but it is not a separate complexity result.

The strongest objection is that the proposed mirror selects a particular market limit. With \(N\) clones per normalized population and capacity \(\beta_{ij}/N\) on each individual pair, the type-pair capacity remains finite after normalization. That is coherent, but it assumes capacities shrink as the market grows. If instead each individual-pair capacity stays fixed, the rescaled capacity becomes \(N\beta_{ij}\), so the type-pair cap disappears in the limit. Sparse compatibility networks pose a different problem: agents with different neighborhoods are different types, which can make the support grow with the population. Those alternatives weaken the claim that a small-support weighted market is a general mirror of the paper’s arbitrary graph model.

The weighted cohort model itself, however, withstands that objection better than a literal continuum of named agents would. For rational masses, it has an exact finite-clone interpretation: each type has \(N\mu_v\) agents, each pair capacity is \(\beta_{ij}/N\), and a symmetric clone assignment \(x\) corresponds to density \(y=Nx\). Each agent then faces the proposed weighted quota rule. The paper’s uniqueness theorem ensures that the clone solution is symmetric. The algorithm on the expanded graph may take time polynomial in \(N\), which can be exponential in the binary input length; that leaves a genuine support-size complexity question.

So the negative case is that the mirror depends on a stylized dense-market regime and a deliberate capacity scaling. But that is a limitation of its reach, not a defeat of the anchor: homogeneous cohorts with capacity normalized by market size are a plausible instance regime, and the mirror gives a precise computational question the paper does not settle. I do not find an honest objection strong enough to rule it out.
