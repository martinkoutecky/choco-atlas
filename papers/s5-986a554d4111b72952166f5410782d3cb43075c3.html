The case FOR (proponent)

My lead is Theorem 7 (\(\texttt{thm:EF:w1h}\)), proved in this paper by reducing from Target Outdegree Orientation; the hardness of that source problem is cited from earlier work. The theorem says that EF Orientation remains W[1]-hard parameterized by vertex-cover number, XNLP-hard parameterized by pathwidth, and XALP-hard parameterized by treewidth, even on simple symmetric instances with polynomially bounded weights. It also proves that, under ETH, those instances admit no \(n^{o(\mathrm{vc})}\)-time algorithm, where \(\mathrm{vc}\) is the input graph’s vertex-cover number. This is the strongest anchor for my case: it gives several named hardness results for the same underlying decision problem.

The mirror I would ask the authors to study is Continuous Type-Mass EF Orientation. Consider a large network of local compute sites. Each site can receive shared jobs only from its neighbors, and values each job additively. Many sites have the same complete role: the same per-capita pattern of interactions with other roles and the same valuations. Write \(T\) for the finite set of roles, \(\mu_t>0\) for role \(t\)’s population share, with \(\sum_t\mu_t=1\), and \(R\) for the interaction classes. Each \(r\in R\) joins two distinct roles \(a_r,b_r\), has supply \(g_r\) per unit of population, and gives both endpoint roles value \(w_r\). This keeps the anchor’s symmetric valuation setting.

A continuous orientation chooses nonnegative masses \(x_r^{a_r},x_r^{b_r}\) with \(x_r^{a_r}+x_r^{b_r}=g_r\): they are the amounts of interaction class \(r\)’s jobs allocated to each endpoint role. Define type \(t\)’s per-agent value of its own bundle as \(U_t=\frac{1}{\mu_t}\sum_{r:\,t\in\{a_r,b_r\}}w_r x_r^t\). Its value for a representative of role \(u\)’s bundle is \(V_{t,u}=\frac{1}{\mu_u}\sum_{r:\,\{a_r,b_r\}=\{t,u\}}w_r x_r^u\). The question is whether there are such masses with \(U_t\ge V_{t,u}\) for every pair \(t\ne u\). A solution is a feasible mass orientation \(x\).

This is a population mirror: with \(N\) sites and \(\tau=|T|\) roles, \(N\) can be very large while \(\tau\) stays modest. Each finite job still goes whole to one endpoint; fractional \(x\) records the proportions of many repeated interactions oriented each way. The model preserves local eligibility, additive values, and envy comparisons. It asks whether the paper’s hardness survives when the repeated population is represented by its type masses and per-capita bundles. The orientation constraints and envy inequalities are linear, so this mirror is expected to be tractable by rational linear programming, in time polynomial in \(|T|\), \(|R|\), and the input bit length. That would make it a Class A outcome for the continuous version of the paper’s hardness result.

The mirror covers Theorem 7’s EF Orientation existence problem on symmetric, polynomial-weight instances. It does not claim to continuize EFX, the paper’s binary characterization, or its minimum-charity results. It also yields natural follow-ups: whether finite replicated instances can realize a continuous solution with small envy violations, and whether the same mass model supports a minimum-charity objective.

The weakest point is that the paper’s envy constraints apply to individual vertices, while this mirror compares per-capita bundles for roles. The hardness reduction may also depend on graph structure that disappears when sites repeat a small set of roles. That is a real modeling condition, not a proof that the mirror is unfaithful: the proposed regime is a repeated network of indistinguishable local roles, where the role-level population and per-capita interaction supplies are the object of interest.

The case AGAINST (opponent, writing after the proponent)

The anchor is real: \(\texttt{thm:EF:w1h}\) proves computational hardness for EF Orientation, including W[1]-hardness by vertex cover and XNLP- and XALP-hardness by pathwidth and treewidth. It cannot be dismissed as an axiomatic result or as prior work that already answers a continuous question.

The difficulty for this mirror is what envy compares. In the paper’s graph model, an agent \(i\) values another agent \(j\)’s bundle only through the particular edges between them. Its EF constraint is therefore \(v_i(X_i)\geq \max_j v_i(X_j\cap E_{ij})\). The proposed type-mass model replaces those recipient-specific values with an average over role \(u\). For example, if one of two \(u\)-agents receives a good worth \(1\) to \(t\), and the other receives nothing, the type average is \(1/2\). A \(t\)-agent with own value \(3/4\) passes the aggregate comparison but envies the first recipient. This is a mismatch in what the constraint measures, not a matter of restating ties or integrality.

One can repair it by requiring allocations to be equalized across role members, or by choosing a dense, regular network where role-level averages represent every individual comparison. That makes a plausible continuous fair-orientation model. But the theorem’s hard instances preserve individual incidence and capacities: the reduction from Target Outdegree Orientation retains the source graph’s adjacencies and encodes each vertex’s capacity on its own edge to the added universal vertex. To preserve that information, a type must include the relevant neighborhood and capacity. In general, that leaves as many types as agents. If instead there are only a few roles, the role schema itself carries the graph, and the proposed LP describes a restricted aggregate network rather than a high-multiplicity version of the theorem’s instances.

There is also no automatic finite-instance dictionary. Taking disjoint copies of an instance preserves every agent’s local neighborhood and envy comparisons, so it does not justify splitting each interaction class into fractional mass. Making the copies interact across roles can create enough repeated goods to support equalization, but changes the incidence graph and the scale of the goods. A useful mirror would need to specify that regime and show that its type-level constraints correspond to individual EF, rather than average envy.

That is the strongest case against this anchor: the proposed formulation is not yet a faithful high-multiplicity relaxation of EF Orientation, and the reduction behind the hardness theorem is intrinsically incidence-specific. It does not establish that no worthwhile mirror exists. A dense, role-regular market may be a sensible continuous problem that the authors would recognize, so I cannot honestly make the universal negative airtight. The remaining question is whether that regime is their problem’s continuous mirror or a new aggregate fairness model.
