The continuous mirror question

Given rational type masses \(\mu\), per-capita supplies \(\beta\) of indivisible goods, observable ordinal rankings, and hidden shared valuations \(v_t(g)\in\{h_t,\ell_t\}\), determine the minimum number \(q\) of adaptive queries \((t,g)\mapsto v_t(g)\) per type needed to output a finite-support distribution \(x\) over integral bundles satisfying \(\sum_B x_{t,B}=\mu_t\), \(\sum_{t,B}x_{t,B}B_g=\beta_g\), and \(v_t(B)\ge \frac{1}{2}v_t(B'\setminus\{g\})\) for every supported pair of bundles and every \(g\in B'\), with complexity independent of an arbitrary clone count.

The model it lives in

Types \(t\in T\) have masses \(\mu_t\), common hidden personalized bivalued valuations, and rankings over goods \(G\); \(\beta_g\) is the per-capita supply of indivisible copies. Choose an adaptive type-level query strategy and finite-support \(x_{t,B}\ge0\) over integral bundles \(B\in\mathbb{Z}_{\ge0}^{G}\), minimizing worst-case queries while guaranteeing support-wise \(1/2\)-EFX and the supply constraints.

The objection that survived

The proposed \(O(\log D)\) query bound depends on an arbitrary finite realization, while common hidden valuations let one query inform an entire type; the proponent identifies but does not resolve this mismatch.

What the mirror covers

The mirror covers Theorem 5.1's bivalued query-enhanced \(1/2\)-EFX guarantee; it leaves the ordinal lower bounds, general query tradeoffs, constant-agent results, and Theorem 5.2 unaddressed.

Open questions for a prover

  • Can Match&Freeze and RoundRobin be compressed into a polynomial-time capacitated or configuration-based algorithm in \(\tau=|T|\), \(|G|\), and the input bit length?
  • What type-level query budget is necessary and sufficient for support-wise \(1/2\)-EFX, without depending on an arbitrary denominator \(D\)?

The case FOR (proponent)

The strongest honest positive case is a high-multiplicity mirror of the paper’s bivalued query problem. It is a good mirror, but not a hardness-dissolution story: the paper contains no named NP-hardness, NP-completeness, FPT, or W[1]-hardness result of its own. Its usable anchors are algorithmic and query-complexity theorems.

The regime is a large allocation of recurring indivisible goods. Let \(T\) be a finite set of complete agent types, \(|T|=\tau\), and let \(\mu_t\) be the fraction of the population of type \(t\). Each type has a common ordinal ranking over a catalogue \(G\) of good species and a personalized bivalued additive valuation

\[ v_t(g)\in\{h_t,\ell_t\},\qquad h_t>\ell_t. \]

There are \(\beta_g\) copies of species \(g\) per unit population. The copies remain indivisible; only the population is continuous. This describes, for example, a municipal or institutional allocation in which millions of recipients fall into a few dozen recurring preference/value profiles.

The action variable is a distribution over integral bundles. If \(B\in\mathbb Z_{\ge 0}^{G}\) is a bundle, let \(x_{t,B}\) be the mass of type \(t\) receiving \(B\). Thus

\[ \sum_B x_{t,B}=\mu_t \]

for every type \(t\), and

\[ \sum_{t,B}x_{t,B}B_g=\beta_g \]

for every good species \(g\). Each individual receives an integral bundle; \(x\) is only the cross-sectional distribution of bundles. The objective is to minimize the worst-case number of value queries per type while guaranteeing an \(\alpha\)-EFX allocation.

To preserve the paper’s individual fairness notion, the EFX requirement must be support-wise, not an average-utility relaxation. Whenever \(x_{t,B}>0\) and \(x_{u,B'}>0\), require

\[ v_t(B)\ge \alpha\,v_t(B'\setminus\{g\}) \]

for every \(g\in B'\). In particular, this does not replace EFX by ex ante EFX or by a fractional bundle vector.

My lead anchor is Theorem 5.1, proved in this paper:

For bivalued instances, Match\(\&\)Freeze-and-RoundRobin (Algorithm 6) makes \(O(\log n)\) queries per agent and computes a \(1/2\)-EFX allocation.

Its content is specific. The algorithm binary-searches each agent’s top \(n\) ranked goods to detect a transition between the two values. Agents for whom the transition is found form \(M\), whose valuation functions are thereby known; the remaining agents form \(R\). In each phase it runs Match\(\&\)Freeze on \(M\), using maximum matching on high-valued goods and freezing agents when necessary, and then runs one RoundRobin round on \(R\). The paper proves that the resulting allocation is \(1/2\)-EFX, while using \(O(\log n)\) value queries per agent. The exact-EFX property of the Match\(\&\)Freeze subroutine is cited from earlier work, but Theorem 5.1 and its query-enhanced combination are proved here.

The corresponding continuous problem is:

Continuous Bivalued Query-EFX\(_{1/2}\). Given rational type masses \(\mu\), rational per-capita supplies \(\beta\), and the ordinal ranking of every type, with the cardinal values hidden but promised to be personalized bivalued, design an adaptive strategy that asks at most \(q\) queries of the form \((t,g)\mapsto v_t(g)\) per type and outputs a finite-support configuration \(x\) satisfying the supply constraints and support-wise \(1/2\)-EFX for every valuation profile consistent with the answers.

The direct high-multiplicity version asks whether \(q=O(\log D)\) suffices, where \(D\) clears the denominators of \(\mu\) and \(\beta\). The stronger compressed version asks for a strategy and a polynomial-size configuration output whose running time and query count are polynomial in \(\tau\), \(|G|\), and the encoding length, rather than in \(D\).

This is recognizably the authors’ problem: additive valuations, indivisible goods, ordinal information, value queries, and approximate EFX are all unchanged. Only repeated agents are represented by mass, and per-capita supplies are scaled so that the goods remain indivisible. The finite/high-multiplicity dictionary is exact: clearing denominators creates \(D\mu_t\) agents of type \(t\) and \(D\beta_g\) copies of each good species. Conversely, aggregating a finite cloned allocation gives \(x\).

I would expect the compressed problem to be Class A, at least for the bivalued case. The matching component should become a capacitated flow or type-good matching problem, and the freeze state is type-level rather than agent-level. The real proof obligation is to compress the RoundRobin and support-wise EFX conditions without enumerating the \(D\) clones. If that succeeds, the paper’s \(1/2\)-EFX result becomes a genuine continuous-population algorithmic result. Further questions include whether \(1/2\) is optimal for fixed \(\tau\), whether \(O(\log D)\) queries per type is necessary, and whether a polynomial-size support decomposition always exists.

The weakest point is that Theorem 5.1 gives \(O(\log n)\) queries per individual agent, whereas the proposed mirror asks for type-level query complexity and a compressed mass allocation. That compression is not proved by the paper. In particular, agents of one type may receive different bundles, and support-wise EFX is stricter than an average guarantee. Thus this is best presented as a strong, author-recognizable Class-A research problem anchored in Theorem 5.1—not as an already-established continuous theorem, and not as evidence that a discrete hardness result disappears.

The case AGAINST (opponent, writing after the proponent)

The proposed anchor is the paper’s best possible rescue, but it still does not survive as a worthwhile population continuization.

The difficulty in Theorem 5.1 is not population size. It is that each named agent has an independently hidden bivalued valuation, and the algorithm must elicit enough information from that particular agent. The \(O(\log n)\) bound comes from searching that agent’s ranking up to position \(n\), not from any interaction among many copies of a population type.

A genuine high-multiplicity model forces a dichotomy. If the repeated agents’ type labels are observable and their hidden bivalued valuation is common, one query to a representative—or \(O(\log m)\) binary-search queries—reveals the valuation of the entire mass. The per-agent query phenomenon in Theorem 5.1 has then disappeared. The natural problem is known-valuation capacitated allocation with a configuration-support constraint, not the paper’s query-enhanced EFX problem. If, instead, agents with the same ordinal ranking may have independently hidden thresholds, then those thresholds are part of their complete types. Preserving the paper’s information model therefore makes the agents distinct types again, destroying the proposed multiplicity compression.

The proposed \(O(\log D)\) formulation exposes the same problem. \(D\) is not an intrinsic parameter of a continuous society: the same distribution \(\mu=(1/2,1/2)\) can be realized by two agents, two million agents, or any larger even population. Thus a query bound in \(\log D\) either depends on an arbitrary finite realization or reduces to a bound in the number of goods, \(O(\log m)\), rather than in population mass. It is not a well-defined continuous analogue of the theorem’s resource measure.

Support-wise EFX does not repair this. With rational masses, a finite-support distribution \(x_{t,B}\) satisfying the proposed support-wise condition is simply an exact encoding of an allocation to sufficiently many cloned agents. It preserves indivisibility, but it adds no population-level relaxation to EFX. The new challenge would be compressing Match\(\&\)Freeze and RoundRobin into a capacitated configuration representation—something the paper neither studies nor motivates as a query theorem. Conversely, replacing support-wise EFX by ex ante or average EFX would produce a more convex and potentially tractable problem, but it would no longer be the individual EFX guarantee of Theorem 5.1.

The same objection defeats the stronger bivalued variants. Theorem 5.2’s two-query \(1/n\)-EFX guarantee becomes a type-revelation question under observable repeated types; keeping independent hidden values removes the high-multiplicity premise. Existing full-information bivalued algorithms can be compressed into a new capacitated fair-division problem, but that is a different contribution whose substance lies in allocation decomposition, not in continuizing this paper’s result.

This is not an airtight impossibility claim. A recurring institutional allocation with publicly identifiable cohorts, indivisible good copies, and support-wise EFX is a sensible high-multiplicity object. But it is not a faithful mirror of the paper’s central query tradeoff: preserving multiplicity eliminates the information-theoretic phenomenon, while preserving that phenomenon eliminates multiplicity. The continuous version is therefore either a repackaged finite clone allocation or a new fair-division problem with a different source of difficulty.
