The case AGAINST (opponent, writing after the proponent)

The “no anchor” case is right in a narrow sense: the paper has no numbered theorem giving a complexity classification. But it does contain a computational task to continue. RECURSALL is presented as an algorithm for finding all Kemeny rankings, and equations (3)–(4) give the paper’s central procedure for convolving those rankings into one tie-inclusive result.

A natural mirror takes a society to be a rational distribution \(\mu\) over the paper’s weak-order types. Let \(K(\mu)\) be the set of strict rankings minimizing the paper’s pairwise-disagreement objective, weighted by \(\mu\). The mirrored convolution orders alternatives by
\[ r_i(\mu)=\sum_{\pi\in K(\mu)}\operatorname{rank}_{\pi}(a_i), \]
with ties when these sums agree. The computational question is whether this final ranking can be found directly from the sparse input \((\mu_t)\), with complexity in the number of alternatives, support size \(\tau\), and bit length \(L\)—especially when \(K(\mu)\) is too large to enumerate.

This is a plausible population regime in the paper’s own settings: a large crowdsourced ranking task can have many users who submit the same complete ranking. Each type then captures everything the procedure uses. For rational \(\mu_t=q_t/Q\), expanding each type into \(q_t\) voters multiplies every Kemeny distance by \(Q\); it preserves the optimal set and the convolution. That gives a precise high-multiplicity dictionary while making compressed input size, and the cost of processing all optimal rankings, the questions to study.

So the missing complexity theorem weakens the case for a direct mirror of a stated complexity result. It does not establish that no worthwhile continuous mirror exists. The follow-on problem is anchored in the paper’s algorithm and main procedure, and asks how their computation behaves when the society is supplied as masses.
