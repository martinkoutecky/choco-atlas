The continuous mirror question

Given a finite type set \(T\), rational masses \(\mu_t>0\) summing to \(1\), and a type-invariant Boolean preference formula \(\varphi_t\) for each type, decide whether there is a mass allocation \(x_{t,S}\ge 0\) over coalition supports \(S\subseteq T\), with \(x_{t,S}>0\) only when \(t\in S\) and \(\sum_{S\ni t}x_{t,S}=\mu_t\), that is AE-FX stable against profitable tagged infinitesimal individual deviations and Pareto-optimal by satisfied mass of each type.

The model it lives in

A nonatomic society with finitely many complete preference types and rational masses. Variables \(x_{t,S}\) give the mass of type \(t\) in coalitions with support \(S\); stability checks whether a tagged infinitesimal member can profitably move to an existing coalition or a singleton with required entry approval, and Pareto optimality compares satisfied mass for every type.

The objection that survived

The allocation \(x\) does not itself represent a zero-mass entrant, so the tagged-agent convention for evaluating destination support and entry approval is additional structure; the proponent flags this issue but does not establish that this convention is the uniquely faithful one.

fatal: False

What the mirror covers

The mirror covers Theorem 3’s existence question for partitions that are both Pareto-optimal and AE-FX Nash-stable. It leaves the FE-AX, core-stability, other complexity, algorithmic, and empirical results without a mirror.

Open questions for a prover

  • Does Σᵖ₂-hardness persist when types may split their mass among coalition supports?
  • What precise tagged-deviation convention best preserves the paper’s AE-FX membership-rights meaning in the nonatomic model?
  • Is the existence problem tractable or fixed-parameter tractable in the number of types?

The case FOR (proponent)

The strongest honest mirror I see is a nonatomic, type-invariant version of Pareto-optimal AE-FX Nash-stable coalition formation. The population becomes continuous, while the paper’s central question remains: can agents form coalitions so that no agent has a permitted profitable move, and no feasible reorganization makes anyone worse off while making someone better off?

My anchor is Theorem 3, proved in this paper. It establishes that deciding whether a Boolean hedonic game has a partition that is both Pareto optimal and Nash stable under approved entry and free exit (AE-FX, or individual Nash stability) is \(\Sigma^p_2\)-complete. The authors prove membership and give a hardness reduction from \(\exists\forall\)-QBF-SAT; this is not merely a result cited from earlier work.

Call the mirror AE-PO Coalition Formation\(_\infty\). An instance has a finite set of types \(T\), positive rational masses \(\mu_t\) summing to \(1\), and, for each type \(t\), a Boolean formula \(\varphi_t\). A type is a complete preference profile: all its members have the same formula, which evaluates whether they are happy in a coalition based on which types have other members there. The formulas are invariant to the identities of individual members. This is a natural clone-symmetric regime of Boolean hedonic games.

A coalition structure can be specified by masses \(x_{t,S}\), where \(S\subseteq T\) is a coalition’s type support. Require \(x_{t,S}>0\) exactly when \(t\in S\), and \(\sum_{S\ni t}x_{t,S}=\mu_t\). Thus mass is the fraction of each type assigned to each coalition support; agents remain indivisible, but type-level assignments can be fractional. Since preferences depend only on support, coalitions with the same support can be merged.

Ask whether there is such an \(x\) that is both AE-FX stable and Pareto optimal. For stability, consider an infinitesimal member of type \(t\) in a positive-mass coalition with support \(S\). They may move to another existing coalition with support \(R\), or form a singleton. Their move is profitable if \(\varphi_t(R)=1\) and \(\varphi_t(S)=0\); it is permitted under approved entry if no incumbent type \(j\in R\) strictly prefers \(R\) without the entrant to \(R\cup\{t\}\). For Pareto optimality, write \(H_t(x)=\sum_{S:\varphi_t(S)=1}x_{t,S}\) for the satisfied mass of type \(t\). A feasible \(y\) Pareto-dominates \(x\) when \(H_t(y)\ge H_t(x)\) for every type and the inequality is strict for at least one. A solution is a mass allocation \(x\) satisfying both conditions.

A plausible regime is a large cooperative or mutual-aid network in which many members share a relatively small number of complete preference profiles—for example, members’ Boolean preferences depend on which occupational or service roles are represented in a project coalition. The population size \(n\) is much larger than the number of profiles \(\tau=|T|\); mass records how much of each profile type joins each coalition. This keeps the paper’s coalition formation, individual moves, entry approval, and welfare question intact while making the population itself continuous.

For this unrestricted-\(\tau\) mirror, my provisional expectation is Class B, hardness transfers: the Boolean choices in Theorem 3 live in coalition composition, so they may survive when headcount becomes divisible. That is a conjectural direction, not a consequence of the theorem. A reduction would have to show that fractional splitting does not create stable, Pareto-optimal outcomes that have no discrete counterpart. With fixed \(\tau\), I would instead expect the finite support structure to permit tractability. This case covers only Theorem 3; it does not claim a mirror for the paper’s other results.

The weakest point is that the paper’s hardness construction uses individual agents as distinct logical roles. It does not establish hardness when many agents are interchangeable copies of a small set of types, and its \(\Sigma^p_2\) result therefore does not transfer automatically. The continuous move convention also needs scrutiny: a single infinitesimal departure leaves the source coalition’s type support unchanged. Entry approval remains consequential in this model, but an author or referee may reasonably ask whether this is the right nonatomic interpretation of their membership-rights notion.

The key follow-up questions are whether the Theorem 3 reduction can be made robust to fractional type mass, whether the mirror is tractable or fixed-parameter tractable in \(\tau\), and which membership-rights refinements retain their intended meaning under infinitesimal deviations.

The case AGAINST (opponent, writing after the proponent)

Theorem 3 is a real computational anchor: the paper proves \(\Sigma^p_2\)-completeness for existence of a Pareto-optimal AE-FX Nash-stable partition. Its result cannot be dismissed because a continuous version might have a different complexity or answer.

The strongest objection is about what its agents and deviations mean. In the paper, each Boolean formula can refer to named agents. A type that captures everything relevant may therefore be unique to each agent, leaving no high-multiplicity regime in the general model. The proponent’s role-based formulas repair that by imposing clone symmetry. That is a legitimate restriction, and plausible settings such as project teams with role-based preferences exist, so this objection alone does not defeat the mirror.

The sharper problem is that Nash stability tests a single agent’s move, while \(x_{t,S}\) records only mass. A lone agent has zero mass. If coalition support means positive mass, their entry does not add their type to \(R\); if it means that any member counts, the tagged entrant changes support without changing \(x\). The proposed approval test using \(R\cup\{t\}\) supplies a tagged-agent convention, but that convention is extra structure: it is not determined by the mass allocation. Requiring positive-mass moves instead would give a group-deviation notion, not the paper’s individual Nash stability. The same atomic issue affects the paper’s FE-AX variants and the stability component of its core-stability results.

A repaired model with anonymous type templates, positive-mass coalition supports, and explicitly defined tagged-agent deviations could be coherent and worth studying. That repair also shows why the negative case is weak: role-based repeated types are plausible, and the authors might recognize that model as their problem. I can argue that the proposed mirror is not yet a well-defined consequence of the paper’s population data, but I cannot honestly establish that no worthwhile mirror exists in any scenario.
