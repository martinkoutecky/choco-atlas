The continuous mirror question

Given a finite set of request types \(T\), population masses \(\mu_t\), vehicle capacity \(Q\), and feasible route configurations \(r\) with type-count vectors \(a_r\) and costs \(c_r\), let \(p_t\) be a proposed per-passenger charge. Determine whether any blocking mass exists by maximizing \(\sum_r (p^\top a_r-c_r)x_r\) subject to \(\sum_r a_{tr}x_r\le\mu_t\) for each \(t\) and \(x_r\ge0\); if the optimum is positive, return a blocking route mixture, and otherwise certify none exists.

The model it lives in

A high-multiplicity ridesharing cost game with repeated, fully specified request types and mass \(\mu_t\) of each type. Each integral route configuration serves at most \(Q\) passengers; continuous route frequencies \(x_r\) describe the population shares assigned to those configurations. Separation for type-level prices \(p_t\) is reduced-cost pricing over the route configurations.

The objection that survived

The configuration LP makes the continuous core nonempty whenever feasible and bounded, so the mirror loses the finite game's empty-core behavior; this bounds the question but does not remove the route-pricing problem.

fatal: False

What the mirror covers

The mirror covers Proposition 3's reduction of core constraints and the associated route-generation subproblem. It does not cover the finite game's exact nucleolus, its empty-core cases, or the empirical approximation claims.

Open questions for a prover

The case FOR (proponent)

The paper has no numbered theorem, lemma, corollary, or proposition that states a complexity classification. Its NP-hardness statements appear in prose. The strongest named result I can use for a positive case is Proposition 3, proved in the paper: *for an RSP game with a non-empty core, every core-defining inequality for an infeasible coalition \(S\ne N\) is unnecessary.* The proof partitions that coalition’s optimal rideshare plan into feasible route coalitions and sums their inequalities. This is a useful computational reduction, though it does not meet a strict requirement for a named P/NP-hardness result or a numbered formulation theorem.

A plausible mirror is Continuous Core Separation for Type-Based Ridesharing. Consider a large commuter population with a relatively small support \(T\) of repeated request types: each type completely specifies the pickup and drop-off zones, time window, and other features relevant to routing and cost. Let \(\mu_t\) be type \(t\)’s population share. Vehicle capacity \(Q\) stays fixed while the fleet scales with the population.

A route configuration \(r\) is a feasible pickup-and-drop-off route serving at most \(Q\) riders, with type counts \(a_{tr}\) and cost \(c_r\). For a coalition with mass vector \(0\le\nu\le\mu\), define its normalized cost by

\[ C(\nu)=\min\left\{\sum_r c_r x_r: \sum_r a_{tr}x_r=\nu_t\ \text{for each }t,\quad x_r\ge0\right\}. \]

Here \(x_r\) is the route frequency per capita: fractional frequencies describe the proportions of many same-type passengers assigned to each route configuration, while each passenger still receives an integral ride.

Given a proposed per-passenger charge \(p_t\), the continuous core-separation problem asks whether the allocation is efficient, \(p\cdot\mu=C(\mu)\), and whether any coalition mass can block it. More precisely, solve

\[ \max\left\{\sum_r (a_r\cdot p-c_r)x_r: \sum_r a_{tr}x_r\le\mu_t\ \text{for each }t,\quad x_r\ge0\right\}. \]

If the optimum is positive, return the blocking mass \(\nu=\sum_r a_r x_r\) and its route mixture. If it is zero, certify that no coalition mass blocks the allocation. Proposition 3 motivates restricting the search to route-sized coalitions: deviations assembled from larger coalitions can be decomposed into feasible route configurations.

I think ride-service authors could recognize this as a continuous version of their core-stability and coalition-generation subproblem. The setting is a fleet serving many repeated commute requests, with \(N\gg\tau\), where \(\tau=|T|\). It changes the coalition costs to their high-multiplicity configuration-LP form, but that co-modification is what gives mass a precise meaning here.

With \(Q\) variable, I expect the route-pricing part to remain hard for the same pickup-and-drop-off ordering reasons as in the paper’s prize-collecting subproblem. That points toward Class B, though a formal hardness reduction for this exact separation problem would still be needed. With fixed \(Q\), enumerating type bundles and their feasible route orders takes polynomial time in \(\tau\) and the input bit length, giving a tractable restricted regime. Further questions include whether pricing admits a useful parameterized algorithm in \(Q\), how the continuous core relates quantitatively to finite high-multiplicity games, and what continuous lexicographic notion would preserve the paper’s nucleolus.

This case covers the paper’s core-constraint reduction and route-generation subproblem, not its exact nucleolus algorithm or its experimental approximation claims. Its weakest point is also the anchor issue: Proposition 3 is a proved structural simplification, not a complexity classification. So this is a credible candidate mirror of a computational subproblem, but it does not satisfy the strict named-complexity-anchor requirement as written.

The case AGAINST (opponent, writing after the proponent)

The only named result the proponent anchors on is Proposition 3. It says that, when the finite ridesharing game has a nonempty core, inequalities for infeasible coalitions are redundant. It is a computationally useful structural result, but it is not a complexity classification. The paper’s harder computational claims concern its nucleolus algorithm and its routing subproblems; those appear in the algorithm and discussion, not as a named theorem about worst-case complexity.

The proposed continuous core question also changes what Proposition 3 is doing. Write \(a_r\) for the vector of type counts on a route and \(c_r\) for its cost. Under the proposed model,
\[ C(\mu)=\min\{c^\top x: Ax=\mu,\ x\ge 0\}. \]
A per-type price vector \(p\) is in the continuous core exactly when it is efficient, \(p^\top\mu=C(\mu)\), and satisfies \(p^\top a_r\le c_r\) for every route. Those route inequalities imply every coalition-mass inequality by summing over its route mixture. Conversely, if one route violates its inequality, a sufficiently small positive mass of that route fits within \(\mu\) and blocks \(p\). The route inequalities are precisely the dual constraints of the displayed LP.

So the proposed separator is reduced-cost pricing for the route LP. The continuous model also has a nonempty core whenever that LP is feasible and bounded: an optimal dual price vector supplies one. In this sense, the coalition reduction is built into the convexified cost function, and the proposed question does not carry over the paper’s difficult nucleolus computation or its empty-core cases. It may still be useful to study the pricing oracle’s complexity, but that is a narrower claim, especially since the paper already uses column generation for the operational routing problem.

A better setting for the mirror is repeated commuter requests with the same stops and schedule, a finite type support, and a fleet that scales with demand. That is a plausible high-multiplicity regime; I would not reject it on the ground that rideshare passengers must always be unique. But if requests vary continuously by location and time, treating them as identical types changes routing costs; if they are grouped into zones, the zonal cost model needs defending. More importantly, in the resulting route-frequency model, core prices are LP dual values. That makes the proposed fairness question look like an extension of the existing route-pricing machinery, rather than a new continuous counterpart to the paper’s main fairness algorithm.

The stronger attempt—taking the limit of the finite games’ nucleoli—has a different obstacle. The finite nucleolus lexicographically orders finitely many coalition excesses; a continuum has uncountably many coalitions and no immediate corresponding ordered excess vector. A least-core limit or a chosen measure over coalitions could define a new question, but it would require a substantive modeling choice, and neither follows from Proposition 3.

That is the best skeptical case: the named anchor appears to collapse to LP duality, while the paper’s nucleolus contribution lacks a canonical continuum analogue. It does not establish the universal negative the assignment asks for. Repeated, type-homogeneous commute flows make the population regime credible, and route-pricing complexity could still be worth studying. I cannot honestly claim that no worthwhile mirror survives.
