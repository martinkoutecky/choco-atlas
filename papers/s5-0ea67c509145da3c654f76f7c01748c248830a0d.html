The case FOR (proponent)

The strongest positive angle is a high-multiplicity version of the spatial core problem: types are voters’ ideal points in \(\mathbb{R}^d\), mass is the fraction of society at each ideal point, and preferences are Euclidean. Given a rationally weighted list of ideal points and a majority threshold, ask for the exact set of alternatives unbeaten by any alternative preferred by enough mass. That is a sensible computational question about a continuous population; the paper’s discussion of pivotal strips and the core makes it especially natural.

But it has no qualifying anchor under your criteria. The named results here—Black’s Median Voter Theorem, Plott’s Majority Rule Equilibrium Theorem, McKelvey’s Global Cycling Theorem, and Greenberg’s Core Existence Theorem—are unnumbered analytical results, not numbered computational-complexity results. In particular, Greenberg’s theorem says that in \(d\) dimensions the core is guaranteed to be nonempty when \(k>nd/(d+1)\), and may be empty when \(k\le nd/(d+1)\); it is cited from elsewhere and says nothing about an algorithm or complexity. So the core-computation question is a plausible research extension, but it cannot honestly serve as an anchor for the requested case.

The case AGAINST (opponent, writing after the proponent)

The only positive anchor raised is computing the core from a population distribution of ideal points. The chapter has named theorems, but none asserts the complexity of a computational problem: Black, Plott, McKelvey, and Greenberg characterize when a Condorcet winner, cycles, or a nonempty core exist. So the proposed core computation has no computational result here to mirror. That is the strongest objection, and it disposes of the anchor under the requested standard.

The best repair is to ask for the exact core from rationally weighted ideal points, with dimension and majority threshold as parameters. That is a sensible high-multiplicity scenario; repeated locations could represent large groups. But it adds an algorithmic problem to the chapter’s geometric characterizations. For finite support, the chapter already describes the core through pivotal points or strips, so a complexity study would be about computing a weighted geometric region, not about a computational question the paper posed. If instead the society is a smooth distribution over locations, the mirror needs an input representation for that distribution; the chapter’s finite-voter results do not supply one.

Extending the proposal to the yolk or uncovered set does not rescue the anchor. Those are also geometric objects characterized in the chapter, and it mentions software that demarcates the uncovered set for ideal-point configurations. Distributional or weighted algorithms could still be useful, but they would be further computational research, not a mirror of a complexity result in this paper.

I cannot make the broader claim that computational spatial voting is unworthy: the population interpretation is plausible, and weighted core computation could be a worthwhile project. The negative case is strong only on the narrower judgment the anchor test requires: this chapter does not offer a computational result for ChoCo to continuize.
