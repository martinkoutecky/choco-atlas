The continuous mirror question

Given a finite type set \(T\), distribution \(\mu\), path length \(m\), binary valuations \(v_t:[m]\to\{0,1\}\), rational \(0\le\beta\le1\), and type-level \((4,3)\)-sparsity, decide whether there are nonnegative interval-assignment masses \(\lambda_{t,I}\) satisfying \(\sum_I\lambda_{t,I}=\mu_t\), \(\sum_{t,I:j\in I}\lambda_{t,I}=\beta\) for every \(j\in[m]\), and \(\sum_{t,I}\lambda_{t,I}\sum_{j\in I}v_t(j)=m\beta\).

The model it lives in

A repeated-path high-multiplicity CAP model: type \(t\) carries mass \(\mu_t\), each mass unit receives one indivisible contiguous interval \(I\subseteq[m]\), \(\lambda_{t,I}\) records aggregate assignment mass, each slot has capacity \(\beta\), and utilitarian welfare \(\mathrm{U}_\infty=\sum_{t,I}\lambda_{t,I}v_t(I)\) is maximized.

The objection that survived

For full coverage, the type-level \((4,3)\) promise implies \(|T| \ge m/4\), so the mirror may retain a large type description and provide less compression than the motivating regime.

fatal: False

What the mirror covers

The mirror covers Theorems 12 and 13, while leaving the fixed-order algorithms, EF1 result, PROP, EQ, MMS, PO, and other approximation and parameterized results untreated.

Open questions for a prover

  • Can the interval configuration LP be solved exactly in polynomial time in \(m\), \(|T|\), and the input bit-length?
  • Does every rational feasible \(\lambda\) admit an exact realization by finitely many repeated paths and cloned organizers?
  • For fixed \(|T|\), where is the complexity boundary between full coverage, egalitarian thresholds, and other contiguous-allocation objectives?

The case FOR (proponent)

The strongest positive case is a high-multiplicity version of the paper’s flexible-order problem, using the scheduling interpretation from its introduction: many recurring conference sessions, each with the same ordered time-slot template, and many organizers whose preferences fall into finitely many complete schedule types.

My lead anchor is Theorem 12, proved in this paper by a reduction from \(2\mathrm{L}\)-\(\mathrm{OCC}\)-\(3\mathrm{SAT}\). It states that, in the flexible-order setting, maximizing utilitarian social welfare for binary \((4,3)\)-sparse CAP is NP-hard. Moreover, it is NP-complete to decide whether the optimum utilitarian welfare equals the number of items. Here “\((4,3)\)-sparse” means that each agent values at most four items and each item is valued by at most three agents; every bundle must be contiguous, but the order of agents’ blocks is unrestricted.

I would mirror it as follows. Let \(T\) be a finite set of organizer types, with population distribution \(\mu\). Type \(t\) has a binary valuation \(v_t(j)\in\{0,1\}\) for each position \(j\in[m]\) of a standard path template. A type is complete: all organizers of that type have the same valued slots. The venue supplies \(\beta\) copies per organizer of every slot position, where \(\beta\) is rational; at population size \(N\), this means \(N\beta\) identical path sessions. Each organizer receives one integral contiguous interval \(I\subseteq[m]\), possibly empty, in one session.

The continuous decision variable is

\[ \lambda_{t,I}\ge 0, \]

the mass of type \(t\) assigned to interval \(I\). It must satisfy

\[ \sum_I\lambda_{t,I}=\mu_t \]

for every type \(t\), and

\[ \sum_{t,I:j\in I}\lambda_{t,I}=\beta \]

for every slot \(j\). The objective is

\[ \mathrm{U}_\infty = \max_\lambda \sum_{t,I}\lambda_{t,I} \sum_{j\in I}v_t(j). \]

This is not divisible-item allocation: every unit of mass receives an integral interval. Only the aggregate number of identical organizers assigned to each interval is fractional. For rational data, multiplying by a common denominator gives a finite allocation of cloned organizers and indivisible item copies. Since intervals have the interval-graph property, any such aggregate interval multiset can be packed into the repeated path sessions.

The precise continuous question is therefore:

Given \((T,\mu,v,\beta)\), does there exist a feasible high-multiplicity contiguous allocation with \(\mathrm{U}_\infty=m\beta\), meaning that every supplied item copy is assigned to a type that values it?

The \((4,3)\) promise is naturally carried over at type level: each type values at most four slot positions, and each slot position is desired by at most three types. Literal agent-level sparsity cannot survive cloning, so this is an explicit, honest co-modification.

I expect this mirror to be Class A. The configuration LP above has only \(O(|T|m^2)\) variables, since the configurations are intervals. Thus the continuous optimum is computable in polynomial time. The paper’s NP-hardness can dissolve because identical type mass may split across several integral intervals, while the repeated item supply removes the one-copy bottlenecks that encode individual identities. This is exactly the kind of population-driven hardness that continuization is meant to test.

A second worthwhile anchor is Theorem 13, also proved in this paper, by a reduction from \(3\mathrm{SAT}\). It states that flexible-order E-max is NP-hard for binary \((6,3)\)-sparse CAP, and more specifically that it is NP-complete to decide whether the optimum egalitarian welfare is at least \(2\) or at most \(1\).

Its continuous counterpart is \(\mathrm{CCAP}\text{-}E_\infty\), on the same \((T,\mu,v,\beta)\) instances. Define \(E_\infty\) as the largest \(\eta\) for which there is a feasible \(\lambda\) satisfying

\[ \lambda_{t,I}>0 \quad\Longrightarrow\quad \sum_{j\in I}v_t(j)\ge\eta \]

for every type \(t\) with \(\mu_t>0\). In words, every organizer—not merely every type on average—must receive a contiguous integral bundle worth at least \(\eta\). The continuous decision question is:

Is \(E_\infty\ge2\), or is \(E_\infty\le1\)?

For any fixed \(\eta\), this is again a linear feasibility problem: simply forbid configurations \(I\) with \(v_t(I)<\eta\). I therefore also expect this mirror to be Class A. It preserves the paper’s flexible ordering, binary additive valuations, contiguity, and egalitarian objective while replacing named-agent scarcity by a distribution of repeated types.

The regime is plausible in the paper’s own application domain: a large organization runs many identical conference days, and thousands of organizers belong to a relatively small catalogue of recurring schedule types. The number of organizers is much larger than the number of types, and the number of available slots scales with the population. This is a genuine high-multiplicity scenario, not an assertion that a committee of seven agents should be treated as a continuum.

The weakest point is that the natural scaling produces repeated path sessions rather than one fixed path shared by all agents. If the authors insist that only one physical path is admissible, with no replicated per-capita supply, then the mirror becomes much less convincing: contiguity and item scarcity may retain the original hardness. But under the programme’s permitted co-modification—per-capita supplies with indivisible bundles for each underlying organizer—the two named hardness results have precise continuous counterparts, and both plausibly become polynomial configuration-LP problems.

The case AGAINST (opponent, writing after the proponent)

The strongest case against is that neither proposed mirror preserves the paper’s central object. CAP has one path containing one copy of each item. With \(N\) cloned organizers but the same inventory, at most \(m\) organizers receive nonempty bundles, so the nonempty population has mass at most \(m/N\). In the atomless limit, utilitarian welfare per capita collapses to \(0\), and egalitarian welfare is \(0\). Thus the literal high-multiplicity limit is degenerate.

The proposed repair—\(\beta N\) copies of every position, packed into repeated paths—avoids that degeneration only by changing the resource environment. It is no longer allocation on one path; it is capacitated interval assignment over a collection of paths. The fact that interval multisets can be packed by interval-graph coloring confirms that the single-path coupling has been removed. This is a legitimate new problem, but the connection to Theorems 12 and 13 is then only motivational rather than a faithful continuization of their instances.

Theorem 12 is especially vulnerable. Its \((4,3)\)-sparsity is a bound on named-agent incidence: each item is valued by at most three agents. Under genuine cloning, one valued type produces arbitrarily many agents valuing that item, so the promise disappears. Replacing it by “at most three types value each position” is a different promise, not a population-scaled version of the theorem’s sparse instance. Moreover, the reduction’s SAT consistency is carried by unique variable, occurrence, and divider agents sharing one scarce path. Splitting a type’s mass among several intervals and several paths deliberately destroys precisely that mechanism.

Theorem 13 has the same defect. Its egalitarian threshold forces each named variable agent into one of two contiguous choices, thereby encoding a truth assignment. In the proposed \(E_\infty\), mass of one type may be divided between both choices. The resulting LP is perfectly well-defined, but it has discarded the indivisible-agent consistency that makes the theorem hard. If one forbids such splitting to preserve the reduction, the variables become unsplittable integer blocks and the claimed continuous optimization advantage disappears.

There is also no fixed-small-type regime behind the sparse perfect-coverage question. If every one of \(m\) positions must be valued by some type and each type values at most four positions, then

\[ m\le \sum_{t\in T}|\{j:v_t(j)=1\}|\le 4|T|. \]

Hence \(|T|=\Omega(m)\). The model may have many organizers per type, but it does not compress the type structure responsible for the paper’s hard instances.

This is nevertheless a weak negative case. The programme explicitly permits per-capita supply when a fixed inventory would make the limit degenerate, and it explicitly allows type-level reformulations of individual-level promises. Under those rules, the repeated-session model is a plausible high-multiplicity scheduling scenario, and the fact that the SAT obstruction vanishes is itself a worthwhile Class A result. I therefore cannot honestly sustain the universal conclusion that no valuable continuous mirror exists. The fair negative verdict is “substantial fidelity and novelty concerns,” not rejection of both anchors.
