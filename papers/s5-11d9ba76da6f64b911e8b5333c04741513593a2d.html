The continuous mirror question

Given a finite type set \(Q\), rational population masses \(\mu\), and an explicitly represented rational polynomial \(F:[0,\mu]\to\mathbb{Q}\) with \(F(0)=0\), define the \(r\)-player game by \(v_r(S)=rF(k(S)/r)\), where \(k(S)\) counts each type in coalition \(S\) and \(r\mu_q\) is integral for every \(q\in Q\). For each \(q\in Q\), compute the limit as \(r\to\infty\) of the average solidarity payoff of type-\(q\) players.

The model it lives in

A society has fixed types \(Q\) with masses \(\mu\); coalition worth is \(F(x)\) for its type-mass vector \(x\). The output is the limiting per-player payoff vector \(p\), with no optimization variables or objective. For the proposed smooth worth functions, \(p_q=F(\mu)\) for every \(q\in Q\).

The objection that survived

The case gives a plausible large-venture setting but does not establish that the authors would value this equal-payoff limit.

The case FOR (proponent)

There is no fully compliant computational complexity anchor in this paper. Its numbered results prove dividend identities and axiomatic characterizations; none establishes that a computational problem is in P, NP-hard, or has another complexity classification. The paper’s claims that computation becomes easier are not formal complexity results.

The closest possible lead is Proposition 3, proved here. It states that for a finite TU game \((N,v)\), the solidarity payoff to player \(i\) is
\[ \phi_i^{\mathrm{Sol}}(N,v) = \sum_{\substack{T\subseteq N\\i\in T}} \frac{\mu_v(T)}{|T|\binom{|N|}{|T|}}, \]
where the coefficients \(\mu_v(T)\) are defined by the paper’s recursive dividend rule on the basis \(b_T(S)=\binom{|S|}{|T|}^{-1}\) when \(T\subseteq S\), and \(0\) otherwise. This is a useful formula for computing the value, but it is not a complexity classification or an algorithmic formulation that the paper analyzes. So it is only a provisional anchor under the prompt’s formulation exception.

If that formula is admitted as an anchor, the strongest mirror I can make is a large-population limit of computing the solidarity value. Take a fixed finite set \(Q\) of player types and a rational mass vector \(\mu\), with \(\sum_{q\in Q}\mu_q=1\). A type is a player’s complete cooperative role; players of the same type are indistinguishable, and coalition worth depends only on its type composition. Represent worth by an explicitly listed rational polynomial \(F\) on \([0,\mu]\), with \(F(0)=0\). For each integer \(r\) such that \(r\mu_q\) is integral, form the finite game with \(r\mu_q\) players of type \(q\) and coalition worth \(v_r(S)=rF(k(S)/r)\), where \(k(S)\) is the vector of type counts in \(S\).

Call the continuous problem Continuous Solidarity Limit Computation: given \(Q,\mu,F\), return the limiting solidarity payoff per player for each type as \(r\) tends to infinity. The type-level payoff is the output; there is no separate optimization objective. A plausible regime is a large cooperative venture with many interchangeable members in each of a small number of roles, where surplus depends on the proportions of roles in a coalition.

For differentiable \(F\), the random-permutation interpretation of the solidarity value gives the limiting payoff
\[ p_q = \int_0^1\sum_{s\in Q}\mu_s\,\partial_s F(\alpha\mu)\,d\alpha = F(\mu)-F(0) = F(\mu) \qquad\text{for every }q\in Q. \]
Thus this explicit-polynomial version is tractable: every type receives the same limiting payoff, computable by evaluating \(F(\mu)\). It is a faithful limit of the paper’s value formula, though the limiting egalitarian outcome means it loses type-level payoff differences.

That is the mirror’s weak point, along with the fact that Proposition 3 is a formula rather than a complexity result. The authors could plausibly recognize the question as a high-multiplicity limit for computing their solidarity value, but the paper does not study that regime, and its central axiomatic theorems—including Theorems 4–6—are not mirrored here. Further questions would be finite-\(r\) error bounds, limits for less regular worth functions, and whether the dividend and potential formulas yield informative finite-population approximations.

The case AGAINST (opponent, writing after the proponent)

There is no numbered computational complexity result to mirror. Theorem 1, Theorem 2, and Theorems 4–6 characterize a value axiomatically; Proposition 3 gives a dividend formula; Theorem 3 rewrites the A-potential. None classifies an algorithmic problem. The paper’s claims about reduced computational complexity are not backed by a stated algorithm or runtime bound; it even describes “efficient” as easier interpretation and says algorithms can be designed. So Proposition 3 is the strongest possible anchor, but it is a formula, not a complexity result.

The best continuous question built around Proposition 3 would give many interchangeable players a fixed set of types and define coalition worth by a smooth function \(F\) of type masses. In the paper’s own polynomial setting, the limit of the solidarity payoff per player is the same for every type:
\[ p_q=\int_0^1\sum_s\mu_s\,\partial_sF(\alpha\mu)\,d\alpha =F(\mu)-F(0)=F(\mu). \]
The solidarity allocation thus becomes an equal per-capita split of the grand-coalition worth. Type-specific payoff differences disappear. This is a genuine continuum degeneration: in a nonatomic population, one player’s type has zero mass, so the coalition compositions used to distinguish players no longer depend on who the focal player is. The paper’s player-level dividend distinctions—and the axioms that compare individual players—lose their bite in that limit.

There is a fork if one tries to avoid that collapse. Restrict worth to smooth functions of type masses, and the natural limit is the equal split above. Preserve effects that distinguish particular players, and the type description must retain those identities or encode finite-scale details; then the population is no longer usefully summarized by a small support of high-multiplicity types. A more elaborate continuum dividend decomposition could be a new project, but this paper supplies neither a computational result nor a canonical continuous object for it to mirror.

I can’t establish that no worthwhile continuous cooperative-game problem could be posed. The honest negative case is narrower: this paper offers no named complexity result, and its strongest natural high-multiplicity version of Proposition 3 loses the type-level allocation structure in the continuum.
