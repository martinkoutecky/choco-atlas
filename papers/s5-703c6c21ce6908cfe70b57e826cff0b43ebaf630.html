The continuous mirror question

Given finite type sets \(\mathcal A,\mathcal B\), rational masses \(\mu,\nu\), strict rankings of opposite-side types, and a target \((a^*,b^*)\), decide whether \(\max x_{a^*b^*}>0\) over mass-matching matrices \(x\geq 0\) with row sums \(\mu\), column sums \(\nu\), and, for every \((a,b)\), \(R_{ab}(x)=0\) or \(S_{ab}(x)=0\). Here \(R_{ab}(x)=\sum_{b':\,b\succ_a b'}x_{ab'}\) and \(S_{ab}(x)=\sum_{a':\,a\succ_b a'}x_{a'b}\), so stability rules out positive mass on both sides preferring each other to their assigned types.

The model it lives in

A distribution over applicant types and placement types, each with a complete ranking of opposite-side types. The decision variable \(x_{ab}\) is the mass matched between types, with prescribed type masses and no blocking type pair; each person still receives one whole match. Ask for the maximum stable mass on a designated type pair.

The objection that survived

A finite stable matching may contain the designated pair only once, so its \(1/n\) mass vanishes; positive type-pair mass asks about a macroscopic possibility, and the case gives no finite-to-continuum equivalence for that event.

fatal: False

What the mirror covers

The mirror covers Corollary 1's designated-pair existence question at type-pair scale; it leaves Corollaries 2–3, the broader stable-marriage variants, and optimal stable marriage untouched.

Open questions for a prover

  • Can the maximum stable mass on a target type pair be computed in time polynomial in the number of types and input bit length?
  • Can all type pairs that occur with positive mass in some stable allocation be characterized efficiently?
  • How does the type-level model relate to stable pair occurrence in finite replicas?

The case FOR (proponent)

My strongest case is a typed, high-multiplicity version of stable-pair existence. The lead anchor is Corollary 1: for a size-\(n\) stable-marriage instance, determining whether an arbitrary designated pair is stable takes \(\Theta(n^2)\) time in the worst case. The report proves the lower bound using its adversary argument; the matching upper bound comes from Gusfield’s algorithm, which the report cites. The stated computation model matters: the preference and ranking matrices are already available, and querying any entry costs \(O(1)\). The lower bound counts queries to those matrices.

A plausible regime is a large, repeated placement market: for example, a yearly cohort of applicants matched one-to-one with single-slot placements. Many applicants share the same relevant credentials and ranking of placement categories; many placements share the same priorities over applicant categories. There may be tens of thousands of agents on each side but only a modest number \(\tau\) of distinct types. A type records everything relevant to matching, including its ranking of the other side’s types. Type mass is the fraction of the population with that description. This is credible only where category-level preferences are meaningful; if the market depends on individualized rankings of named counterparts, this mirror is a poor fit.

Type-Pair Stable Support is the continuous problem I would hand to a prover. An instance gives finite type sets \(\mathcal A,\mathcal B\), rational masses \(\mu_a,\nu_b\) summing to \(1\) on each side, strict rankings of counterpart types for every type, and a target pair \((a^*,b^*)\). The decision variable is a mass-matching matrix \(x\), with \(x_{ab}\geq 0\), row sums \(\mu_a\), and column sums \(\nu_b\). Each \(x_{ab}\) is the mass of type \(a\) matched to type \(b\); it describes an aggregate of ordinary one-to-one matches, not individuals receiving fractional partners.

For each type pair define
\[ R_{ab}(x)=\sum_{b':\,b\succ_a b'}x_{ab'},\qquad S_{ab}(x)=\sum_{a':\,a\succ_b a'}x_{a'b}. \]
The allocation is stable exactly when, for every \((a,b)\), \(R_{ab}(x)=0\) or \(S_{ab}(x)=0\): there cannot be positive mass on both sides who strictly prefer each other to their assigned types. The question is whether the maximum of \(x_{a^*b^*}\) over stable allocations is positive. A solution gives that maximum and a stable allocation attaining it; equivalently, it answers whether some stable allocation uses the target type pair with positive mass. Rational input yields a rational witness when the answer is yes.

This preserves the anchor’s central question: can the designated pair occur in some stable outcome? In a continuum, an individual has zero mass, so the natural high-multiplicity counterpart is whether a positive mass of the two types can be matched. The category-level indifference among agents of the same type is a co-modification of the model: it makes agents within a type interchangeable, while each individual still receives one whole match. I expect Class A, with a polynomial-time algorithm in \(\tau\) and the mass bit length. The paper’s \(n^2\) query burden could disappear when the input is a compact list of type rankings and masses. That is a conjecture, not an LP claim: the stability condition contains disjunctions, and finding an efficient way to handle them is part of the problem.

My weakest point is also the main limitation of the anchor. Corollary 1 gives an oracle-query lower bound for dense rankings over named individuals; it is not an NP-hardness result driven by population multiplicity. In an explicit-input model, reading the preference matrices already costs \(\Theta(n^2)\). And the typed model changes strict individual rankings into rankings of categories with indifference within a category. So I would not claim that the paper’s lower bound transfers, or that this covers every stable-marriage instance. The case rests on the narrower claim that type-pair stable support is a recognizable continuous version of the paper’s designated-pair question in a genuine repeated-cohort regime.

The scope is Corollary 1 alone. The next questions are whether the maximum stable mass on a target pair can be computed in polynomial time, whether all type pairs that occur in any stable allocation can be characterized efficiently, and how this typed model relates to strict rankings in large finite replicas.

The case AGAINST (opponent, writing after the proponent)

Corollary 1 is a real computational result, so the negative case cannot rest on there being nothing to mirror. Its object, though, is specifically whether one named man–woman pair occurs in some stable marriage. The adversary hides changes in preference-matrix entries indexed by individuals. That dependence on identity is central to the lower bound’s construction.

There are two ways to take this problem to a high-multiplicity setting, and each loses something essential. If agents retain strict rankings of named counterparts, then a type must preserve those rankings. In a market where preferences vary across individuals, this can make nearly every agent a different type, so the population measure does not compress the preference data. If instead types rank counterpart *categories*, agents within a category are interchangeable and indifferent among its members. That is a plausible market model, but it removes the identity-level distinctions the paper’s result probes.

The proposed target-type-pair question is coherent, but it changes the event being asked about. In the continuum, a particular man and woman have zero mass. Asking whether \(x_{a^*b^*}>0\) asks whether a type pair carries positive density in some stable allocation. A finite stable matching could contain a designated pair only \(1/n\) of the population; that occurrence vanishes in the limit. Requiring positive mass therefore changes “can this pair occur?” into “can this pair occur at a macroscopic rate?” Marking two individuals inside the continuum would preserve the original event, but those marked agents would be exceptional point objects outside the mass representation.

The strongest version of the mirror is the proponent’s repeated placement market, with agents ranking categories and a stable allocation recording mass matched between categories. That may be a worthwhile matching problem in its own right. But its stability condition sees aggregate capacity and category preferences; it cannot express the hidden, individual-indexed preference entries that drive this paper’s lower bound. The same identity gap affects the report’s other corollaries: an aggregate matching records how much mass crosses each type pair, not which named agents are partners.

So I would not use this paper as a strong case for the continuization programme. The objection is not that its lower bound would disappear; the proposed type model asks a different question. Still, the negative case has a real limit: category-level matching in large cohorts is a plausible high-multiplicity regime, and the resulting stable-support problem could merit study independently. What this paper does not establish is that such a model is a worthwhile continuous mirror of its named-pair result.
