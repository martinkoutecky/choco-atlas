The case FOR (proponent)

I cannot make a positive case that meets the anchor requirement: the paper contains no named computational complexity result. Its only numbered proposition, Proposition 1 (proved in this paper), says that for the paper’s admissible states with \(n\ge 4\), Mechanism 1 implements the socially optimal choice in subgame-perfect equilibria: an equilibrium yielding the deserving winner exists, and no subgame-perfect equilibrium yields a different winner. That is a game-theoretic implementation result; it classifies no underlying problem as tractable or hard.

The setting gives a tempting lead: a large contest in which every contestant also serves on the jury. But each agent ranks themself first, so agents with different identities have different preference types. With all contestants represented, the number of types therefore grows with the population. And Proposition 1 relies on agents taking individual turns in sequence; replacing them with aggregate mass would change the strategic structure the proposition establishes.

A model with masses of jurors sharing preferences could be worth studying, but it would need a new mechanism and a new implementation result. The paper supplies no named computational anchor for that question. So there is no continuous problem I can state as the required mirror of an anchor; the most honest positive conclusion is that this paper does not provide a qualifying anchor.

The case AGAINST (opponent, writing after the proponent)

The only possible anchor is Proposition 1, and it is not a computational result: it proves that Mechanism 1 implements the socially optimal choice in subgame-perfect equilibrium. The paper does not pose an algorithmic problem or classify its complexity. Turning that proposition into a continuized equilibrium theorem would be a game-theoretic extension, outside ChoCo’s computational question.

The strongest mirror would group many jurors into preference types while keeping the deserving winner as an individual. But the paper’s defining assumption defeats that grouping: every contestant is also a juror, and each juror ranks themself first. As the population grows, so does the set of distinct alternatives and the set of distinct preference types. Treating agents as equivalent up to relabelling would discard which person is preferred, which person is speaking, and which individual the mechanism selects. If instead candidates become a fixed set of roles shared by many jurors, the jury is no longer made up of all contestants; if the output becomes a role rather than a named person, the socially optimal choice has changed.

A continuum of identity-indexed contestants does not preserve the mechanism either. Its stages are individual turns in a sequence, and its outcome is one named contestant. Replacing those turns with mass decisions changes the extensive-form game; keeping identity as a continuum leaves the serial order and individual actions to be newly specified. Either route requires a new model and a new implementation result, rather than a population mirror of Proposition 1.

So the negative case is strong for this paper’s result: there is no computational anchor to continuize, and its identity-based sequential structure has no evident high-multiplicity regime that preserves the result’s object. It is not a proof that no algorithmic study of large contest institutions could be worthwhile; that would be a different research question, not a continuous mirror of this paper.
