The continuous mirror question

Given \(m\) item categories, \(\tau\) valuation types with rational masses \(\mu_t\) summing to \(1\), rational per-capita supplies \(q_j\), and value oracles for monotone valuations \(v_t:2^{[m]}\to\mathbb{R}_+\) satisfying \(\ell_t(S)\le v_t(S)\le(1+\epsilon)\ell_t(S)\) for some affine-linear \(\ell_t(S)=c_t+\sum_{j\in S}a_{tj}\), define \(W^*=\max\sum_{t,S}x_{t,S}v_t(S)\) subject to \(\sum_S x_{t,S}=\mu_t\), \(\sum_{t,S:j\in S}x_{t,S}\le q_j\), and \(x_{t,S}\ge0\). Characterize the worst-case number of type-value queries needed to estimate \(W^*\), in particular whether Proposition 4's lower bound against subexponential-query algorithms achieving better-than-polynomial approximation in \(m,\tau\) persists when each type has arbitrarily many identical copies and supplies scale with the population.

The model it lives in

A continuum of buyers distributed over \(\tau\) complete valuation types; each type's mass may be split among integral bundles, subject to per-capita item-category supplies, and the objective is average social welfare. The input gives each type's valuation by a value oracle and promises pointwise closeness to an affine-linear valuation.

The objection that survived

The lower bound requires τ to grow: increasing K alone only clones existing oracle types, so this anchor establishes no query barrier for large markets at fixed support.

fatal: False

What the mirror covers

The mirror covers Proposition 4's close-to-linear welfare value-estimation lower bound in the value-oracle model. It leaves the paper's additive-valuation result, greedy guarantee, demand-oracle results, and Kelso-Crawford analyses without a mirror.

Open questions for a prover

  • Does the lower bound persist at fixed \(\tau\) as the number of copies per type grows?
  • How does demand-oracle access change the query complexity of this mass problem?
  • Can explicit representations of the type valuations avoid the value-query barrier?

The case FOR (proponent)

The strongest mirror is a high-multiplicity version of the paper’s welfare problem. It keeps bidders’ bundle valuations and the social-welfare objective intact; it makes the population a distribution over complete valuation types. The most useful anchor is Proposition 4 in the published paper. Proved there in Section 3.1, it says that with value-oracle access to valuations that are \(\epsilon\)-close to linear, no algorithm using a subexponential number of queries can approximate optimal social welfare within a factor better than polynomial in the number of items \(m\) and bidders \(n\). This is an oracle-query lower bound, not an NP-hardness result. [Published paper, Proposition 4](https://doi.org/10.4230/LIPIcs.APPROX-RANDOM.2017.22).

Here is a continuous problem that puts that result to work. Call it Near-Linear Mass Welfare-Value Estimation. The instance has \(m\) item categories; a support \(T\) of \(\tau\) bidder types; rational masses \(\mu_t\ge 0\) summing to \(1\); rational per-capita supplies \(q_j\); and a value oracle for each type’s monotone valuation \(v_t:2^{[m]}\to\mathbb R_+\). Each \(v_t\) is promised to be pointwise \(\epsilon\)-close to an affine linear valuation: for some \(\ell_t(S)=c_t+\sum_{j\in S}a_{tj}\), \(\ell_t(S)\le v_t(S)\le(1+\epsilon)\ell_t(S)\).

A feasible allocation assigns mass \(x_{t,S}\) of type \(t\) to each whole bundle \(S\subseteq[m]\), subject to \(\sum_S x_{t,S}=\mu_t\) and \(\sum_{t,S:j\in S}x_{t,S}\le q_j\). Its welfare is \(\sum_{t,S}x_{t,S}v_t(S)\). The task is to estimate the maximum of that objective, \(W^*\), to a specified multiplicative factor using as few type-value queries as possible. Mass is assigned to integral bundles; only the fraction of a type receiving each bundle is continuous.

The regime is a large market for many copies of a standardized catalogue: buyers share one of \(\tau\) complete bundle-value schedules, and each category’s supply grows with the market. This could describe repeated allocation of capacity or service slots to large buyer segments. With \(K\) copies of each type, there are \(N=K\tau\) buyers but only \(\tau\) valuation functions. Taking \(\mu_t=1/\tau\) and \(q_j=1/\tau\) corresponds to \(K\) copies of each category in that finite market. Thus the high-multiplicity condition is explicit: \(N/\tau=K\) can grow without bound. It does not depend on pretending that individually different buyers share a type.

The paper’s hidden-partition construction gives a concrete reason to expect its lower bound to transfer. Set \(\tau=n\), partition the \(m=a\tau\) categories into equal hidden sets \(A_t\), and give type \(t\) the paper’s near-linear valuation built around \(\ell_t(S)=\epsilon+\frac{1}{a}|S\cap A_t|\), with the closeness parameter adjusted as in its proof. Assigning mass \(1/\tau\) of each type to bundle \(A_t\) is feasible: each category is used by exactly \(1/\tau\) mass. This gives welfare greater than \(1\) per capita in the construction’s normalization. In the low-information comparison, the oracle values depend only on bundle size, and the welfare under those baseline valuations is at most \((1+\epsilon)\epsilon+1/\tau\). The paper’s query argument hides the partition behind oracle answers; scaling bidder cohorts and supplies leaves those type oracles and the welfare gap in place.

So the question for a prover is: for Near-Linear Mass Welfare-Value Estimation, characterize the worst-case value-query complexity in \(m,\tau\), and the rational input bit length \(L\); in particular, does Proposition 4’s subexponential-query lower bound against better-than-polynomial approximation persist when \(n\) is replaced by support size \(\tau\)? I expect a hardness-transfer answer in the value-oracle model. This is not a claim of NP-completeness, and the result would cover the paper’s close-to-linear welfare lower bound, not its demand-oracle guarantees or its analyses of particular auctions.

The soft spot is the change from one copy of each item to per-capita supplies of item categories. That co-modification is needed for a populated continuum market, and the hidden-partition gap supports it, but the paper’s own stated model uses a finite set of distinct items. The paper does not prove this mass-supply version; the argument above is the proposed transfer. Its lower bound is also specific to value-oracle access. The natural follow-up questions are whether the same bound holds when \(\tau\) is small, whether demand access changes the continuous problem as it does in the paper, and whether an explicit representation of each type’s valuation evades the query barrier.

The case AGAINST (opponent, writing after the proponent)

The best case against the mirror is that the hard part of Proposition 4 is the list of black-box valuation functions, not the number of people. In the proposed model, the query bound is in \(m\) and \(\tau\); the number \(K\) of copies of each type disappears. The hidden-partition construction needs \(\tau\) distinct valuation oracles. Cloning each type \(K\) times makes a large market, but adds no oracle information and does not change the welfare gap. The result would therefore say little about whether large population multiplicity changes the computational picture.

That is a novelty concern, though, not a decisive objection under this programme’s standard. A valid mirror can show that continuization preserves hardness, and the proposed reduction appears to do exactly that. With \(\mu_t=q_j=1/\tau\), assigning type \(t\)’s mass to \(A_t\) is feasible and reproduces the high-welfare allocation. In the baseline instance, the optimum is \((1+\epsilon)\epsilon+1/\tau\). Both welfare values are the corresponding finite-market values divided by \(\tau\), so normalization preserves the gap. The type oracles also expose the same hidden information as the paper’s bidder oracles.

A narrower mirror with fixed \(\tau\) and growing \(K\) would avoid making support size the source of hardness, but Proposition 4 would then no longer establish the claimed lower bound. That leaves a separate question about fixed-support markets; it does not invalidate the broader mass model. Nor can I reject this anchor for lacking a computational result: Proposition 4 is explicitly a value-query lower bound, and the proposed mirror uses the same access model.

So the honest negative case is weak. The mirror may offer limited new leverage because it largely normalizes the paper’s oracle problem and its hard instances require growing support. But the transfer is coherent, and a preserved-hardness result is within the programme’s stated scope. I cannot honestly defeat this anchor or support the universal claim that no worthwhile continuous mirror exists.
