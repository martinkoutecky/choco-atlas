The continuous mirror question

Given finitely many voter types \(T\), rational masses \(\mu_t \ge 0\) summing to \(1\), nonnegative rational per-voter weights \(w_t\), and a quota \(q\) with \(0 < q \le V := \sum_{t \in T} \mu_t w_t\), decide whether every yea-mass vector \(x \in \prod_{t \in T}[0,\mu_t]\) with \(\sum_t w_t x_t < q\) has a winning complement, \(\sum_t w_t(\mu_t-x_t) \ge q\).

The model it lives in

Types are voters with the same per-voter weight; type \(t\) has mass \(\mu_t\). The decision variables are yea masses \(x_t \in [0,\mu_t]\); strongness asks whether no feasible \(x\) makes both \(x\) and \(\mu-x\) lose. There is no optimization objective, and the property holds exactly when \(V \ge 2q\).

What the mirror covers

Covers only the IsStrong clause of Theorem 9 for weighted games; it leaves the paper's results on properness, majority, other representations, and unweighted simple games aside.

Open questions for a prover

  • For fixed weight types, characterize when finite electorates with integer type counts have the same strongness answer as the continuous criterion \(V \ge 2q\), including behavior as the counts grow.

The case FOR (proponent)

The strongest mirror I see is Weighted-Strongness\(_\infty\), anchored on the IsStrong clause of Theorem 9, proved in this paper: given a weighted simple game by an integer realization \((q;w)\), deciding whether the game is strong is co-NP-complete. Strong means that every losing coalition has a winning complement.

In the continuous version, types are voters with the same per-person voting weight. An instance gives finitely many types \(T\), rational masses \(\mu_t\ge 0\) summing to \(1\), rational weights \(w_t\ge 0\), and a quota \(q\) with \(0<q\le V\), where \(V=\sum_{t\in T}\mu_t w_t\). A yea coalition is a vector \(x\) with \(0\le x_t\le\mu_t\), where \(x_t\) is the mass of type \(t\) voting yea. It wins exactly when \(\sum_t w_t x_t\ge q\). The question is whether this continuous game is strong: for every losing \(x\), does its complement \(\mu-x\) win? The answer is yes or no; a no-instance has a witness \(x\) for which both sides lose.

This fits a large association or shareholder electorate with many members in a relatively small number of voting-weight classes. A type is a complete description for this question: members with the same voting weight are interchangeable. For a finite electorate of \(n\) voters, with \(n_t\) voters of type \(t\), set \(\mu_t=n_t/n\) and divide the discrete quota by \(n\). The discrete coalitions then correspond to the grid points \(x_t=k_t/n\); the continuous question allows every point in the box \(0\le x_t\le\mu_t\). The voting rule and the definition of strongness carry over directly, while the population becomes divisible.

This mirror is exactly solvable by computing \(V\). It is strong if and only if \(V\ge 2q\): a losing coalition has score \(s<q\), so its complement scores \(V-s>V-q\); if \(V\ge2q\), that is at least \(q\). If \(V<2q\), taking \(x_t=\mu_t/2\) gives each side score \(V/2<q\), witnessing failure. Thus the problem takes \(O(\tau)\) rational arithmetic operations, polynomial in \(\tau\) and the input bit length \(L\). I expect this to be a Class A mirror: the discrete hardness vanishes when a type’s population can be split continuously.

The case for author recognition is that this asks the same property of the same weighted voting rule, with coalitions interpreted as measurable portions of voter types. The scope is deliberately narrow: it mirrors only the strongness result for integer-weighted games in Theorem 9. It does not claim to cover the paper’s arbitrary minimal-winning-coalition games or its representation-conversion results.

The main weakness is that atomless coalitions change the granularity that drives the discrete problem. The paper’s Partition reduction uses indivisible voters; its weights can all be distinct, so the hard instances need not lie in the intended regime where \(n\) is much larger than \(\tau\). For the reduction’s strongness construction, the total weight is \(2s\) and the quota is \(s+1\). The continuous game therefore answers “not strong” for every such instance, while the discrete answer turns on whether a subset sums to \(s\). That makes the mirror a convincing high-multiplicity relaxation, but it does not show that the theorem’s hardness disappears for an electorate with few types.

A natural follow-up is to characterize when discrete strongness agrees with the continuous answer, especially near \(V=2q\), and how quickly agreement emerges as the number of voters in each type grows.

The case AGAINST (opponent, writing after the proponent)

The strongest negative case is that Theorem 9’s hardness reduction uses a separate weight for each Partition item. It does not establish hardness in the high-multiplicity regime with few weight types and many voters per type. So the proposed mirror may shed little light on the source of the paper’s hardness.

But that does not defeat the mirror. A large shareholder electorate with many holders in each voting-weight class is a plausible high-multiplicity setting. For strongness, holders of the same weight are interchangeable, so grouping them into types loses no information the question uses. The continuum model then asks whether every losing portion of the electorate has a winning complement—a direct mass version of the paper’s property.

The proposed question is well-defined and computational, and it anchors to the named result in Theorem 9. Its aggregate criterion, \(V\ge 2q\), makes the answer simple; under the programme’s rules, that is not a reason to dismiss a well-posed mirror. Nor does the discrete reduction’s reliance on distinct weights invalidate the question for a different, sensible instance regime.

I cannot make an honest case that this anchor fails. The negative argument limits how much it says about Theorem 9’s hardness, but the continuous mirror itself survives.
