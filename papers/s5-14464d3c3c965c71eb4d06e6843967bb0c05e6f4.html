Why no mirror

Theorem 3 is computational, but its objects are the items being ranked, and the output is their permutation; the paper supplies no agent population with multiplicity to continuize. The catalog construction puts mass on ranked object classes and uses a shared noisy judgment per class pair, changing both the continuous object and the noise model. No population-continuous version of this result survives that the authors would recognize as their problem.

What the mirror covers

The proposed construction targets Theorem 3's exact-optimizer result; it leaves Theorem 4's proximity guarantee, Theorem 5's sampling bound, and Theorem 16's algorithmic refinement without a population mirror.

The case FOR (proponent)

The strongest anchor is Theorem 3, proved in this paper. It says that for every \(\gamma>0\) and \(\beta>0\), when a complete set of pairwise comparison outcomes is generated independently conditional on a hidden true order, and each comparison favors that order with probability at least \(1/2+\gamma\), there is a randomized algorithm that finds a score-maximizing ranking in time \(n^{O((\beta+1)\gamma^{-4})}\), with failure probability at most \(n^{-\beta}\). This is a high-probability result under the noisy-instance promise, not a worst-case polynomial-time result for arbitrary tournaments. The paper’s cited NP-hardness for unrestricted feedback arc set does not give a comparable named hardness result for its noisy problem.

A credible high-multiplicity setting is a large catalog of listings that fall into a modest number of exact product types. For example, a platform might have millions of listings but only hundreds of product archetypes that matter to the ranking decision. Let a type specify everything relevant to that decision, and let \(\mu_t\) be its fraction of the catalog. A panel compares one representative pair of types once; that type-level judgment is used to rank the corresponding groups. The output is an order of type blocks, with all listings of a type occupying its block. This retains the paper’s one-comparison constraint at the type level, while making the catalog’s scale and the consequences of each ordering decision proportional to mass.

Call the mirror Type-Mass Noisy Sorting. Its instance is a finite support \(T\) of \(\tau\) types, positive binary-rational masses \(\mu_t\) summing to one, and one antisymmetric comparison \(q(t,u)\in\{-1,+1\}\) for each type pair. The promise is that, conditional on a hidden order \(\pi\), these comparisons are independent and each favors \(\pi\) with probability at least \(1/2+\gamma\). A solution is a permutation \(\sigma\) of the support types maximizing

\[ S_{\mu,q}(\sigma) = \sum_{\{t,u\}:\,t\prec_\sigma u} \mu_t\mu_u\,q(t,u), \]

where \(q(t,u)=+1\) means the observed comparison supports \(t\) before \(u\). The product \(\mu_t\mu_u\) is the fraction of cross-type pairs affected by that ordering decision. The prover’s question is whether an algorithm can find an exact maximizer in time \(\tau^{O((\beta+1)\gamma^{-4})}\operatorname{poly}(L)\), with failure probability at most \(\tau^{-\beta}\), where \(L\) is the mass encoding length. Equal masses recover the paper’s noisy sorting objective on the support types, up to a constant factor.

I would initially expect this weighted version to be Class A: the hidden one-dimensional order and the noise margin still offer the structural foothold used by the paper, and the masses give a natural weighted loss. But Theorem 3 does not prove that extension. A useful next question is whether its closeness result, Theorem 4, has an analogue in cumulative-mass rank rather than unit positions, and whether the algorithm’s dependence on very small masses can remain polynomial in \(L\). This mirror covers Theorem 3’s exact-optimizer result; it does not claim to continuize the paper’s sampling-complexity result, Theorem 5.

The weak point is the shared type-pair judgment: the paper’s errors are independent for every pair of individual items, while this mirror applies one noisy observation to all cross-type pairs. That choice keeps the no-resampling optimization problem alive at the type level, but an author or referee could reasonably regard it as a meaningful change to the noise model. If comparisons were instead independently sampled for every pair of catalog listings, the many copies would average the noise within each type pair, changing the computational question.

The case AGAINST (opponent, writing after the proponent)

Theorem 3 is a genuine computational result, so the case against cannot rest on the absence of an anchor. The problem it solves, though, has no society to continuize: its \(n\) counts the items being ordered. The input is one noisy bit for each pair of items, and the output is a permutation of those named items. Their identities and positions are part of the question.

The catalog mirror moves mass onto product archetypes, which are still objects being ranked. If an archetype contains multiple listings, one shared judgment for that archetype pair changes the paper’s noise model; the weight \(\mu_t\mu_u\) makes it the stakes of ordering object classes. If instead each listing pair gets its own noisy judgment, those pair-specific data must be retained to determine the optimal order. A type that preserves them must distinguish the listings, so the supposed multiplicity disappears. Ranking archetype blocks could be a useful separate problem, but its continuous object is the ranked object set, outside ChoCo’s population scope. The same issue blocks the proposed cumulative-mass analogue of Theorem 4: it replaces displacement of individual items with displacement of object classes.

The strongest population-side rescue would make the experts who supply comparisons into agents. In the paper’s no-resampling setup, however, there is only one expert-query per item pair. Preserving which pair was queried makes that address part of the expert’s type, leaving \(\Theta(n^2)\) essentially singleton types. Giving each pair many experts creates repeated observations, while giving experts full rankings creates a different, correlated-vote model. Either may motivate worthwhile research, but neither mirrors Theorem 3’s one-observation-per-pair problem.

So the negative case is strong for a ChoCo mirror: the proposed mass belongs to the alternatives, while a faithful expert population has no meaningful high-multiplicity regime. It is not a proof that no adjacent continuous ranking problem is worthwhile; a broader programme could choose to study one. That would be a new direction rather than a continuous-population mirror of this result.
