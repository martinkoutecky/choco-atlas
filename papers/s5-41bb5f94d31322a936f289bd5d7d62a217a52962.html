The continuous mirror question

Given a finite alternative set \(A\), rational type masses \(\mu_h\), initial preorders \(\pi_h(0)\), quorum fractions \(\alpha_h\), and a symmetric block interaction kernel \(W\) realizable by exact equitable network blow-ups, compute the terminal preorder \(\pi_h^*\) for each type. At each round, type \(h\) forms \(R_h^t\) from comparisons supported by at least \(\alpha_h\) of its neighbors, takes the transitive-reflexive closure \((R_h^t)^+\), and updates by \(\pi_h(t+1)=\pi_h(t)\vee(R_h^t)^+\), where \(q_{hg}=\mu_gW_{hg}/\sum_j\mu_jW_{hj}\) gives the neighbor type proportions.

The model it lives in

A continuous population of types \(h\), each carrying mass \(\mu_h\) and defined by its initial preorder, update rule, quorum fraction, and network role. The state is one integral preorder \(\pi_h(t)\) per type; neighbor support is computed using \(q_{hg}\), and the task is to compute the terminal mass distribution over the resulting preorders.

The case FOR (proponent)

The strongest mirror is narrow: the paper’s inflationary preference dynamics on a large population whose interaction network has a fixed, repeated block structure. A type \(h\) records an agent’s initial preorder, update personality and network role. Its mass \(\mu_h\) is the fraction of the population of that type, with \(\sum_h\mu_h=1\). A credible regime is a large fleet of replicated agents, or a large organization with many repeated roles, where agents within each type use the same preference and update rule and encounter types in stable proportions. Then the number of agents can be far larger than the number \(\tau\) of types.

Here is a concrete problem. The instance has a finite alternative set \(A\), rational masses \(\mu_h\), and a symmetric rational block interaction matrix \(W_{hg}\). For an agent of type \(h\), let \(q_{hg}=\mu_gW_{hg}/\sum_j\mu_jW_{hj}\) be the fraction of its neighborhood drawn from type \(g\). Each type has an initial preorder \(\pi_h(0)\) and a quorum fraction \(\alpha_h\in(0,1]\). At time \(t\), the support for comparison \(a\succeq b\) among type \(h\)’s neighbors is
\[ s_h^t(a,b)=\sum_g q_{hg}\,\mathbf{1}[a\succeq_{\pi_g(t)}b]. \]
Let \(R_h^t\) contain the comparisons with support at least \(\alpha_h\), and let \((R_h^t)^+\) be their transitive-reflexive closure. Update by
\[ \pi_h(t+1)=\pi_h(t)\vee(R_h^t)^+. \]
This is the paper’s truthful-message, quorum-aggregation and join-update model with the natural population-scale change from a neighbor count \(r\) to a quorum fraction \(\alpha_h\). The decision variable is each type’s evolving preorder; mass is conserved, and each unit of mass always holds an integral preorder. There is no optimization objective: given the initial society and update rules, compute the terminal preference distribution \(\mu_h\) on \(\pi_h^*\).

My lead anchor is Theorem 3, proved in this paper. It says that when \(A\) is finite and the update map \(F\) is inflationary, the join of the trajectory \(\pi^*=\bigvee_{t\ge0}\pi(t)\) is a stable profile and the trajectory reaches it in finite time. In the mirror, join updates make the type-level map inflationary too. Each type can add at most \(|A|^2\) comparisons, so the trajectory stabilizes after at most \(\tau|A|^2\) strict rounds. With the stated quorum rule, each round can be computed using rational support sums and transitive closure. Thus I expect this precise problem to be tractable, with running time polynomial in \(|A|,\tau\), and the input bit length. That bound is a consequence for this mirror; Theorem 3 itself does not state a complexity-class result.

The authors should recognize this as their preference-dynamics problem: it keeps their partial preorders, network-mediated messages, consensus thresholds, join revision and equilibrium target. It is not a question about aggregating society into a winner. The high-multiplicity assumption is on the *instance regime*: many replicated agents share the complete attributes the model uses, while the block interaction pattern has few types. The paper has no named NP-hardness, \(P\), or parameterized-complexity theorem to anchor a hardness-dissolution question; Theorem 3’s finite-time convergence is the closest computational anchor.

The mirror covers only Theorem 3’s inflationary setting. It does not cover arbitrary preference dynamics, the paper’s full network heterogeneity, or its simulation results. The main weakness is the block-network assumption: replacing each agent’s neighborhood by stable type proportions can discard topology that matters to the authors’ local dynamics. The scaled quorum is also a model co-modification, though it represents the same threshold-consensus rule as population size grows. The next questions are whether the terminal state remains efficiently computable for non-inflationary updates, and whether richer network limits admit a finite type-level representation. I would leave both open; unlike the stated lead problem, they could introduce genuinely new computational difficulty.

The case AGAINST (opponent, writing after the proponent)

The strongest objection is that Theorem 3 is not a complexity result. It proves finite-time convergence for an inflationary map on a finite lattice, but specifies neither an encoded input problem nor a runtime bound for computing the map or its fixed point. The paper’s Theorems 2 and 3 concern equilibrium structure and convergence. A terminal-state computation problem can be built from them, but it is an added algorithmic question, not a continuous mirror of a stated complexity result.

That distinction matters for the proposed mirror. In the paper, each update depends on an agent’s actual neighborhood. The block model replaces that local graph with a type-level neighborhood distribution \(q_{hg}\). For the replacement to reproduce the original dynamics exactly, agents grouped into a type must have the same update rule, initial preference, and neighborhood counts by type—an equitable partition of the graph. In a general network, including a large fleet or organization, those conditions need not hold. Grouping agents by preference and role alone can erase the local variation that drives their updates; retaining enough network information may instead force \(\tau\) to grow with the number of agents.

There is a stronger version of the mirror: exact equitable blow-ups of a small network, with identical agents in each role and a population-scaled quorum. That can preserve the paper’s dynamics and yield the stated finite-type computation. But it is a carefully restricted quotient model, and its tractability follows directly from the finite preference lattice: at most \(\tau |A|^2\) comparisons can be added. It does not make Theorem 3 a complexity classification, and the paper supplies no complexity result for this quotient problem to continuize.

This is a real negative case, but it does not establish the universal claim. Equitable blow-ups are a coherent high-multiplicity regime, and the resulting terminal-state question is well posed. The case against is strongest on whether that question is a worthwhile ChoCo complexity mirror of this paper, not on whether any recognizable continuous-population version exists.
