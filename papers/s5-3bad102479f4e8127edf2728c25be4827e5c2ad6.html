The case FOR (proponent)

The strongest honest foothold is Theorem 3, proved in this paper: under complete information and assumptions (A1)–(A3), the authors’ finite-agent procedure has unique equilibrium payoffs, and its final allocation is efficient and egalitarian equivalent. Each agent is indifferent between their share and a proportional benchmark of size \(\lambda^*\), the largest benchmark size for which some feasible allocation gives every agent at least the benchmark utility. Theorem 2, also proved here, adds that every equilibrium allocation is proportional.

There is an important limit to that anchor: neither theorem gives a complexity classification or running time, and Theorem 3 is an implementation result, not a theorem that an allocation problem is in P. The paper’s Theorem 1 is an existence result. So under the brief’s strict requirement for a named computational-complexity result, this paper has no qualifying anchor. Theorem 3 is only a possible anchor if “computational” is taken broadly enough to include a procedure that implements an outcome.

The best continuous-population scenario I can make plausible is a large land-restoration or land-trust programme with many claimants but relatively few preference types. A type must include the claimant’s full utility over the relevant parcels and the other information used in the model. The number of claimants could be very large while the number \(\tau\) of distinct types stays small. The per-capita resource supply would need to remain meaningful as population mass grows; that scaling is a necessary co-modification. This is a population mirror: the paper already makes the *good* divisible and heterogeneous, but keeps the set of claimants finite.

A concrete problem would be Type-EE\(_\infty\). The input is a finite set \(T\) of types with rational masses \(\alpha_t>0\), summing to \(1\); a finite common refinement of \(q\) homogeneous parcels; per-capita supplies \(e_j\); and rational utility rates \(a_{tj}\) for type \(t\) on parcel \(j\), normalized so that \(\sum_j a_{tj}e_j=1\). A type’s utility for quantities \(z_{tj}\) is \(U_t=\sum_j a_{tj}z_{tj}\). A feasible type-level allocation has \(z_{tj}\ge 0\) and \(\sum_t\alpha_t z_{tj}\le e_j\) for each parcel \(j\). The task is to find a feasible allocation and benchmark \(\lambda^*\) such that every type gets utility \(\lambda^*\), the allocation is Pareto efficient, and \(\lambda^*\) is the largest common benchmark utility that a feasible allocation can guarantee every type. The output is the allocation and benchmark, not an encoding of them.

For this finite-partition version, I expect the allocation problem to be tractable: the maximin benchmark is a linear optimization problem with \(\tau q\) allocation variables, and a further question is how to select an efficient, equal-utility allocation at the optimum. That gives a possible Class A direction with complexity in \(\tau\), \(q\), and the input bit length. It covers only the allocation-selection content of Theorem 3, not its bidding and acceptance mechanism. Further questions include whether the equal-utility efficient selection always exists for the continuous population, how it relates to the finite problem when \(n_t/n\) approaches \(\alpha_t\), and whether any version of the authors’ strategic procedure has a meaningful atomless-population analogue.

The weak point is substantial: Theorem 3 relies on a finite list of agents, including a divider and sequential choosers. A continuum of agents has no obvious counterpart to those roles, and the paper does not analyze computing its equilibrium. The proposed mirror is most credible as a continuous-population version of its *fair allocation problem*, not as a direct continuization of its mechanism.

The case AGAINST (opponent, writing after the proponent)

The strongest case against a mirror is that the paper supplies no named computational result to mirror. Theorem 1 proves existence, Theorem 2 characterizes equilibrium allocations as proportional, and Theorem 3 proves a subgame-perfect implementation result. None gives an algorithm for a computational problem, a complexity bound, or a hardness result. The paper also assumes arbitrary nonatomic utility measures without giving them a finite input representation. Under ChoCo’s stated gate, there is no qualifying anchor.

Theorem 3 is the best candidate, but its main result concerns a finite-agent game: one agent proposes, the others accept or refuse in sequence, and bids determine the agents’ roles and benchmark weights. In an atomless population, an individual has zero mass, so an individual bid or refusal cannot play those roles. A finite-parcel, rational-utility version of the proponent’s Type-EE problem is a sensible optimization problem, and it can be written as an LP. But it drops the strategic implementation and fixes a finite common partition as input. That is a new computational question about the allocation criterion, not a continuous-population version of a computational result established by this paper. Recovering a strategic analogue would require a new mechanism over types or groups that the paper neither states nor analyzes.

I would not argue that a high-multiplicity population is implausible here: the paper itself cites work on Pazner–Schmeidler rules in large societies, which supports that regime. Nor is the possibility of a tractable LP a reason to dismiss the Type-EE question. The honest weakness in the negative case is that, if ChoCo accepts computational questions extracted from non-computational theorems, that LP is a credible research direction. So the case against is strong only under the programme’s strict requirement for a computational result in the paper; the broader claim that no worthwhile mirror could exist is not established.
