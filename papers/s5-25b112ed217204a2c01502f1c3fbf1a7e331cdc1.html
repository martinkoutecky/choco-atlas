The continuous mirror question

Given rational type masses \(\mu\), a symmetric block-affiliation matrix \(A\), positive rival-value parameters \(b\), and an initial informed-mass vector \(x^0\), determine whether there is a forecast \(F:[0,\mu]\to[0,\mu]\) satisfying the mass versions of Theorem 2’s consistency and incentive conditions with a finite exact semialgebraic description; if so, construct one and return \(F(x^0)\).

The model it lives in

Use a finite set of types with masses \(\mu_t\), symmetric block affiliations \(A_{ts}\), and utilities \(u_t(x)=b_t\sum_s A_{ts}x_s-\sum_s x_s\). A state is the informed-mass vector \(x\); an informed agent may share with any measurable subset of the uninformed population, and the task is to construct a consistent forecast over these states and evaluate it at \(x^0\).

The objection that survived

A finite exact semialgebraic description of a global forecast is an added output requirement, and the case does not establish that such a forecast exists for every rational block instance.

fatal: False

What the mirror covers

The mirror covers Theorem 2’s forecast existence and construction question for homogeneous finite-type block societies; it leaves the paper’s arbitrary network structures, comparative statics, seeding examples, and network-formation results aside.

The case FOR (proponent)

There are no named \(P\), NP-hardness, or parameterized-complexity results in this paper. Its strongest named computational anchor is Theorem 2, proved here: for any finite agent set and any preference profile, at least one forecast exists; moreover, every forecast can be generated by backward induction. The algorithm starts from outcomes where everyone is informed and works backward through the inclusion order. At each outcome, it marks the outcome terminal if every informed agent weakly prefers stopping to every continuation from sharing. Otherwise it chooses an informed agent who can gain by sharing and assigns that agent a favorite forecast continuation. The theorem makes no efficiency claim; the finite procedure may range over an enormous set of outcomes.

My lead mirror is Block Continuum Forecast. Consider a large population divided into \(\tau\) social types, with rational masses \(\mu_t\) summing to \(1\). Members of a type have the same preferences and the same affiliation pattern with every other type. Concretely, take a symmetric matrix \(A\) of type-to-type affiliation weights and a rival-information value parameter \(b_t>0\) for each type. If \(\mathbf{x}\in[0,\boldsymbol{\mu}]\) records the informed mass of each type, an informed type-\(t\) agent’s utility from the eventual informed population is
\[ u_t(\mathbf{x})=b_t\sum_s A_{ts}x_s-\sum_s x_s. \]
This is the paper’s linear altruism and rivalry utility, scaled by population size. Each person still either has the information or does not; fractional values of \(x_t\) describe the share of a large type that is informed. From any state, one informed agent can tell the information to any measurable subset of the remaining population. Recipients accept it, as in the paper.

An instance consists of \(\boldsymbol{\mu}\), \(A\), \(b\), and an initial informed-mass vector \(\mathbf{x}^0\), encoded with binary rationals. The question is to compute a forecast \(F:[0,\boldsymbol{\mu}]\to[0,\boldsymbol{\mu}]\) and the eventual profile \(F(\mathbf{x}^0)\). A forecast must satisfy the paper’s consistency and incentive conditions in mass form: \(F(\mathbf{x})\ge\mathbf{x}\) and \(F(F(\mathbf{x}))=F(\mathbf{x})\); if \(F(\mathbf{x})=\mathbf{x}\), every informed type weakly prefers that outcome to \(F(\mathbf{y})\) for every \(\mathbf{y}\ge\mathbf{x}\); and if \(F(\mathbf{x})\ne\mathbf{x}\), some informed type strictly prefers \(F(\mathbf{x})\) to \(\mathbf{x}\), with \(F(\mathbf{x})\) maximizing that type’s utility among all \(F(\mathbf{y})\) for \(\mathbf{y}\ge\mathbf{x}\). A computational version can require the forecast’s graph to have a finite exact semialgebraic description.

The regime is a large referral or outreach network for scarce opportunities—for example, information about limited paid-study places—organized into a fixed number of roles, localities, or cohorts with shared incentives and reciprocal ties. There may be hundreds of thousands of people but only dozens of such types. A type includes the full preference and affiliation profile relevant to the model, so grouping agents is the high-multiplicity assumption itself. The block network is a real restriction: it says members of a cohort relate to each other and other cohorts in the same way. But it describes a credible regime, and the paper’s central question—who eventually learns rival information when agents anticipate further sharing—is preserved.

This is a population continuization. The continuous state is the distribution of informed mass across types; it is not a continuous outcome or a continuous timeline. Compressing communication trees into mass profiles follows the paper’s set-based preferences: when agents care about who is informed rather than the route by which the information arrived, identities within a type do not affect the forecast. The paper’s altruistic application has exactly this feature. The question extends its finite backward-induction problem to a continuum of possible mass states. It does not claim that the paper has already shown the continuous version is tractable.

For the full forecast-computation problem, I would expect Class C, continuum-specific difficulty: backward induction over a finite set of trees no longer directly applies when states and possible sharing actions range over a continuum. That is a prediction, not a result of this paper. A tractable Class A result for fixed \(\tau\) and affine utilities remains plausible. The mirror also raises questions about whether a forecast exists for every continuous instance, whether the informed-mass outcome is essentially unique, how to encode it exactly, and when discrete clone models converge to it.

The soft spot is the type-block network and its exact homogeneity. An arbitrary sparse social graph may require nearly one type per person, eliminating the population-to-types gap. The seed is also a positive mass profile, rather than necessarily the paper’s single originator. And Theorem 2 is a constructive finite algorithm, not a complexity classification, so it supplies no discrete hardness that the continuous question might dissolve. I would therefore make a focused claim: this is a plausible continuous mirror of the paper’s forecast computation in a meaningful high-multiplicity regime, not a mirror of all its network results.

The case AGAINST (opponent, writing after the proponent)

Theorem 2 is the right anchor to examine, but it is a finite existence and construction theorem, not a complexity result. Its backward induction works because the outcome space is finite and every continuation strictly adds informed agents. The paper gives no input encoding, runtime bound, or canonical forecast-selection rule. So a continuous “compute the forecast” problem needs extra choices: what representation of preferences to accept, whether to return one forecast or all of them, and how to select among forecasts or indifferent outcomes. Requiring a finite semialgebraic description, as the proposed mirror does, adds a restriction with no counterpart in the theorem.

There is a deeper modeling cost. In the paper’s network application, an agent’s type includes their relationships with particular other agents. In a large sparse network, two people with the same degree or local role can still face different informed neighbors. On a cycle, for example, the same informed fraction could be one contiguous group or alternating vertices; those states give agents different incentives. A vector of informed masses by type cannot distinguish them. Grouping exactly by affiliation profile usually leaves nearly one type per person, removing the high-multiplicity regime.

The proposed block model avoids that problem by making each member of a type relate uniformly to every member of every other type. That can preserve strategic effects on a small quotient network, but it describes dense, anonymous blocks, not the sparse and position-dependent trust structures that motivate this paper. A richer continuum model could retain a network kernel and a measurable informed set, but then its state and input are function-valued; the computational question becomes one about encoding and solving that new model. It is no longer a straightforward mirror of Theorem 2’s finite backward induction.

The seed also exposes the gap: the paper’s central example starts with one originator, while the proposed model starts with positive informed mass. A distinguished atomic originator could repair that part, but it would not make mass profiles sufficient for the rest of a sparse network.

So the strongest negative case is that the proposed mirror either compresses away the network configurations that drive the paper’s results or preserves them in a much richer model whose computational input has not been specified. I would not claim that no useful continuous model could be built: a finite-type dense network with a carefully defined forecast query is a plausible new project. That concession is also where the negative case is weakest; the paper’s existing theorem does not itself supply a complexity question, but the repaired block model might still be worth studying on its own.
