Turning those findings into a continuous question about limiting committee quality could be interesting, but it would be a new analytic study, not a continuous version of a computational result in this paper.

The best attempt to make such a mirror faithful runs into the network. Each voter chooses among particular neighbors using edge-specific perceived integrity; the resulting individual-to-individual choices determine cycles and vote flow. A distribution over opinions and intrinsic integrity omits those relationships. Adding each voter’s neighborhood and edge data to their type may preserve the rule, but in a generic network it leaves almost every voter with a distinct type, so the support can grow with the population. Replacing the graph with a block model or interaction kernel restores compression only by changing the neighborhood choices and cycle structure the paper studies. That could motivate a separate continuum network model, but it would not supply the missing complexity anchor.

This is a strong case against a *paper-anchored* mirror, not proof that no useful continuum study is possible in any scenario. A carefully chosen block-network model could have a meaningful population limit. The weakness is that its computational questions would need to be formulated from scratch; none of the paper’s stated results tells us which one to mirror.
