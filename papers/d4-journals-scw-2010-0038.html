The case FOR (proponent)

I can’t make a qualifying positive case from this paper. It has named equilibrium and optimization results, but none asserts an algorithmic or complexity result of the kind required for an anchor.

The closest candidate is Proposition 8, proved in the paper. It partitions the \((y_B,y_A)\) parameter space into four BPR equilibrium regions using three decreasing functions, \(\Phi_A,\Phi,\Phi_B\): the equilibrium is type IIB when \(y_A\leq\Phi_B(y_B)\), type IB between \(\Phi_B\) and \(\Phi\), type IA between \(\Phi\) and \(\Phi_A\), and type IIA when \(y_A\geq\Phi_A(y_B)\). That is a characterization of equilibrium structure, not a result about an algorithm, tractability, or hardness.

There is also a basic mirror problem: the paper already models a continuum of citizens whose incomes follow a distribution \(H\). Recasting its electorate as many agents in a few income types could motivate a new algorithmic study, but it would not make the population continuous in a way that mirrors this paper’s problem—the population is continuous already.

So there is no eligible anchor and no anchor-based continuous problem or predicted complexity class to give. Computing BPR equilibria from a finite representation of \(H\) could be a useful follow-on question, but it would be new computational work on an already-continuous model, not a defensible continuous mirror of a named computational result in this paper.

The case AGAINST (opponent, writing after the proponent)

The proponent’s main conclusion holds: there is no eligible computational result to anchor a mirror on. Proposition 8 partitions the income parameters into four equilibrium regions, but it gives no algorithm, complexity bound, or computational problem. Propositions 2–3 and 5–6 characterize optimal tax schedules through functional optimization programs; Proposition 1 establishes equilibrium existence. Those may be valuable analytic results, but naming them does not make them computational results.

The best rescue would be to formalize an input—say, a rational finite-support income distribution—and ask for an algorithm to classify its BPR equilibrium, compute the schedules, or approximate the threshold curves. But that would computationalize a model whose electorate is already a continuum: the paper uses a distribution \(H\), measures voter support by mass, and imposes the budget constraint by integration. A finite-voter version would be a discretization of that model; the proposed algorithm would be new work on the existing continuous model. Neither is a discrete computational result from this paper awaiting continuization.

Income cohorts could make a plausible high-multiplicity scenario, but that only reinforces that population mass is already central to the paper. It does not supply the missing computational anchor. I would therefore reject this as a ChoCo continuous mirror while being candid about the limit of the negative case: an algorithmic study of these equilibria might be worthwhile in its own right, but that is a different research question.
