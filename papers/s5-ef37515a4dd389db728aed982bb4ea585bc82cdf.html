The continuous mirror question

Given rational type masses \(\mu_t>0\) for \(t\in T\), rational per-capita room supplies \(q_j\ge 0\) for \(j\in J\) with \(\sum_t\mu_t=\sum_j q_j=1\), and each type's strict ranking and cardinal values for room types, run fluid RSD along a common priority coordinate \(u\in[0,1]\): type \(t\) arrives at rate \(\mu_t\) and selects its highest-ranked room type still in supply. If \(y_{sj}(u)\) is the rate at which type \(s\) receives room type \(j\), compute the maximum type-pair envy ratio \(\max_{t,s}\rho_{t,s}\) and a pair attaining it, where \(\rho_{t,s}=\frac{\mu_s^{-1}\int_0^1\sum_j v_{t,j}y_{sj}(u)\,du}{\mu_t^{-1}\int_0^1\sum_j v_{t,j}y_{tj}(u)\,du}\), assuming positive denominators; \(t=s\) refers to distinct members of that type.

The model it lives in

Types \(t\in T\) carry masses \(\mu_t\), and room types \(j\in J\) have per-capita supplies \(q_j\). Along \(u\in[0,1]\), each type arrives at rate \(\mu_t\) and selects its favorite available room type; room depletion determines the allocation rates \(y_{tj}(u)\). Each individual still receives one room, while type averages may be fractional. The objective is the largest expected cross-type envy ratio \(\rho_{t,s}\).

The objection that survived

The theorem measures envy between two agents in the same random run, while the fluid mirror compares type-average allocations and loses their finite-pair priority correlation; the proponent flags this but leaves open whether the authors would view the type-average question as the same fairness problem.

fatal: False

What the mirror covers

The mirror covers the one-round, unit-demand RSD envy-ratio result in Theorem 3.1. It leaves the multi-round results for additive, submodular, XOS, and subadditive valuations unaddressed.

The case FOR (proponent)

The strongest positive case is a fluid high-multiplicity limit of one-round RSD. A large dorm lottery is a plausible regime: thousands of students fall into a modest number of exact preference-and-valuation types, and standardized room categories have supplies that scale with the cohort. Each student still gets one room; the fractional quantities describe how many students and rooms there are of each type.

The paper’s best anchor is Theorem 3.1, proved here: for any house-allocation instance and any two distinct agents \(A,B\), under a uniformly random serial order, \(A\)’s expected value for \(B\)’s item is at most \(\sqrt{2}\) times \(A\)’s expected value for their own item. This is a named guarantee about the performance of RSD. The paper has no named result classifying a problem as being in P, NP-hard, FPT, or similar, so it has no anchor of that kind.

A concrete mirror is Fluid-RSD Envy Evaluation. Its input is a finite set \(T\) of agent types and a finite set \(J\) of room types; rational masses \(\mu_t>0\) with \(\sum_t\mu_t=1\); rational room supplies \(q_j\ge 0\) with \(\sum_jq_j=1\); and each type’s cardinal values and strict ranking of room types. For every ordered pair \(t,s\), the question is to compute the average value a type-\(t\) agent assigns to a type-\(s\) agent’s room, divided by the type-\(t\) agent’s average value for their own room. The solution is the maximum of these ratios and a type pair attaining it.

Define the process by a common priority coordinate \(u\in[0,1]\). Type \(t\) arrives at rate \(\mu_t\); at each \(u\), its infinitesimal arrivals take their highest-ranked room type still in supply. If \(y_{tj}(u)\) is the rate at which type \(t\) takes room type \(j\), supplies evolve as
\[ q'_j(u)=-\sum_{t\in T}y_{tj}(u). \]
The type-pair ratio is
\[ \rho_{t,s}= \frac{\mu_s^{-1}\int_0^1\sum_{j\in J}v_{t,j}y_{sj}(u)\,du} {\mu_t^{-1}\int_0^1\sum_{j\in J}v_{t,j}y_{tj}(u)\,du}. \]
These integrals are averages across a type’s members; they do not give any individual a fractional bundle.

This is the fluid limit of replicated finite instances: type members are interleaved by the random priority order, and as the population grows, each type arrives at rate \(\mu_t\) along the priority coordinate. The evaluation problem is tractable. Simulate the process until a room type runs out, update which room each agent type selects, and repeat. Each such event exhausts a room type, so there are at most \(|J|\) events; with rational input, the resulting averages and ratios can be computed exactly in polynomial time.

In this fluid process the ratio is in fact at most \(1\). At almost every priority position, types \(t\) and \(s\) face the same available rooms. Type \(t\)’s choice maximizes \(t\)’s value among those rooms, so it is worth at least as much to \(t\) as the room type \(s\) chooses at that position. Both types’ per-member averages integrate over the same priority interval. For \(t=s\), two distinct members of that type have the same average, giving ratio \(1\); hence the maximum ratio is exactly \(1\). Theorem 3.1’s \(\sqrt{2}\) bound is consistent with this limit, though the sharper fluid result would need its own proof.

The soft spot is substantial: the paper’s lower-bound example uses two exceptional agents, whose population shares vanish in the limit. The fluid model removes the fine-grained competition between those particular agents that drives the finite-instance envy. The authors may accept this as the high-multiplicity limit of their mechanism, but may object that it changes the object of study from envy between named agents to envy between representative members of positive-mass types. This mirror covers only the one-round, unit-demand RSD result; it makes no claim about the multi-round mechanisms or valuation classes.

The case AGAINST (opponent, writing after the proponent)

The strongest case against is that this paper has no named result about the complexity of a computational problem. Theorem 3.1 proves a worst-case fairness guarantee for a mechanism. It does not ask for an algorithm to compute an allocation, optimize a change to a society, or decide whether a threshold can be reached. Turning it into “given a type distribution, compute its envy ratio” adds a problem the paper did not study; in the proposed one-round fluid model, that computation is just an event-driven simulation of room supplies.

The proposed fluid limit also removes the feature that makes Theorem 3.1 interesting. At each priority position \(u\), every type faces the same remaining room types. If \(j_t(u)\) is type \(t\)’s choice and \(j_s(u)\) is type \(s\)’s choice, then \(v_t(j_t(u))\ge v_t(j_s(u))\). A representative member of either type has a uniform priority position, so their expected utilities are the integrals of those choices over the same \(u\in[0,1]\). Thus the type-pair envy ratio is at most \(1\); for two members of the same type it is \(1\). This is a genuine degeneration of the individual-level phenomenon: in the paper’s finite examples, the two highlighted agents have vanishing population shares, and their effects on each other’s available rooms disappear in the deterministic fluid path.

The best repair—positive-mass types, per-capita room supplies, and envy measured between representative members—still has that same-position comparison. Keeping the finite pair’s interaction would require retaining distinguished agents as atoms whose priority positions affect supply. A finite number of such agents has zero mass in the normalized society model; assigning them positive mass changes the object into a mixed atomic and continuum model.

There is a serious qualification to this negative case. The XOS lower bound in Theorem 5.11 can be lifted to positive-mass cohorts: scale the supplies of \(P\) and \(Q\) with the sizes of the two cohorts, and the envy ratio still approaches \(r\). So continuous high-multiplicity fair-division results are possible in this paper’s setting. That makes a universal claim that no worthwhile continuous mirror exists hard to defend. My narrower conclusion is that the paper’s strongest one-round result is a poor fit for ChoCo’s computational programme: its natural fluid mirror collapses the finite-pair interaction, while the computational task in the proposed mirror is newly introduced and simple. The case is strongest as an objection to this anchor, and weak as a claim against every continuous result one could build from the paper.
