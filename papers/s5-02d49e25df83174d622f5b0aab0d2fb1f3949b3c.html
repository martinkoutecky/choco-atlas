The continuous mirror question

Given finite candidate sites \(C\) in a metric space, voter types \(T\) represented by points \(p_t\), a rational distribution \(\mu\), committee size \(k\), and threshold \(\rho\), does there exist \(S\subseteq C\) with \(\lvert S\rvert=k\) such that \(\min_{t:\mu_t>0}\max_{c\in S} d(p_t,c)\ge\rho\)? The optimization version maximizes this minimum value.

The model it lives in

A high-multiplicity municipal facility-selection model with finitely many complete neighborhood metric profiles \(t\), population masses \(\mu_t\), an integral committee \(S\subseteq C\) of size \(k\), and egalitarian obnoxious value \(\min_{t:\mu_t>0}\max_{c\in S}d(p_t,c)\).

The objection that survived

The masses \(\mu_t\) do not affect the egalitarian minimum, so this mirror cannot support genuinely mass-sensitive quantile or weighted-welfare questions; the proponent acknowledges this limitation but cannot make it disappear.

fatal: False

What the mirror covers

The mirror covers Theorem 2's hardness, approximation-hardness, and parameterized lower bounds, and also Theorem 4's \(\mathbb{R}^2\) hardness; it leaves the paper's algorithmic results and other parameter regimes unclaimed.

Open questions for a prover

  • Classify exact and approximation complexity as functions of the number \(\tau\) of positive-mass types, committee size \(k\), and metric dimension.
  • Determine whether bounded-type compression yields fixed-parameter algorithms despite the support-only dependence on \(\mu\).

The case FOR (proponent)

There is a credible continuous mirror here, and I would lead with a Class B conclusion: continuization gives a natural high-multiplicity version, but the paper’s hardness survives because its combinatorics live in candidate selection and metric geometry rather than in the number of named voters.

The common mirror is this. Let \(C\) be a finite set of candidate sites and let \(k\) be the committee size. A voter type \(t\) is a complete metric profile: a point \(p_t\) together with its distances to every candidate, hence also its “farther is better” ranking. The society is a rational distribution \(\mu\) over finitely many types, with \(\mu_t\) the fraction of residents of type \(t\). For a committee \(S\subseteq C\), define

\[ d_\lambda(t,S) \]

as the \(\lambda\)-th largest distance from \(p_t\) to a candidate in \(S\). The continuous egalitarian value is

\[ \operatorname{val}_\mu(S) = \min_{t:\mu_t>0} d_\lambda(t,S), \]

equivalently the essential infimum under \(\mu\). The decision problem asks whether some \(k\)-element committee satisfies \(\operatorname{val}_\mu(S)\ge \rho\); the optimization problem maximizes \(\operatorname{val}_\mu(S)\). The committee remains integral and the candidate set remains finite: only the population has been continuized.

A plausible regime is municipal facility planning. There may be millions of residents but only \(\tau\) relevant neighborhood or location profiles, with \(N=M\tau\) residents formed by \(M\) repeated cohorts of each type and \(M\gg1\). This is not claiming that every spatial electorate is high-multiplicity; it is a specific regime of standardized neighborhoods, census zones, or repeated residential developments. The type records everything the problem uses, so grouping is legitimate.

My lead anchor is Theorem 4, proved in this paper. It states:

“Obnox-Egal-Median-CS is NP-hard when \(\lambda=k-1\), even in the special case where \(V\cup C\subseteq\mathbb R^2\) and the distances are given by standard Euclidean distances.”

The source problem’s hardness is cited from elsewhere, but the reduction and this theorem are proved here. The corresponding continuous problem is:

\[ \textbf{Continuous Obnoxious-Egal-Median-CS}_{\mathbb R^2}. \]

An instance consists of candidate points \(C\subseteq\mathbb R^2\), voter-type points \(P=\{p_t:t\in T\}\subseteq\mathbb R^2\), rational masses \(\mu_t\), integers \(k\) and \(\lambda=k-1\), and a threshold \(\rho\). The question is whether there exists \(S\subseteq C\), \(|S|=k\), such that

\[ d_{k-1}(p_t,S)\ge \rho \]

for every type with \(\mu_t>0\).

I expect hardness to transfer. Given the paper’s 2-Independent Set reduction, put one voter type and one candidate at each point of the source instance and give every voter type mass \(1/|P|\). Alternatively, make \(M\) copies of each type, yielding an actual population of \(M|P|\) agents while preserving the same normalized society. Every type remains positive-mass, so the continuous feasibility condition is exactly the finite condition used by the reduction. The hard structure lies in which candidates can be jointly selected in the plane; multiplying residents does not remove it. Thus this is a genuine continuous-population question, but it is expected to be Class B rather than tractable.

The second anchor is Theorem 2, also proved in this paper through a reduction from Hitting Set. It states in full that Obnoxious-Egal-CC is NP-hard; for every \(\alpha>1/3\), it has no polynomial-time \(\alpha\)-approximation unless \(\mathrm P=\mathrm{NP}\); and it has no FPT approximation parameterized by \(k\) with approximation guarantee \(\alpha\ge 1/3\), unless \(\mathrm{FPT}=\mathrm{W}[2]\).

The corresponding problem is:

\[ \textbf{Continuous Obnoxious-Egal-CC}. \]

The instance is a finite general metric space containing candidate sites \(C\) and voter-type points \(p_t\), a rational distribution \(\mu\), an integer \(k\), and, for the decision version, a threshold \(\rho\). The task is to choose \(k\) candidates maximizing

\[ \operatorname{val}_\mu(S) = \min_{t:\mu_t>0}\max_{c\in S} d(p_t,c). \]

For the paper’s Hitting Set construction, create one candidate \(c_e\) for each ground element \(e\), one voter type \(t_F\) for each set \(F\), use exactly the paper’s graph metric, and assign every type mass \(1/|\mathcal F|\). A hitting set gives continuous value \(3\); a non-hitting committee leaves some positive-mass type with value at most \(1\). Hence the exact hardness, the \(1/3\) approximation gap, and the parameterized lower bound all survive arbitrary replication of every type. Again, the reduction’s combinatorics live in the selected candidates and the family of constraints, not in population multiplicity.

The paper’s authors should recognize both mirrors as their own problems. Their motivating examples explicitly treat voters as neighborhoods and candidates as facility sites, and \(\lambda=k-1\) is directly connected to requiring almost all selected obnoxious facilities to be far from every neighborhood. The continuous formulation changes neither the “farther is better” preference model nor the integral committee decision. It only replaces a list of named residents by population proportions. The paper’s finite metric model is not already a collision: it gives a finite electorate, whereas the mirror gives a high-multiplicity population object.

The further questions are natural: whether the hardness remains for nonuniform masses with lower bounds on \(\mu_t\); whether the problem becomes FPT in the number \(\tau\) of positive-mass types; and what happens for genuinely mass-sensitive objectives such as maximizing a distance quantile rather than the essential infimum.

The weakest point is that egalitarian objectives ignore the magnitudes of positive masses. In this mirror, \(\mu\) matters through its support, not through weighted averaging. That makes the formulation a faithful high-multiplicity analogue, but it may look less like a new continuous optimization problem than the programme’s LP-based examples. A mass-weighted or quantile version would make continuity algorithmically more substantive, but it would no longer be exactly the paper’s egalitarian problem. The honest positive claim is therefore narrower: this paper supplies a convincing population-continuation question, and its named hardness results predictably survive, locating it on the “continuization stops helping” side of the programme.

The case AGAINST (opponent, writing after the proponent)

The strongest negative case is not that the paper lacks computational results—it has several numbered theorems—but that both proposed mirrors erase the population variable entirely.

For any committee \(S\), write \(f_S(t)=d_\lambda(p_t,S)\). The proposed continuous objective is

\[ F_\mu(S)=\min_{t:\mu_t>0} f_S(t). \]

This depends only on the positive support of \(\mu\), not on its masses. Any two distributions with the same support give exactly the same value for every committee. Replicating a voter type \(10\) times, or \(10^9\) times, is invisible; assigning it mass \(0.99\) rather than \(0.001\) is also invisible. This is not an objection that “continuization does not help.” It is a more basic degeneration: the egalitarian problem contains no population multiplicity for continuization to expose. Its finite instances can already be quotiented by duplicate complete metric profiles without changing the problem.

Thus the proponent’s uniform assignments \(\mu_t=1/|T|\) do not establish a high-multiplicity relaxation. They merely attach irrelevant positive weights to the finite set of constraints already present in the reduction.

This defeats the proposed reading of Theorem 4. The \(2\)-Independent Set reduction can certainly be copied into the support of a distribution, and the hardness may survive. But that only gives a support-preserving restatement of the finite geometric problem. The repeated “neighborhoods” contribute no computational or social content: once two residents have the same complete distance profile, the paper’s least-satisfied objective treats them as one constraint. Calling them a continuum does not create a new population model.

The obvious stronger rescue is to let voter locations themselves range over a region \(\Omega\subseteq\mathbb R^2\), and use

\[ \operatorname*{ess\,inf}_{p\sim\mu} d_\lambda(p,S). \]

That could be an interesting robust facility-location problem, but it is no longer the high-multiplicity version of Theorem 4. It replaces the paper’s finite voter set by an uncountable family of distinct metric profiles and requires a new representation of \(\Omega\) and \(\mu\). The ambient Euclidean continuum—not the population multiplicity of the paper—is now doing the substantive work. The density itself still matters only through its essential support.

The same objection is even sharper for Theorem 2. Its Hitting Set reduction uses a finite graph metric with one voter for each set \(F\). Assigning masses \(\mu_F\) produces

\[ \min_{F:\mu_F>0}\max_{e\in S} d(v_F,c_e), \]

which again depends only on which sets occur, not on how many agents belong to each set. The \(1/3\) gap and the parameterized hardness can be transported, but the transport carries no continuous-population phenomenon. It is simply the original Hitting Set constraint system with positive weights attached.

One could instead ask for a distance threshold satisfied by, say, \(90\%\) of the population, or optimize a distance quantile. That would make \(\mu\) genuinely relevant, but it changes the paper’s egalitarian rule: a small population may now be sacrificed, whereas the paper requires every voter to be protected. Such a quantile or chance-constrained problem could be worthwhile, but it is a new mass-sensitive facility-location problem, not a continuous mirror of either anchored theorem. Setting the quantile to \(100\%\) returns to the support-only degeneration.

The honest limitation of this negative case is that a continuous-density version over a naturally represented geographic region might still be valuable in its own right. The paper’s facility-location motivation makes that plausible. What the two anchors do not establish, however, is a worthwhile continuization of the paper’s computational problems: their proposed mirrors leave \(\mu\) semantically inert, while the genuinely mass-sensitive repairs change the objective.
