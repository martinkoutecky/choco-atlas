The nearest possible mirror would take a type \(t\) to be a complete state-dependent utility function, with \(\mu_t\) the fraction of a large population sharing it. A mechanism would map agents’ messages—or their population proportions—to a lottery in \(\Delta(A)\). The question would be whether the resulting rationalizable outcomes equal \(F(\theta)\) in each state. That is an implementation question, with outcome-set equality as its criterion, not an optimization problem. Theorem 3, proved here, is the closest motivation: with at least three agents, set-monotonicity and SNWA imply full rationalizable implementation.

But that extension is a weak case for a continuous mirror of the paper’s problem. The theorem’s mechanism and proof rely on individually strategic, role-bearing agents. If a person’s message affects only an aggregate and they have zero mass, a unilateral deviation may leave the outcome unchanged, changing the rationalizability question. Keeping agents individually pivotal may require retaining their identities as part of their types, which can erase the small-support regime. So I can identify a possible new implementation question, but I cannot honestly claim it mirrors a named computational result in this paper or predict its place in the continuization trichotomy.

The case AGAINST (opponent, writing after the proponent)

The strongest case against starts with the paper’s actual results. Theorem 1 gives a necessary condition for rationalizable implementation; Theorems 2 and 3 give sufficient conditions; Section 5 gives a finite mechanism for an example. None states a computational problem or its complexity. There is no encoded input, size measure, or algorithmic claim to continue into a complexity landscape. Theorem 3 is the closest candidate, but turning its constructive existence proof into a question about computing mechanisms would add a task the paper does not study.

The best version of the proposed population mirror would give each utility type a mass \(\mu_t\), restrict mechanisms to act on aggregate message distributions, and ask whether a social choice correspondence is fully implementable under rationalizability. That runs into a structural problem: in an atomless population, one agent’s message does not change the aggregate. Every message is therefore a best response at every deletion round. All aggregate message profiles remain rationalizable in every state, so the mechanism generates the same set of outcomes in each state. It cannot implement a state-varying \(F\), as the paper’s results seek to do.

Preserving the paper’s strategic force requires preserving agents whose individual deviations can change outcomes. A finite set of pivotal agents keeps the discrete strategic skeleton; assigning one decisive representative to each positive-mass type makes each type a coordinating bloc. The latter changes the players and the solution concept. Either model might motivate new work, but neither is a high-multiplicity version of the paper’s rationalizable implementation problem.

There is also little for the masses to do in the paper’s conditions. Set-monotonicity and SNWA quantify over agents and their preferences; duplicating a type does not change those tests. A distribution over utility types could affect which types are present, but its weights supply no natural optimization variable or pricing problem. One could add an algorithmic task—such as checking the conditions from finite tables or synthesizing a mechanism—but that would be a new computational wrapper, with population mass playing no meaningful role.

This does not rule out every worthwhile paper on implementation in large populations. It makes the negative case strongest for the claim at issue: this paper offers no named computational result to mirror, and its closest implementation result loses its strategic content under a genuinely atomless population. Any promising rescue needs added structure that shifts the object of study.
