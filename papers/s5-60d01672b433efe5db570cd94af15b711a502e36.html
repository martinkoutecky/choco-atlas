The continuous mirror question

Given an arborescence hypergraph \(H=(T,E)\) on \(\tau\) types, strict preferences \(\succ_t\) over incident contracts, and positive rational masses \(\mu_t\) with \(\sum_{t\in T}\mu_t=1\), find contract masses \(x_e\ge 0\) such that \(\sum_{e\ni t}x_e\le\mu_t\) for every type \(t\), and for every contract \(e\in E\), some \(t\in e\) satisfies \(\sum_{f\ni t,\ f\succeq_t e}x_f=\mu_t\). Is there an algorithm polynomial in \(\tau\), \(|E|\), and the input bit length \(L\) that finds such a stable allocation?

The model it lives in

Types are vertices of an arborescence hypergraph, with rational population mass \(\mu_t\) and a shared strict ranking per type. Each variable \(x_e\) is the mass assigned to a contract requiring one agent of every type in \(e\); type capacities and the blocking condition are defined by the stated inequalities.

What the mirror covers

The mirror covers the polynomial-time stable-matching result for arborescence hypergraphs. It leaves the network-hypergraph pivot structure and the fractional stable-matching polytope result unaddressed.

Open questions for a prover

  • Does the rational-supply stable-allocation problem on arborescence hypergraphs admit a polynomial-time algorithm in \(\tau\), \(|E|\), and \(L\)?
  • Can the separator and first-forward-arc-leaving analysis be extended from unit supplies to arbitrary rational type masses?

The case FOR (proponent)

The strongest mirror is a stable matching problem among large cohorts of interchangeable agents. Let the vertices of an arborescence hypergraph \(H=(T,E)\) be agent types: every agent of type \(t\) has the same feasible contracts and the same strict ranking \(\succ_t\) over them. Each hyperedge \(e\) is a contract requiring one agent from every type in \(e\). For example, a large regional staffing market could have many agents in each qualification category and team contracts whose roles follow paths in a qualification tree. The number of agents \(N\) can be much larger than the number of types \(\tau=|T|\).

Give each type rational mass \(\mu_t>0\), with \(\sum_t\mu_t=1\), and include a singleton option for remaining unmatched. The decision variable \(x_e\ge 0\) is the mass assigned to contract \(e\); each unit of contract mass uses that much mass from every type in \(e\). A continuous stable allocation is a vector \(x\) satisfying \(\sum_{e\ni t}x_e\le\mu_t\) for each type, and, for every feasible contract \(e\), some \(t\in e\) satisfies \(\sum_{f\ni t,\ f\succeq_t e}x_f=\mu_t\). Thus at least one participating type has all its mass in contracts it ranks at least as highly as \(e\), ruling out a positive-mass blocking coalition. The task is to find such an \(x\); there is no optimization objective. The input and output can be encoded with rational masses, rankings, and contract masses, with running time measured in \(\tau\), \(|E|\), and the input bit length \(L\).

My anchor is the paper’s main theorem, proved here. The supplied text prints its statement without a theorem number; later it refers to it as thm:main-arb-poly, so I cannot honestly supply a printed number. Its full claim is that for every hypergraphic preference system whose hypergraph is an arborescence hypergraph, there is a pivoting rule under which Scarf’s algorithm terminates in at most \(|V|\) iterations and outputs an integral stable matching in time \(O(|V||E|)\). The result imposes no degree, hyperedge-size, or preference-list bound. This is the paper’s strongest computational anchor; the cited hardness for general hypergraph stable matching is not a result proved in this paper and does not apply to this restricted family.

The mass formulation preserves the paper’s underlying question: which coalitions form, and does any feasible coalition block? It replaces unit supply per vertex with a population distribution over complete agent types. That supply change is the co-modification needed for a population mirror; real-valued \(x_e\) records mass assigned to discrete contract types. For equal masses \(\mu_t=1/\tau\), scaling all masses by \(\tau\) recovers the paper’s unit-capacity instance at the type level. For unequal masses, the problem is a genuine extension. I expect Class A, as a conjecture: the paper’s tree structure and increasing separator suggest a polynomial method depending on the number of types and contracts, rather than on cohort size. The further questions are whether that method extends to arbitrary rational supplies, and what finite high-multiplicity approximation or rounding guarantees follow.

The weak point is substantial: the paper proves the algorithmic result for unit right-hand sides, and its pivot analysis uses integral \(0\)-\(1\) matching vectors. It does not establish a polynomial algorithm for rational type masses. Extending the separator argument to those supplies—or finding a counterexample—would be the central work of this mirror. The scope here is specifically the paper’s stable-matching algorithm for arborescence hypergraphs.

The case AGAINST (opponent, writing after the proponent)

The paper’s main theorem is a real computational anchor: on arborescence hypergraphs, it gives a polynomial-time Scarf algorithm that outputs a stable matching. The fact that its statement is unnumbered in the supplied text does not weaken it.

My strongest objection is that the proposed mirror changes the instance from unit-capacity agents to types with rational supplies. Its output is a mass allocation among contract types, and its stability condition rules out positive-mass blocking coalitions. That is a coherent problem, but it is a capacitated stable-allocation problem; the paper’s pivot analysis is built around unit supplies and \(0\)-\(1\) matching vectors. So the theorem itself provides little assurance that its algorithmic contribution transfers.

That objection does not defeat the mirror. The programme explicitly allows the supply change that population continuization requires. And if agents of a type are interchangeable in preferences and feasible contracts, their identities need not be preserved: the mass allocation can represent a matching among large cohorts, with no loss relevant to stability. A standardized team-formation market on a tree is a plausible scenario. Fractional contract mass is then the natural type-level description, not a relaxation that obviously erases the question.

I can’t make a stronger case against this anchor without relying on an excluded argument about what the continuous answer or algorithm will be. The continuous problem is well-posed, population-centered, and computational. The honest negative case is weak here; this anchor survives.
