What the mirror covers

Corollary 3 and the main theorem characterize secure implementation; the paper contains no algorithmic or complexity results for a population mirror.

The case FOR (proponent)

The strongest plausible population regime is a large community deciding how much flood protection to provide. Each household’s type is its complete quasi-linear valuation function for the public good, including any preference-relevant exposure or cost parameters. Many households may share one of a small number \(\tau\) of valuation types, even when the population \(N\) is very large. A continuous society is a distribution \(\mu\) over those types. A mechanism maps reported type masses to a provision level \(y\) and per-unit cost shares \(x_t\), with feasibility requiring \(c(y)\leq\sum_t\mu_t x_t\). The natural question is to characterize which such mechanisms are securely implementable. This is a credible *population* mirror of the paper’s public-good economy; its existing divisible outcome does not itself make the society continuous.

The nearest named result is Corollary 3, proved here using the paper’s main theorem and the cited characterization of secure implementation: if a social choice function in the paper’s divisible, non-excludable public-good economy with quasi-linear utilities is securely implementable, then it is dictatorial or constant. Here, dictatorial means some named agent weakly prefers the selected allocation to every allocation selected at every other profile; constant means the allocation is the same at all profiles. This is a useful substantive anchor, but it does not meet the requested anchor rule: it asserts neither a complexity bound nor computational hardness. The paper has no named computational result of the required kind. Its numbered propositions and lemmas establish structural properties of mechanisms and option sets, not algorithmic complexity.

If Corollary 3 were allowed as a provisional, non-computational anchor, one precise extension would be Atomless Secure Public-Good Provision. Its instance is a cost function \(c\), a feasible production set \(Y\), a finite set \(T\) of valuation types, and a population distribution \(\mu\in\Delta(T)\). A direct anonymous mechanism maps each reported distribution \(\hat\mu\) to \(y(\hat\mu)\) and per-unit shares \(x_t(\hat\mu)\), satisfying \(c(y(\hat\mu))\leq\sum_t\hat\mu_t x_t(\hat\mu)\). The question is to characterize mechanisms for which truthful reporting is dominant and every Nash equilibrium produces the same allocation as truthful reporting. Under this atomless formulation, I expect only constant allocations: one agent’s report cannot change \(\hat\mu\); dominant-strategy truthfulness then requires equal shares across reports, leaving every report profile a Nash equilibrium. Secure implementation across all those equilibria forces the allocation to be independent of the reported distribution. That is a continuum-specific degeneracy, rather than a complexity classification in the programme’s tractable / hardness-transfer / continuum-specific-hard trichotomy.

The weakness is that this formulation may not preserve the paper’s strategic problem. In its finite-agent model, a named agent can affect the outcome, and the dictatorial alternative in Corollary 3 relies on that fact. In an atomless population, an individual has zero mass; a type-based anonymous mechanism removes precisely that influence. A finite-replica formulation, where an agent’s report changes mass by \(1/N\), preserves individual incentives better, but then the question is about a sequence of finite economies and not the exact atomless problem above. So there is a plausible public-good population mirror, but the paper supplies no qualifying computational anchor, and the continuous strategic version needs careful justification before it can be presented as the paper’s computational analogue.

The case AGAINST (opponent, writing after the proponent)

Corollary 3 is the proponent’s only anchor, and it is not a computational result: it characterizes securely implementable social choice functions as dictatorial or constant. The paper gives no algorithmic problem, complexity bound, or finite instance representation to mirror. Its theorem quantifies over all profiles of arbitrary strictly increasing, strictly concave valuation functions and over a class of social choice functions. It does not specify an input on which an algorithm could operate. For ChoCo’s computational programme, that is decisive.

A large public-good population with repeated valuation types is a sensible high-multiplicity regime, so the proponent clears the modelling plausibility test. But that does not supply the missing computational question. To make one, we would have to choose a finite representation of valuations, restrict the report domain or the mechanisms, and define what is to be computed—for example, whether a represented mechanism is secure, or how to find one meeting additional goals. Those choices create a new algorithmic problem; Corollary 3 does not identify or constrain its complexity.

The proposed atomless version does not rescue the anchor. If outcomes depend only on the reported distribution, a single agent has measure zero, so unilateral deviations cannot change the outcome. Truthful reporting is then vacuous, and every report distribution can be a Nash equilibrium. Requiring all those equilibria to yield the truthful outcome forces the mechanism to ignore the reported distribution. That is a possible observation about an atomless game, but it comes from removing individual influence and does not mirror the paper’s named-agent incentive conditions. It also gives no computational classification.

A finite-replica version avoids that collapse: each person changes the reported mass by \(1/N\). But it restores individual deviations and makes the model depend on the number of replicas; if anonymity is imposed so histograms suffice, it also changes a theorem whose dictatorial case explicitly depends on named agents. Studying that version could be worthwhile, but it would be a new high-multiplicity mechanism-design project, not a continuous mirror of a computational result in this paper.

So no anchor survives as a ChoCo computational mirror. The honest limit of this negative case is that it cannot establish the literal universal claim that no related algorithmic problem is worth studying. It can establish that this paper offers no named computational result to continuize, and that the proponent’s replacement either leaves computation out or changes the strategic problem.
