The case FOR (proponent)

This paper contains no named computational result in the required sense: no numbered result classifies a problem as tractable or hard, or analyzes an algorithm. The closest anchor is Theorem 3.2, proved here, but it is an existence theorem. So there is no qualifying computational anchor. My best positive case is a narrow computational extension of that theorem, rather than a claim that the paper already does computational complexity.

Theorem 3.2 says: for every \(\varepsilon>0\), there is a replication threshold \(\hat r\) such that, for every \(r>\hat r\), the economy with \(r\) copies of each agent characteristic has a nonempty \(\varepsilon\)-interim core with respect to equilibrium blocking. This is the strongest anchor-like result because its central object is already a large population made from repeated types. The proof constructs incentive-compatible allocations close to statewise Walrasian allocations on likely signal profiles, with ex-post-core allocations elsewhere.

A natural limit model keeps that replication structure. Let \(N\) be the finite set of agent characteristics, \(\Theta\) the state space, and \(T=\prod_i T_i\) the joint signal space. Replace the many finite replicas with an atomless unit mass of infinitesimal replica cohorts, each containing one agent of every characteristic \(i\). Conditional on state \(\theta\), cohort signal profile \(t\) has mass \(\mu^\theta_t=P(t\mid\theta)\). A cohort profile, together with the agents’ characteristics, is the type description; using the full profile preserves the within-cohort signal correlations. Each characteristic then has unit mass, regardless of how many replicas the finite economy has.

The resulting question is Atomless Replica \(\varepsilon\)-Interim-Core Feasibility. Given the finite pre-economy \(E\) and \(\varepsilon>0\), find an incentive-compatible allocation rule \(z_i(\hat t,q)\), assigning a bundle to characteristic \(i\) in a cohort reporting \(\hat t\), when the population distribution of cohort reports is \(q\). Require resource feasibility at every report distribution, truthful reporting to be optimal under the agent’s interim beliefs, and no measurable coalition to have an equilibrium objection that improves every member’s utility by more than \(\varepsilon\). A solution is any such rule; there is no welfare objective, because the anchored result is about nonemptiness. A computational version would also need an explicit encoding for utilities and a finite representation of the rule.

This seems like a mirror the authors could recognize: their model already fixes finitely many characteristics and studies equal replications, and Theorem 3.2 is explicitly about what happens as replication grows. The conditional cohort-profile masses are also a natural continuous description of that sequence. Since the conditional signal distributions differ across states, the limiting profile distribution identifies the state; an individual cohort has zero mass, so its report cannot change that aggregate. The paper’s informational-smallness argument therefore has a clear continuum analogue.

I would tentatively expect the resulting feasibility problem to be Class A, using finite-support aggregation and convex optimization to search for an approximate core allocation. That is a research hypothesis, not a consequence of Theorem 3.2. The key follow-up questions are whether the equilibrium-blocking constraints admit an efficient separation procedure, whether a solution has a polynomial-size representation, and how the result depends on \(\varepsilon\) and the input bit length. Theorem 3.3’s extension to multiplicities \(f(i)=r g_i\) suggests varying the limiting masses by characteristic as well.

The weak point is substantial: the paper proves nonemptiness for sufficiently large *finite* replicas, but gives neither a complexity analysis nor an explicit continuum mechanism. In the continuum, a positive-mass coalition can change the aggregate report distribution, even though an individual cannot; whether the paper’s blocking and communication definitions yield the proposed limit problem is the central technical obstacle. Still, the high-multiplicity regime is unusually well supported here: it is the paper’s own setting, so the mirror is a plausible extension of its problem, even though it cannot be presented as an anchored computational result.

The case AGAINST (opponent, writing after the proponent)

The fatal problem is source eligibility. Theorem 3.2 proves that an \(\varepsilon\)-interim core is nonempty for all sufficiently large replica counts \(r\). It gives no algorithm, complexity bound, finite encoding of an allocation, or effective bound on \(\hat r\). Theorem 3.3, Lemma 3.1, and the corollary are existence results of the same kind. The paper therefore supplies no named computational result to mirror.

The strongest repair would be to ask for an algorithm that constructs an allocation, or to define a feasibility problem for a continuous replica economy. Those could be sensible research questions, but each adds the computational object the paper lacks. The finite version stays on the paper’s replication axis. The continuous version needs a new input and output model, and its feasibility constraints need an encoding the paper never provides.

The proposed cohort construction shows the extra modeling work. The paper’s society is not a fixed distribution of agent types: signal profiles are random under a common, hidden state, with law \(P(t\mid\theta)\). The vectors \(\mu^\theta_t=P(t\mid\theta)\) describe different state-conditioned populations; they do not give agents a single known society distribution. A continuum model could preserve that uncertainty, but it would be a Bayesian continuum economy. Treating each joint signal profile as one cohort type also groups \(n\) people together, while the paper’s agents can participate separately in coalitions and communication. Restoring separate role populations and their joint signal information is possible, but it requires new semantics for reports and blocking.

There is a further limit mismatch. If a rule depends on the aggregate report distribution \(q\), one atomless agent cannot change \(q\), so individual incentive compatibility becomes vacuous. Requiring resistance to positive-mass coalitions can keep a strategic question alive, but it changes the incentive condition and does not follow from Theorem 3.2. Nor does finite support make the proposed problem an LP: the paper uses general quasilinear utilities and equilibrium-blocking constraints, and establishes no compact representation or separation method for them. The suggested Class A route is a hypothesis, not a consequence of the proof.

The replica structure is the proponent’s strongest point: high multiplicity is plainly a sensible regime here. That supports studying a continuous Bayesian-core extension. It does not supply the missing computational anchor. My negative case is strong under ChoCo’s mirror criterion, but weaker as a claim that the extension could never be worthwhile as a separate research project.
