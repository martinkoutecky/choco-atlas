The continuous mirror question

Given resource classes \(J\), rational per-capita supplies \(b_j\), and a support \(T\) of \(\tau\) types with rational masses \(\mu_t\) summing to \(1\), where type \(t\subseteq J\) values an integral bundle \(k\in\mathbb{Z}_{\ge 0}^{J}\) at \(u_t(k)=\sum_{j\in t}v_jk_j\), maximize \(\lambda\) over finite-support masses \(x_{t,k}\ge 0\) satisfying \(\sum_k x_{t,k}=\mu_t\), \(\sum_{t,k}k_jx_{t,k}\le b_j\), and \(x_{t,k}>0\) only if \(u_t(k)\ge\lambda\); what approximation guarantee can be achieved in time polynomial in \(|J|,\tau,L\), and the accuracy parameter?

The model it lives in

A nonatomic population described by rational masses \(\mu_t\) over complete valuation types receives indivisible bundles \(k\in\mathbb{Z}_{\ge 0}^{J}\); decision variables \(x_{t,k}\) divide each type's mass among bundles, resource use is bounded by per-capita supplies \(b_j\), and the objective is to maximize the minimum utility \(\lambda\).

The case FOR (proponent)

The strongest mirror is a continuous version of Restricted Max-Min Fair Allocation, anchored on the paper’s Theorem 1.1, proved here. It states that for every \(\epsilon>0\), there is a combinatorial \((6+2\sqrt{10}+\epsilon)\)-approximation algorithm for Restricted Max-Min Fair Allocation, running in time \(n^{O(1/\epsilon^2\log(1/\epsilon))}\), where \(n\) is the instance size. The paper’s introduction also recounts a cited hardness of approximation below \(2\), but that is not a numbered result of this paper, so I would not use it as an anchor.

Call the mirror Continuous Restricted Max-Min Allocation. Let \(J\) be a finite set of resource classes, with \(v_j\in\mathbb{Q}_{\ge 0}\) the value of one unit of class \(j\). A type \(t\subseteq J\) describes exactly which classes its members value; a member values one unit of \(j\) at \(v_j\) if \(j\in t\), and at zero otherwise. The population is given by rational masses \(\mu_t>0\), summing to \(1\), over a support of \(\tau\) types. Class \(j\) has supply \(b_j\in\mathbb{Q}_{\ge 0}\) per unit of population.

A bundle is an integer vector \(k\in\mathbb{Z}_{\ge 0}^{J}\): each person still receives whole resource units. An allocation is a finite-support collection of masses \(x_{t,k}\ge 0\), where \(x_{t,k}\) is the fraction of the whole population of type \(t\) receiving bundle \(k\). It must satisfy
\[ \sum_k x_{t,k}=\mu_t \quad\text{for every }t, \qquad \sum_{t,k} k_jx_{t,k}\le b_j \quad\text{for every }j. \]
The utility of bundle \(k\) to type \(t\) is \(u_t(k)=\sum_{j\in t}v_jk_j\). The value of an allocation is the greatest \(\lambda\) such that \(x_{t,k}>0\) only when \(u_t(k)\ge\lambda\). The optimization question is to return a feasible allocation and a value at least \(\lambda^*/(6+2\sqrt{10}+\epsilon)\), where \(\lambda^*\) is the best value. The intended running-time parameters are \(|J|,\tau,L,\epsilon\), with \(L\) the bit length of the rational input.

A plausible regime is a large public benefits or services program: residents fall into a modest number of eligibility or need profiles, while the available units in each resource class scale with the population. There may be millions of residents but only a small support of distinct profiles. Each resident receives whole units; the continuous variable says what fraction of a profile receives each integral bundle. This is a high-multiplicity instance regime, not a claim that all allocation settings have one.

I expect the approximation question to be tractable. At a fixed threshold \(\lambda\), it is a Configuration-LP over masses assigned to integral bundles. The paper already uses this LP as a benchmark and says its value can be estimated in polynomial time using approximate separation; its related-work discussion cites a \(4+\epsilon\) estimate for the restricted case. In the mirror, a fractional configuration assignment across identical agents is an actual distribution of people among bundles, rather than a relaxation of named-player integrality. That makes the LP’s role unusually direct. A natural further question is whether one can recover an explicit feasible mass allocation with the same guarantee efficiently, and how its support can be bounded.

The authors should recognize the underlying allocation question: its types are complete valuation descriptions, its objective is still max-min utility, and every person’s bundle remains integral. The continuous change is in how mass of a type is divided among bundles, with resource supplies stated per capita. This covers Theorem 1.1’s restricted problem only; it does not claim a mirror for the general version with arbitrary values or for the paper’s hypergraph discussion.

The soft spot is that Theorem 1.1 constructs an allocation for discrete named players, while this mirror permits a type’s mass to receive different bundles. The paper’s Configuration-LP makes that co-modification credible, but its approximation theorem does not itself prove the proposed continuous allocation guarantee. The case rests on the problem being a sensible continuous population model and on the configuration formulation making that model computationally approachable.

The case AGAINST (opponent, writing after the proponent)

The proposed mirror is unusually plausible, and that is also its weakness: its mass-allocation variables are exactly the Configuration-LP already developed in the paper. Fix a target value \(\lambda\). For each type \(t\), the variables \(x_{t,k}\) assign mass to integral bundles \(k\) with \(u_t(k)\ge\lambda\); the constraints are \(\sum_k x_{t,k}=\mu_t\) and \(\sum_{t,k}k_jx_{t,k}\le b_j\). These are the Configuration-LP’s configuration and resource constraints, aggregated by type and normalized by population. Every feasible mass allocation gives such an LP solution, and every such solution describes a mass allocation. So the LP is the continuous problem itself, not a relaxation of it.

That distinction matters because the LP’s gap is measured against the *finite integral* allocation problem. It does not create a gap between the LP and the proposed continuous model. Section 2 already gives the same object, and says it can be solved to arbitrary accuracy with polynomial-time approximate separation; the paper also cites a \(4+\epsilon\) estimate. This is not an appeal to high-multiplicity work as evidence against the mirror, or merely an observation that its answer is known. The paper already contains the mirror’s mathematical formulation, and its cited computational treatment already addresses that formulation.

The stronger variants do not escape this. Refining types to include all relevant eligibility or valuation data still gives the same configuration formulation. Requiring each finite named person to receive a deterministic bundle restores the original discrete assignment problem; making resource units themselves divisible changes the outcome space. For this anchor, the natural continuous population model is already the paper’s central LP object. That is a substantial case against spending the programme’s effort on this mirror, though it does not prove that every imaginable continuous reformulation of allocation is uninteresting.
