The continuous mirror question

Given a finite type set \(T\), rational masses \(\mu_t>0\) with \(\sum_{t\in T}\mu_t=1\), rational valuations \(v_{t,o}\) for \(m\) resource classes, and variables \(z_{t,o}\ge 0\) satisfying \(\sum_{t\in T}\mu_t z_{t,o}=1\), decide whether there exists an allocation with \(U_t(z)=\sum_o v_{t,o}z_{t,o}\) that is fractionally Pareto-optimal across positive-mass types, proportional \(\bigl(U_t(z)\ge\sum_o v_{t,o}\bigr)\) or envy-free \(\bigl(U_t(z)\ge\sum_o v_{t,o}z_{t',o}\ \text{for all }t,t'\bigr)\), and \(S(z)=\sum_o\bigl(|\{t:\mu_t>0,\ z_{t,o}>0\}|-1\bigr)=0\).

The model it lives in

A high-multiplicity economy with finitely many complete valuation types, population masses \(\mu\), per-capita supplies of standardized resource classes, type-level average allocations \(z\), and an objective \(S(z)\) counting resource classes used by multiple valuation cohorts.

The objection that survived

The opponent's strongest point is that \(S(z)\) is not determined by the original identity-sensitive sharing count: identical type averages can arise from allocations with different numbers of physically shared objects.

fatal: False

What the mirror covers

The mirror covers the zero-sharing existence hardness in Theorem 3.6(b), but not the low-degeneracy algorithm in Theorem 3.6(a), the broader graph-enumeration framework, the CEEI comparison, or the experiments.

Open questions for a prover

  • Does minimizing \(S(z)\), rather than merely testing \(S(z)=0\), remain NP-hard in the two-type regime?
  • Can the low-degeneracy algorithm in Theorem 3.6(a) extend with \(\tau=|T|\) and mass-weighted fairness constraints?
  • What is the precise relation between individual physical sharing and cohort support when resource supplies scale with population?

The case FOR (proponent)

I think there is a defensible mirror, with Theorem 3.6(b) as the lead. It is not the paper’s small-inheritance story verbatim; the credible high-multiplicity regime is a population of many interchangeable claimants divided into a small number of valuation cohorts over a catalogue of standardized resource classes.

Let \(T\) be a fixed finite set of complete valuation types. A type \(t\) has mass \(\mu_t\), with \(\sum_t\mu_t=1\), and values \(v_{t,o}\in\mathbb{Q}\) for each of \(m\) object classes \(o\). The many agents in one cohort have exactly the same valuations; there are no hidden individual prices or preferences. Think of \(N\gg m\) households in two or three standardized claimant classes, with \(N\mu_t\) households of type \(t\), and with the supply of every resource class scaled with population. This is appropriate for recurring asset lots, service slots, or standardized liabilities, rather than one-off heirlooms.

The action is a type-level average allocation \(z=(z_{t,o})\), subject to \(\sum_t\mu_tz_{t,o}=1\) for every object class \(o\). Thus \(z_{t,o}\) is the average amount of class \(o\) received per unit of type-\(t\) population. The normalization makes equal division the allocation \(z_{t,o}=1\) for every \(t,o\), just as an \(n\)-agent finite allocation gives each agent a \(1/n\) fraction of every object before rescaling utilities.

Type \(t\)’s utility is \(U_t(z)=\sum_o v_{t,o}z_{t,o}\). Proportionality requires \(U_t(z)\geq\sum_o v_{t,o}\). Envy-freeness requires \(U_t(z_t)\geq\sum_o v_{t,o}z_{t',o}\) for every pair of types \(t,t'\). Fractional Pareto-optimality means that no feasible allocation weakly improves every positive-mass type and strictly improves at least one of them.

The high-multiplicity version of the paper’s sharing objective is

\[ S(z)=\sum_o\left(\left|\{t:\mu_t>0,\ z_{t,o}>0\}\right|-1\right). \]

An object class is therefore shared when it is used by two or more valuation cohorts. This is the natural aggregate notion when individual identities disappear: sharing creates coordination between cohorts, whereas allocating a whole resource class within one homogeneous cohort does not.

My named anchor is Theorem 3.6(b), proved in this paper. For every fixed number of agents \(n\geq 2\), and arbitrary constants \(C>0\) and \(\alpha>0\), the theorem states that deciding whether there exists a fractionally Pareto-optimal proportional allocation, or a fractionally Pareto-optimal envy-free allocation, with \(\shar{\mathbf z}=0\), is NP-hard for valuation matrices whose degree of degeneracy satisfies \(\D{\mathbf v}\geq C m^\alpha\). The paper proves the result by reducing from Partition; for \(n>2\), dummy agents extend the two-agent construction.

The corresponding continuous question is:

Continuous Cohort FPO Zero-Sharing. Given rational masses \(\mu\), rational type valuations \(v_{t,o}\), and \(m\) resource classes, does there exist a feasible type-level allocation \(z\) satisfying fractional Pareto-optimality, proportionality or envy-freeness, and \(S(z)=0\)?

This is a genuine population mirror. It does not continuize the outcome space in place of the population: the population is represented by the measure \(\mu\), and the allocation is an aggregate decision over that population. The original paper already permits fractional object allocations, but it has finitely many named agents. Here the agents are replaced by a distribution over repeated types, and all fairness and efficiency conditions are imposed on the resulting type bundles.

The most persuasive regime has just two types, \(T=\{A,B\}\), each of mass \(1/2\), with \(N\) arbitrarily large. The types are genuinely distinct, so this avoids the collapse that would occur if one simply duplicated identical agents and then grouped them into one complete type.

The reduction in Theorem 3.6(b) transfers directly. There are \(p\) “big” objects with \(v_{A,o}=v_{B,o}=a_o\), and small paired objects \(q_k,\bar q_k\) with the paper’s values

\[ v_{A,q_k}=v_{B,\bar q_k}=\frac{k+1}{4mk}, \qquad v_{A,\bar q_k}=v_{B,q_k}=\frac{1}{4mk}. \]

For a zero-sharing allocation, each object class is assigned wholly to \(A\) or wholly to \(B\). Since the two masses are \(1/2\), the receiving cohort has \(z_{t,o}=2\) and the other has \(z_{t',o}=0\). Fractional Pareto-optimality forces every \(q_k\) to \(A\) and every \(\bar q_k\) to \(B\), while the big objects can be divided between the two cohorts. The small-object contribution is deliberately less than the unit gap between possible sums of the integer \(a_i\). Consequently, proportionality—or envy-freeness, which is equivalent here—holds exactly when the big objects assigned to \(A\) have total value \(\frac12\sum_i a_i\). Thus a zero-sharing continuous allocation exists exactly when the Partition instance is positive.

The expected classification is therefore Class B: hardness transfers. The combinatorics live in the \(m\) object classes and in the zero-sharing support restriction, not in the number of individual agents. Replacing \(N\) named agents by two large homogeneous cohorts compresses the population, but it does not fractionalize the assignment of an object class once \(S(z)=0\) is required. This is precisely the kind of hardness the continuization programme predicts should survive.

I deliberately would not use Theorem 3.2 as the main anchor. Its two-agent identical-valuation reduction is Partition, but in a complete-type model the two agents become one valuation type, so that construction risks collapsing into a trivial one-type population. Theorem 3.6(b) is stronger for the mirror because its small objects make the two cohorts genuinely different while preserving the Partition encoding.

This mirror covers only the paper’s zero-sharing existence problem, not its whole algorithmic framework, CEEI comparison, or experimental section. It also suggests further questions: whether minimizing \(S(z)\), rather than merely testing \(S(z)=0\), remains NP-hard; whether the paper’s low-degeneracy algorithm in Theorem 3.6(a) extends with the number of types \(\tau\) replacing the number of agents; and whether approximation or bounded sharing admits a high-multiplicity transfer theorem.

The weakest point is the interpretation of “sharing.” In the paper, a unique physical object shared by several same-type individuals counts as shared; in the mirror, the object class is unshared if all its scaled supply goes to one cohort. That is a real co-modification, justified only for repeated or population-scaled resources. If the intended application insists on a fixed finite collection of unique objects and counts sharing at individual rather than cohort level, a continuum population has no useful fair limit: each object becomes negligible relative to the population. I therefore regard the cohort-sharing version as the honest mirror, but not as a universal replacement for the paper’s inheritance interpretation.

There is also a textual issue in the anchor: Theorem 3.6(b) is printed with \(\D{\mathbf v}\geq C m^\alpha\), while the displayed construction chooses \(m\) so that \(p-1=\D{\mathbf v}\leq C m^\alpha\). The intended polynomial-degeneracy hardness boundary is clear, and the constants can likely be tuned, but the inequality should be repaired before treating the theorem as formally airtight.

The case AGAINST (opponent, writing after the proponent)

The proponent’s anchor is the strongest available one, but its central identification is wrong: \(S(z)\) is not the high-multiplicity limit of the paper’s sharing objective.

In the paper,
\[ \shar z=\sum_o\bigl(|\{i:z_{i,o}>0\}|-1\bigr) \]
depends on the identities of the recipients. A type distribution and type-level averages do not determine it. For example, \(N\) identical agents may receive one object by giving it entirely to one agent, or by giving each agent a \(1/N\) share. Both allocations have the same type-level average, but the first has zero sharings and the second has one shared object. The same loss of information affects envy-freeness: the type-level model can report no envy among one type even when one individual receives everything and the others receive nothing.

Thus there is a fundamental dichotomy. If allocations are constant within each valuation type, then individual sharing disappears: every positive type bundle represents sharing among all members of that type, while the model counts only sharing between types. If allocations may vary within a type, the finite vector \(z\) no longer records either fairness or the objective. Refining the type space by individual bundles or identities restores that information only by abandoning the fixed finite high-multiplicity representation.

The proposed quantity
\[ S(z)=\sum_o\left(|\{t:\mu_t>0,\ z_{t,o}>0\}|-1\right) \]
is mathematically coherent, but it is a new objective: “sharing between valuation cohorts.” It declares an object class unshared when many same-type individuals jointly consume it, and shared when two cohorts receive separate copies of it. That is not the paper’s concern with the number of physical objects allocated to multiple agents. Scaling supplies with population does not repair this; it changes the objects into resource classes and replaces physical sharing by cross-cohort use.

The Partition construction therefore proves only that this new cohort-support problem can encode the original two-agent problem. With \(\mu_A=\mu_B=1/2\), the population mass can be absorbed by rescaling allocations, and the number of claimants never enters the instance. The result is a weighted two-cohort reformulation, not a continuous relaxation of the paper’s identity-sensitive sharing problem. This is a modelling failure, not an objection that the answer is merely unchanged.

The best repair is to retain individual-level allocations while scaling supplies. But then, for a genuine continuum, an object consumed by any positive set of agents has infinitely many recipients, so the original cardinality objective becomes infinite or collapses to counting all used objects as shared. Replacing cardinality by recipient mass or by the number of supporting types brings us back to a different objective.

There is also a formal weakness in the proposed citation: the displayed reduction establishes \(D(\mathbf v)=p-1\leq C m^\alpha\), whereas the theorem is stated with \(D(\mathbf v)\geq C m^\alpha\). This can likely be repaired by choosing \(m\) differently, so it is not the main objection.

My negative case is therefore strong against a mirror of the paper as written, because its key objective is identity-dependent and has no canonical population limit. It is not airtight against an explicitly new research problem about minimizing cross-cohort resource sharing. If the programme accepts that co-modification as the authors’ problem, Theorem 3.6(b) survives as a legitimate, though essentially two-cohort, Class B mirror.
