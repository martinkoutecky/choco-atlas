The case FOR (proponent)

This paper contains no named computational-complexity result of the required kind, so it gives me no valid hardness or tractability anchor. Theorem 1, proved here, says that for every finite multiple-source problem the folk allocation defined by the Shapley value of the irreducible game, the obligation rule, the partition rule, and the cone-wise decomposition is the same allocation. Theorem 2, also proved here, characterizes the folk rule using either IIT, CA, CS, SYM, and ETSC, or IIT, CA, SEP, SYM, and ETSC. Both are mathematical or axiomatic results, not results that a computational problem is in P, hard, or parameterized-tractable. The paper’s statement that Kruskal’s algorithm computes a minimum tree in polynomial time is unnumbered background, not an eligible anchor.

The strongest positive construction I can offer is therefore a shadow of a mirror, rather than a case anchored to a qualifying result. Call it *Continuum Folk Cost Allocation*. Imagine a very large service population divided among a small number \(\tau\) of customer cohorts—for example, users attached to a small set of shared network sites. Members of a cohort have the same service requirements, network attachment point, and connection costs. Let \(T\) be the cohort types, \(M\) the sources, and \(\mu_t>0\) the fraction of the population in type \(t\), with \(\sum_{t\in T}\mu_t=1\). The instance gives a nonnegative symmetric rational connection cost \(c_{uv}\) for each pair in \(T\cup M\). The task is to return a minimum-cost tree connecting all types to all sources and an aggregate cost share \(a_t\) for each type.

One precise continuum folk allocation is obtained by running Kruskal’s algorithm on the type-and-source graph and charging each selected edge as follows. When two source-containing components join, add \(\mu_t c_{uv}\) to every type’s share. When a source-free component \(A\) joins a source-containing one, add \(\frac{\mu_t}{\mu(A)}c_{uv}\) to each \(t\in A\), where \(\mu(A)=\sum_{t\in A}\mu_t\). When two source-free components \(A,B\) join, add \(\frac{\mu_t\mu(B)}{\mu(A)(\mu(A)+\mu(B))}c_{uv}\) to each \(t\in A\), and the symmetric amount with \(A,B\) reversed to each \(t\in B\). The returned shares sum to the tree cost. With rational input and a fixed tie-breaking order, this is computable in polynomial time in \(\tau+|M|\) and the input bit length, by Kruskal’s algorithm and rational arithmetic. The corresponding extension of Theorem 1 would ask whether mass-based versions of the four constructions still agree.

This regime is plausible where many customers share a small set of network attachment points, and mass is the natural measure of how much of society bears a cost. Its expected direction is Class A: the support graph is finite, and the tree and shares are directly computable. But it supplies little of the programme’s central prize: the finite minimum-tree problem is already polynomial, so there is no discrete hardness here to dissolve.

The weak point is substantial. The paper’s cost matrix describes links between individual agents. Agents with identical cost profiles do not automatically collapse into one type-node without changing the minimum-tree problem or its allocation. Treating a cohort as a shared attachment point makes the scenario more credible, but it is a co-modification that the authors might reject as changing their model. And the four-way equivalence itself is an axiomatic and mathematical result; simply continuizing it would not make it a computational-complexity result. So the honest conclusion is that a population-continuous version of this cost-allocation problem is imaginable, but this paper offers no qualifying named computational result to anchor it.

The case AGAINST (opponent, writing after the proponent)

The strongest objection is that this paper has no named computational result for ChoCo to mirror. Theorem 1 proves that four definitions of the folk allocation coincide; Theorem 2 characterizes that allocation axiomatically. Neither gives a complexity result for computing a solution. The closest candidate is the paper’s background statement that Kruskal’s algorithm computes a minimum tree in polynomial time. That is not a numbered result, and it concerns the standard finite graph problem rather than a computational question the paper investigates.

The best repair to the proposed mirror is a population of customers at shared network attachment points. Give each attachment type mass \(\mu_t\), use the attachment points and sources as graph nodes, and replace group cardinalities in the cost-sharing formulas by their total mass. That is a coherent model. But collapsing customers into type nodes requires the shared-point structure—identical cost profiles alone do not make their vertices interchangeable in the paper’s tree problem. And even granting that structure, Kruskal runs on the finite support graph: the masses change how the tree’s costs are divided, not which tree is selected. Extending the four-way equivalence would be a new measure-based cost-sharing theorem, not a computational-complexity result from this paper.

That extension might interest researchers in network cost allocation. Its fit with ChoCo is weak: the paper’s contribution is axiomatic, while ChoCo’s target is the computational landscape that appears when the population becomes continuous. The paper gives no hard or tractable computational result in that landscape to chart.

The negative case is strongest as a verdict on this paper’s fit with the programme, not as proof that no plausible continuum model exists. The shared-attachment scenario is plausible, and the mass-based allocation is worth studying on its own terms. But it does not turn this paper’s results into the kind of computational mirror the programme is seeking.
