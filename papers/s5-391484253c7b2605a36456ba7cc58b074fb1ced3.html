The continuous mirror question

Given a candidate set \(A\), a finite support \(T\subseteq 2^A\) of ideal boards with positive rational masses \(\mu_t\) summing to \(1\), a threshold \(\sigma\), an explicit finite proposal set \(Q\) containing the type peaks and current public proposals, and status quo \(s=\varnothing\), let \(u_t(c)=d(t,s)-d(t,c)\). For each distinct \(p,q\in Q\), form at most two canonical Hamming midpoints using a fixed ordering of \(A\). Define \(\Phi^\mu_\sigma(c)=\sup\{z:\sum_{t:u_t(c)\ge z}\mu_t\ge\sigma\}\). Find a generated midpoint \(c^*\) of maximum \(\Phi^\mu_\sigma\), and return it if its score exceeds \(\max_{x\in Q}\Phi^\mu_\sigma(x)\); otherwise return \(\bot\).

The model it lives in

A board-selection round in a large cooperative whose complete voter types are ideal boards \(t\in T\), represented by masses \(\mu_t\). The proposal slate \(Q\) is explicit and finite; the decision is which canonical pairwise midpoint, if any, to add, maximizing the population generalised-median utility \(\Phi^\mu_\sigma\) subject to strict improvement over the current slate.

What the mirror covers

The mirror covers the Heuristic P complexity proposition for board selection. It leaves the full proposal protocol, the other application settings, and the compromise-gap results aside.

Open questions for a prover

  • Can a realistic board-governance protocol keep the proposal-slate size \(q=|Q|\) bounded by the number of types \(\tau=|T|\), so the runtime remains independent of total membership?

The case FOR (proponent)

The strongest positive case I can make is narrow: the paper’s Appendix J has a named Proposition, “Complexity of Heuristic P.” The supplied text prints no proposition number, so I can’t give one without inventing it. The proposition states that, given a round’s proposal set \(P^r\), status quo, and scoring rule \(\phi\), Heuristic P generates a bounded set \(C(p,q)\) for each distinct pair of proposals, finds the candidate with maximum \(\phi\)-score, and returns it only if its score exceeds the best score already in \(P^r\); otherwise it returns \(\bot\). Its runtime is \(O(|P^r|^2(T_c+n))\), where \(T_c\) bounds the cost of generating candidates for a pair. The paper gives \(T_c=O(|A|)\) for subsets under symmetric difference and concludes that Heuristic P is polynomial in every application setting. This is an in-paper result, not an externally cited complexity claim; the supplied text does not include its proof. The paper also reports cited hardness results for \(L_p\) aggregation, including Kemeny ranking, but presents them as comparisons rather than numbered formal results, so I would not use them as anchors here.

A faithful population regime is a large cooperative or federated association selecting a board from eligible members. Many members may share the same ideal board, giving \(N\) members but only \(\tau\) distinct preference types, with \(\tau\ll N\). A type \(t\) is an ideal board, and \(\mu_t\) is its fraction of the membership. The board space stays \(X=2^A\), with the paper’s symmetric-difference metric and status quo \(s=\varnothing\); only the society becomes continuous. This fits the paper’s board-election application and its public-proposal channel, which can carry deliberated or mediated proposals.

Here is a precise one-round mirror. The input is a finite support \(T\subseteq 2^A\), binary-rational masses \(\mu_t>0\) summing to \(1\), a rational threshold \(\sigma\), and an explicit finite current proposal set \(Q\) containing the type peaks and any current public proposals. For \(x\in 2^A\), define \(u_t(x)=d(t,s)-d(t,x)\) and the population generalised-median score
\[ \Phi^\mu_\sigma(x)=\sup\left\{z:\sum_{t:u_t(x)\ge z}\mu_t\ge\sigma\right\}. \]
This is the weighted order statistic corresponding to the paper’s \(\lceil\sigma n\rceil\)-th largest utility; \(\Phi^\mu_\sigma(x)>0\) exactly when at least \(\sigma\) of the society strictly prefers \(x\) to the status quo. For each distinct \(p,q\in Q\), form at most two canonical Hamming midpoints along a shortest path from \(p\) to \(q\), with ties resolved by a fixed ordering of \(A\). The problem is to find the midpoint \(c^*\) with maximum \(\Phi^\mu_\sigma\), and return it if it strictly improves on the best score in \(Q\); otherwise return \(\bot\). If the result enters the full proposal protocol, its ordinary support, proposer-preference, novelty, and round-improvement checks also apply.

This is a sensible high-multiplicity instance for the paper’s authors: it preserves their board metric, status quo, thresholded generalised-median objective, and pairwise proposal-generation idea. When \(\mu_t=n_t/n\), the weighted score and support test recover the finite profile’s order statistic and supermajority rule. If \(Q\) has size \(q\), each pair yields a constant number of candidates, and each candidate’s score can be computed from the \(\tau\) type utilities in time polynomial in \(\tau\), \(|A|\), and the mass bit length \(L\). The resulting problem is therefore tractable in \((q,\tau,|A|,L)\); in the intended regime \(q=O(\tau)\), its cost is independent of the much larger \(N\). I expect Class A, through direct weighted evaluation of a polynomial-size candidate set. Further questions include how this one-round bound composes across epochs, and whether useful guarantees relate the pairwise candidates to the unrestricted best board.

The mirror covers only the paper’s Heuristic P complexity proposition in the board-selection setting. Its weakest point is the bounded proposal pool: if members submit many distinct proposals, \(q\) may grow with \(N\), and the type compression alone no longer yields a population-independent runtime. The paper’s proposition itself is also a one-round search over generated candidates; it does not establish tractability of unrestricted board aggregation. The positive case is consequently modest, but it rests on a formal computational result and a mass-based version whose input and output are explicit.

The case AGAINST (opponent, writing after the proponent)

The sole anchor is Appendix J’s Proposition “Complexity of Heuristic P.” It is a named computational result, so the case against it cannot rest on a lack of results. The \(L_p\)-aggregation hardness claims are comparisons in the paper, not additional anchors.

The strongest mirror is a large cooperative choosing a board from a fixed slate, with voters grouped by their ideal boards. Give each type a rational mass, retain the symmetric-difference metric and status quo, and run Heuristic P on a finite proposal set \(Q\). This is a credible high-multiplicity regime, and the weighted generalised median has the expected interpretation. So the model itself is hard to dismiss.

The skeptical case is about what the result studies. Heuristic P searches pairwise combinations of an already finite proposal pool. The population distribution only scores those candidates. If \(|Q|=O(\tau)\), the continuous version follows by enumerating \(O(|Q|^2)\) candidates and evaluating each weighted order statistic over \(\tau\) types. That is a direct compression of the voter list, with no new optimization problem or complexity boundary. If distinct public proposals remain available to all \(N\) members, \(|Q|\) can still grow with \(N\), even when everyone has the same ideal board; then the population compression does not bound the running time. Restricting proposals to a finite pool, such as one delegate proposal per type, makes the algorithm clean, but narrows the mirror to a subroutine of the paper’s protocol. Enumerating every possible Hamming midpoint instead could introduce exponentially many candidates, which would change the question rather than strengthen this anchor.

This makes the anchor look modest as a contribution to a programme about the computational landscape of continuous societies. Still, the objection attacks its scale, not its legitimacy. The fixed-slate cooperative is plausible, and a tractable high-multiplicity result can be worth recording even when the algorithm is immediate. Under the programme’s stated standard, I cannot honestly claim that this anchor has been defeated decisively; the negative case is weak here.
