The case AGAINST (opponent, writing after the proponent)

The strongest case against a ChoCo mirror is that the paper has no computational result to continuize. Theorem 5.1 characterizes a value by axioms; Theorem 5.4 identifies it with McQuillin’s value; Lemma 4.4 proves an algebraic basis result. None studies an algorithm, a complexity class, or a computational task. That absence is decisive for this programme’s purpose.

The supplier consortium is a plausible high multiplicity setting, and the proponent’s proposed type payoff rate could be made coherent. One could represent coalitions by type masses and replace the effect of moving a single agent with a directional derivative. But that produces a continuous value theory: it asks how to define or characterize an allocation, not how the complexity of a computational problem changes when the population becomes continuous. A computational version would need an additional task and a finite representation of the externality function. The paper supplies neither. With the full partition function listed explicitly, the McQuillin value can be computed by the ordinary Shapley sum in time polynomial in that table’s size; with a succinct representation, the complexity depends on a representation the paper never chooses.

Theorem 5.4 is the closest candidate for a “turns out” result, but it equates two values on the same finite-agent model. It does not show that a discrete stochastic model converges to a continuous one, or that finite and mass-based formulations coincide. A continuous analogue would require defining both steady marginality and the comparison value for infinitesimal transfers. If those definitions yield an identity, that is still an axiomatic identity, not a computational result. The basis lemma has the same problem: a continuous function-space analogue would be algebraic, and the paper gives no computational question for it to answer.

So the paper can motivate a new continuous cooperative-game project, perhaps one with computational questions added later. The honest weakness in the negative case is that no one can rule out such a project being worthwhile in its own right. But making it a computational project requires choices about tasks and input representations that are absent here. That is a new programme inspired by the paper, not a worthwhile continuous mirror of one of its results.
