What the mirror covers

The candidate mirror covers only Corollary 9's conversion from extended BC to permissive GCC protocols; it leaves the reverse conversion and the other results untouched.

The case FOR (proponent)

The best anchor is Corollary 9, proved in this paper. It says that, under the more permissive interpretation of GCC protocols—where a piece may contain earlier cuts—every extended BC protocol can be converted in polynomial time to a strongly envy-equivalent GCC protocol. Strong envy-equivalence means that each agent can guarantee the same simultaneous envy bounds toward any chosen set of other agents in either protocol. This is a result about converting protocols, not about computing an allocation. The paper gives no named hardness result, so the honest positive case is about extending a tractable conversion result, not asking whether discrete hardness disappears.

A concrete mirror would be Mass-BC-to-GCC Conversion. Take a finite set \(T\) of valuation types, with rational masses \(\mu_t>0\) summing to \(1\). Each type has a normalized piecewise-constant valuation density \(v_t\); type also includes any role or eligibility relevant to the protocol. The population could be, for example, a large group of residents with \(100{,}000\) households but only \(20\) distinct valuation-and-role types. For this scenario, each cohort has an authorized delegate who makes its type’s common cut and branch choices.

The input is that population description and a finite extended BC tree whose action nodes are controlled by types. At a leaf, cake is allocated by type-level share densities \(f_t(x)\in[0,1]\), with \(\sum_{t\in T}\mu_t f_t(x)=1\): members of a type receive the same fractional, per-capita bundle, while the mass-weighted allocation uses the cake once. A type \(t\)’s envy toward type \(u\) is
\[ \max\left\{\int_0^1 v_t(x)\bigl(f_u(x)-f_t(x)\bigr)\,dx,\ 0\right\}. \]
The question is: given this input, construct an extended GCC tree with the same mass-allocation semantics such that, for every type \(t\), every subset \(S\subseteq T\setminus\{t\}\), and every collection of bounds \(M_u\), the cohort \(t\) can guarantee all bounds simultaneously in the BC protocol exactly when it can in the GCC protocol. The returned GCC tree is the solution. Its expected classification is tractable: polynomial time in the tree size, \(|T|\), and the rational input length. The mass representation makes the population continuous; the conversion itself is structural, as in the corollary. The paper’s cuts-before-choices normalization in Theorem 4 is part of the conversion route, not a separate anchor here.

This is my lead because it takes the paper’s central model-equivalence result and gives its guarantee a population-level interpretation. It covers the conversion from extended BC to the permissive GCC model, not the reverse direction or every claim about BC and GCC. It also generates useful follow-up questions: can the reverse conversion be made polynomial under the same semantics? Can one compute type-level envy guarantees efficiently? What happens if members of a cohort may choose different branches rather than act through a common delegate?

The weak point is substantial: Corollary 9’s algorithm does not use the masses, and the paper’s agents act individually. The delegate assumption and fractional type-level bundles are co-modifications, so an author might accept this as a useful extension of their protocol question—or say the continuum is attached to a problem that remains finite and structural. The case survives only as a modest one: it offers a precise, plausible population version of a result the paper actually proves in polynomial time, while conceding that it is not evidence of a new complexity landscape for cake cutting.

The case AGAINST (opponent, writing after the proponent)

Corollary 9 is a real algorithmic result, so I would not dismiss it as merely axiomatic: an extended BC protocol can be converted to an envy-equivalent GCC protocol in polynomial time. But the algorithm’s input is a protocol tree, and its work is on that tree. It does not take a society as input or use population masses. Adding rational masses to the input leaves the conversion unchanged.

The more fundamental problem is that agents’ roles are part of this protocol model. Nodes name the agent who cuts or chooses; leaves assign pieces to named agents; and strong envy-equivalence compares what each named agent can guarantee against selected other agents. A type complete for this problem must include those roles and allocation positions, as well as valuation. In general, that makes agents distinct types even when many share a valuation. Keeping those distinctions preserves the theorem, but gives no high-multiplicity compression.

The proposed cohort version removes those distinctions by appointing one delegate per type and comparing a type’s envy against other types’ average bundles. That may define a coherent new model, but it changes the strategic actors and the guarantee being preserved. Individual members can choose differently, and can receive different pieces; a type-average bundle cannot recover their individual envy guarantees. Giving a cohort one common fractional bundle changes the leaf semantics too. Those are permissible co-modifications in principle, but here they are what create the new problem.

The strongest version of this mirror would formalize precisely that cohort game, with mass-weighted feasibility and fractional per-capita allocations, then ask for BC-to-GCC conversion preserving type-level guarantees. It is well-posed, but the conversion would still be the paper’s structural translation with cohort labels carried along; the masses do not drive its algorithm or its difficulty. If one instead asks for guarantees while preserving members’ separate actions and allocations, the identities return and the mass representation no longer compresses the problem. I see no version that both retains the paper’s question and makes the population continuum computationally consequential.

That is a strong case against this anchor as a ChoCo mirror, not a proof that no continuous cake-protocol model could ever be worthwhile. Its weak point is the universal claim: authors who want to study delegated cohorts and fractional type-level fairness might reasonably regard that as their problem, though it would be a new protocol semantics rather than a population version of Corollary 9.
