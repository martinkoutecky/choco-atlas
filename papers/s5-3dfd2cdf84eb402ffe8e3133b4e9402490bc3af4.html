The case AGAINST (opponent, writing after the proponent)

The proponent has no qualifying anchor to defend. The paper’s only numbered formal statement is Definition 1, which defines a coalition structure. Its computational content is a search-space count and a simulation comparing TACOS with simulated annealing; it proves no complexity or algorithmic result. So the strongest case against a mirror is that there is no named computational result here for ChoCo to continuize. The paper’s actual contribution is an empirical comparison of two heuristics on sampled finite games.

The best candidate for a new continuous question would restrict the games to a small set of interchangeable agent types and make coalition value depend only on type counts. For a characteristic-function game, one could use variables \(y_q\) for the mass of coalitions with composition \(q\), constrain their aggregate type use to equal the society’s supplies, and optimize total value. That is a coherent high-multiplicity model, and its configuration LP or pricing problem could be interesting. But it adds the symmetry and valuation structure the paper does not supply. In its experiments, coalition values are sampled independently for each coalition; in partition-function games, they are sampled for each coalition within each structure. For those instances, agents generally have distinct interaction profiles, so grouping them into a few types would discard information. A continuous version faithful to those inputs would typically have as many types as agents and no population compression.

That restricted configuration model also would not mirror the paper’s main result. TACOS’s tabu list, its chosen neighborhoods, and simulated annealing’s random moves are defined over exact finite partitions. One could redesign both to search over fractional coalition configurations, but the resulting comparison would depend on new choices of neighborhood, tabu memory, and input distribution. It would be a new heuristic study, not a continuous counterpart of the reported finding that TACOS outperformed simulated annealing on the paper’s sampled games.

The negative case is strongest against calling this paper a ChoCo mirror: there is no qualifying result, and the paper’s actual benchmark has no canonical continuous extension. It is weaker against the broader claim that no worthwhile continuous problem could arise from coalition structure generation. The type-count model above is sensible enough that it may merit study on its own. I cannot honestly rule out every such scenario; I can only say that the paper neither establishes one nor provides a result for it to mirror.
