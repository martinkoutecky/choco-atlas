The continuous mirror question

Given a realizable weighted tournament \(W\) induced by a finite-support society of \(\tau\) voter types with binary-rational masses \(\mu_t\), compute a candidate \(j\) using only \(W\) such that, for every compatible mass society and every consistent metric \(d\) with positive optimal cost, \(\mathrm{SC}_{\mu}(j,d)/\min_{c\in C}\mathrm{SC}_{\mu}(c,d)\le 1+2\sqrt{2}\).

The model it lives in

A society is a distribution \(\mu\) over complete voter types \(t=(\pi_t,x_t)\), where \(\pi_t\) is a strict ranking and \(x_t\) is the voter’s location in a consistent metric completion. Its observable tournament has \(w_{ab}=\sum_{t:a\succ_{\pi_t}b}\mu_t\), and \(\mathrm{SC}_{\mu}(c,d)=\sum_t\mu_t d(x_t,c)\). The mechanism receives only \(W\) and returns the candidate selected by the \(\sqrt{2}\)-Path-Unblanketed Set Rule.

The objection that survived

The rule uses only \(W\), so the type support adds no \(\tau\)-dependent work and clearing denominators transfers the guarantee to rational masses. This limits the mirror’s computational novelty, but the proponent acknowledges that compression and it does not eliminate the population-mass analogue.

fatal: False

The case FOR (proponent)

My strongest lead is Theorem 2, proved in this paper. It says that the \(\sqrt{2}\)-Path-Unblanketed Set Rule is a polynomial-time deterministic C2 rule and has distortion at most \(1+2\sqrt{2}\approx3.8284\), uniformly for every finite number of candidates. The proof combines the existence result in Theorem 1 with the metric comparison in Lemma 1; that comparison uses Proposition 1, which is cited from Charikar et al. [8]. The paper has no named hardness result, so this algorithmic theorem is its clearest computational anchor.

A direct mirror is Mass-C2 Robust Winner Selection. There are \(m\) candidates and a population of total mass one, supported on \(\tau\) complete voter types. A type includes a strict ranking \(\pi_t\) and, in a given hidden metric realization, a voter location \(x_t\); two agents share a type only when they agree on the features relevant to that realization. Type \(t\) has rational mass \(\mu_t\), with \(\sum_t\mu_t=1\). The observable weighted tournament is \(w_{ab}=\sum_{t:a\succ_{\pi_t}b}\mu_t\). The C2 rule receives only \(W=(w_{ab})\), not the type table, locations, or metric.

For a metric completion consistent with the rankings, candidate \(c\)’s social cost is \(\mathrm{SC}_\mu(c,d)=\sum_t\mu_t d(x_t,c)\). Given a realizable rational \(W\), the task is to return a candidate \(j\) whose ratio to the minimum social cost is at most \(1+2\sqrt{2}\) for every mass society and consistent metric completion inducing that same \(W\), whenever the optimum cost is positive. The solution is the rule from Theorem 2: for each comparison candidate \(i\), find an admissible proxy \(k\) and a path from \(j\) to \(k\) in the graph with arcs \(a\to b\) when \(w_{bj}\le\sqrt{2}\,w_{ak}\); return a candidate that passes these tests for every \(i\). The path supplies a cut comparison for each relevant partition, yielding the stated social-cost guarantee. This is tractable: the construction needs only polynomially many graph reachability checks in \(m\). If the mass table is supplied to form \(W\), that aggregation takes time polynomial in \(m,\tau\), and the mass bit length \(L\).

The regime I find plausible is a large consultation or membership vote with millions of participants but relatively few repeated, complete preference-and-location types—for example, stable cohorts at a modest number of sites ranking a fixed slate of candidates. Then \(N\gg\tau\): the number of people is large, while the number of distinct types remains modest. The rule still sees only pairwise mass frequencies, so the mirror preserves the paper’s information restriction and its robust objective. Candidates remain discrete; it is the population that becomes mass.

The bridge is exact for binary-rational masses: clear denominators and each mass society becomes a finite electorate, and every finite electorate induces such a mass society. Thus the paper’s bound transfers directly to this version. I would expect the mirror to be Class A, through the same structural argument and reachability algorithm. It raises further questions about whether \(1+2\sqrt{2}\) is the best guarantee for deterministic C2 rules in this regime, and whether a rule that sees more than \(W\)—for example, the full ranking-type distribution—can improve it.

The weakest point is novelty. The paper already defines pairwise inputs as fractions of voters, and its rule’s running time depends on the weighted tournament rather than the electorate size. For rational finite-support societies, this mirror is exactly a high-multiplicity restatement of finite profiles. That is a strong reason to believe the authors would recognize it as their problem, but it also makes this a close case for whether the paper’s model is already continuous enough to count as a genuine collision. The positive case is strongest as a precise population-mass formulation of their algorithmic result, not as a claim that the paper has opened a new complexity landscape.

The case AGAINST (opponent, writing after the proponent)

Theorem 2 is a genuine computational anchor: it gives a polynomial-time rule with a distortion guarantee. I would not argue that elections lack a plausible high-multiplicity regime. A large consultation with repeated rankings is sensible. The stronger negative case is that the paper’s computational problem has already discarded the population detail a continuous mirror would introduce.

Take the best version of the proposed mirror: a mass distribution over complete voter types, including rankings and locations, with the rule required to meet the distortion bound for every metric completion inducing the observed pairwise frequencies. The rule in Theorem 2 already sees only \(W\), and its tests use only \(W\). The paper quantifies the guarantee over every finite profile and every consistent metric. For rational finite-support masses, clearing denominators produces exactly such a profile; the same rule and guarantee apply. Aggregating a supplied support of size \(\tau\) costs \(O(\tau m^2)\), after which the rule’s graph searches depend only on \(m\). The population representation adds no computational variable to the result.

For a genuinely continuous distribution, the social-cost sums become integrals. The comparison behind Lemma 1 is linear in voter mass, so the same argument extends to integrable costs. The output still depends only on \(W\). If arbitrary real frequencies are the input, one must specify how they are represented for exact computation; rational finite-support encodings return to the model the theorem already covers. Either way, the mass version supplies no new complexity question for this anchor.

A version that gives the rule the full type distribution might create a different algorithmic problem, but it changes the C2 information restriction that Theorem 2 is about. Likewise, studying which distributions realize a worst-case distortion is a possible research direction, but it asks about the adversarial analysis of the rule rather than a new computational task on a continuous society. Appendix B already uses distributions over rankings with common pairwise marginals as lower-bound certificates, then relates them back to finite electorates. That is not by itself a continuous treatment, but it reinforces how little new computational structure the proposed mass formulation adds.

So the proponent’s mirror is coherent and its large-election setting is convincing. My case against it is narrower: as a continuization of Theorem 2, it restates a rule already computed from population shares and already proved against all finite populations. The negative case is vulnerable if the programme counts a formal integral extension as worthwhile in its own right; there is no fundamental obstacle to the model, only a strong case that this particular anchor offers little new computational landscape to chart.
