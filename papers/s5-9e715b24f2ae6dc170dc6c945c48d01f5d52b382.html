The case FOR (proponent)

I can’t make a qualifying positive case under your anchor rule: this paper has no numbered result about the complexity of a computational problem. Its propositions characterize farsighted stability and efficiency for finite networks; none establishes an algorithmic running time, hardness, or a parameterized complexity result.

The closest seed is Proposition 8, proved in this paper: for any anonymous, component-additive value function \(v\), under the componentwise egalitarian allocation rule, the strongly efficient networks are the unique pairwise farsightedly stable set if and only if \(v\) is top convex. That is a substantive characterization, but it is not a computational result, so it cannot serve as an anchor here.

A continuum network model is imaginable: many agents in a few classes with shared payoff and link-cost parameters, represented by a graphon of link densities. But a single link between two agents has zero mass in that representation. Replacing pairwise farsighted deviations with positive-mass changes to link densities would alter the paper’s stability concept. That makes the authors’ acceptance of such a mirror uncertain, and the proposed question would be a new stability theory rather than a computational mirror of a named result. The honest conclusion is that this paper offers no anchor for the requested continuous computational question.

The case AGAINST (opponent, writing after the proponent)

The case against a ChoCo mirror is strongest at the threshold: none of this paper’s numbered propositions asserts a computational result. Propositions 3, 5, 7, and 8 characterize which network sets are stable under specified payoff models. They give no running time, hardness result, or algorithmic problem whose complexity is being classified. That leaves no computational result to mirror.

Proposition 8 is the best candidate to rescue. One could ask whether a high multiplicity version admits an efficient test for top convexity or an algorithm to find the farsightedly stable set. But that would introduce a new computational problem. The proposition itself is a mathematical equivalence, and for arbitrary value functions there is no succinct input or oracle model to analyze. Restricting to particular, efficiently represented network models might produce interesting algorithms, but those would be new results about those models, not computational mirrors of Proposition 8.

A graphon is the strongest proposed continuum model, but it loses the moves that define the paper’s stability concept. Pairwise farsighted paths proceed through single-link changes. In a graphon, changing one link has zero mass and leaves the aggregate state unchanged, even though it can change the incentives of its endpoints and alter later moves. Allowing positive-mass link changes would instead define a different, collective stability concept. And aggregating links by type does not generally retain the individual network structure needed to evaluate paths, connectivity, or bargaining opportunities.

The buyer–seller results offer a more natural high multiplicity setting: a continuum matching model could replace disjoint pairs with matching flows. But that would study a new mass-allocation problem; it would not preserve the bilateral link moves on which Propositions 4–6 rest, nor mirror a computational result in the paper. Similar reinterpretations may be worthwhile as new network theory, but they do not meet this programme’s computational-mirror criterion.

This makes the negative case strong for ChoCo’s stated scope, though it cannot establish that no useful continuum theory could ever be built from the paper.
