What the mirror covers

The proposed mirror covers the paper’s sole main theorem: the unique fair allocation formula for finite lists of intervals. It does not extend the paper’s fairness axioms to a new measure-theoretic setting.

The case FOR (proponent)

The best positive case is narrow but credible: interval-uncertain fair division has a natural high-multiplicity mirror, and the paper’s formula extends to it directly.

There is a limitation on the anchor. The paper has no numbered computational-complexity result. Its main result in §3 is printed simply as “Theorem” and proved in the paper: for every consistent finite list of intervals, there is exactly one fair division, and its weights are given by an explicit formula. That is a computationally useful result, but it does not state that a problem is in P or assert a hardness classification. I would use it as the closest anchor, while being clear that it does not meet the requested numbered-anchor criterion.

My lead mirror is High-Multiplicity Fair Division Under Interval Uncertainty. A type \(t\) is a recipient with a particular interval of permitted per-capita allocations, \([a_t,b_t]\); people with the same interval are indistinguishable for this problem. The input is a finite-support distribution \(\mu\) over types, with rational masses summing to \(1\). Let \(x_t\) be the allocation to each recipient of type \(t\), in units of the average share. Given a unit total to divide, ask for a fair allocation \(x\) satisfying \(a_t\le x_t\le b_t\) and \(\sum_t\mu_t x_t=1\). There is no separate cost objective in the paper’s problem: fairness is meant to select the allocation.

When the interval data are consistent, set \(A=\sum_t\mu_t a_t\) and \(D=\sum_t\mu_t(b_t-a_t)\). The natural continuous extension of the paper’s theorem returns
\[ x_t=a_t+(b_t-a_t)\frac{1-A}{D} \]
when \(D>0\), and \(x_t=a_t\) when \(D=0\). This gives a solution in time polynomial in the support size \(\tau\) and the input bit length. The finite-to-continuous dictionary is exact for rational masses: if there are \(n\) recipients and \(n_t\) have type \(t\), take \(\mu_t=n_t/n\) and scale their original share intervals \([\ell_t,u_t]\) to \([a_t,b_t]=[n\ell_t,nu_t]\). Then \(x_t=nw_t\), where \(w_t\) is the paper’s per-recipient share, and the weighted resource constraint and formula agree.

A convincing regime is a large relief or benefits fund distributed among many claimants in a small number of statutory need bands. Recipients in a band share the same permitted interval; the number of claimants can be enormous while the number of interval types is modest. That is a population continuization: the mass records what fraction of recipients belongs to each type. The fact that money is divisible is already present in the paper’s finite-participant problem; it is not what makes this mirror continuous.

I expect this mirror to be tractable by the formula above. It covers the paper’s main uniqueness-and-construction result, not any broader complexity landscape. It also suggests questions about exact bit complexity, stability under changes in type masses or interval endpoints, and which fairness axioms characterize the formula for general measures. The weakest point is that the paper proves its axioms for finite participant lists, not for a nonatomic population. The formula and finite rational-mass correspondence make the extension natural, but a formal continuum axiom system would still need to be specified.

The case AGAINST (opponent, writing after the proponent)

The negative case is narrow, but it lands on the paper’s only proposed anchor: there is no numbered result asserting the complexity of a computational problem. The main theorem is an axiomatic characterization with an explicit formula. It can be evaluated as an algorithm, but it does not leave a computational question for ChoCo to classify.

The claimant scenario is plausible, and grouping recipients by interval is a sound high-multiplicity model. The best version of the proposed mirror works: for support types \(t\), masses \(\mu_t\), and intervals \([a_t,b_t]\), set \(A=\sum_t\mu_ta_t\) and \(D=\sum_t\mu_t(b_t-a_t)\). When \(D>0\), the allocation is \(x_t=a_t+(b_t-a_t)(1-A)/D\). That is the paper’s formula with repeated participants aggregated. For rational masses, it also follows directly by scaling to integer counts and applying the finite theorem. This makes the mirror mathematically legitimate, but leaves its computation as evaluating two sums and a quotient.

A more ambitious version does not add much. With a general distribution over interval types, the same rule needs only the corresponding averages. Under ChoCo’s finite-support input model, that is still direct formula evaluation; beyond it, computational questions would depend on how the distribution is represented, a new input model rather than a harder mirror of this paper’s result. Stability questions are likewise formula analysis, while extending the fairness axioms to general measures is axiomatic work outside the programme’s target.

So I would not argue that the population model is incoherent, that the fund example is implausible, or that the result is already covered by continuous prior art. The case against is that this paper offers no substantive computational result to continuize: its exact construction already compresses repeated interval types, and the natural mass version adds no algorithmic problem beyond computing the formula. This is a real but modest objection. The proponent has established a valid continuous reformulation; what remains unconvincing is that it merits a place in a programme aimed at charting computational complexity.
