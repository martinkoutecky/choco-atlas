The continuous mirror question

Given candidates \(C\), committee size \(k\), and an ordered support of \(\tau\) types with rational masses \(\mu_j>0\) summing to \(1\), approval sets \(A_j\), and rational non-increasing per-capita sequences \(w^j_1,\ldots,w^j_m\), where each candidate is approved by a consecutive block of types, compute a size-\(k\) committee \(W\subseteq C\) maximizing \(\sum_{j=1}^{\tau}\mu_j\sum_{r=1}^{|A_j\cap W|}w^j_r\) in time polynomial in \(m,\tau,L\).

The model it lives in

A rational distribution over complete approval-and-satisfaction types, with each candidate’s approvals consecutive in the support order. Choose an indivisible committee \(W\) of size \(k\) to maximize \(\sum_j\mu_j\sum_{r=1}^{|A_j\cap W|}w^j_r\). Equivalently, encode each type as one Generalized Thiele voter with sequence \(\tilde w^j_r=\mu_jw^j_r\).

The objection that survived

Each type can be represented by one generalized voter whose sequence is scaled by its mass, so Theorem 3 applies directly and the mirror requires no new algorithmic machinery.

fatal: False

What the mirror covers

The mirror covers Generalized Thiele winner determination on Voter Interval support; it leaves out robustness and profiles with approval intervals violated by some types.

The case FOR (proponent)

The strongest case is a type-mass version of the paper’s Generalized Thiele winner-determination problem. My anchor is Theorem 3, proved in this paper: for a Voter Interval approval profile, given a committee size \(k\) and a rational non-increasing Thiele weight sequence for each voter, a polynomial-time algorithm computes an optimal size-\(k\) committee. The paper’s introduction mentions hardness for unrestricted Thiele rules, but that is cited background, not a numbered result here; Theorem 3 is the paper’s named computational result that I would mirror.

Call the mirror Continuous Voter-Interval Generalized Thiele Winner Determination. An instance has \(m\) candidates, a committee size \(k\), and an ordered support of \(\tau\) types. Type \(t_j\) consists of an approval set \(A_j\subseteq C\), a rational non-increasing weight sequence \(w^j_1,\ldots,w^j_m\), and a positive rational mass \(\mu_j\), with \(\sum_j\mu_j=1\). The type is complete: agents with the same type have the same approvals and weights. The type order is part of the instance, with the Voter Interval promise that each candidate is approved by a consecutive block of types.

The question is to return a committee \(W\subseteq C\), \(|W|=k\), maximizing
\[ \operatorname{sc}_{\mu}(W) =\sum_{j=1}^{\tau}\mu_j \sum_{r=1}^{|A_j\cap W|} w^j_r. \]
The input uses binary rationals; the complexity target is polynomial in \(m,\tau,L\), where \(L\) is the encoding length of the masses and weights. The population size \(N\) may be very large compared with \(\tau\).

A plausible regime is a large public consultation choosing \(k\) projects from a menu. Residents fall into a relatively small number of repeated approval-and-satisfaction cohorts along a one-dimensional needs spectrum; each project is approved by a contiguous band of cohorts. For example, \(N\) could be in the hundreds of thousands while \(\tau\) is a few dozen. Mass means the fraction of residents in a cohort. The decision remains an ordinary indivisible committee, and each cohort’s contribution is its per-capita Thiele score multiplied by its population share.

This is close to the authors’ problem in the relevant respects: the alternatives, approval ballots, size-\(k\) committee, generalized Thiele objective, and interval restriction all remain. Only voter multiplicities become rational masses. The expected answer is Class A, tractable. Set
\[ f_j(q)=\mu_j\sum_{r=1}^{q}w^j_r. \]
Each \(f_j\) remains non-decreasing and concave, so the paper’s interval-combination concavity argument still applies. In the Lagrangian formulation, masses change objective coefficients; they do not change the constraint matrix whose total unimodularity drives the algorithm. The proof therefore appears to support an algorithm with one row per type, rather than one per person.

That last point is an adaptation to prove, not a runtime bound stated by Theorem 3: simply clearing mass denominators could produce an explicit electorate exponentially large in \(L\). The mirror should ask whether the compressed formulation can be solved in time polynomial in \(m,\tau,L\), without expanding those multiplicities. It also raises useful follow-ups: does the algorithm still work when the interval order must be recovered from the support, and can it handle a small mass of voters whose approvals violate the interval condition?

My scope is Theorem 3 alone. I would not count Corollary 2’s concavity in committee size as a separate population mirror: committee size is an outcome parameter, and here it serves as support for the algorithm. The main weakness is that this is a tractability anchor, not a case where continuous mass might dissolve a named hardness result. The Voter Interval regime is also restrictive. Still, it is a faithful, concrete high-multiplicity version of the paper’s central problem, and the paper’s proof gives a specific reason to expect the compressed population algorithm to work.

The case AGAINST (opponent, writing after the proponent)

The proposed anchor has a genuine collision: its continuous population is already expressible as an instance of the paper’s Generalized Thiele problem.

For a support type \(t\), let \(A_t\) be its approval set, \(\mu_t\) its mass, and \(w^t\) its per-capita Thiele sequence. Replace that type by one representative voter with sequence
\[ \widetilde w^t_r=\mu_t w^t_r. \]
This is a valid sequence in the paper’s model: it is rational, non-increasing, and lies in \([0,1]\). For every committee \(W\), the representative voter contributes exactly the type’s population-weighted score:
\[ \sum_{r=1}^{|A_t\cap W|}\widetilde w^t_r =\mu_t\sum_{r=1}^{|A_t\cap W|}w^t_r. \]
Summing over types gives precisely the proposed continuous objective. The interval promise is preserved when the support types are ordered as in the mirror. Theorem 3 therefore applies directly to the \(\tau\) representative voters, with running time polynomial in \(m,\tau,L\); there is no need to expand rational masses into individual voters.

That matters because mass has no other role in this problem. Feasibility concerns an indivisible committee of size \(k\), and each type affects a committee only through its additive score contribution. Changing mass simply rescales a generalized voter’s score sequence. The public-consultation scenario does not alter that equivalence: it motivates the distribution, but does not create a new computational model. The mirror’s formal instance and objective are already contained in the paper’s own generalized formulation.

The stronger version with a nonatomic population along an ordered spectrum also collapses for this anchor. Candidate approval intervals partition that spectrum into at most \(2m+1\) cells on which the approved candidate set is constant. Integrating each cell’s per-capita weight sequence gives one representative generalized voter with the same contribution to every committee. If the population is specified through some implicit representation for which those integrals are hard to compute, that difficulty comes from the representation, not from the continuous population model.

So the case against this anchor is not that a continuous answer would be uninteresting. It is that the proposed question, including its compressed bit-complexity version, is already the paper’s problem under a direct change of coefficients. The case is strongest for the stated winner-determination mirror; it does not establish that every other possible population-based problem inspired by the paper would collapse in the same way.
