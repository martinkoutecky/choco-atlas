The continuous mirror question

Given types \(T\), rational masses \(\mu_t>0\) summing to \(1\), initial opinions \(b_t\in\{0,1\}\) with \(\sum_t\mu_t b_t<1/2\), and a rational symmetric interaction-density matrix \(P\), choose \(q_t\in[0,1]\), the final fraction of type \(t\) holding opinion \(1\), to minimize \(\sum_t\mu_t|q_t-b_t|\), subject for every \(t\) to \(\sum_{t'}\mu_{t'}P_{tt'}q_{t'}\le\sum_{t'}\mu_{t'}P_{tt'}(1-q_{t'})\).

The model it lives in

A dense block-structured society has types \(t\) with mass \(\mu_t\), initial opinion \(b_t\), and symmetric interaction densities \(P_{tt'}\). The decision variable \(q_t\in[0,1]\) gives the fraction of type \(t\) ending with opinion \(1\); minimize changed mass \(\sum_t\mu_t|q_t-b_t|\) while requiring no type to have a local majority of opinion \(1\). This is a linear program after linearizing the absolute values.

What the mirror covers

It mirrors Theorem 1’s minimum-change objective and local-majority requirement for large dense societies with a modest number of homogeneous interaction types. It does not cover the paper’s arbitrary graph instances or its results about planar graphs, treewidth, pathwidth, or vertex cover.

Open questions for a prover

  • Under what margin or concentration assumptions can a continuous solution be rounded to a finite dense block network while preserving the no-illusion condition?
  • How much within-type variation in interaction profiles can the model tolerate before it ceases to predict individual illusions?

The case FOR (proponent)

The strongest honest lead is a continuous version of Eliminating Illusion for a large, block-structured social network. Picture millions of people in a few dozen stable community or role groups. People in each group share an initial opinion and the same interaction profile: for example, each group member has the same exposure rate to every other group. The number of people \(N\) is large while the number of distinct types \(\tau\) stays modest.

Call the problem Continuous Majority-Illusion Elimination on Block-Structured Societies (CMIE). An instance has types \(T\), rational masses \(\mu_t>0\) summing to \(1\), initial opinions \(b_t\in\{0,1\}\), and a rational symmetric interaction matrix \(P\). Assume \(\sum_t\mu_t b_t<1/2\), as in the paper. \(P_{tt'}\in[0,1]\) gives the interaction density between types \(t\) and \(t'\). A type-\(t\) person therefore has interaction mass \(\mu_{t'}P_{tt'}\) with type \(t'\).

A solution is a vector \(q\in[0,1]^\tau\), where \(q_t\) is the fraction of type \(t\) that ends with opinion \(1\). Individuals still hold binary opinions; \(q_t\) records the mass split within a type. The solution must eliminate every illusion: for each \(t\),
\[ \sum_{t'}\mu_{t'}P_{tt'}q_{t'} \le \sum_{t'}\mu_{t'}P_{tt'}(1-q_{t'}). \]
Among such solutions, minimize the mass whose opinion changes,
\[ \sum_t\mu_t|q_t-b_t|. \]
This is my lead mirror.

Its anchor is Theorem 1, proved in this paper by reduction from Set Cover. It says that EI is NP-hard and W[2]-hard parameterized by the solution size, even when the input graph is bipartite and has bounded diameter; the construction in the proof has diameter at most \(6\). EI asks, given a graph with an initial labelling having a strict majority of \(0\)s and an integer \(k\), whether at most \(k\) vertices can be relabelled so that no vertex has more \(1\)-labelled than \(0\)-labelled neighbours. The Set Cover hardness used in the reduction is cited; the EI hardness result itself is established here.

CMIE is a plausible continuous counterpart because it keeps the paper’s central objects: binary opinions, local majority perceptions, and minimizing the number—here the mass—of people whose opinion changes. The interaction matrix is the continuous description needed to define neighbourhood exposure when the population is a continuum. In the proposed regime, type means the task-relevant combination of initial opinion and interaction profile, so many agents can genuinely share a type.

CMIE is tractable, in Class A: its objective and constraints form a rational linear program with \(\tau\) variables and \(\tau\) constraints, solvable in polynomial time in \(\tau\) and the input bit length. This does not refute Theorem 1. Its Set Cover reduction encodes incidence information in graph neighbourhoods; under this mirror, a society with only a modest number of interaction profiles has a compact aggregate description and permits fractional mass transfers. If encoding the reduction requires a number of distinct profiles comparable to the number of agents, it falls outside the high-multiplicity regime defended here.

The weakest point is that the paper studies arbitrary individual graphs, while CMIE replaces their detailed topology with a block-structured interaction model. In a generic graph, two people assigned the same broad community label can still have different neighbours and different local majorities. So this is a credible mirror for large societies with stable, homogeneous exposure profiles, not a claim that the paper’s full graph model has become continuous. The paper’s focus on neighbourhood structure makes that limitation material; the mirror survives because the homogeneous regime is a recognizable social-network setting and retains the problem the authors study.

The next questions are whether a CMIE solution can be rounded to finite agents while preserving the no-illusion condition, what margin or concentration assumptions would make that possible for dense stochastic block networks, and how much within-type variation in exposure the model can tolerate before it stops predicting individual illusions.

The case AGAINST (opponent, writing after the proponent)

Theorem 1 is a genuine computational anchor: EI minimizes the number of vertices changed while enforcing a local-majority condition at every vertex. Its Set Cover reduction relies on the exact incidence pattern between set vertices and element vertices. The difficulty in carrying that problem into a population model is preserving those local conditions after grouping people into types.

In the proposed CMIE, \(q_t\) records how a type’s mass is split between opinions, and each constraint checks that type’s aggregate exposure. If people grouped together have different actual neighborhoods, that aggregate can hide which particular people must change to fix which illusions. A faithful type would need to capture the relevant neighborhood information; for general graphs, that can leave nearly every vertex in its own type. Then the model retains the incidence structure but loses the modest-support advantage the mirror was meant to provide.

The best repair is a graphon-style model: give each continuum agent a neighborhood profile \(W(x,\cdot)\), choose a final opinion density \(q(x)\), and require the local-majority condition almost everywhere. That preserves the per-agent flavor for dense networks. With a finite-step kernel, though, it reduces to an LP over the steps. In sparse networks, an individual’s neighborhood has vanishing population mass, so the continuum constraint loses the finite-neighborhood information that drives EI; rescaling interactions to preserve it does not restore positive mass to individual interventions.

This is the strongest objection I see to the anchor: the mirror can preserve the paper’s local condition in dense, homogeneous regimes, or preserve arbitrary graph incidence, but the latter generally needs many types and the former changes the network regime being studied. Still, I cannot honestly make the universal negative case stick. A large dense block-structured society is a plausible high-multiplicity setting, and its continuum majority-illusion problem is recognizable as the authors’ problem. The proponent’s Theorem 1 mirror therefore survives in that regime; the paper’s reduction alone does not establish that such a mirror is unworthy.
