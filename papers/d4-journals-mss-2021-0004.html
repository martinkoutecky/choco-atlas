The closest results are structural. Theorem 3.20, proved here, says nonzero \(\beta_n\) implies at least \(\beta_n\) nonviable agent subsets, each of size at least \(n+2\). The case AGAINST (opponent, writing after the proponent)

The strongest negative case is that the paper offers no computational result to mirror. Theorem 3.20 connects Betti numbers to nonviable configurations; Proposition 4.4 connects homology to the absence of compromises; Theorem 4.1 describes what a friendly delegation does to viability and stability. None classifies the complexity of a problem or gives an algorithm for finding a compromise, delegation, or mediator. The remark that homology can be computed by linear algebra is a standard computational observation, not a result about the complexity of a political problem. So the proposed case has named mathematical results, but no computational anchor.

The best attempts to turn those results into anchors still leave that gap. One could ask whether a given finite political structure has nontrivial homology or a \(D\)-compromise. But that would be a computational problem built around the paper’s topology, not a complexity result stated in it. In a population model, treating agent types as vertices also leaves a basic modeling choice: a measure over types does not by itself specify how to count or sample coalitions. A mass-based compromise or viability objective would need its own definition and computational question.

Theorem 4.1 is the nearest candidate for a population intervention: it studies the effect of deleting one dominated agent. In an atomless society, deleting one person has zero mass; moving positive mass between types would be a bulk-delegation operation, which the theorem does not analyze. One could define an optimization problem for choosing such moves, but that would add a new objective and intervention model, rather than continuize a result in the paper.

A large population of citizens grouped by issue profiles is a plausible adjacent scenario. If coalition compatibility is specified by a compact type-level rule, one could study fractional interventions on that population. But the resulting algorithmic questions would be new work inspired by the paper. If compatibility instead depends on detailed coalition context, encoding that context in each agent’s type may also eliminate the small-support structure a continuous treatment needs.

So the negative case is strong for this paper as a source of continuous mirrors: it develops topological and structural claims, not computational ones. It is weaker as the universal claim that no worthwhile continuous project could arise in any related scenario. A fractional intervention model might be worth studying; the paper simply gives no computational result for it to mirror.
