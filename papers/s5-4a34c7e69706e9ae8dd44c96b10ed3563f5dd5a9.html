What the mirror covers

The proposed mirror covers the restricted half-integer allocation case, where heavy goods go only to agents who value them at \(s\). It leaves the unrestricted case and the other value regimes outside this proof.

Open questions for a prover

  • Can the bundle-pricing problem for a type and dual prices be solved efficiently, or approximated with a useful guarantee?
  • How closely do rational finite replications approximate the continuous optimum as a function of type support and input bit length?

The case FOR (proponent)

The strongest mirror I believe in is a high-multiplicity version of the paper’s two-value Nash social welfare problem. The supplied text does not print a number for its closing lemma, so I cannot quote one without inventing it. Its statement is: “An optimal allocation for \(N_s\) can be computed in polynomial time. The \(\NSW\)-allocation for half-integer instances can be computed in polynomial time.” The paper proves this result here, using a parity-matching subroutine. Its detailed proof explicitly restricts heavy goods to agents who value them at \(s\); the unrestricted case is referred to earlier work. That restriction is the scope I would mirror.

Call the continuous problem Restricted Half-Integer \(2\)-Value NSW\(_\infty\). Fix a rational half-integer \(s>1\). An instance has a finite set \(T\) of agent types, a finite set \(G\) of good classes, rational type masses \(\mu_t\) summing to \(1\), and rational per-capita supplies \(\sigma_g\). Each type has a complete valuation vector \(v_{tg}\in\{1,s\}\). Goods in a class have the same value to every type, so they are interchangeable; a class is heavy if some type values it at \(s\). As in the paper’s restricted case, agents may receive a heavy good only if they value it at \(s\).

The decision is a distribution \(y_{t,b}\) of population mass over integral bundles \(b\in\mathbb N^{G}\). It must satisfy \(\sum_b y_{t,b}=\mu_t\) for each type and \(\sum_{t,b}y_{t,b}b_g=\sigma_g\) for each good class. The objective is to maximize
\[ \exp\!\left(\sum_{t,b} y_{t,b}\log\!\left(\sum_g v_{tg}b_g\right)\right), \]
with zero welfare if positive mass receives an empty bundle. The requested output is a feasible finite-support distribution within additive \(\varepsilon\) of optimal log-welfare. That makes the computational question precise while retaining the paper’s individual-level indivisibility: each agent gets an integral bundle; only the population is represented by mass.

A plausible regime is a recurring allocation of standardized, indivisible entitlements among large cohorts whose members have the same value vector over the available entitlement classes. The number of agents grows with supply, while the number of distinct valuation types and good classes stays modest. A type therefore captures everything this problem uses about an agent, and \(\mu_t\) means a share of the population. The per-capita supply \(\sigma_g\) scales with that population. This is a genuine population continuization, not fractional goods or lotteries for individual agents.

I expect this problem to be tractable, though that is a conjecture about the mirror, not a consequence of the paper’s theorem. The continuous objective is linear in the mass variables \(y_{t,b}\) after taking logs, so it has an LP form with bundle columns. The key question is pricing: for a given type and dual prices, can one efficiently find the integral bundle maximizing log-utility minus its priced resource use? Each type sees only two values, and \(s\) is fixed, which makes this look like a small, structured optimization problem. If that pricing step admits an efficient approximation, continuous-optimization methods could handle the exponentially large bundle description. The paper’s parity-matching algorithm does not establish that step; it gives a concrete reason to ask whether the continuous version falls in Class A.

The finite-to-continuous bridge is direct for rational allocations: a finite instance yields masses equal to the fractions of agents of each type receiving each bundle, and rational mass allocations can be represented by sufficiently large finite populations. A fuller result would characterize how well finite instances approximate the continuous optimum, and how that depends on type support and input bit length.

The weakest point is that this mirror changes the computational structure the paper exploits. The paper’s algorithm reasons about a finite agent–good graph, heavy-good transfers, and parity constraints. In the continuous version, a type can be split across bundles by mass, so those constraints may simplify or the pricing problem may introduce a different difficulty. That is a serious question for the prover, not a reason to dismiss the mirror: the agents still receive integral bundles, and the scaled supply is the natural high-multiplicity regime.

The paper’s introduction also reports NP-completeness for rational \(s\) outside the integer and half-integer cases, citing earlier work. Since the supplied text gives that claim no numbered result, and does not prove it here, I have not used it as a separate anchor. The lead anchor is the closing polynomial-time lemma; the mirror covers the restricted half-integer allocation result, not the paper’s entire surrounding landscape.

The case AGAINST (opponent, writing after the proponent)

The only clear computational anchor is the closing lemma: an optimal allocation for \(N_s\), and the half-integer NSW allocation, can be computed in polynomial time. The strongest case against mirroring it is that ordinary allocations often lack the required multiplicity. If goods remain individually distinguished, an agent’s complete type is its valuation vector over those goods; in many applications, both that type support and the number of distinct goods grow with the population. Then there is no compact cohort model, and keeping the goods fixed while the population grows can make per-capita supply vanish.

That objection does not defeat the proposed mirror. Recurring allocations of standardized indivisible entitlements can have fixed valuation types and good classes whose supplies scale with population. Those assumptions describe a plausible instance regime. Grouping agents by their full valuation vectors and goods by their full valuation profiles preserves everything the restricted NSW problem uses. The mass distribution over integral bundles also preserves the individual bundle constraint and the Nash objective: it records which share of each type receives each bundle, rather than assigning fractional goods to individuals. Rational mass solutions correspond to finite replicated instances.

The paper’s use of heavy-good transfers and parity matching makes the continuous question especially concrete. A mass model may smooth away the parity structure, or it may retain a difficult pricing problem over integral bundles. Either outcome would clarify the relationship between the theorem and high multiplicity. The result being restricted to half-integer \(s\), and to the paper’s restricted allocation case, narrows the mirror; it does not invalidate it.

So the negative case is weak. I can argue that high multiplicity is uncommon in many applications of NSW, but I cannot honestly argue that no plausible scenario supports this mirror, or that the stronger version proposed by the other analyst fails. Their anchor survives.
