The continuous mirror question

Given a finite set of contributor types \(T\), rational masses \(\mu_t\) summing to \(1\), and work weights \(q_t\), take finite populations with \(n_t/N \to \mu_t\), one distinguished founder, and coalition value \(\nu(S)=0\) without the founder and \(\nu(S)=\rho(\sum_{i\in S}q_i)^2\) otherwise. What are the limits, as fractions of grand-coalition value, of the founder’s Shapley payoff and each type’s aggregate Shapley payoff?

The model it lives in

A founder and a nonatomic crowd with type distribution \(\mu\), where type \(t\) carries work weight \(q_t\). Define the continuous allocation as the limit of finite-game Shapley payoffs aggregated by type: the founder receives \(1/3\), and type \(t\) receives \((2/3)\mu_tq_t/\sum_s\mu_sq_s\). This is an allocation calculation, not an optimization problem.

The objection that survived

The type-level limit largely aggregates Theorem 3.4 and adds no new complexity question; this bounds its novelty, though the proponent acknowledges that limitation.

fatal: False

What the mirror covers

The mirror covers the heterogeneous-work quadratic model in Theorem 3.4; it leaves the paper’s other single-system, oligopoly, geographic, and empirical results aside.

Open questions for a prover

The case FOR (proponent)

There is no qualifying computational-complexity anchor in this paper: it proves no named result that a problem is in P, NP-hard, FPT, or otherwise classifies its complexity. The nearest named result is Theorem 3.4, proved in the paper’s Appendix 8.1. It computes asymptotic Shapley allocations for a game with one founder \(g\) and crowd members \(u_1,\ldots,u_n\): a coalition has value zero without \(g\), and otherwise has value \(\rho(\sum_{i\in S}W_i^\alpha)^2\). Writing \(f_i=W_i^\alpha/\sum_j W_j^\alpha\), the theorem gives
\[ \lim_{n\to\infty}\frac{\phi_g}{\nu(N)} =\frac13+\sum_i\frac{f_i^2}{6}, \qquad \lim_{n\to\infty}\frac{\phi_{u_i}}{\nu(N)} =\frac23 f_i-\frac{f_i^2}{6}. \]
This is a substantive allocation result, but it is not a complexity classification.

The strongest plausible population mirror of that result is a Founder–Crowd Shapley Limit. Let \(T\) be a fixed finite set of contributor types, where type \(t\) specifies the contributor’s work weight \(q_t=W_t^\alpha\). The crowd has \(N\) members, with fraction \(\mu_t\) of type \(t\), \(\sum_t\mu_t=1\); one founder remains distinguished. The regime is \(N\to\infty\) with fixed type support and an increasing number of members of each positive-mass type. For the paper’s quadratic value model, the grand coalition’s value is \(V=\rho(N\bar q)^2\), where \(\bar q=\sum_t\mu_tq_t\).

The question is: given rational type masses \(\mu_t\) and weights \(q_t\), compute the limiting Shapley allocation as fractions of \(V\), one fraction for the founder and one for each crowd type. The solution is
\[ a_g=\frac13,\qquad a_t=\frac23\,\frac{\mu_tq_t}{\sum_s\mu_sq_s}. \]
These fractions sum to one. They follow from Theorem 3.4 when no individual contributor has a nonvanishing share of total work: then \(\sum_i f_i^2\to0\), and aggregating the crowd members of each type gives the displayed type shares. The “decision variable” here is the output allocation vector; there is no optimization objective because the paper’s Shapley rule prescribes the allocation. If counted as a computational task, this limiting instance has a direct closed-form solution. It raises further questions about finite-\(N\) error, concentrated contributors, and whether similar limits hold for the paper’s oligopoly and geographic models.

This is a plausible population mirror in its scenario: a large crowd can consist of many contributors sharing a small number of work profiles, and the paper itself studies large-\(n\) allocation behavior. The authors could reasonably recognize the limiting allocation as a continuous version of that analysis. It covers the heterogeneous-work result in Theorem 3.4, not the paper’s entire framework.

The weakness is decisive for ChoCo: the paper studies axiomatic cooperative-game allocation, not computational social choice. Its result already gives asymptotic formulas for a stylized finite game, and the proposed mirror continues the fairness-allocation analysis rather than posing a missing computational question about a continuous society. So this is the strongest honest positive case for a population limit, but it does not supply an anchor for the programme’s complexity landscape.

The case AGAINST (opponent, writing after the proponent)

The only anchor raised is Theorem 3.4. It gives Shapley shares for a specified cooperative game; it does not classify the complexity of a computational problem. The strongest repaired mirror—compute aggregate Shapley shares for a population with finitely many work types and rational masses—is a sensible population model. I would not object that contributors must have identical profiles: grouping them by the work weight the model uses is exactly high multiplicity.

But that mirror remains an allocation-limit question. The Shapley rule prescribes the output, and the paper studies closed-form shares and their asymptotics. It identifies no search, optimization, or complexity problem whose continuous version would fill ChoCo’s stated gap. Making the calculation harder by allowing arbitrary coalition values, black-box access, or strategic constraints would add a new problem rather than strengthen this mirror.

So the case against is strong only under ChoCo’s computational remit: this paper offers no qualifying computational-complexity anchor. I cannot honestly defend the broader claim that no worthwhile continuous mirror exists in any scenario. The paper’s large crowd and its asymptotic allocation analysis make a continuous population mirror plausible; it could be worthwhile as Shapley-allocation research, even if it does not advance the programme’s complexity landscape.
