The continuous mirror question

Given rational recipient-type masses \(\mu\in\Delta_\tau\), rational resource-type probabilities \(p\in\Delta_L\), utilities \(v_{a\ell}\in[0,1]\), initial per-capita utilities \(B_0(a)\), horizon \(T\), and \(\eta\in(1,4/3)\), each arriving resource type \(\ell_t\sim p\) must be allocated online using \(x_{t,a}\ge0\) with \(\sum_a\mu_a x_{t,a}=1\). Can one compute a nonanticipative policy using at most \(O(\log\log T)\) fluid re-solves whose expected regret against \(\max_x\min_{a:\mu_a>0}B_T(a)\) is \(O(1)\) in \(T\)?

The model it lives in

A finite high-multiplicity population of recipient types \(a\), with mass \(\mu_a\), receives population-scaled divisible supply. Static decisions are \(\xi_{\ell a}\), feasibility is \(\sum_a\mu_a\xi_{\ell a}=1\), terminal utility is \(B_0(a)+\sum_t v_{a\ell_t}x_{t,a}\), and the objective is egalitarian or mass-weighted Hölder welfare.

The objection that survived

The weighted \mathsf{BIRT} coupling and thresholding proof is not inherited automatically: its constants may depend badly on \(1/\mu_{\min}\), so a uniform guarantee over variable rational masses remains unproved.

fatal: False

Open questions for a prover

  • Does weighted \mathsf{BIRT}__\eta achieve \(O(1)\) regret with explicit dependence on \(\mu_{\min}\), \(p\), and \(v\)?
  • Can the fluid and \mathsf{BIRT} policies be computed with polynomial bit complexity in the rational input encoding?

The case FOR (proponent)

The strongest honest positive case is a high-multiplicity version of the paper’s dynamic fair-allocation problem. The population becomes continuous; resources remain sequential, divisible, and stochastic. This is a genuine population continuization, not outcome-space continuity.

There is one formal qualification. The paper has no named NP-hardness, \(P\), FPT, or parameterized-complexity theorem. Its strongest anchors are algorithmic regret theorems. Thus, if ChoCo’s anchor rule requires a complexity-class result literally, this paper has no compliant anchor. If algorithmic performance theorems count, the following is a credible Class A mirror. The theorem numbering below follows the supplied paper and its current arXiv version. [The paper](https://arxiv.org/html/2205.12447v2) proves both results itself.

The lead anchor is Theorem 2, labelled \(\ref{thm:main}\) in the source. It states: for every fixed finite arrival distribution \(P\in\mathcal P\) and every \(\eta\in(1,\nicefrac43)\), under egalitarian welfare, the Backward Infrequent Re-solving with Thresholding policy \(\mathsf{BIRT}_\eta\) has regret \(\mathcal R_T(\mathsf{BIRT}_\eta)=O(1)\). The constant depends only on \(P\) and \(\eta\), not on the horizon \(T\). The policy re-solves the deterministic fluid problem only \(O(\log\log T)\) times and uses thresholding to remain robust to degeneracy. This theorem is proved in the paper, not imported from elsewhere.

Call the continuous problem \(\mathsf{CP}\)-BIRT. An instance consists of a finite set of recipient types \(A=\{1,\ldots,\tau\}\), a rational mass distribution \(\mu\in\Delta_\tau\), a finite set of resource-arrival types \(L=\{1,\ldots,L\}\), rational arrival probabilities \(p\in\Delta_L\), a utility matrix \(v\in[0,1]^{\tau\times L}\), a horizon \(T\), and optionally initial per-capita utilities \(B_0(a)\). Type \(a\) is a complete recipient type: every member of that type has the same utility \(v_{a\ell}\) for every resource type \(\ell\), and the same initial state. The mass \(\mu_a\) is the fraction of the population of that type.

At each period \(t\), a resource of type \(\ell_t\sim p\) arrives and is revealed. The policy chooses per-capita allocations \(x_{t,a}\ge0\) satisfying \(\sum_a\mu_a x_{t,a}=1\). This is the required per-capita normalization: a finite population of \(N\) agents would receive a batch of \(N\) resource units per period, with \(N\mu_a\) agents of type \(a\). Each type receives the same per-capita allocation, not an arbitrary fractional outcome imposed on an otherwise finite population. Its terminal utility is \(B_T(a)=B_0(a)+\sum_{t=1}^T v_{a\ell_t}x_{t,a}\).

The hindsight benchmark is

\(\mathrm{OPT}_\mu(\ell_{1:T})=\max \min_{a:\mu_a>0} B_T(a)\),

where the maximization ranges over allocations satisfying the same per-period feasibility constraints. An online policy sees only \(\ell_1,\ldots,\ell_t\) when choosing \(x_t\), and its regret is

\(\mathcal R_T^\mu(\pi)=\mathbb E[\mathrm{OPT}_\mu-\min_{a:\mu_a>0}B_T^\pi(a)]\).

The question is: given this instance, compute a nonanticipative policy \(\pi\), preferably using at most \(O(\log\log T)\) fluid re-solves, such that \(\mathcal R_T^\mu(\pi)\le C(\mu,p,v,\eta)\) for every \(T\). A natural candidate is the mass-weighted BIRT policy. At each re-solving time, it solves the LP

\(\max u\), subject to \(u\le B_t(a)+(T-t)\sum_\ell p_\ell v_{a\ell}\xi_{\ell a}\) for every type \(a\), \(\sum_a\mu_a\xi_{\ell a}=1\) for every resource type \(\ell\), and \(\xi_{\ell a}\ge0\). It then thresholds small allocation components and assigns the residual to a largest component, preserving the weighted feasibility constraint.

This should be Class A for fixed finite \(\tau\) and \(L\). Each re-solving problem is a linear program with \(O(\tau L)\) variables, and the number of re-solves is \(O(\log\log T)\). The substantive question is whether the paper’s coupling, sensitivity, and concentration proof survives after replacing named agents by mass types. That is recognisably the authors’ problem: same irrevocable online allocation, same stochastic resource arrivals, same egalitarian objective, same hindsight benchmark, and the same fluid-versus-prophet comparison.

The regime is plausible. Think of millions of households, patients, charities, or small service units divided into perhaps \(10\)–\(100\) recurring need types. A type records the complete utility profile for all resource categories. The high-multiplicity condition is \(N\gg\tau\), with many agents sharing each profile. The original examples involving a handful of hospitals are weak instances of this regime; a large network of repeated recipient units is much stronger.

A useful secondary anchor is Theorem 1, labelled \(\ref{thm:main-fluid}\). It proves that for every fixed \(P\), every Hölder mean \(w_q\) with \(q\in(-\infty,1]\), and every fluid policy \(\mathsf F\), the regret satisfies \(\mathcal R_T(\mathsf F)=O(1)\) uniformly in \(T\), with a constant depending only on \(P\). This includes the Nash, harmonic, and utilitarian cases, but excludes the non-smooth egalitarian case. The result is proved in the paper.

Its mirror, \(\mathsf{CP}\)-FLUID-\(q\), uses the same instance but evaluates population welfare by

\(W_q(B)=(\sum_a\mu_aB(a)^q)^{1/q}\),

with the usual geometric-mean interpretation at \(q=0\). The solution is the static type policy \(\xi_{\ell a}\) maximizing

\(W_q(B_0(a)+T\sum_\ell p_\ell v_{a\ell}\xi_{\ell a})\)

subject to \(\sum_a\mu_a\xi_{\ell a}=1\). The question is whether this policy has \(O(1)\) expected regret against the continuous-population hindsight optimum for every \(T\). This is also plausibly Class A: the fluid problem is a finite convex optimization problem, and the paper’s concentration argument should have a weighted-mass analogue.

The main follow-up questions are whether the constant can be controlled in terms of \(\tau\), \(\min_a\mu_a\), and the utility matrix; whether rational finite populations admit explicit rounding bounds; whether the result extends from finite support to a genuinely diffuse type space; and whether allowing type-dependent budgets, eligibility, or indivisible per-capita bundles produces a Class B or Class C boundary.

The weakest point is decisive but narrow: Theorem 1 and Theorem 2 are regret/performance theorems, not formal computational-complexity classifications. Moreover, extending BIRT is not automatic when some type masses become very small: the sensitivity constants and the egalitarian benchmark may deteriorate with \(\min_a\mu_a\). So the positive case is strongest for finite-support populations with masses bounded away from zero. Under that regime, however, this is a genuine and natural continuous-population mirror of the paper’s central algorithmic contribution.

The case AGAINST (opponent, writing after the proponent)

The strongest objection comes before either proposed theorem: this paper has no qualifying computational anchor. Theorem \(\ref{thm:main}\) and Theorem \(\ref{thm:main-fluid}\) are statistical performance guarantees for online policies. They do not classify a computational problem, establish polynomial-time solvability in an encoded input size, or give an approximation or parameterized algorithm. The paper’s “computationally efficient” claim is informal: \(O(\log\log T)\) fluid re-solves are counted, but bit complexity, dependence on \(n,L\), and dependence on the numerical input are not analysed. Under ChoCo’s stated anchor rule, that is decisive.

Even granting the proponent’s broader interpretation, the BIRT mirror is not a genuine population continuization of the paper’s contribution. The paper has a fixed list of \(n\) recipient coordinates and a stochastic process over resource-arrival vectors. The distribution \(P\) is a distribution over resources, not over a society; \(T\) is time, not population size. There is no discrete population parameter tending to high multiplicity.

Cloning each recipient into \(N\mu_a\) identical copies does not repair this. With one resource per period, equal per-capita allocation \(r_{t,a}\) satisfies
\[ N\sum_a\mu_a r_{t,a}=1. \]
As \(N\) grows, every individual’s utility and regret shrink like \(1/N\), so the unscaled limit degenerates. Scaling the supply to \(N\) resources per period avoids that collapse, but then setting \(x_{t,a}=Nr_{t,a}\) yields exactly the same finite weighted allocation problem for the \(\tau\) recipient categories. The population multiplicity disappears by normalization. This is a coherent rescaling, but it is not a high-multiplicity relaxation of a computational problem studied in the paper; it is a newly imposed weighted version of the same dynamic program.

The proposed BIRT LP also is not an automatic extension of the paper’s LP. Its feasibility condition is
\[ \sum_a\mu_a\xi_{\ell a}=1, \]
rather than \(\sum_i\xi_{\ell i}=1\). The paper’s thresholding proof relies on the latter simplex structure, bounded coordinates, and a residual assignment to one largest coordinate. In the weighted model, thresholding a small per-capita coordinate requires transferring weighted mass and adding the residual divided by \(\mu_a\); per-capita coordinates can be as large as \(1/\mu_a\). The sensitivity constants consequently depend on \(1/\mu_{\min}\), and can become arbitrarily bad as a type’s mass becomes small. A repaired proof may well exist for fixed finite support and fixed positive masses, but that would be a new weighted theorem, not a result anchored by BIRT.

The same problem defeats the fluid-policy anchor. Under the paper’s egalitarian objective, the natural continuous version is
\[ W_{-\infty}(B)=\min_{a:\mu_a>0}B(a), \]
so the masses do not enter the objective at all. For finite \(q\), replacing the paper’s welfare by
\[ W_q(B)=\left(\sum_a\mu_a B(a)^q\right)^{1/q} \]
is mathematically natural, but it changes the welfare metric. The proposed result would then be a weighted concentration-and-smoothness extension of the paper’s proof, not a computational question about a continuous society. Again, the paper supplies neither a complexity theorem nor a population-level algorithmic object to mirror.

The better alternatives do not rescue the case. A genuinely diffuse recipient space would require an encoding of measurable utility functions and an infinite-dimensional optimization model; the finite-support paper provides neither. If the diffuse space is represented by finitely many regions, it collapses back to the finite-type construction above. If one adds type-dependent budgets, eligibility, indivisible bundles, mass transfers, or population-dependent costs to obtain a real complexity landscape, one has created a new allocation problem rather than continuized this paper.

The positive case is therefore not mathematically incoherent: a finite-support, per-capita, weighted recipient model is plausible and may admit a BIRT-style theorem. But it is an unanchored extension of a stochastic-optimization paper, not a worthwhile continuous computational-social-choice mirror of one of its named results. Under the programme’s computational-anchor requirement, neither proposed anchor survives.
