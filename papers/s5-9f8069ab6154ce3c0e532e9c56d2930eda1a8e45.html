The continuous mirror question

Given positive rational type masses \(\mu_1,\ldots,\mu_\tau\) summing to \(1\), a rational query state \(x\in\prod_t[0,\mu_t]\), rational polynomial vector fields \(f_t\) on that box, and rational \(\epsilon>0\), compute each type’s allocation \(u_t(x)-u_t(0)\) to additive error at most \(\epsilon\). Here \(u_t\) is the mean-zero solution of \(-\Delta u_t=-\nabla\cdot f_t\) with Neumann boundary condition and the compatibility condition \(\int_\Omega\nabla\cdot f_t=0\); the aggregate allocation to type \(t\) is \(\mu_t(u_t(x)-u_t(0))\).

The model it lives in

A cooperative project has a continuum of participation states \(x\in\Omega=\prod_{t=1}^{\tau}[0,\mu_t]\), with interchangeable contributors grouped by type. Each type has a marginal-value flow \(f_t\); the allocation at a state is obtained from its Poisson potential \(u_t\), and its aggregate share is scaled by \(\mu_t\). The computational task is to approximate those allocations from compact flow descriptions.

The case FOR (proponent)

The credible positive case is concentrated on Theorem 10. It is proved in the paper, not cited: for a reversible Markov chain on a connected, weighted finite graph, the expected signed path integral of an edge flow \(f_i\), from the initial state \(O\) until the first visit to each state, uniquely solves the graph Poisson equation \(L\Phi_{f_i}=d^*f_i\), with \(\Phi_{f_i}(O)=0\). The paper then computes the allocation by solving that linear system. This is an algorithmic anchor, though the theorem gives no complexity classification; solving a system polynomial in the *explicit graph size* may still be exponential in the number of players when the coalition graph has \(2^n\) states.

My lead mirror is the *Continuous Hodge–Shapley Allocation Problem*. Consider a large cooperative project with many small suppliers or contributors, grouped into \(\tau\) types. A type records everything relevant to participation and payout: role, technology, contract, and marginal-contribution rule. Agents within a type are interchangeable. Let \(\mu_t\) be type \(t\)’s fraction of the population, and let \(x_t\in[0,\mu_t]\) be the participating mass of that type. The project’s coalition states are therefore points in \(\Omega=\prod_{t=1}^{\tau}[0,\mu_t]\), rather than subsets of named individuals. The population is the continuous object; the values being allocated can remain ordinary real numbers.

Give each type a smooth marginal-value flow \(f_t\) over infinitesimal changes in coalition composition. Let coalition composition evolve by reflected Brownian motion on \(\Omega\), a reversible continuous-state counterpart of the paper’s random walk. Define the allocation potential \(u_t\) by the Neumann Poisson problem \(-\Delta u_t=-\nabla\cdot f_t\), with \(\partial_nu_t=0\) on the boundary and \(\int_\Omega u_t(x)\,dx=0\). The per-person allocation at state \(x\) is \(\Phi_t(x)=u_t(x)-u_t(0)\); the type’s aggregate allocation is \(\mu_t\Phi_t(x)\). Thus the question is: given rational type masses, polynomial descriptions of the flows, and a rational query state \(x\), compute \(\Phi_t(x)\), or approximate it within \(\epsilon\). A natural efficient-project condition is \(\sum_t\mu_tf_t=\nabla V\), where \(V\) is project value; then \(\sum_t\mu_t\Phi_t(x)=V(x)-V(0)\), so the continuous allocation remains efficient.

This is a plausible extension of the authors’ problem because they already extend the coalition hypercube to general cooperative networks and allow arbitrary edge flows. Here infinitesimal changes of type mass replace graph edges, and the Poisson equation becomes an elliptic PDE. In a discrete project with \(n_t\) members of each type, coalition states are the mass lattice \(x_t=r_t/n\); with fixed \(\tau\), these lattices fill \(\Omega\) as multiplicities grow. The continuous calculation could therefore replace an increasingly large state graph with a fixed-dimensional Poisson problem. For fixed \(\tau\) and controlled smoothness, I would expect approximation to be tractable using standard numerical methods, with running time polynomial in the input description and \(\epsilon^{-1}\), but with a dependence on \(\tau\) that may grow sharply. Variable-\(\tau\) complexity, and whether it becomes continuum-specifically hard, are open questions this mirror would generate.

My weakest point is that the paper’s formula uses first visits to individual states, while a diffusion in dimension greater than one does not generally hit a specified point. So this mirror defines the continuous allocation through its Hodge–Poisson potential; it does not claim that the same point-target path-expectation formula carries over unchanged. Showing that the PDE allocation arises as a suitable limit of discrete path allocations would be an important part of the research. The mirror covers Theorem 10’s computational allocation result only; it does not continuize the paper’s axiomatic characterizations.

The case AGAINST (opponent, writing after the proponent)

The strongest objection is to the claimed anchor’s reach. Theorem 10 is genuinely computational: it identifies the expected path allocation on a finite reversible graph with a solution to a weighted graph Poisson equation. But it gives no complexity bound in the number of players, type count, or input bit length. Its linear system is tractable in the *explicit graph size*; for the coalition graph that size is \(2^n\). The theorem therefore supports efficient calculation when the state graph is already listed, not a result about computation from a compact, high-multiplicity population description.

The proposed diffusion mirror changes that computational object. In the paper, the allocation is an expectation up to the first visit to a particular state. A diffusion in dimension at least two will generally not hit a specified point, as the proponent acknowledges. Defining the mirror instead by a Neumann Poisson problem is natural, but the paper does not derive that problem as a limit of its allocations. It also does not supply the mirror’s new input model: how smooth flows are encoded, what regularity is promised, or how complexity depends on dimension and approximation accuracy. Until those choices are justified, this is a plausible new PDE allocation problem, not yet a continuization of Theorem 10’s computational result.

The strongest repair is to group interchangeable agents into \(\tau\) types, aggregate coalition states to a mass lattice, and scale type-level flows so the lattice Poisson systems might converge to a PDE. That is a coherent high-multiplicity regime, and it could yield useful algorithms for smooth, compactly represented flows. But the paper allows arbitrary player-specific edge flows; neither smoothness nor a compact type-level description follows from its assumptions. The repair therefore depends on a substantial, scenario-specific restriction.

That makes the negative case limited. Theorem 10 does not establish a population-complexity question, and the proponent has not shown that their PDE allocation is its limit. But a homogeneous, smooth project model could still be sensible and worth studying. I cannot honestly conclude that no worthwhile mirror exists in any scenario; the case against is strongest as a challenge to this particular anchor’s fidelity and generality.
