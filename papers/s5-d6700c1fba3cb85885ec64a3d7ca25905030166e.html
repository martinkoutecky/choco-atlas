The continuous mirror question

Given τ complete types with rational masses μ, survival probabilities r_t, and a monotone differentiable value function g with g(0)=0 and range [0,1], consider replicated games whose coalition value is g(q(C)/n), where q_t(C) counts type-t agents and n is the population size. Under independent type-level survival, compute the limiting aggregate Shapley payoff of each type. In the smooth case, is the limit Φ_t=μ_t r_t∫_0^1 ∂_t g(λ(r⊙μ))dλ, and can all Φ_t be approximated within additive error ε with probability at least 1-δ in time polynomial in τ, the input bit length, 1/ε, log(1/δ), and the oracle cost, given a known polynomially bounded envelope for the marginal integrands?

The model it lives in

A nonatomic reliability cooperative game with type masses μ, survival probabilities r, coalition value G_r(x)=g(r⊙x), and Aumann–Shapley type allocations Φ_t=μ_t∫_0^1 ∂_tG_r(λμ)dλ.

Open questions for a prover

The case FOR (proponent)

My strongest mirror is for Corollary 1, proved in this paper. It says that for a simple cooperative game \(H=(N,v)\), if \(v(C)\) can be computed in polynomial time for any coalition \(C\), then the Shapley value of any agent in its reliability extension can be approximated in polynomial time. The paper’s Theorem 2, also proved here, gives the guarantee: with \(k\ge \frac{\ln(2/\delta)}{2\epsilon^2}\) independent samples, the estimate lies within \(\epsilon\) of the true value with probability at least \(1-\delta\). The network reliability problem’s \(\#\mathrm P\)-hardness appears as a citation in the prose, not as a numbered result of this paper, so I would not use it as an anchor.

The mirror is a fluid reliability power problem. Let \(T\) be a finite set of complete agent types: agents of a type have the same role in the cooperative task and the same survival probability. A society is a rational mass vector \(\mu\in\mathbb{Q}_{\ge 0}^{T}\), with \(\sum_t\mu_t=1\). A coalition is a submass vector \(x\le\mu\), and its base value is given by a monotone, differentiable function \(g:[0,\mu]\to[0,1]\), with \(g(0)=0\). Assume the value and gradient of \(g\) are efficiently computable. Type \(t\) survives with probability \(r_t\). In the continuum, independent failures produce surviving mass \(r\odot x\), so the reliability value of coalition mass \(x\) is \(G_r(x)=g(r\odot x)\).

The requested output is the type-level allocation
\[ \Phi_t(\mu,r)=\mu_t\int_0^1\frac{\partial G_r}{\partial x_t}(\lambda\mu)\,d\lambda =\mu_t r_t\int_0^1\partial_t g(\lambda(r\odot\mu))\,d\lambda. \]
This is the continuous Shapley analogue I would ask a prover to study: each \(\Phi_t\) is the aggregate allocation to type \(t\), and the allocations sum to the grand coalition’s value. Under the natural normalization that each sampled marginal contribution lies in \([0,1]\), sample \(\lambda\) uniformly from \([0,1]\), evaluate the gradient, and average the resulting contributions. Hoeffding’s inequality and a union bound give simultaneous error at most \(\epsilon\) for all \(\tau=|T|\) types with probability \(1-\delta\) using \(k\ge \frac{\ln(2\tau/\delta)}{2\epsilon^2}\) samples. I expect this stated problem to be tractable in randomized polynomial time in \(\tau\), the input bit length, \(1/\epsilon\), \(\log(1/\delta)\), and the oracle cost.

A plausible regime is a large infrastructure or service cooperative with many exchangeable units—such as links replicated across regions—in a handful of functional roles and reliability tiers. The mass is the fraction of units of each role; the population size is much larger than the number of types. This requires the coalition value to depend on those type masses, with a smooth fluid limit. The authors would have reason to recognize the mirror: the paper studies reliability games, and its limited-reliability-games discussion in §5.2 already uses a constant number of agent types and survival probabilities. That section supports the regime, though it is not my numbered anchor.

The mirror covers the paper’s Shapley-approximation result, not its core results or every network-reliability instance. Its weakest point is also substantial: a continuum of independently failing agents has deterministic surviving mass by the law of large numbers, and the per-agent Shapley value disappears. The proposed question therefore uses a type-level Aumann–Shapley allocation and assumes a smooth mass-value function. For a literal binary connectivity game, the limit may be discontinuous or retain important topology that type masses lose. So this is a credible mirror for repeated, exchangeable systems with a smooth aggregate value—not a claim that arbitrary network reliability instances continuize directly. The next questions are whether discrete Shapley allocations converge to this allocation under useful conditions, what happens at threshold boundaries, and whether value-oracle access alone suffices when gradient access is unavailable.

The case AGAINST (opponent, writing after the proponent)

Corollary 1 is a genuine computational result, so “there is no result to mirror” does not work here. The problem is that the proposed mirror changes what the result computes. In the paper, the base game is simple: a coalition either wins or loses. For a game whose value depends only on type masses, its faithful continuum base value is therefore an indicator of a winning region, not a smooth function \(g\). As the population grows, independent failures make surviving mass concentrate at its expectation; they do not smooth that indicator. The proposed derivative integral is then undefined at winning boundaries and zero almost everywhere. Giving \(g\) and its gradient as efficient oracles makes the calculation routine, but does not recover the paper’s simple-game Shapley problem.

The more faithful candidate is the limit of the *aggregate* Shapley allocation to each type in a count-based simple game. But mass data alone need not determine that limit. Take one type with \(n\) agents, let a coalition win at size \(q_n=\lceil n/2+a\sqrt n\rceil\), and let each agent survive with probability \(1/2\). For every fixed \(a\), the continuum winning region is the same: mass at least \(1/2\). Yet the reliability value of the grand coalition tends to \(1-\Phi(2a)\), so it varies with \(a\). With one type, its aggregate Shapley allocation equals that grand-coalition value. The mass-level game has discarded information needed to determine the result; retaining it requires a finite-population boundary scale.

Away from such boundaries, the limiting reliability value is typically just zero or one, while each individual Shapley value vanishes with population size. A two-scale analysis of aggregate pivotality might still be useful, but it would be a different question from the proposed smooth fluid model, and its answer depends on details that the continuous mass input omits.

That is the strongest case against this anchor: the stated mirror is not faithful, and the faithful mass-only version loses information precisely where the reliability Shapley allocation is nontrivial. I would not claim the universal negative is established, though. Section 5.2 makes typed, few-type games a credible regime, and a carefully specified asymptotic boundary problem could be worthwhile. I can reject this proposed mirror more confidently than I can rule out every continuous mirror of Corollary 1.
