The case FOR (proponent)

The strongest positive case is for a high-multiplicity version of computing the Rawlsian assignment. The paper’s sole named computational item is Algorithm 1, “Computing the Rawlsian assignment.” It computes the unique Rawlsian assignment using at most \(n^2(n+1)/2\) linear programs: at each rank cutoff, it minimizes the largest probability of receiving an object at or below that cutoff, then tests which agents’ probabilities are forced at that level, fixes them, and continues to the next level. The paper has no numbered Theorem, Lemma, Corollary, or Proposition asserting a complexity result. So Algorithm 1 is my only possible anchor; under a rule requiring a theorem-style anchor, there is no qualifying anchor.

A plausible regime is a large housing allocation across a city or agency: many households, but relatively few distinct preference types over standardized apartment categories. A type must include the household’s complete ranking and any other feature the allocation problem uses. Each category has a per-capita supply, and copies within a category must be interchangeable to the households. That co-modification is material, but it keeps the underlying question recognizable: assigning one indivisible apartment to each household while limiting how badly off the worst-off households are.

Here is the continuous problem. Let \(O\) be a finite set of apartment categories, and let \(T\) be the supported strict rankings of those categories. The input gives each type a rational mass \(\mu_t>0\), with \(\sum_{t\in T}\mu_t=1\), and each category a rational supply \(q_o\ge 0\), with \(\sum_{o\in O}q_o=1\). Choose masses \(y_{to}\ge0\) such that \(\sum_o y_{to}=\mu_t\) and \(\sum_t y_{to}=q_o\). Each household of type \(t\) then receives lottery \(x_{to}=y_{to}/\mu_t\); in an individual realization, the household still gets one indivisible apartment.

For cutoff \(k\), define the type’s probability of receiving an apartment ranked \(k\) or worse as
\[ \beta_t(k)=\sum_{o:\,r_t(o)\ge k}x_{to}. \]
Let \(Q_k(u)\) be the non-increasing quantile function of these probabilities across the population: type \(t\) contributes mass \(\mu_t\) at value \(\beta_t(k)\). Weighted-Quantile Rawlsian Assignment\(_\infty\) asks for a feasible \(y\) whose sequence \((Q_{|O|},Q_{|O|-1},\ldots,Q_2)\) is lexicographically minimal, comparing each step function from its worst-off mass downward. Equivalently, within each cutoff, compare the sorted probability levels and the mass occupying each level. This carries the paper’s priority order—first the worst rank, then the next rank cutoff—into a society represented by type masses.

My forecast is Class A. The paper’s sequential LP method appears to extend: work with one allocation row per supported type, retain the rational type masses and category supplies in the feasibility constraints, and at each cutoff identify which types are forced to the current worst probability before continuing. That suggests a polynomial-time algorithm in \(|O|\), \(\tau=|T|\), and the input bit length \(L\), using LPs with polynomial-size descriptions. This would mirror only Algorithm 1’s computation of the Rawlsian assignment; it does not extend the paper’s claims about incentives, envy, empirical comparisons, or large-market rank bounds.

The scenario has a credible high-multiplicity story—for example, \(100{,}000\) households but a few dozen recurring rankings over genuinely interchangeable apartment categories. The weakest point is that the paper ranks individual agents, while this mirror ranks a population quantile of type-level probabilities. The weighted quantile is the natural way to retain the finite ordering when types have different masses, but the authors and a referee would need to accept that extension. Also, the paper’s own cooperatives have only 4–42 families; they motivate the allocation problem, but they are not themselves the large-population regime.

The case AGAINST (opponent, writing after the proponent)

The best case against is that Algorithm 1 is the paper’s only serious computational anchor. The numbered propositions mostly establish properties of the rule, and the large market result is an asymptotic bound, not a complexity classification. Algorithm 1 computes the rule by repeatedly solving linear programs over a finite assignment polytope.

Scaling the population while keeping the paper’s objects fixed is impossible: there must be one object per agent. The proposed mirror therefore also scales object supply and groups interchangeable apartments into categories. That is a meaningful extension of the setting. The paper ranks preferences over distinct apartments; the mirror ranks preferences over categories. Its computational result would concern a capacitated category market, not the paper’s original assignment problem. And while a large city may have many households, the assumption that they share a small set of complete rankings over genuinely interchangeable categories deserves scrutiny.

That objection does not defeat the strongest version of the mirror. With category supplies scaled alongside the population, the authors could plausibly recognize the model as an assignment problem. For rational masses, one can expand the instance into repeated types and objects; the weighted quantile objective then reproduces the paper’s ordering of individual probabilities. Conversely, an aggregate LP could avoid expanding a potentially enormous market and run in terms of the number of categories, supported rankings, and input bit length. That is a coherent high-multiplicity computational question.

So the negative case is weak. The proposed mirror changes the market in a material but permitted way, and its algorithmic content may be a fairly direct extension of Algorithm 1. I cannot honestly argue that no worthwhile continuous mirror exists: the assumptions about categories limit its reach, but the aggregate allocation question survives them.
