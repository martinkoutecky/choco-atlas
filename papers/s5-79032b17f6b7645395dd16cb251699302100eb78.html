The continuous mirror question

Given a finite set of \(d\) policies, \(k\) criteria, evaluator types \(t\) specifying a complete ranking of the policies on every criterion, and rational masses \(\mu_t\) summing to \(1\), form \(P^\mu_j(a,b)=\sum_t\mu_tQ^t_j(a,b)\). Given a valid target set \(S\), an \(\ell_q\) norm, and \(\epsilon>0\), compute \(\pi\in\Delta_d\) such that \(\max_{\pi'\in\Delta_d}\operatorname{dist}_q(P^\mu(\pi,\pi'),S)\le\min_{\hat\pi\in\Delta_d}\max_{\pi'\in\Delta_d}\operatorname{dist}_q(P^\mu(\hat\pi,\pi'),S)+\epsilon\).

The model it lives in

The society is a distribution \(\mu\) over complete evaluator preference profiles. Its mass-weighted pairwise preferences \(P^\mu\) determine the Blackwell objective; the decision variable is a randomized policy \(\pi\), which minimizes worst-case distance from \(S\) over comparison policies \(\pi'\). Proposition 5 supplies an approximation algorithm using a target-set distance oracle, after forming \(P^\mu\).

The objection that survived

The objective depends only on the aggregate tensor \(P^\mu\), so the profile masses add no profile-sensitive computational content and Proposition 5 already handles the resulting tensor.

fatal: False

What the mirror covers

The mirror covers Proposition 5’s approximation guarantee after constructing \(P^\mu\) from the type masses. It leaves the paper’s sample-complexity bounds, statistical lower bounds, and user-study results outside the mirror.

Open questions for a prover

  • Can the approximation guarantee be implemented with polynomial bit complexity for rational masses and an explicit polyhedral \(S\), including dependence on the input bit length?

The case FOR (proponent)

My strongest case is a mass-based version of the paper’s Blackwell-winner approximation problem. The type is an evaluator’s complete preference profile: for each of the \(k\) criteria, a ranking of the \(d\) policies. The mass \(\mu_t\) is the fraction of evaluators with profile \(t\). Thus a large panel of riders evaluating a small menu of driving policies might have \(n\) evaluators but only \(\tau\) recurring preference profiles, with \(n\gg\tau\).

For each type \(t\), let \(Q^t_j(a,b)\) be \(1\) if that type ranks policy \(a\) above \(b\) on criterion \(j\), \(0\) if it ranks \(b\) above \(a\), and \(1/2\) on the diagonal. The population preference tensor is
\[ P^\mu_j(a,b)=\sum_{t=1}^{\tau}\mu_t Q^t_j(a,b). \]
Given a valid target set \(S\) and an \(\ell_q\) norm, define
\[ V_\mu(\pi)=\max_{\pi'\in\Delta_d} \operatorname{dist}_q\!\left(P^\mu(\pi,\pi'),S\right), \qquad P^\mu_j(\pi,\pi')=\sum_{a,b}\pi_a\pi'_bP^\mu_j(a,b). \]
The named problem is Mass-Blackwell-Winner Approximation: given the policies, criteria, type profiles and rational masses, \(S\), \(q\), and \(\epsilon>0\), output \(\pi\in\Delta_d\) such that
\[ V_\mu(\pi)\le \min_{\hat\pi\in\Delta_d}V_\mu(\hat\pi)+\epsilon. \]
Here the randomized policy \(\pi\) is the paper’s existing decision variable; the population continuization is the evaluator mass vector \(\mu\).

My lead anchor is Proposition 5 (Appendix D.2.1), proved in the paper by applying a result of Shamir (2017). It states that, for a valid target set \(S\) and an \(\ell_q\) distance, running the paper’s zeroth-order algorithm for \(T\) iterations with step size \(\eta_t=c/(k^{1/q}\sqrt{dT})\) and smoothing radius \(\delta=c\log d/\sqrt{T}\) gives an average policy \(\bar\pi_T\) satisfying
\[ V(\bar\pi_T)\le \min_{\pi\in\Delta_d}V(\pi) +c\,k^{1/q}\sqrt{\frac{d\log^2 d}{T}}. \]
Consequently, the stated guarantee is reached in \(O(k^{2/q}d^2\log^2 d/\epsilon^2)\) calls to the target-set distance oracle. This is an algorithmic approximation result, rather than an NP-hardness result; the paper gives no comparable named hardness anchor. For the mass mirror, constructing \(P^\mu\) from the explicit type list takes \(O(\tau d^2k)\) arithmetic operations, after which the proposition’s optimization guarantee applies.

I expect this stated approximation problem to be Class A in the paper’s oracle model: its objective has the convexity and Lipschitz properties needed by the algorithm. The scenario is plausible because it keeps the paper’s policies, criteria, target set, worst-case comparison, and Blackwell objective intact. The panel’s preference profiles are simply supplied as type masses rather than hidden behind samples. A useful next question is whether explicit polyhedral descriptions of \(S\) yield a polynomial bit-complexity guarantee, including dependence on the masses’ bit length, rather than only the oracle-relative iteration bound. Others include how finite-population rounding affects the guarantee and how much the ranking-type restriction limits the preference tensors that can be represented.

The soft spot is substantial: the paper already models pairwise preferences as population probabilities and computes the Blackwell winner from the aggregate tensor \(P\). So this mirror is strongest as an explicit high-multiplicity input model—few evaluator types with known masses—not as a claim that the paper lacked any population-level formulation. If its existing probabilistic model is judged to already be the continuous-population problem, this risks being a restatement. The narrower distinction is that the mirror makes coherent evaluator profiles and their masses the input, whereas the paper works directly with a preference tensor and, for its learning results, samples of pairwise comparisons.

The case AGAINST (opponent, writing after the proponent)

The strongest objection is that Proposition 5 already operates on the population-level object the proposed mirror would construct. In Section 3.1, each pairwise response is a draw from an underlying population distribution, and \(P_j(a,b)\) is its probability of preferring \(a\) to \(b\). The Blackwell objective and Proposition 5 take that preference tensor as input. For evaluator types with masses \(\mu_t\), the proposed construction gives \(P^\mu_j(a,b)=\sum_t\mu_tQ^t_j(a,b)\); after this aggregation, the type distribution no longer appears in the objective. Any two evaluator populations producing the same tensor yield the same optimization problem and the same guarantee.

A panel with many evaluators and few recurring preference profiles is a plausible high-multiplicity regime. But it makes this mirror a re-encoding of the paper’s existing problem: construct \(P^\mu\), then apply Proposition 5, which already covers arbitrary preference tensors. Computing the tensor from the listed profiles costs \(O(\tau d^2k)\) arithmetic operations. The paper states oracle iteration complexity rather than a full bit-complexity bound, but seeking a sharper bound for rational inputs would refine the computational analysis of its existing problem; the evaluator masses do not create that question.

The more promising way to make masses affect the answer would be to impose group-specific guarantees—for example, require acceptable performance for each evaluator type, or optimize a trade-off across subpopulations. That could be a worthwhile extension, but it changes the aggregate Blackwell-winner objective: the relevant score would now retain group-level information that the paper’s tensor deliberately collapses. It is not a new population formulation of Proposition 5. A model of evaluator-level correlations in the sampled data could also be interesting, but that changes the observation model and statistical question rather than supplying a distinct computational mirror.

So the proponent’s caveat is the main case against the mirror: the population interpretation is sensible, yet the paper already formulates and computes from the sufficient aggregate probabilities. I cannot rule out a useful type-compressed algorithm or a profile-sensitive extension. Those are the honest openings in the negative case; neither currently shows that the proposed mass-based winner problem adds a new continuous-population complexity question.
