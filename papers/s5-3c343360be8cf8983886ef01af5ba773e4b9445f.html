The continuous mirror question

Given a cycle \(C_n\) and a partition \(V_1,\ldots,V_m\), find rational weights \(\lambda_I\geq 0\) over independent sets \(I\) of \(C_n\) such that \(\sum_I\lambda_I=1\) and \(\sum_I\lambda_I|I\cap V_i|\geq |V_i|/2-1\) for every \(i\).

The model it lives in

A continuum of repeated cycle copies with the same partition and conflict pattern. Each unit receives an integral independent set \(I\subseteq V(C_n)\); the rational weights \(\lambda_I\) give the population shares receiving each set, and fairness is imposed on the population averages.

The objection that survived

The paper studies one cycle and gives no application for pooling fairness across repeated cycles; the proposed population setting must supply that motivation.

fatal: False

What the mirror covers

The mirror covers Theorem 1.3. It leaves the fair-splitting results, approximate variants, and Schrijver-graph result untreated.

Open questions for a prover

  • How many finite copies suffice to realize or approximate a feasible distribution while preserving the group quotas?
  • What complexity returns if every cycle copy must satisfy the fairness bounds individually?

The case FOR (proponent)

My lead is a mass version of Theorem 1.3. That theorem says that Fair Independent Set in Cycle—given a cycle \(G\) and a partition \(V_1,\ldots,V_m\) of its vertices, find an independent set \(S\) with \(|S\cap V_i|\geq |V_i|/2-1\) for every \(i\)—is \(\mathrm{PPA}\)-complete. The paper proves this result: its hardness argument uses a reduction from the cited Consensus Halving hardness result, and its membership argument reduces the search problem to Octahedral Tucker.

A plausible high-multiplicity setting is many repeated copies of the same cyclic arrangement: for example, repeated rounds of a circular assignment in which the roles, group labels, and neighbor-role pattern are the same each time. With \(M\) copies of an \(n\)-role cycle, the population has \(Mn\) agents but only \(n\) role types, so \(N/\tau=M\). A type records a role’s group and its position in the cyclic conflict pattern; the copy identifier carries no other information used by the problem.

Call the resulting problem Mass-Fair-IS-Cycle. Its input is \(C_n\) and the partition \(V_1,\ldots,V_m\). There is a continuum of copies indexed by \(x\in[0,1]\); each type \(v\in V(C_n)\) has normalized mass \(1/n\), and each copy has the original cycle’s conflicts. A solution is a measurable family of independent sets \(S_x\subseteq V(C_n)\), independent for almost every \(x\), such that for every group \(i\),
\[ \int_0^1 \frac{|S_x\cap V_i|}{n}\,dx \;\geq\; \frac{|V_i|}{2n}-\frac{1}{n}. \]
The slack is one role’s mass per copy, preserving the paper’s “half minus one” guarantee at the repeated-motif scale. Equivalently, output rational weights \(\lambda_I\geq 0\) over independent sets \(I\) of \(C_n\), with \(\sum_I\lambda_I=1\) and \(\sum_I\lambda_I|I\cap V_i|\geq |V_i|/2-1\) for every group. A weight \(\lambda_I\) means that fraction of the population’s copies receives the integral set \(I\). Thus no individual copy receives a fractional independent set; fairness is required across the continuous population.

I expect this mirror to be tractable. The weights form a linear program with one variable per independent set. Its pricing problem is maximum-weight independent set on a cycle, solvable by dynamic programming, so separation and the rational LP can be handled in polynomial time in \(n,m\), and the input bit length. A feasible solution is guaranteed by the paper’s existence theorem: any one fair independent set gives a feasible distribution concentrated on that set. A basic solution needs at most \(m+1\) independent sets in its support. This is a Class A candidate: continuous optimization finds a population-wide fair allocation even though the paper’s task of finding one fair set is \(\mathrm{PPA}\)-complete.

The mirror covers Theorem 1.3 only. It raises useful follow-on questions: how many finite copies suffice to round a continuous distribution while preserving the fairness bounds, and how much complexity returns if each copy must be fair on its own?

The weak point is substantive: the paper asks for one fair set on one cycle; this problem asks for aggregate fairness across many repeated cycles. The population regime is plausible, and the mass solution keeps each copy’s choice integral, but an author or referee could still judge this a high-multiplicity variant rather than the continuous analogue of the paper’s exact search problem.

The case AGAINST (opponent, writing after the proponent)

FISC is a genuine computational anchor: Theorem 1.3 proves a search problem is \(\mathrm{PPA}\)-complete. The difficulty for a continuous mirror is finding a population in the model. In the paper, cycle vertices are positions in one constraint graph; a vertex’s neighbors depend on its exact position, and the partition into groups is arbitrary. In a single cycle, recording position and group gives \(n\) types, each appearing once. Merging positions to create multiplicity loses the adjacency structure that defines the problem.

Repeating whole cycles preserves that structure, and the proponent’s model is coherent as a repeated-batch allocation problem. But the two natural fairness requirements lead to different tasks. Requiring each cycle to be fair leaves the original search problem in every cycle. Requiring fairness only across cycles permits one cycle’s choices to compensate for another’s. The proposed condition,
\[ \mathbb{E}\!\left[|S\cap V_i|\right]\geq |V_i|/2-1, \]
is exactly the second task: a distribution over integral independent sets can meet every group’s bound even when no set in its support meets all bounds. The cycle’s maximum-weight independent-set algorithm makes that pooled LP tractable, but its output need not provide the paper’s fair independent set. The polynomial algorithm therefore answers a different, convexified question.

The best version of the mirror still faces that choice. A distribution over configurations is a sensible model if the application is fairness across repeated batches. That application would need its own motivation: the paper studies one cycle, and its results do not identify repeated cohorts or pooled fairness as the underlying use case. Keeping the single-cycle guarantee preserves the paper’s task and its search difficulty. Allowing compensation across cycles creates a new task whose connection to the paper is the choice of constraint graph and group labels.

The other main results offer little help with the population interpretation. Fair splitting keeps the same tension between per-cycle and pooled guarantees. In the Schrijver-graph problem, the input is an arbitrary succinct coloring and the output must identify two particular disjoint sets; retaining those identities gives no evident small collection of repeated types.

This is a case against calling the proposed LP a worthwhile ChoCo mirror, not a proof that no useful scenario exists. Repeated circular scheduling could motivate the pooled problem independently, and that would make a credible algorithmic question. On the evidence in this paper, though, the negative case is strongest at the modelling gate: the only clear high-multiplicity construction repeats entire instances, while the faithful fairness guarantee leaves the original witness search intact.
