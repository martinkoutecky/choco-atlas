The continuous mirror question

Given a finite type set \(T\), rational masses \(\mu_t\), \(q\) recurring indivisible chore classes with rational per-capita supplies \(\rho_g\), and binary vectors \(a_t\in\{0,1\}^q\), output \(\lambda_{t,S}\ge0\) over integral bundle vectors \(S\in\mathbb{Z}_{\ge0}^q\) satisfying \(\sum_S\lambda_{t,S}=\mu_t\) and \(\sum_{t,S}S_g\lambda_{t,S}=\rho_g\), such that for every \(\lambda_{t,S}>0\), \(\lambda_{u,R}>0\), and \(g\) with \(S_g>0\), \(c_t(S-e_g)\le c_t(R)\), and the allocation is Pareto-optimal among feasible mass allocations, where \(c_t(S)=\sum_g a_{t,g}S_g\).

The model it lives in

A high-multiplicity binary-additive chores model with type mass \(\mu\), recurring per-capita supply \(\rho\), integral bundle configurations \(S\), mass variables \(\lambda_{t,S}\), additive costs \(c_t(S)=a_t\cdot S\), support-wise individual EFX, and Pareto dominance over feasible mass allocations.

The objection that survived

The strongest unresolved concern is that exact support-wise EFX is nonconvex, so rational scaling may produce a compressed discrete allocation problem without a demonstrated polynomial-size support or configuration representation.

The case FOR (proponent)

The strongest case is a high-multiplicity mirror of the paper’s binary-additive setting. The supplied paper contains no named NP-hardness result, so I would not invent a hardness anchor. Its strongest anchors are the positive existence-and-algorithm theorems.

Take \(q\) recurring chore classes \(G=\{g_1,\ldots,g_q\}\). For a population of normalized mass \(1\), let \(\rho_g\) be the per-capita supply of chore \(g\). Thus a finite realization with population \(N\) has \(N\rho_g\) distinct copies of \(g\). Copies remain indivisible: an individual receives an integral bundle \(S\in\mathbb{Z}_{\ge 0}^q\), although the population may split fractionally across bundles.

A type \(t\) is a complete cost description. In the additive-binary case it is a vector \(a_t\in\{0,1\}^q\), with

\[ c_t(S)=\sum_{g=1}^q a_{t,g}S_g. \]

The society is \(\mu=(\mu_t)_{t\in T}\), where \(\mu_t\) is the mass of type \(t\). An allocation is a mass assignment \(\lambda_{t,S}\), where

\[ \sum_S\lambda_{t,S}=\mu_t \quad\text{and}\quad \sum_{t,S}S_g\lambda_{t,S}=\rho_g \]

for every type \(t\) and chore class \(g\). Hence every unit of population receives an integral bundle; only the type-level frequencies \(\lambda_{t,S}\) are fractional.

The allocation is EFX if, whenever \(\lambda_{t,S}>0\) and \(\lambda_{u,R}>0\),

\[ c_t(S-\{g\})\le c_t(R) \]

for every \(g\) appearing in \(S\). This is the paper’s individual EFX condition, imposed almost everywhere on the continuum, not an expected-cost relaxation. Pareto optimality means that no other feasible allocation can weakly reduce the cost of almost every individual and strictly improve a positive mass. Equivalently for the lead case, one may minimize

\[ \operatorname{SC}(\lambda)=\sum_{t,S}\lambda_{t,S}c_t(S) \]

and then require EFX among social-cost minimizers.

This is a credible high-multiplicity regime for large task-rotation systems, municipal services, hospitals, or distributed workplaces: millions of workers perform a fixed catalogue of recurring tasks, while only a small number \(\tau\) of exact skill/disutility types occur. The relevant regime is \(N\gg\tau,q\), with many agents sharing each type. The type includes the entire cost function, so this does not incorrectly erase genuine heterogeneity.

My lead anchor is Theorem 3.1, proved in this paper. Its full content is: for every instance with additive cost functions and binary item costs \(c_i(e)\in\{0,1\}\), there is a polynomial-time algorithm that computes a complete allocation that is simultaneously EFX and Pareto-optimal.

The corresponding problem is:

\[ \textsc{EFX--PO--BinaryAdditive}_{\infty}. \]

Given rational type masses \(\mu_t\), rational per-capita chore supplies \(\rho_g\), and explicitly represented binary-additive type vectors \(a_t\), output a mass allocation \(\lambda\) satisfying the supply constraints, individual-bundle EFX, and Pareto optimality. The expected classification is Class A.

The reason is that the proof’s structure survives continuization. The paper separates chores into those that some agent can perform at zero cost and those that every agent necessarily pays for. In the continuum, the zero-cost chores can be routed as mass flows to compatible types, while unavoidable chores are balanced across the population. The paper’s reassignments move only zero-cost items and preserve social-cost minimality; in the mirror these become aggregate transfers between type-and-bundle states. The natural algorithmic question is whether this balancing can be implemented by a polynomial-size flow or configuration LP, perhaps with column generation.

The finite-to-continuous dictionary is exact for rational data. If \(N\) clears all denominators, then \(N\mu_t\) agents of type \(t\), \(N\rho_g\) chore copies, and \(N\lambda_{t,S}\) agents receiving bundle \(S\) realize the continuous solution. Conversely, every finite high-multiplicity instance induces \(\mu\), \(\rho\), and \(\lambda\). Thus this is not merely an analogy: it is the high-multiplicity version of the underlying allocation problem.

A second, broader anchor is Theorem 4.1, also proved here. It states that for cancelable cost functions with binary marginals, EFX allocations always exist and can be computed in polynomial time. It does not assert Pareto optimality.

Its mirror is:

\[ \textsc{EFX--Cancelable}_{\infty}. \]

The input is a finite-support type distribution \(\mu\), per-capita supplies \(\rho\), and one complete cancelable binary-marginal cost function \(c_t\) for each type, represented with the same kind of value or marginal access assumed by the finite algorithm. The output is a complete integral-bundle mass allocation \(\lambda\) satisfying EFX. The expected classification is again Class A, though less confidently than for the lead problem.

The paper’s two-phase proof is encouraging here. Phase 1 equalizes the cost of suitably chosen bundles across agents using cancelability; Phase 2 maintains EFX using residual submodular functions and only a bounded number of structural updates. In a high-multiplicity population, those updates should be performed in bulk on masses of agents rather than one named agent at a time. The main technical question is whether the resulting bundle-support description remains polynomial when the cost functions are supplied succinctly.

I would not claim that either theorem automatically proves its continuous analogue. Exact EFX is a support-wise, nonconvex condition: mixing two bundle types is harmless only if every pair in their supports satisfies the individual inequality. The weakest point is therefore the representation and algorithmics of \(\lambda\), especially for general cancelable functions and binary-encoded supplies. If the authors’ intended interpretation requires one-off chores with no repeated supply, the mirror is also much weaker; the proposed scenario depends on recurring chore copies, which is the necessary co-modification that makes a high-multiplicity population meaningful.

The mirror deliberately covers Theorems 3.1 and 4.1, not the whole paper. I would not stretch it to the partial-allocation guarantee of Theorem 5.1 without deciding how “at most \(n-1\) unallocated items” scales under per-capita supplies. Nor would I claim that Theorem 4.8 disappears: its EFX-versus-PO obstruction can plausibly persist with identical types and five chores per capita. That is a useful boundary question, not a reason to reject the mirror.

The case AGAINST (opponent, writing after the proponent)

The paper does contain genuine computational anchors, so the negative case cannot honestly begin by saying that it is merely axiomatic. The strongest objection is instead that EFX does not admit a nondegenerate continuous-population interpretation without either becoming vacuous or ceasing to be the paper’s problem.

For Theorem 3.1, keeping the finite chore set while making the agent population atomless makes the mirror degenerate. Only finitely many individuals can receive an indivisible chore, hence the set of nonempty agents has measure zero. Almost every agent has an empty bundle, and the paper’s EFX condition is explicitly vacuous for such agents. Pareto optimality concerns only finitely many exceptional assignments. There is no meaningful population-level fairness problem.

The proposed repair—scaling the number of chore copies with population size—is coherent, but it changes what the theorem is about. With recurring chore classes, an allocation is a distribution \(\lambda_{t,S}\) over integral bundles. EFX then requires

\[ c_t(S-\{g\})\leq c_t(R) \]

for every pair of bundle configurations in the support. This is a support-wise, nonconvex condition; averaging costs or bundles does not preserve it. If \(\mu\), \(\rho\), and \(\lambda\) are rational, clearing denominators turns the solution exactly into a finite EFX allocation for a sufficiently replicated instance. Thus the “continuum” does not relax the indivisibility or aggregate the fairness condition. It merely compresses a much larger discrete allocation.

Allowing fractional bundles would create an LP-like continuous problem, but that is precisely an outcome-space relaxation and no longer mirrors the paper’s EFX notion. Keeping integral bundles gives a legitimate high-multiplicity batching problem, but not the claimed continuous optimization problem. Moreover, in the binary-additive case Pareto optimality contributes almost nothing: all chores that someone can perform at zero cost should be assigned to such agents, while universally costly chores have fixed total cost. The only remaining issue is discrete bundle balancing under EFX. That may support a new high-multiplicity fair-division paper, but it is not a continuous population analogue generated by Theorem 3.1.

The same problem is sharper for Theorem 4.1. General cancelable costs are functions on subsets of individually identified chores. If repeated chore copies are collapsed into \(q\) classes, one must restrict to cost functions invariant under permutations of copies. That is a strict subclass of the paper’s cancelable functions, and the theorem’s generality has been discarded. If copies remain distinguishable so that arbitrary cancelable interactions are retained, then a type’s complete cost description grows with the replicated item universe; the finite type-space assumption disappears.

The proposed “same oracle model” does not repair this. The paper’s algorithm repeatedly constructs residual functions

\[ d_i(S)=c_i(S\mid A_i) \]

after assigning a different base bundle \(A_i\) to each named agent. In the population model, one type can be split across many base bundles, and each \((t,A)\) pair becomes a different residual state. There is no polynomial bound on these states in the paper, nor a representation of the resulting configuration space. Bulk execution of the two phases is therefore an unproved conjecture, not a consequence of Theorem 4.1. Replacing EFX by an expected-cost or type-average condition would yield a tractable-looking model, but it would no longer be the paper’s individual EFX guarantee.

The proponent’s rational-scaling dictionary establishes that the proposed models are formally definable; it does not establish that they are worthwhile mirrors. For this paper, the faithful fixed-inventory limit is vacuous, while the nonvacuous replicated-inventory limit preserves indivisible bundles and turns EFX into a compressed discrete feasibility problem. The cancelable case additionally loses either finite type descriptions or the theorem’s general cost-function domain.

This negative case is not airtight: a genuinely new polynomial algorithm for the additive high-multiplicity configuration problem would make that restricted mirror worthwhile. But the paper itself supplies no reason to expect such an algorithm, and the proposed cancelable mirror is not yet a well-specified continuation of the theorem. On the strongest reading, neither anchor currently supports a worthwhile continuous mirror; the additive one is the serious residual vulnerability.
