The continuous mirror question

Given finite type sets \(P\) and \(Q\), rational masses \((\alpha_p)_{p\in P}\) and \((\beta_q)_{q\in Q}\) each summing to \(1\), strict rankings of opposite-side types, a common strictly increasing rank disutility function \(d\), and a nonnegative nonincreasing rational piecewise-constant weight density \(\lambda\) on \([0,2]\), find a stable mass matching \(x\) minimizing its GGI. A feasible \(x\) has \(x_{pq}\ge 0\), row sums \(\alpha_p\), and column sums \(\beta_q\); it is stable when \(A_{pq}B_{pq}=0\) for every \((p,q)\), where \(A_{pq}=\sum_{q':q\succ_p q'}x_{pq'}\) and \(B_{pq}=\sum_{p':p\succ_q p'}x_{p'q}\). Its disutility measure is \(\eta_x=\sum_{p,q}x_{pq}(\delta_{d(\operatorname{rk}_p(q))}+\delta_{d(\operatorname{rk}_q(p))})\); minimize \(\int_0^2\lambda(s)D_x^\downarrow(s)\,ds\), where \(D_x^\downarrow\) is the nonincreasing quantile function of \(\eta_x\). Determine the computational complexity in the number of types and input bit length.

The model it lives in

Two nonatomic populations are represented by type masses \(\alpha_p\) and \(\beta_q\). Decision variables \(x_{pq}\) assign mass between types while preserving each type's mass; the no-blocking condition excludes type pairs with positive mass on both sides preferring each other to their assigned partners. The objective applies a continuous GGI to the resulting population measure of rank disutilities.

The objection that survived

There is no formal finite-to-mass dictionary showing that type-level ranks and split flows preserve the paper's named-agent stability structure; the proponent flags this as unresolved, so it limits predictions about hardness transfer.

What the mirror covers

The mirror covers Theorem 2's exact GGI optimization question. Theorem 3's approximation guarantee and the bounded-positive-weight XP result are not claimed to transfer.

Open questions for a prover

  • Does the type-level no-blocking feasible region have a polynomial-size or separation-based characterization in the number of types?
  • Is exact GGI minimization NP-hard as the type support grows, and can the paper's rotation gadgets survive split mass?
  • What finite-to-mass dictionary or approximation guarantee relates this model to finite markets with repeated preference profiles?

The case FOR (proponent)

The strongest mirror is the exact GGI stable marriage problem for two large populations with repeated preference types. Consider, for example, a centralized internship match with many applicants and positions: an applicant type records a complete ranking of position types, and a position type records a complete ranking of applicant types. Many people can share each type, with the same rank based disutility. A regime with tens of thousands of people but hundreds of distinct types is plausible when rankings depend on a relatively small set of publicly defined profiles. This is a claim about that kind of market, not about every stable marriage instance.

My anchor is Theorem 2, proved in this paper. It states that GGISM is NP-hard: given equal sized sets of men and women with complete preference lists, a nonincreasing GGI weight vector, and a common strictly increasing rank disutility function, finding a stable marriage minimizing the GGI of all agents’ disutilities is NP-hard. The proof reduces from the paper’s stated strongly NP-hard Minimum 2-Satisfiability problem. It builds one independent rotation per variable, so stable marriages correspond one to one with truth assignments. Decisive agents and added agents place clause related disutilities at controlled positions in the GGI ordering. Lemma 1 gives the recovery formula
\[ \left\lfloor\frac{\Delta_u-\GGI_{\boldsymbol{\lambda}}(\mathbf{d}(\mathbf{x}))}{n_c+1}\right\rfloor \]
for the number of unsatisfied clauses. Thus the GGI value encodes the clause count used in the reduction.

Here is a continuous problem that mirrors that optimization. Let \(P\) and \(Q\) be finite sets of applicant and position types. Each type has a strict ranking of the types on the other side; members of a type are interchangeable for preferences and disutility. Give each \(p\in P\) rational mass \(\alpha_p\), and each \(q\in Q\) rational mass \(\beta_q\), with \(\sum_p\alpha_p=\sum_q\beta_q=1\). The input also includes a common strictly increasing rank disutility function \(d\), and a nonnegative, nonincreasing, rational piecewise constant weight density \(\lambda\) on \([0,2]\).

A solution is a mass matching \(x_{pq}\geq0\), where \(x_{pq}\) is the mass of type \(p\) matched to type \(q\), with
\[ \sum_q x_{pq}=\alpha_p,\qquad \sum_p x_{pq}=\beta_q. \]
Every unit of mass gets one partner; \(x_{pq}\) can be fractional because it may describe different members of a type receiving different partner types. For each pair \(p,q\), define
\[ A_{pq}=\sum_{q':\,q\succ_p q'}x_{pq'},\qquad B_{pq}=\sum_{p':\,p\succ_q p'}x_{p'q}. \]
Require \(A_{pq}B_{pq}=0\). If both masses were positive, some members on each side could be paired and both would strictly prefer that match, so the pair would block. This gives a concrete no blocking condition for a continuum of agents.

The matching induces a disutility measure
\[ \eta_x=\sum_{p,q}x_{pq} \left(\delta_{d(\operatorname{rk}_p(q))} +\delta_{d(\operatorname{rk}_q(p))}\right), \]
of total mass \(2\). Let \(D_x^\downarrow(s)\) be its nonincreasing quantile function. The objective is to find a stable mass matching minimizing
\[ \int_0^2 \lambda(s)D_x^\downarrow(s)\,ds. \]
This is the population version of the paper’s GGI: with \(n\) people on each side, each assigned mass \(1/n\), taking \(\lambda(s)=n\lambda_i\) on the \(i\)-th interval of width \(1/n\) reproduces the discrete weighted sum. The fractional entries describe subpopulations with actual assigned partners, not a lottery over whole marriages.

I expect the unrestricted problem, with the number of types part of the input, to be continuum specifically hard (Class C). The paper’s variable and clause gadgets suggest that a substantial part of the difficulty lies in the structure of preferences and possible rotations, which the type model retains as the number of types grows. But Theorem 2 does not prove this: mass splitting may soften its binary rotation choices. A tractable description of stable mass matchings, combined with optimization of the quantile GGI, could instead yield a Class A result. That is a genuine question for this mirror, not an answer supplied by the paper.

The scope here is just Theorem 2’s exact optimization problem. I am not claiming that Theorem 3’s 2-approximation or the bounded-positive-weight XP result carries over.

The weak point is the change from strict rankings over named individuals to strict rankings over counterpart types, with members of one type interchangeable. That is natural for a repeated-profile market, but it coarsens the paper’s input, and the paper’s hardness reduction may lose force once a type’s mass can split. A useful first set of follow-up questions is whether the stable mass matchings have a tractable polyhedral description, whether hardness persists as support size \(\tau\) grows or even for fixed \(\tau\), and what exact or approximation relationship connects this mass problem to finite elections with type counts \(n_t\) and proportions \(\mu_t=n_t/n\).

The case AGAINST (opponent, writing after the proponent)

Theorem 2 is the one serious anchor: it is a named computational hardness result, so “there is nothing computational to mirror” does not work. The strongest case against it is that the paper’s input resists high multiplicity. Stability uses strict rankings of named partners, and the GGI charges each person according to their exact position in that list. Grouping partners into types erases those distinctions: the paper’s reduction, for example, uses dummy agents to put decisive agents at clause-specific ranks.

The proponent’s repair—rank counterpart types and allow mass to split—defines a coherent market, but changes those primitives. Members of a type become interchangeable in rankings, and \(A_{pq}B_{pq}=0\) rules out positive-mass blocks rather than preserving the paper’s test for every named pair. A stronger version could track rank by cumulative counterpart mass. That is also coherent, but it needs choices about rank scaling and how to represent priority within each type. Keeping exact priority profiles can make the number of types grow with the population; using type-level ranks returns to the coarsened model. The case against is that neither version yet supplies a clear high-multiplicity dictionary for Theorem 2.

Existing work on stable fractional matching studies computational welfare objectives, and continuum matching models establish natural large-market settings; neither settles this paper’s GGI objective ([stable fractional matchings](https://doi.org/10.1016/j.artint.2020.103416), [continuum matching markets](https://www.microsoft.com/en-us/research/publication/a-supply-and-demand-framework-for-two-sided-matching-markets/)). Those neighbors therefore do not make the mirror redundant.

This is a real modeling gap, but it does not establish that the mirror is unworthy. Large applicant and position cohorts with shared rankings make the type model plausible, and the resulting GGI optimization remains a computational question. The authors could reasonably recognize it as their problem. So the negative case is weak at its central point: it questions whether the proposed model preserves the paper’s exact rank structure, but cannot defeat the better type-level mirror.
