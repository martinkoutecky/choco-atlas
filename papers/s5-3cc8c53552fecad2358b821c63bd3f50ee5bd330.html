The continuous mirror question

Given types \(T\) with rational masses \(\mu_t\), goods classes \(Q\) with rational supplies \(\lambda_q\), values \(v_q\), capacity \(k\), and eligibility sets \(\Omega_t\), define coalition worth \(V(z)\) by maximizing \(\sum_{t,q}v_qx_{tq}\) subject to \(\sum_qx_{tq}\le kz_t\), \(\sum_tx_{tq}\le\lambda_q\), and \(x_{tq}=0\) when \(q\notin\Omega_t\). Let \(D_tV(z)=\lim_{\epsilon\downarrow0}(V(z+\epsilon e_t)-V(z))/\epsilon\) and \(H_t=\{t\}\cup\{s:\Omega_s\cap\Omega_t\ne\emptyset\}\). For \(u\in[0,1]\), set \(z^-_s(u)=z^+_s(u)=u\mu_s\) for \(s\in H_t\), set \(z^-_s(u)=\mu_s\) for \(s\notin H_t\), and set \(z^+_s(u)=0\) otherwise. Can one compute the exact endpoints \(L_t=\int_0^1D_tV(z^-(u))\,du\) and \(U_t=\int_0^1D_tV(z^+(u))\,du\), prove they bound \(\sigma_t=\int_0^1D_tV(u\mu)\,du\), and determine the running time in \(\tau=|T|\), \(|Q|\), input bit length, and maximum type-neighborhood size?

The model it lives in

A recurring allocation market represented by a finite set of worker types carrying masses \(\mu_t\), with goods-class supplies \(\lambda_q\) scaling with population. Coalition worth is the optimal value of an aggregate allocation LP over flows \(x_{tq}\); the target is each type's order-averaged marginal contribution and its neighborhood-based interval.

The objection that survived

The case defines the integral of directional derivatives as a replica-limit Shapley contribution but does not establish that this equals the limit of finite-replica Shapley values when the allocation LP value is nondifferentiable along the population path.

Open questions for a prover

  • When the LP value is nondifferentiable along the population path, does the defined integral equal the limit of finite-replica Shapley values, or should the continuum value be defined directly?

The case FOR (proponent)

The strongest honest case is narrow: Theorem 6, proved in this paper. It says that Algorithm 1 computes lower and upper bounds \(LB_i\) and \(UB_i\) on each agent’s Shapley value, with \(LB_i\leq\phi(i)\leq UB_i\), in time \(O(2^{|Neigh(i)|}|N|^3)\) per agent. Here \(Neigh(i)\) consists of agents who share a good with \(i\). This is a local-structure algorithm, not a claim that Shapley values are generally easy to compute. The paper’s #P-hardness statement is cited from earlier work, rather than proved in a numbered result here, so I would not use it as an anchor.

A plausible high-multiplicity setting is a large allocation market for recurring jobs or service slots. There may be millions of workers but only a few dozen or hundred complete eligibility profiles. A type records the worker’s eligibility and capacity; everyone of that type is identical for the game. Goods are repeated classes of opportunities, with a value and a supply per unit of population. This is not the VQR experiment itself: its one-off publications and author-specific links make that a weak high-multiplicity regime.

Here is a concrete mirror, which I would call Type-Mass Shapley Bounds for Allocation Games. Its input is a finite type set \(T\), rational masses \(\mu_t\geq0\) summing to \(1\), a finite set \(Q\) of good classes, rational per-capita supplies \(\lambda_q\), values \(v_q\), and a capacity \(k\). Each type \(t\) has an eligibility set \(\Omega_t\subseteq Q\). For a coalition with type-mass vector \(z\), define its worth as the optimum of the allocation LP with variables \(x_{tq}\geq0\): maximize \(\sum_{t,q}v_qx_{tq}\), subject to \(\sum_qx_{tq}\leq kz_t\), \(\sum_tx_{tq}\leq\lambda_q\), and \(x_{tq}=0\) when \(q\notin\Omega_t\). The quantities \(x_{tq}\) are aggregate assignments. They can be fractional even though each individual still receives an integral bundle of at most \(k\) goods; goods and population both scale in the replicated market.

The value to compute is the replica-limit Shapley contribution. In a finite replication, put \(N\) agents into the market, with \(N\mu_t\) agents of type \(t\) and \(N\lambda_q\) goods of class \(q\). A uniformly random order puts roughly mass \(u\mu_s\) of each type before an agent arriving at rank fraction \(u\), where \(u\) is uniform on \([0,1]\). If \(V(z)\) is the LP worth and \(D_tV(z)=\lim_{\epsilon\downarrow0}(V(z+\epsilon e_t)-V(z))/\epsilon\), the per-agent type-\(t\) limit is \(\sigma_t=\int_0^1D_tV(u\mu)\,du\). The type’s total Shapley share, normalized by population size, is \(\mu_t\sigma_t\). This retains the paper’s marginal-contribution fairness question while making the population the continuous object.

The proposed bounds use the same neighborhood idea as Theorem 6. Let \(H_t=\{t\}\cup\{s:\Omega_s\cap\Omega_t\neq\emptyset\}\), the neighboring types. Define \(z^-_s(u)=u\mu_s\) for \(s\in H_t\) and \(\mu_s\) otherwise; define \(z^+_s(u)=u\mu_s\) for \(s\in H_t\) and \(0\) otherwise. The problem is: given the rational instance, compute exact rational endpoints \(L_t=\int_0^1D_tV(z^-(u))\,du\) and \(U_t=\int_0^1D_tV(z^+(u))\,du\) for every type, and establish the running time in the number of types \(\tau\), good classes \(|Q|\), bit length \(L\), and maximum type-neighborhood size \(\Delta\). The solution is the vector of intervals \([L_t,U_t]\), which should enclose \(\sigma_t\); multiplying by \(\mu_t\) gives the normalized cohort intervals. Diminishing marginal returns in the allocation game motivate the enclosure, but the finite-agent theorem does not prove this continuous claim.

I would provisionally expect a Class A result when \(\Delta\) is bounded: each worth evaluation is a weighted matching problem, and the continuous model represents large cohorts by a small number of types. The central difficulty is exact integration of parametric matching values; their breakpoints could make the desired fixed-parameter running time fail. The mirror therefore asks a real algorithmic question rather than assuming the answer. It also raises whether the intervals collapse to exact type values, and how quickly finite replicated Shapley values approach the continuous limit.

The authors should recognize the underlying question: the worth of a coalition is still optimal allocation, and the output is still a fair division of its total worth by expected marginal contribution. The mirror covers Theorem 6’s bound-computation result, not the paper’s entire suite of preprocessing and approximation results. Its weakest point is that an atomless population has no automatic, unique Shapley value; this mirror commits to the replica-limit definition above. Scaling good supplies with population is also a substantive modeling choice, though it is a standard co-modification for a high-multiplicity allocation market.

The case AGAINST (opponent, writing after the proponent)

The only solid negative point is about the VQR case study itself: its researchers and publications are largely one-off and linked by individual authorship, so that instance does not naturally compress into a small set of types with per-capita supplies. That defeats a mirror of the experiment, but not a mirror of the paper’s allocation problem.

The proponent’s anchor survives the stronger test. Theorem 6 is a named computational result: it computes Shapley-value bounds using the allocation graph’s neighborhood structure. A plausible high-multiplicity version is a recurring assignment market with many workers sharing a small number of eligibility and capacity profiles. Shapley symmetry means grouping identical workers loses no distinction relevant to their per-person values. Scaling goods with population is a reasonable co-modification for that market, and aggregate fractional assignments can arise as the limit of replicated integral assignments.

The proposed integral bounds still need proof. But that is the algorithmic question, not a reason the question is unworthy. A more cautious version could define the continuous bounds as limits of the finite-replica bounds and then ask whether those limits are computable efficiently. The paper supplies no continuous computational answer to that question. Nor can I dismiss it on the ground that the answer might be easy, hard, or unchanged: those are results the programme is meant to discover.

So the strongest honest case against is narrow: the mirror changes the paper’s particular VQR instance into a recurring allocation market, and the continuous bound formulas are not established by Theorem 6. I cannot make either point defeat the better mirror. The negative case is weak, and this anchor should survive.
