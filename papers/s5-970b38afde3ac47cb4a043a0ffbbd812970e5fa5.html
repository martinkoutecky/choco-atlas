What the mirror covers

No result is covered by a computational mirror; the main theorem is an implementability characterization, and the technical lemma establishes strictness of preferences.

The case FOR (proponent)

The narrow positive seed is a plausible high multiplicity setting: a large constituency repeatedly choosing a contingent policy from fixed finite sets \(X\) and \(\Omega\), with relatively few complete SEU types \(t=(v,p)\). Its society could be represented by rational masses \(\mu_t\), with the number of participants much larger than the support size \(\tau\). That makes the population continuous while leaving outcomes and states finite. It suggests asking whether unanimous OSP implementation still forces dictatorship as those type masses grow.

But the paper supplies no named computational result to anchor that question. Its main result, proved here and unnumbered in the supplied text, says that an SCF is unanimous and OSP implementable if and only if it is dictatorial. That is an implementability characterization, not a complexity result: the paper defines no finite input problem, algorithm, or complexity classification. The Bahel–Sprumont theorem it cites—unanimous and strategy-proof SCFs are exactly locally bilateral top selections—is also a characterization, and is cited from elsewhere. The technical lemma about strict SEU preferences is not a computational result either.

The possible population mirror also runs into a modeling problem. The paper assigns each state to a named individual, then uses that individual’s favorite outcome there. With a mass distribution over types, assigning a state to a type makes the mass largely irrelevant; splitting it across types risks changing the outcome into a mixture. If outcomes depend only on the aggregate distribution, an individual’s report has no effect in an atomless population, so individual OSP constraints become vacuous. Treating each type bloc as a strategic player would instead change who acts in the mechanism.

So I would not offer a prover-ready continuous problem or predict a tractability class here: there is no qualifying anchor, and a plausible type distribution alone does not repair the mismatch. The soft spot is also the strongest warning sign: the theorem already covers every finite \(n\ge2\), while its conclusion singles out an individual whose identity disappears from a population distribution.

The case AGAINST (opponent, writing after the proponent)

The paper’s main theorem gives no computational problem to continuize. It characterizes which social choice functions are both unanimous and OSP implementable: exactly the dictatorial ones. The cited Bahel–Sprumont result is also a characterization, and the lemma is technical. The paper defines no input encoding, algorithmic task, or complexity measure. So its main result cannot anchor the programme’s computational question; the proposed mirror would have to supply one from outside the paper.

The strongest candidate is to fix a finite set \(T\) of complete SEU types, represent a large society by rational type masses \(\mu\), and ask whether unanimous rules on those distributions admit OSP implementations. But OSP compares an individual agent’s truthful and deviating paths. In an atomless population, one person has zero mass, so a unilateral report does not change \(\mu\) or the resulting act; the incentive comparisons become vacuous. Making each positive-mass type bloc a player avoids that, but turns many independent agents into a coordinated player. Keeping a finite population preserves individual OSP, but then the mechanism still acts on named agents; \(\mu\) records repeated preferences rather than replacing the players.

The paper’s own structure sharpens the mismatch. Its assignment rule partitions the *state space* \(\Omega\) among agents, so the assigned individual’s favorite outcome determines the social act in each state. If identical-type agents are compressed into one type, which member receives a state stops affecting the act, and the type’s mass adds nothing. Splitting a state’s assignment fractionally across types would require multiple or randomized outcomes at that state, changing the model.

One could invent a finite-input problem about recognizing OSP implementation for rules on rational-mass type profiles. That might be worthwhile in its own right, but it needs a rule encoding and an algorithmic task that this paper does not provide; the population continuum would not turn the paper’s theorem into a computational result. The negative case is strongest against a *mirror of this paper*. It cannot prove that no adjacent computational project is worth pursuing, but the proponent’s proposed dictatorship question is either an axiomatic characterization or a degenerate individual-incentive limit, not a continuous computational mirror.
