The anchor — hardness

Theorem B.1

Every anchor argued

  • Theorem B.1 — survived: The mass-splitting version preserves the theorem’s menu choices and per-good nonoverlap condition, while allowing repeated agents of a type to divide across whole bundles.

The continuous mirror question

Given goods \(G\), a finite set of types \(T\) with rational masses \(p_t\ge 0\) summing to \(1\), and for each type a fixed reference MMS menu \(M_t=(M_{t1},\ldots,M_{tn})\) that partitions \(G\) into \(n\) whole bundles, decide whether there are nonnegative masses \(x_{tj}\) such that \(\sum_{j=1}^{n}x_{tj}=p_t\) for each \(t\), and \(\sum_{t\in T}\sum_{j:g\in M_{tj}}x_{tj}\le 1/n\) for every \(g\in G\). Each unit of mass receives a whole bundle; only the mass of a type choosing each bundle is split.

The model it lives in

A distribution over complete menu types, with fixed reference MMS partitions, mass variables \(x_{tj}\), and per-good capacity \(1/n\). The feasibility objective has the uniform solution \(x_{tj}=p_t/n\), since each menu partitions the goods.

The objection that survived

The original \(n\)-part MMS menus need not certify standard MMS fairness in a replicated \(Kn\)-agent instance; the projective-plane example demonstrates this. Treating the menus as fixed reference options still mirrors Theorem B.1’s supplied-menu selection problem, but limits the interpretation as standard MMS fairness for a growing cohort.

fatal: False

What the mirror covers

The mirror covers the supplied-menu selection hardness in Theorem B.1. It does not cover the paper’s supply-adjustment bounds for goods and chores, or its other results.

Open questions for a prover

  • How does feasibility change when per-good capacities differ from \(1/n\)?
  • What additive capacity increase suffices to round a feasible mass assignment for a finite cohort?
  • Which type-level side constraints preserve feasibility under mass splitting?

The case FOR (proponent)

The strongest honest mirror I see is narrow: Theorem B.1, proved in this paper. It says that, given a partition \(M_i=(M^i_1,\ldots,M^i_n)\) of the goods for each agent \(i\), it is NP-hard to decide whether one can choose a single part \(A_i\in M_i\) for every agent so that the chosen bundles are pairwise disjoint—equivalently, each good is assigned to at most one agent. The authors prove this by reduction from Maximum Independent Set.

Here is a continuous version of that selection problem. Take a recurring allocation setting with \(n\) reference agents and \(m\) goods. Each type \(t\) has population mass \(p_t\), a valuation \(v_t\), and a designated \(n\)-part MMS partition \(M_t=(M_{t1},\ldots,M_{tn})\), so every bundle \(M_{tj}\) meets that type’s MMS benchmark. A type is complete: agents share the valuation and the same designated partition. The question is whether there are nonnegative rational masses \(x_{tj}\) such that

\[ \sum_{j=1}^{n} x_{tj}=p_t \quad\text{for each type }t, \qquad \sum_{t}\sum_{j:\,g\in M_{tj}}x_{tj}\le \frac{1}{n} \quad\text{for each good }g. \]

A solution assigns each type’s mass among its MMS bundles. Every individual still receives a whole bundle; only the share of a type receiving each option is continuous. The capacity \(1/n\) is the natural normalization: replicate the reference population \(K\) times, with \(K\) copies of each good, and normalize the \(Kn\) agents to mass one. Each good then has capacity \(K/(Kn)=1/n\).

This question is always feasible. Set \(x_{tj}=p_t/n\). Since each \(M_t\) partitions the goods, each good appears in exactly one bundle of each type, so its total assigned mass is \(\sum_t p_t/n=1/n\). This is also exactly implementable in sufficiently large replicated populations: choose \(K\) to clear the mass denominators, and distribute each type evenly over its \(n\) bundles. Thus this mirror is Class A: the disjoint-selection hardness disappears when a type’s mass can be split among whole, MMS-guaranteeing choices and supply scales with population.

The regime could be a large recurring course-allocation system: many students fall into a modest number of preference-and-partition types, and course capacities grow with cohort size. More abstractly, replicate the paper’s \(n\)-agent instance \(K\) times. Its \(n\) reference agents become at most \(n\) types, while the population grows to \(Kn\); the support stays fixed as \(K\) grows. This is not continuity of the goods or bundles: they remain indivisible. It is continuity of the population assigned to those bundles.

I would expect the authors to recognize this as a mirror of the selection problem in Theorem B.1. It keeps its central decision—choosing among MMS-inducing bundles—and its no-overlap condition, while giving repeated agents of one type the flexibility to divide across those options. The main deliverable is the precise feasibility question above; it is not a mirror of the paper’s main supply-bound theorems. Those results concern integral multi-allocations, whereas this question isolates the computationally hard bundle-selection step.

The weak point is that the mirror takes the MMS partitions as input, just as Theorem B.1 does, and lets a type split across them. If one considers that split an unacceptable change to the authors’ question, the tractability gain will look too easy. I think it is defensible: the bundles each person receives remain integral and fair, and the split describes how many agents of a repeated type receive each bundle. The paper’s course-allocation motivation makes that a plausible population regime. The paper’s adjusted supply is not itself a collision: its items may be duplicated or discarded, but its society is still finite and its assignments remain integral.

This mirror raises useful follow-ups: what happens when capacities do not scale exactly with the population; which type-level constraints preserve the uniform assignment; and how much per-good overload is needed to round a continuous assignment for a finite cohort? It does not address the complexity of finding MMS partitions, or claim to continuize the paper’s other results.

The case AGAINST (opponent, writing after the proponent)

The strongest objection to Theorem B.1 is that its input is an agent-indexed list of menus \(M_i\), and the reduction encodes graph structure in those menus. For this problem, the menu is part of an agent’s complete description: two agents with different partitions have different feasible choices. The hard instances therefore have \(\tau=n\). Repeating each menu many times gives a legitimate restricted regime, but it does not carry the reduction’s heterogeneous menu structure into a large-multiplicity instance. That limits how much the proposed mirror says about the source of B.1’s hardness.

There is also an MMS issue with the proposed replication story. With \(K\) copies of every good and \(Kn\) agents, the standard MMS benchmark is defined using \(Kn\) bundles. An original \(n\)-part MMS partition need not certify that benchmark. For example, let goods be the points of a projective plane of order \(q\), let \(n=q\), and give an agent value \(1\) exactly when its bundle contains a line. Any two lines intersect, so the original MMS is \(0\). With \(K=q+1\) copies of each point and \(Kn\) agents, the agents can each receive a distinct line: every point is used at most \(q+1\) times. The replicated instance has MMS at least \(1\). So the claim that the original partition options remain MMS-guaranteeing requires a fixed baseline benchmark.

A repair is possible: recompute MMS partitions for the scaled instance and pose the type-level feasibility problem over those menus. That gives a coherent population model, though it asks a different question from the one using the original \(M_i\). I cannot make the objection decisive: high-multiplicity regimes need not preserve the hard reduction, and a tractable answer is not disqualifying under the programme’s criteria. The best case against is that the proposed anchor loses the heterogeneous menu structure that makes B.1 hard; I cannot honestly conclude that no worthwhile continuous mirror survives.
