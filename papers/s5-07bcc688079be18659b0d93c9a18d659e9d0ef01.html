The continuous mirror question

Given two colleges \(c_1,c_2\), a finite type set \(T\), rational masses \(\mu_t\ge0\) with \(\sum_{t\in T}\mu_t=1\), rational values \(p_t\ge0\), capacities \(\beta_j\ge1/2\), and scale \(N\), find a complete mass assignment \(x_{tj}\ge0\) satisfying \(x_{t1}+x_{t2}=\mu_t\) and \(\sum_t x_{tj}\le\beta_j\), with each individual assigned integrally and no type–college blocking pair, that lexicographically maximizes the sorted pair \((W_{(1)},W_{(2)})\), where \(W_j=N\sum_t p_tx_{tj}\) and \(W_{(1)}\le W_{(2)}\).

The model it lives in

A nonatomic student population consists of complete identical types \(t\) with mass \(\mu_t\), assignment-independent utility \(p_t\), and college value \(p_t\). The variables \(x_{tj}\) are assigned masses, capacities are per-capita, and the objective lexicographically balances the aggregate college values after the fixed student-utility distribution is held constant.

The case FOR (proponent)

I think there is a credible positive mirror, with Theorem 5 as the lead anchor.

Theorem 5 is proved in this paper. It states that finding a leximin-optimal stable matching is NP-hard under isometric valuations with weak rankings when \(m=2\), and strongly NP-hard when \(n=3m\). The two reductions use Balanced Partition and 3-Partition. In the \(m=2\) construction, each student \(s_i\) has value \(p_i\) for either college, every college values \(s_i\) at \(p_i\), and \(\sum_i p_i=2B\). Thus every complete matching is stable, student utilities are fixed, and the leximin problem becomes partitioning the \(p_i\)'s between the colleges. Both colleges receive value \(B\) exactly when the Balanced Partition instance is solvable. The \(n=3m\) clause uses the same idea with 3-Partition. The reductions use capacities \(b_j=n-m+1\).

My continuous problem is:

Continuous Leximin Two-College Matching. There are two colleges \(c_1,c_2\), a finite set of student types \(T=\{1,\ldots,\tau\}\), rational masses \(\mu_t\ge 0\) with \(\sum_t\mu_t=1\), and rational values \(p_t\ge0\). Type \(t\) means students who are identical in every relevant respect: each is indifferent between the two colleges, has value \(p_t\) for either one, and is valued by either college at \(p_t\). Capacities are per-capita capacities \(\beta_1,\beta_2\), with \(\beta_j\ge 1/2\).

The decision variable is \(x_{tj}\), the mass of type \(t\) assigned to college \(c_j\). It must satisfy \(x_{t1}+x_{t2}=\mu_t\), \(x_{tj}\ge0\), and \(\sum_t x_{tj}\le\beta_j\). Every individual in the continuum receives one integral college assignment; \(x_{tj}\) is fractional only because a nonatomic type population can be divided into subsets.

To preserve the paper’s additive college valuations, let \(N\) be a population-scale parameter and define \(W_j(x)=N\sum_t p_tx_{tj}\). The student-utility distribution is fixed, while the two college values vary. The question is to output a stable feasible \(x\) that lexicographically maximizes the sorted pair \((W_1,W_2)\), equivalently maximizes \(\bigl(\min\{W_1,W_2\},\max\{W_1,W_2\}\bigr)\). This is exactly the paper’s leximin objective on this family, because all student utilities are assignment-independent.

Stability is not being discarded: its direct nonatomic analogue forbids a type–college blocking pair. Here, however, every student is indifferent between the colleges, so no strict student improvement exists and every feasible complete assignment is stable, just as in the paper’s own reduction.

The continuous problem is in Class A. Since \(W_1+W_2=N\sum_t\mu_tp_t\) is fixed, the optimum equalizes the college values. The assignment \(x_{t1}=x_{t2}=\mu_t/2\) is feasible and gives \(W_1=W_2\). More generally, the first leximin stage is the linear program \(\max z\) subject to \(\sum_t p_tx_{tj}\ge z\), together with the mass and capacity constraints; the remaining lexicographic stages are also linear. Thus the discrete partition hardness disappears because a type mass can be split across colleges while every individual still receives an integral assignment.

This is a sensible high-multiplicity regime: millions of applicants fall into a relatively small number of score, productivity, or socioeconomic bands, so \(N\gg\tau\). Two equivalent programmes, hospitals, or employers can value each band identically, while applicants are indifferent between them. A finite instance with \(n_t\) students of type \(t\) gives \(\mu_t=n_t/N\); the continuous assignment is the limit in which those type populations become divisible. Rounding back to integral counts introduces only a granularity error controlled by the number of types and the largest \(p_t\).

The weakest point is that this mirrors only a restricted part of the paper. Theorem 5’s reduction has essentially vacuous stability and, in its raw form, one distinct value \(p_i\) per item, so it does not itself exhibit \(\tau\ll N\). I would not claim that this validates a continuous mirror for the paper’s strict-preference or general-valuation results. But the restriction is not invented merely to make the problem easy: it is precisely the isometric weak-ranking setting of the paper’s named hardness theorem, and the hardness there comes from indivisible population mass. That makes the dissolution of the partition hardness a legitimate continuization question rather than an unrelated fractional-matching problem.

The resulting programme asks whether the same phenomenon persists with non-vacuous stability, strict preferences, heterogeneous type valuations, or a growing number of colleges; whether continuous solutions admit uniform rounding guarantees; and whether some of those extensions become genuinely continuum-specific hard.

The case AGAINST (opponent, writing after the proponent)

The strongest objection is that this is not really a stable-matching mirror of Theorem 5. In that reduction, students are indifferent between the colleges and both colleges value each student identically. Consequently, every feasible complete assignment is stable: the stability constraint contributes nothing. The proposed continuum therefore reduces to splitting a divisible weighted population between two bins, with leximin balancing two aggregate loads. The \(N\)-scaling also matters: the paper’s leximin tuple contains individual student utilities and aggregate college utilities, whereas a continuum has no canonical finite sorted tuple. Using totals makes college values dominate as \(N\) grows; using per-capita values gives a different objective; quantile-based leximin would be a further redefinition.

That is a real limitation of the claimed “exact” correspondence. A more substantive mirror would need strict preferences or heterogeneous college valuations, a nonatomic blocking-pair definition, and a principled normalization of individual versus aggregate welfare. But adding those features leaves the particular Theorem 5 reduction behind.

It does not, however, defeat the best possible mirror. A population of many students in finitely many score or productivity bands, assigned integrally at the individual level but divisible in aggregate, is a legitimate high-multiplicity regime. The fact that stability is vacuous in this deliberately symmetric subcase is not disqualifying, and the resulting question is genuinely about population continuization rather than merely fractional outcomes. Repeated finite instances converge naturally to the proposed mass model.

So the negative case is honestly weak: it can challenge the proponent’s claim that this is a faithful mirror of the whole matching problem, but it cannot establish that no worthwhile continuous mirror exists. Theorem 5 remains a surviving anchor.
