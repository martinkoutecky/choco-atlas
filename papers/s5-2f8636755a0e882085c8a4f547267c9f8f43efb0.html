The case FOR (proponent)

There is no qualifying named anchor in this paper: it has no numbered Theorem, Lemma, Corollary, or Proposition asserting a computational complexity result. The closest hook is the Introduction’s unnumbered statement that finding a Kemeny ranking is NP-hard, cited to reference [9]; that result is not proved here. The strongest plausible mirror is Continuous Kemeny Ranking Aggregation. Let \(O\) be the objects being ranked, and let each type \(P\) be a partial order on \(O\), with rational mass \(\mu_P\) and \(\sum_P\mu_P=1\). A concrete regime is a very large group of users ranking products or services, where many users provide the same complete or partial comparisons. The support size \(\tau\) counts the distinct partial orders, which could be much smaller than the number of users.

For a total order \(T\), let \(T_{ij}=1\) when \(i\) is ranked at least as high as \(j\). Define its disagreement with the society by
\[ D_\mu(T)=\sum_P\mu_P\sum_{i\ne j}\mathbf{1}[(j,i)\in P]T_{ij}. \]
The problem is: given \(O\) and the supported partial-order types with their masses, output a total order \(T\) minimizing \(D_\mu(T)\). This mirrors the paper’s underlying objective directly: each type contributes its share of the pairwise-incompatibility cost. Replacing counts with population fractions changes the scale of the objective, not which ranking minimizes it.

If the unnumbered NP-hardness statement is accepted as a provisional hook, the expected classification is hardness transfers (Class B). Restrict types to complete rankings and set \(\mu_P=n_P/N\), where \(n_P\) is the number of discrete voters of type \(P\). Then the discrete Kemeny instance and its continuous version have the same minimizers. The hard combinatorics live in the number of objects being ranked, so continuizing the population does not remove them. This covers the Kemeny objective and its hardness background, not the paper’s QUBO encodings or quantum-algorithm experiments. Natural follow-up questions concern algorithms parameterized by the number of objects or support size, and approximation guarantees for this rational-mass version.

The case AGAINST (opponent, writing after the proponent)

The strongest case against is that this paper supplies no named complexity result to mirror. Its NP-hardness statement is background cited to reference [9], not a result proved here. The paper’s own contributions are four QUBO formulations and experiments comparing their performance. Those experiments do not establish the complexity of a computational problem on a continuous society.

The best version of the proposed mirror is still well defined: let types be partial orders \(P\) with rational masses \(\mu_P\), aggregate them into \(c^\mu_{ij}=\sum_P \mu_P\mathbf{1}[(j,i)\in P]\), and find a total order minimizing \(\sum_{i,j}c^\mu_{ij}T_{ij}\). A large population of users who share a relatively small set of rankings is a plausible high-multiplicity regime. For complete-ranking types, clearing denominators turns the masses into integer voter counts and scales every ranking’s cost by the same positive factor.

That makes the continuous Kemeny problem a sensible object, but it does not make it a mirror of this paper’s result. The paper’s formulations already take the aggregated cost matrix as input. Replacing a voter list by masses changes those coefficients; it does not change the order variables, constraints, or four encodings being compared. Studying weighted Kemeny complexity could be useful as a separate ChoCo project, especially with binary-encoded multiplicities, but it would address the background Kemeny problem rather than a computational result established in this paper.

So no qualifying anchor survives.
