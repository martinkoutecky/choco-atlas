The continuous mirror question

Given finite agent types \(\Theta\) with rational masses \(\mu_\theta\), item classes \(K\) with rational per-capita supplies \(\sigma_k\), and additive utilities \(v_{\theta k}\), find nonnegative masses \(x_{\theta,B}\) over integral bundles \(B\subseteq K\) satisfying \(\sum_B x_{\theta,B}=\mu_\theta\) and \(\sum_{\theta,B:k\in B}x_{\theta,B}=\sigma_k\), such that every pair of positive-mass assignments \((\theta,B)\) and \((\theta',B')\) satisfies \(u_\theta(B)\ge u_\theta(B')\) or \(u_\theta(B\setminus\{k\})\ge u_\theta(B'\setminus\{k\})\) for some \(k\in B\cup B'\); output such an \(x\), with exact or approximate complexity guarantees.

The model it lives in

A high-multiplicity mixed-manna allocation model with agent types \(\theta\) and masses \(\mu_\theta\), per-capita supplies \(\sigma_k\) of indivisible item classes, assignment variables \(x_{\theta,B}\) over integral bundles, and a feasibility/search objective requiring EF1 for every supported ordered pair.

The objection that survived

The exact support-wise EF1 requirement may require exponentially many integral bundle configurations, while the theorem's sequential agent order does not itself define or compress a mass allocation.

fatal: False

What the mirror covers

The mirror covers the double-round-robin EF1 algorithm and leaves the two-agent EF1-plus-PO result, the mixed-cake and connected-PROP1 results, and the paper's axiomatic material unmirrored.

Open questions for a prover

  • Does every rational feasible instance have a polynomial-bit-support \(x\), and can it be found in time polynomial in \(|\Theta|\), \(|K|\), and the encoding length?
  • Is exact support-wise EF1 polynomial-time solvable for fixed \(|\Theta|\), and what hardness appears when the number of types is part of the input?
  • Can EF1 be combined with Pareto-optimality or welfare maximization in this mass-allocation model?

The case FOR (proponent)

The strongest positive case is the paper’s general EF1 theorem, not its cake-cutting result. The latter continuizes the outcome space and is outside ChoCo’s scope. The paper contains no named NP-hardness theorem of its own; the hardness statements in related work are cited facts, so I would not misuse them as anchors.

My lead anchor is Theorem 1, proved in this paper: for additive utilities, the double round robin algorithm returns an EF1 allocation in time \(O(\max\{m\log m,mn\})\). The algorithm first separates objective chores, which have non-positive utility for every agent, from items that are positive for at least one agent. It allocates chores in a forward round-robin order, adding zero-valued dummy chores so that agents receive equally many chore turns. It then allocates the remaining goods in the reverse round-robin order, finally deleting the dummy chores. The theorem proves that the resulting allocation is EF1.

I would mirror this with the following problem.

Lead problem: High-Multiplicity Mixed-Manna EF1. An instance consists of a finite set of agent types \(\Theta\), rational masses \(\mu_\theta\) summing to \(1\), and a finite catalogue of indivisible item classes \(K\). Type \(\theta\) has additive utility \(v_{\theta k}\) for an item of class \(k\). Item class \(k\) has rational per-capita supply \(\sigma_k\): in a finite realization with \(N\) agents, there are \(N\sigma_k\) distinct indivisible copies of class \(k\). For simplicity, one may impose at most one copy of each class per agent, so an integral bundle is \(B\subseteq K\); allowing bounded multisets gives the more general version.

The decision variable is \(x_{\theta,B}\), the mass of type-\(\theta\) agents receiving integral bundle \(B\). It must satisfy \(\sum_B x_{\theta,B}=\mu_\theta\) for every \(\theta\), and \(\sum_{\theta,B:k\in B}x_{\theta,B}=\sigma_k\) for every item class \(k\). The utility of \(B\) to type \(\theta\) is \(u_\theta(B)=\sum_{k\in B}v_{\theta k}\).

The question is to find such an \(x\) for which every pair of agents in its support satisfies the paper’s EF1 condition: for every supported \((\theta,B)\) and \((\theta',B')\), either \(u_\theta(B)\geq u_\theta(B')\), or there is an item \(k\in B\cup B'\) such that \(u_\theta(B\setminus\{k\})\geq u_\theta(B'\setminus\{k\})\), with deletion having no effect when \(k\) is absent from one bundle. The objective is feasibility/search: output a mass allocation, not a fractional item allocation.

This is genuinely a population continuization. A concrete regime is a large workforce receiving assignments from a fixed menu of tasks. There may be millions of workers but only a few dozen stable preference types—say, students in recurring degree programmes with identical valuations for the available tasks. Task copies scale with the workforce: if class \(k\) has supply \(\sigma_k\), then \(N\sigma_k\) indivisible copies exist for \(N\) workers. Each worker still receives an integral bundle; \(x_{\theta,B}\) merely records what fraction of the population receives each bundle. Type means the complete utility profile, including any other parameters relevant to allocation, so this is genuine high multiplicity rather than pretending distinct workers have identical prices.

The authors should recognize this as their problem. It preserves mixed goods and chores, additive utilities, indivisible assignments, and EF1 exactly. The only additional modelling move is the necessary one for a continuum of agents: supplies scale per capita. Without that move, a fixed finite set of tasks could not support a positive-mass population. The finite-\(N\) specialization is literally an instance of their allocation problem with repeated utility-identical agents and item copies.

I expect this mirror to be Class A, at least when the number of item and agent types is moderate. The proof of Theorem 1 relies on structural ordering, not on the identities of individual agents: classify item classes by sign, sort each type’s choices, equalize chore turns with zero-valued placeholders, and reverse the order for goods. Those operations suggest a compressed mass-flow or column-generation algorithm whose variables are type-to-bundle masses rather than \(N\) individual assignments. The crucial new complexity question is whether the EF1 support constraints admit such a compression with running time polynomial in \(|\Theta|\), \(|K|\), and the input bit length, rather than in the huge denominator \(N\).

That is not already solved by Theorem 1. The paper’s \(O(mn)\) algorithm is polynomial in the number of named agents, so expanding a high-multiplicity instance to \(N\) agents would defeat the purpose. The continuous mirror asks whether the same structural proof can be batched over masses. If this batching fails, the failure could itself produce a continuum-specific hardness result, but the question remains a faithful computational mirror either way.

It also generates useful follow-up questions: whether a finite-support rational \(x\) always suffices; whether the problem is polynomial for fixed \(|\Theta|\) but hard when the number of types is part of the input; whether approximate EF1 admits a simpler LP; and whether one can impose Pareto-optimality or welfare maximization in addition to EF1.

The weakest point is that EF1 is not a linear type-average condition. A naive formulation comparing only each type’s expected utility would be a softened problem and could reasonably be rejected as no longer the authors’ question. The exact mirror must require EF1 for every bundle appearing with positive mass, and the required support may be complicated. Thus I cannot honestly claim that Theorem 1 automatically yields a polynomial high-multiplicity algorithm. What I can claim is that this is a natural, precise population mirror of the paper’s central indivisible-allocation problem, with a plausible Class-A route and a clearly identifiable boundary where continuum-specific complexity might begin.

The case AGAINST (opponent, writing after the proponent)

The negative case cannot use the missing-anchor objection. Theorem 1 is plainly a named computational result: it gives an algorithm and a running time. Nor can it object that the proposed problem might be easy; a tractable high-multiplicity reformulation is still a legitimate Class-A target.

The strongest objection is fidelity. The theorem operates on a finite set of named indivisible items, whereas the proposed model replaces them by item classes with scalable supplies. That identifies previously distinct copies and imposes a new resource regime. The theorem also relies on a sequential order of individual agents. The mass vector \(\mu\) does not specify how equal-type agents are interleaved in the round-robin sequence, yet different interleavings can produce different bundle distributions \(x_{\theta,B}\). A block order or periodic order would be an additional policy, while optimizing over orders would create a new scheduling problem.

The exact EF1 repair is also awkward. Expected or type-average utility is not enough: EF1 is a support-wise, ex-post condition. The natural formulation must require that every pair of bundles with positive mass satisfies the relevant type’s EF1 inequality. That produces a nonconvex support-selection problem over exponentially many configurations \(B\), not the kind of linear mass-transfer problem for which continuization naturally supplies an LP. If bundles are allowed to contain repeated item classes, the configuration space becomes even less like the paper’s input.

This leaves a sharp dilemma. If one fractionalizes bundles, one has left the paper’s indivisible-allocation problem. If one keeps bundles integral, then the new difficulty is to find a compact EF1-supported configuration distribution and prove its bit complexity. The double round robin theorem supplies no such compression theorem; expanding a rational instance to \(N\) named agents may be exponentially larger than the input. Thus the proposed question is either a different fractional problem or a new succinct-support problem whose connection to the theorem is only motivational.

That is the best negative argument, but it does not establish the universal claim. Clearing denominators gives an exact dictionary: from rational \(\mu\) and supplies, create repeated agents and item copies, run the paper’s algorithm, and aggregate the resulting bundles. Conversely, any rational \(x\) expands to a finite allocation. A large workforce receiving repeated task types is also a credible high-multiplicity setting, and per-capita supply scaling is expressly permitted by the programme. The order can be fixed canonically, and the exact support-wise EF1 question remains a legitimate open computational extension.

So I would reject the proponent’s claim that Theorem 1 already yields a plausible polynomial algorithm, but I could not honestly argue that no worthwhile continuous mirror exists. The negative case shows that the mirror is an extension with a serious configuration-support bottleneck, not that it is ill-posed. The proponent’s anchor survives that stronger attack.
