The continuous mirror question

Given a finite list of household types with rational population masses, Boolean action sets, goal formulas, costs and taxes, together with a rational mass profile over actions, determine whether the profile is a Wardrop equilibrium: every action used by positive mass must be a best response when an individual deviation leaves the aggregate state fixed.

The model it lives in

A population is a distribution over complete household types. Each type has a Boolean action block, a local goal formula, and costs; optional shared threshold facts describe aggregate action shares. A profile assigns each type’s mass across its actions, and a negligible household’s deviation does not change those aggregate facts.

What the mirror covers

The mirror covers Nash Outcome Verification from Proposition 2. It leaves Proposition 9’s tax implementation result, the later welfare and equity results, and the paper’s other propositions outside the surviving mirror.

The case FOR (proponent)

The best mirror I can defend is an anonymous, nonatomic Boolean game. Imagine a very large population of smart-grid households. Each household controls a small set of binary settings, has a local logical goal and action costs, and responds to taxes set by an outside principal. A type records everything that matters about a household: its goal, controlled settings, and costs. The mass \(\mu_t\) of type \(t\) is its fraction of the population. There may be millions of households but only a modest number of types.

To represent the society’s shared state, let \(z_\ell\) mean that at least a specified fraction \(q_\ell\) of the population has an action feature \(h_\ell\). If \(x_{t,a}\) is the mass of type \(t\) choosing Boolean action \(a\), then \(z_\ell\) is true exactly when \(\sum_{t,a:h_\ell(t,a)=1}x_{t,a}\ge q_\ell\). Each type’s goal formula can refer to its own action bits and these aggregate facts; the principal’s objective is a formula over the aggregate facts. This is a natural anonymous version of Boolean games: households still control Boolean actions, pursue logical goals, and face action-level taxes, while the shared facts describe what fraction of society behaves in a given way.

For a tax schedule \(\lambda\), let \(e_t(a)\) be a type’s action cost plus tax, and let \(M_t=\max_a e_t(a)\). Give a household utility \(1+M_t-e_t(a)\) when its goal is satisfied and \(-e_t(a)\) otherwise, as in the paper. A population profile is an equilibrium if each type’s mass is assigned only to actions that are best responses at the resulting aggregate state. Since one household has zero mass, changing its own action does not change the aggregate facts. This is the Wardrop, or nonatomic, version of Nash equilibrium.

The cleanest anchor is Proposition 2, proved in the paper: *Nash Outcome Verification is co-NP-complete, even for two-player games with zero taxes and zero action costs.* It asks whether a specified outcome is a Nash equilibrium. Its hardness reduction is from SAT. The reduction is particularly well suited to this mirror because its hard part is an agent’s own Boolean goal, not a large or complicated population.

The corresponding continuous problem is Continuous Boolean-Game Equilibrium Verification. Its input is a finite list of types with rational masses, Boolean action schemas, goal formulas, costs and taxes, together with a rational action-mass profile \(x\). It asks whether \(x\) is an equilibrium. A “yes” answer means every positive-mass action for every type is a best response at the aggregate state induced by \(x\).

The paper’s SAT reduction carries over directly, with just two types. Type 1 has goal formula \(\varphi\) over its own Boolean action bits; type 2 has one bit \(r\) and goal \(r\). Set the candidate profile to put all type-1 mass on the all-false action and all type-2 mass on \(r=\top\), with costs and taxes zero. If \(\varphi\) is satisfiable, a type-1 household can switch to a satisfying assignment and improve. If it is unsatisfiable, no type-1 household has a successful deviation, and type 2 already satisfies its goal. So equilibrium verification is co-NP-hard even with two types and arbitrarily large populations. It is also in co-NP: a certificate that the profile is not an equilibrium is a type, an action used by positive mass, and a profitable alternative action. This is hardness that transfers: the combinatorics live in the Boolean goal formula, not in the number of agents.

A second, more ambitious anchor is Proposition 9, also proved in the paper: *IMPLEMENTATION is \(\Sigma_2^p\)-complete.* Its input is a Boolean game \(G\) and objective \(\Upsilon\). It asks whether there is a taxation scheme for which \(G\) has at least one Nash equilibrium and every Nash equilibrium satisfies \(\Upsilon\). The paper proves hardness via Proposition 8’s STABILISATION problem; the cited source for the underlying pure-equilibrium existence hardness is Bonzon et al., [2, Proposition 5].

The continuous counterpart is Anonymous Strong Tax Implementation. Its instance is the typed population model above, including rational masses, local goals and costs, aggregate threshold facts, and an objective \(\Upsilon\). Its solution is a nonnegative rational tax schedule, with polynomially many bits of encoding, such that the induced equilibrium set is nonempty and every equilibrium profile satisfies \(\Upsilon\). It mirrors strong implementation directly: the principal must make the desired objective hold at every equilibrium, while ensuring that some equilibrium exists.

I would provisionally expect this second problem to be hard for continuum-specific reasons, rather than claim that Proposition 9’s \(\Sigma_2^p\)-hardness transfers. The tax schedule must leave at least one feasible equilibrium while excluding every equilibrium profile in every bad aggregate-state region. The equilibrium conditions within each fixed threshold state have a finite, linear description, but choosing taxes while ruling out all bad states creates a difficult quantified search. This is a conjecture, not a result; useful next questions are whether it becomes tractable for a fixed number of aggregate facts, or whether hardness persists with a fixed number of types.

Proposition 2 is my strongest anchor. It gives a precise complexity question in a genuine high-multiplicity regime: two types, each with a continuum of indistinguishable members, and hardness already present in a household’s logical goal. Proposition 9 adds a mirror of the paper’s central tax-design question, though its expected complexity is less certain.

The main weakness is that the paper allows a player’s goal to mention another named player’s exact variable, while this mirror uses shared aggregate facts such as “at least \(q\) of society chose this setting.” A unilateral deviation in the continuum cannot move those facts. That is a meaningful change to strategic interaction, so the Proposition 9 mirror is an anonymous extension, not a literal limit of every Boolean game in the paper. The Proposition 2 reduction survives this change because it needs no strategic dependence on other players at all.

This case covers equilibrium verification and strong tax implementation, not the paper’s later welfare and equity objectives. I do not see a novelty collision: mean-field work studies analytic equilibrium behavior, while these mirrors ask computational questions about verifying equilibria and designing taxes.

The case AGAINST (opponent, writing after the proponent)

The strongest case against starts with a modeling gap: the paper gives no population structure to continuize. An agent controls variables no one else controls, and a goal may refer to variables owned by particular other agents. Replicating an agent therefore requires deciding whether copies get private variables, keep references to particular agents, or respond to aggregate facts. The paper supplies no principle for choosing among those options. A genuine high-multiplicity version needs an interaction model as well as repeated agents.

That gap weakens Proposition 9’s proposed mirror. Its \(\Sigma_2^p\)-hardness comes from equilibrium existence in a finite game whose players can have distinct roles and dependencies. Keep those roles to preserve the reduction, and the “types” may amount to one type per player, with mass serving only as bookkeeping. Merge players into a small set of types, and the named-variable dependencies have to be replaced. The proponent’s aggregate thresholds are a plausible replacement, but they add a public-state interaction absent from the paper. The proposed strong implementation problem is therefore a reasonable new model, but the paper’s hardness result does not establish its complexity; the claimed continuum-specific hardness remains conjectural.

Proposition 2 is harder to dismiss. Its direct lift really does give a co-NP-complete continuous verification problem: one household type has goal \(\varphi\), and a deviation exists exactly when \(\varphi\) is satisfiable. The mass and the rest of the population play no role. One can object that this is a type-level SAT check packaged as population equilibrium, rather than a computational question about a society’s distribution. In the aggregate-state version, fixing the public state likewise leaves each type with a local best-response problem. With a fixed number of aggregate facts, one can enumerate their truth assignments; any extra combinatorics then comes from the aggregate language chosen for the extension.

That objection is limited. A continuous mirror need not get its hardness from population size, and the programme explicitly treats single-type hardness as potentially valuable. Nor does a result remain unworthy merely because its answer resembles the discrete one. Proposition 2 is a serious surviving anchor if the authors accept repeated households with common local goals.

So the negative case can challenge whether either mirror is a faithful and distinctive continuization of this paper. It cannot honestly show that no worthwhile mirror exists in any scenario. Proposition 2, in particular, defeats that universal claim unless “worthwhile” requires the continuous population itself to affect the computation—a requirement the programme’s brief does not impose.
