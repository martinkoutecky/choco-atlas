Why no mirror

That changes the problem: marginal-welfare utilities make every Wardrop equilibrium optimal in the proposed model, so the finite-player utility-design question does not carry over.

What the mirror covers

The proposed model targets Theorem 1 (Informal) and its utility-design guarantee; it does not mirror the simulation results or the discussion of specialized welfare-function sets.

The case FOR (proponent)

The strongest anchor is the manuscript’s Theorem 1 (Informal), proved here in §2.1. It says that for the class of resource allocation games with nonnegative, nondecreasing concave welfare functions whose maximum curvature is \(c\in[0,1]\), an optimal utility mechanism achieves \(\poa(\mathcal G)=1-c/e\) and can be computed efficiently. The proof builds that mechanism here, using Proposition 1, which restates Theorem 6 of Chandan et al. (2019). The paper gives no numbered hardness result of its own, so this is an algorithmic anchor rather than a hardness one.

A concrete mirror is Smooth Nonatomic Utility Design. Its input is a finite resource set \(R\), types \(T\) with rational masses \(\mu_t\) summing to \(1\), and for each type an explicitly listed menu \(\mathcal A_t\subseteq 2^R\). A type is a complete feasible-action menu: its members are interchangeable for this model. Each resource \(r\) has a differentiable, nonnegative, nondecreasing concave welfare curve \(w_r:[0,1]\to\mathbb R_{\ge0}\), given by a finite representation such as a rational polynomial. The mass assigned by type \(t\) to action \(a\) is \(x_{t,a}\ge0\), with \(\sum_{a\in\mathcal A_t}x_{t,a}=\mu_t\). Thus the resource load is \(q_r=\sum_{t,a:r\in a}x_{t,a}\), and total welfare is \(\sum_r w_r(q_r)\).

The question is: compute local utility functions \(f_r(q_r)\), each based only on that resource’s welfare curve and load, that maximize the worst ratio of welfare at a Wardrop equilibrium to optimal feasible welfare. At equilibrium, each type’s positive mass uses only actions maximizing \(\sum_{r\in a} f_r(q_r)\). A solver returns the functions and their worst-case guarantee; the individual agents still choose discrete bundles, while the type-level flow records how much mass chooses each bundle.

One plausible regime is a large fleet of autonomous vehicles with a small number \(\tau\) of mission or target-feasibility menus: \(n\gg\tau\). The mass \(\mu_t\) is the fleet fraction with menu \(t\). For instance, if a target has independent hit probability \(\lambda/n\) per assigned vehicle, its limiting expected-value curve at load \(q\) is \(w(q)=v(1-e^{-\lambda q})\). This keeps the paper’s resource allocation and target-assignment setting, while making the population—not the action bundles—the continuous object.

The expected classification is tractable. Return \(f_r(q)=w'_r(q)\), the marginal welfare of an infinitesimal increase in load. The feasible aggregate-flow set is convex. At any Wardrop equilibrium, the gradient of total welfare has nonpositive inner product with every feasible load change; concavity then implies that no feasible change can increase welfare. So every Wardrop equilibrium is optimal, giving ratio \(1\), which is best possible. For the stated finite curve encoding, producing each derivative is polynomial in its representation size. This gives one continuous problem for the theorem’s utility-design question, not an attempt to mirror every result in the paper.

The weak point is also the source of the gain: an infinitesimal vehicle has no effect on aggregate load, whereas a finite player changes resource counts by one. That removes the strategic feedback behind the theorem’s \(1-c/e\) tradeoff, so the mirror changes the equilibrium model and may be easier than the authors’ finite-player problem. I think authors and a referee could still recognize it as their central question in a natural population limit: design local utilities so decentralized resource-allocation equilibria maximize system welfare. The useful follow-up questions are how the guarantee for finite \(n\) approaches this limit, and what changes when action menus are succinctly represented or welfare is not separable by resource.

The case AGAINST (opponent, writing after the proponent)

Theorem 1 is a genuine computational anchor: the paper claims an efficient method for designing an optimal utility mechanism. So the strongest negative case is not that the paper lacks a result to mirror. It is that the proposed nonatomic mirror removes the strategic feature that makes this result a utility-design problem.

With divisible type flows and separable concave welfare, the feasible aggregate loads form a convex set. Set the utility on resource \(r\) to its marginal welfare, \(f_r(q_r)=w'_r(q_r)\). At a Wardrop equilibrium with load vector \(q\), every feasible load vector \(q'\) satisfies
\[ \sum_r w'_r(q_r)(q'_r-q_r)\le 0. \]
Concavity then gives
\[ \sum_r w_r(q'_r)\le \sum_r w_r(q_r). \]
This reasoning applies to the paper’s bundle menus too: splitting a type’s mass among its available bundles still gives a convex feasible-flow set. The issue is not that the continuous model has a particularly favorable answer. It is that a zero-mass agent cannot change resource loads, so the finite-player strategic effect that utility design must manage has disappeared. The remaining task is to specify marginal-welfare utilities for a convexified allocation model.

The vehicle-target scaling does not restore that effect. For a target with hit probability \(\lambda/n\), the limiting curve \(w(q)=v(1-e^{-\lambda q})\) still has a directly specified marginal utility. Adding more explicit types or bundles likewise leaves the first-order argument intact. If menus are succinct and allocation optimization becomes difficult, that difficulty lies in finding the welfare-maximizing allocation; it does not reappear in the paper’s task of computing a utility mechanism.

One could retain nonzero strategic impact by giving each deviator a positive mass, or by studying finite-size corrections as the population grows. That might be a worthwhile project, especially if it yields bounds for the discrete high-multiplicity game. But it introduces a granularity parameter and asks how the finite-player problem approaches the nonatomic limit. It does not rescue the proposed pure Wardrop mirror from the loss of finite-player strategic effects.

That is the best negative case I can make: the direct continuous mirror is well-posed and recognizably related to the paper, but its central mechanism-design tension collapses in the atomless model. The broader claim that *no scenario* could produce a worthwhile mirror is weaker. A finite-size or mass-deviation study could survive that claim, and I cannot honestly rule it out from this paper alone.
