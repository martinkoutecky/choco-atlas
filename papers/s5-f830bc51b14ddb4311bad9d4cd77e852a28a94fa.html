The continuous mirror question

Given finite agent types \(A\) with rational masses \(\mu_a\) summing to one, finite good types \(\Xi\), and binary values \(v(a,\xi)\), consider finite adversarially ordered batches \((\xi_r,q_r)\) of rational mass with \(\sum_r q_r=1\). Each unit good is assigned irrevocably on arrival, and every agent receives an integral bundle \(z\in\mathbb{Z}_{\ge 0}^{|\Xi|}\). For this type system, determine the best deterministic competitive ratio \(C_{\det}=\sup_{\pi}\inf_{\sigma:\operatorname{OPT}(\sigma)>0}\operatorname{ALG}_{\pi}(\sigma)/\operatorname{OPT}(\sigma)\), where utility is the essential minimum over the agent mass and the offline benchmark knows the full batch sequence; in particular, does \(C_{\det}=0\) already for two equal-mass types with public and type-specific goods?

The model it lives in

A continuum of agent mass \(\mu_a\) by type, with each agent retaining an integral bundle \(z\); unit goods arrive in mass-scaled batches and are assigned irrevocably. Compare the best deterministic online essential-minimum utility with the offline optimum on the same sequence.

What the mirror covers

The mirror covers Theorem 2.1’s deterministic adversarial lower bound; it leaves the randomized and random-order lower bounds and the IID algorithmic guarantees unaddressed.

Open questions for a prover

  • Which finite type and valuation structures admit a positive deterministic competitive ratio against adversarial mass batches?
  • What randomized competitive ratio is achievable in the same two-type mass model?

The case FOR (proponent)

The strongest anchor is Theorem 2.1, proved in this paper: for every deterministic online algorithm, the adversarial-arrival competitive ratio for online MaxMin is zero. The paper’s construction starts with one good valued by every agent, then presents \(n-1\) goods valued by everyone except the agent the algorithm left without the first good. The online minimum is zero, while an offline allocator can give that agent the first good and achieve value \(1\).

My mirror is Continuous Adversarial Santa Claus. Let \(A\) be a finite set of agent types, with rational masses \(\mu_a\) summing to \(1\), and let \(\Xi\) be a finite set of good types. Each agent type has a binary value \(v(a,\xi)\) for each good type. The input is an ordered list of arriving batches \((\xi_r,q_r)\), where \(q_r\) is the mass of goods in batch \(r\). The online allocator sees each batch on arrival and assigns its goods mass irrevocably.

The assignment must preserve the Santa Claus objective at the individual-bundle level. Formally, track \(\rho_{a,z}\), the mass of type-\(a\) agents holding integer bundle \(z\in\mathbb Z_{\ge 0}^{|\Xi|}\). A batch can move agent mass between bundle states, but every agent in each state still has an integral bundle. The value of bundle \(z\) for type \(a\) is \(u_a(z)=\sum_{\xi\in\Xi}v(a,\xi)z_\xi\); the outcome is the essential minimum of this value over the population. The offline benchmark knows the entire arrival sequence and maximizes the same minimum.

The prover’s question is: given \((A,\mu,\Xi,v)\), characterize or compute the best deterministic worst-case competitive ratio
\[ C_{\det}=\sup_{\pi}\inf_{\sigma:\,\mathrm{OPT}(\sigma)>0} \frac{\mathrm{ALG}_{\pi}(\sigma)}{\mathrm{OPT}(\sigma)}, \]
where \(\pi\) ranges over online mass-allocation policies and \(\sigma\) over ordered batch inputs. A solution is a policy together with a matching competitive guarantee, or a lower-bound construction ruling out a positive guarantee.

The regime is a large allocation system with two macroscopic cohorts of recipients who share the same valuation profiles. For example, many recipients may fall into one of two eligibility classes, with the same values, costs, and other relevant attributes within each class. In an \(N\)-agent discretization, each class has \(N/2\) agents, while the number of types stays \(\tau=2\). Goods supplies scale with the population, so batches have positive normalized mass. This is a sensible high-multiplicity regime for Santa Claus: the objective, online decisions, and integral bundle values remain intact.

In fact, the zero-ratio phenomenon survives directly with these two types. Give both classes mass \(1/2\), and first present public goods of mass \(1/2\), each valued by both classes. Once the deterministic policy has assigned them, at least one class is not fully covered: it cannot have given a whole public good to every agent in both classes. Call that class the target. Next present goods of mass \(1/2\) valued only by the other class. The target retains a positive mass of agents with value zero, so the online minimum is zero. Offline, assign the public mass to the target class and the later goods to the other class; everyone gets value \(1\). Thus this continuous problem has \(C_{\det}=0\), already for \(\tau=2\), binary values, and total supply equal to population mass. I expect the lower-bound direction to transfer. This is competitive-performance impossibility, rather than an NP-hardness claim.

The scope is deliberately narrow: this mirrors the paper’s deterministic adversarial online MaxMin result, not its randomized bound, IID guarantee, or random-order lower bound. It is the strongest anchor here because it is a proved, explicit negative result whose core adversarial choice still works when agents are grouped into fixed types.

The weakest point is that Theorem 2.1’s printed construction singles out an individual agent, whereas the continuous mirror uses a whole under-covered class and goods in population-scaled batches. That is a genuine model adaptation, not a literal limit of the proof as printed. The case survives because the adapted instance preserves the same online information, irreversible assignments, unit values, integral bundles, and minimum-utility objective; only the adversary’s target changes from one named agent to a positive-mass class.

This mirror also raises natural follow-ups: what is the randomized competitive ratio in the same two-type mass model; how does the answer change with lookahead or the ability to hold goods temporarily; and which type structures admit a positive deterministic ratio?

The case AGAINST (opponent, writing after the proponent)

The strongest case against is about programme fit, not whether the proposed mirror works. Theorem 2.1 studies the cost of online information: an irrevocable policy is compared with an offline allocator that knows the later arrivals. Its continuous version would classify competitive guarantees for an online allocation process. If ChoCo is prioritizing static high-multiplicity optimization and its complexity landscape, that is a different research axis and may be a peripheral use of the programme’s time.

That objection is conditional, though. The stated scope is broader than static intervention problems, and a competitive guarantee is an algorithmic result. I can’t turn the fit concern into a sound reason that the mirror is unworthy.

The proposed instance appears to survive the stronger objections. With two agent types of mass \(1/2\), a public batch of mass \(1/2\) cannot give every agent an integral item: some positive mass in at least one type remains uncovered. The adversary can then make the second batch valuable only to the other type. The online essential minimum is zero, while offline can give the first batch to the undercovered type and the second to the other type, attaining \(\mathrm{OPT}=1\). Tracking mass over integral bundle states preserves the per-agent objective, and the adversarial continuation can be fixed in advance for a deterministic policy.

So the original singleton construction does not itself transfer literally, but the cohort version does. Neither vanishing population mass nor type compression defeats it. The negative case is therefore weak: unless ChoCo explicitly excludes online competitive analysis, I would not argue that this paper has no worthwhile continuous mirror.
