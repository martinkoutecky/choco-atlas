The continuous mirror question

Given a finite path with positions \(j\in[m]\), type masses \(\mu_t\), per-capita item capacities \(\rho_j\), and additive chore values \(u_t(j)\le 0\), compute a mass assignment \(x_{t,I}\) over integral intervals \(I\) (including the empty interval) satisfying \(\sum_I x_{t,I}=\mu_t\) and \(\sum_{t,I\ni j}x_{t,I}=\rho_j\), such that every interval receiving positive mass of type \(t\) has \(u_t(I)\ge q_t\), where \(q_t\) is the type's continuous MMS threshold obtained from the corresponding interval-distribution max-min problem.

The model it lives in

A finite type set \(T\) carries population masses \(\mu_t\); integral path intervals remain indivisible bundles; \(x_{t,I}\) is assigned mass; \(\rho_j\) gives per-capita item capacity; and the computational task is to find a feasible MMS-fair assignment, optionally maximizing \(\sum_{t,I}x_{t,I}u_t(I)\).

The objection that survived

Scaling supply changes one shared partitioned path into a capacitated interval-assignment model, so Algorithm 5's proof does not itself establish the continuous theorem and the conventions for \(q_t\) and empty bundles require care.

fatal: False

What the mirror covers

The mirror covers the MMS allocation algorithm and motivates a continuous utilitarian price-of-fairness problem. It does not directly cover the paper's PROP1, egalitarian-welfare, goods, or two-agent results, nor does it transfer the discrete Θ(n) bound automatically.

Open questions for a prover

  • Can Algorithm 5's prefix and final-agent proof be generalized to capacitated mass assignments and type-wise \(q_t\) in polynomial time?
  • What is the exact continuous price of fairness as a function of \(\tau\), \(\mu_{\min}\), and the supply granularity \(\rho\)?
  • Which empty-bundle and per-capita-supply convention gives the exact finite/high-multiplicity dictionary?

The case FOR (proponent)

The strongest positive case is a high-multiplicity version of the paper’s chore-allocation problem that keeps chores indivisible and bundles connected. The lead anchor is Lemma 18, proved in this paper: for a path of indivisible chores, additive normalized valuations, and connected bundles, Algorithm 5 returns an MMS allocation in polynomial time. The algorithm processes the path from left to right, gives a longest feasible prefix to an agent meeting the threshold \(\max\{\mathrm{MMS}_i,-2/n\}\), otherwise gives the leftmost item to the agent valuing it most, and assigns the remainder to the final agent. The MMS values themselves are computable in polynomial time by Lemma 2.

A natural continuous population is a large workforce of interchangeable crews assigned contiguous stretches of a linear maintenance route. A type records the crew’s complete per-location disutility vector; crews of the same type have identical valuations. There may be \(N\) crews but only \(\tau\) types, with \(N\gg\tau\). Item supply scales with the population: \(\rho_j\) is the number of chore units at position \(j\) per unit population. Items remain indivisible. A crew receives one integral interval of positions; only the mass of crews assigned to each interval is fractional.

Formally, let \(T\) be the finite type set, \(\mu_t\) the mass of type \(t\), and \(\mathcal I_m\) the set of integral intervals of the path. A solution is a mass assignment \(x_{t,I}\ge 0\), where \(x_{t,I}\) is the mass of type \(t\) receiving interval \(I\), satisfying \(\sum_I x_{t,I}=\mu_t\) and \(\sum_{t,I\ni j}x_{t,I}=\rho_j\). For additive chore utilities, \(u_t(I)=\sum_{j\in I}u_t(j)\le 0\).

The continuous MMS value of type \(t\) is the largest \(q_t\) for which the per-capita item supply can be distributed among integral intervals so that every interval used with positive mass has value at least \(q_t\). Equivalently, \(q_t\) is obtained by choosing a distribution \(y_I\) over integral intervals with \(\sum_I y_I=1\), \(\sum_{I\ni j}y_I=\rho_j\), and \(u_t(I)\ge q_t\) whenever \(y_I>0\). The continuous allocation is MMS-fair when \(x_{t,I}>0\) implies \(u_t(I)\ge q_t\) for every positive-mass type.

This is the named problem “Continuous Connected MMS Allocation.” Its input is \((T,\mu,\rho,u)\); its output is a feasible mass assignment \(x\) satisfying those type-wise MMS constraints. I expect it to be Class A. There are only \(O(m^2)\) connected interval configurations. Each \(q_t\) can be found by threshold feasibility over those configurations, and the final fair allocation is a linear program. Thus the continuum does not make bundles divisible: it replaces many indistinguishable agents by mass variables over integral bundles.

The high-multiplicity dictionary is exact. Given a finite paper instance with \(N\) agents, type counts \(N_t\), and one copy of each item, set \(\mu_t=N_t/N\), \(\rho_j=1/N\), and scale utilities by \(N\). A finite allocation becomes \(x_{t,I}=\#\{\text{type-}t\text{ agents receiving }I\}/N\). Conversely, rational \(x\), \(\mu\), and \(\rho\) can be realized after clearing denominators. Hence this is not cake cutting or fractional allocation of an item.

A second, stronger anchor is Theorem 19, also proved here: for Chores \(|\) Utilitarian \(|\) MMS with \(n\ge3\), the price of fairness is \(\Theta(n)\). The paper proves an upper bound of \(3n\) using Algorithm 5 and Lemma 18, and a lower bound of \(n/5\) using the explicit construction in Lemma 31. This is the paper’s tight quantitative result for the welfare loss caused by MMS fairness.

The corresponding “Continuous Chores–Utilitarian–MMS Price of Fairness” asks, for the same \((T,\mu,\rho,u)\), for the maximum utilitarian welfare \(F_U\) among continuous MMS allocations, the unconstrained optimum \(OPT_U\), and the worst-case ratio \(F_U/OPT_U\) under the paper’s chores convention. I expect the per-instance optimization to remain Class A, since both the unconstrained and MMS-constrained optima are configuration LPs. The interesting theorem is then not whether one can compute an allocation, but how the discrete \(\Theta(n)\) loss transforms into a bound involving \(\tau\), the smallest positive type mass, and the item-supply granularity.

The discrete lower-bound construction may partly transfer: its special agent becomes a small-mass special type, while the other \(n-1\) agents form a common type. Thus the continuous price need not become constant merely because there are few types; it may scale like an inverse mass or supply parameter. Conversely, if every type has mass bounded below and supplies are genuinely replicated, the individual-agent obstruction may disappear. Determining which of these regimes is correct is precisely the useful continuization question.

The mirror is plausible because it preserves the paper’s central objects—indivisible chores, additive valuations, connected bundles, MMS fairness, and utilitarian welfare—and changes only the population representation. I would not claim mirrors for every table entry, especially the PROP1 and egalitarian results, because their “one item” and worst-agent conditions may require separate continuum definitions.

The weakest point is that the paper does not contain a named NP-hardness result; its anchors are polynomial-time and price-of-fairness results. Also, continuum MMS is a new definition forced by the atomless limit rather than a definition stated by the authors. If the anchor rule accepts named polynomial algorithms and approximation/price results, Lemma 18 and Theorem 19 give a solid positive case. If it requires only explicit complexity-class theorems, Lemma 18 is the safer anchor, while the broader price-of-fairness mirror should be treated as a natural research question rather than an already-established theorem.

The case AGAINST (opponent, writing after the proponent)

The strongest negative argument is a limit-order obstruction. Lemma 18 concerns one finite path of indivisible items partitioned among \(N\) agents. If that inventory is held fixed while \(N\) grows, then \(\rho_j=1/N\), and the total mass receiving nonempty bundles is at most \(m/N\). Almost all population therefore receives the empty bundle; for goods, the MMS threshold collapses to \(0\), and the welfare objective becomes supported on vanishing mass. Requiring every agent to receive a nonempty block instead prevents \(N\gg m\). Thus the literal high-multiplicity limit is degenerate.

The proponent’s repair—scaling the item supply to \(N\rho_j\)—is coherent, but it changes the paper’s central resource structure. Bundles can now overlap in position, so the allocation is no longer a partition of one path; it is a capacitated interval-assignment problem over many replicated paths. That is a legitimate extension, especially since per-capita supply scaling is allowed here, but it is not a direct mirror of the single-path theorem. The paper’s Algorithm 5 and its proof do not establish the proposed continuous result; the configuration LP does.

Theorem 19 is weaker as an anchor. Its lower-bound instance uses one exceptional agent, hence a type of mass \(1/N\), and simultaneously lets the number of item positions grow as \(3N-2\). With fixed positive type masses and a fixed finite route, that particular obstruction disappears. After population normalization, \(N\) is no longer a canonical parameter: one must introduce \(\mu_{\min}\), route length, or supply granularity by hand. A resulting bound in \(1/\mu_{\min}\) or supply granularity would be an interesting new extremal problem, but it would not be the paper’s \(\Theta(N)\) result transferred unchanged.

That is the best case against the proposal. It defeats the naive fixed-inventory mirror and downgrades Theorem 19 to an open extension. It does not, however, defeat the repaired Lemma 18 mirror: rational mass assignments over integral intervals can be expanded into finite multi-copy instances, and the MMS-constrained welfare problem is genuinely a configuration LP. I therefore cannot honestly sustain the universal claim that no worthwhile mirror exists. The defensible negative verdict is only that the direct mirror is degenerate and the price-of-fairness mirror is not yet anchored by the paper’s theorem.
