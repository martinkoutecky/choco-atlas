The continuous mirror question

Given ordered item types \(a\in M\), rational per-capita supplies \(q_a\), and an explicit blacklist \(\mathcal F\) of pairs of intervals, decide whether a unit-mass population can each receive an integral interval bundle. Writing \(x_S\geq 0\) for the mass receiving interval \(S\), require \(\sum_S x_S=1\), \(\sum_{S:a\in S}x_S=q_a\) for every item type \(a\), and \(x_Bx_{B'}=0\) for every \((B,B')\in\mathcal F\).

The model it lives in

A nonatomic population of unit mass with one type, whose members share the blacklist compatibility constraints. Each individual receives an integral interval bundle; \(x_S\) records the fraction receiving \(S\), while rational per-capita item supplies \(q_a\) enforce the allocation totals. The decision question is whether such a mass allocation exists.

What the mirror covers

The mirror covers Theorem 10’s blacklist allocation-feasibility problem, including its contiguous restriction. It does not cover the paper’s interactive EF1 results or establish hardness when blacklists must obey the closure property of realizable EF1 feedback.

Open questions for a prover

  • Does the mass-allocation problem remain NP-hard when the blacklist satisfies the closure property induced by monotone valuations and actual EF1 feedback?

The case FOR (proponent)

My lead is Mass Forbidden-Tuple Allocation, a continuous version of the allocation step in Theorem 10.

The anchor is Theorem 10, “NP-Completeness of Allocation Step,” proved in this paper. It states that deciding whether a given blacklist permits an almost-contiguous allocation is NP-complete, and remains NP-complete when every bundle in a blacklist tuple is an interval and the sought allocation must be contiguous. The paper proves this by reduction from Independent Set. The mirror below targets that allocation-feasibility problem, not EF1 existence as a whole.

Take a population of mass \(1\) with a single agent type: everyone has the same bundle-compatibility behavior. There are \(m\) item types, each with a rational per-capita supply \(q_a\), and a blacklist \(\mathcal F\) of ordered pairs of intervals. A solution is a distribution \(x_S\geq 0\) over integral bundles \(S\) (here, intervals), where \(x_S\) is the fraction of the population receiving \(S\). It must satisfy
\[ \sum_S x_S=1,\qquad \sum_{S:\,a\in S}x_S=q_a\quad\text{for every item type }a, \]
and no forbidden pair may both occur with positive mass: \(x_Bx_{B'}=0\) for every \((B,B')\in\mathcal F\). Thus each person still receives an indivisible bundle; only the type-level allocation is fractional.

This is a plausible high-multiplicity regime for a large recurring allocation program: many otherwise identical participants receive bundles of standard resource slots, and failed proposals have produced a common blacklist of incompatible bundle pairs. The item supplies scale with population size. In the theorem’s hard instances, cloning every agent and every item \(r\) times gives \(rn\) agents and \(r\) copies of each item; after normalizing population mass to \(1\), each item type has supply \(1/n\). The continuous version permits arbitrary real masses of agents to receive each bundle. The reduction’s blacklist is symmetric across agent identities, so one type suffices.

The Independent Set reduction still works with those real masses. Given \(G=(V,E)\) and target \(k\), use \(n=2|V|-k\), the \(2|V|\) ordered items \(a_{v,1},a_{v,2}\), supply \(q_a=1/n\) for each, and the blacklist from Theorem 10. It permits two-item bundles only for vertex pairs \(\{a_{v,1},a_{v,2}\}\), and forbids the pairs corresponding to graph edges. Let \(x_v\) be the mass receiving vertex \(v\)’s two-item bundle. Each \(x_v\leq 1/n\), and the vertices with \(x_v>0\) form an independent set. Total item mass is \(2|V|/n\); since every allowed bundle has size at most two, the mass \(y=\sum_v x_v\) receiving two-item bundles must satisfy \(2|V|/n\leq 1+y\). Hence \(y\geq k/n\), so at least \(k\) vertices have positive mass. Conversely, an independent set of size \(k\) gives a feasible allocation: put mass \(1/n\) on each selected pair bundle and mass \(1/n\) on each remaining item’s singleton bundle. The masses sum to \(1\) and meet every item supply exactly. This proves NP-hardness even though the population itself has no finite agent count. With rational supplies and an explicit blacklist, the problem is also in NP: any feasible solution can be reduced to support of size at most \(m+1\), with rational masses of polynomial bit length.

I expect hardness to transfer. The reduction’s combinatorics live in the item-pair conflict graph, while fractional mass only changes how much of each permitted bundle is used. This is a Class B style result for the stated allocation question.

The scope is deliberately narrow: it mirrors Theorem 10’s generalized blacklist allocation step, not the paper’s central interactive EF1 problem. The weakest point is also the important one. The paper notes that its hardness construction can violate the closure property obeyed by blacklists generated by actual EF1 feedback. So this mirror establishes hardness for a precise subproblem the authors study, but does not establish hardness for continuous EF1 interaction under realizable feedback. A natural next question is whether the continuous problem remains hard when the blacklist must satisfy that closure property.

The case AGAINST (opponent, writing after the proponent)

Theorem 10 is a real computational result, so the negative case cannot rest on the paper lacking something to mirror. Its weakness is that the proposed mirror carries over the theorem’s arbitrary blacklist, while dropping the preference structure that gives the blacklist meaning in the paper.

For an actual EF1 witness, the forbidden pair comes from an agent’s valuation. With monotone goods, that relation obeys the closure property the authors identify: if \(B\) is forbidden against \(B'\), shrinking the agent’s own bundle or enlarging the other bundle preserves the violation. The Independent Set reduction uses graph-specific pair exclusions that need not obey this property. The paper itself flags this gap. Calling the arbitrary relation a single type’s “compatibility behavior” makes the mass allocation mathematically coherent, but replaces a valuation with an external bundle-conflict system. The resulting hardness is for a new constrained-packing problem, not for the paper’s preference-based allocation problem.

A closer continuous mirror would give each type an actual valuation, scale item supplies with population mass, and ask for an allocation in which every individual still receives an integral bundle and no used bundle pair creates an EF1 violation. That is a sensible population-level question. Theorem 10’s reduction does not answer it, though: its hard instances need not be realizable by such types. The paper’s own result therefore does not establish the computational obstacle claimed for this repaired mirror.

That is the strongest case against this anchor: its hardness proof fails the semantic gate for the paper’s fair-division model. The broader claim that *no* worthwhile mirror exists is weak. The repaired question remains plausible, and this paper gives no basis for ruling it out. If the reader accepts arbitrary compatibility constraints as part of the paper’s problem, the proponent’s anchor survives.
