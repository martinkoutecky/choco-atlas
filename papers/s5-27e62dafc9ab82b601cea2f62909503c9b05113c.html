The continuous mirror question

Given commodities \(N\), a finite set of types \(T\), rational masses \(\mu_t>0\) summing to \(1\), endowments \(e_t\in\{0,1\}^N\), and integer valued utilities \(u_t:\{0,1\}^N\to\mathbb{Z}\cup\{-\infty\}\) sharing a unimodular demand type \(D\), find a competitive equilibrium: a price vector \(p\) and assignment masses \(\lambda_{t,S}\ge 0\) such that \(\sum_S\lambda_{t,S}=\mu_t\), \(\sum_{t,S}\lambda_{t,S}\mathbf{1}_S=q=\sum_t\mu_t e_t\), and \(\lambda_{t,S}>0\) only when \(S\in\arg\max_R(u_t(R)-p\cdot\mathbf{1}_R)\). Each unit of mass receives an integral bundle.

The model it lives in

Use complete types \(t\) carrying mass \(\mu_t\), utility \(u_t\), and endowment \(e_t\). Choose assignment masses \(\lambda_{t,S}\) to maximize \(\sum_{t,S}\lambda_{t,S}u_t(S)\), subject to type mass and per capita supply \(q=\sum_t\mu_t e_t\); return supporting competitive equilibrium prices \(p\). Bundles remain integral for each agent, while mass of one type can be divided across bundles.

The case FOR (proponent)

The strongest mirror is the paper’s price-taking equilibrium computation, not its strategic-incentive result. Consider a large exchange for standardized inputs among many small firms. Many firms share the same bundle valuations and endowments, perhaps because they use a small number of recurring production or procurement templates. Let the number of firms be \(M\), and let the number of distinct complete types be \(\tau\), with \(\tau\ll M\). Each type includes its utility and endowment, so agents grouped together are identical in every respect the model uses. To make this a genuine large-market regime, supplier endowments scale with the population: the relevant supply is per capita.

Here is a precise mirror: Continuous Unimodular-Type Market Clearing. The input is a finite set \(N\) of \(n\) commodities and a finite support \(T\). Each type \(t\in T\) has rational mass \(\mu_t>0\), with \(\sum_t\mu_t=1\); an endowment \(e_t\in\{0,1\}^N\); and an integer-valued utility \(u_t:\{0,1\}^N\to\mathbb Z\cup\{-\infty\}\). Assume every type has the same unimodular demand type \(D\). The per-capita supply is \(q=\sum_t\mu_t e_t\).

A solution is a common price vector \(p\in\mathbb Q^N\) and nonnegative masses \(\lambda_{t,S}\), where \(\lambda_{t,S}\) is the mass of type \(t\) assigned the integral bundle \(S\subseteq N\). They must satisfy
\[ \sum_{S\subseteq N}\lambda_{t,S}=\mu_t,\qquad \sum_{t\in T}\sum_{S\subseteq N}\lambda_{t,S}\mathbf 1_S=q, \]
and \(\lambda_{t,S}>0\) only if \(S\in\arg\max_{R\subseteq N}(u_t(R)-p\cdot\mathbf 1_R)\). Equivalently, find a welfare-maximizing feasible assignment and supporting competitive-equilibrium prices. The assignment variable can be fractional by type, but every member of the population receives an indivisible bundle. Suppliers can be represented as types with endowments and utilities, so the supply-side change is explicit.

My anchor is Theorem 3, proved in this paper. Under (A1), integer private values, and (A2), a common unimodular demand type, the UCD auction starting from any integer price vector finds an integer competitive-equilibrium price vector in finitely many rounds. The theorem is about the underlying market-clearing problem; its auction uses demand reports and updates prices using the search set. It is not a polynomial-time bound: the paper proves finite convergence, not membership in P.

I expect the stated continuous problem to be Class A when utilities are given as explicit bundle tables. Its welfare formulation is a linear program with variables \(\lambda_{t,S}\), so it can return an efficient assignment and supporting prices in time polynomial in the explicit input size, roughly \(\tau 2^n\) bundle entries and their bit length. This is a computational mirror of Theorem 3’s equilibrium-finding task, rather than a claim that the paper’s particular auction has a polynomial round bound. Natural follow-up questions are whether a type-compressed version can run in time polynomial in \(n,\tau,L,\lvert D\rvert\) when valuations are supplied by demand oracles, and whether the integral-price conclusion of Theorem 3 persists for rational type masses.

The soft spot is substantial: the paper’s distinctive mechanism contribution concerns strategic bidders with market power, while an atomless population makes each individual too small to manipulate prices. Theorem 4’s VCG outcome and Theorem 5’s ex post perfect equilibrium therefore do not carry over as stated. This mirror also replaces the paper’s single seller with a scaled population of suppliers. I think authors working on the UCD auction would recognize the resulting equilibrium-computation question as theirs, since their own basic auction is explicitly the price-taking core of the paper. But the positive case is for that core alone; it should not be presented as a continuous version of their strategy-proof mechanism.

The case AGAINST (opponent, writing after the proponent)

The only strong anchor is Theorem 3, and it is a real algorithmic result. I can’t honestly argue that the paper has no computational result to mirror. The narrower objection is that Theorem 3 proves finite termination, not a complexity bound: it gives no polynomial round count or bit complexity. Its most faithful continuous counterpart would therefore need to define what computational question is being asked beyond termination.

The proposed welfare LP is a coherent high multiplicity market model, but it changes the task. It takes full utility tables as input and centrally computes an assignment and supporting prices. The UCD auction instead elicits demand sets over time and updates prices using them. A closer mirror would weight the type-level demand reports by their masses and study the resulting price updates. That would preserve the paper’s price-taking core, but the population continuum would enter mainly as weights in an aggregate update. Whether that extension has an interesting complexity theory is a question to formulate and establish, not a consequence of Theorem 3.

The paper’s strategic results do not close this gap. In an atomless population, an individual’s effect on market prices and VCG externality can vanish; keeping a strategically pivotal bidder would require a different population model. That makes the paper’s distinctive mechanism harder to carry over, though it does not defeat a mirror of the price-taking theorem.

So the strongest case against is limited: the proponent’s LP does not mirror the auction algorithm, and Theorem 3 supplies no complexity bound that the proposed LP can directly extend. But a mass-weighted UCD auction is plausible, and the authors could reasonably recognize it as their equilibrium-computation problem. I can’t make the universal claim—that no worthwhile continuous mirror exists—convincing on this evidence.
