The case FOR (proponent)

There is no numbered result in this paper that classifies a problem as NP-hard, polynomial-time solvable, or otherwise computationally hard. The conclusion does say, without a numbered theorem, that recognizing fair FSSP solutions is binary NP-hard and that pseudopolynomial dynamic programs can find Pareto-efficient solutions. Under your anchor rule, those statements cannot support the case. The closest named result for a continuous mirror is Theorem 16, proved in this paper, though it is a price-of-fairness characterization rather than a complexity result.

Theorem 16 concerns maximin fairness for FSSP with separate item sets and a bound \(\alpha\) on item weights. It proves
\[ \operatorname{PoF}_{MM}(\alpha)=2-\frac1\alpha \quad\text{for } \frac23\le\alpha\le1, \]
\[ \operatorname{PoF}_{MM}(\alpha)=\frac12 \quad\text{for } \frac12\le\alpha<\frac23, \]
and
\[ \frac{1}{\lceil 1/\alpha\rceil} \le \operatorname{PoF}_{MM}(\alpha)\le\alpha \quad\text{for }\alpha<\frac12. \]
That is the one result I would mirror.

A plausible high-multiplicity setting is two equally sized, large cohorts competing for a bounded resource: for example, residents in two districts, where each resident has the same menu of indivisible service blocks as everyone else in their district. A type specifies the district and its complete per-person item menu and weights. Set \(\mu_A=\mu_B=1/2\); the number of residents is large while the support size is \(\tau=2\). Scale total capacity with population, so the per-person average capacity is \(1/2\), corresponding to repeating the paper’s two-agent instance across many copies.

Call the mirror Two-type continuous maximin packing. An instance gives the rational item weights for each type, all at most \(\alpha\), and the population masses. A feasible allocation specifies, for each type \(t\), frequencies \(\lambda_{t,S}\) over integral bundles \(S\) from that type’s menu. Each unit of mass receives an integral bundle; different portions of the type’s mass may receive different bundles. Require
\[ \sum_{t\in\{A,B\}}\mu_t\sum_S\lambda_{t,S}w_t(S)\le \frac12, \qquad \sum_S\lambda_{t,S}=1. \]
The type’s utility \(u_t\) is its average allocated weight. The system optimum maximizes \(U=\sum_t\mu_tu_t\); a maximin fair solution maximizes \(\min(u_A,u_B)\), with the paper’s Pareto-efficiency requirement. The question is to compute these values for an instance and characterize the worst-case continuous price of fairness over instances with item bound \(\alpha\).

I expect this mirror to be tractable, with \(\operatorname{PoF}^{cont}_{MM}(\alpha)=0\) for every \(\alpha\). Because each type’s mass can be divided among integral bundles, its average utility can take any value from zero to its total per-person inventory weight. The feasible average utilities therefore form a box cut by the capacity constraint. Any Pareto-efficient fair allocation uses all available resource up to capacity, just as the system optimum does. Computing a maximin point reduces to a small linear program in \(u_A,u_B\). The discrete losses in Theorem 16 arise from packing whole item lists in one two-agent instance; the replicated population lets the decision maker distribute those lists across fractions of a type while each person still receives an integral bundle.

The authors could plausibly recognize this as their problem in a cohort setting: the resource, item weights, central decision maker, sum-of-utilities objective, maximin fairness, and price-of-fairness comparison all remain. This case covers only the separate-item maximin result in Theorem 16. It does not establish a mirror for the paper’s Kalai–Smorodinski, proportional-fair, or shared-item results.

The weakest point is that the paper’s two agents are the actual fairness subjects, while this mirror treats them as cohorts and measures fairness by type-average utility. If the authors require fairness for every named resident, or reject repeated per-person inventories as changing what an “agent” is, they may not accept the mirror. The model’s positive case rests on the programme’s high-multiplicity convention that type-level averages can be fractional even when each person receives an integral bundle.

The case AGAINST (opponent, writing after the proponent)

The strongest negative is a scope objection: Theorem 16 characterizes a price-of-fairness distortion; it does not state a complexity classification or an algorithmic result. The paper’s NP-hardness and dynamic-programming claims appear only in its conclusion. So Theorem 16 is a weak anchor for a programme about computational complexity. That objection does not defeat the proposed mirror, though: a tractable optimization problem can still be a worthwhile continuous result.

The better cohort version survives the modelling test. A type can specify a resident’s complete item menu, and every resident can still receive an integral bundle while the continuum allows different fractions of a type to receive different bundles. If \(M_t\) is the total item weight in type \(t\)’s menu, mixtures of the empty and full bundles make any average utility in \([0,M_t]\) attainable. Since utility equals resource use here, the aggregate utility set is just those intervals intersected with the capacity constraint. A Pareto-efficient maximin allocation can use all available capacity, so the proposed mirror’s zero price of fairness follows from a small linear program. That is a simple Class A result, but the programme explicitly allows such results; simplicity alone does not make the question unworthy.

The authors’ cited convex-allocation literature may leave little new price-of-fairness analysis to do: Bertsimas, Farias, and Trichakis study max-min fairness over compact convex utility sets, the kind produced by these population mixtures ([“The Price of Fairness”](https://web.mit.edu/~dbertsim/www/papers/Fairness/The%20Price%20of%20Fairness.pdf)). Under the programme’s rules, that is prior machinery, not a collision: it does not itself continuize the population.

So the honest negative case is narrower than the requested universal claim. The anchor is not a named computational-complexity result, but I cannot convincingly reject the cohort model as a sensible population mirror. If price-of-fairness optimization counts as an eligible computational question, this anchor survives; I would not claim that no worthwhile mirror exists.
