The continuous mirror question

Let \(H\) be a finite set of unit classes and let supported types \(t\) consist of a weak ranking over \(H\) and an endowed class \(e_t\), with rational masses \(\mu_t\). Set \(q_h=\sum_{t:e_t=h}\mu_t\). For an atomless population partitioned into these type cohorts, does there exist a uniform algorithm, polynomial in \(|H|\), \(\tau\), and the mass encoding length \(L\), that specifies a direct exchange rule with a measurable individual assignment \(\alpha(i)\in H\), represented compactly by its mass flows? Each individual must receive one whole unit, and each class must be assigned mass \(q_h\). The rule must be Pareto efficient and individually rational, select a core allocation whenever one exists, and admit no measurable positive-mass coalition whose members can all strictly improve by jointly misreporting or by reallocating their endowed units.

The model it lives in

An atomless housing exchange with finite support over weak-ranking and endowed-class types. Class supplies scale with population mass; the rule assigns whole class units to individuals, while a compact flow records the aggregate assignment and a measurable lift specifies coalition outcomes.

The objection that survived

The proposed flow \(x_{t,h}\) does not identify which individuals in a split type cohort receive each class, so by itself it cannot determine whether every member of a deviating coalition strictly gains; the rule must specify measurable individual assignments.

What the mirror covers

The mirror concerns Theorem 2’s coexistence result, drawing on the weak group strategy-proofness results for TTAS, TC, and HPO. It does not mirror the sufficient-condition proof as a computational result or establish that the finite algorithms run in time polynomial in the mass encoding length.

Open questions for a prover

  • Can a compact rule preserve exact weak group strategy-proofness when a type cohort can split across unit classes?
  • Can its runtime be polynomial in \(|H|\), \(\tau\), and the binary encoding length \(L\), rather than in a finite replication size?
  • Do the continuous rule’s outcomes agree with limits of finite replications?

The case FOR (proponent)

The strongest mirror is a high-multiplicity weak housing exchange. Imagine a large relocation or room-reassignment programme where many units fall into a small number of genuinely interchangeable classes. A type is a weak ranking over those classes together with the class of the unit the agent currently owns. Including the endowed class is essential: it is part of what makes agents of the same type indistinguishable. The regime is plausible when the population is large but the number \(\tau\) of supported preference-and-endowment types and the number \(m\) of unit classes are both modest. If exact addresses matter to preferences, they must be represented as separate classes; the high-multiplicity regime then may disappear.

The continuous population is a distribution \(\mu\) over those types. For class \(h\), its per-capita supply is \(q_h=\sum_{t:e_t=h}\mu_t\), where \(e_t\) is type \(t\)’s endowed class. The decision variable is a flow \(x_{t,h}\): the mass of type \(t\) assigned a unit of class \(h\). It must satisfy \(x_{t,h}\geq 0\), \(\sum_h x_{t,h}=\mu_t\), and \(\sum_t x_{t,h}=q_h\). Each agent still receives one whole unit; the flow records how the mass of a type is split among classes. This population-and-supply co-modification is part of the mirror.

My lead anchor is Theorem 2. It states that for housing markets with weak preferences there are computationally efficient rules that are Pareto efficient, weak-core-selecting (hence individually rational), weakly group strategy-proof (hence strategy-proof), and core-selecting whenever the core is non-empty. The paper’s new contribution is the weak group strategy-proofness argument, built on Theorem 1 and the results for the named rules. The efficiency claim draws on prior implementation bounds: in particular, the Top Cycles rule has a polynomial implementation, \(O(n^6)\), cited from Jaramillo and Manjunath [8]. So this is a computational-efficiency anchor, but not a new algorithmic bound proved in this paper. The paper gives no NP-hardness anchor.

Continuous Weak Housing Rule Synthesis is the corresponding question I would hand to a prover. An instance specifies a finite set of unit classes, the weak-order-and-endowment type domain, and a rational distribution over its \(\tau\) supported types. The task is to give a uniform algorithm that returns a feasible mass allocation flow in time polynomial in \(m,\tau\), and the input bit length \(L\), and whose induced direct-revelation rule has the following guarantees across the domain:

  • Agents weakly prefer their assignments to their endowments, and no feasible reassignment makes everyone weakly better off and a positive mass strictly better off.
  • No positive-mass coalition can reallocate its own endowed supply so that every member strictly improves; when a core allocation exists, the rule selects one.
  • No positive-mass coalition can jointly misreport its rankings so that every member strictly improves.

Coalitions here may split a type’s mass, and outcomes are understood as assignments of whole units to agents, represented in aggregate by the flow. The question has no welfare-maximization objective: as in the anchor, it asks for a computable exchange rule satisfying the stated properties. It asks whether the coexistence result of Theorem 2 survives when a large society is represented by masses. That is a question the authors could plausibly recognize as theirs: it retains endowment-conserving exchange, weak preferences, and coalitional incentive compatibility.

I would tentatively expect a Class A route: finite type support and class supplies suggest an aggregated departure-and-trading algorithm or a flow formulation. But the result is open as stated. For any proposed rule, one must prove the coalition guarantees when types can split, and achieve runtime polynomial in the *encoding length* of the masses, not just in the number of agents. Useful follow-up questions are whether the continuous rule agrees with limits of finite replications, and whether exact weak group strategy-proofness can coexist with type-level aggregation.

The weak point is substantial: the paper’s finite economy gives each agent a distinct endowed object, while its rules use priorities over agents or objects. In a high-multiplicity model, replacing named units with classes and individual priorities with class-level tie-breaking could change the mechanisms or break their proofs. Also, the paper’s polynomial bound in \(n\) says nothing by itself about polynomial time in \(\tau\) and \(L\). Thus this is a credible mirror of the *housing exchange problem and its guarantee*, not a claim that the paper’s particular algorithms already extend to a continuum.

The case AGAINST (opponent, writing after the proponent)

The only clear computational anchor is Theorem 2: it asserts the existence of computationally efficient housing rules with the stated guarantees. Theorem 1 is a sufficient condition for an incentive property, not a complexity result, and the paper’s runtime bounds for the named rules come from prior work. So there is a real result to discuss, but the paper’s new contribution is the incentive proof, not a new algorithm or complexity classification.

The proposed mirror has a more basic gap: its flow does not by itself define the direct-revelation rule whose incentives are to be tested. A flow can assign part of one reported type to one class of unit and the rest to another. But weak group strategy-proofness asks whether every member of a particular coalition strictly improves. To answer that, the model must say which people in the cohort receive which units. Two implementations of the same flow can give different members the better units, and thus have different profitable coalitions.

There are repairs, but each changes the object being mirrored. A deterministic partition of a type cohort needs a label or priority to select who receives each class; if that feature affects outcomes, it belongs in the complete type, potentially eliminating the repeated types that made the high-multiplicity regime attractive. Random assignment keeps agents with the same type symmetric, but requires a lottery-based incentive notion. Treating the flow as a fractional bundle for each person would change the indivisible housing allocation itself. These may all be worthwhile models, but the paper does not choose among them, and its Theorem 2 does not settle any of them.

There is also a complexity gap. Simulating the finite rules on a replicated electorate gives a runtime polynomial in the replication size \(n\), not necessarily in \(\tau\) and the bit length \(L\) of the masses: a rational input may require a denominator exponentially large in \(L\). A compressed algorithm could be an interesting result, but “rule synthesis” asks for much more than the paper’s theorem, which evaluates particular rules on finite profiles. It needs a specified individual-level allocation semantics and a new complexity question.

This is the strongest negative case I can defend: the proposed flow formulation does not yet mirror the theorem’s incentive guarantees, and the natural repairs move the question into different models. It does not establish the universal claim that no worthwhile mirror exists. For instance, an exchange among genuinely interchangeable classes of offices could make high multiplicity plausible, and a carefully specified rule for assigning whole offices might be worth studying. The negative case is therefore weak at the universal quantifier; I would reject this particular formulation as a demonstrated mirror, but not claim that every plausible continuous housing-exchange mirror is unworthy.
