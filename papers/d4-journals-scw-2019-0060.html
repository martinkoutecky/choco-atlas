The continuous mirror question

Given finite worker-type and position-type sets \(A,B\), rational masses \(\mu\in\mathbb{Q}_{\ge 0}^{A}\), \(\nu\in\mathbb{Q}_{\ge 0}^{B}\), and rational pair surpluses \(w_{ab}\ge 0\), find an exact finite description of a piecewise-linear path \((\alpha(s),\beta(s),u(s),v(s))\), \(s\in[0,1]\). Require \(\alpha(0)=\beta(0)=0\), \(\alpha(1)=\mu\), \(\beta(1)=\nu\), nondecreasing masses and per-type payoffs, and a core allocation at every \(s>0\): \(u_a(s),v_b(s)\ge 0\), \(u_a(s)+v_b(s)\ge w_{ab}\), and \(\sum_a\alpha_a(s)u_a(s)+\sum_b\beta_b(s)v_b(s)=W(\alpha(s),\beta(s))\), where \(W(\alpha,\beta)=\max\{\sum_{a,b}w_{ab}z_{ab}: z\ge 0,\ \sum_b z_{ab}\le\alpha_a,\ \sum_a z_{ab}\le\beta_b\}\).

The model it lives in

A finite-support assignment market with type masses and per-unit payoffs. The decision variables are participating masses \(\alpha,\beta\), payoffs \(u,v\), and, in the core-value LP, matched mass \(z_{ab}\); the objective is to maximize \(\sum_{a,b}w_{ab}z_{ab}\) at each stage. Each unit of mass receives one match, while the type-level matching masses may be fractional.

What the mirror covers

The mirror covers Theorem 3.1’s existence question. It does not capture the prescribed extreme endpoints of Corollary 3.1 or the terminal-set characterizations in Propositions 4.1 and 4.2.

The case FOR (proponent)

There is a plausible population-continuum mirror here, but the paper has no named computational result to anchor it to. Theorem 3.1, proved in this paper, says every finite assignment game has a monotonic core allocation path. Corollary 3.1 says every extreme core allocation can be the terminal allocation of such a path. Propositions 4.1 and 4.2 say that in gloves games and Böhm–Bawerk games, respectively, the MCAP terminal allocations are exactly the extreme core allocations. These are existence and structural results; none states a complexity classification or analyzes an algorithm’s running time. The proof of Theorem 3.1 is constructive, which offers an algorithmic lead, but it does not let me honestly report that the paper proves an algorithm is in P.

The most convincing setting for a mirror is a large labor market: many workers and positions, but relatively few distinct valuation profiles. A worker type would specify the worker’s value for every position type; a position type would specify its value for every worker type, along with any relevant capacity or outside-option data. The input would be finite type sets \(A,B\), rational masses \(\mu_a,\nu_b\), and rational pair surpluses \(w_{ab}\). Here mass is the amount of each type in the market, and the regime is many agents \(N\) relative to support size \(\tau=|A|+|B|\).

A concrete prospective problem is Continuous MCAP Search. Find a path of participating masses \(\alpha_a(s),\beta_b(s)\), increasing from zero to \(\mu_a,\nu_b\), and per-unit payoffs \(u_a(s),v_b(s)\). At every stage \(s\), require a core allocation of that mass market:

\[ u_a(s),v_b(s)\ge 0,\qquad u_a(s)+v_b(s)\ge w_{ab}, \]

\[ \sum_a\alpha_a(s)u_a(s)+\sum_b\beta_b(s)v_b(s) = \max_{z\ge0} \left\{ \sum_{a,b}w_{ab}z_{ab}: \sum_b z_{ab}\le\alpha_a(s),\ \sum_a z_{ab}\le\beta_b(s) \right\}. \]

Require each type’s payoff rate to be nondecreasing while its mass participates. A solution is an exact finite description of the path, for example by finitely many rational linear pieces. Theorem 3.1 is a strong existence precedent for this question, and the paper’s tight-graph construction suggests structural tools to investigate. I would test for tractability using finite-support assignment optimization, but that is a conjecture about the mirror, not a result of this paper.

The soft spot is substantial: finite MCAPs add named players one at a time, and their allocations can distinguish individuals who share a valuation type. The paper does not show that its paths can be represented by a type-homogeneous mass path, or that such a path is efficiently computable. So this is a credible research lead, not an anchored positive case under the stated computational-result requirement.

The case AGAINST (opponent, writing after the proponent)

The main problem for the case for a mirror is that its anchors are not computational results. Theorem 3.1 proves existence of an MCAP; Corollary 3.1 proves that every extreme core allocation can be its endpoint; Propositions 4.1 and 4.2 characterize endpoints in two subclasses. The tight-graph proof is constructive, so it may invite an algorithmic study. But the paper states no complexity result for a computational problem. “Continuous MCAP Search” would therefore be a new problem motivated by the paper, rather than a continuous version of a result it reports.

The labor-market setting is plausible: many workers and positions can share a small number of valuation types. That makes the proposed mirror’s weakness more revealing. Given full-market masses \((\mu,\nu)\) and any core payoff vector \((u,v)\), grow every type proportionally: \(\alpha(s)=s\mu\), \(\beta(s)=s\nu\), for \(s\in[0,1]\), and keep \((u,v)\) fixed. The assignment value satisfies \(W(s\mu,s\nu)=sW(\mu,\nu)\). Pairwise core constraints stay unchanged, while aggregate payoffs scale by \(s\), so the same vector is core at every stage. Payoffs are constant, hence monotone. This gives a one-piece exact path to any terminal core allocation; finding one reduces to finding a core allocation for the full market.

That defeats each stated anchor under this natural continuous formulation. Theorem 3.1’s existence becomes immediate by scaling. Corollary 3.1’s extreme endpoints remain reachable, but they lose their special status because every core point is reachable. The terminal-set characterization in Propositions 4.1 and 4.2 no longer carries over: in the continuous \(2\times2\) gloves market, the equal-split payoff \((1/2,1/2)\) is a valid terminal of the proportional path, even though the paper’s finite-player example excludes its corresponding allocation from MCAP terminals. The path-search question is therefore trivial, and the paper’s finer structural result dissolves.

The strongest salvage is to constrain arrivals: grow one type cohort at a time, or track separate payoffs for infinitesimal arrival tranches to preserve individual order. Those changes could yield interesting research questions. The first imposes a new admission protocol; the second makes the path depend on a continuum of within-type ranks. The paper’s results establish neither version, and neither is the proposed finite-support search problem.

So the negative case is strongest against a paper-anchored continuous mirror: no computational result is stated, and the natural high-multiplicity search collapses under proportional growth. I cannot honestly rule out every worthwhile arrival-constrained assignment-market problem. That is the remaining weakness in the universal claim; such a problem would need its own justification as a new model.
