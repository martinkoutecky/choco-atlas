The continuous mirror question

Given a finite type set \(T\) with rational masses \(\mu_t>0\), \(\sum_{t\in T}\mu_t=1\), a sector map \(\sigma:T\to\mathcal{S}\), symmetric rational link densities \(w_{tu}\in[0,1]\), and \(\alpha,\beta\geq 0\), consider dense regular simple-graph sequences realizing those type proportions and link densities. For each type \(t\), determine the limiting per-firm power \(p_t=\lim_{n\to\infty}\varphi_i^{(\alpha,\beta)}(E_n,\Pi_n)/n\) for vertices \(i\) of type \(t\), where \(D_{t,A}=\sum_{v:\sigma(v)=A}\mu_v w_{tv}\), \(D_t^{\mathrm{ext}}=\sum_{v:\sigma(v)\ne\sigma(t)}\mu_v w_{tv}\), and \(p_t=\alpha D_t^{\mathrm{ext}}+\beta\sum_{u:\sigma(u)\ne\sigma(t)}\mu_u w_{tu}\,D_u^{\mathrm{ext}}/D_{u,\sigma(t)}\).

The model it lives in

A continuum population of firms distributed over \(\tau\) sector-and-link-profile types, with masses \(\mu_t\). The symmetric link-density matrix \(w\) describes regular cross-type access patterns, and \(\alpha,\beta\) retain their licensing-value interpretation. Compute the normalized power \(p_t\) for each type from the limiting degree profiles.

What the mirror covers

The mirror covers Theorem 15 and the underlying power-index calculation for dense regular block-network populations. It leaves the monotonicity and ranking results, core analysis, and axiomatic characterizations aside.

Open questions for a prover

  • Can useful error bounds relate the type-level limit to finite networks whose degree profiles are only approximately regular?
  • Can the same power calculation be extended to optimize changes in cross-sector link densities?

The case FOR (proponent)

The strongest affirmative case is narrow and rests on one result. The paper gives no named NP-hardness, polynomial-time, or parameterized-complexity classification. Its closest computational anchor is Theorem 15, proved in the paper: for the proposed TU game on a graph with a priori unions, each firm’s Shapley value equals its \((\alpha,\beta)\)-power index,
\[ \mathrm{Sh}_i =\alpha d_i(N\setminus S^i) +\beta\sum_{j\in N(i,S^{-i})} \frac{d_j(S^{-i})}{d_j(S^i)}. \]
The proof uses the potential-function characterization cited as Theorem 12, but Theorem 15 itself is proved here. It is an exact computation result, though not an explicit complexity classification.

A plausible mirror is Block-Continuum Power Allocation, for standardized licensing ecosystems with many firms. A type is a sector, technology family, and licensing role, together with its regular link profile to the other types. The society is a distribution over \(\tau\) such types: \(\mu_t\) is the fraction of firms of type \(t\), with rational masses summing to one. A symmetric rational value \(w_{tu}\in[0,1]\) gives the fraction of type \(t\)’s links to type \(u\). Thus firms of the same type are indistinguishable for the index: they share a sector and the same per-type degree profile. The many-firm regime might be a platform ecosystem with numerous small vendors and integrators following a relatively small catalogue of licensing and compatibility patterns.

The instance consists of the type support, masses \(\mu\), sector map \(\sigma(t)\), link densities \(w\), and coefficients \(\alpha,\beta\). The network is fixed; there is no action variable or optimization objective in the paper’s problem. The task is to compute the limiting per-firm power for each type—the finite Shapley value divided by population size along regular block-network replications. Define
\[ D_{t,A}=\sum_{v:\sigma(v)=A}\mu_vw_{tv}, \qquad D_t^{\mathrm{ext}}=\sum_{v:\sigma(v)\ne\sigma(t)}\mu_vw_{tv}. \]
The required output is the vector \(p=(p_t)_{t\in T}\), where
\[ p_t=\alpha D_t^{\mathrm{ext}} +\beta\sum_{u:\sigma(u)\ne\sigma(t)} \mu_u w_{tu}\, \frac{D_u^{\mathrm{ext}}}{D_{u,\sigma(t)}}. \]
Whenever \(w_{tu}>0\), the denominator is positive because type \(t\) has positive mass and \(w\) is symmetric. The formula is the limit of the scaled Theorem 15 formula for regular block-network sequences.

I expect this mirror to be tractable: the type-level values can be computed with polynomially many rational arithmetic operations in \(\tau\), the number of sectors, and the input bit length. The authors could plausibly recognize it as a population limit of their network-power calculation, particularly since they identify weighted networks as a direction for future work. It covers Theorem 15 and the underlying power index; it does not attempt to continuize the paper’s axiomatization, core analysis, or rank-reversal results. It also does not produce a new hardness question: the finite result already supplies an explicit formula.

The weak point is the regime. Licensing ties between firms are often idiosyncratic, so a small set of link-profile types may not describe real networks well. The proposed model is most convincing where firms repeat standardized roles and access patterns; it is a block-network population limit, not a mirror for arbitrary graphs. Further questions would be whether useful discrete-to-continuous error bounds hold when the profiles are only approximately regular, and whether one can extend the power calculation to optimize changes in cross-sector link densities.

The case AGAINST (opponent, writing after the proponent)

The paper’s computational anchor is Theorem 15, which identifies each firm’s Shapley value with its power index. It is a proved result, but it does not assert the complexity of a computational problem: there is no input–output task, complexity bound, or algorithmic classification. The other named results concern network properties, game representations, and axioms. That leaves no complexity result here for a continuous mirror to classify.

The strongest version of the proposed mirror is mathematically coherent. In a large, regular block network, firms can share a sector and link profile, and the normalized power values can be written in terms of type masses and link densities. The index’s anonymity and dependence on degrees make repeated profiles plausible; I would not argue that firms are too individuated, or use existing high-multiplicity work against the idea.

But this mirror changes the paper’s object into a block-network limit and asks for type-level power values. Theorem 15 already supplies the relevant finite-graph formula; the type-level expression translates it to that new representation. Asking for a computational classification of the resulting formula would be a new algorithmic question, not a mirror of a computational question the paper posed. If the model is generalized beyond regular blocks, the added computational challenge would depend on how the network or kernel is encoded, rather than on a complexity claim in this paper.

So my case against is a case against spending ChoCo’s time on this anchor, not proof that no sensible continuous version exists. The proponent’s standardized licensing scenario could pass the high-multiplicity plausibility test. That is where the negative case is weak: the population model is credible, but the paper gives the programme no computational result to investigate in it.
