The continuous mirror question

Given applicant types \(A\), job types \(J\), strict rankings over the opposite type set, and positive rational masses \(\mu_a,\nu_j\) summing to one on each side, define \(\mathcal S\) as the set of flows \(x_{aj}\ge 0\) with row sums \(\mu_a\), column sums \(\nu_j\), and, for each \(a,j\), at least one of \(\sum_{j':\,j'\succeq_a j}x_{aj'}=\mu_a\) or \(\sum_{a':\,a'\succeq_j a}x_{a'j}=\nu_j\). Compute the number \(b_0(\mathcal S)\) of connected components; the extremal version asks for its maximum over instances with \(p\) applicant types, \(q\) job types, and mass encoding length at most \(L\).

The model it lives in

A balanced atomless placement market whose agents are grouped into complete preference types, with rational mass per type. The decision variable is a mass flow between types; stability rules out any type pair with positive mass on both sides able to improve by matching. The finite output measure is the number of connected components of the resulting stable-flow set.

The objection that survived

Connected-component counting identifies distinct flows within one connected family, and the proponent gives no reason this should be the preferred measure of stable-outcome multiplicity.

fatal: False

What the mirror covers

The mirror covers Theorem 1’s stable-outcome multiplicity question. It leaves the roommates corollary and the general counting lemma unmirrored.

Open questions for a prover

  • Can the stable-flow set have positive-dimensional connected components under strict type rankings?
  • How does its component count relate to stable matchings in finite markets formed by cloning types?
  • Can one bound the maximum component count tightly in terms of the number of types and mass encoding length?

The case FOR (proponent)

My lead is an extension of the paper’s solution-counting question. The anchor is Theorem 1, proved in this paper: for any stable matching instance with \(n\) jobs and \(n\) applicants, the number of stable matchings satisfies \(\mathrm{SM}(n)\le 3.55^n+O(1)\). This is a bound on the size of the stable-outcome set, rather than a P-versus-NP classification. It has a direct algorithmic consequence: the paper uses it to improve an exponential running-time bound for an algorithm for popular roommates.

Lead mirror — Stable-Mass Component Counting. An instance has applicant types \(A\), job types \(J\), strict rankings by each type over the opposite side’s types, and rational masses \(\mu_a,\nu_j>0\), with \(\sum_{a\in A}\mu_a=\sum_{j\in J}\nu_j=1\). A type is a complete preference template for the problem; people or positions in the same type are interchangeable. The decision variable is a mass flow \(x_{aj}\ge 0\), where \(x_{aj}\) is the mass of type \(a\) matched to type \(j\), with row sums \(\mu_a\) and column sums \(\nu_j\).

Call a flow stable if no positive mass of applicants and jobs can both improve by matching to each other. Precisely, for every \(a,j\), require at least one of
\[ \sum_{j':\,j'\succeq_a j}x_{aj'}=\mu_a \qquad\text{or}\qquad \sum_{a':\,a'\succeq_j a}x_{a'j}=\nu_j. \]
The first condition says all of type \(a\) already has a job at least as good as \(j\); the second says all of type \(j\) is already assigned to applicants at least as good as \(a\). These conditions make the stable-flow set \(\mathcal S\) a finite union of rational polyhedra. The problem is to output the exact number of connected components \(b_0(\mathcal S)\). When the stable set consists of isolated points, this is just the number of stable aggregate assignments; when it contains continua, it counts separated families of assignments.

The regime is a balanced, large placement market—say a national graduate-placement cycle—with many applicants and positions but far fewer complete preference templates. An applicant type could specify a shared ranking over job categories; a job type could specify a shared ranking over applicant categories. Mass is the fraction of the cohort in each type, and flow may split a type across several counterpart types. If a relevant preference or cost differs, it defines a different type. Thus the model keeps the paper’s stable matching problem while letting the population become continuous.

I think the authors would recognize this as a genuine analogue of their stable-outcome multiplicity question: it preserves the market, the blocking notion, and the concern with how many distinct stable outcomes an instance can have. The output measure changes because a continuous set of flows need not have a finite cardinality. The paper’s Theorem 1 asks for the worst-case maximum; the corresponding extremal question here is to bound the maximum \(B(p,q,L)\) of \(b_0(\mathcal S)\) over instances with \(p\) applicant types, \(q\) job types, and mass encoding length at most \(L\).

I expect fixed-parameter tractability in the number of types, though I would not claim polynomial time when that number grows. There are \(pq\) stability disjunctions. Choosing a saturated side for each pair gives at most \(2^{pq}\) polyhedral cells. Each cell and each pairwise intersection can be checked for feasibility by linear programming; the connected components of their union are the components of the cell-intersection graph. This gives a \(2^{O(pq)}\operatorname{poly}(L)\)-time route, hence FPT in \(p+q\). A sharper bound on \(B(p,q,L)\), or a polynomial-time algorithm in the support size, remains open. The theorem’s count bound supplies no hardness result to transfer, so this mirror predicts neither Class B nor a hardness boundary.

The main further questions are whether the stable-flow set can have positive-dimensional components under strict type rankings, how its component count relates to stable matchings in finite markets formed by cloning types, and whether a rotation-poset or entropy argument can give a tight exponential bound in the number of types. This mirror covers Theorem 1’s bound on stable-outcome multiplicity and its enumeration motivation. It does not extend the paper’s separate roommates corollary or its general counting lemma.

The weak point is the change in what gets counted. The paper counts matchings between named individuals; this mirror identifies relabelings within a type and, when flows vary continuously, counts connected families rather than individual assignments. A referee could reasonably see component counting as a new topological question about stable flows. I still find the case credible because the population is the object being continuized, the aggregate decision remains a stable matching, and connected components give a finite, well-defined measure of separated stable outcomes when raw cardinality stops making sense.

The case AGAINST (opponent, writing after the proponent)

The best objection is that Theorem 1 bounds the number of individual matchings: each outcome pairs named jobs with named applicants, and the proof counts those outcomes through the rotation poset. In the proposed mirror, a flow records only how much mass moves between types. If types have a fixed, small set of rankings over counterpart *types*, the model has changed to a capacitated market with category-level preferences. If types retain strict rankings over named counterparts, the type description generally grows with the population, undermining the high-multiplicity regime.

The proposed component count does not preserve the theorem’s quantity. A whole continuum of distinct stable flows can count as one component, so it measures separated families of allocations rather than the number of stable outcomes. A more faithful alternative might count vertices or count stable flows on a finite clone grid. But neither supplies a canonical finite-valued measure for the continuous set: vertex counts need a convention for a nonconvex union of polyhedra, while grid counts depend on the chosen resolution. Each would pose a new question about the chosen representation, not a direct continuous version of the paper’s bound on matchings.

The proposed algorithm also makes the component-count version look less compelling as a mirror: after choosing a saturated side for each type pair, feasibility and intersections reduce to linear programming, giving a \(2^{O(pq)}\operatorname{poly}(L)\) method. That is a valid result, but it does not recover the paper’s extremal bound or its algorithmic motivation.

This is not a decisive case against every mirror. A market with many agents sharing a small number of preference templates is a sensible high-multiplicity regime, and counting its distinct aggregate stable assignments could be worth studying. The weakness is that once fractional flows are admitted, the paper supplies no canonical count to bound. I therefore cannot honestly rule out a worthwhile mirror of Theorem 1; I can only argue that the proposed connected-component count is a substantial change of question, and that the stronger aggregate-count versions need their own justification.
