The case AGAINST (opponent, writing after the proponent)

The proponent’s case concedes the strongest point: it names no computational result to mirror. Theorem 1 characterizes a social welfare function from axioms; Propositions 1 and 2 characterize related classes. None defines an algorithmic problem or proves a complexity bound or hardness result. The paper’s non-atomic beliefs are distributions over states of the world, while its set of agents remains finite. Neither feature supplies the continuous-population computational question ChoCo is looking for.

The best population-continuous reformulation would replace the finite set of agents with a distribution over complete subjective expected utility types, then aggregate beliefs and normalized utilities by integration. That could be a worthwhile axiomatic extension, but it asks a different kind of question from the programme’s computational ones. A computational task would need something extra, such as a specified feasible set of acts to optimize over. With finite, explicitly represented types, computing the aggregate for a given act is just aggregation; any substantial complexity would come from the added optimization problem or the encoding of beliefs and utilities, neither of which the paper studies.

So the negative case is strong for a mirror of this paper: none of the proponent’s anchors survives because none was raised. It is weaker as the universal claim that no useful computational project could ever grow out of the paper. Such a project is possible, but it would need a new problem definition and would not be anchored in a computational result here.
