The continuous mirror question

Given finitely many complete TA types \(t\in T\) with binary-rational masses \(\mu_t\ge 0\), \(\sum_t\mu_t=1\), and a common course value \(q_t\in\mathbb Z_{\ge 0}\) for both courses, where each type has utility and grade \(1\) for either course, decide whether there are nonnegative rational assignments \(z_{t,i}\) such that \(\sum_{i=1}^2 z_{t,i}=\mu_t\), \(\sum_t z_{t,i}=1/2\), and \(\frac{\sum_t q_t z_{t,i}}{1/2}\ge k\) for each course \(i\in\{1,2\}\).

The model it lives in

A two-course staffing market with a distribution \(\mu\) over complete TA types, each type carrying a common qualification value \(q_t\) for both courses. The decision variables \(z_{t,i}\) assign type mass to courses, each with capacity \(1/2\); the question is whether both courses meet average value \(k\). Merit-based envy is automatic in this restriction, and there is no separate objective.

The objection that survived

The reduction may have \(\tau=N\) when its values \(s_i\) are distinct, so it does not show that the hard instances themselves lie in a high-multiplicity regime; this limits the bridge's scope but not the separate cohort model.

fatal: False

What the mirror covers

Covers only Theorem 1's restriction with two courses, equal capacities, identical course valuation vectors, and TA utilities and grades all equal to \(1\); it leaves the other hardness, polynomial-time, FPT, approximation, and existence results aside.

Open questions for a prover

  • Does tractability persist when course capacities are unequal and scale with population size?
  • Does it persist when the courses have different valuation functions?
  • How do feasible mass assignments round to finite cohorts?

The case FOR (proponent)

My lead is Two-Course Mass-MEFE, a continuous mirror of Theorem 1. The theorem, proved in the paper using a reduction from the cited EQUAL-CARDINALITY PARTITION problem, says MEFE-MATCHING is NP-complete even with exactly two courses having identical valuation functions, when every TA has utility \(1\) for both courses and grade \(1\) in both. The reduction uses equal course capacities and assigns each TA \(t_i\) a common course value \(s_i\).

The mirror’s regime is two large parallel course offerings that each need half of a large TA cohort. TAs share a small set of complete profiles—so the number \(N\) of TAs may be much larger than the support size \(\tau\). Each type \(t\) records its common course value \(q_t\), its utilities and grades for both courses, and any other attributes relevant to matching. In this restricted mirror, both courses use the same qualification score \(q_t\), and every TA type has utility and grade \(1\) for either course. This is a narrow staffing scenario, but it preserves the paper’s course-satisfaction and merit-based-envy criteria. Course capacities become per-capita masses; splitting type mass means assigning different people from a cohort to different courses, not giving an individual a fractional assignment.

Precisely, an instance has a finite type set \(T\), binary-rational masses \(\mu_t\ge 0\) summing to \(1\), integer course values \(q_t\ge 0\), and a rational threshold \(k\). Each course has capacity \(1/2\). Ask whether there is a rational mass assignment \(z_{t,i}\ge 0\), for \(t\in T\) and \(i\in\{1,2\}\), such that
\[ \sum_{i=1}^2 z_{t,i}=\mu_t,\qquad \sum_{t\in T}z_{t,i}=\frac12,\qquad \frac{\sum_{t\in T}q_tz_{t,i}}{1/2}\ge k \quad(i=1,2). \]
A solution is this assignment of all TA mass, meeting both course thresholds and having no merit-based envy. In this restriction envy is automatic: every type values both courses equally and has the same grade in each. The paper’s problem is a threshold-feasibility question, so there is no separate cost objective to add.

I expect this mirror to be tractable (Class A). Let \(\bar q=\sum_t\mu_tq_t\). Feasibility requires \(k\le\bar q\), since adding the two course-value constraints gives that bound. It is also sufficient: assign \(z_{t,1}=z_{t,2}=\mu_t/2\). Each course then has average value \(\bar q\). Thus the answer is computable in polynomial time in \(\tau\) and the input bit length \(L\).

The connection to the hardness anchor is concrete. For the reduction’s weights \(s_1,\ldots,s_N\), give each TA mass \(1/N\), set \(q_i=s_i\), and set \(k=\sum_i s_i/N\). With indivisible TAs and equal capacities, meeting both average thresholds requires an equal-cardinality, equal-sum partition. With divisible cohort mass, splitting every type equally between the courses is feasible. The continuous question therefore tests whether the partition hardness dissolves when the population is the continuous object.

One caveat in the anchor itself should be made explicit: the paper defines average utility by dividing by course capacity, but its appendix writes the reduction threshold as \(\sum_i s_i/2\). With capacity \(N/2\), the corresponding threshold for the stated average is \(\sum_i s_i/N\). I would treat this as a scaling error in the displayed reduction and use the corrected normalization above.

My weakest point is the narrowness of the mirror: identical course values and TA indifference make the continuous problem collapse to a single weighted average. Also, the reduction may have \(\tau=N\) when all weights are distinct; it is not itself a low-support instance. The mirror remains a sensible, sharply bounded question about Theorem 1’s MEFE subcase, while leaving open whether meaningful heterogeneity in course values, TA preferences or grades preserves tractability. Further questions include whether mass-MEFE remains tractable with unequal course capacities or nonidentical course valuations, and how well its solutions round to finite cohorts.

The case AGAINST (opponent, writing after the proponent)

The strongest objection is to the claimed connection between Two-Course Mass-MEFE and the paper’s hardness anchor. In the reduction, each TA’s course value \(s_i\) is the information that distinguishes them. Under the programme’s complete-type definition, two TAs with different \(s_i\) are different types. The proposed mapping gives each TA mass \(1/N\), so if the \(s_i\) are distinct—as they may be in an Equal-Cardinality Partition instance—then \(\tau=N\). That maps the reduction into a continuum, but not into the low-support, high-multiplicity regime that motivates the programme. Grouping TAs into a few repeated score types gives a plausible staffing model, but it no longer represents the reduction’s general inputs. This weakens the anchor’s claim to be a direct high-multiplicity continuation; it does not make the restricted model meaningless.

The mirror also inherits a particularly thin subcase of MEFE-MATCHING: TAs are indifferent between the courses, have identical grades, and the courses value them identically. Merit-based envy is therefore inactive. A natural broader version would use several course types and TA types that record complete preference, grade, and course-value profiles, with mass assignments to courses and course satisfaction constraints. Large cohorts with a limited set of standardized profiles are plausible in staffing or placement. I don’t see a fundamental obstacle to asking the computational questions for that model.

The normalization caveat in the appendix is real, but correcting the threshold to match the paper’s average-utility definition is straightforward; it does not defeat the mirror. Overall, the negative case against this anchor is weak. The proponent’s exact instance mapping does not establish that the hard family has high multiplicity, and the fairness condition is vacuous in that subcase. But the paper’s broader matching problem admits sensible population-type models, so those points cannot support the requested universal claim that no worthwhile continuous mirror exists.
