The continuous mirror question

Given a finite type graph \(H=(T,F)\), rational type masses \(\mu_t>0\) summing to \(1\), rational \(\varepsilon\in(0,\tfrac12]\), and nonnegative rational type-pair values \(w\), define \(\nu_w(q)\) for \(0\le q\le\mu\) as the maximum of \(\sum_{tu\in F}w_{tu}z_{tu}\) subject to \(2z_{tt}+\sum_{u\ne t:tu\in F}z_{tu}\le q_t\) for each \(t\), and \(z\ge0\). Does there exist a polynomial-time algorithm that outputs \(x\in\mathbb R_{\ge0}^{T}\) with \(\sum_t x_t=\nu_w(\mu)\), \(\sum_t(q_t/\mu_t)x_t\ge(\tfrac12-\varepsilon)\nu_w(q)\) for every \(q\le\mu\), \(q\ne\mu\), and a universal constant \(C\) such that \(\|x(w)-x(w')\|_1\le(C/\varepsilon)\|w-w'\|_1\) for all nonnegative \(w,w'\)?

The model it lives in

A continuum matching game with types \(t\in T\), masses \(\mu_t\), and values \(w_{tu}\) per type pair. Coalitions are mass vectors \(q\le\mu\); their values come from the fractional matching formulation \(\nu_w(q)\). The decision is a total allocation \(x_t\) to each type, inducing per-person share \(x_t/\mu_t\), with an approximate-core guarantee for all proper coalition masses and a Lipschitz bound under changes to type-pair values.

What the mirror covers

The mirror covers Theorem 1.4’s matching-game approximate-core allocation and robustness guarantee; it leaves Theorem 1.5’s minimum-spanning-tree allocation and Theorems 1.6–1.7’s Shapley-value sensitivity results aside.

Open questions for a prover

  • Does a polynomial-time algorithm achieve the stated approximate-core and size-independent Lipschitz guarantees for arbitrary finite type graphs?
  • How should the type-pair perturbation norm be normalized when relating this model to finite cloned instances and the paper’s edgewise perturbation norm?

The case FOR (proponent)

The strongest case is the matching-game result, Theorem 1.4, proved in this paper in Section 3. It states: for every \(\varepsilon\in(0,\tfrac12]\), the matching game has a polynomial-time algorithm with Lipschitz constant \(O(\varepsilon^{-1})\) that returns a \((\tfrac12-\varepsilon)\)-approximate-core allocation. This is a good anchor because the theorem is about the problem ChoCo cares to mirror: computing a stable allocation under perturbations. The paper’s cited \(\#P\)-hardness result for Shapley values is not a numbered theorem proved here, so I would not use it as an anchor.

A plausible high-multiplicity setting is a large doubles platform or recurring tournament. Players fall into a small number \(\tau\) of skill and compatibility profiles; many players share each profile, and the value of a pairing depends only on the two profiles. The type is that complete profile of matching-relevant information, and \(\mu_t\) is the fraction of players with type \(t\). It is credible to have millions of players but only dozens of types. For a coalition, the honest quantity is its mass of each type: in a continuum, a coalition can contain any amount of a type’s mass.

Here is the mirror I would put to a prover: Lipschitz Continuous High-Multiplicity Matching-Core Allocation. An instance has a finite type graph \(H=(T,F)\), rational masses \(\mu_t>0\) summing to \(1\), and a rational \(\varepsilon\in(0,\tfrac12]\). Each allowed type pair \(e\in F\) has a nonnegative rational pairing value \(w_e\). For any coalition mass vector \(q\in[0,\mu]\), define its matching value \(\nu_w(q)\) by

\[ \nu_w(q)=\max \sum_{tu\in F} w_{tu}z_{tu}, \qquad 2z_{tt}+\sum_{u\ne t:\,tu\in F}z_{tu}\le q_t\quad(t\in T), \qquad z\ge 0. \]

Here \(z_{tu}\) is the mass paired across types \(t,u\); \(z_{tt}\) is the mass of pairs drawn from type \(t\). This is the matching value of the coalition’s mass, not a claim that the platform allocates fractional people.

The task is to find an allocation measure \(x\in\mathbb R_{\ge0}^{T}\), where type \(t\)’s per-person share is \(x_t/\mu_t\), such that

\[ \sum_t x_t=\nu_w(\mu), \qquad \sum_t \frac{q_t}{\mu_t}x_t \ge \left(\frac12-\varepsilon\right)\nu_w(q) \quad\text{for every }q\le\mu,\ q\ne\mu. \]

The algorithmic question is whether, for each fixed \(H,\mu,\varepsilon\), there is an algorithm running in time polynomial in \(\tau\) and the rational input bit length that computes such an allocation for every \(w\), with a universal \(C\) such that

\[ \|x(w)-x(w')\|_1 \le \frac{C}{\varepsilon}\|w-w'\|_1 \]

for all nonnegative weight vectors \(w,w'\). The weight norm is over type pairs; the allocation norm measures changes in the total allocation received by each type.

I expect this mirror to be tractable, in the Class A sense: the continuous matching value has a compact type-level linear formulation, and the central challenge is to find a Lipschitz allocation satisfying all coalition constraints. The result mirrors the paper’s allocation guarantee, approximate-core requirement, and robustness question. Its further questions include whether one can improve the approximation factor while retaining a size-independent Lipschitz bound, and how the answer translates back to finite elections or populations with many agents per type.

The main weakness is the dictionary between this model and the paper’s exact perturbation setup. The paper measures changes in weights on individual graph edges; this mirror has one weight per type pair, and changes to it represent coordinated changes across many individual pairings. A formal high-multiplicity limit and an explicit choice of normalization would be needed before claiming Theorem 1.4 transfers. Still, the underlying problem remains recognizably theirs: coalition values come from matching, the output allocates the grand coalition’s value, and the allocation must remain stable when pairing values change. The scope here is just Theorem 1.4’s matching-game allocation result; the MST and Shapley results need not be stretched into this mirror.

The case AGAINST (opponent, writing after the proponent)

The only live anchor is Theorem 1.4: it gives a polynomial time algorithm for a Lipschitz continuous approximate core allocation. So the objection that the paper has no named computational result does not apply.

The strongest case against the proposed mirror is that its robustness guarantee does not carry over from the paper. In the paper, weights belong to individual edges and the perturbation norm sums changes across those edges. In a finite clone model with \(N\) agents, a type-pair value is repeated across \(\Theta(N^2)\) edges. Changing that one type-pair value by \(\delta\) therefore changes the paper’s input norm by \(\Theta(N^2\delta)\). If the paper’s allocation is aggregated and normalized by \(N\), its guarantee yields only a bound of order \(\Theta(N\delta)\), not a size-independent Lipschitz bound in the type-pair weights. That does not rule out such a bound, but it means the proposed mirror needs a new robustness result and a justified perturbation scale; it is not a direct high-multiplicity limit of Theorem 1.4.

There is a related modeling concern. In a general matching game, two agents with the same personal attributes can have different edge weights to other agents. To keep the type count small, the model must assume that pairing values depend only on the pair of types. That is plausible for a platform using class-level values, but it removes the paper’s motivating uncertainty about individual pair compatibility. The mirror thus captures coherent errors to whole classes of pairings, rather than the paper’s edge-by-edge perturbations.

That case against has a clear limit. The class-level matching model is coherent, the population really is the continuous object, and its coalition values have a finite type-level formulation. The changed perturbation model may still be one the authors recognize as their problem. I can challenge the claimed bridge from Theorem 1.4, but I cannot honestly show that the mirror is unworthy; the negative case is weak against this anchor.
