The continuous mirror question

Given \(m\) candidates, \(\tau\) ranking types with positive rational masses \(\mu_t\) summing to \(1\), and a fixed \(K\)-list \(L\), compute the worst-case metric distortion of its induced lottery \(p_L\). Each type’s mass is represented by a voter point shared by all members of that type; the unknown pseudometric on those points and the candidates must be consistent with the type rankings. Return the supremum of weighted social cost divided by the minimum candidate cost, including \(+\infty\) when a zero-optimum obstruction or an unbounded positive-optimum LP exists.

The model it lives in

Use one metric point for each ranking type and one for each candidate, with rational type masses \(\mu_t\). For fixed \(K\), compute the distortion of \(p_L\) by the paper’s LPs and zero-optimum feasibility checks, replacing voter averages by mass-weighted sums; the resulting computation is polynomial in \(m\), \(\tau\), and the mass bit length.

What the mirror covers

The mirror covers Proposition C.1’s fixed-list distortion evaluation in the co-located type regime; it does not cover the sensitivity and privacy guarantees or the full Gibbs rule’s performance.

Open questions for a prover

  • Can the paper’s full metric uncertainty model, which permits voters with the same ranking to occupy different points, be represented by a finite-support weighted LP?
  • Can the computation over all \(m^K\) lists be avoided when evaluating or implementing the Gibbs rule?

The case FOR (proponent)

My strongest case is Continuous Clone Metric-Distortion Evaluation, anchored only on Proposition C.1 (Finite LP Characterization), proved here. The paper has no named hardness result, and its sensitivity and privacy theorems are analytic guarantees rather than complexity results. Proposition C.1 is the computational anchor: for a fixed profile and list lottery, it computes the lottery’s worst-case distortion by finitely many LPs. For fixed \(K\), it computes the energies of all \(K\)-lists using \(O(m^{K+1})\) polynomial-size LPs or feasibility problems, each with \(O((m+n)^2)\) variables and \(O((m+n)^3)\) triangle constraints, plus ordinal and normalization constraints. It also says the resulting Gibbs weights can be approximated to arbitrary numerical precision.

Here is the mirror. An instance has \(m\) candidates, a finite support \(T\) of \(\tau\) strict rankings, and rational masses \(\mu_t>0\) summing to \(1\). Each ranking type is a bloc whose members are clones: they share the ranking and are represented by one metric point. Given a fixed \(K\)-list \(L\), the decision is the lottery \(p_L\) induced by a uniform draw from that list. The question is to compute its worst-case metric distortion
\[ \rho_\mu(L) = \sup_{d\text{ consistent with }T} \frac{\displaystyle\sum_{t\in T}\mu_t\sum_{c\in C}p_L(c)d(t,c)} {\displaystyle\min_{o\in C}\sum_{t\in T}\mu_t d(t,o)} , \]
using the paper’s convention for zero optimum.

A solution is the exact value, including \(+\infty\) if a zero-optimum obstruction or an unbounded positive-optimum LP makes the distortion infinite. The type points and candidates are the LP’s nodes. For each proposed optimal candidate \(o\), normalize \(\sum_t\mu_t d(t,o)=1\), require \(\sum_t\mu_t d(t,c)\ge1\) for every candidate \(c\), and maximize the lottery’s weighted social cost subject to the metric and ranking constraints. Check zero-optimum obstructions with the corresponding feasibility LP. This is the underlying distortion problem, not a question about an encoding.

The plausible regime is a large electorate represented by a small number of ballot blocs: for example, many residents in a few concentrated communities, with one ranking archetype and metric location per bloc. Then \(n\) can be very large while \(\tau\) stays small, and \(\mu_t\) means the share of residents in bloc \(t\). The hidden metric remains hidden; the computation ranges over all metrics consistent with the rankings. On this clone regime, Proposition C.1 carries over by replacing voter averages with \(\sum_t\mu_t\) and using the \(\tau\) type representatives. For fixed \(K\), the resulting computation is polynomial in \(m,\tau\), and the binary encoding length of the masses. I expect Class A: tractable by LP. If \(K\) is part of the input, the \(m^K\) enumeration is no longer a polynomial-time guarantee; the paper’s own construction also has an enormous constant \(K\), so this formal tractability need not be practical.

This asks the authors to compute the same object they compute in Proposition C.1—the robust distortion of a specified lottery—after replacing a clone electorate’s counts with fractional masses. The mirror covers that proposition alone; it does not claim to continuize the paper’s headline sensitivity or privacy results.

The soft spot is real: Proposition C.1 is in the appendix, and the clone model assumes voters with the same ranking share a metric point. The paper allows voters with the same ballot to occupy different points, and aggregating them by ranking alone could change the worst-case distortion. So this is a credible high-multiplicity regime for their problem, but not a mirror of its full metric uncertainty class. Natural next questions are whether arbitrary within-ranking location variation admits a finite-support LP, whether the all-lists computation can avoid \(m^K\) enumeration, and whether finite-precision sampling can preserve the paper’s guarantees.

The case AGAINST (opponent, writing after the proponent)

The best objection is that the proposed mirror compresses voters by ranking while the paper’s metric distortion problem distinguishes voters who have the same ranking but different locations. Proposition C.1’s LP has a separate metric point for each voter. Replacing those points with one point per ranking type changes the set of metrics over which distortion is maximized, so it evaluates a restricted common-location version of the problem.

That objection does not defeat the strongest repair. Define types by both ranking and the metric information relevant to costs, and give each type a rational mass. Then the LP has one point per complete type, with the mass-weighted social costs in its objective and constraints. For the regime where each type has identical metric data, this is a coherent high-multiplicity version of the authors’ problem, and the same distortion-evaluation question applies. Allowing variation in metric location within a ranking type would require a richer model, but that does not invalidate the simpler regime.

Nor can I dismiss the mirror because its answer follows readily from the LP, or because it covers only Proposition C.1: neither defeats a well-posed continuous computational question under the programme’s rules. The honest negative case is therefore weak. The clone assumption narrows the paper’s metric uncertainty, but a plausible, recognized high-multiplicity regime survives, and I cannot show that no worthwhile continuous mirror exists.
