The continuous mirror question

Given \(m\) package kinds, supported household types \(t\) with rational masses \(\mu_t\), eligibility sets \(E_t\), values \(v_j\), and rational per-household supplies \(q_j\), maximize \(\lambda\) over mass assignments \(x_{t,a}\). Each bundle \(a\in\mathbb{Z}_{\ge 0}^m\) must be integral and satisfy \(a_j=0\) for \(j\notin E_t\); require \(\sum_a x_{t,a}=\mu_t\), \(\sum_{t,a}a_jx_{t,a}\le q_j\), and \(x_{t,a}>0\) only when \(\sum_jv_ja_j\ge\lambda\).

The model it lives in

A nonatomic population with \(\tau\) complete household types and mass \(\mu_t\) per type; each household receives an integral bundle, while each type’s mass may be split among bundles. Per-capita supplies \(q_j\) constrain total mass assigned each package kind, and the objective is to maximize the least utility.

The objection that survived

The theorem gives a polynomial-time bound for explicit finite instances, not a bound polynomial in the compressed input size \(m,\tau,L\); the proponent acknowledges this, and it remains an open algorithmic question.

fatal: False

What the mirror covers

The mirror covers the restricted-assignment objective and the configuration-LP bound in Theorem 1. It leaves the paper’s hypergraph local-search analysis, its open questions about finding local optima, and general max-min allocation outside the stated mirror.

Open questions for a prover

  • Can the continuous optimum and a witnessing mass assignment be computed in time polynomial in \(m,\tau,L\), without expanding binary-encoded supplies into individual package copies?
  • What is the continuous optimum’s relation to the finite integral optimum across compatible high-multiplicity realizations?

The case FOR (proponent)

The strongest positive case is a narrow mirror of the paper’s restricted-assignment Santa Claus problem. Consider a large relief programme serving \(N\) households. Households fall into \(\tau\) need and eligibility types, and the catalogue has \(m\) kinds of indivisible aid packages. A type records a household’s complete eligibility and valuation profile. Every copy of package kind \(j\) has value \(v_j\) to each eligible household and value zero to the others. The regime is credible when \(N\) is very large relative to \(\tau\) and \(m\), and package supplies grow with the population.

Here is the continuous problem. The instance gives supported household types \(T\), rational masses \(\mu_t\) summing to \(1\), eligible package kinds \(E_t\subseteq\{1,\ldots,m\}\), and rational per-household supplies \(q_j\) of each package kind. A bundle is an integer vector \(a\in\mathbb Z_{\ge0}^m\), where \(a_j\) counts how many units of kind \(j\) one household receives; require \(a_j=0\) when \(j\notin E_t\). Let \(x_{t,a}\) be the mass of type \(t\) assigned bundle \(a\). The question is to find the largest \(\lambda\) and a witnessing assignment \(x\) satisfying

\[ \sum_a x_{t,a}=\mu_t,\qquad \sum_{t,a} a_jx_{t,a}\le q_j,\qquad x_{t,a}>0\ \Longrightarrow\ \sum_j v_ja_j\ge\lambda. \]

Thus every household receives an integral bundle, while a continuum of households of one type can be split among different bundles. The output is the optimal minimum utility and a mass assignment witnessing it. For a finite realization, take \(N\mu_t\) households of type \(t\) and \(Nq_j\) copies of package kind \(j\), with \(N\) chosen so those counts are integral. This is a high-multiplicity regime: many agents share a relatively small number of complete types.

My anchor is Theorem 1, proved in this paper. It says that for restricted-assignment max-min allocation, a polynomial-time algorithm estimates the optimum within a factor of \(1/5-\epsilon\), for any \(\epsilon>0\). The paper identifies the algorithm as the configuration LP and proves that its value is at most \(5\,\mathrm{OPT}\); solving that LP to arbitrary precision is attributed to Bansal and Sviridenko [3]. The introduction also cites an inapproximability result, but it is not a numbered result of this paper, so I do not use it as an anchor.

This theorem gives the mirror a concrete bridge to the finite problem. In the continuous model, the configuration LP represents allocations exactly: its variables say what mass of each type receives each integral bundle. For compatible finite realizations, the paper’s result gives

\[ \mathrm{OPT}_N\le \lambda_\infty\le 5\,\mathrm{OPT}_N, \]

up to the stated LP-solver precision, where \(\lambda_\infty\) is the continuous optimum. In the finite instance the LP is a relaxation; in the continuum the same mass variables describe the allocation itself. The problem being mirrored remains the authors’ max-min allocation problem, with indivisible bundles and the same restricted-assignment valuations.

I expect this mirror to be Class A. For a fixed threshold \(\lambda\), feasibility is an LP over bundle configurations, with potentially many columns. The natural route is to adapt the paper’s configuration-LP machinery using a pricing procedure over integer bundle counts. The target running time should be polynomial in \(m,\tau,L\), and \(1/\epsilon\), where \(L\) is the binary input length. A further question is whether this pricing can handle binary-encoded per-capita supplies without expanding all \(Nq_j\) copies. The paper’s theorem motivates the tractable direction, but does not by itself establish that compressed-input bound. Other follow-up questions are whether the factor \(5\) is tight in this regime and how closely finite realizations track the continuous optimum.

The weakest point is also the source of the tractability: a nonatomic type’s mass can be divided among integral bundles, so the configuration LP becomes exact. The case depends on the authors and a referee accepting that large populations with per-capita supplies are the relevant high-multiplicity version of their allocation problem. The programme’s scope explicitly allows supplies to scale with population, and the households retain indivisible bundles, which makes this a plausible mirror. It is a case for this one result and this regime, not for continuizing the paper’s entire subject.

The case AGAINST (opponent, writing after the proponent)

Theorem 1 is the proponent’s strongest anchor, but its continuous version is almost exactly the configuration LP the paper already studies. In a finite realization with \(N\mu_t\) households of each type and \(Nq_j\) copies of each package kind, group identical households and items in the LP. Its variables then describe the mass of each type assigned each integral bundle—the proposed continuous allocation. The paper already says this LP can be solved to arbitrary precision, and Theorem 1 bounds its value by \(5\,\mathrm{OPT}\). So the central continuous question—whether the configuration LP computes the mass-allocation optimum, and how that value relates to an integral allocation—has already been answered by the paper’s formulation and result.

Keeping the paper’s original \(m\) one-off items while letting the population grow does not rescue a distinct mirror: almost all the population must receive nothing, and the max-min value collapses. The better model scales package supply with population, as the proponent does. That is a plausible Santa Claus regime, but its distinctive computational question is then whether the LP can be handled from binary-encoded per-capita supplies without expanding to \(N\) households and \(Nq_j\) items. That is a real caveat: the paper’s polynomial running time on an explicit instance does not by itself establish a bound polynomial in \(m,\tau,L\).

That caveat is also where my negative case is weakest. Succinct high-multiplicity complexity could be worth studying, and the problem remains recognizable as max-min allocation. I can argue that this is a narrow input-compression question around an LP whose continuous meaning and finite-instance value are already known; I cannot honestly argue that no worthwhile mirror survives.
