The case AGAINST (opponent, writing after the proponent)

The strongest case against is that this paper supplies no computational result for a continuous mirror to carry over. Proposition 1 says each agent’s belief sequence is eventually cyclic; Propositions 10–12 give conditions under which policies guarantee convergence. These are qualitative results about the dynamics, not complexity bounds or algorithms for a computational problem. Proposition 1’s finite characterization is not an efficiency claim. A continuous version could ask interesting questions, but it would need to define a new computational task rather than mirror one established here.

The most plausible version of the cycle question would use a well-mixed population with mass distributed over belief states. But that requires extending the paper’s finite-profile merging operators to weighted populations. The finite-agent cycle result then no longer transfers: the population state ranges over a continuum, and the update could have different convergence or periodicity behavior. That may be a worthwhile study of mean-field belief dynamics, but it is a new dynamics question, not a continuous counterpart of Proposition 1’s finite-state observation.

The convergence results face a sharper modeling obstacle. An agent’s update depends on which neighbors send beliefs, so a type must capture more than its initial belief and revision policy: it must preserve relevant network structure. If types encode each agent’s full network role, the number of types may grow with the population. If the model keeps only masses of belief types, it loses who communicates with whom. A graphon or block-network limit could retain that information, but it would replace finite, unweighted neighbor profiles with a new interaction kernel and weighted aggregation rule. In particular, the finite DAG condition in Proposition 12 does not carry over directly: a continuum acyclic network need not have the finite graph’s bounded layering. Such a model could inspire new work, but it would not be a mirror of the stated convergence results.

So the negative case is strong for the paper’s named results: none provides the computational anchor ChoCo seeks. It is weaker as a universal claim that no continuous BRG research could be worthwhile; a carefully chosen population model might pose valuable new computational questions. The case against is that those would be extensions of this paper’s subject, not continuous mirrors of its results.
