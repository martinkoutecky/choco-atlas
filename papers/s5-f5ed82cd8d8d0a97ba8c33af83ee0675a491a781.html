The continuous mirror question

Fix a tidy kitchen and a finite type set \(T\). Given rational masses \(\lambda_t>0\) summing to \(1\), and rational per-capita intensities \(a_t\geq 0\) with \(\sum_{t\in T}\lambda_t a_t=1\), each type \(t\) has an unknown shared kitchen measure \(\nu_t\). A query selects a type representative to make a Robertson–Webb cut, after which every type appraises the queried servings. What is the minimum worst-case number of such queries needed for a protocol to output a partition \((X_t)_{t\in T}\) satisfying \(\nu_t(X_t)\geq E_t=\lambda_t a_t\) for every type, for every measure profile consistent with the replies?

The model it lives in

A finite-support population distribution \(\lambda\) over complete types \(t\), where members of each type share a kitchen measure and entitlement intensity \(a_t\). Type \(t\) has aggregate claim \(E_t=\lambda_t a_t\); queries elicit cuts and appraisals from representatives, and the decision assigns one serving to each type.

What the mirror covers

The mirror covers the query lower bound in Theorem 1 and its irrational-entitlement consequence in Corollary 1. It leaves aside individual disaggregation costs, the other query bounds, the preference representation result, and the adversary-game result.

Open questions for a prover

  • For rational aggregate claims \(E_t\), how do query bounds depend on support size \(\tau\) and binary input length \(L\)?
  • Can approximate cohort guarantees give finite query bounds for irrational aggregate claims?
  • What changes if the protocol must construct each member’s bundle and count the queries used for disaggregation?

The case FOR (proponent)

There is a real, if narrow, positive case in the paper’s query complexity result. The right mirror is a large population with a few complete preference and entitlement types, where each type’s members can be treated as a homogeneous block.

Call the problem Continuous Type-Block Entitled Division. Fix a tidy kitchen and a finite type set \(T\). Type \(t\) has rational population mass \(\lambda_t>0\), with \(\sum_t\lambda_t=1\), a shared but privately known kitchen measure \(\nu_t\), and a known entitlement intensity \(a_t\), normalized so \(\sum_t\lambda_t a_t=1\). Its aggregate claim is \(E_t=\lambda_t a_t\). In a finite population of \(N\) agents, with \(N\lambda_t\) integral, each member of type \(t\) has claim \(a_t/N\), so the block’s total claim is \(E_t\).

A query chooses a type representative, knife, serving, and target proportion. That representative makes the cut; each type appraises the serving and cut. A solution is a partition \((X_t)_{t\in T}\) of the cake such that \(\nu_t(X_t)\ge E_t\) for every type, guaranteed for every profile of type measures consistent with the query record. The problem is to minimize the worst-case number of type queries. This block output has the right finite-clone interpretation: knife divisibility lets \(X_t\) be split among the \(N\lambda_t\) identical members, each receiving value at least \(a_t/N\). Thus the mass is a share of the population, and the block’s fractional entitlement is the aggregate of its members’ claims.

My lead anchor is Theorem 1 (Main result), proved in this paper. It says: in any fixed setting with at least two agents, for every clonage level \(\mathsf{c}\in\mathbb N\), if \(\mathsf{C}(e)>\mathsf{c}\), then the optimal worst-case protocol cost satisfies
\[ \mathsf{cost}(e)>\left\lfloor\log_2\!\left(\log_2\!\left(2\mathsf{c}^{1/(n-1)}\right)\right)\right\rfloor. \]
Applied to the type-block problem, \(n\) is the number of supported types and \(e\) is their aggregate claim profile \(E\). With two types, the bound grows with the denominator of rational \(E\); if a type’s aggregate entitlement is irrational, \(\mathsf{C}(E)=\infty\), so the bound holds for every \(\mathsf{c}\). The paper’s Corollary 1 gives the resulting conclusion directly: no protocol has a finite worst-case query bound. I expect the mirror to inherit this lower bound. In the ChoCo trichotomy it is closest to hardness transferring from a finite block problem; it is a query lower bound, not an NP-hardness result.

The regime is concrete: a large estate divided between two beneficiary cohorts, with members of each cohort sharing the same normalized valuation and the same within-cohort claim. For an even population, take \(\lambda_A=\lambda_B=1/2\), aggregate claims \(E_A=\alpha\) and \(E_B=1-\alpha\), and \(\alpha=(-1+\sqrt5)/2\). Then \(a_A=2\alpha\) and \(a_B=2(1-\alpha)\). The population can grow while support stays at \(\tau=2\). This is not a claim that every cake-division setting is high-multiplicity; it is one plausible regime, made especially credible by the paper’s own use of clones. The paper already studies divisible outcomes, but this mirror’s continuous object is the population distribution across homogeneous types.

The scope is only the communication lower bound about entitlements. The weakness is that the type-block problem is very close to the paper’s original two-agent problem: aggregation supplies a credible large-population regime, but does not create a new source of difficulty. Also, the resource being bounded is query count, and exact irrational claims are not ordinary binary-rational inputs. If the problem instead requires the protocol to output every individual bundle and charges for the cuts that disaggregate each block, this theorem does not automatically give the same bound. That leaves worthwhile follow-up questions: how query complexity depends on \(\tau\) and the bit length of rational aggregate claims, whether approximate guarantees tame irrational claims, and what changes when individual disaggregation queries are counted.

The case AGAINST (opponent, writing after the proponent)

The proponent has one anchor: Theorem 1, with Corollary 1 as its irrational-entitlement consequence. It is a genuine named lower bound, so I would not dismiss it as merely axiomatic or about divisible outcomes. The problem is that the proposed type-block version is exactly the paper’s problem after relabelling.

For each type \(t\), combine its mass and per-capita claim into \(E_t=\lambda_t a_t\). Replace that block with one paper agent whose entitlement is \(E_t\) and whose measure is \(\nu_t\). A query to the block, every appraisal response, every information set, and every guaranteed allocation then matches the corresponding object in the paper. Thus the type-block protocol game has the same worst-case cost as the paper’s game with \(n=\tau\). The population size \(N\), the masses \(\lambda_t\), and the intensities \(a_t\) disappear once \(E_t\) is fixed. This is a definition-level equivalence, not a discrete-to-continuous identity that the paper establishes as a result.

That leaves a choice about what the block allocation means. If each block receives one serving, the mirror is the exact finite-agent problem just described. If every individual must receive a separate serving and those cuts count, the theorem bounds only the block-level information phase; the cost of disaggregating blocks is unaccounted for. And if individuals have different preferences or claims, one representative no longer captures their cuts and appraisals. A richer type distribution might model them, but the paper supplies neither a finite encoding for such a distribution of arbitrary kitchen measures nor a query model whose complexity is covered by Theorem 1.

There is also a mismatch with the programme’s computational target. The theorem bounds communication queries against unknown, unrestricted measures. It does not analyze an algorithm on a binary-encoded society in parameters such as \(m,\tau,L\). The irrational-entitlement corollary cannot itself be an ordinary finite-input computational result; restricting to rational claims leaves a query bound driven by entitlement precision, still independent of population size. One could discretize the cake or encode valuations to ask a new algorithmic question, but that would require a new model and would not be a stronger version of this anchor.

So the strongest case against is that the proposed population is bookkeeping: aggregate the homogeneous blocks and the paper’s two-agent theorem already applies verbatim. That does not show the type-block scenario is implausible; repeated cohorts are credible, and query complexity might be considered relevant to ChoCo. The negative case is weakest if the programme values that reinterpretation itself. But it does show why this anchor offers little continuous-computational work: keeping the model faithful reduces it to the original finite-agent game, while making the population operational requires a different problem.
