The case FOR (proponent)

The strongest honest positive case is narrow: the paper’s Theorem 3, proved in this paper, says that for every \(d\ge1\), deciding whether a sequential mechanism belongs to \(GF_d\)—meaning every profile violating the deontic constraint has some agent responsible at an order at most \(d\)—is \(\Pi_{2d+1}\)-complete. The paper proves both membership and hardness. This is the right anchor because it is a named complexity result about closing responsibility gaps, not just a logical encoding.

A plausible high-multiplicity setting is a large sequential safety or dispatch system with many standardized decision units assigned to a small number of ordered escalation tiers. For instance, many sites might share the same local action options and discharge coefficients, while a small number of tiers act in sequence. The tier’s mass is its fraction of the system; a type records its place in the order, its action repertoire, and its effect on the deontic constraint. Thus the number of units \(N\) can be much larger than the number of types \(\tau\). Each unit still takes an integral action, while a type’s distribution across actions can be fractional.

I would call the resulting decision problem Cohort \(d\)-Gap-Freeness. An instance gives ordered types \(T=\{t_1,\ldots,t_\tau\}\), rational masses \(\mu_t\) summing to one, finite action sets \(A_t\), a threshold \(d\), and a deontic constraint \(\Gamma\) expressed as a Boolean combination of rational linear inequalities over action masses. A profile is a matrix \(x\) with \(x_{t,a}\ge0\) and \(\sum_{a\in A_t}x_{t,a}=\mu_t\). Here \(x_{t,a}\) is the mass of type \(t\) taking action \(a\).

The question is whether every profile violating \(\Gamma\) is covered by responsibility of some type at some order at most \(d\). Define \(D_0(x)\) to mean that \(\Gamma(x)\) is false. Recursively, \(D_q(x)\) means that \(\Gamma(x)\) is false and no type is responsible at any order through \(q\). Type \(t\) is responsible at order \(q+1\) when \(D_q(x)\) holds and there is a replacement distribution \(y_t\) for its mass such that every completion by later types puts the profile outside \(D_q\), with earlier types held fixed. The required answer is yes exactly when \(D_d\) is empty; a no answer can include a profile in \(D_d\). This is a quantified decision problem over products of simplices, with all input data finitely encoded.

My provisional expectation is Class B: hardness transfers. The paper’s reduction builds its alternation in the action variables and the deontic formula, not by relying on a large number of agents. That makes it plausible that a population limit will not erase the source of hardness. But Theorem 3 does not prove this for the continuous problem: allowing mass to split across actions could change which counterfactual guarantees exist. A prover would need to establish whether the reduction survives those fractional profiles, and whether fixed \(d\) or small \(\tau\) admits a continuous-optimization algorithm.

The scope is just Theorem 3’s gap-freeness decision problem. I would not claim this mirrors every result in the paper. Its weakest point is also central: responsibility in the proposed model belongs to a whole type cohort, because a single member of an atomless population has zero mass and cannot change an aggregate threshold. That shifts the paper’s individual-accountability question toward cohort responsibility—the very distinction the authors discuss. I think they could recognize it as a meaningful analogue if a cohort is itself an institutional decision-maker, but I would not claim they must accept it as their problem.

The case AGAINST (opponent, writing after the proponent)

Theorem 3 is a genuine anchor: it gives a \(\Pi_{2d+1}\)-complete computational problem, so the negative case cannot rest on a lack of a result to mirror. The difficulty is that its objects are ordered, individually acting decision makers. An agent’s type would have to include its position in the sequence and the action information available there. Those positions are not interchangeable: moving earlier or later changes which choices the agent can condition on and which later choices it must withstand. In a mechanism, there is only one agent at each position, so the paper supplies no natural high-multiplicity population of equivalent agents.

The proposed cohort version supplies multiplicity by letting a whole tier replace its mass distribution across actions. That gives a tier collective control over the actions of its members. If instead the members act individually in sequence, their order and observed histories matter, and the action-mass vector does not capture the contingencies in the paper’s responsibility definition. If they act together as a tier, the tier is a new decision maker. Either way, the mirror changes the bearer of responsibility—especially pointed here, since the paper motivates higher-order responsibility partly as an alternative to group responsibility.

A more careful continuum could keep individual actions and define responsibility for a measurable set of agents. But in an atomless population, a single agent has zero mass, so changing that agent’s action cannot change an aggregate constraint. Responsibility for a positive-mass set avoids that degeneracy by making the set’s coordinated intervention consequential; it therefore returns to collective responsibility. Keeping finite agents as positive-mass atoms preserves individual counterfactuals, but then the model retains the finite ordered actors whose multiplicity the continuum was supposed to relax. These are substantial semantic costs for this particular anchor, not objections based on what its complexity answer might be.

The negative case is not airtight. A sequential institution with standardized tiers that control aggregate actions could make the cohort question worthwhile, and the authors might recognize it as their problem. But that recognition depends on treating each cohort as an accountable institutional actor, rather than treating many interchangeable individuals as the society. The paper’s individual, position-sensitive responsibility question gives little support for that move, so the case against this mirror is strongest on the mismatch in what counts as an agent and whose responsibility is being measured.
