The continuous mirror question

Given a finite set of types \(T\), positive rational masses \(\mu_t\) summing to \(1\), and an LPFD formula \(\varphi\) over \(T\), decide whether there exist a nonatomic population with those type masses, a set \(A\subseteq\prod_{t\in T}[0,\mu_t]\) of feasible aggregate states, a preorder \(\preceq_t\) on \(A\) for each type, predicate interpretations satisfying the paper’s dependence condition, and a state \(z\in A\) such that \(z\models\varphi\). Each coordinate \(z_t\) is the mass of type \(t\) choosing action \(1\), with every individual choosing either \(0\) or \(1\); interpret \(D_Xy\) and \(J_{X,Y,Z}\) over aggregate states using coordinate equality and the type preorders as in LPFD.

The model it lives in

A nonatomic population of cohorts \(t\in T\), each of mass \(\mu_t\), with binary individual actions, feasible aggregate states \(A\subseteq\prod_{t\in T}[0,\mu_t]\), and a common preorder for each type; interpret LPFD’s dependence and preference operators over these aggregate states.

What the mirror covers

The mirror covers Theorem 5’s decidability result for LPFD satisfiability. It does not cover the axiomatization results, the HLPFD core characterization, or the paper’s philosophical conclusions, and it supplies no complexity bound.

Open questions for a prover

  • What is the exact complexity of this satisfiability problem as a function of formula length, \(|T|\), and the mass bit lengths?
  • Can the paper’s finite abstraction argument be realized with aggregate population coordinates while preserving the dependence and preference relations?
  • What type-preserving translation connects finite populations to this atomless model when formulas use exact equality and strict preference?

The case FOR (proponent)

The strongest case I see is a narrow one: the lead mirror is Continuum LPFD-SAT, a population version of the paper’s satisfiability problem. The paper’s single suitable computational anchor is Theorem 5, proved by the authors in §4.4: *the satisfiability problem of LPFD is decidable*. In full, given an LPFD formula, the question is whether there exists a preference-dependence model and a strategy profile at which that formula is true. The theorem gives decidability, not a running-time bound. I would not use the paper’s core results as computational anchors: they express game-theoretic properties, but do not classify an algorithmic problem. Nor would I extend this claim to HLPFD; the authors explicitly leave its decidability open.

Here is the mirror I would put to a prover. An instance is a finite set of types \(T\), positive rational masses \(\mu_t\) summing to \(1\), and an LPFD formula \(\varphi\) whose variables are types in \(T\). Imagine a nonatomic population split into those types. Every individual chooses one of two actions, \(0\) or \(1\), and all individuals of a type share the same action menu and preference ordering over population states. A population state is a vector \(z\in A\subseteq\prod_{t\in T}[0,\mu_t]\), where \(z_t\) is the mass of the whole society consisting of type-\(t\) individuals choosing action \(1\). Every such vector can be realized by measurable individual choices; \(A\) specifies which population states are feasible.

Each type \(t\) has a weak preference preorder over \(A\), and predicate symbols receive interpretations that depend only on the action-mass coordinates named in them, as in the paper’s dependence condition. Interpret \(D_X y\) by holding the aggregate action masses for types in \(X\) fixed and asking whether type \(y\)’s mass is fixed too. Interpret \(J_{X,Y,Z}\varphi\) using the paper’s same combination of fixed \(X\)-coordinates, weak preferences for \(Y\), and strict preferences for \(Z\). The question is: does there exist such a continuum game and a state \(z\in A\) with \(z\models\varphi\)? A yes witness is the population model and satisfying state. This keeps the underlying question as LPFD satisfiability, rather than asking whether an encoding has some property.

The regime is a large participation or coordination setting: many individuals choose whether to join or support a shared policy, with a relatively small number of cohorts whose members have the same relevant preferences and action options. Here \(N\), the number of individuals, is very large while \(\tau=|T|\) is modest. The type coordinate is an aggregate action share, not a claim that an individual takes a fractional action. This seems recognizably connected to the authors’ interpretation of variables as players and strategy profiles as assignments: a type stands for an exchangeable block of players, and its coordinate records their population-level behavior.

I expect this mirror to be decidable, though that is a prediction, not a result of the paper. Theorem 5’s finite abstraction argument is a plausible route: a formula mentions only finitely many types, while their aggregate coordinates range over intervals large enough to represent the equality patterns the logic observes. A proof would need to establish that the paper’s model construction can be realized with these population coordinates. It should not be advertised as polynomial-time or otherwise efficient without a separate complexity analysis.

The discrete bridge is clearest in one direction. A finite population with \(n_t\) individuals of type \(t\) embeds as the grid where \(z_t=k_t/n\) for the possible integer counts \(k_t\). Conversely, approximating an arbitrary continuum state by grid points need not preserve a formula: LPFD can distinguish exact equality and strict preference. So whether there is a useful converse translation, or an approximation guarantee, is an open question rather than part of this case.

My weakest point is that the anchor is a logic satisfiability result, not an algorithm for bribery, control, campaigning, or winner robustness. The authors’ game-theoretic applications also emphasize finite player sets. More fundamentally, because satisfiability ranges over freely chosen predicates, feasible-state sets, and preference preorders, the rational masses may have little effect on whether a formula is satisfiable: the continuous coordinates may chiefly provide a new semantic carrier for the same relational question. That makes this a plausible population mirror of Theorem 5, but a modest fit to ChoCo’s central complexity landscape. The questions it naturally opens are whether this mirror has a sharper complexity classification, whether a concrete and economically restricted payoff model changes decidability, and whether HLPFD satisfiability becomes decidable in the same continuum setting.

The case AGAINST (opponent, writing after the proponent)

The proponent’s anchor is real: Theorem 5 proves decidability of LPFD satisfiability. The strongest objection is that the proposed Continuum LPFD-SAT does not make the *population* continuous in the sense ChoCo needs.

In LPFD, a variable is a named player, and a state assigns that player one action. \(D_X\) holds those players’ actions fixed; the preference operators compare strategy profiles. In the proposed mirror, a variable is instead a whole type, and its action is the fraction of that type choosing \(1\). The operators now hold group shares fixed and compare aggregate allocations. That may define a population game, but it changes what the variables and operators mean. If each variable remains an individual player, its value in \([0,1]\) is simply a continuous action, which continuizes the action space rather than the society.

The mass coordinates do not give this formulation a distinct population semantics. For every positive mass \(\mu_t\), normalize \(z_t\) to \(q_t=z_t/\mu_t\). This maps the state space to an arbitrary subset of \([0,1]^T\), preserving equality of coordinates, predicates, and preference relations. Since the proposed model leaves the feasible set and preferences unrestricted, the masses can be scaled away. LPFD already allows arbitrary action domains, including \([0,1]\). So the formulation adds no population counts, no aggregate welfare or payoff condition, and no constraint linking a type’s preferences to those of its members. Its computational input is still the formula; the rational masses contribute no information to the satisfiability question.

The high-multiplicity reading has a related gap. In the paper, preferences are assigned separately to players, and formulas can refer to players asymmetrically. To treat several agents as one type, those agents must be indistinguishable in every respect used by the model. The paper’s semantics does not supply that replication or quotient operation. Giving a type one preorder over aggregate states is a new group-level preference assumption, not a consequence of the original player-level model. A more faithful atomless formulation would need to specify how individual choices generate feasible aggregate states, how individual preferences induce the type-level relations, and how coalitions deviate. Once those constraints are encoded, the result is a new population-game satisfiability problem, not the paper’s Theorem 5.

The same issue blocks a stronger replacement anchor based on the core. The paper characterizes core membership in its cooperative-game models, but does not classify a computational problem for it. Asking whether an atomless typed population has a core state could be interesting; it would require a definition of measurable coalition deviations and a finite representation of payoffs or feasible outcomes. Those additions may make a worthwhile project, but they are not a continuization of a computational result in this paper.

So the negative case is strongest against the sole named computational anchor: its proposed mirror either reduces to continuous actions for finitely many players, or gains population meaning only by introducing new semantics and constraints. I cannot establish that no author would find the latter extension worthwhile. The weakness is that the paper’s game-theoretic applications give a natural foothold for such an extension, even though this paper does not provide the computational problem or population model needed to make it a strong ChoCo mirror.
