The continuous mirror question

Given finite providers \([N]\), finite item menus \(L_j\), a finite support \(T\) of user types with rational masses \(\mu_t\) summing to one, rational satisfaction values \(\sigma_t(l)\), and a fixed provider profile \(X\), compute the expected mass \(a_{t,j}=\mu_t q_{t,j}\) assigned to each provider and \(a_{t,\emptyset}=\mu_t(1-\max_j \sigma_t(X_j))\) assigned to no display. For each type \(t\), sort \(s_{t,j}=\sigma_t(X_j)\) as \(s_{t,(1)}\le\cdots\le s_{t,(N)}\), set \(s_{t,(0)}=0\), and compute \(q_{t,j}=\sum_{r=1}^{\rho_t^j}(s_{t,(r)}-s_{t,(r-1)})/(N-r+1)\), where \(\rho_t^j\) is a rank of \(s_{t,j}\).

The model it lives in

A continuum of audience mass distributed over complete satisfaction types, with providers and their finite item menus remaining discrete. Each type receives the paper’s per-user lottery; its expected provider flows are weighted by \(\mu_t\).

The objection that survived

What the mirror covers

The mirrors cover Theorem 3’s mediator computation and Theorem 2 / Corollary 2’s potential and convergence argument. They leave the fairness and uniqueness results, welfare bounds, and user-utility bounds untouched.

Open questions for a prover

  • Can a pure Nash equilibrium of the weighted provider game be found in time polynomial in \(N\), \(|T|\), the menu sizes, and the input bit length?

The case FOR (proponent)

A credible mirror is a platform with a very large audience but relatively few distinct satisfaction profiles. A type \(t\) is a user’s complete satisfaction function \(\sigma_t\) over every item any provider can offer; \(\mu_t\) is the fraction of the audience with that function. For example, a news app might have millions of visits from recurring audience segments, while the providers and their finite item menus remain strategic and discrete. If \(n_t\) of \(n\) users have type \(t\), then \(\mu_t=n_t/n\); multiplying the continuous per-capita payoff by \(n\) recovers the original display-count payoff, so providers’ incentives are unchanged. This is a high-multiplicity regime in the sense relevant here: \(n\) can be much larger than the number \(\tau\) of distinct types.

My lead anchor is Theorem 3, proved in the paper. It gives a closed-form Shapley display probability for any fixed strategy profile \(X\) and user \(u_i\). Sort the providers’ satisfaction levels for that user as \(\sigma_i^1(X)\le\cdots\le\sigma_i^N(X)\), preserving duplicates, set \(\sigma_i^0(X)=0\), and let \(\rho_i^j(X)\) be a rank at which provider \(j\)’s satisfaction occurs. Then
\[ \Pr(\mathrm{SM}(X,u_i)=j) =\sum_{r=1}^{\rho_i^j(X)} \frac{\sigma_i^r(X)-\sigma_i^{r-1}(X)}{N-r+1}. \]
The paper also gives an implementation that samples a recommendation in linear time in the number of providers \(N\).

The continuous problem I would hand to a prover is Continuous Shapley Mass Allocation. An instance gives finite provider menus \(L_j\), \(\tau\) supported user types with binary rational masses \(\mu_t\) summing to one, their satisfaction values \(\sigma_t(l)\), and a fixed provider profile \(X\). The task is to compute the expected mass assigned to each provider and to no display. For \(s_{t,j}=\sigma_t(X_j)\), sort the \(N\) values for type \(t\) as \(s_{t,(1)}\le\cdots\le s_{t,(N)}\), with \(s_{t,(0)}=0\), and use the formula above to obtain \(q_{t,j}\). The output is \(a_{t,j}=\mu_tq_{t,j}\) for each provider and \(a_{t,\emptyset}=\mu_t(1-\max_j s_{t,j})\). These values are the expected type-mass flows; each individual still receives a single recommendation or none according to a lottery. There is no optimization objective here: the task is exact computation of the mediator’s allocation. Computing the full flow by sorting takes \(O(\tau N\log N)\) arithmetic operations, with polynomial bit complexity for rational input. I expect this mirror to be tractable, Class A. The paper has no named hardness result to anchor a claim that discrete hardness dissolves.

A second, less direct computational anchor is Theorem 2, proved in the paper, together with its Corollary 2. Theorem 2 says recommendation games induced by the Shapley mediator are exact potential games; the corollary says every strict better-response dynamic converges. In the paper’s finite-user setting, this gives a pure Nash equilibrium and rules out cycles of strict improvements.

The corresponding continuous question is Weighted Shapley Stability: given the same finite provider menus and a rational-mass society, provide a potential certifying that every strict unilateral improvement path ends at a pure Nash equilibrium. This lift has a direct candidate. For each type, sort \(E_t=\{0,1\}\cup\{\sigma_t(l):l\in\bigcup_j L_j\}\) as \(0=e_{t,0}<\cdots<e_{t,B_t}=1\). Let \(k_{t,r}(X)\) count providers whose selected item has satisfaction at least \(e_{t,r}\) for type \(t\), and write \(H_k=\sum_{h=1}^k 1/h\), with \(H_0=0\). Then
\[ \Phi^\mu(X)= \sum_t\mu_t\sum_{r=1}^{B_t} (e_{t,r}-e_{t,r-1})H_{k_{t,r}(X)} \]
is an exact potential: a provider’s payoff change is exactly its change in this function. With finite provider menus, every strict-improvement path terminates, in at most \(\prod_j|L_j|-1\) moves. I expect this stability-certificate problem to be tractable in the structural sense of Class A. That bound can be exponential, however; Theorem 2 does not establish a polynomial-time algorithm for finding an equilibrium.

These are plausible mirrors of the authors’ questions because user payoffs are additive across users, and the mediator depends on each user through their satisfaction levels. Replacing the sum over users with a mass-weighted sum preserves both the allocation calculation and the potential argument. The scope is focused on Theorem 3 and Theorem 2 / Corollary 2; it does not extend the uniqueness result or the price-of-anarchy bounds.

The weak point is that a type must have exactly the same satisfaction function over all available items, which is a demanding assumption for personalized platforms. More fundamentally, these extensions mostly replace finite sums with type-weighted sums. They give a natural high-multiplicity model and a support-based computation, but they do not expose a new continuous-optimization method or a population-driven complexity gap. Natural follow-up questions are whether a pure equilibrium can be found in time polynomial in \(N,\tau\), and the input bit length, and whether the paper’s welfare bounds have sharper forms in terms of the type masses.

The case AGAINST (opponent, writing after the proponent)

The strongest case against is that both proposed continuizations are low-yield for ChoCo. Theorem 3 computes a recommendation distribution for one user at a fixed provider profile. The proposed mass-allocation task repeats that calculation for each supported type and multiplies by \(\mu_t\). Its output is useful for aggregate reporting, but it adds no allocation decision over the population. Likewise, Theorem 2’s potential lifts by replacing the sum over users with a mass-weighted sum. With finite provider menus, the same argument gives convergence; the stated path-length bound can still be exponential in the number of provider profiles. Neither extension brings the paper’s central question within reach of a new continuous-optimization tool.

That is a case for low priority, though, and it does not defeat the mirrors. Large audiences with repeated satisfaction profiles and finite item catalogs are plausible. Provider payoffs depend on aggregate displays, not on the identity of the user receiving one. Expected type-mass flows preserve the per-user lotteries, and weighting the potential by type masses preserves payoff differences. The population axis is doing real representational work in both models.

A stronger follow-up would ask for an algorithm to find a pure equilibrium given rational type masses and finite provider menus. That is a genuine computational question about the weighted society, and the potential argument does not supply a polynomial-time search algorithm. I cannot rule it out by appealing to user individuation, a degenerate limit, or existing continuous computational work.

So the negative case does not meet its universal burden. Theorem 3 and Theorem 2 each have a sensible high-multiplicity interpretation, and the paper states named computational or algorithmic results to anchor them. My honest conclusion is that the mirrors may be modest extensions, but I do not have a sound argument that no worthwhile scenario exists.
