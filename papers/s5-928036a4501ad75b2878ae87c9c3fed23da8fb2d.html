The case FOR (proponent)

I can’t make a defensible computational mirror from this paper: it contains no named computational result to anchor one to.

The closest result is Theorem 2, proved here. It characterizes, for a fixed finite player set, the solutions satisfying linearity, symmetry, nullity, and efficiency: they are exactly a uniquely represented family parameterized by \(\beta\) subject to stated constraints. Corollary 1 gives the dimension of that family. These are axiomatic classification results, not claims about the complexity of a problem or an algorithm for solving one. Theorem 1 is an axiomatic characterization attributed to Myerson, not a computational result either.

One could imagine a continuum-agent version of partition-function games with measurable coalitions and payoff densities. But that would continuize an axiomatic question, and the paper supplies no computational problem whose continuous form it could mirror. Under this programme’s scope and anchor requirements, proposing it as the paper’s continuous mirror would overstate the case.

The case AGAINST (opponent, writing after the proponent)

The missing complexity theorem defeats a literal mirror of the paper’s claims, but it does not rule out a worthwhile computational question anchored in Theorem 1. The theorem gives an explicit Myerson value for partition-function games. A natural question is whether that allocation can be computed efficiently when the game describes a large population with only a few distinct player types.

For example, consider many firms grouped by abatement cost or many platform users grouped by their network effects. Within each type, agents are interchangeable; a coalition’s worth depends on its type composition, and externalities depend on how the other agents are grouped. Represent the society by rational type masses \(\mu_t\), and describe worths as functions of coalition-mass profiles. Using per-capita worths, a type’s limiting payoff density can be defined from finite replicas: if each replica has type proportions approaching \(\mu\), scale an individual’s payoff by the population size. The continuous question is then whether this limit exists and whether it can be computed or approximated from a succinct worth function, with running time measured in the number of supported types, input length, and approximation tolerance.

That asks about the population itself: a share of firms of each type, rather than a named list of firms. The mass-based coalition structures follow from applying the population limit to the paper’s game model. Theorem 2’s parameterized family could also motivate computation of the admissible allocation set, though that is a less direct anchor.

This is an algorithmic follow-on to an axiomatic result, not a complexity result already stated in the paper; that makes the case weaker than a mirror of a theorem about an algorithm or hardness bound. But Theorem 1 supplies a concrete allocation rule to evaluate, and the high-multiplicity externality-game regime is a plausible setting for doing so. The absence of a numbered complexity theorem does not by itself show that the resulting computational question is unworthy.
