The case FOR (proponent)

The strongest honest positive case is a narrow computational extension of the paper’s strategic aggregation model, rather than a claim that the paper’s existing two-group model needs continuizing.

The useful anchors are Theorem 1 and Theorem 2, both proved in this paper. Theorem 1 says that a pure-strategy Nash equilibrium can exist only if the angle between the groups’ true preference vectors is less than \(\pi-\arcsin(\alpha/(1-\alpha))\). Theorem 2 says that this condition is sufficient too, and characterizes the equilibrium reports: with \(R\) the \(\pi/2\) rotation matrix, they are
\[ \theta'_A=\frac{(\sqrt{1-2\alpha}I-\alpha\,\operatorname{sign}(\theta_D^*\cdot R\theta_A^*)R)\theta_A^*}{1-\alpha}, \qquad \theta'_D=\operatorname{sign}(\theta_D^*\cdot R\theta_A^*)R\theta_A^*. \]
Their angle is \(\pi/2+\arcsin(\alpha/(1-\alpha))\). Theorem 2 is the stronger anchor: it gives an explicit equilibrium, not just a necessary condition.

These are constructive equilibrium results, but the paper states no named complexity classification such as membership in P or NP-hardness. So the computational status below is a proposed research question, not a complexity result established by the paper.

Call the proposed problem Type-Distribution Averaging Equilibrium. An instance has \(\tau\) stakeholder types, rational masses \(\mu_t>0\) summing to \(1\), and true preference vectors \(\theta_t^*\in S^1\). Require one type to have mass greater than \(1/2\), so the aggregate report cannot be zero. Each type chooses one report \(\theta_t\in S^1\), shared by its members. The aggregate is \(q=\sum_t\mu_t\theta_t\), normalized to \(q/\|q\|\). Type \(t\)’s payoff is \(q\cdot\theta_t^*\), equivalent to its expected agreement over the paper’s random contested alternatives. The task is to decide whether a pure Nash equilibrium exists and, if so, return reports for every type that satisfy the unilateral best-response conditions.

The regime is a large participatory system with many participants but relatively few recurring stakeholder profiles: \(n\) is large while \(\tau\) is modest. Each type represents agents with the same relevant preferences and payoff, and its mass is its population share. Treating a type as a strategic bloc follows the paper’s own formal game, where each group is a player. The proposed question varies the number of types while keeping the two-dimensional preference-vector aggregation that the authors analyze.

For \(\tau=2\), Theorems 1 and 2 give the exact existence criterion and equilibrium form, so that case is tractable. For variable \(\tau\), my tentative expectation is also Class A, because reports affect payoffs only through a two-dimensional aggregate direction, which may permit an angular characterization of best responses. That is a conjecture, not a consequence of the paper. Natural follow-ups include the complexity as \(\tau\) grows, whether the characterization extends to higher-dimensional preferences, and how bloc equilibria relate to a nonatomic population model.

The authors would plausibly recognize the extension: it retains their reported preference vectors, weighted averaging rule, utilities, and pure-equilibrium question. Its scope is their strategic-equilibrium findings—especially Theorems 1 and 2—not their separate observations about truthful-report fairness, alternative mechanisms, or deliberation.

The weak point is substantial: the paper already assigns the two groups continuous population shares \(\alpha\) and \(1-\alpha\). Its two-group model is therefore already a continuous-population model; presenting that same case as a new mirror would be a collision. The positive case survives only as the \(\tau\)-type computational extension, and the paper’s two-group theorem motivates that question without resolving its complexity.

The case AGAINST (opponent, writing after the proponent)

Theorem 1 and Theorem 2 are poor targets for a *new* continuous mirror because the paper’s two-group model already uses continuous population shares. The minority’s size is the real parameter \(\alpha\), and the aggregate is already \((1-\alpha)\theta_A+\alpha\theta_D\). The theorems characterize equilibrium from \(\alpha\) and the angle between the groups’ true preferences; no voter count or discrete population computation enters. The truthful-report fairness result has the same feature. A mirror that replaces group counts with shares would restate the paper’s model.

The proposed \(\tau\)-type extension is the strongest possible repair, but it changes what the players are. Giving each type one shared report makes each type a strategic bloc. Then the computation scales with \(\tau\), the number of blocs, while increasing the number of people within a bloc changes nothing. That may define a coherent multi-player game, but the paper’s two-bloc equilibrium results do not establish that this is the high-multiplicity version of independently reporting agents.

If members report individually, a unilateral report changes the aggregate by only \(1/n\). In the nonatomic limit, it changes the aggregate by zero, so each person is indifferent among reports. Pure Nash equilibrium then stops capturing the paper’s strategic effect; retaining it requires a positive-mass coalition deviation, which reintroduces bloc coordination. The paper’s informal claim that collusion is unnecessary does not by itself resolve this limit: individual rationality in a finite population does not give an individual positive influence in a nonatomic one.

There is also no named complexity result here to translate. The paper gives an analytic characterization of a two-player continuous-action game. Asking for the complexity of equilibrium in a \(\tau\)-bloc generalization could be worthwhile on its own, but it would be a new variable-player game, rather than a computational consequence of making this paper’s population continuous. The honest negative case is therefore strongest against calling the proposed extension a ChoCo mirror. It cannot rule out the extension’s independent research value; that is where the universal “no scenario” claim is weakest.
