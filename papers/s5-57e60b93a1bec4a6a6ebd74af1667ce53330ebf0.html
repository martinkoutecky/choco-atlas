The continuous mirror question

Given a path with positions \(1,\ldots,m\), a finite type set \(T\), binary additive valuation vectors \(u_t\in\{0,1\}^m\), a rational mass vector \(\mu\) with \(\sum_t\mu_t=1\), and rational per-capita capacities \(b_j\), decide whether there are masses \(\lambda_{t,I}\ge0\) for types \(t\in T\) and intervals \(I\subseteq\{1,\ldots,m\}\), including \(\varnothing\), such that \(\sum_I\lambda_{t,I}=\mu_t\), \(\sum_{t,I:j\in I}\lambda_{t,I}=b_j\), \(\sum_{t,I:j\in I}u_t(j)\lambda_{t,I}=b_j\), and for every positive-mass classes \((t,I)\), \((t',J)\) with \(J\ne\varnothing\), some \(j\in J\) satisfies \(u_t(I)\ge u_{t'}(J\setminus\{j\})\), where \(u_t(I)=\sum_{j\in I}u_t(j)\).

The model it lives in

A normalized capacitated path in which recurring valuation types carry mass \(\mu_t\), each mass unit receives one indivisible interval, capacities \(b_j\) scale with population, and feasibility enforces completeness, non-wastefulness, and \(EQ1\).

The objection that survived

Per-capita copies permit overlapping interval assignments and destroy the paper’s single-path separator mechanism, so this is not a literal high-multiplicity copy of the original reduction.

fatal: False

What the mirror covers

The mirror covers the connected \(EQ1\)-non-wastefulness decision problem in Corollary 1, part \(a\). It leaves the \(EF1\) variants, utilitarian-welfare formulations, Theorem \(2\)’s \(PO\) and egalitarian results, Theorems \(3\)–\(5\), and the chore extensions unmirrored.

Open questions for a prover

  • Does the common-threshold characterization with \(r_t(I)=\min_{j\in I}u_t(I\setminus\{j\})\) yield a polynomial-time LP algorithm for all rational \(\mu\) and \(b\), including empty bundles?
  • Does a meaningful continuous analogue of the paper’s \(PO\) or structured-preference results survive under the same capacitated-path model?

The case FOR (proponent)

The strongest positive case is a high-multiplicity mirror of the paper’s connected EQ1-plus-non-wastefulness problem. I would use Corollary 1 as the sole anchor.

Corollary 1 is proved in this paper, as a consequence of the construction behind Theorem 1. It states that, on a path with \((4,4)\)-sparse binary valuations, checking whether there exists a connected allocation that is

(a) EQ1 and non-wasteful,

(b) EF1 and non-wasteful,

(c) EQ1 with utilitarian welfare at least \(m\), or

(d) EF1 with utilitarian welfare at least \(m\),

is NP-complete. Here \(m\) is the number of goods. I would anchor specifically on part (a), because it retains both the paper’s fairness notion and its efficiency requirement.

The lead mirror is Continuous Connected EQ1–NW. Its population consists of a finite set \(T\) of valuation types. A type \(t\) is a complete binary additive valuation vector \(u_t\in\{0,1\}^m\) over an ordered path of positions \(1,\ldots,m\). The society is a rational distribution \(\mu\), where \(\mu_t\) is the mass of agents of type \(t\) and \(\sum_t\mu_t=1\). The intended regime is a large population of interchangeable households, teams, or classes, with only a small number \(\tau=|T|\) of recurring valuation profiles. For example, a large institution may repeatedly allocate contiguous blocks of standardized rooms, appointments, or processing slots to agents from a few role types. Agents sharing a type have identical valuations for every position.

A nondegenerate continuum requires the corresponding homogeneous supply scaling. Let \(b_j\) be the supply of copies of path position \(j\) per unit population. This is a capacitated path: copies remain indivisible, but a unit of agent mass still receives an integral interval of positions. For rational data, multiplying by a sufficiently large \(N\) gives \(N\mu_t\) agents of type \(t\) and \(Nb_j\) indivisible copies of position \(j\). Thus the continuous model is the normalized high-multiplicity limit, not a cake-cutting model.

The decision variable is \(\lambda_{t,I}\), the mass of type \(t\) assigned the integral connected bundle \(I\), where \(I\) is an interval of the path or the empty bundle. It must satisfy \(\sum_I\lambda_{t,I}=\mu_t\) for every \(t\), and \(\sum_{t,I:j\in I}\lambda_{t,I}=b_j\) for every position \(j\). The latter is completeness.

Non-wastefulness requires every supplied copy to be assigned to a type valuing it. Equivalently, for each \(j\), \(\sum_{t,I:j\in I}u_t(j)\lambda_{t,I}=b_j\). EQ1 is imposed pointwise on positive-mass bundle classes: whenever \(\lambda_{t,I}>0\) and \(\lambda_{t',J}>0\), with \(J\neq\varnothing\), there must be a \(j\in J\) such that \(u_t(I)\ge u_{t'}(J\setminus\{j\})\). The question is whether such a \(\lambda\) exists.

This is recognisably the authors’ problem. The path, connected integral bundles, binary additive valuations, EQ1, and non-wastefulness are all retained. What changes is precisely the population representation: named agents are replaced by masses of indistinguishable agents. The goods have not become divisible, and the utility test is not replaced by an average welfare criterion. The aggregate variable \(\lambda\) merely records how much type mass receives each integral bundle.

I expect this mirror to be Class A: the discrete NP-hardness should dissolve in this high-multiplicity regime. For binary additive valuations, define the residual value of an interval \(I\) for type \(t\) by \(r_t(I)=\min_{j\in I}u_t(I\setminus\{j\})\). EQ1 is equivalent to requiring \(u_t(I)\ge r_{t',J}\) for every two occupied bundle classes. Hence one can enumerate an integer threshold \(q\) and allow only bundle classes satisfying \(u_t(I)\ge q\) and \(r_t(I)\le q\). For each \(q\), the remaining feasibility problem is a linear program in \(O(\tau m^2)\) interval variables and polynomially many constraints. On a path there are only \(O(m^2)\) connected bundles, and the type-level sparsity promise can be retained by requiring each type and each position to have at most four positive incidences.

The finite-to-continuous correspondence is also unusually clean. A finite high-multiplicity allocation gives \(\lambda\) by dividing bundle counts by \(N\). Conversely, any rational \(\lambda\) can be realized exactly after clearing denominators. The hardness in Corollary 1 is therefore plausibly tied to atomic assignment and the gadget-specific identity of agents, rather than to the population mass itself. This is exactly the kind of Class A collapse the programme is looking for.

The scope claim is deliberately narrow: this covers Corollary 1(a), not the paper’s EF1 variants, the Pareto-optimality hardness in Theorem 2, or the fixed-order algorithm in Theorem 3. Natural follow-up questions are whether the LP collapse survives general monotone valuations, whether Pareto optimality creates a continuum-specific obstruction, and whether connected bundles on trees or general graphs retain a pricing or separation barrier.

The weakest point is the supply scaling. With one fixed copy of every good and an atomless population, almost all agents must receive empty bundles, so the continuum would be degenerate. The mirror therefore uses per-capita copies of path positions, which is a genuine co-modification of the resource model. An opponent could argue that this is a capacitated-path problem rather than exactly the paper’s one-copy path problem. My response is that the modification is forced by continuization and preserves the paper’s defining combinatorics: indivisible integral intervals, common path connectivity, type-specific valuations, EQ1, and non-wastefulness. If that co-modification is accepted, this is a concrete and credible positive mirror; if it is forbidden, the fixed-inventory version has no meaningful continuous regime.

The case AGAINST (opponent, writing after the proponent)

The proponent chose the paper’s strongest anchor, and the honest negative case is weak.

The best objection concerns the resource scaling. In the paper, a path with \(m\) goods admits at most \(m\) nonempty bundles. If the population becomes atomless while the path remains fixed, the mass receiving goods tends to zero; non-wastefulness and EQ1 then lose their intended meaning. Thus a genuine continuum requires scaling the goods as well.

But the proposed scaling changes more than population size. With \(N\) copies of every path position, two agents may receive overlapping intervals at the same positions. The original allocation is a partition of one path into disjoint intervals; the proposed object is a capacitated interval-assignment problem. The separator-goods mechanism in Theorem 1 no longer creates the same global blocking constraints, and the paper’s \((4,4)\)-sparsity is preserved only at the compressed type level, not as literal agent–good sparsity. Replicating the whole path instead does not solve this: disjoint path copies remove the common ordering, while concatenating them makes valuations location-dependent and causes the type space to grow with the population.

That is the strongest case against calling this a mirror of the paper’s exact problem. It says that the nondegenerate version is a new capacitated-path model, not merely the paper with many agents.

However, the programme explicitly permits per-capita resource scaling when it is forced by continuization. Under that rule, the objection does not defeat the anchor. Standardized rooms, processing slots, or appointment positions are plausible repeated resources, and the resulting question still retains integral bundles, path connectivity, binary valuations, EQ1, and non-wastefulness.

Moreover, the proposed LP is not merely a handwave. For occupied bundle classes, EQ1 is equivalent to the existence of a common threshold \(q\) such that every assigned interval \(I\) satisfies \(u_t(I)\ge q\) and \(r_t(I)\le q\), where \(r_t(I)=\min_{j\in I}u_t(I\setminus\{j\})\). Enumerating \(q\) leaves an ordinary LP over type–interval masses. Rational solutions can be realized exactly after clearing denominators. That is a legitimate Class A result, regardless of whether the original NP-hardness survives.

So the negative case can insist that the mirror should be labelled a capacitated-path generalization rather than an exact continuization of Corollary 1(a). It cannot honestly establish that no worthwhile continuous mirror exists. Under the programme’s stated rules, this anchor survives.
