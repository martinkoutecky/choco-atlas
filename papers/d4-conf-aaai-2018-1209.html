The continuous mirror question

Given a feasible configuration space \(X\), bounded features \(\phi\), basic parts \(\mathcal P\), an initial configuration, and a finite support \(T\) with binary-rational masses \(\mu_t\) summing to one, let each type have an unknown linear utility \(u_t(x)=\langle w_t,\phi(x)\rangle\), and let the population objective be \(\bar u_\mu(x)=\sum_{t\in T}\mu_tu_t(x)=\langle\bar w,\phi(x)\rangle\). At each round \(r\), a learner selects a part \(p_r\), holds the rest fixed, and receives a feasible replacement that is conditionally \(\alpha\)-informative for \(\bar u_\mu\). Does PCL achieve \(T^{-1}\sum_{r=1}^{T}\mathrm{CREG}^{\bar u_\mu}_{p_r}(x^r)\le 2DS\lVert\bar w\rVert/(\alpha\sqrt T)+(\alpha T)^{-1}\sum_{r=1}^{T}\bar\zeta_r\), where \(D\) bounds feature magnitudes, \(S\) is the largest part feature-set size, and \(\bar\zeta_r\) is the omitted-feature residual under the aggregate utility?

The model it lives in

A single shared configuration \(x\in X\), decomposed into parts, serves a population with type support \(T\) and rational masses \(\mu_t\). Type \(t\) has utility \(u_t(x)=\langle w_t,\phi(x)\rangle\), and the design is evaluated by \(\bar u_\mu(x)=\sum_t\mu_tu_t(x)\). The learner’s decisions are its sequence of configurations and partial replacements; a common group feedback oracle returns replacements that satisfy the stated informativeness condition for \(\bar u_\mu\).

The objection that survived

The regret guarantee depends on the population only through its aggregate utility and has no support-size dependence, so it may reveal little about the population’s computational structure.

fatal: False

What the mirror covers

The mirror covers Theorem 1’s average conditional regret guarantee and Proposition 1’s local-optimality certificate under aggregate utility; it leaves the paper’s empirical evaluations and general solver-runtime behavior without population-specific claims.

Open questions for a prover

  • Can the common group feedback oracle be implemented from type-level responses while retaining conditional \(\alpha\)-informativeness for the aggregate utility?
  • What running-time bounds for partial inference depend on support size \(\tau\) and input bit length?

The case FOR (proponent)

The strongest case is a narrow mirror of the paper’s part-wise preference learning, with a group of customers as the “user.” The paper has no named P, NP-hardness, W[1]-hardness, or FPT classification. Its anchors are instead a learning-theoretic regret bound and a finite local-optimality guarantee.

Consider a hotel chain, campus, or hospital choosing one shared configuration for a large population. There are \(N\) people but only \(\tau\) complete preference types, with \(N\gg\tau\). A type includes the utility weights and feedback behavior relevant to the decision. Its mass \(\mu_t\) is its fraction of the population, with rational masses summing to one. The configuration \(x\) is built from parts such as rooms or zones, as in the paper. If type \(t\) has utility \(u_t(x)=\langle w_t,\phi(x)\rangle\), the group’s objective is

\[ \bar u_\mu(x)=\sum_{t\in T}\mu_tu_t(x) =\langle\bar w,\phi(x)\rangle, \qquad \bar w=\sum_{t\in T}\mu_tw_t. \]

The regime is the large user population with few repeated preference types; the decision remains one shared product. For a finite population with \(n_t\) people of each type, \(\mu_t=n_t/N\).

My lead anchor is Theorem 1, proved here. It states that for a conditionally \(\alpha\)-informative user, PCL’s average conditional regret after \(T\) iterations is at most

\[ \frac{1}{T}\sum_{t=1}^{T}\mathrm{CREG}_{p_t}(x^t) \le \frac{2DS\lVert w^*\rVert}{\alpha\sqrt T} + \frac{1}{\alpha T}\sum_{t=1}^{T}\zeta_t. \]

Here \(D\) bounds feature magnitudes, \(S\) is the largest part feature-set size, and \(\zeta_t\) accounts for utility change in features omitted by the algorithm’s update: it is zero on iterations updating the full part feature set, and otherwise is the user’s utility gain on the omitted features \(I_t\setminus J_t\). That residual matters: the theorem alone gives a vanishing \(O(T^{-1/2})\) bound only when the average residual is controlled.

The corresponding continuous question is Population PCL. An instance consists of a feasible configuration space \(X\), bounded feature map \(\phi\), basic parts \(\mathcal P\), a finite support \(T\) with rational masses \(\mu_t\), an initial configuration, and a group feedback oracle. The type utilities \(w_t\) are unknown to the learner. Each round, the learner presents a part \(p\) with the rest of the current configuration fixed; the population returns one feasible common replacement \(\hat x_p\) that is conditionally \(\alpha\)-informative for \(\bar u_\mu\). The question is whether a PCL-style learner can return configurations whose average aggregate conditional regret satisfies the Theorem 1 bound, with \(\bar w\) and the corresponding aggregate residual in place of \(w^*\) and \(\zeta_t\). The solution is the learner’s sequence of recommendations and its final configuration, evaluated by that bound.

This is the strongest mirror because the aggregate utility remains linear in the same features, and the common feedback has the same form as the paper’s user improvement. The proof’s linear-algebra argument then carries over with \(\bar w\) substituted for \(w^*\). I would expect Class A when part-wise inference and the group feedback can be computed efficiently: the population adds support-weighted aggregation, while inference still concerns one part. That is a conditional expectation, not a general polynomial-time result—the paper’s MILP inference can be hard, and it establishes no blanket runtime bound. The natural follow-up questions are how runtime depends on \(\tau\), whether the residual can be bounded through part ordering, and how the guarantee changes when masses or group feedback are estimated from samples.

A second anchor is Proposition 1, proved here. It says: for parts \(p_1,\ldots,p_n\), suppose there are rounds
\[ \tau_1<\cdots<\tau_n<\hat\tau_1<\cdots<\hat\tau_n\le T \]
with \(p_{\tau_k}=p_{\hat\tau_k}=p_k\) for every \(k\), and \(\mathrm{CREG}_{p_t}(x^t)=0\) for every \(t\ge\tau_1\). Then \(x^T\) is locally optimal: no single part can be changed, holding the rest fixed, to improve the user’s utility.

The mirror is Two-Sweep Population Local-Optimality Certification. Given the same population model and a common group oracle with respect to \(\bar u_\mu\), ask whether two complete passes over the parts with zero aggregate conditional regret from the first pass onward certify that the final configuration has no improving one-part replacement for the population objective. The output is that configuration and the sweep certificate. Under the paper’s assumptions, this is Class A: it uses a finite number of part interactions, though the cost of each depends on the underlying part inference. Further questions include whether this coordinate-wise guarantee can be strengthened to global optimality, and how it depends on the decomposition.

The weak point is the collective feedback model. The paper elicits from one coherent user; this mirror assumes a large population can provide one common critique that reflects its mass-weighted utility. If types instead return different preferred replacements, these theorems do not automatically apply: their weighted mixture need not be a feasible common replacement or satisfy the same regret condition. That is a real extension, and the one a referee should scrutinize. Still, for an institution or community acting as the client for a shared design, a collective response is a credible CPE question the authors could recognize. This case covers PCL’s theoretical guarantees, not the paper’s empirical results or the general complexity of its MILP problems.

The case AGAINST (opponent, writing after the proponent)

I would vote against both anchors as ChoCo mirrors. The paper’s Theorem 1 gives a regret bound for online learning, and Proposition 1 gives a local optimality condition. Neither classifies a computational problem by running time, approximation, or parameterized complexity. The claim that part-wise inference can be exponentially faster is motivation supported by experiments, not a complexity result. A population version of these guarantees may be mathematically valid, but it does not supply the kind of complexity question the programme is meant to chart.

For Theorem 1, the strongest version of the proposed mirror uses a shared configuration and the mass-weighted utility
\[ \bar u_\mu(x)=\sum_t \mu_t u_t(x)=\langle \bar w,\phi(x)\rangle. \]
If the population can provide feedback that is conditionally \(\alpha\)-informative for this aggregate utility, the proof goes through with \(\bar w\) substituted for \(w^*\), and with an aggregate residual term. That is a clean corollary. But the distribution over types adds no computational structure to the result: the bound has no dependence on support size \(\tau\), and the learner still optimizes over the same parts of the same configuration space.

The population feedback assumption carries the hard modeling step. If everyone has the same complete preference and feedback type, the aggregate reduces to one user. If types differ, their individual improvements need not combine into one feasible improvement that is informative for \(\bar u_\mu\). The paper supplies no collective feedback rule that ensures this. Assuming such a group oracle makes the theorem immediate; constructing one would be a new group preference elicitation problem. If the type utilities are known, computing \(\bar w\) is straightforward preprocessing and PCL is again the single-user algorithm. If they are unknown, the masses alone do not determine the group’s response. The residual term also remains uncontrolled unless the collective feedback and part decomposition provide a separate bound.

Proposition 1 has the same issue. Under a fixed aggregate objective and exact zero conditional regret, its proof carries over unchanged. The proposed two-sweep certificate is therefore a restatement of the coordinate-wise guarantee. It does not give an algorithm for producing or checking the certificate from type-level preferences. With known aggregate utility, checking a part still requires the underlying optimization; with separate feedback from each type, subgroup improvements do not certify that the aggregate has no improving change. The “population” adds no new computation to the proposition.

A stronger redesign could give each type its own configuration, with shared per-capita supplies or other constraints coupling the types. That would make mass consequential, and it is a plausible research problem. But it changes PCL’s object from one user learning one configuration to a coupled allocation-and-learning problem. If the type problems are uncoupled, one can run PCL separately for each type; if they are coupled, the paper’s two guarantees do not address the new optimization or feedback problem. This could be worthwhile work, but it is not a continuous mirror anchored by either result.

The group-client scenario is the best point for the other side: a large institution might reasonably seek one design for a heterogeneous community. My objection is that the proposed mirrors either compress that community into a single synthetic user, leaving the computation and guarantees unchanged, or require a new aggregation model that the paper does not provide. That makes the negative case a judgment about ChoCo’s research value, not a proof that no useful population model can be built.
