The continuous mirror question

Given a finite ordered shift template \(W\), an integer \(D\), finite worker types \(T\), rational type masses \(\mu_t\), and rational additive values \(a_{t,g}\), consider replications \(W^k\) with \(kD\mu_t\) integral. For each type define \(C_{t,k}=\max_{\mathcal Q}\min_{B\in\mathcal Q}u_t(B)\), over partitions of \(W^k\) into \(kD\) contiguous blocks, and \(\beta_t=\liminf_k C_{t,k}\). Let \(\mathcal P_W\) be the limiting empirical distributions of blocks in such partitions. Can one give a finite or compressed algorithm that outputs masses \(x_{t,b}\ge 0\) with \(\sum_b x_{t,b}=\mu_t\), aggregate block distribution in \(\mathcal P_W\), and \(x_{t,b}>0\Rightarrow u_t(b)\ge\beta_t\)?

The model it lives in

A society has worker types with masses \(\mu_t\); its repeated shift supply is described by \(W\) and \(D\). Each worker receives an integral contiguous block, while the assignment of types to block configurations is represented by masses \(x_{t,b}\). The objective is to find a mass assignment meeting each type’s limiting contiguous maximin share benchmark.

The objection that survived

The limits defining \(\beta_t\) and \(\mathcal P_W\) lack an effective finite representation, so a prover still needs a certificate model for the mass allocation; the proponent identifies this gap but does not resolve it.

What the mirror covers

The mirror covers Theorem 11’s contiguous maximin share allocation result. It leaves the thesis’s cake-cutting mechanisms, other indivisible allocation results, and online roommate results aside.

Open questions for a prover

  • Can \(\beta_t\) and \(\mathcal P_W\) be represented effectively from \(W\), \(D\), and the type valuations?
  • Can feasible assignments have finite or compressed certificates, and what is the running time in the template size, number of types, and input bit length?

The case FOR (proponent)

The strongest case I can make is a narrow one around Theorem 11, proved in Chapter 4.1.2 of the thesis. It states that, for indivisible goods arranged in a list and agents with additive valuations, a polynomial-time algorithm finds an allocation in which every agent receives one contiguous block worth at least their contiguous maximin share:
\[ \mathrm{CMMS}^{(n)}_i(I)= \max_{\text{contiguous }n\text{-partitions }(S_1,\ldots,S_n)} \min_j v_i(S_j). \]
The theorem is proved in the thesis; it cites Bouveret et al. for a broader connected-graph setting. This result is my anchor because it covers an arbitrary number of agents and preserves a clear fairness guarantee. The thesis also contains a hardness statement labelled Fact 2, but that concerns selecting an EF1 allocation from a restricted family of Pareto-optimal allocations, not the core allocation question here.

A plausible high-multiplicity setting is a large workforce receiving consecutive blocks of shifts. Shifts are indivisible and ordered; workers value them additively. As the operation grows, its roster and workforce scale together, while many workers share the same complete valuation vector. Let \(T\) be the finite set of worker types, with mass \(\mu_t\) for each type and \(\sum_t\mu_t=1\). If two workers differ in any preference relevant to the allocation, they belong to different types. The number of workers grows while the number of types stays moderate. Per-capita shift supply scales with the workforce.

Here is the mirror I would put to a prover: High-Multiplicity Contiguous MMS Allocation. Fix a finite ordered template \(W\) of shift classes and an integer \(D\), so that the growing instance has \(kD\) workers and the roster is \(W^k\). Each type \(t\) has rational additive values \(a_{t,g}\) for shift class \(g\). For a finite contiguous block \(b\), write \(u_t(b)\) for its value to type \(t\). Along replications \(k\) for which \(kD\mu_t\) is integral, let
\[ C_{t,k}= \max_{\mathcal Q\text{ partitions }W^k\text{ into }kD\text{ contiguous blocks}} \min_{B\in\mathcal Q}u_t(B), \qquad \beta_t=\liminf_{k\to\infty} C_{t,k}. \]
The instance is \(W,D,T,\mu\), and the type valuation vectors. Let \(\mathcal P_W\) be the set of limiting empirical distributions of blocks from contiguous partitions of \(W^k\) into \(kD\) blocks. The decision variable is \(x_{t,b}\), the mass of type \(t\) assigned integral block configuration \(b\). A solution has type marginals \(\sum_b x_{t,b}=\mu_t\), has bundle marginal \(\sum_t x_{t,b}\) in \(\mathcal P_W\), and satisfies \(x_{t,b}>0\Rightarrow u_t(b)\ge\beta_t\). Thus every worker still gets an integral contiguous block; only the assignment of workers to block configurations is fractional. The objective is to find such a fair mass allocation.

I expect this question to be tractable, probably through interval structure, per-type share computations, and a mass-allocation LP or configuration formulation. Theorem 11 is evidence for that direction, not a proof of it. It also suggests further questions: can \(\beta_t\) and \(\mathcal P_W\) be represented and priced efficiently from the template; can a continuous solution be rounded with a bounded loss in finite high-multiplicity instances; and can the algorithm run in \((\tau,L)\) and template size, rather than in the explicit workforce size?

I think the authors would recognize this as their problem: it retains indivisible goods, contiguous bundles, and the same maximin-share benchmark. Population mass is the continuous object. Scaling the roster with the workforce is a necessary co-modification, and fractional type-level assignment simply records how many identical workers receive each integral block. This case covers Theorem 11 only; it does not try to continuize the thesis’s cake-cutting results or its fixed-agent results.

The soft spot is that Theorem 11’s polynomial time is measured in the explicit numbers of agents and goods. It does not establish an algorithm for the compressed type-mass problem, and my limiting benchmark \(\beta_t\) is a newly stated object whose relation to finite CMMS needs proof. That is a real gap. The case still holds as a proposed mirror because it preserves the theorem’s allocation question and fairness criterion while placing them in a credible large-population regime; it does not claim the thesis has already solved the continuous version.

The case AGAINST (opponent, writing after the proponent)

Theorem 11 is the hardest anchor to defeat: it gives a polynomial-time algorithm for a named allocation problem with a clear fairness guarantee. The strongest objection is to the proposed limit model, rather than to the underlying mirror.

If the ordered list of goods stays fixed while the workforce grows, the contiguous maximin-share guarantee collapses. For identical valuations with total value \(V\), the least-valued block in any partition into \(n\) blocks is at most \(V/n\). Avoiding that collapse requires scaling the supply with the workforce. The proposed periodic roster \(W^k\) does this, but it makes the limit depend on two growing structures: the population and the ordered resource sequence.

As written, the limit formulation does not yet define a computational problem. The benchmark \(\beta_t\) and feasible set \(\mathcal P_W\) are specified through limits over replications, while the block configurations \(b\) range over strings whose length can grow with \(k\). A prover would need an effective finite representation for those objects, plus constraints that certify a feasible partition of the repeated roster. Without that representation, the proposed mass-allocation LP has no specified finite input or output.

That objection does not defeat a better mirror. One could give \(k\) in binary, encode \(W^k\) by its template, and ask for a CMMS allocation represented by counts of block configurations and a compressed tiling certificate. Assigning consecutive shifts to workers with repeated preference types is a plausible high-multiplicity regime; the bundles can remain integral while type-level assignments use mass. The model preserves the theorem’s central features and fits the programme’s allowance for per-capita supply to scale.

So the negative case is weak. The proposed limit needs a computationally effective formulation, but a finite-template high-multiplicity version looks worthwhile and I cannot honestly rule it out. Theorem 11’s anchor survives.
