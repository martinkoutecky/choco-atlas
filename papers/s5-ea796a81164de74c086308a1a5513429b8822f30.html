The continuous mirror question

Given a finite supported type set \(T\), rational masses \(\mu_t\), each type’s ranking of partner types and being unmatched, and a feasible incumbent matching recorded by masses \(a_{t,u}\), decide whether an atomless rematching can make every agent weakly better off and a positive mass strictly better off. Equivalently, maximize strictly improved mass over transfers \(y_{t,u,v}\) from incumbent partner type \(u\) to new partner type \(v\), subject to preserving incumbent row masses, permitting only weakly preferred assignments, and balancing the two sides of every cross-type match; efficiency holds exactly when the optimum is zero.

The model it lives in

A society consists of atomless masses of agents with identical preferences within each type. The incumbent matching is given by rational masses over type pairs and unmatched agents. The decision variables are masses reassigned from each incumbent partner type to each new partner type; the objective is to maximize the mass strictly improved while requiring weak improvement for everyone and feasible pairings.

The objection that survived

The paper itself does not establish that its authors would accept indifference among individuals of the same partner type as part of the roommates problem.

The case FOR (proponent)

The strongest mirror I see is a high-multiplicity version of Pareto-efficiency recognition in the roommates problem. The paper’s anchor is Theorem 3.4, presented here: the iterative biconnected-component decomposition algorithm decides whether a given matching is efficient, and the paper states that it runs in \(O(n^2)\) time. The algorithm and its correctness are developed in this paper from Lemmas 3.1 and 3.2 and Proposition 3.3; the runtime statement points to Appendix A.1 of Morrill (2010). The paper has no named hardness result to anchor instead.

Here is the continuous problem I would hand to a prover. Call it Type-Roommates Efficiency\(_\infty\). An instance has a finite set \(T\) of supported agent types, rational masses \(\mu_t>0\) summing to \(1\), and, for each type \(t\), a strict ranking of the possible partner types and being unmatched, denoted \(\bot\). It also gives a current matching as rational masses \(a_{t,u}\): for distinct types \(t,u\), \(a_{t,u}\) is the mass of type-\(t\) agents matched with type \(u\), and \(a_{t,u}=a_{u,t}\); \(a_{t,t}\) is the mass of type-\(t\) agents matched within their own type; \(a_{t,\bot}\) is the unmatched mass. For each \(t\), these masses sum to \(\mu_t\).

Ask whether this matching is Pareto efficient in the atomless society: is there a feasible rematching that makes every agent weakly better off and a positive mass strictly better off? A witness can be described by \(y_{t,u,v}\), the mass of type-\(t\) agents currently matched to type \(u\) (possibly \(\bot\)) who would be matched to type \(v\) (possibly \(\bot\)) after the rematching. The rows must preserve the current masses, \(y_{t,u,v}\) can be positive only when \(v\) is at least as preferred as \(u\) by type \(t\), and the new cross-type pairings must balance: the total mass of type-\(t\) agents assigned to \(u\) must equal the total mass of type-\(u\) agents assigned to \(t\). Within-type pairings are feasible because the population is atomless. Maximize the mass assigned to strictly preferred outcomes. The input matching is efficient exactly when this linear program has optimum zero; otherwise an optimizing \(y\) describes a Pareto improvement.

This is a plausible high-multiplicity regime for large pairing systems—say, residential cohorts or a very large service cohort—where people rank partner profiles, such as lifestyle or work-style types, and people with the same profile have the same ranking. The relevant scale is millions of agents but perhaps dozens or hundreds of supported types. Such a type is a complete description for this model: the question deliberately concerns preferences over partner types, not the identity of a particular person within a type.

Theorem 3.4 is the lead anchor because this mirror keeps its underlying question: whether a given pairing can be Pareto-improved, including when some people are unmatched. It does not ask whether the paper’s graph encoding is efficient; it asks whether the matching is efficient. The expected outcome is Class A, tractable: the LP has \(O(|T|^3)\) variables and polynomially many constraints, so exact rational linear programming decides the question in time polynomial in the support size and input bit length. The paper’s alternating-path and alternating-cycle characterization suggests a further question: can this LP be replaced by a comparably direct graph algorithm over the type-and-incumbent-outcome cohorts?

The high-multiplicity connection is substantive but should be stated carefully. Clearing denominators realizes the rational masses as a sufficiently replicated finite cohort, and fractional rematching allows the population-scale question to express improvements that a smaller finite cohort may not support. That is the relaxation’s point, not an identity for every finite instance.

My weakest point is that the paper assumes strict rankings of named individuals, whereas this mirror assumes rankings of partner types, so agents are indifferent between people in the same type. That is a real model choice, and a referee could ask whether it remains the authors’ roommates-efficiency problem. I think it is a defensible mirror because the matching, Pareto-improvement question, and unmatched option all remain; the coarsening specifies the high-multiplicity regime in which agents are indistinguishable for the problem’s purposes. It would not justify claiming a mirror for arbitrary identity-specific rankings.

The case AGAINST (opponent, writing after the proponent)

Theorem 3.4 is a genuine computational anchor: it gives a recognition algorithm and an \(O(n^2)\) running time. The strongest objection is that its input is built around named people. Each preference compares one particular agent with another, and the graph’s normal edges record those pair-specific comparisons. The theorem asks whether that particular assignment of people can be Pareto-improved.

The proposed LP is coherent for a society whose members rank partner *types*. Its balance constraints ensure a feasible rematching, and maximizing the mass that strictly improves is a natural atomless Pareto criterion. The problem is the change in what counts as a preference and a matching. Members of one type become interchangeable as partners; agents are indifferent between every person in a given partner type. The input matching becomes a distribution over type pairs. That is a plausible typed matching problem, but the LP no longer tests the paper’s strict, individual-ranked roommates problem.

A closer high-multiplicity version would have to preserve the identities that agents rank. A small set of preference labels alone would not suffice: the matching must still say which people are paired, and the endpoints’ rankings can distinguish people within any label. Preserving those distinctions requires carrying individual-level rank data into the model, so the support can grow with the population. A richer continuum with identity coordinates and preference functions might be possible, but it would need a new input representation and would not be the finite-support rational-mass mirror proposed here.

So the case against this anchor turns on the programme’s recognition gate. If the authors would regard “efficiency of a matching among partner types” as their roommates-efficiency problem, the proponent has a strong mirror. If they mean the paper’s problem of efficiency among individually named agents with strict rankings, the proposed LP changes its preference domain and loses the structure the theorem recognizes. I cannot make the universal negative airtight: the typed version is sensible, and the paper alone cannot establish that the authors would reject it. The strongest honest case is that the viable finite-type mirror is a related model, while preserving the paper’s identity-sensitive problem seems to remove the high-multiplicity compression.
