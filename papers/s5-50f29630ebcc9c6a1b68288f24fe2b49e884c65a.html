The continuous mirror question

Given processor types \(P\) with rational masses \(\mu_t\) summing to \(1\), minimum salaries \(p_t\), and processing times \(s_{tj}\), task classes \(J\) with rational supplies \(r_j\) per unit workforce, a deadline \(d\), and a per-capita budget \(B\), do rational masses \(x_{t,a}\ge 0\) exist for configurations \(a\in\mathbb{Z}_{\ge 0}^{J}\) satisfying \(\sum_j a_js_{tj}\le d\), \(\sum_a x_{t,a}=\mu_t\) for each \(t\), \(\sum_{t,a}a_jx_{t,a}=r_j\) for each \(j\), and \(\sum_t p_t\sum_{a\ne 0}x_{t,a}\le B\)? Take processing times and deadline to be positive integers encoded in unary.

The model it lives in

A configuration LP over processor-type mass, with integral task bundles per processor, per-capita task supplies, and a per-capita hiring budget; pricing reduces to unary-deadline knapsack.

What the mirror covers

Covers the FFTPS half of Theorem 20's unary-input W[1]-hardness result; leaves the FFTHS half and the paper's other scheduling, equilibrium, winning-team, and mechanism results aside.

Open questions for a prover

  • Does unary Mass-FFTPS admit a polynomial-time algorithm in \(\tau\), the number of task classes, and the input bit length, using configuration pricing?
  • What is the complexity when processing times and the deadline are binary encoded?

The case FOR (proponent)

The strongest mirror is the scheduling feasibility problem in Appendix C, specifically the FFTPS half of Theorem 20. That theorem is proved here: FFTPS and FFTHS are W[1]-hard when parameterized by the number \(n\) of agents, even when every agent’s minimum salary is \(1\) and the numerical input is unary. Its reduction from Unary Bin Packing gives all agents the same processing-time vector: each agent takes \(s_j\) time on task \(j\). So the hardness already has a one-type workforce. That is unusually good evidence for a high-multiplicity mirror.

A plausible regime is a large rollout staffed by many subcontractor or processor slots drawn from a few capability profiles. A type records the full processing-time vector and minimum project salary, so its members are interchangeable for this problem. The project has repeated classes of work orders; both the workforce and the number of jobs in each class scale together. The deadline stays fixed. The number of agents can be very large while the number \(\tau\) of distinct workforce types stays small—\(\tau=1\) in the reduction’s workforce. The paper’s own scheduling model makes this a direct scenario for its feasibility problem, not an analogy to its equilibrium results.

Call the mirror Mass-FFTPS. An instance has processor types \(T\), with rational masses \(\mu_t\ge 0\) summing to \(1\); task classes \(J\), with \(r_j\ge 0\) jobs of class \(j\) per unit of workforce; a minimum project salary \(p_t\) for each type; processing times \(s_{tj}\); a deadline \(d\); and a per-capita budget \(B\). To stay on Theorem 20’s unary domain, take the processing times and deadline to be positive integers given in unary. A configuration \(a\in\mathbb Z_{\ge0}^{J}\) is a bundle of whole tasks one type-\(t\) processor can complete: \(\sum_j a_js_{tj}\le d\).

The question is whether there are rational masses \(x_{t,a}\ge0\) of type-\(t\) processors assigned each configuration such that \(\sum_a x_{t,a}=\mu_t\) for every type, \(\sum_{t,a}a_jx_{t,a}=r_j\) for every task class, and \(\sum_t\sum_{a\ne0}p_tx_{t,a}\le B\). The zero configuration represents an idle processor. A solution is such a list of masses. Each unit of mass still receives an integral bundle of tasks; only the distribution across bundles is fractional.

This is the high-multiplicity form of FFTPS. For a finite instance with \(N\) processors, \(N_t\) processors of type \(t\), \(Q_j\) jobs of class \(j\), and total budget \(V\), normalize to \(\mu_t=N_t/N\), \(r_j=Q_j/N\), and \(B=V/N\). A finite assignment gives a Mass-FFTPS solution by dividing each configuration count by \(N\). Conversely, a rational mass solution can be multiplied by a common denominator to give an exact assignment in a scaled-up instance with the same per-capita workforce and job supplies. That is the relevant bridge: the mirror asks whether the project can be staffed across an arbitrarily large cohort with those proportions.

I expect this unary Mass-FFTPS problem to be tractable. Its configuration formulation is an LP, with potentially many columns. Pricing a column for one type is a knapsack-style optimization over configurations; with unary processing times and deadline, dynamic programming over the deadline is polynomial in the input length. Thus column generation or separation with the ellipsoid method appears to give a polynomial algorithm in the task-class count, \(\tau\), the bit length of the rational data, and the unary deadline. In the reduction underlying Theorem 20, the single type has mass \(1\), each task class has demand \(1/n\), salary \(1\), and the per-capita budget is \(1\). The mass formulation can mix integral bin configurations fractionally, which is exactly where the discrete packing obstruction may dissolve.

This case covers Theorem 20’s FFTPS result, not the paper’s Strong Nash Equilibrium or decentralized winning-team results. Further questions include whether binary-encoded processing times make pricing continuum-specifically hard, and how large the gap can be between a feasible mass solution and feasibility for the original, unscaled cohort.

The weakest point is that task classes and their per-capita supplies must be part of the scenario: the theorem’s jobs can have many distinct sizes, and the mirror lets each such class recur as the population scales. More fundamentally, the mass solution need not pack the original finite batch; it guarantees an assignment only after scaling to a suitable cohort. That is a real change in the question. I think the authors could still recognize it as their high-multiplicity FFTPS: it retains their processors, skill vectors, indivisible task bundles, deadline, and salary budget, and changes how many interchangeable processors receive each schedule.

The case AGAINST (opponent, writing after the proponent)

The strongest objection is a limit problem. FFTPS is stated for one finite project with a fixed task set and budget. If the workforce grows while those stay fixed, only a bounded number of processors need be hired, so the working workforce has vanishing mass. A literal atomless limit then loses the project’s cost and workload. To keep it nontrivial, the mirror must scale task supplies and budget with the workforce. That changes the finite-batch question in Theorem 20 into feasibility for a scaled-up workload: a rational mass solution need only realize an assignment after common-denominator scaling, not for the original instance.

That is a real change, but it does not defeat this anchor under the programme’s stated rules. Scalable workloads made up of repeated modules are plausible, the paper’s FFTPS model permits varying task sets, and processor types can preserve all the skill and salary information that feasibility uses. High-multiplicity scheduling work also studies repeated job and machine types, which supports this as a sensible regime rather than creating a collision with the paper’s result. [Parameterized Algorithms for High-multiplicity Scheduling](https://research.koutecky.name/papers/hm-scheduling.pdf)

So I cannot make a strong case that no worthwhile mirror exists. The co-scaling requirement is the honest weakness, but it does not show that the question is outside scope or that the authors would reject it. Theorem 20 gives a clear computational anchor, and the proposed configuration-mass formulation appears to be a credible high-multiplicity version of FFTPS. The fact that fractional mixing may remove the original hardness is a possible answer to that question, not an objection to asking it.
