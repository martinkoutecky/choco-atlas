The continuous mirror question

Given a finite set of complete agent types \(\mathcal{T}\), a rational population mass vector \(\mu\in\mathbb{Q}_{\ge 0}^{\mathcal{T}}\) with \(\sum_{t\in\mathcal{T}}\mu_t=1\), and an explicit finite catalogue \(\mathcal{Q}\subseteq\mathbb{Z}_{\ge 0}^{\mathcal{T}}\setminus\{0\}\) of feasible integral team compositions with rational values \(w_q\), compute an optimal \(y\in\mathbb{R}_{\ge 0}^{\mathcal{Q}}\) maximizing \(\sum_{q\in\mathcal{Q}}w_qy_q\), subject to \(\sum_{q\in\mathcal{Q}}q_ty_q=\mu_t\) for each \(t\in\mathcal{T}\). Here \(y_q\) is the number of recipe-\(q\) teams per unit of population.

The model it lives in

A continuum of agents distributed across complete capability and contribution types; each team has an integral type-composition recipe, while the population can contain fractional masses of teams. The decision variables are recipe intensities \(y_q\), and the objective maximizes total coalition value subject to using exactly the available mass of each type.

The objection that survived

The dissertation does not establish that coalition values are scale-independent or that finite integral team recipes remain repeatable in a large society, so the LP’s connection to its finite instances depends on the application.

fatal: False

What the mirror covers

The mirror covers type-based coalition structure generation and offers a separate continuous extension of type-based core feasibility; it leaves the DCOP-based hardness result, negative-rule handling, constrained-core algorithms, and quota matching mechanisms untreated.

Open questions for a prover

  • If the recipe catalogue is given succinctly through a value oracle or type-level rules, can the pricing problem be solved efficiently?
  • Under what assumptions on repeatability and team size does this LP capture the limit of finite societies with proportions \(\mu_t=n_t/n\)?
  • Which fractional-mass value extensions, such as piecewise-affine extensions, make the type-based core question meaningful and computationally tractable?

The case FOR (proponent)

I’d lead with Chapter 4, Theorem 14. It is proved in the dissertation and says: using a type-based characteristic-function representation, finding an optimal coalition structure can be done in \(O(n^{2t})\) time, where \(n\) is the number of agents and \(t\) the number of agent types. My second anchor is Chapter 4, Theorem 11, also proved there: for fixed \(t\), deciding whether the core is nonempty takes polynomial time in \(n\), and deciding whether a symmetric payoff vector is in the core takes \(O(n^t)\) time. Its proof uses the symmetry result cited as Lemma 3.2 of Shrot et al. Theorem 14 is my stronger anchor: it concerns the dissertation’s central coalition-formation task directly.

A credible regime is a large emergency-response network or workforce consortium. There may be tens of thousands of people, but only a small number of complete capability profiles: for example, medic, driver, and firefighter combinations. A type includes everything the coalition model uses about a person—capabilities, costs, and contribution to coalition value—so people assigned the same type are genuinely interchangeable. Coalition value depends on the composition of types, not on names. This is precisely the kind of high-multiplicity setting Chapter 4 motivates.

For Theorem 14, I would ask about Continuous Type-Based Coalition Structure Generation. An instance gives a finite set of types \(T\), a rational mass vector \(\mu\in\mathbb{Q}_{\ge 0}^{T}\) with \(\sum_t\mu_t=1\), and a finite catalogue \(\mathcal Q\) of feasible team recipes. Each recipe \(q\in\mathbb{Z}_{\ge0}^{T}\setminus\{0\}\) specifies the integral type composition of one team, and has rational value \(w_q\). A solution is a vector \(y\in\mathbb{R}_{\ge0}^{\mathcal Q}\), where \(y_q\) is the number of recipe-\(q\) teams per population member, satisfying
\[ \sum_{q\in\mathcal Q} q_t y_q=\mu_t\qquad(t\in T). \]
The question is to maximize
\[ \sum_{q\in\mathcal Q} w_q y_q. \]
Here the team itself still has an integral composition; the continuum lets the society contain fractional masses of each kind of team. The problem is a configuration LP. With the recipe catalogue explicit, it is tractable in \(\tau=|T|\), \(|\mathcal Q|\), and the input bit length. With a succinct value description, the natural further question is whether the pricing problem over recipes is efficient.

For Theorem 11, the corresponding question is Continuous Type-Based Core Feasibility. An instance gives \(T\), a rational society mass \(\mu\), and a coalition-value function \(F(x)\) for every coalition mass vector \(x\) with \(0\le x\le\mu\). To make this a concrete computational problem, specify \(F\) as a rational piecewise-affine function on an explicit rational triangulation of that domain. A solution is a per-capita payoff vector \(p\in\mathbb{R}^{T}\) satisfying
\[ \sum_{t\in T}\mu_t p_t=F(\mu) \quad\text{and}\quad \sum_{t\in T}x_t p_t\ge F(x)\ \ \text{for every }x\in[0,\mu]. \]
The question is whether such a \(p\) exists; for a supplied candidate \(p\), the companion question is whether it satisfies these conditions. Because the inequalities are affine on each triangulation cell, checking them reduces to checking its vertices, giving a finite LP for existence and a finite check for membership. This is a continuous, type-symmetric version of the paper’s core question, not a claim that its integer-count table already specifies values at fractional masses.

I would expect both mirrors to be tractable under these explicit representations: the first by LP, the second by LP or vertex checking. They are Class A questions, though they are not evidence that every discrete hardness result in the dissertation dissolves. The programme they generate is to find out what happens when the catalogue or piecewise-affine value function is given succinctly, when \(\tau\) is part of the input, and how the continuous optimum relates to finite societies with proportions \(\mu_t=n_t/n\).

The paper also proves the NP-completeness result in Chapter 3, Theorem 4, for decision CSG with DCOP-based coalition values. I would not use it as a positive anchor. Its reduction carries arbitrary variable interactions; a complete type description would generally encode those agent-specific interactions, leaving the number of types to grow with the population. The theorem therefore does not establish hardness in the fixed-type regime that makes the mirrors convincing. That is why, despite the programme’s preference for hardness anchors, Theorem 14 and Theorem 11 are the honest choices here.

The weakest point is the extension from integer coalition counts to fractional mass. The dissertation’s type-based values are defined on integer count vectors, while both continuous questions need a rule for fractional populations. The core mirror supplies a piecewise-affine extension; the coalition-generation mirror uses a bounded catalogue of integral team recipes and fractional team intensities. Those are defensible model choices for large interchangeable populations, but they are not consequences of the theorems. The positive case rests on the authors’ explicit focus on types, composition-dependent coalition values, CSG, and symmetric payoffs—not on pretending the paper already solved the continuous versions.

The case AGAINST (opponent, writing after the proponent)

The strongest case against these anchors is that Chapter 4 specifies values only for coalitions with integer type counts. It gives no semantics for splitting a coalition or for assigning value to fractional mass. Both proposed mirrors must add that semantics, so their computational results would concern newly specified games rather than follow from Theorems 14 or 11.

For Theorem 14, the proposed recipe model is a fractional set-partitioning problem. Its recipes remain finite teams with integral compositions, while the number of teams of each recipe may be fractional. That is a meaningful model choice, but it is an extra assumption about a large society: coalition value must depend only on a finite catalogue of team compositions, and fractional recipe counts must represent realizable population proportions. In some settings, such as repeated rescue teams, that assumption is natural. In others, coalition value may depend on scale or on interactions between particular agents, and the catalogue will not capture the problem. This limits the mirror’s reach, but it does not defeat the rescue-team case. The LP is a direct continuization of type-based coalition structure generation.

Theorem 11 has a more serious gap between theorem and mirror. Its finite game supplies values at integer count vectors; the proposed core problem supplies a piecewise-affine value function over every fractional coalition mass. Different extensions can give different blocking coalitions and different cores. An explicit triangulation makes the resulting problem well-posed, but it also makes the extension part of the input rather than a consequence of the theorem. Still, a workforce or consortium with a credible continuous production function could make this a sensible continuum core question. The missing canonical extension weakens the link to the theorem; it does not rule out a worthwhile model.

Theorem 4 in Chapter 3 offers little help to the negative case. Its arbitrary agent-level DCOP interactions generally make complete types proliferate with the population, so its NP-completeness result does not establish hardness for a fixed-type continuum. A model with finitely many role types and type-level interaction rules could be studied, but that would be a separate construction.

So the best objection is that the continuous questions require substantive modeling choices that the dissertation does not settle. That is a real limitation, especially for the core anchor. It is not enough to support the requested universal claim. The Theorem 14 mirror has a plausible high-multiplicity setting and a clear continuous formulation; by the programme’s standard, it survives. The negative case is therefore weak.
