The case FOR (proponent)

The strongest honest positive-side case is that this paper has no eligible computational anchor, so I cannot state a continuous problem that faithfully mirrors one of its named computational results. Its subject is numerical representation of preference relations, not computational social choice.

The nearest named result is Theorem 63, proved here. It says: (1) an \(I\)-connected semiorder has a unit representation; (2) a semiorder on a denumerable set has a unit representation if and only if every bounded \(P\)-chain is finite; and (3) when such a representation exists, one can choose it to be both strict and non-strict and to take rational values. These are existence and structural claims. The theorem gives no complexity classification, and the paper does not define a finite encoded input or a computational task whose running time it analyzes.

The countably infinite set in the theorem is a set of objects being compared, not a continuous population of agents. Giving those objects masses would change the model; treating their utility values as the continuity would continuize the representation or outcome side. Neither yields a society distributed over voter types, and the latter angle is outside ChoCo’s scope. I therefore have no defensible lead anchor or prover-ready continuous problem for this paper.

The case AGAINST (opponent, writing after the proponent)

Theorem 63 is the only plausible anchor, and it is not a computational result to mirror. It characterizes when a *single semiorder* admits a unit representation: the countable case requires every bounded \(P\)-chain to be finite. The paper gives no finite input model, computational task, or complexity claim. In fact, the countably infinite relations at the theorem’s center are not finite encoded instances; replacing them with finite relations changes the setting, while deciding the chain condition from an infinite relation would require a new model of computation.

The tempting continuous questions move the wrong object. If \(X\) is treated as a continuum, that continuizes the domain of objects being compared; the paper itself points to a companion treatment of the uncountable case. That is continuity of the representation domain, not of a society. If instead agents are given semiorder preferences over alternatives and distributed by type, Theorem 63 applies separately to each preference relation. The distribution over agents supplies no computational target from this paper.

One might try to assign mass to the objects in \(X\) and ask for a mass-based representation question. But that changes the theorem’s subject: its claim depends on the pairwise order structure and its chains, not on how much mass each object carries. Duplicating indistinguishable objects does not create a population-sensitive version of that structure; the paper explicitly allows equivalent elements to be identified. Any new optimization or complexity question built on such masses would be a new problem, not a mirror of a named result here.

So the proponent’s central point stands. There is no paper result that supplies a computational anchor, and the best attempts to manufacture one either continuize the object domain or add a population model and computational task absent from the paper. That is a strong negative case for a ChoCo mirror, though—as in any modelling question—it cannot rule out every conceivable new problem inspired by semiorders.
