The continuous mirror question

Given finite types \(T\), rational masses \(\mu\), a bounded worth oracle \(V(t,\ell;q)\) on feasible participation-mass vectors \(q\) satisfying \(\sum_\ell q_{t,\ell}=\mu_t\), and sampling access to specified probability measures \(\nu_{t,\ell}\) over those vectors, compute or estimate every \(\Psi_{t,\ell}=\int V(t,\ell;q)\,d\nu_{t,\ell}(q)\). What query bounds suffice for additive error \(\varepsilon\), and what exact-query lower bounds hold when each \(\nu_{t,\ell}\) has full support?

The model it lives in

A nonatomic society with type masses \(\mu\); \(q\) is its type-by-level census, \(V\) is bounded worth for a tagged type and level, and \(\nu\) gives the measure-valued coefficients over censuses. Queries to \(V\) are the computational resource.

The objection that survived

With complete types, each finite census orbit has a single worth, so the paper’s within-orbit sampling advantage vanishes; the proposed integral requires a new measure over mass censuses and a new oracle model.

The case FOR (proponent)

The strongest case I can make rests on Proposition 9.1, proved in this paper. It is the paper’s clearest named computational result. Part (i) says that, for a game \(v\) with \(\|v\|_\infty\le1\), all \(N=n\,m\binom{n+m-2}{m-1}=O(n^m)\) normalized readings—and hence all anonymous values with coefficient mass at most \(1\)—can be estimated to additive error \(\varepsilon\), with probability at least \(1-\delta\), using \(O(\varepsilon^{-2}N\log(N/\delta))\) queries. Part (ii) says that any deterministic algorithm exactly computing a full-support anonymous value must query all \(m^n-1\) nonzero profiles in the worst case. Here “full-support” means the value is nonzero on every nonzero profile. The paper proves both claims; the binary sampling tradition it cites is background, not the anchor.

A plausible regime is a large standardized contributor workforce: for instance, many people performing the same task under the same cost and participation rules, with levels such as off, attenuated, and on. There are \(N\gg\tau\) agents and a fixed, small number \(\tau\) of complete role types; in the most direct case, everyone has the same type. The society is a distribution \(\mu\) over those types. Its participation state is a mass vector \(q=(q_{t,\ell})\), where \(q_{t,\ell}\) is the fraction of society of type \(t\) at level \(\ell\), and \(\sum_\ell q_{t,\ell}=\mu_t\). A type includes every relevant characteristic, so agents within it are interchangeable.

Lead mirror: Mass-Anonymous Audit Query. An instance gives \(m\), binary-rational type masses \(\mu_t\), a bounded worth oracle \(V(t,\ell;q)\in[-1,1]\), and known sampling access to a probability measure \(\nu_{t,\ell}\) over the census states \(q\). The tagged infinitesimal agent of type \(t\) is at level \(\ell\); \(q\) records the graded participation of the rest of the continuum. The measure \(\nu_{t,\ell}\) specifies which censuses the anonymous audit averages over. The requested output is the type-level value vector
\[ \Psi_{t,\ell}(V)=\int V(t,\ell;q)\,d\nu_{t,\ell}(q). \]
The decision is which oracle points to query and what values to return; the resource objective is minimizing queries. This keeps the paper’s own-level-plus-census reading, while making society itself a distribution over participant types and participation levels.

For arbitrary bounded oracle games and full-support \(\nu_{t,\ell}\), exact evaluation has no finite-query algorithm: after any finite set of queries, the game can be changed on an unqueried region of positive measure without changing those answers. In this oracle model, exact evaluation is therefore continuum-specifically hard. The approximation question has the opposite outlook: with sampling access to the measures, all \(\tau m\) values can be estimated to error \(\varepsilon\) and confidence \(1-\delta\) using \(O(\varepsilon^{-2}\tau m\log(\tau m/\delta))\) queries. That is a direct continuous analogue of Proposition 9.1(i), and is tractable in the stated query model.

The high-multiplicity bridge makes the comparison sharper. With \(N_t\) repeated agents of type \(t\), a game depending only on type-and-level histograms has \(\prod_t\binom{N_t+m-1}{m-1}\) distinct states, rather than \(m^N\) named profiles. A full-support exact audit over this finite grid requires querying every distinct histogram state in the worst case, but querying that whole grid is polynomial in \(N\) when \(m\) and \(\tau\) are fixed. Thus the named-profile query barrier can dissolve under genuine high multiplicity; the continuum limit then raises a distinct exact-versus-approximation question.

The authors could plausibly recognize this as a mirror of their result: the quantity being computed remains an anonymous linear value of a graded-participation game, and the census has become a population mass distribution. This case covers only Proposition 9.1’s query-complexity results. The representation-theoretic characterization and blindness examples are not computational-complexity anchors, so I would not stretch the mirror to cover them.

The weakest point is also central: Proposition 9.1 is an oracle-query result, not a bit-complexity classification such as membership in P or NP-hardness. With an arbitrary function on a continuum, the exact lower bound is nearly forced by the input model. To obtain a substantive finite-input complexity landscape, one would need to specify a representation for \(V\)—for example, circuits, piecewise-linear functions, or bounded-degree polynomials—and the paper does not do that. The strongest honest positive case is therefore a narrow mirror of its query-complexity contribution, with a clear tractable approximation problem and a meaningful high-multiplicity comparison.

The case AGAINST (opponent, writing after the proponent)

Proposition 9.1 is the right anchor: it is a genuine computational result, so I would not dismiss it as merely axiomatic. But its query object does not carry over cleanly to a continuous population.

A finite reading averages \(v\) over labeled profiles with the same census. In a high-multiplicity model with complete types, assignments that differ only by swapping agents of the same type describe the same state. If the game respects that equivalence, the orbit average collapses to one evaluation at the type-by-level mass vector \(q\). The sampling problem in Proposition 9.1(i) has disappeared. If the game varies across those assignments, the assignment details matter to the problem and must be retained in the types or in additional relational data; then the finite-type distribution no longer captures the input the query result needs.

The proposed repair—integrating \(V(t,\ell;q)\) against a measure \(\nu_{t,\ell}\)—is coherent, but \(\nu\) is an added model choice. The population distribution \(\mu\) gives the masses of agent types; it does not specify a probability law over counterfactual censuses. Once that law and sampling access are supplied, the approximation bound is generic Monte Carlo for bounded functions. The exact lower bound is likewise generic for an arbitrary function oracle: finitely many point queries cannot determine its integral. The paper gives no representation or regularity condition for \(V\) on the mass simplex, and values on finite empirical populations do not determine an integral over the continuum. Adding circuits, smoothness, or another encoding could make a substantive problem, but then that added structure supplies the computational question.

So the strongest case against this anchor is that a true type quotient removes the orbit-sampling task, while restoring it requires a new census distribution and a new function model. Proposition 9.1 can inspire a continuous sampling question, but it does not itself select a well-posed, distinctive continuous mirror.

This negative case is not airtight: a natural measure over censuses and a meaningful representation of type-level worth could make continuous estimation worthwhile. Those choices are simply absent here, so the proponent’s version is a plausible new problem rather than a direct continuization of the paper’s result.
