The continuous mirror question

Given a finite type set \(T\), rational masses \(\mu_t\), finite action sets \(A_t\), and rational multilinear payoff functions of aggregate action shares, decide whether there is a type-symmetric mixed profile \(\sigma_t\) that is a Nash equilibrium and admits no positive-mass coalition deviation that strictly benefits every deviating type; if one exists, return it.

The model it lives in

A continuum anonymous game with finitely many complete payoff types and masses \(\mu_t\). The decision variables are type-level mixed strategies \(\sigma_t\); a coalition is described by deviating masses \(x_t\) and replacement mixed strategies \(\rho_t\), which determine the new aggregate shares. Search for a profile with no profitable coalition deviation.

The objection that survived

The finite anchor concerns atomic players in arbitrary payoff tables, whereas the mirror uses anonymous aggregate payoffs and positive-mass coalitions; the continuous question therefore needs separate complexity analysis.

fatal: False

What the mirror covers

The mirror covers existence and search for type-symmetric mixed SNEs in anonymous finite-type population games; it leaves the paper’s arbitrary-game verification results, finite two-agent algorithms, and experiments outside the mirror.

Open questions for a prover

  • What is the complexity of finding a type-symmetric mixed SNE in this finite-type anonymous population model?
  • Can hardness for finite anonymous games be related to the continuum problem, or do fractional-mass coalition deviations change the complexity?

The case FOR (proponent)

The best case is a population version of mixed-strategy strong Nash equilibrium. It keeps the paper’s central question intact: can a coalition coordinate a deviation that strictly benefits every member? The continuum makes the society a distribution over agent types, then asks for the computational complexity of finding a profile with no such coalition.

My lead anchor is Corollary 3.6. It states that finding a strong Nash equilibrium in a game with a constant number \(n\) of agents is NP-complete. The paper derives the NP-membership side from its own Corollary 3.5; the hardness side comes from Corollary 5 of reference [8]. This is the strongest anchor for a continuization case because it gives us a hardness question whose fate in a population model is worth investigating.

A natural regime is a large platform or market with many participants but relatively few complete payoff types: for example, millions of sellers grouped by sector and cost class, choosing among finitely many strategies, with payoffs depending on aggregate strategy shares. Each type records everything relevant to the game, including its actions and payoff parameters. Its mass \(\mu_t\) is the fraction of the population with that type. The number of agents may be enormous while the support size \(\tau\), the number of distinct types, remains modest.

Lead mirror: Typed-Continuum Strong Nash Search. An instance consists of a finite type set \(T\), rational masses \(\mu_t\geq 0\) summing to \(1\), finite action sets \(A_t\), and rational payoff functions \(u_t(a,p)\). Here \(p_{t,a}\) is the fraction of type \(t\) using action \(a\), and each payoff function is given explicitly as a rational multilinear polynomial of these aggregate action shares. A candidate profile is type-symmetric: every member of type \(t\) uses the same mixed strategy \(\sigma_t\in\Delta(A_t)\). The problem is to decide whether such a profile exists that is a strong Nash equilibrium, and, if so, return one exactly.

For a profile \(\sigma\), let \(p_{t,a}=\sigma_t(a)\) and write
\[ V_t(\rho;p)=\sum_{a\in A_t}\rho(a)u_t(a,p) \]
for the payoff to a type-\(t\) agent using mixed strategy \(\rho\). The profile must be a Nash equilibrium, so \(V_t(\sigma_t;p)\geq V_t(\rho;p)\) for every type \(t\) and every \(\rho\in\Delta(A_t)\). It must also resist every positive-mass coalition deviation. Such a deviation is represented by masses \(x_t\in[0,\mu_t]\) and replacement mixed strategies \(\rho_t\in\Delta(A_t)\), with \(\sum_t x_t>0\). It changes the aggregate mass using action \(a\) in type \(t\) to
\[ q'_{t,a}=\mu_t\sigma_t(a)+x_t\bigl(\rho_t(a)-\sigma_t(a)\bigr). \]
The profile is strong if there is no such choice for which
\[ V_t(\rho_t;q'/\mu)>V_t(\sigma_t;p) \quad\text{for every }t\text{ with }x_t>0, \]
where \(q'/\mu\) denotes the resulting within-type action shares. Thus the output is a type-symmetric mixed profile stable against coordinated deviations by any positive fraction of each type, including mixed deviations.

This is finite-dimensional despite allowing arbitrary measurable coalitions: for each type, the deviators’ mean mixed strategy determines the aggregate change. Since payoff is linear in an individual’s own mixed strategy, if all members of a type’s deviating coalition strictly gain, replacing their possibly different deviations by their average preserves the aggregate and gives that type’s deviators a common strictly improving strategy. So the coalition check really can be stated using the \(x_t\) and \(\rho_t\) variables above.

I would expect this problem provisionally to be Class C, hard for continuum-specific reasons. The search must find a profile that survives a family of fractional-mass deviations described by strict, generally nonconvex polynomial inequalities. But Corollary 3.6 does not establish that prediction: its finite-game hardness does not automatically transfer to an atomless, aggregate-payoff model. Whether the fractional coalition variables create hardness, or instead enable a tractable optimization method, is exactly the question worth handing to a prover. It also leads to concrete follow-ups: the complexity of detecting one profitable mass deviation; whether verification is easier than finding a stable profile; and whether any finite-game hardness reduction survives the anonymous, finite-type restriction.

The mirror is plausible because it preserves the paper’s distinctive computational object: mixed-strategy coalitional stability. The paper emphasizes that mixed multilateral deviations matter, and its search algorithms alternate between finding Nash equilibria and checking whether a coalition can dominate them. A population model with aggregate payoffs keeps both the equilibrium target and the coalition check, while making the society itself continuous. Mean-field game theory is a close neighbor, but this question is about exact verification and search complexity, not equilibrium dynamics or their analytic structure.

The weakest point is that the paper studies arbitrary finite strategic-form games, whereas this mirror assumes anonymous aggregate payoffs and searches for profiles that are symmetric within each type. The Corollary 3.6 reduction therefore does not carry over by inspection. Still, this is a credible high-multiplicity regime: type symmetry describes repeated agents with the same complete payoff description, while the deviation test continues to allow coalitions to select fractional masses and coordinate on mixed strategies. The case is for this one bounded mirror of the paper’s hardness result, not for a continuous version of every result in the paper.

The case AGAINST (opponent, writing after the proponent)

The strongest objection is a model mismatch in the lead anchor, Corollary 3.6. The paper’s input is an arbitrary finite strategic-form game: each player has a payoff table over joint action profiles, and SNE checks coalitions of those named players. A type mass preserves that input only when agents of the type are interchangeable in the *whole game*. In a general payoff table, they need not be: players’ interactions can depend on their identities and positions. Grouping them by their own payoff descriptions alone would lose information.

The proposed mirror repairs this by restricting payoffs to functions of aggregate action shares. That gives a coherent population game, but it changes the model rather than continuizing the one in Corollary 3.6. The corollary supplies no result about this anonymous-game restriction. A more faithful population version could allow agents of the same intrinsic type to use different strategies and let coalitions select among them. But then a type mass and one common mixed strategy per type no longer describe the profile or the possible deviators; the state must also represent how strategies are distributed within each type. The proponent’s finite-dimensional formulation gets its clarity by imposing symmetry, and that is a substantive restriction for SNE.

This is a real reason to resist treating Corollary 3.6 as an established mirror: the paper’s arbitrary-game computation does not itself identify a high-multiplicity regime, and the clean proposed regime needs additional structure. It also cautions against treating the paper’s other computational results as population results; their fixed-player verification setup has the same dependence on individually specified payoff arrays.

But this does not defeat the best nearby mirror. Large anonymous markets or platforms with finitely many payoff types are plausible high-multiplicity settings, and strong Nash stability against mass coalitions is still a recognizable computational question about SNE. The paper’s authors could reasonably regard it as their problem, even though the paper does not establish hardness or tractability there. The symmetry and encoding issues are research costs, not proof that the question is unworthy.

So the negative case is weak against the requested universal claim. It undermines the directness of the proposed mirror and exposes a serious modeling choice, but I cannot honestly rule out a worthwhile continuous mirror in an anonymous population game.
