The continuous mirror question

Given a finite type set \(T\), distinct house classes \(H=\{h_t:t\in T\}\), and positive rational masses \(\mu_t\) summing to \(1\), each member of type \(t\) has strict ranking \(\succ_t\) and owns one indivisible house of class \(h_t\), with supply \(q_{h_t}=\mu_t\). Find an assignment flow \(x_{t,h}\ge 0\) with \(\sum_h x_{t,h}=\mu_t\) and \(\sum_t x_{t,h}=q_h\), such that no positive-mass coalition can block it: a blocker chooses \(z_{t,h}\le x_{t,h}\) and reassignment masses \(y_{t,h,r}\ge 0\), where \(\sum_r y_{t,h,r}=z_{t,h}\), \(y_{t,h,r}>0\) only if \(r\succeq_t h\), \(\sum_{t,h}y_{t,h,r}\le\sum_{t:h_t=r}\sum_h z_{t,h}\) for every \(r\), and \(\sum_{t,h,r:\,r\succ_t h}y_{t,h,r}>0\). Is there an algorithm polynomial in \(|T|\) and the input bit length that computes such a flow?

The model it lives in

A nonatomic population has finitely many complete types, each specified by a ranking and the class of its privately owned indivisible house. House-class supplies scale with type masses. The assignment is recorded as a flow across types and house classes; a mass-TTC procedure follows favorite-house and owner-type cycles, transferring the bottleneck mass around each cycle until all mass is assigned.

The objection that survived

The paper supplies no runtime bound for YRMH-IGYT, so polynomial tractability of the mass version would be a new result rather than a guarantee carried by Proposition 3.

fatal: False

What the mirror covers

Covers the one privately owned house per agent subcase of Proposition 3 and its core-mechanism correspondence. It leaves multiple-object ownership, unacceptable goods, redundant endowments, and the paper’s results on complex ownership and exclusion rights aside.

Open questions for a prover

  • Prove whether bottleneck cycle transfers always yield a mass strong-core flow, and give their running time in \(|T|\) and the rational input bit length.
  • Determine whether the set of mass strong-core flows exactly matches the outcomes of the mass-TTC procedure.

The case FOR (proponent)

The paper has no named result classifying a problem as polynomial-time solvable, NP-hard, or similar. The nearest computational anchor is Proposition 3, proved in the paper using a result of Balbuzanov and Kotowski: in private-ownership economies—each object has one owner, though agents may own redundant objects or find some objects unacceptable—YRMH-IGYT, the rectified core, the refined exclusion core, and the exclusion core coincide; when the strong core is nonempty, it coincides with them too. This is an algorithmic characterization, not a runtime bound.

A concrete continuous mirror is Mass-TTC core computation. Let \(T\) be a finite set of types, with rational masses \(\mu_t\) summing to \(1\). A type records a strict ranking of a finite set \(H\) of standardized house classes and the class \(h_t\) from which its members each own one indivisible house. Take one distinct house class per type, with supply \(q_{h_t}=\mu_t\). Thus a type is complete for this problem, the house supply scales with population, and the number \(\tau=|T|\) of types can stay small while the population grows.

A solution is an assignment flow \(x_{t,h}\geq 0\), where \(x_{t,h}\) is the mass of type \(t\) receiving a house of class \(h\), with row sums \(\mu_t\) and column sums \(q_h\). Individuals still receive whole houses; only the type-level averages are fractional. There is no scalar objective in the paper’s core-selection problem: the task is to find a feasible allocation with no blocking coalition. Formally, a block selects masses \(z_{t,h}\leq x_{t,h}\) and reassigns them via \(y_{t,h,r}\). Each selected person must get a weakly preferred house, some positive mass must strictly improve, and the coalition can use at most its own endowment mass of each class: for each \(r\), total reassignment to \(r\) is at most the selected mass of its owner type.

The proposed mass-TTC procedure points each active type to its favorite available house class and each house class to its owner type. For every cycle, transfer the bottleneck mass—the minimum remaining mass among its types—around the cycle, then remove that mass of agents and houses and repeat. The problem is to output the resulting flow, or equivalently a mass-TTC outcome that is in the mass strong core. I expect this to be tractable, with a cycle-bottleneck algorithm polynomial in the number of types, house classes, and rational input bit length. This is an expected continuous result, not a claim made in Proposition 3.

The regime is a large housing exchange with many households but few combinations of preference ranking and unit class: for instance, a housing association whose members trade among standardized apartment classes. It is a plausible high-multiplicity setting because both preferences and endowment class define type. The paper explicitly treats the housing market as a special case, so its authors should recognize the question. Its TTC result is supporting prior work, not a novelty collision; the continuous question is the computation of a core allocation from type masses.

This mirror covers only the private, one-house-per-agent housing case of Proposition 3. It does not continue the paper’s distinctive results about overlapping ownership, redundant endowments, or the rectified and refined exclusion cores under complex rights. That is the weak point: the mirror is credible, but narrow, and mass-TTC is close to a type-level restatement of the familiar TTC algorithm. The broader complex-endowment models would be more distinctive, but their ownership relations are much harder to represent faithfully with a small set of types.

The case AGAINST (opponent, writing after the proponent)

The strongest objection to this anchor is that Proposition 3 is not a complexity result. It equates four solution correspondences in private-ownership economies and says when they coincide with the strong core; it gives no runtime bound, hardness result, or complexity classification. The proposed mass-TTC computation would therefore add a new computational question, rather than continuize a computational result in the paper.

The proposed model also captures only a narrow part of Proposition 3: one privately owned house per agent, grouped into standardized classes. Proposition 3 permits agents to own multiple objects, own none, and find objects unacceptable. Those features allow redundant endowments, central to the paper’s account of why the strong core can be empty. Mass-TTC does not test whether that distinctive part of the result has a useful continuous mirror.

That objection does not defeat a stronger mirror, though. A type could record both a preference ranking and a private endowment bundle, with supplies scaling with type mass. This preserves the redundant-endowment cases and is a plausible high-multiplicity economy. Whether its core correspondence can be computed efficiently is a recognizable question for these authors. I can make a case that the proponent’s example undershoots Proposition 3 and that the paper itself supplies no complexity theorem to mirror; I cannot honestly make the universal case that no worthwhile mirror exists. The negative case is weak at precisely the stronger, more faithful formulation.
