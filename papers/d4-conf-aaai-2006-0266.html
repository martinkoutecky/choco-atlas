The continuous mirror question

Given a finite target set \(J\), sensor types \(a\in\{1,\ldots,\tau\}\) with rational masses \(\mu_a\), finite mode sets \(S_a\), rational mode costs \(c_{a,s}\), visibility indicators \(\mathrm{vis}(a,s,j)\), and rational monotone concave piecewise-linear target valuations \(F_j\) over type masses, find an allocation \(x_{a,s}\ge 0\) with \(\sum_{s\in S_a}x_{a,s}=\mu_a\) that maximizes \(\sum_{j\in J}F_j(q_j)-\sum_a\sum_{s\in S_a}c_{a,s}x_{a,s}\), where \(q_{a,j}=\sum_{s:\mathrm{vis}(a,s,j)=1}x_{a,s}\).

The model it lives in

A high-multiplicity sensor fleet represented by rational type masses \(\mu_a\), where each type has shared visibility and mode costs. The decision variables \(x_{a,s}\) assign mass of each type to modes; the resulting type-mass vectors \(q_j\) determine overlapping coalition values \(F_j(q_j)\), and the objective maximizes total value minus costs counted once per assigned mass. With each \(F_j\) given by affine facets, this is a linear program.

What the mirror covers

Covers the welfare-maximization task from Theorem 1.2 for explicitly represented concave piecewise-linear valuations over typed sensor masses. It leaves the arbitrary monotone subadditive valuation class, the factor-\(n\) guarantee, and the branch-and-bound experiments without a corresponding continuous result.

Open questions for a prover

  • Does the continuous welfare problem remain tractable for broader succinct monotone subadditive valuations?
  • How closely can an optimal mass allocation be rounded to a finite typed fleet, and what guarantees depend on \(\tau\) rather than the fleet size?

The case FOR (proponent)

The strongest mirror I see is a high multiplicity version of the paper’s overlapping sensor coalition welfare problem. Imagine a large surveillance network built from repeated sensor station profiles: many sensors share the same visibility by sensing mode, energy costs, and information characteristics, while the network monitors a fixed set of target regions. The number \(N\) of sensors can be very large while the number \(\tau\) of distinct profiles remains small. A type is one such complete profile, and \(\mu_a\) is its fraction of the fleet. Mass means a share of that type’s sensors assigned to a mode; no individual sensor has to act fractionally.

My anchor is Theorem 1.2, proved in this paper. It states that Algorithm 1’s greedy solution, with welfare \(V_1\), is within a factor of \(n\) of the optimal welfare \(V^*\): \(V^*/V_1\le n\). The theorem concerns the paper’s welfare-maximization problem under monotone, subadditive coalition values and sensor costs; it is a guarantee for the greedy solution, not a claim that the optimum is computed in polynomial time.

A concrete continuous problem is High-Multiplicity Overlapping Sensor Welfare. Its input is a finite target set \(J\), types \(a\in\{1,\ldots,\tau\}\) with rational masses \(\mu_a\ge0\) summing to \(1\), and a finite set \(S_a\) of modes for each type, including sleep. The input specifies rational costs \(c_{a,s}\) and visibility indicators \(\mathrm{vis}(a,s,j)\). It also gives each target \(j\) a rational, monotone, concave piecewise-linear valuation \(F_j(q)\), represented by its affine facets, where \(q_a\) is the mass of type \(a\) observing \(j\). Require \(F_j\) to be nonnegative and subadditive on coalition masses: \(F_j(q\oplus r)\le F_j(q)+F_j(r)\), where \((q\oplus r)_a=\min(q_a+r_a,\mu_a)\). This is the mass-level counterpart of set-valued coalition subadditivity.

The decision variable is \(x_{a,s}\), the mass of type \(a\) assigned to mode \(s\). The question is to find an optimal feasible allocation, with \(\sum_{s\in S_a}x_{a,s}=\mu_a\), maximizing normalized system welfare:
\(\sum_{j\in J} F_j(q_j)-\sum_a\sum_{s\in S_a}c_{a,s}x_{a,s}\), where \(q_{a,j}=\sum_{s:\mathrm{vis}(a,s,j)=1}x_{a,s}\). A mode can observe several targets, so its assigned mass contributes to multiple overlapping coalitions; its cost is counted once. A solution is an allocation \(x\) and its induced coalition masses attaining the maximum.

This is still their problem: it chooses sensor modes to form overlapping coalitions, trades information value against sensor costs, and maximizes system welfare. The valuation family is also recognizable from the paper’s information-fusion motivation. For example, a target value can be a concave saturating function of the total information contributed by each sensor type. Types capture the visibility and cost distinctions, while the target valuation captures diminishing returns from correlated observations.

For this stated family I expect Class A. Each \(F_j\) is the minimum of its listed affine facets, so introducing a welfare variable \(y_j\) and constraining it below each facet turns the objective into a linear program. An exact optimum is therefore computable in time polynomial in the input size, including \(m\), \(\tau\), the listed modes and facets, and their binary bit lengths. Discrete typed fleets embed by setting \(\mu_a=n_a/N\); the continuous allocation permits type cohorts to divide among modes, which is the high-multiplicity relaxation.

The scope is the welfare-maximization problem Algorithm 1 approximates, for this explicit information-fusion valuation family. It does not claim to mirror the paper’s entire class of arbitrary monotone subadditive values or its branch-and-bound experiments. It also suggests further questions: how the complexity changes for broader succinct subadditive valuations, whether useful approximation guarantees can depend on \(\tau\) rather than \(N\), and how closely the continuous optimum approximates a finite fleet after rounding.

The weakest point is that Theorem 1.2’s \(n\)-factor guarantee does not itself establish a high-multiplicity algorithm: its bound grows with the individual sensor count. The tractability I predict comes from the explicit concave valuation representation, not from transferring that theorem. That restriction is meaningful for a repeated-profile surveillance regime, but a referee who requires the full arbitrary-subadditive model would reasonably regard the broader continuous question as still open.

The case AGAINST (opponent, writing after the proponent)

The strongest objection is an anchor mismatch. Theorem 1.2 bounds a particular greedy algorithm for arbitrary set-based values \(v(C,t_j)\). The proposed continuous problem instead assumes each target’s value is an explicitly represented concave piecewise-linear function of type masses. That assumption makes the problem an LP, but it is doing the work: the paper’s theorem neither assumes that structure nor gives the continuous LP result. So the LP is not a continuation of Theorem 1.2’s guarantee.

That objection does not defeat the better mirror. Repeated sensor profiles with shared visibility, costs, and information characteristics are a plausible high-multiplicity regime. In that setting, target value can reasonably depend on the mass of each profile observing it, while a sensor’s mode still couples which targets it observes. The paper’s emphasis on correlated observations and diminishing returns gives the authors a reason to recognize such a model. A richer valuation representation might make the complexity less clear, but that is an open computational question, not a reason the mirror is unworthy.

So the negative case is weak at its crucial step. I can argue that the proponent overstates how directly their LP mirrors Theorem 1.2; I cannot honestly argue that no worthwhile continuous mirror exists. The repeated-profile model survives that challenge.
