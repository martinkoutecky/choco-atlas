The continuous mirror question

Given a finite explicit set of population states Ω, a finite type set Τ, rational state probabilities and type masses μ_t^ω, and the induced posterior π(ω|t), does there exist a per-capita transfer schedule τ(r,μ) such that ∑_t μ_t^ωτ(t,μ^ω)=0 in every state and ∑_ω π(ω|t)τ(t,μ^ω) > ∑_ω π(ω|t)τ(r,μ^ω) for every type t and false report r? Such a schedule makes truthful reporting strictly Bayesian incentive compatible and permits every public decision rule based on the reported population distribution.

The model it lives in

An atomless population has finitely many complete types, with state-dependent masses μ^ω and common uncertainty over a finite set of states. Each agent reports a type; the public decision and per-capita transfer depend on the reported aggregate distribution, while a single report has zero effect on that distribution. The decision variables are transfers τ(r,μ), with state-by-state aggregate budget balance and strict Bayesian incentive constraints.

The objection that survived

For weak BIC, an individual's report leaves the aggregate unchanged, so truthful reporting is only indifference; the mirror needs strict incentives. This bounds the mirror, but condition B itself uses strict incentives and the paper explicitly includes strict implementation.

fatal: False

What the mirror covers

The mirror covers Theorem 3's condition B and its construction for implementing all decision rules. It leaves aside Theorem 1's condition C result, the comparisons among belief conditions, and Theorem 4's characterization.

Open questions for a prover

  • How does the complexity change when the finite population-state support is represented succinctly rather than listed explicitly?
  • Which finite-agent information structures converge to this mass-state model while preserving the condition B incentive and budget-balance constraints?

The case FOR (proponent)

The strongest plausible bridge is high-multiplicity contracting. Imagine a large cohort of suppliers with a finite catalog of complete types: each type specifies a supplier’s preferences, costs, and beliefs. The mass of a type is its share of the cohort. A mechanism chooses a public decision from reported type masses and assigns transfers by type, with total transfers summing to zero in every population state. This is a credible setting for asking whether truthful reporting and a balanced budget can coexist as the number of suppliers grows.

The closest anchor is Theorem 3, proved in this paper. It says that condition B is necessary and sufficient for an information structure to guarantee implementation of *all* decision rules with balanced transfers; the authors also give a construction for sufficiency. But condition B is an existence condition on transfers, and the theorem does not classify the complexity of deciding or computing anything. It therefore does not meet the requested standard for a computational anchor. Theorem 1, which says condition C guarantees implementation of efficient decision rules, is similarly an existence result.

A natural follow-on question would be: given a finite list of population states, rational probabilities, and type masses, can one decide and construct a balanced Bayesian incentive compatible mechanism for a specified decision rule? Its variables could be per-type, per-state transfers, and its constraints would express BIC and state-by-state budget balance. The paper’s transfer constructions make that direction plausible. But this is a proposed new computational problem, not a continuous version of a named computational result in the paper, and a continuum of agents changes the strategic role of an individual report.

So the honest positive case is limited: the paper offers a promising mechanism-design question for high-multiplicity populations, anchored most closely by Theorem 3, but it contains no named computational result of the required kind. There is consequently no compliant per-anchor continuous problem or complexity prediction to give. The weak point is central: the paper’s results concern finite-agent Bayesian implementability, while the proposed mirror would require both a continuum-population model and a new computational analysis.

The case AGAINST (opponent, writing after the proponent)

The proponent’s best anchor is Theorem 3, but it is not a computational result: it characterizes which finite-agent information structures permit balanced implementation. Theorem 1 and condition C are likewise existence results. The paper gives no complexity classification to continuize.

The supplier-cohort model is plausible, but its data would have to include more than type masses. In the paper, a state is a labeled profile \(\alpha\in\prod_i A_i\); the prior \(p\) determines each named agent’s posterior \(p(\alpha_{-i}\mid\alpha_i)\), and transfers are indexed by the full profile. Keeping that information retains a finite-agent problem. Replacing it with a continuum of agents and a rule \(s(\hat\mu)\) based on reported type shares changes the incentive question: one agent’s report changes \(\hat\mu\) by zero, so it cannot change the public decision. Under the paper’s weak BIC notion, zero transfers are balanced and truth-telling is an equilibrium for every such rule. Theorem 1’s efficient-implementation question collapses in the same way. This loss of individual pivotality is a familiar feature of large-economy models; for example, Bierbrauer and Hellwig show budget-balanced implementation of first-best public-good provision in a continuum because no individual can affect the aggregate outcome. That is evidence about the limit’s behavior, not a claim that their analytic result answers a computational question. [Bierbrauer and Hellwig, *Public-Good Provision in Large Economies*](https://cmr.uni-koeln.de/sites/cmr/pdf/Bierbrauer_Publication_List/LargeOct6FinalFinal.pdf)

A stronger version could require strict truth-telling. That avoids the zero-transfer collapse, but it asks a different question: whether type reports can be elicited by balanced transfers when reports do not affect the public decision. With finitely many explicitly listed aggregate states, those strict incentive and balance constraints form a linear feasibility problem; positive strict margins can be normalized by scaling. With an infinite or compressed state space, the computational problem would need a new input and oracle model. Neither version supplies a complexity result from this paper to mirror. Requiring one-person pivotality instead keeps a finite market, while allowing coordinated deviations by a whole type mass changes BIC into a coalition or mass-deviation criterion.

So the negative case is strongest against a direct mirror of Theorems 1 or 3: weak BIC becomes vacuous at the atomless limit, while the variants that preserve nontriviality introduce a new computational problem rather than continuize a named one. I cannot rule out that a carefully specified strict, correlated continuum model would be worthwhile; that is where the universal negative case is weakest.
