The continuous mirror question

Given finite type sets \(P,Q\), rational masses \(\mu_p,\nu_q\) each summing to \(1\), and strict complete rankings of opposite-side types, can one compute in time polynomial in \(|P|+|Q|\) and the input bit length \(L\) a rational flow \(x_{pq}\ge 0\) with row sums \(\mu_p\), column sums \(\nu_q\), and no pair \((p,q)\) for which both positive mass of \(p\) is assigned below \(q\) and positive mass of \(q\) is assigned below \(p\)?

The model it lives in

A capacitated bipartite matching model with type sets \(P,Q\), rational masses \(\mu,\nu\), and decision variables \(x_{pq}\) giving the mass of type \(p\) matched to type \(q\). The objective is to find a feasible flow satisfying the type-level stability condition for every pair.

The objection that survived

Theorem 4’s distinctive claim concerns Scarf’s polynomial pivot path, while the stated mirror asks only for a stable flow and supplies no type-level ordinal matrix or pivot rule.

What the mirror covers

The mirror covers finding a stable matching for a typed population; it leaves Scarf’s pivot complexity and perturbation analysis, and the results on which stable matchings Scarf can represent, unmirrored.

Open questions for a prover

  • To retain the Scarf-specific contribution, what ranking-consistent ordinal matrix and cardinal pivot rule should be used on the type-capacity polytope, and does that execution have a polynomial bound in \(|P|+|Q|+L\)?
  • What precise discrete-to-continuous correspondence relates these stable flows to matchings in clone-expanded finite markets?

The case FOR (proponent)

The strongest continuous mirror I believe is Stable Mass Matching. The paper’s named complexity anchor is Theorem 4, proved in the paper: for any marriage instance on a bipartite graph, using the matching polytope and a specific ordinal matrix \(C^*\), there is a cardinal pivoting rule under which Scarf’s algorithm runs in polynomial time and returns the characteristic vector of a stable matching. The paper’s other major negative result concerns which stable matchings Scarf can represent; it is not a hardness result for the stable-matching search problem, so I would not use it as a second complexity anchor.

For the mirror, take two populations, each of total mass \(1\), with finite supports \(P\) and \(Q\). A type is a complete description of an agent for matching: in particular, all agents of a type have the same strict ranking of types on the other side. Let \(\mu_p\) and \(\nu_q\) be the rational masses of types \(p\in P\) and \(q\in Q\), and assume every type pair is acceptable. The regime could be a large annual placement market where many applicants share a qualification-and-preference profile and many positions share a job-and-preference profile: perhaps hundreds of thousands of agents, but tens or hundreds of distinct types. Each unit of mass still represents agents receiving individual partners; mass is the aggregate accounting for those pairings.

The decision variable is a nonnegative flow \(x_{pq}\): the mass of type \(p\) matched to type \(q\). It must satisfy \(\sum_q x_{pq}=\mu_p\) and \(\sum_p x_{pq}=\nu_q\). There is no welfare objective in the paper’s problem; the task is to find any stable matching. For each pair \((p,q)\), define \(R_{pq}=\mu_p-\sum_{q':q'\succeq_p q}x_{pq'}\), the mass of \(p\) assigned below \(q\), and \(S_{pq}=\nu_q-\sum_{p':p'\succeq_q p}x_{p'q}\), the mass of \(q\) assigned below \(p\). Stability requires \(R_{pq}=0\) or \(S_{pq}=0\) for every pair: there must not be positive mass on both sides who would prefer to be matched to each other. A solution is a rational flow satisfying these equalities and stability conditions.

I expect this problem to be tractable, hence Class A, with running time polynomial in the numbers of supported types and the input bit length \(L\). A finite-type deferred-acceptance procedure can pass proposed mass between types, letting each receiving type hold its highest-ranked proposals up to its capacity; there are only finitely many type pairs, and rational masses allow exact arithmetic. The further questions are whether the authors’ particular Scarf pivot rule also has a polynomial bound on the type-capacity matching polytope, and what precise discrete-to-continuous dictionary holds when rational type masses are expanded into individual agents.

This mirrors the paper’s stable-matching search, not its full study of Scarf’s reachability or its extensions to roommates, hypergraphs, and couples. The weakest point is that the paper ranks named individuals, while this mirror ranks types. That introduces indifference among people within a type and replaces unit capacities with rational masses, so it is a real typed-market extension; Theorem 4’s specific matrix and pivot analysis do not automatically transfer. Still, the underlying question—finding a stable matching in a bipartite population—is the same one the authors compute, and the type-level model is a natural high-multiplicity regime for it.

The case AGAINST (opponent, writing after the proponent)

The only anchor is Theorem 4, and the best objection is that the proposed mass-flow problem does not quite mirror it. Theorem 4 bounds the runtime of a particular Scarf pivot process on a matching polytope with one row per named agent. The proponent’s first problem is instead to find a stable type-level flow. That is a sensible continuous problem, but it changes the computational object.

There is also substantial continuous stable-matching work nearby. For example, Arnosti gives a continuum model with finite capacities whose stable outcome can be found by a deferred-acceptance analogue; Leshno studies continuum matching through supply and demand and relates its outcomes to large discrete economies ([Arnosti](https://arxiv.org/abs/2205.12881), [Leshno](https://www.microsoft.com/en-us/research/publication/a-supply-and-demand-framework-for-two-sided-matching-markets/)). These do not settle the runtime of Scarf’s algorithm on the proposed type-capacity polytope, so they are not a decisive collision. They do make “compute a stable mass matching” a weak target for this paper’s mirror.

The stronger concern is that aggregation does not preserve the object Theorem 4 analyzes. Collapsing identical agents merges rows and edge variables; a type-level flow basis is not a one-to-one image of the clone-expanded individual bases. Different numbers or orderings of identical clones can therefore yield different ordinal matrices and pivot paths for the same type masses. To ask about Scarf’s runtime after aggregation, one must define a new type-level ordinal matrix and pivot rule on a capacitated transportation polytope. That may be a worthwhile question, but Theorem 4 itself supplies no canonical way to derive it from the individual-level process.

That objection stops short of defeating the best mirror. A type-capacity Scarf question is still well-posed, and it is plausible these authors would recognize it as their problem. Identical-ranking cohorts are a convincing high-multiplicity regime, and neither fractional capacities nor a mass stability condition is inherently illegitimate. So the case against is weak at its crucial point: it challenges whether the Scarf extension is a continuation of this theorem, but cannot honestly establish that no worthwhile continuous mirror exists.
