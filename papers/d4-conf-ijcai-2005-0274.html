What the mirror covers

The proposed anchor covers Corollary 4.1's uniform-prior existence test and mechanism synthesis for anonymous functions; it leaves the paper's nonuniform-prior and general sequential-simultaneous results aside.

The case FOR (proponent)

The paper has no named hardness result, so the strongest anchor is an algorithmic one: Corollary 4.1, proved in this paper. For an anonymous binary function \(G\), independent secrets with \(q=1/2\), and agents ordered by computation cost, it says the USNO algorithm efficiently decides whether any appropriate mechanism exists and, if so, produces a semi-natural cost-ordered oblivious mechanism. Its test uses the path \(v'_0,\ldots,v'_{n-1}\) in the unresolved-state graph: set \(\Psi_i=C_{\max}(v'_i)\), and let \(t\) be the first index with \(\Psi_t>\Psi_0\). A mechanism exists exactly when \(c(0),\ldots,c(t-1)\leq\Psi_0\) and \(c(i)\leq\Psi_i\) for every \(i\geq t\). The synthesized mechanism first approaches the \(t\) cheapest agents simultaneously, then approaches the others one at a time in cost order. I would specialize this result to odd-electorate majority.

My lead mirror is Diffusive Majority Elicitation. Its continuous input is a finite set of cost types \(K=\{\kappa_1<\cdots<\kappa_\tau\}\) with rational masses \(\mu_j>0\) summing to \(1\). For each sufficiently large admissible odd \(N\), form a population of \(N\) agents, with \(N\mu_j\) agents of type \(\kappa_j\). Each agent has a fair private bit, values a correct majority result at \(1\), and pays \(\kappa_j/\sqrt N\) to compute their bit. Thus mass \(\mu_j\) means the fraction of the population in cost type \(j\); \(\tau\) stays fixed as \(N\) grows. A type includes the agent’s cost and all other shared parameters. This fits, for example, a large sensor or survey network with many devices but few computation-cost tiers.

The question is: does there exist an \(N_0\) such that every admissible odd \(N\geq N_0\) has an appropriate oblivious majority-elicitation mechanism? A yes solution supplies a family of cost-ordered batch schedules: cut the unit mass into successive intervals, query each batch simultaneously, and stop when the reports determine the majority. At each finite \(N\), the cuts must correspond to groups of agents, and the computing equilibrium must yield the correct majority for every secret vector. This asks for mechanism existence and synthesis, as in the anchor; it does not add an objective of minimizing query cost.

The \(\sqrt N\) cost scale is deliberate. At the fair prior, an agent’s initial probability of being pivotal is
\[ \Pr\!\left[\operatorname{Bin}(N-1,1/2)=\frac{N-1}{2}\right], \]
so the paper’s initial cost ceiling is
\[ \Psi_0(N)=\frac12\binom{N-1}{(N-1)/2}2^{-(N-1)} \sim \frac{1}{\sqrt{2\pi N}}. \]
The majority path’s first rise above \(\Psi_0\) occurs only \(O(\log N)\) agents from the end. The first batch therefore contains all but \(O(\log N)\) agents. In this regime the theorem’s test suggests a sharp phase boundary: away from equality, feasibility should turn on or off according to whether \(\max_j\kappa_j\) is below or above \(1/\sqrt{2\pi}\). The remaining agents form a vanishing-mass tail that still needs an explicit schedule. I expect this asymptotic problem to be tractable: the finite test reduces it to the pivotality profile along one path, with the central-binomial estimate controlling the bulk and exact finite-\(N\) values resolving the boundary.

This mirrors the paper’s actual strategic question: agents decide whether to compute private bits, free-riding matters, and the center must elicit enough information to compute majority. The population mass is over cost types, while the outcome and secrets remain binary. The authors would likely recognize the connection because the scaling comes directly from their \(C_{\max}\) condition.

The weak point is that this is a high-multiplicity *limit family* that retains finite-\(N\) pivotality while costs scale with \(N\). In a strictly atomless society, a single agent has zero mass and cannot change an oblivious mechanism’s aggregate report; positive computation costs then eliminate the incentive to compute. That literal limit is degenerate. So the proposed phase diagram is strongest as a population-continuous boundary-layer question, where the vanishing tail is still resolved, rather than as a claim that their nontrivial mechanism result survives unchanged in a purely atomless game.

The case AGAINST (opponent, writing after the proponent)

Corollary 4.1 is a real computational result, so the objection cannot be that this paper offers nothing to mirror. It efficiently decides whether an appropriate mechanism exists in the finite-agent uniform model and constructs one. The question is whether its key object survives continuization.

The difficulty is that the corollary’s incentives are built around an individual being pivotal. In a society represented by an atomless distribution, one agent has zero mass. Changing their report cannot change the aggregate outcome, so an agent with positive computation cost has no incentive to compute. For majority with fair secrets, there is an additional collapse: the continuum aggregate is exactly half 0s and half 1s, while the finite electorate’s majority is decided by fluctuations around that tie. The paper requires correctness for every secret vector, so those finite fluctuations matter. A type distribution over cost tiers does not preserve them. If the distribution instead includes the realized masses of secret types, the center already knows the majority.

The proponent’s \(\kappa/\sqrt N\) construction keeps the finite pivotality calculation alive, but it does so by retaining \(N\), finite agents, and exact finite-\(N\) reports. The final \(O(\log N)\) agents have vanishing mass yet can remain pivotal; representing them as individuals preserves the finite model, while replacing them with mass removes their individual incentives. The \(\sqrt N\) normalization matches the finite pivotality scale, but it does not give an atomless agent positive influence. The proposed eventual-\(N\) test is therefore a finite-population asymptotic question, not a mechanism problem on a continuous society. Its main phase boundary already follows from the corollary’s pivotality formula.

A richer model could treat positive-mass cohorts as coordinated strategic actors, or study a stochastic fluctuation limit. Either could be interesting, but each changes the strategic unit or makes the fluctuation process central. I would not count them as continuizations of this paper’s individual free-riding problem. The negative case is strongest for the paper’s actual mechanism question: its essential unit is an individually pivotal agent, and that unit disappears in the continuous population. I cannot rule out a worthwhile related model, but the proposed cost-type mirror does not establish one.
