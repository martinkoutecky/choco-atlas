The strongest plausible mirror would model a large cohort with finitely many preference types and item or school classes, scaling supplies with population. A mass-allocation matrix could then describe the assignment and its welfare. That is a sensible high-multiplicity model, but the static flow formulation would ask about aggregate assignments, not the proposal algorithms this paper introduces. To preserve those algorithms, a model must also specify the order of proposals, rejection queues or stacks, memory resets, and TTC cycles. Preference-type masses alone do not specify those paths. Adding priority as part of each type risks making the number of types grow with population; defining a continuum priority process instead requires a new scheduling model. Either route may support a worthwhile project, but neither is a complexity question anchored in this paper’s results.

The stronger, supportable conclusion is narrower: the paper gives no named computational result for a continuous mirror to anchor, and its main contributions do not by themselves establish a continuous computational question worth prioritizing.
