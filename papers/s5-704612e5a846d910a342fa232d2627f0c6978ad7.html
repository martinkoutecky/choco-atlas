The continuous mirror question

Given rational valuation types \(v_\ell\in\mathbb Q_{\ge0}^{2}\) with masses \(\mu_\ell\in\mathbb Q_{\ge0}\), \(\sum_\ell\mu_\ell=1\), and rational per-capita supplies \(q_1,q_2\ge0\), find finite-support \(y_{\ell,b}\ge0\), \(b\in\mathbb Z_{\ge0}^{2}\), satisfying \(\sum_b y_{\ell,b}=\mu_\ell\) and \(\sum_{\ell,b}b_a y_{\ell,b}=q_a\), such that \(y_{\ell,b}y_{\ell',b'}>0\) and \(b'_a>0\) imply \(v_\ell\cdot b\ge v_\ell\cdot(b'-e_a)\); or report infeasibility.

The model it lives in

A high-multiplicity two-item allocation model with valuation types \(\ell\) carrying masses \(\mu_\ell\), per-capita supplies \(q_a\), and variables \(y_{\ell,b}\) assigning each agent an integral bundle \(b\in\mathbb Z_{\ge0}^{2}\); the objective is to construct a complete support-wise EFX assignment.

The objection that survived

The proposed output is a finite-support distribution over unbounded integral bundles, and no polynomial-size encoding or algorithm in \((\tau,L)\) is supplied; Theorem 19 only guarantees polynomial time in expanded \(n\) and \(m\).

The case FOR (proponent)

My strongest mirror is the paper’s constructive EFX result for two item types, rather than its threshold theorem for EF.

The anchor is Theorem 19, proved in this paper. It states that, for arbitrary \(n\) agents with additive valuations and a multiset containing two item types, Algorithm \(\cref{alg:tequals2}\) returns a complete EFX allocation. EFX means that for every pair of agents, removing any one item from the second agent’s bundle eliminates the first agent’s envy. The algorithm first gives agents their preferred type in complete rounds; gives the remaining items of the scarce type to agents with largest ratio \(v_i(1)/v_i(2)\); then distributes the other type in rounds, stopping when the selected agents would envy someone; finally it distributes any remainder, beginning with those selected agents. The paper proves correctness and then observes that the algorithm runs in polynomial time in \(n\) and \(m\), using sorting, per-item assignments, and envy-graph updates. This is a result proved here, not imported from another paper.

I would call the continuous problem \(\mathrm{Complete\text{-}EFX}^{(2)}_\infty\).

An instance consists of finitely many valuation types \(\ell\in[\tau]\), where type \(\ell\) has an additive valuation \(v_\ell=(v_\ell(1),v_\ell(2))\), normalized up to positive scaling, and has population mass \(\mu_\ell\ge0\), with \(\sum_\ell\mu_\ell=1\). The society therefore has \(\tau\) distinct valuation types but nonatomic total population one. It also has per-capita supplies \(q_1,q_2\ge0\) of the two item types. For computational purposes, take all data to be rational.

The action is a finite-support assignment \(y_{\ell,b}\ge0\), where \(b=(b_1,b_2)\in\mathbb Z_{\ge0}^2\) is an indivisible bundle and \(y_{\ell,b}\) is the mass of valuation type \(\ell\) receiving bundle \(b\). It must satisfy \(\sum_b y_{\ell,b}=\mu_\ell\) for every \(\ell\), and \(\sum_{\ell,b}b_a y_{\ell,b}=q_a\) for \(a\in\{1,2\}\). Thus every individual receives an integral bundle; only the distribution of bundles across the population is fractional.

The assignment is EFX if, whenever \(y_{\ell,b}>0\) and \(y_{\ell',b'}>0\), then for every item type \(a\) with \(b'_a>0\), \(v_\ell\cdot b\ge v_\ell\cdot(b'-e_a)\). The problem is to find such a complete assignment, or report that none exists. Equivalently, one could minimize unallocated item mass and ask whether the optimum is zero.

This is a genuine population continuization. The many agents are, for example, a large workforce receiving two kinds of surplus produce, with only finitely many recurring preference profiles. The regime is \(N\gg\tau\): as \(N\) grows, \(n_\ell/N\) approaches \(\mu_\ell\), while the number of item types remains two and \(m_a/N\) approaches \(q_a\). This is especially plausible here because the paper itself uses surplus produce and employees as its motivating multiset example. A valuation type is not merely “an agent who likes apples”; it is the complete normalized marginal-value vector, so agents of one type are indistinguishable for the fairness problem.

The mirror preserves the paper’s central difficulty. Items remain indivisible, allocation remains complete, and EFX is still an individual-level comparison against every other bundle. A fractional average bundle is not handed to anyone. The fractional quantities \(q_a\) and \(y_{\ell,b}\) describe aggregate mass, exactly as a high-multiplicity formulation should.

For rational data, Theorem 19 immediately gives existence. Choose a common denominator \(N\) so that \(N\mu_\ell=n_\ell\) and \(Nq_a=m_a\) are integers. Run the paper’s finite algorithm on \(n_\ell\) agents of valuation \(v_\ell\) and \(m_a\) items of type \(a\). Counting how many agents of each valuation type receive each bundle gives a feasible \(y\). Conversely, any solution whose masses have denominator \(N\) expands to a finite allocation. So this is not an arbitrary divisible-goods relaxation: it is precisely the high-multiplicity limit of the paper’s allocation problem.

I would expect this continuous problem to be Class A. The finite theorem already establishes universal feasibility for two item types. More importantly, the proof has exactly the structure one would want for a type-compressed algorithm: classify agents by their preferred item, sort them by the ratio \(v_\ell(1)/v_\ell(2)\), and replace individual prefixes and rounds by cumulative mass intervals and boundary splits. The nonatomic population makes it possible to split a valuation type at a boundary while still giving every individual an integral bundle. This suggests an algorithm polynomial in \(\tau\) and the encoding length of the rational data, rather than in the denominator \(N\).

That last compression claim is not proved by Theorem 19 itself. Its stated runtime is polynomial in \(n\) and \(m\), so naïvely lifting a rational continuous instance may be exponentially expensive in the bit length of its denominator. The continuous mirror therefore asks a new computational question: can the ratio-ordering algorithm be compressed to valuation types and masses? This is precisely the sort of distinction the programme cares about.

The mirror covers Theorem 19, and indirectly the paper’s \(t=2\) EFX result. It does not claim to cover the EF threshold theorems, the \(t\ge3\) setting, or the geometric counterexample to one particular proof strategy. Those generate useful follow-up questions: whether a type-compressed algorithm exists with support bounded by \(O(\tau)\); whether continuous EFX remains feasible for \(t\ge3\); and whether the paper’s cited NP-completeness of finite EF existence disappears under population continuization. That NP-completeness is mentioned only as related work, not as a numbered hardness theorem proved in this paper, so I would not use it as an anchor.

My weakest point is therefore computational rather than semantic. Existence transfers cleanly from Theorem 19, but a genuinely polynomial algorithm in the continuous input size still needs to be designed and proved. The opposing analyst could also argue that requiring support-wise EFX over integral bundles makes the continuous problem less smooth than a standard LP. Even so, the mirror remains faithful: it continuizes the population, keeps the goods indivisible, preserves the exact EFX question, and places the paper’s polynomial finite result inside a new high-multiplicity complexity regime.

The case AGAINST (opponent, writing after the proponent)

The strongest objection is that this is a thin mirror. After clearing denominators \(N\), the proposed instance becomes exactly a finite instance with \(n_\ell=N\mu_\ell\) agents and \(m_a=Nq_a\) items. Theorem 19 already guarantees feasibility. Thus the continuous decision problem is universally affirmative; the remaining question is only whether the finite algorithm can be compressed from dependence on \(n\) and \(m\) to dependence on \(\tau\) and the input bit length.

For \(t=2\), that compression appears especially close to bookkeeping. The algorithm has a constant number of phases: sort valuation types by \(v_\ell(1)/v_\ell(2)\), split at a few cumulative-mass boundaries, and determine round counts using floors and linear inequalities. It does not seem to expose a new pricing problem or a population-specific obstruction. If the programme demands a genuinely new computational landscape, this anchor is scientifically modest.

That is not, however, a valid decisive objection under the programme’s rules. The finite runtime is polynomial in the expanded quantities \(n\) and \(m\), not necessarily in their binary encodings. A polynomial-time algorithm in \((\tau,L)\), together with a polynomial-support configuration assignment, is a real high-multiplicity question. The mirror also keeps every bundle integral; only the population distribution over bundles is fractional. Hence it does not continuize the outcome space.

The other standard objections fail as well. The farm-and-employees regime is explicitly a plausible high-multiplicity setting; additive EFX depends on an agent only through their valuation, so identity is irrelevant; and per-capita supply scaling is an allowed co-modification. Existing finite EFX or high-multiplicity work would support rather than collide with this mirror.

Accordingly, I cannot honestly defeat this anchor. The negative case is that it is probably a compact restatement with limited payoff, not that it is ill-posed. The proponent’s mirror survives, so a universal “no worthwhile mirror” verdict is not defensible.
