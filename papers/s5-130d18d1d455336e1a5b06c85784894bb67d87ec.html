What the mirror covers

The proposed extension covers fixed-\(K\) Peer Rank score and ranking updates; it leaves out Elo, Peer Discussion, and the empirical alignment and bias results.

The case FOR (proponent)

The paper has no admissible named anchor under your rule. It contains no numbered Theorem, Lemma, Corollary, or Proposition classifying a problem as tractable or hard. Appendix A gives an unnumbered convergence argument for Peer Rank, and the Limitations section says the PR procedure takes \(O(N^3)\) in the number of models. Neither is a numbered complexity result. The accuracy and ranking tables report experiments, not complexity classifications.

The strongest plausible mirror is therefore an unanchored extension of Peer Rank, not a result-backed case. Imagine a benchmarking service running many evaluator instances drawn from a small set of fixed configurations: the same model version, prompt, decoding settings, and complete pattern of judgments on a fixed benchmark. A type \(t\) is one such complete reviewer-and-contestant profile; its mass \(\mu_t\) is its share of the evaluator pool. The intended regime has many evaluation runs but relatively few distinct profiles. Contestant systems and benchmark questions remain finite.

A precise question for that extension is \(K\)-Round Continuous Peer Rank. Its input is a finite contestant set \(C\), question set \(Q\), supported reviewer types \(T\) with rational masses \(\mu_t\), each type’s pairwise judgments \(K_t(q,i,j)\in\{-1,0,1\}\), and a fixed number \(K\) of rounds. Each type is associated with its contestant profile \(\rho(t)\), as in the paper’s setting where models both review and compete. Compute the exact score vector and induced ranking after \(K\) rounds of the PR weight update, treating each type’s mass as the combined weight of its copies. The state is the vector of reviewer-type weights; there is no optimization objective. Assuming the paper’s min–max normalization is defined at each round, this finite-round version should be tractable in \(|Q|\), \(|C|\), \(\tau=|T|\), and the input bit length for fixed \(K\). Questions about convergence to a limiting ranking, its rate, and winner robustness under changes to \(\mu\) would follow.

This is a plausible population mirror of PR: it keeps the peer judgments, peer-derived weights, and global ranking, while making the evaluator population the continuous object. A large benchmark operation that repeatedly deploys a few stable evaluator configurations is a more credible high-multiplicity setting than the paper’s small collection of individually named LLMs. Peer Discussion is a weaker fit: its central object is a finite, turn-based exchange between two reviewers.

The weakest point is also decisive for the requested anchoring: the paper does not prove a complexity result for this problem, or for a continuous version. Moreover, Appendix A’s convergence argument uses a linear eigenvector update, while the main PR procedure updates weights using min–max normalization. I would not use that appendix claim to assert convergence of the continuous mirror. So the positive case is that a sensible continuous PR question can be formulated and the authors could recognize its connection to their method; under the anchor requirement, this paper supplies no qualifying result to mirror.

The case AGAINST (opponent, writing after the proponent)

The strongest objection is that the paper offers no named computational result to mirror. Its experiments measure agreement with human judgments; the \(O(N^3)\) statement is a scalability observation about the number of reviews, not a complexity result for a decision, search, or optimization problem. Appendix A’s convergence argument does not fill that gap: it studies a linear update, while the main Peer Rank procedure uses min–max rescaling and normalization. It therefore does not establish a result about the stated algorithm, much less a computational result.

The proposed \(K\)-round continuous Peer Rank is a coherent extension, but it does not uncover the kind of computational problem ChoCo is designed to chart. With an explicit table of pairwise judgments, each round aggregates those judgments by mass and applies the update. For fixed \(K\), this is direct arithmetic over the supported types and contestant pairs; there is no implicit exponential domain or pricing problem. The discrete procedure is already computable by the same aggregation after identical reviewer profiles are grouped. Continuization changes the representation and can reduce bookkeeping, but it supplies no new algorithmic question anchored in a result of this paper.

The evaluator-fleet scenario is plausible at first glance, but it strains the meaning of the population. If a type is a complete realized judgment profile across the benchmark, repeated copies must agree on all those judgments; stochastic LLM calls will often produce many distinct profiles. If instead a type is a model-and-prompt configuration with expected judgments, its “mass” describes how much evaluation budget that configuration receives. Peer Rank then ranks systems partly according to deployment prevalence. That could be a worthwhile question about benchmark design, but it changes what the ranking measures. Keeping system rankings independent of prevalence requires a further modeling choice that the paper neither makes nor motivates.

A stronger proposal might fix the contestant systems, let reviewer mass vary, and ask which mass transfers can change the winner. That is a legitimate new intervention problem. But the paper supplies no reviewer costs, admissible transfers, or complexity result for such interventions; those would have to be added to create the problem. The same is true of robustness to changes in the reviewer mixture. These are possible extensions of Peer Rank, not continuous mirrors of a computational contribution in this paper.

Peer Discussion does not provide a better anchor. Its unit is an ordered exchange between two named reviewer systems over a fixed number of turns. A population model could randomize which types meet and aggregate the outcomes, but for a fixed protocol and supplied type-pair outcomes that is again finite aggregation. Studying evolving opinions or large-scale interaction dynamics would move toward analytic mean-field work, rather than expose a missing computational question in this paper.

I cannot make the universal claim airtight: a benchmark service that deliberately allocates influence by reviewer-family share could motivate continuous robustness or control questions. The negative case is weaker there. But this paper’s core contribution is an empirical evaluation protocol, not a computational result about a population. Its most natural continuous extension either compresses the existing finite calculation or adds a new intervention problem whose population semantics and costs come from elsewhere. That makes it a poor target for the continuization programme, even though related future work is possible.
