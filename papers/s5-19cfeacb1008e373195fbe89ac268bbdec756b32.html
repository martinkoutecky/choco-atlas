What the mirror covers

The unanchored mirror covers only SDM1 winner selection by top-rank divergence; it leaves the axiomatic results, scoring-vector characterization, and whole-matrix welfare-function discussion without a computational mirror.

The case FOR (proponent)

I can’t build a qualifying anchored case from this paper: it contains no numbered result asserting that a computational problem is in P, NP-hard, FPT, or otherwise classifying its complexity. Proposition 3.2 proves anonymity and neutrality; Proposition 3.5 proves consistency and *continuity* for SDM1, where continuity means that sufficiently many copies of one finite profile can sway the outcome. Neither is a computational-complexity result. Lemma 1.4 establishes additivity of divergence. So there are no eligible anchors, and no per-anchor continuous problems to state.

The strongest plausible mirror, though, is an unanchored one: given candidates \(C\), a support \(T\) of strict rankings, and rational masses \(\mu_t\ge 0\) summing to \(1\), with fixed \(p=2\), return the unique minimizer, if one exists, of
\[ D_\mu(c)=\sum_{t\in T}\mu_t\bigl(\operatorname{rank}_t(c)-1\bigr)^2. \]
This is SDM1 applied to a continuous population: the mass of each ranking type replaces its number of occurrences in a finite profile. A plausible regime is a large electorate with millions of voters but relatively few distinct ballots. The paper’s multiset profiles and Lemma 1.4 make this extension natural, and the authors would likely recognize it as their compromise-winner rule over type masses.

That problem is directly computable in polynomial time by evaluating the score for each candidate, in \(O(m\tau)\) arithmetic operations. But this is an obvious extension of a score calculation, not a named result of the paper, and it does not show that continuization dissolves any discrete hardness. It covers only SDM1 winner selection; Proposition 3.5’s “continuity” is an axiom about finite profile replication, not a result about continuum populations.

The case AGAINST (opponent, writing after the proponent)

The strongest negative case starts with the lack of an eligible anchor. This paper gives no computational complexity result: Proposition 3.5’s “continuity” is an axiom about how an outcome changes when finite profiles are replicated, not a result about continuum populations or algorithms. The substantive result is that SDM1 is a scoring rule, alongside axiomatic analysis of the rule. So there is no named computational problem here whose complexity a population mirror could clarify.

The proposed SDM1 mirror is nevertheless natural. The paper treats profiles as multisets, and its additivity lemma makes replacing ballot counts with type masses a sensible extension. For fixed \(p=2\), compute each candidate’s divergence from the top position and select the minimum; this takes \(O(m\tau)\) arithmetic operations and polynomial time in the input bit length. That is a valid continuous-population formulation, but computationally it is just evaluating an additive score. Grouping identical ballots compresses the familiar finite computation; it does not expose a new algorithmic question.

The strongest internal extension is to use the whole divergence matrix to choose an outcome ranking: set \(d_\mu(c,j)=\sum_t\mu_t|\operatorname{rank}_t(c)-j|^2\), then find the permutation \(\pi\) minimizing \(\sum_c d_\mu(c,\pi(c))\). This respects the paper’s interest in all positions and avoids its failed greedy construction. But it supplies a new objective the paper does not define, and the resulting problem is a standard assignment problem: build the costs in \(O(m^2\tau)\) operations, then solve the assignment in polynomial time. It offers a useful rule-design exercise, not a compelling complexity frontier.

I would not argue that high multiplicity is implausible here, or that an existing high-multiplicity result counts as a collision. The population model is sensible; the weakness is that the paper studies rule properties rather than computational difficulty. One could create more demanding questions about changing the winner through mass transfers, but those add an intervention problem absent from the paper and would be new work rather than a mirror of its results. So the negative case is strong that this is a poor target for ChoCo’s complexity programme, but weak as a universal claim that no worthwhile continuous-population question can be built from it.
