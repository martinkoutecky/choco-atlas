The continuous mirror question

Given a finite type set \(T\), posts \(P\), rational masses \(\mu_t\) summing to \(1\), weak rankings and eligibility by type, and type-symmetric post rank functions \(\rho_p\), decide whether there is a measurable assignment \(f\) giving each individual one eligible post such that, for every feasible assignment \(g\), \(V(f,g)\geq V(g,f)\); return such an \(f\) if one exists. Feasibility requires \(\sum_{t\in S}x_{t,p}\leq\rho_p(S)\) for each post \(p\) and \(S\subseteq T\), where \(x_{t,p}\) is the mass of type \(t\) assigned to \(p\).

The model it lives in

A nonatomic population partitioned into types with masses \(\mu_t\), where each type has a fixed weak ranking and eligibility set. Aggregate type-to-post masses \(x_{t,p}\) obey type-symmetric matroid-rank constraints; comparisons between assignments use the mass of the same individuals who strictly prefer one post to the other. The task is deciding existence and returning a popular assignment, with no optimization objective.

What the mirror covers

The mirror covers the existence-and-search task in Theorem 23. It leaves arbitrary edge-specific post matroids outside its scope and treats Theorem 9’s discrete characterization as motivation, not as a result already proved for the continuum.

Open questions for a prover

  • Which type-level rank functions give a faithful, replication-consistent matroid model on individual applicants?
  • Does the paper’s popularity characterization extend to fractional type masses, and what oracle or input assumptions would support an efficient algorithm?
  • Which finite replica instances correspond exactly to popular assignments in the continuum?

The case FOR (proponent)

The strongest mirror I believe is a high-multiplicity version of the paper’s own popular matching problem, with post constraints restricted to ones that respect applicant types. Call it Popular Matching with Ties and Type-Symmetric Matroid Constraints\(_\infty\).

Its anchor is Theorem 23, proved in this paper: Algorithm PMTM correctly decides whether a popular matching exists in the finite problem with ties and post matroid constraints, and returns one if it exists. The paper’s following running-time analysis gives \(O(m^3 E_O)\), where \(m=|E|\) and \(E_O\) is the time for a matroid independence query. Thus it is polynomial when those queries are polynomial-time. The paper proves this result here. It states no numbered hardness result to use as an alternative anchor.

Here is the continuous problem. The input has a finite set \(T\) of applicant types, rational masses \(\mu_t\) summing to \(1\), and a finite set \(P\) of posts. A type fully specifies an applicant’s weak ranking over eligible posts, including a last-resort post, and the applicant’s role in the post constraints. Represent the society by measurable populations \(I_t\), with \(\lvert I_t\rvert=\mu_t\). Each person receives one post. For each post \(p\), give a rational, normalized matroid rank function \(\rho_p\) on the types: it describes the per-capita rank available to groups of type classes at that post. An assignment \(f\) is feasible if, for every \(p\) and \(S\subseteq T\),
\[ \sum_{t\in S} x_{t,p}\leq \rho_p(S), \qquad x_{t,p}=\lvert\{i\in I_t:f(i)=p\}\rvert, \]
and ineligible type–post assignments have zero mass. The rank functions are chosen so that, when populations are replicated by a common factor, the corresponding integer rank constraints define matroids on the individual applicant copies. Thus the constraints are the continuous, type-symmetric form of the paper’s post matroids.

For feasible assignments \(f,g\), let \(V(f,g)\) be the mass of people who strictly prefer their assignment under \(f\) to their assignment under \(g\). An assignment is popular if \(V(f,g)\geq V(g,f)\) for every feasible \(g\). The problem is to decide whether such an assignment exists and return a measurable assignment if it does. This is a search problem, not an optimization problem: popularity is the no-majority-defeat condition, and the solution gives each unit of mass an integral post. Fractional values occur in the aggregate type assignments, as they should when each individual still receives one post.

A plausible regime is a large annual placement round—say, hospital residency placements—with many applicants but a modest number of repeated preference and credential profiles. A type includes the profile’s post eligibility and its class in the post constraints, so people grouped together are indistinguishable for everything this problem uses. Post quotas or matroid ranks scale with cohort size. In a finite cohort of \(n\) people, type \(t\) has \(n\mu_t\) copies; assignments constant on chunks of mass \(1/n\) reproduce the finite matching and its vote counts. The continuous problem admits finer partitions as well. If individual preferences or constraint roles are mostly unique, then the support grows toward the number of applicants and the intended compression disappears.

The paper’s Theorem 9, proved here, helps make a tractability conjecture credible: a matching is popular exactly when its top-choice edges form a maximum-size common independent set of the two restricted matroids and the matching lies within the paper’s further permitted edge set \(\Pi\). This is the structure PMTM uses, rather than checking every challenger matching individually. In the type-symmetric mirror, the natural expectation is Class A: an analogous characterization might lead to finite-dimensional polymatroid or LP computations on types and posts. That is a conjecture about the mirror, not a consequence already established by Theorem 23. Further questions include whether the characterization survives fractional masses, what rank-oracle assumptions suffice, and which finite replica instances exactly correspond to the continuous solution.

The scope is deliberately just the paper’s popular matching problem with ties and matroid constraints, represented by Theorem 23. The weakest point is that the paper’s theorem runs on an explicit applicant-edge ground set; its \(m\) can grow with the population. It does not itself give an algorithm polynomial in support size, nor does it handle the identity and coupling of people in a nonatomic population. The proposed mirror addresses those issues by requiring type-symmetric matroids and defining popularity over measurable assignments to the same people. That is a substantive, recognizable high-multiplicity version of the authors’ problem, but extending their characterization to it remains the research question.

The case AGAINST (opponent, writing after the proponent)

The strongest case against is that the proposed mirror is much narrower than Theorem 23. The paper allows arbitrary post matroids on applicant–post edges. To keep the number of types small as the population grows, the constraints must treat repeated applicants symmetrically; the proposed type-rank constraints make that a polymatroid or quota-style model. In a general matroid, two applicants with the same preferences may still have different roles in its circuits. Encoding those differences in their types can make the support grow with the population, removing the hoped-for compression.

The theorem’s running time, \(O(m^3 E_O)\), is polynomial in the explicit edge set and the cost of matroid independence queries. It does not give an algorithm polynomial in the number of types or the bit length of their masses. Nor does Theorem 9 directly supply one: its characterization uses maximum common independent sets and exchange structure on the discrete edge ground set. In the continuous model, aggregate assignment masses alone also do not determine who prefers one assignment to another; a faithful type-level analysis must track flows from each current post to each new post. That is manageable in principle, but it is new work, not a consequence of the paper’s characterization.

These points make the tractability conjecture less secure than the proponent suggests. They do not defeat the mirror. An annual placement round with repeated preference and credential profiles and scaled diversity constraints is a plausible high-multiplicity regime, and the programme explicitly allows the constraint role to be part of a type. The measurable-population model can also preserve the same-person comparisons by tracking those post-to-post flows. The nearest newer matroid-popularity work I found still formulates a finite ground-set problem with matroid independence oracles; it does not resolve this continuous-population question ([Popular Maximum-Utility Matchings with Matroid Constraints](https://arxiv.org/abs/2407.09798)).

So the negative case is weak. Theorem 23 is a genuine computational anchor, and there is a credible type-symmetric version worth studying. The honest objection is that the paper’s general matroid model does not itself provide the needed high-multiplicity compression—not that no worthwhile continuous mirror exists.
