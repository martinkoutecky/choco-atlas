The case FOR (proponent)

The strongest positive hook is the paper’s public-goods setting. A municipality could have many residents but relatively few preference types: residents with the same relevant circumstances share a complete ranking over facility allocations. A continuous society would assign each ranking \(P\) a mass \(\mu_P\), and a rule would choose an allocation of facilities to sites from that distribution. This is a credible high-multiplicity regime for the paper’s subject.

The anchor requirement rules out a defensible computational mirror, however. Theorem 1, proved in this paper, says that for a rich domain \(D\), \(D\) is a decomposable domain if and only if it is a multidimensional hybrid domain. That is a structural characterization of strategy-proof rules, not a result about an algorithm’s complexity. The paper contains no named result asserting tractability, hardness, or another computational-complexity classification.

The nearest proposed mirror would ask whether strategy-proof rules from preference distributions to allocations decompose into component rules. That would continuize an axiomatic characterization—the programme’s stated out-of-scope case. In a nonatomic population, a single resident’s report also leaves \(\mu\) unchanged, making individual strategy-proofness vacuous. Requiring positive-mass groups to manipulate instead would change the paper’s strategic question.

So the public-goods scenario makes continuous mass natural, but this paper supplies no eligible computational anchor. A precise computational problem per anchor would have to be invented rather than mirrored.

The case AGAINST (opponent, writing after the proponent)

The decisive objection is that the paper gives no computational result to continuize. Its strongest candidate is Theorem 1, but that theorem characterizes which preference domains make strategy-proof rules decomposable. It gives no algorithmic problem, complexity bound, or optimization task.

The public-goods setting is a credible high-multiplicity regime: many residents could share the same ranking over facility allocations. But a distribution \(\mu\) over those rankings does not make Theorem 1 computational. The theorem’s conditions concern the domain \(D\)—its richness, induced marginal domains, and hybrid structure—not the frequency of each preference in a particular society. Replacing voter profiles with masses would turn the result into an axiomatic characterization over distributions, which is outside ChoCo’s computational scope.

A stronger computational proposal still lacks an anchor in the paper. Evaluating a specified component rule on a distribution would be a new task; searching among rules needs an objective or additional constraints that the paper does not supply. Optimizing welfare, for example, would require adding a welfare criterion and likely cardinal information absent from the model.

There is also a mismatch in strategy-proofness. If the continuous society is represented only by \(\mu\), one resident’s report has measure zero and cannot change the outcome, so unilateral strategy-proofness becomes vacuous. Treating a positive-mass group’s deviation as the relevant manipulation changes the strategic question. Keeping named individuals in the mechanism may restore individual incentives, but then the distribution alone no longer captures the information the rule uses.

So the positive case establishes that a continuous population is plausible for the paper’s setting; it does not identify a worthwhile computational mirror of any result in the paper. I cannot rule out a useful algorithmic project built from this environment, but it would need to add a computational question the authors did not study.
