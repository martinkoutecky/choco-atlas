The continuous mirror question

Given candidates \(C\), committee size \(k\), and a rational mass distribution \(\mu\) over approval types \(t\subseteq C\), find \(W\subseteq C\) with \(|W|=k\) containing an affordable \(R\subseteq W\) of maximum cardinality, with witness payments \(x_{t,c}\ge0\) satisfying \(x_{t,c}=0\) when \(c\notin t\), \(\sum_{c\in C}x_{t,c}\le k\mu_t\), and \(\sum_t x_{t,c}=1\) for \(c\in R\) and \(0\) otherwise.

The model it lives in

Approval types \(t\subseteq C\) carry mass \(\mu_t\); aggregate payments \(x_{t,c}\) are divisible, each type has budget \(k\mu_t\), each selected candidate requires one unit, and the objective is to maximize \(|R|\) before completing to an integral \(k\)-committee \(W\).

What the mirror covers

The mirror covers MCAR’s affordability objective and Theorem 6.3’s computational hardness; it leaves the paper’s MPR results, fractional GRP results, tractability results, and strategic-candidacy results unmirrored.

Open questions for a prover

  • Is continuous MCAR NP-complete for rational \(\mu\) under a standard binary encoding, rather than merely NP-hard?
  • Does the paper’s PJR+-resignation recovery theorem extend exactly to continuous MCAR, and what parameterized algorithms remain?

The case FOR (proponent)

The strongest positive case is a high-multiplicity version of the paper’s Maximum-Cardinality Affordable Rule (MCAR). This is not a cosmetic replacement of \(n\) by a real number: MCAR is already defined entirely through aggregate voter budgets and candidate funding, so its natural input is a distribution of approval types.

Let \(C\) be the candidates and \(k\) the committee size. A voter type is an approval set \(t\subseteq C\), and the society is a rational distribution \(\mu=(\mu_t)\) over such types. Here \(\mu_t\) is the fraction of the electorate with approval set \(t\). The regime is a large electorate—say a parliamentary or participatory-budgeting election with millions of voters—but only \(\tau\) distinct approval types, with \(\tau\ll n\). Party blocs, institutional constituencies, or recurring approval patterns provide plausible examples.

The aggregate payment variable is \(x_{t,c}\ge 0\), the total payment made by type \(t\) to candidate \(c\). It must satisfy

\[ x_{t,c}=0\quad\text{if }c\notin t, \qquad \sum_{c\in C}x_{t,c}\le k\mu_t. \]

Thus a unit of population has budget \(k\), because a finite voter has budget \(k/n\). A set \(R\subseteq C\) is continuously affordable if

\[ \sum_t x_{t,c}=1\quad(c\in R), \qquad \sum_t x_{t,c}=0\quad(c\notin R). \]

The candidates remain indivisible: every candidate in \(R\) must be funded to the full unit, while voter mass may be divided among approved candidates. Define the Continuous MCAR problem as follows: given \((C,k,\mu)\), find a committee \(W\subseteq C\) with \(|W|=k\) that contains an affordable set \(R\) of maximum possible cardinality. The solution is the committee \(W\), together with the payment flow witnessing the affordability of \(R\).

This is exactly the paper’s question in the high-multiplicity regime. If a finite profile has \(n_t\) voters of type \(t\), set \(\mu_t=n_t/n\). Summing the original budgets \(k/n\) over those voters gives \(k\mu_t\), so the finite and continuous affordability systems are equivalent. Conversely, any aggregate payment can be distributed among the identical voters of a type. Replicating every voter \(r\) times leaves \(\mu\) unchanged, which is precisely the high-multiplicity interpretation.

My lead anchor is Theorem 6.3, proved in this paper: unless \(P=NP\), there is no polynomial-time algorithm that finds a committee selected by MCAR. MCAR selects committees containing a maximum-cardinality affordable set, and the proof establishes hardness by reducing from the paper’s fixed-threshold payment problem, itself obtained from X3C. This is a genuine computational anchor, not a literature summary.

The same reduction transfers directly to Continuous MCAR. Given an X3C instance with universe \(X\), \(|X|=3q\), create one candidate for each three-set, set \(k=q\), and give each element \(x\in X\) a type approving exactly the candidates corresponding to sets containing \(x\), with mass \(1/(3q)\). Each type has total budget \(1/3\). An affordable set of \(q\) candidates exists exactly when the corresponding \(q\) three-sets form an exact cover: all \(q\) candidates require total payment \(q\), exhausting the entire population budget, and each selected three-set must therefore receive \(1/3\) from each of its three element types. Hence the continuous problem is NP-hard, and an MCAR algorithm would decide X3C by checking whether its output committee is affordable. The expected classification is therefore Class B: hardness transfers. The combinatorics live in the candidate–approval incidence structure and integral full funding, not in the number of named voters.

The authors should recognise this as their problem rather than a tractability-motivated simplification. The objective is still “maximize the number of candidates that can be fully funded”; the committee is still integral; the same equal-share budget \(k/n\) is merely expressed per unit of population; and the same affordability certificate and flow network are used. It also preserves the paper’s surrounding resignation question: after candidates in \(T\subseteq W\) resign, one can ask whether a replacement committee containing \(W\setminus T\) can again contain a maximum-cardinality affordable set and satisfy PJR+. The flow and restriction arguments suggest that the paper’s relaxed resignation result should extend naturally to mass distributions.

The scope is deliberately narrow. This mirrors MCAR’s computational core and its affordability-based resignation mechanism, not every result about PAV, MES, fractional committees, or strategic candidacy.

The weakest point is that this is a clean high-multiplicity lift rather than a case where continuity makes the problem easier. If one demanded an atomless model with genuinely new continuum-specific phenomena, this mirror would look modest: rational mass profiles can encode finite elections exactly. But that is still a legitimate ChoCo outcome. The programme explicitly treats transferred hardness as a Class B result, and this paper supplies a particularly natural example where large repeated populations do not dissolve the underlying committee-selection difficulty.

The case AGAINST (opponent, writing after the proponent)

I cannot make a credible universal negative case here. The MCAR anchor survives.

Theorem 6.3 is exactly the kind of named computational result the programme seeks to mirror: MCAR is NP-hard to compute, with a reduction whose combinatorics lie in the candidate–approval incidence structure. Grouping voters by identical approval sets is legitimate high multiplicity, not an alteration of the problem. For a type \(t\) of mass \(\mu_t\), the aggregate budget \(k\mu_t\) is precisely the sum of the original \(k/n\) budgets of its members. Candidate funding remains integral, while payments may be split across mass, exactly as the programme permits.

The X3C reduction transfers without change. Give each element type mass \(1/(3q)\), let \(k=q\), and create one candidate per three-set. Each type has budget \(1/3\). Funding \(q\) candidates requires total payment \(q\), exhausting the entire population budget. Since every candidate has three supporting element types, the selected candidates can all be funded exactly when their corresponding sets form an exact cover. Thus Continuous MCAR is NP-hard, and an algorithm for it would decide X3C. This is a genuine Class B result, not an objectionable dependence on named voter identities.

The better versions of the mirror do not help the negative case. Allowing an atomless society changes nothing, because with finitely many candidates every approval profile aggregates into finitely many approval types. Allowing arbitrary rational masses only enlarges the natural high-multiplicity input class. Conversely, fixing the number of types would merely impose a parameter restriction; it would not show that the continuous-population question is misguided. The objective also does not depend on individual identity: it asks which candidates can be fully funded, and the paper’s own payment formulation already treats voters only through aggregate budgets and approval incidence.

The resignation component reinforces rather than weakens the mirror. MCAR’s recovery proof uses restriction and extension of payment systems and maximal affordability, all aggregate flow arguments. Those operations have direct mass-distribution counterparts. Even if one found that the continuous version had exactly the same complexity as the finite one, that would be a Class B conclusion, not a failure: the programme explicitly counts transferred hardness as a worthwhile outcome.

The only honest criticism is that this mirror is unlikely to produce a population-driven tractability gain; rational continuous instances can encode finite elections exactly. But the programme does not require continuity to help, and “the answer is unchanged” or “the hardness lives in the candidates” is expressly not a valid objection. Consequently, this anchor cannot be defeated, and the universal negative case fails.
