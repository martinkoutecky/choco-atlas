The continuous mirror question

Given finite states \(S\), outcomes \(A\), complete firm classes \(\Theta\), rational shares \(\lambda_\theta\), rational evidence laws \(p_\theta(s)\), and a target rule \(f:S\to A\), determine whether an anonymous mechanism exists for an atomless population of type \((\theta,E)\), with mass \(\mu_s(\theta,E)=\lambda_\theta p_\theta(s)(E)\), that implements \(f(s)\) in every continuum Bayesian Nash equilibrium for every bounded preference profile and gives zero transfers almost everywhere in equilibrium. The mechanism may condition outcomes and per-capita transfers on individual reports and the aggregate report distribution; a mass-deception witness for classes and states should be returned when the corresponding NPD condition fails.

The model it lives in

A continuum of firms in finitely many complete classes \(\theta\), with evidence mass \(\mu_s(\theta,E)=\lambda_\theta p_\theta(s)(E)\). Feasible report strategies move mass from \(E\) only to evidence reports \(E'\subseteq E\); decision variables \(x_{\theta,E,E'}\) describe those flows, and the objective is to construct an implementing outcome and per-capita transfer rule.

The objection that survived

In an atomless population, one agent's report does not change the aggregate report distribution, so the paper's crosschecks and bets need a new incentive construction.

fatal: False

What the mirror covers

The mirror covers Theorem 1's mixed-strategy BNE implementation characterization through classwise mass-deception flows; it leaves Theorem 2's pure-strategy condition, Theorem 3's uncertain-state and information-smallness results, and Theorem 4's rationalizable implementation aside.

Open questions for a prover

  • Does the classwise mass-deception condition remain necessary and sufficient for implementation in continuum Bayesian Nash equilibrium?
  • Can finite-description per-capita transfers reproduce the paper's crosschecks and bets when individual deviations leave aggregate reports unchanged?

The case FOR (proponent)

The strongest honest case is a population-mass version of the paper’s evidence-separation problem. The closest anchor is Theorem 1, proved in this paper. It says that, in the common-knowledge-state model, a social choice function is implementable in mixed-strategy Bayesian Nash equilibrium exactly when it satisfies NPD: whenever a state \(s'\) is nonrefutable at \(s\) and agents can use feasible stochastic deceptions to reproduce the evidence distributions they would have under truthful play at \(s'\), the desired outcomes must agree, \(f(s)=f(s')\). The implementation works for all bounded preference profiles and has zero transfers in equilibrium.

Theorem 1 is a named implementation characterization, not a named complexity result: the paper proves no runtime bound or hardness classification. So this can be a credible computational mirror, but not a claim that the paper already contains a complexity theorem.

A plausible high-multiplicity setting is a government choosing a licensing outcome for many exploration firms investigating the same oil field. Firms in the same class have the same payoff for each licensing outcome, the same evidence technology, and the same feasible evidence submissions. Let \(\theta\in\Theta\) denote such a complete class, with population share \(\lambda_\theta\), and let \(p_\theta(s)(E)\) be the probability that a class-\(\theta\) firm receives evidence collection \(E\) in state \(s\). The continuous society is

\[ \mu_s(\theta,E)=\lambda_\theta p_\theta(s)(E). \]

This describes the population’s mass of each evidence type. It is a credible regime when the number of firms is large and the number of genuinely distinct classes \(|\Theta|=\tau\) is comparatively small.

The lead question is Mass-NPD Population Implementation. Its input is a finite, explicitly listed state set \(S\), outcome set \(A\), class set \(\Theta\), rational shares \(\lambda_\theta\), rational evidence distributions \(p_\theta(s)\), and a target rule \(f:S\to A\). A population mechanism observes the distribution of reports, chooses an outcome, and assigns per-capita transfers. A strategy for a class is a report kernel from its received evidence to feasible messages; equivalently, it specifies how much mass of each \((\theta,E)\) reports each message. The question is whether there is a finite-description mechanism for which every continuum Bayesian Nash equilibrium yields \(f(s)\), with zero transfers almost everywhere on equilibrium reports. A positive solution supplies the mechanism; a negative certificate supplies states \(s,s'\) and a feasible mass deception showing why different outcomes cannot be separated.

The deception witness has a concrete form. For each class \(\theta\), let \(x_{\theta,E,E'}\) be the mass moving from received evidence \(E\) to reported evidence \(E'\). It must satisfy

\[ x_{\theta,E,E'}\ge 0,\qquad x_{\theta,E,E'}=0\ \text{unless }E'\subseteq E, \]

\[ \sum_{E'}x_{\theta,E,E'}=\lambda_\theta p_\theta(s)(E), \qquad \sum_E x_{\theta,E,E'}=\lambda_\theta p_\theta(s')(E'). \]

Together with the paper’s nonrefutability condition, these are the mass-level form of a perfect deception. Thus the proposed NPD audit reduces, for each ordered state pair, to a finite rational feasibility problem. With explicitly listed finite supports, that gives a plausible Class A route: solve the corresponding flow LPs and return either a violating pair and flow or a pass certificate. The LP test is the likely tractable core; extending the paper’s mechanism to prove that passing this test is sufficient in an atomless population is part of the research question.

There is unusually good evidence that authors would recognize this as their problem. Their model already treats evidence as state-dependent distributions, and the deception condition asks whether one distribution can be reproduced from another using feasible evidence reports. Aggregating many firms with identical complete types turns those reports into mass flows without changing what “perfectly imitate the false state” means. Theorem 3, also proved here, strengthens the regime fit: for informationally small agents with information size \(\varepsilon_I\), GNPD is sufficient for implementation in a large economy as \(I\to\infty\), with expected transfers vanishing; under nonexclusive information, GNPD is necessary and sufficient for exact BNE implementation with uncertain state types. That result is a direct large-economy bridge, though still not a complexity classification.

I would expect the finite-support Mass-NPD audit to be tractable, with running time measured in the number of listed states, classes, evidence types, and input bit length. That expectation applies to the mass-flow test, not yet to the full continuum implementation theorem. The scope here is the mixed-strategy, common-knowledge-state result of Theorem 1; it does not cover the paper’s rationalizability result or its general uncertain-state-type mechanisms.

The weakest point is the incentive argument. The finite-agent mechanisms use individual deviations, crosschecks, and a circular ordering of agents. In an atomless population, one agent’s report has zero effect on the aggregate report distribution, so those incentives may disappear. The paper’s large-economy result is encouraging, but it does not establish an atomless mechanism or show that Mass-NPD remains sufficient there. That is the main proof obligation—and, under the programme’s strict gate, the absence of a named complexity result remains a real limitation.

The case AGAINST (opponent, writing after the proponent)

The strongest case against a ChoCo mirror is that this paper has no computational result to continuize. Theorem 1 characterizes when a social choice function can be implemented in equilibrium; it does not analyze the complexity of computing an outcome, or give an algorithmic or hardness result. Theorem 3 extends that implementation analysis to large economies, but still makes no complexity claim. A new computational problem could be built around either theorem, but that would be a new mechanism-design project rather than a continuous mirror of a computational result in the paper.

The proposed Mass-NPD audit does not close that gap. With finite, explicitly listed evidence collections, its mass-deception constraints are ordinary transportation LPs. They provide a polynomial-time way to check the paper’s NPD condition across state pairs. That is a clean computational reformulation, but the desired outcome \(f(s)\) remains given; the task is to test whether some mechanism can implement it. The flow LP does not compute a social choice outcome, and it does not establish that the finite-agent implementation mechanism works in an atomless population.

The best atomless version makes the missing step substantive. If the designer is given \(\mu_s(\theta,E)=\lambda_\theta p_\theta(s)(E)\) as the society, the input includes the aggregate evidence distribution that was private in the paper. If instead that distribution is latent and only reports are observed, the object is an anonymous Bayesian game over report masses, not the paper’s finite-agent mechanism with a new input format. The finite proof uses named agents for crosschecks, predictions, and bets. A continuum has no designated successor to crosscheck; an individual’s report cannot change an aggregate outcome. Per-capita transfers could still give individuals incentives, but designing and analyzing those incentives would require a new implementation theorem. The proposed flow feasibility test alone cannot supply it.

Theorem 3 is the proponent’s strongest support for a population interpretation. Its large-economy result makes it hard to argue that multiplicity is inherently unnatural here, and that evidence should count in the paper’s favour. But it is a limit of finite-agent mechanisms with individual types and beliefs, not an atomless society or a complexity classification. A richer mirror based on Theorem 4 would face an even less direct translation: its object is higher-order belief hierarchies, so a population model would need to preserve how agents’ beliefs depend on other agents’ types, not just the mass of evidence types.

So the negative case is strongest on programme fit and weakest on the possibility of a worthwhile new model. The paper’s large-economy result is real evidence that a continuous population question could make sense. I would not claim that no such question is worth asking in any scenario. I would argue that the proposed mirror has not yet shown a computational contribution that belongs to ChoCo: its tractable part is an LP check of the paper’s implementation condition, while the genuinely continuous implementation problem remains to be formulated and proved.
