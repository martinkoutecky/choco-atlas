The continuous mirror question

Given types \(t\in\mathcal T\) with rational masses \(\mu_t\) summing to \(1\), eligibility sets \(\Gamma_t\subseteq\mathcal R\), rational per-capita supplies \(b_j\), and a common monotone submodular utility \(f:2^{\mathcal R}\to\mathbb Q_{\ge 0}\), each unit of type mass must receive an integral bundle \(S\subseteq\Gamma_t\). Let \(x_{t,S}\) be the mass receiving \(S\); require \(\sum_{S\subseteq\Gamma_t}x_{t,S}=\mu_t\) and \(\sum_{t}\sum_{S\ni j}x_{t,S}\le b_j\) for each \(j\in\mathcal R\). Find the largest \(z\) such that \(x_{t,S}>0\) only when \(f(S)\ge z\), or approximate that optimum, with running time polynomial in \(|\mathcal R|\), \(|\mathcal T|\), and the binary input length given value-oracle access to \(f\).

The model it lives in

A continuum of households partitioned into \(\tau=|\mathcal T|\) eligibility types, with mass \(\mu_t\) per type and scalable per-capita supplies \(b_j\). Decision variables \(x_{t,S}\) allocate mass to integral bundles; the objective is to maximize the minimum utility \(f(S)\) received.

What the mirror covers

The mirror concerns Theorem 1’s restricted-assignment submodular Santa Claus problem; it does not cover arbitrary player-specific valuations or Theorem 20’s general-hypergraph reduction.

Open questions for a prover

  • Can the configuration-LP guarantee of \((1-1/e)/2\) from Theorem 2 be established for arbitrary rational type masses and supplies with running time polynomial in their bit length?
  • How does the continuous optimum compare with the best allocation at a specified finite population size?

The case FOR (proponent)

The strongest lead is Mass-Restricted Submodular Santa Claus, a continuous-population version of the paper’s restricted-assignment problem.

The anchor is Theorem 1, proved in this paper: for \(n\) indivisible resources and \(m\) players, with a common monotone submodular utility \(f\) and each player \(i\)’s valuation \(f_i(S)=f(S\cap\Gamma_i)\), there is a randomized polynomial-time \(O(\log\log n)\)-approximation for maximizing the minimum player utility. The paper has no numbered hardness result for this restricted-assignment problem; its set-packing hardness discussion concerns unrestricted utilities.

A plausible high-multiplicity setting is a large public allocation program: many households, but relatively few eligibility profiles, each with the same eligibility set and utility function as other households in its profile. The utility might measure coverage from bundles of standardized, indivisible aid categories, with diminishing returns across categories. If the population has \(N\) households and \(\tau\) profiles, the regime is \(N\gg\tau\); supplies of each category scale with \(N\). This preserves the paper’s common-\(f\), restricted-assignment structure while making the population, rather than individual households, the object being modeled.

Here is the mirror problem precisely. An instance has a finite set of household types \(\mathcal T\), a finite catalog \(\mathcal R\) of resource categories, rational type masses \(\mu_t\ge 0\) summing to \(1\), eligibility sets \(\Gamma_t\subseteq\mathcal R\), rational per-capita supplies \(b_j\ge 0\), and a monotone submodular function \(f:2^{\mathcal R}\to\mathbb Q_{\ge0}\) with \(f(\emptyset)=0\). Assume \(f\) is available through an exact value oracle. A household in type \(t\) receives an actual subset \(S\subseteq\Gamma_t\); it never receives a fractional bundle. The output is a threshold \(z\) and masses \(x_{t,S}\ge0\), where \(x_{t,S}\) is the mass of type \(t\) receiving bundle \(S\). Require \(x_{t,S}=0\) whenever \(f(S)<z\), \(\sum_{S\subseteq\Gamma_t}x_{t,S}=\mu_t\) for each \(t\), and \(\sum_{t}\sum_{S\ni j}x_{t,S}\le b_j\) for each resource category \(j\). The optimization asks for the largest feasible \(z\), and a sparse allocation of masses attaining it or an approximation to it. In particular, every positive-mass household gets utility at least \(z\); this is still a max-min fairness question, not one about average utility.

I expect Class A, with a constant-factor approximation in time polynomial in \(|\mathcal R|\), \(\tau\), and the binary input length \(L\), using value-oracle calls. For a fixed threshold, the mass allocation is exactly a configuration LP: its variables say how much of each type receives each qualifying bundle. The paper’s Section 2 already approximates the finite-player configuration LP within \((1-1/e)/2\), using approximate separation through submodular knapsack. In the mass version, rational masses and supplies change the LP’s right-hand sides, while the separation problem remains the same kind of submodular knapsack problem. So a concrete target for a prover is a \((1-1/e)/2\)-approximation for this mass allocation problem, with running time polynomial in \(|\mathcal R|,\tau,L\).

The reason this mirror could improve on Theorem 1’s guarantee is also concrete. For finite players, the configuration LP is a relaxation: its fractional solution still has to be rounded into an assignment of indivisible resources to named players. The paper handles that step with hypergraph matching and randomized rounding. For a continuum of agents and proportionally scaled supplies, \(x_{t,S}\) is itself an allocation: mass \(x_{t,S}\) of actual agents receives the integral bundle \(S\). Thus the configuration LP describes the continuous problem directly, and the finite-instance rounding obstacle is absent. A finite discrete assignment maps to a feasible mass allocation by dividing counts by population size; conversely, a rational mass allocation can be realized exactly in a sufficiently replicated population. How well it rounds at a specified finite population size is a further question.

This mirror covers Theorem 1’s monotone submodular restricted-assignment problem, not Santa Claus with arbitrary player-specific valuations or the paper’s general-hypergraph connection. Its weakest point is the resource regime: the formulation assumes a finite catalog of resource categories with scalable supplies and a utility function over those categories. A setting with many one-off, noninterchangeable resources may not admit that description naturally. The case survives when the application really does have replicated categories, because the household’s allocation remains an integral bundle and the paper’s eligibility and diminishing-returns structure are preserved. The next questions are whether the same constant guarantee follows for arbitrary rational masses and supplies, and how its continuous optimum compares with the best allocation at a fixed finite population size.

The case AGAINST (opponent, writing after the proponent)

I cannot honestly defeat the sole anchor. Theorem 1 is a named computational result, and the proponent’s mass allocation is a coherent continuous-population question. For each type \(t\), mass \(x_{t,S}\) receives an integral bundle \(S\); type mass is conserved, and resource use is bounded in aggregate. With eligibility and utility included in the type, the model does not discard information the paper’s objective needs. Proportional supplies are also a natural co-modification when the population grows.

The best objection is that this mirror narrows the paper’s resource model. It treats resources as standardized categories with scalable supplies and a common submodular utility over categories. The paper allows a finite set of distinct resources, and an arbitrary \(f\) may distinguish resources that a category model would treat as copies. That weakens the mirror’s coverage, but it does not rule out the proposed aid-allocation regime. The programme asks whether a sensible high-multiplicity regime exists, not whether every instance fits it.

There is also a real novelty concern: for a fixed utility threshold, the continuous allocation is essentially a configuration LP with type masses and scaled capacity bounds. The paper already approximates its configuration LP in Theorem 2. That makes the algorithmic work look close to an existing result. But the continuous model’s equivalence to that LP is itself a discrete-to-continuous identity, and the programme explicitly treats such identities as worthwhile results. Knowing the likely algorithm does not defeat a well-posed mirror.

So the strongest negative case is that this would be a narrow, possibly short mirror whose main algorithmic machinery is already in the paper. That is a caution about its novelty, not a sound reason to say there is no worthwhile scenario. Under the stated rules, the anchor survives; a stronger case against would need to show that even the standardized-category, scalable-supply regime is not a sensible object, and the paper provides no basis for that claim.
