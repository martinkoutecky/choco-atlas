The continuous mirror question

Given a finite outcome set \(X\) and a rational distribution \(\mu\) over supported weak-order preference types, is every lottery supported on the Pareto-optimal outcomes ex-ante efficient under stochastic-dominance preferences of all supported types?

The model it lives in

Each type \(t\) is a weak order over \(X\), and \(\mu_t>0\) is its population mass, with \(\sum_t \mu_t=1\). Keep lotteries in \(\Delta(X)\); define Pareto optimality and ex-ante stochastic-dominance efficiency across the supported types, with strict improvement for at least one type. Decide whether the ex-ante- and ex-post-efficient lottery sets coincide.

What the mirror covers

The mirror covers Corollary 3 and its supporting linear criterion for recognizing equivalence of the two efficiency sets. It leaves the paper’s other structural characterizations and domain-specific results unmirrored.

The case FOR (proponent)

The strongest honest anchor is Corollary 3, proved in this paper: given a finite preference profile, deciding whether its sets of ex-ante-efficient and ex-post-efficient lotteries coincide is possible in polynomial time. The authors first identify Pareto-optimal outcomes, then use the linear criterion in Criterion 1(e) to test the equivalence. This is a genuine computational result, though the paper offers no comparable named hardness result to anchor a “discrete hardness dissolves” story.

I would mirror it as Continuum Ex-Ante/Ex-Post Equivalence Recognition. Let \(X\) be an explicitly listed set of \(m\) outcomes. A type \(t\) is a complete weak order over \(X\), and the society is a distribution \(\mu\) over its \(\tau\) supported types, with positive rational masses summing to one. Think of a large electorate choosing among a small finite menu of public policies: many residents share each ranking, while the lottery over policy outcomes remains the paper’s ordinary lottery in \(\Delta(X)\).

For a lottery \(q\), type \(t\) weakly prefers \(q\) to \(p\) by stochastic dominance when
\[ \sum_{y\succ_t x}q_y\ \ge\ \sum_{y\succ_t x}p_y \quad\text{for every }x\in X. \]
An outcome is Pareto-optimal if no other outcome is weakly preferred by every supported type and strictly preferred by a positive mass of the society. An ex-post-efficient lottery is supported on Pareto-optimal outcomes. An ex-ante improvement weakly stochastically dominates the original lottery for every supported type and strictly dominates it for a positive mass of types.

The instance is \((X,\mu)\). The question is whether every ex-post-efficient lottery is ex-ante-efficient—equivalently, whether those two sets of lotteries coincide. A YES or NO is the decision output; for NO, one can return an ex-post-efficient lottery \(p\) and a lottery \(q\) that ex-ante dominates it. This states the underlying efficiency question, rather than asking about an encoding.

The same criterion gives a polynomial algorithm. Let \(X^*_\mu\) be the society’s Pareto-optimal outcomes. The answer is NO exactly when there is a nontrivial vector \(\alpha\in\mathbb R^{X^*_\mu}\) such that
\[ \sum_{x\in X^*_\mu}\alpha_x=0,\qquad \sum_{y\succ_t x}\alpha_y\ge 0 \quad\text{for every supported type }t\text{ and }x\in X^*_\mu, \]
with at least one of these inequalities strict. By homogeneity, test each possible strict inequality by requiring it to be at least \(1\). Computing \(X^*_\mu\) and solving the resulting polynomial number of linear feasibility problems takes time polynomial in \(m,\tau,L\), where \(L\) is the input bit length. Thus this mirror is Class A.

This is a plausible mirror of the authors’ problem because preferences are the complete agent descriptions used in their efficiency definitions, and duplicate agents with the same preference type make no difference to the test. It covers Corollary 3’s profile-level equivalence question and its finite-outcome assumption. The continuous population is the object being modeled; the lottery over outcomes stays as in the paper.

The weak point is that this mirror does not expose a new tractability gain from continuity. The paper’s recognition problem is already polynomial, and the continuous version depends on the support of \(\mu\), not the precise positive mass values. The payoff is a faithful high-multiplicity formulation with running time in the number of distinct types. It also raises natural follow-ups: what happens with implicitly represented or very large outcome sets, with an infinite type space, or when small changes in masses cause a type to enter or leave the support?

The case AGAINST (opponent, writing after the proponent)

Corollary 3 is the proponent’s strongest anchor, and the proposed recognition problem is a valid way to restate it for a population. But the population’s masses do no work in that problem.

With finite \(X\), there are only finitely many ordinal preference types. For any rational society \(\mu\), multiply its masses by a common denominator to obtain a finite electorate with the same supported types. Pareto optimality is unchanged: a type that strictly prefers an alternative represents positive mass exactly when it appears in that electorate. The stochastic-dominance constraints are also unchanged by duplicating a type. Consequently, two societies with the same support but radically different shares have the same answer. The paper’s test can run on one representative per supported type; the mass values and their bit lengths can be discarded.

That also defeats a stronger version of the mirror. A large electorate choosing among public policies is plausible, but changing a ranking type’s share—from a tiny fraction to nearly the whole population—cannot change the equivalence question. Giving the distribution more detail does not help: with finitely many outcomes, ordinal preferences induce only finitely many relevant types, even if residents differ in cardinal intensities. Those intensities are outside the paper’s stochastic-dominance model. To make population shares affect the question, one would need to replace its unanimity-based efficiency criterion with a mass-weighted or cardinal one. That could be a worthwhile problem, but it would be a different efficiency concept rather than a better mirror of Corollary 3.

So the continuous formulation collapses to the original finite-profile question after quotienting duplicate rankings. This is not a claim that an existing continuous treatment already solved it; it is that the chosen result contains no population-mass question for a continuous treatment to expose. The case against this anchor is strongest on that structural point, and weaker if the programme counts a support-compressed restatement as worthwhile in its own right.
