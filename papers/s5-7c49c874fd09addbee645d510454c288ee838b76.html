The continuous mirror question

Given a finite set \(T\) of voter types, rational type masses \(\mu_u>0\), and rational delegation-flow masses \(z_{tu}\) from source type \(t\) to target type \(u\), estimate nonnegative weights \(\varphi_{tu}\) maximizing \(\sum_{t,u} z_{tu}\log\!\left(\frac{\mu_u\varphi_{tu}}{\sum_v\mu_v\varphi_{tv}}\right)\), with \(\sum_u\mu_u\varphi_{tu}=1\) for each source type. For rows with positive delegation mass, the MLE is \(\hat\varphi_{tu}=z_{tu}/(\mu_u\sum_v z_{tv})\).

The model it lives in

A high-multiplicity delegation-estimation model: each type records the competence and delegation behavior relevant to the paper; the society is the mass distribution \(\mu\), observations are fractional type-to-type delegation flows \(z\), and the decision variables are target weights \(\varphi_{tu}\) maximizing the mass-level log-likelihood.

The case FOR (proponent)

The strongest positive case is narrow: a continuous-population version of the paper’s delegation-kernel estimation, anchored on the Appendix Proposition. The text supplied here prints no proposition number; the proposition is proved in the paper. It states that for source competence bucket \(\ell\) and target bucket \(k\), the maximum-likelihood estimate is \(\varphi^\ell_{e,t}(\eta_k)=z^\ell_k/n_k\) when \(k\ne\ell\), and \(z^\ell_k/(n_\ell-1)\) when \(k=\ell\), up to scaling; if the denominator is zero, the estimate may be \(0\). This is a closed-form algorithmic result, though the paper does not state a complexity classification. The named model theorems are about asymptotic probabilistic do-no-harm and positive gain, not computational complexity.

A precise mirror is Continuous Delegation-Kernel Estimation. An instance has a finite set \(T\) of complete voter types, each specifying competence and delegation behavior; rational type masses \(\mu_u\); and rational aggregate delegation flows \(z_{tu}\), where \(z_{tu}\) is the mass of type \(t\) delegating to type \(u\). For each source type \(t\), estimate nonnegative target weights \(\varphi_{tu}\). A type-\(t\) delegate chooses target type \(u\) with probability \(\varphi_{tu}\mu_u/\sum_v\varphi_{tv}\mu_v\). The task is to return weights maximizing the likelihood of the observed flows, with a normalization such as \(\sum_u\mu_u\varphi_{tu}=1\). For rows with positive delegation mass, the solution is \(\hat\varphi_{tu}=z_{tu}/(\mu_u\sum_v z_{tv})\). Thus the exact solution is computable in polynomial time in \(\tau=|T|\) and the input bit length. The individual self-exclusion correction in the finite proposition disappears when mass replaces head counts.

The regime could be a large, issue-specific prediction platform: many participants fall into a modest number of competence-and-behavior types, and the platform records delegation totals between types. Type mass is a population fraction, and aggregate flow may be fractional. That is a credible high-multiplicity regime, and the authors would likely recognize the mirror: they already model delegation probabilities through \(\varphi\) and estimate them from competence-bucketed flows. Further questions include estimating \(\varphi\) under monotonicity constraints, handling sparse observations, and measuring how estimation error affects truth-tracking.

The weak point is substantial: this mirrors an appendix estimation result, not the paper’s central results about random delegation graphs. Aggregate flows discard the component sizes, cycles, and concentration tails that those results analyze. So this is a defensible Class A mirror of one computed part of the paper, not a continuous computational account of its main truth-tracking theorems.

The case AGAINST (opponent, writing after the proponent)

The only computational-looking anchor is the Appendix proposition giving the maximum-likelihood estimate of \(\varphi\). The paper’s three delegation theorems establish high-probability performance properties; they do not classify the complexity of a computational problem. The proposition is a closed-form statistical estimation result, not a complexity result for an intervention or outcome problem of the kind ChoCo is set up to study.

The proponent’s finite-type mirror is a sensible statistical model, and I would not reject it on high-multiplicity grounds. Given type masses \(\mu_u\) and aggregate flows \(z_{tu}\), its row-wise estimate is
\[ \hat\varphi_{tu}=\frac{z_{tu}}{\mu_u\sum_v z_{tv}}. \]
But this asks for a frequency-based estimate of delegation behavior. Computing it takes polynomially many rational operations in the table size; there is no combinatorial search or algorithmic bottleneck for continuization to change. Calling that an algorithmic result makes almost any closed-form estimator a computational-social-choice problem, stretching ChoCo’s stated focus beyond its complexity landscape.

The stronger continuous version exposes the same boundary. With a genuinely diffuse competence space, the input and output become measures or functions, not finite binary encodings. To ask for a complexity classification, one must add a representation and assumptions such as a finite basis, smoothness, or a sampling model. A finite partition returns to the table estimator; the other choices define a statistical-learning problem whose computational questions are additional to this paper’s result.

So this anchor does not establish a worthwhile ChoCo mirror. The negative case is weakest at the universal claim: a large platform with repeated, genuinely identical competence-and-behavior types could motivate mass-level kernel estimation, and a programme that includes statistical learning might pursue it. That would be a plausible adjacent project. The paper itself, however, supplies no nontrivial computational problem for a continuous mirror to advance.
