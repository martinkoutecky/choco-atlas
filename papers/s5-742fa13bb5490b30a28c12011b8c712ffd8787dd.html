The case FOR (proponent)

I can’t make a valid anchored positive case: the paper contains no named computational result asserting tractability, hardness, or a parameterized complexity classification.

The closest candidate is Theorem 3.1, which the paper attributes to Kurz (2018), rather than proving here. It says that for the Nucleolus, Public Good, Deegan-Packel, minimum sum representation, average weight, and average representation indices, for every \(\varepsilon>0\) there is an \(N(\varepsilon)\) such that in every simple game \(v\) with \(n\ge N(\varepsilon)\), each player \(i\) has either \(g_i(v)=1\) or \(g_i(v)\le \tfrac12+\varepsilon\). The text contrasts this with the Shapley-Shubik, Penrose-Banzhaf, and Johnston indices, for which games can make \(g_i(v)\) arbitrarily close to any value in \([\tfrac12,1]\). That is an asymptotic statement about possible power values, not a computational result.

There is a plausible population setting nearby: a large weighted legislature or company with many small members in a few weight classes, so the number of members is much larger than the number of types. Section 3.3 also discusses limit results for many minor players. But turning either into a continuous computational problem would require defining how the indices extend to the limit and what quantity an algorithm should compute. The paper neither does that nor presents a named computational result to anchor it. Its central question is which indices are appropriate for applications, not how to compute a power index on a continuous society.

So a continuum power-index problem could be a worthwhile new follow-up, but presenting one as a mirror of this paper’s computational result would overstate the case. The missing anchor is the decisive weakness.

The case AGAINST (opponent, writing after the proponent)

The only named result offered as an anchor, Theorem 3.1, does not give this paper a computational result to continuize. It is an asymptotic statement about the values certain indices can assign across simple games; the paper cites it from earlier work. It specifies no computational task, input representation, algorithm, or complexity bound. The paper’s contribution is a discussion of how to choose and design power indices, not a computational classification.

The large-committee scenario is plausible as a high-multiplicity regime. It still does not supply a continuous version of Theorem 3.1. The theorem concerns an individual player’s index in a finite simple game. A distribution over weight types and a quota does not, on its own, define how to extend that index. In an atomless threshold model, changing a coalition by one individual has no effect, so individual pivotal power disappears. Retaining power requires extra structure: finite atoms, a finite replication limit, or an aggregate index for each type. Each can be a sensible modeling choice, but each changes the quantity the theorem studies. In particular, the theorem’s bound on \(g_i(v)\) does not directly become a bound on the sum of power held by a type.

The paper’s discussion of limit results for major and minor players points toward the strongest repair: encode a weighted game by a small number of player types, then compute limiting or aggregate index values. That could be a worthwhile project in its own right. It would need to define the game representation, the coalition or ordering model, and the index being computed. Those choices matter especially for indices based on counting minimal winning coalitions or swings, since a continuum supplies no direct finite counting measure. The cited limit results are mathematical analyses, not computational answers; their existence supports the plausibility of the regime but does not fill in a computational mirror.

So the negative case is strong against treating this paper as an anchored continuization target: its named theorem is not computational, and the best computational salvage asks a new question about a newly specified index on a newly specified model. The universal claim—that no such scenario could be worthwhile—is weaker. A high-multiplicity power-index computation problem may be worth studying; the supplied paper just does not establish it as a mirror of one of its results.
