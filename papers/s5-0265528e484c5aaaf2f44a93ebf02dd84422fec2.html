The continuous mirror question

Given candidates \(C\), a committee \(W\), and a distribution \(\mu\) over supported approval types \(T\), compute the exact threshold \(\theta_\mu(W)=\max_{c\notin W,\ \emptyset\ne S\subseteq T_c,\ r_W(S)<k} k\mu(S)/(r_W(S)+1)\), where \(T_c=\{t\in T:c\in t\}\), \(\mu(S)=\sum_{t\in S}\mu_t\), and \(r_W(S)=|\bigcup_{t\in S}(t\cap W)|\); return a maximizing \(c,S\) and the boundary level \(\ell=r_W(S)+1\).

The model it lives in

Use supported approval types \(t\) with masses \(\mu_t\), and select a nonempty set \(S\subseteq T_c\) of types. The objective is to maximize \(k\mu(S)/(r_W(S)+1)\) over unelected candidates \(c\), subject to \(r_W(S)<k\); the output is the threshold and a maximizing witness.

What the mirror covers

The mirror covers the exact threshold in Theorem 12 and fixed-parameter violation verification in Proposition 5. It does not carry over the paper's voter-count running-time bounds or settle the practical comparison among flow implementations.

Open questions for a prover

  • Can the exact threshold and witness be computed in bit complexity polynomial in \(m,k,\tau,L\) using rational-capacity parametric mincuts?
  • What dependence on the support graph's number of edges can an exact implementation achieve?

The case FOR (proponent)

The strongest mirror is continuous PJR\(^+\) verification for an approval election whose electorate is represented by ballot types. Take a large membership organization electing a \(k\)-seat council from \(m\) nominees. Its many members submit approval ballots, but repeated cohorts—perhaps chapters or occupational groups—share ballots, so \(n\) can be in the millions while the number \(\tau\) of distinct ballots is much smaller.

A type is an approval set \(t\subseteq C\), and the society is a rational distribution \(\mu\) over its \(\tau\) supported types, with \(\sum_t\mu_t=1\). The committee \(W\) remains an ordinary \(k\)-element set. A proposed group is described by masses \(x_t\in[0,\mu_t]\) of each type; its mass is \(\sum_t x_t\), and it represents \(r_W(x)=|\{w\in W:\exists t,\ x_t>0,\ w\in t\}|\) committee members. For an unelected candidate \(c\), a violation at level \(\ell\) has \(x_t=0\) unless \(c\in t\), mass at least \(\alpha\ell/k\), and \(r_W(x)<\ell\). The group is measured as a fraction of society, and the committee and its representation count stay integral.

For deciding violations, it is enough to consider groups that take all the mass of every type they include. Expanding a group to the full mass of its selected types cannot reduce its size or change which committee members those types approve. This is not an imposed restriction on coalitions: it follows from the axiom’s own coverage structure. A returned witness can therefore be a candidate \(c\), level \(\ell\), and a set of types \(S\), with group mass \(\mu(S)=\sum_{t\in S}\mu_t\).

Proposition 5 is my lead anchor; it is proved in this paper. It says that, for a finite election, an \(\alpha\)-PJR\(^+\) violation can be found or its nonexistence certified in \(\mathrm{O}(m(nk)^{1+o(1)})\) time using almost-linear maximum flow, in \(\mathrm{O}(mnk\min\{n,k\})\) time using specialized bipartite preflow–push, or in \(\mathrm{O}(m(n+k)^2\sqrt{nk})\) time using generic highest-label preflow–push, when \(\alpha\geq1\). For \(0<\alpha<1\), each bound gains a factor of \(k\). The underlying continuous question is: given \(C,W,\mu\) and rational \(\alpha>0\), does a violating \(c,\ell,S\) exist, and if so, return one? This is the lead continuous problem. The mincut carries over directly: type \(t\) receives a source-edge capacity proportional to \(\mu_t\), and its voter-to-winner edges encode the same shared coverage cost. For \(\alpha<1\), iterate over a committee member \(w\) and restrict to types that do not approve \(w\), ensuring fewer than \(k\) winners are represented. The graph has only \(\tau\) type vertices, so exact rational-capacity mincut gives a polynomial-time algorithm in \(m,k,\tau\), and the input bit length \(L\). I expect tractability. A concrete follow-up is whether the paper’s near-linear flow bounds extend to these weighted capacities with a sharp dependence on \(L\).

Theorem 12, proved in Appendix A using cited parametric-flow machinery, is a second useful anchor. In the finite election it first runs the verifier at \(\alpha=1\). If that finds a violation, it computes the threshold as \(\frac{k}{n}\max_{c\notin W}\lambda_{N_c}\); otherwise it computes it as \(\frac{k}{n}\max_{c\notin W,\ w\in W}\lambda_{N_c\setminus N_w}\), where \(\lambda_U=\max_{\varnothing\ne N'\subseteq U}|N'|/(r_W(N')+1)\). The parametric cuts return a group attaining the maximum and hence a boundary witness with \(\ell=r_W(N')+1\). The stated worst-case time is \(\mathrm{O}(mnk^2\min\{n,k\}\log(\min\{n,k\}))\); when the query at \(1\) finds a violation, the factor \(k\) is removed.

The corresponding continuous problem is to return the exact largest \(\alpha\) for which the society fails \(\alpha\)-PJR\(^+\), together with a boundary witness. For a nonempty set \(S\) of types approving \(c\), its threshold contribution is \(k\mu(S)/(r_W(S)+1)\), provided \(r_W(S)<k\). Thus define \(\theta_\mu(W)=\max_{c\notin W,\ \varnothing\ne S\subseteq T_c,\ r_W(S)<k} k\mu(S)/(r_W(S)+1)\), with value \(0\) if there is no such pair; return a maximizing \(c,S\) and \(\ell=r_W(S)+1\). To mirror Theorem 12, the parametric cut for a type set \(U\) uses capacities \(\mu_t\) on source-to-type, type-to-winner, and type-to-dummy edges, and capacity \(\lambda\) on winner-to-sink and dummy-to-sink edges. A canonical cut for \(S\) has value \(\mu(U)-\mu(S)+\lambda(r_W(S)+1)\), so its breakpoint gives the desired ratio. The \(U\) sets follow the theorem’s two cases, and exact rational capacities preserve a polynomial-time route in \(m,k,\tau,L\). I also expect tractability here; the further question is whether the parametric method retains a near-linear dependence on the support graph’s edges.

Both anchors are computational results proved in this paper. The introduction’s cited coNP-completeness result is for PJR, a different axiom, so it is not a hardness anchor for this note. The paper presents no comparable in-paper hardness result to prefer.

The soft spot is that this is a particularly favorable axiom to continuize: its witnesses depend only on ballot types, group mass, and shared coverage. In fact, for an empirical distribution \(\mu_t=n_t/n\), the continuous and finite versions have the same yes/no answer and threshold: any finite or continuous witness can be expanded to all members of its included ballot types. That identity is a good bridge, but it limits the claim of a new complexity phenomenon. The positive case is instead that the distribution over a high-multiplicity electorate is a sensible input in its own right, with complexity measured in \(\tau\) and binary mass lengths rather than the number of people. The authors could reasonably recognize both questions as theirs: they retain PJR\(^+\)’s unelected-candidate claim, integral committee, coverage rule, and representation levels, while replacing head counts with population fractions.

The case AGAINST (opponent, writing after the proponent)

I can make a case that these are unusually *mechanical* mirrors, but I can’t make a convincing case that no worthwhile mirror exists.

For Proposition 5, a coalition can be expanded to include the full mass of every approval type it touches: its size only increases, while its represented committee members stay the same. So the continuous witness is just a subset of supported types. Aggregating identical ballots in the paper’s mincut gives the corresponding weighted graph directly: use capacities proportional to each type’s mass, with the same shared cost for each represented committee member. This gives a polynomial-time verification algorithm in the support size and mass bit length. The negative argument is that this is a weighted quotient of the paper’s proof, not a new combinatorial insight. But it is still a high-multiplicity algorithm, which the programme explicitly values.

Theorem 12 is even closer to a direct lift. In the appendix’s parametric graph, replace each voter’s unit mass by its type’s mass. The same cuts maximize \(\mu(S)/(r_W(S)+1)\), yielding the continuous threshold and a boundary witness. Again, the likely contribution is an exact compressed-input result, rather than a new method. That may make it less surprising, but it does not make the question already solved for arbitrary rational distributions: the paper gives running times in the number of explicitly listed voters, not in support size and bit length.

One might object that coalition mass never needs to be fractional within a type. That is true, but it does not defeat the mirror: the programme’s continuous society is a distribution over types, and aggregating identical agents is precisely its high-multiplicity regime. Nor does the fact that the continuous and finite answers coincide count against it under the stated standard.

So the strongest honest negative case is about novelty, not whether the mirrors are well-posed or useful. Both anchors survive that test. Under ChoCo’s remit, their directness is a reason the mirrors may be tractable, not a sound reason to rule them out.
