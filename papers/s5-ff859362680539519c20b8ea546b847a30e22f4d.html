The continuous mirror question

Given two types \(T=\{t_1,t_2\}\) with masses \(\mu_t=\frac12\), resource categories \(G\), binary values \(v_{tgk}\), supply \(q_g=\frac12\) of each category, and bundles \(B\in\{0,1\}^{G}\), choose nonnegative masses \(\lambda_{t,B}\) satisfying \(\sum_B\lambda_{t,B}=\mu_t\) and \(\sum_{t,B}\lambda_{t,B}B_g=q_g\). For each dimension define \(W_k=\sum_{t,B}\lambda_{t,B}\sum_g v_{tgk}B_g\) and \(U_k^*=\max_{\lambda}W_k\) over feasible allocations; maximize the number of dimensions \(k\) for which \(W_k=U_k^*\).

The model it lives in

A continuous population of two complete recipient types, each of mass \(\frac12\), receives replicated resource categories with supply \(\frac12\) per category. Each recipient receives an integral bundle with at most one unit of each category; mass allocations over bundles yield fractional type-level averages. The objective is to maximize the count of dimensions attaining their separate utilitarian optima.

What the mirror covers

The mirror covers Theorem 6's hardness for maximizing the number of Umax dimensions; it leaves the paper's other algorithmic, egalitarian, approximation, and Pareto results aside.

Open questions for a prover

  • Formalize the MAX-Intersect reduction for mass allocations over integral bundles and prove that it preserves the optimum and approximation gap.
  • Determine whether the paper's \(c/\ell\)-approximation extends to rational-mass instances of this model.

The case FOR (proponent)

The strongest mirror is Continuous Maximum Umax Dimensions. The anchor is Theorem 6, proved in this paper: for every \(\epsilon>0\), approximating the maximum number of dimensions in which utilitarian welfare is optimal within a factor \(1/\ell^{1-\epsilon}\) is NP-hard, even with two agents and binary valuations. The paper proves this by a gap-preserving reduction from MAX-Intersect, whose hardness it cites from earlier work. [The paper’s arXiv version](https://arxiv.org/html/2606.21346)

Here is a continuous-population version of that problem. Let \(T\) be a finite set of complete recipient types, with positive rational masses \(\mu_t\) summing to one. A type specifies each recipient’s value \(v_{tgk}\) for every resource category \(g\in G\) and dimension \(k\in[\ell]\). Category \(g\) has rational supply \(q_g\) per person. An allocation gives each individual a bundle of whole items; write \(\lambda_{t,B}\) for the mass of type \(t\) receiving integral bundle \(B\in\mathbb Z_{\ge0}^{G}\). Require \(\sum_B\lambda_{t,B}=\mu_t\) and \(\sum_{t,B}\lambda_{t,B}B_g=q_g\) for each category \(g\). The question is to find such an allocation maximizing the number of dimensions \(k\) for which \(W_k=\sum_{t,B}\lambda_{t,B}\sum_g v_{tgk}B_g\) equals that dimension’s optimum \(U_k^*=\max W_k\). The allocation may be represented by aggregate quantities \(x_{tg}=\sum_B\lambda_{t,B}B_g\), with \(\sum_t x_{tg}=q_g\). These quantities can be fractional because they are averages across people: each person still receives whole items.

A plausible regime is a large cloud provider repeatedly assigning resource modules to sites in two stable workload groups. Sites in each group share the same complete valuation profile across resource categories and criteria; the supply of each category grows with the number of sites. As the population grows, \(N\) is large while the number of distinct types \(\tau\) can remain two. The categories and dimensions remain explicit parts of the input. This matches the paper’s allocation question closely: it keeps additive values, indivisible goods for each recipient, and the count of objectives attaining their own optimum. Growing supply with the population is the natural co-modification needed for a large population of recipients.

The hardness mechanism survives the move. In the reduction for Theorem 6, take two types of mass \(1/2\), one resource category for each paper item, and supply \(q_g=1\) per person. For each dimension \(k\), its optimum is attained only if every category’s supply goes to types that value it maximally in that dimension. For a set of dimensions to be optimized together, each category must therefore have at least one type that is a maximizer in all of them. That is exactly the common-set condition in MAX-Intersect. Splitting a category’s supply across types does not evade the condition: any type receiving positive mass must be a maximizer in every dimension being counted. So the reduction preserves the optimum and its approximation gap. I expect this mirror to be Class B: hardness transfers, even with \(\tau=2\). The combinatorics lives in the resource categories and the dimensions, not in a large number of distinct recipients.

I would keep the scope to this one result. It also raises concrete follow-up questions: whether the paper’s \(c/\ell\) approximation carries over to these type flows, how its fixed-\(\ell\) algorithmic results depend on \(\tau\) and the input bit length, and how added per-recipient capacity constraints would change the picture.

The weakest point is the scenario fit: the paper’s hardness instance has two agents, and the mirror’s large population comes from cloning those two profiles while scaling resource supply with the population. That is credible for repeated workload sites, but less so in settings where inventory does not grow with recipients or each recipient faces a binding capacity constraint.

The case AGAINST (opponent, writing after the proponent)

The strongest objection is about what the proposed mirror buys. With a fixed stock of \(m\) one-off items, a continuum of recipients is a poor limit: assigning an item to a measure-zero set of people contributes nothing to per-capita welfare. Scaling supply with population avoids that collapse, but turns each paper item into a repeatable resource category. In a cloud setting, that is plausible only when sites can be treated as stable valuation types and the resource categories can be replicated in proportion to the population. Real capacity or compatibility constraints might matter, but they would need to be modeled rather than assumed away.

That objection does not survive a better version of the mirror. Keep two types of mass \(1/2\), give each category supply \(1/2\) per capita, and impose a limit of one unit of each category per recipient. Any one type can absorb a category’s full supply. For a set \(K\) of dimensions to attain their separate optima, every category’s supply must go only to types that maximize its value in every dimension in \(K\). Thus the dimensions are jointly attainable exactly when each category has a common maximizing type—the same condition used in the paper’s MAX-Intersect reduction. The paper’s Theorem 6 therefore appears to transfer, even with integral bundles and a per-person capacity.

One can object that this leaves the type masses doing little mathematical work, so the mirror may add less than a richer high-multiplicity model would. But that is a novelty or payoff concern, not a fundamental obstruction; and the programme treats hardness that survives continuization as a worthwhile boundary result. The paper has an explicit computational anchor, the continuum need not degenerate, and the proposed version has a credible repeated-allocation scenario. I cannot honestly defeat this anchor: the negative case is weak, and this mirror appears to survive.
