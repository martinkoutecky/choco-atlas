The continuous mirror question

Given a finite set of service-relevant value types \(\Theta\), rational type masses \(\mu\), an anonymous feasible correspondence \(\mathcal F(\mu)\) over type-level service probabilities, and black-box access to an algorithm \(\mathcal A\) returning feasible allocations on reported mass profiles, determine the optimal worst-case welfare-loss factor \(\lambda(\tau,L)\) achievable by a polynomial-\((\tau,L)\)-query transformation that preserves feasibility and makes a tagged agent’s expected service nondecreasing in its reported value at every fixed background mass profile. Welfare is \(W_\mu(x)=\sum_{\theta\in\Theta}\mu_\theta\theta x_\theta\), with each unit of mass receiving either a whole unit of service or none.

The model it lives in

A large anonymous service market represented by a rational distribution \(\mu\) over finitely many complete value types. The algorithm and transformation operate on type-level service probabilities; a tagged agent still receives a whole service unit, and its incentive constraint is evaluated with the background mass held fixed.

The objection that survived

Encoding the hidden sets \(V,S,T\) as anonymous types makes their membership visible to type-level queries, so the paper’s exponential hiding argument gives no lower bound for this model; the oracle must also formalize the allocation to a tagged agent whose report has zero mass.

fatal: False

What the mirror covers

The mirror covers the black-box TIE transformation lower bound in Theorem 3.1. It leaves the makespan result in Theorem 4.1 and the per-agent ironing results in Theorems 5.1 and 5.2 outside the computational mirror.

Open questions for a prover

  • For fixed support size, can anonymous type-level queries achieve a bounded welfare-loss factor, or is there an anonymous lower-bound family?
  • Can transformations that coordinate across types evade the loss bound that Theorem 5.1 proves for per-agent ironing?

The case FOR (proponent)

The lead is a high-multiplicity version of the paper’s black-box truthfulness question for social welfare. My strongest secondary case is narrower: the paper’s per-agent ironing lower bound has a natural mass-coupling mirror. Neither anchor is an NP-hardness theorem; both are computational impossibility results proved in this paper.

Lead — Theorem 3.1, proved here. It states that there is a constant \(c>0\) such that, for every polynomial-time TIE black-box transformation \(\mathcal T\), some social-welfare feasibility constraint \(\mathcal F\) and algorithm \(\mathcal A\) satisfy
\[ \frac{\operatorname{approx}_{\mathcal F}(\mathcal A)} {\operatorname{approx}_{\mathcal F}(\mathcal T(\mathcal A))}\ge n^c. \]
In other words, no such transformation preserves worst-case approximation up to a subpolynomial loss on every instance.

I would mirror it as Mass-Society TIE Repair for Social Welfare. Consider a large cohort of interchangeable households with private values in a finite set \(\Theta\), represented by rational masses \(\mu_\theta\). Within each value class, agents share the same preferences, costs, and eligibility. The action is a service rate \(x_\theta\): a fraction \(x_\theta\) of that class receives an indivisible unit of service. Since the population is nonatomic, these rates describe whole bundles assigned to fractions of a class, not fractional bundles for individuals. Welfare is \(W_\mu(x)=\sum_{\theta\in\Theta}\mu_\theta\theta x_\theta\).

An instance includes a feasible correspondence \(\mathcal F(\mu)\) over these rate vectors and a black-box allocation algorithm \(\mathcal A\) that returns feasible allocations for reported society profiles. A transformation sees \(\mathcal A\), but not \(\mathcal F\), and must return feasible allocations while making expected service nondecreasing in an individual’s report, holding the background mass profile fixed. The question is to characterize the smallest worst-case loss factor \(\lambda\) for a universal transformation running in time polynomial in support size \(\tau\) and encoding length \(L\). A solution would be such a transformation with a proved \(\lambda\), or a lower-bound family of anonymous mass instances ruling out better guarantees.

This is a sensible regime: a large service market can have millions of participants but only a few value classes. I expect the black-box repair problem to remain hard for continuum-specific reasons: the transformation must repair incentives while learning feasibility only through oracle outputs. The paper’s theorem does not establish this result for the mass model. It motivates the question.

Secondary — Theorem 5.1, proved here. For the objective \(\max \mathbb E_v[\sum_i h_i(x_i(v))v_i]\), the theorem says that if some \(h_i\) is continuous and superlinear or sublinear, then for every \(\epsilon\in(0,1)\) there is a value distribution and algorithm such that any per-agent ironing that preserves that agent’s value distribution and makes expected allocation monotone must violate the objective-preservation condition (P.3) by a factor of \(\Omega(1/\epsilon)\).

Its mirror is Continuum Per-Agent Ironing for Nonlinear Welfare. The input is a mass distribution \(\mu\) over agent values, an allocation rule giving each value class a lottery over whole- agent allocations, and a continuous increasing nonlinear objective \(h\). The decision variable is a measure-preserving remapping kernel \(K\) on value types: mass of true type \(v\) can be sent to reported type \(v'\), but the total mass of each reported type must remain \(\mu\). The remapped rule must have nondecreasing expected allocation in the true value, and the objective is to maximize \(\int v\,\mathbb E[h(X_{K(v)})]\,d\mu(v)\). A solution is a feasible kernel and its objective value, or a lower-bound certificate showing the best achievable value is small relative to the original rule.

The paper gives a concrete obstruction: with mass \(1-\epsilon\) at value \(0\) and mass \(\epsilon\) at value \(1\), it constructs an algorithm for which every such monotone, distribution-preserving remapping loses a factor \(\Omega(1/\epsilon)\). This lower bound carries to a continuum cohort by integrating the same per-agent construction over the population. It is a firm negative result for per-agent ironing; it does not rule out joint transformations across agents.

The main soft spot is the lead mirror’s anonymity requirement. Theorem 3.1’s construction uses hidden identity-specific sets \(S\) and \(T\). Making membership in those sets part of an agent’s type may increase \(\tau\), while omitting it would make supposedly identical agents behave differently in ways the problem uses. So the mass version is a genuine, narrower problem, not a consequence of Theorem 3.1. A useful next question is whether an anonymous, constant-support version still has a polynomial loss barrier—or whether aggregation makes truthfulness repair easier. I would not use Theorem 4.1 as another anchor: its single forbidden allocation is also tied to named machines, which creates the same type-compression problem.

The case AGAINST (opponent, writing after the proponent)

The strongest case against the lead is that Theorem 3.1’s obstruction is built from named coordinates and hidden identity sets \(V,S,T\). A faithful type must record membership in those sets, since membership changes feasibility and how the algorithm treats an agent. If that membership stays hidden among named agents, the type support grows with \(n\), so the construction has no high-multiplicity regime. If it is recorded in the types, there are only eight membership classes. Their masses and the algorithm’s responses can be explored with a constant number of type-level queries; the random hiding argument that drives the theorem no longer applies. A nonatomic model also needs care about incentives: an individual report changes no aggregate mass, so the model must separately specify the deviator’s allocation rate. These are substantial obstacles to carrying over Theorem 3.1, though they do not rule out a different lower bound for a carefully defined mass model.

Theorem 5.1 is harder to dismiss. Its proposed mirror has a natural two-class version: masses \(1-\epsilon\) and \(\epsilon\) at values \(0\) and \(1\), with a measure-preserving remapping kernel between the classes. The paper’s construction and loss bound translate directly to that setting; replicating the construction across identical agents scales the objective without changing the per-capita ratio. So the high-multiplicity version is a sensible object, and the paper supplies a strong result for it.

The negative case is that this secondary mirror offers little new computational landscape. Its core transformation is a coupling problem over value classes, and with the paper’s two-point construction it is a \(2 \times 2\) problem. More generally, finite-support kernels have only polynomially many variables in the support size, while the paper already establishes the central loss obstruction. That makes it a weak candidate for a new complexity project. But this is a claim about novelty and scope, not a fundamental objection to the mirror; the programme explicitly allows a useful result to be a discrete-to-mass identity or a known negative boundary.

I cannot honestly defeat the second anchor on the stated standard. The case against Theorem 3.1 is strong, but Theorem 5.1 has a coherent population interpretation and survives that case. The universal claim that no worthwhile continuous mirror exists is therefore weak on this paper.
