The case FOR (proponent)

The best honest mirror is an efficiency-certification problem for a population described by preference masses. The paper has no named NP-hardness result or theorem explicitly classifying a problem as polynomial-time solvable. Its strongest computational anchor is Theorem 4, proved in the paper: for each \(e\in\{\mathrm{sd},\mathrm{dl},\mathrm{ul}\}\), a feasible assignment \(\pi\) is \(e\)-efficient exactly when the relation \(\tau(R,\pi)\) is acyclic, where \(k\,\tau(R,\pi)\,\ell\) if some agent prefers \(k\) to \(\ell\) and receives positive probability of \(\ell\). Thus sd-, dl-, and ul-efficiency coincide. This is a structural theorem, rather than a printed complexity result; its polynomial-time consequence is inferred from the graph test.

A plausible regime is a large annual housing allocation: many applicants compete for the same number of single-capacity rooms, and applicants with the same complete ranking over rooms are indistinguishable for the allocation problem. If the cohort has \(n\) applicants but only \(\tau\ll n\) distinct rankings, type \(t\) has mass \(\mu_t\), its fraction of the cohort. Normalize total population mass to \(1\); each of the \(m=n\) rooms then has supply \(1/m\). The paper’s lotteries remain part of the assignment, while the society itself is represented by \(\mu\).

The lead question is Continuous Probabilistic Assignment Efficiency Certification. An instance gives \(m\) objects, a support \(S\) of \(\tau\) strict preference rankings, positive binary-rational masses \(\mu_t\) summing to \(1\), and a rational lottery \(q_t\) for each supported type. Each member of type \(t\) receives lottery \(q_t\), and feasibility requires
\[ \sum_{a\in A}q_t(a)=1 \quad\text{for each }t\in S, \qquad \sum_{t\in S}\mu_t q_t(a)=\frac1m \quad\text{for each }a\in A. \]
The question is whether this assignment is \(e\)-efficient: is there another feasible assignment \(q'\) that every supported type weakly prefers under extension \(e\), with at least one type strictly preferring it? There is no scalar objective; the task is to decide whether a Pareto improvement exists.

The expected answer is tractable. Form a directed graph on the objects, adding \(a\to b\) when some supported type prefers \(a\) to \(b\) and has \(q_t(b)>0\). The continuous analogue of Theorem 4 says the assignment is efficient exactly when this graph is acyclic, for each of the three extensions. A cycle is a witness of inefficiency; an acyclic graph certifies efficiency. Building the graph takes \(O(\tau m^2)\) comparisons and cycle detection is polynomial, so the decision procedure is polynomial in \(m,\tau\), and the total input bit length \(L\). Extending the theorem to this mass model is the prover’s task; the finite theorem supplies the anchor, not the completed continuum proof.

The mirror is close to the authors’ problem: it asks about ordinal efficiency in probabilistic assignment, with a larger society represented by repeated complete preference types and per-capita supplies. It covers Theorem 4’s efficiency characterization only. It does not mirror the paper’s strategy-proofness, no-envy, or generalized serial-rule results. Further questions include whether a serial rule can compute an efficient mass assignment in time polynomial in \(m,\tau,L\), and how incentive properties should be defined when one person’s report does not change the population distribution.

The weak point is substantial: the paper’s finite efficiency test is already polynomial, so this mirror does not show discrete hardness dissolving in a continuum. It offers a natural high-multiplicity formulation and a clean algorithmic characterization, but a modest ChoCo case rather than a hardness-boundary result.

The case AGAINST (opponent, writing after the proponent)

The strongest case against starts with a mismatch: this paper studies how preference extensions change axioms for probabilistic assignments. It does not study a computational problem or state a complexity result. Theorem 4 characterizes efficiency; it does not ask how to find an assignment, or analyze the complexity of checking one. So the proposed certification problem is a new computational question built from the theorem, rather than a mirror of a computational result in the paper.

That objection does not defeat the mirror. Efficiency certification is a natural task: given an assignment and a high-multiplicity society, determine whether a Pareto improvement exists. The proposed type model is coherent, and normalizing object supplies by population is an admissible co-modification. Nor does the finite theorem merely rely on named agents: its cycle argument is driven by preferences and positive allocations, which can be stated for types of positive mass.

In fact, Theorem 4 appears to carry over cleanly. Make an edge \(a\to b\) when some supported type ranks \(a\) above \(b\) and receives positive probability of \(b\). With finitely many objects and supported types, acyclicity can be checked in time polynomial in \(m\), \(\tau\), and the input length. Calling that result too easy, or noting that it does not use continuous-optimization machinery, would not be a sound objection under the programme’s criteria: a well-posed mirror still counts if its answer is straightforward.

The paper is therefore a weak ChoCo fit in a narrower sense: its contribution is axiomatic, and the continuous question is an algorithmic extension of that contribution rather than a complexity result the authors themselves pursued. But that leaves the proposed mirror standing. I cannot honestly make the universal negative case here; this anchor is a plausible, if modest, continuous computational question.
