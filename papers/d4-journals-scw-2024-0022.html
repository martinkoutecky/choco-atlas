The continuous mirror question

Given seller and buyer type sets \(I,J\), rational type masses \(\bar\mu_i,\bar\nu_j\), and nonnegative rational surpluses \(a_{ij}\), define \(W(x,y)=\max\{\sum_{ij}a_{ij}z_{ij}: z_{ij}\geq0,\ \sum_j z_{ij}\leq x_i,\ \sum_i z_{ij}\leq y_j\}\) for every coalition mass vector \((x,y)\in[0,\bar\mu]\times[0,\bar\nu]\). Do there exist per-capita payoff maps for all nonzero coalition mass vectors that satisfy exact efficiency, \(\sum_i x_i p_i(x,y)+\sum_j y_j r_j(x,y)=W(x,y)\), and payoff monotonicity whenever the coalition masses increase?

The model it lives in

Seller and buyer types carry masses and are specified by their market role and surplus pattern. For each coalition mass vector, the decision variables are type-level per-capita payoffs; feasibility requires exact assignment-worth allocation and monotonicity as masses increase. This is an existence problem with no optimization objective.

What the mirror covers

The mirror covers Theorem 9's PMAS-admissibility question. It leaves the finite block decomposition, the extension of every core allocation, Theorem 13's nucleolus and tau-value result, and the other finite results without separate continuous counterparts.

The case FOR (proponent)

The strongest honest mirror is *Mass-PMAS Recognition for Assignment Markets*. Consider a large one-to-one placement market: one side consists of single-seat positions, the other of applicants, and \(a_{ij}\) is the surplus from matching position type \(i\) with applicant type \(j\). A type specifies the agent’s full pattern of match surpluses. The regime is many positions and applicants but relatively few such types; a type’s mass \(\mu_t\) is its fraction of the population.

For coalition masses \(q=(x,y)\), define its worth by fractional matching: \(\nu(q)\) is the maximum of \(\sum_{ij}a_{ij}z_{ij}\), over \(z_{ij}\geq0\) with \(\sum_jz_{ij}\leq x_i\) and \(\sum_iz_{ij}\leq y_j\). The continuous problem is: given rational type masses and a nonnegative rational surplus matrix, decide whether there is a population-monotonic allocation scheme for every coalition mass vector \(q\) in the box \([0,\mu]\). A scheme assigns each type present in \(q\) a per-capita payoff \(p_t(q)\), satisfies \(\sum_t q_t p_t(q)=\nu(q)\), and has \(p_t(q)\leq p_t(q')\) whenever \(q\leq q'\) and \(q_t>0\). A solution is such a payoff map, or a proof that none exists. This asks about the same object as the paper—whether assignment-game worth can be allocated monotonically as the population changes—while making population mass the continuous quantity.

My lead anchor is Theorem 9, proved in this paper. It says that an assignment game admits a PMAS exactly when, after row and column permutations, its surplus matrix is block diagonal with every block supported on a single row, a single column, or a \(\Gamma\)-shape with a dominant corner; equivalently, the game decomposes into assignment games with a veto player or a dominant veto mixed pair. It also says that, whenever the game admits a PMAS, every core allocation extends to one. The paper presents this as an efficiently verifiable characterization, so it gives a polynomial-time recognition result for the finite problem; the theorem itself does not state a formal running-time bound or complexity class.

For the mass problem, I expect a sharper negative answer than that finite classification suggests. If any active seller type \(i\) and buyer type \(j\) have \(a_{ij}>0\), split a small amount of each type’s mass into two equal chunks. Restrict a proposed type-level scheme to coalitions formed from those four chunks. Homogeneity of matching worth then gives a PMAS for the corresponding four-player assignment game, whose \(2\times2\) surplus matrix has all entries positive. Theorem 2, citing Sprumont (1990), says such an assignment game has no PMAS. Thus the continuous problem should have no solution whenever there is any positive-surplus edge between types of positive mass. If there is no such edge, the game has zero worth and the zero-payoff scheme works. This yields a trivial polynomial-time decision test, with a transferred nonexistence obstruction rather than a hardness result. It also predicts that Theorem 9’s interesting positive cases largely disappear once a type can contain arbitrarily divisible population.

The weakest point is that this continuous version requires type-anonymous per-capita payoffs. That fits a mass model in which agents of a type are indistinguishable, but the original paper permits allocations to named individuals. More substantively, the proposed mirror seems to erase the finite theorem’s positive cases: a single row is a single veto player in the paper, while a positive mass of that row type contains enough agents to recreate the four-player obstruction. So this is a credible mirror of the paper’s *PMAS-admissibility question*, not a claim that its main structural classification survives continuization.

The case AGAINST (opponent, writing after the proponent)

The proposed mirror is well-posed, and its four-chunk obstruction is sound. That is the strongest case against Theorem 9 as a worthwhile continuous mirror: exact population monotonicity over *all* subpopulations makes its defining positive cases collapse.

Suppose supported types \(i\) and \(j\) have \(a_{ij}>0\). Split each type’s mass into two equal chunks of size \(\delta>0\). A scheme defined for every mass vector must also work for every coalition formed from those four chunks. Restrict it to those coalitions and treat each chunk’s total payoff as one player’s payoff. Efficiency and monotonicity give a PMAS for a four-player assignment game whose \(2\times2\) surplus matrix has every entry \(a_{ij}>0\), contradicting the nonexistence result cited as Theorem 2. The same argument works if payoffs can differ within a type: integrate each chunk’s payoffs. Thus a positive-mass veto type cannot play the role of the paper’s single veto player, and a positive-mass veto pair cannot preserve its special status either. They can be split into clones.

Consequently, the exact mass-PMAS question has only the zero-worth case: if any supported pair has positive surplus, no scheme exists; if none does, the zero-payoff scheme works. That is a straightforward matrix check, but the deeper objection is that the characterization’s building blocks are indivisible pivotal agents. In a divisible population, even an arbitrarily small clone can participate in a forbidden \(2\times2\) obstruction. The theorem’s structural landscape does not survive as a landscape over population types.

The natural repairs change the object. Treating each type as an indivisible bloc removes the intermediate population sizes that make this a continuous PMAS question. Keeping a unique pivotal individual gives that person vanishing population mass, unless identities proliferate with population size and high multiplicity is lost. Restricting the scheme to a single proportional growth path also drops the paper’s requirement across all coalitions.

So I would reject this as a promising mirror of Theorem 9, while conceding that the authors might recognize the formal mass question as theirs. The negative case is limited: it does not rule out other worthwhile continuous questions about assignment games, or approximate variants of PMAS. It shows that the most faithful exact population continuization of this particular anchor is dominated by a clone obstruction, rather than opening the kind of structural or algorithmic landscape the paper develops.
