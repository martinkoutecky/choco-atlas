The continuous mirror question

Given a connected network type graph \(H=(T\cup\{s\},E)\), nonnegative rational edge costs \(w\), positive rational masses \(\mu_t\) with \(\sum_{t\in T}\mu_t=1\), and nonnegative per-unit allocations \(a_t\), with \(\sum_{t\in T}\mu_t a_t=\operatorname{MST}_H(T\cup\{s\})\), does there exist a mass vector \(y\) with \(0\le y_t\le\mu_t\) such that, for \(A=\{t:y_t>0\}\), \(\sum_{t\in T}a_t y_t>\operatorname{MST}_{H[A\cup\{s\}]}(A\cup\{s\})\)?

The model it lives in

A continuum of residents grouped into network-location types, each with mass \(\mu_t\) and per-unit allocation \(a_t\). A coalition selects mass \(y_t\) from each type; every selected type activates its location, and the coalition pays the fixed edge costs of a minimum spanning tree connecting those locations to the source. The question is whether some coalition has aggregate allocation exceeding that connection cost.

What the mirror covers

The mirror covers only the 2-apex NP-hardness result; it leaves the paper’s other hardness results, parameterized algorithms, and kernelization results aside.

The case FOR (proponent)

The strongest anchor is the paper’s theorem thmnphtwoapex. It states that \(\textsc{MSTGcore}\) is NP-hard even when the input graph is 2-apex—deleting at most two vertices makes it planar—and the allocation satisfies the efficiency condition. The paper proves this by reducing from Vertex Cover on 3-regular planar graphs; that source problem’s hardness is cited. The supplied transcription omits the theorem’s displayed numeral, so I’m identifying it by its exact source label rather than guessing one.

A plausible setting is a large population of residents or customers served through a small set of shared network locations. A type specifies a location, its per-capita allocation, and its network access and costs. Thus everyone of a type is interchangeable, while connecting a location to the network incurs a shared fixed cost. The population can be much larger than the number \(\tau\) of types: for example, there can be \(K\) residents at each of \(\tau\) locations, with \(K\) large. A coalition may include any fraction of a location’s residents; once that fraction is positive, the location must be connected.

Call the mirror Continuous Location-Core Recognition. Its input is a connected type graph \(H=(T\cup\{s\},E)\), nonnegative rational edge costs \(w\), a positive rational mass \(\mu_t\) for each type with \(\sum_{t\in T}\mu_t=1\), and a nonnegative rational per-unit allocation \(a_t\). The supply vertex \(s\) has zero allocation. Require efficiency: \(\sum_{t\in T}\mu_t a_t=\operatorname{MST}_H(T\cup\{s\})\). The question is whether there are selected masses \(y_t\in[0,\mu_t]\) such that, writing \(A=\{t:y_t>0\}\),
\[ \sum_{t\in T} a_t y_t > \operatorname{MST}_{H[A\cup\{s\}]}(A\cup\{s\}). \]
A solution is such a mass vector and a minimum spanning tree witnessing the right-hand cost. This asks whether some measurable population coalition can block the allocation by connecting its occupied locations to the supply.

The hardness transfers exactly. Take the paper’s efficient 2-apex instance \((G',s,x,w)\), and let \(q=|V(G')\setminus\{s\}|\). Make each non-source vertex \(v\) a type with \(\mu_v=1/q\) and \(a_v=q\,x(v)\), keeping the graph and edge costs. Then the full mass of type \(v\) carries aggregate allocation \(x(v)\), so efficiency is preserved. A discrete blocking coalition gives a continuous one by selecting full mass at its vertices. Conversely, if a continuous coalition blocks, fill every selected type to its full mass: this does not change the locations that must be connected and can only increase the allocation. That yields a discrete blocking coalition. The continuous problem is therefore NP-hard even on 2-apex type graphs with efficiency. Its expected classification is hardness transfers: the reduction’s combinatorics live in the type graph, so representing each role by a large cohort does not remove the choice problem.

This mirror covers only the paper’s 2-apex hardness result. It does not claim to continuize the paper’s other hardness, parameterized algorithms, or kernelization results. It raises a useful follow-up: if individual access costs scale with selected mass instead of being shared fixed costs, does fractional participation change the complexity?

The weak point is that the model treats each type as a shared network location: the cost depends on whether the type has positive mass in the coalition, not on how much mass participates. With nonnegative allocations, filling a selected type to its full mass is always at least as good, so fractional selection itself does not create the hardness. That is a deliberate, plausible feature of fixed-cost network sharing, and it preserves the MST core-blocking question. But authors or referees who require every individual to be a separate network terminal, with person-level access costs, may judge this location-based model to be too much of a co-modification.

The case AGAINST (opponent, writing after the proponent)

The strongest objection to the proponent’s \(\textsc{thmnphtwoapex}\) mirror is that its continuous decision variable disappears. In their location model, the coalition cost depends only on which types have positive mass. Given any blocking vector \(y\), fill every selected type to its full mass: set \(\hat y_t=\mu_t\) when \(y_t>0\), and \(0\) otherwise. The network cost stays the same, while the allocation weakly increases because \(a_t\ge 0\). Thus blocking is equivalent to choosing a subset \(A\) of locations satisfying
\[ \sum_{t\in A}\mu_t a_t > \operatorname{MST}_{H[A\cup\{s\}]}(A\cup\{s\}). \]
That is exactly the paper’s finite \(\MSTGcore\) question on the type graph, with allocation \(x(t)=\mu_t a_t\).

This is not an objection that hardness survives: the population coordinate itself has vanished. Any positive mass, however small, activates a location and incurs the same fixed connection cost; a large cohort and an arbitrarily small subcohort are indistinguishable to the blocking test. Replicating \(K\) residents at each location therefore changes the population count without changing the problem. The 2-apex theorem’s combinatorics remain entirely in the unbounded type graph, while the mass values merely rescale the original allocations. I would not spend ChoCo’s effort presenting this as a continuous computational landscape.

Charging network costs in proportion to selected mass would make fractions matter, but it changes the cost game. In a simple per-person path-cost version, blocking can reduce to checking whether some type has positive per-unit surplus. To recover interactions between types, one needs additional structure such as capacities or shared charges; that may define an interesting new network game, but the paper’s 2-apex result no longer anchors its complexity.

This is a case for rejecting the proposed mirror as a *population-continuum contribution*, not a proof that no useful variant exists. The weak point is real: shared fixed-cost infrastructure at locations is plausible, and ChoCo permits type-level common costs. If the authors accept that interpretation, they may regard the immediate discrete–continuous equivalence as a useful high-multiplicity dictionary result. I cannot honestly rule that out; the negative case rests on the fact that fractional population never affects the question in this model.
