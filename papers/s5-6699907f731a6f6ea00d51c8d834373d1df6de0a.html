The continuous mirror question

Given finite type sets \(X,Y\) with rational masses \((\alpha_x)_{x\in X}\) and \((\beta_y)_{y\in Y}\), each summing to \(1\), and one-world values \(v^A_{xy},v^B_{yx}\) and principal utilities \(u_{xy}\), compute a maximum-utility stable flow \(q\). The flow satisfies \(q_{xy}\ge 0\), \(\sum_y q_{xy}=\alpha_x\), and \(\sum_x q_{xy}=\beta_y\). It is stable if for each \((x,y)\), at least one of \(\sum_{y':\,v^A_{xy'}<v^A_{xy}}q_{xy'}\) and \(\sum_{x':\,v^B_{yx'}<v^B_{yx}}q_{x'y}\) is zero. Maximize \(\sum_{x,y}q_{xy}u_{xy}\), with the number of types allowed to vary.

The model it lives in

An atomless population on each side, represented by finite type sets and rational type masses. The decision variable is a nonnegative type-flow \(q\) with the prescribed row and column masses; each individual still receives one partner, and positive masses on both sides cannot form a blocking pair. The objective is total principal utility, \(\sum_{x,y}q_{xy}u_{xy}\).

What the mirror covers

The mirror covers the one-world public stable-matching problem with variable type support; Theorem 4.6 supplies the constant-type tractable case. It leaves the paper’s other multiworld and private-persuasion results outside this mirror.

Open questions for a prover

  • Does allowing type cohorts to split make maximum-utility stable flow tractable, or can variable type support still encode computational hardness?
  • What approximation guarantees are meaningful when welfare is normalized per capita?

The case FOR (proponent)

My lead is a public mass stable-persuasion problem, mirroring Theorem 3.5. Its hardness is the important question for the continuization programme: does the difficulty of choosing a stable matching survive when the population is a distribution over types and assignments can be split across mass?

Take finite type sets \(X\) and \(Y\) on the two sides. A type is a complete description for this problem: its members have the same value for every opposite-side type in each world, and the principal’s utility for a pair depends only on the pair of types and the world. Each side has rational type masses summing to \(N\), so the normalized masses describe its population distribution. The instance also gives a finite world set \(\Omega\), a rational prior, agents’ type-level values \(v^A_{xy\omega}\) and \(v^B_{yx\omega}\), and principal utilities \(u_{xy\omega}\).

A matching is a nonnegative type-flow matrix \(q\) whose row and column sums equal the respective type masses. It is an aggregate matching: an atomless cohort can be divided into subcohorts to realize the flows, while each individual is still matched to one partner. A public policy assigns probabilities \(\pi(g,q\mid\omega)\) to a public message \(g\) and a publicly announced type-flow \(q\), conditional on the realized world. The posterior \(p\) after \((g,q)\) is computed by Bayes’ rule. Under that posterior, \(q\) must be stable: for every pair \(x,y\), it cannot be that positive mass of \(x\) is matched below \(y\) in \(x\)’s ranking and positive mass of \(y\) is matched below \(x\) in \(y\)’s ranking. These rankings come from expected type values under \(p\), and ties do not count as strict preference, matching the paper’s stability notion. The objective is to maximize
\[ \sum_{\omega,g,q}\lambda_\omega\pi(g,q\mid\omega) \sum_{x\in X,y\in Y}q_{xy}u_{xy\omega}. \]
The solution is an optimal finite-support public policy, with each supported flow stable under the posterior it induces.

Theorem 3.5, the lead anchor, states that assuming \(P\ne NP\), no efficient algorithm computes a \(1/n^{1-\epsilon}\)-approximation to an optimal public policy, for any constant \(\epsilon>0\), even when \(|\Omega|=1\). The paper explicitly rephrases Iwama et al. (1999, Theorem 2); this hardness is cited, not proved there. In the one-world slice of the mass problem, the signal has no informational role: the question is to find a maximum-utility stable type-flow. That is a concrete continuous counterpart to weighted stable matching with ties, not a continuation of outcome space or of time.

For this unrestricted-support problem, my expectation is hard for continuum-specific reasons (Class C), though the theorem does not establish that. Its finite hardness cannot simply be carried over: a continuum type cohort can split across partners, which can change the optimum. A proof would need to show that the pairwise blocking conditions still encode hard choices over type flows. They are disjunctive—one side or the other must have no mass strictly preferring the proposed pair—so allowing fractional masses does not obviously make the problem an LP. I would hand a prover the exact optimization problem above and ask whether it is tractable or hard when the number of types varies. Further questions include whether hardness persists when \(N/|X\cup Y|\) grows, whether fixed type support is a tractable boundary, and what approximation guarantees make sense after normalizing welfare per capita. The theorem’s \(n\)-dependent approximation ratio is an anchor about the discrete problem; it does not automatically become a meaningful ratio for a population whose mass scale can be normalized.

A second, more secure mirror is the few-type public mass stable-persuasion problem, the same optimization problem restricted to a constant number \(T\) of types on each side. Theorem 4.6, proved in this paper, says that an optimal policy can be computed in \(\operatorname{poly}(|\Omega|,\log n)\) time when \(T\) is constant. In the paper’s type-based model, type sizes are binary encoded, so \(n\) can be exponentially large in the representation. This is a direct tractability result for large cohorts sharing complete value descriptions. For rational mass inputs of bit length \(L\), I would expect a corresponding \(\operatorname{poly}(|\Omega|,L)\)-time algorithm for fixed \(T\): clear denominators to obtain integer cohort sizes, then use the paper’s finite-dimensional type-flow and policy construction. This is Class A. A prover could be asked to establish that algorithmic bound for the stated mass-policy problem and give an explicit translation in both directions between rational-mass policies and the paper’s succinct type-count policies.

The setting is credible in large centralized matching markets. For example, students can be grouped by a limited set of academic and interest profiles, and seats by institution or program type. Many students and seats share each description, so the total population can greatly exceed the number of types. A platform may observe a market condition—such as funding or demand—before publicly signaling and recommending a match. The paper itself introduces type-based matching, describes exponentially many agents by binary type sizes, and proves Theorem 4.6. That existing high-multiplicity work supports the premise that the regime is sensible; it does not make the mass question a novelty collision. The type-flow matrix is a co-modification forced by the population model: it records fractional aggregate quantities while every individual receives an ordinary partner.

The scope here is the paper’s public optimal-policy problem, especially its single-world hardness anchor and its few-agent-types algorithm. I would not claim these mirrors cover the private-persuasion results or every general multi-world result.

The weakest point is the gap between the two regimes. The paper’s few-type result gives a compelling high-multiplicity case, but the hardness-bearing regime may require the number of distinct types to grow with the instance. If that growth is nearly as fast as the population, the proposed hardness question has a weaker large-market motivation. And if the hard combinatorics vanish as soon as each type cohort can split, Theorem 3.5 will not save the continuum problem. That is precisely why the unrestricted-support mass-flow problem is the lead: it is a specific, author-recognizable computational question, and its answer would locate a real boundary for continuization.

The case AGAINST (opponent, writing after the proponent)

The strongest case against is that the two anchors do not support the same claim.

For Theorem 4.6, the proposed fixed-type mass problem is already solved by the paper’s succinct type-count model. Given rational type masses, multiply by a common denominator \(D\) to obtain integer cohort sizes. A rational type-flow then scales to a finite matching; on each fixed support pattern, the relevant transportation polytope has integral vertices. Stability is unchanged by scaling, and the policy optimization has rational data. Thus the theorem’s algorithm covers this mass problem in \(\operatorname{poly}(|\Omega|,L)\) time for constant \(T\). A continuous formulation could make that equivalence explicit, but it would not pose a missing computational problem. Under ChoCo’s rules, this is not a reason to reject the mirror: the identity itself may be a useful result. It does, however, make this anchor a weak case for a new research target.

For Theorem 3.5, the paper’s hardness result does not establish hardness for aggregate flows. The mass model permits a type cohort to split among partners, and stability is defined by whether positive mass on both sides can block. That changes the feasible set; discrete WSM hardness cannot simply be carried over. The best case against is that the fixed-support regime with genuine large cohorts is already tractable by Theorem 4.6. To retain the hardness anchor, the number of complete types must grow with the instance. Then the hard instances may consist mostly of vanishingly small cohorts, so the link to a large market with repeated agents is less convincing. But this is a concern about the application regime, not a fundamental obstruction: growing type support can still describe a society, and whether splitting removes the hardness is exactly a worthwhile computational question.

The private results are a weaker target for mass aggregation because the paper shows that agents of the same type may need different signals. The proponent avoids that issue by limiting the claim to public persuasion.

So the best negative case is narrow: Theorem 4.6’s mirror largely restates an algorithm already in the paper, while Theorem 3.5 gives no direct evidence about the continuous flow problem. That does not defeat the stronger public mass-flow question. Under the programme’s own standards, I cannot make an honest case that no worthwhile continuous mirror exists; this negative case is weak.
