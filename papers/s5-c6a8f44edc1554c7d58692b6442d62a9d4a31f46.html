The continuous mirror question

Given candidates \(C\), committee size \(k\), a finite complete type set \(T\), rational distribution \(\mu\), rational valuations \(v_t\in\mathbb{Q}_{\geq 0}^{C}\), and \(W\in\binom{C}{k}\), decide whether there exists \(\mathbf{p}\in[0,1]^C\) with \(\sum_{c\in C}\mathbf{p}(c)=k\), \(u_t(\mathbf{p})\geq u_t(W)\) for every \(t\in\operatorname{supp}(\mu)\), and strict inequality for some supported type; equivalently, decide whether \(W\) is not \(\mu\)-\(\mathrm{fPO}\), outputting \(\mathbf{p}\) when dominated and a positive supporting type-weight vector \(\lambda\) when it is \(\mu\)-\(\mathrm{fPO}\). The weak variant replaces the last condition by strict improvement for every supported type and permits nonnegative \(\lambda\).

The model it lives in

Types are complete valuation vectors \(v_t\), carrying masses \(\mu_t\); the decision variable is the paper's fractional committee \(\mathbf{p}\), and the verification LP uses type-level improvements \(\varepsilon_t\) with objective \(\sum_{t\in\operatorname{supp}(\mu)}\mu_t\varepsilon_t\). A positive certificate is \(\lambda\in\Delta^+(\operatorname{supp}(\mu))\) satisfying \(\sum_t\lambda_t v_t(c)\geq\sum_t\lambda_t v_t(c')\) for all \(c\in W\) and \(c'\notin W\); the weak case allows \(\lambda\geq 0\). The intended running time is polynomial in \(m\), \(\tau=|T|\), and the encoding length, rather than the expanded population size.

The objection that survived

The strongest residual objection is that the numerical values of \(\mu\) are computationally inert and duplicate-row deduplication already gives the same smaller LP, so the mirror may add little beyond an encoding change. This bounds the contribution and rules out a claim of hardness dissolution, but it does not make the high-multiplicity problem ill-posed.

The case FOR (proponent)

The strongest honest positive case is a high-multiplicity mirror of the paper’s verification problem. It is a modest Class A mirror rather than a new hardness-dissolution result, but it is mathematically exact and clearly population-continuous.

The anchor is the paper’s named Theorem \(\mathrm{ComputabilityFPO}\). The supplied text exposes its restatable label rather than a numerical theorem number, so I quote that label rather than inventing a number. The theorem is proved in this paper. Its full content is:

Given an instance \(I\) and committee \(W\), verifying (weak) fractional Pareto-optimality can be done in polynomial time. Moreover, if \(W\in\fPO(I)\) (respectively \(W\in\wfPO(I)\)), a strictly positive weight vector \(\weight\in\Weights^+\) (respectively non-negative \(\weight\in\Weights\)) supporting \(W\) can be computed in polynomial time.

I would not use the paper’s coNP-hardness statement for ordinary \(\PO\) as an anchor: the table marks it with \(\dagger\), and the result is attributed to Aziz and Monnot rather than proved as a numbered result here.

My mirror is Continuous-Population Fractional-Pareto Verification.

An instance consists of candidates \(C\), committee size \(k\), a finite set \(T\) of complete voter types, a rational distribution \(\mu\in\mathbb{Q}_{\geq 0}^{T}\) with \(\sum_{t\in T}\mu_t=1\), and a proposed committee \(W\subseteq C\) of size \(k\). A type \(t\) is either an approval set \(A_t\subseteq C\), or more generally a complete valuation vector \(v_t\in\mathbb{Q}_{\geq 0}^{C}\). Thus \(\mu_t\) is the fraction of society having exactly that approval set or valuation vector.

The paper’s fractional committee remains exactly the same object: a vector \(\p\in[0,1]^C\) with \(\sum_{c\in C}\p(c)=k\). It is not the population being continuized; it is still the paper’s comparison object. Define

\[ u_t(W)=\sum_{c\in W}v_t(c) \quad\text{and}\quad u_t(\p)=\sum_{c\in C}v_t(c)\p(c). \]

We say that \(\p\) \(\mu\)-fractionally Pareto-dominates \(W\) if

\[ u_t(\p)\geq u_t(W) \]

for every type with \(\mu_t>0\), and the inequality is strict for a positive-mass set of types. Since \(T\) is finite, this means strict inequality for at least one type in \(\operatorname{supp}(\mu)\). The proposed committee is \(\mu\)-\(\fPO\) if no such \(\p\) exists. The weak version requires \(u_t(\p)>u_t(W)\) for every type in \(\operatorname{supp}(\mu)\).

The problem asks whether \(W\) is \(\mu\)-\(\fPO\) or \(\mu\)-\(\wfPO\). A negative certificate is a fractional committee \(\p\) witnessing domination. A positive certificate is a supporting type-weight vector \(\lambda\), with \(\lambda_t>0\) for \(\fPO\) and \(\lambda_t\geq 0\) for \(\wfPO\), satisfying

\[ \sum_{t\in T}\lambda_t=1 \]

and

\[ \sum_{t\in T}\lambda_t v_t(c) \geq \sum_{t\in T}\lambda_t v_t(c') \]

for every \(c\in W\) and \(c'\notin W\). If desired, write \(\lambda_t=\mu_t\rho_t\), where \(\rho_t\) is a per-capita influence density and \(\sum_t\mu_t\rho_t=1\).

This is a genuine high-multiplicity regime. Think of a large public consultation over a fixed menu of projects: millions of residents, but only \(\tau\) recurring approval or valuation profiles induced by demographic groups, institutional constituencies, or standardized survey responses. The natural regime is \(n\gg\tau\), with each type appearing many times. A type is a complete description for this problem, exactly as required by the high-multiplicity interpretation: voters with the same type are indistinguishable for every utility comparison the paper makes.

The finite-to-continuous dictionary is exact. If \(n_t\) named voters have type \(t\), set \(\mu_t=n_t/n\). Then

\[ W\in\fPO(I) \quad\Longleftrightarrow\quad W\in\fPO_\infty(\mu,k), \]

and likewise for \(\wfPO\). Conversely, a rational \(\mu\) can be expanded into a finite profile using a common denominator. This is not merely an analogy: duplicate rows in the paper’s valuation matrix can be replaced by their masses without changing any Pareto comparison.

The continuous problem is tractable. For \(\fPO\), solve

\[ \max \sum_{t\in T}\mu_t\varepsilon_t \]

subject to

\[ u_t(\p)\geq u_t(W)+\varepsilon_t \quad\text{for all }t\in\operatorname{supp}(\mu), \]

\[ \sum_{c\in C}\p(c)=k,\qquad 0\leq \p(c)\leq 1,\qquad \varepsilon_t\geq 0. \]

The optimum is positive exactly when \(W\) is not \(\mu\)-\(\fPO\). For \(\wfPO\), maximize a common \(\varepsilon\) subject to \(u_t(\p)\geq u_t(W)+\varepsilon\) for every supported type. The supporting-weight certificate is obtained from the corresponding score-separation LP. The running time is polynomial in \(m\), \(\tau\), and the encoding length of \(\mu\) and the valuations, rather than in the expanded number \(n\) of voters.

The authors should recognize this as their problem because nothing substantive has been removed: the same committees, same additive utilities, same fractional comparison set, and same Pareto quantifiers remain. Only repeated voters have been represented by masses. The mirror also respects the paper’s central weighted-utilitarian characterization: identical voters can have their individual certificates aggregated into a positive total weight \(\lambda_t\), and any such type weight can be distributed among the voters of that type.

The main weakness is that \(\mu_t\) affects the \(\fPO\) decision only through whether it is zero. That is not an accidental defect: ordinary Pareto optimality is invariant under duplicating voters, so making population shares affect the dominance relation would change the paper’s question into a welfare or majority notion. Still, this makes the mirror less dramatic than the programme’s bribery examples: it demonstrates exact high-multiplicity compression and a continuous population model, but it does not show discrete computational hardness disappearing.

The mirror covers Theorem \(\mathrm{ComputabilityFPO}\), including both verification and succinct supporting certificates. It does not claim to continuize the paper’s fractional outcome space, candidate cloning, or axiomatic results. Natural follow-up questions would be whether continuous-population verification of ordinary \(\PO\) remains coNP-hard as a function of \(\tau\), and whether type distributions given implicitly by a geometric or probabilistic model create a genuinely new separation problem.

The case AGAINST (opponent, writing after the proponent)

The proponent’s anchor is the paper’s Theorem \(\mathrm{ComputabilityFPO}\), but its proposed mirror is not genuinely a continuous-population problem. The decisive fact is that Pareto dominance is invariant under duplicating voters.

Let \(S(\mu)=\{t:\mu_t>0\}\). The proposed \(\mu\)-\(\fPO\) condition is exactly

\[ \not\exists \p\in\Probs: \quad u_t(\p)\ge u_t(W)\ \text{for every }t\in S(\mu), \quad u_t(\p)>u_t(W)\ \text{for some }t\in S(\mu). \]

The numerical values of the masses never appear. Societies with distributions \((0.999,0.001)\) and \((0.001,0.999)\) have identical \(\fPO\) committees whenever their supports coincide. A type with mass \(10^{-100}\) has exactly the same veto power as a type with mass \(0.5\), while at mass \(0\) it disappears entirely. Thus the simplex of population distributions collapses into support strata; there is no population quantity being optimized, approximated, or algorithmically exploited.

The same defect affects the proposed LP. Maximizing

\[ \sum_t \mu_t\varepsilon_t \]

only tests whether some supported type has \(\varepsilon_t>0\). Any strictly positive coefficients would give the same answer. The supporting certificate has the identical problem: arbitrary positive type weights \(\lambda_t\) are allowed. Writing \(\lambda_t=\mu_t\rho_t\) does not restore population meaning, because unrestricted densities \(\rho_t\) simply cancel the masses. If one instead fixes \(\lambda_t=\mu_t\), the certificate becomes average-utility maximization and is no longer equivalent to the paper’s \(\fPO\) characterization.

This is not an objection to high multiplicity in general. High-multiplicity voting is a sensible regime, and it often changes the algorithmic representation. Here, however, the paper’s finite problem already admits the same compression: delete duplicate valuation rows and retain one constraint per distinct type. The proposed result is therefore a row-deduplication observation about an already polynomial-time LP, not a continuous-population complexity question. The fractional committee remains the only substantive continuous object, but that object is already central to the paper.

The strongest possible repair would use a genuinely nonatomic type space and define domination almost everywhere:

\[ u_v(\p)\ge u_v(W)\quad\text{for }\mu\text{-almost every }v, \]

with strict improvement on a positive-measure set. But that is no longer the paper’s Pareto notion. It discards every measure-zero voter, whereas one named voter is fully consequential in the finite model. It also makes the answer depend primarily on the essential support of \(\mu\), not on population shares. What remains is a new semi-infinite or robust-optimization problem over a type domain, not a high-multiplicity mirror of \(\mathrm{ComputabilityFPO}\).

The alternatives leave no useful middle ground: pointwise domination makes \(\mu\) irrelevant; almost-everywhere domination changes the axiom; weighting improvements by mass changes Pareto efficiency into welfare optimization. Hence the proposed anchor does not survive as a worthwhile continuous-population mirror. The negative case is weaker only against a broader, newly invented study of measure-theoretic “essential fractional Pareto-optimality”; that could be interesting, but it would be a new problem rather than a continuization of this paper’s computational result.
