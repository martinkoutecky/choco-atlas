What the mirror covers

No continuous mirror covers a named computational result; Theorem 1 and its supporting propositions and lemmas establish an implementation equivalence.

The case FOR (proponent)

There is no eligible computational anchor in this paper. Its main named result, Theorem 1 (proved here), says that for every finite discrete partition-function game, the recursive core \(C(N,v)\) equals the set \(SQPP(N,v)\) of partitions produced by stationary quasi-perfect equilibria of the modified sequential coalition-formation game. That is an implementation equivalence, not a result that a computational problem is in P, NP-hard, FPT, or otherwise computationally classified. Proposition 2 and Lemmas 3–4 are proof components, not such classifications either.

The nearest positive lead would be a different question: in a large organization with finitely many member types, let \(\mu_t\) be each type’s share, and describe coalitions by their type-mass composition. One could ask whether recursively stable mass partitions coincide with outcomes of an anonymous stationary coalition-formation process. But the paper supplies neither a payoff representation for continuum coalition structures nor a continuum version of its ordered, individual-proposer process. That extension would be a new implementation question, not a continuous computational mirror of a named result here.

The paper’s breadth—Theorem 1 covers arbitrary finite games, including games with empty residual cores—makes it an interesting starting point for that extension. The weak point is decisive for this assignment: without a named computational result to anchor, there is no defensible per-anchor continuous problem or predicted complexity outcome to hand to a prover.

The case AGAINST (opponent, writing after the proponent)

The strongest case against a mirror starts with the missing anchor: Theorem 1 identifies the partitions in the recursive core with those produced by stationary quasi-perfect equilibria for every finite discrete partition-function game. It proves an implementation equivalence; it gives no complexity classification or algorithmic result. Proposition 2 and Lemmas 3–4 support that equivalence. A continuous version of the theorem would therefore ask for another implementation result, not the computational question this programme is set up to chart.

The proponent’s best rescue is a large organization with finitely many interchangeable member types. One could represent coalitions by type masses and ask whether a recursive core of mass partitions matches outcomes of an anonymous stationary coalition-formation process. That is a coherent research direction, but the paper does not specify the ingredients it needs. Its payoff function is arbitrary over partitions of named players, including residual partitions. A mass model needs a payoff rule over measurable coalition structures, payoffs for infinitesimal members, and enough structure to make the solution well-defined. The sequential game also gives individual players turns in an order. In an atomless population, an individual proposer has zero mass; giving proposal power to a positive-mass bloc or committee adds an institutional feature. The resulting implementation question would depend on those new choices.

A computational version could ask whether a recursive core exists, or how to find one, for typed mass games. Its difficulty would depend on how the payoff function is represented and constrained—details absent from this paper. That could become a worthwhile project in its own right, but it would not be a computational mirror of a result here.

This is a strong reason to reject the paper as an anchored ChoCo mirror. I cannot honestly make it a proof that no plausible scenario could ever support worthwhile continuous computational work: a carefully specified typed coalition model might. The narrower negative verdict is firmer: the paper itself provides no computational result to mirror, and its natural continuous extension is presently an analytic implementation problem whose computational form would require substantial new modelling.
