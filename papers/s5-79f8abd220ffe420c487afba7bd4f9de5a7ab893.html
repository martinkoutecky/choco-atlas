The case FOR (proponent)

The strongest positive premise is a large R&D consortium or scientific collaboration: many firms or labs could fall into a small number of types, with each type fixing its stand-alone surplus and its link-related payoff parameters. A continuous population would let us describe the share of each type. But the paper’s problem also depends on the exact network of bilateral links and their bargaining order. Encoding each agent’s exact neighborhood in its type could make the number of types grow with the population; replacing that graph with a type-level link density or graphon would add a modeling choice the paper does not make.

The paper has named results, but none is a computational-complexity result of the kind required for a ChoCo anchor. The nearest is Theorem 4.1, proved here: for a link-convex value function and any graph, the bargaining procedure has a unique subgame-perfect equilibrium outcome, and the players’ total payoffs in that outcome equal the Myerson value on the original graph. Lemma 2.3, also proved here, says that under link-convexity, deleting any link in a connected component strictly lowers every player’s Myerson-value payoff in that component. Theorem 2.1 states that the unique component-efficient and fair allocation is the Shapley value of an auxiliary TU game; it is attributed to Myerson (1977) and Jackson and Wolinsky (1996), rather than established as this paper’s result. These are equilibrium and allocation characterizations, not claims that a problem is in P, NP-hard, or otherwise classified computationally. The introduction’s observation that the Myerson value is relatively easy to compute is not a numbered complexity result.

One could imagine a continuum extension asking whether a mass-based bilateral bargaining model has a unique equilibrium whose payoff distribution is the limit of finite-population Myerson values. That would be an analytical implementation or limit question, not the computational question this programme targets; it would also require specifying how individual links, their order, and the continuum Myerson value are defined. I therefore cannot give a faithful, prover-ready continuous problem for a qualifying anchor, or say whether it should be tractable or hard. The paper’s results are outside the scope of the proposed complexity mirror, even though a large, repeated-type setting makes a continuous-population extension conceivable.

The case AGAINST (opponent, writing after the proponent)

The main obstacle is that the paper does not give ChoCo a computational result to continuize. Theorem 4.1 characterizes an equilibrium outcome; Lemma 2.3 proves a comparative static; and Theorem 2.1 is an allocation characterization attributed to Myerson and Jackson–Wolinsky. None classifies the complexity of a computational problem. The introduction says the Myerson value is “relatively easy to compute,” but supplies no input encoding, algorithm, or complexity bound. That leaves no paper result for a continuous complexity question to mirror.

The best candidate is Theorem 4.1: ask whether a mass-based bargaining process has a unique equilibrium whose payoffs match a continuum Myerson value. But that is an equilibrium and limit question, not a computational one. To make it computational, one would have to add a task such as computing the outcome, and specify how the network and value function are encoded. The paper leaves \(w\) general over graphs; an explicit encoding can itself grow exponentially with the number of players, while a succinct encoding makes the complexity depend on the chosen formula. Repeated agent types do not resolve the missing input model: a type must capture the agent’s network position and relevant link data, which can make types effectively individual. A graphon or block model could provide a new model, but then the task is to define and analyze its continuum bargaining game, not to continuize Theorem 4.1’s result.

Lemma 2.3 is no firmer anchor. It says deleting one link strictly lowers each player’s Myerson payoff. In a nonatomic network, a single agent pair has zero mass, so the most promising repair would study the effect of removing a positive-mass set of links or changing a graphon. That may be an interesting comparative-static question, but it changes the object and still does not ask for an algorithm or a complexity classification. Theorem 2.1 offers even less: it is an axiomatic characterization, and continuizing that characterization would be outside the programme’s computational scope.

There may be worthwhile continuous network-bargaining research here. The honest negative case is narrower: the paper does not identify a computational question for which a continuous population is the natural input. Making one would require choosing a network limit, a value-function encoding, and a new computational objective. Those could support a separate project, but they do not yield a worthwhile ChoCo mirror of the results this paper establishes.
