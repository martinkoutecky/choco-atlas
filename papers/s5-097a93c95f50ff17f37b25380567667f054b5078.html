The continuous mirror question

Given a bipartite type graph with rational masses \(\mu_t\) and \(\nu_b\) on its two sides, an optimal coupling \(x_{tb}\), and dual potentials, costs incident to one type vertex change. Compute a new optimal coupling and dual potentials, and determine the exact reoptimization complexity in the type counts, edge count, and input bit length \(L\), independently of the expanded population.

The model it lives in

Each left type represents agents with the same complete valuation, and each right type represents repeated slots carrying the same integral bundle. A feasible coupling \(x_{tb}\) assigns mass of agent type \(t\) to bundle type \(b\), with row and column sums fixed by the rational marginals; minimize \(\sum_{t,b}c_{tb}x_{tb}\). The costs of pairs incident to one type may change, and the input includes an optimal coupling and dual potentials for the old costs.

The case FOR (proponent)

My strongest mirror is the paper’s local assignment update, not a claim that its whole envy-cycle procedure already has a continuous version.

The anchor is Theorem 3.1, proved in this paper. It says that, given a bipartite graph with \(n\) vertices on each side, \(m\) edges, a minimum-weight perfect matching and a corresponding potential, if the edge weights change only around one vertex, Algorithm 1 returns a new minimum-weight perfect matching and potential in \(O(m+n\log n)\) time. The theorem handles absent edges in a way that preserves this bound. It is the paper’s central computational result, and the same local-update structure is used in its fair-allocation application.

Here is the continuous problem I would hand to a prover: High-Multiplicity Local Bundle Assignment. There is a finite set \(\mathcal T\) of agent types, each specifying everything relevant to assignment, including its valuation. Type \(t\) has rational mass \(\mu_t\), with \(\sum_t\mu_t=1\). There is a finite set \(\mathcal B\) of bundle-slot types. Each \(b\in\mathcal B\) represents slots holding the same integral bundle \(B_b\), and has rational mass \(\nu_b\), with \(\sum_b\nu_b=1\). The mass \(\nu_b\) is the amount of population’s bundle inventory in that class.

A solution is a coupling \(x_{tb}\geq 0\): \(x_{tb}\) is the mass of type \(t\) assigned bundle \(B_b\). It must satisfy \(\sum_b x_{tb}=\mu_t\) for every \(t\), and \(\sum_t x_{tb}=\nu_b\) for every \(b\). Give each pair a cost \(c_{tb}\), for example \(c_{tb}=-v_t(B_b)\), so minimizing \(\sum_{t,b}c_{tb}x_{tb}\) maximizes welfare. The input includes an optimal coupling and dual potentials for the current costs. Now change costs only in the column for one bundle-slot type \(b^\star\). The task is to return an optimal coupling for the changed costs, together with dual potentials certifying optimality.

This is a population question: a large group of agents with the same complete valuation is represented by one mass, rather than by separately named agents. The bundles remain indivisible; only the assignment of population mass to bundles is aggregated. A plausible regime is a large institution distributing repeated standardized packages to many people, with many recipients but relatively few valuation types and package types. If all masses share denominator \(D\), multiplying by \(D\) recovers a finite assignment instance with \(D\mu_t\) agents of each type and \(D\nu_b\) slots of each bundle type. Conversely, a discrete assignment yields such a coupling. The transportation polytope also has integral vertices after scaling the rational marginals to integers, so an optimal mass plan has a discrete high-multiplicity realization. The relevant size parameters are the type counts \(\tau=|\mathcal T|\), \(\sigma=|\mathcal B|\), the number of allowed pairs, and the input bit length \(L\)—not the expanded population \(D\).

I expect this problem to be Class A: it is a rational min-cost transportation problem, solvable in time polynomial in the explicit type graph and \(L\), without expanding the population. A sharper question is whether the paper’s one-Dijkstra update bound survives arbitrary rational capacities. The mass version may need to rebalance flow along several residual cycles, so I would leave the matching bound as a further question rather than assert it.

The mirror covers the paper’s assignment-update result and the assignment subproblem used in the envy-cycle procedure. It does not claim a continuous analogue of Theorem 4.8’s EF1 guarantee. That is my weakest point: a welfare-optimal coupling of types to bundles does not by itself ensure EF1 when a type’s mass is split across bundles. The authors would, I think, recognize the local-update problem as their assignment problem in a high-multiplicity regime; whether the resulting type-level assignment can preserve the procedure’s fairness guarantee is a separate question.

The case AGAINST (opponent, writing after the proponent)

The best objection is that Theorem 3.1’s one-Dijkstra update depends on an atomic feature: vertex \(s\) has exactly one matched edge. Remove it, and the reoptimization reduces to finding one shortest path. In the proposed coupling, a positive-mass type can send mass along several bundle edges. Updating that type’s costs can require rerouting mass through multiple residual cycles. The literal local-update guarantee therefore has no evident continuous counterpart.

That creates a real modeling tension. If “one agent changes” means a mass \(1/D\), its effect vanishes as the population grows. To get a nontrivial limit, the update must change the costs for an entire positive-mass type. That is a collective revaluation, not the single matched unit the paper’s proof repairs. The strongest continuous question is consequently a different one: how quickly can an optimal capacitated transport plan be updated after one row or column of costs changes?

That question is coherent, but the static optimization underneath it is already standard minimum-cost flow; strongly polynomial algorithms have been known for decades ([Orlin, 1993](https://pubsonline.informs.org/doi/10.1287/opre.41.2.338)). This does not answer the dynamic update question, so it is not a novelty collision. It does mean the proposed mirror’s ordinary tractability comes from established flow machinery, while its potentially distinctive part—whether one can preserve the paper’s unusually cheap update—loses the atomic argument that made the theorem work. And because the coupling permits fractional mass assignments, it does not carry over the paper’s EF1 guarantee.

I cannot make that a decisive case against every mirror. Repeated agent and package types in a large institution are plausible, and a type-level revaluation could be worth studying. The negative case is therefore weak at its most important point: it shows that the paper’s update theorem does not transfer directly, but not that the resulting dynamic transportation problem is unworthy of the programme.
