The continuous mirror question

Given a finite set of complete player types \(T\), rational masses \(\mu_t \ge 0\) summing to \(1\), and a sparse rational polynomial \(v(x)=\sum_{a\in A}q_a\prod_{t\in T}x_t^{a_t}\) with \(v(0)=0\), compute the exact limiting aggregate Shapley payoff for each type as finite societies with proportions \(\mu\) are replicated. Is the vector \(\Phi_t=\mu_t\int_0^1\partial_t v(\lambda\mu)\,d\lambda\) computable in time polynomial in the sparse input size, \(|T|\), the degree bound, and the rational bit lengths?

The model it lives in

A continuous cooperative cost-sharing game has types \(t\in T\) with masses \(\mu_t\); a coalition is described by its type-mass vector \(x\), and its worth is an explicitly represented sparse polynomial \(v(x)\). The output is the aggregate Shapley allocation by type, given by \(\Phi_t=\mu_t\int_0^1\partial_t v(\lambda\mu)\,d\lambda\), the limit of aggregate type payoffs in replicated finite societies. Each monomial contributes \(q_a(a_t/|a|)\mu^a\), giving an exact polynomial-time algorithm for the stated representation.

What the mirror covers

It mirrors Proposition 3.1's general Shapley-computation question for symmetric type-mass worths; it leaves the level-structure algorithms, relevant-coalition results, and value axiomatizations unmirrored.

Open questions for a prover

  • Does exact computation remain tractable when \(v\) is given by an arithmetic circuit or an evaluation oracle?
  • Which other coalition-worth representations preserve the finite-replica Shapley limit and efficient computation?

The case FOR (proponent)

The strongest mirror I see is the paper’s baseline Shapley computation result, Proposition 3.1. As printed, it says that no algorithm computes the Shapley value in polynomial time in the number of players \(n\) for all TU games. The paper proves this: if coalition worths can vary independently, changing any worth for a coalition containing player \(i\) can change \(i\)’s payoff, so computing even one player’s payoff requires reading \(\Omega(2^{n-1})\) worths. This is a lower bound in the paper’s player-count model, not an NP-hardness result under a succinct input encoding.

A plausible high-multiplicity setting is a large cooperative purchasing or cost-sharing consortium. Millions of members fall into a small number \(\tau\) of complete profiles—such as contract, usage, and service classes—and the consortium’s surplus depends on how much mass of each profile joins a coalition. Here \(\mu_t\) is the fraction of members of type \(t\), and a coalition is represented by its type-mass vector \(x\), where \(0\le x_t\le\mu_t\). The many members are the population being continuized; the monetary payoff remains the object being divided.

My lead question is High-Multiplicity Continuous Shapley Allocation. An instance consists of a finite type set \(T\), rational masses \(\mu_t\ge0\) summing to \(1\), and a coalition-worth function
\[ v(x)=\sum_{a\in A}q_a\prod_{t\in T}x_t^{a_t},\qquad v(0)=0, \]
given as an explicit sparse list of rational coefficients and exponent vectors. The degree bound \(D\) is part of the input, encoded so that polynomial dependence on \(D\) is polynomial in input size. The question is to compute the exact aggregate Shapley payoff to each type in the limit of replicated societies with these proportions. The solution is
\[ \Phi_t=\mu_t\int_0^1\partial_t v(\lambda\mu)\,d\lambda. \]
This is the Aumann–Shapley path allocation, selected here by the high-multiplicity limit: in the finite replicas, members of each type are interchangeable, and their total Shapley payoff converges to \(\Phi_t\) under the stated smooth worth model. The payoffs are efficient, since \(\sum_t\Phi_t=v(\mu)\).

For this input representation the mirror is tractable. Each monomial \(q_a x^a\) contributes \(q_a(a_t/|a|)\mu^a\) to \(\Phi_t\), so the exact vector can be computed in time polynomial in the sparse description, \(\tau\), \(D\), and the bit lengths of the rationals. The downstream question is whether tractability persists for more succinct function representations, or for smooth worth functions given by an evaluation oracle. Those versions may have a different complexity.

Proposition 3.1 is the sole anchor here, and the mirror covers the paper’s general Shapley-computation lower bound in Section 3. It does not cover the paper’s level-structure results. The case for author recognition is that the underlying allocation is still Shapley payoff computation, now for a population whose worths are specified by aggregate type masses. The weakest point is that the paper’s arbitrary TU game need not admit this smooth, low-dimensional representation, and the Aumann–Shapley value is not claimed as a universal continuous extension of every discrete Shapley instance. That limits the mirror to a plausible, explicitly represented high-multiplicity regime; it does not make it merely an outcome-space or probabilistic-profile continuization.

The case AGAINST (opponent, writing after the proponent)

Proposition 3.1 is the strongest anchor, but it gives a narrow target for the negative case. Its lower bound comes from allowing coalition worths to vary independently: changing any one of \(2^{n-1}\) worths can change a player’s payoff. Since the game is supplied by its coalition-worth table, that table is already exponential in \(n\). The proposed mirror adds exchangeability within types and a low-dimensional worth function \(v(x)\). Those are sensible high-multiplicity assumptions, but they restrict the game’s representation as well as its population: arbitrary TU games cannot be represented by a fixed, sparse polynomial over type masses. So this is not a general continuization of Proposition 3.1’s input regime.

The best repair is to allow richer descriptions of \(v\), such as an arithmetic circuit, and ask for the exact limiting allocation. That could produce a real complexity question, but its difficulty would depend on circuit differentiation and integration. The sparse-polynomial version avoids those questions: the Aumann–Shapley path allocation is established in continuous cost allocation, and the proposed monomial formula gives its computation term by term. [Tauman’s survey of Aumann–Shapley prices](https://www.cambridge.org/core/books/abs/shapley-value/aumannshapley-prices-a-survey/8023E3AE9A301A872C386FB4E7409C0C)

That is a case against treating this anchor as a strong ChoCo priority: its paper result is an input-access lower bound, while its tractable mirror relies on a structured worth-function promise. But it does not defeat the mirror. Many consortium members sharing a small number of complete types is plausible; their aggregate type payoffs retain the individual Shapley payoffs under the model’s symmetry. The finite paper model and the continuous allocation literature also do not create a novelty collision by themselves. I cannot honestly argue that no worthwhile mirror survives this anchor.
