The case FOR (proponent)

The strongest mirror I believe in keeps the paper’s geography and districting rules intact while making the population a distribution over geographic voter types. A type is a graph location together with its party label: \(t_v=(v,\operatorname{col}(v))\). Its mass \(\mu_v\in\mathbb{Q}_{>0}\) is that bloc’s share of the population, with \(\sum_{v\in V}\mu_v=1\). A district is still a nonempty connected set of vertices. Its mass for party \(c\) is
\[ M_c(D)=\sum_{\substack{v\in D\\\operatorname{col}(v)=c}}\mu_v. \]
It is uniquely won by \(c\) when \(M_c(D)>M_{c'}(D)\) for every \(c'\ne c\). The decision is whether the graph can be partitioned into exactly \(k\) connected districts so that the number uniquely won by the target party \(p\) exceeds the number uniquely won by each other party. A solution is the partition; the paper’s problem is a feasibility question, so there is no separate optimization objective.

The regime is districting over a network of atomic geographic units—wards, blocs, or other areas that cannot be split by the districting operation—with many residents represented at each unit. Residents at the same unit and with the same party label are indistinguishable for this problem; their location matters because it determines which connected districts can contain them. Thus \(N\), the number of residents, can be much larger than \(\tau=|V|\), the number of supported location-party types. The tree result below even uses large vertex weights. For the path result, scaling every unit weight by the same factor gives arbitrarily many residents per type while leaving every district comparison unchanged.

My lead anchor is Theorem 2, proved in this paper: *Gerrymandering over Graphs restricted to trees is weakly NP-hard even if \(|C|=3\).* Its continuous mirror is Three-Party Continuous Tree Gerrymandering. An instance is a tree \(G\), a label \(\operatorname{col}(v)\) from exactly three parties for each vertex, positive rational masses \(\mu_v\) summing to \(1\), a target party \(p\), and an integer \(k\). The question is whether there is a partition into exactly \(k\) connected vertex sets for which the number uniquely won by \(p\) is greater than the number uniquely won by each of the other two parties. The partition is the certificate of a yes-instance. This is a sensible high-multiplicity question: it asks how party shares across many residents at each location affect the same connected-district decision studied in the paper.

The expected result for this mirror is hardness transfers. Given any integer-weight instance from Theorem 2, set \(\mu_v=w(v)/\sum_u w(u)\). This is a polynomial-size rational distribution, and scaling all party totals by the same positive number preserves every strict plurality comparison. The allowed partitions and their winners therefore correspond exactly. The paper’s reduction from Partition gives weak NP-hardness on this rational-mass subfamily. That makes the numerical side worth investigating: for example, whether useful algorithms can depend on a common denominator or population scale, and whether the three-party tree case can be made strongly NP-hard.

A second anchor is Theorem 1, also proved here: *Gerrymandering over Graphs restricted to paths is NP-hard even if all vertices have unit weight*, with no fixed bound on the number of colors. Its mirror is Continuous Path Gerrymandering with Unbounded Parties: the instance is a path, a party label at each vertex, positive rational masses summing to \(1\), a target party, and \(k\); the question is whether an exactly-\(k\) connected partition satisfies the same strict count-of-winners condition. The solution is the partition itself. Here too I expect hardness transfers: the theorem’s unit-weight instances map to \(\mu_v=1/|V|\), preserving every answer exactly. This anchor demonstrates hardness even when the population shares are uniform; the combinatorics can reside in the path and the party labels. It also marks an important boundary: the paper cites a polynomial-time result for paths when the number of colors is fixed, so this mirror does not claim hardness for that restricted regime.

Together these mirrors cover the paper’s two new hardness results, not its full classification. The further questions include how complexity changes with the number of parties, how mass precision affects exact algorithms for trees, and whether approximating the winner-count condition under small mass perturbations is tractable.

The weakest point is the atomic-geography assumption. The paper partitions vertices, so I have kept each location wholly in one district while making the residents at that location continuous mass. A reader who expects a continuous population to let a district split a vertex’s residents may regard that as a different, more fractional districting model. I think the stated version remains a credible mirror because location and connectivity are part of each type’s description, and the paper’s districting action is defined on those locations. Its honest limitation is that the continuous model retains the paper’s discrete geographic decisions; the hardness transfer shows precisely that this form of population continuization need not make the problem easier.

The case AGAINST (opponent, writing after the proponent)

The strongest case against is that both proposed anchors already live inside the paper’s weighted problem. This is more than expecting the same hardness result: the proposed rational-mass decision problems have the same instances and feasible partitions, expressed in different units.

For Theorem 1, the proposed uniform-mass path instance is exactly the unit-weight instance in the theorem. More generally, for any rational masses \(\mu_v\), choose a common denominator \(D\) and set \(w(v)=D\mu_v\). Every party comparison is multiplied by the same positive constant, so every partition has exactly the same district winners. The paper’s path problem already permits those integer weights. The number of parties and the strict winner-count condition also remain unchanged.

For Theorem 2, the correspondence works both ways: normalize any positive integer weighting by its total \(W=\sum_v w(v)\) to get \(\mu_v=w(v)/W\), or scale a rational mass vector to integer weights using a common denominator. The decision predicate is identical on trees with three parties. The common denominator has polynomial bit length in the rational input, so this is an encoding equivalence, not a new computational regime. Questions about denominator size or population scale can be stated directly as questions about weight magnitude in the paper’s problem.

The proposed geographic story—many residents at each indivisible location—is plausible. But under the paper’s single-party-per-vertex model, it makes the mirror an exact restatement of the weighted problem the paper already studies. To escape that equivalence, one could give each location a vector of party masses, or allow a district boundary to split a location’s population. Those may be sensible extensions, but they change the paper’s input or its partition operation; neither change is forced by continuizing the population, since rational masses at the existing vertices already fit the weighted model. Whether the authors would recognize either extension as *their* problem is the vulnerable point in this negative case.

So the case against is strong for the two anchors actually raised: neither yields a new continuous computational question. It is weaker as a universal claim that no worthwhile continuous gerrymandering model exists. A model with heterogeneous party populations at geographic sites could be worth studying if the authors accept that co-location structure as part of their problem.
