What the mirror covers

The proposed analogue concerns only Theorem 2.1's Arrow aggregation conclusion; it gives no computational analogue for the topology proofs, reduction lemmas, domain-restriction examples, or distributed-computing connections.

The case FOR (proponent)

The strongest positive case is a population version of Arrow aggregation. Let a type be a strict ranking \(t\in W\), and let \(\mu_t\) be the fraction of a large electorate with that ranking. A society is a finite-support distribution \(\mu\); the decision is a strict social ranking \(F(\mu)\). Unanimity requires \(F(\mu)\) to rank \(a\) above \(b\) when the mass preferring \(a\) to \(b\) is \(1\). IIA requires the social comparison of \(a\) and \(b\) to depend only on the pairwise masses for that pair. This is a natural population regime: many voters but relatively few distinct rankings.

The nearest named result is Theorem 2.1, proved in this paper. It states that, for \(|X|\ge 3\) and \(n\ge 2\), every simplicial map \(f:N_I\to N_O\) that maps each unanimous pairwise-preference vertex to the corresponding unanimous social-preference vertex is a projection: there is a voter \(k\) such that \(f(U^\sigma_{ab})=U^{\sigma(k)}_{ab}\) for every pair \(a,b\) and sign vector \(\sigma\). In the paper’s formulation, this is Arrow’s conclusion that an aggregation map satisfying IIA and unanimity must be dictatorial.

A precise nearby question is Anonymous Continuum Arrow Feasibility: given a finite alternative set \(X\), does there exist a function \(F\) from all finite-support rational distributions over \(W\) to strict rankings, satisfying the unanimity and pairwise IIA conditions above? A solution is such a global function. This is a credible *axiomatic* mirror: a distribution contains no named voter, so any \(F(\mu)\) is anonymous. Restricting to equal-mass distributions over two rankings would already conflict with Theorem 2.1’s projection conclusion, since a projection distinguishes the two voters while the distribution does not.

That is the best honest positive case, but it does not qualify as a ChoCo computational mirror. The paper contains no named result classifying a computational problem as tractable, hard, or parameterized; Theorem 2.1 is an axiomatic impossibility theorem. The nearby question asks whether a global rule exists, has no computational objective or per-instance algorithmic task, and falls outside the programme’s complexity trichotomy. The paper’s distributed-computing connection does not change that: its theorem concerns existence of a simplicial map, not a complexity bound for computing one. So I would present the population analogy as mathematically natural, while declining to claim a qualifying computational anchor.

The case AGAINST (opponent, writing after the proponent)

The decisive problem is that Theorem 2.1 is axiomatic, not computational. It classifies global aggregation maps: every map satisfying unanimity and IIA is a projection. The theorem has no per-instance computational task, algorithm, or complexity bound to continuize.

The proposed distribution over rankings is a plausible population version of Arrow’s question, but it drops the voter identities that make the theorem’s conclusion meaningful. If identity is included in each type, each voter becomes a distinct type, so support grows with \(n\) and the high-multiplicity compression disappears. In an atomless model, a single dictator has zero mass; a distribution cannot register that person’s report. This is a real identity problem for the mirror, not a matter of choosing a more natural tie-breaking convention.

A stronger computational formulation might take a distribution \(\mu\) and ask for a social ranking. But IIA constrains how one global rule behaves across societies, so a single \(\mu\) cannot establish it. Giving the algorithm the whole rule or its domain instead creates a global rule-synthesis problem whose complexity depends on an encoding the paper never studies. Its domain-restriction examples could inspire a separate computational project, but they do not supply a computational result in this paper to mirror.

So the negative case is strong on programme fit: the natural mirror is axiomatic and out of scope, while making it computational changes the problem. It cannot prove that no worthwhile adjacent project could be built.
