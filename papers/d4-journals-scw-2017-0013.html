The case AGAINST (opponent, writing after the proponent)

The strongest negative case is that the proponent raised no eligible computational anchor. Theorem 1 characterizes a value by axioms; Theorem 2 and Proposition 3 give representation results; Corollary 1 rules out a representation of the Shapley value. None states the complexity of a computational problem or gives an algorithm. The Dutch Parliament table reports calculated values, but it is an application, not a named computational result. So there is no paper result here whose continuous complexity mirror can be assessed.

The Parliament example is the best starting point for a repaired proposal: treat voting behavior as types and party seat shares as masses. One could define a type’s prediction value as \(\mathbb{E}[v(X)\mid I_t=1]-\mathbb{E}[v(X)\mid I_t=0]\), where \(X\) is a random coalition and \(I_t\) records whether a representative of type \(t\) participates. That is a coherent continuous statistic. But under independent voting and a mass-based outcome rule, one person has zero effect on the coalition’s mass, so the statistic can collapse. Adding common latent shocks can make it nonzero because a representative’s vote predicts the aggregate outcome. That is the stronger version of the mirror, and it fits the paper’s informational interpretation.

It still supplies no computational result to mirror. To ask for efficient computation, one must newly choose how the coalition distribution and worth function are represented—say, an explicit support, a generative model, or a latent-state process. The resulting complexity question depends on those choices; it is not specified or answered by this paper. Conditioning on an entire positive-mass type or party could produce a different, potentially useful block-level quantity, but that changes the object being measured.

So the defensible negative conclusion is narrower than “no worthwhile continuous scenario exists.” Continuous prediction values may be worthwhile, and the correlated-population version is not inherently degenerate. The stronger case is that this paper offers no named computational result for ChoCo to continuize; turning its value concept into a continuous computational study would be a new research question, not a mirror of the paper’s results.
