What the mirror covers

The case FOR (proponent)

I can’t make an honest, anchor-based computational case for this paper: it contains no named result about a computational problem being tractable, hard, or otherwise classified.

The closest result is Theorem 3, proved here by combining Theorems 1 and 2. It says that if \(\mu_0,\mu_1\) induce non-atomic initial beliefs, then there is a sequence \(q(n)\to1\) such that, for every connected undirected graph with \(n\) agents and every agent \(u\), the probability that \(u\)’s limiting optimal action set is exactly the true state, \(\P{\limac_u=\{S\}}\), is at least \(q(n)\). That is an asymptotic learning theorem, not a complexity result: it gives no algorithm, input encoding, running-time bound, or hardness classification.

The paper’s population also remains a set of graph vertices—even in Theorem 3.41, where it is countably infinite. Its \(\mu_0,\mu_1\) describe private-signal distributions, and its limit in \(n\) is an asymptotic probability statement; neither makes the society a distribution over voter types. Replacing the graph with masses of types would need to preserve the network structure that drives information flow, and any resulting computational question would be newly proposed rather than a mirror of a named computational result here.

So there are no eligible anchors, no per-anchor continuous problems to hand to a prover, and no tractability or hardness predictions to give. The strongest positive hook is the paper’s large-population setting and identical signal model across agents. Its weakness is decisive for this assignment: the results are analytic, not computational.

The case AGAINST (opponent, writing after the proponent)

Theorem 3 is the strongest finite-population hook, but it is an asymptotic probability guarantee, not a computational result. A generous continuous reformulation could give types both signal likelihoods and network roles. Yet grouping only by signal type loses the neighborhoods that determine what agents observe. Grouping by complete network position preserves the dynamics, but arbitrary graphs may have no repeated positions; grouping by finite-radius neighborhoods preserves only finite-time behavior, while the theorem concerns the infinite-time limit. A richer continuum network model might be possible, but its learning theorem would be a new analytic question, not a computational mirror of Theorem 3.

Theorem 3.41 has the same problem in an even clearer form. Its countably infinite graph is a limit of individual agents, each with its own neighbors and signals; it is not a distribution of population mass over types. One could study learning on a continuous network object, but the theorem supplies no encoded input, algorithm, running time, or complexity classification for that object. Its result is that \(p(G)=1\), not a claim about how hard it is to compute anything.

The paper’s identical, conditionally i.i.d. signals do make repeated agent types plausible in some symmetric network families. That is a sensible regime to explore, but it does not supply the missing computational question. The signal distributions \(\mu_0,\mu_1\) are arbitrary measures, the graph is a relational structure that carries the information flow, and agents are assumed to perform Bayesian updates without any computational model. Turning this into an algorithmic problem would require choosing an input encoding, a restricted signal family, and a task such as deciding or approximating learning probability. Those could be worthwhile projects in their own right; none is a mirror of a named computational result in this paper.

So the negative case is strong under ChoCo’s criterion: neither named theorem offers an eligible computational anchor, and continuizing the population would at most yield another analytic learning model. This does not prove that no useful computational study of continuous social learning could ever be built; it says the paper itself gives no result for that study to mirror.
