The continuous mirror question

Given a network, a finite set of user types \(T\) with rational masses \(\mu_t>0\) summing to \(1\), a nonnegative per-capita edge-capacity vector \(b\), and for each type \(t\) a finite set \(A_t\) of feasible integral packet-flow bundles including zero flow, with capped utility \(U_t\), determine whether \(b\) is weakly enforceable by common nonnegative edge prices. Equivalently, find \(\lambda\ge 0\) and masses \(z_{ta}\ge 0\) such that \(\sum_{a\in A_t}z_{ta}=\mu_t\), \(y=\sum_{t\in T}\sum_{a\in A_t}z_{ta}a\le b\), \(\lambda_e(b_e-y_e)=0\) for each edge \(e\), and \(z_{ta}>0\) only when \(a\in\arg\max_{a'\in A_t}\{U_t(\operatorname{val}(a'))-\lambda^{\top}a'\}\).

The model it lives in

A nonatomic population of packet-flow users represented by types \(t\), masses \(\mu_t\), and integral per-user bundles \(a\in A_t\). Decision variables \(z_{ta}\) distribute each type's mass across bundles; the objective is to maximize \(\sum_{t,a}z_{ta}U_t(\operatorname{val}(a))\) subject to type-mass totals and per-capita edge capacities. Dual edge prices \(\lambda\) support the used bundles as best responses.

The case FOR (proponent)

My strongest positive case is Proposition 9.4, with Theorem 3.15 as a broader algorithmic anchor. The paper’s central question—whether anonymous resource prices can support a target load—is a good fit for a continuous population. Here the types are not rankings: they are complete descriptions of network users, including their source and destination, feasible packet flows, utility function, and rate cap.

A plausible regime is a large network serving many repeated sessions from a small set of endpoint and application profiles. If there are \(N\) sessions but only \(\tau\) distinct profiles, with \(N\gg\tau\), type \(t\) has mass \(\mu_t=n_t/N\). Let \(b\) be edge capacity per unit population. Each individual still chooses an integral packet-flow bundle; the continuum variable is the fraction of a type assigned to each bundle. Thus fractional type-level averages arise from a continuous society, not from making each individual’s packet divisible.

Proposition 9.4, proved in this paper, says that unless \(P=NP\), there is a two-player instance with distinct source–sink pairs and identical nondecreasing, linear capped bandwidth utilities, and an integral capacity vector \(u\) that is not weakly enforceable by market prices. Its proof uses the hardness of two-directed disjoint paths, while the individual demand problem is polynomially solvable.

The lead mirror is Continuous-Type Weak Enforceability for Packet Flows. An instance gives a network, a finite support \(T\) with positive rational masses \(\mu_t\) summing to \(1\), and a per-capita capacity vector \(b\). Each type \(t\) specifies a source–sink pair, a capped utility \(U_t\), and a finite set \(A_t\) of feasible integral packet-flow bundles, including the zero-flow bundle. Ask whether there are nonnegative edge prices \(\lambda\) and masses \(z_{ta}\geq 0\) assigned to bundles such that, writing \(y=\sum_{t,a}z_{ta}a\),

\(\sum_{a\in A_t}z_{ta}=\mu_t\) for every \(t\), \(y\leq b\), and \(\lambda_e(b_e-y_e)=0\) for every edge; moreover, \(z_{ta}>0\) only if \(a\in\arg\max_{a'\in A_t}\{U_t(\operatorname{val}(a'))-\lambda^\top a'\}\). A solution is the price vector and supported type–bundle masses satisfying those conditions.

I expect this mirror to be tractable, in Class A. The mass-allocation problem is a configuration LP: each type’s mass can be distributed across its integral bundles, and LP dual prices make every used bundle a best response. With a zero-flow option, the LP is feasible for every nonnegative \(b\); its dual gives weakly enforcing prices. In the paper’s capped network setting, the relevant per-type demand optimization is polynomial, so the pricing-oracle approach applies. The two-player disjoint-path obstruction need not survive: the continuum can divide a type’s mass among tied routes while each individual still takes an integral bundle. Further questions include how the running time depends on \(\tau\) and the input bit length, what happens under exact capacity equality rather than weak enforceability, and whether hardness returns if members of a type must all receive the same bundle.

The second anchor is Theorem 3.15, proved in this paper. Under the assumptions of Theorem 3.11—finite strategy sets, or the stated finitely generated convex-hull and concave-extension case, with linear resource use—it says that the master LP can be solved in polynomial time if, for every player and every nonnegative price vector, a polynomial-time demand oracle returns a cost-minimizing strategy. Remark 3.16 carries the results over to maximization problems.

Its mirror is Type-Supported Price Discovery. Given rational type masses, resource capacities, and per-type action sets and utilities, compute a welfare-maximizing assignment of type mass to actions and supporting prices. The action sets may be listed or implicit; in the latter case, the input supplies a demand oracle for optimizing each type’s utility net of prices. The expected result is polynomial time in the number of resources, \(\tau\), and the binary input length, plus the oracle cost, under the theorem’s assumptions. This asks for the underlying allocation and pricing solution, not merely a solution to an encoding. It also raises questions about sparse equilibrium certificates and about which non-network demand oracles are efficient.

These mirrors cover Proposition 9.4’s failure of weak enforceability and Theorem 3.15’s demand-oracle tractability; they do not attempt to continuize every application in the paper. The authors should recognize both as their problem: the same resource allocations, common prices, best responses, and capacity targets are present. The high-multiplicity change is to describe repeated users by masses over complete types.

The main weakness is that this is close to material the paper already develops. Section 6.1 explicitly studies nonatomic routing, and Theorem 9.1 studies pricing with concave utilities and continuous flow choices. Those are supporting neighbors, not the exact mirror here: the lead question preserves integral per-user packet bundles and makes the population itself the continuous object. Still, a referee could view the answer as a direct consequence of the paper’s convexification framework, or argue that the disjoint-path hardness is tied to graph structure rather than population size. The case rests on the authors accepting mass allocation across a large cohort as the natural high-multiplicity version of their integral-user pricing problem.

The case AGAINST (opponent, writing after the proponent)

The strongest case against is that these two mirrors may be routine applications of the paper’s own LP framework, rather than substantial new continuization results. But I don’t think that defeats either anchor.

For Proposition 9.4, a plausible high-multiplicity regime is many repeated sessions with the same endpoints, rate cap, and packet-flow options. Assigning mass across integral flow bundles preserves integral choices for each individual; it only lets a large cohort divide among them. With zero flow available, the configuration LP is feasible, and its dual prices support the assigned bundles. In the capped-flow setting, the demand problem is a max-flow problem. The resulting question is well-posed and computationally meaningful, even if its answer is tractable.

There is a real novelty concern: the paper already studies nonatomic routing in Section 6.1, and Section 9.1 studies price enforcement with continuous flow choices. Those are close neighbors, especially for repeated source–sink sessions. But they do not quite settle the proposed mirror, which keeps each agent’s packet bundle integral and makes the population continuous. Calling that a collision would overstate the overlap.

Theorem 3.15 is also a defensible anchor. Grouping identical players into types turns the player-by-player LP into a weighted type–action LP. Its running time can depend on support size \(\tau\), rather than the number of agents encoded by the masses. For packet-flow types, the required demand oracle is efficient. The proponent’s “welfare-maximizing assignment” wording should be tightened to the paper’s target-capacity enforceability question, but that repair leaves a valid mirror.

The paper has named computational results, and the type model handles idiosyncratic attributes by including them in the type. Repeated network users are credible, and repeated buyers of a few valuation types are another plausible regime. I can argue that these mirrors may be straightforward extensions, with some overlap already present in the paper; I cannot honestly turn that into a case that no worthwhile mirror exists in any scenario. The negative case is weak, and the positive case survives both anchors.
