The continuous mirror question

Given a finite agenda \(X\), its minimal inconsistent subsets, and rational quota shares \(q_p\), decide whether every rational distribution \(\mu\) with finite support over complete, consistent judgment types yields a consistent collective set \(Q_q(\mu)=\{p:\sum_{t:\,p\in t}\mu_t\ge q_p\}\). If not, return a rational distribution that yields an inconsistent set.

The model it lives in

Types are complete, logically consistent judgment sets \(t\subseteq X\); each type has mass \(\mu_t\). The quota share \(q_p\) is the acceptance threshold for proposition \(p\), and the collective set contains each proposition whose supporting mass reaches its quota. The decision is whether this set is consistent for every rational finite-support society; a negative answer can include a finite-support witness.

What the mirror covers

The mirror covers the ordinary quota-rule consistency characterization in Theorem 2(c). It leaves the paper’s other rationality conditions, sequential rules, path-dependence, strategy-proofness, and committee-rule results aside.

Open questions for a prover

  • Can a violating minimal inconsistent subset be found efficiently when the agenda is encoded by logical formulas rather than supplied as an explicit list?
  • What is the complexity of the certification problem under compact agenda encodings?

The case FOR (proponent)

The strongest honest anchor is Theorem 2(c), proved in this paper. It says that, for a fixed population of \(n\) people, a quota rule \(F_{(m_p)}\) produces a consistent collective judgment set for every profile of individually rational judgments if and only if, for every minimal inconsistent subset \(Z\) of the agenda,
\[ \sum_{p\in Z} m_p > n(|Z|-1). \]
The paper then uses these inequalities in §3.6 to check quota rules without enumerating profiles. This is a computationally used characterization, but it is not a named P-versus-hardness result; under a strict reading of that requirement, the paper has no qualifying complexity-class anchor.

A mirror I would defend is Continuous Quota-Consistency Certification. Consider a large membership organization deciding a fixed set of logically connected policy propositions. Its members can be grouped into recurring, complete and logically consistent judgment types; a type’s mass is its fraction of membership. Let \(T\) be the set of such types, and let a society be a rational finite-support distribution \(\mu\) over \(T\). Given rational quota shares \(q_p\in[0,1]\), the collective judgment is
\[ Q_q(\mu)=\left\{p:\sum_{t\in T:\,p\in t}\mu_t\ge q_p\right\}. \]
The problem takes the agenda and quota vector as input and asks whether every such society produces a consistent \(Q_q(\mu)\). If not, a solution can return a finite-support rational society that produces an inconsistency. This is a decision and witness problem, so it has no optimization objective.

The continuous condition is exact: universal consistency holds if and only if
\[ \sum_{p\in Z}q_p>|Z|-1 \]
for every minimal inconsistent set \(Z\). For sufficiency, each consistent type can accept at most \(|Z|-1\) propositions in \(Z\), so the total mass of accepted propositions cannot meet quotas whose sum exceeds that bound. For necessity, if the inequality fails, minimality lets us choose, for each \(p\in Z\), a type accepting \(Z\setminus\{p\}\). We can assign mass \(\lambda_p\le 1-q_p\) to those types with \(\sum_p\lambda_p=1\); then every proposition in \(Z\) meets its quota, producing an inconsistent collective set. This extends Theorem 2(c) from count thresholds to arbitrary population shares.

The high-multiplicity scenario is an association or mass-membership organization with hundreds of thousands of members but relatively few recurring judgment profiles on a fixed agenda. A type is a complete judgment set, and mass is the fraction of members holding it. That is close to the paper’s own model: its individuals already have complete judgment sets, and proposition-wise quotas remain the aggregation rule. The mirror covers the ordinary quota-rule consistency result only; I would not stretch it to the paper’s results on sequential rules or individual strategy-proofness.

For an input that explicitly lists the agenda’s minimal inconsistent sets, I expect this certification problem to be Class A: check the displayed inequality for each set, using polynomially many rational arithmetic operations in the list size and bit length. The further question is whether one can find or price a violating minimal inconsistent set efficiently when the agenda is given compactly as logical formulas. That is where the computational bottleneck would lie.

The soft spot is that the paper’s motivating bodies are small committees, while the large-organization scenario is an extension. Also, the paper already notes that count thresholds are equivalent to proportions for fixed \(n\), so the continuous model is a natural high-multiplicity extension, not a novel mathematical move by itself. And if the agenda is encoded compactly, tractability may depend on searching its logical structure rather than on the population continuum.

The case AGAINST (opponent, writing after the proponent)

Theorem 2(c) is the right result to inspect, but it does not give this paper a computational problem about an input society. It characterizes when a quota rule is consistent on every profile. Section 3.6 calls the inequalities computationally useful, but the tasks it discusses are checking or choosing thresholds from the agenda; it gives no complexity classification for an algorithm that acts on a society. Under the programme’s stated test, that is a serious gap in the anchor.

The proposed Continuous Quota-Consistency Certification is a valid extension of the theorem, but it quantifies over all societies instead of taking one as input. Its condition, \(\sum_{p\in Z}q_p>|Z|-1\), is the paper’s inequality divided by \(n\). A counterexample can be built from a few types, but producing that witness is part of the same universal rule check. If the agenda’s minimal inconsistent sets are supplied, checking the condition is rational arithmetic; if the agenda is encoded compactly, finding those sets is where the hard work lies. For an actual input \(\mu\), one can instead sum the masses supporting each proposition and check consistency. Any difficulty then comes from the agenda’s logic, not from the continuous population.

A plausible high-multiplicity setting exists: a large membership organization could have many members sharing a small number of complete judgment profiles. That makes the model sensible, but it does not repair the mismatch between the paper’s result and the proposed computational task. A stronger candidate might ask for the least mass transfer needed to make the collective judgments inconsistent. That would be a genuine mass-optimization problem, but it needs a baseline society, transfer costs, and an objective that this paper neither studies nor supplies. It is an adjacent research question, not a continuous mirror of Theorem 2(c).

So the positive case has a real soft spot: its sole anchor is a characterization of a quota rule, and its continuous version leaves the society out of the input. I would argue against spending ChoCo effort on this paper as a computational mirror on that basis. I would not claim the broader universal negative is airtight: high multiplicity is plausible here, and a suitably motivated robustness problem might be worthwhile. The paper itself, though, does not anchor that stronger project.
