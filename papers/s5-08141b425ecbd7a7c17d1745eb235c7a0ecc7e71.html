The anchor — hardness

Theorem 3

Every anchor argued

  • Theorem 3 — survived: The opponent shows that hardness may not persist for fixed type sets, but does not defeat the well-posed unrestricted high-multiplicity mirror.
  • Theorem 1 — fell: The opponent correctly notes that replacing exactly two agents by two population blocs changes the problem rather than continuously relaxing the theorem's fixed-two-agent setting.

The continuous mirror question

Given rational type masses \(\mu_t\), rational per-capita supplies \(s_o\), and weak-order types over object kinds \(O\), output a finite-support rational allocation \(x_{t,b}\) of integral bundles \(b\in\mathbb{Z}_{\ge 0}^{m}\) using at most \(s_o\) mass of each object, such that all positive-mass agents receive equal-size bundles and no agent SD-envies another. Require the allocation to be maximal under positive-mass couplings that weakly extend every assigned bundle, and complete whenever any complete EF allocation exists.

The model it lives in

A high-multiplicity indivisible-assignment model with type masses \(\mu\), replicated per-capita supplies \(s\), integral bundles \(b\), and mass variables \(x_{t,b}\); the task is maximal EF allocation with completeness certification through the output.

The objection that survived

For strict types, exact EF collapses the bundle-distribution variables to one integral bundle per type, so the mirror may lack the intended continuous LP structure and its hardness may disappear when \(\tau\) is fixed.

fatal: False

What the mirror covers

The mirror covers the arbitrary-agent maximal-EF and completeness guarantee of Theorem 3; it does not directly cover the fixed-two-agent GAL algorithm, its \(O(m^2)\) bound, or the supporting axiomatic lemmas.

Open questions for a prover

  • Does \(\mathsf{MaxCompleteEF}_\infty\) remain hard when the number of preference types \(\tau\) is fixed?
  • Is there a polynomial-time configuration, flow, or separation algorithm for fixed \(\tau\) or fixed per-agent bundle size?
  • Which discrete complete-EF hardness constructions survive when many agents share each type and every positive type mass is bounded away from zero?

The case FOR (proponent)

The strongest positive case is a high-multiplicity mirror of the paper’s fair-assignment problem. The paper’s own comparison with probabilistic serial is useful background, but the mirror should not be PS: objects remain indivisible for every individual, and only the population is made continuous.

Take a finite set of object kinds \(O=\{o_1,\ldots,o_m\}\) and a finite set \(T\) of preference types. A type \(t\in T\) is a complete weak order over \(O\), and \(\mu_t\) is its population mass. Because a fixed stock of \(m\) objects cannot serve a continuum of agents, the natural co-modification is a per-capita supply vector \(s\), where \(s_o\) is the number of copies of object kind \(o\) per unit population. Assume \(\sum_o s_o=k\in\mathbb{Z}\). Clearing denominators gives finite instances with \(N\mu_t\) agents of type \(t\) and \(Ns_o\) copies of \(o\).

Each individual still receives an integral bundle \(b\in\mathbb{Z}_{\ge 0}^m\) with \(\sum_o b_o=k\). The continuous decision variable is

\[ x_{t,b}\ge 0, \]

the mass of type-\(t\) agents receiving bundle \(b\), subject to

\[ \sum_b x_{t,b}=\mu_t \quad\text{and}\quad \sum_{t,b} b_o x_{t,b}=s_o. \]

Thus \(x\) is not a fractional allocation to an individual: every unit of mass receives an integral bundle. It is a distribution of integral assignments across many indistinguishable agents.

For a type \(t\), define \(b\succeq_t^{SD}b'\) by the usual cumulative-rank inequalities,

\[ \sum_{o'\succeq_t o} b_{o'} \ge \sum_{o'\succeq_t o} b'_{o'} \]

for every cutoff object \(o\). The allocation is EF if all agents receive bundles of the same cardinality and, whenever \(x_{t,b}>0\) and \(x_{u,b'}>0\),

\[ b\succeq_t^{SD} b'. \]

For integral bundles this is the natural population version of the paper’s EF condition, which its Lemma 1 identifies with SD envy-freeness. A complete allocation uses all supplies. A maximal EF allocation is one for which there is no EF allocation that can be coupled to it agent-by-agent so that every agent keeps its old bundle and a positive mass receives additional objects.

This is a credible regime in a large school district or university system: many students receive bundles of course seats, housing units, or services; students are grouped by programme, year, accessibility requirements, or contract class; and each group has the same ordinal ranking over replicated object categories. Here \(N\) may be millions while \(\tau=|T|\) is in the dozens or hundreds. The type description includes everything relevant to the problem, so this is genuine high multiplicity rather than an objectionable assumption that named agents have identical prices.

My lead anchor is Theorem 3, proved in this paper. It states:

Assume there exists an algorithm \(\mathcal A\) that returns a maximal envy-free assignment that is complete if a complete envy-free assignment exists. Then \(\mathcal A\) does not take polynomial time assuming \(P\ne NP\).

This is a conditional lower-bound theorem proved by the author. Its proof invokes the NP-completeness of complete-EF existence for strict preferences from Bouveret, Endriss, and Lang, and for dichotomous preferences from Aziz, Gaspers, Mackenzie, and Walsh. The theorem is therefore not itself an independent NP-completeness classification, but it is a named computational impossibility result in the paper.

The corresponding continuous problem is:

\[ \mathsf{MaxCompleteEF}_\infty. \]

An instance consists of rational type masses \(\mu\), rational per-capita supplies \(s\), the finite object-kind set \(O\), and the weak orders defining \(T\). The task is to output a finite-support rational mass allocation \(x\) that is EF and maximal. If any complete EF allocation exists, the output must be complete.

This is precisely the same computational question at the population level: can one construct the strongest EF allocation, and does failure to allocate all available objects certify that no complete EF allocation exists? The objective is not welfare maximisation; it is the paper’s inclusion-maximality and complete-if-possible guarantee.

My conservative expectation is that the unrestricted problem is a Class B candidate. The paper’s hardness may live not in the identities of the agents but in the indivisible object categories and the combinatorics of partitioning them into equally sized, mutually non-envied bundles. Those structures remain after continuization. In that case Theorem 3’s hardness transfers. But there is also a serious Class-A subquestion: for fixed \(\tau\), or for a fixed number of object units per agent, the aggregate problem may reduce to a configuration or flow formulation. The paper’s arbitrary-agent obstruction could then dissolve because the exponentially many named agents have become a small number of mass variables.

The exact boundary is itself valuable. If every type has mass \(1/N\), the model merely embeds the original discrete instance and hardness transfers immediately. If a small number of types carry large masses, the problem tests whether agent multiplicity was the source of the NP-hardness. Further questions include whether complete EF has an LP or separation formulation for fixed \(\tau\), whether rational mass solutions admit exact finite clone realizations, and whether hardness persists when every type has mass bounded away from zero.

A useful supporting anchor is Theorem 1, also proved in this paper. It states that for two agents, GAL runs in \(O(m^2)\) time and returns a maximal EF and locally Pareto-optimal assignment, even with weak preferences; if a complete EF assignment exists, GAL returns one; and no other EF assignment Pareto dominates its output.

Its continuous counterpart is the two-faction problem

\[ \mathsf{GAL}^{(2)}_\infty. \]

The instance has two preference types \(t=1,2\), masses \(\mu_1,\mu_2\), replicated object supplies \(s\), and the same integral-bundle semantics above. The task is to output an EF allocation that is maximal and locally Pareto optimal, complete whenever a complete EF allocation exists, and undominated among EF allocations. Local Pareto optimality means that no allocation using the same aggregate object supply weakly SD-improves every positive-mass agent and strictly improves a positive mass.

The exact clone lift of a two-agent instance has \(\mu_1=\mu_2=1/2\) and \(s_o=1/2\) for every object kind \(o\): \(r\) copies of each original object are allocated among \(2r\) agents. This makes the relationship to the paper transparent. I would expect this two-type version to be Class A, probably through a continuous priority-order or flow argument, although I would not claim that the paper’s \(O(m^2)\) bound automatically survives.

The authors should recognise both questions as their problem. They preserve the same ordinal preference domain, indivisible bundles, EF predicate, maximality, completeness, and Pareto notions. They do not replace indivisible assignments by fractional ownership. GAL’s discussion of probabilistic serial is relevant only as motivation: here a fractional-looking \(x\) records different integral bundles received by different agents.

The weakest point is that scaling object supplies and introducing bundle-distribution variables is a genuine extension of the paper, not a literal theorem already contained in it. Also, if the paper’s NP-hardness uses many distinct preference orders, then \(\tau\) may grow with \(N\), weakening the high-multiplicity interpretation. That is why I would present \(\mathsf{MaxCompleteEF}_\infty\) as the lead open mirror, with the two-type version as the clearest tractable candidate, rather than claiming that GAL itself already supplies a continuous algorithm.

The case AGAINST (opponent, writing after the proponent)

The strongest negative case is that the proposed \(\mathsf{MaxCompleteEF}_\infty\) is not really a continuous relaxation of the paper’s computational problem. It is a new high-multiplicity integer allocation problem, and the paper’s results provide no theorem-level bridge to it.

The key obstruction is exact EF. Suppose \(t\) is a strict preference type and \(x_{t,b},x_{t,b'}>0\). Since two agents of type \(t\) must not envy one another, EF requires both \(b\succeq_t^{SD} b'\) and \(b'\succeq_t^{SD} b\). With strict preferences and equal bundle sizes, this implies \(b=b'\). Thus every positive-mass strict type receives one integral bundle; the alleged distribution \(x_{t,b}\) collapses to a choice of bundles \(b_t\) satisfying

\[ \sum_t \mu_t b_t=s. \]

The masses are merely coefficients in an integer configuration equation. There is no fractional allocation to individuals and no continuous LP structure of the sort that makes continuization analytically or algorithmically distinctive. If one instead compares type-level averages, or permits different realized bundles so long as their averages are fair, one has abandoned the paper’s individual SD-envy-freeness and moved toward probabilistic serial or fractional assignment. That is outcome-space continuity, explicitly outside the programme’s target.

The same problem affects maximality. In the paper, EF requires every agent to receive the same number of objects. Consequently, any faithful extension \(q\) containing \(p\) must add the same number of objects to every positive-mass agent. “A positive mass receives additional objects” is therefore not the natural analogue of the paper’s inclusion maximality; a genuine extension is a jump from one common per-agent bundle size to the next. The proposed coupling is coherent, but it defines a new per-capita packing problem rather than preserving GAL’s inclusion structure.

Theorem 3 is consequently a weak anchor. Its hardness premise concerns arbitrary individually specified preference orders. The paper gives no hardness result for a profile with a small number of repeated types, and the cited NP-complete problem may rely precisely on the information that disappears after quotienting agents by type. Conversely, if one lets \(\tau\) grow with the number of agents so that the original profile is retained, the construction is just a compressed encoding of the discrete instance, not a meaningful high-multiplicity regime. The theorem therefore does not itself establish a continuous mirror; one would first need a formal reduction showing that the relevant hardness or algorithmic question survives the type quotient.

Theorem 1 is even less suitable. GAL is a result for exactly two named agents and one finite set of one-copy objects. Keeping two agents leaves no population to continuize. Replacing them by two positive-mass blocs creates many agents, replicated supplies, and a new bundle-distribution problem; the priority-order and contested-pile argument no longer constitutes a limit of GAL. The proposed \(\mathsf{GAL}^{(2)}_\infty\) is therefore not a continuous version of Theorem 1, but another problem that would need independent justification.

There is also a discontinuity absent from the proponent’s account: under universal EF, a type of mass \(\varepsilon>0\) constrains the allocation just as strongly as a type of mass \(1/2\). Its constraint disappears only when its mass becomes exactly zero. Thus the fairness predicate depends primarily on support, not continuously on population mass. This is a poor fit for a continuum whose intended advantage is that aggregate proportions become the natural quantities.

The negative case nevertheless has a serious limitation. A school district with many students, replicated seats, and a small number of preference or eligibility types is a plausible high-multiplicity regime, and the paper’s subject matter plainly permits such a reinterpretation. Existing high-multiplicity work would strengthen that case rather than defeat it. So the arguments above do not honestly establish that no worthwhile mirror exists. They show only that the two proposed anchors do not transfer automatically: the first becomes a new integer high-multiplicity problem, and the second loses the two-agent structure entirely. The universal negative is therefore not defensible on the paper alone.
