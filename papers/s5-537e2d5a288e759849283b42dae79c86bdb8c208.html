The continuous mirror question

Given a finite candidate set \(A\), ranking types \(T=L(A)\), and rational masses \(\mu\in\Delta(T)\), compute every \(\rho^\star\in\arg\min_{\rho\in L(A)}\sum_{t\in T}\mu_t d_{\mathrm{swap}}(t,\rho)\), together with the set of top alternatives of the minimizing rankings.

The model it lives in

A high-multiplicity electorate has ranking types \(t\in L(A)\) with masses \(\mu_t\); the decision variable is a consensus ranking \(\rho\), and the objective is \(D_\mu(\rho)=\sum_t\mu_t d_{\mathrm{swap}}(t,\rho)\).

What the mirror covers

The mirror covers the Kemeny and Borda MLE results, while leaving Arrow, Gibbard–Satterthwaite, strategic manipulation, STV, and the multiwinner axiomatic results untreated.

Open questions for a prover

  • What is the exact complexity of minimizing \(D_\mu\) when \(m\) is part of the input and the masses are rational?
  • Do single-peaked or otherwise structured supports admit efficient exact or approximation algorithms?
  • How does uncertainty in \(\mu\), or a bounded mass perturbation of \(\mu\), affect the Kemeny winner set?

The case FOR (proponent)

There is a credible positive mirror, led by Kemeny aggregation. But there is an important qualification: this paper contains no numbered theorem, lemma, proposition, or corollary asserting NP-hardness, membership in P, FPT, or a similar complexity classification. Its only explicit complexity claims are unnumbered prose in §3.3: manipulation is polynomial for Plurality and Borda, but NP-hard for STV, citing Bartholdi and Orlin (1991). I therefore cannot honestly present that as a qualifying hardness anchor.

The strongest named anchor is nevertheless Theorem 2.3, proved in the notes. It states that, under Condorcet’s assumptions C0–C3—equally likely true rankings, independent pairwise judgments with accuracy \(p>1/2\), independence between pairwise judgments, and independence between voters—the maximum-likelihood correct ranking is any linear order minimizing \(\sum_i d_{\mathrm{swap}}(\succeq_i,\succeq)\). The theorem allows observed ballots to be tournaments, while the inferred ranking remains a linear order. This is precisely the optimization underlying the paper’s Kemeny rule.

My lead problem would be:

Continuous Kemeny-MLE. An instance consists of a finite candidate set \(A\), the finite type set \(T=L(A)\) of complete rankings, and a rational population distribution \(\mu\in\Delta(T)\). For each ranking \(\rho\in L(A)\), define \(D_\mu(\rho)=\sum_{t\in T}\mu_t d_{\mathrm{swap}}(t,\rho)\). The task is to return every minimizer \(\rho^\star\in\arg\min_{\rho\in L(A)}D_\mu(\rho)\), together with the winner set \(\{\operatorname{top}(\rho^\star):\rho^\star\text{ is optimal}\}\). A solution is correct exactly when it provides the optimal Kemeny distance and the complete set of minimizing top alternatives.

This is not a softened version of Kemeny. If a finite profile has \(n_t\) voters of type \(t\), then setting \(\mu_t=n_t/n\) gives \(D_\mu(\rho)=n^{-1}\sum_i d_{\mathrm{swap}}(\succeq_i,\rho)\), so the minimizers are identical. The population has become continuous; the candidate rankings, swap distance, and optimization problem have not.

A convincing regime is a large electorate with a fixed or moderately sized set of alternatives, where voters fall into repeated preference classes induced by party platforms, standard issue packages, organizational recommendations, or recurring survey profiles. Millions of voters may therefore be represented by a much smaller number of distinct rankings. Here \(\mu_t\) means the fraction of the electorate of type \(t\), and the type is a complete ranking, exactly as required by the paper’s objective. This is a sensible high-multiplicity instance regime, not an arbitrary probability reinterpretation.

I would expect this mirror to be Class B. Every discrete Kemeny instance embeds exactly by taking rational masses \(\mu_t=n_t/n\). Thus any hardness caused by the number and interaction of alternatives survives continuization. Conversely, when \(m\) is fixed, the finite ranking space is fixed and the continuous problem is directly solvable by enumeration. The interesting further questions are whether structured domains such as single-peaked rankings make the continuous problem tractable, whether approximate minimization has useful guarantees, and how much population mass must move before the Kemeny winner changes.

A second, supporting anchor is Theorem 2.4, “Borda as MLE,” proved in the notes and attributed to Conitzer and Sandholm (2005). It states that, under assumptions C0, C1, C3, and C4, together with the stated conditional rank-likelihood condition \(\Pr(i(x)=k\mid \max_{\succeq}(A)=x)\sim 2^{m-k}\), the Borda rule is the maximum-likelihood estimator of the correct winner.

Its continuous counterpart is:

Continuous Borda-MLE. An instance consists of \(A\) and a rational distribution \(\mu\) over complete rankings. Define \(B_\mu(c)=\sum_{t\in L(A)}\mu_t(m-\operatorname{pos}_t(c))\). The task is to return \(\arg\max_{c\in A}B_\mu(c)\), including all tied winners. A solution is the exact winner set and the corresponding scores.

This is a natural Class A mirror: compute every \(B_\mu(c)\) by a weighted sum and compare the results, in time polynomial in \(m\), the explicit number of types, and the bit-length of the masses. Again, this is not merely outcome-space fractionalization. The candidates and ballots remain discrete; only the electorate is represented by mass. The resulting score is exactly the normalized finite Borda score.

The Borda mirror is weaker as a research contribution because it is algorithmically immediate. Its value is that it demonstrates the programme’s basic bridge cleanly: the discrete sum over voters becomes an expectation over population types, while the MLE interpretation remains intact. It also generates genuine follow-up problems, such as the minimum mass perturbation needed to change the Borda winner, continuous manipulation by a positive-mass bloc, and robustness under uncertainty in \(\mu\).

These mirrors cover only the paper’s Kemeny and Borda MLE results. They do not claim to continuize Arrow’s theorem, Gibbard–Satterthwaite, STV manipulation, or the multiwinner axiomatic results. Those are either axiomatic rather than computational or require a careful redesign of individual manipulation: a single voter has zero mass in a continuum, so one must replace her by a positive-mass bloc, which is a materially different problem.

The weakest point is therefore clear. The paper is primarily lecture notes on voting theory, not a computational-complexity paper, and it lacks a qualifying numbered complexity anchor. The Kemeny mirror is a strong and faithful high-multiplicity object, but its exact equivalence with the finite problem means that continuization is expected to preserve hardness rather than dissolve it. Borda supplies a clean tractable mirror, but it is too elementary to carry the programme alone. I would therefore make a positive case for the existence and legitimacy of a continuous mirror, especially for Kemeny, while not presenting this paper as a strong source of new continuum-specific complexity results.

The case AGAINST (opponent, writing after the proponent)

The strongest negative case is that this is the wrong paper for the programme’s core target. It contains no numbered theorem, lemma, proposition, or corollary establishing membership in P, NP-hardness, FPT tractability, or any comparable computational classification. Theorem 2.3 and Theorem 2.4 are statistical characterizations; Arrow’s and Gibbard–Satterthwaite’s results are axiomatic; and the manipulation complexity claims in §3.3 are unnumbered prose. Thus the paper supplies no named computational result whose continuization could directly advance ChoCo’s complexity landscape.

The Borda anchor is correspondingly weak. For a distribution \(\mu\), the quantity
\[ B_\mu(c)=\sum_t\mu_t\bigl(m-\operatorname{pos}_t(c)\bigr) \]
is simply a weighted average, and finding its maximizer is immediate. Calling this a continuous Borda-MLE does not add computational substance. If one instead asks for the minimum mass transfer needed to change the Borda winner, that can be a legitimate ChoCo problem, but it is a new intervention problem, not a mirror of Theorem 2.4. The MLE interpretation itself also requires care: an arbitrary \(\mu\) is not a likelihood model, only a population-risk distribution. One can repair this by defining an infinite-population expected log-likelihood, but the resulting computation remains the same elementary weighted score comparison.

The Kemeny anchor is much harder to defeat. Its objective
\[ D_\mu(\rho)=\sum_{t\in L(A)}\mu_t\,d_{\mathrm{swap}}(t,\rho) \]
is a perfectly meaningful high-multiplicity version of Kemeny aggregation. A large electorate with repeated rankings is an entirely credible regime, and the type—complete ranking—is exactly the information the rule uses. Rational masses recover every finite profile, so this is a legitimate Class B mirror.

The best objection is that the construction introduces no new continuum-specific algorithmic phenomenon: it is merely weighted Kemeny optimization over permutations, and its hardness survives unchanged. But that objection is expressly unavailable under the programme’s rules. A faithful high-multiplicity restatement is not disqualified because it preserves the discrete answer or hardness; indeed, Kemeny is precisely the kind of problem the programme identifies as a natural hardness-transfer case. The MLE terminology can be replaced by population-risk minimization if necessary, without removing the computational question.

So the honest negative conclusion is limited. The paper is a poor source of new continuous complexity results, and the Borda mirror is too routine to carry a programme. But I cannot defeat the Kemeny anchor: it is a natural continuous-population problem, not an outcome-space or axiomatic continuization, and it remains worthwhile even if its final classification is Class B. A universal claim that no worthwhile mirror exists is therefore not supportable.
