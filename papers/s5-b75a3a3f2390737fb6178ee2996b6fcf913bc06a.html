Why no mirror

Theorem 1 is a named computational result, but its axioms track particular people: one person’s report can affect others’ positions while that person’s own position remains fixed. A type-mass vector cannot identify which person reported which type or assign a rank to that person; retaining pointwise identities makes individual changes invisible to the mass input, and the proposed finite encoding omits those changes. The stated mirror therefore changes or makes vacuous the central question rather than giving it a computational analogue over a distributional society.

What the mirror covers

The proposed attempt addresses Theorem 1 only; it leaves Theorems 2–4 and their results untouched. No distributional mirror of Theorem 1 survives.

The case FOR (proponent)

The strongest anchor is Theorem 1, proved in this paper: for every \(n\ge4\), there is an \(n\)-ranking mechanism satisfying impartiality, monotonicity, and individual full rank. The paper constructs these mechanisms and says they can be implemented in polynomial time. This is an algorithmic anchor; the paper offers no named NP-hardness result, so this mirror would not test whether discrete hardness disappears in the continuum.

A plausible setting is a large member-owned organization producing a priority ranking of its members. Many members might use one of a small number \(\tau\) of shared ranking templates—for instance, templates ordering role categories, with a common public ordering within each category. Each member is both a reporter and someone ranked. The regime of interest has \(n\) members with \(n\) much larger than \(\tau\). The templates are complete rankings for the problem; members sharing one are otherwise indistinguishable.

I would call the proposed mirror Atomless Impartial Full-Rank Aggregation. Let the population be \(\Omega=[0,1]\) with Lebesgue measure. An instance specifies a finite set \(T\) of complete measurable strict orders \(\succ_t\) over \(\Omega\), and allows measurable report profiles \(\theta:\Omega\to T\), with type masses \(\mu_t=\lambda(\theta^{-1}(t))\). A solution is a single rule \(\Phi\) on these profiles. For each \(\theta\), it returns a measurable, measure-preserving bijection \(\rho_\theta:\Omega\to[0,1]\); \(\rho_\theta(x)\) is person \(x\)’s rank, with smaller values better. Measure preservation ensures that the continuum of rank positions is fully occupied.

The rule must satisfy direct continuum versions of Theorem 1’s three axioms:

  • Impartiality: if \(\theta'\) differs from \(\theta\) only in \(x\)’s report, then \(\rho_{\theta'}(x)=\rho_\theta(x)\).
  • Monotonicity: if only \(x\)’s report changes and the new order raises \(y\) while leaving the relative order of everyone else unchanged, then \(\rho_{\theta'}(y)\le \rho_\theta(y)\).
  • Individual full rank: for every \(x\in\Omega\) and every \(q\in[0,1]\), some allowed profile gives \(x\) rank \(q\).

The computational version asks for a finite-description rule that can be evaluated efficiently on finitely encoded profiles—for example, profiles represented by rational interval partitions—and returns a finite description of \(\rho_\theta\). The expected direction is Class A: divisibility should help with assigning rank mass, and the paper’s blocking construction suggests a possible starting point for an explicit rule. Further questions include whether the rule can be uniform across type sets and whether a continuum version can add weak unanimity.

This case covers Theorem 1 only. It preserves the unusual central feature of the paper: people both submit rankings and receive positions in the output. The paper’s Theorems 2–4 are outside this proposed mirror.

My weakest point is that the canonical ChoCo input is the type-mass vector \(\mu\), while individual impartiality requires knowing which identity carries which report. If the rule sees only \(\mu\), changing one person’s report leaves the input unchanged, and impartiality—and much of monotonicity—can become vacuous. The proposed rule therefore sees the identity-to-type assignment as well as the masses. That keeps the axioms meaningful and makes this recognizably the authors’ rank-aggregation problem, but it weakens the case that the mirror is a clean high-multiplicity problem in ChoCo’s distribution-only model.

The case AGAINST (opponent, writing after the proponent)

Theorem 1 is a genuine computational anchor: it gives a constructive, polynomial-time mechanism. I would not argue that the paper has no result to mirror. The problem is that the result ranks named people, and its axioms depend on that person-by-person structure. The proposed continuum does not resolve how to preserve it while making the population a ChoCo-style distribution.

The large-organization scenario starts plausibly: many members might use the same ranking templates. But holders of one template are still distinct alternatives in the output. The mechanism assigns each a particular position, and impartiality asks what happens to that particular person when their report changes. So shared preferences alone do not make those members interchangeable for this problem. Put identity into the type, and support grows with the population; the high-multiplicity compression is lost. Leave identity out, and a mass vector over templates cannot say which person holds which report or which person receives which rank.

The atomless proposal makes the tradeoff explicit. If the input is just the type masses \(\mu\), changing one person’s report changes no mass. The whole outcome is then unchanged: impartiality and monotonicity hold automatically, but reports have no effect on anyone’s placement. That loses a central feature of the finite mechanism, where one person’s report can affect others’ positions. To keep that feature, the input must retain the identity-to-report assignment. Yet a singleton change is invisible to a distribution over \([0,1]\). Encoding arbitrary singleton changes requires pointwise identity data; encoding identity as part of the type gives an uncountable type space rather than a finite-support instance with moderate \(\tau\). Restricting inputs to rational interval partitions avoids that encoding problem only by leaving out the individual changes the axioms are about.

The output has the same difficulty. A mass distribution over ranks for each template could describe how much of each group occupies each rank range, but it would not specify which individual receives which rank. Restoring that mapping gives an identity-indexed object again. Calling it a finite-description rule does not settle the issue: its input must still represent pointwise changes, and its output must still assign ranks to named individuals.

Weak unanimity, suggested as an extension, does not repair this mismatch; it still concerns the placement of each individual. Unanimity-style conditions also need care in an atomless model: if agreement is defined almost everywhere, changing one person’s report cannot affect it; if defined pointwise, the same encoding problem returns.

A distinct theory of identity-indexed continuum mechanisms may be worth studying. But on this paper’s strongest anchor, the available choices seem to remove either the population compression or the individual-level question that makes Theorem 1 interesting. I do not see a worthwhile ChoCo mirror without changing that question.
