The case FOR (proponent)

The strongest honest positive case is that this paper’s label inference problem has a plausible high-multiplicity version. The limitation is that the paper supplies no named computational result to anchor that case: it has no numbered theorem, lemma, corollary, or proposition establishing a complexity classification. Equations (1)–(12) define the model and inference procedure; Tables 4–6 report empirical results. Those are not qualifying anchors, so I cannot honestly present a continuous mirror as an analogue of a result proved here.

A concrete, but explicitly unanchored, mirror would be *Population GLAD Inference*. Let \(T\) be a finite set of worker types, with rational masses \(\mu_t\) summing to one. A type records the worker attributes and response parameters used by the model, so workers of that type share expertise and worker-specific bias parameters. Let \(V\) be a finite set of items and \(K\) the label categories. For each type, item, context stratum \(c\), and response \(r\), the input gives a rational mass \(q_{tvcr}\) of the total workforce that produced that response; the masses must respect the assignment and per-capita workload limits. Context strata carry the session and response features, while items carry their item features.

Using the paper’s model, define
\[ p_{tvc}=\sigma\!\left((e_t+x_t^\top\beta_U+x_{tc}^\top\beta_S) \exp(d_v+x_v^\top\beta_V)+x_{tvc}^\top\alpha_t\right). \]
Given an item’s true label \(\ell_v\), response \(r\) has probability \(p_{tvc}\) if \(r=\ell_v\), and \((1-p_{tvc})/(|K|-1)\) otherwise. The computational question is to find an \(\epsilon\)-optimal item-label vector \(\ell\) and model parameters \(\Theta\) maximizing the population version of the paper’s log-posterior score:
\[ \sum_{t,v,c,r}q_{tvcr}\log P_\Theta(r\mid \ell_v,t,v,c) +\sum_v\log\theta_{\ell_v} +\log p(\Theta\mid H_0). \]
This asks for the same underlying inference the paper studies—predicting item truths from noisy responses and side information—with response contributions weighted by population mass. It covers true-label inference and, with held-out response masses, unseen-response prediction. It does not cover the paper’s feature-importance analysis.

A plausible regime is a large annotation workforce serving recurring tasks, where many workers share the same task qualifications, demographic or self-reported feature bins, and response behavior. Then \(N\), the number of workers, can be large while the number \(\tau=|T|\) of distinct types stays moderate. The mirror seems recognizable to the authors: it replaces repeated workers with type-level masses while retaining their GLAD likelihood and label-prediction goal. I would not infer tractability from that alone; the latent labels and logistic parameters leave a mixed discrete and continuous optimization problem. The paper provides no complexity result from which to classify this candidate.

The weak point is the regime’s relationship to the paper’s sparse-label setting. Its experiments collect only three responses per item. To obtain stable positive response masses as the workforce grows while keeping a finite item set, each item’s response quota must grow with the workforce; if each item still gets only \(O(1)\) responses, the type-level population limit does not supply those stable masses. The paper’s reported datasets also have only 160–505 workers, and their feature combinations may produce many distinct types. So this is a sensible scenario for the underlying inference problem, but not a continuous analogue of a named computational result in this paper.

The case AGAINST (opponent, writing after the proponent)

The strongest negative is that this paper gives ChoCo no computational result to mirror. It states no complexity theorem and gives no exact, approximation, or parameterized algorithm with guarantees. Equations (1)–(12) define a probabilistic model and an inference procedure; the results are empirical comparisons on three datasets. The other analyst named no qualifying result either. Their “Population GLAD Inference” is therefore a proposed new question, not a continuous mirror of a result in this paper.

That proposal also changes the task. The paper samples latent labels and updates model parameters to estimate posterior label probabilities. The proposed question maximizes a joint score over labels and parameters. Joint MAP need not give the marginal posterior predictions the paper evaluates. One could formulate a population version of posterior inference instead, but that would still be a new computational question without a result here to anchor it.

There is a fidelity problem as well. GLAD assigns each worker their own expertise \(e_u\) and, in the response-feature model, their own bias vector \(\alpha_u\), with worker-level priors. If a type contains only observed features, sharing one \(e_t,\alpha_t\) across its members changes those worker-specific effects into common type parameters. If a type includes the exact latent parameters, independent worker variation can make the support grow with the workforce. A finite latent-class model could avoid that, but it is an extra modeling assumption, not an aggregation supplied by the paper.

The proposed regime also sits awkwardly with the paper’s sparse-label setting. For a fixed item set, keeping positive response mass per item as the workforce grows means collecting more responses per item, which removes the sparsity that motivates the framework. If the item catalog grows so each item still gets only a few responses, each item’s share of the normalized workforce vanishes; preserving its finite evidence then requires an additional scaling or a different population model.

So I can defeat every anchor actually raised: there are none, and the proposed problem is not a faithful mirror without further choices. I cannot honestly establish the broader claim that no continuous version of GLAD could ever be worthwhile. A finite-class workforce model could be sensible and interesting. Its weakness for this programme is that it would be a new model and complexity question, not a mirror of a computational result in this paper.
