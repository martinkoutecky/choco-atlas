The case FOR (proponent)

I can’t make a compliant anchor based case for a continuous mirror: the paper has no named computational complexity result asserting that a problem is in P, NP hard, FPT, or similar.

The nearest results are Theorem 3 (proved here), which says that for any \(n\)-node tree and \(T \le n\ln n/(32\ln\ln n)\), a Correct majority appears by time \(T\) with the stated high probability; and Theorems 5 and 6 (also proved here), which say that asynchronous majority dynamics stabilize in a Correct majority with high probability on preferential attachment trees and balanced \(M\)-ary trees, respectively. These are probabilistic claims about the dynamics and its number of rounds. The \(O(n\ln n/\ln\ln n)\) bound is not the running time of an algorithm solving a computational problem. Theorem 2 is cited from [26] and is a probability inequality, not a complexity result either.

One could study a continuum of agents arranged in a balanced hierarchy and ask whether Correct opinions eventually hold a majority. But that would mirror the paper’s analytic dynamics question, not a computational question of the kind this programme asks. There is therefore no eligible anchor here from which to state the required continuous problem or predict its complexity class.

The case AGAINST (opponent, writing after the proponent)

The proponent’s strongest point is also the main obstacle: the paper supplies no named computational problem whose complexity a continuous mirror could classify. Theorem 3 bounds, with high probability, when a correct majority appears in a stochastic process. Theorems 5 and 6 bound whether that process stabilizes correctly on two tree families. Their \(O(n\ln n/\ln\ln n)\) quantity is the number of update rounds, not the running time of an algorithm that takes an instance and returns a solution. None asks for an algorithm, a complexity class, or a resource trade-off. Theorem 2 is a cited probability inequality.

A natural continuous restatement would track the mass of correct announcements over time and ask whether it exceeds one half. But mass by private belief alone discards the feature that drives these results: the tree’s edges and paths. A star and a line can have the same proportions of correct and incorrect private signals, yet their asynchronous dynamics behave differently. To preserve the result, the model needs the network relation as well as the population distribution.

The stronger proposed mirror would put mass on network roles and retain an edge relation between them, then ask whether a continuum of agents stabilizes with a correct majority. That could be a meaningful study of continuum network dynamics. It still mirrors a probabilistic convergence theorem, not a computational result of the kind ChoCo is charting. If one adds a task such as choosing which agents to influence, or computing stabilization probabilities from a finite representation of the network, one has introduced a new computational problem absent from the paper. Replicating many copies of a tree does not close the gap: it can make frequencies across copies continuous, but it leaves the paper’s result as a statement about stochastic dynamics.

So the negative case is strong for the paper’s actual results and weak only against the literal universal claim. One can invent a computational task around almost any model. Here, that would be a follow-on project, not a continuous mirror of a result the authors proved.
