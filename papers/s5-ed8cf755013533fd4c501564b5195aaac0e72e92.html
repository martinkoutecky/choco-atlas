The continuous mirror question

Given \(m\) goods and \(\tau\) types with rational masses \(\mu_t\), per-member endowments \(e_t\), and WGS demand systems \(D_t\) with elasticity at least \(-f\), compute prices \(p\) and, for each type \(t\), an individual price vector \(\hat p_t\), desired bundle \(z_t\), and allocation \(x_t\). Require \(p \le \hat p_t \le (1+\epsilon)p\), \(z_t \in D_t(\hat p_t,p^\top e_t)\), \(0 \le x_t \le z_t\), \(\sum_t \mu_t x_t \le \bar e := \sum_t \mu_t e_t\), and \(p^\top(\bar e-\sum_t\mu_t x_t) \le \epsilon p^\top\bar e\).

The model it lives in

Represent each type \(t\) by one agent with endowment \(\mu_t e_t\) and aggregate demand \(\widehat D_t(p,B)=\mu_t D_t(p,B/\mu_t)\). Apply Theorem 3.3 to the \(\tau\) representative agents, then divide their allocations by \(\mu_t\) to obtain per-member bundles. The objective is to compute an approximate equilibrium; there is no separate social-welfare objective.

The objection that survived

The mirror adds no algorithmic difficulty: each type is exactly one scaled representative agent under Theorem 3.3. This limits its novelty, but does not invalidate the population-as-mass question.

fatal: False

What the mirror covers

The mirror covers Theorem 3.3 for bounded-elasticity WGS exchange markets; it leaves the other price-update implementations and the spending-restricted Nash social welfare application outside its scope.

The case FOR (proponent)

The strongest mirror I believe in is a continuum exchange market with bounded-elasticity WGS types. It keeps the paper’s computational question—finding an approximate market equilibrium—and changes the society from a list of agents to a distribution over complete agent types.

Let the population have total mass \(1\), with \(\tau\) supported types and rational masses \(\mu_t>0\), where \(\sum_t\mu_t=1\). A type includes its WGS demand system and per-member endowment vector \(e_t\); all members of that type share those parameters. The total endowment per unit of population is \(\bar e=\sum_t\mu_t e_t\), and at market prices \(p\), a type-\(t\) member’s budget is \(b_t=p^\top e_t\). A plausible regime is a very large resource market whose participants fall into a relatively small number of preference and endowment classes, so the underlying population size \(N\) is much larger than \(\tau\).

Call the problem Mass WGS Equilibrium. Its input is \(m\) goods, those \(\tau\) types and masses, rational endowments, an accuracy \(\epsilon>0\), and a demand oracle for each type. Ask for market prices \(p\) and an allocation certificate. To preserve the paper’s approximate-equilibrium definition, the certificate may split each type into subcohorts: for type \(t\), choose weights \(\alpha_{tr}\) summing to \(1\), and for each subcohort choose prices \(\hat p_{tr}\), an actual bundle \(x_{tr}\), and a desired bundle \(z_{tr}\). Require \(p\le\hat p_{tr}\le(1+\epsilon)p\), \(z_{tr}\in D_t(\hat p_{tr},b_t)\), and \(0\le x_{tr}\le z_{tr}\). With \(\bar x_t=\sum_r\alpha_{tr}x_{tr}\), the market conditions are \(\sum_t\mu_t\bar x_t\le\bar e\) and \(p^\top(\bar e-\sum_t\mu_t\bar x_t)\le\epsilon p^\top\bar e\). At most \(2m+1\) subcohorts per type suffice to represent any feasible aggregate pair of actual and desired bundles, by Carathéodory’s theorem. The output is a price vector and per-type mass allocation satisfying demand and approximate clearing; there is no separate social-welfare objective.

The anchor is Theorem 3.3, proved in this paper. It says that if every agent has a WGS demand system with elasticity at least \(-f\), an \(\epsilon\)-approximate market equilibrium can be computed in time \(O(nm^2fT_D\epsilon^{-2}\log(p_{\max}/p_{\min}))\), where \(T_D\) is the time for one demand-oracle call. The concrete mirror can use Cobb–Douglas types or CES types with substitution parameter greater than \(1\), which the paper identifies as WGS systems with bounded elasticity. This is an algorithmic anchor, not a hardness result. The paper’s statement that NSW is NP-hard for additive utilities is unnumbered, so I do not use it as an anchor.

I expect the mass problem to be tractable, in Class A, with a runtime polynomial in \(m,\tau\), the input bit length \(L\), \(f\), \(1/\epsilon\), and the demand-oracle cost, plus the relevant price-range bound. The reason is structural: the paper’s price-update procedure works type by type, and its bounded-elasticity implementation takes \(O(mfT_D)\) time per call. A mass version could transfer quantities between subcohorts rather than process each named agent. That adaptation is plausible, but not proved by Theorem 3.3. The key follow-up questions are whether the auction invariants survive weighted mass transfers, whether the certificate can be kept polynomial in size, and how the price bound depends on small rational masses. A formal finite-to-continuous dictionary would also need to account for bit complexity when rational type masses are expanded into repeated finite agents.

The authors should recognize this as their market-equilibrium problem: the same demand systems, budgets, price updates, and approximate clearing conditions remain in place; the society is the object being changed. The mirror covers the bounded-elasticity exchange-market result, not the paper’s full NSW allocation and rounding application.

My weakest point is that the paper already gives a polynomial algorithm in the explicit agent count \(n\). The mirror matters as a distinct regime when \(N\) is huge but the support size \(\tau\) is small; without that compressed input regime, it risks looking like a weighted restatement. It is also an algorithmic mirror, so it does not test the programme’s central question of whether a discrete hardness result disappears in the continuum.

The case AGAINST (opponent, writing after the proponent)

The only anchor raised is Theorem 3.3. Its proposed Mass WGS Equilibrium has an exact representative-agent formulation, so this particular mirror does not need a new mass-transfer algorithm.

For a type \(t\) of mass \(\mu_t\), per-member endowment \(e_t\), and demand system \(D_t\), give one representative agent endowment \(\widehat e_t=\mu_t e_t\) and demand system
\[ \widehat D_t(p,B)=\mu_t D_t\!\left(p,\frac{B}{\mu_t}\right). \]
At prices \(p\), its budget is \(p^\top\widehat e_t=\mu_t p^\top e_t\), so its demand is exactly the aggregate demand of that type. This scaling preserves WGS and the elasticity bound. It also works through the demand-oracle interface: divide the budget by \(\mu_t\), query the original oracle, then multiply the returned bundle by \(\mu_t\).

The resulting exchange market has \(\tau\) agents and the same total supply as the continuous society. Apply Theorem 3.3 with \(n=\tau\), then divide each representative agent’s actual and desired bundles by \(\mu_t\) to give every member of that type a per-member allocation. The approximate clearing condition maps directly, and one cohort per type suffices. Rational masses add only their bit-length to the oracle arithmetic; there is no need to expand them into \(N\) named agents. The theorem’s runtime therefore gives the proposed polynomial dependence on \(\tau\) directly, subject to its same price-range and oracle assumptions.

That defeats the raised anchor as a worthwhile *new* algorithmic question: the best version of the mirror is already a change of units in the theorem’s input, even for non-homothetic demand oracles. A mirror with infinitely many supported types would escape this reduction, but it would need a new finite encoding and falls outside the programme’s stated finite-support input model.

The negative case is limited. ChoCo explicitly treats a finite-to-continuous dictionary as a possible result, so a reader could value this reduction itself. My case is that this instance is too immediate to warrant a research programme, not that no continuous mirror could ever be worthwhile.
