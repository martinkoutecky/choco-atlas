The case FOR (proponent)

The positive case is narrow. The paper has no named result asserting a standard complexity classification such as membership in P or NP-hardness. Its closest computational anchor is Theorem 8, proved in this paper: for distinct vote totals \(p_1>\cdots>p_n\), it gives an exact formula for the number of sequential apportionment sequences obtainable as the stationary cutpoint varies. For each party pair \(k=\{i,j\}\), let
\[ m_k=\frac{p_i-p_j}{\gcd(p_i,p_j)} \quad\text{and}\quad A_k=\left\{0,\frac1{m_k},\ldots,\frac{m_k-1}{m_k}\right\}. \]
The number is
\[ 1+\left|\bigcup_{k\in M}A_k\right| = 1+\sum_{\varnothing\ne J\subseteq M}(-1)^{|J|+1} \gcd(m_k:k\in J), \]
where \(M\) is the set of all party pairs and a singleton gcd is its sole element. This is an exact counting theorem, not a complexity classification. If your anchor rule requires a result explicitly placing a problem in a complexity class, then the paper has no qualifying anchor; I would not present Theorem 8 as one.

If an exact counting result is acceptable as an anchor, the strongest mirror is Rational-Mass Stationary Sequence Count. An instance is a finite set of party-support types \(T=\{1,\ldots,n\}\) with distinct positive rational masses \(\mu_i\) summing to \(1\). Starting with seat counts \(a_i=0\), for each cutpoint \(c\in[0,1]\), award the next seat to a party maximizing \(\mu_i/(a_i+c)\), using the paper’s tie-breaking rule and its special initialization for \(c=0\). The question is: how many distinct full apportionment sequences arise as \(c\) ranges over \([0,1]\)? The required output is that exact integer count. Theorem 8 supplies its formula after converting the rational masses to their primitive integer vote vector.

The population regime is plausible: millions of voters may cast ballots for a small set of parties, so \(N\) is large while the support size \(\tau=n\) is small. A type is “casts a vote for party \(i\)”; its mass is that party’s fraction of the electorate. Voters who differ in other ways can share a type so long as those differences do not affect this apportionment problem. This asks about the paper’s actual object—the order in which seats go to parties—not about a fractional-seat variant. The authors should recognize it: they explicitly study sequences as a function of party vote shares.

I expect the continuous problem to be equivalent to the discrete rational-vote problem, so any hardness of exact sequence counting would transfer directly; the paper establishes no such hardness, so its actual complexity remains open. Natural follow-up questions are whether the count can be computed in time polynomial in \(n\) and the bit length of \(\mu\), and whether the interval partition can be listed in output-sensitive time.

The weakness is also the reason this mirror is author-faithful: the paper already has integer vote totals, studies a scale-invariant method, and proves homogeneity. Every rational mass vector can be scaled to integer votes, and vice versa. Thus the mirror is a credible continuous-population formulation, but it introduces little new mathematical territory. The paper’s Theorem 8 gives a counting formula; it does not establish the computational-complexity result the programme ultimately seeks.

The case AGAINST (opponent, writing after the proponent)

The strongest objection is that the proposed count mirror is already the paper’s problem in normalized coordinates. Take voter types to be the parties they vote for. For any rational society \(\mu\), clear denominators to get integers \(q_i=D\mu_i\), then divide by their common gcd to obtain the primitive vote vector \(p\). At every seat state, comparing \(\mu_i/(a_i+c)\) across parties gives exactly the same winner as comparing \(p_i/(a_i+c)\). The pairwise thresholds are unchanged too:
\[ \frac{q_i-q_j}{\gcd(q_i,q_j)} = \frac{p_i-p_j}{\gcd(p_i,p_j)}. \]
So Theorem 8 gives the exact count for every rational mass vector, including ties via Corollary 5. This is more than an outside result that happens to give the same answer: the proposed input and output are mathematically identical to the paper’s, after rescaling.

That identity also defeats the better versions of the same mirror. Asking for the sequence, its initial \(h\) seats, or the cutpoint intervals producing distinct sequences stays within the paper’s existing sequence analysis. And duplicating the electorate changes nothing: homogeneity leaves the sequence and the pairwise thresholds invariant. There is no new population-size behavior to analyze in this model.

There is no theorem classifying a standard decision problem as polynomial-time or hard. Theorem 8 is an exact counting formula, not a running-time result. One could ask how quickly to evaluate that count from binary-encoded masses; that is a legitimate algorithmic question. But it is the same arithmetic function on the same rational vectors as the paper’s integer-vote problem. It may merit algorithmic study, yet it does not establish a distinct continuous-population question or bring in continuous optimization.

This negative case is limited. The population interpretation is natural, the types are genuinely repeated voter types, and the sequence-count question is well posed. A separate robustness question—how much mass must shift between party-vote types to force a specified seat order—could be a worthwhile continuous problem, though it adds a new intervention question beyond the paper’s count over cutpoints. I cannot honestly rule out every worthwhile mirror. The strongest case against is that the proponent’s sole anchor has already been solved on exactly the rational-mass domain the programme uses; whether a follow-up on its computational complexity is enough to justify a mirror remains the weak point in the negative case.
