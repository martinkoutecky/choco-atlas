The continuous mirror question

Given rational type masses μ_t, where each type has eligibility set \(F_t\) and claim \(x_t\), and per-capita resource supplies \(r_a\) satisfying \(∑_{a∈A} r_a ≤ ∑_{t:F_t\cap A\ne\varnothing}\mu_t x_t\) for every \(A\subseteq Q\), compute the unique feasible per-type allocation \(y_{ta}\ge 0\) minimizing \(∑_t\mu_t[\sum_{a\in F_t}y_{ta}^2+(x_t-\sum_{a\in F_t}y_{ta})^2]\), subject to \(∑_{a\in F_t}y_{ta}\le x_t\) and \(∑_{t:a\in F_t}\mu_t y_{ta}=r_a\).

The model it lives in

A supported population distribution over complete worker types \(t=(F_t,x_t)\), with per-capita resource supplies \(r_a\); choose one per-agent flow \(y_{ta}\) for each type, exhaust each resource supply, respect each type's claim, and minimize the mass-weighted quadratic allocation and unmet-claim objective.

What the mirror covers

The mirror asks for the computed allocation for the fixed quadratic member of Theorem 3.3's family. It leaves the other \(W,B\) choices, the remaining numbered results, and the paper's characterization and strategic-mechanism questions aside.

Open questions for a prover

The case FOR (proponent)

The strongest honest anchor is Theorem 3.3, stated here as a result of Moulin and Sethuraman (2011); this excerpt does not prove it. There is no named complexity classification in the paper. Theorem 3.3 is an explicit optimization formulation for computing a fair allocation, so it is the best computational anchor under the formulation allowance—but it is not itself a result saying the problem is in P or hard.

The theorem says: fix a strictly convex function \(W\) and a convex function \(B\). For every bipartite rationing problem \(P\), choose a maximum flow \(\tilde\varphi\) minimizing
\[ \sum_{(i,a)\in G} W(\varphi_{ia}) +\sum_{i\in N} B\!\left(x_i-\sum_{a\in f(i)}\varphi_{ia}\right). \]
The resulting method is symmetric, continuous, and edge-consistent. Strict convexity of \(W\) also makes the minimizing flow unique. The theorem covers a family of fairness methods; I would mirror its fixed quadratic member, \(W(z)=B(z)=z^2\), whose objective penalizes large edge allocations and unmet claims.

Call the proposed mirror High-Multiplicity Quadratic Bipartite Rationing. Its instance has resource types \(Q\), and a supported set \(\mathcal T\) of agent types. A type \(t\) consists of an eligibility set \(F_t\subseteq Q\) and a per-agent claim \(x_t\). Its population mass is a binary rational \(\mu_t>0\), with \(\sum_t\mu_t=1\). Each resource \(a\) has a per-capita supply \(r_a\). Require feasibility: for every \(A\subseteq Q\),
\[ \sum_{a\in A}r_a \le \sum_{t:F_t\cap A\ne\varnothing}\mu_t x_t. \]
The decision variable is \(y_{ta}\ge 0\), the amount of resource \(a\) allocated per member of type \(t\), for \(a\in F_t\). It must satisfy
\[ \sum_{a\in F_t}y_{ta}\le x_t \quad\text{for every }t, \qquad \sum_{t:a\in F_t}\mu_t y_{ta}=r_a \quad\text{for every }a. \]
The task is to find the unique feasible allocation minimizing
\[ \sum_{t\in\mathcal T}\mu_t \left[ \sum_{a\in F_t}y_{ta}^{2} + \left(x_t-\sum_{a\in F_t}y_{ta}\right)^2 \right]. \]
This is the same fair max-flow selection problem, expressed over population masses. It is a rational convex quadratic program with size polynomial in the support, graph, and input bit length, so I expect this fixed quadratic mirror to be tractable.

A plausible regime is large-scale workforce or load balancing: many workers, a comparatively small set of qualification-and-demand profiles, and job categories whose capacities grow with workforce size. For example, millions of workers might occupy a few hundred types determined by qualification set and workload claim. Eligibility and claims are exactly what distinguishes agents in this rationing problem, so grouping them is faithful to the paper’s model. For a finite population with \(n_t\) members of each type, set \(\mu_t=n_t/n\) and scale each total resource capacity by \(1/n\). Symmetry and strict convexity make identical agents receive identical per-capita flows; multiplying the displayed objective by \(n\) recovers the corresponding finite-agent objective. Thus the mirror has a direct high-multiplicity bridge, rather than merely making the resource outcome fractional.

I consider this a plausible analogue of the authors’ underlying problem: it retains claims, compatibility, constrained access, full use of overdemanded supplies, and their convexly selected max-flow. It covers the allocation-method family in Theorem 3.3 through a concrete member, not the paper’s strategic-mechanism questions or broader characterization agenda. Further questions include whether the general \(W,B\) family admits efficient exact or approximate computation, and whether edge consistency has a natural formulation when one removes a positive mass of a type.

The weak point is substantial: the theorem’s result is about fairness properties, not computational complexity, and the paper’s word “continuous” refers to continuity in claims and capacities—not to a continuum population. Its allocations are already divisible, which by itself would not be a continuous mirror under this programme. The positive case depends on the separate, explicit replacement of the finite agent set by a distribution over complete agent types. The paper’s result gives that replacement a well-defined flow-selection objective; the claimed tractability of the quadratic mirror is a consequence to establish, not a result the authors report.

The case AGAINST (opponent, writing after the proponent)

The only anchor is Theorem 3.3, and its result is axiomatic: the minimizer defines a symmetric, continuous, edge-consistent method. The paper does not classify the complexity of computing that method. The same is true of the other numbered results. Under a strict reading of ChoCo’s target, there is no computational result here to mirror; Theorem 3.3 supplies a possible starting point for a new computational question, not a complexity result from this paper.

The proposed population model is nevertheless well formed. Workers with the same eligibility set and claim are a plausible high-multiplicity type. If \(n_t=n\mu_t\) agents have type \(t\), and total resource capacities scale as \(nr_a\), strict convexity makes identical agents’ allocations equal. Dividing the finite objective by \(n\) gives exactly the stated mass-weighted quadratic program. So I cannot reject this mirror on grounds of identity, an implausible type space, or a degenerate limit.

The strongest negative case is therefore about fit: computing the minimizer is an algorithmic question added to a paper whose results concern fairness axioms and consistent extensions. The authors might recognize that question as relevant, but the paper does not establish its computational importance. That leaves a real weakness in the negative case: if ChoCo accepts an explicit optimization formulation as an anchor, the proposed mirror survives the modelling objections. I cannot honestly claim that no worthwhile continuous mirror exists in any scenario; I can only argue that this is a new computational agenda attached to the paper, rather than a mirror of a computational result it reports.
