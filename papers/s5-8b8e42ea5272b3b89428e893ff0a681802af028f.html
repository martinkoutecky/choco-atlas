The continuous mirror question

Given integer type weights \(w_t\ge2\), rational masses \(\mu_t\) summing to \(1\), and a population scale \(N\), define \(V(x)=\prod_t w_t^{Nx_t}-1\) for \(0\le x_t\le\mu_t\). Compute a type-anonymous payoff vector \(p\) satisfying \(\sum_t\mu_t p_t=V(\mu)\) and \(\sum_t x_t p_t\ge V(x)\) for every feasible mass vector \(x\).

The model it lives in

An atomless high-multiplicity CPG with type masses \(\mu_t\), zero-normalized surplus \(V(x)=\prod_t w_t^{Nx_t}-1\), and type-level payoff variables \(p_t\); order the types and assign \(p_{t_j}=(R_j-R_{j-1})/\mu_{t_j}\), where \(R_j=R_{j-1}w_{t_j}^{N\mu_{t_j}}\).

The objection that survived

The normalization is not literally the paper's characteristic function, and with binary-encoded \(N\) an exact payoff such as \(2^N-1\) has \(\Theta(N)\) output bits, so the mirror needs an explicit symbolic or output-sensitive representation.

fatal: False

The case FOR (proponent)

The strongest honest positive case is a modest Class A mirror anchored only in Theorem 3.

The paper’s qualifying computational result is Theorem 3, proved in the paper: “It is possible to find a core imputation in a CPG in linear time.” Given any permutation of the players, the theorem computes each player’s marginal contribution. The first player receives \(w_{x_1}\); the \(i\)-th player receives

\[ \left(\prod_{j<i} w_{x_j}\right)(w_{x_i}-1). \]

Because the game is convex by Theorem 1, this marginal-contribution vector lies in the core. The proof invokes Weber’s cited result that marginal vectors of convex games are core imputations. Theorem 2, also proved in the paper, supplies the supporting existence claim that every CPG has a non-empty core, but I would not treat it as a separate computational anchor.

The relevant regime is a large consortium of agents divided into a small number of standardized multiplier classes. A type is a weight \(w_t\in\{2,3,\ldots\}\), together with all other characteristics used by the game; agents of the same type are interchangeable. The society is a rational distribution \(\mu=(\mu_1,\ldots,\mu_\tau)\), where \(\mu_t\) is the fraction of the population of type \(t\), \(\tau\ll N\), and \(N\) is the population scale. This is a genuine high-multiplicity scenario: the input describes a histogram of many repeated players rather than \(N\) named individuals.

I would pose the following problem.

Continuous Product-Surplus Core Construction. An instance consists of integer weights \(w_1,\ldots,w_\tau\ge2\), a rational distribution \(\mu\), and a population scale \(N\). The population is atomless, with type-\(t\) mass \(\mu_t\). If a coalition takes mass \(x_t\le\mu_t\) of each type, its value is

\[ V(x)=\prod_{t=1}^{\tau} w_t^{N x_t}-1, \qquad V(0)=0. \]

The subtraction of \(1\) is the zero-normalized continuous extension of the multiplicative surplus: when \(N x_t\) are integer type counts, the multiplicative term is exactly \(\prod_t w_t^{N x_t}\). The task is to output a payoff density \(p\) such that

\[ \int_U p\,d\lambda=V(\mu) \]

and, for every measurable coalition \(S\) with type-mass vector \(x(S)\),

\[ \int_S p\,d\lambda\ge V(x(S)). \]

A type-anonymous solution can be required: every member of type \(t\) receives the same payoff \(p_t\).

This is directly connected to Theorem 3’s permutation construction. Choose an order \(t_1,\ldots,t_\tau\) of the types, define

\[ R_0=1,\qquad R_j=R_{j-1}w_{t_j}^{N\mu_{t_j}}, \]

and assign every member of type \(t_j\) the payoff

\[ p_{t_j}=\frac{R_j-R_{j-1}}{\mu_{t_j}}. \]

Then \(\sum_j\mu_{t_j}p_{t_j}=R_\tau-1=V(\mu)\), and the usual marginal-contribution argument shows that every coalition is paid at least its value. Thus the continuous problem has a succinct \(O(\tau)\)-type construction, independent of the number of repeated agents. It is the population-level analogue of taking a permutation in Theorem 3 and replacing consecutive same-type players by a mass block.

I expect this mirror to be tractable, in Class A. Its interesting computational content is not merely that a product can be written with fractional exponents; it is that the paper’s \(N\)-player marginal-vector algorithm compresses to a type-level greedy construction, while the core constraints quantify over all measurable subcoalitions. Further questions include computing the least core, Shapley-like allocations, or nucleoli for the mass game; characterizing finite-\(N\) rounding guarantees; and determining whether type-dependent coalition restrictions or quotas destroy the greedy construction.

The weak point is substantial: the exact paper defines \(v(C)=\prod_{i\in C}w_i\), whereas an atomless exact extension with \(V(\varnothing)=0\) is pathological. Arbitrarily small positive coalitions would have value tending to \(1\), while their total payoff tends to \(0\), making the core empty. The \(-1\) normalization is therefore mathematically forced for a useful atomless model, but it changes singleton values and is not literally the original CPG. If the authors insist that only the unmodified product game counts, this positive case fails. If they accept the normalized product-surplus game as the natural continuum limit, Theorem 3 gives a clean and plausible continuous mirror, though not a hardness result.

The case AGAINST (opponent, writing after the proponent)

The sole computational anchor is Theorem 3. There is no credible objection based on multiplicity: a population with many interchangeable players sharing a weight is a sensible high-multiplicity regime. The negative case must therefore attack the proposed continuum itself.

The faithful extension of the paper’s characteristic function is

\[ F_N(x)=\prod_t w_t^{N x_t} \]

for every nonempty mass vector \(x\), with \(F_N(0)=0\). On an atomless population this destroys the core. If \(S_\varepsilon\) is a coalition of mass \(\varepsilon\) consisting only of type \(t\), then

\[ F_N(S_\varepsilon)=w_t^{N\varepsilon}\longrightarrow 1 \]

as \(\varepsilon\to0\). But the payoff of any integrable density satisfies

\[ \int_{S_\varepsilon}p\,d\lambda\longrightarrow0. \]

Thus sufficiently small coalitions block every proposed imputation. This is not merely a case where the continuous answer differs from the discrete one: the central object that Theorem 3 constructs does not exist.

The proponent’s subtraction of \(1\) repairs this pathology, but changes the game:

\[ \widetilde F_N(x)=\prod_t w_t^{N x_t}-1. \]

For a discrete coalition with \(k_t\) players of type \(t\), this gives

\[ \widetilde F_N(k/N)=\prod_t w_t^{k_t}-1, \]

whereas the paper’s value is \(\prod_t w_t^{k_t}\). Even a singleton’s value changes from \(w_t\) to \(w_t-1\), so the paper’s interpretation of \(w_t\) as a multiplicative contribution is lost. This is not population scaling forced by high multiplicity; it is a new characteristic function selected precisely to restore continuity and core feasibility. Other choices—logarithmic normalization, per-capita scaling, or other regularizations—produce different games and different cores. The paper gives no reason to privilege this one.

The strongest faithful alternative is to let mass vary only in units of \(1/N\), so that every coalition corresponds to an actual integer collection of players. But then the “continuum” is only run-length encoding: the admissible coalitions remain discrete count vectors, and the type-level construction is just Theorem 3 with repeated equal weights grouped together. If arbitrary fractional coalitions are admitted, one encounters the empty-core problem or must introduce an unmotivated new utility model.

There is also a high-multiplicity encoding problem. Even accepting \(\widetilde F_N\), take one type with \(w=2\) and mass \(1\). The exact payoff is \(2^N-1\). With \(N\) binary encoded, this has \(\Theta(N)\) output bits despite an input of size \(O(\log N)\). Thus the claimed \(O(\tau)\) construction is only an arithmetic-expression claim, not a polynomial-time exact algorithm in the usual bit model. Allowing compressed expressions makes the result essentially “print \(2^N-1\)”; taking logarithms to avoid the blow-up turns the product game into the additive game \(N\sum_t x_t\log w_t\).

Consequently, Theorem 3 does not provide a worthwhile continuous-population mirror as stated. Its faithful atomless extension has no core; its repaired extension is a different game with arbitrary normalization and exponential exact outputs; and its grid-restricted extension is merely compressed finite computation. I would not claim that no future paper could study a product-surplus or least-core continuum model. But that would be a new cooperative-game model, not a computational mirror of this paper’s result.
