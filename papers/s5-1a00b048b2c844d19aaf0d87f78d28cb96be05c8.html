The continuous mirror question

Given a finite support \(T\), positive rational masses \(\mu_t\) summing to \(1\), a rational metric \(d\) on \(T\), and \(k\), can \(T\) be partitioned into \(k\) positive-mass clusters \(T_1,\ldots,T_k\), with each type assigned wholly to one cluster, so that for every \(t\in T_i\) and \(j\ne i\), \(\frac{\sum_{s\in T_i}\mu_s d(t,s)}{M_i}\leq\frac{\sum_{s\in T_j}\mu_s d(t,s)}{M_j}\), where \(M_i=\sum_{s\in T_i}\mu_s\)?

The model it lives in

A population distribution over complete feature-profile types, with each type's mass assigned as a whole to one cluster; stability compares each type's mass-weighted average distance to its own cluster with its average distance to every other cluster.

The objection that survived

The paper permits identical data points to be assigned separately, while this mirror commits each profile cohort to one cluster; whether the authors would accept that deployment constraint remains the weakest assumption.

The case FOR (proponent)

The strongest honest mirror is the paper’s existence question for exact IP-stable clustering, in a setting where clusters are assigned to whole customer or student cohorts. Imagine millions of people described by a few hundred or thousand complete feature profiles. Each profile type includes everything used by the distance function, so people of that type have the same distances to every other type. The organization assigns each type one common curriculum or intervention. If \(N_t\) people have type \(t\), its mass is \(\mu_t=N_t/N\); the number of people can be enormous while the support size \(\tau\) stays moderate.

Call the continuous problem Cohort-IP-Stable Clustering. An instance is a finite support \(T\), positive rational masses \(\mu_t\) summing to \(1\), an explicitly given rational metric \(d\) on \(T\), and a requested number \(k\) of clusters. A solution is a partition \(T=T_1\dot\cup\cdots\dot\cup T_k\) into positive-mass clusters. Define \(M_i=\sum_{s\in T_i}\mu_s\). For every type \(t\in T_i\), require, for each \(j\ne i\),
\[ \frac{\sum_{s\in T_i}\mu_s d(t,s)}{M_i} \le \frac{\sum_{s\in T_j}\mu_s d(t,s)}{M_j}. \]
The question is whether such a partition exists, and a solution is the partition itself. This is the continuum version of the paper’s comparison of average distances: an individual has zero mass in the population limit, while everyone of the same type receives the same cluster assignment.

My anchor is Theorem 1 (NP-hardness of IP-stable clustering), proved in this paper. It states that deciding whether a data set with a given distance function has an IP-stable \(k\)-clustering is NP-hard, even when \(k=2\) and the distance function is a metric. The paper proves this by reduction from a restricted 3-SAT variant. This is the strongest anchor because it asks whether the computational barrier to finding a stable clustering survives when the input population is represented by masses over types.

I expect the cohort version to be Class B: hardness transfers. The theorem’s reduction puts its combinatorics in the types and their pairwise distances, rather than in a large population count. Replicating each type many times leaves that support-level structure intact, and the paper’s reduction uses separated inequalities that seem amenable to preserving under a high-multiplicity limit. That transfer is a proof obligation, though: the paper’s finite definition divides own-cluster distance by \(|C_i|-1\), while the population limit divides by cluster mass. The theorem alone does not establish hardness for the stated mass problem; a prover should verify that the reduction survives this change.

The main modelling vulnerability is cohort integrity. If agents of one type may be split arbitrarily among clusters, assigning \(\mu_t/k\) of every type to each cluster makes all clusters have the same type distribution, so everyone is indifferent and the existence question becomes trivial. The whole-type assignment is defensible where an intervention is deployed uniformly to a profile cohort, and the paper’s curriculum and personalized-marketing motivations make that scenario recognizable. It is still a restriction the authors could reject if they insist that identical data points may be assigned independently. The mirror covers Theorem 1’s existence question, not the paper’s approximation algorithms, special-metric results, or empirical claims. Natural next questions are whether the hardness proof survives the limiting normalization, how complexity depends on \(\tau\), and what happens when only a bounded amount of each type may be split.

The case AGAINST (opponent, writing after the proponent)

Theorem 1 is a real computational anchor: deciding whether an IP-stable clustering exists is NP-hard, even for two clusters and a metric. The strongest objection is to whether its population mirror remains nontrivial under a faithful continuum model.

If a continuum population allows identical feature types to be divided among clusters, the existence question degenerates. Assign mass \(\mu_t/k\) of every type \(t\) to each of the \(k\) clusters. Each cluster then has the same type distribution, so every type has the same average distance to every cluster. The result is stable for any metric, regardless of the SAT gadgets behind Theorem 1. This is a genuine limit effect: an individual has measure zero, and splitting a type does not change the population an individual compares against.

The proposed mirror avoids that degeneration by requiring each type’s entire cohort to enter one cluster. That is plausible for a policy that assigns a common intervention to everyone with an identical profile, but it adds a constraint the paper does not impose. Its data points may be assigned independently, including points with identical features. If assignments can be randomized or varied within a profile cohort, the degeneracy returns. If cohorts must stay intact, the decision is again a discrete partition of the support; the continuum appears only in the weights. The paper’s hardness reduction does not itself establish hardness for that weighted problem: its inequalities use the finite definition’s exclusion of the individual from their own cluster, which changes under positive-mass types.

So the anchor supports a potentially interesting *cohort-integral* variant, but the case against a faithful, nontrivial population mirror is that the natural divisible model makes existence automatic, while avoiding that outcome requires an additional operational restriction. I cannot honestly make the requested universal negative case airtight: profile-based cohort assignments are a plausible scenario, and the weighted existence problem is well-posed. The negative case is strongest as a challenge to the proposed mirror’s fit with the paper, not as evidence that no worthwhile mirror exists in any scenario.
