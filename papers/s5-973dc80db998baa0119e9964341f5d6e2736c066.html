The case AGAINST (opponent, writing after the proponent)

The case for does not supply a qualifying anchor. Theorem 4 is its closest lead, but it characterizes the proportional division value from consistency, efficiency, and a two-player fairness condition; it does not classify the complexity of a computational problem. The same is true of Theorems 1–5: they characterize a solution by axioms. Proposition 1 is an incompatibility result between axioms, not a computational classification. The paper has no named computational result to mirror.

The strongest version of the Theorem 4 mirror would put a large population into a few types, each with a common stand-alone worth, and restate projection-nullified consistency and equal-ratio fairness for type masses. That could be a coherent continuous-population model. But its central question would still be whether axioms characterize a value, which is outside ChoCo’s computational scope. Turning it into an algorithmic question—such as evaluating the value, or checking the axioms on an input game—would add a problem the paper does not study. The composition characterizations in Theorems 2 and 3, and the alternative characterization in Theorem 5, have the same limitation.

There is a legitimate high-multiplicity regime here: many players can share the same relevant characteristics. The obstacle is not that such a regime is impossible. It is that a general TU-game assigns worths to every coalition, so grouping players by their stand-alone worths may discard distinctions the characteristic function retains. A type-based game could preserve the distinction by imposing a structured, type-level description of coalition worths, but that is an additional model. Even if its axioms had a useful continuous formulation, it would not turn these results into computational ones. The paper’s “grand-coalition continuity” concerns changes in a scalar game value, and “fixed-population consistency” compares games on the same finite player set; neither supplies the missing computational question.

So the strongest honest negative case is a scope mismatch: this paper offers no computational result for a continuous mirror to address. A continuous axiomatic study of TU-games might be worthwhile in its own right, but it would not be a continuization of the kind ChoCo is pursuing. The limit of this case is that it cannot rule out a new computational project inspired by the paper; it can only say that such a project would need a question and result not present here.
