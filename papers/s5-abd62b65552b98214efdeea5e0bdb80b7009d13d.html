The continuous mirror question

Given a society μ over finite types \(t\), each specifying a hierarchy \(h_t\) and request vector \(p_{t,r}\), per-capita supplies \(b_r\) for resource classes \(r\), and an initial rational allocation \(x\) with \(x_{t,r}\geq 0\) and \(\sum_t x_{t,r}=b_r\), output a feasible allocation \(x^*\) and a finite sequence of feasible allocations from \(x\) to \(x^*\). Each step transfers an amount \(\delta>0\) of one class \(r\) from type \(t\) to type \(u\), where either \(h_u\succeq h_t\) and \(p_{u,r}=1\), or \(h_t\succeq h_u\) and \(p_{v,r}=0\) for every type \(v\) with \(h_v\succeq h_t\). Require that in \(x^*\), each class is assigned only to highest-hierarchy requesters if any type requests it, and otherwise only to lowest-hierarchy types.

The model it lives in

The society is μ over complete \((h_t,p_{t,·})\) types; each resource class has \(b_r\) copies per capita, and \(x_{t,r}\) records its aggregate per-capita allocation to type \(t\). A legal move transfers \(\delta\) of one class between types under the paper's rational-deal condition; the goal is a good allocation, with no cost objective.

The objection that survived

The repair handles each resource class independently and adds no coupled optimization or pricing problem; this limits its computational reach, though the proponent already scopes the mirror to Theorem 1.

fatal: False

What the mirror covers

The mirror covers Theorem 1's repair to a good allocation. It leaves Theorem 2's optimality characterization dependent on set plausibility and Theorem 3's local-fairness criterion unextended to masses.

The case FOR (proponent)

The strongest honest case is a narrow mirror of the paper’s constructive rational-deal result. The paper has no named theorem classifying a problem as polynomial-time or NP-hard. Its best computational anchor is Theorem 1, proved here: if an allocation has \(l\) columns that are not in good position, there is a sequence \(\mathcal F_1,\ldots,\mathcal F_{l+1}\) of allocations, starting at the given allocation and ending at a good one, where each successive pair is a rational deal. The proof repairs a bad column with a rational deal. I would not present this as a P theorem: the paper gives no runtime bound. Its displayed construction does, however, give a direct polynomial-time algorithm for the continuous problem below.

Call the mirror Continuous Rational-Deal Repair. An instance has a finite set \(R\) of resource classes, a finite set \(T\) of agent types, and binary-rational data. Each type \(t\) specifies a hierarchy level \(h_t\) and a complete request vector \(p_{t,r}\in\{0,1\}\) over \(r\in R\). The society is a distribution \(\mu\) over \(T\), with support size \(\tau\). For each resource class \(r\), \(b_r\) is its supply per capita, and \(x_{t,r}\) is the amount of that supply assigned to recipients of type \(t\), with \(x_{t,r}\geq 0\) and \(\sum_{t\in T}x_{t,r}=b_r\). A unit of \(x_{t,r}\) means one unit of resource per society member, in aggregate, allocated to type \(t\).

The regime is a large allocation program with many applicants but relatively few complete request-and-priority types: for example, emergency supplies distributed among applicants with standardized requests and priority tiers. The resource classes are categories containing many separate, individually assigned copies. In a finite population of \(n\) applicants, \(b_r\) corresponds to \(nb_r\) copies; each copy still goes to one person, though type-level averages can be fractional. Thus \(N\), the number of applicants, can be much larger than \(\tau\). The authors should recognize the type definition and the repair rule: hierarchy and binary requests are exactly the information their rational deals use. The resource plausibility relation can be retained, but Theorem 1’s repair rule does not depend on it.

The question is: given \(\mu\), the supplies, and an initial feasible assignment \(x\), output a feasible assignment \(x^*\) and a finite sequence of feasible assignments from \(x\) to \(x^*\), each step transferring some amount \(\delta>0\) of one resource class \(r\) from a source type \(t\) to a destination type \(u\). The transfer is rational exactly when either \(h_u\succeq h_t\) and \(p_{u,r}=1\), or \(h_t\succeq h_u\) and every type \(v\) with \(h_v\succeq h_t\) has \(p_{v,r}=0\). The final assignment must be good: all positive mass for class \(r\) goes to a highest-hierarchy requester, if anyone requests \(r\); if nobody does, it goes to a lowest-hierarchy type. The solution is the resulting assignment and transfer sequence, not a minimum-cost plan—the paper specifies no deal costs.

This mirror is tractable. For each resource class, choose one highest-hierarchy requesting type, or, if there are no requesters, one lowest-hierarchy type. Transfer to it the mass currently assigned to every other type. Each transfer satisfies the paper’s rational-deal condition: a source at or below the chosen requester’s level meets the first clause; a higher source has no requester at its level or above and meets the second. With no requesters, the second clause applies directly. This uses at most \(K(\tau-1)\) transfers for \(K=|R|\), and takes time polynomial in \(K\), \(\tau\), and the input bit length \(L\). The predicted class is tractable; the mirror supplies an explicit repair algorithm, rather than a claim that the paper itself proves a complexity classification.

The scope is deliberately just Theorem 1’s task of reaching a good allocation. In the finite model, Theorem 2 establishes that good allocations are exactly the optimal allocations when the set-plausibility relation is positive. I would not claim that result carries over automatically: the paper does not specify how its comparison of *sets* of resources should extend to masses of resource copies.

That is the weakest point too. The mirror scales the supply alongside the population and aggregates copies by resource class, while Theorem 1 concerns a finite set of individual resources. The mass-transfer sequence compresses many individual deals into a batch. These are natural high-multiplicity choices for a program distributing many repeated units, but they make this a focused mirror of the repair theorem—not a continuization of the paper’s full qualitative welfare theory. Further work would define a mass-based plausibility comparison and test whether Theorem 2’s optimality characterization survives.

The case AGAINST (opponent, writing after the proponent)

The sole anchor is Theorem 1’s rational-deal repair. The strongest case against it is that it supplies a constructive procedure, not a computational result whose complexity the paper investigates. Each resource can be handled independently: choose a highest-hierarchy requester, or a lowest-hierarchy agent if nobody requests it. The paper’s own construction therefore runs in \(O(qk)\) time on the explicit instance. Grouping identical agents into \(\tau\) types reduces the scan to \(O(k\tau)\); batching repeated copies of each resource gives the same calculation. That compression may be useful, but it adds no pricing problem, coupled constraint, or optimization challenge to chart.

Keeping the original finite set of resources while making the population nonatomic also leaves a mismatch: each resource has one recipient, and a distribution over types cannot record which zero-measure individual receives it. The best repair is the proponent’s co-modification: scale up copies of each resource and let type-level assignments be fractional. That is a coherent high-multiplicity model, and I accept that standardized applicants with repeated resource classes are a plausible regime. But it changes a deal over one named resource into a bulk transfer between types. Under the paper’s assumptions, those transfers still reduce to the same independent choice for each resource class. Adding capacities, costs, or cross-resource fairness could create a richer computational question, but those features are absent from the theorem being mirrored.

Theorem 2’s qualitative comparison and Theorem 3’s local-fairness criterion do not supply an obvious rescue for this anchor: extending set plausibility or individual dispersion to type masses would require additional modeling choices. I do not count that as a formal objection, since a recognizable mass variant could be defined.

So the negative case is limited. The proposed mirror is well-posed and author-recognizable; I cannot honestly rule out every worthwhile scenario. The case against is that this particular anchor looks like a side example in high-multiplicity aggregation, rather than a substantial addition to the programme’s computational landscape.
