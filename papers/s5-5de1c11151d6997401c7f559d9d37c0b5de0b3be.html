The continuous mirror question

Given a finite item catalogue \(O\), a finite set of complete valuation types \(T\), type masses \(\mu_t\), additive valuations \(v_t\), and per-capita item supplies \(q_o\), decide whether there exist nonnegative masses \(x_{t,B}\) over integral bundles \(B\subseteq O\) satisfying \(\sum_{B\subseteq O}x_{t,B}=\mu_t\) and \(\sum_{t\in T,\,B\ni o}x_{t,B}=q_o\), such that every \(x_{t,B},x_{u,D}>0\) with \(v_t(B)<v_u(D)\) satisfies pointwise \(\mathrm{EQ1}\), and no measurable reassignment weakly improves every individual while strictly improving a positive mass.

The model it lives in

A high-multiplicity mixed-manna model with finite complete valuation types \(T\), agent masses \(\mu_t\), per-capita item supplies \(q_o\), and variables \(x_{t,B}\) assigning mass to integral bundles \(B\subseteq O\); the objective is feasibility of pointwise \(\mathrm{EQ1}+\mathrm{PO}\), not welfare maximization.

The objection that survived

The direct \(3\)-Partition gadget does not survive scaled item supplies: the continuum can realize a fractional exact cover by \(T\)-valued bundles, and no hardness-preserving repair is supplied.

fatal: False

What the mirror covers

It covers Theorem 5.1's strong NP-hard existence result and Theorem 4.1's polynomial \(\mathrm{EQX}\) search as continuous-population questions. It leaves the objective-valuation algorithms, type-normalized two-agent results, ternary \(\mathrm{EQ1}+\mathrm{PO}\) algorithm, welfare dynamic program, and auxiliary compatibility corollaries outside the mirror.

Open questions for a prover

  • Can strong NP-hardness be recovered for \(\mathrm{EQ1+PO}_\infty\) with scaled supplies, or does fractional exact-cover structure yield a configuration-LP algorithm?
  • Is pointwise \(\mathrm{EQX}_\infty\) search polynomial-time despite support compatibility among multiple bundles per valuation type?
  • What finite-replication and rational-mass conditions give a two-way dictionary between the discrete and continuous variants?

The case FOR (proponent)

I think there is a defensible mirror, with the paper’s EQ1+\(\mathrm{PO}\) hardness result as the lead. The right continuization is not cake-cutting: individuals still receive integral bundles. What becomes continuous is the mass of agents and repeated copies of the item types.

Take a finite item catalogue \(O=\{o_1,\ldots,o_m\}\), a finite set of complete valuation types \(T\), and a population distribution \(\mu\), where \(\mu_t\) is the mass of agents of type \(t\). Each type has an additive valuation \(v_t\). Each item type \(o\) has per-capita supply \(q_o\); in the \(K\)-fold replication of a discrete instance with \(n\) agents and one copy of each item, \(\mu_t=n_t/n\) and \(q_o=1/n\).

An allocation is represented by \(x_{t,B}\), the mass of type \(t\) receiving the integral bundle \(B\subseteq O\). Thus \(\sum_B x_{t,B}=\mu_t\), and \(\sum_{t,B:o\in B}x_{t,B}=q_o\). The aggregate variables are fractional, and the type-average utility \(\bar u_t=\mu_t^{-1}\sum_Bx_{t,B}v_t(B)\) may be fractional, but every unit of agent mass receives an integral bundle.

I would use the following exact pointwise lift of EQ1: whenever \(x_{t,B}>0\) and \(x_{u,D}>0\) and \(v_t(B)<v_u(D)\), either some good \(g\in D\) for type \(u\) satisfies \(v_t(B)\ge v_u(D\setminus\{g\})\), or some chore \(c\in B\) for type \(t\) satisfies \(v_t(B\setminus\{c\})\ge v_u(D)\). Pareto optimality means that no measurable reassignment of item mass can weakly improve every individual and strictly improve a positive mass of individuals.

This gives the problem I would call \(\mathrm{EQ1+PO}_\infty\)-Existence:

Given \((T,\mu,O,q,v)\), with additive mixed valuations and, in the restricted version, the same type-normalization used in the paper, decide whether there is an integral-bundle mass allocation satisfying pointwise EQ1 and Pareto optimality. A solution is the support of \(x\), together with its measurable realization; the objective is feasibility, not welfare maximization.

My lead anchor is Theorem 5.1, cross-referenced in the manuscript as \(\Cref{thm:eq1pohard}\), proved in this paper. It states that deciding whether a mixed fair-division instance admits an EQ1+\(\mathrm{PO}\) allocation is strongly NP-hard. The reduction is from \(3\)-Partition. There are \(r\) identical set-agent valuation types and one dummy-agent type. The \(3r\) set items have values \(b_i\) for every set agent; two dummy items have values \(-T\) and \(-(r-3)T\). The dummy agent values the first \(3r-1\) set items at \(0\), the final set item at \(-(r-2)T\), and the two dummy items at \(T\) and \((r-1)T\). Every agent values the entire instance at \(2T\), so the hardness already holds for type-normalized valuations. A valid \(3\)-partition yields an EQ1+\(\mathrm{PO}\) allocation, while any such allocation forces the set items into \(r\) groups of total value \(T\).

The continuous mirror is particularly natural in a large review-allocation or course-assignment market. There may be millions of reviewers or students but only a small number of complete preference/workload types. Each paper, assignment, or course slot is an item type with a repeated supply, and the same type may value some items positively and others negatively. EQ1 says that a reviewer who is behind can be brought within fairness by removing one attractive task from the richer reviewer or one disliked task from their own bundle. Pareto optimality has exactly its original reassignment meaning.

I expect this mirror to be Class B: hardness should ultimately transfer because the reduction’s combinatorics live in the item catalogue and the numerical packing structure, not in named-agent identities. In the replicated version of the reduction, the set population has mass \(r/(r+1)\), the dummy population has mass \(1/(r+1)\), and every item type has supply \(1/(r+1)\). The important caveat is that the paper’s finite proof does not automatically lift. In the continuum, dummy items can be distributed among different dummy agents, and identical set types can be split among different integral bundles. A robustification of the reduction would be needed. That is a genuine research question, not a reason to reject the mirror.

A second, cleaner anchor is Theorem 4.1, cross-referenced as \(\Cref{thm:norm_EQ1}\) and proved here. It states that for every mixed fair-division instance with symmetric bi-valued normalized valuations in \(\{-1,1\}\), an EQX allocation always exists and can be computed in polynomial time for any number of agents. For these valuations EQX and EQ1 coincide. The proof uses transfers among poor and rich agents and then completes the allocation with objective items.

Its continuous counterpart is \(\mathrm{BinaryEQX}_\infty\)-Search:

Given \((T,\mu,O,q,v)\) with \(v_t(o)\in\{-1,1\}\) and \(v_t(O)\) equal to the same constant for every type, output an integral-bundle mass allocation satisfying the pointwise EQX conditions: for every poorer and richer positive-mass cohort, removing every good from the richer bundle must repair the inequality, and removing every chore from the poorer bundle must do so as well.

I would expect this problem to be Class A. The paper’s poor/rich transfers become mass transfers between type-bundle cohorts, and in the binary normalized setting the resulting feasibility problem has no numerical magnitudes beyond counts. The natural formulation is a transportation or configuration LP, with a flow or separation routine deciding which integral bundles can receive mass. The nonatomic population should make the mass implementation easier, not harder.

The mirror covers only these two results. It deliberately does not continuize the divisible-goods model, the welfare objective, or time. Nor does it replace an individual’s integral bundle by fractional ownership of an item. Fractionality appears only in the distribution over integral bundles and in type averages, as forced by high multiplicity.

My weakest point is the lead hardness prediction. The continuous model is unquestionably recognizable as the same EQ1+\(\mathrm{PO}\) problem in a high-multiplicity regime, but the paper’s reduction may lose force when identical item copies and dummy items can be spread across a continuum. If that splitting destroys the \(3\)-Partition gadget, the resulting problem could instead expose a tractable configuration-LP formulation. That would still validate the mirror: it would show precisely that the discrete hardness was caused by population/item multiplicity and dissolved under continuization, while the binary theorem supplies a plausible positive algorithmic case.

The case AGAINST (opponent, writing after the proponent)

The strongest negative case is that the lead mirror has not yet been shown to be the paper’s problem in a genuine high-multiplicity regime.

For Theorem 5.1, the finite reduction depends on exactly one copy of every item and on partitioning those copies among \(r\) set agents. In the proposed continuum, a nondegenerate allocation requires item supply to scale with population: with finitely many indivisible items, almost every agent has an empty bundle. But once copies are scaled, the reduction no longer forces an integral \(3\)-partition.

Indeed, Pareto optimality still forces every set item to the set-agent population and both dummy items to the dummy population. EQ1 then forces every positive-mass set agent to receive utility \(T\). The continuous feasibility condition becomes the existence of masses \(x_B\) over \(T\)-valued bundles satisfying

\[ \sum_B x_B=\frac{r}{r+1}, \qquad \sum_{B\ni o_i}x_B=\frac{1}{r+1} \]

for every set item \(o_i\). Equivalently, it asks for a fractional exact cover by \(T\)-valued bundles. Such a cover need not decompose into \(r\) disjoint triples, so the \(3\)-Partition argument disappears. Pareto optimality does not restore the missing coupling; it only determines which agent class receives each item.

One could try to repair the reduction by preserving named bins, forbidding agents from receiving repeated item types, or forcing each cohort to receive one bundle. But named bins destroy the high-multiplicity interpretation, while the other restrictions define a different allocation problem. Thus the paper’s strongest hardness theorem does not presently supply a valid Class B mirror. The proponent’s admission that a “robustification” is needed is substantial: the missing step is exactly the preservation of the discrete combinatorics under continuization.

The binary EQX theorem is a better anchor, but the proposed Class A argument is also incomplete. Under the exact pointwise lift, feasibility requires

\[ x_{t,B}>0,\ x_{u,D}>0 \;\Longrightarrow\; \text{the pair }(t,B),(u,D)\text{ satisfies EQX}. \]

This is a support-compatibility constraint, not an ordinary transportation or configuration LP. A valuation type may receive several different bundles, and introducing one new bundle can make it incompatible with every existing bundle. The finite poor/rich transfer proof relies on moving a whole item between named agents; in the mass model, a transfer creates or changes support and must be checked against the entire support. A flow formulation controls marginals but not these pairwise bundle constraints.

There are only three obvious escapes. Using type-average utilities gives a tractable aggregate notion, but it is no longer the theorem’s EQX. Requiring each valuation type to receive one bundle suppresses the very high-multiplicity relaxation being proposed. Encoding valuation-plus-bundle as the type restores pointwise correctness but makes the outcome part of the population description and loses the intended compression.

These objections do not prove that no useful mirror exists. In fact, the binary theorem remains the most serious problem for a negative verdict: repeated students, reviewers, or workers with identical valuation types and repeated item capacities are plainly plausible, and integral bundles for each individual can be retained. Nor can existing high-multiplicity work be treated as a collision. The honest negative conclusion is therefore narrower: the proposed EQ1+\(\mathrm{PO}\) mirror is not yet a lifted version of the paper’s hardness result, and the proposed EQX mirror has not yet identified an algorithmic formulation preserving the theorem’s meaning. A universal claim that no worthwhile continuous mirror exists would be too strong.
