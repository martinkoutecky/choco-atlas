The continuous mirror question

Given a finite type set \(\Theta\) of size \(\tau\), rational masses \(\mu_\theta\ge0\) summing to \(1\), \(T\) rounds, type-level values \(v_{\theta,t}\), and predictions \(\widetilde V_\theta\) for \(V_\theta=\sum_{t=1}^T v_{\theta,t}\), reveal only the current values and history online, without splitting or repartitioning types. At each round choose intensities \(a_{\theta,t}\ge0\) satisfying \(\sum_{\theta}\mu_\theta a_{\theta,t}=1\), and determine the best worst-case competitive ratio for \(\operatorname{NSW}_\mu(a)=\exp(\sum_{\theta}\mu_\theta\log u_\theta)\), where \(u_\theta=\sum_t v_{\theta,t}a_{\theta,t}\), under perfect or bounded-error predictions.

The model it lives in

A fixed finite population of complete repeated types carrying masses \(\mu\), with type-level current valuations revealed sequentially, per-capita divisible resource constraints, online allocation intensities, and weighted geometric-mean welfare; the adversary may vary future values at the type level but cannot split a type.

The objection that survived

The fixed-type model must specify whether future type-level valuations are fixed in advance or adaptively revealed, since allowing mass to split after allocation would change the problem rather than continuize it.

fatal: False

What the mirror covers

The mirror covers the paper's main online Nash-social-welfare algorithm and lower bound, Theorems 1 and 3; it leaves the maximin lower bound, no-prediction lower bound, warm-up propositions, and auxiliary variants untreated.

Open questions for a prover

  • Does a logarithmic lower bound survive when \(\tau\) is fixed and all positive masses are bounded below?
  • What dependence on \(\tau\), \(\mu_{\min}\), \(T\), and prediction error does weighted Set-Aside Greedy achieve?
  • Can type-level policies be rounded to finite cloned populations with explicit additive welfare loss?

The case FOR (proponent)

The strongest positive case is a genuine high-multiplicity version of the paper’s online fair-allocation problem. The paper already makes goods divisible, but its agents remain named and finite. The proposed mirror continuizes the population, not the goods.

My lead is Online Continuum Nash Social Welfare with Predictions.

Take a finite set of complete agent types \(\Theta\), with rational masses \(\mu_\theta\ge 0\) summing to \(1\). A type includes everything relevant to the problem: its valuation process, its prediction, and any other parameters. There may be millions of agents but only \(\tau=|\Theta|\) types, with many agents sharing each type. A natural regime is a large cloud-computing cluster serving millions of recurring workload instances belonging to a few dozen workload classes. Each class has the same value for each day’s capacity and the same predicted total value.

There are \(T\) sequential divisible resources. At day \(t\), the current per-unit value \(v_{\theta,t}\) of each type is revealed, but future values are not. The policy chooses a per-agent allocation intensity \(a_{\theta,t}\ge 0\), subject to the per-capita resource constraint \(\sum_{\theta}\mu_\theta a_{\theta,t}=1\). The normalized utility of type \(\theta\) is \(u_\theta=\sum_t v_{\theta,t}a_{\theta,t}\), and the population Nash welfare is

\[ \operatorname{NSW}_\mu(a)=\exp\!\left(\sum_{\theta\in\Theta}\mu_\theta\log u_\theta\right). \]

This is not an arbitrary weighted objective. If \(\mu_\theta=n_\theta/n\) and \(n_\theta\) named agents are exact clones of type \(\theta\), then

\[ \left(\prod_{i=1}^n u_i\right)^{1/n} = \exp\!\left(\sum_{\theta}\mu_\theta\log u_\theta\right). \]

Scaling each day’s resource from one unit to \(n\) units, or equivalently normalizing individual allocations by \(n\), preserves competitive ratios exactly. Thus rational type masses are a high-multiplicity representation of finite cloned instances, with per-capita supply scaling as the population grows.

The relevant named anchor is Theorem 3, proved in this paper in Section 5.2. It states that no online algorithm can achieve a competitive ratio of \(O(\log^{1-\varepsilon}N)\) or \(O(\log^{1-\varepsilon}T)\), for any constant \(\varepsilon>0\), with respect to Nash social welfare, even when the algorithm knows perfectly that \(V_i=1\) for every agent. In other words, perfect predictions of every agent’s total monopolist value do not remove the logarithmic online barrier: the difficulty is that the algorithm cannot know which currently indistinguishable agents will later have abundant private opportunities and which will later compete for scarce resources.

The continuous problem mirroring Theorem 3 is:

Online-\(\mathrm{NSW}_\infty\) with Perfect Type Predictions. An instance consists of \((\Theta,\mu,T)\), a stream of nonnegative type values \(v_{\theta,t}\) satisfying \(V_\theta=\sum_t v_{\theta,t}=1\) for every positive-mass type, and an online policy that is told these exact totals but not future values. At each \(t\), after observing the current value vector, the policy must choose \(a_{\theta,t}\) satisfying \(\sum_\theta\mu_\theta a_{\theta,t}=1\). Its performance is the ratio between the offline optimal weighted NSW and its online weighted NSW. The task is to design the best policy, or determine the optimal competitive ratio as a function of \(\tau\), \(T\), \(\mu\), and the prediction-information model.

This is recognisably the authors’ problem: the online information pattern, sequential divisible resources, Nash social welfare objective, and perfect monopolist-value predictions are all retained. Only the population representation changes. The continuous question is particularly valuable because it asks exactly where Theorem 3’s lower bound lives. If the type count is unrestricted, the result transfers immediately by making every named agent a singleton type; that is a Class B embedding, but not the interesting high-multiplicity regime. If \(\tau\ll n\), the lower-bound construction must be rebuilt using repeated types rather than selecting one named low-allocation agent at a time. That is a substantive continuization question.

My expectation for the genuine high-multiplicity regime is Class A, or possibly a Class A/Class C boundary, rather than automatic hardness transfer. The paper’s lower-bound mechanism is heavily population-individualized: the adversary identifies particular agents whose current allocations are small and assigns them damaging future roles. With only a moderate number of repeated types, that mechanism may dissolve. The remaining online uncertainty could still produce a continuum-specific lower bound, especially as \(T\) grows, but that would be a new Class C result rather than a transfer of Theorem 3.

The paper’s positive result gives a second, independent anchor. Theorem 1, proved here in Section 4, states that Set-Aside Greedy has competitive ratio

\[ \gamma_{\mathrm{NSW}} \le \left(\prod_{i=1}^N c_i\right)^{1/N} \min\left\{ \log(2N)+\frac{1}{N}\sum_{i=1}^N\log d_i,\, \log(2T)+\log\!\left(\max_i d_i\right) \right\}, \]

where \(c_i,d_i\ge 1\) satisfy \(\widetilde V_i\in[V_i/d_i,c_iV_i]\). Consequently, perfect predictions give \(O(\log N)\) and \(O(\log T)\) guarantees, and the logarithmic guarantee remains robust under substantial prediction error.

The corresponding continuous problem is:

Continuous Set-Aside Greedy. Given \((\Theta,\mu,T)\), rational type masses, current value streams, and predictions \(\widetilde V_\theta\) satisfying \(\widetilde V_\theta\in[V_\theta/d_\theta,c_\theta V_\theta]\), compute an online allocation policy and determine its worst-case weighted-NSW competitive ratio. The natural policy gives every agent one-half of the per-capita resource and allocates the other half by choosing \(z_{\theta,t}\) to maximize

\[ \sum_{\theta}\mu_\theta \log\!\left( \frac{\widetilde V_\theta}{2} + \sum_{s<t}v_{\theta,s}z_{\theta,s} + v_{\theta,t}z_{\theta,t} \right) \]

subject to \(\sum_\theta\mu_\theta z_{\theta,t}\le 1/2\) and \(z_{\theta,t}\ge0\). The final allocation is \(a_{\theta,t}=1/2+z_{\theta,t}\).

This is a finite-dimensional weighted Eisenberg–Gale-type program with \(\tau\) variables per round, so it is a strong Class A candidate. The correct theorem would rederive Theorem 1 with population weights, likely replacing unweighted averages over agents by \(\mu\)-weighted averages and making the dependence on \(\tau\), \(\mu\), and \(\mu_{\min}\) explicit. I would not claim that the paper already proves this weighted theorem verbatim; the weighted telescoping and bit-complexity arguments should be checked. But the underlying optimization structure is exactly the one the authors use, and the type-level action variable is genuinely population-level rather than merely a change in notation.

Further questions follow naturally: does the \(\log T\) lower bound survive when \(\tau\) is fixed? Can the continuous problem achieve a guarantee independent of \(n\), perhaps depending only on \(\tau\) and prediction error? What dependence on tiny type masses is unavoidable? Can a type-level schedule be rounded to a finite population with an additive error bound? And does allowing hidden future type trajectories rather than explicit type labels preserve the authors’ online information model?

The weakest point is the lead mirror’s information semantics. If a “type” publicly reveals its complete future valuation trajectory, then the online uncertainty disappears and the mirror is too easy. If future roles are hidden, then the model must say precisely what the policy observes and how latent types are assigned; otherwise it risks replacing the paper’s adversarial online problem with a different Bayesian or anonymous-cohort model. I would therefore present Theorem 3 as a faithful and worthwhile boundary question, not as a claimed hardness transfer. Theorem 1 makes the positive case robust: even if the individual-level lower bound collapses under high multiplicity, the paper’s core online NSW problem survives as a concrete weighted type-allocation problem with a plausible polynomial-time continuous algorithm.

The case AGAINST (opponent, writing after the proponent)

The strongest case against is that neither anchor produces a genuinely new continuous-population problem.

Theorem 3’s lower bound depends on selecting particular low-allocation agents and assigning them different future roles. Those roles make the agents different complete types: their future valuation paths, not merely their current values, differ. If repeated agents are exact clones, an allocation policy can treat them symmetrically, and the adversary cannot later “banish” one clone without splitting the type. Splitting off mass \(1/N\) recreates essentially the original named-agent instance, with \(\tau\) or \(1/\mu_{\min}\) growing with \(N\). Allowing the adversary to repartition a type after observing allocations would instead create a new latent-population or adaptive type-evolution model, not a continuization of the paper’s fixed society.

Thus the proposed low-\(\tau\) mirror does not preserve the combinatorial mechanism behind Theorem 3. The singleton-type version preserves it, but is merely an embedding; the fixed-type version removes the very individualized uncertainty that drives the theorem.

Theorem 1 is a weaker anchor still. For cloned agents, the population NSW is exactly

\[ \exp\!\left(\sum_{\theta}\mu_\theta\log u_\theta\right), \]

and Set-Aside Greedy aggregates exactly by type. Its per-round optimization becomes the weighted convex program

\[ \max \sum_{\theta}\mu_\theta\log \widetilde u_{\theta,t} \quad\text{subject to}\quad \sum_{\theta}\mu_\theta z_{\theta,t}\le \frac12. \]

The weights cancel in the KKT conditions, so this is just the paper’s same water-filling computation after grouping identical agents. The resulting \(O(T\tau)\) implementation is useful compression, but not a new separation problem, complexity phenomenon, or continuous optimization barrier. The disappearance of the \(N\)-dependence after per-capita normalization is a change in units and multiplicity representation, not evidence that the paper’s computational problem has acquired a new landscape.

So the best negative verdict is that Theorem 3 does not survive as a faithful fixed-type mirror, while Theorem 1 survives only as an immediate weighted high-multiplicity reformulation. The continuum either has few complete types, in which case the lower-bound mechanism disappears, or many trajectory-specific types, in which case it is the finite instance in disguise.

That said, this is not an airtight universal negative. The weighted online NSW problem is mathematically coherent, and studying its dependence on \(\tau\), type masses, and hidden future trajectories could be worthwhile in its own right. The honest conclusion is therefore that the proponent has established a plausible mirror, but not yet a compelling ChoCo-style computational one; claiming that no worthwhile scenario exists would overreach.
