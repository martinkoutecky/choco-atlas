The continuous mirror question

Given finitely many roles \(R\), hypotheses \(\Theta\), role masses \(\mu_r\), likelihood models \(L_r\), step size \(\delta\), and observed role-average log-ratio trajectories \(\Lambda_0,\ldots,\Lambda_H\), find \(x_{r\theta}\geq 0\) and a column-stochastic block-mixing matrix \(B\), with \(\sum_\theta x_{r\theta}=\mu_r\), minimizing \(\sum_{i=1}^{H}\left\|\Lambda_i-(1-\delta)B^{\mathsf T}\Lambda_{i-1}-\delta G(x)\right\|_F^2\), where \(G_{rj}(x)=\sum_{\theta\in\Theta}(x_{r\theta}/\mu_r)\,\mathbb E_{\zeta\sim L_r(\cdot\mid\theta)}[\log(L_r(\zeta\mid\theta_0)/L_r(\zeta\mid\theta_j))]\). For the resulting estimate, bound the probability that the inferred malicious mass \(\sum_r\sum_{\theta\ne\theta_0}x_{r\theta}\) differs from its true value by more than a given tolerance.

The model it lives in

A continuum of agents with types \((r,\theta)\), where \(r\) is a recurring network and observation role and \(\theta\) is the agent’s true hypothesis. The mass \(x_{r\theta}\) is unknown, while role totals \(\mu_r\) are known; the decision variables are these masses and the role-level mixing matrix \(B\). Minimize trajectory residuals, then bound error in the inferred malicious mass. With fixed observed trajectories, the residual is affine in \(x\) and \(B\), making the stated optimization a convex quadratic program.

What the mirror covers

The mirror covers Theorem 1’s recovery guarantee and malicious-agent detection at role-mass resolution. It leaves per-agent identification on arbitrary graphs, the paper’s full estimation procedure, and its MIRO experiments aside.

Open questions for a prover

  • Under what trajectory and likelihood conditions are \(x\) and \(B\) identifiable?
  • What finite-sample error bound can be obtained for inferred malicious mass?

The case FOR (proponent)

The anchor audit is the weak point: the paper contains no named computational result of the kind this programme asks for. Its Theorem 1, proved in the paper, bounds the probability that a false hypothesis is included in an agent’s estimated set:
\[ \Pr\{\theta\in\widehat{\boldsymbol\Theta}_k\} \leq \frac{4}{M}\operatorname{Tr}(\mathbf R_{\mathbf L}) \sum_{\theta^\star\in\Theta_k^\star} D_{\mathrm{KL}}^{-1}\!\left(L_k(\theta^\star)\,\middle\|\,L_k(\theta)\right) +O(\mu/\delta^2)+O(1/(\delta^5M^2)). \]
That is a statistical error bound, not a runtime or complexity result. The paper gives an algorithm, but no named theorem about its computational complexity. So there are zero eligible anchors, and I would not present Theorem 1 as one.

The strongest positive case I can make is a candidate mirror of the paper’s inverse-learning task, with Theorem 1 as motivation rather than an anchor. Call it Block-Population Inverse Learning. Imagine a large sensor network with a small number of recurring sensor and network roles. Let \(r\in R\) denote a role, including the observation model and the role’s mixing pattern with other groups. Let \(\theta\in\Theta\) be the agent’s true data-generating hypothesis. The complete types are \((r,\theta)\), with unknown rational masses \(x_{r\theta}\); the known mass of role \(r\) is \(\mu_r\), so \(\sum_\theta x_{r\theta}=\mu_r\). Each unit of mass is an agent, and the total mass is one. The regime is many deployed sensors but few roles and hypotheses, so the population size is far larger than the support \(\tau\leq |R||\Theta|\).

Given the likelihood models \(L_r\), a step size \(\delta\), and observed class-average log-belief-ratio matrices \(\Lambda_0,\ldots,\Lambda_H\), infer the type masses and the unknown role-to-role mixing matrix \(B\). For a reference hypothesis \(\theta_0\), define
\[ G_{rj}(x)= \sum_{\theta\in\Theta}\frac{x_{r\theta}}{\mu_r} \mathbb E_{\zeta\sim L_r(\cdot\mid\theta)} \left[\log\frac{L_r(\zeta\mid\theta_0)}{L_r(\zeta\mid\theta_j)}\right]. \]
One precise version asks for a global minimizer of
\[ \min_{x,B}\ \sum_{i=1}^{H} \left\| \Lambda_i-(1-\delta)B^{\mathsf T}\Lambda_{i-1}-\delta G(x) \right\|_F^2 \]
subject to \(x_{r\theta}\geq 0\), \(\sum_\theta x_{r\theta}=\mu_r\), and \(B\geq0\) with columns summing to one. A solution returns the inferred type masses and mixing matrix; if \(\theta_0\) is the nominal truth, it also gives the malicious mass \(\sum_r\sum_{\theta\ne\theta_0}x_{r\theta}\). With the observed \(\Lambda_i\) fixed, each residual is affine in \(x\) and \(B\), so this is a convex quadratic program. I would expect this specified version to be Class A. It also raises natural follow-up questions about identifiability of \(x\) and \(B\), and finite-sample error bounds for the inferred malicious mass.

The appeal is that this preserves the paper’s inverse question—recover latent truths and mixing behavior from belief trajectories—while making fractions of a repeated population the quantity to recover. The weakest point is the model change: the paper handles individual agents and an unknown combination matrix, whereas this mirror assumes a small set of roles with block-level mixing and uses class-average trajectories. It cannot recover which named sensor is malicious, and the paper proves no complexity result for it. If that block-structured regime is too far from the authors’ problem, the positive case fails; the paper’s own named results do not independently establish it.

The case AGAINST (opponent, writing after the proponent)

The proponent is right about the anchor audit. The paper’s Theorem 1 is a statistical error bound, not a computational result; the algorithm and experiments do not establish a complexity classification either. So there is no named computational theorem here for ChoCo to mirror.

The block-population proposal is the strongest rescue, but it changes the task. The paper aims to recover the true-state set for each agent from belief trajectories on a general network. To preserve that task, a type must include the agent’s observation model and its network-relevant mixing role. In a generic graph those roles may be distinct, leaving support size \(\tau\) proportional to the number of agents. If instead many agents share a finite set of roles, their histories can be pooled only under additional structure that makes those role averages evolve closedly—for example, an equitable block network. Then the output is the mass of malicious agents in each role, not which agents are malicious. That may be a sensible new problem, but it is an anonymous mixture-estimation problem under a special network model, not a population version of the paper’s general-graph identification task.

The same tension remains in a more ambitious mirror. Keeping individual trajectories preserves the paper’s target but gives up the finite-support aggregation that makes a continuum useful. Moving to a continuum of network roles could preserve more structure, but then the task becomes measure-valued inverse network learning and needs a new input representation and computational question. Neither version is anchored in a result this paper proves.

So I would argue against spending ChoCo’s continuization effort on this paper: there is no computational result to classify, and the best candidate shifts both the network regime and the object being recovered. The limit of that case is important, though: I cannot rule out an independently worthwhile continuous model of malicious mass in a block-structured sensor network. That possibility is where the universal claim—no useful mirror in any scenario—is weakest.
