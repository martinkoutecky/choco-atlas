Why no mirror

Theorem 4 plainly has computational character, and the bloc encoding defines a precise winner-decision question. But preserving the game requires each positive-mass type to vote as a single bloc, with a distinct type for each named player; the paper does not establish that this is a population-distribution problem rather than its original code-description problem. Whether a plausible role-bloc application makes that encoding an author-recognizable continuous mirror is the unresolved gate.

The case FOR (proponent)

The strongest case I can make is narrow: the paper’s main characterization has a continuous-population mirror if its named players are read as recurring voter blocs. That reading needs countably many types, so it sits outside ChoCo’s usual fixed finite type set.

Imagine a mass-one electorate partitioned into blocs \(B_0,B_1,\ldots\), with rational masses \(\mu_i=2^{-(i+1)}\). Members of each bloc share the same complete role and vote together on a yes/no question. A coalition is a choice \(b_i\in\{0,1\}\) for each bloc; its type-level mass profile is \(x_i=b_i\mu_i\). The voting rule \(W\) assigns winning or losing status to the selected blocs and may distinguish their roles.

My lead mirror is Type-Blocs Winner Computability. Fix \(W\). An instance is a program \(e\) that computes the total sequence \(b_0,b_1,\ldots\), with the promise that it is a valid bloc-coalition description. Decide whether the associated coalition wins under \(W\). A solution is the correct yes/no answer for every valid program. This preserves the paper’s central task: deciding the winner from an algorithmic description of a coalition.

The anchor is Theorem 4, proved in this paper. It says that a simple game \(\omega\) is \(\delta\)-computable if and only if there are recursively enumerable sets \(T_0\) and \(T_1\) of losing-determining and winning-determining finite strings, respectively, such that every recursive coalition has an initial segment in \(T_0\) or \(T_1\). In the mirror, a finite string records the first few blocs’ votes; a determining string guarantees that every continuation has the same outcome. Thus the same characterization answers the mirror: a winning-decision algorithm exists exactly when such effectively enumerable finite-prefix certificates cover every computable bloc coalition. The theorem is proved here, not merely cited.

I expect this mirror to be tractable in the paper’s sense of computability: once those certificates exist, an algorithm can search for a matching prefix and return its label. This is not a polynomial-time claim, and it is not a uniform procedure for recognizing whether an arbitrary rule \(W\) has the property. It is a characterization of which fixed rules admit an evaluator. The paper’s fixed-player, code-described coalition setting and its discussion of manuals and attributes make the underlying question recognizable to its authors.

The weak point is substantial: the masses mostly relabel the players as blocs. Each type votes all together, the rule can depend on bloc identity rather than mass, and the mirror needs countably infinitely many types. It does not yield the usual finite-\(T\) ChoCo model, an LP over fractional transfers, or a continuous algorithm whose complexity depends on \(\tau\) and bit length. If within-type voters must be free to split their votes, this mirror no longer follows from Theorem 4. The further question is whether a useful characterization survives when each bloc can contribute an arbitrary rational fraction of its mass; the paper’s theorem does not answer that.

The case AGAINST (opponent, writing after the proponent)

Theorem 4 is a genuine computational anchor: it characterizes when a fixed simple game has an algorithm for deciding winners from descriptions of recursive coalitions. Its substance is an effective finite-prefix property. For each coalition, some finite initial segment of its named players settles the outcome, and such decisive segments can be listed algorithmically.

The proposed bloc encoding preserves that task exactly. With fixed masses \(\mu_i\) and \(x_i=\mu_i b_i\), the mass vector records the original binary sequence \(b\) coordinate by coordinate. The winner algorithm still receives a program describing that sequence and evaluates the same rule \(W\). It gains no finite-support input, running-time bound in \(\tau\) or \(L\), or optimization problem. The countably many indexed blocs and their all-or-nothing votes are essential to preserving the theorem. For ordinary voting with \(m\) candidates, the ranking types are finite; this construction needs countably many separately distinguished types.

Allowing each bloc to contribute a fraction \(q_i\in[0,1]\) is a stronger possible mirror, but the paper gives no rule for extending \(W\) from binary coalitions to fractional profiles. The values at fractional profiles are unconstrained by its model. If an extension preserves the full coordinate vector, it introduces a new game on countably many type masses and keeps the infinite code-description problem. If it collapses profiles to aggregate masses, it can erase distinctions the paper’s games use: Proposition 13 shows that nontrivial computable games under its stated conditions violate even finite anonymity. Either extension needs additional modeling choices whose computational consequences come from those choices, not from Theorem 4.

There is a worthwhile adjacent question: which natural mass-based extensions of simple games admit effective winner evaluation? But it would need its own semantics and motivation, and the paper does not supply a canonical extension to study. The negative case is strongest against a ChoCo mirror: the bloc version is an encoding of the paper’s existing computability question, while the genuinely fractional version remains underspecified. It cannot rule out a compelling application involving a countable hierarchy of institutional roles; it shows that the paper itself offers little reason to treat that application as a continuous-population complexity problem.
