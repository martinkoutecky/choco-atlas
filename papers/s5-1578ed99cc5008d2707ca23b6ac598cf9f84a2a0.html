The continuous mirror question

Given a feature set \(\mathcal F\), alternatives \(\mathcal A\subseteq 2^{\mathcal F}\), types \(T\) with strict comparison sets \(R_t\), rational masses \(\mu_t>0\) summing to one, a threshold \(q\in(0,1]\), a budget \(k\), and \(\xi\in\{\mathrm{card},\mathrm{ws}\}\), does there exist a shared interaction set \(\theta\subseteq 2^{\mathcal F}\setminus\{\emptyset\}\), a type subset \(T'\subseteq T\), and value functions \(v^t:\theta\to\mathbb R\) such that \(\sum_{t\in T'}\mu_t\ge q\), \(\xi(\theta)\le k\), and for every \(t\in T'\) and \((A,B)\in R_t\), \(f_{\theta,v^t}(A)>f_{\theta,v^t}(B)\), where \(f_{\theta,v^t}(A)=\sum_{S\in\theta:S\subseteq A}v^t_S\)?

The model it lives in

A society is a distribution \(\mu\) over customer types, each type specified by its observed comparison pattern \(R_t\). Choose one sparse interaction library \(\theta\), a covered set of types, and type-specific values; the decision question is whether the covered mass reaches \(q\) within budget \(k\).

The objection that survived

The population-specific coverage question comes from adding heterogeneous users and a mass threshold, while Theorem 1 directly anchors only the one-type case.

What the mirror covers

The mirror covers Theorem 1’s model-selection hardness for MIN-\(\theta\)-card and MIN-\(\theta\)-ws; it leaves Theorem 2, Corollary 1, robust dominance computation, and the experiments aside.

Open questions for a prover

  • What is the complexity when the number of types \(\tau\), feature count \(n=|\mathcal F|\), or comparison count is restricted?
  • Are there useful approximation or parameterized algorithms for maximizing covered mass under a fixed interaction budget?

The case FOR (proponent)

My lead mirror is a population version of the paper’s sparse interaction learning problem. Consider a product platform with many customers comparing alternatives built from the same binary features. The platform has a single interaction library \(\theta\) for the cohort, while the values \(v^t\) of those interactions can vary by customer type. A type \(t\) is a complete observed comparison pattern \(R_t\) on the shared alternative set: customers with the same pattern are indistinguishable to this model. If there are \(N\) customers but only \(\tau\) such patterns, their population is \(\mu\), with \(\mu_t\) the fraction of customers of type \(t\). A standardized comparison task can make \(N\) much larger than \(\tau\).

The anchor is Theorem 1, proved in this paper. It states that both MIN-\(\theta\)-card and MIN-\(\theta\)-ws are NP-complete. In MIN-\(\theta\)-card, the input is a set of alternatives, strict comparisons \(R\), and a budget \(k\); the question is whether some interaction set \(\theta\) with \(|\theta|\le k\) admits values \(v_S\) that represent every comparison in \(R\). MIN-\(\theta\)-ws asks the same question with the budget on \(\mathrm{ws}(\theta)=\sum_{S\in\theta}|S|\). The paper proves hardness by reduction from Hitting Set. This is a hardness result about choosing the underlying preference model, not merely about its MIP encoding.

Here is the continuous question I would hand to a prover, Mass-Threshold Shared-\(\theta\) Learning. An instance gives a feature set \(\mathcal F\), alternatives \(\mathcal A\subseteq 2^{\mathcal F}\), a finite set of types \(T\), each type’s strict comparison set \(R_t\), rational masses \(\mu_t>0\) summing to one, a target population fraction \(q\in(0,1]\), a budget \(k\), and a cost choice \(\xi\in\{\mathrm{card},\mathrm{ws}\}\). It asks whether there exist an interaction set \(\theta\subseteq 2^{\mathcal F}\setminus\{\emptyset\}\), a covered set \(T'\subseteq T\), and values \(v^t:\theta\to\mathbb R\) for \(t\in T'\), such that \(\sum_{t\in T'}\mu_t\ge q\), \(\xi(\theta)\le k\), and every \((A,B)\in R_t\) satisfies \(f_{\theta,v^t}(A)>f_{\theta,v^t}(B)\), where \(f_{\theta,v^t}(A)=\sum_{S\in\theta:S\subseteq A}v^t_S\). A solution gives the shared \(\theta\), the covered types, and their value functions. At \(q=1\), every positive-mass type’s observations must be represented; for \(q<1\), the mass threshold makes the fractions matter directly.

The expected direction is hardness transfers (Class B). With one type of mass \(1\), the \(q=1\) decision problem is exactly the paper’s MIN-\(\theta\)-card or MIN-\(\theta\)-ws instance. The same one-type instance also gives hardness for any fixed \(q>0\). The difficult combinatorics already live in selecting feature interactions, so this mirror does not rely on population size to create hardness. The relevant complexity parameters for broader results would include \(n=|\mathcal F|\), \(\tau=|T|\), the total number of listed comparisons, and the bit length of the masses and threshold.

I think the authors could recognize this as a collaborative extension of their \(\theta\)-additive learning objective: a shared sparse interaction vocabulary with type-specific values. Their earlier AAMAS version is itself titled *Robust Ordinal Regression for Collaborative Preference Learning with Opinion Synergies*, which supports that reading. The mirror covers Theorem 1’s model-selection hardness; it does not claim to continuize the paper’s full robust-prediction procedure or its experiments.

The weak point is that the formal paper studies one decision maker, while this question imposes a shared \(\theta\) across many types and introduces a mass-coverage target. That is a substantive population-level model choice, not a result already established by Theorem 1. The one-type case nevertheless gives an exact anchor, and the shared library is a plausible collaborative use of the paper’s model. Natural next questions are whether the problem has useful algorithms when \(\tau\) or \(n\) is small, and how to define population robust ordinal dominance: for example, whether a comparison holds for every simplest shared model and every compatible value function on at least a \(q\)-fraction of the society.

The case AGAINST (opponent, writing after the proponent)

Theorem 1 is a genuine computational anchor: it proves NP-completeness for two explicit model-selection problems. The strongest objection is about what that result models. Its input \(R\) is one decision maker’s comparisons among alternatives; \(\theta\) is a sparse interaction vocabulary for representing that person’s preferences. The paper has no population whose mass can be varied.

In the proposed mirror, setting \(q=1\) and using one type recovers Theorem 1 exactly. Repeating that type across a large population changes no constraint or answer. With several types, the shared \(\theta\) makes the problem depend on the cohort, but the mass threshold \(q<1\) adds a new objective: find one interaction vocabulary that can represent at least a specified share of users. That is a sensible collaborative preference-learning problem, though its population component comes from the new coverage objective, not from the theorem being mirrored.

The stronger version is also plausible: give a large customer cohort a common interaction vocabulary and let each preference type have its own parameter values. The paper’s earlier collaborative-learning framing makes it credible that its authors would recognize this extension. A group-level model based on the distribution of individual preferences is another possible direction, though it would need to choose how to handle disagreement and cycles.

These are reasons to place the work at the edge of ChoCo’s focus: the population supplies weighted learning instances, while the paper’s core questions concern sparse utility representation and robust prediction for a decision maker. There is no clear mass-transfer, control, or winner-robustness problem here, and the proposed extension brings a new cohort-coverage question. But that is a scope and priority argument, not a decisive demonstration that no worthwhile continuous mirror exists. I cannot honestly defeat the anchor universally: the shared-vocabulary cohort model is plausible, and the one-type case is an exact connection to Theorem 1.
