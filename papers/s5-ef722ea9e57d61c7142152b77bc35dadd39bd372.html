The case FOR (proponent)

I can’t supply a qualifying anchor: the paper contains no named computational result asserting that a problem is tractable, hard, fixed-parameter tractable, or otherwise classifying its complexity. Its numbered results concern value properties and characterizations, not algorithms for computational problems. So there is no continuous problem “per anchor” that I can honestly hand to a prover under your rules.

The closest support for a positive case is Theorem 6.3, proved in this paper. It considers a positive symmetric TU game divided into hierarchical player classes, with class weights \(\eta^*\). When successive weights are sufficiently far apart, it shows that a player \(j\) in class \(S_i\) receives approximately
\[ \phi_j(S,v_{\eta^*}) \approx \frac{1}{z_{S_i}}\, \frac{\eta_i^*}{\sum_{r=1}^{k}\eta_r^*}\, v_{\eta^*}(S), \]
where \(z_{S_i}\) is the number of class-\(i\) players in coalition \(S\). This is an asymptotic allocation result, not an approximation algorithm or a complexity result.

The population regime behind it is credible: many producers could share the same endowments and contribution behavior, with a few distinct classes. Class mass would then be a natural description, and the class’s total allocation would be fractional even though each individual receives an allocation. Section 7’s monopolist-and-small-producers example makes that kind of large-population setting concrete. This is real support for the claim that a high-multiplicity version of the *allocation problem* makes sense.

But turning that substrate into a computational mirror would require adding a problem the paper does not study—such as computing proportional allocations from a succinct description of type masses and coalition worths. The paper does not define that continuous input model, give an algorithm for it, or establish a complexity baseline that a continuum might change. Its main questions are axiomatic characterizations and bargaining implementations; those are outside ChoCo’s computational scope. The paper’s continuum-player example is analytic, not a computational result.

So the honest positive case is limited: a plausible high-multiplicity allocation problem could be built around the paper’s hierarchical small-player setting, but none of the paper’s named results is a computational anchor for it. I cannot assign that proposed problem a tractability, hardness-transfer, or continuum-specific-hardness prediction based on this paper.

The case AGAINST (opponent, writing after the proponent)

The strongest case against a mirror is that this paper proves no computational result. Theorem 6.3 gives an approximate allocation formula for hierarchical player classes in symmetric TU games. Theorem 2.1 concerns core inclusion; the other numbered results concern value properties, characterizations, and bargaining equilibria. None defines an algorithmic problem, an input encoding, or a complexity claim.

The proponent’s proposed population is credible. Section 7’s many identical small producers alongside one monopolist is a natural high-multiplicity setting, and the producers’ aggregate allocation remains meaningful as their number grows. Theorem 6.3 likewise treats classes whose members share the relevant characteristics. So the negative case cannot rest on lack of multiplicity, identity-dependent objectives, or a vanishing aggregate. The paper’s analytic continuum example is not a computational collision either.

The strongest replacement mirror would ask for an algorithm to compute proportional allocations from type masses and a coalition-worth function. That needs a new computational model. For arbitrary anonymous games, the worth function still has to describe coalitions across the possible count vectors; encoding that whole table does not give a compact high-multiplicity input. Restricting the worth function to a compact formula could make computation meaningful, but its complexity would depend on the chosen formula. The paper supplies no computational task or discrete complexity baseline for that bridge. A strategic task, such as changing coalition worths to improve a player’s allocation, would add an objective the paper never studies.

So I would argue against selecting this paper as a ChoCo mirror: the type of population is sensible, while the computational question would have to be created from scratch. The limit in Section 7 may motivate that separate research question, but it does not anchor one in this paper’s results. The universal claim remains weak outside the programme’s scope: a well-specified algorithmic study of proportional-value computation in anonymous games could still be worthwhile.
