The continuous mirror question

Given a finite type set \(T\) with service values \(v_t\in\{0,1\}\), rational population-mass profiles \(\mu\), a prior over those profiles, and black-box access to an anonymous downward-closed feasibility oracle returning lotteries over per-capita service rates \(q\in[0,1]^T\), determine the best welfare approximation achievable by a transformation with query and computation bounds polynomial in support size \(\tau\) and bit length \(L\). Require mass-level MIDR: for every true profile \(\mu\) and report pattern \(\rho\) with row sums \(\mu\) and report masses \(\nu\), truthful reporting maximizes expected welfare \(W_\mu(\rho,q)=\sum_{t,r}\rho_{t,r}v_tq_r\) over the transformed range, and compare its expected truthful welfare with the oracle's.

The model it lives in

A high-multiplicity black-box MIDR conversion problem: the society is a rational mass distribution over complete types, the oracle returns lotteries over type-level per-capita service rates from an unknown anonymous downward-closed range, and the goal is to preserve expected welfare with query complexity polynomial in \(\tau\) and \(L\).

The objection that survived

The proposed \(\rho\)-based condition tests positive-mass bloc deviations, not a negligible individual's MIDR or DSIC deviation; aggregate outputs also cannot specify that individual's allocation rate in a zero-mass report class. This limits the mirror to a mass-level MIDR question and blocks transferring Theorem 2's individual-agent lower bound.

The case FOR (proponent)

My lead is a narrow mass version of the paper’s single-parameter MIDR lower bound.

Anchor — Theorem 2, proved in this paper (§3). There are constants \(\varepsilon,c>0\) such that, for every MIDR black-box transformation using at most \(e^{n^\varepsilon}\) queries, some allocation algorithm \(A\) and prior \(D\) satisfy
\[ \mathrm{Wel}(M_A)\le \frac{\mathrm{Wel}(A)}{n^c}. \]
The result holds for welfare maximization with \(n\) single-parameter agents, even with binary values and binary service outcomes, and even when the transformation knows the feasibility constraint is downward closed. Thus polynomially many queries cannot guarantee a sub-polynomial welfare approximation. This is an oracle-query lower bound, not an NP-hardness result.

The natural regime to mirror is a large service market with many interchangeable applicants but few complete classes—for example, applicants grouped by the eligibility and value information that affects allocation. If there are \(N\) applicants and \(\tau\) such classes, the society is a rational mass vector \(\mu\in\Delta(T)\), with \(\tau\ll N\). Feasible service depends only on the mass served in each class. That anonymity condition is essential: if the constraint distinguishes two applicants, their distinction belongs in their types.

I would ask the prover to classify Mass-MIDR Welfare-Oracle Conversion. An instance has a finite type set \(T\), with \(|T|=\tau\) and service values \(v_t\in\{0,1\}\); a bit-length bound \(L\); and black-box access to an allocation rule \(A\). On a reported type-mass vector \(\nu\), \(A\) returns a lottery over feasible service-mass vectors \(Y\in F\), where \(F\subseteq[0,1]^T\) is an unknown downward-closed set and \(0\le Y_r\le\nu_r\). A mass-MIDR transformation \(M\) must return feasible lotteries whose truthful outcome maximizes expected welfare over the outcomes available through \(M_A\). To make deviations meaningful in the mass model, describe a report pattern by \(\rho_{t,r}\), the mass of true type \(t\) reporting \(r\); its row sums are the true society \(\mu\), and its column sums are \(\nu\). Allocation mass \(Y_r\) is assigned uniformly within report class \(r\), so welfare under that report pattern is
\[ W_\mu(\rho,Y)=\sum_{t,r:\,v_t=1}\rho_{t,r}\frac{Y_r}{\nu_r}, \]
with zero contribution when \(\nu_r=0\). Require truthful reporting to maximize this welfare for every \(\mu\) and every such \(\rho\). The computational question is to determine the best approximation factor \(\alpha(\tau,L)\) achievable by a uniform transformation with query and side-computation bounds polynomial in \(\tau,L\), compared with \(A\)’s truthful welfare. Exhaustively querying the finite set of mass vectors gives an exact but generally exponential baseline, as in the paper’s discussion of unrestricted query budgets.

I expect Class C for the unrestricted mass-oracle version: an oracle might hide a welfare-critical outcome at a hard-to-find rational report mass. That would be a continuum-specific query obstruction, rather than hardness transferred from the number of named agents. This is a conjecture about the proposed mirror, not a consequence of Theorem 2. Further questions are whether such a lower bound already holds for fixed \(\tau\), and whether an explicit polyhedral feasibility region or separation oracle instead enables a polynomial conversion.

The mirror is recognizable as the paper’s computational question: black-box conversion to MIDR while preserving welfare, with profiles and allocations represented by cohort masses. Its weakest point is substantial. Theorem 2’s construction hides random identity sets \(S,T\); if those identities affect feasibility, a complete type must record them, making \(\tau\) grow with \(n\) and erasing the high-multiplicity regime. Its hard prior also has positive-value probability \(3N/(4n)\), which vanishes as \(n\) grows. So the theorem does not establish hardness for this mass problem. What survives is a precise, natural question about whether the paper’s oracle-conversion barrier persists when the relevant allocation structure really is anonymous across large cohorts. My proposed mirror covers Theorem 2 only; I would not stretch it to Theorems 3 or 4, whose main constructions concern additive values across goods.

The case AGAINST (opponent, writing after the proponent)

Theorem 2 is the strongest anchor: it gives a genuine oracle-query lower bound for MIDR welfare conversion. My objection is that the proposed mass model does not preserve the incentive problem that theorem studies.

In the finite model, MIDR compares outcomes across reported profiles while evaluating each outcome for the *same named agents*. In the proposed model, an outcome is just the mass \(Y_r\) served in report class \(r\). A single agent’s deviation changes no mass vector, so it changes neither \(\nu\) nor the aggregate allocation. The welfare formula \(W_\mu(\rho,Y)\) therefore cannot test that deviation: changing \(\rho\) by one agent has measure zero. Moving positive mass does change the formula, but that tests a bloc deviation, not individual MIDR. And when \(\nu_r=0\), \(Y_r/\nu_r\) does not define the deviator’s per-capita allocation; assigning zero contribution to that class defines aggregate welfare, not the deviator’s utility. The proposed requirement may be a coherent population-level welfare property, but it is not the MIDR condition whose role in the paper is to yield individual incentive compatibility.

The strongest repair is to give a tagged, negligible agent an allocation rate \(q_r(\mu)\) for each report, including reports made by nobody else. That would let us state individual incentive constraints against a continuum background. But the paper’s oracle returns aggregate allocations on finite profiles; it does not return \(q_r(\mu)\) for a zero-mass class. Many tagged-agent rules can agree on every aggregate mass allocation and disagree on those rates, hence disagree on incentives. Supplying those rates requires a different oracle interface and assumptions about symmetry or how finite-profile behavior converges. Keeping a finite atom of size \(1/N\) instead preserves deviations, but then exact incentive constraints depend on the finite population’s mass grid. The continuous limit need not preserve them, especially for the paper’s unrestricted black boxes, which need not vary continuously with a one-agent change.

The lower-bound construction also makes the mismatch visible. Its hidden sets \(S,T\) distinguish named coordinates. If their memberships are part of agents’ complete types, the type labels expose distinctions that the proof hides; if they are omitted, agents grouped as one type still differ in a way the oracle uses. Either choice changes the construction’s information structure. Moreover, the hard prior gives a positive-value agent probability \(3N/(4n)\), which tends to zero for the paper’s \(N=n^{1/2+2\varepsilon}\) with small \(\varepsilon\). The lower bound’s normalized society approaches the all-zero population, even though the number of positive-value agents grows. A rare-mass regime can still be studied, but this is not the proponent’s fixed-cohort story.

One could pursue the proposed aggregate mass-oracle problem, or a model in which cohorts act as strategic blocs. Either might be mathematically interesting. The first studies aggregate welfare comparisons; the second changes the strategic unit. Neither answers whether the paper’s individual MIDR conversion barrier survives continuization. The negative case is strongest against this anchor and its natural repairs; it is not airtight against every conceivable new continuum oracle model. In particular, a separately justified tagged-agent oracle could be worth studying, but its connection to Theorem 2 would need to be established rather than assumed.
