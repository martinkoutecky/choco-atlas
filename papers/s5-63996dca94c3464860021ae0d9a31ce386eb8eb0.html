The case FOR (proponent)

The strongest mirror is Theorem 20, the paper’s own result. It says that for constants \(3\le p\le k+1\), and precision \(\epsilon\) satisfying \(k<\log^{1-\delta}(1/\epsilon)\) for some constant \(\delta>0\), finding an \(\epsilon\)-approximate \(3\)-out-of-\(p\)-envy-free cake cut with \(k\) cuts is PPAD-complete. The theorem also gives a value-oracle lower bound of \((1/\epsilon)^{\Omega(1/k)}/\operatorname{polylog}(1/\epsilon)\) queries. The paper proves this result; its hardness reduction uses the paper’s symmetric Sperner construction, while PPAD membership draws on the earlier cake-cutting framework of Deng, Qi, and Saberi.

A plausible high-multiplicity setting is a large, recurring allocation programme. Each cycle divides a standardized resource kit among \(p\) recipients, using \(k\) cuts and bundling the resulting pieces into \(p\) package types. Many cycles repeat the same allocation template, so there are \(N\) recipients but only \(\tau\) distinct valuation types, with \(N\gg\tau\). People of a type share their complete valuation function, including how they value a piece in the context of the whole partition. The hard subfamily in the paper is especially apt: the authors explicitly use the same utility function for every agent, so it has \(\tau=1\).

Here is the continuous problem I would hand to a prover. Call it Mass-\(3/p\) Approximate Envy-Free Template Cake Cutting. An instance gives \(k,p,\epsilon\), a finite set \(T\) of valuation types with rational masses \(\mu_t\) summing to \(1\), and for each type a utility function satisfying the paper’s continuity and nonnegativity conditions. Choose a \(k\)-cut \(x\), bundle its \(k+1\) pieces into \(p\) packages \(\mathcal B=(B_1,\ldots,B_p)\), and assign population mass \(q_{tj}\) of type \(t\) to package \(B_j\). Each package class has capacity \(1/p\), so a valid assignment obeys
\[ \sum_{j=1}^{p}q_{tj}=\mu_t \quad\text{and}\quad \sum_{t\in T}q_{tj}=\frac1p. \]
A type-\(t\) recipient assigned \(B_j\) is \(\epsilon\)-envy-free when
\[ u_t([x],B_j)+\epsilon\ge u_t([x],B_\ell) \quad\text{for every }\ell\in[p]. \]
The objective is to maximize the mass assigned to packages for which this condition holds. The anchor-specific search task asks for a cut, bundling, and assignment with at least \(3/p\) of the population envy-free. Each unit of mass receives a whole package; \(q_{tj}\) records the share of a type assigned to each package.

The package capacities are the necessary co-modification: a one-off cake cannot be handed to a continuum of people, but repeated per-capita kits can supply each package class to its quota of the population. On the paper’s one-type hard instances, this mirror preserves the envy-free question exactly. Since \(\mu=1\), the capacity constraints force \(q_{1j}=1/p\) for every package. The envy-free mass is therefore the number of \(\epsilon\)-envy-free package types divided by \(p\). It reaches \(3/p\) exactly when at least three packages are envy-free. With identical utilities, assigning one such package to each of three finite agents gives precisely the paper’s \(3\)-out-of-\(p\) condition, and the converse holds as well. Thus the continuous version retains the anchor’s PPAD hardness on this subfamily. I expect hardness to transfer: the reduction’s difficulty lies in the precise cut geometry and encoded utility function, rather than in the number of distinct agent types.

The mirror covers Theorem 20, including its setting where pieces may be bundled, rather than claiming to continueize every result in the paper. It is also distinct from the paper’s existing continuity: the cuts and utility functions are continuous there, but the agents remain finite. The population mass here is the new continuous object.

The weakest point is the repeated-kit interpretation. It is more convincing for a large programme that reuses a package template than for a single cake divided among a handful of people. And the hardness does not show that population multiplicity causes the difficulty: it already holds with one valuation type. Further questions include whether the heterogeneous finite-type version has a matching complexity classification, whether its oracle lower bound survives, and how the result changes if package quotas or the envy-free mass threshold vary.

The case AGAINST (opponent, writing after the proponent)

The strongest case against Theorem 20 as a ChoCo mirror is that the population does no computational work in the proponent’s hard instance. With one valuation type, \(\mu_t=1\), and the equal package quotas force \(q_{tj}=1/p\) for every package. If \(G\) is the set of packages that type considers \(\epsilon\)-envy-free, the assigned envy-free mass is exactly \(|G|/p\). So reaching \(3/p\) is precisely the paper’s condition that three agents be envy-free. The cut geometry, bundling choices, and utility encoding carry the entire PPAD reduction; the continuous population merely rescales the number of recipients.

That gives the mirror a real limitation: its hardness witness does not show that aggregating a large population changes or illuminates the computation. The repeated-kit story also creates a modeling choice. To let many recipients each receive a whole package, the resource supply must grow with the population, and the shared decision is a template repeated across kits rather than a division of one cake among a large society. A heterogeneous extension could make mass assignment substantive, but Theorem 20’s reduction says nothing about that extension’s complexity. The proponent’s formulation also needs a computational representation for the type utility functions—such as circuits or value oracles—before it is a complete complexity problem.

Those points make this a thin mirror, but they do not defeat it under the programme’s stated standard. A single valuation type is still a legitimate high-multiplicity regime; scaling per-capita supply is an allowed co-modification; and an exact discrete-to-continuous identity can itself be a worthwhile result. Theorem 20’s value-oracle lower bound also transfers on the identical-utility subcase. I cannot honestly make a strong negative case against this anchor: the mirror is meaningful, though its demonstrated connection to population aggregation is narrow.
