The continuous mirror question

Given a finite set of types \(T\) with rational masses \(\mu_t>0\) summing to \(1\), rational initial opinions \(s_t\in[-1,1]\), confidence indices \(\alpha_t\in(0,1)\), and signed block-level trust coefficients \(w_{t,u}\), choose changes \(\delta_t\) satisfying \(-1\le s_t+\delta_t\le1\) and \(\sum_t\mu_t|\delta_t|\le B\). The expressed opinions \(z_t\) satisfy \(\left(\alpha_t+(1-\alpha_t)\sum_u\mu_u|w_{t,u}|\right)z_t=\alpha_t(s_t+\delta_t)+(1-\alpha_t)\sum_u\mu_u w_{t,u}z_u\). Find a feasible \(\delta\) maximizing the mean equilibrium opinion \(\sum_t\mu_tz_t\), and return the maximum value.

The model it lives in

A finite-support society with type masses \(\mu_t\), where every member of type \(t\) has the same internal opinion, confidence, and mass-scaled trust interactions with each type \(u\). The decision variable \(\delta_t\) changes the type’s internal opinion within its \([-1,1]\) bounds; the per-capita intervention cost is \(\sum_t\mu_t|\delta_t|\), and the objective is the population mean expressed opinion at the resulting equilibrium.

The objection that survived

The paper studies arbitrary node-specific trust graphs and gives no evidence that large communities commonly have repeated block-level interaction profiles; this limits the mirror’s empirical scope, though the proponent acknowledges the restriction and gives a plausible large-community regime.

fatal: False

What the mirror covers

The mirror covers Theorem 3.1’s internal-opinion allocation with fixed trust topology and confidence indices. It leaves aside interventions that change the graph or recompute confidence, as well as the paper’s experimental comparisons.

Open questions for a prover

  • Give an exact polynomial-time algorithm in the support size and input bit length for this block-regular continuous problem.
  • Determine whether useful approximation guarantees extend from block-regular to approximately block-regular trust networks.

The case FOR (proponent)

The strongest mirror I believe is Block-Trust Continuous Opinion Maximization. The paper gives no named theorem classifying a problem as being in P or NP-hard. Its best computational anchor is Theorem 3.1, proved in this paper: Algorithm 1 optimally solves the internal opinion problem by computing each person’s contribution index \(g_i\), changing internal opinions toward the sign of \(g_i\), and spending the budget first on people with largest \(|g_i|\), up to their \([-1,1]\) bounds. The theorem’s claim is that this produces an optimal modification under the paper’s \(\ell_1\) budget. Its equilibrium formula in Proposition 2 supplies the linear objective that makes this greedy allocation possible.

Here is a continuous version of that underlying problem. An instance has a finite set \(T\) of \(\tau\) agent types, with rational masses \(\mu_t>0\) summing to \(1\). A type specifies an initial opinion \(s_t\in[-1,1]\), confidence \(\alpha_t\in(0,1)\), and its signed trust profile \(w_{t,u}\) toward every type \(u\). The trust profile is block-regular: members of a type have the same interaction pattern with each type group. For a large product or event community, for example, types could be formed from a small number of opinion categories, confidence strata, and recurring interaction roles; millions of users might occupy only dozens or hundreds of such types.

Choose an internal-opinion change \(\delta_t\) for each type, with \(-1\le s_t+\delta_t\le1\) and per-capita budget \(\sum_t\mu_t|\delta_t|\le B\). Let \(z_t\) be the type’s expressed opinion at equilibrium, defined by
\[ \left(\alpha_t+(1-\alpha_t)\sum_u\mu_u|w_{t,u}|\right)z_t =\alpha_t(s_t+\delta_t)+(1-\alpha_t)\sum_u\mu_u w_{t,u}z_u. \]
The problem is to return a feasible \(\delta\) maximizing the society’s mean equilibrium opinion \(\sum_t\mu_tz_t\), together with that maximum value. This is Block-Trust Continuous Opinion Maximization; it mirrors Theorem 3.1’s intervention problem, with the network’s trust interactions represented as per-capita type-to-type influence. Normalizing the paper’s total opinion and budget by population size leaves the intervention objective unchanged.

For this finite-support version, I expect tractability. The equilibrium equations form a \(\tau\times\tau\) linear system. Its solution gives the marginal contribution of changing each type’s internal opinion to the population-wide objective. Because every member of a type has the same contribution in the block-regular regime, the optimal allocation moves opinions toward the beneficial endpoint in order of marginal benefit per unit mass, \(|q_t|/\mu_t\), where \(q_t\) is the objective’s coefficient on \(\delta_t\). It stops when the budget is exhausted or the type reaches its opinion bound. Exact rational linear algebra and sorting give polynomial time in \(\tau\) and the input bit length. This is an algorithmic mirror of the paper’s result, not a claim that the paper proves a complexity classification or that a discrete hardness result dissolves.

The authors have a credible reason to recognize this as their problem: it retains the same social-trust equilibrium, internal-opinion interventions, per-person bounds, limited budget, and aggregate opinion objective. It also preserves their key mechanism: compute marginal influence, then spend the budget where it yields the greatest return. The mirror covers Theorem 3.1’s internal opinion maximization under fixed trust topology and confidence indices. It does not cover changing the network or intervening on confidence itself.

The main weakness is the network regime. The paper’s input is an individual-level signed graph, and its adjusted confidence values may depend on node-specific PageRank and evaluations. A block-regular trust kernel is a genuine restriction: on an arbitrary graph, keeping each person’s full incoming and outgoing interaction pattern as part of their type could make \(\tau\) as large as the population. Still, large communities with repeated roles and group-level exposure patterns are a plausible regime for the same model. Further questions are whether approximately block-regular graphs admit useful additive approximations, and how the computation changes if confidence indices are recomputed as part of the intervention.

The case AGAINST (opponent, writing after the proponent)

The best case against is that the proposed mirror makes a strong new assumption about the network before it makes the population continuous. In Theorem 3.1, a node’s contribution index \(g_i\) depends on the whole signed, directed graph, through \((\Lambda+(I-\Lambda)L)^{-1}\). Nodes with the same opinion, confidence, and local trust summary can still have different \(g_i\) because they occupy different positions in the network. To merge many nodes into one type while preserving the intervention problem, a type must capture their full influence role, not merely their opinion or social category. In a generic trust graph, that can leave nearly every node as its own type.

The proposed block model avoids that problem by assuming repeated roles and type-level interaction patterns. That is coherent, but it describes a restricted, group-averaged network. In the paper’s setting, trust is attached to particular edges; replacing those edges with mass-scaled type interactions changes how influence is represented. If one instead preserves richer variation through a graphon or another continuum network, the computational question depends on how that object is finitely encoded. A finite-step representation returns to a block model; a general kernel does not, by itself, specify a finite binary input or a complexity measure. So the most faithful version risks having no useful multiplicity, while the compressed version risks making the network—not just the population—a different model.

There is also little algorithmic terrain for continuization to expose. The paper already solves its finite-node intervention problem by computing network-wide marginal contributions and allocating budget in their order, subject to each node’s opinion bound. In a block model, the corresponding calculation is a type-level linear solve followed by the analogous allocation. That is a valid continuous-population question, but it appears to inherit the paper’s existing solution structure rather than reveal a new complexity landscape. This point alone would not defeat a well-posed mirror: a simple answer can still be worth asking. It does, however, make the value of the mirror rest almost entirely on whether the group-averaged trust regime is an important instance regime for these authors.

I cannot honestly make the negative case decisive. Theorem 3.1 is a genuine computational anchor, and a large community with repeated, group-level trust roles is plausible. The authors could recognize the block model as their internal-opinion intervention problem. The strongest objection is therefore about the scope and input value of that regime, not that the continuous question is invalid. On the programme’s stated standard, the sole anchor survives unless one can establish that block-structured trust is not a meaningful regime for this model.
