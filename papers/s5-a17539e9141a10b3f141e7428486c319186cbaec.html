The case AGAINST (opponent, writing after the proponent)

The claim that there is no anchor because the paper has no numbered complexity theorem is too strong. It has a named computational contribution in its active-learning methods: entropy and information gain choose expert-labeled tasks, and the experiments report that these choices improve accuracy over random selection. The paper leaves those methods as empirical procedures, without a worst-case complexity or approximation analysis. That gap is a natural mirror question.

Keep the task catalogue finite and continuize the workers. Let \(\mu_t\) be the fraction of the crowd with complete response type \(t\), including its task-feature-dependent error behavior and annotation propensity. In a large citizen-science project, many volunteers contribute only a few annotations; the paper itself motivates pooling their data to learn population-wide bias. Given these type masses, crowd annotations, and an expert-label budget \(B\), ask which set of tasks \(S\), with \(|S|\le B\), minimizes expected label-prediction error after expert answers are obtained. Equivalently, one can study the computational complexity of maximizing expected information gain over \(S\). The workers are the continuous population; the tasks and their labels remain discrete.

This is a recognizable continuation of the paper’s active-learning problem, not a claim that its current model is already a continuous-population treatment. A type can preserve every worker characteristic the model uses, while annotation supply can scale with population size and be represented as mass. The resulting complexity question has clear parameters—task count, number of worker types, label classes, feature dimension, and expert budget—and asks for exact, approximate, or parameterized algorithms. The paper’s missing theorem is therefore an opportunity for the programme, not evidence that no worthwhile mirror exists.
