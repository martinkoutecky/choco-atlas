The continuous mirror question

Given a finite set \(T\) of complete preference types, a rational distribution \(\mu\) over \(T\), and a finite rational antichain \(\Delta\) of threshold vectors \(x\in[0,1]^{\tau+1}\) with \(\sum_{i=0}^{\tau}x_i\le 1\), compute the selected alternative. Let \(p=\sum_{t\in T:\,a\succ_t b}\mu_t\), \(z_i=\mu_{W_i}\) for the \(\tau\) types \(W_i\) indifferent between \(a\) and \(b\), and \(q(\mu)=(p,z_1,\ldots,z_\tau)\). Select \(a\) exactly when some \(x\in\Delta\) satisfies \(\sum_{i=1}^{\tau}(x_i-z_i)^+\le p-x_0\); otherwise select \(b\).

The model it lives in

The society is a distribution \(\mu\) over complete preference types, represented by rational masses. The rule’s input includes a finite antichain \(\Delta\); there is no optimization variable or objective, only aggregation of type masses and threshold comparisons.

The objection that survived

Corollary 4.4 does not state a complexity bound or address finding the antichain, so its computational content rests on treating its explicit finite threshold formula as an evaluation procedure.

The case FOR (proponent)

The strongest case is narrow: Section 4’s anonymous, two-outcome rules for a large electorate. My lead anchor is Corollary 4.4, proved in this paper as a consequence of its preceding characterization results. It says that when the agent set \(V\) is finite, the domain is \(\mathcal W^V\), and there are finitely many preference types \(W_1,\ldots,W_\tau\) indifferent between \(a\) and \(b\), the anonymous weakly group strategy-proof rules with range \(\{a,b\}\) correspond bijectively to antichains in a poset of count vectors. The vector for profile \(P\) is
\[ \bigl(|D(a,P)|,\ |I_1(P)|,\ldots,|I_\tau(P)|\bigr). \]
A rule selects \(a\) exactly when this vector is above at least one antichain element in the paper’s order. The corollary gives an explicit way to compute the outcome by comparing the profile’s vector with those thresholds; the conclusion calls this an implementable algorithm. The paper does not state a complexity bound or prove a hardness result. I use this as an algorithmic representation anchor, not as a formal “in P” theorem.

The natural regime is a large, anonymous consultation on two public projects, with residents asked to rank a broader set of possible designs. Many residents share the same complete preference ordering, while the number of distinct orderings represented is much smaller than the population. Each type is a complete weak order over the alternatives, so people of the same type are indistinguishable for the rule. This resembles the paper’s educational-institution example and its distinction between the two implementable choices and the wider preference domain.

Here is the continuous problem I would hand to a prover: Continuous Anonymous Rule Evaluation. Let \(T\) be an explicitly listed finite set of preference types, including \(\tau\) types \(W_1,\ldots,W_\tau\) indifferent between \(a\) and \(b\). An instance gives a rational distribution \(\mu\) over \(T\), with support size \(\sigma\), and a finite rational antichain \(\Delta\) of threshold vectors in
\[ X=\left\{x\in[0,1]^{\tau+1}:\sum_{i=0}^{\tau}x_i\le 1\right\}. \]
Write \(p=\sum_{t:\,a\succ_t b}\mu_t\), \(z_i=\mu_{W_i}\), and \(q(\mu)=(p,z_1,\ldots,z_\tau)\). Define
\[ x\preceq y \quad\Longleftrightarrow\quad \sum_{i=1}^{\tau}(x_i-y_i)^+\le y_0-x_0. \]
The question is to compute the selected alternative. The rule selects \(a\) if and only if there is an \(x\in\Delta\) such that
\[ \sum_{i=1}^{\tau}(x_i-z_i)^+\le p-x_0; \]
otherwise it selects \(b\). The answer, \(a\) or \(b\), is the solution. This is the normalized-mass version of the corollary’s threshold evaluation.

For explicit finite \(\Delta\), I expect this evaluation problem to be tractable: aggregate the \(\sigma\) listed masses, then check the \(|\Delta|\) thresholds, in \(O(\sigma+\tau|\Delta|)\) rational arithmetic operations, with polynomial bit complexity. The corresponding characterization question is whether, for an atomless population with these types, all anonymous rules immune to manipulation by a positive-mass coalition are exactly the rules whose \(a\)-region is an upper set under \(\preceq\). A coalition can be described by mass transfers \(y_{tt'}\ge0\), where \(y_{tt'}\) is the mass of true type \(t\) reporting type \(t'\); every deviating type must strictly prefer the changed outcome. Extending the paper’s finite-agent equivalence to this setting is part of the proposed mirror, not a result already proved by Corollary 4.4.

The authors would plausibly recognize this as their anonymous two-outcome problem: the finite character vector of counts becomes a vector of type shares, and anonymity still makes that aggregate the input to the decision rule. The mirror covers only Section 4’s anonymous result. It does not cover the paper’s nonanonymous characterization, which is already stated for arbitrary agent sets and uses identity-specific coalitions, nor its other classes of rules. Existing high-multiplicity work would support the regime’s plausibility; it would not make this mirror a novelty collision.

The main follow-up is how to represent the full continuous class. An arbitrary upper set of \(X\) need not have a finite antichain frontier, so finite \(\Delta\) describes a computable subfamily unless a richer effective representation is supplied. Another question is the discrete-to-continuous dictionary: a discrete rule at population size \(n\) lives on a finite grid, and its grid behavior may admit multiple continuous extensions.

The weakest point is substantial: this paper is primarily a characterization paper, not a computational-complexity paper. The proposed evaluation is a direct normalization of an explicit finite formula, and it may be too elementary to open much of the complexity landscape ChoCo is meant to chart. The case stands as a plausible population mirror of one named, computationally usable result, but not as evidence of a new complexity phenomenon.

The case AGAINST (opponent, writing after the proponent)

The strongest case against is that Corollary 4.4 is a characterization, not a computational result. The paper’s theorems and corollaries describe which rules are anonymous and weakly group strategy-proof; they do not define a computational problem, analyze its complexity, or give an algorithm for finding a rule. The conclusion calls the representation implementable, but it assumes the rule’s antichain is already known. Comparing a profile’s character with supplied thresholds explains how to evaluate that rule; it does not explain how to discover or optimize one.

The large-electorate scenario is credible. In an anonymous consultation about two public projects, residents could share complete preference types, and the count vector could naturally become a vector of population shares. That makes a continuous axiomatic characterization plausible. But for the proposed finite-antichain version, evaluation just aggregates the listed type masses and checks each listed threshold. The proposed \(O(\sigma+\tau|\Delta|)\) bound describes that direct calculation; it does not uncover a computational landscape in the paper’s result.

The stronger version—characterizing *all* anonymous rules on the continuous population simplex—runs into a different obstacle. The paper’s finite antichains do not provide a finite input representation for arbitrary upper sets of real-valued shares. Restricting to finite antichains, or to some effectively encoded family of frontiers, makes an algorithmic question possible, but that restriction is additional modeling work. Under the finite-antichain encoding, evaluation remains direct; under an unrestricted class, there is no specified finite input to analyze. Designing rules subject to new objectives might yield harder problems, but it would add a computational task that this paper does not pose.

So I do not have a sound argument that a continuous population is implausible here. The anonymous result makes that mirror more natural than most. The negative case is narrower: its best mirror is a sensible continuous *characterization*, but the paper supplies no named computational result for ChoCo to continue, and the natural finite representation makes the proposed evaluation routine. If a simple evaluation algorithm counts as sufficient computational substance for the programme, the proponent’s anchor survives; on the programme’s stated focus on computational questions, I find it weak.
