The continuous mirror question

Given institutes \(I\), voter or applicant types \(T\), rational masses \(\mu_t\) with \(\sum_{t\in T}\mu_t=1\), type preferences over institutes, institute rankings over types, and class families \(\mathcal C_i\) with rational upper quotas \(u_{i,K}\), where the class-inclusion posets belong to a fixed set \(P\), decide whether there exists a mass allocation \(x_{i,t}\ge0\) satisfying \(\sum_i x_{i,t}\le\mu_t\), \(\sum_{t\in K}x_{i,t}\le u_{i,K}\), and no blocking type-institute pair. Construct such an allocation when one exists, especially when \(P\) contains a non-downward forest.

The model it lives in

A high-multiplicity classified matching market: each type \(t\) carries mass \(\mu_t\), \(x_{i,t}\) is the mass assigned to institute \(i\), quotas constrain aggregate type mass, and stability forbids a positive mass of type \(t\) from preferring \(i\) when every class containing \(t\) has insufficient higher-ranked mass to block admission.

What the mirror covers

The mirror covers Theorem 16's non-laminar stable-existence problem and extends Theorem 13's laminar constructive and existence result to type masses. It leaves the finite-agent polyhedral integrality, median-choice, rural-hospitals, and many-to-many consequences unmirrored.

Open questions for a prover

  • Does non-laminar classified stability remain NP-hard when type mass may be split continuously?
  • Can the paper's intersecting-class gadgets force every stable mass allocation to be integral?
  • Does the laminar mass problem admit applicant-optimal and institute-pessimal allocations under a canonical cumulative-mass order?

The case FOR (proponent)

The strongest positive case is a genuine high-multiplicity mirror of the paper’s classified stable-matching problem. The paper is not already doing this: its fractional variables \(x_{ia}\) are an LP representation of a finite set of named applicants, whereas the mirror treats \(x_{it}\) as the mass of many distinct applicants of the same complete type. A fractional entry does not mean that one applicant is lottery-assigned; an atomless cohort is partitioned into integral assignments.

The natural regime is a large centralized placement market: for example, a national residency, graduate-placement, or public-sector hiring system with millions of applicants but perhaps hundreds of recurring preference-and-qualification profiles. A type \(t\) records everything relevant to the problem: the applicant’s complete preference order over institutes, eligibility, research area, and membership in every institute’s classification. Applicants of the same type are interchangeable. Institute \(i\) has a strict ranking of applicant types, a capacity, and upper/lower quotas on classes of types. The number of applicants \(n\) is enormous, while the number of types \(\tau\) is moderate; rational masses \(\mu_t\) record fractions of the population. Capacities and quotas are naturally normalized by \(n\), since this is a repeated market whose scale grows with the cohort.

My lead anchor is Theorem 16, proved in this paper. It states:

If the fixed set of class-inclusion posets \(P\) contains a poset that is not a downward forest, then deciding whether a \(P\)-classified stable matching exists is NP-complete. This remains true when every class has lower bound zero.

The proof is a reduction from one-in-three SAT. The obstruction is an intersecting “\(V\)” of classes; the construction uses only upper-bound constraints, and the appendix explains that the gadgets can be implemented with at most two intersecting classes per institute. Thus the hardness is not caused by complicated lower-bound bookkeeping.

I would mirror it with the following problem.

Continuous Non-Laminar Classified Stability. An instance consists of:

  • a finite type set \(T\) and rational masses \(\mu_t\ge 0\) with \(\sum_t\mu_t=1\);
  • institutes \(I\);
  • for every type \(t\), a strict preference order \(\succ_t\) over acceptable institutes;
  • for every institute \(i\), a strict ranking \(\succ_i\) of the types;
  • a family \(\mathcal C_i\) of classes \(K\subseteq T\), with rational upper quotas \(u_{i,K}\), including the whole type set as the capacity class;
  • class-inclusion posets belonging to a fixed \(P\) containing a non-downward forest.

A solution is a nonnegative mass allocation \(x_{i,t}\), where \(x_{i,t}\) is the mass of type \(t\) assigned to \(i\). It must satisfy

\[ \sum_{i\in I}x_{i,t}\le \mu_t \]

and

\[ \sum_{t\in K}x_{i,t}\le u_{i,K} \qquad \text{for every }i\in I,\ K\in\mathcal C_i. \]

The allocation is stable if there is no type \(t\) and institute \(i\) such that a positive mass of type \(t\) is currently unmatched or assigned to an institute worse than \(i\), while

\[ \sum_{\substack{u\in K\\u\succ_i t}}x_{i,u}<u_{i,K} \]

for every class \(K\in\mathcal C_i\) containing \(t\). The latter condition says that \(i\) can admit an arbitrarily small mass of \(t\), possibly displacing lower-ranked mass, without violating any class quota.

The decision question is whether such a stable mass allocation exists; the constructive version asks for one.

This is recognisably the authors’ problem: the same two-sided preferences, the same classified institute choice, the same blocking logic, and the same laminar-versus-intersecting class boundary. Only the applicant population has become a distribution. For rational masses, clearing denominators gives the high-multiplicity dictionary: \(N\mu_t\) identical applicants of type \(t\), with \(Nu_{i,K}\) quota. Conversely, an integral matching aggregates to \(x\).

I would expect this problem to be Class C, continuum-specifically hard, though that is a conjectural research direction rather than something already implied by Theorem 16. The reason is that non-laminar stability contains a discrete choice even after individual identities disappear. For every applicant type that wants an institute, some intersecting class-prefix quota must be tight to prevent a blocking move. With crossing classes, those tightness choices can interact in the same SAT-like way as the paper’s gadgets. A successful reduction would need a rigidity lemma showing that splitting a type’s mass cannot evade the gadget; if that succeeds, the hardness is genuinely about the geometry of non-substitutable classified choice, not about counting individual applicants.

I would not claim immediate hardness transfer. Simply replacing each paper applicant by mass \(1/n\) permits fractional splitting, and that may create stable allocations absent in the discrete instance. The important question is whether the paper’s intersecting-class gadgets force relevant masses to \(0\) or their full available value. If they do, the result may be Class B; if they do not, the continuous problem could collapse to a tractable disjunctive LP. Either outcome is valuable.

My second anchor is Theorem 13, also proved in this paper. It states that the proposed algorithm runs in \(O(m^2)\) time, where \(m\) is the total preference-list size, and returns the applicant-optimal, institute-pessimal stable matching whenever one exists; otherwise it correctly reports that none exists. Moreover, when there are no lower bounds, a stable matching always exists.

The corresponding problem is Continuous Laminar Classified Stability. It has the same input and output as above, but every \(\mathcal C_i\) is laminar, equivalently every class-inclusion poset is a downward forest. In the basic no-lower-bound version, the task is to construct a stable mass allocation. In the stronger version, the output must be applicant-optimal and institute-pessimal under the natural cumulative-mass order: for a type \(t\), compare allocations by how much \(t\)-mass receives one of its top \(r\) institutes for every \(r\); for an institute, compare allocations by the cumulative mass it receives among its top-ranked types.

I expect this problem to be Class A. The paper’s proposal algorithm should become a mass-proposal algorithm: a type sends mass down its preference list, and each laminar institute accepts or rejects mass while maintaining the same deficiency and affluent-set invariants. The events are quota saturations and type rejections, so the procedure should be polynomial in the explicit type-level input and the bit length of the rational masses. The no-lower-bound existence result is especially natural in this setting.

The continuous version would also generate useful questions: whether the applicant-optimal/institute-pessimal correspondence survives exactly; whether every rational stable mass allocation decomposes into stable finite matchings; how lower bounds affect rationality and complexity; and whether optimization over stable mass allocations admits a compact LP or requires separation.

The paper’s polyhedral Section 4 is supporting evidence, but I would not use Theorem 25 as a third anchor. Its integral stable-matching polytope concerns finite named applicants and laminar classifications, so presenting it as already being the continuous population problem would invite the correct objection that this is merely outcome-space fractionalization. The lead mirror avoids that collision by making repeated type mass—not fractional assignment of an individual—the primitive object, and by targeting the paper’s non-laminar hardness boundary, where the paper has no integral-polytope result.

My weakest point is therefore clear: the positive case establishes a compelling question, but not that Theorem 16’s NP-hardness survives divisible type mass. Fractional splitting may dissolve precisely the SAT gadget that creates the discrete hardness. The mirror nevertheless survives that objection because it preserves the authors’ central modelling issue—the interaction between stability and classified choice—and turns the uncertainty into the right ChoCo question: does non-laminar classification remain computationally hard when the population, rather than the matching encoding, is continuous?

The case AGAINST (opponent, writing after the proponent)

The strongest negative case is that the proponent has mistaken fractional encoding for population continuization, especially for Theorem 16.

The NP-completeness construction depends on named applicants being distinct across the gadgets. Their preference lists, class memberships, and connections through \(\Gamma\), \(\Psi\), and \(\Lambda\) encode the SAT instance. A complete type must include all of those features. Consequently, in the reduction almost every applicant is its own type: \(\tau\) grows with the formula, and replacing each applicant by a unit mass merely rewrites the discrete instance as variables \(x_{i,t}\in[0,1]\). It does not create a genuine high-multiplicity society.

If, instead, each gadget role is repeated by a large cohort, the proof breaks at its essential point. The literal-pair gadget relies on one applicant occupying one quota position. A continuous cohort can split between the two institutes, so the three integral outcomes in Claim B are no longer exhaustive. Similarly, the clause gadget’s “exactly one activated literal” becomes a system of fractional balances. This is not a superficial failure of notation: the Boolean choice is created by indivisibility.

Repairing that construction would require an all-or-nothing constraint on a type’s mass, an integer cohort variable, or a fixed-charge/nonconvex condition. The first two abandon the population-continuum model; the last introduces a new problem whose hardness is not supplied by Theorem 16. Thus the theorem does not itself provide the claimed continuous mirror. A new fractional hardness construction might exist, but that would be a new result, not a continuization of this paper’s reduction.

Theorem 13 has a different but related problem. Its substantive conclusion is applicant-optimality and institute-pessimality for named agents. Once a type’s mass may be divided among several institutes, there is no automatic analogue of “the applicant’s assignment.” One could compare cumulative mass at the top \(r\) institutes, but that gives a partial preference over allocations and need not produce a greatest stable allocation. One could impose a lexicographic order or optimize a weighted welfare function, but those are additional choices absent from the theorem. In particular, the institute-pessimal order over an ordered tuple of named applicants has no canonical type-level counterpart.

A mass version asking merely for some stable allocation is more defensible, but it discards the theorem’s distinctive optimality statement and becomes a fairly direct laminar-capacitated flow or polymatroidal matching extension. The proposed mass-proposal algorithm is plausible, but that plausibility cuts against the mirror’s value as a faithful computational analogue: it is not the paper’s applicant-optimal stable matching theorem with names removed, but a new anonymous allocation problem with newly chosen objectives.

The proponent can improve the modelling story by using recurring cohorts in a national placement market. That makes high multiplicity plausible, and it prevents a categorical objection based on the application domain. It does not, however, restore the two anchors: Theorem 16 loses its Boolean gadgets under divisible cohorts, while Theorem 13 loses its canonical individual-optimality order.

This is nevertheless not an airtight negative verdict. A carefully designed non-laminar construction might force every stable mass solution to be integral, and a suitable dominance order might recover a meaningful type-optimal theorem. Those would be worthwhile ChoCo questions. The honest conclusion is therefore that the proponent has not established either anchor as stated, but the universal claim that no worthwhile continuous mirror exists is too strong: Theorem 16 remains a plausible open mirror precisely because its fractional-gadget obstruction has not been settled.
