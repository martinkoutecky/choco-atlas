The continuous mirror question

Given a finite rational distribution μ over tree-community templates \(H_j\) and a rational pair-sampling rule π_j for candidate nonlinks in each template, compute the exact population-average Myerson distance \(̅d=∑_j μ_j∑_{(u,v)} π_j(u,v)(1/2-q_{uv}(H_j))\) for a continuum of repeated independent communities.

The model it lives in

A population formed from mass-weighted copies of finite tree communities. Each template specifies the agents’ risk-sharing network and roles; the decision is to compute the exact mean pairwise Myerson distance under the stated template and pair-sampling distributions.

The objection that survived

The tree topology and path calculations remain finite, while population masses only weight the final average; this does not pose a complexity question about a growing connected network.

fatal: False

What the mirror covers

The mirror covers Proposition 20’s exact computation for tree networks and its mass-weighted aggregate over repeated tree communities; it leaves the equilibrium, investment, and empirical results unmirrored.

Open questions for a prover

  • Can exact Myerson-distance computation extend to useful restricted classes of non-tree community templates?

The case FOR (proponent)

The strongest positive case is narrow: it mirrors the paper’s computation of Myerson distances on tree networks, not its main equilibrium results.

The anchor is Proposition 20, proved in this paper’s Appendix A. It says that for a tree network \(L\), the paper’s Incoming Link Deletion algorithm computes \(\hat q(L)=q(L)\) exactly. Here \(q_{ij}\) is the probability, over a uniformly random arrival order, that \(i\) and \(j\) are connected when \(i\) arrives; the Myerson distance is \(1/2-q_{ij}\). So the proposition establishes exact computation of the all-pairs quantity on trees. It is an algorithmic exactness result, not a stated polynomial-time classification or hardness result. The paper has no comparable named hardness anchor.

A possible mirror is Continuum Tree-Population Myerson-Distance Computation. Its population consists of a continuum of interchangeable copies of finite, decorated tree-shaped risk-sharing communities. A type specifies a household’s complete role in a community template: its risk and cost characteristics, group, and rooted position in the decorated tree. Mass is the fraction of the population in each role; if there are many repeated communities with a few symmetric roles, the number of agents can be enormous while the number of types stays small. This fits a plausible regime of many similar village or cooperative risk-sharing groups, though less naturally than a single large village.

An instance gives a finite rationally weighted list \((H_j,\mu_j)\) of tree templates, where \(\mu_j\) is the population share in communities of template \(H_j\), and a rational sampling rule \(\pi_j\) over candidate nonlinks within each template. The task is to return the exact population-average Myerson distance
\[ \bar d=\sum_j\mu_j\sum_{(u,v)}\pi_j(u,v)\left(\frac12-q_{uv}(H_j)\right). \]
The solution is that exact rational value (or the corresponding pairwise values). This is a computation problem, so it has no decision variable to optimize. Running Incoming Link Deletion on each template and taking the rational weighted sum is the direct proposed method. Proposition 20 supplies exactness on every template; tractability of the mixture is an inference from applying the finite computation to each explicitly listed tree and aggregating. I would expect this mirror to be tractable.

The mirror covers only Proposition 20’s tree-case computation. It does not cover the paper’s results about stable network formation, underinvestment, or the star’s incentives. Further questions include exact Myerson-distance computation beyond trees, and whether useful tractability results hold for restricted non-tree networks.

The weakness is substantial: the paper presents Proposition 20 as a tool for empirical preprocessing, while its central contribution is economic and structural. Replicating tree communities makes the population continuous, but leaves the hard part—the network topology—inside each finite template. The mirror also depends on a repeated-community scenario and an explicit pair-sampling rule. If the required anchor must explicitly state a complexity class such as \(\mathrm P\) or \(\mathrm{NP}\)-hardness, then this paper has no qualifying named result; Proposition 20 is only the closest computational anchor.

The case AGAINST (opponent, writing after the proponent)

Proposition 20 is an exactness statement, not a complexity result: on a finite tree, the paper’s estimator agrees with the Myerson-distance quantity it is meant to estimate. It gives no running-time bound or classification of a computational problem. The proposed mirror supplies the missing problem by asking for a weighted average over tree templates and sampled pairs. But once those finite templates are listed, the computation remains inside each tree; the population masses only weight the answers. That is a distribution over finite network instances, not a computational problem created by making the agents in a network continuous.

Repeating a finite village template many times is a plausible high-multiplicity regime, and I would not dismiss it on realism grounds. Its limitation here is that the repeated villages never interact: the topology and all Myerson-distance calculations stay finite, and changing the mass assigned to a template changes only its weight in the average. The mirror therefore adds an aggregate statistic that Proposition 20 does not establish or need. It does not expose a population-scale algorithmic question for ChoCo to chart.

The more substantive alternative is to let a single connected network grow with the population. But the proposition’s quantity relies on finite pivotality: on a tree, if the unique path has \(K\) vertices, then \(q_{ij}=1/K\). As paths grow, this contribution vanishes and the distance tends to \(1/2\). In an atomless limit, a random-priority ordering does not preserve the finite event that every other vertex on a path precedes a focal agent. Nor do type masses alone preserve exceptional structures such as a star’s single hub with links to a growing mass of leaves. One can add singular hubs or a richer network limit, but then the extra structure doing the work is not the distribution over agent types; Proposition 20 provides no result for that new model.

So the negative case is strongest against this anchor, not against every conceivable continuum network model. A continuum average over repeated finite communities is coherent, but it keeps the computation finite and changes only how its outputs are aggregated. A genuinely continuous network would require a different model and a new result. On the evidence of Proposition 20, neither yields a worthwhile continuous mirror of a computational result in the paper.
