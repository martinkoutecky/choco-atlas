The continuous mirror question

Given a rational distribution \(\mu\) over supported valuation types \(T\), rational per-capita supplies \(s\in\mathbb{Q}_{\ge 0}^q\), and valuations \(v_t\in[0,1]^q\) sharing a common weak order over the \(q\) categories, compute integral bundle vectors \(b^1,\ldots,b^r\in\mathbb{Z}_{\ge 0}^q\) and rational masses \(\lambda_1,\ldots,\lambda_r\ge 0\) such that \(\sum_\ell\lambda_\ell=1\), \(\sum_\ell\lambda_\ell b^\ell=s\), and \(\sum_jv_{tj}b^\ell_j\ge p_t-1\) for every supported type \(t\) and every bundle with \(\lambda_\ell>0\), where \(p_t=\sum_jv_{tj}s_j\). Can this be done in time polynomial in \(q,\tau,L\), with bundles remaining integral for each individual?

The model it lives in

A unit mass of agents is distributed over valuation types with masses \(\mu_t\); category supply per capita is \(s_j\). The output is a mass distribution over integral category bundles, with mean bundle equal to the supply vector and every supported type valuing every available bundle at least \(p_t-1\).

The objection that survived

Denominator clearing may make the finite population size exponential in the input length, so Theorem 1.2 does not establish a polynomial-time algorithm for the compressed input; this leaves the Class A prediction unproved.

fatal: False

The case FOR (proponent)

My lead is the ordered-additive clause of Theorem 1.2, proved in this paper. When all agents’ additive valuations are derived from a common master list, the authors give a polynomial-time algorithm that produces a partition \(M\) in which every agent values every part at least \(\mathrm{PROP}_a-1\). I rely on that clause alone; it gives a strong autonomous-choice guarantee because no matter which remaining part an agent prefers, that part meets the bound.

A plausible high-multiplicity setting is a large population receiving indivisible goods from a fixed set of \(q\) categories. Households fall into a finite set \(T\) of valuation types: type \(t\) has a fixed additive value \(v_{tj}\) for category \(j\), and all types rank the categories in the same weak order. There may be millions of households but only a modest number \(\tau=|T|\) of distinct types. The total supply of category \(j\) scales with population size. This fits settings such as distributing standardized goods to large cohorts whose valuation profiles differ while their category rankings broadly agree.

Here is the continuous problem I would hand to a prover: Common-Order Mass Partition. The input is a rational type distribution \(\mu\) over \(T\), rational per-capita supplies \(s\in\mathbb{Q}_{\ge0}^q\), and rational valuations \(v_t\in[0,1]^q\) sharing a common weak order over the categories. Define type \(t\)’s proportional share by \(p_t=\sum_j v_{tj}s_j\). Compute a finite list of integral bundle vectors \(b^1,\ldots,b^r\in\mathbb{Z}_{\ge0}^q\) and rational masses \(\lambda_1,\ldots,\lambda_r\ge0\) such that
\[ \sum_{\ell=1}^r\lambda_\ell=1,\qquad \sum_{\ell=1}^r\lambda_\ell b^\ell=s,\qquad \sum_{j=1}^q v_{tj}b^\ell_j\ge p_t-1 \]
for every type \(t\) in the support of \(\mu\) and every bundle \(\ell\) with \(\lambda_\ell>0\). The output size and running time should be polynomial in \(q,\tau\), and the binary input length \(L\).

The mass \(\lambda_\ell\) is the fraction of the population for whom bundle \(b^\ell\) is available. Agents arrive in any measurable order with type frequencies \(\mu\), and each infinitesimal mass of agents chooses a most-valued bundle among those still available, consuming the same mass of that bundle option. Since every available bundle satisfies the guarantee for every type, any order and any tie-breaking among best options preserve the bound. Each individual still receives an integral bundle; only population shares, bundle frequencies, and per-capita supplies are continuous.

This is a faithful mirror of the ordered-additive result: its key object is a partition that is safe for every agent, so autonomous choice cannot deplete a later agent’s only good option. For any compatible finite population size \(N\), take \(N\mu_t\) agents of each type and \(Ns_j\) copies of each category. Theorem 1.2 applies to that instance, and the empirical distribution of its bundles satisfies the mass constraints. The result therefore supports the mirror’s existence and its \(\mathrm{PROP}-1\) guarantee. I expect the compressed search problem to be Class A, with the common order enabling a round-robin-style construction. A feasible mass measure can also be compressed to at most \(q+1\) bundles while preserving its mean supply and guarantee.

The scope is deliberately narrow: it covers the static ordered-additive guarantee in Theorem 1.2. It does not mirror the paper’s dynamic rebundling results, its general additive setting, or Theorem 1.1’s discrepancy lower bound. The paper’s fixed-arrival optimization hardness appears as an unnumbered statement in Section 10, so it cannot serve as an anchor under the requested numbering rule.

The weakest point is the gap between the theorem’s explicit-instance algorithm and the compressed continuous problem. Clearing the rational denominators may require a finite population \(N\) exponential in \(L\); Theorem 1.2’s polynomial runtime in \(N\) and the item count therefore does not establish polynomial time in \((q,\tau,L)\). That compressed algorithm is the actual computational question this mirror adds. Still, the population regime is credible, and the mirror preserves both the indivisibility each household faces and the autonomous choice that motivates the paper.

The case AGAINST (opponent, writing after the proponent)

The best case against is that the continuous problem’s existence is inherited almost mechanically from Theorem 1.2, while the proponent has not shown that its compressed input yields a new tractability question. Clear the denominators of \(\mu\) and \(s\), make \(N\mu_t\) agents of each type and \(Ns_j\) copies of each category, and apply the theorem. The resulting \(N\) bundles, each with mass \(1/N\), satisfy the proposed constraints. Carathéodory compression can shrink the output, but it does not show how to find it in time polynomial in \(q,\tau,L\). The proponent’s Class A expectation is therefore a conjecture, not a consequence of the cited algorithm.

That is a reason to scrutinize the mirror’s computational formulation, but it does not defeat it. The denominator-clearing argument confirms that the mass model is an exact high-multiplicity version of the static guarantee. Repeated copies of categories are indistinguishable for the problem, the common-order regime is plausible for a large standardized cohort, and the \(-1\) bound remains meaningful when per-capita supply is fixed. Because every supported bundle meets the guarantee for every type, autonomous choice does not create a depletion problem: any bundle still available is good for the arriving mass.

Nor does compression make the question ill-posed. The discrete theorem runs in time polynomial in the expanded population, which may be exponential in the binary input length; finding a polynomial-time algorithm in the compressed parameters is precisely the additional computational question. The fact that existence transfers from finite instances is supporting evidence for the mirror, not a novelty collision.

So I cannot make a persuasive universal case against this anchor. The scenario is narrow, and the proponent has not justified its algorithmic prediction, but the ordered-additive clause of Theorem 1.2 has a coherent, nondegenerate continuous-population mirror. A negative verdict would need a stronger obstruction than the material here supplies.
