The case FOR (proponent)

I can make a narrow positive case, but I can’t honestly supply a qualifying computational anchor: the paper states no named result that puts a problem in P, proves it hard, or gives a parameterized complexity classification. Its closest result is Proposition 1, proved in the paper: the strong Pareto rule \(\phi^{SPO}\), which selects outcomes not weakly dominated for every agent and strictly dominated for at least one, is behaviorally implementable when all agents are socially responsible. That is an implementation result, not a computational one.

A natural population version would take each type \(t\) to be a complete weak ranking of the finite outcome set \(X\), with mass \(\mu_t>0\) denoting its share of a large membership organization or policy constituency. The regime is many members but relatively few distinct rankings; people with the same ranking are indistinguishable for this rule. The continuous problem would be: given \(X\), the supported types and their rational masses, compute the set
\[ \operatorname{SPO}(\mu)=\{x\in X:\nexists y\in X\text{ such that }yR_tx\text{ for every }t\text{ with }\mu_t>0,\text{ and }yP_tx\text{ for at least one such }t\}. \]
The solution is the selected set, with a dominating outcome \(y\) as a certificate for any excluded \(x\). The mass vector describes the society; the decision being computed is which outcomes survive the Pareto test. Proposition 1 makes this a plausible companion to the paper’s result: it identifies the rule that socially responsible agents can implement, while the population version asks for that rule’s outcomes.

This query is tractable: with \(m=|X|\) and support size \(\tau\), pairwise dominance checks take \(O(m^2\tau)\) preference comparisons, plus the cost of reading the input. It covers only the strong-Pareto application under social responsibility, not Theorem 2’s full characterization or the partial-honesty result. A natural next question would be whether Theorem 2’s characterization has a useful measure-based version for rules defined over distributions of preferences.

The weakness is decisive for the programme’s anchor requirement: Proposition 1 neither claims a computational bound nor studies a continuous population. The proposed query also computes the rule’s output, not the rights structure or its implementation, and its answer depends only on which types have positive mass. It is therefore a sensible follow-on question, but it does not establish that this paper contains a continuous computational mirror of one of its named results.

The case AGAINST (opponent, writing after the proponent)

The decisive problem is that this paper states no computational result to mirror. Theorem 1 gives a sufficient condition for implementation with partially honest agents; Theorem 2 characterizes implementation with socially responsible agents; Proposition 1 applies that characterization to the strong Pareto rule. None studies an algorithm, complexity, or computational problem. A continuous version could ask a new question, but it would not continue a computational result in this paper.

The strongest proposed anchor is Proposition 1. For a society \(\mu\) over weak-ranking types, computing the strong Pareto set means checking, for each pair \(x,y\in X\), whether every type with positive mass weakly prefers \(y\) to \(x\), and at least one strictly prefers \(y\). With \(m=|X|\) and support size \(\tau\), this takes \(O(m^2\tau)\) preference comparisons. The masses themselves do no work: the result depends only on which types have positive mass, and is the same as the strong Pareto set for a finite profile containing one representative of each supported type. That is a coherent population model, but it supplies no computational question from Proposition 1.

The stronger alternative is to continuize Theorem 2: define social choice rules over distributions of rankings and seek a measure-based version of its characterization. That remains an axiomatic implementation question. If the rule is an arbitrary input, its representation and size are unspecified; if it is a fixed rule such as strong Pareto, the task becomes checking an abstract condition on the rule, not computing a solution for a society. The partial-honesty theorem has the same issue: it is an implementation claim, with its assumption about at least one honest agent requiring a behavioral restatement in a continuum.

So the best negative case is about fit with this programme, rather than a proof that no useful follow-on could exist. The continuous strong-Pareto query is sensible, and high multiplicity makes its population interpretation reasonable. But the paper offers no computational anchor, and the most natural query adds only a simple support-based calculation. A richer computational project would need to introduce a new problem beyond the paper’s stated results.
