The continuous mirror question

Given rational type masses \(\mu_p\) and rational per-capita supplies \(q_r\), with each type \(p\) desiring resource classes \(D_p\) at values \(v_r\), allocate mass \(x_{p,b}\) to integer bundles \(b\in\mathbb{Z}_{\ge 0}^{R}\). Subject to \(\sum_b x_{p,b}=\mu_p\) and \(\sum_{p,b}b_r x_{p,b}\le q_r\), compute the largest \(T\) such that every assigned bundle has value \(\sum_{r\in D_p}v_rb_r\ge T\), or an additive-\(\epsilon\) approximation to it.

The model it lives in

A nonatomic population with finitely many complete types and rational masses; standardized indivisible resource classes have rational per-capita supplies. The decision variables are masses assigned to integral bundles, and the objective is to maximize the minimum value received.

The objection that survived

For explicit instances, the continuous problem is already the configuration LP that the paper studies and can approximately solve; the remaining question is whether support-compressed masses and supplies permit the stated polynomial running time.

fatal: False

What the mirror covers

The mirror covers the restricted max-min allocation objective and allocation of integral bundles to type mass. It does not transfer Theorem 1’s \(23/6\) integrality-gap claim, which compares the discrete optimum with the configuration LP, or settle the discrete rounding problem.

Open questions for a prover

  • Can the optimum be approximated in time polynomial in the number of types, resource classes, input bit length, and \(1/\epsilon\) when masses and supplies are binary-encoded?
  • Can the required integral-bundle covering problem be priced efficiently for this support-compressed input?

The case FOR (proponent)

My lead is a Continuous Restricted Max-Min Fair Allocation problem. It mirrors the paper’s underlying allocation problem, rather than asking for an integrality gap between two models.

The anchor is Theorem 1, proved in this paper: for restricted max-min fair allocation, the configuration LP’s integrality gap is at most \(23/6\). The paper says that, together with the cited result that the configuration LP can be solved to any desired accuracy \(\delta\) in polynomial time, this gives a polynomial-time \(23/6+\delta\)-approximation for the discrete problem.

A plausible regime is a large public allocation of recurring, indivisible opportunities—such as standardized places or slots—where supplies scale with the population. There may be millions of people but relatively few complete types: people of a type have the same desired resource classes and the same values for them. If resource class \(r\) has per-capita supply \(q_r\), a population of size \(N\) has \(Nq_r\) copies. This is a credible high-multiplicity regime when types are few compared with people and the opportunities are standardized. It preserves the paper’s central question: how to maximize the least value received when assigning indivisible resources. Each person still receives an integral bundle; only the mass of people assigned each bundle can be fractional.

Precisely, let \(P\) be the finite set of player types, with rational masses \(\mu_p\) summing to \(1\), and let \(R\) be the resource classes. Each class \(r\) has per-capita supply \(q_r\) and value \(v_r\); type \(p\) desires the classes in \(D_p\), receiving value \(v_r\) from each unit of a desired class and zero otherwise. A bundle is an integer vector \(b\in\mathbb Z_{\ge0}^{R}\). Let \(x_{p,b}\) be the mass of type \(p\) assigned bundle \(b\). The problem asks for the largest \(T\) for which there is an allocation satisfying

\[ \sum_b x_{p,b}=\mu_p \quad\text{for each }p,\qquad \sum_{p,b} b_r x_{p,b}\le q_r \quad\text{for each }r, \]

with \(x_{p,b}>0\) only when \(\sum_{r\in D_p}v_rb_r\ge T\). A solution is \(T\) and a finite-support allocation \(x\); for an additive-\(\epsilon\) version, require \(T\ge T^*-\epsilon\). The intended running-time question is whether this can be done in \(\mathrm{poly}(\tau,s,L,1/\epsilon)\), where \(\tau=|P|\), \(s=|R|\), and \(L\) is the binary input length.

I expect Class A, at least for additive approximation. The configuration LP now describes an actual allocation of a nonatomic population: the mass of a type can be divided among integral bundles, so its optimum is the continuous max-min value. A column-generation approach would need to price integral bundles meeting a target value, a type-specific covering-knapsack problem. Establishing the needed running time for the support-compressed input is a concrete part of the mirror, rather than something Theorem 1 itself settles. Further questions include how the continuous optimum relates to finite replicated instances and whether exact pricing is harder than approximate pricing.

The authors should recognize this as their allocation problem in a natural high-multiplicity regime: the restricted valuations, indivisible bundles, and max-min objective are retained. The weak point is substantial: the \(23/6\) bound itself does not survive as a meaningful continuous claim. It bounds the gap between integral allocation and the configuration LP; in this mirror, the LP is the allocation model, so that gap is \(1\) by construction. The honest case is therefore that Theorem 1 motivates a computational question about the continuous population version of their underlying problem—not that its numerical integrality-gap theorem has a direct continuous counterpart.

The case AGAINST (opponent, writing after the proponent)

The strongest case against the mirror is that its computational core is already the paper’s configuration LP. At a target \(T\), let \(x_{t,B}\) be the mass of type \(t\) assigned an integral bundle \(B\). Requiring \(\sum_B x_{t,B}=\mu_t\) and \(\sum_{t,B\ni r}x_{t,B}\le q_r\), with only bundles worth at least \(T\) allowed, is the configuration-LP feasibility question with type masses and per-capita supplies on the right-hand sides. In a nonatomic population, splitting a type’s mass across bundles is a literal allocation, so the LP is no longer merely a relaxation. The paper itself says this LP can be solved to arbitrary accuracy in polynomial time. For the ordinary explicit-instance formulation, the proposed additive-approximation question is therefore already answered by the machinery the paper studies.

The strongest version of the mirror—standardized resource classes whose supplies scale with the population, while every person still receives an integral bundle—does not escape this overlap. It keeps the allocation story intact, but still reduces to the same configuration model. Class multiplicities change the pricing oracle into a multiplicity-coded covering-knapsack problem; they do not introduce a new population-level objective or interaction. Theorem 1’s contribution is an analysis of the configuration LP against integral allocations. Making fractional assignment operational for a continuous population puts the LP itself at the center, where the paper already places it.

There is a genuine caveat: the paper’s polynomial-time statement for the LP does not, by itself, establish a runtime polynomial in the proposed binary-encoded parameters \((\tau,s,L,1/\epsilon)\). Clearing denominators could create a huge explicit instance, and the compressed pricing problem needs its own analysis. That leaves a possible technical follow-up, but it is a narrower question about succinct multiplicities and pricing around an established LP. So the negative case is one of novelty and priority, not a fundamental objection to the model. The population regime is sensible, and I cannot honestly rule out that the compressed-input result would be worthwhile; the claim that *no* worthwhile mirror exists is weak.
