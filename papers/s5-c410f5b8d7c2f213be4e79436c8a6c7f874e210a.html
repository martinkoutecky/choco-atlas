The closest candidate is minimax-regret voting with partial preferences. Its algorithm chooses a voter-query pair: it uses who has answered which questions to decide whom to ask next. A mass of voters with the same *partial* ranking does not necessarily have the same answer to the next query, since their hidden rankings may differ. If the type records enough to guarantee identical answers, asking one representative can resolve the whole type and the elicitation problem largely disappears. If it does not, a continuous version needs extra structure for how query responses divide the mass. That makes it a new population-learning model, not a direct continuation of the paper’s elicitation result.

That is a substantial paper-specific objection, but it does not establish the requested universal claim.
