The continuous mirror question

Given \(m\) chores, types \(T=\{1,\ldots,\tau\}\) with masses \(\mu_t=1/\tau\), positive rational linear disutilities \(D_t(y)=\sum_{j=1}^{m}d_{tj}y_j\), and accuracy \(\eta>0\), compute type bundles \(x_t\in\mathbb{R}_{\geq 0}^{m}\) and prices \(p\in\mathbb{R}_{\geq 0}^{m}\) such that \((1-\eta)\langle p,x_t\rangle\leq\langle p,x_{t'}\rangle\), \(D_t(x_t)\leq D_t(y)\) whenever \(\langle p,y\rangle\geq\langle p,x_t\rangle\), and \(\sum_t\mu_t x_{tj}=1\) for every chore \(j\).

The model it lives in

A finite type distribution \(T\) with mass \(\mu\), type bundles \(x_t\), prices \(p\), and aggregate feasibility \(\sum_t\mu_t x_{tj}=1\); the weighted objective is \(\sum_t\mu_t\log D_t(x_t)\).

The objection that survived

Exact type aggregation means the mirror introduces little new equilibrium geometry or algorithmic structure; its value depends on treating high-multiplicity compression as a substantive computational regime.

fatal: False

What the mirror covers

The mirror covers the paper's approximate CEEI algorithms for linear and well-behaved convex disutilities. It leaves exact CEEI, the cited exchange-model hardness result, and the mixed-manna and unequal-income extensions as separate variants unless transferred explicitly.

Open questions for a prover

  • Can arbitrary rational masses \(\mu_t\) be handled with a running time polynomial in their encoding length and the relevant income ratio?
  • Does exact CEEI remain tractable in the finite-type mass model?
  • What approximation guarantee transfers from the type-level solution to a finite population with \(N\) agents?

The case FOR (proponent)

The strongest positive case is a continuous-population version of chore CEEI, with the population—not the chores or the allocation space—as the continuous object.

Let \(T=\{1,\ldots,\tau\}\) be a finite set of complete agent types. Type \(t\) has mass \(\mu_t\), disutility function \(D_t\), and all agents of that type have identical preferences and all other parameters relevant to equilibrium. A type-level allocation gives every member of type \(t\) a bundle \(x_t\in\mathbb R^m_{\ge 0}\). With one normalized unit of each chore per unit society, feasibility is

\[ \sum_{t\in T}\mu_t x_{tj}=1 \]

for every chore \(j\). A price vector is \(p\in\mathbb R^m_{\ge0}\). The action variable is the collection of type bundles \(x=(x_t)_{t\in T}\); the objective is to find prices and bundles forming an approximate CEEI. Equivalently, the algorithm searches for a positive approximate KKT point of the weighted Nash-disutility objective

\[ \sum_{t\in T}\mu_t\log D_t(x_t) \]

over the aggregate feasible disutility region.

The cleanest regime is \(\mu_t=1/\tau\) for every type. The population may nevertheless contain \(N=K\tau\) agents, with \(K\) identical copies of each type and \(K\) very large. Thus \(N\) can be millions while \(\tau\) is only a few dozen or a few hundred. A natural example is a large institution assigning fractional teaching loads, shifts, or administrative chores to many workers in a small number of skill-and-preference cohorts. The cohort description is complete: two workers of one type have the same disutility for every chore and the same income requirement.

This is not merely saying that chores are divisible; the paper already does that. The new continuous object is the population measure \(\mu\), and market clearing is weighted by mass. The normalization is harmless. If the paper’s \(\tau\)-agent algorithm returns bundles \(z_t\) with \(\sum_t z_{tj}=1\), set \(x_t=\tau z_t\) and \(p^{\mathrm{cont}}=p^{\mathrm{paper}}/\tau\). Then \(\sum_t \mu_t x_{tj}=1\), while payments and optimal-bundle comparisons are preserved because the disutilities are homogeneous. Conversely, a discrete election with \(K\) copies of each type can be averaged by type and rescaled in exactly this way.

My lead problem is:

\[ \textsc{Cont-CEEI}_{\mathrm{lin}} \]

An instance consists of \(m\) chores, \(\tau\) types with rational linear disutilities

\[ D_t(y)=\sum_{j=1}^{m}d_{tj}y_j,\qquad d_{tj}>0, \]

uniform masses \(\mu_t=1/\tau\), and a rational accuracy parameter \(\eta>0\). The output must be type bundles \(x_t\) and prices \(p\) such that, for every pair of types \(t,t'\),

\[ (1-\eta)\langle p,x_t\rangle\le \langle p,x_{t'}\rangle, \]

each \(x_t\) is an optimal bundle for type \(t\) at its own payment level,

\[ D_t(x_t)\le D_t(y) \quad\text{whenever}\quad \langle p,y\rangle\ge \langle p,x_t\rangle, \]

and aggregate supply is cleared,

\[ \sum_{t=1}^{\tau}\frac1\tau x_{tj}=1 \]

for every chore \(j\). The linear part of the paper in fact gives the stronger version in which the last two conditions are exact and only equal income is approximate.

This mirrors the paper’s main computational problem directly. The paper does not use arbitrary stories about workers: it takes each agent’s disutility function as the complete input. Replacing \(N\) identical rows by one type with mass is therefore a legitimate high-multiplicity version, not a change to a different economic question.

The anchor is Theorem 16, proved in this paper. It states that, given positive linear disutility values \(D_{11},\ldots,D_{nm}\), Algorithm \(\ref{alg:KKT}\), together with the conversion from approximate KKT points to equilibria, finds an \(\varepsilon\)-CEEI in time polynomial in \(n\), \(m\), \(1/\varepsilon\), \(\log(\max D_{ij}/\min D_{ij})\), and the description complexity of the disutilities. Applying the theorem with \(n=\tau\), then applying the scaling above, gives a polynomial-time algorithm for \(\textsc{Cont-CEEI}_{\mathrm{lin}}\) whose running time depends on the number of types \(\tau\), not on the number \(N\) of agents represented by those types.

I expect this problem to be Class A: tractable by continuous optimization. The paper’s exterior-point method is already searching in disutility space rather than enumerating named agents. In the high-multiplicity regime, the same method becomes an algorithm over type masses and type disutilities. The further questions are whether arbitrary rational masses \(\mu_t\) can be handled with the same dependence on the bit-length of the masses, whether exact CEEI remains tractable, and how rounding the continuous type solution gives an additive approximation for a finite discrete population.

A second, broader mirror is:

\[ \textsc{Cont-CEEI}_{\mathrm{cvx}} \]

The instance is the same type distribution and aggregate feasibility system, but each \(D_t\) is a convex, monotone, 1-homogeneous disutility function supplied through value and partial-derivative oracles. The functions satisfy the paper’s Assumption 17: their marginal changes are bounded below by \(1/L\) in each coordinate and their values are \(L\)-Lipschitz on the relevant feasible region. The requested output is an \(\eta\)-CEEI in the same sense as above, with type bundles, prices, approximate equal incomes, approximate optimality, and approximate aggregate market clearing.

The anchor is Theorem 42, also proved in this paper. It states that, given black-box access to 1-homogeneous convex disutilities satisfying the well-behavedness assumption and to their partial derivatives, Algorithm \(\ref{alg2:KKT}\) finds an \(\varepsilon^{1/6}\)-CEEI in time polynomial in \(n\), \(m\), \(1/\varepsilon\), and \(\log L\). In the type model, substitute \(n=\tau\) and run the algorithm with internal accuracy \(\varepsilon=\eta^6\). This yields an \(\eta\)-CEEI in time polynomial in \(\tau\), \(m\), \(1/\eta\), and \(\log L\), under the oracle model.

This second problem is also expected to be Class A, but with a more conditional claim: the result depends essentially on finite \(\tau\), well-behaved disutilities, and usable derivative oracles. If the type space itself becomes continuous, or if types are represented only implicitly by a distribution oracle, a genuinely new separation and integration problem appears. That could produce a continuum-specific hardness result.

The supplied paper contains no numbered hardness theorem for its own chore-division problem. Its introduction mentions PPAD-hardness for a more general exchange model, but that is cited from elsewhere and is not the paper’s numbered computational anchor. The honest positive case therefore rests on Theorems 16 and 42, both algorithmic anchors.

The weakest point is that the paper does not itself formulate \(\mu\) or prove a theorem parameterized by a binary-encoded arbitrary mass vector. The cleanest direct transfer uses equal-sized cohorts, and arbitrary masses would require the weighted KKT modifications discussed only informally in Section 6.2; very small masses may also create dependence on \(\mu_{\max}/\mu_{\min}\). Moreover, because the paper’s algorithm is already polynomial in the number of named agents, the first mirror can look like a compression of an existing algorithm rather than a radically new problem.

That weakness does not eliminate the mirror. The paper’s model remains finite-agent throughout, while the proposed question has a population measure, mass-weighted market clearing, and complexity measured in the number of distinct types rather than the number of represented agents. It is therefore a genuine high-multiplicity continuous analogue of the paper’s CEEI computation, with a concrete and credible Class A prediction.

The case AGAINST (opponent, writing after the proponent)

The negative case is weaker than it first appears. Theorem 16 is a genuine computational result, and its best continuous-population reformulation survives the obvious objections.

For a finite type set with uniform masses, the proposed mirror is almost exactly isomorphic to the paper’s own problem. Given a \(\tau\)-agent instance with bundles \(z_t\), define \(x_t=\tau z_t\), use per-capita feasibility \(\sum_t \frac1\tau x_{tj}=1\), and rescale prices by \(p^{\mathrm{cont}}=p^{\mathrm{paper}}/\tau\). Since every disutility is 1-homogeneous,

\[ D_t(x_t)=\tau D_t(z_t), \]

and payments, optimal-bundle comparisons, and approximation guarantees are preserved. Thus Theorem 16 immediately yields a polynomial algorithm over types rather than represented agents.

That is the strongest available negative point: the “continuum” adds no new mathematical structure here. Chores are already divisible, allocations are fractional, and the objective and constraints contain no individual identities. A population of many identical workers can be quotiented exactly to one representative per type; the large population exists only in the accompanying story, not in the computational object. The proposed mirror is therefore a compressed restatement of the finite problem, not a relaxation that exposes a previously hidden population phenomenon.

The same observation defeats the weaker objection based on arbitrary masses. For masses \(\mu_t\), set \(y_t=\mu_t x_t\). Then \(\sum_t y_{tj}=1\), while type \(t\) has effective income proportional to \(\mu_t\). By homogeneity,

\[ D_t(y_t/\mu_t)=\frac{1}{\mu_t}D_t(y_t), \]

so the continuous problem is precisely a finite unequal-income CE instance. Section 6.2 already sketches this weighted KKT formulation. Very small masses may create dependence on the income ratio, but that is a numerical-conditioning issue in a finite weighted problem, not a fundamental obstruction to the mirror. Uniform masses avoid it entirely.

Theorem 42 has the same status. With finitely many types, the value and derivative oracles are simply the paper’s \(n=\tau\) named oracles, and the exterior-point method operates on the same finite disutility region. Replacing agents by type masses changes coefficients in the feasibility equations; it does not create a population-level separation or integration problem. If one instead insists on a genuinely infinite type space, the problem becomes a new oracle and measure-theoretic model not covered by Theorem 42, so it can no longer serve as a direct mirror of this paper’s result.

This is not an objection based on what the continuous answer happens to be. It is an objection that, for this particular paper, the finite-agent model already forgets identity whenever agents are interchangeable. Continuization does not simplify an individual-level combinatorial structure; it merely renames repeated rows and rescales bundles. Existing high-multiplicity work should not be treated as a collision, but here the stronger fact is that the paper’s optimization model itself admits exact type aggregation.

Still, this does not amount to a convincing universal negative. The proposed cohort interpretation—many workers with identical skill and chore-disutility profiles—is economically credible, and the type-compressed formulation has a legitimate complexity parameter \(\tau\) instead of the represented population size. Theorem 16 and Theorem 42 therefore remain worthwhile anchors unless the programme demands that a mirror introduce genuinely new computational structure rather than an exact high-multiplicity quotient. I would not honestly claim that no continuous mirror is worthwhile; the defensible verdict is “yes, but with low novelty: the mirror is an exact weighted/type compression of an already divisible finite problem.”
