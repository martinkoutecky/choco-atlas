The case FOR (proponent)

The best positive case is the paper’s aggregation across scientists in section 5. It has a plausible population mirror: a large scientific community evaluating the same finite set of theories, with many scientists sharing the same overall ranking. A type is a strict ranking \(R\) of the theories, and \(\mu_R\) is the fraction of scientists with that ranking.

One could define Mass-Borda Theory Ranking as follows. The input is a finite theory set \(X\) and a rational distribution \(\mu\) over the supported rankings. For each theory \(x\), compute its mass-weighted Borda score \(B_\mu(x)=\sum_R\mu_R b_R(x)\), where \(b_R(x)\) is its positional score under \(R\). The output is the ranking of theories by these scores. A setting with many scientists but relatively few ranking types makes the high-multiplicity interpretation credible. This directly mirrors the paper’s discussion of using Borda to aggregate individual scientists’ rankings; its expected computational classification is tractable.
