The continuous mirror question

Given a finite item set \(M\), budget \(q\), and rational distribution \(\mu\) over finitely many complete monotone submodular valuation types \(v_t:2^M\to\mathbb{Q}_{\ge 0}\), choose an integral project \(S\subseteq M\) with \(|S|\le q\) maximizing \(W_\mu(S)=\sum_t\mu_t v_t(S)\), or approximate its optimum within a specified factor.

The model it lives in

Continuous submodular CPP has valuation types \(t\), masses \(\mu_t\), an integral public project \(S\), and objective \(W_\mu(S)=\sum_t\mu_t v_t(S)\). Equivalently, the population induces the aggregate submodular valuation \(V_\mu\), so the item-selection combinatorics remain discrete.

The objection that survived

For CPP, the exact aggregation \(V_\mu(S)=\sum_t\mu_t v_t(S)\) makes type multiplicity computationally redundant and means the mirror may not expose continuum-specific tractability.

fatal: False

What the mirror covers

The mirrors cover the constant-size computational hardness clauses of Theorems 1.3 and 1.1. They leave the communication-complexity results, two-player communication variants, upper-bound approximation results, and the continuous valuation-domain construction largely untouched.

Open questions for a prover

  • Can the finite-to-continuous dictionary for CPP be formalized with concise rational type descriptions and explicit bit-complexity bounds?
  • For welfare maximization with unrestricted submodular type supports, what is the complexity of the resulting configuration-LP pricing problem?
  • Which additional constraints on type masses or item supplies produce genuinely continuum-specific hardness rather than Class B hardness?

The case FOR (proponent)

The strongest positive case is a two-anchor case, with Theorem 1.3 as the lead because its population mirror is especially clean.

The paper’s Theorem 1.3 is proved in the paper. In full, it says that for Combinatorial Public Projects (CPP) with submodular valuations, a \((3/4+\varepsilon)\)-approximation requires exponential communication; with two players, a \((7/8+\varepsilon)\)-approximation requires exponential communication; and with constant-size submodular valuations, a \((1-1/e+\varepsilon)\)-approximation would imply \(\mathrm{P}=\mathrm{NP}\). I anchor on the final, computational clause.

The natural mirror is Continuous Submodular CPP. There is a finite set \(M\) of project items and a budget \(q\). A voter or user type \(t\) is a complete submodular valuation \(v_t:2^M\to\mathbb{Q}_{\ge 0}\), including its support and all parameters relevant to its utility. The society is a rational distribution \(\mu\) over finitely many types, with \(\sum_t\mu_t=1\). The decision variable remains an integral public project \(S\subseteq M\), \(|S|\le q\), and its welfare is

\[ W_\mu(S)=\sum_t \mu_t v_t(S). \]

The problem is: given \((M,q,T,\mu,(v_t)_{t\in T})\), output such an \(S\) maximizing \(W_\mu(S)\), or approximate the optimum within a specified factor. This continuizes only the population. The project itself remains a discrete set of items.

A convincing regime is a large population of users sharing finitely many recurring demand profiles: for example, many households with the same public-service needs, or many customers with the same preferred software features. If there are \(N\) copies of every type, then the population has \(N|T|\) agents but only \(|T|\) distinct types, with \(N\) arbitrarily large. This is a genuine high-multiplicity instance, not an appeal to individually named users.

The paper’s CPP reduction gives a direct hardness-transfer argument. It associates a type \(e\) with every element of a Max \(k\)-Cover universe and uses the unit-demand valuation

\[ v_e(S)=\min\{|S\cap D_e|,1\}, \]

where \(|D_e|\) is constant. Give each type equal mass. Then \(W_\mu(S)\) is exactly the fraction of universe elements covered by the selected project items. Replicating every type \(N\) times changes the number of agents but not the normalized objective. Therefore a \((1-1/e+\varepsilon)\)-approximation for Continuous Submodular CPP would yield the forbidden approximation for Max \(k\)-Cover. I would classify this mirror as Class B: hardness transfers because the combinatorics live in the item universe and the project budget, not in population multiplicity.

The paper’s Theorem 1.1 supplies a second, complementary mirror. It is also proved in the paper and states that for welfare maximization with submodular valuations, a \((1-\frac{1}{2e}+\varepsilon)\)-approximation requires exponential communication, while for constant-size submodular valuations such an approximation would imply \(\mathrm{P}=\mathrm{NP}\). I use its second clause.

Call the mirror Continuous Constant-Size Submodular Welfare. There is a finite set \(M\) of item categories, a rational per-capita supply \(\rho_j\) for each \(j\in M\), and a type distribution \(\mu\). Each type \(t\) has a monotone submodular valuation \(v_t\), depending nontrivially on at most \(d\) item categories, where \(d\) is constant. A solution assigns each unit of type mass an integral bundle \(S\subseteq M\). If \(x_{t,S}\) is the mass of type \(t\) receiving \(S\), feasibility is

\[ \sum_{S}x_{t,S}=\mu_t \]

for every \(t\), and

\[ \sum_{t,S:j\in S}x_{t,S}\le \rho_j \]

for every item category \(j\). The objective is

\[ \max \sum_{t,S}x_{t,S}v_t(S). \]

The supplies are scaled with population: for an \(N\)-agent realization, there are \(N\rho_j\) item copies. Thus every individual still receives an integral bundle; only the assignment of mass to bundles is fractional.

This mirror is plausibly Class A under the paper’s own constant-size restriction. Since \(v_t(S)=v_t(S\cap D_t)\) and \(|D_t|\le d\), it is sufficient to consider at most \(2^d\) relevant bundles for each type. The entire problem is then an explicitly polynomial-size configuration LP with at most \(\tau 2^d\) variables. The discrete NP-hardness in Theorem 1.1 can therefore disappear: it relied on assigning one-copy indivisible items among named players, whereas the high-multiplicity version has repeated item supply and fractional mass assignment while preserving integral bundles.

This is a plausible continuation of the authors’ problem because welfare maximization is already a sum over players; replacing the census by type masses and scaling supplies is exactly its high-multiplicity form. It also exposes the paper’s real computational boundary: with constant-size types, pricing is trivial; with unrestricted submodular types, the configuration LP again raises a demand/pricing problem. Further questions include whether general submodular types yield Class C hardness, whether fixed support size gives stronger parameterized algorithms, and how accurately finite populations approximate the mass solution.

I would not use the paper’s Definition 2.1 or Lemma 2.1 as anchors: their continuity concerns the valuation domain \([0,1]^M\), not the population. Nor would I claim the communication-complexity clauses themselves have been continuized.

The weakest point is the welfare mirror’s supply scaling. If a referee insists that the paper concerns a one-shot auction with a fixed finite inventory, recurring copies of item categories may seem like a substantive market change. The CPP mirror is less vulnerable: it has no item-allocation supply issue, and its public project remains exactly the paper’s discrete decision. Even if the welfare mirror is rejected, Continuous Submodular CPP remains a precise, natural, high-multiplicity problem whose hardness is inherited from the paper’s Theorem 1.3.

The case AGAINST (opponent, writing after the proponent)

The strongest negative argument defeats the CPP anchor, but it does not honestly defeat the welfare anchor.

For Theorem 1.3, the proposed continuous CPP has an exact sufficient statistic that removes the population entirely. Define

\[ V_\mu(S)=\sum_t \mu_t v_t(S). \]

Because nonnegative weighted sums of submodular functions are submodular, Continuous CPP is simply ordinary CPP for the single submodular valuation \(V_\mu\). In the paper’s reduction,

\[ V_\mu(S)=\sum_e \mu_e \min\{|S\cap D_e|,1\}, \]

which is just a weighted coverage function. The type distribution, its multiplicities, and the “households” interpretation contribute no population-level decision or constraint. They can be aggregated away before the algorithm starts. This is a genuine degeneracy of the population axis, not an argument that the answer happens to remain hard.

The communication version is even less suitable: its lower bound depends on valuations being held separately by players. A publicly supplied distribution over valuation types has erased precisely the private-information structure that communication complexity measures. One could add max-min objectives, type-specific guarantees, fairness, or strategic reporting, but those would be new problems rather than continuizations of Theorem 1.3.

The welfare anchor is much harder to defeat. With fixed item inventory, high multiplicity does degenerate: \(N\) repeated bidders compete for only \(m\) items, so per-capita welfare vanishes as \(N\) grows. But the programme explicitly permits the natural repair—scale supplies with population. Under that repair, with constant-support types, the proposed problem has the configuration LP

\[ \max \sum_{t}\sum_{S\subseteq D_t} x_{t,S}v_t(S) \]

subject to

\[ \sum_{S\subseteq D_t}x_{t,S}=\mu_t,\qquad \sum_{t,S:j\in S}x_{t,S}\le \rho_j. \]

There are at most \(\tau 2^d\) relevant configurations when \(|D_t|\le d\). Clearing denominators gives a finite market with \(N\) copies of each type and \(N\rho_j\) copies of each item category; every individual still receives an integral bundle. Thus this is a legitimate high-multiplicity population model, not merely fractional outcomes.

One can object that the source paper has unique items whereas the mirror has recurring item categories. That is a real modelling choice, but it is exactly the sort of co-modification the programme permits when population continuization otherwise collapses. The resulting question remains recognisably submodular welfare maximization, and its tractable LP is precisely the kind of continuous computational result the programme seeks.

So the defensible negative case is: Theorem 1.3 contributes no worthwhile population mirror because CPP aggregates all population information into one valuation. But the universal claim fails on Theorem 1.1. The scaled-supply, constant-support welfare model survives the strongest objections and is a credible Class A mirror.
