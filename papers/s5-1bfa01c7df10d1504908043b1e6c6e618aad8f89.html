The continuous mirror question

Given a finite set of dwelling classes \(H\), a support \(T\) of types, and a rational distribution \(\mu\) over \(T\), where each type specifies a strict ranking over \(H\) and an initial endowment class \(\eta(t)\), compute a feasible core allocation or report that none exists. An allocation is a rational flow \(x_{t,h}\ge 0\) with \(\sum_h x_{t,h}=\mu_t\) and \(\sum_t x_{t,h}=q_h\), where \(q_h=\sum_{t:\eta(t)=h}\mu_t\). A blocking coalition may select positive mass from each type currently assigned to each class, pool its members’ initial endowments, and reassign them so that every participant weakly prefers their new class and positive mass strictly prefers it. Determine the complexity of exact core-finding as a function of \(|H|\), \(\tau=|T|\), and input bit length \(L\).

The model it lives in

A continuum housing-exchange market with finitely many interchangeable dwelling classes \(H\) and complete agent types \(t\in T\), each encoding both a ranking and an initial endowment class. The rational mass \(\mu_t\) of each type receives one whole dwelling per individual; \(x_{t,h}\) records type-level assignment mass, and class supply \(q_h\) scales with the population. Core blocking is defined by reallocating the participants’ initial endowments without making any participant worse off and strictly improving positive mass.

What the mirror covers

The mirror covers Theorem 12’s housing-market core problem. It leaves aside the Pareto-optimal matching results, core verification, and the distributed TTC algorithm.

Open questions for a prover

  • Does a core allocation always exist in this mass model, and is it unique?
  • What is the exact computational complexity of finding and verifying a core as a function of \(|H|\), \(\tau\), and \(L\)?
  • Does the CC-hardness reduction in Theorem 12 survive when cohorts can split across dwelling classes?

The case FOR (proponent)

The strongest anchor is Theorem 12, proved in this paper: *computing the core of a housing market is CC-hard*. The paper proves this with a logspace reduction from the lexicographically first maximal matching problem, which it identifies as CC-complete. Each graph vertex becomes an agent with an initially owned house; the ordered incident edges determine that agent’s preferences. The reduction shows that an edge belongs to the lex-first maximal matching exactly when its two corresponding agents exchange houses in the unique core. This is a hardness result about finding the core, rather than about verifying a proposed matching.

A plausible high-multiplicity setting is a large public-housing exchange. Many households may share a preference ranking over standardized dwelling classes and the same initial class of dwelling. Let \(H\) be the finite set of dwelling classes, and let each type \(t\) specify both a strict ranking \(\succ_t\) over \(H\) and an initial endowment class \(\eta(t)\). The society is a rational distribution \(\mu\) over a support \(T\), with \(\tau=|T|\); class \(h\) has supply \(q_h=\sum_{t:\eta(t)=h}\mu_t\). Here the number of households can be much larger than \(\tau\). Preferences and endowments are both included in the type, so agents grouped together are genuinely indistinguishable for this problem.

I would call the mirror Mass-Core Housing Exchange. An instance consists of \(H,T,\mu\), the rankings, and the endowment map \(\eta\). A candidate allocation is a rational mass flow \(x_{t,h}\ge 0\) satisfying
\[ \sum_{h\in H}x_{t,h}=\mu_t \quad\text{and}\quad \sum_{t\in T}x_{t,h}=q_h. \]
Each resident receives one whole dwelling; \(x_{t,h}\) records the mass of type \(t\) receiving class \(h\). The task is to output a core allocation, or report that none exists. There is no separate welfare objective: the solution must be feasible and admit no blocking coalition of positive mass.

Precisely, a block selects \(z_{t,h}\le x_{t,h}\) mass of type \(t\) currently assigned to \(h\). Those participants bring their initial endowments, giving the coalition supply \(b_j=\sum_{t:\eta(t)=j}\sum_h z_{t,h}\) of class \(j\). It can reassign them using masses \(w_{t,h,j}\) with \(\sum_j w_{t,h,j}=z_{t,h}\) and \(\sum_{t,h}w_{t,h,j}=b_j\). A block requires \(w_{t,h,j}>0\) only when \(j\succeq_t h\), and requires positive mass to strictly improve. A core flow has no such certificate. These definitions make the mirror a computational question about population mass and the original housing-market exchange, rather than a question about fractional outcomes in isolation. The parallel version should ask whether the exact output flow can be computed in uniform NC, and whether computing it is CC-hard under logspace reductions, with input size measured in \(|H|,\tau,L\).

At the paper’s parallel-complexity resolution, I expect hardness to transfer: this is the transfer-side outcome of the programme’s trichotomy. Theorem 12’s reduction encodes ordered graph structure in the preference and house data, so its combinatorics appear to live in the market’s alternatives and rankings, not only in the number of repeated agents. The paper itself gives a sequential TTC algorithm for the discrete core, so the relevant comparison is parallel complexity, not a claim of NP-hardness. Establishing the expected CC-hardness for the mass problem would require proving that the reduction still works when cohorts can split across house classes.

That last point is the weakest part of the case. The discrete theorem concerns indivisible, individually identified houses and finite coalitions. The mass model permits a type’s cohort to split across classes and defines blocking in terms of positive mass. In the public-housing scenario, the mirror is credible when dwelling classes are interchangeable for the preferences and endowments being modeled; where individual addresses matter, collapsing them into classes changes the problem. The paper’s other results—Pareto-optimal allocation and distributed TTC—are outside this proposed mirror. The further questions are whether a mass core always exists and is unique, how efficiently it can be found and verified as a function of \(|H|,\tau,L\), and whether the discrete reduction survives fractional cohort assignments.

The case AGAINST (opponent, writing after the proponent)

Theorem 12 is a genuine computational anchor: the paper proves a named complexity result about finding the core. The strongest objection is that its housing market has no repeated complete types. Each agent initially owns a distinct house, and a type that records both preferences and the exact endowment is therefore unique to that agent. Repeating agents while preserving those endowments is impossible: the theorem’s model ties ownership and preference data to individual vertices.

The proposed mass model repairs this by replacing individual houses with interchangeable classes and letting each class’s supply scale with the population. That can describe standardized public housing, but it changes what coalitions can do. In the paper, a coalition trades specific houses among their specific owners. In the class model, a cohort can split across classes and its members can exchange equivalent copies. The reduction from lex-first maximal matching encodes graph structure in vertex-specific ownership and ordered preferences; it does not establish hardness for this class-based economy. Preserving all those distinctions would make the support grow with the graph, often to one type per agent.

That gap weakens the connection to Theorem 12, but it does not defeat the mirror. A class-based core problem is well-defined, and a public-housing setting with genuinely interchangeable units is plausible. The flow records who receives each class, and the proposed blocking certificate can be stated entirely in terms of those flows. The theorem’s reduction need not transfer for the continuous question to be worth asking.

So the negative case is limited: the anchor supports a mirror only after a substantive change to the market’s goods and blocking relation, and the paper’s hardness result offers little direct guidance about the resulting problem. I cannot honestly conclude that no worthwhile mirror exists in any scenario. The proposed mass-core version survives that objection, though its case depends on convincing the authors that class-based housing exchange is a natural instance of their problem.
