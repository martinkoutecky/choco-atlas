The continuous mirror question

Given a network hypergraph \(H=(T,E)\) with singleton recipes \(e_t=\{t\}\), a strict ranking \(\succ_t\) of each type's incident recipes, and rational masses \(\mu_t>0\) summing to \(1\), find a rational allocation \(x\in\mathbb{Q}_{\ge 0}^{E}\) such that \(\sum_{e\ni t}x_e=\mu_t\) for every \(t\in T\), and for every recipe \(e\in E\) some \(t\in e\) satisfies \(\sum_{\substack{f\in\delta(t)\f\succeq_t e}}x_f=\mu_t\). Can such a stable allocation be computed in time polynomial in \(|T|\), \(|E|\), and the input bit length \(L\)?

The model it lives in

Treat \(T\) as interchangeable role cohorts with population masses \(\mu_t\), and each hyperedge as a feasible team recipe. The variable \(x_e\) is the mass assigned to recipe \(e\); each individual still receives one indivisible recipe. Stability requires every recipe to be blocked by at least one type whose entire mass is assigned to recipes ranked at least as high.

What the mirror covers

The mirror covers Theorem 1.1's stable-matching search problem for network hypergraphs; it leaves weighted optimization over stable matchings and other hypergraph families untouched.

Open questions for a prover

  • Can a stable mass allocation be computed in time polynomial in \(|T|\), \(|E|\), and \(L\)?
  • Does scaling rational masses to integer capacities give an exact finite stable \(b\)-matching counterpart under the same recipe and preference assumptions?

The case FOR (proponent)

My anchor is Theorem 1.1, proved in this paper: given a hypergraphic preference system whose hypergraph is a network hypergraph, there is a polynomial-time algorithm to compute a stable matching. It is a search result, not an optimization result: the output is a stable matching, with no objective to minimize or maximize. The proof uses the known correspondence between stable matchings and kernels, then shows that the relevant conflict graph is a directed-edge graph with a clique-acyclic orientation.

A plausible high-multiplicity setting is a large production or service system that forms teams along a directed workflow tree. A type is a role cohort: many interchangeable agents with the same feasible team recipes and the same strict ranking of those recipes. A feasible team recipe uses one agent from each of a set of distinct role types, and those sets form a network hypergraph. The population can be enormous while the number of role types and recipes stays moderate. This is a narrow regime, but the paper itself gives bipartite stable matching as a special case of its model, and describes stable matching with capacities as a natural adjacent problem.

I would call the mirror Network-Hypergraph Stable Mass Matching. Its input is a network hypergraph \(H=(T,E)\) over role types \(T\), each type’s ranking of its incident recipes, and rational type masses \(\mu_t>0\) with \(\sum_{t\in T}\mu_t=1\). As in the paper, include a singleton recipe \(e_t=\{t\}\) for the outside option. The decision variable \(x_e\ge 0\) is the mass of teams using recipe \(e\); each infinitesimal agent still gets a whole, discrete team recipe. Require \(\sum_{e\ni t}x_e=\mu_t\) for every type \(t\). A mass allocation is stable if, for every recipe \(e\), some type \(t\in e\) satisfies
\[ \sum_{\substack{f\in\delta(t)\\ f\succeq_t e}}x_f=\mu_t. \]
That condition says the whole cohort of at least one role in \(e\) is assigned to teams it likes at least as well as \(e\). Otherwise every role has positive mass assigned to worse teams, and a positive mass of agents could form teams using \(e\). The question is to output such an \(x\), with running time measured in \(|T|\), \(|E|\), and the binary bit length \(L\) of the masses and rankings. There is no optimization objective, just as in Theorem 1.1.

This makes the population continuous while leaving the outcome for each agent indivisible. The mass is the amount of population assigned to each recipe, not a lottery over teams for a finite society. It is also a genuine capacity change: each type now supplies \(\mu_t\) mass rather than one agent. That change is within the programme’s scope. The paper’s final section makes the connection especially plausible: it discusses stable \(b\)-matching, notes that total unimodularity gives existence, and identifies polynomial-time stable \(b\)-matching on network hypergraphs as a natural open direction. Rational masses can be scaled to integer capacities, so this problem is a continuous-capacity version of that question.

My working conjecture would be Class A, tractable, using a capacity-aware method that exploits the network-tree structure. The result in Theorem 1.1 does not establish that conjecture, but the network structure and the paper’s capacity discussion make it a credible computational question. The competing concern is Class C: the paper says its kernel approach depends on capacity one, and general fractional stable-matching computation is known to be hard. Whether that difficulty persists on network hypergraphs is a question this mirror would make precise. Class B is not the natural forecast here: the anchor is a tractability result, not a discrete hardness result to transfer.

The weak point is that a type-level network hypergraph need not remain a network hypergraph if one literally replaces each type by many named clones and expands every recipe into all combinations of those clones. So the high-multiplicity relationship needs a careful finite-to-continuous dictionary; I would not claim the paper’s theorem automatically supplies it. Still, this is a strong candidate for author recognition: it asks about the same stability notion and network coalition structure, with population masses entering as capacities, and it lands directly on a future direction the paper itself identifies.

The case AGAINST (opponent, writing after the proponent)

The strongest objection is that this does not inherit Theorem 1.1’s algorithm. That theorem is about capacity one: its kernel corresponds to a stable matching because the selected hyperedges must form a stable set. With type masses, several units of the same recipe may be selected, and intersecting recipes may both carry mass. As the paper itself says for stable \(b\)-matching, the kernel reduction then fails. So the role-cohort model is not a routine high-multiplicity application of the theorem; it asks for an algorithm for a different, capacitated problem. A clone-level interpretation also needs care: all recipe combinations must be feasible, and agents in a role cohort must rank them identically.

That objection does not defeat the best version of the mirror. The model can stipulate interchangeable role cohorts and recipe-level preferences, just as the proponent does. Rational masses give a natural finite counterpart through integer capacities after scaling. More decisively, the paper itself calls stable \(b\)-matching a useful model and identifies polynomial-time stable \(b\)-matching on network hypergraphs as a future direction. Under the programme’s scope, that capacity change is allowed, and the paper’s recognition of the question supports its relevance.

There is one anchor, Theorem 1.1, and I cannot honestly defeat it. The proponent’s Class A forecast is conjectural, and the paper’s kernel algorithm does not establish it. But whether the answer will be tractable is not grounds against asking. My negative case is therefore weak: this is a distinct capacitated problem with a real modelling and algorithmic gap, but the paper’s own discussion makes that gap look like a worthwhile continuous-population mirror.
