The continuous mirror question

Given alternatives \(A\) and a distribution \(\mu\) over source types \(t=(A_t,\sigma_t)\), where \(A_t\subseteq A\) is the visible set and \(\sigma_t\) is its local total order, does there exist a total order \(\rho\) on \(\bigcup_{\mu_t>0} A_t\) such that \(\rho|_{A_t}=\sigma_t\) for every \(t\) with \(\mu_t>0\)?

The model it lives in

Build a precedence digraph on \(\bigcup_{\mu_t>0} A_t\), adding \(a\to b\) whenever some positive-mass type ranks \(a\) above \(b\); ask whether it has a topological ordering \(\rho\). The distribution is encoded by binary rational masses, and feasibility depends on which types have positive mass; cycle detection gives a polynomial-time test, for example \(O(\tau m^2+L)\).

What the mirror covers

Covers Proposition C.1 and full-merge stalk feasibility over supported types; leaves the Incompatibility Index, Mallows experiments, and other quotient results outside the mirror.

The case FOR (proponent)

The strongest honest case is a narrow mirror of exact fusion feasibility. My lead problem is Continuous Full-Fusion Feasibility. The paper has no numbered theorem explicitly classifying a problem as “in P”; its closest computational anchor is Proposition C.1 (Empty stalk \(\Leftrightarrow\) constraint cycle), proved in Appendix C. I would use the proposition’s precise characterization as the anchor and treat polynomial-time solvability as a consequence of that result and the cycle-detection algorithm, not as wording the proposition itself uses.

Proposition C.1 says: for a quotient map \(\pi\), a merged vertex \(v'\) with preimage \(P\), and a profile \(\sigma\), form a directed graph on the alternatives visible in \(P\), with an arc \(a\to b\) whenever some source \(v\in P\) ranks \(a\) above \(b\). The pushforward stalk at \(v'\)—the set of total orders extending every source’s local order—is nonempty if and only if this constraint graph is acyclic, and empty if and only if it contains a directed cycle. This holds for any size of \(P\), including cases where every pairwise overlap is consistent. The paper proves this characterization and computes with it by cycle detection.

In the mirror, an instance is a finite set of alternatives \(A\) and a distribution \(\mu\) over source types \(t=(A_t,\sigma_t)\), where \(A_t\subseteq A\) is the type’s visibility set and \(\sigma_t\) is its complete local ranking. Each \(\mu_t>0\) is a binary rational fraction of the source population, and \(\tau=|\operatorname{supp}(\mu)|\). The question is whether there is a total order \(\rho\) on \(\bigcup_t A_t\) such that \(\rho|_{A_t}=\sigma_t\) for every positive-mass type. The decision variable is that shared ranking \(\rho\); the criterion is exact feasibility, with no compromise to any represented type. A solution is \(\rho\), or, for a no-instance, a directed cycle certifying the conflict. This is the paper’s underlying fusion problem after merging the full population into one source. Its expected classification is tractable: build the constraint graph and test it for a cycle in time polynomial in \(m=|A|\), \(\tau\), and the mass encoding length \(L\), for example \(O(\tau m^2+L)\).

A plausible regime is a large rating or survey platform that fuses partial rankings over a fixed small slate. Many sources see different subsets, but the number of possible visibility-and-ranking types is bounded for fixed \(m\). For five alternatives there are at most 325 nonempty visibility-and-order types, so millions of source records could be represented by a distribution over a few hundred types. Here mass means the share of sources with each complete data pattern. The paper’s setting already treats sources as voters where appropriate, and exact fusion is its stated task; the common-ranking question should be recognizable to its authors. The cycle \(A\to B\to C\to A\) formed by three types seeing \(\{A,B\}\), \(\{B,C\}\), and \(\{A,C\}\) also preserves a distinctive feature of their problem: pairwise obstruction can be zero while a full merge is impossible.

This mirror covers the pushforward and merged-stalk solvability result only. It does not continuize the Mallows experiment, the Incompatibility Index experiments, or the paper’s topological language. The paper’s Remark 3.6 reports that counting compatible orders is \(\#\mathrm P\)-complete, citing Brightwell and Winkler; that could motivate a separate counting question, but it is not a numbered complexity theorem or an anchor for this case.

The soft spot is substantial: the masses do not affect feasibility except by determining which types have positive mass. Repeated sources collapse to one type, so this is a clean high-multiplicity version of exact fusion, but not a mass-weighted optimization problem and not a case where discrete hardness is shown to dissolve. A natural next question would be the minimum population mass that must be excluded to make the remaining sources fusible. That would make mass consequential, but it extends beyond the result anchored here.

The case AGAINST (opponent, writing after the proponent)

The strongest objection is that Proposition C.1 is a feasibility characterization, not a named complexity result. Its algorithm checks a constraint digraph for a cycle on one proposed merge. The continuous mirror can inherit that check, but it does not turn the paper’s result into a new population-scale computational problem.

The proposed distribution over source types is coherent: for a fixed slate, a type can be its visibility set and local ranking, and many sources can share that type. But exact full fusion asks whether one order extends every positive-mass type. The masses themselves never affect the answer. The instance reduces to the union of the types’ precedence constraints on at most \(m\) alternatives; feasibility depends on whether that graph is acyclic. This is a real high-multiplicity feasibility question, but its continuous population enters only through which types are present, not through how much of society holds each type. That limits the mirror’s value as a study of population continuization.

A more population-sensitive variant would maximize the mass of sources whose partial rankings a single order can satisfy, or minimize the mass that must be excluded to make fusion possible. That fits the paper’s talk of locating and repairing conflict, and could be a worthwhile problem. But it adds a selection objective the paper does not study: Proposition C.1 supplies a test for a fixed set of sources, not a result about choosing the mass to retain. It would be a new mirror, not a continuous formulation of this anchor.

That leaves a genuine weakness in the negative case. The exact-fusion problem has a plausible high-multiplicity setting, a faithful type definition, and a clean continuous formulation. Its mass-insensitive answer is not by itself a reason to reject it: a well-posed tractable mirror can still be useful. I can argue that the anchor offers little computational payoff from continuization, but I cannot honestly rule out a worthwhile mirror in every scenario.
