The continuous mirror question

Given a finite set of APs \(F\), user types \(T\) with rational masses \(\mu_t\), a population scale \(\rho\), and explicitly represented continuous cell-payoff functions derived from the WLAN throughput and control rules, compute an assignment \(x_{tf}\geq 0\) (including an outside option) with \(\sum_f x_{tf}=\mu_t\) that has no blocking reassignment. A block may involve a finite set of APs and portions of incumbent or unmatched type mass; all participating APs and user mass must weakly improve under the new cell payoffs, with at least one strict improvement.

The model it lives in

Keep the APs as individual facilities and represent users by complete types that include their rate vectors, traffic parameters, and utility parameters. Assign type mass \(x_{tf}\) to each AP, evaluate cells using explicit mass-dependent payoff maps and population scale \(\rho\), and ask for a core-stable assignment under mass-splitting deviations.

The objection that survived

The paper's throughput depends on absolute cell size as well as type proportions, but the proposed normalized masses do not specify the population scale needed to define the continuous payoff functions.

fatal: False

What the mirror covers

The mirror covers BDAA's computation of a core-stable association; it leaves the paper's throughput simulations, quota-control design, and radio-resource allocation results outside the question.

Open questions for a prover

  • Which population scaling gives continuous cell payoffs that preserve the paper's WLAN throughput and control assumptions?
  • Does a core-stable mass assignment always exist under the paper's regularity conditions, and is it unique?
  • Can one compute such an assignment in time polynomial in \(F\), \(\tau\), and the encoded input size, including the cost of checking blocks?

The case FOR (proponent)

My lead is a fluid core-stable WLAN association problem, anchored in Proposition 6, proved in this paper’s Appendix D. It says that BDAA has complexity \(O(n^5)\), where \(n=\max(F,W)\), measured in proposals; the proof bounds the total number of proposals by \(F^3W^2\). BDAA is the paper’s algorithm for finding a stable association in a many-to-one matching game. The paper gives no numbered hardness result for this association problem. Its related-work section mentions NP-hardness for a different AP-association objective, but that is not a result of this paper.

Here is the mirror I would ask someone to solve. The input has a finite set of labelled APs \(F\), and a finite support \(\mathcal T\) of user types with rational masses \(\mu_t\), where \(\sum_t\mu_t=1\). A type is a complete user description for this model: its physical-rate vector to the APs, traffic and packet parameters, and utility parameters. Users of a type are indistinguishable in all these respects. APs remain individual facilities. For each AP \(f\), the instance specifies the continuous cell-payoff functions induced by the paper’s throughput, sharing, and control rules: \(\pi_{tf}(z)\) is the payoff to one type-\(t\) user in a cell with type-mass vector \(z\), and \(\Pi_f(z)\) is the AP’s payoff. The cell equations use masses and type proportions in place of integer counts; any quota penalty is applied to cell mass. Users who are unmatched receive a specified outside payoff.

A feasible association is a matrix \(x_{tf}\geq 0\), for \(t\in\mathcal T\) and \(f\in F\cup\{0\}\), such that \(\sum_f x_{tf}=\mu_t\); \(f=0\) denotes unmatched mass. Write \(z_f=(x_{tf})_{t\in\mathcal T}\). The question is to compute an association with no blocking coalition in the fluid core sense: no finite set \(A\subseteq F\), together with its incumbent user mass and any recruited unmatched mass, can reassign those users among the APs in \(A\) and the outside option so that every participating AP and every participating user mass weakly improves and at least one strictly improves. More explicitly, the blocking reassignment may split each type’s mass; each resulting cell’s payoff is evaluated at its new type-mass vector. A solution is the matrix \(x\), together with a certificate that no such reassignment blocks it.

This preserves the paper’s question: self-interested users and APs form cells, payoffs depend on who else is in the cell, and the target is a core-stable association. The changed object is the user population: a large campus, convention, or city-centre WLAN may serve many sessions through a modest number of APs, while PHY rates, coverage patterns, traffic profiles, and utility parameters place users into a much smaller set of complete types. The association variable is mass because an operator can target a share of each type, rather than named users one at a time. The corresponding algorithmic question is whether the fluid problem can be solved in time polynomial in \(F,\tau,L\), where \(\tau=|\mathcal T|\) and \(L\) encodes the input, rather than in the number of individual users.

I expect this version to be tractable under the paper’s regular Nash-bargaining and stable-preference conditions. The assignment uses \(F\tau\) mass variables, and the same type-level payoff structure that defines the discrete preferences also defines the fluid cells. Continuous optimization could help search over those masses and check for blocking reassignments. This is a Class A conjecture, not a consequence of Proposition 6. It also raises questions the paper’s theorem does not answer: does a fluid core-stable association always exist, is it unique, and can an algorithm compress BDAA’s proposals to type masses while accounting for the cost of evaluating AP preferences?

The mirror covers the BDAA stable-association result only. It does not claim to continuize the paper’s throughput simulations, its quota-control design, or radio-resource allocation as an outcome-space problem. The users—not the throughput allocations—are the continuum.

My weakest point is that Proposition 6 counts proposal steps, while the paper’s initialization has APs compute preferences over possible user coalitions. There can be exponentially many such coalitions in \(W\); the paper does not establish polynomial end-to-end complexity in a compact raw WLAN input. And a fluid core is not obtained just by replacing \(W\) with mass: divisible users can form blocking groups unavailable in the finite model, and BDAA’s individual proposals do not directly become mass proposals. Those are substantial gaps. They do not make the mirror artificial, though: coalition composition, user types, and mass-based load targets are already central to the authors’ model. The concrete open question is whether those ingredients admit a compact continuous algorithm.

The case AGAINST (opponent, writing after the proponent)

Proposition 6 is the only algorithmic anchor. It says BDAA uses \(O(n^5)\) proposals, where \(n=\max(F,W)\). That is a real computational result, but it is not an end-to-end polynomial-time bound for a compact WLAN instance. In Step 1.b, each AP computes preferences over possible user coalitions; there can be \(\sum_{j\le q_f}\binom{W}{j}\) such coalitions. The proposition counts proposals after those preferences are available. A continuous mirror of that count risks measuring a different algorithmic task from the one the paper actually implements.

There is also a model-level obstacle. The paper’s cell performance depends on both the rate composition \(n_C\) and the number of users \(|C|\). A distribution over user types gives proportions, but does not by itself determine cell cardinality. Replicating the same type proportions can change the contention and throughput calculations while leaving the proposed mass-assignment input unchanged. One can add a total-population parameter and choose how radio resources and payoffs scale with it. That would make a coherent fluid model, but the choice determines which preferences and blocking coalitions the model retains.

The strongest fluid version would define throughput functions of type masses and ask for a positive-mass core-stable assignment. It is mathematically sensible, and the WLAN’s finite rate levels make repeated complete user types plausible. But its stability notion changes the role of individual users. In the paper’s finite game, a particular user can join a blocking coalition and affect the cell’s composition. In an atomless model, one user has zero mass and cannot change that composition. Requiring a deviating group to have positive mass tests coordinated cohort moves; preserving the effect of one-user deviations requires retaining an atom size or a population scale. The fluid core may answer a useful market-design question, but it no longer directly mirrors BDAA’s finite-player core result.

So the negative case is that the proposed mirror would need both a new physical scaling model and a new blocking notion, while Proposition 6 itself gives only a proposal-count bound that omits potentially dominant preference construction. Those are substantial reasons to treat this as a separate continuum matching project rather than a continuization of the paper’s computational result. They do not rule out such a project: the repeated-type regime is plausible, and a deliberately specified fluid WLAN could be worth studying. That is where this case is weakest.
