The case FOR (proponent)

The strongest positive mirror is Theorem 1, proved in this paper. It says that no deterministic rule for four states can assign a nonnegative integer allocation summing to house size \(h\), satisfy quota \(f_i(p,h)\in\{\lfloor hp_i/\sum_j p_j\rfloor,\lceil hp_i/\sum_j p_j\rceil\}\), and be population monotone across all pairs of inputs \((p,h),(p',h')\), even when \(h\ne h'\). Here monotonicity forbids a comparison in which state \(i\)'s population weakly rises and state \(j\)'s weakly falls, yet \(i\) loses seats and \(j\) gains seats. The paper proves this result using a finite gadget: quota choices at several profiles force Boolean relations that end in a contradiction. It assumes no anonymity, neutrality, order preservation, or homogeneity.

A close continuous analogue is Continuous Four-State Quota-and-Monotonicity Rule Synthesis. There are four types, one for residents of each state. A society is a positive real mass vector \(x\in\mathbb{R}_{>0}^4\), equivalently a total mass \(N=\sum_i x_i\) and a distribution \(\mu_i=x_i/N\). The mass \(x_i\) represents the population of state \(i\); house size \(h\) remains an integer because seats remain indivisible. The question is whether there is one deterministic rule \(F\), defined for every such society and every \(h\), whose allocation \(F(x,h)\in\mathbb{Z}_{\ge0}^4\) sums to \(h\), satisfies quota using \(q_i=h\mu_i\), and has no population paradox under comparisons of real mass vectors: for every \(x,x',h,h'\) and distinct \(i,j\), if \(x_i'\ge x_i\) and \(x_j'\le x_j\), it must not be that \(F_i(x',h')<F_i(x,h)\) and \(F_j(x',h')>F_j(x,h)\). A solution is such a global rule; a negative solution is a proof that no such rule exists.

This is a plausible high-multiplicity setting: residents of a region share the relevant type, and a very large population may have only four types, so \(N\) can be large while \(\tau=4\). The mass scale \(N\) is retained because this version of population monotonicity compares absolute population changes; the quota itself depends only on \(\mu\). The model still apportions indivisible seats. The paper’s integer profiles sit inside the real-mass domain, so Theorem 1’s contradiction carries over. Scaling all its population profiles by the same large factor preserves their quota patterns and comparisons, giving arbitrarily large populations with the same four types.

The expected direction is that the obstruction transfers from those embedded profiles. That is an impossibility transfer, though, not a computational-hardness classification. The continuous question is a global rule-existence problem, rather than a per-instance algorithm for computing an allocation. That is the main weakness of this positive case. The paper has no named result establishing a runtime bound, NP-hardness, parameterized complexity, or an algorithmic formulation. If “computational result” in the anchor requirement is read strictly in that sense, this paper has no qualifying anchor; Theorem 1 is a named axiomatic impossibility theorem. The continuous mirror is therefore real and recognizable, but it does not fit ChoCo’s central computational agenda as well as a complexity result would.

The mirror covers Theorem 1’s cross-house-size incompatibility and, through Corollary 1, its relative-population-monotonicity variant. It does not claim a result about expected fairness under randomization or continuous seat allocations. Natural follow-up questions include whether the obstruction persists when comparisons are restricted to a common house size, and what becomes possible under approximate or ex-ante monotonicity.

The case AGAINST (opponent, writing after the proponent)

The strongest case against a ChoCo mirror is that the paper has no computational result to mirror. Theorem 1 is named, but it is an axiomatic impossibility theorem about whether a global rule exists. It gives no algorithmic problem, complexity classification, or optimization task on an input society. Corollaries 1 and 2 extend that same impossibility; they do not add computational anchors.

The proposed real-mass model is nevertheless coherent. Let \(x\in\mathbb{R}_{>0}^4\) record the masses of residents in four states, retain the integer house size \(h\), and require \(F(x,h)\) to allocate integer seats with quotas \(h x_i/\sum_j x_j\). Comparing the unnormalized masses preserves the paper’s population-monotonicity condition. This is a plausible high-multiplicity regime, and the paper’s theorem applies on its integer inputs. So the negative case should not rest on claiming that apportionment has no natural continuous population model.

The difficulty is what that model asks us to compute. The paper asks whether *any function* on all population vectors and house sizes can satisfy two global axioms. A continuous version asks the same kind of question over a larger domain; it still does not ask for an algorithm that acts on a given society. The proof’s finite gadget is a logical incompatibility argument, not an optimization formulation whose tractability turns on pricing, separation, or another continuous-optimization tool.

One could make a computational problem by supplying a finite set of profiles and asking whether quota-respecting allocations can be assigned to them without a monotonicity violation. That would be a new finite constraint-satisfaction problem: it changes the paper’s universal “one rule works everywhere” question into a question about a supplied sample. Its complexity and relevance would need their own justification. The paper’s fixed four-state impossibility gadget settles its own finite witness; it does not establish an algorithmic landscape for that new problem. Asking about approximate axioms or the same-house-size variant could also be worthwhile apportionment theory, but those remain rule-existence questions unless given additional computational structure.

Thus the continuous mirror is valid as an axiomatic extension, but the case that it belongs in this computational programme is weak. A broader research agenda might value it; under ChoCo’s stated focus on computational questions about continuous societies, it supplies no clear algorithmic problem to pursue.
