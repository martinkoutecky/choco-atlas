The continuous mirror question

Given a finite set of types \(T\), rational masses \(\mu_t\ge 0\) with \(\sum_{t\in T}\mu_t=1\), and a directed compatibility relation on type pairs, let \(Q_3\) be the compatible cycle patterns of lengths two and three. Repeated types in a pattern represent distinct pairs of that type. For each \(q\in Q_3\), choose cycle mass \(x_q\ge 0\); let \(a_t(q)\) count the uses of type \(t\) in \(q\). What is the maximum transplanted mass \(\max \sum_{q\in Q_3}\ell(q)x_q\), subject to \(\sum_{q\in Q_3}a_t(q)x_q\le\mu_t\) for every \(t\in T\)?

The model it lives in

A high-multiplicity kidney-exchange model with types that completely determine compatibility, mass \(\mu_t\) for each type, and decision variables \(x_q\) for feasible length-two and length-three cycle patterns. The objective maximizes the mass of pairs receiving transplants, subject to each type’s mass capacity.

The objection that survived

The paper supplies no evidence that real registries contain many pairs per exact deterministic compatibility class; the proponent names this condition but does not substantiate how often it holds.

fatal: False

The case FOR (proponent)

The strongest mirror is the paper’s unweighted, length-at-most-three clearing problem. Consider a large kidney-exchange registry with many patient–donor pairs but a much smaller set of exchange-relevant classes. A type is a clinical class that completely determines a pair’s compatibility with every other type; for the weighted variant, it also determines the value of each compatible exchange. Mass \(\mu_t\) is the fraction of pairs in class \(t\). This is plausible for a registry whose compatibility rules and exchange values are class-based, with \(N\) pairs and \(\tau\) classes where \(N\) is much larger than \(\tau\).

The continuous decision is how much mass to assign to each feasible cycle of types. Let \(Q_3\) be the cyclic type sequences of length two or three whose consecutive types, including the last and first, are compatible. Repeated types in a sequence represent distinct pairs of that type. For \(q\in Q_3\), let \(x_q\ge 0\) be the mass of cycles of that type sequence, and let \(a_t(q)\) count how many pairs of type \(t\) each such cycle uses. Feasibility requires \(\sum_{q\in Q_3}a_t(q)x_q\le\mu_t\) for every type. This preserves the paper’s cycle-clearing decision and makes the society the continuous object.

The lead anchor is Theorem 6, proved in this paper. It states that MAX-SIZE-3-EXCHANGE is NP-hard to approximate within a factor of \(698/697\). More precisely, for every sufficiently small constant \(\epsilon>0\), GAP-MAX-SIZE-3-EXCHANGE-\([697/700+\epsilon,\,698/700-\epsilon]\) is NP-hard. The paper proves this by reduction from MAXIMUM-3-DIMENSIONAL-MATCHING, using the hardness result cited as Theorem 3.

Its continuous mirror is High-Multiplicity MAX-SIZE-3-EXCHANGE: given the rational masses \(\mu_t\) and the type compatibility relation, choose feasible cycle masses \(x_q\) to maximize the total mass of pairs receiving transplants. Since each cycle of length \(\ell(q)\) transplants that many pairs, the problem is
\[ \max \sum_{q\in Q_3}\ell(q)x_q \quad\text{subject to}\quad \sum_{q\in Q_3}a_t(q)x_q\le\mu_t\ \ \forall t,\qquad x_q\ge0. \]
The vector \(x\) is the solution. There are \(O(\tau^3)\) cycle types, so this rational LP is solvable in time polynomial in \(\tau\) and the input bit length. I expect Class A: tractable. The discrete hardness need not transfer: its reduction uses individually specified vertices and gadgets, while the mirror lets a type’s mass be split across cycle patterns. In a large registry, a fractional allocation can be rounded down to whole cycles with additive loss bounded by the number of cycle types; that loss vanishes per capita as the population grows relative to \(\tau^3\). Further questions include sharper finite-population rounding guarantees and the integrality gap when the registry is not yet large relative to its type support.

A second, related anchor is Theorem 5, also proved in this paper. It states that MAX-WEIGHT-3-EXCHANGE is NP-hard to approximate within a factor of \(434/433\); more precisely, GAP-MAX-WEIGHT-3-EXCHANGE-\([433/434+\epsilon,\,1-\epsilon]\) is NP-hard for every sufficiently small constant \(\epsilon>0\). The proof reduces from bounded-occurrence MAX-3LIN-2(3), using its hardness result cited as Theorem 2.

Its mirror, High-Multiplicity MAX-WEIGHT-3-EXCHANGE, takes the same type masses and compatibility relation, together with a nonnegative rational value \(w(t,t')\) for an exchange from type \(t\) to type \(t'\). The task is to choose feasible cycle masses maximizing their total exchange value:
\[ \max \sum_{q\in Q_3} \left(\sum_{i=1}^{\ell(q)}w(t_i,t_{i+1})\right)x_q \quad\text{subject to}\quad \sum_{q\in Q_3}a_t(q)x_q\le\mu_t\ \ \forall t,\qquad x_q\ge0, \]
where \(q=(t_1,\ldots,t_{\ell(q)})\) and \(t_{\ell(q)+1}=t_1\). Again, the solution is the cycle-mass vector, and the \(O(\tau^3)\)-variable LP makes the mirror tractable. I consider this a sound second anchor, though weaker than Theorem 6 as a motivating case: the weighted mirror additionally requires that exchange values be properties of type pairs.

These mirrors cover Theorems 5 and 6, not the paper’s unrestricted-length weighted result, Theorem 4. Extending the weighted mirror to input cycle bounds would raise a separate question about pricing longer cycles; I would not claim the three-cycle LP settles it. The paper’s greedy approximation result and experiments are outside the proposed scope.

The weakest point is whether kidney-exchange compatibility and value really admit a low-support type description. Crossmatch compatibility and transplant values can be pair-specific; if exact distinctions must go into the type, \(\tau\) may approach \(N\), and the high-multiplicity story loses force. The case rests on a real registry regime with many pairs sharing complete, exchange-relevant compatibility and payoff classes. In that regime, this remains the paper’s problem—clearing kidney exchanges by short, vertex-disjoint cycles—with the indivisible electorate replaced by mass.

The case AGAINST (opponent, writing after the proponent)

The best objection to both anchors is that kidney exchange is relational at its core. A pair’s type must determine not just its own medical attributes, but its compatibility—and, for the weighted problem, exchange value—with every other type. Blood and tissue compatibility make that a demanding exact description; tissue compatibility depends on the relationship between a donor’s antigens and a recipient’s antibodies. [A kidney-exchange model discussing these compatibility factors](https://academic.oup.com/restud/article/92/4/2108/7762213)

For Theorem 6, the proponent’s finite-class mirror is mathematically sound: with deterministic compatibility between types, the length-three clearing problem is a fractional cycle-packing LP with \(O(\tau^3)\) variables. The objection is whether those classes describe a useful real regime. If type means an exact compatibility signature, many pairs may have distinct types, leaving little compression. Coarser clinical classes avoid that, but can make the LP allocate mass to cycles that do not correspond to compatible pairs in the actual pool. The theorem’s reduction uses precisely specified graph connections, so it does not establish that its hard instances contain large populations of interchangeable pairs.

A probabilistic compatibility kernel is the natural stronger proposal: group pairs by clinical traits and model compatibility between groups probabilistically. But an expected edge is not a feasible transplant. The model must still ensure that actual compatible, vertex-disjoint cycles exist; simply optimizing over expected compatibility can promise exchanges that cannot be performed. A stochastic matching model might address that, but it would be a new question about random compatibility and expected yield, rather than a continuous mirror of this paper’s exact cycle-packing problem.

Theorem 5 has the same obstacle, with the extra burden of preserving edge values. If value varies by the particular exchange, exact types must capture that too, further enlarging the type space. Averaging values can assign a profitable weight to a cycle that is infeasible or has different value for the pairs actually involved. If compatibility and value are genuinely constant within type pairs, the weighted problem again becomes a small LP—but then it inherits the same question about whether those exchange classes are a credible population model.

The two anchors therefore rise or fall together: under a credible deterministic block model, both have tractable continuous mirrors. Existing work on kidney-exchange algorithms parameterized by vertex types is evidence that typed regimes are worth studying, not a collision with the continuous treatment. [Xiao and Wang, “Exact Algorithms and Complexity of Kidney Exchange”](https://www.ijcai.org/Proceedings/2018/77) That evidence weakens the negative case; it does not settle whether the exact mass LP is already a worthwhile contribution.

So the strongest case against is that the mirrors’ tractability depends on a block-compatibility assumption that may be too coarse for exact kidney exchange, while exact types may leave support nearly as large as the pool. But I cannot honestly make the universal claim the assignment demands. If a substantial registry has many pairs per exchange-relevant class, Theorem 6 survives as a clean and faithful population limit, and Theorem 5 follows alongside it. The negative case is weakest exactly where a useful continuization needs to be tested: whether that regime is plausible.
