What the mirror covers

The proposed mirror covers Theorem 2’s unweighted connectivity game on a fixed periodic, low-treewidth graph family; it leaves the weighted game, arbitrary networks, and the experimental results aside.

Open questions for a prover

  • Do the scaled role Shapley values converge for every connected role graph \(H\), and can convergence or its failure be characterized?
  • Can the limit be computed to additive error \(\varepsilon\) without enumerating increasingly large finite graphs?

The case FOR (proponent)

My strongest honest case is narrow: a high multiplicity limit for connectivity centrality in a network built from repeated roles.

The anchor is Theorem 2, proved in this paper. It says that, given a graph \(G\) of treewidth at most \(\mathrm{tw}\), the Shapley values of all vertices can be computed in time \(2^{\Theta(\mathrm{tw}\log \mathrm{tw})}n^4\log n\) and space \(2^{\Theta(\mathrm{tw}\log \mathrm{tw})}n^3\). In context, the algorithm computes values for both the unweighted connectivity game and the vertex-weighted connectivity game. I use only the unweighted result below. The paper’s #P-hardness claim is attributed to Michalak et al.; it is not a numbered result proved here, so it is not a second anchor.

Lead: Periodic Connectivity Shapley Limit. Let \(H=(T,F)\) be a finite connected graph of roles, with \(\tau=|T|\). For each \(q\ge 3\), form \(G_q\) from \(q\) copies of \(H\) arranged in a cycle: retain the edges of \(H\) within each copy, and connect each role in one copy to the same role in the next copy. The agents are the vertices \((t,j)\), where \(t\in T\) and \(j\in\mathbb Z/q\mathbb Z\). Each role \(t\) is a type; the cyclic symmetry makes its \(q\) agents interchangeable for the game. Its population mass is \(\mu_t=1/\tau\).

On \(G_q\), use exactly the paper’s game \(v_{\mathrm{conn}}\): a coalition is worth \(1\) if it contains more than one agent and induces a connected subgraph, and \(0\) otherwise. Let \(\phi^{(q)}_{t,j}\) be the Shapley value of agent \((t,j)\). Rotational symmetry makes this value independent of \(j\). The continuous question is: given \(H\) and an error tolerance \(\varepsilon>0\), compute the type-allocation vector
\[ \alpha_t=\lim_{q\to\infty}q\,\phi^{(q)}_{t,0} \]
to additive error \(\varepsilon\), on instances where these limits exist. Here \(q\phi^{(q)}_{t,0}\) is the total Shapley credit received by type \(t\). A complete theory should establish whether the limits exist for every connected \(H\); if not, it should characterize the promised instances on which PCSL is defined.

There is no intervention variable in the paper’s problem: its computational task is to evaluate a fair allocation. PCSL keeps that task. Its solution is the limiting allocation by type, where credit means expected marginal contribution over random arrival orders. When the limits exist, Shapley efficiency gives \(\sum_{t\in T}\alpha_t=1\).

The regime is a repeated organization or service network with a fixed set of roles in each recurring unit and the same role interactions between neighboring units—for example, a large rotating operation with a stable liaison structure. With \(N=q\tau\) agents and \(\tau\) fixed, \(N\) grows while the number of types stays fixed. Members of a type are genuinely interchangeable under graph automorphisms, not merely assigned the same label. The interaction graph \(G_q\) also has treewidth bounded by a function of \(\tau\), uniformly in \(q\). Thus Theorem 2 computes every finite-\(q\) instance in polynomial time for fixed \(\tau\), with a treewidth-dependent factor.

I expect PCSL to be Class A for fixed \(\tau\), and plausibly fixed-parameter tractable in \(\tau\): the paper already gives exact values for every finite approximation, while the repeated structure suggests a transfer-matrix method for extracting the limit. That expectation is not proved by Theorem 2; deriving an error bound and computing the limit without enumerating ever larger populations is the research question. It also raises whether the limits have exact rational or algebraic representations and whether an analogous limit is useful for the vertex-weighted game.

The mirror is plausible because every finite approximant uses the paper’s exact graph, connectivity condition, and Shapley value. The population becomes continuous through repeated, interchangeable role classes; the question is the aggregate allocation as their multiplicities grow. This case covers only Theorem 2’s unweighted connectivity game in a periodic, low-treewidth regime. It does not claim a mirror for arbitrary networks or for the paper’s weighted variant.

The weak point is that the cyclic repeated-role scenario is constructed, and PCSL defines continuity through a limit of finite Shapley games rather than relying on a canonical Shapley value for an atomless society. Connectivity can be sensitive to a few agents, so convergence itself may fail. That is a real limit of the case, but the finite games remain exactly the authors’ problem and the limiting regime has fixed role masses with growing population.

The case AGAINST (opponent, writing after the proponent)

Theorem 2 is a real computational anchor: it gives an algorithm for computing every vertex’s Shapley value on a specified bounded-treewidth graph. The strongest objection is that the result depends on the graph’s incidence structure, not just on a population distribution over types. In the proposed cycle family, every \(q\) has the same role masses \(\mu_t=1/\tau\), but the links between copies determine which coalitions are connected. Those masses alone cannot define the game or its Shapley values.

Adding a location coordinate to each role can encode the links, but it exposes the deeper problem. In an ordinary atomless model, a single individual has measure zero, while connectivity can change when that individual is added. Connectivity is not well-defined on populations identified up to measure-zero differences. And for this bounded-degree family, the usual dense graphon limit loses the links that drive the game. Preserving them requires a sparse graph limit or an explicit sequence of finite graphs, plus an ordering process that reproduces finite Shapley values.

That repair is coherent, but it makes the proposed \(\alpha_t\) a thermodynamic limit of finite network centralities, rather than an allocation determined by a continuous society of type masses. It may be worthwhile research in asymptotic network analysis. My negative case is that this is a different and substantially richer object than the paper’s population-continuization mirror: the population distribution does not carry the essential structure, and the continuous Shapley rule is not canonical.

This objection does not defeat the proponent’s carefully specified graph family. Their limit could be a legitimate new computational question if its ordering semantics and convergence are established. So the case against is strongest against a general type-mass mirror, and weak against that explicit sparse-limit proposal; I cannot honestly claim the universal negative is airtight.
