The continuous mirror question

Given a finite set of cohort types \(T\), positive rational masses \(\mu_t\) summing to \(1\), and an explicit finite common prior over binary \(W\) and the cohort signals \((X_t)_{t\in T}\), run the Standard Consensus Protocol with one representative announcement per positive-mass type in each round. Find the least round \(r\) for which \(\max_{t:\mu_t>0} I(X_t;W\mid H_r)\le\epsilon\), and return the horizon and transcript.

The model it lives in

A finite-support society with type distribution \(\mu\), where each type is a cohort sharing the same signal behavior and announcement rule. Each type announces its Bayesian posterior once per round; consensus is reached when every positive-mass type has residual information at most \(\epsilon\).

The case FOR (proponent)

The strongest case I can make is narrow: the paper’s consensus process has a plausible high multiplicity form, but the paper does not give a named complexity classification such as membership in P or NP-hardness. Its closest usable anchor is an explicit bound on the number of communication rounds.

Theorem 3.7, proved here as a reproof of Aaronson [1], says that the Standard Consensus Protocol reaches \(\epsilon\)-MI consensus within \(2/\epsilon\) rounds. For binary events, the \(\epsilon\)-Discretized Consensus Protocol reaches it within
\[ \frac{512}{\epsilon^3\log\!\left(1/E^{-1}(\epsilon/4)\right)} \]
rounds, where \(E^{-1}(z)\le 0.5\) solves \(x\log x+(1-x)\log(1-x)=-z\). This is a convergence-rate result, not a bit-complexity theorem; I would use the Standard Protocol clause as the lead.

A concrete mirror is the Mass-Weighted Cohort Consensus Horizon problem. An instance gives a finite set of cohorts \(T\), rational masses \(\mu_t>0\) summing to \(1\), and an explicit finite rational common prior over \(W\) and the cohort signals \((X_t)_{t\in T}\). Cohort \(t\) consists of many people who share the same private information \(X_t\); the number of people is large compared with \(\tau=|T|\). In a fixed order, each cohort announces its current posterior once per round, either as a full posterior or, for binary \(W\), using the paper’s discretized protocol. The public history \(H_r\) records those cohort announcements. The question is to find the least round \(r\) at which
\[ \sum_{t\in T}\mu_t I(X_t;W\mid H_r)\le\epsilon, \]
and return that horizon and the corresponding transcript. The information quantities are averaged over histories, as in the paper.

This is a plausible regime where mass is the useful description: for example, a large panel whose members fall into a small number of cohorts receiving the same report from a shared source. The type is the cohort’s complete information state for this process; mass is its share of the panel. Treating a cohort as one mass-valued speaker is the necessary co-modification. Theorem 3.7 bounds each cohort’s residual information, so it implies the stated mass-weighted threshold as well. The authors could reasonably recognize this as their consensus question applied to a society represented by cohorts.

For an explicit prior with \(K\) support atoms, one can simulate each atom’s transcript and group identical histories. The round bound then gives a finite algorithm with work polynomial in \(K\) and \(\tau\) per simulated round. The natural expectation is tractability in the explicit-support input and \(1/\epsilon\); that is not a claim of polynomial time in the binary encoding of \(\epsilon\). Exact threshold comparisons also need care because mutual information contains logarithms; a version with a promised gap from \(\epsilon\) gives a clean approximation problem.

The scope here is only Theorem 3.7’s convergence rate. I would not stretch the case to Theorem 3.8’s no-false-consensus bound: its \(n\epsilon\) scaling does not yield a useful continuum bound just by replacing agent counts with mass. Nor would I use Proposition 4.5 as an anchor: its prediction-market equilibrium result is a natural subject for a population extension, but the paper does not analyze that extension computationally.

The soft spot is substantial: the mirror is a round-complexity question about information aggregation, not a conventional ComSoC algorithmic problem, and Theorem 3.7 does not bound the computational cost of processing an input. If “computational result” strictly requires a named complexity classification, then this paper has no qualifying anchor. The positive case rests on treating a proved convergence-rate theorem as the nearest algorithmic result and asking for its mass-based cohort analogue.

The case AGAINST (opponent, writing after the proponent)

Theorem 3.7 is the only strong anchor here, but it bounds communication rounds, not the time needed to compute a solution from an instance. Its standard-protocol bound, \(2/\epsilon\), holds for every finite number of agents. The proposed cohort model therefore gives a mass-weighted way to measure the paper’s existing convergence notion; it does not yet pose a computational question about the population.

The closest faithful continuum version would preserve the paper’s requirement that every agent have residual information at most \(\epsilon\). For a mass distribution, that becomes an essential-supremum condition over types. If everyone in a cohort shares the same private signal, one representative can make the cohort’s announcement: later copies have the same posterior, and their mass does not change the transcript. The number of distinct signal sources, \(\tau\), still determines how many announcements must be processed. Mass adds no new computational structure.

The proposed weighted average does make mass affect the stopping condition, but it changes what counts as consensus. A cohort with mass \(\delta\) and one bit of residual information contributes only \(\delta\) to the average, so the criterion can declare consensus while every member of that cohort retains the full bit. The paper’s XOR example is a sharper warning: each agent has zero individual mutual information with the outcome at the start, while their joint signals determine it. A weighted average can therefore report success without information having been aggregated. That may be a useful per-capita welfare measure, but it is a new objective rather than a population version of aggregation.

Making the signal observations independent across cohort members does not fix the mismatch. Then the realized distribution of private signals is itself evidence. If that distribution is supplied as the public society input, it can reveal the outcome—for example, when different outcomes induce different signal distributions in an atomless population. If it remains private, the model needs a prior over random population measures and a rule for how a continuum of agents speaks. Either choice adds a new information structure or communication protocol; neither follows from Theorem 3.7.

So the negative case is that every close mirror leaves population mass irrelevant to the protocol, while versions where mass matters alter the paper’s target or its information model. The case is not airtight: a per-capita disclosure objective with an explicit batch protocol could be a worthwhile mean-field information-aggregation problem. But that would be a new model for this programme to assess, rather than a computational mirror of the result this paper proves.
