The continuous mirror question

Given finite valuation types \(T\) with positive rational masses \(\mu_t\) summing to \(1\), additive values \(v_t(g)\), and indivisible-good lots \(g\) with rational supplies \(q_g\), each lot must be assigned to one type and is compatible with \(t\) only if \(t\in S_g=\{s:v_s(g)>0\}\) and \(q_g=\mu_t\), so each person of that type receives one copy. Let \(M_t=\max_g v_t(g)\), \(T_t=\{g:v_t(g)=M_t>0\}\), and form \(C_2\) by joining lots whose positive supports overlap in at least two types. Decide whether there is an injective anchor choice \(h(t)\in T_t\) with \(q_{h(t)}=\mu_t\) such that, after precoloring each anchor by its type, every nonempty residual lot set \(Y\) contains a lot \(g\) with \(d_{C_2[Y]}(g)<|L_h(g)|\), where \(L_h(g)=\{t\in S_g:q_g=\mu_t\}\setminus\{t:gh(t)\in E(C_2)\}\); if so, produce a compatible list coloring and the resulting EFX0 allocation of common integral bundles to each type.

The model it lives in

A population of valuation types \(T\) with rational masses \(\mu_t\), where everyone in a type receives the same integral bundle. Each lot has aggregate supply \(q_g\) and can go to type \(t\) only when \(q_g=\mu_t\); the computational task is recognition and construction of the paper's maximum-anchor A-LD certificate on the resulting type conflict graph.

The objection that survived

Requiring each lot's supply to equal a type's mass and giving every person of a type the same bundle makes this a narrow batch-allocation regime, whose plausibility rests on the proponent's standardized-program example.

fatal: False

What the mirror covers

The mirror covers Theorem 6.2's maximum-anchor recognition and search bounds and Theorem 5.4's supplied-anchor construction; it leaves general EFX0 existence and the exact RI-completion results outside its scope.

Open questions for a prover

  • Can the discrete-to-continuous correspondence be formalized for integer population scales that realize the rational masses and lot supplies?
  • Can the certificate mirror be broadened to supplies that do not equal a type's mass while retaining shared integral bundles and the same EFX0 guarantee?

The case FOR (proponent)

The strongest case is a narrow, high-multiplicity version of the paper’s maximum-anchor certificate. Imagine a large allocation program serving many people who fall into a small number \(\tau\) of complete additive-valuation types. People of type \(t\) have mass \(\mu_t\), with \(\sum_t\mu_t=1\). The program has finitely many lots of goods; each lot \(g\) contains \(q_g\) copies per person in the population. In this regime, each lot is sized for one cohort: assigning \(g\) to type \(t\) means \(q_g=\mu_t\), so every person in that cohort receives one indivisible copy. Everyone in a cohort receives the same integral bundle, while the cohort’s mass determines how many copies its bundle consumes.

This is a real population limit when the number of people grows but \(\tau\) and the number of lots stay moderate. It preserves EFX0’s individual comparisons: a person still compares her integral bundle with another person’s bundle, including when the removed good is worth zero to her. The common bundle within a type makes a type a legitimate ownership color: the paper’s one-good-per-observer–owner condition then applies to every pair of people in those two cohorts. The cohort-sized lot supply is a co-modification of the allocation model, not a change to the fairness criterion.

Lead anchor: Theorem 6.2, proved in this paper. Let \(a=|N^+|\) be the number of active agents and \(p=\sum_{i\in N^+}(|T_i|-1)\) the total maximum-tie surplus. The theorem says maximum-anchor A-LD recognition and search take \(O(m^a\operatorname{poly}(|I|))\) and \(O(2^p\operatorname{poly}(|I|))\) time, respectively. Thus the problem is polynomial for every fixed number of agents, XP in \(a\), and FPT in \(p\). It leaves the general recognition problem unresolved. This is a positive algorithmic result, not a hardness result.

Here is the continuous problem I would ask on its strength.

High-Multiplicity Anchor Recognition. An instance gives a finite set \(T\) of active valuation types with rational masses \(\mu_t>0\), a finite set \(G\) of positive-support good lots, per-capita lot sizes \(q_g\), and additive values \(v_t(g)\). The full valuation vector defines each type. Let \(S_g=\{t:v_t(g)>0\}\), \(M_t=\max_g v_t(g)\), and \(T_t=\{g:v_t(g)=M_t\}\). Form the conflict graph on lots, joining \(g,h\) when \(|S_g\cap S_h|\ge2\). A lot can be assigned to type \(t\) only if \(t\in S_g\) and \(q_g=\mu_t\), so its feasible colors are \(A_g=\{t\in S_g:q_g=\mu_t\}\).

Ask whether there is an injective choice of anchors \(h(t)\in T_t\) with \(q_{h(t)}=\mu_t\), such that, after precoloring each anchor \(h(t)\) by \(t\), the remaining lots are list-degenerate using the residual lists
\[ L_h(g)=A_g\setminus\{t:gh(t)\in E(C_2)\}. \]
Here “list-degenerate” means that every nonempty residual subset \(Y\) contains a lot \(g\) with \(d_{C_2[Y]}(g)<|L_h(g)|\). A solution is the anchors, a proper coloring \(o(g)\) from the feasible lists, and the resulting integral bundle \(B_t=\{g:o(g)=t\}\) for each cohort. The lot-size constraint ensures all copies are allocated exactly.

Adapting Theorem 6.2’s search gives an expected \(O(K^\tau\operatorname{poly}(|I|))\) search and \(O(2^p\operatorname{poly}(|I|))\) search, where \(K=|G|\) and \(p=\sum_t(|T_t|-1)\). Lot compatibility adds polynomial checks; for fixed anchors, residual degeneracy is checked by peeling. I expect this problem to be FPT in maximum-tie surplus \(p\). The masses matter through the supply constraints, and the parameter counts distinct types’ maximum choices rather than the number of people.

Supporting anchor: Theorem 5.4, proved in this paper. Given a specified injective maximum-anchor map satisfying A-LD, the theorem constructs a complete allocation that is RI and has maximum-singleton dominance, hence is EFX0; verification and construction take \(O(nm^2)\) time. Its continuous counterpart is the same cohort allocation question *with the anchors supplied*: does the anchor-residual list test pass, and if so, what cohort bundles result? It should be polynomial in \(\tau\), \(K\), and the input bit length. The anchor goods give each active type its maximum-valued singleton. RI leaves at most one positively valued good in any other cohort’s bundle; therefore, even if a zero-valued good is removed, the remaining visible value is bounded by that type’s maximum singleton.

The paper’s authors should recognize these as mirrors of their certificate construction and its recognition problem: the population is represented by rational mass over full types, but the allocation and every EFX0 comparison remain integral at the person level. The scope is deliberately limited to allocations furnished by the maximum-anchor A-LD certificate, not general EFX0 existence.

The weakest point is the cohort-sized-lot and type-homogeneous allocation regime. It is plausible for standardized programs assigning packages to recurring cohorts, but it is narrower than ordinary fair division and can make the inventory pattern look engineered. Also, the paper establishes tractability of certificate recognition, not a discrete hardness result that dissolves in the continuum. This is a credible positive mirror for one algorithmic slice of the paper, not a claim that continuization solves additive EFX0 generally.

The case AGAINST (opponent, writing after the proponent)

The paper does have computational results to mirror: Theorem 6.2 studies recognition and search for maximum-anchor certificates, and Theorem 5.4 gives a construction when anchors are supplied. My concern is that the proposed continuum either preserves those results by collapsing to the same finite certificate problem, or becomes a different problem whose fairness constraints no longer have the paper’s form.

In the proposed cohort model, every member of a valuation type receives the same integral bundle, and a lot can serve a type only when its supply matches that type’s mass. Under those restrictions, the conflict graph, maximum-good sets, anchor choices, and A-LD peeling are just the paper’s objects on \(\tau\) representative agents. The masses enforce lot compatibility, but do not change the fairness test or the recognition algorithm. So Theorem 6.2 becomes the same search with \(n\) replaced by \(\tau\), and Theorem 5.4 the same fixed-anchor construction with the same substitution. This is coherent for a standardized program that assigns whole cohorts identical packages, but the exact cohort-sized lots make it a narrow batch-allocation variant. The population scale itself supplies little new computational structure.

A more general mirror would let each valuation type receive a distribution of integral bundles. Write \(x_{t,B}\) for the mass of type \(t\) receiving bundle \(B\). Supply constraints can then be linear in the \(x_{t,B}\), while EFX0 requires that every bundle in one type’s positive-mass support satisfy the all-good inequalities against every bundle in every other type’s support. That retains individual-level comparisons without forcing each cohort to share a bundle. But the constraints depend on whether \(x_{t,B}\) is zero, not on how large it is: an arbitrarily small positive-mass class imposes the same EFX comparisons as a large one. Capturing the allocation therefore requires tracking bundle supports, potentially up to \(2^m\) bundles per valuation type. The masses do not smooth the fairness condition, and the anchor and RI arguments do not directly address this support-selection problem.

That same fork defeats both anchors. For Theorem 6.2, homogeneous bundles give a finite quotient and essentially the original recognition task; allowing heterogeneous bundles makes a type-level anchor insufficient to certify every person’s allocation. For Theorem 5.4, the supplied anchor works for a cohort only if every member gets its copy and the cohort’s bundle is shared. If copies can be split among different bundle classes, the paper’s one-visible-good argument must be reformulated over those classes.

This is a case against the breadth of the proposed mirror, not a proof that no useful scenario exists. A cohort package-allocation model is plausible, and an author could reasonably want to study its certificate problem. I cannot honestly rule out that narrow application. The strongest negative case is that the natural broad version preserves the pointwise, support-sensitive difficulty of EFX0, while the tractable version offered here obtains its match to the paper by imposing a cohort-homogeneous allocation regime that reduces the algorithm to the finite certificate on valuation types.
