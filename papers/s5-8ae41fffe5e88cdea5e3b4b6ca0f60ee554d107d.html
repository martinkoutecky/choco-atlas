The continuous mirror question

Given ℓ≥3, m, a finite supported type set T, binary affinities q:T×T→{0,1}, and rational masses μ, decide whether real assignments x_{t,v}≥0 exist for the vertices v of the ℓ×m grid, with ∑_v x_{t,v}=μ_t and ∑_t x_{t,v}=1/(ℓm), such that whenever x_{t,v}>0, U_t(v;x)≥U_t(z;x) for every grid vertex z, where U_t(v;x)=∑_{u∈N(v)}∑_{s∈T} ℓm x_{s,u}q(t,s).

The model it lives in

Each grid vertex is a fixed-capacity seating pod of mass 1/(ℓm). The society is a rational distribution μ over complete affinity types, and x_{t,v} is the mass of type t in pod v. A type's utility is its average affinity to occupants of adjacent pods; the question is whether a mass assignment exists in which no represented type prefers another pod.

What the mirror covers

The mirror covers envy-free existence on grids of width ℓ≥3 with binary type affinities, as in Theorem 2. It leaves the ℓ=2 envy-free case in Theorem 1 and the exchange-stability results in Theorems 3–5 unmirrored.

Open questions for a prover

  • What is the complexity of the stated feasibility problem in ℓ, m, the support size τ, and the input bit length?
  • Does fixing grid width ℓ and type support size τ yield a polynomial-time algorithm?

The case FOR (proponent)

The strongest mirror is a cohort-level grid seating problem. It keeps the paper’s local seat graph, social preferences, envy, and reciprocal blocking, while making the population continuous.

Take \(G=P_\ell\square P_m\), with \(N=\ell m\) grid locations, and a finite set \(T\) of complete agent types. A type \(t\) specifies its affinity \(q(t,s)\) toward every type \(s\); members of a type are identical in every respect the model uses. The society is a rational distribution \(\mu\) over the \(\tau\) supported types, with \(\sum_t\mu_t=1\). Here \(\tau\) is the number of distinct types, not the number of possible preference profiles.

Interpret each grid location as a cohort-sized seating pod. Let \(x_{t,v}\) be the fraction of the society consisting of type \(t\) assigned to location \(v\). Require
\[ \sum_v x_{t,v}=\mu_t,\qquad \sum_t x_{t,v}=\frac1N. \]
Thus each pod has equal population mass, and its type mix is \(N x_{t,v}\). Define the normalized utility of type \(t\) at \(v\) by
\[ U_t(v;x)=\sum_{w\in N_G(v)}\sum_{s\in T}N x_{s,w}q(t,s). \]
This is the original additive neighborhood utility averaged over the occupants of each adjacent pod. The decision variable is the mass assignment \(x\); the objective is feasibility, as in the paper’s existence questions.

Lead mirror — Continuous Envy-Free Arrangement on Grids. Given \(\ell\ge3\), \(m\), the supported types, binary affinities \(q:T\times T\to\{0,1\}\), and rational masses \(\mu\), ask whether such an \(x\) exists with
\[ x_{t,v}>0\ \Longrightarrow\ U_t(v;x)\ge U_t(w;x) \quad\text{for every }w\in V. \]
In this nonatomic model, swapping two infinitesimal agents leaves the aggregate assignment unchanged, so this inequality is precisely the type’s comparison between its current location and another occupied location. Every grid location is occupied by the capacity constraint.

The anchor is Theorem 2, proved in this paper: deciding whether an envy-free arrangement exists on an \(\ell\times m\) grid is NP-complete for every \(\ell\ge3\), even with binary preferences. The paper proves this result by reduction from \(DHP^*\); Proposition 1 establishes \(DHP^*\)’s NP-completeness in the paper. The result makes the continuous question compelling: does the hardness survive when many students share a small number of preference types and assignments can split mass across pods? I would first look for tractability when \(\ell\) and \(\tau\) are fixed, using the grid’s bounded width and an LP-based treatment of type mixtures. Whether there is an efficient algorithm when those parameters vary is open.

Second mirror — Continuous Exchange-Stable Arrangement on Grids. Use the same instance and constraints, but allow rational affinities \(q:T\times T\to\mathbb{Q}\). Ask for an \(x\) such that, for every pair of distinct locations \(v,w\) and types \(t,s\) with \(x_{t,v}>0\) and \(x_{s,w}>0\), it is *not* the case that
\[ U_t(w;x)>U_t(v;x) \quad\text{and}\quad U_s(v;x)>U_s(w;x). \]
The anchor is Theorem 5, also proved here: deciding whether an exchange-stable arrangement exists on an \(\ell\times m\) grid is NP-complete for every \(\ell\ge4\). Its preference profile is not restricted to binary preferences. For this mirror my first guess is continuum-specific hardness when \(\tau\) varies: the no-blocking condition has support-dependent choices between two weak improvement inequalities. That is a conjecture about the continuous problem, not a hardness result supplied by Theorem 5. Fixed-width, fixed-\(\tau\) tractability is a natural further question.

The regime I find plausible is a large school or assembly organized into many grid-arranged pods, with many more people than preference cohorts. Cohorts might share affinities based on program, year, or project group. For example, “\(23\%\) of the students are type \(t\)” is a natural population description when the school is large and the number of relevant peer-affinity profiles is modest. This is an instance regime, not a claim that all classroom seating is high-multiplicity. The type definition must include the full affinity profile: if students have genuinely idiosyncratic preferences toward named individuals, they belong to different types.

The main weakness is that the paper’s reductions do not establish hardness for these mirrors. Their gadgets use indexed agents with preferences tied to particular other agents, so the number of distinct types can grow with the number of agents. And cohort averaging changes a key feature of the original model: an agent’s utility there depends on the particular occupants of a few neighboring seats. The authors might reject the pod interpretation if they require literal one-person seats and individual neighbor identities. I still think it is a serious mirror because it retains the grid, local social interaction, and the two stability concepts while making the population itself the mass-valued object. It asks a computational question about those authors’ arrangement problems; it does not mistake fractional outcomes alone for continuization.

The case AGAINST (opponent, writing after the proponent)

The strongest objection is that the paper’s primitive is a bijection between named people and individual seats. An agent’s utility depends on which particular people occupy neighboring seats, and envy is tested by actually swapping two people. In the proposed pod model, each grid vertex instead holds a divisible population, utility depends on the *mix* in neighboring pods, and exchanging two infinitesimal agents leaves that mix unchanged. Envy becomes a comparison between locations; exchange-stability becomes a comparison between type-location pairs. These are coherent questions, but they describe an anonymous spatial placement model rather than the paper’s literal seat arrangement problem.

That gap is especially visible in both anchors. The envy-free hardness reduction gives agents indexed preferences, and each \(z_i\)’s preferences encode which \(x_p\) correspond to outgoing edges of a particular source-graph vertex. The exchange-stable reduction uses the same kind of encoding. A fixed set of types with affinities \(q(t,s)\) cannot preserve those instance-specific preference rows. This is a reason the theorems do not establish hardness for the proposed mirrors; it is not, by itself, a reason the mirrors are unworthy. The programme explicitly allows the continuous answer to differ.

The objection also weakens against a better version of the mirror. One could describe large seating areas as grid-arranged pods, each with a per-capita capacity, where a person’s utility is the average affinity toward people in adjacent pods. Both envy-freeness and reciprocal exchange stability then have clear type-level definitions. That changes the unit of seating, but the programme allows per-capita supply and type-level averages when population continuity requires them. Nor is the type abstraction foreign to the authors’ problem: the paper itself cites work that groups agents by common preferences and gives polynomial algorithms for envy-free and stable arrangements on paths and cycles when the number of classes is constant. That is evidence for the regime’s relevance, not an existing continuous answer. [Berriaud et al.](https://tzin.bgu.ac.il/~omerlev/comsoc/papers/paper64.pdf)

So I can make a substantial case against treating Theorems 2 and 5 as direct support for the proposed mirrors: the reductions depend on individualized preferences, while the pod model changes how locations, utilities, and swaps work. But I cannot honestly turn that into a case that *no* worthwhile mirror exists. A large school or campus with cohort-sized seating pods is plausible, and the resulting computational questions do not obviously collapse or become vacuous. The no-mirror case is weak precisely where the burden is hardest: it depends on whether the authors recognize that pod-level model as their problem.
