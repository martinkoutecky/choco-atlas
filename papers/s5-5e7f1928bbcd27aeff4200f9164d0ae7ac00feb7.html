The case FOR (proponent)

I find no eligible computational anchor in this paper. Theorem 1, proved here, says that for sufficiently large even \(n\), under independent uniformly random preferences on \(K_n\), the probability that any stable matching exists is at most \(n^{-1/17}\). That is a probabilistic existence bound, not a result about the complexity of a problem or an algorithm for it. The numbered lemmas are also probability estimates, not computational classifications. The paper mentions Irving’s polynomial-time decision algorithm as prior work, but does not state it as a numbered result of this paper.

So I can’t responsibly give a continuous problem “per anchor.” A continuum model of stable roommates might be a worthwhile separate question, but translating this paper’s independently random rankings over named individuals into finitely many homogeneous types—and perhaps replacing perfect pairings with mass assignments—would change the model without mirroring an eligible result. The positive case therefore fails at the required anchor gate.

The case AGAINST (opponent, writing after the proponent)

The proponent identifies the strongest point: there is no eligible computational anchor in the paper. Theorem 1 bounds the probability that a stable matching exists in a random finite instance. The lemmas estimate probabilities under that random model; none gives a complexity classification or algorithmic result. Irving’s polynomial time algorithm appears only as prior work. A continuous algorithmic question about roommates may be interesting, but this paper does not establish the computational result it would mirror.

The most plausible alternative is a finite set of complete preference types over other types, with rational masses, and a question about stable mass pairings. That is a coherent model, but it changes the central object. In the paper, each person ranks the other named people, and stability depends on those identity-specific comparisons. If a type records those full rankings, the random instance has no useful repeated types. If types rank categories instead, the model discards distinctions among potential partners and changes the stability events. Taking a continuum of named partners offers no canonical version of the paper’s uniform random rankings; specifying one would add assumptions that drive a different probabilistic question.

That leaves a real weakness in the universal claim: a type-level stable allocation problem could be worth studying on its own. But it would be a new computational question, not a continuous mirror anchored in this paper’s results. On the supplied paper, the negative case is strongest at the anchor gate, and weaker if extended to every conceivable continuous roommates model.
