The case FOR (proponent)

There is no qualifying computational anchor in this paper. Its main results concern a game-theoretic property, not the complexity or algorithms of a computational problem.

Proposition 7, proved here, gives a nine-player game whose nucleolus \(x\) is the starting bargaining-set solution. When only the grand coalition’s worth is increased by \(1\), every bargaining-set solution \(y\) in the new game has \(y_i < x_i\) for at least one player. Corollary 8 uses this example to conclude that the bargaining set, kernel, and nucleolus are nonmonotonic. The case AGAINST (opponent, writing after the proponent)

The case labeled “for” raises no continuous anchor, so there is nothing to defeat point by point. Its central observation is right: this paper gives no named computational result to mirror. Proposition 7 constructs a nine-player counterexample; Corollary 8 draws the nonmonotonicity conclusion for three solution concepts. Theorem 3 characterizes the nucleolus. None asks for an algorithm or establishes a complexity bound. The paper gives no computational problem, input encoding, or runtime claim.

The strongest replacement would be a high-multiplicity cooperative-game model: represent players by finitely many types, let coalition worth depend on the mass of each type, and ask whether the nucleolus, kernel, or bargaining set is monotonic when grand-coalition worth increases. One could also ask for algorithms to compute those solutions. Such a project might be worthwhile, but its computational questions would be newly supplied; they are not continuizations of a computational result in this paper.

There is a deeper modeling gap as well. The paper allows an arbitrary characteristic function on named coalitions, and Proposition 7 relies on exact coalition and player relations in its nine-player construction. A type-mass model needs additional structure on coalition worths. It also needs a replacement for the solution concepts’ finite-player machinery: the nucleolus lexicographically orders the excesses of finitely many coalitions, while in a continuum there are uncountably many; bargaining-set objections and kernel comparisons refer to particular players. Defining positive-mass deviations or taking limits of replicated finite games could repair these issues, but those choices define a new model and solution question.

So the strongest defensible negative verdict is about fit: this paper provides no anchor for ChoCo’s computational-continuization programme. It does not prove that no worthwhile continuum cooperative-game project could grow from it; that broader claim would be too strong. Such a project would need to be presented as a new computational direction, not as a mirror of Megiddo’s result.
