The continuous mirror question

Given finitely many creditor types \(T\), rational type masses \(\mu_t\), per-capita bounds \(\ell_t,u_t\), and total worth per capita \(V\), with the type-constant core promised to be \(C_\mu=\{x:\ell_t\le x_t\le u_t,\ \sum_{t\in T}\mu_t x_t=V\}\), compute its egalitarian-core allocation.

The model it lives in

A large creditor population with interchangeable creditors grouped by claim amount and legal priority. Type \(t\) has mass \(\mu_t\) and common per-capita allocation \(x_t\); the core is the weighted box slice \(C_\mu\). The allocation is \(x_t=\min\{\max\{\ell_t,\lambda\},u_t\}\), where \(\lambda\) satisfies \(\sum_t\mu_t x_t=V\).

What the mirror covers

Covers Theorem 5’s single-valuedness result and allocation formula; it leaves Theorems 1–4 and 6, including the reduced-game and axiomatic characterizations, alone.

Open questions for a prover

The case FOR (proponent)

Strictly, this paper has no named computational-complexity result: none of Theorems 1–6 classifies a problem as polynomial-time solvable, hard, or parameterized. It is an axiomatic analysis of cooperative-game solutions. The closest honest anchor is Theorem 5, proved in this paper. It says that for every two-bound core game, the egalitarian core is single-valued and gives its allocation explicitly: if \(C(v)=[l^*(v),u^*(v)]\cap X(v)\), then
\[ \operatorname{EC}_i(v)= \begin{cases} l_i^*(v) & \lambda\le l_i^*(v),\\ \lambda & l_i^*(v)\le\lambda\le u_i^*(v),\\ u_i^*(v) & \lambda\ge u_i^*(v), \end{cases} \]
where \(\lambda\) makes \(\sum_i\operatorname{EC}_i(v)=v(N)\). The paper proves this result, using the known single-valuedness of the egalitarian core for convex games. It is an exact solution formula, not a theorem about computational complexity. If the anchor rule requires a result explicitly asserting a complexity classification, there is no qualifying anchor here.

The strongest positive case I can make is a narrow follow-up to Theorem 5: Type-Continuum Egalitarian-Core Computation. Consider a cooperative bankruptcy setting with many creditors, grouped into a fixed, small number \(\tau\) of types—for example, creditors with the same claim amount and legal priority. Those details make agents within a type interchangeable. Let \(\mu_t\) be the fraction of creditors of type \(t\), and let \(x_t\) be their common per-creditor allocation. Normalize total worth per creditor. Represent the game’s type-constant core by rational bounds \(\ell_t,u_t\) and grand-coalition worth \(V\), so that
\[ C=\left\{x:\ell_t\le x_t\le u_t\ \text{for all }t,\quad \sum_t\mu_t x_t=V\right\}. \]
The instance is \((T,\mu,\ell,u,V)\), with the promise that these bounds describe the core of the continuous game. The task is to output its egalitarian-core allocation: the core allocation from which no feasible transfer from a higher-paid agent to a lower-paid agent is possible. A solution is the unique vector
\[ x_t=\min\{\max\{\ell_t,\lambda\},u_t\}, \qquad \sum_t\mu_t x_t=V. \]

This is a population continuization: mass records the fraction of creditors of each complete type, and coalition worth depends on the quantities of each type in the coalition. The scenario is strongest when the creditor pool is large but the number of legally relevant claim categories is small. The paper itself lists bankruptcy games among the examples of two-bound core games, which supports this as a plausible setting. Its authors should recognize the solution concept and game class; the computational formulation is a follow-up, rather than a question the paper itself studies.

For the stated input, the mirror should be tractable: sorting the \(2\tau\) bound values and solving for the threshold \(\lambda\) gives the exact allocation with polynomially many rational operations. That is my expected Class A answer. It relies on the compact core description being supplied. A further, genuinely open computational question is whether one can obtain the bounds efficiently from a succinct representation of the coalition-worth function. Other natural follow-ups are whether this allocation is the limit of normalized finite games with repeated types, and whether reduced-game operations preserve a useful type-level representation.

This mirrors Theorem 5 only. It does not mirror Theorems 3, 4, or 6, which characterize solutions axiomatically, or claim computational content for the reduced-game results. The weakest point is also decisive: the paper does not analyze the complexity of finding the bounds from game data, and Theorem 5 is not itself a complexity result. The positive case is that its explicit formula identifies a natural, exact continuum computation; it cannot honestly be presented as a computational result already established by the paper.

The case AGAINST (opponent, writing after the proponent)

The strongest negative point is that this paper has no computational result to mirror. Its Theorems 1–6 concern core structure and axiomatic characterizations; none gives a complexity classification or an algorithmic problem. The closest anchor, Theorem 5, gives an explicit formula for the egalitarian core. That makes it a natural source of a new computational question, but not a computational result whose continuous counterpart this paper leaves open.

The proposed mirror does not quite supply that missing question. It takes the core bounds \(\ell_t,u_t\) as input, then asks for the egalitarian allocation. Given those bounds, the allocation is obtained by finding a threshold \(\lambda\) in a weighted water-filling calculation. The substantive work—deriving the bounds from a game description—has been assumed away. Asking how to derive them could be a worthwhile project, but it requires choosing a representation of the game and studying its structure; Theorem 5 itself does not pose or motivate a particular computational task there.

There is a better version of the mirror: a large bankruptcy instance with many creditors in a small number of claim or priority categories, represented by their type masses, and with coalition worth defined for fractional quantities of each type. That is a credible high-multiplicity setting, and the paper’s own mention of bankruptcy games supports it. But to ask for the egalitarian-core allocation from such an input, one must specify the continuous coalition-worth function and an encoding for the game, then determine how its core bounds are obtained. Those choices define a new computational problem; they are not supplied by the paper’s axiomatic result. If the bounds are supplied, the computation is the threshold formula. If they are not, the interesting problem is an added investigation of a chosen game family.

So the case against is limited but real: Theorem 5 supports a plausible follow-up, yet the paper provides neither a computational problem nor a canonical input model for that follow-up. The case is weakest against the broader claim that a carefully specified continuous bankruptcy model could be worth studying: the repeated-type scenario is sensible, and this paper gives no basis for ruling it out.
