The continuous mirror question

Given a finite type set \(T\) with positive rational masses \(\mu_t\) summing to one, an explicitly listed Markov chain \(Q\) over graphs \(H\) on \(T\), component values \(w(S,H)\), and rational \(0<\delta<1\) for which the operator in Theorem 4.1 is invertible, compute the unique per-capita allocation table \(y_t(H)\) satisfying \(\sum_{t\in S}\mu_t y_t(H)=w(S,H)\) for every component and \(X_t(y,H)-X_t(y,H\setminus e)=X_u(y,H)-X_u(y,H\setminus e)\) for each edge \(e=\{t,u\}\), where \(X_t\) is the discounted expected per-capita payoff under \(Q\).

The model it lives in

A population with mass \(\mu_t\) of each interchangeable type \(t\); graph nodes are types and edges are standardized class-to-class agreements. Each graph state has component values and transitions under \(Q\). The decision variable is the per-capita payoff \(y_t(H)\), with mass-weighted component efficiency and discounted expected fairness across adjacent types.

The objection that survived

Deleting a type edge changes a collective class relationship, whereas the paper compares individual endpoints after deleting their bilateral link; mass weighting alone does not recover that original bargaining unit.

fatal: False

What the mirror covers

The mirror covers the dynamic uniqueness result in Theorem 4.1 and the sum-property simplification in Theorem 5.4; it leaves the static characterization and unrestricted individual-link network states without a type-level counterpart.

The case FOR (proponent)

The paper proves no named result in a complexity class such as P or NP-hardness. Its strongest computational anchors are constructive allocation theorems: they say which allocation rule to compute, but do not bound its running time. I would build the positive case around those results, without claiming the paper already supplies a complexity classification.

The most convincing regime is a large networked economy of interchangeable firms or organizations. Let a type capture everything the allocation problem uses about a firm—technology, costs, outside options, and contract terms—and let \(\mu_t\) be the fraction of firms of type \(t\). A network state is then a graph on the \(\tau\) types: an edge represents a standardized relationship between two classes, such as a shared supplier or technology agreement. The class-level graph evolves over time. The allocation is a per-firm payoff for each type and state; a component’s total value is split across its members according to their masses. This fits settings where the number of firms is huge but the number of genuinely different roles is modest.

My lead is Theorem 4.1, proved in this paper. It says that for every transition matrix \(P\), the operator \(I-\delta(m\circ W_P)\) is invertible for all but finitely many discount factors \(\delta\). For each such \(\delta\), there is a unique allocation rule that is component efficient and expected fair, given by
\[ f=(I-\delta P)\circ(I-\delta(m\circ W_P))^{-1}\circ m. \]
Here \(m\) is the static Myerson allocation, and \(W_P\) maps expected next-period payoffs into component values. The theorem thus gives an explicit rule for the underlying dynamic allocation problem, not merely an encoding of it.

The corresponding continuous question is Type-Continuum Expected-Fair Allocation. An instance gives a finite support \(T\) of \(\tau\) types with rational masses \(\mu_t\) summing to one; a Markov transition matrix \(Q\) over graphs \(H\) on \(T\); a rational discount factor \(\delta\); and a value \(w(S,H)\) for every component \(S\) of every state \(H\). Find the per-capita allocation table \(y_t(H)\). It must satisfy
\[ \sum_{t\in S}\mu_t y_t(H)=w(S,H) \]
for every component, and expected fairness
\[ X_t(y,H)-X_t(y,H-e)=X_u(y,H)-X_u(y,H-e) \]
for every edge \(e=\{t,u\}\) in \(H\), where
\[ X_t(y,H)=\sum_{s\ge 0}\delta^s\sum_{H'}Q^s(H'\mid H)y_t(H') \]
is type \(t\)’s discounted expected per-capita payoff. There is no optimization objective in the paper’s problem: the task is to find the rule satisfying these conditions, which Theorem 4.1 says is unique for generic \(\delta\).

I expect this mirror to be tractable when the graph-state data are given explicitly: the theorem’s finite-dimensional formula points to linear algebra over the state table. If \(K=2^{\binom{\tau}{2}}\) is the number of type graphs, that suggests a running time polynomial in \(K\), the input bit length \(L\), and \(\tau\), rather than polynomial in \(\tau\). Since the population size can be much larger than \(\tau\), the formulation still removes dependence on the number of individual firms. Whether a compact description of \(Q\) and \(w\) permits an algorithm polynomial in \(\tau\) is a further question; hardness driven by the type-graph structure would more naturally transfer from the discrete model than arise from population mass itself.

A second, narrower anchor is Theorem 5.4, also proved here. It says that if \(P\) satisfies the sum-property—specifically, for any graphs \(g_1,g_2\) and edge \(e\) absent from both,
\[ P(g_1\mid g_2)+P(g_1\cup e\mid g_2) = P(g_1\mid g_2\cup e)+P(g_1\cup e\mid g_2\cup e), \]
—then for every \(\delta\) the unique component-efficient and expected-fair rule is the stage-wise Myerson value, \(f(g)=m(g)\). Its mirror is Sum-Property Type-Continuum Allocation: take the same mass-and-type-network instance, require \(Q\) to satisfy that identity, and find the unique per-capita rule satisfying weighted component efficiency and expected fairness. The expected answer is the type-weighted static Myerson rule at each state, independent of \(\delta\). This is a structurally restricted tractable case, not a second claim about all dynamic networks.

The scope is just these dynamic fair-allocation results. The weakest point is the change in what an edge means. Navarro’s links join individual players; in this mirror an edge joins whole homogeneous classes under a standardized agreement. That makes the type-level state manageable, but changes the granularity of the fairness comparison. A literal continuum limit of individually linked agents would need to explain how removing one link has a non-negligible effect on payoffs. I think the class-level version remains recognizable because it preserves the paper’s evolving network, component values, and forward-looking equal-gains condition, but that modeling step is the part a skeptical author or referee could reject.

The case AGAINST (opponent, writing after the proponent)

The main weakness in the proposed anchors is that neither is a complexity result. Theorem 4.1 proves generic existence and uniqueness and gives a formula; Theorem 5.4 identifies a condition under which that rule equals the stage-wise Myerson value. With the transition matrix and values listed explicitly over all graph states, the formula amounts to finite linear algebra. The state space already has \(2^{\binom{n}{2}}\) graphs. A complexity question polynomial in the length of that explicit table is routine; a question polynomial in a compact encoding of the transition process would depend on an encoding the paper never specifies. The anchors therefore do not identify a computational problem whose complexity continuization could change.

The deeper obstacle is what counts as a type. In this paper, an agent’s current links determine the components, and fairness compares that agent’s payoff when one particular link is removed. A firm’s technology and contract terms do not fully describe its role: its position in the evolving graph matters too. If firms with the same business attributes have different neighbors, they need not be interchangeable for the allocation problem. Including their network roles in their types can make the type set as large as the population.

The proponent’s strongest repair is a network on types. It is coherent for a setting with industry-wide agreements, where an edge between two classes represents a collective relationship. But then deleting one edge changes the relationship for the whole classes, and expected fairness compares class-level payoffs. That is a different bargaining unit and a different link-removal question from the paper’s bilateral one. Mass weights the component-efficiency equation, but it does not make the individual network’s links into class-level links.

Keeping individual links creates the opposite problem. In an atomless population, one agent or one link has measure zero. In a dense graph or graphon model, changing a single link leaves the limiting object unchanged, so the paper’s link-by-link expected-fairness condition loses its content. Perturbing a positive mass of links can have an effect, but it asks about collective changes to a block of relationships. Sparse-network limits can retain local links, yet the paper allows component values and transition probabilities to depend on the whole finite graph; a type-mass distribution alone does not preserve that connectivity information. Theorem 5.4’s sum-property also concerns toggling one specific edge, so restricting transitions by that identity does not resolve the aggregation problem.

Thus both anchors face the same fork: aggregate agents into class nodes and change the meaning of a link, or retain bilateral links and lose the paper’s fairness comparison in the continuum. I would not call the universal negative airtight. A real institution with collective class-to-class agreements might make the first model worth studying, and an author could recognize it as a related problem. But that case rests on a new group-level bargaining structure, while the paper itself supplies no computational classification to motivate the mirror. The case against these anchors is strongest when the target is a faithful continuization of Navarro’s problem.
