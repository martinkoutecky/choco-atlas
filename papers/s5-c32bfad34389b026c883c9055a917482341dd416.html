The continuous mirror question

Given finite types \(T\), rational masses \(\mu_t\), strict rankings over \(T\cup\{\bot\}\), and a feasible typed roommate assignment with pair masses \(x_{tr}\) and singleton masses \(s_t\), compute the exact rational mass \(B\) of type/current-partner cells with a reciprocal-preference witness. Set \(d_{z\bot}=s_z\), \(d_{zz}=2x_{zz}\), and \(d_{zv}=x_{zv}+x_{vz}\) for \(z\ne v\). Let \(P\) contain both orientations of every positive-mass pair team and \((t,\bot)\) for each positive singleton mass. Return \(B=\sum_{z,v}d_{zv}\,\mathbf 1[\exists(t,r)\in P:\ z\succ_t r\ \land\ t\succ_z v]\).

The model it lives in

A roommate assignment over a finite support of complete preference types, with pair and singleton team mass; the output is the mass of type/current-partner cells having at least one reciprocal-preference witness among the realized proposer contexts.

The objection that survived

The global witness scan forgets proposal order and evolving availability, so it may count agents who could not have been candidates at a particular proposal; the proponent acknowledges that the strategic interpretation is not yet proved.

fatal: False

The case FOR (proponent)

My strongest positive case is narrow: Theorem 1, proved in this paper, says that Algorithm 1 returns an upper bound on the number of players who could gain by misreporting their preferences. The text says this applies to exact RPM and its approximate versions, including HRPM. Its proof identifies potential gainers through reciprocal preference comparisons around the realized teams. The displayed algorithm appears to run in polynomial time—roughly \(O(n^2)\) preference checks with rank lookups—but Theorem 1 itself proves the bound’s correctness, not a complexity classification. The paper has no named hardness result, so there is no stronger hardness anchor to use.

A plausible setting is a large housing or team-placement program where many participants fall into a small number of complete preference types. For instance, participants might rank teammate categories—roles, skills, or work styles—rather than named individuals. A type specifies that whole ranking, and \(\mu_t\) is the fraction of the population with type \(t\). Here \(n\) can be very large while the number \(\tau\) of supported types stays modest. That is a high-multiplicity roommate problem: people of a type are interchangeable for the preferences the model uses.

I would call the mirror RPM Witness-Mass Bound. Its instance is a finite type set \(T\), rational masses \(\mu_t\), each type’s strict ranking \(\succ_t\) over teammate types and being alone \(\bot\), and a realized type-level roommate assignment with proposer and receiver roles. Let \(x_{tr}\) be the mass of teams with proposer type \(t\) and receiver type \(r\), and let \(s_t\) be the singleton mass. Require
\[ \mu_t=s_t+\sum_{r\ne t}(x_{tr}+x_{rt})+2x_{tt}. \]
The input assignment is supplied, just as Theorem 1’s algorithm takes the RPM outcome as input.

Let \(d_{zv}\) be the mass of type-\(z\) agents currently teamed with type \(v\), with
\[ d_{z\bot}=s_z,\qquad d_{zz}=2x_{zz},\qquad d_{zv}=x_{zv}+x_{vz}\ \text{for }z\ne v. \]
For types \(t,r\), let \(\rho_{tr}>0\) mean that the assignment contains a team with those endpoint types. The task is to return the mass
\[ B=\sum_{z,v}d_{zv}\, \mathbf 1\!\left[ \exists\,t,r:\ \rho_{tr}>0,\ z\succ_t r,\ t\succ_z v \right]. \]
This counts the population mass in type-and-current-partner cells that the paper’s reciprocal-preference witness test flags: type \(t\) would prefer \(z\) to its current teammate \(r\), and type \(z\) would prefer \(t\) to its current teammate \(v\). A solution is the exact rational value of \(B\), together with the flagged cells if desired. This is a mass version of the theorem’s diagnostic, merging duplicate witnesses into the mass of distinct flagged agents.

The expected result is Class A for this diagnostic: enumerate the supported type combinations and sum the flagged masses, in time polynomial in \(\tau\) and the input bit length (a direct implementation takes at most \(O(\tau^4)\) comparisons). This is a modest algorithmic result, not a claim that the continuous RPM game itself is tractable. It covers only Theorem 1’s post-outcome upper-bound calculation; the paper’s empirical welfare and fairness comparisons are not anchors for this mirror.

The weakest point is substantial: the paper’s RPM is a sequential game over named players, and a continuum does not supply a canonical proposer sequence. In a nonatomic model, one agent’s deviation also has zero mass and may not affect the outcome. So the proposed problem mirrors the *witness calculation* after an assignment is given; it does not yet define a continuous RPM or prove that \(B\) bounds actual unilateral manipulation in that game. The natural next questions are whether this bound remains sound for a specified finite-clone limit, whether a continuous RPM outcome can be defined in a way the authors would accept, and whether any such model preserves the theorem’s strategic interpretation.

The case AGAINST (opponent, writing after the proponent)

Theorem 1 is the only strong anchor, and its vulnerable point is what the proposed mass statistic actually preserves. The theorem’s algorithm scans a finite proposer order, checks candidates available at each step, then removes players and updates the remaining feasible sets. Its correctness is about that sequential process and its counterfactuals.

The proposed \(B\) uses a final assignment and asks whether a compatible proposer–receiver type pair exists anywhere. It can therefore flag all agents in a cell even when they were already unavailable when that proposer acted. The input omits the order and the evolving candidate sets that make the theorem’s bound sound. So \(B\) is a computable mass statistic, but the paper does not establish it as a continuous version of Theorem 1’s upper bound.

One could repair the model by recording priority or time and tracking the remaining population through the mechanism. That is a sensible research direction, but it brings back the core difficulty: priority affects the game, so a complete type must include it, or the population state must carry an equivalent time-indexed history. In an atomless population there is no canonical first proposer or last subgame for the paper’s backward induction. A finite-clone limit could supply those details, but then the result would depend on how the order and limit are defined. The mass-only formulation does not settle them.

The negative case is limited. A finite-clone model with repeated preference types and random proposer order might yield a meaningful limit for the fraction flagged by the theorem, and the authors could recognize that as their problem. But that would require defining and analyzing a sequential limit first. As stated, the proposed anchor is a static aggregation that has not retained the theorem’s sequential guarantee; the paper offers no named complexity result for a continuous RPM outcome to rescue the mirror.
