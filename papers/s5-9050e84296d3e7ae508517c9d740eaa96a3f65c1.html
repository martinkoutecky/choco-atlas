What the mirror covers

The case FOR (proponent)

The strongest mirror is the paper’s budget-balance lower bound, not a claim about runtime. Theorem 3 (proved in this paper) says that for \(A=\{1,2,3\}\), if \(x\ge 1\) and the costs are
\(C(\{1,2\})=C(\{1,3\})=1\), \(C(\{1\})=C(\{2\})=C(\{3\})=x\), \(C(\{2,3\})=x^2+x\), and \(C(\{1,2,3\})=x^3+x^2+x\), then no \(1/x\)-budget-balanced cost-sharing scheme satisfies Fence Monotonicity. Theorem 1, also proved here, says that a cost-sharing scheme gives rise to a group-strategyproof mechanism exactly when it satisfies Fence Monotonicity. Together, these results give an \(x\)-dependent impossibility for GSP mechanisms, with the guarantee deteriorating without bound as \(x\) grows. The paper has no named NP-hardness result; this is its most useful anchor for a continuous mirror because it is a concrete impossibility about the performance of GSP mechanisms.

I would ask about the Continuous Three-Cohort Budget-Balance Frontier. There are three publicly known service classes, each with population mass \(1/3\). Agents have private values for service; their complete types include their class and value, with a finite rational support of size \(\tau\). Thus the scenario can have a very large population but only a few distinct types: for example, three large client groups with different effects on service costs and a small number of valuation levels. The mechanism receives the distribution of reported bids, chooses which agents receive the service, and charges served agents. Each person’s service is still integral; the served mass \(q_i\in[0,1/3]\) in class \(i\) can be fractional because the population is nonatomic.

To make Theorem 3’s cost data into a specific mass-cost instance, let \(c_x(S)\) denote the listed cost for each \(S\subseteq\{1,2,3\}\), with \(c_x(\varnothing)=0\). Define \(z_i=3q_i\), the fraction of class \(i\) served, and set
\(C_x(q)=\sum_{S\subseteq\{1,2,3\}}c_x(S)\prod_{i\in S}z_i\prod_{i\notin S}(1-z_i)\).
This is a continuous, nonnegative cost function that agrees with the paper’s table whenever each cohort is either entirely served or entirely excluded. The question is: for rational \(x\ge1\), what is the greatest \(\alpha\) for which there exists a deterministic, anonymous direct mechanism that is voluntary-participation, no-positive-transfer, consumer-sovereign, group-strategyproof against positive-mass coalition deviations, and \(\alpha\)-budget-balanced on every finite-support bid distribution? A solution is either an impossibility proof for a proposed \(\alpha\), or a mechanism meeting that guarantee.

The authors would recognize this as their cost-sharing problem: the population, service decision, payments, and budget-balance objective are all central to the paper. Mass-based costs and type-level service quantities are co-modifications forced by the population model. I expect an \(x\)-dependent lower bound on achievable budget balance to remain an interesting target, but the precise \(1/x\) bound is a conjecture for this continuous instance, not something Theorem 3 establishes. Partial service of a cohort may evade an argument that works over the discrete subset lattice. So the expected route is a continuum-specific lower bound; there is no hardness transfer from a three-player instance whose outcomes need not embed in the mass model. This mirror covers Theorem 3, using Theorem 1 to connect it to GSP, rather than claiming a continuous version of the paper’s full characterization. I would not anchor on Theorem 4’s polynomial-time stable-pair recovery: it assumes the values \(\xi^*(i,L,U)\) have already been computed for all discrete pairs \(L\subseteq U\), which does not itself give an algorithm for continuous mass bounds.

The weakest point is the cost extension. The paper specifies costs only for all-or-none sets; its theorem does not choose a cost curve for partially served cohorts. The multi-affine extension above makes the prover’s question precise and preserves every listed cost, but another plausible mass-cost model could have a different budget-balance frontier. A useful follow-up is to test whether the bound survives other natural extensions and whether Fence Monotonicity admits a characterization over mass vectors.

The case AGAINST (opponent, writing after the proponent)

Theorem 3 is a real impossibility result, but it is not a computational result: it bounds the budget balance of every GSP cost-sharing scheme for a three-player set function. Theorem 1 characterizes which schemes are GSP. Neither asks for an algorithm, a complexity classification, or an approximation procedure. Turning Theorem 3 into a continuous “frontier” therefore changes the kind of question the paper answers.

The proposed three-cohort version does not remove that mismatch. The paper gives costs only for all-or-none subsets. The proposed multi-affine extension assigns a cost to partial service by averaging the corner costs as if each cohort were independently included in a random all-or-none set. That is a coherent mathematical choice, but it has no operational basis in the paper; another mass-cost function can agree at every listed subset and behave differently between them. Once an extension is stipulated, finding its best budget-balance guarantee may be interesting, but it is an axiomatic mechanism-design problem for that chosen cost model, not a continuous version of a computational result here. And with only three cohorts and \(x\) as the parameter, it does not by itself yield a complexity landscape.

There is also a tension in the proposed allocation model. At a truthful profile, everyone in a cohort with the same complete type reports alike. A deterministic anonymous mechanism cannot select an arbitrary proper fraction of those indistinguishable agents without using labels or another tie-breaker. Labels would distinguish agents the high-multiplicity model groups together; lotteries would change the deterministic mechanism model. A mechanism can treat a cohort fractionally after its members submit different reports, but that makes the outcome depend on report-splitting behavior rather than establishing that the paper’s three-player obstruction has a natural mass counterpart.

The only explicit runtime result is Theorem 4. It identifies a stable pair in polynomial time *given the mechanism’s outcome and the values \(\xi^*(i,L,U)\) for every nested pair \(L\subseteq U\)*. That is a large table indexed by the subset lattice, not a succinct cost-sharing input. A continuous analogue would need a finite representation or oracle model for values over a continuum of mass vectors; the paper supplies neither. So this theorem offers a possible lead, but not a ready-made algorithmic problem to mirror.

This is a strong case against treating the paper’s main results, especially Theorem 3, as a worthwhile ChoCo mirror. It does not honestly establish the universal claim that no useful continuous cost-sharing problem exists: large markets with repeated service and valuation types are plausible. But to reach one here, an analyst must choose and defend the mass-cost model, the anonymity and allocation semantics, and a finite computational input model. Those choices would create a new problem whose connection to the paper’s results is limited.
