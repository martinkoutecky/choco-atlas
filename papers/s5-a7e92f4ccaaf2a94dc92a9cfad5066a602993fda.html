The case FOR (proponent)

The best positive case is a single mirror around Theorem 3, but there is an anchor problem: the paper has no numbered result asserting that a problem is in P, NP-hard, or in another complexity class. Theorem 3 is a proved characterization, not a complexity theorem. The introduction says the question is computationally tractable, but that claim is not a numbered result. So Theorem 3 is the closest named result to anchor on, not a qualifying computational anchor under your rule.

Theorem 3, proved in this paper, says that for a rationalizable group dataset and a proposed allocation, these are equivalent: there are monotone increasing, explicitly quasiconcave utilities rationalizing the agents’ data that make the allocation Pareto efficient; there are monotone increasing, concave rationalizing utilities that make it Pareto efficient; and the allocation is not empirically dominated by any other allocation. Empirical domination means that another allocation uses no more aggregate resources, while each agent’s bundle “bests” theirs according to the revealed-preference relation inferred from their data, with a strict besting for at least one agent.

A plausible population regime is a large market with many consumers drawn from a relatively small set of standardized demand-history cohorts. A type \(t\) would be a cohort sharing its observed price-and-bundle dataset and its underlying preferences; \(\mu_t\) would be its fraction of consumers. The regime is credible when \(N\) is much larger than the number \(\tau\) of such cohorts—for example, hundreds of thousands of consumers represented by dozens or hundreds of types. The proposed allocation gives each type a per-capita bundle \(\bar x_t\), with aggregate resources \(\sum_t \mu_t\bar x_t\).

The one mirror I would propose is Possible Pareto Efficiency for a Continuous Population of Revealed-Preference Types. Its instance consists of the number of commodities \(m\), finitely many types \(T\), positive rational masses \(\mu_t\) summing to one, each type’s finite rational dataset \(D_t=\{(p_t^k,x_t^k)\}\), and proposed per-capita bundles \(\bar x_t\). Ask whether there are monotone increasing, concave utilities \(u_t\), one common utility for each type, that rationalize \(D_t\) and make the allocation Pareto efficient. Efficiency means there is no reassignment \(y_t\) satisfying \(\sum_t\mu_t y_t\leq\sum_t\mu_t\bar x_t\), with \(u_t(y_t)\geq u_t(\bar x_t)\) for every type and strict improvement for at least one positive-mass type. A solution is a yes or no answer; the expected finite certificate is an Afriat-style linear-program solution in the yes case, or a weighted empirical domination witness in the no case.

I expect this mirror to be tractable, by adapting the paper’s linear-programming and duality argument to rational type masses. The expected running time would be polynomial in \(m\), \(\tau\), the total number of observations, and their bit length \(L\). That is an extrapolation, not a complexity result established by the paper. The scope is deliberately just the possible-efficiency question of Theorem 3; it does not claim to mirror the paper’s other welfare questions.

The positive case is that the population change preserves the central question: can this proposed allocation be efficient for preferences consistent with observed choice data? A type distribution and per-capita bundles make that question natural for large cohorts, while leaving the paper’s revealed-preference and efficiency machinery in place.

The weak point is the type assumption. Consumers with the same observed dataset need not have the same actual preferences. This mirror assumes a shared underlying preference within each type, and its tractability prediction needs a proof for the weighted, type-level model. That is a meaningful homogeneous-population version of the authors’ problem, but it is not already covered by Theorem 3. The main follow-up question is whether its weighted empirical-domination characterization remains exact; extensions to unbounded or continuous type spaces would come later.

The case AGAINST (opponent, writing after the proponent)

Theorem 3 is the only anchor the proponent raises, and it is a characterization, not a numbered complexity result. The paper’s introduction says the condition is computationally tractable, but the theorem itself answers which allocations can be efficient; it does not state a complexity bound. Under the requested standard for anchors, this is already a serious defect.

The stronger objection is that the proposed mirror is almost exactly Theorem 3 with repeated agents compressed into types. For rational masses, choose a common denominator \(Q\) and make \(Q\mu_t\) identical copies of each type. Multiplying the continuous resource constraint by \(Q\) gives the finite-agent constraint. If a continuum allocation varies within a type, concavity lets us replace those bundles by their average: the type’s average bundle is at least as good for its common utility, and a strict improvement on positive mass remains strict after averaging. The efficiency question therefore reduces to the finite one.

That cloning argument alone could expand the input exponentially in its bit length, so it does not establish a compressed-input runtime. But the proposed model repeats the same dataset and allocation within each type. The paper’s Afriat system can be grouped by type, with the rational masses entering as coefficients; this leaves a system sized by the number of types and observations, with coefficient bit lengths controlled by the input. The proponent’s predicted tractability is thus a direct weighted version of the paper’s existing LP machinery. There is no distinct separation problem or new source of complexity to investigate.

The best scenario for the mirror is a large standardized panel in which many consumers share an exact demand history and a common underlying preference. That is coherent, but restrictive: with individual price and bundle histories, even consumers with similar preferences will often fall into different data types. Allowing varied histories generally increases the support and erodes the proposed compression. The type assumption also turns uncertainty about each consumer’s rationalizing utility into uncertainty about one shared utility per cohort.

So the mirror is well-posed, and the positive case is not clumsy. Its weakness is that its best version is a compressed, weighted corollary of the paper’s finite-agent result, while its empirically natural versions may have little multiplicity. I would not call that a convincing universal impossibility; I would call it a weak case for spending ChoCo’s effort on this paper.
