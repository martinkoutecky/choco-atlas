The continuous mirror question

Given a finite type set \(K\), a rational mass vector \(\mu\) with \(\sum_{j\in K}\mu_j=1\), and a rational polynomial \(f_\mu(x)\) in dense or unary-degree encoding with \(f_\mu(0)=0\), where \(f_\mu(x)\) is the worth of a coalition of type-mass \(x\) against its complement as one rival coalition, compute the exact continuous McQuillin allocation \(A_j=\mu_j a_j\), where \(a_j=\int_0^1\partial_j f_\mu(t\mu)\,dt\). Equivalently, compute the limit of the type allocations in replica games with \(q\mu_j\) identical agents of each type, as \(q\) ranges over multiples of the common denominator of \(\mu\).

The model it lives in

A society is a rational mass distribution \(\mu\) over payoff-equivalent agent types \(K\). A coalition is represented by its type-mass vector \(x\), and its two-block worth is given by \(f_\mu(x)\). The task is to compute the exact type allocations \(A_j=\mu_j\int_0^1\partial_j f_\mu(t\mu)\,dt\) using a polynomial encoding whose exact output size is controlled.

The objection that survived

The polynomial-time claim depends on the input encoding: sparse monomials with binary exponents can produce an exact output with exponentially many bits, and Theorem 2 itself supplies no algorithm for the proposed type-mass representation. A dense or unary-degree encoding repairs the output-size issue, but leaves the mirror narrower than the paper's general PDT result.

fatal: False

What the mirror covers

The mirror covers the McQuillin component of Theorem 2 on anonymous type-composition games. It leaves the other values in Theorem 2, the Hu–Yang result in Theorem 3, and the paper's general representation results aside.

Open questions for a prover

  • Can the type-anonymous payoff representation be made substantially more succinct while retaining polynomial-time exact computation of the continuous McQuillin allocation?
  • Which broader externality-dependent payoff functions admit an analogous replica limit for other values studied in the paper?

The case FOR (proponent)

The strongest honest positive case is a continuous McQuillin value for an anonymous, high-multiplicity production game. An agent’s type records everything payoff-relevant: for example, production role, capacity, cost, and outside option. A society is a rational mass vector \(\mu\) over a fixed finite set \(K\) of such types. A large market might have thousands of small suppliers but only a handful of types; suppliers within a type are interchangeable. A coalition’s surplus can depend on its type composition and on the remaining suppliers forming a single rival coalition, so externalities remain part of the model.

My anchor is Theorem 2, proved in this paper. It says that if a value is additive and satisfies the Strong Null-Player Axiom, and can be computed in \(O(|N|)\) time on games in \(\Psi(N)\)—linear combinations of elementary games whose nonzero payoffs occur in one partition—then it can be computed in \(O(|N||T|)\) time on a game represented by a set \(T\) of Partition Decision Tree rules. The theorem further establishes that the externality-free, McQuillin, Macho-Stadler et al., and Myerson values all have this running time on PDT games. The proof uses path additivity and the ability to remove null players. The paper has no numbered computational hardness result to anchor on, so this algorithmic result is the strongest suitable anchor.

Here is the continuous problem I would hand to a prover. The instance consists of \(K\), a rational mass vector \(\mu\) with \(\sum_{j\in K}\mu_j=1\), and an explicitly represented rational polynomial \(f_\mu(x)\). For a coalition with type-mass vector \(x\), \(f_\mu(x)\) gives that coalition’s surplus when the complement forms one rival coalition; assume \(f_\mu(0)=0\). Compute the continuous McQuillin allocation: a payoff density \(a_j\) for each type \(j\), and hence total allocation \(A_j=\mu_j a_j\) to that type’s mass. A precise definition is the replica limit. For each admissible \(q\), create \(q\mu_j\) identical agents of type \(j\), and give a coalition \(S\) worth \(f_\mu(x(S))\), where \(x_j(S)=|S\cap N_j|/q\). If \(\phi_i^{(q)}\) is a clone’s finite McQuillin value, set

\[ a_j=\lim_{q\to\infty}q\,\phi_i^{(q)} =\int_0^1 \partial_j f_\mu(t\mu)\,dt, \qquad A_j=\mu_j a_j. \]

The solution is the exact type-allocation vector. For a sparse rational polynomial input, the displayed integral gives a direct exact algorithm, with running time polynomial in the polynomial representation, the number of types, and the bit lengths. The expected classification is Class A. It also satisfies efficiency: \(\sum_j A_j=f_\mu(\mu)\), by integrating the derivative of \(f_\mu(t\mu)\) along the population ray.

This retains the underlying question the authors study—how to allocate coalition surplus under externalities using the McQuillin extension. It does not treat fractional outcomes or random profiles as the continuization: population mass is the continuous object, and the allocation is the type-level limit of the finite value. The case is deliberately limited to McQuillin’s two-block slice, which is exactly the part of the game its formula reads. Natural further questions are whether the limit and an efficient computation extend to less smooth payoff functions, and whether analogous limits exist for values that depend on arbitrary partitions, such as Bolger, Myerson, or Hu–Yang.

The weak point is that this is not a continuous reformulation of the full PDT input class. PDT rules can distinguish named agents, and Theorem 2’s general algorithm benefits from removing null players; the proposed mirror instead uses anonymous type-mass payoff functions. So it does not transfer Theorem 2’s general algorithm into the continuum. Its claim is narrower: the McQuillin allocation problem remains recognizable and meaningful when many payoff-equivalent agents are represented by mass, and its replica limit is explicit.

The case AGAINST (opponent, writing after the proponent)

Theorem 2 is a real computational result, and a market with many interchangeable suppliers is a plausible high-multiplicity setting. So I can’t honestly rule out every worthwhile mirror. The stronger objection is that this theorem does not itself supply one.

Its input is a Partition Decision Tree over \(n\) individually named agents. A path can distinguish those agents by name, and its running time is \(O(n|T|)\); the bound has no support-size or mass-bit-length parameter. Representing a mass vector by \(q\) clones leaves those clones explicit. Collapsing them into types would require a new, anonymous input representation, and arbitrary PDT rules need not respect that collapse: they can distinguish agents of the same proposed type or depend on detailed coalition partitions. Thus Theorem 2’s algorithm does not become a high-multiplicity algorithm by taking a limit.

The best version of the proposed mirror—a smooth surplus function over type masses and a continuous McQuillin allocation—is coherent. But its radial integral is the familiar Aumann–Shapley form of a value for non-atomic games and continuum-trader settings.[Aumann and Shapley, *Values of Non-Atomic Games*](https://www.degruyterbrill.com/_language/de?uri=%2Fde%2Fdocument%2Fdoi%2F10.1515%2F9781400867080%2Fhtml), [Aumann, “Values of Markets with a Continuum of Traders”](https://www.ma.huji.ac.il/raumann/pdf/Values%20of%20Markets%20with%20a%20Continuum%20of%20Traders.pdf) That precedent does not settle complexity for succinctly represented externality games. But with an explicitly represented polynomial, the proposed computation is simply differentiation and integration along a ray; the complexity claim comes from that chosen encoding, not from the PDT result. Even the claimed polynomial exact runtime needs an encoding qualification: with sparse monomials and binary exponents, \(f(x)=x_1^D\) at \(\mu_1=1/3\) yields \(A_1=3^{-D}\), whose binary rational output has \(\Theta(D)\) bits despite an exponent encoding of \(O(\log D)\) bits.

A more challenging mirror could use a new type-anonymous compressed representation and ask for the value on that representation. But specifying that representation, which externalities it can express, and how it relates to finite PDTs would be a separate modeling and complexity project. The two-block restriction makes the continuum manageable, but also leaves little of the paper’s representation problem to study. My negative case is therefore strongest as a priority argument: this anchor leads either to a classical continuous allocation formula on explicit inputs or to a new representation project, not a direct continuation of Theorem 2. It does not establish that no narrower mirror could be worthwhile.
