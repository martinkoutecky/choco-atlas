The continuous mirror question

For an atomless, labelled unit-mass population whose type map has rational masses \(\mu_t\) over a finite set \(T\), with \(v_t(s)\in\{0,1\}\), does there exist a deterministic mechanism computable in time polynomial in \((|T|,L)\) that outputs a measurable pairing and singletons, achieves welfare at least half the optimum over measurable coalition partitions, is acceptable, and is strategyproof against every individual’s unilateral report change? The mechanism must specify how aggregate pairing rates are realized as assignments to individuals.

The model it lives in

A type \(t\) specifies its values \(v_t(s)\) for each type \(s\), with \(v_t(t)\) excluded for the individual herself. The input is the finite type table and rational mass vector \(\mu\); the output is a pointwise measurable matching, represented in aggregate by pair frequencies \(x_{ab}\) satisfying \(2x_{aa}+\sum_{b\ne a}x_{ab}\leq\mu_a\), together with a realization rule. Welfare is compared with the optimum over all coalition partitions, and truthfulness is tested for each individual, including measure-zero unilateral deviations.

The objection that survived

A single agent’s report change has zero effect on the type masses, while Theorem 10’s truthfulness proof depends on the named agent’s position in a finite matching; the type-frequency LP alone supplies no pointwise truthful implementation or matching computational representation.

fatal: False

What the mirror covers

The mirror covers Theorem 10’s factor-\(2\) strategyproof mechanism for simple-valuation FHGs. It leaves the paper’s other valuation classes, lower bounds, and their mechanisms outside the question.

Open questions for a prover

  • Can a polynomial-time aggregate pairing algorithm be given a pointwise measurable realization that remains strategyproof for every individual report change?
  • Is the factor \(2\) tight for strategyproof mechanisms in this type-frequency setting?

The case FOR (proponent)

The strongest positive case is narrow: fractional hedonic welfare with simple valuations in a population made up of many copies of a few preference types. I would not claim that this paper establishes a standard complexity classification. Its useful anchor is an algorithmic approximation theorem.

That regime fits settings such as a large organization or matching platform where people have a small number of compatibility profiles. A type \(t\) is the complete vector \(v_t(s)\in\{0,1\}\) describing how someone of type \(t\) values every *other person* of each type \(s\). The society is given by rational masses \(\mu_t\), with support size \(\tau\ll N\). This is a plausible high-multiplicity regime when preferences genuinely depend on role or category rather than personal identity.

My anchor is Theorem 10, proved in this paper. For fractional hedonic games with simple valuations, the deterministic mechanism that outputs the maximum-weight matching described in Lemma 9 is strategyproof and acceptable, and has approximation ratio \(2\) for social welfare. Its matching graph puts an edge between two agents if either values the other; the edge weight is \(1\) for a one-way value and \(2\) for mutual values. The paper computes that matching in polynomial time. The theorem is an approximation and mechanism-design result, not a named \(P\)-versus-hardness result.

I would ask a prover to study Type-Frequency Fractional Hedonic Welfare. An instance is a finite set \(T\) of types, rational masses \(\mu_t\geq 0\) summing to \(1\), and values \(v_t(s)\in\{0,1\}\). In a coalition with composition \(k\in\mathbb Z_{\geq0}^{T}\setminus\{0\}\), a member of type \(t\) gets

\[ u_t(k)=\frac{\sum_{s\in T} k_s v_t(s)-v_t(t)}{\sum_{s\in T}k_s}. \]

The subtraction removes the member’s own value: two people of the same type may value one another positively, even though nobody values themselves.

A society partition can be represented by coalition frequencies \(\rho_k\geq0\), where \(\rho_k\) is the number of coalitions of composition \(k\) per unit of population. Feasibility requires \(\sum_k \rho_k k_t=\mu_t\) for each type. Welfare per capita is \(\sum_k \rho_k\sum_t k_tu_t(k)\). The problem is to construct a deterministic strategyproof, acceptable mechanism that, for every reported type profile with these masses, outputs a pairing and singletons whose welfare is at least half the optimum over all coalition partitions. Strategyproofness is tested against a single person changing their report while everyone else’s report stays fixed. The output must include a rule realizing the type-level pairing rates as assignments to individuals, so that incentive claims concern actual agents and not only aggregate masses.

The matching part has a compact continuous formulation. Let \(x_{ab}\) be the frequency of pairs of types \(a,b\). It obeys

\[ 2x_{aa}+\sum_{b\ne a}x_{ab}\leq\mu_a. \]

Maximizing \(\sum_{a<b}x_{ab}(v_a(b)+v_b(a))/2+\sum_a x_{aa}v_a(a)\) is a linear program with \(O(\tau^2)\) variables. The paper’s matching argument gives a reason to expect this pairing solution to approximate welfare even when the benchmark permits larger coalitions. The expected classification is Class A: the optimization is tractable in \((\tau,L)\), and the paper provides the structural reason to focus on pairs.

The weakest point is the incentive guarantee. Theorem 10’s strategyproofness is proved for a finite matching of named agents. A mass LP alone does not establish strategyproofness in the continuum: changing one person’s report has zero effect on the masses, yet can still change that person’s partner. A valid mirror needs an individual-level realization and a truthful tie-breaking rule, with running time polynomial in \((\tau,L)\). That is a real proof obligation, not something the approximation argument settles. The mirror also covers only Theorem 10’s simple-valuation FHG setting; I would not stretch it to the paper’s other valuation classes or bespoke lower-bound constructions. Further questions include whether the factor \(2\) is tight for truthful mechanisms in this regime and whether the same type-frequency approach extends beyond binary valuations.

The case AGAINST (opponent, writing after the proponent)

Theorem 10 is the only anchor raised, and it passes the named-result screen: it gives a polynomial-time, strategyproof mechanism with a factor-\(2\) welfare guarantee. So the case against cannot honestly rest on the paper having no computational result.

A role-based population is also plausible. If people fall into a few categories and value others by category, the type table \(v_t(s)\) is coherent, and type masses can describe a large society. Pairing rates then capture aggregate welfare. I would not reject the mirror on the grounds that matching needs indivisible people or that the resulting answer might be easy.

The harder problem is preserving the theorem’s strategyproofness claim. In the paper, a named person can change their valuation row while everyone else’s rows stay fixed; the mechanism then assigns that person to a particular partner. A distribution \(\mu\) records neither that person nor their partner. In an atomless model, changing one person’s report leaves \(\mu\) unchanged, while the matching LP specifies only aggregate pairing rates. If outcomes identify societies up to measure-zero changes, the deviator’s allocation is undefined there. If the mirror retains pointwise pairings, it needs an additional rule for assigning individuals to those rates, and truthfulness depends on that rule. Treating a whole type’s report as the deviation instead changes the incentive condition; giving each person positive mass returns to a finite clone model.

So the strongest objection is that the proposed type-frequency LP preserves the welfare calculation but does not, by itself, preserve the theorem’s central joint claim of welfare approximation and individual strategyproofness. A continuous welfare-only mirror remains plausible, and a richer pointwise mechanism model might preserve incentives too. But that model needs to be specified before there is a well-defined computational question over the population distribution. I can make a substantial case against this anchor’s fit; I cannot honestly establish the requested universal claim that no worthwhile mirror exists in any scenario.
