The continuous mirror question

Given rational masses \(\mu_t\) on agent types \(t\in T\), rational supplies \(\nu_s\) on object types \(s\in S\), with both totals equal to \(1\), and partial-order preferences for each agent type, is there a feasible target assignment \(x\) with row sums \(\mu_t\) and column sums \(\nu_s\) whose mass unpopularity margin is at most \(\kappa\)? Define that margin as \(U(x)=\max_z\sum_{t,s,s'}\sigma_t(s',s)z_{tss'}\), where \(z_{tss'}\ge 0\) couples the target object \(s\) and rival object \(s'\) for the same type-\(t\) mass, satisfies \(\sum_{s'}z_{tss'}=x_{ts}\) and \(\sum_{t,s}z_{tss'}=\nu_{s'}\), and uses only acceptable pairs; \(\sigma_t(s',s)\) is \(1\), \(-1\), or \(0\) according as type \(t\) prefers \(s'\), prefers \(s\), or is indifferent or incomparable.

The model it lives in

An atomless population with rational type masses \(\mu_t\) and co-scaled object supplies \(\nu_s\); each unit of mass receives one acceptable object. A feasible target transport \(x\) is judged against every feasible rival via a joint coupling \(z\) of target and rival assignments, and the objective is the maximum mass vote margin \(U(x)\).

What the mirror covers

The mirror covers Theorem 1.3’s bounded-unpopularity-margin assignment problem, including its \(\mathsf{W}_{\ell}[1]\)-hardness and \(\mathsf{NP}\)-completeness statements. It leaves the paper’s cost, forced-edge, penalty, and housing-market results aside.

Open questions for a prover

  • What is the complexity of the mass-margin problem when agent-type and object-type support sizes are fixed or parameterized?
  • Does the paper’s parameterized hardness for weak rankings have a useful formulation under a canonical common denominator for the mass threshold?
  • What is the parameterized complexity for strict rankings in the mass setting?

The case FOR (proponent)

The strongest mirror is the paper’s \(k\)-unpopularity-margin assignment problem, with a continuum of agents and a co-scaled supply of objects. It preserves the paper’s central comparison—one assignment against every rival assignment—while making explicit how to compare two assignments when agents are grouped by type.

Take agent types \(T\) and object types \(S\). A type \(t\) specifies the agent’s acceptable object types and their partial order; object type \(s\) has supply \(\nu_s\). Let \(\mu_t\) be the mass of agent type \(t\), with \(\sum_t\mu_t=\sum_s\nu_s=1\). A target assignment is a matrix \(x\) supported on acceptable pairs, with row sums \(\mu_t\) and column sums \(\nu_s\). Each unit of mass receives one object; \(x_{ts}\) says how much of type \(t\) receives type \(s\).

To compare the target with a rival assignment, use \(z_{tss'}\): the mass of type \(t\) receiving \(s\) in the target and \(s'\) in the rival. Require \(\sum_{s'}z_{tss'}=x_{ts}\) and \(\sum_{t,s}z_{tss'}=\nu_{s'}\), with both objects acceptable to \(t\). Let \(\sigma_t(s',s)\) be \(1\) if \(t\) prefers \(s'\), \(-1\) if it prefers \(s\), and \(0\) if it is indifferent or the objects are incomparable. The target’s mass unpopularity margin is

\[ U(x)=\max_{z}\sum_{t,s,s'}\sigma_t(s',s)z_{tss'}. \]

The continuous decision problem is: given rational \(\mu,\nu\), the type preferences, and \(\kappa\ge 0\), does there exist a feasible target \(x\) with \(U(x)\le\kappa\)? A witness is such an \(x\), together with a dual certificate bounding the rival’s maximum margin. The coupling \(z\) matters: it records how the *same* mass of people fares in both assignments. Every feasible coupling can be realized by splitting each type’s atomless cohort into the corresponding \(t,s,s'\) pieces. Dropping that joint information would change the popularity comparison.

This fits, for example, a large hospital-placement market: many applicants share a profile of qualifications, acceptable roles, and role preferences, while role supplies scale with the applicant population. The type count \(\tau=|T|\) and number of role types can be far below the population size. For the hardness embedding below, \(\tau\) grows with the source instance, but each type can still represent an arbitrarily large cohort.

The anchor is Theorem 1.3 in the paper’s full version. It says that deciding whether an assignment has unpopularity margin at most \(k\) is \(\mathsf{W}_{\ell}[1]\)-hard parameterized by \(k\) for weak rankings, and is \(\mathsf{NP}\)-complete even for strict rankings. The authors prove this result in the paper. [The full version on arXiv](https://arxiv.org/abs/2110.10984) prints it as Theorem 1.3.

I expect the strict-ranking hardness to transfer: Class B, rather than the mass relaxation automatically making the problem tractable. There is a useful reason. Clear the rational denominators of \(\mu\) and \(\nu\), giving integer type counts and object supplies. The feasible target assignments form a bipartite flow polytope, so its vertices are integral. Also, \(U(x)\) is concave in \(x\): the dual of the rival-assignment LP expresses it as a minimum of affine functions of \(x\). If any fractional \(x\) has \(U(x)\le\kappa\), concavity implies that some vertex in its convex decomposition has margin at most \(\kappa\). At such a vertex, the rival-coupling problem is itself an integral bipartite flow problem, so its worst rival is realizable by an ordinary assignment of the cloned population.

In particular, from a source instance with \(n\) agents and \(n\) objects, make each agent and object its own type, set \(\mu_t=\nu_s=1/n\), and set \(\kappa=k/n\). The target polytope then has the source assignments as its vertices, and the margin at each vertex is exactly the source margin divided by \(n\). Thus the continuous instance is yes exactly when the discrete source instance is yes. The paper’s \(\mathsf{NP}\)-hardness therefore gives a polynomial reduction to this mass problem. This also explains why merely observing that the rival problem at a fixed target is an LP would be insufficient: the outer choice of target still carries the hard question.

The mirror covers Theorem 1.3’s bounded-margin assignment problem only; it makes no claim about the paper’s cost, forced-edge, or housing-market results. A parameterized follow-up is whether the weak-ranking \(\mathsf{W}_{\ell}[1]\)-hardness persists when the continuous threshold is expressed as an unnormalized margin at a canonical common denominator. The strict-ranking parameterized case, fixed-support complexity, and algorithms for low \(\tau\) are further questions.

The weakest point is that the hardness embedding uses a growing number of detailed preference types, one per source agent. It does not establish hardness when the number of recurring types is fixed or very small. It also relies on treating copies of an object category as interchangeable and scaling their supply with the population. Those are real regime restrictions. But the mirror itself remains recognizable: mass is assigned to objects, and a target is judged by the same head-to-head vote margin against feasible rival assignments.

The case AGAINST (opponent, writing after the proponent)

The strongest case against this mirror is that its apparent fractional freedom may do no work. Clear the rational denominators of the agent masses and object supplies. The target assignments then form an integral transportation polytope. For a target \(x\), the rival’s best margin \(U(x)\) is a concave function: by LP duality, it is a minimum of affine functions of \(x\). So if any fractional target has \(U(x)\le\kappa\), some vertex does too. At that vertex the rival-coupling polytope is also integral. The mirror therefore has an equivalent target and rival made of ordinary assignments in a cloned finite population.

That puts a limit on what the mirror’s fractional allocation can deliver. The paper’s hardness reduction uses a growing number of distinct preference types, so it establishes hardness as type support grows; it does not show hardness among a fixed, recurring set of agent and object types. With both type sets fixed, the target space has fixed dimension, and one can enumerate its vertices and evaluate each by an LP. This makes the proposed anchor look like hardness from the structure among types, rather than a computational problem created by a continuum of people.

But that is not enough to defeat the anchor under ChoCo’s standards. A succinct rational description of the cloned population can be much smaller than the clone expansion, and establishing the exact correspondence is itself a meaningful high-multiplicity result. Classifying the hardness as driven by type support could also be useful. The hospital-placement scenario is plausible, and the coupling is a sound way to compare the same atomless cohort across two assignments. I do not see a fundamental identity or modeling obstruction.

So the negative case is weak at the decisive point: it can question whether this mirror yields a new tractability story, but that is not a reason the question is unworthwhile. The bounded-margin anchor survives; I cannot honestly support the universal claim that no worthwhile continuous mirror exists.
