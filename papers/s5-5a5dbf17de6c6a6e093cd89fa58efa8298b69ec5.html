The continuous mirror question

Given finite supports of pair types \(P\) and altruist types \(A_0\), rational masses \(\mu_u\) summing to \(1\), type-determined compatibility, and length limits \(l_p,l_c\), compute the maximum pair mass that can be covered by feasible typed chains and cycles. Equivalently, for a target share \(\rho\), decide whether at least \(\rho\sum_{u\in P}\mu_u\) pair mass can be covered, with each type’s available mass respected.

The model it lives in

Let \(\mathcal Q\) contain every compatible typed chain or cycle within the length limits; repeated type positions use distinct units of mass. For each \(Q\), let \(x_Q\ge 0\) be its assigned mass, \(a_{uQ}\) its number of pair positions of type \(u\), \(b_{aQ}\) indicate whether it starts at altruist type \(a\), and \(k(Q)\) its number of pair positions. Maximize \(\sum_{Q\in\mathcal Q} k(Q)x_Q\), subject to \(\sum_Q a_{uQ}x_Q\le\mu_u\) for each \(u\in P\) and \(\sum_Q b_{aQ}x_Q\le\mu_a\) for each \(a\in A_0\).

What the mirror covers

The mirror retains KEP’s maximum-coverage objective, but does not transfer the \(O^*(6.855^t)\) bound or the paper’s representative-set, \(O^*(2^n)\) dynamic-programming, and randomized \(O^*(4^t)\) analyses in Theorems 2 and 3.

Open questions for a prover

  • Prove the typed-pattern LP pricing bound in bit complexity, including when \(l_p\) and \(l_c\) are binary encoded.
  • Establish the precise additive rounding bound from the continuous optimum to finite registries with the same type support.

The case FOR (proponent)

The strongest mirror is a high-multiplicity kidney exchange problem in which compatibility is determined by a finite set of medical types. It keeps the paper’s central decision—packing feasible chains and cycles to maximize transplants—and makes the population, rather than each named pair, the input object.

My anchor is Theorem 1, proved in this paper: given a directed compatibility graph \(G=(V,A)\), a set \(B\) of altruistic vertices with no incoming edges, chain and cycle length limits \(l_p,l_c\), and a target \(t\), KEP asks whether there is a vertex-disjoint collection of paths starting in \(B\) and cycles avoiding \(B\), each within its length limit, whose total number of edges is at least \(t\). The theorem gives a deterministic algorithm running in \(O^*(6.855^t)\) time, and the paper says it can output a packing as well. This is the paper’s main result, not a result cited from earlier work.

Here is the continuous question I would put to a prover. Let \(P\) be the finite set of donor-recipient pair types and \(A_0\) the finite set of altruistic donor types. A pair type records all medical attributes relevant to the pair’s incoming and outgoing compatibility; an altruist type records the attributes relevant to donation. Let \(\mu_u\) be the fraction of the whole registry of type \(u\), for \(u\in P\cup A_0\), with \(\sum_u\mu_u=1\). Compatibility is a directed relation from altruist or pair types to pair types. A type-level self-arc means that one pair of that type can donate to a *different* pair of the same type; it does not create an individual self-loop.

Given \(l_p,l_c\) and a target share \(\rho\) of pair recipients, consider every feasible typed exchange pattern \(Q\): either a chain \((a,p_1,\ldots,p_k)\) starting at an altruist type, with \(1\le k\le l_p\), or a cycle \((p_1,\ldots,p_k,p_1)\), with \(2\le k\le l_c\). Repeated types in a pattern refer to distinct people. Let \(x_Q\ge0\) be the mass of the population assigned to pattern \(Q\), and let \(a_{uQ}\) count how many pair positions of type \(u\) it uses. The continuous problem is to find such masses satisfying

\[ \sum_Q a_{uQ}x_Q\le \mu_u\quad(u\in P),\qquad \sum_{Q:\,Q\text{ starts at }a}x_Q\le\mu_a\quad(a\in A_0), \]

and covering at least \(\rho\sum_{u\in P}\mu_u\) pair mass, where coverage is \(\sum_Q k(Q)x_Q\) and \(k(Q)\) is the number of pair positions in \(Q\). Equivalently, compute the maximum covered pair mass. Each unit of mass receives an ordinary, integral role in a chain or cycle; the model does not make kidneys divisible.

This is a credible registry regime when many pairs share a relatively small number of medically relevant compatibility types—for example, a large regional exchange pool with a fixed clinical classification. The number of pairs \(N\) can be much larger than the number of supported types \(\tau\). A finite instance with \(n_u\) people of type \(u\) gives masses \(\mu_u=n_u/N\). The mirror preserves the paper’s exchange structures, length limits, compatibility conditions, and objective; it changes the supply of each vertex type into mass.

I expect this continuous problem to be tractable. Its natural formulation is an LP with one variable for every typed chain or cycle pattern. There may be exponentially many patterns, but the dual pricing question is to find a bounded-length path or cycle whose sum of type prices is too low relative to its covered pair mass. Since those prices add over type occurrences, pricing reduces to finding a maximum-weight walk of bounded length in the type compatibility graph, which dynamic programming can do in time polynomial in \(\tau,l_p,l_c\). Thus the LP can be optimized in polynomial time in those quantities and the input bit length; in particular, this is polynomial for fixed clinical length caps. This is an independent continuous result suggested by the structure of KEP, not a consequence of Theorem 1’s \(O^*(6.855^t)\) algorithm.

The high-multiplicity bridge is also concrete. With type-uniform compatibility and fixed support and length caps, a basic optimal LP solution uses at most one positive pattern per type constraint. Scaling by \(N\) and rounding each pattern count down gives an integral packing, losing at most \(O(\tau\max(l_p,l_c))\) transplants. So the continuous optimum supplies an additive approximation for large finite pools. A useful follow-up is to sharpen this gap and establish the precise finite-to-continuum correspondence across repeated cohorts.

The weakest point is the type assumption. If individualized crossmatch results make compatibility depend on the identity of each pair, then representing every distinction may require \(\tau\) close to \(N\), and the aggregation buys little. Also, Theorem 1 is parameterized by the number of transplants \(t\), whereas the mirror’s input target is a share of a large population; the theorem’s running-time bound does not transfer directly. The case for the mirror survives when the registry really does have many members per compatibility type: it is then the same chain-and-cycle packing question in a high-multiplicity regime.

The case AGAINST (opponent, writing after the proponent)

Theorem 1 is a real computational result, so the “nothing here to mirror” objection does not work. The strongest case against its mirror is that KEP’s input is an individual compatibility graph. Grouping pairs into types is sound only when compatibility is determined by the two types. Coarse medical categories can miss pair-specific crossmatch outcomes; refining types until they preserve every compatibility relation may leave nearly every pair in its own type. That would make the proposed high-multiplicity regime rare or unhelpful in practice.

But that does not defeat the better version of the mirror. A model with many pairs per exact compatibility type is coherent: type-level supplies constrain how often a type can appear in exchanges, so repeated types still represent distinct people. Its typed chain-and-cycle LP has a plausible pricing algorithm when length limits are fixed. And the proponent’s additive rounding argument gives it a concrete connection back to large finite registries. The paper’s \(O^*(6.855^t)\) algorithm does not establish these results; they would be separate contributions.

Cycle-and-chain formulations and their LP relaxations are already standard for finite KEP instances ([Constantino et al.](https://www.sciencedirect.com/science/article/abs/pii/S0377221713004244)). That makes the proposed LP machinery less novel, but it does not settle the compressed, high-multiplicity problem: the existing formulations still describe individual vertices. Under ChoCo’s criteria, that prior work is not a collision.

So my best negative case is about how narrow the credible type regime may be, not about a fundamental flaw in the mirror. It cannot support the requested universal claim. If exact compatibility types are common in a large registry, the mirror remains worth studying; I do not see an honest objection that rules out that scenario.
