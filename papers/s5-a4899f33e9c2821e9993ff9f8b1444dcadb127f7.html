The case FOR (proponent)

The strongest mirror is the paper’s exact computation of a linearly pooled conditional probability. Imagine a large forecasting panel in which people use one of a small number of standardized belief models over the same events. A type is a complete belief model: the shared Bayesian-network topology and all its conditional probability tables. People with identical models are indistinguishable for this computation. The mass \(\mu_t\) of a type is its fraction of the panel. This is plausible for platform-mediated or institutional forecasting where many participants use the same model template; it is a much weaker fit for a small, unstructured group of experts.

My lead is Continuous LinOP CPT Computation. An instance gives Boolean events \(A_1,\ldots,A_m\), a common Bayesian-network DAG \(G\), a target node \(A_j\) and assignment \(u\) to its parents, and \(\tau\) types with positive rational masses \(\mu_t\) summing to one. Each type supplies rational CPTs for a network \(P_t\) on \(G\). Form the pooled belief \(P_\mu(w)=\sum_t\mu_tP_t(w)\). The task is to output exactly
\[ P_\mu(A_j=1\mid \mathrm{pa}(A_j)=u) = \frac{\sum_t\mu_t P_t(A_j=1,\mathrm{pa}(A_j)=u)} {\sum_t\mu_t P_t(\mathrm{pa}(A_j)=u)}. \]
There is no manipulation variable or optimization objective here; the computational question is the exact value of the underlying pooled belief query. The input is described by \(m,\tau\), the rational bit lengths, and the network structure.

The anchor is Proposition 4, proved in this paper: “Let all input BNs have identical topologies. Then computing \(Pr_0(A_j\mid pa(A_j))\) consistent with LinOP is NP-hard.” The paper’s proof sketch uses two networks with the same topology, one arbitrary and one encoding a uniform distribution, to reduce from NP-hard Bayesian-network inference; that inference hardness is cited to Cooper (1990). The continuous version keeps the shared-topology condition and is NP-hard already with \(\tau=2\) and masses \(1/2,1/2\). A panel can contain many agents of those two types, so \(N\) can be much larger than \(\tau\) without changing the pooled query. The expected classification is hardness transfers: the reduction’s combinatorics live in the event network, not in the number of agents, and the two-source case embeds directly as a two-atom society. The result therefore does not suggest that continuization makes this computation easier.

This mirror covers Proposition 4’s LinOP CPT computation. It does not try to continuize the paper’s axiomatic claims about which independencies pooling preserves, or its LogOP algorithm. Further questions include whether bounded network width makes exact LinOP queries tractable, whether useful additive approximations are possible, and how complexity changes with \(\tau\).

The soft spot is that the paper’s weighted LinOP already assigns normalized weights to experts, so the continuous formulation is close to a re-expression of its existing model. Its case for ChoCo is strongest as a high-multiplicity regime—many forecasters grouped by complete belief type—and as a clean example where that regime leaves hardness intact. It is not evidence of a new tractability gain.

The case AGAINST (opponent, writing after the proponent)

The exact LinOP query is the strongest anchor, and its proposed population version is already the paper’s input in different language. The paper defines weighted pooling with coefficients \(a_i\ge 0\) summing to one. Set \(a_i=\mu_i\), and its pooled CPT query is exactly the proposed formula. If a large panel contains repeated belief models, their weights can be added; splitting one type’s mass among many identical people changes no input to the computation. In particular, the claimed \(\tau=2\) case is already the paper’s two-expert case with weights \(1/2,1/2\). Proposition 4 already gives the hardness result for it.

The forecasting-panel story makes the weights interpretable as population shares, but that interpretation adds no computational question. The paper’s weights may represent expert influence rather than headcount; requiring them to equal headcount shares selects a subset of the weighted-pool instances it already studies. A stronger mirror with a genuinely continuous distribution over belief models has a problem of its own: finite support reduces to weighted pooling again, while a general measure needs a new representation and integration problem beyond the paper’s stated input.

The negative case is weaker on plausibility than on novelty: a large panel with repeated, standardized belief models is conceivable. But its computation is already captured by the paper’s weighted pooling, and the most natural anchored result is therefore a collision, not a new continuous mirror. Adding mass transfers or other interventions might create new computational problems, but the paper does not study them as part of consensus construction.
