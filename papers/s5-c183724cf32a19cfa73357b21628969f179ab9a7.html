The continuous mirror question

Given types \(T\) with rational masses \(\mu_t\ge 0\), \(\sum_{t\in T}\mu_t=1\), and contract classes \(E\) between types, each with endpoint-type weak rankings, choose pair masses \(x_e\ge 0\) satisfying \(\sum_{e\ni t}d_{te}x_e\le\mu_t\), where \(d_{te}=2\) for a same-type pair and \(1\) for an ordinary endpoint. Let \(A_t(e;x)\) be the mass of type \(t\) unmatched or assigned a contract it strictly ranks below \(e\); a distinct-type contract blocks when both endpoint types have positive willing mass, and a same-type contract blocks when \(A_t(e;x)>0\). Does an algorithm polynomial in the type and contract counts, preference input length, and mass bit length return a stable \(x\) whose matched mass \(2\sum_e x_e\) is at least \(2/3\) of the maximum stable matched mass?

The model it lives in

A society is a distribution \(\mu\) over complete agent types. Decision variables \(x_e\) give the mass of pairs using each contract class; type capacities ensure each agent receives at most one integral partner, and stability rules out contracts for which positive willing masses can pair.

The objection that survived

The paper's algorithm establishes its guarantee on explicit finite instances; expanding rational masses into clones may take time polynomial in cohort size rather than mass bit length, so the proposed high-multiplicity complexity bound needs new work.

fatal: False

Open questions for a prover

  • What finite-cohort rounding or scaling result relates the mass-based blocking condition to stable roommate matchings?

The case FOR (proponent)

The strongest positive case is a high-multiplicity version of the paper’s maximum-size weakly stable roommates problem. Imagine a large university pairing students for shared housing. Many students have the same full profile for this market: the same acceptable roommate categories and the same weak ranking of contract types. If compatibility and preferences depend on these categories rather than on named individuals, a market with many thousands of students can have far fewer distinct types. The mirror is credible only in that regime; a market where everyone ranks named people differently may have almost as many types as agents.

The paper’s anchor is Theorem 2, proved here: given an arbitrary roommates graph with ties and incomplete preferences, Max-fSRTI asks for a maximum-size weakly stable *fractional matching*, and the paper gives a polynomial-time \(3/2\)-approximation, including a simpler algorithm for this special case. In full, the algorithm returns a weakly stable half-matching whose size is at least \(2/3\) of the largest weakly stable fractional matching’s size. This is the paper’s direct algorithmic result for the stability objective I want to continue. I use one anchor because the paper’s popularity results would require a less direct population-level voting model.

Here is the continuous problem I would hand to a prover: Max-Mass Weakly Stable Roommates (Max-MWSR). An instance has a finite set \(T\) of agent types; a finite set \(E\) of contract classes, each joining two types (possibly the same type); weak rankings of incident contract classes for each endpoint type; and binary-rational masses \(\mu_t\geq 0\) with \(\sum_{t\in T}\mu_t=1\). A type is a complete profile for this market, including its preferences and contract eligibility. Every pair of agents from the endpoint types can make the corresponding contract.

A solution chooses \(x_e\geq 0\), the mass of pairs formed using contract class \(e\). It must satisfy \(\sum_{e\ni t} d_{te}x_e\leq\mu_t\) for each type \(t\), where \(d_{te}=1\) for an ordinary endpoint and \(d_{te}=2\) when \(e\) pairs two agents of type \(t\). Thus each unit of population gets at most one whole partner; \(x_e\) records how much population is paired, not a fractional bundle received by each person. The objective is to maximize matched population mass, \(2\sum_e x_e\).

To state stability, let \(A_t(e;x)\) be the mass of type \(t\) that is unmatched or assigned a contract it strictly ranks below \(e\). Equivalently, \(A_t(e;x)=\mu_t-\sum_{f\ni t}d_{tf}x_f+\sum_{f\ni t:\,e\succ_t f}d_{tf}x_f\). A contract between distinct types \(t,s\) blocks if both \(A_t(e;x)>0\) and \(A_s(e;x)>0\): positive amounts of both populations can form it and strictly improve. A same-type contract blocks if \(A_t(e;x)>0\), since any positive mass can be split into two disjoint submasses. A solution is weakly stable when no contract blocks. The concrete approximation question is whether there is an algorithm, polynomial in the number of types, contract classes, preference input, and mass bit length, that returns a stable \(x\) with matched mass at least \(2/3\) of optimum.

I expect a Class A answer for a constant-factor approximation, and \(3/2\) is the natural first target from Theorem 2. The continuous input describes the repeated population directly, without expanding it into a huge list of named agents. The paper’s edge-copy construction and stable-half-matching algorithm offer a plausible starting point for a capacity-aware version. This is a research question, though: Theorem 2 does not itself establish the bound for rational type masses or for this mass-based blocking condition.

The bridge to the paper is that mass assignments aggregate matches among interchangeable agents, while weak stability still means that no mutually acceptable pair can improve strictly on both sides. For a finite cohort, type masses on an \(1/N\) grid can be represented by \(N\mu_t\) clones per type, with contract classes expanded across eligible clones. The clone model also makes the boundary visible: within-type pairs require two distinct willing clones, while the continuum permits arbitrarily small positive submasses. A formal finite-to-continuum dictionary, including this rounding boundary, is one of the follow-up questions.

The mirror covers Theorem 2’s weak-stability objective and approximation guarantee; it does not claim to continuize the paper’s popularity results or its \(\gamma\)-stability generalization. Further questions are whether the \(3/2\) guarantee survives capacity-based mass directly, whether the optimum can be found exactly when \(\tau\) is small, and how well continuous solutions round to finite cohorts.

My weakest point is the change from fractional assignments at individually specified vertices to population masses partitioned among integral pairings. That change is what makes the society genuinely continuous while keeping each person’s match indivisible, but it means the stability condition must be restated in terms of willing mass rather than copied verbatim from Max-fSRTI. The model also assumes compatibility is determined by types, so it cannot compress arbitrary named-person constraints. I think the authors would recognize it as their stable-roommates problem in a high-multiplicity regime, but the \(3/2\) result for this exact mass model remains to be proved.

The case AGAINST (opponent, writing after the proponent)

The strongest objection is that Theorem 2 is about a finite graph of named vertices and fractional edge assignments, while the proposed mirror uses type-level pair masses and declares a contract blocking when positive amounts of both endpoint populations would prefer it. Its edge-copy proof does not automatically give a \(3/2\)-approximation for that model. Compressing agents into types also restricts the graph: members of a type must share their contract eligibility and rankings.

That objection does not defeat the mirror. Those restrictions describe a genuine high-multiplicity regime, and the quotient graph on types can still contain arbitrary non-bipartite structure. With identical preferences within each type, positive mass assigned to worse contracts corresponds to positive mass willing to block; for rational masses and assignments, scaling gives a finite cohort of clones. Treating each person’s match as integral while allowing the cohort to split across contracts is a natural population-level version of the paper’s fractional matching model.

So the algorithm’s failure to transfer directly is the question to investigate, not a reason to dismiss it. Theorem 2 is a named computational result, and the paper’s fractional assignments do not already make the population continuous. I can’t make an honest case that this anchor fails: the proposed mirror survives.
