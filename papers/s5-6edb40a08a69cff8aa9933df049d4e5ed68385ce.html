The continuous mirror question

Given a finite set of types \(T\), rational masses \(\mu_t\geq 0\) summing to \(1\), a maximum team size \(K\), and strict rankings \(\succ_t\) over integral team compositions \(q\in\{0,\ldots,K\}^{T}\) with \(1\leq\sum_t q_t\leq K\) and \(q_t>0\), does there exist a core-stable allocation, and can one be returned? An allocation is a vector of team densities \(\lambda_q\geq 0\) satisfying \(\sum_q q_t\lambda_q=\mu_t\) for each \(t\). For each possible team \(q\), let \(b_t(q,\lambda)=\sum_{r:r_t>0,\ q\succ_t r} r_t\lambda_r\). It is stable exactly when no \(q\) has \(b_t(q,\lambda)>0\) for every type \(t\) with \(q_t>0\), so each formed team remains finite and integral while the population mass is continuous.

The model it lives in

A continuum of agents divided among finitely many complete preference types \(t\), with rational masses \(\mu_t\). Decision variables \(\lambda_q\) give the density of finite, integral teams of composition \(q\); the constraints conserve each type’s mass, and stability excludes any composition that can be formed at positive density from agents who all strictly prefer it to their assigned teams.

What the mirror covers

The mirror covers existence of a core-stable allocation in a typed population; it leaves out the empirical distribution of core sizes, fitted distributions, and the paper’s random-game sampling results.

Open questions for a prover

  • What is the complexity of typed continuum core existence as a function of \(|T|\), \(K\), and the input bit length?
  • Do fixed \(|T|\) or fixed \(K\) yield tractable algorithms, and is there a hardness result when both vary?

The case FOR (proponent)

My lead is a typed continuum core-existence problem, anchored—somewhat narrowly—on Lemma 4, proved in this paper. Lemma 4 says that any finite hedonic game with strict transitive preferences can be represented by an \(n\times 2^{n-1}\) matrix: row \(i\) records player \(i\)’s ranking of the \(2^{n-1}\) coalitions containing them, with each row a permutation of \(1,\ldots,2^{n-1}\). The paper uses this preference representation in its computation of core partitions; Corollary 2 gives the converse representation. The underlying problem I mirror is finding the set of partitions unblocked by any coalition, in particular deciding whether that set is nonempty—not the matrix encoding itself.

Here is a plausible high-multiplicity regime: a large robot swarm with a small number \(\tau\) of role types, where many robots of each type share the same strict ranking over feasible team compositions. Let \(\mu_t\) be the fraction of the population of type \(t\), with rational \(\mu_t\geq 0\) and \(\sum_t\mu_t=1\). Fix a maximum team size \(K\), and let \(\mathcal Q\) be the nonzero integer vectors \(q\in\{0,\ldots,K\}^{\tau}\) with \(\sum_t q_t\leq K\). Each type \(t\) is given a strict ranking \(\succ_t\) over the configurations \(q\in\mathcal Q\) with \(q_t>0\).

Call the resulting problem Typed Continuum Core Existence. A candidate solution is a vector \(\lambda_q\geq0\), where \(\lambda_q\) is the density of teams with composition \(q\), satisfying
\[ \sum_{q\in\mathcal Q}q_t\lambda_q=\mu_t\qquad\text{for every type }t. \]
For a possible deviating configuration \(q\), define the mass of type \(t\) currently assigned to worse teams as
\[ b_t(q,\lambda)=\sum_{\substack{r\in\mathcal Q:\ r_t>0\\q\succ_t r}}r_t\lambda_r. \]
The allocation is stable exactly when there is no \(q\) for which \(b_t(q,\lambda)>0\) for every type \(t\) with \(q_t>0\): such positive supplies would allow a positive density of teams of configuration \(q\) to form, with every participating type strictly preferring to deviate. The task is to decide whether a stable \(\lambda\) exists and, if so, return one. Mass stays continuous while each team remains a finite, integral bundle of agents.

I would provisionally expect this problem to be continuum-specifically hard (Class C): feasibility is linear, but stability imposes a combinatorial choice of which types must lack a positive supply of agents who would prefer each possible blocking team. That is a reason to investigate hardness, not a hardness result. The cited claim in §3.2 that core nonemptiness is NP-complete is attributed to Ballester (2004); it is not a numbered complexity result of this paper, and fractional team densities mean discrete hardness does not automatically transfer. Further questions include whether fixed \(\tau\) or \(K\) makes the problem tractable, and what continuum statistic could replace the paper’s count of core partitions.

The regime is plausible for large populations of repeated robot roles, with the number of agents far exceeding \(\tau\). Its main weakness is also substantial: the paper’s random games rank coalitions of named players, whereas this mirror ranks team compositions. Under independent random rankings of named subsets, players will generally have distinct complete types, so the paper’s Monte Carlo experiment itself does not have a small-support continuum limit. The mirror is recognizable as a type-homogeneous hedonic core problem, but it covers core existence, not the paper’s empirical distribution of core sizes. Lemma 4 is also a borderline anchor: it is a named representation used in computation, not a numbered complexity classification. If the formulation exception is read narrowly, this paper has no qualifying named computational result; its numbered lemmas and corollaries establish representation facts, not complexity bounds.

The case AGAINST (opponent, writing after the proponent)

Lemma 4 is a weak anchor for a continuous mirror. It encodes each named player’s strict ranking of the \(2^{n-1}\) coalitions containing them; it proves no computational result. The paper’s main computational output is an empirical distribution from finite random games. Its only complexity claim about core existence is attributed to Ballester (2004), rather than proved here. Core existence is the strongest problem to salvage, since the paper computes core partitions, but that means the mirror is attached to the paper’s computational task, not to Lemma 4 as a result.

The paper’s random model gives no fixed finite type space to carry into a population limit. As \(n\) grows, each player’s alternatives are coalitions of a changing set of named players, and the paper independently samples full rankings over those alternatives. Its model supplies neither a bounded-support type distribution nor a canonical way to aggregate those rankings into one. With exact types, the type domain grows with \(n\); the paper’s Monte Carlo ensemble therefore has no evident high-multiplicity limit of the proposed form.

The strongest repair is the proposed model of finitely many robot roles, with preferences over team compositions of size at most \(K\). That is a coherent core-existence problem, and the robot-swarm scenario is plausible. But it changes the input from rankings of named-player coalitions to rankings of anonymous compositions, and replaces the paper’s random-game experiment with a new choice of role types and preference law. The paper’s results do not determine that law or transfer its empirical core-size findings to the new model. This is a good argument against calling it a mirror of this paper; it does not show that the new problem lacks research value.

So the negative case is strong on attribution and weak on the universal claim. The typed formulation avoids an obvious continuum degeneracy: finite teams can still form from positive masses of each role. I cannot honestly rule out a worthwhile continuous hedonic-core project in that regime. I would reject Lemma 4 as a result anchor for this paper, while acknowledging that the broader core-existence question could survive the reader’s gate if the standard is simply whether the authors would recognize it as their problem.
