The continuous mirror question

Given a finite multigraph template \(H=(R,F)\) with rational additive endpoint valuations normalized so each role values some incident edge at \(1\), consider copies indexed by \(x\in[0,1]\). Each role \(r\) has population share \(1/|R|\); each edge \((f,x)\) is indivisible and assigned to an endpoint in its copy, and agents value only goods in their own copy according to the template valuations. Can an algorithm compute measurable orientations and nonnegative payments \(p_r(x)\) that are envy-free between every pair of agents, including agents in different copies, and satisfy \(\frac{1}{|R|}\sum_{r\in R}\int_0^1 p_r(x)\,dx\le\frac12\)?

The model it lives in

A continuum of exchangeable copies of a finite graph orientation instance. Roles are population types, each local edge remains an indivisible good, and agents receive integral bundles; the aggregate subsidy is the population-average payment. A template orientation and role payments, repeated across copies, provide a finite representation of a measurable solution.

What the mirror covers

The mirror covers Theorem 2’s polynomial-time subsidy guarantee for repeated templates. It does not cover the paper’s EFX discussion, minimum subsidy for each instance, or extensions to general valuations and non-repeating networks.

Open questions for a prover

  • For continuum populations with heterogeneous local graph structures rather than repeated templates, does the same average subsidy bound admit a computational guarantee while preserving integral bundles and pairwise envy-freeness?

The case FOR (proponent)

The strongest anchor is Theorem 2, proved in this paper: for every multigraph with \(n\) agents, a polynomial-time algorithm computes an envy-free orientation with total subsidy at most \(\lfloor n/2\rfloor\). This is a constructive guarantee, not a result that minimizes subsidy for each instance. The paper’s cited NP-hardness result concerns EFX orientations, a different fairness condition, so I would not use it as an anchor here.

A continuous version I would trust is Replica-Template EF Subsidy. Its input is a finite multigraph template \(H=(R,F)\), with rational additive values \(v_r(f)\) for each endpoint \(r\) of each edge \(f\), and \(\max_{f\ni r}v_r(f)=1\) for every role \(r\). Make a continuum of copies indexed by \(x\in[0,1]\): copy \(x\) has agents \((r,x)\) and indivisible goods \((f,x)\), each assignable only to an endpoint of \(f\). Agent \((r,x)\) values the goods incident to role \(r\) in that copy according to \(v_r\), and values other goods at zero. The role types have equal mass, so each has population share \(1/|R|\). The task is to compute a measurable orientation and nonnegative payments \(p_r(x)\) that are envy-free between all agents and satisfy
\[ \sum_{r\in R}\int_0^1 p_r(x)\,dx\le |R|/2. \]
A solution is an integral bundle for each individual agent, not a fractional bundle; only the population and total subsidy are measured continuously.

The regime is a large institution made of many repeated local allocation networks: for example, recurring service units in which each indivisible resource is available to exactly two neighboring roles, and agents value only resources incident to them. People in the same role share the same valuation parameters and position in the local network; copy labels distinguish resources but carry no preference information. With \(K\) copies, there are \(K|R|\) agents but only \(|R|\) role types. That is a genuine high-multiplicity regime, though it is stylized.

The lift from Theorem 2 is direct. Run its algorithm once on \(H\), then repeat the resulting orientation and role payments in every copy. Envy within a copy follows from the theorem. Across copies, an agent values another copy’s bundle at zero; envy-freeness within \(H\), together with nonnegative values, ensures their own utility is at least every other role’s payment. Total subsidy is at most \(\lfloor |R|/2\rfloor\), hence at most \(|R|/2\). The algorithm runs in polynomial time in the template’s size and input bit length. A repeated single-edge template, with both endpoints valuing the edge at \(1\), also shows why the per-agent bound \(1/2\) is tight: each copy needs total subsidy at least \(1\).

I expect this particular mirror to be tractable. The authors should recognize it as their graph-orientation problem with the population replicated across identical network roles. It preserves the central ingredients—indivisible edge goods, endpoint restrictions, additive valuations, envy, and objective payments—rather than making the goods or fairness condition fractional.

The scope is Theorem 2’s subsidy guarantee and constructive algorithm, in repeated-template populations. It does not cover the paper’s EFX discussion or claim that the algorithm finds the minimum subsidy for each input. Further questions include whether the same bound holds for non-repeating continuum networks, how to define and compute envy-free allocations when local graph structure varies across types, and what changes for more general valuation or incidence models.

The weak point is that this is a narrow, periodic regime: the solution can be obtained by solving one finite template and repeating it. So this is a clean high-multiplicity mirror of the named result, but not evidence that continuization reveals a new algorithmic phenomenon. Its plausibility also relies on treating copy-specific item labels as interchangeable under the graph’s relabeling symmetry.

The case AGAINST (opponent, writing after the proponent)

Theorem 2 is a genuine computational anchor: it gives a polynomial-time algorithm for producing an envy-free orientation with total subsidy at most \(\lfloor n/2\rfloor\). The paper’s EFX hardness result concerns a different problem and does not weaken this anchor.

The strongest objection is that a role \(r\) is not automatically a complete type in a repeated-template population. An agent \((r,x)\) values edges in copy \(x\), while \((r,y)\) values edges in copy \(y\). Their feasible bundles and valuations over the global set of goods differ, and envy comparisons depend on whether two agents share a copy. A distribution over role labels alone does not encode that incidence relation. A broader model would need to retain the copy structure, perhaps as a distribution over whole graph components. A graphon-style aggregate of edge mass would preserve less: it could turn indivisible edges into fractional resources and lose the individual envy constraints the theorem addresses.

That objection does not defeat the proposed repeated-template mirror. The copy index is structurally interchangeable, and a finite template records the local incidence pattern. With that structure, the authors’ algorithm can be run on the template and repeated across copies; the stated subsidy guarantee and cross-copy envy argument follow. The resulting question is narrow and its solution reduces to a finite instance, which makes its algorithmic payoff modest. But modest payoff and a direct reduction are not grounds for rejecting a well-posed mirror under the programme’s criteria.

So I cannot honestly make the requested universal negative case. The repeated-template scenario is plausible, and the type objection can be answered by treating copies as isomorphic local environments. The negative case is weak precisely at its only anchor: unless the authors reject that relational population model as outside their problem, Theorem 2 survives.
