The continuous mirror question

Given a finite type set \(T\), source set \(M\), positive rational masses \(\mu_t\) summing to \(1\), and a symmetric nonnegative rational cost matrix \(C\) on \(T\cup M\), treat each type as a cohort connected through a shared terminal with zero-cost within-type links. For each distinct positive cost \(\lambda_q\), let \(D^q_{uv}=1\) when \(c_{uv}\ge\lambda_q\) and \(0\) otherwise; let \(P_q\) be the components of its zero-cost graph, \(p_q\) the number containing a source, and \(S_q(t)\) the component containing \(t\). With \(\mu(S)=\sum_{u\in S\cap T}\mu_u\), compute each type's aggregate payment \(A_t=\mu_t\sum_q(\lambda_q-\lambda_{q-1})\left(p_q-1+\frac{\mathbf{1}[S_q(t)\cap M=\varnothing]}{\mu(S_q(t))}\right)\), where \(\lambda_0=0\); determine whether the mass-weighted painting procedure always returns this vector, independently of the minimum tree and source-connecting choices.

The model it lives in

A finite quotient network on type terminals \(T\) and sources \(M\), with type \(t\) carrying mass \(\mu_t\) and zero-cost links within its cohort; the output is each type's aggregate share of the minimum tree cost under the threshold-component formula for \(A_t\).

What the mirror covers

It covers Proposition 2's painting-to-folk allocation identity for cohorts connected through shared type terminals; it leaves Theorem 1's axiomatic characterization and unrestricted individual cost matrices aside.

Open questions for a prover

  • For every rational mass distribution, is the mass-weighted painting procedure independent of all tree choices and equal to \(A_t\) for each type?
  • What is the running time for computing \(A\) in \(|T|\), \(|M|\), and the input bit length?

The case FOR (proponent)

My strongest positive case is narrow: the paper’s painting construction has a credible high-multiplicity mirror, but the paper does not establish a named complexity result of the kind the programme most wants.

The anchor is Proposition 2, proved in this paper. It states that for every multiple-source spanning-tree problem \((N,M,C)\) and every minimal tree \(t\), the painting allocation \(f^{P,t}(N,M,C)\) equals the folk rule \(F(N,M,C)\). Thus the painting result does not depend on the choice of minimal tree or on the Phase 1 tree used to connect the sources. This is a computational correctness result: the painting procedure computes the same allocation as the folk rule. It is not, however, a theorem that the problem is in P or hard, and the paper gives no numbered complexity classification. Theorem 1 is an axiomatic characterization, so I would not use it as a computational anchor.

My lead mirror would be Mass-Weighted Folk Allocation. Its instance is a finite support \(T\) of agent types, a finite source set \(M\), rational masses \(\mu_t>0\) summing to \(1\), and a symmetric nonnegative rational cost matrix \(C\) on \(T\cup M\). A type is a cohort at a shared connection terminal: its members have the same connection-cost profile, and their local links to that terminal are free. A society with millions of agents but only tens of such cohorts is a plausible regime—for example, customers served through a finite set of municipal or industrial connection hubs. The decision variable is the type-level allocation of the minimum network’s cost. The underlying network objective remains to minimize total connection cost; the allocation problem itself asks for the payment vector the rule prescribes.

Here is a precise version. List the distinct positive edge costs as \(0<\lambda_1<\cdots<\lambda_r\), and set \(\lambda_0=0\). For each \(q\), let \(D^q_{uv}=1\) when \(c_{uv}\ge\lambda_q\), and \(D^q_{uv}=0\) otherwise. Let \(P_q\) be the connected components of the zero-cost graph for \(D^q\), and let \(p_q\) count those components that contain a source. For type \(t\), write \(S_q(t)\) for its component, and \(\mu(S_q(t))\) for the total mass of agent types in that component. The requested solution is the aggregate payment \(A_t\) for each type, where

\(A_t=\mu_t\sum_{q=1}^{r}(\lambda_q-\lambda_{q-1})\left(p_q-1+\frac{\mathbf{1}[S_q(t)\cap M=\varnothing]}{\mu(S_q(t))}\right).\)

This is the mass-weighted version of the paper’s simple-problem folk-rule formula, extended over a canonical threshold decomposition. The output is a rational vector \(A\), with total payments equal to the minimum tree cost.

The paper’s painting procedure suggests how to compute the same vector: find a minimum tree on the type terminals and sources, connect the sources as in Phase 1, then paint each unfinished edge by the mass of types currently assigned to it. If edge \(e\) has assigned mass \(Q_e\), a painting increment \(\Delta\) charges type \(t\) an aggregate amount \(\mu_t\Delta/Q_e\). The cost of the source tree is divided in proportion to mass. The question corresponding to Proposition 2 is whether this mass-based procedure always returns the displayed allocation, independently of the choices of minimum trees and source-connecting tree.

I expect this problem to be tractable in \(\tau=|T|\), \(|M|\), and the input bit length: there are at most \(\binom{\tau+|M|}{2}\) cost levels, and each level requires only a component calculation. The painting implementation also has finitely many edge-removal stages. This tractability assessment is mine; the paper does not state it as a complexity theorem.

There is a concrete high-multiplicity bridge. For rational \(\mu\), choose \(n\) with \(n\mu_t\) integral and replace each type by \(n\mu_t\) named agents, joining agents of the same type at zero cost. On these instances, aggregating the discrete folk-rule payments by type gives exactly the mass-weighted formula above. That makes the mirror an exact identity for a sensible instance regime, not just a continuous reinterpretation of the story.

The mirror covers Proposition 2’s painting-to-folk computation, not the paper’s full axiomatic characterization or arbitrary agent-specific cost matrices. The follow-up questions are whether the continuous painting procedure is choice-independent, whether this weighted rule inherits the paper’s axioms, and what changes when members of a type have nonzero costs between them.

The weak point is that the shared-terminal assumption materially restricts the original model: the paper allows arbitrary pairwise costs among individual agents. It is plausible for cohorts sharing infrastructure, and the discrete aggregation identity supports it, but authors could reasonably regard it as a specialized instance family. Also, Proposition 2 supplies correctness, not a complexity separation or a hard problem whose hardness might dissolve. This is a modest positive case for a continuous mirror, not evidence that the paper opens a substantial new complexity landscape.

The case AGAINST (opponent, writing after the proponent)

Proposition 2 is the only plausible anchor, but it proves an identity between two allocation rules on finite instances; it does not state a complexity result. The paper gives no complexity classification for computing the allocation. Its named characterization is axiomatic, and it describes minimum-tree construction as polynomial. So the proposed mirror adds a mass-weighted allocation problem; it does not continuize a computational question the paper itself investigates.

The strongest version of that mirror is coherent. Treat each type as a shared connection terminal, give its cohort mass \(\mu_t\), and let agents within the cohort connect to the terminal for free. For rational masses, cloning each terminal into the corresponding number of agents yields the proposed aggregate formula from the finite folk rule. That is a real high-multiplicity regime, and the shared-hub scenario is plausible. I would not reject it on the grounds that the population cannot have repeated types.

The limitation is what that bridge actually carries: the network still has one vertex per type, while mass enters the cost allocation. The continuous painting question is therefore about extending an allocation identity over that quotient network, not about computation on a continuum of agents. If we instead require each resident to have an individual connection in the network, positive within-cohort costs or location differences must be modeled. Then the finite spanning-tree object no longer gives a canonical continuous network or painting procedure. A hub model can avoid that issue, but it does so by making the type representative the network terminal.

That is the best case against: under ChoCo’s narrow aim of charting computational complexity, this paper offers little to continuize because it supplies no such classification. It is not a strong universal case. The shared-hub mirror is sensible, and an exact discrete-to-continuous identity could itself be worthwhile. The negative argument weakens if the programme counts new continuous allocation identities as computational contributions.
