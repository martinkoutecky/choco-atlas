The continuous mirror question

Given finite \(S\), finite priority-cohort types \(\Theta\), rational masses \(\mu_\theta\), rational per-capita capacities \(q_s\) with \(\sum_s q_s=1\), a finite rational distribution \(\nu\) over common strict rankings \(\Pi\), and strict inter-cohort relations \(\succ_s\), choose a type order \(\sigma:[0,1]\to\Theta\) with \(\lambda(\sigma^{-1}(\theta))=\mu_\theta\), encoded by rational block lengths and at most \(K\) blocks. Run serial dictatorship along \(\sigma\), let \(a_{\sigma,\Pi}(u)\) be the assigned object at position \(u\), and minimize \(J(\sigma)=\mathbb{E}_{\Pi\sim\nu}\left[\int_0^1\int_u^1 \mathbf{1}[a_{\sigma,\Pi}(u)\succ_\Pi a_{\sigma,\Pi}(v)]\mathbf{1}[\sigma(v)\succ_{a_{\sigma,\Pi}(u)}\sigma(u)]\,dv\,du\right]\), or decide whether \(J(\sigma)\le B\); ties within a cohort do not create justified envy.

The model it lives in

A high-multiplicity priority-cohort version of SD: types \(\theta\) carry masses \(\mu_\theta\) and object-specific cohort priorities, objects have per-capita capacities \(q_s\), and a finite block-coded mass order \(\sigma\) is chosen independently of realized common preferences to minimize expected pairwise justified-envy mass \(J(\sigma)\).

The objection that survived

Unrestricted mass orders can split a priority type across capacity blocks, so the resulting objective need not be a positive scaling of Kemeny disagreement; the proposed Class B hardness transfer is therefore unsupported.

fatal: False

What the mirror covers

The mirror covers the common-preference optimization in Theorem 1, the nonuniform preference distribution in Proposition 1, and the capacity extension in Proposition 3; it leaves Proposition 2's independent-preference analysis and the unnumbered approximation discussion untouched.

Open questions for a prover

  • Does every instance admit an optimal order with polynomially boundedly many blocks, or an efficiently computable \(\varepsilon\)-optimal rational order?
  • What is the complexity of the bounded-block decision problem, and does hardness arise from priorities, type structure, or continuum interleaving?
  • What tie-handling and rounding theorem relates cohort priorities and \(J(\sigma)\) to finite strict-priority SD markets?

The case FOR (proponent)

The strongest honest case is a qualified yes: the paper admits a natural continuous-population mirror, probably in Class B, but it fails the programme’s strict computational-anchor requirement.

The paper’s strongest candidate is Theorem 1, proved in the paper:

If preferences are identical across agents and uniformly distributed, and objects have unit capacities, the serial order minimizing the expected number of justified-envy cases is a Kemeny ranking of the objects’ priority rankings over agents.

This is a genuine optimization result, although not itself a complexity classification. The paper’s only explicit complexity claim— that computing a Kemeny ranking is NP-hard—is an unnumbered Section 5 discussion citing Bartholdi et al.; it is not proved as a numbered result here.

A continuous mirror would be Continuous Kemeny-SD Fairness. Let \(S\) be a finite set of school or housing categories. Let \(\Theta\) be a finite set of priority cohorts. A type \(\theta\in\Theta\) specifies the cohort’s priority position at every object; \(\mu_\theta\) is its population mass, with \(\sum_\theta\mu_\theta=1\). Objects have per-capita capacities \(q_s\), with \(\sum_s q_s=1\). The lead case takes \(q_s=1/|S|\). All agents share a common strict preference ranking \(\Pi\), drawn from the uniform distribution over rankings of \(S\). The planner must choose a serial mass order \(\sigma:[0,1]\to\Theta\), with \(\lambda(\sigma^{-1}(\theta))=\mu_\theta\), before observing \(\Pi\), so the order may depend on priorities and the preference distribution but not on realized preferences.

Run serial dictatorship along \(\sigma\): each infinitesimal agent receives her most-preferred object with remaining capacity. If \(a_{\sigma,\Pi}(u)\) is the object assigned at position \(u\), the objective is to minimize the expected normalized number of justified-envy cases
\[ J(\sigma)=\mathbb{E}_{\Pi}\!\left[\int_0^1\int_u^1 \mathbf{1}\!\left[a_{\sigma,\Pi}(u)\succ_\Pi a_{\sigma,\Pi}(v)\right] \mathbf{1}\!\left[\sigma(v)\succ_{a_{\sigma,\Pi}(u)}\sigma(u)\right]\,dv\,du\right]. \]
A solution is an optimal measurable mass order, or an \(\varepsilon\)-optimal rational piecewise-constant order. The decision version asks whether some admissible order has \(J(\sigma)\le B\).

This is a credible regime for school choice, public housing, or dormitory allocation with very large cohorts sharing the same eligibility and priority profile—residency, sibling status, disability category, or lottery class—while the number of distinct priority types is small relative to the population. Each person still receives an integral school seat; only aggregate type assignments are fractional. A finite realization with rational masses is obtained by taking \(N\mu_\theta\) agents and \(Nq_s\) seats, so the continuous objective is exactly the finite expected envy count divided by \(N^2\).

The mirror is recognizably the authors’ problem: the action is still a preference-independent serial order, the outcome is still serial dictatorship, and the objective is still expected justified envy. The only necessary co-modifications are population masses and capacities scaling with population size. Proposition 3, proved in the paper, explicitly studies non-unit capacities and therefore supports this scaling; Proposition 1 supports replacing the uniform common-preference law by arbitrary positional probabilities \(p(s,t)\).

I would expect this mirror to be Class B. With \(m=|\Theta|=|S|\), equal masses, equal capacities, and uniform \(\Pi\), the objective is a positive scaling of the Kemeny disagreement objective. Thus Kemeny hardness transfers through the distinct priority types; increasing the number of copies of each type does not remove the combinatorics. The continuum may help with representation, approximation, and parameterized analysis, but it does not make this general problem tractable merely by removing population multiplicity.

The weakest point is that strict priorities over named individuals do not naturally survive high multiplicity: repeated cohorts create priority ties, requiring a weak-priority or cohort-priority convention. Also, in the simplest uniform case the continuum is partly a normalization of Kemeny rather than a dramatic new phenomenon. Nevertheless, the mirror is substantively faithful and opens concrete questions about approximation, fixed-parameter algorithms in the number of priority types, optimal interleaving of cohorts, capacity heterogeneity, and finite-population rounding.

So the positive case is strong on model plausibility, but formally limited: Theorem 1 provides a good structural anchor, while the paper contains no numbered theorem asserting a qualifying complexity result.

The case AGAINST (opponent, writing after the proponent)

The strongest negative case is that the proposed mirror does not actually preserve Theorem 1’s instance regime.

Theorem 1 assumes one agent per object and unit capacities. If we replicate agents while keeping the object set \(S\) fixed, capacities must scale to \(Nq_s\). That is no longer Theorem 1’s model; it is the many-to-one extension in Proposition 3. If instead capacities remain unit, then \(|S|\) must grow with \(N\), and each object’s strict priority ranking is over an ever-growing set of named individuals. There is then no fixed finite type space with positive mass per type.

This exposes the deeper problem: strict priority is not a replicable individual attribute. An agent’s position in \(\succ_s\) is defined relative to the other named agents. Duplicating a “priority type” creates ties, whereas the paper’s justified envy relation uses strict \(i\succ_s j\). Resolving those ties by a deterministic lottery restores individual identity; treating ties as equal priority changes the fairness relation; random tie-breaking adds a new stochastic primitive. A priority-cohort model may be reasonable school-choice theory, but it is not simply the high-multiplicity version of the paper’s strict-priority model.

The proposed mass-order formulation also fails to reproduce the claimed Kemeny identity. Consider two schools \(a,b\), two priority types \(A,B\), each of mass \(1/2\), capacities \(1/2\), and common preferences uniformly distributed over \(a\succ b\) and \(b\succ a\). Let \(B\succ_a A\) and \(A\succ_b B\). A contiguous order \(A\) then \(B\) gives expected normalized envy \(1/8\), matching the relevant Kemeny-style ordering. But the admissible mass order

\[ A\;B\;A\;B \]

with each block of mass \(1/4\) gives expected envy \(1/16\): each type is split across the two capacity blocks, so many cross-type pairs receive the same school and cannot form envy. Thus the proposed continuum is not a positive scaling of Kemeny. To recover Kemeny, one must impose that every type occupy one contiguous block, an extra restriction absent from serial dictatorship. If splitting is allowed, the mirror becomes a different fractional scheduling problem.

Propositions 1 and 3 do not repair this. Proposition 3 already handles the finite capacity-scaling step, while Proposition 1 merely replaces discrete positional probabilities by their continuous analogue. The paper supplies no named complexity theorem for the resulting infinite-dimensional optimization: a measurable \(\sigma\) has no finite input encoding, and “\(\varepsilon\)-optimal rational piecewise-constant order” requires an additional bound on representation size or alternation. Imposing such a bound changes the problem; taking a finite high-multiplicity limit returns a sequence of finite problems rather than the paper’s stated optimization problem.

This defeats the proponent’s specific mirror and its claimed Class B reduction. It does not, however, justify a universal negative. Once one explicitly changes strict priorities into priority cohorts, scales capacities per capita, and defines envy by pair mass, a coherent continuous school-choice problem does exist. The interleaving example even suggests a potentially interesting fractional relaxation. My honest conclusion is therefore that the paper’s actual anchor is weak and the proposed formulation is not faithful as stated, but “no worthwhile continuous mirror in any scenario” is not defensible: the cohort-based variant survives as a legitimate, if substantially remodeled, research question.
