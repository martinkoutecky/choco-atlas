The case FOR (proponent)

There is no named computational result in this paper to anchor a ChoCo mirror. The strongest nearby result is Theorem 1, proved here: for a cost-sharing instance \(\langle N,\pi,a\rangle\), if the marginal cost \(\pi'\) is convex, the average-cost allocation majorizes the Shapley allocation; if \(\pi'\) is concave, the Shapley allocation majorizes the average-cost allocation. That is a theorem about allocation inequality, not about an algorithm or a complexity class. The paper calls the Shapley value computationally demanding, but gives no named result establishing hardness, tractability, or an algorithm. Its other numbered results are allocation properties or steps in the proof; Proposition 1 is cited from Sudhölter (1998).

The strongest plausible population-continuum analogue would take a distribution \(\mu\) over agents’ input sizes \(a\), with mass \(\mu(da)\) of each type and aggregate input \(A=\int a\,d\mu\). The average-cost allocation density is \(a\pi(A)/A\). Define the continuum Shapley allocation as the limit of finite replications in which each agent’s input is scaled by the population size. Its density is \(a\int_0^1\pi'(uA)\,du=a\pi(A)/A\), so the two allocations coincide in that limit. This is a plausible population continuization, but its central question is an allocation-inequality question, and the limiting comparison is equality. It does not supply the computational question or named computational anchor the programme requires.

So I can identify a nearby continuous analogue, but I would not present it as a qualifying positive case: doing so would stretch an analytical cost-sharing result into a computational claim the paper does not make.

The case AGAINST (opponent, writing after the proponent)

The sole plausible anchor is Theorem 1, and it is an analytical comparison of allocations, not a computational result. The paper gives no complexity claim, algorithm, or computational problem with an encoding of the cost function. Calling the Shapley value “computationally demanding” does not supply those missing pieces. A question about computing Shapley allocations could be worthwhile on its own, but the paper does not formulate it, and a continuous version would be an added project rather than a mirror.

The strongest population mirror uses a distribution of input types with aggregate input \(A=\int a\,d\mu\). In the nonatomic limit, the Shapley allocation density for type \(a\) is
\[ a\int_0^1 \pi'(uA)\,du = a\frac{\pi(A)}{A}, \]
which is exactly average-cost pricing. The per-capita allocation remains meaningful; what disappears is the distinction Theorem 1 compares. Its Lorenz order becomes equality, regardless of the curvature condition. That identity may be mathematically neat, but it creates no computational question.

Keeping finitely many input types does not rescue the comparison: their per-capita allocations still coincide in the nonatomic limit. Treating each type as one player instead preserves a finite Shapley game, but then the population has not been continuized. Nor does the richer, multivariate version in Section 3.2 provide a computational anchor: the natural nonatomic Shapley counterpart is the Aumann–Shapley path allocation, which the paper itself identifies. Comparing it with other allocations could yield new analytic results, but not the computational complexity landscape ChoCo targets. The paper may suit a high-multiplicity regime; the case against rests on the mismatch between its allocation-inequality contribution and the programme’s computational questions.
