The continuous mirror question

Given a rational distribution \(\mu\) over complete cost types \(t\), with \(v_t(e)\in\{0,-c_e\}\), and rational per-capita supplies \(b_e\) for \(r\) task classes, construct one succinct randomized direct mechanism that works at every admissible scale \(q\), where \(q\mu_t\) workers have type \(t\) and \(qb_e\) copies of task class \(e\) are allocated. Does it produce a lottery over integral allocations satisfying Theorem 4.4's strategyproofness, fairness, and efficiency guarantees at each scale?

The model it lives in

The society is the type distribution \(\mu\); each type is a complete cost vector and each task class has a common per-unit cost \(c_e\). At scale \(q\), the mechanism receives the finite workers' reports and allocates \(qb_e\) indivisible task copies, outputting a sampled integral allocation. The computational objective is a compact mechanism description and sampler, with construction time polynomial in the number of task classes, the type-support size, and input bit length; allocation time may depend on the realized population.

What the mirror covers

The mirror covers Theorem 4.4 for 1-restricted additive chores. It leaves the deterministic impossibility results and the mixed-items mechanism in Theorem 5.1 aside.

The case FOR (proponent)

The strongest positive case is a high-multiplicity version of the chore-allocation result in Section 4. Each type should be a complete cost vector, so agents of one type agree on the cost of every task. A realistic regime is a large workforce handling recurring task classes: many workers share a small number \(\tau\) of cost profiles, and task supply grows with the workforce.

The anchor is Theorem 4.4, proved in this paper. For indivisible chores with 1-restricted additive valuations, it says that \(\mathsf{RandChore}\) is group-strategyproof in expectation; it guarantees ex-ante EF, PROP, and EQ and ex-post EF1, PROP1, and EQ1; and it guarantees ex-ante PO, UWM, and EWM and ex-post PO, UWM, and a 2-approximation of EWM. The paper describes the mechanism explicitly and states an \(O(mn)\) running time in the accompanying prose. This is a constructive algorithmic anchor, rather than a hardness or complexity-classification result.

Call the proposed mirror High-Multiplicity RandChore Implementation. An instance has \(r\) task classes, rational per-capita supplies \(b_e\) for each class \(e\), and a finite set \(\mathcal T\) of cost types, where \(v_t(e)\in\{0,-c_e\}\) for rational \(c_e>0\). It also has a rational society distribution \(\mu\) over \(\mathcal T\), with support size \(\tau\). For every admissible population scale \(q\), there are \(q\mu_t\) workers of type \(t\) and \(qb_e\) indivisible copies of task class \(e\), with these quantities integral. The scale represents the large workforce; each worker still receives an integral bundle of tasks.

The question is whether one can construct a succinct randomized direct mechanism, given the type support, masses, task supplies, and their bit length \(L\), that works uniformly across admissible scales. It must allocate every task copy, and at truthful profiles it must satisfy the guarantees in Theorem 4.4. Group-strategyproofness must hold for every finite realization of the mechanism, so the type-mass description does not make individual incentives vacuous. A solution is a compact mechanism description and sampler, with construction time polynomial in \(r,\tau,L\) and allocation time allowed to depend on the size of the realized population.

I expect this mirror to be tractable. The theorem’s mechanism already separates tasks that some agents report as costless from tasks that everyone values identically, then uses random assignment and ordered round-robin allocation. Those steps look amenable to computation from type counts and task-class supplies. The main further questions are whether the mechanism can be represented compactly while preserving exact finite-scale incentives, and whether its ex-post EF1/EQ1 guarantees survive that compression.

The case is strongest for this one result and covers only the restricted-additive chore setting. Its weakest point is that the paper proves properties of a mechanism, rather than a complexity classification; the \(O(mn)\) bound is stated outside the theorem. Also, tying task supply to population size is a necessary model choice for this regime, and the authors might regard a succinct mass-based implementation as an extension rather than their original problem. The mirror remains credible because it keeps the same agents, reports, indivisible tasks, and mechanism guarantees while making the population distribution the compact input.

The case AGAINST (opponent, writing after the proponent)

I would reject this mirror, though the negative case is not airtight: Theorem 4.4 is the paper’s strongest computational anchor. It gives an explicit mechanism with substantial guarantees, and the paper states an \(O(mn)\) running time. But the theorem is about the properties of that mechanism, not the complexity of a computational problem over a population distribution. It specifies no optimization or decision task for the proposed mass input.

There is a fundamental tension in preserving its guarantees. In a genuinely atomless society, an individual has measure zero. Changing that person’s report leaves \(\mu\) unchanged, so group-strategyproofness either becomes vacuous for a mechanism driven only by \(\mu\), or requires extra pointwise machinery. Likewise, EF1 and EQ1 compare individual bundles and remove one item; type-level average allocations do not define those ex-post properties. A richer continuum model might supply such definitions, but it would need to add structure that the theorem does not address.

The proponent’s finite-scale repair preserves that structure, but then each scale is an ordinary finite instance of the paper’s problem. Run \(\mathsf{RandChore}\) on its \(q\mu_t\) agents and \(qb_e\) task copies: the theorem already guarantees the requested properties for that instance. The compact mechanism description is the same fixed algorithm, while producing the individual allocation still takes work proportional to the realized population and tasks. That is a valid high-multiplicity encoding, but it does not turn this result into a new computational question about the continuous society.

A new question about designing or optimizing mechanisms under additional population-level constraints could be worthwhile. Those constraints would need to be specified, though; they do not arise from the named result itself. The case against this anchor is therefore about the gap between its individual-level guarantees and a population-only computational problem—not about whether the finite mechanism remains valid at larger scales.
