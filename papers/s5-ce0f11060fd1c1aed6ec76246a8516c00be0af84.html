The case AGAINST (opponent, writing after the proponent)

The proponent’s first point is decisive under the programme’s criteria: this paper has no numbered computational result to mirror. Theorem 1 characterizes equilibria; Theorems 2 and 15–17 study stability. None analyzes an algorithm, a reduction, or computational complexity. So there is no qualifying anchor from which to pose the requested continuous computational question.

The strongest rescue is to ask for an algorithm that finds or tests for a stable threshold equilibrium. But in the paper’s symmetric model, agents share the same signal law and use the same strategy. As population size grows, the society is still just one agent type with mass \(1\); apart from sampling requirements, population size does not enter the equilibrium characterizations. Treating realized signals as population types would simply recast the signal distribution \(F\) and predictive probabilities \(P,G,Q\), which the paper already analyzes. That may motivate an algorithmic study, but the continuous-population lift adds no computational structure.

A more ambitious version would give graders different effort levels or signal-generating laws, then compute a threshold strategy for each type in a continuum population. That is plausible and the authors mention heterogeneity and effort as future directions. But it changes the symmetric game the paper studies and supplies a new problem rather than a mirror of one of its results. The negative case is weakest there: such a project might be worthwhile in its own right. It still does not provide the paper with an anchored continuous mirror.
