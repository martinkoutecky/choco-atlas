The case FOR (proponent)

There are no eligible computational anchors in this paper: none of its numbered results classifies a problem as polynomial time, NP-hard, FPT, or similar. The closest named results are Lemma 2 (proved here), which says that whenever an optimal designer signal exists, an optimal binary signal exists, and Proposition 4 (proved here), which says that if all signal accuracies lie in \([\sqrt{2}/2,1]\), the designer cannot manipulate the election, while if they all lie in \([1/2,2/3]\), the designer can. These are structural and analytic results, not complexity results.

A plausible computational follow-up is Finite-Support Persuasion Manipulability. Its input is a finite list of voter types \(i=1,\dots,\tau\), each with rational mass \(\mu_i\) summing to \(1\) and rational signal accuracy \(q_i\in[1/2,1]\). Voters are a nonatomic population: type \(i\) means having that accuracy and otherwise identical voting behavior. Each voter gets an independent exogenous signal; the platform chooses one common binary signal \(s\), described by \(p_A=\Pr[s=a\mid\theta_A]\) and \(p_B=\Pr[s=a\mid\theta_B]\), and sends independent realizations. Given the known signal rule, voters update by Bayes’ rule and vote sincerely, with ties for \(A\). The question is whether some \(s\) makes at least half the population vote for \(A\) in both states; a solution is such a signal, and a negative answer certifies that none exists.

A natural regime is a very large platform audience with relatively few distinct, calibrated accuracy classes: the number of users is large while \(\tau\) is moderate. This is a sensible high-multiplicity grouping for the problem, and the paper’s Lemma 2 supports restricting the search to binary signals. I would expect this finite-input decision problem to be tractable: with two signal parameters, voter behavior changes at rational likelihood-ratio thresholds determined by the \(q_i\), yielding a polynomial-size arrangement to check. That is a proposed algorithmic direction, not a result of the paper. Further questions include optimizing the probability of an \(A\) outcome when perfect manipulation is impossible, and allowing the platform to target types separately.

The scope of this candidate is the paper’s private, conditionally independent persuasion with sincere voting and two alternatives. Authors would likely recognize it as their manipulation question in a finite-support input representation. But the central weakness is decisive for calling it a *continuous mirror*: their model already has a continuum of voters, and their extension already considers a distribution of signal accuracies. This candidate adds a computational question to an existing continuous-population model; it does not continuize a discrete problem studied in the paper. So it is a credible computational follow-up, but I cannot honestly present it as a valid continuous mirror anchored in a named computational result.

The case AGAINST (opponent, writing after the proponent)

There is no computational result here to continuize. Lemma 2 says an optimal signal can be binary; Propositions 1–4 characterize when manipulation succeeds and, in some cases, which signal biases can work. None classifies the complexity of a computational problem or gives an algorithmic result. Recasting Lemma 2 as a search problem, or Proposition 4 as a decision problem, supplies a new computational question; it does not mirror a computational result in the paper.

The proposed finite-support manipulability question is coherent, and it could be worth studying computationally. But its population is already nonatomic: Section 3 has a continuum of voters divided into accuracy types, and Section 5.1 extends the model to a distribution of accuracies. Giving that population finitely many rational type masses makes the input explicit; it does not continuize the population. The same holds for a sharper version allowing targeted signals or optimizing manipulation over arbitrary finite supports. Those would analyze computation within a model the paper already makes continuous.

A finite-electorate version could also be interesting, with a limit or approximation question connecting it to the paper’s model. But that would add a discrete problem and study its relation to an already-continuous model; it would not be a continuous mirror of one of the paper’s results. Calling it a mirror would reverse the direction of the programme’s move.

So the strongest negative case is narrow but solid: these anchors cannot support a continuous mirror under the programme’s stated standard. That is not a claim that the proposed computational follow-up lacks value; it is a claim that its value would come from computationalizing an existing continuous-population model, not from continuizing a result of this paper.
