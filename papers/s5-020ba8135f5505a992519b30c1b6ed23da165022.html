The continuous mirror question

Given a finite issue set \(P\), behavioral types \(T\) with positive rational masses \(\mu_t\) summing to \(1\), successor maps \(f_p:T\to T\), and initial binary opinions \(b^0:T\times P\to\{0,1\}\), determine whether there is a \(K\) such that \(b^{k+1}_{t,p}=b^k_{t,p}\) for every \(k\ge K\), \(t\in T\), and \(p\in P\). If so, return the eventual opinions and their mass shares; otherwise, return an issue and a disagreeing cycle witnessing nonconvergence.

The model it lives in

A distribution \(\mu\) over complete behavioral types, each with an initial opinion and a successor type for each issue. Each type copies its successor’s opinion at every discrete step; the question is whether all positive-mass types stabilize, with \(\mu\) used to compute final population shares.

The objection that survived

The convergence verdict depends on the positive-support type graph, while μ affects only the final opinion shares; this limits how much the convergence question itself uses population mass.

fatal: False

What the mirror covers

The mirror covers BDP convergence, including Theorem 3 and Corollary 1, and the polynomial-time model-checking consequence. It leaves the paper’s aggregation characterizations, impossibility result, and other axiomatic analyses aside.

Open questions for a prover

  • Can one establish an exact algorithm with running time polynomial in \(|P|\), \(\tau=|T|\), and the input bit length \(L\), returning either the eventual mass shares or a disagreeing-cycle witness?

The case FOR (proponent)

My strongest case is Mass-BDP Convergence∞, anchored in Corollary 1, which the authors prove. It says that a Boolean DeGroot process converges exactly when, for every agent and every issue, the agent can reach in finitely many influencer steps an agent whose current opinion agrees with all of that agent’s direct and indirect influencers. In the paper’s notation, the condition is

\[ \langle N,G,O\rangle,i \models \mathsf U\left(\bigwedge_{p\in P}\mu x.\bigl(\mathrm{stb}(p)\lor[p]x\bigr)\right) \]

for every \(i\in N\), where \(\mathrm{stb}(p)=\nu y.(\pm p\land[p]y)\), \(\mathsf U\) is the universal modality, and \([p]\) follows the influencer edge for issue \(p\). The paper gives no numbered NP-hardness result or theorem explicitly labeled “in P.” This is the algorithmic anchor because the authors compute with the formula: they state that the individual stabilization formula has alternation depth zero and can be checked in \(O(|\varphi||N|)\) time. Checking the all-issues condition remains polynomial.

The continuous instance has a finite set \(T\) of behavioral types, rational masses \(\mu_t>0\) summing to \(1\), a finite issue set \(P\), an influencer-type map \(f_p:T\to T\) for each issue, and initial opinions \(b^0:T\times P\to\{0,1\}\). A type completely specifies the features used by this process: its initial opinions and, on each issue, the type of the influencer it copies. The dynamics are

\[ b^{k+1}_{t,p}=b^k_{f_p(t),p}. \]

The problem asks whether the process becomes stationary in mass: is there a \(K\) such that, for every \(k\ge K\) and issue \(p\),

\[ \sum_{t\in T}\mu_t\,\mathbf{1}[b^{k+1}_{t,p}\ne b^k_{t,p}]=0? \]

A yes solution gives such a \(K\), the eventual type opinions \(b^*\), and the final share \(\sum_t\mu_t b^*_{t,p}\) supporting each issue. A no solution gives an issue and a directed cycle of types whose initial opinions disagree. Since every listed type has positive mass, this is exactly convergence of the entire population’s type-opinion distribution.

The regime is a large membership organization or political platform with standardized, issue-specific delegation roles. For example, many members may share an initial ballot pattern and copy the opinion of the same role or cohort on each issue. The number of people \(n\) can greatly exceed the number of distinct behavioral types \(\tau=|T|\). This grouping is exact for the process when members of a type copy members of a successor type whose opinion is uniform within that type. The population is represented by fractional cohort sizes; individual opinions remain binary and time remains discrete. That keeps the authors’ BDP question intact while making the society itself the mass distribution.

The expected result is tractability in \(|P|,\tau,L\), where \(L\) is the input bit length of the masses. For each issue, inspect the cycles of its type graph. If a cycle contains disagreeing initial opinions, it supplies a nonconvergence witness. Otherwise, propagate each cycle’s common opinion back through its trees; every type settles within at most \(\tau\) steps. Exact rational summation then gives the final support shares. This takes polynomial time and is independent of the total number of members. The paper’s formulation-based algorithmic result supports that expectation, while the cycle check gives a direct solver for this particular type model.

The authors should recognize this mirror: it retains the binary opinions, issue-specific copying, and convergence question they study, and changes the representation of the population to masses over interchangeable types. Its scope is the BDP convergence result, especially Corollary 1. It does not cover the paper’s aggregation axioms or impossibility results. A natural next question is the minimum cost of redirecting a chosen mass of members so that every positive-mass type stabilizes.

The soft spot is that \(\mu\) weights the population readout but does not affect the update rule or its convergence. The mirror therefore gains most when \(\tau\ll n\); in a network with individualized influencer links, \(\tau\) may approach \(n\). Still, a large organization with recurring delegation roles is a plausible high-multiplicity regime, and the underlying question remains the authors’ own stabilization problem.

The case AGAINST (opponent, writing after the proponent)

I can’t honestly claim this anchor is ill-posed. Theorem 3 and Corollary 1 give a real convergence result, and the proposed type dynamics preserve the paper’s copying rule. A platform with large cohorts following shared delegation roles is plausible. The fact that the paper also contains axiomatic results does not defeat this anchor.

The strongest objection is that the proposed population masses do not govern the convergence question. With types \(T\), successor maps \(f_p\), and initial opinions \(b^0\), a cycle of \(f_p\) converges exactly when its types agree on \(p\) initially. Since every supported type has \(\mu_t>0\), the proposed zero-mass-change condition is equivalent to every type stabilizing. Its truth is independent of the masses; they only weight the final opinion shares. Thus the mirror is a finite functional graph with a population distribution attached, rather than a computational question whose operative input is a continuous society.

That objection survives the best version of the type model: taking types to include the successor type makes the quotient exact for homogeneous cohorts. It also exposes the limit of the model. Arbitrary BDP networks need not have homogeneous blocks, so the quotient describes a restricted network regime. If a continuous type space is used to avoid that restriction, the input becomes a measurable influencer map or kernel. The paper’s finite-graph theorem no longer supplies a finite algorithmic input or a complexity question in \(m,\tau,L\). Replacing single-trustee copying with mass-weighted influence would make masses affect the dynamics, but would change the process the paper analyzes.

A more promising repair or robustness question would make mass matter directly: for example, how much population must have its delegation redirected to eliminate oscillation? Yet under exact convergence, leaving any positive mass on a disagreeing cycle leaves positive mass changing forever. Splitting a cohort therefore does not create a fractional repair: the intervention must remove all mass from at least one type on each offending cycle. That is a weighted graph-edit problem on the type quotient. It may be a worthwhile follow-on, but it adds an intervention problem and costs that the paper does not formulate; it is weaker evidence for a continuous mirror of its convergence result.

So the negative case is limited. The role-based cohort scenario is credible, and the authors could recognize a mass-weighted intervention question as natural future work. The case against rests on the narrower claim that the paper’s existing convergence result has no population-sensitive computational core: preserving its dynamics leaves mass as a readout, while making mass shape the dynamics changes the model.
