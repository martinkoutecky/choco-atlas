The continuous mirror question

Given a finite institution set \(I\), a finite type set \(T\), an owner \(o(t)\in I\) for each type, rational masses \(\mu_t\ge 0\) with \(\sum_{t\in T}\mu_t=1\), and a compatibility relation \(\Gamma\) on types, decide whether there is a feasible mass matching \(x\) with no blocking coalition. A feasible \(x\) assigns nonnegative mass \(x_{tu}\) to each compatible unordered type pair, consuming \(2x_{tt}+\sum_{u\ne t}x_{tu}\le\mu_t\) of type \(t\); institution \(i\)’s utility is the total mass of its types matched. A coalition \(S\subseteq I\) blocks if a feasible mass matching \(y\), using only types owned by \(S\), gives every \(i\in S\) strictly more matched mass than \(x\).

The model it lives in

A continuous NTU partitioned matching game: patient-donor pairs are grouped into exact compatibility types carrying rational mass, and institutions remain the strategic players. The decision variable is mass assigned to compatible type pairs; each patient-donor unit is matched integrally, while type-level matched quantities and institution utilities may be fractional.

What the mirror covers

The mirror covers Theorem 29’s weak-core existence question for partition classes of size at most seven; it does not cover core verification, strong-core existence, or minimum-cost core optimization.

Open questions for a prover

  • Can an exact rational weak-core mass matching be constructed in time polynomial in the input bit length, \(|T|\), and \(|I|\)?
  • Can a continuous weak-core matching be rounded to a finite matching with a quantified additive loss in each institution’s matched-patient mass?

The case FOR (proponent)

My lead is the weak-core existence problem for a continuum of patient-donor pairs. The anchor is Theorem 29, proved in this paper: deciding whether the weak core is nonempty is NP-hard even when every player controls at most seven vertices. The reduction is from 3-SAT, using variable and clause gadgets and a gadget that simulates forbidden edges. The theorem’s hardness is about finding a stable matching among many players; it does not claim that the number of vertices per player is large.

For the mirror, let \(I\) be the hospitals or countries, and let \(T\) be a finite set of exact patient-donor types. A type includes its owner and its full compatibility profile, so pairs of the same type are interchangeable for matching. The input gives each type a rational mass \(\mu_t\), with \(\sum_{t\in T}\mu_t=1\), and a compatibility relation on types. This fits a large exchange pool in which many pairs fall into recurring compatibility classes, even though each individual pair can receive only an integral outcome.

The decision variable is a mass matching \(x\): for each compatible unordered pair of types \(t,u\), \(x_{tu}\) is the mass exchanged between them. A self-pairing \(x_{tt}\), when allowed, uses two units of type \(t\). Thus the mass of type \(t\) matched is
\[ h_t(x)=2x_{tt}+\sum_{u\ne t}x_{tu}\leq\mu_t, \]
and hospital \(i\)’s utility is \(q_i(x)=\sum_{t:\,o(t)=i}h_t(x)\). These are fractions of the population; they do not mean that a patient receives a fractional kidney.

A coalition \(S\subseteq I\) can deviate using only exchanges between types owned by members of \(S\). It blocks \(x\) in the paper’s weak-core sense if it can find such a mass matching \(y\) with \(q_i(y)>q_i(x)\) for every \(i\in S\). The continuous problem is: given the type masses, owners, and compatibility relation, does there exist a feasible mass matching \(x\) with no such blocking coalition? A solution is the mass matching \(x\); this question has no edge-cost objective.

I expect the answer to be yes for every instance, so this existence question is tractable in the strongest decision sense. The reason is the balanced-game argument behind Scarf’s theorem, which the paper itself cites. For a balanced collection of coalitions with weights \(\lambda_S\), take a feasible deviation matching \(y^S\) for each coalition and sum their edge masses with those weights. For a type owned by \(i\), the combined use is at most \(\mu_t\sum_{S\ni i}\lambda_S=\mu_t\); the combined matching is feasible for the grand coalition, and its utility vector is the weighted sum of the coalition utilities. The feasible utility sets are also compact and downward closed. Thus the continuous matching game is balanced, giving a nonempty weak core. This applies for arbitrary numbers of institutions and types. Scarf’s result is prior machinery that answers this mirror; it is not a collision with the paper’s discrete model.

The authors should recognize this as their problem: it retains the same players, pairwise compatibility, matched-patient utility, and coalition deviations. The change is that exchangeable cohorts are represented by mass, so matchings can split cohorts. That co-modification is part of making the population continuous. This case covers Theorem 29’s weak-core existence question only; it says nothing by itself about core verification, strong-core existence, or minimum-cost core matching.

The weakest point is that Theorem 29’s reduction grows the number of players while keeping each player’s class small. My mass model makes patient-donor pairs continuous and leaves institutions as the strategic players, so it does not claim to preserve the reduction’s hard instances. Its plausibility rests on a different but recognizable regime: large cohorts with repeated, exact compatibility profiles. If actual medical compatibility makes nearly every pair a distinct type, the support may be too large for this to be a useful high-multiplicity model. Also, Scarf’s theorem settles nonemptiness, but does not by itself give a polynomial-time procedure that outputs a rational core matching. Those are worthwhile next questions, alongside whether the mass solution can be rounded with controlled loss in a finite exchange program.

The case AGAINST (opponent, writing after the proponent)

The strongest negative case is the gap between Theorem 29’s reduction and a natural high-multiplicity kidney-exchange instance. Its \(3\)-SAT gadgets use a growing set of players and carefully chosen, vertex-specific compatibility edges. Under the proposed exact-type model, two pairs can share a type only when they have the same owner and the same relevant compatibility profile. In those gadgets, that may leave almost every pair in its own type. Coarsening the profiles to create larger cohorts can change which coalitions can improve, so it may change the problem being mirrored.

That objection has limited reach. A clearinghouse with a fixed set of compatibility classes, where compatibility is determined by class and many pairs occupy each class, is a plausible high-volume regime. The proposed model preserves the paper’s players, matching feasibility, utilities, and coalition deviations. It also keeps the strategic players as institutions, so their mass does not vanish in the limit. The paper itself distinguishes small-institution cases from large ones; that variation makes a restricted large-cohort regime a reasonable mirror of the hardness question.

There is a technical correction to the proponent’s Scarf argument: the exact utility set of matchings need not be downward closed. For two players with compatible types, it can be \(\{(a,a):0\le a\le1\}\), which is not comprehensive. Taking its downward comprehensive hull repairs the balanced-game argument, and does not change strict blocking: a feasible payoff above a proposed outcome must be dominated by an actual matching payoff that is also above it. Scarf’s theorem therefore supports nonemptiness, but it does not supply a polynomial-time method for finding an exact rational core matching. That constructive question remains a computational mirror.

So the reduction itself does not establish that high multiplicity is typical in kidney exchange, and the paper’s specific hard instances may not have repeated exact types. But a plausible repeated-profile regime survives, as does the stronger question of computing a core outcome there. I cannot honestly defeat this anchor across all scenarios; the negative case is weak exactly where it must rule out that regime.
