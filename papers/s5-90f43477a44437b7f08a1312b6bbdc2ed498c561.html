The case FOR (proponent)

There is no named computational result in this paper to anchor a continuous mirror to. The main theorem, referenced as \(\ref{thm.total}\) in the supplied text, characterizes the facet inequalities of \(T(N)\): they correspond exactly to non-trivial irreducible min-balanced systems whose carriers are subsets of \(N\). That is a substantial structural result, but it does not assert an algorithm, a complexity bound, or hardness for a computational problem. The paper’s small-player facet counts are computational support, not a named complexity result. Nor does the Farkas-style feasibility lemma supply an algorithmic anchor: it is used to derive cone characterizations.

There is a plausible *research extension* in the paper’s market-game setting. Let \(\tau\) complete market-participant types have rational masses \(\mu_t\), with many interchangeable participants per type. A coalition is a mass vector \(x\in[0,\mu]\), and its transferable worth is a rational piecewise-linear function \(v(x)\). One could ask whether the game is totally balanced: for every subpopulation \(q\in[0,\mu]\), is there a payoff-rate vector \(p^q\in\mathbb{R}^{\tau}\) such that \(p^q\cdot q=v(q)\) and \(p^q\cdot x\ge v(x)\) for every \(x\le q\)? A yes-instance has a nonempty core for every subpopulation; a no-instance has some \(q\) whose core is empty. Cohorts of participants with the same technology, endowments, and other relevant attributes make the high-multiplicity regime credible.

But that extension asks for recognition of total balancedness over a continuous mass domain; the paper characterizes facets of a cone of set functions on a finite player set. The theorem does not establish that its facet description persists under this change, or give a computational result about the extension. The weakest point is therefore decisive for this assignment: although the population model is plausible and the underlying game concept is shared, there is no qualifying named result here to mirror. I would not present the extension as an anchored continuous mirror.

The case AGAINST (opponent, writing after the proponent)

The only serious anchor is Theorem \(\ref{thm.total}\), and it is a structural characterization of facets—not a result about the complexity of a computational problem. The paper gives no decision, search, or optimization problem with an encoding and complexity bound. Its facet counts for small \(n\) are computations, not a complexity analysis. So the theorem does not provide the kind of computational result ChoCo is meant to continuize.

The best repair is the proposed cohort model: finitely many participant types with rational masses, a piecewise-linear worth function \(v(q)\) over coalition mass vectors, and a question about core existence for every subpopulation. That is a coherent continuous-population question, and large cohorts of economically similar participants are plausible. But it splits in a way that weakens its connection to this paper. With the paper’s natural market-game structure—concave production—the market-game characterization already supplies total balancedness. Recognizing it would be built into the model. If we allow general \(v\) to make the question nontrivial, we need to choose how \(v\) is represented and how it extends the finite coalition values. Those choices define a new computational problem; the paper’s facet theorem neither selects among them nor yields a complexity question for them.

One could still study facets of a cone of continuous worth functions. That might be worthwhile mathematics, but it would be a new cone and a new structural problem, not a computational mirror anchored in this paper. The negative case is therefore strong on the assignment’s criterion, though it cannot rule out an interesting follow-on project. It does not depend on denying that high-multiplicity economic cohorts make sense; it depends on the absence of a computational result here to continuize.
