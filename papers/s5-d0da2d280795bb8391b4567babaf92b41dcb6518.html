The case FOR (proponent)

A credible population setting is repeated provision of a public good by many households with a small number of shared valuation types. Let each type \(t\) have mass \(\mu_t\) and utility \(f_t\) for the public good; the paper’s linear case is \(f_t(q)=\theta_t q\). A continuous version could let each unit of mass choose the CCM’s conditional contribution offers, with the resulting allocation recording type-level contributions. One could ask whether a proposed allocation occurs in a recurrent class under population Unexploitable Better Response Dynamics. This is a plausible high-multiplicity regime: many households, relatively few distinct valuation types.

But that is a possible new computational question, not one anchored by this paper’s named results. The closest results are Theorem 3.7, proved here, which characterizes binary-model recurrent outcomes under UBRD as exactly the Pareto-optimal outcomes that are strict* Pareto improvements over zero; Theorem 4.4, proved here, which gives the corresponding characterization for the non-binary CCM with linear valuations; and Theorem 5.5, proved here, which characterizes recurrent outcomes for weakly increasing valuations as core allocations strict* for \(SC(z)\), assuming such an allocation exists. These are equilibrium characterizations, not results asserting a computational complexity, algorithm, or computed formulation.

So the paper supplies a sensible setting for population continuization, but no eligible computational anchor. I can’t honestly assign the proposed question a tractable, hardness-transfer, or continuum-specific-hardness prognosis based on these theorems.

The case AGAINST (opponent, writing after the proponent)

The proposed setting—many households with a small number of valuation types—is credible high multiplicity. That clears an important modelling hurdle, but it does not give this paper a computational result to mirror. Theorem 3.7 and Theorem 4.4 characterize recurrent outcomes under UBRD; Theorem 5.5 gives a core characterization under an existence assumption. None asserts a complexity bound or poses an algorithmic problem. The mechanism’s outcome is already described as computable from its messages. Turning the equilibrium characterizations into a complexity question would add a task the paper does not study.

The most direct mirror, “which allocations recur under population UBRD?”, also runs into a limit problem. UBRD tests named agents’ unilateral message changes. In a nonatomic population, one agent has zero mass: changing their message cannot change aggregate provision. They can avoid their own contribution while leaving the public good unchanged, so positive contribution loses its incentive basis; moreover, sequences of individual changes do not describe changes to population mass. Treating an entire valuation type as one strategic bloc would restore pivotality, but then the players are the \(\tau\) blocs, not the many individuals within them. Allowing positive-mass groups to move instead requires a coalition or population-level dynamic that the paper does not define.

Theorem 5.5 offers the strongest escape: ask whether a continuum allocation is in the core against blocking coalitions of positive mass. That is a coherent follow-on question, but its computational form needs additional choices—especially a finite encoding for the valuation functions and a specified core-recognition or blocking algorithm. Without those, the mirror is a new equilibrium-analysis problem, not a complexity result anchored in this paper.

So the negative case is strong against calling this a computational mirror of Reischmann’s results. It is not a proof that no worthwhile computational project can be built nearby: a finitely encoded continuum-core problem might be one. That possibility is the case’s main weakness, and it is a distinct research question rather than a surviving computational anchor from Theorems 3.7, 4.4, or 5.5.
