The continuous mirror question

Given a finite support of \(\tau\) complete valuation types \(\nu_t\) on \([0,1]\), with positive rational masses \(\mu_t\) summing to one and binary encoding length \(L\), determine the worst-case Robertson–Webb query complexity of producing a finite partition and nonnegative, piecewise-constant per-capita bundle densities \(x_t\) satisfying \(\sum_t \mu_t x_t(z)=1\) almost everywhere and \(\int x_t\,d\nu_t \ge \int x_u\,d\nu_t\) for every pair of types \(t,u\). In particular, is there a deterministic protocol using \(\mathrm{poly}(\tau,L)\) queries, independent of the masses’ denominators and the population size?

The model it lives in

A society has exact valuation types \(t\) with masses \(\mu_t\); type \(t\) receives a common per-capita average bundle with density \(x_t\) over replicated cake supply. The mass-weighted capacity constraint is \(\sum_t\mu_t x_t(z)=1\), and envy-freeness compares the value of each type’s own bundle with each other type’s bundle.

The objection that survived

Exact equality of unrestricted valuation measures may leave the support size close to the headcount in many instances, limiting how broadly the high-multiplicity regime applies.

fatal: False

What the mirror covers

The mirror covers Theorem 1.1’s query guarantee for complete envy-free allocation. It leaves the subroutine-specific query analyses, proof architecture, and cited historical lower bounds without separate mirrors.

Open questions for a prover

  • Can a deterministic protocol produce such a complete envy-free allocation with query complexity polynomial in \(\tau\) and \(L\), independent of the replicated population size?

The case FOR (proponent)

The strongest case is for a high multiplicity version of the paper’s complete envy free allocation problem. The paper’s only substantial named anchor for that case is Theorem 1.1 (Main Theorem), proved here: for every \(n\ge1\) and every collection of nonnegative, additive, nonatomic valuations, a deterministic bounded Robertson–Webb protocol returns a complete envy free allocation using at most \(n^{O(1)}2^n\) queries. The paper gives no comparable named hardness result, so this algorithmic theorem is the right anchor.

Here is a mirror I think the authors could recognize. Let a type \(t\) be a complete valuation measure \(\nu_t\) on a unit cake, accessible through evaluation and cut queries. A continuous society has finite support \(T\), with \(|T|=\tau\), and positive rational masses \(\mu_t\) summing to one. To keep an individual’s allotment meaningful as the population grows, scale the supply with the population: in a finite approximation with \(N\) people, there are \(N\) identical copies of the cake. Let \(x_t(z)\) be the quantity of cake at location \(z\) allocated per person of type \(t\), and extend utility additively, so type \(t\)’s value for type \(u\)’s bundle is \(\int x_u\,d\nu_t\). A complete envy free solution is a finite partition of the cake and nonnegative, piecewise constant densities \(x_t\) such that, almost everywhere,

\[ \sum_{t\in T}\mu_t x_t(z)=1, \qquad \int x_t\,d\nu_t\ge \int x_u\,d\nu_t \quad\text{for every }t,u\in T. \]

The first condition allocates all per capita supply; the second says no type envies another type’s bundle.

The continuous problem to hand a prover is: given the rational masses and Robertson–Webb oracles for the \(\tau\) valuation types, determine the worst case number of oracle queries needed to output such a solution, as a function of \(\tau\) and the masses’ binary encoding length \(L\). In particular, is there a deterministic protocol using \(\mathrm{poly}(\tau,L)\) queries, independent of the population size and the masses’ denominators? A solution is the partition and densities satisfying the two displayed conditions. I would expect Class A, though the theorem does not establish that: the hope is that once identical agents are aggregated, the support size rather than the headcount drives the query complexity.

The bridge to the anchor is concrete. For rational masses, choose \(N\) so that \(N\mu_t\) is an integer for every type, and apply Theorem 1.1 to \(N\) people dividing \(N\) identical cake copies. Averaging each type’s allocated bundles gives a type-level density. Additivity preserves envy inequalities under this averaging, and the averaged allocation uses one unit of supply per capita. Conversely, such type-level densities can be shared among the finitely many members of each type in the replicated finite instance. This makes the mirror a population continuization of the same envy comparison and completeness requirements, with the supply scaling needed to avoid a vanishing allotment.

My weakest point is that supply scaling is a real modification of the paper’s setting: its agents divide one cake, while this mirror gives a growing population a growing stock of repeated resources. The paper’s theorem also has no direct implication that the query count can depend on \(\tau\) instead of \(N\). I think the case survives because the programme permits per capita supplies that scale with population, and the problem still asks for the paper’s central object—complete envy free allocation under valuation queries. It covers Theorem 1.1’s general additive nonatomic setting; it does not claim a mirror for the paper’s internal subroutines. It also raises the sharper follow up: can query complexity be bounded by support size and encoding length, or is there a lower bound showing that multiplicity still matters even when types are fixed?

The case AGAINST (opponent, writing after the proponent)

Theorem 1.1 is a genuine computational result, so the negative case cannot rest on a missing anchor. It gives a deterministic Robertson–Webb query bound for finding a complete envy-free allocation. The continuous question is also clear: how does query complexity change when the population has \(\tau\) exact valuation types with rational masses?

The strongest objection is that, for this paper, a type is a whole valuation measure. With arbitrary nonatomic additive valuations, that is an unusually rich description: two people have the same type only if they value every cake piece identically. Unlike rankings over a finite candidate set, these valuation types have no obvious finite catalogue. In a typical cake-cutting instance, exact type classes may therefore be singletons, leaving \(\tau\) close to the headcount. Coarsening people into approximate types would change the guarantee: arbitrary valuations provide no bound on how much an approximation can alter an envy comparison.

The proponent’s mirror avoids that problem by considering exact clones and scaling the cake supply with population. That gives a coherent weighted envy-free allocation problem, and averaging an allocation among clones preserves the type-level comparisons. It is a real mirror of the theorem, not just a consequence of the cake already being divisible. The changed supply is also permitted by the programme’s scope.

That leaves a narrow negative case: exact clone classes may be an unconvincing regime for the paper’s unrestricted model, and the mirror’s clearest formulation uses replicated supply. But neither point rules out a sensible scenario, especially for stylized populations with repeated valuations. I cannot honestly defeat this anchor universally. The case against is weak here: the exact-type assumption limits how broadly the mirror applies, but the weighted clone problem still looks worth asking.
