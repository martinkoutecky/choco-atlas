The continuous mirror question

Given a finite catalogue \(T\) of complete atomless valuation oracles \(V_t\), rational masses \(\mu\), and \(c\ge1\), issue shared exact Robertson–Webb \(\operatorname{Eval}_t\) and \(\operatorname{Cut}_t\) queries and output pairwise-disjoint measurable type bundles \(A_t\) satisfying \(V_t(A_t)\ge\mu_t/c\) for every \(\mu_t>0\); minimize worst-case query complexity.

The model it lives in

A high-multiplicity Robertson–Webb oracle model with \(\tau=|T|\) complete valuation types, mass vector \(\mu\), shared type queries, collective bundle variables \(A_t\), and worst-case query complexity as the objective.

The objection that survived

The collective-bundle output may hide the \(N\)-sized disaggregation that the original query model explicitly constructs; if individual pieces or their cut locations must be output and charged, the proposed problem is materially different.

fatal: False

What the mirror covers

The mirror covers Theorems 1 and 6 as exact and approximate type-oracle query-complexity questions, including their population-driven lower-bound mechanisms. It leaves the value-tree technical lemmas, constants, existing upper bounds, and tightness discussion outside the main mirror.

Open questions for a prover

  • What is the optimal deterministic query complexity as a function of \(\tau\), \(c\), and \(\mu_{\min}\)?
  • Does a weighted Even–Paz-style protocol achieve a bound polynomial in \(\tau\) and logarithmic in the mass encoding?
  • Can the approximate-cut variant retain a type-count bound, or does finite precision create a continuum-specific lower bound?

The case FOR (proponent)

The strongest positive case is a genuine high-multiplicity oracle mirror, with Theorem 1 as the lead. The paper does not contain an NP-hardness or classical polynomial-time theorem; its computational contribution is query complexity. That is still a valid anchor, but the mirror should be stated in the same Robertson–Webb query model.

Take a large population of \(N\) claimants drawn from a fixed finite catalogue \(T\) of complete valuation types, with \(|T|=\tau\ll N\). Type \(t\) includes the entire additive, atomless valuation function \(V_t\), not merely a ranking. The society is the rational mass distribution \(\mu\), where \(N\mu_t\) agents have type \(t\). All agents of a type share the same valuation oracle. Thus one query to type \(t\) gives information usable for all \(N\mu_t\) agents of that type.

The continuous allocation is a family of pairwise disjoint cake sets \((A_t)_{t\in T}\), where \(A_t\) is the collective bundle assigned to type \(t\). The fairness condition is

\[ V_t(A_t)\ge c\mu_t \]

for every positive-mass type. This is exactly the aggregate form of the paper’s \(c\)-fairness condition: if \(N\mu_t\) identical agents receive a partition of \(A_t\), each can receive value at least

\[ \frac{c\mu_t}{N\mu_t}=\frac{c}{N}. \]

Thus the continuous output remains an integral cake allocation at the type level; only the population is represented by mass. For rational \(\mu\), clearing denominators gives the corresponding finite high-multiplicity instance.

My lead problem is Exact Type-Mass Cake Cutting\(_\infty\). Its instance consists of \(T\), rational masses \(\mu\), a fairness factor \(c\), and hidden valuation oracles \(V_t\). A deterministic protocol may issue exact \(\operatorname{Eval}_t\) and \(\operatorname{Cut}_t\) queries to types. It must output disjoint sets \(A_t\) satisfying \(V_t(A_t)\ge c\mu_t\), and its objective is to minimize the worst-case number of oracle queries.

The anchor is Theorem 1, proved in this paper. It states that every deterministic cake-cutting protocol has complexity

\[ \Omega\!\bigl(n(\log n-\log c)\bigr), \]

even with exact queries, even when a player may receive a union of intervals, and even when only \(c\)-approximate fairness is required, meaning value at least \(c/n\). In particular, when \(c=n^{1-\delta}\), the lower bound remains \(\Omega(n\log n)\).

This is a particularly good mirror because the paper’s proof identifies exactly where the population factor comes from. Lemma 2 treats the \(n\) players as \(n\) independent black boxes: each player may require a separate thin-rich search. In the type-mass version there are only \(\tau\) valuation oracles. Repeating a type \(N\mu_t\) times does not create \(N\mu_t\) independent thin-rich games. The likely outcome is therefore Class A: the \(N\)-dependence should collapse to dependence on \(\tau\), the bit-length of \(\mu\), and perhaps \(\log(1/\mu_{\min})\). A weighted divide-and-conquer protocol should plausibly solve the problem with complexity polynomial in the number of types rather than in the number of named agents.

The residual difficulty would still be meaningful. A value-tree adversary could force a logarithmic search for a hard type, so the continuous problem need not become trivial. Natural questions include whether the correct bound is \(\Theta(\tau\log(1/\mu_{\min}))\), whether a weighted Even–Paz-style protocol is optimal, and how finite-\(N\) rounding affects the guarantee.

A second, closely related mirror is Approximate Type-Mass Cake Cutting\(_\infty\). It has the same \(T,\mu,c\), and valuation-oracle input, but uses the paper’s finite-precision query model: approximate cut queries have relative error \(1+\epsilon\), with exact evaluations available as in the Section 3 construction. A randomized Las Vegas protocol must output the same type-level allocation satisfying \(V_t(A_t)\ge c\mu_t\), while minimizing expected worst-case queries.

The anchor is Theorem 6, also proved in this paper using Yao’s method and Lemmas 7–10. It states that randomized protocols in the \(1+\epsilon\)-approximate-query model requiring \(c\)-fairness have complexity

\[ \Omega\!\left( n\,\frac{\log(n/c)}{\log(1/\epsilon)} \right) \]

using the notation of the displayed theorem. For constant \(\epsilon\), this gives an \(\Omega(n\log n)\)-type lower bound when \(c=n^{1-\delta}\).

The same positive mechanism applies: the theorem’s hard distribution independently chooses a random value tree for every player. Under high multiplicity, randomness is independent across types, not across all \(N\) agents. The population-driven \(N\) factor should therefore disappear when \(\tau\) is fixed or much smaller than \(N\). I would expect this approximate mirror also to be Class A in the type-oracle regime, with a remaining precision/query barrier depending on \(\epsilon\), \(\tau\), and the smallest positive type mass. If a lower bound survives for fixed \(\tau\), it would be continuum-specific information complexity, not transferred hardness from the original population size.

The original authors should recognize both questions as their problem: the cake remains the same interval, the valuation functions remain private additive measures, the allowed queries remain Evaluation and Cut, the bundles remain disjoint, and the fairness objective is exactly recovered by aggregating identical agents. The only substantive change is the high-multiplicity regime: a distribution over complete valuation types replaces a list of individually unrelated players.

The weakest point is that the query and output semantics really do change. If the protocol must explicitly enumerate \(N\) individual bundles, or if agents sharing a broad category still have independent valuation functions, then \(\tau\) is effectively \(N\) and the advantage disappears. Likewise, if type labels are hidden and must themselves be learned, the mirror becomes a new clustering problem. My case therefore covers the explicit type-oracle, aggregate-output regime, not every interpretation of “a continuum of cake-cutting players.” Within that regime, however, it is a legitimate population continuization, and Theorems 1 and 6 give a concrete reason to expect the paper’s \(N\)-driven lower bounds to dissolve rather than transfer.

The case AGAINST (opponent, writing after the proponent)

The strongest objection is that the proposed aggregate output silently removes the paper’s central task: producing a fair allocation to individual players.

For \(k=N\mu_t\) identical players of type \(t\), an individual allocation implies

\[ V_t(A_t)\ge k\frac{c}{N}=c\mu_t. \]

Conversely, atomlessness lets one partition \(A_t\) into \(k\) equal-value pieces. Thus the aggregate condition is existentially equivalent, but not algorithmically equivalent. The protocol in the paper must produce those \(k\) pieces. The proposed mirror outputs only \(A_t\), treating the \(k-1\) further cut locations as free postprocessing. With one type and \(\mu_t=1\), it can give the whole cake to that type with zero queries, whereas the original task still requires constructing \(N\) individually fair pieces. A better mirror that explicitly outputs an allocation kernel or all individual pieces reintroduces the population-sized output and query burden. The choice is therefore between changing the objective and retaining the discrete individual structure.

This matters especially for Theorem 1. Its \(n\)-factor is not caused by a population distribution; Lemma 2 obtains it by treating the players as \(n\) independent black boxes, each potentially hiding a different value tree. If \(N\mu_t\) agents share one valuation oracle, those black boxes have deliberately been identified. The resulting problem is a weighted cake-cutting problem with \(\tau\) valuation oracles, not Theorem 1 over a continuous society. That quotient may be worth studying, but the theorem itself provides no continuous-population lower-bound anchor.

The parameter regime also does not transport. Since \(V_t(A_t)\le 1\), the aggregate condition requires \(c\mu_t\le 1\). For fixed \(\tau\), some type has \(\mu_t\ge 1/\tau\), so necessarily \(c\le\tau\). The paper’s prominent regime \(c=N^{1-\delta}\) is therefore infeasible for a fixed-support high-multiplicity society. Choosing \(c\) bounded produces a different weighted-entitlement problem whose dependence on \(N\) has disappeared. That is not an objection that the answer becomes easy; it is a failure of the proposed formulation to mirror the theorem’s actual asymptotic question.

The same problem defeats Theorem 6 even more sharply. Its hard distribution gives independently chosen random value trees to the players. With high multiplicity, there are only \(\tau\) trees. If approximate cut replies may vary independently between otherwise identical players, that reply behaviour is part of the agents’ complete type and \(\tau\) grows back toward \(N\). If replies are shared, the model has changed to a common approximate oracle, and the theorem’s randomized lower-bound construction no longer applies. The \(N\)-dependent theorem is consequently neither preserved nor naturally instantiated.

There is also a basic information issue: unless type membership is supplied to the protocol, equality of arbitrary valuation oracles cannot be certified with finitely many queries. If membership is supplied, the model is simply weighted cake cutting; if it is hidden, the proposed query sharing is unavailable.

These objections do not honestly prove that no group-level or type-oracle cake-cutting problem could be worthwhile. The proponent’s model is mathematically coherent if one accepts symbolic disaggregation and regards weighted cake cutting as the desired high-multiplicity regime. My negative case is therefore limited but substantive: the two named theorems do not support the claimed mirror without either erasing individual fairness or changing the problem into a different weighted-oracle problem. A universal “no scenario is worthwhile” verdict would be overstated.
