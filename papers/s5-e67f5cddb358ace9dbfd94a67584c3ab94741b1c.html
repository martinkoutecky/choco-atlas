The continuous mirror question

Given a finite object set \(A_0\), an outside option \(a_0\), per-capita capacities \(\kappa_a\), and a regular probability measure \(\mu\) over complete types \((S,v)\), find a measurable direct mechanism for a unit mass of atomless agents that maximizes expected per-capita revenue while satisfying individual DSIC and IR, aggregate capacity constraints, and integral assignments to each individual. The mechanism may assign fractional shares of each type mass across objects, with every individual receiving an acceptable object or \(a_0\).

The model it lives in

A measure-valued one-sided matching mechanism design problem: types are complete \((S,v)\) pairs carrying mass under \(\mu\); the mechanism chooses individual assignments and payments, with type-level assignment masses \(x_{S,v,a}\) and objective expected revenue. Capacities scale per capita, and type averages may be fractional although individual assignments remain integral.

The objection that survived

The fixed-profile flow model neither enforces pointwise DSIC nor supplies the counterfactual cutoffs, and continuous iid values almost surely yield distinct realized \((S,v)\) types, so the proposed finite-support encoding needs a separate bridge.

fatal: False

What the mirror covers

The mirror covers the revenue-maximizing one-sided matching mechanism in Theorem 5, including its virtual-surplus allocation question; it does not transfer the general implementability characterizations or revenue-equivalence results in Theorems 1–4.

Open questions for a prover

  • Does Theorem 5’s virtual-surplus allocation and cutoff-payment structure continue to characterize the optimal atomless DSIC mechanism?
  • Which encoding of the value measure and capacities permits exact polynomial-time computation of the continuous optimum?

The case FOR (proponent)

The strongest mirror is the paper’s one-sided matching application, where many people compete for scarce, indivisible appointments or tickets and can pay for an acceptable assignment. Let \(A_0\) be the available objects and \(a_0\) the outside option. An agent’s type is \(t=(S,v)\): \(S\subseteq A_0\) is the set of acceptable objects, and \(v\) is the agent’s value for any object in \(S\). People of the same type have the same preferences and value. A plausible high-multiplicity regime is a large pool of customers with a relatively small number \(\tau\) of eligibility-and-value categories. Normalize the population to mass \(1\), and scale each object’s capacity to a per-capita supply \(\kappa_a\). Individuals still receive an integral object; allocations within a type group can average to fractional masses.

My anchor is Theorem 5, proved in this paper. It assumes one-sided matching with a worthless outside option, independent draws of each agent’s acceptable set and value, and value distributions with nondecreasing hazard rates. Among deterministic dominant-strategy incentive-compatible and individually rational mechanisms, it gives an optimal mechanism. For a reported profile \(t\), define the virtual value \(w_i(v_i)=v_i-(1-G_i(v_i))/g_i(v_i)\), and let \(W(t)=\{i:w_i(v_i)>0\}\). The allocation \(f^\ast(t)\) assigns the outside option to agents with nonpositive virtual value and chooses a feasible assignment maximizing the sum of the positive virtual values of agents who receive an acceptable object. The theorem also specifies cutoff payments \(p_i^\ast(t)=\kappa^f_{i,t_{-i}}(f_i^\ast(t))\delta(f_i^\ast(t),t_i)\). This is an exact optimal-mechanism result, rather than a P-versus-NP or runtime classification. It is the best anchor here because it computes an optimal policy for the paper’s matching problem.

I would hand a prover the following continuous allocation problem, Continuum Virtual-Surplus Matching. An instance consists of a finite object set \(A_0\), per-capita capacities \(\kappa_a\), and a reported population profile supported on \(\tau\) dichotomous types \(t=(S,v)\), with rational masses \(\mu_t\) summing to \(1\). It also includes regular value priors that determine a virtual weight \(w(v)\) for each reported value. Find masses \(x_{t,a}\geq 0\) assigned from type \(t\) to object \(a\), maximizing

\[ \sum_t w(v_t)\sum_{a\in S_t}x_{t,a} \]

subject to

\[ \sum_{a\in S_t}x_{t,a}\leq \mu_t \quad\text{for each }t, \qquad \sum_t x_{t,a}\leq \kappa_a \quad\text{for each }a. \]

Types with \(w(v_t)\leq 0\) receive no acceptable object; their remaining mass goes to \(a_0\). The solution is the type-to-object mass assignment, implemented by giving individual agents integral objects. This is the per-profile allocation problem solved by Theorem 5’s virtual-surplus rule. A max-cost flow formulation solves the capacitated matching version in polynomial time in \(\tau\), \(|A_0|\), and the input bit length. Applying it profile by profile, with the paper’s cutoff payments, gives the continuous analogue of the anchored mechanism. I expect this capacity-matching version to be tractable. Richer feasibility constraints \(\mathcal F\) could change that conclusion.

The authors should recognize this as their problem: the same dichotomous preferences, transfers, matching constraints, and virtual-surplus objective appear in their one-sided matching application. The continuous population changes the scale of the allocation and lets the mechanism reason directly about shares of each report type; object supply scales with population, while each person still gets an integral assignment. The scope is specifically Theorem 5’s matching application. It does not claim to continuize every result in the paper.

This mirror also raises useful follow-up questions: how accurately can a finite high-multiplicity allocation be recovered by rounding the mass solution; which structured feasibility constraints retain the flow algorithm; and how do correlation or irregular value distributions change the continuous optimum and its cutoff payments?

The weakest point is the bridge from the theorem to the mirror. Theorem 5 optimizes expected revenue for a finite set of agents with privately drawn values. The stated continuous problem computes virtual-surplus allocation for a population mass profile. The per-profile allocation is exactly the object Theorem 5 uses, but the paper does not prove that the entire finite-agent mechanism and its expected-revenue guarantees carry over to an atomless population. The mirror is therefore strongest as a continuous allocation-and-mechanism-design question anchored in the paper’s own matching result; its discrete-to-continuous identity remains to be established.

The case AGAINST (opponent, writing after the proponent)

Theorem 5 is the paper’s strongest anchor, but it does not state a computational complexity result. It gives an optimal finite-agent mechanism: independent priors over each named agent’s private type determine expected revenue, and the mechanism must remain incentive compatible across each agent’s possible reports. The proposed flow problem instead fixes one aggregate report profile and maximizes virtual surplus for that profile. Its solution gives allocation masses, but by itself it does not specify how individual reports affect allocations or how to recover the theorem’s cutoff payments, which depend on counterfactual unilateral reports.

There is also a support mismatch. A type here includes the exact value \(v\), and the paper assumes values drawn from distributions with densities. In a finite sample, independently drawn values are almost surely distinct, so the support of complete types typically grows with the number of agents. In an atomless limit, the population is a measure over a continuum of values, not the finite rational support used by the proposed LP. Discretizing values would create finite type classes, but it changes the paper’s distributional assumptions; the paper supplies no result showing that the optimal mechanism or its revenue survives that approximation.

A stronger mirror could model a continuum of agents with a measure over \((S,v)\), per-capita capacities, and individual incentive constraints. That is coherent, but it is a new measure-valued mechanism-design problem. The proposed max-flow formulation does not establish its connection to Theorem 5.

This defeats the stated LP as a faithful mirror, but it does not justify the universal claim that no worthwhile mirror exists. A continuum direct-mechanism extension could be natural and valuable. The honest negative case is therefore limited: the anchor’s bridge is missing, and the best version would require substantial new modeling and results; the available material does not rule that version out.
