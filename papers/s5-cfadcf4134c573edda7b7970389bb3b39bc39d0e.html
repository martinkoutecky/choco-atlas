The continuous mirror question

Given alternatives \(C\), a support \(T\) of \(\tau\) complete rankings, and binary-rational masses \(\mu_t>0\) summing to \(1\), compute the Schulze winner set. Define \(\gamma_\mu(x,y)=\sum_{t\in T}\mu_t\mathbf{1}[x\succ_t y]\), path strength \(s_\mu(x,y)=\max_{\pi:x\leadsto y}\min_{(u,v)\in\pi}\gamma_\mu(u,v)\) (zero if no path exists), and return all \(x\in C\) such that \(s_\mu(x,y)\ge s_\mu(y,x)\) for every \(y\in C\).

The model it lives in

A high-multiplicity election with ranking types \(t\in T\), each carrying mass \(\mu_t\). Aggregate those masses into pairwise supports and output the candidates whose strongest-path comparisons meet the Schulze condition.

What the mirror covers

The mirror covers Theorem 1’s Schulze winner computation and applies to its successive elimination procedure. It leaves the Kemeny–Young reformulation, axioms, and runtime improvements outside its scope.

The case FOR (proponent)

This paper has no numbered result asserting a computational complexity classification, so it has no eligible anchor under your rule. The closest is Theorem 1 (proved here): for any pairwise comparison network \(\mathcal N\), SuccessiveDicut returns exactly the Schulze winner set. Corollary 1 gives a successive Schwartz-set characterization, and Proposition 3 reformulates the Kemeny–Young objective. None states that a problem is in P, NP-hard, or otherwise classifies its complexity. The runtime bounds in §5.3 are unnumbered.

The strongest plausible continuous extension is: given alternatives \(C\) and a support of \(\tau\) rankings \(t\), each with binary-rational mass \(\mu_t\ge 0\) summing to \(1\), compute the Schulze winner set. Define pairwise support by
\[ \gamma_\mu(x,y)=\sum_t \mu_t\,\mathbf{1}[x\succ_t y], \]
and compare candidates using strongest-path values, maximizing the minimum edge support along each path. A solution is the set of candidates \(x\) for which the strongest-path value from \(x\) to every \(y\) is at least the value from \(y\) to \(x\).

A plausible regime is a large ranked-ballot election with many voters but relatively few repeated ranking types, so \(n\gg\tau\). The type is a complete ranking, and its mass is the fraction of voters with that ranking. This is a natural high-multiplicity model, and the authors should recognize it as their winner-computation problem on a normalized profile. Because the masses are rational, a common denominator turns them into a finite profile; normalizing its pairwise supports only rescales every path value, leaving the winner set unchanged. That gives an exact extension of Theorem 1.

I would expect this continuous winner-computation problem to be tractable: compute pairwise supports in \(O(\tau m^2)\), then compute strongest paths in \(O(m^3)\), with exact rational arithmetic polynomial in the input bit length. But this is a weak positive case as a continuization result. The paper already works with an aggregate weighted graph, states an unnumbered runtime for its algorithm, and proves the equivalence for arbitrary pairwise comparison networks. The continuous formulation adds a sensible population regime, but appears to rescale an already-computable problem rather than reveal a new complexity question.

The case AGAINST (opponent, writing after the proponent)

The proponent’s anchor misses ChoCo’s computational-result criterion. Theorem 1 proves that SuccessiveDicut returns the Schulze winner set; Corollary 1 describes the result through strongly connected components; Proposition 3 reformulates the Kemeny–Young objective. None classifies the complexity of a computational problem. The runtime in §5.3 is unnumbered, and its input is already the weighted comparison graph.

The best continuous candidate is still coherent: take a large election with many repeated rankings, give each ranking type rational mass \(\mu_t\), and compute the Schulze winners. But the computation immediately reduces to the paper’s graph input:
\[ \gamma_\mu(x,y)=\sum_t \mu_t\,\mathbf{1}[x\succ_t y]. \]
The paper’s algorithm uses only the resulting edge weights and their comparisons. Normalizing integer vote counts to rational masses merely rescales those weights; starting from a support of \(\tau\) rankings adds the straightforward aggregation step \(O(\tau m^2)\). That is a reasonable input representation, but it does not expose a new computational structure or a complexity landscape for this paper to chart. The same applies to the Schwartz characterization and the Kemeny reformulation: both operate on the aggregate comparison data.

This is the strongest negative case, but it does not establish the requested universal claim. A high-multiplicity election is plainly a sensible continuous-population regime, and the mass formulation is a legitimate extension. I would argue that this particular paper offers little ChoCo payoff because its central computation is already stated at the aggregate-graph level; I cannot honestly rule out every worthwhile mirror.
