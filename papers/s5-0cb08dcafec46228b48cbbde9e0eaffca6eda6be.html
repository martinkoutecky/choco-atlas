The continuous mirror question

Given a rational finite-support distribution \(\mu\) over approval types \(A_t\subseteq P\), rational per-capita project costs \(c_p\), a common per-capita budget \(\beta\), fixed project tie-breaking, and the current continuous EES state, compute \(\delta^*=\inf\{\delta>0:\text{EES at }\beta+\delta\text{ changes }W\text{ or a type's paying mass for some project}\}\). Report whether the infimum is attained, or report \(+\infty\) if no such change occurs.

The model it lives in

A continuous EES population has approval types \(t\) with masses \(\mu_t\); project costs and the common budget are per capita. A paying cohort of total mass \(q\) divides project cost \(c_p\) equally, so each member pays \(c_p/q\); record the selected set \(W\) and the type-level paying masses.

What the mirror covers

The mirror covers Theorem 4.9's cardinal-utility next-change problem and transfers Theorem 5.8's cost-utility outcome-count construction. It leaves MES, the proportionality results, the experiments, and optimizing spending across the full budget path aside.

Open questions for a prover

  • Can the next-change threshold be computed in time \(\mathrm{poly}(m,\tau,L)\) by scanning weighted type breakpoints?
  • Can one optimize spending over the entire budget path without enumerating exponentially many outcomes?

The case FOR (proponent)

The strongest case is that EES already has the right kind of structure for a population mirror: voters have complete approval types, and equal-shares payments can be assigned to whole masses of identical voters. If a type’s members start with the same budget and approve the same projects, EES never needs to split them: if some can afford the equal payment, including the rest of that identical cohort only increases the feasible paying mass. The type’s mass therefore moves together through the run.

For the regime, take a citywide participatory-budgeting round or a large DAO grant vote with many members but a modest menu of repeated approval ballots. A type is an approval set \(A_t\subseteq P\), with mass \(\mu_t\), where \(\sum_t\mu_t=1\). Members of a type have the same project utilities and budget treatment. Let each project have per-capita cost \(c_p\), and give each unit of population per-capita budget \(\beta\); total costs and the total budget scale with population. This co-modification preserves EES’s economic question as the population grows. The number of people \(n\) can be much larger than the number of types \(\tau\).

My lead is Theorem 5.8, proved in the paper. It states that for every \(m\), there is an instance of size \(O(m^3)\) with cost utilities and increasing budgets \(b_1<\dots<b_{2^m}\) for which the EES winning sets are pairwise distinct. The construction has \(2m\) projects. Its continuous mirror is the following path-richness problem: given a rational type distribution, per-capita project costs, and cost utilities \(u(p)=c_p\), can there be \(2^m\) rational per-capita budgets at which continuous EES selects pairwise distinct project sets? A solution is the society and the ordered budget list witnessing those distinct sets.

This is an unusually direct fit. In the paper’s construction, the voters can be grouped into at most \(2m+1\) approval types: \(n=O(m^3)\) people, but only \(O(m)\) types. Set \(\mu_t\) to each type’s share, \(c_p=\mathrm{cost}(p)/n\), and \(\beta_i=b_i/n\). If a discrete group of \(|V|\) voters can pay \(\mathrm{cost}(p)/|V|\) each, its continuous counterpart has mass \(q=|V|/n\) and pays \(c_p/q=\mathrm{cost}(p)/|V|\). Its EES score is also preserved: \(q/c_p=|V|/\mathrm{cost}(p)\). Thus the same sequence of project sets witnesses \(2^m\) outcomes in a society with \(\tau=O(m)\) and \(n\gg\tau\). For this lower-bound question, I expect the exponential behavior to transfer directly—the Class B side of the trichotomy. This is an exponential outcome-count lower bound, not a claim of NP-hardness.

A second anchor is Theorem 4.9, proved in the paper. For cardinal utilities, it says ADD-OPT computes the minimum positive per-voter budget increase \(d\) that changes the EES solution \((W,X)\), in time \(O(mn)\). Its continuous mirror, Continuous EES Next-Change, takes a rational distribution over approval types, per-capita project costs, a baseline per-capita budget \(\beta\), and the current cardinal-utility EES outcome. At each step, a project \(p\) can be paid for by a set of approving types of total mass \(q\) if each type in that set has enough remaining budget to pay \(c_p/q\); EES selects the feasible project and paying mass with highest \(q/c_p\), with fixed project tie-breaking. The output records \(W\) and, for each type and project, the mass paying. The question is to find the smallest uniform increase \(\delta\) to everyone’s per-capita budget that changes this record. Since continuous thresholds might have an infimum of zero without a least positive increment, the precise version returns the threshold \(\inf\{\delta>0:\text{the record at }\beta+\delta\text{ differs}\}\), and says whether the threshold itself is attained.

I expect this next-change problem to be tractable in \(\mathrm{poly}(m,\tau,L)\), where \(L\) is the input bit length. The paper’s cardinal algorithm scans ordered voter budgets and leximax payments; in the mirror, identical voters form weighted cohorts, so the scan should be over cohort breakpoints rather than individuals. This is a genuine computational question about the same EES transition, not about fractional project outcomes. The main further questions are whether the more general uniform-utility result admits the same support-sensitive bound, and whether one can optimize spending over the entire budget path without enumerating its potentially exponentially many distinct outcomes.

This case covers the paper’s EES next-budget-change result for cardinal utilities and its cost-utility lower bound on the number of outcomes. It does not claim to mirror MES completion, the paper’s experiments, or its proportionality results. The paper has no numbered NP-hardness theorem for its central completion or path problems; its cited NP-hardness statement about finding an EJR outcome concerns a different question.

My weakest point is that the exponential path construction is deliberately engineered, and its existence says nothing about how often such richness appears in real PB data. Also, the proposed \(\mathrm{poly}(m,\tau,L)\) bound for Continuous EES Next-Change still needs a proof; Theorem 4.9 gives \(O(mn)\), not that support-sensitive bound. Those limitations weaken claims about practical frequency and the algorithmic payoff, but they leave the mirror itself concrete: the paper’s own outcomes and budget transitions can be posed over rational population masses, and its explicit low-type construction already shows exponential outcome variation in that regime.

The case AGAINST (opponent, writing after the proponent)

I can make a limited case against prioritizing these mirrors, but I cannot honestly defeat either anchor or support the universal claim that no worthwhile continuous mirror exists.

The best objection to Theorem 5.8 is that its continuous path-richness version looks close to an immediate corollary, rather than a new algorithmic problem. The construction has only \(O(m)\) approval types; dividing voter counts, costs, and budgets by \(n\) preserves its project choices at the corresponding rational per-capita budgets. That makes the continuous lower bound easy to establish, but it does not make it an invalid mirror: the question is well-posed, and the programme explicitly treats the discrete-to-continuous dictionary as a deliverable. The transfer shows the mirror is already answered for that construction; it does not show the broader continuous question is worthless.

Theorem 4.9 is a stronger research prospect. Its scan over voters’ budget and payment levels appears adaptable to weighted types by scanning type-level breakpoints. That adaptation needs a proof, especially that the continuous payment model does not introduce useful partial cohorts or new transition cases. But the paper’s voters have common budgets and approval types, so there is no evident identity dependence blocking the model. If the weighted algorithm is straightforward, the result may be modest; if it is not, that is a real computational question.

Nor does the natural PB scenario rescue the negative case: a large city or DAO with repeated approval ballots is a credible high-multiplicity regime, and the allowed per-capita scaling preserves the EES dynamics. The paper’s own low-support construction strengthens that fit. My honest negative position is therefore only that these particular mirrors may offer limited novelty or practical payoff. That is not enough to argue that neither is worth the programme’s time.
