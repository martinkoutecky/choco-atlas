The continuous mirror question

Given finite type and object-class sets \(T\) and \(J\), rational type masses \(\mu_t>0\) summing to \(1\), rational per-capita class supplies \(q_j>0\) summing to \(1\), rational values \(v_{tj}\), and compensation ceilings \(c_j\), find a fair allocation with a componentwise greatest payment vector. The decision variables are mass assignments \(y_{tj}\ge 0\) and class payments \(x_j\le c_j\), with \(\sum_j y_{tj}=\mu_t\) and \(\sum_t y_{tj}=q_j\); fairness requires that whenever \(y_{tj}>0\), \(v_{tj}+x_j\ge v_{t\ell}+x_\ell\) for every \(\ell\in J\).

The model it lives in

A high-multiplicity placement economy with finite valuation types \(T\), type masses \(\mu\), finite object classes \(J\), per-capita supplies \(q\), and quasi-linear values \(v_{tj}\). Assign mass \(y_{tj}\) to each type-class pair and choose class payments \(x_j\) under the compensation ceilings, seeking a fair allocation with greatest feasible payments.

What the mirror covers

Covers the fair-allocation computation grounded in Theorem 2.2 and the paper’s assignment and shortest-path algorithm; leaves the finite-agent strategy-proofness claim and its incentive guarantee unmirrored.

Open questions for a prover

  • Can the greatest-payment fair mass allocation be found in time polynomial in \(|T|\), \(|J|\), and the input bit length?
  • When do rational mass solutions translate exactly or by rounding to finite cohorts with discrete class inventories?

The case FOR (proponent)

The strongest honest case is for a narrow mirror of the optimal fair allocation problem, not for the paper’s full finite-agent strategy-proofness story. The paper has no numbered theorem that simply says “this problem is in P.” My anchor is Theorem 2.2, proved here: it gives the primal–dual characterization that the paper then uses computationally. Part (i) says that if \((\pi,x)\) is fair, then \(\pi\) is an optimal assignment, and setting \(v=-x\) and \(u(i)=V(i,\pi(i))+x(\pi(i))\) gives an optimal solution to the dual assignment problem. Part (ii) says that any optimal assignment \(\pi\) and any optimal dual solution \((u,v)\) yield a fair allocation \((\pi,-v)\). Theorem 2.1 supplies the complementary-slackness fact used in this argument; the paper cites it from standard assignment theory. The paper’s assignment-plus-shortest-path algorithm is stated in prose, rather than as a numbered complexity theorem.

Here is the continuous problem I would hand to a prover: Type-Mass Optimal Fair Assignment. An instance has a finite set \(T\) of complete valuation types, with rational masses \(\mu_t>0\) summing to \(1\); a finite set \(J\) of object classes, with rational per-capita supplies \(q_j>0\) summing to \(1\); rational values \(v_{tj}\) for every type and class; and a rational maximum compensation \(c_j\) for each class. Money can be negative. A solution consists of mass assignments \(y_{tj}\ge 0\) and class payments \(x_j\le c_j\), with \(\sum_j y_{tj}=\mu_t\) and \(\sum_t y_{tj}=q_j\). Every recipient gets one object from a class. The allocation is fair if whenever \(y_{tj}>0\), type \(t\) weakly prefers that class and payment to every other class: \(v_{tj}+x_j\ge v_{t\ell}+x_\ell\) for all \(\ell\). The task is to return a fair allocation whose payment vector is componentwise greatest among all feasible fair allocations.

I expect this mirror to be tractable (Class A), with running time polynomial in \(|T|,|J|\), and the input bit length \(L\), independent of the population represented by the masses. The reason is close to Theorem 2.2’s computational core: maximize \(\sum_{t,j}\mu_t v_{tj}y_{tj}\) subject to the mass-balance constraints, obtaining a transportation LP. Its dual potentials give class payments by the same sign change as in the theorem. Complementary slackness makes the assigned classes utility-maximizing, so the resulting allocation is fair. The remaining choice of greatest capped payments reduces to difference constraints, as in the paper’s shortest-path step. The output is a mass allocation, but each individual still receives one object class; only the type-level accounting is fractional.

A plausible regime is a large housing or job-placement program with many recipients but relatively few standardized classes of units or positions. People who share a type have the same complete valuation vector over those classes, and units of a class have the same per-capita supply and compensation ceiling. Then the input describes \(\tau=|T|\) cohorts rather than a list of every person. This co-modifies the object inventory into per-capita supplies, but it preserves the paper’s central question about assigning one indivisible object to each person under envy-freeness and compensation limits.

The mirror covers Theorem 2.2’s optimal-fair-allocation characterization and the algorithmic passage that computes an allocation from assignment and shortest-path algorithms. It does not claim to preserve the paper’s full finite-agent strategic setting. An atomless population makes an individual report unable to change aggregate payments, so any strategy-proofness statement there risks becoming a price-taking observation rather than the paper’s substantive result. The discrete algorithm in this paper is not a novelty collision: it solves the finite-agent model, while the proposed question is about a distribution over types and per-capita supplies.

My weakest point is that the authors explicitly motivate their model by the strategic importance of having relatively few agents. The high-multiplicity regime I propose pushes against that motivation, and the most central strategic claim does not carry over with equal force. The case survives only as a mirror of the paper’s fair-allocation optimization problem, whose assignment-dual structure remains intact. It also raises two useful follow-ups: whether the mass solution has a precise discrete high-multiplicity dictionary, including when fractional type flows can be rounded; and what strategic question remains meaningful when agents have positive mass or can manipulate as a coalition.

The case AGAINST (opponent, writing after the proponent)

The strongest case against is at the anchor gate. Theorem 2.2 characterizes fair allocations using optimal assignments and dual solutions; it does not state a complexity result for a named computational problem. The paper’s assignment-plus-shortest-path algorithm appears in prose. So the proposed Type-Mass Optimal Fair Assignment is a plausible new high-multiplicity question, but it is not a mirror of a *named computational result* in the paper. If that gate is strict, this anchor does not qualify.

The better version of the mirror is still hard to dismiss on modeling grounds. A large placement market with repeated valuation types and per-capita supplies is credible, and the transportation formulation preserves fair allocation while allowing each person to receive one object. The loss of individual strategy-proofness in an atomless population does not defeat this narrower mirror, which asks only for an optimal fair allocation. Nor does the paper’s small-population motivation rule out another instance regime.

That leaves the negative case narrow and weak: it depends on treating the absence of a numbered complexity theorem as disqualifying. If the paper’s prose algorithm is accepted as the computational anchor, the proposed mass model survives; I cannot honestly argue that no worthwhile scenario exists.
