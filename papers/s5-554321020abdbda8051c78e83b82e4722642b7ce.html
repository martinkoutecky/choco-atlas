The continuous mirror question

Given finite projects \(C\), rational costs \(\operatorname{cost}(c)\), budget \(b>0\), finite complete additive valuation types \(\Theta\) with \(u_\theta:C\to[0,1]\cap\mathbb{Q}\), and rational population masses \(\mu\in\mathbb{Q}_{\geq 0}^{\Theta}\) satisfying \(\sum_\theta\mu_\theta=1\), output an integral project set \(W\subseteq C\) with \(\operatorname{cost}(W)\leq b\) satisfying mass-EJR: for every \(T\subseteq C\), \(\alpha:C\to[0,1]\), and subpopulation \(\lambda\in\mathbb{R}_{\geq 0}^{\Theta}\) with \(\lambda\leq\mu\), if \(\sum_\theta\lambda_\theta\geq\operatorname{cost}(T)/b\) and \(u_\theta(c)\geq\alpha(c)\) for every \(\theta\) with \(\lambda_\theta>0\) and every \(c\in T\), then some such \(\theta\) satisfies \(u_\theta(W)\geq\sum_{c\in T}\alpha(c)\).

The model it lives in

A high-multiplicity PB model with complete additive valuation types \(u_\theta\), population mass \(\mu\), and indivisible projects; the decision variable is an integral project set \(W\), feasible when \(\operatorname{cost}(W)\leq b\), and the task is to find any \(W\) satisfying mass-EJR. For \(\mu_\theta=1\), this becomes the type's knapsack optimum.

The objection that survived

The hardness witness can be the Dirac population \(\mu_\theta=1\), so it says nothing about heterogeneous populations or population-sensitive computation; the continuous formulation may therefore add little beyond removing duplicate names.

fatal: False

What the mirror covers

It mirrors Proposition 1's EJR hardness, including its one-type knapsack subfamily. It leaves the paper's numbered guarantees for Equal Shares, approximate core, GCR, priceability and exhaustiveness, and ordinal PSC unmirrored.

Open questions for a prover

The case FOR (proponent)

The strongest honest positive case is a high-multiplicity version of the paper’s general PB problem, anchored in its hardness result rather than pretending that the paper proves a new continuous algorithm.

The continuous problem is Continuous EJR Outcome. An instance consists of a finite project set \(C\), rational project costs \(\operatorname{cost}(c)\), a rational budget \(b>0\), and a finite set of voter types \(\Theta\). Type \(\theta\) is the complete additive valuation vector \(u_\theta:C\to[0,1]\cap\mathbb{Q}\). The population is a distribution \(\mu\in\mathbb{Q}_{\geq 0}^{\Theta}\) with \(\sum_{\theta}\mu_\theta=1\).

A solution is an integral project set \(W\subseteq C\) with \(\operatorname{cost}(W)\leq b\). Projects remain indivisible; only the population is continuous. The objective is to output any \(W\) satisfying the following population version of EJR. For every project set \(T\), threshold function \(\alpha:C\to[0,1]\), and subpopulation \(\lambda\) with \(0\leq\lambda_\theta\leq\mu_\theta\), if

\[ \sum_{\theta}\lambda_\theta\geq \frac{\operatorname{cost}(T)}{b} \]

and every type with \(\lambda_\theta>0\) satisfies \(u_\theta(c)\geq\alpha(c)\) for every \(c\in T\), then some type with \(\lambda_\theta>0\) must satisfy

\[ u_\theta(W)\geq \sum_{c\in T}\alpha(c). \]

This is directly the paper’s EJR condition with voter counts replaced by population mass. It does not continuize projects, utilities, lotteries, or time.

The natural regime is a city-wide participatory-budgeting election with hundreds of thousands of residents but a much smaller catalogue of recurring valuation profiles: for example, residents with the same approval ballot, or the same point allocation over a standard project catalogue. The relevant regime is \(n\gg\tau\), where \(n\) is the number of residents and \(\tau=|\Theta|\) is the number of distinct complete types. Exact type repetition is plausible when the interface offers a finite approval or scoring language, and it is precisely what high multiplicity means. Project costs remain common public parameters, as in the paper.

The lead anchor is Proposition 1, proved in this paper:

“Unless \(P=NP\), no aggregation rule that can be computed in strongly polynomial time can satisfy EJR in the general PB model.”

The paper’s argument is that with one voter, EJR forces the rule to solve that voter’s knapsack problem: taking the grand coalition and setting \(\alpha(c)=u_1(c)\), every feasible counterproposal \(T\) must be matched by an outcome with at least as much utility. The paper notes the corresponding weakly NP-hard obstruction, and also observes that cost utilities already give subset sum.

In the continuous mirror, the “one voter” instance becomes a population with one type, \(\mu_\theta=1\): an arbitrarily large homogeneous society. For that type, Continuous EJR requires \(W\) to maximize

\[ \sum_{c\in W}u_\theta(c) \]

subject to \(\operatorname{cost}(W)\leq b\), which is exactly knapsack. Thus the expected classification is Class B: hardness transfers, because the combinatorics live in the project set and budget constraint, not in the number of named voters. A strongly polynomial algorithm in \(m\), \(\tau\), and the numerical operations would already solve this one-type subfamily. More generally, with rational \(\mu\), multiplying by a common denominator produces a finite election with \(q\mu_\theta\) copies of each type, giving the paper’s finite model back exactly.

This is a credible mirror of the authors’ problem because it preserves their central objects: indivisible projects, arbitrary costs, additive utilities, proportional budget shares, and EJR’s coalition guarantee. It is not a tractable caricature. Indeed, the point of the mirror would be to show that population continuization does not dissolve this particular difficulty. The continuous formulation removes irrelevant dependence on the number of duplicate residents while exposing the genuine project-selection hardness.

The weakest point is that the paper has only a narrow named computational anchor. Proposition 1 gives a lower-bound obstruction, but the paper’s positive polynomial-time claim for Equal Shares appears in the surrounding discussion and implementation section rather than as a numbered complexity theorem. Theorem 2 is a named EJR-up-to-one guarantee, and Theorem 3 is a named core-approximation guarantee, but neither is itself a formal complexity classification. I would therefore not present them as additional anchors.

The mirror nevertheless generates useful follow-up questions: whether Continuous EJR admits an FPTAS or an exact algorithm parameterized by \(\tau\) or the number of utility levels; whether Equal Shares has a genuinely type-level implementation with complexity polynomial in \(m\), \(\tau\), and input bit length; and whether the paper’s EJR-up-to-one and approximate-core guarantees survive unchanged when coalitions are arbitrary positive-mass subpopulations. The central first question, however, is the precise Continuous EJR Outcome problem above, and the best prediction is that its hardness survives continuization.

The case AGAINST (opponent, writing after the proponent)

The strongest negative case is that Proposition 1 is a very weak continuization anchor. Its proof uses \(n=1\), so the proposed continuum instance is simply a Dirac population \(\mu_\theta=1\). EJR then says exactly that the selected project set must solve

\[ \max\left\{\sum_{c\in W}u_\theta(c):\operatorname{cost}(W)\le b\right\}, \]

which is knapsack. The population has contributed no structure: no coalition interaction, type heterogeneity, or mass-transfer decision remains. In the general finite-type formulation, rational masses can likewise be cleared of denominators and replaced by repeated voters, so the “continuous” problem is exactly a weighted finite PB instance.

One can strengthen the objection measure-theoretically. The paper’s EJR witness is “there exists one voter.” In an atomless population that becomes “there exists one supported type,” not a positive-mass guarantee. Thus the literal continuum axiom is insensitive to how much mass receives the representation. Requiring a positive fraction of the coalition to be represented would be more genuinely continuous, but it would be a new axiom rather than the paper’s EJR mirror.

Those are real reservations about substantive novelty, but they do not defeat the anchor under ChoCo’s stated rules. A city with many residents sharing standardized approval or point-allocation ballots is a legitimate high-multiplicity regime; common valuation types are precisely what the programme defines as meaningful. The fact that the one-type subcase retains knapsack hardness is not an admissible objection: it is a legitimate Class B result, and indivisible projects are allowed to remain integral while only the population is continuized. Nor is exact equivalence with denominator-cleared finite elections a collision; it is the expected high-multiplicity bridge.

Accordingly, I cannot honestly make the universal negative case. The mirror is low-novelty and population-insensitive in its strongest subcase, but it is well-posed, application-plausible, and anchored in a named computational proposition. Proposition 1 survives the attempted attack.
