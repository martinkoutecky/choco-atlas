Why no mirror

Theorem 1 characterizes α-permissiveness through independent sets, but it does not state an algorithm or a complexity result for stable-allocation existence. A continuous question for dense, role-based networks is plausible, yet the paper has no named computational result to anchor it.

What the mirror covers

The proposed blockmodel would revisit Theorem 1’s permissiveness question for dense, role-based comparison networks; it leaves Proposition 1’s allocation-level condition, the directed and limited-enforcement extensions, and the random-network comparative statics outside.

Open questions for a prover

  • Does Theorem 1’s independent-set characterization extend to this atomless blockmodel, with a measurable independent set of mass at least \(1-α\)?

The case FOR (proponent)

The strongest foothold is Theorem 1, “Permissive networks” (proved in this paper). It says that for any finite network and any preference profile between the baseline ranking preference and the strong ranking preference, an \(\alpha\)-stable allocation exists if and only if the network has an independent set of at least \((1-\alpha)n\) agents. The paper also notes that finding a largest independent set in an arbitrary network is NP-hard. Thus, when \(\alpha\) is part of the input, Theorem 1 gives an exact route from the paper’s stable-allocation question to a familiar hard decision problem.

There is a qualification: Theorem 1 does not itself state a complexity classification, and the NP-hardness observation is not a numbered result. Strictly applying your anchor rule, this paper has no numbered computational result asserting P, NP-hardness, or another complexity class. Theorem 1 is the nearest structural anchor; treating its consequence for the decision problem as a computational anchor is the strongest positive reading I can defend.

The lead mirror would be the Continuum Network Permissiveness problem. An instance consists of a finite set \(T\) of network types, rational masses \(\mu_t>0\) summing to \(1\), a rational \(\alpha\in(0,1)\), and a symmetric finite-step network kernel \(a_{tt'}\). Type \(t\) means an agent with that same comparison pattern toward every type \(t'\); \(a_{tt'}\) records the intensity of comparison between the two types. The population is atomless within each type, with mass \(\mu_t\). A feasible allocation is a measurable income function \(u\geq 0\) with total resource \(\int u=1\). Agent \(x\) has local ranking score
\[ r_x(u)=\int a_{t(x)t(y)}\,\mathbf{1}\{u(y)\geq u(x)\}\,dy. \]
An allocation is \(\alpha\)-stable if there is no alternative feasible allocation \(v\) and measurable coalition \(S\) of mass greater than \(\alpha\) such that \(r_x(v)<r_x(u)\) for almost every \(x\in S\). The question is whether such a stable allocation exists; a yes-solution is a measurable allocation witnessing it. This preserves the paper’s ranking preferences, resource constraint, and blocking rule. It makes the population continuous; the income allocation is part of the original model, not the point of continuization.

A plausible regime is a large workforce with repeated roles or departments: many employees share the same comparison pattern, while the number of distinct patterns is much smaller than the workforce. That is a substantive assumption about the setting, not a claim that all social networks have few types. A finite-step kernel is a compact way to encode those shared reference patterns.

I would provisionally expect hardness to transfer. The finite characterization points directly to an independent-set threshold, and the paper identifies that problem as NP-hard. The key question for a prover is whether the characterization survives when each network type has a continuum of members: does stable-allocation existence coincide with the existence of an independent population subset of mass at least \(1-\alpha\)? If it does, the finite-type kernel problem inherits the independent-set obstruction as the number of types grows. Further questions include whether the problem is tractable when the number of types is fixed, and whether atomless allocation variation can produce stable allocations even when no sufficiently large independent set exists.

The weak point is real: the paper’s necessity proof uses a finite greedy construction, and the text does not establish its continuum analogue. Also, a block kernel suppresses individual network structure, which may matter to the authors. So this is a credible mirror question, not a result already licensed by Theorem 1—and, under the strict anchor rule, the paper supplies no fully qualifying named computational anchor.

The case AGAINST (opponent, writing after the proponent)

The strongest case against is that this paper has no named computational result to mirror. Theorem 1 characterizes when a finite network permits a stable allocation; it makes no complexity claim about a computational problem. The paper’s observation that finding a largest independent set is NP-hard does not classify stable-allocation existence, and the other numbered results are structural conditions or comparative statics. So “Continuum Network Permissiveness” is a new computational question suggested by the paper’s characterization, rather than a mirror of one of its computational results. Under the stated anchor rule, the proposed anchor fails.

The best version of the mirror is still coherent: model a large, dense population with repeated roles, where everyone in one role compares with everyone in certain other roles. A finite-step kernel represents those comparisons, and a measurable allocation and blocking coalition make sense. But that model adds a strong symmetry assumption. In the paper, an edge identifies a particular person whose allocation enters a neighbor’s ranking. A type-pair kernel instead makes the relation uniform across whole groups. To preserve arbitrary individual networks, one would need types that encode increasingly detailed neighborhood identities; grouping people into a fixed number of roles changes the network model.

That concern is sharpest for sparse networks, where agents have only a bounded number of neighbors as the population grows. Normalizing neighbor counts into masses makes each agent’s comparison neighborhood vanish in the limit; retaining unnormalized counts does not yield an ordinary population-mass model. A dense blockmodel avoids that collapse, but covers a narrower regime.

This is a substantial reason not to prioritize the paper as a ChoCo mirror: its results are about network structure, and it supplies no computational theorem for the programme to continuize. It does not, however, defeat the strongest blockmodel mirror as a worthwhile question. If the authors accept dense, role-based comparison networks as a regime of their problem, the continuum formulation is plausible. I cannot honestly make the universal negative claim airtight on the material given; the case is strongest at the anchor gate and weaker against that restricted scenario.
