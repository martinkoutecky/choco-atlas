Theorem 5.1

The continuous mirror question

Given a rational distribution μ over recipient types \(t\), additive values \(v_{tj}\) for indivisible good classes \(j\), and per-recipient supplies \(b_j\) with \(\sum_j b_j \geq 1\), choose assignment masses \(x_{tj} \geq 0\) satisfying \(\sum_j x_{tj}=μ_t\) and \(\sum_t x_{tj}\leq b_j\). What is the maximum \(\lambda\) such that \(x_{tj}>0\) only when \(v_{tj}\geq\lambda\), and what assignment attains it?

The model it lives in

A max-min capacitated assignment of a continuous population: each type’s mass is split among good classes, every assigned unit of mass receives one indivisible item, and the objective maximizes the minimum value \(v_{tj}\) among assigned type-class pairs.

The objection that survived

The opponent notes that the proposed mass assignment gives no rule for the later envy-cycle eliminations or guarantee for the theorem’s strong welfare prices; the proponent acknowledges this gap but does not resolve it.

fatal: False

What the mirror covers

The mirror covers the max-min matching initialization in Theorem 5.1. It leaves the subsequent envy-cycle eliminations, the theorem’s strong-price guarantees, the other heuristics, and the empirical results unmirrored.

Open questions for a prover

  • Can this max-min initialization be integrated with a well-defined mass-level ECE continuation that yields a welfare-price guarantee in terms of type support and per-capita supplies?

The case FOR (proponent)

The strongest honest positive case is narrow: the paper contains no named result classifying a problem as NP-hard, in P, FPT, or similar. Its closest computational anchor is Theorem 5.1, proved here. It says that ECE with the max-min matching heuristic has strong utilitarian price \(n^2\), and strong egalitarian price \(m-n+1\) when \(m\ge n\), or \(1\) when \(m<n\). That is a named algorithmic guarantee, but it is not a complexity classification. So if the anchor requirement is literal, this paper has no qualifying anchor.

Theorem 5.1 does, however, use a clear computational subproblem: its heuristic starts by finding a max-min matching, assigning one good to each agent so that the least utility is as large as possible. A plausible high-multiplicity setting is a large relief or furnishing programme with many recipients, standardized goods, and relatively few distinct preference profiles. A type is a recipient’s complete additive utility vector over the good classes; mass \(\mu_t\) is the fraction of recipients of type \(t\). For each class \(j\), suppose there are \(b_j\) units per recipient. As the population grows, the supply of each class grows proportionally. The number of recipients is then large while the number of types \(\tau\) and good classes \(q\) stays moderate.

The resulting problem, Continuous Max-Min Assignment, is: given rational \(\mu_t\), per-capita supplies \(b_j\), and utilities \(v_{tj}\), choose fractions \(x_{tj}\) of type \(t\) to receive one unit of class \(j\), with \(\sum_j x_{tj}=\mu_t\) and \(\sum_t x_{tj}\le b_j\). Maximize \(\lambda\) subject to \(x_{tj}>0\Rightarrow v_{tj}\ge\lambda\). Each recipient still gets an indivisible good; splitting \(x_{tj}\) means splitting a type cohort across assignments, not giving an individual a fractional item. A solution is the value \(\lambda\) and a feasible assignment attaining it.

This is a genuine population continuization of the matching computation in Theorem 5.1. It is expected to be tractable: for a proposed \(\lambda\), keep only type–good edges with \(v_{tj}\ge\lambda\) and test whether a capacitated bipartite flow can assign all mass. There are finitely many candidate thresholds, among the input utilities, so the optimum can be found with polynomially many flow computations in \(\tau\), \(q\), and the input bit length. This is a Class A prediction for the matching subproblem, not a claim that the paper’s full ECE price theorem transfers.

The scope is deliberately limited to the max-min matching initialization used by Theorem 5.1. A further question is whether the subsequent envy-cycle elimination process also has a useful continuous-population formulation, and what strong egalitarian price that process guarantees. The theorem’s bound itself does not supply a finite population-independent guarantee under proportional supply scaling: with \(N\) recipients and total per-capita supply \(B=\sum_j b_j\ge1\), the factor \(m-n+1\) becomes \(N(B-1)+1\). The number of types being small might change that behavior, but the paper establishes no such result.

That scaling is the weakest point in the positive case, along with the anchor mismatch: the mirror I believe in is a precise, tractable subproblem of the theorem’s heuristic, while the theorem itself concerns the full ECE execution and proves a welfare ratio. If the requested anchors must be complexity-class results, this candidate should not be counted as satisfying the anchor requirement.

The case AGAINST (opponent, writing after the proponent)

The best objection is that Theorem 5.1 is not a complexity classification. It bounds the welfare price of an ECE heuristic; it does not classify the complexity of a decision or optimization problem. The proposed continuous max-min assignment mirrors only the heuristic’s initialization. Its threshold-flow solution says nothing about the theorem’s main object: the welfare ratio after the remaining goods are allocated and envy cycles are eliminated.

That gap matters for a full population mirror. ECE proceeds through individual allocations and bundle exchanges between agents. If the population grows and supplies scale with it, each single allocation changes a vanishing fraction of society. Batching those steps into a mass process would require new rules for which cohorts receive goods and how cycles exchange bundles. Tracking the resulting bundle histories may also require enlarging the type space. Those choices could define a worthwhile new model, but they do not follow from Theorem 5.1. The clean flow formulation avoids the issue by stopping at the first \(n\) assignments—and so leaves the theorem’s ECE dynamics out.

Still, I cannot make this a strong argument that no worthwhile mirror exists. Continuous max-min assignment is a coherent population problem: types can split across assignments while each person receives an indivisible good, and the capacities can scale per capita. The fact that its solution reduces to a finite sequence of flow computations does not disqualify it under the programme’s criteria. So the negative case defeats Theorem 5.1 as an anchor for the *full welfare-price result*, but it does not defeat the proposed assignment problem as a mirror of the theorem’s computational subroutine. On that broader reading, this case is weak.
