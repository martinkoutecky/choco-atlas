The continuous mirror question

Given a finite type set \(T\), rational masses \(\mu_t>0\) with \(\sum_{t\in T}\mu_t=1\), rational internal opinions \(s_t\in[0,1]\), a symmetric nonnegative rational interaction kernel \(q_{tu}\), a leader-mass budget \(\kappa\in[0,1]\), and accuracy \(\eta>0\), choose \(x_t\) with \(0\le x_t\le\mu_t\) and \(\sum_t x_t=\kappa\). Define the ordinary-agent equilibrium by \(z_t(x)=\frac{s_t+\sum_{u\in T}q_{tu}(\mu_u-x_u)z_u(x)}{1+\sum_{u\in T}q_{tu}\mu_u}\), and let \(H_\mu(x)=\sum_t(\mu_t-x_t)z_t(x)\). Is there an algorithm polynomial in \(|T|\), the input bit length, and \(1/\eta\) that returns a feasible rational \(x\) with \(g(x)\ge(1-1/e)(g^*-\eta)\), where \(g(x)=H_\mu(0)-H_\mu(x)\) and \(g^*=\max_{\sum_t y_t=\kappa,\ 0\le y_t\le\mu_t}g(y)\)?

The model it lives in

A block-structured FJ network with rational population masses, type-level internal opinions and symmetric interaction rates; the decision variable is the leader mass \(x_t\) per type, and the objective is the reduction in aggregate equilibrium opinion.

What the mirror covers

The mirror covers OMin’s leader-selection objective and the approximation question motivated by Theorem 6. It leaves out BES, arbitrary non-block networks, the experiments, and other opinion-optimization problems.

Open questions for a prover

  • Does the type-level objective have the diminishing-returns structure needed for a near-\((1-1/e)\) guarantee?
  • Can that guarantee be achieved in time polynomial in the number of types, input bit length, and \(1/\eta\)?
  • How closely do finite block networks approximate this type-level model as their populations grow?

The case FOR (proponent)

The strongest mirror is a mass-allocation version of the paper’s original opinion-leader problem on a block-structured social network. It keeps the same Friedkin–Johnsen dynamics, leader intervention, and aggregate-equilibrium objective; it changes the unit of choice from individual nodes to fractions of a population.

Lead problem: Continuum Opinion-Leader Allocation (C-OMin). An instance consists of a finite set of types \(T\), rational masses \(\mu_t>0\) summing to \(1\), rational internal opinions \(s_t\in[0,1]\), a symmetric nonnegative rational interaction kernel \(q_{tu}\), a leader budget \(\kappa\in[0,1]\), and an accuracy \(\eta>0\). A type completely specifies an agent’s internal opinion and influence on, and from, each type. The population has very many agents but relatively few types: for example, users grouped by role, susceptibility, and community-level contact rates, with thousands or millions of users per type. The kernel represents the interaction rates between those groups.

Choose leader masses \(x_t\) satisfying \(0\le x_t\le\mu_t\) and \(\sum_t x_t=\kappa\). Each unit of leader mass is fixed at opinion \(0\); everyone else follows the same FJ equilibrium dynamics as in the paper. The equilibrium opinion \(z_t\) of ordinary agents of type \(t\) is defined by \(z_t=(s_t+\sum_u q_{tu}(\mu_u-x_u)z_u)/(1+\sum_u q_{tu}\mu_u)\). Minimize \(H_\mu(x)=\sum_t(\mu_t-x_t)z_t\), the aggregate equilibrium opinion. A solution is a feasible rational vector \(x\) whose improvement \(g(x)=H_\mu(0)-H_\mu(x)\) satisfies \(g(x)\ge(1-1/e)(g^*-\eta)\), where \(g^*=\max_x g(x)\). This is the population-mass analogue of selecting \(k\) individual leaders to reduce the aggregate opinion in OMin.

The anchor is Theorem 6, proved in this paper. It states that DDEA’s output \(L_k\) satisfies \(H(\emptyset)-H(L_k)\ge(1-1/e)(H(\emptyset)-H(L_o)-2k\epsilon)\), where \(L_o\) is an optimal set of \(k\) leaders. The paper gives DDEA expected running time \(\widetilde O(kmn)\). The theorem is an algorithmic anchor; the supplied paper has no comparable named hardness result. The proposed mirror asks whether the same near-\((1-1/e)\) improvement guarantee can be obtained in time polynomial in the number of types, input bit length, and \(1/\eta\), with no dependence on the underlying population size.

I expect this mass-allocation problem to be Class A for the stated block-network regime. The paper’s Theorem 2 proves that \(H(L)\) is supermodular, so the improvement from adding leaders has diminishing returns in its discrete model. That gives a reason to investigate a continuous diminishing-returns formulation and continuous optimization methods. It does not itself establish the needed property or algorithm for \(H_\mu(x)\); those are exactly the questions for the prover. The mirror is plausible because it still allocates opinion leaders to change the same network equilibrium objective. In a finite block network with many nearly interchangeable agents per block, \(x_t\) is the honest population-scale decision: agents remain individually either leaders or ordinary members, while the intervention is specified as a share of each group.

The scope is deliberately limited to the paper’s OMin reformulation and its greedy leader-selection result. It does not claim a mirror for arbitrary sparse graphs, BES’s SDDM evaluation method, the paper’s experimental comparisons, or other opinion-optimization objectives. Further questions include whether the type-level objective has the continuous diminishing-returns property needed for the guarantee; how accurately finite block graphs approximate it as population grows; and whether the exact optimum is tractable or only the approximation is.

The weak point is that the paper’s graph model can encode detailed node-level topology, while this mirror retains only type-level interaction rates. Real users within a behavioral or community type may still have very different neighbors, so the proposed regime cannot stand in for every network studied by the paper. Nor does Theorem 6’s node-by-node greedy algorithm automatically transfer to fractional leader masses. The case survives as a mirror for a concrete, plausible high-multiplicity regime: it preserves the intervention and equilibrium objective, while making the population itself continuous.

The case AGAINST (opponent, writing after the proponent)

The strongest objection is that Theorem 6’s gains depend on the exact placement of leaders in the network. Its \(O(kmn)\) algorithm uses each node’s position in the graph, and the equilibrium depends on the graph’s full interaction structure. The proposed C-OMin model preserves that structure exactly only for networks with a strong block symmetry: every agent in a type must have the same interaction with each other type. Replacing irregular neighborhoods with average interaction rates can change the equilibrium and the value of choosing a leader, since those quantities depend on an inverse network operator, not just block averages.

That limits how far the mirror represents the paper’s general network problem. If types record enough detail to preserve an arbitrary sparse graph, most nodes may need distinct types, leaving little high-multiplicity compression. A graphon model could retain more structure for dense networks, but a general kernel needs its own finite input representation; for sparse networks, local neighborhood structure may likewise require many types. Theorem 2 does not resolve this: its supermodularity result concerns sets of vertices, and the fractional mass objective needs its own analysis.

This objection does not defeat the proposed anchor. Exact block networks with many exchangeable users per type form a coherent high-multiplicity regime, and a fixed positive leader share avoids the vanishing effect of a fixed number of leaders as the population grows. Theorem 6 therefore motivates a well-posed continuous question there, even though its guarantee does not carry over automatically. The honest negative case is weak: it challenges the mirror’s reach, but cannot establish that no worthwhile mirror exists.
