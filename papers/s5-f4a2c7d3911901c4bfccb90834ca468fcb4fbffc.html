The continuous mirror question

Given a finite catalogue of undirected FEN module types \(H\), each with \(|V(H)|\le q\), fixed coalition-size bound \(c\), and rational agent masses \(\lambda_H\) summing to \(1\), what is the minimum normalized relation-edit mass needed to give every module copy a perfect coalition partition? Equivalently, distinguish \(\mathrm{OPT}=0\) from \(\mathrm{OPT}>\epsilon\), where \(\mathrm{OPT}=\frac{1}{d}\sum_{H,a}x_{H,a}\frac{|R_a|}{|V(H)|}\), \(a\) ranges over valid local repair-and-partition plans, and \(\sum_a x_{H,a}=\lambda_H\).

The model it lives in

The society is a distribution over bounded-size FEN module templates, with each copy retaining its internal friend and enemy links. Each plan deletes relation edges and partitions the module into coalitions of size at most \(c\), so every member’s coalition contains all remaining friends and no remaining enemies. Variables \(x_{H,a}\) allocate agent mass of type \(H\) to such plans; minimize the mass-weighted number of deleted edges per agent, normalized by \(d\).

What the mirror covers

Covers Theorem 16’s perfect-coalition existence question and its relation-edit distance for repeated bounded-size modules; leaves the paper’s arbitrary-graph query-testing results, other stability notions, and directed lower bound aside.

Open questions for a prover

  • For fixed \(q\), can the local repair plans and exact mass allocation be handled by a polynomial-time algorithm in the catalogue size and input bit length?
  • When \(q\) is part of the input, is there a compact optimization method for the local repair choices?

The case FOR (proponent)

My lead is a continuous version of the paper’s perfect-coalition existence problem, scoped to a natural high-multiplicity regime: a large advertising system built from many repeated, bounded-size interaction modules. Each module is a small network of ads with friend and enemy relations. Across the system there may be millions of agents but only \(\tau\) distinct module types and their roles.

The anchor is Theorem 16, proved in this paper’s Section 4.2. It says that for undirected, unweighted FEN-hedonic games of maximum degree \(d\), with a fixed coalition-size bound \(c\), there is a one-sided-error tester for whether a perfect coalition structure exists, using a number of queries independent of the number of players. It accepts every game with a perfect structure and rejects with probability at least \(2/3\) when the game is more than \(\epsilon d n\) edge modifications from having one. The tester samples vertices and explores their friend-connected components; it rejects if one exceeds \(c\) or if an enemy edge joins two vertices in the same friend-connected component. Those conditions characterize the obstruction: every friend-connected component must fit in one coalition, and no enemy edge may lie within it.

The proposed mirror is Continuous Perfect-Partition Repair. Fix constants \(d,c\), and let the input be a finite catalogue \(\mathcal H\) of FEN interaction modules, each of size at most a fixed \(q\), together with rational masses \(\lambda_H\ge 0\) summing to \(1\). Here \(\lambda_H\) is the fraction of agents who belong to copies of module \(H\); each position \(v\in V(H)\) is a role type, with mass \(\lambda_H/|V(H)|\). A copy preserves all the module’s friend and enemy links, so agents of the same role type have the same relevant relationships, utilities, and coalition constraints. This retains the network structure rather than replacing each agent with an independent preference description.

For each module \(H\), a repair plan \(a=(R,\Pi)\) deletes a set \(R\) of relation edges and partitions the module’s agents into coalitions \(\Pi\) of size at most \(c\). The plan is valid if every agent’s coalition contains all their remaining friends and no remaining enemies. With positive friend and enemy values, that is exactly the paper’s perfection condition. Let \(x_{H,a}\) be the fraction of the agent mass of type \(H\) assigned to plan \(a\), with \(\sum_a x_{H,a}=\lambda_H\). The problem is to minimize

\[ \mathrm{OPT}_{\mathrm{perf}}(\lambda) = \frac{1}{d} \sum_{H\in\mathcal H}\sum_a x_{H,a}\frac{|R_a|}{|V(H)|}. \]

This is the minimum edge-repair cost per \(dn\), matching the paper’s distance normalization. A solution is an optimal mass allocation \(x\), with a repair and perfect partition for every plan used. The decision variant asks whether the society already admits a perfect structure, \(\mathrm{OPT}_{\mathrm{perf}}=0\), or is more than \(\epsilon\)-far, \(\mathrm{OPT}_{\mathrm{perf}}>\epsilon\). That is the closest continuous counterpart of Theorem 16’s promise problem.

I expect this fixed-\(q\) version to be tractable (Class A): each module type has finitely many repair-and-partition options, so the mass allocation is a linear program with a number of variables polynomial in \(\tau\). The result preserves the paper’s underlying question—whether agents can be placed into favorite coalitions, and how much relation editing would make that possible—while replacing repeated copies with their masses.

The scenario is plausible when the same bounded interaction templates recur across many pages, inventory groups, or campaigns. A type is the complete module-and-role description, not merely an agent’s local friend count; mass is the fraction of the population in that role. The authors could reasonably recognize the problem as their perfect-partition question in a repeated-module population. Existing high-multiplicity work would support the regime’s legitimacy, rather than count as a novelty collision.

The scope is deliberately narrow: this mirrors Theorem 16’s undirected perfect-existence result, not every stability notion or directed oracle model in the paper. It also raises natural follow-ups: what happens when module size \(q\) is part of the input; which repair patterns admit a compact separation oracle; and whether the same mass-repair formulation works for Nash or core stability.

The weakest point is that the paper’s main computational gain is a query bound independent of \(n\), while this mirror receives a finite module catalogue and its masses as input. Restricting to repeated bounded-size modules also removes much of the topology variation that makes arbitrary graphs difficult. So this is an honest, recognizable high-multiplicity mirror of one result, but it does not explain the paper’s general property-testing phenomenon or establish that its hardness barriers dissolve in a continuum.

The case AGAINST (opponent, writing after the proponent)

Theorem 16 is a real computational result, so “there is no result to mirror” cannot carry the negative case. The strongest objection is that its input is a relational graph, while a distribution over agent types records only masses. In a general FEN graph, knowing each agent’s local friend/enemy pattern does not say which agents are connected to one another. Encoding those partners exactly can make almost every agent a distinct type, so \(\tau\) grows with the population and the high-multiplicity advantage disappears.

The repeated-module construction addresses that problem by keeping each module’s links intact. Its cost is a narrower input regime: the society is a mass of independent copies, and the algorithm receives the module catalogue. The paper’s tester receives oracle access to an arbitrary bounded-degree graph and needs no decomposition into recurring components. Thus the proposed LP studies a sound repeated-module repair problem, but it does not capture the general graph-testing phenomenon behind Theorem 16.

That objection does not defeat the best version of the mirror. One can take full connected components as types, assign rational mass to each component type, and ask for the minimum mass-weighted relation repair that permits perfection. This preserves the relevant links, gives a direct analogue of the paper’s edge-edit distance, and describes a plausible population of recurring interaction modules. It may require solving a repair problem for each component type, but that is a computational question the programme could investigate.

So the negative case is weak at its decisive point. A distribution over ordinary agent types does not preserve arbitrary network structure, and the fixed-size module version is narrower than the theorem’s input model. Yet the component-type version remains a coherent, potentially worthwhile continuous mirror of Theorem 16. I cannot honestly argue that no scenario makes this anchor worth pursuing.
