The best possible rescue would normalize a margin matrix by a known population size \(K\), set \(D=\Delta L/K\), and ask for a distribution \(\mu\) over rankings whose expected pairwise comparisons equal \(D\). That is a coherent continuous-population reconstruction problem. But it is not a computational result established by this paper. When \(K\) is unknown, as the paper allows, the raw margins do not specify the normalized quantities for a unit-mass society. When \(K\) is known, the paper’s input comes from actual experts, so a realizing empirical distribution exists; finding some realization is a new witness-finding problem. Adding a criterion such as minimum support or maximum entropy would make the task more selective, but would add an objective the paper does not study. The paper itself emphasizes that its reconstruction is ambiguous and need not recover the original opinions.

That is a substantial negative case against treating this paper as an anchored complexity mirror. It does not prove the universal claim that no scenario could make the continuous reconstruction problem worthwhile: large populations with shared rankings are plausible, and finding a distribution from pairwise data fits the programme’s subject. The honest limit is that this would be a new project motivated by the paper’s construction, rather than a continuization of a computational result the paper proves.
