Theorem 1

  • Theorem 2 — fell: The stated singleton-coordinate correction does not carry to normalized type counts without a new guarantee that those singleton patterns are feasible.
  • Theorem 3 — fell: The opponent shows that coordinate-by-coordinate correction on binary allocation vectors does not establish the same bound for type-count patterns.

The continuous mirror question

Given rational masses \(\mu_t=N_t/N\) for \(\tau\) complete valuation types, a type-indexed packing relaxation \(P_\mu\subseteq[0,1]^d\) with \(d\) depending on types and bundle options, an optimal fractional welfare point \(x^\star\), and an efficient \(\alpha\)-integrality-gap verifier returning feasible integral count-allocation patterns, can one output a lottery \((\lambda_j,z^j)\) over those patterns with \(\left\|\sum_j\lambda_j z^j-x^\star/\alpha\right\|_2\le\epsilon\) using \(O(d\epsilon^{-2})\) verifier calls independently of \(N\)? Each pattern records how many members of each type receive each integral bundle.

The model it lives in

A high-multiplicity allocation market represented by rational type masses. Outcomes are feasible per-type counts of members receiving integral bundles; the decision variables are lottery weights on those count patterns, and the target is a scaled fractional welfare allocation. The computational task is to approximate that target by a short lottery using an integrality-gap verifier.

The objection that survived

The stated binary pattern gives every member of a type the same bundle, so it cannot represent allocating a scarce item to only some members; the paper also gives no type-count complexity bound. The count-based formulation repairs the allocation model but requires a new analysis.

fatal: False

What the mirror covers

The mirror covers the approximate decomposition in Theorem 1 for type-count allocation patterns. The singleton correction in Theorem 2 and the exact coordinate correction in Theorem 3 are not established for that model; the mirror also does not cover the paper’s full incentive and payment claims.

Open questions for a prover

  • Can a type-indexed integrality-gap verifier run in time polynomial in the number of types, bundle options, and input bit length, independently of population size?
  • Does the paper’s \(O(d\epsilon^{-2})\) decomposition bound extend to normalized bounded-integer count patterns?
  • What finite high-multiplicity assumptions are needed to connect this decomposition question to the mechanism’s truthfulness and payment guarantees?

The case FOR (proponent)

The strongest positive case is a narrow one: this paper’s main computational object is the decomposition of a fractional welfare solution into a lottery over feasible integral allocations. That object has a plausible high-multiplicity version in a large allocation market: millions of participants, perhaps only dozens of complete valuation-and-budget types, with resource capacities scaling with market size. Write the society as rational type masses \(\mu_t\), and let each realized allocation pattern give every member of a type an integral bundle. The lottery can give each type fractional *expected* allocation shares without giving anyone a fractional bundle.

For a concrete restricted range, take coordinates \((t,B)\) for types and bundles. A binary pattern \(z\in Z(X_\mu)\) says which bundle each type block receives; \(X_\mu\subseteq[0,1]^n\) is the associated packing relaxation, with welfare coefficients weighted by \(\mu_t\). The fractional optimum \(x^\star\) maximizes aggregate reported welfare. The restriction that a type block is treated uniformly within each realized pattern is deliberate: the mirror is the decomposition subproblem for that range, not a claim that all allocation rules have this form. Its dimension \(n\) can be based on types and options rather than the population size.

My lead anchor is Theorem 1, proved in this paper. It says that Algorithm 1 returns a convex combination \(\lambda\) of integral feasible points whose expectation is within Euclidean distance \(\epsilon\) of \(x^\star/\alpha\), after at most \(\lceil n\epsilon^{-2}\rceil-1\) iterations. The corresponding continuous problem is Approximate Type-Mass Lottery Decomposition: given \(\mu\), \(X_\mu\), an optimal fractional welfare solution \(x^\star\), an \(\alpha\)-integrality-gap verifier, and \(\epsilon>0\), output feasible patterns \(z^1,\ldots,z^q\) and probabilities \(\lambda_1,\ldots,\lambda_q\) such that \(\sum_j\lambda_j=1\) and \(\left\|\sum_j\lambda_j z^j-x^\star/\alpha\right\|_2\le\epsilon\). Each outcome assigns integral bundles; the expectation records type-level mass shares. I expect Class A conditional on an efficient verifier and LP solver: Theorem 1 gives a polynomial number of verifier calls in \(n\) and \(1/\epsilon\), but does not make a hard verifier easy.

Two proved results complete the mirror, each as a distinct problem. Theorem 2 says that, from the approximate combination \(\lambda\), one can construct a convex combination \(\lambda'\) whose expectation componentwise dominates \(x^\star/[\alpha(1+\sqrt n\,\epsilon)]\). Its mirror, Mass-Dominating Decomposition, takes the same data and the approximate lottery, and asks for a feasible lottery with that componentwise guarantee. The construction adds singleton feasible patterns and the zero pattern; I expect this problem also to be Class A under the paper’s packing assumptions.

Theorem 3 says that if \(\sigma(\lambda')\) dominates a point \(x\), Algorithm 2 converts \(\lambda'\) into a convex combination \(\lambda''\) with \(\sigma(\lambda'')=x\), using at most \(|\psi(\lambda')|n+(n^2+n)/2\) iterations. Its mirror, Domination-to-Exact Type-Mass Lottery, takes a feasible lottery and a feasible target marginal vector \(x\) dominated by its expectation, and asks for a lottery over feasible integral patterns with expectation exactly \(x\). This is again Class A: the theorem gives a support-dependent polynomial correction procedure. All three theorem results are proved in the paper.[Kraft, Fadaei, and Bichler, *Fast Convex Decomposition for Truthful Social Welfare Approximation*](https://pub.dss.in.tum.de/bichler-research/2014_kraft_convex_decomposition.pdf)

Together these stages explain why the mirror is relevant to the authors’ work: exact expectation is needed for the truthful-in-expectation mechanism, whereas Theorem 1 alone only gives an approximate decomposition. Running it at precision \(\epsilon/\sqrt n\), then applying Theorems 2 and 3, yields an exact lottery with expectation \(x^\star/[\alpha(1+\epsilon)]\). This covers the paper’s convex-decomposition results and their role in welfare approximation; it does not claim that the paper has a continuous-population theorem already, or that the decomposition removes the need for a good integrality-gap verifier. Further questions are whether natural type-indexed auction ranges have efficient verifiers, how their complexity depends on \(\tau\) and the number of alternatives, and what finite-to-continuum dictionary preserves the mechanism’s incentives and payments.

The weak point is real: the paper’s \(n\) is the dimension of a packing polytope, not the number of people, and the paper does not study a distribution over agent types. The mirror earns its plausibility because the authors’ theorem is a generic decomposition method for packing allocations, while type masses naturally weight welfare and resource constraints in a repeated market. But if a useful allocation model needs coordinates for every named person, the hoped-for dependence on \(\tau\) disappears. And an atomless model makes a single person’s report have zero effect, so this case mirrors the paper’s computational decomposition problem, not by itself its full strategic mechanism-design problem.

The case AGAINST (opponent, writing after the proponent)

The paper does have named algorithmic results, so I would not argue that there is nothing to mirror. But Theorems 1–3 bound the work of decomposing a point in a packing polytope, given an integrality-gap verifier. Their dimension \(n\) counts allocation coordinates; it is not the number of agents, types, or units of population. The paper’s vector \(\mu\) is a vector of accumulated valuation weights, not a distribution over agent types. Its convex combination is over feasible outcomes. A type-mass version therefore needs to add a population model; it is not already implicit in these theorems.

That distinction breaks the proposed type-level construction. If one coordinate represents a whole type block receiving the same bundle in each outcome, it cannot express even the basic allocation of one scarce item to one of two identical agents: giving the item to the whole block is infeasible, while giving it to neither agent misses feasible allocations. To represent the allocation, an outcome must say how many members of the type receive each bundle. Those count coordinates are not the paper’s \(0\)-\(1\) allocation coordinates. Alternatively, retaining a binary coordinate per person preserves the paper’s setup but makes \(n\) grow with the population, eliminating the claimed dependence on the number of types.

This applies to all three anchors. Theorem 1 gives \(O(n\epsilon^{-2})\) oracle calls, not a bound in the support size of a population distribution. Theorem 2’s singleton-coordinate correction and Theorem 3’s coordinate-by-coordinate exact correction operate on the same allocation vector; neither supplies the missing count-based model or a population-sensitive complexity bound. One could formulate new versions for count polytopes, but the paper’s guarantees do not establish them. And the proponent’s Class A claim is conditional on an efficient verifier and LP solver—the decomposition theorem does not make either computation tractable for the proposed type-based allocation problem.

There is also a mismatch with the paper’s purpose. In an atomless population, one individual’s report has measure zero, so a mechanism based only on the type distribution cannot reproduce the paper’s individual truthfulness comparisons. A finite high-multiplicity model can retain those comparisons, but then the effect of an individual report is \(1/N\), and the paper gives no limit result showing that its truthful mechanism or decomposition guarantee survives that change. Restricting the mirror to decomposition alone avoids this incentive issue, but then it is a generic geometric subproblem with type labels added, rather than a continuous-population result from the paper.

The best negative case is therefore that these anchors do not yield a population-continuous mirror of the paper’s results: faithful individual allocations keep the population-sized dimension, while type compression changes the feasible outcome polytope and leaves the theorem’s bounds behind. This is not airtight. A new decomposition theorem for anonymous count polytopes, with complexity in the number of types and a suitable finite-to-continuum account of incentives, could be worthwhile. But that would be a new project, not the continuous mirror claimed by these three anchors.
