The continuous mirror question

Given a finite path of locations, object classes \(\mathcal O\), and types \(t=(v,\succeq_t,e_t)\) with rational initial masses \(\mu_t\), a target type \(t^\star\), target class \(o^\star\), and rational threshold \(\theta>0\), is there a finite sequence of mass swaps after which at least \(\theta\) mass of type \(t^\star\) holds \(o^\star\)? A swap chooses types at adjacent locations currently holding classes \(a,b\) and exchanges equal mass \(\delta\) when \(b\succeq_t a\) and \(a\succeq_{t'} b\).

The model it lives in

Each type fixes location, weak ranking, and initial object class; its mass is the population share of interchangeable agents of that type. Objects remain indivisible for individuals but are grouped into interchangeable classes. The state is the mass table \(z_{t,o})\); a swap transfers \(\delta\) mass from cells \((t,a)\) and \((t',b)\) to \((t,b)\) and \((t',a)\). Because swap eligibility depends on fixed type, current holdings, and adjacency, this table specifies each transition without tracking individual histories.

The objection that survived

The reduction’s gadget roles remain indexed by path position and endowed object class, so \(\tau\) may grow with the instance, and the cohort model requires treating adjacency between locations as permitting mass pairings.

fatal: False

What the mirror covers

The mirror covers Theorem 2’s weak-preference path reachability and Theorem 4’s reachable-welfare result. It leaves the strict-preference path algorithm, weak Pareto-efficiency hardness, and the star-network results unmirrored.

Open questions for a prover

  • Does fractional splitting of type mass preserve NP-hardness for target-mass reachability on a cohort path?
  • Can the reduction enforce a positive target threshold despite mass taking different routes through the gadgets?

The case FOR (proponent)

The strongest case is the paper’s weak-preference Object Reachability result, with its welfare result as a second anchor. I would model many interchangeable agents at each position of a path-shaped exchange network. The agents are arranged in cohorts: members of a cohort share their location, weak ranking over object classes, and initial object class. A cohort’s mass is its fraction of the population. Objects remain indivisible for each individual; a cohort may have fractional mass holding each class because it aggregates many individuals.

This fits, for example, a large housing exchange across neighboring districts. Each district has many households, households share a modest number of preference and initial-housing types, and exchanges can be arranged only between neighboring districts. The number of households can greatly exceed the number of supported types. A mass swap of size \(\delta\) pairs \(\delta\) agents from adjacent cohorts, each receiving an object class they weakly prefer to their current one. This keeps the paper’s core ingredients—initial endowments, weak preferences, local swaps, and reachability—while making the population itself continuous.

My lead question is Continuous Weak Object Reachability on a Cohort Path. An instance gives a finite path of exchange positions, a finite set of object classes, rational masses for each supported type \(t=(v,\succeq_t,e_t)\), and a target type \(t^\star\), object class \(o^\star\), and rational threshold \(\theta>0\). Starting from the initial endowments, can a finite sequence of mass swaps leave at least \(\theta\) mass of type \(t^\star\) holding \(o^\star\)? A solution is the sequence of swaps and the resulting type-by-object mass table. Each swap acts across an edge of the path and exchanges equal masses of two cohorts; if they currently hold \(a,b\), respectively, it is allowed when \(b\succeq_t a\) and \(a\succeq_{t'} b\). My provisional expectation is hardness transfers: the paper’s reduction uses growing collections of preference, object, and path gadgets, so the combinatorics appear in the number of types and object classes, not just in how many copies of each agent exist. Whether fractional splitting preserves that reduction is an open question, not a proved consequence.

The anchor is Theorem 2, proved in this paper by reduction from 2P1N-SAT. It states that Weak Object Reachability is NP-hard even when the network is a path. The continuous question asks whether a target object *class* can reach a positive specified mass of a target *type*, rather than one named object reaching one named agent. That is the population-scale form of the same reachability question.

A second, related question is Continuous Reachable Welfare on a Cohort Path. Add a rational utility \(u_t(o)\) for each type and object class, consistent with its weak ranking. Given a welfare threshold \(W\), ask whether a finite sequence of individually rational mass swaps can reach a state with
\[ \sum_{t,o} z_{t,o}u_t(o)\ge W, \]
where \(z_{t,o}\) is the mass of type \(t\) holding class \(o\); return the sequence and final state if so. I also expect hardness transfers, for the same reason: the discrete reduction’s path and object-class structure grows with the hard instance. Its anchor is Theorem 4, proved here: finding a reachable assignment maximizing utilitarian social welfare is NP-hard even when the network is a path. This formulation preserves the paper’s objective over reachable assignments while expressing welfare as an integral over population mass.

These mirrors cover the paper’s weak-preference path reachability and welfare results; they do not claim a mirror for every result in the paper. They ask computational questions about a continuous population. The objects are still indivisible at the individual level, so this is not continuity of the outcome space, and the question is not an analytic equilibrium problem.

The weakest point is the network co-modification. The paper’s path has individual agents as vertices; the mirror has cohorts at path positions, with mass exchanges across adjacent cohorts. That is a meaningful high-multiplicity regime for local exchanges between neighboring populations, but it is not a literal continuum limit of the paper’s individual-level path graph. The positive case depends on the authors accepting cohort-level adjacency as a natural version of their network-constrained swap problem.

The case AGAINST (opponent, writing after the proponent)

The strongest case against both mirrors is that this paper’s central object is a network of *individual positions*, each holding its own endowed object. A complete type therefore includes the agent’s exchange neighborhood and endowment, not just their ranking. In the paper’s path instances, those features make positions and objects distinct. Repeating preference rankings does not create high multiplicity: the support size \(\tau\) still grows with the instance.

To get cohorts, one must replace individual vertices with locations containing many agents and replace exact objects with classes of replicated, interchangeable objects. Exchanges between neighboring cohorts then allow mass from one location to pair with mass from another. That is a coherent model, but it changes the graph’s exchange semantics as well as the population representation. Whether the authors would recognize that weighted path as their problem is the decisive question.

For Theorem 2, the reduction places variable and clause gadgets at particular path positions, with distinct preferences and endowed objects encoding the formula. A faithful type encoding keeps those roles separate, so it offers no population compression. The proposed cohort mirror is stronger and more plausible, but its positive-mass target raises a real modeling issue: the same mass must make a consistent sequence of trades through the gadgets. A final type-by-object table can lose the link between which mass took which route. Preserving that link requires tracking histories through the swaps, potentially a large distribution over trajectories. That makes the cohort problem a different and more involved computational object. It does not show the question is unworthy, but it weakens the claim that this is a straightforward continuization of Theorem 2.

The same issue applies to Theorem 4. Its reduction assigns distinct roles and values to vertex and arc agents; the welfare threshold counts gains along a particular sequence. In a cohort model, welfare averages across mass that may take different routes. A weighted final assignment need not preserve the identity correlations that make the reduction encode a Hamiltonian path. Tracking those correlations again requires a trajectory-level model. The theorem’s computational result therefore gives little direct reason to expect a compact, population-based welfare mirror.

This is a limited negative case. A large housing market with many households per district, local exchange between neighboring districts, and replicated housing classes is plausible. Asking whether a positive share of one district can obtain a class of housing, or maximizing aggregate reachable welfare, is a sensible computational question. The necessary co-modification could be one the authors recognize, and existing high-multiplicity work would support that regime. I cannot honestly rule out either mirror, let alone establish that no scenario is worthwhile. The strongest objection is that these results depend on positional and object identity in ways cohort aggregation may erase; that makes the negative case substantially weaker than the affirmative case.
