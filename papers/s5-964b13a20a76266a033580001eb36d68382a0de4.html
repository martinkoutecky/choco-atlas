The continuous mirror question

Given a finite set of types \(A\), masses \(p_a>0\) summing to \(1\), preferred actions \(s_a\in Z\), and influence shares \(q_{ab}\) summing to \(1\) for each type \(a\), find an equilibrium allocation \(x_{a,z}\geq0\) with \(\sum_{z\in Z}x_{a,z}=p_a\). Let \(\nu_b(z)=x_{b,z}/p_b\) and let \(A_a(x)\) be a weighted Fréchet median minimizing \(\sum_b q_{ab}\sum_{z\in Z}\nu_b(z)d(y,z)\) over \(y\in Z\). Require every action assigned positive mass to type \(a\) to minimize \(\alpha d(s_a,z)+(1-\alpha)d(z,A_a(x))\) over \(z\in Z\), for \(\alpha>1/2\) and an exact metric \(d\).

The model it lives in

A nonatomic population with finite types \(a\), each defined by a preferred action \(s_a\) and an influence kernel \(q_{ab}\), has mass \(p_a\). The decision variables \(x_{a,z}\) allocate each type’s mass among discrete actions; cohort action distributions induce weighted Fréchet medians, and a solution is an equilibrium allocation. There is no social-cost objective.

What the mirror covers

The mirror covers Theorem 2 for unrestricted games with exact metrics and α > 1/2. It leaves the price-of-anarchy bounds, restricted games, and the κ-approval model aside.

Open questions for a prover

  • How does equilibrium existence and computation change for restricted types whose preferred strategies may lie outside \(Z\)?

The case FOR (proponent)

The strongest defensible mirror is a narrow one: computing equilibria in a large, type-structured population. The paper does not give a formal NP-hardness or complexity-class theorem of its own. Its best algorithmic anchor is Theorem 2, proved in the paper: in an unrestricted game with an exact metric, when \(\alpha\geq 1/2\), the profile where every agent plays their preferred strategy is an equilibrium; when \(\alpha>1/2\), it is the only equilibrium. The theorem is an equilibrium characterization, not a stated “in P” result, but it directly yields an algorithm for the paper’s equilibrium-search problem.

Lead mirror: High-Multiplicity Unrestricted Preference-Game Equilibrium. Consider a large online community with a finite set of platform actions \(Z\). Users fall into \(K\) cohorts. A cohort’s type records its members’ preferred action and the shares of their influence directed to each cohort. Members of a type have the same costs and influence pattern; there may be millions of users but only a modest number of types. Let \(p_a\) be type \(a\)’s population mass, with \(\sum_a p_a=1\), and let \(q_{ab}\) be the share of type \(a\)’s influence directed to type \(b\), with \(\sum_b q_{ab}=1\).

A type-level action allocation is \(x_{a,z}\geq 0\), where \(\sum_{z\in Z}x_{a,z}=p_a\). Each user still chooses one discrete action; mass records the fraction of a cohort choosing each action. Write \(\nu_a(z)=x_{a,z}/p_a\). To make the local aggregate concrete, let \(A_a(x)\) be a weighted Fréchet median of the cohorts’ action distributions:
\[ A_a(x)\in\arg\min_{y\in Z}\sum_b q_{ab}\sum_{z\in Z}\nu_b(z)d(y,z), \]
with fixed tie-breaking. A user of type \(a\) who chooses \(z\) incurs cost
\[ \alpha d(s_a,z)+(1-\alpha)d(z,A_a(x)). \]
The problem is: given the types, rational masses and influence shares, the exact metric, and \(\alpha>1/2\), find an equilibrium allocation \(x\). A solution is an allocation in which every action receiving positive mass for a type minimizes that type’s cost given the induced aggregates. There is no social-cost objective here; it is an equilibrium-search problem.

This is a plausible high-multiplicity regime for the authors’ model: a large platform may have many users with the same preferred action and cohort-level influence pattern. The continuous object is the society: every user remains individually assigned a discrete action. A nonatomic user’s deviation does not change the aggregate. Since this is the unrestricted case, Theorem 2’s dominant-preference conclusion carries over: the unique solution has \(x_{a,s_a}=p_a\) for every type and zero mass on other actions. The problem is therefore tractable by outputting one action-mass entry per type, in time polynomial in the sparse input and output size. The prediction is Class A, though this is an easy case.

The mirror covers only Theorem 2’s unrestricted, high-confidence equilibrium-search result. It does not claim to continuize the paper’s price-of-anarchy bounds, its restricted games, or its \(k\)-approval model with fractional preferred strategies. Natural follow-on questions include whether the lower-confidence consensus result also yields a useful type-level search problem, whether restricted high-confidence continuum games always admit equilibrium, and how equilibrium efficiency depends on the cohort mixing pattern.

The soft spot is substantial: when \(\alpha>1/2\), the theorem’s strict preference incentives settle the equilibrium regardless of the local aggregation details. So this mirror shows that the high-multiplicity version is a sensible object and gives a clean algorithmic consequence; it does not show that continuization unlocks a new optimization technique or removes a hard computation.

The case AGAINST (opponent, writing after the proponent)

The strongest case against the proposed mirror is that Theorem 2 is an equilibrium characterization, not a complexity result. The paper’s own theorems concern equilibrium existence and structure, or price-of-anarchy bounds; the PLS-completeness result it mentions is prior work on a different game. So the proposed equilibrium-search problem is a computational consequence of Theorem 2, rather than a complexity question the paper itself formulates. In the proposed regime, the output is simply \(x_{a,s_a}=p_a\) for every type. That makes the mirror a thin algorithmic corollary, though its simplicity alone cannot disqualify it under the programme’s rules.

There is also a modeling gap in the stated cohort construction: influence shares \(q_{ab}\) do not in general determine an individual’s local aggregate. A weighted median, for example, can depend on the distribution of strategies among a particular agent’s neighbors, not just cohort totals. But this objection can be repaired by restricting to an exchangeable block network, with each type sharing the same influence kernel over cohorts. That is a plausible regime within the paper’s model, and the continuum aggregate in the proponent’s construction is a recognizable extension of its Fréchet median. Theorem 2 then applies pointwise.

So I cannot honestly defeat this anchor. Its weakness is that it exposes little new computational structure, not that it fails to define a sensible continuous population problem. Since a well-posed mirror can count even when its answer is immediate, the negative case here is weak.
