What the mirror covers

The proposed procedure covers applying the threshold rules to support shares; the paper's axiomatic characterization and strategy-proofness analysis contain no computational claim.

The case FOR (proponent)

The strongest positive scenario is a large peace process over a fixed set of issues. A type is a complete ranking of those issues; mass is the share of the public holding each ranking. Millions of people may fall into a relatively small number \(\tau\) of ranking types. That is a sensible high-multiplicity regime, and the paper’s focus on support shares and consistency under merging makes a population-level formulation natural.

For example, one could define Continuous Threshold Delegation: given a rational distribution \(\mu\) over supported rankings and a threshold function \(f\), find the smallest \(k\) for which the \(k\) most-supported rankings have total mass at least \(f(k)\), and return those rankings as the delegation. For fixed \(f\), this is computable by sorting the \(\tau\) masses. The authors would likely recognize this as their delegation rule applied to population shares.

But that is only a plausible extension, not a qualifying anchored case under your criteria. The paper contains no named computational result asserting that a problem is in P, NP-hard, FPT, or another complexity class. Theorem 4.1, proved here, characterizes the rules satisfying Pareto optimality, consistency, ballot neutrality, and strategy-proofness as threshold rules; it is an axiomatic characterization, not a computational result. Applying a fixed threshold rule also gives no substantial complexity question beyond sorting.

So the positive case is that this population regime is credible and the paper’s model is already organized around aggregate support. Its weak point is decisive for ChoCo: the paper’s named result is axiomatic, while the programme asks for computational questions. The possible continuous delegation problem is easy to state, but it is not a continuous mirror of a named computational anchor in this paper.

The case AGAINST (opponent, writing after the proponent)

The peace-process scenario is a credible high-multiplicity regime. A distribution \(\mu\) over rankings gives a natural meaning to public support shares, and merging societies fits the paper’s consistency condition. That is good evidence that the model can be continuized; it is not evidence that the paper contains a computational result to mirror.

The strongest proposed mirror is to take rational \(\mu\) and a threshold function \(f\), then compute the delegation. But Theorem 4.1 characterizes rules from normative axioms; it does not analyze a computational problem. The other numbered results support that characterization. Computing the threshold rule would be a sensible way to apply it, but it is not a complexity result asserted by the paper. Making \(f\) part of the input would require specifying how its values are represented, and would pose a new computational question rather than recover one from the theorem.

The natural continuous restatement of Theorem 4.1 remains axiomatic, which is outside ChoCo’s scope. There is also a strategic wrinkle: in an atomless population, one person’s report has zero mass and cannot change the delegation. A positive-mass deviation can be defined, but that recasts individual strategy-proofness as a coalition or group-level condition. That may be interesting, yet it changes the paper’s central axiom and still supplies no computational anchor from this paper.

So the strongest case against is narrow but firm: the positive case establishes that a continuous population model is sensible, while the paper’s main contribution is an axiomatic characterization, not a computational problem. A richer computational study might be built around delegation, but it would need a new objective or strategic problem; that would be a new project, not a continuous mirror of a named computational result here.
