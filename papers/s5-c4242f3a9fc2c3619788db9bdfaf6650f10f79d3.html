The case FOR (proponent)

There is no qualifying anchor in this paper: it contains no numbered Theorem, Lemma, Corollary, or Proposition asserting a complexity classification. Algorithm 1 is a named procedure, and Section V-D reports empirical runtimes, but neither establishes a formal tractability or hardness result. Results cited from other papers are not this paper’s results.

The strongest positive candidate is an unanchored high-multiplicity version of OpinionRank. Consider a fixed panel of \(n\) binary labeling tasks and a finite set \(T\) of source types. A type \(t\) is its complete observed response signature \(x_t\in\{0,1,\bot\}^n\), where \(\bot\) means missing; \(\mu_t\) is the fraction of sources with that signature. The input gives the positive-mass signatures and their rational masses. Define agreement by
\[ a(t,u)=\frac{1}{n}\sum_{i=1}^{n}\mathbf{1}[x_{ti}=x_{ui}\in\{0,1\}], \]
and the transition probabilities by
\[ P(t,u)=\frac{\mu_u e^{a(t,u)}}{\sum_{v\in T}\mu_v e^{a(t,v)}}. \]
The problem is to compute the stationary type masses \(\pi\), satisfying \(\pi_u=\sum_t\pi_tP(t,u)\), and the per-task scores \(w_i=\sum_t\pi_t z_{ti}\), where \(z_{ti}=x_{ti}\) for an observed label and \(z_{ti}=1/2\) for a missing one. Return the scores and thresholded labels, leaving exact-threshold ties unresolved.

This mirrors the computation in Algorithm 1: source mass replaces individual sources, the scaled agreement count becomes \(a(t,u)\), and the Perron–Frobenius ranking weights the resulting votes. It is an exact aggregation of the discrete computation when sources are grouped by identical signatures: the type-level chain is the lumped chain of the individual-source chain, and its stationary masses equal the sums of the individual weights within each type. The scenario is a large crowd labeling the same fixed diagnostic panel. With \(n\) fixed, there are at most \(3^n\) complete signatures, so the number of sources can greatly exceed the number of types. This is a credible regime for replicated or repetitive annotation sources, though it is narrower than crowdsourcing in general.

I would expect this candidate to be tractable for additive-precision scores when the support size \(\tau=|T|\) is moderate: form the agreement matrix in \(O(n\tau^2)\) time, then approximate the stationary distribution by power iteration. Since \(a(t,u)\in[0,1]\), each transition row dominates \(\mu/e\), giving uniform mixing; scoring costs \(O(n\tau)\). That is an analysis of the proposed mirror, not a result proved in the paper.

The weakest point is the type definition’s dependence on the observed response vector. For a long panel, sources may have nearly unique signatures, making \(\tau\) as large as the population; a type based on stable behavior would be more natural but would add a behavioral model absent from this method-free paper. So this is a plausible mirror of OpinionRank’s underlying label-aggregation task, but it cannot be presented as the continuous counterpart of a named complexity result. It covers neither the paper’s comparisons with generative models nor a formal claim about their complexity.

The case AGAINST (opponent, writing after the proponent)

The paper offers no named computational result to mirror. Algorithm 1 is a proposed method, and Section V reports empirical performance and runtime; neither establishes a complexity classification. The Condorcet and spectral claims in the paper are background results from other work. So there is no qualifying anchor here.

The proposed type-signature mirror is technically sound, though. For a fixed panel of \(n\) labeling tasks, take each source’s complete response vector in \(\{0,1,\bot\}^n\) as its type. Sources with the same vector are interchangeable to OpinionRank. Replacing their individual counts with type masses gives the same transition probabilities and aggregated stationary weights; computing the resulting scores is a well-posed continuous-population question.

The strongest objection is that this exact mirror is narrow. Its types encode the realized answers to the whole panel. As \(n\) grows, sources are likely to have distinct signatures, so the support size \(\tau\) can approach the number of sources and the population compression disappears. A more behavioral type, such as a reliability profile, would be more useful across changing datasets, but it would not suffice to compute OpinionRank’s observed pairwise agreements without adding a model of responses.

That limits the mirror’s reach, but it does not defeat it. A large crowd labeling a fixed panel is a plausible high-multiplicity regime, and the signature-based formulation preserves the paper’s computation exactly. Since the programme allows a well-posed question even when its eventual answer is simple, I cannot honestly make the universal case that no worthwhile mirror exists. The negative case is strongest against treating this paper as an established complexity result; it is weak against the specific fixed-panel mirror.
