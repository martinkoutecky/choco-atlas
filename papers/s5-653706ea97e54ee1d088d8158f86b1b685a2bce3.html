The continuous mirror question

Given \(m\) options \(C\) and a list of \(\tau\) strict partial-order types \(t\), each with positive binary-rational mass \(\mu_t\) summing to \(1\), compute the exact limit \(q^\infty\) from the uniform initial distribution under \(q^{(k+1)}=q^{(k)}P\), where \(P_{ij}=\frac{1}{m-1}\sum_{t:\,x_i\prec_t x_j}\mu_t\) for \(i\ne j\) and \(P_{ii}=1-\sum_{j\ne i}P_{ij}\). Return the induced ranking and winner set, including when the chain has multiple closed classes.

The model it lives in

The society is a distribution \(\mu\) over complete preference types, with type masses as the input. Pairwise mass totals determine the \(m\times m\) transition matrix; the task is to compute its limit from the uniform distribution exactly, with no optimization objective.

What the mirror covers

Covers Proposition 3.8’s computation of the convergence-voting ranking; it leaves the paper’s axiomatic properties and comparisons with other voting rules aside.

Open questions for a prover

  • For a specified current winner, what minimum mass must be transferred between preference types to change the winner?

The case FOR (proponent)

The strongest mirror is a high multiplicity version of computing the paper’s convergence-voting ranking. Consider a large referendum on a fixed, small set of options. Each voter submits a strict partial order over those options, as in the paper; two voters have the same type exactly when they submit the same order. For example, with three options there are only finitely many possible types, so a population of millions can have far more voters than distinct types. This is a credible regime for a standardized ballot or consultation, and each type captures all the preference information the rule uses.

My anchor is Proposition 3.8, proved in this paper. It states that the convergence-voting ranking can be computed in deterministic polynomial time, specifically \(O(|VO|^2|V|+|VO|^3)\): first construct the Condorcet graph, then compute the stationary distribution using matrix operations on matrices of size at most \(|VO|\). The paper has no named hardness result to anchor, so I would not add one.

Here is the corresponding continuous problem, Continuous Convergence Voting. An instance gives a set \(C\) of \(m\ge 2\) options and a list of \(\tau\) strict partial orders \(t\) on \(C\), each with a positive binary-rational mass \(\mu_t\), where \(\sum_t\mu_t=1\). For distinct options \(x_i,x_j\), set
\[ P_{ij}=\frac{1}{m-1}\sum_{t:\,x_i\prec_t x_j}\mu_t, \qquad P_{ii}=1-\sum_{j\ne i}P_{ij}. \]
Let \(q^{(0)}\) be uniform over \(C\), and set \(q^{(k+1)}=q^{(k)}P\). The task is to return the exact limit \(q^\infty=\lim_{k\to\infty}q^{(k)}\), together with its induced ranking and winner set. As in the paper, the starting distribution matters when the chain has multiple closed classes: the answer is the limit from uniform, not an arbitrary stationary distribution. There is no optimization objective here; this is the computation of the social choice function’s output.

I expect this problem to be tractable. Proposition 3.8 supplies the algorithmic shape, and replacing integer pairwise counts by sums of rational type masses gives a matrix of dimension \(m\), built from \(\tau\) types. The continuous question should therefore be solvable in time polynomial in \(m,\tau,L\), where \(L\) is the input bit length; establishing that exact bit bound is part of the continuous formulation, since the proposition’s stated bound counts operations without analyzing bit lengths.

This is a population continuization: \(\mu_t\) is the fraction of society with type \(t\). The fact that the output is itself a distribution over options is already part of the paper’s rule and is not the continuization being claimed. I expect the authors would recognize this mirror: their ranking depends on pairwise comparison counts, and the proposed problem replaces those counts with population fractions while preserving their transition rule and their convention for selecting the limit.

Further questions include how the ranking changes under small shifts of mass between types, and how much mass must move to change the winner. My weakest point is that this is a modest case. The paper’s named computational result is already polynomial time, so this mirror does not test whether continuization dissolves discrete hardness; and the extension from counts to rational masses is direct. Its value is a precise, plausible continuous form of the paper’s central computation, rather than a dramatic new complexity separation.

The case AGAINST (opponent, writing after the proponent)

The referendum setting is credible: with a fixed menu of options, millions of voters can share one of finitely many preference types, and each type captures everything convergence voting uses. So multiplicity itself is not an objection.

The strongest negative case is that the paper’s computation has already compressed the society to its pairwise comparison matrix. For a continuous society, define
\[ a_{ij}=\sum_{t:\,x_i\prec_t x_j}\mu_t. \]
The rule uses these \(m(m-1)\) values to form its transition matrix; it does not use any other feature of the type distribution. Computing them takes polynomial time in \(m,\tau,L\), and computing the limit from the uniform distribution is rational linear algebra on matrices of size \(m\). Proposition 3.8 supplies the algorithmic shape. The continuous formulation is therefore a succinct, rationally weighted input to an already small Markov-chain computation. It needs no pricing oracle, optimization machinery, or new structural insight.

That makes the proposed mirror low-value as a research contribution: it checks that the existing computation works on rational masses and accounts for bit lengths, but it does not reveal a new algorithmic boundary for continuous societies. Yet this is a priority argument, not a fundamental objection. A simple or unsurprising answer is still an answer, and the continuous input is a genuine high-multiplicity model.

A stronger question might ask for the least mass that must move between types to change the winner. That could be a meaningful continuous control problem, but it is not the computation asserted in Proposition 3.8, and I cannot honestly rule out its value from this paper alone. The case against is therefore weak at the decisive point: the proponent’s one named anchor survives. I can argue that its continuous version is routine and limited in payoff, but not that there is no worthwhile mirror.
