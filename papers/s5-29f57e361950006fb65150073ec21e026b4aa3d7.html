The case FOR (proponent)

There is a modest continuous-population extension here, but the paper has no named computational-complexity result of the kind your anchors require. Theorem 1 proves that the \(216\) preference triads on three alternatives fall into \(10\) equivalence classes under node relabeling and a common relabeling of alternatives; Theorem 2 gives a formula for the corresponding number of classes on \(n\) alternatives. Both are proved here. They are combinatorial classification and counting results, not claims that an underlying problem is in P, hard, or otherwise classified. So neither is a qualifying anchor under the stated criterion.

The closest positive case I can make is an unanchored extension of Theorem 1 and the paper’s empirical class histograms. For three alternatives, take a finite-type network population: each type \(t\) has a ranking in \(S_3\), mass \(\mu_t\), and a symmetric rational link-probability kernel \(W_{t,u}\). Assume links are sampled independently conditional on endpoint types. Given \((\mu,W)\), compute the distribution of the ten preference-triangle classes among network triangles. For each class \(E\), the output is

\[ p_E = \frac{\displaystyle\sum_{t_1,t_2,t_3} \mathbf{1}\!\left[(t_1,t_2,t_3)\in E\right]\, \mu_{t_1}\mu_{t_2}\mu_{t_3} W_{t_1,t_2}W_{t_1,t_3}W_{t_2,t_3}} {\displaystyle\sum_{t_1,t_2,t_3} \mu_{t_1}\mu_{t_2}\mu_{t_3} W_{t_1,t_2}W_{t_1,t_3}W_{t_2,t_3}} . \]

The instance consists of the rational masses and kernel; the solution is the ten class probabilities. A plausible regime is a large online community where many users share a ranking and one of a small number of network strata: \(N\) may be large while the number of supported ranking-stratum types \(\tau\) stays small. The paper’s preference-class histograms and comparison with rewired networks give this statistic a recognizable connection to its work. Computing it takes \(O(\tau^3)\) arithmetic operations, so I would expect this particular problem to be tractable by direct summation. That is a useful continuous statistic, but it does not establish a hardness-dissolution result.

The weak point is that the paper’s main theorem classifies a single triangle; it does not study a population-level computation. The finite-type link model also assumes that the type masses and kernel capture the network structure relevant to triangle frequencies. That is plausible for a block-structured network, but it does not preserve arbitrary social-network topology. Thus this is a credible extension of the empirical analysis, not a strong mirror of a named computational result.

The case AGAINST (opponent, writing after the proponent)

The strongest negative point is the one the proponent concedes: the paper has no named computational result to mirror. Theorem 1 classifies preference triangles under relabelings; Theorem 2 counts the resulting equivalence classes. Both are finite combinatorial results. The paper’s remaining contribution is an empirical comparison with degree-preserving rewires, while its open questions concern how to order the classes and define balance. None asks for an algorithm or a complexity classification.

The proposed finite-type extension is a reasonable calculation, but it does not supply the missing computational problem. For three alternatives there are only six rankings and ten classes. Given a finite-step link kernel, the class densities are finite sums over triples of types. That connects to the paper’s histograms, but it adds a population model and computes a statistic; it does not continuize either theorem. The same issue remains in a stronger version using a graphon \(W(x,y)\) and a ranking label \(r(x)\): the class density is an integral over triples of population points. With a finite-step graphon, it reduces to sums like the proponent’s. With a more general graphon, what it means to compute the integral depends on how the graphon is represented. That is a graphon-computation question, not a complexity question latent in the paper.

There is a real modelling tradeoff here. A ranking distribution and type-conditioned link probabilities are sensible for a large community with many users of each type, but they replace the paper’s observed network and its degree-preserving rewiring experiment with a block model. To preserve the observed degrees and topology, types would need to carry more structure; in the extreme, the model retains node-specific neighborhoods, and the support may grow with the population. A graphon can preserve some network structure, but then it supplies a new network model whose assumptions drive the problem. The paper itself offers no computational objective for choosing among these models.

One could invent a stronger project: assign a score to the ten classes, then optimize preference-mass transfers or network changes to improve that score. But the authors explicitly leave the class ordering and the mapping from classes to balance unresolved. Choosing an objective would therefore add the central normative and computational question rather than mirror a result they established. Even the canonical class-frequency vector avoids that choice, but remains a statistic rather than a computational problem posed by the paper.

So I would not count the proponent’s extension as a surviving anchor. The case against is strongest on scope: the paper classifies configurations and reports an empirical pattern; it does not identify a computational task whose population version this programme could classify. It is not airtight that no worthwhile project could grow from the paper. Large networks with repeated preference types are plausible, and a carefully specified graphon study could be valuable. The weaker point is that such a study would be a new computational or statistical project inspired by the paper, not a continuous mirror of one of its results.
