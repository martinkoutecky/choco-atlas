The continuous mirror question

Given finitely many sections \(K\) with rational costs \(C(k)\), a fixed finite set of blocs \(\mathcal B\), and a finite support of trip types \(r\), each with route \(R_r \subseteq K\), bloc \(a(r)\), and positive rational mass \(\mu_r\) summing to \(1\), compute the aggregate bill \(x_r\) for each type under the mass extension of the Owen allocation. Define \(\mu_{a,k}=\sum_{r:a(r)=a,\ k\in R_r}\mu_r\) and \(\mathcal B_k=\{a:\mu_{a,k}>0\}\); then \(x_r=\mu_r\sum_{k\in R_r} C(k)/(|\mathcal B_k|\mu_{a(r),k})\).

The model it lives in

A population of trip types with masses \(\mu_r\), each type specifying a route and membership in one of finitely many bargaining blocs. For each type, the allocation assigns charge density \(q_r=\sum_{k\in R_r} C(k)/(|\mathcal B_k|\mu_{a(r),k})\) and aggregate bill \(x_r=\mu_r q_r\); computing the bills takes \(O(\tau |K|)\) arithmetic operations.

What the mirror covers

The mirror covers the Owen allocation formula in Proposition 3.1, interpreted over type masses. It leaves the other value formulas, alliance results, axiomatic characterizations, and AP-9 comparisons outside.

The case FOR (proponent)

My strongest case is a continuous version of the paper’s grouped Owen cost allocation. The society is the population of trips on a highway; the object being allocated is the fixed cost of its sections. This is a cost-sharing problem, not a manipulation problem, and the paper gives no NP-hardness or complexity-class result. Its computational anchor is an explicit formula for calculating the allocation.

The anchor is Proposition 3.1, proved in this paper. For a finite generalized highway problem with section set \(K\), costs \(C(k)\), and a partition of users into a priori unions \(P\), it gives the Owen payment to user \(i\in P_a\) as
\[ \Psi_i=\sum_{k\in T(i)}\frac{C(k)}{|A_k|\,|N^a_k|}, \]
where \(A_k\) is the set of unions that use section \(k\), and \(N^a_k\) is the set of users in union \(a\) who use it. Thus each section’s cost is first divided among the unions using it, then among the users in each such union.

I would hand a prover this problem: Continuous Owen Highway Allocation (\(\mathrm{COHA}\)). An instance has finitely many sections \(K\) with binary-rational costs \(C(k)\), a fixed finite set of bargaining blocs \(\mathcal B\), and a finite support of \(\tau\) trip types \(r\). A type specifies its bloc \(a(r)\in\mathcal B\) and its route \(R_r\subseteq K\); its positive rational mass \(\mu_r\) is its fraction of the population, with \(\sum_r\mu_r=1\). Define
\[ \mu_{a,k}=\sum_{\substack{r:a(r)=a\\k\in R_r}}\mu_r, \qquad \mathcal B_k=\{a:\mu_{a,k}>0\}. \]
The task is to return the aggregate bill \(x_r\) for each type’s mass, or equivalently its charge density \(q_r=x_r/\mu_r\). A solution is the type-level aggregation of the finite Owen allocation under replication. There is no optimization objective in the source problem: the output is the Owen cost split, which recovers the section costs.

That replication gives a direct candidate solution:
\[ q_r=\sum_{k\in R_r}\frac{C(k)}{|\mathcal B_k|\,\mu_{a(r),k}}, \qquad x_r=\mu_r q_r. \]
Indeed, replicate the population \(N\) times, choosing \(N\) so every \(N\mu_r\) is an integer. Each replicated user of type \(r\) pays \(q_r/N\) by Proposition 3.1, so the type’s total payment is \(x_r\), independent of \(N\). Summing across types recovers \(\sum_{k\in K}C(k)\). With routes represented as subsets of \(K\), the formula takes \(O(\tau|K|)\) arithmetic operations, with polynomial bit complexity in the input size. I expect this mirror to be tractable.

The regime is daily highway traffic: many trip-agents, but comparatively few distinct route, vehicle-class, and bargaining-bloc types. For example, trips could be typed by origin–destination route, vehicle class or required road level, and membership in one of a fixed number of fleet or user blocs. Those attributes determine the section use and bargaining position relevant to this cost game, so the types are complete for the problem. The paper’s AP-9 application already uses daily traffic counts and a grouped-user model. Its particular numerical partition makes light and heavy-1 trips singleton unions, however; I would not rely on that partition scaling with the population. A plausible mirror uses a fixed set of actual fleet or negotiating blocs.

This should be recognizable to the authors: it preserves their sections, fixed-cost game, a priori unions, and Owen allocation, while replacing large counts of repeated trips with masses. The paper also cites Castaño-Pardo and García-Díaz’s nonatomic highway cost-allocation work. That supports the naturalness of a large-population setting, while warning against claiming that highway cost allocation becomes continuous here for the first time. The narrower question is the mass-based computation of this paper’s grouped Owen allocation.

The mirror covers Proposition 3.1, not the paper’s other value formulas, axiomatic characterizations, or AP-9 numerical comparison. Further questions include whether the paper’s characterization axioms have a corresponding continuous uniqueness theorem, and how the allocation behaves when the number of bargaining blocs grows with the population.

The weak point is that the paper’s anchor is a closed-form allocation rule, not a hard computational problem; its continuous version is also easy to compute. And the paper’s own AP-9 grouping does not itself supply the fixed, small set of blocs this regime needs. So this is a credible, precise continuous mirror, but a modest one: it shows a tractable population-continuous cost-allocation question, not a new complexity boundary.

The case AGAINST (opponent, writing after the proponent)

Proposition 3.1 is the only plausible anchor, and it has a coherent population mirror. Trips can be typed by route, vehicle class, and membership in a fixed set of bargaining blocs. Under replication by \(N\), a type with mass \(\mu_r\) has \(N\mu_r\) users, so the finite Owen formula gives the aggregate type bill
\[ x_r=\mu_r\sum_{k\in R_r}\frac{C(k)}{|\mathcal B_k|\,\mu_{a(r),k}}. \]
That is a sensible mass allocation, and fleet or user blocs give it a credible setting. I cannot dismiss it on multiplicity, identity, or a failure of the limit.

The strongest case against is about fit with ChoCo’s computational agenda. Proposition 3.1 supplies an explicit evaluation formula; it does not establish a complexity classification for an optimization or search problem. The proposed COHA input already lists its support, routes, and blocs, so its sufficient statistics are the bloc-by-section masses. Computing them and applying the formula takes \(O(\tau |K|)\) arithmetic operations. The paper’s finite calculation is already explicit in the same way. Thus the mirror is a valid computational function, but it gives the programme no pricing problem, optimization structure, or complexity frontier to investigate.

The stronger variants do not repair that gap. Asking for a continuum version of the paper’s uniqueness characterizations turns toward axiomatic work, which ChoCo sets aside. Asking the algorithm to choose blocs or merge them changes the task: the paper takes the coalitional structure as input. Allowing a richer route distribution still leaves the stated allocation formula to aggregate section use and compute the same shares. The paper also cites earlier non-atomic highway cost allocation; that is not an exact collision with grouped Owen allocation, but it makes the population-continuous setting less distinctive.

So the negative case is about priority, not whether a mirror can be formulated. The proponent’s COHA is a legitimate continuous version of Proposition 3.1, and I do not see an honest way to claim that no scenario supports one. I would argue that this mirror is too close to direct formula evaluation to warrant much of ChoCo’s complexity effort; under the prompt’s gate, though, the anchor survives.
