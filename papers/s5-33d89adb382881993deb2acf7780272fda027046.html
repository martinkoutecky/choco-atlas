The continuous mirror question

Given \(m\) alternatives, count up to relabelling the inclusion-maximal supports \(D\subseteq\mathcal{L}(A)\) such that every distribution \(\mu\) with \(\operatorname{supp}(\mu)\subseteq D\) induces an acyclic weighted majority relation.

The case FOR (proponent)

My best positive case is a population-level robustness interpretation of the paper’s enumeration, though it is a narrow one. The paper contains no named result classifying a problem as NP-hard, in P, FPT, or similar. Its strongest usable anchor is instead an exact counting theorem.

Theorem 0.24, proved in this paper, defines \(\mathcal{P}(m)\) as the number of maximal Arrow single-peaked domains on \(m\) alternatives that share a common extremal path, \(\mathcal{N}(m)\) as the number of their isomorphism classes, and \(\mathcal{SP}(m)\) as the number of isomorphism classes that are self-paired. It states that \(\mathcal{P}(3)=\mathcal{N}(3)=\mathcal{SP}(3)=1\), and, for every \(m\ge4\),
\[ \mathcal{P}(m)=2^{m-3}\mathcal{P}(m-1),\qquad \mathcal{N}(m)=\frac{\mathcal{P}(m)+\mathcal{SP}(m)}2,\qquad \frac{\mathcal{P}(m)}2\le\mathcal{N}(m)\le\mathcal{P}(m). \]
In particular, it reduces the isomorphism-class count to counting self-paired domains. This is an enumerative result, not a complexity classification.

A continuous mirror would be Continuous Maximal Arrow-Domain Enumeration. For an instance \(m\), let the alternatives be \(A=\{1,\ldots,m\}\), and let each type \(t\) be a complete ranking in \(\mathcal{L}(A)\). A society is a mass vector \(\mu\) over its positive-mass ranking types. The decision object is a support \(D\subseteq\mathcal{L}(A)\): include or exclude each ranking type. Call \(D\) admissible when, on every triple \(T\subseteq A\), some fixed alternative is never ranked last by any type in \(D\). Such a support is an Arrow single-peaked domain. Require it to be inclusion-maximal among admissible supports, identify supports that differ only by relabelling alternatives, and return their number. This is the continuous version of the paper’s count: the population may have any mass distribution over the admitted types, and the property must hold for the whole simplex of such distributions.

A plausible regime is a large, recurring consultation over a small fixed slate of alternatives, where many people share each permitted ranking. The ranking is the complete type description; \(\mu_t\) is the population fraction with ranking \(t\). For \(m\) alternatives, the paper cites the fact that maximal Arrow single-peaked domains have \(2^{m-1}\) rankings, so a large electorate can have far more people than distinct types.

The bridge is exact here. Every finite electorate gives a rational mass vector. Conversely, if some real mass vector over a finite support produces a strict Condorcet cycle, its strict margins persist under a sufficiently close rational approximation, which corresponds to a finite electorate. Thus universal acyclicity over the continuous simplex does not change which supports qualify. The mirror’s expected classification is hardness transfers, in the limited sense that any complexity result for the corresponding finite-domain counting problem would carry over to this identical family of objects. Theorem 0.24 itself establishes no such hardness or tractability result.

The weakest point is that the theorem counts supports, not societies supplied as mass vectors: the continuous masses do not affect the answer. So this is a defensible population mirror, but it may be too close to restating the paper’s support classification to fill the programme’s intended complexity gap. Further questions include whether one can count self-paired supports efficiently, and whether, given a particular \(\mu\), one can efficiently find or count maximal Arrow domains containing its support.

The case AGAINST (opponent, writing after the proponent)

Theorem 0.24 is the paper’s strongest anchor: it gives an exact recurrence and bounds for counting maximal Arrow single-peaked domains. I would not dismiss it as merely axiomatic. The problem for the mirror is that the theorem counts sets of rankings, not societies.

A ranking can be a voter type, and a large electorate with many voters of each type is plausible. But Theorem 0.24 takes \(m\), the number of alternatives, as its parameter. It counts domains \(D\) by asking which sets of rankings satisfy a condition quantified over *every* profile drawn from \(D\). It takes no population distribution \(\mu\) as input. Calling \(D\) the support of a continuous society gives each such domain a simplex of possible mass distributions, but the theorem still counts the supports; the masses contribute nothing. If \(\mu\) is added as an input to the proposed enumeration, the output is unchanged by it.

The best salvage is to ask for the number of maximal support sets whose entire simplices of population compositions avoid Condorcet cycles. That is mathematically coherent, and the rational-profile bridge makes the correspondence exact. Yet it packages each domain as a family of societies rather than making population composition part of the computational question. A mass-weighted variant—say, finding the largest share of a given population whose support lies in a Condorcet domain—would use \(\mu\), but it adds a new objective and a new problem; the theorem does not motivate or resolve those choices.

The negative case has a real limit: repeated ranking types make high multiplicity sensible here, so I cannot rule out every useful population-based question about Condorcet domains. My case against this anchor is narrower: the proposed enumeration does not turn the paper’s counted objects into a computational problem *about a given continuous society*. If the programme treats counting robust type supports as sufficient, this anchor survives.
