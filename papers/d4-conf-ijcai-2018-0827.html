What the mirror covers

No named result is covered by a surviving mirror. The proposed allocation model covers only welfare maximization and leaves CSM’s payments, incentive compatibility, budget balance, and revenue guarantees aside.

The case FOR (proponent)

The strongest honest case is narrow, and it fails the required anchor test: this paper contains no named computational-complexity result.

The closest named results are Proposition 1, which proves that IDM-TC is efficient, individually rational, incentive compatible, and weakly budget balanced on tree networks, with revenue at least that of the Vickrey auction; Theorem 1, which proves that CSM is efficient, individually rational, and incentive compatible in general networks; and Theorem 2, which proves that CSM is weakly budget balanced and gives a lower bound on its revenue. These are mechanism-property results. “Efficient” means welfare-maximizing here, not polynomial-time computable. None asserts tractability, hardness, or a running-time bound, so none qualifies as an anchor under the stated rules. There is therefore no honest anchor-indexed continuous problem to hand to a prover.

There is a plausible high-multiplicity setting behind the paper: a large online marketplace or dealer network with many buyers and intermediaries but relatively few shared valuation, cost, and network-role classes. A type would need to include the agent’s role, valuation or cost, and the neighboring role classes through which information can pass; \(\mu_t\) would be that type’s share of the population. This could describe \(n\gg\tau\) agents. But preserving the paper’s mechanism is difficult: it rewards particular intermediaries for being pivotal in a route to the winner. In an atomless population, removing one agent need not change reachability, so that incentive can disappear. Also, with one indivisible commodity, type masses may determine which buyer types exist without affecting which one has the highest net surplus. A type-level version risks discarding the feature that makes CSM work.

If structural mechanism results were allowed as anchors, a modest candidate would be Typed Customer-Sharing Welfare Allocation. Its instance would be a finite directed graph of network roles, rooted at the seller, with positive rational masses for finitely many buyer and intermediary types. Each buyer type has a value \(b_t\); each intermediary type has a cost \(c_t\); graph edges specify which role classes can pass sale information to which others. The task is to return a buyer type and a minimum-cost route to it that maximize the buyer’s value minus the costs on the route. This mirrors the welfare-maximizing allocation used by CSM, and I would expect this allocation subproblem to be tractable on the finite role graph. But mass mostly indicates which roles are present, and the problem does not capture CSM’s payment or incentive guarantees. It is a possible extension, not a continuous mirror anchored by this paper’s computational results.

That is the weakest point, and it is decisive for the requested format: the paper offers a potentially useful market-network setting, but no named computational result whose complexity can be continued into the population continuum.

The case AGAINST (opponent, writing after the proponent)

The strongest negative is that none of the three named results is a computational result. Proposition 1 establishes mechanism properties for IDM-TC on trees; Theorem 1 establishes properties of CSM; Theorem 2 establishes budget balance and a revenue bound. “Efficient” in these statements means welfare-maximizing, not polynomial-time computable. None gives a complexity claim or algorithmic bound to continue into the population continuum.

The proposed typed welfare-allocation problem is the best way to extract a computational question from the paper: give a finite graph of network roles, masses of buyer and intermediary types, values and costs, then find the winning buyer type and a least-cost route. But that is a newly posed allocation problem, not a mirror of one of the paper’s results. More fundamentally, the commodity still goes to one buyer, while CSM’s payments and incentives depend on what happens when a particular intermediary changes her sharing strategy. In an atomless population, one intermediary has zero mass, so the distribution cannot register that deviation. Treating a whole type’s mass as the deviator instead changes individual incentive compatibility into a collective-reporting question.

Refining types to retain each intermediary’s exact network position and neighbors preserves the pivotality CSM uses, but then the types encode named graph positions; it does not give a population with many interchangeable agents per type. Coarsening types into repeated network roles gives a plausible large-market story, but loses the individual counterfactuals needed for the paper’s central mechanism guarantees. One could devise a mass-allocation or many-auction variant, but that changes the single-commodity mechanism problem and supplies a new computational question rather than a continuous version of Proposition 1, Theorem 1, or Theorem 2.

So no anchor survives the paper’s stated computational standard. The universal claim is less certain: a carefully redesigned market with many units or repeated auctions could make continuous analysis worthwhile. The paper gives no named computational result, though, from which that programme of continuous mirrors can begin.
