The continuous mirror question

Given \(m,k\), a finite set of types with approval sets \(A_t\), positive rational masses \(\mu_t\) summing to \(1\), and proposed utilities \(\alpha_t\), does there exist a size-\(k\) committee \(W\) inducing \(\alpha_t=1\) exactly when \(A_t\cap W\ne\emptyset\), such that no coalition choosing masses \(q_t\in[0,\mu_t]\) can propose an integral committee \(W'\) with \(|W'|\le k\sum_t q_t\) and strictly improve every participating type, meaning \(s_t(W')>\alpha_t\) whenever \(q_t>0\)?

The model it lives in

Represent each complete approval ballot and its proposed utility as a type carrying rational population mass. Committees remain integral; a coalition may select any mass of each type, and its committee entitlement is \(k\) times its total mass.

What the mirror covers

The mirror covers Theorem 10’s NP-completeness result for NTU-\(\CC\) core membership; it does not cover the paper’s other rules, utility model, or core non-emptiness results.

Open questions for a prover

  • Does NTU-\(\CC\) core membership remain NP-complete for societies represented by \(\tau\) approval types with rational masses, with running time measured in \(m\), \(\tau\), and the input bit length?

The case FOR (proponent)

My strongest clean anchor is Theorem 10, proved in the paper: given a multi-winner approval instance \((\mathcal C,\mathcal V,\mathcal R,k)\) and a proposed utility function \(\boldsymbol{\alpha}\), deciding whether \(\boldsymbol{\alpha}\) belongs to the NTU core under Chamberlin–Courant is NP-complete. The paper proves this by reducing from Set Cover, rather than citing the result. [Theorem 10 and its proof](https://arxiv.org/html/2605.22528)

A natural regime is a large electorate choosing a fixed-size committee, where many residents share the same approval ballot. For this verification problem, a complete type can be \((A_t,\alpha_t)\): an approval set and the proposed per-capita utility. There may be \(N\) residents but only \(\tau\) such types, with \(N\) far larger than \(\tau\). Cloning each voter in the paper’s Set Cover reduction \(R\) times leaves the type masses unchanged while making the electorate \(R\) times larger. This is a sensible high-multiplicity regime for committee representation; the paper’s established voter-core model supports the subject matter, while the mirror changes the population representation.

I would pose Continuous NTU-CC Core Membership as follows. An instance consists of \(m\) alternatives, a committee size \(k\), a finite list of \(\tau\) types with approval sets \(A_t\subseteq\mathcal C\), positive binary-rational masses \(\mu_t\) summing to \(1\), and proposed utilities \(\alpha_t\). A committee \(W\) gives type \(t\) utility \(s_t(W)=1\) if \(A_t\cap W\ne\emptyset\), and \(0\) otherwise. A coalition may select any mass \(q_t\in[0,\mu_t]\) from each type. It may propose an integral committee \(W'\) only when \(|W'|\le k\sum_t q_t\). It blocks if every type with \(q_t>0\) strictly improves: \(s_t(W')>\alpha_t\). The question is whether some committee \(W\) of exactly \(k\) alternatives induces \(\alpha_t=s_t(W)\) for every supported type and has no blocking coalition. The input size and running time are measured in \(m,\tau\), and the bit length of the masses and utilities.

For this mirror, the expected answer is NP-complete, with hardness transferring (Class B). In the paper’s reduction, each universe element becomes a voter type approving exactly the alternatives corresponding to sets containing that element; set \(k=h\) and \(\alpha_t=1\) for every type. A committee induces this allocation exactly when it covers every supported type. Since CC utility is capped at \(1\), no coalition can strictly improve on that allocation. Thus continuous core membership on these instances is precisely the Set Cover question. The continuous model is also in NP: guess \(W\), check that it induces \(\alpha\), then check continuous JR by verifying, for every alternative \(c\), that the mass of currently unrepresented types approving \(c\) is less than \(1/k\). If a larger blocking committee could be afforded by a coalition of unrepresented types, some alternative in it would have at least \(1/k\) mass of such approvers; conversely, that much mass gives a blocking deviation to the single alternative. Fractional coalition masses therefore do not alter this anchor’s classification.

This mirrors only Theorem 10’s NTU-CC membership problem; it makes no claim about the paper’s TU results, its other rules, or core non-emptiness. Its soft spot is also clear: on the all-ones allocations driving the reduction, blocking is vacuous. The hardness comes from the discrete committee covering the approval types, not from subtle interactions between fractional coalitions and proportional entitlements. That makes this a modest but defensible continuous-population mirror—and a clean example of hardness that should survive because its combinatorics live in the alternatives and type support, not in population multiplicity.

The case AGAINST (opponent, writing after the proponent)

The strongest case against this anchor is that its computational work sits almost entirely in the committee, not in fractional coalition behavior. Under CC, a proposed utility for each type must be \(0\) or \(1\). Once a committee realizes those utilities, stability can be checked by asking whether any alternative is approved by at least \(1/k\) mass of currently unrepresented types. The continuous blocking calculation is therefore simple; the NP-hardness comes from finding a size-\(k\) committee that covers the types.

That makes the mirror computationally thin, but it does not make it a bad mirror under ChoCo’s criteria. A large electorate with repeated approval ballots is a sensible high-multiplicity regime. Cloning each voter type preserves the mass distribution while making the population arbitrarily large. Set Cover still reduces to whether a committee induces the all-ones allocation, and CC’s utility cap makes blocking vacuous there. So the proposed mirror is well-posed and inherits NP-hardness from the discrete problem.

I cannot honestly defeat this anchor. “The hardness is in the alternatives” and “fractional coalitions add little here” do not rule it out: the programme explicitly treats transferred hardness as a valid Class B result, and does not require every mirror to gain new complexity from fractional mass. The negative case is weak at this anchor; the most I can argue is that this would be a modest mirror whose continuous-specific contribution is limited.
