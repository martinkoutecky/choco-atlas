The case FOR (proponent)

The strongest honest case for a mirror is only a plausible setting for the paper’s subject: a large cooperative workforce with a small number of agent types, where agents of a type share the same contributions, costs, and bargaining role. Mass would be the fraction of each type, a coalition a selection of mass from each type, and an allocation a payoff per unit of each type. But the paper does not specify how worth is assigned to fractional coalitions, so even this extension needs a new model.

There is no eligible computational anchor. The closest result is Theorem 4.2, proved here: an efficient allocation \(x\) is undominated exactly when there are balanced collections \(B_1,B_2\) with \(L(x)\subseteq B_1\), \(H(x)\subseteq B_2\), and \(B_1\cap B_2\subseteq E(x)\). Theorem 5.3, also proved here, says the L1-center equals \(AC(B_1,v)\cap C(B_2,v)\) for some pair of balanced collections. These are structural characterizations, not claims that a problem is in P, hard, or otherwise in a complexity class. The paper mentions a finite check and computational convenience, but gives no complexity result or algorithmic analysis.

So I cannot give a continuous problem per anchor: there are none that meet the requested criterion. A continuum version of computing undominated allocations could be a research direction, but it would require new assumptions about fractional-coalition worths and would not be a mirror of a named computational result in this paper.

The case AGAINST (opponent, writing after the proponent)

The proponent offers no anchor, so there is no continuous question to defeat one by one. That absence is the strongest case against a ChoCo mirror: the paper’s theorems characterize solution sets and their geometry; none states a complexity result for a computational problem. The closest candidates, Theorem 4.2 and Theorem 5.3, give balancedness and polyhedral characterizations. The paper notes their computational usefulness, but gives no algorithm or complexity bound. A finite characterization is not itself a complexity result.

The strongest possible repair would be to ask how hard it is to recognize an undominated allocation or compute the undominated set, then pose that task for a population with repeated types. But that would add a computational question the paper does not answer. It also requires a worth function for fractional coalitions. A finite characteristic function \(v:2^N\to\mathbb{R}\) specifies values only for actual coalitions; it does not determine values for fractional masses of each type. Many extensions agree on the original coalitions and disagree elsewhere, potentially changing the core, anticore, and the paper’s extensions.

A large workforce with shared roles could be a sensible setting for a continuous TU game. Yet to make it well-defined, one must specify how coalition worth depends on the masses of each type—perhaps through a production function. Then the computational questions and their tractability depend on that added structure, rather than mirroring a computational result in this paper. This could be worthwhile cooperative-game research, but it is a new model and agenda.

So the negative case is strong under ChoCo’s computational-mirror criterion: this paper supplies no named computational result to continuize. The literal claim that no scenario could yield valuable continuous research is weaker. A carefully specified nonatomic game might be worth studying; the point is that its value would not come from mirroring this paper’s computational findings.
