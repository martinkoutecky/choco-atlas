What the mirror covers

The proposal targets only the stable multicommodity-flow search claim in Theorem 6; it leaves Theorems 2, 4, 5, 7, and 8 without mirrors.

The case FOR (proponent)

The strongest mirror I believe is a type-mass stable multicommodity routing problem, based on the paper’s Section 5. Picture a large stream of passenger and freight traffic on a fixed network. A type is a cohort whose members share an origin, destination, vehicle class, and all the routing and priority properties the model uses. The cohort has mass \(\mu_i\), with \(\sum_i\mu_i=1\). A scenario could have millions of trips but only a moderate number \(\tau\) of such types. The paper itself uses roads carrying different kinds of vehicles as an example.

Here is the problem I would hand to a prover. The input is a directed network \(D=(V,E)\), types \(i\in\{1,\ldots,\tau\}\) with rational masses \(\mu_i>0\), sources \(s_i\), sinks \(t_i\), and per-capita edge capacities \(\kappa_i(e)\). Each edge has a shared capacity \(C(e)\) and ranks the types; each vertex has incoming and outgoing edge rankings for each type. The decision variables are real masses \(x_i(e)\ge 0\), with type-\(i\) capacity \(\mu_i\kappa_i(e)\), shared-capacity and flow-conservation constraints. The question is to find a stable flow: one with no blocking walk under the paper’s Definition 4, using capacities \(\mu_i\kappa_i(e)\). Thus a walk must be unsaturated for its type on each edge; its endpoints must be willing to reroute flow of that type, or be its source and sink; and any shared-saturated edge on the walk must prefer that type to some type currently using it. A solution is an exact rational flow array. There is no optimization objective: this is a search problem. Its input size is measured by \(|V|,|E|,\tau\), and the bit length \(L\) of the rational data.

My anchor is Theorem 6 (Király, Pap [27]), cited in this paper and proved elsewhere: *a stable multicommodity flow exists for every instance, but finding one is PPAD-hard.* That is the full result I rely on; the paper does not prove it. It applies directly to the mass model after a change of units: given an instance with commodity capacities \(c_i(e)\), set \(\mu_i=1/\tau\) and \(\kappa_i(e)=\tau c_i(e)\). Then \(\mu_i\kappa_i(e)=c_i(e)\), so the feasible flows and blocking conditions are unchanged. The explicit mass distribution gives the paper’s commodity types a high-multiplicity interpretation; it does not make the search easier. I expect this problem to be hard in the continuous model itself, rather than to inherit hardness from a discrete problem.

The authors could plausibly recognize this as their problem: the network, commodity priorities, vertex preferences, and blocking walks are retained, while each flow amount is read as mass from a homogeneous traffic cohort. This mirror covers the search for a stable multicommodity flow in Theorem 6. It does not claim to mirror the paper’s single-commodity interval algorithms. Nor do I use Theorem 8, which proves NP-completeness for the existence of an *integral* stable multicommodity flow. Dropping integrality changes that question; moreover, Theorem 6 already gives existence for the fractional model. Presenting Theorem 8’s NP-completeness as the hardness of the fluid mirror would overstate the case.

The main follow-up questions are whether PPAD-hardness persists for fixed \(\tau\), bounded-degree networks, or other restricted type spaces, and whether finite populations admit useful rounding guarantees for the stable fluid flow.

My weakest point is the interpretation of population. The paper’s stability is expressed through flows, preferences at network vertices, and commodity priorities; it does not start from individually described vehicles and aggregate them. Reading each commodity as a cohort of trips is credible, especially given the paper’s road-traffic example, but a referee could argue that this makes traffic mass continuous while leaving the society’s agents—the network participants—finite. Theorem 6 is also a cited hardness result for the fractional flow model, not evidence that a discrete-to-continuous transition created that hardness. The mirror stands or falls on whether shipment cohorts count as the population for this problem.

The case AGAINST (opponent, writing after the proponent)

Theorem 6 is a genuine computational result, and the traffic-cohort interpretation is plausible. But on the proponent’s own formulation, it does not create a new population-continuous problem. For each type \(i\) and edge \(e\), set \(\widehat c_i(e)=\mu_i\kappa_i(e)\). Then the constraints and blocking walks are exactly those of the paper’s stable multicommodity flow model, with the same shared capacities and rankings. The masses have been folded into the commodity capacities, which the original model already allows to vary. Theorem 6 is therefore already about the search problem being proposed.

A more substantial population model might require each cohort to have a fixed supply—say, at most \(\mu_i\) units can enter the network, or all \(\mu_i\) units must be routed. That would make population size constrain the flow independently of the edge capacities. But the paper has no cohort supplies: how much flow each commodity carries is determined by stability. Adding fixed supplies changes the question and needs new choices about unserved traffic and blocking; it is not a consequence of Theorem 6.

So the case against this anchor is strongest as a collision: the proposed mass model, as stated, is a reparameterization of an already-formulated continuous computational problem, and its population interpretation does no independent work. The universal claim remains weak, though. A fixed-supply or fixed-number-of-types variant could be worth studying, but it would need its own motivation and would no longer be the mirror the proponent anchored on Theorem 6.
