The continuous mirror question

Given a finite type set \(T\), a compatibility graph \(H\), rational type masses \(\mu_t>0\) summing to \(1\), and integer per-agent capacities \(b_t\), consider a nonatomic population in which every agent of type \(t\) can exchange with every agent of each compatible type; exchanges remain integral for each individual, including exchanges between distinct agents of the same type. Find a feasible assignment of population mass to integral exchange patterns that maximizes total exchanges and whose per-capita expected utility profile Lorenz-dominates that of every other maximum-exchange assignment. Equivalently, for an aggregate exchange plan \(x\), set \(d_t(x)=\sum_{s\ne t:\{t,s\}\in F}x_{ts}+2\mathbf{1}_{\{\{t,t\}\in F\}}x_{tt}\) and \(u_t=d_t(x)/\mu_t\); require a maximum plan to maximize \(L_u(q)=\min\{\sum_t a_tu_t:0\le a_t\le\mu_t,\ \sum_t a_t=q\}\) for every \(q\in[0,1]\), among all feasible maximum plans.

The model it lives in

A nonatomic block network with type masses \(\mu_t\), per-agent integer capacities \(b_t\), and complete compatibility between each pair of linked types. A feasible allocation is a mass assignment to individual integral exchange patterns; its aggregate exchange masses \(x_{ts}\) obey \(d_t(x)\le b_t\mu_t\). Maximize \(\sum_{\{t,s\}\in F}x_{ts}\), then select a Lorenz-dominant per-capita utility profile \(u_t=d_t(x)/\mu_t\).

What the mirror covers

The mirror covers the indivisible-goods egalitarian exchange and lottery construction in Theorem 1 for networks with complete compatibility between types. It leaves Lemma 1’s divisible-goods case, Theorem 2’s weak link group strategyproofness, and results for arbitrary topology, capacities, and other extensions outside.

Open questions for a prover

  • Does the incidence constraint \(d_t(x)\le b_t\mu_t\) fully characterize aggregate plans realizable by mass assignments to integral exchange patterns in every type-block network?
  • Does every such instance admit a Lorenz-dominant maximum-exchange profile, and can it be computed by a finite sequence of type-level LPs?
  • How do these profiles relate to the finite egalitarian mechanism as the number of agents in each type grows?

The case FOR (proponent)

A credible positive mirror is the paper’s indivisible-goods egalitarian exchange problem in a large, block-structured network. Picture a large resource-sharing consortium with many depots but relatively few operating types. A type specifies a depot’s per-depot capacity \(b_t\), its preferences over the amount exchanged, and which other types it can exchange with. Depots of the same type are identical for everything the model uses; compatibility between types is fixed. For example, there might be hundreds of thousands of depots but only a few dozen capacity and compatibility classes.

Let \(T\) be the type set, with rational masses \(\mu_t>0\) summing to \(1\), and let \(H=(T,F)\) describe compatible type pairs. A mass of type \(t\) is a fraction of the whole population, and its total exchange capacity is \(b_t\mu_t\). This is still the paper’s model of indivisible exchanges at the individual level: the continuum lets us divide *the mass of people* among integral exchange patterns. It does not give an individual a fractional exchange. In a block network, the fraction of a type assigned to each pattern replaces the lottery probability in the finite model.

My lead anchor is Theorem 1, proved in this paper. It says that the egalitarian allocation can be obtained through the constructed bipartite network: its relevant maximum flows correspond to utility profiles from maximum \(b\)-matchings in the original network, and its possibly fractional maximum flow can be written as a convex combination of integral maximum flows. Those integral flows correspond to maximum \(b\)-matchings, so the coefficients give probabilities for a lottery over them. The paper computes with this construction through the LP in Section 5.4. Theorem 1 is a formulation-and-computation anchor under the stated exception; it is not a numbered claim that the problem is in P or NP-hard.

I would hand a prover the following problem, Continuous Egalitarian \(b\)-Exchange. An instance is \((T,H,\mu,b)\) as above. For every compatible unordered pair \(\{t,s\}\), choose an exchange mass \(x_{ts}\ge 0\); a loop \(\{t,t\}\) means exchanges between distinct members of that type. Define the total exchange incidence of type \(t\) by
\[ d_t(x)=\sum_{s\ne t:\{t,s\}\in F}x_{ts} +2\mathbf{1}_{\{\{t,t\}\in F\}}x_{tt}. \]
Require \(d_t(x)\le b_t\mu_t\). The per-capita utility of type \(t\) is \(u_t=d_t(x)/\mu_t\), and total exchanges are \(\sum_{\{t,s\}\in F}x_{ts}\). First maximize total exchanges, as the paper’s maximum \(b\)-matching does. Among all maximum-exchange plans, find a plan whose utility profile Lorenz-dominates every other one. Precisely, for each \(q\in[0,1]\), define
\[ L_u(q)=\min\left\{\sum_{t\in T}a_tu_t: 0\le a_t\le\mu_t,\ \sum_{t\in T}a_t=q\right\}. \]
The required plan \(x\) must satisfy \(L_u(q)\ge L_v(q)\) for every \(q\) and every maximum-exchange plan inducing profile \(v\). A solution is the rational exchange plan \(x\), hence its per-type utilities, together with the guarantee that it is maximum and has this dominance property.

I expect this mirror to be Class A, provided the paper’s egalitarian structure carries over to the weighted, type-mass setting. The maximum-exchange part is a rational LP with at most \(O(\tau^2)\) exchange variables, where \(\tau=|T|\); the substantive algorithmic question is whether the Lorenz-dominant selection can be computed by a type-level water-filling or progressive LP method. The paper’s flow construction and egalitarian algorithm give a real reason to expect that, but writing down the first LP does not prove it. This also generates natural follow-up questions: does a Lorenz-dominant profile always exist for these continuum instances, and does the finite mechanism’s profile converge to it as the number of agents grows?

The authors should recognize this as their problem: it preserves pairwise exchanges, per-agent capacities, maximum exchange, and egalitarian utilities, while changing the population representation. It also makes the theorem’s lottery interpretation concrete: in the continuum, probabilities over integral outcomes can become fractions of a population assigned to those outcomes. The co-modification from capacities \(b_t\) to aggregate capacities \(b_t\mu_t\) is part of making the population continuous.

The weakest point is that this mirrors one computation in the indivisible model, not the paper’s whole contribution. In particular, it fixes compatibility by type and does not continue the paper’s results about strategic reports of named links. If the depots have highly idiosyncratic neighborhoods, \(\tau\) may grow to the population size and the high-multiplicity advantage disappears. And although Theorem 1 is the best anchor here, the paper supplies no numbered hardness result to ask whether its hardness dissolves in the continuum.

The case AGAINST (opponent, writing after the proponent)

Theorem 1 is the only anchor, and it does not meet the programme’s computational-result bar. It proves a correspondence between flows, maximum \(b\)-matchings, and lottery outcomes. Section 5.4 gives an LP procedure for selecting an egalitarian allocation, but the paper states no complexity result for a computational problem: no input and output complexity claim, running time, or hard subproblem. Calling Theorem 1 a “formulation-and-computation anchor” does not supply that missing result. This is the best ground for rejecting the paper as a direct anchor for the programme.

The strongest version of the proposed mirror is a sequence of large, dense block networks: agents fall into a fixed number of capacity classes, and every member of one class can exchange with every member of a compatible class. Normalizing the matching and scaling capacities by type mass makes sense in that regime; the indivisibility of each exchange does not itself defeat the model. But this is a restriction that changes the paper’s general network problem. In an arbitrary graph, a type-level edge normally turns one observed link into compatibility between every pair in two classes, losing the original topology.

Repeated motifs show the loss. Suppose the network is many disjoint triangles, with one agent of each of three types in every triangle, and each agent has capacity one. Each triangle permits at most one exchange. Yet the proposed type-level constraints allow exchange mass \(1/2\) on each of the three type pairs: every type’s capacity is respected, but the plan represents \(3/2\) exchanges per triangle. Keeping the true constraints requires recording which agents belong to the same triangle; with many triangles, that structure is not captured by a fixed distribution over the three agent types. More generally, exact neighborhoods or repeated network context may need to become part of the type, making the support grow with the population.

That objection does not eliminate the complete-block scenario: a large resource-sharing network with genuine compatibility classes could be a sensible high-multiplicity object, and its authors might recognize it as a restriction of their model. So the honest negative case is limited. The paper offers no named complexity result to mirror, and its general network structure does not compress into the proposed type model; but I cannot defend the universal claim that no worthwhile mirror exists. The proposed block-network question remains the part of the positive case that survives.
