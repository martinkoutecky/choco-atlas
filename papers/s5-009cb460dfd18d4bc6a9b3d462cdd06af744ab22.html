The continuous mirror question

Given a finite type set \(T\), rational population masses \(\mu_t\), and symmetric rational link costs \(c_{tu}\) and \(c_{tr}\), define \(F(x)=\sum_{t:x_t>0}x_t\min\bigl(\{c_{tr}\}\cup\{c_{tu}:x_u>0\}\bigr)\) for coalition masses \(x\in[0,\mu]^T\). Decide whether \(F\) has diminishing returns: for every \(x\le y\), type \(i\in T\), and \(\delta\ge0\) with \(y+\delta e_i\le\mu\), does \(F(x+\delta e_i)-F(x)\ge F(y+\delta e_i)-F(y)\) hold?

The model it lives in

A society consists of mass \(\mu_t\) of each complete connection-cost type \(t\). A coalition is a mass vector \(x\); its cost \(F(x)\) is the limiting per-capita minimum spanning-tree cost in the cloned population. The computational task is to recognize diminishing-returns submodularity on the mass box, including marginal changes within a type.

The case FOR (proponent)

The best positive case is narrow: the paper’s main result is about recognizing submodularity, and that question has a direct high-multiplicity form.

My anchor is Theorem 1, proved in this paper. For a spanning-tree game on a complete edge-weighted graph with root \(r\), let the distinct edge weights be \(w_1<\cdots<w_k\), and let \(G_i\) contain the edges of weight at most \(w_i\). A cycle is *well-covered* if each chord has weight at least every edge on one of the two paths it cuts off. It is *violated* if it is well-covered, contains a nonadjacent pair of vertices, and has a vertex not adjacent to \(r\). For an edge \(uv\) of weight \(w_i\), its expensive neighborhood is \(\hat N(uv)=\{s\notin\{u,v\}:\max(w(su),w(sv))>w_i\}\); the edge is a candidate if \(r\in\hat N(uv)\). With
\[ f_{uv}(S)=\operatorname{mst}(S\cup\{u\})+\operatorname{mst}(S\cup\{v\})-\operatorname{mst}(S)-\operatorname{mst}(S\cup\{u,v\}), \]
Theorem 1 says the game is submodular if and only if (i) no \(G_i\), for \(i<k\), contains a violated cycle, and (ii) \(f_{uv}(\hat N(uv))\ge 0\) for every candidate edge. The theorem also says these conditions can be checked in polynomial time. This is a strong anchor because the theorem gives both a structural characterization and an efficient recognition result.

I would mirror it with Continuous Submodularity Recognition for High-Multiplicity Spanning-Tree Games. Take a finite type set \(T\), a society distribution \(\mu\) over \(T\), and a root \(r\). A type is a complete connection-cost profile: every client of type \(t\) has the same cost \(c_{tu}\) to link to a client of type \(u\), including a cost \(c_{tt}\) between distinct clients of its own type, and the same cost \(c_{tr}\) to link to the root. All masses and costs are binary rationals.

For a coalition, let \(x\in[0,\mu]^T\) be its mass vector. Build the finite game with about \(q x_t\) cloned clients of each type \(t\), charge the coalition the minimum spanning-tree cost connecting them to \(r\), and divide that cost by \(q\). The continuous coalition cost is the limit as \(q\) grows. In this type-homogeneous model it has the explicit form
\[ F(x)=\sum_{t\in\operatorname{supp}(x)}x_t \min_{u\in\operatorname{supp}(x)\cup\{r\}}c_{tu}. \]
The recognition problem is: given \(T,\mu\), and the type-cost matrix, decide whether
\[ F(x)+F(y)\ge F(x\vee y)+F(x\wedge y) \]
for every \(x,y\in[0,\mu]^T\), with maximum and minimum taken coordinatewise. A “no” answer can be witnessed by two mass vectors violating the inequality; a “yes” answer establishes submodularity of the continuous cost game.

This is a plausible large-cohort regime: many clients use standardized connection-cost profiles, while the number of profiles \(\tau=|T|\) is much smaller than the population. For example, a large service consortium could have many clients but a modest number of standardized site and interface classes. Clients with genuinely different costs belong to different types. The central-source network cost and the submodularity question remain the paper’s own; normalizing the cloned game’s cost per unit of population is the co-modification needed to give the large-population limit a finite value.

I expect this recognition problem to be tractable, in Class A. The limit compresses the replicated graph to a \(\tau\times\tau\) cost matrix, and its coalition cost is explicit. That gives a reasonable starting point for a type-level structural characterization inspired by Theorem 1. The theorem itself does not establish the answer: applying its algorithm to the \(q\)-clone graph would not by itself give a running time polynomial in \(\tau\) and the binary input length \(L\). The prover’s task is to find a compressed characterization or algorithm, or show that this expectation is wrong. Further questions include whether an analogue of the violated-cycle and candidate-edge conditions suffices, and when submodularity of the limit agrees with submodularity of the finite clone games.

The authors should recognize this as a close analogue of their problem: it keeps the spanning-tree characteristic cost and asks whether the cost game is submodular, while replacing named clients with mass over clients who are identical in every cost the game uses. The main soft spot is that the limit can jump when a type’s mass changes from zero to any positive amount: even a tiny positive share represents arbitrarily many clients as \(q\) grows and can supply cheaper links for the rest. That support effect is a real modeling consequence, not a smoothness claim. It may make the mirror less attractive to authors who require coalition costs to vary continuously with mass, but it does not make the population limit arbitrary.

The case AGAINST (opponent, writing after the proponent)

The best objection is to the proposed mirror’s *definition* of submodularity. Theorem 1 recognizes submodularity of a set function on individual players; for a type-symmetric clone game, that requires diminishing returns when adding another player of the same type as well as of a different type. The proposed inequality on \([0,\mu]^T\), using coordinatewise maximum and minimum, does not impose the same-type condition: in one dimension it is automatic for every function. So that formulation alone does not faithfully mirror the theorem.

Its limiting cost also has a singular boundary. For example, let the root-to-client costs be \(10\), the cost between distinct \(A\) and \(B\) clients be \(1\), and within-type costs be \(100\). The proposed limit gives \(F(a,0)=10a\), but \(F(a,\epsilon)=a+\epsilon\) for every \(\epsilon>0\). An arbitrarily small positive share of type \(B\) changes the connection cost of all type \(A\) clients: in the clone limit, even that small share contains arbitrarily many potential links. This makes the limit discontinuous at zero and means the stated continuous recognition problem is not simply a smooth mass version of the finite game.

Those are real cautions, but they do not defeat the anchor. The authors could define the mirror using diminishing returns on the type-count lattice, including same-type additions, or ask for a mass-scale version of that condition while retaining the boundary behavior. Both keep the spanning-tree cost game and its submodularity question, and both give a computational problem parameterized by the number of types and the input bit length. Standardized client cost profiles are a plausible high-multiplicity regime. Theorem 1 is plainly a named polynomial-time recognition result, and the fact that its algorithm runs in the number of vertices does not answer whether it can be compressed to a small type space.

So I cannot make the requested universal case honestly. The proposed continuous formulation needs repair, and its limit has an unusual support effect; but a better, author-recognizable mirror survives. The negative case is weak precisely at its central claim: I see no fundamental reason this paper’s submodularity-recognition problem has no worthwhile high-multiplicity version.
