The case AGAINST (opponent, writing after the proponent)

The strongest possible anchor is Theorem 1, but it is a characterization of core nonemptiness, not a computational result. The paper itself says its interest is “more mathematical than algorithmical” and recommends testing the core inequalities with linear programming. It gives no input representation, complexity bound, or algorithm whose behavior a continuous mirror could extend.

The best proposed mirror would take a society with finitely many types, represent a coalition by its mass vector \(z\), and ask whether there is a type-level payoff vector \(y\) satisfying the continuum core constraints. That can be a sensible new problem. But the paper does not specify how coalition worths \(v(S)\) become a function of \(z\), how feasible coalitions aggregate, or how either is encoded. With arbitrary worths, the continuous instance still needs an unbounded amount of input; with a compact, structured worth function, its representation supplies the computational problem. Theorem 1 chooses none of these models.

So the argument is not that a continuous-player core question is meaningless, or that identity can never be abstracted away. It is that making such a question computational requires adding the very structure this paper does not study. The universal claim that no scenario could yield worthwhile research is hard to establish; the narrower case is strong that this survey supplies no computational result to mirror.
