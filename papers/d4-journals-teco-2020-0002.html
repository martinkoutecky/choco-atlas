The continuous mirror question

Given a finite outcome set \(A\), supported nonempty like-sets \(\mathcal T\subseteq 2^A\setminus\{\emptyset\}\), and binary-rational masses \(\mu_S>0\) summing to one, compute the exact expected RP share of each distinct outcome signature. Draw a type order sequentially, choosing each remaining \(S\) with probability proportional to \(\mu_S\); for each order, select its lexicographically maximal like-set signature, then average the resulting shares over orders.

The model it lives in

Types are nonempty like-sets \(S\subseteq A\) with mass \(\mu_S\). For each order \(\pi=(S_1,\ldots,S_\tau)\), lexicographically maximize \((\mathbf{1}[a\in S_1],\ldots,\mathbf{1}[a\in S_\tau])\) over outcomes \(a\in A\), grouping outcomes with identical signatures; the output is the expected share of each signature under the size-biased type-order distribution.

The objection that survived

The proposed type-utility output is weaker than the RP outcome computation behind the \(\#\mathrm{P}\)-completeness claim, so hardness does not automatically transfer; the mirror should ask for exact shares over outcome-signature classes.

fatal: False

What the mirror covers

The mirror covers Theorem 2(iv)'s polynomial-time CUT computation and exact RP computation hardness. It leaves the fairness, incentive, and efficiency claims, as well as the numerical experiments, outside the mirror.

Open questions for a prover

  • Does a fully polynomial randomized approximation scheme exist for expected RP shares with binary-rational type masses?

The case FOR (proponent)

My strongest anchor is item (iv) of Theorem 2. It says, in full, that the Conditional Utilitarian (CUT) mixture can be computed in time polynomial in \(n+|A|\), while computing the Random Priority (RP) rule is \(\#\mathrm P\)-complete in \(n+|A|\), for the paper’s dichotomous-preference model. The paper gives the CUT computation in its computational discussion; it attributes the RP hardness to Aziz, Brandt, and Brill (2013), so that hardness is cited here rather than newly proved. The RP half is the stronger anchor for ChoCo: it asks whether exact computational hardness survives when the population is represented by type masses.

A natural setting is a large participatory-budgeting consultation. Let \(A\) be a small menu of public projects or services, and let a voter’s type be a nonempty like-set \(S\subseteq A\). The society is a distribution \(\mu\) over supported types, with positive rational masses summing to one. For a city with many residents but a modest project menu, the number \(n\) of residents can be far larger than the support size \(\tau\); there are at most \(2^{|A|}-1\) possible types. Mass records each group’s share of the population. This preserves the paper’s dichotomous preferences and its outcome mixtures while making the society itself continuous.

I would ask the authors to study Mass-Profile CUT/RP Evaluation. An instance is \(A\), a support \(\mathcal T\subseteq 2^A\setminus\{\emptyset\}\), and binary-rational masses \((\mu_S)_{S\in\mathcal T}\) summing to one. The task is to return the exact type-indexed utility profiles selected by both rules.

For CUT, let \(q_a=\sum_{S:a\in S}\mu_S\), the mass that likes outcome \(a\). As in the paper, first identify outcomes with identical utility profiles across the society: \(a\sim b\) when every supported type likes \(a\) exactly when it likes \(b\). For each type \(S\), take the distinct outcome classes it likes that have maximum \(q_a\), and divide its mass uniformly across those classes. The resulting mixture induces \(F^{\mathrm{CUT}}_R\), the utility of each supported type \(R\). This is the mass version of the paper’s CUT computation and is computable in polynomial time in \(|A|,\tau,L\), where \(L\) is the mass encoding length.

For RP, generate an ordering \(\pi=(S_1,\ldots,S_\tau)\) of the supported types by choosing each next type with probability proportional to its remaining mass. Thus
\[ \Pr_\mu(\pi)=\prod_{j=1}^{\tau} \frac{\mu_{S_j}}{\sum_{k=j}^{\tau}\mu_{S_k}}. \]
For a fixed ordering, let \(v^\pi\) be the utility profile induced by lexicographically maximizing
\[ \bigl(z(S_1),\ldots,z(S_\tau)\bigr) \quad\text{over }z\in\Delta(A), \qquad z(S)=\sum_{a\in S}z_a. \]
The continuous RP output is the exact expected profile
\[ \bar F^{\mathrm{RP}}_S=\sum_\pi \Pr_\mu(\pi)\,v^\pi_S \quad\text{for each }S\in\mathcal T. \]
This is the paper’s rule-level output: an average utility profile, which is feasible because it is an average of feasible profiles. So the proposed problem has a precise instance, a precise query, and a precise solution.

The connection to the named result is unusually direct. If \(\mu_S=n_S/n\), assign each individual an independent continuous random priority. The earliest individual of each type induces a random type order; the minima for the types race with weights \(n_S\), giving exactly the ordering probabilities above. Repeated individuals of one type add repeated, identical lexicographic criteria and do not change the resulting utility profile. Thus the continuous RP output at these masses is exactly the finite RP output compressed by type. The discrete \(\#\mathrm P\)-hardness therefore transfers to exact continuous RP evaluation on this subfamily. I expect the RP part to be hardness transfers, not continuum-specific hardness. The CUT part remains tractable. Exact RP evaluation is also fixed-parameter tractable in \(\tau\) by enumerating the \(\tau!\) orders and solving the lexicographic optimization for each.

The mirror covers the paper’s computational comparison in Theorem 2(iv), not its axiomatic results as a whole. Its computational question is not made easier by dropping clone masses or by replacing RP with an easier rule: the type masses retain RP’s dependence on how many people hold each preference. And although the paper already studies lotteries over outcomes, its agents are finite. Here the population distribution is the object of the input. That distinction matters for complexity because binary-encoded masses can describe very large populations compactly.

The weakest point is that the mass-weighted type ordering is not separately defined in the paper. The case for it is that the finite RP rule itself induces exactly that ordering after identical voter types are compressed; it is not an unrelated stochastic extension. A second qualification is that the hardness source is cited rather than proved by these authors. Neither weakens the core mirror: the authors’ exact mechanism has a natural high-multiplicity input, and its hard computational question survives there. Further questions include whether exact RP evaluation admits substantially better algorithms parameterized by \(\tau\), and whether a useful relative approximation scheme exists for its output.

The case AGAINST (opponent, writing after the proponent)

The strongest objection is to the proponent’s *specific complexity claim*: the paper’s \(\#\mathrm P\)-completeness statement concerns computing RP, while their proposed query returns only the expected utility of each supported type. The paper distinguishes utility profiles from mixtures, and different mixtures can induce the same profile. So the cited result does not, by itself, establish hardness for that weaker output. A sound transfer argument needs either a reduction that recovers the hard output from the type utilities or a mirror that asks for the relevant outcome shares directly.

That objection does not defeat the better mirror. For rational masses with common denominator \(D\), set \(d_S=D\mu_S\) and expand the society into \(d_S\) voters of each type. In a random permutation of those voters, the order in which types first appear has exactly the proponent’s probabilities:
\[ \Pr(S_1,\ldots,S_\tau) =\prod_{j=1}^{\tau} \frac{\mu_{S_j}}{\sum_{k=j}^{\tau}\mu_{S_k}}. \]
Repeated voters of a type add redundant lexicographic criteria. Thus this weighted type order is a natural high-multiplicity version of RP, and the paper’s finite rule supplies a clear bridge to it. The society has genuine repeated types, and the aggregate output does not depend on named identities.

There is a practical qualification: with binary-encoded masses, the expanded population can be enormous, so an exact output may itself require many bits. That calls for care about output encoding and approximation questions; it does not make the mirror vacuous. In particular, the paper already highlights exact and approximate RP computation as computational concerns.

So I can challenge the claimed hardness transfer for the utility-profile query as stated. I cannot honestly make the stronger case that no worthwhile continuous mirror exists. The mass-weighted RP evaluation problem remains a plausible mirror of Theorem 2(iv), and the paper’s \(\#\mathrm P\)-completeness result makes it more compelling, not less, once the output query is matched precisely.
