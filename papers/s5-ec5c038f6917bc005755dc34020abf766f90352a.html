The continuous mirror question

Given a finite metric support \(X\), finite candidate set \(F\), integer \(k\), and rational public location masses \(\lambda_x\), compute a set \(A\subseteq F\) with \(|A|=k\). For every hidden distribution \(\mu\) on \(X\times\{M,S\}\) satisfying \(\mu_{x,M}+\mu_{x,S}=\lambda_x\), let \(r=\sum_x\mu_{x,M}\), \(c_M(x,A)=\max_{a\in A}d(x,a)\), \(c_S(x,A)=\frac{1}{k}\sum_{a\in A}d(x,a)\), and \(\mathrm{SC}_{\mu}(A)=\sum_{x,\theta}\mu_{x,\theta}c_\theta(x,A)\). Find a deterministic rule using only \(\lambda\) such that \(\mathrm{SC}_{\mu}(A)\leq (3-\frac{4}{k}+\frac{2r}{k})\min_{B\in{F\choose k}}\mathrm{SC}_{\mu}(B)\) for every compatible \(\mu\).

The model it lives in

The population consists of masses \(\mu_{x,\theta}\) for location and cost type \((x,\theta)\), with public location marginal \(\lambda_x\) and hidden type composition. The outcome remains a discrete \(k\)-subset of \(F\); choose the \(k\) facilities with smallest \(w(a)=\sum_x\lambda_xd(x,a)\), and assess the result against the mixed social cost for every compatible type distribution.

What the mirror covers

The mirror covers the welfare guarantees of Theorems 2.2 and 2.4 in the type-private, location-public setting. It leaves out Theorem 2.6’s individual-report lower bound, the private-location results in Section 3, and Section 4’s unrestricted facility locations.

Open questions for a prover

  • For the Theorem 2.4 variant with known \(r\), can an SC-Max-optimal \(k\)-set be computed in polynomial time when \(k\) varies?
  • Is the Theorem 2.4 approximation ratio tight for continuous populations with known \(r\)?

The case FOR (proponent)

The best mirror is the paper’s private-type, public-location problem. It already treats the share of each type as an aggregate quantity, and its main guarantee depends on that share rather than on the number of agents. A plausible high-multiplicity setting is a city with many residents concentrated in a modest number of zones. A resident’s type is their zone and whether they care about the maximum distance to the selected facilities or the average distance. Residents in the same zone with the same cost type are indistinguishable for this problem. Thus the population may be large while the number of distinct types \(\tau\) is at most twice the number of occupied zones.

Keep the candidate facility set finite, as in the paper. The population is the object being continuized; the facilities and the \(k\)-facility outcome remain discrete. Let \(\mu_{x,\theta}\) be the fraction of the population at location \(x\) with cost type \(\theta\in\{M,S\}\), where

\[ c_M(x,A)=\max_{a\in A}d(x,a),\qquad c_S(x,A)=\frac{1}{k}\sum_{a\in A}d(x,a). \]

For a \(k\)-facility set \(A\), the social cost is

\[ \mathrm{SC}_{\mu}(A)=\sum_{x,\theta}\mu_{x,\theta}c_\theta(x,A), \qquad \mathrm{OPT}_{\mu}=\min_{A\in {F\choose k}}\mathrm{SC}_{\mu}(A). \]

The masses are binary rationals, and the support is finite. The mechanism sees the location marginal \(\lambda_x=\mu_{x,M}+\mu_{x,S}\), but not which residents have which cost type.

My lead is Theorem 2.2, proved in this paper. It says that for arbitrary metrics and \(k\ge2\), choosing a solution optimal for \(\mathrm{SC\text{-}Avg}\) gives a \(\left(3-\frac{4}{k}+\frac{2|M|}{kn}\right)\)-approximation to \(\mathrm{SC\text{-}Mix}\), for every mixture of max and sum agents. This is a deterministic strategyproof mechanism for the paper’s type-private, location-public setting; it does not need to know the individual types.

Its continuous mirror is Type-Blind Mixed Facility Selection. Given \((X,F,d,k,\lambda)\), find a deterministic rule \(\Phi\) that returns \(A\in{F\choose k}\) such that, for every hidden population \(\mu\) with location marginal \(\lambda\),

\[ \mathrm{SC}_{\mu}(\Phi(\lambda)) \le \left(3-\frac{4}{k}+\frac{2r}{k}\right)\mathrm{OPT}_{\mu}, \qquad r=\sum_x\mu_{x,M}. \]

The rule is not given \(r\). A concrete solution is to choose the \(k\) facilities with smallest values of \(w(a)=\sum_x\lambda_xd(x,a)\), which is exactly an \(\mathrm{SC\text{-}Avg}\)-optimal choice. Since the rule ignores type reports, it is strategyproof for those reports. Computing the \(w(a)\) values and selecting the \(k\) smallest takes time polynomial in \(|F|\), the location support size \(\tau\), and the input bit length \(L\). I expect this mirror to be Class A.

The link to high multiplicity is direct: any rational \(\mu\) can be represented by replicating agents up to a common denominator. But the continuous input can be much shorter than that expanded electorate, and the algorithm works from the support and masses without constructing it. This is a useful computational question in its own right: what can be done in \(\tau\) and \(L\), rather than in the potentially enormous population size?

A second, stronger-information mirror rests on Theorem 2.4, also proved here. It says that, for arbitrary \(k\) and metric, there is a deterministic strategyproof mechanism with approximation factor

\[ \frac{2}{1-k+\sqrt{k^2-k+1}}-1, \]

without knowing individual types but with the true fraction \(r=|M|/n\). Its continuous question is the same as above, now given \((X,F,d,k,\lambda,r)\), and asks for a type-report-independent facility rule meeting that factor for every compatible hidden \(\mu\). The paper’s witness chooses between an \(\mathrm{SC\text{-}Avg}\)-optimal set and an \(\mathrm{SC\text{-}Max}\)-optimal set according to \(r\).

I expect this second question to be tractable for fixed \(k\); for variable \(k\), any difficulty seems likely to come from the finite facility-selection combinatorics in finding the \(\mathrm{SC\text{-}Max}\)-optimal set, so I would expect Class B, if hardness is established, rather than continuum-specific hardness. The paper itself does not give a running-time classification for that optimization step. The follow-up questions are whether the stated guarantee can be achieved in polynomial time for variable \(k\), and whether it is tight for continuous populations with known \(r\).

These mirrors cover Section 2’s type-private, location-public results, not the paper’s private-location results or its unrestricted-location median result. I would not anchor on Theorem 2.6’s \(1.186\) lower bound: its proof concerns incentives among individual finite agents, and it does not transfer as directly to an atomless population.

My weakest point is that the lead is an approximation guarantee, not a named NP-hardness or polynomial-time classification from the paper. Also, individual truthfulness in the continuous model is weak when a single resident has zero mass. Here that does not erase the central question—the mechanism is already type-blind—but it means the substantive mirror is the guarantee against every hidden type composition, not a new continuum incentive effect. The authors have a strong reason to recognize that question: they already motivate knowledge of the aggregate type fraction as useful while withholding individual type identities.

The case AGAINST (opponent, writing after the proponent)

The strongest negative case is a fit problem. The paper’s numbered results are distortion guarantees, strategyproofness claims and optimality statements. It gives no running-time classification for a computational problem, and studies no mass-transfer, control or manipulation algorithm. A continuous version can preserve its approximation ratios, but that would carry mechanism-quality results into a weighted model; it would not mirror a complexity result of the kind ChoCo is set up to chart.

The proposed Theorem 2.2 scenario is plausible: residents can share a neighborhood and a cost type, giving rational masses over a finite support. The resulting question—how well a facility rule performs for every hidden assignment of max and sum types with a given location distribution—is well-posed. But its core is robust mechanism quality. The mechanism ignores type reports, so individual strategyproofness adds no constraint; in an atomless model, individual reports have no effect in any event. A stronger question about the best achievable ratio or a best rule for each distribution could be worthwhile, but it would be a new mechanism-synthesis problem, not a computational question the paper’s theorem answers.

Theorem 2.4 has the same limitation. Knowing the aggregate type share \(r\) gives a stronger information model and a different ratio guarantee. A continuous mirror could ask for the best rule given location masses and \(r\), or for an efficient way to implement the paper’s choice. The first asks for optimal distortion; the second adds a runtime question absent from the theorem. Neither makes the population masses the object being optimized or intervened upon. Facilities remain a finite choice, and the paper’s result concerns the quality of that choice.

Other results do not offer an obvious escape. Theorem 2.6’s lower bound rests on individual type reports and one-agent changes; preserving that incentive test requires a positive per-person mass quantum. The median results in Sections 3 and 4 can be expressed for weighted populations, but their claims are still about strategyproofness and approximation, while Theorem 4.2 also continuizes the facility locations—a different axis from ChoCo’s population focus.

This does not establish that the model is already continuous, or that high multiplicity is an objection; neither would be a sound basis for rejecting it. The negative case is narrower: the proposed mirrors are credible weighted extensions, but their natural questions concern robust approximation and mechanism design rather than the computational landscape ChoCo is targeting. That case is strongest if the programme keeps that boundary; it weakens substantially if ChoCo intends to include continuous robust mechanism design.
