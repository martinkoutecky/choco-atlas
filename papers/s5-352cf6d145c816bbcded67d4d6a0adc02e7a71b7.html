The case FOR (proponent)

The paper has one useful computational anchor, Proposition 1, proved here. It says that among games with no finite carrier, for each of the sixteen combinations of monotonicity, properness, strongness, and nonweakness, a \(\delta\)-computable game exists if and only if a \(\delta\)-noncomputable game exists. This is an existence classification, not an NP-hardness or polynomial-time result. Five axiom types contain no games at all, and type 2 has no infinite games; in each of the other ten types, both computable and noncomputable infinite games exist. That is the result I would mirror.

A plausible setting is a large authorization or multi-criteria system whose participants fall into interchangeable roles: for example, many citizens in each eligibility or constituency category. A type is a role containing every attribute relevant to the decision. Its mass is the fraction of the population in that role, and a coalition is described by the participating mass of each type. The population can be large even when a particular society has few supported roles. To match Proposition 1’s no-finite-carrier condition, though, the *universe* of possible roles must be countably infinite, and rules must be allowed to depend on arbitrarily many of them.

Here is a concrete question. Fix \(\mathcal T=\mathbb N\) and a society with rational type masses \(\mu_i=2^{-(i+1)}\). A coalition is a uniformly computable rational sequence \(x\) with \(0\le x_i\le\mu_i\), where \(x_i\) is the participating mass of type \(i\). A continuum simple game is a rule \(W(x)\in\{0,1\}\). Define monotonicity by coordinatewise increase in \(x\); define properness and strongness using the complementary coalition \(\mu-x\); and call the game weak when some type is fully included in every winning coalition, meaning \(x_i=\mu_i\) for every winning \(x\). A finite type carrier is a finite \(C\subseteq\mathcal T\) such that \(W(x)\) depends only on \(x|_C\).

Cohort Computability Independence asks: among games with no finite type carrier, for each of the sixteen axiom signatures, does an effectively decidable game exist if and only if a nondecidable game exists? An algorithmic game has a Turing procedure deciding \(W(x)\) from a program index for the computable rational sequence \(x\), with the indicator on valid indices admitting a partial recursive extension, in the spirit of the paper’s \(\delta\)-computability. A solution is a proof or construction for each signature, or a proof that one side is empty. There is no optimization objective here: as in the paper, the computational task is to decide whether a coalition wins.

The connection is concrete at the all-or-none profiles: each recursive coalition \(S\subseteq\mathbb N\) gives \(x_i=\mu_i\) for \(i\in S\) and \(x_i=0\) otherwise. Thus the continuous question retains the paper’s binary coalition domain while adding partial participation within a type. My expectation is that nondecidability can survive this enlargement; a noncomputable discrete game cannot acquire a computable lift if the lift agrees with it on those profiles. Whether the fractional profiles permit new examples, or allow the full classification to be proved, remains open. This is a computability question, so the programme’s usual tractable-versus-hard complexity trichotomy does not apply directly.

The mirror covers Proposition 1 alone, not the paper’s entire investigation of finite games or all 64 classes. Its weakest point is that the paper’s games can depend on the identities of countably many players, while this mirror groups participants into cohorts. The mass values and the available fractional coalitions also introduce choices the paper never makes; its \(\delta\)-computability concerns indices for recursive coalitions, not rational mass profiles. The authors could recognize this as a continuous analogue of their classification question, especially given their criteria and contingencies interpretations, but the countably infinite type universe and infinite support make it an edge-regime mirror rather than a standard few-type high-multiplicity case.

The case AGAINST (opponent, writing after the proponent)

Proposition 1 is the paper’s strongest anchor, and it is a real algorithmic result: it classifies when computable and noncomputable infinite games coexist across the sixteen axiom types. The negative case should not pretend the paper lacks a computational theorem. The mismatch is that \(\delta\)-computability is a property of a rule on program-described, infinite coalitions. It does not give running-time bounds for a finite-input decision problem of the kind ChoCo studies.

The carrier condition makes the mismatch structural. In the paper, a finite carrier is a finite set of named players whose membership determines the outcome for every recursive coalition. Those names can remain separately consequential across an infinite domain. With a fixed finite set of continuous voter types, every mass rule has the entire type set as a finite carrier, so Proposition 1’s “no finite carrier” setting disappears. Making players interchangeable within types cannot preserve distinctions the rule makes between their names. Giving each player their own type preserves those distinctions, but requires infinitely many types.

The proposed geometric masses illustrate the cost of that choice. The profiles with \(x_i\in\{0,\mu_i\}\) encode the paper’s recursive coalitions, so extending a game from those profiles can reproduce its result. But the base society then has countably infinite support, and its mass vector must be given as an infinite program-described sequence. That carries over the paper’s infinite-input computability setting; it does not fit ChoCo’s finite list of supported types and binary-rational masses. If the model instead requires finite support, it cannot represent the paper’s arbitrary infinite coalitions. In an atomless population, individual names have measure zero, so mass-based rules erase the finite identity distinctions that the carrier notion tracks. Keeping decisions sensitive to those names would make mass an insufficient description of the society.

There are conceivable repairs. One could study countably many positive-mass cohorts, or a family of finite-support societies over a countable universe of possible roles. Those are coherent research questions, especially for criteria or constituency systems. They need new choices about what a type means, how the rule takes a finite input, and how the paper’s infinite-coalition axiom and carrier conditions translate. They are no longer a direct continuization of Proposition 1 within ChoCo’s finite-support population model. The repaired setting also risks making the fractional mass coordinates incidental: the computability phenomenon may be carried entirely by the countable set of role identities.

So the negative case is strong against this as a ChoCo mirror, but it is not an impossibility claim. An infinite-cohort computability project could be worthwhile on its own. Its weakness as a rebuttal is that someone willing to expand ChoCo to infinite type spaces could still make a serious case for it; the paper’s criteria interpretation gives that proposal some footing.
