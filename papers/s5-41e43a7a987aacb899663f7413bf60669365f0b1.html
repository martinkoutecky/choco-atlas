What the mirror covers

No result is covered by a computational mirror; Theorems 4.1 and 4.2 are axiomatic characterizations, as are the paper's other named mechanism results.

The case FOR (proponent)

I can’t give a valid positive computational case under your anchor rule: this paper has no named result asserting that a problem is in P, NP-hard, FPT, or otherwise classifying its computational complexity.

The closest result is Theorem 4.1, proved here. It says that, when agents control multiple locations, a mechanism is anonymous, efficient, and strategyproof against manipulation, replication, and hiding if and only if there are constants \(\alpha_1,\ldots,\alpha_{n-1}\) and \(\beta\in[0,1]\) such that it outputs the median of those constants and the agents’ representative locations \(y_i^*=\beta y_i^0+(1-\beta)y_i^1\), where \([y_i^0,y_i^1]\) is agent \(i\)’s median interval. Theorem 4.2, also proved here, gives the same characterization for manipulation alone when every agent controls the same number of locations. These are axiomatic characterizations, not computational results. The median formula may be straightforward to evaluate, but the paper does not state a complexity result for that task.

The most plausible population scenario would be many repeated communities, each with the same finite bundle of resident or service-site locations. A type would be one such bundle, and \(\mu_t\) its fraction of the population; the planner chooses a facility location, with each type’s loss given by the sum of its members’ distances to the facility. One could ask for a characterization of anonymous, Pareto-efficient rules over these distributions that resist manipulation, hiding, and replication. Theorem 4.1 suggests generalized-median rules as a possible starting point, but does not establish a continuum characterization. In particular, an individual with zero mass cannot change the distribution, making individual strategyproofness vacuous; requiring deviations by positive-mass coalitions would change the question.

That is a possible axiomatic continuation with a plausible high-multiplicity setting, but it is outside the programme’s computational focus. I would not present it as a mirror anchored in this paper’s computational results.

The case AGAINST (opponent, writing after the proponent)

The decisive problem is that the paper has no named computational result to mirror. Theorems 4.1 and 4.2 characterize which mechanisms satisfy anonymity, efficiency, and strategyproofness; Theorem 3.1 gives an impossibility result for non-identifying reports; and Theorems 5.1 and 5.2 characterize group strategyproofness. None studies the running time or complexity of a computational problem. That is exactly the distinction ChoCo draws: an axiomatic characterization is not a computational mirror, even if the mechanism it describes is easy to evaluate.

The proposed repeated-community setting is plausible, and a type containing a community’s full bundle of locations could preserve the identifying information the paper needs. But it does not preserve the theorem’s incentive question in a nondegenerate continuum. If each community member has zero mass, one person’s report cannot change the outcome, so individual strategyproofness becomes vacuous. If instead a whole positive-mass type changes its report together, the question becomes strategyproofness against mass coalitions, which is a different incentive notion. Keeping a finite number of communities as strategic actors avoids that change, but then the strategic population has not been continuized.

The same obstacle applies to Theorem 4.2: its equal-number-of-locations assumption and manipulation-only characterization remain axiomatic, and moving from individuals to a distribution does not supply a complexity problem. Theorem 3.1 makes the modeling constraint especially clear: the mechanism needs to know which locations belong to the same agent. A distribution over complete location bundles can retain that information, but preserving it does not turn the characterization into an algorithmic result.

One could propose a new task, such as computing the smallest mass coalition that can move the facility to a target location. That is a coherent research question, but it adds an objective and an input problem that the paper does not define; it is not a computational result already anchored by these theorems. So the case against a *mirror of this paper for ChoCo* is strong. The universal claim that no worthwhile computational question could ever be built from this model is harder to defend: a new coalition or robustness problem might be worthwhile, but it would be a new line of work rather than the continuous counterpart of a result here.
