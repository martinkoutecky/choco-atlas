The continuous mirror question

Given a fixed \(k\ge5\), an explicit rational distribution \(\mu\) over complete ranking types on candidates \(C\), a target \(p\), and a budget \(B\), let \(w\) be the current \(k\)-approval winner and \(E=\{t:p\succ_t w\}\). For each source type \(t\in E\) and approval set \(A\subseteq C\) with \(|A|=k\), choose transferred mass \(x_{t,A}\ge0\) with \(\sum_A x_{t,A}\le\mu_t\) and \(\sum_{t,A}x_{t,A}\le B\). Does there exist such a transfer, changing the \(k\)-approval score vector to \(s'(c)=\sum_t\mu_t\mathbf{1}[c\in\operatorname{top}_k(t)]-\sum_{t,A}x_{t,A}\mathbf{1}[c\in\operatorname{top}_k(t)]+\sum_{t,A}x_{t,A}\mathbf{1}[c\in A]\), such that \(p\) wins under the paper's tie-breaking rule?

The model it lives in

Mass-\(k\)-Approval Frugal-\$Bribery\(_\infty\) over an explicit type support: each type carries mass \(\mu_t\), only types with \(p\succ_t w\) may be changed, \(x_{t,A}\) transfers mass to a target top-\(k\) set \(A\), the objective is to minimize transferred mass or satisfy budget \(B\), and winner constraints are linear in the resulting score vector. For fixed \(k\), the \(\binom{m}{k}\) target sets give a polynomial-size linear program.

What the mirror covers

The mirror covers the frugal-bribery and frugal-\$bribery results anchored by Theorems 87 and 80, but leaves the thesis's preference-elicitation, sampling, streaming, kernelization, manipulation-detection, partial-information, and other control results without a defended continuous-population formulation.

Open questions for a prover

  • What finite-population rounding bound relates the fractional optimum to an \(N\)-voter election with the same type distribution?
  • What integrality gaps arise when the budget and campaign masses are discretized in units of \(1/N\)?

The case FOR (proponent)

There is a strong positive case, led by Theorem 87. The paper contains hardness results whose combinatorics live in indivisible population weights; replacing those weights by divisible mass produces natural finite-dimensional optimization problems.

The lead anchor is Theorem 87, proved in the thesis by a reduction from Partition: *Frugal-bribery for the maximin rule is \(\mathsf{NP}\)-complete for weighted elections with four candidates.* In the reduction, the candidates are \(p,a,b,c\); the Partition item \(w_i\) becomes a vote of weight \(w_i\) with ranking \(p\succ a\succ b\succ c\); three additional vote types each have weight \(K\); the current winner is \(a\), so precisely the \(p\succ a\succ b\succ c\) votes are \(p\)-vulnerable. The target \(p\) can win by changing only those vulnerable votes if and only if some subset of the weights \(w_i\), summing to \(2K\), sums to \(K\).

My continuous mirror is Mass-Maximin Frugal Bribery\(_\infty\). An instance consists of four candidates \(C=\{p,a,b,c\}\), a rational distribution \(\mu\) over the \(24\) complete rankings of \(C\), and the target \(p\). Let \(w\) be the current maximin winner and let \(E=\{t:p\succ_t w\}\) be the vulnerable types. A solution is a nonnegative transfer \(x_{t,t'}\) of mass from \(t\in E\) to arbitrary output rankings \(t'\), subject to \(\sum_{t'}x_{t,t'}\le\mu_t\). The resulting society is

\[ \mu'_{u}=\mu_u-\sum_{t'}x_{u,t'}+\sum_{t\in E}x_{t,u}. \]

The question is whether some such transfer makes \(p\) the maximin winner, with the same tie-breaking convention as the paper; naturally, one may also minimize the transferred mass \(\sum_{t,t'}x_{t,t'}\).

This is precisely the paper’s question with voters replaced by a distribution over complete voter types. It is especially plausible in a large organization choosing among four proposals, where many agents share one of a small number of stable preference archetypes and a campaign can persuade a fraction of a vulnerable archetype. The regime has \(N\gg\tau\), with \(\tau\le24\), and all agents of a type have identical preferences and intervention status.

I expect this mirror to be Class A. Pairwise maximin margins are linear in \(\mu'\). For a fixed candidate \(p\), introduce \(z\) as its maximin score, impose \(z\le D_{\mu'}(p,y)\) for every \(y\neq p\), and, for each rival \(x\), guess a witness \(y_x\) with \(D_{\mu'}(x,y_x)\le z\). Since there are only four candidates, there are constantly many witness choices, each yielding a rational linear program.

The Partition hardness disappears for exactly the reason continuization is meant to expose. All \(w_i\)-votes in the reduction have the same ranking and become one type of aggregate mass \(2/5\); the three fixed vote types have masses \(1/5\) each. The subset-sum choice becomes divisible mass transfer. The theorem is therefore not a novelty collision: weighted elections still treat weighted ballots as indivisible objects, whereas this mirror makes the population itself continuous.

A second useful anchor is Theorem 80, also proved in the thesis, which states: *Frugal-\(\$\)bribery for \(k\)-approval is \(\mathsf{NP}\)-complete for every fixed constant \(k\ge5\), even when every vulnerable vote has price \(1\) or \(\infty\).* The proof is from X3C. For each set \(S_i\), it creates a vote \(p\succ q\succ S_i\succ D\succ\cdots\), with \(|D|=k-1\); additional votes arrange the scores so that \(q\) is ahead of \(p\) by \(|U|/3\), every universe candidate is just ahead of \(p\), and the budget is \(|U|/3\). Changing exactly the right set-votes makes \(p\) win if and only if the corresponding \(S_i\)'s form an exact cover.

The corresponding question is Mass-\(k\)-Approval Frugal-\(\$\)Bribery\(_\infty\). The input is a rational type distribution \(\mu\), fixed \(k\ge5\), target \(p\), and budget \(B\). The current winner \(w\) determines the vulnerable types \(E=\{t:p\succ_t w\}\). A transfer \(x_{t,t'}\) is allowed only from \(E\), costs one unit per unit of transferred mass, and must satisfy

\[ \sum_{t\in E,t'}x_{t,t'}\le B. \]

The resulting \(k\)-approval scores are

\[ s_{\mu'}(c)=\sum_t\mu'_t\,\mathbf 1[c\text{ is among the top }k\text{ positions of }t]. \]

The question is whether \(p\) wins after some affordable transfer.

This is also a faithful mirror: it retains the same target, current-winner-relative vulnerability, \(k\)-approval rule, unit/\(\infty\) prices, and budgeted bribery action. A natural regime is a large electorate divided into campaign segments whose members share the same top-\(k\) slate and the same unit campaign cost. With \(k\) fixed, only the output top-\(k\) set matters, so the possible output actions are the \(\binom{m}{k}\) approval sets. The problem is therefore a polynomial-size LP in the type support and \(\binom{m}{k}\), with linear winner and budget constraints. I again expect Class A.

Here the X3C hardness becomes a fractional covering problem: a type can be influenced by an arbitrary fraction of its mass, rather than selected as an indivisible vote. That is not a weakened story; it is the high-multiplicity version of campaigning. It generates useful follow-up questions about integrality gaps, finite-\(N\) rounding, and whether the continuous optimum approximates the discrete optimum within an additive error depending on \(\tau/N\).

The weakest point is that both mirrors deliberately remove indivisibility. An opponent can say that the paper’s hardness is precisely about selecting whole weighted voters or whole set-votes, so fractional intervention changes the problem. That criticism is valid—but it identifies the intended boundary, not a failure of the mirror. The continuous programme asks whether that indivisibility is population multiplicity rather than substantive social-choice structure. For Theorem 87 this case is particularly strong: the supposedly hard weighted votes already share one complete type, and the continuous model simply turns their aggregate weight into mass. I would not anchor on Theorem 79’s Borda result, because its reduction has only two vulnerable votes; preserving their separate identities would require adding artificial constituency labels.

Thus the strongest positive verdict is: yes, emphatically, for Theorem 87, and independently yes for Theorem 80. Both continuous questions are recognizable versions of the paper’s underlying bribery problems, and both are expected to be tractable because the paper’s discrete hardness is carried by population multiplicity.

The case AGAINST (opponent, writing after the proponent)

The negative case is not strong enough to support the universal verdict. I can defeat the proposed reading of Theorem 87, but not Theorem 80.

Theorem 87 concerns atomic weighted ballots. Changing one ballot changes its entire weight \(w_i\); the Partition reduction depends on the indivisibility of that bloc. The proposed continuum instead permits transferring an arbitrary fraction of the mass of the common type \(p\succ a\succ b\succ c\). That is a fractional relaxation, not literally the weighted problem. Preserving the theorem would require variables constrained to \(0\) or \(w_i\), reinstating the discrete problem. Thus Theorem 87 is a weak anchor for a claim about the paper itself. If the weights are interpreted as populations of cloned unit voters, however, the relaxation becomes a perfectly sensible high-multiplicity question, so even here the objection is only about fidelity, not legitimacy.

Theorem 80 is harder to defeat. Its set-votes can naturally be reinterpreted as campaign segments: a fraction of a large segment shares the same top-\(k\) slate and has the same unit campaign price. Let \(x_{i,A}\) be the mass moved from vulnerable type \(i\) to an approval set \(A\). Then

\[ \sum_A x_{i,A}\le \mu_i,\qquad \sum_{i,A}x_{i,A}\le B, \]

and every candidate’s final \(k\)-approval score is linear in the \(x_{i,A}\). For fixed \(k\), there are only \(\binom{m}{k}\) output approval sets, so this is a polynomial-size LP in the explicit type support. It preserves the target, vulnerability restriction, prices, budget, and voting rule, while replacing indivisible set-vote selection by divisible campaign mass.

Calling the result “fractional set cover” does not refute it: that is precisely the computational consequence a population continuization is meant to expose. It also yields natural finite-population rounding and integrality-gap questions. The thesis does not already formulate this distribution-over-voter-types problem, and existing high-multiplicity work would support rather than collide with it.

So the strongest honest negative case is that Theorem 87 should not be sold as an exact mirror of weighted frugal bribery. But Theorem 80 survives the stronger objections: its continuous version is well-posed, population-based, computationally meaningful, and plausibly Class A. I therefore cannot honestly defend “no worthwhile continuous mirror in any scenario.”
