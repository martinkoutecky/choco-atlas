Why no mirror

Proposition 1 characterizes stability but does not assert a computational result, and the paper's IP formulations and computational comparisons are not numbered results. The proposed mass-cycle problem is coherent, but it cannot meet the required paper-specific computational anchor.

What the mirror covers

The proposed mirror covers maximum-cardinality stable exchange with bounded cycles; it leaves strong stability, NDD chains, and the trade-off between transplant count and blocking cycles aside.

Open questions for a prover

  • What is the complexity of finding a maximum stable cycle-mass assignment for fixed \(K\) and for variable \(K\)?
  • Can solutions in the mass model be rounded to discrete pools with controlled loss?

The case FOR (proponent)

The strongest honest positive case is a mirror of maximum-cardinality stable exchange, but the paper’s numbered results create a real anchor problem. It has no numbered theorem, lemma, corollary, or proposition asserting a complexity classification, and its integer-programming formulations and computational experiments are not numbered results. The introduction does report that bounded-length stable-exchange existence is NP-hard, but attributes that result to Biro (2010) and Huang (2010); it is not proved here.

The nearest named result is Proposition 1, stated in this paper and used in its formulations: an exchange \(M\) is stable if and only if, for every allowed cycle \(c\), some arc \((i,j)\) of \(c\) has a corresponding selected arc \((k,j)\) in \(M\) such that \(j\) weakly prefers \(k\) to \(i\). In other words, every proposed blocking cycle must be vetoed at some vertex by an incumbent donor at least as preferred as the cycle’s donor. This is a useful structural anchor for the mirror below, but it is not itself a complexity result or an IP formulation. Under a strict reading of the anchor requirement, there is no qualifying named computational anchor in this paper.

The lead candidate is Maximum Stable Cycle Mass, a continuous-population form of that underlying problem. An instance consists of a finite set \(\mathcal T\) of patient-donor-pair types, rational masses \(\mu_t>0\) summing to one, a directed compatibility relation between types, a strict ranking for each type over compatible donor types, and a maximum cycle length \(K\). A type includes everything the problem uses: medical characteristics, compatibility, and the type’s preference ranking. An allowed cycle \(W\) is a compatible cycle of length at most \(K\); a type may occur more than once in \(W\), with each occurrence representing a distinct pair. Choose a nonnegative rational mass \(x_W\) for each allowed cycle, subject to
\[ \sum_W q_t(W)x_W\leq \mu_t \qquad\text{for every }t\in\mathcal T, \]
where \(q_t(W)\) counts the occurrences of type \(t\) in \(W\). The objective is to maximize \(\sum_W |W|x_W\), the fraction of the population receiving transplants.

The output must be a maximum-mass allocation with no blocking cycle, or a report that no stable allocation exists. Precisely, a type-cycle blocks if some \(\varepsilon>0\) mass of distinct pairs can be taken at each of its positions so that each pair is unmatched or strictly prefers the cycle’s incoming donor type to its current donor type. Stability means no allowed cycle admits such a positive-mass block. This defines a problem over \(\tau=|\mathcal T|\), \(K\), and the binary input length \(L\), rather than over the total number of pairs.

A plausible regime is a large regional or national exchange pool whose pairs fall into a modest number of standardized medical and preference classes. For example, pairs might rank donor quality tiers based on shared clinical measures, rather than ranking each named donor differently. There, the number of pairs could greatly exceed the number of complete types. Each patient still receives one whole kidney; only the population and the allocation across types are expressed as masses. That is a credible high-multiplicity version of the paper’s bounded-cycle exchange problem, though the ranking-by-type assumption is a substantive modeling choice.

My provisional expectation is continuum-specific hardness (Class C), with low confidence. The paper’s cited discrete NP-hardness makes the question worthwhile, but it does not automatically transfer: continuous mass can split across cycles, even when each type has small mass. At the same time, the stability condition still imposes a choice of which participating type can veto each potential blocking cycle. A prover should investigate whether that structure permits a polynomial algorithm—especially for fixed \(K\)—before claiming hardness. A direct discrete embedding would need to address fractional splitting.

This mirror covers the paper’s maximum-cardinality stable-exchange problem for bounded cycles. It does not claim to cover strong stability with ties, NDD chains, or the near-stability trade-off. Those can be separate extensions if the lead question survives. Natural follow-ups include the exact complexity for fixed and variable \(K\), whether discrete-to-continuous rounding gives additive guarantees, and whether the same mass model supports strong stability and blocking-cycle trade-offs.

The weakest point is the type regime: the paper permits rankings over individual compatible vertices, whereas my scenario requires many pairs to share the same complete ranking over donor types. If real pools do not have that kind of repeated profile, the type count may approach the population size and the high-multiplicity motivation weakens. The mirror is strongest as a carefully stated regime for the authors’ problem, not as a claim that every kidney-exchange pool has that structure.

The case AGAINST (opponent, writing after the proponent)

Proposition 1 is an equivalence characterizing stability. It contains no complexity claim or algorithmic result. The paper’s NP-hardness statement is attributed to earlier work, while its own contribution is three IP formulations and computational comparisons. So the proponent’s named anchor does not meet the programme’s criterion for a paper-specific computational result. That is the strongest reason to deprioritize this paper as an anchored ChoCo case.

The proposed Maximum Stable Cycle Mass is nevertheless a coherent problem. Cycle masses can be bounded by type supplies, and a block can be defined by whether positive mass of eligible participants exists at each position. I cannot dismiss it as ill-posed. The stronger objection is that the paper gives little reason to expect the type compression that would make this a useful high-multiplicity mirror. Its instances are individual compatibility graphs with preferences generated over incoming arcs. A complete type would have to capture a pair’s compatibility relations and preference rankings; in those instances, that signature is likely to distinguish most vertices. Coarsening types where those features differ changes the exchange problem.

A better version would posit a pool with repeated patient–donor profiles and compatibility and rankings determined by those profiles. That would preserve complete types and admit a mass-cycle model. It is a legitimate regime, but it is an added assumption whose relevance to the paper’s instance model is not established. The paper reports pools of 20–400 pairs, random preferences, and no repeated-type analysis. Thus the paper supports neither a named computational anchor nor an evident small-support regime.

I can make a strong case against this paper as a priority target on those grounds. I cannot honestly defend the universal claim that no worthwhile mirror exists in any scenario: a sufficiently large pool with repeated, behaviorally identical clinical profiles would make the proposed continuous question sensible. The negative case is therefore weak against that best version of the mirror; its strongest conclusion is about the paper’s fit as an anchored ChoCo paper.
