The continuous mirror question

Given a population scale \(N\), rational type proportions \((\mu_t)_{t\in T}\) summing to \(1\), normalized Robertson–Webb valuation oracles \(v_t\), and \(K=|T|\leq \epsilon N-1\), compute a mass assignment of connected intervals on \([0,1]\). Each type \(t\) must receive total mass \(N\mu_t\); at almost every point \(z\), the total mass assigned intervals containing \(z\) must equal \(1\). For every type \(t\), every interval \(I\) assigned positive mass to \(t\), and every interval \(J\) assigned positive mass to any type, require \(v_t(I)\geq v_t(J)-\epsilon\). Empty intervals may receive mass.

The model it lives in

A finite set of complete valuation types with population masses \(N\mu_t\), sharing a fixed cake \([0,1]\). The decision variables are masses \(q\geq 0\) assigned by type to connected intervals; they must match each type's population mass, satisfy aggregate capacity \(1\) at almost every cake point, and meet the pairwise additive envy bound. This is a feasibility and computation problem, with Robertson–Webb access to valuations.

What the mirror covers

Covers the bounded-heterogeneity ε-EF algorithm of Theorem 3; leaves Theorems 1 and 2, which give general-instance approximation guarantees, untouched.

Open questions for a prover

  • Can the cutpoint construction and mass assignment be implemented with polynomially many Robertson–Webb queries and arithmetic operations in \(K\), \(N\), and \(1/\epsilon\)?

The case FOR (proponent)

My strongest case is a continuous mass version of Theorem 3, proved in this paper. The theorem says that if \(n\) agents have at most \(\epsilon n-1\) distinct valuation functions, then, with Robertson–Webb query access, one can compute in time polynomial in \(n\) and \(1/\epsilon\) a complete connected cake allocation that is \(\epsilon\)-additively envy-free. It is an algorithmic result, not a cited hardness result. The paper’s cited PPAD-hardness result is not a numbered result here and concerns exact envy-freeness under ordinal preferences, so I do not use it as an anchor.

Consider a large municipality dividing one linear tract of land into contiguous plots for \(N\) residents. Residents’ valuation functions over the tract come from a small set of \(K\) standardized profiles: for example, the same profile describes residents with the same priorities for access, frontage, and nearby amenities. Here a type is the complete valuation function used by the problem, and \(\mu_t\) is the fraction of residents with type \(t\). This is a regime where \(N\) can be very large while \(K\) remains small. The tract is scarce, so each resident’s bundle is a connected interval, and the question remains whether residents envy other residents’ bundles.

The continuous problem I would hand to a prover is Mass-Connected \(\epsilon\)-EF Cake Allocation. Its input is a population scale \(N\), rational type proportions \((\mu_t)_{t\in T}\) summing to \(1\), normalized valuation functions \(v_t\) for the \(K=|T|\) types, and \(\epsilon\in(0,1)\), with \(K\leq \epsilon N-1\). The mass of type \(t\) is \(N\mu_t\). A solution is a finite list of triples \((t,I,q)\): mass \(q\geq0\) of type \(t\) receives the connected interval \(I\subseteq[0,1]\). Empty intervals are allowed, as they are in the paper’s allocation model. The masses must sum to \(N\mu_t\) for each type, and the assigned intervals must use the tract exactly once in aggregate: for almost every point \(z\),
\[ \sum_{(t,I,q):\,z\in I} q=1. \]
Finally, for every type \(t\), every interval \(I\) assigned positive mass to type \(t\), and every interval \(J\) assigned positive mass to any type, require
\[ v_t(I)\geq v_t(J)-\epsilon. \]
Thus each unit of population mass gets a whole connected bundle; only the number of agents receiving each bundle is fractional. The question is whether this mass assignment can be computed efficiently from the type valuations and masses.

I expect this problem to be tractable, in Class A. Theorem 3’s cutpoint method gives a direct reason. Cut the tract at equal-value points for each distinct valuation, producing \(O(K/\epsilon)\) cells. Each cell is worth at most \(\epsilon\) to every type. The condition \(K\leq\epsilon N-1\) ensures there are fewer than \(N\) cells, so each cell can be assigned to one unit of population mass, distributing that mass across types as needed; the remaining mass gets empty intervals. Since every possible bundle is worth at most \(\epsilon\) to every type, no agent envies another by more than \(\epsilon\). This suggests a compact algorithm using \(O(K/\epsilon)\) cut queries and a small flow computation, with type masses represented as binary rationals. The paper’s finite-agent theorem nearly supplies this argument already; the mass-kernel version is still a distinct question because it permits fractional cohort sizes and bundle assignments directly.

This is a plausible mirror of the authors’ problem rather than a change to outcome-space continuity. It keeps the same cake, the same valuation functions, the same connected-bundle requirement, and the same pairwise additive envy criterion. What becomes continuous is the population count: a cohort of a given type can have fractional mass. The regime is specific—a large population with repeated valuation profiles—not a claim about every cake-cutting setting. The paper’s bounded-heterogeneity result is strong evidence that this regime makes sense for their problem.

My weakest point is that the additive guarantee permits empty bundles. As \(N\) grows with \(K\) fixed, most population mass may receive no land, while only a bounded number of unit masses receive the cells. That is faithful to Theorem 3’s guarantee, but it makes the mirror a weak fairness result and may limit its practical appeal. Also, the paper proves the finite-agent theorem, not this fractional-mass formulation; the continuous version is a reasoned extension, not a result already established by the authors. I would mirror Theorem 3 alone and would not stretch this case to the paper’s main Theorems 1 and 2.

The case AGAINST (opponent, writing after the proponent)

The strongest objection is a scale problem in the proposed mirror. With \(K\) valuation types and fixed \(\epsilon\), Theorem 3’s cutpoint construction uses only \(O(K/\epsilon)\) cells, independent of \(N\). In the proposed model, each cell consumes one unit of population mass. So as \(N\) grows with \(K\) fixed, only \(O(K/\epsilon)\) mass gets cake; the rest gets empty intervals. The envy guarantee still holds because every cell is worth at most \(\epsilon\) to every type. This is a genuine degeneration of the fixed-cake, normalized-valuation limit: almost the whole population receives nothing, and the bound certifies that those agents envy no bundle by more than \(\epsilon\).

Requiring positive-value pieces would address that degeneracy, but the paper says even that requirement under bounded heterogeneity is as hard as the general problem. Scaling the cake supply with \(N\) is a better alternative, but it changes the normalization and the approximation scale: the paper’s fixed-\(\epsilon\) theorem does not establish a result for that model. This is a real weakness in the specific mirror, though it does not rule out a worthwhile per-capita version.

I cannot honestly make the universal negative case. Theorem 3 is a named computational result, and its bounded-heterogeneity regime gives a plausible repeated-type population. A mass version is well-posed and has a direct cutpoint algorithm. The strongest case against it is that its most straightforward limit may be a poor fairness object; that does not defeat the broader continuous mirror.
