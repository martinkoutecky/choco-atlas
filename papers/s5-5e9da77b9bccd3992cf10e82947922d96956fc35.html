The continuous mirror question

Given a society described by \(\tau\) types with positive binary-rational masses \(\mu_t\) summing to \(1\), where each type ranks its acceptable partner types and the type-level profile is acyclic, construct symmetric marks \(w_{tu}=w_{ut}\) for acceptable pairs of distinct types such that \(u\succ_t v\) if and only if \(w_{tu}<w_{tv}\); assign \(+\infty\) to unacceptable pairs.

The model it lives in

The types are service classes whose members make partner choices at the class level; \(\mu_t\) is each class's population share. The decision variables are integer marks \(w_{tu}\) for acceptable distinct type pairs, with symmetric values and inequalities realizing each type's ranking. There is no optimization objective.

What the mirror covers

Covers Lemma 3's symmetric-mark construction for type-level preferences, with Theorem 1's acyclic characterization as structural context; leaves stable \(b\)-matching behavior, convergence, and graph-property results aside.

The case FOR (proponent)

The strongest honest mirror I see is Acyclic Type-Mass Symmetric Realization, anchored only to Lemma 3, proved in this paper. It says that for a preference instance \(L\) on \(n\) peers, the paper’s algorithm constructs, in \(O(n^2)\) time, a symmetric mark matrix that induces \(L\). Its proof uses Lemma 2’s loving-pair property; the paper says the formal proof of that property appeared in earlier work. The structural result behind the construction is Theorem 1, also proved here: the acyclic preference instances are exactly the symmetric ones, and they strictly include the global preference instances. Lemma 3 is the computational anchor; Theorem 1 explains why its output matters.

Here is the continuous problem. An instance is a distribution \(\mu\) over \(\tau\) peer types, with positive binary-rational masses summing to one. Each type \(t\) describes peers with the same acceptable partner types \(N(t)\) and the same strict ranking \(\succ_t\) of those types. For this mirror, links are allowed only between distinct types, and the type-level preference profile is promised acyclic: there is no cycle of at least three types in which each type prefers its successor to its predecessor. The question is to construct symmetric marks \(w_{tu}=w_{ut}\) for acceptable pairs such that
\[ u\succ_t v \quad\Longleftrightarrow\quad w_{tu}<w_{tv}. \]
Unacceptable pairs receive mark \(+\infty\). A solution is the mark table; this is a feasibility and construction problem, with no optimization objective in the paper’s anchor.

The regime I would defend is a large P2P network whose users fall into a modest number of genuine service classes—for example, classes defined by network region and resource role—with many users in each class. Every user in a class accepts and ranks the same partner classes, perhaps because connection choice is made at the class level. Then \(\mu_t\) is the fraction of users in class \(t\), the number of peers can be very large relative to \(\tau\), and the mark table describes symmetric compatibility between classes. A rational distribution can also be realized exactly by a finite high-multiplicity population after scaling by a common denominator.

This is a narrow but concrete Class A question. Applying the loving-pair construction to the \(\tau\) types gives a table in \(O(\tau^2)\) operations, with marks of polynomial bit length; reading the rational masses adds their input cost. The continuous version does not resolve a hardness result—the paper provides no named hardness anchor to support that story. Instead, it asks whether the paper’s constructive characterization remains useful when the input describes cohort proportions rather than named peers. I would expect the authors to recognize it as their problem only under the stated class-level semantics.

The weakest point is that \(\mu\) does not affect whether a realization exists, and ranking partner types suppresses the paper’s strict rankings among individual peers. If latency differences between particular users matter, grouping them this way loses information; restoring those differences may require many more types. So I would not present this as a mirror of the paper’s full stable \(b\)-matching or dynamics questions. It covers the constructive symmetric-mark representation result in a plausible high-multiplicity regime. Further questions are whether such marks preserve useful properties of stable configurations in a mass-flow model, and how to handle within-class links or individual-level tie breaking without erasing the type compression.

The case AGAINST (opponent, writing after the proponent)

Lemma 3 is the one real computational anchor: given an acyclic preference profile on a finite set of peers, it constructs symmetric marks on peer pairs in \(O(n^2)\) time. The difficulty is that the proposed mirror changes what a vertex is. In the paper, a peer ranks particular neighboring peers; in the mirror, a type ranks other types. A mark \(w_{tu}\) gives the same value to every pair between those classes, so it does not encode the strict, peer-by-peer rankings that Lemma 3 represents. Acyclicity of the class profile therefore establishes representability of a quotient system, not of the underlying P2P preference system.

The strongest repair is to define preferences at the class level and treat within-class choices as irrelevant or break those ties by an added rule. That can be a coherent model for some protocols, but Lemma 3 then applies to the \(\tau\) classes as the vertices. The mass \(\mu\) affects neither whether marks exist nor which rankings they realize; the question is the same finite construction on the support. If instead peer identities and their strict rankings must be preserved, the type-level input does not contain enough information to reconstruct them. Adding a structured tie-breaking rule might restore a compact representation, but that structure is an extra assumption, not a consequence of the paper’s theorem.

Making masses matter by adding per-capita quotas, mass flows, or stability conditions could produce a more consequential continuous problem. But that would be a new mass-matching problem: Lemma 3 neither constructs its stable configuration nor establishes an algorithm for it. So the proposed mirror is either a finite representation lemma with population proportions attached, or a broader model whose computational question is no longer anchored by this result.

This is a strong objection to the *worth* of this particular mirror, not a proof that no class-level P2P model could interest the authors. The service-class scenario is plausible, and its type-level mark construction is well-posed. The negative case is weakest precisely there: an author could value that quotient representation as a useful high-multiplicity preprocessing result, even though the lemma itself gives no mass-dependent computational content.
