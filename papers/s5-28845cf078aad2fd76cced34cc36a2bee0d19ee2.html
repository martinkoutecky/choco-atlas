The continuous mirror question

Input a finite catalogue of \(m\) goods, rational type masses \(\mu_t\), rational per-capita supplies \(q_j\), and additive type values \(v_{tj}\), with a common goods order. For each type define \(\sigma_t\) as the supremum of \(z\) such that a finite-support distribution \(y_{t,b}\) over integral bundles \(b\in\mathbb{Z}_{\ge0}^m\) satisfies \(\sum_b y_{t,b}=1\), \(\sum_b y_{t,b}b_j=q_j\) for every good \(j\), and \(y_{t,b}>0\) only when \(v_t\cdot b\)\ge z\). For every fixed \(\varepsilon>0\), can one compute a finite-support assignment \(x_{t,b}\) with \(\sum_b x_{t,b}=\mu_t\), \(\sum_{t,b}x_{t,b}b_j=q_j\), and \(x_{t,b}>0\) only when \(v_t\cdot b\)\ge(10/13-\varepsilon)\sigma_t\), in time polynomial in \(m,\tau,L\) for that fixed \(\varepsilon\)?

The model it lives in

A continuous population has type masses \(\mu_t\) and per-capita supplies \(q_j\). Each person receives an integral bundle \(b\) of goods; \(x_{t,b}\) assigns type mass to bundles, and \(\sigma_t\) is type \(t\)'s maximin benchmark over distributions of integral bundles averaging to the full per-capita supply.

What the mirror covers

The mirror targets Theorem 12.1's approximation guarantee and allocation problem. It leaves the paper's individual reduction and bag-filling lemmas outside the mirror, and does not claim that the explicit-instance runtime transfers to compressed inputs.

Open questions for a prover

  • Can the distributional MMS values \(\sigma_t\) and a feasible type-to-bundle mass assignment be computed in time polynomial in \(m,\tau,L\) for each fixed \(\varepsilon\)?
  • Can one give a formal approximation-preserving dictionary between finite replications with \(N\mu_t\) agents and \(Nq_j\) copies and the distributional benchmark \(\sigma_t\)?

The case FOR (proponent)

The strongest mirror is the paper’s approximate MMS allocation problem in a high multiplicity market for standardized indivisible goods. Imagine a large population served from a catalogue of goods available in many interchangeable copies. Agents fall into a small number \(\tau\) of valuation types: everyone of type \(t\) has the same additive value vector \(v_t\). The mass \(\mu_t\) is the fraction of the population with that vector. If the supply of good class \(j\) is \(q_j\) per unit population, then a population of \(N\) agents has \(Nq_j\) copies of that class. The regime of interest has \(N\) much larger than \(\tau\). The paper’s common-order reduction makes the restriction that all types rank goods in the same order especially plausible.

Here is the continuous problem I would hand to a prover. The input is a finite catalogue \(G=\{1,\ldots,m\}\), rational type masses \(\mu_t\) summing to \(1\), rational additive values \(v_{tj}\), and rational per-capita supplies \(q_j\). A bundle is an integral vector \(b\in\mathbb Z_{\ge0}^m\), with type-\(t\) value \(v_t\cdot b\). Define \(\sigma_t\), the continuous MMS benchmark for type \(t\), as the supremum of \(z\) for which there is a finite-support distribution \(y_b\ge0\) over integral bundles satisfying \(\sum_b y_b=1\), \(\sum_b y_b b_j=q_j\) for every good class \(j\), and \(y_b>0\) only for bundles with \(v_t\cdot b\ge z\). The question is: for each fixed \(\varepsilon>0\), can we compute a finite-support mass assignment \(x_{t,b}\ge0\), with \(\sum_b x_{t,b}=\mu_t\) and \(\sum_{t,b}x_{t,b}b_j=q_j\), such that every bundle receiving positive mass for type \(t\) has value at least \((10/13-\varepsilon)\sigma_t\)? The decision variable assigns mass to agent types and integral bundles; it never gives a fraction of a good to an individual agent. The computational target would be time polynomial in \(m,\tau,L\), and \(1/\varepsilon\), where \(L\) is the input bit length.

The numbered computational anchor is Theorem 12.1, proved in this paper: for every constant \(\varepsilon>0\), there is a polynomial-time algorithm that, on an explicit finite instance with additive valuations, returns an allocation giving every agent at least a \((10/13-\varepsilon)\) fraction of their own MMS. Its proof uses a PTAS cited from Woeginger to approximate exact MMS, which the paper says is NP-hard to compute. Theorem 12.1 is an algorithmic anchor; the excerpt supplies no numbered hardness theorem for the allocation problem itself, so I would not present exact-MMS hardness as one.

The mirror preserves the paper’s substantive question: each person receives an indivisible bundle, and the guarantee is measured against that type’s maximin share of the whole supply. Only the representation of the population and inventory changes: agent counts and copy counts become masses and per-capita supplies. The paper’s reductions and bag-filling analysis may give useful structure for a pricing or column-generation approach. I would provisionally expect Class A for this fixed-catalog, finite-type mirror: mass assignments are linear once the relevant bundle patterns and MMS thresholds are known. The difficult part—and a natural further question—is whether those patterns and thresholds can be found efficiently with exponentially many possible integral bundles.

My weakest point is the supply model. The paper studies a finite set of distinct goods, whereas this mirror needs the inventory to grow with the population as interchangeable copies of a finite catalogue. That is a credible regime for standardized goods, but it is a real restriction. Also, Theorem 12.1’s polynomial runtime is for the explicitly listed finite instance; it does not establish polynomial time in the compressed continuous input. The proposed mirror covers that theorem’s approximation guarantee and underlying allocation problem, not every technical lemma in the paper.

The case AGAINST (opponent, writing after the proponent)

The best objection is that the proposed mirror keeps the paper’s hardest structure intact. Each person still receives an integral bundle, and each type’s MMS still comes from partitioning the full supply into integral bundles. The mass variables only mix which bundles are assigned to a type; they do not make the bundle choices or MMS computation continuous. Also, Theorem 12.1 gives polynomial time for an explicitly listed finite instance, not for the compressed input \((m,\tau,L)\): expanding rational masses and per-capita supplies to a common denominator \(N\) can make the finite instance much larger than its encoding.

That objection does not defeat the stronger mirror. A population with repeated, identical valuation types and a catalogue whose supplies scale with population is coherent; type-level mass can be divided among integral bundles without giving any individual fractional goods. The finite theorem transfers an approximation guarantee after scaling, while its runtime does not automatically transfer. Whether the guarantee can be computed efficiently on the compressed input is therefore a real computational question. Work on high-multiplicity fair allocation and MMS guarantees for a few agent types also makes this regime more credible, not less ([high-multiplicity fair allocation](https://www.sciencedirect.com/science/article/pii/S0004370222001606), [MMS allocations for few agent types](https://www.ijcai.org/proceedings/2025/452)).

So I cannot make a sound case that this anchor fails in every plausible scenario. There is no identity dependence or continuum degeneration here, and the paper does state a numbered computational result in Theorem 12.1. My negative case is weak: the mirror’s algorithmic benefit is unproved, but that gap is the research question, not a reason to reject it.
