The continuous mirror question

Given rational masses \(\mu\) on \(\tau\) interchangeable types and a bounded stochastic oracle that returns an independent reward sample for each queried coalition mass \(z\in\prod_t[0,\mu_t]\), with \(F(0)=0\), known \(F(\mu)\), and feasible mass-scale strong supermodularity \(F(z+he_i+ke_j)-F(z+he_i)-F(z+ke_j)+F(z)\ge\kappa hk\), can an adaptive algorithm return, with probability at least \(1-\delta\), a type-symmetric allocation \(b\) satisfying \(\sum_t b_t=F(\mu)\) and \(\sum_t q_tb_t\ge F(\mu\odot q)\) for every \(q\in[0,1]^\tau\), using polynomially many samples and polynomial computation in \(\tau\), the input bit length, \(\kappa^{-1}\), and \(\log(\delta^{-1})\)?

The model it lives in

An anonymous stochastic cooperative game with type masses \(\mu_t\), coalition-value function \(F(z)\), and an oracle for noisy rewards at coalition mass vectors \(z\). The decision variable \(b_t\) is the total allocation to type \(t\); stability requires every fractional coalition \(q\in[0,1]^\tau\) to receive at least its expected value \(F(\mu\odot q)\).

The objection that survived

For normalized smooth rewards on \(M\) interchangeable agents, the discrete strict-convexity margin can scale as \(M^{-2}\), making Theorem 18's \(\varsigma^{-4}\) bound scale as \(M^8\); a mass-scale \(\kappa\) guarantee needs a new proof. The proponent already acknowledges that neither replacing \(n\) by \(\tau\) nor using type-block marginals establishes the claim.

The case FOR (proponent)

This paper has no named NP-hardness, P, FPT, or W[1]-hardness theorem. Its named complexity results are about oracle samples needed to learn a solution, with polynomial-time computation noted for the algorithm. I’m treating those as anchors for the paper’s own learning problem; they are not standard worst-case complexity classifications.

A plausible regime is a large research-computing consortium: many labs pool resources, and labs with the same workload, usage rights, and cost profile are interchangeable. Let there be \(M\) labs but only \(\tau\) such types, with \(M\gg\tau\). Write \(\mu_t\) for type \(t\)’s share of the consortium. A coalition is described by \(z_t\in[0,\mu_t]\), the mass of each type that joins. Its unknown stochastic reward has mean \(F(z)\), and a query returns one independent reward sample. Assume \(F(0)=0\), rewards are bounded, and the grand-coalition mean \(F(\mu)\) is known, as in the paper.

A type-symmetric allocation gives every member of type \(t\) the same rate \(a_t\). Equivalently, let \(b_t=\mu_t a_t\) be the total allocation to that type’s full cohort. If \(q_t=z_t/\mu_t\) is the fraction of type \(t\) that joins, the continuum expected core is

\[ \mathcal C(F)=\left\{b\in\mathbb R^\tau: \sum_t b_t=F(\mu),\quad \sum_t q_tb_t\ge F(\mu\odot q)\ \text{for every }q\in[0,1]^\tau \right\}. \]

Thus mass is the fraction of each cohort participating; the decision variable is the type-level allocation \(b\); and stability must hold for every fractional coalition, not only whole type groups. In the finite version, a coalition with \(q_t\) equal to a multiple of \(1/M_t\) is an ordinary subset of the \(M_t\) members of that type. This is a high-multiplicity regime, not a claim that every cooperative game has one.

My lead anchor is Theorem 7, proved in this paper. It says that if the expected core has dimension \(k<n-1\), then for every \(0<\delta<0.2\), no algorithm using finitely many samples can output a point in the expected core with probability at least \(1-\delta\). The proof constructs games with arbitrarily small statistical distance but disjoint cores, using face games; the face-game idea is cited from [14], while this impossibility result is proved here. The theorem is a sample-identification impossibility, not an NP-hardness result.

Its continuous mirror is the following low-dimensional continuum core learning problem: given \(\mu\), a bounded-reward oracle indexed by all \(z\in\prod_t[0,\mu_t]\), and the promise that \(F\) is a convex anonymous game whose type-symmetric core has dimension \(k<\tau-1\), can an adaptive learner use finitely many samples and return \(b\in\mathcal C(F)\) with probability at least \(1-\delta\), uniformly over the promised instances? I expect the answer to be no without further assumptions on the reward family. A low-dimensional core can leave no interior slack to absorb estimation error, while distinct expected rewards can remain statistically hard to distinguish. This is the most direct negative boundary the paper offers for a population mirror. It is a continuum query-hardness question by analogy with Class C, though the underlying obstruction is statistical rather than a discrete reduction.

The complementary tractability anchor is Theorem 18, also proved here. Under Assumption 4’s \(\varsigma\)-strict convexity, using the permutation collection from Proposition 17—one order and its \(n-1\) adjacent-swap neighbors—the paper proves that Common-Points-Picking returns an expected-core point with probability at least \(1-\delta\) after

\[ T=O\!\left(\frac{n^{15}\log(n\delta^{-1}\varsigma^{-1})}{\varsigma^4}\right) \]

samples. The paper also explains that its computational subroutines run in polynomial time.

The corresponding strictly convex continuum core learning problem has the same oracle and core definition, but promises a full-dimensional core and a positive increasing-marginal margin. One concrete version of that promise is that, for every feasible \(z\), types \(i,j\) (including \(i=j\)), and feasible \(h,k>0\),

\[ F(z+he_i+ke_j)-F(z+he_i)-F(z+ke_j)+F(z)\ge \kappa hk. \]

Can a learner return an exactly stable \(b\) with probability at least \(1-\delta\), in time and samples polynomial in \(\tau\), the bit length of \(\mu\) and \(\kappa\), and \(\log(\delta^{-1})\), with no dependence on \(M\)? This is my Class A expectation. The natural candidate objects are type-block marginal allocations: for an order of the \(\tau\) types, query the rewards at the successive prefix mass vectors and assign each type its marginal increase. A base order and adjacent type swaps give a polynomial-size family of such allocations, paralleling the paper’s vertex construction. A common-point procedure could then handle their sampling uncertainty. This is a substantive prover question: the paper does not establish that these block marginals support every fractional coalition or that its geometric argument survives this reduction.

The two questions are deliberately separate. The low-dimensional case asks whether exact learning fails at a degenerate core; the strictly convex case asks whether positive interior width makes robust learning possible with complexity governed by type support rather than headcount. They cover the paper’s expected-core, bandit-feedback, and convex-game results, not its discussion of Shapley approximation or robust and Bayesian cores. Reward uncertainty remains part of the oracle model; the object being continuized is the population.

My weakest point is that the paper’s players are individually indexed, while the mirror assumes anonymity within types and asks for a type-symmetric allocation. That is a reasonable high-multiplicity specialization, but it is a real modeling choice. Also, polynomial dependence on \(\tau\) does not follow just by replacing \(n\) with \(\tau\): fractional coalitions add infinitely many constraints, and the transfer from discrete marginal vectors to type-block marginals must be proved. The anchors nevertheless make a credible case: Theorem 7 identifies a precise failure mode for exact learning, while Theorem 18 gives a concrete route to ask whether strict convexity and a small type support yield an efficient population-scale algorithm.

The case AGAINST (opponent, writing after the proponent)

The strongest case against begins with what the paper actually measures. Theorem 7 gives an impossibility result for learning from stochastic samples; Theorem 18 bounds the number of samples for a learning algorithm. The paper notes that its geometric subroutines run in polynomial time, but gives no named result about the running time of an algorithm on an encoded game. ChoCo’s central targets are complexity and algorithms for problems specified by an instance. A mirror here needs a representation of the unknown reward function and an oracle model, so its main question becomes statistical query complexity. That is a genuine change of focus, though it may still be worthwhile under ChoCo’s broader interest in computational questions.

Theorem 7’s proof perturbs the reward of a particular coalition and uses face games to create nearby instances with disjoint cores. In a generic cooperative game, an agent’s type must capture their contribution in every coalition context; that can give nearly every agent a distinct type, leaving no compression. A small support requires an extra exchangeability assumption: coalition rewards must depend on participation by type, not on which same-type individuals participate. Under that assumption, the paper’s coalition-specific perturbations need not remain valid. A better mirror would study low-dimensional cores for anonymous continuous reward functions, but that requires specifying the function class and oracle. It would be a new statistical learning problem, not a direct transfer of Theorem 7.

Theorem 18 offers the stronger algorithmic anchor, but its guarantee does not directly yield a population-size-independent bound. Its strict-convexity margin \(\varsigma\) measures changes in individual players’ marginal contributions. For \(M\) interchangeable agents with a smooth, bounded reward \(F\) of normalized mass, those discrete second differences typically scale as \(M^{-2}\). Substituting that scale into the theorem’s \(\varsigma^{-4}\) dependence introduces a factor of order \(M^8\). The proposed continuous model can instead assume curvature in mass units, but then the sample bound needs a new proof. The geometric argument also uses marginal vectors from permutations of finitely many players; block marginals over types do not by themselves certify stability against every fractional coalition. A piecewise-linear extension from a finite type game could restore finite geometry, while a richer smooth model would need other tools.

These objections weaken both anchors as direct support for a ChoCo-style complexity result. They do not defeat the best population scenario: a large consortium of genuinely interchangeable labs with type-level coalition rewards is plausible, and learning a stable allocation from noisy coalition queries could be a worthwhile question. I therefore cannot honestly defend the universal claim that no scenario offers a worthwhile mirror. The negative case is strongest against calling these theorems ready-made continuization results; it is weak against the existence of a new, sensible mirror.
