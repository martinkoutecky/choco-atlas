The continuous mirror question

Given types \(T\) with masses \(\mu_t\ge 0\) summing to \(1\), housing categories \(H\) with rational per-capita supplies \(q_h\), and a strict preference list of at most two acceptable categories per type plus an outside option, allocate each unit of mass one indivisible dwelling or the outside option. Represent allocations by flows \(x_{th}\ge 0\), with \(\sum_h x_{th}\le \mu_t\) and \(\sum_t x_{th}\le q_h\). Call an allocation Pareto optimal if no positive submass can be reassigned feasibly so that every member of that submass strictly improves while all other assignments stay fixed. Compute the number of distinct exact supports \(S=\{h\in H:\sum_t x_{th}>0\}\) attained by Pareto-optimal allocations.

The model it lives in

A nonatomic, capacity-constrained house-allocation problem: types carry mass \(\mu_t\), categories have per-capita supplies \(q_h\), individuals receive whole dwellings, and aggregate flows \(x_{th}\) describe assignments. Count the exact category supports attained by allocations with no positive-mass Pareto-improving coalition.

The objection that survived

The positive-mass blocking rule omits finite applicant exchanges, so its efficient allocations need not correspond to discrete POMs; the proponent defines this continuous rule but does not establish a discrete-to-continuous correspondence.

fatal: False

What the mirror covers

The mirror covers Theorem 12's counting of exactly reachable sets, using its two-column case. It leaves the reachable-element bounds, avoidability algorithms, other reachability complexity results, and multi-matching results untouched.

Open questions for a prover

  • What is the complexity of exactly counting these supports in \(|T|\), \(|H|\), and the input bit length?
  • Does the restriction to at most two acceptable categories per type already yield \(\#\mathrm P\)-hardness?

The case FOR (proponent)

The strongest mirror I see is an exact-support counting problem for a large housing market. In a recurring placement program, many applicants can share the same ranking over a finite set of housing categories—say, location and dwelling types—and each category has a supply that scales with the population. A type is a complete applicant preference ranking; its mass is the fraction of applicants with that ranking. The number of applicants is large relative to the number of types, though the number of types and housing categories can grow with the input.

Keep each person’s assignment indivisible: everyone gets one whole dwelling or an outside option. The continuous object is the population and the category supplies. A flow \(x_{th}\) records the mass of type \(t\) assigned to category \(h\); its fractional entries describe different members of a large cohort receiving different whole dwellings.

My anchor is Theorem 12, proved in this paper by reduction from \(\#\)Independent Set. It states that Problem 4, counting exactly reachable sets, is \(\#\)P-complete already for two-column matrices. The paper also says the hardness extends to every \(k\)-column matrix with \(k\geq 2\), by adding columns containing single new elements. In the underlying problem, an exactly reachable set is the precise set of houses used by some Pareto-optimal matching.

Here is the continuous question I would hand to a prover:

Continuous Exact Reachability Counting. The input is a finite set \(T\) of applicant types, a finite set \(H\) of housing categories, binary-rational type masses \(\mu_t\geq 0\) summing to \(1\), binary-rational per-capita supplies \(q_h\), and a strict ranking of the categories for each type. Each type has at most two acceptable categories, as in the two-column restriction, with the outside option available if needed. A feasible allocation assigns every applicant either one whole dwelling or the outside option, respects each category’s supply, and is represented in aggregate by its type-to-category flows. A positive-mass coalition blocks an allocation if its members can be reassigned feasibly, with everyone in the coalition receiving a strictly preferred category and everyone outside it unchanged. The question is: how many subsets \(S\subseteq H\) occur exactly as the set of categories receiving positive mass in at least one allocation with no blocking coalition? A solution is the exact integer count. Call this problem *Continuous Exact Reachability Counting*.

I would expect Class B, hardness transferring, as a working hypothesis: the reduction’s combinatorics concern which named houses can be jointly occupied under preference constraints, rather than the number of applicants. That makes the question a plausible place to test whether those constraints still force hard support choices when each applicant type contains a large cohort. It is a hypothesis for the prover, not a result of the paper.

The main weakness is that cohorts can split their mass across categories. The discrete reduction relies on one-row, one-house conflicts; fractional flows may erase some of those conflicts and change the family of reachable supports. Also, the mirror counts supports of *categories*, whereas the paper counts sets of individual houses. I think authors working on house allocation would recognize the question as a continuous high-multiplicity variant of their reachability problem, but whether it preserves the reduction is precisely what needs investigation.

The scope is deliberately narrow: it mirrors the paper’s exact-reachability counting result, not its bounds on reachable elements, its avoidability algorithms, or its multi-matching generalization. It also raises natural follow-ups: decide whether a designated category set can occur in a support; count supports containing a designated set; and require each occupied category to receive at least a specified positive mass, rather than merely nonzero mass.

The case AGAINST (opponent, writing after the proponent)

The single anchor is real: Theorem 12 proves \(\#\)P-completeness for counting exactly reachable sets, even with two-column matrices. So the case against cannot rely on there being no computational result to mirror, or on high-multiplicity housing being implausible. A large placement program with recurring preference cohorts is a sensible setting.

The difficulty is what the theorem counts. Its “houses” are individually named, unit-capacity objects, and a matching is injective. In the reduction, edge and vertex elements are distinct resources; which ones are selected encodes an independent set. The proposed category model changes that object. If a category has positive per-capita supply, many applicants can receive it. Counting which categories get any positive mass no longer counts the sets of distinct houses used by an injective matching. That may be a worthwhile capacitated allocation problem, but it is not a direct continuization of Theorem 12’s support count.

Keeping the houses individually named creates the opposite problem. If the population is replicated \(N\)-fold while the finite set of houses is fixed, the assigned fraction of the population tends to zero. If houses are replicated too, then either the clones remain separate zero-mass outcomes, or they are grouped into categories and the counted supports change. In particular, one applicant using one house has mass \(1/N\): it registers as positive support at every finite \(N\), but disappears in the limit. Exact support is therefore not a stable population-level observable for individual houses. A positive threshold could remove that sensitivity, but it would define a different counting question.

There is also a mismatch in the blocking condition. A finite coalition can block a discrete POM, including by a swap, even though its size is negligible in a large population. The proposed definition counts only positive-mass coalitions, so those deviations do not register in the aggregate flows. One can add conditions that track finite exchanges, but then the continuous problem has extra pointwise structure beyond the stated positive-mass blocking model.

That is the strongest objection I see: the best natural repair is a capacitated, category-level Pareto allocation problem, while preserving the paper’s named-house supports leaves the population limit with vanishing-mass outcomes. It is a substantive gap in the claimed mirror, but not a decisive case that no worthwhile mirror exists. The category-level problem remains coherent, and matching theorists might well recognize it as a natural extension of their subject. I would call the negative case weak on the universal claim.
