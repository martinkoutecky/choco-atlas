The continuous mirror question

Given a finite support \(T\) of complete piecewise-constant valuation types, a rational mass vector \(\mu\in\Delta(T)\), and normalized per-capita cake supply, define the weighted-quantile and middle-piece recursion of Algorithm 3 together with a report-indexed allocation kernel and deterministic implementations on sufficiently large \(q\)-replicas; compute the allocation and the smallest uniform \(\epsilon\) such that every present type receives value at least \(1/n\) and no single representative gains more than \(\epsilon\) by misreporting.

The model it lives in

A finite-type anonymous high-multiplicity cake-cutting model: \(T\) and \(\mu\) specify type masses, \(\beta_t^\mu(x)\) specifies per-agent allocation, and a report-indexed kernel specifies a representative's bundle; the objective is to compute the recursive allocation and minimize uniform \(\epsilon\) subject to proportionality and deterministic \(q\)-replica implementability.

The objection that survived

The proponent's \beta_t^\mu-only formulation does not encode a unilateral report of zero mass, so a report-indexed individual allocation kernel and a precise deterministic \(q\)-replica convergence convention are still needed.

fatal: False

What the mirror covers

The mirror covers the modified Even–Paz proportionality and approximate-strategyproofness guarantee in Theorem 8. It leaves the non-wasteful and contiguous-allocation impossibilities, as well as the Robertson–Webb connection in Proposition 6, outside the primary mirror.

Open questions for a prover

  • Can weighted cutpoint quantiles and middle-piece recursion be implemented by deterministic finite \(q\)-replica allocations with explicit convergence rates?
  • What report-indexed kernel gives nonvacuous unilateral strategyproofness when one representative has zero mass?
  • Can the allocation and worst-case \(\epsilon\) be computed in time polynomial in \(|T|\), the number of breakpoints, and the encoding length?

The case FOR (proponent)

The strongest honest case is a population-level mechanism-design mirror, not a complexity-class mirror. This paper contains no named theorem asserting NP-hardness, membership in \(P\), W[1]-hardness, or FPT. Its named results are impossibility theorems, query bounds, and mechanism guarantees. I would therefore not claim that it supplies a direct ChoCo hardness anchor. It does, however, give a very plausible continuous-population question.

Take \(q\) copies of each public agent role, with \(q\to\infty\), and scale the cake supply linearly with \(q\). Copies of a role have exactly the same piecewise-constant valuation function and all other relevant parameters. Thus the population has \(qn\) agents but only \(\tau\ll qn\) valuation types. The scaling keeps proportional entitlement nontrivial: each agent still deserves \(1/n\) of their normalized total value.

Let \(\mu\in\Delta(T)\) be the type distribution. A mass allocation can be represented by measurable functions \(\beta_t(x)\), where \(\beta_t\) is the rescaled average amount of cake position \(x\) assigned to a type-\(t\) agent. Feasibility is \( \sum_t n\mu_t\beta_t(x)\le 1 \) almost everywhere, and type \(t\)'s per-agent utility is \( U_t=\int_0^1v_t(x)\beta_t(x)\,dx \). Equality expresses non-wastefulness wherever some present type values the cake.

The lead anchor is Theorem 1, proved in this paper:

“For any \(n\ge2\) and \(0\le\epsilon_1,\epsilon_2<1/n\) such that \(3\epsilon_1+\epsilon_2<1/n\), there is no deterministic and non-wasteful mechanism for \(n\) agents with piecewise constant valuations that is \(\epsilon_1\)-strategyproof and \(\epsilon_2\)-proportional.”

The corresponding continuous problem is:

“Continuum Piecewise-Constant Cake Mechanism Existence.” Given \(n\), a finite type set \(T\) of piecewise-constant valuation densities, and \(\epsilon_1,\epsilon_2\), decide whether there is a deterministic mass mechanism \(M\) which, for every reported distribution \(\mu\), supplies a feasible allocation menu \(\{\beta^\mu_r:r\in T\}\) satisfying:

\( \int v_t(x)\beta^\mu_t(x)\,dx\ge 1/n-\epsilon_2 \) for every present type \(t\);

\( \int v_t(x)\beta^\mu_t(x)\,dx\ge \int v_t(x)\beta^\mu_r(x)\,dx-\epsilon_1 \) for every true type \(t\) and possible report \(r\);

and \( \sum_t n\mu_t\beta^\mu_t(x)=1 \) wherever some present type values \(x\).

A solution is an explicit measurable mechanism \(M\), or a proof that none exists. Equivalently, one can ask for the minimum achievable manipulation tolerance \(\epsilon_1\) subject to non-wastefulness and \(\epsilon_2\)-proportionality.

This is recognisably the paper’s problem: the private object is still a valuation function, the mechanism is still direct revelation, and the requirements are exactly strategyproofness, proportionality, and non-wastefulness. Only the society has changed from named agents to a high-multiplicity distribution. The proof of Theorem 1 is especially promising for transfer: it uses a small collection of piecewise-constant valuation profiles and inequalities about allocated lengths, so its combinatorics do not depend on having many idiosyncratic agents. My expectation is that the impossibility transfers to the mass model, at least when the mass allocation is required to be implementable by deterministic allocations among large finite replicas.

The main further question is whether fractional splitting among identical agents creates an escape. If it does not, the theorem becomes a clean population-limit impossibility. If it does, that would be a genuinely continuum-specific phenomenon: the discrete impossibility would dissolve because the continuum permits type-level fractional assignments.

A second, weaker anchor is Theorem 8, also proved here:

“Algorithm 3 is deterministic, proportional, and \(\epsilon\)-strategyproof, where \( \epsilon=1-\frac{3}{2n} \) when \(n\) is even, and \( \epsilon=1-\frac{3}{2n}+\frac{1}{2n^2} \) when \(n\) is odd.”

Algorithm 3 is the modified Even–Paz procedure: it recursively separates agents by their reported cutpoints and proportionally allocates the middle interval using Even–Paz before recursing on the two sides.

Its continuous mirror is “Continuum Modified Even–Paz.” Given \(T\), \(\mu\), and piecewise-constant valuations, construct a deterministic mass allocation rule by replacing each finite sorted list of cutpoints with the weighted quantile of the cutpoint distribution. If a valuation type creates an atom at the quantile, split that type’s mass there. Recursively allocate the two sides and use a mass version of Even–Paz on the middle interval. The output must satisfy proportionality for every type and bound the gain from changing a report by some \(\epsilon\); the optimization question is the smallest such worst-case \(\epsilon\).

I would expect the allocation part to be tractable for finite \(T\): weighted quantiles, piecewise-constant integration, and middle-piece allocation are all finite-dimensional operations. The exact incentive guarantee is less clear. In an atomless population, one individual cannot move the aggregate quantile, which may make manipulation disappear; but that can also make strategyproofness vacuous unless the focal agent’s report-specific bundle is defined carefully. The right formulation should preserve a meaningful deviation by a representative agent while retaining the mass-level allocation.

Proposition 6 supports this regime, although I would not use it as a primary anchor. It shows that a finite direct-revelation mechanism for \(k\)-breakpoint valuations can be approximated in the Robertson–Webb model using \(n\lfloor 2k/\epsilon\rfloor\) queries. In the high-multiplicity regime, the natural next question is whether one representative per type suffices, replacing dependence on the population size by dependence on \(\tau\). That is a genuine computational-population question, but it is not proved by Proposition 6 itself.

The weakest point is the semantics of determinism. The functions \(\beta_t\) describe aggregate type allocations and may look like lotteries or fractional assignments. A referee could reasonably object that this has weakened the paper’s individual-level deterministic mechanism. The mirror should therefore require implementability by deterministic allocations for every sufficiently large finite replica \(q\), with the mass mechanism as the limit. If that implementability condition is dropped, the positive case becomes much less persuasive.

I would not try to mirror the paper’s contiguous-allocation results: contiguity for a continuum of individually allocated intervals introduces an additional modelling choice that could obscure the population question. The strongest case is therefore Theorem 1’s non-wasteful impossibility, with Theorem 8 as an algorithmic companion. The paper is not already a continuous-population paper: its cake is continuous, but its society remains finite and individually represented. A mass version would be a distinct high-multiplicity question, and if its answer coincides with Theorem 1, that would be a substantive transfer result rather than a novelty collision.

The case AGAINST (opponent, writing after the proponent)

The negative case begins with a mismatch between the paper’s object and the proposed continuum object. The paper has no theorem about computational complexity in the ChoCo sense: Theorem 1 and Proposition 5 are mechanism impossibilities, while Theorem 8 and Proposition 6 give mechanism/query guarantees. That does not make a mirror illegitimate, but it means the paper offers no direct complexity anchor. More importantly, its central property—unilateral strategyproofness—is not determined by a population distribution and aggregate type allocations.

Suppose \(q\) replicas of each role are introduced. One agent changing report changes the empirical distribution only by

\[ \frac{1}{nq}(e_{r}-e_{t}). \]

In the limit, that perturbation disappears. If the continuum mechanism depends continuously only on \(\mu\), the individual’s report cannot change the aggregate outcome, so strategyproofness becomes automatic. If instead a positive mass of type \(t\) changes report, that is a coalition deviation, not the unilateral deviation used throughout the paper.

The proposed inequalities do not repair this. Comparing the bundle \(\beta_t^\mu\) with \(\beta_r^\mu\) at the same \(\mu\) treats reports as choices from a fixed menu. In the paper, reporting \(r\) changes the mechanism’s input and therefore potentially everyone’s allocation. A faithful continuum version would need an additional report-indexed allocation kernel, specifying what an individual reporter receives even when that report has zero mass, together with a deterministic microscopic assignment of cake to agents. The aggregate function \(\beta_t^\mu\) is insufficient: two deterministic allocations can have the same type average while giving different individual agents completely different utilities. Adding this kernel and microscopic coordinate is a new asymptotic mechanism-design model, not a mass-transfer version of the paper.

This defeats Theorem 1 as an anchor. Its proof is not merely about lengths of aggregate pieces. It selects two named agents, obtains their particular allocations \(A_1\) and \(A_2\), defines a new valuation \(v\) supported exactly on \(A_1\), and then uses unilateral deviations by agents 1 and 2. A type-level allocation has no canonical \(A_1\): identical \(u\)-agents can be assigned arbitrary microscopic pieces with the same aggregate average. The valuation \(v\) is consequently not a type determined by the population state; it is chosen after inspecting an individual allocation.

There is also a type-space problem. The theorem quantifies over all piecewise-constant valuations, whose breakpoints and densities range over a continuum. A fixed finite \(T\) can only give a restricted-domain theorem, and the adversarial valuation constructed in the proof need not belong to that domain. Allowing every such valuation as a type means continuizing the valuation space as well as the population, outside the programme’s population-only model. Replicating the finite instance and requiring a deterministic mechanism for every \(q\) is a possible asymptotic question, but it retains the individual mechanism at every finite \(q\); its limit is not a mechanism specified by \(\mu\) alone.

Theorem 8 has the same defect in algorithmic form. Modified Even–Paz sorts individual cutpoints, assigns agents to recursive subproblems, and bounds the gain from one agent moving her own cutpoint. A weighted quantile construction can reproduce the macroscopic geometry, but splitting an atom at a quantile is a fractional assignment of identical agents. One agent cannot move that quantile; moving a whole atom is a coalition deviation. The theorem’s \(n\) is also the number of strategic individuals, not the number of valuation types. Replacing it by the number of roles changes the fairness and incentive problem; replacing it by \(nq\) gives the ordinary finite algorithm with complexity growing in \(q\). Thus the weighted-quantile procedure is a new anonymous allocation rule, not a continuous mirror of Theorem 8’s incentive guarantee.

Proposition 6 does not provide the missing bridge. Its query bound is \(n\lfloor 2k/\epsilon\rfloor\) because every named agent has a private valuation. If \(q\) replicas have privately reported valuations, identical underlying types do not let the mechanism query only one copy: it does not know they are identical. If the type partition and common valuation of every group are public, then one representative suffices, but the private-information problem has been removed rather than continuized. Moreover, the proposition is conditional on a finite direct-revelation mechanism; it gives no type-level algorithm or complexity result.

The honest qualification is that repeated valuation roles with scaled cake supply are not absurd. A separate programme on anonymous continuum cake-cutting, report kernels, deterministic microscopic implementations, and convergence rates could be worthwhile. But that programme would add precisely the structure the proposed mirrors omit. As written, Theorem 1 loses its individual incentive content, Theorem 8 loses the deviation that drives its guarantee, and Proposition 6 loses either privacy or the claimed query reduction. The paper therefore supplies no worthwhile continuous-population mirror within ChoCo’s stated model; the universal “no possible scenario” claim is less secure only because one could invent that larger asymptotic mechanism-design model around it.
