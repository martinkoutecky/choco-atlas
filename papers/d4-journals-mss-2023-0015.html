The case FOR (proponent)

There is a plausible population mirror here, but the paper supplies no qualifying computational-complexity anchor. The state \(\theta\) is continuous; the society is still a finite network. None of the numbered results classifies an algorithmic problem as polynomial-time solvable, hard, fixed-parameter tractable, or similar.

The closest formal anchor is Proposition 4, proved in this paper. It says that in a strongly connected network with \(0<b<1\), all agents’ opinions converge almost surely to either the right-biased consensus \((1-\mu)\theta+\mu\bar\gamma\) or the left-biased consensus \((1-\mu)\theta+\mu(1-\bar\gamma)\), where \(\bar\gamma=\sum_j\pi_j\gamma_j\) and \(\pi\) is the invariant distribution of the update matrix \(W\). This establishes the possible long-run outcomes, but does not compute the probability of reaching either one. The numbered “Results” in the simulation section report empirical trends, not complexity classifications.

The strongest prospective mirror I can make from those results is Block-Continuum Less-Biased Consensus Probability. Consider a large online community or public-health audience with many people but a modest number \(\tau\) of complete behavioral types. Type \(i\) has mass \(\nu_i\), with \(\sum_i\nu_i=1\), and all its members share the same initial Beta parameters \((\alpha_{i,0},\beta_{i,0})\), confirmation-bias parameter \(\gamma_i\), and contact affinities \(H_{ij}\). Let its attention share for type \(j\) be
\[ K_{ij}=\frac{\nu_j H_{ij}}{\sum_\ell \nu_\ell H_{i\ell}}, \]
with \(K\) strongly connected. This makes mass meaningful: it affects who each type encounters. The population is large relative to \(\tau\), and the type description includes every feature that affects learning or contact.

Given rational parameters \(\theta\ne\tfrac12\), ambiguity rate \(\mu\), reliance weight \(b\in(0,1)\), and the type data above, each type updates its Beta parameters using the paper’s rule with \(K\) as the block interaction matrix. Types see the same public signal stream, and interpret ambiguous signals according to their current opinions and \(\gamma_i\). Let \(q\) be the probability that the limiting consensus is the less-biased branch: the right-biased branch when \(\theta>\tfrac12\), and the left-biased branch when \(\theta<\tfrac12\). The computational problem is to return an estimate \(\hat q\) with \(|\hat q-q|\le\varepsilon\) with probability at least \(3/4\). This preserves the paper’s network externalities, confirmation bias, and less-biased-consensus question while making the *population* a type-mass distribution.

I would tentatively expect this probability-computation problem to be difficult for continuum-specific reasons: Proposition 4 identifies the possible limiting values but leaves their probabilities unresolved, even when the population has been compressed to a small type support. That is a research conjecture, not a result of this paper. Natural follow-ups include whether the problem is tractable in \(\tau\), whether a finite-state description computes \(q\), and how well the block model approximates finite networks.

The case is recognizable to the authors because it asks about the same long-run consensus probability their simulations study. Its weakest point is decisive under your anchor rule: this is a proposed new computational question, not a mirror anchored in a named computational-complexity result. Proposition 4 and the simulation results motivate it, but do not qualify as computational anchors. So the honest anchor count is zero, and this positive case remains a plausible research direction rather than an eligible continuous mirror.

The case AGAINST (opponent, writing after the proponent)

The case against has one clean gate: this paper has no computational-complexity result to continuize. Proposition 4 proves an almost-sure convergence statement for a finite, strongly connected network. It gives the two possible consensus values through the invariant distribution \(\pi\), but says nothing about the complexity of computing the probability of reaching either branch. Results 1–6 are simulation-based claims about small network topologies, partisanship, and connections. The continuous state \(\theta\) does not make the society continuous.

The proposed block-continuum question—estimate the probability \(q\) of reaching the less-biased consensus—tracks the paper’s simulations closely, but it is a new computational problem, not a mirror of a named computational result. The paper defines that probability and estimates it by simulation; it gives no exact, approximation, or parameterized algorithm for it. Calling the follow-up a mirror would erase the programme’s distinction between a computational question the paper established and one a later researcher chooses to add.

The strongest version of the candidate is plausible: model a large community with a few behavioral groups, positive mass for each group, and a contact kernel between groups; then ask for an \(\varepsilon\)-accurate estimate of \(q\). A graphon model could make a similar move. But these formulations expose a real modeling tradeoff in the paper’s topology results. Preserve each agent’s network role exactly, and types may need to distinguish many vertices; collapse roles into a small block system, and the model replaces individual centrality and adjacency with group-level mixing. Giving partisan groups positive mass avoids their disappearance in a large-population limit, but changes the paper’s experiments with one left partisan and one right partisan into a cohort model. That may be a worthwhile extension, but it is not a continuization of the results the paper reports.

So the negative case is strong for the programme’s decision: this paper offers no eligible continuous mirror anchored in its computational results. It is weaker as the universal claim that no scenario could make a continuous version worth studying. A positive-mass block model is a sensible candidate for new work, and the paper’s authors might recognize it as their problem. The honest limit of the case is that such work would be a new computational social-learning project, not a ChoCo mirror of this paper.
