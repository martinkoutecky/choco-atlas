What the mirror covers

The proposed formulation covers Theorem 4.1’s maximum-size and uniqueness claim for eight alternatives; it leaves the paper’s other structural observations and search methodology without separate mirrors.

The case FOR (proponent)

The strongest mirror I can defend is a maximum-diversity preference repertoire for a large electorate. Imagine a recurring mass vote over eight candidates, with many voters sharing each of a relatively small number of complete rankings. An institution or a stylized model specifies which rankings are admissible and wants the repertoire to be as diverse as possible while guaranteeing that majority comparisons never cycle, whatever the proportions of those types. This is a plausible high-multiplicity regime: the electorate can be enormous while the selected set of types is bounded by the 40,320 possible rankings.

Here is the continuous problem. For input \(n\), let the types be the complete rankings \(S_n\). Choose a set \(T\subseteq S_n\) maximizing \(|T|\), subject to this condition: for every distribution \(\mu\in\Delta(T)\), the strict-majority relation is acyclic, where \(a\succ_\mu b\) exactly when more than half the mass ranks \(a\) above \(b\). A solution is a maximizing repertoire \(T\), together with its size and a guarantee that it satisfies the condition. The lead instance is \(n=8\). In the regime of interest, the population size is much larger than the number of types; mass is each type’s fraction of the population.

The anchor is Theorem 4.1, established in this paper by the authors’ exhaustive computer search. It says that the largest Condorcet domain on eight alternatives has size \(224\); there is exactly one such domain up to relabelling; that domain has a core of size \(4\); and there are no maximal Condorcet domains of size \(223\). The theorem is the paper’s named exact computational result, though it is an extremal result rather than a complexity-class classification. Its continuous mirror asks for the maximum admissible support and, at \(n=8\), the maximizing support. The theorem gives the answer: \(224\), with a unique solution up to isomorphism.

The high-multiplicity setting is credible here because rankings are the complete descriptions of agents that the majority-domain condition uses; voters with the same ranking are interchangeable. The scenario is deliberately a structured or institutionally specified preference repertoire, rather than a claim that ordinary electorates naturally have exactly these restrictions. That makes it stylized, but it keeps the underlying question intact: how much preference diversity can coexist with a guarantee of acyclic majority comparisons? The authors would recognize that as their Condorcet-domain problem.

For variable \(n\), I expect no continuum-specific escape: if the discrete maximum-domain problem is hard, that hardness carries over. In fact, the continuous and discrete formulations are equivalent here. A discrete profile gives rational masses; conversely, if some real-valued mass vector creates a strict majority cycle, sufficiently close rational masses preserve that cycle, and those rational masses correspond to a finite electorate. Thus the universal condition over continuous distributions holds exactly when the set is a Condorcet domain in the paper’s sense. Theorem 4.1 solves the \(n=8\) case, but establishes neither hardness nor a general efficient algorithm.

The mirror covers Theorem 4.1’s maximum-size and uniqueness result; it does not turn the paper’s other structural observations into additional anchors. The further questions are the complexity of the maximum-domain problem as \(n\) varies, whether maximum domains are unique up to isomorphism at other values of \(n\), and what changes if the condition is required only for mass distributions near a particular observed electorate.

The soft spot is also the central limitation: because the paper’s domain definition already ranges over all finite voter profiles, the density argument makes the continuous version exactly the same optimization problem. That is strong evidence that the mirror is a sensible object, but weak evidence that continuization reveals a new complexity landscape. I would present this as a credible, narrowly scoped mirror—not as a new continuous result.

The case AGAINST (opponent, writing after the proponent)

Theorem 4.1 is a genuine computational extremal result, but the proposed mirror does not give it a new population problem. A Condorcet domain is already a set of rankings whose majority relation is acyclic for every profile drawn from that set. Requiring acyclicity for every distribution \(\mu\) over the set states the same condition: finite profiles give rational masses, and any strict majority cycle under real masses persists under a sufficiently close rational approximation. So maximizing the size of \(T\) subject to that condition is the maximum-domain problem the paper already studies.

That is the strongest objection to the anchor: the continuous population is not an input to the computation. The object being searched for is a subset of \(S_n\); masses are universally quantified away. The theorem’s finite profile definition already ranges over all electorate sizes and compositions. Thus the proposed mirror is a genuine collision with the paper’s model, not merely a case where a new continuous problem happens to have the same answer.

The better variants do not rescue this anchor. Restricting the condition to distributions near an observed electorate would make masses matter, but it would ask about that electorate’s robustness, not the paper’s maximum-domain and uniqueness result. A large-electorate scenario makes repeated ballot types plausible, but it cannot turn a population-independent search over domains into an algorithmic problem on a given continuous society.

This negative case has a limit: the equivalence could be useful to state explicitly as a bridge between finite profiles and distributions. But for this paper, it is already implicit in what a Condorcet domain means; it does not supply a distinct continuous mirror of Theorem 4.1.
