The continuous mirror question

Given a finite type set \(T\), rational masses \(\mu_t>0\) summing to \(1\), positive integer weights \(w_t\), and rational quota \(0<\theta<\sum_t\mu_t w_t\), form, for each admissible integer \(q\), a weighted voting game with \(q\mu_t\) players of type \(t\), each of weight \(w_t\), and quota \(q\theta\). As \(q\) tends to infinity through values for which every \(q\mu_t\) and \(q\theta\) is integral, determine whether \(a_t^{(q)}=q x_i^{(q)}\) converges for players \(i\) of type \(t\), where \(x^{(q)}\) is the finite-game nucleolus, and compute the limit or an \(\varepsilon\)-approximation to it.

The model it lives in

The society is a distribution \(\mu\) over finitely many weight types. A coalition selects masses \(y_t\in[0,\mu_t]\) and wins when \(\sum_t w_t y_t\ge\theta\). Its type-level payoff density is the replication-rescaled nucleolus payoff \(a_t\); the finite replication sequence defines how coalition multiplicities and the nucleolus objective carry over to the limit.

What the mirror covers

The mirror covers Theorem 4 for weighted voting games under high-multiplicity replication. It leaves Theorems 1–3 and Theorem 2's bounded-treewidth \(b\)-matching result unaddressed.

Open questions for a prover

  • Give a finite-replication error bound for the limit in terms of the input size and the quota's distance from the endpoints.
  • Analyze the boundary quota \(\theta=\sum_t\mu_t w_t\) separately.

The case FOR (proponent)

I would anchor the positive case on Theorem 4: “The nucleolus of a weighted voting game can be computed in pseudopolynomial time.” The game has integer player weights \(w_i\), a threshold \(T\), and coalition value \(1\) exactly when its total weight reaches \(T\); the task is to compute the unique imputation that lexicographically maximizes the coalition excesses. The paper attributes this result to Pashkovich [26] and Elkind et al. [12], then derives it again from Theorem 1. The ordinary finite-game nucleolus is defined from the ordered list of coalition excesses. ([Benedek et al.](https://link.springer.com/article/10.1007/s10107-020-01527-9)) Theorem 4 is my lead because weight classes give an unusually direct, complete notion of agent type. The paper’s b-matching result is less clean for this purpose: agents’ graph neighborhoods often distinguish them even when other attributes match.

Here is the regime I have in mind. A large cooperative body has many members, but only a small number \(\tau\) of voting-right classes. Members in a class have the same vote weight and the same other characteristics relevant to this game; the population size \(q\) is much larger than \(\tau\). For example, many member organizations in a federation might share one of a few contractual voting weights. This is a high-multiplicity instance regime, not a claim that every weighted voting application is large and homogeneous.

I would call the mirror Replication-Limit Nucleolus for Weighted Voting. Its input is a finite type set \(T\), rational masses \(\mu_t>0\) summing to \(1\), integer weights \(w_t\), and a rational per-capita threshold \(\theta\), with \(0<\theta\leq\sum_t\mu_t w_t\). For every integer \(q\) that makes all \(q\mu_t\) and \(q\theta\) integral, form a finite weighted voting game with \(q\mu_t\) members of type \(t\), each of weight \(w_t\), and quota \(q\theta\). Let \(x_i^{(q)}\) be its nucleolus payoff. Symmetry and uniqueness make the payoff equal for all members of each type, so define \(a_t^{(q)}=q x_i^{(q)}\) for a type-\(t\) member.

The continuous society has mass \(\mu_t\) of each type. A coalition is described by masses \(y_t\in[0,\mu_t]\); it wins when \(\sum_t w_t y_t\geq\theta\), and its per-capita-scale allocation is \(\sum_t a_t y_t\). The continuous problem is: prove that \(a^{(q)}\) converges as \(q\) tends through the allowed replication factors, and compute its limit \(a^\infty\)—for instance, return \(\hat a\) with \(\lVert\hat a-a^\infty\rVert_\infty\leq\varepsilon\). A concrete target is an algorithm polynomial in \(\tau\), the input bit length \(L\), and \(\log(1/\varepsilon)\). This asks for a limit of the paper’s nucleolus on exact high-multiplicity expansions, rather than replacing its solution concept with an arbitrary measure over continuum coalitions.

I expect this mirror to be Class A, though Theorem 4 does not prove that outcome. The instance retains the paper’s threshold coalition value and surplus-sharing question, while the population is represented directly by type masses. With few types, coalition counts compress to a small-dimensional mass vector, and the threshold is a single linear boundary; the paper’s dynamic-programming approach gives a plausible route to tractability. Existing high-multiplicity weighted-voting work supports the regime’s plausibility. Further questions are whether convergence always holds, whether the limit has a direct continuum characterization, and whether hardness returns when the number of weight classes grows.

The weakest point is that the standard nucleolus orders a finite list of coalition excesses, whereas the continuous society has uncountably many possible coalition masses. The replication limit is precise, but it is a proposed continuous solution concept whose existence and relation to any direct continuum leximin notion must be established. Nor does the pseudopolynomial algorithm in Theorem 4 automatically yield an efficient algorithm for that limit. This is a real gap, but it leaves a concrete, faithful mirror question for the authors rather than merely calling a fractional outcome “continuous.”

The case AGAINST (opponent, writing after the proponent)

The strongest case against this anchor is that a mass vector does not by itself define the nucleolus’s objective. In the \(q\)-person game, every individual coalition contributes a coordinate to the sorted excess list. A type-count vector \(k\) appears \(\prod_t \binom{q\mu_t}{k_t}\) times. Passing to coalition masses \(y=k/q\) collapses those repeated coordinates. For uncountably many possible \(y\), there is no ordinary sorted list, and choosing a measure over mass coalitions would change the problem.

That objection defeats a casual “continuous nucleolus” defined only over mass vectors. It does not defeat the proponent’s stronger repair: define the target as the limit of the finite games along the specified replication sequence. That is a precise, canonical question, and it fits the programme’s high-multiplicity bridge. With identical members within each weight class, symmetry also reduces the output to one payoff density per type. The natural federation scenario is credible; per-capita rescaling does not make the limit degenerate. Theorem 4 supplies a named computational result to mirror. I cannot honestly turn the coalition-multiplicity issue into a reason to reject the repaired mirror.

There is also relevant prior analysis: for interior quotas, Kurz, Napel, and Nohn show that as individual normalized weights vanish, nucleolus payoffs become asymptotically proportional to weights for regular players. In the proposed fixed-type regime, each positive-weight type has positive aggregate weight, so this result gives \(a_t^\infty=w_t/\sum_u\mu_u w_u\) for those types; zero-weight types receive zero. [Kurz, Napel, and Nohn, *The Nucleolus of Large Majority Games*](https://www.vwl4.uni-bayreuth.de/pool/Publikationen_Napel/2014_the_nucleolus_of_large_majority_games.pdf). That is analytic prior work, not a computational collision under the programme’s criteria. It changes what the authors should be asked to establish, but it does not make the mirror invalid.

So the honest negative case is weak: it exposes a real ambiguity in a direct continuum definition, but the replication-limit formulation resolves it. This anchor survives.
