The case FOR (proponent)

The positive case is narrow. Strictly, the paper has no named complexity result: no numbered result classifies a problem as polynomial-time solvable, NP-hard, or similar. The closest algorithmic anchor is Proposition 1, proved in §3.1 here, though the paper notes earlier versions of the result. It says that when all agents have the same value distribution, a qualified majority rule with threshold
\[ \bar k=\min\left\{k\in\{1,\ldots,n\}: k>\frac{U^-}{U^++U^-}n\right\} \]
maximizes expected welfare over anonymous BIC mechanisms; an ordinal mechanism therefore suffices. This is an explicit optimizer, so it supports a tractability mirror if that counts as a computational result. It is not a complexity classification.

Lead mirror — Continuous Anonymous Welfare Choice. An instance is a finite set of possible cardinal values \(V\subset\mathbb Q\setminus\{0\}\) and a rational distribution \(\mu\) over \(V\), with positive and negative values in its support. The society is a unit mass of members whose realized values have distribution \(\mu\); \(\mu_v\) is the fraction with value \(v\). An anonymous direct mechanism is a measurable rule \(F:\Delta(V)\to[0,1]\), mapping the reported distribution of values to the probability of reform. The task is to choose a BIC \(F\) maximizing expected per-capita utilitarian welfare. A solution is an optimal rule on report distributions, including its choice at the truthful aggregate \(\mu\).

In this nonatomic model, one member’s report cannot change the aggregate, so BIC imposes no effective restriction. The objective at truthful reports is \(F(\mu)\sum_v\mu_vv\). Thus an optimum chooses reform with probability \(1\) if the mean value is positive, probability \(0\) if it is negative, and any probability if it is zero. It is computable in time linear in the support size. This is the symmetric high-multiplicity limit suggested by Proposition 1: the fraction of positive reports concentrates at \(p\), and its threshold converges to \(U^-/(U^++U^-)\), which is exactly where the mean value changes sign. A large membership organization with many members drawn from a small, shared set of valuation levels is a plausible regime, with many members and few value types.

I would not use Theorem 2 as a computational anchor. Proved here, it says that for every \(n\ge3\) there are value distributions for which no ordinal SCF maximizes the paper’s welfare program: an anonymous cardinal BIC mechanism can do strictly better. That is a substantive welfare result, but not a complexity result. Nor does the paper’s example establish that this advantage survives a continuum limit: its construction has two high-stakes agents and \(n-2\) low-stakes agents, so the high-stakes share shrinks as \(n\) grows.

The main weakness of the proposed mirror is also its key simplification: nonatomicity removes individual pivotality, making BIC vacuous. The authors may recognize it as the limit of their symmetric welfare problem, but may reasonably judge it too weak to represent their incentive-design question. This mirror covers only Proposition 1’s symmetric case; it does not cover the asymmetric cardinal advantage in Theorem 2. Natural follow-up questions are whether that advantage persists when both high- and low-stakes cohorts have positive limiting mass, and whether a finite-population correction can retain meaningful BIC constraints while approaching a continuous population model.

The case AGAINST (opponent, writing after the proponent)

The strongest case against starts with the anchor: the paper has no named complexity result. Proposition 1 gives an explicit welfare-maximizing rule, but it does not classify the complexity of a computational problem. Theorem 1 and Theorem 2 are also welfare characterizations, not complexity results. The appendix’s Z3 code shows one way to solve finite instances; it does not turn those results into a complexity landscape.

Even granting Proposition 1 as an anchor, its strongest continuous mirror collapses to a first-best calculation. Let a positive fraction \(\lambda_j\) of the population share each value distribution \(G_j\), and let an anonymous mechanism depend on the aggregate report distribution. In an atomless society, one person’s report does not change that distribution, so the BIC constraints impose no effective restriction. Under truthful reports, the aggregate distribution is \(\nu=\sum_j\lambda_jG_j\); the planner chooses reform if \(\int v\,d\nu(v)>0\), and status quo if it is negative. This takes time linear in the input support.

That also explains the proposed symmetric limit. Proposition 1’s threshold fraction tends to \(r=U^-/(U^++U^-)\), while the truthful fraction of positive values tends to \(p\). Since \(p>r\) exactly when the mean value is positive, the limiting rule is just the mean-sign decision. The mirror’s simplicity is not a reason to reject it by itself; the problem is that the limit has removed the mechanism-design constraints that made the paper’s problem interesting. There is no nontrivial BIC optimization left to solve.

The best stronger mirror would let high-stakes and low-stakes cohorts both retain positive population shares, rather than shrinking the high-stakes group. That does not restore individual pivotality: a report by one member still changes no aggregate mass. The finite-population interim probabilities central to the paper’s analysis depend on how an individual report changes the outcome, and that information is absent from the limiting population distribution.

One could preserve pivotality by treating each cohort as a strategic player, or by retaining deviations of mass \(1/n\) and the finite grid of empirical profiles. The first changes the information and incentive model: a whole cohort now acts as one agent. The second keeps the finite-player problem, with its microscopic structure, rather than yielding a continuous-population problem. Either might support useful research, but neither supplies the missing computational mirror of the paper’s BIC design question.

This is a strong case about fit and likely research yield, not a proof that no imaginable reformulation could be worthwhile. Many members sharing a small set of valuation distributions is a plausible high-multiplicity regime; the objection is that the exact atomless limit makes individual incentive constraints disappear.
