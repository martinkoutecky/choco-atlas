The case FOR (proponent)

The best positive case is a high-multiplicity extension of the paper’s PAC-core sample-transfer result. Supplier or manufacturer consortia are a plausible regime: many firms draw from a small set of complete preference schedules over permitted coalition formats, so the number of firms \(n\) can be far larger than the support size \(\tau\). A type records the full schedule and all other attributes the model uses; \(\mu_t\) is the fraction of firms of type \(t\). A continuum partition assigns masses of types to coalition formats, conserving each \(\mu_t\), while each firm still receives an actual coalition format.

The closest named anchor is Theorem 8, proved in the paper. For top-responsive hedonic games, it relates \(\tilde m\), the samples needed for \(\tilde\epsilon\)-PAC stability in the noisy game, to \(m\), the samples needed for the same partition \(\tilde\pi\) to be \(\epsilon\)-PAC stable in the unknown noise-free game:
\[ m\zeta \leq \tilde m \leq m +(2n^3+2n^4) \left( \frac{(1-\tilde\epsilon)+\tilde\epsilon\zeta} {\tilde\epsilon(1+\tilde\epsilon\zeta)} \log\frac{2n^3}{\delta} \right). \]
The theorem’s transfer uses \(\epsilon=1-(1-\tilde\epsilon)\zeta\). Its relation is proved here; the underlying finite-game sample bound it uses is cited from Sliwinski and Zick. [Theorem 8 in the PMLR paper](https://proceedings.mlr.press/v189/trivedi23a/trivedi23a.pdf).

A concrete mirror is High-Multiplicity Top-Responsive PAC-Core Learning. An instance gives rational masses \(\mu\) over \(\tau\) complete top-responsive types; an explicit finite set \(\mathcal Q\) of coalition formats and their type compositions; a rational distribution \(D\) over tested formats; a finite class \(\mathcal H\) of possible type-by-format value tables; a finite-support multiplicative noise model; and \(\tilde\epsilon,\delta,\zeta\). A noisy sample draws \(q\sim D\) and reveals its corrupted values. A partition is represented by nonnegative masses assigned to formats, with the mass constraints enforcing \(\mu\); types split across incumbent formats are refined so each has a defined current coalition. The question is to construct a learner and give its sample bound so that, for every table in \(\mathcal H\), with probability at least \(1-\delta\) it outputs a feasible partition that is \(\tilde\epsilon\)-PAC stable in the noisy society and \(\epsilon\)-PAC stable in the clean society. The target is a bound and running time in \(\tau,|\mathcal Q|\), input bit length, noise support, and accuracy parameters, rather than the number of replicated firms.

I would expect the sample-transfer part to be tractable when the type and coalition-format descriptions are explicit. Whether the partition-finding step also admits an efficient type-level algorithm is open; Theorem 8 bounds sample counts in \(n\) and leaves running time and dependence on \(\tau\) unspecified. This mirror covers the paper’s top-responsive PAC sample-transfer result, not all hedonic core computation.

The main limitation is the anchor requirement: Theorem 8 is a sample-complexity theorem, not a numbered running-time or hardness classification. The paper’s safety-value discussion calls global minimization for \(l\geq3\) computationally hard, but nonconvexity alone is not a hardness proof, and the paper gives no numbered complexity result establishing that claim. So this is a credible positive research direction, but under a strict requirement for a named result asserting membership in P or a hardness class, the paper supplies no qualifying anchor.

The case AGAINST (opponent, writing after the proponent)

The proponent’s only anchor, Theorem 8, is a sample-complexity relation, not a computational complexity result. It compares the sample counts needed for PAC stability in noisy and noise-free games, assuming the same partition \(\tilde{\pi}\) is already available. It gives no running-time bound for finding that partition and proves no tractability or hardness result for a computational problem. The paper’s claim that a safety value is “computationally hard” because its objective is non-convex does not supply the missing hardness proof. By ChoCo’s stated standard, there is no qualifying named result here to mirror.

The strongest version of the proposed mirror would use firms with a finite catalogue of consortium formats, complete preference types over those formats, a distribution over tested formats, and a mass allocation of types to formats. That can be a sensible high-multiplicity model. But getting a bound in \(\tau\) would require new assumptions about anonymity, the format family, and how coalitions form. Theorem 8’s bound depends on \(n\), and it does not show that type support controls the learning or partition-finding problem. With unrestricted hedonic preferences, the coalition domain grows with the agent set; with a finite format catalogue, the central problem has been reformulated as type-format PAC learning and allocation. Either way, the result would be new work, not a continuization of Theorem 8’s computational content.

That is a strong objection to this anchor under ChoCo’s current algorithmic remit, but it does not establish the universal negative. The finite-format firm scenario is plausible, and a type-level PAC-core problem could be worthwhile on its own. My case is weakest precisely there: the paper supplies no computational result to transfer, but a well-designed extension might create one.
