The case FOR (proponent)

The strongest positive case is a plausible new extension of the paper’s implementation problem. The paper itself supplies no named computational-complexity result to anchor a ChoCo mirror: it proves no result about polynomial time, hardness, or algorithms.

The nearest conceptual anchors are Theorem 4.5 and Theorem 6.3, both proved in this paper. Theorem 4.5 says that if an SCF \(f\) is implementable in interim rationalizable strategies, then some equivalent SCF \(\hat f\approx f\) satisfies weak interim rationalizable monotonicity (weak IRM). Theorem 6.3 says that if some equivalent \(\hat f\approx f\) satisfies weak IRM and weak no-worst-rule (weak NWR), then \(f\) is implementable in interim rationalizable strategies. Theorem 6.3 is the stronger conceptual lead: it builds an implementing mechanism from structural conditions. These are implementation results, not computational anchors under the requested criterion.

A plausible regime is a large public-policy consultation or member organization with many participants but few complete strategic types. A type \(\theta\) would include everything the model uses about a participant: their utility and their interim beliefs. The society is a distribution \(\mu\in\Delta(\Theta)\), and the target rule is \(F:\Delta(\Theta)\to\Delta(A)\), mapping the population’s type composition to a lottery over policy outcomes.

The candidate problem is Anonymous Continuum Interim-Rationalizable Implementation. An instance consists of a finite outcome set \(A\), a finite set \(\Theta\) of complete types, a domain \(D\subseteq\Delta(\Theta)\) of possible population distributions, rational utility and belief data for those types, and a target rule \(F:D\to\Delta(A)\) with a finite rational description. A mechanism has countable message sets and an anonymous outcome rule \(g\) that maps the masses of each type sending each message to a lottery in \(\Delta(A)\). Using a continuum analogue of the paper’s iterated deletion of never-best responses, ask whether there is a mechanism such that, for every \(\mu\in D\), each type with \(\mu_\theta>0\) has a surviving message and every surviving profile of message masses induces \(F(\mu)\). A positive solution is a mechanism with an implementation proof; a useful negative solution would be a necessary-and-sufficient characterization or impossibility result.

That is a recognizable extension of interim rationalizable implementation: it preserves the target-rule, mechanism, and rationalizability questions while replacing a finite type profile with a population distribution. On the ChoCo trichotomy, my provisional expectation is continuum-specific difficulty (Class C). The reason is structural: in an atomless population, one participant’s deviation does not change the aggregate report distribution, which may make incentives and rationalizable-message selection degenerate. This is a conjecture about the proposed extension, not a hardness result established by this paper.

The scope would be the implementation characterization behind Theorems 4.5 and 6.3. It would not cover the paper’s comparisons with Bayesian implementation as computational findings. Its references to “continuous implementation” concern finite-agent implementation concepts; lotteries over \(A\) also make outcomes stochastic, but neither feature by itself continuizes the population.

The weakest point is the scenario’s fit to the authors’ model. Their finite agents have potentially distinct utilities and interim beliefs over the other agents’ type profiles. Making them interchangeable requires an anonymous rule and repeated complete types, including repeated belief structures. More seriously, the atomless limit may erase the individual incentives that their mechanism relies on. That makes this a credible question to investigate, but a weak claim that the paper already contains a continuous-population computational result.

The case AGAINST (opponent, writing after the proponent)

Theorem 4.5 and Theorem 6.3 are existence results, not computational results. The first says implementation implies weak IRM; the second gives sufficient conditions and constructs a mechanism. Neither asks for an algorithm, proves a complexity bound, or identifies a separation problem. The proposed continuum version is therefore a new research question, not a computational mirror of either theorem.

There is also a structural obstacle to making that extension faithful. The paper’s states are profiles in \(T=\prod_i T_i\), and its implementation arguments depend on named agents, their interim beliefs, and what each agent gains from a unilateral deviation. Repeating agents is not automatically high multiplicity: the complete type must include beliefs as well as preferences, and the paper supplies no population-level symmetry or aggregation rule for those beliefs. One could impose such a structure, but that would be an additional model choice.

In the proponent’s proposed model, the outcome depends only on the masses of messages. In an atomless population, one person’s message changes no mass, so it changes no outcome. Every message then gives the same payoff and survives iterated deletion for every type. The implementation requirement quantifies over every surviving profile, so it cannot select a particular report distribution. For a fixed population, the mechanism must give the target outcome at every report-mass profile that can arise; with unrestricted reports, those profiles overlap across populations. A nonconstant \(F\) is therefore generally unimplementable, while a constant target is trivial. That is a degeneracy of this anonymous aggregate-message formulation, not continuum-specific computational hardness.

Avoiding the collapse would require something like atomic groups, coalition deviations, or outcomes that depend on an individual’s own message. Those may define worthwhile mechanism-design problems, but they change the strategic object or the paper’s common-outcome SCF model. Even then, the proposed formulation has no specified finite encoding or input-size measure for its arbitrary countable-message mechanisms, so it does not yet pose a complexity question.

I would not claim to have ruled out every useful project nearby. A redesigned population mechanism with an explicit computational representation could be valuable. But it would be a new programme, not a continuous mirror of Theorems 4.5 or 6.3; the universal “no scenario” claim remains the weakest part of the negative case.
