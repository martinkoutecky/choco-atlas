The case FOR (proponent)

I cannot identify a qualifying anchor in this paper. Its numbered results do not assert that any problem is in \(P\), NP-hard, FPT, or otherwise computationally classified.

The closest are Theorem 3.1, proved here, which characterizes dynamic rules satisfying Equal Treatment of Equal Problem Histories and Equal Treatment of Equal Solution Histories as exactly those arising from a static rule through some aggregator extension; and Proposition 4.1, proved here, which says that under its stated endowment conditions, the constrained equal-awards rule with either the previous-allocation or minimum aggregator persistently gives each claimant \(E_t/n\). These are structural and allocation results, not computational results. Proposition 4.2 likewise concerns preservation of fairness properties, not complexity. So there is no honest per-anchor continuous problem to state, and no lead anchor to classify.

There is a plausible population-continuous *extension* of the model. For example, in a large refugee population, let a type \(q\) be a household’s complete claim history over a fixed finite horizon \(H\), and let \(\mu_q\) be its population share. Given per-capita endowments \(e_t\), the type-level decision is an allocation \(x_{q,t}\) satisfying \(0\le x_{q,t}\le c^t_q\) and \(\sum_q\mu_qx_{q,t}=e_t\). Past type-level allocations supply the baselines through the paper’s aggregator, and a specified static rule supplies each period’s allocation through the composition extension. This continuizes the population while leaving time finite; fractional type-level averages fit the divisible rationing good. It is a sensible high-multiplicity version of dynamic rationing.

One could ask for an algorithm to compute that allocation history from a rationally weighted list of claim-history types. But the paper neither asks that question nor provides a numbered computational result to anchor it. The strongest positive case is therefore for a natural continuous-population *research direction*, not a continuous mirror of a named result in this paper. The weak point is decisive for the requested task: its contributions are axiomatic, and adding a computational problem would be new work rather than continuizing a result the authors establish.

The case AGAINST (opponent, writing after the proponent)

The strongest negative case is narrower than the assigned universal claim: this paper offers no computational result to continuize. The proponent’s proposed refugee-population model is sensible. With a finite horizon \(H\), a type could be a complete claim history \((c_q^1,\ldots,c_q^H)\), with mass \(\mu_q\), per-capita awards \(x_q^t\), and per-capita endowment \(e_t\), so that \(\sum_q \mu_q x_q^t=e_t\). Baselines can then be computed type by type from earlier awards. That is a plausible high-multiplicity model of dynamic rationing. But a plausible model does not supply a computational question anchored in this paper.

Theorem 3.1 characterizes which dynamic rules satisfy two equal-treatment axioms. Its possible continuous counterpart would characterize rules over a population measure, perhaps with the axioms interpreted almost everywhere. That remains an axiomatic characterization, outside ChoCo’s computational scope. To make it an algorithmic problem, one would first need a finite representation of the rules and aggregators and a task such as testing or computing something. The theorem supplies none; it ranges over arbitrary rules and aggregators.

Proposition 4.1 says that, under its conditions, a particular rule and aggregator yield \(E_t/n\) for every claimant. A mass version can replace \(n\) by total mass and give each type the same per-capita award. That preserves the proposition’s allocation identity, but it does not turn the proposition into a computational result. Asking for an algorithm to check its conditions or calculate those awards would add a task not studied in the paper.

Proposition 4.2 similarly concerns preservation of fairness properties under composition. A population version could restate equal treatment and order preservation over types, but it would still be a structural or axiomatic question. A computational formulation would need extra choices about what is encoded and what is to be computed. The same issue applies to the proponent’s suggestion to compute an allocation history: once a particular rule, aggregator, horizon, and input representation are fixed, that is a new evaluation problem, not a computational claim made or analyzed here.

So none of the three results the proponent mentions survives as a qualifying mirror. The weakness in the negative case is that this does not establish that every adjacent computational project would be uninteresting: one could add an optimization or algorithmic question to the mass model. It establishes only that doing so would create new work rather than continuize a computational contribution of this paper.
