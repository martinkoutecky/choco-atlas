What the mirror covers

The proposed query concerns winner determination for four-agent ROLO rules; it leaves other ballot systems, the \(n=5\) analysis, and the broader representation-theoretic characterizations outside its scope.

The case FOR (proponent)

The strongest plausible mirror is winner determination for neutral ROLO voting with four people to seat. Imagine the paper’s poker audience voting on the seating order of four players. Each voter’s type is a ROLO ballot such as \(A\{D,C\}\): the voter wants \(D\) to the right of \(A\) and \(C\) to its left. There are 24 such types. If the audience is large but many voters submit the same ballot, the instance is a rational distribution \(\mu\) over those types, with support size \(\tau\) potentially far smaller than the number of voters.

The precise problem is: given \(\mu\), six rational weights \(a,b,c,d,e,f\) specifying a neutral ROLO scoring rule, and the rule’s associated score matrix \(M\), return the set of cyclic orders \(h\) maximizing \(\sum_b \mu_b M_{h,b}\). A solution is the full tied winner set. For this fixed four-person case, the computation is polynomial in the input bit length and can be done by aggregating the \(\tau\) ballot types against six outcomes. The authors should recognize this as their own winner determination: it uses their ballot types, neutral points rules, and maximization over cyclic orders. It covers the ROLO analysis, not the paper’s broader representation-theoretic programme.

The closest named anchor is Proposition 4.8, proved in the paper. It characterizes every neutral points-based rule from a 24-element transitive \(S_4\)-set of ballots to the six cyclic orders by a matrix with six parameters. In the paper’s fixed ordering, its rows are:
\[ \begin{aligned} (&a,a,a,a,b,b,b,b,c,d,e,f,c,d,f,e,c,d,f,e,c,d,e,f),\\ (&b,b,b,b,a,a,a,a,d,c,f,e,d,c,e,f,d,c,e,f,d,c,f,e),\\ (&c,d,f,e,c,d,e,f,a,a,a,a,b,b,b,b,e,f,c,d,f,e,c,d),\\ (&d,c,e,f,d,c,f,e,b,b,b,b,a,a,a,a,f,e,d,c,e,f,d,c),\\ (&e,f,c,d,f,e,c,d,d,c,e,f,d,c,f,e,a,a,a,a,b,b,b,b),\\ (&f,e,d,c,e,f,d,c,e,f,d,c,f,e,d,c,b,b,b,b,a,a,a,a). \end{aligned} \]
The paper uses this characterization to instantiate and calculate with rules such as ROLO(2,1). It is a useful scoring-rule formulation for the winner-determination question, though it does not itself claim a complexity classification.

That limitation is also the main weakness. The paper has no named theorem, lemma, corollary, or proposition asserting that a computational problem is in P, hard, or otherwise classified by complexity. Moreover, the paper already defines profiles as rational vectors \(p\in\mathbb{Q}^{(n-1)!}\). A normalized, nonnegative such profile is already a rational population distribution over ballot types. So this candidate mirror is not a distinct continuous model the programme would introduce; it is essentially the paper’s existing profile model, recast as a high-multiplicity scenario. The four-person winner problem is also easy for a fixed-size reason, not because a continuous relaxation resolves discrete hardness.

A more consequential follow-up would ask how winner determination behaves as the number of people in the cyclic order grows, when the scoring rule has a compact description and the profile has support \(\tau\). That would put the problem in the intended complexity landscape, but Proposition 4.8 does not anchor that variable-size question. The honest positive case is therefore narrow: the paper offers a clear, plausible population scenario and an exact aggregation problem, but not a distinct continuous mirror with a computational result to carry it.

The case AGAINST (opponent, writing after the proponent)

Proposition 4.8 characterizes neutral scoring matrices; it does not claim a complexity result. The proposed winner problem is obtained by supplying a profile to the matrix and taking the maximizing cyclic orders. But a profile is already a vector over ballot types in this paper, and the authors say their analysis also works over real entries. A normalized distribution \(\mu\) over ROLO ballots is therefore already an allowed profile. Since multiplying every mass by the same positive constant scales every score equally, normalizing a profile to total mass one changes no winners. The poker audience gives the model a population story, but it does not create a new population model.

The variable-\(n\) version is the strongest upgrade. It could ask for winner determination when the cyclic orders and scoring rule have compact descriptions. That may be a worthwhile computational problem, but it requires specifying an input representation the paper does not study; its concrete characterizations are for fixed \(n=4\) and \(n=5\). Any mass-based bribery or robustness question would likewise add an intervention model absent from the paper. Those could be new ChoCo projects, but they do not mirror a named computational result here.

So the offered anchor does not support a continuous mirror: the continuous population is already present in the profile formalism, while the paper’s contributions are algebraic characterizations of voting rules. The broader claim that no useful new computational question could be built around cyclic-order voting is harder to defend; the negative case is strongest when limited to mirrors of this paper’s results.
