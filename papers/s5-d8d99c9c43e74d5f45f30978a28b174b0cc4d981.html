The continuous mirror question

Given a planning domain with independent repeated task modules, type shares (mu_i), rational per-capita goal-template demands (d_j), resource quotas (b_r), and each type's feasible finite action traces (p) with integral goal counts (h_{ipj}), resource use (a_{ipr}), and cost (c_{ip}), choose finite-support masses (x_{ip}\ge0) satisfying (\sum_p x_{ip}=\mu_i), (\sum_{i,p}x_{ip}h_{ipj}=d_j), and (\sum_{i,p}x_{ip}a_{ipr}\le b_r). What is the maximum, over feasible assignments, of the minimum goal count among positively represented traces, and the minimum total action cost among assignments attaining that fairness level?

The model it lives in

A configuration model assigns population mass (x_{ip}) to whole individual action traces for each type (i). Each trace retains integral goal counts and resource use; aggregate demand and quota constraints couple the traces, and the lexicographic objective maximizes the least goal count before minimizing (\sum_{i,p}x_{ip}c_{ip}).

The objection that survived

The proposed mass-over-traces optimization is not itself the soundness-and-completeness claim proved for the finite PFC compilation, so the theorem-to-mirror correspondence is indirect.

fatal: False

What the mirror covers

The mirror covers Goal-Maximin fairness with joint goal allocation and planning in repeated, factorized task settings. It leaves out Goal-Proportional Equality, workload fairness, the separate pre-assignment approach, and arbitrary PDDL tasks with shared-state dependencies.

Open questions for a prover

  • What is the complexity of deciding whether a type distribution admits a finite-support plan assignment meeting a given fairness threshold and cost bound?
  • When can the trace-configuration problem be solved through tractable pricing, and when does individual planning hardness persist?

The case FOR (proponent)

The paper has no named result classifying a problem as polynomial-time, NP-hard, or otherwise. Its strongest named computational anchor is the pair Theorems 1 and 2, proved in the paper. Theorem 1 (Completeness) says that if a MAP task \(P\) has a valid plan \(\pi\), then the compiled fair task \(PFC\) has a corresponding valid plan \(\pi_{FC}\). Theorem 2 (Soundness) says that any valid plan for \(PFC\) induces a valid plan for \(P\). Together, they certify that the authors’ planning compilation preserves feasibility. They do not prove a complexity bound or, by themselves, prove that the compiled plan is fairness-optimal. I would use them as one two-sided formulation anchor: the paper computes with the compiled task, so it fits the formulation exception, but it is a modest anchor.

Lead mirror: Continuous Goal-Maximin MAP. Take a repeated-workforce setting: a company has many robots or employees and many instances of a small set of task types. A type is a complete planning-relevant description of an agent—its capabilities, starting-state category, resource access, and action costs. Let the types be \(i\in\{1,\ldots,\tau\}\), with rational population shares \(\mu_i\) summing to one. Let \(J\) be a finite set of goal templates, with rational demand \(d_j\) of each template per unit of population. Shared consumable resources have per-capita supplies \(b_r\), which scale with the workforce. Thus the number of agents and repeated tasks can grow while \(\tau\), the number of distinct types, remains small.

For each type \(i\), let \(\mathcal P_i\) be the set of finite, executable individual action traces in the planning domain. A trace \(p\) has action cost \(c_{ip}\), resource use \(a_{ipr}\), and an integer vector \(h_{ipj}\) counting the goal instances of template \(j\) that this agent first achieves. A solution assigns mass \(x_{ip}\ge 0\) of type \(i\) to each trace, with

\[ \sum_{p\in\mathcal P_i}x_{ip}=\mu_i,\qquad \sum_{i,p}x_{ip}h_{ipj}=d_j,\qquad \sum_{i,p}x_{ip}a_{ipr}\le b_r. \]

Each individual still executes a valid plan and achieves an integral number of goals; only the mass assigned to different plans is fractional. Define \(\kappa(x)=\min_{x_{ip}>0}\sum_j h_{ipj}\), the least number of goals achieved by any positive-mass group of agents. The problem is to maximize \(\kappa(x)\), then minimize total action cost \(\sum_{i,p}x_{ip}c_{ip}\) among those solutions. A prover would return the optimal value and a finite-support assignment of population mass to action traces, or decide whether a solution meets a specified fairness threshold and cost bound.

This mirrors the paper’s joint goal-allocation-and-planning question: each mass assigned to a trace represents agents receiving a whole action plan, and the objective balances their first-achieved goal counts before using cost as a tie-breaker. It is not just a continuous goal-assignment MILP. The scenario is plausible for a large maintenance or fulfillment operation with repeated job templates and a handful of interchangeable roles or depot zones. The paper’s motivation includes both robots and human workloads, so I think its authors would recognize the central question, provided the task population really has repeated templates and the type description captures every relevant difference.

The mirror has a meaningful optimization shape: a master LP chooses mass over plan configurations, while pricing asks for useful individual plans under the current goal and resource weights. That puts the continuous-optimization toolbox in reach, but does not guarantee tractability. For the domain-independent version, I would expect hardness to transfer (Class B): if every agent type faces a replicated copy of a classical planning task and the fairness threshold requires each agent to achieve all its goals, the threshold is attainable exactly when an individual valid plan exists. The mass relaxation cannot remove that plan-search difficulty. A tractable case may still emerge when the per-type pricing problem is tractable. These are questions for the mirror; the paper proves neither classification.

The mirror covers the paper’s goal-oriented Maximin objective and its compiled joint-planning approach, not workload fairness or every coupled PDDL task. In particular, it assumes repeated task modules coupled by scalable resource quotas; arbitrary dependencies through named shared objects may not admit this configuration description.

The weak point is exactly that restriction. The paper’s MAP instances can contain unique objects and cross-agent dependencies, and its experiments use relatively few agents. A referee could reasonably ask whether the repeated-module scenario captures enough of the paper’s problem, rather than a neighboring scheduling problem. The case survives for a substantial subfamily: the population is genuinely the continuous object, individual plans and goal bundles remain integral, and the authors’ central fairness-versus-cost question is preserved.

The case AGAINST (opponent, writing after the proponent)

The only named results to anchor are Theorems 1 and 2, and they establish feasibility preservation for a compilation of a finite MAP task. They say a valid plan exists before compilation exactly when one exists after it; they do not classify the complexity of fair planning or prove that the compiled plan is optimal. A continuous analogue of that claim risks being either a routine trace-by-trace correctness argument or a different claim about a new, population-scale planning language.

For the paper’s actual finite goal set, Goal-Maximin also degenerates as the workforce grows. Each goal has one first achiever, so at most \(|G|\) agents can achieve any goal first. Once \(n>|G|\), some agent must have a count of zero, and the maximin value is zero. In an atomless population, each of finitely many named goals has a first achiever of measure zero. The proposed mirror avoids this by scaling goal demand with population and replacing named goals with repeated templates. That is a sensible repair, but it changes the task from planning over a finite set of shared goal facts to distributing a growing workload.

There is a further gap between that repaired model and domain-independent MAP. A distribution over individual plan traces, with aggregate resource constraints, need not describe a jointly executable plan: PDDL actions can depend on shared objects, shared predicates, and the order in which other agents change the state. The compilation’s first-achiever markers likewise refer to events in one global plan. Encoding those dependencies may require tracking joint state and ordering, which removes the simple type-and-trace description. If the setting is restricted enough that individual traces plus aggregate quotas suffice, the resulting repeated-task allocation problem is coherent—but it captures a narrower, factorized regime.

That is the strongest negative case: the theorem anchor is about a finite compiler, the paper’s exact goal fairness vanishes in the population limit, and repairing it demands a repeated-task regime where the proposed configuration model may not represent MAP’s shared-state interactions. It does not defeat the proponent’s warehouse or maintenance subfamily. Repeated workforces, scalable supplies, and recurring tasks make that a plausible high-multiplicity planning problem, and the authors could recognize it. So I can argue against treating this paper as motivation for a general continuous theory of MAP, but I cannot honestly sustain the stronger claim that no worthwhile continuous mirror exists in any scenario.
