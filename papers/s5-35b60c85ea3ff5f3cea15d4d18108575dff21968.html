The continuous mirror question

Given \(|C|=4\), a target \(c^\star\), and rational masses \(\mu_t\) summing to \(1\) over sincere types \(t=(\succ_t,q_t)\) and manipulator types \(t=(q_t,c^\star)\), does there exist an allocation \(x_{t,\pi}\geq 0\) over complete ballots \(\pi\in\mathcal L(C)\) for manipulator types, with \(\sum_{\pi}x_{t,\pi}=\mu_t\) for each such type, that makes \(c^\star\) the unique SkS winner? Compute each stage's score and sum of positions using the sincere masses and the allocated manipulator masses, weighted by \(q_t\), and use the continuous majority threshold \(W/2\), where \(W=\sum_t q_t\mu_t\).

The model it lives in

Use a rational distribution of sincere \((\succ,q)\)-types and coalition \((q,c^\star)\)-types; choose \(x_{t,\pi}\) to distribute each coalition type's mass among complete ballots, and ask only whether the resulting weighted mass profile makes \(c^\star\) the unique SkS winner under threshold \(W/2\).

The case FOR (proponent)

My lead is a continuous version of weighted constructive coalitional manipulation. Theorem 3, proved in this paper, says that SkS-CCWM is NP-complete even with only four candidates. In full, its input is a candidate set, weighted nonmanipulator votes, the weights of a coalition whose ballots are unspecified, and a favored candidate; it asks whether the coalition can choose ballots that make that candidate the unique SkS winner. The paper’s hardness argument extends Faliszewski et al.’s cited Bucklin-CCWM proof, using a reduction from Partition. So the SkS theorem is the authors’ result, while the earlier Bucklin result and the Partition problem are prior work.

Call the mirror Continuous SkS-CCWM with four candidates. Its instance has \(|C|=4\), a favored candidate \(c^\star\), and a rational-mass population of types. Each sincere type \(t\) has a fixed ranking \(\succ_t\), a voting weight \(q_t\), and mass \(\mu_t\). Each manipulator type has a weight \(q_t\) and mass \(\mu_t\); all coalition members favor \(c^\star\), as in the paper’s problem. The total mass is \(1\), and type weights and masses are given in binary. Thus \(\tau\), the number of supported types, can be small even when the represented population is very large.

A solution is an allocation \(x_{t,\pi}\geq 0\) of each manipulator type’s mass among complete ballots \(\pi\in\mathcal L(C)\), with \(\sum_\pi x_{t,\pi}=\mu_t\) for every manipulator type \(t\). This splits a cohort across ballots; each unit of mass still casts a complete ranking. Let \(W=\sum_t q_t\mu_t\) be total voting weight. At stage \(i\), candidate \(a\)’s score is

\[ S_i(a;x)= \sum_{t\text{ sincere}}q_t\mu_t\,\mathbf 1[\operatorname{pos}_{\succ_t}(a)\leq i] + \sum_{t\text{ manipulator}}\sum_{\pi\in\mathcal L(C)} q_t x_{t,\pi}\,\mathbf 1[\operatorname{pos}_{\pi}(a)\leq i], \]

and the corresponding sum of positions \(P_i(a;x)\) uses the same terms with \(\operatorname{pos}(a)\) as an additional factor. Apply the paper’s SkS stages to these quantities, using \(S_i(a;x)>W/2\) for reaching a majority. The question is whether some feasible allocation \(x\) makes \(c^\star\) the unique SkS winner. There is no cost objective in the paper’s manipulation problem; the decision is whether such an allocation exists.

A plausible regime is a large federation or membership organization electing among four nominees, where delegates have standardized voting weights and repeated ranking-and-weight types. A coordinated bloc favors one nominee, and the chair or analyst asks whether it can make that nominee win alone. The relevant scale is many represented people but relatively few distinct types, \(\tau\ll N\). This is still the authors’ problem in its essentials: weighted coalition, SkS, favored candidate, unique-winner goal. The paper itself presents SkS as applicable beyond ballroom finals.

I expect this fixed-four-candidate mirror to be tractable. Once the masses are variables, every stage score and sum of positions is linear in \(x\). With four candidates, one can enumerate the constant number of possible SkS stage and tie-breaking paths; each path gives linear equalities and inequalities, hence an LP-feasibility problem. Strict comparisons can be handled by maximizing a slack variable. There are at most \(24\) ballot variables per manipulator type, so this suggests polynomial time in \(\tau\) and the input bit length. The contrast is apt: the paper proves hardness with four candidates, and its Partition-based argument puts the combinatorics in assigning weighted manipulators’ ballots. The continuum can remove that indivisibility while keeping the target and winning rule intact. A natural follow-up is whether the variable-candidate version is fixed-parameter tractable in \(m\), and how well a continuous solution can be rounded to a finite coalition.

The weak point is the regime, not the definition. Actual ballroom finals have few adjudicators, and in any application where manipulator types are mostly singletons, \(\tau\) grows with the population and the high-multiplicity rationale weakens. The mirror depends on a setting with many manipulators sharing complete problem-relevant types—especially voting weight—and on treating their cohort mass as divisible across ballots. That is a meaningful population continuation, but it is a real application assumption.

The case AGAINST (opponent, writing after the proponent)

The only computational anchor is Theorem 3, which proves SkS-CCWM NP-complete even with four candidates. Its strongest mirror is a continuous manipulation problem with a large cohort of manipulators grouped by voting weight, whose mass can be divided among complete ballots. That is a coherent population model: the type contains the weight and the common target, and SkS evaluates the resulting mass of rankings. For four candidates, each type has only 24 possible ballots, and the finite set of SkS stage and tie-breaking cases can be expressed through linear constraints. The proposed tractability is plausible.

The negative case is about where that model fits. The paper’s motivating ballroom finals have at most six couples, and it identifies no large, interchangeable manipulator cohort. The proposed federation is conceivable, but it is an added application scenario. Also, the paper’s Partition-based hardness uses binary voter weights. Instances with many distinct weights may have support growing with the coalition, so they offer little high-multiplicity compression. Restricting to a few repeated weight types removes much of the indivisibility that drives the reduction. That weakens the connection between the paper’s hardness result and the regime where the continuous model is most attractive.

Those points support a low-priority judgment, not the requested universal negative. A large cohort sharing a weight and target is a sensible object, and splitting its mass across ballots is a natural continuous version of the coalition’s choice. If that version is tractable, the result would show exactly how continuization changes a named complexity problem. Calling it uninteresting because the answer may be an LP would rely on a ground this task rules out. I cannot honestly defeat this anchor; the case against a worthwhile mirror is weak.
