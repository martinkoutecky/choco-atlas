The case FOR (proponent)

There is no numbered computational-complexity result in this paper, so there is no qualifying anchor under your rule. Proposition 1 is a classical stability, efficiency and lattice result cited from Shapley and Shubik; Proposition 2 cites Sasaki and Toda’s existence result for pessimistic agents. Neither classifies an algorithmic problem.

The strongest nearby result is Theorem 1, proved here, but it is an existence result, not a complexity result: for any fixed belief profile \(\lambda\) in which some pair has \(\lambda_{fw}(\mu)=\varepsilon>0\) at some matching \(\mu\) that does not pair them, there is a value profile \(A\) for which \((A,\lambda)\) has no stable outcome. Its construction uses unrestricted externalities. I can use it to motivate a computational question about stable-outcome existence, but I cannot honestly present it as a computational anchor.

The best prospective mirror I see is Type-Aggregate Stable Assignment Feasibility. Imagine a large labor market with many one-vacancy positions and workers: perhaps \(10^5\) or more on each side, but only tens or hundreds of distinct firm product types and worker skill types. Agents of a type share the relevant product or skill characteristics, externality parameters, and belief rule. That is a plausible high-multiplicity regime, and it follows the paper’s own complementary and substitutable firm example. It does not make matching “continuous” instead of the population: the assignment matrix records how much of each firm and worker type is matched.

Concretely, an instance gives finite type sets \(I,J\), positive rational masses \(p_i,q_j\) summing to \(1\) on each side, a rational affine value function \(\alpha_{ij}(x)\), and a rational affine belief function \(\lambda_{ij}(x)\in[0,1]\). A feasible mass assignment is a matrix \(x\geq0\) with row sums \(p_i\) and column sums \(q_j\). For each pair of types, let \(\pi_{ij}\) and \(\omega_{ij}\) be the minimum and maximum of \(\alpha_{ij}(y)\) over all feasible residual assignments \(y\). The deviating pair is treated as an infinitesimal tagged firm and worker, so it does not change the mass totals; \(\lambda_{ij}(x)\) describes their belief about the residual assignment after blocking. Their threshold is
\[ b_{ij}(x)=\lambda_{ij}(x)\omega_{ij}+ (1-\lambda_{ij}(x))\pi_{ij}. \]

The problem asks whether there are \(x\), nonnegative type-level profits \(u_i\), and nonnegative type-level salaries \(v_j\) such that \(u_i+v_j=\alpha_{ij}(x)\) whenever \(x_{ij}>0\), and \(u_i+v_j\geq b_{ij}(x)\) for every type pair. A solution is such a stable mass assignment and payoff vector. Common profits and salaries per type are an explicit standardized-contract regime; they make the question finite-dimensional while preserving the paper’s blocking-threshold idea. The question covers stable-outcome existence for this structured high-multiplicity version, not the paper’s efficiency or lattice claims, nor arbitrary externalities depending on every named agent’s identity.

I would tentatively expect this problem to be hard for continuum-specific reasons when the number of types is part of the input: the assignment support must be consistent with payoff equalities while the no-blocking thresholds depend on the aggregate assignment. That is a research hypothesis, not a result of this paper, and not a claim that the paper proves hardness transfers. Further questions include whether restrictions on the complementarity matrix or belief functions yield an efficient algorithm, and when finite repeated-type markets converge to this mass problem.

The soft spot is substantial: the paper’s externalities and beliefs are defined over individual matchings, while this mirror makes them depend on aggregate type assignments. A tagged infinitesimal pair also has no effect on the aggregate state, so preserving the paper’s post-block expectations requires an explicit residual-assignment interpretation. The authors might recognize this as a natural type-restricted population version—especially given their structured externality example—but the paper does not establish that they would accept it. The proposed question is therefore a plausible follow-up, not a mirror anchored in a named computational result.

The case AGAINST (opponent, writing after the proponent)

The strongest case against a mirror is that this paper has no named computational result to continuize. Proposition 1 is a classical stability result, and Proposition 2 is an existence result attributed to Sasaki and Toda. Theorem 1 is the paper’s own strongest candidate, but it is a sensitivity result: a single optimistic pair can make stable outcomes fail to exist for some value profile. It neither poses an algorithmic problem nor classifies its complexity. Turning stable-outcome existence into a decision problem is possible, but that would introduce the computational question rather than mirror one in the paper.

The proposed Type-Aggregate Stable Assignment Feasibility problem is coherent, but it changes the paper’s central mechanism. In the paper, a pair’s threshold depends on values across the possible post-block matchings of the named agents. In the type model, an infinitesimal tagged pair leaves the aggregate assignment \(x\) unchanged; the residual feasible assignments are consequently determined by the type masses, and the functions \(\alpha_{ij}(x)\) and \(\lambda_{ij}(x)\) supply a new aggregate-state rule. That rule may be a sensible model of a replicated labor market, but it is not a computational question already formulated by Theorem 1. To retain the paper’s unrestricted dependence on named-agent matchings, types would need to distinguish the agents whose responses differ, undermining the high-multiplicity reduction.

The strongest version of the mirror would use the paper’s own structured example: workers grouped by skill and firms grouped by complementarity profile, with stability tested over a fractional assignment of those types. That is a plausible follow-up and could yield an interesting feasibility problem. But it mirrors a structured example, not a computational result, and its affine aggregate payoff and belief functions are additional modeling choices. A conjecture that the resulting feasibility problem is hard does not supply the missing connection to a complexity question in the paper.

I would therefore reject this as a strong mirror of this paper: the computational target is absent, and the proposed target requires a consequential new model. The negative case is weaker if the standard is “no related problem is worth asking.” A replicated labor market with homogeneous firm and worker types is plausible, and the proposed mass-feasibility question is well-defined. I cannot honestly rule out its value; I can only say this paper does not establish it as the continuization programme’s next computational mirror.
