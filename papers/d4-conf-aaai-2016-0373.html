The continuous mirror question

Given a finite type set \(T\), rational masses \(\mu_t\) summing to \(1\), and for each type \(t\) either no approved coalition profile or one integral profile \(a^t\in\mathbb{Z}_{\ge 0}^{T}\) with \(a^t_t\ge 1\), choose nonnegative masses \(x_q\) of coalitions with integral type-count vectors \(q\). Require \(\sum_q q_t x_q=\mu_t\) for every \(t\), and maximize the mass of agents in approved coalitions, \(\sum_q x_q\sum_{t:a^t=q}q_t\).

The model it lives in

A society is a distribution \(\mu\) over roles, with each role having one approved integral coalition composition or none. Coalitions retain integral membership; mass is allocated among their profiles, and the objective is the total mass satisfied. It suffices to use the approved profiles and singleton profiles, giving at most \(2|T|\) columns.

What the mirror covers

The mirror covers Theorem 5’s welfare-maximization result for one approved coalition per agent; it does not cover the paper’s stability results or its other preference restrictions.

Open questions for a prover

  • How does the complexity change when a type may approve multiple coalition compositions?
  • What approximation or rounding guarantees relate this continuous optimum to finite replicated populations?

The case FOR (proponent)

My lead, and only anchor, is Theorem 5, proved in this paper: the decision version of maximizing social welfare is NP-complete even when each agent approves at most one coalition. Given a graph \(G=(V,E)\) and target \(k\), the reduction creates an agent for every vertex and edge. A vertex agent \(v\) approves only \(A_v=\{v\}\cup\{e\in E:v\in e\}\); edge agents approve nothing. A partition with at least \(k\) satisfied agents exists exactly when \(G\) has an independent set of size at least \(k\).

I would mirror the underlying welfare problem with Type-List Welfare\(_\infty\). An instance has a finite set \(T\) of agent types, rational masses \(\mu_t\geq 0\) summing to \(1\), and, for each type \(t\), either no approved coalition profile or one profile \(a^t\in\mathbb{Z}_{\geq 0}^{T}\) with \(a^t_t\geq 1\). A type-\(t\) agent approves a coalition exactly when its vector of type counts is \(a^t\). An outcome divides the population into finite coalitions, each with an integral type-count vector \(q\); mass may be split among different coalition profiles. Let \(x_q\geq0\) be the number of coalitions of profile \(q\) per unit of population. Feasibility requires \(\sum_q q_t x_q=\mu_t\) for every \(t\). The task is to return a feasible allocation maximizing \(\sum_q x_q\sum_{t:a^t=q}q_t\), the mass of agents in approved coalitions.

This question keeps coalition formation and approval as the paper studies them; it makes the population continuous while leaving each coalition’s membership integral. For this one-profile-per-type restriction, it is an LP: it suffices to use the profiles \(a^t\) and singleton profiles \(e_t\). Any other coalition profile pleases nobody, and replacing it by singletons cannot reduce welfare. There are at most \(2\tau\) columns, so the mirror is solvable in polynomial time in the number of types and the input bit length. I expect Class A: the discrete hardness can disappear when agents of each type may be divided fractionally among coalition configurations.

The regime is a large organization or repeated project system with many participants in each role, where everyone in a role has the same ideal team composition. For example, principal-role agents may approve a team containing one principal and one representative of each required liaison role. The number of people can be \(K\tau\) for large \(K\), with only \(\tau\) distinct role profiles. In the paper’s reduction, make each vertex a principal type and each edge a liaison type. A principal type approves a profile containing one principal and one liaison for each incident edge; liaison types approve no team. With equal type masses, the variables \(x_v\) for principal teams satisfy \(x_u+x_v\leq\mu_e\) for every edge \(e=\{u,v\}\), and the welfare objective is to maximize \(\sum_v x_v\). The independent-set conflict remains visible in these capacity constraints, but the continuous problem optimizes their fractional version.

The weakest point is that Theorem 5’s approved coalitions name particular agents, whereas my mirror specifies approved type compositions. Its reduction has one agent per role, so it does not itself exhibit the high-multiplicity regime. The mirror is the natural type-based version of the same welfare question, not a claim that the theorem already solves or directly implies anything about that version. That change is defensible under the programme’s definition of a type as a complete preference profile, though an author or referee could reasonably ask whether composition-based approval captures the intended application.

This mirror covers Theorem 5’s welfare-maximization result, not the paper’s stability results. It also suggests asking how the picture changes with several approved profiles per type, what guarantees rounding a continuous optimum back to a finite replicated population, and whether stability concepts admit useful mass-based counterparts.

The case AGAINST (opponent, writing after the proponent)

The strongest objection to the sole anchor, Theorem 5, is about what its input represents. In the reduction, a vertex agent approves one coalition containing that particular vertex and its incident edge agents. The graph’s incidence pattern is written in named-agent membership. Preserving those preferences literally gives each vertex and edge a distinct type, so the theorem itself supplies no repeated population types.

The proposed type-composition model repairs that problem by changing the primitive: agents approve a coalition with a specified count of each role, rather than a set of named people. That is a coherent high-multiplicity model, but its motivating scenario needs one role for each graph vertex and edge, replicated many times, with agents free to form coalitions across replicas. If replicas are separate projects, project identity belongs in the type and the multiplicity disappears; if they are pooled, the setting is a particular shared-resource system rather than an ordinary replication of the original instance. The model is plausible, but the paper does not establish that this is a natural regime for its one-list result.

A broader type-profile version could allow several approved compositions per type, or succinct approval predicates over compositions. That may be a worthwhile problem, but the result then depends on the chosen language for those predicates. Theorem 5 does not identify that language or supply a further computational question beyond its one-approved-coalition case. This makes the anchor a weak basis for a larger continuization programme.

That is the best negative case I can make, and it does not defeat the mirror outright. The proposed role-composition model is well-defined, the repeated-network scenario is defensible, and the resulting LP is a clean tractable mirror. Since the programme accepts such type-level co-modelling and treats a tractable answer as a valuable result, I cannot honestly conclude that no worthwhile mirror survives. Theorem 5 remains a viable anchor.
