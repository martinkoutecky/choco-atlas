The continuous mirror question

Given a finite type set \(T\), rational type-mass vector \(\mu\), and rational piecewise-linear positively homogeneous component-value function \(V\), does the greedy selection of feasible profiles \(x\le r\) maximizing \(V(x)/\|x\|_1\), with residual mass \(r\), generate the unique groupwise farsightedly stable set of measurable networks under egalitarian per-capita payoffs, and can its component-profile decompositions be computed?

The model it lives in

An atomless population with finitely many types \(t\in T\) and masses \(\mu_t\); measurable undirected networks whose positive-mass connected components have type-mass profiles \(x\) and value \(V(x)\); each member of a component receives \(V(x)/\|x\|_1\). Measurable group deviations add links within the coalition and delete links incident to it, with farsighted moves evaluated against terminal payoffs. Represent the output by component-profile decompositions and connected network realizations.

The objection that survived

The stability conditions quantify over measurable network relations, and the resulting deviation paths may not be captured by component mass profiles, so the proposed greedy method does not yet establish a finite algorithm.

fatal: False

What the mirror covers

The mirror covers Propositions 1 and 2 for component-additive values under the componentwise egalitarian rule; it leaves pairwise myopic stability and Section 5’s alternative stability concepts aside.

Open questions for a prover

  • Does the finite-player uniqueness characterization in Proposition 1 survive for measurable group deviations in the atomless network model?
  • Are stable-set membership and external reachability determined by component mass profiles, so that a finite profile-based algorithm suffices?

The case FOR (proponent)

The strongest honest case is narrow: this paper has no named NP-hardness or polynomial-time complexity theorem. It does have named algorithmic characterizations of a stable set, which give a concrete problem to continuize. They make this a possible algorithmic mirror, but not a direct test of whether discrete hardness disappears.

A plausible regime is a large collaboration or production network with a fixed, small number \(\tau\) of network-relevant agent types. A type could encode an agent’s discipline, sector, and other payoff-relevant attributes; agents of the same type are interchangeable, and their mass \(\mu_t\) is their fraction of the population. The population is atomless, with type masses \(\mu_t\), while links remain the agents’ decisions.

Here is a specific model for that mirror. Let \(T\) be finite, \(\mu\in\mathbb{Q}_{\ge 0}^{T}\) with \(\sum_t\mu_t=1\), and let \(V(x)\) be a rational, piecewise-linear, positively homogeneous value function for a connected component with type-mass vector \(x\). This is a deliberate subclass of the paper’s component-additive value functions: a component’s value depends on its type composition, not its internal wiring. A network is a symmetric measurable graph on the population, with countably many positive-mass connected components covering the population almost everywhere. A component with mass vector \(x\) has total value \(V(x)\); each member receives \(V(x)/\|x\|_1\), as under componentwise egalitarian allocation.

Group deviations are measurable coalitions that can add links within the coalition and delete links incident to it. For a farsighted path, each moving coalition must prefer the path’s terminal network to its current one; for a myopic path, it must prefer the next network. Define stable sets by the paper’s deterrence, external-reachability, and minimality conditions, replacing finite coalitions with measurable ones and “some deviator” with a positive-measure subset of deviators. The computational task is to find a network in the relevant stable set, represented by its component mass profiles and a connected realization of those components.

My lead is Farsighted Mass-Network Stability. Its anchor is Proposition 1, proved in this paper: for every component-additive value function \(v\), the set \(G_v\) produced by repeatedly choosing, from the remaining players, a network component maximizing value per capita and removing its members is both the unique pairwise farsightedly stable set and the unique groupwise farsightedly stable set under the componentwise egalitarian rule. The proposition allows multiple outputs when there are ties. The continuous question is whether the atomless version has a corresponding unique groupwise farsightedly stable set, and whether a stable network can be found by repeatedly choosing a feasible mass vector \(x\le r\) maximizing \(V(x)/\|x\|_1\) for the residual mass \(r\), then removing \(x\). A solution is a finite component-profile decomposition of \(\mu\) and a network realizing it that belongs to the stable set. Positive homogeneity makes the greedy candidate concrete: a maximizing type mix can be scaled until at least one residual type is exhausted, suggesting at most \(\tau\) selections. That suggests a Class A route for this restricted model: optimize over the finitely encoded linear pieces at each step. Whether that candidate really characterizes farsighted stability in the atomless network is the question, not a result of the paper.

A distinct but closely related question, Myopic Mass-Network Stability, mirrors Proposition 2, also proved here. It states that for every component-additive \(v\), \(G_v\) is the unique groupwise myopically stable set under the componentwise egalitarian rule. Its continuous counterpart uses the same instance and payoff model, but myopic groupwise paths, and asks for a network in the unique stable set. It has the same provisional Class A expectation for the same polyhedral greedy computation, while leaving open whether the continuous stability argument survives.

These anchors cover the paper’s central component-additive, componentwise-egalitarian results. They do not cover pairwise myopic stability, which the paper shows can differ, or its other stability concepts. They also do not establish a complexity class: the paper’s greedy characterization does not give a running-time bound for an encoded value function.

The weakest point is the atomless deviation model. A single agent has zero mass and cannot change a graphon, so the groupwise version is the natural one to mirror; the pairwise version has no direct atomless analogue. More fundamentally, the paper’s finite-player proof does not establish that a mass-based greedy construction yields a unique stable set. That gap is a serious open question, but the proposed problem keeps the authors’ central ingredients—network components, farsighted or myopic deviations, egalitarian per-capita payoffs, and stable-set computation—rather than replacing the network problem with an unrelated optimization task.

The case AGAINST (opponent, writing after the proponent)

The strongest objection is that “Farsighted Mass-Network Stability” and “Myopic Mass-Network Stability” are two versions of the same finite-player characterization, not two independent computational results. Propositions 1 and 2 identify the same \(G_v\), built by repeatedly selecting a per-capita-maximizing component from the remaining players. The paper gives a constructive characterization, but no encoded computational problem or complexity bound: it does not specify how \(v\) is represented or the cost of evaluating it. So these propositions do not themselves provide a complexity landscape to continuize.

The proposed mirrors also run into a structural issue. A finite network records exact links between identifiable vertices. In an atomless population, a link between two individuals has measure zero, so changing it leaves a measurable network unchanged. That removes the pairwise deviation primitive behind Proposition 1. Groupwise deviations can be made meaningful by letting positive-measure coalitions rewire links, but that is a substantive model choice: it turns a finite coalition’s link changes into changes to a positive-measure set of edges. It does not follow from the paper’s definition.

For Proposition 2, the same choice is needed. Type masses and component mass profiles generally do not determine which links exist or which paths of deviations are possible. Retaining that information calls for a representation of the network relation, such as a measurable graph kernel. Arbitrary kernels are not finite algorithmic inputs. Restricting to finitely many blocks gives a finite representation, but then agents in a block cannot be split into different network positions without refining the blocks. Making those positions part of the types risks making the type space grow with the population.

The proponent’s piecewise-linear \(V(x)\) avoids much of this difficulty by making component value depend only on type composition. That may define a useful continuous coalition-partition problem, but it removes wiring from the payoff model and leaves network formation to the deviation definition. A model in which coalitions are simply allowed to regroup mass into components would study a different object from the paper’s link-based farsighted and myopic stability. So the proposed greedy computation does not yet establish a continuous mirror of either anchor.

That is the best negative case I can make, and it is not airtight. Large organizations with many interchangeable workers or collaborators are plausible high-multiplicity settings, and a carefully specified block-network or graph-limit model could make one of these questions worth studying. I would reject the two mirrors as currently under-specified computational problems; I would not claim that no worthwhile continuous mirror exists in any scenario.
