The case FOR (proponent)

I see one credible but narrow mirror in the paper: the MLE of the ground truth when voter reliabilities and prior parameters are known. The paper has no named NP-hardness or complexity-class result. My anchor is Theorem 1, proved here. It says that for a fixed approval profile, known voter parameters \((p_i,q_i)\), prior parameters \(t_j\), and size bounds \([l,u]\), a maximum-likelihood ground truth consists of the top \(k\) alternatives by weighted approval score for some \(k\in[l,u]\). It further specifies how many must come from the alternatives scoring above, at, or below the threshold \(\tau_n=\sum_i\log((1-q_i)/(1-p_i))\). This is an exact characterization the paper uses to compute the estimator—not a formal claim that the problem is in P.

A continuous version fits a large multi-label annotation project. Suppose there are \(N\) annotators and \(\tau\) competence types. Type \(r\) has mass fraction \(\mu_r\), with \(\sum_r\mu_r=1\), and all its members share the same known approval probabilities \((p_r,q_r)\). For each task \(z\) and alternative \(a\), let \(x_{rza}\) be the fraction of type \(r\) that approved \(a\). A type is the annotator’s complete behavior-relevant description in the model; ballots can still differ because they are noisy draws. A plausible regime would be a very large pool of annotators working on the same set of tasks, grouped into a modest number of shared training or workflow cohorts. The paper’s 76-person experiment is not itself a high-multiplicity regime, but its crowdsourcing setting provides a natural larger-scale scenario.

Call the resulting problem Continuous Multi-instance Epistemic Approval MLE. Its input is the alternatives \(A\), tasks \(z=1,\ldots,L\), size bounds \([l,u]\), rational prior parameters \(t_a\), rational type masses \(\mu_r\), known rational reliabilities \((p_r,q_r)\), population size \(N\), and observed approval fractions \(x_{rza}\). For each task, choose a ground-truth set \(S_z\subseteq A\), with \(l\leq |S_z|\leq u\), maximizing the joint log posterior
\[ \sum_{z=1}^{L}\left[\log \widetilde P_t(S_z)+N\sum_{r=1}^{\tau}\mu_r\sum_{a\in A} \left(\mathbf 1_{a\in S_z}\big[x_{rza}\log p_r+(1-x_{rza})\log(1-p_r)\big] +\mathbf 1_{a\notin S_z}\big[x_{rza}\log q_r+(1-x_{rza})\log(1-q_r)\big]\right)\right], \]
where \(\widetilde P_t\) is the paper’s independent prior conditioned on the size bounds. A solution is a maximizing tuple \((S_1,\ldots,S_L)\), including ties.

For each task, the change in log posterior from including \(a\) is
\[ g_{za}=\log\frac{t_a}{1-t_a} +N\sum_{r=1}^{\tau}\mu_r\left[x_{rza}\log\frac{p_r}{q_r} +(1-x_{rza})\log\frac{1-p_r}{1-q_r}\right]. \]
So one can sort these \(m\) gains and choose the best prefix of a permitted size. I expect this mirror to be Class A: it has essentially the same structure as Theorem 1, with fractional mass replacing voter counts. The computational question for a prover is whether the exact maximizing tuple can be found in time polynomial in \(m,\tau,L\), and the binary input length. Sorting gives a polynomial number of score operations; exact bit complexity for comparing the resulting weighted sums of logarithms deserves explicit treatment.

The authors should recognize this as the population relaxation of their known-parameter estimation problem in Section 4.1: it keeps the likelihood objective, the cardinality prior, and discrete ground-truth sets intact. Its scope is that subproblem only. I would not claim a mirror of the full AMLE procedure or of the paper’s experiments.

The weak point is that the most natural cohorts may be too coarse for the paper’s individualized, unknown voter reliabilities. This is a genuine restriction, though the known-parameter subproblem is an explicit part of the paper and shared-competence annotation cohorts are plausible. It also means the mirror is a modest computational result: the paper’s named theorem is a structural characterization, not a hardness result, and the continuous version may be easy for much the same reason. Further questions include whether the unknown-reliability AMLE has a useful continuous analogue, how its convergence claim behaves with fractional type masses, and how the continuous optimizer relates to finite high-multiplicity datasets.

The case AGAINST (opponent, writing after the proponent)

The strongest case against this anchor is that the paper proves no complexity classification. Theorem 1 gives an exact characterization of the known-parameter MLE; it does not state a running-time bound or analyze a hard computational problem. The main algorithm, AMLE, is a different matter: its convergence theorem gives no polynomial bound on the number of iterations. So the paper offers little of the complexity landscape ChoCo is meant to chart.

That objection does not defeat the proposed mirror, though. Theorem 1 is still a numbered result about computing an estimator, and the known-parameter subproblem is explicit in the paper. A large annotation pool with shared competence cohorts is plausible. More carefully, the continuous input could give each cohort’s mass distribution over realized ballot profiles across tasks. The per-task approval fractions \(x_{rza}\) are sufficient statistics for the paper’s stated likelihood, so this repairs the concern that competence types alone do not specify observed votes.

With that repair, the continuous question remains recognizable: maximize the population log likelihood over ground-truth sets. Integrating voter contributions produces the same per-alternative gains \(g_{za}\); the optimizer is still found by sorting gains and checking permitted set sizes. This is a modest extension, and exact comparisons of sums of logarithms of rationals need a precise bit-complexity treatment. But neither point shows that the question is ill-posed or that the authors would reject it.

So I cannot honestly defeat this anchor universally. Its weakness is that the continuous formulation appears to inherit a very direct solution from Theorem 1, leaving little algorithmic terrain to explore. But the programme explicitly treats an easy answer as a valid result, and this is a sensible high-multiplicity annotation regime. The negative case is therefore weak here: I can argue that the mirror is narrow and computationally undemanding, but not that no worthwhile continuous mirror exists.
