The continuous mirror question

Given \(N\), \(k\), rational type masses \(\mu_t\) with \(N\mu_t\in\mathbb{N}\), and Robertson–Webb oracles for \(\tau\) normalized valuation types \(v_t\), determine the minimum worst-case expected number of type-oracle queries for a \(k\)-round protocol with success probability at least \(2/3\) to partition \([0,1]\) into \(N\) contiguous intervals and assign one to each agent so that every type-\(t\) agent values its interval at least \(1/N\). Each query to a type oracle is reusable for all agents of that type; characterize the complexity in \(N\), \(k\), \(\tau\), and \(\mu\).

The model it lives in

A type-compressed Robertson–Webb model with \(N\mu_t\) agents of each type \(t\): oracle answers are shared within each type, and the protocol must output \(N\) individually assigned contiguous pieces worth at least \(1/N\) to their recipients.

What the mirror covers

The mirror covers the cake-cutting query bounds in Appendix D.1, Proposition 1, and Appendix D.2, Corollary 5, including the sorting reduction used for the lower bound. It leaves the ordered and unordered search results outside its scope.

Open questions for a prover

  • For fixed \(\tau\), what is the optimal \(k\)-round query complexity above the \(\Omega(N)\) output-size floor?
  • For which growth rates of \(\tau(N)\) does the \(\Omega(kN^{1+1/k})\) lower bound persist, and can matching support-sensitive protocols be given?

The case FOR (proponent)

The strongest case is in the paper’s cake-cutting results. They have a natural high-multiplicity regime: a very large population drawn from a small set of standardized valuation profiles. Here “continuous” describes the population distribution over valuation types; the fact that the cake is divisible is incidental to the mirror.

Let \(T\) be a finite set of valuation types, each with a normalized value density \(v_t\), and let \(\mu_t\in\mathbb{Q}_{>0}\) be the fraction of the population of type \(t\), with \(\sum_{t\in T}\mu_t=1\). For a population scale \(N\) such that \(N\mu_t\) is integral, the instance has \(N\mu_t\) identical agents of type \(t\). A type is complete for this problem: its agents have the same valuation function. The input gives the type masses and access to each type’s Robertson–Webb cut and evaluation oracle. One query to a type oracle serves all agents of that type.

The protocol runs in \(k\) rounds and must output a partition of \([0,1]\) into \(N\) contiguous intervals, assigned to the individual agents, with each agent of type \(t\) receiving an interval \(I\) satisfying \(V_t(I)\ge 1/N\). Its cost is the number of distinct type-oracle queries; its objective is to minimize worst-case expected cost at the required success probability. This preserves the paper’s individual proportionality and contiguity requirements. The co-modification is the \(1/N\) per-capita entitlement, which is necessary to retain the original fairness question as population scale grows.

My lead is the lower-bound mirror, anchored in Appendix D.2, Corollary 5. It says that any \(k\)-round cake-cutting algorithm returning a contiguous proportional allocation for \(n\) agents with constant success probability must use \(\Omega(k n^{1+1/k})\) queries in expectation. The paper derives this from Alon and Azar’s cited lower bound for sorting with rank queries and its own round-preserving reduction; the reduction is proved in the paper, while the sorting lower bound is cited.

The continuous question is: High-Multiplicity Cake Query Complexity. Given \((T,\mu,(v_t)_{t\in T},N,k)\) as above, determine the minimum number \(Q_k(N,\mu)\) of distinct type-oracle calls needed to produce the required allocation, or prove matching upper and lower bounds for it. In particular, does the paper’s \(\Omega(kN^{1+1/k})\) lower bound hold when the support size \(\tau=|T|\) stays small as \(N\) grows? A solution is a query protocol meeting the allocation guarantee, or a lower bound ruling such protocols out.

There is already a useful boundary case: if \(\tau=1\), query \(Cut_t(j/N)\) for \(j=1,\ldots,N-1\) in one round and give each resulting interval to one agent. This uses \(N-1\) queries and gives every agent value \(1/N\). Thus the superlinear lower bound does not extend to that homogeneous regime. I expect the low-\(\tau\) problem to be tractable in the sense that the general lower bound dissolves as types become reusable; for growing \(\tau\), the problem is to locate the boundary. When \(\tau=N\) and every type occurs once, the original lower bound transfers directly. That contrast is evidence for studying the mirror: the outcome depends on the instance regime, not on cake cutting as a whole.

The upper-bound mirror is anchored in Appendix D.1, Proposition 1, proved in the paper. It states that a deterministic \(k\)-round protocol computes a contiguous proportional allocation for \(n\) players with \(O(k n^{1+1/k})\) Robertson–Webb queries. In the type-mass setting, the question is whether one can give a \(k\)-round protocol with that budget when queries to identical types are reusable, and sharpen the bound as a function of \(N\), \(k\), and \(\tau\). A solution is again an actual protocol producing individual contiguous pieces. The paper’s algorithm supplies the \(O(kN^{1+1/k})\) bound immediately; the interesting expected result is a sharper bound when \(\tau\ll N\).

The authors should recognize both as their cake-cutting problem: the oracle model, round restriction, proportionality, and contiguous individual pieces are all retained. A plausible setting is a large administrative allocation in which many residents share one of a small number of standardized valuation profiles. The mass \(\mu_t\) records each cohort’s population share, and shared type information is exactly what makes the high-multiplicity regime meaningful.

This case covers the paper’s proportional cake-cutting query bounds in Appendices D.1–D.2, not its unordered or ordered search results. Those search problems distribute uncertainty over a hidden location; that would continuize uncertainty rather than the society.

The weakest point is that this is a high-multiplicity family indexed by \(N\), rather than a fully scale-free continuum protocol with no individual population size. That scale is needed to state what each agent must receive and to output the individual intervals. Also, the paper’s hard lower-bound instance relies on a round-preserving reduction from sorting and may use many distinct valuation profiles; it does not establish hardness for small \(\tau\). The proposed mirror is strongest as a precise question about where that lower bound stops applying, not as a claim that its hardness already survives in the continuum.

The case AGAINST (opponent, writing after the proponent)

The strongest objection is that proportional cake cutting has no nondegenerate, scale-free population limit that preserves the paper’s output contract. With \(N\) players, the guarantee is \(V_i(A_i)\ge 1/N\), and the protocol must output \(N\) individually assigned contiguous intervals. As \(N\) tends to infinity on a fixed cake, the entitlement tends to zero; under the paper’s nonatomic valuations, zero-value singleton pieces then satisfy the limiting inequality. Keeping a positive entitlement instead would require uncountably many disjoint positive-value intervals, which cannot partition a finite cake.

A cohort distribution \(\mu\) does not resolve that mismatch. Giving each type one aggregate piece, or describing an average allocation to its mass, drops the requirement that every individual receive a contiguous proportional piece. To retain that requirement, the mirror must also retain a finite scale \(N\) and produce the \(N\) intervals. The same \(\mu\) can describe populations at different scales, so the question becomes \(Q_k(N,\mu)\). In the Robertson–Webb model, an allocation into \(N\) positive-value intervals requires \(N-1\) internal cut points. The mirror therefore carries an output-size floor that grows with the finite population.

This weakens the Proposition 1 upper-bound anchor. Expanding the types into \(N\) agents gives the paper’s \(O(kN^{1+1/k})\) protocol, while a single valuation type can be divided with \(N-1\) quantile cuts in one round. Reusing a type’s oracle answers can reduce repeated valuation queries, but it cannot avoid producing the individual boundaries while preserving the paper’s guarantee. A sharper bound in \(N\) and \(\tau\) could be a sound finite-population query-complexity problem; it would not establish a scale-free population-continuous allocation result.

The same issue reaches Corollary 5. Its sorting reduction gives a genuine query lower bound, but the proposed small-\(\tau\) question asks how that bound changes when many agents share valuations. For \(\tau=1\), the quantile protocol already removes the superlinear cost. Locating the transition as \(\tau\) grows may be interesting, but the resulting object still has \(N\) individual outputs and a cost floor of \(N-1\). Compressing the output to type-level pieces would change the fairness and contiguity requirements that make Corollary 5 a cake-cutting result.

This is a narrow negative case, not a decisive rejection of the cohort formulation. The paper has named computational query-complexity results, and a large population with a small number of standardized valuation profiles is plausible. If ChoCo treats an \(N\)-indexed high-multiplicity family with individual outputs as a worthwhile mirror, the proposed question survives. The objection is that its value comes from studying finite-\(N\) query complexity across support sizes; the actual continuum either erases individual proportionality or changes the allocation being computed.
