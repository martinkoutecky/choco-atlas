What the mirror covers

Theorem 3.1, Theorem 3.3, and Theorem 4.1 are the results raised as possible anchors; the paper's other numbered results likewise concern existence or nonexistence rather than computation.

The case FOR (proponent)

The honest positive case is that this paper suggests a possible high-multiplicity research direction, but it contains no named computational result to anchor the required mirror. Its named results concern existence or nonexistence of envy-free divisions, proved with topological arguments. The paper does not classify an algorithmic problem as being in \(\mathrm{P}\), NP-hard, FPT, or similar.

For example, Theorem 3.1, proved here, says that when \(r\) is prime or \(r=4\), every closed, covering, equivariant preference system on \(\mathcal C_1\) admits an envy-free division. Theorem 3.3, also proved here, gives preference systems with no such division when \(r\) is neither prime nor \(4\). Theorem 4.1 proves an existence result for prime-power \(r\), reproving a result of Avvakumov and Karasev. These are meaningful anchors for a study of existence, but none is a computational-complexity anchor of the kind this task requires.

A possible adjacent question would take a large population with a small number \(\tau\) of complete preference types, represented by a distribution \(\mu\), and ask for a mass assignment to preferred shares. But the paper’s model has \(r\) players and \(r\) boxes, with preference systems defined over cuts and allocations. Passing to a continuum of players would require specifying how the cake shares and configuration space scale too. That is a substantial new model, not a direct continuous-population mirror of one of the paper’s named computational results.

So I cannot honestly give a lead continuous problem “per anchor” here: there are no qualifying anchors. The paper’s cake is continuous, but its society remains finite; that is outcome-space continuity, not population continuization.

The case AGAINST (opponent, writing after the proponent)

The strongest case against a mirror is that there is no computational result here to continuize. Theorem 3.1 is a topological existence theorem for every admissible preference system; Theorem 3.3 constructs preference systems for which envy-free division fails; Theorem 4.1 proves another existence theorem, reproving an earlier result. None defines an algorithmic problem or gives a complexity classification. That matters under ChoCo’s remit: a new theorem about existence would not fill the computational gap the programme is meant to study.

One could turn any of these into a search problem—given preferences, find an envy-free division. But the paper permits arbitrary closed preference sets over a configuration space. It supplies no finite representation or query model for those sets, so the search problem has no defined input size or running time. A stronger proposal might encode preferences by formulas or finite utility descriptions. That could yield a computational fair-division problem, but its complexity would depend on the added representation and assumptions, not on the paper’s theorems.

The population limit also strains the model at its core. Here \(r\) simultaneously counts players, boxes, and cake intervals; it also determines the symmetric group and configuration spaces used in the proofs. With a fixed finite set of preference types and growing \(r\), one would need a coherent family of preference descriptions on configuration spaces that change with \(r\). The paper provides no such family. And if each of a continuum of agents must receive an individual piece of a finite cake, ordinary bounded value densities give each person a zero-measure share. Grouping people by type and assigning each group a positive share, or giving individuals lotteries over pieces, can avoid that collapse, but changes the one-person/one-piece envy-free criterion into a type-level or probabilistic allocation problem.

The same objections apply to Theorem 3.3: its negative result is an existence construction from an equivariant map, not a computational hardness result on society inputs. Recasting it as a decision problem would again require a finite input model for preferences. Theorem 4.1 has the same issue as Theorem 3.1, compounded by being a new proof of an existing existence result.

I cannot rule out that a suitably restricted, finitely encoded continuum-agent cake model would be worthwhile, or that these authors would recognize it as a related problem. That is the weak point in a universal negative. But it would be a new computational fair-division model, with a different allocation object and preference representation—not a continuous mirror of any named computational result in this paper.
