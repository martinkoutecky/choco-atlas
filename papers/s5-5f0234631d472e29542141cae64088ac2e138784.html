The continuous mirror question

Given candidates \(P\), a horizon \(\ell\), finitely many approval-schedule types \(\theta\) with rational masses \(\mu_\theta\) summing to \(1\), and a rational threshold \(B\), does there exist an outcome \(\mathbf{o}\in P^\ell\) with \(\util_\mu(\mathbf{o})=\sum_{r=1}^{\ell}\sum_{\theta\in T}\mu_\theta\mathbf{1}[o_r\in A_{\theta,r}]\ge B\), such that for every nonzero coalition mass vector \(\mathbf{a}\) with \(0\le a_\theta\le\mu_\theta\) and every round set \(R\subseteq[\ell]\) on which all types with \(a_\theta>0\) have a common approved candidate in each round, the number of rounds in \(R\) whose chosen candidate is approved by positive coalition mass is at least \(\left\lfloor |R|\sum_{\theta\in T}a_\theta\right\rfloor\)?

The model it lives in

A finite support of complete approval schedules with rational population masses; one indivisible candidate is selected each round, and welfare is mass-weighted. PJR is extended to every coalition formed by taking any amount of each type, with integer round entitlements given by the floor of round count times coalition mass.

The objection that survived

The existing type and round-profile FPT formulation may carry over with little change, limiting algorithmic novelty; this bounds the mirror’s contribution but does not invalidate it.

fatal: False

What the mirror covers

Mirrors the PJR-UTIL hardness slice of Theorem 4.3 through its X3C construction; it does not establish continuous counterparts for the price bounds, the other axioms, or the parameterized results.

Open questions for a prover

  • Does an exact FPT algorithm parameterized by support size \(\tau\) and number of round profiles \(q\) extend to arbitrary binary-encoded rational masses?
  • What approximation guarantees are possible for maximizing \(\util_\mu\) subject to continuous PJR?

The case FOR (proponent)

The most convincing mirror is the welfare problem under PJR, with the population—not the rounds or outcomes—made continuous.

Take a finite support \(T\) of complete approval schedules. A type \(\theta\) has approval set \(A_{\theta,r}\subseteq P\) in each round \(r\), and mass \(\mu_\theta\in\mathbb{Q}_{\ge 0}\), with \(\sum_{\theta\in T}\mu_\theta=1\). In the static instances used below, a type is just a fixed approval set. A coalition can contain any amount \(a_\theta\in[0,\mu_\theta]\) of each type; its mass is \(\alpha=\sum_\theta a_\theta\). It agrees on a set of rounds \(R\) if, in each such round, the approval sets of all types represented with positive mass have a common candidate.

Keep the paper’s indivisible decision: choose one candidate per round, allowing repeats. Let \(\sat_{\mathbf a}(\mathbf o)\) count the rounds in which the chosen candidate is approved by positive mass of coalition \(\mathbf a\). My proposed problem, PJR-UTIL\(_\infty\), takes \(P\), the horizon, the rational type masses and schedules, and a rational threshold \(B\). It asks whether there is an outcome \(\mathbf o\in P^\ell\) satisfying, for every coalition \(\mathbf a\) and every set \(R\) on which it agrees,
\[ \sat_{\mathbf a}(\mathbf o)\ \ge\ \left\lfloor |R|\alpha\right\rfloor, \]
and achieving per-capita welfare
\[ \util_\mu(\mathbf o) =\sum_{r=1}^{\ell}\sum_{\theta\in T}\mu_\theta\, \mathbf{1}[o_r\in A_{\theta,r}] \ \ge B. \]
The floor preserves the paper’s discrete representation units: rounds remain indivisible, while population mass and welfare are fractional. That is the co-modification needed to lift their PJR question to a distribution over voter types.

This is a plausible setting for repeated exposure planning on a large platform: millions of users have stable interests in creators, job postings, or product categories, and the platform plans a sequence of promotions in batches. Users sharing an approval schedule form a type; mass is their fraction of the audience; the support size \(\tau\) counts distinct schedules. The X3C construction below has \(O(q)\) types, but each cohort can be replicated \(K\) times for arbitrarily large \(K\) without changing its mass. Thus population size can greatly exceed the number of types.

My anchor is Theorem 4.3, proved in this paper by a reduction from X3C. It states that for each \(\Phi\in\{\mathrm{JR},\mathrm{PJR},\mathrm{EJR},\mathrm{EJR+}\}\), \(\Phi\)-UTIL is NP-complete even with static preferences and at most four approvers per candidate. The PJR instance of the underlying problem asks whether a temporal election and integer threshold \(B\) admit a length-\(\ell\) outcome that satisfies PJR and has utilitarian welfare at least \(B\). I use the PJR slice of that theorem; the other axioms need not be mirrored to make the case.

The same X3C gadget gives a weighted-type hardness argument for PJR-UTIL\(_\infty\). Write the X3C universe as \(3q\) elements and set \(n=9q+4\), \(\ell=3q+2\), as in the paper’s reduction. Give each \(x_e\) type mass \(1/n\), each combined \(y_e^1,y_e^2\) type mass \(2/n\), and the dummy type mass \(4/n\). These masses sum to one. In the reduction, every cohesive group lies among the approvers of some candidate, so its mass is at most \(4/n\), and
\[ \left\lfloor \ell\cdot\frac{4}{n}\right\rfloor=1. \]
Each element group \(G_e=\{x_e,y_e^1,y_e^2\}\) has mass \(3/n\), so it has a one-round entitlement as well:
\[ \left\lfloor \ell\cdot\frac{3}{n}\right\rfloor=1. \]

If the X3C instance has an exact cover, select its \(q\) set candidates and select \(z\) in the remaining rounds. Every \(x_e\) is represented by a selected set candidate, and the dummy type by \(z\). Any quota-positive cohesive group agreeing on \(z\) or a set candidate is therefore represented. A group agreeing on \(p_e\) that contains positive mass of \(x_e\) is represented too; if it contains no \(x_e\), its mass is at most \(2/n\), whose entitlement is zero because \(\lfloor 2\ell/n\rfloor=0\). So this outcome satisfies the continuous PJR constraints, including for partial cohorts.

Conversely, set the welfare threshold to \((4\ell-q)/n\). Since selecting \(z\) gives per-round welfare \(4/n\) and every other candidate gives \(3/n\), any outcome meeting the threshold can use at most \(q\) non-\(z\) rounds. Each \(G_e\) must nevertheless be represented, and that requires selecting either \(p_e\) or a set candidate containing \(e\). A set candidate can represent at most three elements; \(p_e\) represents one. Representing all \(3q\) elements with at most \(q\) such rounds forces exactly \(q\) set candidates covering distinct elements—an exact cover. Thus the continuous decision problem is NP-hard, and its exact welfare-maximization counterpart is NP-hard too.

I expect this mirror to be hardness-transfer territory: the X3C combinatorics live in the candidate/set system, and the reduction survives mass weighting. The authors could recognize it as their problem because it retains the temporal candidate sequence, utilitarian objective, and group-based PJR constraint, while replacing headcounts by type masses. It does not simplify the task to outcome-space fractionality.

This mirror covers the PJR-UTIL hardness slice of Theorem 4.3, not the paper’s price bounds or every temporal proportionality axiom. Natural next questions are whether PJR-UTIL\(_\infty\) is tractable when \(\tau\) or the number of round profiles is small, and what approximation guarantees its maximization version permits.

The weakest point is the quota convention. Extending the paper’s floor entitlement to real coalition mass is faithful to indivisible round entitlements, but it is not the only possible continuum definition. A definition using unfloored fractional entitlements would impose different constraints on small cohorts, and this particular hardness argument would not establish hardness for that variant. The case here is for the stated, type-mass version of their PJR problem.

The case AGAINST (opponent, writing after the proponent)

The strongest objection is that this particular mirror adds little new structure. In the proposed model, choosing an outcome is still choosing \(\ell\) discrete candidates, and PJR still requires integer numbers of represented rounds. For any fixed set \(U\) of types present in a coalition, its satisfaction depends only on \(U\), while its entitlement is largest when the coalition takes the full mass of those types. So the continuous constraints reduce to finitely many weighted quota constraints. The X3C reduction then carries over almost unchanged: it is a weighted version of the paper’s discrete coverage gadget, not a new phenomenon created by continuous optimization.

There is a related novelty concern. Proposition 5.6 already gives PJR-MaxUTIL an FPT algorithm in the number of voter types and round profiles. In the static anchor, there is one round profile. Replacing integer type counts \(n_\theta\) by rational masses \(\mu_\theta\) changes the quota to \(\lfloor \ell\sum_{\theta\in U}\mu_\theta\rfloor\); the same type-level formulation applies. Thus the paper has already exposed much of the algorithmic structure the mirror would ask about.

But neither point defeats the anchor under ChoCo’s criteria. The paper’s type counts are still a finite population; the binary-encoded mass model makes the high-multiplicity input regime explicit. And the hardness reduction survives that change. Replicating each type \(K\) times makes the population arbitrarily large relative to the support while preserving the instance’s masses and answer. The fact that the combinatorics live in the candidate set system is expected Class B evidence, not an objection. The floor is also a defensible way to retain indivisible round entitlements.

So the honest negative case is about incremental novelty, not about whether the mirror is worthwhile. Theorem 4.3 is a named computational result, the population has a plausible high-multiplicity interpretation, and the continuous PJR question is well-posed. I cannot make a strong case that no scenario yields a worthwhile mirror; this anchor survives.
