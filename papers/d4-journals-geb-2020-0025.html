The case FOR (proponent)

I don’t see a qualifying computational anchor in this paper. Its numbered results concern implementation and mechanism structure; none classifies a computational problem as tractable or hard, or gives an algorithm for one.

The closest results are Theorem 1, proved here: every stochastic rule with a random OSPS implementation has a randomized round-table implementation, which is also random OSPC; Theorem 2, proved here: the paper’s three-agent random serial dictatorship rule has no round-table implementation; and Theorem 5, proved here: a deterministic rule has an OSPC implementation if and only if it has a strategy-proof implementation through a round-table mechanism. These are substantive results, but they are not computational-complexity anchors.

A plausible high-multiplicity setting would be a large school-allocation market: many students, a relatively small support of preference rankings, and school capacities scaled with population. But turning that setting into a continuous OSP-implementation problem exposes a serious mismatch. If each student has zero mass, an individual misreport does not change the aggregate distribution, so the OSP incentive test can become vacuous. Treating a positive-mass group as the strategic agent would change the paper’s model. The paper’s randomization over outcomes or mechanisms also does not make its population continuous.

So I can’t honestly state a continuous prover question *per anchor* for this paper: it supplies none that meet the requested criterion. The implementation theorems could motivate a new continuous-mechanism project, but that would be a proposed extension, not a mirror of a named computational result here.

The case AGAINST (opponent, writing after the proponent)

The strongest case is that there is no qualifying computational result to mirror. Theorems 1, 2, and 5 are structural results about implementation: they restrict the game forms an analyst needs to consider, rule out a particular implementation, and characterize deterministic rules with OSP implementations. None studies an algorithm or classifies the complexity of a computational problem in parameters such as the number of agents, type support, or input bit length. That is decisive under ChoCo’s stated scope.

The natural continuous version of Theorem 1 would ask whether a stochastic rule \(F\) over society distributions has a randomized round-table implementation whenever it has some random OSP implementation. But if outcomes depend only on the distribution of reports, a single atomless agent’s report cannot change that distribution. Their OSP comparisons then have no bite. Giving a positive-mass type class the power to report for its members could restore an effect on the outcome, but it makes the class a coordinated strategic player rather than a mass of individual agents.

A stronger version of Theorem 2 could study random serial dictatorship in a large school market, with preference types in fixed support and capacities scaled with the population. That is a plausible high-multiplicity setting. To preserve meaningful individual incentives in its continuous limit, though, the model needs to retain each student’s own assignment—perhaps through an assignment rule for a tagged student conditional on the background distribution. A rule over aggregate assignment masses alone loses that information. The enriched question might be useful mechanism-design theory, but it is a new implementation question, not a mirror of a computational result in this paper.

For Theorem 5, the candidate is an equivalence between SP and OSP implementation for deterministic rules on a continuous society. With aggregate-only outcomes, individual deviations are invisible to the population measure, so both incentive conditions can become vacuous. Keeping personal outcomes requires extra structure that the society distribution does not supply. Again, making type classes strategic blocs changes the underlying players.

So the school-market example does establish that high multiplicity can be sensible for this subject matter; it does not supply the missing computational anchor. I would not claim that no continuous mechanism-design follow-up could be worthwhile. A model retaining focal individuals and a nonatomic background may be worth studying. The case against is narrower and stronger: none of the named results yields a continuous computational mirror for ChoCo’s programme.
