The continuous mirror question

Given a finite catalogue \(G\), a cardinality bound \(k\), and two additive valuation types \(v_1,v_2:G\to\mathbb{Z}_{\ge 0}\), each with mass \(1/2\), choose \(S\subseteq G\) with \(|S|\le k\) to maximize \(\sqrt{v_1(S)v_2(S)}\), on instances where some feasible set gives both types positive utility. What is the computational complexity of this problem?

The model it lives in

A society is a distribution over complete additive valuation types: type \(t\) has mass \(\mu_t\), with \(\sum_t\mu_t=1\). The decision variable is the shared indivisible set of goods \(S\subseteq G\), with \(|S|\le k\); the natural objective is weighted Nash welfare \(\prod_t v_t(S)^{\mu_t}\). The strongest anchored case has two types, each of mass \(1/2\).

What the mirror covers

The mirror covers NP-hardness for Public MNW with two types of equal mass and, by grouping identical valuation vectors, binary-valued instances with support that may grow. It leaves the leximin results, fairness guarantees, approximation algorithm, and special-case exact algorithms unmirrored. Weighted-Nash-welfare work cited by the opponent is adjacent objective literature, not a continuous-population solution to this public-goods selection problem.

Open questions for a prover

  • For two types of mass \(1/2\), what approximation guarantees are achievable for maximizing \(\sqrt{v_1(S)v_2(S)}\) as the valuation magnitudes grow?
  • Which restrictions on overlap among goods’ valuation sets make the two-type problem tractable?

The case FOR (proponent)

The strongest mirror is Public MNW over a continuous population with two valuation types. Consider a public library system choosing at most \(k\) shared resources from a catalogue \(G\). Its membership is large, but the system represents users by two standardized valuation profiles—for example, two service programmes with different published value scores for each resource. A type is the full vector \(v_t(g)\), and \(\mu_t\) is that type’s fraction of the membership. This is plausible where the institution actually uses common score schedules; it does not claim that every real patron has identical personal tastes.

The decision remains a single indivisible set \(S\subseteq G\), with \(|S|\le k\). For additive valuations, type \(t\)’s utility is \(v_t(S)=\sum_{g\in S}v_t(g)\), and the continuous-population objective is
\[ \operatorname{WMNW}_{\mu}(S)=\prod_{t=1}^{\tau}v_t(S)^{\mu_t}. \]
For equal masses and an even finite population with \(N/2\) copies of each type, this is exactly the ordinary Nash welfare:
\[ \left(\prod_{i=1}^{N}v_i(S)\right)^{1/N} =\bigl(v_1(S)v_2(S)\bigr)^{1/2}. \]
So the mass objective follows directly from duplicating agents, while the goods and the choice among them remain discrete.

The lead anchor is Theorem 21, proved in the paper by a reduction from Equal Sized Partition. It states that computing a maximum-Nash-welfare allocation in PublicGoods is NP-hard even with two agents. In the theorem’s problem, the input includes public goods, a cardinality limit \(k\), and two agents with additive nonnegative integer valuations; the required output is a feasible set maximizing \(\bigl(v_1(S)v_2(S)\bigr)^{1/2}\). The continuous question is the same optimization with two types of mass \(1/2\). The paper’s reduction therefore gives NP-hardness directly for this continuous restriction. Equivalently, each two-agent instance can be repeated across arbitrarily large equal-sized cohorts without changing the objective.

This is a Class B expectation: hardness transfers. The hard choices lie in selecting goods to balance additive utilities, not in distinguishing individual members of a large population. The fixed support size \(\tau=2\) makes this especially useful as a mirror: increasing the population while keeping the type distribution fixed does not remove the obstacle.

A second, broader anchor is Theorem 20, also proved in the paper. It states that PublicMNW remains NP-hard when all valuations are binary: given agents, goods, a cardinality limit, and additive values in \(\{0,1\}\), compute a feasible set maximizing the agents’ geometric-mean utility. The proof reduces from Exact Regular Set Packing. Its continuous counterpart is Binary-Valuation Public MNW over Rational Type Masses: input binary additive valuation vectors for \(\tau\) types and positive binary-rational masses summing to one; return a set of at most \(k\) goods maximizing \(\prod_t v_t(S)^{\mu_t}\). The reduction transfers by assigning each distinct valuation vector the fraction of agents having it. This is also Class B. Its support \(\tau\) can grow with the instance, so it is less compelling than Theorem 21 as evidence about a large population with few types, but it establishes a clean binary-valued mirror.

I would keep the claim to these PublicMNW results. The paper’s fairness guarantees, leximin results, and reductions to PublicDecisions are not needed for this case. Useful next questions are whether bounded overlap or other structure among the goods’ valuation sets makes either mirror tractable, and what approximation guarantees are possible for the fixed two-type problem as valuation magnitudes grow.

The soft spot is that this is a population mirror, not a relaxation of the goods: the selected set is still indivisible, so the mirror does not promise to dissolve the hardness. Exact shared valuation profiles also make the scenario stylized. But the population objective is the direct high-multiplicity form of the paper’s own MNW objective, and the two-type regime gives a plausible setting in which that abstraction is useful.

The case AGAINST (opponent, writing after the proponent)

I can’t honestly defeat either anchor. The strongest case against them is that they leave the goods problem unchanged: the selected set is still discrete, and the hard choice is still which goods to select. So this is a clean Class B mirror, not a promising example of population continuization dissolving hardness. But the programme explicitly counts hardness transfer as a useful result, so that is a limit on the mirror’s novelty, not a reason it fails.

For Theorem 21, the transfer is exact. If the two valuation profiles are \(v_1,v_2\), each with mass \(1/2\), then the continuous objective is \(\sqrt{v_1(S)v_2(S)}\), precisely the paper’s objective. Repeating each agent \(q\) times gives a population of \(2q\) people and leaves the objective unchanged. The reduction’s utilities are positive, so the zero-utility tie convention creates no obstacle. A setting with two large cohorts using standardized value schedules is stylized, but it is a coherent high-multiplicity regime; names and identities carry no information the optimization uses.

Theorem 20 transfers too: group agents with identical binary valuation vectors into types and assign each type its population share. The resulting weighted product has the same maximizing sets. Its support may grow with the instance, which makes it a weaker low-support example, but Theorem 21 already supplies the two-type case.

Weighted Nash welfare is an established formulation in fair division, which narrows any novelty claim about the objective itself.[The MWNW formulation for indivisible goods](https://arxiv.org/abs/2204.03803) However, that is not by itself an existing continuous-population solution to this public-goods selection problem, so it does not establish a collision.

The honest negative verdict is therefore weak: these may be low-novelty mirrors whose hardness follows directly from the discrete results, but neither the fixed support, the population interpretation, nor the retained indivisibility defeats them. Both anchors survive the strongest case against.
