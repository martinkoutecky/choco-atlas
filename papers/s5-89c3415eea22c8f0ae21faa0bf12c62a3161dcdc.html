The continuous mirror question

Given a finite type set \(T\), rational masses \(\mu_t>0\) summing to \(1\), a compact rational piecewise-linear worth function \(w:[0,\mu]\to\mathbb{Q}\), and \(\varepsilon>0\), suppose that for every \(r\) with \(r\mu_t\in\mathbb{Z}\), the game \(v_r(S)=r\,w((|S\cap N_{r,t}|/r)_{t\in T})\) is balanced and two-bound, and its per-type nucleolus payoffs converge; compute a vector within \(\varepsilon\) of their limit.

The model it lives in

Types \(t\) carry population masses \(\mu_t\); a coalition is described by its mass vector \(q\in[0,\mu]\), with worth \(w(q)\). The decision is a per-person payoff \(a_t\) for each type, subject in the limiting core to \(\sum_t\mu_t a_t=w(\mu)\) and \(\sum_t q_t a_t\ge w(q)\) for every coalition mass vector \(q\). The output is the limit of the finite replicas' type-level nucleolus payoffs, with the nucleolus evaluated by Theorem 3 whenever each replica is two-bound.

The objection that survived

Theorem 3 gives the Talmud allocation only once suitable core bounds are known; the paper neither computes those bounds nor establishes convergence for replicated games.

fatal: False

What the mirror covers

The mirror covers Theorem 3's nucleolus formula for the promised replicated two-bound core games. It leaves the paper's core characterizations, bound-stretching results, and robustness result (Theorem 4) without a corresponding mirror.

Open questions for a prover

  • For which compactly represented worth functions can the limiting exact core bounds be computed efficiently?
  • What conditions ensure convergence of the replica nucleoli, and provide an effective rate for approximating their limit?
  • Which type-based worth functions ensure that all finite replicas are two-bound core games?

The case FOR (proponent)

By the requested anchor rule, this paper has no qualifying complexity result: no numbered theorem or proposition classifies a problem as polynomial-time solvable, hard, or parameterized. The strongest positive lead is Theorem 3, proved in this paper. It gives an explicit formula for the nucleolus of every two-bound core game: whenever \(v\in\Gamma_t^N\) and \(C(v)=[l,u]\cap X(v)\), for *every* such pair \(l,u\),
\[ \eta(v) = l+f^{TAL}\!\left(v(N)-\sum_{i\in N}l_i,\ u-l\right) = u-f^{TAL}\!\left(\sum_{i\in N}u_i-v(N),\ u-l\right). \]
This is a computational characterization, but the paper gives it no complexity bound. So it is a useful lead for a mirror, not a complexity anchor in the strict sense.

A plausible high-multiplicity setting is a large organization whose surplus is shared among employees in a small number of standardized roles or skill classes. A type records everything about an employee that affects coalition worth; \(r\mu_t\) employees share type \(t\), and coalition worth depends on the numbers of each type in the coalition. Here mass means population share, and the decision is the per-employee payoff for each type. It is credible when the organization has many employees but relatively few such classes.

A precise candidate is the Replicated Two-Bound Core Nucleolus Limit problem. An instance has a finite type set \(T\), rational masses \(\mu_t>0\) summing to \(1\), a rational piecewise-linear worth function \(w\) on \([0,\mu]\), and an accuracy \(\varepsilon>0\). For each \(r\) such that \(r\mu_t\) is integral, create \(r\mu_t\) players of type \(t\), and define the finite game
\[ v_r(S)=r\,w\!\left(\left(\frac{|S\cap N_{r,t}|}{r}\right)_{t\in T}\right). \]
Promise that these games are balanced and two-bound core games, and that their nucleoli converge in per-employee payoffs. By symmetry, write \(a_t^{(r)}\) for the nucleolus payoff of each type-\(t\) player. The task is to return a vector within \(\varepsilon\), in maximum norm, of \(\lim_{r\to\infty}a^{(r)}\). The object being computed is the underlying game’s nucleolus along a specified replication path, not an encoding of that game.

The corresponding continuous core is
\[ K(w)=\left\{a\in\mathbb R^T: \sum_t\mu_ta_t=w(\mu),\quad \sum_tq_ta_t\ge w(q)\ \text{for every }q\in[0,\mu]\right\}. \]
Here \(q_t\) is the mass of type \(t\) in a coalition and \(a_t\) is that type’s payoff per employee. If \(K(w)\) is a box intersected with the efficiency hyperplane, let \(\ell_t\) and \(u_t\) be its exact coordinate bounds. Theorem 3 then suggests the limit formula \(a_t^*=\ell_t+\rho_t\), where \(c_t=u_t-\ell_t\), \(E=w(\mu)-\sum_t\mu_t\ell_t\), and
\[ \rho_t= \begin{cases} \min\{c_t/2,\lambda\},&\sum_t\mu_tc_t\ge 2E,\\ \max\{c_t/2,c_t-\lambda\},&\sum_t\mu_tc_t<2E, \end{cases} \qquad \sum_t\mu_t\rho_t=E. \]
The shared threshold \(\lambda\) is the continuum version of the Talmud rule’s threshold. This is not asserted by the paper: it is the result the mirror problem would investigate. In the replicated games, Theorem 3 gives the corresponding formula at each finite \(r\); convergence of the exact bounds would make the displayed limit formula follow.

My expectation is tractable for a useful subclass where \(w\) is concave and piecewise linear with a compact rational description. Core-bound optimization then has a natural separation problem over coalition masses, and the Talmud step is a threshold calculation. The main proof obligations are to establish convergence of the finite-game bounds and to show that the continuous core captures the limiting constraints. Further questions include which worth functions keep every replication two-bound, and whether the paper’s robustness result, Theorem 4, has a limit analogue.

The soft spot is substantial: Theorem 3 is an explicit formula, not a complexity result, and a nucleolus for a continuum of players is not defined by the paper. Defining the mirror as a limit of ordinary finite nucleoli avoids inventing a lexicographic ordering over infinitely many coalition excesses, but makes convergence part of the question. This is a credible high-multiplicity problem connected closely to the paper’s central object; it should not be presented as a complexity result the authors already established.

The case AGAINST (opponent, writing after the proponent)

The strongest case against this anchor is that Theorem 3 is not a computational result in the programme’s sense. It gives a formula for the nucleolus once a pair of bounds describing the core is known. The paper specifies neither an input model nor a running time for finding those bounds. For a general characteristic-function game, that work involves the coalition constraints themselves. A continuous question about computing the bounds from a compact description of a type-based game therefore adds the central algorithmic problem; it does not mirror a complexity result the paper established.

That matters for the proposed limit problem. Its piecewise-linear worth function, replication path, two-bound promise, and convergence requirement are substantial modeling choices. Theorem 3 supplies the Talmud step, but it does not establish that the replicated games stay two-bound, that their exact bounds converge, or that the limit can be approximated effectively. Qualitative convergence alone is not a complexity guarantee. Those are reasonable questions to investigate, but they are new results the mirror would need to prove.

I cannot, however, use this to argue that no worthwhile continuous mirror exists. A large bankruptcy with many creditors in a few claim brackets is a credible high-multiplicity setting, and bankruptcy games are explicitly among the paper’s two-bound games. The type can include the claim amount; coalition worth depends on the mass of each claim type; and per-person payoffs preserve the allocation the nucleolus selects. This is a particularly natural setting for the paper, not an objection to it.

So the negative case defeats Theorem 3 as an anchor to a computational result in the paper. It does not defeat the proposed family of continuous computational questions. Under a strict anchor rule I would not count this as a qualifying computational mirror; under the broader question of whether there is a worthwhile continuous mirror in some scenario, the case against is weak.
