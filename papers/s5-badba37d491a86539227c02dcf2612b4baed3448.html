The continuous mirror question

Given projects \(P\), costs \(c\), budget \(b\), a satisfaction function, and a finite-support distribution \(\mu\) over approval types \(A\subseteq P\), decide whether a feasible allocation \(\pi\) has no blocker: a mass vector \(0\le z_A\le\mu_A\) with \(\sum_A z_A\ge c(Q)/b\) for some \(Q\subseteq P\), such that every type with \(z_A>0\) strictly prefers \(Q\) to \(\pi\).

The model it lives in

Approval ballots are types with rational masses \(\mu_A\); projects and allocations remain indivisible, with \(c(\pi)\le b\). A blocking coalition selects mass \(z_A\) from each type. For share satisfaction, divide each project's cost by its approving population mass, which preserves finite comparisons up to scaling by electorate size.

The objection that survived

The opponent's strongest point is that deciding core existence on arbitrary inputs is broader than the paper's constructed witnesses; this bounds the mirror to constructive empty-core questions but does not eliminate it.

fatal: False

What the mirror covers

The mirror covers the cost-satisfaction witness in Theorem 1, the cost-based function family in Theorem 2, and the share witness in Theorem 3. It leaves the open cardinality-satisfaction question and any complexity classification of core existence unaddressed.

Open questions for a prover

  • Can core existence be decided efficiently as a function of the number of projects, support size, and input bit length?
  • Which satisfaction functions satisfying Theorem 2's conditions admit continuous empty-core witnesses, and does the cardinality case behave differently?

The case FOR (proponent)

The best positive case is a continuous-population version of the paper’s core question. Let each type be a complete approval ballot \(A\subseteq P\), and let \(\mu_A\) be the rational fraction of society with that ballot. An allocation remains an indivisible project set \(\pi\) with \(c(\pi)\le b\). A blocking coalition is a mass vector \(z_A\in[0,\mu_A]\): it may deviate to \(Q\subseteq P\) if \(\sum_A z_A\ge c(Q)/b\) and every type with \(z_A>0\) strictly prefers its satisfaction from \(Q\) to its satisfaction from \(\pi\). The continuous-core existence problem is: given \(P,c,b,\mu\), does any feasible \(\pi\) have no such blocker? A solution is that allocation, or a proof that none exists.

This has a plausible high-multiplicity setting: a large participatory-budgeting electorate divided among a few standardized approval types, such as three large constituencies approving pairwise shared projects and their own local projects. The number of residents can be large while the support has only three types. For the share satisfaction function, replace the number of approvers of a project with its population mass; multiplying the resulting per-type satisfaction by the electorate size recovers the finite comparison. This changes the population variable while leaving the projects indivisible. It is a recognizable continuous version of the paper’s core question.

The note’s theorems give strong evidence that this mirror is well-posed, but none is a computational-complexity anchor of the kind requested. They prove core-emptiness results, not hardness, tractability, or parameterized-complexity bounds.

  • Theorem 1, proved here: There is an approval-based PB instance whose cost-satisfaction core is empty. It has three voters; voter \(i\) approves the pairwise projects involving \(i\), plus personal projects \(\ell_i,s_i\). Each pairwise project costs \(8\), each \(\ell_i\) costs \(5\), each \(s_i\) costs \(2\), and the budget is \(15\). The same construction gives a continuous instance with mass \(1/3\) on each approval type. This is my strongest *mirror* anchor because it supplies a concrete, scalable three-type population and the paper’s proof transfers directly.
  • Theorem 2, proved here: For a satisfaction function strictly increasing under proper inclusion and strictly increasing with a project’s cost, if there are \(b,\varepsilon\) satisfying \(2b/3-\varepsilon>b/2\) and

\[ \operatorname{sat}(\{p_{b/3},p_\varepsilon\}) < \operatorname{sat}(p_{2b/3-\varepsilon}), \]
then some approval-based PB instance has an empty core. The continuous mirror asks whether core allocations exist for rational type-mass instances under each such satisfaction function; the paper’s three-type construction carries over. The note says this covers natural cost-based diminishing-return functions under suitable parameters.

  • Theorem 3, proved here: There is an approval-based PB instance whose share core is empty. It uses the same three approval types, pairwise-project costs \(11\), personal-project costs \(3\) and \(2\), and budget \(21\). In the continuous mirror, each pairwise project has approver mass \(2/3\), so its normalized share satisfaction is \(11/(2/3)\); the proof’s comparisons persist. This is a credible second family, with the necessary type-mass adjustment stated explicitly.

For each, the precise computational question would be the continuous-core existence problem defined above, restricted to that satisfaction function or class. The examples establish that a core is *not guaranteed*; they do not classify the decision problem’s complexity. So I cannot honestly label these Class A, B, or C from the paper. The further questions are whether core existence can be decided efficiently, how its complexity depends on the number of projects and support types, and whether any satisfaction functions retain universal nonemptiness.

The main limitation is decisive for ChoCo: the paper studies an axiomatic existence question, not an algorithmic one. Its numbered theorems are constructive counterexamples, not named complexity results. Thus I can make a solid case that the *population-continuous core question* is a natural mirror, but not that this paper supplies the required computational anchor. The continuous examples’ immediate inheritance from the finite proofs makes the mirror plausible; it does not turn those proofs into computational-complexity results.

The case AGAINST (opponent, writing after the proponent)

The strongest case against is that all three anchors are existence theorems, not computational results. The paper proves that some approval-based PB instances have empty cores; it gives no algorithmic problem, complexity classification, or parameterized bound. The continuous population versions may be well-defined, but calling core existence a computational problem adds a new question to the paper rather than continuizing a computational result it established.

Theorem 1 is the best of the proposed anchors for a population mirror: three approval types with mass \(1/3\) each are a plausible high-multiplicity electorate. But the theorem’s result is still just that this particular instance has no core allocation. Asking an algorithm to decide core existence on arbitrary inputs would be a reasonable follow-up; it is not the result being mirrored.

Theorem 2 broadens the satisfaction functions covered, not the kind of result proved. Its continuous analogue would likewise establish core emptiness for a family of instances and functions. Turning that into a complexity question requires choosing a search or decision problem and an input regime beyond the theorem.

Theorem 3 has the same limitation. The share adjustment to approver mass is coherent: for a type with positive mass of approvers, satisfaction can be scaled so that it preserves the finite comparisons. That makes the continuous example credible, but it does not make the theorem computational.

This is a narrow objection, and the population model itself is plausible. The note’s results have straightforward continuous counterparts, and a later study of algorithms for the continuous core could be worthwhile. The negative case is that such work would be a new computational programme around an axiomatic paper, rather than a continuous mirror of any computational result in it.
