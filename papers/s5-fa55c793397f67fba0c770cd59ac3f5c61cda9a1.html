The continuous mirror question

Given finite type and good-kind sets \(T\) and \(G\), rational additive values \(v_t(g)\), type masses \(\mu_t\ge 0\) summing to \(1\), and rational per-capita supplies \(q_g\ge 0\) summing to an integer \(R\), consider integral bundles \(B\in\mathbb{N}^{G}\) with \(\sum_g B_g=R\). Can an exact NC algorithm, measured in the compressed input’s bit length, output rational masses \(x_{t,B}\ge 0\) such that \(\sum_B x_{t,B}=\mu_t\), \(\sum_{t,B}x_{t,B}B_g=q_g\) for every \(g\), and whenever \(x_{t,B}>0\) and \(x_{u,B'}>0\), there is some \(g\) with \(B'_g>0\) for which \(v_t(B)\ge v_t(B'-e_g)\)? In particular, does an efficient algorithm exist when each kind is valued by only a constant number of types and each type values only polylogarithmically many kinds?

The model it lives in

Types are complete additive valuation vectors over good kinds. The society has rational type masses \(\mu_t\), and each kind has rational per-capita supply \(q_g\), scaled with population so each individual still receives an integral bundle of fixed size \(R\). The decision variables \(x_{t,B}\) give the mass of type \(t\) receiving bundle \(B\); they must meet type-mass and supply constraints while every realized bundle is EF1 relative to every other realized bundle for the receiving type.

The case FOR (proponent)

My lead mirror is Sparse Continuous EF1 Allocation. A type \(t\) is a complete additive valuation vector over a finite set \(G\) of good kinds: agents of that type value every kind identically. The society is a rational distribution \(\mu\) over types, with \(\sum_t\mu_t=1\). Each kind \(g\) has rational per-capita supply \(q_g\), and \(\sum_g q_g=R\) for a fixed integer \(R\). The many-agent regime is \(N\) agents with about \(N\mu_t\) of type \(t\), and about \(Nq_g\) copies of kind \(g\). Thus supply scales with population, while each individual still receives an integral bundle of \(R\) goods.

The precise computational question is: given \(T,G,\mu,q\), and the values \(v_t(g)\), output an exact rational mass allocation \(x_{t,B}\), where \(B\in\mathbb N^{G}\) and \(\sum_g B_g=R\). It must satisfy
\[ \sum_B x_{t,B}=\mu_t,\qquad \sum_{t,B}x_{t,B}B_g=q_g\quad\text{for every }g. \]
For every pair of bundles \(B,B'\) with positive mass assigned to them, the type receiving \(B\) must weakly prefer \(B\) to \(B'\) after removal of some one good from \(B'\): \(v_t(B)\ge v_t(B'-e_g)\) for some \(g\) with \(B'_g>0\). The output is a distribution of integral individual bundles; only the aggregate mass of recipients is fractional. For fixed \(R\), the bundle list is polynomial in \(|G|\), so the question can ask for a polynomial-size output and an exact algorithm polynomial in the binary input length.

My anchor is Theorem 3.3, proved in this paper. It says that for additive-valuation instances whose induced hypergraph has rank \(r=O(1)\) and edge degree at most \(\Delta\), an EF1 allocation can be computed in depth \(O(\Delta\log^4 m)\) and work \(O(m^{r+1})\). In the mirror, the hypergraph has types as vertices and good kinds as edges: an edge connects the types that value that kind positively. The continuous question is whether the same sparse-incidence regime—constant rank and polylogarithmic edge degree—admits an exact NC algorithm on the compressed rational input. I expect Class A, plausibly by extending the paper’s local decomposition to masses and enforcing the per-capita quotas. The theorem motivates that conjecture; it does not prove the extension.

This is a plausible problem for these authors to recognize: it is still computing EF1 allocations for additive valuations and indivisible goods. It makes the population continuous, and scales supplies with it; it does not make an individual’s bundle divisible. Clearing denominators gives a finite EF1 instance, so feasibility follows. But the common denominator can be exponential in its bit length. The computational question is whether the aggregate allocation can be found succinctly from the rational input, rather than by expanding that enormous instance.

The paper’s Theorem 6.4, proved here, says that Fixed-Order Round Robin is \(\mathrm{CC}\)-complete. That is a significant hardness result, but it concerns computing the outcome of a particular procedure whose input includes the order of named turns. A type distribution omits that order. Preserving it would require adding a priority schedule to the continuous model, and the schedule could carry much of the individual-level input. I therefore do not use Theorem 6.4 as an anchor for this EF1 mirror.

The mirror covers Theorem 3.3’s EF1 allocation result under sparse type–good incidence. Its weakest point is that EF1 constrains pairs of realized bundles, so rational type masses alone do not turn the problem into a straightforward LP: choosing which bundles have positive mass is itself combinatorial. The paper’s coloring and local-allocation structure gives a reason to investigate a tractable mass version, but whether it survives that support-selection problem is the central open question.

The case AGAINST (opponent, writing after the proponent)

The only anchor the proponent actually uses is Theorem 3.3; they explicitly leave the Fixed-Order Round Robin completeness result aside. The strongest objection is that Theorem 3.3’s sparsity does not carry over unchanged when agents are grouped into types. In the finite theorem, rank counts individual agents who value a good. If a positive-mass type values a good kind, then after clearing denominators, every clone of that type values every copy of the kind. The individual rank can therefore grow with the population. Counting types instead gives a sensible high-multiplicity restriction, but it is a different restriction from the theorem’s bounded-rank instances.

That difference also breaks the proof’s direct route to the proposed algorithm. Theorem 3.3 colors goods so that each color class has disjoint sets of actual agents, then combines local allocations using an envy graph on those agents. A continuous allocation may split one type’s mass among several bundles; its type–bundle groups can interact through envy even when the type-level incidence graph is sparse. The theorem supplies no way to maintain those interactions or the exact per-capita quotas. Clearing denominators establishes feasibility, but the resulting population can be exponentially large in the rational input length, so running the paper’s algorithm on that expansion does not give the proposed compressed-input algorithm.

That is a substantial objection to presenting Theorem 3.3 as support for the claimed tractable mirror. It does not, however, defeat the better version of the mirror. With fixed integral bundle size and supplies scaled per capita, the proposed mass-allocation problem is coherent: identical types can be assigned different integral bundles, and their bundle frequencies retain the information EF1 needs. Denominator clearing gives a finite EF1 allocation, while the compressed exact algorithm remains a nontrivial question. Neither the sparse-proof mismatch nor the exponential expansion makes that question ill-posed or unworthy.

So the negative case is strongest against the claimed connection to this paper’s sparse algorithm. It is weak against the universal claim that no worthwhile continuous mirror exists: the proponent’s strengthened EF1 formulation survives the main objections, and I cannot honestly rule out that the authors would recognize it as their problem.
