The continuous mirror question

Given a unit-mass panel of one respondent type with unknown \(w^\star\in\{w\ge 0:\|w\|_1=1\}\), a known feature map \(\phi\), and the ability to choose comparison pairs and obtain noise-free responses from panel members, can an adaptive learner return \(\hat w\) with \(\|\hat w-w^\star\|_2\le\epsilon\) using \(O(m\log(\sqrt m/\epsilon))\) queries when \(\phi^{-1}\) can be approximated to arbitrary precision?

The model it lives in

The society is \(\mu=\delta_{(w^\star,Q_0)}\), a unit-mass population sharing a latent normalized utility and noise-free response model. Each query selects a pair \((x,x')\) and receives the shared type’s comparison according to \(w^{\star\top}(\phi(x')-\phi(x))\); the objective is to recover \(w^\star\), with query count as the resource.

The objection that survived

The theorems count oracle calls without tying them to respondent mass or limiting each person’s query budget, so the added population does not itself drive either bound.

fatal: False

What the mirror covers

Covers active noiseless parameter recovery (Theorem 9) and passive parameter non-identifiability (Theorem 8) for a single shared-utility type; leaves out pairwise-preference prediction, noisy learning guarantees, and heterogeneous panels.

Open questions for a prover

  • How does active recovery change when the panel has \(\tau>1\) utility types with different masses?
  • What query or sample lower bounds arise when each respondent has a finite response budget?

The case FOR (proponent)

The strongest mirror I believe is a large, nearly homogeneous preference-elicitation panel: many interchangeable respondents share the same underlying linear utility, while individual reports may still be random. That is a plausible high-multiplicity regime for RLHF or a large recommender system using one common preference rubric.

Let a respondent’s type be their normalized utility vector \(w\in W=\{w\ge 0:\|w\|_1=1\}\), together with their response-noise model. The society is a mass distribution \(\mu\) over these types. To mirror the paper’s theorems faithfully, I would take the one-type case, \(\mu=\delta_{(w^\star,Q)}\): the whole panel has one underlying preference type, and \(w^\star\) is unknown to the learner. The panel’s mass is one; a query asks a respondent for a comparison between two alternatives, and the objective is to use as few independent responses as possible to learn either the panel’s comparison behavior or its utility parameters. The pair-sampling distribution \(P\) remains the experiment design; it is not the society.

My lead is the active parameter-recovery mirror, anchored in Theorem 9 (proved here). The theorem says that in the noise-free setting, if the feature map \(\phi\) has an inverse that can be approximated to arbitrary precision, then an active learner can recover a linear utility hypothesis with \(e_2\le\epsilon\) after \(O(m\log(\sqrt m/\epsilon))\) queries. The paper defines \(e_2\) as squared Euclidean error, while the theorem’s proof constructs a point within Euclidean distance \(\epsilon\); that stronger radius bound implies the printed guarantee for \(\epsilon<1\). Its query bound is polynomial, though polynomial running time also depends on computing the inverse efficiently.

The continuous problem to hand to a prover is Active Continuum-Panel Utility Recovery. Its instance is a mass-one panel of respondents sharing an unknown \(w^\star\in W\), a known feature map \(\phi:X\to[0,1]^m\), and access to fresh noise-free respondents. The learner may adaptively choose any pair \((x,x')\) for each query and receives the comparison implied by \(w^\star\cdot(\phi(x')-\phi(x))\). Given \(\epsilon,\delta\), the question is whether it can return \(\hat w\) with \(\|\hat w-w^\star\|_2\le\epsilon\), with probability at least \(1-\delta\), using the stated number of queries. The answer should be tractable in query complexity under the inverse assumption, and computationally tractable when the inverse is efficiently computable. A natural next question is how much of this guarantee survives when respondents have a small number \(\tau>1\) of utility types, or when queries have type-dependent costs.

The complementary boundary is Passive Continuum-Panel Utility Identification, anchored in Theorem 8 (proved here). Its proof gives a concrete impossibility: for every \(\epsilon<1/2\) and \(\delta<1/2\), there is a noise-free pair distribution \(P\) for which no finite-sample learner can guarantee \(e_2\le\epsilon\) with confidence \(1-\delta\). The witness distribution supplies only pairs with \(x'_i>x_i\) in every coordinate. Every nonnegative normalized utility then gives the same comparison, so the observations cannot distinguish parameter vectors separated by \(\sqrt 2\).

The continuous problem has the same panel and unknown \(w^\star\), but pairs arrive i.i.d. from \(P\) and cannot be selected. Given \(\epsilon<1/2\) and \(\delta<1/2\), it asks whether any finite number of responses suffices to return \(\hat w\) with \(\|\hat w-w^\star\|_2^2\le\epsilon\) and confidence \(1-\delta\), uniformly over the permitted utility vectors and query distributions. The answer is no for the witness regime. This is an information-theoretic identifiability failure, not NP-hardness and not a continuum-specific complexity class: adding more interchangeable respondents does not help if the passive query design never separates their possible utility types. The relevant follow-up is to characterize which supports of \(P\) identify \(w^\star\), and when active query choice repairs the failure.

These anchors make a credible, narrow case for the mirror: the paper’s central contrast between passive data collection and active elicitation is meaningful for a large respondent population sharing a preference type. The paper contains no NP-hardness or standard complexity-class result to anchor; its named results concern sample and query complexity. I would not claim that the mirror covers its whole learning theory, or that its existing continuous outcome space already continuizes the population.

The weakest point is that the paper models a utility function and a query process, not a distribution of people. Treating its unknown \(w^\star\) as a high-multiplicity respondent type is a plausible interpretation of its human-feedback setting, but the theorems do not study heterogeneous population mass \(\mu\), nor do they optimize over mass transfers between types. A broader mirror that learns an unknown mixture of distinct utilities would be more population-centered, but these anchors would not establish its results.

The case AGAINST (opponent, writing after the proponent)

The strongest objection is that the paper’s results are about queries to an unknown utility function, not computations on a society. Its continuous objects are the outcome space and the weight vector. The passive pair distribution \(P\) describes which comparisons are queried; it is not a distribution of people. The paper does have named algorithmic learnability results, so “there is no computational result to mirror” would be the wrong argument. The problem is that population size and type masses do not enter those results.

For Theorem 9, a panel whose members share \(w^\star\) gives the active learner no population-level problem to solve. In the noise-free case, one respondent already supplies the same deterministic comparison oracle as the whole panel. The \(O(m\log(\sqrt m/\epsilon))\) query bound comes from cutting down the feasible region for \(w^\star\), and depends on the dimension and the ability to invert the feature map—not on how much respondent mass exists. If each query must use a new person, the relevant resource is the number of people, which a normalized mass distribution does not record. If people can answer repeatedly, the population adds no resource constraint. A per-person query budget could make that constraint meaningful, but it would be an added model feature, not a question the theorem puts within reach.

Theorem 8 has the same problem. Its passive witness gives only comparisons with \(x'_i>x_i\) in every coordinate, so every admissible \(w^\star\) produces the same label. More respondents of that same type repeat uninformative observations; they do not change the support of \(P\). One could instead make the society heterogeneous, with utilities \(w_t\) and masses \(\mu_t\). But then a randomly sampled respondent yields
\[ \Pr(y=1\mid\Delta)=\sum_t\mu_t F(w_t^\top\Delta), \]
which generally cannot be represented by the paper’s single utility vector. Recovering that mixture is a different learning problem, with a different target and its own identifiability questions. It may be worth studying, but it does not preserve the theorem’s mirror.

The same reply covers the stronger noisy-panel version: independent noisy responses from many interchangeable people can supply repeated oracle calls, as in the paper’s active noisy setting. The population is then a source of samples. The computational question remains which outcome pairs to ask about and how to infer the unknown utility—not how to act on a distribution of voter or agent types.

So I would reject these anchors as evidence for a worthwhile population-continuization of this paper. The negative case is strongest for the paper’s actual results and weaker as a universal claim: a model with heterogeneous preferences, limited queries per person, or a population-level target could be valuable. But those additions would motivate a new learning problem; the paper’s results do not show that making the society continuous is the move that makes it tractable.
