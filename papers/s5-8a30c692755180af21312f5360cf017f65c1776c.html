The continuous mirror question

Given a finite directed role graph \(H=(R,F)\), signal laws \(p_\theta(r)\), and query \((r^\star,t,s^\star,h)\), consider the population \(\Omega=R\times[0,1]\) with role masses \(\mu(\{r\}\times B)=\lambda(B)/|R|\), a shared state \(\theta\), and communication edges only between corresponding roles in the same copy \(z\); compute the queried agent’s action, or decide whether its posterior is at least \(1-2^{-g}\) or at most \(2^{-g}\).

The model it lives in

Types are network roles \(r\in R\), each with mass \(1/|R|\); each \(z\in[0,1]\) indexes an isomorphic copy of \(H\), and agents communicate only within that copy. Given the role graph, signal laws, and a tagged agent’s signal and history, compute its action or posterior-gap side; there is no aggregate optimization variable.

The case FOR (proponent)

The strongest honest case is a narrow one: the paper’s binary-action computation has a continuous-population version in a repeated-module regime. The continuum describes who occupies each network role; it does not replace the Bayesian action question with an aggregate opinion or a mean-field equilibrium.

My lead anchor is Corollary 4, proved in the paper as a consequence of Theorem 3. It says that both computing an agent’s binary action \(\BAY\) and distinguishing a posterior above \(1-\exp(-O(N))\) from one below \(\exp(-O(N))\) are \(\mathsf{PSPACE}\)-hard. The reduction in Theorem 3 starts from a quantified Boolean formula \(\Phi=Q_Kx_K\cdots\exists x_1\,\phi(x_K,\ldots,x_1)\), where \(\phi\) is a 3-CNF formula with \(N\) variables and \(M\) clauses, and the \(K\) variable blocks have alternating quantifiers. It constructs a binary-action Bayesian network with \(O(N^2(N+M))\) agents, asks for the action at time \(2K\) of an observer with no private signal, and uses efficiently computable signal probabilities bounded away from zero and one by \(\exp(-O(N))\). If \(\Phi\) is true, the observer’s posterior is \(1-\exp(-\Theta(N))\); if false, it is \(\exp(-\Theta(N))\).

Here is a continuous problem that preserves that question. Call it Fibered Continuum Bayesian Action. An instance gives a finite directed network \(H=(R,F)\) of communication roles, a binary signal law \(p_\theta(r)=\Pr[S=1\mid\theta]\) for each role \(r\), a uniform prior on the shared hidden state \(\theta\in\{\mathsf T,\mathsf F\}\), and a query \((r^\star,t,s^\star,h)\). The society is \(\Omega=R\times[0,1]\), with mass \(1/|R|\) on each role: \(\mu(\{r\}\times B)=\lambda(B)/|R|\). Each \(z\in[0,1]\) indexes a copy of the whole network \(H\); \((r,z)\) observes \((s,z)\) whenever \((r,s)\in F\). Signals are conditionally independent, and agents update and announce actions exactly as in the paper. They know the model and use only their own signal and their local observed action history.

The query asks for the action of a typical role-\(r^\star\) agent with signal \(s^\star\) and history \(h\): output \(\mathsf T\) if its posterior exceeds \(1/2\), and \(\mathsf F\) otherwise. The associated gap version asks whether that posterior is at least \(1-2^{-g}\) or at most \(2^{-g}\), for a supplied gap parameter \(g\). The solution is therefore an action bit, or the correct side of the posterior gap. The reduction’s finite graph becomes \(H\), its observer becomes \(r^\star\), and each role has mass \(1/|R|\). Taking \(g\) to be a sufficiently small constant times \(N\) preserves the exponential gap. Other modules contribute no observations, so their signals integrate out and the queried agent’s posterior is exactly the finite-instance posterior. Corollary 4 therefore transfers to this continuous problem.

A plausible regime is a very large population of repeated deliberation cells: for example, many regional teams addressing the same hidden question, with the same communication workflow and role-specific evidence sources in each cell. A type is a role in the cell, including its signal law and communication position. Mass is the fraction of the whole population occupying that role. With \(q=|R|\) roles, the continuous society has support size \(\tau=q\); a finite approximation with \(B\) cells has \(Bq\) agents and \(B\) agents per type. This is a high-multiplicity regime, even though the role network can grow with the computational instance. The problem stays within the paper’s scope: it continuizes the population, while retaining the paper’s discrete time, binary actions, and local Bayesian reasoning.

I expect hardness to transfer. The quantified-formula combinatorics live in the network roles and the \(2K\)-round computation, not in the number of copies of the population. This is exactly the kind of hardness that can survive a high-multiplicity embedding.

The weakest point is that the continuum is a continuum of copies of a finite network. Because copies do not communicate, the mass vector does not affect a focal agent’s posterior. A referee might accept this as the paper’s problem in a repeated-cell population, yet still judge it a thin continuum mirror rather than a genuinely mass-sensitive network limit. The case is strongest if repeated, role-structured cells count as a sensible instance regime; it does not establish that PSPACE-hardness persists when cohort masses themselves shape a connected population’s information flow. The scope here is only Corollary 4’s binary-action hardness and posterior-gap hardness, not the paper’s separate revealed-belief result. Further questions are whether the hardness survives in a connected continuum network with mass-dependent contacts, and whether fixed role support or stronger symmetry admits an efficient algorithm.

The case AGAINST (opponent, writing after the proponent)

Corollary 4 is a genuine computational result, so the objection is not that there is nothing to mirror. The problem is that the proposed fibered continuum adds no continuous population question. In each copy of \(H\), the queried agent sees only that copy. The other copies’ signals integrate out, leaving exactly the finite-network posterior. The reduction, its input size, and its \(\mathsf{PSPACE}\)-hardness all remain in \(H\); the role masses do no computational work. Repeated deliberation cells may be a sensible high-multiplicity regime, but this construction makes their multiplicity inert.

The more promising repair is to let agents observe positive-mass cohorts, so population mass affects their information. In the straightforward version, an informative cohort’s time-zero actions reveal its signal frequencies. With conditionally independent signals and a continuum of agents, those frequencies equal \(p_\theta(r)\) almost surely. If \(p_{\mathsf T}(r)\ne p_{\mathsf F}(r)\), an observer of that cohort identifies \(\theta\) exactly; once that information reaches the queried agent, its posterior collapses to \(0\) or \(1\). That is a real continuum degeneration: the finite rare configurations and threshold behavior behind the hardness result disappear.

Keeping each agent’s neighborhood finite avoids that collapse, but restores the discrete local object the paper computes over. Given a realized neighborhood and its history, the action is again the finite-network action; population masses can at most govern how often different neighborhoods occur. Asking for a typical agent’s action over random neighborhoods would be a different, distributional problem. Moreover, a worst-case hard observer placed in a vanishing fraction of the population disappears from a typical-agent query; replicating it across cells returns to the inert-copy construction.

One could add a limiting noise model, such as scaled signal quality, to preserve uncertainty in aggregate observations. That might be worth studying, but it adds a new stochastic object and a new inference problem rather than yielding a clear mirror of Corollary 4. So the best case against this anchor is that its faithful mirror is computationally redundant, while the natural mass-sensitive version either collapses or changes the query. This is a case against prioritizing the mirror, not a proof that no useful version can exist: a carefully designed sparse or noise-scaled model remains the negative case’s weak point.
