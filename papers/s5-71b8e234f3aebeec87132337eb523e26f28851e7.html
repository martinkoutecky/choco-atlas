What the mirror covers

The proposed Mass-UFP covers maximum-value routing with request types represented by mass. It does not cover Theorem 3.11's algorithm-family lower bound, the truthful approximation results, the auction result, or the repetitions variant.

The case FOR (proponent)

The strongest honest anchor is Theorem 3.11, proved in this paper. It says that for directed unsplittable flow, when \(B=o(m^{1/2})\), no *reasonable iterative path-minimizing algorithm* can achieve an approximation guarantee better than \(e/(e-1)-o(1)\). Here “reasonable” is the paper’s defined class: at each step the algorithm chooses a path minimizing a priority function that, with equal edge capacities and unit demands and values, does not favor a longer path or one whose non-increasing vector of current edge loads is componentwise larger. This is a real lower-bound result, but it is not an NP-hardness or inapproximability result for all algorithms; its restriction to that family is a material limitation.

The mirror I would put to a prover is Mass-UFP. An instance has a directed graph \(G=(V,E)\), rational per-capita edge capacities \(b_e\), and a distribution \(\mu\) over request types \(r=(s_r,t_r,d_r,v_r)\). A type records the endpoints, demand, and value used by the allocation problem; \(\mu_r\) is that type’s fraction of the population, and there are \(\tau\) positive-mass types. For each simple \(s_r\)-to-\(t_r\) path \(p\), choose mass \(x_{r,p}\ge 0\). The constraints are
\[ \sum_p x_{r,p}\le \mu_r \quad\text{for every }r,\qquad \sum_{r,p:e\in p}d_r x_{r,p}\le b_e \quad\text{for every }e. \]
The objective is to maximize \(\sum_r v_r\sum_p x_{r,p}\). A solution is the path allocation of each type’s mass; each individual request still travels on one whole path or is rejected. Only a homogeneous cohort is divided across paths.

There is a plausible high-multiplicity regime for this mirror: a large network serving repeated, standardized requests between service regions, with common demand and value within each origin-destination class. The paper’s own lower-bound construction points toward that regime: it has \(\ell\) source classes, each represented by \(B\) identical unit-demand, unit-value requests. Thus \(N=B\ell\) requests have only \(\tau=\ell\) types, and the ratio \(N/\tau=B\) can grow. Capacities scale with the population; after normalizing by \(N\), the requests become type masses and the capacities become per-capita capacities. This is a sensible instance regime, not a claim that every network-routing problem has few types.

Mass-UFP looks tractable. It is a linear program with exponentially many path variables, but its dual has one nonnegative price \(y_e\) per edge and one nonnegative cap price \(z_r\) per type, with constraints
\[ z_r+d_r\sum_{e\in p}y_e\ge v_r. \]
Separation reduces to finding a shortest path for each type under the edge prices \(y_e\), which is polynomial. So the expected classification is tractable, by exact LP optimization with pricing; the number of supported types \(\tau\) and the input bit length are the relevant population parameters. The paper itself discusses the multicommodity-flow relaxation, so I would not present the LP as a novel mathematical object. The mirror is that the population is represented by masses of complete request types while individual requests remain unsplittable.

The authors should recognize the underlying problem: it preserves their maximum-value routing objective, request demands, endpoint pairs, and edge capacities. The scope is the allocation problem and the high-multiplicity behavior of the instances behind Theorem 3.11. It does not establish that the theorem’s restricted algorithm-family lower bound transfers to the continuum, or that the paper’s truthful-mechanism results have a continuous counterpart.

That last point is the weakest part of the case. The paper’s central motivation includes truthful mechanisms, while Theorem 3.11 bounds a class of allocation algorithms, and Mass-UFP asks for welfare optimization without truthfulness constraints. Natural follow-up questions are whether a continuous optimum can be selected monotonically in the privately reported demand and value, and how to relate that answer to truthful mechanisms and finite-population instances. The mirror is strongest as a case that the paper’s high-multiplicity allocation problem has a clear continuous form; it is not yet a mirror of the paper’s full mechanism-design contribution.

The case AGAINST (opponent, writing after the proponent)

The weak point is that the proposed Mass-UFP does not mirror Theorem 3.11’s result. That theorem does not give an approximation threshold for unsplittable flow across all algorithms; it lower-bounds a particular, formally defined family of iterative path-minimizing algorithms. Mass-UFP instead asks for the optimal allocation of type mass. Its LP imposes no such algorithm restriction, so solving it would not confirm or refute the theorem’s claim.

The proposed mass LP is also exactly the paper’s fractional multicommodity-flow relaxation, after identical requests are grouped by type. For example, set \(y_{r,p}=d_r x_{r,p}\): the mass bound becomes a per-commodity flow bound, the edge constraints become ordinary capacity constraints, and the objective becomes a linear value per unit of flow. Reading that flow as fractions of a population cohort is a sound interpretation, but it leaves the theorem’s algorithm-family question untouched. The mirror therefore has a natural model, but the anchored result is not about that model’s optimum.

The strongest repair would ask whether a corresponding family of mass-allocation algorithms has the same lower bound. But there is no canonical way to extend “select the next unselected request”: a continuous cohort can be routed in whole chunks, arbitrary chunks, or infinitesimal increments, defining different algorithm families. A theorem about one chosen extension would be a new, method-specific result, not a complexity classification of the continuous population problem.

This is the best negative case, and it is not airtight. The paper’s lower-bound instances do contain many identical requests per endpoint pair, so the high-multiplicity interpretation is credible. A carefully motivated mass-greedy family might be worth studying. The case against is that the proposed mirror misses the anchor, while the closer mirror depends on a modeling choice with no obvious canonical answer—not that the population regime is implausible.
