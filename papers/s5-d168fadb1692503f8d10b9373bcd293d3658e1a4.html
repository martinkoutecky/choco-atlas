The continuous mirror question

Given a finite set \(T\) of types with positive rational masses \(\mu_t\), type-level roommate rankings and acceptability, and a graph on types whose paths induce the paper's \(k\)-connection extensions, decide whether a stable mass matching exists. Choose symmetric flows \(x_{tu}=x_{ut}\ge 0\) only on mutually acceptable type pairs and single masses \(s_t\ge 0\), with \(\sum_{u\in T}x_{tu}+s_t=\mu_t\). For each mutually acceptable pair \(t,u\), let \(B_{t,u}=s_t+\sum_{v:\,u\succ_t v}x_{tv}\), the mass of type \(t\) that is single or strictly prefers type \(u\) to its assigned partner type; require \(B_{t,u}=0\) or \(B_{u,t}=0\). Decide whether such a matching exists and return one if it does.

The model it lives in

A finite type set \(T\) with rational masses \(\mu_t\), rankings over types, and uniform acceptability and \(k\)-connection relationships between types. The decision variables are symmetric matching masses \(x_{tu}\) and single masses \(s_t\); there is no objective.

What the mirror covers

The mirror covers Proposition 1's existence question for \(k\)-SRTI under repeated type-level relationships. It leaves the personalized criteria, ASP implementation, and empirical evaluations without a continuous result.

Open questions for a prover

  • What is the complexity of deciding existence as the number of types, \(k\), and input bit length vary?
  • Can feasible mass matchings be rounded to discrete stable matchings, or do fractional assignments change existence?

The case FOR (proponent)

My lead is a continuous \(k\)-SRTI existence problem, anchored in the paper’s Proposition 1: “\(k\)-SRTI (and thus \(k\)-Personalized-\(\srti\)) is NP-complete.” In full, the result says that deciding whether an instance with incomplete, possibly tied preferences and the paper’s \(k\)-connection extension has a \(k\)-stable matching is NP-complete; the same hardness then holds for \(k\)-Personalized-\(\srti\). This is the paper’s own numbered proposition, not presented as a citation to an earlier result. The supplied text does not include a proof, so I cannot say from it whether the proposition is proved elsewhere in the paper.

Here is the mirror. Imagine a large dormitory intake of several thousand students, with students falling into a few dozen or perhaps a few hundred repeated roommate-profile classes. A type records everything relevant to this problem: the class’s base weak ranking of roommate types, which types are acceptable or unwanted, and its position in the type-level \(k\)-acceptability graph. Members of one type are interchangeable in all those respects. The graph records which profile classes have the paper’s known, non-forbidden relationship; its paths supply the \(k\)-connection extensions. This is a regime for the model, not a claim that ordinary friend networks always have this block structure.

Write the positive rational mass of type \(t\) as \(\mu_t\), with \(\sum_t\mu_t=1\). The decision variable \(x_{tu}\) is the fraction of type \(t\) matched to type \(u\), and \(s_t\) is the fraction left single. Require \(x_{tu}=x_{ut}\), prohibit positive flow on pairs that are not mutually acceptable after the \(k\)-extension, and impose
\[ \sum_{u\in T}x_{tu}+s_t=\mu_t \quad \text{for every }t\in T. \]
The diagonal \(x_{tt}\) represents the mass of type \(t\) paired within its own type. People still receive integral assignments; the fractions describe how the cohort is divided among partner types.

For each mutually acceptable type pair \(t,u\), let \(B_{t,u}\) be the mass of type \(t\) who are single or are matched to a type they strictly like less than \(u\), using the extended preferences. Require \(B_{t,u}=0\) or \(B_{u,t}=0\). Thus there cannot be positive mass on both sides who would prefer to pair with each other. A solution is a mass matching satisfying these conditions: the question is whether one exists, and to return one if it does. That mirrors the paper’s search for a \(k\)-stable matching, rather than its ASP encoding.

I think the authors could recognize this as their problem at high multiplicity: the same indirect-connection rule extends the same preferences, and stability still means that no mutually acceptable pair prefers each other to their assignment. A large standardized intake with repeated profile classes also gives the high-multiplicity premise some substance: many students share each type, while type count is small relative to population. The model does not turn the room into a divisible outcome; only the cohort’s allocation across roommate types is fractional.

My tentative expectation is Class C, for reasons specific to this continuous formulation. Each type-pair stability condition is a disjunction, and the \(k\)-connection graph couples those conditions through paths. The paper’s NP-completeness result does not by itself prove hardness transfers: fractional assignment can let a type split across partner types, so a discrete instance need not retain its yes/no answer. Whether these conditions have structure that makes the continuous problem tractable, or instead yield continuum-specific hardness, is precisely a question for the prover.

The mirror covers Proposition 1’s \(k\)-SRTI matching-existence result. It does not claim to continuize the paper’s measured usefulness, student surveys, or arbitrary person-specific friend networks. Its weakest point is that the paper’s \(k\)-acceptability graph is built from relations between named students. Replacing that with a graph between profile classes is credible only in a regime where those relations are uniform at class level; for a sparse, individualized friendship graph, the number of complete types could grow with the population. There is also a modeling choice in treating a block as a positive-mass opportunity to deviate: in an atomless population an individual pair has zero measure, so the authors may want a different continuum blocking convention.

The mirror raises further questions: does hardness persist for fixed \(k\), or only when \(k\) is part of the input? Can the type-level problem be solved or approximated as \(\tau\) grows? How closely can its stable mass matchings be rounded to discrete matchings, and how does the answer change if one requires only approximate, rather than exact, stability?

The case AGAINST (opponent, writing after the proponent)

Proposition 1 is a genuine computational anchor: it states that deciding whether a \(k\)-SRTI instance has a \(k\)-stable matching is NP-complete. The strongest case against its mirror is about whether the population can be compressed without changing the problem the paper studies.

Here, \(k\)-connection depends on paths in a graph of relationships between named students. A complete type would have to preserve each student’s preferences, unwanted pairs, and relevant graph relationships. In a realistic sparse friendship network, those relationship patterns are usually person-specific, so the number of complete types can grow with the population. The continuous model then has little high-multiplicity advantage. If instead students are grouped by preference profile and the network is replaced with a graph between groups, a path between groups no longer says that a particular student is connected to a particular other student. Dense group-level links can also make two-step reachability nearly universal within a community, erasing the individualized referral structure that motivates the paper. A graphon-style model faces the same choice: dense links tend to wash out the local path information, while sparse links require retaining fine-grained neighborhoods.

That objection survives the proponent’s improved mass-blocking condition: the condition can represent stability correctly when people within each type really do have the same relevant relationships. It does not solve the underlying compression problem. Still, there are plausible structured regimes—repeated dormitory pods or cohorts with the same preferences and repeated local friendship patterns—in which the type graph could preserve \(k\)-connection and a mass matching could be a faithful mirror of Proposition 1. The authors might recognize that question as theirs.

So the negative case is strongest for individualized, sparse networks, which appear central to the paper’s motivation. It does not establish that no worthwhile continuous mirror exists in any scenario. Claiming that would overstate the evidence; a repeated-network regime remains a credible counterexample.
