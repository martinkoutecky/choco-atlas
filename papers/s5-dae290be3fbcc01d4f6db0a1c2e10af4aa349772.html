The case FOR (proponent)

My strongest positive case is narrow: the paper’s optimistic minimum-menu problem has a credible continuous-population mirror.

The anchor is Proposition 4.2, proved in this paper by reduction from 3-Dimensional Matching. It says that, given a Menu Selection instance with \(n\) agents, a budget \(B\ge n\), and serving sizes \(s_o\ge 3\) for every option, it is NP-complete to decide whether there is an optimistically valid menu of size at most \(B\). Here, optimistic validity means that a central planner can assign enough acceptable food to every agent; menu size is \(\sum_o q_o s_o\), where \(q_o\) is the number of orders of option \(o\). The reduction uses serving sizes of exactly \(3\).

Call the mirror Fractional-Population Optimistic Menu Selection. Its input is a finite set of options \(O\), each with an integer serving size \(s_o\); a population scale \(P>0\); and a list of dietary types \(A\subseteq O\), each with rational mass fraction \(\mu_A>0\), where \(\sum_A\mu_A=1\). A type is the complete description the paper’s problem uses: the set of options its members accept. Type \(A\) has mass \(P\mu_A\). Choose whole order quantities \(q_o\in\mathbb Z_{\ge0}\), minimizing \(\sum_o s_o q_o\). The menu is valid if there are nonnegative assignment masses \(x_{A,o}\), only for \(o\in A\), such that
\[ \sum_{o\in A}x_{A,o}=P\mu_A \quad\text{for every type }A, \qquad \sum_{A:o\in A}x_{A,o}\le s_o q_o \quad\text{for every option }o. \]
The decision form asks whether such a menu exists with \(\sum_o s_o q_o\le B\). A solution is the order vector \(q\), together with an assignment of the population mass that certifies validity.

A natural regime is a large institutional or humanitarian meal programme: many diners, but a comparatively small support of recurring dietary profiles, such as vegan, vegetarian, halal, and allergy-related restrictions. The organizer knows the fractions in each group and centrally allocates the food; whole orders retain their ordinary meaning, while demands scale with the population. The per-capita menu size is \(\sum_o s_o q_o/P\). This is close to the authors’ problem in its acceptability model, capacity constraint, allocation role, and waste-minimizing objective. It changes the population representation by aggregating identical diners into types with mass.

The hardness transfers to this mirror. Set \(P=n\) and \(\mu_A=|N_A|/n\), where \(N_A\) is the set of original agents with acceptability set \(A\). Then each type has integer mass \(|N_A|\), and aggregating equal types preserves the optimistic matching question. Conversely, the matching network with these integer capacities has an integral flow whenever it has a feasible flow, so the continuous assignment does not change whether the finite instance is valid. Proposition 4.2 therefore gives NP-hardness for the mirror’s decision problem; feasibility for a proposed menu is checkable by a flow computation, giving NP-completeness. I expect this general mirror to be Class B: hardness transfers. Its further questions include whether the problem becomes tractable or fixed-parameter tractable for bounded support size \(\tau\), and how closely its optimum can be approximated from the fully divisible food-allocation relaxation.

The weakest point is the gap between general hardness and the intended high-multiplicity regime. The Proposition 4.2 reduction can use a growing number of distinct acceptability types, so it does not establish hardness when there are many diners but few types. Also, the mirror keeps order quantities integral. That is faithful to the paper’s menu decision and to whole food orders; if order quantities were made continuous too, optimistic minimum total capacity would simply equal the population mass \(P\), erasing the menu-rounding question. This case supports asking the authors’ problem over continuous populations, but it does not claim their hardness result settles the small-\(\tau\) case.

The case AGAINST (opponent, writing after the proponent)

Proposition 4.2 is a real computational result, so the strongest available objection is not that the paper lacks anything to mirror. The weakness is the gap between its reduction and the high-multiplicity regime that would make the mirror valuable. The proponent’s construction sets \(P=n\) and gives each type mass equal to its original headcount divided by \(n\). In the 3-Dimensional Matching reduction, the number of distinct acceptability types can grow with \(n\). That embeds the original instance in a distribution; it does not establish hardness when a large population has a small support of recurring dietary profiles.

The strongest version of the proposed mirror—many diners, few dietary types, central allocation, but whole orders—does make sense. Its computational payoff is less clear. If order quantities become divisible, the minimum total capacity is exactly \(P\): assign each type’s mass to acceptable options and order precisely the capacity used. If orders remain whole, rounding each option’s assigned load up to a whole order adds at most \(\sum_o s_o\) capacity. With a fixed menu of options and serving sizes, the excess per diner therefore vanishes as \(P\) grows. Exact optimization can still depend on batch rounding, but that is a narrow arithmetic effect; the paper’s hardness result does not show it persists in the bounded-support population regime.

The pessimistic result, Proposition 4.3, is a weaker alternative anchor. Its characterization reserves one serving for a particular agent: \(\operatorname{size}(M|A_i)\ge 1+\rho_i(M)\). Under population normalization, that reserve is \(1/P\) and disappears. Requiring only almost every diner to be fed lets a null set go hungry; retaining a guarantee for every diner retains atomic individuals. A robust group-level consumption model might still be worth defining, but its guarantee would need new semantics and analysis.

That leaves a meaningful challenge, not a decisive rejection. The large catering or humanitarian programme with a few repeated dietary profiles is a plausible high-multiplicity setting, and the optimistic question survives the arguments above. I cannot make the universal claim that no worthwhile mirror exists convincing. The negative case is strongest as a caution: Proposition 4.2’s hardness transfer does not itself establish the payoff in the regime ChoCo cares about; the bounded-support version would need to carry that case.
