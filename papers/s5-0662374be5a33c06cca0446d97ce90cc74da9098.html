The continuous mirror question

Given a finite report domain \(D\), a population support \(T\subseteq D\) with rational masses \(\mu_t>0\) summing to one, and sample access to \(Z_{tu}=v(t,O)\) for \(O\sim\mathcal A(u)\), where \(u\in T\), can one compute and sample lotteries \(q_t\in\Delta(T)\) for every report \(t\in D\) such that \(\sum_{t\in T}\mu_tq_t(u)=\mu_u\) for each \(u\), the lotteries form a truthful common-price menu, and population welfare is within \(\epsilon\) per unit mass of the best balanced coupling, in expected time and sample complexity polynomial in \(|D|,\ |T|,\ 1/\epsilon\), and the input bit length?

The model it lives in

A mass replica–surrogate market: type \(t\) has population mass \(\mu_t\), surrogate type \(u\) has capacity \(\mu_u\), and sampled pair values have expectations \(w_{tu}\). Choose a balanced assignment policy \(q_t(u)\) maximizing \(\sum_{t\in T}\mu_t\sum_{u\in T}q_t(u)w_{tu}\), while each report type \(t\in D\) receives a lottery maximizing \(\sum_{u\in T}w_{tu}q(u)-\delta\sum_{u\in T}q(u)\log q(u)-\sum_{u\in T}\alpha_uq(u)\) for common prices \(\alpha\). Truthfulness remains pointwise menu choice; the balance constraint is imposed on the population masses.

The objection that survived

What the mirror covers

The mirror covers the replica–surrogate matching subproblem underlying Theorem 5.9. It does not directly continuize the Bernoulli-factory results, the full end-to-end reduction, or its type-space dimension bounds.

Open questions for a prover

  • Can the balanced lotteries and common prices be computed with exact mass balance using only sample access to the pair values?
  • Can expected runtime and sample complexity be bounded polynomially in support size, report-domain size, input bit length, and \(1/\epsilon\)?

The case FOR (proponent)

The strongest positive case is the replica–surrogate matching subproblem. The lead anchor is Theorem 5.9, proved in this paper: for suitable parameters, the online entropy-regularized matching algorithm achieves expected welfare within additive \(\epsilon\) per replica of the optimal replica–surrogate matching, and runs in time polynomial in \(m\) and \(1/\epsilon\), given oracle access to the allocation algorithm. The paper’s proof uses sampled values for replica–surrogate pairs and produces a matching that supports the incentive-compatible reduction. [Theorem 5.9](https://arxiv.org/html/1703.04143)

A plausible high-multiplicity regime is a large allocation platform processing many users from a stable set of \(\tau\) complete valuation types, with \(N\gg\tau\). In the paper’s matching construction, replicas and surrogate reports are drawn from the same prior; when many copies share each type, type masses are a natural description of that virtual market. The type must include the user’s full valuation function and every other feature that affects their value. The sampled outcomes of the allocation algorithm remain part of the model, so the mirror retains the paper’s sample-only access to pair values.

Call the proposed problem Mass Replica–Surrogate Matching from Sampled Values. An instance consists of a finite type set \(T\), rational masses \(\mu_t>0\) summing to one, an induced allocation oracle \(\mathcal A(u)\) for each surrogate type \(u\), and valuations \(v(t,o)\in[0,1]\). For each pair \((t,u)\), the oracle supplies samples of \(Z_{tu}=v(t,O)\), where \(O\sim\mathcal A(u)\); write \(w_{tu}=\mathbb E[Z_{tu}]\). For load \(k\), the replica population has mass \(k\mu_t\) of type \(t\), and surrogate type \(u\) has capacity \(k\mu_u\). A solution is a lottery \(q_t\in\Delta(T)\) for every replica type \(t\), with exact mass balance \(\sum_t\mu_tq_t(u)=\mu_u\) for each \(u\).

To preserve the mechanism-design question, require each \(q_t\) to be maximal-in-range: for common prices \(\alpha_u\) and regularization parameter \(\delta>0\), it maximizes
\[ \sum_u w_{tu}q(u)-\delta\sum_u q(u)\log q(u)-\sum_u\alpha_uq(u). \]
The associated common menu cost gives truthful payments, up to an additive constant. The target welfare is within \(\epsilon\) per unit mass of the best balanced coupling, \(\mathrm{OPT}_{\mathrm{mass}}=\max_q\sum_{t,u}\mu_tq_t(u)w_{tu}\). The computational question is whether this policy, including an exact sampler for its lotteries, can be obtained with expected time and sample complexity polynomial in \(\tau\), \(1/\epsilon\), and the input bit length, rather than in a finite clone count. With known weights, entropy-regularized transport is a finite convex program and loses at most \(\delta\log\tau\) welfare per unit mass; the hard part is preserving exact mass balance and truthful incentives when the \(w_{tu}\) are available only through samples.

I expect Class A, as a plausible extension of the paper’s price updates and Bernoulli-factory sampling to finitely many mass types. Clearing rational masses gives a concrete bridge back to finite matching markets: the transportation polytope has integral vertices, so aggregate flows can be realized by lotteries over capacity-respecting matchings. The open questions are whether the sample-only algorithm can produce the balanced lotteries with exact maximal-in-range behavior, and how its runtime depends on support size and bit length. Extending the construction to type supports that grow with the population is a separate issue.

The weakest point is that replicas and surrogates are auxiliary objects in the paper’s reduction, not a real society of participants. Its exact BIC argument is for a finite matching mechanism; the proposed mirror treats type mass as the matching decision variable and requires a mass-menu interpretation of individual incentives. The paper’s own fractional matching program makes that extension recognizable, but Theorem 5.9 does not prove it. This mirror covers that matching subproblem only, not the entire black-box reduction or the paper’s Bernoulli-factory results. The paper’s “continuous type spaces” concern each agent’s preference domain; they do not themselves make the population continuous. The positive case rests on Theorem 5.9, an algorithmic anchor; the paper offers no comparable numbered hardness result to anchor a hardness-dissolution claim.

The case AGAINST (opponent, writing after the proponent)

The replica–surrogate matching result is a real computational anchor: the paper gives a polynomial time algorithm, using samples, that approximately preserves matching welfare while supporting the BIC reduction. So the “no computational result to mirror” argument does not apply.

The strongest objection is that the \(km\) replicas and \(m\) surrogates are internal samples chosen by the reduction, not participants in an underlying society. Their size is an algorithm parameter. Replacing their type counts by masses yields a balanced transport problem, but that alone does not preserve the result’s incentive claim. BIC concerns an individual who can report any type in the paper’s domain, including types outside the prior’s support. A coupling defined only for the finitely many positive-mass types cannot establish those comparisons. Extending it to every report type requires an allocation map over the whole type domain; with a continuous domain, that is a different, richer mechanism-design problem than the finite mass-coupling formulation proposed here.

That objection weakens considerably against the best alternative: define an atomless matching market over a type measure, and require a pointwise truthful menu for every possible report. This is a coherent continuous-population question, and the paper’s entropy regularization and price interpretation make it recognizable. I do not see an honest basis for claiming that no scenario could make it worthwhile. The negative case is strongest as a warning that the proposed finite mass coupling is not itself a mirror of the paper’s full BIC guarantee; it does not defeat the more general continuum-market version.
