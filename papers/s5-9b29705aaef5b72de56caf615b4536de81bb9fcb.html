The continuous mirror question

Given a finite type set \(T\), rational masses \(\mu_t\) summing to \(1\), self-qualification bits \(\sigma_t\), cross-agent qualifications \(\Phi(t,u)\) for an agent of type \(t\) judging a different agent of type \(u\) including \(u=t\), a target type set \(P\), and rational budget \(B\), choose \(x_t\in[0,\mu_t]\) with \(x_t=0\) for \(t\in P\) and \(\sum_t x_t\le B\). Let \(S(x)=\{t:\mu_t-x_t>0\}\), evaluate the iterative-consensus closure using \(\sigma_s=1\) and \(\Phi(r,s)=1\) for every present type \(r\) in \(Q_0\), and in iteration \(i\) requiring \(Q_{i-1}\ne\varnothing\), \(\sigma_s=1\), and \(\Phi(r,s)=1\) for every \(r\in Q_{i-1}\). Decide whether every surviving agent of every target type in \(P\) belongs to some \(Q_i\).

The model it lives in

A high-multiplicity, finite-type society with rational mass \(\mu\); \(x_t\) deletes mass at unit cost, and feasibility is determined by the support-induced \(f^{\mathrm{IC}}\) closure. Because unanimity ignores positive mass magnitudes, optimal \(x_t\) is effectively all-or-nothing, making this a weighted support-deletion mirror rather than an LP.

The objection that survived

The stated profile \(\Phi:T\times T\to\{-1,1\}\) conflates an agent's self-qualification with its opinion about other members of the same type, so the mirror needs separate self and same-type cross-opinion data.

fatal: False

What the mirror covers

It mirrors Theorem 9.2's \(f^{\mathrm{IC}}\)-constructive group control by deleting individuals; it does not cover the thesis's other objectives, rules, bribery and microbribery variants, or relaxed-deletion results.

Open questions for a prover

  • Does NP-hardness persist for arbitrary rational type masses and budgets when the number of types is part of the input?
  • Can the separate self and same-type cross-opinion convention be formalized so the reduction is preserved exactly?
  • What is the complexity under a mass-threshold consensus rule, where partial deletion has a genuine marginal effect?

The case FOR (proponent)

My strongest mirror is anchored in Theorem 9.2 (the result labelled thm:ic_cgcdi_npc), proved in the thesis.

The theorem states that \(f^{\mathrm{IC}}\)-Constructive Group Control by Deleting Individuals is NP-complete and W[2]-hard with respect to the deletion budget \(\ell\). An instance consists of a finite individual set \(N\), a binary qualification profile \(\varphi\), a constructive target set \(A^+\), and \(\ell\); one may delete at most \(\ell\) individuals outside \(A^+\), and asks whether every member of \(A^+\) can be made socially qualified under the iterative-consensus rule \(f^{\mathrm{IC}}\). The proof is given here, by reduction from Set Cover.

I would mirror it as Continuous Iterative-Consensus Constructive Mass Control.

An instance consists of:

  • a finite set \(T\) of complete agent types;
  • rational masses \(\mu_t>0\), with \(\sum_{t\in T}\mu_t=1\);
  • a binary type-level qualification profile \(\Phi:T\times T\to\{-1,1\}\);
  • a constructive target set \(P\subseteq T\);
  • a rational mass budget \(B\).

A type contains everything relevant to the problem: its self-qualification status, its qualifications of every other type, and its deletion price. Thus a type is a genuine cohort of interchangeable agents, not merely a shared preference label.

The action is a deletion vector \(x\), with \(0\le x_t\le\mu_t\), \(x_t=0\) for target types, and

\[ \sum_{t\in T}x_t\le B. \]

The remaining mass of type \(t\) is \(\bar\mu_t=\mu_t-x_t\), and its type remains present exactly when \(\bar\mu_t>0\). Let \(S(x)=\{t:\bar\mu_t>0\}\). Define

\[ Q_0(x)=\{s\in S(x):\Phi(r,s)=1\text{ for every }r\in S(x)\}. \]

For \(i\ge1\),

\[ Q_i(x)= \left\{ s\in S(x)\setminus\bigcup_{j<i}Q_j(x): \begin{array}{l} \Phi(s,s)=1,\quad Q_{i-1}(x)\neq\varnothing,\\ \Phi(r,s)=1\text{ for every }r\in Q_{i-1}(x) \end{array} \right\}. \]

The question is whether \(P\subseteq\bigcup_{i\ge0}Q_i(x)\). A solution is the deletion vector \(x\).

This is the same problem the authors study: the same qualification graph, the same iterative-consensus aggregation, the same constructive deletion objective. Only the population has become a distribution over repeated role-types, and deletion is measured in mass rather than people.

A natural regime is a large online community, professional association, or platform population divided into recurring organizational or behavioural cohorts. Members of a cohort have the same self-assessment, the same qualification policy toward every other cohort, and the same control cost. The number of agents can be \(q|T|\), with \(q\gg |T|\); the relevant input is the type distribution, not the names of millions of interchangeable participants.

Theorem 9.2’s Set Cover reduction survives this continuization, so I expect hardness to transfer, placing this mirror in Class B. Give every role-type equal positive mass. Each individual in the reduction becomes a type: the element types \(a_x\), set types \(a_{F_i}\) and \(\tilde a_{F_i}\), and the chain types \(a_\ast,z_\ast\). Deleting a complete \(\tilde a_{F_i}\)-type has the same effect as deleting that individual in the proof.

Crucially, partial deletion does not create a fractional Set Cover. If any positive mass of \(\tilde a_{F_i}\) remains, that type is still present in the universal-consensus test and still blocks the relevant element types. Hence a useful deletion either removes the entire type or has no logical effect. With each type having mass \(1/|T|\), budget \(k/|T|\) permits at most \(k\) complete type deletions, and the successful deleted types are exactly a set cover. The hardness is therefore driven by the combinatorics of the qualification graph and the agenda of types, not by the number of individually named agents.

This also explains why the mirror is worth asking even though the answer is likely negative from the tractability perspective: it identifies a precise boundary. If unanimity is replaced by a positive support threshold, or if the objective requires only \(1-\varepsilon\) of each target mass to qualify, partial deletion becomes effective and the Set Cover obstruction may collapse into a linear or fractional optimization problem.

My weakest point is that \(f^{\mathrm{IC}}\) uses unanimity. Consequently, the continuous model is partly a weighted finite role system: an arbitrarily small surviving mass of a dissenting type has the same logical force as one dissenting individual. A referee could reasonably prefer a majority- or share-based consensus rule as a more genuinely mass-sensitive analogue. That criticism does not invalidate this mirror, but it limits its scope: this is a strong continuous-population counterpart to the thesis’s constructive control result, not a claim that every group-identification attack becomes an LP after continuization.

The case AGAINST (opponent, writing after the proponent)

The only serious anchor is Theorem 9.2, the NP-completeness and W[2]-hardness of \(f^{\mathrm{IC}}\)-Constructive Group Control by Deleting Individuals. The strongest case against its mirror is that the proposed continuization is not genuinely continuous: unanimity makes every positive-mass type an indivisible veto block.

There is also a formal defect in the proposed model. A type-level relation \(\Phi(t,t)\) cannot simultaneously represent an agent’s opinion of themself and their opinion of other members of the same type. A repaired model needs, at minimum, a self-qualification bit and a separate same-type cross-opinion. That repair is possible, but it exposes the deeper problem.

Under the proposed rule, the outcome depends only on

\[ \operatorname{supp}(\mu-x)=\{t:\mu_t-x_t>0\}, \]

not on the remaining masses. If any positive mass of type \(t\) survives, that type continues to participate in every universal-consensus test exactly as before. Therefore every partial deletion \(0<x_t<\mu_t\) is useless: it can be replaced by \(x_t=0\) without changing the outcome and while reducing the cost. Every optimum has the form

\[ x_t\in\{0,\mu_t\}. \]

Thus the alleged continuous control problem is simply a weighted finite support-deletion problem. The mass variable has no marginal meaning; deleting \(1\%\) or \(99\%\) of a cohort has exactly the same social effect as deleting none. The proposed Set Cover encoding works precisely because the continuum has collapsed into a collection of indivisible logical vertices.

This is more than the permitted observation that “continuous does not help.” The issue is that the model does not describe a society whose aggregate behaviour is represented by mass. It describes a finite qualification graph whose vertices have weights. In a genuinely nonatomic interpretation, the difficulty is worse: a measure-zero dissenting set can block unanimity if the rule quantifies over every agent, while ignoring that set makes the rule depend only on an essential-support convention. The result is representation-sensitive and discontinuous at zero mass.

The natural rescue is to replace unanimity with a mass threshold, for example requiring that a type be approved by at least a \(\theta\)-fraction of the current population, or to require only \(1-\varepsilon\) of a target mass to qualify. That would make partial deletion meaningful. But it is no longer the \(f^{\mathrm{IC}}\) problem in Theorem 9.2: it is a new weighted or approximate consensus rule. The thesis itself presents majority-based iterative consensus as future work, so this may be worthwhile research, but it cannot be claimed as a continuous mirror of the named theorem without a new model and new complexity result.

The negative case is therefore strongest only under a strict requirement that the mirror preserve the paper’s unanimous iterative-consensus semantics. Under that requirement, every faithful continuization degenerates to weighted support deletion, and every genuinely mass-sensitive repair changes the social rule. But I cannot honestly claim that this defeats the anchor universally. The recurring-cohort scenario is plausible, the high-multiplicity regime is legitimate, and the theorem does yield a clean Class B mirror after the formal repair. The other analyst’s anchor probably survives; the negative case is weak rather than decisive.
