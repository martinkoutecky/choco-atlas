The continuous mirror question

Given a finite set of chore species \(E\), additive cost types \(T\) with rational costs \(a_{t,e}\), rational type masses \(\mu_t\) summing to \(1\), and rational per-capita supplies \(\rho_e\), compute a minimum-cost finite-support rational allocation \(x_{t,b}\) over integral bundles \(b\in\mathbb{Z}_{\ge0}^{E}\). Require \(\sum_b x_{t,b}=\mu_t\), \(\sum_{t,b}x_{t,b}b_e=\rho_e\), and, for every pair of support bundles \(x_{t,b},x_{u,b'}>0\), \(c_t(b)\le \frac{3}{2}\operatorname{MMS}_t(2,b+b')\), where \(c_t(b)=\sum_e a_{t,e}b_e\) and \(\operatorname{MMS}_t(2,q)=\min_{z\in\mathbb{Z}_{\ge0}^{E},\,0\le z\le q}\max\{c_t(z),c_t(q-z)\}\). The objective is \(\sum_{t,b}x_{t,b}c_t(b)\).

The model it lives in

A high-multiplicity indivisible-chore allocation in which type \(t\) carries mass \(\mu_t\), each support point is an integral bundle, \(x_{t,b}\) assigns mass to bundles, \(\rho_e\) enforces per-capita supply, and aggregate cost is minimized subject to exact pairwise \(3/2\)-PMMS compatibility.

The case FOR (proponent)

The strongest positive case is anchored by the paper’s only clear named algorithmic result, rather than by inventing a hardness claim.

The lead anchor is Corollary 3.1, proved in this paper: when agents have additive cost functions, the round-robin algorithm produces a \(3/2\)-PMMS allocation in polynomial time. Its underlying problem is the allocation of indivisible chores among \(n\) agents, where PMMS requires, for every pair \(i,j\), \(c_i(A_i)\leq \frac{3}{2}\operatorname{MMS}_i(2,A_i\cup A_j)\). The corollary follows from the paper’s proved Proposition 3.7, which says that every \(\alpha\)-EF1 allocation is \(\frac{2\alpha+1}{\alpha+1}\)-PMMS, tightly; setting \(\alpha=1\) gives \(3/2\)-PMMS, while round-robin supplies EF1.

My continuous mirror would be the following.

Call it HM-\(3/2\)-PMMS Chore Allocation. The input consists of:

  • a finite catalogue of chore species \(E=\{e_1,\ldots,e_m\}\);
  • a finite set of complete additive cost types \(T=\{1,\ldots,\tau\}\), where type \(t\) has costs \(a_{t,e}\in\mathbb{Q}_{\geq 0}\) and hence \(c_t(b)=\sum_e a_{t,e}b_e\);
  • rational type masses \(\mu_t\), with \(\sum_t\mu_t=1\);
  • rational per-capita chore supplies \(\rho_e\).

A bundle is still indivisible: \(b\in\mathbb{Z}_{\geq0}^m\) records how many copies of each chore species one agent receives. The decision variable is \(x_{t,b}\), the mass of type-\(t\) agents receiving integral bundle \(b\). It must satisfy \(\sum_bx_{t,b}=\mu_t\) and \(\sum_{t,b}x_{t,b}b_e=\rho_e\) for every chore species \(e\).

For two bundles \(b,b'\), define

\(\operatorname{MMS}_t(2,b+b')=\min_{0\leq z\leq b+b'}\max\{c_t(z),c_t(b+b'-z)\}\),

where \(z\) ranges over integral sub-bundles. The allocation is \(3/2\)-PMMS if, whenever \(x_{t,b}>0\) and \(x_{u,b'}>0\), we have

\(c_t(b)\leq \frac{3}{2}\operatorname{MMS}_t(2,b+b')\).

The computational question is: given \((E,T,\mu,\rho)\), construct a finite-support rational \(x\) satisfying these mass-balance and support-wise PMMS constraints, or report that none exists. The objective is feasibility—produce an actual allocation of integral bundles to population mass—not merely fractional expected bundles. A natural harder extension is to minimize the aggregate social cost \(\sum_{t,b}x_{t,b}c_t(b)\) subject to the same constraints.

This is a credible high-multiplicity regime. Think of a large municipal workforce or repeated institutional task pool. There are many workers or teams, but only a modest number of complete cost profiles determined by qualification, contract, risk, and workload category. The number of agents is enormous, while \(\tau\) remains small. The chores also scale: each task species has many indistinguishable copies, so the per-capita supply \(\rho_e\) stays meaningful. Every worker still receives an indivisible bundle; only the mass of workers receiving each bundle is continuous.

The mirror is therefore not a fractional-chore formulation. It preserves the paper’s underlying objects: additive cost functions, indivisible bundles, and the exact PMMS predicate based on integral two-partitions. Population mass is active because the algorithm chooses how much of each cost type receives each integral configuration. A rational common denominator gives the bridge back to finite instances: clearing denominators turns \(x\) into a large discrete population with \(N\mu_t\) agents of type \(t\) and \(N\rho_e\) copies of each chore species. Conversely, aggregating a finite high-multiplicity allocation gives \(x\).

I would tentatively place the feasibility problem in Class A for additive costs. The paper’s proof route is unusually promising: EF1 is generated by round-robin, and Proposition 3.7 converts EF1 into \(3/2\)-PMMS. In the high-multiplicity setting, one should be able to batch identical turns by type and chore species, or formulate the allocation over integral bundle configurations. The real theorem target would be a polynomial algorithm in \(m\), \(\tau\), and the encoding length of \(\mu,\rho,a\), rather than in the enormous cleared denominator \(N\).

The further question is whether the minimum-social-cost version remains Class A. A configuration formulation has potentially exponentially many integral bundles, and PMMS is support-sensitive: if two incompatible bundle patterns both receive positive mass, the allocation fails. Thus the raw configuration LP is not automatically sufficient. One needs either a batched round-robin construction, a separation/pricing theorem, or a finite-support and rounding argument. That is a genuine continuous-computational question, not a disguised average-cost calculation.

The authors would recognize this as their problem because the fairness predicate has not been weakened to expected costs or type averages. The only co-modifications are the ones forced by high multiplicity: chore supplies scale with population, and identical agents are represented by mass. This is closer to the paper’s intended setting than a continuum in which each agent receives a fractional chore.

The weakest point is exactly the support issue. The paper proves polynomiality for explicitly listed agents and chores; it does not prove that round-robin can be compressed to polynomially many type-level configurations when multiplicities are given in binary. Nor is the PMMS feasible region obviously convex. If that compression fails, the mirror could become Class C because of continuum-specific configuration-support hardness. But that is a substantive open boundary around a faithful mirror, not evidence that the mirror is artificial.

I would scope the case narrowly to Corollary 3.1 and its Proposition 3.7 bridge. The paper contains no named NP-hardness result, so I would not claim hardness dissolves or transfers. The positive claim is instead that its polynomial-time \(3/2\)-PMMS result naturally generates a precise, high-multiplicity computational problem whose central issue is exactly whether the discrete round-robin argument admits a genuine population-level compression.

The case AGAINST (opponent, writing after the proponent)

The best negative argument defeats the proponent’s *specific feasibility formulation*, but not the underlying mirror.

For rational \((\mu,\rho)\), clear denominators and obtain a finite instance with many agents and chore copies. Corollary 3.1 then guarantees a \(3/2\)-PMMS allocation via round-robin. Hence the proposed “construct an allocation or report none” problem has no NO instances: feasibility is vacuous. The only remaining issue is whether the finite allocation can be represented succinctly in the input bit-length.

Moreover, PMMS is not a convex population-level constraint. If \(x_{t,b}>0\), the bundle \(b\) must be compatible with every other bundle in the support, however tiny its mass. Thus the mass variables only enforce balance; the substantive problem is selecting a pairwise-compatible family of integral bundle configurations. That is a support-selection and packing problem, not the sort of continuous LP or pricing problem that motivates the programme. Replacing these support-wise constraints by average-cost constraints would restore convexity, but would no longer be the paper’s PMMS notion.

This does weaken the claimed anchor: the continuous version of Corollary 3.1 itself contributes no feasibility landscape, and any hardness comes from integral bundle configurations and support compatibility rather than from population multiplicity. But it does not establish the universal negative case. The stronger version—minimizing aggregate social cost over \(3/2\)-PMMS high-multiplicity allocations—is exactly a natural continuization of the paper’s price-of-fairness question, with heterogeneous cost types making the objective nontrivial. I therefore cannot honestly claim that no worthwhile mirror exists: the feasibility formulation is weak, but the high-multiplicity optimization mirror survives.
