The continuous mirror question

Given finite complete agent types \(T\) with rational masses \(\mu_t\), bundles \(D\), utilities \(u_t(d)\), per-capita resource bound \(b\), resource use \(a(d)\), and nonnegative welfare weights \(\lambda_t\), find an incentive-compatible direct mechanism \(y(d\mid r)\) maximizing \(\sum_{t\in T}\mu_t\lambda_t\sum_{d\in D}y(d\mid t)u_t(d)\), subject to \(\sum_d y(d\mid r)=1\), \(y(d\mid r)\ge 0\), \(\sum_t\mu_t\sum_d y(d\mid t)a(d)\le b\), and truthful reporting being optimal for each type.

The model it lives in

A high-multiplicity cooperative membership with finitely many complete agent types, rational type masses \(\mu_t\), per-capita resources, and integral bundles for each member. The decision is a lottery \(y(d\mid r)\) for each reported type; maximize mass-weighted welfare subject to resource feasibility and type-by-type incentive compatibility.

The objection that survived

The mirror replaces named-player joint actions and intermediate-coalition threats with per-type bundle allocations, so it captures only grand-coalition incentive efficiency and may be seen as a mechanism-design extension.

fatal: False

What the mirror covers

The mirror covers Proposition 1’s incentive-efficiency and virtual-surplus characterization; it leaves the S-solution’s egalitarian threats and coalition values, Theorems 1–3, and Proposition 4’s nonexistence result unmirrored.

Open questions for a prover

  • For compactly described or exponentially large bundle sets \(D\), can the virtual-surplus pricing problem be solved efficiently?
  • What welfare and feasibility guarantees follow when a mechanism for rational masses is rounded to a finite membership?

The case FOR (proponent)

The strongest positive case is narrow: Proposition 1, proved in this paper, is a formulation based anchor. The paper contains no named result placing a problem in P, proving it NP-hard, or giving another complexity classification. Proposition 1 instead characterizes the underlying problem of finding an incentive efficient mechanism. It says that an incentive compatible mechanism is incentive efficient exactly when there are nonnegative utility weights \(\lambda\), not all zero, and nonnegative multipliers \(\alpha\) for the incentive constraints such that (1) complementary slackness holds for every truth-telling constraint, and (2) at every information state, the mechanism assigns positive probability only to decisions maximizing the sum of the players’ virtual utilities. Those virtual utilities are the players’ actual utilities adjusted by \(\lambda\) and \(\alpha\); the paper derives the characterization from its primal and dual linear programs and uses it in its examples.

A plausible regime is a large mutual insurance or public service cooperative: many households share a relatively small set of complete types, including their valuations, service needs, and relevant constraints. The instance is a distribution \(\mu\) over those types, with \(\mu_t\) the fraction of members of type \(t\). The number of members is large while the support size \(\tau\) remains modest. Per capita resources scale with the population. Each member receives an integral service bundle, while a type’s average allocation can be fractional.

The lead mirror is Continuum Incentive Efficient Allocation. An instance consists of a finite type set \(T\), rational masses \(\mu_t\) summing to one, a finite set \(D\) of bundles, a per capita resource bound \(b\), each type’s rational utility \(u_t(d)\), resource use \(a(d)\), and nonnegative welfare weights \(\lambda_t\), not all zero. Find a direct mechanism \(y(d\mid r)\) that assigns a lottery over bundles to each reported type \(r\), maximizing

\[ \sum_{t\in T}\mu_t\lambda_t\sum_{d\in D}y(d\mid t)u_t(d) \]

subject to \(\sum_d y(d\mid r)=1\), \(y(d\mid r)\ge 0\), per capita feasibility

\[ \sum_{t\in T}\mu_t\sum_{d\in D}y(d\mid t)a(d)\le b, \]

and incentive compatibility for every pair \(t,r\):

\[ \sum_{d\in D}y(d\mid t)u_t(d)\ge \sum_{d\in D}y(d\mid r)u_t(d). \]

The solution is the optimal mechanism \(y\), or a report that the instance is infeasible. This asks for the underlying incentive efficient allocation, not for an encoding.

For explicitly listed bundles, I expect this mirror to be Class A: it is a linear program with size polynomial in \(\tau\), \(|D|\), the resource dimension, and the input bit length. As in Proposition 1, the dual multipliers give a virtual surplus interpretation. If bundles have a compact description and exponentially many possibilities, the next question is whether the resulting virtual surplus can be optimized efficiently; that could make pricing the real bottleneck. A high multiplicity dictionary would also ask how rounding a mechanism for rational masses to a finite society affects feasibility and welfare.

This mirrors only the paper’s incentive efficient mechanism problem. It does not continuize the S-solution’s coalition threats or Shapley value construction. The paper’s prior \(p\), a probability distribution over private information profiles, is not itself a population distribution; the mirror’s \(\mu\) represents actual population mass. The paper’s Theorem 3 concerns the relationship to the Harsanyi NTU value, and Proposition 4 proves nonexistence for a particular game; neither is a computational complexity result. The weak point is whether the authors would accept this as their problem: their mechanisms choose joint actions for a finite set of strategic players, while this mirror allocates per capita bundles to a continuum of members. They may recognize the shared incentive efficiency and virtual utility problem but see the population allocation model as a substantive extension.

The case AGAINST (opponent, writing after the proponent)

The anchor does not establish a computational result to mirror. Proposition 1 characterizes incentive efficiency in a finite Bayesian game through LP optimality conditions: complementary slackness for incentive constraints and maximization of virtual surplus at each information state. The paper gives no complexity classification, algorithmic problem statement, or running time. It uses the characterization to define and analyze solution concepts. So the proposed mirror is not a continuous version of a computational result in this paper.

The proposed population allocation LP is coherent, but it changes the object. In the paper, a mechanism chooses a joint action for a finite coalition based on its members’ reported information; each player evaluates that mechanism using beliefs about the other named players’ types. In the proposed model, \(\mu\) is a distribution of agents, a resource constraint is added, and a planner allocates bundles to reported types. That resembles Bayesian screening, but it removes the coalition actions, threat mechanisms, and Shapley-based division of cooperative value that motivate the paper. Similar incentive constraints do not by themselves make it the same problem.

The strongest repair would be a large cooperative membership setting with many interchangeable participants in a few roles and private-information classes. One could scale resources per capita, let coalitions be described by role masses, and seek a continuum version of the S-solution. But the paper supplies no rule for how coalition action sets or payoffs vary with coalition mass. Nor does its finite Shapley-based equity condition specify a continuum value: an individual’s effect on mass vanishes, so a nontrivial limit needs an added normalization or a derivative-based value rule. Those choices would define a new cooperative model and solution concept, rather than continue a computational question the paper posed.

The negative case is strongest on attribution: the paper offers a useful LP characterization that could inspire a continuous population model, but no named computational result whose complexity landscape this programme could chart. Its weak point is that a researcher studying large cooperatives could plausibly regard the repaired model as a worthwhile extension of the paper’s incentive-efficiency framework. I would still not count that as a strong mirror of this paper: it requires new population and coalition primitives, and the clean LP proposal leaves out the paper’s central cooperative-value construction.
