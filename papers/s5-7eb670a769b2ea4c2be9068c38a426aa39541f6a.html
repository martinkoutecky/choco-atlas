The continuous mirror question

Given \(m\) bins and a finite set of \(\tau\) types with rational masses \(\mu_t\), values \(v_t\), and public resource requirements \(w_{tj}\), with \(\sum_t\mu_t=1\), find a maximum-welfare allocation \(x_{tj}\ge 0\) satisfying \(\sum_j x_{tj}\le\mu_t\) and \(\sum_t w_{tj}x_{tj}\le b_j\) for each bin, where \(b_j\) is its capacity per unit population. Interpret \(x_{tj}\) as mass of agents assigned wholly to bin \(j\); the society is atomless, so each type’s mass can be partitioned without splitting any individual’s assignment.

The model it lives in

A finite-support distribution of agent types, each recording value and public resource requirements, with atomless mass \(\mu_t\); decisions are assignment masses \(x_{tj}\), the objective is total welfare, and bin capacities scale per unit population. The resulting linear program has \(m\tau\) variables and is solvable in time polynomial in the input bit length.

The objection that survived

The LP does not encode individual monotonicity or truthful payments; this limits coverage, even though the proponent flags the gap.

fatal: False

What the mirror covers

Covers the welfare-allocation component of Corollary 2.11 for generalized assignment; it leaves the truthful-mechanism guarantee and the paper’s other offline and online applications aside.

Open questions for a prover

  • Can a continuum mechanism for this type distribution preserve individual truthfulness and achieve a nontrivial welfare approximation, with measurable whole-agent assignments and payments?
  • How does a mass-optimal allocation round to whole agents in large finite populations, and what additive welfare loss results?

The case FOR (proponent)

My strongest case is narrow and rests on Corollary 2.11, proved here as an application of the paper’s iterative packing framework: it gives a truthful \((2+\epsilon)\)-approximation mechanism for the generalized assignment problem among single-parameter agents. Here, each agent has a private value, while its resource requirements across bins are public. The result builds on the knapsack FPTAS of Briest, Krysta, and Vöcking [12]; this paper adds the loser-independence argument used to apply it in the iterative framework. The paper has no numbered NP-hardness or complexity-classification theorem to anchor instead.

A plausible high-multiplicity setting is a large system routing recurring service requests among facilities. Each request can go to at most one facility; its type records its resource requirements at each facility and its value. A million requests might have only dozens of distinct type profiles. As the number of requests grows, facility capacities grow proportionally too, so write \(b_j\) for facility \(j\)’s capacity per unit of population. This is a regime-specific story for generalized assignment, not a claim that every allocation market has few types.

Here is the mirror I would hand to a prover: High-Multiplicity Generalized Assignment Welfare. An instance has \(m\) bins and \(\tau\) types. Type \(t\) has rational mass \(\mu_t\), value \(v_t\), and public resource requirements \(w_{tj}\) for bin \(j\), with \(\sum_t\mu_t=1\). Bin \(j\) has per-capita capacity \(b_j\). Find an allocation \(x_{tj}\geq 0\) maximizing

\[ \sum_{t=1}^{\tau}\sum_{j=1}^{m}v_t x_{tj} \]

subject to

\[ \sum_{j=1}^{m}x_{tj}\leq\mu_t \quad\text{for every }t, \qquad \sum_{t=1}^{\tau}w_{tj}x_{tj}\leq b_j \quad\text{for every }j. \]

The output is the mass of each type assigned to each bin; unassigned mass is allowed. Since the population measure is atomless, \(x_{tj}\) represents a subset of type \(t\)’s agents assigned wholly to bin \(j\). It does not give any individual a fraction of a request or a split assignment. With binary-rational input, this is a linear program with \(m\tau\) variables, so its exact optimum is computable in time polynomial in \(m,\tau\), and the input bit length \(L\). I expect Class A.

This is recognizably the generalized-assignment allocation problem in Corollary 2.11: it has the same agents, bins, resource requirements, and welfare objective. The change is that repeated agents become mass, while capacities are normalized to population size. It covers the welfare-allocation problem underlying that corollary. It does not claim a continuous version of the corollary’s full truthful-mechanism guarantee.

That boundary is also the weakest point. The corollary is about truthful mechanisms, while the LP is only about finding an allocation. In an atomless population, an individual has no effect on aggregate type masses, so treating incentive compatibility as an ordinary unilateral-report condition risks making it vacuous. The LP is still a credible mirror of the underlying computational problem, but preserving the paper’s strategic content would require a further model of reports, payments, and individual influence.

The next questions are whether solutions to this mass problem yield useful additive guarantees for large finite populations, and whether a nontrivial truthful mechanism survives that limit. Those questions would test how much of Corollary 2.11’s computational and strategic content carries over.

The case AGAINST (opponent, writing after the proponent)

The strongest attack is that Corollary 2.11 is about a truthful mechanism, while the proposed LP mirrors only the welfare-allocation problem underneath it. The corollary’s content includes a monotone allocation algorithm, loser-independence, and the resulting incentive guarantee. A type-mass allocation does not specify how an individual’s report affects their own assignment or payment. In an atomless population, one person has zero mass, so an algorithm that sees only aggregate masses cannot by itself express that strategic effect. On this reading, the LP is not a mirror of the named result.

That objection does not defeat the better version. One could define a continuum mechanism with individual allocation probabilities or measurable subsets of each type, then ask for monotonicity and truthful payments. A person’s report would not change aggregate masses, but it could still change their own assignment. The proposed LP supplies a tractable allocation rule; whether it extends to a truthful mechanism is a genuine computational question. The paper’s single-parameter setting makes that extension especially plausible.

The welfare mirror also has a direct high-multiplicity interpretation: take many copies of each generalized-assignment type and scale bin capacities with population. The LP optimizes the resulting continuous allocation exactly. With fixed \(m\) and \(\tau\), its mass solution can be rounded to whole copies with bounded additive loss, so normalized welfare loss vanishes as the population grows. This is a meaningful bridge to the paper’s problem, even though it does not reproduce the corollary’s incentive guarantee by itself.

I can argue that the LP is a standard relaxation and may reveal little beyond the tractability created by divisibility. But under the programme’s stated standard, a tractable answer is still worth asking for; that is not a sound reason to reject the mirror. So the negative case against Corollary 2.11 rests on a real gap between welfare optimization and truthful mechanism design, but the gap motivates a stronger mirror rather than ruling one out. I cannot honestly support the universal claim that no worthwhile continuous mirror exists.
