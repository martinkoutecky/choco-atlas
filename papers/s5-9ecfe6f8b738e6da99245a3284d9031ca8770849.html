The case FOR (proponent)

The strongest positive opening is Theorem 1, proved in this paper. It says that for every monotonic TU-game and admissible \(\rho,\delta\), there is a unique subgame-perfect equilibrium; its average payoffs equal the discounted Shapley value with parameter \(\alpha=\delta(1-\rho)/(1-\delta\rho)\). It also gives limiting behavior: with fixed \(\delta<1\), as \(\rho\to1\), the average tends to equal division while proposer-specific offers remain separated; with fixed \(\rho\), taking \(\delta\to1\) or \(\delta\to0\) makes the average tend to the Shapley value or equal division, respectively. But this is a strategic implementation and characterization result, not a result about computational complexity. The other named results characterize values or establish convergence. There is no named computational result in the paper asserting tractability, hardness, or a parameterized complexity bound, so there is no eligible anchor under your criterion.

A plausible, but unanchored, follow-on question would use a high-multiplicity regime for cooperative bargaining. Let \(K\) be a fixed set of participant types, where members of each type share all bargaining-relevant attributes, and let \(\mu_k\) be each type’s population share. Suppose a coalition’s transferable worth is \(nW(x)\), where \(x\) is its vector of type masses divided by \(n\), and \(W\) is a monotone rational polynomial with \(W(0)=0\). In the finite replication, give every participant the same discounted-Shapley parameter \(\alpha_n=e^{-\lambda/n}\). The continuous problem is: given \(K,\mu,\lambda,W\), compute each type’s limiting per-person allocation \(a_k\), to additive error \(\varepsilon\). The natural candidate is

\[ a_k=\int_0^1 e^{-\lambda(1-u)} \left(\partial_k W(u\mu)+\lambda W(u\mu)\right)\,du. \]

Here mass represents population share, and the output is the type-level payoff. The regime could be a large cooperative workforce with many members but relatively few skill and contract types; worth depends on coalition composition. For this explicitly represented \(W\), I would expect the computation to be tractable, and the allocations satisfy \(\sum_k\mu_k a_k=W(\mu)\). The mirror covers only Theorem 1’s TU-game average-payoff result.

The soft spot is substantial: the proposed limit scales the discount parameter with population size and restricts coalition worth to a smooth composition function. The paper neither studies that limit nor makes a complexity claim. A prover would first need to establish the finite-to-continuous convergence and its error bounds; the computational classification would then depend on the encoding of \(W\). So this is a credible extension of the paper’s value calculation, but it cannot honestly be presented as a continuous mirror of a named computational result in the paper.

The case AGAINST (opponent, writing after the proponent)

The paper gives no named computational result to continuize. Theorem 1 proves uniqueness of a subgame-perfect equilibrium and identifies its average payoffs with the discounted Shapley value; it gives no input encoding, algorithm, or complexity bound. The other named results are value characterizations or convergence statements. The proponent’s own “unanchored follow-on” description concedes the point: there is no eligible computational anchor here.

The workforce proposal could become a sensible new computation problem, but it adds a polynomial worth function \(W\), a population-dependent parameter \(\alpha_n=e^{-\lambda/n}\), and an approximation task that the paper never defines. A direct continuum version also has a modeling gap: when a proposer exits, removing one person changes no mass, so a worth function of type masses is unchanged. Scaling total worth with population and scaling delay may yield a meaningful limit, but that is a new mass-based bargaining model whose convergence and computational input need to be specified. Those choices may be defensible; they do not turn Theorem 1 into a computational result.

There is already a continuum-player tradition for cooperative values: Hart and Mas-Colell study continuum-player solutions using potential and PDE methods, building on the Aumann–Shapley diagonal principle.[Hart and Mas-Colell (1995)](https://doi.org/10.1287/moor.20.4.959) That is analytic prior art, not a computational collision, so it does not rule out a later complexity study.

So the strongest honest negative is narrow: no paper-anchored ChoCo mirror survives. I cannot honestly claim that no worthwhile high-multiplicity computation could ever be built around this bargaining model. The workforce example is plausible as a separate project; it simply does not supply the missing computational anchor in this paper.
