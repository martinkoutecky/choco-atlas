The continuous mirror question

Given a finite set of roommate types \(T\), rational masses \(\mu_t>0\) summing to \(1\), and a strict ranking \(\succ_t\) of partner types for each \(t\), represent pairings by masses \(x_{tu}=x_{ut}\ge 0\) with \(\sum_{u\ne t}x_{tu}+2x_{tt}=\mu_t\). For distinct types \(t,u\), let \(b_t(u)\) be the mass of type \(t\) assigned partners it ranks below \(u\); require \(b_t(u)=0\) or \(b_u(t)=0\), and require \(b_t(t)=0\) to rule out same-type blocking. Determine the entire stable-pairing set in a finite-union-of-rational-polyhedra representation when it is nonempty; otherwise return a feasible pairing that is Pareto efficient under type-level first-order stochastic dominance.

The model it lives in

A type-symmetric continuous roommate market: each type has rational population mass and a strict ranking of partner types; symmetric pair-mass variables form feasible matchings, and stability and Pareto efficiency are defined over the types’ partner distributions.

The case FOR (proponent)

The strongest positive case is narrow. This paper has no named theorem classifying a problem as polynomial-time solvable, NP-hard, FPT, or similar. It cites Irving’s efficient algorithm, but does not state that as one of its own numbered results. Its closest usable anchor is Theorem 22, asserted and proved here: for a preference profile and its purified Borda ordering(s), mechanism \(\beta\) implements the full set of stable matchings when stable matchings exist, and returns a Pareto-efficient matching when none exists. That is a named result about computing outcomes, though not a complexity classification; the paper gives no running-time bound.

I would mirror that outcome problem in a large co-housing placement system. The agents are residents, and a type records the complete roommate-relevant description: for example, shared schedules, language needs, and a strict ranking of roommate types. A regime with thousands of residents but only a few dozen recurring types is plausible if many residents share those descriptions and rankings. Mass is the fraction of residents of each type.

Call the resulting problem Type-Symmetric Continuous Roommate Outcomes. An instance consists of a finite set \(T\) of types, positive rational masses \(\mu_t\) summing to \(1\), and, for each type \(t\), a strict ranking \(\succ_t\) of the possible partner types, including \(t\). A candidate solution is a symmetric mass pairing \(x\): for distinct types, \(x_{tu}=x_{ut}\) is the population fraction of \(t\)-\(u\) pairs; \(x_{tt}\) is the fraction of pairs within type \(t\). Feasibility requires
\[ \sum_{u\ne t}x_{tu}+2x_{tt}=\mu_t \]
for every \(t\).

For each type \(t\), let \(d_t(u)=x_{tu}\) when \(u\ne t\), and \(d_t(t)=2x_{tt}\). Let \(b_t(u)\) be the mass of type \(t\) paired with types it ranks below \(u\). The pairing is stable if no two positive masses can block: for every distinct \(t,u\), \(b_t(u)=0\) or \(b_u(t)=0\); and \(b_t(t)=0\) for every \(t\). The latter rules out two type-\(t\) residents, both assigned worse partners, pairing with each other. A pairing is Pareto-efficient if no feasible pairing gives every positive-mass type a weakly better partner lottery in the first-order stochastic sense and gives at least one type a strict improvement.

The search task is: return the entire set of stable mass pairings, in an exact finite-union-of-rational-polyhedra representation, if that set is nonempty; otherwise return a Pareto-efficient feasible pairing. This mirrors Theorem 22’s stable-outcomes-versus-efficient-fallback claim. It asks about the underlying roommate allocation problem, rather than about the mechanism’s Borda calculation.

I would expect this version to be tractable when parameterized by the number of supported types \(\tau=|T|\). For each type pair, stability is a disjunction of linear equalities: one side has no mass assigned below the other’s type, or the other side does. Enumerating those choices gives at most \(2^{\binom{\tau}{2}}\) rational linear programs; their feasible regions describe the stable set. If every region is empty, a linear program maximizing a positive weighted sum of rank scores yields a Pareto-efficient pairing. This suggests an FPT route in \(\tau\), not a claim that the paper already proves one. Further questions are whether the dependence on \(\tau\) can be improved, whether stable mass pairings always exist, and which such pairings arise as limits of finite roommate matchings.

The match to the paper is credible because it keeps the one-sided pairing objective, stability, and the Pareto-efficient fallback. It also uses high multiplicity directly: residents of a type are interchangeable for every feature the model uses. The main weakness is substantial. The paper ranks named individuals and its mechanism relies on an ordering of those individuals; this mirror ranks partner types and permits fractional mass pairing. That is a natural high-multiplicity roommate model, but it is a co-modification of the paper’s strict individual-preference model. Theorem 22 supports asking the question; it does not establish that the authors would accept this extension, or that its continuous answer has the same structure.

The case AGAINST (opponent, writing after the proponent)

The strongest case against this anchor is that Theorem 22 is not a complexity result. It says what mechanism \(\beta\) implements when stable matchings exist and what kind of outcome it returns otherwise. The paper gives no running-time bound, complexity classification, or parameterized algorithm for that mechanism. Theorem 20 is a structural characterization, too. Irving’s \(O(n^2)\) algorithm appears as cited prior work, not as a result of this paper. So the proponent has turned an implementation claim into a new mass-allocation search problem.

That new problem is coherent, but it changes what the mechanism acts on. In the paper, \(\beta\) repeatedly chooses a *named individual* using a Borda ranking computed from the current finite profile, then deletes a pair. A faithful mass limit would need to say how a zero-mass individual can take a turn, and how the result depends on tie-breaking among individuals with identical descriptions. Ranking partner *types* avoids those questions by changing strict rankings of named partners into rankings of categories. That may be a sensible roommate variant, but it does not preserve the identity-indexed preferences and Borda purification that drive this paper’s mechanism. The proponent’s stable-pairing formulation then asks a further new question: it replaces the mechanism’s outcome claim with a type-level stable set and an ex-ante Pareto criterion.

There is a credible route to a continuous roommate model, so the objection should stay narrow. Carmona explicitly formulates a nonatomic roommate market and proves stability existence under stated conditions; that is analytic prior art, which supports the plausibility of a continuum model rather than resolving its computational questions. [Carmona, “Stable matching in large markets with occupational choice”](https://onlinelibrary.wiley.com/doi/full/10.3982/TE5915). The proponent’s mass-pairing question could therefore be worthwhile research. Its weakness as a *mirror of this paper* is that the paper supplies no computational-complexity result for it to continue, and the closest way to obtain repeated types alters the preference model.

I cannot honestly make the universal negative case airtight: a computational study of stable mass pairings could be valuable in its own right. The strongest defensible verdict against this anchor is that it does not establish a worthwhile ChoCo mirror of this paper’s computational results.
