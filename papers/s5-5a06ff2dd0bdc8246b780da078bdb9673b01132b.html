The continuous mirror question

For fixed \(\varepsilon>0\), given a finite conflict graph \(G=(V,E)\), rational supplies \(b_v\geq 0\), and rational common additive values \(w_v\), with \(\rho=\max_{v:b_v>0}\sum_{u\in N_G(v)}b_u\leq 1/(3+\varepsilon)\), can one output in time polynomial in \(|V|,|E|\), and the binary input length \(L\) a rational finite-support distribution \(x_k\) over integral bundles \(k\in\mathbb{Z}_{\geq 0}^{V}\)? Require \(\sum_k x_k=1\), \(\sum_k x_k k_v=b_v\) for every \(v\), and \(\operatorname{supp}(k)\) independent in \(G\) for every bundle in the support. Also require that for every ordered pair \(k,l\) in the support there are integer removal vectors \(p\leq k\), \(q\leq l\), with \(\|p\|_1,\|q\|_1\leq 1\) and \(\sum_v w_v(k_v-p_v)\geq\sum_v w_v(l_v-q_v)\)?

The model it lives in

A mass-\(1\) population of one recipient type receives integral bundles from a fixed set of resource types. The input gives per-capita supplies \(b_v\), conflicts \(G\), and common additive values \(w_v\); the decision variable is a distribution \(x_k\) over feasible bundles, constrained to match each expected supply and satisfy \(\mathrm{EF}[1,1]\) between every pair in its support. The task is to find such a distribution; there is no separate optimization objective.

What the mirror covers

The mirror covers Theorem 1.6’s arbitrary-additive \(\mathrm{EF}[1,1]\) guarantee on scaled low-density instances; it leaves the other fairness algorithms, strong-chromatic characterizations, and path-graph results aside.

Open questions for a prover

  • Does a bit-polynomial algorithm exist for this distributional allocation problem without expanding the repeated copies?
  • Can a weighted strong-coloring or pricing formulation produce a compact solution?
  • Can the density bound be improved, or can the problem be characterized without a density promise?

The case FOR (proponent)

The strongest mirror I believe is a high-multiplicity version of the paper’s EF[1,1] allocation algorithm. Theorem 1.6 is my lead anchor. It is proved in the paper using Harris’s algorithm as a subroutine: for each fixed \(\varepsilon>0\), given a conflict graph of maximum degree \(\Delta\), an integer \(\ell\ge(3+\varepsilon)\Delta\), and a common additive valuation, a deterministic polynomial-time algorithm finds a feasible EF[1,1] allocation to \(\ell\) agents. The paper gives analogous algorithms for SD-EF1 and monotone EF1 as well. It contains no comparable named hardness result, so an algorithmic anchor is the right choice here.

Here is the mirror I would put to a prover: Low-Density Continuous EF[1,1] Conflict Allocation. The input is a finite conflict graph \(G=(V,E)\), a rational per-capita supply \(b_v\ge 0\) for each item type \(v\), and a rational additive value \(w_v\) shared by all recipients. The population has mass \(1\); all its members have the same complete preference type, so \(\tau=1\). Each member must receive an integral bundle: a vector \(k\in\mathbb Z_{\ge0}^{V}\) whose support is an independent set of \(G\). The solution is a finite-support distribution \(x_k\ge0\) over such bundles, with \(\sum_k x_k=1\) and \(\sum_k x_k k_v=b_v\) for every \(v\). For every pair \(k,l\) with positive mass, each bundle must envy the other by at most one item from each side under the common additive valuation. Thus mass is the fraction of recipients receiving each *integral* bundle; only the distribution and the per-capita supplies are fractional.

I would study the low-density slice
\[ \rho(G,b)=\max_{v:b_v>0}\sum_{u\in N_G(v)} b_u \le \frac{1}{3+\varepsilon}, \]
for fixed \(\varepsilon>0\). This is the direct scaling of Theorem 1.6’s degree condition. For a common denominator \(N\) of the \(b_v\), make \(N\) agents and \(Nb_v\) copies of each item type \(v\). Copies of adjacent types conflict, and copies of the same type do not. In the resulting graph \(H_N\), the maximum degree is \(N\rho(G,b)\), so \(\ell=N\) meets the theorem’s condition. A finite allocation gives a continuous solution by taking the fraction of agents receiving each bundle. The paper’s algorithm therefore establishes the promised existence on every rational instance in this slice.

The computational question is whether one can find that mass allocation in time polynomial in \(|V|,|E|\), and the binary input length \(L\), without expanding the \(N\) copies. I would initially expect tractability here, or Class A: the paper’s strong-coloring approach already supplies the structural route, and the mass formulation invites a compressed optimization method. The new result would be a bit-polynomial high-multiplicity algorithm, not a claim that Theorem 1.6 already gives one. Useful follow-up questions are whether the density bound can be improved, whether there is a weighted strong-coloring or pricing formulation for the compressed instance, and what happens without the density promise.

The regime is plausible: many otherwise identical residents or users receive indivisible resource units from a fixed set of categories; some categories cannot be held together, and each category has a rational per-person supply. The population grows while the number of preference types stays at one. Scaling the inventory with the population is the co-modification that makes per-capita supply meaningful; recipients still receive integral bundles. The mirror covers only Theorem 1.6’s arbitrary-additive EF[1,1] result. It does not claim to continuize the paper’s full strong-chromatic characterization or its path-graph results.

The weak point is also the main computational challenge: the theorem’s algorithm is polynomial in the *expanded* graph, whose size depends on \(N\), and \(N\) may be exponential in \(L\). So the cited result gives an explicit high-multiplicity realization and proves existence, but it does not prove the compact, bit-polynomial algorithm this mirror asks for. That limitation is why the mirror is a real continuization question rather than a restatement of the paper’s algorithm.

The case AGAINST (opponent, writing after the proponent)

Theorem 1.6 is a genuine computational anchor, so I can’t dismiss it for lacking an algorithmic result. My strongest reservation is about where the mirror’s substance ends up. With a fixed finite item set, once \(\ell\ge |V|\), assigning each item to its own agent gives a feasible EF[1,1] allocation: removing the single item from each nonempty bundle leaves value zero everywhere. To keep the limit nontrivial, the proposed mirror must scale the inventory too. That turns the instance into a weighted blow-up of the conflict graph: each resource category is copied many times, and every copy has the same value and conflict neighborhood. This is plausible for interchangeable resource units, but it is a special regime of the paper’s arbitrary conflict graphs.

There is also a sharp gap between the paper’s guarantee and the proposed computation. Theorem 1.6 runs in time polynomial in the expanded graph; if \(N\) is specified through binary rational supplies, that time can be exponential in the compact input length. Finding a compact mass allocation is therefore a new weighted strong-coloring problem. The theorem supplies existence after expansion, but neither a bit-polynomial algorithm nor a continuous-optimization formulation. That is a legitimate question, though it is a narrower high-multiplicity graph problem than the paper’s theorem might first suggest: the agent society has just one preference type, and most instance data describe per-capita resource supplies and conflicts.

I don’t think this makes a strong case that the mirror is unworthwhile in every scenario. The repeated-resource setting is sensible, and the compact algorithm question survives the objections above. My negative case is weak: it supports treating this as a specialized, resource-side continuization, but it does not defeat the anchor.
