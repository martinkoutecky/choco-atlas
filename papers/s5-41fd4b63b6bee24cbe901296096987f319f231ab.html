The continuous mirror question

Given alternatives \(X\), a support \(Τ\) of τ complete rankings, and positive binary-rational masses \(μ_t\) summing to \(1\), compute an exact ranking \(π\) minimizing \(∑_{t\inΤ}\mu_t\left|\left\{\{x,y\}\subseteq X: π\text{ orders }x,y\text{ oppositely to }t\right\}\right|\).

The model it lives in

Types are complete rankings \(t\inΤ\), with mass \(μ_t\); the decision is a ranking \(π\) minimizing the mass-weighted Kendall disagreement. The induced pairwise matrix is \(c_{xy}=\sum_{t:\,x\succ_t y}\mu_t\).

The objection that survived

The mass objective aggregates to \(C^\mu\), so the paper's reductions apply verbatim and discard support size τ; the stated optimization task adds no objective-level difference, leaving its value tied to the population input regime and possible support-sensitive algorithms.

fatal: False

What the mirror covers

The mirror covers Kemeny rankings for societies supported on τ ranking types, including the LOP-to-weighted-feedback-arc-set reduction and the forced orders implied by Theorem 1.4. It leaves general LOP matrices that are not induced by ranking distributions, as well as triangulation and the paper's other applications, outside its scope.

Open questions for a prover

  • Can an exact algorithm for the ranking-mass input exploit support size τ beyond constructing the induced pairwise matrix?
  • Do pairwise matrices induced by distributions over rankings admit a sharper characterization that yields support-sensitive algorithms?

The case FOR (proponent)

The strongest mirror is narrow: Kemeny consensus for a large population of voters whose rankings come from a relatively small set of distinct types. It covers the paper’s preference-aggregation application, not every linear ordering instance or its triangulation applications.

The population regime is natural: a poll, consultation, or election may have millions of respondents but far fewer distinct rankings. A type is a complete ranking of the alternatives; its mass is the fraction of the population with that ranking. Since Kemeny aggregation uses only rankings, people of the same type are indistinguishable for this problem.

My lead computational anchor is Corollary 2.5. It states that the linear ordering problem and the weighted feedback arc set problem are reducible to each other: an optimal solution to either can be transformed into an optimal solution to the other. The corollary is attributed to Grötschel, Jünger, and Reinelt [8]; this paper also gives direct proofs of the reductions. It is a computational reduction result, though not a numbered classification such as NP-hardness or membership in P. The introduction separately says that unrestricted linear ordering is NP-hard, citing [8].

Here is the continuous problem I would hand to a prover. Given alternatives \(X\), a support \(\mathcal T\) of \(\tau\) complete rankings, and positive binary-rational masses \(\mu_t\) summing to \(1\), find a ranking \(\pi\) minimizing

\[ K_\mu(\pi) = \sum_{t\in\mathcal T}\mu_t \left|\left\{\{x,y\}\subseteq X: \pi \text{ orders }x,y\text{ oppositely to }t \right\}\right|. \]

A solution is an optimal ranking, with its exact rational objective value. Define \(c_{xy}=\sum_{t:\,x\succ_t y}\mu_t\). Then

\[ K_\mu(\pi)=\sum_{1\le j<i\le m}c_{\pi(i)\pi(j)}, \]

so this is the Kemeny-profile restriction of the paper’s linear ordering problem. The strict-majority graph has an arc \(x\to y\) when \(c_{xy}>c_{yx}\), weighted by \(c_{xy}-c_{yx}\). For any ranking, its Kemeny cost is a constant \(\sum_{\{x,y\}}\min(c_{xy},c_{yx})\) plus the weight of the strict-majority arcs it reverses. Thus the ranking problem reduces directly to weighted feedback arc set on this induced graph.

The continuous formulation preserves the discrete Kemeny answer exactly: if a profile has \(n_t\) voters of each ranking type, set \(\mu_t=n_t/n\). Then \(K_\mu\) is the discrete total disagreement divided by \(n\), so the entire set of optimal rankings is unchanged. I would expect Class B: hardness transfers from discrete Kemeny aggregation, since every explicit discrete profile maps to this rational-mass instance in polynomial time. The paper’s claim that unrestricted LOP is NP-hard is relevant context, but alone does not establish hardness for the profile-realizable matrices in this mirror.

The paper’s main Theorem 1.4, proved here, supports the same mirror structurally: for any two distinct strongly connected components \(Y,Z\) of the strict-majority graph, if \(y\in Y\), \(z\in Z\), and \(y\to z\) is a strict-majority arc, every optimal ranking places \(y\) before \(z\). In the continuous instance, the arc records a strict majority of population mass. This gives forced pairwise orders that can help prune enumeration of all optimal rankings.

The follow-up questions are whether the induced majority graphs from ranking distributions admit a sharper description than general weighted graphs, and whether support-sensitive algorithms can exploit \(\tau\) beyond constructing the pairwise matrix. The paper’s Corollary 2.5 gives the reverse reduction for unrestricted LOP; that does not by itself show that every weighted feedback arc set instance comes from a population distribution over rankings.

The soft spot is that this is a strong mirror of the paper’s Kemeny application, but a modest new computational question: the paper already handles arbitrary nonnegative matrices, and the continuous society maps to a restricted class of those matrices. The authors would plainly recognize the problem as theirs; the mirror’s value is to make the high-multiplicity population regime and its exact relationship to discrete Kemeny explicit.

The case AGAINST (opponent, writing after the proponent)

The strongest negative case is that the Kemeny mirror is already contained in the paper’s input model. I would grant that a large electorate with relatively few ranking types is a sensible population regime. But for masses \(\mu_t\), form the pairwise matrix \(C^\mu\) with \(c^\mu_{xy}=\sum_{t:\,x\succ_t y}\mu_t\). Then the proposed objective is exactly the paper’s \(f(\pi)\), so the optimal rankings are identical. The pairwise matrix is a sufficient statistic: the optimization does not use the type distribution after that matrix is formed.

This makes Theorem 1.4 a particularly direct collision. It applies to every nonnegative matrix, including \(C^\mu\), and already gives the proposed continuous strong Condorcet property. Corollary 2.5’s reductions apply to the same matrix. These are not answers from outside literature being used to dismiss a new question; the paper’s own general model already accepts the continuous society’s aggregate input. The introduction’s finite-voter interpretation does not impose an integrality condition on the formal LOP.

The strongest improved mirror would ask for algorithms parameterized by the support size \(\tau\), or for faster enumeration of optima from a list of \(\tau\) rankings. That question survives the direct identity: the paper’s matrix representation does not preserve \(\tau\). But its novelty is then a compressed-input or parameterized version of LOP. The distribution can be aggregated into \(C^\mu\) in polynomial time, and the remaining optimization is exactly the one this paper studies. That may still be useful, especially if \(\tau\) yields better algorithms, but it is a narrow claim for ChoCo’s continuous-population programme.

So this is a strong case against treating either named result as a new continuous mirror. It is not an honest proof that no worthwhile mirror exists: a support-sensitive Kemeny project could be worthwhile, and the paper does not settle its parameterized complexity. The negative case is therefore strongest as a collision argument for these anchors, and weak against the universal claim.
