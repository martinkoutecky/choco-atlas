But the named anchor, Theorem 1, asserts symmetry, continuity, and consistency; it does not state an algorithmic bound, hardness result, or a formulation result that meets the required computational criterion.

What the mirror covers

The proposed mirror covers maximum-flow selection and edge-fair selection, associated with Theorem 1. It leaves aside the strategyproofness results and the fairness claims in the node-agent and edge-agent models.

The case FOR (proponent)

The strongest positive case is a high-multiplicity version of the paper’s maximum-flow selection problem. There is an important qualification: the paper gives no named result asserting a complexity class such as P or NP-hardness. Its closest anchor is Theorem 1, proved here: the edge-fair rule is symmetric, continuous, and edge-consistent. The theorem is about properties of a rule, not its running time. The paper does, however, define that rule by an algorithm using a sequence of linear programs. That gives a tractability case to investigate, but it is not a formal complexity result stated in the theorem.

Here is a concrete mirror. Let \(A\) and \(B\) be finite sets of supplier and demander types, with masses \(\mu_a,\nu_b\ge 0\), where \(\sum_{a\in A}\mu_a+\sum_{b\in B}\nu_b=1\). Type \(a\) has per-agent supply peak \(s_a\); type \(b\) has per-agent demand peak \(d_b\). A fixed set \(E\subseteq A\times B\) gives the compatible type pairs, and \(U_{ab}\) is the channel’s capacity per unit of society. All numerical inputs are binary rationals. The decision variable is a flow \(x_{ab}\ge 0\), with
\[ \sum_{b:(a,b)\in E}x_{ab}\le \mu_a s_a,\qquad \sum_{a:(a,b)\in E}x_{ab}\le \nu_b d_b,\qquad x_{ab}\le U_{ab}. \]
Among feasible flows of maximum total value, compute the flow whose nondecreasingly sorted vector of channel flows is lexicographically maximal. The solution is that unique flow vector. Call this Continuous Type-Flow Edge-Fair Selection.

A plausible regime is a large, distributed allocation system with many repeated local supplier and demander units—say, depots and receiving centers—with a relatively small number of shared preference, capacity, and compatibility profiles. The type description must include everything the model uses: role, per-capita peak, and compatibility and capacity pattern. With thousands of units but perhaps dozens of types, the input is a distribution over types rather than a list of named agents. Supplies, demands, and channel capacities are normalized to the society’s mass; that scaling is part of the mirror.

This is recognizably the paper’s question: it retains the maximum-flow requirement and the edge-fair choice among maximum flows. The continuous object is the population represented by type masses, not the already-divisible commodity or the flow outcome. Theorem 1’s symmetry, continuity, and consistency are then properties to ask of the type-level rule as well. The mirror covers that maximum-flow selection result; it does not claim to continuize the paper’s group-strategyproofness theorems.

I expect this problem to be tractable. The paper’s edge-fair algorithm uses \(O(|E|)\) LP stages, with a polynomial-sized flow formulation at each stage. Applied to a type graph of support size \(\tau=|A|+|B|\), that suggests polynomial time in \(\tau\), the number of compatible type pairs, and the rational input bit length \(L\). This is a consequence of the algorithm and standard polynomial-time LP methods, not a complexity claim made by Theorem 1. Further questions are whether quotienting a repeated-agent network preserves the rule’s edge-consistency property, and whether a type-level fairness definition should order aggregate channel flows or per-copy flow rates.

The weak point is exactly that aggregation choice. The paper lexicographically compares individual edge flows; aggregating repeated links into one type-level channel can change that ordering. The mirror is strongest for a regime where each type-level channel is itself the meaningful allocation unit, or where the model explicitly defines fairness by per-copy rates. If the authors require the original individual-edge ordering without such a justification, they may reject this as their continuous analogue. And if the grader requires the anchor itself to state a complexity class, this paper supplies no qualifying anchor.

The case AGAINST (opponent, writing after the proponent)

The strongest objection is that there is no computational result here to mirror. Theorem 1 says the edge-fair rule is symmetric, continuous in the numerical inputs \(s,d,u\), and edge-consistent. Its “continuity” is a property of a rule on finite networks, not a continuum-population model. The other named results concern strategyproofness and fairness. None asserts a complexity classification or an algorithmic bound.

The edge-fair algorithm does give a plausible starting point: it selects a maximum flow through a sequence of linear programs. One could formulate a high-multiplicity type-flow problem around it, with types recording roles, per-agent peaks, and compatibility and capacity patterns. That would be a legitimate continuous-population question; I would not dismiss it because the commodity or flow is divisible, or because the type model changes the answer.

But the proposed type-level selection does not automatically preserve the paper’s rule. The rule compares the sorted vector of flows on individual edges. Aggregating links into type-pair totals changes that object, while defining per-copy rates or a continuum of links requires a new fairness specification. Those choices might support a worthwhile *new* computational project, but the paper does not establish a computational result whose high-multiplicity version that project would be.

So the case against this anchor rests on the scope of the programme, not on a claim that no sensible high-multiplicity flow model exists. If the programme accepts new computational questions suggested by axiomatic papers, the negative case is weak: repeated depots or distribution centers could make the population regime credible. Under the stated requirement to mirror a computational result of this paper, however, the proposed anchor does not qualify.
