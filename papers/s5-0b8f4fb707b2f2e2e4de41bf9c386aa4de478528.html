The continuous mirror question

Given a finite alternative set \(S\), supported reflexive preference types \(R_t\) with positive binary-rational masses \(\mu_t\) summing to \(1\), and \(m=|S|\), \(\tau=|\operatorname{supp}(\mu)|\), let \(P_t\) be the strict part of \(R_t\) and set \(p_\mu(x,y)=\sum_{t:xP_ty}\mu_t\). For \(1/2<\alpha\le1\), define \(xM^\mu_\alpha y\) iff \(p_\mu(x,y)\ge\alpha\), and let \(C_\mu(S)\) be the alternatives optimal in every \(\operatorname{tr}_S(M^\mu_\alpha)\). Define common components across the supported types and apply the paper’s quotient recursion for \(C^{(CC)}\), carrying and aggregating masses on quotient types. Compute the exact output \(C_\mu^{(CC)}(S)\); is this possible in time polynomial in \(m\), \(\tau\), and the input bit length \(L\)?

The model it lives in

The society is a binary-rational distribution over complete preference-relation types on a finite alternative set. The rule uses strict-preference mass to form majority relations, then recursively contracts common components and returns an exact subset of acceptable alternatives. There is no optimization objective; the computational task is to output that subset from the supported types and masses.

What the mirror covers

The mirror instantiates Corollary 6 with the \(M(.5,1]\) majority-chain rule and asks for its \(C^{(CC)}\) modification. It leaves the paper’s other majority and minority rules, additional axioms, and proposed simulations outside this anchor.

Open questions for a prover

  • Give an explicit bit-complexity bound polynomial in \(m\), \(\tau\), and \(L\) for exact evaluation of \(C_\mu^{(CC)}(S)\).

The case FOR (proponent)

The strongest mirror is Continuous Component-Consistent Majority Choice. Imagine a city consulting a very large population about a modest slate of public projects. Each person reports pairwise judgments: they may prefer one project, regard two as equivalent, or be undecided; their judgments may even be cyclic. Many residents can share exactly the same report. A type is one complete reflexive relation on the alternatives, and \(\mu_t\) is the fraction of residents with type \(t\). In a plausible high-multiplicity regime, the number \(N\) of residents is very large while the number \(\tau\) of distinct reports is much smaller. The alternatives and each person’s report stay discrete; the population becomes a distribution.

My lead anchor is Corollary 6, proved in this paper. It says that if a choice rule \(C\) satisfies isomorphism invariance, independence of irrelevant alternatives, generalized Condorcet, and Condorcet, then its recursively defined composition-consistency modification \(C^{(CC)}\) also satisfies those conditions. Computationally, if \(C\) can be computed in polynomial time, so can \(C^{(CC)}\). The proof finds a minimal proper common component in \(O(k^5 n)\) time for \(k\) alternatives and \(n\) individuals, recurses over at most \(k-1\) sets, and gives a total time of at most \(O(k^6 n)\) times the cost of computing \(C\).

Here is a specific continuous problem for that result. Call it CC-Majority\(_\infty\). An instance consists of a finite feasible set \(S\), an explicit support of \(\tau\) reflexive preference relations \(R_t\) on \(S\), and binary rational masses \(\mu_t>0\) summing to \(1\). Let \(P_t\) be the strict part of \(R_t\), and define the strict-preference mass
\[ p_\mu(x,y)=\sum_{t:\,xP_ty}\mu_t. \]
For each \(1/2<\alpha\le 1\), define \(xM^\mu_\alpha y\) exactly when \(p_\mu(x,y)\ge\alpha\). Let \(C_\mu(S)\) be the alternatives that are optimal in every transitive hull \(\operatorname{tr}_S(M^\mu_\alpha)\). This is the paper’s \(M(.5,1]\) rule with counts replaced by fractions. The question is to compute its composition-consistency modification \(C_\mu^{(CC)}(S)\).

For this recursion, a proper component \(B\subset S\) is a common component of every supported type: each alternative outside \(B\) has the same relation to all members of \(B\), in both directions. Contract \(B\) to one alternative, push the type masses through the paper’s quotient construction, and recurse. If the contracted \(B\) is not chosen, retain the contracted choice outside \(B\); if it is chosen, replace it with the recursively computed choice inside \(B\). The required solution is the exact subset of \(S\) returned by this rule. The question is whether that set can be computed in time polynomial in \(m=|S|\), \(\tau\), and the input bit length \(L\).

This is a faithful population mirror: the rule still processes incomplete and cyclic preferences, still uses majority arguments, and still returns the paper’s set of acceptable alternatives. It does not turn the problem into winner selection or add probabilities over outcomes. For the base rule, \(M^\mu_\alpha\) is antisymmetric for \(\alpha>1/2\); the paper’s construction gives the required choice-rule conditions for such chains. Although \(\alpha\) ranges continuously, the relation changes only at finitely many values \(p_\mu(x,y)\), so the base choice can be computed by checking polynomially many rational breakpoints. Component detection also needs only the \(\tau\) supported relations, and the recursion contracts alternatives, not individual people. That gives a credible route to the requested polynomial bound.

The finite-to-continuous dictionary is particularly clean. For a discrete profile, set \(\mu_t=n_t/n\), where \(n_t\) is the number of voters of type \(t\). Then \(p_\mu(x,y)=p_{xy}/n\), so every \(M_\alpha\) relation and every component agrees with the discrete definition. The continuous input also permits arbitrary rational proportions in a compact support representation. This is a high-multiplicity computational question: can the rule be evaluated from a short list of types and binary masses, without expanding the population into \(N\) named voters?

I expect CC-Majority\(_\infty\) to be tractable. A further question is whether the same support-based analysis works for the paper’s other majority and minority chains, especially the relative types \(B\) and \(D\), and for the additional idempotency modification in Corollary 9. One could also ask how efficiently to determine whether the output is a singleton or how it changes under small mass perturbations.

The weakness is that this paper offers no named hardness result to mirror: its computational anchor is an algorithmic result, and the majority rule itself is built directly from aggregate masses. The opponent can reasonably argue that this is a succinct-input extension of the authors’ existing computation, rather than a new complexity landscape where discrete hardness might dissolve. Also, \(\tau\) can itself be large—there are many possible reflexive relations as \(m\) grows. Still, the mirror has a concrete population regime, preserves the paper’s actual choice problem, and asks a real algorithmic question in the binary-encoded high-multiplicity model.

The case AGAINST (opponent, writing after the proponent)

The strongest case against the proposed mirror is that this paper’s rules already reduce the profile to aggregate counts. The relations \(M_\alpha,N_\alpha,\ldots\) are defined from pairwise cardinalities, and the component recursion works on the alternatives. For the proposed input, compute the corresponding weighted sums from the \(\tau\) supported types; the rule then uses the same thresholds and recursion. Each rational mass vector is also an ordinary finite profile after multiplying by a common denominator. So the mirror’s main change is to encode that profile by type and mass, rather than list its voters.

That makes the best version of the proposal quite easy to state, but also narrows its research contribution. For Corollary 6, one could seek a bound polynomial in \(m,\tau,L\) for the exact \(C^{(CC)}\) output. The weighted counts can be computed from the support, the threshold relations change at finitely many rational breakpoints, and component detection checks the supported types. The same method appears to cover the \(B\) and \(D\) chains and the idempotency iteration: quotienting maps each supported type to a quotient type, and the iteration can shrink the choice set only finitely many times. That looks more like a support-sensitive implementation of the paper’s existing computation than a new computational landscape or an occasion to use the continuous-optimization machinery motivating ChoCo.

This criticism has a limit: the common denominator can be enormous relative to \(L\), so a polynomial-time algorithm on the support representation could be useful for a succinct, high-multiplicity input. Nor does rationality disqualify the model under ChoCo’s definition. It is the expected finite-to-continuous bridge. The point is only that this paper already makes aggregation central, so the bridge seems unusually direct and may yield little beyond a compressed-input version of its polynomial algorithm.

The proposed city-consultation scenario is plausible: many residents can share a complete pattern of pairwise judgments over a modest set of projects. The same observation applies to the other majority and minority chains. I cannot honestly argue that no meaningful high-multiplicity regime exists, or that fuzzy-relation discussions in the paper already constitute a continuous-population treatment. The singleton and perturbation questions are weaker anchors: they add questions about the output or its stability, rather than mirror a further named computational result here.

So the negative case is weak against the main anchor. Corollary 6 is a genuine computational result, and the proposed society preserves its central choice problem. My best objection is about the likely incremental value of this particular mirror, not a fundamental failure of the model. Under the programme’s stated standard that a well-posed, even straightforward mirror can be worthwhile, I have not defeated it.
