The continuous mirror question

Given a directed network \(D=(V,E;s,t)\) and rational type masses \(\mu\in\mathbb{Q}_{\ge 0}^{E}\) with \(\sum_{e\in E}\mu_e=1\) and \(F_D(\mu)>0\), where type \(e\) consists of interchangeable suppliers whose mass provides capacity on arc \(e\), let \(F_D(y)\) be the maximum \(s\)-to-\(t\) flow under capacities \(y\). Find payment rates \(p_e\ge 0\) and the largest \(\varepsilon\) satisfying \(\sum_e\mu_ep_e=1\) and \(\sum_ep_ey_e\ge F_D(y)/F_D(\mu)+\varepsilon\) for every coalition mass vector \(y\in\prod_e[0,\mu_e]\).

The model it lives in

A continuous cooperative flow game with interchangeable capacity suppliers typed by arc: type \(e\) has mass \(\mu_e\), coalition mass \(y_e\) supplies that much arc capacity, worth is normalized maximum flow, and \(p_e\) is payment per unit mass.

What the mirror covers

The mirror covers the edge path game's least-core flow/minimum-cut characterization and efficient computation; it does not cover the binary game's empty-core behavior, the nucleolus, or the vertex path games.

Open questions for a prover

  • Is the full least-core set exactly the set of rates \(p=z/F_D(\mu)\), where \(z\) lies in the convex hull of minimum \(s,t\)-cut incidence vectors?

The case FOR (proponent)

The strongest mirror I see is the least-core result for edge path games, using the paper’s own bridge from path games to flow games.

My anchor is Theorem 1, proved in this paper. It says that for an edge path cooperative game \(\Gamma_E\) and its associated flow game \(\Gamma_f\) on the same unit network \(D\), with maximum flow \(f^*\), an imputation \(x\) is in \(LC(\Gamma_E)\) exactly when \(x=z/f^*\) for some \(z\in C_E\). Here \(C_E\) is the set of optimal solutions to the dual flow LP, equivalently the convex hull of the minimum edge-cut indicator vectors. The paper draws the computational consequence explicitly: the least-core value and an imputation can be found efficiently, as can membership in the least core. The theorem’s proof is here; its structural engine is the max-flow/min-cut correspondence.

Here is a continuous problem that uses that bridge. Take a fixed directed network template \(D=(V,E;s,t)\). A type is a supplier of capacity on a particular arc, with the arc role and all relevant attributes—capacity contribution, reliability, and price—part of the type. A society is a rational mass vector \(\mu\in\mathbb{Q}_{\ge 0}^{E}\), normalized so \(\sum_e\mu_e=1\). In a large infrastructure operation, many interchangeable capacity units may serve each of a relatively small number \(\tau\) of route segments: the population is large, while the number of distinct arc roles stays bounded by the network template. Each unit supplies a small amount of capacity, so a coalition containing mass \(y_e\) of type \(e\) has arc capacity \(y_e\).

Let \(F(y)\) be the maximum \(s\)-to-\(t\) flow with capacity vector \(y\), and normalize coalition worth as \(v(y)=F(y)/F(\mu)\). An allocation is a payment rate \(p_e\ge 0\) per unit of type-\(e\) mass, with \(\sum_e\mu_ep_e=1\). Fluid Edge-Supply Least Core is: given \(D\) and \(\mu\), find a rate vector \(p\) and the largest \(\varepsilon\) such that
\[ \sum_{e\in E}p_ey_e\ \ge\ \frac{F(y)}{F(\mu)}+\varepsilon \qquad\text{for every }y\in[0,\mu]. \]
A solution is an optimal \((p,\varepsilon)\).

This problem is tractable. A minimum cut \(C^*\) for capacities \(\mu\) has \(\mu(C^*)=F(\mu)\). Set \(p_e=1/F(\mu)\) on \(C^*\) and \(p_e=0\) elsewhere. For every coalition mass vector \(y\), the flow it can carry is at most the capacity of that cut, so \(F(y)\le y(C^*)\). Thus this allocation satisfies every core constraint, and the empty coalition forces \(\varepsilon\le 0\); the optimum is \(\varepsilon=0\). A minimum cut therefore gives a solution in polynomial time. I expect this mirror to be Class A. Further questions include computing the entire least-core set, rather than one allocation, and testing membership for a supplied rate vector.

The scenario is plausible because the paper’s players already control network resources, and their type-level identity can be the network role plus any attributes that affect the game. The co-modification is that fractional capacity earns fractional flow worth. That is a real change from the paper’s binary “does this coalition contain a path?” value, but it follows the paper’s own flow-game connection: Theorem 1 identifies the path game’s least core with a scaled flow-game core. So this is a mirror of a computational object the authors themselves use, rather than an unrelated fractional-outcome model.

The soft spot is substantial: in the continuous capacity game the core is nonempty, so its least-core value is \(0\), whereas the paper’s binary path game can have an empty core. The mirror captures the flow-cut allocation structure of Theorem 1, not the full effect of indivisible edge ownership on coalition success. That limits its scope: I would claim a strong mirror of the edge-game least-core result’s flow formulation, not a continuous replacement for the paper’s results on nucleolus or vertex games.

The case AGAINST (opponent, writing after the proponent)

Theorem 1 is a genuine computational anchor: it characterizes the least core and supports efficient computation. The strongest case against the proposed mirror is that the population limit of the paper’s *binary* path game loses the distinction Theorem 1 studies.

Suppose a type represents an arc role, and a coalition wins whenever it has positive mass of every role on some \(s\)-to-\(t\) path. It can then win with arbitrarily small mass: take \(\delta>0\) of each type on one path. For any integrable payment rates, the coalition’s payment tends to zero as \(\delta\to0\), while its worth remains \(1\). Its excess approaches \(-1\). The least-core value is therefore \(-1\), and at that value every imputation satisfies the constraints. The least core has lost its discriminatory force. Requiring a coalition to take an entire type class preserves the finite game, while a fixed positive capacity threshold yields a threshold-flow game whose winning rule is a new modeling choice.

The proponent avoids that degeneration by defining coalition worth as \(F(y)/F(\mu)\). That is coherent for a society of capacity suppliers, and the paper’s flow-game connection gives it real motivation. But it changes what coalition mass means: mass supplies divisible capacity, and worth is flow volume. A minimum cut then gives a core allocation, so this model does not retain the empty-core phenomenon that makes the paper’s least-core characterization distinctive. The mirror is strongest as a population version of the associated flow game, rather than as a high-multiplicity version of the path game itself.

That boundary makes the negative case weaker than the proponent’s case. Many suppliers contributing capacity to a small set of network links is plausible, and the paper explicitly relates path games to flow games. The authors might recognize the fluid capacity problem as theirs. I can argue that it changes the object behind Theorem 1; I cannot honestly argue that no worthwhile continuous mirror exists in any scenario.
