The continuous mirror question

Given a finite component repository \(E\), compatibility constraints, a Boolean goal model \(R\), optional traits \(O\), and a nonempty feasible design set \(\mathcal D=\{C\subseteq E: C\text{ is compatible and its composition satisfies }R\}\), suppose each type \(t\) has a CI-net preference relation \(\succ_t\) over subsets of \(O\), with rational mass \(\mu_t\ge 0\) and \(\sum_t\mu_t=1\). Let \(\gamma(C)\subseteq O\) be the optional traits achieved by design \(C\), and let \(\operatorname{Top}_t=\{C\in\mathcal D:\nexists C'\in\mathcal D,\ \gamma(C')\succ_t\gamma(C)\}\). Find a design \(C\in\mathcal D\) maximizing \(\sum_{t:C\in\operatorname{Top}_t}\mu_t\).

The model it lives in

A common component configuration for a large user population represented by a finite support of complete CI-net preference types. Each type carries rational mass; among configurations satisfying the shared goal model, choose one that is undominated for the greatest total mass.

What the mirror covers

The mirror covers Theorem 5’s selection of a preferred, functionally satisfactory design. It leaves the dissertation’s component realization, verification, and broader framework results aside.

Open questions for a prover

  • What is the exact complexity of finding a mass-maximizing design as a function of repository size, number of optional traits, support size \(\tau\), and input bit length?
  • Is the problem approximable or fixed-parameter tractable in \(\tau\), and how does the answer change with compact CI-net inputs?

The case FOR (proponent)

The best anchor is Theorem 5 (Soundness and Completeness), proved in this dissertation. It says: if the Chapter 5 algorithm returns a satisfiable assignment to the goal-model formula \(R\), then no other satisfiable goal assignment contributes to a more preferred set of optional goals; if the algorithm returns no assignment, then no satisfying assignment exists. This is the dissertation’s central named result for selecting a preferred, functionally satisfactory system design.

One qualification matters: Theorem 5 proves correctness, not a complexity classification. The dissertation has no named theorem claiming that this selection problem is in P, NP-hard, or otherwise classified. If an anchor must assert a conventional complexity class, the paper supplies none. Theorem 5 is the closest honest computational anchor, and there is no comparable hardness result in the paper to prefer instead.

A plausible continuous mirror is Mass-Optimal Component Configuration. Consider a public-service platform configured once for a very large user population. Its users fall into a modest number \(\tau\) of recurring types—for example, preference profiles formed from common views about payment traceability, operating costs, documentation, and service channels. There may be hundreds of thousands of users but only a few dozen types. Every user within a type has the same relevant requirements and CI-net preferences; type \(t\) has population share \(\mu_t\), with \(\sum_t\mu_t=1\).

An instance consists of a finite component repository \(E\), compatibility data, a Boolean goal model \(R\), optional traits \(O\), and the stakeholder types with their CI-nets and rational masses \(\mu_t\). Let \(\mathcal D\) be the sets of compatible components whose composition satisfies \(R\), and let \(\gamma(C)\subseteq O\) be the optional traits achieved by design \(C\). For each type \(t\), define \(\operatorname{Top}_t\) as the feasible designs whose achieved trait sets are not strictly dominated under that type’s CI-net by any other feasible design. The task is to return a feasible design maximizing

\[ \sum_{t:\,C\in\operatorname{Top}_t}\mu_t. \]

The returned design is thus one that is individually non-dominated for the greatest share of the population; ties are allowed. The question is whether this design can be found efficiently, perhaps in terms of repository size, number of traits, support size \(\tau\), and rational input bit length.

This is a credible extension of the dissertation’s problem: it still chooses components to satisfy a system requirement while reasoning qualitatively over optional traits. It also makes the authors’ stated future direction of multi-stakeholder preference reasoning concrete. The mass objective preserves ordinal information: it counts the share for whom a design is among their best feasible options, without assigning numerical utilities to their preferences. The population types are complete preference profiles, and grouping repeated profiles is exactly the high-multiplicity premise.

I would expect the computational difficulty to persist in a Class B-shaped way. The combinatorics of component compatibility, goal satisfaction, and optional-trait choices remain even with a single type of mass \(1\); making the population continuous does not fractionalize the system configuration. This is a structural expectation, not a result of the dissertation: Theorem 5 gives no hardness proof, so there is no paper-established discrete hardness to transfer. Further questions include whether the mass-optimal design can be approximated, whether the problem is fixed-parameter tractable in \(\tau\), and how sensitive the winning design is to small changes in the population shares.

The mirror covers Theorem 5’s preferred correct-design selection. It does not mirror the whole dissertation’s service-composition, realization, or verification framework.

The weak point is the aggregation rule. The authors seek a most-preferred design under a stakeholder preference model; they do not define “maximize the mass for whom the design is individually top.” Their future-work discussion makes multiple stakeholders relevant, but it does not endorse this particular objective. A reviewer could reasonably view the proposed problem as a new social-choice extension of their selection problem rather than its direct continuization. That is the main risk, and it is why this is a case for one specific mirror, not a claim that the dissertation as a whole already contains a continuous-population problem.

The case AGAINST (opponent, writing after the proponent)

Theorem 5 is the only plausible anchor, but it proves soundness and completeness of a finite goal-assignment procedure. It gives no complexity classification. The other named theorems likewise concern feasibility or correctness. So the dissertation supplies no established complexity result whose population version could directly continue a complexity landscape; a new question must first be built around the algorithm.

The proposed construction does that by giving user types separate CI-nets and choosing a feasible design that is top-ranked for the greatest mass. That changes the paper’s decision problem. The dissertation takes one system requirement and one agreed preference relation over optional traits. Its stakeholders help specify a system; they are not modeled as a population choosing among common alternatives. Treating end users as preference-bearing agents adds a social aggregation rule, and “mass for whom this design is top” is one such rule. A shared design for a large customer base makes the scenario plausible, but it turns Theorem 5 into a starting point for a new social-choice problem rather than a continuization of its result.

The stronger versions keep the same difficulty. Giving every user the same CI-net reduces the mass objective to the paper’s existing search among maximal designs. Giving users different CI-nets creates the genuinely new case, but then the central question is how to aggregate their conflicting preferences. The dissertation’s future-work discussion of multiple stakeholders makes this extension recognizable to the authors; it does not establish that a population-weighted top-set rule is the right continuation of their framework. If each user instead receives a separate configuration, the problem becomes a portfolio of system designs, with any coupling constraints adding another new layer.

That leaves a credible but narrow objection: the paper has no population input or multiplicity regime, and the only route to one changes the single-stakeholder configuration problem into collective choice over a common product design. This makes the proposed mirror’s fit uncertain. It does not support the universal claim that no worthwhile mirror exists. A large customer base with a small number of preference types is a plausible high-multiplicity regime, and multi-stakeholder preference reasoning is already on the dissertation’s future-work agenda. The negative case is therefore weak at its strongest point: the proposed formulation may be a worthwhile ChoCo problem, though it is better described as a social-choice extension of the dissertation than as a direct mirror of Theorem 5.
