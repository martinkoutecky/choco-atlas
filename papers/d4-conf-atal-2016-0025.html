The continuous mirror question

Given a finite action set \(A\), a finite support \(T\) with positive rational masses \(\mu_t\) summing to \(1\), each type's preferences and internal argumentation framework, and agreed attacks between disclosable arguments, determine whether there is a rational allocation \(x_{t,a}\geq 0\) with \(\sum_a x_{t,a}=\mu_t\), \(x_{t,a}=0\) unless \(a\) is feasible for type \(t\), and rational per-action bounds \(\ell_a\leq\sum_t x_{t,a}\leq u_a\). Feasibility is defined by admissibility of the action's practical argument in the type's perfect-view framework. Return an allocation for which no other feasible allocation \(y\) admits, for every type \(t\), a coupling from \(x_{t,\cdot}\) to \(y_{t,\cdot}\) supported only on actions that type \(t\) strictly prefers; otherwise report that none exists.

The model it lives in

Represent each repeated agent group as a type \(t\) carrying mass \(\mu_t\), with one indivisible action per individual and a potentially fractional type-level allocation \(x_{t,a}\). Enforce admissibility-based feasibility and per-capita action bounds, then maximize \(\sum_{t,a}x_{t,a}r_t(a)\), where \(r_t\) strictly increases along each type's strict preferences. This gives a socially optimal allocation under the paper's all-agents-strictly-better criterion; the allocation LP is polynomial once the feasible-action sets are known.

The objection that survived

The mirror supplies the type frameworks centrally and asks for an allocation, so it does not preserve the paper's distributed privacy-sensitive protocol; the proponent acknowledges this but does not establish that the authors would treat that feature as incidental.

fatal: False

What the mirror covers

The mirror covers Theorem 2's social-optimality guarantee for returned profiles. It leaves aside Theorem 1's termination result, Theorems 3 and 4's privacy and communication claims, the protocol's incompleteness, and the paper's full range of exact action-count constraints.

Open questions for a prover

  • What is the exact complexity of computing each type's feasible-action set? Credulous acceptance suggests hardness can persist with only a small support.
  • Can a type-level protocol preserve the paper's perfect-security guarantee while computing an allocation without centralizing private arguments?
  • Which normalized forms of the paper's exact action-count constraints, beyond per-action intervals, have useful population limits?

The case FOR (proponent)

The strongest honest case is a narrow mirror of Theorem 2. The paper states: “Alg. 1 is sound, i.e. the strategy profile obtained by this protocol is socially optimal.” Proved here, with a sketched proof, this means that any profile the protocol returns is acceptable, every chosen action is feasible for its agent in that agent’s perfect-view argumentation framework, and there is no other acceptable, feasible profile in which every agent strictly prefers their replacement action. Feasibility means the action’s practical argument belongs to at least one admissible set. The paper separately proves termination, but does not prove completeness: it gives an instance where the protocol returns no profile although one exists. Nor does it establish a polynomial-time bound. So this is an anchor for a computational *outcome property*, not a tractability result.

A plausible high-multiplicity setting is a large sensor network. Many nodes may share the same firmware, local observation class, argumentation structure, and action priorities; the network can then have millions of nodes but relatively few distinct types. Each node still chooses one indivisible action, such as a channel or operating mode. The continuous model describes what fraction of each type takes each action. The type must include the full information the paper uses: preferences, private and disclosable arguments, and the internal attack structure. Nodes with different relevant information belong to different types.

Here is the problem I would hand to a prover: Continuous Socially Optimal Coordination. The instance consists of a finite action set \(A\), a finite support \(T\) of types with positive rational masses \(\mu_t\) summing to \(1\), each type’s preference order and internal argumentation framework, the agreed attacks between disclosable arguments, and rational per-action share bounds \([\ell_a,u_a]\). For each type \(t\), combine its own framework with the disclosable arguments of the other supported types to form its perfect-view framework. Let \(E_t\) be the actions whose practical arguments are admissible there.

A solution is a rational allocation \(x_{t,a}\geq 0\) such that \(\sum_a x_{t,a}=\mu_t\), \(x_{t,a}=0\) for \(a\notin E_t\), and \(\ell_a\leq\sum_t x_{t,a}\leq u_a\). It must also be socially optimal in the paper’s sense. Precisely, there must be no other feasible allocation \(y\) and, for each type \(t\), a coupling \(\pi_{t,a,b}\) with marginals \(x_{t,a}\) and \(y_{t,b}\), supported only on pairs where type \(t\) strictly prefers \(b\) to \(a\). Such a coupling means that, up to a measure-zero set, every member of the population could receive a strictly preferred action. The answer is an allocation or a report that none exists. The bounds on shares are the natural per-capita scaling of the paper’s permitted action counts; each person still receives one action, while averages within a type can be fractional.

With the feasible-action sets \(E_t\) already known, this allocation problem has a clean continuous-optimization core: maximize \(\sum_{t,a}x_{t,a}r_t(a)\), where \(r_t\) increases with type \(t\)’s preference order. The constraints are linear, and an optimum is socially optimal under the paper’s strict-all-agent criterion: a coupling that strictly improves everyone would strictly increase the objective. This gives a polynomial-time LP for the allocation stage.

The unrestricted problem should remain hard, however. Admissibility testing is already computationally difficult: credulous acceptance under admissible semantics is NP-complete ([IJCAI paper on argumentation complexity](https://www.ijcai.org/Proceedings/11/Papers/177.pdf)). The paper’s restrictions on argument types do not remove this obstacle. Given an argumentation framework \(F\) and query \(q\), make a target type with a disclosable argument \(d\), a private argument \(p\), and practical argument \(A\), with attacks \(d\to p\to A\). Locally, \(A\) is feasible. A second type supplies the disclosable arguments of \(F\), plus \(z\), with attacks \(q\to z\to d\) and the original attacks of \(F\). In the target type’s perfect view, \(A\) is feasible exactly when \(q\) is credulously accepted in \(F\). With one action required for the whole population, a solution exists exactly in that case. The local-feasibility assumption is respected, and the same construction works with two discrete agents. This is a derived hardness argument, not a result claimed by the paper; it suggests that the full mirror lies on the hardness-transfer side of the trichotomy, while its allocation stage is tractable once action feasibility is settled.

The weakest point is that this mirrors the theorem’s allocation guarantee, not the paper’s full privacy-preserving protocol. Per-capita share bounds replace exact finite count sets, and a mass allocation replaces the protocol’s individually ordered token passing. That is a real co-modification, but it leaves the population as the continuous object and preserves the theorem’s feasibility and social-optimality requirements. The authors might still say the privacy guarantee is too central to leave outside the question; a type-level version of their entropy-based security claim would be a natural follow-up. Another is whether parameterizing the argumentation checks can yield an efficient end-to-end algorithm when the number of types is moderate.

The case AGAINST (opponent, writing after the proponent)

Theorem 2 is the proponent’s only strong anchor, but it establishes a conditional correctness property: any profile Alg. 1 returns is socially optimal. It gives no runtime bound, and the paper explicitly shows that the protocol can return no profile even when one exists. The stated optimality condition is also weak: no *feasible* profile makes every named agent strictly better. For any finite nonempty feasible set, some profile is maximal under that relation. A continuous version that asks only for a Pareto-efficient allocation therefore adds little by itself.

The proposed LP makes this gap visible. Once the globally feasible action sets \(E_t\) are supplied, maximizing a strictly preference-increasing score over type-action masses produces a Pareto-efficient allocation by a routine LP argument. That calculation says nothing about the paper’s distinctive computation: agents use argumentation dialogues and backtracking to determine feasibility while limiting disclosure. Supplying \(E_t\) has already done the difficult, privacy-sensitive work. If the full type descriptions and attack relations are instead given centrally, the model exposes the information the protocol is meant to protect. Hiding them would require a new secure protocol for type-level masses; Theorem 2 supplies no such algorithm or guarantee. Moreover, once the support is fixed, the dialogue depends on which types are present, not their masses. The continuous population mainly changes the allocation stage that the theorem does not analyze for complexity.

There is also a scaling gap in the constraints. The paper permits arbitrary sets of exact agent counts, such as \(\{0,2\}\). Replacing these with per-capita share bounds is sensible for some capacity-style applications, but it changes exact simultaneous-participation requirements and does not continue the paper’s whole constraint language. Preserving those requirements would need additional structure about how large populations form action groups. That may be a worthwhile extension, but it is not delivered by the proposed LP mirror.

I would not claim this rules out every author-recognizable continuous version. A large network of genuinely repeated sensor types is plausible, and a mass-allocation question could make sense for it. The negative case is that the clean version mirrors a generic allocation fact after setting aside the protocol’s privacy-sensitive computation; the version that retains that computation needs a substantially new model. That makes this a weak case against *any* mirror, though a stronger case against the specific anchor proposed.
