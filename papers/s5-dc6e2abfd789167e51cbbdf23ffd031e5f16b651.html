The continuous mirror question

Given \(\tau\) interchangeable route types, unary-encoded positive edge lengths \(w\in\mathbb{Z}_{>0}^{\tau}\), rational per-worker order supplies \(\rho\in\mathbb{Q}_{\ge0}^{\tau}\), and a polynomially bounded threshold \(q\), decide whether there is a finite-support mass distribution \(\lambda\) over integral bundles \(B\in\mathbb{Z}_{\ge0}^{\tau}\) satisfying \(\sum_B\lambda_B=1\), \(\sum_B\lambda_BB_r=\rho_r\) for every \(r\), and \(\lambda_B>0\Rightarrow w\cdot B\le q\); equivalently compute \(\theta_\infty(\rho,w)=\min_{\lambda}\max_{\lambda_B>0}w\cdot B\).

The model it lives in

A unit-mass population of identical workers serves interchangeable route-order types. The decision variables are masses \(\lambda_B\) of workers receiving each integral bundle \(B\), with average supply \(\rho\); the objective is to minimize the maximum bundle cost \(w\cdot B\).

The case FOR (proponent)

The strongest honest positive case is a continuous high-multiplicity version of the paper’s weighted-star problem, anchored in Theorem 6. I would make this the lead mirror and would not claim that the whole paper has to be continuized.

Theorem 6, proved in this paper, states: unless \(P=NP\), no polynomial-time algorithm can find an MMS and non-wasteful allocation, even when the topology \(G\) is a weighted star and the edge weights are unary encoded. The paper proves this by reducing from \(3\)-PARTITION. On a star, non-wastefulness is automatic, so the underlying difficulty is precisely distributing weighted orders among agents while minimizing the largest bundle cost.

A natural high-multiplicity regime is a large pool of interchangeable delivery workers serving a small number \(\tau\) of recurring route classes. Every worker has the same cost model, so there is one worker type; the high multiplicity is \(K\gg\tau\), with many workers and many repeated orders of each route type. This is plausible for a platform serving standard delivery zones or a postal operation with repeated routes. Keeping a fixed finite set of orders while sending \(K\) to infinity would make almost every worker idle and destroy the MMS question, so the order supply must scale per capita. That is a co-modification forced by continuizing the population, not a replacement of the population by a continuous outcome.

I would call the resulting problem Continuous Star-MMS-NW. Its input is a star with route types \(r\in[\tau]\), rational edge lengths \(w_r>0\), rational per-worker order supplies \(\rho_r\ge 0\), and, for the decision version, a rational threshold \(q\). A bundle is still integral: \(B=(B_1,\ldots,B_\tau)\in\mathbb{Z}_{\ge0}^{\tau}\), where \(B_r\) is the number of type-\(r\) orders assigned to one worker. Its cost is

\[ c(B)=\sum_{r=1}^{\tau} w_r B_r. \]

A continuous allocation is a finite-support distribution \(\lambda\) over integral bundles, where \(\lambda_B\) is the mass of workers receiving \(B\). It must satisfy

\[ \sum_B\lambda_B=1 \qquad\text{and}\qquad \sum_B\lambda_B B_r=\rho_r \quad\text{for every }r. \]

The question is whether there exists such a \(\lambda\) with \(c(B)\le q\) for every bundle in its support; equivalently, compute

\[ \theta_\infty(\rho,w) = \min_{\lambda} \max\{c(B):\lambda_B>0\}. \]

The output is the finite-support mass allocation \(\lambda\), not a fractional bundle given to an individual worker. Each infinitesimal worker receives an integral bundle; only the population fraction receiving each bundle is fractional. On a star, every such allocation is non-wasteful because every order is already a leaf.

This is recognizably the authors’ problem rather than a tractable substitute. It preserves the same topology, the same route cost, the same integral bundles, the same worst-off-worker objective, and the same non-wastefulness condition. The only change is that workers with the same type are represented by mass. For any finite \(K\) clearing the denominators, \(\lambda_B\) corresponds exactly to \(K\lambda_B\) workers receiving bundle \(B\), while the supply becomes \(K\rho_r\) orders of type \(r\). Conversely, every finite allocation produces its empirical bundle distribution. Thus this is a genuine high-multiplicity bridge, not merely a normalized restatement.

I expect this mirror to be Class A in the unary-weight, bounded-workload regime. For a fixed \(q\), the feasible bundles form a configuration set and the problem is a configuration LP. A basic feasible solution uses at most \(\tau+1\) bundle types. Its pricing problem is an integer knapsack over bundles of cost at most \(q\); with unary edge weights and polynomially bounded per-capita workload, dynamic programming gives polynomial-time separation, hence column generation or the ellipsoid method is plausible.

The important phenomenon is that Theorem 6’s discrete hardness need not survive. Its reduction has one copy of each \(3\)-PARTITION item and asks for one integral partition into \(k\) named bundles. In the continuum, different positive-mass cohorts of workers may receive different integral triple configurations. The individual bundles remain indivisible, but the population may mix configurations fractionally. The exact \(3\)-PARTITION obstruction can therefore disappear without making orders divisible.

The main weakness is that Theorem 6’s particular reduction is not itself a high-multiplicity family: it has roughly as many distinct item types as agents. So I am not claiming that the theorem already proves a continuous algorithm, only that it supplies a strong hardness anchor for a natural high-multiplicity version of the same underlying problem. The unrestricted binary-weight version may instead have continuum-specific hardness through knapsack pricing.

The resulting programme is concrete: determine exact complexity for \(\mathrm{Continuous\ Star\text{-}MMS\text{-}NW}\), quantify convergence and rounding from \(\theta_\infty\) to finite \(K\), characterize when the \(3\)-PARTITION obstruction vanishes, and locate the boundary between unary-weight tractability and binary-weight hardness. This covers Theorem 6 emphatically; I would leave the paper’s other topology-specific results outside the claimed scope.

The case AGAINST (opponent, writing after the proponent)

The best case against starts by noting that Theorem 6 is a real computational anchor, so the objection cannot be that the paper lacks algorithmic content. The difficulty is that its \(3\)-PARTITION reduction is not driven by population multiplicity. Agents have identical cost functions; the combinatorial information lies in the \(3k\) individually specified orders and their edge weights \(a_i\). A faithful type description therefore has as many relevant route-weight classes as the instance requires, while the worker population itself is essentially one type.

If the order set is held fixed while the number of workers grows, the mirror degenerates: once there are enough workers, every order can be assigned to a separate worker and the MMS value is just the largest order cost. To avoid that, the proponent scales the order supply per worker. That is coherent, but it changes the instance regime from the paper’s finite weighted star into a recurring-route, per-capita supply model. The input is no longer the paper’s collection of orders; it is a high-multiplicity bin-packing instance described by \((\rho,w)\).

This distinction matters because the proposed \(\lambda\) is not a distribution over worker types in the paper’s model. It is a configuration distribution over integral bundles. The worker population is a singleton type, while route classes and per-capita supplies carry all the information. Thus the claimed continuum effect comes from allowing a population mixture of complete integral bundles, together with scaled resources. That may be a legitimate high-multiplicity allocation problem, but it is an extension through resource and configuration structure, not a direct continuization of the theorem’s population.

The strongest version of the proponent’s model nevertheless survives this objection. It does preserve integral bundles, uses the correct support-wise worst-bundle MMS objective, and has an exact rational-cloning interpretation: rational \(\lambda\) can be realized by sufficiently many identical workers. The star also makes non-wastefulness automatic, exactly as in the source problem. Calling it merely “fractional bundles” would therefore be wrong; the bundles remain integral and only their population frequencies are fractional.

What does fail is the proponent’s implicit Class-A conclusion. For a fixed threshold \(q\), the configuration LP has pricing problem

\[ \max\{\pi\cdot B : B\in\mathbb{Z}_{\ge 0}^{\tau},\; w\cdot B\le q\}, \]

which is an unbounded-knapsack problem. Unary edge weights and polynomially bounded \(q\) permit dynamic programming, but unary weights alone do not establish polynomial running time in the ordinary binary encoding when \(q\) or the per-capita supplies are large. Nor does the disappearance of the particular \(3\)-PARTITION obstruction prove that all fractional-support or bit-complexity issues disappear.

That is the strongest negative case: the faithful fixed-supply limit is trivial, while the nontrivial repaired model is a standard high-multiplicity configuration problem whose population type space is itself vacuous. But it is not enough to sustain the universal claim. The repaired weighted-star model is mathematically natural, author-recognizable, and computationally open at its exact boundary. The honest conclusion is therefore that the negative case is weak: Theorem 6 supplies a narrow but defensible continuous mirror, even though the proponent has overstated the evidence for tractability.
