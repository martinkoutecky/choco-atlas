The continuous mirror question

Given a finite type set \(\mathcal T\), resource classes \(\mathcal K\), rational masses \(\mu_t\) summing to \(1\), strict class rankings for each type, and rational initial and target allocation matrices \(A^0,A^1\) with row sums \(\mu_t\) and matching column sums, is \(A^1\) reachable from \(A^0\) by a finite sequence of moves? Each move chooses distinct types \(t,u\), classes \(a,b\), and mass \(\delta>0\) available in cells \((t,a)\) and \((u,b)\), where \(b\succ_t a\) and \(a\succ_u b\), then exchanges that mass between the two types.

The model it lives in

A complete-graph population with rational mass \(\mu_t\) for each preference type \(t\); each unit of mass holds one indivisible resource class in \(\mathcal K\). The state is a type-by-class allocation matrix, and a move exchanges positive mass between two types when both strictly prefer the other's class. The decision asks whether a finite sequence reaches the specified target matrix exactly.

The objection that survived

The clique reduction depends on a particular object reaching a particular agent, while the proposed quotas erase those named identities; the proponent does not show that the reduction survives this quotient.

What the mirror covers

The mirror covers Proposition 6 through clique mass-reachability. It leaves the cycle algorithm in Theorem 1 aside because its reasoning depends on agents' distinct positions around the cycle.

The case FOR (proponent)

My strongest mirror is the clique hardness, not the cycle algorithm. On a cycle, an agent’s location determines which swaps are possible, so treating location as part of a complete type would usually make the number of types grow with the population. The clique case gives a cleaner large-population scenario: every pair is eligible to trade.

The anchor is Proposition 6: \(\textsc{Reachable Assignment}\) is NP-hard on cliques. Its input has equally many agents and objects, strict agent preferences, an initial and a target bijective assignment, and a clique as the trade graph; it asks whether a sequence of pairwise rational swaps reaches the target, where both agents in every swap strictly prefer what they receive. This proposition is proved in this paper. The proof adapts Gourvès et al.’s reduction from \(\textsc{Reachable Object}\) to \(\textsc{Reachable Assignment}\), adding missing edges to preserve a clique, and relies on Bentert et al.’s cited NP-hardness result for \(\textsc{Reachable Object}\) on cliques.

A natural scenario is a large exchange programme for indivisible units in standardized resource classes, with a clearinghouse that makes any pair of participants eligible to trade. Participants have one of a small number of preference rankings over the classes. The population may be enormous while the number \(\tau\) of preference types stays small. Each unit still receives one whole indivisible item; a fractional entry below records the share of a cohort holding that class of item.

Call the proposed problem Clique Mass-Reachable Assignment. An instance has a finite set of types \(\mathcal T\), with rational masses \(\mu_t\geq 0\) summing to \(1\); a finite set of resource classes \(\mathcal K\); a strict ranking \(\succ_t\) of those classes for each type; and rational initial and target allocation matrices \(A^0,A^1\). Each matrix entry \(A_{t,k}\) is the mass of type \(t\) holding class \(k\). Both matrices must have row sums \(\mu_t\), and their column sums must agree, preserving each class’s supply.

A move chooses distinct types \(t,u\), classes \(a,b\), and positive mass \(\delta\). It is allowed when the current allocation has at least \(\delta\) of type \(t\) holding \(a\) and type \(u\) holding \(b\), and \(b\succ_t a\) and \(a\succ_u b\). It exchanges that mass: \(t\) loses \(\delta\) of \(a\) and gains \(\delta\) of \(b\), while \(u\) does the reverse. The question is whether a finite sequence of such moves reaches \(A^1\) exactly from \(A^0\). This is a reachability decision problem, so it has no cost objective; the move sizes and sequence are its solution witness.

The class-level model treats identical copies as one resource class, so preferences are strict over classes and indifferent among copies within a class. That is a modest co-modification of the paper’s strict rankings over individually named objects. One could instead make every named object its own class, but then the model gives up that compression. The class version is plausible for standardized indivisible units; the exact-identity version is a useful follow-up question.

For this mirror I would tentatively expect Class C when \(\tau\) and \(|\mathcal K|\) vary: the order in which mutually improving swaps occur may retain hard dependencies even after agents of the same type become interchangeable. That is a low-confidence conjecture, not a consequence of Proposition 6. The paper’s discrete hardness alone does not establish hardness of this mass problem. In particular, the continuous move can split a cohort, and the type-level target specifies quotas rather than which named agent receives which named object. Those changes may dissolve the reduction; a structural characterization or optimization formulation could instead yield tractability.

The main questions for a prover are therefore whether this problem is tractable for fixed \(\tau\) or fixed \(|\mathcal K|\), how its complexity depends on \(\tau\), \(|\mathcal K|\), and the input bit length, and whether exact finite-sequence reachability can be characterized by a flow or linear-programming condition. It is also worth separating exact reachability from reaching the target only as a limit of increasingly small trades.

The weak point is the aggregation itself: the paper’s target is an assignment of each named agent to a named object, whereas this mirror uses type-level quotas and resource classes. If those distinctions are essential to the authors, this is a related high-multiplicity variant rather than their continuous analogue. The case survives if agents within a type really are interchangeable for the question being asked and the target is naturally expressed as cohort quotas. I would mirror Proposition 6 alone; it is the paper’s strongest anchor for a continuous complexity question.

The case AGAINST (opponent, writing after the proponent)

Proposition 6 is the right anchor, but its target makes a faithful population limit difficult. In the paper, an agent is distinguishable not only by preference: the input specifies the unique object they initially hold and the unique object they must hold at the end. If those are part of a complete type, every type has mass \(1/n\), since the initial assignment is a bijection. Keeping the named objects and named target assignment therefore leaves no repeated population types to aggregate. In an atomless limit, each individual swap changes zero mass, so finitely many original swaps cannot move the population to a different aggregate assignment.

The proposed repair—standardized resource classes, repeated copies, and type-by-class target quotas—is much stronger than merely replacing headcounts with masses. It makes assignments within a cohort interchangeable and changes the target from a named-agent bijection to an aggregate allocation matrix. That erases the feature the hardness reduction uses: a particular object \(x_\ell\) must reach a particular agent \(i\), after which the copies and their individually tailored preferences force the target. The resulting question may be a good exchange problem, but Proposition 6 does not establish that its hard instance survives that quotient.

That is the strongest case against the anchor, and it has a clear limit. The cohort version is well-defined, and for rational masses a finite mass move can be expanded, after clearing denominators, into finitely many disjoint rational swaps among clones. Standardized copies and quota targets could also be a regime the authors would recognize. I cannot honestly rule out that this is a worthwhile high-multiplicity extension; I can only say it is not a faithful mirror of the named-assignment hardness result, and its computational value has to be established independently. The cycle theorem offers little escape from this concern: its algorithm depends on agents’ distinct positions around the ring, which either remain singleton types or are lost when positions are merged.
