The continuous mirror question

Given a finite type set \(T\) with positive binary-rational masses \(\mu_t\) summing to \(1\), a listed family \(E\) of contract templates \(e\subseteq T\), and a strict ranking \(\succ_t\) over templates containing each type \(t\), find nonnegative rational masses \(x_e\) such that \(\sum_{e\ni t}x_e\leq\mu_t\) for every \(t\), and for every template \(e\), some \(t\in e\) satisfies \(\sum_{f\ni t:\,f\succeq_t e}x_f=\mu_t\).

The model it lives in

A type-capacity stable hypergraph matching model: each type carries mass \(\mu_t\), each listed template uses one unit of every type it contains, and the variables \(x_e\) give the mass assigned to each template. There is no welfare objective; the task is to find a feasible assignment satisfying the stability condition.

What the mirror covers

The mirror covers Theorem 5.7’s Fractional Hypergraph Matching hardness through its equal-mass subcase. It leaves the paper’s other results alone, and does not establish the complexity of the arbitrary-capacity version.

Open questions for a prover

  • Does the version with arbitrary binary-rational type masses admit a PPAD-membership proof, and what is its complexity in \(|T|\), the number of templates and incidences, and bit length \(L\)?
  • Do bounded template size or restrictions on type rankings yield tractable or fixed-parameter cases?

The case FOR (proponent)

The mirror I would defend is Type-Mass Fractional Hypergraph Matching, based on the paper’s Fractional Hypergraph Matching result. It makes the population continuous while keeping the object being allocated—a whole contract or team—discrete. That is within the programme’s scope: the fractional values represent how much population receives each integral kind of contract.

A plausible regime is a large labor market in which millions of people fall into a few hundred complete types: for example, combinations of occupation, credentials, location, and a shared ranking over team templates. A template specifies which types contribute one person to a team. The type definition must include everything relevant to the model, including preferences; if individual differences matter, they create more types. The regime is credible when the number of people \(N\) is far larger than the number of supported types \(\tau\), with many people in each type.

My anchor is Theorem 5.7, proved in this paper: \(\text{Degree }d\text{ Preference Game} \le_P \text{Fractional Hypergraph Matching}\). The theorem starts with a preference game on players \([n]\). It creates two vertices \(i\) and \(i^*\) for each player, a singleton edge \(\{i^*\}\), and, for every \(J\subseteq \mathrm{in}(i)\), an edge \(\{i,i^*\}\cup J\). Here \(\mathrm{in}(i)\) consists of players whose preference lists rank \(i\) above themselves. At vertex \(i\), incident edges are ordered by the original preference of the player associated with the edge; when two edges have the same associated player, the edge containing the larger set is preferred. At \(i^*\), \(\{i,i^*\}\) is preferred to \(\{i^*\}\). For constant \(d\), this construction has polynomial size. The theorem proves that an equilibrium of the preference game can be mapped to a stable fractional matching in the constructed instance, and vice versa. The paper’s preceding preference-game construction supplies degree-three PPAD-hard instances, so this reduction is the hardness leg for Fractional Hypergraph Matching.

Here is the continuous problem I would hand to a prover. An instance consists of a finite set \(T\) of types, positive binary-rational masses \(\mu_t\) with \(\sum_{t\in T}\mu_t=1\), a listed family \(E\) of feasible contract templates \(e\subseteq T\), and a strict ranking \(\succ_t\) over every template containing \(t\). Each template uses one unit of mass from each type it contains. Find nonnegative rational masses \(x_e\) of contracts such that, for every type \(t\), \(\sum_{e\ni t}x_e\leq\mu_t\), and for every template \(e\), some type \(t\in e\) satisfies \(\sum_{f\ni t:\,f\succeq_t e}x_f=\mu_t\). The latter says that every proposed template is blocked by at least one type whose supply is fully committed to templates it likes at least as much. There is no global welfare objective in the paper’s problem; the solution criterion is stability under the participants’ preferences.

This is a direct type-capacity version of the paper’s matching problem. In a finite realization, each person receives an integral contract, while \(x_e\) records the fraction of the whole society assigned to template \(e\). The type masses and contract masses are the continuous quantities. A finite Fractional Hypergraph Matching instance with \(\tau\) vertices embeds exactly as the uniform-mass case: set \(\mu_t=1/\tau\), and divide each original matching weight by \(\tau\). Conversely, multiply a solution by \(\tau\) to recover the original instance. Thus the continuous problem is PPAD-hard even when all type masses are equal and every type can contain arbitrarily many identical people. The hardness is in the type and template structure, not in having few people per type. I would expect Class B: hardness transfers. The continuous problem’s natural complexity parameters are \(\tau\), the number of listed templates and incidences, and the bit length \(L\); the reduction does not establish hardness at fixed \(\tau\).

I would scope this case to Theorem 5.7 and its Fractional Hypergraph Matching target. It does not claim to mirror the paper’s other results on personalized equilibria, routing, or cooperative-game cores. It also keeps separate two kinds of continuity: the paper already allows fractional matching weights, but this mirror makes the *society* a distribution over types. In applications, finite rational supplies should be approachable through the same Scarf-style framework used for fractional stability; a precise PPAD-membership statement for arbitrary rational type masses would be a further result to establish.

The weakest point is the type compression. The reduction constructs many bespoke vertices and does not show that its hard instances have a small number of realistic preference types. Nor does the mirror show that the problem becomes easier when millions of people share a type. Its positive case is narrower: large, repeated populations make type-level supplies a sensible model of stable hypergraph matching, and the paper’s hardness survives that population interpretation. Further questions include whether bounded template size or restrictions on type rankings yield tractable or fixed-parameter cases, and how well type-level stable masses can be realized or approximated in finite populations.

The case AGAINST (opponent, writing after the proponent)

Theorem 5.7 passes the computational-anchor test: it is a named reduction to Fractional Hypergraph Matching, and the paper’s preference-game hardness supplies the hard source. The labor-market interpretation is also coherent. A type can describe everything relevant about its members, each person can receive a whole contract, and the aggregate template masses can express a large population without tracking names.

The strongest objection is that the uniform-mass mirror is already the theorem’s target under a change of scale. Let \(\tau=|V|\), set \(T=V\), \(\mu_v=1/\tau\), and define \(x_e=w_e/\tau\), where \(w_e\) is the paper’s fractional matching weight. Then the capacity and stability conditions scale exactly: \(\sum_{e\ni v}x_e\le\mu_v\), and a blocking type has preferred-or-equal mass \(\mu_v\). This is a population interpretation, not merely an appeal to fractional outcomes: with enough identical clones of each type, the aggregate assignments describe people receiving integral contracts. The paper already studies the resulting uniform-type-mass problem.

The stronger mirror with arbitrary rational masses \(\mu_t\) remains well posed, but it changes only the supply capacities in that same model. The paper’s Scarf formulation already permits an arbitrary right-hand-side vector \(b\), so the capacity extension appears to fit its existing machinery by setting \(b_t=\mu_t\). That makes it hard to present as a new continuous-complexity frontier, though I have not traced the cited reduction closely enough to claim the extension is already proved.

So the best case against is a narrow one: this looks like a useful population reading of an existing fractional matching result, with the unequal-mass version a nearby capacity generalization. But I cannot honestly rule out a worthwhile mirror in every scenario. The proposed type-mass model is faithful, and the paper itself may already be doing much of the relevant work.
