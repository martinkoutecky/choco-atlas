The continuous mirror question

Given finite type sets \(I,J\), positive rational masses \(p_i,q_j\) with \(\sum_i p_i=\sum_j q_j=\tfrac12\), and nonnegative rational surpluses \(a_{ij}\), let feasible assignment flows satisfy \(x_{ij}\ge0\), \(\sum_jx_{ij}\le p_i\), and \(\sum_ix_{ij}\le q_j\). Let \(W\) be the maximum of \(\sum_{i,j}a_{ij}x_{ij}\). A core payoff assigns rates \(u_i,v_j\ge0\) satisfying \(u_i+v_j\ge a_{ij}\) and \(\sum_i p_i u_i+\sum_jq_jv_j=W\). Compute, for every type pair, the exact rational bound \(\ell_{ij}=\min\{u_i+v_j:(u,v)\text{ is a core payoff}\}\), with a core payoff attaining each bound.

The model it lives in

A bipartite assignment market with a continuum of agents represented by type masses, mass-flow assignment variables, and per-unit transferable payoff rates; the objective is to compute each type-pair’s minimum combined rate over the core.

What the mirror covers

The mirror covers the exact individual and mixed-pair core payoff lower bounds computed by Algorithm Cover, translated into bounds for pairs of types in a mass assignment market. It leaves aside Theorem 2’s lemaral characterization, the Alexia value, and the paper’s general lexicographic-allocation results.

Open questions for a prover

  • Can a mass-weighted analogue of Algorithm Cover compute all \(\ell_{ij}\) in time polynomial in the number of supported types and the input bit length?

The case FOR (proponent)

The strongest case I believe is a narrow mirror around the paper’s computation of exact lower bounds on core payoffs. The natural regime is a large placement market: many workers and vacancies, but comparatively few payoff-relevant types. A worker type might fix credentials, location, and the surplus generated with every vacancy type; a vacancy type likewise fixes the relevant match values. With thousands of agents but tens or hundreds of types, the population is plausibly much larger than the support. This is a familiar continuum assignment-market model, not a claim that continuizing populations is new.

My anchor is Proposition 6, proved in this paper. It analyzes Algorithm Cover on a square assignment matrix whose diagonal is an optimal matching. In each round, the algorithm raises each entry \(a_{ij}\), if needed, to \(\max\{a_{ij},\max_{k\ne i,j}(a_{ik}+a_{kj}-a_{kk})\}\), using the current matrix’s entries. Proposition 6 states that the process stops after at most \(m\) rounds and takes \(O(m^4)\) elementary operations. Cover is intended to compute the exact lower bounds on core payoffs for each individual and mixed pair. Proposition 7, also proved here, establishes that each round preserves the core and keeps the diagonal optimal, supporting the use of Cover for that computation. The paper has no comparable numbered hardness result, so this is its strongest computational anchor.

Here is the continuous problem I would hand to a prover: the lead mirror, Continuous Exact Core-Bound for Assignment Markets. Its instance is two finite type sets \(I,J\), with positive rational masses \(p_i,q_j\) satisfying \(\sum_i p_i=\sum_j q_j=\tfrac12\), and a nonnegative rational match-surplus matrix \(a_{ij}\). The combined population mass is one; dummy types can represent outside options. Every unit of type \(i\) has the same surplus \(a_{ij}\) from matching with a unit of type \(j\). The type description includes all match-relevant attributes, so agents sharing a type are interchangeable for this problem.

A feasible assignment is a mass flow \(x_{ij}\ge0\), with \(\sum_jx_{ij}\le p_i\) and \(\sum_ix_{ij}\le q_j\). Let \(W\) be the maximum of \(\sum_{ij}a_{ij}x_{ij}\) over those flows. A core payoff vector gives each unit of type \(i\) a transferable payoff rate \(u_i\) and each unit of type \(j\) a rate \(v_j\), subject to \(u_i,v_j\ge0\), \(u_i+v_j\ge a_{ij}\), and \(\sum_i p_i u_i+\sum_jq_jv_j=W\). These conditions protect every coalition of submasses: no matching within it can generate more than its members’ combined payoffs.

The question is to compute, for every type pair, \(\ell_{ij}=\min\{u_i+v_j:(u,v)\text{ is a core payoff vector}\}\). A solution is the exact rational matrix \((\ell_{ij})\), with a core payoff vector attaining each bound. This mirrors the paper’s lower core-bound problem directly: its mixed-pair quantity is now a per-unit bound for a pair of types. Mass is the population share, \(x_{ij}\) records the matched mass, and the objective for each bound is to minimize the combined per-unit payoff across core allocations.

I expect this problem to be tractable. Compute \(W\) by the assignment LP, then solve one rational LP for each \(\ell_{ij}\). The total work is polynomial in the number of supported types and the binary input length \(L\). If the masses are rational clone proportions with common denominator \(D\), scaling produces a finite high-multiplicity instance with \(D\) agents in total. The type-level LP works in the support size and \(\log D\), rather than explicitly expanding all those agents. The finite and continuous welfare formulations also agree after scaling: the matching polytope with integer supplies has an integral optimum.

The mirror covers the exact lower core bounds computed by Cover. The paper’s Theorem 2, which identifies its lemarals with extreme core points, and its Alexia-value computation raise further questions but are outside this mirror: their lexicographic procedure orders named individuals, and an order over a continuum of agents is not supplied by the type model.

The soft spot is that Proposition 6 is already an algorithmic result for a finite assignment matrix, not a hardness result whose difficulty might disappear under continuization. The proposed mirror therefore makes a credible high-multiplicity computational question, but it does not demonstrate that continuity dissolves hardness. A useful next question is whether a mass-weighted analogue of Cover can compute the exact type-pair bounds directly, and whether an order over types yields a meaningful counterpart to the paper’s lemarals.

The case AGAINST (opponent, writing after the proponent)

The strongest case against the proposed mirror is that its continuous computation is almost immediate from the assignment LP. Given type masses, compute the maximum matching flow \(W\); the type-level core is the dual optimal face, and each bound \(\ell_{ij}\) comes from minimizing \(u_i+v_j\) over that face. That is one rational LP per type pair. The assignment-game core was already characterized as the set of dual optimal solutions to the assignment problem, with effective computation as a consequence of that characterization ([Shapley and Shubik, *The Assignment Game I: The Core*](https://www.math.utoronto.ca/mccann/assignments/477/ShapleyShubik72.pdf)). So this mirror adds no pricing problem, new optimization machinery, or apparent complexity barrier. Proposition 6 already gives a polynomial algorithm for the discrete bounds; the continuous version seems likely to be a routine capacity-weighted LP formulation, rather than a case where continuization opens a previously inaccessible computational question.

That is a case about likely research yield, not about whether the mirror is well-posed. The proposed market is plausible: repeated worker and vacancy types make population mass meaningful, and exact per-type payoff bounds are sensible outputs. Requiring type-level payoffs is also defensible for indistinguishable agents. A stronger attempt to dismiss it because the finite and continuous assignment problems are related would fail the programme’s standard: establishing that correspondence can itself be a useful result, and high multiplicity is evidence for the regime.

The same limitation applies to alternate mirrors of Theorem 2 or the Alexia value. Ordering supported types and lexicographically optimizing the type-level core gives a coherent finite-dimensional question. The paper’s order over named individuals does not directly supply that model, and a type order changes the object being averaged, but those points do not rule out a recognized mass-level version.

So the negative case is weak at its essential burden. Proposition 6’s mirror looks modest and may have low marginal value because a standard LP appears to settle it, but I cannot honestly establish that no worthwhile continuous mirror exists. The assignment-market scenario survives the main objections; the best case against it is that it may be too easy to merit priority, not that it fails as a mirror.
