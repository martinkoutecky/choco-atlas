The continuous mirror question

Given a finite task set \(S\), exact worker types \(T\), rational type masses \(\mu_t\geq 0\) summing to \(1\), and rational task data with workload and reward scaled per reference population, choose masses \(x_{ts}\geq 0\) assigned from type \(t\) to task \(s\), subject to \(\sum_s x_{ts}\leq\mu_t\) and reachability constraints. For each assigned task let \(y_s=\sum_t x_{ts}>0\) and \(q_s=a_s+(\sum_t \Delta_{ts}x_{ts}+\bar w_s)/y_s\); require completion by the deadline and positive work contribution \(q_s-a_s-\Delta_{ts}>0\) for every assigned type. Keep tasks indivisible: an assigned task earns the paper’s reward-pricing-model reward at \(q_s\), and an unassigned task earns zero. Maximize total task reward, or decide whether a feasible assignment achieves at least a given rational threshold \(K\).

The model it lives in

A finite set of indivisible tasks and a finite set of exact worker types, each with rational population mass \(\mu_t\), location, availability, speed, and reach. The decision variables are type-to-task masses \(x_{ts}\), with each type’s total assigned mass bounded by \(\mu_t\); task workloads and maximum rewards scale with the reference population. Coalition completion times use the mass-weighted travel and workload formula, and the objective is total reward under the paper’s reward pricing model.

What the mirror covers

Covers the global reward-maximizing CTA objective and its knapsack-hardness result, Lemma 1; leaves the greedy approach, equilibrium and simulated-annealing results, and priority-aware fairness results unmirrored.

Open questions for a prover

  • What approximation guarantees or parameterized algorithms are possible for F-CTA, given hardness already with one worker type?
  • Which restrictions on task data or spatial reachability make F-CTA tractable?

The case FOR (proponent)

My lead, and the only anchor I would use, is Lemma 1, proved in this paper: CTA is NP-hard. The authors reduce from 0–1 knapsack. For each knapsack item \(i\), they create a task with workload \(m_i\), maximum reward \(v_i\), publication time \(0\), and expected completion time and deadline \(1\). They place all tasks and \(M\) workers in the same location, with each worker able to supply one unit of workload. Choosing tasks that can be completed by the workers then corresponds to choosing items whose total weight is at most \(M\), maximizing their total value. The lemma is the authors’ result; the paper cites the known knapsack hardness.

A credible mirror is Fluid Coalition-based Task Assignment (F-CTA) for a large spatial-crowdsourcing dispatch. Think of a regional event setup or municipal field operation: many workers are dispatched from a modest number of hubs in scheduled batches. A worker type records everything CTA uses about a worker—such as exact dispatch location, online time, speed, reachable distance, and capacity. For instance, \(100{,}000\) workers could belong to a few dozen hub, shift, and mobility profiles. They are interchangeable for this assignment because the information relevant to task eligibility, travel, and work contribution is identical within each type.

An F-CTA instance has a finite task set \(S\), a finite type set \(T\), and rational type masses \(\mu_t\geq 0\) with \(\sum_{t\in T}\mu_t=1\). Task data include location, publication and assignment times, expected completion time, deadline, penalty rate, and maximum reward. Because this is a large operation, specify workload and reward in per-reference-population units: in a population of size \(N\), the corresponding task workloads and budgets scale with \(N\). This keeps worker supply and task demand comparable as the population grows.

The decision variable \(x_{ts}\geq 0\) is the fraction of the population of type \(t\) assigned to task \(s\); require \(\sum_{s\in S}x_{ts}\leq\mu_t\), and \(x_{ts}=0\) when type \(t\) cannot reach task \(s\). Thus each actual worker still receives one task or none; the assignment divides the *mass of interchangeable workers* across tasks. Tasks themselves remain indivisible: each task is completed as a whole or left unassigned.

Write \(y_s=\sum_t x_{ts}\) for the coalition mass assigned to task \(s\), and \(\Delta_{ts}\) for the travel time from type \(t\) to task \(s\). If \(y_s>0\), the normalized counterpart of the paper’s completion-time formula is
\(q_s(x)=a_s+\bigl(\sum_t\Delta_{ts}x_{ts}+\bar w_s\bigr)/y_s\),
where \(a_s\) is the assignment time and \(\bar w_s\) is the workload per reference population. Assigned types must contribute nonnegative work, and an assigned coalition must finish by the deadline. The task earns the paper’s RPM reward: its normalized maximum reward \(\bar R_s\) if \(q_s\) is between publication and expected completion, its normalized linearly penalized reward if \(q_s\) is later but before the deadline, and zero if unassigned. F-CTA asks for a feasible mass assignment \(x\) maximizing the sum of task rewards; its threshold version asks whether some feasible \(x\) achieves at least a given rational value \(K\). An output is the mass assigned to each type–task pair and the resulting total reward.

I expect hardness to transfer, because Lemma 1’s task-selection combinatorics survive even when the workforce is a continuum. In its knapsack construction, replace the \(M\) workers by one type of mass \(1\), put all tasks at the same location, set publication time to \(0\) and expected completion time and deadline to \(1\), and give task \(i\) normalized workload \(\bar w_i=m_i/M\) and reward \(v_i\). With zero travel, assigning mass \(y_i\) gives completion time \(\bar w_i/y_i\). Task \(i\) earns its reward exactly when \(y_i\geq m_i/M\). Since the total available mass is \(1\), the completed-task subset is feasible exactly when \(\sum_i m_i\leq M\). Thus the continuous-worker threshold problem is NP-hard already with one worker type. The mass can split freely, but it cannot split a task’s reward or workload into independently selectable pieces.

This is a mirror the authors could plausibly recognize: it preserves their task data, coalition-based completion time, reward pricing, worker exclusivity, and total-reward objective. The co-modification is that aggregate job workload and budget scale with the population. That is natural for large field-operation bundles, though it needs to be stated as part of the intended regime. This proposal covers the paper’s global reward-maximizing CTA problem and Lemma 1, not its greedy algorithm, equilibrium convergence results, or priority-aware fairness extension.

The weakness is that the population scaling matters. If the intended tasks stay fixed in size as more workers join, a mass-normalized model may let a vanishing fraction of the workforce complete them, so it would not faithfully capture that regime. The hub-and-shift scenario also depends on genuinely repeated worker profiles, not merely approximate similarity. Those are the points an author or referee would need to accept.

The mirror raises useful follow-up questions: does the full RPM model admit approximation guarantees despite the knapsack barrier; which parameterizations beyond support size \(\tau\) help, given hardness at \(\tau=1\); and can its completion-time constraints be handled by a tractable optimization formulation? This would put a precise boundary on what population continuization buys for CTA: it makes the aggregate workforce the object of study, but does not dissolve hardness carried by indivisible task choices.

The case AGAINST (opponent, writing after the proponent)

The one serious anchor is Lemma 1: the paper explicitly proves CTA NP-hard by reduction from 0–1 knapsack. So the case against cannot deny that there is a computational result to mirror.

The strongest objection is that F-CTA preserves the knapsack choice while making the workforce fluid. For each task \(i\), its reward is available only once the assigned mass reaches \(m_i/M\); the optimizer still chooses a subset of indivisible tasks. That captures the paper’s hardness witness, where workers are already identical and colocated. It says little about the paper’s spatial coalition formation, equilibrium dynamics, or fairness mechanisms. This limits what the mirror would teach about CTA’s distinctive structure, though it does not make the question ill-posed or rule out value in mapping the boundary.

A more faithful model with fixed projects and rewards has a different problem: as the workforce grows, each project’s required worker mass shrinks toward zero. The normalized objective can then vanish, and the growing population has little bearing on which finite set of projects is selected. F-CTA avoids that degeneration by scaling project workload and reward with the population. That is allowed within ChoCo’s scope, but it changes the instance regime. For the paper’s examples—furniture installation, home improvement, and event work—projects are ordinarily bounded jobs with particular locations and deadlines. A convincing scaled version needs a scenario such as recurring regional service campaigns, where both labor demand and payment grow with the cohort.

That scenario is plausible. Workers dispatched in identical hub-and-shift cohorts can share the location, availability, speed, and reach attributes the model uses. A campaign can also be a whole task completed by a coalition, with its workload and reward scaling with the operation. I cannot honestly rule that out as a mirror the authors would recognize. The negative case is therefore weak: its best point is that the proposed mirror centers on task selection and requires a changed task regime, while the paper’s named hardness result supplies only one anchor. Those points narrow the mirror’s contribution; they do not defeat it.
