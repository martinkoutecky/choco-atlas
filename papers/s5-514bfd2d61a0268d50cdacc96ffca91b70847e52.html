The continuous mirror question

Given \(s\) item classes with rational per-capita supplies \(q_r\), integer values \(v_r\), and a rational distribution \(\mu\) over \(\tau\) types \(D_t\subseteq [s]\), assign each type’s mass to integral bundles \(b\in\mathbb Z_{\ge 0}^s\), subject to \(\sum_b x_{t,b}=\mu_t\) and \(\sum_{t,b}x_{t,b}b_r\le q_r\). Can one compute an allocation whose minimum utility among positive-mass bundles is at least \(U^*/(6+\delta)\), in time polynomial in \(\tau\) and the input bit length \(L\), for fixed \(s\), where \(U^*\) is the optimal continuous allocation value?

The model it lives in

A unit mass of households is distributed over \(\tau\) types with masses \(\mu_t\); type \(t\) desires item classes \(D_t\) and values bundle \(b\) at \(\sum_{r\in D_t}v_rb_r\). Variables \(x_{t,b}\) assign mass to integral bundles, and rational per-capita supplies \(q_r\) constrain total use of each class.

The objection that survived

After aggregating types, the continuous allocation is mathematically the paper’s configuration LP, so the fixed-\(s\) question may add little beyond a known formulation; this limits novelty but does not invalidate the distinct population regime.

The case FOR (proponent)

The strongest mirror I see is Continuum Restricted Max-Min Fair Allocation.

The paper’s anchor is Theorem 4.2, proved here: for every fixed \(\delta\in(0,1)\), there is a polynomial-time algorithm, polynomial in the numbers \(m\) of players and \(n\) of resources, that returns a \((6+\delta)\)-approximate allocation for restricted max-min fair allocation. The theorem’s objective is to maximize the least total value received by any player. The introduction also mentions hardness below approximation ratio \(2\), but attributes it to Bezáková and Dani; it is not a numbered result proved in this paper, so I do not use it as an anchor.

Here is a scenario where the population limit is credible: a large relief programme serves households from a small number of eligibility and preference profiles, distributing a handful of standard classes of indivisible aid items. A type \(t\) is a complete profile: it determines which item classes the household wants. Every household wanting class \(r\) values one item from it at \(v_r\), and households not wanting it value it at zero. The number \(N\) of households is large compared with the number \(\tau\) of types; supplies of each item class grow with the population.

Normalize the population to mass \(1\). Type \(t\) has rational mass \(\mu_t>0\), with \(\sum_t\mu_t=1\). There are \(s\) item classes, with rational per-capita supply \(q_r\) for class \(r\). A person still receives an integral bundle \(b\in\mathbb Z_{\ge0}^s\); the continuous decision is how much mass of each type receives each bundle. Let \(x_{t,b}\) be that mass. The problem is:

\[ \begin{aligned} \text{maximize}\quad& \min_{\substack{t,b\\x_{t,b}>0}} \sum_{r=1}^s v_r\,\mathbf 1[r\in D_t]\,b_r\\ \text{subject to}\quad& \sum_b x_{t,b}=\mu_t &&\text{for each type }t,\\ &\sum_{t,b}x_{t,b}b_r\le q_r &&\text{for each item class }r,\\ &x_{t,b}\ge0. \end{aligned} \]

Here \(D_t\) is the set of item classes type \(t\) wants. A solution is a feasible assignment of mass to integral bundles. The allocation is fractional only at the type level: each household still gets whole items. This preserves the paper’s restricted valuations and max-min objective while making the population itself continuous.

I would make the precise question for Theorem 4.2’s mirror this: for fixed \(s\), given the rational type masses, per-capita supplies, and integer values, can we compute an optimal continuous allocation in time polynomial in \(\tau\) and the input bit length \(L\)? This is a Class A question, and in this fixed-\(s\) regime the configuration LP gives a concrete route. For a candidate minimum value \(z\), use variables for type-and-bundle configurations meeting value \(z\). Feasibility is an LP with \(\tau+s\) resource and type constraints. Though there can be many configurations, pricing for a type reduces to minimizing a linear resource cost over integral bundles satisfying one value threshold. With \(s\) fixed, this is fixed-dimensional integer optimization, so the LP’s separation problem is polynomial in \(L\). Binary search over the integer value \(z\) then finds the optimum. The aggregate value available per capita, \(\sum_r q_rv_r\), bounds that search.

The authors should recognize this as their problem: the same resource allocations, additive restricted values, and least-served-agent objective remain. Only the instance regime changes to many indistinguishable agents and a small number of item classes. A configuration LP is exact here because its variables describe actual mass assigned to whole bundles, rather than fractional items assigned to an individual.

My weakest point is the fixed-\(s\) restriction. It gives a convincing continuous mirror for a low-category regime, but it does not establish a polynomial algorithm when the number of resource classes is part of the input. Nor does Theorem 4.2 itself give the desired bit-complexity bound: expanding rational masses and supplies into explicit agents and resources could take time polynomial in a population size that is exponential in \(L\). The broader follow-up is whether the paper’s \((6+\delta)\)-approximation can be obtained in time polynomial in \(\tau,s,L\), or whether pricing becomes hard as \(s\) grows. A related bridge question is how precisely a continuous allocation lifts to a finite population of a specified size, rather than only to a suitably scaled finite realization.

This mirror covers Theorem 4.2’s allocation guarantee, not every result or technique in the paper.

The case AGAINST (opponent, writing after the proponent)

The only in-paper computational anchor is Theorem 4.2. The best objection is that the proposed mirror is very close to the paper’s own configuration LP: if \(x_{p,B}\) is the LP’s fractional assignment of player \(p\) to an integral bundle \(B\), grouping identical players into types gives \(x_{t,B}=N^{-1}\sum_{p:\,\mathrm{type}(p)=t}x_{p,B}\). Those are exactly masses assigned to integral bundles. The paper already says its configuration LP can be solved approximately in polynomial time and gives a \(4+\delta\) estimate for the restricted problem. So the fixed-\(s\) mirror risks repackaging a familiar LP as a population model.

That objection has a limit, though: the paper’s runtime is for an explicitly expanded instance. It does not establish a runtime polynomial in the binary input length \(L\) when type masses and per-capita supplies compactly encode a much larger population and inventory. Asking whether the configuration approach remains efficient in \((\tau,s,L)\), or where pricing becomes hard as \(s\) grows, is a distinct high-multiplicity question. Nearby work on high-multiplicity fair allocation also supports the plausibility of this regime, though it studies different fairness criteria and is not a continuous-population collision ([Bredereck et al.](https://arxiv.org/abs/2005.04907)).

The other obvious objections do not hold up. The minimum utility can be defined over bundles receiving positive mass, and the objective does not depend on agent identities. Fixed supplies would make some growing-population limits degenerate, but per-capita supplies that scale with the population are a coherent regime for the problem. The mirror’s authors could reasonably recognize it.

So the negative case is weak. I can argue that the fixed-\(s\) version may add little beyond a known configuration-LP formulation, but I cannot show that the stronger compressed-input question fails, or that no plausible scenario makes it worthwhile.
