The continuous mirror question

Given a candidate set \(C\), cohort size \(k\), finite type support \(T\) with rational masses \(\mu_t>0\), candidate values \(v_{tc}\), and named groups \(G_1,\ldots,G_m\) encoded by membership indicators \(a_{tj}\), define \(U_j(S)=\frac{\sum_{t\in T}\mu_t a_{tj}\sum_{c\in S}v_{tc}}{\sum_{t\in T}\mu_t a_{tj}}\). For fixed \(0\le\epsilon<1/2\), compute a cohort \(S\subseteq C\) of size \(k\) whose minimum group utility is within additive \(\epsilon\) of the optimum; classify the problem’s complexity in \(m\), \(|T|\), input bit length, and other relevant parameters.

The model it lives in

A society consists of rational masses over complete valuation-and-membership types. Each named group’s utility is the mass-weighted average of its members’ additive utilities for an integral size-\(k\) cohort, and the objective remains leximax over named groups. The hardness reduction uses the restricted case of one homogeneous type per disjoint group with equal masses.

The objection that survived

The individual-quantile version weights fairness by population mass and can reverse the paper’s equal-standing group priorities; the group-preserving version avoids this by retaining named groups as fairness units.

fatal: False

What the mirror covers

Covers the deterministic cohort-selection maxmin hardness in Lemma 20; on equal-mass groups, the non-minimum-utility count also corresponds to population mass above the minimum. It leaves the randomized marginal-selection algorithm and the paper’s general approximation and noise results aside.

Open questions for a prover

  • Does Lemma 20’s hardness persist when named groups aggregate multiple valuation types with unequal rational masses?

The case FOR (proponent)

My lead is Continuous-Population Leximax Cohort Selection. Keep the paper’s candidate pool and its deterministic, size-\(k\) cohort decision; continuize the people whose representation is being measured.

An instance has a finite candidate set \(C\), an integer \(k\), and a finite support \(T\) of stakeholder types. Each type \(t\) has rational mass \(\mu_t>0\), with \(\sum_t\mu_t=1\), and a value \(v_{tc}\in[0,1]\) for every candidate \(c\). A type is a complete valuation profile: everyone of type \(t\) has the same values for every candidate and every other feature used by the problem. For a cohort \(S\subseteq C\), \(|S|=k\), each person of type \(t\) gets utility
\[ u_t(S)=\sum_{c\in S}v_{tc}. \]
Let \(q_S(p)\), for \(p\in(0,1]\), be the lower \(p\)-quantile of these utilities under masses \(\mu\). The task is to return a cohort whose quantile function is lexicographically maximal from the lowest utilities upward: between two cohorts, the first positive-mass quantile interval on which their functions differ decides, and the cohort with the higher utility there wins. Since there are finitely many possible cohorts and types, this defines an attained optimum. The masses matter: they determine how much of the population occupies each part of the ordered utility profile.

A plausible regime is a large population of residents whose representation is assessed through a citizen panel of \(k\) people selected from a finite applicant pool. Residents with the same issue profile, and hence the same value for every possible panelist, form a type. For example, a city might have hundreds of thousands of residents but only a modest number of relevant issue-and-valuation profiles; their shares are the rational masses. This is a scenario about repeated complete profiles, not a claim that every panel-selection setting has high multiplicity.

The anchor is Lemma 20, proved in this paper. It states that for every fixed \(0\le\epsilon<1/2\), the integer \(\epsilon\)-approximate maxmin cohort-selection problem is NP-hard. It also states that approximating the number of groups with non-minimum utility is NP-hard within the factor \((e-1)/e+o(1)\). The proof reduces from Minimum Hitting Set; its approximation claim uses the cited maximum-coverage hardness result of Feige [14].

The continuous mirror retains the paper’s additive candidate utilities and indivisible size-\(k\) cohort. Its first quantile is exactly the minimum utility over positive-mass types, so Lemma 20’s maxmin hardness applies directly. In the hitting-set reduction, make each subset \(C_j\) a type of mass \(1/m\), and each universe element \(s_i\) a candidate, with \(v_{t_j,s_i}=1\) precisely when \(s_i\in C_j\). The utility is then \(|S\cap C_j|\). A hitting set exists exactly when the optimal minimum utility is at least \(1\); because these utilities are integral, an additive-\(\epsilon\) solution for \(\epsilon<1/2\) distinguishes that case from minimum utility \(0\). The second part of Lemma 20 also has a direct mass version: under equal type masses, the population mass receiving utility above the minimum is the number of such types divided by \(m\). Thus the corresponding hardness factor carries over on that restricted input family.

I expect this mirror to be Class B: hardness transfers. The reduction’s combinatorics live in choosing candidates to hit subsets, not in the number of people. A polynomial algorithm in the continuous model would already solve the finite hard instances encoded with equal rational masses. That makes this a useful boundary case for the programme: the society is genuinely represented as a distribution, while continuization does not remove hardness.

The authors could plausibly recognize the model as their deterministic cohort problem with the utility recipients represented by valuation types and population shares. The main caveat is also the weakest point: the paper’s objectives are named groups, which may overlap and may each count equally, whereas this mirror applies leximin to individual stakeholder utilities and lets mass determine later quantile intervals. That is a real modeling choice. I think it is defensible where each resident’s utility is the object being protected and types are homogeneous; it would be less convincing if the authors regard each named group, regardless of size, as the irreducible fairness unit.

This case covers the paper’s deterministic integer cohort-selection hardness, not its randomized marginal-selection algorithm or its general definitions of approximate leximax. It leaves natural follow-up questions about parameterized algorithms in \(k\) or support size \(\tau\), and about the weighted quantile objective when type masses are unequal.

The case AGAINST (opponent, writing after the proponent)

The strongest case against the proposed mirror is that it changes who counts as a fairness unit. The paper leximaxes a finite list of chosen, possibly overlapping groups, giving each group a place in the ordering regardless of its population size. The proposed quantile objective leximaxes residents: masses determine how long each utility value occupies the ordered profile. That can reverse priorities among the groups the paper was designed to protect. A faithful version would keep the named groups as the fairness units and use a population distribution only to compute their utilities. That is a real modeling concern, especially if the authors regard group-level guarantees as essential.

But it does not defeat the anchor. The paper’s Lemma 20 is a named computational hardness result, and its reduction embeds directly into the proposed population model: give each hitting-set constraint a valuation type of mass \(1/m\), and each candidate the corresponding \(0\)-\(1\) value. The minimum utility is then the minimum over positive-mass types. It is at least \(1\) exactly when the chosen candidates hit every set, so an additive-\(\epsilon\) solution for \(\epsilon<1/2\) distinguishes the cases. The non-minimum-utility count also becomes population mass above the minimum under equal type masses. The reduction’s combinatorics survive intact.

There is an even more faithful mirror: describe residents by complete types that include their group memberships and candidate values, compute each named group’s utility from its members, and retain the paper’s group-level leximax objective. On instances with disjoint homogeneous constituencies, this represents the paper’s group utilities exactly while allowing arbitrarily many residents per type. Lemma 20’s hard instances fit that regime too. The objection that the proposed quantiles shift the fairness unit therefore weakens that particular formulation, but does not remove the mirror.

Nor can the paper’s randomized marginal-selection algorithm count as an existing continuous-population treatment: it makes the choice fractional while keeping the set of groups finite. That is outcome-space continuity, not a continuous society. A transferred hardness result might be a boundary case rather than a tractability gain, but the programme explicitly treats such boundaries as worthwhile. I do not see an honest way to defeat Lemma 20 or its better group-preserving mirror. The negative case is weak precisely where it needs to be strongest: the computational anchor survives the change of model.
