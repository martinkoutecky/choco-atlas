The continuous mirror question

Given a fixed-width canonized DAG-network \(D\) with rational arc costs and a rational mass distribution \(\mu\) over its occupied-node types \(T\), compute an exact description of the stable cost-rate polytope \(\mathcal C_\mu(D)=\{q\in\mathbb R_{\ge 0}^{T}:\sum_{p\in T}\mu_pq_p=c_D(T),\ \sum_{p\in S}\mu_pq_p\le c_D(S)\ \forall S\subseteq T\}\), where \(c_D(S)\) is the cheapest-trunk cost for connecting the types in \(S\) to the root.

The model it lives in

The society is a distribution \(\mu\) over occupied network locations, with each location a type because its users share the same access options and costs. A type-level rate \(q_p\) assigns cost per unit of population mass there; the output is the core polytope, with total cost \(\sum_p\mu_pq_p=c_D(T)\) and coalition constraints indexed by represented-location sets. The substitution \(y_p=\mu_pq_p\) identifies this polytope with the core of the representative-player game.

What the mirror covers

The mirror covers the core-computation clause of Theorem 6. It leaves the nucleolus clause and the paper’s structural results outside the proposed question.

Open questions for a prover

  • Can the fixed-width algorithm be stated with an explicit bit-complexity bound and an exact polynomial-size output description for binary-rational arc costs and masses?

The case FOR (proponent)

The strongest honest anchor is Theorem 6, proved in this paper. It states that there is a polynomial-time algorithm, in the number of players, to compute both the core and the nucleolus of any DAG-game induced by a fixed-width canonized DAG-network. I find no numbered in-paper hardness result to anchor instead; the NP-hardness claims in the introduction are cited background results about other game classes. So the best case here is for a tractable mirror of Theorem 6’s core-computation part.

A natural regime is a large service population spread across a modest number of locations or service zones. Take users of a fixed-cost water network: people at the same network node have the same access options and face the same construction costs, while many users can live in each zone. Let the type set \(T\) be the occupied nodes, with \(\tau=|T|\), and let \(\mu_p>0\) be the fraction of the population at node \(p\), where \(\sum_{p\in T}\mu_p=1\). This is a high-multiplicity regime when the number of users is very large relative to \(\tau\). The paper’s many-to-one residency map already allows several players at one node, so this is a direct population extension of its model. Fixed width describes networks with bounded branching complexity; it is plausible for a hierarchical service network, though not for every infrastructure network.

Lead question — Fixed-Width Continuum DAG Core. The input is a canonized DAG-network \(D\) of fixed width, with rational arc costs, and a rational mass distribution \(\mu\) over its occupied nodes. For a set \(S\subseteq T\), let \(c_D(S)\) be the cost of the cheapest trunk connecting the nodes in \(S\) to the root. A solution is an exact description of the polytope of stable, type-anonymous cost rates \(q_p\), where \(q_p\) is the construction-cost contribution per unit of population mass at node \(p\):

\[ \mathcal C_\mu(D)= \left\{ q\in\mathbb R_{\ge 0}^{T} : \sum_{p\in T}\mu_p q_p=c_D(T),\ \sum_{p\in S}\mu_p q_p\le c_D(S)\quad\forall S\subseteq T \right\}. \]

The equality allocates the cost of connecting the whole population; each inequality says that no coalition can be charged more than the cost of connecting its represented locations. More precisely, a continuum of users can form a measurable coalition containing any positive fraction of each type. Since costs depend on which locations are represented, and the rates are nonnegative, the strongest constraint for any given support \(S\) comes from including all the mass of those types. Thus the displayed finite system captures the core constraints for all measurable coalitions. In the finite model with \(n_p\) users at node \(p\), setting \(\mu_p=n_p/n\) and \(q_p=n x_p\), where \(x_p\) is each user’s cost share, gives the same type-level inequalities. The continuous question therefore preserves the underlying stability problem rather than changing what coalitions can build.

I expect this question to be tractable for fixed width. The paper’s route is through dually essential coalitions: its fixed-width structural bounds make the coalitions needed to describe the core polynomially enumerable. In the mirror, their constraints are weighted by the rational masses \(\mu_p\); the population becomes a vector of coefficients in the allocation problem. A natural complexity target is polynomial time in the network size, \(\tau\), and the bit length \(L\) of the costs and masses, for each fixed width. That extension is not proved by Theorem 6 itself, but it is a credible continuization of its structural algorithm.

The scope is deliberately limited to the core. Theorem 6 also computes the nucleolus, but I would not claim that its nucleolus clause has an equally clean continuum mirror: the finite nucleolus orders a finite vector of coalition excesses, whereas the continuum has uncountably many measurable coalitions and no automatic finite lexicographic excess vector. A type-level nucleolus that allows only whole types to form coalitions would be precise, but it would omit partial-mass coalitions and needs separate justification as the authors’ intended analogue.

The soft spot is the fixed-cost assumption: an arbitrarily small positive mass at a location triggers the same connection requirement as the full mass there. That is credible when the decision is whether to build access to a service zone, but less so when capacity or usage costs grow with customer volume. The paper’s own network model makes the fixed-cost case a faithful mirror; population-dependent costs would be a further, distinct extension.

The case AGAINST (opponent, writing after the proponent)

Theorem 6 is the only serious anchor: it gives a polynomial-time core algorithm on a meaningful high-multiplicity regime. The location-based water-network example is credible, and neither the paper’s finite-player framing nor the use of a type-level allocation defeats it.

The strongest case against its value is that, for this paper’s fixed construction costs, the proposed continuum core is exactly a smaller finite core in rescaled coordinates. Set \(y_p=\mu_p q_p\). Then the displayed constraints become

\[ \sum_{p\in T} y_p=c_D(T),\qquad \sum_{p\in S} y_p\le c_D(S)\quad(S\subseteq T),\qquad y_p\ge 0. \]

That is the core of the \(\tau\)-player game with one representative at each occupied node. Partial-mass coalitions add no constraints: for a given support, costs depend only on which nodes are represented, while nonnegative charges are maximized by including all the mass at those nodes. The same aggregation works for the paper’s finite game: sum the core shares of co-resident players to get \(y_p\), or split \(y_p\) among them. Thus \(\mu\) changes the reported per-capita rates, but not the core computation. Applying Theorem 6 to the representative-player game gives the proposed fixed-width computation directly.

The best attempt to escape that collapse would make connection costs depend on how much population uses each arc, perhaps through capacity or usage costs. That could give mass a substantive role. But the paper studies fixed construction costs for access to a network; population-dependent costs would change the cost game, and continuization does not force that change. For the faithful mirror, there is no new pricing or optimization problem to investigate.

This is a credible argument that the computational work is already an immediate reduction to the paper’s theorem, rather than a worthwhile new algorithmic project. It does not show that the mirror is ill-posed, and the programme explicitly treats formal dictionaries between discrete and continuous variants as useful deliverables. So the negative case remains weak: I can argue that this anchor adds little computational content, but I cannot honestly establish that the continuous question is not worth recording or studying.
