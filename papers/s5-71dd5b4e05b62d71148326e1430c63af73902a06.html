The continuous mirror question

Given projects \(A\) with positive integer costs \(c(a)\), budget \(L\), a nonincreasing worth vector \(\alpha\) with \(\alpha(1)=L\), and a distribution \(\mu\) over \(\tau\) supported complete weak-ranking types with binary-rational masses, define \(B_t=\{a\in A:c(a)\leq\alpha(r_t(a))\}\). Find a feasible whole-project slate \(S\subseteq A\), with \(c(S)\leq L\), maximizing \(\sum_t\mu_t c(B_t\cap S)\).

The model it lives in

A population is represented by its supported weak-ranking types and their rational masses. Project costs, the budget, and the worth vector are shared across types; the planner chooses an integral feasible slate, maximizing its mass-weighted cost-worthy score.

What the mirror covers

The mirrors cover Theorem 4 for \(f(S)=c(S)\) and Proposition 3 for \(f(S)=|S|\). They leave the other rule families and the paper's axiomatic results aside.

Open questions for a prover

  • Which restrictions on project costs or worth vectors make exact winner determination polynomial-time solvable?
  • What approximation guarantees are useful when welfare is measured in mass-weighted project cost?

The case FOR (proponent)

I would defend two mirrors, with Theorem 4 as the lead. Both keep projects indivisible and continuize the population: a type is a complete weak ranking, its mass is its share of residents, and the planner still chooses a feasible set of whole projects.

A plausible regime is a city or university running a large participatory-budgeting ballot. Tens of thousands of residents rank a shortlist of projects in tiers, with many residents sharing the same ranking because they respond to common proposals or submit a common priority template. Project costs, the budget, and the worth vector are public and shared. A type therefore needs only its ranking; the input lists the \(\tau\) rankings that occur and their rational masses, even if the population is much larger than \(\tau\).

Lead: Mass Cost-Worthy-\(c\) Winner Determination. Theorem 4, proved in this paper, says that \(W_{f,\alpha}\) is NP-hard when \(f(S)=c(S)\) for any worth vector with \(\alpha(1)=L\). Its Subset Sum reduction is also a direct continuous-population reduction.

An instance has projects \(A\) with positive integer costs \(c(a)\), budget \(L\), worth vector \(\alpha\), and a distribution \(\mu\) over the \(\tau\) supported weak rankings. For each type \(t\), define its approved set by the paper’s cost-worthy layer,
\[ B_t=\{a\in A:c(a)\leq \alpha(r_t(a))\}. \]
For a feasible slate \(S\), define its mass-weighted welfare as
\[ W_\mu(S)=\sum_t \mu_t\,c(B_t\cap S). \]
The problem is to return a feasible \(S\) maximizing \(W_\mu(S)\), with all maximizing slates constituting the rule’s outcome.

For the reduction, take Subset Sum items \(x_1,\ldots,x_m\) and target \(Z\), removing any item larger than \(Z\). Set \(c(a_j)=x_j\), \(L=Z\), and \(\alpha(1)=Z\). Give the society one type of mass \(1\), ranking all projects in a single top tier. That type approves every project, so \(W_\mu(S)=c(S)\). A feasible slate has welfare at least \(Z\) exactly when its projects’ costs sum to \(Z\). This gives NP-hardness with \(\tau=1\). Any number of residents can share that type; replicating them leaves the mass and optimization problem unchanged. Theorem 4 is therefore a Class B mirror: the Subset Sum hardness transfers from the discrete problem, and its combinatorics lie in project costs and slate selection.

Questions it generates include which cost restrictions make exact winner determination tractable, and what additive approximation in budget value is useful for realistic project costs.

Second mirror: Mass Cost-Worthy-Count Winner Determination. Proposition 3, also proved here, says that \(W_{f,\alpha}\) is polynomial-time computable for every worth vector when \(f(S)=|S|\). With an explicitly listed electorate, the paper’s dynamic program runs in \(O(m^2n)\).

The continuous problem uses the same instance structure and approval sets \(B_t\), but maximizes
\[ W_\mu(S)=\sum_t\mu_t\,|B_t\cap S| \]
over feasible slates. Here the solution is again an optimal whole-project slate. For each project \(a\), its value is the mass of types approving it, so this is a knapsack problem with rational values and project costs.

That change in representation matters. Reduce Subset Sum with positive items \(x_1,\ldots,x_m\), target \(Z\), and \(x_j\leq Z\). Set \(c(a_j)=x_j\), \(L=Z\), and \(\alpha=(Z,0,\ldots,0)\). Type \(t_j\) ranks \(a_j\) first and all other projects below it, and has mass \(\mu_{t_j}=x_j/M\), where \(M=\sum_jx_j\). Each type approves only its own project. Thus
\[ W_\mu(S)=\frac{c(S)}{M}. \]
There is a feasible slate with welfare at least \(Z/M\) exactly when some subset of the items sums to \(Z\). So this continuous mirror is NP-hard in \(m\), \(\tau\), and the binary input length, despite Proposition 3’s polynomial result for an explicitly listed population.

Relative to the paper’s explicit-agent representation, I expect this mirror to be Class C: binary-encoded masses make a high-multiplicity instance compact, and the paper’s \(O(m^2n)\) running time can be exponential in the mass denominators’ bit length. Equivalently, the reduction describes a discrete electorate with \(x_j\) copies of type \(t_j\); writing out all those voters can require \(M\) entries. Scaling the items and target by a common factor leaves the masses unchanged while making the implied population arbitrarily large compared with \(\tau\). This is a population mirror in the programme’s sense, with the precise caveat that a baseline already using binary-encoded multiplicities would call it high-multiplicity discrete hardness.

Further questions include which worth vectors or cost restrictions recover exact polynomial algorithms, and what approximation guarantees can be stated in population-mass units.

The authors should recognize both questions as theirs: each applies their stated layer, utility, budget constraint, and slate objective, replacing voter counts by type masses. The second changes the input regime, not the decision rule; the first even has a one-type mirror. These mirrors cover two winner-determination results only. They do not extend the paper’s axiomatic results or its other rule families.

The weakest point is that Theorem 4’s mirror is almost an exact restatement after normalization, and its hardness does not depend on population size. The second mirror’s new hardness comes from compressed multiplicities, so it would need to be presented as a high-multiplicity complexity question, not as a general claim that continuity itself makes computation harder. Neither result supplies a tractable continuous solver. The case for the mirror rests on a precise, natural population model and a useful contrast between the explicit and high-multiplicity computational questions it exposes.

The case AGAINST (opponent, writing after the proponent)

The strongest case against is that the paper’s computational structure changes very little under continuization. Its rules use agents only through sums of their contributions. Group agents by weak ranking, replace each group’s count by its mass, and the selected projects remain indivisible. For the two cost-worthy rules raised here, the resulting objectives are just weighted \(0/1\) knapsack objectives: one assigns project \(a\) value \(c(a)\sum_{t:a\in B_t}\mu_t\), the other value \(\sum_{t:a\in B_t}\mu_t\). That gives the mirror little of the continuous-optimization character that motivates much of ChoCo.

It does not, however, defeat the first anchor. A city or university ballot with many residents and recurring weak rankings is a plausible high-multiplicity regime. Theorem 4’s one-type reduction is an especially narrow case: its mass is \(1\), so it exposes no mass trade-off. But the better mirror allows several supported rankings and asks for exact winner determination from rational type masses. Its reduction to weighted knapsack makes it familiar, not ill-posed. Nor can I reject it because its hardness comes from project selection: the programme explicitly treats that as a possible boundary result.

The second anchor is harder to dismiss. The mass objective for Proposition 3 is exact winner determination with rational profits. The proposed Subset Sum construction gives a valid mirror: type \(t_j\) has mass \(x_j/M\), approves only project \(a_j\), and the feasible slate’s value is \(c(S)/M\). A value of at least \(Z/M\), under budget \(Z\), exists exactly when some subset sums to \(Z\). The construction uses binary-encoded multiplicities, but that is precisely the high-multiplicity bridge the programme is meant to examine. Calling it compressed discrete input does not make it a collision or a modeling objection.

The paper has named computational results, so “no result to mirror” does not apply. Its rules also do not track named recipients: a weak ranking is a complete enough type for these objectives. Nothing in the supplied paper establishes that this continuous computational question has already been answered. Axiomatic continuity elsewhere in participatory budgeting would not settle it.

So the negative case is mainly about research yield: these mirrors appear to reduce to standard knapsack questions, rather than opening a new optimization structure. That may make them less attractive than mirrors built around an exponential-variable LP or a difficult pricing problem. But the programme permits ordinary complexity questions, and a low-novelty objection does not show that no scenario yields a worthwhile mirror. I cannot honestly defeat either anchor on the grounds allowed here; the universal negative case is weak.
