What the mirror covers

The proposed mirror addresses only Theorem 3, restricted to anonymous outcomes and gateway cohorts; it does not cover Theorems 1 and 2 or the paper’s general named-agent outcome functions.

The case FOR (proponent)

The strongest case is Theorem 3, because it already concerns coalitions rather than only a single agent’s deviation. Theorem 3, stated in this paper with its proof omitted from this report, says: for an environment \(E\) and a ring communication graph \(L\), if an outcome function is strongly implementable by a standard mechanism in \(E\), then it is strongly implementable by a distributed protocol in \((E,L)\). Here, strong implementation rules out a coalition whose joint deviation benefits every member.

A plausible high-multiplicity setting is a large marketplace served through a fixed ring of regional gateways. Many participants share each gateway and one of a small number of private-value types; their utility-relevant type is therefore \((r,w)\), where \(r\) is the gateway role and \(w\) the value type. A society is a rational mass vector \(\mu\) over \(T=R\times W\), with \(\sum_{r,w}\mu_{r,w}=1\). Millions of participants can then be represented by a modest support of gateway–value pairs. The mass being rerouted or changing its messages has an operational meaning: it is a fraction of participants, not a count of named people.

Here is the continuous question I would put to a prover. Call it Mass-Strong Ring Implementation. An instance gives finite sets \(R,W,A\), with \(R\) a ring; utilities \(u(a,r,w)\); a rational mass profile \(\mu\in\Delta(R\times W)\); and an explicitly represented anonymous outcome rule \(G\) on a stated domain of mass profiles. It also gives a direct mechanism that strongly implements \(G\): truthful reporting produces \(G(\mu)\), and no measurable coalition of positive mass can coordinate a deviation that strictly benefits every member. A distributed protocol is a finite-round binary-message protocol over the ring, with mass of each \((r,w)\) type allowed to split among messages in rational proportions. The question is whether one can construct such a protocol so that compliant message flows produce exactly \(G(\mu)\), while no positive-mass coalition can profitably alter, withhold, or reroute messages. A solution is the protocol and its prescribed type-contingent message flows, with the implementation and equilibrium guarantees.

I expect this restricted synthesis problem to be Class A, though that is a conjecture about the continuous version, not a result in the paper. The paper’s protocols already use message encodings to match type probabilities and, in the strong-implementation construction, random keys to detect tampering. With rational mass inputs, splitting a cohort among encoded messages appears to offer a direct way to represent those probabilities exactly. The main follow-up questions are whether the key correlations and coalition checks survive aggregation, and what bounds one can prove on message length and rounds in terms of support size and input bit length.

This mirror covers Theorem 3’s strong implementation result for anonymous mass-based outcomes in a high-multiplicity gateway scenario. It does not cover the paper’s full class of outcome functions, which may depend on the ordered profile of named agents. The paper does not give complexity bounds for protocol synthesis, so establishing an efficient algorithm would be new work; the theorem itself is an existence result.

The weakest point is that the mirror treats a gateway cohort as a mass stream with identifiable message lanes. The original model has one player at each network node, and its proof uses per-agent keys. Moving from those individual paths to measure-valued traffic while preserving identity-sensitive checks is a real modeling and proof obligation. That limitation matters, but it does not erase the core match: the question still asks whether an outcome implementable by a direct mechanism remains implementable through a ring network when agents can tamper with communication, now with a high-multiplicity population and coalition deviations measured by mass.

The case AGAINST (opponent, writing after the proponent)

Theorem 3 is the strongest anchor, but its key object is not a population of interchangeable participants. It is a ring whose vertices are the agents: each agent has a particular place in the communication network, can relay or alter other agents’ messages, and receives a key intended for that agent’s report. The proponent’s gateway scenario changes this structure. If a gateway is a vertex, the paper’s model gives it one player; if many participants sit behind it, their messages, identities, and ability to interfere with one another need a new model.

That leaves a poor fit for high multiplicity. Keep the paper’s one-agent-per-vertex setup and enlarge the ring, and agents’ positions affect the routes and messages relevant to implementation. A type that omits position loses information the problem uses; including it can make the support grow with the population. Collapse positions into a finite set of gateway roles, and the ring’s individual message paths disappear. A continuum of mass moving through regional relays could be interesting, but it would need its own account of routing, timing, and tampering. It is not a direct mass version of the theorem’s ring protocol.

There is a sharper mismatch in the equilibrium guarantee. Strong implementation excludes profitable deviations by any coalition, including a single agent. In a nonatomic mass-flow model, one agent has measure zero, so its altered message does not change the flow the center observes. Requiring only positive-mass coalitions to be unprofitable therefore weakens the security claim at exactly the point where the paper’s construction checks individual reports with individual keys. Retaining single-agent deviations requires retaining agents as atoms; then a distribution over types alone does not describe the relevant protocol state.

The proposed synthesis problem also adds substantial machinery to an existential transfer theorem. Theorem 3 says that an outcome function implementable by a standard mechanism has a distributed implementation; it gives no complexity bound for synthesizing protocols from an encoded outcome rule. To ask for an efficient continuous synthesis algorithm, one would need to specify succinct inputs, the continuum’s network and message semantics, and what it means to verify coalition-proofness for mass flows. Those choices may produce a worthwhile problem, but its computational content would come largely from that new formalization, not from continuizing the theorem.

So I would reject Mass-Strong Ring Implementation as a convincing mirror of Theorem 3: preserving the ring and its individual checks leaves no clear population-level compression, while compressing them changes the network or weakens the guarantee. That is a strong reason against this anchor, not a proof that no reasonable continuous model can be devised. An anonymous mass-traffic model with explicit relay roles could still be worth studying; on the paper alone, though, I cannot honestly rule out every such scenario.
