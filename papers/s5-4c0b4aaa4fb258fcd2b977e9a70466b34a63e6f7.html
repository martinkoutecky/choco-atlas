The continuous mirror question

Given  m  ordered resource classes, \tau supported types with rational masses \mu_t, interval eligibility, rational values  v_j>0, and rational per-capita supplies  b_j, each member must receive an integral bundle. The model it lives in

A society of total mass one has \tau types with rational masses and interval eligibility over  m repeatable resource classes. Class  j has value  v_j and supply  b_j per unit of population. Each person receives an integral bundle; a distribution  x_{t,a} over bundles must allocate all type mass within supplies, and the objective is to maximize the minimum utility threshold  q.

The case FOR (proponent)

The strongest anchor I see is Theorem 6, proved in this paper. It concerns the Max-Min allocation problem on a convex bipartite graph: there are \(n\) players and \(m\) indivisible items, each item \(j\) has value \(v_j\) for every adjacent player and zero value for the others, and each player’s neighbors form an interval in the item ordering. A feasible solution assigns every item to one adjacent player, and its value is the minimum total utility received by any player. Theorem 6 gives, for every \(k\ge 3\), an algorithm achieving at least \(1-\frac{3}{k+1}\) times the optimum in time \(O(n^2m^{K+2})\), where \(K=\left\lceil\frac{\log k}{\log(1+1/k)}\right\rceil\). Thus it gives a PTAS for this restricted Max-Min problem. The paper also mentions strong NP-completeness in its introduction, but that statement is not a numbered result, so I use Theorem 6 as the anchor.

My lead mirror is Interval-Type High-Multiplicity Max-Min Allocation. Consider a large population distributed over \(\tau\) supported types, with type \(t\) having mass \(\mu_t\), where \(\sum_t\mu_t=1\). Its eligible resource classes form an interval \([\ell_t,r_t]\) in an ordering of \(m\) classes. Class \(j\) has value \(v_j>0\) to every eligible person and a supply of \(b_j\ge0\) units per person in the population. The masses, supplies, and values are binary rationals. A type completely specifies how its members participate in the problem; in this model, members of one type have the same eligibility and values.

A solution chooses a threshold \(q\) and nonnegative masses \(x_{t,a}\). Here \(x_{t,a}\) is the mass of type \(t\) receiving bundle \(a\), with \(a\in\mathbb Z_{\ge0}^m\) and \(a_j=0\) outside that type’s interval. Each person still receives an integral bundle; only the mass of people receiving each bundle can be fractional. Feasibility requires \(\sum_a x_{t,a}=\mu_t\) for every type, every used bundle to satisfy \(\sum_jv_ja_j\ge q\), and total use of each class to satisfy \(\sum_{t,a}x_{t,a}a_j\le b_j\). The objective is to maximize \(q\). It suffices to consider inclusion-minimal bundles meeting \(q\), so the bundle set is finite for any threshold.

The computational question is whether this problem has a PTAS: for each fixed \(\epsilon>0\), given the instance, output a feasible allocation with \(q\ge(1-\epsilon)q^*\), in time polynomial in \(m,\tau,L\), where \(L\) is the input bit length. In the trichotomy’s terms, I expect Class A for approximation. The paper’s interval structure and its rounding of item values give a plausible route: approximate the useful bundle patterns, then combine them in the right proportions to meet the rational type masses and supplies. That is a research hypothesis, not a consequence of Theorem 6.

A natural regime is a large resource-distribution programme with many recipients but relatively few cohorts sharing contiguous eligibility windows over ordered, repeatable resource classes. For example, a cohort might be eligible for classes released during one time window. The population count \(N\) can be enormous while \(\tau\) stays modest; each class’s inventory scales with \(N\), at a fixed rate \(b_j\) per resident. This is a high-multiplicity version of the paper’s problem: it keeps the additive utility, integral bundles, interval eligibility, and minimum-utility objective, while replacing named recipients with masses of indistinguishable recipients. For rational inputs, a feasible rational mass allocation can be realized by taking a sufficiently large population and scaling its type counts and inventories accordingly. Establishing precise bounds for that discrete-to-continuous dictionary is itself a worthwhile follow-up.

The mirror covers Theorem 6’s convex-graph Max-Min result. It does not try to cover the paper’s Min-Max scheduling result or its tree-neighborhood extension. The paper’s theorem is useful evidence for the mirror because its algorithm exploits ordering and interval structure, rather than relying only on the number of explicitly listed players. The authors should recognize the resulting problem as theirs: it is the same allocation question with repeated, complete types and per-capita supplies.

The weakest point is that Theorem 6 is not a compressed high-multiplicity algorithm. Its running time depends on the explicit player count \(n\), and the paper has one-off items whereas the mirror has repeated resource classes whose supply scales with the population. So the theorem does not establish the requested runtime in \((m,\tau,L)\). The case for the mirror rests on the model’s direct high-multiplicity interpretation and the apparent relevance of the paper’s structural ideas—not on a claim that its PTAS already transfers.

The main follow-up questions are whether interval structure yields the proposed PTAS with no dependence on the denominator-expanded population size; whether exact optimization or bundle-pricing is hard even for a single supported type; and how sharply the continuous optimum predicts finite instances at a specified population size.

The case AGAINST (opponent, writing after the proponent)

Theorem 6 is the right anchor, but its most literal continuum limit breaks the objective. Keep the paper’s finite set of one-off items and spread the players over a population of total mass one. Only a zero-mass set of people can receive any items, so the essential minimum utility is zero. The theorem’s nontrivial fairness question disappears.

The strongest repair is the proponent’s: make each item class repeatable, with supply proportional to population, and give every member of a type the same interval of eligible classes and the same values. That is a coherent high-multiplicity allocation problem. The source paper’s explicit-player algorithm does not settle its running time in \(m,\tau,L\): expanding rational masses into individual players and copied items can make the instance size depend on the denominators. Still, that gap is precisely a computational question, rather than a reason to dismiss the mirror.

Nor does the repair obviously erase the problem’s substance. Members still receive integral bundles, and a distribution over bundles must meet every type’s minimum-utility threshold while respecting class supplies. The resulting configuration problem could be hard, or the interval structure could support an approximation algorithm. Either outcome would be relevant to the programme. The theorem’s interval argument offers motivation, though it does not establish that its PTAS transfers.

So the strongest negative case is that the unchanged finite-item model degenerates, while the repaired model changes one-off goods into per-capita supplies of repeated classes. That is a real limitation on how directly Theorem 6 supports the proposed mirror. It does not defeat the repaired mirror: the programme explicitly allows supplies to scale with population, and the resulting high-multiplicity problem is sensible. I can’t honestly make the case that no worthwhile mirror exists in any scenario; this anchor’s best version survives.
