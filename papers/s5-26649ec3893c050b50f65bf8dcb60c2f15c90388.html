The continuous mirror question

Given a finite set \(T\) of household market-situation strata, positive rational masses \(\mu_t\) summing to \(1\), per-household prices \(p_t\), aggregate bundles \(q_t\), and assignable lower bounds \(q_t^1,q_t^2\) with \(q_t^1+q_t^2\le q_t\), choose \(\mathcal A\in\{\mathrm{GARP},\mathrm{SARP}\}\). Do there exist per-situation splits \(x_t^1,x_t^2\in\mathbb R_+^m\) satisfying \(x_t^1+x_t^2=q_t\) and \(x_t^\ell\ge q_t^\ell\), such that for each role \(\ell\), the data \(\{(p_t,x_t^\ell):t\in T\}\) satisfy \(\mathcal A\) under one shared role-specific preference relation across the cohort’s market situations?

The model it lives in

A continuous population of two-adult households distributed with masses \(\mu_t\) across observed market-situation strata. Each stratum has per-household prices, aggregate consumption, and assignable bounds; the decision variables are per-household member-level splits, and the feasibility objective is collective GARP or SARP rationalizability under shared role-specific preferences.

What the mirror covers

The mirror covers Theorem 1’s NP-completeness results for 2-GARP and 2-SARP; it leaves the MIP formulations, simulated-annealing heuristic, and computational experiments unmirrored.

Open questions for a prover

  • What is the parameterized complexity in the number of distinct strata \(|T|\) and the number of goods \(m\)?
  • Which restrictions on repeated or related market situations yield tractable rationalizability tests?

The case FOR (proponent)

I would make one case, anchored on Theorem 1. It proves that both Problem 2-GARP and Problem 2-SARP are NP-complete, even with no assignable information. The result is proved in this paper’s Appendix A; its reduction uses the earlier NP-completeness result for CARP. I would mirror both clauses with one problem whose input selects GARP or SARP.

Call it Continuous Two-Member Collective Rationalizability. An instance has \(m\) goods and a finite support \(T\) of \(\tau\) household observation types. Each type \(t\) has positive rational mass \(\mu_t\), with \(\sum_{t\in T}\mu_t=1\), a positive price vector \(p_t\), a per-household aggregate bundle \(q_t\), and assignable lower bounds \(q_t^1,q_t^2\) (with \(q_t^1+q_t^2\le q_t\)). The mass \(\mu_t\) is the fraction of households in that observed market situation; if the data give cell totals, \(q_t\) is the per-household bundle.

The question takes \(\mathcal A\in\{\mathrm{GARP},\mathrm{SARP}\}\): do there exist per-household splits \(x_t^1,x_t^2\in\mathbb R_+^m\) for every supported type, satisfying \(x_t^1+x_t^2=q_t\) and \(x_t^\ell\ge q_t^\ell\), such that each member’s type-indexed consumption data satisfy \(\mathcal A\)? For member \(\ell\), type \(s\) directly reveals preference over type \(t\) when \(p_s^\top x_s^\ell\ge p_s^\top x_t^\ell\). GARP requires that if \(s\) is preferred to \(t\) by the transitive closure of this relation, then \(p_t^\top x_t^\ell\le p_t^\top x_s^\ell\). SARP requires the strict inequality when \(x_s^\ell\ne x_t^\ell\). A solution is the family of per-type splits witnessing the selected axiom.

The intended regime is a large cohort of similar two-adult households, with many households per stratum but relatively few distinct price, bundle, and assignability records: \(N\gg\tau\). Role-specific preferences are unknown, but the rationalizability hypothesis tests whether the cohort can be described by the same two preference relations across those market situations. This is a plausible setting for the paper’s stated applications to large scanner and cross-sectional household data. The mirror concerns continuity of the household population; the fact that consumption quantities are real-valued is not the reason it qualifies.

I expect hardness to transfer (Class B) when \(\tau\) is unrestricted. Any finite instance of either discrete problem can be used as the support of a society, assigning each type positive rational mass—for example, equal mass. The same split variables and revealed-preference conditions decide the instance. The theorem’s hardness is therefore retained as the number of distinct observation types grows; duplicating households within a type does not remove its combinatorics. Useful follow-up questions include whether the problem is fixed-parameter tractable in \(m\) or \(\tau\), and whether particular low-support or repeated-market regimes admit efficient algorithms.

The weakest point is that the paper’s \(n\) indexes jointly tested observations, not straightforwardly interchangeable copies of households. My mirror reads cross-sectional observations as market-situation strata in a homogeneous cohort, and requires common role-specific preferences across them. That is a substantive assumption: if households in different strata have different preferences, this is no longer the paper’s test. Also, once per-household bundles are specified, the masses affect cohort prevalence but not the GARP/SARP feasibility question; the complexity is in the support, not population size. So this is a credible, authors-recognizable population setting for their collective rationality test, but it does not claim that mere growth in the number of households makes the test easier.

The case AGAINST (opponent, writing after the proponent)

Theorem 1 is the one serious anchor: it gives a named NP-completeness result for both 2-GARP and 2-SARP. The strongest objection is that its \(n\) counts observations for the same two household members, not interchangeable households. The preference graph compares bundles across observations for each persistent member. If a type is instead a complete household history, testing each positive-mass type is an independent within-household test. The theorem’s hard coupling is inside each history; population mass does not create it.

There are two ways to try to recover that coupling, and each changes what the rows mean. Treating rows as separate household strata makes them populations of different couples, then requires the same role-specific preferences to hold across those couples. Treating all rows as situations faced by one homogeneous cohort preserves the original test, but the rows are situations, not agent types: the population has one shared profile, and its mass does not enter the test. A continuous distribution over situations also has no natural weighting in GARP or SARP: any positive-mass situation imposes the full pairwise constraints, however small its mass.

The best version of the mirror is a large, homogeneous cohort of two-adult households, all sharing the same role-specific preferences and observed across a finite set of market situations. That is conceivable, and Theorem 1 then carries over with the number of distinct situations as support size. But the population continuum is incidental to the complexity result; the assumption that makes the pooled test work is shared preferences across situations, not high multiplicity of households.

So the negative case is strongest against the claim that this theorem charts a population-continuization frontier: it charts complexity in the number of choice situations. It is not airtight. If the authors accept the homogeneous-cohort interpretation, the theorem has a clean high-multiplicity mirror. I cannot honestly rule out that scenario, so the case against this anchor—and against any worthwhile mirror of the paper—is weak.
